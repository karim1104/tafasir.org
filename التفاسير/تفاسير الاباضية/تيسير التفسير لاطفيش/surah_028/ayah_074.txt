{ ويَوْم يُنادِيهم } مثل ما مر { فيقول أين شركائى الذين كُنتُم تزعُمُون } تكرير للأول لزيادة التذكر ، ولا شىء أجلب لغضب الله من الاشراك ، كما لا شىء أدخل فى رحمته من توحيده عز وجل أو الأول لبيان فساد رأيهم لقوله : { حق عليهم القول } [ القصص : 63 ] والثانى لبيان أن إشراكهم لا سند له ، بل مجرد الهوى لقوله :<br />
{ قل هاتوا برهانكم } [ البقرة : 111 ] أو الأول إحضار لشركائهم بعدم الصلوح لقوله تعالى : { ادعوا شركاءكم فدعوهم } [ القصص : 64 ] الخ ، وهذا تحسير بأنه لا فائدة لهم لقوله عز وجل : { وضل عنهم ما كانوا يفترون } [ القصص : 75 ] .
