{ فِي أيِّ صُورَةٍ } متعلق بركبك أو حال من الكاف الاسمية { مَّا } صلة للتأكيد أو للتعميم وهى حرف أو نكرة غير موصوفة وهى نعت بمعنى عجيبة { شاءَ رَكَّبَكَ } أى ركبك فى أى صورة شاء تركيبك عليها من طول وقصر ورقة وغلظ وحمرة وبياض والحسن والقبح والذكورة والأُنوثة وشبه أب أو أم أو خال أو عمة أو خالة وإن شاء خلقك على صورة بعير أو بقرة أو ظبى ونحو ذلك وأى بمعنى الصفة ولم تعطف الجملة لأنها بيان لعدلك وقال بعض أى موصولة صلتها شاء أى شاءها وما صلة وذلك قول ابن عصفور بجواز إضافة أى الموصولة إلى النكرة وأجاز بعض أنها شرطية كما تقول بمن تمْر أمر وركبك بمعنى المستقبل وأجيز تعليق فى بعدلك وما مفعول مطلق اسم شرط أى أى تركيب شاء ركبك . <br />
