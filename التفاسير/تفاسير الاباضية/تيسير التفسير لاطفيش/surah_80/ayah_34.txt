{ يَوْمَ } بدل من إِذا أو من الصاخة وهذا على بنائه كما فى قوله يوم يتذكر { يَفِرُّ الْمَرْءُ } يفر بقلبه أو بإِعراضه لا برجليه إِذ لا يجد أهل المحشر الذهاب حيث شاءُوا . <br />
{ مِنْ أخِيهِ .  وَأُمِّهِ وَأبِيهِ .  وَصَاحِبَتِهِ } زوجه ، { وَبَنِيهِ } قيل المراد الهروب ممن كان يقرب منه ويتعزز به فى الدنيا وقوله : { لِكُلِّ امْرِئٍ مِّنْهُمْ يَوْمَئِذٍ شَأْنٌ يُغْنِيهِ } . <br />
