{ إنَّما السَّبيلُ على الَّذين يظْلمونَ النَّاس } ابتداء أو فى الانتصار بالزيادة ، أو بما لا يجوز مثل أن يضربك فتفسد ماله ، أو يقول فيك سوء فتضربه { ويبغُونَ في الأرض } وقوله : { بغَير الحق } حال مؤكدة ، لأن البغى أبداً غير حق ، { أولئك } الباغون بغير الحق مشركين أو موحدين { لَهُم } ببغيهم هو متعلق بيبغون لتأكيد كذلك { عَذابٌ أليمٌ } شديد حتى كأنه نفسه متألم كالذى أصابه ، أو ذوى ألم فيمن أصيب به ، أو مؤلم من استعمال الثلاثى المجرد بمعنى الرباعى بالزيادة ، إذ ورد ذلك فى ألفاظ أو على حذف مضاف أى أليم صاحبه . <br />
