{ قال } تصديقاً لهم { إنْ } ما { لبثتم إلاَّ قليلاً } لبثاً قليلا أو زماناً قليلا { لو أنَّكم } لو ثبت أنكم { كُنْتم تعلمون } ما يصلح بكم ، أو تعلمون فى الدنيا مدة اللبث مدة عاماً نافعاً لعملتم بموجب قصرها ، وهو التوحيد والطاعة ، ولم تغتروا عن هذا اليوم ، وكأنهم لم يعلموا ، فإن من لم يعمل بما علم كجاهله ، وقيل ذلك سؤال عن مدة لبثهم فى القبور ، ويرده ما روى أن الله تعالى يقول لأهل الجنة فيها : { كم لبثتم فى الأرض عدد سنين } [ المؤمنون : 112 ] فيقولون : { يوماً أو بعض يوم } [ المؤمنون : 113 ] فيقول : لنعم ما انجزتم فى اليوم أو بعض اليوم ، اخلدوا فى رحمتى وجنتى ، ويقول لأهل النار : { كم لبثتم فى الأرض عدد سنين } [ المؤمنون : 112 ] فيقولون : { يوماً أو بعض يوم } [ المؤمنون : 113 ] فيقول لبئس ما فعلتم فى اليوم أو بعض اليوم اخلدوا فى غضى ونارى .
