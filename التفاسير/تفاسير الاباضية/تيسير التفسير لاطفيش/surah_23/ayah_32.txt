{ فأرسلنا فيهم } قال فيهم ، لأنه نشأ فيهم كما قال :  "  كذلك أرسلنا فى أمة  "  { رسولاً منْهُم } هوداً لقوله تعالى : { واذكروا إذ جعَلكم خلفاء من بعد قوم نوح } [ الأعراف : 59 ] ولمجىء قصتهم بعد قصة قوم نوح فى سائر السور ، وقيل : القوم الآخرون قوم صالح ، والرسول صالح لقوله : { فأخذتهم الصيحة } [ المؤمنون : 41 ] وهم المهلكون بالصيحة ، وقوم هود أهلكوا بريح ، وأجيب بأن جبريل صاح عليهم منها : { أن اعْبُدوا الله ما لَكُم من إلهٍ غيرُهُ أفلا تتقون  }
