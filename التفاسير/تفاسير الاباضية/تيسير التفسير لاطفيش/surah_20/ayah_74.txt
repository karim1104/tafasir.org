{ إنَّه } الخ تقرير لقولهم : { والله خير وأبقى } [ طه : 73 ] ورد على فرعون الذي يشتد عذابه وثوابه ،  مع دوام هو الله عز وجل ،  وأكد بضمير الشأن { من يَأتِ } بالموت أو بالبعث { ربَّهُ مُجْرماً } بالشرك أو غيره بالشرك أو غيره من الكبائر { فإن لّه جَهنَّم لا يمُوتُ فيها } فيستريح { ولا يحيا } فيها حياة نافعة .
