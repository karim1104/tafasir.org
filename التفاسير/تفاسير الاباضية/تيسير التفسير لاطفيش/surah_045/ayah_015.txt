{ مَن عَمل صالحاً فلنفْسِه } فعمله لنفسه { ومَن أساءَ } أذنب ومات غير تائب { فعَليْها } فعمله على نفسه ، لا يتعدى عمل الى غير عامله ، والآية فى الموحد والمشرك ، ومن عمل حسنة ونواها لغيره أثيبا معا ، وقصده ونواه لنفسه لا لغيره { ثُم } للترتيب الذكري بلا تراخ أو مع تراخ رتبي ، والعطف على الجملة قبلها { إلى ربِّكُم تُرجَعون } للجزاء . <br />
