{ إِنَّ لَدَيْنَا } عندنا { أنكَالاً } جمع نكل بكسر النون وهو أوفق لهذا الجمع أو بفتحها والأَوفق له أنكلُ وهو القيود الشديدة وهو المعروف فى اللغة ، وفسرها الكلبى بالأَغلال ،وعن الشعبى لم تجعل الأَنكال فى أرجلهم حبساً عن الهروب لأَنه لا موضع فى النار يهربون إِليه يستريحون فيه أو ينجون فيه ولا يفوتون الزبانية بل لتسفل بهم إِذا أرادوا الانتفاع { وَجَحِيماً } ناراً شديدة الاتقاد . <br />
