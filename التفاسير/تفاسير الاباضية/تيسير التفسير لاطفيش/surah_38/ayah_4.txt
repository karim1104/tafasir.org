{ وعَجبُوا } عجب الكفرة قريش عجب نفى وانكار { أنْ جاءهم } من أن جاءهم { مُنْذرٌ } أى من مجيئهم نذير يرفع نذير على الفاعلية للمجىء بالمضاف للمفعول ، والنذير الرسول يخبرهم بالعقاب على الكفر { مِنْهم } من جنسهم وهو البشر أو خوفهم وهو الأميون الذين لا يكتبون ولا يقرءون مكتوبا { وقال الكافرون } مقتضى الظاهر ، وقالوا لكن ذكرهم ذما لهم باسم الرسوخ فى الكفر { هذا } أى محمد صلى الله عليه وسلم { ساحِرٌ } فيما يقوله عظيم لا يطاق { كذَّابٌ } فيما يقوله عن الله بأنه واحد ، وبالعقاب عن من قال بالتعدد . <br />
