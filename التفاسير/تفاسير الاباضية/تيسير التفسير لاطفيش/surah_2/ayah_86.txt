{ أُوْلَئِكَ الَّذِينَ اشْتَرَوْا الحَيَوةَ الدُّنْيَا } لذتها ومتاعها { بِالآخِرَةِ } فباعوا ما لهم فيها من الخير بالدنيا ،  بأن ضيعوا دينهم لأجل تحصيل الدنيا { فَلاَ يُخَفَّفُ عَنْهُمُ الْعَذَابُ } فى الآخرة أو فيها وفى الدنيا { وَلاَ هُمْ يُنْصَرُونَ } يمنعون منه ألبنة ،  أو لا ينصرون بترك الجزية . <br />
