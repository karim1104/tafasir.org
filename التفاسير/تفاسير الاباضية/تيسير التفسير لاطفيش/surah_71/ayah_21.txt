{ قَالَ } لمناجاة الله تعالى .  { نُوحٌ } أظهر لطول الفصل .  { رَّبِّ } يا رب .  { إِنَّهُمْ } أى إِن غير المتجبرين بالمال أو الولد المجموع لا الجميع بدليل قوله تعالى { واتبعوا من لم يزده ماله وولده إِلاَّ خساراً } { عَصَوْنِي } من حين بلغت الرسالة إِليهم إِلى الآن .  { وَاتَّبعُوا مَن لَّمْ يَزِدْهُ مَالُهُ ووَلَدُهُ إِلاَّ خَسَاراً } كفر أكابرهم ذوو المال والولد استغناء بحالهم واتبعهم باقيهم تقليداً أو مداهنة أو طمعاً أو خوفاً . <br />
