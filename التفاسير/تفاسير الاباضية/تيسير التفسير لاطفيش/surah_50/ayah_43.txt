{ إنَّا نحْنُ } لا غيرنا { نُحْيي } نحيى النطف ونحوها ، فتصير حيوانا { ونُميتُ } الأحياء ، أو المراد بالاحياء احياء الدنيا ، واحياء البعث ، وعلى كل حال الآية حجة على منكرى البعث { وإليْنَا } وحذف لا الى غيرنا وحده ، ولا الى غيرنا معنا { المَصِيرُ } مصدر ميمى أى الرجوع للحساب والجزاء . <br />
