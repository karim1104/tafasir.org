{ إنَّ أَوْلَى النَّاسِ } أقربهم وأخصهم { بِإِبْرَاهِيمَ } بالفخر به والكون من آله وحزبه { لَلَّذِينَ اتَّبَعُوهُ } فى شريعته من أهل زمانه وبعده حتى تغيرت بالبدع أو بنحو التوراة { وَهَذَا النَّبِىُّ } محمد صلى الله عليه وسلم { وَالَّذِينَ ءَامَنُوا } من أمته لكونهم على دينه ،  أصوله كلها وفروعه كلها أو جلها ،  لا اليهود ولا النصارى المتبعون للتوراة والإنجيل ولا الملحدون منهم ،  والمبتدعون ،  والعطفان تخصيص بعد تعميم { وَاللهُ وَلِىُّ الْمُؤْمِنينَ } ناصرهم ومجازيهم على إيمانهم بالجنة وما دونها . <br />
