{ فدعا ربَّه أنَّ هؤلاء } بأن هؤلاء الكفرة فرعون وقومه { قومٌ مُجْرمُون } مبالغون فى الكفر ، وأنت أعلم بهم ، فعجل لهم ما يستحقون باجرامهم ، أو قال : { ربنا لا تجعلنا فتنة للقوم الظالمين } [ يونس : 85 ] الى قوله : { حتى يروا العذاب الأليم } [ يونس : 88 ] والآية تتضمن الدعاء والاجابة لذكر دعائه ، وما يوجب الهلاك .
