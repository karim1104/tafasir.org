{ أمْ تَسْأَلُهُمْ } بل أتسأَلهم ، { أجْراً } دنيوياً على تبليغ الوحى ، { فَهُم } بسببه ، { مِّن مَّغْرَمٍ } مصدر ميمى أى غرامة ، { مُّثْقَلُونَ } ملزومون ما يثقلهم ، وهذه الجملة مثل قوله تعالى فهو على نور من ربه معطوفة على قوله تعالى : { تسأَلهم أجراً } عطف إِخبار واسمية من إِنشاء وفعلية . <br />
