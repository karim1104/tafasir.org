{ إنَّا أنْزلنَا عَليْك الكتابَ } القرآن { للنَّاس } لأجل الناس أو هو نفع لهم ،  وذلك أن فيه مصالح دينهم ودنياهم وأخراهم { بالحقِّ } متعلق بأنزل { فَمنِ اهْتدى } بطاعة الله والبعد عن معصيته { فلنفسه } فاهتداؤه لنفسه { ومَن ضلَّ } بالكفر به أو عدم العمل به { فإنمَّا يضلُّ عَليْها } إذ هو المعاقب لا غيره بذلك { وما أنتَ عَليْهم بوكيلٍ } تجبرهم على الاهتداء ،  إن عليك إلا التبليغ ،  وقد اجتهدت فيه ،  اللهم صل وسلم عليه . <br />
