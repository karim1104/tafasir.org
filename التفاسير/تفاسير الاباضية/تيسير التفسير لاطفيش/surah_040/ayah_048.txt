{ قال الَّذين اسْتَكبروا } للاتباع { إنَّا } وإياكم { كُل فيها } كل مبتدأ ،  أى كلنا وفيها خبر ،  والجملة خبر إن ،  أى كيف ندفع عنكم ونحن معكم فيها لو وجدنا قدرة لدفعنا عن أنفسنا أو كل خبر ،  وفيها متعلق به بمعنى مجموعون فيها ،  أو نعت لكل أى فريق ،  أو جماعة ثابتون فيها { إنَّ الله قد حَكَمَ بَيْن العِبَاد } { فريق في الجنة وفريق في السعير } [ الشورى : 7 ] لا يتبادلون ،  ولا يغنى أحد عن أحد .
