{ فَسَتذكُرونَ } يحضر ذكره فى قلوبكم يوم القيامة ،  نادمين إن لم تتوبوا ،  وهذا تفريع على قوله تعالى :<br />
{ مالي أدعوكم } [ غافر : 41 ] { ما أقُول } فى هذا الحال { لكُم } من توحيد الله وعبادته { وأفوِّض أمري إلى الله } ليعصمنى من شركم وشر كل شىء ،  وقد توعدوه بالقتل { إنَّ الله بصيرٌ بالعِباد } فيحرس من يلوذ به ويعتصم مما يكره ،  ويعاقب الظالم ،  وهذا آخر كلام المؤمن ؟ ويل : { إن الله بصير بالعباد } من كلام الله سبحانه وتعالى بقوله عز وجل : { فَوقَاه الله سيِّئات ما مَكَروا }
