{ مَنْ عَمِل } فى الدنيا { سيِّئةً } معصية لم يتب منها { فلا يُجْزى } فى الآخرة { إلا مثلها } مقابلها ومعادلها من العذاب { ومَن عَمل } فى الدنيا { صَالحاً مِنْ ذكر أو أنْثى وهو مُؤمنٌ } أى موحد ،  ولم يبطله بالإصرار ،  وأما المشرك فيجازى فى الدنيا على حسناته { فأولئك } الذين عملوا الصالح { يَدخُلون الجنَّة يُرزَقُون فيها بغَير حِسابٍ } وهى وما فيها فوق ما عملوا بأضعاف لا تنتهى لا مثل ما عملوا ،  وفى ذكره ذلك رضى الله عنه ترغيب . <br />
