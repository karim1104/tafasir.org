{ لَهُ مُلْكُ السَّمَاوَاتِ وَالأَرْضِ } إِيجاداً وإِعداما وإِبقاء بكل ما أراد من التصرف { يُحْيِي وَيُمِيتُ } استئناف ولا غرض للفعلين فى المفعول به فهما لازمان فى الآية أى يفعل الإِحياء والإِماتة { وَهُوَ عَلَى كُلِّ شَىْءٍ } من الأَجسام والأَعراض والجواهر { قَدِيرٌ } عظيم القدرة يوجده ويتصرف فيه بما أراد<br />
