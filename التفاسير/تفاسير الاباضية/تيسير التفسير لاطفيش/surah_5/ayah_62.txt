{ وَتَرَى } تعلم أَو تشاهد وهو أَنسب لظهور حالهم { كَثِيراً مِنْهُمْ } من المنافقين أَو اليهود { يُسَارِعُونَ } أَصله المسارعة في الخير ففيه المبالغة بأَنهم رغبوا في الشر كأَنه خير يتسابق إِليه { في الإِثمِ } الذنب ويقال الكذب لقوله { عن قولهم الإِثم } وقيل الإِثم الحرام وقيل الكذب بقولهم آمنا إِخبارا كان أَو إِنشاء إِلا أنه إِن كان إِنشاء فالكذب باعتبار تضمنه الإِخبار بحصول صفة الإِيمان وقيل الإِثم الكفر مطلقا { والعُدْوَانِ } الذنب بينهم وبين الخلق أَو خصوص الذنب المجاوز للحد { وَأَكْلِهُمُ السُّحْتَ } الحرام كالرشا وما يؤكل على الدين وعلى إِفساده ،  والربا وعطفه تخصيص بعد تعميم { لَبِئْسَ مَا كَانُوا يَعْمَلونَ } هو المسارعة في الإِثم والعدوان وأَكل السحت .  . <br />
