{ ولو أنَّا أهْلكْناهم بعذابٍ من قبَله } ولو ثبت أهلاكناهم بعذاب مستأصل من قبل البينة ،  وذكرها باعتبار أنها برهان ،  أو قبل الإتيان المفهوم من قوله : { أو لم تأتهم } [ طه : 33 ] أو من قبل الرسول ،  أو الإرسال { لقالُوا } يوم القيامة { ربَّنا } يا ربَّنا { لولا } طلب برغبة { أرسَلت إلينا رسُولاً } فى الدنيا مع آيات مع آيات { فنتَّبع آياتك } التى جاءنا بها { من قبل أن نُذِلّ } بعذاب الاستئصال فى الدنيا { ونَخْزَى } بدخول النار لليوم ومعناهما واحد ،  وقيل الذل الهوان والخزى الافتضاح ،  وقيل كل من الذل والخزى بعذاب الآخرة ،  وهو متبادر لأنه لا بيقون بعد مجىء الاستئصال فى الدنيا ،  وقتا يتبين فيه ذلهم ،  بل يفاجأهم إلا أنه من الجائز بقاء وقت ،  فما أهلكهم الله إلا على حجة ،  كما قال : { قالوا بلى قد جاءنا نذير فكذبنا }<br />
[ الملك : 9 ] الخ وليس فى الآية جواز الإهلاك ،  بلا نبى ولا كتاب وإنما قال الله عز وجل : { لو فعلناه } وهو لم يفعله .
