{ يدْعو } يعْبُد أو ينادى للتخلص من شدة { من دون الله } ذكر لقبح صنيعه ، وبيان لعظم خسرانه ، أو حال من ضمير انقلب { مَالا يضره } من الأصنام ، ولو لم يعبده أو كسره أو بال عليه { وما لا ينفعُه } ولو عبده { ذلك } الدعاء { هُو الضَّلال } الخروج عن الطريق فى الأرض دون اهتداء الى حيث قصد ، فالضلال استعارة تصريحية للخروج عن الدين { البَعِيد } عن الاهتداء . <br />
