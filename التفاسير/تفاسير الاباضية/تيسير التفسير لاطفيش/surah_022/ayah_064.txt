{ لهُ } وحده لغيره { ما فى السَّماوات وما فى الأرض } خلقا وملكا وزيادة ونقصا وتبديلا وتغييرا وإبقاء { وإن الله لَهُو الغَنىٌّ } الذى لا يفتقر الى شىء ، لأنه الذى خلق المنافع والمضار { الحميدُ } المحمود حمدا لغويا لصفاته وأفعاله فى جيمع خلقه اعتقادا وقولا وفعلا وحالا ، ولو أنكر منكر ، أو كفر كافر بكذبه حاله . <br />
