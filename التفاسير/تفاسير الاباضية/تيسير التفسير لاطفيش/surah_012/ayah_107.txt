{ أَفَأَمِنُوا } أَتركوا التفكر فأَمنوا { أَنْ تَأْتِيَهُمْ غَاشِيَةٌ مِنَ عَذَابِ اللهِ } عقوبة تعمهم فى الدينا أَو صاعقة لا يفلت منها أَحد { أَوْ تَأْتِيَهُمْ السَّاعَةُ بغْتَةً } فجأَة بلا تقدم علامة { وَهُمْ لاَ يَشْعُرُونَ } بوقت إتيانها فلا يستعدون لدفعها على سبيل الفرض بأَن لهم دفعاً ،  ولا للتخلص منها بالتوبة وإِصلاح الفساد . <br />
