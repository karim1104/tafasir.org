{ لا يَسأم } لا يمل { الإنسان مِنْ دُعاءٍ } طلب { الخيْر } المال وأسبابه ، والصحة والشفاء والجاه ، وزوال الحزن ، وغير ذلك ، ولا يفتر { وإنْ مَسَّه } أصابه مجاز لاستعارة لجامع الحضور { الشَّرُّ } ضد الخير المذكور { فيئوسٌ } فهو عظيم الاياس من الخير { قَنُوطٌ } منقطع الرجاء انقطاعا عظيما ، ولا يظهر ما قيل إن القنوط ظهور أثر الحزن على البدن من الذبول ، ورقة الجسم ، والصوت ، وقد قال الله تعالى : { لا تقْنطوا منْ رحمَة الله }<br />
[ الزمر : 53 ] فقنوط تأكيد ليؤس أو هو أشد اليأس ، والآية نزلت فى الوليد بن المغيرة ، أو عتبة بن ربيعة .
