قال الله عز وجل :  {  أَمْ يَقُولُونَ افْتَرَاهُ } أي :  محمد ،   أي :  قد قالوا افتراه محمد {  قُلْ } يا محمد لهم {  إِنِ افْتَرَيْتُهُ فَلاَ تَمْلِكُونَ لِي مِنَ اللَّهِ شَيْئًا } أي :  لا تستطيعون أن تمنعوني من عذاب الله شيئاً {  هُوَ أَعْلَمُ بِمَا تُفِيضُونَ فِيهِ } أي :  بما تقولون فيه من الشرك ،   {  كَفَى بِهِ شَهِيدًا بَيْنِي وَبَيْنَكُمْ } أي :  أني جئت بالقرآن من عنده وأني لم أفتره .   قال :  {  وَهُوَ الْغَفُورُ الرَّحِيمُ } أي :  لمن آمن بالله .  <br />
