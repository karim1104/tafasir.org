قال :  {  وَوَصَّيْنَا الإِنسَانَ بِوَالِدَيْهِ إِحْسَانًا حَمَلَتْهُ أُمُّهُ كُرْهًا وَوَضَعَتْهُ كُرْهًا } أي حملته بمشقة ووضعته بمشقة ،   {  وَحَمْلُهُ } أي في البطن {  وَفِصَالُهُ } أي :  وفطامه {  ثَلاَثُونَ شَهْرًا حَتَّى إِذَا بَلَغَ أَشُدَّهُ } أي :  إذا احتلم ،   وبعضهم يقول :  عشرين سنة{[3444]} ،   {  وَبَلَغَ أَرْبَعِينَ سَنَةً } أي في السّنّ {  قَالَ رَبِّ أَوْزِعْنِي } أي :  ألهمني {  أَنْ أَشْكُرَ نِعْمَتَكَ الَّتِي أَنْعَمْتَ عَلَيَّ وَعَلَى وَالِدَيَّ وَأَنْ أَعْمَلَ صَالِحًا تَرْضَاهُ وَأَصْلِحْ لِي فِي ذُرِّيَّتِي إِنِّي تُبْتُ إِلَيْكَ وَإِنِّي مِنَ الْمُسْلِمِينَ } .  <br />
قال الحسن :  هذا دعاء المؤمن لوالديه إن كانا مؤمنين ،   ودعاؤهما لذريتهما المؤمنين .   وقال الكلبي :  بلغنا أنها نزلت في أبي بكر الصديق رضي الله عنه ،   وهي بعدُ مرسلة في المؤمنين .
