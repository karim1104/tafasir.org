قوله :  {  قَالَ رَبِّ أَنَّى يَكُونُ لِي غُلاَمٌ } أي :  من أيْنَ يكون لي غلام {  وَكَانَتِ امْرَأَتِي عَاقِراً } لا تلد {  وَقَدْ بَلَغْتُ مِنَ الْكِبَرِ عِتِيّاً } قال الحسن :  أراد زكرياء أن يعلم كيف ذلك .  <br />
قوله :  {  وَقَدْ بَلَغْتُ مِنَ الكِبَرِ عِتِيّاً } قال مجاهد :  قحول العظم{[2181]} .   وقال الكلبي :  العتي :  اليبس وهي في قراءة عبد الله بن مسعود :  {  وَقَدْ بَلَغْتُ مِنَ الكِبَرِ عِتِيّاً }{[2182]} .   قال بعضهم :  يبس جلدي على عظمي .   وقال بعضهم :  {  عِتِيّاً } ،   أي غاية ومنتهى .
