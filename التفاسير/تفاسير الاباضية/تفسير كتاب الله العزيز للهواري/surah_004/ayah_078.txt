ثم أخبرهم ليعزيهم ويصبّرهم{[771]} فقال :  {  أَيْنَمَا تَكُونُوا يُدْرِككُّمُ الْمَوْتُ وَلَوْ كُنتُمْ فِي بُرُوجٍ مُّشَيَّدَةٍ } قال بعضهم :  في قصور محصّنة .  <br />
قال الحسن :  ثم ذكر المنافقين خاصة فقال :  {  وَإِن تُصِبْهُمْ حَسَنَةٌ } أي :  النصر والغنيمة {  يَقُولُوا هَذِهِ مِنْ عِندِ اللهِ وَإِن تُصِبْهُمْ سَيِّئَةٌ } أي :  نكبة من العدو {  يَقُولُوا هَذِهِ مِنْ عِندِكَ } أي إنما أصابتنا هذه عقوبة مذ خرجتَ فينا ،   يتشاءمون به .   {  قُلْ كُلٌّ مِّنْ عِندِ اللهِ } أي :  النصر على الأعداء والنكبة ؛  نكبوا يوم أحد عقوبة .
