قوله :  {  إِن يَشَأْ يُذْهِبْكُمْ أَيُّهَا النَّاسُ } أي بعذاب الاستئصال {  وَيَأتِ بِآخَرِينَ } أي يطيعونه {  وَكَانَ اللهُ عَلَى ذَلِكَ قَدِيراً } وهو كقوله :  {  وَإِن تَتَوَلَّوْا يَسْتَبْدِلْ قَوْماً غَيْرَكُمْ ثُمَّ لاَ يَكُونُوا أَمْثَالَكُم } [ محمد : 38 ] في الخلاف والمعصية :  يعني بهذا المشركين .
