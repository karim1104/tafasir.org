قوله :  {  يَا أَيُّهَا الذِينَ ءَامَنُوا كُونُوا قَوَّامِينَ بِالْقِسْطِ } أي بالعدل {  شُهَدَاءَ لِلَّهِ وَلَوْ عَلَى أَنفُسِكُمْ أَوْ الوَالِدَيْنِ وَالأَقْرَبِينَ إِن يَكُنْ غَنِيّاً أَوْ فَقِيراً فَاللهُ أَوْلَى بِهِمَا } في الشهادة إذا كانت عنده .   يقول :  اشهدوا على أنفسكم ،   أي على أبنائكم وآبائكم وأمهاتكم وقرابتكم ،   أغنياء كانوا أو فقراء .   وهو قوله :  {  إِن يَكُنْ غَنِيّاً أَوْ فَقِيراً فَاللهُ أَوْلَى بِهِمَا } أي أولى بغناه وفقره .  <br />
وقال بعضهم :  لا يمنعكم غنى غني ،   ولا فقر فقير أن تشهدوا عليه بما تعلمون ،   قال :  الله أعلم بغناهم وفقرهم .  <br />
قوله :  {  فَلاَ تَتَّبِعُوا الهَوَى } فتدعوا الشهادة{[838]} {  أَن تَعْدِلُوا } فتقيموا الشهادة{[839]} {  وَإِن تَلْوُوا } بِأَلسنتكم ،   أي تلجلجوا فتحرّفوا الشهادة {  أَوْ تُعْرِضُوا } فلا تشهدوا بها .   وقال مجاهد :  إن تلووا ،   أي تبدّلوا الشهادة ،   أو تعرضوا ،   أي تكتموها {  فَإِنَّ اللهَ كَانَ بِمَا تَعْمَلُونَ خَبِيراً } .
