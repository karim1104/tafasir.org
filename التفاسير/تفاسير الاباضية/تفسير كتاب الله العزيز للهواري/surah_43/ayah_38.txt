{  حَتَّى إِذَا جَاءَنَا } أي :  هو وقرينه ،   يعني شيطانه .   وهي تقرأ على وجه آخر :  {  حَتَّى إِذَا جَاءَنَا } [ أي :  العاشي عن ذكر الرحمن ] .   {  قَالَ } :  أي :  لقرينه {  يَا لَيْتَ بَيْنِي وَبَيْنَكَ بُعْدَ الْمَشْرِقَيْنِ فَبِئْسَ الْقَرِينُ } .  <br />
[ قال بعضهم :  إن الكافر إذا خرج من قبره وجد عند رأسه شيطانه فيأخذ بيده فيقول :  أنا قرينك حتى أدخل أنا وأنت جهنم .   قال محمد :  عند ذلك يقول :  {  يَا لَيْتَ بَيْنِي وَبَيْنَكَ بُعْدَ الْمَشْرِقَيْنِ فَبِئْسَ الْقَرِينُ } ]{[3376]} .
