قوله :  {  وَأَصْبَحَ فُؤادُ أُمِّ مُوسَى فَارِغاً } أي :  من كل شيء إلا من ذكر موسى ،   أي :  لا تذكر غيره .   {  إِنْ كَادَتْ لَتُبْدِي بِهِ } أي :  لتُبَيّنُ لهم أنه ابنها من شدة وجدها {  لَوْلا أَن رَّبَطْنَا عَلَى قَلْبِهَا } أي :  بالإِيمان {  لِتَكُونَ } أي :  لكي تكون {  مِنَ المُؤمِنِينَ } .  <br />
