قوله :  {  وَلَقَدْ آتَيْنَا مُوسَى الكِتَابَ } يعني التوراة {  مِن بَعْدِمَا أَهْلَكْنَا القُرُونَ الأُولَى بَصَائِرَ لِلنَّاسِ وَهُدىً وَرَحْمَةً لَّعَلَّهُمْ يَتَذَكَّرُونَ } أي :  لكي يتذكروا .   فكانت التوراة أول كتاب نزل فيه الفرائض والحدود والأحكام .   قوله :  {  مِن بَعْدِمَا أَهْلَكْنَا القُرُونَ الأُولَى } أي :  قرناً بعد قرن ،   كقوله :  على مقرأ هذا الحرف :  {  وَكَذَلِكَ أَخْذُ رَبِّكَ إِذَا أَخَذَ الْقُرَى وَهِيَ ظَالِمَةٌ } [ هود :  102 ] .
