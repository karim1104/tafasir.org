{  قَالَ } قارون {  إِنَّمَا أُوتِيتُهُ عَلَى عِلْمٍ عِنْدِي } أي :  إنما أعطيته ،   يعني ما أعطي من الدنيا ،   على علم عندي ،   أي :  بقوتي وعلمي ،   وهي مثل قوله :  {  ثُمَّ إِذَا خَوَّلْنَاهُ نِعْمَةً مِّنَّا قَالَ إِنَّمَا أُوتِيتُهُ عَلَى عِلْمٍ } قال الله :  {  بَلْ هِيَ فِتْنَةٌ } أي :  بليّة<br />
{  وَلَكِنَّ أَكْثَرَهُمْ لاَ يَعْلَمُونَ } [ الزمر :  49 ] .  <br />
قوله :  {  أَوَلَمْ يَعْلَمْ } قارون ،   أي :  بلى قد علم ،   وهذا على الاستفهام {  أَنَّ اللهَ قَدْ أَهْلَكَ مِنْ قَبْلِهِ } من قبل قارون {  مِنَ القُرُونِ مَنْ هُوَ أَشَدُّ مِنْهُ قُوَّةً وَأَكْثَرُ جَمْعاً } أي :  من الجنود والرجال .  <br />
قال الله :  {  وَلاَ يُسْأَلُ عَنْ ذُنُوبِهِمُ المُجْرِمُونَ } أي :  المشركون والمنافقون ،   أي :  ليعلم ذنوبهم منهم ،   أي :  يُعرَفون بسواد وجوههم وزرقة عيونهم ،   كقوله :  {  فَيَوْمَئِذٍ لاَّ يُسْأَلُ عَن ذَنبِهِ إِنْسٌ وَلاَ جَانٌّ } [ الرحمن :  39 ] ،   وكقوله : <br />
{  يُعْرَفُ المُجْرِمُونَ بِسِيمَاهُمْ فَيُؤخَذُ بِالنَّوَاصِي وَالأَقْدَامِ } [ الرحمن :  41 ] أي :  يجمع بين ناصيته وقدمه .
