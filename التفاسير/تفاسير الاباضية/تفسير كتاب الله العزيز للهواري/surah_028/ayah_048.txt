قال الله :  {  فَلَمَّا جَاءَهُمُ الْحَقُّ مِنْ عِندِنَا } أي :  القرآن {  قَالُوا لَوْلا أُوتِيَ } يعنون النبي محمداً عليه السلام {  مِثْلَ مَا أُوتِيَ مُوسَى } أي :  هلا أعطي مثل ما أعطي موسى ؛  أي :  هلاّ أنزل عليه القرآن جملة واحدة كما أنزلت التوراة على موسى جملة واحدة .  <br />
قال الله :  {  أَوَلَمْ يَكْفُرُوا بِمَا أُوتِيَ مُوسَى مِن قَبْلُ } وقد كان كتاب موسى عليهم حجّة ،   في تفسير الحسن .   {  قَالُوا سِحْرَانِ تَظَاهَرَا } أي :  موسى ومحمد ،   في تفسير الحسن ؛  وهذا قول مشركي العرب .   {  وَقَالُوا إِنَّا بِكُلٍّ كَافِرُونَ } أي :  بالتوراة والقرآن .  <br />
وقال بعضهم :  {  سِحْرَانِ تَظَاهَرَا } أي :  موسى وهارون .   وقال مجاهد :  {  قَالُوا لَوْلا أُوتِيَ مِثْلَ مَا أُوتِيَ مُوسَى } هذا قول اليهود ؛  أمروا قريشاً أن يسألوا محمداً مثل ما أوتي موسى ؛  يقول الله يا محمد ،   قل لقريش يقولوا لهم :  {  أَوَلَمْ يَكْفُرُوا بِمَا أُوتِيَ مُوسَى مِن قَبْلُ قَالُوا سِحْرَانِ تَظَاهَرَا } قاله يهود لموسى وهارون {  وَقَالُوا } أي :  اليهود {  إِنَّا بِكُلٍّ كَافِرُونَ } أي :  نكفر أيضاً بما أوتي محمد .  {[2819]}
