قال :  {  لَوْ نَشَآءُ لَجَعَلْنَاهُ } يعني الزرع {  حُطَاماً } وهو كقوله عز وجل : {  ثُمَّ يَهِيجُ فَتَرَاهُ مُصْفَرّاً ثُمَّ يَكُونُ حُطَاماً } [ الحديد : 20 ] ،   وكقوله :  {  هَشِيماً تَذَرُوهُ الرِّيَاحُ } [ الكهف : 45 ] {  فَظَلْتُمْ تَفَكَّهُونَ } تفسير الحسن :  تَنَدَّمَون ،   أي :  على ما أنفقتم في الزرع .   وقال مجاهد :  أي :  فَظَلْتُم تعجبون [ المعنى تعجبون لهلاكه بعد خضرته{[3778]} .
