قوله :  {  يَا أَيُّهَا الَّذِينَ ءامَنُواْ مَالَكُمْ إِذَا قِيلَ لَكُمُ انفِرُواْ فِي سَبِيلِ اللهِ اثاقَلْتُمْ إِلَى الأَرْضِ } وهو مثل قوله :  {  أَخْلَدَ إِلَى الأَرْضِ } [ الأعراف : 176 ] وهو الرضا بالدنيا .  <br />
قال :  {  أَرَضِيتُم بِالحَيَاةِ الدُّنْيَا مِنَ الآخِرَةِ } أي ليست الدنيا عوضاً من الآخرة {  فَمَا مَتَاعُ الحَيَاةِ الدُّنْيَا فِي الآخِرَةِ إِلاَّ قَلِيلٌ } أي يستمتع به في الدنيا ثم يفنى ،   ويذهب ولا يبقى .   وما في الآخرة باقٍ دائم ،   لا يفنى ولا يذهب .   كقوله {  مَا عِندَكُمْ } أي في الدنيا {  يَنفَذُ وَمَا عِندَ اللهِ } أي في الآخرة {  بَاقٍ } [ النحل : 96 ] .   وكقوله :  {  إِنَّ هَذَا لَرِزْقُنَا مَا لَهُ مِن نَّفَادٍ } [ سورة ص : 54 ] أي :  من فناء .
