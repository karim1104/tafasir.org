قوله :  {  وَإِذَا مَا أُنزِلَتْ سُورَةٌ فَمِنْهُم } يعني المنافقين ؛  رجع إليهم {  مَّن يَقُولُ أَيُّكُمْ زَادَتْهُ هَذِهِ } يعني السورة{[1533]} {  إِيمَاناً } يقوله بعضهم لبعض .  <br />
قال الله جواباً لقولهم {  فَأَمَّا الَّذِينَ ءَامَنُوا فَزَادَتْهُمْ إِيمَاناً } أي تصديقاً إلى تصديقهم {  وَهُمْ يَسْتَبْشِرُونَ } أي بما يجيء من عند الله .
