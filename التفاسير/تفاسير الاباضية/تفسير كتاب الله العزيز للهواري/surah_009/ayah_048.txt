قوله :  {  لَقَدِ ابْتَغَوُا الفِتْنَةَ } أي الشرك {  مِن قَبْلُ } أي من قبل أن تهاجروا {  وَقَلَّبُوا لَكَ الأُمُورَ } وهو قوله عزّ وجلّ :  {  وَإِذْ يَمْكُرُ بِكَ الَّذِينَ كَفَرُوا لِيُثْبِتُوكَ أَوْ يَقْتُلُوكَ أَوْ يُخْرِجُوكَ } [ الأنفال : 30 ] وقوله :  {  أَمْ أَبْرَمُواْ أَمْراً فَإِنَّا مُبْرِمُونَ } [ الزخرف : 79 ] ،   وهو اجتماع المشركين في دار الندوة يتشاورون في أمر النبي .   وقد فسَّرنا ذلك في سورة الأنفال .  {[1440]}<br />
وقال الحسن :  {  لَقَدِ ابْتَغَوُا الفِتْنَةَ مِن قَبْلُ وَقَلَّبُوا لَكَ الأُمُورَ } :  أي القتل قبل أن تقدم المدينة ،   يعني المنافقين .  <br />
قال :  {  حَتَّى جَاءَ الحَقُّ وَظَهَرَ أَمْرُ اللهِ } أي دين الله {  وَهُمْ كَارِهُونَ } أي لظهوره .
