{  وَأَلْقِ عَصَاكَ } فألقاها {  فَلَمَّا رَآهَا تَهْتَزُّ كَأَنَّهَا جَانٌّ } أي :  كأنها حيّة ،   وقال في آية أخرى : <br />
{  فَإِذَا هِيَ حَيّةٌ تَسْعَى } [ طه :  20 ] ،   {  وَلَّى مُدْبِراً } أي :  من الفَرَق {  وَلَمْ يُعَقِّبْ } أي :  ولم يلتفت .   وقال مجاهد :  ولم يرجع{[2735]} .  <br />
{  يَا مُوسَى لاَ تَخَف إِنِّي لاَ يَخَافُ لَدَيَّ المُرْسَلُونَ } قال الحسن :  {  لاَ يَخَافُ لَدَيَّ الْمُرْسَلُونَ } أي :  في الآخرة والدنيا لأنهم أهل الولاية وأهل المحبة
