قال الله :  {  وَمَكَرُوا مَكْراً } أي :  الذي أرادوا بصالح {  وَمَكَرْنَا مَكْراً } أي رماهم الله بالصخرة فأهمدتهم .   قال :  {  وَهُمْ لاَ يَشْعُرُونَ } قال :  {  فَانظُرْ كَيْفَ كَانَ عَاقِبَةُ مَكْرِهِمْ إِنَّا دَمَّرْنَاهُمْ } أي :  بالصخرة {  وَقَوْمَهُمْ أَجْمَعِينَ } أي :  دمّرنا قومهم بعدهم بالصيحة .  <br />
