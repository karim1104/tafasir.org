قوله :  {  أَمَّن يَهْدِيكُمْ فِي ظُلُمَاتِ البَرِّ وَالبَحْرِ } [ أي :  من شدائد البر والبحر ]{[2768]} {  وَمَن يُّرْسِلُ الرِّيَاحَ بُشْراً } أي :  ملقحات للسحاب {  بَيْنَ يَدَيْ رَحْمَتِهِ } أي :  بين يدي المطر .   وهو على الاستفهام .   يقول :  أم من يفعل هذا خير أم أوثانهم .   وهذا تبع لقوله :  {  آللهُ خَيْرٌ أَمَّا تُشْرِكُونَ } أي :  إن الله خير من أوثانهم .   قال :  {  أَءِلهٌ مَّعَ اللهِ } على الاستفهام .   أي :  ليس معه إله .   {  تَعَالَى اللهُ عَمَّا يُشْرِكُونَ } ينزّه نفسه عمّا يشركون به .
