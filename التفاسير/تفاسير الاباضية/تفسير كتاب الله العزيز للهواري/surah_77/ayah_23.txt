قال تعالى :  {  فقدَرنا فنعم القادرون } وهي تقرأ على وجهين :  {  فَقَدَرْنَا } خفيفة و{  فَقَدَّرْنَا } مثقلة .   فمن قرأها بالتخفيف فهو يقول :  {  فَقَدَرْنَا فَنِعْمَ القَادِرُونَ } من باب القُدرة ،   أي :  فملكنا فنعم المالكون .   ومن قرأها بالتثقيل {  فَقَدَّرْنَا فَنِعْمَ القَادِرُونَ } فمِن قِبَل التقدير .  <br />
