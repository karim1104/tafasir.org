قال تعالى :  {  ذَلِكَ بِأَنَّهُ كَانَت تَّأتِيهِمْ رُسُلُهُمْ بِالْبَيِّنَاتِ فَقَالُواْ أَبَشَرٌ يَهْدُونَنَا } أي :  إنكاراً لذلك ،   وهو مثل قولهم : <br />
{  أَبَعَثَ اللهُ بَشَراً رَّسُولاً } [ الإِسراء : 94 ] أي :  لم يفعل .   قال :  {  فَكَفَرُواْ وَتَوَلَّواْ } أي :  عن طاعة الله .   قال :  {  وَّاسْتَغْنَى اللهُ } أي :  عنهم {  وَاللهُ غَنِيٌّ } عن خلقه {  حَمِيدٌ } أي :  استحمد إلى خلقه ،   أي :  استوجب عليهم أن يحمدوه .
