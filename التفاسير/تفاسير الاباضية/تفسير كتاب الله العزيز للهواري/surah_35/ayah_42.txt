قوله :  {  وَأَقْسَمُوا بِاللهِ جَهْدَ أيْمَانِهِمْ لَئِن جَاءَهُمْ نَذِيرٌ لِّيَكُونُنَّ أَهْدى مِنْ إِحْدَى الأُمَمِ } كقوله : {  وَإِن كَانُوا لَيَقُولُونَ لَوْ أَنَّ عِندَنَا ذِكْراً مِّنَ الأَوَّلِينَ لَكُنَّا عِبَادَ اللهِ المُخْلَصِينَ }[ الصافات :  167-169 ] قال الله :  {  فَلَمَّا جَاءَهُمْ نَذِيرٌ } أي :  محمد صلى الله عليه وسلم {  مَّا زَادَهُمْ إِلاَّ نُفُوراً } أي :  الإِيمان .
