قال :  {  أَفَمَن زُيِّنَ لَهُ سُوءُ عَمَلِهِ فَرَآهُ حَسَناً } أي :  كمن آمن وعمل صالحاً .   أي :  لا يستويان .   وهذا على الاستفهام ،   وفيه إضمار .   قال :  {  فَإِنَّ اللهَ يُضِلُّ مَن يَشَاءُ وَيَهْدِي مَن يَشَاءُ فَلاَ تَذْهَبْ نَفْسُكَ عَلَيْهِمْ } أي :  على المشركين {  حَسَرَاتٍ } أي :  لا تتحسر عليهم إذا لم يؤمنوا ؛  كقوله : {  وَلاَ تَحْزَنْ عَلَيْهِمْ }[ النحل :  127 ] قال :  {  إِنَّ اللهَ عَلِيمٌ بِمَا يَصْنَعُونَ } .
