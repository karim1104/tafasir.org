قوله :  {  وَهُمْ يَصْطَرِخُونَ فِيهَا } أي :  في النار {  رَبَّنَا أَخْرِجْنَا نَعْمَلْ صَالِحاً غَيْرَ الَّذِي كُنَّا نَعْمَلُ } أي :  أخرجنا فردنا إلى الدنيا نعمل صالحاً غير الذي كنا نعمل .   قال الله :  {  أَوَلَمْ نُعَمِّرْكُم مَّا يَتَذَكَّرُ فِيهِ مَن تَذَكَّرَ وَجَاءَكُمُ النَّذِيرُ } يعني النبي صلى الله عليه وسلم .   ذكر بعضهم قال :  نزلت هذه الآية وفيها ابن ثمان عشرة سنة .   وكل شيء ذُكِر من كلام أهل النار فهو قبل أن يقول الله لهم : {  قَالَ اخْسَئُوا فِيهَا وَلاَ تُكَلِّمُونِ } [ المؤمنون :  108 ] .  <br />
قوله :  {  فَذُوقُوا } أي :  العذاب {  فَمَا لِلظَّالِمِينَ مِن نَّصِيرٍ } وهذا ظلم الشرك وهو ظلم فوق ظلم ،   وظلم دون ظلم .
