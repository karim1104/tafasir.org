قوله :  {  وَقَالُوا } يعني المشركين {  أَئذَا ضَلَلْنَا فِي الأَرْضِ } أي :  إذا كنا تراباً وعظاماً {  أَئِنَّا لَفِي خَلْقٍ جَدِيدٍ } وهذا استفهام على إنكار ،   أي :  إنا لا نبعث بعد الموت .   وبعضهم يقرأها أئذا صللنا في الأرض ،   أإذا نتنّا في الأرض {  أَئِنَّا لَفِي خَلْقٍ جَدِيدٍ } قال الله :  {  بَلْ هُم بِلِقَاءِ رَبِّهِمْ كَافِرُونَ } .  <br />
