قوله :  {  وَاصْنَعِ الفُلْكَ بِأَعْيُنِنَا } أي :  بأمرنا {  وَوَحْيِنَا } أي :  وبوحينا{[1602]} فعملها على مثل جؤجؤ الطير .   قال بعضهم :  رأسها مثل رأس الحمامة ،   وذنبها مثل ذنب الديك .  <br />
قوله :  {  وَلاَ تُخَاطِبْنِي فِي الَّذِينَ ظَلَمُواْ } ،   أي :  ولا تراجعني في الذين ظلموا أنفسهم بشركهم {  إِنَّهُم مَّغْرَقُونَ } .
