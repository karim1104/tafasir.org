قال :  {  فَإِلَّمْ يَسْتَجِيبُوا لَكُمْ } فيأتوا بعشر سور مثله ،   ولن يفعلوا ،   يعني الأوثان .   {  فَاعْلَمُوا أَنَّمَا أُنزِلَ } أي :  القرآن {  بِعِلْمِ اللهِ } أي :  من عند الله {  وَأَن لاَّ إِلَهَ إِلاَّ هُوَ فَهَلْ أَنتُم مُّسْلِمُونَ } .   يقول :  قل لهم فهل أنتم مسلمون .   وهو كقوله :  {  وَمَا أَرْسَلْنَا مِن قَبْلِكَ مِن رَّسُولٍ إِلاَّ نُوحَي إِلَيْهِ أَنَّهُ لاَ إِلَهَ إِلاَّ أَنَا فَاعْبُدُونِ } [ الأنبياء : 25 ] .
