قال :  {  وَأُوحِيَ إِلَى نُوحٍ أَنَّهُ لَن يُؤْمِنَ مِن قَوْمِكَ إِلاَّ مَن قَدْ آمَنَ } قال :  بعضهم :  ذلك حين دعا نوح عليهم فقال :  {  رَّبِّ لاَ تَذَرْ عَلَى الأَرْضِ مِنَ الكَافِرِينَ دَيَّاراً } [ نوح : 26 ] {  فَلاَ تَبْتَئِسْ } أي :  لا تحزن عليهم {  بِمَا كَانُوا يَفْعَلُونَ } قال بعضهم :  لا تأسَ ولا تحزن .
