{  لِّيَعْلَمَ أَن قَدْ أَبْلَغُواْ رِسَالاَتِ رَبِّهِمْ } أي :  ليعلم ذلك الرسول أن الرسل قبله قد بلّغوا رسالات{[4128]} ربهم {  وَأَحَاطَ } أي :  أحاط الله {  بِمَا لَدَيْهِمْ } أي :  بما عندهم مما أرسلوا به ،   أي فلا يوصل إليهم حتى يُبلِّغوا عن الله الرسالة .   {  وَأَحْصَى كُلَّ شَيْءٍ } من خلقه {  عَدَدا } .
