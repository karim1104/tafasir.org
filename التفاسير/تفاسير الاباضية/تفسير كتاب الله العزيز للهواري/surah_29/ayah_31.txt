قال :  {  وَلَمَّا أن جَاءَتْ رُسُلُنَا } يعني الملائكة {  إِبْرَاهِيمَ بِالْبُشْرَى } أي :  بإسحاق وذلك أن الملائكة لما بعثت إلى قوم لوط بعذابهم مرّوا بإبراهيم فسألوه الضيافة ،   فلما أخبروه أنهم أرسلوا بعذاب قوم لوط بعدما بشّروه بإسحاق {  قَالُوا إِنَّا مُهْلِكُو أَهْلِ هذِهِ القَرْيَةِ } يعنون قرية قوم لوط {  إِنَّ أَهْلَهَا كَانُوا ظَالِمِينَ } أي :  مشركين .  <br />
