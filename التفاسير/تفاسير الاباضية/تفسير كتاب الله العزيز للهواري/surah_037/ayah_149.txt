قوله :  {  فَاسْتَفْتِهِمْ } أي :  فاسألهم ،   يعني المشركين {  أَلِرَبِّكَ الْبَنَاتُ وَلَهُمُ الْبَنُونَ } وذلك لقولهم إن الملائكة بنات الله .   قال :  {  وَيَجْعَلُونَ لِلَّهِ مَا يَكْرَهُونَ } أي :  البنات {  وَتَصِفُ أَلْسِنَتُهُمُ الْكَذِبَ أَنَّ لَهُمُ الْحُسْنَى } أي :  الغلمان<br />
{  لاَ جَرَمَ أَنَّ لَهُمُ النَّارَ } [ النحل :  62 ] .
