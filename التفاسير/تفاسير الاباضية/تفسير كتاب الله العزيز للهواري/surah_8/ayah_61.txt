قوله :  {  وَإِن جَنَحُوا } أي مالوا {  لِلسِّلْمِ فَاجْنَحْ لَهَا } والسلم هو الصلح .  <br />
قوله :  {  فَاجْنَحْ لَهَا } أي للموادعة .   قال مجاهد :  هم قريظة .   وقال بعضهم :  نسخها في هذه الآية :  {  فَاقْتُلُوا المُشْرِكِينَ حَيْثُ وَجَدتُّمُوهُمْ } [ التوبة : 5 ] .   قوله :  {  وَتَوَكَّلْ عَلَى اللهِ إِنَّهُ هُوَ السَّمِيعُ العَلِيمُ } أي فلا أسمع منه ولا أعلم منه .
