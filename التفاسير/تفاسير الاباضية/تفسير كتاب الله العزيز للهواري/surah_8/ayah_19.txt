قوله :  {  إِن تَسْتَفْتِحُوا فَقَدْ جَاءَكُمُ الفَتْحُ } قال الكلبي :  إن المشركين لما صافّوا رسول الله صلى الله عليه وسلم يوم بدر قالوا :  اللهم ربنا أيُّنا كان أَحبَّ إليك ،   وأرضى عندك ،   فانصره .   فنصر الله نبيَّه ،   وقال :  {  إِن تَسْتَفْتِحُوا } يعني أن تستنصروا {  فَقَدْ جَاءَكُمُ الفَتْحُ } والفتح النصر .  <br />
قال :  {  وَإِن تَنتَهُوا } عن قتال محمد {  فَهُوَ خَيْرٌ لَّكُمْ وَإِن تَعُودُوا } لِقِتاله {  نَعُدْ } عليكم بالهزيمة {  وَلَن تُغْنِيَ عَنكُمْ فِئَتُكُمْ شَيْئاً وَلَوْ كَثُرَتْ وَأَنَّ اللهَ مَعَ المُؤْمِنِينَ } .  <br />
وقال مجاهد :  {  فَقَدْ جَاءَكُمُ الفَتْحُ } بدعاء كفار قريش في قولهم :  ربنا افتح بيننا وبين محمد ،   ففتح الله بينه وبينهم يوم بدر{[1309]} .
