قوله :  {  وَكَمْ أَهْلَكْنَا مِن قَرْيَةٍ بَطِرَتْ مَعِيشَتَهَا } كقوله :  {  فَكَفَرَتْ بِأَنْعُمِ اللهِ } [ النحل :  112 ] أي :  فأهلكناهم ،   يعني من أهلك من القرون الأولى .   {  فَتِلْكَ مَسَاكِنُهُمْ لَمْ تُسْكَن مِّن بَعْدِهِمْ إِلاَّ قَلِيلاً وَكُنَّا نَحْنُ الوَارِثِينَ } كقوله :  {  إِنَّا نَحْنُ نَرِثُ الأَرْضَ وَمَنْ عَلَيْهَا } [ مريم :  40 ] .
