{  وَأَخِي هَارُونُ هُوَ أَفْصَحُ مِنِّي لِسَاناً } يعني العقدة التي كانت في لسانه .   {  فَأَرْسِلْهُ مَعِي رِدءًا } أي :  عوناً ،   في تفسير الحسن{[2812]} .   {  يُصَدِّقُنِي } وقال الكلبي :  {  مَعِي رِداً يُصَدِّقْنِي } أي :  كيما{[2813]} يصدقني ،   أي :  كي يكون معي في الرسالة .   {  إِنِّي أَخَافُ أَن يُّكَذِّبُونِ } .
