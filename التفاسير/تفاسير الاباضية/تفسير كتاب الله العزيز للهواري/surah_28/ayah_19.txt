ثم أدركت موسى الرقةُ عليه {  فَلَمَّا أَن أَرَادَ أَن يَبْطِشَ بِالذِي هُوَ عَدُوٌّ لَّهُمَا } أي :  بالقبطي {  قَالَ } الإِسرائيلي .   [ قال بعضهم ]{[2799]} :  وبلغنا أنه السامري ،   فخلى السامري عن القبطي وقال :  {  يَا مُوسَى } الإِسرائيلي يقوله :  {  أَتُرِيدُ أَنْ تَقْتُلَنِي كَمَا قَتَلْتَ نَفْساً بالأَمْسِ إِنْ تُرِيدُ إِلا أَنْ تَكُونَ جَبَّاراً فِي الأَرْضِ } يعني قتالاً في الأرض {  وَمَا تُرِيدُ أَنْ تَكُونَ مِنَ المُصْلِحِينَ }{[2800]} .
