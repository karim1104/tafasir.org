قال الله :  {  فَرَدَدْنَاهُ إِلَى أُمِّهِ كَيْ تَقَرَّ عَيْنُهَا وَلاَ تَحْزَنَ وَلِتَعْلَمَ أَنَّ وَعْدَ اللهِ حَقٌّ } أي :  الذي قذف في قلبها :  {  إِنَّا رَادُّوهُ إِلَيْكِ وَجَاعِلُوهُ مِنَ المُرْسَلِينَ } قال :  {  وَلَكِنَّ أَكْثَرَهُمْ لاَ يَعْلَمُونَ } أي :  جماعتهم لا يعلمون .  <br />
