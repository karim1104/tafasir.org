{  وَأَنْ أَلْقِ عَصَاكَ } فألقاها .  <br />
{  فَلَمَّا رَآهَا تَهْتَزُّ كَأَنَّهَا جَانٌ } أي :  كأنّها حيّة {  وَلَّى مُدْبِراً } أي :  هارباً {  وَلَمْ يُعَقِّبْ } أي :  ولم يلتفت ،   أي :  من الفرَق .   وقال مجاهد :  ولم يرجع .   {  يَا مُوسَى أَقْبِلْ } الله يقوله :  {  يَا مُوسَى أقْبِلْ وَلاَ تَخَفْ إِنَّكَ مِنَ الآمنين } .  <br />
