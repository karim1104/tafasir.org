{  قَالَ الذِينَ حَقَّ عَلَيْهِمُ القَوْلُ } أي :  الغضب{[2831]} ،   يعني الشياطين الذين دعوهم إلى عبادة الأوثان {  رَبَّنَا هَؤُلاءِ الذِينَ أَغْوَيْنَا أَغْوَيْنَاهُمْ } أي :  أضللناهم {  كَمَا غَوَيْنَا } أي :  كما ضللنا {  تَبَرَّأْنَا إِلَيْكَ مَا كَانُوا إِيَّانَا يَعْبُدُونَ } أي :  سلطان كان لنا عليهم استكرهناهم به ،   وإنما دعوهم بالوسوسة كقول إبليس : {  وَمَا كَانَ لِيَ عَلَيْكُم مِّن سُلْطَانٍ إِلا أَن دَعَوْتُكُمْ فَاسْتَجَبْتُمْ لِي }<br />
[ إبراهيم :  22 ] ،   وكقوله في قولهم : {  وَمَا كَانَ لَنَا عَلَيْكُم مِّن سُلْطَانٍ }[ الصافات :  30 ] وكقول الله : <br />
{  وَمَا كَانَ لَهُ عَلَيْهِم مِّن سُلْطَانٍ }[ سبأ :  21 ] .   .   إلى آخر الآية .   وكقوله : {  مَا أنتُمْ عَلَيْهِ بِفَاتِنِينَ }<br />
[ الصافات :  162 ] أي :  بمضلّين {  إِلاَّ مَنْ هُوَ صَالِ الجَحِيمِ } [ الصافات :  163 ] .
