قال :  {  وَنُمَكِّنَ لَهُمْ فِي الأَرْضِ } وهو تبع للكلام الأول :  {  وَنُرِيدُ أَن نَّمُنَّ عَلَى الذِينَ اسْتُضْعِفُوا فِي الأَرْضِ } قال :  {  وَنُرِيَ فِرْعَوْنَ وَهَامَانَ وَجُنُودَهُمَا مِنْهُم } أي :  من بني إسرائيل {  مَّا كَانُوا يَحْذَرُونَ } وذلك أنه قيل لفرعون إنه يولد في هذا العام غلام يسلبك ملكك ؛  فتتبع أبناءهم يقتلهم ويستحيي نساءهم فلا يقتلهن حذراً مما قيل له{[2793]} .
