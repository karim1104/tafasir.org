قال تعالى :  {  يُرْسَلُ عَلَيْكُمَا } يعني الكفار من الجن والإِنس {  شُوَاظٌ مِّن نَّارٍ } وهو اللهب الذي لا دخان فيه {  وَنُحَاسٌ } وهو الدخان الذي لا لهب فيه ،   وهو تفسير ابن عباس .   وهي تقرأ على وجه آخر :  {  مِن نَّارٍ وَنُحَاسٍ } ،   وهي قراءة عبد الرحمن الأعرج ،   يقول :  {  يُرْسَلُ عَلَيْكُمَا شُوَاظٌ مِّن نَّارٍ وَنُحَاسٍ ) يقول :  من لهب ودخان .   قال الله :  {  فَلاَ تَنتَصِرَانِ } أي :  لا تمتنعان .   {  فبأي آلاء ربكما تكذبان } .  <br />
