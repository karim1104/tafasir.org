{  وَإِذَا قِيلَ إِنَّ وَعْدَ اللَّهِ حَقٌّ } .   أي :  يوم القيامة {  وَالسَّاعَةُ } أي :  القيامة {  لاَ رَيْبَ فِيهَا } أي :  لا شك فيها {  قُلْتُم مَّا نَدْرِي مَا السَّاعَةُ إِن نَّظُنُّ إِلاَّ ظَنًّا } ذكروا أنهم تدخلهم خلجات شك .   قال بعضهم :  إن نشك إلا شكاً .   {  وَمَا نَحْنُ بِمُسْتَيْقِنِينَ } أي :  إن الساعة آتية .  <br />
