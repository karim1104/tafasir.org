قال :  {  وَوُضِعَ الكِتَابُ } أي :  ما كانت تكتب عليهم الملائكة في الدنيا من أعمالهم .   {  فَتَرَى المُجْرِمِينَ } أي :  المشركين والمنافقين {  مُشْفِقِينَ } أي :  خائفين {  مِمَّا فِيهِ وَيَقُولُونَ يَا وَيْلَتَنَا مَالِ هَذَا الكِتَابِ لاَ يُغَادِرُ صَغِيرَةً وَلاَ كَبِيرَةً إِلاَّ أَحْصَاهَا وَوَجَدُوا مَا عَمِلُوا حَاضِراً } أي :  في كتبهم {  وَلاَ يَظْلِمُ رَبُّكَ أَحَداً } .  <br />
