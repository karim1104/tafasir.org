قوله :  {  قَالَ لَنْ أُرْسِلَهُ مَعَكُمْ حَتَّى تُؤْتُونِ مَوْثِقاً مِّنَ اللهِ } أي :  حتى تعطون موثقاً من الله {  لَتَأْتُنَّنِي بِهِ إلاَّ أَن يُحَاطَ بِكُمْ } أي :  إلا أن تغلبوا عليه .   وقال بعضهم :  أي :  إلا أن تهلكوا جميعاً .  <br />
{  فَلَمَّا آتَوْهُ } أي :  أعطوه {  مَوْثِقَهُمْ قَالَ } يعقوب :  {  اللهُ عَلَى مَا نَقُولُ وَكِيلٌ } أي :  حفيظ لهذا العهد .  <br />
