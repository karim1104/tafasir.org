قال :  {  وَمَا تَسْأَلُهُمْ عَلَيْهِ } أي :  على القرآن {  مِنْ أَجْرٍ } فيكونون إنما حملهم على تركه الغرم .   وقال في آية أخرى :  {  قُل لاَّ أَسْأَلُكُمْ عَلَيْهِ أَجْراً إِنْ هُوَ إِلاَّ ذِكْرَى لِلْعَالَمِينَ } .   [ الأنعام : 90 ] قوله :  {  إِنْ هُوَ إِلاَّ ذِكْرَى لِلْعَالَمِينَ } يذكرون به الجنة والنار .
