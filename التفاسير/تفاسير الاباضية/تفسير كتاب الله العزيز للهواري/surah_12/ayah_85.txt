قوله :  {  قَالُوا تَاللَّهِ } وهو قسم {  تَفْتَؤُا تَذْكُرُ يُوسُفَ } أي :  لا تزال تذكر يوسف{[1744]} {  حَتَّى تَكُونَ حَرَضاً } أي :  حتى تبلى{[1745]} {  أَوْ تَكُونَ مِنَ الهَالِكِينَ } أي :  أو تموت .   وقال مجاهد :  {  تَفْتَؤُا } أي :  لا تفتأ ،   أي :  لا تفتر عن ذكر يوسف أو تكون من الميتين .
