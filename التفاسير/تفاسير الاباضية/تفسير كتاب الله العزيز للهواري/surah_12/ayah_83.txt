قالوا ذلك له فلم يصدقهم و {  قَالَ بَلْ سَوَّلَتْ لَكُمْ أَنفُسُكُمْ } أي :  زيَّنت لكم أنفسكم {  أَمْراً فَصَبْرٌ جَمِيلٌ } .   قال مجاهد :  الصبر الجميل :  الذي ليس فيه جزع .   كان مفزع يعقوب في يوسف وأخيه جميعاً إلى الصبر الجميل الذي لم يخالطه الجزع .   وكل صبر فيه جزع فليس بجميل .  <br />
قوله :  {  عَسَى اللهُ أَن يَأْتِيَنِي بِهِمْ جَمِيعاً } أي :  يوسف وأخيه [ وروبيل ]{[1741]} {  إِنَّهُ هُوَ العَلِيمُ } أي :  العليم بخلقه {  الحَكِيمُ } أي :  في أمره .
