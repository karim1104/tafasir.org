{  قَالَ } يوسف {  مَعَاذَ اللهِ أَن نَّأْخُذَ } فنستعبد {  إِلاَّ مَن وَجَدْنَا مَتَاعَنَا عِندَهُ } أي :  على ما قضوا به على أنفسهم حيث {  قَالُوا جَزَآؤُهُ مَن وُجِدَ فِي رَحْلِهِ فَهُوَ جَزَآؤُهُ } يؤخذ عبداً بتلك السرقة .   {  إِنَّا إِذاً لَّظَالِمُونَ } [ أي :  إن أخذنا غير الذي وجدنا متاعنا عنده ]{[1739]} .
