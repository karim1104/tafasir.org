قوله عز وجل :  {  هُمُ الَّذِينَ كَفَرُوا وَصَدُّوكُمْ عَنِ الْمَسْجِدِ الْحَرَامِ } عن نافع عن ابن عمر قال :  إن رسول الله صلى الله عليه وسلم صدَّه المشركون عن المسجد الحرام وأنا معه فنحر [ ونحر أصحابه ] الهدي بالحديبية .  <br />
قوله عز وجل :  {  وَالْهَدْيَ مَعْكُوفًا } أي :  محبوساً {  أَن يَبْلُغَ مَحِلَّهُ } أي لئلا يبلغ محلّه .   قال :  {  وَلَوْلاَ رِجَالٌ مُّؤْمِنُونَ وَنِسَاء مُّؤْمِنَاتٌ } بمكة يدينون بالتقية {  لَّمْ تَعْلَمُوهُمْ أَن تَطَؤُوهُمْ } فتقتلوهم {  فَتُصِيبَكُم مِّنْهُم مَّعَرَّةٌ } أي :  إثم {  بِغَيْرِ عِلْمٍ } .   قال الله تعالى :  {  لِيُدْخِلَ اللَّهُ فِي رَحْمَتِهِ مَن يَشَاء } أي :  في دينه الإِسلام فيُسلمون ،   وقد فعل الله ذلك .   قال الله :  {  لَوْ تَزَيَّلُوا } أي زال المسلمون من المشركين والمشركون من المسلمين فصار المشركون محضاً {  لَعَذَّبْنَا الَّذِينَ كَفَرُوا مِنْهُمْ عَذَابًا أَلِيمًا } أي :  لسلطناكم عليهم فقتلتموهم .  <br />
