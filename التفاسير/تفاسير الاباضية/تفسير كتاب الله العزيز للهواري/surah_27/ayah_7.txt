قوله :  {  إِذْ قَالَ مُوسَى لأَهْلِهِ إِنِّي آنَسْتُ نَاراً } قال بعضهم :  إني أحسست ناراً{[2733]} .   وقال في آية أخرى : <br />
{  إِذْ رَأَى نَاراً } [ طه :  10 ] أي :  رآها ناراً عند نفسه ،   وإنما كانت نوراً .  <br />
{  سََآتِيكُم مِّنْهَا بِخَبَرٍ } أي :  بخبر الطريق ،   وكان على غير الطريق .   وقال في آية أخرى :  {  أًو أَجِدُ عَلَى النَّارِ هُدىً } أي :  هداة يهدونني إلى الطريق .   {  أَو آتِيكُم بِشِهَاب قَبَسٍ }{[2734]} وقال في آية أخرى :  {  أَوْ جِذْوَةٍ مِّنَ النَّارِ }<br />
[ القصص :  29 ] ،   {  لَّعَلَّكُمْ تَصْطَلُونَ } لكي تصطلوا ،   وكان شاتياً .
