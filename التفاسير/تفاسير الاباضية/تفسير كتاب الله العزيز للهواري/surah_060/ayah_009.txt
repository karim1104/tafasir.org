قوله عز وجل :  {  إِنَّمَا يَنْهَاكُمُ اللهُ عَنِ الَّذِينَ قَاتَلُوكُمْ فِي الدِّينِ } يعني كفار أهل مكةِ  ،  {  وَأَخْرَجُوكُم مِّن دِيَارِكُمْ } أي :  من مكة  ،  {  وَظَاهَرُواْ } أي :  وأعانوا {  عَلَى إِخْرَاجِكُم أَن تَوَلَّوْهُمْ وَمَن يَتَوَلَّهُمْ فَأُوْلَئِكَ هُمُ الظَّالِمُونَ } .  <br />
