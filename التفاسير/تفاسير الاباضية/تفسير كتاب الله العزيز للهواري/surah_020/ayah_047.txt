{  فَأَتِيَاهُ فَقُولا إِنَّا رَسُولاَ رَبِّكَ فَأَرْسِلْ مَعَنَا بَنِي إسْرَائِيلَ وَلاَ تُعَذِّبْهُمْ } وكان بنو إسرائيل عند القبط بمنزلة أهل الجزية فينا .  <br />
قوله :  {  قَدْ جِئْنَاكَ بِآيَةٍ مِّن رَّبِّكَ } قال الحسن :  العصا واليد {  وَالسَّلامُ عَلَى مَنِ اتَّبَعَ الهُدَى } .   ذكروا أن رسول الله صلى الله عليه وسلم كان إذا كتب إلى المشركين كتب :  {  السَّلاَمُ عَلَى مَنِ اتَّبَعَ الهُدَى }{[2256]}
