{  ثُمَّ اجْتَبَاهُ رَبُّهُ } وهو قوله :  {  فَتَلَقَّى آدَمُ مِن رَّبِّهِ كَلِمَاتٍ } [ البقرة :  37 ] و {  قَالاَ رَبَّنَا ظَلَمْنَا أَنفُسَنَا وَإِن لَّمْ تَغْفِرْ لَنَا وَتَرْحَمْنَا لَنَكُونَنَّ مِنَ الخَاسِرِينَ } [ الأعراف :  23 ] .   قال عز وجل :  {  فَتَابَ عَلَيْهِ } أي :  من ذلك الذنب {  وَهَدَى } أي :  مات على الهدى .
