قوله عزّ وجلّ :  {  فَاصْبِرْ عَلَى مَا يَقُولُونَ } من قولهم إنك ساحر وإنك شاعر ،   وإنك مجنون ،   وإنك كاهن ،   وإنك كاذب {  وَسَبِّحْ بِحَمْدِ رَبِّكَ قَبْلَ طُلُوع الشَّمْسِ } يعني صلاة الصبح {  وَقَبْلَ غُرُوبِهَا } أي الظهر والعصر {  وَمِنْ آناءِ اللَّيْلِ } يعني المغرب والعشاء {  فَسَبِّحْ } .   وقال بعضهم :  {  وَمِنْ آنَاءِ اللَّيْلِ } أي :  ساعات الليل{[2296]} {  وَأَطْرَافَ النَّهَارِ } قال الحسن :  يعني التطوّع .  <br />
وذكروا عن الحسن في قوله عز وجل :  {  وَأَقِمِ الصَّلاَةَ طَرَفَيِ النَّهَارِ } ما بين صلاة الصبح وصلاة العصر<br />
{  وَزُلفاً مِنَ الّلَيْلِ } [ هود :  114 ] أي :  المغرب والعشاء .  <br />
قوله عز وجل :  {  لَعَلَّكَ تَرْضَى } أي ثواب عملك في الآخرة .  <br />
وقال الحسن :  {  لَعَلَّكَ تَرْضَى } أي :  فإنك سترضى ثواب عملك .   وهي تقرأ على وجه آخر :  {  لَعَلَّكَ تُرْضَى } أي :  تُرضى في الآخرة بثواب عملك .   أي :  يرضيك الله بالثواب .
