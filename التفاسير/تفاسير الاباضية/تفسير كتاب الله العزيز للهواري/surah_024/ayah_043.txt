قوله :  {  أَلَمْ تَرَ أَنَّ اللهَ يُزْجِي سَحَاباً } أي :  ينشئ سحاباً{[2605]} .   {  ثُمَّ يُؤَلِّفُ بَيْنَهُ } أي :  يجمع بعضه إلى بعض {  ثُمَّ يَجْعَلهُ رُكَاماً } [ أي :  بعضه على بعض ]{[2606]} {  فَتَرَى الوَدْقَ } أي :  المطر {  يَخْرُجُ مِنْ خِلاَلِهِ } أي :  من خلال السحاب .  <br />
قال :  {  وَيُنَزِّلُ مِنَ السَّمَاءِ مِنْ جِبَالٍ فِيهَا مِن بَرَدٍ } أي :  ينزل من تلك الجبال التي هي من برد ،   والتي هي في السماء {  فَيُصِيبُ بِهِ } أي :  بذلك البرد {  مَن يَّشَاءُ } فيهلك الزرع .   كقوله :  {  رِيحٍ فِيهَا صِرٌّ } أي :  برد<br />
{  أَصَابَتْ حَرْثَ قَوْمٍ ظَلَمُوا أَنفُسَهُمْ فَأَهْلَكَتْهُ } [ آل عمران :  117 ] .  <br />
وما أصاب العباد من مصيبة فبذنوبهم ،   وما يعفو الله عنه أكثر .   كقوله :  {  وَمَا أَصَابَكُمْ مِّن مُّصِيبَةٍ فَبِمَا كَسَبَتْ أَيْدِيكُمْ وَيَعْفُوا عَن كَثِيرٍ } [ الشورى :  30 ] .  <br />
ذكروا أن رجلاً قال لابن عباس :  بتنا الليلة نمطر الضفادع .   قال ابن عباس :  صدقت ،   إن في السماء بحاراً .  <br />
قوله :  {  وَيَصْرِفُهُ عَن مَّن يَشَاءُ } أي :  يصرف ذلك البرد عمن يشاء .   {  يَكَادُ سَنَا بَرْقِهِ } أي :  ضوء برقه {  يَذْهَبُ بِالأَبْصَارِ } .  <br />
ذكروا عن عروة بن الزبير قال :  قال رسول الله صلى الله عليه وسلم :  "  إذا رأى أحدكم البرق أو الودق فليسبحن الله ولينعت{[2607]} "  .  <br />
ذكروا أن رسول الله صلى الله عليه وسلم قال :  "  اطلبوا إجابة الدعاء عند ثلاثة مواضع :  عند إقامة الصلاة ،   وعند نزول الغيث ،   وعند التقاء الجيوش{[2608]} "  .
