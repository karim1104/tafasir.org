قوله :  {  هُوَ الَّذِي بَعَثَ فِي الأُمِّيِّينَ } العرب {  رَسُولاً مِّنْهُمْ } أي :  كانوا أميين ليس عندهم كتاب من عند الله كما كان لأهل الكتاب ،   وقد كانوا يخطون بأيديهم .  <br />
قال عز وجل :  {  يَتْلُواْ عَلَيْهِمْ آيَاتِهِ } يعني القرآن {  وَيُزَكِّيهِمْ وَيُعَلِّمُهُمُ الْكِتَابَ وَالْحِكْمَةَ } قال بعضهم :  الكتاب :  القرآن ،   والحكمة :  السنة ،   والزكاة :  العمل الصالح .   قال عز وجل :  {  وَإِن كَانُواْ مِن قَبْلُ } أي :  كانوا قبل أن يأتيهم محمد صلى الله عليه وسلم بالكتاب والحكمة {  لَفِي ضَلاَلٍ مُّبِينٍ } أي :  بيّن .  <br />
