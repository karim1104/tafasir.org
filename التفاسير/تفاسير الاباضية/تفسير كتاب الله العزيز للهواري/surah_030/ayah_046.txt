قوله :  {  وَمِنْ آيَاتِهِ أَن يُرْسِلَ الرِّيَاحَ مُبَشِّرَاتٍ } أي :  بالمطر {  وَلِيُذِيقَكُم مِّن رَّحْمَتِهِ } يعني بالمطر {  وَلِتَجْرِيَ الفُلْكُ بِأَمْرِهِ وَلِتَبْتَغُوا مِن فَضْلِهِ } أي :  طلب التجارة في البحر .   وهذا تبع للكلام الأول في هذه الآية :  {  وَمِنْ آيَاتِهِ أَن يُرْسِلَ الرِّيَاحَ مُبَشِّرَاتٍ } وما ذكر من المطر والسفن وطلب الفضل .   قال :  {  وَلَعَلَّكُمْ تَشْكُرُونَ } أي :  لتشكروا هذه النعم .  <br />
