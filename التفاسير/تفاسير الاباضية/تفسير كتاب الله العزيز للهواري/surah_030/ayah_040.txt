قوله :  {  اللهُ الَّذِي خَلَقَكُمْ ثُمَّ رَزَقَكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ } يعني البعث {  هَلْ مِن شُرَكَائِكُم } يعني ما تعبدون من دون الله {  مَّن يَفْعَلُ مِن ذَلِكُم مِّن شَيْءٍ } أي :  يخلق أو يرزق أو يحيي أو يميت {  سُبْحَانَهُ } ينزّه نفسه {  وَتَعَالَى عَمَّا يُشْرِكُونَ } أي :  ارتفع عما يقول المشركون .  <br />
