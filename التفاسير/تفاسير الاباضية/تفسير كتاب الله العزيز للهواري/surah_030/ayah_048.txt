قوله :  {  اللهُ الَّذِي يُرْسِلُ الرِّيَاحَ فَتُثِيرُ سَحَاباً فَيَبْسُطُهُ فِي السَّمَاءِ كَيْفَ يَشَاءُ وَيَجْعَلُهُ كِسَفاً } أي :  قطعاً بعضه على بعض {  فَتَرَى الوَدْقَ } أي :  المطر {  يَخْرُجُ مِنْ خِلاَلِهِ } أي :  من خلال السحاب ،   وقال بعضهم :  {  مِنْ خِلاَلِهِ } أي :  من خلل السحاب .   قال :  {  فَإِذَا أَصَابَ بِهِ مَن يَشَاءُ مِنْ عِبَادِهِ إِذَا هُمْ يَسْتَبْشِرُونَ } أي :  بالمطر .  <br />
