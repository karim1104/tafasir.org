قوله :  {  وَلَقَدْ أَرْسَلْنَا مِن قَبْلِكَ } يا محمد {  رُسُلاً إِلَى قَوْمِهِمْ فَجَاءُوهُم } أي :  جاءتهم تلك الرسل {  بِالْبَيِّنَاتِ } أي :  بالبينات والنور والهدى فكذبوهم {  فَانتَقَمْنَا مِنَ الَّذِينَ أَجْرَمُوا } أي :  من الذين أشركوا {  وَكَانَ حَقّاً عَلَيْنَا نَصْرُ المُؤْمِنِينَ } أي :  إجابة دعاء الأنبياء على قومهم بالهلاك حين كذّبوهم ،   فأمروا بالدعاء عليهم ،   ثم استجيب لهم فأهلكهم الله .  <br />
