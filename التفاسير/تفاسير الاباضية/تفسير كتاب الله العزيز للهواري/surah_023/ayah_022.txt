قوله :  {  وَعَلَيْهَا } أي :  وعلى الإِبل {  وَعَلَى الفُلْكِ } أي :  السفن {  تُحْمَلُونَ } وقد يقال :  إنها سفن البَرّ .   وقال في آية أخرى :  {  وَآيَةٌ لَّهُمْ أَنَّا حَمَلْنَا ذُرِّيَّتِهُمْ فِي الفُلْكِ المَشْحُونِ } أي :  الموقر ،   {  وَخَلَقْنَا لَهُم مِّن مِّثْلِهِ مَا يَرْكَبُونَ } [ سورة يس :  41-42 ] يعني الإِبل .   عدلت بالسفن .   وقال في آية أخرى :  {  وَجَعَل لَكُم مِّنَ الفُلْكِ وَالأَنْعَامِ مَا تَرْكَبُونَ } [ الزخرف :  12 ] .
