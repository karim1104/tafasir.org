قال :  {  فَأَوْحَيْنا إِلَيْهِ أَنِ اصْنَعِ الفُلْكَ بِأَعْيُنِنَا وَوَحَيِنَا فَإِذَا جَاءَ أَمْرُنَا وَفَارَ التَّنُّورُ فَاسْلُكْ فِيهَا } أي :  فاحمل فيها {  مِن كُلٍّ زَوْجَيْنِ اثْنَيْنِ } وقد فسّرنا ذلك في سورة هود{[2480]} .  <br />
قوله :  {  وَأَهْلَكَ } أي :  واحمل فيها أهلك {  إِلاَّ مَن سَبَقَ عَلَيْهِ القَوْلُ مِنْهُمْ } أي :  ابنه الذي غرق .   والقول :  الغضب {  وَلاَ تُخَاطِبْنِي فِي الذِينَ ظَلَمُوا } أي :  [ ولا تراجعني في الذين ظلموا ]{[2481]} {  إِنَّهُم مُّغْرَقُونَ } .
