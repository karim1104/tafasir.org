{  أَوْ تَقُولُوا لَوْ أَنَّا أُنزِلَ عَلَيْنَا الكِتَابُ لَكُنَّا أَهْدَى مِنْهُمْ } أي من أهل الكتاب .   {  فَقَدْ جَاءَكُم بَيِّنَةٌ } أي موعظة {  مِّن رَّبِّكُمْ وَهُدًى وَرَحْمَةٌ } يعني القرآن {  فَمَنْ أَظْلَمُ مِمَّن كَذَّبَ بِآيَاتِ اللهِ وَصَدَفَ عَنْهَا } أي وصدَّ عنها في تفسير الحسن .   وقال غيره :  وأعرض عنها .   أي لا أظلم منه .   {  سَنَجْزِي الَّذِينَ يَصْدِفُونُ عَنْ ءَايَاتِنَا سُوءَ العَذَابِ } أي أشدّه {  بِمَا كَانُوا يَصْدِفُونَ } أي يصدون في تفسير الحسن .   وقال غيره :  يعرضون .  <br />
