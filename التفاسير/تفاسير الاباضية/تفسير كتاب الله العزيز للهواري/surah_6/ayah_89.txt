{  أُوْلَئِكَ الَّذِينَ ءَاتَيْنَاهُمُ الكِتَابَ وَالحُكْمَ } يعني الفهم والعقل {  وَالنُّبُوَّةَ فَإِن يَكْفُرْ بِهَا هَؤُلاَءِ } يعني المشركين {  فَقَدْ وَكَّلْنَا بِهَا } أي بالنبوّة {  قَوْماً لَّيْسُوا بِهَا بِكَافِرِينَ } يعني النبيين الذين ذكر{[1069]} .  <br />
وقال بعضهم :  {  فَإِن يَكْفُرْ بِهَا هَؤُلاَءِ } يعني أهل مكة {  فَقَدْ وَكَّلْنَا بِهَا } أي بالنبوّة {  قَوْماً لَّيْسُوا بِهَا بِكَافِرِينَ } يعني أهل المدينة .
