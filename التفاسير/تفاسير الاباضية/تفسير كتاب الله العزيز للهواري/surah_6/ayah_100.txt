قوله :  {  وَجَعَلُوا لِلَّهِ شُرَكَاءَ الجِنَّ } يعني الشياطين من الجن لأن الشياطين هي التي دعتهم إلى عبادة الأوثان ،   ولم تدعهم الأوثان إلى عبادتها ،   فأشركوا الجن بعبادة الله .  <br />
قال :  {  وَخَلَقَهُمْ } أي الله خلقهم {  وَخَرَقُوا لَهُ بَنِينَ وَبَنَاتٍ } أي جعلوا له بنين وبنات في تفسير الحسن .   وقال بعضهم :  كذِبوا له بنين وبنات .   وقالوا :  له بنون وبنات .   قال الحسن :  يعني قوله :  {  وَيَجْعَلُونَ لِلَّهِ البَنَاتِ سُبْحَانَهُ } [ النحل : 57 ] قوله :  {  بِغَيْرِ عِلْمٍ } أي أتاهم من الله {  سُبْحَانَهُ } ينزّه نفسه عما قالوا :  {  وَتَعَالَى } أي من قبل العلو والارتفاع ،   أي ارتفع {  عَمَّا يَصِفُونَ } أي عما يكذبون .
