قوله :  {  تَبَارَكَ الذِي جَعَلَ فِي السَّمَاءِ بُرُوجاً } والبروج النجوم{[2677]} {  وَجَعَلَ فِيهَا سِرَاجاً } يعني الشمس {  وَقَمَراً مُّنِيراً } أي :  مضيئا .   وهي تجري في فلك دون السماء .   قوله :  {  الذِي جَعَلَ فِي السَّمَاءِ } ،   والسماء كل ما ارتفع .   وقال في آية أخرى : <br />
{  ألَمْ يَرَوا إِلَى الطَّيْر مُسَخَّرَاتٍ فِي جَوِّ السَّمَاءِ } [ النحل :  79 ] أي :  مرتفعات متحلّقات .
