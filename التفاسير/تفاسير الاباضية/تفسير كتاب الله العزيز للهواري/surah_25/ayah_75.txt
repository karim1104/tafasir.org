قال :  {  أَولَئِكَ يُجْزَوْنَ الغُرْفَةَ } كقوله :  {  وَهُمْ فِي الغُرُفَاتِ آمِنُونَ } [ سبأ :  37 ] {  بِمَا صَبَرُوا } أي :  على طاعة الله وعن معصية الله .   {  وَيُلَقَّوْنَ فِيهَا } أي :  في الجنة {  تَحِيَّةً وَسَلاَماً } التحية :  السلام ،   والسلام :  الخير الكثير كقوله : <br />
{  سَلاَمٌ هِيَ } [ القدر :  5 ] قال مجاهد :  {  سَلاَمٌ هِيَ } أي :  خيرٌ هي كلها {  حَتَّى مَطْلَعِ الفَجْرِ } يعني ليلة القدر .
