قوله :  {  وَقَوْمَ نُوحٍ لَّمَّا كَذَّبُوا الرُّسُلَ } أي :  وأهلكنا قوم نوح أيضاً بالغرق لما كذبوا الرسل بتكذيبهم نوحاً .   قال :  {  أَغْرَقْنَاهُمْ وَجَعَلْنَاهُمْ لِلنَّاسِ آيَةً } أي :  لمن بعدهم {  وَأَعْتَدْنَا لِلظَّالِمِينَ } أي :  للمشركين ،   يعنيهم{[2660]} ،   {  عَذَاباً أَلِيماً } أي :  موجعاً في الآخرة .
