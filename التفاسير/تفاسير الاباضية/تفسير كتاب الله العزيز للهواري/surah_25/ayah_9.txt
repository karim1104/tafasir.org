قوله :  {  انظُرْ كَيْفَ ضَرَبُوا لَكَ الأَمْثَالَ } يعني قولهم :  {  إِنْ هذَا إِلا إِفْكٌ افْتَرَاهُ وَأَعَانَهُ عَلَيْهِ قَوْمٌ آخَرُونَ } وقولهم :  {  أَسَاطِيرُ الأَوَّلِينَ اكْتَتَبَهَا } ،   وقولهم :  {  مَالِ هذَا الرَّسُولِ يَأكُلُ الطَّعَامَ وَيَمْشِي فِي الأَسْوَاقِ } وقولهم :  ساحر وشاعر وكاهن ومجنون ،   و {  لَوْلا أُنزِلَ إِلَيْهِ مَلَكٌ فَيَكُونَ مَعَهُ نَذِيراً أوْ يُلْقى إِلَيْهِ كَنْزٌ أَوْ تَكُونُ لَهُ جَنَّةٌ يَأكُلُ مِنْهَا } قال الله :  {  انْظُرْ كَيْفَ ضَرَبُوا لَكَ الأَمْثَالَ }<br />
قال :  {  فَضَلُّوا فَلاَ يَسْتَطِيعُونَ سَبِيلاً } أي :  مخرجاً من الأمثال التي ضربوا لك ،   في تفسير مجاهد{[2646]} .
