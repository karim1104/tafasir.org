قوله :  {  وَقَدِمْنَا إلَى مَا عَمِلُوا مِنْ عَمَلٍ } أي :  وعمدنا .   وفي تفسير مجاهد :  {  إِلَى مَا عَمِلُوا مِنْ عَمَلٍ } أي :  حسن ،   يعني المشركين {  فَجَعَلْنَاهُ } أي :  في الآخرة {  هَبَاءً مَّنْثُوراً } وهو الذي يتناثر من الغبار الذي يكون من أثر حوافر الدوابّ إذا سارت .   وفي الآية :  {  هَبَاءً مُّنْبَثّاً } [ الواقعة :  6 ] وهو الذي يدخل من الكوّة من ضوء الشمس .   وتفسير مجاهد :  {  هَبَاءً مَّنْثُوراً } هو عنده هذا .
