قوله :  {  وَقَالَ الذِينَ كَفَرُوا إِنْ هَذَا } يعنون القرآن {  إِلا إِفْكٌ } أي :  كذب {  افْتَرَاهُ } يعنون محمداً عليه السلام {  وَأَعَانَهُ عَلَيْهِ قَوْمٌ آخَرُونَ } أي :  اليهود في تفسير مجاهد .   وقال الحسن :  يعنون عبد ابن الحضرمي .   وقال الكلبي :  عبد ابن الحضرمي ،   وعداس غلام عتبة .  <br />
قال الله :  {  فَقَدْ جَاءُوا ظُلْماً وَزُوراً } أي :  أتوا شركاً وكذباً .   والظلم ها هنا الشرك ،   والزور الكذب .  <br />
