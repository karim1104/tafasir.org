قوله :  {  أَلَمْ تَرَ إِلَى رَبِّكَ كَيْفَ مَدَّ الظِّلَّ } قال الحسن :  {  أَلَمْ تَرَ إِلَى رَبِّكَ كَيْفَ مَدَّ الظِّلَّ } من طلوع الفجر إلى طلوع الشمس .   {  وَلَوْ شَاءَ لَجَعَلَهُ سَاكِناً } أي :  لا يزول .   قال :  {  ثُمَّ جَعَلْنَا الشَّمْسَ عَلَيْهِ } أي :  على الظل {  دَلِيلاً } أي :  تتبعه وتقبضه{[2665]} .  <br />
وقال مجاهد :  {  سَاكِناً } لا تصيبه الشمس ولا يزول .   {  ثُمَّ جَعَلْنَا الشَّمْسَ عَلَيْهِ دَلِيلاً } أي :  تحويه .
