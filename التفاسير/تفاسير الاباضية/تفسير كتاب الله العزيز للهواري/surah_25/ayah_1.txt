{  بسم الله الرحمن الرحيم } قوله :  {  تَبَارَكَ } وهو من باب البركة{[2642]} كقوله :  {  تَعَالَى } أي :  ارتفع .   قوله :  {  الذِي نَزَّلَ الفُرْقَانَ } أي :  القرآن .   وفُرقانه حلاله وحرامه ،   وفرائضه وأحكامه .  <br />
{  عَلَى عَبْدِهِ } يعني محمداً صلى الله عليه وسلم {  لِيَكُونَ لِلْعَالَمِينَ نَذِيراً } أي :  ينذرهم النار وعذاب الدنيا قبل عذاب الآخرة إن لم يؤمنوا .
