{  فَانْطَلَقَا حَتَّى إِذَا أَتَيَا أَهْلَ قَرْيَةٍ اسْتَطْعَمَا أَهْلَهَا فَأَبَوْا أَن يُضَيِّفُوهُمَا } وزعموا أنها أنطاكية{[2145]} .   {  فَوَجَدَا فِيهَا جِدَاراً يُرِيدُ أَن يَنقَضَّ فَأَقَامَهُ } أي :  رفعه بيده {  قَالَ } له موسى {  لَوْ شِئْتَ لَتَّخَذْتَ عَلَيْهِ أَجْراً } أي :  ما يكفينا اليوم .
