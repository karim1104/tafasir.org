قال الله :  {  وَدَخَلَ جَنَّتَهُ وَهُوَ ظَالِمٌ لِّنَفْسِهِ } يعني بشركه {  قَالَ :  مَا أَظُنُّ } أي :  ما أوقن {  أَن تَبِيدَ هَذِهِ أَبَداً } أي :  أن تفنى هذه أبداً ،   أي :  إنها لا تفنى فتذهب .   ولكن ظن أن يعيش فيها حتى يأكلها حياتَه .   كقوله :  {  يَحْسَبُ أَنَّ مَالَهُ أَخْلَدَهُ } [ الهُمَزة : 3 ] أي :  يحسب أنه يخلد في ماله حتى يأكله .
