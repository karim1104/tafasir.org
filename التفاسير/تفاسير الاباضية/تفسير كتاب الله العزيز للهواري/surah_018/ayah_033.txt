قوله :  {  وَاضْرِبْ لَهُم مَّثَلاً رَّجُلَيْنِ جَعَلْنَا لأَحَدِهِمَا جَنَّتَيْنِ مِنْ أَعْنَابٍ وَحَفَفْنَاهُمَا بِنَخْلٍ وَجَعَلْنَا بَيْنَهُمَا زَرْعاً كِلْتَا الجَنَّتَيْنِ آتَتْ أُكُلَهَا } أي :  أطعمت ثمرتها {  وَلَمْ تَظْلِم مِّنْهُ شَيْئاً } أي :  ولم تنقص منه شيئاً {  وفَجَّرْنَا خِلاَلَهُمَا نَهَراً } أي :  بينهما .  <br />
