قوله :  {  الَّذِينَ كَانَتْ أَعْيُنُهُمْ فِي غِطَاءٍ عَن ذِكْرِي } أي :  كانت على أعينهم غشاوة الكفر .   كقوله :  {  لَّقَدْ كُنتَ فِي غَفْلَةٍ مِّنْ هَذَا فَكَشَفْنَا عَنْكَ غِطَاءَكَ } أي :  غطاء الكفر {  فَبَصَرُكَ اليَوْمَ حَدِيدٌ } [ سورة ق : 22 ] أي :  أبصر حين لا ينفعه البصر .   {  وَكَانُوا لاَ يَسْتَطِيعُونَ سَمْعاً } أي :  لا يسمعون الهدى بقلوبهم .   وقال مجاهد :  لا يعقلون .
