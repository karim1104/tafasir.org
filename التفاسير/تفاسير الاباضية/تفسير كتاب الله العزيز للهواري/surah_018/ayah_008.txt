قال :  {  وَإِنَّا لَجَاعِلُونَ مَا عَلَيْهَا } أي :  ما على الأرض {  صَعِيداً جُرُزاً } والجُرُز ها هنا الخراب .   وقال بعضهم :  التي ليس فيها شجر ولا نبات .   وقال مجاهد :  بلقعاً .   وقال في موضع آخر :  {  أَوَ لَمْ يَرَوا أَنَّا نَسُوقُ المَاءَ إِلَى الأَرْضِ الجُرُزِ } أي :  اليابسة التي ليس فيها نبات {  فَنُخْرِجُ بِهِ زَرْعاً } [ السجدة : 27 ] .
