قوله :  {  وَاذْكُرْ عِبَادَنَآ } يقول للنبي عليه السلام :  واذكر عبادنا {  إِبْرَاهِيمَ وَإِسْحَاقَ وَيَعْقُوبَ أُوْلِي الأَيْدِي وَالأَبْصَارِ } قال بعضهم :  {  أُوْلِي الأَيْدِي } ،   أولي القوة في أمر الله ،   {  والأَبْصَارِ } ،   أي في كتاب الله .   وقال الحسن :  {  أُوْلِي الأَيْدِي } أي :  أولي القوة في عبادة الله .  <br />
