{  مَنْ عَمِلَ سَيِّئَةً } والسيئة ها هنا الشرك {  فَلاَ يُجْزَى إِلاَّ مِثْلَهَا } أي :  النار .   {  وَمَنْ عَمِلَ صَالِحًا مِّن ذَكَرٍ أَوْ أُنثَى وَهُوَ مُؤْمِنٌ } أي :  لا يقبل الله العمل الصالح إلا من المؤمن {  فَأُوْلَئِكَ يَدْخُلُونَ الْجَنَّةَ يُرْزَقُونَ فِيهَا بِغَيْرِ حِسَابٍ } [ قال السّدّي :  بغير متابعة ولا منّ عليهم فيما يعطون ]{[3253]} .
