{  وَيَا قَوْمِ إِنِّي أَخَافُ عَلَيْكُمْ يَوْمَ التَّنَادِ } قال بعضهم :  يوم ينادي أهل الجنة أهل النار : {  قَدْ وَجَدْنَا مَا وَعَدَنَا رَبُّنَا حَقّاً فَهَلْ وَجَدتُّم مَّا وَعَدَ رَبُّكُمْ حَقّاً } [ الأعراف :  44 ] ،   وينادي أهل النار أهل الجنة :  {  أَنْ أَفِيضُواْ عَلَيْنَا مِنَ الْمَآءِ أَوْ مِمَّا رَزَقَكُمُ اللهُ } [ الأعراف : 50 ] .  <br />
وتفسير الكلبي :  {  يَوْمَ التَّنَادِ } ،   مشدّدة ،   أي يوم الفرار يوم يندّون كما يندّ البعير .   قال ألا تراه
