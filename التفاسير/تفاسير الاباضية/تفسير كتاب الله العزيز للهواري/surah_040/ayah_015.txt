قوله :  {  رَفِيعُ الدَّرَجَاتِ } أي :  هو رفيع الدرجات ،   أي :  درجات المؤمنين في الجنة {  ذُو الْعَرْشِ } رب العرش {  يُلْقِي الرُّوحَ } أي :  ينزل الوحي{[3240]}{  مِنْ أَمْرِهِ عَلَى مَن يَشَاء مِنْ عِبَادِهِ } أي :  الأنبياء مع جبريل {  لِيُنذِرَ يَوْمَ التَّلاَقِ } أي :  يوم القيامة ،   يوم يلتقي فيه الخلائق من أهل السماء وأهل الأرض عند الله يوم القيامة .
