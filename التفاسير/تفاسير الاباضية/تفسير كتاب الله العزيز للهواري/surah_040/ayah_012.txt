{  ذَلِكُم بِأَنَّهُ إِذَا دُعِيَ اللَّهُ وَحْدَهُ كَفَرْتُمْ وَإِن يُشْرَكْ بِهِ تُؤْمِنُوا } أي :  تصدَّقوا بعبادة الأوثان .  <br />
وقال بعضهم :  ليس فيها إضمار ،   ولكن قال :  {  إِنَّ الَّذِينَ كَفَرُوا يُنَادَوْنَ لَمَقْتُ اللَّهِ أَكْبَرُ مِن مَّقْتِكُمْ أَنفُسَكُمْ } لأنكم كنتم {  تُدْعَوْنَ } في الدنيا {  إِلَى الإِيمَانِ فَتَكْفُرُونَ } .  <br />
قال :  {  فَالْحُكْمُ لِلَّهِ الْعَلِيِّ } أي :  لا أعلى منه {  الْكَبِيرِ } أي لا أكبر منه .   قوله :  {  فَالْحُكْمُ لِلَّهِ } أي حكمه على العباد بأن أدخل المؤمنين الجنة وأدخل المشركين النار .  <br />
