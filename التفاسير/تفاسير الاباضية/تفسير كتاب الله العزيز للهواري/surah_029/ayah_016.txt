قوله :  {  وَإِبْرَاهِيمَ } أي :  وأرسلنا إبراهيم إلى قومه ،   وهذا تبع للكلام الأول في نوح :  {  وَلَقَدْ أَرْسَلْنَا نُوحاً إِلَى قَوْمِهِ } قال :  {  إِذْ قَالَ لِقَوْمِهِ اعْبُدُوا اللهَ } أي :  وحدوه {  وَاتَّقُوهُ } أي :  واخشوه {  ذَلِكُمْ خَيْرٌ لَّكُمْ إِن كُنتُمْ تَعْلَمُونَ } .  <br />
