قوله :  {  مَثَلُ الَّذِينَ اتَّخَذُوا مِن دُونِ اللهِ أَوْلِيَاءَ } يعني أوثانهم التي عبدوها .   {  كَمَثَلِ الْعَنكَبُوتِ اتَّخَذَتْ بَيْتاً وَإِنَّ أَوْهَنَ البُيُوتِ } أي :  أضعف البيوت {  لَبَيْتُ العَنكَبُوتِ } أي :  إن أوثانهم لا تغني عنهم شيئاً كما لا يكن بيت العنكبوت من حرّ ولا برد {  لَوْ كَانُوا يَعْلَمُونَ } أي :  لعلموا أن أوثانهم لا تغني عنهم شيئاً كبيت العنكبوت .  <br />
