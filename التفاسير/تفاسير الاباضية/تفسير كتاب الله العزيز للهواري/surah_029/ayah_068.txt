قال :  {  وَمَنْ أَظْلَمُ مِمَّنِ افْتَرَى عَلَى اللهِ كَذِباً } فعبد الأوثان دونه {  أَوْ كَذَّبَ بِالْحَقِّ } أي :  بالقرآن {  لَمَّا جَاءَهُ } أي :  لا أحد أظلم منه ،   ثم قال :  {  أَلَيْسَ فِي جَهَنَّمَ مَثْوىً لِّلْكَافِرِينَ } وهو على الاستفهام ،   أي :  بلى فيها مثوى للكافرين .  <br />
