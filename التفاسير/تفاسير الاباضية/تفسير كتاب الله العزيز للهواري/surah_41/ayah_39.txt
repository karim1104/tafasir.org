قوله :  {  وَمِنْ آيَاتِهِ أَنَّكَ تَرَى الأَرْضَ خَاشِعَةً } أي هامدة متهشمة{[3312]} وتفسير الحسن :  ميّتة ،   وهو واحد .   قال :  {  فَإِذَا أَنزَلْنَا عَلَيْهَا الْمَاء اهْتَزَّتْ } بالمطر {  وَرَبَتْ } {  اهْتَزَّتْ وَرَبَتْ } فيها تقديم وتأخير .   ( وَرَبَتْ ) :  انتفخت للنبات ( وَاهْتَزَّتْ ) :  أي بنباتها إذا أنبتت{[3313]} .  <br />
قال :  {  إِنَّ الَّذِي أَحْيَاهَا لَمُحْيِي الْمَوْتَى إِنَّهُ عَلَى كُلِّ شَيْءٍ قَدِيرٌ } وهذا مثل للبعث .
