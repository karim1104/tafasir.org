قوله :  {  أَمْ تُرِيدُونَ أَن تَسْأَلُوا رَسُولَكُمْ كَمَا سُئِلَ مُوسَى مِن قَبْلُ } ذكر بعض المفسِّرين أنه قال :  كان الذي سألوا موسى من قبل أن قالوا :  {  أَرِنَا اللهَ جَهْرَةً }[ النساء : 153 ] .   قال الحسن :  وقد سألوا ذلك النبي عليه السلام فقالوا : {  أَوْ تَأْتِي بِاللهِ والمَلاَئِكَةِ قَبِيلاً }[ الإِسراء : 92 ] ،   وقالوا : {  لَوْلاَ أُنزِلَ عَلَيْنَا المَلاَئِكَةُ أَوْ نَرَى رَبَّنَا } [ الفرقان : 21 ] .  <br />
قوله :  {  وَمَن يَتَبَدَّلِ الكُفْرَ بِالإِيمَانِ } أي :  ومن يقل ذلك فقد بدّل الكفر بالإِيمان ،   يعني تبدّل اليهودية والنصرانية بالإِسلام .   {  فَقَدْ ضَلَّ سَوَاءَ السَّبِيلِ } أي قصد الطريق .
