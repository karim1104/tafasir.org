قال :  {  ثُمَّ تَوَلَّيْتُم مِّن بَعْدِ ذَلِكَ } فنقضتم الميثاق {  فَلَوْلاَ فَضْلُ اللهِ عَلَيْكُمْ } بعد نقض الميثاق الأول حين اتخذوا العجل ثم عفا عنهم بالتوبة التي أمرهم أن يقتلوا أنفسهم [ بها ]{[136]} {  وَرَحْمَتُهُ } إذ لم يعجّل عليك بالعذاب {  لَكُنتُم مِّنَ الْخَاسِرِينَ } أي من المعذَّبِينَ .
