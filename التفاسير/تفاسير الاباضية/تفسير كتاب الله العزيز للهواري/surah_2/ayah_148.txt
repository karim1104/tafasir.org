قوله :  {  وَلِكُلٍّ وَجْهَةٌ } أي ولكل قوم وجهة وشريعة{[230]} {  هُوَ مُوَلِّيهَا } أي :  الله موليها ،   مثل قوله : <br />
{  لِكُلٍّ جَعَلْنَا مِنكُمْ شِرْعَةً وَمِنْهَاجاً }<br />
[ المائدة : 48 ] أي سبيلاً وسنة ،   والدين واحد وإن اختلفت الشرائع والأحكام .   وقال مجاهد :  ولكل صاحب ملّة وجهة هو مستقبلها .   وقال بعضهم :  ولكل قبلة هو مستقبلها .  <br />
قوله :  {  فَاسْتَبِقُوا الخَيْرَاتِ } قال بعض المفسرين :  لا تُغْبَنُنَّ{[231]} عَن قبلتكم {  أَيْنَ مَا تَكُونُوا يَأْتِ بِكُمُ اللهُ جَمِيعاً إِنَّ اللهَ عَلَى كُلِّ شَيْءٍ قَدِيرٌ } .
