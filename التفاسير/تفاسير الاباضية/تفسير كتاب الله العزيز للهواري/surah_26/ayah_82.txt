{  وَالذِي أَطْمَعُ } وهذا طمع اليقين {  أَن يَغْفِرَ لِي خَطِيئَتِي يَوْمَ الدِّينِ } أي :  يوم يدين الله الناس فيه بأعمالهم في تفسير بعضهم .   وقال مجاهد :  يوم الحساب ،   وهو واحد .   وقوله :  {  خَطِيئَتِي } يعني قوله :  {  إِنِّي سَقِيمٌ } [ الصافات :  89 ] وقوله : <br />
{  بَلْ فَعَلَهُ كَبِيرُهُمْ هذَا } [ الأنبياء :  63 ] ،   وقوله لسارّة :  إن سألوك فقولي إنك أختي .   ذكروه بإسناد عن النبي عليه السلام{[2701]} .
