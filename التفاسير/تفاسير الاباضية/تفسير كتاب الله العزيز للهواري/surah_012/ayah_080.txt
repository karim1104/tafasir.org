قوله :  {  فَلَمَّا اسْتَيْئَسُوا مِنْهُ } أي :  يئسوا من أن يرد عليهم أخاهم {  خَلَصُوا نَجِيّاً } أي :  خلصوا وحدهم نجِيّاً .   جعلوا يتناجون ويتشاورون فيما بينهم في ذلك .  <br />
{  قَالَ كَبِيرُهُمْ } وهو روبيل ،   وهو الذي قال :  {  لاَ تَقْتُلُوا يُوسُفَ وَأَلْقُوهُ فِي غَيَابَتِ الجُبِّ } .   وقال مجاهد :  كبيرهم شمعون ،   وأكبر منه في الميلاد{[1740]} روبيل .   {  أَلَمْ تَعْلَمُوا أَنَّ أَبَاكُمْ قَدْ أَخَذَ عَلَيْكُم مَّوْثِقاً مِّنَ اللهِ ،   وَمِن قَبْلُ مَا فَرَّطتُمْ فِي يُوسُفَ } قال الحسن :  وقد كانوا أعطوا أباهم في يوسف أيضاً عهداً أن يردوه عليه .  <br />
{  فَلَنْ أَبْرَحَ الأَرْضَ } يعني أرض مصر {  حَتَّى يَأْذَنَ لِي أَبِي } في الرجوع إليه {  أَوْ يَحْكُمَ اللهُ لِي } بغير الرجوع .   وقال بعضهم :  أو يحكم الله لي بالموت {  وَهُوَ خَيْرُ الحَاكِمِينَ } .
