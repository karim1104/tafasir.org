قوله :  {  احْشُرُوا الَّذِينَ ظَلَمُوا وَأَزْوَاجَهُمْ } أي :  سوقوا الذين أشركوا وأزواجهم ،   أي :  وأشكالهم .   [ وقال بعضهم :  {  وَأَزْوَاجَهُمْ } أي :  وقرناءهم من الشياطين ]{[3156]} {  وَمَا كَانُوا يَعْبُدُونَ مِن دُونِ اللهِ فَاهْدُوهُمْ إِلَى صِرَاطِ الجَحِيمِ } .  <br />
ذكروا عن النعمان بن بشير عن عمر بن الخطاب في قوله :  {  وَإِذَا النُّفُوسُ زُوِّجَتْ }<br />
[ التكوير :  7 ] قال :  يزوّج كل إنسان نظيره من النار ،   ثم تلا هذه الآية :  {  احْشُرُوا الَّذِينَ ظَلَمُوا وَأَزْوَاجَهُمْ وَمَا كَانُوا يَعْبُدُونَ مِن دُونِ اللهِ فَاهْدُوهُمْ }<br />
وقال الكلبي :  {  احْشُرُوا الَّذِينَ ظَلَمُوا } أي :  أشركوا ،   {  وَأَزْوَاجَهُمْ } أي :  ومن عمل بأعمالهم من بني آدم .
