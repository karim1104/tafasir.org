قوله :  {  أَمْ حَسِبْتُمْ أَن تُتْرَكُوا } أي :  فلا يفرض عليكم الجهاد {  وَلَمَّا يَعْلَمِ اللهُ } أي :  ولما يعلمكم فاعلين لما فرض عليكم ،   وهو علم الفعال{[1404]} .   {  الَّذِينَ جَاهَدُوا مِنكُمْ وَلَمْ يَتَّخِذُوا مِن دُونِ اللهِ وَلاَ رَسُولِهِ وَلاَ المُؤْمِنِينَ وَلِيجَةً } .   أي :  دخلا .   وقال بعضهم :  بطانة ،   وهو واحد .   أي :  مثل ما صنع المنافقون {  إِذَا لَقُوا الَّذِينَ ءَامَنُوا قَالُوا ءَامَنَّا وَإِذَا خَلَوْا إِلَى شَيَاطِينِهِمْ } أي :  إلى الكفار المشركين {  قَالُوا إِنَّا مَعَكُمْ } [ البقرة : 14 ] أي :  في المودة والهوى .   قال الله :  {  وَاللهُ خَبِيرٌ بِمَا تَعْمَلُونَ } .
