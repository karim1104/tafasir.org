قال :  {  وَمِنْ آيَاتِهِ أَن تَقُومَ السَّمَاءُ وَالأَرْضُ بِأَمْرِهِ } [ يعني بغير عمد ] [ فاطر :  2 ] قال :  {  ثُمَّ إِذَا دَعَاكُمْ دَعْوَةً مِّنَ الأَرْضِ إِذَا أَنتُمْ تَخْرُجُونَ } يعني النفخة الآخرة .   وفيها تقديم :  إذا دعاكم دعوة إذا أنتم من الأرض تخرجون .   كقوله :  {  وَنُفِخَ فِي الصُّورِ فَإِذَا هُم مِّنَ الأَجْدَاثِ } أي :  من القبور {  إِلَى رَبِّهِمْ يَنسِلُونَ } [ يس :  51 ] أي :  يخرجون ،   وهو نفخ صاحب الصور .   وهو كقوله :  {  فَإِنَّمَا هِيَ زَجْرَةٌ وَاحِدَةٌ فَإِذَا هُم بِالسَّاهِرَةِ } [ النازعات :  13-14 ] أي :  فإذا هم على الأرض .   وهو قوله : {  يَوْمَ يُنَادِي المُنَاديِ } [ سورة ق :  41 ] .
