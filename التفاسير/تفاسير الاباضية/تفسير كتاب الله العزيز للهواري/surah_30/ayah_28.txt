قوله :  {  ضَرَبَ لَكُم مَّثَلاً مِّنْ أَنفُسِكُمْ } ثم ذكر ذلك المثل فقال :  {  هَل لَّكُم مِّن مَّا مَلَكَتْ أَيْمَانُكُم مِّن شُرَكَاءَ فِي مَا رَزَقْنَاكُمْ } أي :  هل يشارك أحدكم مملوكه في زوجته وماله ؟  {  فَأَنتُمْ فِيهِ سَوَاءٌ تَخَافُونَهُمْ } أي :  تخافون لائمتهم {  كَخِيفَتِكُمْ أَنفُسَكُمْ } أي :  كخيفة بعضكم بعضاً ،   أي :  إنه ليس أحد منكم هكذا ،   فأنا أحق ألا يُشرَك بعبادتي غيري ،   فكيف تعبدون غيري دوني ،   تشركونه في ألوهيتي وربوبيتي ؟  وهو مثل قوله :  {  وَاللهُ فَضَّلَ بَعْضَكُمْ عَلَى بَعْضٍ فِي الرِّزْقِ فَمَا الَّذِينَ فُضِّلُوا بِرَادِّي رِزْقِهِمْ عَلَى مَا مَلَكَتْ أَيْمَانُهُمْ فَهُمْ فِيهِ سَوَاءٌ } [ النحل :  71 ] قال :  {  كَذَلِكَ نُفَصِّلُ الآَيَاتِ } يعني نبيّن الآيات {  لِقَوْمٍ يَعْقِلُونَ } وهم المؤمنون .
