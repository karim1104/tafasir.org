قوله :  {  أَلا إِنَّ لِلَّهِ مَا فِي السَّمَاوَاتِ وَالأَرْضِ قَدْ يَعْلَمُ مَا أَنتُمْ عَلَيْهِ } أي :  من النفاق ،   يعني المنافقين {  وَيَوْمَ يُرْجَعُونَ إِلَيْهِ } يقول للنبي :  ويوم يرجعون إليه ،   أي :  يوم القيامة {  فَيُنَبِّئُهُم } أي :  فيخبرهم {  بِمَا عَمِلُوا } أي :  من النفاق والكفر {  وَاللهُ بِكُلِّ شَيْءٍ عَلِيمٌ } أي :  فلا أعلم منه سبحانه .  <br />
