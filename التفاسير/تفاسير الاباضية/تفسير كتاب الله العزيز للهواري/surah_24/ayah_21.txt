قوله : {  يا أيها الذين آمنوا لا تتبعوا خطوات الشيطان } أي :  خطايا الشيطان ؛  وبعضهم يقول :  أمر الشيطان .   قال : {  ومن يتبع خطوات الشيطان فإنه } أي :  فإن الشيطان {  يأمر } بالخطيئة ويأمر{  بالفحشاء والمنكر }{[2559]}قال : {  ولولا فضل الله عليكم ورحمته } وهي مثل الأولى {  ما زكا منكم من أحد } أي :  ما صلح منكم من أحد {  أبدا ولكن الله يزكي } أي : يصلح {  من يشاء والله سميع عليم } .
