{  بل تؤثرون الحياة الدنيا } وهي تقرأ على وجهين :  {  تُوثِرُونَ } {  وَيُؤثِرُونَ } فمن قرأها {  تُؤثِرُونَ } يقولها للمشركين ،   أي :  تزعمون أن الدنيا باقية وأن الآخرة لا تكون .   ومن قرأها {  تَؤثِرُونَ } فهو يقول للنبي عليه السلام :  {  بَلْ يُؤثِرُونَ } ،   يعني المشركين الحياة الدنيا .  <br />
