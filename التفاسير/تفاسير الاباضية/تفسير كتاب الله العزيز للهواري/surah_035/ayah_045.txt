قوله :  {  وَلَوْ يُؤَاخِذُ اللهُ النَّاسَ بِمَا كَسَبُوا } أي :  بما عملوا {  مَا تَرَكَ عَلَى ظَهْرِهَا مِن دَابَّةٍ } يقول :  يحبس عنهم المطر ،   فهلك ما في الأرض من دابّة{[3116]} .   {  وَلَكِن يُؤَخِّرُهُمْ } يعني المشركين {  إِلَى أَجَلٍ مُّسَمّىً } أي :  الساعة التي يكون بها هلاك آخر كفّار هذه الأمة {  فَإِذَا جَاءَ أَجَلُهُمْ } أي :  الساعة {  فَإِنَّ اللهَ كَانَ بِعِبَادِهِ بَصِيراً } لا تخفى عنه منهم خافية ،   أي :  لا يكذب صادقاً ،   ولا يصدّق كاذباً ولا يقضي بباطل ،   سبحانه وتعالى .
