قوله :  {  يَوْمَ نَدْعُوا كُلَّ أُنَاسٍ بِإِمَامِهِمْ } .   أي :  بكتابهم ،   أي :  ما نسخت عليهم الملائكة من أعمالهم .   وقال بعضهم :  {  بِإِمَامِهِمْ } أي :  بنبيّهم قال :  {  فَمَنْ أُوتِيَ كِتَابَهُ بِيَمِينِهِ فَأُوْلَئِكَ يَقْرَءُونَ كِتَابَهُمْ } وقد فسّرناه قبل هذا الموضع{[2054]} {  وَلاَ يُظْلَمُونَ فَتِيلاً } وقد فسّرناه في سورة النساء{[2055]} .
