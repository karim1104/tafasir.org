قال الله :  {  انظُرْ كَيْفَ ضَرَبُوا لَكَ الأَمْثَالَ } أي :  الأشباه{[2037]} {  فَضَلُّوا } بقولهم ذلك {  فَلاَ يَسْتَطِيعُونَ سَبِيلاً } قال مجاهد :  مخرجاً [ مما قالوا ] يعني الوليد بن المغيرة وأصحابه .   وقال في قوله :  {  إِذْ يَسْتَمِعُونَ إِلَيْكَ } :  [ هو مثل ]{[2038]} قول الوليد بن المغيرة ومن معه في دار النَّدوة .  {[2039]}
