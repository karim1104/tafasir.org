قوله :  {  قُل لَّوْ أَنتُمْ تَمْلِكُونَ خَزَائِنَ رَحْمَةِ رَبِّي } يعني مفاتيح الرزق {  إِذاً لأَمْسَكْتُمْ خَشْيَةَ الإِنفَاقِ } [ أي :  خشية الفاقة ]{[2077]} {  وَكَانَ الإِنسَانُ قَتُوراً } أي :  بخيلاً يقتّر على نفسه وعلى غيره .   يخبر أنهم بخلاء أشحاء ،   يعني المشركين .   وقال بعضهم :  {  قَتُوراً } أي :  مِسِّيكاً{[2078]} .
