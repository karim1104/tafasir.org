{  يَعْلَمُ مَا يَلِجُ } أي :  ما يدخل {  فِي الأَرْضِ } من المطر {  وَمَا يَخْرُجُ مِنْهَا } أي :  من النبات {  وَمَا يَنزِلُ مِنَ السَّمَاءِ } أي من المطر وغير ذلك {  وَمَا يَعْرُجُ فِيهَا } أي :  وما يصعد فيها ،   أي :  ما تصعد به الملائكة {  وَهُوَ الرَّحِيمُ } أي :  بخلقه {  الغَفُورُ } أي :  لمن تاب وآمن .  <br />
