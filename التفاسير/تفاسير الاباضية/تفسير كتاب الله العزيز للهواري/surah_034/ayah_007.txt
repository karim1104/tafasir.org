قوله :  {  وَقَالَ الَّذِينَ كَفَرُوا } يقوله بعضهم لبعض {  هَلْ نَدُلُّكُمْ عَلَى رَجُلٍ } يعنون محمداً صلى الله عليه وسلم {  يُنَبِّئُكُمْ } أي :  يخبركم {  إِذَا مُزِّقْتُمْ كُلَّ مُمَزَّقٍ إِنَّكُمْ لَفِي خَلْقٍ جَدِيدٍ } أي :  إذا متم وتفرقت عظامكم وكانت رفاتاً إنكم مبعوثون خلقاً جديداً ،   إنكاراً للبعث .  <br />
