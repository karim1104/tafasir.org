قال :  {  فَقَالُوا رَبَّنَا بَاعِدْ بَيْنَ أَسْفَارِنَا } تفسير الحسن :  أنهم مَلُّوا النعمة كما ملَّتْ بنو إسرائيل المنَّ والسَّلْوَى .  <br />
وتفسير الكلبي :  إنهم قالوا لرسلهم حين ابتلوا ،   أي :  حين كذبوهم :  كنا نأبى عليكم{[3063]} وأرضنا عامرة خير أرض ،   فكيف اليوم وأرضنا خراب .  <br />
وبعضهم يقرأها :  ربنا {  باعِد } ،   وبعضهم يقرأها :  {  بَعِّدْ } ،   وبعضهم :  {  بَعُدَ } قال الله :  {  وَظَلَمُوا أَنفُسَهُمْ } أي :  بشركهم {  فَجَعَلْنَاهُمْ أَحَادِيثَ } [ أي :  لمن بعدهم ]{[3064]} {  وَمَزَّقْنَاهُمْ كُلَّ مُمَزَّقٍ } أي :  بددنا عظامهم وأوصالهم فأكلهم التراب .   {  إِنَّ فِي ذَلِكَ } أي :  في إهلاك القرية ومن فيها {  لآَيَاتٍ لِّكُلِّ صَبَّارٍ } أي :  على أمر الله {  شَكُورٍ } لنعمة الله ،   وهو المؤمن .
