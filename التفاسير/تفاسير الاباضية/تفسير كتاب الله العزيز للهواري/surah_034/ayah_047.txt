قوله :  {  قُلْ مَا سَأَلْتُكُم } أي :  على القرآن {  مِّنْ أَجْرٍ فَهُوَ لَكُمْ } كقوله :  {  قُلْ مَا أَسْأَلُكُمْ عَلَيْهِ مِنْ أَجْرٍ وَمَا أَنَا مِنَ المُتَكَلِّفِينَ } [ سورة ص :  86 ] وأشباه ذلك .   {  إِنْ أجْرِيَ إِلاَّ عَلَى اللهِ وَهُوَ عَلَى كُلِّ شَيْءٍ شَهِيدٌ } أي :  شاهد على كل شيء .
