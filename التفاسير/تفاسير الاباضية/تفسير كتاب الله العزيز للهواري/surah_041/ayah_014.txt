{  إِذْ جَاءتْهُمُ الرُّسُلُ مِن بَيْنِ أَيْدِيهِمْ وَمِنْ خَلْفِهِمْ أَلاَّ تَعْبُدُوا إِلاَّ اللَّهَ } يحذرونهم وقائع الله في الكفار حين كذبوا رسلهم .   ويعني ب {  مِن بَيْنِ أَيْدِيهِمْ } قوم نوح ومن أهلك بعدهم ،   و ب {  مِنْ خَلْفِهِمْ } عذاب الآخرة ،   أي أنذروهم عذاب الدنيا وعذاب الآخرة{[3285]} .  <br />
{  قَالُوا لَوْ شَاء رَبُّنَا لأَنزَلَ مَلاَئِكَةً } كقولهم للنبي عليه السلام :  {  أَوْ جَآءَ مَعَهُ الْمَلاَئِكَةُ مُقْتَرِنِينَ } [ الزخرف : 53 ] أي :  فيخبرون أنه رسول الله .   ومثل قوله :  {  لَّوْ مَا تَأْتِينَا بِالْمَلاَئِكَةِ إِن كُنتَ مِنَ الصَّادِقِينَ } [ الحجر : 7 ] أي :  فتخبرنا أنك رسول الله ؛  أي :  يقوله كل قوم لرسولهم .   {  فَإِنَّا بِمَا أُرْسِلْتُمْ بِهِ كَافِرُونَ } .
