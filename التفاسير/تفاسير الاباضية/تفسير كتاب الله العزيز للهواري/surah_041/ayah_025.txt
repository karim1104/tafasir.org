قال :  {  وَقَيَّضْنَا لَهُمْ قُرَنَاء } أي :  نسبنا لهم قرناء{[3295]} ،   يعني الشياطين .   كقوله :  {  أَلَمْ تَرَ أَنَّا أَرْسَلْنَا الشَّيَاطِينَ عَلَى الْكَافِرِينَ تَؤُزُّهُمْ أَزًّا } [ مريم : 83 ] أي :  تزعجهم إزعاجاً في معاصي الله .  <br />
قال :  {  فَزَيَّنُوا لَهُم مَّا بَيْنَ أَيْدِيهِمْ وَمَا خَلْفَهُمْ } قال الحسن :  {  مَّا بَيْنَ أَيْدِيهِمْ } أي :  حبّ ما كان عليه آباؤهم من الشرك وتكذيبهم الرسل .   {  وَمَا خَلْفَهُمْ } تكذيبهم بالبعث .   وقال الكلبي :  {  مَّا بَيْنَ أَيْدِيهِمْ } :  من أمر الآخرة ،   فأخبروهم أنه لا بعث ولا جنة ولا نار ،   {  وَمَا خَلْفَهُمْ } :  زيّنوا لهم أمر الدنيا فلم يريدوا غيرها{[3296]} .  <br />
{  وَحَقَّ عَلَيْهِمُ الْقَوْلُ } أي :  وجب عليهم القول .   وتفسير القول :  الغضب ،   في قول بعضهم :  وقال الحسن :  القول من الله أنهم من أهل النار ؛  كقوله :  {  وَكَذَلِكَ حَقَّتْ كَلِمَتُ رَبِّكَ عَلَى الَّذِينَ كَفَرُوا أَنَّهُمْ أَصْحَابُ النَّارِ } [ غافر : 6 ] أي :  بكفرهم .   قال :  {  فِي أُمَمٍ } أي :  مع أمم {  قَدْ خَلَتْ مِن قَبْلِهِم مِّنَ الْجِنِّ وَالْإِنسِ إِنَّهُمْ كَانُوا خَاسِرِينَ } والخاسرون :  أهل النارِ ،   خسروا أنفسهم فصاروا في النار .
