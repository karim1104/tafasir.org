قوله :  {  وَإِذَا أَنْعَمْنَا عَلَى الإِنسَانِ أَعْرَضَ } أي :  عنا {  وَنَأى بِجَانِبِهِ } أي :  تباعد .   وهو مثل قوله :  {  وَإِذَا مَسَّ الإِنسَانَ الضُّرُّ دَعَانَا لِجَنبِهِ أَوْ قَاعِدًا أَوْ قَآئِمًا فَلَمَّا كَشَفْنَا عَنْهُ ضُرَّهُ مَرَّ } أي أعرض {  كَأَن لَّمْ يَدْعُنَا إِلَى ضُرٍّ مَّسَّهُ } [ يونس : 12 ] .   قال :  {  وَإِذَا مَسَّهُ الشَّرُّ فَذُو دُعَاء عَرِيضٍ } أي :  كثير .
