قوله عز وجل :  {  إِنَّ الَّذِينَ كَفَرُوا وَصَدُّوا عَن سَبِيلِ اللَّهِ } أي :  عن الإسلام {  وَشَاقُّوا الرَّسُولَ } أي :  فارقوا الرسول وعادوه {  مِن بَعْدِ مَا تَبَيَّنَ لَهُمُ الهُدَى } أي من بعد ما قامت عليهم الحجة {  لَن يَضُرُّوا اللَّهَ شَيْئًا } أي :  بكفرهم {  وَسَيُحْبِطُ أَعْمَالَهُمْ } أي :  في الآخرة ،   يعني ما كان من عمل حسن عملوه في الدنيا .  <br />
