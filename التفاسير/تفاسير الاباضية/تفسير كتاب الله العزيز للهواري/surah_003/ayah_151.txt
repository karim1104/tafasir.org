قوله :  {  سَنُلْقِي فِي قُلُوبِ الَّذِينَ كَفَرُوا الرُّعْبَ } قال الحسن :  يعني مشركي العرب .   ذكر الحسن قال :  قال رسول الله صلى الله عليه وسلم :   "  نصرت بالرعب بين يدي مسيرة شهر{[597]}  قوله :  {  بِمَا أَشْرَكُوا بِاللهِ } أي نلقي في قلوبهم الرعب بما أشركوا بالله {  مَا لَمْ يُنَزِّلْ بِهِ سُلْطَاناً } أي حجة بما هم عليه من الشرك {  وَمَأْوَاهُمُ النَّارُ } أي :  مصيرهم النار .   {  وَبِئْسَ مَثْوَى الظَّالِمِينَ } أي المشركين .
