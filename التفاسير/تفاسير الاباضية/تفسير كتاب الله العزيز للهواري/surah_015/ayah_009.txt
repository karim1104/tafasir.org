قوله :  {  إِنَّا نَحْنُ نَزَّلْنَا الذِّكْرَ } يعني القرآن {  وَإِنَّا لَهُ لَحَافِظُونَ } أي :  حفظه الله من إبليس أن يزيد فيه شيئاً أو ينقص منه شيئاً .   كقوله :  {  إِنَّ الَّذِينَ كَفَرُوا بِالذِّكْرِ لَمَّا جَاءَهُمْ وَإِنَّهُ لَكِتَابٌ عَزِيزٌ لاَّ يَأْتِيهِ البَاطِلُ } والباطل هو إبليس {  مِن بَيْنِ يَدَيْهِ } فينقصَ منهُ<br />
{  وَلاَ مِنْ خَلْفِهِ } [ فصّلت : 41-42 ] فيزيد فيه شيئاً .   حفظه الله من ذلك{[1856]} .  <br />
وقال مجاهد :  {  وَإِنَّا لَهُ لَحَافِظُونَ } أي :  عندنا .
