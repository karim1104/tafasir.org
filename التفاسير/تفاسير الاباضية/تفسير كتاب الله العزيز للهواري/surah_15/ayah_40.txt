قال :  {  إِلاَّ عِبَادَكَ مِنْهُمُ المُخْلَصِينَ } أي :  الذين أخلصوا القول والعمل فوفوا لله بهما .  {[1870]}<br />
هو كقوله :  {  لأَحْتَنِكَنَّ ذُرِّيَّتَهُ إِلاَّ قَليلاً } [ الإسراء : 62 ] وكقوله :  {  وَلاَ تَجِدُ أَكْثَرَهُمْ شَاكِرِينَ } [ الأعراف : 17 ] أي :  مؤمنين .   وكان الحسن يقرأها :  {  وَلَقَدْ صَدَّقَ عَلَيْهِمْ إِبْلِيسَ ظَنُهُ } [ سبإ : 20 ] يرفع الظن وينصب إبليسَ .   يقول صدق عليهم ظنه ولم يقل ذلك بعلم .   وكان مجاهد يقرأها مثقلة :  {  وَلَقد صَدَّقَ عَلَيْهُم إِبْلِيسُ ظَنَّه فَاتَّبَعُوهُ } يرفع إبليس وينصب الظنّ .
