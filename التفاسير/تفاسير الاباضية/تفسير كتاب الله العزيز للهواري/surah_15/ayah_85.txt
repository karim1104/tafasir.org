قوله :  {  وَمَا خَلَقْنَا السَّمَاوَاتِ وَالأَرْضَ وَمَا بَيْنَهُمَا إِلاَّ بِالْحَقِّ } أي :  للبعث {  وَإِنَّ السَّاعَةَ } أي :  القيامة {  لآتِيَةٌ } أي :  لجائية {  فَاصْفَحِ الصَّفْحَ الجَمِيلَ } والصفح ها هنا منسوخ بالقتال .   وهو كقوله :  {  فَاصْفَحْ عَنْهُمْ } يعني المشركين {  وَقُلْ سَلاَمٌ فَسَوْفَ يَعْلَمُونَ } [ الزخرف : 89 ] .   ثم أمره بقتالهم في سورة براءة فقال :  {  فَإِذَا انْسَلَخَ الأَشْهُرُ الحُرُمُ فَاقْتُلُوا المُشْرِكِينَ حَيْثُ وَجَدْتُّمُوهُمْ } [ التوبة : 5 ] .
