قوله عز وجل :  {  يَتَنَازَعُونَ فِيهَا } أي :  يتعاطون فيها {  كَأْسًا } والكأس :  الخمر .   {  لاَّ لَغْوٌ فِيهَا } أي في الجنة ،   لا معصية فيها ،   في قول الحسن .   وقال مجاهد :  أي :  لا يسمعون فيها لغواً .   {  وَلاَّ تَأْثِيمٌ } أي :  لا يؤثم بعضهم بعضاً .   وتفسير الكلبي :  {  لاَّ لَغْوٌ فِيهَا } أي :  لا حلف{[3643]} فيها ،   {  وَلاَّ تَأْثِيمٌ } أي :  لا إثم عليها في شربها .   وقال بعضهم :  {  وَلاَّ تَأْتِيمٌ } أي :  ولا تكذيب .
