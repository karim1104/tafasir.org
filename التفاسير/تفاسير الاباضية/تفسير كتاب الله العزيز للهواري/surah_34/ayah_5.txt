قال :  {  وَالَّذِينَ سَعَوْا } أي :  عملوا {  فِي آيَاتِنَا مُعَاجِزِينَ } تفسير الحسن :  يظنون أنهم يسبقوننا حتى لا نقدر عليهم فنبعثهم فنعذبهم كقوله : {  وَمَا كَانُوا سَابِقِينَ }[ العنكبوت :  39 ] .  <br />
وتفسير الكلبي :  {  مُعَاجِزِينَ } مبطئين ،   أي :  يثبطون الناس عن الإِيمان ولا يؤمنون بها .  <br />
قال :  {  أُوْلَئِكَ لَهُمْ عَذَابٌ مِّن رِّجْزٍ } والرجز :  العذاب {  أَلِيمٌ } أي :  موجع .   أي :  لهم عذاب من عذاب موجع .
