قال الله :  {  قُلْ } يا محمد {  إِنَّمَا أَعِظُكُم بِوَاحِدَةٍ } أي :  بلا إله إلا الله .   يقوله للمشركين {  أَن تَقُومُوا لِلَّهِ مَثْنَى وَفُرَادَى } يقول :  أن تقوموا واحداً واحداً أو اثنين اثنين {  ثُمَّ تَتَفَكَّرُوا مَا بِصَاحِبِكُم } أي :  بمحمد صلى الله عليه وسلم {  مِّن جِنَّةٍ } أي :  من جنون{[3077]} {  إِنْ هُوَ إِلاَّ نَذِيرٌ لَّكُم } أي :  من العذاب {  بَيْنَ يَدَيْ عَذَابٍ شَدِيدٍ } يعني عذاب جهنم .   أي :  أرسل محمداً بين يدي عذاب شديد .  <br />
ذكروا عن الحسن قال :  قال رسول الله صلى الله عليه وسلم :  "  إنما مثلي ومثل الساعة كهاتين ،   فما فضل إحداهما على الأخرى ،   فجمع بين أصبعه السّبّابة والوسطى{[3078]} "  .
