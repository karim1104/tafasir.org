قوله :  {  إِذْ أَنتُم بِالعُدْوَةِ الدُّنْيَا } أي عدوة الوادي بأعلى الوادي {  وَهُم بالْعُدْوَةِ القُصْوَى } أي أسفل الوادي .   {  وَالرَّكْبُ أَسْفَلَ مِنكُمْ } يعني أبا سفيان وأصحاب العير .  <br />
قال الكلبي :  كان أبو سفيان والعير أسفل من الوادي  زعموا  بثلاثة أميال في طريق الساحل ،   لا يعلم المشركون مكان عيرهم ،   ولا يعلم أصحاب العير مكان المشركين .  <br />
قال بعضهم :  العدو كان شفير الوادي ؛  كان المسلمون بأعلاه ،   وكان المشركون بأسفله ،   والركب يعني به أبا سفيان والعير ،   الخدم فانطلق على حورمه{[1352]} .  <br />
قال :  {  وَلَوْ تَوَاعَدتُّمْ } أي :  أنتم والمشركون {  لاَخْتَلَفْتُمْ فِي المِيعَادِ } قال الحسن :  لو تواعدتم فيما بينكم فقلتم نصنع كذا وكذا لاختلفتم في الميعاد .   {  وَلَكِن لِّيَقْضِيَ اللهُ أَمْراً كَانَ مَفْعُولاً } أي فيه نصركم والنعمة عليكم .  <br />
قوله :  {  لِّيَهْلِكَ مَنْ هَلَكَ عَن بَيِّنَةٍ وَيَحْيَى مَنْ حَيَّ عَن بَيِّنَةٍ } أي بعد الحجة والبيان .   كقوله :  {  وَمَا أَرْسَلْنَا مِن رَّسُولٍ إِلاَّ بِلِسَانِ قَوْمِهِ لِيُبَيِّنَ لَهُمْ فَيُضِلُّ اللهُ مَن يَشَاءُ وَيَهْدِي مَن يَشَاءُ } [ إبراهيم : 4 ] أي بعد البيان .   {  وَإِنَّ اللهَ لَسَمِيعٌ عَلِيمٌ } .
