قوله :  {  أَوَلَمْ يَهْدِ لَهُمْ } أي :  أو لم نبيّن لهم .   وهي تقرأ على وجه آخر :  {  أَوَلَمْ يَهدِ لَهُمْ } أي :  أي أولم يبيّن لهم الله {  كَمْ أهْلَكْنَا مِن قَبْلِهِم مِّنَ القُرُونِ } يعني ما قصّ ممّا أهلك به الأمم السالفة حين كذّبوا رسلهم .   قال :  {  يَمْشُونَ فِي مَسَاكِنِهِمْ } التي كانوا فيها ؛  منها ما يُرى ومنها ما لا يُرى ،   كقوله :  {  مِنْها قَائِمٌ } تراه {  وَحَصِيدٌ } [ هود :  100 ] أي :  لا تراه .   قال :  {  إِنَّ فِي ذَلِكَ لآَيَاتٍ } أي :  للمؤمنين {  أَفَلاَ يَسْمَعُونَ } يعني المشركين .
