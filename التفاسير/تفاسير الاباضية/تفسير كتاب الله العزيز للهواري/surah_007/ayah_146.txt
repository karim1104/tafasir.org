قوله :  {  سَأَصْرِفُ عَنْ ءَايَاتِي الَّذِينَ يَتَكَبَّرُونَ فِي الأَرْضِ بِغَيْرِ الحَقِّ } قال الحسن :  سأصرفهم عنها بفعلهم حتى لا يؤمنوا بها .   قال :  {  وَإِن يَرَوْا كُلَّ ءَايَةٍ لاَّ يُؤْمِنُوا بِهَا } يخبر بعلمه فيهم .   {  وَإِن يَرَوْا سَبِيلَ الرُّشْدِ لاَ يَتَّخِذُوهُ سَبِيلاً وَإِن يَرَوْا سَبِيلَ الغَيِّ يَتَّخِذُوهُ سَبِيلاً } أخبر أَنهم لا يؤمنون أبداً .   ثم أخبر لِمَ ذلك وبِمَ هو ،   فقال : <br />
{  ذَلِكَ بِأَنَّهُمْ كَذَّبُوا بِآيَاتِنَا وَكَانُوا عَنْهَا غَافِلِينَ } أي معرضين جاحدين .  <br />
