قوله :  {  هُوَ الَّذِي خَلَقَكُم مِّن نَّفْسٍ وَاحِدَةٍ } أي :  آدم {  وَجَعَلَ مِنْهَا زَوْجَهَا } يعني حواء من ضلعه القصيري اليسرى وهو نائم {  لِيَسْكُنَ إِلَيْهَا } .  <br />
قال :  {  فَلَمَّا تَغَشَّاهَا حَمَلَتْ حَمْلاً خَفِيفاً فَمَرَّتْ بِهِ } أي [ استمر بها الحمل فأتمته ]{[1271]} .   {  فَلَمَّا أَثْقَلَت } قال بعضهم :  استبان حملها ،   أي فاشتهر بها الحمل .   {  دَّعَوا اللهَ رَبَّهُمَا } أي :  آدم وحواء {  لَئِنْ ءَاتَيْتَنَا صَالِحاً } أي غلاماً{[1272]} {  لَّنَكُونَنَّ مِنَ الشَّاكِرِينَ } أي لأنعمك .
