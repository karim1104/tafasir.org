قوله :  {  أَمْ يَقُولُونَ } يعني المشركين {  افْتَرَى } أي :  محمد {  عَلَى اللَّهِ كَذِبًا } بما جاء ،   أي :  قد قالوه {  فَإِن يَشَأِ اللَّهُ يَخْتِمْ عَلَى قَلْبِكَ } فيذهب عنك النبوة التي أعطاكها ،   وهذا موضع القدرة ،   ولا تنزع منه النبوّة ،   كقوله : <br />
{  لَوْ أَرَادَ اللَّهُ أَنْ يَتَّخِذَ وَلَدًا لَّاصْطَفَى مِمَّا يَخْلُقُ مَا يَشَاء سُبْحَانَهُ } [ الزمر : 4 ] .  <br />
قوله :  {  وَيَمْحُ اللَّهُ الْبَاطِلَ } قال الحسن :  فلا يجعل لأهله في عاقبته خيراً ولا ثواباً{[3338]} ،   يعني ما عليه المشركون .   {  وَيُحِقُّ الْحَقَّ بِكَلِمَاتِهِ } فينصر النبي والمؤمنين .   قال :  {  إِنَّهُ عَلِيمٌ بِذَاتِ الصُّدُورِ } أي :  بما في الصدور .
