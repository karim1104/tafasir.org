قوله :  {  تَرَى الظَّالِمِينَ } أي :  المشركين {  مُشْفِقِينَ } أي :  خائفين {  مِمَّا كَسَبُوا } أي :  مما عملوا في الدنيا إذ أخرجته كتبهم {  وَهُوَ وَاقِعٌ بِهِمْ } أي :  الذي خافوا منه من عذاب الله .   {  وَالَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ فِي رَوْضَاتِ الْجَنَّاتِ لَهُم مَّا يَشَاؤُونَ عِندَ رَبِّهِمْ } أي :  في الجنة {  ذَلِكَ هُوَ الْفَضْلُ الكَبِيرُ }<br />
