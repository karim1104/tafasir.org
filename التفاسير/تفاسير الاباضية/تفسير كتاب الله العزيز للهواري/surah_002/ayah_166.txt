قوله :  {  إِذْ تَبَرَّأَ الَّذِينَ اتُّبِعُوا } وهم الجبابرة والقادة والرؤوس في الشرك والنفاق {  مِنَ الَّذِينَ اتَّبَعُوا } والأتباع :  الضعفاء الذين اتبعوهم على عبادة الأوثان .   قال :  {  وَرَأَوُا العَذَابَ } جميعاً ،   أي :  القادة والأتباع {  وَتَقَطَّعَتْ بِهِمُ الأَسْبَابُ } أي :  المواصلة [ التي كانت بينهم ] في الدنيا{[247]} لأنهم كانوا أولياءهم .
