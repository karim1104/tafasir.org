{  وَإِذَا مَسَّكُمُ الضُّرُّ } أي :  الأهوال {  فِي البَحْرِ ضَلَّ مَن تَدْعُونَ } أي :  ما تدعون من دونه ضلّ عنكم .   قال :  {  إِلاَّ إِيَّاهُ } تدعونه .   كقوله :  {  بَلْ إِيَاهُ تَدْعُونَ } [ الأنعام : 41 ] ،   يعلمون أنه لا ينجيهم من الغرق إلا الله .   قال :  {  فَلَمَّا نَجَّاكُم إِلَى البَرِّ أَعْرَضْتُمْ } عن الذي نجاكم ورجعتم إلى شرككم {  وَكَانَ الإِنسَانُ كَفُوراً } يعني المشرك .
