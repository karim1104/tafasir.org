قوله :  {  وَمَن يَهْدِ اللهُ فَهُوَ المُهْتَدِ } أي :  لا يستطيع أحد أن يضلّه {  وَمَن يُضْلِلْ فَلَن تَجِدَ لَهُمْ أَوْلِيَاءَ مِن دُونِهِ } أي :  يمنعونهم من عذاب الله .  <br />
قال :  {  وَنَحْشُرُهُمْ يَوْمَ القِيَامَةِ عَلَى وُجُوهِهِمْ عُمْياً وَبُكْماً وَصُمّاً } .   قال بعضهم :  هذا حشر إلى النار .   قال الحسن :  {  عُمياً وَبُكْماً وَصُمّاً } عموا في النار حين دخلوها فلم يبصروا فيها شيئاً ،   وهي سوداء مظلمة لا يضيء لهبها .   {  وَبُكْماً } أي :  خرساً انقطع كلامهم حين قال :  [ الله لهم ]{[2075]} {  اخْسَئُوا فِيهَا وَلاَ تُكَلِّمُونِ } [ المؤمنون : 108 ] .   وقد فسَّرناه قبل هذا الموضع{[2076]} .   {  وَصُمّاً } أي :  ذهب الزفير والشهيق بسمعهم فلا يسمعون شيئاً .   وقال في آية أخرى :  {  وَهُمْ فِيهَا لاَ يَسْمَعُونَ } [ الأنبياء : 100 ] .  <br />
قوله :  {  كُلَّمَا خَبَتْ زِدْنَاهُمْ سَعِيراً } .   وخبّوها أنها تأكل كل شيء :  الجلد واللحم والعظم ،   والشعر والبشر والأحشاء حتى تهجم على الفؤاد ،   فلا يريد الله أن تأكل أفئدتهم ،   فإذا انتهت إلى الفؤاد خبت ،   أي :  سكنت فلم تستعر بهم ،   وتركت فؤادهم ينضج ،   ثم يجدّد جلدهم فيعود ،   فتأكلهم ،   فلا يزالون كذلك .   وهو قوله :  {  كُلَّمَا نَضِجَتْ جُلُودُهُمْ بَدَّلْنَاهُمْ جُلُوداً غَيْرَهَا } .   [ النساء : 56 ] .   وقال مجاهد :  {  كُلَّمَا خَبَتْ } أي :  كلما طفئت أسعرت .
