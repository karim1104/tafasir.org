قوله :  {  قَالَتْ رُسُلُهُمْ } أي :  قالت لهم رسلهم {  أَفِي اللهِ شَكٌّ فَاطِرِ السَّمَاوَاتِ وَالأَرْضِ } أي :  خالق السماوات والأرض أنه لا إله غيره .   وهو على الاستفهام .   أي :  إنه ليس فيه شك أنه خالق السماوات والأرض وأنه لا إله غيره .   فأنتم تقرون أنه خالق السموات والأرض فكيف تعبدون غيره ؟  .  <br />
قوله :  {  يَدْعُوكُمْ لِيَغْفِرَ لَكُم مِّن ذُنُوبِكُمْ } أي :  إن آمنتم .   {  وَيُؤَخِّرَكُمْ إِلَى أَجَلٍ مُّسَمًّى } أي :  إلى آجالهم بغير عذاب إن آمنوا ،   فلا يكون موتهم بالعذاب .  <br />
{  قَالُوا إِنْ أَنتُمْ إِلاَّ بَشَرٌ مِّثْلُنَا } أي :  لا يوحى إليكم {  تُرِيدُونَ أَن تَصُدُّونَا عَمَّا كَانَ يَعْبُدُ آبَآؤُنَا } يعنون الأوثان {  فأْتُونَا بِسُلْطَانٍ مُّبِينٍ } أي :  بحجة بينة .  <br />
