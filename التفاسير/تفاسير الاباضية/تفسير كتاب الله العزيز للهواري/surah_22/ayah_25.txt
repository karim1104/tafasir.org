قوله :  {  إِنَّ الذِينَ كَفَرُوا وَيَصُدُّونَ عَن سَبِيلِ اللهِ } أي :  الهدى ،   يعني المشركين {  وَالمَسْجِدِ الحَرَامِ } أي :  ويصدّون عن المسجد الحرام {  الذِي جَعَلْنَاهُ لِلنَّاسِ } أي :  قِبلة ونسكاً .   وقوله :  {  سَوَاءٌ العَاكِفُ فِيهِ } أي :  الساكن فيه {  وَالبَادِ }<br />
قال بعضهم :  العاكف فيه أهل مكة ،   والبادي من يقصده ،   أي :  ينتابه من الناس للحج والعمرة ،   وهما سواء في حرمه ومناسكه وحقوقه .  <br />
قوله :  {  وَمَن يُرِدْ فِيهِ بِإِلْحَادٍ بِظُلْمٍ } أي :  بشرك {  نُّذِقْهُ مِنْ عَذَابٍ أَلِيمٍ }<br />
قال بعضهم :  من لجأ إلى حرم الله ليعبد فيه غير الله عذّبه الله .   تفسير الكلبي :  الإِلحاد :  الميل عن عبادة الله إلى الشرك .  {[2405]}
