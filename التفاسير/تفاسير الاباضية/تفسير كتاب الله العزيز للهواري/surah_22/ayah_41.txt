قوله :  {  الذِينَ إِن مَّكَّنَّاهُمْ فِي الأَرْضِ } يعني أصحاب النبي عليه السلام .   {  أَقَامُوا الصَّلاَةَ وَآتَوُا الزَّكَاةَ وَأَمَرُوا بِالْمَعْرُوفِ } أي :  بعبادة الله {  وَنَهَوْا عَنِ المُنْكَرِ } أي :  عن عبادة الأوثان {  وَلِلَّهِ عَاقِبَةُ الأُمُورِ } أي :  إليه تصير الأمور .   كقوله : <br />
{  إِنَّا نَحْنُ نَرِثُ الأَرْضَ وَمَنْ عَلَيْهَا وَإِلَيْنَا يُرْجَعُونَ } [ مريم :  40 ]
