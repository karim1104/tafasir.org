{  إِلاَّ الَّذِينَ آمَنُوا وَعَمِلُواْ الصَّالِحَاتِ } استثنى الله من آمن وعمل الصالحات {  لَهُمْ أَجْرٌ } أي :  ثواب .   وهو الجنة {  غَيْرُ مَمْنُونٍ } أي :  غير محسوب .   كقوله تعالى : {  يُرْزَقُونَ فِيهَا بِغَيْرِ حِسَابٍ } [ غافر : 40 ] .   وتفسير الحسن :  غير ممنون عليهم مَنَّ أذى .   والحمد لله رب العالمين .
