قال :  {  وَرَدَّ اللهُ الَّذِينَ كَفَرُوا بِغَيْظِهِمْ لَمْ يَنَالُوا خَيْراً } أي :  لم ينالوا من المسلمين غنيمة ولا ظفراً ؛  وظفرهم بالمسلمين عندهم - لو ظفروا - خيرٌ{[2991]} {  وَكَفَى اللهُ الْمُؤْمِنِينَ القِتَالَ } أي :  بالريح والجنود التي أرسلها الله عليهم {  وَكانَ اللهُ قَوِيّاً عَزِيزاً } .
