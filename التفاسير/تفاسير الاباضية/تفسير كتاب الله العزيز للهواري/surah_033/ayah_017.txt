قال :  {  قُلْ مَن ذَا الَّذِي يَعْصِمُكُم مِّنَ اللهِ } أي :  يمنعكم من الله {  إِنْ أَرَادَ بِكُمْ سُوءاً } أي :  عذاباً .   [ وقال بعضهم :  القتل أو الهزيمة ]{[2982]} {  أَوْ أَرَادَ بِكُمْ رَحْمَةً } أي :  توبة ،   يعني المنافقين .   كقوله :  {  وَيُعَذِّبَ المُنَافِقِينَ إِن شَاءَ } أي :  الذين يَموتون على نفاقهم فيعذبهم<br />
{  أَوْ يَتُوبَ عَلَيْهِمْ }<br />
[ الأحزاب :  24 ] أي :  أو يمن عليهم بالرجعة فيرجعون عن نفاقهم .   [ وقال بعضهم :  النصر والفتح ]{[2983]} قال :  {  وَلاَ يَجِدُونَ لَهُم مِّن دُونِ اللهِ وَلِيّاً } أي :  يتولاهم فيدفع العذاب عنهم {  وَلاَ نَصِيراً } أي :  ينصرهم مما ينزل بهم من العذاب .
