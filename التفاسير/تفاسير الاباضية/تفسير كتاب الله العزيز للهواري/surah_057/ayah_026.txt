قوله :  {  وَلَقَدْ أَرْسَلْنَا نُوحاً وَإِبْرَاهِيمَ وَجَعَلْنَا فِي ذُرِّيَّتِهِمَا النُّبُوَّةَ وَالْكِتَابَ } فكان أول كتاب نزل فيه الحلال والحرام كتاب موسى .   قال :  {  فَمِنْهُم مُّهْتَدٍ } أي من ذريتهما {  وَكَثِيرٌ مِّنْهُمْ } أي :  من ذريتهما {  فَاسِقُونَ } أي :  مشركون ومنافقون .  <br />
