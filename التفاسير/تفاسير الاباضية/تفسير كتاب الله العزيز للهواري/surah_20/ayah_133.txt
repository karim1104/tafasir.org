قوله عز وجل :  {  وَقَالُوا لَوْلاَ } أي :  هلا {  يَأتِينَا بآيَةٍ مِّن رَّبِّهِ } قال الله عز وجل :  {  أَوَلَمْ تَأتِهِم بَيِّنَةُ مَا فِي الصُّحُفِ الأُولَى } أي :  في التوراة والإِنجيل .   كقوله عزّ وجلّ :  {  النَّبِيَّ الأُمِّيَّ الذِي يَجِدُونَهُ مَكْتُوباً عِندَهُمْ فِي التَّوْرَاةِ وَالإِنجِيلِ }[ الأعراف :  157 ] .
