قال :  {  أَفَرَأَيْتَ مَنِ اتَّخَذَ إِلَهَهُ هَوَاهُ } هو المشرك اتخذ إلهه هواه فعبد الأوثان من دون الله ،   وبعضهم يقرأها {  اتَّخَذَ ءَالِهَةً هَوَاهُ } قال :  {  وَأَضَلَّهُ اللَّهُ عَلَى عِلْمٍ وَخَتَمَ عَلَى سَمْعِهِ } أي :  بكفره فلا يسمع الهدى سمع قبول .   {  وَقَلْبِهِ } أي :  وختم على قلبه ،   أي :  فلا يفقه الهدى .   {  وَجَعَلَ عَلَى بَصَرِهِ غِشَاوَةً } فلا يبصر الهدى {  فَمَن يَهْدِيهِ مِن بَعْدِ اللَّهِ } أي :  لا أحد .   قال :  {  أَفَلاَ تَذَكَّرُونَ } يقوله للمشركين .  <br />
