قال :  {  ذَلِكَ بِأَنَّ الَّذِينَ كَفَرُوا اتَّبَعُوا الْبَاطِلَ } أي :  إبليس ،   اتبعوا وساوسه بالذي دعاهم إليه من عبادة الأوثان .   {  وَأَنَّ الَّذِينَ آمَنُوا اتَّبَعُوا الْحَقَّ مِن رَّبِّهِمْ } أي :  القرآن الذي جاء به محمد عليه السلام {  كَذَلِكَ يَضْرِبُ اللَّهُ لِلنَّاسِ } أي يبيّن للناس {  أَمْثَالَهُمْ } أي :  صفات أعمالهم .  <br />
