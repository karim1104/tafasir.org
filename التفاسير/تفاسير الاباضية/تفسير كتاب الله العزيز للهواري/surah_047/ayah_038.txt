قوله عز وجل :  {  هَاأَنتُمْ هَؤُلاَء تُدْعَوْنَ لِتُنفِقُوا فِي سَبِيلِ اللَّهِ فَمِنكُم مَّن يَبْخَلُ } أي :  بالنفقة في سبيل الله ،   يعني المنافق .   قال الله تعالى :  {  وَمَن يَبْخَلْ فَإِنَّمَا يَبْخَلُ عَن نَّفْسِهِ وَاللَّهُ الْغَنِيُّ } أي :  عنكم {  وَأَنتُمُ الْفُقَرَاء } إلى الله ،   يعني جماعة الناس .  <br />
{  وَإِن تَتَوَلَّوْا } عن الإيمان ،   يعني جماعة الناس في تفسير الحسن {  يَسْتَبْدِلْ قَوْمًا غَيْرَكُمْ } أي :  خيراً منكم ،   أي :  أطوع منكم ،   ويهلككم بالاستئصال .   كقوله : {  وَمَا نَحْنُ بِمَسْبُوقِينَ عَلَى أَن نُّبَدِّلَ أَمْثَالَكُمْ }[ الواقعة : 60-61 ] أي :  خيراً منكم ويهلككم بالعذاب .   قال الله تعالى :  {  ثُمَّ لاَ يَكُونُوا أَمْثَالَكُمْ } يقوله للمشركين ،   أي :  يكونوا خيراً منكم وأطوع له منكم .
