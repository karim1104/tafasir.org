قوله :  {  وَإِذَا مَسَّ الإِنسَانَ الضُّرُّ } يعني المرض .   والإِنسان ها هنا المشرك .   {  دَعَانَا لِجَنبِهِ } أي :  وهو مضطجع على جنبه {  أَوْ قَاعِداً } يقول :  أو دعانا قاعداً {  أَوْ قَائِماً } قال :  {  فَلَمَّا كَشَفْنَا عَنْهُ ضُرَّهُ مَرَّ كَأَن لَّمْ يَدْعُنَا إِلَى ضُرٍّ مَّسَّهُ } أي :  مَرَّ معرضاً عن الله عزّ وجلّ الذي كشف عنه الضر .   {  كَأَن لَّمْ يَدْعُنَا إِلَى ضُرٍّ مَّسَّهُ } ،   أي :  لنكشفه عنه .  <br />
{  كَذَلِكَ زُيِّنَ لِلْمُسْرِفِينَ } أي للمشركين {  مَا كَانُوا يَعْمَلُونَ } .  <br />
