قوله :  {  وَمَا كَانَ هَذَا القُرْءَانُ أَن يُفْتَرَى مِن دُونِ اللهِ } يقول :  لم يكن أحد يستطيع أن يفتريه فيأتي به من قِبَل نفسه {  وَلَكِن تَصْدِيقَ الَّذِي بَيْنَ يَدَيْهِ } أي :  من التوراة والإِنجيل {  وَتَفْصِيلَ الكِتَابِ } أي من الحلال والحرام والأحكام والوعد والوعيد .   {  لاَ رَيْبَ فِيهِ } أي :  لا شك فيه {  مِن رَّبِّ العَالَمِينَ } .  <br />
