قوله :  {  وَمَا تَكُونُ فِي شَأْنٍ } يعني النبي عليه السلام ،   أي :  في شأن من حوائجك في الدنيا {  وَمَا تَتْلُوا مِنْهُ مِن قُرْءَانٍ } يعني النبي عليه السلام {  وَلاَ تَعْمَلُونَ } يعني العامة {  مِنْ عَمَلٍ إِلاَّ كُنَّا عَلَيْكُمْ شُهُوداً } أي :  بذلك {  إِذْ تُفِيضُونَ فِيهِ } أي :  في ذلك العمل أجمع {  وَمَا يَعْزُبُ عَن رَّبِّكَ } أي :  وما يضل عن ربك ،   وبعضهم يقول :  وما يغيب عن ربك {  مِن مِّثْقَالِ ذَرَّةٍ } أي :  وزن ذرة{[1567]} .   {  فِي الأَرْضِ وَلاَ فِي السَّمَاءِ } أي :  حتى لا يعلمه ولا يعلم موضعه {  وَلاَ أَصْغَرَ مِن ذَلِكَ وَلاَ أَكْبَرَ إِلاَّ فِي كِتَابٍ مُّبِينٍ } أي :  بيّن عند الله .   يحذر الله العباد ويخبرهم أنه شاهد لأعمالهم .
