قوله :  {  أَمْ يَقُولُونَ افْتَرَاهُ } أي :  إن محمداً افتعل هذا القرآن ؛  على الاستفهام .   أي :  نعم ،   قد قالوا افتراه ،   أي :  افتعله .  <br />
قال الله :  {  قُلْ } يا محمد {  فَأْتُوا بِسُورَةٍ مِّثْلِهِ } أي مثل هذا القرآن {  وَادْعُوا مِنِ اسْتَطَعْتُم مِّن دُونِ اللهِ } حتى يشهدوا أنه مثل هذا القرآن{[1559]} {  إِن كُنتُمْ صَادِقِينَ } .   يقول :  إن كنتم صادقين فأتوا بسورة مثله ؛  أي :  إنكم لستم بصادقين ولا تأتون بسورة مثله .
