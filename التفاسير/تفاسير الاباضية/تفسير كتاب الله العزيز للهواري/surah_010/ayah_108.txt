قوله :  {  قُلْ يَا أَيُّهَا النَّاسُ قَدْ جَاءَكُمُ الحَقُّ مِن رَّبِّكُمْ } يعني القرآن {  فَمَنِ اهْتَدَى فَإِنَّمَا يَهْتَدِي لِنَفْسِهِ وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } أي :  على نفسه ،   كقوله :  {  مَّنْ عَمِلَ صَالِحاً فَلِنَفْسِهِ وَمَنْ أَسَاءَ فَعَلَيْهَا } [ سورة فصلت : 46 ] .  <br />
قوله :  {  وَمَا أَنَا عَلَيْكُمْ بِوَكِيلٍ } أي :  بحفيظ لأعمالكم حتى أجازيكم بها .   إنما أنا منذر أُبَلِّغُكُمْ رسالة ربي .
