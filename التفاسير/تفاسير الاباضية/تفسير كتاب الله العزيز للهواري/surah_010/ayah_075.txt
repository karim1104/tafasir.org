قوله :  {  ثُمَّ بَعَثْنَا مِن بَعْدِهِم مُّوسَى وَهَارُونَ إِلَى فِرْعَوْنَ وَمَلإِيْهِ } يعني :  قومه {  بِآيَاتِنَا } أي :  التسع الآيات :  يده وعصاه والطوفان والجراد والقمل والضفادع والدم ،   قال تعالى :  {  وَلَقَدْ أَخَذْنَا آلَ فِرْعَوْنَ بِالسِّنِينَ وَنَقْصٍ مِّنَ الثَّمَرَاتِ } [ الأعراف :  130 ] .   قال :  {  فَاسْتَكْبَرُوا } أي :  عن إجابة الرسل {  وَكَانُوا قَوْماً مُّجْرِمِينَ } أي :  مشركين .
