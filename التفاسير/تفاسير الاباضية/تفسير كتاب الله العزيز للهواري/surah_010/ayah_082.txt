{  وَيُحِقُّ اللهُ الحَقَّ } أي :  الذي جاء به موسى {  بِكَلِمَاتِهِ } أي :  بوعده الذي وعد موسى بقوله :  {  لاَ تَخَفْ إِنَّكَ أَنتَ الأَعْلَى } [ طه : 68 ] أي :  إنك أنت الظاهر الظافر .   {  وَلَوْ كَرِهَ المُجْرِمُونَ } أي :  المشركون .   أي :  إن فرعون وقومه كانوا يكرهون الحق ،   وأن يظهر عليهم موسى وهارون فيظهر دينهما ،   ويغرق آل فرعون وهم ينظرون .
