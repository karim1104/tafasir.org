قوله :  {  قَالُوا اتَّخَذَ اللهُ وَلَداً } يعني مشركي العرب .   وذلك أنهم قالوا :  إن الملائكة بنات الله {  سُبْحَانَهُ } ينزّه نفسه عن ذلك {  هُوَ الغَنِيُّ } أي :  عن الولد {  لَهُ مَا فِي السَّمَاوَاتِ وَمَا فِي الأَرْضِ } .   ثم قال :  {  إِنَّ عِندَكُم مِّن سُلْطَانٍ بِهَذَا } أي :  ما عندكم من حجة بهذا الذي قلتم {  أَتَقُولُونَ عَلَى اللهِ مَا لاَ تَعْلَمُونَ } أي :  نعم قد قلتم على الله ما لا تعلمون .  <br />
