ثم احتجّ عليهم أيضاً فقال :  {  هُوَ الَّذِي جَعَلَ الشَّمْسَ ضِيَاءً وَالقَمَرَ نُوراً وَقَدَّرَهُ مَنَازِلَ } يعني القمر {  لِتَعْلَمُوا عَدَدَ السِّنِينَ وَالحِسَابَ } بالليل والنهار .  <br />
{  مَا خَلَقَ اللهُ ذَلِكَ إِلاَّ بِالْحَقِّ } أي :  إن ذلك يصير إلى الحق والمعاد{[1540]} .   ثم قال :  {  يُفَصِّلُ الآيَاتِ } أي :  نبِيّنها {  لِقَوْمٍ يَعْلَمُونَ } وهم المؤمنون .
