قوله :  {  وَيَقُولُونَ مَتَى هَذَا الوَعْدُ إِن كُنتُمْ صَادِقِينَ } يقوله المشركون لما كان يعدهم به النبي عليه السلام من عذاب الله إن لم يؤمنوا ؛  فكانوا يستعجلونه بالعذاب استهزاءً وتكذيباً .   أي :  إنه لا يأتيهم العذاب ،   ويقولون :  متى هذا الوعد ،   و{  ائْتِنَا بِعَذَابِ اللهِ إِن كُنتَ مِنَ الصَّادِقِينَ } [ العنكبوت : 29 ] .  <br />
قال الله لمحمد عليه السلام :  {  قُلْ إِنِّي عَلَى بَيِّنَةٍ مِّن رَّبِّي } أي :  النبوة {  وَكَذَّبْتُم بِهِ } أي :  بالقرآن {  مَا عِندِي مَا تَسْتَعْجِلُونَ بِهِ } أي :  من عذاب الله {  إِنِ الحُكْمُ إِلاَّ لِلَّهِ } أي :  إنِ القَضَاءُ {  إِلاَّ لِلَّهِ } أي :  إنما ذلك إلى الله {  يَقُصُّ الحَقَّ وَهُوَ خَيْرُ الفَاصِلِينَ } [ الأنعام : 57 ] أي القاضين .
