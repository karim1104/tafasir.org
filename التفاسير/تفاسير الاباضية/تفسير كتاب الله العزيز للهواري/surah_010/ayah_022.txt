قوله :  {  هُوَ الَّذِي يُسَيِّرُكُمْ فِي البَرِّ وَالبَحْرِ حَتَّى إِذَا كُنتُمْ فِي الفُلْكِ } أي :  في السفن .   [ يقول هذا للمشركين ،   ثم قال للنبي عليه السلام ]{[1551]} {  وَجَرَيْنَ بِهِم بِرِيحٍ طَيِّبَةٍ } للمسير {  وَفَرِحُوا بِهَا جَاءَتْهَا رِيحٌ عَاصِفٌ } أي شديدة {  وَجَاءَهُمُ المَوْجُ مِن كُلِّ مَكَانٍ وَظَنُّوا أَنَّهُمْ أُحِيطَ بِهِمْ } أي :  أنهم مغرقون {  دَعَوُا اللهَ مُخْلِصِينَ لَهُ الدِّينَ لَئِنْ أَنجَيْتَنَا مِنْ هَذِهِ } أي من هذه الشّدّة {  لَنَكُونَنَّ مِنَ الشَّاكِرِينَ } .   أي :  من المؤمنين .
