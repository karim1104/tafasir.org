ثم استثنى من الناس فقال :  {  إِلاَّ الَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ وَتَوَاصَوْاْ بِالْحَقِّ } أي :  بالتوحيد {  وَتَوَاصَوْاْ بِالصَّبْرِ } أي :  على الفرائض .   وبعضهم يقول :  {  بِالْحَقِّ } أي :  بالله {  إِلاَّ الَّذِينَ آمَنُواْ } فإنهم ليسوا في خسر من الجنة ،   وهم أهل الجنة .  <br />
