قوله :  {  وَكَذَلِكَ أَنزَلْنَاهُ حُكْماً عَرَبِيّاً } يعني القرآن{[1812]} {  وَلَئِنِ اتَّبَعْتَ أَهْوَاءَهُم } أي :  أهواء المشركين حتى لا تبلغ عن الله الرسالة {  بَعْدَ مَا جَاءَكَ مِنَ الْعِلْمِ } قال :  {  مَالَكَ مِنَ اللهِ مِن وَلِيٍّ } أي :  يتولى دفع العذاب عنك {  وَلاَ وَاقٍ } أي :  يقيك عذابه إن فعلت ،   ولست فاعلاً .
