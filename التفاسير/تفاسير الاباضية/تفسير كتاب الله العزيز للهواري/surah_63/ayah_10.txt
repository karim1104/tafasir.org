قال عز وجل :  {  وَأَنفِقُوا مِن مَّا رَزَقْنَاكُم } يعني الزكاة المفروضة ،   وهي قصة المنافقين ،   كقوله عز وجل :  {  وَلاَ يَأْتُونَ الصَّلاَةَ إِلاَّ وَهُمْ كُسَالَى وَلاَ يُنفِقُونَ إِلاَّ وَهُمْ كَارِهُونَ } [ التوبة : 54 ] وكقوله عز وجل :  {  فَوَيْلٌ لِّلْمُصَلِّينَ الَّذِينَ هُمْ عَن صَلاَتِهِمْ سَاهُونَ الَّذِينَ هُمْ يُرَآءُونَ وَيَمْنَعُونَ الْمَاعُونَ } [ الماعون :  4-7 ] يعني الزكاة .   قال عز وجل :  {  مِّن قَبْلِ أَن يَأْتِيَ أَحَدَكُمُ الْمَوْتُ فَيَقُولَ رَبِّ لَوْلآ } أي :  هلا {  أَخَّرْتَنِي إلَى أَجَلٍ قَرِيبٍ } وهو الموت ،   قريب ،   وإِنَّ عمر العبد قليل .   قال :  {  فَأَصَّدَّقَ } أي فأزكى {  وَأَكُن مِّنَ الصَّالِحِينَ } أي :  فأحجّ ،   ومثلها في سورة المؤمنون قوله عز وجل :  {  حَتَّى إِذَا جَآءَ أَحَدَهُمُ الْمَوْتُ قَالَ رَبِّ ارْجِعُونِ } أي إلى الدنيا {  لَعَلِّي أَعْمَلُ صَالِحاً فِيمَا تَرَكْتُ }
