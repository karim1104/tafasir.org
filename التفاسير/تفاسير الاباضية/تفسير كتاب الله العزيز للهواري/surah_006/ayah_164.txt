قوله :  {  قُلْ أَغَيْرَ اللهِ أَبْغِي رَبّاً وَهُوَ رَبُّ كُلِّ شَيْءٍ } [ وهذا جواب من الله للمشركين حيث دعوا النبي إلى أن يعبد ما كان يعبد آباؤهم ]{[1141]} {  وَلاَ تَكْسِبُ كُلُّ نَفْسٍ إِلاَّ عَلَيْهَا } أي على نفسها {  وَلاَ تَزِرُ } أي :  ولا تحمل {  وَازِرَةٌ وِزْرَ أُخْرَى } والوزر :  الذنب .   أي لا يحمل أحد ذنب أحد .   {  ثُمَّ إِلَى رَبِّكُم مَّرْجِعُكُمْ فَيُنَبِّئُكُم بِمَا كُنتُمْ فِيهِ تَخْتَلِفُونَ } أي ما اختلف فيه المؤمنون والمشركون فيدخل المؤمنين الجنة ويدخل المشركين النار .
