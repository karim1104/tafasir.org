قوله :  {  وَمَا الْحَيَاةُ الدُّنْيَا إِلاَّ لَعِبٌ وَلَهْوٌ } [ أي إن أهل الدنيا أهل لعب ولهو ]{[1030]} كقوله :  {  إِنَّ الَّذِينَ لاَ يَرْجُونَ لِقَاءَنَا وَرَضُوا بِالحَياةِ الدُّنْيَا وَاطْمَأَنُّوا بِهَا } [ يونس : 7 ] ذكر الحسن قال :  قال رسول الله صلى الله عليه وسلم :   "  الدنيا سجن المؤمن وجنة الكافر {[1031]}قال :  {  وَلَلدَّارُ الآخِرَةُ خَيْرٌ لِّلَّذِينَ يَتَّقُونَ أَفَلاَ تَعْقِلُونَ } .
