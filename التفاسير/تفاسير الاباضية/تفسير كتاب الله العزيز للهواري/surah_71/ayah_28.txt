قال نوح :  {  رَّبِّ اغْفِرْ لِي وَلِوَالِدَيَّ } .   قال الحسن :  كانا مؤمنين {  وَلِمَن دَخَلَ بَيْتِيَ مُؤْمِناً } قال بعضهم :  ( مَنْ دَخَلَ بَيْتِي ) يعني مسجدي ( مُؤمِناً ) {  وَلِلْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ وَلاَ تَزِدِ الظَّالِمِينَ إِلاَّ تَبَاراً } أي :  إلا هلاكاً .   وذلك حين أمر بالدعاء عليهم فاستجاب الله له فأغرقهم .  <br />
