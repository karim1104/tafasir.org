قوله :  {  إِنَّ الَّذِينَ ءَامَنُوا وَالَّذِينَ هَادُوا } أي تهوّدوا {  وَالصَّابِئُونَ } وقد فسّرنا أمرهم في سورة البقرة{[949]} {  وَالنَّصَارَى } أي :  والذين تنصروا {  مَنْ ءَامَنَ بِاللهِ وَالْيَوْمِ الآخِرِ وَعَمِلَ صَالِحاً } يعني من آمن منهم بمحمد ودخل بيته وشريعته وحكمه .   {  فَلاَ خَوْفٌ عَلَيْهِمْ وَلاَ هُمْ يَحْزَنُونَ } .
