قوله :  {  قُل لِّعِبَادِيَ الَّذِينَ آمَنُوا يُقِيمُوا الصَّلاَةَ } أي :  الصلوات الخمس ،   يحافظون على وضوئها ومواقيتها وركوعها وسجودها {  وَيُنفِقُوا مِمَّا رَزَقْنَاهُمْ سِرّاً وَعَلاَنِيَةً } أي :  الزكاة الواجبة {  مِّن قَبْلِ أَن يَّأْتِيَ يَوْمٌ } أي :  يوم القيامة {  لاَّ بَيْعٌ فِيهِ } أي :  لا يتبايعون فيه {  وَلاَ خِلاَلٌ } أي :  تنقطع كل خلّة إلا خلّة المتقين .   كقوله :  {  الأَخِلاَّءُ يَوْمَئِذٍ بَعْضُهُمْ لِبَعْضٍ عَدُوٌّ إِلاَّ المُتَّقِينَ } [ الزخرف : 67 ] ،   وكقوله :  {  لاَّ بَيْعٌ فِيهِ وَلاَ خُلَّةٌ وَلاَ شَفَاعَةٌ } [ البقرة : 254 ] .
