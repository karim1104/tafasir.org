قوله :  {  أَلَمْ تَرَ أَنَّ اللهَ خَلَقَ السَّمَاوَاتِ وَالأَرْضَ بِالْحَقِّ } أي :  يصير الأمر إلى البعث والحساب والجنة والنار .   كقوله :  {  وَمَا خَلَقْنَا السَّمَاءَ وَالأَرْضَ وَمَا بَيْنَهُمَا بَاطِلاً ذَلِكَ ظَنُّ الَّذِينَ كَفَرُوا } أي :  ألا بعث ولا حساب ،   ولا جنة ولا نار .   {  فَوَيْلٌ لِّلَّذِينَ كَفَرُوا مِنَ النَّارِ } [ سورة ص : 27 ] .  <br />
قوله :  {  إِن يَشَأْ يُذْهِبْكُمْ } أي :  يهلككم بعذاب فيستأصلكم {  وَيَأْتِ بِخَلْقٍ جَدِيدٍ } أي :  آخرين .
