{  وَلَوْ شَاءَ اللهُ لَجَعَلَكُمْ أُمَّةً وَاحِدَةً } ،   أي :  على الإيمان .   وهو كقوله :  {  وَلَوْ شِئْنَا لآتَيْنَا كُلَّ نَفْسٍ هُدَاها }{[1944]} [ السجدة : 13 ] .   وكقوله :  {  وَلَوْ شَاءَ رَبُّكَ لآمَنَ مَن فِي الأَرْضِ كُلُّهُمْ جَمِيعاً } [ يونس : 99 ] ،   {  وَلَكِن يُضِلُّ مَن يَشَاءُ } ،   أي :  بفعله ،   {  وَيَهْدِي مَن يَشَاءُ وَلَتُسْئَلُنَّ عَمَّا كُنتُمْ تَعْمَلُونَ } .
