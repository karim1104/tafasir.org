قوله :  {  وَلَقَدْ بَعَثْنَا فِي كُلِّ أُمَّةٍ رَّسُولاً } يعني ممن أهلك بالعذاب {  أَنِ اعْبُدُوا اللهَ وَاجْتَنِبُوا الطَّاغُوتَ } والطاغوت الشيطان ،   هو دعاهم إلى عبادة الأوثان وهو مثل قوله :  {  إِن يَّدْعُونَ مِن دُونِهِ إِلاَّ إِنَاثاً وَإِن يَدْعُونَ إِلاَّ شَيْطَاناً مَّرِيداً } [ النساء : 117 ] .   قال :  {  فَمِنْهُم مَّنْ هَدَى اللهُ وَمِنْهُم مَّنْ حَقَّتْ عَلَيْهِ الضَّلاَلَةُ } كقوله :  {  فَمِنْهُمْ شَقِيٌّ وَسَعِيدٌ } [ هود : 105 ] .   والذين حقّت عليهم الضلالة والذين شقوا إنما ضلوا وشقوا بأعمالهم .  <br />
قال :  {  فَسِيرُوا في الأَرْضِ فَانظُرُوا كَيْفَ كَانَ عَاقِبَةُ المُكَذِّبِينَ } أي :  الرسل .   كان عاقبتهم أن دمّر الله عليهم ثم صيّرهم إلى النار .
