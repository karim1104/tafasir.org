قوله :  {  وَهُوَ الَّذِي سَخَّر البَحْرَ } أي :  خلق البحر {  لِتَأْكُلُوا مِنْهُ لَحْماً طَرِيّاً } أي :  الحيتان {  وَتَسْتَخْرِجُوا مِنْهُ حِلْيَةً تَلْبَسُونَهَا } أي :  اللؤلؤ .   {  وَتَرَى الفُلْكَ } أي :  السفن {  مَوَاخِرَ فِيهِ } يعني شقها الماء في وقت جريها{[1901]} .  <br />
وقال بعضهم :  {  مَوَاخِرَ فِيهِ } أي :  سفن البحر مقبلة مدبرة تجري فيه بريح واحدة .   وقال مجاهد :  ولا تُجري الريح من السفن إلا العظام {  وَلِتَبْتَغُوا مِن فَضْلِهِ } يعني طلب التجارة في البحر .   {  وَلَعَلَّكُمْ تَشْكُرُونَ } أي :  لكي تشكروا .   وهو مثل قوله : <br />
{  لَعَلَّكُمْ تُسْلِمُونَ } [ النحل : 81 ] .
