قوله :  {  وَمِنْ آيَاتِهِ الْجَوَارِ } أي :  السفن ،   كقوله :  {  وَالْفُلْكَ تَجْرِي فِي الْبَحْرِ بِأَمْرِهِ }<br />
[ الحج : 65 ] قال :  {  فِي الْبَحْرِ كَالأَعْلَامِ } أي :  كالجبال ،   وهي كقوله :  {  وَلَهُ الْجَوَارِ الْمُنشَآتُ فِي الْبَحْرِ كَالأَعْلَامِ } [ الرحمن : 24 ] ،   وهي السفن إذا كان عليها قلوعها .
