قوله :  {  وَكَذَلِكَ أَوْحَيْنَا إِلَيْكَ قُرْآنًا عَرَبِيًّا لِّتُنذِرَ أُمَّ الْقُرَى } أي :  مكة ،   ومنها دحيت الأرض {  وَمَنْ حَوْلَهَا } يعني الآفاق كلها .   {  وَتُنذِرَ يَوْمَ الْجَمْعِ } أي :  يوم القيامة{[3326]} .   يجتمع فيه الخلائق ،   أهل السماوات وأهل الأرض {  لاَ رَيْبَ فِيهِ } أي :  لا شك فيه أنه آت .   {  فَرِيقٌ فِي الْجَنَّةِ وَفَرِيقٌ فِي السَّعِيرِ } أي :  في النار .
