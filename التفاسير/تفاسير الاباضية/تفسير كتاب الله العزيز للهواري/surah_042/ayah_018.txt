قال :  {  يَسْتَعْجِلُ بِهَا الَّذِينَ لاَ يُؤْمِنُونَ بِهَا } أي :  استهزاءً وتكذيباً لا يقرّون بها {  وَالَّذِينَ آمَنُوا مُشْفِقُونَ مِنْهَا } أي :  خائفون {  وَيَعْلَمُونَ أَنَّهَا الْحَقُّ } أي :  كائنة {  أَلاَ إِنَّ الَّذِينَ يُمَارُونَ فِي السَّاعَةِ } أي :  يكذبون بها .   كقوله :  {  وَلَقَدْ أَنذَرَهُم بَطْشَتَنَا فَتَمَارَوْا بِالنُّذُرِ } [ القمر : 36 ] أي :  كذّبوا الأنبياء .   قال :  {  لَفِي ضَلاَلٍ بَعِيدٍ } أي :  من الحق .
