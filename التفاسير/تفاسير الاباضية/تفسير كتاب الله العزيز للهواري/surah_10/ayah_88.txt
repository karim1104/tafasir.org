قوله :  {  وَقَالَ مُوسَى رَبَّنَا إِنَّكَ ءَاتَيْتَ فِرْعَوْنَ وَمَلأَهُ زِينَةً } أي :  زينة الدنيا {  وَأَمْوَالاً فِي الحَيَاةِ الدُّنْيَا رَبَّنَا لِيَضِلُّوا عَنْ سَبِيلِكَ } وهذا دعاء ،   أي :  يا ربَّنَا فأضلهم عن سبيلك ،   وهذا حين جاء وقت عذابهم وأمرهم بالدعاء عليهم .   {  رَبَّنَا } أي :  يا ربنا {  اطْمِسْ عَلَى أَمْوَالِهِمْ } فمسخت دنانيرهم ودراهمهم وزروعهم حجارة .   ذكر لنا أن زروعهم تحولت حجارة .   {  وَاشْدُدْ عَلَى قُلُوبِهِمْ } أي :  بالضلالة التي كانت منهم {  فَلاَ يُؤْمِنُوا } أي :  فَحِيل{[1577]} بينهم وبين أن يؤمنوا بفعلهم في تفسير الحسن .   وقد فعل .   {  حَتَّى يَرَوُا العَذَابَ الأَلِيمَ } أي :  الموجع .
