قوله :  {  وَلَوْ أَنَّ لِكُلِّ نَفْسٍ ظَلَمَتْ } أي :  أشركت فظلمت بذلك نفسها {  مَا فِي الأَرْضِ لاَفْتَدَتْ بِهِ } أي :  لو أن لها ما في الأرض من ذهب أو فضة لافتدت به يوم القيامة من عذاب الله {  وَأَسَرُّوا النَّدَامَةَ لَمَّا رَأَوُا العَذَابَ } أي :  أسروا الندامة في أنفسهم لما دخلوا العذاب {  وَقُضِيَ بَيْنَهُم بِالْقِسْطِ } أي :  بالعدل {  وَهُمْ لاَ يُظْلَمُونَ } .  <br />
