قوله :  {  وَاتْلُ عَلَيْهِمْ نَبَأَ نُوحٍ } أي :  خبر نوح {  إِذْ قَالَ لِقَوْمِهِ يَا قَوْمِ إِن كَانَ كَبُرَ عَلَيْكُم } أي :  عظم عليكم {  مَّقَامِي } أي :  بالدعاء إلى الله عزّ وجلّ {  وَتَذْكِيرِي بِآيَاتِ اللهِ فَعَلَى اللهِ تَوَكَّلْتُ فَأَجْمِعُوا أَمْرَكُمْ وَشُرَكَاءَكُمْ } [ أي :  وأجمعوا شركاءكم ]{[1570]} .  <br />
وقال بعضهم :  وليجمع أوثانكم أيضاً أمرهم{[1571]} .   قال الحسن ومجاهد :  ما في أنفسكم وكيدكم .   والعامة على الوجه الأول :  فأجمعوا أمركم وشركاءَكم ،   أي :  واجمعوا شركاءَكم .  <br />
{  ثُمَّ لاَ يَكُنْ أَمْرُكُمْ عَلَيْكُمْ غُمَّةً } أي :  في ستر وشبهة ،   أي :  ليكن ذلك علانية .  <br />
قال :  {  ثُمَّ اقْضُوا ،   إِلَيَّ } أي :  اجهدوا عليَّ جهدَكم {  وَلاَ تُنظِرُونِ } ،   أي :  طرفة عين .   أي :  إنكم لا تقدرون على ذلك .   وذلك حين قالوا :  {  لَئِن لَّمْ تَنتَهِ يَا نُوحُ لَتَكُونَنَّ مِنَ المَرْجُومِينَ } [ الشعراء : 116 ] .   وهو كقوله :  {  فَكَذَّبُوا عَبْدَنَا وَقَالُوا مَجْنُونٌ وَازْدُجِرَ } [ القمر : 9 ] أي :  ويهدد بالقتل .
