قوله عز وجل : {  لاَّ تَجِدُ قَوْماً يُؤْمِنُونَ بِاللهِ وَالْيَوْمِ الآخِرِ يُوَآدُّونَ } أي يحبون ،   من المودة والمحبة {  مَنْ حَآدَّ } أي من عادى{  اللهَ وَرَسُولَهُ وَلَوْ كَانُواْ آبَآءَهُمْ أَوْ أَبْنَآءَهُمْ أَوْ إِخْوَانَهُمْ أَوْ عَشِيرَتَهُمْ } .  <br />
تفسير الحسن :  إنهم المنافقون يوادون المشركين .  <br />
وتفسير الكلبي :  إن هذا نزل في أمر حاطب بن أبي بلتعة حيث كتب إلى أهل مكة ينذرهم خروج النبي عليه السلام إليهم{[3860]} ؛  وتفسيره في سورة الممتحنة{[3861]} .  <br />
قال تعالى :  {  أُوْلَئِكَ كَتَبَ } أي :  جعل {  فِي قُلُوبِهِمُ الإِيمَانَ } وهم المؤمنون الذين لا يوادون المشركين .   قال تعالى : {  وَيُدْخِلُهُمْ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا الأَنْهَارُ خَالِدِينَ فِيهَا } وقد فسّرنا أمرها في غير هذا الموضع .  <br />
قال :  {  رَضِيَ اللهُ عَنْهُمْ } أي :  بأعمالهم {  وَرَضُواْ عَنْهُ } أي :  بثوابه إياهم .   {  أُوْلَئِكَ حِزْبُ اللهِ } أي :  جند الله {  أَلآ إِنَّ حِزبَ اللهِ } أي جند الله {  هُمُ المُفْلِحُونَ } أي :  السعداء ،   وهم أهل الجنة ،   صاروا إلى دار القرار ،   ودار السعادة ،   ودار الخلود ؛  فطوبى لهم .
