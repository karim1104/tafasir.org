قوله :  {  أَمْوَاتٌ غَيْرُ أَحْيَاءٍ } أي :  الأوثان أموات لا أرواح فيها {  وَمَا يَشْعُرُونَ أَيَّانَ يُبْعَثُونَ } .  <br />
قال بعضهم :  تحشر الأوثان بأعيانها فتخاصم عابديها عند الله بأنها لم تدعهم إلى عبادتها ،   وإنما كان دعاهم إلى عبادتها الشيطان .   قال الله :  {  إِن يَدْعُونَ مِن دُونِهِ إِلاَّ إِنَاثاً } أي :  أمواتاً لا أرواح فيها {  وَإن يَدْعُونَ إِلاَّ شَيْطَاناً مَّرِيداً } [ النساء : 117 ] .
