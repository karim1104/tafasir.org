قوله :  {  وَاللهُ يَعْلَمُ مَا تُسِرُّونَ } أي :  ما يسر المشركون من نجواهم في أمر النبي ،   أي :  ما يتشاورون في أمره ،   مثل قوله :  {  وَأَسَرُّوا النَّجْوَى الَّذِينَ ظَلَمُوا } أي :  الذين أشركوا {  هَلْ هَذَا } يعنون محمداً {  إِلآَّ بَشَرٌ مِّثْلُكُمْ أَفَتَأْتُونَ السِّحْرَ وَأَنتُمْ تُبْصِرُونَ } [ الأنبياء : 3 ] أي :  أنه سحر .   يعنون القرآن .   قال الله {  وَمَا تُعْلِنُونَ } أي :  من شركهم وجحودهم .
