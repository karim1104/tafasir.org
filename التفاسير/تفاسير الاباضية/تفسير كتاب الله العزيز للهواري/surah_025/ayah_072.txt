قوله :  {  وَالذِينَ لاَ يَشْهَدُونَ الزُّورَ } والزور الشرك والنفاق والعمل السيئ [ وقال بعضهم :  {  لاَ يَشْهَدُونَ الزُّورَ } :  أي :  لا يحضرون مجالس الكذب والباطل ]{[2685]} قوله :  {  وَإِذَا مَرُّوا بِاللَّغْوِ } أي :  بالباطل {  مَرُّوا كِرَاماً } أي :  ليسوا من أهله .   [ وقال بعضهم :  {  لاَ يَشْهَدُونَ الزُّورَ وَإِذَا مَرُّوا بِاللَّغْوِ مَرُّوا كِرَاماً } أي :  لا يشهدون أهل الباطل على باطلهم ولا يمالئونهم فيه ]{[2686]} .
