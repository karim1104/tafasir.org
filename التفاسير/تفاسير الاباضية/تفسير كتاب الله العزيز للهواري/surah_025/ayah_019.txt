قال الله لهم في الآخرة :  {  فَقَدْ كَذَّبُوكُم بِمَا تَقُولُونَ } قال الحسن :  يقول للمشركين :  {  فَقَدْ كَذَّبُوكُمْ بِمَا تَقُولُونَ } أي :  إنهم آلهة .  <br />
وفي تفسير مجاهد قال :  يكذبون المشركين بقولهم ،   إذ جعلوهم آلهة ،   فانتفوا من ذلك ونزّهوا الله عنه .   وبعضهم يقرأها :  {  بِمَا يَقُولُونَ } يعني قول الملائكة في قول الحسن ،   وفي قول مجاهد :  الملائكة وعيسى وعزير .  <br />
قال :  {  فَمَا تَسْتَطِيعُونَ صَرْفاً وَلاَ نَصْراً } قال الحسن :  فما يستطيع الذين عبدوهم لهم {  صَرْفاً } ،   أي :  أن يصرفوا عنهم العذاب ،   {  وَلاَ نَصْراً } أي :  ولا ينصرونهم .  <br />
قوله :  {  وَمَن يَظْلِم مِّنكُمْ } أي :  ومن يشرك منكم وينافق {  نُذِقْهُ } أي :  نعذّبه {  عَذَاباً كَبِيراً } كقوله : <br />
{  إِلاَّ مَن تَوَلَّى وَكَفَرَ فَيُعَذِّبُهُ اللهُ العَذَابَ الأَكْبَرَ } [ الغاشية :  23-24 ] .
