قال :  {  قُلْ يَا عِبَادِيَ الَّذِينَ أَسْرَفُوا عَلَى أَنفُسِهِمْ } بالشرك والكبائر الموبقة .   {  لاَ تَقْنَطُوا } أي :  لا تيأسوا {  مِن رَّحْمَةِ اللَّهِ إِنَّ اللَّهَ يَغْفِرُ الذُّنُوبَ جَمِيعًا } على التوبة {  إِنَّهُ هُوَ الْغَفُورُ الرَّحِيمُ } .  <br />
ذكروا عن الحسن أنه قال :  لما نزل في قاتل المؤمن وفي السارق والزاني وغير ذلك ما نزل تخوَّف قوم أن يؤاخذوا بما عملوا في الجاهلية فقالوا :  أينا لم يفعل ،   فأنزل الله :  {  قُلْ يَا عِبَادِيَ الَّذِينَ أَسْرَفُوا عَلَى أَنفُسِهِمْ لاَ تَقْنَطُوا مِن رَّحْمَةِ اللَّهِ إِنَّ اللَّهَ يَغْفِرُ الذُّنُوبَ جَمِيعًا } أي :  لمن تاب وآمن وعمل صالحاً{[3207]} ،   {  إِنَّهُ هُوَ الْغَفُورُ الرَّحِيمُ } وأنزل<br />
{  وَالَّذِينَ لاَ يَدْعُونَ مَعَ اللهِ إِلهاً ءَاخَرَ وَلاَ يَقْتُلُونَ النَّفْسَ الَّتِي حَرَّمَ اللهُ إِلاَّ بِالْحَقِّ وَلاَ يَزْنُونَ .   .   .   }<br />
إلى قوله :  {  إِلاَّ مَن تَابَ وَءَامَنَ وَعَمِلَ صَالِحاً فَأُولَئِكَ يُبَدِّلُ اللهُ سَيِّئَاتِهِمْ حَسَنَاتٍ وَكَانَ اللهُ غَفُوراً رَّحِيماً }<br />
[ الفرقان : 68-70 ] أي :  لمن تاب إليه إذ جعل له بعد ذنوبه متاباً ومرجعاً{[3208]} .
