قوله :  {  وَلَوْ أَنَّ لِلَّذِينَ ظَلَمُوا مَا فِي الْأَرْضِ جَمِيعًا } أي :  من الذهب والفضة {  وَمِثْلَهُ مَعَهُ لاَفْتَدَوْا بِهِ مِن سُوءِ الْعَذَابِ } أي :  من شدة العذاب {  يَوْمَ الْقِيَامَةِ } لم يقبل منهم {  وَبَدَا لَهُم مِّنَ اللَّهِ مَا لَمْ يَكُونُوا يَحْتَسِبُونَ } أي :  لم يكونوا يحتسبون أنهم مبعوثون ومعذبون .  <br />
