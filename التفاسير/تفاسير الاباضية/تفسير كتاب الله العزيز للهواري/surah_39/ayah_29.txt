قوله :  {  ضَرَبَ اللهُ مَثَلاً رَّجُلاً } أي :  المشرك {  فِيهِ شُرَكَآءُ مُتَشَاكِسُونَ } أي :  يعبد أوثاناً شتى .   وهو مثل قول يوسف :  {  ءَارْبَابٌ مُّتَفَرِّقُونَ خَيْرٌ أَمِ اللهُ الْوَاحِدُ القَهَّارُ } [ يوسف : 39 ] {  وَرَجُلاً سَلَماً لِّرَجُلٍ } يعني المؤمن الذي يعبد الله وحده {  هَلْ يَسْتَوِيَانِ مَثَلاً } أي :  إنهما لا يستويان .   قال :  {  الْحَمْدُ لِلَّهِ بَلْ أَكْثَرُهُمْ لاَ يَعْلَمُونَ } وهم الذين لا يؤمنون .
