قوله :  {  وَمِنَ النَّاسِ مَن يَعْبُدُ اللهَ عَلَى حَرْفٍ } أي :  على شك{[2394]} {  فَإِنْ أَصَابَهُ خَيْرٌ اِطْمَأَنَّ بِهِ } [ يقول رضي به ]{[2395]} {  وَإِنْ أَصَابَتْهُ فِتْنَةٌ انقَلَبَ عَلَى وَجْهِهِ } هذا المنافق إذا رأى في الإِسلام رخاء وطمأنينة طابت نفسه لما يصيبه من ذلك الرخاء ،   وقال :  أنا منكم ومعكم ،   وإذا رأى في الإِسلام شدة أو بلية لم يصبر على بليتها ،   ولم يَرْجُ عاقبتها ،   {  انْقَلَبَ عَلَى وَجْهِهِ } أي :  كافراً .   قال الله :  {  خَسِرَ الدُّنْيَا } أي :  ذهبت عنه وزالت {  والآخرة } أي :  وخسر الآخرة فلم يكن له فيها نصيب{[2396]} .   قال الله :  {  ذَلِكَ هُوَ الخُسْرَانُ المُبِينُ }
