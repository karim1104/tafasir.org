قوله :  {  وَلِكُلِّ أُمَّةٍ جَعَلْنَا مَنسَكاً } أي :  حجاً وذبحاً {  لِّيَذْكُرُوا اسْمَ اللهِ عَلَى مَا رَزَقَهُم مِّنْ بَهِيمَةِ الأَنْعَامِ } وقد فسّرناه في الآية الأولى{[2428]} .  <br />
قوله :  {  فَإِلهُكُمْ إلهٌ وَاحِدٌ فَلَهُ أَسْلِمُوا } يقوله للمشركين .   قوله :  {  وَبَشِّرِ المُخْبِتِينَ } تفسير الحسن أن المخبتين هم الخاشعون .   والخشوع المخافة الثابتة في القلب .   وقال بعضهم :  المخبتون المطمئنون بالإِيمان كقوله :  {  فَتُخْبِتَ لَهُ قُلُوبُهُمْ }<br />
[ الحج :  54 ] أي :  خافت قلوبهم ،   أي :  فتطمئن قلوبهم .   وقال :  {  الذِينَ آمنوا وَتَطْمَئِنُّ قُلُوبُهُم بِذِكْرِ اللهِ } [ الرعد :  28 ]
