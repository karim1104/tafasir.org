قوله :  {  وَلِيَعْلَمَ الذِينَ أُوتُوا العِلْمَ } يعني المؤمنين {  أَنَّهُ الحَقُّ مِن رَّبِّكَ } أي :  القرآن {  فَيُؤمِنُوا بِهِ } أي :  فيصدّقوا به {  فَتُخْبِتَ لَهُ قُلُوبُهُمْ } أي :  فتطمئن له قلوبهم ،   في قول الكلبي .   وقال الحسن :  فتخشع له قلوبهم .   قوله :  {  وَإِنَّ اللهَ لَهَادِ الذِينَ آمنوا إِلَى صِرَاطٍ مُّسْتَقِيمٍ } أي :  الجنة .  <br />
