{  هُوَ الَّذِي خَلَقَكُم مِّن تُرَابٍ } يعني خلق آدم {  ثُمَّ مِن نُّطْفَةٍ } يعني نسل آدم {  ثُمَّ مِنْ عَلَقَةٍ ثُمَّ يُخْرِجُكُمْ طِفْلاً ثُمَّ لِتَبْلُغُوا أَشُدَّكُمْ } أي :  الاحتلام {  ثُمَّ لِتَكُونُوا شُيُوخًا } يعني من يبلغ حتى يكون شيخاً {  وَمِنكُم مَّن يُتَوَفَّى مِن قَبْلُ } أي :  من قبل أن يكون شيخاً {  وَلِتَبْلُغُوا أَجَلاً مُّسَمًّى } أي الموت {  وَلَعَلَّكُمْ تَعْقِلُونَ } أي :  لكي تعقلوا .  <br />
