{  الَّذِينَ يَحْمِلُونَ الْعَرْشَ وَمَنْ حَوْلَهُ } أي :  ومن حول العرش {  يُسَبِّحُونَ بِحَمْدِ رَبِّهِمْ وَيُؤْمِنُونَ بِهِ } .   ذكر بعضهم قال :  قال الله لآدم :  يا آدم أهبط بيتي معك يطاف حوله كما يطاف على العرش .  <br />
قال :  {  وَيَسْتَغْفِرُونَ لِلَّذِينَ آمَنُوا } يقولون {  رَبَّنَا وَسِعْتَ كُلَّ شَيْءٍ رَّحْمَةً وَعِلْمًا } أي :  ملأت كل شيء رحمة وعلماً {  فَاغْفِرْ لِلَّذِينَ تَابُوا } من الشرك والنفاق وأعمال السيئات {  وَاتَّبَعُوا سَبِيلَكَ } أي :  الهدى ،   يعني الإِسلام ،   وهو السبيل ،   أي الطريق إلى الجنة .   {  وَقِهِمْ } أي :  واصرف عنهم {  عَذَابَ الْجَحِيمِ } .  <br />
