قال :  {  وَإِذْ يَتَحَاجُّونَ فِي النَّارِ فَيَقُولُ الضُّعَفَاء } أي :  السَّفَلة {  لِلَّذِينَ اسْتَكْبَرُوا } يعني الرؤساء والقادة في الضلالة .   وقال بعضهم :  الضعفاء بنو آدم ،   يعني المشركين ،   والذين استكبروا الشياطين ،   وكلهم مستكبرون عن عبادة الله :  {  إِنَّا كُنَّا لَكُمْ تَبَعًا } أي :  دعوتمونا إلى الضلالة فأطعناكم {  فَهَلْ أَنتُم مُّغْنُونَ عَنَّا نَصِيبًا } أي :  جزءاً {  مِّنَ النَّارِ } .  <br />
