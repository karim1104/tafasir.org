{  ثُمَّ قِيلَ لَهُمْ أَيْنَ مَا كُنتُمْ تُشْرِكُونَ مِن دُونِ اللَّهِ } كقوله :  {  أَينَ مَا كُنتُم تعبدُونَ مِن دُونِ اللهِ هَلْ يَنصُرُونَكُم أَوْ يَنتَصِرُونَ } [ الشعراء : 92-93 ] {  قَالُوا ضَلُّوا عَنَّا بَل لَّمْ نَكُن نَّدْعُو مِن قَبْلُ شَيْئًا } ينفعنا ولا يضرنا .   قال الله :  {  كَذَلِكَ يُضِلُّ اللَّهُ الْكَافِرِينَ } أي بكفرهم .
