قال تعالى :  {  ثم رددناه أسفل سافلين } أي :  جهنم ،   ويعني بالإِنسان ها هنا المشرك .   وقال بعضهم :  {  فِي أَحْسَنِ تَقْوِيمٍ } أي :  الشباب ،   {  ثُمَّ رَدَدْنَاهُ أَسْفَلَ سَافِلِينَ } يعني الهرم{[4321]} .   وقال الكلبي :  {  أَسْفَلَ سَافِلِينَ } أي :  الهرم ،   يعني مثل قوله :  {  وَمَن نُّعَمِّرْهُ نُنَكِّسْهُ فِي الْخَلْقِ } [ يس : 68 ] ،   فيصير مثل الصبي الذي لا يعقل شيئاً .
