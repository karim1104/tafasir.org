فقال الله {  مَا كَانَ لِبَشَرٍ أَن يُؤْتِيَهُ اللهُ الكِتَابَ وَالحُكْمَ وَالنُّبُوَّةَ } كما آتى عيسى {  ثُمَّ يَقُولَ لِلنَّاسِ كُونُوا عِبَاداً لِّي مِن دُونِ اللهِ } أي اعبدوني من دون الله ،   يقول :  لا يفعل ذلك من آتاه الله الكتاب والحكم والنبوءة {  وَلَكِن } يقول لهم :  {  كُونُوا رَبَّانِيِّينَ } أي علماء فقهاء في تفسير الحسن وغيره .   وفي تفسير مجاهد :  ولكن كونوا حكماء فقهاء {  بِمَا كُنتُمْ تُعَلِّمُونَ الكِتَابَ وَبِمَا كُنتُمْ تَدْرُسُونَ } أي تقرأون{[539]} .
