قوله :  {  وَلاَ تُؤْمِنُوا إِلاَّ لِمَن تَبِعَ دِينَكُمْ } يقوله بعضهم لبعض ،   أي :  ولا تصدِّقوا إلا لمن تبع دينكم فأخذ به .   {  قُلْ إِنَّ الْهُدَى هُدَى اللهِ } أي إن الدين دين الله ،   وهو الإِسلام .   قال :  {  أَن يُؤْتَى أَحَدٌ مِّثْلَ مَا أُوتِيتُمْ } إنما قالوا لأصحابهم اليهود ؛  قال يهود خيبر ليهود المدينة :  ( لاَ تُؤْمِنُوا إِلاَّ لِمَن تَبِعَ دِينَكُمْ ) ،   فإنه لن يؤتى أحد مثل ما أوتيتم {  أَوْ يُحَاجُّوكُمْ } بمثل دينكم أحد {  عِندَ رَبِّكُمْ } .   فقال الله :  {  قُلْ إِنَّ الهُدَى هُدَى اللهِ } ،   وقال :  {  قُلْ إِنَّ الفَضْلَ بِيَدِ اللهِ } وفضل الله الإِسلام {  يُؤْتِيهِ مَن يَشَاءُ وَاللهُ وَاسِعٌ عَلِيمٌ } أي واسع لخلقه ،   عليم بأمرهم .  <br />
