قوله :  {  قُلْ إِن كُنتُمْ تُحِبُّونَ اللهَ فَاتَّبِعُونِي يُحْبِبْكُمُ اللهُ } قال الحسن :  جعل محبةَ رسوله محبتَه ،   وطاعتَه طاعتَه ؛  فقال : <br />
{  مَّن يُّطِعِ الرَّسُولَ فَقَدْ أَطَاعَ اللهَ } [ النساء : 80 ] وقال :  {  إِنَّ الَّذِينَ يُبَايِعُونَكَ إِنَّمَا يُبَايِعُونَ اللهَ } [ الفتح : 10 ] .
