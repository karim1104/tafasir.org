قوله :  {  لَقَدْ مَنَّ اللهُ عَلَى المُؤْمِنِينَ إِذْ بَعَثَ فِيهِمْ رَسُولاً مِّنْ أَنفُسِهِمْ يَتْلُوا عَلَيْهِمْ ءَايَاتِهِ وَيُزَكِّيهِمْ } أي :  يصلحهم {  وَيُعَلِّمُهُمُ الكِتَابَ } أي القرآن {  وَالحِكْمَةَ } يعني السنة .   {  وَإِن كَانُوا مِن قَبْلُ } أي من قبل أن يأتيهم النبي عليه السلام {  لَفِي ضَلاَلٍ مُّبِينٍ } .  <br />
