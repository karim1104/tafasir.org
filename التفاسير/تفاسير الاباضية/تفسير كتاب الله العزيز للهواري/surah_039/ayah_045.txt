قوله :  {  وَإِذَا ذُكِرَ اللَّهُ وَحْدَهُ اشْمَأَزَّتْ } أي :  انقبضت {  قُلُوبُ الَّذِينَ لاَ يُؤْمِنُونَ بِالآخِرَةِ } وهم المشركون {  وَإِذَا ذُكِرَ الَّذِينَ مِن دُونِهِ } يعني أوثانهم {  إِذَا هُمْ يَسْتَبْشِرُونَ } ،   حين قرأ عليهم بمكة سورة والنجم ،   وألقى الشيطان على لسانه حيث انتهى إلى قوله : {  أَفَرَءَيْتُمُ اللاَّتَ وَالْعُزَّى وَمَنَاةَ الثَّالِثَةَ الأُخْرَى } [ النجم : 19-20 ] لهن الغرانيق العلى وإن شفاعتهم لترتجى ،   ففرح المشركون بذلك ؛  وهو قوله :  {  وَإِذَا ذُكِرَ الَّذِينَ مِن دُونِهِ إِذَا هُمْ يَسْتَبْشِرُونَ } .
