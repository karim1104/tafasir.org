قوله :  {  أَمِ اتَّخَذُوا مِن دُونِ اللَّهِ شُفَعَاء } أي :  قد اتخذوهم ليشفعوا لهم  زعموا  وذلك لدنياهم ليصلحوها لهم ،   كقولهم : <br />
{  مَا نَعْبُدُهُمْ إِلاَّ لِيُقَرِّبُونَآ إلَى اللهِ زُلْفَى }<br />
[ الزمر : 3 ] ليصلحوا لهم معايشهم ولا يقرّون بالآخرة .  <br />
قال الله :  {  قُلْ } يا محمد {  أَوَلَوْ كَانُوا } يعني أوثانهم {  لاَ يَمْلِكُونَ شَيْئًا وَلاَ يَعْقِلُونَ } أي :  إنهم لا يملكون شيئاً ولا يعقلون شيئاً .
