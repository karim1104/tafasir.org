قوله :  {  وَإِذَا مَسَّ الإِنسَانَ ضُرٌّ } أي :  مرض {  دَعَا رَبَّهُ مُنِيباً إِلَيْهِ } أي :  دعاه بالإخلاص أن يكشف عنه {  ثُمَّ إِذَا خَوَّلَهُ نِعْمَةً مِّنْهُ } أي :  عافاه من ذلك المرض .   {  نَسِيَ مَا كَانَ يَدْعُواْ إِلَيْهِ مِنْ قَبْلُ } وهو كقوله :  {  مَرَّ } أي :  معرضاً {  كَأَن لَّمْ يَدْعُنَآ إِلَى ضُرٍّ مَّسَّهُ } [ يونس : 12 ] ،   يعني الكافر المشرك .   قال :  {  وَجَعَلَ لِلَّهِ أَنْدَاداً } يعني الأوثان ،   عدلوها بالله فعبدوها من دونه ،   والنّدّ العدل .   {  لِّيُضِلَّ عَن سَبِيلِهِ } أي :  يتبعه على ذلك غيره {  قُلْ } أي :  قل يا محمد للمشرك {  تَمَتَّعْ } في الدنيا {  بِكُفْرِكَ قَلِيلاً } أي :  إن بقاءك في الدنيا قليل {  إِنَّكَ مِنْ أَصْحَابِ النَّارِ } .
