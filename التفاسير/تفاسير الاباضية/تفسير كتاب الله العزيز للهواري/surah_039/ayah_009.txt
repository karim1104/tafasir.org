قوله :  {  أَمَّنْ هُوَ قَانِتٌ } أي :  قائم في الصلاة {  ءَانَآءَ الَّيْلِ } أي :  ساعات الليل {  سَاجِداً وَّقَآئِماً } قال بعضهم :  هو الذي {  يَحْذَرُ الأَخِرَةَ } أي :  يخاف عذابها {  وَيَرْجُواْ رَحْمَةَ رَبِّهِ } أي :  الجنة .   يقول :  أمَن هو قانت كالذي جعل لله أنداداً يعبد الأوثان دونه ،   أي :  ليس مثلَه .  <br />
قوله :  {  قُلْ هَلْ يَسْتَوِي الَّذِينَ يَعْلَمُونَ وَالَّذِينَ لاَ يَعْلَمُونَ } أي :  هل يستوي هذا المؤمن ،   الذي علم أنه مُلاق ربه ،   الذي يقوم آناء الليل ،   وهذا المشرك الذي جعل لله أنداداً ،   أي :  إنهما لا يستويان .   <br />
{  إِنَّمَا يَتَذَكَّرُ } أي :  إنما يقبل التذكرة {  أُوْلُواْ الأَلْبَابِ } أي :  أصحاب العقول ،   وهم المؤمنون .  <br />
