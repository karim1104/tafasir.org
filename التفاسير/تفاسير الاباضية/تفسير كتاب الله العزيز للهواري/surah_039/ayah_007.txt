قال :  {  إِن تَكْفُرُواْ فَإِنَّ اللهَ غَنِيٌّ عَنكُمْ } أي :  عن عبادتكم {  وَلاَ يَرْضَى لِعِبَادِهِ الْكُفْرَ وَإِن تَشْكُرُواْ } وتؤمنوا {  يَرْضَهُ لَكُمْ وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَى } أي لا يحمل أحد ذنب غيره ،   والذنب الوزر ،   وهو الحمل .   كقوله :  {  وَهُمْ يَحْمِلُونَ أَوْزَارَهُمْ عَلَى ظُهُورِهِمْ } [ الأنعام : 31 ] {  ثُمَّ إِلَى رَبِّكُم مَّرْجِعُكُمْ } أي :  يوم القيامة {  فيُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ إِنَّهُ عَلِيمٌ بِذَاتِ الصُّدُورِ } أي :  بما في الصدور .
