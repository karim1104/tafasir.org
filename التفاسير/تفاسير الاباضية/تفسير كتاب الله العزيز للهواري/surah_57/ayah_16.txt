قوله :  {  أَلَمْ يَأنِ لِلَّذِينَ{[3815]} آمَنُواْ أَن تَخْشَعَ قُلُوبُهُمْ لِذِكْرِ اللهِ } والخشوع الخوف الثابت في القلب {  وَمَا نَزَلَ مِنَ الْحَقِّ } أي القرآن {  وَلاَ يَكُونُواْ كَالَّذِينَ أُوتُوا الْكِتَابَ مِن قَبْلُ } يعني اليهود والنصارى {  فَطَالَ عَلَيْهِمُ الأَمَدُ } أي :  الدهر ،   يعني بقاءهم في الدنيا {  فَقَسَتْ قُلُوبُهُمْ } فغلظت قلوبهم {  وَكَثِيرٌ مِّنْهُمْ فَاسِقُونَ } أي :  من ثبت منهم على الشرك .  <br />
وتفسير الحسن قال :  نزلت هذه الآية {  أَلَمْ يَأنِ لِلَّذِينَ آمَنُواْ أَن تَخْشَعَ قُلُوبُهُمْ لِذِكْرِ اللهِ } قال :  نزلت والله وهم أهل الصلاة والصوم والأعمال الحسنة ،   وهم أصحاب النبي عليه السلام فاستزادهم بذلك .  <br />
وبعضهم يقول :  نزلت في المنافقين :  {  أَلَمْ يَأنِ لِلَّذِينَ آمَنُواْ } أي :  الذين أقرّوا ولم يعملوا {  أَن تَخْشَعَ قُلُوبُهُمْ لِذِكْرِ اللهِ وَمَا نَزَلَ مِنَ الْحَقِّ } أي :  فيصدُقوا في القول والعمل كما فعل المؤمنون الذين صدَقوا الله في قولهم وعملهم{[3816]} .
