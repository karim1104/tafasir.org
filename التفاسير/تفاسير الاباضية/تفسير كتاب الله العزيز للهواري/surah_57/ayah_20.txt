قوله :  {  اعْلَمَُواْ أَنَّمَا الْحَيَاةُ الدُّنْيَا لَعِبٌ وَلَهْوٌ } أي :  إنما أهل الدنيا أهل لعب ولهو ،   [ يعني المشركين ]{[3822]} {  وَزِينَةٌ وَتَفَاخُرٌ بَيْنَكُمْ وَتَكَاثُرٌ فِي الأَمْوَالِ وَالأَوْلاَدِ كَمَثَلِ غَيْثٍ } أي :  مطر {  أَعْجَبَ الْكُفَّارَ نَبَاتُهُ }{[3823]} يعني ما أنبتت الأرض من ذلك المطر {  ثُمَّ يَهِيجُ } ذلك النبات {  فَتَرَاهُ مُصْفَرّاً } أي :  يصفار {  ثُمَّ يَكُونُ حُطَاماً } [ أي :  متكسّراً ذاهباً ] كقوله : {  هَشِيماً تَذْرُوهُ الرِّيَاحُ } [ الكهف : 45 ] {  وَفِي الآخِرَةِ عَذَابٌ شَدِيدٌ } أي :  للكافرين {  وَمَغْفِرَةٌ مِّنَ اللهِ وَرِضْوَانٌ } أي :  للمؤمنين .   {  وَما الْحَيَاةُ الدُّنْيَآ إِلاَّ مَتَاعُ الْغُرُورِ } أي :  يغترّ بها أهلها .  <br />
ذكروا عن أبي عبد الله قال :  سمعت أبا الدرداء يقول :  الدنيا ملعونة وملعون ما فيها إلا ذكر الله ،   وما أوى إليه ذكر الله .  <br />
ذكروا عن الحسن قال :  قال رسول الله صلى الله عليه وسلم :   "  الدنيا سجن المؤمن وجنة الكافر " {[3824]} .
