قوله :  {  مَّن كَانَ يُرِيدُ ثَوَابَ الدُّنْيَا فَعِندَ اللهِ ثَوَابُ الدُّنْيَا وَالآخِرَةِ } أي :  فعنده ثواب الآخرة لمن أراد الآخرة {  وَكَانَ اللهُ سَمِيعاً بَصِيراً } وهو كقوله :  {  مَّن كَانَ يُرِيدُ الْعَاجِلَةَ عَجَّلْنَا لَهُ فِيهَا مَا نَشَاءُ لِمَن نُّرِيدُ ثُمَّ جَعَلْنَا لَهُ جَهَنَّمَ يَصْلاَهَا مَذْمُومًا مَّدْحُورًا وَمَنْ أَرَادَ الآخِرَةَ وَسَعَى لَهَا سَعْيَهَا وَهُوَ مُؤْمِنٌ فَأُولَئِكَ كَانَ سَعْيُهُم مَّشْكُورًا ً } [ الإِسراء : 18-19 ] .
