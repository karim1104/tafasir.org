قوله :  {  وَلَن تَسْتَطِيعُوا أَن تَعْدِلُوا بَيْنَ النِّسَاءِ وَلَوْ حَرَصْتُمْ } أي في النكاح والحب{[836]} .   قال مجاهد :  أي :  لن تستطيعوا العدل بينهن {  فَلاَ تَمِيلُوا كُلَّ المَيْلِ } أي لا تعمّدوا الإِساءة .   وقال الحسن :  {  فَلاَ تَمِيلُوا كُلَّ المَيْلِ } فتأتي واحدة وتترك الأخرى .   قال :  {  فَتَذَرُوهَا كَالْمُعَلَّقَةِ } أي كالمسجونة{[837]} .   قال الحسن :  أي لا أيّم ولا ذات بعل .   {  وَإِن تُصْلِحُوا } الفعل في أمرهن {  وَتَتَّقُوا } الميل والجور {  فَإِنَّ اللهَ كَانَ غَفُوراً رَّحِيماً } .
