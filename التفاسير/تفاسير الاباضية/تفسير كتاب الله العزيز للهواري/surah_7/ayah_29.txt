قوله :  {  قُلْ أَمَرَ رَبِّي بِالْقِسْطِ } أي بالعدل {  وَأَقِيمُوا وُجُوهَكُمْ عِندَ كُلِّ مَسْجِدٍ وَادْعُوهُ مُخْلِصِينَ لَهُ الدِّينَ } كقوله :  {  وَأَنَّ الْمَسَاجِدَ لِلَّهِ فَلاَ تَدْعُوا مَعَ اللهِ أَحَداً } [ الجن :  18 ] أي :  إن كل قوم سوى المسلمين إذا صلوا في مساجدهم أشركوا بالله ،   وقال مجاهد :  {  وَأَقِيمُوا وُجُوهَكُمْ عِندَ كُلِّ مَسْجِدٍ } أي إلى الكعبة حيث صلّيتم في كنيسة أو غيرها .  {[1160]}<br />
قوله :  {  كَمَا بَدَأَكُمْ تَعُودُونَ } ذكروا أن رسول الله صلى الله عليه وسلم قال :  {  كَمَا بَدَأَكُمْ تَعُودُونَ } أي عراة كما خلقوا{[1161]} .  <br />
ذكروا عن جابر بن عبد الله قال قال رسول الله صلى الله عليه وسلم :   "  يبعث الله الناس يوم القيامة حفاة عراة غرلاً{[1162]} .
