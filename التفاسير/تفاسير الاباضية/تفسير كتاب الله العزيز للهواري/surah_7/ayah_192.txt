قال :  {  وَلاَ يَسْتَطِيعُونَ لَهُمْ نَصْراً } أي ولا تستطيع الأوثان أن تنصر من عبدها .   {  وَلاَ أَنفُسَهُمْ يَنصُرُونَ } أي :  ولا تنصر الأوثان أنفسها .   قال في آية أخرى :  {  وَإِن يَسْلُبْهُمُ الذُّبَابُ شَيْئاً لاَّ يَسْتَنقِذُوهُ مِنْهُ ضَعُفَ الطَّالِبُ } أي الوثن {  وَالمَطْلُوبُ } أي الذباب [ الحج : 73 ] .
