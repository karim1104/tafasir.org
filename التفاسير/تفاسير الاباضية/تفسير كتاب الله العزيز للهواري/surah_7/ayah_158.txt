قوله :  {  قُلْ يَا أَيُّهَا النَّاسُ إِنِّي رَسُولُ اللهِ إِلَيْكُمْ جَمِيعاً } ذكروا عن الحَسَن قال :  قال رسول الله صلى الله عليه وسلم :   "  بعثت إلى كل أحمر وأسود{[1233]} .   وفي تفسير عمرو عن الحسن قال :  بعثت إلى الناس كافة ،   ولم يُعْطَ هذه المنزلة نبي قط ،   قال :  {  إِنِّي رَسُولُ اللهِ إِلَيْكُمْ جَمِيعاً } .  <br />
{  الَّذِي لَهُ مُلْكُ السَّمَاوَاتِ وَالأَرْضِ لاَ إِلَهَ إِلاَّ هُوَ يُحْيِي وَيُمِيتُ فَئَامِنُوا بِاللهِ وَرَسُولِهِ النَّبِيِّ الأُمِّيِّ الَّذِي يُؤمِنُ بِاللهِ وَكَلِمَاتِهِ } وهي تقرأ على وجهين :  {  وكَلِمَاتِهِ } {  وكَلِمَتِه } .   وكان الحسن يقرأها :  {  وَكَلِمَاتِه } قال :  كلمات الله وحيه الذي أنزل على محمد عليه السلام .   ومن قرأها :  {  وَكَلِمَتِهِ } فهو يعني عيسى روحَ الله وكلمته .   وقال بعضهم :  {  وَكَلِمَاتِهِ } أي :  وآياته .   قال :  {  وَاتَّبِعُوهُ لَعَلَّكُمْ تَهْتَدُونَ } أي لكي تهتدوا .   ولعلّ من الله واجبة .
