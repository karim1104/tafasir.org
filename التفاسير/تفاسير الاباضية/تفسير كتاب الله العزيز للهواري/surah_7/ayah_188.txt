قوله :  {  قُل لاَ أَمْلِكُ لِنَفْسِي نَفْعاً وَلاَ ضَرًّا إِلاَّ مَا شَاءَ اللهُ } أي إنما ذلك بما شاء الله {  وَلَوْ كُنتُ أَعْلَمُ الغَيْبَ لاَسْتَكْثَرْتُ مِنَ الخَيْرِ } أي :  لو أطلعني الله على أكثر مما أطلعني عليه من الغيب لكان أكثر لخيري عنده{[1270]} ؛  ولم يطلعني الله على علم الساعة متى قيامها .  <br />
قوله :  {  وَمَا مَسَّنِيَ السُّوءُ } هذا جواب لقول المشركين إنه مجنون ؛  فقال الله له :  قل :  {  وَمَا مَسَّنِيَ السُّوءُ } أي الجنون ،   كقولهم لنوح عليه السلام :  {  إِن نَّقُولُ إِلاَّ اعْتَرَاكَ بَعْضُ آلِهَتِنَا بِسُوَءٍ } [ هود : 54 ] أي بجنون .   {  إِنْ أَنَا إِلاَّ نَذِيرٌ } أي من العذاب {  وَبَشِيرٌ } بالجنة {  لِّقَوْمٍ يُّؤْمِنُونَ } وهذا تبع للكلام الأول :  {  أَوَلَمْ يَتَفَكَّرُوا مَا بِصَاحِبِهِم مِّن جِنَّةٍ إِنْ هُوَ إِلاَّ نَذِيرٌ مُّبِينٌ } .
