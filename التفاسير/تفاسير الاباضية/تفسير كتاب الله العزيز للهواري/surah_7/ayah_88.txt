قوله :  {  قَالَ المَلأُ الَّذِينَ اسْتَكْبَرُوا مِن قَوْمِهِ } أي :  عن عبادة الله {  لَنُخْرِجَنَّكَ يَا شُعَيْبُ وَالَّذِينَ ءَامَنُوا مَعَكَ } أي الذين صدقوا معك {  مِن قَرْيَتِنَا أَوْ لَتَعُودُنَّ فِي مِلَّتِنَا } أي :  في دِينِنَا حتى تعبدوا ما نعبد {  قَالَ } شعيب {  أَوَ لَوْ كُنَّا كَارِهِينَ } أي لدينكم .   وهذا على الاستفهام .  <br />
