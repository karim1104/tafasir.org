ثم قال :  {  أَلَهُمْ أَرْجُلٌ يَمْشُونَ بِهَا } على الاستفهام ،   يعني الأوثان {  أَمْ لَهُمْ أَيْدٍ يَبْطِشُونَ بِهَا أَمْ لَهُمْ أَعْيُنٌ يُبْصِرُونَ بِهَا أَمْ لَهُمْ ءَاذَانٌ يَسْمَعُونَ بِهَا } أي :  إنه ليس لهم شيء من هذا ،   كقوله :  {  أَمْوَاتٌ غَيْرُ أَحْيَاءٍ } [ النحل : 21 ] {  قُلِ ادْعُوا شُرَكَاءَكُمْ } يعني أوثانكم التي أشركتموها بالله .   {  ثُمَّ كِيدُونِ } أنتم وأوثانكم {  فَلاَ تُنظِرُونَ } أي :  اجهدوا عليّ جهدكم .
