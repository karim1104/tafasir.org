قوله :  {  وَكَم مِّن قَرْيَةٍ أَهْلَكْنَاهَا } يعني ما أهلك من الأمم السالفة حين كذّبوا رسلهم .   {  فَجَاءَهَا بَأْسُنَا } أي عذابنا {  بَيَاتاً } أي ليلاً {  أَوْ هُمْ قَائِلُونَ } أي عند القائلة بالنهار .   وهو كقوله :  {  قُلْ أرَيْتُمْ إِنْ أتَاكُمْ عَذَابُهُ بَيَاتاً أَوْ نَهَاراً } [ يونس : 50 ] .
