قال تعالى :  {  مَّنَّاعٍ لِّلْخَيْرِ } أي :  للزكاة ؛  وهذا المشرك .   وقال في حم السجدة :  {  وَوَيْلٌ لَّلْمُشْرِكينَ الذِينَ لاَ يُؤتُونَ الزَّكَاةَ } أي :  الواجبة {  وَهُمْ بِالآخِرَةِ هُمْ كَافِرُونَ } [ فصّلت : 6-7 ] .  <br />
قال :  {  مُعْتَدٍ } أي :  من قبل العدوان .   والعدوان ها هنا الشرك .   {  مُّرِيبٍ } أي :  في شك من البعث .
