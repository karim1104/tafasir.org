قوله تعالى :  {  إِنَّ الأَبْرَارَ يَشْرَبُونَ مِن كَأْسٍ } يعني الخمر {  كَانَ مِزَاجُهَا } أي :  طعمها {  كَافُوراً } وهو الكافور إلا أنه أفضل من هذا الكافور وأطيب .   وقال الحسن :  يشربونها على برد الكافور وطعم الزنجبيل .   وتفسير مجاهد :  {  مِزَاجُهَا } أي :  الذي يمزج به .   وقال الكلبي {  كَافُوراً } عين في الجنة تسمى كافوراً .  <br />
