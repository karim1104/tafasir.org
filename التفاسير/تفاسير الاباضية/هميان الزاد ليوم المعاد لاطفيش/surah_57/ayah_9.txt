{ هُوَ الَّذِى يُنَزِّلُ عَلَى عَبْدِهِ } محمد صلى الله عليه وسلم { آيَاتٍ بَيِّنَاتٍ } أي القرآن { لِّيُخْرِجَكُمْ } أي الله أو عبده بدعوته { مِّن الظُّلُمَاتِ } ظلمات الكفر { إِلَى النُّورِ } نور الايمان . <br />
{ وَإِنَّ اللهَ بِكُمْ لَرَءُوفٌ رَّحِيمٌ } حيث نبهكم بالرسل والآيات ولم يقتصر على ما نصب لكم من الحجج العقلية وقرىء باسقاط الواو تخفيفا . <br />
