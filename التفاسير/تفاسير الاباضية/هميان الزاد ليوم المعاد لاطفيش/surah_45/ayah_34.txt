{ وَقِيلَ الْيَوْمَ } متعلق بقوله* { نَنسَاكُمْ } نترككم في العذاب .  والنسيان يستعمل للترك عمداً أو هو هنا مجاز أي نترككم ترك ما ينسى* { كَمَا نَسِيتُمْ } تركتم أو تغافلتم لعدم المبالاة كما ينسى الشيء*<br />
{ لِقَآءَ يَوْمِكُمْ هَذَا } بدل أو بيان أو نعت ليوم ،  أي تركتم العمل والاستعداد للقائه والإيمان باللقاء .  واضافة اللقاء لليوم اضافة مصدر لظرفه كمكر الليل أي لقاء الله في يومكم ،  والاشارة للتهديد باليوم الحاضر .  ويجوز تقدير لقاء جزاء يومكم { وَمَأْوَاكُمُ النَّارُ } منزلكم ومرجعكم { وَمَا لَكُم مِّن نَّاصِرِينَ } يمنعونكم منها<br />
