{ أَمَنْ جَعَلَ الأَرْضَ قَرَاراً } يستقر الخلق عليها ولا تميد بهم . <br />
{ وَجَعَلَ خِلالِهَا } أي بين أجزائها . <br />
{ أَنْهَاراً } تجري . <br />
{ وَجَعَلَ لَهَا رَوَاسِيَ } جبالا فيها معادن ثبتت بها الأرض فيلا تميل . <br />
{ وَجَعَلَ بَيْنَ البَحْرَيْنَ } البحر العذب والمالح أو بحر فارس وبحر الروم . <br />
{ حَاجِزاً } يمنع من اختلاط أحدهما بالآخر وهو أرض وقال مجاهد حلزا لا يرى . <br />
{ أَءِلَهٌ مَّعَ اللهِ بَلْ أَكْثَرُهُمْ لا يَعْلَمُونَ } الحق فهم يشركون به . <br />
