{ والذين كفروا لهم نار جهنم لا يقضى } بالموت . <br />
{ عليهم فيموتوا } ليستريحوا مما هم فيه والنصب بان في جواب النفي وقرىء بثبوت النون عطفا على يقضي أي فلا يموتون { ولا يخفف عنهم من عذابها } طرفة بل كلما خبت زدناهم سعيرا . <br />
{ كذلك } مثل ذلك الجزاء . <br />
{ نجزي } وقرأ نجازى فينصب { كل كفور } مبالغ في الشرك او المعاصي . <br />
