{ وَكَم مِّن مَّلِكٍ } أي كثير { فِي السَّمَاوَاتِ } لهم الزامي { لاَ تُغْنِي شَفَاعَتُهُم } في أقل شيء ولو اجتمعوا عليه { شَيْئاً } من الاغناء { إِلاَّ مِن بَعدِ أَن يَأذَنَ اللهُ } في الشفاعة . <br />
{ لِمَن يَشَآءُ } من الملائكة أو الناس ان يشفع .  { وَيَرضَى } يراه اهلا لذلك فكيف تشفع الاصنام لعبادها فذلك رد على قريش وانما الشفاعة للمسلمين في المسلمين . <br />
