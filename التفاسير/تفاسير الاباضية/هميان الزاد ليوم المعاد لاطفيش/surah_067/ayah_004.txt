{ ثُمَّ ارْجِعِ البَصَرَ كَرَّتَيْنِ } أي رجعتين مرتين أي كرة بعد أخرى فهو من التثنية ،  المراد بها أكثر من اثني ب( لبيك )و( سعديك ) بدليل رجوع البصر حسيرا . <br />
{ يَنقَلِبْ } يرجع { إِلَيْكَ البَصَرُ خَاسِئاً } ذليلا لعدم إدراك الخلل الذي يبحث عنه { وَهُوَ حَسِيرٌ } كليل من طول المعاودة وكثرة المراجعة . <br />
