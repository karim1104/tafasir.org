{ فَأَمَّا الإِنْسَانُ إِذَا } جواب إذا دل عليه في فيقول ربي أكرمني * { مَا } زائدة * { ابْتَلاَهُ رَبُّهُ } فعل فيها فعل المختبر بالنعمة أيشكر أم يكفر * { فَأَكْرَمَهُ ونَعَّمَهُ } بالمال والولد والجاه * { فَيَقُولُ رَبِّي أَكْرَمَنِي } مبتدأ وخبر وجملتهما مفعول القول والمجموع خبر المبتدأ الذي هو الإنسان وإذا في نية التأخير . <br />
