{ لايُقَاتِلُونَكُمْ } أي اليهود والمنافقون وقيل اليهود { جَمِيعاً } مجتمعين أي ومع اجتماعهم لا يقاتلونكم { إِلا فِى قُرىً } جمع قرية { مُّحَصَّنَةٍ } بالدروب والخنادق { أَوْمِن وَرَآءِ جُدُرٍ } رعبا منكم لا يظهرون وقرأ ابن كثير وأبو عمر واو من وراء جدار بكسر الجيم وبألف بعد اسكان الدال واما ابو عمر فتح الدال وقرىء جدر بضم الجيم واسكان الدال وقرىء جدر بفتح الجيم واسكان الدال والمراد الحائط الساتر والمضمومان جمعان . <br />
{ بَأْسُهُم } ضرهم او حربهم { بَينَهُمٌْ } شديد واما معكم فلا يبقى لهم بأس لان الشجاع يجبن والعزيز يذل إذا حارب الله ورسوله وقيل بأسهم شديد بينهم من وراء الحيطان وإذا برزوا اليكم فهم اجبن خلق الله . <br />
{ تَحْسَبْهُمْ جَمِيعاً } مجمتعين ذوي الفة { وَقُلُوبُهُمْ شَتَّى } متفرقة جمع شتيت كقتيل وقتلى الفة للتأنيث يعني ان بينهم حذا وعداوات لا يتعاضدون حق التعاضد ولا يرمون عن قوس واحدة ولا شيء اخزى للقوم من اختلاف قلوبهم فهذا تجسير للمؤمنين وتشجيع لقلوبهم على قتالهم وذلك لاختلاف مقاصدهم وعقائدهم قال قتادة اهل الباطل مختلفة اهوائهم مختلفة اعمالهم مختلفة شهاداتهم وهم مجتمعون في عداوة اهل الحق وقيل اراد ان دين المنافقين وآرائهم تخالف دين اليهود وارائهم . <br />
{ ذَلِكَ بِأَنَّهُمْ قَوْمٌ لا يَعْقِلُونَ } ما فيه صلاحهم ولا يعلمون ان تشتيت القلوب يوهن قواهم . <br />
