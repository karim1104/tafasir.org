{ أَلَمْ تَرَ } تنظر { إِلَى الَّذِينَ نَافَقُوا } أظهروا خلاف ما أبطنوا وهم عبدالله بن أُبي بن سلول وغيره من اصحابه وقوم من منافقي الأنصار .  { يَقُولُونَ لإِخْوَانِهِمُ } في الكفر والموالاة { الَّذِينَ } نعت إخوان { كَفَرُوا مِنْ أَهْلِ الكِتَابِ } هم قريظة والنضير { لَئِنْ } اللام موطئة في الأربعة . <br />
{ أُخْرِجْتُمْ } من المدينة { لَنَخْرُجَنَّ مَعَكُمْ } منها { وَلا نُطِيعُ فِيكُمْ } في قتالكم وخذلانكم { أَحَداً } من رسول الله والمؤمنين { أَبَداً وَإِن قُوتِلْتُمْ } أي ولئن قوتلتم فحذف اللام بدليل { لَنَنصُرَنَّكُمْ } لنعيننكم واغتروا بما هو كذب كما قال عز وجل { وَاللهُ يَشْهَدُ إِنَّهُمْ لَكَاذِبُونَ } لعلمه بأنهم لا يفعلون ذلك ولو قالوه كما قال . <br />
