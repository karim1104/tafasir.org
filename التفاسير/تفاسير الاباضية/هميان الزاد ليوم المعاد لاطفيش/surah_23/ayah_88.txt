{ قُلْ أَفَلاَ تَتَّقُونَ } تحذرون عبادة غيره أو افلا تحذرون عقابه بترك موجباته التي منها اشراك بعض مخلوقاته به وانكار قدرته على بعض مقدوراته وعصيان الرسل * { قُلْ مَن بِيَدِهِ مَلَكُوتُ كُلِّ شَىْءٍ } اي ملك كل شيء والتاء للمبالغة اي من بيده غاية الملك . <br />
وقيل : ملكوت كل شيء غاية خزائن كل شيء * { وَهُوَ يُجِيرُ } يمنع من يشاء عمن اراده بسوء ويجعله آمنا { وَلاَ يُجَارُ عَلَيْهِ } لا يمنع منه من اراده بسوء ولا يجعله آمنا وعدّى بعلى لتضمنه معنى النصر ومفعول يجير مقدر كما رايت أو ينزل ( يجير ) منزلة اللازم بان يراد الاخبار بمجرد اثبات الاجارة وعليه نائب ( يجار ) . <br />
{ إِنْ كُنتُم تَعْلَمُونَ } . <br />
