{ قَالَ } نوح بعد اياسه من ايمانهم * { رَبِّ انصُرْنِي } يا رب انصرني عليهم باهلاكهم { بِمَا كَذَّبُونِ } بسبب تكذيبهم فما مصدرية او اسم اي بالتكذيب الذي كذبوني اياه وانصرني بانجاز ما وعدتهم من العذاب وهو ما كذبوه فيه حين قال : { اني اخاف عليكم عذاب يوم عظيم }<br />
أو الباء للبدلية اي انصرني بدل ما كذبوني اي ابدلني من غم تكذيبهم سلوة النصر عليهم . <br />
