{ إِنْ } اي ما * { هُوَ } اي نوح * { إِلاَّ رَجُلُ بِهِ جنَّةٌ } جنون ولكونه جنة قال انه رسول والباء بمعنى ( في ) ويجوز ان يكون الجنة بمعنى الجن كقوله من   { الجنة والناس } اي فيه الجن يخبلونه * { فَتَرَبَّصُوا بِهِ } اي انتظروه * { حَتَّى حِينٍ } يموت فيه فتستريحوا منه أو حتى حين يفيق فيه من جنونه وان انتظرتموه ولم يفق قتلتموه . <br />
