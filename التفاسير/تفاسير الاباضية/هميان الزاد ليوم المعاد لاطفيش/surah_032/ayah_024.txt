{ وَجَعَلْنَاهُ } اي موسى او الكتاب . <br />
{ هُدىً لِّبَنِي إِسْرَائِيلَ وَجَعَلْنَا مِنْهُمْ } من بني اسرائيل . <br />
{ أَئِمَّةً } بتحقيق الهمزتين والدال الثانية ياء وتسهيلها والأئمة حملة الكتاب وقيل الانبياء وقيل اتباع الانبياء . <br />
{ يَهْدُونَ } الناس الى ما فيه من الحكم والاحكام . <br />
{ بِأَمْرِنَا } إياهم به او بتوفيقنا له وقيل بطاعتنا . <br />
{ لَمَّا صَبَرُوا } على دينهم وعلى بلاء العدو وغيرهم وعن المعاصي وقرأ حمزة والكسائي ورويس ( لما ) بكسر اللام وتخفيف الميم فتكون اللام جارة وما مصدرية . <br />
{ وَكَانُوا بِآيَاتِنَا يُوقِنُونَ } انها منا لأمعانهم النظر . <br />
