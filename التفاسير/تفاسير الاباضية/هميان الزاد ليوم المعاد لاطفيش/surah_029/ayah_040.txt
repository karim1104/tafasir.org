{ فَكُلاًّ } من المذكورين . <br />
{ أَخَذْنَا بِذَنبِهِ } عاقبناه بذنبه . <br />
{ فَمِنْهُم مَّنْ أَرْسَلْنَا عَلَيْهِ حَاصِباً } حجارة صغارا رماهم بها بالريح او بأيدي الملائكة او الحاصب الريح العاصف او الملك رماهم بالحصباء كقوم لوط رميت مدينتهم ومن غاب منها او كان خارجها وخسف بها . <br />
{ وَمِنْهُم مَّنْ أَخَذّتْهُ الصَّيْحَةُ } كثمود ومدين . <br />
{ وَمِنْهُم مَّنْ خَسَفْنَا بِهِ الأَرْضِ } كقارون . <br />
{ وَمِنْهُم مَّنْ أَغْرَقْنَا } كفرعون وقومه وقوم نوح . <br />
{ وَمَا كَانَ اللهُ لِيَظْلِمَهُمْ } بالعذاب من غير ذنب . <br />
{ وَلَكِن كَانُوا أَنفُسَهُمْ يَظْلِمُونَ } بفعل ما يوجب العذاب واما الله جل وعلا فليس له الظلم عادة ولا نادرا ولكن العدل . <br />
