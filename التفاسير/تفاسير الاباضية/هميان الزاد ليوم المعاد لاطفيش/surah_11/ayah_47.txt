{ قالَ ربِّ إني أعوذُ } اعتصم { بِكَ } من { أنْ أسألكَ ما لَيس لى به عِلمٌ } بجواره وصحته ،  أو سؤال عزم واللجاج فيما قد حجب وجه الحكمة فيه { وإلاَّ تَغفِرْ لي } هذا السؤال وغيره مما فرط منى { وترحمني } بالتوبة والتفضل علىَّ { أكُن مِنَ الخاسِرينَ } عدما لم يتعمد العصيان به معصية ،  صونا لمرتبة النبوة التي يستعظم فيها أدنى ما يكرهه ،  وتعظيما لله فلا دليل فى الآية على عدم عصمة الأنبياء . <br />
