{ قَالَ فَإِنِ اتبعتني } صاحبتني حيث أمشى . <br />
{ فَلاَ تسألني } وقرأ نافع وابن عامر بإسكان اللام وتخفيف النون وحذف الياء ابن ذكوان وصلا ووقفا بخلاف عن الأخفش عنه وأثبتها الباقون فيهما وكذا رسمها { عَنْ شَيْءٍ } فعلته مما تنكره ولم تعلم وجهه . <br />
{ حَتَّى أُحْدِثَ لَكَ } أي حتى أبتدئ لك { مِنْهُ } متعلق بأحدث ومن الابتداء أو متعلق بمحذوف حال مما بعده ويقدر مضاف أي من بيانه أو يقدر الكلام هكذا . <br />
{ ذِكْراً } في بيانه فإذا أحدثته لك لم تحتج بعد إلى السؤال عنه كما تقول : لا أعصى الله إن شاء الله إلى أن أموت ومعلوم أنه لا معصية بعد الموت فقبل موسى شرطه كما يتأدب المتعلم للمعلم . <br />
