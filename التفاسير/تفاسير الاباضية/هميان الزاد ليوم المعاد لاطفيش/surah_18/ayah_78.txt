{ قَالَ } الخضر لموسى : { هذَا } أي هذا الوقت { فِرَاقُ } أي وقت فراق وهذا الاعتراض الثالث سبب فراق أو موجب فراق أو هذا الفراق الذي تضمنه قولك : { إن سألتك عن شئ بعدها فلا تصاحبني } وهو فراق . <br />
{ بَيْنِي وَبَيْنِكَ } وإضافة الفراق لبين من إضافة المصدر إلى الظرف على الاتساع . <br />
وقد قرأ ابن أبى عبلة بتنوين فراق وتفتح بينك فيكون بيني وبينك منصوبين على الظرفية . <br />
ويجوز أن يكون بيني وبينك بمعنى وصلى وصالك فإضافة فراق إضافة مصدر لمصدر أي فراق بيني وبينك أي وصلى وصالك ووصالك وصلى فهي إضافة مصدر فاعله أو مفعوله لأن كلا من المتفاريقين مفارق للآخر أو مفارقتك بيني ومفارقتي بينك أي مفارقتك وصلى ومفارقتي وصلك فهى إضافة مصدر لمفعول وقراءة ابن أبى عبلة تدل على الظرفية لأنه لما نون نصب إلا أن يقال : يحتمل النصب فيها المفعولية للمصدر المنون . <br />
{ سَأُنَبْئُكَ } سأخبرك { بِتَأْوِيلِ } بتفسير وهو تفسير الشئ على خلاف ظاهره . <br />
{ مَا لَمْ تَسْتَطِعْ عَلَيْهِ صَبْراً } لأنه بحسب علمك الظاهري منكر . <br />
