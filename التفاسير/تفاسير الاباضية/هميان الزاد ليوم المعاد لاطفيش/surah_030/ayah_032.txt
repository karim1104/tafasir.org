{ مِنَ الَّذِينَ } بدل من قوله { من المشركين } { فَرَّقُوا دِينَهُمْ } جعلوه اديانا مختلفة لاختلاف اهوائهم فيما يعتقدون وفيما يعبدون وقرأ حمزة والكسائي ( فارقوا ) الى تركوا الدين الذي يجب ان يكون دينهم وهو دين الله . <br />
{ وَكَانُوا شِيَعاً } فرقا مختلفة كل فرقة تشايع امامها الذي اضل دينها . <br />
{ كُلُّ حِزْبٍ } فرقة . <br />
{ بِمَا لَدَيْهِمْ } عندهم . <br />
{ فَرِحُونَ } ظنا انه الحق كل مبتدأ وفرحون خبره ويجوز كون كل مبتدأ وفرحون نعته ومن الدين خبره . <br />
