{ وَقَالَ الَّذِى آمَنَ } من آل فرعون وكتم أو موسى على ما مر ويقوي على انه موسى قوله* { يَا قَوْمِ اتَّبِعُونِ } فى التصديق بالله والرسالة وان احتمل أن يريد ان المؤمن من آل فرعون قال اتبعون فى اتباع موسى وقرئ ( اتبعونى ) باثبات الياء والحذف قراءة نافع* { أَهْدِكُمْ } جواب الأمر أي أهدكم بالدلالة* { سَبِيلَ الرَّشَادِ } الصلاح الدنيوي والأخروي وذلك كناية عن ان فرعون وقومه في الغي وعظهم أولاً اجمالاً وفسر بعد ذلك مفتتحاً بذم الدنيا وتصغير شأنها لانها رأس كل خطيئة ومجلاب الشقاوة قائلاً* { يَا قَوْمِ إِنَّمَا هَذِهِ الْحَيَاةُ الدُّنْيَا }<br />
