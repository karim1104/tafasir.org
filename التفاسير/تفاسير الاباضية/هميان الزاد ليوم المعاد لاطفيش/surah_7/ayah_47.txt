{ وإذا صُرفَتْ } وقرأ الأعمش قلبت { أبصارُهم } أبصار أصحاب أهل الأعراف { تِلْقاء أصْحاب النَّار } أي أثبت نظرهم فى جهة أصحاب النار وتجاههم { قالُوا } نعوذ بالله { ربَّنا لا تَجْعلنا مَع القَوم الظَّالمين } أنفسهم بالشرك والمعاصي ،  وهم أصحاب النار ،  أي لا تجعلنا معهم في النار ،  وقال أبو مجلز : الهاء في أبصارهم لأهل الجنة ،  يقولون قبل دخولها وهم طامعون : ربنا لا تجعلنا الخ . <br />
