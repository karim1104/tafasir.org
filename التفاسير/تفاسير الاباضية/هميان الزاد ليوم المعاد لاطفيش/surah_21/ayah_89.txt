{ وَزَكَرِيَّا إِذْ نَادَى رَبَّهُ رَبِّ } يا رب .  { لاَ تَذَرْنِى } لا تتركنى .  { فَرْدًا } بلا ولد يرثنى .  والجملة مفعول لقول محذوف ،  أى بقوله : { رب لا تذرنى فردا } أو قال : رب لا تذرنى . <br />
{ وَأَنْتَ خَيْرُ الْوَارِثِينَ } رد أمره مستسلما إلى الله كأنه قال : إن لم ترزقنى ولداً فلا أُبالى به ؛ فإنك خير الوارثين . <br />
