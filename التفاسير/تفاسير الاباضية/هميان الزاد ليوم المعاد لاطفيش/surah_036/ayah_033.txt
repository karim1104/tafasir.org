{ وآية } تدل على القدرة والبعث . <br />
{ لهم الأرض الميتة } وقرأ غير نافع باسكان الياء والأرض مبتدأ خبره آية ولهم نعت آية . <br />
{ أحييناها } : بالماء مستأنف أو بدل من الأرض على تقدير حذف المصدر أو نعت للأرض } ؛ لأن المراد بها الجنس لا أرض مخصوصة وأجيز كون { آية  }مبتدأ و{ الأرض } خبر  ، وجملة { احييناها  }كما مر وكون{  الأرض } مبتدأ خبره{ احييناها } والجملة خبر آية لا يحتاج لمربط لانه نفس المبتدأ في المعنى . <br />
{ وأخرجنا منها حبا } أي : جنس الحب كالبر . <br />
{ فمنه يأكلون } : قدم منه للفاصلة وللدلالة على أن الحب معظم ما يؤكل ويعاش به . <br />
