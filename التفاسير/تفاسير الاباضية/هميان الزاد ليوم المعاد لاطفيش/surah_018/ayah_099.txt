{ وَتَرَكْنَا } هذا إلى آخر السورة من كلام الله سبحانه وتعالى : { بَعْضَهُمْ } أي بعض يأجوج ومأجوج أو بعض الخلق وهذا الخلق الإنس الجن وهؤلاء من جملة الإنس . <br />
واختار بعضهم الوجه الثاني والأول أولى عندي لأن الكلام على يأجوج ومأجوج وقد يقوى الثاني بقوله : { ونفخ فى الصور } . <br />
{ يَوْمَئِذٍ } أي يوم إذ جعلناه دكا أو يوم إذ جاء وعدنا أو يوم إذ خرجوا من السد فإن خروجهم منه مذكور ضمنا فى قوله : { فإذا جاء وعد ربى جعله دكا } . <br />
{ يَمُوجُ } يختلط ويضطرب كموج الماء فى بعض يختلط الإنس والجن بعضهم ببعض حيارى ويأجوج ومأجوج مزدحمين فى البلاد أو يمجون لكثرتهم . <br />
{ وَنُفِخَ في الصُّورِ } أي القرن أي ينفخ إسراقيل فيه للبعث فحذف الفاعل وناب المجرور عنه . <br />
{ فَجَمَعْنَاهُمْ } للحساب { جَمْعاً } لا يغادر أحدا . <br />
