{ وَرَبُّكَ الْغَفُورُ } البليغ المغفرة كثيرة وعِظَما . <br />
{ ذُو الرَّحْمَةِ } المتصف برحمة الدنيا والآخرة . <br />
{ لَوْ يُؤَاخِذُهُمْ } في الدنيا .  { بِمَا كَسَبُوا } من الذنوب . <br />
{ لَعَجَّلَ لَهُمُ الْعَذَابَ } في الدنيا ألا ترى يا محمد كيف أصرت قريش على الكفر وعداوة الرسول والقرآن والوحي فلم أعجل لهم العذاب واللام في لهم بمعنى إلى أو للاستلحاق . <br />
{ بَلْ لَهُمْ مَوْعِدٌ } وعد أو زمان يوعدون إليه أو مكان يوعدون أن يعذبوا فيه فموعد مصدر أو اسم مكان أو زمان وذلك وعد بدر أو وقته أو بدر أو وعد القيامة أو زمانه أو مكان يحشرون إليه من الموقف وهو النار واللام للاستحقاق ولهم خبر وموعد مبتدأ أي لهم موعد للعذاب أو لعذابهم موعد . <br />
{ لَنْ يَجِدُوا مِنْ دُونِهِ مَوْئِلا } منجىً أي نجاة أو مكان نجاة أو زمانا يقال : وأل بهمزة مفتوحة أي نجا .  ويقال : وأل إليه كذلك أي التجأ فكأنه قيل ملجأ أي التجاء أو مكانه أو زمانه والهاء في من دونه راجعة لموعد .  والجملة نعت موعد . <br />
