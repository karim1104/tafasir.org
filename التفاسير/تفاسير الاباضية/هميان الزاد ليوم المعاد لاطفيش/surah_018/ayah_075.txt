{ قَالَ } الخضر لموسى : { أَلمْ أَقُلْ لَكَ } زاد هنا لفظ لك لزيادة التأكيد والعتاب لمخالفة الشرط مرتين ولعدم العذر هنا . <br />
{ إِنَّكَ لَنْ تَسْتَطِيعَ معي صَبْراً } ولعدم العذر هنا قال ما حكى الله سبحانه وتعالى عنه بقوله : { قَالَ إِنْ سَأَلْتُكَ عَنْ شَيْءٍ بَعْدَهَا } أي بعد هذه المسألة أو بعد هذه المرة . <br />
