{ قُلْ لَوْ كَانَ الْبَحْرُ مِدَداً لِكَلِمَاتِ رَبِّى } أي لعلم ربى ويسمى العلم كلمة لأن ما يعلمه أحد يتكلم به فى الجملة . <br />
والمداد : اسم لما تمد به الدواة من حبر أسود أو أصفر أو أحمر أو أزبر أو غير ذلك وما يمد به السراج من الزيت أو غيره . <br />
ويقال : السماء مداد الأرض ويقدر مضاف فى قوله : كان البحر أي ماء البحر لأن البحر اسم للأرض التي فيها ذلك الماء لا للماء . <br />
ويجوز أن يراد به الماء مجازا تسمية للحال باسم لمحل ولأحد المتجاورين باسم الآخر .  والمعنى لو كان ماء البحر مداداً يكتب الخلائق به كلهم علم الله { لَنَفِدَ الْبَحْرُ } أي انقضى ملؤه وفرغ . <br />
{ قَبْلَ أَنْ تنْفَدَ } وقرأ حمزة والكسائى فى رواية عنهما قبل أن ينفد بالمثناة التحتية . <br />
{ كَلِمَاتُ رَبِّى } علمه وحكمه { وَلَوْ جِئْنَا بِمِثْلِهِ } أي بمثل البحر . <br />
{ مَدَداً } زيادة وهو كالمداد وقد قرأ ابن عباس مداداً . <br />
وقرأ الأعرج مددا بكسر الميم جمع مدة وهى ما يمد به الكاتب فيكتب به والنصب على التمييز وجواب لو محذوف أي لنفد أيضا ولم تنفد كلمات ربى فإن كلماته لا تتناهى بخلاف الأجسام . <br />
قيل : قال يحيى بن أخطب : فى كتابكم :  "  ومن يؤت الحكمة فقد أوتى خيراً كثيراً  "  ثم تقرأون : { وما أوتيم من العلم إلا قليلا } فنزل : { قل لو كان البحر مدادا } إلى قوله : { مدداً } يعنى أن ذلك خير كثير ولكنه قطرة من بحر كلمات الله . <br />
وقيل : لما نزل : { وما أوتيتم من العلم إلا قليلا } قالت اليهود : أوتينا التوراة وفيها علم كل شئ فأنزل الله تبارك وتعالى : { قل لو كان البحر مدادا } - إلى قوله - { مددا } . <br />
