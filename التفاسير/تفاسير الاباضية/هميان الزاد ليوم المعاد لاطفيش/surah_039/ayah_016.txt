{ لَهُم مِّن فَوْقِهِمْ ظُلَلٌ } جمع ظلة وهى ما غشى وغم كالسحابة والسقف أي لهم فوقهم طباق . <br />
{ مِّنَ النَّارِ وَمِن تَحْتِهِمْ ظُلَلٌ } طباق من نار ظللت على غيرهم ممن دركتها أسفل فهم معذبون بظلهم وظل من تحتهم فالمراد احاطة النار بهم من جميع الجهات كما تقول ضربت زيداً الظهر والبطن اذا أردت عممته بالضرب فهى غطاؤهم وفراشهم أو سمى الطبقة التي تحتهم ظلة مجازاً من باب اطلاق أحد الضدين على الآخر كتسمية الأرض بالسماء والعكس أو لمشابهة تلك الطبقة بالظلة التى فوقه صورة وحراً وضراً { ذَلِكَ } العذاب*<br />
{ يُخَوِّفُ اللهُ بِهِ عِبَادَهُ } ليجتنبوا ما يوقعهم فيه وقيل المراد بالعباد المؤمنون فقط اذا سمعوا حال الكفرة في الآخرة خافوا وأخلصوا . <br />
{ يَا عِبَادِي } باثبات الباء ساكنة وقرئ بحذفها* { فَاتَّقُونِ } خافون واحذروا عذابي عظة من الله ونصيحة قيل : وقوله { يا عبادي فاتقون } دليل على أن المراد بقوله عباده المؤمنون والنداء راجع الى ( فاتقون ) فالفاء زائدة أو الى ما قبله كما تقول : قام زيد فأبو بكر فالفاء عاطفة على ما قبل عطف انشائية فعلية على خبرية اسمية أو للاستئناف أو راجع محذوف معطوف عليه بالفاء أي ( اعملوا يا عبادي فاتقون ) . <br />
