{ قُلْ إِنْ } اي ما * { أَدْرِي أَقَرِيبٌ مَا تُوعَدُونَ } قريب مبتدأ وما فاعل أغناه عن الخبر أو قريب خبر وما مبتدأ { أمْ } متصلة عطفت الفعلية على الاسمية { يَجْعَلُ لَهُ رَبِّي } وقرأ غير نافع وابن كثير والي عمر وبإسكان الياء { أَمَداً } غاية غير قريبة لما سمعوا أن الإيعاد قالوا متى هذا الإيعاد فأجابهم بذلك أنه كائن لا محالة أما عاجلا وإما آجلا وإخفاء وقته لمصلحة . <br />
