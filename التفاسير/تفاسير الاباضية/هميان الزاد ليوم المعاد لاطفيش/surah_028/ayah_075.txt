{ وَنَزَعْنَا } أخرجنا . <br />
{ مِن كُلِّ أُمَّةٍ شَهِيداً } وهو رسولهم يشهد عليهم بما كانوا عليه من شرك وتوحيد . <br />
{ فَقُلْنَا } لهم . <br />
{ هَاتُوا بُرْهَانَكُمْ } على ما قلتم من الاشراك . <br />
{ فَعَلِمُوا } حينئذ . <br />
{ أَنَّ الحَقَّ } في الألوهية . <br />
{ وَضَلّ عَنْهُم } غاب عنهم غيبة الضائع . <br />
{ مَّا كَانُوا يَفْتَرُونَ } من الباطل من الأوثان التي يعبدونها . <br />
