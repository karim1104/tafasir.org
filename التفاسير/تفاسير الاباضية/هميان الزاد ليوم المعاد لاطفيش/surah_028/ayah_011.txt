{ وَقَالَتْ لأُخْتِهِ } واسمها مريم . <br />
{ قُصِّيهِ } اتبعي أثره حتى تعلمي خبره . <br />
{ فَبَصُرَتْ } أي الأخت . <br />
{ بِهِ } أي اتصل نظرها به ،  والباء للإلصاق المجازي وقرأ بعض بكسر الصاد . <br />
{ عَن جُنُبٍ } أي عن بعد أو باختلاص تنظر إليه كأنها لا تريده بالنظر ،  وقرىء بإسكان النون وقرىء عن جنابة أي بعد وعن جانبه . <br />
{ وَهُمْ لا يَشْعُرُونَ } أي والناس لا يشعرون انها أخته وأنها ترفيه . <br />
