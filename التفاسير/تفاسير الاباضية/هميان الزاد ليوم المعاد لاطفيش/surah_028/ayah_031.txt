{ وَأَنْ أَلْقِ عَصَاكَ } فألقاها واهتزت . <br />
{ فَلَمَّا رَآهَا تَهْتَزُّ } تتحرك . <br />
{ كَأَنَّهَا جَانٌّ } أي حية في الهيئة والخفة او في السرعة وقد مر ذلك . <br />
{ وَلَّىَ مُدْبِراً } حال مؤكدة لعاملها وهو ولي فان التولية والادبار بمعنى وهو الرجوع الى خلف او توليتك ظهرك لغيرك مع الذهاب وقيل مدبرا بمعنى هاربا استعمالا للعام في الخاص فالحال مؤسسة . <br />
{ وَلَمْ يُعَقِّبْ } لم يرجع اليها بعد توليه وادباره وقيل لم يلتفت وكان يراها تبلع الصخور والعظام والشجر العظام ويسمع صرير اسنانها والدخان خارج من ذلك . <br />
{ يَا مُوسَى } أي فقيل له يا موسى . <br />
{ أَقْبِلْ } أيتها . <br />
{ وَلا تَخَفْ إِنَّكَ مِنَ الآمِنِينَ } عن المخاوف فانه لا يخاف لدي المرسلون . <br />
