{ ضَرَبَ لَكُم مَّثَلاً مِّنْ أَنفُسِكُمْ } معشر المشركين اي منتزعا من احوال انفسكم وهي اقرب الامور اليكم ومن للابتداء وبين ذلك المثل بقوله . <br />
{ هَل لَّكُم مِّمَّا مَلَكَتْ أَيْمَانُكُم } من عبيدكم وامائكم ومن للتبعيض متعلق بمحذوف حال من ضمير الاستقرار . <br />
{ مِّن شُرَكَاءَ } من صلة في المبتدأ او في فاعل الجار والمجرور للتأكيد . <br />
{ فِيمَا رَزَقْنَاكُمْ } متعلق بشركاء او بالاستقرار او بلكم . <br />
{ فَأَنتُمْ فِيهِ سَوَاءٌ } فتكونوا أنتم وهم فيه سواء يتصرفون فيه كتصرفكم . <br />
{ تَخَافُونَهُمْ } ان تستبدوا فيه بتصرف وتدبير دونهم . <br />
{ كَخِيفَتِكُمْ أَنفُسَكُمْ } الخيفة مصدر للهيئة وفيه دليل على جواز اعمال المصدر الذي بالتاء ومصدر الهيئة في المفعول به الصريح الا ان قيل انفسكم مفعول لفعل محذوف دل عليه خيفتكم والمراد كما يخاف بعضكم بعضا ايها الاحرار في الشركة والارث والاستفهام انكار ونفي منسحب الى قوله { أَنفُسِكُمْ } اي اذا لم ترضوا ان يكون بعض مماليككم شركاء لكم فيما رزقناكم من الاموال مع انهم بشر مثلكم ومخلوقون مثلكم ومع ان الاموال في ايديكم معارة فكيف ترضون لرب الارباب ومالك الاحرار والعبيد ان تجعلوا بعض عبيده شركاء له وهم مخلوقون له والملك له بالتحقيق وقال الزجاج : المثل هو قوله { وهو أهون } اي ضرب لكم مثلا فيما يسهل ويصعب . <br />
{ كَذَلِكَ نُفَصِّلُ الآيَاتِ } نبينها بالتمثيل لأن التمثيل مما يكشف المعاني ويوضحها ويجعلها بمثابة ماله صورة محسوسة . <br />
{ لِقَوْمٍ يَعْقِلُونَ } يتدبرون بعقولهم في الامثال . <br />
