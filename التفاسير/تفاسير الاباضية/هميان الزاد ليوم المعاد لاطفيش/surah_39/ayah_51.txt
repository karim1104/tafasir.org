{ فَأَصَابَهُمْ سَيِّئَاتُ مَا كَسَبُواْ } ما كسبوه أو كسبهم أصابهم جزاء سيئاته أو السيئات الجزاء كما مر* { وَالَّذِينَ ظَلَمُواْ مِنْ هَؤُلآَءِ } المعاصرين لك يا محمد من أهل مكة وليس هذا دليلاً على أن المقصود بالانسان وما معه العموم ولا الخصوص و ( من ) للبيان أي وهم هؤلاء المعاصرون أو للتبعيض أي بعضهم* { سَيُصِيبُهُمْ سَيِّئَاتُ } أي جزاء* { مَا كَسَبُواْ } أو جزاء سيئات ما كسبوا كما أصاب من قبلهم وقد قحطوا سبع سنين وحبس عنهم الرزق وقتلت أشرافهم ببدر ولم يغنهم كسبهم شيئاً كما قال* { وَمَا هُم بِمُعْجِزِينَ } أي فائتين عذابنا <br />
