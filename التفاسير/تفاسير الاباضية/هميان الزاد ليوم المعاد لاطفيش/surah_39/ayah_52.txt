ثم مطروا سبع سنين وبسط لهم الرزق وقال الله لهم*<br />
{ أَوَ لَمْ } الهمزة بعد الواو أو داخلة على محذوف أي أفعلوا ذلك ولم* { يَعْلَمُواْ أَنَّ اللهَ يَبْسُطُ } يوسع* { الرِّزْقَ لِمَن يَشَآءُ } امتحاناً* { وَيَقْدِرُ } أي يقبض ويضيق عمن يشاء ابتلاء ولا باسط ولا قابض سواه* { إِنَّ فِى ذَلِكَ } الذي يحدثه من بسط وقدر كغيرهما { لأَيَاتٍ } دلائل على وجود الصانع* { لِّقَوْمٍ يُؤْمِنُونَ }<br />
