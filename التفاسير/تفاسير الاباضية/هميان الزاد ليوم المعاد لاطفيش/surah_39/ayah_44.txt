{ قُل للهِ } لا لغيره { الشَّفَاعَةُ جَمِيعاً } ليس منها شيء لغيره الا من أذن له فهو الأهل للعبادة دون من لا يملك شيئاً أقل قليلاً فضلاً عن الشفاعة ولا عقل له يميز* { لَّهُ } لا لغيره { مُلْكُ السَّمَوَاتِ وَالأَرْضِ } كله فلا يملك أحد شفاعة الا باذنه ورضاه* { ثُمَّ إِلَيْهِ } لا الى غيره* { تُرْجَعُونَ } يوم القيامة فله الملك في الدنيا والآخرة . <br />
