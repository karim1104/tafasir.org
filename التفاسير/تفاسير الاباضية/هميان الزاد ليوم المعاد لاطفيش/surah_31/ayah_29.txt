{ أَلَمْ تَرَ } الخطاب لمن يصلح خطابه . <br />
{ أَنَّ اللهَ يُولِجُ } يدخل . <br />
{ الَّليْلَ فِي النَّهَارِ وَيُولِجُ النَّهَارَ فِي الَّيْلِ } يزيد كلا منهما بما نص من الآخر . <br />
{ وسَخَّرَ الشَّمْسَ وَالقَمَرَ كُلٌّ } من الشمس والقمر . <br />
{ يَجْرِى } في فلكه . <br />
{ إِلَى أَجَلٍ مُّسَمىًّ } هو يوم القيامة والمسمى المحدود ولا ينقطع جريهما الى يوم القيامة وذلك قول الحسن وحينئذ ينقطع جريهما ويذهب ضوءهما . <br />
وقيل الأجل المسمى آخر السنة للشمس وآخر الشهر للقمر صرح بعض العلماء ان اللام في قوله { يَجْرِي لأَجَلٍ مُّسَمىُّ } بمعنى ( الى ) بدليل هذه الآية ونحوها . <br />
وذكر جار الله أن هذه الطريقة لا يسلكها الى بليد الطبع ضيق الفطن وان المعنى مع الى ان كلا يبلغ الاجل وينتهي اليه ومع اللام انه يجري لادراك اجل مسمى يجعل الجري مختصا بادراك اجل مسمى فاللام للتعليل حقيقة او مجازا وافعال الله تعلل بالاغراض على ما ارجحه لكثرة ادلته وتأويل الكثير خلاف الظاهر . <br />
{ وَأَن اللهَ بِمَا تَعْمَلُونَ خَبِير ذَلِكَ } المذكور الذي تعجز عنه الاحياء القادرون العالمون وكيف الجماد التي يدعونها آلهة من سعة العلم وشمول القدرة وعجائب الصنع واختصاص الباري بها . <br />
{ بِأَنَّ اللهَ } اي لأن الله . <br />
{ هُوَ الحَقُّ } الثابت الألوهية وغيره باطل . <br />
{ وَأَنَّ مَا يَدْعُونَ مِن دُونِهِ } من الأصنام وقرىء بالتحتية { يدعون } . <br />
{ البَاطِلُ } الزائل الذي لا يستحق العبادة ولا الالوهية المعدوم في حد ذاته لولا ان الله أوجده . <br />
{ وَأَنَّ اللهَ هُوَ العَلِيُّ الكَبِيرُ } مرتفع الشأن على كل شيء ومتصرف في كل شيء له الصفات العليا والأسماء الحسنى . <br />
