{ قَالَ رَبِّ انْصُرْنِي بِمَا كَذَّبُونِ قَالَ }  الله { عَمَّا قَلِيلٍ } الاصل عن ما ابدلت النون ميما فادغمت في ميم ما الزائدة وقليل مجرور بعن وانما زيدت للتأكيد معنى قلة المدة وتقصيرها ويجوز ان تكون ( ما ) نكرة موصوفة بقليل واقعة على الزمان اي عن زمان قليل . <br />
والاول ابلغ لأن فيه التأكيد والزمان غير فائت فيه لان ( قليل ) واقع على الزمان نعت لمحذوف اي عما زمان قليل وعن متعلقة ( يصبحون ) محذوف مدلولا عليه بجواب القسم اي ( يصبحون عما قليل نادمين ) والله { لَّيُصْبِحُنَّ } يصيرن { نَّادِمِينَ } على التكذيب لمعاينة العذاب لا متعلق بالجواب لان لام جواب القسم لها الصدر خلافا لبعض . <br />
