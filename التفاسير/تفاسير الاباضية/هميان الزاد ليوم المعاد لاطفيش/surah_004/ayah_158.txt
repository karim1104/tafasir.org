{ بَل رَّفَعَهُ اللَّهُ إِلَيْهِ وَكَانَ اللَّهُ عَزِيزاً حَكِيماً }<br />
{ بَلْ رَّفَعَهُ اللهُ إِلَيْهِ } : لأن مابعد العاطف لا يتقدم عليه ،  وهذه الجملة أيضا تأكيد لقوله : { فى شك } وكل ذلك تكذيب لهم . <br />
{ وَكَانَ اللهُ عَزِيزاً } : غالبا فى أمره لايرد عنه ،  ومنه الانتقام وقد انتقم منه بملك رومى يسمى نيطوس قتل منهم مقتلة عظيمة . <br />
{ حَكِيماً } : فى انجاء عيسى عليه السلام . <br />
