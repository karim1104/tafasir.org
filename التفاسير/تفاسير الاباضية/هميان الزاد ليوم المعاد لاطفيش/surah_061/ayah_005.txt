{ وَإِذَ } مفعول لاذكر قال جار الله : أو حين قال لهم ما قال كان كذا وكذا  ، { قَالَ مُوسَى لِقَوْمِهِ } بني اسرائيل  ، { يَقَوْمِ لِمَ تُؤْذُونَنِى } تضرونني بالعصيان والرمي بكونه ادر أي كبير الخصيين وتكذيبه وعبادة البقر وطلب رؤية الله وغير ذلك . <br />
{ وَقَد } للتحقيق { تَّعْلَمُونَ أَنِّى رَسُولُ اللهِ إِلَيْكُمْ } الواو للحال واليكم متعلق برسول ومن حق الرسول ان يعظم ولا يؤذى  ، { فَلَمَّا زَاغُوا } أي قوم موسى أي عدلوا عن الحق { أزَاغَ اللهُ قُلُوبَهُمْ } عن قبول الحق أو طبعها أو كثر ميلها عن الحق عقوبة عن الذنب بالذنب . <br />
{ وَاللهُ لا يَهْدِى القَوْمَ الفَاسِقِينَ } لا يوفقهم ذكر مقالة موسى ليحذر المؤمنون ما وقع فهي هؤلاء من العصيان . <br />
