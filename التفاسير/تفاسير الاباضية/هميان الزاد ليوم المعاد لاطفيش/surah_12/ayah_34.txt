{ فاسْتَجابِ لَه ربُّه } أي أجاب دعاءه ،  لأن قوله : { رب السجن أحب إلى } إلى قول : { من الجاهلين } بتضمن الشكوى إلى الله سبحانه وتعالى من حاله معهن ،  ولأن قوله : { وإلا تصرف } الخ فزع إلى الله سبحانه وتعالى إلى ألطاف الله وعصمته . <br />
{ فَصَرف عَنْه كَيدَهنَّ } بأن ثبته فاعتار السجن على اللذة المحرمة { إنَّه هُوا السَّميعُ } لدعاء الملتجئين { العَليمُ } بأحوالهم ،  وما يصلح لهم<br />
