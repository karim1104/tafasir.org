{ وَقِيلَ ادْعُوا شُرَكَاءَكُمْ } الأصنام التي تعبدونها وتزعمون انها شركاء الله . <br />
{ فَدَعَوْهُمْ } لشدة حيرتهم . <br />
{ فَلَمْ يَسْتَجِيبُوا لَهُمْ } لعجزهم عن الاجابة والنصر . <br />
{ وَرَأَوُا العَذَابَ } أبصروه . <br />
{ لَوْ أَنَّهُمْ كَانُوا } في الدنيا . <br />
{ يَهْتَدُونَ } للاسلام جواب لو محذوف اي ما ابصروه ويجوز كون لو للتمني ويقدر القول اي وقالوا ليتنا اهتدينا فيكون بين قالوا . <br />
و { لَوْ أَنَّهُمْ كَانُوا } الخ التفات السكاكي ويجوز ان يراد وانهم يهتدون اليوم لحيلة يدفعون بها العذاب . <br />
