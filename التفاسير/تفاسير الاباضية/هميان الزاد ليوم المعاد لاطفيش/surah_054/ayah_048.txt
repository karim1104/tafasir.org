{ يَوْمَ } مفعول اذكر أو ظرف للاستقرار باعتبار قوله سعر ان فسر بعذاب الآخرة ونارها أو متعلق بقول مقدر عامل في قوله ذوقوا مَسّ سقر . <br />
{ يُسْحَبُونَ } يجرون { فِى النُّارِ عَلَى وُجُوهِهِمْ } يقال لهم { ذُوا مَسَّ سَقَرَ } من سقرته النار أو صقرته حرقته أي ذوقوا ايها المكذبون حر النار وألمها فإن مسها سبب للتألم أو شبه أصابتها إياهم بالاحراق بمس الحيوان للآخر مسا موجعا . <br />
