{ أَكُفَّارُكُمْ } يا أهل مكة أو معشر العرب . <br />
{ خَيْرٌ مِّنْ أُوْلَئِكُمْ } الكفار المعدودين قوة وعدة في الدنيا أو أقل كفرا وعنادا يعني أن كفاركم مثل اولائكم الذين هم أقوام هود وصالح ونوح ولوط وفرعون بل شر منهم { أَمْ لَكُم بَرَآءَةٌ } من العذاب { فِى الزُّبُرِ } الكتب المقتدمة والاستفهام انكاري . <br />
