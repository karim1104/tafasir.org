{ بَلِ السَّاعَةِ } يوم القيامة { مَوْعِدَهُمْ } زمان وعد الله عذابهم اليه وما يحيق بهم في الدنيا فطلائع منه وقيل يهلك كفار آخر الأمة { وَالسَّاعَةُ أَدْهَى } أعظم بلية من كل هزم وقتل واشدد اهبة والداهية الامر العظيم الذي لا يهتدي للخلاص منه { وَأَمَرُّ } أشد مرارة من عذاب الدنيا قال الحسن : يعذب الله كفار آخر هذه الأمة عذابا لم تعذبه أمة وهو النفخة الأولى وقرأ سينهزم . <br />
