{ هُمُ } أي عبد الله ومن تبعه { الَّذِينَ يَقُولُونَ } لاصحابهم من الانصار { لا تُنفِقُوا عَلَى مَنْ عِندَ رَسُولِ اللهِ } جهجاه وغيره من الفقراء المهاجرين { حَتَّى يَنفَضُّوا } كي يتفرقوا عنه أو حتى للغاية أي فإذا تفرقوا فانفقوا عليهم وقرىء بضم الياء وكسر الفاء وتخفيف الضاد من انفض القوم إذا افنيت ازوادهم جمع زاد وقبح الله رأيهم بقوله { وللهِ } لا لغيره { خَزَائِنُ السَّمَاوَاتِ وَالأَرْضِ } فهو الرازق للمهاجرين وغيرهم وهو المانع المعطي { وَلَكِنَّ المُنَافِقِينَ لا يَفْقَهُونَ } ان الامر لله يقول للشيء كن فيكون  "  وروي انه صلى الله عليه وسلم لما نادى جهجاه للمهاجرين ونادى سنان يا للانصار خرج اليهم وقال  "  مابال دعوى الجاهلية  "  فلما اخبروه بالقصة قال :  "  دعوها فانها منثنة  "  . <br />
وقال ايضاً عبدالله في جملة كلامه ما حكى الله عنه بقوله . <br />
