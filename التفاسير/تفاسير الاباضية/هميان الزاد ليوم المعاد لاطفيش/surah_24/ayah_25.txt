{ يَوْمَئِذٍ يُوَفِّيهِمْ اللَّهُ } يجازيهم فقوله * { دِينَهُمُ } مفعول مطلق أي جزاءهم أو يوفيهم بمعنى يعطيهم ويحضر لهم فدينهم مفعول به { الحَقُّ } اي الواجب عليهم اي الذي استوجبوه بعملهم أو العدل أي جزاؤهم العدل . <br />
وقرئ بالرفع نعتا لله . <br />
وقرأ أبيّ وابن مسعود { يومئذ يوفيهم الله الحق دينهم } بنصب الحق وتقديمه فدينهم بدله . <br />
{ وَيَعْلَمُونَ أَنَّ اللَّهَ هُوَ الحَقُّ } الثابت الموجود وهو من اسماء الله تعالى أو هو العدل ضد الباطل فيقدر مضاف اواصله الحاق بوزن فاعل للنسب { المُبِينُ } الظاهر بالآيات أو الذي ظهر عدله ومن صفته ذلك لا تسقط عنه اساءة ولا إحسانة فحقه لان تجتنب محارمه ولا يشاركه غيره في الالوهية ولا يقدر على الثواب والعقاب سواءه . <br />
وقيل : معنى { المُبِينَ } انه يبين لهم حقيقة ما أوعدهم في الدنيا . <br />
