{ يَوْمَ يَبْعَثُهُمُ اللهُ } متعلق بمهين أو بعذاب عند من أجاز مثل هذا أو بما يتعلق به اللام أو مفعول لمحذوف أي أذكر وفي هذا تعظيم لليوم . <br />
{ جَمِيعاً } حال من الهاء أي مجتمعين قيل أو توكيد لها ورده ابن هشام لعدم اتصاله بضمير المؤكد .  { فَيُنَبِّئُهُم } أي يخبرهم { بِمَا عَمِلُوا } على رؤوس الأشهاد توبيخاً وتخذيلا وتشهيرا بحالهم حتى يتمنوا المسارعة إلى النار { أَحْصَاهُ اللهُ } حفظه تجزئه وتفصيلا وعددا لم يفته شيء { وَنَسُوهُ } لتهاونهم به أو لكثرته . <br />
{ وَاللهُ عَلَى كُلِّ شَىْءٍ شَهِيدٌ } لا يغيب عنه شيء . <br />
