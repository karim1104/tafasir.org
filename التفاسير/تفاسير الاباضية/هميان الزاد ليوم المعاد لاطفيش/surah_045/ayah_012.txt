{ اللهُ الَّذِي سَخَّرَ لَكُمُ الْبَحْرَ } مبتدأ وخبر أو خبر ونعت والمبتدأ محذوف أي ( هو الله ) الذي سخره لكم بأن جعله أملس السطح يعلوه نحو الخشب ويغوص فيه بقدر ما يتمكن*<br />
{ لِتَجْرِيَ الْفُلْكُ فِيهِ بِأَمْرِهِ } باذنه وتسخيره وأنتم فيها مع ما تريدون جملة* { وَلِتَبْتَغُواْ } تطلبوا* { مِن فَضْلِهِ } بالتجارة والغوص على اللؤلؤ والمرجان واستخراج اللحم الطري وغير ذلك من منافع البحر* { وَلَعَلَّكُمْ تَشْكُرُونَ } نعمة الله . <br />
