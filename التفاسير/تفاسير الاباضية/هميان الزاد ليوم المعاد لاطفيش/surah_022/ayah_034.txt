{ وَلِكُلِ أُمَّةٍ } لكل أهل دين قبلكم من المؤمنين أو المراد مطلق الامم مؤمنة أو مشركة فالمؤمنة نفعها نسكها والمشركة ان نسكت لم ينفعها { جَعَلْنَا مَنسَكاً } مصدر ميمي أي عبادة أو تقربا إلى الله بقربان يذبحونه أو حجا . <br />
وقرأ حمزة والكسائي بكسر السين على انه اسم مكان اي موضع طاعة وعبادة أو موضع ذبح أو حج وموضع الحج مكة ويجوز تفسير المفتوح بالمكان ايضا بل الفتح فيه هو القياس لان مضارعه مضموم العين فتح عين الماضي أو ضم ولم يرد مصدره الا بالفتح على القياس وظاهر بعض ورود الكسر فيه { لِّيَذْكُرُواْ اسْمَ اللَّهِ عَلَى مَا رَزَقَهُمْ مِّن بَهِيمَةِ الأَنْعَامِ } عند النحر أو الذبح هذا دليل على كون المنسك في امر الحج وخص الانعام لان غيرها لا يجوز في الحج ولا في قرابين الاولين . <br />
قيل : سميت البهيمة بهيمة لانها لا تتكلم وفي التعليل اشعار بان المقصود من المناسك تذكر المعبود . <br />
{ فَإِلهُكُمْ إِلَهٌ وَاحِدٌ } فلا تذكروا على الذبح الا اسمه ولا تعبدوا سواه { فَلَهُ أَسْلِمُوا } اخضعوا واخشعوا وانقادوا واخلصوا التقرب والذكر فانه الرازق لا غيره أو ( اسلموا ) بمعنى آمنوا وتعديته باللام لما مر { وَبَشِّرِ المُخْبِتِينَ } المتواضعين لله بالطاعة والاخلاص والخشوع والاطمئنان بالايمان و ( الخبت ) المطمئن من الارض بانخفاض واستواء . <br />
وعن الحسن ( المخبت ) الخاشع وقال عمر وابن أويس : ( المخبتون ) الذين لا يظلمون وإذا ظلموا لم ينتضروا . <br />
