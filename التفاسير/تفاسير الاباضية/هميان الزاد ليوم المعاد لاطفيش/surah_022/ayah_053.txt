{ لِّيَجْعَلَ } متلق بمحذوف اي مكن الله الشيطان من الالقاء ليجعل فاللام للتعليل أو ب ( ألقى ) فهو لام الصيرورة * { مَا يُلْقِي الشَّيْطَانُ } فيه تلويح إلى ان ما يلقيه امر ظاهر البطلان عند المحق والمبطل ولو كان المبطل يرتاب بادنى طرف شبهة * { فِتْنَةً } ابتلاء وله ابتلاء عباده بما شاء { لِلَّذِينَ فِي قُلُوبِهِم مَّرَضٌ } شك ونفاق { وَالقَّاسِيَةِ قُلُوبِهِم } عن قبول الحق وهم المشركون { وَإِنَّ الظَّالِمِينَ } اي الذين في قلوبهم مرض والقاسية قلوبهم والاصل وانهم ولكن يوضع الظاهر موضع الضمير قضاء بالظلم عليهم ظلم انفسهم وظلم غيرهم وليؤذن بالخير قبل مجيئه { لَفِي شِقَاقِ } خلاف * { بَعِيدٍ } طويل مع النبي صلى الله عليه وسلم والمؤمنين من حيث الايمان وهذه الجملة معترضة أو الشقاق الكون في شق الفساد . <br />
