{ وَلَقَدْ آتَيْنَا مُوسَى الْكِتَابَ } هو التوراة أو ( ال ) للجنس والمراد جميع كتبه* { فَاخْتُلِفَ } مبني للمفعول* { فِيهِ } نائب أي اختلف قومه فيه فمنهم مصدق به ومنهم مكذب كما اختلف قومك في كتابك { وَلوْلاَ كَلِمَةٌ } وجملة* { سَبَقَتْ مِن رَّبِّكَ } نعت لكلمة والخبر محذوف ومن أجاز ذلك خبر ما بعد لولا اذا كان مقيداً جعلها خبراً والكلمة سابقة الوعد بالقيامة وفصل الخصومة في يوم القيامة أو تقدير الآجال أو تأخير العذاب* { لَقُضِيَ بَيْنَهُمْ } في الدنيا فيما اختلفوا فيه وعجل هلاك المكذبين* { وَإِنَّهُمْ } أي اليهود* { لَفِي شَكٍّ مِّنْهُ } أي من كتاب موسى أو من موسى ويجوز عود اسم ( ان ) على الذين لا يؤمنون ومجرور من على القرآن* { مُرِيبٍ } أي موقع في الريبة وموجب للاضطراب<br />
