{ فَإِنِ اسْتَكْبَرُواْ } عن السجود لله وحده . <br />
{ فَالَّذِينَ عِندَ رَبِّكَ } وهم الملائكة* { يُسَبِّحُونَ لَهُ } يتلفظون له بألفاظ التقديس والتسبيح عندهم بمنزلة النفس من آدم فيما قيل* { بِاللَّيْلِ وَالنَّهَارِ } الماهية باستغراق أفرادها أي أبداً والياء بمعنى ( في ) ويدل على الأبدية قوله* { وَهُمْ لاَ يَسْأَمُونَ } لا يضجرون فيفتروا وما بعد الفاء قائم مقام الجواب لانه سبب والجواب مسبب أي { فَإِن اسْتَكْبَرُواْ } فدعهم فان الله أي لان الله لا يعدم ساجدين وعابدين بالاخلاص وهم الملائكة المقربون المنزهون له بالليل والنهار عن الأنداد والعندية ظرف مكان مجازي عبارة عن المنزلة والكرامة لا ظرف مكان حقيقي وفي ضمن ذلك حقارة لهؤلاء الكفار وقرئ بكسر الياء وهو لغة بكسر نون حرف المضارعة في غير الرباعي ولو ياء وبسطت ذلك في شرح اللامية . <br />
