{ وَإِذَا حُشِرَ } جمع للبعث* { النَّاسُ كَانُواْ } أي ما يعبدون من دون الله* { لَهُمْ } أي لعبادهم متعلق بكانوا أو بقوله* { أَعْدَآءً } أو نعت لهم فذلك أشقى شقاوة لانهم يتعبون أنفسهم بعبادتها في الدنيا ولا تستجيب لهم وتعاديهم في الآخرة وتجحد عبادتهم كما قال*<br />
{ وَكَانُواْ بِعِبَادَتِهِمْ كَافِرِينَ } جاحدين مكذبين بلسان الحال أو المقال بل يجمع كل معبود بعابده بين يدي الله فيخاصمه بالكلام وقيل الواو في قوله و ( كانوا ) للعبادة كقولهم { والله ربنا ما كنا مشركين }<br />
