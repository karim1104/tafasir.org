{ وَيَوْمَ } أي ويقال للذين كفروا يوم*<br />
{ يُعْرَضُ الَّذِينَ كَفَرُواْ عَلَى النَّارِ } يقال لهم ذلك وهم في النار والاعراض التعذيب . <br />
صدر السورة بتحقيق المبدأ وذكر في خواتمها اثبات المعاد وذلك وعيد لقريش وقيل ( يوم ) مفعول أذكر فيقدر لقوله* { أَلَيْسَ هَذَا بِالْحَقِّ } هذا القول والاشارة للعذاب والمراد توبيخهم والتهكم عليهم لاستهزائهم بالوعد والوعيد { وما نحن بمعذبين } { قَالُواْ بَلَى } هو حق* { وَرَبِّنَا } انه الحق اعتراض على أنفسهم بعد الانكار وتصديق حيث لا ينفع . <br />
وعن الحسن : ( انهم ليعذبون في النار وهم راضون يعرفون انه العدل )*<br />
{ قَالَ فَذُوقُواْ الْعَذَابَ بِمَا كُنتُمْ تَكْفُرُونَ } دليل على ان الاشارة للعذاب . <br />
قال القاضي : ما مصدرية والأمر للاهانة والتوبيخ وأقول قول الزمخشري والمعني للتهكم الخ عائد الى أليس هذا بالحق وكان القاضي أرجعه الى ( ذوقوا العذاب ) ثم ظهر لي انه يصح هذا أيضاً ويصح عوده للكل<br />
