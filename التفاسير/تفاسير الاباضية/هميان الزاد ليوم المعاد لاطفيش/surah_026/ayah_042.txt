{ لَنَا لأَجْراً } أي عظيما . <br />
{ إِن كُنَّا نَحْنُ } تأكيد لإسم كان أو بدل أو ضمير فصل . <br />
{ الغَالِبِينَ } قال : نعم وقرىء بكسر النون وهو لغة أي لكم الأجر كما قلتم وزاد لهم القربى والزلفى إغراء لهم الأجر كما كان على جملة فيها معنى الجواب جواب الشرط وهي { أَئِنَّ لَنَا لأَجْراً } . <br />
