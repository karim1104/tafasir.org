{ أَمْ } أي بل { تَأْمُرُهُمْ أَحْلاَمُهُمْ } أي عقولهم ،  { بِهَذَا } التناقض في قول يقولون شاعر أو مجنون أو ساحر وكانت قريش تدعي اهل الاحلام فازرى بعقولهم حيث لم يتميز لهم الحق أي لا احلام لهم وقيل المراد لا تأمرهم أحلامهم بهذا وأمر الاحلام مجاز عن ادائها إلى ذلك واجاز بعضهم رجوع الإشارة إلى ما هم عليه من عبادة الأصنام . <br />
{ أَمْ } بل ،  { هُمْ قَوْمٌ طَاغُونَ } مجازوزن الحد بعنادهم في الكفر وقرىء بل هم . <br />
