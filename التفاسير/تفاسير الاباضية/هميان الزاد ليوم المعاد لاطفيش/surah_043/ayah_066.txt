{ هَلْ } أي ما* { يَنظُرُونَ } أي ينتظرون كما نقول في قوله<br />
{ الى ربها ناظرة } أي منتظرة متشوقة الى رحمة ربها والواو لقريش*<br />
{ إِلاَّ السَّاعَةَ أَن تَأْتِيَهُم بَغْتَةً } فجأة ومصدر ( ما ) بعد ( ان ) بدل اشتمال من الساعة أي هل ينظرون الا الساعة اتيانها أي ما ينتظرون الا اتيان الساعة*<br />
{ وَهُمْ لاَ يَشْعُرُونَ } بوقت مجيئها أو هم غافلون عنها بالدنيا وانكارها وليس بتوكيد لمعنى البغتة لامكان اتيانها بغتة وهم فطنون<br />
