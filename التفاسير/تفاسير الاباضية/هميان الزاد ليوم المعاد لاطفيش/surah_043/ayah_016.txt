{ أَمِ اتَّخَذَ مِمَّا يَخْلُقُ بَنَاتٍ } { أَمِ } بمعنى همزة الانكار والتوبيخ قال بعض وللاضراب وقدر بعضهم مع ذلك القول أي أتقولون اتخذ وفي { أَمِ } أيضاً التعجب بالنظر الينا وذلك انهم لم يكفهم جعل الجزء له حتى جعلوه أخس وهو الأنثى { وَأًصْفَاكُم } أخلصكم { بِالْبَنِينَ } وتنكير بنات وتقديمهن وتعريف البنين وتأخيره لما مر فى أواخر الشورى وكأنه قيل هب ان اتخاذ الولد جائز فرضاً وتمثيلاً أما تستحيون من هذه القسمة الضيزى وهي ادعاء ايثاره اياكم بخير الجزءين وهو الذكر وتركه لنفسه شرهما وهم الأنثى اليت أنتم أنفر خلق الله عنها حتى انهم يقولون الله صاحب بنات فألحقوا البنات به فيقتلونهن وحتى انهم يشتد غمهم عند ولادتهن كما قال* { وَإِذَا بَشِّرَ أَحَدُهُم بِمَا ضَرَبَ لِلرَّحْمَنِ }<br />
