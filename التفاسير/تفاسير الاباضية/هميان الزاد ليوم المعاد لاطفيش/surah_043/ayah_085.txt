{ وَتَبَارَكَ } تعظم*<br />
{ الَّذِي لَهُ مُلْكُ السَّمَاوَات وَالأَرْضِ وَمَا بَيْنَهُمَا } كالهواء*<br />
{ وَعِندَهُ } لا عند غيره*<br />
{ عِلْمُ السَّاعَةِ } أي علم بالقيامة التى تقوم الساعة فيها*<br />
{ وَإِلَيْهِ } لا الى غيره* { تُرْجَعُونَ } للجزاء وفيه التفات عن الغيبة الى الخطاب للتهديد وذلك قراءة نافع وابن عامر وأبي عمرو وعاصم وروح وبعض قرأ للبناء للفاعل وقرأ الباقون بالمثناة تحت مبنيا للمفعول وقريء ( تحشرون ) بالتاء الفوقية . <br />
