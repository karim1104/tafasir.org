{ إِلاَّ الَّذِي فَطَرَنِي } أوجدنى وخلقنى فاني لا أبرأ منه بل أعبده لكونه أهلا للعبادة فانه الخالق فان جعلت ( ما ) مصدرية أو موصولاً اسمياً أو نكرة موصوفة واقعة على الأصنام وهى غير عاقلة ولا يعبدون الا اياها فالاستثناء منقطع وان جعلت موصولاً اسمياً أو نكرة موصوفة واقعة على ما يعلم وما لا يعلم وقلنا انهم يعبدون الله وغيره من الاصنام فالاستثناء متصل وأجازه الزمخشري كون الذي بدلاً مما أجازه ابدالاً في الاثبات بعد { إِلاَّ } ويجوز كمن { إِلاَّ } اسماً مضاف للذي بمعنى غير ( نعتاً ) لما النكرة الموصوفة وقيل { إِلاَّ } حرف والنعت هي وما بعدها ولا يصح معنى الابدال الا ان قلنا بعبادتهم لله والأصنام* { فَإِنَّهُ سَيَهْدِينِ } فى المستقبل وفى الآية الأخرى يهدينى والمراد ب ( يهدي ) الحال على استمرار الهداية فى الحال والاستقبال جميعاً والهداية المستقبلة ثبات على الهداية أو هداية لأشياء أخرى فان الطاعة لا تتناهى<br />
