{ فَسَخَّرْنَا لَهُ الرِّيحَ } وقرئ ( الرياح ) أي ( ذللها لطاعته ) اجابة له تنقله في كرسيه وجنوده من الأرض ثم { تَجْرِى بِأَمْرِهِ رُخَآءً } أي حال كونها لينة طيبة لا تزعزع ولا تدفع الدفع المفرط فتحمله غدوها شهراً ورواحها شهراً ،  وقيل مرخية له العنان لا تعصيه أو رخاء مصدر رخى أي رخاء { حَيْثُ أَصَابَ } أي حيث أراد وقصد . <br />
حكى الأصمعي : ( أصاب الصواب فأخطأ الجواب ) أو حيث صوب جنوده تقول صاب يصوب أي توجه يتوجه اصابه غيره أي وجهه<br />
