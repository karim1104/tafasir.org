{ خَاشِعَةً } حال من واو يدعون او من ولو يستطيعون ومعناه ذليلة { أَبْصَارُهُمْ } فاعل خاشعة أي لايرفعون ابصارهم { تَرْهَقُهُمْ } تغشاهم { ذِلَّةٌ } أي نوع عظيم من الذل يسجد المؤمنون يوم القيامة فيرفعون وجوههم اشد بياضا من الثلج وقد علاه النور وتسود وجوه الكفار والمنافقين ويغشاهم ذل وحسرة وندامة { وَقَدْ كَانُوا } في الدنيا في حال الصحة { يُدْعَوْنَ } بالنداء والاقامة على ما قدروا { إِلَى السُّجُودِ } الصلاة المفروضة { وَهُمْ سَالِمُونَ } قادرون قال كعب الاحبار والله ما نزلت هذه الآية الا في الذين يتخلفون عن الجماعة . <br />
