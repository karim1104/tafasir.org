{ الَّذِي جَعَلَ مَعَ اللهِ إِلَهاً آخَرَ } بدل من كل ومن أجاز نعت النكرة المخصصة بالمعرفة أجاز كون { الَّذِي } نعتاً لكل أو للكفار فجملة*<br />
{ فَأَلْقِيَاهُ فِي الْعَذَابِ الشَّدِيدِ } تكرير للتوكيد من التوكيد اللفظي المقرون بالفاء أو الذي مبتدأ خبره جملة ألقياه وقرنت بالفاء لتضمنه معنى الشرط أو مفعول لمحذوف يفسره ألقياه والفاء زائدة<br />
