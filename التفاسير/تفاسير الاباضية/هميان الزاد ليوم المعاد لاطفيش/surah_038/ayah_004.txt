{ وَعَجِبُوا } أي كفار مكة أو كفار قريش من { أَن جَآءَهُم مُّنذِرٌ مِّنْهُمْ } رسول بشر مثلهم مترب فيهم من أنفسهم ينذرهم ويخوفهم بالنار بعد البعث ويبطل تعديدهم للآلهة وهو النبي صلى الله عليه وسلم { وَقَالَ الْكَافِرُونَ } مقتضى الظاهر وقالوا باعادة الضمير للذين كفروا فأقام الظاهر مقام المضمر ليذكرهم باسم الكفر ما لهم واشعاراً بأن كفرهم جسرهم على قولهم { هَذَا سَاحِرٌ } فيما يظهره من معجزة كانشقاق القمر { كَذَّابٌ } فيما يقول الله سبحانه<br />
