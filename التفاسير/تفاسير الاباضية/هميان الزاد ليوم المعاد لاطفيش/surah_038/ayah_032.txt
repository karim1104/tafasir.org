{ فَقَالَ إِنِّى أَحْبَبْتُ حُبَّ الْخَيْرِ عَن ذِكْرِ رَبِّى } وانما عدي ( أحببت ) بعن لتضمينه معنى ( أنبت ) من النيابة وأصله بمعنى ( آثرت ) فيتعدى ب ( علي ) وقيل : لتضمنه معنى ( قعدت وتأخرت ) وعن بعض أن أحببت بمعنى ( لزمت ) وعلى كل فحب الخير مفعول وقيل مصدر تسبيبي أي مثل حب والخير المال الكثير والمراد به الخيل التى شغلته أو سمى الخيل ( خيرا ) بالراء أي مالاً لانها سببه لقوله صلى الله عليه وسلم  "  الخيل معقود فى نواصيها الخير الى يوم القيامة  "  والعرب تسمى الخيل خيراً ،  وفى مصحف ابن مسعود حب الخيل باللام والمراد ( بذكر ربي ) صلاة العصر أو الورد المذكور ،  وقرأ غير ابن كثير ونافع وابن عمرو باسكان الياء* { حَتَّى تَوَارَتْ } أي استترت الشمس بدليل ذكر العشي* { بِالْحِجَابِ } ما يحجبها عن الابصار وهو جبل دون قاف بمسيرة سنة تغرب الشمس من ورائه وهذا من بدع التفاسير وقيل : هو جبل قاف وقيل : ضمير توارت للصافنات ،  والحجاب الليل واصطبلاتها أي أماكن الدواب<br />
