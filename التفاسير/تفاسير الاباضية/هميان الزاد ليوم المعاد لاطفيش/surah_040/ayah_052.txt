{ يَوْمَ } بدل من ( يوم ) { لاَ يَنفَعُ } بالياء عند الكوفيين ونافع والفوقية المثناة عند الباقيين* { الظَّالِمِينَ مَعْذِرَتُهُمْ } مصدر ميمي بمعنى الاعتذار والقياس ان يفتح داله وما جاءت الا مكسورة أي يعتذرون ولا ينفع اعتذارهم أو لو جاءوا باعتذار لم ينفعهم ولكنهم لا يجيئون قال { ولا يؤذن لهم فيعتذورن } وانما لم تنفع لبطلانها لانهم يعتذرون عن الكفر وقد جاءتهم الرسل وتمكنوا من التصديق والعمل فأعرضوا { وَلَهُمُ اللَّعْنَةُ } البعد من رحمة الله* { وَلَهُمْ سُوءُ الدَّارِ } أي عذاب الدار الآخرة وقيل أشد عذابها وقيل جهنم<br />
