{ فَلَمَّا رَأَوْاْ بَأْسَنَا } عذابنا أو شدته . <br />
{ قَالُواْ آمَنَّا بِاللهِ وَحْدَهُ وَكَفَرْنَا بِمَا كُنَّا بِهِ مُشْرِكِينَ } من الاصنام { فَلَمْ يَكُ } لم يصح ولم يستقم* { يَنْفَعُهُمْ إِيمَانُهُمْ لَمَّا رَأَوْاْ بَأْسَنَا } لامتناع قبوله حينئذ وهكذا من عاين العذاب أو أمر من الآخرة عند الموت قال الزمخشري فاء ( فما أغنه ) نتيجة للاكثرية والاشدية وأما ( فلما جاءتهم ) فجر مجر البيان لقوله ( فَما أَغنى ) نحو رزق زيد المال فمنع المعروف فلم يحسن الى الفقراء وقوله لما رأوا تابع لقوله ( فَلَما جَاءتهم ) كأنه قال فكفروا { فَلمَّا رَأَوا بأسنا آمَنُوا } فكذلك<br />
