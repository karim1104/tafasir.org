{ مِن دُونِ اللهِ قَالُواْ } أي يقولون* { ضَلُّواْ عَنَّا } فقدناهم فلم نرهم وذلك قبل أن تقرن بهم آلهتهم أو بعده ولكن ضلوا عنهم اذ وبخوا وهم مقرونون بهم لكن لما لم ينفعوهم فكأنهم ضالون عنهم والمراد أين شركاؤكم فيشفعون لكم*<br />
{ بَلْ لَّمْ نَكُن نَّدْعُواْ مِن قَبْلُ شَيْئاً } اضطراب وقع الى الكذب وقيل لم ندع شيئاً نافعاً بل شيئاً لا يعتد به وقيل ضاعت عبادتنا فكأنا لم ندع شيئاً أي تبين لنا بطلان ذلك ثم تحضر آلهتهم ان قلنا غابت انكم وما الخ* { كَذَلِكَ } أي اضلالا ثابتاً كذلك الضلال الذي ضلت آلهتهم* { يُضِلُّ اللهُ الْكَافِرِينَ } عما ينفعهم في الآخرة أو يضلهم عن آلهتهم حتى لو طلبوها وطلبتم أن تطالبوا لم يتصادفوا بالفاء لا بالقاف<br />
