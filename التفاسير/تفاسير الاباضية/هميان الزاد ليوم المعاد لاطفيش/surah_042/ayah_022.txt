{ تَرَى } ببصرك أو بقلبك بعد رؤية البصر وقبلها والاول أنسب . <br />
{ الظَّالِمِينَ مُشْفِقِينَ } خائفين يوم القيامة حيث لا ينفع الخوف*<br />
{ مِمَّا كَسَبُواْ } من الشرك والأعمال القبيحة ( وما ) مصدرية أي من كسبهم* { وَهُوَ } عائد الى ( ما كسبوا ) على تقدير مضاف أي جزاء ما كسبوا أو عائد الى الجزاء أو العذاب دل عليه المقام* { وَاقِعٌ بِهِمْ } ولا تنفعهم شفاعتهم حينئذ والباء للالصاق أي متصل بهم أو بمعنى على . <br />
{ وَالَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ فِي رَوْضَاتِ الْجَنَّاتِ } الجنة كلها حسنة والمواضع التى تخصص بها المؤمنون أحسن من المواضع المشتركين فيها فهى روضات الجنات أي أطيب بقاعها وأنزهها وعلى طريقة هؤلاء تجعل هذه المواضع التي هي أحسن لمن جمعوا بين القول والعمل وما دونها للآتين بالقول فقط وهذا لا يصح عندنا معشر الاباضية ولك أن تقول للجامع بين القول والأعمال الكثيرة وما دونها للجامع بينها وبين الأعمال القليلة أو لمن مات غير عامل وهو واف بدين الله مثل مشرك أسلم فمات وبالغ واف جنَّ قيل العمل*<br />
{ لَهُم مَّا يَشَآءُونَ عِندَ رَبِّهِمْ } وتعلق بما تعلق به لهم وهو الاستقرار ولو علق بلهم لنيابته عن الاستقرار لجاز { ذَلِكَ } الذي ذكر المؤمنين*<br />
