{ بَلْ قَالُواْ إِنَّا وَجَدْنَآ آبَآءَنَا عَلَى أُمَّةٍ } بضم الهمزة وقرئ بكسرها والمعنى على كل حال هو الملة والدين وقال الطبري : ( الطريقة ) والمراد ملة الشرك ودينه وطريقه وتغلبت الاسمية عليهما ويجوز البقاء على الأصل فالأمة بالضم الطريقة التى تؤم أي تقصد كالدخلة للمدخول اليه والرحلة للمرحول اليه وبالكسر الحالة التى يكون عليها من هو ( آم ) أي قاصد وقيل المراد النعمة وقيل : هى والحال الحسنة . <br />
{ وَإِنَّا عَلَى آثَارِهِم مُّهْتَدُونَ } آثار جمع أثر وهو أثر نحو القدم ( وعلى ) متعلقة ب { مُّهْتَدُونَ } أو حال من المستتر فيه ( ومهتدون ) خبر ان أو بمحذوف خبر أول أي ثابتون أو ماشون على اثرهم( ومهتدون ) خبر ثان أي لم نخط ملتهم وهى عبادة غير الله والقول بأن الملائكة بنات الله وبأن الله راض ونحو ذلك وهم على هدى فانا نهتدي بهداهم وما لهم من حجة عقلية ولا نقلية وانما احتجوا بالتقليد وفى الآية عيب التقليد ويجوز كون { مُّهْتَدُونَ } بمعنى ( متبعون ) وهو اسم فاعل على كل حال أصله مهتديون نقلت ضمة الياء لثقلها الى الدال بعد سلب كسرها فالتقى ساكنان حذف الأول وهو الياء وسلي النبى صلى الله عليه وسلم وضرب له مثلاً بقوله . <br />
{ وَكَذَلِكَ مَآ أَرْسَلْنَا مِن قَبْلِكَ فِي قَرْيَةٍ مِّن نَّذِيرٍ }<br />
