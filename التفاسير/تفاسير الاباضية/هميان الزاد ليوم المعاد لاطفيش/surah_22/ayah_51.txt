{ وَالَّذِينَ سَعَواْ فِي آيَاتِنَا } القرآن بالابطال والرد . <br />
يقال : ( سعى زيد في امر فلان ) اي اصلحه أو افسده بسعيه { مُعَاجِزِينَ } حال مقارنة أي مسابقين لنا بظنون انهم يبطلون كلامنا بقولهم : ( انه سحر ) مثل أو يشاقوننا بانكارهم البعث والعقاب أو انهم يكيدون الاسلام ويتم كيدهم والحق يقتضي عجزه يقال عاجزه اي سابقه لان كلا في طلب اعجاز الآخر عن اللحوق به أو المعنى متراخين عن الايمان وهو قول مجاهد أو مثبطين للناس عنهم . <br />
وقرأ ابن كثير وابو عمرو ( معجزين ) على انه حال مقدرة اي يقدرون انهم سيعجزون الآيات والمؤمنين أو مقارنة اي ينسبونهم إلى العجز . <br />
وقيل : انما قرئ ( معجزين ) بالتشديد { أُوْلَئِكَ أَصْحَابُ الجَحِيمِ } النار الموقدة أو دركة مخصوصة . <br />
