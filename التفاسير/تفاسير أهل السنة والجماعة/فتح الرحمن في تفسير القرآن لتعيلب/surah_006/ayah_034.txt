{  وَلَقَدْ كُذّبَتْ } تسلية لرسول الله صلى الله عليه وسلم وهذا دليل على أن قوله :  {  فَإِنَّهُمْ لاَ يُكَذّبُونَكَ } [ الأنعام :  33 ] ليس بنفي لتكذيبه ،  وإنما هو من قولك لغلامك :  ما أهانوك ولكنهم أهانوني {  على مَا كُذّبُواْ وَأُوذُواْ } على تكذيبهم وإيذائهم {  وَلاَ مُبَدّلَ لكلمات الله } لمواعيده من قوله :  {  وَلَقَدْ سَبَقَتْ كَلِمَتُنَا لِعِبَادِنَا المرسلين إِنَّهُمْ لَهُمُ المنصورون } [ الصافات :  171 ] {  وَلَقدْ جَآءَكَ مِن نَّبَإِ المرسلين } بعض أنبائهم وقصصهم وما كابدوا من مصابرة المشركين .
