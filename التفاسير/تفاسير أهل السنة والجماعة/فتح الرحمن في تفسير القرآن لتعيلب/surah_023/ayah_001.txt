بِسْمِ اللَّهِ الرَّحْمَانِ الرَّحِيمِ<br />
{  قَدْ أَفْلَحَ الْمُؤْمِنُونَ {  1 ) الَّذِينَ هُمْ فِي صَلَاتِهِمْ خَاشِعُونَ {  2 ) وَالَّذِينَ هُمْ عَنِ اللَّغْوِ مُعْرِضُونَ {  3 ) }<br />
{  أفلح } فاز ونجا وبقي في النعيم . <br />
{  المؤمنون } المصدقون بالله وملائكته وكتبه ورسله والآخرة والعاملون بمقتضى التصديق . <br />
/خ1
