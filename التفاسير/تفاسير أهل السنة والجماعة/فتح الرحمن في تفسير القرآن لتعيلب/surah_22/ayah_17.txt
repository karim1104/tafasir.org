{  إِنَّ الَّذِينَ آَمَنُوا وَالَّذِينَ هَادُوا وَالصَّابِئِينَ وَالنَّصَارَى وَالْمَجُوسَ وَالَّذِينَ أَشْرَكُوا إِنَّ اللَّهَ يَفْصِلُ بَيْنَهُمْ يَوْمَ الْقِيَامَةِ إِنَّ اللَّهَ عَلَى كُلِّ شَيْءٍ شَهِيدٌ {  17 ) أَلَمْ تَرَ أَنَّ اللَّهَ يَسْجُدُ لَهُ مَنْ فِي السَّمَاوَاتِ وَمَنْ فِي الْأَرْضِ وَالشَّمْسُ وَالْقَمَرُ وَالنُّجُومُ وَالْجِبَالُ وَالشَّجَرُ وَالدَّوَابُّ وَكَثِيرٌ مِنَ النَّاسِ وَكَثِيرٌ حَقَّ عَلَيْهِ الْعَذَابُ وَمَنْ يُهِنِ اللَّهُ فَمَا لَهُ مِنْ مُكْرِمٍ إِنَّ اللَّهَ يَفْعَلُ مَا يَشَاءُ {  18 ) } . <br />
{  الذين هادوا } اليهود المنتسبون إلى ملة موسى عليه السلام .  {  الصابئين } القوم الذين يعبدون النجوم ،  والذين يعبدون الملائكة . <br />
{  النصارى } المنتسبون إلى ملة عيسى عليه السلام . <br />
{  المجوس } عبدة النار والثانوية الذين يدعون للعالم أصلين :  نور وظلمة . <br />
{  الذين أشركوا } الذين ادعوا أن لله تعالى شركاء ،  وعبدوا من دونه الأصنام ونحوها . <br />
{  يفصل } يقضي ويحكم ،  أو يصير هؤلاء إلى مستقر غير مستقر أولئك . <br />
