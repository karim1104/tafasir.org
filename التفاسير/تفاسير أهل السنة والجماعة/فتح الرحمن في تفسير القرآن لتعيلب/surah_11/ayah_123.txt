{  وَللَّهِ غَيْبُ السماوات والأرض } لا تخفى عليه خافية مما يجري فيهما ،  فلا تخفى عليه أعمالكم {  وَإِلَيْهِ يُرْجَعُ الأمر كُلُّهُ } فلا بدّ أن يرجع إليه أمرهم وأمرك ،  فينتقم لك منهم {  فاعبده وَتَوَكَّلْ عَلَيْهِ } فإنه كافيك وكافلك {  وَمَا رَبُّكَ بغافل عَمَّا تَعْمَلُونَ } وقرىء :  «تعملون » بالتاء :  أي أنت وهم على تغليب المخاطب . <br />
