{  الفواحش } ما تفاحش قبحه أي تزايد .  وقيل :  هي ما يتعلق بالفروج {  والإثم } عام لكل ذنب .  وقيل :  شرب الخمر {  والبغى } الظلم والكبر ،  أفرده بالذكر كما قال :  {  وينهى عَنِ الفحشاء والمنكر والبغى } .  {  مَا لَمْ يُنَزّلْ بِهِ سلطانا } فيه تهكم ،  لأنه لا يجوز أن ينزل برهاناً بأن يشرك به غيره {  وَأَن تَقُولُواْ عَلَى الله } وأن تتقوّلوا عليه وتفتروا الكذب من التحريم وغيره . <br />
