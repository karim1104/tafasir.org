{  فَلَنَسْئَلَنَّ الذين أُرْسِلَ إِلَيْهِمْ } {  أُرْسِلَ } مسند إلى الجار والمجرور وهو {  إِلَيْهِمْ } ومعناه :  فلنسألنّ المرسل إليهم وهم الأمم ،  يسألهم عما أجابوا عنه رسلهم ،  كما قال :  {  وَيَوْمَ يناديهم فَيَقُولُ مَاذَا أَجَبْتُمُ المرسلين } [ القصص :  65 ] ويسأل المرسلين عما أجيبوا به ،  كما قال :  {  يَوْمَ يَجْمَعُ الله الرسل فَيَقُولُ مَاذَا أُجِبْتُمْ } [ المائدة :  109 ] .
