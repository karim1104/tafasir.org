{  سخرها عليهم سبع ليال وثمانية أيام حسوما فترى القوم فيها صرعى كأنهم أعجاز نخل خاوية ( 7 ) } . <br />
سلطها الله تعالى عليهم بقدرته سبع ليال وثمانية أيام متتابعة .  أو {  حسوما } بمعنى :  مستأصلة . <br />
{  فترى القوم فيها صرعى } لو كنت شاهدا لرأي كيف صرعت القوم في تلك الليالي والأيام الثمانية . <br />
{  كأنهم أعجاز نخل خاوية } فصيرتهم مثل أصول النخل إذا خلت بليّ وفسادا .
