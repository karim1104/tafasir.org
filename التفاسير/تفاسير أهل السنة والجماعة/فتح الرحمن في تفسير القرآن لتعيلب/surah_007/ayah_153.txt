{  والذين عَمِلُواْ السيئات } من الكفر والمعاصي كلها {  ثُمَّ تَابُواْ } ثم رجعوا {  مِن بَعْدِهَا } إلى الله واعتذروا إليه {  وَءامَنُواْ } وأخلصوا الإيمان {  إِنَّ رَبَّكَ مِن بَعْدِهَا } من بعد تلك العظائم {  لَغَفُورٌ } لستور عليهم محاء لما كان منهم {  رَّحِيمٌ } منعم عليهم بالجنة .  وهذا حكم عام يدخل تحته متخذو العجل ومن عداهم .  عظَّم جنايتهم أو لا ثم أردفها تعظيم رحمته ،  ليعلم أن الذنوب وإن جلت وعظمت فإن عفوه وكرمه أعظم وأجلّ ،  ولكن لا بدّ من حفظ الشريطة :  وهي وجوب التوبة والإنابة ،  وما وراءه طمع فارغ وأشعبية باردة ،  لا يلتفت إليها حازم . <br />
