{  لكن الرسول } أي إن تخلف هؤلاء فقد نهد إلى الغزو من هو خير منهم وأخلص نية ومعتقداً ،  كقوله :  {  فَإِن يَكْفُرْ بِهَا هَؤُلاء فَقَدْ وَكَّلْنَا بِهَا قَوْماً } [ الأنعام :  89 ] ،  {  فَإِنِ استكبروا فالذين عِندَ رَبّكَ } [ فصلت :  38 ] .  {  الخَيْرَاتِ } تتناول منافع الدارين لإطلاق اللفظ .  وقيل :  الحور ،  لقوله :  {  فِيهِنَّ خيرات } [ الرحمن :  70 ] .
