{  سبحان الله عما يصفون } :  تنزه وتقدس عن الذي وصفه به المبطلون الملحدون . <br />
{  سبحان الله } :  تنزه مولانا المعبود بحق وتقدس وتبرأ ، {  عما يصفون } :  عما يصفونه به عز وجل من نسبة الولد إليه :  {  وأنه تعالى جد ربنا ما اتخذ صاحبة ولا ولدا } تعالى مقامه أن يتخذ زوجة أو ذرية :  {  لم يلد ولم يولد .  ولم يكن له كفوا أحد } . <br />
