{  مِن بَعْدِهِ } من بعد نوح {  رُسُلاً إلى قَوْمِهِمْ } يعني هوداً وصالحاً وإبراهيم ولوطاً وشعيباً {  فَجَاءوهُم بالبينات } بالحجج الواضحة المثبتة لدعواهم {  فَمَا كَانُواْ لِيُؤْمِنُواْ } فما كان إيمانهم إلاّ ممتنعاً كالمحال لشدّة شكيمتهم في الكفر وتصميمهم عليه {  بِمَا كَذَّبُواْ بِهِ مِن قَبْلُ } يريد أنهم كانوا قبل بعثة الرسل أهل جاهلية مكذبين بالحق .  فما وقع فصل بين حالتهم بعد بعثة الرسل وقبلها ،  كأن لم يبعث إليهم أحد {  كَذَلِكَ نَطْبَعُ } مثل ذلك الطبع المحكم نطبع {  على قُلوبِ المعتدين } والطبع جار مجرى الكناية عن عنادهم ولجاجهم ،  لأنّ الخذلان يتبعه .  ألا ترى كيف أسند إليهم الاعتداء ووصفهم به . <br />
