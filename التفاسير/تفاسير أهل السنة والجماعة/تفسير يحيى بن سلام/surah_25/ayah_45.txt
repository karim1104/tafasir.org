قوله :{ ألم تر إلى ربك كيف مد الظل } ( 45 ) أي ألم تر كيف مد ربك الظل .  { ولو شاء لجعله ساكنا }( 45 )<br />
وحدثنا الحسن بن دينار عن الحسن قال :{ ألم تر إلى ربك كيف مد الظل } قال : مده الله من حين طلع الفجر إلى أن تطلع الشمس . { ولو شاء لجعله ساكنا } أي لا يزول . <br />
قال :{ ثم جعلنا الشمس عليه } ( 45 ) أي على الظل .  { دليلا } ( 45 ) فظللت الشمس كل شيء .  { ثم قبضناه } ثم قبضنا ذلك الظل .  { إلينا قبضا يسيرا } ( 46 ) علينا ،  كقوله :{ إن ذلك على الله يسير }{[3309]} .  وقال السدي : { قبضا يسيرا } يعني خفيا .  وقال ابن مجاهد عن أبيه ،  ساكنا ،  لا تصيبه الشمس ولا يزول . {[3310]} { ثم جعلنا الشمس عليه دليلا }( 45 ) تحويه .  { ثم قبضناه }( 46 ) حوى الشمس إياه . <br />
قال يحيى : وذلك حين يقوم العمود نصف النهار حين لا يكون ظل ،  فإذا زالت الشمس رجع الظل فازداد حتى تغيب الشمس .
