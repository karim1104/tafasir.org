{ إن هذا }( 137 ) أي الذي جئتنا به .  { إلا خلق الأولين }( 137 ) في تفسير الحسن . <br />
[ عن أبيه ]{[3554]} ( قال ){[3555]} ( و ){[3556]} ( حدثني ){[3557]} إسماعيل بن مسلم قال : اختلفت أنا ومالك بن دينار في هذا الحرف فقلت [ أنا ]{[3558]} : { إن هذا إلا خلق الأولين } .  وقال مالك [ بن دينار ]{[3559]} : { خلق الأولين } .  فأتيت الحسن فسألته فقال : { إن هذا إلا  ( خلق ){[3560]} الأولين } .  ( قال ) :{[3561]} ( خلقهم ){[3562]} ( الكذب ){[3563]} . <br />
وقال السدي : ( ( إلا خلق ){[3564]} إني الأولين ) يعني تخلق الأولين وتخرّصهم للكذب . <br />
[ وعن ]{[3565]} سعيد عن قتادة قال : { إن هذا إلا ( خلق ){[3566]} الأولين } أي هكذا كان الناس قبلنا يعيشون ما عاشوا ثم يموتون ،  ولا بعث عليهم ولا حساب{[3567]} . <br />
قال يحيى : يعنون أن هكذا كان [ الخلق ]{[3568]} قبلنا ،  ونحن مثلهم . <br />
وبعضهم يقول : { خلق الأولين } دين الأولين ،  ويعنون ما هم عليه من ( شرك ){[3569]} .
