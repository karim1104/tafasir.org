قوله : { ولو اتبع الحق أهواءهم }( 71 ) أهواء المشركين .  { لفسدت }( 71 ) يعني لهلكت .  { السماوات والأرض ومن فيهن } ( 71 ) . <br />
وتفسير الحسن : لو كان الحق في أهوائهم ،  لوقعت أهواؤهم على هلاك السماوات والأرض ومن فيهن . <br />
وقال بعضهم : الحق هاهنا : الله ،  كقوله : { وتواصوا بالحق }{[2981]} .  عني بالحق الله { وتواصوا بالصبر } ( على ){[2982]} فرائضه . <br />
قال : { بل آتيناهم بذكرهم } ( 71 ) بشرفهم ،  شرف لمن آمن به . <br />
قال السحن وقتادة : يعني القرآن ،  أنزلنا عليهم فيه ما يأتون ،  وما يتقون ،  وما يحرمون ،  وما يحلون .  { فهم عن ذكرهم } ( 71 ) عما بينا لهم .  { معرضون } ( 71 )وقال قتادة : معرضون عن القرآن . <br />
وقال السدي : { بل أتيناهم بذكرهم } : بشرفهم { فهم عن ذكرهم } يعني عن شرفهم { معرضون } . <br />
قال يحيى : سمعت سفيان الثوري يذكر في هذه الآية :{ لقد أنزلنا إليكم كتابا فيه ذكركم }{[2983]} : فيه شرفكم .
