{ وإذا رأى الذين أشركوا شركاءهم } ( 86 ) ،  إذا رأوا الشياطين الذين كانوا يضلونهم في الدنيا ،  يعرف كل إنسان شيطانه .  { قالوا } ( 86 ) ،  يقول بنو آدم . <br />
{ ربنا هؤلاء شركاؤنا } ( 86 ) ،  يعنون : بني إبليس . { الذين كنا ندعوا من دونك } ( 86 ) ؛ لأنهم هم الذين دعوهم إلى عبادة الأوثان . <br />
قال : { وإن يدعون إلا شيطانا مريدا } {[222]} ،  [ وقال قتادة : { الذين كنا ندعوا من دونك } .  .  .  ]{[223]} .  { فألقوا إليهم القول } ( 86 ) ،  فألقى بنو آدم إلى بني{[224]} إبليس القول ،  حدثوهم .  [ تفسير مجاهد ،  ذكره عاصم بن حكي وابن مجاهد ]{[225]} فقالوا لهم : { إنكم لكاذبون } ( 86 ) ،  أي : إنكم كذبتمونا في الدنيا وغررتمونا .
