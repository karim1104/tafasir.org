بسم الله الرحمان الرحيم<br />
قوله : { أتى أمر الله } ( 1 ) يعني القيامة ،  وهو تفسير السدي .  { فلا تستعجلوه } ( 1 ) .  قال الحسن : هذا جواب من الله لقول المشركين للنبي : { ائتنا بعذاب الله }{[5]}  وقولهم : { عجل لنا قطنا }{[6]}  وأشباه ذلك فقال : { يستعجلونك بالعذاب } {[7]}<br />
وقال : { أتى أمر الله فلا تستعجلوه } أي إن العذاب آت قريب ،  وبعضهم يقول : استعجلوا بعذاب الآخرة وذلك منهم تكذيب واستهزاء ،  فأنزل الله : { أتى أمر الله فلا تستعجلوه } . <br />
قوله : { سبحانه } ( 1 ) ينزه نفسه عما يقول المشركون .  { وتعالى عما يشركون } ( 1 ) تعالى : من العلو ،  يرفع نفسه عما يشركون به .
