{ وتحمل أثقالكم إلى بلد لم تكونوا بالغيه } ( 7 ) إلى البلد الذي تريدونه .  وفي تفسير الحسن : إنها الإبل والبقر . <br />
{ إلا بشق الأنفس } ( 7 ) لولا أنها تحمل أثقالكم لم تكونوا بالغي ذلك البلد إلا بمشقة ( على أنفسكم ){[17]} .  وقال سعيد عن قتادة : إلا بجهد الأنفس . <br />
قال : { إن ربكم لرؤوف رحيم } ( 7 ) يقول : فبرأفة الله ورحمته سخر لكم هذه الأنعام وهي للكافر رحمة الدنيا : المعايش والنعم التي رزقه الله .
