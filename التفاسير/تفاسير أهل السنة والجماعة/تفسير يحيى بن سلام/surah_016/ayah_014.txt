قوله : { وهو الذي سخ البحر } ( 14 ) خلف البحر .  { لتأكلوا منه لحما طريا } ( 14 )<br />
قال قتادة : حيتان البحر .  { وتستخرجوا منه حلية تلبسونها } ( 14 ) اللؤلؤ{[29]} .  { وترى الفلك } ( 14 ) السفن .  { مواخر فيه } ( 14 ) . <br />
سعيد عن قتادة قال : يعني سفن البحر مقبلة ومدبرة تجري فيه بريح واحدة{[30]} .  وقال مجاهد : ولا تمخر الريح من السفن إلا العظام{[31]} .  وبعضهم يقول : { مواخر فيه } يعني شقها الماء في وقت جريها{[32]} .  قال : { ولتبتغوا من فضله } ( 14 ) .  قال مجاهد : طلب التجارة في السفن .  { ولعلكم تشكرون } ( 14 ) ولكي تشكروا ،  هي مثل قوله : { لعلكم تسلمون }{[33]} .
