قوله [ عز وجل ]{[5430]} : { ظهر الفساد في البر والبحر }( 41 ) يعني قحط المطر وقلة النبات . <br />
{ في البر } يعني في البادية ،  { والبحر } يعني به العمران والريف .  [ وهذا ]{[5431]} تفسير السدي . <br />
قال : { بما كسبت أيدي الناس ليذيقهم بعض الذي عملوا لعلهم يرجعون }( 41 )<br />
[ الفساد ،  الهلاك ،  يعنى من أهلك من الأمم السابقة بتكذيبهم رسلهم كقوله : { وكلا تبرنا تتبيرا }{[5432]} أي أفسدنا { لعلهم يرجعون } ]{[5433]} ( يعني ){[5434]} لعل من بعدهم أن يرجعوا عن شركهم إلى الإيمان [ ويتعظون بهم .  و ]{[5435]} قوله : { في البر والبحر } :<br />
[ حدثني ]{[5436]} قرة بن خالد عن الحسن قال : أهلكهم الله ( تبارك وتعالى ){[5437]} بذنوبهم في بر الأرض وبحرها بأعمالهم الخبيثة . <br />
{ لعلهم يرجعون }( 41 ) [ قال : يرجع من كان بعدهم ويتعظون بهم ]{[5438]} . <br />
قال يحيى : كقوله : { فكلا أخذنا بذنبه فمنهم من أرسلنا عليه حاصبا } يعني قوم لوط الذين كانوا خارجا من المدينة وأهل السفر منهم .  { ومنهم من أخذته الصيحة } ثمود .  { ومنم من خسفنا به الأرض } قوم لوط ،  أصاب مدينتهم الخسف ،  وقارون { ومنهم من أغرقنا }{[5439]} قوم نوح ، {[5440]} وفرعون وقومه . <br />
وقال مجاهد : { ظهر الفساد في البر } قتل ابن آدم أخاه { والبحر } اخذ الملك السفن غصبا{[5441]} .
