قال : { يوم يدعوكم } ( 52 ) من قبوركم .  ينادي صاحب الصور ينفخ فيه .  [ قال السدي : يوم يناديكم إسرافيل ]{[967]} .  { فتستجيبون بحمده } ( 52 ) بمعرفته في تفسير الحسن وقتادة{[968]} .  وقال قتادة : بمعرفته وطاعته يومئذ{[969]} . <br />
قال يحيى : والاستجابة [ منهم ]{[970]} خروجهم من قبورهم إلى الداعي صاحب الصور إلى بيت المقدس .  { وتظنون } ( 52 ){[971]} في الآخرة .  { إن لبثتم } ( 52 ) في الدنيا .  { إلا قليلا } ( 52 ) مثل قوله : { قالوا لبثنا يوما أو بعض يوم }{[972]} تصاغرت الدنيا عندهم .  ومثل قوله : { ويوم تقوم الساعة يقسم المجرمون } المشركون .  { ما لبثوا } في الدنيا ،  { غير ساعة } .  قال الله : { كذلك كانوا يؤفكون } ( 55 ){[973]} يصدون عن الهدى .  { وقال الذين أوتوا العلم والإيمان لقد لبثتم في كتاب الله إلى يوم البعث }{[974]} وهي مقدمة يقول : { وقال الذين أوتوا العلم } في كتاب الله{[975]} { والإيمان لقد لبثتم } إلى يوم البعث .  وقال في الآية الأولى : { إن لبثتم إلا قليلا } أي إن الذين كانوا فيه في الدنيا قليل{[976]} في الآخرة لأنها لا تنقضي ،  فعلموا ( هناك ){[977]} في الآخرة ( أنه ){[978]} كذلك . <br />
سعيد عن قتادة قال : و ( ذلك ){[979]} مما تحاقرت الدنيا في أنفسهم حين عاينوا يوم القيامة{[980]} .
