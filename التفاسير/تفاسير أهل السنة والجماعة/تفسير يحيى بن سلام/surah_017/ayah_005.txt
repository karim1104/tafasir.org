{ فإذا جاء وعد أولاهما } ( 5 ) : أولى العقوبتين{[613]} .  { بعثنا عليكم عبادا لنا أولى بأس شديد } ( 5 ) ( تفسير مجاهد ){[614]} .  فارس{[615]} .  { فجاسوا خلال الديار } ( 5 ) ( فقتلوهم ){[616]} في الديار وهدموا بيت المقدس وألقوا فيه الجيف والعذرة .  { وكان وعدا مفعولا } ( 5 ) أي أنه كائن . <br />
[ وقال ابن مجاهد عن أبيه ] : { وقضينا إلى بني إسرائيل في الكتاب } كتبنا عليهم .  { لتفسدن في الأرض [ مرتين ] }{[617]} إلى قوله : { أولى بأس شديد } قال : ذلك بيان من جاءهم من فارس يتحسسون أخبارهم ويسمعون حديثهم ومعهم بختنصر ،  فوعى أحاديثهم من بين أصحابه ثم  رجعت فارس ،  فلم ( يكن ){[618]} قتال ونصرت عليهم بنو إسرائيل .  فهذا وعد الأولى . <br />
{ فإذا جاء وعد الآخرة ليسألوا وجوهكم } ( 7 ) بعث مالك فارس ببابل جيشا وأمر عليهم بختنصر ،  فأتوا ( بني ){[619]} اسرائيل فدمروهم .  فكانت هذه الآخرة ووعدها{[620]} . <br />
[ وقال السدي : { فإذا جاء وعد الآخرة } يعني : الموت الأخير من العذاب الذي وعدهم ]{[621]} . <br />
سعيد عن قتادة قال : عوقب القوم على ( غلوّهم ){[622]} وفسادهم ،  فبعث [ الله ]{[623]} عليهم في الأولى جالوت ( الخزري ){[624]} فسبى وقتل وجاسوا خلال الديار كما قال الله ،  ثم ( روجع ){[625]} القوم على دخن{[626]} فيهم كثير .
