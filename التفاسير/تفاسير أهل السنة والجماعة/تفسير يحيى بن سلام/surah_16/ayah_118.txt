قوله : { وعلى الذين هادوا } ( 118 ) اليهود ،  سموا أنفسهم اليهود وتركوا اسم الإسلام .  { حرمنا } ( 118 ) عليهم بكفرهم .  { ما قصصنا عليك من قبل } ( 118 ) . <br />
[ سعيد عن قتادة قال : يعني : ما قص الله عليه ]{[350]}  في سورة الأنعام وهي مكية ،  وهذا الموضع من هذه السورة مدني ،  يعني : { وعلى الذين هادوا حرمنا كل ذي ظفر ومن البقر والغنم حرمنا عليهم شحومها إلا ما حملت ظهورهما أو [ 5أ ] الحوايا } {[351]} والحوايا : المبعر .  { أو ما اختلط بعظم } / وقد فسرناه في سورة الأنعام . <br />
قال : { وما ظلمناهم ولكن كانوا أنفسهم يظلمون } ( 118 ) ،  إنما حرم ذلك عليهم بظلمهم ،  قال : { فبظلم من الذين هادوا حرمنا عليهم طيبات أحلت لهم }{[352]}  إلى  آخر الآية .
