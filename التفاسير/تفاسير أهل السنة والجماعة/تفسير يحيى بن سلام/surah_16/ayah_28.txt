[ 9 ]  قوله : { الذين / توفاهم الملائكة ظالمي أنفسهم } ( 28 ) قال بعضهم : توفاهم عند الموت .  وقال الحسن : هي وفاة إلى النار ،  حشر إلى النار .  { فألقوا السلم }( 28 ) .  تفسير قتادة : استسلموا .  وتفسير الحسن : فأعطوا الإسلام ،  أسلموا فلم يقبل ذلك منهم . <br />
وقال{[58]} : إن القيامة مواطن ،  فمنها موطن{[59]}  يقرون فيه بأعمالهم الخبيثة وهو قوله : { وشهدوا على أنفسهم أنهم كانوا كافرين } {[60]} ومنها موطن{[61]}  يجحدون فيه فقالوا : { ما كنا نعمل من سوء } ( 28 ) فقيل لهم : { بلى إن الله عليم بما كنتم تعملون } ( 28 ) في الدنيا أنكم مشركون ،  وقالوا : { والله ربنا ما كنا مشركين } {[62]} . <br />
قال : { انظر كيف كذبوا على أنفسهم } {[63]} فادعوا أنهم لم يكونوا مشركين { وضل عنهم ما كانوا يفترون } {[64]} من عبادتهم الأوثان فلم تغن عنهم شيئا .  وأن آخرها موطنا أن يختم على أفواههم وتكلم أيديهم وتشهد أرجلهم بما كانوا يكسبون( 1 ) يعملون .  وقال السدي في قوله : { ما كنا نعمل من سوء } يعني من شرك .
