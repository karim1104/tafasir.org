قوله : { ضرب الله مثلا } ( 75 ) [ يعني وصف الله شبها ،  وهو تفسير السدي ]{[183]} .  { عبدا مملوكا لا يقدر على شيء } ( 75 ) ،  يعني : الوثن .  { ومن رزقناه منا رزقا حسنا } ( 75 ) ،  يعني : المؤمن .  { فهو ينفق منه سرا حسنا } ( 75 ) ،  يعني : المؤمن .  { فهو ينفق منه سرا وجهرا } ( 75 ) ،  قال : { هل يستوون }{[184]} ( 75 ) ،  يعني : هل{[185]} يستوي هذا الذي يعبد الوثن الذي لا يقدر على شيء ،  والذي يعبد الله فيرزقه الرزق الحسن ،  أي : إنهما لا يستويان . <br />
ثم قال : { الحمد لله بل أكثرهم لا يعلمون } ( 75 ) ،  وهم : المشركون . <br />
سعيد عن قتادة قال : هذا مثل ضربه الله للكافر{[186]} ،  رزقه الله مالا فلم يقدم فيه خيرا {[187]} ،  ولم يعمل فيه بطاعته{[188]} . <br />
قال الله : { ومن رزقناه منا رزقا حسنا فهو ينفق منه سرا وجهرا }{[189]} ( 75 ) .  فهذا المؤمن أعطاه الله رزقا حلالا طيبا فعمل فيه بطاعته وأخذه بشكر .  قال الله : { هل يستوون }{[190]} ( 75 ) مثلا .
