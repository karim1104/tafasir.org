ثم قال : { يوم يرون الملائكة } ( 22 ) وهذا عند الموت .  { لا بشرى يومئذ للمجرمين } ( 22 ) للمشركين ،  لا بشرى لهم يومئذ بالجنة .  وذلك أن المؤمنين تبشرهم الملائكة عند الموت بالجنة .  قال : { إن الذين قالوا ربنا الله ثم استقاموا تتنزل عليهم الملائكة } عند الموت { ألا تخافوا ولا تحزنوا وأبشروا بالجنة التي كنتم توعدون } {[3280]} . <br />
وتفسير ابن مجاهد عن أبيه : { يوم يرون الملائكة } يوم القيامة{[3281]} .  قال : { ويقولون حجرا محجورا } ( 22 ) . <br />
سعيد عن قتادة قال : حراما محرما على الكافر البشرى يومئذ{[3282]} . <br />
المعلى بن هلال عن إدريس عن عطية العوفي قال : { حجرا محجورا } قال : حراما محرما . <br />
المعلى عن أبي يحيى عن مجاهد قال : هو كقوله للشيء : معاذ الله ،  أي أن يكون لهم البشرى بالجنة{[3283]} .
