{ وما كان معه من إله } ( 91 ) وذلك لما عبدوا من الأوثان ،  اتخذوا مع الله آلهة . <br />
قال : { إذا لذهب كل إله بما خلق } ( 91 ) يقول : لو كان معه آلهة :{ إذا لذهب كل إله بما خلق } .  { ولعلا بعضهم على بعض }( 91 ) لطلب بعضهم ملك بعض حتى يعلو عليه ،  كما يفعل ملوك الدنيا .  { سبحان الله عما يصفون } ( 91 ) ينزه نفسه ( كما ){[2991]} يكذبون .
