قوله : { إني جزيتهم اليوم بما صبروا } ( 111 ) في الدنيا . <br />
{ أنهم هم الفائزون }( 111 ) ذلك جزاؤهم { أنهم } أي بأنهم { هم الفائزون } .  وهي تقرأ على وجه آخر : إني جزيتهم اليوم الجنة بما صبروا في الدنيا . <br />
ثم قال : { أنهم هم الفائزون } وقوله :{ الفائزون } الناجحون من النار ،  فازوا من النار إلى الجنة .
