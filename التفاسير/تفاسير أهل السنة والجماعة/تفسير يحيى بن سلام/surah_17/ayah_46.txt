{ جعلنا على قلوبهم أكنة } ( 46 ) ( غلف ){[932]} .  { أن يفقهوه } ( 46 ) ( لئلا يفقهوه ){[933]} .  { وفي آذانهم وقرا } ( 46 ) مثل قوله : { وختم{[934]} على سمعه وقلبه وجعل على بصره غشاوة }{[935]} . <br />
سعيد عن قتادة قال : حجابا مستورا وهو أكنة على قلوبهم أن يفقهوه{[936]} .  قال : { وإذا ذكرت ربك في القرآن وحده } ( 46 ) أنه لا إله إلا هو .  { ولوا على أدبارهم نفورا } ( 46 ) أعرضوا عنه . <br />
سعيد عن قتادة قال : إن المسلمين لما قالوا : لا إله إلا الله أنكر ذلك المشركون{[937]} وكبرت عليهم وضاقها إبليس وجنوده .
