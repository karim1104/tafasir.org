{ فانطلقا حتى إذا لقيا غلاما فقتله } ( 74 ) .  سفيان عن أبي إسحاق الهمداني عن رجل من بني تميم عن ابن عباس قال : طُبع [ الغلام ]{[1262]} كافرا{[1263]} . <br />
قال يحيى : قوله طبع كافرا لعلّه لو بلغ كان يكون كافرا مثل قوله : { ولا يلدوا إلا فاجرا كفارا }{[1264]} أي من بلغ منهم ثم كفر وفجر . <br />
{ قال أقتلت نفسا ( زاكية ) } {[1265]} ( 74 ) أي لم تذنب .  وقال قتادة : الزكية التائبة{[1266]} .  { بغير نفس لقد جئت شيئا نكرا } ( 74 ) .  ابن مجاهد عن أبيه قال : النكر : المنكر .
