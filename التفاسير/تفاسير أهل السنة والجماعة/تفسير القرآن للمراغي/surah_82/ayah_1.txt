شرح المفردات : انفطرت : أي انشقت . <br />
/م1<br />
الإيضاح : { إذا السماء انفطرت } أي إذا انشقت السماء وتغير نظامها ، فلم يبق نظام الكواكب على ما نرى ، عند خراب هذا العالم بأسره . <br />
وجاء نحو الآية قوله : { ويوم تشقق السماء بالغمام } [ الفرقان : 25 ] وقوله : { فإذا انشقت السماء فكانت وردة كالدهان } [ الرحمن : 37 ] وقوله : { وفتحت السماء فكانت أبوابا } [ النبأ :19 ] .
