شرح المفردات : الحميم : القريب . <br />
{ ولا يسأل حميم حميما } أي ولا يسأل قريب مشفق قريبا عن حاله ، ولا يكلمه لابتلاء كل منهما بما يشغله كما جاء في قوله : { وإن تدع مثقلة إلى حملها لا يحمل منه شيء ولو كان ذا قربى } [ فاطر : 18 ] وقوله : { يوم يفر المرء من أخيه ( 34 ) وأمه وأبيه ( 35 ) وصاحبته وبنيه ( 36 ) لكل امرئ منهم يومئذ شأن يغنيه } [ عبس : 34-37 ] .
