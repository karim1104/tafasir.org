( 3 ) { أو تسقط السماء كما زعمت علينا كسفا } تقول العرب : جاءنا بثريد كسف أي قطع من الخبز : أي أو تسقط علينا جرم السماء إسقاطا مماثلا لما زعمت في قولك : { أو نسقط عليهم كسفا من السماء } [ سبأ : 9 ] . <br />
وخلاصة ذلك : أو تسقط السماء علينا متقطعة قطعا قطعا ، ونحو الآية قوله : { اللهم إن كان هذا هو الحق من عندك فأمطر علينا حجارة من السماء } [ الأنفال : 32 ] وكذلك سأل قوم شعيب منه فقالوا : { فأسقط علينا كسفا من السماء إن كنت من الصادقين } [ الشعراء : 187 ] . <br />
( 4 ) { أو تأتي بالله والملائكة قبيلا } أي أو تأتي بالله والملائكة نقابلهم معاينة ومواجهة قاله مجاهد وعطاء ، ونحو الآية قولهم : { لولا أنزل علينا الملائكة أو نرى ربنا } [ الفرقان : 21 ] .
