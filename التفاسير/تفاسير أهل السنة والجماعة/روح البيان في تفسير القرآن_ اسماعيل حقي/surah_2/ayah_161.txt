{ إن الذين كفروا } اى استمروا على الكفر المستتبع للكتمان وعدم التوبة { وماتوا وهم كفار } مصرون على كفرهم لا يرتدعون عن حالتهم الاولى { أولئك } مستقر { عليهم لعنة الله والملائكة والناس أجمعين } اى هم المخصوصون باللعنة الابدية احياء وامواتا فمن يعتد بلعنتهم وهم المؤمنون لانهم هم الناس فى الحقيقة لانتفاعهم بالانسانية واما الكفار فهم كالانعام واضل سبيلا فلا اعتداد بهم عند الله او الناس عام لان الكفار يوم القيامة يلعن بعضهم بعضا والله تعالى يلعنهم يوم القيامة ثم يلعنهم الملائكة ثم تلعنهم الناس والظالم يلعن الظالمين ومن لعن الظالمين وهو ظالم فقد لعن نفسه.
