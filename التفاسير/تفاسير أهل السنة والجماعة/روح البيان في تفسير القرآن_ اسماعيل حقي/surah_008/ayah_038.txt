{ قل للذين كفروا } اللام للتعليل اى لاجلهم والمراد ابو سفيان واصحابه { إِن ينتهوا } عن معاداة الرسول بالدخول فى الاسلام { يغفر لهم ما قد سلف } من ذنوبهم قبل الاسلام { وإِن يعودوا } الى قتاله انتقمنا منهم واهلكناهم { قد مضت سنة الأولين } الذين تجزبوا على الانبياء بالتدمير كما جرى على اهل بدر فليتوقعوا مثل ذلك وانشد بعضهم
