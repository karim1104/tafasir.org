{ قال } الله تعالى تذكيرا لما لبثوا فيما سألوا الرجوع اليه من الدنيا بعد التنبيه على استحالته بقوله { كم لبثتم فى الارض } التى تدعون ان ترجعوا اليها يقال لبث بالمكان اقام به ملازما له { عدد سنين } تمييز لكم { قالوا لبثنا يوما او بعض يوم } استفصارا لمدة لبثهم فيها بالنسبة الى دخولهم فى النار او لانها كانت ايام السرور وايام السرور قصار أو لانها منقضية والمنقضى كالمعدوم { فاسأل العادين } اى الذين يعلمون عد ايامها ان اردت تحقيقها فانا لما نحن فيه من العذاب مشغولون عن تذكرها واحصائها.وفى التأويلات النجمية فاسأل العادين يعنى الذين يعدّون انفاسنا وايامنا وليالينا من الملائكة الموكلين علينا.
