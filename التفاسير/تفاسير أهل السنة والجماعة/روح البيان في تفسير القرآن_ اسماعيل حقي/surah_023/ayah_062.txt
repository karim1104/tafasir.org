{ ولا نكلف نفسا } من النفوس { الا وسعها } قدر طاقتها لا اله الا الله والعمل بما يترتب عليه من الاحكام من قبيل ماهو فى الوسع، قال مقاتل من لم يستطع القيام فليصل قاعدا ومن لم يستطع القعود فليومىء ايماء، قال الحريرى لم يكلف الله العباد معرفته على قدره وانما كلفهم على اقدارهم ولو كلفهم على قدره لما عرفوه لانه لا يعرفه على الحقيقة احد سواه قال الجامى { ولدينا } عندنا { كتاب } صحائف اعمال قد اثبت فيها اعمال كل احد على ماهى عليه { ينطق بالحق } بالصدق لا يوجد فيه مايخالف الواقع اى يظهر الحق ويبينه للناظر كما يبينه النطق ويظهر للسامع فنيظر هنالك اعمالهم ويترتب عليها اجزيتها ان خيرا فخير وان شرا فشر وبالفارسية ونزد ما هست نامه اعمال هركس كه سخن كويد براستى وكواهى دهد بركردار هركس { وهم لا يظلمون } فى الجزاء بنقص ثواب او بزيادة عذاب بل يجزون بقدر اعمالهم التي كلفوها ونطقت بها صحائفها بالحق.
