{ فكذبوه } اى هودا واصروا على ذلك { فاهلكناهم } اى عادا بسبب التكذيب بريح صرصر. تلخيصه ان هودا انذر قومه ووعظهم فلم يتعظوا فاهلكوا { ان فى ذلك } بدرستى كه در هلاك قوم عاد { لآية } نشانه ايست دلالت كند برآنكه عاقبت اهل تكذيب بعقوبت كشد { وما كان اكثرهم } اى اكثر قوم عاد { مؤمنين } جه اندك ازان قبيله باهود بودند
