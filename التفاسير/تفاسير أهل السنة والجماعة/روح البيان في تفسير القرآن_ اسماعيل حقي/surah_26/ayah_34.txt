{ قال } فرعون { للملأ } اى لاشراف قومه حال كونهم مستقرين { حوله } فهو ظرف وضع موضع الحال وقد سبق معناه. الملأ جماعة يجتمعون على رأى فيملأون العيون رواء والنفوس جلالة وبهاء { ان هذا } بدرستى كه اين مرد يعنى موسى { لساحر عليم } فائق فى علم السحر وبالفارسية جادوييست دانا واستاد فرعون ترسيد كه كسان وى بموسى ايمان آرند حيله انكيخت وكفت اين جاد وييست كه درفن سحر مهارتى تمام دارد " يريد " الخ والسحر تخيلات لا حقيقة لها فالساحر المحتال المخيل بما لاحقيقة له وجه الجمع بين شذا وبين قوله فى الاعراف قال الملأ من قوم فرعون حيث اسند القول بالساحرية اليهم ان فرعون قاله للحاضرين والحاضرون قالوه للغائبين كما فى كشف الاسرار.
