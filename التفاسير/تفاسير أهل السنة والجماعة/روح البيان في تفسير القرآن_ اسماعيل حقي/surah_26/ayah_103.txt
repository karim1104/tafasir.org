{ ان فى ذلك } اى فيما ذكر من قصة ابراهيم مع قومه { لآية } لعبرة لمن يعبد غير الله تعالى ليعلم انه يتبرأ منه فى الآخرة ولا ينفعه احد ولا سيما لاهل مكة الذين يدعون انهم على ملة ابراهيم { وما كان اكثرهم } اكثر قوم ابراهيم { مؤمنين } كحال اكثر قريش. وقد روى انه ماآمن لابراهيم من اهل بابل الا لوط وابنة نمرود
