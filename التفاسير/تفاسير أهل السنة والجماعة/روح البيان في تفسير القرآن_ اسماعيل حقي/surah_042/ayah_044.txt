{ ومن يضلل الله } يخلق فيه الضلالة من الهوى او بتركه على ما كان عليه من ظلم الناس { فماله من ولى من بعده } من ناصر يتولاه من بعد خذلانه تعالى اياه وبالفارسية وهراكرا كمراه سازد خداى تعالى بس نيست مراورا هيج دوستى كه كار سازى كندبس ازفرو كذشتن خداى تعالى مراورا { وترى الظالمين } الخطاب لكل من يتأتى منه الرؤية البصرية والظالمون المشركون والعاصون { لما رأوا العذاب } اى حين يرونه وصيغة الماضى للدلالة على التحقق { يقولون } الخ فى موضع الحال من الظالمين لان الرؤية بصرية { هل } آياهست { الى مرد } بمعنى الرداى الرجعة الى الدنيا { من سبيل } هيج راهى يا جاده تابرويم وتدارك مافات كنيم ازايمان وعمل صالح. وقد سبق بيانه فى قوله فى حم المؤمن فهل الى خروج من سبيل
