{ واما من اوتى كتابه بشماله } تحقيرا له لان الشمال يتشاءم بها بان تلوى يسراه الى خلف ظهره فيأخذه بها ويرى ما فيه من قبائح الاعمال { فيقول } تحزنا وتحسرا وخوفا مما فيه وهو من قبيل الألم الروحانى الذى هو أشد من الألم الجسمانى { يا } هؤلاء يا معشر المحشر { ليتنى } كاشكى من. وهو تمنٍ للمحال { لم اوت } متكلم مجهول من الايتاء بمعنى لم اعط { كتابيه } هذا الذى جمع جميع سيئاتى.
