{ وانه } اى القرءآن { لتذكرة } موعظة وبالفارسية بنديست { للمتقين } لمن اتقى الشرك وحب الدنيا فانه يتذكر بهذا القرءآن وينتفع به بخلاف المشرك ومن مال الى الدنيا وغلبه حبها فانه يكذب به ولا ينتفع وفى تاج المصادر التذكير والتذكرة باياد دادن وحرف را مذكر كردن. ومنه الحديث فذكروه اى فأجلوه لان فى تذكير الشئ اجلالا له.
