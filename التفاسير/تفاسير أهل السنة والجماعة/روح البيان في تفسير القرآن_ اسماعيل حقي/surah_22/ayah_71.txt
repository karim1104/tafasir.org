{ ويعبدون } اى اهل الشرك { من دون الله } اى متجاوزين عبادة الله تعالى { مالم ينزل به } اي بجواز عبادته وما عبارة عن الاصنام { سلطانا } اى حجة وبرهانا { وما ليس لهم به } اى بجواز عبادته { علم } حصل لهم من ضرورة العقل او استدلاله فهم انما يعبدون الاصنام بمجرد الجهل ومحض التقليد { وما للظالمين } اى المشركين الذين ارتكبوا مثل هذا الظلم العظيم { من نصير } يدفع عنهم العذاب الذى يعتريهم بسبب ظلمهم. وفى التأويلات النجمية يشير الى من كان من جملة خواصه افرده ببرهان وايده ببيان واعزه بسلطان وما لاهل الخذلان سلطان فميا عبدوه من اصناف الاوثان ولا برهان على ما طلبوه ومالهم نصرة من الله بل خذلان.
