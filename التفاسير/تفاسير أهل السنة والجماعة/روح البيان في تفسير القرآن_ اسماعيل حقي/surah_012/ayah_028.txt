{ فلما رأى } العزيز { قميصه قد من دبر } وعلم براءة يوسف وصدقه كما قال الجامى { قال انه } اى الامر الذى وقع فيه التشاجر { من كيدكن } من جنس حيلتكن ومكركن ايتها النساء لا من غيركن فخجلت زليخا وتعميم الخطاب للتنبيه على ان ذلك خلق لهن عريق { ان كيدكن عظيم } فانه الصق واعلق بالقلب واشد تأثيرا فى النفس اى من كيد الرجال فعظم كيد النساء على هذا بالنسبة الى كيد الرجال ولان الشيطان يوسوس مسارقة وهن يواجهن به الرجال فالعظم بالنسبة الى كيد الشيطان وعن بعض العلماء انى اخاف من النساء ما لا اخاف من الشيطان فانه تعالى يقول وقال للنساء { ان كيدكن عظيم }
