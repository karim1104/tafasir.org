{ قل } يا محمد { سيروا } ايها المنكرون المكذبون من السير وهو المضى { فى الارض } فى ارض اهل التكذيب مثل الحجر والاحقاف والمؤتفكات ونحوها { فانظروا } تفكروا واعتبروا { كيف كان عاقبة المجرمين } آخر امر المذكبين بسبب التكذيب حيث اهلكوا بانواع العذاب وفيه تهديد لهم على التكذيب وتخويف بان ينزل بهم مثل مانزل بالمكذبين قبلهم واصل الجرم قطع الثمر عن الشجر والجرامة رديىء الثمر المجروم واستعير لكل اكتساب مكروه
