{ أئنكم } آياشما { لتأتون الرجال } بيان لاتيانهم الفاحشة وعلل الاتيان بقوله { شهوة } للدلالة على قبحه والتنبيه على ان الحكمة فى المواقعة طلب النسل لاقضاء الوطر واصل الشهوة نزوع النفس الى ماتريده { من دون النساء } اى حال كونكم مجاوزين النساء اللاتى هن محال الشهوة { بل انتم قوم تجهلون } حيث لا تعملون بموجب علمكم فان من لايجرى على مقتضى بصارته وعلمه ويفعل فعل الجاهل فهو والجاهل سواء وتجهلون صفة لقوم والتاء فيه لكون الموصوف فى معنى المخاطب
