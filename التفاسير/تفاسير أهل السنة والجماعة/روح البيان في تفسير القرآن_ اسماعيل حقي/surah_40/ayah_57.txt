{ لخلق السموات والارض } تحقيق للحق وتبيين لاشهر ما يجادلون فيه وهو امر البعث { اكبر } اعظم فى القدرة { من خلق الناس } مرة ثانية وهى الاعادة فمن قدر على خلق الاعظم الاقوى بلا اصل ولا مادة وجب أن يقدر على خلق الاذل الاضعف من الاصل والمادة بطريق الاولى فكيف يقرون بأن الله خلق السموات والارض وينكرون الخلق الجديد يوم البعث { ولكن اكثر الناس } يعنى الكفار { لا يعلمون } أن الاعادة اهون من البداية لقصورهم فى النظر والتأمل لفرط غفلتهم واتباعهم لاهوآئهم
