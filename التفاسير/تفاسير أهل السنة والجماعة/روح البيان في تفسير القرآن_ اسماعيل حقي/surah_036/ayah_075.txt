{ لا يستطيعون نصرهم } اى لا تقدر آلهتهم على نصرهم والواو لوصفهم الاصنام باوصاف العقلاء { وهم } اى المشركون { لهم } اى لآلهتهم { جند } عسكر { محضرون } اثرهم فى النار اى يشيعون عند مساقهم الى النار ليجعلوا وقودا لها وبالفارسية سباه اند حاضر كرده شد كان فردا كه لشكر ايشانند باايشان حاضر شوند دردوزخ قال الكواشى روى انه يؤتى بكل معبود من دون الله ومعه اتباعه كأنهم جنده فيحضرون فى النار هذا لمن امر بعبادة نفسه او كان جمادا
