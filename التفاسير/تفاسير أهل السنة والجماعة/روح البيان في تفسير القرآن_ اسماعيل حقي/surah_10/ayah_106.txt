{ ولا تدع } عطف على قوله تعالى { قل يا ايها الناس } غير داخل تحت الامر { من دون الله } استقلالا ولا اشتراكا { ما لا ينفعك } اذا دعوته بدفع مكروه او جلب محبوب { ولا يضرك } اذا تركته بسلب المحبوب دافعا او رفعا او بايقاع المكروه { فان فعلت } اى ما نهيت عنه من دعاء ما لا ينفع ولا يضر { فانك اذا من الظالمين } الضارين بانفسهم فانه اذا كان ما سوى الحق معزولا عن التصرف الى ما سوى الحق وضعا للشيء فى غير موضعه فيكون ظلما فلا نافع ولا ضار الا الحق وكل شيء هالك الا وجهه
