{ فالقى } من يده { عصاه } والالقاء طرح الشىء حيث تلقاه وتراه ثم صار فى التعارف اسما لكل طرح { فاذا هى } بس آنجا عصا بسى ازافكندن { ثعبان مبين } اى ظاهر الثعبانية وانها شىء يشبه الثعبان صورة بالسحر او بغيره والثعبان اعظم الحيات بالفارسية ازدها واشتقاقه من ثعبت الماء فانثعب اى فجرته فانفجر. قال الكاشفى وفرعون از مشاهده اوبترسيد ومردمان كه حاضر بودند هزيمت كردند جنانجه دروقت فراربيست وننج هز اركس كشته شد. قال فرعون من شدة الرعب ياموسى اسألك بالذى ارسلك ان تأخذها فاخذها فعادت عصا ولاتناقض بينه وبين قوله وهو الصغير من الحيات لان خلقها خلق الثعبان العظيم وحركتها وخفتها كالجان كما فى كشف الاسرار. وفيه اشارة الى القاء القلب عصا الذكر وهو كلمة لا اله الا الله فاذا هى ثعبان مبين يلتقم بفم النفى ما سوى الله.
