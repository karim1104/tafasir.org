{ ولئن سألتهم } اى الكافرين { من خلق السموات والارض } اى الاجرام العلوية والسفلية { ليقولن } خلقهن { الله } لغاية وضوح الامر بحيث اضطروا الى الاعتراف به { قل الحمد لله } على ان جعل دلائل التوحيد بحيث لا يكاد ينكرها المكابرون ايضا { بل اكثرهم لا يعلمون } شيئا من الاشياء فلذلك لا يعملون بمقتضى اعترافهم بان يتركوا الشرك ويعبدوا الله وحده
