{ ومن آياته } دلائل وحدته تعالى وقدرته وعظمته وحكمته { الجوار } السفن الجارية وهى بالياء فى الاصل حذفت الكسر الدال عليها { فى البحر } در دريا { كالاعلام } جمع علم بفتحتين بمعنى الجبل وكل مرتفع علم أى كالجبال على الاطلاق لا التى عليها النار للاهتداء خاصة وبالفارسية مانند كوها درعظمت. فقوله جوار جمع جارية بمعنى سائرة صفة للسفن المقدرة وفى البحر متعلق على التقديرين
