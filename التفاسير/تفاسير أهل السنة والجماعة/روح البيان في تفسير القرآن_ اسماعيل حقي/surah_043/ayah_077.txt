{ ونادوا يا مالك } درخواه ازخداى تو { ليقض علينا ربك } اى ليمتنا حتى نستريح من قضى عليه اذا أماته والمعنى سل ربك ان يقضى علينا وهذا لا ينافى ما ذكر من ابلاسهم لانه جوءار اى صياح وتمن للموت لفرط الشدة { قال } مالك مجيبا بعد اربعين سنة يعنى ينادون مالكا اربعين سنة فيجيبهم بعدها او بعد مائة سنة او ألف. درتبيان آورده كه بعد ازجهل روز از روزهاى آن سراى. لان تراخى الجواب احزن لهم { انكم ماكثون } المكث ثبات مع انتظار اى مقيمون فى العذاب ابدا لا خلاص لكم منه بموت ولا بغيره فليس بعدها الا جؤار كصياح الحمير اوله زفير وآخره شهيق
