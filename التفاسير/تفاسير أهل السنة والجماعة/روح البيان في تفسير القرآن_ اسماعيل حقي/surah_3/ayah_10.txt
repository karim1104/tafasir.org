{ ان الذين كفروا لن تغنى عنهم } اى لن تنفعهم { أموالهم } التي يبذلونها فى جلب المنافع ودفع المضار قدم الاموال على الاولاد لانها اول عدة يفزع اليها عند نزول الخطوب { ولا اولادهم } الذين بهم يتناصرون فى الامور المهمة وعليهم يعولون فى الخطوب الملمة وتوسيط حروف النفى لعراقة الاولاد فى كشف الكروب { من الله } اى عذابه تعالى { شيأ } اى شيأ من الاغناء ومعناه لا يصرف عنهم كثرة الاموال والاولاد والتناصر بهما عذابه وكانوا يقولون نحن اكثر اموالا واولادا وما نحن بمعذبين قال تعالى فى ردهم سبأ 37. { واولئك } اى اولئك المتصفون بالكفر { هم وقود النار } حطب النار وحصبها الذى تسعر به.
