{ ان هذه } اى ملة التوحيد والاسلام اشير اليها بهذه تنبيها على كمال ظهور امرها فى الصحة والسداد { امتكم } ايها الناس اى ملتكم التى يجب ان تحافظوا على حدودها وتراعوا حقوقها ولا تخلوا بشئ منها { امة واحدة } نصب على الحالية من امتكم اى غير مختلفة فيما بين الانبياء فانهم متفقون فى الاصول وان كانوا مختلفين فى الفروع بحسب الامم والاعصار. قال فى القاموس الامة جماعة ارسل اليهم رسول انتهى فاصلها القوم الذى يجتمعون على دين واحد ثم اتسع فيها فاطلقت على ما اجتمعوا عليه من الدين والملة واشتقاقها من ام بمعنى قصد فالقوم هم الجماعة القاصدة وما اجتمعوا عليه هو الملة المقصود { وانا ربكم } لا اله لكم غيرى { فاعبدون } خاصة لا غير.
