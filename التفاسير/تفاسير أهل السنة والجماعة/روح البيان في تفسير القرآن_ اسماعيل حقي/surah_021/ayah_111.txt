{ وان } ما { ادرى لعله } لعل تأخير جزائكم { فتنة لكم } استدراج لكم وزيادة فى افتتانكم لما كان الاستدراج سببا للفتنة والعذاب اطلق عليه لفظ الفتنة مجازا مرسلا او امتحان لكم كيف تعملون اى معاملة تشبيهية بالامتحان على طريق الاستعارة التمثيلية { ومتاع الى حين } وتمتيع لكم الى اجل مقدر يقتضيه مشيئته المبنية على الحكم البالغة ليكون ذلك حجة عليكم وليقع الجزاء فى وقت هو فيه حكمة.
