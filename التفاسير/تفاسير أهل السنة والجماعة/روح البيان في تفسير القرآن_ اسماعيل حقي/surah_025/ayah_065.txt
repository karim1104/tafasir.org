{ والذين يقولون } اى فى اعقاب صلواتهم او فى عامة اوقاتهم { ربنا } اى بروردكارما { اصرف عنا } صرفه رده { عذاب جهنم } العذاب الايجاع الشديد { ان عذابها كان غراما } اى شرا دائما وهلاكا لازما غير مفارق لمن عذب به من الكفار، قال الراغب مأخوذ من قولهم هو مغرم بالنساء اى يلازمهن ملازمة الغريم اى ملازمة من له الدين لغريمه اى من عليه الدين فكلاهما غريم، قال محمد بن كعب ان الله تعالى سأل الكفار ثم نعمته فلم يؤدوها اليه فاغرقهم فادخلهم النار.
