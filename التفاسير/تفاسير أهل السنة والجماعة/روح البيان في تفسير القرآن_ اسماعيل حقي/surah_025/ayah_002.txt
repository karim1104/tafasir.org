{ الذى } اى هو الذى { له } خاصة دون غيره استقلالا او اشتراكا { ملك السموات والارض } الملك هو التصرف بالامر والنهى فى الجمهور، قال الكاشفى بادشاهىء آسمانهارا وزمينها جه وى منفرداست بآ فريد آنها بس اورا رسد تصرف دران ثم قال ردا على اليهود والنصارى { ولم يتخذ ولدا } ليرث ملكه لانه حى لا يموت وهو عطف على ما قبله من الجملة الظرفية، قال فى المفردات تخذ بمعنى اخذ واتخذ افتعل منه والولد المولود ويقال للواحد والجمع والصغير والكبير والذكر والانثى ثم قال ردا على قريش { ولم يكن له شريك فى الملك } اى فى ملك السموات والارض لينازعه او ليعاونه فى الايجاد وفى المثنوى { وخلق كل شىء } احدث كل موجود من الموجودات من مواد مخصوصة على صور معينة ورتب فيه قوى وخواص مختلفة الاحكام والآثار { فقدره تقديرا } اى فهيأه لما أراده منه من الخصائص والافعال اللائقة به كهيئة الانسان للادراك والفهم والنظر والتدبر فى امور المعاش والمعاد واستنباط الصانع المتنوعة ومزاولة الاعمال المختلفة وهكذا احوال سائر الانواع.
