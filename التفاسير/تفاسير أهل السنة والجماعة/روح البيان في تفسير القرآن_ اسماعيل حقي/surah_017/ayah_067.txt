{ واذا مسكم } وجون برسد شمارا { الضر فى البحر } خوف الغرق فيه { ضل من تدعون } اى ذهب عن خواطركم كل من تدعون فى حوادثكم وتسغيثون { الا اياه } تعالى وحده من غير ان يخطر ببالكم احد منهم وتدعوه لكشفه استقلالا او اشتراكا ويجوز ان يكون الاستثناء منقطعا اى ضل كل من تدعونه وتعبدونه من الآلهة كالمسيح والملائكة وغيرهم من عونكم وغوثكم ولكن الله هو الذى ترجونه لصرف النوازل عنكم { فلما } بس آن هنكام كه { نجاكم } من الغرق واوصلكم { الى البر } بسوى بيابان { اعرضتم } عن التوحيد وعدتم الى عباد الاوثان ونسيتم النعمة وكفرتم بها { وكان الانسان كفورا } بليغ الكفران ولم يقل وكنتم كفورا ليسجل على ان هذا الجنس موسوم بكفران النعمة.
