{ فاراد } اى فرعون من نتائج ظنه الكاذب { ان يستفزهم } الاستفزاز الازعاج. والمعنى بالفارسة. برانكيزد ودور كند موسى وقوم او { ومن الارض } اى ارض مصر او من وجه الارض بالقتل الاستئصال { فاغرقناه } اى فرعون { ومن معه } من القبط { جميعا } ونجينا موسى وقومه من نتائج ظنه الصادق. قال فى الارشاد فعكسنا عليه مكره واستفززناه وقومه بالاغراق }
