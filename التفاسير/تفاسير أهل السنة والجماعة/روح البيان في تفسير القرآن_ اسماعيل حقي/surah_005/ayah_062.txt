{ وترى } يا محمد رؤية بصرية { كثيرا منهم } اى من اليهود والمنافقين حال كونهم { يسارعون فى الإثم } اى الكذب على الاطلاق وايثار كلمة فى على كلمة الى للدلالة على انهم مستقرون فى الاثم وانما مسارعتهم من بعض مراتبه الى بعض آخر منها كقوله تعالى المؤمنون 61. لا انهم خارجون منه متوجهون اليه كما فى قوله تعالى آل عمران 133. { والعدوان } اى الظلم المتعدى الى الغير { وأكلهم السحت } اى الحرام { لبئس ما كانوا يعملون } اى لبئس شيئاً كانوا يعملونه والجمع بين صيغتى الماضى والمستقبل للدلالة على الاستمرار.
