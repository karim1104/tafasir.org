{ يا قوم ادخلوا الارض المقدسة } هى ارض بيت المقدس طهرت من الشرك وجعلت قرار الانبياء ومسكن المؤمنين { التى كتب الله لكم } اى كتب فى اللوح المحفوظ انها تكون مسكنا لكم ان آمنتم واطعتم لقوله تعالى لهم بعدما عصوا فانها محرمة عليهم { ولا ترتدوا } لا ترجعوا { على ادباركم } اى مدبرين خوفا من الجبابرة فهو حال من فاعل لا ترتدوا ويجوز ان يتعلق بنفس الفعل اى ولا ترجعوا على اعقابكم بخلاف ما امر الله { فتنقلبوا } فتنصرفوا حال كونكم { خاسرين } اى مغبونين بفوت ثواب الدارين.
