{ يا ايها الذين آمنوا كونوا قوامين لله } مقيمين لاوامره ومتمسكين بها معظمين لها مراعين لحقوقها { شهداء بالقسط } اى بالعدل خبر بعد خبر { ولا يجرمنكم } اى ولا يحملنكم { شنآن قوم } اى شدة بغضكم للمشركين { على ان لا تعدلوا } اى على ترك العدل فيهم فتعتدوا عليهم بارتكاب ما لا يحل كمثلة وقذف وقتل نساء وصبية ونقض عهد تشفيا مما فى قلوبكم { اعدلوا هو } اى العدل { اقرب للتقوى } التى امرتم بها واذا كان وجوب العدل فى حق الكفار بهذه المثابة فما ظنك بوجوبه فى حق المسلمين { واتقوا الله } فانه ملاك الامر وزاد سفر الآخرة { ان الله خبير بما تعملون } من الاعمال فيجازيكم بذلك وحيث كان مضمون هذه الجملة التعليلية منبئا عن الوعد والوعيد عقب بالوعد لمن يخاف على طاعته تعالى وبالوعيد لمن يخل بها فقيل.
