{ قال رجلان } كانه قيل هل اتفقوا على ذلك او خالفهم البعض فقيل قال رجلان وهما كالب ويوشع { من الذين يخافون } الله تعالى دون العدو ويتقونه فى مخالفة امره ونهيه وهو صفة لرجلان { أنعم الله عليهما } بالتثبيت والوقوف على شؤونه تعالى والثقة بوعده وهو صفة ثانية لرجلان { ادخلوا عليهم الباب } اى باب بلد الجبارين وهو اريحا وتقديم الجار والمجرور عليه للاهتمام به لان المقصود انما هو دخول الباب وهم فى بلدهم اى باغتوهم وضاغتوهم فى المضيق وامنعوهم من البروز الى الصحراء لئلا يجدوا للحرب مجالا { فاذا دخلتموه } اى باب بلدهم وهم فيه { فانكم غالبون } من غير حاجة الى القتال فانا قد رأيناهم وشاهدناهم ان قلوبهم ضعيفة وان كانت اجسادهم عظيمة فلا تخشوهم واهجموا عليهم فى المضايق فانهم لا يقدرون فيها على الكر والفر { وعلى الله } خاصة { فتوكلوا } بعد ترتيب الاسباب ولا تعتمدوا عليها فانها بمعزل من التأثير وانما التأثير من عنايته العزيز القدير { ان كنتم مؤمنين } به تعالى مصدقين لوعده فان ذلك مما يوجب التوكل عليه حتما.
