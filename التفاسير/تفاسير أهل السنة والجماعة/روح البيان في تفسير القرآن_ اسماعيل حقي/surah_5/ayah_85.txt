{ فاثابهم الله } اى اعطاهم وجازاهم { بما قالوا } اى عن اعتقادهم بدليل قوله مما عرفوا من الحق { جنات } اى بساتين { تجرى من تحتها الأنهار } اى تجرى من تحت اشجارها ومساكنها وغرفها انهار الماء والعسل والخمر واللبن { خالدين فيها وذلك } الثواب { جزاء المحسنين } اى الذين احسنوا النظر والعمل او الذين اعتادوا الاحسان فى الامور.
