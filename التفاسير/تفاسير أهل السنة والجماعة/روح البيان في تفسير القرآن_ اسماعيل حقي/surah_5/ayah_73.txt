{ لقد كفر الذين قالوا ان الله ثالث ثلاثة } اى احد ثلاثة آلهة والالهية مشتركة بينهم وهم الله وعيسى ومريم { وما من إله الا إله واحد } اى والحال ليس فى الوجود ذات واجب مستحق للعبادة من حيث انه مبدأ جميع الموجودات الالٰهية موصوف بالوحدانية متعال عن قبول الشركة { وان لم ينتهوا عما يقولون } عن مقالتهم الاولى والثانية ولم يوحدوا { ليمسن الذين كفروا منهم } اى والله ليمسنهم ووضع الموصول موضع الضمير لتكرير الشهادة عليهم بالكفر فمن بيانية حال من الذين { عذاب اليم } نوع شديد الالم من العذاب يخلص وجعه الى قلوبهم.
