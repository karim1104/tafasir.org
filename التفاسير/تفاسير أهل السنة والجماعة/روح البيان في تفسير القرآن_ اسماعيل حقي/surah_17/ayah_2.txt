{ وآيتنا موسى الكتاب } اى التوراة جملة واحدة بعدما اسريناه الى الطور { وجعلناه } اى ذلك الكتاب { هدى لبنى اسرائيل } هاديا لاولاد يعقوب يهتدون الى الحق والصواب بما فيه من الاحكام والخطاب { ان لا تتخذوا } ان مفسرة لما يتضمنه الكتاب من الامر والنهى بمعنى اى كما فى قوله كتبت اليه ان افعل كذا. قال الكاشفى وكفتيم مرايشانرا كه آيافرا ميكيريد { من دونى } بجز از من { وكيلا } برور دكاريكه مهم خود بدو كذا ريد. قوله من دونى بمعنى غيرى احد مفعولى لا تتخذوا ومن مزيدة.
