{ او تكون لك جنة } بستان يستر اشجاره ما تحتها من العرصة { من نخيل وعنب } از درختان خرما وانكور يعنى مشتمل بران درختان وهما اسم جمع لنخلة وعنبة { فتفجر الانهار } اى تجريها بقوة { خلالها } درميان آن بستانها قال فى القاموس خلال الدار ما حوالى جدورها وما بين بيوتها وخلال السحاب مخارج الماء { تفجيرا } كثيرا والمراد اما اجراء الانهار خلالها عند سقيها او ادامة اجرائها كما ينبئ عنه الفاء لا ابتداؤه.
