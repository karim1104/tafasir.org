{ وكلا } منصوب بمضمر يدل عليه ما بعده اى ذكرنا وانذرنا كل واحد من الامم المذكورين المهلكين { ضربنا له الامثال } بيناله القصص العجيبة الزاجرة عماهم عليه من الكفر والمعاصى بواسطة الرسل { وكلا } اى كل واحد منهم بعد التكذيب والاصرار { تبرنا تتبيرا } اهلكا اهلاكا عجيبا هائلا فان التبر بالفتح والكسر الاهلاك والتتبير التكسير والتقطيع، قال الزجاج كلى شىء كسرته وفتته فقد تبرته ومنه التبر لمكسر الزجج وفتات الذهب والفضة قبل ان يصاغا فاذا صيغا فهما ذهب وفضة.
