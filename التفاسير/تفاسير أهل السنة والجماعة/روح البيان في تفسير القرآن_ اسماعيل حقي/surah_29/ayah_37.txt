{ فكذبوه } اى شعيبا ولم يمتنعوا من الفساد { فاخذتهم الرجفة } اى الزلزلة الشديدة حتى تهدمت عليهم دورهم وفى سورة هود اى صيحة جبريل فانها الموجبة للرجفة بسبب تمويجها للهواء وما يجاوره من الارض { فاصبحوا } اى صاروا { فى دارهم } اى بلدهم او منازلهم ولم يجمع بان يقال فى ديارهم لامن اللبس { جاثمين } باركين على الركب ميتين مستقبلين بوجوههم الارض وذلك بسبب عدم استماعهم الى داعى الحق وتزلزل باطنهم فالجزاء من حنس العمل
