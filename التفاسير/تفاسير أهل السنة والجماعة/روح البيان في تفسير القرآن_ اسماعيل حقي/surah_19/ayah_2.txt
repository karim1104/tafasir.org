{ ذكر } اى هذا المتلو ذكر { رحمة ربك } ذكر مضاف الى مفعوله { عبده } مفعول رحمة { زكريا } بدل منه وهو زكريا يمد ويقصر ابن آزر. قال الكاشفى واو ازاولاد رجعيم بن سليمان بن داود عليهم السلام بوده بيغمبر عاليشان ومهتر احبار بيت المقدس وصاحب قربان. قال الامام زكريا من ولد هارون اخى موسى وهما من ولد لاوى بن يعقوب بن اسحاق.
