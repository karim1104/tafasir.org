{ بل متعت هؤلاء } اضراب عن محذوف اى فلم يحصل ما رجاه بل متعت منهم هؤلاء المعاصرين للرسول من اهل مكة { وآباءهم } بالمد فى العمر والنعمة فاغتروا بالمهلة وانهمكوا فى الشهوات وشغلوا بها عن كلمة التوحيد { حتى جاءهم } اى هؤلاء { الحق } اى القرآن { ورسول } اى رسول { مبين } ظاهر الرسالة واضحها بالمعجزات الباهرة او مبين للتوحيد بالآيات البينات والحجج فحتى ليست غاية للتمتع بل لما تسبب عنه من الاغترار المذكور وما يليه
