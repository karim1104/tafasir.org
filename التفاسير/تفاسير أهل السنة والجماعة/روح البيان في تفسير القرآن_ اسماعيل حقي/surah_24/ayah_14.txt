{ ولولا } امتناعية اى لامتناع الشىء لوجود غيره { فضل الله عليكم ورحمته } خطاب للسامعين والمسلمين جميعا { فى الدنيا } من فنون النعم التى من جملتها الامهال بالتوبة { والآخرة } من ضروب الآلاء التى من جملتها العفو والمغفرة المقدران لكم { لمسكم } عاجلا يعنى هر آينه برسيدى شمارا { فما افضتم فيه } اى بسبب ما خضتم فيه من حديث الافك { عذاب عظيم } يستحقر دونه التوبيخ والجلد.
