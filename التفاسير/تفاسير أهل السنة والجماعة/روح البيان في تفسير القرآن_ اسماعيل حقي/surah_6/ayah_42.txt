{ ولقد أرسلنا } اى وبالله لقد ارسلنا رسلا { الى أمم } كثيرة { من قبلك } اى كائنة من زمان قبل زمانك فمن لابتداء الغاية فى الزمان على مذهب الكوفية مثل نمت من اول الليل وصمت من اول الشهر الى آخره. وقال المحشى سنان جلبى من زائدة على قول من جوز زيادتها فى الموجب واما عند غيره فهى بمعنى فى كما فى قوله تعالى الجمعة 9 { فأخذناهم } الفاء فصيحة تفصح ان الكلام مبنى على اعتبار الحذف اى فكذبوا رسلهم فأخذناهم { بالبأساء } اى بالشدة والفقر { والضراء } اى الضر والآفات وهما صيغتا تأنيث لا مذكر لهما { لعلهم يتضرعون } اى لكى يدعوا الله فى كشفها بالتضرع والتذلل ويتوبوا اليه من كفرهم ومعاصيهم.
