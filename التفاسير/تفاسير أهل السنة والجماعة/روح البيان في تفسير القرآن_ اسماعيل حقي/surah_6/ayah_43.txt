{ فلولا } هلا { إذ جاءهم بأسنا } عذابنا { تضرعوا } اى لم يفعلوا ذلك مع قيام المقتضى له فلولا يفيد اللوم والتنديم وذلك عند قيام الداعى الى الفعل وانتفاء العذر فى تركه { ولكن قست قلوبهم } استدراك على المعنى اى لم يتضرعوا ولكن يبست وجفت قلوبهم ولو كان فى قلوبهم رقة وخوف لتضرعوا { وزين لهم الشيطان ما كانوا يعملون } اى حسن لهم الكفر والمعاصى بان اغواهم ودعاهم الى اللذة والراحة دون التفكر والتدبر ولم يخطر ببالهم ان ما اعتراهم من البأساء والضراء ما اعتراهم الا لاجله.
