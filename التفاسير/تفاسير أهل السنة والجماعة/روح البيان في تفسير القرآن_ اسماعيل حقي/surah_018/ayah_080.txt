{ واما الغلام } الذى قتلته وهو جيسور { فكان ابواه } اسم ابيه كازبرا واسم امه سهوى كما فى التعريف { مؤمنين } مقرين بتوحيد الله تعالى { فخشينا } خفنا من { أن يرهقهما } رهقه غشيه ولحقه وارهقه طغيانا اغشاه اياه وألحق ذلك به كما فى القاموس. قال الشيخ ان يكلفهما { طغيانا } ضلالة { وكفرا } ويتبعان له لمحبتهما اياه فيكفران بعد الايمان ويضلان بعد الهداية وانما خشى الخضر من ذلك لان الله اعلمه بحال الولد انه طبع اى خلق كافرا.
