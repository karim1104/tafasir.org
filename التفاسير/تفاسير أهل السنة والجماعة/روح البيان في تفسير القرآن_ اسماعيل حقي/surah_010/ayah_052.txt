{ ثم قيل } عطف على ما قدر قبل آلآن { للذين ظلموا } اى وضعوا التكذيب موضع التصديق والكفر موضع الايمان { ذوقوا عذاب الخلد } عذاب جاويدى كه آن دائم بود وذلك انهم يعذبون فى قبورهم ثم يصيرون الى جهنم فيعذبون فيها ابدا { هل تجزون } اليوم يعنى لا تجزون { الا بما كنتم تكسبون } فى الدنيا من الكفر والمعاصى وفيه تنبيه على ان العذاب لم يصدر منه تعالى ابتداء فانه لم يخلق عباده الا ليرحمهم بل هو نتيج عملهم الباطل بمنزلة الهلاك المترتب على تناول السم
