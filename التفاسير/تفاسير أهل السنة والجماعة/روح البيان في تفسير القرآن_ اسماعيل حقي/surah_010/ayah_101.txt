{ قل انظروا } تفكروا يا اهل مكة { ماذا } مرفوع المحل على الابتداء { فى السموات والارض } خبره اى أى شيء بديع فيهما من عجائب صنعه الدالة على وحدته وكمال قدرته فماذا جعل بالتركيب اسما واحدا مغلبا فيه الاستفهام على اسم الاشارة ويجوز ان يكون اسمين بمعنى ما الذى على ان تكون ما استفهامية مرفوعة على الابتداء والظرف صلة الذى والجملة خبر للمبتدأ وعلى التقديرين فالمبتدأ والخبر فى محل النصب باسقاط للخافض وفعل النظر معلق بالاستفهام { وما } نافية { تغنى الآيات والنذر } جمع نذير على انه فعيل بمعنى منذر او على انه مصدر اى لا تنفع الآيات الا نفسية والآفاقية الدالة على الوحدانية والرسل والمنذرون او الانذارات شيئا { عن قوم لا يؤمنون } فى علم الله تعالى وحكمه
