{ وربك الغنى } عن العباد والعبادة. والغنى هو الذى لا يحتاج الى شئ فيكون وجود كل شئ عنده وعدمه سواء وغيره تعالى لا يسمى غنيا الا اذا لم يبق له حاجة الا الى الله تعالى فاصل الحاجة لا ينقطع عن غير الله لانه فى وجوده وغناه يحتاج الى الغنى الحقيقى { ذو الرحمة } يترحم عليهم بالتكليف تكميلا لهم ويمهلهم على المعاصى. وفى التأويلات النجمية يعنى مع غناه عن الخلق له رحمة قد اقتضت ايجاد الخلق ليربحوا عليه لا ليربح عليهم قال فى المثنوى { ان يشأ يذهبكم } ايها العصاة اى يهلككم { ويستخلف } بالفارسى خليفه وجانشين شما سازد { من بعدكم } اى من بعد اذهابكم واهلاككم { ما يشاء } اى خلقا آخر اطوع لله منكم وايثار ما على من لا ظهار كمال الكبرياء واسقاطهم عن رتبة العقلاء { كما انشأكم من ذرية قوم آخرين } اى من قوم آخرين لم يكونوا على مثل صفتكم وهو اهل سفينة نوح عليه السلام لكنه ابقاكم ترحما عليكم وفى التفسير الفارسى همجنانكه شمارا بيدا كرد از ذرية قومى ديكركه بدران شمابودند.
