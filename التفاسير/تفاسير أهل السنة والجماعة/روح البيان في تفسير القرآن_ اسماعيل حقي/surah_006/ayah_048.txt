{ وما نرسل المرسلين إلا مبشرين ومنذرين } حالان مقدرتان من المرسلين اى ما نرسلهم الا مقدرا تبشيرهم وانذارهم ففيهما معنى العلة الغائية قطعا اى لم نرسلهم لان يقترح عليهم الآيات ويتلهى بهم بل لان يبشروا قومهم بالثواب على الطاعة وينذروهم بالعقاب على المعصية التبشير الاخبار بالخبر السار والانذار الاخبار بالخبر الضار { فمن آمن } بهم { واصلح } عمله او دخل فى الصلاح { فلا خوف عليهم } من العذاب الذى انذروه دنيويا كان او اخرويا { ولا هم يحزنون } بفوات ما بشروا به من الثواب العاجل والآجل.
