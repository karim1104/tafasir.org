{ ربنا لا تزغ قلوبنا } اى يقولون لا تمل قلوبنا عن نهج الحق الى اتباع المتشابه بتأويل لا ترتضيه { بعد اذ هديتنا } الى الحق والتأويل الصحيح او الى الايمان { وهب لنا من لدنك } اى من عندك { رحمة } واسعة تزلفنا اليك ونفوز بها عندك { انك انت الوهاب } واطلاق الوهاب ليتناول كل موهوب. وفيه دلالة على ان الهدى والضلال من قبله وانه متفضل بما ينعم به على عباده من غير ان يجب عليه شىء.
