{ قال } عند نداء الملائكة إياه وبشارتهم له بالولد بالاستفهام متعجبا من حيث العادة ومسرورا بالولد { رب أنى يكون لى } اى كيف يحصل لى { غلام } وفيه دلالة على انه خبر بكونهِ غلاما عند التبشير { وقد بلغنى الكبر } اى ادركنى كبر السن واثر فىّ. وفيه دلالة على ان كبر السن من حيث كونه من طلائع الموت طالب للانسان لا يكاد يتركه قيل كان له تسع وتسعون سنة ولامرأته ثمان وتسعون { وامرأتى عاقر } اى ذات عقر وعقيم لا تلد { قال } اى الله { كذلك } اشارة الى مصدر يفعل فى قوله تعالى { الله يفعل ما يشاء } اى ما يشاء ان يفعله من تعاجيب الافاعيل الخارقة للعادات. فالله مبتدأ ويفعل خبره والكاف فى محل النصب على انها فى الاصل نعت لمصدر محذوف اى الله يفعل ما يشاء ان يفعله فعلا مثل ذلك الفعل العجيب والصنع البديع الذى هو خلق الولد من شيخ فان وعجوز عاقر.
