{ ان اولى الناس بابراهيم } اى ان احق الناس بدعواه انه على دين ابراهيم { للذين اتبعوه } فى زمانه { وهذا النبى } اى محمد المصطفى صلى الله تعالى عليه وسلم لانه اتبعه { والذين آمنوا } بالله وبمحمد صلى الله عليه وسلم من هذه الامة لموافقتهم فى اكثر ما شرعه لهم على الاصالة { والله ولى المؤمنين } ينصرهم ويجازيهم الحسنى بايمانهم.
