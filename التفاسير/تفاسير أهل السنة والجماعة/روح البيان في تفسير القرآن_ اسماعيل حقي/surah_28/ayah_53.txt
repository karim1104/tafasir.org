{ الذين آتيناهم الكتاب } مبتدأ وهم مؤمنوا اهل الكتاب { من قبله } اى من قبل ايتاء القرآن { هم به يؤمنون } اى بالقرآن والجملة خبر المبتدأ ثم بين ما اوجب ايمانهم بقوله { واذا يتلى } اى القرآن { عليهم قالوا آمنا به } اى بانه كلام الله تعالى { انه الحق من ربنا } اى الحق الذى كنا نعرف حقيقته وبالفارسية راست ودرست است فرود آمدن بنزديك آفريد كارما { انا كنا من قبله } اى من قبل نزوله { مسلمين } بيان لكون ايمانهم به ليس مما احدثوه حينئذ وانما هو مر متقادم العهد لما شاهدوا ذكره فى الكتب المتقدمة وانهم على دين الاسلام قبل نزول القرآن
