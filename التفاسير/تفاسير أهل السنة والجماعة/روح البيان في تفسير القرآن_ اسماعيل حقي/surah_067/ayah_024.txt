{ قل } يا اكمل الخلق { هو الذى ذرأكم فى الارض } اى خلقكم وكثركم فيها لا غيره من الذرء وهو بالفارسية آفريدن قال فى القاموس ذرأ كجعل خلق والشئ كثره ومنه الذرية مثلثة لنسل الثقلين { واليه } تعالى لا الى غيره اشتراكا او استقلالا { تحشرون } حشرا جسمانيا اى تجمعون وتبعثون للحساب والجزآء شيأ فشيأ على البرزخ دفعة واحدة يوم البعث فابنوا اموركم على ذلك ختم الآية بقوله واليه تحشرون فبين ان جميع الدلائل المذكورة انما كان لاثبات هذا المطلوب.
