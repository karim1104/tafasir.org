{ ان يثقفوكم } اى يظفروا بكم ويتمكنوا منكم والثقف الحذق فى ادراك الشىء وفعله وثقفت كذا اذا ادركته ببصرك الحذق فى النظر ثم قد تجوز به فاستعمل فى الادراك وان لم يكن معه ثقافة كما فى هذا الموضع ونحوه { يكونوا لكم اعدآء } اى يظهروا مافى قلوبهم من العداوة ويرتبوا عليها احكامها ولا ينفعكم القاء المودة اليهم { ويبسطوا } ويطيلوا { اليكم ايديهم وألسنتهم بالسوء } او بما يسوءكم من القتل والاسر والشتم { وودوا لو تكفرون } اى تمنوا ارتدادكم وكونكم مثلهم كقوله فكلمة لو هنا مصدرية وصيغة الماضى للايذان بتحقق ودادتهم قبل أن يثقفوهم ايضا فهو معطوف على يبسطوا
