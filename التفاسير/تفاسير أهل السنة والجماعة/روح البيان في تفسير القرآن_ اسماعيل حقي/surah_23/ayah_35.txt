{ ايعدكم } ايا وعده ميدهد شمارا اين بيغمبر { انكم اذا متم } بكسر الميم من مات يمات وقرىء بضمها من مات يموت { وكنتم } وصرتم { ترابا وعظاما } نخرة مجردة عن اللحوم والاعصاب اى كان بعض اجزائكم من اللحم ونظائره ترابا وبعضها عظاما وتقديم التراب لعراقته فى الاستبعاد وانقلابه من الاجزاء البادية او كان متقدموكم ترابا صرفا ومتأخروكم عظاما، يقول الفقير الظاهر ان مرادهم بيان صيرورتهم عظاما ثم ترابا لان الواو لمطلق الجمع { انكم } تأكيد للاول لطول الفصل بينه وبين خبره الذى هو قوله { مخرجون } اى من القبور احياء كما كنتم.
