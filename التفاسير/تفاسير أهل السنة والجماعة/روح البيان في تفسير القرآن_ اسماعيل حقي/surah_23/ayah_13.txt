{ ثم جعلناه } اى الجنس باعتبار افراده المغايرة لآدم وقال بعضهم ثم جعلناه اى نسله فحذف المضاف فيكون المراد بالانسان آدم خلق من صفوة سلت من الطين { نطفة } بان خلقناه منها والنطفة الماء الصافى ويعبر بها عن ماء الرجل { فى قرار } اى مستقر وهو الرحم عبر عنها بالقرار الذى هو مصدر مبالغة { مكين } اى حصين وهو وصف لها بصفة مااستقر فيها مثل طريق سائر وبالفارسية در قرار كاهى كه استوار يعنى رحم وجهل روز اورا نكاه داشتيم سفيد
