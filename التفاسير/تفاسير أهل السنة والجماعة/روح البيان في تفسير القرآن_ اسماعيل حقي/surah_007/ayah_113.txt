{ وجاء السحرة فرعون } بعدما ارسل اليهم الحاشرين { قالوا } واثقين بغلبتهم { ان لنا لاجرا ان كنا نحن الغالبين } بطريق الاخبار بثبوت الاجر وايجابه كأنهم قالوا لا بد لنا من اجر عظيم حينئذ او بطريق الاستفهام التقريرى بحذف الهمزة وقولهم ان كنا لمجرد تعيين مناط ثبوت الاجر لا لترددهم فى الغلبة وتوسيط الضمير وتحلية الخبر باللام للقصر اى ان كنا نحن الغالبين لا موسى.
