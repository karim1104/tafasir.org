{ ولما وقع عليهم الرجز } اى العذاب المذكور من الطوفان وغيره اى كلما وقع عليهم عقوبة من تلك العقوبات { قالوا } فى كل مرة { يا موسى ادع لنا ربك بما عهد عندك } الباء صلة لادع وما مصدرية والمراد بالعهد النبوة اى ادع لنا ربك يكشف عنا العذاب بحق ما عندك من عهد الله تعالى وهو النبوة فان حق النبوة ومقتضاها ان يدعو النبى لامته لدفع ما اصابهم من البلايا والمحن سميت النبوة عهدا للمبالغة فى كونها معهودا بها فانه تعالى لما بعثه رسولا واوصاه بتحمل اعباء الرسالة وميثاق التبليغ فقد جعلت النبوة مما اوصى به وعهده فجعلت نفس العهد للمبالغة فى كونها معهودا بها. وفى التفسير الفارسى { بما عهد عندك } بآنجه عهد كرده وآن عهد نزديك تست يعنى خداى تو باتو وعده كرده كه جون اورا بخوانى ابابت كند فما موصولة عبر بها عما يدعو به المتضرع الى الله تعالى فى طلب حاجته والباء ايضا صلة لادع { لئن كشفت } اى بازبرى وزائل كردانى { عنا الرجز } الذى وقع علينا { لنؤمنن لك ولنرسلن معك بنى اسرائيل } الى موطن آبائهم وهو الارض المقدسة ولنطلقنهم من التسخير والاعمال الشاقة.
