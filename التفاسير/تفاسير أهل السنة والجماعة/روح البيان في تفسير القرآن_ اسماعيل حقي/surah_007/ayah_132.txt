{ وقالوا } اى فرعون وقومه بعد ما رأوا من شان العصا والسنين ونقص الثمرات { مهما } اسم شرط يجزم فعلين كقولك مهما تفعل افعل كأن قائلا قال لك لا تقدر على ان تفعل ما افعل فتقول له مهما تفعل افعل ومحله الرفع على الابتداء وخبره فما نحن لك بمؤمنين اى أى شيء وبالفارسية هرجيز كه { تأتنا به } تظهر لدينا وتحضره والضمير لمهما { من آية } بيان لمهما وانما سموها آية على زعم موسى لا لاعتقادهم { لتسحرنا بها } اى لتسحر بتلك الآية اعيننا وتسكرها { فما نحن لك بمؤمنين } اى بمصدقين لك ومؤمنين بنبوتك.
