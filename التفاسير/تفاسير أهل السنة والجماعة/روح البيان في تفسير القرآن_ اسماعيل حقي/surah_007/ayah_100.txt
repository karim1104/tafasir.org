{ أو لم يهد للذين يرثون الارض من بعد اهلها } عدى فعل الهداية باللام لانها بمعنى التبيين والمفعول محذوف والفاعل قوله لو ان لو نشاء ومعنى يرثون الارض من بعد اهلها يخلفون من خلا قبلهم من الامم المهلكة ويرثون ديارهم والمراد بهم اهل مكة ومن حولها. والمعنى او لم يبين ويوضح لهم عاقبة امرهم ان سلكوا طريق اسلافهم { ان } مخففة اى ان الشأن { لو نشاء اصبناهم بذنوبهم } اى بجزاء ذنوبهم وسيآتهم او بسبب ذنوبهم كما اصبنا من قبلهم. قال سعدى جلبى المفتى ويجوز ان يضمن معنى اهلكناهم فلا حاجة الى تقدير المضاف { ونطبع على قلوبهم } عطف على ما يفهم من قوله تعالى { أو لم يهد } كأنه قيل لا يهتدون ونطبع على قلوبهم اى نختم عليها عقوبة لهم { فهم لا يسمعون } اى اخبار الامم المهلكة فضلا عن التدبر والنظر فيها والاغتنام بما فى تضاعيفها من الهدايات. قال الكاشفى كوش دل أز استماع سخن حق فائده داردنه كوش آب وكل
