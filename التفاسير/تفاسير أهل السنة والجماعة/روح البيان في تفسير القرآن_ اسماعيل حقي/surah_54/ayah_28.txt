{ ونبئهم } اخبرهم { ان الماء قسمة بينهم } مقسوم لها يوم ولهم يوم فالماء قسمة من قبيل تسمية المفعول بالمصدر كضرب الامير وبينهم لتغليب العقلاء { كل شرب } اى لك نصيب من الماء ونوبة الانتفاع منه { محتضر } يحضره صاحبه فى نوبته فليس معنى كون الماء مقسوما بين القوم والناقة انه جعل قسمين قسم لها وقسم لهم بل معناه جعل الشرب بينهم على طريق المناوبة يحضره القوم يوما وتحضره الناقة يوما وقسمة الماء اما لان الناقة عظيمة الخلق ينفر منها حيواناتهم او لقلة الماء
