{ او تقول حين ترى العذاب } عيانا ومشاهدة { لو ان لى } لو للتمنى اى كاشكى مرابودى { كرة } رجعة الى الدنيا يقال كر عليه عطف وعنه رجع والكرة المرة والحملة كما فى القاموس { فاكون } بالنصب جواب التمنى يعنى تاباشم آنجا { من المحسنين } فى العقيدة والعمل واو للدلالة على انها لا تخلو عن هذه الاقوال تحيرا وتعللا بما لا طائل تحته وندما حيث لا ينفع وقيل ان قوما يقولون هذا وقوما يقولون ذاك
