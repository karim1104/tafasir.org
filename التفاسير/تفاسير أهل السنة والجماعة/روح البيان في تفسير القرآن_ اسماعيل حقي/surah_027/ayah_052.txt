{ فتلك بيوتهم } حال كونها { خاوية } خالية عن الاهل والسكان من خوى البطن اذا خلا او ساقطة منهدمة من خوى النجم اذا سقط وبالفارسية بس آنست خانهاى ايشان در زمين حجر بنكريدا آنرا درحالتى كه خالى وخرابست { بما ظلموا } اى بسبب ظلمهم المذكور وغيره كالشرك. قال سهل رحمه الله الاشارة فى البيوت الى القلوب فمنها عامرة بالذكر ومنها خراب بالغفلة ومن ألهمه الله الذكر فقد خلص لله من الظلم { ان فى ذلك } المذكور من التدمير العجيب بظلمهم { لآية } لعبرة عظيمة { لقوم يعلمون } يتصفون بالعلم فيتعظون. يعنى اعلم يامحمد انى فاعل ذلك العذاب بكفار قومك فى الوقت الموقت لهم فليسوا خيرا منهم كما فى كشف الاسرار
