{ ائذا متنا وكنا ترابا } اى أحين نموت فتفارق ارواحنا اشباحنا ونصير ترابا لا فرق بيننا وبين تراب الارض نرجع ونبعث كما ينطق به النذير والمنذر به مع كمال التباين بيننا وبين الحياة حينئذ والهمزة للانكار اى لا ترجع ولا نبعث { ذلك } اشارة الى محل النزاع اى مضمون الخبر برجوعها { رجع } الرجع متعد بمعنى الرد بخلاف الرجوع اى رد الى الحياة والى ما كنا عليه { بعيد } جدا عن الاوهام او العادة او الامكان او عن الصدق غير كائن لانه لا يمكن تمييز ترابنا من بقية التراب
