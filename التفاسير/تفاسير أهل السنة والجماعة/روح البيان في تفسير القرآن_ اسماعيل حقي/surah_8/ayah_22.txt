{ إن شر الدواب } اى شر ما يدب على الارض فلفظ الدابة محمول على معناه اللغوى او شر البهائم فهو محمول على معناه العرفى والبهيمة كل ذات اربع من حيوانات البر والبحر { عند الله } اى فى حكم قضائه { الصم } الذين لا يسمعون { البكم } الذين لا ينطقون به { الذين لا يعقلون } الحق عدهم من البهائم ثم جعلهم شرها لابطالهم ما ميزوا به وفضلوا لاجله. وانما وصفهم بعدم العقل لان الاصم الابكم اذا كان له عقل ربما يفهم بعض الامور ويفهمه غيره بالاشارة ويهتدى بذلك الى بعض مطالبه. واما اذا كان فاقدا للعقل ايضا فهو الغاية فى الشريه وسوء الحال قال السعدى
