{ تلك } اى الاحكام التى تقدمت فى امر اليتامى والوصايا والمواريث { حدود الله } شرائعه التى هى كالحدود المحدودة التى لا يجوز مجاوزتها { ومن يطع الله ورسوله } فى جميع الاوامر والنواهى التى من جملتها ما فصل ههنا { يدخله جنات تجرى من تحتها الانهار خالدين فيها } صيغة الجمع اى خالدين بالنظر الى جمعية من بحسب المعنى { وذلك } اى هذا الثواب { الفوز العظيم } اى النجاة الوافرة يوم القيامة والظفر الذى لا ظفر وراءه.
