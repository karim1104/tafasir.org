{ ومن يكسب اثما } من الآثام { فانما يكسبه على نفسه } بحيث لا يتعدى ضرره ووباله الى غيره فليحترز عن تعريضها للعقاب والعذاب عاجلا وآجلا. وفى التأويلات النجمية { فانما يكسبه على نفسه } فان رين الاثم يظهر فى الحال فى صفاء مرآة قلبه يعميه عن رؤية الحق ويصمه عن سماع الحق كما قال تعالى المطففين 14. { وكان الله عليما حكيما } فهو عالم بفعله حكيم فى مجازاته.
