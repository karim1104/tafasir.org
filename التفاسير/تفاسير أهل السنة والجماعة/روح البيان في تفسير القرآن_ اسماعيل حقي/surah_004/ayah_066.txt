{ ولو انا كتبنا عليهم } اى اوجبنا او فرضنا على هؤلاء المنافقين { ان اقتلوا انفسكم او اخرجوا من دياركم } كما اوجبناه على بنى اسرائيل حين طلبوا التوبة من ذنوبهم { ما فعلوه } اى المكتوب المدلول عليه بكتبنا { الا قليل منهم } الا ناس قليل منهم وهم المخلصون { ولو انهم فعلوا ما يوعظون به } من متابعة الرسول وطاعته والمشى تحت رايته والانقياد لما يراه ويحكم به ظاهرا وباطنا وسميت اوامر الله ونواهيه مواعظ لاقترانها بالوعد والوعيد والترغيب والترهيب { لكان } اى فعلهم ذلك { خيرا لهم } اى احمد عاقبة فى الدارين { واشد تثبيتا } لهم على الايمان وابعد من الاضطراب فيه.
