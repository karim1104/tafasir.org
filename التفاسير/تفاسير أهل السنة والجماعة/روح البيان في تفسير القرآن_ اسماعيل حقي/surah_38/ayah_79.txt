{ قال } ابليس { رب } اى بروردكارمن { فانظرنى } الانظار الامهال والتأخير والفاء فصيحة اى اذا جعلتنى رجيما فامهلنى ولا تمتنى { الى يوم يبعثون } من قبورهم للجزاء وهو يوم القيامة والمراد آدم وذريته والبعث مرده رازنده كردن واراد بدعائه ان يجد فسحة لاغوائهم ويأخذ منهم ثاره وينجو من الموت بالكلية اذ لا موت بعد يوم البعث فلم يجب ولم يوصل الى مراده
