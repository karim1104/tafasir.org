{ وقال موسى ان تكفروا } نعمة الله ولم تشكروها { انتم } يا بنى اسرائيل { ومن فى الارض } من الثقلين { جميعا } حال من المعطوف والمعطوف عليه { فان الله } تعليل للجواب المحذوف اى ان تكفروا لم يرجع وباله الا عليكم فان الله { لغنى } على شكركم وشكر غيركم { حميد } محمود فى ذاته وصفاته وافعاله لا تفاوت له بايمان واحد ولا كفره. قال الكاشفى ذرات مخلوقات بنعمت او ناطق والسنة جميع اشيا بتسبيح وحمداو جارى قال السعدى قدس سره
