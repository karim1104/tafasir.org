{ وقد مكروا مكرهم } اى فعلنا بالذين ظلموا ما فعلنا والحال انهم قد مكروا فى ابطال الحق وتقرير الباطل مكرهم العظيم الذى استفرغوا فى عمله المجهود وجاوزنا فى كل حد معهود بحيث لا يقدر عليه غيرهم والمكر خديعة { وعند الله مكرهم } اى جزاء مكرهم الذى فعلوه { وان } وصلية { كان مكرهم } فى العظم والشدة { لتزول منه الجبال } مسوى لازالة الجبال عن مقارّها معدا لذلك. قال فى الارشاد اى وان كان فى غاية المتانة والشدة وعبر عن ذلك بكونه مسوى ومعدا لذلك لكونه مثلا فى ذلك
