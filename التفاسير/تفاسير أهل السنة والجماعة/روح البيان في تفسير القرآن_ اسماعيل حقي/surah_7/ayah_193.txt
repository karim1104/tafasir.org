{ وان تدعوهم } ايها المشركون { الى الهدى } الى ان يهدوكم الى ما تحصلون به مقاصدكم { لا يتبعوكم } الى مرادكم ولا يجيبوكم كما يجيبكم الله { سواء عليكم } ايها المشركون { أدعوتموهم } اىالاصنام { أم أنتم صامتون } ساكتون اى مستوى عليكم فى عدم الافادة دعاؤكم له وسكوتكم فانه لا يتغير حالكم فى الحالين كما لا يتغير حالهم بحكم الجمادية ولم يقل ام صمتم لرعاية رؤوس الآى.
