{ ساء مثلا } ساء بمعنى بئس ومثلا تمييز من الفاعل المضمر فى ساء مفسر له { القوم } مخصوص بالذم بتقدير المضاف لوجوب التصادف بينه وبين الفاعل والتمييز اى شاء مثلا مثل القوم وبئس الوصف وصف القوم. قال الحدادى وهذا السوء انما يرجع الى فعلهم لا الى نفس المثل كأنه قال ساء فعلهم الذى جلب اليهم الوصف القبيح فاما المثل فهو من الله حكم وصواب { الذين كذبوا بآياتنا } بعد قيام الحجة عليها وعلمهم بها { وانفسهم كانوا يظلمون } اى ما ظلموا بالتكذيب الا انفسهم فان وباله لا يتخطاها.
