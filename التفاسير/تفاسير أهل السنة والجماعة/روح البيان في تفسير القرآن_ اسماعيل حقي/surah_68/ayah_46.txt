{ ام تسألهم } آيا مبطلى از ايشان برابلاغ وارشاد ودعوت ايمان وطاعت. وهو معطوف على قوله ام لهم شركاء { اجرا } دنيويا { فهم } لاجل ذلك { من مغرم } اى من غرامة مالية وهى ما ينوب الانسان فى ماله من ضرر لغير جناية منه { مثقلون } مكلفون حملا ثقيلا فيعرضون عنك اى لا تسأل منهم ذلك فليس لهم عذر فى اعراضهم وفرارهم.
