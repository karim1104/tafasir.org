{ ذلك } الله العظيم الشان المتصف بالخلق والاستواء وانحصار الولاية والنصرة فيه وتدبير امر الكائنات { عالم الغيب } ما غاب عن الخلق { والشهادة } ما حضر لهم ويدبر امرهما حسبما يقتضيه. وقال الكاشفى داند امور دنيا وآخرت يا عالم بآنجه بوده باشد وخواهد بود. وقال بعض الكبار الغيب الروح والشهادة النفس والبدن { العزيز } الغالب على امره { الرحيم } علىعباده فى تدبيره. وفيه ايماء الى انه تعالى يراعى المصالح تفضلا واحسانا لا ايجابا
