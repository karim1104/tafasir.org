{ ان نقول الا اعتراك } قوله اعتراك جملة مفسرة لمصدر محذوف تقديره ما نقول فى شأنك الا قولنا اعتراك اى اصابك من عراه يعره اذا اصابه { بعض آلهتنا بسوء } الباء للتعدية. والمعنى بالفارسية مكر آنكه رسانيده اند بتو برخى ازخدايان ما رنجى وكزندى وعلتى اى بجنون لسبك اياها وصدك عنها وعداوتك مكافاة لك منها على سوء فعلك بسوء الجزاء فمن ثم تتكلم بكلام المجانين وتهذى بهذيان المبرسمين { قال } هود { انى اشهد الله واشهدوا } اى واقول اشهدوا لئلا يلزم عطف الانشاء على الخبر { انى بريئ } تنازع فيه اشهد الله واشهدوا اى على انى بريئ { مما تشركون } اى من اشراككم
