{ قال } نوح { يا قوم } اى كروه من { أرأيتم } اى اخبرونى فان الرؤية سبب للاخبار { ان كنت على بينة } برهان ظاهر { من ربى } وشاهد يشهد بصحة دعواى { وآتانى رحمة من عنده } هى النبوة { فعميت عليكم } اى اخفيت تلك البينة عليكم { انلزمكموها } اى نلزمكم قبول تلك البينة ونوجبها عليكم ونجبركم على الاهتداء بها. وهذا استفهام معناه الانكار يقول لا نقدر ان نلزمكم من ذات انفسنا وهو جواب ارأيتم وساد مسد جواب الشرط { وانتم لها كارهون } والحال انكم لا تختارونها ولا تتاملون فيها ومحصول الجواب اخبرونى ان كنت على حجة ظاهرة الدلالة على صحة الدعوى الا انها خافية عليكم غير مسلمة عندكم أيمكننا ان نكرهكم على قبولها وانتم معرضون عنها غير متدبرين فيها اى لا يكون ذلك. قال سعدى المفتى المراد الزام جبر بالقتل ونحوه فاما الزام الايجاب فهو حاصل. قال قتادة لو قدر الانبياء ان يلزموا قومهم الايمان لالزموهم ولكن لم يقدروا
