{ وإن منكم } خطاب لعسكر رسول الله صلى الله عليه وسلم كلهم المؤمنين والمنافقين { لمن } الذى اقسم بالله { ليبطئن } ليتأخرن عن الغزو ويتخلفن تثاقلا من بطأ لازم بمعنى ابطأ او ليبطئن غيره ويثبطه عن الجهاد وكان هذا ديدن المنافق عبد الله بن ابى وهو الذى يثبط الناس يوم احد والاول انسب لما بعده وهو قوله تعالى حكاية النساء 73. وبالجملة المراد بالمبطئين المنافقون من العسكر لانهم كانوا يغزون نفاقا { فان اصابتكم مصيبة } نالتكم نكبة من الاعداء كقتل وهزيمة { قال } اى المبطىء فرحا بصنعه حامدا لربه { قد انعم الله على } اى بالقعود والتخلف عن القتال { اذ لم اكن معهم شهيدا } اى حاضرا فى المعركة فيصيبنى ما اصابهم.
