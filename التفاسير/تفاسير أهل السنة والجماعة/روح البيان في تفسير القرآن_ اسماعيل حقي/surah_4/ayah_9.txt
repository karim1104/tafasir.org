{ وليخش الذين } صفتهم وحالهم انهم { لو تركوا } اى لو شارفوا ان يتركوا { من خلفهم } اى بعد موتهم { ذرية ضعافا } اولادا عجزة لا غنى لهم وذلك عند احتضارهم { خافوا عليهم } اى الضياع بعدهم لذهاب كافلهم وكاسبهم والفقر والتكفف والمراد بالذين هم الاوصياء امروا ان يخشوا الله فيخافوا على من فى حجورهم من اليتامى وليشفقوا عليهم خوفهم على ذريتهم لو تركوهم ضعافا وشفقتهم عليهم وان يقدروا ذلك فى انفسهم ويصوروه حتى لا يجسروا على خلاف الشفقة والرحمة { فليتقوا الله } فى ذرارى غيرهم { وليقولوا قولا سديدا } اى وليقولوا لليتامى مثل ما يقولون لأولادهم بالشفقة وحسن الادب والترهيب ويدعوهم بيابنى ويا ولدى ولا يؤذوهم.
