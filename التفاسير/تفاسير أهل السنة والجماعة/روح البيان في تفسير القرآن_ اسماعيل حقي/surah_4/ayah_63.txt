{ اولئك } اى المنافقون { الذين يعلم الله ما فى قلوبهم } من النفاق فلا يغنى عنهم الكتمان والحلف الكاذب من العقاب { فاعرض عنهم } اى لا تقبل اعتذارهم ولا تفرج عنهم بدعائك { وعظهم } اى ازجرهم عن النفاق والكيد { وقل لهم فى انفسهم } اى فى حق انفسهم الخبيثة وقلوبهم المطوية على الشرور التى يعلمها الله تعالى او فى انفسهم خاليا بهم ليس معهم غيرهم مسارا بالنصيحة لانها فى السر انجع { قولا بليغا } مؤثرا واصلا الى كنه المراد مطابقا لما سيق له المقصود والقول البليغ بان يقول ان الله يعلم سركم وما فى قلوبكم فلا يغنى عنكم اخفاؤه فاصلحوا انفسكم وطهروا قلوبكم من رذيلة الكفر وداووها من مرض النفاق والا انزل الله بكم ما انزل بالمجاهرين بالشرك وشرا من ذلك واغلظ عسى ان تنجع فيهم الموعظة.
