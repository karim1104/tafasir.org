{ واخذهم الربوا وقد } اى والحال انهم قد { نهوا عنه } فان الربا كان محرما عليهم كما هو محرم علينا. وفيه دليل على ان النهى يدل على حرمة المنهى عنه { واكلهم اموال الناس بالباطل } بالرشوة وسائر الوجوه المحرمة { واعتدنا } اى خلقنا وهيأنا { للكافرين منهم } اى للمصرين على الكفر لا لمن تاب وآمن من بينهم { عذابا اليما } وجيعا يخلص وجعه الى قلوبهم سيذوقونه فى الآخرة كما ذاقوا فى الدنيا عقوبة التحريم.
