{ وقال الذى آمن } اى مؤمن آل فرعون { يا قوم اتبعون } فيما دللتكم عليه اصله يا قومى اتبعونى { اهدكم سبيل الرشاد } اى سبيلا يصل سالكه الى المقصود والرشد والرشاد الاهتدآء لمصالح الدين والدنيا وفيه تعريض بان ما يسلكه فرعون وقومه سبيل الغى والضلال وفيه اشارة الى ان لهداية مودعة فى اتباع الانبياء والاولياء وللولى ان يهدى سبيل الرشاد بتبعية النبى عليه السلام كما يهدى النبى اليه ومن الهداية قوله
