{ فلما رأوا } اى الامم السالفة المكذبة { بأسنا } شدة عذابنا فى الدنيا ووقعوا فى مذلة الخيبة ومنه قوله تعالى اى شديد { قالوا } مضطرين { آمنا بالله وحده } بخداى يكبتا { وكفرنا بما كنا به } اى بسبب الايمان به يعنون الاصنام { مشركين } يعنى ازانباز كه ميكفتيم بيزار وبرى كشتيم وهذه الفاء لمجرد التعقيب وجعل ما بعدها تابعا لما قبلها واقعا عقيبه لان مضمون قوله تعالى الخ هو انهم كفروا فصار مجموع الكلام بمنزلة ان يقال فكفروا ثم لما رأوا بأسنا آمنوا
