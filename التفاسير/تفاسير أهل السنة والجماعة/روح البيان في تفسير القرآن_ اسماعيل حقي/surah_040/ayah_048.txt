{ قال الذين استكبروا } جه جاى اين سخن است { انا كل } اى كلنا نحن وانتم وبهذا صح وقوعه مبتدأ { فيها } خبر اى فى النار فكيف نغنى عنكم ولو قدرنا لاغنينا عن انفسنا { ان الله قد حكم بين العباد } بماهية كل احد فادخل المؤمنين الجنة على تفاوتهم فى الدرجات والكافرين النار على طبقاتهم فى الدركات ولا معقب لحكمه
