{ واذا رأى الذين ظلموا } كفروا { العذاب } الذى يستوجبونه بظلمهم وهو عذاب جهنم صاحبوا وطلبوا من مالك تخفيف العذاب { فلا يخفف عنهم } ذلك العذاب بعد الدخول { ولا هم ينظرون } اى لا يمهلون قبله ليستريحوا اى زمانى ايشانرا مهلت ندهند وبى عذاب نكذارند فكل من وضع الكفر واعمال الطبيعة موضع الايمان واعمال الشريعة فلا يخفف عنه اثقال الاخلاق الذميمة ولا يؤخر لتبديل مذمومها بمحمودها.
