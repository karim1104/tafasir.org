{ ويجعلون } اى كفار مكة { لما لا يعلمون } اى للأصنام التى لا يعلم الكفار حقيقتها وقدرها الخسيس ويعقتدون فيها انما تضرو وتنفع وتشفع عند الله تعالى { نصيبا } بهره { مما رزقناهم } من الزرع والانعام وغيرهما تقربا اليها فقالوا هذا لله. بزعمهم وهذا لشركائنا وهو مذكور فى الانعام ويحتمل ان يعود ضمير لا يعلمون الى الاصنام وصيغة جمع العقلاء لكون ما عبارة عن آلهتهم التى وصفوها بصفات العقلاء اى الاشياء التى غير موصوفة بالعلم ولا تشعر أجعلوا لها نصيبا وحظا فى انعامهم وزروعهم ام لا { تالله لتسألن } سؤال توبيخ وتقريع { عما كنتم تفترون } فى الدنيا بأنها آلهة حقيقة بان يتقرب اليها. وفيه اشارة الى ان اصحاب النفوس والاهواء يجعلون مما رزقهم الله من الطاعات نصيبا بالرياء لمن لا علم لهم باحوالهم ليحسنوا فى حقهم ظنا ويكتسبوا عندهم منزلة وهم غافلون فارغون عن توهمهم وافترائهم فى نفوسهم عليهم
