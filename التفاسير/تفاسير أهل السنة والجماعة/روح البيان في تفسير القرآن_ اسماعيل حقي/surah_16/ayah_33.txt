{ هل ينظرون } ايا انتظار ميبرند كفار مكة اى ما ينتظرون { الا ان تأتيهم الملائكة } اى ملك الموت واعوانه لقبض ارواحهم بالعذاب لمواظبتهم على الاسباب الموجبة له المؤدية اليه فكأنهم يقصدون اتيانه ويترصدون لوروده { او يأتى امر ربك } اى العذاب الدنيوى وقد اتى يوم بدر { كذلك } مثل فعل هؤلاء من الشرك والظلم والتكذيب والاستهزاء { فعل الذين } خلوا { من قبلهم } من الامم { وما ظلمهم الله } بما سيتلى من عذابهم { ولكن كانوا انفسهم يظلمون } بالكفر والمعاصى المؤدية اليه.
