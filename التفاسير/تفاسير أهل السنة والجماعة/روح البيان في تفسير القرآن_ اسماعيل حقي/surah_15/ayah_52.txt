{ اذ دخلوا عليه } ظرف لضيف فانه مصدر فى الاصل { فقالوا } عند دخولهم عليه { سلاما } اى نسلم سلاما قال سلام فما لبث ان جاء يعجل حنيذ فلما رأى ايديهم لا تصل اليه نكرهم واوجس منهم خيفة { قال } ابراهيم { انا منكم وجلون } خائفون فان الوجل اضطراب النفس لتوقع مكروه وانما قاله عليه السلام حين امتنعوا من اكل ما قربه اليهم من العجل الحنيذ لما ان المعتاد عندهم انه اذا نزل بهم ضيف فلم يأكل من طعامهم ظنوا انه لم يجئ بخير لا عند ابتداء دخولهم
