و : { سلاماً } منصوب على المصدر كأنهم قالوا : تسلم سلاماً ،   أو سلمت سلاماً{[10604]} ،   ويتجه فيه أن يعمل فيه { قالوا } على أن نجعل { سلاماً } بمنزلة قولاً .   ويكون المعنى حينئذ أنهم قالوا تحية وقولاً معناه : { سلاماً } وهذا قول مجاهد .  <br />
وقوله : { سلام } مرتفع على خبر ابتداء .   أي أمر { سلام } .   أو واجب لكم { سلام } ،   أو على الابتداء والخبر محذوف ،   كأنه قال : سلام عليكم وإبراهيم عليه السلام قد حيا بأحسن لأن قولهم دعاء وقوله واجب قد تحصل لهم .  <br />
وقرأ ابن وثاب والنخعي وحمزة والكسائي وطلحة وابن جبير قال : «سِلْم » بكسر السين وسكون اللام .   والمعنى نحن سلم وأنتم سلم .  <br />
وقوله : { قوم منكرون } معناه : لا نميزهم ولا عهد لنا بهم .   وهذا أيضاً على تقدير : أنتم { قوم منكرون } وقال أبو العالية : أنكر سلامهم في تلك الأرض وفي ذلك الزمن .
