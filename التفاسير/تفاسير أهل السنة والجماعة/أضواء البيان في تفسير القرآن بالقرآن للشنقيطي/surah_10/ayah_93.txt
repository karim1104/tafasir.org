قوله تعالى :  {  وَلَقَدْ بَوَّأْنَا بَنِى إِسْرَاءِيلَ مُبَوَّأَ صِدْقٍ } الآية . <br />
ذكر تعالى في هذه الآية :  أنه بوأ بني إسرائيل مبوأ صدق . <br />
وبين ذلك في آيات أخر كقوله :  {  وَأَوْرَثْنَا الْقَوْمَ الَّذِينَ كَانُواْ يُسْتَضْعَفُونَ مَشَارِقَ الأرض وَمَغَارِبَهَا التي بَارَكْنَا فِيهَا } [ الأعراف :  137 ] الآية ،  وقوله :  {  فَأَخْرَجْنَاهُمْ مِّن جَنَّاتٍ وَعُيُونٍ وَكُنُوزٍ وَمَقَامٍ كَرِيمٍ } [ الشعراء :  57 -58 ] إلى قوله :  {  كَذَلِكَ وَأَوْرَثْنَاهَا بَنِى إِسْرَاءِيلَ } [ الشعراء :  59 ] وقوله :  {  كَمْ تَرَكُواْ مِن جَنَّاتٍ وَعُيُونٍ } {  وَزُرُوعٍ وَمَقَامٍ كَرِيمٍ } إلى قوله :  {  كَذَلِكَ وَأَوْرَثْنَاهَا قَوْماً ءَاخَرِينَ } [ الدخان :  26 – 28 ] ومعنى {  بَوَّأْنَا بَنِى إِسْراءيلَ مُبَوَّأَ صِدْقٍ } أنزلناهم منزلاً مرضياً حسناً .
