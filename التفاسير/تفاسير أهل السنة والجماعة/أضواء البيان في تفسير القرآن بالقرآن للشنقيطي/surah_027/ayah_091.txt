قوله تعالى :  {  إِنَّمَآ أُمِرْتُ أَنْ أَعْبُدَ رَبِّ هَذِهِ الْبَلْدَةِ } . <br />
جاء معناه موضحًا في آيات كثيرة ؛  كقوله تعالى :  {  قُلْ يا أَيُّهَا النَّاسُ إِن كُنتُمْ في شَكّ مّن ديني فَلاَ أَعْبُدُ الَّذِينَ تَعْبُدُونَ مِن دُونِ اللَّهِ وَلَكِنْ أَعْبُدُ اللَّهَ الَّذِي يَتَوَفَّاكُمْ } [ يونس :  104 ] الآية ،  وقوله تعالى :  {  فَلْيَعْبُدُواْ رَبَّ هَذَا الْبَيْتِ * الَّذِي أَطْعَمَهُم مّن جُوعٍ وَءامَنَهُم مّنْ خوْفٍ } [ قريش :  3-4 ] ،  إلى غير ذلك من الآيات . <br />
قوله تعالى :  {  وَأُمِرْتُ أَنْ أَكُونَ مِنَ الْمُسْلِمِينَ وَأَنْ أَتْلُوَ القرآن } [ 91-92 ] . <br />
قد قدّمنا الآيات التي فيها زيادة إيضاح لقوله :  {  وَأُمِرْتُ أَنْ أَكُونَ مِنَ الْمُسْلِمِينَ } ،  في سورة «الأنعام » ،  في الكلام على قوله تعالى :  {  وَأُمِرْتُ أَنْ أَكُونَ أَوَّلَ مَنْ أَسْلَمَ } [ الأنعام :  14 ] . <br />
وقد قدّمنا الآيات الموضحة لقوله تعالى هنا :  {  وَأَنْ أَتْلُوَ القرآن } ،  في سورة «الكهف » ،  في الكلام على قوله تعالى :  {  وَاتْلُ مَا أُوْحِىَ إِلَيْكَ مِن كِتَابِ رَبّكَ } [ الكهف :  27 ] الآية .
