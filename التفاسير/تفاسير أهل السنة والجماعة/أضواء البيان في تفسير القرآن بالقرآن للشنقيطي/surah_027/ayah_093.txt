قوله تعالى :  {  وَقُلِ الْحَمْدُ للَّهِ سَيُرِيكُمْ ءَايَاتِهِ فَتَعْرِفُونَهَا } . <br />
جاء معناه في غير هذا الموضع ؛  كقوله تعالى :  {  سَنُرِيهِمْ آيَاتِنَا في الآفَاقِ وَفِى أَنفُسِهِمْ حَتَّى يَتَبَيَّنَ لَهُمْ أَنَّهُ الْحَقُّ } [ فصلت :  53 ] . <br />
قوله تعالى :  {  وَمَا رَبُّكَ بِغَافِلٍ عَمَّا تَعْمَلُونَ }[ 93 ] . <br />
جاء معناه موضحًا في آيات كثيرة ؛  كقوله تعالى :  {  وَلاَ تَحْسَبَنَّ اللَّهَ غَافِلاً عَمَّا يَعْمَلُ الظَّالِمُونَ إِنَّمَا يُؤَخّرُهُمْ لِيَوْمٍ تَشْخَصُ فِيهِ الأبْصَارُ } [ إبراهيم :  42 ] ،  إلى غير ذلك من الآيات . <br />
وقرأ نافع وابن عامر وحفص عن عاصم :  {  عَمَّا تَعْمَلُونَ } بتاء الخطاب ،  وقرأ الباقون {  عَمَّا يَعْمَلُونَ } بياء الغيبة . <br />
تم بحمد الله تفسير سورة النمل
