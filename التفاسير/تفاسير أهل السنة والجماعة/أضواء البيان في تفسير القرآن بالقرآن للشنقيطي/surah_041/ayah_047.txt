قوله تعالى :  {  إِلَيْهِ يُرَدُّ عِلْمُ السَّاعَةِ } . <br />
تقدم الكلام على نحوه في سورة الأعراف في الكلام على قوله تعالى :  {  قُلْ إِنَّمَا عِلْمُهَا عِنْدَ رَبِّي لاَ يُجَلِّيهَا لِوَقْتِهَآ إِلاَّ هُوَ } [ الأعراف :  187 ] وفي الأنعام عند قوله تعالى :  {  وَعِندَهُ مَفَاتِحُ الْغَيْبِ لاَ يَعْلَمُهَآ إِلاَّ هُوَ } [ الأنعام :  59 ] . <br />
قوله تعالى :  {  وَمَا تَحْمِلُ مِنْ أُنْثَى وَلاَ تَضَعُ إِلاَّ بِعِلْمِهِ } . <br />
قد قدمنا الكلام عليه في سورة الرعد في الكلام على قوله تعالى :  {  اللَّهُ يَعْلَمُ مَا تَحْمِلُ كُلُّ أُنثَى وَمَا تَغِيضُ الأرحام وَمَا تَزْدَادُ } [ الرعد :  8 ] الآية .
