قوله تعالى :  {  يا أَيُّهَا الَّذِينَ كَفَرُواْ لاَ تَعْتَذِرُواْ الْيَوْمَ } . <br />
لم يبيّن هنا نوع الاعتذار الذي نهوا عنه ولا سبب النهي عنه لماذا ؟  ولا زمنه ،  وقد بين تعالى نوع اعتذارهم في مثل قوله تعالى :  {  حَتَّى إِذَا ادَّارَكُواْ فِيهَا جَمِيعًا قَالَتْ أُخْرَاهُمْ لأَولاَدهُمْ رَبَّنَا هؤلاء أَضَلُّونَا فآتِهِمْ عَذَابًا ضِعْفًا مِّنَ النَّارِ } [ الأعراف :  38 ] . <br />
وكقوله تعالى :  {  ثُمَّ لَمْ تَكُنْ فِتْنَتُهُمْ إِلاَّ أَن قَالُواْ وَاللَّهِ رَبِّنَا مَا كُنَّا مُشْرِكِينَ انظر كيف كذبوا على أنفسهم } [ الأنعام :  27 ] . <br />
وكقوله بعدها :  {  وَلَوْ تَرَى إِذْ وُقِفُواْ عَلَى النَّارِ فَقَالُواْ يا لَيْتَنَا نُرَدُّ وَلاَ نُكَذِّبَ بِآيَاتِ رَبِّنَا وَنَكُونَ مِنَ الْمُؤْمِنِينَ } [ الأنعام :  23- 24 ] فهذا غاية في الاعتذار ،  ولكنهم نهوا عنه وذلك يوم القيامة ،  كما في قوله :  {  إِذْ وُقِفُواْ عَلَى النَّارِ فَقَالُواْ يا لَيْتَنَا نُرَدُّ } [ الأنعام :  27 ] أي :  إلى الدنيا . <br />
وقد نهوا عن هذا الاعتذار لأنه لا ينفعهم كما في قوله تعالى :  {  فَيَوْمَئِذٍ لاَّ ينفَعُ الَّذِينَ ظَلَمُواْ مَعْذِرَتُهُمْ وَلاَ هُمْ يُسْتَعْتَبُونَ } [ الروم :  57 ] . <br />
وقوله :  {  يَوْمَ لاَ يَنفَعُ الظَّالِمِينَ مَعْذِرَتُهُمْ وَلَهُمُ الْلَّعْنَةُ وَلَهُمْ سُوءُ الدَّارِ } [ غافر :  52 ] .
