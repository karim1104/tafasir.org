قوله تعالى :  {  وَءَاتَيْنَاهُمْ ءَايَاتِنَا فَكَانُواْ عَنْهَا مُعْرِضِينَ } . <br />
ذكر تعالى في هذه الآية الكريمة أنه آتى أصحاب الحجر  وهم ثمود  آياته فكانوا عنها معرضين .  والإعراض :  الصدود عن الشيء وعدم الالتفات إليه ؛  كأنه مشتق من العرض  بالضم  وهو الجانب .  لأن المعرض لا يولي وجهه بل يثنى عطفه ملتفتاً صاداً . <br />
ولم يبين جل وعلا هنا شيئاً من تلك الآيات التي آتاهم ،  ولا كيفية إعراضهم عنها ،  ولكنه بين ذلك في مواضع أخر .  فبين أن من أعظم الآيات التي آتاهم :  تلك الناقة التي أخرجها الله لهم .  بل قال بعض العلماء :  إن في الناقة المذكورة آيات جمة :  كخروجها عشراء ،  وبراء ،  جوفاء من صخرة صماء ،  وسرعة ولادتها عند خروجها ،  وعظمها حتى لم تشبهها ناقة ،  وكثرة لبنها حتى يكفيهم جميعاً ،  وكثرة شربها .  كما قال تعالى :  {  لَّهَا شِرْبٌ وَلَكُمْ شِرْبُ يَوْمٍ مَّعْلُومٍ } [ الشعراء : 155 ] وقال :  {  وَنَبِّئْهُمْ أَنَّ الْمَآءَ قِسْمَةٌ بَيْنَهُمْ كُلُّ شِرْبٍ مُّحْتَضَرٌ } [ القمر :  28 ] . <br />
فإذا علمت ذلك فاعلم أن مما يبين قوله تعالى :  {  وَءَاتَيْنَاهُمْ ءَايَاتِنَا } قوله :  {  فَأْتِ بِآيَةٍ إِن كُنتَ مِنَ الصَّادِقِينَ قَالَ هَذِهِ نَاقَةٌ لَّهَا شِرْبٌ وَلَكُمْ شِرْبُ يَوْمٍ مَّعْلُومٍ } [ الشعراء : 154-155 ] .  وقوله :  {  قَدْ جَآءَتْكُم بَيِّنَةٌ مِّن رَّبِّكُمْ هَذِهِ نَاقَةُ اللَّهِ لَكُمْ ءَايَةً فَذَرُوهَا تَأْكُلْ في أَرْضِ اللَّهِ وَلاَ تَمَسُّوهَا بِسُوءٍ } [ الأعراف : 73 ] الآية .  وقوله :  {  وَءَاتَيْنَا ثَمُودَ النَّاقَةَ مُبْصِرَةً } [ الإسراء : 59 ] الآية .  وقوله :  {  إِنَّا مُرْسِلُواْ النَّاقَةِ فِتْنَةً لَّهُمْ فَارْتَقِبْهُمْ وَاصْطَبِرْ } [ القمر :  27 ] وقوله :  {  وَيا قَوْمِ هَذِهِ نَاقَةُ اللَّهِ لَكُمْ ءَايَةً فَذَرُوهَا تَأْكُلْ فِى أَرْضِ اللَّهِ وَلاَ تَمَسُّوهَا بِسُوءٍ فَيَأْخُذَكُمْ عَذَابٌ قَرِيبٌ } [ هود :  64 ] إلى غير ذلك من الآيات . <br />
وبين إعراض قوم صالح عن تلك الآيات في مواضع كثيرة ؛  كقوله :  {  فَعَقَرُواْ النَّاقَةَ وَعَتَوْاْ عَنْ أَمْرِ رَبِّهِمْ وَقَالُواْ يَا صَالحُ ائْتِنَا بِمَا تَعِدُنَآ إِن كُنتَ مِنَ الْمُرْسَلِينَ } [ الأعراف :  77 ] وقوله {  فَعَقَرُوهَا فَقَالَ تَمَتَّعُواْ فِى دَارِكُمْ ثَلَاثَةَ أَيَّامٍ } [ هود : 65 ] الآية .  وقوله :  {  كَذَّبَتْ ثَمُودُ بِطَغْوَاهَآ إِذِ انبَعَثَ أَشْقَاهَا فَقَالَ لَهُمْ رَسُولُ اللَّهِ نَاقَةَ اللَّهِ وَسُقْيَاهَا فَكَذَّبُوهُ فَعَقَرُوهَا فَدَمْدمَ عَلَيْهِمْ رَبُّهُمْ بِذَنبِهِمْ فَسَوَّاهَا } [ الشمس : 11-14 ] الآية .  وقوله :  {  فَنَادَوْاْ صَاحِبَهُمْ فَتَعَاطَى فَعَقَرَ } [ القمر : 29 ] .  وقوله :  {  وَءَاتَيْنَا ثَمُودَ النَّاقَةَ مُبْصِرَةً فَظَلَمُواْ بِهَا } [ الإسراء : 59 ] .  وقوله :  {  قَالُواْ إِنَّمَآ أَنتَ مِنَ الْمُسَحَّرِينَ مَآ أَنتَ إِلاَّ بَشَرٌ مِّثْلُنَا فَأْتِ بِآيَةٍ } [ الشعراء :  153-154 ] .  إلى غير ذلك من الآيات .
