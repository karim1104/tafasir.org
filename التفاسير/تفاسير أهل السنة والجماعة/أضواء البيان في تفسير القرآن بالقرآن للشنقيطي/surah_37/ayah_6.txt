قوله تعالى : {  إِنَّا زَيَّنَّا السَّمَاء الدُّنْيَا بِزِينَةٍ الْكَواكِبِ } . <br />
قد قدّمنا الآيات الموضحة له في سورة «الأنعام » ، في الكلام على قوله تعالى :  {  وَهُوَ الَّذِي جَعَلَ لَكُمُ النُّجُومَ لِتَهْتَدُواْ بِهَا } [ الأنعام :  97 ] الآية .  وقرأ هذا الحرف السبعة غير عاصم وحمزة ،  بإضافة {  زِينَةُ } إلى {  الْكَواكِبِ } ،  أي :  بلا تنوين في {  زِينَةُ } مع خفض الباء في {  الْكَواكِبِ } .  وقرأه حمزة وحفص عن عاصم بتنوين {  زِينَةُ } ،  وخفض {  الْكَواكِبِ } على أنه بدل من {  زِينَةُ } .  وقرأه أبو بكر عن عاصم :  {  بِزِينَةٍ الْكَواكِبِ } ،  بتنوين {  زِينَةُ } ،  ونصب {  الْكَواكِبِ } ،  وأعرب أبو حيان {  الْكَواكِبِ } على قراءة النصب إعرابين : <br />
أحدهما :  أن {  الْكَواكِبِ } بدل من {  السَّمَاء } في قوله تعالى :  {  إِنَّا زَيَّنَّا السَّمَاء } . <br />
والثاني :  أنه مفعول به ل :  {  زِينَةُ } بناء على أنه مصدر منكر ؛  كقوله تعالى :  {  أَوْ إِطْعَامٌ في يَوْمٍ ذي مَسْغَبَةٍ * يَتِيماً } الآية . <br />
والأظهر عندي :  أنه مفعول فعل محذوف ،  تقديره :  أعني {  الْكَواكِبِ } ،  على حدّ قوله في «الخلاصة » : <br />
ويحذف الناصبها إن علما ***  وقد يكون حذفه متلزما
