قوله تعالى :  {  وَاجْنُبْنِي وَبَنِىَّ أَن نَّعْبُدَ الأَصْنَامَ } . <br />
لم يبين هنا هل أجاب دعاء نبيه إبراهيم هذا ولكنه بين في مواضع أخر أنه أجابه في بعض ذريته دون بعض كقوله :  {  وَمِن ذُرِّيَّتِهِمَا مُحْسِنٌ وَظَالِمٌ لِّنَفْسِهِ مُبِينٌ } [ الصافات : 113 ] وقوله :  {  وَجَعَلَهَا كَلِمَةً بَاقِيَةً في عَقِبِهِ } [ الزخرف :  28 ] الآية .
