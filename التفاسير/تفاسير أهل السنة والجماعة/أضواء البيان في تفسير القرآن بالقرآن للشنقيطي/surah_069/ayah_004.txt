وجاء بعدها {  كَذَّبَتْ ثَمُودُ وَعَادٌ بِالْقَارِعَةِ } وهي من أسماء القيامة أيضاً ،  كما قال تعالى :  {  وَمَآ أَدْرَاكَ مَا الْقَارِعَةُ يَوْمَ يَكُونُ النَّاسُ كَالْفَرَاشِ الْمَبْثُوثِ } [ القارعة :  3 -14 ] الآية . <br />
سميت بالحاقة لأنه يحق فيها وعد الله بالبعث والجزاء ،  وسميت بالقارعة ،  لأنها تقرع القلوب بهولها {  وَتَرَى النَّاسَ سُكَارَى وَمَا هُم بِسُكَارَى } [ الحج :  2 ] . <br />
كما سميت الواقعة {  الْوَاقِعَةُ لَيْسَ لِوَقْعَتِهَا كَاذِبَةٌ } [ الواقعة :  2 ] . <br />
قوله تعالى :  {  كَذَّبَتْ ثَمُودُ وَعَادٌ بِالْقَارِعَةِ فَأَمَّا ثَمُودُ فَأُهْلِكُواْ بِالطَّاغِيَةِ } .  والطَّاغية فاعلة من الطُّغيان ،  وهو مجاوزة الحد مطلقاً ،  كقوله :  {  إِنَّا لَمَّا طَغَا الْمَآءُ } [ الحاقة :  11 ] . <br />
وقوله :  {  إِنَّ الإِنسَانَ لَيَطْغَى } [ العلق :  6 ] . <br />
وقد اختلف في معنى الطغيان هنا ،  فقال قوم :  طاغية عاقر الناقة ،  كما في قوله تعالى :  {  كَذَّبَتْ ثَمُودُ بِطَغْوَاهَآ إِذِ انبَعَثَ أَشْقَاهَا } [ الشمس :  11 -12 ] فتكون الباء سببية أي بسبب طاغيتها ،  وقيل :  الطاغية الصيحة الشديدة التي أهلكتهم ،  بدليل قوله تعالى :  {  إِنَّآ أَرْسَلْنَا عَلَيْهِمْ صَيْحَةً وَاحِدَةً فَكَانُواْ كَهَشِيمِ الْمُحْتَظِرِ } [ القمر :  31 ] فتكون الباء آلية ،  كقولك :  كتبت بالقلم وقطعت بالسكين . <br />
والذي يشهد له القرآن هو المعنى الثاني لقوله تعالى :  {  وَفِى ثَمُودَ إِذْ قِيلَ لَهُمْ تَمَتَّعُواْ حَتَّى حِينٍ فَعَتَوْاْ عَنْ أَمْرِ رَبِّهِمْ فَأَخَذَتْهُمُ الصَّاعِقَةُ وَهُمْ يَنظُرُونَ } [ الذاريات :  43 -44 ] ،  ولو قيل :  لا مانع من إرادة المعنيين لأنهما متلازمان تلازم المسبب للسبب ،  لأن الأول سبب الثاني لما كانوا بعيداً ،  ويشير إليه قوله تعالى :  {  فَعَتَوْاْ عَنْ أَمْرِ رَبِّهِمْ فَأَخَذَتْهُمُ الصَّاعِقَةُ } [ الذاريات :  44 ] .
