قوله تعالى :  {  وَتُؤْمِنُونَ بِالْكِتَابِ كُلِّهِ } الآية . <br />
يعني :  وتؤمنون بالكتب كلها كما يدل له قوله تعالى :  {  وَقُلْ آمَنتُ بِمَا أَنزَلَ اللَّهُ مِن كِتَابٍ } ،  وقوله :  {  كُلٌّ آمَنَ بِاللَّهِ وَمَلَائِكَتِهِ وَكُتُبِهِ } الآية . <br />
قوله تعالى :  {  وجنة عرضها السماوات والأرض } . <br />
يعني :  عرضها كعرض السماوات والأرض كما بيّنه قوله تعالى في سورة {  الْحَدِيدَ } :  {  سَابِقُواْ إِلَى مَغْفِرَةٍ مّن رَّبّكُمْ وَجَنَّةٍ عَرْضُهَا كَعَرْضِ السَّمَاء والأرض } ،  وآية آل عمران هذه تبيّن أن المراد بالسماء في آية الحديد جنسها الصادق بجميع السماوات كما هو ظاهر ،  والعلم عند اللَّه تعالى . <br />
