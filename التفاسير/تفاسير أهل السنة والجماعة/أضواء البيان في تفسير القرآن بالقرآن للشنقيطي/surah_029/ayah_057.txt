قوله تعالى : {  كُلُّ نَفْسٍ ذَائِقَةُ الْمَوْتِ } . <br />
جاء معناه موضحًا في آيات أُخر ؛  كقوله تعالى في سورة «آل عمران » :  {  كُلُّ نَفْسٍ ذَائِقَةُ الْمَوْتِ وَإِنَّمَا تُوَفَّوْنَ أُجُورَكُمْ يَوْمَ الْقِيَامَةِ } [ آل عمران :  158 ] ،  وقوله :  {  كُلُّ مَنْ عَلَيْهَا فَانٍ } [ الرحمن :  26 ] ،  وقوله تعالى :  {  كُلُّ شَيء هَالِكٌ إِلاَّ وَجْهَهُ } [ القصص :  88 ] .
