قوله تعالى :  {  وجعل الليل سكنا }<br />
أي مظلماً ساجياً ليسكن فيه الخلق فيستريحوا من تعب الكد بالنهار كما بينه قوله تعالى :  {  هُوَ الَّذِي جَعَلَ لَكُمُ الليل لِتَسْكُنُواْ فِيهِ وَالنَّهَارَ مُبْصِراً } [ يونس :  67 ] ،  وقوله {  قُلْ أَرَأَيْتُمْ إِن جَعَلَ اللَّهُ عَلَيْكُمُ الليل سَرْمَداً إِلَى يَوْمِ الْقِيَامَةِ مَنْ إِلَاهٌ غَيْرُ اللَّهِ يَأْتِيكُمْ بِضِيَآءٍ أَفَلاَ تَسْمَعُونَ قُلْ أَرَءَيْتُمْ إِن جَعَلَ اللَّهُ عَلَيْكُمُ النَّهَارَ سَرْمَداً إِلَى يَوْمِ الْقِيَامَةِ مَنْ إِلَاهٌ غَيْرُ اللَّهِ يَأْتِيكُمْ بِلَيْلٍ تَسْكُنُونَ فِيهِ أَفلاَ تُبْصِرُون وَمِن رَّحْمَتِهِ جَعَلَ لَكُمُ الَّيْلَ وَالنَّهَارَ لِتَسْكُنُواْ فِيهِ وَلِتَبتَغُواْ مِن فَضْلِهِ } [ القصص :  71 -73 ] الآية ،  وقوله {  لِتَسْكُنُواْ فِيهِ } يعني الليل ،  {  وَلِتَبْتَغُواْ مِن فَضْلِهِ } يعني بالنهار {  وَمِنْ ءَايَاتِهِ الليل وَالنَّهَارُ } [ فصلت :  37 ] الآية .
