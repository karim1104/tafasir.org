قوله تعالى :  {  أَيَحْسَبُ الإِنسَانُ أَلَّن نَّجْمَعَ عِظَامَهُ } . <br />
هذا الحسبان قد جاء مصرحاً به في قوله تعالى :  {  وَضَرَبَ لَنَا مَثَلاً وَنَسي خَلْقَهُ قَالَ مَن يُحييِ الْعِظَامَ وَهِيَ رَمِيمٌ } [ يس :  78 ] . <br />
وجاءه الجواب :  {  قُلْ يُحْيِيهَا الَّذِي أَنشَأَهَآ أَوَّلَ مَرَّةٍ } [ يس :  79 ] الآية .
