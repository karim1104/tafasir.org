قَوْلهُ تَعَالَى :  {  مُخَلَّقَةٍ وَغَيْرِ مُخَلَّقَةٍ } آية5<br />
عَنِ ابْنِ عَبَّاسٍ فِي قَوْلِهِ :  {  مُخَلَّقَةٍ وَغَيْرِ مُخَلَّقَةٍ } قَالَ :  المخلقة :  مَا كَانَ حياً {  وَغَيْرِ مُخَلَّقَةٍ } مَا كَانَ مِنْ سقط .  <br />
عَنْ عِكْرِمَةَ قَالَ :  العلقة :  الدم ،   والمضغة اللحم ،   والمخلقة التي تم خلقها {  وَغَيْرِ مُخَلَّقَةٍ } السقط .  <br />
عَنْ مُجَاهِدٍ {  مُخَلَّقَةٍ وَغَيْرِ مُخَلَّقَةٍ } قَالَ :  السقط مخلوق وغير مخلوق {  وَنُقِرُّ فِي الأَرْحَامِ مَا نَشَاءُ إِلَى أَجَلٍ مُسَمًّى } قَالَ :  التمام .  <br />
عَنِ ابْنِ زَيْدٍ فِي قَوْلِهِ :  {  وَنُقِرُّ فِي الأَرْحَامِ مَا نَشَاءُ إِلَى أَجَلٍ مُسَمًّى } قَالَ :  إقامته في الرحم حتى يخرج .  <br />
قَوْلهُ تَعَالَى :  {  لِنُبَيِّنَ لَكُمْ }<br />
عَنْ قَتَادَة فِي قَوْلِهِ :  {  لِنُبَيِّنَ لَكُمْ } قَالَ :  إنكم كنتم في بطون أمهاتكم كذلك .  <br />
قَوْلهُ تَعَالَى :  {  وَتَرَى الأَرْض هَامِدَةً }<br />
عَنْ قَتَادَة فِي قَوْلِهِ :  {  وَتَرَى الأَرْض هَامِدَةً } أي :  غبراء متهشمة {  فَإِذَا أَنْزَلْنَا عَلَيْهَا الْمَاءَ اهْتَزَّتْ وَرَبَتْ } يَقُولُ :  نفرق الغيث في سبختها وربوها {  وَأَنْبَتَتْ مِنْ كُلّ زَوْجٍ بَهِيجٍ } أي :  حسن .  <br />
قَوْلهُ تَعَالَى :  {  زَوْجٍ بَهيج }<br />
عَنِ ابْنِ عَبَّاسٍ فِي قَوْلِهِ :  {  زَوْجٍ بَهِيجٍ } قَالَ :  حسن .
