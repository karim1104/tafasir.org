قَوْلهُ تَعَالَى :  {  يَوْم تَرَوْنَهَا تَذْهَلُ } آية2<br />
عَنْ سُفْيَانَ فِي قَوْلِهِ :  {  يَوْم تَرَوْنَهَا تَذْهَلُ } قَالَ :  تغفل .  <br />
قَوْلهُ تَعَالَى :  {  وَتَرَى النَّاسَ }<br />
عَنِ أَبِي نهيك ،   أنه قرأ {  وَتَرَى النَّاسَ } يَعْنِي تحسب الناس ،   قَالَ :  لو كانت منصوبة كانوا سكارى ،   ولكنها {  تري } تحسب .  <br />
عَنِ الرَّبِيعِ {  وَتَرَى النَّاسَ سُكَارَى } ،   قَالَ :  ذَلِكَ عند الساعة ،   يسكر الكبير ويشيب الصغير وتضع الحوامل مَا في بطونها .
