قوله تعالى :  {  إن سعيكم }<br />
عن عكرمة في قوله :  {  إن سعيكم } قال :  السعي :  العمل .  <br />
عن ابن مسعود ،   أنا أبا بكر الصديق اشترى بلالا من أمية بن خلف ،   ببردة وعشر أواق فأعتقه لله فأنزل الله :  {  والليل إذا يغشى } إلى قوله {  إن سعيكم لشتى } سعى أبي بكر وأمية وأبي إلى قوله :  {  وكذب بالحسنى } قال :  لا إله إلا الله إلى قوله :  {  فسنيسره للعسرى } قال :  النار .  <br />
