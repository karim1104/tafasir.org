عن قتادة رضي الله ،   عنه في قوله :  {  وأقبل بعضهم على بعض يتساءلون } قال :  الإنس على الجن ،   قالت الإنس للجن :  {  إنكم تأتوننا عن اليمين } قال :  من قبل الخير أفتنهونا ،   عنه ،   قالت الجن للإنس :  {  بل لم تكونوا مؤمنين فحق علينا قول ربنا } قال :  هذا قول الجن {  فأغويناكم إنا كنا غاوين } هذا قول الشياطين لضلال بني آدم {  ويقولون أئنا لتاركوا آلهتنا لشاعر مجنون } يعنون محمدا صلى الله عليه وسلم {  بل جاء بالحق وصدق المرسلين } أي صدق من كان قبله من المرسلين {  إنكم لذائقو العذاب الأليم وما تجزون إلا ما كنتم تعملون إلا عباد الله المخلصين } قال :  هذه ثنية الله :  {  أولئك لهم رزق معلوم } قال :  الجنة .  <br />
قوله تعالى :  {  وأقبل بعضهم على بعض يتساءلون } آية 27<br />
عن ابن عباس رضي الله عنهما في قوله :  {  وأقبل بعضهم على بعض يتساءلون } قال :  ذلك إذا بعثوا في النفخة الثانية .
