قوله تعالى :  {  احشروا الذين ظلموا وأزواجهم } آية 22<br />
عن ابن عباس رضي الله ،   عنهما في قوله :  {  احشروا الذين ظلموا وأزواجهم } .   قال :  تقول الملائكة للزبانية {  احشروا الذين ظلموا وأزواجهم } .  <br />
عن ابن عباس رضي الله عنهما في قوله :  {  احشروا الذين ظلموا وأزواجهم } قال :  أشباههم ،   وفي لفظ :  نظراءهم .  <br />
عن زيد بن أسلم رضي الله ،   عنه في قوله :  {  احشروا الذين ظلموا وأزواجهم } قال :  أزواجهم في الأعمال ،   وقرأ ( وكنتم أزواجا ثلاثة ) الآية .   {  فأصحاب الميمنة } زوج {  وأصحاب المشئمة } زوج {  السابقون } زوج .  <br />
عن قتادة رضي الله عنه في قوله :  {  احشروا الذين ظلموا وأزواجهم } قال :  أشباههم من الكفار مع الكفار {  وما كانوا يعبدون من دون الله } قال :  الأصنام .
