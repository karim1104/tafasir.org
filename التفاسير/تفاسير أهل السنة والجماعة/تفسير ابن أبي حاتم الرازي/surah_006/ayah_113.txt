قوله تعالى :  {  ولتصغى إليه } آية<br />
وبه عن ابن عباس :  في قوله :  {  ولتصغى إليه } ،   قال لتميل اليه وروى عن السدى أنه قال :  تميل إليه قلوب الكفار .  <br />
أخبرنا أبو يزيد القراطيسي فيما كتب إلي ثنا اصبغ بن الفرج قال :  سمعت ابن زيد يعني عبد الرحمن في قوله :  {  ولتصغى اليه } ،   قال :  ولتهوى ذلك .   قال :  يقول الرجل للمراة :  صغيت إليها :  هويتها .  <br />
قوله تعالى :  {  أفئدة }<br />
أخبرنا احمد بن عثمان بن حكيم الأودي فيما كتب إلي ثنا احمد بن مفضل ثنا اسباط عن السدى :  قوله :  {  أفئدة } قال :  قلوب .  <br />
قوله تعالى :  {  الذين لا يؤمنون بالآخرة }<br />
وبه عن السدى :  قوله :  {  الذين لا يؤمنون بالآخرة } قال :  تميل إليه قلوب الكفار .  <br />
قوله تعالى :  {  وليرضوه }<br />
وبه عن السدى :  {  ليرضوه } ،   قال :  يحبونه ويرضونه .  <br />
قوله تعالى :  {  وليقترفوا }<br />
وبه عن السدى :  قوله :  {  وليقترفوا } يقول :  ليعملوا .  <br />
وروى عن عبد الرحمن بن زيد بن اسلم نحو ذلك .  <br />
قوله تعالى :  {  ما هم مقترفون }<br />
وبه عن السدى :  قوله :  {  ما هم مقترفون } يقول :  ما هم عاملون .  <br />
وروى عن ابن زيد بن أسلم مثل ذلك .  <br />
