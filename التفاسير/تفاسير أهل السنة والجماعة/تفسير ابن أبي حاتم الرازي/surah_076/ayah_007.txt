قوله تعالى :  {  يوفون بالنذر } آية 7<br />
عن قتادة {  يوفون بالنذر } قال :  كانوا يوفون بطاعة الله من الصلاة والزكاة والحج والعمرة وما افترض عليهم فسماهم الله الأبرار لذلك فقال :  {  يوفون بالنذر ويخافون يوما كان شره مستطيرا } قال :  استطار والله شر ذلك اليوم ،   حتى ملاء السماوات والأرض .  <br />
قوله تعالى :  {  كان شره مستطيرا }<br />
عن ابن عباس في قوله :  {  كان شره مستطيرا } قال :  فاشيا .
