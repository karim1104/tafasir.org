قوله :  {  وَتَحْمِلُ أَثْقَالَكُمْ إِلَى بَلَدٍ لَمْ تَكُونُوا بَالِغِيهِ إِلا بِشِقِّ الأَنْفُسِ } آية 7<br />
عَنِ ابْنِ عَبَّاسٍ ،   فِي قَوْلِهِ :  {  وَتَحْمِلُ أَثْقَالَكُمْ إِلَى بَلَدٍ } قَالَ :  يَعْنِي مكة .   {  لَمْ تَكُونُوا بَالِغِيهِ إِلا بِشِقِّ الأَنْفُسِ } قَالَ :  لو تكلفتموه لَمْ تطيقوه إلا بجهد شديد "  .  <br />
عَنْ مُجَاهِدٍ ،   فِي قَوْلِهِ :  "  {  إِلا بِشِقِّ الأَنْفُسِ } قَالَ :  مشقة عليكم "  .
