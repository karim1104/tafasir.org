قوله :  {  لَكُمْ فِيهَا دِفْءٌ وَمَنَافِعُ } آية 5<br />
عَنِ ابْنِ عَبَّاسٍ ،   فِي قَوْلِهِ :  {  لَكُمْ فِيهَا دِفْءٌ } قَالَ :  الثياب {  وَمَنَافِعُ } قَالَ :  مَا تنتفعون به مِنَ الأطعمة والأشربة .  <br />
عَنِ ابْنِ عَبَّاسٍ ،   فِي قَوْلِهِ :  "  {  لَكُمْ فِيهَا دِفْءٌ وَمَنَافِعُ } قَالَ :  نسل كُلّ دابة .
