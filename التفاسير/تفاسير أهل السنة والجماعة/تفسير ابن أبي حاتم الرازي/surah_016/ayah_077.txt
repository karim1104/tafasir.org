عَنْ قَتَادَة فِي قَوْلِهِ :  "  {  وَمَا أَمْرُ السَّاعَةِ إِلا كَلَمْحِ الْبَصَرِ } ،   هُوَ أن يَقُولُ :  كن أو أقرب ،   فالساعة {  كَلَمْحِ الْبَصَرِ أَوْ هُوَ أَقْرَبُ }  "  .  <br />
قَوْلهُ تَعَالَى :  {  كَلَمْحِ الْبَصَرِ } آية 77<br />
عَن السُّدِّيِّ فِي قَوْلِهِ :  "  {  كَلَمْحِ الْبَصَرِ } ،   يَقُولُ :  كلمح ببصر العين مِنَ السرعة .   أو {  أَقْرَبُ } مِنْ ذَلِكَ إِذَا أردنا "  .
