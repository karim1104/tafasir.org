قوله تعالى :  {  ورد الله الذين كفروا بغيظهم }<br />
عن مجاهد رضي الله عنه في قوله :  {  ورد الله الذين كفروا بغيظهم } قال :  الأحزاب .  <br />
قوله تعالى :  {  لم ينالوا خيراً } .  <br />
عن السدى رضي الله تعالى عنه في قوله :  {  ورد الله الذين كفروا بغيظهم } قال :  أبو سفيان وأصحابه {  لم ينالوا خيراً } قال :  لم يصيبوا من محمد صلى الله عليه وسلم وأصحابه ظفراً    {  وكفى الله المؤمنين القتال } انهزموا بالريح من غير قتال .  <br />
قوله تعالى :  {  وكفى الله المؤمنين القتال }<br />
عن قتادة رضي الله عنه في قوله :  {  وكفى الله المؤمنين القتال } قال :  بالجنود من عنده ،   والريح التي بعث عليهم {  وكان الله قويا } في أمره {  عزيزاً } في نقمته .  <br />
عن ابن مسعود رضي الله عنه أنه كان يقرأ هذا الحرف {  وكفى الله المؤمنين القتال } بعلي بن أبي طالب .  <br />
