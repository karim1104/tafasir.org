قوله :  {  فَاصْدَعْ بِمَا تُؤْمَرُ } آية 94<br />
مِنْ طَرِيق علي ،   عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا ،   "  {  فَاصْدَعْ بِمَا تُؤْمَرُ } ،   فامضه "  .   قوله :  {  وَأَعْرِضْ عَنِ الْمُشْرِكِينَ }<br />
مِنْ طَرِيق علي ،   عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا "  {  وَأَعْرِضْ عَنِ الْمُشْرِكِينَ } ،   قَالَ :  نسخه قوله :  {  فَاقْتُلُوا الْمُشْرِكِينَ }  "  .  <br />
عَنْ مُجَاهِدٍ رَضِيَ اللهُ عَنْهُ ،   فِي قَوْلِهِ :  "  {  فَاصْدَعْ بِمَا تُؤْمَرُ } قَالَ :  اجهر بالقرآن في الصلاة "  .
