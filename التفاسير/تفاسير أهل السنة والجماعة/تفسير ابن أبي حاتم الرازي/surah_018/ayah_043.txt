قوله :  {  وَلَمْ تَكُنْ لَهُ فِئَةٌ } آية 43<br />
عَنْ مُجَاهِدٍ ،   فِي قَوْلِهِ :  "  {  وَلَمْ تَكُنْ لَهُ فِئَةٌ } قَالَ :  عشيرة "  .  <br />
عَنْ قَتَادَة ،   فِي قَوْلِهِ :  "  {  وَلَمْ تَكُنْ لَهُ فِئَةٌ } قَالَ :  عشيرة "  .  <br />
عَنْ قَتَادَة ،   فِي قَوْلِهِ :  "  {  وَلَمْ تَكُنْ لَهُ فِئَةٌ } أي جند يعينونه {  مِنْ دُونِ اللَّهِ وَمَا كَانَ مُنْتَصِرًا } أي ممتنعا "  .  <br />
قوله :  {  الْوَلايَةُ } آية 44<br />
عَنْ مبشر بن عبيد ،   قَالَ :  "  {  الْوَلايَةُ } لدين ،   والولاية مَا أتولى "  .
