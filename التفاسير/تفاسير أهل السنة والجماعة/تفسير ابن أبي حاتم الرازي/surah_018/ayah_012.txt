قَوْلهُ تَعَالَى :  {  أَيُّ الْحِزْبَيْنِ أَحْصَى لمَا لَبِثُوا أَمَدًا } آية 12<br />
عَنْ مُجَاهِدٍ رَضِيَ اللهُ عَنْهُ ،   فِي قَوْلِهِ :  "  {  أَيُّ الْحِزْبَيْنِ } قَالَ :  مِنْ قوم الفتية {  أَحْصَى لِمَا لَبِثُوا أَمَدًا } قَالَ :  عددا "  .  <br />
عَنْ قَتَادَة رَضِيَ اللهُ عَنْهُ ،   فِي قَوْلِهِ :  "  {  لِنَعْلَمَ أَيُّ الْحِزْبَيْنِ أَحْصَى لِمَا لَبِثُوا أَمَدًا } يَقُولُ :  مَا كَانَ لواحد مِنَ الفريقين علم ،   لا لكفارهم ولا لمؤمنهم "  .
