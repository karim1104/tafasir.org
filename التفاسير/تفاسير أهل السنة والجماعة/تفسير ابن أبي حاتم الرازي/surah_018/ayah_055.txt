قوله :  {  إِلا أن تَأْتِيَهُمْ سُنَّةُ الأَوَّلِينَ } آية 55<br />
عَنْ قَتَادَة ،   فِي قَوْلِهِ :  "  {  إِلا أن تَأْتِيَهُمْ سُنَّةُ الأَوَّلِينَ } قَالَ :  عقوبة الأولين "  .  <br />
قوله :  {  أَوْ يَأْتِيَهُمُ الْعَذَابُ قُبُلا }<br />
عَنْ مُجَاهِدٍ ،   أنه قرأ :  "  {  أَوْ يَأْتِيَهُمُ الْعَذَابُ قُبُلا } قَالَ :  قبائل "  .  <br />
عَنْ مُجَاهِدٍ ،   فِي قَوْلِهِ :  "  {  أَوْ يَأْتِيَهُمُ الْعَذَابُ قُبُلا } قَالَ :  فجأة "  .  <br />
عَنْ قَتَادَة أنه قرأ :  "  {  أَوْ يَأْتِيَهُمُ الْعَذَابُ قُبُلا } أي :  عياناً "  .  <br />
عَنِ الأعمش ،   فِي قَوْلِهِ :  "  {  قُبُلا } قَالَ :  جهاراً "  .  <br />
عَنِ السُّدِّيِّ فِي قَوْلِهِ :  "  {  أَوْ يَأْتِيَهُمُ الْعَذَابُ قُبُلا } ،   قَالَ :  مقابلهم فينظرون إليه "  .
