قَوْلهُ تَعَالَى :  {  فَنَسِيَ أَفَلا يَرَوْنَ أَلا يَرْجِعُ إِلَيْهِمْ قَوْلا } آية 89<br />
عَنْ مُجَاهِدٍ رَضِيَ اللهُ عَنْهُ "  {  فَنَسِيَ } ،   قَالَ :  هم يقولونه قَوْمه أخطأ الرب العجل {  أَفَلا يَرَوْنَ أَن لا يَرْجِعُ إِلَيْهِمْ قَوْلا } قَالَ :  العجل ،   {  وَلا يَمْلِكُ لَهُمْ ضَرًّا } قَالَ :  ضلالة "  .
