قوله :  {  وَعَلامَاتٍ } آية 16<br />
عَنْ قَتَادَة فِي قَوْلِهِ :  "  {  وَسُبُلا } قَالَ :  طرقا {  وَعَلامَاتٍ } قَالَ :  هي النجوم "  .  <br />
عَنْ السُّدِّيِّ فِي قَوْلِهِ :  "  {  وَعَلامَاتٍ } قَالَ :  أنهار الجبال "  .  <br />
قوله :  {  وَبِالنَّجْمِ هُمْ يَهْتَدُونَ } عَنْ ابْنِ عَبَّاسٍ ،   فِي قَوْلِهِ :  "  {  وَعَلامَاتٍ } ،   يَعْنِي :  معالم الطرق بالنهار {  وَبِالنَّجْمِ هُمْ يَهْتَدُونَ } يَعْنِي :  بالليل "  .
