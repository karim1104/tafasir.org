قَوْلهُ تَعَالَى :  {  وَالشَّمْسَ وَالْقَمَرَ كُلّ فِي فَلَكٍ يَسْبَحُونَ } آية33<br />
عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا فِي قَوْلِهِ :  {  كُلّ فِي فَلَكٍ } قَالَ :  دوران {  يَسْبَحُونَ } قَالَ :  يجرون .  <br />
عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا فِي قَوْلِهِ :  {  كُلّ فِي فَلَكٍ } قَالَ :  فلكة كفلكة المغزل {  يَسْبَحُونَ } قَالَ :  يدورون في أبواب السَّمَاء مَا تدور الفلكة في المغزل .  <br />
عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا فِي قَوْلِهِ :  {  كُلّ فِي فَلَكٍ } قَالَ :  هُوَ فلك السَّمَاء .  <br />
عَنْ حسان بن عطية قَالَ :  الشمس والقمر والنجوم مسخرة في فلك بين السَّمَاء والأرض .  <br />
عَنِ ابْنِ زَيْدٍ رَضِيَ اللهُ عَنْهُ فِي قَوْلِهِ :  {  كُلّ فِي فَلَكٍ } قَالَ :  الفلك الّذِي بين السَّمَاء والأرض مِنْ مجاري النجوم والشمس والقمر وفي قوله :  {  يَسْبَحُونَ } قَالَ :  يجرون .
