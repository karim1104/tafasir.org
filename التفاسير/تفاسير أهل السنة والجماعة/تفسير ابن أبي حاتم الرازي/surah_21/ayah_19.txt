قَوْلهُ تَعَالَى :  {  وَمَنْ عِنْدَهُ لا يَسْتَكْبِرُونَ عَنْ عِبَادَتِهِ وَلا يَسْتَحْسِرُونَ } آية19<br />
عَنْ قَتَادَة فِي قَوْلِهِ :  {  وَمَنْ عِنْدَهُ } قَالَ :  الملائكة .  <br />
عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا فِي قَوْلِهِ :  {  وَلا يَسْتَحْسِرُونَ } يَقُولُ :  لا يرجعون .  <br />
عَنْ مُجَاهِدٍ رَضِيَ اللهُ عَنْهُ فِي قَوْلِهِ :  {  وَلا يَسْتَحْسِرُونَ } قَالَ :  لا يحسرون .  <br />
عَنِ السُّدّيِّ رَضِيَ اللهُ عَنْهُ فِي قَوْلِهِ :  {  وَلا يَسْتَحْسِرُونَ } ،   قَالَ :  لا يعيون .  <br />
عَنِ السدي فِي قَوْلِهِ :  {  وَلا يَسْتَحْسِرُونَ } قَالَ :  لا ينقطعون مِنَ العبادة .
