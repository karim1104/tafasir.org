قوله تعالى :  {  ولا هم منا يصحبون } آية 43<br />
عَنِ ابْنِ عَبَّاسٍ فِي قَوْلِهِ :  {  وَلا هُمْ مِنَّا يُصْحَبُونَ } قَالَ :  لا ينصرون .  <br />
عن ابْنِ عَبَّاسٍ فِي قَوْلِهِ :  {  وَلا هُمْ مِنَّا يُصْحَبُونَ } قَالَ :  لا يجارون .  <br />
قوله تعالى :  {  أم لهم آلهة تمنعهم من دوننا لا يستطيعون نصر أنفسهم } آية43<br />
عن قتادة في قوله :  {  أم لهم آلهة تمنعهم من دوننا لا يستطيعون نصر أنفسهم } يعني الآلهة {  ولا هم منا يصحبون } يقول :  لا يصحبون من الله بخير .
