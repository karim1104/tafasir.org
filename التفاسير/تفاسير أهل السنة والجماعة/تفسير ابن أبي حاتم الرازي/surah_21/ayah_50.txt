قَوْلهُ تَعَالَى :  {  وَهَذَا ذِكْرٌ مُبَارَكٌ أَنْزَلْنَاهُ } آية50<br />
عَنْ قَتَادَة فِي قَوْلِهِ :  {  وَهَذَا ذِكْرٌ مُبَارَكٌ أَنْزَلْنَاهُ } أي هَذَا القرآن .  <br />
عَنْ مَيْمُونِ بْنِ مَهْرَانَ قَالَ :  خصلتان فيهما البركة :  القرآن والمطر .   وتلا :  {  وَأَنْزَلْنَا مِنَ السَّمَاء مَاءً } {  وَهَذَا ذِكْرٌ مُبَارَكٌ } .
