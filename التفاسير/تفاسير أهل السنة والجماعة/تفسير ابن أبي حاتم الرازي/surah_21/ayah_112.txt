قَوْلهُ تَعَالَى :  {  قل رَبِّ احْكُمْ بِالْحَقِّ } آية112<br />
عَنْ قَتَادَة قَالَ :  كَانَتِ الأَنْبِيَاء تقول :  {  رَبُّنَا افْتَحْ بَيْنَنَا وَبَيْنَ قَوْمِنَا بِالْحَقِّ وَأَنْتَ خَيْرُ الْفَاتِحِينَ } فأمر الله نبيه أن يَقُول :  {  رَبِّ احْكُمْ بِالْحَقِّ } أي اقض بالحق .  <br />
 وكان رَسُول الله صَلَّى اللهُ عَلَيْهِ وَسَلَّمَ يعلم أنه عَلَى الحق ،   وأن عدوه عَلَى الباطل وكان إِذَا لقى العدو قَالَ :  {  رَبِّ احْكُمْ بِالْحَقِّ } .
