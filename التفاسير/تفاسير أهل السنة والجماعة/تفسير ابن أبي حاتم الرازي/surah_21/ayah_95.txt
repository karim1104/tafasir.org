قَوْلهُ تَعَالَى :  {  وَحَرَامٌ عَلَى قَرْيَةٍ أَهْلَكْنَاهَا } آية95<br />
عَنِ ابْنِ عَبَّاسٍ فِي قَوْلِهِ :  {  وَحَرَامٌ عَلَى قَرْيَةٍ أَهْلَكْنَاهَا } قَالَ :  وجب إهلاكها .   قَالَ :  دمرناها {  أَنَّهُمْ لا يَرْجِعُونَ } قَالَ :  إِلَى الدُّنْيَا .  <br />
عَنِ ابْنِ عَبَّاس عباس أنه كَانَ يقرأ :  {  وحرم عَلَى قرية } قَالَ :  وجب عَلَى قرية أهلكناها ،   أنهم لا يرجعون كما قَالَ :  {  أَلَمْ يَرَوْا كَمْ أَهْلَكْنَا قَبْلَهُمْ مِنَ الْقُرُونِ أَنَّهُمْ إِلَيْهِمْ لا يَرْجِعُونَ } .  <br />
عَنْ عِكْرِمَةَ  " وحرم "  قَالَ :  وجب بالحبشية .  <br />
عَنْ قَتَادَة {  وَحَرَامٌ عَلَى قَرْيَةٍ } أي وجب عليها أنها إِذَا هلكت لا ترجع إِلَى دنياها .
