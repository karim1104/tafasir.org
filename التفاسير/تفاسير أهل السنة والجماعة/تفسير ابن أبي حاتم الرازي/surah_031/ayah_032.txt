وفي قوله :  {  وإذا غشيهم موج كالظل } قال كالسحاب وفي قوله :  {  وما يجحد بآياتنا إلا كل ختار كفور } قال :  غدار بذمته ،   كفور بربه .  <br />
عن مجاهد رضي الله عنه في قوله :  {  فمنهم مقتصد } قال :  في القول وهو كافر {  وما يجحد بآياتنا إلا كل ختار } قال :  غدار {  كفور } قال :  كافر .  <br />
