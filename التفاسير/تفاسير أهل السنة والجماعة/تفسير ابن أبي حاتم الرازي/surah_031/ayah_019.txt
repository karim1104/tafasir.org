{  واقصد في مشيك } آية 19<br />
عن مجاهد رضي الله عنه في قوله :  {  واقصد في مشيك } قال :  تواضع .  <br />
عن يزيد بن أبي حبيب رضي الله عنه في قوله :  {  واقصد في مشيك } قال :  يعني السرعة .  <br />
عن سعيد بن جبير رضي الله عنه في قوله :  {  واقصد في مشيك } يقول :  لا تختال{  اغضض من صوتك } قال :  اخفض من صوتك عن الملأ {  إن أنكر الأصوات } قال :  أقبح الأصوات {  لصوت الحمير } .  <br />
عن قتادة رضي الله عنه في قوله :  {  واقصد في مشيك } قال :  نهاه عن الخيلاء {  واغضض من صوتك } قال :  أمره بالاقتصاد في صوته {  إن أنكر الأصوات } قال :  أقبح الأصوات {  لصوت الحمير } قال :  أوله زفير وآخره شهيق .  <br />
عن سفيان الثوري رضي الله عنه قال :  صياح كل شيء تسبيحه إلا الحمار .  <br />
عن ابن زيد رضي الله عنه قال :  لو كان رفع الصوت خيرا ما جعله الله للحمير .
