قوله :  {  مُهْطِعِينَ مُقْنِعِي رُءُوسِهِمْ } آية 43<br />
- 13154 عَنِ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا ،   فِي قَوْلِهِ :  "  {  مُهْطِعِينَ } ،   قَالَ :  يَعْنِي بالإهطاع :  النظر مِنْ غير أن تطرف ،   {  مُقْنِعِي رُءُوسِهِمْ } ،   قَالَ :  الإقناع رفع رءوسهم ،   {  لا يَرْتَدُّ إِلَيْهِمْ طَرْفُهُمْ } ،   قَالَ :  شاخصة أبصارهم ،   {  وَأَفْئِدَتُهُمْ هَوَاءٌ } ،   ليس فيها شيء مِنَ الخير فهي كالخربة "  .  <br />
عَنْ مُجَاهِدٍ رَضِيَ اللهُ عَنْهُ ،   "  {  مُهْطِعِينَ } ،   قَالَ :  مديمي النظر "  .  <br />
قوله :  {  وَأَفْئِدَتُهُمْ هَوَاءٌ } عَنْ مرة رَضِيَ اللهُ عَنْهُ ،   "  {  وَأَفْئِدَتُهُمْ هَوَاءٌ } ،   قَالَ :  متخرقة لا تعي شيئاً "  .
