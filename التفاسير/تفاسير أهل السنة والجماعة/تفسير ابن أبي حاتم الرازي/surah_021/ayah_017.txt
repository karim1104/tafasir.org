قوله تعالى :  {  لَوْ أَرَدْنَا أَنْ نَتَّخِذَ لَهْوًا } آية17<br />
عَنْ عِكْرِمَةَ فِي قَوْلِهِ :  {  لَوْ أَرَدْنَا أنَّ نَتَّخِذَ لَهْوًا } ،   قَالَ :  اللهو :  الولد .  <br />
عَنِ السُّدِّيِّ فِي قَوْلِهِ :  {  لَوْ أَرَدْنَا أنَّ نَتَّخِذَ لَهْوًا } الآية .   يَقُولُ :  لو أردت أنَّ أتخذ ولداً لاتخذت مِنَ الملائكة .  <br />
عَنِ الحَسَنِ ،   قَالَ :  اللهو بِلِسَانِ اليمن :  المرأة .  <br />
عَنْ قَتَادَة فِي قَوْلِهِ :  {  لَوْ أَرَدْنَا أنَّ نَتَّخِذَ لَهْوًا } ،   قَالَ :  اللهو بلغة أَهْل اليمن :  المرأة ،   وفي قوله :  {  إِنَّ كُنَّا فَاعِلِينَ } ،   أي :  إِنَّ ذَلِكَ لا يكون ولا ينبغي .  <br />
عَنِ إبراهيم النخعي فِي قَوْلِهِ :  {  لَوْ أَرَدْنَا أنَّ نَتَّخِذَ لَهْوًا } ،   قَالَ :  نساء .  <br />
{  لاتخذناه من لدنا } قال :  من الحور العين .  <br />
عن ابن عباس في قوله :  {  لو أردنا أن نتخذ لهوا } قال :  لعبا .  <br />
عَنْ مُجَاهِدٍ فِي قَوْلِهِ :  {  لاتَّخَذْنَاهُ مِنْ لَدُنَّا } ،   قَالَ :  مِنْ عندنا {  إِنَّ كُنَّا فَاعِلِينَ } أي مَا كنا فاعلين ،   يَقُولُ :  وما خلقنا جنة ولا ناراً ولا موتاً ولا بعثاً ولا حساباً ،   وكل شيء في القرآن {  إِنَّ } فهو إنكار .
