قوله :  {  بِمَا كَسَبُوا } عَنْ ابْنِ عَبَّاسٍ ،   فِي قَوْلِهِ :  "  {  بِمَا كَسَبُوا } يَقُولُ :  بما عملوا "  .  <br />
قوله :  {  بَلْ لَهُمْ مَوْعِدٌ } آية 58<br />
عَنِ السُّدِّيِّ ،   فِي قَوْلِهِ :  "  {  بَلْ لَهُمْ مَوْعِدٌ } قَالَ :  الموعد يَوْم الْقِيَامَة "  .  <br />
قوله :  {  لَنْ يَجِدُوا مِنْ دُونِهِ مَوْئِلا }<br />
مِنْ طَرِيق علي ،   عَنْ ابْنِ عَبَّاسٍ ،   فِي قَوْلِهِ :  "  {  لَنْ يَجِدُوا مِنْ دُونِهِ مَوْئِلا } ،   قَالَ :  ملجأ "  .
