قوله :  {  أتَتْ أُكُلَهَا وَلَمْ تَظْلِمْ مِنْهُ شَيْئًا } آية 3<br />
عَنْ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا ،   فِي قَوْلِهِ :  "  {  آتَتْ أُكُلَهَا وَلَمْ تَظْلِمْ مِنْهُ شَيْئًا } قَالَ :  لَمْ تنقص ،   كُلّ شجر الْجَنَّة أطعم "  .  <br />
قوله :  {  وَفَجَّرْنَا خِلالَهُمَا نَهَرًا } عَنِ السُّدِّيِّ رَضِيَ اللهُ عَنْهُ ،   فِي قَوْلِهِ :  "  {  وَفَجَّرْنَا خِلالَهُمَا نَهَرًا } يَقُولُ :  وسطهما "  .
