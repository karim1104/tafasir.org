قوله تعالى :  {  ووالد وما ولد }<br />
عن شريك عن خصيف عن عكرمة عن ابن عباس قوله :  {  ووالد وما ولد } الوالد :  الذي يلد ،   وما ولد :  العاقر الذي لا يولد له .  <br />
عن ابن عباس {  ووالد وما ولد } قال :  الوالد الذي يلد {  وما ولد } العاقر الذي لا يلد من الرجال والنساء- وقال عكرمة :  الولد :  العاقر ،   وما ولد :  الذي يلد .  <br />
عن أبي عمران الجوني {  ووالد وما ولد } قال :  إبراهيم وما ولد .  <br />
عن مجاهد {  ووالد وما ولد } قال :  الوالد آدم {  وما ولد } ولده .  <br />
