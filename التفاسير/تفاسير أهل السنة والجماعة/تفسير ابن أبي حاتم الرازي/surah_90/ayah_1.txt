قوله تعالى :  {  لا أقسم بهذا البلد وأنت حل بهذا البلد }<br />
عن ابن عباس {  لا أقسم بهذا البلد } قال :  مكة .  <br />
عن مجاهد في قوله :  {  لا أقسم } قال :  لا ردا عليهم {  أقسم بهذا البلد } .  <br />
عن مجاهد {  لا أقسم بهذا البلد } يعني مكة .  <br />
عن قتادة {  لا أقسم بهذا البلد } قال :  مكة .  <br />
