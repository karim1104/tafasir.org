{  يَدْعُو لَمَنْ ضَرُّهُ أَقْرَبُ مِنْ نَفْعِهِ } يَقُولُ :  ضره في الآخرة مِنَ أجل عبادته إياه في الدُّنْيَا {  لَبِئْسَ الْمَوْلَى } يَقُولُ :  الصنم .  <br />
قَوْلهُ تَعَالَى :  {  لَبِئْسَ الْمَوْلَى وَلَبِئْسَ الْعَشِيرُ } آية13<br />
عَنْ مُجَاهِدٍ {  لَبِئْسَ الْمَوْلَى وَلَبِئْسَ الْعَشِيرُ } قَالَ :  الصاحب .
