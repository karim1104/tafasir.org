قَوْلهُ تَعَالَى :  {  وَالصَّابِئِينَ وَالنَّصَارَى } آية17<br />
عَنْ قَتَادَة رَضِيَ اللهُ عَنْهُ فِي قَوْلِهِ :  {  إِنَّ الَّذِينَ آمَنُوا } الآية ،   قَالَ :  الصابئون ،   قوم يعبدون الملائكة ويصلون القبلة ويقرأون الزبور {  وَالْمَجُوسَ } عبدة الشمس والقمر والنيران وأما {  الَّذِينَ أَشْرَكُوا } فهم عبدة الأوثان {  إِنَّ اللَّهَ يَفْصِلُ بَيْنَهُمْ يَوْم الْقِيَامَة } قَالَ :  الأديان ستة :  فخمسة للشيطان ،   ودين لله عز وجل .  <br />
قَوْلهُ تَعَالَى :  {  إِنَّ اللَّهَ يَفْصِلُ بَيْنَهُمْ }<br />
عَنْ عِكْرِمَةَ فِي قَوْلِهِ :  {  إِنَّ اللَّهَ يَفْصِلُ بَيْنَهُمْ } قَالَ :  فصل قضاءه بَيْنَهُمْ ،   فعجل الْجَنَّة مشتركة وجعل هذه الأمة واحدة .  <br />
عَنْ عِكْرِمَةَ رَضِيَ اللهُ عَنْهُ قَالَ :  قالت اليهود :  عزير ابن الله ،   وقالت النصارى :  المسيح ابن الله ،   وقالت الصابئة :  نحن نعبد الملائكة مِنْ دون الله .   وقالت الْمَجُوس :  نحن نعبد الشمس والقمر مِنْ دون الله ،   وقالت المشركون :  نحن نعبد الأوثان مِنْ دون الله .   فأوحى الله إِلَى نبيه ليكذب قولهم {  قُلْ هُوَ اللَّهُ أَحَدٌ } إِلَى آخرها {  وَقُلِ الْحَمْدُ لِلَّهِ الّذِي لَمْ يَتَّخِذْ وَلَدًا } وأنزل الله {  إِنَّ الَّذِينَ آمَنُوا وَالَّذِينَ هَادُوا وَالصَّابِئِينَ وَالنَّصَارَى وَالْمَجُوسَ } .
