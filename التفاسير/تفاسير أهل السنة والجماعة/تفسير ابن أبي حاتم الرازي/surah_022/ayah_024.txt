قَوْلهُ تَعَالَى :  {  وَهُدُوا إِلَى الطَّيِّبِ }آية24<br />
عَنِ ابْنِ عَبَّاسٍ فِي قَوْلِهِ :  {  وَهُدُوا إِلَى الطَّيِّبِ } قَالَ :  ألهموا .  <br />
عَنِ أَبِي العالية فِي قَوْلِهِ :  {  وهدوا إلى الطيب من القول } قَالَ :  في الخصومة ،   إذ قالوا :  الله مولانا ولا مولى لكم .  <br />
عَنِ إسماعيل بن أبى خالد {  وهدوا إلى الطيب مِنَ القول } قَالَ :  الإخلاص {  وَهُدُوا إِلَى صِرَاطِ الْحَمِيدِ } قَالَ :  الإسلام .  <br />
عَنِ ابْنِ زَيْدٍ فِي قَوْلِهِ :  {  وَهُدُوا إِلَى الطَّيِّبِ مِنَ الْقَوْلِ } قَالَ :  لا إله إلا الله والله أكبر ولا حول ولا قوة إلا بالله الّذِي قَالَ :  {  إِلَيْهِ يَصْعَدُ الْكَلِمُ الطَّيِّبُ } .
