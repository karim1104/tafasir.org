قوله تعالى :  {  ثمرات مختلفا ألوانها } آية 27<br />
عن ابن عباس رضي الله عنهما في قوله :  {  ثمرات مختلفا ألوانها } قال :  الأبيض والأحمر والأسود و في قوله :  {  ومن الجبال جدد بيض } قال :  طرائق بيض يعني الألوان .  <br />
قوله تعالى :  {  وغرابيب سود }<br />
حدثنا أبي حدثنا أبو صالح حدثنا معاوية بن علي ،   عن ابن عباس قال :  {  وغرابيب سود } الشديد السواد .  <br />
عن أبي مالك رضي الله عنه في قوله :  {  ومن الجبال جدد } قال :  طرائق تكون في الجبل بيض وحمر فتلك الجدد {  وغرابيب سود } قال :  جبال سود .
