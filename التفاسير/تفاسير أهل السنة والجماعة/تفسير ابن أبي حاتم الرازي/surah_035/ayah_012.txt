قوله تعالى :  {  وما يستوي البحران هذا عذب فرات وهذا ملح أجاج } آية 12<br />
عن قتادة في قوله :  {  وما يستوي البحران هذا عذب فرات وهذا ملح أجاج } قال :  الأجاج :  المر {  ومن كل تأكلون لحما طريا } أي منهما جميعا {  وتستخرجون حلية تلبسونها } هذا اللؤلؤ {  وترى الفلك فيه مواخر } قال :  السفن مقبلة ومدبرة تجري بريح واحدة .  <br />
عن سنان بن سلمة أنه سأل ابن عباس ،   عن ماء البحر فقال :  بحران لا يضرك فمن أيهما توضأت ماء البحر وماء الفرات .  <br />
قوله تعالى :  {  ومن كل تأكلون لحما طريا }<br />
عن السدى في قوله :  {  ومن كل تأكلون لحما طريا } قال :  السمك {  وتستخرجون حلية تلبسونها } قال :  اللؤلؤ من البحر الأجاج .
