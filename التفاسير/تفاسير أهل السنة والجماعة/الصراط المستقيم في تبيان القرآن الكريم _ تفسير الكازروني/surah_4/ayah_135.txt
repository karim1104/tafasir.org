{ يَٰأَيُّهَا ٱلَّذِينَ آمَنُواْ كُونُواْ قَوَّٰمِينَ }: دائمي القيام، { بِٱلْقِسْطِ }: بالعدل، { شُهَدَآءَ }: خالصين، { للَّهِ وَلَوْ عَلَىۤ أَنْفُسِكُمْ }: وهو الإقرار لأن الشهادة بيان الحق، { أَوِ } على { ٱلْوَٰلِدَيْنِ وَٱلأَقْرَبِينَ إِن يَكُنْ } المشهودُ عليه { غَنِيّاً أَوْ فَقِيراً }: فيشهد عليه بلا رهبة ورحمة، { فَٱللَّهُ }: فشرعه، { أَوْلَىٰ بِهِمَا }: جنسي الغني والفقير من رهبتكم ورحمتكم، { فَلاَ تَتَّبِعُواْ ٱلْهَوَىٰ }: كراهة، { أَن تَعْدِلُواْ وَإِن تَلْوُواْ }: ألسنتكم بتغير الشهادة، { أَوْ تُعْرِضُواْ }: عَن أدائها { فَإِنَّ ٱللَّهَ كَانَ بِمَا تَعْمَلُونَ خَبِيراً }: فيجازيكم، { يَٰأَيُّهَا ٱلَّذِينَ ءَامَنُواْ ءَامِنُواْ }: دُوْمُا على إيمانكم، { بِٱللَّهِ وَرَسُولِهِ وَٱلْكِتَٰبِ ٱلَّذِي نَزَّلَ عَلَىٰ رَسُولِهِ }: القرآن، { وَ }: جنس، { ٱلْكِتَٰبِ ٱلَّذِيۤ أَنزَلَ مِن قَبْلُ وَمَن يَكْفُرْ بِٱللَّهِ وَمَلآئِكَتِهِ وَكُتُبِهِ وَرُسُلِهِ وَٱلْيَوْمِ ٱلآخِرِ }: أي: بشيء من ذلك، { فَقَدْ ضَلَّ ضَلاَلاً بَعِيداً }: عن الحق، { إِنَّ ٱلَّذِينَ آمَنُواْ }: كاليهود بموسى، { ثُمَّ كَفَرُواْ }: كعبادتهم العجل، { ثُمَّ آمَنُواْ }: بعده، { ثُمَّ كَفَرُواْ ثُمَّ ٱزْدَادُواْ كُفْراً }: ككفرهم بعيسى، ككفرهم بمحمد -صلى الله عليه وسلم-، { لَّمْ يَكُنِ ٱللَّهُ لِيَغْفِرَ لَهُمْ وَلاَ لِيَهْدِيَهُمْ سَبِيلاً }: إلى الحق، لأنه يستبعد منهم التوبة، لا لأنها لا تقبل منهم أو معناه: من تكرر منه الكفر والإيمان لا يغفر له، وعن علي: يقتل ولا تقبل توبته.
