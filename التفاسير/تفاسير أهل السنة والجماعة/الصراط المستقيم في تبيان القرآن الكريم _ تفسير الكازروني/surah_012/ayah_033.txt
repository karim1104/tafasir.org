{ قَالَ رَبِّ ٱلسِّجْنُ أَحَبُّ إِلَيَّ }: آثر عندي { مِمَّا يَدْعُونَنِيۤ إِلَيْهِ }: من إطاعتها، { وَإِلاَّ }: لم، { تَصْرِفْ عَنِّي كَيْدَهُنَّ أَصْبُ }: أمل { إِلَيْهِنَّ }: لأنهن دعونه إلى أنفسهن أيضاً، { وَأَكُن مِّنَ ٱلْجَاهِلِينَ }: بارتكاب القبائح { فَٱسْتَجَابَ }: فأجاب، { لَهُ رَبُّهُ }: دُعاءه، المفهوم من كلامه، { فَصَرَفَ عَنْهُ كَيْدَهُنَّ }: بالعصمة، { إِنَّهُ هُوَ ٱلسَّمِيعُ }: للدعوات، { ٱلْعَلِيمُ } بالحالات.
