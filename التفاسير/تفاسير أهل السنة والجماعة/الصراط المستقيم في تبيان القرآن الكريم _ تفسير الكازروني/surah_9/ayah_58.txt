{ وَمِنْهُمْ مَّن يَلْمِزُكَ }: يعيبك { فِي }: قسم، { ٱلصَّدَقَاتِ فَإِنْ أُعْطُواْ مِنْهَا رَضُواْ وَإِن لَّمْ يُعْطَوْاْ مِنهَا إِذَا هُمْ يَسْخَطُونَ }: يعيبون { وَلَوْ أَنَّهُمْ رَضُوْاْ مَآ آتَاهُمُ ٱللَّهُ وَرَسُولُهُ }: من الغنيمة والصدقة { وَقَالُواْ حَسْبُنَا }: كافينا { ٱللَّهُ سَيُؤْتِينَا ٱللَّهُ مِن فَضْلِهِ وَرَسُولُهُ } غنيمة أو صدقة أخرى، { إِنَّآ إِلَى ٱللَّهِ رَاغِبُونَ }: في إغنائنا لكان خيراً لهم.
