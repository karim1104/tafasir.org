موسى السبعين وذهب إلى الطُّور لأخذ التوراة تقدمهم شوقاً إلى ربه فقال تعالى إنكاراً لعجلته مع أنها نقيصة في ذاتها مع انضمام إغفال القوم إليها، { وَمَآ أَعْجَلَكَ عَن قَومِكَ يٰمُوسَىٰ * قَالَ }: جوابا عنهما { هُمْ أُوْلاۤءِ }: بالقرب مني يأتون { عَلَىٰ أَثَرِي وَعَجِلْتُ إِلَيْكَ رَبِّ لِتَرْضَىٰ }: فإن المسارعة إلى امتثال أمرك يزيد رضاك، { قَالَ }: الله تعالى: { فَإِنَّا قَدْ فَتَنَّا قَوْمَكَ مِن بَعْدِكَ }: بعد خروجك وكانوا ستمائة ألف، { وَأَضَلَّهُمُ ٱلسَّامِرِيُّ }: بدعوتهم إلى عبادة العجل، كان علْجًا من كرمان منسوب إلى سامرة، قبيلةٌ من بني إسرائيل { فَرَجَعَ مُوسَىٰ إِلَىٰ قَوْمِهِ غَضْبَٰنَ }: عليهم، { أَسِفاً }: شديد الحزن لهم { قَالَ يٰقَوْمِ أَلَمْ يَعِدْكُمْ رَبُّكُمْ وَعْداً حَسَناً }: التوراة وخير الدارين، { حَسَناً أَفَطَالَ عَلَيْكُمُ ٱلْعَهْدُ }: في انتظار موعدهِ { أَمْ أَرَدتُّمْ أَن يَحِلَّ }: يجب { عَلَيْكُمْ غَضَبٌ مِّن رَّبِّكُمْ فَأَخْلَفْتُمْ مَّوْعِدِي }: وعدكم إيَّاي بالثبوت على الإيمان { قَالُواْ مَآ أَخْلَفْنَا مَوْعِدَكَ بِمَلْكِنَا }: بقدرتنا، { وَلَـٰكِنَّا حُمِّلْنَآ أَوْزَاراً }: أحمالا، { مِّن زِينَةِ }: حُليّ { ٱلْقَوْمِ }: بما استعاروه منهم وخرجوا به { فَقَذَفْنَاهَا }: بأمر السامري في النار { فَكَذَلِكَ أَلْقَى ٱلسَّامِرِيُّ }: ما معه فَنَسِيَ }: موسى أنه هنا ليطلب من الطور، أو فنسي السامري أيمانه في تركه { أَفَلاَ يَرَوْنَ }: أنه { أَلاَّ يَرْجِعُ إِلَيْهِمْ قَوْلاً }: حين كلموه { وَلاَ يَمْلِكُ لَهُمْ ضَرّاً }: إن تركوه، { وَلاَ
