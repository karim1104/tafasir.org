{ وَيَقُولُ ٱلَّذِينَ كَفَرُواْ لَوْلاۤ } هلاَّ { أُنزِلَ عَلَيْهِ آيَةٌ مِّن رَّبِّهِ }: مما نشتهيها { إِنَّمَآ أَنتَ مُنذِرٌ }: لا الآتي بمشتهاهم { وَلِكُلِّ قَوْمٍ }: نبيٍّ { هَادٍ }: فلست بأوحدي { ٱللَّهُ يَعْلَمُ مَا تَحْمِلُ كُلُّ أُنثَىٰ }: أي: حقيقته وصفته، { وَمَا تَغِيضُ }: وما تنقص { ٱلأَرْحَامُ } من نحو جُثة الحَمل ومدته وعدده ولا حَدَّ له عند الشافعي، وكإتمام الحمل وأقصاها أربع سنين عنده، وعن مالك خمس، وعند الحنفية سنتان { وَمَا تَزْدَادُ وَكُلُّ شَيْءٍ عِندَهُ بِمِقْدَارٍ }: تقتضيه الحكمة لا يتجاوزه فهو عالم بكميته، { عَالِمُ ٱلْغَيْبِ }: ما غاب عن الحس، { وَٱلشَّهَادَةِ }: ما حضر { ٱلْكَبِيرُ ٱلْمُتَعَالِ }: عما لا يليق بكماله.
