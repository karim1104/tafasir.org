{ ثُمَّ أَنَزلَ ٱللَّهُ سَكِينَتَهُ }: رحمة سكنوا بها، { عَلَىٰ رَسُولِهِ وَعَلَى ٱلْمُؤْمِنِينَ }: فناداهم عباس بأمر النبي -صلى الله عليه وسلم- فكرُّوا عُنقاً واحداً قائلين: لبيك لبيك { وَأَنزَلَ }: من المَلك، { جُنُوداً لَّمْ تَرَوْهَا }: لكن سمعوا أصواتاً من السماء { وَعذَّبَ ٱلَّذِينَ كَفَرُواْ }: بالقتل والسبي فأُسر ستَّةُ آلاف { وَذٰلِكَ جَزَآءُ ٱلْكَافِرِينَ * ثُمَّ يَتُوبُ ٱللَّهُ مِن بَعْدِ ذٰلِكَ عَلَىٰ مَن يَشَآءُ }: لمن أسلم منهم، { وَٱللَّهُ غَفُورٌ رَّحِيمٌ }: لمن تاب، { يٰأَيُّهَا ٱلَّذِينَ آمَنُوۤاْ إِنَّمَا ٱلْمُشْرِكُونَ نَجَسٌ }: باطناً وديناً، أو عيناً { فَلاَ يَقْرَبُواْ ٱلْمَسْجِدَ ٱلْحَرَامَ }: أي: امنعوهم من الحرم، وظاهرة تكليفهم بالفروع { بَعْدَ عَامِهِمْ هَـٰذَا }: السنة التاسعة، { وَإِنْ خِفْتُمْ عَيْلَةً }: فقراً بانقطاع المتاجر بمنعهم { فَسَوْفَ يُغْنِيكُمُ ٱللَّهُ مِن فَضْلِهِ }: عطائه { إِن شَآءَ }: فعوَّضَهُم بالجزيةِ وأموال البلدان، { إِنَّ ٱللَّهَ عَلِيمٌ }: بأحوالكم، { حَكِيمٌ }: في أفعاله.
