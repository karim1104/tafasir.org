{ أَفَمَنْ أَسَّسَ بُنْيَانَهُ }: مبيَّنة { عَلَىٰ } قاعدة { تَقْوَىٰ مِنَ اللَّهِ وَرِضْوَانٍ }: طلب مرضاته، { خَيْرٌ أَم مَّنْ أَسَّسَ بُنْيَانَهُ عَلَىٰ شَفَا }: طرف، { جُرُفٍ }: جانب وادي من جهنم، { هَارٍ }: متصدع مشرفٍ على السقوط، { فَٱنْهَارَ }: طاح، { بِهِ }: منع بنائه أو بنيه، { فِي نَارِ جَهَنَّمَ }: صحَّ أنهم رأوا الدخان حين حفروه، { وَٱللَّهُ لاَ يَهْدِي ٱلْقَوْمَ ٱلظَّالِمِينَ }: إلى ما ينجيهم.
