{ وَكَذَلِكَ }: التبيين، { نفَصِّلُ }: نُبيِّنُ، { ٱلآيَاتِ }: نوضح الحق { وَلِتَسْتَبِينَ }: ليظهر، { سَبِيلُ ٱلْمُجْرِمِينَ }: ويظهر منه سبيل المؤمنين، أو مثل: [النحل: 81] { قُلْ إِنِّي نُهِيتُ }: عن، { أَنْ أَعْبُدَ ٱلَّذِينَ تَدْعُونَ }: تعبدونهم، { مِن دُونِ ٱللَّهِ قُلْ لاَّ أَتَّبِعُ أَهْوَآءَكُمْ }: تأكيد لقطع أطماعهم، وبيان لمبدأ ضلالهم، { قَدْ ضَلَلْتُ إِذاً }: إن فعلتُ { وَمَآ أَنَاْ مِنَ ٱلْمُهْتَدِينَ }: مثلكم، { قُلْ إِنِّي عَلَىٰ بَيِّنَةٍ }: حُجَّةٍ واضحةٍ { مِّن }: جهة، { رَّبِّي وَكَذَّبْتُم بِهِ }: بالبينة باعتبار القرآن { مَا عِندِي مَا تَسْتَعْجِلُونَ بِهِ }: من العذاب، أي: قولهم: [الأنفال: 32].. الآية، { إِنِ }: ما، { ٱلْحُكْمُ }: الفَصْل بيننا بالعذاب، { إِلاَّ للَّهِ يَقُصُّ } يتبع أو يقول وقرئ: يَقْض { ٱلْحَقَّ وَهُوَ خَيْرُ ٱلْفَٰصِلِينَ }: القاضين، { قُل لَّوْ أَنَّ عِندِي مَا تَسْتَعْجِلُونَ بِهِ }: من العذاب، { لَقُضِيَ ٱلأَمْرُ بَيْنِي وَبَيْنَكُمْ }: بتعجيله، { وَٱللَّهُ أَعْلَمُ بِٱلظَّالِمِينَ }: بوقت عقابهم، { وَعِندَهُ مَفَاتِحُ }: جمع مفتح بفتح الميم، أي: مخازن، { ٱلْغَيْبِ }: الغيب، أي: هو المنفرد بعلم المغيبات، أو هي الخمسةُ التي في آخر لُقْمان { لاَ يَعْلَمُهَآ إِلاَّ هُوَ وَيَعْلَمُ مَا فِي ٱلْبَرِّ وَٱلْبَحْرِ }: أي: كل شيٍء، { وَمَا تَسْقُطُ مِن وَرَقَةٍ إِلاَّ يَعْلَمُهَا }: لأنه يسقطها بإرادته، { وَلاَ حَبَّةٍ فِي ظُلُمَٰتِ ٱلأَرْضِ }: بطنها، { وَلاَ رَطْبٍ وَلاَ يَابِسٍ }: أي: كل شيء، { إِلاَّ فِي كِتَٰبٍ مُّبِينٍ }: اللوح المحفوظ وفي معنى الواو، وكذا كل اشبههما بعد استثناء بخلاف الاستثناء.
