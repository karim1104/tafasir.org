{ وَهُوَ ٱلَّذِي خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ بِٱلْحَقِّ }: بالحكمة لا عبثا، { وَ } خلق، { يَوْمَ }: حين، { يَقُولُ }: لما أراد تكوينه { كُن فَيَكُونُ } فُسِّر مرة، أو يوم ظرف { قَوْلُهُ ٱلْحَقُّ }: النافذ في الكائنات، { وَلَهُ ٱلْمُلْكُ يَوْمَ يُنفَخُ فِي ٱلصُّورِ }: قَرْنٌ يسع أهل السماوات والأرض ينفخ فيه إسرافيل، خصَّهُ بالذكر لظهور تفرده به فيه، هو { عَٰلِمُ ٱلْغَيْبِ }: ما غاب، { وَٱلشَّهَٰدَةِ }: ما حضر { وَهُوَ ٱلْحَكِيمُ }: في خلقه، { ٱلْخَبِيرُ }: ببواطن الأشياء.
