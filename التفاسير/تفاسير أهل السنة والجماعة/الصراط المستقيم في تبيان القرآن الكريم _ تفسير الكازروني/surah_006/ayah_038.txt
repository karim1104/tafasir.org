{ وَمَا مِن دَآبَّةٍ فِي }: جميع، { ٱلأَرْضِ وَلاَ طَائِرٍ } صنفان من جميع الطير { يَطِيرُ بِجَنَاحَيْهِ }: فالوصفان لمزيد التعميم، أو لئلا يتوهم المجاز أو قد يقال: الدابة لغير معناها الحقيقي، وقد يقال للمسرع طير { إِلاَّ أُمَمٌ أَمْثَالُكُمْ } مقدرة أرزاقها وآجالها وأحوالها فيقدر على: " أن تأتيهم بآية " وجمع الأمم حملاً لها على المعنى، { مَّا فَرَّطْنَا }: قصرنا، { فِي ٱلكِتَٰبِ }: اللَّوح المحفوظ { مِن شَيْءٍ }: إذ فيه كل ما يجري في العالم، { ثُمَّ إِلَىٰ رَبِّهِمْ يُحْشَرُونَ }: فيجزون ويقتص للجماء من القرناء، كما في الحديث. وعن ابن عباس -رضي الله عنه- أنَّ موت البهائم حشرها، { وَٱلَّذِينَ كَذَّبُواْ بِآيَاتِنَا صُمٌّ }: عن سماع قبولها، { وَبُكْمٌ }: عن الحق، { فِي ٱلظُّلُمَاتِ }: ظلمات الكفر والجهل والعناد، { مَن يَشَإِ ٱللَّهُ }: إضلاله، { يُضْلِلْهُ }: فيميته على الكفر، { وَمَن يَشَأْ }: هدايته، { يَجْعَلْهُ عَلَىٰ صِرَاطٍ مُّسْتَقِيمٍ }: فيميته على الإسلام، { قُلْ }: يا محمد، { أَرَءَيْتَكُمْ }: أبصروني وأعلموني وأخبروني، جعلوا طلب العلم والبصر موضع طلب الخبر لا شتراكهما في الطلب، { إِنْ أَتَـٰكُمْ عَذَابُ ٱللَّهِ }: قبل موتكم، { أَوْ أَتَتْكُمُ ٱلسَّاعَةُ }: وأهوالها، { أَغَيْرَ ٱللَّهِ تَدْعُونَ }: في صرفه، { إِن كُنتُمْ صَـٰدِقِينَ }: في الأصنام آلهة، { بَلْ إِيَّاهُ تَدْعُونَ } تخصونه بالدعاء { فَيَكْشِفُ مَا تَدْعُونَ إِلَيْهِ }: إلى كشفه وعذاب الساعة، { إِنْ شَآءَ وَتَنسَوْنَ مَا تُشْرِكُونَ }:فلا يذكرونه حينئذ { وَلَقَدْ أَرْسَلنَآ }: الرسل، { إِلَىٰ أُمَمٍ مِّن قَبْلِكَ }: فكذبوهم { فَأَخَذْنَٰهُمْ بِٱلْبَأْسَآءِ }: بالشدة كالقحط، { وَٱلضَّرَّآءِ }: كالأمراض { لَعَلَّهُمْ يَتَضَرَّعُونَ }: إلى الله تائبين، { فَلَوْلاۤ إِذْ جَآءَهُمْ بَأْسُنَا تَضَرَّعُواْ }: أي: لم يتضرعوا مع موجبه { وَلَـٰكِن قَسَتْ قُلُوبُهُمْ }: مَا لَانَتْ { وَزَيَّنَ لَهُمُ ٱلشَّيْطَانُ مَا كَانُواّ يَعْمَلُونَ }: فأصروا عليه.
