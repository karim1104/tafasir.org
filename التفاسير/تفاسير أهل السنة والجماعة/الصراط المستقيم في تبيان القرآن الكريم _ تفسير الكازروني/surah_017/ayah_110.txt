{ قُلِ }: لهم حيث يقولون أتنهانا عن دعوة إلهين وأنت تدعو الله والرحمن، { ٱدْعُواْ }: اسمعوا، معبودكم، { ٱللَّهَ أَوِ ٱدْعُواْ ٱلرَّحْمَـٰنَ أَيّاً مَّا تَدْعُواْ }: منهما، فهو حسن يدل عليه، { فَلَهُ }: فلمُسمَّاها، { ٱلأَسْمَآءَ ٱلْحُسْنَىٰ }: وهما منها، { وَلاَ تَجْهَرْ بِصَلاَتِكَ }: بقراءتها أو الدعاء بحيثُ يسمع المشركون فيسبون إلَهك { وَلاَ تُخَافِتْ بِهَا }: لا تخفها عمَّنْ خَلفك من صحبك { وَٱبْتَغِ بَيْنَ ذٰلِكَ }: من الجهر والمخافته، { سَبِيلاً } وسطا { وَقُلِ ٱلْحَمْدُ لِلَّهِ ٱلَّذِي لَمْ يَتَّخِذْ وَلَداً }: رَدَّا لليهود والمشركين، { وَلَم يَكُنْ لَّهُ شَرِيكٌ فِي ٱلْمُلْكِ }: الألوهية، رد للنصارى والمشركين، { وَلَمْ يَكُنْ لَّهُ وَلِيٌّ } نَاصِر { مِّنَ } أجْلِ { ٱلذُّلِّ }: رد للنصارى والمجوس { وَكَبِّرْهُ }: عَظَّمه عن كل مَا كل مَا لَا يليقُ به { تَكْبِيراً }: تعظيماً تاماً. واللهُ أعلَمُ.
