{ وَإِذَا مَسَّكُمُ ٱلْضُّرُّ فِي ٱلْبَحْرِ } خوف الغرق، { ضَلَّ } عن خاطركم كل { مَن تَدْعُونَ إِلاَّ إِيَّاهُ }: تعالى، { فَلَمَّا نَجَّاكُمْ }: من الغرق، { إِلَى ٱلْبَرِّ أَعْرَضْتُمْ }: عنه، { وَكَانَ ٱلإِنْسَانُ } بالسجية { كَفُوراً }: للنعم، { أَ }: نجوتم من البحر { فَأَمِنْتُمْ أَن يَخْسِفَ بِكُمْ جَانِبَ ٱلْبَرِّ }: أي: تقلبه وأنتم عليه، إذ البحر والبر عند قرته سواء { أَوْ يُرْسِلَ عَلَيْكُمْ حَاصِباً }: مطرا فيه الحجارة، أو ريحا ترمي بالحصباء { ثُمَّ لاَ تَجِدُواْ لَكُمْ وَكِيلاً } ينجيكم { أَمْ أَمِنْتُمْ أَن يُعِيدَكُمْ فِيهِ }: في البحر، { تَارَةً أُخْرَىٰ فَيُرْسِلَ عَلَيْكُمْ قَاصِفاً } كاسِراً { مِّنَ ٱلرِّيحِ }: يكسر كل ما يمر عليه، { فَيُغْرِقَكُم بِمَا كَفَرْتُمْ }: بكفركم، { ثُمَّ لاَ تَجِدُواْ لَكُمْ عَلَيْنَا بِهِ تَبِيعاً }: تابعاً يطالبنا بانتصار أو صرف.
