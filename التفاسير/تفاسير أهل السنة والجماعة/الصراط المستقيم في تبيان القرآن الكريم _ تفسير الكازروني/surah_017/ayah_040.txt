{ ذَلِكَ } الأحكام { مِمَّآ أَوْحَىٰ إِلَيْكَ رَبُّكَ مِنَ ٱلْحِكْمَةِ } معرفة الحق لذاته والخير للعمل به { وَلاَ تَجْعَلْ } أراد أمته، { مَعَ ٱللَّهِ إِلَـٰهاً آخَرَ فَتُلْقَىٰ فِي جَهَنَّمَ مَلُوماً }: من الحقّ والخَلق، { مَّدْحُوراً }: مطرودا، { أَفَأَصْفَاكُمْ }: خصَّكم، يَا مَنْ تصفونه تعالى باتخاذِ البنات، { رَبُّكُم بِٱلْبَنِينَ وَٱتَّخَذَ مِنَ ٱلْمَلاۤئِكَةِ إِنَاثاً } بناتاً { إِنَّكُمْ لَتَقُولُونَ قَوْلاً عَظِيماً * وَلَقَدْ صَرَّفْنَا }: بَيِّناً مكرَّراً هذا المعنى، { فِي هَـٰذَا ٱلْقُرْآنِ لِيَذَّكَّرُواْ }: ليتعظوا { وَمَا يَزِيدُهُمْ }: التصريف { إِلاَّ نُفُوراً }: عن الحق، { قُلْ لَّوْ كَانَ مَعَهُ آلِهَةٌ كَمَا يَقُولُونَ إِذاً لاَّبْتَغَوْاْ }: لطلبوا { إِلَىٰ ذِي ٱلْعَرْشِ سَبِيلاً }: بالمغالبة كما للملوك، أو بطاعته لعلمهم بقدرته.
