{ وَهُوَ ٱلَّذِي يَتَوَفَّٰكُم }: يمينكم، { بِٱلَّيلِ }: بقَبض أنفسكم { وَيَعْلَمُ مَا جَرَحْتُم }: كسبتم، { بِٱلنَّهَارِ }: جَرَى في القيدين على الغالب { ثُمَّ يَبْعَثُكُمْ }: يوقظكم، { فِيهِ }: في النهار، { لِيُقْضَىٰ }: ليستوفي، { أَجَلٌ مُّسَمًّى }: مدة العمر المقدر، { ثُمَّ إِلَيْهِ مَرْجِعُكُمْ }: بالموت، { ثُمَّ يُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ }: بالجزاء، { وَهُوَ ٱلْقَاهِرُ }: الغالب، { فَوْقَ عِبَادِهِ }: فوقية تليق بجلاله { وَيُرْسِلُ عَلَيْكُم حَفَظَةً }: لأبدانكم، وهم المعقبات أو لأعمالكم وهم الكرام الكاتبون، وحكمة إرسالهم أنا إذا عرفنا أن أعمالنا تكتب وتعرض علينا على رؤوس الأشهاد فهذا زجر لنا من أن يكون أمرنا بيننا وبين سيدنا الكريم معتمدين على لطفه، { حَتَّىٰ إِذَا جَآءَ أَحَدَكُمُ ٱلْمَوْتُ تَوَفَّتْهُ رُسُلُنَا }: مَلَكُ الموت وأعوانه { وَهُمْ }: كل المذكورين { لاَ يُفَرِّطُونَ }: لا يُقصِّرون فيما أُمروا به.
