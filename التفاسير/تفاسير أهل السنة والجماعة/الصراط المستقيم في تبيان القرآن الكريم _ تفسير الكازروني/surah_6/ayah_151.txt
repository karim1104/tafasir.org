{ قُلْ تَعَالَوْاْ أَتْلُ }: أقرأ، { مَا حَرَّمَ رَبُّكُمْ عَلَيْكُمْ }: متعلق: { أَتْلُ } ، { أَنَّ }: أي: { تُشْرِكُواْ بِهِ شَيْئاً وَبِٱلْوَالِدَيْنِ }: أحسنوا، { إِحْسَاناً }: بمعنى لا تؤذوهما، { وَلاَ تَقْتُلُوۤاْ أَوْلاَدَكُمْ } خشية { مِّنْ }: أجل، { إمْلاَقٍ }: فقر أنتم فيه { نَّحْنُ نَرْزُقُكُمْ وَإِيَّاهُمْ }: خاطب هنا الفقراء، وكذا لم يقل: خشية ، وقدم: نرزقكم، وفي الإسراء الأغنياء، فقيده بها وعكس { وَلاَ تَقْرَبُواْ ٱلْفَوَاحِشَ }: كبائر الذنوب { مَا ظَهَرَ مِنْهَا }: علانيتها، { وَمَا بَطَنَ }: سرَّها { وَلاَ تَقْتُلُواْ ٱلنَّفْسَ ٱلَّتِي حَرَّمَ ٱللَّهُ }: قتلها وبوجه، { إِلاَّ بِٱلْحَقِّ }: الشرعيّ { ذٰلِكُمْ }: المذكور { وَصَّاكُمْ بِهِ }: بحفظه، { لَعَلَّكُمْ تَعْقِلُونَ }: ترشدون.
