{ وَإِن تُطِعْ أَكْثَرَ مَن فِي ٱلأَرْضِ }: وهم الجُهَّالُ { يُضِلُّوكَ عَن سَبِيلِ ٱللَّهِ }: لأنَّ الضَّال لا يأمر إلَّا بالضلال، { إِن }: ما، { يَتَّبِعُونَ }: في عقاهدهم، { إِلاَّ ٱلظَّنَّ }: ظن هداية آباءَهم { وَإِنْ هُمْ إِلاَّ يَخْرُصُونَ }: يكذبون، { إِنَّ رَبَّكَ هُوَ أَعْلَمُ مَن }: بمن، { يَضِلُّ عَن سَبِيلِهِ وَهُوَ أَعْلَمُ بِٱلْمُهْتَدِينَ * فَكُلُواْ مِمَّا ذُكِرَ ٱسْمُ ٱللَّهِ عَلَيْهِ }: لا غيره عليه عند ذبحه، { إِن كُنتُمْ بِآيَاتِهِ مُؤْمِنِينَ }: فإن الإيمان يقتضي استحلال ما أحله فقط، { وَمَا }: أي عَرضٍ { لَكُمْ }: في، { أَلاَّ تَأْكُلُواْ مِمَّا ذُكِرَ ٱسْمُ ٱللَّهِ عَلَيْهِ }: وتأكلوا من غيره، { وَقَدْ فَصَّلَ لَكُمْ مَّا حَرَّمَ عَلَيْكُمْ }: في قوله: [البقرة: 137]: إلى آخره، { إِلاَّ مَا ٱضْطُرِرْتُمْ إِلَيْهِ }: ممَّا حُرم { وَإِنَّ كَثِيراً لَّيُضِلُّونَ }: بالتحريم والتحليل، { بِأَهْوَائِهِم }: بتشهيهم { بِغَيْرِ عِلْمٍ }: دليل { إِنَّ رَبَّكَ هُوَ أَعْلَمُ بِٱلْمُعْتَدِينَ }: المتجاوزين الحق.
