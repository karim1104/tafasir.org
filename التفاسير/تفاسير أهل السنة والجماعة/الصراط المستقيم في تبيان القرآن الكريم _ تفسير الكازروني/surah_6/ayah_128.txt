{ لَهُمْ دَارُ ٱلسَّلَٰمِ }: الجنة والإضافة أو السلام: السلامة خبره، { عِندَ رَبِّهِمْ وَهُوَ وَلِيُّهُمْ }: مولاهم، { بِمَا كَانُواْ يَعْمَلُونَ }: بأعمالهم، { وَ }: اذكر، { يَوْمَ يِحْشُرُهُمْ جَمِيعاً }: قائلين، { يَٰمَعْشَرَ ٱلْجِنِّ قَدِ ٱسْتَكْثَرْتُمْ مِّنَ }: إغْواء { ٱلإِنْسِ }: أو مثل: استكثر الأمير جنده { وَقَالَ أَوْلِيَآؤُهُم }: مطيعوهم، { مِّنَ ٱلإِنْسِ }: في الجواب، { رَبَّنَا ٱسْتَمْتَعَ }: انتفع، { بَعْضُنَا بِبَعْضٍ }: فانتفاع الإنس وصولهم بسببهم إلى مشتهياتهم، وانتفاع الجن قبول إغوائهم، { وَبَلَغْنَآ أَجَلَنَا ٱلَّذِيۤ أَجَّلْتَ لَنَا }: القيامة والبعث { قَالَ }: الله، { ٱلنَّارُ مَثْوَٰكُمْ خَٰلِدِينَ فِيهَآ إِلاَّ مَا شَآءَ ٱللَّهُ }: الله أعلم بتثنيه، أو المستثنى: الفساق، { إِنَّ رَبَّكَ حَكِيمٌ }: في أفعاله، { عَليمٌ }: بأعمالكم، { وَكَذٰلِكَ }: الإشقاء بالاستمتاع، { نُوَلِّي }: نكل أو نُسلِّطُ { بَعْضَ ٱلظَّٰلِمِينَ بَعْضاً }: إليهم أو عليهم، أو نجعله وليهم، { بِمَا كَانُواْ يَكْسِبُونَ }: من المعاصي.
