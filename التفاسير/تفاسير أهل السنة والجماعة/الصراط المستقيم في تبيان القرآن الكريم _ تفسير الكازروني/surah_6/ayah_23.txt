{ قُلْ أَيُّ شَيْءٍ }: شهيدا، { أَكْبَرُ شَهَٰدةً }: بنبوتي، { قُلِ ٱللَّهُ }: إذْ لا جواب غيره، هو { شَهِيدٌ بِيْنِي وَبَيْنَكُمْ }: ولا تظن منه جواز نداء الله تعالى بـ يَاشيء فإن صحة ندائه مخصوصة بما يدل على المدح والكمال، { وَأُوحِيَ إِلَيَّ هَـٰذَا ٱلْقُرْآنُ }: ناطقا بالحجج، { لأُنذِرَكُمْ بِهِ }: يا أهل مكة، { وَ }: أنذر، { مَن بَلَغَ }: بلغهُ القرآنُ، { أَئِنَّكُمْ لَتَشْهَدُونَ أَنَّ مَعَ ٱللَّهِ ءَالِهَةً أُخْرَىٰ قُل لاَّ أَشْهَدُ }: به، { قُلْ إِنَّمَا هُوَ إِلَـٰهٌ وَاحِدٌ وَإِنَّنِي بَرِيءٌ مِّمَّا تُشْرِكُونَ }: به، { ٱلَّذِينَ آتَيْنَاهُمُ ٱلْكِتَابَ يَعْرِفُونَهُ }: بنعوته المذكورة في كتبهم، { كَمَا يَعْرِفُونَ أَبْنَآءَهُمُ ٱلَّذِينَ خَسِرُوۤاْ أَنْفُسَهُمْ }: من الكفرة، { فَهُمْ لاَ يُؤْمِنُونَ }: به، { وَمَنْ أَظْلَمُ }: بُيِّنَ مرة، { مِمَّنِ ٱفْتَرَىٰ عَلَى ٱللَّهِ كَذِباً }: كالكفرة، { أَوْ كَذَّبَ بِآيَٰتِهِ }: كالقرآن والمعجزات، { إِنَّهُ }: الشأن، { لاَ يُفْلِحُ ٱلظَّٰلِمُونَ }: فضلاً عَن الأظلم، { وَ }: اذكر، { يَوْمَ نَحْشُرُهُمْ }: العابد والمعبود، { جَمِيعاً ثُمَّ نَقُولُ }: توبيخا، { لِلَّذِينَ أَشْرَكُواْ أَيْنَ شُرَكَآؤُكُمُ }: آلهتكم، { ٱلَّذِينَ كُنتُمْ تَزْعُمُونَ }: أنهم شركاء، { ثُمَّ لَمْ تَكُنْ فِتْنَتُهُمْ }: تخليصهم أنفسهم بزعمهم أي: عذرهم الذي يتخلصون به، { إِلاَّ أَن قَالُواْ }: يَوم القيامة، { وَٱللَّهِ رَبِّنَا مَا كُنَّا مُشْرِكِينَ }: وحينئذ يختم على أفواههم وتشهد جوارحهم { ٱنظُرْ كَيْفَ كَذَبُواْ }: بنفي الشِّرْك في الآخرةِ { عَلَىٰ أَنفُسِهِمْ وَضَلَّ }: غاب، { عَنْهُمْ مَّا كَانُواْ يَفْتَرُونَ }: إلهيته، { وَمِنْهُمْ مَّن يَسْتَمِعُ إِلَيْكَ }: إذا قرأت القرآن، { وَجَعَلْنَا عَلَىٰ قُلُوبِهِمْ أَكِنَّةً }: أغطية كراهة، { أَن يَفْقَهُوهُ وَفِيۤ ءَاذَانِهِمْ وَقْراً }: ثقلا وصَمَماً عن قبوله، { وَإِن يَرَوْاْ كُلَّ ءَايَةٍ }: معجزة، { لاَّ يُؤْمِنُواْ بِهَا حَتَّىٰ }: أي: بلغ عناهم إلى أنهم، { إِذَا جَآءُوكَ }: في حالة { يُجَٰدِلُونَكَ يَقُولُ ٱلَّذِينَ كَفَرُوۤاْ إِنْ }: ما، { هَـٰذَآ }: القرآن، { إِلاَّ أَسَٰطِيرُ }: أحاديث، { ٱلأَوَّلِينَ }: أي: أباطيلهم.
