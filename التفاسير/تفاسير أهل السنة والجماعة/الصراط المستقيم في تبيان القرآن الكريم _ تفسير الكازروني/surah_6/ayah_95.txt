{ إِنَّ ٱللَّهَ فَالِقُ }: شاق، { ٱلْحَبِّ }: بإنبات الزرع، { وَٱلنَّوَىٰ }: بإنبات الشجر، { يُخْرِجُ ٱلْحَيَّ }: كالنبات النامي الغاذي والحيوان، { مِنَ ٱلْمَيِّتِ }: كالحب والنطفة، { وَمُخْرِجُ }: عُطف على { فَالِقُ } لأن يخرج كمُبينّ لفالق إلى آخره، ومخرج لا يصلح لبيانه، ولذا غير الأسلوب بخلاف غير هذا الموضع { ٱلْمَيِّتِ }: كالحبِّ والنطف { مِنَ ٱلْحَيِّ }: كالنبات والحيوان إن، { ذٰلِكُمُ }: الفاعل { ٱللَّهُ فَأَنَّىٰ }: كيف، { تُؤْفَكُونَ }: تصرفون عن توحيده.
