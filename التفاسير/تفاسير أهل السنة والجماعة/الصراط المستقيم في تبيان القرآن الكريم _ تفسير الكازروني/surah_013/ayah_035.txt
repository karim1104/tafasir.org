{ مَّثَلُ } صفة { ٱلْجَنَّةِ ٱلَّتِي وُعِدَ ٱلْمُتَّقُونَ }: مبتدأ خبره محذوف نحو " فيما يتلى " ومِثل: صفة زيد أحمر { تَجْرِي مِن تَحْتِهَا ٱلأَنْهَارُ أُكُلُهَا }: ثمرها ومأكولها، { دَآئِمٌ وِظِلُّهَا }: كذلك، { تِلْكَ عُقْبَىٰ }: مآل، { ٱلَّذِينَ ٱتَّقَواْ وَّعُقْبَى ٱلْكَافِرِينَ ٱلنَّارُ * وَٱلَّذِينَ آتَيْنَاهُمُ ٱلْكِتَابَ }: مؤمنوهم، { يَفْرَحُونَ بِمَآ أُنزِلَ إِلَيْكَ }: لموافقته لكتبهم، { وَمِنَ ٱلأَحْزَابِ }: الكفرة منهم { مَن يُنكِرُ بَعْضَهُ }: مما يخالف دينهم، { قُلْ } لهم: { إِنَّمَآ أُمِرْتُ أَنْ أَعْبُدَ ٱللَّهَ وَلاۤ أُشْرِكَ بِهِ }: وإنكاركم بعضه ترك لعبادته { إِلَيْهِ أَدْعُواْ وَإِلَيْهِ مَآبِ }: مرجعي.
