{ بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * الۤر }: مرَّ بيانه، { تِلْكَ }: السُّورةُ { آيَاتُ ٱلْكِتَابِ ٱلْحَكِيمِ }: المشتمل على الحكمة، أو الغير المنسوخ بكتَابٍ { أَكَانَ لِلنَّاسِ }: قُريش { عَجَباً أَنْ أَوْحَيْنَآ إِلَىٰ رَجُلٍ مِّنْهُمْ أَنْ أَنذِرِ ٱلنَّاسَ }: الكفار، { وَبَشِّرِ ٱلَّذِينَ آمَنُوۤاْ أَنَّ }: بأن، { لَهُمْ قَدَمَ }: سابقة { صِدْقٍ }: أي: ثواب ما قدَّموا والعرب تقول إذا مدحت شيئاً تضيف إلى صدق كما سيجئ { عِندَ رَبِّهِمْ قَالَ ٱلْكَافِرُونَ إِنَّ هَـٰذَا }: القرآن أو الرسل، { لَسَاحِرٌ مُّبِينٌ }: بَيّن { إِنَّ رَبَّكُمُ ٱللَّهُ ٱلَّذِي خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ فِي }: قدر، { سِتَّةِ أَيَّامٍ ثُمَّ ٱسْتَوَىٰ عَلَى ٱلْعَرْشِ }: فسِّر في الأعراف { يُدَبِّرُ }: يقدر، { ٱلأَمْرَ }: كله بحكمته { مَا مِن }: صلة { شَفِيعٍ إِلاَّ مِن بَعْدِ إِذْنِهِ ذٰلِكُمُ }: الموصوف { ٱللَّهُ رَبُّكُمْ فَٱعْبُدُوهُ }: وحِّدوهُ { أَفَلاَ تَذَكَّرُونَ }: تتعظون { إِلَيْهِ مَرْجِعُكُمْ جَمِيعاً }: بالموت { وَعْدَ ٱللَّهِ حَقّاً }: مصدران مؤكدان لنفسه ولغيره { إِنَّهُ يَبْدَؤُاْ ٱلْخَلْقَ ثُمَّ يُعِيدُهُ لِيَجْزِيَ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ بِٱلْقِسْطِ }: بعد له، أو بعدالتهم { وَٱلَّذِينَ كَفَرُواْ لَهُمْ شَرَابٌ مِّنْ حَمِيمٍ }: ما حار وتُغْلي قطرة منه بحراً، { وَعَذَابٌ أَلِيمٌ بِمَا كَانُواْ يَكْفُرُونَ }: غير الأسلوب مبالغة في استحقاقهم له، وخصَّ الأولين بالعدل مع أن الكل عدل لمزيد عنايته.
