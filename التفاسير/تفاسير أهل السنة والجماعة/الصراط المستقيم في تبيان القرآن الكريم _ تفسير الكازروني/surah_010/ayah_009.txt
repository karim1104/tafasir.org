{ أُوْلَـٰئِكَ مَأْوَاهُمُ ٱلنَّارُ بِمَا كَانُواْ يَكْسِبُونَ }: من المعاصي { إِنَّ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ يَهْدِيهِمْ رَبُّهُمْ بِإِيمَانِهِمْ }: إلى ما يؤدي إلى الجنة، { تَجْرِي مِن تَحْتِهِمُ ٱلأَنْهَارُ فِي جَنَّاتِ ٱلنَّعِيمِ * دَعْوَاهُمْ }: دعاؤهم لما يشتهون { فِيهَا سُبْحَانَكَ ٱللَّهُمَّ }: فإذا مطلوبهم عندهم { وَتَحِيَّتُهُمْ }: بينَهُم { فِيهَا سَلاَمٌ }: إذْ ملكهم سَالم من الزّوال { وَآخِرُ دَعْوَاهُمْ }: حين أكلوا { أَنِ }: أنه، { ٱلْحَمْدُ للَّهِ رَبِّ ٱلْعَالَمِينَ * وَلَوْ يُعَجِّلُ ٱللَّهُ لِلنَّاسِ ٱلشَّرَّ }: حين دعوا على أنفسهم نحو: [الأنفال: 32].. إلى آخره، { ٱسْتِعْجَالَهُمْ بِٱلْخَيْرِ }: حين دعوه، { لَقُضِيَ إِلَيْهِمْ أَجَلُهُمْ } فيذهب طعامهم لكن يمهلهم { فَنَذَرُ ٱلَّذِينَ لاَ يَرْجُونَ لِقَآءَنَا }: استدراجاً لهم، { فِي طُغْيَانِهِمْ يَعْمَهُونَ }: يتحيرون غايةً.
