{ ٱلَّذِينَ عَاهَدْتَّ }: أخذت العهد { مِنْهُمْ }: ألا يُعينوا المشركين، { ثُمَّ يَنقُضُونَ عَهْدَهُمْ فِي كُلِّ مَرَّةٍ }: كقريظة، { وَهُمْ لاَ يَتَّقُونَ }: عاقبة الغدر، { فَإِمَّا } صلة { تَثْقَفَنَّهُمْ } إن تَظْفَر بهم { فِي ٱلْحَرْبِ فَشَرِّدْ }: فرّق { بِهِم }: بعقوبتهم، { مَّنْ خَلْفَهُمْ }: من المحاربين، { لَعَلَّهُمْ يَذَّكَّرُونَ }: يتعظون.
