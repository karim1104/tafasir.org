{ وَلَقَدْ ذَرَأْنَا }: خَلَقنا { لِجَهَنَّمَ كَثِيراً مِّنَ ٱلْجِنِّ وَٱلإِنْسِ }: وعلامتهم أنهم { لَهُمْ قُلُوبٌ لاَّ يَفْقَهُونَ بِهَا }: الحق { وَلَهُمْ أَعْيُنٌ لاَّ يُبْصِرُونَ بِهَا }: اعتباراً { وَلَهُمْ آذَانٌ لاَّ يَسْمَعُونَ بِهَآ }: المواعظ، { أُوْلَـٰئِكَ كَٱلأَنْعَامِ }: في قصرهم مشاعرهم على الشهوات، { بَلْ هُمْ أَضَلُّ }: فإنها تفعل ما خُلِقت له طَبْعاً أو تسخيراً { أُوْلَـٰئِكَ هُمُ ٱلْغَافِلُونَ }: أشد غفلة.
