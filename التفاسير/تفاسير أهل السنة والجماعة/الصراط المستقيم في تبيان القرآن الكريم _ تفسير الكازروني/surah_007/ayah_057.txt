{ وَهُوَ ٱلَّذِي يُرْسِلُ ٱلرِّيَاحَ بُشْراً }: بالباء، جمع بشير: المطر ونون مضمومة جمع نُشور بمعنى: ناشر وبفتحها مصدر بمعنى ناشرات للسحاب، { بَيْنَ يَدَيْ }: قُدَّم، { رَحْمَتِهِ }: المطر، فإن الَّبا تثير السحاب، والشمال تجمه، والجنوب تدره، والدبور تفرقه، { حَتَّىٰ إِذَآ أَقَلَّتْ }: حملت الرياح { سَحَاباً }: سحائب، { ثِقَالاً }: بالماء { سُقْنَاهُ }: أي: السحاب التفت تنبيهاً على ما فيه من دلالة كمال قدرته وحكمته، وكذا في نظائره { لِبَلَدٍ }: لأجل بلد، { مَّيِّتٍ }: غير منتفع، { فَأَنْزَلْنَا بِهِ }: أي: فيه، { ٱلْمَآءَ فَأَخْرَجْنَا بِهِ } بالماءِ أو بالبلدِ { مِن كُلِّ }: أنواع، { ٱلثَّمَرَاتِ كَذٰلِكَ }: الإخراج والإحياء، { نُخْرِجُ ٱلْموْتَىٰ }: من قبورهم، أحياء بمطر كالمني، { لَعَلَّكُمْ تَذَكَّرُونَ }: أن القادر عليه قادرٌ على ذلك، { وَٱلْبَلَدُ ٱلطَّيِّبُ }: الكريم التربة { يَخْرُجُ نَبَاتُهُ بِإِذْنِ }: بمشيئة، { رَبِّهِ }: سريعاً حسناً كثيراً، وهذا مثل المؤمن في انتفاعه بالوعظ، { وَٱلَّذِي خَبُثَ }: ترابه وهذا مثل الكافر لا ينتفع به، { لاَ يَخْرُجُ إِلاَّ نَكِداً }: قليلاً عديم النفع والكل بإذن الله، فالتفصيل لتعليم الأدب، { كَذٰلِكَ نُصَرِّفُ }: نبين ونكرر، { ٱلآيَاتِ لِقَوْمٍ يَشْكُرُونَ }: نعمة بالتفكر فيها.
