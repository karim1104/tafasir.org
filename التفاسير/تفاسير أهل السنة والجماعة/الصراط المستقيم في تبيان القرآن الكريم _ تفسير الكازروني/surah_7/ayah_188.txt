{ قُل لاَّ أَمْلِكُ لِنَفْسِي نَفْعاً }: أي: حيلة، { وَلاَ ضَرّاً }: أي: دَفْعه، فُسِّر مرَّةً { إِلاَّ مَا شَآءَ ٱللَّهُ }: تمليكي منهما { وَلَوْ كُنتُ أَعْلَمُ ٱلْغَيْبَ لاَسْتَكْثَرْتُ مِنَ ٱلْخَيْرِ }: فكنت رابحاً وغالباً دائما { وَمَا مَسَّنِيَ ٱلسُّوۤءُ }: لم أكن في بعض الأوقات خاسراً مغلوباً، { إِنْ }: مَا { أَنَاْ إِلاَّ نَذِيرٌ وَبَشِيرٌ لِّقَوْمٍ }: كتب في الأزل أنهم { يُؤْمِنُونَ }: فإنهم المنتفعون.
