{ ٱلَّذِي لَهُ مَا فِي ٱلسَّمَٰوَٰتِ وَمَا فِي ٱلأَرْضِ وَوَيْلٌ لِّلْكَافِرِينَ مِنْ عَذَابٍ شَدِيدٍ }: هم، { ٱلَّذِينَ يَسْتَحِبُّونَ }: يختارون { ٱلْحَيَاةَ ٱلدُّنْيَا عَلَى ٱلآخِرَةِ وَيَصُدُّونَ }: الناس { عَن سَبِيلِ ٱللَّهِ }: دينه، { وَيَبْغُونَهَا }: يطلبون لها، { عِوَجاً }: ليقدحوا فيه، { أُوْلَـٰئِكَ فِي ضَلاَلٍ بَعِيدٍ }: عن الحقِّ { وَمَآ أَرْسَلْنَا مِن رَّسُولٍ إِلاَّ بِلِسَانِ } لُغةِ { قَوْمِهِ }: الذينَ هو منهم { لِيُبَيِّنَ لَهُمْ }: ما أمورا فيفهموا فيترجموا لغيرهم، { فَيُضِلُّ ٱللَّهُ مَن يَشَآءُ }: بعد البيان { وَيَهْدِي مَن يَشَآءُ }: باتباعه، { وَهُوَ ٱلْعَزِيزُ }: الغالب فيما أراد { ٱلْحَكِيمُ }: فيما فعل، { وَلَقَدْ أَرْسَلْنَا مُوسَىٰ بِآيَاتِنَآ أَنْ }: بأن، { أَخْرِجْ قَوْمَكَ مِنَ ٱلظُّلُمَاتِ }: الضلالة { إِلَى ٱلنُّورِ }: الهدى { وَذَكِّرْهُمْ بِأَيَّامِ ٱللَّهِ }: وقائعه على الأُمَم من النعم والنق او عليهم من نحو فلق البحر { إِنَّ فِي ذٰلِكَ }: التذكير، { لآيَاتٍ لِّكُلِّ صَبَّارٍ }: على بلائه، { شَكُورٍ }: على نعمائه { وَ }: اذكر، { إِذْ قَالَ مُوسَىٰ لِقَوْمِهِ ٱذْكُرُواْ نِعْمَةَ ٱللَّهِ عَلَيْكُمْ إِذْ أَنجَاكُمْ مِّنْ آلِ فِرْعَوْنَ يَسُومُونَكُمْ }: يبغونكم، { سُوۤءَ }: أفطع { ٱلْعَذَابِ وَيُذَبِّحُونَ أَبْنَآءَكُمْ }: أفاد بالواو أن العذاب هنا غير الذبح، وهو الاستبعاد ونحوه، بخلاف البقرة والأعراف، إذ فسره به، وبالتقتيل، { وَيَسْتَحْيُونَ نِسَآءَكُمْ وَفِي ذٰلِكُمْ بَلاۤءٌ مِّن رَّبَّكُمْ عَظِيمٌ }: فسر مرَّةً { وَإِذْ تَأَذَّنَ }: أعلم، { رَبُّكُمْ لَئِن شَكَرْتُمْ }: بطاعتي { لأَزِيدَنَّكُمْ }: نعمتي، { وَلَئِن كَفَرْتُمْ }: نعمتي، { إِنَّ عَذَابِي لَشَدِيدٌ }: لمن كفرها.
