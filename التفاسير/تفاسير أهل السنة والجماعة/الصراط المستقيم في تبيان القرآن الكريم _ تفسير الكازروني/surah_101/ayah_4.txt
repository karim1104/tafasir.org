لَمَّا ذكر بعثره القبور أتبعها بأهوال القيامة فقال: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ }: القيامة { ٱلْقَارِعَةُ }: للناس بأهوالها { مَا ٱلْقَارِعَةُ } استفهام تعظيم { وَمَآ أَدْرَاكَ مَا ٱلْقَارِعَةُ }: لعظمتها تقرع { يَوْمَ يَكُونُ ٱلنَّاسُ كَٱلْفَرَاشِ }: الطير المتساقط في النار { ٱلْمَبْثُوثِ }: انتشارا وكثرة { وَتَكُونُ ٱلْجِبَالُ كَٱلْعِهْنِ }: الصوف { ٱلْمَنفُوشِ }: المَنْدُوْف في تطايرها وتفرق أجزائها { فَأَمَّا مَن ثَقُلَتْ مَوَازِينُهُ }: برجحان حسناته { فَهُوَ فِي عِيشَةٍ رَّاضِيَةٍ }: أي: ذات رضا { وَأَمَّا مَنْ خَفَّتْ مَوَازِينُهُ }: يرجحان سيئاته، كما مرّ { فَأُمُّهُ }: أي ناره { هَاوِيَةٌ }: أسفل جهنم، أو أمه هالكة كناية عن هلاكه { وَمَآ أَدْرَاكَ مَا هِيَهْ }: الهاء للسكت هي { نَارٌ حَامِيَةٌ }: كاملة الحَرْ - واللهُ أعْلمُ ب الصّوابِ.
