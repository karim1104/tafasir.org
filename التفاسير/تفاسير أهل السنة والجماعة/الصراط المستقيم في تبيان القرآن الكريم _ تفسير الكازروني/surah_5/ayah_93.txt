{ لَيْسَ عَلَى ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ جُنَاحٌ }: إثم، { فِيمَا طَعِمُوۤاْ إِذَا مَا ٱتَّقَواْ }: الحرام، { وَآمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ }: استمروا عليها، { ثُمَّ اتَّقَواْ }: ما حُرَّم بعدُ كالخمر، { وَآمَنُواْ }: استمروا على الإيمان، { ثُمَّ اتَّقَواْ }: استمروا على اتقاء المعاصي، { وَّأَحْسَنُواْ }: العمل، " والإحسان: أن تعبد الله كأنك تراه " إلى آخره، وقيل التكرار باعتبار الماضي والحال والاستقبال، { وَٱللَّهُ يُحِبُّ ٱلْمُحْسِنِينَ }: الموصوفين.
