{ قُلْ يَـٰأَهْلَ ٱلْكِتَابِ لَسْتُمْ عَلَىٰ شَيْءٍ }: دين يعبأُ به { حَتَّىٰ تُقِيمُواْ ٱلتَّوْرَاةَ وَٱلإِنْجِيلَ وَ }: جميع، { مَآ أُنزِلَ إِلَيْكُمْ مِّن رَّبِّكُمْ }: غير ما نسخ بلا تحريف وكتمان، { وَلَيَزِيدَنَّ كَثِيراً مِّنْهُمْ مَّآ أُنْزِلَ إِلَيْكَ مِن رَّبِّكَ طُغْيَاناً وَكُفْراً فَلاَ تَأْسَ }: تحزن، { عَلَى ٱلْقَوْمِ ٱلْكَافِرِينَ }: فإنَّهم لا يستحقون العناية، { إِنَّ ٱلَّذِينَ آمَنُواْ }: أظهروا الإيمان، { وَٱلَّذِينَ هَادُواْ وَٱلصَّابِئُونَ }: عبدة الملائكة كما مر، عطف على محل اسم إن، { وَٱلنَّصَارَىٰ مَنْ آمَنَ }: حقيقة، { بِٱللَّهِ وَٱلْيَوْمِ ٱلآخِرِ وعَمِلَ صَالِحاً فَلاَ خَوْفٌ عَلَيْهِمْ }: عند الفزع الأكبر، { وَلاَ هُمْ يَحْزَنُونَ }: على ما فات منهم في الدنيا.
