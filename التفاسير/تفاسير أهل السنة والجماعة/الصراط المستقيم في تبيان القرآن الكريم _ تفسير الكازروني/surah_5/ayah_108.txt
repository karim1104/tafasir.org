{ ذٰلِكَ }: الحكم من رد اليمين، { أَدْنَىٰ }: أقرب إلى { أَن يَأْتُواْ بِٱلشَّهَادَةِ عَلَىٰ وَجْهِهَآ }: كما في نفس الأمر { أَوْ يَخَافُوۤاْ أَن تُرَدَّ أَيْمَانٌ }: إلى أولياء الميت، { بَعْدَ أَيْمَانِهِمْ }: فيفتضحوا، حاصله ذلك أقرب إلى أحد الشيئين، إما أداء الشهادة صدقا أو الامتناع عن أدائها كذبا { وَٱتَّقُوا ٱللَّهَ وَٱسْمَعُواْ }: سمع إجابةٍ { وَٱللَّهُ لاَ يَهْدِي }: إلى طريق الجنة { ٱلْقَوْمَ ٱلْفَاسِقِينَ }: الذين لا يسمعون.
