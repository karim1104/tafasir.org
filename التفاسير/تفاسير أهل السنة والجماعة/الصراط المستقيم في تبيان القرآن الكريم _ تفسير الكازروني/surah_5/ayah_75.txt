{ مَّا ٱلْمَسِيحُ ٱبْنُ مَرْيَمَ إِلاَّ رَسُولٌ قَدْ خَلَتْ }: مَضَتْ، { مِن قَبْلِهِ ٱلرُّسُلُ }: فهو مثلهم، { وَأُمُّهُ صِدِّيقَةٌ }: صدقت بكلمات ربها، { كَانَا يَأْكُلاَنِ ٱلطَّعَامَ }: احتياجا، وهو ينافي الإلهية، { ٱنْظُرْ كَيْفَ نُبَيِّنُ لَهُمُ ٱلآيَاتِ ثُمَّ ٱنْظُرْ أَنَّىٰ }: كيف، { يُؤْفَكُونَ }: يصرفون عن الحق.
