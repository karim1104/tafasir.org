{ أُوْلَـٰئِكَ جَزَآؤُهُمْ أَنَّ عَلَيْهِمْ لَعْنَةَ ٱللَّهِ وَٱلْمَلاۤئِكَةِ وَٱلنَّاسِ أَجْمَعِينَ }: أفهم عدم جواز اللعن على غيرهم، { خَالِدِينَ فِيهَا }: في اللعنة أو العقوبة المفهومة، { لاَ يُخَفَّفُ عَنْهُمُ ٱلْعَذَابُ وَلاَ هُمْ يُنظَرُونَ }: يُمْهَلُونَ، { إِلاَّ ٱلَّذِينَ تَابُواْ مِن بَعْدِ ذٰلِكَ }: الارتداد كحارث بن سويد حين ندم على ردته، { وَأَصْلَحُواْ }: دخلوا في الصلاح، { فَإِنَّ الله غَفُورٌ } لهم، { رَّحِيمٌ }: بهم.
