{ إِن تَمْسَسْكُمْ }: تصبكم أدْنى إصابة، { حَسَنَةٌ }: خير، { تَسُؤْهُمْ }: تحزنهم، { وَإِن تُصِبْكُمْ سَيِّئَةٌ }: ضر، { يَفْرَحُواْ بِهَا وَإِن تَصْبِرُواْ }: على أذاهم، { وَتَتَّقُواْ }: المعاصي، { لاَ يَضُرُّكُمْ }: بكسر الضاد من ضاره يضره { كَيْدُهُمْ شَيْئاً }: والكيد: احتيالك لتوقع غيرك في مكروه، { إِنَّ ٱللَّهَ بِمَا يَعْمَلُونَ مُحِيطٌ }: علمه فيجازي.
