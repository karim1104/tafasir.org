{ فَمَنِ ٱفْتَرَىٰ عَلَى ٱللَّهِ ٱلْكَذِبَ }: بحرمتها على الأنبياء، { مِن بَعْدِ ذَلِكَ }: العلم، { فَأُوْلَـٰئِكَ هُمُ ٱلظَّالِمُونَ }  { قُلْ صَدَقَ ٱللَّهُ } وهذا تعريض بكذبهم { فَٱتَّبِعُواْ مِلَّةَ إِبْرَاهِيمَ حَنِيفاً }: مائلاً عن الباطل، وهي مِلّتُنا، { وَمَا كَانَ مِنَ ٱلْمُشْرِكِينَ }: تعريض بشرك اليهود.
