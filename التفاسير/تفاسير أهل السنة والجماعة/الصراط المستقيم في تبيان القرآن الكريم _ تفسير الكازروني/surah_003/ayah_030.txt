اذكر { يَوْمَ تَجِدُ كُلُّ نَفْسٍ }: جَزَاءَ { مَّا عَمِلَتْ مِنْ خَيْرٍ مُّحْضَراً وَ } جزاء { مَا عَمِلَتْ مِن سُوۤءٍ تَوَدُّ }: تتمنّى النَّفْسُ { لَوْ }: للتمني كما مؤ، { أَنَّ بَيْنَهَا وَبَيْنَهُ }: أي ذلك اليوم، { أَمَدَاً }: مسافة، { بَعِيداً وَيُحَذِّرُكُمُ ٱللَّهُ نَفْسَهُ }: كرَّره تأكيداً، { وَٱللَّهُ رَؤُوفٌ بِٱلْعِبَادِ }: ولذا يُحذِّركم إصلاحاً لكم.
