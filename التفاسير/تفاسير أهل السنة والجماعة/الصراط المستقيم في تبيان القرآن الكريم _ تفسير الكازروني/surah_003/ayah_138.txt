{ هَـٰذَا } الخلوّ المذكور { بَيَانٌ لِّلنَّاسِ }: عامة، { وَهُدًى وَمَوْعِظَةٌ لِّلْمُتَّقِينَ * وَلاَ تَهِنُوا }: لا تضعفوا عَن الحرب، { وَلاَ تَحْزَنُوا }: على مَغْلوبيَّتكم في أُحُدٍ { وَأَنْتُمُ الأَعْلَوْنَ }: الغالبين في الدارين، { إِنْ كُنْتُمْ مُّؤْمِنِينَ }: فإن الإيمان يقتضي الشجاعة بالوثوق بالله، { إِن يَمْسَسْكُمْ قَرْحٌ }: يوم أحد، وهُو بالفتح جرح، وبالضم ألم، { فَقَدْ مَسَّ ٱلْقَوْمَ }: المشركين، { قَرْحٌ مِّثْلُهُ }: في بدر وهم لم يجبنوا، فإنهم أحق به، { وَتِلْكَ ٱلأَيَّامُ }:أيام الدنيا، { نُدَاوِلُهَا }: نصرفها في تحقيق الحجة وتشديدها لا لأنه -تعالى- لا ينصره وَإنما لم يكُنْ أبداً للمؤمنين لأنه أدعى إلى أحتقار الدنيا، { بَيْنَ ٱلنَّاسِ }: مَرَّة لهؤلاء ومَرَّةً لهؤلاء لمصالح لا تُحْصَى، { وَلِيَعْلَمَ ٱللَّهُ }: علم ظهور، أو القصد في أمثاله ونقائده إثبات معلومه ونفيه بطريق البرهان، { ٱلَّذِينَ آمَنُواْ وَيَتَّخِذَ مِنكُمْ شُهَدَآءَ }: أي ليلزمكم بالشهادة في سبيله، { وَٱللَّهُ لاَ يُحِبُّ ٱلظَّالِمِينَ }: فتغليبهم ليس لمحبتهم بل لأمتحانهم.
