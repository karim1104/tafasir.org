{ زُيِّنَ لِلنَّاسِ }: ابتلاء، { حُبُّ ٱلشَّهَوَاتِ }: المشتهيات، والشهوة: نزوع النفس إلى ما تريده، وهي إما كاذبة، ومنها: [مريم: 59] أو صَادقة، ومنها: [الزخرف: 71]، أو تحملها كما نحن فيه، { مِنَ ٱلنِّسَاءِ وَٱلْبَنِينَ وَٱلْقَنَاطِيرِ }: الأموال الكثيرة، { ٱلْمُقَنْطَرَةِ }: تأكيد مشتق من المؤكد، كبدرة مبدرة، { مِنَ ٱلذَّهَبِ وَٱلْفِضَّةِ وَٱلْخَيْلِ }: عطف على النساء، { ٱلْمُسَوَّمَةِ }: المعلمة أو الراعية أو النجيبة، { وَٱلأَنْعَامِ }: الإبل والبقر والغنم، { وَٱلْحَرْثِ ذٰلِكَ }: المذكور، { مَتَاعُ ٱلْحَيَاةِ ٱلدُّنْيَا }: الفانية، { وَٱللَّهُ عِنْدَهُ حُسْنُ ٱلْمَآبِ }: المرجع، فيه حثٌ على استبداله بالشهوات.
