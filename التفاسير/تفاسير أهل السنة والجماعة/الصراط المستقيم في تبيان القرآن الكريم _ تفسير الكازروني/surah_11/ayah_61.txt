{ وَ } أرسلنا { إِلَىٰ }: قبيلة، { ثَمُودَ أَخَاهُمْ }: واحداً منهم { صَالِحاً قَالَ يٰقَوْمِ ٱعْبُدُواْ ٱللَّهَ مَا لَكُمْ مِّنْ إِلَـٰهٍ غَيْرُهُ هُوَ أَنشَأَكُمْ }: أباكُم { مِّنَ ٱلأَرْضِ وَٱسْتَعْمَرَكُمْ }: أقدركم على عمارتها، دل على أنه - تعالى - يريد عمارتها لا التبتل، أو أطال عمركم { فِيهَا } إذ فيهم من له ألف سنة { فَٱسْتَغْفِرُوهُ }: عمَّا مضى، { ثُمَّ تُوبُوۤاْ }: ارجعوا { إِلَيْهِ }: بالطاعة، { إِنَّ رَبِّي قَرِيبٌ }: بالرحمة، { مُّجِيبٌ } لداعيه.
