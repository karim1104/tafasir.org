{ أُوْلَـٰئِكَ ٱلَّذِينَ خَسِرُوۤاْ أَنْفُسَهُمْ }: أي: سعادتهم باشتراء أسباب العذاب، { وَضَلَّ عَنْهُمْ مَّا كَانُواْ يَفْتَرُونَ }: من الآلهة وشفاعتها، { لاَ جَرَمَ }: بمعنى حقً وفاعله، { أَنَّهُمْ فِي ٱلآخِرَةِ هُمُ ٱلأَخْسَرُونَ }: لا أخْسر منهم { إِنَّ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ وَأَخْبَتُوۤاْ }: اطمأنوا، { إِلَىٰ رَبِّهِمْ }: بلا شك في ربوبيته { أُوْلَـٰئِكَ أَصْحَابُ ٱلجَنَّةِ هُمْ فِيهَا خَالِدُونَ * مَثَلُ }: صفة، { ٱلْفَرِيقَيْنِ }: الكافر والمؤمن، { كَٱلأَعْمَىٰ وَٱلأَصَمِّ وَٱلْبَصِيرِ }: بآيات الله معتبرا، { وَٱلسَّمِيعِ }: للحق، { هَلْ يَسْتَوِيَانِ مَثَلاً } ، تمثيلاً { أَفَلاَ تَذَكَّرُونَ }: فتفقوا بينهما، { وَلَقَدْ أَرْسَلْنَا نُوحاً إِلَىٰ قَوْمِهِ إِنَّي }: بأني أو قائلين { لَكُمْ نَذِيرٌ مُّبِينٌ * أَن }: مفسرة، { لاَّ تَعْبُدُوۤاْ إِلاَّ ٱللَّهَ إِنِّيۤ أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ أَلِيمٍ }: وصف اليوم به مبالغة، { فَقَالَ ٱلْمَلأُ }: الأشراف، { ٱلَّذِينَ كَفَرُواْ مِن قِوْمِهِ }: بُيِّنَ في الأعراف { مَا نَرَاكَ إِلاَّ بَشَراً مِّثْلَنَا وَمَا نَرَاكَ ٱتَّبَعَكَ إِلاَّ ٱلَّذِينَ هُمْ أَرَاذِلُنَا }: سفلتنا اتبعوك، { بَادِيَ ٱلرَّأْيِ }: أوله بلا فكر او ظاهره بلا تعمق، { وَمَا نَرَىٰ لَكُمْ عَلَيْنَا مِن فَضْلٍ }: مطلقاً، { بَلْ نَظُنُّكُمْ كَاذِبِينَ }: في دعواكم { قَالَ يٰقَوْمِ أَرَأَيْتُمْ }: أخبروني { إِن كُنتُ عَلَىٰ بَيِّنَةٍ }: حجة واضحة { مِّن رَّبِّيۤ }: على صدقي، { وَآتَانِي رَحْمَةً }: نبوة، { مِّنْ عِندِهِ فَعُمِّيَتْ }: فخفيت البينة { عَلَيْكُمْ أَنُلْزِمُكُمُوهَا }: الاهتداء بها، { وَأَنتُمْ لَهَا }: للبينة، { كَارِهُونَ }: نافون.
