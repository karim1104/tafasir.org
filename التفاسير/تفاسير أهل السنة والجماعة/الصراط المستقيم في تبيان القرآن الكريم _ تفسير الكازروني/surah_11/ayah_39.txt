{ وَأُوحِيَ إِلَىٰ نُوحٍ أَنَّهُ لَن يُؤْمِنَ مِن قَوْمِكَ إِلاَّ مَن قَدْ آمَنَ فَلاَ تَبْتَئِسْ } لا تحزن، { بِمَا كَانُواْ يَفْعَلُونَ }: من تكذيبك، { وَٱصْنَعِ ٱلْفُلْكَ }: ملتبسا، { بِأَعْيُنِنَا }: بحفظنا حفظ من يعاين، { وَوَحْيِنَا }: إليك كيفية صنعته، { وَلاَ تُخَاطِبْنِي }: بالدعاء، { فِي }: شأن، { ٱلَّذِينَ ظَلَمُوۤاْ إِنَّهُمْ مُّغْرَقُونَ }: بالطُّوْفان، { وَيَصْنَعُ ٱلْفُلْكَ }: حكايةً عن الماضي { وَكُلَّمَا مَرَّ عَلَيْهِ مَلأٌ مِّن قَوْمِهِ سَخِرُواْ مِنْهُ }: كقولهم: كان نبيّاً فصار نجَّاراً، { قَالَ إِن تَسْخَرُواْ مِنَّا فَإِنَّا نَسْخَرُ مِنكُمْ }: عند نزول عذابكم { كَمَا تَسْخَرُونَ }: منا { فَسَوْفَ تَعْلَمُونَ مَن يَأْتِيهِ عَذَابٌ يُخْزِيهِ }: يهيئه في الدنيا، { وَيَحِلُّ }: حلول الدين او ينزل { عَلَيْهِ عَذَابٌ مُّقِيمٌ }: دائم في الآخرة، وكان يصنعه.
