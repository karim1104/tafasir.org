{ قَالُواْ يٰصَالِحُ قَدْ كُنتَ فِينَا مَرْجُوّاً }: في الرشد والسداد { قَبْلَ هَـٰذَا }: الأمر، { أَتَنْهَانَآ أَن نَّعْبُدَ مَا يَعْبُدُ آبَاؤُنَا } حكايةً عن الماضي { وَإِنَّنَا لَفِي شَكٍّ مِّمَّا تَدْعُونَآ إِلَيْهِ }: من ترك الأصنام، { مُرِيبٍ }: موقع في الريبة، فيه مبالغة، { قَالَ يٰقَوْمِ أَرَأَيْتُمْ }: أخبروني، { إِن كُنتُ عَلَىٰ بَيِّنَةً }: حُجَّة { مِّن رَّبِّي وَآتَانِي مِنْهُ رَحْمَةً }: نبوة، { فَمَن يَنصُرُنِي }: يمنعني، { مِنَ ٱللَّهِ }: من عذابه، { إِنْ عَصَيْتُهُ }: في التبليغ، { فَمَا تَزِيدُونَنِي }: إذن باستتباعكم إياي، { غَيْرَ تَخْسِيرٍ }: في حسناتي أو أنسبكم إلى الخسارة، { وَيٰقَوْمِ هَـٰذِهِ نَاقَةُ ٱللَّهِ لَكُمْ آيَةً }: فسر في الأعراف { فَذَرُوهَا تَأْكُلْ فِيۤ أَرْضِ ٱللَّهِ وَلاَ تَمَسُّوهَا بِسُوۤءٍ فَيَأْخُذَكُمْ عَذَابٌ قَرِيبٌ }: عاجل، { فَعَقَرُوهَا فَقَالَ }: لهم صالح، { تَمَتَّعُواْ فِي دَارِكُمْ ثَلاَثَةَ أَيَّامٍ }: من العَقْر: الأربعاء والخمس، والجمعة، ثم تهلكون { ذٰلِكَ وَعْدٌ غَيْرُ مَكْذُوبٍ }: فيه أو مصدر كالمخلود، { فَلَمَّا جَآءَ أَمْرُنَا }: بإهلاكهم { نَجَّيْنَا صَالِحاً وَٱلَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مِّنَّا }: لا بطاعتهم، { وَ }: نجيناهم، { مِنْ خِزْيِ يَوْمِئِذٍ }: يوم هلاكهم بالصيحة، { إِنَّ رَبَّكَ هُوَ ٱلْقَوِيُّ }: القادر، { ٱلْعَزِيزُ }: الغالب، { وَأَخَذَ ٱلَّذِينَ ظَلَمُواْ ٱلصَّيْحَةُ }: مع زلزلة فتقطعت قلوبهم كما مرّ { فَأَصْبَحُواْ فِي دِيَارِهِمْ جَاثِمِينَ }: خامدين ميتين { كَأَن }: كأنهم، { لَّمْ يَغْنَوْاْ }: يقيموا، { فِيهَآ أَلاَ إِنَّ ثَمُودَ كَفرُواْ رَبَّهُمْ أَلاَ بُعْداً }: هلاكا، { لِّثَمُودَ }: فسر في عاد وصرفه باعتبار أنه اسم جدهم وعدمه باعتبار القبيلة.
