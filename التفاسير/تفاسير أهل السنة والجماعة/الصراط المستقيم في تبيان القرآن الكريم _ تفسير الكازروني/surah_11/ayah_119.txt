{ وَلَوْ شَآءَ رَبُّكَ لَجَعَلَ ٱلنَّاسَ أُمَّةً وَاحِدَةً }: مسلمين، { وَلاَ يَزَالُونَ مُخْتَلِفِينَ }: في فواسد العقائد، { إِلاَّ مَن رَّحِمَ رَبُّكَ }: اجتمعوا على الحق، { وَلِذٰلِكَ }: الاختلاف، { خَلَقَهُمْ }: اللام للعاقبة أو للتمكين نحو: [غافر: 61]، أو بمعنى على، نحو [الصافات: 103]: أو كذلك الرحمة والضمير لـ " من " { وَتَمَّتْ كَلِمَةُ }: قضاءُ { رَبِّكَ لأَمْلأَنَّ جَهَنَّمَ مِنَ }: مُتمردي { ٱلْجِنَّةِ وَٱلنَّاسِ أَجْمَعِينَ }: أي منهما لا من أحدهما.
