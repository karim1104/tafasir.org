{ وَكُـلاًّ }: كل نبأ، { نَّقُصُّ عَلَيْكَ مِنْ أَنْبَاءِ ٱلرُّسُلِ }: هو { مَا نُثَبِّتُ بِهِ فُؤَادَكَ }: بزيادة يقينك، { وَجَآءَكَ فِي هَـٰذِهِ } الانباء { ٱلْحَقُّ وَمَوْعِظَةٌ وَذِكْرَىٰ لِلْمُؤْمِنِينَ * وَقُل لِّلَّذِينَ لاَ يُؤْمِنُونَ ٱعْمَلُواْ }: قَارين { عَلَىٰ مَكَانَتِكُمْ }: حالتكم من التجرد { إِنَّا عَامِلُونَ }: على حالنا، { وَٱنْتَظِرُوۤاْ }: بنا الدوائر، { إِنَّا مُنتَظِرُونَ }: عقابكم { وَلِلَّهِ غَيْبُ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ }: لا يخفي عليه ما فيهما، { وَإِلَيْهِ يُرْجَعُ ٱلأَمْرُ }: الأمور { كُلُّهُ فَٱعْبُدْهُ وَتَوَكَّلْ عَلَيْهِ وَمَا رَبُّكَ بِغَافِلٍ عَمَّا تَعْمَلُونَ }: فيجازي كلاًّ بما يستحقه جل وعلا سبحانه وتعالى واللهُ أعلمُ.
