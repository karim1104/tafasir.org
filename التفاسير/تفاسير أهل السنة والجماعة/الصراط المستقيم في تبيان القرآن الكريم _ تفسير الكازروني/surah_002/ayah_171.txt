مَثلُكَ { وَمَثَلُ ٱلَّذِينَ كَفَرُواْ كَمَثَلِ ٱلَّذِي يَنْعِقُ }: يُصَوِّتُ، { بِمَا }: بحيوان، { إِلاَّ دُعَآءً وَنِدَآءً }: يفهم، { لاَ يَسْمَعُ }: من الداعي بلا فهم معناه، { صُمٌّ }: عَنْ سَمَاع الحق، ورُفِعَ ذَمّاً { بُكْمٌ }: عن قوله، { عُمْيٌ }: عن رُؤْيَة مسلكه، { فَهُمْ لاَ يَعْقِلُونَ }: شبَّههم بالحيوان ثم بالمجانين.
