{ وَمِنَ ٱلنَّاسِ مَن يَشْرِي }: يبيع، { نَفْسَهُ }: بالجهاد، { ٱبْتِغَآءَ }: طلب، { مَرْضَاتِ ٱللَّهِ }: كَصُهَيْب، عُذِّيبَ ليرتد فأطى جميع أمواله وأتى المدينة، { وَٱللَّهُ رَؤُوفٌ بِٱلْعِبَادِ * يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ ٱدْخُلُواْ فِي ٱلسِّلْمِ }: الانقياد لله، { كَآفَّةً }: في جميع شَرَائعِه، أو بكُلِّيَّتكم، من كَفَفْت أي: جَمَعْت، { وَلاَ تَتَّبِعُواْ خُطُوَاتِ } آثارِ { ٱلشَّيْطَانِ إِنَّهُ لَكُمْ عَدُوٌّ مُّبِينٌ * فَإِن زَلَلْتُمْ }: عدلتم عن الدخول، { مِّن بَعْدِ مَا جَآءَتْكُمُ ٱلْبَيِّنَاتُ }: على أنه حَقٌّ، { فَٱعْلَمُوۤاْ أَنَّ ٱللَّهَ عَزِيزٌ }: غالبٌ، { حَكِيمٌ }: لا ينتقم ظلماً، وفي العلم بهما انزجار عنها.
