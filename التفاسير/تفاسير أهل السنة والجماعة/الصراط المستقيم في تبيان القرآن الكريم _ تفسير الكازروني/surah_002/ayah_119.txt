{ إِنَّا أَرْسَلْنَاكَ }: ملتبساً، { بِٱلْحَقِّ بَشِيراً }: بالعفو، { وَنَذِيراً }: بالقَهْر، { وَلاَ تُسْأَلُ عَنْ أَصْحَابِ ٱلْجَحِيمِ }: لِمَ لَمْ تُؤْمنوا، ونهى عن سؤاله عن حالهم لِفَظَاعتها، { وَلَنْ تَرْضَىٰ عَنكَ ٱلْيَهُودُ وَلاَ ٱلنَّصَارَىٰ حَتَّىٰ تَتَّبِعَ مِلَّتَهُمْ }: المِلَّةُ مَا شَرعهُ الله تعالى لعباده ليتوصلوا به إلى جواره، وإطلاقها على الباطل للتضاد، { قُلْ إِنَّ هُدَى ٱللَّهِ } الذي يعثني به { هُوَ ٱلْهُدَىٰ وَلَئِنِ ٱتَّبَعْتَ أَهْوَآءَهُمْ }:الباطلة، { بَعْدَ ٱلَّذِي جَآءَكَ مِنَ ٱلْعِلْمِ مَا لَكَ مِنَ ٱللَّهِ مِن وَلِيٍّ وَلاَ نَصِيرٍ }: يدفع عذابه عنك.
