{ وَلَقَدْ عَلِمْتُمُ } حال { ٱلَّذِينَ ٱعْتَدَواْ مِنْكُمْ فِي ٱلسَّبْتِ } من سبت أي: عَظَّمَ السبت، إذ نهوا عن الصيد فيه تعظيماً له { فَقُلْنَا لَهُمْ كُونُواْ قِرَدَةً } أمر تكوينى { خَاسِئِينَ } مطرودين ذليلين، نودوا بذلك فصاروا كذلك، روي لأن شبانهم صاروا قردة وشيوخهم خنازير { فَجَعَلْنَاهَا } المسخة { نَكَالاً } عبرة مانعة عن ارتكاب مثله { لِّمَا بَيْنَ يَدَيْهَا } لمعاصريهم { وَمَا خَلْفَهَا } من بعدهم { وَمَوْعِظَةً لِّلْمُتَّقِينَ }.
