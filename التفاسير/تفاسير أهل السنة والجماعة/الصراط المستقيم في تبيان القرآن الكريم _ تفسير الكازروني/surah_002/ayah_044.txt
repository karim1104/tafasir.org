ُرُونَ ٱلنَّاسَ بِٱلْبِرِّ } كاتباع التوراة التي فيها وجوب اتباع محمد -صلى الله عليه وسلم- { وَتَنْسَوْنَ أَنْفُسَكُمْ } في التزام البر { وَأَنْتُمْ تَتْلُونَ } تقرؤون أو تتبعون { ٱلْكِتَٰبَ } التوراة الناهية عن ذلك { أَفَلاَ تَعْقِلُونَ } قُبْحَهُ، و أَصْلُ العقل الحبس، سُمِّىَ به الإدراك الإنساني لأنه يحبسه عَمَّا يقبح، ثم القوة التي بها النفس تدرك ذلك، وفي الآية حَثُّ الواعظ على الاتعاظ، لا منع الفاسق من الوعظ.
