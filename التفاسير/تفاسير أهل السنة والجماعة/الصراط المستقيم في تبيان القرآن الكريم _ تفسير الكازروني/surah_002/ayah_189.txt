ولما سألوا عن حكمة زيادة الهلال ثم نُقصانه وعن فائدة دُخُول المُحْرمين من ظهور بيوتهم نزلت، { يَسْأَلُونَكَ عَنِ }: فائدة، { ٱلأَهِلَّةِ }: كيف تبدوا دقيقة ثُمَّ تزيد، { قُلْ هِيَ }: فائدتها الظاهرة، { مَوَاقِيتُ }: جمع ميقات ما يعلم به الوقت، وهو الزمان المفروض لأمر، والزمان: مدة مقسومة، والمدة: جمع امتداد، حركة الفلك، { لِلنَّاسِ وَٱلْحَجِّ وَلَيْسَ ٱلْبِرُّ بِأَن تَأْتُواْ ٱلْبُيُوتَ }: في الإحرام، { مِن ظُهُورِهَا }: إذ كانوا ينقبون فيها فيدخلون ويخرجون من النقب، { وَلَـٰكِنَّ ٱلْبِرَّ مَنِ ٱتَّقَىٰ }: المحارم، { وَأْتُواْ ٱلْبُيُوتَ مِنْ أَبْوَابِهَا }: في الإحرام، إذ ليس تركها برّاً، { وَٱتَّقُواْ ٱللَّهَ لَعَلَّكُمْ تُفْلِحُونَ } راجين الفلاح.
