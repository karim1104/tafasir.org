{ وَظَلَّلْنَا عَلَيْكُمُ ٱلْغَمَامَ } في التيه لحفظكم من الشمس { وَأَنزَلْنَا عَلَيْكُمُ ٱلْمَنَّ } الترنجبين من الفجر إلى طلوع الشمس كالثلج { وَٱلسَّلْوَىٰ } نوع من السماني، قائلين: { كُلُواْ مِن طَيِّبَٰتِ } مستلذات { مَا رَزَقْنَٱكُمْ } ولا تدخروا، فادخروا فقطع عنهم { وَمَا ظَلَمُونَا } بالكفران { وَلَـٰكِن كَانُوۤاْ أَنْفُسَهُمْ يَظْلِمُونَ } بكفران ذلك وغيره من النعم كنزول عمود من السماء في الليل لإضاءتهم وعدم توسيخ ثيابهم ونقائها وغير ذلك.
