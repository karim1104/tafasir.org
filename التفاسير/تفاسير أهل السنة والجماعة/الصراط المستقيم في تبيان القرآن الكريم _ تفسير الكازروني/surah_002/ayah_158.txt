{ إِنَّ ٱلصَّفَا وَٱلْمَرْوَةَ }: جبلين بمكة كان عليهما صَنمان: إسَاف ونائلة، وتخَرّج المسلمون السعى بين كُلٍّ منهما لتشبههم بالجاهلية، { مِن شَعَآئِرِ ٱللَّهِ }: أَعْلَام مَناسِكه، { فَمَنْ حَجَّ ٱلْبَيْتَ أَوِ ٱعْتَمَرَ }: أصل الحَجّ: القصد، والاعتمار: الزيارة، فغلبا شَرْعاً على قصد البيت وزيارته المخصوصين، { فَلاَ جُنَاحَ }: إثْمَ، { عَلَيْهِ }: في، { أَن يَطَّوَّفَ بِهِمَا }: دّلَّ على الجواز الداخل في معنَى الوجوب فإنَّ معناهُ: عدم الحرمة والكراهة، وأما وجوبه فيثبتُ بالسنة، { وَمَن تَطَوَّعَ خَيْراً }: فَعلَ طاعة أو زاد على فرضه، { فَإِنَّ ٱللَّهَ شَاكِرٌ }: يجازي عَمَلَهُ الخير، { عَلِيمٌ }: بأحواله.
