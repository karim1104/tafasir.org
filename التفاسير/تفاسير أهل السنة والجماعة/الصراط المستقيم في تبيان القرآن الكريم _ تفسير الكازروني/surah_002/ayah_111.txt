{ وَقَالُواْ }: أهل الكتاب، فِيْه لَفٌ بين كلامي الفريقين، { لَن يَدْخُلَ ٱلْجَنَّةَ إِلاَّ مَن كَانَ هُوداً }: أصله يهوداً أو جمع هائد هدا مالة اليهود، { أَوْ }: لن يدخل الجنة إلا من كان { نَصَارَىٰ }: هذا مقالتهم، { تِلْكَ أَمَانِيُّهُمْ }: جمع أمنية، أفعولة من التمني، { قُلْ هَاتُواْ بُرْهَانَكُمْ }: على أختصاصكم بالجنة، { إِن كُنْتُمْ صَادِقِينَ * بَلَىٰ } إثبات لما نفوه من دخول غيرهم الجنة، { مَنْ أَسْلَمَ } أخلص، { وَجْهَهُ }: نفسه: أي: دينه، { للَّهِ وَهُوَ مُحْسِنٌ }: متبع أمر الله { فَلَهُ أَجْرُهُ عِندَ رَبِّهِ وَلاَ خَوْفٌ عَلَيْهِمْ وَلاَ هُمْ يَحْزَنُونَ }: كما مر.
