9;سْتَعِينُواْ } فيما شق عليكم { بِٱلصَّبْرِ } هُو حَبْسُ النَّفس عَلَى مُقْتَضى العَقْل والشرع، ويسمى في المصيبة صبراً، وعن المُشْتَهى عَناءً، وفي الحَرْبِ شَجَاعةً، وفي النوائب رحب الصدر، وفي إمساك الكلام كتماناً، والمراد هنا الصوم { وَٱلصَّلَٰوةِ } الناهية عن الفحشاء والمنكر { وَإِنَّهَا } الاستعانة بهما { لَكَبِيرَةٌ } ثقيلة { إِلاَّ عَلَى ٱلْخَٰشِعِينَ } الساكنين إلى الطاعة.
