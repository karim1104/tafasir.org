لمَّا عَدَّد رذائل عدُوِّه عقبها ببعض فضائل حبيبه فقال: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * إِنَّآ أَعْطَيْنَاكَ }: يا محمد { ٱلْكَوْثَرَ }: النهر المعروف، أو الحوض، وقيل: الخير المفرط الكثرة { فَصَلِّ }: أي: دم على الصلاة المفروضات، أو صل عيد النحر خالصا { لِرَبِّكَ }: شُكراً له { وَٱنْحَرْ }: نسكك، أو: ضَع اليُمْنى على اليسرى، حذاء النحر في الصلاة، أو ارفع اليد إليه في التكبير { إِنَّ شَانِئَكَ }: أي: مبغضك { هُوَ ٱلأَبْتَرُ }: بلا عقب، وكل مؤمن يولد إلى القيامة فهم أعقابك، والله أعلم.
