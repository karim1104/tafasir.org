لَمَّا بين تحال المشركين الظَّانّين بالله ظنّ السَّوء ووبالهم، نزه ذاته تعالى عما يصفون فقال: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * قُلْ } لمن قال يقول لك: صف لنا ربك: { هُوَ }: أي: المسئول عنه، أو الشأن { ٱللَّهُ }: الذات المستجمع لصفات الكمال { أَحَدٌ }: مستجمع لنعوت الجلال، وتستعمل أحد في الاثبات مكان واحد لا تحادهما معنى { ٱللَّهُ ٱلصَّمَدُ }: المصمود إليه، أي: المقصود في كل الحوائج، وترك العطف لأنها كالدليل على الأولى، أو نتيجتها وعرَّفهُ دون أحد لعلمهم بصمديته دون أحديته { لَمْ يَلِدْ }: كريما، لأنه لم يجانس { وَلَمْ يُولَدْ }: كعيسى وعزير، لتنزهه عن الحدوث { وَلَمْ يَكُنْ لَّهُ كُفُواً }: مكافئا مماثلاُ { أَحَدٌ }: قدم الظروف لأنه أهم، وربط الثلاث بالعطف لأنها كجملة نافية للأمثال، والسورة تعدل ثلث القرآن، لأن مقصاده إما العقائد الإلهية أو الأحكام، أو القصص، وهي عين الثلث، والله تعالى أعلم بالصواب، وإليه المرجع والمآب.
