{ قُلْ أَتَعْبُدُونَ مِن دُونِ ٱللَّهِ مَا لاَ يَمْلِكُ لَكُمْ ضَرّاً }: يدفعه عنكم، { وَلاَ نَفْعاً }: يوصله إليكم، وتأخر الضر عن النفع ظاهر لكن في مثل هذا يقدم اهتماما إذ كانوا يشركون لتشفع في دفع الضر، { وَٱللَّهُ هُوَ ٱلسَّمِيعُ }: لأقوالكم، { ٱلْعَلِيمُ }: بعقائدكم، { قُلْ يَـٰأَهْلَ ٱلْكِتَابِ لاَ تَغْلُواْ } لا تتجاوزا عن الحدِّ { فِي دِينِكُمْ } حَال كون دينكم { غَيْرَ ٱلْحَقِّ } ، { وَلاَ تَتَّبِعُوۤاْ أَهْوَآءَ قَوْمٍ قَدْ ضَلُّواْ مِن قَبْلُ }: قبل الإسلام، { وَأَضَلُّواْ }: خلقا، { كَثِيراً وَضَلُّواْ }: بعدهُ { عَن سَوَآءِ }: قصد، { ٱلسَّبِيلِ }: أي: الإسلام، { لُعِنَ ٱلَّذِينَ كَفَرُواْ مِن بَنِيۤ إِسْرَائِيلَ عَلَىٰ لِسَانِ دَاوُودَ }: في الزبور، أو بدعائه لاعتدائهم في السبت فمسخوا قردة، { وَعِيسَى ٱبْنِ مَرْيَمَ }: في الإنجيل، أو بدعائه بكفرهم بعد المائدة فمسخوا قردة وخنازير، { ذٰلِكَ }: اللعن، { بِمَا عَصَوْا }: بعصيانهم، { وَّكَانُواْ يَعْتَدُونَ }: باعتدائهم.
