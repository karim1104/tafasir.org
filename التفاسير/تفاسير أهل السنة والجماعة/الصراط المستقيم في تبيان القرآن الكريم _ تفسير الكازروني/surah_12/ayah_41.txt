{ يٰصَاحِبَيِ }: ساكني، { ٱلسِّجْنِ ءَأَرْبَابٌ مُّتَّفَرِّقُونَ }: متعددة، { خَيْرٌ أَمِ ٱللَّهُ ٱلْوَاحِدُ ٱلْقَهَّارُ }: الغالبُ الذي لا يُعَادِلُهُ أحد، { مَا تَعْبُدُونَ مِن دُونِهِ إِلاَّ أَسْمَآءً }: بلا معان، { سَمَّيْتُمُوهَآ أَنتُمْ وَآبَآؤُكُمْ مَّآ أَنزَلَ ٱللَّهُ بِهَا }: بعبادتها، { مِن سُلْطَانٍ }: حُجَّة، { إِنِ } مَا { ٱلْحُكْمُ }: في أمر العبادة، { إِلاَّ للَّهِ أَمَرَ أَلاَّ تَعْبُدُوۤاْ إِلاَّ إِيَّاهُ }: أي: وحِّدوهُ { ذٰلِكَ ٱلدِّينُ ٱلْقَيِّمُ }: المستقيم، { وَلَـٰكِنَّ أَكْثَرَ ٱلنَّاسِ لاَ يَعْلَمُونَ }: فيشركون، { يٰصَاحِبَيِ ٱلسِّجْنِ أَمَّآ أَحَدُكُمَا }: الساقي، فيخرج بعد ثلاث، { فَيَسْقِي رَبَّهُ خَمْراً }: يعود إلى منصبه، { وَأَمَّا ٱلآخَرُ }: الخبَّازُ، فيخرج بعد ثلاث، { فَيُصْلَبُ فَتَأْكُلُ ٱلطَّيْرُ مِن رَّأْسِهِ }: فقالا: كَذَبْنَا، فقال: { قُضِيَ } قُطِعَ { ٱلأَمْرُ ٱلَّذِي فِيهِ تَسْتَفْتِيَانِ * وَقَالَ }: يوسف، { لِلَّذِي ظَنَّ }: أيقن لقوله: قَضِي - إلى آخره، { أَنَّهُ نَاجٍ مِّنْهُمَا }: أي: الساقي، { ٱذْكُرْنِي عِندَ رَبِّكَ }: الملك الاعظم رَيَّان بن الوليد لخلصني من العزيز، { فَأَنْسَاهُ }: الساقي، { ٱلشَّيْطَانُ ذِكْرَ }: أي: ذكره عند، { رَبِّهِ }: أو أنسى يوسف ذكر الله فاستعان بغيره، { فَلَبِثَ فِي ٱلسِّجْنِ بِضْعَ }: ما بين ثلاث إلى تسع، { سِنِينَ }: كان لبثه سبعاً.
