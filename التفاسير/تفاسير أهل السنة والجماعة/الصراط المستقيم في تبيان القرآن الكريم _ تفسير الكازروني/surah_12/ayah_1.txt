لما قال: [هود: 120]... إلى آخر أتبعه بأحسن القصص فقال: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * الۤر تِلْكَ }: الآيات التي في السورة، { آيَاتُ ٱلْكِتَابِ ٱلْمُبِينِ }: الواضح إعجازهُ { إِنَّآ أَنْزَلْنَاهُ }: الكتاب، { قُرْآناً }: مجموعاً أو مقروءاً { عَرَبِيّاً }: بلغتكم { لَّعَلَّكُمْ تَعْقِلُونَ }: تفهمون، { نَحْنُ نَقُصُّ عَلَيْكَ أَحْسَنَ ٱلْقَصَصِ }: فصاحةً أو: أحسن المقصوص حكماً ونكتاً والظاهر: أحسنها في بابه لا من سائرها حتى قصة حبيب الله صلى الله عليه وسلم أو: نُبيِّنُ أحسن البيان { بِمَآ أَوْحَيْنَآ }: بإيحائنا، { إِلَيْكَ هَـٰذَا ٱلْقُرْآنَ وَإِن كُنتَ مِن قَبْلِهِ لَمِنَ ٱلْغَافِلِينَ }: عن هذه القصص.
