{ فَلاَ تَكُ فِي مِرْيَةٍ }: شك، { مِّمَّا يَعْبُدُ }: من عبادة، { هَـٰؤُلاۤءِ }: المشركين أي: في أنها كفر مُؤَدٍّ إلى ماحلَّ بسلفهم، { مَا يَعْبُدُونَ }: عبادةً { إِلاَّ كَمَا }: كان { يَعْبُدُ آبَاؤُهُم مِّن قَبْلُ }: فسيلحقهم ما لحقهم { وَإِنَّا لَمُوَفُّوهُمْ نَصِيبَهُمْ }: من الجزاء، { غَيْرَ مَنقُوصٍ }: للتأكيد.
