{ ذَلِكَ }: النبأ، { مِنْ أَنْبَآءِ ٱلْقُرَىٰ }: المهلكة، { نَقُصُّهُ عَلَيْكَ }: يا محمد، { مِنْهَا قَآئِمٌ }: آثار، كحيطانه، { وَ }: منها { حَصِيدٌ }: عافي الأثر، { وَمَا ظَلَمْنَاهُمْ }: بإهلاكهم، { وَلَـٰكِن ظَلَمُوۤاْ أَنفُسَهُمْ }: فاستحقوه، { فَمَا أَغْنَتْ } دفعت { عَنْهُمْ آلِهَتُهُمُ ٱلَّتِي يَدْعُونَ مِن دُونِ ٱللَّهِ مِن شَيْءٍ }: شيئا من عذابه { لَّمَّا جَآءَ أَمْرُ رَبِّكَ }: عذابه، { وَمَا زَادُوهُمْ }: أي: الآلهة، إياهم، { غَيْرَ تَتْبِيبٍ }: هلاك، { وَكَذٰلِكَ }: الأخذ، { أَخْذُ رَبِّكَ إِذَا أَخَذَ } أهل { ٱلْقُرَىٰ وَهِيَ ظَالِمَةٌ }: تعليل لأخذه، { إِنَّ أَخْذَهُ أَلِيمٌ شَدِيدٌ } غير مرجو الخلاص.
