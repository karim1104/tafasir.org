{ إِنَّمَا يَفْتَرِي ٱلْكَذِبَ ٱلَّذِينَ لاَ يُؤْمِنُونَ بِآيَاتِ ٱللَّهِ وَأُوْلـٰئِكَ هُمُ ٱلْكَاذِبُونَ }: حقيقة أكد بالتكرار وإن وغيره مقابلة لـ " إنما أنت " { مَن كَفَرَ بِٱللَّهِ مِن بَعْدِ إيمَانِهِ إِلاَّ مَنْ أُكْرِهَ }: على كلمة الكفر { وَقَلْبُهُ مُطْمَئِنٌّ بِٱلإِيمَانِ }: خبر من محذوف دلّ عليه { وَلَـٰكِن مَّن شَرَحَ بِالْكُفْرِ صَدْراً }: نَفْساً، { فَعَلَيْهِمْ غَضَبٌ مِّنَ ٱللَّهِ وَلَهُمْ عَذَابٌ عَظِيمٌ * ذٰلِكَ }: الكفر أو الغضب، { بِأَنَّهُمُ ٱسْتَحَبُّواْ }: اختاروا، { ٱلْحَيَاةَ ٱلْدُّنْيَا عَلَىٰ ٱلآخِرَةِ وَأَنَّ ٱللَّهَ لاَ يَهْدِي ٱلْقَوْمَ ٱلْكَافِرِينَ }: في علمه تعالى.
