{ وَ }: اذكر { يَوْمَ نَبْعَثُ مِن كُلِّ أُمَّةٍ شَهِيداً }: رَسُولها الشاهد عليهم، { ثُمَّ لاَ يُؤْذَنُ لِلَّذِينَ كَفَرُواْ }: في الاعتذار، { وَلاَ هُمْ يُسْتَعْتَبُونَ }: لا يُطلْلَبُ منهم إ رضاء الله لأنه ليس يوم عملٍ { وَإِذَا رَأى ٱلَّذِينَ ظَلَمُواْ ٱلْعَذَابَ }: في جهنم، { فَلاَ يُخَفَّفُ عَنْهُمْ وَلاَ هُمْ يُنظَرُونَ }: يمهلونَ { وَإِذَا رَأى ٱلَّذِينَ أَشْرَكُواْ شُرَكَآءَهُمْ قَالُواْ }: غيْضاً على آلهتهم ودُنْيَاهُم { رَبَّنَا هَـٰؤُلآءِ شُرَكَآؤُنَا ٱلَّذِينَ كُنَّا نَدْعُوْا }: نعبدهم { مِن دُونِكَ فَألْقَوْا إِلَيْهِمُ ٱلْقَوْلَ }: أي: قالوا لهم: { إِنَّكُمْ لَكَاذِبُونَ } بل عبدتم أهواءكم، { وَأَلْقَوْاْ }: الكُفَّار { إِلَىٰ ٱللَّهِ يَوْمَئِذٍ ٱلسَّلَمَ }: استسلموا لحكمه، { وَضَلَّ }: ضاع، { عَنْهُم مَّا كَانُواْ يَفْتَرُونَ }: من نصرة آلهتهم.
