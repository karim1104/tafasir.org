{ أُولَـٰئِكَ ٱلَّذِينَ طَبَعَ }: ختم، { ٱللَّهُ عَلَىٰ قُلُوبِهِمْ وَسَمْعِهِمْ وَأَبْصَارِهِمْ }: عن فَهْم الحق وسماعه وإبصاره، { وَأُولَـٰئِكَ هُمُ ٱلْغَافِلُونَ }: حقيقة، { لاَ جَرَمَ }: حقاً، { أَنَّهُمْ فِي ٱلآخِرَةِ هُمُ ٱلْخَاسِرونَ }: لتضييعهم فطرتهم، { ثُمَّ إِنَّ رَبَّكَ لِلَّذِينَ هَاجَرُواْ }: أي: لَهُم لا عليهم، أو خبره محذوف دلّ عليه خبر إنّ الثانية، { مِن بَعْدِ مَا فُتِنُواْ }: عُذِّبوا ليرتدوا كعمَّار، { ثُمَّ جَاهَدُواْ وَصَبَرُواْ }: على المشاق لله، { إِنَّ رَبَّكَ مِن بَعْدِهَا }: بعد الثلاثة، { لَغَفُورٌ }: ذنوبهم، { رَّحِيمٌ }: بهم، { يَوْمَ تَأْتِي كُلُّ نَفْسٍ تُجَادِلُ عَن نَّفْسِهَا }: ذاتها لخلاصها، فالنفس الأولى لمجموع الذات وصاحبها، { وَتُوَفَّىٰ كُلُّ نَفْسٍ }: جزاء، { مَّا عَمِلَتْ وَهُمْ لاَ يُظْلَمُونَ }: في أجرهم، { وَضَرَبَ ٱللَّهُ مَثَلاً قَرْيَةً }: جعلها مثلاً لمن أنعم عليه فكفر بنعمته فنزل به نقمة، { كَانَتْ آمِنَةً }: كمكَّة، { مُّطْمَئِنَّةً }: لا يزعج أهلها الخوف { يَأْتِيهَا رِزْقُهَا }: قوتها، { رَغَداً }: واسعاً { مِّن كُلِّ مَكَانٍ }: من نواحيها، { فَكَفَرَتْ بِأَنْعُمِ ٱللَّهِ }: بترك طاعته، { فَأَذَاقَهَا ٱللَّهُ لِبَاسَ ٱلْجُوعِ }: فقحطوا سبع سنين بدعاء النبي صلى الله عليه وسلم، { وَٱلْخَوْفِ }: من سطوة سرايا المسلمين، فالذوق مستعار لإدراك أثر الضرر واللباس لما غشيهم من الجوع والخوف وأوقع الإذاقة عليه بالنظر إلى المستعار له، { بِمَا كَانُواْ يَصْنَعُونَ * وَلَقَدْ جَآءَهُمْ رَسُولٌ مِّنْهُمْ }: نسباً، { فَكَذَّبُوهُ فَأَخَذَهُمُ ٱلْعَذَابُ }: المذكور، { وَهُمْ ظَالِمُونَ * فَكُلُواْ مِمَّا رَزَقَكُمُ ٱللَّهُ حَلَـٰلاً طَيِّباً وَٱشْكُرُواْ نِعْمَتَ ٱللَّهِ إِن كُنْتُمْ إِيَّاهُ تَعْبُدُونَ }: تطيعون.
