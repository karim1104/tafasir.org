{ يُنبِتُ لَكُمْ بِهِ } بالماء، { ٱلزَّرْعَ وَٱلزَّيْتُونَ وَٱلنَّخِيلَ وَٱلأَعْنَابَ وَمِن }: بعض، { كُلِّ ٱلثَّمَرَاتِ }: إذ كلها إنما توجد في الجنة { إِنَّ فِي ذَلِكَ لآيَةً }: على كمال قدرته، { لِّقَوْمٍ يَتَفَكَّرُونَ * وَسَخَّرَ لَكُمُ }: هيَّأ لمنافعكم { ٱلَّيلَ وَٱلْنَّهَارَ وَٱلشَّمْسَ وَٱلْقَمَرَ وَٱلْنُّجُومُ }: أي: نفعكم بها حال كونها { مُسَخَّرَاتٌ } أو تسخيرات أو أنواعا من التسخير، { بِأَمْرِهِ }: بتقديره، { إِنَّ فِي ذَلِكَ لآيَاتٍ لِّقَوْمٍ يَعْقِلُونَ }: { وَ } سخر لكم { مَا ذَرَأَ } خلق { لَكُمْ فِي ٱلأَرْضِ }: من الحيوان والجماد { مُخْتَلِفاً أَلْوَانُهُ }: أشكاله، { إِنَّ فِي ذَلِكَ لآيَةً لِّقَوْمٍ يَذَّكَّرُونَ }: أن اختلاف طباعه وأشكاله مع اتحاد مواده إنما هو بصنع حكيم عليم، أفرد آية هنا ليطابق ما ذرأ وإن كثر ما صدقه، وكذا في الأول لأن الاستدلال بإنبات الماء واحد، وجمع في الثاني لأن الاستدلال فيه متعدد، وجعل العقل فيه والفكر في الأول لأن دلالات العلويات ظاهرة.
