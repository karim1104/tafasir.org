{ قُلِ ٱللَّهُمَّ }: يا الله، أو يا الله أُمَّنا بخَيْرٍ، أي: اقصدنا يا { مَالِكَ ٱلْمُلْكِ }: المتصرف فيما بمكن التصرف فيه، النبوة، { تُؤْتِي ٱلْمُلْكَ مَن تَشَآءُ }: كمحمد وصحبه { وَتَنزِعُ ٱلْمُلْكَ مِمَّنْ تَشَآءُ }: كاليهود والفرس، أو المُلْكُ النبوة، ونزعها: ونقلها، { وَتُعِزُّ مَن تَشَآءُ وَتُذِلُّ مَن تَشَآءُ بِيَدِكَ ٱلْخَيْرُ }: خصَّه بالذِّكر أدباً، أو: لأنه المقضيُّ بالذات، أو لأنه في مقام الشكر ثم نَبَّه على أنهما بقدرته بقوله، { إِنَّكَ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ * تُولِجُ }: بزيادة أحدهما ونقص الآخر، أو بالتعقيب، { ٱللَّيْلَ فِي ٱلْنَّهَارِ وَتُولِجُ ٱلنَّهَارَ فِي ٱلْلَّيْلِ }:بزيادة أحدهما ونقص الآخر، أو بالتعقيب، { وَتُخْرِجُ ٱلْحَيَّ مِنَ ٱلْمَيِّتِ }: كالنطفة، { وَتُخْرِجُ ٱلَمَيِّتَ }: كالنطفة، { مِنَ ٱلْحَيِّ }: أو المسلم من الكافر وعكسه، { وَتَرْزُقُ مَن تَشَآءُ بِغَيْرِ حِسَابٍ }: بلا ضيق، إذ المحسوب يقال للقليل.
