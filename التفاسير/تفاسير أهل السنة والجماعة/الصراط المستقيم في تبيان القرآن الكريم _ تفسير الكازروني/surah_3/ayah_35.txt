اذكر { إِذْ قَالَتِ ٱمْرَأَتُ عِمْرَانَ }: حنَّة اُمُّ مريم، { رَبِّ إِنِّي نَذَرْتُ لَكَ مَا فِي بَطْنِي }: فلا أَسْتَخْدِمه، { مُحَرَّراً }: مخلصاً لعبادتك، { فَتَقَبَّلْ مِنِّي }: ما نذرت، { إِنَّكَ أَنتَ ٱلسَّمِيعُ } لدعائي { ٱلْعَلِيمُ }: بنيتي، وكان هذا النذر مشروعاً لهم في الذَّكَر، { فَلَمَّا وَضَعَتْهَا }: الأنثي أي ما في بطنها، { قَالَتْ }: تَحسُّراً وعُذْراً، { رَبِّ إِنِّي وَضَعْتُهَآ أُنْثَىٰ وَٱللَّهُ أَعْلَمُ بِمَا وَضَعَتْ }: أي: وضَعته، عسى أن يكون فيه سر، وبالغَيبة قول الله تعظيماً { وَلَيْسَ ٱلذَّكَرُ كَٱلأُنْثَىٰ }: فيما نذرت من خدمة بيت المقدس، وعكس في التشبيه مبالغة كالقمر كوجهه، أو هو تعظيمٌ من الله لمريم، أي: ليس الذكر المطلوب كهذه الأنثى لأنها وابنها آية للعالمين، { وَإِنِّي سَمَّيْتُهَا مَرْيَمَ }: تفاؤلا، معناه: عابدة، { وِإِنِّي أُعِيذُهَا بِكَ }: بحفظك، { وَذُرِّيَّتَهَا مِنَ ٱلشَّيْطَانِ ٱلرَّجِيمِ }: المطرود، فما مَسَّهَا الشيطان ولا ابنها.
