{ يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ ٱتَّقُواْ ٱللَّهَ حَقَّ تُقَاتِهِ }: في الحديث أنه طاعةٌ بلا عصيان، وشُكرٌ بلا كفران، وذكر بلا نسيان ونُسِخت بآية: [التغابن: 16]: خلافا لبعض السلف، { وَلاَ تَمُوتُنَّ إِلاَّ وَأَنْتُمْ مُّسْلِمُونَ }: دُوْموا على الإسلام، حتى تموتوا عليه، { وَٱعْتَصِمُواْ }: استمسكوا، { بِحَبْلِ ٱللَّهِ }: القرآن، من حيث أنَّ التمسك به ينجي مِنَ الرَّدَي كما أن المتمسِّك بالحَبْل يسلم من التردي { جَمِيعاً }: مجتمعين عليه، { وَلاَ تَفَرَّقُواْ }: كأهل الكتاب، { وَٱذْكُرُواْ نِعْمَتَ ٱللَّهِ عَلَيْكُمْ }: منها الإسلام، { إِذْ كُنْتُمْ أَعْدَآءً }: أراد عداوة الأوس مع الخزرج في الجاهلية مائة وعشرين سنة، { فَأَلَّفَ بَيْنَ قُلُوبِكُمْ }: بالإسلام، { فَأَصْبَحْتُمْ }: صرتم، { بِنِعْمَتِهِ إِخْوَاناً }: مُتحابين، { وَكُنْتُمْ }: في الجاهلية، { عَلَىٰ شَفَا }: طرف، في الحديث: " لَا تَنْظُروا إلى صَوْم الرَّجُل وصلاته، ولكن إلى وَرَعه إذا أشفى على الذنب " أي: اشرف، { حُفْرَةٍ مِّنَ ٱلنَّارِ }: أي: مشرفين على الوقوع في جهنم، { فَأَنقَذَكُمْ }: أنجاكم بالإسلام، { مِّنْهَا }: من شَفِاها، وتأْنِثهُ باعتبار المضاف إليه، { كَذٰلِكَ }: التبيين، { يُبَيِّنُ ٱللَّهُ لَكُمْ آيَاتِهِ لَعَلَّكُمْ تَهْتَدُونَ }: لتدوموا على الهداية، { وَلْتَكُن مِّنْكُمْ } أيها المؤمنون، { أُمَّةٌ }: جماعة، { يَدْعُونَ }: الناس، { إِلَى ٱلْخَيْرِ }: الدنيوي والأخروي دل بـ " من " على فرضية الكفاية أو تبيينية فيكون المعنَى واجباً ومندوباً لكن على حسب ما يأمر به، { وَيَأْمُرُونَ بِٱلْمَعْرُوفِ }: وهو يكون واجباً ومندوباً لكن على حسب ما يأمر به، { وَيَنْهَوْنَ عَنِ ٱلْمُنْكَرِ }: هو واجب كله إذ كل ما أنكره الشرع حرام، والمكروه غير منكر، وخَصَّصَ بعدما عمم إيذاناً بفضله، { وَأُوْلَـٰئِكَ هُمُ ٱلْمُفْلِحُونَ }: المخصوصون بكمال النجاة.
