{ إِنَّ ٱلدِّينَ }: المرضي، { عِندَ ٱللَّهِ ٱلإِسْلاَمُ }: اتباع محمد عليه الصلاة والسلام فلا يقبل غيره، ويفتح إنَّ بدَلٌ من أنه، { وَمَا ٱخْتَلَفَ ٱلَّذِينَ أُوتُواْ ٱلْكِتَابَ }: في حَقِّيَّة الإسلام، { إِلاَّ مِن بَعْدِ مَا جَآءَهُمُ ٱلْعِلْمُ }: تحقيقه، { بَغْياً }: حسدا، { بَيْنَهُمْ }: لا لشبهة، { وَمَن يَكْفُرْ بِآيَاتِ ٱللَّهِ فَإِنَّ ٱللَّهَ سَرِيعُ ٱلْحِسَابِ }: لمعجزاته.
