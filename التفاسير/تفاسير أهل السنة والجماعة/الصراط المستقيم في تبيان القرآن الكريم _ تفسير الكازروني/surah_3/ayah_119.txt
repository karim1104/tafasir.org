{ هَآأَنْتُمْ أُوْلاۤءِ }: المخاطبون في موالاتهم، { تُحِبُّونَهُمْ وَلاَ يُحِبُّونَكُمْ وَتُؤْمِنُونَ بِٱلْكِتَابِ كُلِّهِ }: وهم لا يؤمنون بكتابكم فهم في باطلهم أصلب منكم في حقكم، { وَإِذَا لَقُوكُمْ قَالُوۤاْ آمَنَّا }: نفاقاً، { وَإِذَا خَلَوْاْ }: بعضكم من بعض، { عَضُّواْ عَلَيْكُمُ ٱلأَنَامِلَ مِنَ }: أجل، { ٱلْغَيْظِ }: حيث لم يجدوا إلى دفعكم سبيلاً، { قُلْ }: يا محمد، { مُوتُواْ بِغَيْظِكُمْ }: دعاء بتضاعف غيظهم إلى موتهم بتضاعف قوة الإسلام، { إِنَّ ٱللَّهَ عَلِيمٌ بِذَاتِ }: بما في، { ٱلصُّدُورِ }: من الغيظ وغيره فيجازي.
