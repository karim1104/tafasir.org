ويقولون، { رَبَّنَا لاَ تُزِغْ }: لا تمل عن الحق، { قُلُوبَنَا }: إلى تأويل لا ترتضيه، { بَعْدَ إِذْ هَدَيْتَنَا }: إلى الحق، { وَهَبْ لَنَا مِن لَّدُنْكَ رَحْمَةً }: ثبتنا، { إِنَّكَ أَنْتَ ٱلْوَهَّابُ }: لكل سؤل، { رَبَّنَآ إِنَّكَ جَامِعُ ٱلنَّاسِ لِيَوْمٍ }: في يوم، { لاَّ رَيْبَ فِيهِ }: في وقوعه، { إِنَّ ٱللَّهَ لاَ يُخْلِفُ ٱلْمِيعَادَ }: أفاد بتلوين تغيير الخطاب أشعر بأن الإلهية تنافيه، واستدل به الوعيدية، وردوا بأن وعيد الفساق مشروط بعدم العفو كما هو مشروط بعدم التوبة وفاقاً.
