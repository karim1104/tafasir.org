{ يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ لاَ تَكُونُواْ كَٱلَّذِينَ كَفَرُواْ وَقَالُواْ لإِخْوَانِهِمْ }: لأجل أصحابهم، { إِذَا ضَرَبُواْ فِي ٱلأَرْضِ }: سافروا لغرض فماتوا سفرا، { أَوْ كَانُواْ غُزًّى }: فقتلوا، جمع غاز، { لَّوْ كَانُواْ عِنْدَنَا مَا مَاتُواْ وَمَا قُتِلُواْ }: لا تَقُولُوا ذلك، وقد مضى بيان الموت والقتل أيضاً، { لِيَجْعَلَ ٱللَّهُ ذٰلِكَ }: القول، { حَسْرَةً فِي قُلُوبِهِمْ }: خاصة دون قلوبكم، { وَٱللَّهُ يُحْيِـي وَيُمِيتُ }: لا الإقامة والسفر { وَٱللَّهُ بِمَا تَعْمَلُونَ }: من موافقتهم { بَصِيرٌ * وَلَئِنْ قُتِلْتُمْ فِي سَبِيلِ ٱللَّهِ أَوْ مُتُّمْ }: في سبيله، { لَمَغْفِرَةٌ مِّنَ ٱللَّهِ وَرَحْمَةٌ خَيْرٌ مِّمَّا يَجْمَعُونَ }: مِنْ حُطَام الدُّنْيا.
