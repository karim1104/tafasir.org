{ قُلْ أَؤُنَبِّئُكُمْ بِخَيْرٍ مِّن ذٰلِكُمْ } المزين، { لِلَّذِينَ ٱتَّقَوْا }: المعاصي، { عِندَ رَبِّهِمْ جَنَّاتٌ تَجْرِي }: تحت أشجارها، { مِن تَحْتِهَا ٱلأَنْهَارُ خَالِدِينَ فِيهَا وَأَزْوَاجٌ مُّطَهَّرَةٌ }: من كل دنس، { وَرِضْوَانٌ مِّنَ ٱللَّهِ }: فلا يسخط عليهم أبدا، نبه على نعمة بأن أدناها متاع الدنيا، وأوسطها الجنة، وأعلاها رضوانه، { وَٱللَّهُ بَصِيرٌ بِٱلْعِبَادِ }: فيثيبهم بمقدار أعمالهم، هم، { ٱلَّذِينَ يَقُولُونَ رَبَّنَآ إِنَّنَآ آمَنَّا فَٱغْفِرْ لَنَا ذُنُوبَنَا وَقِنَا عَذَابَ ٱلنَّارِ * ٱلصَّابِرِينَ }: على مخالفة الهوى واتباع الشرع، { وَٱلصَّادِقِينَ }: قولا، { وَٱلْقَانِتِينَ }: الخاضعين المطيعين، { وَٱلْمُنْفِقِينَ }: في البر، { وَٱلْمُسْتَغْفِرِينَ بِٱلأَسْحَارِ }: وهي الثلث الأخير من الليل، وهو وقت الإجابة.
