{ وَلَمَّا بَرَزُواْ }: ظهروا، { لِجَالُوتَ وَجُنُودِهِ }: وكانوا تسعين ألفا أو أكثر، { قَالُواْ رَبَّنَآ أَفْرِغْ }: اصْبُبْ، { عَلَيْنَا صَبْراً وَثَبِّتْ أَقْدَامَنَا }: بتقوية قلوبنا، { وَٱنْصُرْنَا عَلَى ٱلْقَوْمِ ٱلْكَافِرِينَ * فَهَزَمُوهُمْ }: كسروهم، { بِإِذْنِ ٱللَّهِ }: بنصره، { وَقَتَلَ دَاوُدُ جَالُوتَ }: بثلاث أحجار في مخلاته قد تكلمت معه في الطريق: إنك تَقْتل جَالوت بنا، ووعده طالوت أنه إن قتل جالوت يزوج ابنته منه، ويشركه في ملكه فَوفّى وأَعْطَاه، { وَآتَاهُ ٱللَّهُ ٱلْمُلْكَ }: مُلْك بني اسْرَائيل، { وَٱلْحِكْمَةَ }: النبوة، { وَعَلَّمَهُ مِمَّا يَشَآءُ }: كَمنطق الطَّيْر والدواب والسرد، { وَلَوْلاَ دَفْعُ ٱللَّهِ ٱلنَّاسَ بَعْضَهُمْ بِبَعْضٍ }: كهذا الدفع، { لَفَسَدَتِ ٱلأَرْضُ }: بالكفار، فيه تنبيه على فضيلة الملك، { وَلَـٰكِنَّ ٱللَّهَ ذُو فَضْلٍ عَلَى ٱلْعَالَمِينَ * تِلْكَ }: الأحاديث، { آيَاتُ ٱللَّهِ نَتْلُوهَا عَلَيْكَ بِٱلْحَقِّ }: بالوجه المطابق، { وَإِنَّكَ }: يا محمد، { لَمِنَ ٱلْمُرْسَلِينَ }: لما أخبرت بها بلا تعرف.
