{ وَلاَ تَنْكِحُواْ ٱلْمُشْرِكَاتِ }: عبدة الأوثان، { حَتَّىٰ يُؤْمِنَّ } شملت الكتابيات، وخصَّت بقوله تعالى: [المائدة: 5] إلى آخره، { وَلأَمَةٌ مُّؤْمِنَةٌ خَيْرٌ مِّن مُّشْرِكَةٍ }: حُرَّة، { وَلَوْ أَعْجَبَتْكُمْ }: لمالها وجمالها، { وَلاَ تُنْكِحُواْ ٱلْمُشْرِكِينَ }: المؤمنات، { حَتَّىٰ يُؤْمِنُواْ وَلَعَبْدٌ مُّؤْمِنٌ خَيْرٌ مِّن مُّشْرِكٍ }: حُرٍّ، { وَلَوْ أَعْجَبَكُمْ أُوْلَـٰئِكَ }: المشركون، { يَدْعُونَ إِلَى }: موجبات، { ٱلنَّارِ وَٱللَّهُ يَدْعُوۤاْ إِلَى }: موجبات، { ٱلْجَنَّةِ وَٱلْمَغْفِرَةِ بِإِذْنِهِ }: بتيسيره، { وَيُبَيِّنُ آيَاتِهِ لِلنَّاسِ لَعَلَّهُمْ يَتَذَكَّرُونَ }: قبح المنهي عنه، وحسن المدعو إليه.
