{ وَلَوْ أَنَّهُمْ آمَنُواْ } بمحمد -صلى الله عليه وسلم- { وٱتَّقَوْا } بترك المعاصي، جوابه: لأثيبوا يَدُلُّ عليه: { لَمَثُوبَةٌ } لشيء من الثواب، { مِّنْ عِندِ ٱللَّهِ خَيْرٌ } لَهُمْ، هذا من قبيل: [الفرقان: 24]، أو خاطبهم على اعتقادهم، { لَّوْ كَانُواْ يَعْلَمُونَ * يَٰأَيُّهَا ٱلَّذِينَ آمَنُواْ لاَ تَقُولُواْ } لمحمد عليه الصَّلاةُ والسَّلامُ، { رَاعِنَا } راقبنا وتأن بنا لنفهم، لأن له معنى قبيحاً بُلغَةَ اليَهوْد يضحكون به فيما بينهم، أو لأن المفاعلة للمشاركة، { وَقُولُواْ ٱنْظُرْنَا } انظر إلينا، { وَٱسْمَعُواْ }: النصح قبولاً، { وَلِلكَافِرِينَ } السابين رسلنا، { عَذَابٌ أَلِيمٌ * مَّا يَوَدُّ ٱلَّذِينَ كَفَرُواْ مِنْ أَهْلِ ٱلْكِتَابِ وَلاَ ٱلْمُشْرِكِينَ أَن يُنَزَّلَ عَلَيْكُمْ مِّنْ خَيْرٍ مِّن رَّبِّكُمْ }: حَسَداً { وَٱللَّهُ يَخْتَصُّ بِرَحْمَتِهِ مَن يَشَآءُ وَٱللَّهُ ذُو ٱلْفَضْلِ ٱلْعَظِيمِ }: ولهُ مصالحُ في حرمان بعض.
