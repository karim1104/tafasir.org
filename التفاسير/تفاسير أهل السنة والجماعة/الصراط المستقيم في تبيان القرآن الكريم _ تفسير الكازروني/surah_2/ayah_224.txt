{ وَلاَ تَجْعَلُواْ ٱللَّهَ عُرْضَةً } مانعا وحاجزا، { لأَيْمَانِكُمْ }: أي: الأمور المحلوف عليها، { أَن تَبَرُّواْ }: بيان للإيمان، { وَتَتَّقُواْ وَتُصْلِحُواْ بَيْنَ ٱلنَّاسِ }: كحلف الصديق أن لا ينفق على مِسْطَحٍ لافترائه على عائشة -رضي الله عنها-، والآية نزلت فيه، { وَٱللَّهُ سَمِيعٌ }: لأيمانكم، { عَلِيمٌ }: بمقاصدكم.
