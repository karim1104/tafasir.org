{ وَإِذْ قُلْتُمْ } حِين [10 و] اختار موسى سبعين لأخذ التوراة، لا للاعتذار من عبادة العجل كما اشتهر { يَٰمُوسَىٰ لَن نُّؤْمِنَ } نصدق { لَكَ } بأن ما نسمع هو كلام الله { حَتَّىٰ نَرَى ٱللَّهَ جَهْرَةً } عياناً { فَأَخَذَتْكُمُ ٱلصَّٰعِقَةُ } النار أو الصيحة أو الموت { وَأَنْتُمْ تَنظُرُونَ } ما أصابكم.
