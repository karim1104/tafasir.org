{ إِن تُبْدُواْ }: تظهروا، { ٱلصَّدَقَاتِ فَنِعِمَّا هِيَ }: فنعم شيئا إبداؤها { وَإِن تُخْفُوهَا وَتُؤْتُوهَا ٱلْفُقَرَآءَ فَهُوَ }: فإخفاؤها { خَيْرٌ لَّكُمْ }: هذا في التطوع، لمن لم يعرف بالمال، وعن ابن عباس رضي الله تعالى عنهما: " السر في التطوع أفضل بسبعين ضِعْفاً والعلانية في الفريضة أفضل بخمس وعشرين " ، { وَيُكَفِّرُ عَنكُم مِّن }: بعض، { سَيِّئَاتِكُمْ }: أو شيئا هو سيئاتكم أو من صلة، { وَٱللَّهُ بِمَا تَعْمَلُونَ خَبِيرٌ * لَّيْسَ }: لا يجب { عَلَيْكَ هُدَاهُمْ }: جعلهم مهديين، ما عليك إلا الرشاد، { وَلَـٰكِنَّ ٱللَّهَ يَهْدِي مَن يَشَآءُ وَمَا تُنْفِقُواْ مِنْ خَيْرٍ فَلأَنْفُسِكُمْ }: ثوابه، { وَ } الحال أنه، { مَا تُنْفِقُونَ إِلاَّ ٱبْتِغَآءَ }: طلب رضا { وَجْهِ ٱللَّهِ }: ذاته، أي: ما تنفقون حينئذ فهو لكم، { وَمَا تُنْفِقُواْ مِنْ خَيْرٍ }: ولو على كافر، { يُوَفَّ إِلَيْكُمْ }: ثوابه، { وَأَنْتُمْ لاَ تُظْلَمُونَ }: بنقص ثوابه، وبعد نزوله كانوا يتصدقون على الكافر إيضاً، ولكن هذا في غير صدقة الفَرْض والصَّدقات أولى.
