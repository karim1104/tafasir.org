{ وَلِلْمُطَلَّقَاتِ مَتَاعٌ بِٱلْمَعْرُوفِ حَقّاً عَلَى ٱلْمُتَّقِينَ }: الشِّرْك، { كَذَلِكَ }: التبيين، { يُبَيِّنُ ٱللَّهُ لَكُمْ آيَاتِهِ لَعَلَّكُمْ تَعْقِلُونَ * أَلَمْ تَرَ }: استفهام تعجب وتقرير، أي: حمل على الإقرار بما بعده، { إِلَى ٱلَّذِينَ خَرَجُواْ مِن دِيَٰرِهِمْ }: أهل دَاوَرْدَان، { وَهُمْ أُلُوفٌ }: سبعون ألفا أو متألفون، { حَذَرَ ٱلْمَوْتِ }: الطاعون، { فَقَالَ لَهُمُ ٱللَّهُ }: في الطريق، { مُوتُواْ }: أي أماتهم دفعة، { ثُمَّ أَحْيَٰهُمْ }: بعد تفرق أوصالهم حين مر عليهم حزقيل: فقال: يأمر الله. قومواْ، فقاموا قائلين: سبحانك اللهم وبحمدك لا إله إلا أنت، { إِنَّ ٱللَّهَ لَذُو فَضْلٍ عَلَى ٱلنَّاسِ وَلَـٰكِنَّ أَكْثَرَ ٱلنَّاسِ لاَ يَشْكُرُونَ }: مشغولون عَمَّا خُلِقُوا له.
