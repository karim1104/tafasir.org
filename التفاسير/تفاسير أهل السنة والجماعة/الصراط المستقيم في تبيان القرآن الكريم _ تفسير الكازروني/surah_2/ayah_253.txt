{ تِلْكَ ٱلرُّسُلُ }: المعلومة لك، أو كلهم { فَضَّلْنَا بَعْضَهُمْ عَلَىٰ بَعْضٍ }: بمنقبة لا في الرسالة، { مِّنْهُمْ مَّن كَلَّمَ ٱللَّهُ }: مُوسى في الطور، ومحمدٌ في المعراج حين كان قاب قوسين أو أدنى، { وَرَفَعَ بَعْضَهُمْ دَرَجَاتٍ }: كمحمد المبعوث إلى الكافة عليهم الصلاة والسلام، { وَآتَيْنَا عِيسَى ٱبْنَ مَرْيَمَ }: المعجزات، { ٱلْبَيِّنَاتِ وَأَيَّدْنَاهُ بِرُوحِ ٱلْقُدُسِ }: كما مر، { وَلَوْ شَآءَ ٱللَّهُ مَا ٱقْتَتَلَ ٱلَّذِينَ مِن بَعْدِهِم }: الرسل، { مِّن بَعْدِ مَا جَآءَتْهُمُ ٱلْبَيِّنَاتُ وَلَـٰكِنِ ٱخْتَلَفُواْ فَمِنْهُمْ مَّنْ آمَنَ وَمِنْهُمْ مَّن كَفَرَ }: كفِرَق النَّصارى تحاربوا، { وَلَوْ شَآءَ ٱللَّهُ مَا ٱقْتَتَلُواْ }: كَرَّره تأكيداً، { وَلَـٰكِنَّ ٱللَّهَ يَفْعَلُ مَا يُرِيدُ }: يُوفق بعضاً ويخذلُ بعضاً.
