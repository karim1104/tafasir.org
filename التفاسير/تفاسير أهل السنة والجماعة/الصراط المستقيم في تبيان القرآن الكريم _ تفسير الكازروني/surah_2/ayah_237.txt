{ وَإِن طَلَّقْتُمُوهُنَّ مِن قَبْلِ أَن تَمَسُّوهُنَّ وَقَدْ فَرَضْتُمْ لَهُنَّ فَرِيضَةً فَنِصْفُ }: فلهنَّ نصفُ، { مَا فَرَضْتُمْ }: ولا متعة حينئذ، { إِلاَّ أَن يَعْفُونَ }: المطلقات، { أَوْ يَعْفُوَاْ ٱلَّذِي بِيَدِهِ عُقْدَةُ ٱلنِّكَاحِ }: أي: الزوج يعطيها كل المهر، سمى عفواً للمشاكلة أو من عفوت بمعنى وفّرْت، { وَأَن تَعْفُوۤاْ }: أيها الرجال، { أَقْرَبُ لِلتَّقْوَىٰ وَلاَ تَنسَوُاْ ٱلْفَضْلَ بَيْنَكُمْ }: أي: يتفضل بعضكم على بعض، { إِنَّ ٱللَّهَ بِمَا تَعْمَلُونَ بَصِيرٌ }: لا يضيع تفضلكم.
