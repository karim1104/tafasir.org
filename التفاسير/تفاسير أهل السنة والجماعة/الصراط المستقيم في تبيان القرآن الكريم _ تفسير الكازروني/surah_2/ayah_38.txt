{ قُلْنَا ٱهْبِطُواْ مِنْهَا جَمِيعاً } كَرَّرَهُ تأكيداً، أو الثاني إلى مقام التكليف إذ الهبوط يقال لنقصان المنزلة أيضاً، ودلّ عليه { فَإِمَّا } ما صلة، أي: إنْ { يَأْتِيَنَّكُم مِّنِّي هُدًى } نبى { فَمَن تَبِعَ هُدَايَ } أي: ما جاء به { فَلاَ خَوْفٌ عَلَيْهِمْ } أي: عند الفزع الأكبر { وَلاَ هُمْ يَحْزَنُونَ } على ما فاتهم من الدنيا، والخوف: غَمٌّ على متوقع، والحزن غم على واقع، وأما الخوف المثبت لهم ففي الدنيا.
