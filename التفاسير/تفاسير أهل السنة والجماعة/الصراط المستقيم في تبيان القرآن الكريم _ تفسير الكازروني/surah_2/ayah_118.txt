{ وَقَالَ ٱلَّذِينَ لاَ يَعْلَمُونَ }: المشركون أو اليهود، { لَوْلاَ }: هَلَّا، { يُكَلِّمُنَا ٱللَّهُ }: عياناً، { أَوْ تَأْتِينَآ آيَةٌ }: كتفجير الأنهار، لَا يُقَالُ: هَلَّا أجابهم ليؤمنوا، لأنه ليس للحكيم فِعْلُ ما يُنَافي مُقتضى حِكْمته بطلب جاهل أو شبهته، وقد أزاحها بغير ذلك، { كَذَلِكَ قَالَ }: الكُفَّار، { ٱلَّذِينَ مِن قَبْلِهِمْ مِّثْلَ قَوْلِهِمْ }: نحو: أرنا الله إلى آخره، { تَشَابَهَتْ قُلُوبُهُمْ } عِنَاداً، { قَدْ بَيَّنَّا ٱلآيَاتِ لِقَوْمٍ يُوقِنُونَ } يطلبون اليقين.
