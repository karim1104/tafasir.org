{ لاَّ جُنَاحَ }: أي: لا تبعة من مهر بدليل قوله بعد: [البقرة: 237]، { عَلَيْكُمْ إِن طَلَّقْتُمُ ٱلنِّسَآءَ مَا لَمْ تَمَسُّوهُنَّ }: تجامعوهن، { أَوْ }: إلا أن { تَفْرِضُواْ لَهُنَّ فَرِيضَةً }: مَهْراً إذ لومس، أو فرض لزم الكل أو النصف، والفَرْضُ: تَسميةُ المَهر، { وَمَتِّعُوهُنَّ }: حيث لا مس، ولا تسمية جبرا لإيحاش الطلاق، وتقدير المتعة إلى رأي الحاكم، كما يشعر به، { عَلَى ٱلْمُوسِعِ }: الغني، { قَدَرُهُ وَعَلَى ٱلْمُقْتِرِ } الفقير { قَدَرُهُ }: ما يليق به، { مَتَاعاً } ، تمتيعا، { بِٱلْمَعْرُوفِ }: شرعاً، حق ذلك، { حَقّاً }: وَاجباً، { عَلَى ٱلْمُحْسِنِينَ }: أي: عليكم، وسماهم به للمشارفة ترغيبا، وألحق الشافعيُّ المَمْسُوسْة المفروضة وغيرها بها في أحد قوليه قياسا، وهو مقدم على المفهوم.
