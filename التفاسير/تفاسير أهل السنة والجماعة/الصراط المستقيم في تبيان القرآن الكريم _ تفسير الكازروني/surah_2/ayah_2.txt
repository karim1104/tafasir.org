{ ذَلِكَ } هذا { ٱلْكِتَابُ } القرآن المكتوب، ويجوز اتحاد المشار إليه وبه، إذا لوحظ ضمناً مثل ذلك، وقد مر له معنى آخر أي: في بيان ربط السورتين منه { لاَ رَيْبَ } أي لا شك { فِيهِ } أي: في أنه من الله لو تأمل فيه عاقل { هُدًى } دلالة عظيمة إلى الحق { لِّلْمُتَّقِينَ } الصائرين إلى التقوى، وهي: فرط الصيانة، وشرعاً: وقاية النفس عما يضرها في الأخرةِ. ومراتبها ثلاث: التوقي عن العذاب المخلد، ثُمَّ عَنْ كُلِّ مأثم ثم عما يشغل السر عن الحق. ومن الأولى: [الفتح 26]، وَمن الثانية: [الأعراف: 96]، الآية ومن الثالثة: [ال عمران: 102]. وخصهم لأنهم المنتفعون به، بل غيرهم يَضلُّ به كغذاء صالح يزيد صحة الصحيح وسُقْم السقيم، كما أفادتْهُ آية: [الاسراء: 82].
