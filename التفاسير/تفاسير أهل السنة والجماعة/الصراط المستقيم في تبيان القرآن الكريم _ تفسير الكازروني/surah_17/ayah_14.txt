{ وَجَعَلْنَا ٱلَّيلَ وَٱلنَّهَارَ آيَتَيْنِ }: تدُلاَّن على قدرتنا { فَمَحَوْنَآ آيَةَ ٱلَّيلِ }: هو المحو الذي على القمر أو انتقاص نوره إلى المحاق { وَجَعَلْنَآ آيَةَ ٱلنَّهَارِ مُبْصِرَةً }: مضيئة أو بينة، { لِتَبْتَغُواْ }: فيه، { فَضْلاً }: أسباب مَعَاشكم، { مِّن رَّبِّكُمْ وَلِتَعْلَمُواْ } بهما، أو بآية الليل، { عَدَدَ ٱلسِّنِينَ وَٱلْحِسَابَ }: ولا تكرار إذ العَددُ موضوع الحساب، { وَكُلَّ شَيْءٍ }: تحتاجون إليه، { فَصَّلْنَاهُ }: بيناه بلا التباس { تَفْصِيلاً * وَكُلَّ إِنْسَانٍ أَلْزَمْنَاهُ طَآئِرَهُ }: عمله، أو ما قُدِّر له { فِي عُنُقِهِ }: كلزوم الطوق لا ينفك عنه، { وَنُخْرِجُ لَهُ يَوْمَ ٱلْقِيَامَةِ كِتَاباً يَلْقَاهُ مَنْشُوراً } يقال له: { ٱقْرَأْ كِتَٰبَكَ كَفَىٰ بِنَفْسِكَ } ذكر بتأويله شَخْصك { ٱلْيَوْمَ عَلَيْكَ حَسِيباً } ، مُحاسباً، وهذا في غير موقف يحاسبهم بنفسه، حيث قال: [الأنبياء: 47] { مَّنِ ٱهْتَدَىٰ فَإِنَّمَا يَهْتَدي لِنَفْسِهِ وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا }: نفعه، وضره لا يتعديانه، { وَلاَ تَزِرُ } تحمل نفس { وَازِرَةٌ }: حاملة، { وِزْرَ }: نفس، { أُخْرَىٰ }: بُيِّنَ في الأنعام، { وَمَا كُنَّا مُعَذِّبِينَ حَتَّىٰ نَبْعَثَ رَسُولاً }: فلا يؤمن به، فمن نشأ حيثُ لم يسمع برسول فمعذور { وَإِذَآ أَرَدْنَآ أَن نُّهْلِكَ قَرْيَةً أَمَرْنَا }: أَمْراً قَدَريًّا، { مُتْرَفِيهَا }: مُنعِّميها بالفسق أو كثرناهم، أو جعلناهم أُمَراء، أو أمرناهم بالطاعة، فلا ينافي إنّ الله لا يأمر بالفحشاء وتخصيصهم على الأول، لأنهم أسرع إلى الحماقة والفجور وغيرهم يتبعهم { فَفَسَقُواْ فِيهَا فَحَقَّ عَلَيْهَا ٱلْقَوْلُ }: كلمة العذابِ { فَدَمَّرْنَاهَا }: استأصلناها، { تَدْمِيراً }: ومضى حكم الساكتين عن نهيهم في قوله: .. [الأنفال: 25]: الخ، { وَكَمْ }: كثيرا، { أَهْلَكْنَا مِنَ ٱلْقُرُونِ مِن بَعْدِ نُوحٍ }: هو أوَّلُ من كذبوه، { وَكَفَىٰ بِرَبِّكَ بِذُنُوبِ عِبَادِهِ خَبِيرَاً }: ببواطنها، { بَصِيراً }: بظواهرها، { مَّن كَانَ يُرِيدُ }: بطاعته، { ٱلْعَاجِلَةَ }: الدنيا فقط كالمنافقين، فلا يفهم أن من لم يزهد فيها يكون من أهل النار، { عَجَّلْنَا لَهُ فِيهَا مَا نَشَآءُ لِمَن نُّرِيدُ }: تعجيله له، { ثُمَّ جَعَلْنَا لَهُ جَهَنَّمَ يَصْلاهَا مَذْمُوماً } ، { مَّدْحُوراً }: مطروداً.
