627: 2: 37- سفين عن مجاهد { وَمَا جَعَلْنَاهُمْ جَسَداً } قال، ليس فيهم الروج { وَلاَ هُمْ مِّنَّا يُصْحَبُونَ } قال، يمنعون. [الآية 8 والآية 43].  637: 12: 33- سفين (في) قوله { لاَ يَسْتَطِيعُونَ نَصْرَ أَنْفُسِهِمْ وَلاَ هُمْ مِّنَّا يُصْحَبُونَ } قال، ينصرون. وقال، كان أصحاب عبد الله يقرءونها { يصحبون }. [الآية 43].
