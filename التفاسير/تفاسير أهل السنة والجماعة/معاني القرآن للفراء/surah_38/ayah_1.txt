قوله :  {  ص وَالْقُرْآنِ } جَزَمَها القراء ،  إلاّ الحَسَن فإنه خفضَها بلاَ نون لاجتماع السَّاكنين .  كانت بمنزلة مَنْ قرأ {  نُونَ والقلم } و {  ياسينَ والقرآنِ الحَكيم } جُعلت بمنزلة الأداة كقولِ العرب :  تركته ( حاثِ باث ) و ( خَازِ بازِ ) يُخفضان ؛  لأن الذي يلي آخر الحرف ألِف .  فالخفض مع الألف ،  والنصبُ مع غير الألِف .  يقولون :  تركته حَيْثَ بَيْثَ ،  ولأجعلنّك حَيْصَ بَيْصَ إذا ضُيّق عَلَيْهِ . <br />
وقال الشاعر : <br />
                                   لم يَلتحِصني حَيْصَ بَيْصَ الحاصي *** .  .  . <br />
يريد الحائص فقلبَ كَما قَالَ :  ( عاقِ ) يريد :  عائق . <br />
و ص في معناها كقولكَ :  وجبَ والله ،  ونزل والله ،  وحقّ والله .  فهي جواب لقوله {  والقرآن } كَما تقول :  نزلَ والله .  وقد زعم قوم أنّ جَوَاب {  والقرآن } {  إنَّ ذَلِكَ لَحَقٌّ تخاصُمُ أَهْلِ النارِ } وذلك كلام قد تأخّر تأخُّراً كثيراً عن قوله {  والقرآن } جرت بينهما قِصص مختلِفة ،  فلا نَجد ذلكَ مُستقيما في العربيَّة والله أعلم . <br />
ويقال :  إن قوله {  وَالقرآنِ } يمين اعترض كلام دون مَوقع جوابها ،  فصَار جوابها جواباً للمعترِض ولها ،  فكأنه أراد :  والقرآن ذي الذكر لكَمْ أهلكنا ،  فلما اعترض قوله :  {  بل الذين كَفَرُوا في عِزَّة وشقاق } :  صارت ( كم ) جَوَاباً للعزَّة ولليمين .  ومثله قوله {  والشَمسِ وضُحاها } اعْترض دون الجواب قولُه {  ونَفْسٍ وما سَوَّاها فألْهَمها } فصَارت {  قد أفلح } تابعةً لقوله {  فألهمها } وكفي من جَواب القسم ،  وكأنه كان :  والشمس وضحاها لقد أفلح . <br />
