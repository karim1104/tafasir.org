وقوله :  {  وَإِنِّي مُرْسِلَةٌ إِلَيْهِمْ بِهَدِيَّةٍ فَناظِرَةٌ بِمَ يَرْجِعُ الْمُرْسَلُونَ35 }<br />
نقصت الألف من قوله ( بم ) لأنها في معنى بأي شيء يرجع المرسلون وإذا كانت ( ما ) في موضع ( أي ) ثم وصلت بحرفٍ خافضٍ نُقصت الألف من ( ما ) ليعرف الاستفهام من الخبر .  ومن ذلك قوله :  {  فِيمَ كُنْتم } و {  عَمَّ يتساءلُونَ } وإن أتممتها فصواب .  وأنشدني المفضّل : <br />
إنا قتلنا بقتلانا سَرَاتكم *** أهلَ اللوَاء ففيما يكثر القِيلُ<br />
وأنشدني المفضَّل أيضاً : <br />
على ما قام يشتمنا لَئِيمٌ *** كخنزير تمرَّغ في رمادِ<br />
وقوله :  {  إِلَيْهِمْ بِهَدِيَّةٍ } وهي تعنى سليمان كقوله {  على خَوْفٍ مِنْ فِرْعَوْنَ وَمَلَئِهمْ } وَقَالَتْ {  بِمَ يَرْجِعُ المُرْسَلُونَ } وكان رسولها - فيما ذكروا - امرأةً واحدةٍ فجمعَتْ وإنما هو رسول ،  لذلكَ قالَ {  فلما جَاء سُلَيْمانَ } يريد :  فلما جاء الرسولُ سليمانَ ،  وهي في قراءة عبد الله ( فلما جَاءوا سليمان ) لما قال {  المرسَلونَ } صَلح {  جَاءوا } وصلح {  جاء } لأن المرسَل كان واحداً .  يدلّ على ذلكَ قول سليمان {  ارْجِعْ إليْهِمْ } .
