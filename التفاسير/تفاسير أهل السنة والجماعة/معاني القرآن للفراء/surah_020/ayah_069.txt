وقوله :  {  إِنَّما صَنَعُواْ كَيْدُ سَاحِرٍ69 } جَعلت ( ما ) في مذهب الذي :  إن الذي صَنَعُوا كيد سحر ،  وقد قرَأه بعضهم {  كَيدُ سَاحِرٍ } وكلّ صوابٌ ،  ولو نصبت {  كَيْدَ سحر } كانَ صواباً ،  وجعلت ( إنما ) حرفاً واحداً ؛  كقوله {  إنَّما تَعْبُدُونَ مِنْ دُونِ اللّهِ أَوْثَانا } . <br />
وقوله :  {  وَلاَ يُفْلِحُ السَّاحِرُ حَيْثُ أَتَى } جاء في التفسير أنه يُقتل حيثما وُجدَ .
