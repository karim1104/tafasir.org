وقوله :  {  ما أُخْفِيَ 17 } وكلّ ينصب بالياء ؛  لأنه فعل ماض ؛  كما تقول :  أُهلِك الظالمون .  وقرأها حمزة ( ما أُخْفِيَ لَهُم مِّن قُرَّةِ أَعْيُنٍ ) بإرسال الياء .  وفي قراءة عبد الله ( ما نُخْفِيَ لَهُم مِّن قُرَّةِ أَعْيُنٍ } فهذا اعتبار وقوَّة لحمزة .  وكلٌّ صواب .  وإذا قلت {  أُخْفِيَ لَهُم } وجعلت ( ما ) في مذهب ( أي ) كانت ( ما ) رفعاً بما لم تُسَمّ فاعلَه .  ومن قرأ {  أُخْفِيَ لَهُم } بإرسال الياء وجعَل ( ما ) في مذهب ( أي ) كانت نصباً في {  أُخْفي } و {  نُخْفي } ومَن جعلها بمنزلة الشيء أوقع عليها ( تَعْلَمُ ) فكانت نَصْباً في كلّ الوجوه .  وقد قرئت ( قُرَّاتِ أعْيُن ) ذُكرت عن أبى هريرة .
