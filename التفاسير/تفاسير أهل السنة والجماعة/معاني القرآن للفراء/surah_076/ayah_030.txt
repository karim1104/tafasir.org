وقوله عز وجل :  {  وَما تَشَاءونَ } . <br />
جواب لقوله :  {  فَمَنْ شَاء اتّخذَ إلَى رَبِّهِ سَبِيلاً } . <br />
ثم أخبرهم أن الأمر ليس إليهم ،  فقال :  {  وَما تَشَاءونَ } ذلك السبيل {  إِلاَّ أَن يَشَاء اللَّهُ } لكم ،  وفي قراءة عبد الله {  وَما تَشَاءونَ إِلاَّ أَن يَشَاء اللَّهُ } والمعنى في ( ما ) و ( أن ) متقارب . <br />
