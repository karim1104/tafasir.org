وقوله :  {  خُلُقُ الأَوَّلِينَ137 } وقراءة الكسائي ( خَلْق الأوَّلِينَ ) قال الفراء :  وقراءتي ( خَلَق الأولينَ ) فمن قرأ ( خَلْق ) يقول :  اختلاقهم وكذبهم ومن قرأ {  خَلُق الأولينَ } يقول :  عادة الأولين أي وراثة أبيك عن أول .  والعرب تقول :  حَدِّثنا بأحاديث الخَلْق وهي الخرافات المفتعلة وأشباهها فلذلك اخترت الخُلُق .
