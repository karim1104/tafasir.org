وقوله :  {  وَاضْمُمْ إِلَيْكَ جَناحَكَ مِنَ الرُّهْبِ32 } و{  الرَّهَبِ } قرأها أهل المدينة {  الرّهَب } وَعَاصم والأعمش ( الرُّهْبِ ) . <br />
وقوله :  {  فَذَانِكَ بُرْهانانِ 32 } اجتمع القراء على تخفيف النون من {  ذَانِكَ } وكثير من العرب يقول {  فذانّك } و {  وهذانّ } قائمان {  واللذانِّ يأْتِيانها مِنْكُمْ } فيشدِّدون النون . <br />
وقوله :  {  وَاضْمُمْ إِلَيْكَ جَناحَكَ } يريد عَصَاه في هذا الموضع .  والجَناح في الموضع الآخر :  ما بين أسْفل العَضد إلى الرُّفْغ وهو الإبْط .
