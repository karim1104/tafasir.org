وقوله :  {  وَلاَ يُلَقَّاها إِلاَّ الصَّابِرُونَ80 } يقول :  ولا يُلَقَّى أن يقول ثواب الله خير لمن آمن وعمل صَالحا إلاّ الصابرونَ .  ولو كانت :  ولا يُلَقّاهُ لكان صَوباً ؛  لأنه كلام والكلام يُذهب به إِلى التأنيث والتذكير .  وفي قراءة عبد الله ( بَلْ هي آيات بيِّنات ) وفي قراءتنا {  بَلْ هُوَ آياتٌ } فمن قال ( هي ) ذهبَ إلى الآيات ،  ومَنْ قال ( هو ) ذهَبَ إلى القرآن .  وكذلك {  تِلْكَ مِنْ أَنْبَاء الغَيْبِ } و {  ذَلِكَ مِنْ أَنْبَاء الغَيْبِ } ومثله في الكلام :  قد غمَّني ذاك وغمَّتني تلك منكَ .
