وقوله :  {  نُودِيَ أَن بُورِكَ مَن فِي النارِ8 } تجعل ( أَنْ ) في موضع نصب إذا أَضمرتَ اسم موسى في {  نُودي } وإن لم تُضمر اسم موسى كانت ( أن ) في موضع رفع :  نودىَ ذلكَ وفي حرف أُبَيّ :  ( أَنْ بُورِكتِ النارُ ) {  وَمَنْ حَوْلَها } يعنى الملائكة .  والعرب تقول :  باركك الله وبارك فيك وبَارك عَليْك .
