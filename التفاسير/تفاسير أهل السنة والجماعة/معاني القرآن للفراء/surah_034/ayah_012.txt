وقوله :  {  وَلِسُلَيْمانَ الرِّيحَ12 } منصوبة على :  وسخّرنا لسليمان الريح .  وهي منصوبة في الأنبياء {  وَلِسُلَيْمانَ الرِّيحَ عاصِفَةً } أضمر :  وسَخَّرنا - والله أعلم - وقد رَفَع عاصم - فيما أعلم - ( وَلِسُلَيْمانَ الرِّيحُ ) لما لم يظهر التسْخير أنشدني بعض العرب : <br />
ورأيتُم لمُجَاشعٍ نَعَما *** وبنى أبيه جَامِلٌ رُغُب<br />
يريد :  ورأيتم لبنى أبيه ،  فلما لم يظهر الفعل رُفع باللام . <br />
وقوله :  {  غُدُوُّها شَهْرٌ وَرَوَاحُها شَهْرٌ } يقول :  غدوّها إلى انتصاف النهار مسيرة شهر ورَوحتها كذلك . <br />
وقوله :  {  وَأَسَلْنا لَهُ عَيْنَ الْقِطْرِ } مِثْل {  وألَنّا لَهُ الحَدِيدَ } والقِطْر :  النحاس .
