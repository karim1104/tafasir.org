وقوله :  {  أَمَرْنا مُتْرَفِيها16 }<br />
قرأ الأعْمَش 99 ا وعاصم ورجال من أهل المدينة {  أَمَرْنا } خفيفة حدَّثنا محمد قال حدَّثنا الفراء قال حدّثني سفيان بن عُيَينة عن حُمَيد الأعرج عن مجاهد {  أمَرْنا } خفيفة .  وفسّر بعضهم {  أَمَرْنا مُتْرَفِيها } بالطاعة {  فَفَسَقُوا } أي إن المترف إذا أُمِر بالطاعة خالف إلى الفسوق .  وقى قراءة أُبَىّ بن كعب ( بعثنا فيها أكابر مجرميها ) وقرأ الحسن {  آمَرنا } وروى عنه {  أَمِرْنا } ولا ندرى أنها حُفِظت عنه لأنا لا نعرف معناها ها هنا .  ومعنى ( آمرنا ) بالمدّ :  أكثرنا .  وقرأ أبو العالية الرياحي ( أمَّرنا مُتْرَفيها ) وهو موافق لتفسير ابن عباس ،  وذلك أنه قال :  سلَّطنا رؤساءها فَفَسَقوا فيها .
