وقوله :  {  كَانَ يَئُوساً83 } إذا تركت الهمزة من قوله {  يؤوساً } فإِن العرب تقول يَوْساً ويَوْوْساً تجمعون بين ساكنين وكذلك {  وَلاَ يَؤودُهُ حِفْظُهُما } وكذلك {  بِعَذَابٍ بَئِيسٍ } يقول بَيْسِ و ( بَيْيْسٍ ) و ( ويؤوده ) يجمعون ساكنين .  فهذا كلام العرب :  والقراء يقولون ( يَوُوساً ) و ( يَوُوده ) فيحرّكون الواو إلى الرفع و( بَيِيْسٍ ) يحرّكون الياء الأولى إلى الخفض .  ولم نجد ذلك في كلامهم ،  لأن تحرك الياء والواو أَثقل من ترك الهمزة ،  فلم يكونوا ليَخْرجوا من ثِقَل إلى ما هو أَثقَل منه .
