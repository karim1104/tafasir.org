وقوله :  {  وَالَّذِينَ يَبْتَغُونَ الْكِتَابَ 33 } يعنى المكاتبة .  و ( الذينَ ) في موضع رفع كما قال {  وَالَّلذانِ يأتِيانِها مِنْكُمْ فآذُوهُما } والنصب جائز .  وقوله {  إِنْ عَلِمْتُمْ فِيهِمْ خَيْراً } يقول إذا رجوتم عندهم وفاء وتأدية للمكاتبة {  وَآتُوهُمْ مِّن مالِ اللَّهِ الَّذِي آتَاكُمْ } حثَّ الناسَ على إعطاء المكاتبين .  حدثنا أبو العباس قال حدثنا محمد قال حدثنا الفراء قال حدثنا حِبّان عن الكلبي عن أبى صالح عن علي بن أبى طالب قال :  يعطيه ثُلث مكاتبته .  يعنى المولى يهب له ثلث مكاتبته . <br />
وقوله {  وَلاَ تُكْرِهُواْ فَتَيَاتِكُمْ على الْبِغَاء } البِغاء :  الزنى .  كان أهل الجاهلية يُكرهون الإماء ويلتمسونَ منهنَّ الغَلَّة فيفجرن ،  فنُهي أهل الإسْلام عن ذلكَ {  وَمَن يُكْرِههُنَّ فَإِنَّ اللَّهَ مِن بَعْدِ إِكْرَاهِهِنَّ } لهنَّ {  غَفُورٌ رَّحِيمٌ } .
