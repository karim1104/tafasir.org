وقوله :  {  اسْتِكْبَاراً فِي الأَرْضِ43 }<br />
أي فعَلو ذلك استكباراً {  وَمَكْرَ السَّيِّء } أُضيف المكر إلى السَّيء وهو هو كما قال :  {  إنَّ هَذَا لَهُوَ حَقُّ اليَقينِ } وتصديق ذلك في قراءة عبد الله ( ومَكْراً سَيِّئا ) وقوله {  وَمَكْرَ السَّيِّءِ } الهمز في {  السَّيء } مخفوضة / 155 ب وقد جزمها الأعمش وحمزة لكثرة الحركات ،  كما قال {  لاَ يَحْزُنُهُمُ الفَزَعُ الأَكْبَرُ } وكما قال الشاعر : <br />
إذا اعْوَجَجْنَ قُلْتُ صَاحِبْ قَوِّمِ *** .  .  . <br />
يريد صَاحِب قَوِّم فجزم الباء لكثرة الحركات .  قال الفراء :  حدثني الرؤاسي عن أبى عمرو ابن العلاء {  لاَ يَحْزُنْهُمْ } جَزْم .
