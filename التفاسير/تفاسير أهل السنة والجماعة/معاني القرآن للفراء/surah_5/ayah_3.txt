{  وَالْمُنْخَنِقَةُ } :  ما اختنقت فماتت ولم تُدرَك . <br />
{  وَالْمَوْقُوذَةُ } :  المضروبة حتى تموت ولم تُذَكَّ . <br />
{  وَالْمُتَرَدِّيَةُ } :  ما تردّى من فوق جبل أو بئر ،  فلم تدرَكْ ذكاتُه . <br />
{  وَالنَّطِيحَةُ } :  ما نُطِحت حتى الموت .  كل ذلك محرّم إذا لم تُدرك ذكاته . <br />
وقوله :  {  إِلاَّ ما ذَكَّيْتُمْ } نصب ورفع . <br />
{  وَما ذُبِحَ على النُّصُبِ } :  ذبح للأوثان .  و( ما ذبح ) في موضع رفع لا غير . <br />
{  وَأَنْ تَسْتَقْسِمُواْ } رَفْع بما لم يسمَّ فاعله .  والاستقسام :  أنّ سهاما كانت تكون في الكعبة ،  في بعضها :  أمرني ربي ،  ( وفي موضعها :  نهاني ربي ) فكان أحدهم إذا أراد سفرا أخرج سهمين فأجالهما ،  فإن خرج الذي فيه ( أمرني ربي ) خرج .  وإن خرج الذي فيه ( نهاني ربي ) قعد وأمسك عن الخروج . <br />
قال الله تبارك وتعالى :  {  ذلكمْ فِسْقٌ الْيَوْمَ } والكلام منقطع عند الفسق ،  و {  الْيَوْمَ } منصوب ب ( يئِس ) لا بالفسق . <br />
{  اليومَ أُحِلَّ لَكُمُ الطّيِّباتُ } نصب ( اليوم ) ب ( أُحِلّ ) . <br />
وقوله :  {  غَيْرَ مُتَجَانِفٍ لإِثْمٍ } مثل قوله {  غير محلّى الصيد } يقول :  غير معتمد لإثم .  نصبت ( غير ) لأنها حال ل ( مَنْ ) ،  وهي خارجة من الاسم الذي في ( اضطرّ ) . <br />
