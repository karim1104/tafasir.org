وقوله :  {  طَائرُكُم مَّعَكُمْ 19 } القراء مجتمعون على ( طائركم ) بالألف .  والعرب تقول :  طيركم معكم . <br />
وقوله :  {  أئن ذُكِّرْتُم } قراءة العَامَّة بالهمز وكسر أَلف ( إنْ ) . <br />
وقرأ أبو رَزِين - وكان من أصْحاب عبد الله - {  أََأَنْ ذُكِّرتم } ومَن كسر قال {  أئن } جَعَله جزاء أُدخِل عليه ألف استفهام .  وقد ذُكر عن بعض القرّاء ( طائركم معكم أين ذُكِّرْتم ) و {  ذُكِرتم } يريد :  طائركم معكم حيثما كنتم .  والطائر ها هنا :  الأعمال والرزق .  يقول :  هو في أعناقكم .  ومن جَعَلها {  أَين } فينبغي له أن يخفّف {  ذكرتم } وقد خَفّف أبو جَعفر المدنيّ {  ذُكرتم } ولا أحفظ عنه ( أين ) .
