وقوله :  {  فَكَسَوْنا الْعِظَامَ لَحْما 14 } و( العَظْمَ ) وهي في قراءة عبد الله {  ثم جَعَلنا النطفة عظما وعَصَباً فكسوناه لحما } فهذه حُجّة لمنْ قال :  عَظْما وقد قرأها بعضهم ( عظما ) . <br />
وقوله :  {  ثُمَّ أَنشَأْناهُ خَلْقاً آخَرَ } يذهب إلى الإنسان وإن شئت :  إلى العظم والنطفة والعصب ،  تَجْعله كالشيء الواحد .
