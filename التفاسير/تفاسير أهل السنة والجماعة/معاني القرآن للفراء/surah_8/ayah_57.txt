وقوله :  {  فَإِما تَثْقَفَنَّهُمْ فِي الْحَرْبِ فَشَرِّدْ بِهِم مَّنْ خَلْفَهُمْ }<br />
يريد :  إن أسَرتهم يا محمد فنكّل بهم مَن خلفهم ممن تخاف نقضه للعهد {  فَشرِّدْ بِهِمْ } .  {  لَعَلَّهُمْ يَذَّكَّرُونَ } فلا ينقضون العهد .  وربما قرئت ( مِن خَلْفِهِم ) بكسر ( مِن ) ،  وليس لها معنى أستحبّه مع التفسير . <br />
