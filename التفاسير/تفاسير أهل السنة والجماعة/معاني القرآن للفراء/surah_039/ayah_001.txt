وقوله :  {  تَنزِيلُ الْكِتَابِ1 } ترفع {  تنزيل } بإضمار :  هذا تنزيل ،  كما قال :  {  سُورَةٌ أَنْزلْناها } ومعناه :  هذه سورة أنزلناها وإِن شئتَ جَعَلت رَفعه بمِن .  والمعنى :  من الله تنزيل الكتاب ولو نصبته وأنت تأمر باتباعه ولزومه كان صَوَاباً ؛  كما قالَ الله {  كِتَابَ اللهِ عَلَيْكُمْ } أي الزمُوا كتابَ الله .
