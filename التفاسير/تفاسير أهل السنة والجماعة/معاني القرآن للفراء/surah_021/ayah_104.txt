وقوله :  {  يَوْمَ نَطْوِي السَّماء104 } بالنون والتاء ( تُطْوَى ) ولو قيل ( يَطْوِي ) كما قيل ( نطوى ) بالنون جَاز . <br />
واجتمعت القراء على ( السّجِلّ ) بالتثقيل . <br />
وأَكثرهم يقول ( للكِتَابِ ) وأصْحاب عَبد الله ( للكُتُب ) والسّجِلّ :  الصَّحِيفة .  فانقطع الكلام عند الكتب ،  ثم اسْتأنف فقال {  كَما بَدَأْنا أَوَّلَ خَلْقٍ نُّعِيدُهُ } فالكاف للخَلْق كأنك قلت :  نعيد الخلق كما بدأناهم ( أَوّل مَرّة ) . <br />
وقوله {  وَعْداً عَلَيْنا } كقولك حَقّاً علينا .
