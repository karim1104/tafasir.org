وقوله :  {  أَنَّ السَّماوَاتِ وَالأَرْضَ كَانَتَا رَتْقاً فَفَتَقْناهُما30 }<br />
فُتِقت السَماء بالقَطْر والأرضُ بالنبت ( وقال ) ( كَانَتَا رَتْقاً ) ولم يقل :  رَتْقِين ( وهو ) كما قَالَ {  مهما جَعَلناهم جَسَداً } . <br />
وقوله :  {  وَجَعَلْنا مِنَ الماء كُلَّ شَيْءٍ حَيٍّ } خَفْض ولو كانت :  حيّا كان صَوَابَا أي جعلنا كلَّ شيء حيّاً من الماء .
