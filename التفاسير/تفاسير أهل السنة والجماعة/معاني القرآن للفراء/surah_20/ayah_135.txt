وقوله :  {  فَسَتَعْلَمُونَ مَنْ أَصْحابُ الصِّرَاطِ السَّوِيِّ وَمَنِ اهْتَدَى 135 }<br />
مَن ومَن في موضع رفع .  وكلّ ما كانَ في القرآن مثَله فهو مرفوع إذا كان بعده رافع .  مثل قوله {  فَسَتَعْلَمُونَ مَنْ هُوَ في ضلالٍ مُبِينٍ } ومثله {  لنَعْلمَ أي الحِزْبَيْنِ أحْصَى } ومثله {  أعْلَمُ مَنْ جَاء بِالهُدَى وَمَنْ هُوَ في ضَلاَلٍ مُبِين } ولو نصبَ كان صَواباً ،  يكون بمنزلة قول الله {  اللّهُ يَعْلَمُ المُفْسِدَ مِنَ المُصْلِحِ } . <br />
وقوله :  {  فَسَتَعْلَمُونَ مَنْ أَصْحابُ الصِّرَاطِ السَّوِيِّ } الذين لم يَضِلُّوا {  وَمَنِ اهْتَدَى } ممَّن كان ضَالاً فَهَدَى .
