وقوله :  {  هَذَا فَوْجٌ مُّقْتَحِمٌ مَّعَكُمْ  } هي الأُمَّة تدخل بعد الأُمَّة النار .  ثم قَالَ :  {  لاَ مَرْحَباً بِهِمْ } الكلام متَّصل ،  كأنه قول واحِدٍ ،  وإنما قوله :  {  لاَ مَرْحَباً بِهِمْ } من قول أهل النار ،  وهو كقوله :  {  كُلَّما دَخَلَتْ أُمَّةٌ لعَنَتْ أُخْتَها } وهو في اتّصاله .  كقوله :  {  يُرِيدُ أَنْ يُخْرِجَكُمْ مِنْ أَرْضِكُم بسحره فماذَا تَأْمُرُونَ } فاتصل قول فرعون بقولِ أصحابه . <br />
