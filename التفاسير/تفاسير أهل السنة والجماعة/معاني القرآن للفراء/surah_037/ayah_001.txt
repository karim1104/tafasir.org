ومن سورة الصافات :  بسم الله الرحمن الرحيم<br />
وقوله : {  وَالصَّافَّاتِ1 }<br />
تخفض التاء من {  الصافات } ومن {  التالياتِ } لأنه قَسَمٌ .  وَكَانَ ابن مسعودٍ يُدغم {  وَالصَّافَّاتِ صَفَّا }/158 ا وكذلك {  والتاليات } {  والزاجرات } يدغم التاء منهن والتبيان أجود ؛  لأن القراءة بنيت على التفصيل والبيان . <br />
وهذه الأحرف - فيما ذكروا - الملائكة .
