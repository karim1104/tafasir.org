وقوله :  {  رَبَّنا بَاعِدْ بَيْنَ أَسْفَارِنا19 }<br />
قراءة العوامّ .  وتقرأ على الخبر {  رَبُّنا بَعّدَ بَيْنَ أَسْفَارِنا } وَ {  بَاعَدَ } وتقرأ على الدعاء {  رَبَّنا بَعِّدْ } وتقرأ {  رَبَّنا بَعُدَ بَيْن أسفارِنا } تكون ( بَيْنَ ) في موضع رَفعٍ وهي منصوبة .  فمن رفعها جعلها بمنزلة قوله {  لقد تقَطَّعَ بَيْنَكُمْ }
