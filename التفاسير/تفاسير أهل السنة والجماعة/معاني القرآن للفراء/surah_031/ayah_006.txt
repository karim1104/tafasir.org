وقوله :  {  وَمِنَ الناسِ مَن يَشْتَرِي لَهْوَ الْحَدِيثِ6 } نزلت في النَضْر بن الحارث الداريّ .  وكان يشترى كتب الأعاجم فارسَ والروم وكتب أهل الحِيرة ( ويحدّث ) بها أهل مكة ؛  وإذا سمع القرآن أعرض عنه واستهزأ به .  فذلكَ قوله {  وَيَتَّخِذَها هُزُواً } وقد اختلف القراء في {  وَيَتَّخِذَها } فرفع أكثرهم ،  ونصبها يحيى بن وَثَّاب والأعمش وأصحابُه .  فمن رفع ردّها على {  يَشْتَرِي } ومن نصبها ردّها على قوله {  لِيُضِلَّ عَن سَبِيلِ اللَّهِ } :  وليتَّخذها . <br />
وقوله {  وَيَتَّخِذَها } يذهب إلى آيات القرآن .  وإن شئت جعلتها للسبيل ؛  لأن السَّبيل قد تُؤنَّث قال {  قُلْ هذِهِ سَبِيلِي أَدعُو إِلَي اللهِ } وفي قراءة أُبَيّ ( وإنْ يَرَوْا سَبِيلَ الرُشْدِ لاَ يَتّخذُوها سَبِيلاً وَإنْ يَرَوْا سَبِيلَ الغَيّ يَتّخِذُوها سَبِيلاً } . <br />
حدَّثنا أبو العبَّاس قال حدَّثنا محمد قال حدَّثنا الفراء قال حَدَّثني حِبَّان عن ليث عن مجاهد في قوله {  وَمِنَ الناسِ مَن يَشْتَرِي لَهْوَ الْحَدِيثِ } قال :  هو الغِناء قال الفراء :  والأوّل تفسيره عن ابن عباس .
