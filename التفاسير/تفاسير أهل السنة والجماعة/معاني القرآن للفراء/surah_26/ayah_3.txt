قوله :  {  بَاخِعٌ نَّفْسَكَ3 } قاتل نفسكَ {  أَلاَّ يَكُونُواْ مُؤْمِنِينَ } موضع ( أن ) نصب لأنها جزاء ،  كأنك قلت :  إن لم يؤمنوا فأنتَ قاتل نفسك .  فلما كان ماضِياً نصبتَ ( أن ) كما تقول أتيتك أَنْ أتيتني .  ولو لم يكن ماضياً لقلت :  آتيكَ إلى تَأتنِي .  ولو كانت مجزومةً وكسرْتَ ( إن ) فيها كَانَ صواباً .  ومثله قول الله {  وَلاَ يجْرِمَنّكم شَنآنُ قَوْم أَنْ صَدُّوكُم } و {  إن صَدُّوكم } .  وقوله {  من الشهدَاء أَن تَضِلّ } و {  إِنْ تَضِلّ } وكذلك {  أَفَنَضْرِبُ عَنْكُمُ الذكرَ صَفْحا إنْ كُنْتُم } وَ {  أن كنتم } وَجهان جَيِّدَان .
