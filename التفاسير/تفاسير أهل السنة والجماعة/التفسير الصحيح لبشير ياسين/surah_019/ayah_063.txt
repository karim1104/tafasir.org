قوله تعالى {  تلك الجنة التي نورث من عبادنا من كان تقيا }<br />
قال الشيخ الشنقيطي :  قوله تعالى {  تلك الجنة التي نورث من عبادنا من كان تقيا } الإشارة في قوله {  تلك } على ما تقدم من قوله {  فأولئك يدخلون الجنة ولا يظلمون شيئا جنات عدن التي وعد الرحمن عباده بالغيب } الآية وقد بين جل وعلا في هذه الآية الكريمة أنه يورث المتقين من عباده جنته وقد بين هذا المعنى أيضا في مواضع أخر كقوله تعالى {  قد أفلح المؤمنون الذي هم في صلاتهم خاشعون } إلى قوله {  أولئك هم الوارثون الذين يرثون الفردوس هم فيها خالدون } وقوله {  وسارعوا إلى مغفرة من ربكم وجنة عرضها السموات والأرض أعدت للمتقين } الآيات ،  وقوله تعالى {  وسيق الذين اتقوا ربهم إلى الجنة زمرا } الآية وقوله {  ونودوا أن تلكم الجنة أورثتموها بما كنتم تعملون } . <br />
