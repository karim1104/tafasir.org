أخرج الطبري بسنده الحسن عن قتادة {  لا تسمع فيها لاغية } :  لا تسمع فيها باطلا ،  ولا شاتما . <br />
قال ابن كثير :  وقوله {  لا تسمع فيها لاغية } أي :  لا يسمع في الجنة التي هم فيها كلمة لغو ،  كما قال {  لا يسمعون فيها لغوا إلا سلاما } سورة مريم :  62 . <br />
وقال {  لا لغو فيها ولا تأثيم } سورة الطور :  23 .  اه . <br />
وانظر سورة الطور آية [ 23 ] لبيان {  لا لغو } أي :  لا باطل فيها .
