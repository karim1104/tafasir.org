قوله تعالى :  {  أولئك الذين خسروا أنفسهم وضل عنهم ما كانوا يفترون } قال ابن كثير :  أي خسروا أنفسهم لأنهم أدخلوا نارا حامية فهم معذبون فيها لا يفتر عنهم من عذابها طرفة عين كما قال تعالى {  كلما خبت زدناهم سعيرا } {  وضلّ عنهم } أي ذهب عنهم {  ما كانوا يفترون } من دون الله من الأنداد والأصنام فلم تجد عنهم شيئا بل ضرتهم كل الضرر كما قال تعالى {  وإذا حشر الناس كانوا لهم أعداء وكانوا بعبادتهم كافرين } . <br />
