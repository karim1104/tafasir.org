قوله تعالى :  {  وإن تدعوهم إلى الهدى لا يسمعوا وتراهم ينظرون إليك وهم لا يبصرون }<br />
أخرج الطبري بسنده الحسن عن السدي :  {  وإن تدعوهم إلى الهدى لا يسمعوا وتراهم ينظرون إليك وهم لا يبصرون } قال :  هؤلاء المشركون . <br />
قال ابن كثير :  {  وإن تدعوهم إلى الهدى لا يسمعوا وتراهم ينظرون إليك وهم لا يبصرون } كقوله تعالى {  إن تدعوهم لا يسمعوا دعاءكم } الآية . <br />
