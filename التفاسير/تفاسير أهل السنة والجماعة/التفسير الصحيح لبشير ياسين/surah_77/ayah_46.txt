قوله تعالى {  كلوا وتمتعوا قليلا إنكم مجرمون } . <br />
قال ابن كثير :  خطاب للمكذبين بيوم الدين وأمرهم أمر تهديد ووعيد فقال تعالى {  كلوا وتمتعوا قليلا } أي :  مدة قليلة قصيرة {  إنكم مجرمون } أي :  تم تساقون إلى النار التي تقدم ذكرها {  ويل يومئذ للمكذبين } كما قال تعالى {  نمتعهم قليلا ثم نضطرهم إلى عذاب غليظ } . <br />
