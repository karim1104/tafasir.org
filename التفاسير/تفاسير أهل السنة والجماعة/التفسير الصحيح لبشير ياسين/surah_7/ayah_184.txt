قوله تعالى :  {  أَوَلَمْ يَتَفَكّرُواْ مَا بِصَاحِبِهِمْ مّن جِنّةٍ إِنْ هُوَ إِلاّ نَذِيرٌ مّبِينٌ }<br />
قال ابن كثير :  يقول تعالى {  أولم يتفكروا } هؤلاء بآياتنا {  ما بصاحبهم } يعني محمداً – صلوات الله وسلامه عليه - {  من جِنّة } أي :  ليس به جنون ،  بل هو رسول الله حقاً دعا إلى حق {  إن هو إلا نذير مبين } أي :  ظاهر لمن كان له قلب ولب يعقل به ويعي به ،  كما قال تعالى {  وما صاحبكم بمجنون } وقال تعالى {  قل إنما أعظكم بواحدة أن تقوموا لله مثنى وفرادى ثم تتفكروا ما بصاحبكم من جنة إن هو إلا نذير لكم بين يدي عذاب شديد } . <br />
