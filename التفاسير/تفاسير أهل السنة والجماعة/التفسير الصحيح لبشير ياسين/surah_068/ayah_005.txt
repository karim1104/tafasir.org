قوله تعالى :  {  فستبصر ويبصرون بأيكم المفتون } . <br />
قال ابن كثير :  أي :  فستعلم يا محمد وسيعلم مخالفوك ومكذبوك من المفتون الضال منك ومنهم ،  وهذه كقوله تعالى :  {  سيعملون غدا من الكذاب الأشر } وكقوله :  {  وإنا أو إياكم لعلى هدى أو في ضلال مبين } . <br />
أخرج الطبري بسنده الصحيح عن مجاهد قوله :  {  بأيكم المفتون } قال :  الشيطان . <br />
أخرج الطبري بسنده الحسن عن قتادة قوله :  {  فستبصر ويبصرون بأيكم المفتنون } يقول :  بأيكم أولى بالشيطان . <br />
