قوله تعالى {  قل سيروا في الأرض فانظروا كيف بدأ الخلق ثم الله ينشئ النشأة الآخرة إن الله على كل شيء قدير } . <br />
أخرج الطبري بسنده الحسن عن قتادة {  قل سيروا في الأرض فانظروا كيف بدأ الخلق } خلق السماوات والأرض {  ثم الله ينشئ النشأة الآخرة } :  أي البعث بعد الموت . <br />
قال ابن كثير :  ثم قال تعالى {  قل سيروا في الأرض فانظروا كيف بدأ الخلق ثم الله ينشئ النشأة الآخرة } أي :  يوم القيامة {  إن الله على كل شيء قدير } وهذا المقام شبيه بقوله تعالى {  سنريهم آياتنا في الآفاق وفي أنفسهم حتى يتبين لهم أنه الحق } . <br />
وانظر سورة الأنبياء آية ( 104 ) .
