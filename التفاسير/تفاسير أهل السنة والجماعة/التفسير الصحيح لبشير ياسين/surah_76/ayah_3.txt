قوله تعالى {  إنا هديناه السبيل إما شاكرا وإما كفورا } . <br />
أخرج الطبري بسنده الصحيح عن مجاهد ،  قوله {  إنا هديناه السبيل } قال :  الشقوة والسعادة . <br />
أخرج الطبري بسنده الحسن عن قتادة ،  قوله {  إنا هديناه السبيل إما شاكرا } للنعم {  وإما كفورا } لها . <br />
وانظر سورة البلد آية ( 10 ) قوله تعالى {  وهديناه النجدين } طريق الخير وطريق الشر .
