قوله تعالى {  لتؤمنوا بالله ورسوله وتعزروه وتوقروه وتسبحوه بكرة وأصيلا }<br />
أخرج الطبري بسنده الحسن عن قتادة {  وتعزروه } :  ينصروه {  وتوقروه } أمر الله بتسويده وتفخيمه . <br />
أخرج الطبري بسنده الحسن عن قتادة {  وتسبحوه بكرة وأصيلا } في بعض القراءة {  ويسبحون الله بكرة وأصيلا } . <br />
وهذه القراءة تفسيرية لبيان عود الضمير إلى الله عز وجل . <br />
