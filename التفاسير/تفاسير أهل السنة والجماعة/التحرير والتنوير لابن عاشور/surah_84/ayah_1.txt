قدم الظرف { إذا السماء انشقت } على عامله وهو { كادح } للتهويل والتشويق إلى الخبر وأول الكلام في الاعتبار :  يا أيها الإِنسان إنك كادح إذا السماء انشقت الخ . <br />
ولكن لما تعلق { إذا } بجزء من جملة { إنك كادح } وكانت { إذا } ظرفاً متضمناً معنى الشرط صار :  يا أيها الإنسان إنك كادح جواباً لشرط { إذا } ولذلك يقولون { إذا } ظرف خافض لشرطه منصوب بجوابه ،  أي خافض لجملة شرطه بإضافته إليها منصوباً بجوابه لتعلقه به فكلاهما عامل ومعمول باختلاف الاعتبار . <br />
و { إذا } ظرف للزمان المستقبل ،  والفعل الذي في الجملة المضافة إليه { إذا } مؤول بالمستقبل وصيغ بالمضيّ للتنبيه على تحقق وقوعه لأن أصل { إذا } القطع بوقوع الشرط . <br />
وانشقت مطاوع شَقَّها ،  أي حين يشقُّ السماءَ شَاق فتنشق ،  أي يريد الله شقها فانشقت كما دل عليه قوله بعده :  { وأذنت لربها } . <br />
والانشقاق هذا هو الانفطار الذي تقدم في قوله :  { إذا السماء انفطرت }  [ الانفطار :  1 ] وهو انشقاق يلوح للناس في جوّ السماء من جرَّاء اختلال تركيب الكرة الهوائية أو من ظهور أجرام كوكبية تخرج عن دوائرها المعتادة في الجو الأعلى فتنشق القبة الهوائية فهو انشقاق يقع عند اختلال نظام هذا العالم . <br />
وقدّم المسند إليه على المسند الفعلي في قوله :  { إذا السماء انشقت } دون أن يقال :  إذا انشقت السماء لإفادة تقوّي الحكم وهو التعليق الشرطي ،  أي إن هذا الشرط محقق الوقوع ،  زيادة على ما يقتضيه { إذا } في الشرطية من قصد الجزم بحصول الشرط بخلاف ( إنْ ) .
