والقول في { اشتروا الحياة الدنيا بالآخرة } كالقول في :  { أولئك الذين اشتروا الضلالة بالهدي }  [ البقرة :  16 ] .  والقول في { فلا يخفف عنهم العذاب ولا هم ينصرون } قريب من القول في { ولا يقبل منها شفاعة ولا يؤخذ منها عدل ولا هم ينصرون } . <br />
وموقع الفاء في قوله :  { فلا يخفف عنهم العذاب } هو الترتب لأن المجرم بمثل هذا الجرم العظيم يناسبه العذاب العظيم ولا يجد نصيراً يدفع عنه أو يخفف .
