قوله :  { حسنت مستقراً ومقاماً } هو ضدّ ما قيل في المشركين { إنها ساءت مستقراً ومقاماً }  [ الفرقان :  66 ] .  والتحية تقدمت في قوله :  { وإذا حُيِّيتُم بتحية } في سورة النساء ( 86 ) ،  وفي قوله :  { وتحيتهم فيها سلام } في سورة يونس ( 10 ) ،  وقوله :  { تحية من عند الله مباركة طيبة } في آخر النور ( 61 ) .
