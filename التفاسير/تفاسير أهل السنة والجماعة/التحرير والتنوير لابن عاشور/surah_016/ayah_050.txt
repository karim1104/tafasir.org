جملة { يخافون ربهم } بيان لجملة { وهم لا يستكبرون } . <br />
والفوقية في قوله :  { من فوقهم } فوقية تصرف ومِلك وشرف كقوله تعالى :  { وهو القاهر فوق عباده }  [ سورة الأنعام :  18 ] وقوله { وإنا فوقهم قاهرون }  [ سورة الأعراف :  127 ] . <br />
وقوله تعالى :  { ويفعلون ما يؤمرون } ،  أي يطيعون ولا تصدر منهم مخالفة . <br />
وهنا موضع سجود للقارىء بالاتّفاق .  وحكمته هنا إظهار المؤمن أنه من الفريق الممدوح بأنه مشابه للملائكة في السجود لله تعالى .
