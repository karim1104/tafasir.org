وجعلوا جملة { إنا لمغرمون } تندماً وتحسراً ،  أي تعلمون أن حطم زرعِكُم حرمانٌ من الله جزاء لكفركم ،  ومعنى { مغرمون } من الغرام وهو الهلاك كما في قوله تعالى :  { إن عَذابها كان غراماً }  [ الفرقان :  65 ] .  وهذا شبيه بما في سورة القلم من قوله تعالى :  { فلما رأوها قالوا إنا لضالّون إلى قوله :  إنا كنا طاغين }  [ القلم :  26 31 ] . <br />
فتحصل أن معنى الآية يجوز أن يكون جارياً على ظاهر مادة فعل { تفكهون } ويكون ذلك تهكماً بهم حملاً لهم على معتاد أخلاقهم من الهزْل بآيات الله ،  وقرينة التهكم ما بعده من قوله عنهم { إنا لمغرمون بل نحن محرومون } . <br />
ويجوز أن يكون محمل الآية على جعل { تفكهون } بمعنى تندمون وتحزنون ،  ولذلك كان لفعل { تفكهون } هنا وقع يعوضه غيره . <br />
وجملة { إنا لمغرمون } مقول قول محذوف هو حال من ضمير { تفكهون } . <br />
وقرأ الجمهور { إنا لمغرمون } بهمزة واحدة وهي همزة ( إنّ ) ،  وقرأه أبو بكر عن عاصم { أإنا } بهمزيتن همزة استفهام وهمزة ( إنِ ) .
