وجملة { ونحن أقرب إليه منكم } في موضع الحال من مفعول { تنظرون } المحذوف ،  أو معترضة والواو اعتراضية . <br />
وأيَّاً ما كانت فهي احتراس لبيان أن ثمة حضوراً أقرب من حضورهم عند المحتضر وهو حضور التصريف لأحواله الباطنة . <br />
وقربُ الله :  قربُ علممٍ وقدرة على حد قوله :  { وجاء ربك }  [ الفجر :  22 ] أو قرب ملائكته المرسلين لتنفيذ أمره في الحياة والموت على حد قوله :  { ولقد جئناهم بكتاب }  [ الأعراف :  52 ] ،  أي جاءهم جبريل بكتاب ،  قال تعالى :  { حتى إذا جاءتهم رسلنا يتوفونهم }  [ الأعراف :  37 ] . <br />
وجملة { ولكن لا تبصرون } معترضة بين جملة { ونحن أقرب إليه منكم } وجملة { فلولا إن كنتم غير مدينين } وكلمة { فلولا } الثانية تأكيد لفظي لنظيرها السابق أعيد لتُبنى عليه جملة { ترجعونها } لطول الفصل .
