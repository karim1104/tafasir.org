وجملة :  { يومئذ تحدث أخبارها } الخ جواب { إذا } باعتبار ما أبدل منها من قوله :  { يومئذ يصدر الناس } فيومئذ بدل من { يومئذ تحدث أخبارها } . <br />
واليوم يطلق على النهار مع ليلهِ فيكون الزلزال نهاراً وتتبَعه حوادث في الليل مع انكدار النجوم وانتثارها وقد يراد باليوم مطلق الزمان . <br />
و{ تحدث أخبارها } هو العامل في { يومئذ } وفي البدل ،  والتقدير يوم إذْ تزلْزلُ الأرض وتُخرج أثقالها ويقول الناس :  ما لَهَا تحدّث أخبارها الخ . <br />
و{ أخبارها } مفعول ثاننٍ لفعل { تحدث } لأنه مما ألحق بظن لإِفادة الخَبَر عِلماً ،  وحذف مفعوله الأول لظهوره ،  أي تحدث الإِنسان لأن الغرض من الكلام هو إخبارها لما فيه من التهويل . <br />
وضمير { تحدث } عائد إلى { الأرض } . <br />
والتحديث حقيقته :  أن يصدر كلام بخبر عن حَدث .  وورد في حديث الترمذي عن أبي هريرة قال :  «  قرأ رسول الله صلى الله عليه وسلم هذه الآية { يومئذ تحدث أخبارها } قال :  أتدرون ما أخبارها ؟  قالوا :  الله ورسوله أعلم قال :  فإن أخبارها أن تشهد على كل عبد أو أمة بما عمل على ظهرها تقول :  عَمل كذا وكذا فهذه أخبارها  » اه . <br />
وجُمع { أخبارها } باعتبار تعدد دلالتها على عدد القائلين { ما لها } وإنما هو خبر واحد وهو المبيَّن بقوله :  { بأن ربك أوحى لها } . <br />
وانتصب { أخبارها } على نزع الخافض وهو باء تعدية فعل { تحدث } . <br />
