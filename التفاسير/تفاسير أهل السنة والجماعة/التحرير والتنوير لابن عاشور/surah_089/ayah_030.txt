وإضافة ( جنة ) إلى ضمير الجلالة إضافة تشريف كقوله :  { في مقعد صدق عند مليك مقتدر }  [ القمر :  55 ] . <br />
وهذه الإِضافة هي مما يزيد الالتفات إلى ضمير التكلُّم حسناً بعد طريقة الغيبة بقوله :  { ارجعي إلى ربك } . <br />
وتكرير فعل { وادخلي } فلم يقل :  فادخلي جنتي في عبادي للاهتمام بالدخول بخصوصه تحقيقاً للمسرة لهم .
