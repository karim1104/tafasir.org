وجملة { فيومئذٍ وقعت الواقعة } مشتملة على جواب ( إذَا ) ،  أعني قولَه { وقعت الواقعة ،  } وأما قوله :  { فيومئذٍ } فهو تأكيد لمعنى { فإذا نُفخ في الصور } إلخ لأن تنوين ( يومئذٍ ) عوض عن جملة تدل عليها جملة { نُفخ في الصور } إلى قوله { دَكّة واحدة ،  } أي فيوم إذ نفخ في الصور إلى آخره وقعت الواقعة وهو تأكيد لفظي بمرادف المؤكَّد ،  فإن المراد ب ( يوم ) من قوله { فيومئذٍ وقَعت الواقعة } ،  مطلقُ الزمان كما هو الغالب في وقوعه مُضافاً إلى ( إذا ) . <br />
ومعنى { وقعت الواقعة } تحقق ما كان متوقَّعاً وقوعُه لأنهم كانوا يُتَوعَّدون بواقعة عظيمة فيومئذٍ يتحقق ما كانوا يُتوعدون به . <br />
فعبر عنه بفعل المضي تنبيهاً على تحقيق حصوله . <br />
والمعنى :  فحينئذٍ تقع الواقعة . <br />
و { الواقعة } :  مرادفة للحاقة والقارعة ،  فذكرها إظهار في مقام الإِضمار لزيادة التهويل وإفادة ما تحتوي عليه من الأحوال التي تنبىء عنها موارد اشتقاق أوصاف الحاقة والقارعة والواقعة . <br />
و { الواقعة } صار علماً بالغلبة في اصطلاح القرآن يوم البعث قال تعالى :  { إذا وقَعت الواقعة ليس لوقْعَتِها كاذبة }  [ الواقعة :  12 ] .
