و { إذْ } ظرف للزمن الماضي يتعلق ب { طغواها } لأن وقت انبعاث أشقاها لعقر الناقة هو الوقت الذي بدت فيه شدة طغواها فبعثوا أشقاهم لعقر الناقة التي جُعلت لهم آية وذلك منتهى الجُرأة . <br />
و { انبعث } :  مطاوع بَعَث ،  فالمعنى :  إذ بعثوا أشقاهم فانبعث وانتدب لذلك .  و { إذ } مضاف إلى جملة :  { انبعث أشقاها } . <br />
