لذلك عقب هذا الخطاب بقوله :  { فراغَ عليهم ضرباً باليمينِ .  } وقد استعمل فعل ( راغ ) هنا مضمّناً معنى ( أقبل ) من جهة مائلة عن الأصنام لأنه كان مستقبلها ثم أخذ يضربها ذات اليمين وذات الشمال نظير قوله تعالى :  { فيميلون عليكم }  [ النساء :  102 ] . <br />
وانتصب { ضَرْباً باليمين } على الحال من ضمير { فراغَ } أي ضارباً .  وتقييد الضرب باليمين لتأكيد { ضَرْباً } أي ضرباً قوياً ،  ونظيره قوله تعالى :  { لأخذنا منه باليمين }  [ الحاقة :  45 ] وقول الشماخ : <br />
إذا ما رايةٌ رُفعت لمجد *** تَلقَّاها عَرابَةُ باليمين<br />
فلما علموا بما فعل إبراهيم بأصنامهم أرسلوا إليه من يُحضره في ملئِهم حول أصنامهم كما هو مفصّل في سورة الأنبياء وأجمل هنا .
