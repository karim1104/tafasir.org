{  يوم تشقق الأَرض عنهم سراعاً } أي مصيرهم إلينا في ذلك الوقت تشقق الأرض ،  أي :  تتفتح عنهم أي عن هؤلاء في قبورهم ،  تشقق كما تشقق الأرض عند طلوع النبات ،  {  سراعاً } أي يأتون إلى المحشر {  ذلك حشر علينا يسير } أي سهل علينا ،  لأن الله تعالى يقول في كتابه :  {  فإنما هي زجرة واحدة فإذا هم ينظرون } ويقول تعالى :  {  فإنما هي زجرة واحدة فإذا هم بالساهرة } ويقول تعالى :  {  إن كانت إلا صيحةً واحدة فإذا هم جميع لدينا محضرون } وهذا يدل على يسر ذلك على الله عز وجل<br />
