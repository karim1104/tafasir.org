{  ءأنتم أشد خلقاً أم السماء } هذا الاستفهام لتقرير إمكان البعث ؛  لأن المشركين كذبوا النبي صلى الله عليه وآله وسلم بالبعث وقالوا :  {  من يحيي العظام وهي رميم } [ يس :  78 ] .  فيقول الله عز وجل :  {  ءأنتم أشد خلقاً أم السماء } الجواب معلوم لكل أحد أنه السماء كما قال تعالى :  {  لخلق السماوات والأرض أكبر من خلق الناس ولكن أكثر الناس لا يعلمون } [ غافر :  57 ] .  {  بناها } هذه الجملة لا تتعلق بالتي قبلها ،  ولهذا ينبغي للقارىء إذا قرأ أن يقف على قوله {  أم السماء } ثم يستأنف فيقول :  {  بناها } فالجملة استئنافية لبيان عظمة السماء ،  {  بناها } أي بناها الله عز وجل وقد بين الله سبحانه وتعالى في آية أخرى في سورة الذاريات أنه بناها بقوة فقال :  {  والسماء بنيناها بأيد } أي بقوة {  وإنا لموسعون } .
