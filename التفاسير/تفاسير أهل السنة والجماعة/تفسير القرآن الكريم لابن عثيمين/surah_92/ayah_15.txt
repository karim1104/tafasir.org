{  لا يصلاها إلا الأشقى } {  لا يصلاها } يعني :  لا يحترق بها {  إلا الأشقى } يعني الذي قدرت له الشقاوة .  والشقاوة ضد السعادة لقوله تعالى :  {  فأما الذين شقوا ففي النار } [ هود :  106 ] .  وقوله :  {  وأما الذين سعدوا ففي الجنة } [ هود :  108 ] .  فالمراد بالأشقى يعني :  الذي لم تكتب له السعادة ،  هذا هو الذي يصلى النار التي تلظى .
