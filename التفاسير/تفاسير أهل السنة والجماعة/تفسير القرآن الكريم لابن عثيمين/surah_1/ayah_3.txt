( الرَّحْمَنِ الرَّحِيمِ )<br />
التفسير :  . <br />
قوله تعالى :  {  الرحمن الرحيم } :  {  الرحمن } صفة للفظ الجلالة ؛  و {  الرحيم } صفة أخرى ؛  و {  الرحمن } هو ذو الرحمة الواسعة ؛  و {  الرحيم } هو ذو الرحمة الواصلة ؛  ف {  الرحمن } وصفه ؛  و {  الرحيم } فعله ؛  ولو أنه جيء بـ " الرحمن "  وحده ،  أو بـ " الرحيم "  وحده لشمل الوصف ،  والفعل ؛  لكن إذا اقترنا فُسِّر {  الرحمن } بالوصف ؛  و {  الرحيم } بالفعل .  . <br />
الفوائد : <br />
 . 1  من فوائد الآية :  إثبات هذين الاسمين الكريمين .  {  الرحمن الرحيم } لله عزّ وجلّ ؛  وإثبات ما تضمناه من الرحمة التي هي الوصف ،  ومن الرحمة التي هي الفعل .  . <br />
 . 2  ومنها :  أن ربوبية الله عزّ وجلّ مبنية على الرحمة الواسعة للخلق الواصلة ؛  لأنه تعالى لما قال :  {  رب العالمين } كأن سائلاً يسأل :   " ما نوع هذه الربوبية ؟  هل هي ربوبية أخذ ،  وانتقام ؛  أو ربوبية رحمة ،  وإنعام ؟  "  قال تعالى :  {  الرحمن الرحيم } .  .
