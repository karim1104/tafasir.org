)لِلَّذِينَ يُؤْلُونَ مِنْ نِسَائِهِمْ تَرَبُّصُ أَرْبَعَةِ أَشْهُرٍ فَإِنْ فَاءُوا فَإِنَّ اللَّهَ غَفُورٌ رَحِيمٌ ) ( البقرة : 226 ) ) وَإِنْ عَزَمُوا الطَّلاقَ فَإِنَّ اللَّهَ سَمِيعٌ عَلِيمٌ ) ( البقرة : 227 )<br />
التفسير : <br />
قوله تعالى :  {  للذين } خبر مقدم ؛  و {  تربص } مبتدأ مؤخر ؛  وبعد هذا بين الله الحال بعد هذا التربص . <br />
قوله تعالى :  {  للذين يؤلون من نسائهم } :  اللام يحتمل أن تكون للإباحة ؛  ويحتمل أن تكون للتوقيت ؛  يعني :  أنه يباح للمولين أن يتربصوا أربعة أشهر ؛  أو أن لهم وقتاً محدداً بأربعة أشهر ؛  و {  يؤلون } أي يحلفون على ترك وطء زوجاتهم ؛  و {  مِن } :  قيل إنها بمعنى «عن » ؛  يعني يحلفون عن وطء نسائهم ؛  وقيل :  إنها على بابها ؛  فهي مبينة لموضع الإيلاء - يعني :  الحلف - ؛  و {  نسائهم } أي زوجاتهم . <br />
قوله تعالى :  {  تربص } أي انتظار ؛  وهو شبيه ب«الصبر » لموافقته إياه في الحروف - وإن خالفه في الترتيب - ؛  و«الصبر » بمعنى حبس النفس ،  وانتظارها ؛  {  أربعة أشهر } أي مدة أربعة أشهر ؛  فينتظرون لمدة أربعة أشهر ابتداءً من إيلائهم . <br />
قوله تعالى :  {  فإن فاءوا } أي رجعوا إلى نسائهم بعد أن آلوا منهن ؛  {  فإن الله غفور } أي يغفر لهم ما تجرؤوا عليه من الحلف على حرمان الزوجات من حقوقهن ؛  لأن حلفهم على ألا يطؤوا لمدة أربعة أشهر اعتداء على حق المرأة ؛  إذ إن الرجل يجب عليه أن يعاشر زوجته بالمعروف ؛  وليس من العشرة بالمعروف أن يحلف الإنسان ألا يطأ زوجته مدة أربعة أشهر ؛  فإن فعل فقد عرض نفسه للعقوبة ؛  لكنه إذا رجع غفر الله له ؛  و {  غفور } أي ذو مغفرة ،  كما قال تعالى :  {  وإن ربك لذو مغفرة للناس على ظلمهم } [ الرعد :  6 ]  ؛  والمغفرة هي ستر الذنب مع التجاوز عنه مأخوذة من «المغفر » ؛  وهو ما يوضع على الرأس عند الحرب لاتقاء السهام ؛  وفي المغفر تغطية ،  ووقاية ؛  و {  رحيم } أي ذو رحمة ،  كما قال تعالى :  {  وربك الغني ذو الرحمة } [ الأنعام :  133 ]  ؛  فهو مشتق من الرحمة المستلزمة للعطف ،  والحنوّ ،  والإحسان ،  ودفع النقم . <br />
