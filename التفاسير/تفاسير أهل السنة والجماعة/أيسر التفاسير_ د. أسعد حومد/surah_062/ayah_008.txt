{ مُلاَقِيكُمْ }  { عَالِمِ }  { ٱلشَّهَادَةِ }  (8) - وَقُلْ لَهُمْ: إِنَّ الفِرَارَ مِنَ المَوْتِ لاَ يُجْدِيهِمْ نَفْعاً، وَإِنَّهُ سَيُلاَقِيهِمْ حِينَمَا يَحِينَ أَجَلُهُمْ، لاَ يَصْرِفُهُ عَنْهُمْ صَارِفٌ، وَأَيَّامُ الحَيَاةِ مَعْدُودَةٌ، وَهِيَ سَتَنْقَضِي مَهْمَا طَالَ أَمَدُهَا، ثُمَّ تَرْجِعُونَ بَعْدَ المَوْتِ إِلَى عَالِمِ غَيْبِ السَّمَاوَاتِ وَالأَرْضِ، وَعَالِمِ مَا هُوَ مُشَاهَدٌ فِيهَا، فَيُخْبِرُهُمْ بِمَا كَانُوا يَعْمَلُونَ فِي الدُّنْيَا، وَسَيُجَازِيهِمْ عَلَى أَعْمَالِهِمْ.
