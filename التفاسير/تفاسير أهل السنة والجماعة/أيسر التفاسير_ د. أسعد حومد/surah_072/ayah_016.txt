{ وَأَلَّوِ }  { ٱسْتَقَامُواْ }  { لأَسْقَيْنَاهُم }  (16) - وََأَنَّ كُفَّارَ قُرَيْشٍ لَوِ اسْتَقَامُوا عَلَى طَرِيقَةِ الإِيْمَانِ بِاللهِ، والطَّاعَةِ لَهُ، لأَوْسَعَ اللهُ عَلَيْهِمْ فِي الدُّنْيَا، وَلأَنْزَلَ السَّمَاءَ عَلَيْهِمْ مِدْرَاراً. (وَقَالَ ابْنُ عَبَّاسٍ: هَذِهِ الآيَةُ نَزَلَتْ فِي كُفَّارِ قُرَيْشٍ حِينَمَا مُنِعُوا المَطَرَ سَبْعَ سِنِينَ).  عَلَى الطَّرِيقَةِ - عَلَى طَرِيقَةِ الهُدَى وَالإِيْمَانِ.
