{ أُوْلَـٰئِكَ }  { وَجَنَّاتٌ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  { ٱلْعَامِلِينَ }  (136) - وَالمُتَّقُونَ المُتَمَتِّعُونَ بِهَذِهِ الصِّفَاتِ سَيَجْزِيهِمْ رَبُّهُمْ عَلَيهَا بِالمَغْفِرَةِ، وَبالأمْنِ مِنَ العِقَابِ، وَلَهُمْ ثَوَابٌ عَظِيمٌ فِي جَنَّاتٍ تَجْرِي مِنْ تَحْتِهَا الأنْهَارُ، وَهُمْ مُخَلَّدُونَ فِيهَا أبَداً، وَالجَنَّةُ خَيْرُ مَا يُكَافَأُ بِهِ المُؤْمِنُونَ العَامِلُونَ عَلَى أعْمَالِهِمْ الصَّالِحَاتِ.
