{ يُسَارِعُونَ }  { ٱلْخَيْرَاتِ }  { وَأُوْلَـٰئِكَ }  { ٱلصَّالِحِينَ }  (114) - وَقَدْ آمَنُوا بِاللهِ، وَبِالَيْومِ الآخِرِ، إيمَاناً صَادِقاً، وَنَهَضُوا بِتَكَالِيفِ الجَمَاعَةِ المُسْلِمَةِ، فَأمَرُوا بِالمَعْرُوفِ، وَنَهُوا عَنِ المُنْكَرِ، وَعَمِلُوا الخَيْرَ، فَجَعَلَهُمُ اللهُ تَعَالَى مِنَ الصَّالِحِينَ، وَشَهِدَ لَهُمْ بِهَذَا الصَّلاَحِ.
