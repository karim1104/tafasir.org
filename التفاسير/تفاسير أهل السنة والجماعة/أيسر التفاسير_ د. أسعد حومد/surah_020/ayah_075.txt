{ ٱلصَّالِحَاتِ }  { فَأُوْلَـٰئِكَ }  { ٱلدَّرَجَاتُ }  (75) - وَمَنْ جَاءَ رَبَّهُ يَوْمَ القِيَامَةِ وَهُوَ مُؤْمِنُ القَلْبِ، قَدْ صَدَّق ضَمِيرَهُ، بِقَوْلِهِ وَعَمَلِهِ الصَّالِحِ جَزَاهُ رَبُّهُ عَلَى عَمَلِهِ بِالجَنَّةِ، ذَاتِ الدَّرَجَاتِ العَالِيَةِ، وَالغُرَفِ الآمِنَاتِ، وَالمَسَاكِنِ الطَّيِّبَاتِ.
