{ وَادِ }  { يٰأَيُّهَا }  { مَسَاكِنَكُمْ }  { سُلَيْمَانُ }  (18) - حَتَّى إِذا مَرَّ سُلَيمانُ بمنْ مَعَهُ مِنَ الجُنْدَ عَلى وَادٍ للنَّمْلِ قَالَتْ نملةٌ لِصَحْبِهَا: ادْخُلُوا مَسَاكِنَكُمْ، فإِنَّ سُليمانَ وَجُنُودَهُ قَدْ يَحْطِمُونَكُمْ وهُمْ لا يَشْعُرونَ بِوُجُودِكُمْ، وَلا بِما يَفْعَلُونَ من تَحْطِيمِكُمْ.  يَحْطِمَنَّكُمْ - يُدُوسُكُمْ ويُهْلِكُكُمْ.
