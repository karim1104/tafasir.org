{ أُوْلَـٰئِكَ }  { أَصْحَابُ }  { خَالِدِينَ }  (14) - وََهَؤُلاءِ الذِينَ آمَنُوا بِاللهِ، واستَقَامُوا عَلَى الإِيمَانِ والعَمَلِ الصَّالِحِ، هُمْ أَصْحَابُ الجَنَّةِ يَخلُدُونَ فِيها أبداً، ثَواباً لَهُمْ مِنْ عِنْدِ اللهِ، وَجَزَاءً لَهُمْ عَلَى مَا قَدَّمُوا مِنْ أَعْمَالٍ صَالِحَاتٍ فِي الدُّنيا.
