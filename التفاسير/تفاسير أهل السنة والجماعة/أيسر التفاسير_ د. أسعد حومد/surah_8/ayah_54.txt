{ آلِ فِرْعَوْنَ }  { بآيَاتِ }  { فَأَهْلَكْنَاهُمْ }  { آلَ فِرْعَونَ }  { ظَالِمِينَ }  (54) - فَإذا كَفَرَتِ الأمَمُ بِأنْعُمِ رَبِّهَا، فَإنَّهُ تَعَالَى يَفْعَلُ فِيهِمْ فِعْلَهُ بِقَوْمِ فِرْعَوْنَ، وَأَمْثَالِهِمْ حِينَ كَذَّبُوا بِآيَاتِ اللهِ: أَهْلَكَهُمُ اللهُ بِذُنُوبِهِمْ وَجَرَائِمِهِمْ، وَتَكْذِيبِهِمْ رُسُلَ رَبِّهِمْ وَآيَاتِهِ، وَأغْرَقَ فِرْعَوْنَ وَقَوْمَهُ، وَمَا ظَلَمَهُمُ اللهُ إذْ أغْرَقَهُمْ، وَإنَّمَا كَانُوا هُمُ الظَّالِمِينَ لأنْفُسِهِمْ.
