{ أُوْلَـٰئِكَ }  { آتَيْنَاهُمُ }  { ٱلْكِتَابَ }  { بِكَافِرِينَ }  (89) - أُولَئِكَ الذِينَ أَنْعَمَ اللهُ عَلَيهِمْ، بِأَنْ آتَاهُمُ الكِتَابَ (صُحُفَ إِبراهيمَ، وَتَوْرَاةِ مُوسَى وَزَبُورِ دَاوُدَ، وَإِنْجِيلَ عِيسَى) كَمَا آتَاهُمُ العِلْمَ وَالفِقْهَ فِي الدِّينِ (الحُكْمَ)، وَآتَاهُمُ النُّبُوَّةَ لِيَهْدُوا النَّاسَ إِلَى اللهِ، وَذَلِكَ رَحْمَةٌ مِنَ اللهِ بِعِبَادِهِ، وَلُطْفٌ مِنْهُ بِخَلْقِهِ، فَإِنْ يَكْفُرْ أَهْلُ مَكَّةَ وَغَيْرُهُمْ مِمَّنْ فِي الأَرْضِ مِنَ البَشَرِ (هَؤلاءِ) بِالكِتَابِ وَالحُكْمِ وَالنُّبُوَّةِ فَإِنَّ اللهَ تَعَالَى وَكَّلَ بِرِعَايَتِهَا قَوماً مُؤْمِنِينَ، لاَ يَجْحَدُونَ مِنْهَا شَيئاً، وَلاَ يَرُدُّونَ مِنْهَا حَرْفاً. (وَهُمُ المُهَاجِرُونَ وَالأَنْصَارُ وَالمُؤْمِنُونَ - عَلَى مَا قَالَهُ ابْنُ عَبَّاسٍ فِي تَفْسِيرِ هذا المَقْطَعِ مِنَ الآيَة).
