{ إِبْرَاهِيمُ }  { آزَرَ }  { أَرَاكَ }  { ضَلاَلٍ }  (74) - وَاذْكُرْ أَيُّهَا الرَّسُولُ لِهؤُلاَءِ المُشْرِكِينَ، الذِينَ عَبَدُوا مَا لاَ يَنْفَعُهُمْ وَلاَ يَضُرُّهُمْ، قِصَّةَ جَدِّهِمْ إِبْرَاهِيمَ الذِي يُبَجِّلُونَهُ، وَيَدَّعُونَ اتِّبَاعَ مِلَّتِهِ، إِذْ جَادَلَ قَوْمَهُ وَرَاجَعَهُمْ فِي بَاطِلِ مَا كَانُوا يَعْمَلُونَ: فَقَالَ لأَِبِيهِ آزَرَ: كَيْفَ تَتِّخِذُ أَنْتَ وَقَوْمُكَ آلِهَةً مِنَ الأَصَنْامِ، التِي تَصْنَعُونَهَا بَأَيْدِيْكُمْ مِنَ الحِجَارَةِ وَغَيْرِها، إنِّي أَرَاكُمْ تَائِهِينَ فِي حَيْرَةٍ وَجَهَالَةٍ، وَأَمْرُكُمْ فِي الجَهَالَةِ وَالضَّلاَلَةِ عَنِ الطَّرِيقِ المُسْتَقِيمِ بَيِّنٌ وَاضِحٌ لِكُلِّ ذِي عَقْلٍ.
