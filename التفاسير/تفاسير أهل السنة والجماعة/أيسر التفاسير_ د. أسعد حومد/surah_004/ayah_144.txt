{ يَا أَيُّهَا }  { آمَنُواْ }  { ٱلْكَافِرِينَ }  { سُلْطَاناً }  (144) - يَنْهَى اللهُ تَعَالَى عِبَادَهُ المُؤْمِنينَ عَنْ أَنْ يَتَّخِذُوا الكَافِرِينَ أوْلياءَ لَهُمْ، مِنْ دُونِ المُؤْمِنينَ، يُصَاحِبُونَهُمْ وَيُصَادِقُونَهُمْ، وَيُنَاصِحُونَهُمْ، وَيُسِرُّونَ إلَيْهِمْ بِالمَوَدَّةِ، وَيُفْشُونَ إلَيْهِمْ أحْوَالَ المُؤْمِنينَ البَاطِنَةَ.  وَيَقُولُ لَهُمْ إنَّهُمْ إِنْ فَعَلُوا ذَلِكَ جَعَلُوا للهِ عَلَيْهم حُجَّةً بَيِّنَةً وَعُذْراً فِي عُقُوبَتِهِ إيّاهُمْ. (وَالمُرَادُ هُنَا النُّصْرَةُ بِالقَوْلِ وَالفِعْلِ بِمَا يَكُونُ فِيهِ ضَرَرُ المُسْلِمِينَ).  سُلْطَاناً - حُجَّةً وَسَبَباً لِلْعُقُوبَةِ.
