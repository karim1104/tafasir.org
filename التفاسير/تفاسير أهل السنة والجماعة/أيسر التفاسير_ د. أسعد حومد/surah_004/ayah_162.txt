{ ٱلرَّاسِخُونَ }  { ٱلصَّلاَةَ }  { ٱلزَّكَاةَ }  { أُوْلَـۤئِكَ }  (162) - لكِن الثَّابِتُونَ فِي العِلْمِ، مِنَ اليَهُودِ، وَالمُؤْمِنُونَ مِنْ أُمَّتِكَ يَا مُحَمَّدُ، يُصَدِّقُونَ بِمَا أوحِيَ إلَيْكَ، وَمَا أُوْحِيَ إلَى الرُّسُلِ مِنْ قَبْلِكَ. وَالذِينَ يُؤَدُّونَ الصَّلاةَ حَقَّ أدَائِهَا، وَيَدْفَعُونَ زَكَاةَ أَمْوَالِهِمْ، وَيُصَدِّقُونَ بِاللهِ وَبِالبَعْثِ وَالحِسَابِ، فَهَؤُلاءِ جَمِيعاً سَيُدْخِلُهُمْ رَبُّهُمُ الجَنَّةَ، جَزَاءً لَهُمْ عَلَى إِيمَانِهِمْ وَأَعْمَالِهِمُ الصَّالِحَةِ.  (خَصَّ اللهُ تَعَالَى المُقِيمِينَ الصَّلاَةَ بِالمَدْحِ فَنَصَبَ (المُقِيمِينَ) عَلَى المَدْحِ، لأنَّ الذِي يُقيمُ الصَّلاَةَ عَلى الوَجْهِ الأكْمَلِ لاَ يَمْنَعُ الزَّكَاةَ).  وَالمُقِيمِينَ الصَّلاَةَ - مَنْصُوبٌ عَلَى المَدْحِ.
