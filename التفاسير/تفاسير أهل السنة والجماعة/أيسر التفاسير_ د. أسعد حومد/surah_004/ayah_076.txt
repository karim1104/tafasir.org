{ آمَنُواْ }  { يُقَاتِلُونَ }  { ٱلطَّاغُوتِ }  { فَقَاتِلُوۤاْ }  { ٱلشَّيْطَانِ }  (76) - الذِينَ آمَنُوا يُقَاتِلُونَ فِي سَبِيلِ إعْلاَءِ كَلِمَةِ اللهِ، وَنَشْرِ دِينِهِ، لاَ يَبْتَغُونَ غَيْرَ رِضْوَانِ اللهِ. أمَّا الذِينَ كَفَرُوا، فَإِنَّهُمْ يُقَاتِلُونَ فِي سَبِيلِ الشَّيْطَانِ (الطَّاغُوتِ)، الذِي يُزَيِّنُ لَهُمُ الكُفْرَ، وَيُمَنِّيهِم النَّصْرَ. وَكَيْدُ الشَّيْطَانِ ضَعيفٌ، وَهُوَ لاَ يَسْتَطِيعُ نَصْرَ أوْلِيَائِهِ. أمَّا أوْلِيَاءُ اللهِ فَهُمُ الأَعِزَّةُ، لأنَّ اللهَ حَامِيهِمْ وَنَاصِرُهُمْ وَمُعِزُّهُمْ، وَلِذَلِكَ فَعَلَى المُؤْمِنِينَ، أوْلِيَاءِ اللهِ، أنْ لاَ يَخَافُوا أَعْدَاءَهُمُ الكُفَّارَ، لأنَّ العَاقِبَةَ لِلْمُؤْمِنِينَ المُخْلِصِينَ.  الطَّاغُوتِ - الشَّيْطَانِ أوِ البَاطِلِ.
