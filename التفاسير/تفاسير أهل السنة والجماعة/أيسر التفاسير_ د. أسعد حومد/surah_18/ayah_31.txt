{ أُوْلَـٰئِكَ }  { جَنَّاتُ }  { ٱلأَنْهَارُ }  { ٱلأَرَآئِكِ }  (31) - فَهؤُلاَءِ السُّعَدَاءُ الأَبْرَارُ يَدْخُلُونَ الجَنَّةَ لِيُقِيمُوا فِيهَا أَبَداً، وَتَجْرِي الأَنْهَارُ وَالمِيَاهُ فِي جَنَبَاتِهَا، وَيَلْبَسُونَ فِيهَا حُلِيّاً، هِيَ أَسَاوِرُ مِنْ ذَهَبٍ وَلُؤْلُؤٍ، وَيَلْبَسُونَ فِيهَا ثِيَاباً مِنَ الحَرِيرِ خَضْرَاءَ اللَّوْنِ (كَمَا جَاءَ فِي آيَةٍ أُخْرَى)، مِنْهَا ثِيَابٌ رَقِيقَةٌ كَالقُمْصَانِ، وَمَا مَاثَلَهَا، (مِنْ سُنْدُسٍ)، وَمِنْهَا ثِيَابٌ غَلِيظَةٌ، كَالدِّيبَاجِ لَهُ بَرِيقٌ (مَنْ إِسْتَبْرَقٍ)، وَيَجْلِسُونَ عَلَى الأَرَائِكِ وَالأَسِرَّةِ مُسْتَنِدِينَ (مُتَّكِئِينَ)، لِيَرْتَاحُوا فِي جَلْسَتِهِمْ. وَحَسُنَتِ الجَنَّةُ ثَوَاباً لَهُمْ عَلَى أَعْمَالِهِمْ، وَحَسُنَت مَنْزِلاً وَمَقِيلاً.  جَنَّاتُ عَدْنٍ - جَنَّاتُ إِقَامَةٍ وَاسْتِقْرارٍ.  سُنْدُسٍ - رَقِيقِ الدِّيبَاجِ.  إِسْتَبْرقٍ - غَلِيظِ الدِّيبَاجِ.  الأَرَآئِكِ - السُّرُرِ.
