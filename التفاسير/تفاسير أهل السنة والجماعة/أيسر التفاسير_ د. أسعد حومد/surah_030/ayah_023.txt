{ آيَاتِهِ }  { بِٱلْلَّيْلِ }  { لآيَاتٍ }  (23) - ومِنْ عَلاَمَاتِ قُدْرتِهِ عَلَى الخَلقِ أَنَّكُم تَنَامُون في اللَيْلِ، وتَهْدَؤُونَ، لِتَرتَاحَ أَبدانُكُم مِنْ عَنَاءِ العَمَلِ فِي النَّهارِ، وأَنَّكُم تَنْبَعِثُونَ في النَّهارِ لِلعَمَلِ وطَلَبِ الرِّزْقِ، وفي ذلِكَ عِبَرٌ وأَدِلَّةٌ لِمَنْ يَسْمَعُونَ المَوْعِظَةَ وَيَتَّعِظُونَ بِها.
