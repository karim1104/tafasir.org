{ آثَارِ }  { رَحْمَتِ }  { يُحْيِيِ }  { لَمُحْييِ }  (50) - فَانْظُرِ يَا مُحَمَّدُ إِلى الآثَارِ التِي يُحْدِثُها نُزُولُ المَطَرِ، فَتَحيَا بِهِ الأرضُ، وتُنْبِتُ الزُّرُوعَ، والنَّبَاتَ والخُضْرَةَ والثِّمَارَ، بَعْدَ أَنْ كَانَتْ مَوَاتاً.  وَالذِي قَدِرَ عَلَى إِحْيَاءِ الأَرْضِ المَوَاتِ لَقَادِرٌ عَلَى إِحْيَاءِ المَوتَى مِن قُبُورِهِمْ يَومَ الحَشْرِ، وَهُوَ قَادِرٌ عَلَى كُلِّ شَيءٍ، فَقَدْ أَوْجَدَ اللهُ الكَوْنَ وَمَا فِيهِ وَمَنْ فِيهِ مِنْ عَدَمٍ.
