{ إِسْلاَمَكُمْ }  { هَدَاكُمْ }  { لِلإِيمَانِ }  { صَادِقِينَ }  (17) - جَاءَتْ بَنْو أسَدٍ إلى النَّبيِّ صلى الله عليه وسلم مُسْلِمِينَ وَقَالُوا لَهُ: يا رَسُولَ اللهِ أسْلَمْنا وَقَاتَلتْكَ العَرَبُ وَلم نُقَاتِلْكَ. فَقَالَ رَسُولُ اللهِ: " إِنَّ فِقْهَهُمْ قَليلٌ، وَإنَّ الشَيْطَانَ يَنْطقُ عَلَى ألْسِنَتِهم " وَنَزَلَتْ هَذِهِ الآيةُ. وَفيها يَقُولُ اللهُ تَعَالى لِرَسُولِهِ الكَرِيمِ: إنَّ هَؤلاءِ الأعْرابَ جَاؤُوكَ وَهُمْ يَعُدُّونَ إسْلامَهم وَمُتَابَعَتَهُم لَكَ مِنّةً عَلَيكَ، يَطْلُبُونَ عَلَيها أجْراً، فَقُلْ لَهُم: لا تعُدُّوا إِسْلاَمَكُمْ مِنَّةً عَليَّ، بَل اللهُ هُوَ الذِي يَمنُّ عَلَيكُم إذْ وَفَّقَكُمْ إلى الاهْتِدَاءِ إلى الإِيمانِ، هَذا إنْ كُنْتُمْ صَادِقينَ في إيمانِكُمْ.
