{ كِتَابٌ }  { آيَاتُهُ }  { قُرْآناً }  (3) - وَهُوَ كِتَابٌ بُيِّنَتْ مَعَانِيهِ، وَأُحْكِمَتْ أَحْكَامُهُ، وَأَنْزَلَهُ اللهُ تَعَالَى بِاللُّغَةِ العَرَبِيَّةِ لَيَسْهُلَ عَلَى أَهْلِ العُقُولِ والأَلْبَابِ مِنَ العَرَبِ قِرَاءَتُهُ وَفَهْمُ مَعَانِيهِ (لِقَوْمٍ يَعْلَمُونَ).  فُصِّلَتْ - مُيِّزَتْ أَوْ بُيِّنَتْ أَوْ أُحْكِمَتْ.
