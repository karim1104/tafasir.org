{ يَسْأَمُ }  { ٱلإِنْسَانُ }  { فَيَئُوسٌ }  (49) - لاَ يَمَلُّ الإِنْسَانُ مِنْ دُعَائِهِ رَبَّهُ وَسُؤَالِهِ إِيَّاهُ الخَيْرَ لِنَفْسِهِ مِنْ مَالٍ، وَصِيحَّةٍ وَعِزٍّ، وَإِذَا مَسَّهُ الشَرُّ وَالضُرُّ فَقَدَ الأَمَلَ والرَّجَاءَ، وَظَنَّ أَنْ لاَ مَخْرَجَ لَهُ مِمَا هُوَ فِيهِ مِنَ البَلاَءِ وَلاَ فَرَجَ، لِضعْفِ ثِقَتِهِ بِرَبِّهِ.  القُنُوطُ - ظُهُورُ أَثَرِ اليَأْسَ عَلَى الإِنْسَانِ.  اليَأْسُ - انْقِطَاعُ الرَّجَاءِ.  لاَ يَسْأَمُ - لاَ يَمَلُّ وَلاَ يَفْترُ.
