{ يٰأَيُّهَا }  { آمَنُوۤاْ }  { أَعْمَالَكُمْ }  (33) - يَأمُرُ اللهُ تَعَالى المُؤْمِنينَ بإطَاعَةِ اللهِ، وَإطَاعَةِ رَسُولِهِ فِيما يَأمُرانِهِمْ بِهِ، وَفيما يَنْهَيانِهِمْ عَنْهُ، وَيَنْهَاهُمْ عَنْ إبْطَالِ أَعْمَالِهِم الحَسَنةِ، بارتِكَابِ المَعَاصِي، وَفِعْلِ الكَبَائِرِ والنِّفَاقِ، وَغَيْرِ ذَلِكَ مِنَ الأعْمَالِ التي تُبْطِلُ الحَسَناتِ وَتُذْهِبُها.
