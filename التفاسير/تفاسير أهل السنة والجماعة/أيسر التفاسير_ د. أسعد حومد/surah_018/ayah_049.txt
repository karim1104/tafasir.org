{ ٱلْكِتَابُ }  { يٰوَيْلَتَنَا }  { ٱلْكِتَابِ }  { أَحْصَاهَا }  { مَالِ هَـٰذَا }  (49) - وَوُضِعَ بَيْنَ يَدَيْ كُلِّ فَرْدٍ كِتَابُ أَعْمَالِهِ، وَفِيهِ جَمِيعُ مَا عَمِلَهُ فِي حَيَاتِهِ، مِنْ حَسَنٍ وَقَبِيحٍ، وَمِنْ صَغِيرٍ وَكَبِيرٍ. وَيَرَى المُجْرِمُونَ أَعْمَالَهُمُ القَبِيحَةَ مُحْصَاةً بِتَمَامِها، لَمْ يَنْقُصْ مِنْهَا شَيءٌ، وَيَعْلَمُونَ أَنَّ العَذَابَ وَاقِعٌ بِهِمْ، فَيُشْفِقُونَ مِمَّا سَيَحُلُّ بِهِمْ، وَيَقُولُونَ فِي أَنْفُسِهِمْ: يَا وَيْلَتَنَا، وَيَا حَسْرَتَنَا، عَلَى مَا فَرَّطْنَا فِي حَيَاتِنَا الدُّنْيا، مَا لِهذا الكِتَابِ لاَ يَتْرُكُ صَغِيراً مِنْ أَعْمَالِنَا وَذُنُوبِنا، وَلاَ كَبِيراً إِلاَّ أَحْصَاهُ وَوَعَاهُ؟ وَوَجَدُوا مَا عَمِلُوا مِنْ خَيْرٍ وَشَرٍّ حَاضِراً لِيُحَاسَبُوا عَلَيْهِ، وَلاَ يَظْلِمُ رَبُّكَ أَحَداً مِنْ خَلْقِهِ.  وَإِنَّمَا يُحَاسِبُ العِبَادَ عَلَى أَعْمَالِهِمْ بِالعَدْلِ التَّامِّ.  وُضِعَ الكِتَابُ - صُحُفُ الأَعْمَالِ فِي أَيْدِي أَصْحَابِهَا.  مُشْفِقِينَ - خَائِفِينَ وَجِلِينَ.  يَا وَيْلَتَنَا - يَا هَلاَكَنَا.  لاَ يُغَادِرُ - لاَ يَتْرُكُ وَلاَ يُبْقِي.  أَحْصَاهَا - عَدَّهَا وَضَبَطَهَا وَأَثْبَتَها.
