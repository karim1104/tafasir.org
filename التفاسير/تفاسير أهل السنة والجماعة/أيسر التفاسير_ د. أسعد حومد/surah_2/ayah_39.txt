{ بِآيَاتِنَآ }  { أُوْلَئِكَ }  { أَصْحَابُ }  { خَالِدُونَ }  (39) - أَمَّا الذِينَ سَيَكْفُرونَ بِمَا أَنْزَلَ اللهُ تَعَالَى مِنَ الكُتُبِ، وَبِمَنْ بَعَثَهُمْ مِنَ الرُّسُلِ فَهؤُلاءِ سَيَكُونُونَ مِنْ أَهْلِ النَّارِ، وَيَخْلُدُونَ فِيها أَبَداً، لاَ يَمُوتُونَ فِيها وَلا يَحُولُونَ عَنْهَا أَبَداً.
