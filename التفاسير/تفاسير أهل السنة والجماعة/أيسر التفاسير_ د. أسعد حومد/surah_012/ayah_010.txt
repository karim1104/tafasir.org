{ قَآئِلٌ }  { غَيَابَةِ }  { فَاعِلِينَ }  (10) - فَقَالَ أَحَدُهُمْ، لاَ تَبْلُغُوا فِي كُرْهِكُمْ يُوسُفَ حَدَّ القَتْلِ، وَاكْتَفُوا بِإِلْقَائِهِ فِي أَعْمَاقِ بِئْرٍ (غَيَابَةِ الجُبِّ)، فَتَمُرُّ قَافِلَةٌ مِنَ المُسَافِرِينَ، مِمَّنْ أَلِفُوا الاسْتِقَاءَ مِنْ هذِهِ البِئْرِ، فَتَلْتَقِطُهُ، وَتَأْخُذُهُ بَعِيداً، فَتَرْتَاحُونَ مِنْهُ بِدُونِ ارْتِكَابِ جَرِيمَةِ قَتْلِ أَخِيكُمْ، هَذَا إِنْ كُنْتُمْ مُصِرِّينَ عَلَى أَنْ تَفْعَلُوا ذَلِكَ. وَبِمَا أَنَّ مَشِيئَةَ اللهِ قَضَتْ بِأَنْ يَكُونَ يُوسُفُ ذَا شَأْنٍ عَظيمٍ فَقَدْ قَبِلَ الآخَرُونَ الاقْتِراحَ، لِيَبْلُغَ الكِتَابُ أَجَلَهُ.  غَيَابَةِ الجُبِّ - مَا غَابَ وَأَظْلَمَ مِنْ قَعْرِ الجُبِّ.  السَّيَّارَةِ - المُسَافِرِينَ.
