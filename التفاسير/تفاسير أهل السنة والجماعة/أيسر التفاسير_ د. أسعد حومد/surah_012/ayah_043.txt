{ بَقَرَاتٍ }  { سُنْبُلاَتٍ }  { يَابِسَاتٍ }  { يٰأَيُّهَا }  { رُؤْيَايَ }  { لِلرُّؤْيَا }  (43) - وَرَأَى المَلِكُ رُؤْيا هَالَتْهُ، وَتَعَجَّبَ مِنْ أَمْرِهَا، فَجَمَعَ الكَهَنَةَ، وَكِبَارَ رِجَالِ الدَّوْلَةِ فَقَصَّ عَلَيْهِمْ رُؤْيَاهُ، وَطَلَبَ إِلَيْهِمْ تَفْسِيرَها فَلَمْ يَعْرِفُوا ذَلِكَ. وَقَدْ رَأَى المَلِكُ فيِ مَنَامِهِ سَبْعَ بَقَرَاتٍ عِجَافٍ هَزِيلاتٍ يَأْكُلْنَ سَبْعَ بَقَرَاتٍ سِمَانٍ، وَرَأَى سَبْعَ سَنَابِلَ قَمْحٍ عِجَافٍ يَابِسَاتٍ، وَسَبْعَ سَنَابِلَ خُضْرٍ سِمَانٍ.  عِجَافٌ - مَهَازِيلُ جِدّاً.  تَعْبُرُونَ - تَعْلَمُونَ تَأْوِيلَهَا وَتَفْسِيرَهَا.
