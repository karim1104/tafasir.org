{ بِآيَاتِنَآ }  { أُوْلَـٰئِكَ }  { أَصْحَابُ }  { خَالِدِينَ }  (10) - أَمَّا الذِينَ كَفَرُوا بِاللهِ، وَجَحَدُوا بِوحْدَانِيَّتِهِ، وَكَذَّبُوا رَسُولَهُ، وَالكِتَابَ الذِي أَنْزَلَهُ اللهُ عَلَيهِ، فَهَؤُلاَءِ يُدْخِلُهُمْ رَبُّهُمْ نَارَ جَهَنَّمَ لِيَبْقَوا فِيهَا خَالِدِينَ أَبَداً، وَبِئْسَ النَّارُ مَنْزِلاً وَمَصِيراً.
