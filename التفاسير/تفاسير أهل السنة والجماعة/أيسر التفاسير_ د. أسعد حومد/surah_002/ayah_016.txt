{ أُوْلَـٰئِكَ }  { ٱلضَّلاَلَةَ }  { تِّجَارَتُهُمْ }  (16) - فَهؤُلاءِ المُنَافِقُونَ هُمُ الذِينَ أَخَذُوا الضَّلاَلَةَ وَالكُفْرَ وَتَرَكُوا الهُدَى وَالإِيمَانَ، وَكَأَنَّهُمْ عَقَدُوا صَفْقَةً بِذَلِكَ، وَلكِنَّ هذِهِ الصَّفْقَةَ خَسِرَتْ وَلَمْ تَربَحْ لأَنَّهُمْ بَاعُوا مَا وَهَبَهُمُ اللهُ مِنْ نُورٍ وَهُدًى، بِضَلاَلاَتِ البِدَعِ وَالأَهْوَاءِ، وَلَمْ يَهْتَدُوا فِي عَمَلِهِمْ هذا إِلى الحَقِّ وَالإِيمانِ والصَّوابِ.
