{ آمَنُواْ }  { ٱلصَّالِحَاتِ }  { ٱلصَّلاَةَ }  { وَآتَوُاْ }  { ٱلزَّكَاةَ }  (277) - يَمْدَحُ اللهُ تَعَالَى المُؤْمِنيِن المُصَدِّقِينَ بِمَا جَاءَهُمْ مِنْ رَبِّهِمْ، المُقِيمِينَ الصَّلاَةَ، وَعَامِلِي الصَّالِحَاتِ وَالمُزَكِّينَ، وَيُخْبرُ عَنْهُمْ أنَّهُ يَحْفَظُ لَهُمْ أَجْرَهُمْ، وَأنَّهُمْ لاَ خَوفٌ عَلَيهِمْ، وَلاَ هُمْ يَحْزَنُونَ عَلَى مَا فَاتَهُمْ فِي الدُّنيا.
