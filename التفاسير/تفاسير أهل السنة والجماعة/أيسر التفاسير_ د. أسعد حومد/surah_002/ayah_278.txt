{ يٰأَيُّهَا }  { آمَنُواْ }  { ٱلرِّبَا }  (278) - يَأمُرُ اللهُ تَعَالَى عِبَادَهُ المُؤْمِنينَ، المُصَدِّقِينَ بِمَا أَمَرَهُمْ بِهِ، بِالتَّقْوى، فَيَقُولُ لَهُمْ: اتَّقُوا اللهَ وَاتْرُكُوا مَا لَكُمْ عِنْدَ النَّاسِ مِنَ الرِّبا (أَيْ مَا يَزيدُ عَلَى رُؤُوسِ أَمْوالِكُمْ) إنْ كُنْتُمْ مُؤْمنينَ حَقّاً بِمَا شَرَّعَ اللهُ لَكُمْ مِنْ تَحْلِيلِ البَيْعِ، وَتَحْرِيمِ الرِّبا، وَغَيْرِ ذَلِكَ.
