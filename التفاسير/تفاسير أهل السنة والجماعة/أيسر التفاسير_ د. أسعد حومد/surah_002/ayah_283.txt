{ فَرِهَانٌ }  { أَمَانَتَهُ }  { ٱلشَّهَادَةَْ }  { آثِمٌ }  (283) - فَإِنْ كُنْتُمْ مُسَافِرِينَ وَتَدايَنْتُمْ بِدِينٍ إلى أجَلٍ مُعَيَّنٍ (مُسَمَّى)، وَلَمْ تَجِدُوا مَنْ يَكْتُبُ، أَوْ لَمْ تَجِدُوا أَدَواتِ الكِتَابَةِ، فَلْيَكُنْ مَقَامَ الكِتَابَةِ رَهْنٌ يُسَلِّمُهُ المَدِينُ إلى صَاحِبِ الحَقِّ، فَإذَا وَثِقَ بَعْضُكُمْ بِبَعْضٍ فَلاَ بَأسَ فِي ألاَّ تَكْتُبُوا، أوْ ألاَّ تُشْهِدُوا شَاهِدِينَ، وَلْيَتَّقِ المُؤْمِنُ الله رَبَّهُ، وَعَلَيْكُمْ أنْ لاَ تَكْتُمُوا الشَّهَادَةَ، وَأنْ لاَ تَمْتَنِعُوا عَنْ أدَائِهَا، إذا دُعِيتُم إلى أدَائِها، وَمَنْ يَفْعَلْ ذَلِكَ فَإنَّهُ يَكُونُ آثِمَ القَلْبِ، وَقَدِ ارْتَكَبَ إثْماً وَذَنْباً.  وَلاَ يَخْفَى عَلَى اللهِ مِنْ أعْمَالِكُمْ شَيءٌ.
