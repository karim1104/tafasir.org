{ بِآيَاتِنَا }  { لِقَآءِ }  { ٱلآخِرَةِ }  { فَأُوْلَـٰئِكَ }  (16) - وَأَمّا الذِينَ كَفَرُوا بِرَبِّهِمْ وَآياتِهِ وَكَذَّبُوا رُسُلَهُ، وَأَنْكَرُوا البَعْثَ والنُّشُورَ والحِسَابَ في الآخِرَةِ، فَيَكُونُونَ حَاضِرِينَ في العَذابِ لا يَغِيبُونَ عَنْهُ أبداً.  مُحْضَرُونَ - تُحْضِرُهُمُ المَلائِكَةُ إِلى العَذَابِ وَلاَ يَغِيبُونَ عَنْهُ أَبداً.
