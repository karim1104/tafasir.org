{ فَأَثَابَهُمُ }  { جَنَّاتٍ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  (85) - فَجَازَاهُمُ اللهُ عَلَى إِيمَانِهِمْ بِهِ وَبِرُسُلُهِ، وَعَلَى تَصْدِيقِهِمْ بِالحَقِّ، وَاعْتِرَافِهِمْ بِهِ بِإِدْخَالِهِمْ فِي رَحْمَتِهِ، وَإسْكَانِهِمْ فِي جَنَّاتٍ تَجْرِي فِي جَنَبَاتِهَا الأنْهَارُ، وَسَيَكُونُونَ فِيهَا خَالِدِينَ أبَداً وَذَلِكَ هُوَ الجَزَاءُ الذِي أعَدَّهُ اللهُ لِمَنْ أحْسَنَ عَمَلاً.
