{ آمَنُواْ }  { ٱلصَّلاَةَ }  { ٱلزَّكَاةَ }  { رَاكِعُونَ }  (55) - يَحُثُّ اللهُ تَعَالَى المُؤْمِنينَ عَلَى مُوَالاَةِ اللهِ وَرَسُولِهِ وَالمُؤْمِنينَ الصَّادِقِينَ، الذِينَ يُقِيمُونَ الصَّلاَةَ وَيُؤَدُّونَ زَكَاةَ أمْوَالِهِمْ، وَيُسَاعِدُونَ المُحْتَاجِينَ مِنَ الضُّعَفَاءِ وَالمَسَاكِينِ، وَهُمْ دَائِمُو الرُّكُوعِ للهِ.  (نَزَلْت هَذِهِ الآيَةُ فِي عُبَادَةَ بْنِ الصَّامِتِ حِينَ بَرِئ مِنْ مُوَالاةِ اليَهُودِ، وَرَضِيَ بِمُوَالاَةِ اللهِ وَرَسُولِهِ).
