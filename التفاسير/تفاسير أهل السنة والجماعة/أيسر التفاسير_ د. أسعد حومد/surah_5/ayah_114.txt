{ مَآئِدَةً }  { آخِرِنَا }  { وَآيَةً }  { ٱلرَّازِقِينَ }  (114) - وَلَمَّا عَلِمَ عِيسَى عَلَيْهِ السَّلاَمُ صِدْقَ نِيَّتِهِمْ، وَأَنَّهُمْ لاَ يُرِيدُونَ تَعْجِيزَهُ، وَلا اقْتراحَ الآيَاتِ عَلَيْهِ، دَعَا اللهُ تَعَالَى بِهَذَا الدُّعَاءِ الكَرِيمِ: فَقَالَ: يَا أللهُ، يَا مَالِكَ أَمْرِنَا وَمُتَوَلِّي تَرْبِيَتِنَا، أَنْزِلْ عَلَيْنَا مَائِدَةً مِنَ السَّمَاءِ يَرَاهَا هَؤُلاَءِ المُقْتَرِحُونَ بِأَبْصَارِهِمْ، وَتَتَغَذَّى بَهَا أبْدَانُهُمْ، وَتَكُونُ عِيداً خَاصّاً بنَا، مَعْشَرَ المُؤْمِنينَ، نُعَظِّمُهُ نَحْنُ وَمَنْ يَأْتِي بَعْدَنا، وَاجْعَلْهَا عَلاَمَةً مِنْ لَدُنْكَ تُرْشِدْ بِهَا القَوْمَ إلى صِحَّةِ دَعْوَتي، وَصِدْقِ نُبُوَّتِي، وَارْزُقْنَا رِزْقاً هَنِيئاً بِلاَ كُلْفَةٍ، وَلاَ تَعَبٍ، وَأَنْتَ خَيْرُ مَنْ رَزَقَ.  عِيداً - فَرَحاً وَسُرُوراً أَوَ يَوْماً نُعَظِّمُهُ.
