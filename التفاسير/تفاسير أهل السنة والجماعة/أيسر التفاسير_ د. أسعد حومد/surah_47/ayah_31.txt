{ ٱلْمُجَاهِدِينَ }  { ٱلصَّابِرِينَ }  { نَبْلُوَاْ }  (31) - أمَرَ اللهُ تَعَالى العِبَادَ بالإِيمَانِ وَبالجِهَادِ، وَبالأخْذِ بِمَا أمَرَهُمْ بِهِ، وَبالانْتِهَاءِ عَمَّا نَهَاهُمْ عَنْهُ، لِيَخْتَبِرَهُمْ وَيَكْشِفَ حَقِيقَتَهُم، فَيَظْهَرَ المُجَاهِدُونَ، الصَّابِرُونَ، وَالمُؤْمِنُونَ المُخْلِصُونَ، والمُسْتَسْلِمُونَ للهِ وَأمْرِهِ وَقَدَرِهِ، وَيَظْهَرَ المُتَشَكِّكُونَ النَّاكِلُونَ عَنِ الجِهَادِ، وَعَنِ القِيَامِ بِمَا أَمَرَ اللهُ بهِ.  لَنَبْلُوَنكُمْ - لَنْخْتَبِرنُكُمْ بِالتَّكَالِيفِ الشَّاقَّةِ.  نَبْلُو أخْبَارَكُمْ - نُظْهِرُهَا وَنَكْشِفُها.
