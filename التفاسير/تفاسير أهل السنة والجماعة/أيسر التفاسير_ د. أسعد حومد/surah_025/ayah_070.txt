{ َآمَنَ }  { صَالِحاً }  { فَأُوْلَـٰئِكَ }  { حَسَنَاتٍ }  (70) - إلا مَنْ تَابَ في الدُّنْيا، وأخْلَصَ التوبةَ وهوَ مُؤْمنٌ، وقدْ عَمِلَ الصالحاتِ، ورجَعَ إلى رَبِّهِ مُسْتَغْفِراً مُنِيباً، فإنَّ اللهَ تَعالى يتوبُ عليه، ويُحْسِنُ عاقِبَتَهُ، (وفي ذلك دَلالةٌ على صِحَّةِ توبةِ القَاتل)، وهؤلاءِ هُمُ المُؤمنونَ، كانُوا قبلَ إيْمَانِهِمْ يَعْمَلُونَ السَّيّئاتِ، فَحَوَّلَهُمُ اللهُ تَعالى إلى الحَسَناتِ، وأبْدَلَهُمْ مَكَانَ السَّيئاتِ الحَسَنَاتِ، واللهُ غفورٌ لذُنُوبِ عِبادِه، رَحيمٌ بِهمْ.  (وقيلَ بلْ مَعْنَاهُ: إِنَّ السَّيئاتِ السَّابِقةَ تَنْقلبُ بِنَفْسِ التَّوبَةِ إلى حَسَناتٍ).
