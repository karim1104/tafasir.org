{ يَوْمَئِذٍ }  { آمَنُواْ }  { ٱلصَّالِحَاتِ }  { جَنَّاتِ }  (56) - وَفِي ذَلِكَ اليَوْمِ يَكُونَ السُّلْطَانُ القَاهِرُ، والتَّصَرُّفُ المُطْلَقُ للهِ فَيَحْكُمُ بَيْنَ النَّاسِ بِعَدْلِهِ، فَلاَ يَظْلِمُ أَحَداً شَيْئاً، وَيَجْزِي الذين آ مَنُوا وَعَمِلُوا الصَّالِحَاتِ بِجِنَّاتٍ يَكُونُ لَهُمْ فِيْهَا نَعِيمٌ مُقِيمٌ دَائِمٌ.
