{ ۤ آيَاتِنَا }  { مُعَاجِزِينَ }  { أُوْلَـٰئِكَ }  { أَصْحَابُ }  (51) - أَمَّا الذينَ بَذَلُوا جُهْدَهُم فِي رَدِّ دَعْوَةِ اللهِ، والتَكْذِيبِ بِها، وَسَعَوْا فِي صَدِّ النَّاسِ عَنِ الدُّخُولِ فِي الإِسْلاَمِ، وَسَعَوْا فِي تَعْطِيلِ آيَاتِ اللهِ، وَمَنْعِها مِنْ أَنْ تَفْعَلَ مَفْعُولَها فِي القُلُوبِ، فَأُولَئِكَ أَهْلُ الجَحِيمِ، وإِنْ ظَنُّوا أَنَّهُمْ يُعْجِزُونَ الله وَيَفُوتُونَه هَرَباً.
