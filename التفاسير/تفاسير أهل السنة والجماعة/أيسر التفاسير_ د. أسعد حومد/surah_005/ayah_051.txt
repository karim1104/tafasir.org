{ يَـٰأَيُّهَا }  { آمَنُواْ }  { وَٱلنَّصَارَىٰ }  { ٱلظَّالِمِينَ }  (51) - يَنْهَى اللهُ تَعَالَى المُؤْمِنينَ عَنْ مُوَالاَةِ اليَهُودِ وَالنَّصَارَى، وَاتِّخَاذِهِمْ حُلَفاءَ لَهُمْ عَلَى أهْلِ الإِيمَانِ بِاللهِ وَرَسُولِهِ، وَيَقُولُ لَهُمْ إنَّ مَنْ يَتَّخِذُهُمْ نُصَرَاءَ وَحُلَفَاءَ وَأَوْلِيَاءَ مِنْ دُونِ اللهِ وَرَسُولِهِ، فَهُوَ مِنْهُمْ فِي التَّحَزُّبِ عَلى اللهِ وَرَسُولِهِ وَالمُؤْمِنينَ. وَإنَّ اللهَ وَرَسُولَهُ بَرِيئَانِ مِنْهُ. وَمَنْ يَتَولَّى أعْدَاءَ اللهِ فَهُوَ ظَالِمٌ، وَاللهُ لاَ يَهْدِيهِ إلى الخَيْرِ. وَاليَهُودُ وَالنَّصَارَى بَعْضُهُمْ أوْلِيَاءُ بَعْضٍ، وَلَمْ يَكُنْ لِلْمُؤْمِنينَ مِنْهُمْ وَلِيٌّ وَلاَ نَصِيرٌ.  الوَلاَيَةُ - التَّنَاصُرُ وَالمُحَالَفَةُ.
