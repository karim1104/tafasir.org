{ آمَنُواْ }  { وَٱلصَّابِئُونَ }  { وَٱلنَّصَارَىٰ }  { آمَنَ }  { صَالِحاً }  (69) - الذِينَ آمَنُوا بِاللهِ وَرَسُولِهِ صلى الله عليه وسلم (المُسْلِمُونَ)، وَالذِينَ هَادُوا (أهْلُ التَّوْرَاةِ)، وَالصَّابِئُونَ (وَهُمْ طَائِفَةٌ يَعْبِدُونَ النُّجُومَ، وَقيلَ بَلْ إنَّهُمْ يَعْبُدُونَ المَلاَئِكَةَ وَيَقْرَؤُونَ الزَّبُورَ)، وَالنَّصَارَى (أهْلُ الإِنْجِيلِ)، مَنْ أَخْلَصَ مِنْهُم الإِيمَانَ للهِ، وَمَنْ آمَنَ بِاليَومِ الآخَرِ، وَعَمِلَ عَمَلاً صَالِحاً يَرْضَاهُ اللهُ، فَلاَ خَوْفٌ عَلَيْهِمْ فِيمَا يَسْتَقْبِلُونَهُ مِنْ أهْوَالِ القِيَامَةِ، وَلا يَحْزَنُونَ عَلَى مَا تَرَكُوهُ وَرَاءَ ظُهُورِهِمْ مِنْ لَذَّاتِ الدُّنْيا وَعَيْشِهَا، بَعْدَ أنْ يُعَايِنوا مَا أكْرَمَهُمُ اللهُ بِهِ مِنْ جَزِيلِ الثَّوَابِ.  الصَّابِئُونَ - عُبَّادُ الكَوَاكِبِ أوْ عُبَّادُ المَلاَئِكَةِ.
