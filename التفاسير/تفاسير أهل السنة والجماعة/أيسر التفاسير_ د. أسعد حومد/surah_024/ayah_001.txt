{ أَنزَلْنَاهَا }  { وَفَرَضْنَاهَا }  { آيَاتٍ }  { بَيِّنَاتٍ }  (1) - يُنَبِّهُ اللهُ تَعَالَى عِبَادَه إِلَى الاعْتِنَاءِ بِهَذِهِ السُّورَةِ التي أَنْزَلَهَا عَلَى رَسُولِهِ الكَرِيم، وَقَدَّرَ فِيهَا الحُدُودََ والأَحْكَامَ عَلَى أَتَمَّ وَجْهٍ، وَبَيِّنَ فِيهَا أَدِلَّةَ التَّوْحِيدِ وَبَيِّنَاتِهِ الوَاضِحَةَ لِيُعِدَّهُم بِذَلِكَ إِلَى الهُدَى والاتِّعَاظِ، والعَمَلَِ بِمَا جَاءَ فِيهَا مِنْ أَوَامِرَ، والانْتِهَاءِ عَمَّا جَاءَ فِيهَا مِنْ نَوَاهٍ وَزَوَاجِرَ، لِتَتَحَقَّقَ لَهُم السَعَادَةُ في الدُّنْيَا والآخِرَةِ.  فَرَضْنَاها - أَوْجَبْنَا أَحْكَامَهَا عَلَيْكُم، أَوْ قَدَّرْنَاهَا.
