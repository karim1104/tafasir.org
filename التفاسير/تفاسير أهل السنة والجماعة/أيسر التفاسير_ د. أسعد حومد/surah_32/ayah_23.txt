{ آتَيْنَا }  { ٱلْكِتَابَ }  { لِّقَآئِهِ }  { َجَعَلْنَاهُ }  { ۤ إِسْرَائِيلَ }  (23) - يُخْبِرُ اللهُ تَعَالى رَسُولَه صلى الله عليه وسلم أَنَّهُ آتَى مُوسَى التَّوْرَاةَ (الكِتَابَ)، لِتَكُونَ هُدًى وعِظَةً لِبني إِسْرائيلَ، كَمَا آتَى عَبْدَهُ مُحَمَّداً القُرآنَ، وأَمَرهُ بأَلاَّ يَكُونَ في شَكٍّ وَرِيبَةٍ مِنْ صِحَّةِ مَا آتاهُ اللهُ مِنَ الكِتَابِ، فَمُحَمَّدٌ لَيْسَ بِدْعاً في الرُّسُلِ، فَقَدْ آتى اللهُ غَيْرَهُ مِنَ الأنبياءِ كُتُباً.  في مِرْيَةٍ - فِي شَكٍّ.  مِنْ لِقَائِهِ - مِنْ تَلَقِّيهِ إِيَّاهُ بِالرِّضَا وَالقَبُولِ.
