{ أَرَأَيْتَكَ }  { لَئِنْ }  { ٱلْقِيَامَةِ }  (62) - وَقَالَ إِبْلِيسُ لِلرَّبِّ الكَرِيمِ مُتَواقِحاً: أَلاَ تَرَى إلَى هذا الذِي شَرَّفْتَهُ وَكَرَّمْتَهُ عَلَيَّ فَإِنْ أَخَّرْتَنِي وَأَنْظَرْتَنِي إِلى يَوْمِ القِيَامَةِ، لأُضِلَّنَّ ذُرِّيَّتَهُ، وَلأُسَيْطِرَنَّ عَلَيْهِمْ، وَلأَحْتَوِيَنَّهُمْ إِلاّ قَليلاً مِنْهُمْ.  لأَحْتَنِكَنَّ - الاحْتِنَاكُ، لُغَةً، وَضْعُ شَيءٍ فِي حَنَكِ الدَّابَّةِ الأَسْفَلِ لِتُقَادَ بِهِ، أَيْ إِنَّهُ سَيَمْلِكُ نَاصِيَتَهُمْ، وَيُسَيْطِرُ عَلَيْهِمْ. أَوْ لأَسْتَأْصِلَنَّهُمْ بِالإِغْوَاءِ.
