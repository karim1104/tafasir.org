{ يٰقَوْمِ }  { رِسَالاَتِ }  { آسَىٰ }  { كَافِرِينَ }  (93) - وَبَعْدَ أَنْ نَزَلَ بِهِمْ عَذَابُ اللهِ وَدَمَارُهُ تَوَلَّى شُعَيْبٌ عَنْهُمْ، وَانْصَرَفَ عَنْ دِيَارِهِمْ، وَخَاطَبَهُمْ مُقَرِّعاً، فَقَالَ لَهُمْ: لَقَدْ نَصَحْتُ لَكُمْ يَا قَوْمِي، وَبَلَّغْتُكُمْ مَا أَرْسَلَنِي بِهِ رَبِّي إِلَيكُمْ، مِنْ دَعْوَةٍ إِلى عِبَادَةِ اللهِ، فَكَفَرْتُمْ وَاسْتَكْبَرْتُمْ، فَدَمَّرَكُمُ اللهُ، وَلِذَلِكَ فَإِنَّنِي لاَ يُمْكِنُ أَنْ آسَفَ وَأَحْزَنَ عَلَى قَوْمٍ جَحَدُوا بِوحْدَانِيَّةِ اللهِ، وَكَذَّبُوا رَسُولَهُ.  آسَى - أَحْزَنُ وَآسَفُ.
