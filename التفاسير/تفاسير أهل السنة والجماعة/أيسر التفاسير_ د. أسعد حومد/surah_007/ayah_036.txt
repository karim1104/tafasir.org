{ بِآيَاتِنَا }  { أُوْلَـٰئِكَ }  { أَصْحَابُ }  { خَالِدُونَ }  (36) - أَمَّا الذِينَ كَفَرُوا بِآيَاتِ اللهِ المُنَزَّلَةِ عَلَى أَحَدِ رُسُلِهِ، وَاسْتَكْبَرُوا عَنْ قَبُولِها، وَعَنِ اتِّبَاعِ مَا جَاءَ فِيهَا، وَعَنِ العَمَلِ بِمَا فِيهَا... فَهؤلاءِ سَيَكُونُونَ مِنْ أَصْحَابِ النَّارِ أَبداً، لاَ يَمُوتُونَ وَلاَ يَحْيَوْنَ (خَالِدِينَ أَبَداً).
