{ بِآيَةٍ }  { ٱلصَّادِقِينَ }  (106) - وَقَالَ فِرْعَونُ لِمُوسَى: لَسْتُ أُصَدِّقُكَ فِيمَا تَقُول، وَلَسْتُ أُعْطِيكَ مَا تَطْلُبُ، فَإِنْ كَانَ مَعَكَ بُرْهَانٌ وَحُجَّةٌ وَمُعْجِزَةٌ فَأَظْهِرْهَا لِنَراهَا، إِنْ كُنْتَ صَادِقاً فِيمَا تَقُولُ وَتَدَّعِي، مِنْ أَنَّ اللهَ رَبَّ العَالَمِينَ أَرْسَلَكَ إلَيْنَا.
