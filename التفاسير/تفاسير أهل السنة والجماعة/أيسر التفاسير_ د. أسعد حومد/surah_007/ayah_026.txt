{ يَابَنِيۤ ءَادَمَ }  { يُوَارِي }  { سَوْءَاتِكُمْ }  { آيَاتِ }  (26) - يَمْتَنُّ اللهُ تَعَالَى عَلَى عِبَادِهِ بِمَا جَعَلَ لَهُمْ مِنَ اللِّبَاسِ (وَهُوَ مَا يُلْبَسُ لِسَتْرِ العَوْرَةِ)، وَمِنَ الرِّيشِ (وَهُوَ مَا يُتَجَمَّلُ بِهِ ظَاهِراً). ثُمَّ يَقُولُ تَعَالَى لَهُمْ إنَّ خَشْيَةَ اللهِ، وَالخُوْفَ مِنْهُ، هُمَا أَفْضَلَ مَا يَكْسِبُهُ الإِنْسَانُ وَيَلْبَسُهُ.  وَذَلِكَ الذِي تَقَدَّمَ ذِكْرُهُ مِنَ النِّعَمِ بِإِنْزَالِ المَلاَبِسِ هُوَ مِنْ آيَاتِ اللهِ وَدَلاَئِلِ إِحْسَانِهِ وَفَضْلِهِ عَلَى بَنِي آدَمَ.  (وَقِيلَ بَلِ المَقْصُودُ بِلِبَاسِ التَّقْوَى - هُوَ مَا يُلْبَسُ مِنَ الدُّرُوعِ وَالمَغَافِرِ وَغَيْرِهَا مِمَّا يُتَّقَى بِهِ البَأْسُ فِي الحَرْبِ).  الرِّيشُ - لِبَاسُ الحَاجَةِ وَالزِّينَةِ.  أَنْزَلْنَا عَلَيْكُمْ - أَعْطَيْنَاكُمْ وَوَهَبْنَاكُمْ.  لِبَاسُ التَّقْوى - الإِيمَانُ وَثَمَرَاتُهُ.
