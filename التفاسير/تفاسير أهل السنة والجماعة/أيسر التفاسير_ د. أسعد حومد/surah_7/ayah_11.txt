{ خَلَقْنَاكُمْ }  { صَوَّرْنَاكُمْ }  { لِلْمَلاۤئِكَةِ }  { ٱلسَّاجِدِينَ }  (11) - يُنَبِّهُ اللهُ تَعَالَى النَّاسَ إِلَى شَرَفِ أَبِيهم آدَمَ، وَيُبَيِّنُ لَهُمْ عَدَاوَةَ إِبْلِيسَ لَهُمْ، وَيُذَكِّرُهُمْ بِأَنَّهُ خَلَقَ آدَمَ مِنْ طِينٍ، ثُمَّ بَعْدَ أَنْ صَوَّرَهُ نَفَخَ فِيهِ مِنْ رُوحِهِ، وَأَنَّهُ أَمَرَ المَلاَئِكَةَ بِالسُّجُودِ لآِدَمَ، تَكْرِيماً وَتَعْظِيماً، فَسَجَدُوا إِطَاعَةً لأَِمْرِ اللهِ، إِلاَّ إِبْلِيسَ فَإِنَّهُ رَفَضَ السُّجُودَ، وَتَمَرَّدَ عَلَى أَمْرِ رَبِّهِ.
