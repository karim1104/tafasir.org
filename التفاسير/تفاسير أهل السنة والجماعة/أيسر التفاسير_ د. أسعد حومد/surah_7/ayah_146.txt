{ آيَاتِي }  { آيَةٍ }  { بِآيَاتِنَا }  { غَافِلِينَ }  (146) - سَأَصْرِفُ عَنِ الهِدَايَةِ قُلُوبَ الذِينَ يَتَكَبَّرُونَ عَنْ طَاعَتِي، وَيَتَكَبَّرُونَ عَلَى النَّاسِ بِغَيرِ الحَقِّ، وَإِذا رَأَوْا آيَاتِ اللهِ لَمْ يُؤْمِنُوا بِها، وَإِذَا رَأَوْا طَرِيقَ الخَيْرِ تَنَكَّبُوا عَنْهُ، وَلَمْ يَتَّخِذُوهُ سَبيلاً، وَإِذَا رَأَوا سَبيلَ الضَّلاَلِ اتَّبَعُوهُ، وَقَدْ جَازَاهُمُ اللهُ تَعَالَى هَذا الجَزَاءَ لأَِنَّهُمْ كَذَّبُوا بِآيَاتِ اللهِ، وَغَفَلُوا عَنْهَا، فَأَضَلَُّهُمُ اللهُ، وَلَمْ يَهْدِهِمْ. فَكَمَا اسْتَكْبَرُوا بِغَيرِ الحَقِّ فَإِن اللهَ عَاقَبَهُمْ بِالإِذْلاَلِ وَبِالخَتْمِ عَلَى قُلُوبِهِمْ، وَبِإلقَاءِ الغِشَاوَةِ عَلَى أَعْيُنِهِمْ حَتَّى لاَ يَجِدَ الحَقُّ مَنْفَذاً لِلْوُصُولِ إِلَيها.
