{ ٱلسَّمَاوَاتِ }  { بِـآيَاتِ }  { أُوْلَـٰئِكَ }  { ٱلْخَاسِرُونَ }  (63) - وَاللهُ تَعَالَى هُوَ الحَافِظُ لِخَزَائِنِ السَّمَاوَاتِ والأَرْضِ، وَمُدَبِّرُهَا وَمَالِكُهَا وَمَالِكُ مفَاتِيحِهَا (مَقَالِيدِهَا) فَهُوَ المُتَصَرِّفُ بِكُلِّ شَيءٍ مَخْزُونٍ فِيهَا.  (وَقَدْ يَكُونُ المَعْنَى: وَللهِ تَعَالَى وَحْدَهُ تَصَارِيفُ أُمُورِ السَّمَاوَاتِ والأَرْضِ، فَلاَ يَتَصَرَّفُ فِيهِنَّ سِوَاهُ).  والذِينَ كَفَرُوا بِاللهِ وَبِآيَاتِ اللهِ وَحُجَجِهِ الدَّالَّةِ عَلَى وُجُودِهِ وَوحْدَانِيَّتِهِ تَعَالَى، أولئِكَ هُمُ الخَاسِرُونَ، الذِينَ خَسِرُوا أَنْفُسَهمْ وَأَهْلِيهِمْ.  المَقَالِيدُ - المَفَاتِيحُ والخَزَائِن، وَقِيلَ إِنَّهُ فَارِسِيٌ مُعَرَّبٌ.
