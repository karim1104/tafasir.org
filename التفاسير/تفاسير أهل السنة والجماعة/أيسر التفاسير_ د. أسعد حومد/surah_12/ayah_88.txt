{ يٰأَيُّهَا }  { بِبِضَاعَةٍ }  { مُّزْجَاةٍ }  (88) - فَذَهَبَ إِخْوَةُ يُوسُفَ إِلَى مِصْرَ، عَمَلاً بِوَصِيَّةِ أَبِيهِمْ، فَدَخَلُوا عَلَى يُوسُفَ، وَمَعَهُمْ بِضَاعَةٌ رَدِيئَةٌ (مُزْجَاةٌ) حَمَلُوهَا مَعَهُمْ لِيَدْفَعُوهَا ثَمَنَ المِيرَةِ التِي أَتَوْا يَطْلُبُونَهَا، وَقَالُوا لِيُوسُفَ: لَقَدْ مَسَّنَا وَأَهْلَنَا الضُرُّ وَالأَذَى، وَعَضَّنَا الجُوعُ، فَجِئْنَا بِهذِهِ البِضَاعَةِ الرَّدِيئَةِ نَطْلُبُ أَنْ تُعْطِينَا بِهَا شَيْئاً مِنَ المِيرَةِ، وَتَصدَّقْ عَلَيْنَا بِقَبُولِ هذِهِ البِضَاعَةِ الرَّديئَةِ ثَمَناً لِمِيرَتِنا، إِنَّ اللهَ يَجْزِي المُتَصَدِّقِينَ خَيْراً عَلَى عَمَلِهِمْ.  (وَقِيلَ إِنَّ المَعْنَى هُوَ: وَتَصَدَّقْ عَلَيْنَا بِرَدِّ أَخِينَا عَلَيْنَا، لأَِنَّهُمْ كَانُوا يُرِيدُونَ بِهذِهِ المَقَالَةِ رُؤْيَةَ الأَثَرِ الذِي تَتْرُكُهُ عَلَى مَلاَمِحِ وَجْهِهِ).  الضُّرُّ - الهُزَالُ مِنْ شِدَّةِ الجُوعِ.  بِبِضَاعَة مُزْجَاةٍ - بِأَثْمَانٍ رَدِيئَة كَاسِدَةٍ.
