{ يٰبُنَيَّ }  { رُؤْيَاكَ }  { ٱلشَّيْطَانَ }  { لِلإِنْسَانِ }  (5) - فَخَشِيَ يَعْقُوبُ أَنْ يُحَدِّثَ يُوسُفُ أَحَداً مِنْ إِخْوَتِهِ لأَِبِيهِ بِرُؤْيَاهُ هذِهِ فَيَحْسُدُوهُ عَلَيْهَا، وَيَأَخْذُوا فِي الكَيْدِ لَهُ لإِهْلاَكِهِ، لِذَلِكَ طَلَبَ إِليهِ أَنْ لاَ يَقُصَّ عَلَى أَحَدٍ مِنْ إِخْوَتِهِ شَيْئاً مِنْ رُؤْيَاهُ، مَخَافَةَ أَنْ يُغْرِيَهُمُ الشَّيْطَانُ بِالإِسَاءَةِ إِليهِ، لأَِنَّ الشَّيْطَانِ عَدُوٌّ للإِنْسَانِ، بَيِّنُ العَدَاوَةِ وَوَاضِحُها.
