{ رَاوَدتُّنَّ }  { حَاشَ }  { ٱمْرَأَتُ }  { ٱلآنَ }  { رَاوَدْتُّهُ }  { ٱلصَّادِقِينَ }  (51) - فَجَمَعَ المَلِكُ النِّسْوَةَ اللاَّتِي قَطَعْنَ أَيْدِيَهُنَّ، وَمَعَهُنَّ امْرَأَةُ العَزِيزِ التِي كَانَ يُوسُفُ فِي بَيْتِهَا، وَاتَّهَمَتْهُ بِمُرَاوَدَتِها عَنْ نَفْسِهَا، وَسَأَلَهُنَّ المَلِكُ عَنْ حَالِهِنَّ مَعَ يُوسُفَ، وَمَا اتَّهَمْنَهُ بِهِ مِنْ مُرَاوَدَتِهِ إِيَّاهُنَّ عَنْ أَنْفُسِهِنَّ (وَهُوَ إِنَّمَا يَقْصِدُ بِسُؤَالِهِ امْرَأَةَ العَزِيزِ). فَقُلْنَ: حَاشَ للهِ لَمْ نَعْرِفْ عَلَيْهِ سُوءاً، وَمَا عَرَفْنَا مِنْهُ إِلا طُهْراً وَعِفَّةً وَوَقَاراً. وَهُنَا اعْتَرَفَتْ امْرَأَةُ العَزِيزِ بِفِعْلِهَا، فَقَالَتْ لَقَدْ حَانَ الوَقْتُ لإِظْهَارِ الحَقِّ، وَجَلاَءِ مَا خَفِيَ، وَإِنَّهَا هِيَ التِي رَاوَدَتْ يُوسُفَ عَنْ نَفْسِهِ، وَهُوَ صَادِقٌ فِيمَا قَالَهُ مِنْ أَنَّهَا هِيَ التِي رَاوَدَتْهُ عَنْ نَفْسِهِ، فَاسْتَمْسَكَ بِعِصْمَتِهِ، وَأَنَّهُ هَرَبَ مِنْهَا نَحْوَ البَابِ.
