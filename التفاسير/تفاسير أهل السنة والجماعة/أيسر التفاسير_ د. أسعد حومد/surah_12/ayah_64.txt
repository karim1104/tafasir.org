{ آمَنُكُمْ }  { حَافِظاً }  { ٱلرَّاحِمِينَ }  (64) - فَقَالَ لَهُمْ أَبُوهُمْ: هَلْ أَنْتُمْ صَانِعُونَ بِهِ إِلاَّ كَمَا صَنَعْتُمْ بِأَخِيهِ يُوسُفَ مِنْ قَبْلُ؟ وَلَكِنَّ اللهَ خَيْرُ حَافِظٍ، وَأَنَا أَتَوَكَّلُ عَلَيهِ فِي حِفْظِ هذا الصَّغِيرِ لاَ عَلَى حِفْظِكُمْ، وَهُوَ أَرْحَمُ الرَّاحِمِينَ، سَيَرْحَمُ كِبَرِي وَضَعْفِي.
