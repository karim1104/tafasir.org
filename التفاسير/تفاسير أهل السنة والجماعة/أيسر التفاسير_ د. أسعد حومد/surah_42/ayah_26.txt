{ آمَنُواْ }  { ٱلصَّالِحَاتِ }  { ٱلْكَافِرُونَ }  (26) - وَيَسْتَجِيبُ الذِينَ آمَنُوا وَعَمِلُوا الأَعْمَالَ الصَّالِحَةَ لِدَعْوَةِ رَبِّهِمْ، وَهُوَ يَزِيدُهُمْ مِنْ فَضْلِهِ عَلَى مَطْلُوبِهِمْ إِذَا مَا دَعَوْهُ، أَمَّا الكَافِرُونَ فَلَهُمْ عَذَابٌ شَدِيدٌ يَوْمَ القِيَامَةِ، وَاللهُ تَعَالَى لاَ يَسْتَجِيبُ لِدُعَائِهِمْ (وَقِيلَ إِنَّ مَعْنَى { وَيَسْتَجِيبُ ٱلَّذِينَ آمَنُواْ } هُوَ: أَنَّ اللهَ تَعَالَى يَسْتَجِيبُ لِدُعَاءِ الذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ إِذَا دَعَوْهُ).
