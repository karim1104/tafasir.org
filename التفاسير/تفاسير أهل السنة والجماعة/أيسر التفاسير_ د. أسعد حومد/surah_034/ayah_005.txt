{ سَعَوْا }  { آيَاتِنَا }  { مُعَاجِزِينَ }  { أُوْلَـٰئِكَ }  (5) - أَمَّا الذِينَ كَفَرُوا بِرَبِّهِمْ، وَسَعَوْا فِي صَدِّ النَّاسِ عَنِ اتِّبَاعِ مَا دَعَتْهُمْ إِليهِ الرُّسُلُ مِنَ الإِيمَانِ، وَالعَمَلِ الصَّالِحِ، وَسُبُلِ الهُدَى، وَأَجْهَدُوا أَنْفُسَهُمْ فِي مُحَارَبةِ اللهِ وَرَسُولِهِ وَقُرآنِهِ... فَإِنَّ اللهَ سَيُعَذِّبُهُمْ فِي نَارِ جَهَنَّمَ عَذَاباً أَليماً.  مُعَاجِزينَ - مُسَابِقِينَ ظَانِّينَ أَنَّهُمْ يَفُوتُونَ اللهَ هَرَباً.  الرِّجْزَ - العَذَابُ الشَّديدُ المُؤْلِمُ.
