{ وَرُهْبَانَهُمْ }  { وَاحِداً }  { سُبْحَانَهُ }  (31) - اتَّخَذَ أهْلُ الكِتَابِ، مِنَ اليَهُودِ وَالنَّصَارَى، كِبَارَ رِجَالِ دِينِهِمْ أرْبَاباً وَمُشَرِّعِينَ، فَأحَلُّوا لَهُمُ الحَرَامَ، وَحَرَّمُوا عَلَيْهِمُ الْحَلاَلَ، فَاتَّبَعُوهُمْ فِي ذَلِكَ، وَهَذِهِ المُتَابَعَةُ هِيَ المَقْصُودَةُ بِقَوْلِهِ تَعَالَى: { ٱتَّخَذُوۤاْ أَحْبَارَهُمْ وَرُهْبَانَهُمْ أَرْبَاباً }؛ وَمِنْهُمْ مَنْ جَعَلَ للهِ وَلَداً عَبَدُوهُ مَعَ اللهِ، كَعُزَيْرٍ وَالْمَسِيحِ، لاَ إِلهَ غَيْرُ اللهِ، تَنَزَّهَ وَتَقَدَّسَ عَنِ الشِّرْكِ وَالْوَلَدِ وَالصَّاحِبَةِ، وَعَنِ النُّظَرَاءَ وَالأعْوَانِ، وَلاَ رَبَّ سِوَاهُ.  وَهُمْ لَمْ يُؤْمَرُوا بِذَلِكَ، وَإِنَّمَا أُمِرُوا بَأنْ يَعْبُدُوا اللهَ وَحْدَهُ لاَ شَرِيكَ لَهُ.  الأحْبَارُ - عُلَمَاءُ اليَهُودِ.  الرُّهْبَانُ - مُتَنَسِّكُو النَّصَارَى.  أرْبَاباً - أَطَاعُوهُمْ كَمَا يُطَاعُ الرَّبُّ.
