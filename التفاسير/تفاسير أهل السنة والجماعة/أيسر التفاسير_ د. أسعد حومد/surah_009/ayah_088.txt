{ آمَنُواْ }  { جَاهَدُواْ }  { بِأَمْوَالِهِمْ }  { وَأُوْلَـٰئِكَ }  { ٱلْخَيْرَاتُ }  (88) - إِذَا تَخَلَّفَ الْمُنَافِقُونَ عَنِ الجِهَادِ فَإِنَّ رَسُولَ اللهِ صلى الله عليه وسلم، وَالْمُؤْمِنِينَ جَاهَدُوا فِي سَبِيلِ اللهِ بِأَمْوَالِهِمْ وَأَنْفُسِهِمْ، وَهَؤُلاَءِ وَعَدَهُمُ اللهُ بِالْخَيْرَاتِ: فِي الدُّنْيَا بِتَحْقِيقِ النَّصْرِ، وَمَحْوِ الْكُفْرِ، وَإِعْلاَءِ كَلِمَةِ اللهِ، وَالتَّمَتُّعِ بِالْمَغَانِمِ، وَفِي الآخِرَةِ بِرِضَا اللهِ وَجَنَّاتِهِ.
