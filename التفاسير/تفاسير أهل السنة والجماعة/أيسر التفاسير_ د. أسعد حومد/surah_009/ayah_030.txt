{ ٱلنَّصَارَى }  { بِأَفْوَاهِهِمْ }  { يُضَاهِئُونَ }  { قَاتَلَهُمُ }  (30) - يَحُثُّ اللهُ تَعَالَى الْمُؤْمِنِينَ عَلَى قِتَالِ أهْلِ الْكِتَابِ مِنَ الْيَهُودِ وَالنَّصَارَى لِقَوْلِهِمْ عَلَى اللهِ غَيْرَ الْحَقِّ، إذِ ادَّعَى الْيَهُودُ أنَّ عُزَيْراً ابْنُ اللهِ، وَادَّعَتِ النَّصَارَى أنَّ الْمَسِيحَ ابْنُ اللهِ، وَهُمْ يَقُولُونَ ذَلِكَ بِأفْوَاهِهِمْ، وَلاَ سَنَدَ لَهُمْ فِيمَا ادَّعُوهُ سِوَى افْتِرَائِهِمْ وَاخْتِلاَقِهِمْ، وَهُمْ يُشَابِهُونَ فِي قَوْلِهِمْ هَذَا قَوْلَ الَّذِينَ كَفَرُوا قَبْلَهُمْ مِنَ الأُمَمِ الَّتِي ضَلَّتْ كَمَا ضَلَّ هَؤُلاَءِ، قَاتَلَهُمُ اللهُ وَلَعَنَهُمْ، كَيْفَ يَضِلُّونَ عَنِ الحَقِّ، وَهُوَ ظَاهِرٌ، وَكَيْفَ يُصْرَفُونَ عَنْهُ إِلَى الْبَاطِلِ؟  يُضَاهِئُونَ - يُشَابِهُونَ فِي الكُفْرِ وَالقَوْلِ.  أنَّى يُؤْفَكُونَ - كَيْفَ يُصْرَفُونَ عَنِ الحَقِّ بَعْدَ سُطُوعِهِ؟
