{ ٱلْمَلاَئِكَةُ }  { يٰمَرْيَمُ }  { ٱصْطَفَاكِ }  { ٱلْعَالَمِينَ }  (42) - وَاذْكُرْ يَا مُحَمَّدُ لِقَوْمِكَ حِينَ قَالَتِ المَلاَئِكَةُ: يَا مَرْيَمُ إنَّ اللهَ اخْتَارَكِ لِتكُوني أمّاً لِنَبِيّهِ عِيسَى، لِكَثْرَةِ عِبَادَتِكِ وَزُهْدِكِ وَطَهَارَتِكِ، وَاصْطَفَاكِ عَلَى نِسَاءِ العَالَمِينَ.
