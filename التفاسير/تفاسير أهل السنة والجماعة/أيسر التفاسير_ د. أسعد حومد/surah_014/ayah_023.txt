{ آمَنُواْ }  { ٱلصَّالِحَاتِ }  { جَنَّاتٍ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  { سَلاَمٌ }  (23) - أَمَّا المُؤْمِنُونَ الذِينَ آمَنُوا بِرَبِّهِمْ وَكُتُبِهِ، وَرُسُلِهِ، وَعَمِلُوا فِي الدُّنْيَا الأَعْمَالَ الصَّالِحَةَ، وَأَخْلَصُوا العِبَادَةَ للهِ، فَإِنَّ اللهَ سَيُدْخِلُهُمْ جَنَّاتٍ تَجْرِي المِيَاهُ فِي جَنَبَاتِهَا، لِيَكُونُوا فِيهَا خَالِدِينَ أَبَداً، لاَ يَحُولُونَ عَنْهَا وَلا يَزُولُونَ، بِإِذْنِ رَبِّهِمْ، وَتَوْفِيقِهِ إِيَّاهُمْ إِلى الإِيمَانِ، وَفِعْلِ الخَيْراتِ وَتُحْيِّيهِمُ المَلاَئِكَةُ فِيهَا قَائِلِينَ لَهُمْ: سَلاَمٌ عَلَيْكُمْ.
