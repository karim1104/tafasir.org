{ يَسْتَأْذِنُكَ }  { ٱلآخِرِ }  { يُجَاهِدُواْ }  { بِأَمْوَالِهِمْ }  (44) - لاَ يَسْتَأْذِنُكَ، فِي القُعُودِ عَنِ الجِهَادِ، أَحَدٌ يٌؤْمِنُ بِاللهِ وَرَسُولِهِ، لأِنَّهُمْ يَرَوْنَ الجِهَادَ قُرْبَةً إِلَى اللهِ، وَإِذَا نَدَبَهُمُ النَّبِيُّ إِلَيْهِ بَادَرُوا مُمْتَثِلِينَ، وَاللهُ يَعْلَمُ مَنْ هُمُ الْمُتَّقُونَ الذِينَ يَخْشَوْنَ اللهَ، وَيَطْلُبُونَ مَرْضَاتِهِ، وَيُعِدُّونَ لِلْجِهَادِ عُدَّتَهُ.
