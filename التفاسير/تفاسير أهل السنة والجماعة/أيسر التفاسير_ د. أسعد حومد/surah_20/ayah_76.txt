{ جَنَّاتُ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  (76) - وَهذِهِ الدَّرَجَاتُ العُلاَ، هِيَ جَنَّاتُ إِقَامَةٍ (عَدْنٍ)، تَنْسَابُ فِيهَا الأَنْهَارُ، وَيَبْقَوْنَ فِيهَا مَاكِثِينَ أَبَداً، وَهَذا جَزَاءُ مَنْ طَهَّرَ نَفْسَهُ مِنَ الدَّنَسِ وَالخَبَثِ وَالشِّرْكِ، وَعَبدَ اللهَ وَحْدَهُ لاَ شَرِيكَ لَهُ، وَاتَّبَعَ المُرْسَلِينَ فِيمَا جَاؤُوا بِهِ.  تَزَكَّى - تَطَهَّرَ مِنْ دَنَسِ الشِّرْكِ.
