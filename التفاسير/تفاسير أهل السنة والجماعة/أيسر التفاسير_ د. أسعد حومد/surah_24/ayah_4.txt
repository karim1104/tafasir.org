{ ٱلْمُحْصَنَاتِ }  { ثَمَانِينَ }  { شَهَادَةً }  { وَأُوْلَـٰئِكَ }  { ٱلْفَاسِقُونَ }  (4) - فِي هَذِهِ الآيَةِ يُبَيِّنُ اللهُ تَعَالَى حُكْمَ الذينَ يَتَّهِمُونَ المُحَصَنَاتِ العَفِيفَاتِ بالزِّنَا (وَهُنَّ الحَرَائِرُ البَالِغَاتُ العَفِيفَاتُ). وإِذَا كَانَ المَقْذُوفُ رَجُلاً يُجْلَدُ قَاذِفُه أيضاً. فَإِذَا أَقَامَ القَاذِفُ البَيِّنَةَ عَلَى صِحَّةِ قَوْلِهِ، دَرَأ ذَلِكَ الحَدَّ عَنْهُ. فَإِذَا لَمْ يَأتِ القَاذِفُ بِأَرْبَعَةِ رِجَالٍ يَشْهَدُونَ عَلَى صِحَّةِ مَا قَالَهُ، وَيُثْبِتُونَ صِحَّةَ دَعْوَاهُ، فَإِنَّهُ يُحْكَمُ عَلَيهِ بِثَلاَثِ عُقُوبَاتٍ:  - يُجْلَدُ ثَمَانِينَ جَلْدَةً.  - تُرَدُّ شَهَادَتُهُ.  - يُعَدُّ فَاسِقاً لَيْسَ بِعَدْلٍ لاَ عِنْدَ اللهِ وَلاَ عِنْدَ النَّاسِ.  يَرْمُونَ المُحْصَنَاتِ - يَقْذِفُونَ العَفِيفَاتِ بِالزِّنَى.
