{ وَيَدْرَؤُاْ }  { شَهَادَاتٍ }  { ٱلْكَاذِبِينَ }  (8) - وَلاَ يَدْرَأُ عَنْهَا إِقَامَةَ حَدِّ الزِّنى عَلَيْهَا (وَهُوَ الرَّجْمُ) إِلاَّ أَنْ تُلاَعِنَ، فَتَشْهَدَ أَرْبَعَ شَهَادَاتٍ باللهِ عَلَى أَنَّ زَوْجَها مِنَ الكَاذِبِينَ فِيمَا رَمَاهَا بِهِ مِن الزِّنَى.  يَدْرأُ عَنْهَا العَذَابَ - يَدْفَعُ عَنْهَا عُقُوبَةَ الرَّجْمِ.
