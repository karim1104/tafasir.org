{ ٱلسَّمَاوَاتِ }  { آمَنُواْ }  { بِٱلْبَاطِلِ }  { أُوْلَـٰئِكَ }  { ٱلْخَاسِرُونَ }  (52) - وقُلْ لَهُم حَسْبِي وَحَسْبُكُمْ أَنْ يكُونَ اللهُ تَعَالى عَالِماً بِمَا صَدَرَ مِني مِنْ تَبليغِ رِسَالاَتِهِ، وَنُذُرِهِ إِليكُمْ، وَبِمَا صَدَرَ مِنْكُمْ مِنْ مُقَابَلةِ ذلكَ بالتَّكَذِيبِ والجُحُودِ، وهُوَ يَجزِي كُلاًّ بِمَا يَسْتَحِقٌّهُ. وإِني لَوْ كُنتُ كَاذِباً لانتَقَمَ مِني. وَلكِنِّي صَادِقٌ فيمَا أقُولُهُ عَن رَبّي، وَلِذَلِكَ فَإِنَّهُ يُؤَيِّدُني بالمُعْجِزَاتِ والدَّلاَئِلِ عَلَى صِدْق نُبُوَّتي، وَهُوَ تَعَالَى يَعْلَمُ جَمِيعَ مَا في السَّماوَاتِ والأَرضِ، وَيَعْلَمُ مَا تَنْسُبُونَهُ إِلَيَّ مِنَ التَّقَوُّل عليهِ. والذين َيَعبُدُونَ الأَوثَانَ والأَصْنَامَ، وَيَكْفُرُونَ باللهِ، مَعَ تَظَاهُرِ الأَدِلَّةِ عَلَى وُجُوبِ الإِيمانِ بِهِ، ويَكْفُرُونَ بِرَسُولِهِ مَعَ تَعَاضُدِ البَراهينِ عَلَى صِدْقِهِ، فَهَؤُلاءِ هُمُ الأَخْسَرُونَ أَعْمَالاً، وَسَيلْقَوْنَ جَزَاءَهُمْ يَوْمَ القِيَامَةِ.
