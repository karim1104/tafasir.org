{ لَئِن }  { ٱلسَّمَاوَاتِ }  (61) - وَلئِنْ سَأَلتَ هَؤُلاَءِ المُشْرِكِينَ بِاللهِ: مَنْ خَلَقَ السَّمَاوَاتِ والأَرضَ فَسَوَّاهُنَّ، وَسَخَّرَ الشَّمسَ والقَمَرَ يَجْرِيَانِ دَائِبَيْنِ لِمَصَالِحِ خَلْقِهِ؟ لَيَقُولُنَّ: الذِي خَلَقَ ذَلكَ كُلَّهُ هُوَ اللهُ سُبْحَانَهُ وَتَعَالَى، وَلاَ يَذكُرُونَ أحداً سِوَاهُ.  وإِذا كَانُوا قَدِ اعْتَرَفُوا بأَنَّ اللهَ هُوَ الخَالِقُ لِكُلِّ شَيءٍ، فَكَيفَ يُصْرَفُونَ عَنِ الهُدى والحَقِّ، وَعِبَادَةِ اللهِ وَحْدَهُ لا شَرِيكَ له؟  فَأَنَّى يُؤْفَكُونَ - فَكَيْفَ يُصْرَفُونَ عَن تَوْحِيدِهِ.
