{ أَرَأَيْتُمْ }  { ٱلسَّمَاوَاتِ }  { آتَيْنَاهُمْ }  { كِتَاباً }  { بَيِّنَةٍ }  { ٱلظَّالِمُونَ }  (40) - قلْ يَا مُحَمَّدُ لِهؤلاَءِ المُشْرِكينَ: أَخْبِرُونِي، أَيُّها المُشْرِكُونَ بِاللهِ، عَنْ شُرَكَائِكُمُ الذِينَ تَدْعُونَهُمْ مِنْ دُونِ اللهِ، مِنَ الأَصْنَامِ والأَوْثَانِ: أَيُّ شيءٍ خَلَقُوهُ مِنَ السَّمَاوَاتِ وَمِنَ الأَرْضِ، أَوْ مِنَ البَشَرِ وَالمَخْلُوقَاتِ حَتَّى استَحَقُّوا أَنْ يَكُونُوا آلِهَةً تَعْبُدُونَهُمْ؟ أَمْ هَلْ لَهُمْ شَرِكَةٌ مَعَ اللهِ فِي خَلْق السَّمَاوَاتِ حَتَّى اسْتَحَقُّوا مَا زَعَمْتُمْ؟  أَمْ أَنَّ اللهَ أَنْزَلَ عَلَيهِمْ كِتَاباً يَقُولُ لَهُمْ فِيهِ إِنَّ اللهَ تَعَالى اتَّخَذَ هذِهِ المَعْبُودَاتِ شُرَكَاءَ لَهُ فِي الأُلُوهِيَّةِ، فَكَانَ ذَلِكَ الكِتَابُ حُجَّةً لِلْمُشْرِكِينَ عَلَى أَنَّ مَعْبُودَاتِهِمْ لَهَا شَرِكَةٌ مَعَ اللهِ؟ وَفِي الحَقِيقَةِ إِنَّهُمْ إِنَّما اتَّبَعُوا فِي ذَلِكَ أَهْوَاءَهُمْ، وَأَمَانِيِّهُم التِي تَمَنَّوها لأَِنْفُسِهِمْ، وَهِيَ غُرُورٌ وَبَاطِلٌ وَزورٌ.  أَرَأَيْتُم شُرَكَاءَكُمْ - أَخْبِرُوني عَنِ شُرَكَائِكُمْ.  أَمْ لَهُمْ شِرْكٌ - بَلْ أَلَهُمْ شَركَةٌ مَعَ اللهِ فِي الخَلْقِ.  غُرُوراً - خِدَاعاً وَبَاطِلاً.
