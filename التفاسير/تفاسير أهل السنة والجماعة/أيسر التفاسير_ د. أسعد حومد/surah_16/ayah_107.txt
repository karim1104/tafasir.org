{ ٱلْحَيَاةَ }  { ٱلآخِرَةِ }  { ٱلْكَافِرِينَ }  (107) - وَذَلِكَ الغَضَبُ مِنَ اللهِ، وَذَلِكَ العَذَابُ العَظِيمُ، إِنَّمَا اسْتَحَقَّهُ هؤُلاَءِ لأَِنَّهُمْ آثَرُوا الحَيَاةَ الدُّنْيا وَزِينَتَهَا عَلَى نَعيمِ الآخِرَةِ، وَإِنَّ اللهَ لاَ يُوَفِّقُ مَنْ يَجْحَدُ آيَاتِهِ، وَيُصِرُّ عَلَى إِنْكَارِها، لأَِنَّهُ يَكُونُ قَدْ فَقَدَ الاسْتِعْدَادَ لِسُبُلِ الخَيْرِ بِمَا زَيَّنَتْ لَهُ نَفْسُهُ مِنَ الكُفْرِ.  اسْتَحَبُّوا - اخْتَارُوا أَوْ آثَرُوا.
