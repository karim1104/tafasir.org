{ آمَنُواْ }  { وَٱلصَّابِئِينَ }  { وَٱلنَّصَارَىٰ }  { ٱلْقِيامَةِ }  (17) - يُخْبِرُ اللهُ تَعَالَى أَنَّهُ سَيَفْصِلُ يَوْمَ القِيَامَةِ بَيْنَ أَهْلِ الأَدْيَانِ المُخْتَلِفَةِ: مِنَ المُؤْمِنِينَ واليَهُودِ والنَّصَارَى وَغَيْرِهِمْ مِمَّنْ عَدَّدَهُمْ، وأَنَّهُ سَيَحْكُمْ بَيْنَهُمْ بالعَدْلِ، فَيُدْخِلُ مَنْ آمَنَ مِنهم بِهِ الجَنَّةَ، وَيُدْخِلُ مَنْ كَفَرَ مِنْهُمْ بِهِ النَّارَ، وأنَّهُ تَعَالَى شَهِيدٌ عَلَى أَفْعَالِهِمْ جَمِيعِهَا، حَفِيظٌ لأَِقْوَالِهِم، عَلِيمٌ بِسَرَائِرِهِم وَضَمَائِرِهِمْ.  الصَّابِِئِينَ - عَبَدَةَ الكَوَاكِبِ أَوْ عَبَدَةَ المَلاَئِكَةِ.
