{ جَآءُوهَا }  { أَبْوَابُهَا }  { سَلاَمٌ }  { خَالِدِينَ }  (73) - وَيُوِجَّهُ المُتَّقُونَ إِلَى الجَنَّةِ جَمَاعَاتٍ إِثْرَ جَمَاعَاتٍ: المُقَرَّبُونَ، ثُمَّ الأَبْرَارُ، ثُمَّ الذِينَ يَلُونَهُمْ، ثُمَّ الذِينَ يَلُونَهُمْ.. فَإِذَا وَصَلُوا الجَنَّةَ تُفْتَحُ لَهُمْ أَبْوَابُهَا لاسْتِقْبَالِهِمْ، وَيَسْتَقْبِلُهُمْ حُرَّاسُهَا (خَزَنَتُهَا) بالتَّحِيةِ وَالسَّلاَمِ، وَيَقُولُونَ لَهُمْ: طَابَتْ أَعْمَالُكُمْ وَأَقْوَالُكُمْ، وَطَابَ سَعْيُكُمْ وَجَزَاؤُكُمْ، فَادْخُلُوا الجَنَّةَ لِتَمْكُثُوا فِيهَا خَالِدِينَ أَبَداً.  طِبْتُمْ - طَهُرْتُمْ مِنْ دَنَسِ الكُفْرِ والمَعَاصِي.
