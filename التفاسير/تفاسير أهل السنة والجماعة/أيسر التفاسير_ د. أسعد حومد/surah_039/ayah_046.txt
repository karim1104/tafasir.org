{ ٱلسَّمَاوَاتِ }  { عَالِمَ }  { ٱلشَّهَادَةِ }  (46) - فَادْعُ يَا مُحَمَّدُ اللهَ وَحْدَهُ، فَاطِرَ السَّمَاوَاتِ والأَرْضِ، وَمُبْدِعَهُمَا عَلَى غَيْرِ مِثَالٍ سَبَقَ، عَالِمَ السِّرِّ والعَلاَنِيةِ، وَقُلِ: اللَّهُمَّ أَنْتَ تَحْكُمُ بَيْنَ عِبَادِكَ، فَتَفْصِلُ بَيْنَهُمْ بالحَقِّ يَوْمَ القِيَامَةِ فِيمَا كَانُوا يَخْتَلِفُونَ فِيهِ فِي الدُّنْيَا، فَاحْكُمْ بَيْنِي وَبَيْنَ هَؤُلاَءِ المُشْرِكِينَ المُكَذِّبِينَ.  فَاطِرَ - مُبْدِعَ وَمُخَتَرِعَ وَخَالِقَ.
