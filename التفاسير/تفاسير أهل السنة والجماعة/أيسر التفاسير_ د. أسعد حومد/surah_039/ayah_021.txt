{ يَنَابِيعَ }  { أَلْوَانُهُ }  { فَـتَرَاهُ }  { حُطَاماً }  { ٱلأَلْبَابِ }  (21) - يُشَبِّهُ اللهُ تَعَالَى حَالَ الدُّنْيَا فِي نَضْرَتِهَا وَسُرْعَةِ انْقِضَائِها بِحَالِ المَاءِ الذِي يَنْزِلُ مِنَ السَّمَاءِ فَيَجْرِي عُيوناً فِي الأَرْضِ فَتُسْقَى بِهَذَا الماءِ الأَرضُ فَتنبِتُ الزَّرعَ والنَّبَاتَ والخُضْرَةَ من كُلِّ لونٍ، وَتُصْبِحُ الأََرضُ خَضِرَةً نَضِرَةً، ثُمَّ لا يَلْبَثُ هذا النَّبَاتُ أَنْ يَنْضجَ وَيَجِفَّ وَيَصْفَرَّ، ثُمَّ يُصْبحَ يَابساً يَتَكسَّرُ. وفي كُلِّ ذَلِكَ عِظَةٌ وعِبْرَةٌ لِذَوي العُقُولِ السَّليمةِ تُنَبِّهُهُمْ إِلى عَدَمِ الاغترارِ بالدُّنيا وزُخْرُفِهَا ونَعِيمِهَا الزَّائِلِ.  سَلَكَهُ يَنَابِيعَ - أَدْخَلَهُ فِي عُيونٍ وَمَجَارٍ.  يَهِيجُ - يَنْضُجُ وَيَجِفُّ.  يَجْعَلُهُ حُطَاماً - يُصَيِّرُهُ هَشِيماً مُحَطَّماً مُفَتَّتاً.
