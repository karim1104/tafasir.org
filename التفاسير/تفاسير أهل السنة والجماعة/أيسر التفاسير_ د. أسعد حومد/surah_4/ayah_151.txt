{ أُوْلَـٰئِكَ }  { ٱلْكَافِرُونَ }  { لِلْكَافِرِينَ }  (151) - يَقُولُ تَعَالى إنَّ هَؤُلاءِ، الذِينَ يُفَرِّقُونَ بَيْنَ اللهِ وَبَيْنَ رُسُلِهِ، وَيَقُولُونَ نُؤْمِنُ بِبَعْضٍ وَنَكْفُرُ بِبَعْضٍ، هُمُ الكَافِرُونَ المُمْعِنُونَ فِي الكُفْرِ، وَقَدْ أَعَدَّ اللهُ لِلْكَافِرِينَ عَذَاباً مُهِيناً، عِقَاباً لَهُمْ عَلَى اسْتِهَانَتِهِمْ بِأوَامِرِ رَبِّهِمْ.
