{ آمَنُواْ }  { ٱلصَّالِحَاتِ }  { جَنَّاتٍ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  (122) - بَعْدَ أَنْ بَيَّنَ اللهُ تَعَالَى حَالَ أتْبَاعِ الشَّيْطَانِ، ثَنَّى بَبَيَانِ حَالِ المُؤْمِنِينَ السُّعَدَاءِ، الذِينَ لاَ يَسْتَجِيبُونَ لِدَعْوَةِ الشَّيْطَانِ، وَلاَ يَمْتَثِلُونَ لأمْرِهِ، وَمَا لَهُمْ مِنَ الكَرَامَةِ التَّامَّةِ يَوْمَ القِيَامَةِ، فَقَالَ تَعَالَى: إنَّ الذِينَ آمَنُوا وَصَدَّقَتْ قُلُوبُهُمْ، وَعَمِلَتْ جَوَارِحُهُمْ بِمَا أمِرُوا بِهِ مِنَ الخَيْرَاتِ، وَتَرَكُوا مَا نُهُوا عَنْهُ مِنَ المُنْكَرَاتِ، سَيُدْخِلُهُمْ رَبُّهُمْ جَنَّاتٍ تَجْرِي فِيها الأنْهَارُ، وَيَكُونُونَ خَالِدِينَ فِيهَا أبَداً، وَهُوَ وَعْدٌ حَقٌّ مِنَ اللهِ، وَاللهُ هُوَ القَادِرُ عَلَى أَنْ يُعْطِيَ مَا وَعَدَ بِفَضْلِهِ وَجُودِهِ، وَلَيْسَ أحَدٌ أصْدَقَ قَوْلاً مِنَ اللهِ.
