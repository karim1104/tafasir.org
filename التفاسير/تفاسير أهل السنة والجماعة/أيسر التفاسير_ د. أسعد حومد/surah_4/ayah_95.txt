{ ٱلْقَاعِدُونَ }  { وَٱلْمُجَاهِدُونَ }  { بِأَمْوَالِهِمْ }  { ٱلْمُجَاهِدِينَ }  { ٱلْقَاعِدِينَ }  (95) - يُبَيِّنُ اللهُ تَعَالَى لِلنَّاسِ مَا لِلْمُجَاهِدِينَ فِي سَبيلِ اللهِ، بِأمْوَالِهِمْ وَأنْفُسِهِمْ، مِنْ عَظِيمِ الأجْرِ وَالمَغْفِرَةِ وَالدَّرَجَاتِ الكَرِيمَةِ عِنْدَ رَبِّهِمْ، فَقَالَ تَعَالَى: إنَّ القَاعِدِينَ عَنِ الجِهَادِ - إذا كَانُوا غَيْرَ مَعْذُورِينَ، وَغَيْرَ ذَوِي عِلَّةٍ وَضَرَرٍ - لاَ يَسْتَوُونَ مَعَ المُجَاهِدِينَ بِأمْوَالِهِمْ وَأنْفُسِهِمْ، وَإنَّ اللهَ فَضَّلَ المُجَاهِدِينَ عَلَى القَاعِدِينَ، وَخَصَّهُمْ بِدَرَجَاتٍ عَظِيمةٍ، وَأجْر كَبير، وَإنْ كَانَ تَعَالَى قَدْ وَعَدَ القَاعِدِينَ عَنِ الجِهَادِ عَجْزاً، مَعَ تَمَنِّي القُدْرَةِ عَليهِ، كَمَا وَعَدَ المُجَاهِدِينَ، بِالخَيْرِ وَالمَثُوبَةِ وَالعَفْوِ وَالمَغْفِرَةِ لأنَّ كُلاً مِنْهُمْ كَامِلُ الإِيمَانِ، مُخْلِصٌ للهِ فِي العَمَلِ.  أولي الضَّرَرِ - أرْبَابِ الأعْذارِ المَانِعَةِ مِنَ الجِهَادِ.
