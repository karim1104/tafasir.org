{ يٰشُعَيْبُ }  { أَصَلَٰوتُكَ }  { ءابَاؤُنَآ }  { أَمْوَالِنَا }  { نَشَاءُ }  (87) - قَالُوا عَلَى سَبِيلِ التَّهَكُّمِ وَالسُّخْرِيَةِ: يَا شُعَيْبُ هَلْ صَلاَتُكَ وَإِيمَانُكَ بِرَبِّكَ يَأْمُرَانِكَ بِأَنْ تَدْعُوَنَا إِلى تَرْكِ مَا كَانَ يَعْبُدُ آبَاؤنا مِنْ أَصْنَامٍ وَأَوْثَانٍ، أَوْ أَنْ تَمْنَعَنَا عَنِ التَّصَرُّفِ فِي أَمْوَالِنَا بِمَا يُنَاسِبُ مَصْلَحَتِنَا مِنَ الحِذْقِ وَالخَدِيعَةِ، وَبِالشَّكْلِ الذِي نُرِيدُ؟ إِنَّ هذا غَايَةُ السَّفَهِ. أَهَذا أَنْتَ الحَليمُ المُكْتَمِلُ العَقْلِ (الرَّشِيدُ)؟
