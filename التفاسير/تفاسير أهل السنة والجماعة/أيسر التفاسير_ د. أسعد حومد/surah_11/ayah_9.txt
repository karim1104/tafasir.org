{ وَلَئِنْ }  { ٱلإِنْسَانَ }  { نَزَعْنَاهَا }  { لَيَئُوسٌ }  (9) - يُخْبِرُ اللهُ تَعَالَى عَمَّا فِي نُفُوسِ البَشَرِ مِنَ الصِّفَاتِ الذَمِيمَةِ، إِلاّ مَنْ رَحِمَ اللهُ، فَإِذَا أَصَابَتْهُمْ شِدَّةٌ بَعْدَ نِعْمَةٍ، اعْتَرَاهُمُ اليَأْسُ وَالقُنُوطُ مِنْ أَنْ يُفْرِّجَ اللهُ عَنْهُمْ مَا هُمْ فِيهِ مِنْ شِدَّةٍ فِي المُسْتَقْبَلِ، وَكَفَرُوا بِنِعَمِ اللهِ وَفَضْلِهِ.  لَيَؤُوسٌ - شَديدُ اليَأْسِ وَالقُنُوطِ.  كَفُورٌ - كَثيرُ الكُفْرَانِ بِالنِّعْمَةِ.
