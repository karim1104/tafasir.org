{ فَكَذَّبُوهُ } يعني : صالحاً بالعذاب { فَعَقَرُوهَا } يعني : فعقروا الناقة ،   ويقال : في الآية تقديم فعقروها ،   فخوفهم صالح عليه السلام بالعذاب ،   فكذبوه .   ثم قال عز وجل : { فَدَمْدمَ عَلَيْهِمْ رَبُّهُمْ } يعني : أنزل عليهم ربهم عقوبة { بِذَنبِهِمْ } والدَّمْدَمة ،   المبالغة في العقوبة والنكال .  <br />
ثم قال : { فَسَوَّاهَا } يعني : فسواها في الهلاك يعني : الصغير والكبير .  <br />
