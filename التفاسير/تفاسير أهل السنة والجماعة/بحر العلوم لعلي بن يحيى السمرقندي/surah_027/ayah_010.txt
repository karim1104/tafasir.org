قوله عز وجل : { وَأَلْقِ عَصَاكَ } يعني : من يدك فألقاها ،   فصارت حية ،   وقد يجوز أن يضمر الكلام إذا كان في ظاهره دليل { فَلَمَّا رَءاهَا تَهْتَزُّ } يعني : تتحرك { كَأَنَّهَا جَانٌّ } يعني : حية والجان هي الحية الخفيفة الأهلية ،   فإن قيل : إنه قال في آية أخرى ،   { فألقى عَصَاهُ فَإِذَا هِىَ ثُعْبَانٌ مُّبِينٌ } [ الأعراف : 107 ] والثعبان الحية الكبيرة ،   فأجاب بعض أصحاب المعاني أنه كان في كبر الثعبان ،   وفي خفة الجان قال الفقيه أبو الليث رحمه الله : والجواب الصحيح أن الثعبان كان عند فرعون ،   والجان عند الطور ثم قال : { ولى مُدْبِراً } يعني : أدبر هارباً من الخوف { وَلَمْ يُعَقّبْ } يعني : لم يرجع ويقال : لم يلتفت يقول الله تعالى لموسى { يا موسى لاَ تَخَفْ } من الحية { إِنّى لاَ يَخَافُ لَدَىَّ المرسلون } يعني : لا يخاف عندي
