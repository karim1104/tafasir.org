{ قَالَتْ } المرأة { قَالَتْ يا أيها الملأ } يعني : الأشراف والقادة { أَفْتُونِى فِى أَمْرِى } وكان لها ثلاثمائة وثلاثة عشر قائداً تحت يد كل قائد ألف رجل ،   وقد قيل أكثر من هذا : { أَفْتُونِى فِى أَمْرِى } .   يعني : أجيبوني في أمري .   ويقال : بينوا لي أمري وأخبروني .   ويقال : أشيروا علي { مَا كُنتُ قاطعة أَمْراً } أي قاضية أمراً .   ويقال : فاصلة أمراً { حتى تَشْهَدُونِ } يعني : تحضرون أي : لا أقطع أمراً دونكم<br />
