{ قَالُواْ } مجيبين لها { نَحْنُ أُوْلُواْ قُوَّةٍ وَأُولُو بَأْسٍ شَدِيدٍ } يعني : عدة وكثرة وسلاحاً وقتال شديد { والأمر إِلَيْكِ } يعني : أخبرناك بما عندنا أيتها الملكة ،   ومع ذلك لا نجاوز ما تقولين .   يعني : إن أمرتينا بقتال قاتلنا ،   وإن أمرتنا بغير ذلك أطعناك { فانظرى مَاذَا تَأْمُرِينَ } يعني : ماذا تشيرين إلينا .  <br />
