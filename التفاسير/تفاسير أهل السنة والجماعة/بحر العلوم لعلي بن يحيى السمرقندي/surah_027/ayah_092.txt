{ وَأَنْ أَتْلُوَ القرءان } يعني : أمرت أن أقرأ عليكم القرآن يا أهل مكة { فَمَنُ اهتدى } أي : آمن بالقرآن { فَإِنَّمَا يَهْتَدِي لِنَفْسِهِ } أي : يؤمن لنفسه ويثاب عليها { وَمَن ضَلَّ } ولم يوحد ،   ولم يؤمن بالقرآن وبمحمد صلى الله عليه وسلم { فَقُلْ إِنَّمَا أَنَا مِنَ المنذرين } أي : من المخوفين ومن المرسلين ،   فليس عليَّ إلا تبليغ الرسالة<br />
