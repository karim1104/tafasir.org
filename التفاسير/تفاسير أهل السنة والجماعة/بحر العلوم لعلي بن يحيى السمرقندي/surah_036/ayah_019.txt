{ قَالُواْ طائركم مَّعَكُمْ } يعني : شؤمكم معكم ،   وبأعمالكم الخبيثة .   ويقال : إن الذي يصيبكم ،   كان مكتوباً في أعناقكم ،   { أئن ذُكّرْتُم } يعني : إن وعظتم بالله .   قرأ نافع وأبو عمرو { آينَ } بهمزة واحدة ممدودة .   وقرأ الباقون : بهمزتين .   وقرأ زر بن حبيش : { أنْ ذُكّرْتُم } بهمزة واحدة مع التخفيف والفتح .   يعني : لأنكم وعظتم ؟ فلم تتعظوا .   ومن قرأ بالاستفهام فمعناه : إن وعظتم تطيرتم .   قالوا : هذا جواباً لقولهم : { إِنَّا تَطَيَّرْنَا بِكُمْ } ويقال : معناه { أئن ذُكّرْتُم } .   يعني : حين وعظتم بالله تشاءمتم بنا .   ثم قال : { بَلْ أَنتُمْ قَوْمٌ مُّسْرِفُونَ } يعني : مشركون .  <br />
