ثم قال تعالى : { هُمْ وأزواجهم في ظلال } قرأ حمزة والكسائي { فِي ظُلَلٍ } وقرأ الباقون { في ظلال } فمن قرأ { فِي ظُلَلٍ } فهو جمع الظلة .   يقال : ظلة وظلل مثل حلة وحلل .   ومن قرأ بكسر الظاء فهو جمع الظل يعني : هم في ظلال العرش والشجر ويقال معنى القراءتين يرجع إلى شيء واحد .   يعني : إن أهل الجنة { هُمْ وأزواجهم } الحور العين في القصور { عَلَى الأرائك مُتَّكِئُونَ } يعني : على السرر عليها الحجال .   وروى مجاهد عن ابن عباس قال : الأرائك سرر في الحجال .   وقال الكلبي : لا تكون أريكة إلا إذا اجتمعتا ،   فإذا تفرقا فليست بأريكة { مُتَّكِئُونَ } أي : ناعمون .   وإنما سمي هذا لأن الناعم يكون متكئاً .  <br />
