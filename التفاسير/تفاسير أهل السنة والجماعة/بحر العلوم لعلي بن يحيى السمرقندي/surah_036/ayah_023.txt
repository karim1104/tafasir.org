فقالوا له : ارجع إلى ديننا .   فقال حبيب : { أَأتَّخِذُ مِن دُونِهِ آلِهَةً } يعني : أعبد من دونه أصناماً { إِن يُرِدْنِ الرحمن بِضُرّ } يعني : ببلاء وشدة إذا فعلت ذلك { لاَّ تُغْنِ عَنّي شفاعتهم شَيْئاً } يعني : لا تقدر الآلهة أن يشفعوا لي { وَلاَ يُنقِذُونَ } يعني : لا يدفعون عني الضرر .  <br />
