{ قَالَ } لها جبريل : { كذلك } ،   يعني : هكذا كما قلت .   { قَالَ رَبُّكَ هُوَ عَلَىَّ هَيّنٌ } ،   يعني : خلقه عليّ يسير ،   { وَلِنَجْعَلَهُ ءايَةً لّلْنَّاسِ }  ؛ يعني : عبرة لبني إسرائيل ،   { وَرَحْمَةً مّنَّا }  ؛ أي ونعمة منا .   { وَكَانَ أَمْراً مَّقْضِيّاً } ،   يعني : قضاء كائناً .  <br />
