ثم نزل في شأن المنافقين الذين تخلفوا قوله تعالى : { لَوْ كَانَ عَرَضًا قَرِيبًا } ،   يعني : غنيمة قريبة ويقال : سهلاً قريباً .   { وَسَفَرًا قَاصِدًا } ،   يعني : هيناً يقيناً ،   { لاَّتَّبَعُوكَ }  ؛ يعني : لو علموا أنهم يصيبون مغنماً ،   { لاَّتَّبَعُوكَ ولكن بَعُدَتْ عَلَيْهِمُ الشقة } والشقة : السفر ،   يعني : ثقل عليهم السفر .   { وَسَيَحْلِفُونَ بالله } ،   أي الذين تخلفوا .   { لَوِ استطعنا } ،   يعني : لو قدرنا ولو كانت لنا سعة في المال والزاد ،   { لَخَرَجْنَا مَعَكُمْ } إلى الغزو .  <br />
وقال الله تعالى : { يُهْلِكُونَ أَنفُسَهُمْ } ،   يعني : بحلفهم كذباً .   { والله يَعْلَمُ إِنَّهُمْ لكاذبون } بحلفهم ،   وأن لهم سعة للخروج ،   ولكنهم لم يريدوا الخروج .  <br />
