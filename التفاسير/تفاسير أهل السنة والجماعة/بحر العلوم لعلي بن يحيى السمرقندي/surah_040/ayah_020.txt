{ والله يَقْضِي بالحق } أي : يحكم بالحق .   ويقال : يأمر بما يجب به الثواب ،   وينهى عما يجب به العقاب .   { والذين يَدْعُونَ مِن دُونِهِ } يعني : يعبدون من الآلهة .   قرأ نافع ،   وابن عامر : { تَدْعُونَ } بالتاء على معنى المخاطبة .   والباقون ،   بالياء على معنى الخبر عنهم .  <br />
{ لاَ يَقْضُونَ بِشيء } يعني : ليس لهم قدرة ،   ولا يحكمون بشيء ،   { إِنَّ الله هُوَ السميع البصير } يعني : { السميع } لمقالة الكفار { البصير } بأعمالهم .  <br />
