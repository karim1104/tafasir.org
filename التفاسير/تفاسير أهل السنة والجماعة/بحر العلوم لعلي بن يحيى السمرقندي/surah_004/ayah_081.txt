ثم أخبر عن أمر المنافقين فقال : { وَيَقُولُونَ طَاعَةٌ } أي يقولون بحضرتك : قولك طاعة .   وأمرك معروف ،   فمرنا بما شئت فنحن لأمرك نتبع { فَإِذَا بَرَزُواْ } أي خرجوا { مِنْ عِندِكَ بَيَّتَ } أي ألغت ويقال غيرت { طَائِفَةٌ مّنْهُمْ غَيْرَ الذي تَقُولُ } وقال الزجاج : لكل أمر قضي بليل قد بيت ،   قرأ أبو عمرو وحمزة { بَيَّتَ طَائِفَةٌ } بالإدغام لقرب مخرج التاء من الطاء ،   وقرأ الباقون بالإظهار لأنهما كلمتان .   ثم قال تعالى : { والله يَكْتُبُ مَا يُبَيّتُونَ } يعني : يحفظ عليهم ما يغيرون .   وقال الزجاج : { والله يَكْتُبُ } له وجهان ،   يجوز أن يكون ينزله إليك في كتابه ،   وجائز أن يكون : يحفظ ما جاؤوا به .   ثم قال تعالى : { فَأَعْرِضْ عَنْهُمْ } أي اتركهم { وَتَوَكَّلْ عَلَى الله وكفى بالله وَكِيلاً } أي شهيداً .   ويقال : { وَتَوَكَّلْ عَلَى الله } أي ثق بالله { وكفى بالله وَكِيلاً } أي شهيداً .   أو يقال : وتوكل على الله ثقة لك .   ثم نسخ بقوله تعالى : { يا أيها النبي جاهد الكفار والمنافقين واغلظ عَلَيْهِمْ وَمَأْوَاهُمْ جَهَنَّمُ وَبِئْسَ المصير } [ التوبة : 73 ] .
