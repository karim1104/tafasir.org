قوله تعالى : { وَلَوْلاَ فَضْلُ الله عَلَيْكَ وَرَحْمَتُهُ } يعني فضل الله عليك بالنبوة ،   ورحمته بالوحي { لَهَمَّتْ طَّائِفَةٌ مّنْهُمْ } أي جماعة { أَن يُضِلُّوكَ } أي يخطئون في الحكم { وَمَا يُضِلُّونَ إِلا أَنفُسَهُمْ } أي وما يرجع وبال ذلك إلا على أنفسهم { وَمَا يَضُرُّونَكَ مِن شيء } وإنما يضرون بأنفسهم .   قال الضحاك : نزلت الآية في وفد ثقيف ،   قدموا إلى رسول الله صلى الله عليه وسلم وقالوا : جئناك لنبايعك على أن لا تكسر أصنامنا ولا تعشرنا ،   فلم يجبهم رسول الله صلى الله عليه وسلم ،   فنزلت { لَهَمَّتْ طَّائِفَةٌ مّنْهُمْ أَن يُضِلُّوكَ } وقال الكلبي : يعني قوم طعمة .   ثم قال : { وَأَنزَلَ عَلَيْكَ الكتاب } يعني القرآن { والحكمة } يعني : القضاء والمواعظ { وَعَلَّمَكَ } بالوحي { مَا لَمْ تَكُنْ تَعْلَمُ } قبل الوحي { وَكَانَ فَضْلُ الله عَلَيْكَ عَظِيماً } بالنبوة .  <br />
