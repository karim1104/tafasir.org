ثم قال تعالى : { وَمَن يَعْمَلْ مِنَ الصالحات } يعني يؤدي الفرائض وينتهي عن المحارم { مّن ذَكَرٍ أَوْ أنثى } أي من رجل أو امرأة { وَهُوَ مُؤْمِنٌ } أي مصدق بالثواب والعقاب { فَأُوْلَئِكَ يَدْخُلُونَ الجنة } لا شك فيها { وَلاَ يُظْلَمُونَ } أي لا ينقصون من ثواب أعمالهم { نَقِيراً } وهي النقرة التي تكون على ظهر النواة .   قرأ أبو عمرو وابن كثير { فَأُوْلَئِكَ يَدْخُلُونَ الجنة } بضم الياء ونصب الخاء ،   على معنى فعل ما لم يسم فاعله .   وقرأ الباقون بنصب الياء وضم الخاء ،   أي يدخلون الجنة بأعمالهم .  <br />
