يقول الله تعالى للنبي صلى الله عليه وسلم : { قُلْ } يا محمد ،   { إِنَّمَا أَنَاْ بَشَرٌ مّثْلُكُمْ } يعني : آدمياً مثلكم ،   { يوحى إِلَيّ } ما أبلغكم من الرسالة ،   { أَنَّمَا إلهكم إله واحد فاستقيموا إِلَيْهِ } يعني : أقروا له بالتوحيد ،   { واستغفروه } من الشرك ،   { وَوَيْلٌ لّلْمُشْرِكِينَ } يعني : الشدة من العذاب للمشركين .  <br />
