قوله تعالى : { وَلَقَدْ آتَيْنَا موسى الكتاب } يعني : أعطينا موسى التوراة ،   ويقال : الألواح .  <br />
قوله : { فاختلف فِيهِ } يعني : صدق بعضهم ،   وكذب بعضهم ،   { وَلَوْلاَ كَلِمَةٌ سَبَقَتْ مِن رَّبّكَ } يعني : وجبت بتأخير العذاب ،   { لَقُضِيَ بَيْنَهُمْ } يعني : لفرغ من أمرهم ،   ولهلك المكذب .   { وَإِنَّهُمْ لَفي شَكّ مّنْهُ مُرِيبٍ } يعني : من العذاب بعد البعث { مُرِيبٍ } لا يعرفون شكهم .   ويقال : { مُرِيبٍ } أي : ظاهر الشك .   ويقال : { وَلَوْلاَ كَلِمَةٌ سَبَقَتْ مِن رَّبّكَ } بتأخير العذاب عن هذه الأمة إلى يوم القيامة ،   لأتاهم العذاب ،   إذ كذبوه كما فعل بغيرهم .  <br />
