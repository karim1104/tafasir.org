ثم قال عز وجل : { قُلْ مَن ذَا الذي يَعْصِمُكُمْ مّنَ الله } يعني : يمنعكم من قضاء الله وعذابه { إِنْ أَرَادَ بِكُمْ سُوءاً } يعني : القتل { أَوْ أَرَادَ بِكُمْ رَحْمَةً } أي : عافية .   ويقال : { سُوءا } يعني : الهزيمة { أَوْ أَرَادَ بِكُمْ رَحْمَةً } يعني : خيراً .   وهو النصر .   يعني : من يقدر على دفع السوء عنكم وجر الخير إليكم { وَلاَ يَجِدُونَ لَهُمْ مّن دُونِ الله وَلِيّاً وَلاَ نَصِيراً } يعني : قريباً ومانعاً .  <br />
