ثم قال عز وجل : { يَوْمَ تُقَلَّبُ وُجُوهُهُمْ فِي النار } يعني : هذا العذاب في { يَوْمَ تُقَلَّبُ وُجُوهُهُمْ فِي النار } يعني : تحول عن الحسن إلى القبح ،   من حال البياض إلى حال السواد وزرقة الأعين .   ويقال : { تَقَلُّبُ } يعني : تجدد كقوله : { كلما نضجت جلودهم بدلناهم جلودا غيرها } [ النساء : 56 ] فيندمون على فعلهم ويوبخون أنفسهم { يَقُولُونَ يا ليتنا أَطَعْنَا الله } فيما أمرنا ونهانا { وَأَطَعْنَا الرسولا } فيما دعانا إلى الحق .
