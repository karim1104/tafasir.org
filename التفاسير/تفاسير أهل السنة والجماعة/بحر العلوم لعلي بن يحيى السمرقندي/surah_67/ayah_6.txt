{ وَلِلَّذِينَ كَفَرُواْ } يعني : أعتدنا للذين جحدوا { بِرَبّهِمْ } يعني : بوحدانية الله تعالى { عَذَابَ جَهَنَّمَ } .   قرئ في الشاذ { عَذَابَ جَهَنَّمَ } بالنصب يعني : أعتدنا لهم عذاب جهنم ،   فيصير نصباً لوقوع الفعل عليه ،   وقراءة العامة بالضم ،   على معنى خبر الابتداء .   ثم قال : { وَبِئْسَ المصير } يعني : المرجع .  <br />
