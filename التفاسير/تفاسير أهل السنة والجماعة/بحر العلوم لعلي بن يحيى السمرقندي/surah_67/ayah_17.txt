{ أَمْ أَمِنتُمْ مّن في السماء } يعني : عذاب من في السماء .   { أَن يُرْسِلَ عَلَيْكُمْ حاصبا } يعني : حجارة كما أرسلنا إلى قوم لوط .   وقال القتبي : «أم » على وجهين ،   مرة يراد بها الاستفهام ،   كقوله : { أَمْ يَحْسُدُونَ الناس } ،   ومرة يراد بها أو ،   كقوله : { أَمْ أَمِنتُمْ } ويعني : أو أمنتم .   وهذا كقوله : { أَفَأَمِنتُمْ أَن يَخْسِفَ بِكُمْ جَانِبَ البر أَوْ يُرْسِلَ عَلَيْكُمْ حَاصِبًا ثُمَّ لاَ تَجِدُواْ لَكُمْ وَكِيلاً } [ الإسراء : 68 ] .   ثم قال : { فَسَتَعْلَمُونَ كَيْفَ نَذِيرِ } يعني : تعبيري عليهم بالعذاب .   ويقال : معناه سيظهر لكم كيف عذابي .
