ثم قال عز وجل : { اقرأ وَرَبُّكَ الأكرم } يعني : اقرأ يا محمد صلى الله عليه وسلم وربك يعينك ويفهمك ،   وإن كنت غير قارئ { الأكرم } يعني : ربك المتجاوز عن جهل العباد ،   ويقال : { اقرأ } وقد تم الكلام ،   ثم استأنف فقال { وَرَبُّكَ الأكرم } يعني : الكريم ،   ويقال : الأكرم يعني : المكرم الذي يكرم من يشاء بالإسلام .  <br />
