قوله : { وَقَالَ الذين أَشْرَكُواْ } أي : أهل مكة { لَوْ شَآء الله مَا عَبَدْنَا مِن دُونِهِ مِن شَىْء } قالوا ذلك على وجه الاستهزاء .   يعني : إن الله قد شاء لنا ذلك الذي { نَحْنُ } فيه { وَلاَ ىَابَاؤُنَا } ولكن شاء لنا ولآبائنا { وَلاَ حَرَّمْنَا مِن دُونِهِ مِن شَىْء } ولا آباؤنا ،   ولكن شاء لنا من تحريم البحيرة ،   والسائبة ،   وأمرنا به .   ولو لم يشأ ،   ما حرمنا من دونه من شيء .  <br />
قال الله تعالى : { كَذَلِكَ فَعَلَ الذين مِن قَبْلِهِمْ } يقول : هكذا كذب الذين من قبلهم من الأمم { فَهَلْ عَلَى الرسل إِلاَّ البلاغ } أي : ليس عليهم إلا تبليغ الرسالة { المبين } أي : بينّوا لهم ما أمروا به .  <br />
