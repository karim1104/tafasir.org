قوله : { أَلِيمٍ هَلْ يَنظُرُونَ } يقول : ما ينظرون وهم أهل مكة { إِلا أَن تَأْتِيهُمُ الملائكة } أي : ملك الموت يقبض أرواحهم { أَوْ يَأْتِىَ أَمْرُ رَبّكَ } أي : عذاب ربك يوم بدر ،   ويقال : يوم القيامة { كَذَلِكَ فَعَلَ } أي : كذلك كذب { الذين مِن قَبْلِهِمْ } رسلهم ،   كما كذبك قومك ،   فأهلكهم الله تعالى { وَمَا ظَلَمَهُمُ الله } يعني : بإهلاكه إياهم { ولكن كَانُواْ أَنفُسَهُمْ يَظْلِمُونَ } بتكذيبهم رسلهم .   قرأ حمزة والكسائي : إلا أن يأتيهم بالياء بلفظ التذكير ،   والباقون بلفظ التأنيث ،   لأن الفعل مقدم .  <br />
