ثم أخبرهم عن خلق أنفسهم ليعتبروا ويتفكروا فيه فقال عز وجل : { الله الذي خَلَقَكُمْ مّن ضَعْفٍ } يعني : من نطفة .   ويقال : صغيراً لا يعقل { ثُمَّ جَعَلَ مِن بَعْدِ ضَعْفٍ قُوَّةٍ } يعني : شدة بتمام خلقه { ثُمَّ جَعَلَ مِن بَعْدِ قُوَّةٍ ضَعْفاً } يعني : بعد الشباب الهرم { وَشَيْبَةً } أي : شمطاً .   قرأ عاصم في رواية حفص وحمزة : { من ضعف } بنصب الضاد .   وقرأ الباقون : { من ضعف } بالضم .   وهما لغتان ومعناهما واحد .   { يَخْلُقُ مَا يَشَاء } أي : يحول الخلق كيف يشاء من الصورة { وَهُوَ العليم } بتحويل الخلق ،  { القدير } يعني : القادر على ذلك .  <br />
