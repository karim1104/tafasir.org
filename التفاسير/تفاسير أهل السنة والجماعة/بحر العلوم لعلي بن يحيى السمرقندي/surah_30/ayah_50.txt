ثم قال : { فانظر إلى آثار رَحْمَةِ الله } يعني : ألوان النبات من أثر المطر منه الأخضر ،   والأحمر ،   والأصفر .   قرأ حمزة والكسائي وعاصم في رواية حفص وابن عامر { إلى آثار رَحْمَةِ الله } بلفظ الجماعة .   قرأ الباقون بلفظ الوحدان { إلى أثر } ،   لأن الوحدان ينبئ عن الجمع .  <br />
ثم قال : { كَيْفَ يحيي الأرض بَعْدَ مَوْتِهَا } حين لم يكن فيها نبات { إِنَّ ذلك } يعني : هذا الذي فعل { لمحيي الموتى } في الآخرة { وَهُوَ على كُلّ شيء قَدِيرٌ } .  <br />
