{ وَلَمَّا أَن جَاءتْ رُسُلُنَا لُوطاً سِىء بِهِمْ } يعني : ساء مجيئهم { وَضَاقَ بِهِمْ ذَرْعًا } يعني : اغتم بقدومكم ،   فلا يدري أيأمرهم بالخروج أم بالنزول .   ويقال : ضاق بهم القلب { وَقَالُواْ لاَ تَخَفْ } علينا { وَلاَ تَحْزَنْ } من العذاب { إِنَّا مُنَجُّوكَ وَأَهْلَكَ } قرأ حمزة والكسائي { لَنُنَجّيَنَّهُ } ،   و { إِنَّا مُنَجُّوكَ } كلاهما بالتخفيف .   وقرأ أبو عمرو ونافع وابن عامر وحفص عن عاصم كلاهما بالتشديد .   وقرأ ابن كثير وأبو بكر عن عاصم الأول بالتشديد ،   والثاني بالتخفيف ،   ومعناهما واحد .   ويقال : أنجيته ونجيته بمعنى واحد { إِلاَّ امرأتك كَانَتْ مِنَ الغابرين } .  <br />
