ثم قال عز وجل : { وَمَنْ أَظْلَمُ مِمَّنِ افترى عَلَى الله كَذِباً } بأن معه شريكاً { أَوْ كَذَّبَ بالحق } يعني : بالقرآن { لَمَّا جَاءهُ } أي حين جاءه { أَلَيْسَ فِى جَهَنَّمَ مَثْوًى للكافرين } مثوى ،   أي مقاماً للكافرين بالتوحيد كما قال { وَكَذَلِكَ أَوْحَيْنَآ إِلَيْكَ قُرْءَاناً عَرَبِيّاً لِّتُنذِرَ أُمَّ القرى وَمَنْ حَوْلَهَا وَتُنذِرَ يَوْمَ الجمع لاَ رَيْبَ فِيهِ فَرِيقٌ فِى الجنة وَفَرِيقٌ فِى السعير } [ الشورى : 7 ]
