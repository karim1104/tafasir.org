{ وَعُرِضُواْ على رَبّكَ صَفَّا } ،   يقول : جميعاً ،   كقوله : { فَأَجْمِعُواْ كَيْدَكُمْ ثُمَّ ائتوا صَفّاً وَقَدْ أَفْلَحَ اليوم مَنِ استعلى } [ طه : 64 ] ،   أي جميعاً .   يقول الله تعالى ذكره : { لَّقَدْ جِئْتُمُونَا } فرادى عراة حفاةً ،   { كَمَا خلقناكم أَوَّلَ مَرَّةٍ } بلا أهل ولا مال .   { بَلْ زَعَمْتُمْ } ،   أي قد قلتم في الدنيا : { أَن لَّن نَّجْعَلَ لَكُمْ مَّوْعِدًا } ،   أي لن نبعثكم في الآخرة .
