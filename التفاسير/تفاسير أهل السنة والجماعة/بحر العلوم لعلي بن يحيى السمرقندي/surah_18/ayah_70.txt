{ قَالَ } الخضر : { فَإِنِ اتبعتنى } ،   أي صحبتني { فَلاَ تَسْأَلْنى عَن شَىء } فعلت ،   { حتى أُحْدِثَ لَكَ مِنْهُ ذِكْراً }  ؛ أي حتى أخبرك منه خبراً ،   يعني : إن أنكرته فلا تعجل عليّ بالمسألة .   فأمر موسى يوشع أن يرجع إلى بني إسرائيل وأقام موسى مع الخضر .  <br />
قرأ نافع { فَلاَ تَسْأَلْنى } بتشديد النون مع إثبات الياء والتقدير للتأكيد للنهي ،   وقرأ ابن عامر { فَلاَ تَسْأَلْنى } بتشديد النون بغير ياء لأن الكسرة تدل عليه ،   وقرأ الباقون { فَلاَ تَسْأَلْنى } بالتخفيف وإثبات الياء ،   وقرأ بعضهم بالتخفيف بغيره .  <br />
