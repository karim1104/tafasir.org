ثم قال : { إِن تَكْفُرُواْ } يعني : إن تجحدوا وحدانيته ،   { فَإِنَّ الله غَنِىٌّ عَنكُمْ } يعني : عن إقراركم ،   وعبادتكم ،   { وَلاَ يرضى لِعِبَادِهِ الكفر } قال الكلبي : يعني : ليس يرضى من دينه الكفر .   ويقال : { لاَ يرضى لِعِبَادِهِ الكفر } وهو ما قاله لإبليس : { إن عبادي ليس لك عليهم سلطان } [ الحجر : 42 ] .   ويقال : { لاَ يرضى لِعِبَادِهِ الكفر } يعني : بشيء من عبادة الكفار { وَإِن تَشْكُرُواْ يَرْضَهُ لَكُمْ } يعني : إن تؤمنوا بالله ،   وتوحدوه ،   { يرضه لكم } .   يعني : يقبله منكم ،   لأنه دينه ،   { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أخرى } يعني : لا يؤاخذ أحد بذنب غيره ،   { ثُمَّ إلى رَبّكُمْ مَّرْجِعُكُمْ } يعني : مصيركم في الآخرة { فَيُنَبّئُكُمْ } يعني : فيخبركم ،   { بِمَا كُنْتُمْ تَعْمَلُونَ } من خير ،   أو شر ،   فيجازيكم ،   { إِنَّهُ عَلِيمٌ بِذَاتِ الصدور } يعني : عالم بما في ضمائر قلوبهم .
