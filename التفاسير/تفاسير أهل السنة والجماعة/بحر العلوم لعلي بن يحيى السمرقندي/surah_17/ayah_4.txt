قوله : { وَقَضَيْنَا إلى بَنِى إسراءيل } يقول : أعلمنا وبينّا كقوله : { وَقَضَيْنَآ إِلَيْهِ ذَلِكَ الأمر } أي : أعلمناه ،   وبينّاه { فِى الكتاب } يعني : أخبرناهم في التوراة { لَتُفْسِدُنَّ } أي : لتعصن { فِى الأرض مَرَّتَيْنِ وَلَتَعْلُنَّ عُلُوّاً كَبِيراً } والعلو العتو على الله تعالى ،   والجرأة .   وهذا قول ابن عباس .  <br />
وقال مقاتل : يعني : لتهلكن في الأرض مرتين { وَلَتَعْلُنَّ عُلُوّاً كَبِيراً } يعني : لتقهرن قهراً شديداً .  <br />
