قوله : { أَمْ أَمِنتُمْ أَن يُعِيدَكُمْ فِيهِ } ،   أي البحر { تَارَةً أخرى } ،   يعني : مرة أخرى .   { فَيُرْسِلَ عَلَيْكُمْ قَاصِفًا مّنَ الريح } ،   أي ريحاً شديداً ؛ { فَيُغْرِقَكُم بِمَا كَفَرْتُمْ } بالله وبنعمه ،   { ثُمَّ لاَ تَجِدُواْ لَكُمْ عَلَيْنَا بِهِ تَبِيعًا } ،   أي من يتبعنا ويطالبنا بدمائكم ،   كقوله { ياأيها الذين ءَامَنُواْ كُتِبَ عَلَيْكُمُ القصاص فِي القتلى الحر بِالْحُرِّ والعبد بالعبد والانثى بالانثى فَمَنْ عُفِىَ لَهُ مِنْ أَخِيهِ شَىْءٌ فاتباع بالمعروف وَأَدَآءٌ إِلَيْهِ بإحسان ذلك تَخْفِيفٌ مِّن رَّبِّكُمْ وَرَحْمَةٌ فَمَنِ اعتدى بَعْدَ ذلك فَلَهُ عَذَابٌ أَلِيمٌ } [ البقرة : 178 ] ،   أي مطالبة حسنة ؛ ويقال : يعني : ثائراً ولا ناصراً ،   لينتقم لكم مني .   قرأ ابن كثير وأبو عمرو { ءانٍ  نَخْسِفْ  بِكُمْ } { أَوْ  نُرْسِلُ } { ءانٍ  نُعِيدُكُمْ فنرسل عليكم فنغرقكم } هذه الخمسة كلها بالنون ،   وقرأ الباقون كلها بالياء .
