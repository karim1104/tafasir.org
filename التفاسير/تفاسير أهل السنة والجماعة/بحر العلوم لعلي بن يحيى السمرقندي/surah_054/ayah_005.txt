قوله تعالى : { حِكْمَةٌ بالغة } يعني : جاءهم كلمة بالغة ،   وهو القرآن يعني : حكمة وثيقة { فَمَا تُغْنِى النذر } يعني : لا تنفعهم النذر إن لم يؤمنوا ،   كقوله : { قُلِ انظروا مَاذَا في السماوات والأرض وَمَا تُغْنِي الآيات والنذر عَن قَوْمٍ لاَّ يُؤْمِنُونَ } [ يونس : 101 ] ويقال : { فَمَا تُغْنِ النذر } لم تنفعهم الرسل إذا نزل بهم العذاب إن لم يؤمنوا .
