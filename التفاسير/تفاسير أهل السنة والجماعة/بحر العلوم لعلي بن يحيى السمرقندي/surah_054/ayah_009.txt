ثم عزى نبيه صلى الله عليه وسلم ليصبر على أذى قومه كما لقي الرسل من قومهم فقال : { كَذَّبَتْ قَبْلَهُمْ } يعني : قبل قومك يا محمد { قَوْمُ نُوحٍ } حين أتاهم بالرسالة { فَكَذَّبُواْ عَبْدَنَا } نوحاً { وَقَالُواْ مَجْنُونٌ } يعني : قالوا لنوح : إنك مجنون { وازدجر } يعني : أوعد بالوعيد .   ويقال : صاحوا به حتى غشي عليه .   وقال القتبي : { وازدجر } أي : زجر .   وهو افتعل من ذلك .  <br />
