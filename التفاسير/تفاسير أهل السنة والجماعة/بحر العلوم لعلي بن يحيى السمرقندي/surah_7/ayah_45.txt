ثم قال : { الذين يَصُدُّونَ عَن سَبِيلِ الله } أي الناس عن دين الله ،   وهو الإسلام وهم الرؤساء منهم منعوا أتباعهم عن الإيمان { وَيَبْغُونَهَا عِوَجًا } يقول يريدون بملة الإسلام غيراً وزيفاً { وَهُم بالآخرة كافرون } يعني : أنهم كانوا جاحدون بالبعث .   قرأ ابن عامر وحمزة والكسائي { أنَّ لَعْنَةَ الله } بالتشديد ونصب الهاء .   وقرأ الباقون { أنَّ لَعْنَةُ } بتخفيف أَنْ وضم الهاء .  <br />
