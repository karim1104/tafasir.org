{ قَالَ الملأ مِن قَوْمِ فِرْعَوْنَ } يعني : الأشراف والرؤساء .   قال مقاتل : إن فرعون قال بهذه المقالة فصدقه قومه كما قال في سورة الشعراء : { قَالَ لِلْمَلإِ حَوْلَهُ إِنَّ هذا لساحر عَلِيمٌ } [ الشعراء : 34 ] يعني : حاذق بالسحر .  <br />
ثم قال لقومه : { إِنَّ هذا لساحر عَلِيمٌ } تصديقاً لقوله : { يُرِيدُ أَن يُخْرِجَكُم مّنْ أَرْضِكُمْ } .
