قوله تعالى : { وَمِمَّنْ خَلَقْنَا أُمَّةٌ يَهْدُونَ بالحق } يعني : جماعة وهم أمة محمد صلى الله عليه وسلم { يهدون بالحق } يعني يدعون إلى الحق ويأمرون بالحق { وَبِهِ يَعْدِلُونَ } يعني بالحق يعملون وذلك أنه لما نزل قوله تعالى : { وَمِن قَوْمِ موسى أُمَّةٌ يَهْدُونَ بالحق وَبِهِ يَعْدِلُونَ } [ الأعراف : 159 ] قال أناس من أصحاب رسول الله صلى الله عليه وسلم : يا رسول الله قد ذكر الله تعالى هؤلاء الرهط بالخير الجسيم من بني إسرائيل إن آمنوا بك وجعل لهم أجرين ،   ولنا أجراً واحداً ،   وقد صدقناك والرسل والكتب فنزل { وَمِمَّنْ خَلَقْنَا أُمَّةٌ } يعني : من أمة محمد صلى الله عليه وسلم { يَهْدُونَ بالحق وَبِهِ يَعْدِلُونَ } .
