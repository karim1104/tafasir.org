ثم قال : { وَإِن كَانَ طَائِفَةٌ مّنكُمْ آمَنُواْ بالذي أُرْسِلْتُ بِهِ } يعني : إن كان جماعة منكم صدقوا بي { وَطَائِفَةٌ لَّمْ يْؤْمِنُواْ } بي أي لم يصدقوا { فاصبروا حتى يَحْكُمَ الله بَيْنَنَا } يعني : حتى تنظروا عاقبة المؤمنين أفضل أم عاقبة الكافرين .  <br />
فذلك قوله : { حتى يَحْكُمَ الله بَيْنَنَا } يعني : حتى يقضي الله بين المؤمنين وبين الكافرين { وَهُوَ خَيْرُ الحاكمين } أي أعدل العادلين .  <br />
