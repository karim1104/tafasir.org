قوله تعالى : { قَالَ يَا موسى إِنّي  اصطفيتك عَلَى الناس برسالاتي } يعني : بنبوتي .   قرأ ابن كثير ونافع { برسَالَتِي } .   وقرأ الباقون { برسَالاتي } بلفظ الجماعة ومعناهما واحد أي : اختصصتك بالنبوة .   { وبكلامي } أي بتكلمي معك من غير وحي { فَخُذْ مَا آتَيْتُكَ } أي : اعمل بما أعطيتك { وَكُنْ مّنَ الشاكرين } لما أعطيتك .   وقال القتبي : قوله { وَأَنَاْ أَوَّلُ المؤمنين } أراد به في زمانه كقوله { وَأَنّي فَضَّلْتُكُمْ عَلَى العالمين } [ البقرة : 47 ] .
