قوله : { قَالَ اخرج مِنْهَا مَذْمُومًا مَّدْحُورًا } قال الكلبي ومقاتل : يعني اخرج من الجنة { مذؤوماً } أي معيباً { مدحوراً } أي : مطروداً .   وقال الزجاج : { مذؤوماً } أي مذموماً .   يقال : دأمت الرجل وذممته إذا عبته { مدحوراً } أي : مبعداً من رحمة الله تعالى .   { لَّمَن تَبِعَكَ مِنْهُمْ } أي : مَنْ أطاعك فيما دعوته إليه .   واللام زيادة للتأكيد { لأمْلانَّ جَهَنَّمَ مِنكُمْ أَجْمَعِينَ } أي : ممن أطاعك منهم من الجن والإنس ،   ويكون هذا اللفظ بمعنى القسم والتأكيد وأنه يفعل ذلك لا محالة .  <br />
