ثم قال : { وقطعناهم } يعني : بني إسرائيل فرقناهم { اثنتي عَشْرَةَ أَسْبَاطًا أُمَمًا } يعني : جماعة والأسباط جَمْعٌ والسبط في بني إسرائيل مثل القبيلة عند العرب { وَأَوْحَيْنَا إلى مُوسَى } يعني : في التيه { إِذِ استسقاه قَوْمُهُ } إلى قوله : { رِجْزًا مّنَ السماء بِمَا كَانُواْ يَظْلِمُونَ } كل ذلك مذكور في سورة البقرة<br />
