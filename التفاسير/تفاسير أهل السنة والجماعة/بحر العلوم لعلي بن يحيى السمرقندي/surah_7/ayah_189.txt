قوله تعالى : { هُوَ الذي خَلَقَكُمْ مّن نَّفْسٍ واحدة } يعني : من نفس آدم { وَجَعَلَ مِنْهَا زَوْجَهَا } يعني : خلق من نفس آدم من ضلع من أضلاعه اليسرى زوجته حواء { لِيَسْكُنَ إِلَيْهَا } يعني : ليطمئن إليها ويجامعها { فَلَمَّا تَغَشَّاهَا } أي : سكن إليها وجامعها { حَمَلَتْ حَمْلاً خَفِيفًا } يعني : خفيف الماء { فَمَرَّتْ بِهِ } أي : استمرت بالحمل .   يقول : قامت بالحمل وقعدت ولا تدري أهي حبلى أم لا { فَلَمَّا أَثْقَلَت } يعني : ثقل الولد في بطنها { دَّعَوَا الله رَبَّهُمَا } وذلك أن إبليس أتاها فقال : يا حواء ما هذا الذي في بطنك ؟ قالت : ما أدري .   قال : أخاف إنها بهيمة ،   وإني من الله بمنزلة ،   فإن دعوت الله فولدت إنساناً صالحاً أتسميه باسمي ؟ قالت : نعم .   وما اسمك قال : عبد الحارث فكذب .   فدعت حواء وآدم فذلك قوله : { دعوا الله ربهما لَئِنْ آتَيْتَنَا صالحا } يعني : أعطيتنا ولداً سوياً صحيح الجوارح { لَنَكُونَنَّ مِنَ الشاكرين } وهذا قول سعيد بن جبير رواه عن ابن عباس .  <br />
