ثم قال : { وقطعناهم } أي فرقناهم { فِي الأرض أُمَمًا } أي فرقاً { مّنْهُمُ الصالحون } أي المؤمنون وهم مؤمنو أهل الكتاب .   ويقال : هم الذين وراء رمل عالج { وَمِنْهُمْ دُونَ ذلك } وهم الكفار منهم { وبلوناهم بالحسنات والسيئات } يعني : اختبرناهم بالخصب والجدوبة { لَعَلَّهُمْ يَرْجِعُونَ } من الكفر إلى الإيمان .  <br />
