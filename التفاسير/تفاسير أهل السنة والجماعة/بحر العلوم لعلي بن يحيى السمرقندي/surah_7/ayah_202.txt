ثم ذكر حال الكفار فقال عز وجل : { وإخوانهم يَمُدُّونَهُمْ فِي الغي } يعني : إخوان الشياطين يمدونهم أي : يدعونهم إلى المعصية .   ويقال : يلجونهم في الشرك والضلالة .   { ثُمَّ لاَ يُقْصِرُونَ } عنها كما أقصر المسلمون عنها حين أبصروها .   قرأ نافع { يَمُدُّونَهُمْ } بضم الياء وكسر الميم من أمَدَّ يُمِدّ .   وقرأ الباقون { يَمُدُّونَهُمْ } بالنصب من مَدَّ يَمُدُّ .   قال بعضهم : هذا عطف على قوله : { وَإِن تَدْعُوهُمْ إِلَى الهدى لاَ يَسْمَعُواْ } { وإخوانهم يَمُدُّونَهُمْ فِي الغي } .   وقال الزجاج : معناه التقديم .   والمعنى لا يستطيعون نصركم ولا أنفسهم ينصرون { وإخوانهم يَمُدُّونَهُمْ فِي الغي } يعني : الشياطين والغي : الجهل والوقوع في الهلكة .  <br />
