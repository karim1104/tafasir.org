قوله تعالى : { فَكَذَّبُوهُ } بالعذاب ،   بأنَّه غير نازلٍ بهم { فَنَجَّيْنَاهُ وَمَن مَّعَهُ فِى الفلك } من الغرق ،   { وَجَعَلْنَاهُمْ خَلاَئِفَ } يعني : خلفاء من بعد هلاكِ كُفَّارهم ،   { وأغرقنا الذين كذبوا بآياتنا } يعني : كذَّبوا نوحاً بما أتاهم به ،   { فانظر كَيْفَ كَانَ عَاقِبَةُ المنذرين } كيف كان آخرُ أمرِ مَنْ أنذرهم الرُّسلُ فلم يؤمنوا .  <br />
