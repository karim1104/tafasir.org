{ فَلَمَّا أَلْقُوْاْ } ما معهم من الحبال والعِصِيِّ إلى الأرض { قَالَ موسى مَا جِئْتُمْ بِهِ السحر } يعني : العمل الذي عملتم به هو السِّحر { إِنَّ الله سَيُبْطِلُهُ } يعني : سيهلكه { إِنَّ الله لاَ يُصْلِحُ عَمَلَ المفسدين } يعني : لا يرضى عمل المفسدين .   قرأ أبو عمرو : السِّحر ،   بالمدِّ على وجه الاستفهام ،   ويكون معناه : { قَالَ موسى مَا جِئْتُمْ بِهِ } يَعني ما الَّذي جئتم به ؟ وتمَّ الكلام .   ثم قال : { السحر إِنَّ الله سَيُبْطِلُهُ إِنَّ الله لاَ يُصْلِحُ عَمَلَ المفسدين } يعني : عمل السحرة .  <br />
