قوله تعالى : { قُلْ يا أهل * أَيُّهَا الناس } يعني : يا أهل مكة { قَدْ جَاءكُمُ الحق مِن رَّبّكُمْ } يعني : محمداً صلى الله عليه وسلم والقرآن ،   { فَمَنُ اهتدى } يعني : من آمن بمحمد صلى الله عليه وسلم والقرآن ،   { فَإِنَّمَا يَهْتَدِى لِنَفْسِهِ } يعني : ثوابه لنفسه ،   { وَمَن ضَلَّ } يعني : ومن كفر ولم يؤمن ،   { فَإِنَّمَا يَضِلُّ عَلَيْهَا } يعني : جنايته على نفسه ،   وإثم الضلالة على نفسه ،   { وَمَا أَنَاْ عَلَيْكُمْ بِوَكِيلٍ } يعني : لست عليكم بمسلط ،   وهذا قبل الأمر بالقتال .  <br />
