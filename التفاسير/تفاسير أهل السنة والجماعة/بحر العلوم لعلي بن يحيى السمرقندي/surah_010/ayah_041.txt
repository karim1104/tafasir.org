قوله تعالى : { وَإِن كَذَّبُوكَ } ،   يعني : المشركين بما أتيتهم به .   { فَقُل لّى عَمَلِى } يعني : ديني .   { وَلَكُمْ عَمَلُكُمْ } ،   يعني : دينكم .   { أَنتُمْ بَرِيئُونَ مِمَّا أَعْمَلُ } وأدين ؛ { وَأَنَاْ بَرِىء مّمَّا تَعْمَلُونَ } وتدينون به غير الله تعالى وهذا قبل أن يؤمر بالقتال ،   ولما نزلت آية القتال نسخت هذه الآية .  <br />
