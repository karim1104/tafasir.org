قوله عز وجل : { إِنَّ الله يُمْسِكُ السماوات } يعني : يحفظ السماوات والأرض { أَن تَزُولاَ } يعني : لئلا تزولا عن مكانها { وَلَئِن زَالَتَا } يعني : يوم القيامة { إِنْ أَمْسَكَهُمَا مِنْ أَحَدٍ مّن بَعْدِهِ } يعني : لا يقدر أحد أن يمسكهما .   ويقال : { وَلَئِن زَالَتَا } يعني : إن زالتا في الحال ،   وهما لا يزولان { إِنَّهُ كَانَ حَلِيمًا } عن قول الكُفَّار ،   حيث قالوا : لله ولد ،   فكادت السماوات والأرض أن تزولا فأمسكهما بحلمه فلم يزولا { غَفُوراً } يعني : متجاوزاً عنهم إن تابوا .   ويقال : { غَفُوراً } حيث لم يعجل عليهم بالعقوبة ،   وأمسك السماوات والأرض أن تزولا .  <br />
