قوله تعالى :<br />
{ قُلْ أَغَيْرَ الله أَبْغِي رَبّا } يعني : يقول أعبد وأطلب رباً غيره { وَهُوَ رَبُّ كُلّ شَيْء } من خلقه في السموات والأرض ،   لأنهم كانوا يقولون له : نحن كفلاء لك بما يصيبك ومن تابعك .   فنزلت { وَلاَ تَكْسِبُ كُلُّ نَفْسٍ إِلاَّ عَلَيْهَا } يعني : إلا لها أو عليها إن كان خيراً فلها وإن كان شراً فعليها { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أخرى } يعني : لا تحمل نفس خطيئة نفس أخرى { ثُمَّ إلى رَبّكُمْ مَّرْجِعُكُمْ } أي مصيركم في الآخرة { فَيُنَبّئُكُم بِمَا كُنتُمْ فِيهِ تَخْتَلِفُونَ } من الدين ،   ويبيّن لكم الحق من الباطل بالمعاينة .  <br />
