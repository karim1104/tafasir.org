ثم قال :<br />
{ وَنُقَلّبُ أَفْئِدَتَهُمْ وأبصارهم } يعني : نترك قلوبهم وأبصارهم مغلقة كما هي ولا أوفقهم .   { كَمَا لَمْ يُؤْمِنُواْ بِهِ أَوَّلَ مَرَّةٍ } قبل نزول الآيات ويقال عند انشقاق القمر : لما لم يعتبروا به ولم يؤمنوا فعاقبهم الله تعالى وختم على قلوبهم فثبتوا على كفرهم .   { وَنَذَرُهُمْ } يقول : وندعهم { فِي طغيانهم } يعني : في ضلالتهم { يَعْمَهُونَ } يعني : يترددون ويتحيرون فيه .   ويقال : { كَمَا لَمْ يُؤْمِنُواْ بِهِ أَوَّلَ مَرَّةٍ } يعني : كما لم يؤمن به أوائلهم من الأمم الخالية لما سألوا الآية من أنبيائهم .  <br />
