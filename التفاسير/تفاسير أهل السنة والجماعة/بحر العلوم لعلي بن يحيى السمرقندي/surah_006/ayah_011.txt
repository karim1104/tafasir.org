ثم أمر المشركين بأن يعتبروا بمن قبلهم وينظروا إلى آثارهم في الأرض فقال :<br />
{ قُلْ سِيرُواْ في الأرض } يعني : قل لأهل مكة سافروا في الأرض { ثُمَّ انظروا } يعني : اعتبروا { كَيْفَ كَانَ عاقبة } يعني : آخر أمر { المكذبين } بالرسل والكتب .   وقال الحسن : { سِيرُواْ في الأرض } يعني : اقرؤوا القرآن فانظروا كيف كان عاقبة المتقدمين في العذاب .  <br />
