قوله تعالى : { وَكَيْفَ أَخَافُ مَا أَشْرَكْتُمْ } يعني : من الأصنام { وَلاَ تَخَافُونَ أَنَّكُمْ أَشْرَكْتُم بالله مَا لَمْ يُنَزّلْ بِهِ عَلَيْكُمْ سلطانا } يقول : كتاباً وعذراً وحجة لكم فيه { فَأَيُّ الفريقين أَحَقُّ بالأمن } من العذاب ؟ الموحّد أم المشرك { إِن كُنتُمْ تَعْلَمُونَ } ذلك .  <br />
