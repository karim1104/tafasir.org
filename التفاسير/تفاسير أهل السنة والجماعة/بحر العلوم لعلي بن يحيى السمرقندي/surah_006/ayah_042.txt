ثم ذكر حال الأمم الماضية لكي يعتبروا فقال عز وجل : { وَلَقَدْ أَرْسَلنَا إلى أُمَمٍ مّن قَبْلِكَ } فكذبوهم على وجه الإضمار { فأخذناهم بالبأساء } يعني : بالخوف والشدة { والضراء } يعني : الزمانة والفقر وسوء الحال والجوع .   وقال الزجاج : البأساء : الجوع ،   والضراء : النقص في الأموال والأنفس { لَعَلَّهُمْ يَتَضَرَّعُونَ } يعني : لكي يرجعوا إليه ويؤمنوا به .  <br />
