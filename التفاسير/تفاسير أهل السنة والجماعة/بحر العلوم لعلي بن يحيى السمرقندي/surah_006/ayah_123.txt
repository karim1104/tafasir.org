ثم قال : { وكذلك جَعَلْنَا فِي كُلّ قَرْيَةٍ أكابر مُجْرِمِيهَا } يعني جعلنا مجرميها أكابرها وجبابرتها كما جعلنا في أهل مكة وهذا معطوف على ما قبله أي مثل ذلك جعلنا في كل قرية كما زين للكافرين { لِيَمْكُرُواْ فِيهَا } يعني : ليتكبروا فيها ويكذبوا رسلهم { وَمَا يَمْكُرُونَ } يعني : وما يصنعون ذلك { إِلاَّ بِأَنفُسِهِمْ } يعني : إلا على أنفسهم { وَمَا يَشْعُرُونَ } أن ذلك على أنفسهم .  <br />
