{ قَالَ أَبَشَّرْتُمُونِى على أَن مَّسَّنِىَ الكبر } أي : بعدما أصابني الكبر والهرم { فَبِمَ تُبَشّرُونَ } قرأ نافع { فَبِمَ تُبَشّرُونَ } بكسر النون مع التخفيف لأن أصله تبشروني بالياء فأقيم الكسر مقامه وقرأ ابن كثير { فَبِمَ تُبَشّرُونَ } بكسر النون مع التشديد ،   لأنه في الأصل بنونين ،   فأدغم إحداهما في الأخرى مثل قوله { تَأْمُرُنني } و { تُحَاجُّوننى } .   وقرأ الباقون { تُبَشّرُونَ } بنصب النون مع التخفيف ،   لأنها نون الجماعة .   وقال أبو عبيدة : هذا أعجب إليّ لصحتها في العربية<br />
