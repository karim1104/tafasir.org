{ وَكَذَّبَ الَّذِينَ مِن قَبلِهِمْ } يعني : من قبل قومك رسلهم كما كذبك قومك { وَمَا بَلَغُواْ } أي : ما بلغ قومك { مِعْشَارَ مَا آتيناهم } يعني : ما بلغ أهل مكة عشر الذي أعطينا الأمم الخالية من الأموال والقوة ،   فأهلكتهم بالعذاب حين كذبوا رسلي { فَكَذَّبُواْ رُسُلِي فَكَيْفَ كَانَ نَكِيرِ } يعني : كيف كان إنكاري وتغييري عليهم وإيش خطر هؤلاء بجنب أولئك فاحذروا مثل عذابهم<br />
