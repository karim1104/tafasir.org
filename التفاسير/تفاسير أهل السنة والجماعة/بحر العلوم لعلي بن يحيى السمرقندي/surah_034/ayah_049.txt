قوله عز وجل : { قُلْ جَاء الحق } يعني : ظهر الإسلام { وَمَا يُبْدِئ الباطل } يعني : لا يقدر الشيطان أن يخلق أحداً { وَمَا يُعِيدُ } يعني : لا يقدر أن يحييه بعد الموت ،   والله تعالى يفعل ذلك .   ويقال : { الباطل } أيضاً الصنم .   وروى ابن مسعود أن النبي صلى الله عليه وسلم دخل مكة وحول الكعبة ثلاثمائة وستون صنماً ،   فجعل يطعنها بعود في يده ،   ويقول «{ جَاء الحق وَزَهَقَ البَاطِلُ } .   { قُلْ جَاء الحق } { وَمَا يُبْدِي البَاطِلُ وَمَا يُعِيدُ } » .  <br />
