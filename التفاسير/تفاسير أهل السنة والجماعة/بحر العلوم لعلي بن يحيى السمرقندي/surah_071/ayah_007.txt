قال عز وجل : { وَإِنّي كُلَّمَا دَعَوْتُهُمْ } إلى التوحيد ،   { لِتَغْفِرَ لَهُمْ جَعَلُواْ أصابعهم في آذانهم } يعني : لا يسمعون دعائي ،   { واستغشوا ثِيَابَهُمْ } يعني : غطوا رؤوسهم بثيابهم لكي لا يسمعوا كلامي .   { وَأَصَرُّواْ } يعني : أقاموا على الكفر والشرك ،   { واستكبروا استكبارا } يعني : تكبروا عن الإيمان تكبراً .  <br />
