{ والذين اجتنبوا الطاغوت } قال مقاتل : يعني : اجتنبوا عبادة الأوثان .   وقال الكلبي : { الطاغوت } يعني : الكهنة { أَن يَعْبُدُوهَا } يعني : أن يطيعوها ،   ورجعوا إلى عبادة ربهم { وَأَنَابُواْ إِلَى الله } أي : أقبلوا إلى طاعة الله .   ويقال : رجعوا من عبادة الأوثان إلى عبادة الله { لَهُمُ البشرى } يعني : الجنة .   ويقال : الملائكة يبشرونهم في الآخرة ،   { فَبَشّرْ عِبَادِ } .  <br />
