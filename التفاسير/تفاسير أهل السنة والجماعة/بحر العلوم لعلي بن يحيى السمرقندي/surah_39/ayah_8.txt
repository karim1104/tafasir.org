ثم قال : { وَإِذَا مَسَّ الإنسان ضُرٌّ } يعني : إذا أصاب الكافر شدة في جسده ،   { دَعَا رَبَّهُ مُنِيباً إِلَيْهِ } يعني : مقبلاً إليه بدعائه { ثُمَّ إِذَا خَوَّلَهُ نِعْمَةً مّنْهُ } قال مقاتل يعني : أعطاه ،   وقال الكلبي : يعني : بدله عافية مكان البلاء { نَسِيَ } ترك الدعاء { مَا كَانَ يَدْعُو إِلَيْهِ مِن قَبْلُ } ويتضرع به ،   { وَجَعَلَ لِلَّهِ أَندَاداً } يعني : يصف لله شريكاً ،   { لّيُضِلَّ عَن سَبِيلِهِ } .   قرأ ابن كثير ،   وأبو عمرو ،   { لِيُضِلَّ } بنصب الياء ،   وهو من ضل يضل .   يعني : ترك الهدى .   وقرأ الباقون : { لِيُضِلَّ } بالضم .   يعني : ليضلّ الناس .   ويقال : ليضل نفسه بعبادة غير الله ،   ويصرفهم عن سبيل الله .   يعني : عن دين الله { قُلْ تَمَتَّعْ بِكُفْرِكَ قَلِيلاً } يعني : عش في الدنيا مع كفرك قليلاً { إِنَّكَ مِنْ أصحاب النار } يعني : من أهل النار .  <br />
