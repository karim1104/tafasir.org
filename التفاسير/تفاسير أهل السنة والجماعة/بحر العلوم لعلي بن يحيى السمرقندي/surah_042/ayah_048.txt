قوله عز وجل : { فَإِنْ أَعْرَضُواْ } عن الإيمان ،   وعن الإجابة ،   بعد ما دعوتهم { فَمَا أرسلناك عَلَيْهِمْ حَفِيظاً } تحفظهم على الإيمان ،   وتجبرهم على ذلك { إِنْ عَلَيْكَ إِلاَّ البلاغ } يعني : ليس عليك ،   إلا تبليغ الرسالة ،   وهذا قبل أن يؤمر بالقتال ،   ثم قال : { وَإِنَّا إِذَا أَذَقْنَا الإنسان مِنَّا رَحْمَةً } يعني : أصبنا الإنسان منا رحمة { فَرِحَ بِهَا } أي بطر بالنعمة .   قال بعضهم : يعني : أبا جهل .   وقال بعضهم : جميع الناس ،   والإنسان هو لفظ الجنس ،   وأراد به جميع الكافرين ،   بدليل أنه قال : { وَإِن تُصِبْهُمْ } ذكر بلفظ الجماعة يعني : إن تصبهم { سَيّئَةٌ } يعني : القحط والشدة { بِمَا قَدَّمَتْ أَيْدِيهِمْ } يعني : بما عملوا من المعاصي { فَإِنَّ الإنسان كَفُورٌ } لنعم الله .   يعني : يشكو ربه عند المصيبة ،   ولا يشكره عند النعمة .  <br />
