{ أَوْ يُزَوّجُهُمْ ذُكْرَاناً وإناثا } يعني : من يشاء الأولاد الذكور ،   والإناث { وَيَجْعَلُ مَن يَشَاء عَقِيماً } فلا يعطيه شيئاً من الولد ويقال : { يَهَبُ لِمَن يَشَاء إناثا } كما وهب للوط النبي { وَيَهَبُ لِمَن يَشَاء الذكور } كما وهب لإبراهيم عليه السلام { أَوْ يُزَوّجُهُمْ ذُكْرَاناً وإناثا } كما جعل للنبي صلى الله عليه وسلم ،   وكما وهب ليعقوب عليه السلام { وَيَجْعَلُ مَن يَشَاء عَقِيماً } كما جعل ليحيى ،   وعيسى عليهما السلام { إِنَّهُ عَلِيمٌ قَدِيرٌ } يعني : عالم بما يصلح لكل واحد منهم .   قادر على ذلك .  <br />
