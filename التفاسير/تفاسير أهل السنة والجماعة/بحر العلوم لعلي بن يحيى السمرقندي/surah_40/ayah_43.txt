{ لاَ جَرَمَ } أي : حقاً يقال { لاَ جَرَمَ } يعني : لا بد .   { أَنَّمَا تَدْعُونَنِي إِلَيْهِ لَيْسَ لَهُ دَعْوَةٌ في الدنيا } أي : ليس له قدرة .   ويقال : ليس له استجابة دعوة تنفع في الدنيا .   { وَلاَ في الآخرة وَأَنَّ مَرَدَّنَا إِلَى الله } أي مصيرنا ،   ومرجعنا إلى الله يوم القيامة ،   { وَأَنَّ المسرفين } يعني : المشركين ،   { هُمْ أصحاب النار } يعني : هم في النار أبداً .  <br />
