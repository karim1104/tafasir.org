{ يَوْمَ هُم بارزون } أي : ظاهرين ،   خارجين من قبورهم ،   { لاَ يخفى عَلَى الله مِنْهُمْ شيء } يعني : من أعمال أهل السماوات ،   وأهل الأرض .  <br />
{ لّمَنِ الملك اليوم } قال بعضهم : هذا بين النفختين .   يقول الرب تبارك وتعالى : { لّمَنِ الملك اليوم } ؟ فلا يجيبه أحد ،   فيقول لنفسه : { للَّهِ الواحد الْقَهَّارِ } .   قال بعضهم : إن ذلك لأهل الجمع يوم القيامة .   يقول : { لّمَنِ الملك اليوم } فأقر الخلائق كلهم ،   وقالوا : { للَّهِ الواحد الْقَهَّارِ } .  <br />
