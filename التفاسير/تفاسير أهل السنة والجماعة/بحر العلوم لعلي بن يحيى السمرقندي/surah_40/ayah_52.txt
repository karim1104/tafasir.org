{ يَوْمَ لاَ يَنفَعُ الظالمين مَعْذِرَتُهُمْ } يعني : لا ينفع الكافرون اعتذارهم .   قرأ ابن كثير وأبو عمرو { يَوْمٌ لاَّ تَنفَعُ } بالتاء بلفظ التأنيث ،   لأن المعذرة مؤنثة .   والباقون : بالياء .   وانصرف إلى المعنى ،   يعني : لا ينفع لهم اعتذارهم { وَلَهُمُ اللعنة } أي : السخطة { وَلَهُمْ سُوء الدار } أي : عذاب جهنم .  <br />
