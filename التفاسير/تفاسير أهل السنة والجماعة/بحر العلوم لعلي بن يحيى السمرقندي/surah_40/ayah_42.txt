ثم بيّن عمل أهل النار فقال : { تَدْعُونَنِي لأكْفُرَ بالله } يعني : لأجحد بوحدانية الله ،   { وَأُشْرِكَ بِهِ } أي : أشرك بالله ،   { مَا لَيْسَ لِي بِهِ عِلْمٌ } يعني : ما ليس لي به حجة بأن مع الله شريكاً ،   { وَأَنَاْ أَدْعُوكُمْ إِلَى العزيز الغفار } يعني : إلى دين العزيز الغفار { العزيز } في ملكه { الغفار } لمن تاب .  <br />
