ثم قال عز وجل : { أَمِ اتخذوا مِن دُونِهِ ءالِهَةً } الميم صلة ،   يعني : أعبدوا من دونه آلهة ؟ { قُلْ هَاتُواْ برهانكم } ،   يعني : حجتكم وكتابكم الذي فيه عذركم .   { هذا ذِكْرُ مَن مَّعِىَ } إلى يوم القيامة { وَذِكْرُ مَن قَبْلِى }  ؛ يعني : خبر من قبلي ،   فلا أجد فيه أن الشرك كان مباحاً في وقت من الأوقات ويقال : { هذا ذِكْرُ مَن مَّعِىَ وَذِكْرُ مَن قَبْلِى } ،   يعني : القرآن وكتب الأولين .   ثم قال : { بَلْ أَكْثَرُهُمْ لاَ يَعْلَمُونَ الحق } يعني لا يصدقون بالقرآن ويقال بالتوحيد .   { فَهُمْ مُّعْرِضُونَ } ،   يعني : مكذبون بالقرآن والتوحيد .  <br />
