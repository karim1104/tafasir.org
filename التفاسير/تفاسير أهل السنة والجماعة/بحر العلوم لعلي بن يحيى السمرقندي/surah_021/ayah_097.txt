قوله تعالى : { واقترب الوعد الحق } ،   يعني : قيام الساعة .   { فَإِذَا هِىَ شاخصة } ،   أي فاتحة { أبصار الذين كَفَرُواْ ياويلنا } ،   يعني : يقولون : يَا وَيْلَنَا { ياويلنا قَدْ كُنَّا فِى غَفْلَةٍ }  ؛ يعني : في جهل { مّنْ هذا } اليوم .   ثم ذكروا أن المرسلين كانوا أخبروهم ،   فقالوا : { بَلْ كُنَّا ظالمين } ،   يعني : قد أخبرونا فكذبناهم .  <br />
