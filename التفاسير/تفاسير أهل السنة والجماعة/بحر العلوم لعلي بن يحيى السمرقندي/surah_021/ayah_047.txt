{ وَنَضَعُ الموازين القسط } ،   يعني : ميزان العدل { لِيَوْمِ القيامة } ،   يعني : في يوم القيامة .   قال ابن عباس : هو ميزان له كفتان ،   وله لسانان يوزن به الأعمال الحسنات والسيئات ،   فيجاء بالحسنات في أحسن صورة ويجاء بالسيئات في أقبح صورة .   { فَلاَ تُظْلَمُ نَفْسٌ شَيْئاً } ،   يعني : لا ينقص من ثواب أعمالهم شيئاً ؛ { وَإِن كَانَ مِثْقَالَ حَبَّةٍ } ،   يعني : وزن حبة { مّنْ خَرْدَلٍ } .   قرأ نافع { مِثْقَالَ حَبَّةٍ } بضم اللام ؛ وقرأ الباقون بالنصب ؛ فمن قرأ بالرفع فمعناه وإن حصل للعبد مثقال حبة من خردل ،   ومن قرأ بالنصب معناه وإن كان العمل مِثْقَالَ حَبَّة يصير خبر كان { أَتَيْنَا بِهَا } ،   يعني : جئنا بها وأحضرناها ،   وقرأ بعضهم { ءاتَيْنَا } بالمد ،   يعني : جازينا بها وأعطينا بها ،   وقراءة العامة بغير مد .   ثم قال : { وكفى بِنَا حاسبين } ،   يعني : مجازين .  <br />
