ثم قال عز وجل : { وَمَا لَكُمْ لاَ تُؤْمِنُونَ بالله } يعني : ما لكم لا تصدقون بوحدانية الله تعالى { والرسول يَدْعُوكُمْ } قرأ بعضهم : { والرسول } بضم اللام .   يعني : ما لكم لا تؤمنون بالله ،   وتم الكلام .  <br />
ثم قال : { والرسول يَدْعُوكُمْ } إلى توحيد الله تعالى .   وقراءة العامة { والرسول } بكسر اللام .   يعني : ما لكم لا تصدقون بالله ،   وبرسوله حين يدعوكم ،   { لِتُؤْمِنُواْ بِرَبّكُمْ } يعني : لتصدقوا بوحدانية الله تعالى { وَقَدْ أَخَذَ ميثاقكم } يعني : أخذ الله تعالى إقراركم ،   والميثاق حين أخرجكم من صلب آدم { إِن كُنتُم مُّؤْمِنِينَ } يعني : مصدقين قرأ أبو عمرو : { وَقَدْ أَخَذَ ميثاقكم } بضم القاف ،   وكسر الخاء ،   على معنى فعل ما لم يسم فاعله ،   والباقون : يعني : أخذ الله ميثاقكم .  <br />
