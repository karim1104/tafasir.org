قوله تعالى : { فَلَوْلا إِذْ جَاءهُمْ بَأْسُنَا } يقول : فهلا إذا جاءهم عذاباً { تَضَرَّعُواْ } إلى الله ويؤمنون به حتى يرفع عنهم العذاب يعني : أنهم لو آمنوا لدفع عنهم العذاب ،   ولكن أصروا على ذلك فذاك قوله تعالى : { ولكن قَسَتْ قُلُوبُهُمْ } يعني : جفت ويبست قلوبهم { وَزَيَّنَ لَهُمُ الشيطان مَا كَانُواّ يَعْمَلُونَ } من عبادتهم الأصنام .  <br />
