ثم قال :<br />
{ وَوَهَبْنَا لَهُ } يعني : لإبراهيم { إسحاق وَيَعْقُوبَ } قال الضحاك : ولدت سارة إسحاق ولها تسعة وتسعون سنة .   ولإبراهيم مائة وعشرون سنة ثم ولد لإسحاق يعقوب { كُلاًّ هَدَيْنَا } يعني : إسحاق ويعقوب هديناهما بالنبوة والإسلام { وَنُوحاً هَدَيْنَا مِن قَبْلُ } يعني : هديناه للنبوة والإسلام من قبل إبراهيم { وَمِن ذُرّيَّتِهِ } قال الكلبي : يعني من ذرية نوح .   وقال الضحاك : يعني من ذرية إبراهيم { دَاوُودُ } النبي عليه السلام { وسليمان } وهو ابن داود { وَأَيُّوبَ } وهو من ولد عيصو بن إسحاق { وَيُوسُفَ } وهو ابن يعقوب { وموسى وهارون وَكَذَلِكَ نَجْزِى المحسنين } يعني : نعطيهم أفضل الثواب .  <br />
