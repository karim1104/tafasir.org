{ قُلِ الله يُنَجّيكُمْ مّنْهَا } يعني : من أهوال البر والبحر { وَمِن كُلّ كَرْبٍ } يعني : ينجيكم من كل كرب .   يعني : من كل غم وشدة { ثُمَّ أَنتُمْ تُشْرِكُونَ } يعني : ترجعون إلى الشرك .   وقرأ بعضهم { يُنَجّيكُمْ } بالتخفيف والقراءة المعروفة بالتشديد وقرأ عاصم وحمزة والكسائي { لَّئِنْ أنجانا } بالألف يعني : أنجانا الله تعالى .   وقرأ الباقون { لأِن أَنْجَيْتَنَا } على معنى المخاطبة .   وقرأ عاصم وحمزة والكسائي { قُلِ الله يُنَجّيكُمْ مّنْهَا } بالتشديد .   وقرأ الباقون بالتخفيف ومعناهما واحد .   ويقال : أنْجَى يُنْجِي ونَجَّى يُنَجِّي .  <br />
