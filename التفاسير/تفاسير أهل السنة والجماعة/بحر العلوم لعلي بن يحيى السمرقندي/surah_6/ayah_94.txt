قوله تعالى : { وَلَقَدْ جِئْتُمُونَا فرادى } يعني : في الآخرة { فرادى } لا ولد لكم ولا مال .  <br />
الفرادى جمع فرد ،   يعني : ليس معكم من دنياكم شيء .   { كَمَا خلقناكم أول مرة } يعني : أعطيناكم من المال والولد { وَتَرَكْتُمْ مَّا خولناكم وَرَاء ظُهُورِكُمْ } في الدنيا .   { وَمَا نرى مَعَكُمْ شُفَعَاءكُمُ } يعني : آلهتكم { الذين زَعَمْتُمْ } في الدنيا { أَنَّهُمْ فِيكُمْ شُرَكَاء } يعني : قلتم لي شريك ولكم شفعاء عند الله .  <br />
{ لَقَد تَّقَطَّعَ بَيْنَكُمْ } قرأ نافع والكسائي وعاصم في رواية حفص { بَيْنِكُمْ } بالنصب وقرأ الباقون { بَيْنِكُمْ } بالضم فمن قرأ بالضمّ جعل البَيْن اسماً ،   يعني : تقطع وصْلُكم ومودتكم .   ومن قرأ بالنصب فمعناه لقد تقطع ما كنتم فيه من الشركة بينكم ،   فيصير نصباً بالظرف كما تقول : أصبحت بينكم أي فيما بينكم .   { وَضَلَّ عَنكُم مَّا كُنتُمْ تَزْعُمُونَ } يعني : اشتغل عنكم ما كنتم تعبدون وتزعمون أنها شفعاؤكم .  <br />
