قوله تعالى :<br />
{ قُلْ أَرَأيْتُمْ } أَيُّ قُلْ لأهْلِ مَكَّةَ { أَرَأَيْتُمْ إِنْ أَخَذَ الله سَمْعَكُمْ } فلم تسمعوا شيئاً { وأبصاركم } فلم تبصروا شيئاً { وَخَتَمَ على قُلُوبِكُمْ } فلم تعقدوا شيئاً { مَّنْ إله غَيْرُ الله } يعني هل أحد يرده عليكم { يَأْتِيكُمْ بِهِ } يعني : يخلقها لكم .  <br />
ثمَّ قال : { انظر كَيْفَ نُصَرّفُ الآيات } أي : كيف تبين لهم العلامات فيما ذكر من تخويفهم { ثُمَّ هُمْ يَصْدِفُونَ } يعني : يُعرضون ولا يعتبرون .   قرأ نافع : { أَرَأيْتُمْ } : بعد الألف بغير همز .   وقرأ الكسائي بغير مد ولا همز .   وقرأ الباقون : بالهمز .   فهي كلها لغات العرب .  <br />
