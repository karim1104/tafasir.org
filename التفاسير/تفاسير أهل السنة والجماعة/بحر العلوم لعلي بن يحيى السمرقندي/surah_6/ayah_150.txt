{ قُلْ هَلُمَّ شُهَدَاءكُمُ الذين يَشْهَدُونَ أَنَّ الله حَرَّمَ هذا } عليكم { فَإِن شَهِدُواْ } على تحريمه { فَلاَ تَشْهَدْ مَعَهُمْ } فأخبر الله أنهم لو شهدوا ،   كانت شهادتهم باطلة ،   ولا يجوز قبول شهادتهم ،   لأنهم يقولون بأهوائهم .  <br />
ثم قال : { وَلاَ تَتَّبِعْ أَهْوَاء الذين كَذَّبُواْ بآياتنا } يعني : بمحمد صلى الله عليه وسلم وبالقرآن { والذين لاَ يُؤْمِنُونَ بالآخرة } يعني : البعث { وَهُم بِرَبِهِمْ يَعْدِلُونَ } يعني يشركون بالله .  <br />
