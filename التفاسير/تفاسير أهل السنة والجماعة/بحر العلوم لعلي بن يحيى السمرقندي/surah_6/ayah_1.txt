{ الحمد للَّهِ الذي خَلَقَ السماوات والأرض } وخاتمتها خاتمة سورة هود : { وَللَّهِ غَيْبُ السماوات والأرض وَإِلَيْهِ يُرْجَعُ الأمر كُلُّهُ فاعبده وَتَوَكَّلْ عَلَيْهِ وَمَا رَبُّكَ بغافل عَمَّا تَعْمَلُونَ } [ هود : 123 ] وقوله تعالى : { الحمد للَّهِ } حمد الرب نفسه ،   ودلّ بصنعه على توحيده ،   { الذي خَلَق السماوات والأرض } يعني : خلق السموات وما فيها من الشمس والقمر والنجوم ،   وخلق الأرض وما فيها { وَجَعَلَ الظلمات والنور } يعني : خلق الليل والنهار .   ويقال : الكفر والإسلام .   وقال الضحاك : هذه الآية نزلت في شأن المجوس .   قالوا : الله خالق النور ،   والشيطان خالق الظلمة ،   فأنزل الله تعالى إكذاباً لقولهم ،   ورداً عليهم ،   فقال : { وَجَعَلَ الظلمات والنور } يعني : أن الله واحد لا شريك له ،   وهو الذي خلق السموات والأرض ،   وهو الذي خلق الظلمات والنور { ثْمَّ الذين كَفَرُواْ } يعني : المجوس { بِرَبّهِمْ يَعْدِلُونَ } يعني : يشركون .   ويقال { ثْمَّ الذين كَفَرُواْ بِرَبّهِمْ يَعْدِلُونَ } يعني : مشركي مكة { بِرَبّهِمْ يَعْدِلُونَ } يعني : يعبدون الأصنام .
