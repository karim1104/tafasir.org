ثم استثنى الذين لم ينقضوا العهد فقال : { إِلاَّ الذين عاهدتم مّنَ المشركين } ،   وهم بنو كنانة وبنو ضمرة ؛ { ثُمَّ لَمْ يَنقُصُوكُمْ شَيْئاً } من عهودكم ،   { وَلَمْ يظاهروا عَلَيْكُمْ أَحَداً }  ؛ يقول : ولم يعاونوا عليكم أحداً { فَأَتِمُّواْ إِلَيْهِمْ عَهْدَهُمْ إلى مُدَّتِهِمْ } ،   يعني : إلى إتمام أجلهم .   { إِنَّ الله يُحِبُّ المتقين } الذين يتقون نقض العهد .  <br />
