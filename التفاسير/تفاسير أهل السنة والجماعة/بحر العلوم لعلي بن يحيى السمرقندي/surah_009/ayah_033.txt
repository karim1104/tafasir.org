ثم قال تعالى : { هُوَ الذي أَرْسَلَ رَسُولَهُ بالهدى } ،   يعني : بالقرآن والتوحيد ،   { وَدِينِ الحق }  ؛ يعني : دين الإسلام ؛ ويقال : دين الله تعالى ،   { لِيُظْهِرَهُ عَلَى الدين كُلّهِ }  ؛ يعني : يظهره بالحجة على الدين كله ؛ ويقال : بالقهر والغلبة والرعب في قلوب الكفار ؛ وقال ابن عباس : { لِيُظْهِرَهُ عَلَى الدين كُلّهِ } يعني : بعد نزول عيسى عليه السلام لا يبقى أحد إلا دخل في دين الإسلام ،   { وَلَوْ كَرِهَ المشركون } .  <br />
