قوله تعالى :<br />
{ العظيم يا أيها النبى جاهد الكفار والمنافقين } ،   يعني : جاهد { الكفار } بالسيف { والمنافقين } بالقول الشديد .   قال ابن مسعود في قوله : { جاهد الكفار والمنافقين } قال : جاهد بيدك ،   فإن لم تستطع فبلسانك ،   فإن لم تستطع فبقلبك والقه بوجه مكفهر ،   وعن الحسن قال : { جاهد الكفار } بالسيف { والمنافقين } بالحدود ،   يعني : أقم عليهم حدود الله .   { واغلظ عَلَيْهِمْ } ،   يعني : أشدد عليهم ،   يعني : على الفريقين جميعاً في المنطق .  <br />
ثم بيَّن مرجعهم جميعاً في الآخرة وقال : { وَمَأْوَاهُمْ جَهَنَّمُ } ،   يعني : مصيرهم ومآلهم إلى جهنم ،   { وَبِئْسَ المصير } الذي صاروا إليه .  <br />
