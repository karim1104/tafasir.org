{ الر } قال ابن عباس رضي الله عنهما يعني : أنا الله أرى ،   ويقال : الألف آلاؤه ،   واللام لطفه ،   والراء ربوبيته .   { كِتَابٌ } يعني : هذا الكتاب ،   وهو القرآن { أحكمت آياته } من الباطل ،   فلم يوجد فيه عوج ولا تناقض .   { ثُمَّ فُصّلَتْ } يعني : بيَّن أمره ونهيه .   وقال الحسن : { أحكمت آياته } بالأمر والنهي ،   وفصلت بالوعد والوعيد ،   والثواب والعقاب .   وقال مجاهد : { فصلت } أي فُسِّرت .   وقال القتبي : { أحكمت } ،   فلم تنسخ ،   ثم { فُصّلت } بالحلال والحرام .   ويقال : { فصلت } ،   أي : أنزلت شيئاً بعد شيء ،   فلم تنزل جملة واحدة .  <br />
{ مِن لَّدُنْ حَكِيمٍ خَبِيرٍ } يعني : أنزل جبريل على محمد صلى الله عليه وسلم من عند الله تعالى { حكيم } في أمره ،   { خبير } بالعباد وبأعمالهم<br />
