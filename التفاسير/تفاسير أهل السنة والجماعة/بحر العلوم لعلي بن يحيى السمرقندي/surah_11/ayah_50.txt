قوله تعالى : { وإلى عَادٍ } يعني : أرسلنا إلى عاد { أخاهم } نبيُّهم { هُودًا قَالَ يَا قَوْمٌ  اعبدوا الله } يعني : وحِّدُوا الله ،   { مَا لَكُم مّنْ إله غَيْرُهُ } يعني : ليس لكم من رب سواه ،   { إِنْ أَنتُمْ إِلاَّ مُفْتَرُونَ } يعني : ما أنتم إلا تكذبون في مقالتكم بأن لله شريكاً .  <br />
