ثم قال عز وجل : { لَهُمْ فِيهَا مَا يَشَآءونَ } أي : يحبون { خالدين } أي : دائمين في الجنة { كَانَ على رَبّكَ وَعْداً } منه في الدنيا { مَسْؤُولاً } يسأله المتقون .   ويقال { مَسْؤُولاً } يسأل لهم الملائكة عليهم السلام ،   وهو قوله عز وجل : { رَبَّنَا وَأَدْخِلْهُمْ جنات عَدْنٍ التى وَعَدْتَّهُمْ وَمَن صَلَحَ مِنْ ءَابَآئِهِمْ وأزواجهم وذرياتهم إِنَّكَ أَنتَ العزيز الحكيم } [ غافر : 8 ] ويقال : وعداً على لسان رسولهم ،   وقد سألوا الله عز وجل ذلك ،   وهو قوله : { رَبَّنَا وَءاتِنَا مَا وَعَدتَّنَا على رُسُلِكَ } ويقال : وعداً لا خلف فيه لمن سأله .
