{ فَأَصْبَحَ } موسى { فِى المدينة خَائِفاً } أن يؤخذ فيقتل { يَتَرَقَّبُ } يعني : ينتظر الطلب .   ويقال : ينتظر الأخبار { فَإِذَا الذي استنصره بالأمس يَسْتَصْرِخُهُ } يعني : رأى الإسرائيلي كان يقاتل مع رجل آخر من القبط يستصرخه يعني : يستغيثه كقوله : { وَقَالَ الشيطان لَمَّا قُضِيَ الأمر إِنَّ الله وَعَدَكُمْ وَعْدَ الحق وَوَعَدتُّكُمْ فَأَخْلَفْتُكُمْ وَمَا كَانَ لِىَ عَلَيْكُمْ مِّن سلطان إِلاَّ أَن دَعَوْتُكُمْ فاستجبتم لِي فَلاَ تَلُومُونِي ولوموا أَنفُسَكُمْ مَّآ أَنَاْ بِمُصْرِخِكُمْ وَمَآ أَنتُمْ بِمُصْرِخِىَّ إِنِّي كَفَرْتُ بِمَآ أَشْرَكْتُمُونِ مِن قَبْلُ إِنَّ الظالمين لَهُمْ عَذَابٌ أَلِيمٌ } [ إبراهيم : 22 ] يعني : بمغيثكم { قَالَ لَهُ موسى } يعني : للإسرائيلي { إِنَّكَ لَغَوِىٌّ مُّبِينٌ } يعني : ضال بيّن ويقال جاهل بين ويقال : ظاهر الغواية ،   وقد قتلت لك الأمس رجلاً ،   وتدعوني إلى آخر
