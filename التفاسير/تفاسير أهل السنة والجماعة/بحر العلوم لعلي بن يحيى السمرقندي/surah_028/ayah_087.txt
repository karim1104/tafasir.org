{ وَلاَ يَصُدُّنَّكَ عَنْ ءايات الله } يعني : لا يصرفنك عن آيات الله القرآن والتوحيد { بَعْدَ إِذْ أُنزِلَتْ إِلَيْكَ } أي : بعد ما أنزل إليك جبريل عليه السلام بالقرآن { وادع إلى رَبّكَ } يعني : ادع الخلق إلى توحيد ربك { وَلاَ تَكُونَنَّ مِنَ المشركين } يعني : لا تكونن مع المشركين على دينهم<br />
