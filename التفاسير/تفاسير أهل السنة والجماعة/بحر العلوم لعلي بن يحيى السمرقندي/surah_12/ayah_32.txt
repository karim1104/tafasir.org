وكذلك الذي بعده { قَالَتْ } زليخا للنسوة { فذلكن الذى لُمْتُنَّنِى فِيهِ } يقول : عذلتنني فيه وعبتنني فيه فهل عذرتنني ؟ فقلن لها : أنت معذورة .   قالت : { وَلَقَدْ رَاوَدتُّهُ عَن نَّفْسِهِ } يعني : طلبت إليه أن يمكنني من نفسه { فاستعصم } أي فامتنع بنفسه مني { وَلَئِن لَّمْ يَفْعَلْ مَا ءامُرُهُ لَيُسْجَنَنَّ } يعني : احبسنه في السجن { وَلَيَكُونًا مّن الصاغرين } يعني : من المهانين بالسجن .   ويقال : مذللين .   وقرأ بعضهم { لَّيَكُونُنَّ } بتشديد النون وهذا خلاف مصحف الإمام .   وقراءة العامة : { وَلَيَكُونًا } لأن النون الخفيفة تبدل منها في الوقف بالألف .  <br />
