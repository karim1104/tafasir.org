{ قَالُواْ أَءنَّكَ لاَنتَ يُوسُفُ } قرأ ابن كثير { إِنَّكَ لأنتَ يوسف } بهمزة واحدة ،   وكسر الألف .   يعني : حققوا أنه يوسف .   وقرأ حمزة ،   والكسائي ،   وعاصم ،   وابن عامر : { أَءنَّكَ } بهمزتين على معنى الاستفهام .   يعني : إنك يوسف أم لا ؟ وقرأ نافع وأبو عمرو ،   { آينك } بهمزة واحدة مع المد .   ومعناه : مثل الأول على معنى الاستفهام { يُوسُفُ قَالَ أَنَاْ يُوسُفُ وهذا أَخِى قَدْ مَنَّ الله عَلَيْنَا } يعني : أنعم علينا بالصبر { إِنَّهُ مَن يَتَّقِ } أي : يتق الله { وَيِصْبِرْ } على البلاء { فَإِنَّ الله لاَ يُضِيعُ أَجْرَ المحسنين } أي : ثواب الصابرين .  <br />
