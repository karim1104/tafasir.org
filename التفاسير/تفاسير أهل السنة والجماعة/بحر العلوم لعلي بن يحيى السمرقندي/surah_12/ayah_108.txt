{ قُلْ } يا محمد { هَذِهِ سَبِيلي } يعني : هذه الملة ،   ديني الإسلام ،   ويقال : هذه دعوتي { أدْعُوا } الخلق { إلَى الله } تعالى .   ويقال : أدعوكم إلى توحيد الله وعبادته { عَلَى بَصِيرَةٍ } أي : على يقين وحقيقة .   ويقال : على بيان { أنَا وَمَنِ اتَّبَعَنِي } يعني : من اتبعني على ديني ،   فهو أيضاً على بصيرة { وَسُبْحَانَ الله } تنزيهاً لله عن الشرك { وَمَا أَنَا مِنَ المُشْرِكِينَ } على دينهم .  <br />
