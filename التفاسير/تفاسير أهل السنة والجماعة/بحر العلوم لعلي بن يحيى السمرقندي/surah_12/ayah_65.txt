قوله تعالى : { وَلَمَّا فَتَحُواْ متاعهم } يعني : أوعيتهم وجواليقهم { وَجَدُواْ بضاعتهم } يعني : دراهمهم { رُدَّتْ إِلَيْهِمْ قَالُواْ } لأبيهم { يأَبَانَا مَا نَبْغِى } يعني : ما نكذب .   إنه ألطف علينا وأكرمنا { هذه بضاعتنا } أي : دراهمنا { رُدَّتْ إِلَيْنَا وَنَمِيرُ أَهْلَنَا } يعني : نمتار لأهلنا .   يقال : مار أهله ،   وأمار لأهله ،   إذا حمل إليهم قوتهم من غير بلده .   يعني : ابعثه معنا ،   لكي نحمل الطعام لأهلنا { وَنَحْفَظُ أَخَانَا } من الضيعة { وَنَزْدَادُ كَيْلَ بَعِيرٍ } أي : حمل بعير من أجله .  <br />
روى الأعمش عن إبراهيم ،   عن علقمة ،   أنه كان يقرأ { رُدَّتْ إِلَيْنَا } بكسر الراء ،   لأن أصله رددت .   فأدغمت إحدى الدالين بالأخرى ،   ونقل الكسر إلى الراء وهي قراءة شاذة .  <br />
ثم قال : { ذلك كَيْلٌ يَسِيرٌ } يعني : سريع ،   لا حبس فيه إن أرسلته معناه ويقال : ذلك أمر هين الذي نسأل منك .  <br />
