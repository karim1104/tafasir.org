ثم قال عز وجل : { يا أيها الذين آمَنُواْ لاَ تُلْهِكُمْ أموالكم } يعني : لا تشغلكم أموالكم { وَلاَ أولادكم عَن ذِكْرِ الله } يعني : عن طاعة الله تعالى .   { وَمَن يَفْعَلْ ذلك } يعني : من لم يعمل بطاعته ولم يؤمن بوحدانيته ،   { فَأُوْلَئِكَ هُمُ الخاسرون } يعني : المغبونين بذهاب الدنيا وحرمان الآخرة .  <br />
