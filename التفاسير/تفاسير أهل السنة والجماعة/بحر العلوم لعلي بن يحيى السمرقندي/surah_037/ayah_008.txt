ثم قال : { لاَ يَسْمَعُونَ } قرأ حمزة ،   والكسائي ،   وعاصم ،   في رواية حفص : { لاَ يَسْمَعُونَ } بنصب السين والتشديد .   والباقون : { يَسْمَعُونَ } بنصب الياء ،   وجزم السين ،   مع التخفيف .   فمن قرأ : بجزم السين فهو بمعنى يسمعون .   ومن قرأ بالتشديد فأصله يتسمعون ،   فأدغمت التاء في السين ،   وشددت .   يعني : لكيلا يستمعون { إلى الملإ الأعلى } يعني : إلى الكتبة { وَيَقْذِفُونَ } يعني : يرمون { مِن كُلّ جَانِبٍ دُحُوراً }<br />
