{ واللاتي يَأْتِينَ الفاحشة مِن نّسَائِكُمْ } يعني الزنى وهي المرأة الثيب إذا زنت { فاستشهدوا عَلَيْهِنَّ } أي اطلبوا عليهن { أَرْبَعَةِ } من الشهود { مّنكُمْ } أي من أحراركم المسلمين عدولاً { فَإِن شَهِدُواْ } عليهن بالزنى { فَأَمْسِكُوهُنَّ في البيوت } يعني : احبسوهن في السجن { حتى يَتَوَفَّاهُنَّ الموت } أي حتى يمتن في السجن { أَوْ يَجْعَلَ الله لَهُنَّ سَبِيلاً } يعني مخرجاً من الحبس ،   ثم نسخ فصار حدهن الرجم لما روي عن عبادة بن الصامت رضي الله عنه أن النبي صلى الله عليه وسلم قال : « خُذُوا عَنِّي خُذُوا عَنِّي قَدْ جَعَلَ الله لَهُنَّ سَبِيلاً البِكْرُ بِالبِكْرِ جَلْدُ مائَةٍ وَتَغْرِيبُ عَامٍ وَالثَّيِّبُ بِالثَّيِّبِ جَلْدُ مِائَةٍ وَالرَّجْمُ بِالحِجَارَةِ  »<br />
