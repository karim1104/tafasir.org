ثم قال تعالى :<br />
{ وَللَّهِ مَا في السماوات وَمَا فِي الأرض وَلَقَدْ وَصَّيْنَا } أي أمرنا { الذين أُوتُواْ الكتاب مِن قَبْلِكُمْ } يعني أهل التوراة والإنجيل { وإياكم } يعني أمرناكم يا أمة محمد عليه السلام في كتابكم { أَنِ اتقوا الله } فيما أوصاكم به في كتابكم من التوحيد ،   ثم بعد التوحيد بالشرائع { وَإِن تَكْفُرُواْ } يقول : تجحدوا بما أوصاكم وبوحدانية الله تعالى { فَإِنَّ للَّهِ مَا في السماوات وَمَا فِي الأرض } يعني هو غني عن عبادتكم { وَكَانَ الله غَنِيّاً } عن إيمان الخلق وطاعتهم { حَمِيداً } محموداً في أفعاله .  <br />
