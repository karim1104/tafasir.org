ثم قال تعالى : { يَوْمَئِذٍ يَوَدُّ الذين كَفَرُواْ } يعني : يتمنى الذين كفروا يعني الكفار { وَعَصَوُاْ الرسول لَوْ تسوى بِهِمُ الأرض } أي يكونوا تراباً يمشي عليهم أهل الجمع { وَلاَ يَكْتُمُونَ الله حَدِيثاً } وهو قولهم : { والله رَبّنَا مَا كُنَّا مُشْرِكِينَ } .   قال الزجاج : قال بعضهم : { وَلاَ يَكْتُمُونَ الله حَدِيثاً } مستأنف ،   لأن ما عملوا ظاهر عند الله تعالى لا يقدرون على كتمانه .   وقال بعضهم : هو كلام بناء يعني يودون أن الأرض سويت بهم ،   وأنهم لم يكتموا الله حديثاً لأنه مظهر كذبهم .   قرأ حمزة والكسائي { تسوى } بنصب التاء وتخفيف السين وتشديد الواو يعني يخسف بهم ،   وقرأ عاصم وابن كثير وأبو عمرو { تسوى } بضم التاء فأدغم إحدى التاءين في الأخرى على فعل لم يسم فاعله ،   أي يصيروا تراباً وتسوى بهم الأرض .   وقرأ نافع وابن عامر : { تسوى } بنصب التاء وتشديد السين والواو ،   لأن أصله تتسوى فأدغم إحدى التاءين في السين .  <br />
