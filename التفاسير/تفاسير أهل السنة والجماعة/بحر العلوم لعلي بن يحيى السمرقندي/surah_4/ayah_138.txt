ثم قال تعالى :<br />
{ بَشّرِ المنافقين } وذلك أنه لما نزل قوله تعالى : { لِّيَغْفِرَ لَكَ الله مَا تَقَدَّمَ مِن ذَنبِكَ وَمَا تَأَخَّرَ وَيُتِمَّ نِعْمَتَهُ عَلَيْكَ وَيَهْدِيَكَ صراطا مُّسْتَقِيماً } [ الفتح : 2 ] فقال المؤمنون هذا لك فما لنا ؟ فنزل قوله تعالى : { وَبَشِّرِ المؤمنين بِأَنَّ لَهُمْ مِّنَ الله فَضْلاً كِبِيراً } [ الأحزاب : 47 ] فقال المنافقون : فما لنا ؟ فنزل قوله تعالى { بَشّرِ المنافقين } { بِأَنَّ لَهُمْ عَذَاباً أَلِيماً } في الآخرة .
