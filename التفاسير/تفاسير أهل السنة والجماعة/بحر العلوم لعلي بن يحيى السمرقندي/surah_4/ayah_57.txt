ثم بيّن مصير الذين صدقوا به فقال عز وجل : { والذين آمَنُواْ وَعَمِلُواْ الصالحات } يعني آمنوا بمحمد صلى الله عليه وسلم ،   وبالقرآن { وَعَمِلُواْ الصالحات } يعني الطاعات التي أمرهم الله بها { سَنُدْخِلُهُمْ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا الأنهار خَالِدِينَ فِيهَا } أي مقيمين فيها { أَبَداً لَّهُمْ فِيهَا أَزْوَاجٌ مُّطَهَّرَةٌ } في الخلق والخلق { وَنُدْخِلُهُمْ ظِلاًّ ظَلِيلاً } .   قال الضحاك : يعني ،   ظلال أشجار الجنة ،   وظلال قصورها وقال الكلبي : يعني { ظلاً ظليلاً } أي دائماً .   وقال أكنان القصور ،   ( ظَلِيلا ) يعني لا خلل فيها .  <br />
