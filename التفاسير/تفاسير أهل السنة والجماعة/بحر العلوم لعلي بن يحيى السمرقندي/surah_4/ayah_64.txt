وقوله تعالى :<br />
{ وَمَا أَرْسَلْنَا مِن رَّسُولٍ } و{ من } صلة فكأنه يقول : وما أرسلنا رسولاً { إلاَّ لِيُطَاعَ بِإِذْنِ الله } أي لكي يطاع بأمر الله .   ثم قال تعالى : { وَلَوْ أَنَّهُمْ إِذ ظَّلَمُواْ أَنفُسَهُمْ } بصنعهم { جاءوك } بالتوبة { جَاءوكَ فاستغفروا الله } لذنوبهم { واستغفر لَهُمُ الرسول لَوَجَدُواْ الله تَوَّاباً رَّحِيماً } أي متجاوزاً .  <br />
