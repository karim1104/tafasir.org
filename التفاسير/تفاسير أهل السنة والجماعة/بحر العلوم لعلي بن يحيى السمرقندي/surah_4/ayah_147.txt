قوله تعالى : { مَّا يَفْعَلُ الله بِعَذَابِكُمْ } أي ما يصنع الله بعذابكم { إِن شَكَرْتُمْ } يعني إن آمنتم بالله تعالى ووحدتموه ،   ويقال : معناه ما حاجة الله إلى تعذيبكم لو كنتم موحدين شاكرين له { وَآمَنتُمْ } به وصدقتم رسله .   ثم قال تعالى : { وَكَانَ الله شاكرا عَلِيماً } أي { شاكرا } للقليل من أعمالكم ،   { عليما } بأعمالكم وثوابكم .   ويقال : { شاكرا }ً يقبل اليسير ويعطي الجزيل ،   { عليما }ً بما في صدوركم .   ويقال : بمن شكر وآمن فلا يعذب شاكراً ولا مؤمناً .  <br />
