{ وَإِنّى لَغَفَّارٌ لّمَن تَابَ وَامَنَ } ،   يعني : رجع من الشرك والذنوب { وَامَنَ } يعني : صدق بالله ورسله ،   { وَعَمِلَ صالحا }  ؛ يعني : خالصاً فيما بينه وبين ربه ،   { ثُمَّ اهتدى }  ؛ يعني : علم أن لعمله ثواباً ؛ وهذا قول مقاتل .   وروى جويبر عن الضحاك في قوله { ثُمَّ اهتدى } أي : ثم استقام ،   وروى وكيع عن سفيان قال { ثُمَّ اهتدى } ،   أي : مات على ذلك وقال ابن عباس : { ثُمَّ اهتدى } أي : مات على السنة .  <br />
