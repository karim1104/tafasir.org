{ قَالَ } لهم موسى : { بَلْ أَلْقُواْ } ،   فألقوا في الكلام مضمر .   { فَإِذَا حِبَالُهُمْ وَعِصِيُّهُمْ يُخَيَّلُ إِلَيْهِ } ،   يعني : تراءت إلى موسى { مِن سِحْرِهِمْ أَنَّهَا تسعى } ،   يعني : كأنها حيات .   وروي عن الحسن أنه كان يقرأ بالتاء { تُخَيَّلُ } لأن جمع العصي مؤنث ،   وقراءة العامة بالياء يعني : سعيها .  <br />
