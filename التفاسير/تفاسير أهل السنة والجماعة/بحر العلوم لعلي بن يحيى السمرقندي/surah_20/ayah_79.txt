{ وَأَضَلَّ فِرْعَوْنُ قَوْمَهُ وَمَا هدى } ،   يعني : أهلكهم وما نجا بنفسه ،   ويقال : أضلهم بحمله إياهم على الضلالة ،   { وَمَا هدى } يعني : ما هداهم إلى الرشاد وهذا رد لقوله : { وَقَالَ الذى ءَامَنَ ياقوم اتبعون أَهْدِكُمْ سَبِيلَ الرشاد } [ غافر : 38 ] ويقال : { وَمَا هدى } يعني : ما هداه إلى الصواب .
