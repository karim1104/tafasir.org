ثم قال : { عَنِ النبإ العظيم } يعني : يتساءلون عن الخبر العظيم ،   وهو القرآن كقوله : { قُلْ هُوَ نَبَأٌ عَظِيمٌ أَنتُمْ عَنْهُ مُعْرِضُونَ } [ ص : 68 ] ويقال : معناه عن ماذا يتحدثون ،   وعن أي شيء يتحدثون .   ثم قال : { عَنِ النبإ العظيم } يعني : خبراً عظيماً .   وقال الزجاج : أصله { عَمَّا يَتَسَاءلُونَ } ثم بين فقال : { عَنِ النبإ العظيم } يعني : عن أمر النبي صلى الله عليه وسلم .   وقيل : عن القرآن .   وقيل { عَنِ النبإ العظيم } يعني : عن البعث والدليل قوله تعالى : { إِنَّ يَوْمَ الفصل كَانَ ميقاتا } [ النبأ : 17 ] ثم بين لهم الأمر الذي كانوا يتساءلون ،   وهو البعث .
