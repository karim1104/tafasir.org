ثم قال { وكذلك أنزلناه } يعني : القرآن { حُكْمًا } يعني : القرآن حكماً على الكتب كلها .   ويقال : محكماً { عَرَبِيّاً } يعني : القرآن بلغة العرب <br />
{ وَلَئِنِ اتبعت أَهْوَاءهُم } قال الكلبي : يعني : لئن صليت إلى قبلتهم يعني : نحو بيت المقدس { بَعْدِ مَا جَاءكَ مِنَ العلم } يعني : من بعد ما أتاك العلم بأن قبلتك نحو الكعبة .   ويقال : { وَلَئِنِ اتبعت أَهْوَاءهُم } يعني : أهل مكة فيما يدعونك إلى دين آبائك بعد ما ظهر لك أن الإسلام هو الحق { مَا لَكَ مِنَ الله } يعني : من عذابه { مِن وَلِىّ } ينفعك { وَلاَ وَاقٍ } يقيك من عذاب الله ،   الخطاب للنبي صلى الله عليه وسلم والمُراد به أصحابه .  <br />
