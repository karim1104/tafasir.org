قوله تعالى : { وَلَقَدِ استهزىء بِرُسُلٍ مّن قَبْلِكَ } كما استهزأ بك قومك { فَأَمْلَيْتُ لِلَّذِينَ كَفَرُواْ } يعني : أمهلتهم بعد الاستهزاء ،   ولم أعاقبهم { ثُمَّ أَخَذْتُهُمْ } بالعذاب عند المعصية بالتكذيب ،   فأهلكتهم { فَكَيْفَ كَانَ عِقَابِ } يعني : فكيف رأيت إنكاري وتعبيري عليهم بالعذاب .   لم ير النبي صلى الله عليه وسلم عقوبتهم إلا أنه علم بحقيقته فكان رأي عيانٍ .  <br />
