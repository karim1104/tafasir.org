قوله تعالى : { كَذَلِكَ أَرْسَلْنَاكَ فِى أُمَّةٍ } يقول : هكذا بعثناك في أمة كما بعثنا إلى من كان قبلك من الرجال في الأمم الخالية { قَدْ خَلَتْ مِن قَبْلِهَا } يعني : قد مضت من قبل قومك { أُمَمٌ لّتَتْلُوَ عَلَيْهِمُ } يعني : أرسلناك لتقرأ عليهم { الذى أَوْحَيْنَا إِلَيْكَ } من القرآن { وَهُمْ يَكْفُرُونَ بالرحمن } يعني : يجحدون ،   ويكذبون ،   وذلك أن عبد الله بن أمية المخزومي وأصحابه ،   قالوا : ما نعرف الرحمن إلا مسيلمة الكذاب .  <br />
قال الله تعالى : { قُلْ هُوَ رَبّى } يعني : قل يا محمد : الرحمن الذي تكفرون به ،   هو الله ربي الذي { لا إله إِلاَّ هُوَ عَلَيْهِ تَوَكَّلْتُ } يعني : فوضت أمري إليه { وَإِلَيْهِ مَتَابِ } يعني : وإليه أتوب وأرجع .  <br />
