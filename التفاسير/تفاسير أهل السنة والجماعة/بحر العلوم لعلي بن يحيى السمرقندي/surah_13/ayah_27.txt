قوله تعالى : { وَيَقُولُ الذين كَفَرُواْ لَوْلا } يعني : هلاَّ { وَيَقُولُونَ لَوْلاَ أُنزِلَ عَلَيْهِ ءايَةٌ من ربه } يعني : علامة لنبوته { قُلْ إِنَّ الله يُضِلُّ مَن يَشَاء } من عباده من الهدى يعني : إذا لم يرغب فيه { وَيَهْدِى إِلَيْهِ } يرشد إلى دينه { مَنْ أَنَابَ } يعني : من رجع إلى الحق .   ويقال : رجع عن الشرك .  <br />
