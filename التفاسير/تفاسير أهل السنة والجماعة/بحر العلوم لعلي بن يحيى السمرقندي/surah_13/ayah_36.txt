ثم قال تعالى : { والذين ءاتيناهم الكتاب } أي : التوراة { يَفْرَحُونَ بِمَا أُنزِلَ إِلَيْكَ } وهم مؤمنو أهل الكتاب ،   يعجبون بذكر الرحمن { وَمِنَ الأحزاب مَن يُنكِرُ بَعْضَهُ } يعني : أهل مكة ينكرون ذكر الرحمن ،   ويقولون : ما نعرف الرحمن إلا صاحب اليمامة ،   يعنون : مسيلمة الكذاب .   ويقال : { وَمِنَ الأحزاب مَن يُنكِرُ بَعْضَهُ } يعني : ومِن أهل الكتاب من ينكر ما كان فيه نسخ شرائعهم { قُلْ } يا محمد { إِنَّمَا أُمِرْتُ أَنْ أَعْبُدَ الله } يعني : أمرت أن أقيم على التوحيد { وَلاَ أُشْرِكُ بِهِ } شيئاً .  <br />
ثم قال : { إِلَيْهِ أَدْعُو } يقول : أدعو الخلق إلى توحيده { وَإِلَيْهِ مَآبِ } يعني : المرجع في الآخرة .  <br />
