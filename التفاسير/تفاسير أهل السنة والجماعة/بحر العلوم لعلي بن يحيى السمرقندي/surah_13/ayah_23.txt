فقال تعالى : { جنات عَدْنٍ يَدْخُلُونَهَا وَمَنْ صَلَحَ } يعني : ومن آمن ،   وأطاع الله تعالى { مِنْ ءابَائِهِمْ وأزواجهم وذرياتهم } يدخلون أيضاً جنات عدن وهذا كقوله : { والذين ءَامَنُواْ واتبعتهم ذُرِّيَّتُهُم بإيمان أَلْحَقْنَا بِهِمْ ذُرِّيَّتَهُمْ وَمَآ ألتناهم مِّنْ عَمَلِهِم مِّن شَىْءٍ كُلُّ امرىء بِمَا كَسَبَ رَهَينٌ } [ الطور : 21 ] { والملائكة يَدْخُلُونَ عَلَيْهِمْ مّن كُلّ بَابٍ } ويسلمون عليهم
