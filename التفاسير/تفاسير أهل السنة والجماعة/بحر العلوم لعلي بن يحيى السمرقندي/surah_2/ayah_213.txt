قوله : { كَانَ الناس أُمَّةً واحدة } .   قال الزجاج : الأمة على وجوه منها القرن من الناس ،   كما يقال : مضت أمم أي قرون ،   والأمة : الرجل الذي لا نظير له .   ومنه قوله تعالى : { إِنَّ إبراهيم كَانَ أُمَّةً قانتا لِلَّهِ حَنِيفًا وَلَمْ يَكُ مِنَ المشركين } [ النحل : 120 ] والأمة : الدين وهو الذي قال ها هنا : { كَانَ الناس أُمَّةً واحدة } ،   أي على دين واحد وعلى ملة واحدة .   وقال بعضهم : كان الناس كلهم على دين الإسلام ،   جميع من كان مع نوح في السفينة ثم تفرقوا .   { فَبَعَثَ الله النبيين } .   وقال بعضهم : كان الناس كلهم كفاراً في عهد نوح وعهد إبراهيم عليهما السلام فبعث الله للناس النبيين إبراهيم وإسماعيل ،   ولوطاً وموسى ومن بعدهم { مُبَشّرِينَ } بالجنة لمن أطاع الله ،   { وَمُنذِرِينَ } بالنار لمن عصى الله { وَأَنزَلَ مَعَهُمُ الكتاب بالحق } ،   يقول : بالعدل { لِيَحْكُمَ بَيْنَ الناس } ،   أي يقضي بينهم { فِيمَا اختلفوا فِيهِ } من أمور الدين .   { وَمَا اختلف فِيهِ } ،   أي في الدين .   { إِلاَّ الذين أُوتُوهُ } ،   يعني أعطوا الكتاب .   { مِن بَعْدِ مَا جَاءتْهُمُ البينات } ،   أي البيان من الله .   { بَغْياً بَيْنَهُمْ } ،   يعني اختلفوا فيه حسداً بينهم .   { فَهَدَى الله الذين آمَنُواْ لِمَا اختلفوا فِيهِ مِنَ الحق بِإِذْنِهِ } ،   أي هداهم ووفقهم حتى أبصروا الحق من الباطل { بِإِذْنِهِ } بتوفيقه ويقال : برحمته .   { والله يَهْدِي مَن يَشَاء إلى صِرَاطٍ مُّسْتَقِيمٍ } ،   يعني الإسلام .   وقال بعضهم : فهدى الله الذين آمنوا لما اختلفوا فيه من الحق بإذنه أي بعصمته { والله يَهْدِي } أي يوفق من يشاء إلى صراط مستقيم .
