قوله تعالى : { وَإِذْ قَالَ موسى } وقد قال موسى { لِقَوْمِهِ يا قوم لَّم تُؤْذُونَنِي } بالتكذيب ،   وذلك أنهم كذبوه وقالوا : إنه آدر ،   ويقال : إنه حين مات هارون ،   ويقال : إنه قال لقومه الكفار : لم تؤذونني بالتكذيب والشتم ؟ { وَقَد تَّعْلَمُونَ أَنّي رَسُولُ الله إِلَيْكُمْ فَلَمَّا زَاغُواْ } يعني : مالوا عن الحق وعدلوا عنه .   { أَزَاغَ الله قُلُوبَهُمْ } يعني : خذلهم عن الهدى فثبتوا على اليهودية .   { والله لاَ يَهْدِى } يعني : لا يرشد إلى دينه { القوم الفاسقين } ،   يعني : العاصين المكذبين ،   الذين لا يرغبون في الحق .  <br />
