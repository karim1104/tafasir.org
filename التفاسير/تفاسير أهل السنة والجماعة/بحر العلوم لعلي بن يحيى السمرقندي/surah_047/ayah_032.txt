قوله عز وجل : { إِنَّ الذين كَفَرُواْ } يعني : جحدوا { وَصُدُّواْ } يعني : صرفوا الناس عن دين الإسلام { عَن سَبِيلِ الله } قال مقاتل : يعني : اليهود .   وقال الكلبي : يعني : رؤساء قريش حيث شاقوا أهل التوحيد { وَشَاقُّواْ الرسول } يعني : عادوا الله تعالى ،   ورسوله ،   وخالفوا رسول الله صلى الله عليه وسلم في الدين { مّن بَعْدِ مَا تَبَيَّنَ لَهُمُ الهدى } يعني : الإسلام ،   وأمر النبي صلى الله عليه وسلم أنه الحق { لَن يَضُرُّواْ الله شَيْئاً } يعني : لن ينقصوا الله من ملكه شيئاً بكفرهم ،   بل يضروا بأنفسهم { وَسَيُحْبِطُ أعمالهم } يعني : يبطل ثواب أعمالهم التي عملوا في الدنيا ،   فلا يقبلها منهم .  <br />
