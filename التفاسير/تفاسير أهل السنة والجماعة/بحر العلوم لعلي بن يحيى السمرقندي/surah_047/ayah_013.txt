قوله تعالى : { وَكَأَيّن مّن قَرْيَةٍ } يعني : وكم من قرية فيما مضى .   يعني : أهل قرية { هِي أَشَدُّ قُوَّةً } يعني : أشد منعة ،   وأكثر عدداً ،   وأكثر أموالاً ،   { مّن قَرْيَتِكَ التي أَخْرَجَتْكَ } يعني : أهل مكة الذين أخرجوك من مكة إلى المدينة ،   { أهلكناهم } يعني : عذبناهم عند التكذيب { فَلاَ ناصر لَهُمْ } يعني : لم يكن لهم مانع مما نزل بهم من العذاب ،   وهذا تخويف لأهل مكة .  <br />
