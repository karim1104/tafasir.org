قوله تعالى : { يَسْتَعْجِلُ بِهَا الذين لاَ يُؤْمِنُونَ بِهَا } يعني : إنَّ المشركين كانوا يقولون : { متى هذا الوعد إِن كُنتُمْ صادقين } ويقولون : { رَبَّنَا عَجّل لَّنَا قِطَّنَا } { والذين آمَنُواْ مُشْفِقُونَ مِنْهَا } يعني : خائفين من قيام الساعة ،   لأنهم يعلمون أنهم مبعوثون ،   محاسبون { وَيَعْلَمُونَ أَنَّهَا الحق } يعني : يعلمون أن الساعة كائنة .   { أَلاَ إِنَّ الذين يُمَارُونَ في الساعة } يعني : يشكون ويخاصمون فيها .   { لَفي ضلال بَعِيدٍ } أي : في خطأ طويل ،   بعيد عن الحق .  <br />
