ثم خوّفهم ليعتبروا فقال عز وجل : { أَفَلَمْ يَسِيرُواْ في الأرض } يعني : أفلم يسافروا في الأرض { فَيَنظُرُواْ } يعني : فيعتبروا { كَيْفَ كَانَ عاقبة الذين مِن قَبْلِهِمْ } يعني : كيف كان آخر أمرهم .   { دَمَّرَ الله عَلَيْهِمْ } يعني : أهلكهم الله تعالى بالعذاب { وللكافرين أمثالها } يعني : للكافرين من هذه الأمة أمثالها من العذاب ،   وهذا وعيد لكفار قريش .  <br />
