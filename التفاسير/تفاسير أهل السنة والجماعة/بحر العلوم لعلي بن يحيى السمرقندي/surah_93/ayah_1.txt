قوله تبارك وتعالى : { والضحى } يعني : النهار كله ،   ويقال : الضحى ساعة من ساعات النهار ،   ويقال : الضحى حر الشمس .  { والليل إِذَا سجى } يعني : اسودّ وأظلم ،   ويقال : إذا سكن بالناس ،   ويقال : { والضحى والليل إِذَا سجى } يعني : عباده الذين يعبدونه في وقت الضحى وعباده الذين يعبدونه بالليل إذا أظلم ،   ويقال : { والضحى } نور الجنة إذا تنور { والليل إِذَا سجى } يعني : ظلمة النار إذا أظلم ،   ويقال : { والضحى } يعني : النور الذي في قلوب العارفين كهيئة النهار ،   { والليل إِذَا سجى } يعني : السواد الذي في قلوب الكافرين ،   كهيئة الليل .   وأقسم الله تعالى بهذه الأشياء { مَا وَدَّعَكَ رَبُّكَ وَمَا قلى } .  <br />
