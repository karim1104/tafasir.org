ثم قال عز وجل : { فاتقوا الله مَا استطعتم } يعني : على قدر ما أطقتم .   { واسمعوا } يعني : اسمعوا ما تؤمرون به من المواعظ .   { وَأَطِيعُواْ } يعني : وأطيعوا الله والرسول .   { وَأَنْفِقُواْ خَيْراً لأنفُسِكُمْ } يعني : تصدقوا خيراً ،   يعني : وأنفقوا من أموالكم في حق الله تعالى { لأنفُسِكُمْ } يعني : ثوابه لأنفسكم ،   ويكون زاداً لكم إلى الجنة .   ويقال معناه : تصدقوا خيراً لأنفسكم من إمساك الصدقة .   { وَمَن يُوقَ شُحَّ نَفْسِهِ } يعني : يدفع البخل عن نفسه ،   { فَأُوْلَئِكَ هُمُ المفلحون } يعني : الناجين السعداء .  <br />
