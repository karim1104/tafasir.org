{ إِن تُعَذّبْهُمْ فَإِنَّهُمْ عِبَادُكَ وَإِن تَغْفِرْ لَهُمْ فَإِنَّكَ أَنتَ العزيز الحكيم }<br />
 قرأ ابن مسعود : { فَإِنَّكَ أَنتَ الغفور الرحيم } وقرأ غيره : { العزيز الحكيم } فإن قيل : وكيف سأل المغفرة للكفار .  <br />
قيل له : لأن عيسى علم أن بعضهم قد تاب ورجع عن ذلك .   فقال : { إِن تُعَذّبْهُمْ } يعني : الذين ماتوا على الكفر ،   فإنهم عبادك وأنت القادر عليهم  ،   { وَإِن تَغْفِرْ لَهُمْ } يعني : الذين أسلموا ورجعوا عن ذلك .   وقال بعضهم : احتمل أنه لم يكن في كتابه { إِنَّ الله لاَ يَغْفِرُ أَن يُشْرَكَ بِهِ وَيَغْفِرُ مَا دُونَ ذلك لِمَن يَشَاءُ وَمَن يُشْرِكْ بالله فَقَدْ ضَلَّ ضلالا بَعِيداً } [ النساء : 116 ] فلهذا المعنى دعا لهم ،   ولكن التأويل الأول أحسن .   ويقال : { إن تَغْفِرْ لَهُمْ } يعني : لكذبهم الذي قالوا عليّ خاصة ،   لا لشركهم .   وهذا التأويل ليس بسديد ،   والأول أحسن .   وروي عن أبي ذر الغفاري عن النبي صلى الله عليه وسلم أنه قرأ هذه الآية ذات ليلة ،   فردّدها حتى أصبح : { إِن تُعَذّبْهُمْ فَإِنَّهُمْ عِبَادُكَ وَإِن تَغْفِرْ لَهُمْ } الآية وقال بعضهم : في الآية تقديم وتأخير ومعناه : { إِن تُعَذّبْهُمْ } { فإنك أنت العزيز الحكيم } { وَإِن تَغْفِرْ لَهُمْ } { فإنهم عبادك } .
