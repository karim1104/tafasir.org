قوله تعالى : { وَقَفَّيْنَا على آثارهم بِعَيسَى ابن مَرْيَمَ } يعني : اتبعنا على أثر الرسل عيسى ابن مريم عليه السلام ،   { مُصَدّقاً لّمَا بَيْنَ يَدَيْهِ } يعني : موافقاً لما قبله ،   { مِنَ التوراة } يقال : إن عيسى يصدق التوراة .  <br />
ثم قال : { وآتيناه الإنجيل فيه هدى } من الضلالة ،   { وَنُورٌ } يعني : بيان الأحكام ،   { وَمُصَدّقاً لّمَا بَيْنَ يَدَيْهِ مِنَ التوراة } ،   يعني : الإنجيل موافقاً للتوراة في التوحيد ،   وفي بعض الشرائع ،   { وَهُدًى وَمَوْعِظَةٌ لّلْمُتَّقِينَ } الذين يتقون الشرك ،   والفواحش .  <br />
