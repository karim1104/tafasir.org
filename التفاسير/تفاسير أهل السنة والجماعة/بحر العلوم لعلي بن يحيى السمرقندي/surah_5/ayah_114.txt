ثم : { قَالَ عِيسَى ابن مَرْيَمَ اللهم رَبَّنَا أَنزِلْ عَلَيْنَا مَائِدَةً مّنَ السماء تَكُونُ لَنَا عِيداً لأولنا وَآخِرِنَا }<br />
 وكان يوم الأحد ،   فصار ذلك اليوم عيداً لهم .   ويقال : { عِيداً لَنَا } يعني : حجة لنا { وَآخِرِنَا } يعني : حجة لمن بعدنا { وآية منك } يعني : نزولها علامة منك لنبوتك ،   { وارزقنا } يعني : وأعطنا المائدة { وَأَنتَ خَيْرُ الرازقين } من غيرك .  <br />
