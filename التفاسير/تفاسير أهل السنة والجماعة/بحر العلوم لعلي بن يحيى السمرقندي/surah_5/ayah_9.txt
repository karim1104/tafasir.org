ثم بيّن ثواب من عمل بطاعته فقال : { وَعَدَ الله الذين آمَنُواْ وَعَمِلُواْ الصالحات } يعني الطاعات { لَهُم مَّغْفِرَةٌ } لذنوبهم { وَأَجْرٌ عَظِيمٌ } يعني ثواب عظيم في الجنة .   ويقال : إن أهل مكة قالوا بعدما أسلموا : ما لنا في الآخرة وقد أخرجناك وأصحابك .   فقالوا : { وعد الله الذين آمنوا } بالله وبمحمد صلى الله عليه وسلم { وعملوا الصالحات } بعد الإسلام { لهم مغفرة } لما فعلوا في حال الشرك { وأجر عظيم } في الآخرة .  <br />
