{ قَالَ رَجُلاَنِ } يعني يوشع بن نون وكالب { مِنَ الذين يَخَافُونَ } الله تعالى { أَنْعَمَ الله عَلَيْهِمَا } بالإسلام ،   ويقال من الذين يخافون الجبارين { أَنْعَمَ الله عَلَيْهِمَا } فلم يخافا وصدقا في مقالتهما { ادخلوا عَلَيْهِمُ الباب } وهي أريحا أو إيلياء { فَإِذَا دَخَلْتُمُوهُ فَإِنَّكُمْ غالبون } يعني أن القوم إذا رأوا كثرتكم انكسرت قلوبهم وانقطعت ظهورهم ،   فتكونوا غالبين { وَعَلَى الله فَتَوَكَّلُواْ } يعني فثقوا بأنه ناصركم { إِن كُنتُم مُّؤْمِنِينَ } يعني : مصدقين بوعد الله تعالى .  <br />
