قوله عز وجل : { قُلْ } يا محمد { أَنزَلَهُ } يعني : القرآن { الذى يَعْلَمُ السر فِى * السموات والأرض } يعني : يعلم السِّرَّ والعلانية ،   ومعناه : لو كان هذا القول من ذات نفسه لعلمه الله تعالى ،   وإذا علمه عاقبه ،   كما قال تعالى : { وَلَوْ تَقَوَّلَ عَلَيْنَا بَعْضَ الاقاويل * لأَخَذْنَا مِنْهُ باليمين } [ الحاقة : 44 ،   45 ] ثم قال { إِنَّهُ كَانَ غَفُوراً رَّحِيماً } فكأنه يقول : ارجعوا وتوبوا ،   فإنه كان { غفوراً } لمن تاب ،   { رحيماً } بالمؤمنين .
