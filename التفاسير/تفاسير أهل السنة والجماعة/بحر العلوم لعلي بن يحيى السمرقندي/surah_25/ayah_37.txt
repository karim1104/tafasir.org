قوله عز وجل { وَقَوْمَ نُوحٍ } يعني : واذكر قوم نوح عليه السلام { لَّمَّا كَذَّبُواْ الرسل } يعني : نوحاً وحده كما قال : { ياأيها الرسل كُلُواْ مِنَ الطيبات واعملوا صالحا إِنِّى بِمَا تَعْمَلُونَ عَلِيمٌ } [ المؤمنون : 51 ] ولم يكن إلا واحد وقت هذا الخطاب ،   فيجوز أن يذكر الجماعة ،   ويراد به الواحد كما يذكر الواحد ،   ويراد به الجماعة كقوله : { والعصر إن الإنسان لفي خسر } [ العصر : 1 ] وإنما أراد به الناس ،   ألا ترى أنه استثنى منه جماعة .   ويقال : إن نوحاً كان يدعو قومه إلى الإيمان به ،   وبالأنبياء الذين بعده ،   فلما كذبوه فقد كذبوا جميع الرسل ،   فلهذا قال : { لَّمَّا كَذَّبُواْ الرسل } { أغرقناهم وحعلناهم للناس آية } يعني : عبرة لمن بعدهم { وَأَعْتَدْنَا للظالمين عَذَاباً أَلِيماً } أي : وجيعاً .
