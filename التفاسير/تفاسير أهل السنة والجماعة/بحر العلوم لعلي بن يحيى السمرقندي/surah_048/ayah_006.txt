ثم قال : { وَيُعَذّبَ المنافقين والمنافقات } يعني : ولكن يعذب المنافقين ،   والمنافقات ،   من أهل المدينة { والمشركين } من أهل مكة { والمشركات } الذين أقاموا على عبادة الأصنام .  <br />
قوله : { الظانين بالله ظَنَّ السوء } وظنهم ترك التصديق بالله تعالى ورسوله ،   مخافة ألا ينصر محمد صلى الله عليه وسلم كما قال تعالى : { بَلْ ظَنَنْتُمْ أَن لَّن يَنقَلِبَ الرسول والمؤمنون إلى أَهْلِيهِمْ أَبَداً وَزُيِّنَ ذَلِكَ في قُلُوبِكُمْ وَظَنَنتُمْ ظَنَّ السوء وَكُنتُمْ قَوْماً بُوراً } [ الفتح : 12 ] .  <br />
ثم قال : { عَلَيْهِمْ دَائِرَةُ السوء } يعني : عاقبة العذاب والهزيمة { وَغَضِبَ الله عَلَيْهِمْ وَلَعَنَهُمْ } في الدنيا { وَأَعَدَّ لَهُمْ جَهَنَّمَ } في الآخرة { وَسَاءتْ مَصِيراً } يعني : بئس المصير الذي صاروا إليه .  <br />
