{ قُل لَّوْ كَانَ البحر مِدَاداً لكلمات رَبّى }  ؛ وذلك أن اليهود قالوا : يزعم محمد أن من أوتي الحكمة فقد أوتي خيراً كثيراً ،   ثم يزعم ويقول : { وَيَسْألُونَكَ عَنِ الروح قُلِ الروح مِنْ أَمْرِ رَبِّى وَمَآ أُوتِيتُم مِّن العلم إِلاَّ قَلِيلاً } [ الإسراء : 85 ] فكيف نوافق الخير الكثير مع العلم القليل ؟ فنزل : قل يا محمد : { لَّوْ كَانَ البحر مِدَاداً لكلمات رَبّى } يكتب به ،   { لَنَفِدَ البحر } وتكسرت الأقلام ،   { قَبْلَ أَن تَنفَدَ كلمات رَبّى }  ؛ أي لا تنفد كلمات ربي .   كما قال في آية أخرى : { وَلَوْ أَنَّمَا فِى الأرض مِن شَجَرَةٍ أَقْلاَمٌ والبحر يَمُدُّهُ مِن بَعْدِهِ سَبْعَةُ أَبْحُرٍ مَّا نَفِدَتْ كلمات الله إِنَّ الله عَزِيزٌ حَكِيمٌ } [ لقمان : 27 ] .   { وَلَوْ جِئْنَا بِمِثْلِهِ مَدَداً } ،   أي بمثل البحر ،   وقرأ بعضهم { وَلَوْ جِئْنَا بِمِثْلِهِ مِدَاداً } .   وقراءة العامة { مَدَداً } ومعناهما واحد { ومن يُؤْتِى الْحِكْمَةَ مَن يَشَآءُ وَمَن يُؤْتَ الْحِكْمَةَ فَقَدْ أُوتِىَ خَيْرًا كَثِيرًا وَمَا يَذَّكَّرُ إِلاَّ أُوْلُواْ الألباب } [ البقرة : 269 ] وهو قليل عند علم الله تعالى .
