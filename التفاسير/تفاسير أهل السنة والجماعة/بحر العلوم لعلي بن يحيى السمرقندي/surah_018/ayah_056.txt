{ وَمَا نُرْسِلُ المرسلين إِلاَّ مُبَشّرِينَ } ،   أي للمؤمنين بالجنة ،   { وَمُنذِرِينَ }  ؛ أي للكافرين بالنار { ويجادل الذين كَفَرُواْ بالباطل } أي يخاصموا بالباطل { لِيُدْحِضُواْ بِهِ } أي ليزيلوا ويذهبوا به { الحق } ومنه يقال : حُجَّةٌ دَاحِضَةٌ إذا زالت عن الحجة وقال مقاتل : { لِيُدْحِضُواْ بِهِ } أي ليبطلوا به الحقَّ ،   يعني : القرآن والإسلام ،   يعني : يريدون أن يفعلوا إن قدروا عليه .   { واتخذوا ءاياتى } ،   يعني : القرآن { وَمَا أُنْذِرُواْ } ،   أي وما خوفوا به { هُزُواً } أي سخرية .  <br />
