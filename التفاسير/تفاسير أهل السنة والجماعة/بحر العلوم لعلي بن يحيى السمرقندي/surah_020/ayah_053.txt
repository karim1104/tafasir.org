ثم إن الله تبارك وتعالى قال لمشركي مكة : { الذى جَعَلَ لَكُمُ الأرض مَهْداً } ،   يعني : موضع القرار ،   وهو الرب الذي ذكر موسى لفرعون ودعاه إلى عبادته .   قرأ حمزة والكسائي وعاصم { مهدا } والباقون { مهادا } أي : فراشاً وبساطاً .   قال أبو عبيد : المهد الفعل ،   يقال : مهدت مهداً ؛ والمهاد اسم الموضع .   { وَسَلَكَ لَكُمْ فِيهَا سُبُلاً } ،   يعني : حصل لكم فيها طرقاً ،   { وَأَنزَلَ مِنَ السماء مَاء }  ؛ يعني : المطر ،   { فَأَخْرَجْنَا بِهِ أَزْوَاجاً }  ؛ يعني : أنبتنا بالمطر أصنافاً وألواناً .   { مّن نبات شتى } مختلف ألوانه .  <br />
