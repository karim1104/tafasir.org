قوله تعالى : { قَالُواْ أَجِئْتَنَا } يعني : قال فرعون وقومه لموسى عليه السلام { أَجِئْتَنَا لِتَلْفِتَنَا } ؟ يعني : لتصرفنا ،   وتصدنا { عَمَّا وَجَدْنَا عَلَيْهِ ءابَاءنَا } يقول : عما كان يعبد آباؤنا { وَتَكُونَ لَكُمَا الكبرياء } يعني : السُّلطان والشَّرف والمُلْكُ { فِى الأرض } ،   يعني : في أرض مصر { وَمَا نَحْنُ لَكُمَا بِمُؤْمِنِينَ } يعني : بمصدِّقين بأنّكما رسولا ربِّ العالمين .  <br />
