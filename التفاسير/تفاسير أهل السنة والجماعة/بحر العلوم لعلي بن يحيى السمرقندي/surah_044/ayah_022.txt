قوله تعالى : { فَدَعَا رَبَّهُ } يعني : دعا موسى ربه ،   كما ذكر في سورة يونس { وَقَالَ موسى رَبَّنَآ إِنَّكَ آتَيْتَ فِرْعَوْنَ وَمَلاّهُ زِينَةً وَأَمْوَالاً في الحياة الدنيا رَبَّنَا لِيُضِلُّواْ عَن سَبِيلِكَ رَبَّنَا اطمس على أموالهم واشدد على قُلُوبِهِمْ فَلاَ يُؤْمِنُواْ حتى يَرَوُاْ العذاب الأليم } [ يونس : 88 ] وقوله : { وَنَجِّنَا بِرَحْمَتِكَ مِنَ القوم الكافرين } [ يونس : 86 ] { أَنَّ هَؤُلاَء قَوْمٌ مُّجْرِمُونَ } يعني : مشركون فأبوا أن يطيعوني .
