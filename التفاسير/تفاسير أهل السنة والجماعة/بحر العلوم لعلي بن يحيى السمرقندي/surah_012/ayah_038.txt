ثم قال تعالى : { واتبعت مِلَّةَ ءابَاءي إبراهيم وإسحاق وَيَعْقُوبَ } يعني : دينهم { مَا كَانَ لَنَا } أي : ما جاز لنا { أَن نُّشْرِكَ بالله مِن شَىْء } من الآلهة { ذلك مِن فَضْلِ الله } يعني : ويقال ذلك الإرسال ،   الذي أرسل إليه بالنبوة من فضل الله { عَلَيْنَا  وَعَلَى الناس } يعني : المؤمنين { ولكن أَكْثَرَ الناس } يعني : أهل مصر { لاَ يَشْكُرُونَ } النعمة .  <br />
