{ وَقَالَ الملك إِنّى أرى } يعني : رأيت في المنام { سَبْعَ بقرات سِمَانٍ } خرجن من نهر مصر { يَأْكُلُهُنَّ سَبْعٌ بقرات عِجَافٌ } هزلى ،   فابتلع العجاف السمان ،   فدخلن في بطونهن ،   فلم يرَ منهنّ شيء ،   ورأيت { وَسَبْعَ سنبلات خُضْرٍ وَأُخَرَ يابسات يأَيُّهَا الملا } يعني : العرافين ،   والسحرة ،   والكهنة ،   { أَفْتُونِى فِى رؤياى } يعني : عبروا رؤياي ،   وبيّنوا تفسيرها { إِن كُنتُمْ لِلرُّؤْيَا تَعْبُرُونَ } أي : تفسرون<br />
