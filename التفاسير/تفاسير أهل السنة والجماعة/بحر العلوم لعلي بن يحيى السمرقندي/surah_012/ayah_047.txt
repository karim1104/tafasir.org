{ قَالَ تَزْرَعُونَ سَبْعُ سِنِينَ دَأَبًا } يعني : ازرعوا لسبع سنين { دَأَبًا } يعني : دائماً { فَمَا حَصَدتُّمْ } من الزرع { فَذَرُوهُ فِى سُنبُلِهِ } يعني : في كعبره .   فهو أبقى لكم ،   لكي لا يأكله السوس إذا كانت في الكعبرة ،   { إِلاَّ قَلِيلاً مّمَّا تَأْكُلُونَ } يعني : تدرسون بقدر ما تحتاجون إليه ،   فتأكلون .  <br />
