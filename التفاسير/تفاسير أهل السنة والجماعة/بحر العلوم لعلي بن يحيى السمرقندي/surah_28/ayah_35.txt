{ قَالَ } الله تعالى : { سَنَشُدُّ عَضُدَكَ بِأَخِيكَ } أي : نقويك بأخيك { وَنَجْعَلُ لَكُمَا سلطانا } يعني : حجة ثانية ،   وهي اليد والعصا { فَلاَ يَصِلُونَ إِلَيْكُمَا بآياتنا } يعني : لا يقدرون على قتلكما { أَنتُمَا وَمَنِ اتبعكما الغالبون } يعني : من آمن بكما الغالبون في الحجة .  <br />
