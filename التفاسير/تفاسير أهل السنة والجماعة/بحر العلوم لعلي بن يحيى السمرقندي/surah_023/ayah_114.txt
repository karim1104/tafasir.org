{ قَالَ إِن لَّبِثْتُمْ } في القبر أو في الدنيا ،   { إِلاَّ قَلِيلاً لَّوْ أَنَّكُمْ كُنتُمْ تَعْلَمُونَ } ،   يعني : لو كنتم تصدقون أنبيائي عليهم السلام في الدنيا ،   لعرفتم أنكم ما مكثتم في القبور إلا قليلاً .   قرأ حمزة والكسائي وابن كثير : { قال كَمْ لَبِثْتُمْ } على معنى الأمر ،   وكذلك قوله { قُلْ إِنْ * لَّبِثْتُمْ } ،   وقرأ الباقون : { قَالَ } بالألف ،   وقرأ حمزة والكسائي : { فَسلِ العادين } بغير همز ،   وقرأ الباقون : { فَاسْأَلِ } بالهمزة .  <br />
