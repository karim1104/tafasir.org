ثم قال عز وجل : { يُرِيدُونَ لِيُطْفِئُواْ نُورَ الله بأفواههم } يعني : ليبطلوا دين الله بقولهم : { والله مُتِمُّ نُورِهِ } يعني : مظهر توحيده وكتابه ،   { وَلَوْ كَرِهَ الكافرون } يعني : وإن كره اليهود والنصارى .   قرأ حمزة ،   والكسائي ،   وابن عامر ،   وعاصم في رواية حفص : { والله مُتِمُّ نُورِهِ } على معنى الإضافة ،   والباقون { مُّتُّمْ } بالتنوين { نُورِهِ } بالنصب .   فمتم فاعل ونصب نوره ،   لأنه مفعول به .  <br />
