ثم قال عز وجل : { مّمَّا خطيئاتهم أُغْرِقُواْ } يعني : بشركهم بالله تعالى أُغرقوا في الدنيا .   { فَأُدْخِلُواْ نَاراً } في الآخرة .   قال مقاتل : { بِمَا خطيئاتهم أُغْرِقُواْ } بخطياتهم ؛ وقال القتبي : ( بما خطياتهم أغرقوا ) يعني : من خطيئاتهم أغرقوا ،   والميم زيادة .   ثم قال : { فَلَمْ يَجِدُواْ لَهُمْ مّن دُونِ الله أَنصَاراً } يعني : أعواناً يمنعونهم من العذاب .  <br />
قرأ أبو عمرو { خطاياهم } ،   والباقون { خطيئاتهم } ومعناهما واحد ،   وهو جمع خطيئة .  <br />
