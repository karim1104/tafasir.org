{ يَغْفِرْ لَكُمْ مّن ذُنُوبِكُمْ } يعني : ذنوبكم .   و«من » صلة .   { وَيُؤَخّرْكُمْ } يعني : يؤجلكم { إلى أَجَلٍ مُّسَمًّى } يعني : إلى منتهى آجالكم .   { إِنَّ أَجَلَ الله } يعني : إن عذاب الله ،   { إِذَا جَاء لاَ يُؤَخَّرُ } يعني : لا يستطيع أن يؤخره أحد .   { لَوْ كُنتُمْ تَعْلَمُونَ } يعني : لو كان لكم علم تنتفعون به .  <br />
