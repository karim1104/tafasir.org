قوله تعالى : { وَلَئِنْ أَخَّرْنَا عَنْهُمُ العذاب إلى أُمَّةٍ مَّعْدُودَةٍ } يعني : سنيناً معلومة ،   يعني : إلى الوقت الذي جعل أجلهم .   وقال القتبي : يعني : إلى حين بغير توقيت ،   وقوله : { وَقَالَ الذى نَجَا مِنْهُمَا وادكر بَعْدَ أُمَّةٍ أَنَاْ أُنَبِّئُكُمْ بِتَأْوِيلِهِ فَأَرْسِلُونِ } [ يوسف : 45 ] إنما هو سبع سنين { لَّيَقُولُنَّ مَا يَحْبِسُهُ } يعني : العذاب ،   على وجه الاستهزاء ،   { أَلاَ يَوْمَ يَأْتِيهِمْ } يعني : العذاب { لَيْسَ مَصْرُوفاً عَنْهُمْ } يعني : ليس أحد يصرف العذاب عنهم ،   إذا نزل بهم في الدنيا وفي الآخرة .   { وَحَاقَ بِهِم } يعني : نزل بهم { مَّا كَانُواْ بِهِ يَسْتَهْزِءونَ } .
