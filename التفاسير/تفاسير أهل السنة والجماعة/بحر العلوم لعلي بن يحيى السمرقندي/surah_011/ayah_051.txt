قوله تعالى : { يا قوم لا أَسْئَلُكُمْ عَلَيْهِ } أي : على الإيمان { أَجْراً } يعني : جعلاً ،   ورشوة .   ومعناه لست بطامع في أموالكم ،   { إِنْ أَجْرِىَ } يعني : ما ثوابي { إِلاَّ عَلَى الذى فَطَرَنِى } يعني : خلقني { أَفَلاَ تَعْقِلُونَ } أن الذي خلقكم هو ربكم ،   وهو أحق بعبادتكم من غيره ؟<br />
