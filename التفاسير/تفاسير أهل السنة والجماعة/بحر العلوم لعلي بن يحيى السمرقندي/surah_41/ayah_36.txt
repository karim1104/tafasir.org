ثم قال : { وَإِمَّا يَنَزَغَنَّكَ } يعني : يصيبك { مِنَ الشيطان نَزْغٌ } يعني : وسوسة على الاحتمال ،   { فاستعذ بالله } من شره ،   وامض على احتمالك .   وقال مقاتل : { وَإِمَّا يَنَزَغَنَّكَ } يعني : يفتتنك مِنَ الشَّيْطَانِ .   { نَّزغَ } أي : فتنة .   وقال الكلبي : الذنب عند دفع السيئة .   ويقال : { يَنَزَغَنَّكَ } يعني : يغوينك { فاستعذ بالله } يعني : تعوذ بالله ،   { إِنَّهُ هُوَ السميع } للاستعاذة ،   { العليم } بقول الكفار وعقوبتهم .  <br />
