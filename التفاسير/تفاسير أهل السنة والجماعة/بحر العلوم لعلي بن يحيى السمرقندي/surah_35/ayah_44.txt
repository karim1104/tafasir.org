ثم وعظهم ليعتبروا فقال عز وجل : { أَوَلَمْ يَسيرُواْ في الأرض } يعني : أو لم يسافروا في الأرض { فَيَنظُرُواْ } يعني : فيعتبروا { كَيْفَ كَانَ عاقبة الذين } يعني : آخر أمر { الذين } كانوا { مِن قَبْلِهِمْ وَكَانُواْ أَشَدَّ مِنْهُمْ قُوَّةً } يعني : منعة { وَمَا كَانَ الله لِيُعْجِزَهُ مِن شيء } يعني : ليسبقه ،   ويفوته من شيء .  <br />
ويقال : لا يقدر أحد أن يهرب من عذابه { فِي السماوات وَلاَ في الأرض إِنَّهُ كَانَ عَلِيماً } بخلقه بأنه لا يفوت منهم أحد { قَدِيراً } يعني : قادراً عليهم بالعقوبة .  <br />
