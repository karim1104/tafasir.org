{ لِتَعْجَلَ بِهِ إِنَّ عَلَيْنَا جَمْعَهُ } يعني : حفظه في قلبك { وَقُرْآنَهُ } يعني : يقرأ عليك جبريل ،   حتى تحفظه { فَإِذَا قرأناه فاتبع قُرْآنَهُ } يعني : إذا قرأ عليك جبريل فاقرأ أنت بعد قراءته وفراغه وقال محمد بن كعب : فاتبع قراءته ،   يعني : فاتبع حلاله وحرامه .   وقال الأخفش : { إِنَّ عَلَيْنَا جَمْعَهُ وقراءته } يعني : تأليفه .  <br />
