قوله عز وجل : { ولسليمان الريح }  ؛ قرأ عبد الرحمن { الريح } بضم الحاء على معنى الابتداء ،   وقراءة العامة { الريح } بالنصب ،   ومعناه وسخرنا لسليمان الريح { عَاصِفَةً } ،   يعني : قاصفة شديدة ،   وقال في موضع آخر { فَسَخَّرْنَا لَهُ الريح تَجْرِى بِأَمْرِهِ رُخَآءً حَيْثُ أَصَابَ } [ ص : 36 ] يعني : لينة ،   فإنها كانت تشتد إذا أراد وتلين إذا أراد { تَجْرِى بِأَمْرِهِ } ،   يعني : تسير بأمر الله عز وجل ،   ويقال : بأمر سليمان .   { إِلَى الأرض التى بَارَكْنَا فِيهَا } بالماء والشجر { وَكُنَّا بِكُلّ شَىْء عالمين } ،   يعني : من أمر سليمان وغيره .
