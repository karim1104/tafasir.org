ثم قال عز وجل : { وَمَا كَانَ الله مُعَذّبَهُمْ وَهُمْ يَسْتَغْفِرُونَ } ،   يعني يصلّون لله الخمس وهم أهل الإيمان ؛ وقال مجاهد : { وهم يستغفرون } يعني وهم مسلمون ؛ ويقال : وفيهم من يؤول مرة إلى الإسلام ؛ ويقال : { وهم يستغفرون } يعني وفي أصلابهم من يسلم .   وروي عن أبي موسى الأشعري أنه قال : كان أمانان في الأرض ،   رفع الله أحدهما وبقي الآخر { وَمَا كَانَ الله لِيُعَذّبَهُمْ وَأَنتَ فِيهِمْ } { وَمَا كَانَ الله مُعَذّبَهُمْ وَهُمْ يَسْتَغْفِرُونَ } وقال عطية : { وَمَا كَانَ الله لِيُعَذّبَهُمْ وَأَنتَ فِيهِمْ } ،   يعني المشركين حتى يخرجك منهم .   { وَمَا كَانَ الله مُعَذّبَهُمْ وَهُمْ يَسْتَغْفِرُونَ } ،   يعني المؤمنين .  <br />
