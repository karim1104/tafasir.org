ثم قال عز وجل :<br />
{ كَدَأْبِ ءالِ فِرْعَوْنَ * وَمَا نَحْنُ بِمُنشَرِينَ * فَأْتُواْ بِئَابَائِنَا إِن كُنتُمْ صادقين * أَهُمْ خَيْرٌ أَمْ قَوْمُ تُبَّعٍ والذين مِن قَبْلِهِمْ } من الأمم الخالية .   { كَفَرُواْ بئايات الله } ،   يعني جحدوا بعذاب الله في الدنيا أنه غير نازل بهم ،   { فَأَخَذَهُمُ الله }  ؛ يعني عاقبهم وأهلكهم { بِذُنُوبِهِمْ } وشركهم .   ثم قال : { إِنَّ الله قَوِىٌّ شَدِيدُ العقاب } ،   يعني { قوي } في أخذه ،   { شديد العقاب } لمن عصاه .  <br />
