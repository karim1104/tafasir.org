قوله عز وجل : { لَّقَدْ أَنزَلْنَا ءايات مبينات } قرأ أبو عمرو وعاصم ونافع وابن كثير وأبو بكر : { مبينات } بنصب الياء في جميع القرآن ،   يعني : مفصلات .   وقرأ حمزة والكسائي وابن عامر { مبينات } بكسر الياء ،   يعني : يبين للناس دينهم .  <br />
{ والله يَهْدِى مَن يَشَاء } أي يرشد من كان أهلاً لذلك { إلى صراط مُّسْتَقِيمٍ } يعني : دين مستقيم وهو دين الإسلام .  <br />
