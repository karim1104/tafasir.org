{ ثُمَّ أَغْرَقْنَا بَعْدُ الباقين } يعني : من بقي ممن لم يركب السفينة ،   ولفظ البعد والقبل إذا كان بغير إضافة يكون بالرفع مثل قوله : { فِى بِضْعِ سِنِينَ لِلَّهِ الامر مِن قَبْلُ وَمِن بَعْدُ وَيَوْمَئِذٍ يَفْرَحُ المؤمنون } [ الروم : 4 ] وكقوله : { ثُمَّ أَغْرَقْنَا بَعْدُ الباقين } وإذا كانت بالإضافة يكون نصباً في موضع النصب كقوله : { وَكَمْ قَصَمْنَا مِن قَرْيَةٍ كَانَتْ ظالمة وَأَنشَأْنَا بَعْدَهَا قَوْماً ءَاخَرِينَ } [ الأنبياء : 11 ]
