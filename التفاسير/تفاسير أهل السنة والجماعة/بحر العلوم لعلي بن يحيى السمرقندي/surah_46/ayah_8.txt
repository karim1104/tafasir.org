قوله عز وجل : { أَمْ يَقُولُونَ افتراه } يعني : اختلقه من ذات نفسه { قُلْ إِنِ افتريته } يعني : اختلقته من تلقاء نفسي ،   يعذبني الله تعالى عليه .   { فَلاَ تَمْلِكُونَ لِي مِنَ الله شَيْئاً } يعني : لا تقدرون أن تمنعوا عذاب الله عني { هُوَ أَعْلَمُ بِمَا تُفِيضُونَ فِيهِ } يعني : تخوضون فيه من الكذب في القرآن { كفى بِهِ شَهِيداً } يعني : كفى بالله عالماً { بَيْنِي وَبَيْنَكُمْ } ويقال تفيضون أي تقولون ثم قال { وَهُوَ الغفور الرحيم } يعني : الغفور لمن تاب ،   الرحيم بهم .  <br />
