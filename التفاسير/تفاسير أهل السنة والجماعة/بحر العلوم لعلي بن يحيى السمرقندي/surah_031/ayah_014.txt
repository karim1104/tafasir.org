قوله عز وجل : { وَوَصَّيْنَا الإنسان } فكأنه يقول : آمركم بما أمر به لقمان لابنه بأن لا تشركوا بالله شيئاً ،   وآمركم بأن تحسنوا إلى الوالدين فذلك قوله عز وجل : { وَوَصَّيْنَا الإنسان } يعني : أمرناه بالإحسان { بوالديه } يعني أن يبر والديه .  <br />
ثم ذكر حق الأم وما لقيت من أمر الولد من الشدة فقال : { حَمَلَتْهُ أُمُّهُ وَهْناً على وَهْنٍ } يعني : ضعفاً على ضعف ،   لأن الحمل في الابتداء أيسر عليها .   فكلما ازداد الحمل يزيدها ضعفاً على ضعف { وَفِصَالُهُ فِي عَامَيْنِ } يعني : فطامه بعد سنتين من وقت الولادة { أَنِ اشكر لِي ولوالديك } يعني : وصّيناه وأمرناه بأن اشكر لي بما هديتك للإسلام ،   واشكر لوالديك بما فعلا إليك ثم قال : { إِلَيّ المصير } فأجازيك بعملك .  <br />
