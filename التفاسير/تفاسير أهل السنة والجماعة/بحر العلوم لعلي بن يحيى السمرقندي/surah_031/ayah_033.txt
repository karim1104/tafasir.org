قوله عز وجل : { يَا أَيُّهَا الناس اتقوا رَبَّكُمُ } يعني : وحّدوه وأطيعوه { واخشوا } يعني : واخشوا عذاب يوم { يَوْماً لاَّ يَجْزِي وَالِدٌ عَن وَلَدِهِ } يعني : ولا ينفع والد عن ولده .   ويقال : لا يقضي والد عن ولده ما عليه { وَلاَ مَوْلُودٌ } يعني : ولا الولد { هو جاز عن والده شيئا } لا يقدر الولد أن ينفع والده شيئاً ،   وهذا في الكفار خاصة .   وأما المؤمن فإنه ينفع كما قال في آية أُخرى : { أَلْحَقْنَا بِهِمْ ذُرِّيَّتَهُمْ } [ الطور : 21 ] .  <br />
ثم قال : { إِنَّ وَعْدَ الله حَقٌّ } يعني : البعث بعد الموت كائن ،   ولا خلف فيه { فَلاَ تَغُرَّنَّكُمُ الحياة الدنيا } يعني : لا يغرّنكم ما في الدنيا من زينتها وزهرتها ،   فتركنوا إليها ،   وتطمئنوا بها ،   وتتركوا الآخرة والعمل لها { وَلاَ يَغُرَّنَّكُم بالله الغرور } يعني : لا يغرنكم الشيطان عن طاعة الله عز وجل .   ويقال : كل مضل هو الشيطان .   وقال أهل اللغة : { الغرور } بنصب الغين هو الشيطان .   وبالضم أباطيل الدنيا .
