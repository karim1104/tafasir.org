قوله عز وجل : { وَإِذَا قِيلَ لَهُمْ } يعني : لكفار مكة { اتبعوا مَا أَنزَلَ الله } على نبيه من القرآن ،   فآمنوا به ،   وأحلّوا حلاله ،   وحرموا حرامه { قَالُواْ بَلْ نَتَّبِعُ مَا وَجَدْنَا عَلَيْهِ آبَاءنَا } يقول الله عز وجل ؛ { أَوْ لَّوْ كَانَ الشيطان } يعني : أو ليس الشيطان { يَدْعُوهُمْ إلى عَذَابِ السعير } يعني : يدعوهم إلى تقليد آبائهم بغير حجة ،   فيصيروا إلى عذاب السعير .  <br />
