قوله تعالى : { وَإِمَّا يَنَزَغَنَّكَ مِنَ الشيطان } قال مقاتل يعني : ولا يفتننكم فتنة في أمر أبي جهل { نَزْغٌ فاستعذ بالله } قال الكلبي : أي : وإما يصيبنك من الشيطان وسوسة فاستعذ بالله وقال الزجاج : النزع أدنى حركة .   ومعناه : إن أتاك من الشيطان أدنى وسوسة فاستعذ بالله { إِنَّهُ سَمِيعٌ عَلِيمٌ } يعني : { سميع } لدعائك { عليم } بوسوسة الشيطان .  <br />
