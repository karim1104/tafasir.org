قوله تعالى : { وَلَمَّا وَقَعَ عَلَيْهِمُ الرجز } يعني : وجب عليهم العذاب وحل بهم { قَالُواْ يا موسى ادع لَنَا رَبَّكَ } يعني : سل لنا ربك { بِمَا عَهِدَ عِندَكَ } أي : بما أمرك ربك أن تدعو الله ويقال : بالعهد الذي سأل ربك { لَئِن كَشَفْتَ عَنَّا الرجز } أي : رفعت عنا العذاب { لَنُؤْمِنَنَّ لَكَ } يعني : لنصدقنك { وَلَنُرْسِلَنَّ مَعَكَ بَنِي إسرائيل } .  <br />
