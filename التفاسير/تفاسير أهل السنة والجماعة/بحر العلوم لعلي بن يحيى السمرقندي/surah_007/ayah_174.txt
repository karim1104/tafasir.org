قوله عز وجل : { وَكَذَلِكَ نفَصّلُ الآيات } يعني : هكذا نبيّن الآيات في أمر الميثاق { وَلَعَلَّهُمْ يَرْجِعُونَ } إلى إقرارهم وإلى التوبة فالواو الأولى للعطف وهو قوله { وكذلك } والواو الثانية زيادة للوصل وهي قوله : { وَلَعَلَّهُمْ يَرْجِعُونَ } ومعناه : وكذلك نفصل الآيات لعلهم يرجعون أي لكي يرجعوا .  <br />
