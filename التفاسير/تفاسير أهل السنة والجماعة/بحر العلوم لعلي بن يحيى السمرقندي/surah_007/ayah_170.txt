قوله تعالى : { والذين يُمَسّكُونَ بالكتاب } يعني : يعملون بالتوراة ولا يغيرونها عن مواضعها { وأقاموا الصلاةَ } يعني : أتموا الصلاة المفروضة { إِنَّا لاَ نُضِيعُ أَجْرَ المصلحين } يعني : عمل الموحدين وهم الذين يمسكون بالكتاب ،   وأقاموا الصلاة .   قرأ عاصم في رواية أبي بكر { يُمَسّكُونَ } بالتخفيف .   وقرأ الباقون { يُمَسّكُونَ } بالتشديد على معنى المبالغة .  <br />
