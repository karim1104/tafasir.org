قوله عز وجل : { لَقَدْ أَرْسَلْنَا نُوحاً إلَى قَوْمِهِ } يعني : بعثنا نوحاً إلى قومه بالرسالة فأتاهم ،   ويقال : معناه جعلنا نوحاً رسولاً إلى قومه .   { فَقَالَ يَا قَوْمِ اعْبُدُوا اللَّهَ } أي وحّدوا الله ،   { مَا لَكُمْ مِنْ إِلَهٍ غَيْرُهُ } أي ليس لكم رب سواه .  <br />
قرأ الكسائي { إله غَيْرِه } بكسر الراء .  <br />
وقرأ الباقون { غَيرُهُ } بالضم .   فمن قرأ بكسر الراء فلأجل { مِنْ } وجعله كله كلمة واحدة والغير تابعاً له .   ومن قرأ بالضم فمعناه ما لكم إله غيره ودخلت { من } مؤكدة .  <br />
ثم قال : { إنِّي أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ عَظِيمٍ } وهو الغرق ف .  <br />
