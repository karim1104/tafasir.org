{ قَالُواْ أَرْجِهْ وَأَخَاهُ } يعني : احبسهما ولا تقتلهما .   وأصله في اللغة التأخير أي أخر أمرهما حتى تجتمع السحرة فيغلبوهما .   فإنك إن قتلتهما قبل أن يظهر حالهما يظن الناس أنهما صادقان .   فإذا تبين كذبهما عند الناس فاقتلهما حينئذٍ .   فذلك قوله : { أَرْجِهْ وَأَخَاهُ وَأَرْسِلْ } أي : ابعث { فِي المدائن حاشرين } يعني : الشرط يحشرون الناس إليكم أي : { يَأْتُوكَ بِكُلّ ساحر عَلِيمٍ } .  <br />
