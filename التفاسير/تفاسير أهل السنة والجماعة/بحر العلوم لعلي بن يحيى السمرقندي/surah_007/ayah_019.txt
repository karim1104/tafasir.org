قوله تعالى :<br />
{ وَيَا آدَمُ اسكن أَنتَ وَزَوْجُكَ الجنة } يعني : وقلنا يا آدم اسكن أنت وزوجك الجنة { فَكُلاَ مِنْ حَيْثُ شِئْتُمَا } أي : من حيث أحببتما موسعاً عليكما { وَلاَ تَقْرَبَا هذه الشجرة } يعني : لا تأكلا من هذه الشجرة { فَتَكُونَا مِنَ الظالمين } فتصيرا من الضارين بأنفسكما .  <br />
