قوله تعالى : { وَلَمَّا سُقِطَ فَي أَيْدِيهِمْ } يعني : ندموا على ما صنعوا .   يقال : سقط في يده إذا ندم .   وأصله أن الإنسان إذا ندم جعل يده على رأسه .  <br />
{ وَرَأَوْاْ أَنَّهُمْ قَدْ ضَلُّواْ } أي علموا أنهم قد ضلوا عن الهدى { قَالُواْ لَئِن لَّمْ يَرْحَمْنَا رَبُّنَا } قرأ حمزة والكسائي { لَئِن لَّمْ ترحمنا } بالتاء على معنى المخاطبة { رَبَّنَا } بالنصب يعني : يا ربنا .   وقرأ الباقون { قَالُواْ لَئِن لَّمْ يَرْحَمْنَا رَبُّنَا } بالياء وضم الباء على معنى الخبر .   { وَيَغْفِرْ لَنَا } بعد التوبة عطف على قوله { لَئِن لَّمْ يَرْحَمْنَا رَبُّنَا } { لَنَكُونَنَّ مِنَ الخاسرين } يعني : من المغبونين .  <br />
