ثم قال تعالى : { وَإِن تَدْعُوهُمْ إِلَى الهدى لاَ يَسْمَعُواْ } قال الكلبي : يعني إن دعا المشركون آلهتهم لا يسمعون أي يجيبونهم { وَتَرَاهُمْ يَنظُرُونَ إِلَيْكَ وَهُمْ لاَ يُبْصِرُونَ } يعني : الأصنام تراهم مفتحة أعينهم وهم لا يبصرون شيئاً .   قال مقاتل : { وَإِن تَدْعُوهُمْ إِلَى الهدى } يعني : كفار مكة { لاَ يَسْمَعُواْ وَتَرَاهُمْ يَنظُرُونَ إِلَيْكَ وَهُمْ لاَ يُبْصِرُونَ } الهدى .  <br />
