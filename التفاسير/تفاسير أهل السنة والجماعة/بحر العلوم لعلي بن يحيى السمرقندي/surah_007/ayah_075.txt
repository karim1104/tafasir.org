قوله عز وجل : { قَالَ الْمَلأُ الَّذِينَ اسْتَكْبَرُوا مِنْ قَوْمِهِ لِلَّذِينَ اسْتُضْعفُوا } قرأ ابن عامر { وقَالَ الْمَلأُ } بالواو .   وقرأ الباقون بغير واو أي قال الملأ الذين تكبروا عن الإيمان من قومه وهم القادة { للذين استضعفوا } { لِمَنْ آمَنَ مِنْهُمْ } بصالح { أَتَعْلَمُونَ أَنَّ صَالِحاً مُرْسَلٌ مِنْ رَبِّهِ } يعني : أتصدقون صالحاً بأنه مرسل من ربه إليكم { قَالُوا } يعني : المؤمنين { إنَّا بِمَا أُرْسِلَ بِهِ مُؤْمِنُونَ } أي : مصدقون به .  <br />
