{ تلك آيات الله } يعني القرآن { نَتْلُوهَا عَلَيْكَ } يعني ننزل جبريل فيقرأ عليك { بالحق } أي بالصدق .   وقال الزجاج : { تلك آيات الله } أي تلك التي جرى ذكرها ،   حجج الله وعلاماته { نَتْلُوهَا عَلَيْكَ } ،   أي نعرّفك إياها { وَمَا الله يُرِيدُ ظُلْماً للعالمين } يعني لا يعذبهم بغير ذنب .  <br />
