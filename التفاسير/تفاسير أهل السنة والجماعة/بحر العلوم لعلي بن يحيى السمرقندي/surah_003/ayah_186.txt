قوله تعالى : { لَتُبْلَوُنَّ في أموالكم وَأَنفُسِكُمْ } يقول : لتختبرن في أموالكم بالنقصان والذهاب ،   ويقال بوجوب الحقوق فيها وفي { أنفسكم } ،   بالأمراض والأوجاع والقتل { وَلَتَسْمَعُنَّ مِنَ الذين أُوتُواْ الكتاب مِن قَبْلِكُمْ } حين قالوا : { لَّقَدْ سَمِعَ الله قَوْلَ الذين قالوا إِنَّ الله فَقِيرٌ وَنَحْنُ أغنياء سَنَكْتُبُ مَا قَالُواْ وَقَتْلَهُمُ الأنبياء بِغَيْرِ حَقٍّ وَنَقُولُ ذُوقُواْ عَذَابَ الحريق } [ آل عمران : 181 ] { وَمِنَ الذين أَشْرَكُواْ } يعني مشركي العرب { أَذًى كَثِيراً } باللسان والفعل ،   ويقال : نزلت الآية في شأن أبي بكر رضي الله عنه ،   كانوا أهل الجاهلية يهددونه ويشتمونه ويقولون : إن ما يفعله محمد صلى الله عليه وسلم بمشاورته ،   فأمره الله تعالى بأن يصبر على أذاهم .   فقال تعالى : { وَأَن تَصْبِرُواْ } على أذاهم { وَتَتَّقُواْ } المكافأة ويقال وتتقوا معاصيه { فَإِنَّ ذلك مِنْ عَزْمِ الأمور } يعني من حقائق الأمور .   ويقال : إن ذلك الصبر من خير الأمور .
