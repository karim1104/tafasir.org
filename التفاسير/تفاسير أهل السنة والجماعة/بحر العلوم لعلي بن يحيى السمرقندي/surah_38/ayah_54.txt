يقول الله تعالى : { إِنَّ هذا لَرِزْقُنَا } يعني : إن هذا الذي ذكرنا لعطاؤنا للمتقين { مَا لَهُ مِن نَّفَادٍ } يعني : لا يكون له فناء ،   ولا انقطاع عنهم ،   وهذا كما قال تعالى : { لاَّ مَقْطُوعَةٍ وَلاَ مَمْنُوعَةٍ } [ الواقعة : 33 ] ثم قال : { هذا } يعني : هذا الرزق للمتقين فيتم الكلام عند قوله : { هذا } .
