ثم قال تعالى : { وَقَالُواْ رَبَّنَا عَجّل لَّنَا قِطَّنَا } قال ابن عباس وذلك أن رسول الله صلى الله عليه وسلم قال لقريش : «مَنْ لَمْ يُؤْمِنْ بِالله أُعْطِيَ كِتَابَهُ بِشِمَالِهِ » فقالوا : { رَبَّنَا عَجّل لَّنَا قِطَّنَا } يعني : صحيفتنا ،   وكتابنا في الدنيا { قَبْلَ يَوْمِ الحساب } والقط في اللغة الصحيفة المكتوبة .   ويقال : لما نزل قوله : { فَأَمَّا مَنْ أُوتِىَ كتابه بِيَمِينِهِ فَيَقُولُ هَاؤُمُ اقرؤا كتابيه } [ الحاقة : 19 ] فقالوا { رَبَّنَا عَجّل لَّنَا } هذا الكتاب { قَبْلَ يَوْمِ الحساب } استهزاء .
