ثم قال : { مَا كَانَ لِي مِنْ عِلْمٍ بالملإ الأعلى } يعني : الملائكة عليهم السلام { إِذْ يَخْتَصِمُونَ } يعني : يتكلمون حين قالوا : { وَإِذْ قَالَ رَبُّكَ للملائكة إِنِّي جَاعِلٌ في الأرض خَلِيفَةً قالوا أَتَجْعَلُ فِيهَا مَن يُفْسِدُ فِيهَا وَيَسْفِكُ الدماء وَنَحْنُ نُسَبِّحُ بِحَمْدِكَ وَنُقَدِّسُ لَكَ قَالَ إني أَعْلَمُ مَا لاَ تَعْلَمُونَ } [ البقرة : 30 ] وإنما عرفت ذلك بالوحي .
