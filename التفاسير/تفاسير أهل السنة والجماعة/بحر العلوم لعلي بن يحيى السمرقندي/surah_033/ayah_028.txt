قوله عز وجل { يا أيها النبي قُل لأزواجك } وذلك أنه رأى منهن الميل إلى الدنيا ،   وطلبن منه فضل النفقة { إِن كُنتُنَّ تردن الحياة الدنيا وزينتها } يعني : وزهرتها { فَتَعَالَيْنَ أُمَتّعْكُنَّ } متعة الطلاق { وَأُسَرّحْكُنَّ سَرَاحاً جَمِيلاً } يعني : أطلقكن طلاق السنة من غير إضرار .  <br />
