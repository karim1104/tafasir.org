قوله عز وجل : { وَإِذَا بَلَغَ الأطفال مِنكُمُ الحلم } يعني : الاحتلام { فَلْيَسْتَأْذِنُواْ كَمَا استأذن الذين مِن قَبْلِهِمْ } يعني : الكبار من ولد الرجل وأقربائه معناه فليستأذنوا في كل وقت ،   كما استأذن الذين من قبلكم ،   يعني : من الرجال { كَذَلِكَ يُبَيّنُ الله لَكُمْ آياته } أي أمره ونهيه في كل وقت ،   { والله عَلِيمٌ } بِصَلاَحِكُم { حَكِيمٌ } حكم بالاستئذان .  <br />
