ثم قال تعالى : { وَإِذْ قَالَ موسى لِقَوْمِهِ اذكروا نِعْمَةَ الله عَلَيْكُمْ إِذْ أَنجَاكُمْ مّنْ ءالِ فِرْعَوْنَ } يعني : من فرعون وآله .   كما قال في آية أخرى : { كَدَأْبِ ءَالِ فِرْعَوْنَ والذين مِن قَبْلِهِمْ كَذَّبُواْ بآيات رَبِّهِمْ فأهلكناهم بِذُنُوبِهِمْ وَأَغْرَقْنَآ ءَالَ فِرْعَونَ وَكُلٌّ كَانُواْ ظالمين } [ الأنفال : 54 ] يعني : فرعون وآله .   { يَسُومُونَكُمْ سُوء العذاب } يقول : يعذبونكم بأشد العذاب { وَيُذَبّحُونَ أَبْنَاءكُمْ } الصغار { وَيَسْتَحْيُونَ نِسَاءكُمْ } يعني : يستخدمون نساءكم { وَفِى ذلكم } يعني : ذبح الأبناء ،   واستخدام النساء ،   { بَلاء مِّن رَّبّكُمْ عَظِيمٌ } يعني : بلية عظيمة لكم من خالقكم .   ويقال : في إنجاء الله نعمة عظيمة لكم .
