ثم بيّن دلائل وحدانيته فقال تعالى : { الله الذي خَلَقَ  السموات والأرض وَأَنزَلَ مِنَ السماء مَاء } وهو المطر { فَأَخْرَجَ بِهِ } يعني : فأنبت بالمطر { من الثمرات } يعني من ألوان الثمرات { رزقا لكم } يعني : طعاما لكم يقول بإذنه { وَسَخَّرَ لَكُمُ الفلك } يعني : ذلل لكم ركوب الفلك ،   { لتجري في البحر بأمره } يقول بإذنه .  <br />
