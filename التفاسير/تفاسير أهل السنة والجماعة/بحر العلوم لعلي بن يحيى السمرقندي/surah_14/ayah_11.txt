{ قَالَتْ لَهُمْ رُسُلُهُمْ إِن نَّحْنُ إِلاَّ بَشَرٌ مّثْلُكُمْ } يقول : ما نحن إلا آدميون مثلكم كما تقولون { ولكن الله يَمُنُّ على مَن يَشَاء مِنْ عِبَادِهِ } ويختاره للنبوة { وَمَا كَانَ لَنَا أَن نَّأْتِيَكُمْ بسلطان } جواباً لقولهم : { فَأْتُونَا بسلطان مُّبِينٍ } يعني : لا ينبغي أن نأتيكم بِسُلْطَانٍ { إِلاَّ بِإِذْنِ الله } لأن الأمر بيد الله تعالى { وَعَلَى الله فَلْيَتَوَكَّلِ المؤمنون } يعني : على المؤمنين أن يتوكلوا على الله .  <br />
