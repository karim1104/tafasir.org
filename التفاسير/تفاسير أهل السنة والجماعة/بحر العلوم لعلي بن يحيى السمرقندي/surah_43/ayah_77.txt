قوله تعالى : { وَنَادَوْاْ يا مالك } وذلك أنه لما يشتد عليهم العذاب ،   يتمنون الموت ،   ويقولون لخازن جهنم : يَا مَالِك { لِيَقْضِ عَلَيْنَا رَبُّكَ } يعني : ادع ربك لقبض أرواحنا ،   فأجابهم بعد أربعين سنة { قَالَ إِنَّكُمْ ماكثون } وروى عطاء بن السائب ،   عن رجل عن ابن عباس رضي الله عنهما قال : يجيبهم بعد ألف سنة { إِنَّكُمْ ماكثون } ويقال : إنهم ينادون { وَنَادَوْاْ يا مالك لِيَقْضِ عَلَيْنَا رَبُّكَ } فأوحى الله تعالى إلى مالك ليجيبهم ،   فيقول لهم مالك { إنَّكُمْ مَاكِثُونَ } .  <br />
