ثم قال تعالى : { وكذلك أنزلناه } ،   يعني : جبريل عليه السلام بالقرآن { آيات بَيّنَاتٍ } ،   يعني : واضحات بالحلال والحرام .   { وَأَنَّ الله يَهْدِى مَن يُرِيدُ } ،   يعني : يرشد إلى دينه من كان أهلاً لذلك ،   فيوفقه لذلك ؛ وهذا كقوله : { والله يدعوا إلى دَارِ السلام وَيَهْدِى مَن يَشَآءُ إلى صِرَاطٍ مُّسْتَقِيمٍ } [ يونس : 25 ] .
