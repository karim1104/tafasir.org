ثم قال عز وجل : { ذلك } ،   يعني : هذا الذي ذكر من أمور المناسك .   ثم قال : { وَمَن يُعَظّمْ حرمات الله } ،   يعني : أمر المناسك كلها ،   { فَهُوَ خَيْرٌ لَّهُ عِندَ رَبّهِ }  ؛ يعني : أعظم لأجره ،   { وَأُحِلَّتْ لَكُمُ الأنعام }  ؛ يعني : الإبل والبقر والغنم وغيره .   { إِلاَّ مَا يتلى عَلَيْكُمْ } في التحريم في سورة المائدة .   { فاجتنبوا الرجس مِنَ الاوثان } ،   يعني : اتركوا عبادة الأوثان ،   { واجتنبوا }  ؛ يعني : اتركوا { قَوْلَ الزور } ،   يعني : الكذب ؛ وهو قولهم : هذا حلال وهذا حرام ؛ ويقال : معناه اتركوا الشرك ؛ ويقال : اتركوا شهادة الزور .  <br />
