ثم قال { ضُرِبَتْ عَلَيْهِمُ الذلة } يقول جُعِلَتْ عليهم الجزية ويقال أَلْزِم عليهم القتال { أَيْنَمَا ثُقِفُواْ } أي وُجدوا { إِلاَّ بِحَبْلٍ مّنْ الله } أي بعهد من الله { وَحَبْلٍ مّنَ الناس } يعني تحت قوم يؤدون إليهم الجزية ،   فإن لم يكن لهم عهد قتلوا { وَبَاءوا بِغَضَبٍ مّنَ الله } يقول : استوجبوا الغضب من الله تعالى .   ويقال : رجعوا بغضب من الله { وَضُرِبَتْ عَلَيْهِمُ المسكنة } يعني جعل عليهم زي الفقر .  <br />
قال الكلبي : فترى الرجل منهم غنياً ،   وعليه من البؤس والفقر والمسكنة .   ويقال : إنهم يظهرون من أنفسهم الفقر ،   لكيلا تضاعف عليهم الجزية { ذلك } الذي يصيبهم { بِأَنَّهُمْ كَانُواْ يَكْفُرُونَ بآيات الله } ومحمد صلى الله عليه وسلم وبالقرآن { وَيَقْتُلُونَ الأنبياء بِغَيْرِ حَقّ } يعني رضوا بما فعل آباؤهم ،   فكأنهم قتلوهم { ذلك } الغضب { بِمَا عَصَواْ } الله { وَّكَانُواْ يَعْتَدُونَ } بأفعالهم كلما ذكر الله عقوبة قوم في كتابه بيّن المعنى الذي يعاقبهم لذلك ،   لكيلا يظن أحد أنه عذَّبهم بغير جُرْم .  <br />
