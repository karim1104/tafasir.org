ثم أخبر الله تعالى عن جهلهم ،   وقلة عقلهم ،   فقال : { قُلْ } يا محمد ،   { أَتَعْبُدُونَ مِن دُونِ الله } يعني : عيسى ،   { مَا لاَ يَمْلِكُ لَكُمْ } يقول : ما لا يقدر لكم ،   { ضَرّا } في الدنيا { وَلاَ نَفْعاً } في الآخرة : وتركتم عبادة الله ،   { والله هُوَ السميع } لقولكم ،   { العليم } بعقوبتكم .  <br />
