وقوله تعالى :<br />
{ وَلَوْ أَنَّ أَهْلَ الكتاب } يعني : اليهود والنصارى ،   { آمَنُواْ } يعني : صدقوا بتوحيد الله تعالى وبمحمد صلى الله عليه وسلم والقرآن { واتقوا } الشرك والمعاصي ،   { لَكَفَّرْنَا عَنْهُمْ سيئاتهم } يعني : غفرنا ذنوبهم ،   { ولأدخلناهم جنات النعيم } في الآخرة .  <br />
