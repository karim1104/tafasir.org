{ وَقِيلَ } يعني : قالت لهم الخزنة { اليوم نَنسَاكُمْ } يعني : نترككم في النار .   { كَمَا نَسِيتُمْ لِقَاء يَوْمِكُمْ هذا } يعني : كما تركتم الإيمان والعمل ،   لحضور يومكم هذا .  <br />
{ وَمَأْوَاكُمُ النار } يعني : مثواكم ومستقركم النار { وَمَا لَكُمْ مّن ناصرين } يعني : ليس لكم مانع يمنعكم ،   مما نزل بكم من العذاب .  <br />
