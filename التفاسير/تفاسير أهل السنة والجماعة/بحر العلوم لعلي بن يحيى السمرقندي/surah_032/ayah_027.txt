ثم قال عز وجل : { أَوَ لَمْ يَرَوْاْ أَنَّا نَسُوقُ الماء إِلَى الأرض الجرز } يعني : اليابسة الملساء التي ليس فيها نبات .   يقال : أرض جرز أي : أرض جدب لا نبات فيها .   يقال : جرزت الجراد إذا أكلت ،   وتركت الأرض جرزاً { فَنُخْرِجُ بِهِ زَرْعاً } يعني : نخرج بالماء النبات { تَأْكُلُ مِنْهُ أنعامهم } أي : من الكلأ والعشب والتبن { وَأَنفُسِهِمْ } من الحبوب والثمار { أَفَلاَ يُبْصِرُونَ } هذه العجائب فيوحّدوا ربهم .  <br />
