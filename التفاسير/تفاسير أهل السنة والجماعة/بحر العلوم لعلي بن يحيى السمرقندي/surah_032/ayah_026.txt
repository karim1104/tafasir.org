ثم خوّف كفار مكة فقال عز وجل : { أَوَ لَمْ يَهْدِ لَهُمْ } يعني : أو لم يبيِّن لهم الله تعالى .   وقرئ في الشاذ { أَوَ لَمْ نهد لَهُمْ } بالنون .   وقرأ العامة بالياء .   { كَمْ أَهْلَكْنَا } يعني : أو لم نبين لهم الهلاك { مِن قَبْلِهِمْ مّنَ القرون } يعني : قوم لوط وصالح وهود { يَمْشُونَ في مساكنهم } يعني : يمرون في منازلهم { إِنَّ في ذَلِكَ لآيات } يعني : في إهلاكهم { لآيات } لعبرات { أَفَلاَ يَسْمَعُونَ } أي : أفلا يسمعون المواعظ فيعتبرون بها .  <br />
