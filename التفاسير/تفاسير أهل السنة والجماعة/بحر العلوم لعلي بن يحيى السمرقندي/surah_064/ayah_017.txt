وقوله تعالى : { إِن تُقْرِضُواْ الله قَرْضاً حَسَناً } يعني : صادقاً من قلوبكم .   { يضاعفه لَكُمْ } يعني : القرض يضاعف حسناتكم .   ويقال : { يضاعفه لَكُمْ } يعني : الله تعالى يضاعف القرض لكم ،   فيعطي للواحد عشرة .   إلى سبعمائة ،   إلى ما لا يحصى .   { وَيَغْفِرْ لَكُمْ } يعني : يغفر لكم ذنوبكم .   { والله شَكُورٌ } يعني : يقبل اليسير ويعطي الجزيل .   { حَلِيمٌ } لا يعجل بالعقوبة لمن يبخل .  <br />
