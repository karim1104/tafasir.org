{ سَلاَمٌ قَوْلاً مّن رَّبّ رَّحِيمٍ } يعني : يرسل إليهم ربهم بالتحية والسلام .   والعرب تقول : ادّعي ما شئت ،   { يَدَّعُونَ } يتمنون .   فقوله عز وجل : { سَلاَمٌ قَوْلاً } يعني : يقال لهم سلام كأنهم يتلقونه بالسلام { مّن رَّبّ رَّحِيمٍ } ويقال : { وَلَهُمْ مَّا يَدَّعُونَ سلام } يعني : لهم ما يشاؤون خالصاً .   ثم قال : { قَوْلاً مّن رَّبّ رَّحِيمٍ } .  <br />
