ثم قال عز وجل : { لَقَدْ حَقَّ القول } أي : وجب القول بالعذاب { على أَكْثَرِهِمْ } أي : على الكفار .   ويقال : { لَقَدْ حَقَّ القول } وهو قوله : { قَالَ اخرج مِنْهَا مَذْءُومًا مَّدْحُورًا لَّمَن تَبِعَكَ مِنْهُمْ لأَمْلأَنَّ جَهَنَّمَ مِنكُمْ أَجْمَعِينَ } [ الأعراف : 18 وغيرها ] ويقال : { القول } كناية عن العذاب أي : وجب عليهم العذاب { فَهُمْ لاَ يُؤْمِنُونَ } يعني : لا يصدقون بالقرآن .
