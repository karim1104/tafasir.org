قوله تعالى : { قَالَتْ رُسُلُهُمْ أَفِى الله شَكٌّ } يقول : أفي وحدانية الله شك ؟ وعلامات وحدانيته ظاهرة { فَاطِرَ  السموات والارض } يعني : تشكون في الله خالق السموات والأرض { يَدْعُوكُمْ لِيَغْفِرَ لَكُمْ } يعني : يدعوكم إلى الإقرار بوحدانية الله تعالى ليتجاوز عنكم { مّن ذُنُوبِكُمْ وَيُؤَخّرَكُمْ إِلَى أَجَلٍ مُّسَمًّى } يعني : منتهى آجالكم ،   فلا يصيبكم فيه العذاب .   فأجابهم قومهم { قَالُواْ إِنْ أَنتُمْ إِلاَّ بَشَرٌ مّثْلُنَا } يقول : ما أنتم إلا آدميون مثلنا ،   لا فضل لكم علينا بشيء .   { تُرِيدُونَ أَن تَصُدُّونَا } أي : تصرفونا { عَمَّا كَانَ يَعْبُدُ ءابَاؤُنَا } من الآلهة { فَأْتُونَا بسلطان مُّبِينٍ } يعني : بحجة بيّنة .  <br />
