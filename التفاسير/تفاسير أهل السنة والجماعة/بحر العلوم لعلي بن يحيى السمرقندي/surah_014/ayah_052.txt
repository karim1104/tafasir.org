قوله : { هذا بلاغ لّلنَّاسِ } يعني : هذا القرآن إرسال وبيان من الله تعالى .   ويقال : أبلغكم عن الله تعالى .   { وَلِيُنذَرُواْ بِهِ } يعني : ليخوفوا بالقرآن عن معصية الله تعالى { وَلِيَعْلَمُواْ } يعني : لكي يعلموا { إِنَّمَا هُوَ إله وَاحِدٌ } صادق { وَلِيَذَّكَّرَ } أي ليتعظ بما أنزل من التخويف في القرآن { أُوْلُو الألباب } يعني : ذوو العقول من الناس .   والله أعلم بالصواب .  <br />
