قوله { مُهْطِعِينَ } أي : مسرعين يقال : أهطع البعير في السير .   إذا أسرع .   ويقال : { مُهْطِعِينَ } أي ناظرين ،   قاصدين نحو الداعي .   وقال قتادة : { مهطعين } يعني : مسرعين { مُقْنِعِى * رُؤُوسَهُمْ } المقنع الذي يرفع رأسه ،   شاخصاً بصره ،   لا يطرق .   وقال مجاهد : { مُهْطِعِينَ } مديمي النظر ،   { مُقْنِعِى * رُؤُوسَهُمْ } ،   رافعيها .   وقال الخليل بن أحمد : المهطع الذي قد أقبل إلى الشيء ينظره ،   ولا يرفع عينه عنه { مُقْنِعِى } يعني : رافعي رؤوسهم ،   مادي أعناقهم { لاَ يَرْتَدُّ إِلَيْهِمْ طَرْفُهُمْ } يعني : لا يرجع إلى الكفار بصرهم { وَأَفْئِدَتُهُمْ هَوَاء } يعني : خالية من كل خير .   كالهواء ما بين السماء والأرض .   وقال السدي : { وَلاَ أَفْئِدَتُهُمْ } بين موضعها ،   وبين الحنجرة .  <br />
فلم ترجع إلى موضعها .   ولم تخرج كقوله : { وَأَنذِرْهُمْ يَوْمَ الآزفة إِذِ القلوب لَدَى الحناجر كاظمين مَا للظالمين مِنْ حَمِيمٍ وَلاَ شَفِيعٍ يُطَاعُ } [ غافر : 18 ] وهكذا قال مقاتل ،   وقال أبو عبيدة ،   هواء أي مجوفة لا عقول فيها .
