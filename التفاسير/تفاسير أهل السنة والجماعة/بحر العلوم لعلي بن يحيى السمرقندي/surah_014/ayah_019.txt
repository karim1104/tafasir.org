قوله تعالى : { أَلَمْ تَرَ أَنَّ الله خلق } يعني : ألم تعلم أن الله { خُلِقَ  السموات والارض } قرأ حمزة والكسائي { خالق  السموات والأرض } بكسر الضاد على معنى الإضافة .  <br />
وقرأ الباقون : { خُلِقَ  السموات والارض } بنصب الضاد على معنى فعل الماضي .  <br />
وقوله : { بالحق } يعني : بالعدل .   ويقال : ببيان الحق { إِن يَشَأْ يُذْهِبْكُمْ } يقول : يميتكم ،   ويهلككم إن عصيتموه { وَيَأْتِ بِخَلْقٍ جَدِيدٍ } يعني : قوماً غيركم ،   خيراً منكم ،   وأطوع لله تعالى .   فهذا تهديد من الله ليخافوه .  <br />
