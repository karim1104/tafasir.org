وقوله تعالى : { قُلْ يا أيها الذين هَادُواْ } يعني : مالوا عن الإسلام والحق إلى اليهودية .  <br />
{ إِن زَعمْتُمْ أَنَّكُمْ } يعني : إن ادعيتم وقلتم إنكم { أَوْلِيَاء لِلَّهِ } يعني : أحباباً لله .   { مّن دُونِ الناس } يعني : من دون المؤمنين ،   { فَتَمَنَّوُاْ الموت } يعني : سلوا الموت ،   فقولوا : اللهم أمتنا .   { إِن كُنتُمْ صادقين } بأنكم أولياء الله من دون المؤمنين .  <br />
