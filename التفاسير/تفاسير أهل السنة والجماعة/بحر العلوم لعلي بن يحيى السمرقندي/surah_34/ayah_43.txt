ثم أخبر عن أفعالهم في الدنيا فقال عز وجل : { وَإِذَا تتلى } يعني : يقرأ وتعرض { عَلَيْهِمْ آياتنا بينات } بالأمر والنهي والحلال والحرام { قَالُواْ } ما نعرف هذا { مَا هذا إِلاَّ رَجُلٌ يُرِيدُ أَن يَصُدَّكُمْ } يعني : يصرفكم { عَمَّا كَانَ يَعْبُدُ آبَاؤُكُمْ } من عبادة الأصنام { وَقَالُواْ مَا هذا إِلاَّ إِفْكٌ مُّفْتَرًى } يعني : كذباً مختلقاً { وَقَالَ الذين كَفَرُواْ لِلْحَقّ } يعني : للقرآن { لَمَّا جَاءهُمْ إِنْ هذا إِلاَّ سِحْرٌ مُّبِينٌ } يعني : كذب بيّن .  <br />
