قوله تعالى : { والذي قَدَّرَ فهدى } يعني : قدر لكل شيء شكله ،   يعني لكل ذكر وأنثى من شكله وهداه للأكل والشرب والجماع ،   ويقال الذي قدر فهدى يعني فهداه السبيل { إما شاكراً وإما كفوراً } [ الإنسان : 3 ] ويقال { والذي قدر فهدى } سبح لله الذي خلقك وقدر آجالك وأرزاقك وأعمالك وهداك إلى المعرفة والإسلام والأكل والشرب فصلّ بابن آدم وسبح لهذا المنعم المكرم السيد الذي هو الأحد الصمد ،   { هُوَ الأول والأخر والظاهر والباطن وَهُوَ بِكُلِّ شيء عَلِيمٌ } [ الحديد : 3 ] .  <br />
