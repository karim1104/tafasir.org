ثم قال : { نُسَارِعُ لَهُمْ فِى الخيرات } { بَل لاَّ يَشْعُرُونَ } أن ذلك فتنة لهم ؛ ويقال : { أَنَّمَا نُمِدُّهُمْ بِهِ مِن مَّالٍ وَبَنِينَ } وقد تم الكلام ،   يعني : أيظنون أن ذلك خير لهم في الدنيا ؟ ثم قال عز وجل : { نُسَارِعُ لَهُمْ فِى الخيرات } يعني : نبادرهم في الطاعات وهو خير لهم ،   أي في الآخرة { بَل لاَّ يَشْعُرُونَ } أن زيادة المال والولد أن ذلك مكر بهم وشر لهم في الآخرة .  <br />
