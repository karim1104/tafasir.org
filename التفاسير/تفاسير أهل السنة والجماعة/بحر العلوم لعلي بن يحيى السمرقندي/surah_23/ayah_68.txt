ثم قال عز وجل : { أَفَلَمْ يَدَّبَّرُواْ القول }  ؛ وأصله يتدبروا فأدغم التاء في الدال ،   يعني : أفلم يتفكروا في القرآن ؟ { أَمْ جَاءهُمْ } من الأمان { مَّا لَمْ يَأْتِ ءابَاءهُمُ الأولين } ،   حتى يؤمنوا ؛ وقال : معناه جاءهم الذي لم يجىء آباءهم الأولين ؛ وهذا كقوله : { لِتُنذِرَ قَوْماً مَّا أُنذِرَ ءابَاؤُهُمْ }  ؛ وقال الكلبي : { أم جاءهم ما لم يأت آباءهم الأولين } من البراءة من العذاب<br />
