يقول تعالى: { وَمَا جَعَلْنَا لِبَشَرٍ مِّن قَبْلِكَ } أي يا محمد { ٱلْخُلْدَ } أي في الدنيا بل [الرحمن: 26-27]، وقوله: { أَفَإِنْ مِّتَّ } أي يا محمد { فَهُمُ ٱلْخَالِدُونَ }؟ أي يؤملون أن يعيشوا بعدك! لا يكون هذا بل كلُّ إلى الفناء، ولهذا قال تعالى: { كُلُّ نَفْسٍ ذَآئِقَةُ ٱلْمَوْتِ } وقد روي عن الشافعي رحمه الله أنه أنشد واستشهد بهذين البيتين: وقوله تعالى: { وَنَبْلُوكُم بِٱلشَّرِّ وَٱلْخَيْرِ فِتْنَةً } أي نختبركم بالمصائب تارة، وبالنعم أخرى. فننظر من يشكر ومن يكفر، ومن يصبر ومن يقنط، قال ابن عباس: ونبلوكم يقول: نبتليكم بالشر والخير فتنة، بالشدة والرخاء. والصحة والسَّقم، والغنى والفقر، والحلال والحرام، والطاعة والمعصية، والهدى والضلال، وقوله: { وَإِلَيْنَا تُرْجَعُونَ } أي فنجازيكم بأعمالكم.
