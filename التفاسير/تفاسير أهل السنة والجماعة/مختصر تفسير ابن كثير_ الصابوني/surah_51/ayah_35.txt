قال الله تعالى مخبراً عن إبراهيم عليه الصلاة والسلام: { قَالَ فَمَا خَطْبُكُمْ أَيُّهَا ٱلْمُرْسَلُونَ }؟ أي ما شأنكم، وفيم جئتم؟ { قَالُوۤاْ إِنَّآ أُرْسِلْنَآ إِلَىٰ قَوْمٍ مُّجْرِمِينَ } يعنون قوم لوط، { لِنُرْسِلَ عَلَيْهِمْ حِجَارَةً مِّن طِينٍ * مُّسَوَّمَةً } أي معلمة، { عِندَ رَبِّكَ لِلْمُسْرِفِينَ } أي مكتتبة عنده بأسمائهم، كل حجر عليه اسم صاحبه، { فَأَخْرَجْنَا مَن كَانَ فِيهَا مِنَ ٱلْمُؤْمِنِينَ } وهو لوط وأهل بيته إلا امرأته { فَمَا وَجَدْنَا فِيهَا غَيْرَ بَيْتٍ مِّنَ ٱلْمُسْلِمِينَ } ، وقوله تعالى: { وَتَرَكْنَا فِيهَآ آيَةً لِّلَّذِينَ يَخَافُونَ ٱلْعَذَابَ ٱلأَلِيمَ } أي جعلناها عبرة بما أنزلنا بهم من العذاب والنكال، وجعلنا محلتهم بحيرة منتنة خبيثة، ففي ذلك عبرة للمؤمنين { لِّلَّذِينَ يَخَافُونَ ٱلْعَذَابَ ٱلأَلِيمَ }.
