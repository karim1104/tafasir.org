يقول تعالى آمراً رسوله صلى الله عليه وسلم أن يقول للكفار بالله المشركين به المكذبين لرسوله { قُلْ إِنَّمَآ أَنَاْ مُنذِرٌ } لست كما تزعمون، { وَمَا مِنْ إِلَـٰهٍ إِلاَّ ٱللَّهُ ٱلْوَاحِدُ ٱلْقَهَّارُ } أي هو وحده قد قهر كل شيء وغلبه، { رَبُّ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ وَمَا بَيْنَهُمَا } أي هو مالك جميع ذلك ومتصرف فيه، { ٱلْعَزِيزُ ٱلْغَفَّارُ } أي غفار مع عظمته وعزته، { قُلْ هُوَ نَبَأٌ عَظِيمٌ } أي خبر عظيم وشأن بليغ، وهو إرسال الله تعالى إياي إليكم، { أَنتُمْ عَنْهُ مُعْرِضُونَ } أي غافلون، قال مجاهد { قُلْ هُوَ نَبَأٌ عَظِيمٌ }: يعني القرآن، وقوله تعالى: { مَا كَانَ لِيَ مِنْ عِلْمٍ بِٱلْمَلإِ ٱلأَعْلَىٰ إِذْ يَخْتَصِمُونَ } أي لولا الوحي من أين كنت أدري باختلاف الملأ الأعلى؟ يعني في شأن آدم عليه الصلاة والسلام، وامتناع إبليس من السجود له، ومحاجته ربه في تفضيله عليه، وغير ذلك.
