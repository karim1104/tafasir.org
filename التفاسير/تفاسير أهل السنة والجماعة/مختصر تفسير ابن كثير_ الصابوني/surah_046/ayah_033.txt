يقول تعالى: أو لم ير هؤلاء المنكرون للبعث، المستبعدون لقيام الأجساد يوم المعاد { أَنَّ ٱللَّهَ ٱلَّذِي خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ وَلَمْ يَعْيَ بِخَلْقِهِنَّ } أي ولم يكرثه خلقهن بل قال لها: كوني فكانت، بلا ممانعة ولا مخالفة، بل طائعة مجيبة خائفة وجلة، أفليس ذلك بقادر على أن يحيي الموتى؟ كما قال عزّ وجلّ في الآية الأُخرى: [غافر: 57]، ولهذا قال تعالى: { بَلَىٰ إِنَّهُ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ } ثم قال جلّ جلاله متهدداً ومتوعداً لمن كفر به: { وَيَوْمَ يُعْرَضُ ٱلَّذِينَ كَفَرُواْ عَلَىٰ ٱلنَّارِ أَلَيْسَ هَـٰذَا بِٱلْحَقِّ }؟ أي يقال لهم: أما هذا حق؟ أفسحر هذا أم أنتم لا تبصرون؟ { قَالُواْ بَلَىٰ وَرَبِّنَا } أي لا يسعهم إلاّ الاعتراف، { قَالَ فَذُوقُواْ ٱلْعَذَابَ بِمَا كُنتُمْ تَكْفُرُونَ } ، ثم قال تبارك وتعالى آمراً رسوله صلى الله عليه وسلم بالصبر على تكذيب من كذبه من قومه { فَٱصْبِرْ كَمَا صَبَرَ أُوْلُواْ ٱلْعَزْمِ مِنَ ٱلرُّسُلِ } أي على تكذيب قومهم لهم، { وَلاَ تَسْتَعْجِل لَّهُمْ } أي لا تستعجل لهم حلول العقوبة بهم كقوله تبارك وتعالى [المزمل: 11]، وكقوله تعالى: [الطارق: 17] { كَأَنَّهُمْ يَوْمَ يَرَوْنَ مَا يُوعَدُونَ لَمْ يَلْبَثُوۤاْ إِلاَّ سَاعَةً مِّن نَّهَارٍ } كقوله عزّ وجلّ: [النازعات: 46]، وكقوله عزّ وجلّ: [يونس: 45] الآية، وقوله جل وعلا: { بَلاَغٌ } تقديره هذا القرآن بلاغ، وقوله تعالى: { فَهَلْ يُهْلَكُ إِلاَّ ٱلْقَوْمُ ٱلْفَاسِقُونَ }؟ أي لا يهلك إلاّ هالك، وهذا من عدله عزَّ وجلَّ، أنه لا يعذب إلاّ من يستحق العذاب والله أعلم.
