يقول تعالى: { وَبَرَزُواْ } أي برزت الخلائق كلها، برها وفاجرها لله الواحد القهار، أي اجتمعوا له في براز من الأرض، وهو المكان الذي ليس فيه شيء يستر أحداً، { فَقَالَ ٱلضُّعَفَاءُ } وهم الأتباع لقادتهم وسادتهم وكبرائهم { لِلَّذِينَ ٱسْتَكْبَرُوۤاْ } عن عبادة الله وحده لا شريك له، وعن موافقة الرسل، قالوا لهم: { إِنَّا كُنَّا لَكُمْ تَبَعًا } أي مهما أمرتمونا ائتمرنا وفعلنا، { فَهَلْ أَنتُمْ مُّغْنُونَ عَنَّا مِنْ عَذَابِ ٱللَّهِ مِن شَيْءٍ } أي فهل تدفعون عنا شيئاً من عذاب الله كما كنتم تعدوننا وتمنوننا، فقالت القادة لهم: { لَوْ هَدَانَا ٱللَّهُ لَهَدَيْنَاكُمْ } ولكن حقت كلمة العذاب على الكافرين، { سَوَآءٌ عَلَيْنَآ أَجَزِعْنَآ أَمْ صَبَرْنَا مَا لَنَا مِن مَّحِيصٍ } أي ليس لنا خلاص مما نحن فيه إن صبرنا عليه أو جزعنا منه. قال عبد الرحمٰن بن أسلم: إن أهل النار قالوا: تعالوا فإنما أدرك أهل الجنة الجنة ببكائهم وتضرعهم إلى الله عزّ وجلّ، تعالوا نبك ونتضرع إلى الله، فبكوا وتضرعوا، فلما رأوا أنه لا ينفعهم، قالوا: إنما أدرك أهل الجنة الجنة بالصبر، تعالوا حتى نصبر فصبروا صبراً لم ير مثله، فلم ينفعهم ذلك، فعند ذلك قالوا: { سَوَآءٌ عَلَيْنَآ أَجَزِعْنَآ أَمْ صَبَرْنَا } الآية. قلت: والظاهر أن هذه المراجعة في النار بعد دخولهم إليها، كما قال تعالى: [غافر: 47]، وقال [الأعراف: 38]، وقال تعالى: [الأحزاب: 67]، وأما تخاصمهم في المحشر فقال تعالى: [سبأ: 31-32].
