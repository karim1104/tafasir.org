يقول تعالى: { وَذَرِ الَّذِينَ ٱتَّخَذُواْ دِينَهُمْ لَعِباً وَلَهْواً وَغَرَّتْهُمُ ٱلْحَيَاةُ ٱلدُّنْيَا } أي دعهم وأعرض عنهم وأمهلهم قليلاً فإنهم صائرون إلى عذاب عظيم، ولهذا قال: { وَذَكِّرْ بِهِ } أي ذكر الناس بهذا القرآن وحذرهم نقمة الله وعذابه الأليم يوم القيامة، وقوله تعالى: { أَن تُبْسَلَ نَفْسٌ بِمَا كَسَبَتْ } أي لئلا تبسل، قال ابن عباس والحسن والسدي: تبسل: تسلم، وقال الوالبي عن ابن عباس: تفتضح. وقال قتادة: تحبس، وقال ابن زيد: تؤاخذ، وقال الكلبي: تجزى، وكل هذا الأقوال والعبارات متقاربة في المعنى، وحاصلها الإسلام للهلكة، والحبس عن الخير، والارتهان عن درك المطلوب، كقوله: [المدثر: 38-39]، وقوله: { لَيْسَ لَهَا مِن دُونِ ٱللَّهِ وَلِيٌّ وَلاَ شَفِيعٌ } أي لا قريب ولا أحد يشفع فيها، كقوله: [البقرة: 254]، وقوله: { وَإِن تَعْدِلْ كُلَّ عَدْلٍ لاَّ يُؤْخَذْ مِنْهَآ } أي ولو بذلت كل مبذول ما قبل منها كقوله: [آل عمران: 91] الآية، وكذا قال هٰهنا: { أُوْلَـٰئِكَ ٱلَّذِينَ أُبْسِلُواْ بِمَا كَسَبُواْ لَهُمْ شَرَابٌ مِّنْ حَمِيمٍ وَعَذَابٌ أَلِيمٌ بِمَا كَانُواْ يَكْفُرُونَ }.
