يقول تعالى: { وَ } لقد أرسلنا { إِلَىٰ ثَمُودَ } وهم الذين كانوا يسكنون مدائن الحجر بين تبوك والمدينة وكانوا بعد عاد فبعث الله منهم { أَخَاهُمْ صَالِحاً } فأمرهم بعبادة الله وحده، ولهذا قال: { هُوَ أَنشَأَكُمْ مِّنَ ٱلأَرْضِ } أي ابتدأ خلقكم منها خلق أباكم آدم، { وَٱسْتَعْمَرَكُمْ فِيهَا } أي جعلكم عماراً تعمرونها وتستغلونها، { فَٱسْتَغْفِرُوهُ } لسالف ذنوبكم { ثُمَّ تُوبُوۤاْ إِلَيْهِ } فيما تستقبلونه، { إِنَّ رَبِّي قَرِيبٌ مُّجِيبٌ } ، كما قال تعالى: [البقرة: 186] الآية.
