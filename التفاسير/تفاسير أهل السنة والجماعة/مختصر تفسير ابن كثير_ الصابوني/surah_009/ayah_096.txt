أخبر تعالى عن المنافقين بأنهم إذا رجعوا إلى المدينة أنهم يعتذرون إليهم { قُل لاَّ تَعْتَذِرُواْ لَن نُّؤْمِنَ لَكُمْ } أي لن نصدقكم { قَدْ نَبَّأَنَا ٱللَّهُ مِنْ أَخْبَارِكُمْ } أي قد أعلمنا الله أحوالكم، { وَسَيَرَى ٱللَّهُ عَمَلَكُمْ وَرَسُولُهُ } أي سيظهر أعمالكم للناس في الدنيا، { ثُمَّ تُرَدُّونَ إِلَىٰ عَالِمِ ٱلْغَيْبِ وَٱلشَّهَادَةِ فَيُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ } أي فيخبركم بأعمالكم خيرها وشرها ويجزيكم عليها، ثم أخبر عنهم أنهم سيحلفون لكم معتذرين لتعرضوا عنهم، فلا تؤنبوهم، فأعرضوا عنهم احتقاراً لهم { إِنَّهُمْ رِجْسٌ } أي خبث نجس بواطنهم واعتقاداتهم، ومأواهم في آخرتهم جهنم. { جَزَآءً بِمَا كَانُواْ يَكْسِبُونَ } أي من الآثام والخطايا، وأخبر أنهم إن رضوا عنهم بحلفهم لهم، { فَإِنَّ ٱللَّهَ لاَ يَرْضَىٰ عَنِ ٱلْقَوْمِ ٱلْفَاسِقِينَ } أي الخارجين عن طاعة الله وطاعة رسوله.
