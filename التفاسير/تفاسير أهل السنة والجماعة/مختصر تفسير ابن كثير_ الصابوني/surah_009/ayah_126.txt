يقول تعالى: أولا يرى هؤلاء المنافقون، { أَنَّهُمْ يُفْتَنُونَ } أي يختبرون، { فِي كُلِّ عَامٍ مَّرَّةً أَوْ مَرَّتَيْنِ ثُمَّ لاَ يَتُوبُونَ وَلاَ هُمْ يَذَّكَّرُونَ } أي لا يتوبون عن ذنوبهم السالفة، ولا هم يذكرون فيما يستقبل من أحوالهم. قال مجاهد: يخترون بالسنة والجوع، وقال قتادة: بالغزو في السنة مرة أو مرتين، وقوله: { وَإِذَا مَآ أُنزِلَتْ سُورَةٌ نَّظَرَ بَعْضُهُمْ إِلَىٰ بَعْضٍ } هذا أيضاً إخبار عن المنافقين أنهم إذا أنزلت سورة على رسول الله صلى الله عليه وسلم { نَّظَرَ بَعْضُهُمْ إِلَىٰ بَعْضٍ } أي تلفتوا { هَلْ يَرَاكُمْ مِّنْ أَحَدٍ ثُمَّ ٱنصَرَفُواْ } أي تولوا عن الحق وانصرفوا عنه، وهذا حالهم في الدنيا لا يثبتون عند الحق ولا يقبلونه ولا يفهمونه كقوله تعالى: [المدثر: 49-50]، وقوله: { ثُمَّ ٱنصَرَفُواْ صَرَفَ ٱللَّهُ قُلُوبَهُم } ، كقوله: [فصلت: 5]، وقوله: { بِأَنَّهُمْ قَوْمٌ لاَّ يَفْقَهُونَ } أي لا يفهمون عن الله خطابه، ولا يتصدون لفهمه ولا يريدونه، بل هم في شغل عنه ونفور منه، فلهذا صاروا إلى ما صاروا إليه.
