يقول تعالى: { وَلِكُلِّ أُمَّةٍ } أي قرن وجيل { أَجَلٌ فَإِذَا جَآءَ أَجَلُهُمْ } أي ميقاتهم المقدر لهم { لاَ يَسْتَأْخِرُونَ سَاعَةً وَلاَ يَسْتَقْدِمُونَ } ، ثم أنذر تعالى بني آدم أنه سيبعث إليهم رسلاً يقصون عليهم آياته وبشر وحذر فقال: { فَمَنِ ٱتَّقَىٰ وَأَصْلَحَ } أي ترك المحرمات وفعل الطاعات { فَلاَ خَوْفٌ عَلَيْهِمْ وَلاَ هُمْ يَحْزَنُونَ * وَٱلَّذِينَ كَذَّبُواْ بِآيَاتِنَا وَٱسْتَكْبَرُواْ عَنْهَآ } أي كذبت بها قلوبهم واستكبروا عن العمل بها، { أُوْلَـٰئِكَ أَصْحَابُ ٱلنَّارِ هُمْ فِيهَا خَالِدُونَ } أي ماكثون فيها مكثاً مخلداً.
