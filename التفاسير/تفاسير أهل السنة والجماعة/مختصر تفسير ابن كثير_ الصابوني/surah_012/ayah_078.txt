لما تعين أخذ بنيامين وتقرر تركه عند يوسف بمقتضى اعترافهم، شرعوا يترققون له ويعطفونه عليهم { قَالُواْ يٰأَيُّهَا ٱلْعَزِيزُ إِنَّ لَهُ أَباً شَيْخاً كَبِيراً } يعنون وهو يحبه حباً شديداً ويتسلى به عن ولده الذي فقده، { فَخُذْ أَحَدَنَا مَكَانَهُ } أي بدله يكون عندك عوضاً عنه، { إِنَّا نَرَاكَ مِنَ ٱلْمُحْسِنِينَ } أي العادلين المنصفين القابلين للخير، { قَالَ مَعَاذَ ٱللَّهِ أَن نَّأْخُذَ إِلاَّ مَن وَجَدْنَا مَتَاعَنَا عِندَهُ } أي كما قلتم واعترفتم، { إِنَّـآ إِذاً لَّظَالِمُونَ } أي إن أخذنا بريئاً بمذنب.
