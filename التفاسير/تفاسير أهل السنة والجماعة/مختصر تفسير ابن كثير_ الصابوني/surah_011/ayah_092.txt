يقولون: { يٰشُعَيْبُ مَا نَفْقَهُ } ما نفهم { كَثِيراً } من قولك، { وَإِنَّا لَنَرَاكَ فِينَا ضَعِيفاً } ، قال السدي: أنت واحد، وقال أبو روق: يعنون ذليلاً، لأن عشيرتك ليسوا على دينك، { وَلَوْلاَ رَهْطُكَ لَرَجَمْنَاكَ } أي قومك { لَرَجَمْنَاكَ } قيل: بالحجارة، وقيل: لسببناك، { وَمَآ أَنتَ عَلَيْنَا بِعَزِيزٍ } أي ليس عندنا لك معزة، { قَالَ يٰقَوْمِ أَرَهْطِيۤ أَعَزُّ عَلَيْكُم مِّنَ ٱللَّهِ } ، يقول: أتتركوني لأجل قومي، ولا تتركوني إعظاماً لجناب الرب تبارك وتعالى أن تنالوا نبيّه بمساءة وقد اتخذتم جانب الله { وَرَآءَكُمْ ظِهْرِيّاً } أي نبذتموه خلفكم لا تطيعونه ولا تعظمونه، { إِنَّ رَبِّي بِمَا تَعْمَلُونَ مُحِيطٌ } أي هو يعلم جميع أعمالكم وسيجزيكم عليها.
