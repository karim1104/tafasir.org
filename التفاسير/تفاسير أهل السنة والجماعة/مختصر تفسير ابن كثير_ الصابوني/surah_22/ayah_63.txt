وهذا أيضاً من الدلالة على قدرته وعظيم سلطانه، وأنه يرسل الرياح فتثير سحاباً فيمطر على الأرض الجرز، التي لا نبات فيها وهي هامدة يابسة سوداء ممحلة [فصلت: 39]، وقوله: { فَتُصْبِحُ ٱلأَرْضُ مُخْضَرَّةً } أي خضراء بعد يبسها ومحولها، { إِنَّ ٱللَّهَ لَطِيفٌ خَبِيرٌ } أي عليم بما في أرجاء الأرض وأقطارها وأجزائها، لا يخفى عليه خافية، كما قال لقمان: [لقمان: 16]، وقال تعالى: [الأنعام: 59]، وقوله: { مَا فِي ٱلسَّمَٰوَٰتِ وَمَا فِي ٱلأَرْضِ } أي ملكه جميع الأشياء وهو غني عما سواه، وكل شيء فقير إليه عبد لديه، وقوله: { أَلَمْ تَرَ أَنَّ ٱللَّهَ سَخَّرَ لَكُم مَّا فِي ٱلأَرْضِ } أي من حيوان وجماد وزروع وثمار كما قال: [الجاثية: 13] أي من إحسانه وفضله وامتنانه { وَٱلْفُلْكَ تَجْرِي فِي ٱلْبَحْرِ بِأَمْرِهِ } أي بتسخيره وتسييره، أي في البحر العجاج وتلاطم الأمواج، تجري الفلك بأهلها بريح طيبة فيحملون فيها ما شاءوا من بضائع ومنافع، من بلد إلى بلد وقطر إلى قطر { وَيُمْسِكُ ٱلسَّمَآءَ أَن تَقَعَ عَلَى ٱلأَرْضِ إِلاَّ بِإِذْنِهِ } ولهذا قال: { إِنَّ ٱللَّهَ بِٱلنَّاسِ لَرَءُوفٌ رَّحِيمٌ } أي من ظلمهم كما قال في الآية الأخرى [الرعد: 6]، وقوله: { وَهُوَ ٱلَّذِيۤ أَحْيَاكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ إِنَّ ٱلإِنْسَانَ لَكَفُورٌ } ، كقوله: [البقرة: 28]، وقوله: [الجاثية: 26]، وقوله: [غافر: 11] ومعنى الكلام كيف تجعلون لله أنداداً وتعبدون معه غيره، وهو المستقل بالخلق والرزق والتصرف، { وَهُوَ ٱلَّذِيۤ أَحْيَاكُمْ } أي خلقكم بعد أن لم تكونوا شيئاً يذكر فأوجدكم، { ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ } أي يوم القيامة، { إِنَّ ٱلإِنْسَانَ لَكَفُورٌ } أي جحود لربه.
