يقول تعالى: مخبراً عن الكفار أنهم لا يزالون في { مِرْيَةٍ } أي في شك وريب من هذا القرآن قاله ابن جريج، واختاره ابن جرير، وقال سعيد بن جبير وابن زيد { مِّنْهُ } أي مما ألقى الشيطان، { حَتَّىٰ تَأْتِيَهُمُ ٱلسَّاعَةُ بَغْتَةً } قال مجاهد: فجأة، وقال قتادة: { بَغْتَةً } بغت القوم أمر الله، وما أخذ الله قوماً قط إلا عند سكرتهم وغرتهم ونعمتهم، فلا تغتروا بالله، إنه لا يغتر بالله إلا القوم الفاسقون، وقوله: { أَوْ يَأْتِيَهُمْ عَذَابُ يَوْمٍ عَقِيمٍ } قال أبي بن كعب: هو يوم بدر؛ وقال عكرمة ومجاهد: هو يوم القيامة لا ليل له، وهذا القول هو الصحيح، وإن كان يوم بدر من جملة ما أوعدوا به لكن هذا هو المراد، ولهذا قال: { ٱلْمُلْكُ يَوْمَئِذٍ للَّهِ يَحْكُمُ بَيْنَهُمْ } ، كقوله: [الفاتحة: 4]، وقوله: [الفرقان: 26] { فَٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ } أي آمنت قلوبهم وصدقوا بالله ورسوله، وعملوا بمقتضى ما علموا مع توافق قلوبهم وأقوالهم { فِي جَنَّاتِ ٱلنَّعِيمِ } أي لهم النعيم المقيم الذي لا يحول ولا يزول ولا يبيد، { وَٱلَّذِينَ كَفَرُواْ وَكَذَّبُواْ بِآياتِنَا } أي كفرت قلوبهم بالحق وجحدته، وكذبوا به وخالفوا الرسل، واستكبروا عن اتباعهم، { فَأُوْلَـٰئِكَ لَهُمْ عَذَابٌ مُّهِينٌ } أي مقابلة استكبارهم وإبائهم عن الحق، كقوله تعالى: [غافر: 60] أي صاغرين.
