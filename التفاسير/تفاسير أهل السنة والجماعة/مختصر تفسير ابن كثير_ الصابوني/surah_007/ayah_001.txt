تقدم الكلام في أول سورة البقرة على ما يتعلق بالحروف وبسطه واختلاف الناس فيه، قال ابن جرير عن ابن عباس { الۤمۤصۤ }: أنا الله أفصل، { كِتَابٌ أُنزِلَ إِلَيْكَ } أي هذا الكتاب أنزل إليك أي من ربك، { فَلاَ يَكُنْ فِي صَدْرِكَ حَرَجٌ مِّنْهُ } شك منه، وقيل: لا تتحرج به في إبلاغه والإنذار به، [الأحقاف: 35]، ولهذا قال: { لِتُنذِرَ بِهِ } أي أنزلناه إليك لتنذر به الكافرين { وَذِكْرَىٰ لِلْمُؤْمِنِينَ } ، ثم قال تعالى مخاطباً للعالم: { ٱتَّبِعُواْ مَآ أُنزِلَ إِلَيْكُمْ مِّن رَّبِّكُمْ } أي اقتفوا آثار النبي الأمي الذي جاءكم بكتاب أنزل إليكم من رب كل شيء ومليكه، { وَلاَ تَتَّبِعُواْ مِن دُونِهِ أَوْلِيَآءَ } أي لا تخرجوا عما جاءكم به الرسول إلى غيره فتكونوا قد عدلتم عن حكم الله إلى حكم غيره، { قَلِيلاً مَّا تَذَكَّرُونَ } ، كقوله: [يوسف: 103]، وقوله: [الأنعام: 116]، وقوله: [يوسف: 106].
