ينكر تعالى على من اتخذ من دونه آلهة فقال { أَمِ ٱتَّخَذُوۤاْ آلِهَةً مِّنَ ٱلأَرْضِ هُمْ يُنشِرُونَ } أي يحيون الموتى وينشرونهم من الأرض؟ أي لا يقدرون على شيء من ذلك فكيف جعلوها لله نداً وعبدوها معه؟ ثم أخبر تعالى أنه لو كان في الوجود آلهة غيره لفسدت السماوات والأرض، فقال { لَوْ كَانَ فِيهِمَآ آلِهَةٌ إِلاَّ ٱللَّهُ } أي في السماوات والأرض { لَفَسَدَتَا } ، كقوله تعالى: [المؤمنون: 91]، وقال هٰهنا: { فَسُبْحَانَ ٱللَّهِ رَبِّ ٱلْعَرْشِ عَمَّا يَصِفُونَ } أي عما يقولون إن له ولداً أو شريكاً. وقوله: { لاَ يُسْأَلُ عَمَّا يَفْعَلُ وَهُمْ يُسْأَلُونَ } أي هو الحاكم الذي لا معقب لحكمه، ولا يعترض عليه أحد لعظمته وجلاله وكبريائه، وعدله { وَهُمْ يُسْأَلُونَ } أي وهو سائل خلقه عما يعملون، كقوله: [الحجر: 92-93].
