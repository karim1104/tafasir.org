يقول تعالى: { أَمِ ٱتَّخَذُواْ مِن دُونِهِ آلِهَةً قُلْ } يا محمد { هَاتُواْ بُرْهَانَكُمْ } أي دليلكم عل ما تقولون، { هَـٰذَا ذِكْرُ مَن مَّعِيَ } يعني القرآن، { وَذِكْرُ مَن قَبْلِي } يعني الكتب المتقدمة على خلاف ما تقولونه وتزعمون، فكل كتاب أنزل على كل نبي أرسل، ناطق بأنه [الصافات: 35] ولكن أنتم أيها المشركون لا تعلمون الحق فأنتم معرضون عنه؛ ولهذا قال: { وَمَآ أَرْسَلْنَا مِن قَبْلِكَ مِن رَّسُولٍ إِلاَّ نُوحِيۤ إِلَيْهِ أَنَّهُ لاۤ إِلَـٰهَ إِلاَّ أَنَاْ فَٱعْبُدُونِ } ، كما قال: [الزخرف: 45]؟ فكل نبي بعثه الله يدعو إلى عبادة الله وحده لا شريك له، والفطرة شاهدة بذلك أيضاً، والمشركون لا برهان لهم، وعليهم غضب ولهم عذاب شديد.
