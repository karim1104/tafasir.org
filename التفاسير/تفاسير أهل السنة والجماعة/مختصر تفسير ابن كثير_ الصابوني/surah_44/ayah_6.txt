يقول تعالى مخبراً عن القرآن العظيم، أنه أنزله في ليلة مباركة وهي ليلة القدر، كما قال عزَّ وجلَّ: [القدر: 1] وكان ذلك في شهر رمضان، كما قال تبارك وتعالى: [البقرة: 185]، وقوله عزّ وجلّ: { إِنَّا كُنَّا مُنذِرِينَ } أي معلمين الناس ما ينفعهم ويضرهم شرعاً لتقوم حجة الله على عباده، وقوله: { فِيهَا يُفْرَقُ كُلُّ أَمْرٍ حَكِيمٍ } أي في ليلة القدر يفصل من اللوح المحفوظ إلى الكتبة أمر السنة، وما يكون فيها من الآجال والأرزاق وما يكون فيها إلى آخرها، وقوله جلّ وعلا: { حَكِيمٍ } أي محكم لا يبدل ولا يغير، ولهذا قال جلّ جلاله: { أَمْراً مِّنْ عِنْدِنَآ } أي جميع ما يكون ويقدره الله تعالى وما يوحيه فبأمره وإذنه وعلمه { إِنَّا كُنَّا مُرْسِلِينَ } أي إلى الناس رسولاً يتلو عليهم آيات الله مبينات، فإن الحاجة كانت ماسة إليه، ولهذا قال تعالى: { رَحْمَةً مِّن رَّبِّكَ إِنَّهُ هُوَ ٱلسَّمِيعُ ٱلْعَلِيمُ * رَبِّ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ وَمَا بَيْنَهُمَآ } أي الذي أنزل القرآن هو رب السماوات والأرض وخالقهما ومالكهما وما فيهما، { إِن كُنتُم مُّوقِنِينَ } أي إن كنتم متحققين، ثم قال تعالى: { لاَ إِلَـٰهَ إِلاَّ هُوَ يُحْيِـي وَيُمِيتُ رَبُّكُمْ وَرَبُّ آبَآئِكُمُ ٱلأَوَّلِينَ } وهذه الآية كقوله تعالى: [الأعراف: 158] الآية.
