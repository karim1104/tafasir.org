يقول تعالى منكراً على المنافقين الذين هم على خلاف صفات المؤمنين، ولما كان المؤمنون يأمرون بالمعروف وينهون عن المنكر كان هؤلاء { يَأْمُرُونَ بِٱلْمُنكَرِ وَيَنْهَوْنَ عَنِ ٱلْمَعْرُوفِ وَيَقْبِضُونَ أَيْدِيَهُمْ } أي عن الإنفاق في سبيل الله، { نَسُواْ ٱللَّهَ } أي نسوا ذكر الله { فَنَسِيَهُمْ } أي عاملهم معاملة من نسيهم، كقوله تعالى: [الجاثية: 34]، { إِنَّ ٱلْمُنَافِقِينَ هُمُ الْفَاسِقُونَ } أي الخارجون عن طريق الحق الداخلون في طريق الضلالة، وقوله: { وَعَدَ الله الْمُنَافِقِينَ وَٱلْمُنَافِقَاتِ وَٱلْكُفَّارَ نَارَ جَهَنَّمَ } أي على هذا الصنيع الذي ذكر عنهم، { خَالِدِينَ فِيهَا } أي ماكثين فيها مخلدين هم والكفار { هِيَ حَسْبُهُمْ } أي كفايتهم في العذاب، { وَلَعَنَهُمُ ٱللَّهُ } أي طردهم وأبعدهم { وَلَهُمْ عَذَابٌ مُّقِيمٌ }.
