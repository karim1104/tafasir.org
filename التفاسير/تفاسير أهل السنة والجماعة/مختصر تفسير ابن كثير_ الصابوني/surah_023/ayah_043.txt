يقول تعالى: { ثُمَّ أَنشَأْنَا مِن بَعْدِهِمْ قُرُوناً آخَرِينَ } أي أمماً وخلائق { مَا تَسْبِقُ مِنْ أُمَّةٍ أَجَلَهَا وَمَا يَسْتَأْخِرُونَ } يعني بل يؤخذون على حسب ما قدر لهم تعالى في كتابه المحفوظ وعلمه، قبل كونهم أمة بعد أمة، وجيلاً بعد جيل، { ثُمَّ أَرْسَلْنَا رُسُلَنَا تَتْرَا } قال ابن عباس: يعني يتبع بعضهم بعضاً، وهذا كقوله تعالى: [النحل: 36]، وقوله: { كُلَّ مَا جَآءَ أُمَّةً رَّسُولُهَا كَذَّبُوهُ } يعني جمهورهم وأكثرهم، كقوله تعالى: [يس: 30]، وقوله: { فَأَتْبَعْنَا بَعْضَهُمْ بَعْضاً } أي أهلكناهم، كقوله: [الإسراء: 17]، وقوله: { وَجَعَلْنَاهُمْ أَحَادِيثَ } أي أخباراً وأحاديث للناس، كقوله: [سبأ: 19].
