يخبر تعالى عن ضعف عقول المشركين وقلة ثباتهم وإيقانهم وأنه لا يتصور منهم الإيمان. وقد كتب عليهم الشقاوة وذلك أنهم إذا رأوا تغير الأحكام ناسخها بمنسوخها قالوا لرسول الله صلى الله عليه وسلم: { إِنَّمَآ أَنتَ مُفْتَرٍ } أي كذاب، وإنما هو الرب تعالى يفعل ما يشاء ويحكم ما يريد. وقال مجاهد: { بَدَّلْنَآ آيَةً مَّكَانَ آيَةٍ }: أي وفعناها وأثبتنا غيرها. وقال قتادة: هو كقوله تعالى: [البقرة: 106] الآية، فقال تعالى مجيباً لهم: { قُلْ نَزَّلَهُ رُوحُ ٱلْقُدُسِ } أي جبريل { مِن رَّبِّكَ بِٱلْحَقِّ } أي بالصدق والعدل، { لِيُثَبِّتَ ٱلَّذِينَ آمَنُواْ } فيصدقوا بما أنزل أولاً وثانياً وتخبت له قلوبهم، { وَهُدًى وَبُشْرَىٰ لِلْمُسْلِمِينَ } أي وجعله هادياً وبشارة للمسلمين الذين آمنوا بالله ورسله.
