{ وَلُوطًا إِذْ قَالَ لِقَوْمِهِ } أي واذكر لوطاً «وإذ » بدل منه { أَتَأْتُونَ الفاحشة } أتفعلون السيئة المتمادية في القبح { مَا سَبَقَكُمْ بِهَا } ما عملها قبلكم والباء للتعدية ومنه قوله عليه السلام  "  سبقك بها عكاشة  "  { مّنْ أَحَدٍ } «من » زائدة لتأكيد المنفي وإفادة معنى الاستغراق { مّن العالمين } «من » للتبعيض وهذه جملة مستأنفة أنكر عليهم أولاً بقوله { أَتَأْتُونَ الفاحشة } ثم وبخهم عليها فقال أنتم أول من عملها .  <br />
