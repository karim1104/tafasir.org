{ أَوَلَمْ يَهْدِ } يبين { لِلَّذِينَ يَرِثُونَ الأرض مِن بَعْدِ أَهْلِهَا أَن لَّوْ نَشَاء أصبناهم بِذُنُوبِهِمْ } { أَن لَّوْ نَشَاء } مرفوع بأنه فاعل { يَهْدِ } «وأن » مخففة من الثقيلة أي أولم يهدِ للذين يخلفون من خلا قبلهم في ديارهم ويرثونهم أرضهم هذا الشأن ،   وهو أنا لو نشاء أصبناهم بذنوبهم كما أصبنا من قبلهم فأهكلنا الوارثين كما أهلكنا الموروثين ،   وإنما عدي فعل الهداية باللام لأنه بمعنى التبيين { وَنَطْبَعُ } مسأنف أي ونحن نختم { على قُلُوبِهِمْ فَهُمْ لاَ يَسْمَعُونَ } الوعظ<br />
