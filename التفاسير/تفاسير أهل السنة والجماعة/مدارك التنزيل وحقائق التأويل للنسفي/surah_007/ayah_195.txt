ثم أبطل أن يكونوا عباداً أمثالهم فقال { أَلَهُمْ أَرْجُلٌ يَمْشُونَ بِهَا } مشيكم { أَمْ لَهُمْ أَيْدٍ يَبْطِشُونَ بِهَا } يتناولون بها { أَمْ لَهُمْ أَعْيُنٌ يُبْصِرُونَ بِهَا أَمْ لَهُمْ ءاذَانٌ يَسْمَعُونَ بِهَا } أي فلم تعبدون ما هو دونكم { قُلِ ادعوا شُرَكَاءكُمْ } واستعينوا بهم في عدواتي { ثُمَّ كِيدُونِ } جميعاً أنتم وشركاؤكم .   وبالياء : يعقوب وافقه أبو عمرو في الوصل { فَلاَ تُنظِرُونِ } فإني لا أبالي بكم وكانوا قد خافوه آلهتهم فأمر أن يخاطبهم بذلك .  <br />
