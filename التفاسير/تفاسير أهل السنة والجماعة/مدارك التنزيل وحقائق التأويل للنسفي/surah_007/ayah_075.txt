{ قَالَ الملأ الذين استكبروا مِن قَوْمِهِ } { وَقَالَ } شامي { لِلَّذِينَ استضعفوا } للذين استضعفهم رؤساء الكفار { لِمَنْ ءامَنَ مِنْهُمْ } بدل من { الذين استضعفوا } بإعادة الجار ،   وفيه دليل على أن البدل حيث جاء كان في تقدير إعادة العامل ،   والضمير في { مِنْهُمْ } راجع إلى قومه وهو يدل على أن استضعافهم كان مقصوراً على المؤمنين ،   أو إلى { الذين استضعفوا } وهو يدل على أن المستضعفين كانوا مؤمنين وكافرين { أَتَعْلَمُونَ أَنَّ صالحا مُّرْسَلٌ مّن رَّبّهِ } قالوه على سبيل السخرية { قَالُواْ إِنَّا بِمَا أُرْسِلَ بِهِ مُؤْمِنُونَ } وإنما صار هذا جواباً لهم لأنهم سألوهم عن العلم بإرساله أمراً معلوماً مسلماً كأنهم قالوا : العلم بإرساله وبما أرسل به لا شبهة فيه ،   وإنما الكلام في وجوب الإيمان به فنخبركم أنابه مؤمنون<br />
