{ وقطعناهم } وصيرناهم قطعاً أي فرقاً وميزنا بعضهم من بعض { اثنتي عشرة أسباطاً } كقولك اثنتي عشرة قبيلة ،   والأسباط أولاد الولد جمع سبط وكانوا اثنتي عشرة قبيلة من اثني عشر ولداً من ولد يعقوب عليه السلام .   نعم مميز ما عدا العشرة مفرد فكان ينبغي أن يقال اثني عشر سبطاً ،   لكن المراد وقطعناهم اثنتي عشرة قبيلة وكل قبيلة أسباط لا سبط فوضع «أسباط » موضع «قبيلة » { أمماً } بدل من { اثنتي عشرة } أي وقطعناهم أمماً لأن كل أسباط كانت أمة عظيمة وكل واحدة كانت تؤم خلاف ما تؤمه الأخرى { وأوحينآ إلى موسى إذ استسقاه قومه أن اضرب بّعصاك الحجر } فضرب { فانبجست } فانفجرت { منه اثنتا عشرة عيناً قد علم كلّ أناسٍ مّشربهم } هو اسم جمع غير تكسير { وظلّلنا عليهم الغمام } وجعلناه ظليلاً عليهم في التيه { وأنزلنا عليهم المنّ والسلوى } وقلنا لهم { كلوا من طيّبات ما رزقناكم وما ظلمونا } أي وما رجع إلينا ضرر ظلمهم بكفرانهم النعم { ولكن كانوآ أنفسهم يظلمون } ولكن كانوا يضرون أنفسهم ويرجع وبال ظلمهم إليهم .  <br />
