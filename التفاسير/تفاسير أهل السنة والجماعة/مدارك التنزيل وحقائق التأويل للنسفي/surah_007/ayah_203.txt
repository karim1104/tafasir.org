{ وَإِذَا لَمْ تَأْتِهِم بِئَايَةٍ } مقترحة { قَالُواْ لَوْلاَ اجتبيتها } هلا اخترتها أي اختلقتها كما اختلقت ما قبلها { قُلْ إِنَّمَا أَتَّبِعُ مَا يِوحَى إِلَىَّ مِن رَّبّى } ولست بمقترح لها { هذا بَصَائِرُ مِن رَّبّكُمْ } هذا القرآن دلائل تبصركم وجوه الحق { وَهُدًى وَرَحْمَةً لّقَوْمٍ يُؤْمِنُونَ } به .  <br />
