{ وَمَن كَفَرَ } ولم يسلم وجهه لله { فَلاَ يَحْزُنكَ كُفْرُهُ } من حزن ،   { يُحزِنك } نافع من أحزن أي لا يهمنك كفر من كفر { إِلَيْنَا مَرْجِعُهُمْ فَنُنَبّئُهُم بِمَا عَمِلُواْ } فنعاقبهم على أعمالهم { إِنَّ الله عَلِيمٌ بِذَاتِ الصدور } إن الله يعلم ما في صدور عباده فيفعل بهم على حسبه<br />
