{ أَلَمْ تَرَ أَنَّ الله يُولِجُ اليل فِى النهار } يدخل ظلمة الليل في ضوء النهار إذا أقبل الليل { وَيُولِجُ النهار فِى اليل وَسَخَّرَ الشمس والقمر } لمنافع العباد { كُلٌّ } أي كل واحد من الشمس والقمر { يَجْرِى } في فلكه ويقطعه { إلى أَجَلٍ مُّسَمًّى } إلى يوم القيامة أو إلى وقت معلوم الشمس إلى آخر السنة والقمر إلى آخر الشهر { وَأَنَّ الله بِمَا تَعْمَلُونَ خَبِيرٌ } وبالياء : عياش .   دل أيضاً بتعاقب الليل والنهار وزيادتهما ونقصانهما وجرى النيرين في فلكيهما على تقدير وحساب وبإحاطته بجميع أعمال الخلق على عظم قدرته وكمال حكمته<br />
