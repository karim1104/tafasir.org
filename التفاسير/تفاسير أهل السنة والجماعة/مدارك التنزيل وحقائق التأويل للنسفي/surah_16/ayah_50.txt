خائفين { مِّن فَوْقِهِمْ } إن علقته ب { يخافون } فمعناه يخافونه أن يرسل عليهم عذاباً من فوقهم ،   وإن علقته ب { ربهم } حالاً منه فمعناه يخافون ربهم غالباً لهم قاهراً كقوله { وَهُوَ القاهر فَوْقَ عِبَادِهِ } { [ الانعام : 61 ،   18 ] وَيَفْعَلُونَ مَا يُؤْمَرُونَ } وفيه دليل على أن الملائكة مكلفون مدارون على الأمر والنهي وأنهم بين الخوف والرجاء .
