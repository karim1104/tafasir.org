{ وَأَقْسَمُواْ بالله جَهْدَ أيمانهم } معطوف على { وقال الذي أشركوا } { لاَ يَبْعَثُ الله مَن يَمُوتُ بلى } هو إثبات لما بعد النفي أي بلى يبعثهم { وَعْدًا عَلَيْهِ حَقّا } وهو مصدر مؤكد لما دل عليه { بلى } لأن { يبعث } موعد من الله وبين أن الوفاء بهذا الوعد حق { ولكن أَكْثَرَ الناس لاَ يَعْلَمُونَ } أن وعده حق أو أنهم يبعثون<br />
