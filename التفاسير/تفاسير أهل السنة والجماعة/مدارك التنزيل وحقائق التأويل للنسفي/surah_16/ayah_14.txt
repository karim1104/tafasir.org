{ وَهُوَ الذى سَخَّرَ البحر لِتَأْكُلُواْ مِنْهُ لَحْمًا طَرِيّاً } هو السمك ،   ووصفه بالطراوة لأن الفساد ،   يسرع إليه فيؤكل سريعاً طرياً خيفة الفساد وإنما لا يحنث بأكله إذا حلف لا يأكل لحماً لأن مبني الإيمان على العرف .   ومن قال لغلامه : اشتر بهذه الدراهم لحماً ،   فجاء بالسمك كان حقيقاً بالإنكار { وَتَسْتَخْرِجُواْ مِنْهُ حِلْيَةً } هي اللؤلؤ والمرجان { تَلْبَسُونَهَا } المراد بلبسهم لبس نسائهم ولكنهن إنما يتزين بها من أجلهم فكأنها زينتهم ولباسهم .   { وَتَرَى الفلك مَوَاخِرَ } جواري تجري جرياً وتشق الماء شقاً والمخرشق الماء بحيزومها { فِيهِ } في البحر { وَلِتَبْتَغوُا مِن فَضْلِهِ } هو عطف على محذوف أي لتعتبروا ولتبتغوا وابتغاء الفضل التجارة { وَلَعَلَّكُمْ تَشْكُرُونَ } الله على ما أنعم عليكم به<br />
