{ وَإِنّى كُلَّمَا دَعَوْتُهُمْ } إلى الإيمان بك { لِتَغْفِرَ لَهُمْ } أي ليؤمنوا فتغفر لهم فاكتفى بذكر المسبب { جَعَلُواْ أصابعهم فِى * ءاذَانِهِمْ } سدوا مسامعهم لئلا يسمعوا كلامي { واستغشوا ثِيَابَهُمْ } وتغطوا بثيابهم لئلا يبصرون كراهة النظر إلى وجه من ينصحهم في دين الله { وَأَصَرُّواْ } وأقاموا على كفرهم { واستكبروا استكبارا } وتعظموا عن إجابتي ،   وذكر المصدر دليل على فرط استكبارهم .  <br />
