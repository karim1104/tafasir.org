{ فَلْيَأْتُواْ بِحَدِيثٍ } مختلق { مّثْلِهِ } مثل القرآن { إِن كَانُواْ صادقين } في أن محمداً تقوله من تلقاء نفسه لأنه بلسانهم وهم فصحاء { أم خُلِقُواْ } أم أحدثوا وقدروا التقدير الذي عليه فطرتهم { مِنْ غَيْرِ شَىْءٍ } من غير مقدر { أَمْ هُمُ الخالقون } أم هم الذين خلقوا أنفسهم حيث لا يعبدون الخالق .  <br />
