{ وَإِن تَعْجَبْ } يا محمد من قولهم في إنكار البعث { فَعَجَبٌ قَوْلُهُمْ } خبر ومبتدأ أي فقولهم حقيق بأن يتعجب منه لأن من قدر على إنشاء ما عدد عليك كان الإعادة أهون شيء عليه وأيسره فكان إنكارهم أعجوبة من الأعاجيب { أءِذا كنا تراباً أءِنا لَفِي خَلْقٍ جَدِيدٍ } في محل الرفع بدل من { قولهم } .   قرأ عاصم وحمزة كل واحد بهمزتين { أولئك الَّذِينَ كَفَرُواْ بِرَبِّهِمْ } أولئك الكافرون المتمادون في كفرهم { وأولئك الأغلال فِي أعناقهم } وصف لهم بالإصرار أو من جملة الوعيد { وأولئك أصحاب النار هُمْ فِيهَا خالدون } دل تكرار أولئك على تعظيم الأمر .  <br />
