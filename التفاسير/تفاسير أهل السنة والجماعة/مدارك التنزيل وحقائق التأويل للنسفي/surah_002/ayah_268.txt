{ الشيطان يَعِدُكُمُ } في الإنفاق { الفقر } ويقول لكم إن عاقبة إنفاقكم أن تفتقروا ،   والوعد يستعمل في الخير والشر { وَيَأْمُرُكُم بالفحشاء } ويغريكم على البخل ومنع الصدقات إغراء الآمر للمأمور والفاحش عند العرب البخيل { والله يَعِدُكُم } في الإنفاق { مَّغْفِرَةً مّنْهُ } لذنوبكم وكفارة لها { وَفَضْلاً } وأن يخلف عليكم أفضل مما أنفقتم ،   أو وثواباً عليه في الآخرة { والله واسع } يوسع على من يشاء { عَلِيمٌ } بأفعالكم ونياتكم .  <br />
