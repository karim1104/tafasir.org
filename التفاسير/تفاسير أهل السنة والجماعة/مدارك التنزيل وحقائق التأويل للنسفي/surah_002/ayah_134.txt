{ تِلْكَ } إشارة إلى الأمة المذكورة التي هي إبراهيم ويعقوب وبنوهما الموحدون { أُمَّةٌ قَدْ خَلَتْ } مضت { لَهَا مَا كَسَبَتْ وَلَكُم مَّا كَسَبْتُم } أي إن أحداً لا ينفعه كسب غيره متقدماً كان أو متأخراً ،   فكما أن أولئك لا ينفعهم إلا ما اكتسبوا فكذلك أنتم لا ينفعكم إلا ما اكتسبتم وذلك لافتخارهم بآبائهم { وَلاَ تُسْئَلُونَ عَمَّا كَانُوا يَعْمَلُونَ } ولا تؤاخذون بسيئاتهم .  <br />
