{ رَبَّنَا وابعث فِيهِمْ } في الأمة المسلمة { رَسُولاً مِّنْهُمْ } من أنفسهم فبعث الله فيهم محمداً عليه السلام ،   قال عليه السلام  "  أنا دعوة أبي إبراهيم وبشرى عيسى ورؤيا أمي  "  { يَتْلُواْ عَلَيْهِمْ آياتك } يقرأ عليهم ويبلغهم ما توحي إليه من دلائل وحدانيتك وصدق أنبيائك ورسلك { وَيُعَلّمُهُمُ الكتاب } القرآن { والحكمة } السنة وفهم القرآن { وَيُزَكّيهِمْ } ويطهرهم من الشرك وسائر الأرجاس { إِنَّكَ أَنتَ العزيز } الغالب الذي لا يغلب { الحكيم } فيما أوليت .  <br />
