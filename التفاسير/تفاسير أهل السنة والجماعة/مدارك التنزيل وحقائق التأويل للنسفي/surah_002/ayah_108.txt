{ أَمْ تُرِيدُونَ } «أم » منقطعة وتقديره بل أتريدون { أَن تَسْئَلُواْ رَسُولَكُمْ كَمَا سُئِلَ موسى مِن قَبْلُ } روي أن قريشاً قالوا : يا محمد اجعل لنا الصفا ذهباً ووسع لنا أرض مكة فنهوا أن يقترحوا عليه الآيات كما اقترح قوم موسى عليه حين قالوا اجعل لنا إلهاً .   { وَمَن يَتَبَدَّلِ الكفر بالإيمان } ومن ترك الثقة بالآيات المنزلة وشك فيها واقترح غيرها { فَقَدْ ضَلَّ سَوَاء السبيل } قصده ووسطه .  <br />
