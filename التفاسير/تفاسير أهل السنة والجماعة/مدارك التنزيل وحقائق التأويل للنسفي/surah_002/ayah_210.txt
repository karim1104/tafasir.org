{ هَلْ يَنظُرُونَ } ما ينتظرون { إِلاَّ أَن يَأْتِيَهُمُ الله } أي أمر الله وبأسه كقوله : { أَوْ يَأْتِىَ أَمْرُ رَبّكَ } [ النحل : 33 ] .   { فَجَاءهَا بَأْسُنَا } [ الأعراف : 4 ] أو المأتي به محذوف بمعنى أن يأتيهم الله ببأسه للدلالة عليه بقوله : «فاعلموا أن الله عزيز » { فِي ظُلَلٍ } جمع ظلة وهي ما أظلك { مِّنَ الغمام } الحساب .   وهو للتهويل إذ الغمام مظنة الرحمة أنزل منه العذاب كان الأمر أفظع وأهول { والملائكة } أي وتأتي الملائكة الذين وكلوا بتعذيبهم أو المراد حضورهم يوم القيامة { وَقُضِىَ الأمر } أي وتم أمر إهلاكهم وفرغ منه { وَإِلَى الله تُرْجَعُ الأمور } أي أنه ملّك العباد بعض الأمور فترجع إليه الأمور يوم النشور .   «ترجع الأمور » حيث كان : شامي وحمزة وعلي .
