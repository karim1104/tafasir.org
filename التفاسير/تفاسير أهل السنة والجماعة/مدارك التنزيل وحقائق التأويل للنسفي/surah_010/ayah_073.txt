{ فَكَذَّبُوهُ } فداموا على تكذيبه { فنجيناه } من الغرق { وَمَن مَّعَهُ فِى الفلك } في السفينة { وَجَعَلْنَاهُمْ خَلاَئِفَ } يخلفون الهالكين بالغرق { وَأَغْرَقْنَا الذين كَذَّبُواْ بآياتنا فانظر كَيْفَ كَانَ عَاقِبَةُ المنذرين } هو تعظيم لما جرى عليهم وتحذير لمن أنذرهم رسول الله صلى الله عليه وسلم عن مثله وتسلية له .  <br />
