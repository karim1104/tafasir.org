فَلَمَّا أَلْقُواْ قَالَ موسى مَا جِئْتُمْ بِهِ السحر } «ما » موصولة واقعة مبتدأ ،   أو { جئتم به } صلتها و { السحر } خبر أي الذي جئتم به هو السحر لا الذي سماه فرعون وقومه سحراً من آيات الله .   { آلسحر } بعد وقف : أبو عمرو على الاستفهام ،   فعلى هذه القراءة «ما » استفهامية أيْ أيّ شيء جئتم به أهو السحر { إِنَّ الله سَيُبْطِلُهُ } يظهر بطلانه { إِنَّ الله لاَ يُصْلِحُ عَمَلَ المفسدين } لايثبته بل يدمره<br />
