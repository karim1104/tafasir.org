{ وَيَوْمَ نَحْشُرُهُمْ } أي الكفار وغيرهم { جَمِيعاً } حال { ثُمَّ نَقُولُ لِلَّذِينَ أَشْرَكُواْ مَكَانَكُمْ } أي الزموا مكانكم لا تبرحوا حتى تنظروا ما يفعل بكم { أَنتُمْ } أكد به الضمير في { مكانكم } لسده مسد قوله الزموا { وَشُرَكَاؤُكُمْ } عطف عليه { فَزَيَّلْنَا } ففرَّقنا { بَيْنَهُمْ } وقطعنا أقرانهم والوصل التي كانت بينهم في الدنيا { وَقَالَ شُرَكَاؤُهُمْ } من عبدوه من دون الله من أولي العقل أو الأصنام ينطقها الله عز وجل { مَّا كُنتُمْ إِيَّانَا تَعْبُدُونَ } إنما كنتم تعبدون الشياطين حيث أمروكم أن تتخذوا الله أنداداً فأطعتموهم وهو قوله : { وَيَوْمَ نَحْشُرُهُمْ جَمِيعاً ثُمَّ نَقُولُ للملائكة أَهَؤُلاَء إِيَّاكُمْ } إلى قوله : { بَلْ كَانُواْ يَعْبُدُونَ الجن ) } سبأ : 41 )
