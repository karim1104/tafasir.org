{ وَكُلَّ إنسَانٍ أَلْزَمْنَاهُ طَائِرَهُ } عمله { فِي عُنُقِهِ } يعني أن عمله لازم له لزوم القلادة أو الغل للعنق لا يفك عنه { وَنُخْرِجُ لَهُ يَوْمَ الْقِيَامَةِ كِتَاباً يَلْقَاهُ } هو صفة ل { كتابا } ً .  <br />
يُلقَّاه شامي { مَنْشوراً } حال من { يلقاه } يعني غير مطوي ليمكنه قراءته أو هما صفتان للكتاب <br />
