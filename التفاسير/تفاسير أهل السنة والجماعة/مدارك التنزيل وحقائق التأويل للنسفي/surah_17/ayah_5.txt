{ فَإِذَا جَآءَ وَعْدُ أُولاهُمَا } أي وعد الله عقاب أولاهما { بَعَثْنَا عَلَيْكُمْ } سلطنا عليكم { عِبَاداً لَّنَا أُوْلِي بَأْسٍ شَدِيدِ } أشداء في القتال يعني سنجاريب وجنوده أو بختنصر أو جالوت ،   قتلوا علماءهم وأحرقوا التوراة وخربوا المسجد وسبوا منهم سبعين ألفاً { فَجَاسُوا خِلالَ الدِّيَارِ } ترددوا للغارة فيها .   قال الزجاج : الجوس طلب الشيء بالاستقصاء { وَكَانَ وَعْداً مَّفْعُولاً } وكان وعد العقاب وعداً لا بد أن يفعل<br />
