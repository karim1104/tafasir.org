{ رَّبُّكُمْ أَعْلَمُ بِكُمْ إِن يَشَأْ يَرْحَمْكُمْ } بالهداية والتوفيق { أَوْ إِن يَشَأْ يُعَذّبْكُمْ } بالخذلان أي يقولوا لهم هذه الكلمة ونحوها ولا يقولوا لهم إنكم من أهل النار وإنكم معذبون وما أشبه ذلك مما يغيظهم ويهيجهم على الشر .   قوله : { إن الشيطان ينزع بينهم } .   اعتراض { وَمَا أرسلناك عَلَيْهِمْ وَكِيلاً } حافظاً لأعمالهم وموكولاً إليك أمرهم وإنما أرسلناك بشيراً ونذيراً فدارهم ومر أصحابك بالمداراة<br />
