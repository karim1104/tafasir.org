{ وَمَا مَنَعَ النَّاسَ } يعني أهل مكة ،   ومحل { أَن يُؤْمِنُوا } نصب بأنه مفعول ثان ل { منع } { إِذْ جَآءَهُمُ الهدى } النبي والقرآن { إِلاَّ أَن قَالُوا } فاعل { منع } والتقدير : وما منعهم الإيمان بالقرآن وبنبوة محمد صلى الله عليه وسلم إلا قولهم { أَبَعَثَ اللَّهُ بَشَراً رَّسُولاً } أي إلا شبهة تمكنت في صدورهم وهي إنكارهم أن يرسل الله البشر ،   والهمزة في { أبعث الله } للإنكار وما أنكروه ففي قضية حكمته منكر .  <br />
