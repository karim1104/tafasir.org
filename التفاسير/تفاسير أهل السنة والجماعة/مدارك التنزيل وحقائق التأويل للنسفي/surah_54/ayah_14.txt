{ تَجْرِى بِأَعْيُنِنَا } بمرأى منا أو بحفظنا أو { بِأَعْيُنِنَا } حال من الضمير في { تَجْرِى } أي محفوظة بنا { جَزَاء } مفعول له لما قدم من فتح أبواب السماء وما بعده أي فعلنا ذلك جزاء { لّمَن كَانَ كُفِرَ } وهو نوح عليه السلام وجعله مكفوراً لأن النبي نعمة من الله ورحمة قال الله تعالى : { وَمَا أرسلناك إِلاَّ رَحْمَةً للعالمين } [ الأنبياء : 107 ] فكان نوح نعمة مكفورة
