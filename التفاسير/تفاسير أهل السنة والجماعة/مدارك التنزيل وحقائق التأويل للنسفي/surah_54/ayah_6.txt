{ فَتَوَلَّ عَنْهُمْ } لعلمك أن الإنذار لا يغني فيهم .   نصب { يَوْمَ يَدْعُ الداع } ب { يُخْرِجُونَ } أو بإضمار اذكر .   { الداعى } ،   { إلى الداعى } سهل ويعقوب ومكي فيهما ،   وافق مدني وأبو عمرو في الوصل ،   ومن أسقط الياء اكتفى بالكسرة عنها .   وحذف الواو من { يَدْعُو } في الكتابة لمتابعة اللفظ ،   والداعي إسرافيل عليه السلام { إلى شَىْءٍ نُّكُرٍ } منكر فظيع تنكره النفوس لأنها لم تعهد بمثلة وهو هول يوم القيامة { نُّكُرٍ } بالتخفيف : مكي<br />
