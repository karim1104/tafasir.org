{ يَهْدِى إِلَى الرشد } يدعوا إلى الصواب أو إلى التوحيد والإيمان { فَآمَنا بِهِ } بالقرآن .   ولما كان الإيمان به إيماناً بالله وبوحدانيته وبراءة من الشرك قالوا { وَلَن نُّشرِكَ بِرَبّنَا أَحَداً } من خلقه ،   وجاز أن يكون الضمير في { بِهِ } لله تعالى لأن قوله { بِرَبّنَا } يفسره .  <br />
