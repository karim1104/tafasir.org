{ أَلَمْ تَرَ إِلَى الذين تَوَلَّوْاْ قَوْماً غَضِبَ الله عَلَيْهِم } كان المنافقون يتولون اليهود وهم الذين غضب الله عليهم في قوله { مَن لَّعَنَهُ الله وَغَضِبَ عَلَيْهِ } [ المائدة : 60 ] وينقلون إليهم أسرار المؤمنين { مَّا هُم مّنكُمْ } يا مسلمون { وَلاَ مِنْهُمْ } ولا من اليهود كقوله :{ مُّذَبْذَبِينَ بَيْنَ ذلك لاَ إلى هَؤُلاء وَلاَ إِلَى هَؤُلاء } [ النساء : 143 ] { وَيَحْلِفُونَ عَلَى الكذب } أي يقولون والله إنا لمسلمون لا منافقون { وَهُمْ يَعْلَمُونَ } أنهم كاذبون منافقون  .
