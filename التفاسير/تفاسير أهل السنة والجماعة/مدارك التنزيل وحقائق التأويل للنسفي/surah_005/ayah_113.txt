{ قَالُواْ نُرِيدُ أَن نَّأْكُلَ مِنْهَا } تبركاً { وَتَطْمَئِنَّ قُلُوبُنَا } ونزداد يقيناً كقول إبراهيم عليه السلام { ولكن لّيَطْمَئِنَّ قَلْبِي } [ البقرة : 260 ] { وَنَعْلَمَ أَن قَدْ صَدَقْتَنَا } أي نعلم صدقك عياناً كما علمناه استدلالاً { وَنَكُونَ عَلَيْهَا مِنَ الشاهدين } بما عاينا لمن بعدنا .
