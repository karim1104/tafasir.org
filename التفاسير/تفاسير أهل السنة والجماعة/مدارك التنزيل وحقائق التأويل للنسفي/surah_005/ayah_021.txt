{ يَاقَوْمِ ادْخُلُوا الأَرْضَ المُقَدَّسَةَ } أي المطهرة أو المباركة وهي أرض بيت المقدس أو الشام { الَّتِى كَتَبَ اللَّهُ لَكُمْ } قسمها لكم أو سماها أو كتب في اللوح المحفوظ أنها مساكن لكم { وَلاَ تَرْتَدُّوا على أدباركم } ولا ترجعوا على أعقابكم مدبرين منهزمين من خوف الجبابرة جبناً أو لا ترتدوا على أدباركم في دينكم { فَتَنقَلِبُواْ خاسرين } فترجعوا خاسرين ثواب الدنيا والآخرة .  <br />
