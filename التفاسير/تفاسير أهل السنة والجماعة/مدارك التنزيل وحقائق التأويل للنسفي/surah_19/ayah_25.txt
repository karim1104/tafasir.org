{ وَهْزِّي } حركي { إِلَيْكَ } إلى نفسك { بِجِذْعِ النخلة } قال أبو علي : الباء زائدة أي هزي جذع النخلة .  <br />
{ تساقط عَلَيْكِ } بإدغام التاء الأولى في الثانية : مكي ومدني وشامي وأبو عمرو وعلي وأبو بكر ،   والأصل تتساقط بإظهار التاءين { وتساقط } بفتح التاء والقاف وطرح التاء الثانية وتخفيف السين : حمزة .   و { يساقط } بفتح الياء والقاف وتشديد السين : يعقوب وسهل وحماد ونصير .   و { تساقط } حفص من المفاعلة .   و { تُسقِطْ } و { يُسقِطْ } وتَسقُطْ ويَسقُطْ التاء للنخلة والياء للجذع فهذه تسع قراءات { رُطَباً } تمييز أو مفعول به على حسب القراءة { جَنِيّاً } طرياً وقالوا : التمر للنفساء عادة من ذلك الوقت .   وقيل : ما للنفساء خير من الرطب ولا للمريض من العسل<br />
