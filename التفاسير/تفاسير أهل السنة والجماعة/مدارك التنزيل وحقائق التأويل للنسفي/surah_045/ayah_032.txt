{ وَإِذَا قِيلَ إِنَّ وعْدَ الله } بالجزاء { حَقٌّ والساعة } بالرفع عطف على محل «إن » واسمها .   { والساعة } : حمزة عطف على { وَعَدَ الله } { لاَ رَيْبَ فِيهَا قُلْتُم مَّا نَدْرِى مَا الساعة } أي شيء الساعة { إِن نَّظُنُّ إِلاَّ ظَنّاً } أصله نظن ظناً ومعناه إثبات الظن فحسب فأدخل حرف النفي والاستثناء ليفاد إثبات الظن مع نفي ما سواه ،   وزيد نفي ما سوى الظن توكيداً بقوله { وَمَا نَحْنُ بِمُسْتَيْقِنِينَ }<br />
