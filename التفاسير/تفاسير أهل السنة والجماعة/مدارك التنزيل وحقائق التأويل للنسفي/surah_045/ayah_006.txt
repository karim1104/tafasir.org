{ تِلْكَ } إشارة إلى الآيات المتقدمة أي تلك الآيات { ءايات الله } وقوله { نَتْلُوهَا } في محل الحال أي متلوة { عَلَيْكَ بالحق } والعامل ما دل عليه { تِلْكَ } من معنى الإشارة { فَبِأَىِّ حَدِيثٍ بَعْدَ الله وءاياته } أي بعد آيات الله كقولهم «أعجبني زيد وكرمه » يريدون أعجبني كرم زيد { يُؤْمِنُونَ } حجازي وأبو عمرو وسهل وحفص ،   وبالتاء غيرهم على تقدير قل يا محمد .  <br />
