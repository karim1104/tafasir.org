{ إِنَّمَا النجوى } بالإثم والعدوان { مِنَ الشيطان } من تزيينه { لِيَحْزُنَ } أي الشيطان وبضم الياء : نافع { الذين ءامَنُواْ وَلَيْسَ } الشيطان أو الحزن { بِضَارّهِمْ شَيْئاً إِلاَّ بِإِذْنِ الله } بعلمه وقضائه وقدره  ،  { وَعَلَى الله فَلْيَتَوَكَّلِ المؤمنون } أي يكلون أمرهم إلى الله ويستعيذون به من الشيطان .  <br />
