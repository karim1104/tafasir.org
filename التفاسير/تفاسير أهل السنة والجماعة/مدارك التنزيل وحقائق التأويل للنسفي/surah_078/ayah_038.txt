{ يومَ يقومُ } إن جعلته ظرفاً ل { لا يملكون } لا تقف على { خطاباً } وإن جعلته ظرفاً ل { لا يتكلمون } تقف { الرُّوحُ } جبريل عند الجمهور وقيل هو ملك عظيم ما خلق الله تعالى بعد العرش خلقاً أعظم منه { والملائكة صَفَّاً } حال أي مصطفين { لاّ يتكلّمون } أي الخلائق ثم خوفاً من { إلاّ من أذن له الرَّحمانُ } في الكلام أو الشفاعة { وقال صواباً } حقاً بأن قال المشفوع له لا إله إلا الله في الدنيا أو لا يؤذن إلا لمن يتكلم بالصواب في أمر الشفاعة .  <br />
