{ ياأيها الذين ءامَنُواْ لاَ تَتَّبِعُواْ خطوات الشيطان } أي آثاره ووساوسه بالإصغاء إلى الإفك والقول فيه { وَمَن يَتَّبِعْ خطوات الشيطان فَإِنَّهُ } فإن الشيطان { يَأْمُرُ بالفحشاء } ما أفرط قبحه { والمنكر } ما تنكره النفوس فتنفر عنه ولا ترتضيه { وَلَوْلاَ فَضْلُ الله عَلَيْكُمْ وَرَحْمَتُهُ مَا زَكَى مِنكُم مّنْ أَحَدٍ أَبَداً } ولولا أن الله تفضل عليكم بالتوبة الممحصة لما طهر منكم أحد آخر الدهر من دنس إثم الإفك { ولكن الله يُزَكّى مَن يَشَاء } يطهر التائبين بقبول توبتهم إذا محضوها { والله سَمِيعٌ } لقولهم { عَلِيمٌ } بضمائرهم وإخلاصهم<br />
