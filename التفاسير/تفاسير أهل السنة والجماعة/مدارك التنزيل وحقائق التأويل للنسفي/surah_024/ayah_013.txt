{ لَوْلاَ جَاءو عَلَيْهِ بِأَرْبَعَةِ شُهَدَاء } هلا جاؤوا على القذف لو كانوا صادقين بأربعة شهداء { فَإِذْ لَمْ يَأْتُواْ بِالشُّهَدَاء } الأربعة { فَأُوْلَئِكَ عِندَ الله } أي في حكمه وشريعته { هُمُ الكاذبون } أي القاذفون لأن الله تعالى جعل التفصلة بين الرمي الصادق والكاذب ثبوت الشهادة الشهود الأربعة وانتفاؤها ،   والذين رموا عائشة رضي الله عنها لم يكن لهم بينة على قولهم فكانوا كاذبين<br />
