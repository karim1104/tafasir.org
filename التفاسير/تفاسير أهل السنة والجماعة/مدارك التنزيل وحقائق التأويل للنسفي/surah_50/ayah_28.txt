{ قَالَ لاَ تَخْتَصِمُواْ } هو استئناف مثل قوله تعالى { قَالَ قرِينُهُ } كأن قائلاً قال : فماذا قال الله ؟ فقيل : قال لا تختصموا { لَدَىَّ وَقَدْ قَدَّمْتُ إِلَيْكُم بالوعيد } أي لا تختصموا في دار الجزاء وموقف الحساب فلا فائدة في اختصامكم ولا طائل تحته وقد أوعدتكم بعذابي على الطغيان في كتبي وعلى ألسنة رسلي فما تركت لكم حجة عليّ .   والباء في { بالوعيد } مزيدة كما في قوله { وَلاَ تُلْقُواْ بِأَيْدِيكُمْ } [ البقرة : 195 ] أو معدية على أن قدم مطاوع بمعنى تقدم
