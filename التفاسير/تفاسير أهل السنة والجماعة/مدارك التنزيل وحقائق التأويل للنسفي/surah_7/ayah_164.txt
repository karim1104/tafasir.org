{ وَإِذْ قَالَتِ } معطوف على { إِذْ يَعْدُونَ } وحكمه كحكمه في الإعراب { أُمَّةٌ مّنْهُمْ } جماعة من صلحاء القرية الذين أيسوا من وعظهم بعدما ركبوا الصعب والذلول في موعظتهم لآخرين لا يقلعون عن وعظهم { لِمَ تَعِظُونَ قَوْمًا الله مُهْلِكُهُمْ أَوْ مُعَذّبُهُمْ عَذَاباً شَدِيدًا } وإنما قالوا ذلك لعلمهم أن الوعظ لا ينفع فيهم { قَالُواْ مَعْذِرَةً إلى رَبّكُمْ } - معذرة - أي موعظتنا إبلاء عذر إلى الله لئلا ننسب في النهي عن المنكر إلى التفريط { مَعْذِرَةً } حفص على أنه مفعول له أي وعظناهم للمعذرة { وَلَعَلَّهُمْ يَتَّقُونَ } ولطمعنا في أن يتقوا .  <br />
