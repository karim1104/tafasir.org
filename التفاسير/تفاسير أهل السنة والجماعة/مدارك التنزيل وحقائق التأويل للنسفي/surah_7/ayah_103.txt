{ ثُمَّ بَعَثْنَا مِن بَعْدِهِم } الضمير للرسل في قوله { وَلَقَدْ جَاءتْهُمْ رُسُلُهُم } أو للأمم { موسى بئاياتنا } بالمعجزات الواضحات { إلى فِرْعَوْنَ وَمَلإِيِهِ فَظَلَمُواْ بِهَا } فكفروا بآياتنا ،   أجرى الظلم مجرى الكفر لأنهما من وادٍ واحد { إِنَّ الشرك لَظُلْمٌ عَظِيمٌ } [ لقمان : 13 ] أو فظلموا الناس بسببها حين آذوا من آمن ،   أو لأنه إذا وجب الإيمان بها فكفروا بدل الإيمان كان كفرهم بها ظلماً حيث وضعوا الكفر غير موضعه وهو موضع الإيمان { فانظر كَيْفَ كَانَ عاقبة المفسدين } حيث صاروا مغرقين
