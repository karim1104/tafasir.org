{ والبلد الطّيّب } الأرض الطيبة الترب { يخرج نباته بإذن ربّه } بتيسيره وهو موضع الحال كأنه قيل : يخرج نباتة حسناً وافياً لأنه واقع في مقابلة { نكدا } { والّذي خبث } صفة للبلد أي والبلد الخبيث { لا يخرجُ } أي نباته فحذف للاكتفاء { إلاّ نكداً } هو الذي لا خير فيه وهذا مثل لمن ينجع فيه الوعظ وهو المؤمن ولمن لا يؤثر فيه شيء من ذلك وهو الكافر ،   وهذا التمثيل واقع على أثر ذكر مثل المطر وإنزاله بالبلد الميت وإخراج الثمرات به على طريق الاستطراد { كذلك } مثل ذلك التصريف { نُصرّف الآيات } نرددها ونكررها { لقومٍ يشكرون } نعمة الله وهم المؤمنون ليتفكروا فيها ويعتبروا بها .  <br />
