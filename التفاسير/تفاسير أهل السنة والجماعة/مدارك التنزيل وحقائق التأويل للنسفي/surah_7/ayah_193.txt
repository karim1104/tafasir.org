{ وَإِن تَدْعُوهُمْ } وإن تدعوا هذه الأصنام { إِلَى الهدى } إلى ما هو هدى ورشاد أو إلى أن يهدوكم أي وإن تطلبوا منهم كما تطلبون من الله الخير والهدى { لاَ يَتَّبِعُوكُمْ } إلى مرادكم وطلبتكم ولا يجيبوكم كما يجيبكم الله .   { لاَ يَتَّبِعُوكُمْ } نافع { سَوَاء عَلَيْكُمْ أَدَعَوْتُمُوهُمْ أَمْ أَنتُمْ صامتون } عن دعائهم في أنه لا فلاح معهم ولا يجيبونكم ،   والعدول عن الجملة الفعلية إلى الاسمية لرؤوس الآي<br />
