{ إِنْ هِىَ } ما الأصنام { إِلاَّ أَسْمَاء } ليس تحتها في الحقيقة مسميات لأنكم تدعون الإلهية لما هو أبعد شيء منها وأشذ منافاة لها { سَمَّيْتُمُوهَا } أي سميتم بها يقال سميته زيداً وسميته بزيد { أَنتُمْ وَءابَاؤُكُمْ مَّا أَنزَلَ الله بِهَا مِن سلطان } حجة { إِن يَتَّبِعُونَ إِلاَّ الظن } إلا توهم أن ما هم عليه حق { وَمَا تَهْوَى الأنفس } وما تشتهيه أنفسهم { وَلَقَدْ جَاءهُم مّن رَّبّهِمُ الهدى } الرسول والكتاب فتركوه ولم يعملوا به<br />
