{ إِنَّ الله يَعْلَمُ مَا يَدْعُونَ } بالياء : بصري وعاصم ،   وبالتاء : غيرهما غير الأعشى والبرجمي .   و «ما » بمعنى «الذي » وهو مفعول { يعلم } ومفعول { يدعون } مضمر أي يدعونه يعني يعبدونه { مِن دُونِهِ مِن شَىْء } «من » في { من شيء } للتبيين { وَهُوَ العزيز } الغالب الذي لا شريك له { الحكيم } في ترك المعاجلة بالعقوبة ،   وفيه تجهيل لهم حيث عبدوا جماداً لا علم له ولا قدرة وتركوا عبادة القادر القاهر على كل شيء الحكيم الذي لا يفعل كل شيء إلا بحكمة وتدبير<br />
