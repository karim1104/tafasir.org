{ وَيَسْتَعْجِلُونَكَ بالعذاب } بقولهم { فَأَمْطِرْ عَلَيْنَا حِجَارَةً مّنَ السماء } [ الأنفال : 32 ] الآية .   { وَلَوْلاَ أَجَلٌ مُّسَمًّى } وهو يوم القيامة أو يوم بدر أو وقت فنائهم بآجالهم ،   والمعنى ولولا أجل قد سماه الله وبينه في اللوح لعذبهم والحكمة تقتضي تأخيره إلى ذلك الأجل المسمى { لَّجَاءهُمُ العذاب } عاجلاً { وَلَيَأْتِيَنَّهُمْ } العذاب عاجلاً أو ليأتينهم العذاب في الأجل المسمى { بَغْتَةً } فجأة { وَهُمْ لاَ يَشْعُرُونَ } بوقت مجيئه .
