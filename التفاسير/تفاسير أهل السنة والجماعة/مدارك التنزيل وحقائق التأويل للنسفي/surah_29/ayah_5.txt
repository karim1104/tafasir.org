{ مَن كَانَ يَرْجُو لِقَاء الله } أي يأمل ثوابه أو يخاف حسابه فالرجاء يحتملها { فَإِنَّ أَجَلَ الله } المضروب للثواب والعقاب { لأَتٍ } لا محالة فليبادر للعمل الصالح الذي يصدق رجاءه ويحقق أمله { وَهُوَ السميع } لما يقوله عباده { العليم } بما يفعلونه فلا يفوته شيء ما .   وقال الزجاج : و «من » للشرط ويرتفع بالابتداء وجواب الشرط { فإن أجل الله لات } كقولك «إن كان زيد في الدار فقد صدق الوعد »<br />
