{ فَئَامَنَ لَهُ } لإبراهيم عليه السلام { لُوطٌ } هو ابن أخي إبراهيم وهو أول من آمن له حين رأى النار لم تحرقه { وَقَالَ } إبراهيم { إِنّى مُهَاجِرٌ } من كوثى وهي من سواد الكوفة إلى حران ثم منها إلى فلسطين وهي من برية الشام ،   ومن ثم قالوا : لكل نبي هجرة ولإبراهيم هجرتان .   وكان معه في هجرته لوط وسارة وقد تزوجها إبراهيم { إلى رَبّى } إلى حيث أمرني ربي بالهجرة إليه { إِنَّهُ هُوَ العزيز } الذي يمنعني من أعدائي { الحكيم } الذي لا يأمرني إلا بما هو خير<br />
