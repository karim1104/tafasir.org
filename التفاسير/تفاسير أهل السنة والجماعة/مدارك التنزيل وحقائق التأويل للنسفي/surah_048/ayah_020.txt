{ وَعَدَكُمُ الله مَغَانِمَ كَثِيرَةً تَأْخُذُونَهَا } هي ما أصابوه مع النبي صلى الله عليه وسلم وبعده إلى يوم القيامة { فَعَجَّلَ لَكُمْ هذه } المغانم يعني مغانم خيبر { وَكَفَّ أَيْدِىَ الناس عَنْكُمْ } يعني أيدي أهل خيبر وحلفائهم من أسد وغطفان حين جاءوا لنصرتهم فقذف الله في قلوبهم الرعب فانصرفوا .  <br />
وقيل : أيدي أهل مكة بالصلح { وَلِتَكُونَ } هذه الكفة { ءَايَةً لِّلْمُؤْمِنِينَ } وعبرة يعرفون بها أنهم من الله عز وجل بمكان وأنه ضامن نصرتهم والفتح عليهم فعل ذلك { وَيَهْدِيَكُمْ صراطا مُّسْتَقِيماً } ويزيدكم بصيرة ويقيناً وثقة بفضل الله .  <br />
