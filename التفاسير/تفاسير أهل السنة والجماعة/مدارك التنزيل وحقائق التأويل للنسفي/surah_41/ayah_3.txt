{ كِتَابٌ } خبره { فُصِّلَتْ ءاياته } ميزت وجعلت تفاصيل في معانٍ مختلفة من أحكام وأمثال ومواعظ ووعد ووعيد وغير ذلك { قُرْءَاناً عَرَبِيّاً } نصب على الاختصاص والمدح أي أريد بهذا الكتاب المفصل قرآناً من صفته كيت وكيت ،   أو على الحال أي فصلت آياته في حال كونه قرآناً عربياً { لِّقَوْمٍ يَعْلَمُونَ } أي لقوم عرب يعلمون ما نزل عليهم من الآيات المفصلة المبينة بلسانهم العربي .   و { لِقَوْمٍ } يتعلق ب { تَنزِيل } أو ب { فُصّلَتْ } أي تنزيل من الله لأجلهم أو فصلت آياته لهم ،   والأظهر أن يكون صفته مثل ما قبله وما بعده أي قرآناً عربياً كائناً لقوم عرب<br />
