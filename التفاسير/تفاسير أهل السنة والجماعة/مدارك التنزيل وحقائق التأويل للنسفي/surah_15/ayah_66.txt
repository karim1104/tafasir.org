{ وَقَضَيْنَآ إِلَيْهِ ذَلِكَ الأمر } عدى { قضينا } ب «إلى » لأنه ضمن معنى أوحينا كأنه قيل : وأوحينا إليه مقضياً مبتوتاً ،   وفسر ذلك الأمر بقوله { أَنَّ دَابِرَ هَؤُلآْءِ مَقْطُوعٌ } وفي إبهامه وتفسيره تفخيم للأمر ودابرهم آخرهم أي يستأصلون عن آخرهم حتى لا يبقى منهم أحد { مُّصْبِحِينَ } وقت دخولهم في الصبح وهو حال من { هؤلاء }<br />
