{ مَا نُنَزِّلُ الملائكة } كوفي غير أبي بكر ،   { تُنَزَّل الملائكة } أبو بكر { تَنَزَّل الملائكة } أي تتنزل : غيرهم { إِلاَّ بالحق } إلا تنزيلاً ملتبساً بالحكمة { وَمَا كَانُواْ إِذًا مُّنظَرِينَ } { إذا } جواب لهم وجزاء الشرط مقدر تقديره : ولو نزلنا الملائكة ما كانوا منظرين إذاً وما أخر عذابهم<br />
