{ هَلْ أتى } قد مضى { عَلَى الإنسان } آدم عليه السلام { حِينٌ مّنَ الدهر } أربعون سنة مصوراً قبل نفخ الروح فيه { لَمْ يَكُن شَيْئاً مَّذْكُوراً } لم يذكر اسمه ولم يدر ما يراد به لأنه كان طيناً يمر به الزمان ولو غير موجود لم يوصف بأنه قد أتى عليه حين من الدهر .   ومحل { لَمْ يَكُن شَيْئاً مَّذْكُوراً } النصب على الحال من الإنسان أي أتى عليه حين من الدهر غير مذكور<br />
