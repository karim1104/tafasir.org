{ عاليهم } بالنصب على أنه حال من الضمير في { يَطُوفُ عَلَيْهِمْ } أي يطوف عليهم ولدان عالياً للمطوف عليهم ثياب .   وبالسكون : مدني وحمزة على أنه مبتدأ خبره { ثِيَابُ سُندُسٍ } أي ما يعلوهم من ملابسهم ثياب سندس رقيق الديباج .  <br />
{ خُضْرٌ } جمع أخضر { وَإِسْتَبْرَقٌ } غليظ يرفعهما حملاً على الثياب : نافع وحفص ،   وبجرهما : حمزة وعلي حملاً على { سُندُسٍ } وبرفع الأول وجر الثاني أو عكسه : غيرهم { وَحُلُّواْ } عطف على { وَيَطُوفُ } { أَسَاوِرَ مِن فِضَّةٍ } وفي سورة «الملائكة » : { يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ مِن ذَهَبٍ وَلُؤْلُؤاً } [ الحج : 23 ] .   قال ابن المسيب : لا أحد من أهل الجنة إلا وفي يده ثلاثة أسورة : واحدة من فضة وأخرى من ذهب وأخرى من لؤلؤ .   { وسقاهم رَبُّهُمْ } أضيف إليه تعالى للتشريف والتخصيص .   وقيل : إن الملائكة يعرضون عليهم الشراب فيأبون قبوله منهم ويقولون : لقد طال أخذنا من الوسائط فإذا هم بكاسات تلاقي أفواههم بغير أكف من غيب إلى عبد { شَرَاباً طَهُوراً } ليس برجس كخمر الدنيا لأن كونها رجساً بالشرع لا بالعقل ولا تكليف ثم ،   أو لأنه لم يعصر فتمسه الأيدي الوضرة وتدوسه الأقدام الدنسة يقال لأهل الجنة
