{ استجيبوا لِرَبِّكُمْ } أي أجيبوه إلى ما دعاكم إليه { مِّن قَبْلِ أَن يَأْتِىَ يَوْمٌ } أي يوم القيامة { لاَّ مَرَدَّ لَهُ مِنَ الله } «من » يتصل ب { لاَّ مَرَدَّ } أي لا يرده الله بعدما حكم به ،   أو ب { يَأْتِىَ } أي من قبل أن يأتي من الله يوم لا يقدر أحد على رده { مَا لَكُمْ مِّن مَّلْجَأٍ يَوْمَئِذٍ وَمَا لَكُمْ مِّن نَّكِيرٍ } أي ليس لكم مخلص من العذاب ولا تقدرون أن تنكروا شيئاً مما اقترفتموه ودوّن في صحائف أعمالكم ،   والنكير الإنكار<br />
