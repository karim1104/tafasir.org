{ وَإِذْ بَوَّأْنَا لإبراهيم مَكَانَ البيت } واذكر يا محمد حين جعلنا لإبراهيم مكان البيت مباءة أي مرجعاً يرجع إليه للعمارة والعبادة وقد رفع البيت إلى السماء أيام الطوفان وكان من ياقوتة حمراء ،   فأعلم الله إبراهيم مكانه بريح أرسلها فكنست مكان البيت فبناه على أسه القديم { أن } هي المفسرة للقول المقدر أي قائلين له { لاَّ تُشْرِكْ بِي شَيْئاً وَطَهّرْ بَيْتِىَ } من الأصنام والأقذار : وبفتح الياء : مدني وحفص { لِلطَّائِفِينَ } لمن يطوف به { والقائمين } والمقيمين بمكة { والركع السجود } المصلين جمع راكع وساجد .  <br />
