{ إِنَّ الله يُدَافِعُ } { يدفع } مكي وبصري وغيرهما يدافع أي يبالغ في الدفع عنهم { عَنِ الذين ءامَنُواْ } أي يدفع غائلة المشركين عن المؤمنين ونحوه { إِنَّا لَنَنصُرُ رُسُلَنَا والذين ءامَنُواْ } [ غافر : 51 ] ثم علل ذلك بقوله { إِنَّ الله لاَ يُحِبُّ كُلَّ خَوَّانٍ } في أمانة الله { كَفُورٌ } لنعمة الله أي لأنه لا يحب أضدادهم وهم الخونة الكفرة الذين يخونون الله والرسول ويخونون أماناتهم ويكفرون نعم الله ويغمطونها .
