{ هذان خَصْمَانِ } أي فريقان مختصمان ؛ فالخصم صفة وصف بها الفريق وقوله { اختصموا } للمعنى و { هذان } للفظ والمراد المؤمنون والكافرون .   وقال ابن عباس رضي الله عنهما : رجع إلى أهل الأديان المذكورة : فالمؤمنون خصم وسائر الخمسة خصم { فِى رَبّهِمْ } في دينه وصفاته ،   ثم بين جزاء كل خصم بقوله { فالذين كَفَرُواْ } وهو فصل الخصومة المعنى بقوله { إن الله يفصل بينهم يوم القيامة } { قُطّعَتْ لَهُمْ ثِيَابٌ مّن نَّارِ } كأن الله يقدر لهم نيراناً على مقادير جثتهم تشتمل عليهم كما تقطع الثياب الملبوسة ،   واختير لفظ الماضي لأنه كائن لا محالة فهو كالثابت المتحقق { يُصَبُّ مِن فَوْقِ رُؤُوسَهُمْ } بكسر الهاء والميم ،   بصري ،   وبضمهما : حمزة وعلي وخلف ،   وبكسر الهاء وضم الميم : غيرهم { الحميم } الماء الحار .   عن ابن عباس رضي الله عنهما : لو سقطت منه نقطة على جبال الدنيا لأذابتها .  <br />
