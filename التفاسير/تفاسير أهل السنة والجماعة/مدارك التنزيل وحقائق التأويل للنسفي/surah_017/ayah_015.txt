{ مَّنِ اهتدى فَإِنَّمَا يَهْتَدِي لِنَفْسِهِ وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } أي فلها ثواب الاهتداء وعليها وبال الضلال { وَلا تَزِرُ وَازِرَةٌ وِزْرَ أخرى } أي كل نفس حاملة وزراً فإنما تحمل وزرها لا وزر نفس أخرى { وَمَا وَكُنَّا مُعَذِّبِينَ حتى نَبْعَثَ رَسُولاً } وما صح منا أن نعذب قوماً عذاب استئصال في الدنيا إلا بعد أن نرسل إليهم رسولاً يلزمهم الحجة<br />
