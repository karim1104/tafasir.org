{ قَالَ اذهب } ليس من الذهاب الذي هو ضد المجيء وإنما معناه امض لشأنك الذي اخترته خذلاناً وتخلية .   ثم عقبه بذكر ما جره سوء اختياره فقال : { فَمَن تَبِعَكَ مِنْهُمْ فَإِنَّ جَهَنَّمَ جَزَاؤُكُمْ } والتقدير فإن جهنم جزاؤهم وجزاؤك ثم غلب المخاطب على الغائب فقيل { جزاؤكم } وانتصب { جَزَاء مَّوفُورًا } أي موفراً بإضمار تجازون<br />
