{ فَبِظُلْمٍ مّنَ الذين هَادُواْ حَرَّمْنَا عَلَيْهِمْ طيبات أُحِلَّتْ لَهُمْ } وهي ما ذكر في سورة الأنعام { وَعَلَى الذين هَادُواْ حَرَّمْنَا كُلَّ ذِى ظُفُرٍ } [ الأنعام : 146 ] الآية .   والمعنى ما حرمنا عليهم الطيبات إلا لظلم عظيم ارتكبوه وهو ما عدد قبل هذا { وَبِصَدّهِمْ عَن سَبِيلِ الله } وبمنعهم عن الإيمان { كَثِيراً } أي خلقاً كثيراً أو صداً كثيراً
