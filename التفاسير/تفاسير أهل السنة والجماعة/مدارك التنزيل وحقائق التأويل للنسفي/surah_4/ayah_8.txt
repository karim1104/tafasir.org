{ وإذا حضر القسمة } أي قسمة التركة { أولوا القربى } ممن لا يرث { واليتامى والمساكين } من الأجانب { فارزقوهم } فأعطوهم { مّنه } مما ترك الوالدان والأقربون وهو أمر ندب وهو باقٍ لم ينسخ .  <br />
وقيل : كان واجباً في الابتداء ثم نسخ بآية الميراث { وَقُولُواْ لَهُمْ قَوْلاً مَّعْرُوفاً } عذراً جميلاً وعدة حسنة ،   وقيل : القول المعروف أن يقولوا لهم : خذوا بارك الله عليكم ويستقلوا ما أعطوهم ولا يمنوا عليهم .  <br />
