{ وَمَن يَفْعَلْ ذلك } أي القتل أي ومن يقدم على قتل الأنفس { عدوانا وَظُلْماً } لا خطأ ولا قصاصاً وهما مصدران في موضع الحال أو مفعول لهما { فَسَوْفَ نُصْلِيهِ نَاراً } ندخله ناراً مخصوصة شديدة العذاب { وَكَانَ ذلك } أي إصلاؤه النار { عَلَى الله يَسِيراً } سهلاً وهذا الوعيد في حق المستحيل للتخليد ،   وفي حق غيره لبيان استحقاقه دخول النار مع وعد الله بمغفرته .  <br />
