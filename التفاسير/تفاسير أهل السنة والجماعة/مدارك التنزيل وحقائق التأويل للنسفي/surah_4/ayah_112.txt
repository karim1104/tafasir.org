{ وَمَن يَكْسِبْ خَطِيئَةً } صغيرة { أَوْ إِثْماً } أو كبيرة ،   أو الأول ذنب بينه وبين ربه ،   والثاني ذنب في مظالم العباد { ثُمَّ يَرْمِ بِهِ بَرِيئاً } كما رمى طعمة زيداً { فَقَدِ احتمل بهتانا } كذباً عظيماً { وَإِثْماً مُّبِيناً } ذنباً ظاهراً ،   وهذا لأنه بكسب الإثم آثم ويرمي البريء باهت فهو جامع بين الأمرين ،   والبهتان كذب يبهت من قيل عليه ما لا علم له به<br />
