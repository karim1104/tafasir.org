{ وَيَقُولُ الذين ءَامَنُواْ لَوْلاَ نُزِّلَتْ سُورَةٌ } فيها ذكر الجهاد { فَإِذَآ أُنزِلَتْ سُورَةٌ } في معنى الجهاد { مُّحْكَمَةٌ } مبينة غير متشابهة لا تحتمل وجهاً إلا وجوب القتال .   وعن قتادة : كل سورة فيها ذكر القتال فهي محكمة لأن النسخ لا يرد عليها من قبل أن القتال نسخ ما كان من الصفح والمهادنة وهو غير منسوخ إلى يوم القيامة { وَذُكِرَ فِيهَا القتال } أي أمر فيها بالجهاد { رَأَيْتَ الذين فِى قُلُوبِهِمْ مَّرَضٌ } نفاق أي رأيت المنافقين فيما بينهم يضجرون منها { يَنظُرُونَ إِلَيْكَ نَظَرَ المغشى عَلَيْهِ مِنَ الموت } أي تشخص أبصارهم جبناً وجزعاً كما ينظر من أصابته الغشية عند الموت { فأولى لَهُمْ } وعيد بمعنى فويل لهم وهو أفعل من الولى وهو القرب ومعناه الدعاء عليهم بأن يليهم المكروه<br />
