{ والذين يَجْتَنِبُونَ } عطف على { الذين آمَنُواْ } وكذا ما بعده { كبائر الإثم } أي الكبائر من هذا الجنس ،   { كَبِيرَ الإثم } علي وحمزة .   وعن ابن عباس : كبير الإثم هو الشرك .   { والفواحش } قيل : ما عظم قبحه فهو فاحشة كالزنا { وَإِذَا مَا غَضِبُواْ } من أمور دنياهم { هُمْ يَغْفِرُونَ } أي هم الأخصاء بالغفران في حال الغضب والمجيء بهم .   وإيقاعه مبتدأ وإسناد { يَغْفِرُونَ } إليه لهذه الفائدة ومثله { هُمْ يَنتَصِرُونَ } .  <br />
