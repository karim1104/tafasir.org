{ وَهُوَ الذى يُنَزِّلُ الغيث } بالتشديد : مدني وشامي وعاصم { مِن بَعْدِ مَا قَنَطُواْ } وقرىء { قِنطواْ } { وَيَنشُرُ رَحْمَتَهُ } أي بركات الغيث ومنافعه وما يحصل به من الخصب .   وقيل لعمر رضي الله عنه : اشتد القحط وقنط الناس .   فقال : مطروا إذا أراد هذه الآية .   أو أراد رحمته في كل شيء { وَهُوَ الولى } الذي يتولى عباده بإحسانه { الحميد } المحمود على ذلك يحمده أهل طاعته<br />
