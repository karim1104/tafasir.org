{ ينادونهم } أي ينادي المنافقون المؤمنين { أَلَمْ نَكُن مَّعَكُمْ } يريدون مرافقتهم في الظاهر { قَالُواْ } أي المؤمنون { بلى ولكنكم فَتَنتُمْ أَنفُسَكُمْ } محنتموها بالنفاق وأهلكتموها { وَتَرَبَّصْتُمْ } بالمؤمنين الدوائر { وارتبتم } وشككتم في التوحيد { وَغرَّتْكُمُ الأمانى } طول الآمال والطمع في امتداد الأعمار { حتى جَاء أَمْرُ الله } أي الموت { وَغَرَّكُم بالله الغرور } وغركم الشيطان بأن الله عفو كريم لا يعذبكم أو بأنه لا بعث ولا حساب .  <br />
