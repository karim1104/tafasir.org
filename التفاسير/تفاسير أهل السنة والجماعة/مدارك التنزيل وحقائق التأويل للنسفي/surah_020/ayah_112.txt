{ وَمَن يَعْمَلْ مِنَ الصالحات } الصالحات الطاعات { وَهُوَ مُؤْمِنٌ } مصدق بما جاء به محمد عليه السلام ،   وفيه دليل أنه يستحق اسم الإيمان بدون الأعمال الصالحة وأن الإيمان شرط قبولها { فَلاَ يَخَافُ } أي فهو لا يخاف { فَلاَ يخف } على النهي : مكي { ظُلْماً } أن يزداد في سيئاته { وَلاَ هَضْماً } ولا ينقص من حسناته وأصل الهضم النقص والكسر .  <br />
