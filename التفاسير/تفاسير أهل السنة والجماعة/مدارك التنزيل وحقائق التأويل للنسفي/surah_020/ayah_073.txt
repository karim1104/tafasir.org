{ إِنَاْ ءامَنَّا بِرَبّنَا لِيَغْفِرَ لَنَا خطايانا وَمَا أَكْرَهْتَنَا عَلَيْهِ } «ما » موصولة منصوبة بالعطف على { خطايانا } { مِنَ السحر } حال من «ما » ،   روي أنهم قالوا لفرعون : أرنا موسى نائماً ففعل فوجدوه تحرسه عصاه فقالوا : ما هذا بسحر الساحر إذا نام بطل سحره فكرهوا معارضته خوف الفضيحة فأكرههم فرعون على الإتيان بالسحر وضر فرعون جهله به ونفعهم علمهم بالسحر فكيف بعلم الشرع { والله خَيْرُ } ثواباً لمن أطاعه { وأبقى } عقاباً لمن عصاه وهو رد لقول فرعون { وَلَتَعْلَمُنَّ أَيُّنَا أَشَدُّ عَذَاباً وأبقى } .  <br />
