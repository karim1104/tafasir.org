{ فَأَخْرَجَ لَهُمْ } السامري من الحفرة { عِجْلاً } خلقه الله تعالى من الحلي التي سبكتها النار ابتلاء { جَسَداً } مجسداً { لَّهُ خُوَارٌ } صوت وكان يخور كما تخور العجاجيل { فَقَالُواْ } أي السامري وأتباعه { هذا إلهكم وإله موسى } فأجاب عامتهم إلا اثني عشر ألفاً { فَنَسِىَ } أي فنسي موسى ربه هنا وذهب يطلبه عند الطور ،   أو هو ابتداء كلام من الله تعالى أي نسي السامري ربه وترك ما كان عليه من الإيمان الظاهر ،   أو نسي السامري الاستدلال على أن العجل لا يكون إلهاً بدليل قوله { أَفَلاَ يَرَوْنَ أَلاَّ يَرْجِعُ }<br />
