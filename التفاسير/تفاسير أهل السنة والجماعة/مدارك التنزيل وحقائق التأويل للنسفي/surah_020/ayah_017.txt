{ وَمَا تِلْكَ بِيَمِينِكَ ياموسى } «ما » مبتدأ و { تِلْكَ } خبره وهي بمعنى هذه و { بِيَمِينِكَ } حال عمل فيها معنى الإشارة أي قارة أو مأخوذة بيمينك .   أو { تِلْكَ } موصول صلته { بِيَمِينِكَ } والسؤال للتنبيه لتقع المعجزة بها بعد التثبت ،   أو للتوطين لئلا يهوله انقلابها حية ،   أو للإيناس ورفع الهيبة للمكالمة .  <br />
