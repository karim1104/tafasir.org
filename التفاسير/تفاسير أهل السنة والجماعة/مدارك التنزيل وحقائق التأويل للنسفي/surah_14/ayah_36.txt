{ رَبِّ إِنَّهُنَّ أَضْلَلْنَ كَثِيرًا مّنَ الناس } جعلن مضلات على طريق التسبيب لأن الناس ضلوا بسببهن فكأنهم أضللنهم { فَمَن تَبِعَنِي } على ملتي وكان حنيفاً مسلماً مثلي { فَإِنَّهُ مِنّي } أي هو بعضي لفرط اختصاصه بي { وَمَنْ عَصَانِى } فيما دون الشرك { فَإِنَّكَ غَفُورٌ رَّحِيمٌ } أو ومن عصاني عصيان شرك فإنك غفور رحيم إن تاب وآمن<br />
