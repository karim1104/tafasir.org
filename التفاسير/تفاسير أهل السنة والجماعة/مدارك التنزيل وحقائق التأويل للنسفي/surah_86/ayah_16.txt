{ وَأَكِيدُ كَيْداً } وأجازيهم جزاء كيدهم باستدراجي لهم من حيث لا يعلمون فسمي جزاء الكيد كيداً كما سمي جزاء الاعتداء والسيئة اعتداء وسيئة وإن لم يكن اعتداء وسيئة ،   ولا يجوز إطلاق هذا الوصف على الله تعالى إلا على وجه الجزاء كقوله : { نَسُواْ الله فَنَسِيَهُمْ } [ التوبة : 67 ] { يخادعون الله وَهُوَ خَادِعُهُمْ } [ النساء : 142 ] { الله يَسْتَهْزِىء بِهِمْ } [ البقرة : 15 ]
