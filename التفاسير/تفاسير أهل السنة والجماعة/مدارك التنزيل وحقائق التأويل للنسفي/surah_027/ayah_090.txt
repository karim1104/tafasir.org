{ وَمَن جَاء بالسيئة } بالشرك { فَكُبَّتْ } ألقيت { وُجُوهُهْم فِى النار } يقال كببت الرجل ألقيته على وجهه أي ألقوا على رؤوسهم في النار ،   أو عبر عن الجملة بالوجه كما يعبر بالرأس والرقبة عنها أي ألقوا في النار ويقال لهم تبكيتاً عند الكب { هَلْ تُجْزَوْنَ إِلاَّ مَا كُنتُمْ تَعْمَلُونَ } في الدنيا من الشرك والمعاصي<br />
