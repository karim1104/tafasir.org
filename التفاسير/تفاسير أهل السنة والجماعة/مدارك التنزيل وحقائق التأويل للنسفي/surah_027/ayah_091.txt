{ إِنَّمَا أُمِرْتُ أَنْ أَعْبُدَ رَبّ هَذِهِ البلدة } مكة { الذى حَرَّمَهَا } جعلها حرماً آمناً يأمن فيها اللاجيء إليها ولا يختلي خلاها ولا يعضد شوكها ولا ينفر صيدها { وَلَهُ كُلُّ شَىء } مع هذه البلدة فهو مالك الدنيا والآخرة { وَأُمِرْتُ أَنْ أَكُونَ مِنَ المسلمين } المنقادين له .  <br />
