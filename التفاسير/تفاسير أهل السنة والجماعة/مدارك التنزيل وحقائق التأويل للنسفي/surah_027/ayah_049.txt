{ قَالُواْ تَقَاسَمُواْ بالله } { تحالفوا } خبر في محل الحال بإضمار «قد » أي قالوا متقاسمين أو أمر أي أمر بعضهم بعضاً بالقسم { لَنُبَيّتَنَّهُ } لنقتلنه بياتاً أي ليلاً { وَأَهْلَهُ } ولده وتبعه { ثُمَّ لَنَقُولَنَّ لِوَلِيّهِ } لولي دمه { لتبيتنه } بالتاء وبضم التاء الثانية ثم { لتقولن } بالتاء وضم اللام : حمزة وعلي { ماشهدنا } ما حضرنا { مَهْلِكَ أَهْلِهِ } حفص { مهلَك } أبو بكر وحماد والمفضل من هلك ،   فالأول موضع الهلاك ،   والثاني المصدر { مُهلَك غيرهم ،   من أهلك وهو الإهلاك أو مكان الإهلاك أي لم نتعرض لأهله فكيف تعرضنا له ؟ أو ما حضرنا موضع هلاكه فكيف توليناه ؟ { وِإِنَّا لصادقون } فيما ذكرنا .  <br />
