{ كَلاَّ } [ مريم : 77 ] ردع له وقطع لرجائه أي لا يجمع له بعد اليوم بين الكفر والمزيد من النعم ،   فلم يزل بعد نزول الآية في نقصان من المال والجاه حتى هلك { إِنَّهُ كان لآياتنا } للقرآن { عَنِيداً } معانداً جاحداً وهو تعليل للردع على وجه الاستئناف كأن قائلاً قال : لم لا يزاد ؟ فقيل : إنه جحد آيات المنعم وكفر بذلك نعمته والكافر لا يستحق المزيد
