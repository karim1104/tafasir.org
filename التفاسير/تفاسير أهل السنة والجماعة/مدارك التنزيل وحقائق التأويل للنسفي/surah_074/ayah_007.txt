{ وَلِرَبِّكَ فاصبر } ولوجه الله فاستعمل الصبر على أوامره ونواهيه وكل مصبور عليه ومصبور عنه { فَإِذَا نُقِرَ فِى الناقور } نفخ في الصور وهي النفخة الأولى وقيل الثانية { فذلك } إشارة إلى وقت النقر وهو مبتدأ { يَوْمَئِذٍ } مرفوع المحل بدل من { ذلك } { يَوْمٌ عَسِيرٌ } خبر كأنه قيل : فيوم النقر يوم عسير .  <br />
