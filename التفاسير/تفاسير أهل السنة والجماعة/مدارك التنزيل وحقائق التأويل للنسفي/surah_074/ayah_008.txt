والفاء في { فَإِذَا } للتسبيب وفي { فَذَلِكَ } للجزاء كأنه قيل : اصبر على أذاهم فبين أيديهم يوم عسير يلقون فيه عاقبة أذاهم وتلقى عاقبة صبرك عليه .   والعامل في { فَإِذَا } ما دل عليه الجزاء أي فإذا نقر في الناقور عسر الأمر { عَلَى الكافرين غَيْرُ يَسِيرٍ } وأكد بقوله { غَيْرُ يَسِيرٍ } ليؤذن بأنه يسير على المؤمنين أو عسير لا يرجى أن يرجع يسيراً كما يرجى تيسير العسير من أمور الدنيا .  <br />
