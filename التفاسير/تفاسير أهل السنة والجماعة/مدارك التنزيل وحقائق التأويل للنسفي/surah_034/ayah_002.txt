{ يَعْلَمْ } مستأنف { مَا يَلْجُ } ما يدخل { فِى الأرض } من الأموات والدفائن { وَمَا يَخْرُجُ مِنْهَا } من النبات وجواهر المعادن { وَمَا يَنزِلُ مِنَ السماء } من الأمطار وأنواع البركات { وَمَا يَعْرُجُ فِيهَا } يصعد إليها من الملائكة والدعوات { وَهُوَ الرحيم } بإنزال ما يحتاجون إليه { الغفور } لما يجترئون عليه .  <br />
