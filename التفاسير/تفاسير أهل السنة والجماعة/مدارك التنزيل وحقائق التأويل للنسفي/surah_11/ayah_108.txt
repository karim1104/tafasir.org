{ وَأَمَّا الذين سُعِدُواْ } { سُعدوا } حمزة وعلي وحفص .   سَعد لازم وسعَده يسعَده متعد { فَفِى الجنة خالدين فِيهَا مَا دَامَتِ السماوات والأرض إِلاَّ مَا شَاء رَبُّكَ } هو استثناء من الخلود في نعيم الجنة وذلك أن لهم سوى الجنة ما هو أكبر منها وهو رؤية الله تعالى ورضوانه ،   أو معناه إلا من شاء أن يعذبه بقدر ذنبه قبل أن يدخله الجنة .   وعن أبي هريرة رضي الله عنه عن النبي صلى الله عليه وسلم أنه قال : « الاستثناء في الآيتين لأهل الجنة  » ومعناه ما ذكرنا أنه لا يكون للمسلم العاصي الذي دخل النار خلود في النار حيث يخرج منها ،   ولا يكون له أيضاً خلود في الجنة لأنه لم يدخل الجنة ابتداء ،   والمعتزلة لما لم يروا خروج العصاة من النار ردوا الأحاديث المروية في هذا الباب { وكفى به إثماً مبيناً } [ النساء : 50 ] { عَطَاء غَيْرَ مَجْذُوذٍ } غير مقطوع ولكنه ممتد إلى غير نهاية كقوله : { لَهُمْ أَجْرٌ غَيْرُ مَمْنُونٍ } [ الإنشقاق : 25 ] وهو نصب على المصدر أي أعطوا عطاء .   قيل : كفرت الجهمية بأربع آيات { عَطَاء غَيْرَ مَجْذُوذٍ } .   { أُكُلُهَا دَائِمٌ } [ الرعد : 35 ] { وَمَا عِندَ الله بَاقٍ } [ النحل : 96 ] { لاَّ مَقْطُوعَةٍ وَلاَ مَمْنُوعَةٍ } [ الواقعة : 33 ]
