{ وإلى مَدْيَنَ أخاهم شُعَيْباً } هو اسم مدينتهم أو اسم جدهم مدين بن إبراهيم أي وأرسلنا شعيباً إلى ساكني مدين أو إلى بني مدين { قَالَ يَا قَوْمٌ اعبدوا الله مَا لَكُمْ مّنْ إله غَيْرُهُ وَلاَ تَنقُصُواْ المكيال } أي المكيل بالمكيال { والميزان } والموزون بالميزان { إِنّى أَرَاكُمْ بِخَيْرٍ } بثروة وسعة تغنيكم عن التطفيف ،   أو أراكم بنعمة من الله حقها أن تقابل بغير ما تفعلون { وَإِنّى أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ مُّحِيطٍ } مهلك من قوله { وأحيط بثمره } [ الكهف : 42 ] وأصله من إحاطة العدو والمراد عذاب الاستئصال في الدنيا أو عذاب الآخرة
