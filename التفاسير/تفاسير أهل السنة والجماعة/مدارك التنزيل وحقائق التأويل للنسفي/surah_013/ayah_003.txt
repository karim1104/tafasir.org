{ وَهُوَ الذي مَدَّ الأرض } بسطها { وَجَعَلَ فِيهَا رَوَاسِيَ } جبالاً ثوابت { وأنهارا } جارية { وَمِن كُلِّ الثمرات جَعَلَ فِيهَا زَوْجَيْنِ اثنين } أي الأسود والأبيض والحلو والحامض والصغير والكبير وما أشبه ذلك { يُغْشِي الَّيلَ النَّهارَ } يلبسه مكانه فيصير أسود مظلماً بعد ما كان أبيض منيراً .   يغشِّي حمزة وعلي وأبو بكر { إِنَّ فِي ذلك لآيات لّقَوْمٍ يَتَفَكَّرُونَ } فيعلمون أن لها صانعاً عليماً حكيماً قادراً<br />
