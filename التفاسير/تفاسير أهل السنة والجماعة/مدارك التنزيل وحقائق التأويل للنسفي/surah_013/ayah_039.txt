{ يَمْحُو الله مَا يَشَاء } ينسخ ما يشاء نسخه { وَيُثَبِّتُ } بدله ما يشاء أو يتركه غير منسوخ أو يمحو من ديوان الحفظة ما يشاء ويثبت غيره أو يمحو كفر التائبين ويثبت إيمانهم أو يميت من حان أجله وعكسه { ويثبّت } مدني وشامي وحمزة وعلي { وَعِندَهُ أُمُّ الكتاب } أي أصل كل كتاب وهو اللوح المحفوظ لأن كل كائن مكتوب فيه<br />
