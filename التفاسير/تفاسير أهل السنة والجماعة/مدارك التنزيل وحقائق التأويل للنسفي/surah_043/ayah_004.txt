{ وَإِنَّهُ فِى أُمِّ الكتاب لَدَيْنَا } وإن القرآن مثبت عند الله في اللوح المحفوظ ،   دليله قوله : { بَلْ هُوَ قُرْءانٌ مَّجِيدٌ فِى لَوْحٍ مَّحْفُوظٍ } [ البروج : 21-22 ] .   وسمي أم الكتاب لأنه الأصل الذي أثبتت فيه الكتب منه تنقل وتستنسخ .   { أُمُّ الكتاب } بكسر الألف : علي وحمزة { لَّعَلِىٌّ } خبر «إن » أي في أعلى طبقات البلاغة أو رفيع الشأن في الكتب لكونه معجزاً من بينها { حَكِيمٌ } ذو حكمة بالغة
