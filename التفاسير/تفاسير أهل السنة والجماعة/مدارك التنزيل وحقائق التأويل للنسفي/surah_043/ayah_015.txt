{ وَجَعَلُواْ لَهُ مِنْ عِبَادِهِ جُزْءاً } متصل بقوله { وَلَئِن سَأَلْتَهُمْ } أي ولئن سألتهم عن خالق السماوات والأرض ليعترفن به وقد جعلوا له مع ذلك الاعتراف من عباده جزأ أي قالوا الملائكة بنات الله فجعلوهم جزأ له وبعضاً منه كما يكون الولد جزأ لوالده { جُزُؤاً } أبو بكر وحماد { إِنَّ الإنسان لَكَفُورٌ مُّبِينٌ } لجحود للنعمة ظاهر جحوده لأن نسبة الولد إليه كفر والكفر أصل الكفران كله<br />
