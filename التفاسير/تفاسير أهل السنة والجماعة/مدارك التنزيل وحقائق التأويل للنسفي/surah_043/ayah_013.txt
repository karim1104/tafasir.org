{ لِتَسْتَوُواْ على ظُهُورِهِ } على ظهور ما تركبونه وهو الفلك والأنعام { ثُمَّ تَذْكُرُواْ } بقلوبكم { نِعْمَةَ رَبِّكُمْ إِذَا استويتم عَلَيْهِ وَتَقُولُواْ } بألسنتكم { سبحان الذى سَخَّرَ لَنَا هذا } ذلل لنا هذا المركوب { وَمَا كُنَّا لَهُ مُقْرِنِينَ } مطيقين .   يقال : أقرن الشيء إذا أطاقه وحقيقة أقرنه وجده قرينته لأن الصعب لا يكون قرينة للضعيف<br />
