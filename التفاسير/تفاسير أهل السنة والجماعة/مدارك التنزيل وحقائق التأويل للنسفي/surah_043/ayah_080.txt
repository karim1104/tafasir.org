{ أَمْ يَحْسَبُونَ أَنَّا لاَ نَسْمَعُ سِرَّهُمْ } حديث أنفسهم { ونجواهم } ما يتحدثون فيما ببينهم ويخفونه عن غيرهم { بلى } نسمعها ونطلع عليها { وَرُسُلُنَا } أي الحفظة { لَدَيْهِمْ يَكْتُبُونَ } عندهم يكتبون ذلك ،   وعن يحيى بن معاذ : من ستر من الناس عيوبه وأبداها لمن لا تخفى عليه خافية فقد جعله أهون الناظرين إليه وهو من أمارات النفاق .  <br />
