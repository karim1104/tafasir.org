{ ونادى فِرْعَوْنُ } نادى بنفسه عظماء القبط أو أمر منادياً فنادى كقولك «قطع الأمير اللص » إذا أمر بقطعه { فِى قَوْمِهِ } جعلهم محلاً لندائه وموقعاً له { قَالَ ياقوم أَلَيْسَ لِى مُلْكُ مِصْرَ وهذه الأنهار } أي أنهار النيل ومعظمها أربعة { تَجْرِى مِن تَحْتِى } من تحت قصري .   وقيل : بين يدي في جناني .   والواو عاطفة للأنهار على { مُلْكُ مِصْرَ } و { تَجْرِى } نصب على الحال منها ،   أو الواو للحال واسم الإشارة مبتدأ ،   والأنهار صفة لاسم الإشارة ،   و { تَجْرِى } خبر للمبدأ ،   وعن الرشيد أنه لما قرأها قال : لأولينها أخس عبيدي فولاها الخصيب وكان خادمه على وضوئه ،   وعن عبد الله بن طاهر أنه وليها فخرج إليها فلما شارفها قال : أهي القرية التي افتخر بها فرعون حتى قال { أَلَيْسَ لِى مُلْكُ مِصْرَ } والله لهي أقل عندي من أن أدخلها فثني عنانه { أَفلاَ تُبْصِرُونَ } قوتي وضعف موسى وغناي وفقره .  <br />
