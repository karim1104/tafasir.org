{ وَتِلْكَ } مبتدأ { القرى } صفة لأن أسماء الإشارة توصف بأسماء الأجناس والخبر { أهلكناهم } أو { تلك القرى } نصب بإضمار «أهلكنا » على شريطة التفسير ،   والمعنى وتلك أصحاب القرى أهلكناهم والمراد قوم نوح وعاد وثمود { لَمَّا ظَلَمُواْ } مثل ظلم أهل مكة { وَجَعَلْنَا لِمَهْلِكِهِم مَّوْعِدًا } وضربنا لإهلاكهم وقتاً معلوماً لا يتأخرون عنه كما ضربنا لأهل مكة يوم بدر والمهلك الإهلاك ووقته .   وبفتح الميم وكسر اللام : حفص ،   وبفتحهما : أبو بكر أي لوقت هلاكهم أو لهلاكهم والموعد وقت أو مصدر .  <br />
