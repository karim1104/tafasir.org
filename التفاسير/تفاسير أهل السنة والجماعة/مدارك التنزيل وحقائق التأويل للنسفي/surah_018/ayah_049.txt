{ وَوُضِعَ الكتاب } أي صحف الأعمال { فَتَرَى المجرمين مُشْفِقِينَ } خائفين { مِمَّا فِيهِ } من الذنوب { وَيَقُولُونَ ياويلتنا مَّالِ هذا الكتاب لاَ يُغَادِرُ صَغِيرَةً وَلاَ كَبِيرَةً } أي لا يترك شيئاً من المعاصي { إِلاَّ أَحْصَاهَا } حصرها وضبطها { وَوَجَدُواْ مَا عَمِلُواْ حَاضِرًا } في الصحف عتيداً أو جزاء ما عملوا { وَلاَ يَظْلِمُ رَبُّكَ أَحَدًا } فيكتب عليه ما لم يعمل أو يزيد في عقابه أو يعذبه بغير جرم .  <br />
