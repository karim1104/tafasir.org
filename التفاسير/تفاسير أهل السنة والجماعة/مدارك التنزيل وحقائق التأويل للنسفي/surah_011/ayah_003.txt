{ وَأَنِ استغفروا رَبَّكُمْ } أي أمركم بالتوحيد والاستغفار { ثُمَّ تُوبُواْ إِلَيْهِ } أي استغفروه من الشرك ثم ارجعوا إليه بالطاعة { يُمَتّعْكُمْ مَّتَاعًا حَسَنًا } يطوّل نفعكم في الدنيا بمنافع حسنة مرضية من عيشة واسعة ونعمة متتابعة { إلى أَجَلٍ مُّسَمًّى } إلى أن يتوفاكم { وَيُؤْتِ كُلَّ ذِي فَضْلٍ فَضْلَهُ } ويعط في الآخرة كل من كان له فضل في العمل وزيادة فيه جزاء فضله لا يبخس منه شيئاً { وَإِن تَوَلَّوْاْ } وإن تتولوا { فَإِنّي أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ كَبِيرٍ } هو يوم القيامة .  <br />
