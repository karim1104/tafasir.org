{ وَلَئِنْ أَذَقْنَا الإنسان } هو للجنس { مِنَّا رَحْمَةً } نعمة من صحة وأمن وجدة .   واللام في { لئن } لتوطئة القسم { ثُمَّ نَزَعْنَاهَا مِنْهُ } ثم سلبناه تلك النعمة وجواب القسم { إِنَّهُ لَيَئُوسٌ } شديد اليأس من أن يعود إلى مثل تلك النعمة المسلوبة قاطع رجاءه من سعة فضل الله من غير صبر ولا تسليم لقضائه { كَفُورٌ } عظيم الكفران لما سلف له من التقلب في نعمة الله نسّاء له<br />
