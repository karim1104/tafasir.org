{ أَمْ يَقُولُونَ افتراه } بل أيقولون افتراه { قُلْ إِنِ افتريته فَعَلَىَّ إِجْرَامِى } أي إن صح أني افتريته فعلي عقوبة إجرامي أي افترائي يقال أجرم الرجل إذا أذنب { وَأَنَاْ بَرِىء } أي ولم يثبت ذلك وأنا بريء منه .   ومعنى { مّمَّا تُجْرَمُونَ } من إجرامكم في إسناد الافتراء إلي فلا وجه لإعراضكم ومعاداتكم<br />
