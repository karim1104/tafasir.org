{ وَلاَ يَنفَعُكُمْ نُصْحِى } هو إعلام موضع الغي ليتقي والرشد ليقتفي { ولكني } { إني } { نصحَي } مدني وأبو عمرو { إِنْ أَرَدْتُّ أَنْ أَنصَحَ لَكُمْ إِن كَانَ الله يُرِيدُ أَن يُغْوِيَكُمْ } أي يضلكم وهذا شرط دخل على شرط فيكون الثاني مقدماً في الحكم لما عرف .   تقديره : إن كان الله يريد أن يغويكم لا ينفعكم نصحي إن أردت أن أنصح لكم ،   وهو دليل بين لنا في إرادة المعاصي { هُوَ رَبُّكُمْ } فيتصرف فيكم على قضية إرادته { وَإِلَيْهِ تُرْجَعُونَ } فيجازيكم على أعمالكم<br />
