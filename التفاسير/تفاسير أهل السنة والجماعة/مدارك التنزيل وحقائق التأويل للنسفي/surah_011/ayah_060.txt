{ وَأُتْبِعُواْ فِى هذه الدنيا لَعْنَةً وَيَوْمَ القيامة } لما كانوا تابعين لهم دون الرسل جعلت اللعنة تابعة لهم في الدارين { أَلا إِنَّ عَادًا كَفَرُواْ رَبَّهُمْ أَلاَ بُعْدًا لّعَادٍ } تكرار «ألا » مع النداء على كفرهم والدعاء عليهم تهويل لأمرهم وبعث على الاعتبار ،   بهم والحذر من مثل حالهم ،   والدعاء ب { بعدا } ً بعد هلاكهم وهو دعاء بالهلاك للدلالة على أنهم كانوا مستأهلين له { قَوْمِ هُودٍ } عطف بيان { لعاد } وفيه فائدة لأن عادا عادان : الأولى القديمة التي هي قوم هود والقصة فيهم ،   والأخرى إرم .  <br />
