{ وَلَقَدْ جَاءتْ رُسُلُنَا } جبريل وميكائيل وإسرافيل أو جبريل مع أحد عشر ملكاً { إبراهيم بالبشرى } هي البشارة بالولد أو بهلاك قوم لوط والأول أظهر { قَالُواْ سَلاَماً } سلمنا عليك سلاماً { قَالَ سلام } أمركم سلام { سِلم } حمزة وعلي بمعنى السلام { فَمَا لَبِثَ أَن جَاء بِعِجْلٍ } فما لبث في المجيء به بل عجل فيه ،   أو فما لبث مجيئه ،   والعجل ولد البقرة : وكان مال إبراهيم البقر { حَنِيئذٍ } مشوي بالحجارة المحماة<br />
