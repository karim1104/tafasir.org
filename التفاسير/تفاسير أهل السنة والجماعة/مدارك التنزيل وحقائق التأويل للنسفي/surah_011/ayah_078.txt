{ وَجَاءهُ قَوْمُهُ يُهْرَعُونَ إِلَيْهِ } يسرعون كأنما يدفعون دفعاً { وَمِن قَبْلُ كَانُواْ يَعْمَلُونَ السيئات } ومن قبل ذلك الوقت كانوا يعملون الفواحش حتى مرنوا عليها وقل عندهم استقباحها فلذلك جاؤوا يهرعون مجاهرين لا يكفهم حياء { قَالَ يَا قَوْمٌ هؤلاءآء بَنَاتِى } فتزوجوهن أراد أن يقي أضيافه ببناته وذلك غاية الكرم ،   وكان تزويج المسلمات من الكفار جائزاً في ذلك الوقت كما جاز في الابتداء في هذه الأمة ،   فقد زوج رسول الله صلى الله عليه وسلم ابنتيه من عتبه بن أبي لهب وأبي العاص وهما كافران .   وقيل كان لهم سيدان مطاعان فأراد لوط أن يزوجهما ابنتيه { هُنَّ أَطْهَرُ لَكُمْ } أحل { هؤلاء } مبتدأ { وبناتي } عطف بيان و { هن } فصل و { أطهر } خبر المبتدأ أو { بناتي } خبر و { هن أطهر } مبتدأ وخبر { فاتقوا الله } بإيثارهن عليهم { وَلاَ تُخْزُونِ } ولا تهينوني ولا تفضحوني من الخزي ،   أو ولا تخجلوني من الخزاية وهي الحياء ،   وبالياء : أبو عمرو في الوصل { فِى ضَيْفِى } في حق ضيوفي فإنه إذا خزي ضيف الرجل أو جاره فقد خزى الرجل وذلك من عراقة الكرم وأصالة المروءة { أَلَيْسَ مِنْكُمْ رَجُلٌ رَّشِيدٌ } أي رجل واحد يهتدي إلى طريق الحق وفعل الجميل والكف عن السوء .  <br />
