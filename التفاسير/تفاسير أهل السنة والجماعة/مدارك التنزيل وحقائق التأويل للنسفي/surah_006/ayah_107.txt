{ وَلَوْ شَاءَ الله } أي إيمانهم فالمفعول محذوف { مَا أَشْرَكُواْ } بيّن أنهم لا يشركون على خلاف مشيئة الله ولو علم منهم اختيار الإيمان لهداهم إليه ولكن علم منهم اختيار الشرك فشاء شركهم فأشركوا بمشيئته { وَمَا جعلناك عَلَيْهِمْ حَفِيظاً } مراعياً لأعمالهم مأخوذاً بإجرامهم { وَمَا أَنتَ عَلَيْهِم بِوَكِيلٍ } بمسلط .  <br />
