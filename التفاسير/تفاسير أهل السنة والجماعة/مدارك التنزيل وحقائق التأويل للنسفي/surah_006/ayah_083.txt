{ وَتِلْكَ حُجَّتُنَا } إشارة إلى جميع ما احتج به إبراهيم عليه السلام على قومه من قوله { فَلَمَّا جَنَّ عَلَيْهِ اليل } إلى قوله { وَهُمْ مُّهْتَدُونَ } { ءاتيناها إبراهيم على قَوْمِهِ } وهو خبر بعد خبر { نَرْفَعُ درجات مَّن نَّشَاءُ } في العلم والحكمة وبالتنوين كوفي وفيه نقض قول المعتزلة في الأصلح { إِنَّ رَبَّكَ حَكِيمٌ } بالرفع { عَلِيمٌ } بالأهل .  <br />
