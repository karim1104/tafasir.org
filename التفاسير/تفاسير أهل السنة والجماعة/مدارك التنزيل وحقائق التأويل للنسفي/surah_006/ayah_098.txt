{ وَهُوَ الذي أَنشَأَكُم مّن نَّفْسٍ واحدة } هي آدم عليه السلام { فَمُسْتَقَرٌّ وَمُسْتَوْدَعٌ } { فَمُسْتَقَر } بالكسر : مكي وبصري .   فمن فتح القاف كان المستودع اسم مكان مثله ،   ومن كسرها كان اسم فاعل والمستودع اسم مفعول يعني فلكم مستقر في الرحم ومستودع في الصلب ،   أو مستقر فوق الأرض ومستودع تحتها ،   أو فمنكم مستقر ومنكم مستودع { قَدْ فَصَّلْنَا الآيات لِقَوْمٍ يَفْقَهُونَ } وإنما قيل { يَعْلَمُونَ } ثم { يَفْقَهُونَ } هنا لأن الدلالة ثمّ أظهر وهنا أدق ،   لأن إنشاء الإنس من نفس واحدة وتصريفهم بين أحوال مختلفة أدق فكان ذكر الفقه الدال على تدقيق النظر أوفق<br />
