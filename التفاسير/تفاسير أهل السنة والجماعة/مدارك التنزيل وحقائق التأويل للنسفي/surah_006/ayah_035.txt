كان يكبر على النبي صلى الله عليه وسلم كفر قومه وإعراضهم ويحب مجيء الآيات ليسلموا فنزل { وَإِن كَانَ كَبُرَ عَلَيْكَ } عظم وشق { إِعْرَاضُهُمْ } عن الإسلام { فَإِن استطعت أَن تَبْتَغِيَ نَفَقاً } منفذاً تنفيذ فيه إلى ما تحت الأرض حتى تطلع لهم آية يؤمنون بها { فِى الأرض } صفة ل { نَفَقاً } { أَوْ سُلَّماً فِي السماء فَتَأْتِيَهُمْ } منها { بِئَايَةٍ } فافعل ،   وهو جواب { فَإِن استطعت } و { إِنِ استطعتم } وجوابها جواب { وَإِن كَانَ كَبُرَ } والمعنى إنك لا تستطيع ذلك ،   والمراد بيان حرصه على إسلام قومه وأنه لو استطاع أن يأتيهم بآية من تحت الأرض أو من فوق السماء لأتى بها رجاء إيمانهم { وَلَوْ شَاءَ الله لَجَمَعَهُمْ عَلَى الهدى } لجعلهم بحيث يختارون الهدى ،   ولكن لما علم أنهم يختارون الكفر لم يشأ أن يجمعهم على ذلك كذا قاله الشيخ أبو منصور رحمه الله { فَلاَ تَكُونَنَّ مِنَ الجاهلين } من الذين يجهلون ذلك .  <br />
