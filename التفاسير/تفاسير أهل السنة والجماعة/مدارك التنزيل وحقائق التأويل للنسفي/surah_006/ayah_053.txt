{ وكذلك فَتَنَّا بَعْضَهُمْ بِبَعْضٍ } ومثل ذلك الفتن العظيم ابتليتا الأغنياء بالفقراء { لِّيَقُولُواْ } أي الأغنياء { أهؤلاءآء مَنَّ الله عَلَيْهِم مِّن بَيْنِنَا } أي أنعم الله عليهم بالإيمان ونحن المقدمون والرؤساء وهم الفقراء إنكاراً لأن يكون أمثالهم على الحق وممنوناً عليهم من بينهم بالخير ونحوه<br />
{ لَوْ كَانَ خَيْراً مَّا سَبَقُونَا إِلَيْهِ } [ الأحقاف : 11 ] { أَلَيْسَ الله بِأَعْلَمَ بالشاكرين } بمن يشكر نعمته .
