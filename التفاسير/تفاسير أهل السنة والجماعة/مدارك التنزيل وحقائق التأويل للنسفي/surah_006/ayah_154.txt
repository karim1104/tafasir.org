{ ثُمَّ ءَاتَيْنَا مُوسَى الكتاب تَمَامًا } أي ثم أخبركم إنا آتينا أو هو عطف على { قُلْ } أي ثم قل آتينا ،   و «ثم » مع الجملة تأتي بمعنى الواو كقوله { ثُمَّ الله شَهِيدٌ } [ يونس : 46 ] { عَلَى الذي أَحْسَنَ } على من كان محسناً صالحاً يريد جنس المحسنين دليله قراءة عبد الله { عَلَى الذين أَحْسَنُواْ } أو أراد به موسى عليه السلام أي تتمة للكرامة على العبد الذي أحسن الطاعة في التبليغ في كل ما أمر به { وَتَفْصِيلاً لّكُلِّ شَيْءٍ } وبياناً مفصلاً لكل ما يحتاجون إليه في دينهم { وَهُدًى وَرَحْمَةً لَّعَلَّهُم } أي بني إسرائيل { بِلِقَاء رَبّهِمْ يُؤْمِنُونَ } يصدقون أي بالبعث والحساب وبالرؤية .
