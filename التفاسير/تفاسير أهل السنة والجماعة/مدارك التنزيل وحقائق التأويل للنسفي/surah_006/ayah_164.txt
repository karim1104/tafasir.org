{ قُلْ أَغَيْرَ الله أَبْغِي رَبّاً } جواب عن دعائهم له إلى عبادة آلهتهم .   والهمزة للإنكار أي منكر أن أطلب رباً غيره ،   وتقديم المفعول للإشعار بأنه أهم { وَهُوَ رَبُّ كُلِّ شَيْءٍ } وكل من دونه مربوب ليس في الوجود من له الربوبية غيره { وَلاَ تَكْسِبُ كُلُّ نَفْسٍ إِلاَّ عَلَيْهَا } جواب عن قولهم { اتبعوا سَبِيلَنَا وَلْنَحْمِلْ خطاياكم } [ العنكبوت : 12 ] { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أخرى } أي لا تأخذ نفس آثمة بذنب نفس أخرى { ثُمَّ إلى رَبِّكُمْ مَّرْجِعُكُمْ فَيُنَبِّئُكُم بِمَا كُنتُمْ فِيهِ تَخْتَلِفُونَ } من الأديان التي فرقتموها
