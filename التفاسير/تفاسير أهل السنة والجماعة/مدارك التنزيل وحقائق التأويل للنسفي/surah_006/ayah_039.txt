ولما ذكر من خلائقه وآثار قدرته ما يشهد لربوبيته وينادي على عظمته قال { والذين كَذَّبُواْ باياتنا صُمٌّ } لا يسمعون كلام المنبه { وَبُكْمٌ } لا ينطقون بالحق خابطون { فِي الظلمات } أي ظلمة الجهل والحيرة والكفر ،   غافلون عن تأمل ذلك والتفكر فيه .   { صُمٌّ وَبُكْمٌ } خبر { الذين } ودخول الواو لا يمنع من ذلك ،   و { فِي الظلمات } خبر آخر .   ثم قال إيذاناً بأنه فعال لما يريد { مَن يَشَأْ الله يُضْلِلْهُ } أي من يشأ الله ضلاله يضلله { وَمَن يَشَأْ يَجْعَلْهُ على صراط مُّسْتَقِيمٍ } وفيه دلالة خلق الأفعال وإرادة المعاصي ونفي الأصلح .  <br />
