{ تَكَادُ السماوات } تقرب وبالياء نافع وعليّ { يَتَفَطَّرْنَ } وبالنون بصري وشامي وحمزة وخلف وأبو بكر .   الانفطار من فطره إذا شقه والتفطر من فطره إذا شققه { مِنْهُ } من عظم هذا القول { وَتَنشَقُّ الأرض } تنخسف وتنفصل أجزاؤها { وَتَخِرُّ الجبال } تسقط { هَدّاً } كسراً أو قطعاً أو هدماً ،   والهدة صوت الصاعقة من السماء وهو مصدر أي تهد هدّا من سماع قولهم أو مفعول له أو حال أي مهدودة<br />
