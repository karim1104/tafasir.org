{ قَالَ } جبريل { كذلك } أي الأمر كما قلت : لم يمسسك رجل نكاحاً أو سفاحاً { قَالَ رَبُّكَ هُوَ عَلَىَّ هَيّنٌ } أي إعطاء الولد بلا أب عليَّ سهل { وَلِنَجْعَلَهُ ءايَةً لّلْنَّاسِ } تعليل معلله محذوف أي ولنجعله آية للناس فعلنا ذلك ،   أو هو معطوف على تعليل مضمر أي لنبين به قدرتنا ولنجعله آية للناس أي عبرة وبرهاناً على قدرتنا { وَرَحْمَةً مّنَّا } لمن أمن به { وَكَانَ } خلق عيسى { أَمْراً مَّقْضِيّاً } مقدراً مسطوراً في اللوح فلما أطمأنت إلى قوله دنا منها فنفخ في جيب درعها فوصلت النفخة إلى بطنها<br />
