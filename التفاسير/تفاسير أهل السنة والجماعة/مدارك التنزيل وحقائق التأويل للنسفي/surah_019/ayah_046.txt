{ قَالَ } آزر توبيخاً : { أَرَاغِبٌ أَنتَ عَنْ الِهَتِى ياإبراهيم } أي أترغب عن عبادتها فناداه باسمه ولم يقابل { يا أبت } ب «يا بني » وقدم الخبر على المبتدأ لأنه كان أهم عنده { لَئِن لَّمْ تَنتَهِ } عن شتم الأصنام { لأرْجْمْتَّكَ } لأقتلنك بالرجام أو لأضربنك بها حتى تتباعد أو لأشتمنك { واهجرنى } عطف على محذوف يدل عليه { لأرجمنك } تقديره فاحذرني واهجرني { مَلِيّاً } ظرف أي زماناً طويلاً من الملاوة<br />
