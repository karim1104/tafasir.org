{ جنات } بدل من { الجنة } لأن الجنة تشتمل على جنات عدن لأنها جنس أو نصب على المدح { عَدْنٍ } معرفة لأنها علم لمعنى العدن وهو الإقامة أو علم لأرض الجنة لكونها مقام إقامة { التى وَعَدَ الرحمن عِبَادَهُ } أي عباده التائبين المؤمنين الذين يعملون الصالحات كما سبق ذكرهم ولأنه أضافهم إليه وهو للاختصاص وهؤلاء أهل الاختصاص { بالغيب } أي وعدها وهي غائبة عنهم غير حاضرة أو هم غائبون عنها لا يشاهدونها { إِنَّهُ } ضمير الشأن أو ضمير الرحمن { كَانَ وَعْدُهُ } أي موعوده وهو الجنة { مَأْتِيّاً } أي هم يأتونها<br />
