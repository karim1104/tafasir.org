{ وَرَدَّ الله الذين كَفَرُواْ } الأحزاب { بِغَيْظِهِمْ } حال أي مغيظين كقوله { تَنبُتُ بالدهن } [ المؤمنون : 20 ] { لَمْ يَنَالُواْ خَيْراً } ظفراً أي لم يظفروا بالمسلمين وسماه خيراً بزعمهم وهو حال أي غير ظافرين { وَكَفَى الله المؤمنين القتال } بالريح والملائكة { وَكَانَ الله قَوِيّاً عَزِيزاً } قادراً غالباً .
