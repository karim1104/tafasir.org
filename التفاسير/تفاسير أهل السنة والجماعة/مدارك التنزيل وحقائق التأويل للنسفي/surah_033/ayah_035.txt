ولما نزل في نساء النبي صلى الله عليه وسلم ما نزل قال نساء المسلمين : فما نزل فينا شيء ،   فنزلت :{ إِنَّ المسلمين والمسلمات } المسلم الداخل في السّلم بعد الحرب المنقاد الذي لا يعاند ،   أو المفوض أمره إلى الله المتوكل عليه من أسلم وجهه إلى الله { والمؤمنين } المصدقين بالله ورسوله وبما يجب أن يصدق به { والمؤمنات والقانتين } القائمين بالطاعة { والقانتات والصادقين } في النيات والأقوال والأعمال { والمتصدقات والصابرين والصابرات } على الطاعات وعن السيئات { والخاشعين } المتواضعين لله بالقلوب والجوارح أو الخائفين { والخاشعات والمتصدقين والمتصدقات } فرضاً ونفلاً { والصائمين والصائمات } فرضاً ونفلاً .   وقيل : من تصدق في كل أسبوع بدرهم فهو من المتصدقين ،   ومن صام البيض من كل شهر فهو من الصائمين { والحافظين فُرُوجَهُمْ } عما لا يحل { والحافظات والذكرين الله كَثِيراً } بالتسبيح والتحميد والتهليل والتكبير وقراءة القرآن والاشتغال بالعلم من الذكر والمعنى والحافظات فروجهن { والذاكرات } الله فحذف لدلالة ما تقدم عليه .   والفرق بين عطف الإناث على الذكور وعطف الزوجين على الزوجين لأن الأول نظير قوله { ثيبات وَأَبْكَاراً } [ التحريم : 5 ] في أنهما جنسان مختلفان واشتركا في حكم واحد فلم يكن بد من توسط العاطف بينهما ،   وأما الثاني فمن عطف الصفة على الصفة بحرف الجمع ومعناه أن الجامعين والجامعات لهذه الطاعات { أَعَدَّ الله لَهُم مَّغْفِرَةً وَأَجْراً عَظِيماً } على طاعاتهم .
