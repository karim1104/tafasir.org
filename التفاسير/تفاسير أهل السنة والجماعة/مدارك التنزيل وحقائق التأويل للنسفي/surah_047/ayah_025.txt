{ إِنَّ الذين ارتدوا على أدبارهم مِّن بَعْدِ مَا تَبَيَّنَ لَهُمُ الهدى } أي المنافقون رجعوا إلى الكفر سراً بعد وضوح الحق لهم { الشيطان سَوَّلَ } زين { لَهُمْ } جملة من مبتدأ وخبر وقعت خبراً ل «إن » نحو : إن زيداً عمرو مر به { وأملى لَهُمْ } ومدّ لهم في الآمال والأماني { وَأُمْلِىَ } أبو عمرو أي امهلوا ومد في عمرهم<br />
