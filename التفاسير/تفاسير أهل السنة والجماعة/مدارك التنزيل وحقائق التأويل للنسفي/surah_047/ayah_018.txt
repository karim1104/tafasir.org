{ فَهَلْ يَنظُرُونَ إِلاَّ الساعة } أي ينتظرون { أَن تَأْتِيهُم } أي إتيانها فهو بدل اشتمال من { الساعة } { بَغْتَةً } فجأة { فَقَدْ جَآءَ أَشْرَاطُهَا } علاماتها وهو مبعث محمد صلى الله عليه وسلم وإنشقاق القمر والدخان .   وقيل : قطع الأرحام وقلة الكرام وكثرة اللئام { فأنى لَهُمْ إِذَا جَآءَتْهُمْ ذِكْرَاهُمْ } قال الأخفش : التقدير فأنى لهم ذكراهم إذا جاءتهم<br />
