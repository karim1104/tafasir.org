{ بَلْ نَقْذِفُ } «بل » إضراب عن اتخاذ اللهو وتنزيه منه لذاته كأنه قال سبحاننا أن نتخذ اللهو بل من سنتنا أن نقذف أي نرمي ونسلط { بالحق } بالقرآن { عَلَى الباطل } الشيطان أو بالإسلام على الشرك أو بالجد على اللعب { فَيَدْمَغُهُ } فيكسره ويدحض الحق الباطل ،   وهذه استعارة لطيفة لأن أصل استعمال القذف والدمغ في الأجسام ،   ثم استعير القذف لإيراد الحق على الباطل والدمغ لإذهاب الباطل فالمستعار منه حسي والمستعار له عقلي فكأنه قيل : بل نورد الحق الشبيه بالجسم القوي على الباطل الشبيه بالجسم الضعيف فيبطله إبطال الجسم القوي الضعيف { فَإِذَا هُوَ } أي الباطل { زَاهِقٌ } هالك ذاهب { وَلَكُمُ الويل مِمَّا تَصِفُونَ } الله به من الولد ونحوه .  <br />
