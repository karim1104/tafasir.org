{ وَجَعَلْنَا السماء سَقْفاً مَّحْفُوظاً } في موضعه عن السقوط كما قال { وَيُمْسِكُ السماء أَن تَقَعَ عَلَى الأرض إِلاَّ بِإِذْنِهِ } [ الحج : 65 ] أو محفوظاً بالشهب عن الشياطين كما قال : { وحفظناها مِن كُلّ شيطان رَّجِيمٍ } [ الحجر : 17 ] { وَهُمْ } أي الكفار { عَنْ ءاياتها } عن الأدلة التي فيها كالشمس والقمر والنجوم { مُّعْرِضُونَ } غير متفكرين فيها فيؤمنون .
