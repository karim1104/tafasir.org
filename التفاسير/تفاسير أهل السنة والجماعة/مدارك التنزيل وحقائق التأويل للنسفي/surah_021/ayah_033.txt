{ وَهُوَ الذى خَلَقَ اليل } لتسكنوا فيه { والنهار } لتتصرفوا فيه { والشمس } لتكون سراج النهار { والقمر } ليكون سراج الليل { كُلٌّ } التنوين فيه عوض عن المضاف إليه أي كلهم والضمير للشمس والقمر والمراد بهما جنس الطوالع ،   وجمع جمع العقلاء للوصف بفعلهم وهو السباحة { فِى فَلَكٍ } عن ابن عباس رضي الله عنهما : الفلك السماء .   والجمهور على أن الفلك موج مكفوف تحت السماء تجري فيه الشمس والقمر والنجوم و { كل } مبتدأ خبره { يَسْبَحُونَ } يسيرون أي يدورون والجملة في محل النصب على الحال من الشمس والقمر<br />
