{ وجعلناهم أَئِمَّةً } يقتدى بهم في الدين { يَهْدُونَ } الناس { بِأَمْرِنَا } بوحينا { وَأَوْحَيْنَا إِلَيْهِمْ فِعْلَ الخيرات } وهي جميع الأعمال الصالحة وأصله أن تفعل الخيرات ثم فعلا الخيرات ثم فعل الخيرات .   وكذلك قوله { وإقام الصلاة وإيتاء الزكاة } والأصل وإقامة الصلاة إلا أن المضاف إليه جعل بدلاً من الهاء { وَكَانُواْ لَنَا عابدين } لا للإصنام فأنتم يا معشر العرب أولاد إبراهيم فاتبعوه في ذلك .  <br />
