{ فَلاَ تَحْسَبَنَّ الله مُخْلِفَ وَعْدِهِ رُسُلَهُ } يعني قوله { إِنَّا لَنَنصُرُ رُسُلَنَا } [ غافر : 51 ] { كَتَبَ الله لأَغْلِبَنَّ أَنَاْ وَرُسُلِي } [ المجادلة : 21 ] { مخلف } مفعول ثانٍ ل { تحسبن } وأضاف { مخلف } إلى { وعده } وهو المفعول الثاني له والأول { رسله } والتقدير مخلف رسله وعده وإنما قدم المفعول الثاني على الأول ليعلم أنه لا يخلف الوعد أصلاً كقوله : { إن الله لا يخلف الميعاد } [ آل عمران : 9 ] ثم قال { رسله } ليؤذن أنه إذا لم يخلف وعده أحداً فكيف يخلفه رسله الذين هم خيرته وصفوته { إِنَّ الله عَزِيزٌ } غالب لا يماكر { ذُو انتقام } لأوليائه من أعدائه وانتصاب
