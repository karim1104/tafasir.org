{ فَأَوْجَسَ } فأضمر { مِنْهُمْ خِيفَةً } خوفاً لأن من لم يأكل طعامك لم يحفظ ذمامك .  <br />
عن ابن عباس رضي الله عنهما : وقع في نفسه أنهم ملائكة أرسلوا للعذاب { قَالُواْ لاَ تَخَفْ } إنا رسل الله ،   وقيل : مسح جبريل العجل فقام ولحق بأمه { وَبَشَّرُوهُ بغلام عَلَيمٍ } أي يبلغ ويعلم والمبشر به إسحاق عند الجمهور .  <br />
