{ وَإِذَا الجنة أُزْلِفَتْ } أدنيت من المتقين كقوله : { وَأُزْلِفَتِ الجنة لِلْمُتَّقِينَ غَيْرَ بَعِيدٍ } [ ق : 31 ] .   فهذه اثنتا عشرة خصلة ست منها في الدنيا والباقية في الآخرة .   ولا وقف مطلقاً من أول السورة إلى { مَّا أَحْضَرَتْ } لأن عامل النصب في { إِذَا الشمس } وفيما عطف عليه جوابها وهو { عَلِمَتْ نَفْسٌ } أي كل نفس ولضرورة انقطاع النفس على كل آية جوز الوقف { مَّا أَحْضَرَتْ } من خير وشر .
