{ وَأَخِى هَرُونُ هُوَ أَفْصَحُ مِنّى لِسَاناً فَأَرْسِلْهِ مَعِىَ } حفص { رِدْءاً } حال أي عونا يقال ردأته أعنته ،   وبلا همز : مدني { يُصَدّقُنِى } عاصم وحمزة صفة أي ردأ مصدقاً لي ،   وغيرهما بالجزم جواب ل { أرسله } ومعنى تصديقه موسى إعانته إياه بزيادة البيان في مظان الجدال إن احتاج إليه ليثبت دعواه لا أن يقول له صدقت ،   ألا ترى إلى قوله { هو أفصح مني لساناً فأرسله } وفضل الفصاحة إنما يحتاج إليه لتقرير البرهان لا لقوله صدقت فسحبان وباقل فيه يستويان { إِنّى أَخَافُ أَنْ يُكَذّبُونِ } .   { يكذبوني } في الحالين : يعقوب<br />
