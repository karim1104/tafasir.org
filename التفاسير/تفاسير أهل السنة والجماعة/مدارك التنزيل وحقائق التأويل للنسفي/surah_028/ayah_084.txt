{ مَن جَاء بالحسنة فَلَهُ خَيْرٌ مّنْهَا } مر في «النمل » { وَمَن جَاء بالسيئة فَلاَ يُجْزَى الذين عَمِلُواْ السيئات } معناه فلا يجزون فوضع { الذين عملوا السيئات } موضع الضمير لأن في إسناد عمل السيئة إليهم مكرراً ،   فضل تهجين لحالهم وزيادة تبغيض للسيئة إلى قلوب السامعين { إِلاَّ مَا كَانُواْ يَعْمَلُونَ } إلا مثل ما كانوا يعملون ومن فضله العظيم أن لا يجزي السيئة إلا بمثلها ويجزي الحسنة بعشر أمثالها وبسبعمائة<br />
