{ فَلَمَّا أَنْ أَرَادَ } موسى { أَن يَبْطِشَ بالذى } بالقبطي الذي { هُوَ عَدُوٌّ لَّهُمَا } لموسى والإسرائيلي لأنه ليس على دينهما ،   أو لأن القبط كانوا أعداء بني إسرائيل { قَالَ } الإسرائيلي لموسى عليه السلام وقد توهم أنه أراد أخذه لا أخد القبطي إذ قال له { إنك لغوي مبين } { ياموسى أَتُرِيدُ أَن تَقْتُلَنِى كَمَا قَتَلْتَ نَفْساً } يعني القبطي { بالأمس إِن تُرِيدُ } ما تريد { إِلاَّ أَن تَكُونَ جَبَّاراً } أي قتالاً بالغضب { فِى الأرض } أرض مصر { وَمَا تُرِيدُ أَن تَكُونَ مِنَ المصلحين } في كظم الغيظ ،   وكان قتل القبطي بالأمس قد شاع ولكن خفي قاتله ،   فلما أفشى على موسى عليه السلام علم القبطي أن قاتله موسى فأخبر فرعون فهموا بقتله .  <br />
