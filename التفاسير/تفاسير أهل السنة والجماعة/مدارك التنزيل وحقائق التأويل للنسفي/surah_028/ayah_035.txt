{ قَالَ سَنَشُدُّ عَضُدَكَ بِأَخِيكَ } سنقويك به إذ اليد تشد بشدة العضد لأنه قوام اليد والجملة تقوى بشدة اليد على مزاولة الأمور { وَنَجْعَلُ لَكُمَا سلطانا } غلبة وتسلطاً وهيبة في قلوب الأعداء { فَلاَ يَصِلُونَ إِلَيْكُمَا باياتنا } الباء تعلق ب { يصلون } أي لا يصلون إليكما بسبب آياتنا وتم الكلام ،   أو ب { نجعل لكما سلطاناً } أي نسلطكما بآياتنا أو بمحذوف أي إذهبا بآياتنا ،   أو هو بيان ل { الغالبون } لا صلة ،   أو قسم جوابه { لا يصلون } مقدماً عليه { أَنتُمَا وَمَنِ اتبعكما الغالبون }<br />
