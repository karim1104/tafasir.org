{ وابتغ فِيمَا ءاتَاكَ الله } من الغنى والثروة { الدار الأخرة } بأن تتصدق على الفقراء وتصل الرحم وتصرف إلى أبواب الخير { وَلاَ تَنسَ نَصِيبَكَ مِنَ الدنيا } وهو أن تأخذ ما يكفيك ويصلحك .   وقيل : معناه واطلب بدنياك آخرتك فإن ذلك حظ المؤمن منها { وَأَحْسَنُ } إلى عباد الله { كَمَا أَحْسَنَ الله إِلَيْكَ } أو أحسن بشكرك وطاعتك لخالق الأنام كما أحسن إليك بالإنعام { وَلاَ تَبْغِ الفساد فِى الأرض } بالظلم والبغي { إِنَّ الله لاَ يُحِبُّ المفسدين } .  <br />
