{ وَأَصْبَحَ } وصار { الذين تَمَنَّوْاْ مَكَانَهُ } منزلته من الدنيا { بالأمس } ظرف ل { تمنوا } ولم يرد به اليوم الذي قبل يومك ولكن الوقت القريب استعارة { يَقُولُونَ وَيْكَأَنَّ الله يَبْسُطُ الرزق لِمَن يَشَاء مِنْ عِبَادِهِ وَيَقْدِرُ } و «ي » منفصلة عن «كأن » عند البصريين .   قال سيبويه : «وي » كلمة تنبه على الخطأ وتندم يستعملها النادم بإظهار ندامته يعني أن القوم قد تنبهوا على خطئهم في تمنيهم ،   وقولهم { يا ليت لنا مثل ما أوتى قارون } وتندموا { لَوْ لاَ أَن مَنَّ الله عَلَيْنَا } بصرف ما كنا نتمناه بالأمس { لَخَسَفَ بِنَا } لخَُسِفَ وبفتحتين : حفص ويعقوب وسهل ،   وفيه ضمير الله تعالى { وَيْكَأَنَّهُ لاَ يُفْلِحُ الكافرون } أي تندموا ثم قالوا : كأنه لا يفلح الكافرون<br />
