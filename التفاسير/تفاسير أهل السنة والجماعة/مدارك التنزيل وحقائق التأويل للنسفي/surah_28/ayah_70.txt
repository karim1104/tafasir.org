{ وَهُوَ الله } وهو المستأثر بالإلهية المختص بها { لاَ إله إِلاَّ هُوَ } تقرير لذلك كقولك «القبلة الكعبة لا قبلة إلا هي » .   { لَهُ الحمد فِى الأولى } الدنيا { والآخرة } هو قولهم { الحمد للَّهِ الذى أَذْهَبَ عَنَّا الحزن } [ فاطر : 34 ] { الحمد للَّهِ الذى صَدَقَنَا وَعْدَهُ } [ الزمر : 74 ] { وَقِيلَ الحمد لِلَّهِ رَبّ العالمين } [ الزمر : 75 ] والتحميد ثمة على وجه اللذة لا الكلفة { وَلَهُ الحكم } القضاء بين عباده { وَإِلَيْهِ تُرْجَعُونَ } بالبعث والنشور .   وبفتح التاء وكسر الجيم : يعقوب .
