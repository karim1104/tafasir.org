{ وَلَمَّا رَأَى المؤمنون الأحزاب } وعدهم الله أن يزلزلوا حتى يستغيثوه ويستنصروه بقوله { أَمْ حَسِبْتُمْ أَن تَدْخُلُواْ الجنة وَلَمَّا يَأْتِكُم مَّثَلُ الذين خَلَوْاْ مِن قَبْلِكُم } إلى قوله { قَرِيبٌ } [ البقرة : 214 ] فلما جاء الأحزاب واضطربوا ورعبوا الرعب الشديد { قَالُواْ هذا مَا وَعَدَنَا الله وَرَسُولُهُ وَصَدَقَ الله وَرَسُولُهُ } وعلموا أن الغلبة والنصرة قد وجبت لهم .   وعن ابن عباس رضي الله عنهما أن النبي صلى الله عليه وسلم قال لأصحابه : إن الأحزاب سائرون إليكم في آخر تسع ليال أو عشر .   فلما رأوهم قد أقبلوا للميعاد قالوا ذلك ،   وهذا إشارة إلى الخطب والبلاء { وَمَا زَادَهُمْ } ما رأوا من اجتماع الأحزاب عليهم ومجيئهم { إِلاَّ إِيمَانًا } بالله وبمواعيده { وَتَسْلِيماً } لقضائه وقدره .
