{ يدبّر الأمر } أي أمر الدنيا { من السّماء إلى الأرض } إلى أن تقوم الساعة { ثمّ يعرج إليه } ذلك الأمر كله أي يصير إليه ليحكم فيه { في يومٍ كان مقداره ألف سنةٍ } وهو يوم القيامة { مّمّا تعدّون } من أيام الدنيا ولا تمسّك للمشبهة بقوله { إليه } في إثبات الجهة لأن معناه إلى حيث يرضاه أو أمره كما لا تشبث لهم بقوله : { إني ذاهب إلى ربي } [ الصافات : 99 ] .   { إني مهاجر إلى ربي } [ العنكبوت : 26 ] .   { ومن يخرج من بيته مهاجراً إلى الله } [ النساء : 100 ] .
