{ اتخذناهم سِخْرِيّاً } بلفظ الإخبار : عراقي غير عاصم على أنه صفة ل { رِجَالاً } مثل { كُنَّا نَعُدُّهُمْ مّنَ الأشرار } وبهمزة الاستفهام : غيرهم على أنه إنكار على أنفسهم في الاستسخار منهم ،   { سُخرِياً } مدني وحمزة وعلي وخلف والمفضل { أَمْ زَاغَتْ } مالت { عَنْهُمُ الأبصار } هو متصل بقوله { مَا لَنَا } أي ما لنا لا نراهم في النار كأنهم ليسوا فيها بل أزاغت عنهم أبصارنا فلا نراهم وهم فيها ،   قسموا أمرهم بين أن يكونوا من أهل الجنة وبين أن يكونوا من أهل النار إلا أنه خفي عليهم مكانهم .  <br />
