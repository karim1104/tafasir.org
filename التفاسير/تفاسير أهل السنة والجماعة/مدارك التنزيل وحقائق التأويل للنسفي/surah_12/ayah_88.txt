{ فَلَمَّا دَخَلُواْ عَلَيْهِ } على يوسف { قَالُواْ يا أَيُّهَا العزيز مَسَّنَا وَأَهْلَنَا الضر } الهزال من الشدة والجوع { وَجِئْنَا بِبِضَاعَةٍ مُّزْجَاةٍ } مدفوعة يدفعها كل تاجر رغبة عنها واحتقاراً لها من أزجيته إذا دفعته وطردته .   قيل : كان دراهم زيوفاً لا تؤخذ إلا بوضيعة .   وقيل : كانت صوفاً وسمناً { فَأَوْفِ لَنَا الكيل } الذي هو حقنا { وَتَصَدَّقْ عَلَيْنَا } وتفضل علينا بالمسامحة والإغماض عن رداءة البضاعة أوزدنا على حقنا أوهب لنا أخانا { إِنَّ الله يَجْزِى المتصدقين } .  <br />
