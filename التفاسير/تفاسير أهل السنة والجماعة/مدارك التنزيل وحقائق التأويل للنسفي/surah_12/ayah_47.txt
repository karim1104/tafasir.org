{ قَالَ تَزْرَعُونَ سَبْعُ سِنِينَ } هو خبر في معنى الأمر كقوله : { تُؤْمِنُونَ بالله واليوم الأخر وتجاهدون } الصف : 11 ) دليله قوله { فذروه في سنبله } وإنما يخرج الأمر في صورة الخبر للمبالغة في وجود المأمور به فيجعل كأنه موجود فهو يخبر عنه { دَأَبًا } بسكون الهمزة وحفص يحركه وهما مصدرا دأب في العمل ،   وهو حال من المأمورين أي دائبين { فَمَا حَصَدتُّمْ فَذَرُوهُ فِى سُنبُلِهِ } كي لا يأكله السوس { إِلاَّ قَلِيلاً مّمَّا تَأْكُلُونَ } في تلك السنين
