{ ياصاحبى السجن } يا ساكني السجن كقوله { أصحاب النار } [ البقرة : 39 ] و { أصحاب الجنة } [ البقرة : 82 ] { أأرْبَابٌ مُّتَّفَرّقُونَ خَيْرٌ أَمِ الله الواحد القهار } يريد التفرق في العدد والتكاثر أي أن تكون أرباب شتى يستعبدكما هذا ويستعبدكما هذا خير لكما أم يكون لكما رب واحد قهار لا يغالب ولا يشارك في الربوبية ؟ وهذا مثل ضربه لعبادة الله وحده ولعبادة الأصنام
