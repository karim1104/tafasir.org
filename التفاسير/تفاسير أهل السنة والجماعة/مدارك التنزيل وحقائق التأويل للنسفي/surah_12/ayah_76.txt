{ فَبَدَأَ بِأَوْعِيَتِهِمْ قَبْلَ وِعَاء أَخِيهِ } فبدأ بتفتيش أوعيتهم قبل وعاء بنيامين لنفي التهمة حتى بلغ وعاءه فقال : ما أظن هذا أخذ شيئاً فقالوا : والله لا نتركه حتى تنظر في رحله فإنه أطيب لنفسك وأنفسنا { ثُمَّ استخرجها } أي الصواع { مِن وِعَاء أَخِيهِ } ذكر ضمير الصواع مرات ثم أنثه لأن التأنيث يرجع إلى السقاية ،   أو لأن الصواع يذكر ويؤنث .  <br />
الكاف في { كذلك } في محل النصب أي مثل ذلك الكيد العظيم { كِدْنَا لِيُوسُفَ } يعني علمناه إياه { مَا كَانَ لِيَأْخُذَ أَخَاهُ فِى دِينِ الملك } تفسير للكيد وبيان له لأن الحكم في دين الملك أي في سيرته للسارق أن يغرم مثلي ما أخذ لا أن يستعبد { إِلاَّ أَن يَشَاء الله } أي ما كان ليأخذه إلا بمشيئة الله وإرادته فيه { نَرْفَعُ درجات } بالتنوين : كوفي { مَّن نَّشَاء } أي في العلم كما رفعنا درجة يوسف فيه { وَفَوْقَ كُلّ ذِى عِلْمٍ عَلِيمٌ } فوقه أرفع درجة منه في علمه أو فوق العلماء كلهم عليهم هم دونه في العلم وهو الله عز وجل .  <br />
