{ ثُمَّ أَرْسَلْنَا رُسُلَنَا } فعلى والألف للتأنيث كسكرى لأن الرسل جماعة ولذا لا ينون لأنه غير منصرف { تترى } بالتنوين : مكي وأبو عمرو ويزيد على أن الألف للإلحاق كأرطى ،   وهو نصب على الحال في القراءتين أي متتابعين واحداً بعد واحد ،   وتاؤها فيهما بدل من الواو والأصل و «ترى » من الوتر وهو الفرد فقلبت الواوتاء كتراث { كُلَّمَا جَاء أُمَّةً رَّسُولُهَا كَذَّبُوهُ } الرسول يلابس المرسل والمرسل إليه والإضافة تكون بالملابسة فتصح إضافته إليهما { فَأَتْبَعْنَا } الأمم والقرون { بَعْضُهُم بَعْضاً } في الهلاك { وجعلناهم أَحَادِيثَ } أخباراً يسمع بها ويتعجب منها ،   والأحاديث تكون اسم جمع للحديث ومنه أحاديث النبي عليه الصلاة والسلام ،   وتكون جمعاً للأحدوثة وهي ما يتحدث به الناس تلهياً وتعجباً وهو المراد هنا { فَبُعْداً لّقَوْمٍ لاَّ يُؤْمِنُونَ<br />
