{ فَأَخَذَتْهُمُ الصيحة } أي صيحة جبريل صاح عليهم فدمرهم { بالحق } بالعدل من الله يقال فلان يقضي بالحق أي بالعدل { فجعلناهم غُثَاء } شبههم في دمارهم بالغثاء وهو حميل السيل مما يلي واسودّ من الورق والعيدان { فَبُعْداً } فهلاكاً يقال بعد بعداً أو بعداً أي هلك وهو من المصادر المنصوبة بأفعال لا يستعمل إظهارها { لّلْقَوْمِ الظالمين } بيان لمن دعي عليه بالبعد نحو { هَيْتَ لَكَ } [ يوسف : 23 ]
