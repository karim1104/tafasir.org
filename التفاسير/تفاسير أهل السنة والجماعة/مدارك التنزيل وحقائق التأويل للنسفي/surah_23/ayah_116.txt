{ فتعالى الله } عن أن يخلق عبثاً { الملك الحق } الذي يحق له الملك لأن كل شيء منه وإليه ،   أو الثابت الذي لا يزول ولا يزول ملكه { لاَ إله إِلاَّ هُوَ رَبُّ العرش الكريم } وصف العرش بالكرم لأن الرحمة تنزل منه أو لنسبته إلى أكرم الأكرمين .   وقرىء شاذاً برفع { الكريم } صفة للرب تعالى .  <br />
