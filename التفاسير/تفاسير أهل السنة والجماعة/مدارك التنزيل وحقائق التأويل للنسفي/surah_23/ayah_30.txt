{ إِنَّ فِى ذَلِكَ } فيم فعل بنوح وقومه { لأَيَاتٍ } لعبراً ومواعظ { وَإِنْ } هي المخففة من المثقلة واللام هي الفارقة بين النافية وبينها والمعنى وإن الشأن والقصة { كُنَّا لَمُبْتَلِينَ } مصيبين قوم نوح ببلاء عظيم وعقاب شديد ،   أو مختبرين بهذه الآيات عبادنا لننظر من يعتبر ويذكر كقوله تعالى { وَلَقَدْ تركناها ءايَةً فَهَلْ مِن مُّدَّكِرٍ } [ القمر : 15 ] .
