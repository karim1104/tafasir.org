{ مِنَ الذين } بدل من { المشركين } بإعادة الجار { فَرَّقُواْ دِينَهُمْ } جعلوه أدياناً مختلفة لاختلاف أهوائهم { فارقوا } حمزة وعلي وهي قراءة علي رضي الله عنه أي تركوا دين الإسلام { وَكَانُواْ شِيَعاً } فرقاً كل واحدة تشايع إمامها الذي أضلها { كُلُّ حِزْبٍ } منهم { بِمَا لَدَيْهِمْ فَرِحُونَ } فرح بمذهبه مسرور يحسب باطله حقاً .  <br />
