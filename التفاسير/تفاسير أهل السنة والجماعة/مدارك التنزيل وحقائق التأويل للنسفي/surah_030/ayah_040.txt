ثم أشار إلى عجز آلهتهم فقال{ الله الذى خَلَقَكُمْ } مبتدأ وخبر { ثُمَّ رَزَقَكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ } أي : هو المختص بالخلق والرزق والإماتة والإحياء { هَلْ مِن شُرَكَائِكُمْ } أي : أصنامكم التي زعمتم أنهم شركاء لله { مَّن يَفْعَلُ مِن ذَلِكُمْ } أي : من الخلق والرزق والإماتة والإحياء { مِن شَىْءٍ } أي : شيئاً من تلك الأفعال فلم يجيبوا عجزاً فقال استبعاداً : { سُبْحَانَهُ وتعالى عَمَّا يُشْرِكُونَ } و «من » الأولى الثانية والثالثة كل واحدة منهن مستقلة بتأكيد لتعجيز شركائهم وتجهيل عبدتهم .  <br />
