{ وَإِذَا أَذَقْنَا الناس رَحْمَةً } أي نعمة من مطر أوسعة أوصحة { فَرِحُواْ بِهَا } بطروا بسببها { وَإِن تُصِبْهُمْ سَيّئَةٌ } أي بلاء من جدب أو ضيق أو مرض { بِمَا قَدَّمَتْ أَيْدِيهِمْ } بسبب شؤم معاصيهم { إِذَا هُمْ يَقْنَطُونَ } من الرحمة و { إذا } لمفاجأة جواب الشرط نابت عن الفاء لتآخيهما في التعقيب .  <br />
