{ وَإِذَا تتلى عَلَيْهِمْ ءاياتنا بَيّنَاتٍ } يعني القرآن { تَعْرِفُ فِى وُجُوهِ الذين كَفَرُواْ المنكر } الإنكار بالعبوس والكراهة والمنكر مصدر { يكادون يَسْطُونَ } يبطشون والسطو الوثب والبطش { بالذين يَتْلُونَ عَلَيْهِمْ ءاياتنا } هم النبي صلى الله عليه وسلم وأصحابه { قُلْ أَفَأُنَبّئُكُم بِشَرّ مّن ذلكم } من غيظكم على التالين وسطوكم عليهم أو مما أصابكم من الكراهة والضجر بسبب ما تلي عليكم { النار } خبر مبتدأ محذوف كأن قائلاً قال : ما هو ؟ فقيل : النار أي هو النار { وَعَدَهَا الله الذين كَفَرُواْ } استئناف كلام { وَبِئْسَ المصير } النار .  <br />
