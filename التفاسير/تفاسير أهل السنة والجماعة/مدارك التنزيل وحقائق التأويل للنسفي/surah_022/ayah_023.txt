ثم ذكر جزاء الخصم الآخر فقال :<br />
{ إِنَّ الله يُدْخِلُ الذين ءامَنُواْ وَعَمِلُواْ الصالحات جنات تَجْرِى مِن تَحْتِهَا الأنهار يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ } جمع أسورة جمع سوار { مِن ذَهَبٍ وَلُؤْلُؤاً } بالنصب : مدني وعاصم وعلي ويؤتون لؤلؤاً وبالجر : غيرهم عطفاً على { من ذهب } وبترك الهمزة الأولى في كل القرآن : أبو بكر وحماد { وَلِبَاسُهُمْ فِيهَا حَرِيرٌ } إبريسم .  <br />
