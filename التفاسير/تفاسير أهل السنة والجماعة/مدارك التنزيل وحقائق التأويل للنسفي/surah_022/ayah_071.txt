ثم أشار إلى جهالة الكفار لعبادتهم غير المستحق لها بقوله { وَيَعْبُدُونَ مِن دُونِ الله مَا لَمْ يُنَزّلْ بِهِ } { ينْزل } مكي وبصري { سلطانا } حجة وبرهاناً { وَمَا لَيْسَ لَهُمْ بِهِ عِلْمٌ } أي لم يتمسكوا في عبادتهم لها ببرهان سماوي من جهة الوحي ولا حملهم عليها دليل عقلي { وَمَا للظالمين مِن نَّصِيرٍ } وما للذين ارتكبوا مثل هذا الظلم من أحد ينصرهم ويصوب مذهبهم<br />
