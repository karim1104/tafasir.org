{ فَدَعَا رَبَّهُ } شاكياً قومه { أَنَّ هَؤُلآءِ قَوْمٌ مُّجْرِمُونَ } بأن هؤلاء أي دعا ربه بذلك .   قيل : كان دعاؤه : اللهم عجل لهم ما يستحقونه بإجرامهم .   وقيل : هو قوله { رَبَّنَا لاَ تَجْعَلْنَا فِتْنَةً لّلْقَوْمِ الظالمين } وقرىء { إِنَّ هَؤُلآء } بالكسر على إضمار القول أي فدعا ربه فقال إن هؤلاء<br />
