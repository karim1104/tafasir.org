{ رَحْمَةً مِّن رَّبِّكَ } مفعول له على معنى أنزلنا القرآن .   لأن من شأننا وعادتنا إرسال الرسل بالكتب إلى عبادنا لأجل الرحمة عليهم ،   أو تعليل لقوله { أَمْراً مّنْ عِنْدِنَا } ،   و { رَحْمَةً } مفعول به .   وقد وصف الرحمة بالإرسال كما وصفها به في قوله { وَمَا يُمْسِكْ فَلاَ مُرْسِلَ لَهُ مِن بَعْدِهِ } [ فاطر : 2 ] والأصل إنا كنا مرسلين رحمة منا فوضع الظاهر موضع الضمير إيذاناً بأن الربوبية تقتضي الرحمة على المربوبين { إِنَّهُ هُوَ السميع } لأقوالهم { العليم } بأحوالهم
