{ وَقَالُواْ الحمد للَّهِ الذى صَدَقَنَا وَعْدَهُ } أنجزنا ما وعدنا في الدنيا من نعيم العقبى { وَأَوْرَثَنَا الأرض } أرض الجنة وقد أورثوها أي ملكوها وجعلوا ملوكها وأطلق تصرفهم فيها كما يشاءون تشبيهاً بحال الوارث وتصرفه فيما يرثه واتساعه فيه { نَتَبَوَّأُ } حال { مِنَ الجنة حَيْثُ نَشَآءُ } أي يكون لكل واحد منهم جنة لا توصف سعة وزيادة على الحاجة فيتبوأ أي فيتخذ متبوأ ومقراً من جنته حيث يشاء { فَنِعْمَ أَجْرُ العاملين } في الدنيا الجنة<br />
