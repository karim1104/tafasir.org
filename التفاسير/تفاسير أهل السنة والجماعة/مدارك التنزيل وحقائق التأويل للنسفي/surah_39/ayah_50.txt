{ قَدْ قَالَهَا } هذه المقالة وهي قوله { إِنَّمَا أُوتِيتُهُ على عِلْمٍ } { الذين مِن قَبْلِهِمْ } أي قارون وقومه حيث قال : { إِنَّمَا أُوتِيتُهُ على عِلْمٍ عِندِى } [ القصص : 78 ] وقومه راضون بها ،   فكأنهم قالوها ،   ويجوز أن يكون في الأمم الخالية آخرون قائلون مثلها { فَمَآ أغنى عَنْهُمْ مَّا كَانُواْ يَكْسِبُونَ } من متاع الدنيا وما يجمعون منها .
