{ أَلَمْ تَرَ أَنَّ الله أَنزَلَ مِنَ السمآء مَآءً } يعني المطر .   وقيل : كل ماء في الأرض فهو من السماء ينزل منها إلى الصخرة ثم يقسمه الله { فَسَلَكَهُ } فادخله { يَنَابِيعَ فِى الأرض } عيوناً ومسالك ومجاري كالعروق في الأجساد .   و { يَنَابِيعَ } نصب على الحال أو على الظرف و { فِى الأرض } صفة ل { يَنَابِيعَ } .   { ثُمَّ يُخْرِجُ بِهِ } بالماء { زَرْعاً مُّخْتَلِفاً أَلْوَانُهُ } هيئاته من خضرة وحمرة وصفرة وبياض أو أصنافه من بن وشعير وسمسم وغير ذلك { ثُمَّ يَهِيجُ } يجف { فَتَرَاهُ مُصْفَرّاً } بعد نضارته وحسنه { ثُمَّ يَجْعَلُهُ حطاما } فتاتاً متكسراً ،   فالحطام ما تفتت وتكسر من النبت وغيره { إِنَّ فِى ذلك } في إنزال الماء وإخراج الزرع { لذكرى لأُِوْلِى الألباب } لتذكيراً وتنبيهاً على أنه لا بد من صانع حكيم ،   وأن ذلك كائن عن تقدير وتدبير لا عن إهمال وتعطيل<br />
