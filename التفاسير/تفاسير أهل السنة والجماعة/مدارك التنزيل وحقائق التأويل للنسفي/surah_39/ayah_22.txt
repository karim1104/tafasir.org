{ أَفَمَن شَرَحَ الله صَدْرَهُ } أي وسع صدره { للإسلام } فاهتدى ،   وسئل رسول الله صلى الله عليه وسلم عن الشرح فقال :  "  «إذا دخل النور القلب انشرح وانفسح » فقيل : فهل لذلك من علامة ؟ قال نعم الإنابة إلى دار الخلود والتجافي عن دار الغرور والاستعداد للموت قبل نزول الموت  "  { فَهُوَ على نُورٍ مِّن رَّبّهِ } بيان وبصيرة ،   والمعنى : أفمن شرح الله صدره فاهتدى كمن طبع على قلبه فقسا قلبه ؟ فحذف لأن قوله : { فَوَيْلٌ للقاسية قُلُوبُهُمْ } يدل عليه { مِّن ذِكْرِ الله } أي من ترك ذكر الله أو من أجل ذكر الله أي إذا ذكر الله عندهم أو آياته ازدادت قلوبهم قساوة كقوله : { فَزَادَتْهُمْ رِجْسًا إلى رِجْسِهِمْ } [ التوبة : 125 ]  .  { أُوْلَئِكَ فِى ضلال مُّبِينٍ } غواية ظاهرة .
