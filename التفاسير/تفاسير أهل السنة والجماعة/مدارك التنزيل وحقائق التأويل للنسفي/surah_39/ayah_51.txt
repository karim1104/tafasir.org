{ فأصابهم سَيِّئَاتُ مَا كَسَبُواْ } أي جزاء سيئات كسبهم ،   أو سمى جزاء السيئة سيئة للازدواج كقوله : { وَجَزَاء سَيّئَةٍ سَيّئَةٌ مّثْلُهَا } [ الشورى : 40 ] .   { والذين ظَلَمُواْ } كفروا { مِنْ هَؤُلآءِ } أي من مشركي قومك { سَيُصِيبُهُمْ سَيِّئَاتُ مَا كَسَبُواْ } أي سيصيبهم مثل ما أصاب أولئك ،   فقتل صناديدهم ببدر وحبس عنهم الرزق فقحطوا سبع سنين { وَمَا هُمْ بِمُعْجِزِينَ } بفائتين من عذاب الله ،
