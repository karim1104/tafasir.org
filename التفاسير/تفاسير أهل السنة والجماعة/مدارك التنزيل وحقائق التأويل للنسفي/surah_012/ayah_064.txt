{ قَالَ هَلْ امَنُكُمْ عَلَيْهِ إِلاَّ كَمَا أَمِنتُكُمْ على أَخِيهِ مِن قَبْلُ } يعني أنكم قلتم في يوسف { أرسله معنا غداً يرتع ويلعب وإناله لحافظون } كما تقولونه في أخيه ثم خنتم بضمانكم فما يأمنني من مثل ذلك ؟ ثم قال { فالله خَيْرٌ حافظا } كوفي غير أبي بكر .   فتوكل على الله فيه ودفعه إليهم وهو حال أو تمييز ،   ومن قرأ { حِفظا } ً فهو تمييز لا غير .   { وَهُوَ أَرْحَمُ الرحمين } فأرجو أن ينعم عليّ بحفظه ولا يجمع عليّ مصيبتين قال كعب : لما قال { فالله خير حفظاً } قال الله تعالى وعزتي وجلالي لأردن عليك كليهما .  <br />
