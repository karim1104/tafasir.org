{ مَا تَعْبُدُونَ } خطاب لهما ولمن كان على دينهما من أهل مصر { مِن دُونِهِ } من دون الله { إلا أسماء سميتموها أنتم وآباؤكم } أي سميتم مالا يستحق الإلهية آلهة ثم طفقتم تعبدونها فكأنكم لا تعبدون إلا أسماء لا مسميات لها ،   ومعنى { سميتموها } سميتم بها يقال : سميته زيداً وسميته يزيد { مَّا أَنزَلَ الله بِهَا } بتسميتها { مّن سلطان } حجة { إِنِ الحكم } في أمر العبادة والدين { إلاَ لِلَّهِ } ثم بين ما حكم به فقال { أَمَرَ أَلاَّ تَعْبُدُواْ إِلاَّ إِيَّاهُ ذلك الدين القيم } الثابت الذي دلت عليه البراهين { ولكن أَكْثَرَ الناس لاَ يَعْلَمُونَ } وهذا يدل على أن العقوبة تلزم العبد وإن جهل إذا أمكن له العلم بطريقه .  <br />
