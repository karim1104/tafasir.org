{ وَقَالَ الذى نَجَا } من القتل { مِنْهُمَا } من صاحبي السجن { وادكر } بالدال هو الفصيح وأصله «اذتكر » فأبدلت الذال دالاً والتاء دالاً وأدغمت الأولى في الثانية ليتقارب الحرفين .   وعن الحسن : «واذكر » ووجهه أنه قلب التاء ذالاً وأدغم أي تذكر يوسف وما شاهد منه { بَعْدَ أُمَّةٍ } بعد مدة طويلة وذلك أنه حين استفتى الملك في رؤياه وأعضل على الملك تأويلها تذكر الناجي يوسف وتأويله رؤياه ورؤيا صاحبه وطلبه إليه أن يذكره عندالملك { أَنَاْ أُنَبّئُكُمْ بِتَأْوِيلِهِ } أنا أخبركم به عمن عنده علمه { فَأَرْسِلُونِ } وبالياء يعقوب أي فابعثوني إليه لأسأله <br />
