{ وَمَا أَرْسَلْنَا مِن قَبْلِكَ إِلاَّ رِجَالاً } لا ملائكة لأنهم كانوا يقولون لو شاء ربنا لأنزل ملائكة ،   أو ليست فيهم امرأة { نُوحِى } بالنون حفص { إِلَيْهِمْ مّنْ أَهْلِ القرى } لأنهم أعلم وأحلم وأهل البوادي فيهم الجهل والجفاء { أَفَلَمْ يَسِيرُواْ فِى الأرض فَيَنظُرُواْ كَيْفَ كَانَ عاقبة الذين مِن قَبْلِهِمْ وَلَدَارُ الآخرة } أي ولدار الساعة الآخرة { خَيْرٌ لّلَّذِينَ اتقوا } الشرك وآمنوا به { أَفَلاَ تَعْقِلُونَ } وبالياء : مكي وأبو عمرو وحمزة وعلي .  <br />
