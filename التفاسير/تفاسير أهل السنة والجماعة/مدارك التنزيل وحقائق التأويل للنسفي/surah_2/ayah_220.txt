{ وَيَسْئَلُونَكَ عَنِ اليتامى قُلْ إصْلاَحٌ لَّهُمْ خَيْرٌ } أي مداخلتهم على وجه الإصلاح لهم ولأموالهم خير من مجانبتهم { وَإِن تُخَالِطُوهُمْ } وتعاشروهم ولم تجانبوهم { فَإِخوَانُكُمْ } فهم إخوانكم في الدين ومن حق الأخ أن يخالط أخاه { والله يَعْلَمُ المفسد } لأموالهم { مِنَ المصلح } لها فيجازيه على حسب مداخلته فاحذروه ولا تتحروا غير الإصلاح { وَلَوْ شَاءَ الله } إعناتكم { لأَعْنَتَكُمْ } لحملكم على العنت وهو المشقة وأحرجكم فلم يطلق لكم مداخلتهم { إِنَّ الله عَزِيزٌ } غالب يقدر على أن يعنت عباده ويحرجهم { حَكِيمٌ } لا يكلف إلا وسعهم وطاقتهم .
