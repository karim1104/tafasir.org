{ أَفَتَطْمَعُونَ } الخطاب لرسول الله والمؤمنين .   { أَن يُؤْمِنُواْ لَكُمْ } أن يؤمنوا لأجل دعوتكم ويستجيبوا لكم كقوله تعالى : { فَئَامَنَ لَهُ لُوطٌ } [ العنكبوت : 26 ] ،   يعني اليهود .   { وَقَدْ كَانَ فَرِيقٌ مّنْهُمْ } طائفة فيمن سلف منهم .   { يَسْمَعُونَ كلام الله } أي التوراة .   { ثُمَّ يُحَرِّفُونَهُ } كما حرفوا صفة رسول الله صلى الله عليه وسلم وآية الرجم .   { مِن بَعْدِِ مَا عَقَلُوهُ } من بعد ما فهموه وضبطوه بعقولهم .   { وَهُمْ يَعْلَمُونَ } أنهم كاذبون مفترون .   والمعنى إن كفر هؤلاء وحرفوا فلهم سابقة في ذلك .
