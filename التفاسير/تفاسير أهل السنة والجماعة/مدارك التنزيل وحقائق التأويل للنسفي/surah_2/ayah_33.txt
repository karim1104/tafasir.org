{ قَالَ يَاءَادَمُ أَنبِئْهُم بِأَسْمَائِهِمْ فَلَمَّا أَنبَأَهُم بِأَسْمَائِهِم } سمى كل شيء باسمه .   { قَالَ أَلَمْ أَقُل لَّكُمْ إِنِي أَعْلَمُ غَيْبَ السموات والأرض } أي أعلم ما غاب فيهما عنكم مما كان ومما يكون .   { وَأَعْلَمُ مَا تُبْدُونَ } تظهرون .   { وَمَا كُنتُمْ تَكْتُمُونَ } تسرون .  <br />
