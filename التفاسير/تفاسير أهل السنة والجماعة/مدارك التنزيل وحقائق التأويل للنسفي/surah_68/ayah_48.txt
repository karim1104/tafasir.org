{ فاصبر لِحُكْمِ رَبّكَ } وهو إمهالهم وتأخير نصرتك عليهم لأنهم وإن أمهلوا لم يهملوا { وَلاَ تَكُن كصاحب الحوت } كيونس عليه السلام في العجلة والغضب على القوم حتى لا تبتلى ببلائه .   والوقف على الحوت لأن «إذ » ليس بظرف لما تقدمه ،   إذ النداء طاعة فلا ينهى عنه بل مفعول محذوف أي اذكر { إِذْ نادى } دعا ربه في بطن الحوت ب { لاَّ إله إِلاَّ أَنتَ سبحانك إِنّى كُنتُ مِنَ الظالمين } [ الأنبياء : 87 ] { وَهُوَ مَكْظُومٌ } مملوء غيظاً من كظم السقاء إذا
