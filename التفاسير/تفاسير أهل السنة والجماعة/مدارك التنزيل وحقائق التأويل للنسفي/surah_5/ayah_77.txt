{ قل ياأهل الكتاب لا تغلوا في دينكم } الغلو مجاوزة الحد ،   فغلو النصارى رفعه فوق قدره باستحقاق الألوهية ،   وغلو اليهود وضعه عن استحقاق النبوة { غير الحقِّ } صفة لمصدر محذوف أي غلوا غير الحق يعني غلواً باطلاً { ولا تتّبعوآ أهوآءَ قومٍ قد ضلُّوا من قبلُ } أي أسلافكم وأئمتكم الذين كانوا على الضلال قبل مبعث النبي صلى الله عليه وسلم { وأضلُّوا كثيراً } ممن تابعهم { وضلُّوا } لما بعث رسول الله صلى الله عليه وسلم { عن سوآءِ السَّبِيلِ } حين كذبوه وحسدوه وبغوا عليه .  <br />
