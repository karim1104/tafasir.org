ونزل فيمن تعاطى شيئاً من الخمر والميسر قبل التحريم .  { لَيْسَ عَلَى الذين ءَامَنُواْ وَعَمِلُواْ الصالحات جُنَاحٌ فِيمَا طَعِمُواْ } أي شربوا من الخمر وأكلوا من مال القمار قبل تحريمهما { إِذَا مَا اتقوا } الشرك { وَءامَنُواْ } بالله { وَعَمِلُواْ الصالحات } بعد الإيمان { ثُمَّ اتَّقَواْ } الخمر والميسر بعد التحريم { وَءَامَنُواْ } بتحريمهما { ثُمَّ اتَّقَواْ } سائر المحرمات ،   أو الأول عن الشرك والثاني عن المحرمات والثالث عن الشبهات { وَأَحْسَنُواْ } إلى الناس { والله يُحِبُّ المحسنين } .  <br />
