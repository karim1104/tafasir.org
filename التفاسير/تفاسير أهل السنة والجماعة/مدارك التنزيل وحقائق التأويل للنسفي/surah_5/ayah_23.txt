{ قَالَ رَجُلاَنِ } كالب ويوشع { من الّذين يخافونَ } الله ويخشونه كأنه قيل رجلان من المتقين وهو في محل الرفع صفة ل «رجلان » وكذا { أَنْعَمَ الله عَلَيْهِمَا } بالخوف منه { ادخلوا عَلَيْهِمُ الباب } أي باب المدينة { فَإِذَا دَخَلْتُمُوهُ فَإِنَّكُمْ غالبون } أي انهزموا وكانت الغلبة لكم ،   وإنما علما ذلك بإخبار موسى عليه السلام { وَعَلَى الله فَتَوَكَّلُواْ إِن كُنتُم مُّؤْمِنِينَ } إذ الإيمان به يقتضي التوكل عليه وهو قطع العلائق وترك التملق للخلائق<br />
