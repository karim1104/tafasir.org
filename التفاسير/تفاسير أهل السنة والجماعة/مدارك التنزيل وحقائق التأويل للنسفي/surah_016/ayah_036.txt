{ وَلَقَدْ بَعَثْنَا فِى كُلِّ أُمَّةٍ رَّسُولاً أَنِ اعبدوا الله } بأن وحدوه { واجتنبوا الطاغوت } الشيطان يعني طاعته { فَمِنْهُم مَّنْ هَدَى الله } لاختيارهم الهدى { وَمِنْهُمْ مَّنْ حَقَّتْ عَلَيْهِ الضلالة } أي لزمته لاختياره إياها { فَسِيرُواْ فِى الأرض فانظروا كَيْفَ كَانَ عاقبة المكذبين } حيث أهلكهم الله وأخلى ديارهم عنهم .  <br />
