{ إِنَّمَا يَفْتَرِي الكذب } على الله { الذين لاَ يُؤْمِنُونَ بآيات الله } ،   أي : إنما يليق افتراء الكذب بمن لا يؤمن ؛ لأنه لا يترقب عقاباً عليه ،   وهو رد لقولهم : { إنما أنت مفتر } .   { وَأُوْلئِكَ } ،   إشارة إلى : { الذين لايؤمنون } ،   أي : وأولئك { هُمُ الكاذبون } على الحقيقة الكاملون في الكذب ؛ لأن تكذيب آيات الله أعظم الكذب ،   أو وأولئك هم الكاذبون في قولهم : { إنما أنت مفتر } .  <br />
