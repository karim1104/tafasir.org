بِالْبَيِّنَاتِ وَالزُّبُرِ } أي بالمعجزات والكتب والباء يتعلق ب { رجالاً } صفة له أي رجالاً ملتبسين بالبينات ،   أو بأرسلنا مضمراً كأنه قيل : بم أرسل الرسل ؟ فقيل : بالبينات ،   أو ب { يوحي } أي يوحي إليهم بالبينات أو ب { لا تعلمون } ،   وقوله : { فاسألوا أهل الذكر } اعتراض على الوجوه المتقدمة وقوله { وَأَنزَلْنَا إِلَيْكَ الذكر } القرآن { لِتُبَيِّنَ لِلنَّاسِ مَا نُزِّلَ إِلَيْهِمْ } في الذكر مما أمروا به ونهوا عنه ووعدوا به وأوعدوا { وَلَعَلَّهُمْ يَتَفَكَّرُونَ } في تنبيهاته فينتبهوا<br />
