{ فَإِنَّهُمْ } أي الأصنام { عَدُوٌّ لِى } العدو والصديق يجيئان في معنى الوحدة والجماعة يعني لو عبدتهم لكانوا أعداء لي في يوم القيامة كقوله { سَيَكْفُرُونَ بعبادتهم وَيَكُونُونَ عَلَيْهِمْ ضِدّاً } [ مريم : 82 ] وقال الفراء : هو من المقلوب أي فإني عدوهم .   وفي قوله { عدو لي } دون «لكم » زيادة نصح ليكون أدعى لهم إلى القبول ،   ولو قال «فإنهم عدو لكم » لم يكن بتلك المثابة { إِلاَّ رَبَّ العالمين } استثناء منقطع لأنه لم يدخل تحت الأعداء كأنه قال : لكن رب العالمين .
