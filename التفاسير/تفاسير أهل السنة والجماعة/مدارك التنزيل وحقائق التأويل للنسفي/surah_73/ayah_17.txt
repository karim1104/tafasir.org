{ فَكَيْفَ تَتَّقُونَ إِن كَفَرْتُمْ يَوْماً } هو مفعول { تَتَّقُونَ } أي كيف تتقون عذاب يوم كذا إن كفرتم ؟ أو ظرف أي فكيف لكم التقوى في يوم القيامة إن كفرتم في الدنيا ؟ أو منصوب ب { كَفَرْتُمْ } على تأويل جحدتم أي كيف تتقون الله وتخشونه إن جحدتم يوم القيامة والجزاء لأن تقوى الله خوف عقابه { يَجْعَلُ الولدان } صفة ل { يَوْماً } والعائد محذوف أي فيه { شِيباً } من هوله وشدته وذلك حين يقال لآدم عليه السلام : قم فابعث بعث النار من ذريتك وهو جمع أشيب .   وقيل : هو على التمثيل للتهويل يقال لليوم الشديد : يوم يشيب نواصي الأطفال .  <br />
