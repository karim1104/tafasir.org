{ كَدَأْبِ ءَالِ فِرْعَوْنَ } تكرير للتأكيد ،   أو لأن في الأولى الأخذ بالذنوب بلا بيان ذلك ،   وهنا بين أن ذلك هو الإهلاك والاستئصال { والذين مِن قَبْلِهِمْ كَذَّبُواْ بئايات رَبِّهِمْ } وفي قوله { بآيات رَبِّهِمْ } زيادة دلالة على كفران النعم وجحود الحق { فأهلكناهم بِذُنُوبِهِمْ وَأَغْرَقْنَا ءَالَ فِرْعَونَ } بماء البحر { وَكُلٌّ } وكلهم من غرقى القبط وقتلى قريش { كَانُواْ ظالمين } أنفسهم بالكفر والمعاصي .  <br />
