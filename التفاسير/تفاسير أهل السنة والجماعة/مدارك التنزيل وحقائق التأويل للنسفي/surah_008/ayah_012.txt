{ إِذْ يُوحِى } بدل ثالث من { إِذْ يَعِدُكُمُ } أو منصوب ب { يُثَبّتُ } { رَبُّكَ إِلَى الملئكة أَنّي مَعَكُمْ } بالنصر { فَثَبّتُواْ الذين ءامَنُواْ } بالبشرى وكان الملك يسير أمام الصف في صورة رجل ويقول : أبشروا فإن الله ناصركم { سَأُلْقِى فِي قُلُوبِ الذين كَفَرُواْ الرعب } هو امتلاء القلب من الخوف و { الرعب } شامي وعلي { فاضربوا } أمر للمؤمنين أو الملائكة ،   وفيه دليل على أنهم قاتلوا { فَوْقَ الأعناق } أي أعالي الأعناق التي هي المذابح تطييراً للرؤوس ،   أو أراد الرؤوس لأنها فوق الأعناق يعني ضرب الهام { واضربوا مِنْهُمْ كُلَّ بَنَانٍ } هي الأصابع يريد الأطراف ،   والمعنى فاضربوا المقاتل والشوي لأن الضرب إما أن يقع على مقتل أو غير مقتل ،   فأمرهم أن يجمعوا عليهم النوعين<br />
