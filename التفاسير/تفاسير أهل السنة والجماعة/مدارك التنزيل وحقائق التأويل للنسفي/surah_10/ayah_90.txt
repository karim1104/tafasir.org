{ وَجَاوَزْنَا بِبَنِى إسراءيل البحر } هو دليل لنا على خلف الأفعال { فَأَتْبَعَهُمْ فِرْعَوْنُ وَجُنُودُهُ } فلحقهم .   يقال : تبعته حتى أتبعته { بَغِيّاً } تطاولاً { وَعَدْوًا } ظلماً وانتصباً على الحال أو على المفعول له { حتى إِذَا أَدْرَكَهُ الغرق } ولا وقف عليه لأن { قَالَ ءامَنتُ } جواب { إذا } - { أَنَّهُ } - إنه حمزة وعلي على الاستئناف بدل من { آمنت } وبالفتح غيرهما على حذف الباء التي هي صلة الإيمان { لا إله إِلاَّ الذى ءامَنَتْ بِهِ بَنواْ إسراءيل وَأَنَاْ مِنَ المسلمين } وفيه دليل على أن الإيمان والإسلام واحد حيث قال : { آمنت } ثم قال : { وأنا من المسلمين } كرر فرعون المعنى الواحد ثلاث مرات في ثلاث عبارات حرصاً على القبول ثم لم يقبل منه حيث أخطأ وقته وكانت المرة الواحدة تكفي في حالة الاختيار<br />
