{ وَمَا يَتَّبِعُ أَكْثَرُهُمْ } في قولهم للأصنام إنها آلهة وإنها شفعاء عند الله والمراد بالأكثر الجميع { إِلاَّ ظَنّا } بغير دليل وهو اقتداؤهم بأسلافهم ظناً منهم إنهم مصيبون { إَنَّ الظن لاَ يُغْنِي مِنَ الحق } وهو العلم { شَيْئاً } في موضع المصدر أي إغناء { إِنَّ الله عَلَيمٌ بِمَا يَفْعَلُونَ } من اتباع الظن وترك الحق .  <br />
