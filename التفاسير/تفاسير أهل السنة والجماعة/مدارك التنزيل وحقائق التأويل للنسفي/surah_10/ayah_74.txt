{ ثُمَّ بَعَثْنَا مِن بَعْدِهِ } من بعد نوح عليه السلام { رُسُلاً إلى قَوْمِهِمْ } أي هوداً وصالحاً وإبراهيم ولوطاً وشعباً { فَجَآءُوهُم بالبينات } بالحجج الواضحة المثبتة لدعواهم { فَمَا كَانُواْ لِيُؤْمِنُواْ } فأصروا على الكفر بعد المجيء { بِمَا كَذَّبُواْ بِهِ مِن قَبْلُ } من قبل مجيئهم ،   يريد أنهم كانوا قبل بعثة الرسل أهل جاهلية مكذبين بالحق فما وقع فصل بين حالتيهم بعد بعثة الرسل وقبلها كأن لم يبعث إليهم أحد { كَذَلِكَ نَطْبَعُ } من ذلك الطبع نختم { على قُلوبِ المعتدين } المجاوزين الحد في التكذيب<br />
