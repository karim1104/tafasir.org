{ وَيَقُولُونَ لَوْلاَ أُنزِلَ عَلَيْهِ ءايَةٌ مّن رَّبّهِ } أي آية من الآيات التي اقترحوها { فَقُلْ إِنَّمَا الغيب للَّهِ } أي هو المختص بعلم الغيب فهو العالم بالصارف عن إنزال الآيات المقترحة لا غير { فانتظروا } نزول ما اقترحتموه { إِنِّي مَعَكُمْ مِّنَ الْمُنتَظِرينَ } لما يفعل الله بكم لعنادكم وجحودكم الآيات<br />
