{ قُلْ أَرَءَيْتُمْ شُرَكَآءَكُمُ } آلهتكم التي أشركتموهم في العباد { الذين تَدْعُونَ مِن دُونِ الله أَرُونِى مَاذَا خَلَقُواْ مِنَ الأرض } { أَرُونِىَ } بدل من { أَرَءَيْتُمْ } أخبروني كأنه قيل : أخبروني عن هؤلاء الشركاء وعما استحقوا به الشركة ،   أروني أي جزء من أجزاء الأرض استبدوا بخلقه دون الله ؟ { أَمْ لَهُمْ شِرْكٌ فِى السماوات } أم لهم مع الله شركة في خلق السماوات { أَمْ ءاتيناهم كتابا فَهُمْ على بينات مِّنْهُ } أي معهم كتاب من عند الله ينطق أنهم شركاؤه فهم على حجة وبرهان من ذلك الكتاب .   { بينات } علي وابن عامر ونافع وأبو بكر { بَلْ إِن يَعِدُ } ما يعد { الظالمون بَعْضُهُم } بدل من { الظالمون } وهم الرؤساء { بَعْضًا } أي الأتباع { إِلاَّ غُرُوراً } هو قولهم { هَؤُلاء شفعاؤنا عِندَ الله } [ يونس : 18 ] .
