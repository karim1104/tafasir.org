{ وَقَالَ الذين كَفَرُواْ لِلَّذِينَ ءَامَنُواْ } أي لأجلهم وهو كلام كفار مكة قالوا : إن عامة من يتبع محمداً السقاط يعنون الفقراء مثل عمار وصهيب وابن مسعود { لَوْ كَانَ خَيْراً مَّا سَبَقُونَا إِلَيْهِ } لو كان ما جاء به محمد خيراً ما سبقنا إليه هؤلاء { وَإِذْ لَمْ يَهْتَدُواْ بِهِ } العامل في «إذ » محذوف لدلالة الكلام عليه تقديره وإذ لم يهتدوا به ظهر عنادهم وقوله { فَسَيَقُولُونَ هذا إِفْكٌ قَدِيمٌ } مسبب عنه وقولهم { إِفْكٌ قَدِيمٌ } أي كذب متقادم كقولهم { أساطير الأولين } [ الأنعام : 25 ]
