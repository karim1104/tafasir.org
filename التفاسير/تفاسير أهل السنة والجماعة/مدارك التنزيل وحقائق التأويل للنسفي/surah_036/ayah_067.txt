{ وَلَوْ نَشَآءُ لمسخناهم } قردة أو خنازير أو حجارة { على مكانتهم } { على مكاناتهم } أبو بكر وحماد .   والمكانة والمكان واحد كالمقامة والمقام أي لمسخناهم في منازلهم حيث يجترحون المآثم { فَمَا استطاعوا مُضِيّاً وَلاَ يَرْجِعُونَ } فلم يقدروا على ذهاب ولا مجيء أو مضياً أمامهم ولا يرجعون خلفهم .  <br />
