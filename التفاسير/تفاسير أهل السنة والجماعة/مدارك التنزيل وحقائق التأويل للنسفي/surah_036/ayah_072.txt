{ وذللناها لَهُمْ } وصيرناها منقادة لهم وإلا فمن كان يقدر عليها لولا تذليله تعالى وتسخيره لها ،   ولهذا ألزم الله سبحانه الراكب أن يشكر هذه النعمة ويسبح بقوله { سبحان الذى سَخَّرَ لَنَا هذا وَمَا كُنَّا لَهُ مُقْرِنِينَ } [ الزخرف : 13 ] { فَمِنْهَا رَكُوبُهُمْ } وهو ما يركب { وَمِنْهَا يَأْكُلُونَ } أي سخرناها لهم ليركبوا ظهرها ويأكلوا لحمها
