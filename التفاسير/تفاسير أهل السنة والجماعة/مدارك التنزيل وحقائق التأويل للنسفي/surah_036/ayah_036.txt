{ سبحان الذى خَلَق الأزواج } :الأصناف { كُلَّهَا مِمَّا تُنبِتُ الأرض } من النخيل والشجر والزرع والثمر { وَمِنْ أَنفُسِهِمْ }  :الأولاد ذكوراً وإناثاً { وَمِمَّا لاَ يَعْلَمُونَ }  :ومن أزواج لم يطلعهم الله عليها ولا توصلوا إلى معرفتها ،   ففي الأودية والبحار أشياء لا يعلمها الناس .  <br />
