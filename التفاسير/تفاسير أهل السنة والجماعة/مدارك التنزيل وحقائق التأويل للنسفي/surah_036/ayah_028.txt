{ وَمَا أَنزَلْنَا } «ما » نافيه { على قَوْمِهِ } قوم حبيب { مِن بَعْدِهِ } أي  :من بعد قتله أو رفعه { مِن جُندٍ مِّنَ السمآء } لتعذيبهم { وَمَا كُنَّا مُنزِلِينَ } :وما كان يصح في حكمتنا أن ننزل في إهلاك قوم حبيب جنداً من السماء ،   وذلك لأن الله تعالى أجرى هلاك كل قوم على بعض الوجوه دون بعض لحكمة اقتضت ذلك .  <br />
