{ والشمس تَجْرِى } :وآية لهم الشمس تجري { لِمُسْتَقَرٍّ لَّهَا } : لحد لها موقت مقدر تنتهي إليه من فلكها في آخر السنة ،   شبه بمستقر المسافر إذا قطع مسيره أو لحد لها من مسيرها كل يوم في مرائي عيوننا وهو المغرب ،   أو لانتهاء أمرها عند انقضاء الدنيا { ذلك } الجري على ذلك التقدير والحساب الدقيق { تَقْدِيرُ العزيز } :الغالب بقدرته على كل مقدور { العليم } بكل معلوم<br />
