{ وَرَفَعْنَا لَكَ ذِكْرَكَ } ورفع ذكره أن قرن ذكر الله في كلمة الشهادة والأذان والإقامة والخطب والتشهد وفي غير موضع من القرآن : { أَطِيعُواْ الله وَأَطِيعُواْ الرسول } [ محمد : 33 ] [ التغابن : 12 ] .   { وَمَن يُطِعِ الله وَرَسُولَهُ } [ النساء : 13 ] .   { والله وَرَسُولُهُ أَحَقُّ أَن يُرْضُوهُ } [ التوبة : 62 ] .   وفي تسميته رسول الله ونبي الله ومنه ذكره في كتب الأولين .   وفائدة لك ما عرف في طريقة الإبهام والإيضاح لأنه يفهم بقوله : { أَلَمْ نَشْرَحْ لَكَ } أن ثم مشروحاً ،   ثم أوضح بقوله { صَدْرَكَ } ما علم مبهماً وكذلك { لَكَ ذِكْرَكَ } ،   و { عَنكَ وِزْرَكَ } .
