يَحْذَرُ المنافقون } خبر بمعنى الأمر أي ليحذر المنافقون { أَن تُنَزَّلَ عَلَيْهِمْ سُورَةٌ } { تُنَزَّلَ } بالتخفيف : مكي وبصري { تُنَبِّئُهُمْ بِمَا فِي قُلُوبِهِم } من الكفر والنفاق ،   والضمائر للمنافقين لأن السورة إذا نزلت في معناهم فهي نازلة عليهم دليله { قُلِ استهزءوا } ،   أو الأولان للمؤمنين ،   والثالث للمنافقين ،   وصح ذلك لأن المعنى يقود إليه { قُلِ استهزءوا } أمر تهديد { إِنَّ الله مُخْرِجٌ مَّا تَحْذَرُونَ } مظهر ما كنتم تحذرونه أي تحذرون إظهاره من نفاقكم ،   وكانوا يحذرون أن يفضحهم الله بالوحي فيهم وفي استهزائهم بالإسلام وأهله حتى قال بعضهم : وددت أني قدّمت فجلدت مائة وأنه لا ينزل فينا شيء يفضحنا<br />
