{ وَإِذَا أُنزِلَتْ سُورَةٌ نَّظَرَ بَعْضُهُمْ إلى بَعْضٍ } تغامزوا بالعيون إنكاراً للوحي وسخرية به قائلين { هَلْ يَرَاكُمْ مِّنْ أَحَدٍ } من المسلمين لننصرف فإنا لا نصبر على استماعه ويغلبنا الضحك فنخاف الافتضاح بينهم ،   أو إذا ما أنزلت سورة في عيب المنافقين أشار بعضهم إلى بعض هل يراكم من أحد إن قمتم من حضرته عليه السلام { ثُمَّ انصرفوا } عن حضرة النبي عليه السلام مخافة الفضيحة { صَرَفَ الله قُلُوبَهُم } عن فهم القرآن { بِأَنَّهُمْ } بسبب أنهم { قَوْمٌ لاَّ يَفْقَهُونَ } لا يتدبرون حتى يفقهوا<br />
