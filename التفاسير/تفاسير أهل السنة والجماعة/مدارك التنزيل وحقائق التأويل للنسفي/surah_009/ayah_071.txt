{ والمؤمنون والمؤمنات بَعْضُهُمْ أَوْلِيَاء بَعْضٍ } في التناصر والتراحم { يَأْمُرُونَ بالمعروف } بالطاعة والإيمان { وَيَنْهَوْنَ عَنِ المنكر } عن الشرك والعصيان { وَيُقِيمُونَ الصلاة وَيُؤْتُونَ الزكواة وَيُطِيعُونَ الله وَرَسُولَهُ أُوْلَئِكَ سَيَرْحَمُهُمُ الله } السين مفيدة وجود الرحمة لا محالة فهي تؤكد الوعد كما تؤكد الوعيد في «سأنتقم منك يوماً » { إِنَّ الله عزيزٌ } غالب على كل شيء قادر عليه فهو يقدر على الثواب والعقاب { حَكِيمٌ } واضع كلا موضعه<br />
