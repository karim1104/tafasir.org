{ لَّيْسَ عَلَى الضعفاء } الهرمى والزمنى { وَلاَ على المرضى وَلاَ عَلَى الذين لاَ يَجِدُونَ مَا يُنفِقُونَ } هم الفقراء من مزينة وجهينة وبني عذرة { حَرَجٌ } إثم وضيق في التأخر { إِذَا نَصَحُواْ الله وَرَسُولُهِ } بأن آمنوا في السر والعلن وأطاعوا كما يفعل الناصح بصاحبه { مَا عَلَى المحسنين } المعذورين النّاصحين { مّن سَبِيلٍ } أي لا جناح عليهم ولا طريق للعتاب عليهم { والله غَفُورٌ } يغفر تخلفهم { رَّحِيمٌ } بهم<br />
