{ قَالَ ءامَنتُمْ لَهُ قَبْلَ أَنْ ءاذَنَ لَكُمْ } بذلك { إِنَّهُ لَكَبِيرُكُمُ الذى عَلَّمَكُمُ السحر } وقد تواطأتم على أمر ومكر { فَلَسَوْفَ تَعْلَمُونَ } وبال ما فعلتم .   ثم صرح فقال { لأقَطّعَنَّ أَيْدِيَكُمْ وَأَرْجُلَكُمْ مّنْ خِلاَفٍ } من أجل خلاف ظهر منكم { وَلأصَلّبَنَّكُمْ أَجْمَعِينَ } كأنه أراد به ترهيب العامة لئلا يتبعوهم في الإيمان<br />
