{ وَهُوَ الذى خَلَقَ مِنَ الماء } أي النطفة { بَشَرًا } إنساناً { فَجَعَلَهُ نَسَباً وَصِهْراً } أراد تقسيم البشر قسمين : ذوي نسب أي ذكوراً ينسب إليهم فيقال فلان بن فلان وفلانة بنت فلان ،   وذوات صهر أي إناثاً يصاهر بهن كقوله تعالى { فَجَعَلَ مِنْهُ الزوجين الذكر والأنثى } [ القيامة : 39 ] { وَكَانَ رَبُّكَ قَدِيراً } حيث خلق من النطفة الواحدة بشراً نوعين ذكراً وأنثى .   وقيل : فجعله نسباً أي قرابة وصهراً مصاهرة يعني الوصلة بالنكاح من باب الأنساب لأن التواصل يقع بها وبالمصاهرة لأن التوالد يكون بهما
