{ فأخذه الله نكال الآخرة } عاقبة الله عقوبة الآخرة والنكال بمعنى التنكيل كالسلام بمعنى التسليم .   ونصبه على المصدر لأن أخذ بمعنى نكل كأنه قيل : نكل الله به نكال الآخرة أي الإحراق { والأولى } أي الإغراق ،   أو نكال كلمتيه الآخرة وهي { أنا ربكم الأعلى } والأولى وهي { ما علمت لكم من إله غيري } [ القصص : 38 ] وبينهما أربعون سنة أو ثلاثون أو عشرون
