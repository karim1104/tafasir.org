{ هذا يَوْمُ الفصل } يوم القضاء والفرق بين فرق الهدى والضلال { الذي كُنتُمْ بِهِ تُكَذِّبُونَ } ثم يحتمل أن يكون { هذا يَوْمُ الدين } إلى قوله { احشروا } من كلام الكفرة بعضهم مع بعض ،   وأن يكون من كلام الملائكة لهم ،   وأن يكون { ياويلنا هذا يَوْمُ الدين } من كلام الكفرة و { هذا يَوْمُ الفصل } من كلام الملائكة جواباً لهم .  <br />
