{ ثُمَّ إِنَّ لَهُمْ عَلَيْهَا } على أكلها { لَشَوْباً } لخلطاً ولمزاجاً { مِّنْ حَمِيمٍ } ماء حار يشوي وجوههم ويقطع أمعاءهم كما قال في صفة شراب أهل الجنة { وَمِزَاجُهُ مِن تَسْنِيمٍ } [ المطففين : 27 ] والمعنى ثم إنهم يملئون البطون من شجرة الزقوم وهو حار يحرق بطونهم ويعطشهم فلا يسقون إلا بعد مليء تعذيباً لهم بذلك العطش ثم يسقون ما هو أحر وهو الشراب المشوب بالحميم .
