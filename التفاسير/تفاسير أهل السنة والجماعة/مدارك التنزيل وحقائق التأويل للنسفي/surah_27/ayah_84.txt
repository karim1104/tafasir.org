{ حتى إِذَا جَآءُو } حضروا موقف الحساب والسؤال { قَالَ } لهم تعالى تهديداً { أكذبتم بآياتي } المنزلة على رسلي { وَلَمْ تُحِيطُواْ بِهَا عِلْماً } الواو للحال كأنه قال : أكذبتم بآياتي بادىء الرأي من غير فكر ولا نظر يؤدي إلى إحاطة العلم بكنهها وأنها حقيقة بالتصديق أو بالتكذيب { أَمَّاذا كُنْتُمْ تَعْمَلُونَ } حيث لم تتفكروا فيها فإنكم لم تخلقوا عبثاً<br />
