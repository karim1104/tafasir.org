أَمَّن يَبْدَأُ الخلق } ينشيء الخلق { ثُمَّ يُعِيدُهُ } وإنما قيل لهم { ثُمَّ يُعِيدُهُ } وهم منكرون للإعادة لأنه أزيحت علتهم بالتمكين من المعرفة والإقرار فلم يبق لهم عذر في الإنكار { وَمَن يَرْزُقُكُم مّنَ السماء } أي المطر { والأرض } أي ومن الأرض النبات { أءلاه مَّعَ الله قُلْ هَاتُواْ برهانكم } حجتكم على إشراككم { إِن كُنتُمْ صادقين } في دعواكم أن مع الله إلهاً آخر .  <br />
