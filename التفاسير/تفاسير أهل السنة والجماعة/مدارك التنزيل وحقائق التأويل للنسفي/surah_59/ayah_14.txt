{ لاَ يقاتلونكم } لا يقدرون على مقاتلتكم { جَمِيعاً } مجتمعين يعني اليهود والمنافقين { إِلا } كائنين { فِى قُرًى مُّحَصَّنَةٍ } بالخنادق والدروب { أَوْ مِن وَرَاء جُدُرٍ } { جدار } مكي وأبو عمرو { بَأْسُهُمْ بَيْنَهُمْ شَدِيدٌ } يعني أن البأس الشديد الذي يوصفون به إنما هو بينهم إذا اقتتلوا ولو قاتلوكم لم يبق لهم ذلك البأس والشدة لأن الشجاع يجبن عند محاربة الله ورسوله { تَحْسَبُهُمْ } أي اليهود والمنافقين { جَمِيعاً } مجتمعين ذوي ألفة واتحاد { وَقُلُوبُهُمْ شتى } متفرقة لا ألفة بينها يعني أن بينهم إحناً وعداوات فلا يتعاضدون حق التعاضد ،   وهذا تحسير للمؤمنين وتشجيع لقلوبهم على قتالهم { ذلك } التفرق { بِأَنَّهُمْ قَوْمٌ لاَّ يَعْقِلُونَ } أن تشتت القلوب مما يوهن قواهم ويعين على أرواحهم .  <br />
