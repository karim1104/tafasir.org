{ وَمَن يَقُلْ مِنْهُمْ } من الملائكة { إِنّى إله مّن دُونِهِ } من دون الله { إني } مدني وأبو عمرو { فَذَلِكَ } مبتدأ أي فذلك القائل خبره { نَجْزِيهِ جَهَنَّمَ } وهو جواب الشرط { كذلك نَجْزِى الظالمين } الكافرين الذين وضعوا الإلهية في غير موضعها وهذا على سبيل الفرض والتمثيل لتحقق عصمتهم .   وقال ابن عباس رضي الله عنهما وقتادة والضحاك : قد { تحقق الوعيد في إبليس فإنه ادعى الإلهية لنفسه ودعا إلى طاعة نفسه وعبادته .  <br />
