{ وَلَقَدْ كَتَبْنَا فِى الزبور } كتاب داود عليه السلام { مِن بَعْدِ الذكر } التوراة { أن الأرض } أي الشام { يَرِثُهَا عِبَادِىَ } ساكنة الياء : حمزة غيره بفتح الياء { الصالحون } أي أمة محمد عليه السلام ،   أو الزبور بمعنى المزبور أي المكتوب يعني ما أنزل على الأنبياء من الكتب .   والذكر أم الكتاب يعني اللوح لأن الكل أخذوا منه .   دليله قراءة حمزة وخلف بضم الزاي على جمع الزبر بمعنى المزبور والأرض أرض الجنة .  <br />
