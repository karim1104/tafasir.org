{ وَقَالَ رَبُّكُمْ ادعونى } اعبدوني { أَسْتَجِبْ لَكُمْ } أثبكم فالدعاء بمعنى العبادة كثير في القرآن ويدل عليه قوله { إِنَّ الذين يَسْتَكْبِرُونَ عَنْ عِبَادَتِى } وقال عليه السلام :<br />
 "  الدعاء هو العبادة  "  وقرأ هذه الآية صلى الله عليه وسلم .   وعن ابن عباس رضي الله عنهما : وحدوني أغفر لكم وهذا تفسير للدعاء بالعبادة ثم للعبادة بالتوحيد .   وقيل : سلوني أعطكم { سَيَدْخُلُونَ جَهَنَّمَ } { سيُدخلون } مكي وأبو عمرو .   { داخرين } صاغرين .  <br />
