{ أسباب السماوات } أي طرقها وأبوابها وما يؤدي إليها وكل ما أداك إلى شيء فهو سبب إليه كالرشاء ونحوه { فَأَطَّلِعَ } بالنصب : حفص على جواب الترجي تشبيهاً للترجي بالتمني .   وغيره بالرفع عطفاً على { أبلغ } { إلى إله موسى } والمعنى فأنظر إليه { وَإِنِّى لأَظُنُّهُ } أي موسى { كاذبا } في قوله له إله غيري { وكذلك } ومثل ذلك التزيين وذلك الصد { زُيِّنَ لِفِرْعَوْنَ سُوءَ عَمَلِهِ وَصُدَّ عَنِ السبيل } المستقيم .   وبفتح الصاد : كوفي ويعقوب أي غيره صداً أو هو بنفسه صدوداً .   والمزين الشيطان بوسوسته كقوله : { وَزَيَّنَ لَهُمُ الشيطان أعمالهم فَصَدَّهُمْ عَنِ السبيل } [ النمل : 24 ] .   أو الله تعالى ،   ومثله : { زَيَّنَّا لَهُمْ أعمالهم فَهُمْ يَعْمَهُونَ } [ النمل : 4 ] { وَمَا كَيْدُ فِرْعَوْنَ إِلاَّ فِى تَبَابٍ } خسران وهلاك .
