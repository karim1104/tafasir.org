{ أَفَحَسِبْتُمْ أَنَّمَا خلقناكم عَبَثاً } حال أي عابثين أو مفعول له أي للعبث { وَأَنَّكُمْ إِلَيْنَا لاَ تُرْجَعُونَ } وبفتح التاء وكسر الجيم : حمزة وعلي ويعقوب وهو معطوف على { أَنَّمَا خلقناكم } أو على { عبثاً } أي للعبث ولنترككم غير مرجوعين بل خلقناكم للتكليف ،   ثم للرجوع من دار التكليف إلى دار الجزاء فنثيب المحسن ونعاقب المسيء<br />
