{ مُسْتَكْبِرِينَ } متكبرين على المسلمين حال من { تنكصون } { بِهِ } بالبيت أو بالحرم لأنهم يقولون لا يظهر علينا أحد لأنا أهل الحرم ،   والذي سوغ هذا الإضمار شهرتهم بالاستكبار بالبيت أو ب { آياتي } لأنها في معنى كتابي ،   ومعنى استكبارهم بالقرآن تكذيبهم به استكباراً .   ضمن مستكبرين معنى مكذبين فعدي تعديته أو يتعلق الباء بقوله { سامرا } تسمرون بذكر القرآن وبالطعن فيه ،   وكانوا يجتمعون حول البيت يسمرون وكانت عامة سمرهم ذكر القرآن وتسميته شعراً وسحراً .   والسامر نحو الحاضر في الإطلاق على الجمع وقرىء { سمّارا } .   أو بقوله { تَهْجُرُونَ } وهو من الهجر الهذيان { تهجرون } : نافع من أهجر في منطقه إذا فحش<br />
