{ ثُمَّ جعلناه } أي نسله فحذف المضاف وأقيم المضاف إليه مقامه لأن آدم عليه السلام لم يصر نطفة وهو كقوله { وَبَدَأَ خَلْقَ الإنسان مِن طِينٍ * ثُمَّ جَعَلَ نَسْلَهُ مِن سُلاَلَةٍ مّن مَّاء مَّهِينٍ } [ السجدة : 8 ] وقيل : الإنسان بنو آدم والسلالة النطفة والعرب تسمي النطف سلالة أي ولقد خلقنا الإنسان من سلالة يعني من نطفة مسلولة من طين أي من مخلوق من طين وهو آدم عليه السلام { نُّطْفَةٍ } ماء قليلاً { فِى قَرَارٍ } مستقر يعني الرحم { مَّكِينٍ } حصين
