{ إِذْ تَمْشِى } بدل من { إِذْ أَوْحَيْنَا } لأن مشي أخته كان منة عليه { أُخْتُكَ فَتَقُولُ هَلْ أَدُلُّكُمْ على مَن يَكْفُلُهُ } رُوي أن أخته مريم جاءت متعرفة خبره فصادفتهم يطلبون له مرضعة يقبل ثديها وكان لا يقبل ثدي امرأة فقالت : هل أدلكم على من يضمه إلى نفسه فيربيه وأرادت بذلك المرضعة الأم .   وتذكير الفعل للفظ { مِنْ } ،   فقالوا : نعم فجاء بالأم فقبل ثديها وذلك قوله { فرجعناك } فرددناك { إلى أُمّكَ } كما وعدناها بقولنا { إِنَّا رَادُّوهُ إِلَيْكِ } [ القصص : 7 ] { كَى تَقَرَّ عَيْنُها } بلقائك { وَلاَ تَحْزَنْ } على فراقك { وَقَتَلْتَ نَفْساً } قبطياً كافراً { فنجيناك مِنَ الغم } من القود .   قيل الغم : القتل بلغة قريش وقيل : اغتم بسبب القتل خوفاً من عقاب الله تعالى ومن اقتصاص فرعون فغفر الله له باستغفاره { قَالَ رَبّ إِنّى ظَلَمْتُ نَفْسِى فاغفر لِى } [ القصص : 16 ] ونجاه من فرعون بأن ذهب به من مصر إلى مدين   { وفتناك فُتُوناً } ابتليناك ابتلاء بإيقاعك في المحن وتخليصك منها ،   والفتون مصدر كالقعود أو جمع فتنة أي فتناك ضروباً من الفتن ،   والفتنة المحنة وكل ما يبتلي الله به عباده فتنة .   { وَنَبْلُوكُم بالشر والخير فِتْنَةً } [ الأنبياء : 35 ] { فَلَبِثْتَ سِنِينَ فِى أَهْلِ مَدْيَنَ } هي بلدة شعيب عليه السلام على ثمان مراحل من مصر .   قال وهب : لبث عند شعيب ثمانياً وعشرين سنة ،   عشر منها مهر لصفوراء ،   وأقام عنده ثمان عشرة سنة بعدها حتى ولد له أولاد .   { ثُمَّ جِئْتَ على قَدَرٍ ياموسى } أي موعد ومقدار للرسالة وهو أربعون سنة
