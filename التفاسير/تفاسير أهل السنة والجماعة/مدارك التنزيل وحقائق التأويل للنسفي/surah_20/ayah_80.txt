ثم ذكر منته على بني إسرائيل بعد ما أنجاهم من البحر وأهلك فرعون وقومه بقوله { يابنى إسراءيل } أي أوحينا إلى موسى أن أسر بعبادي وقلنا يا بني إسرائيل { قَدْ أنجيناكم مّنْ عَدُوّكُمْ } أي فرعون { وواعدناكم } بإيتاء الكتاب { جَانِبِ الطور الأيمن } وذلك أن الله عز وجل وعد موسى أن يأتي هذا المكان ويختار سبعين رجلاً يحضرون معه لنزول التوراة .   وإنما نسب إليهم المواعدة لأنها كانت لنبيهم ونقبائهم وإليهم رجعت منافعها التي قام بها شرعهم ودينهم .   و { الأيمن } نصب لأنه صفة { جَانِبٍ } وقرىء بالجر على الجواز { وَنَزَّلْنَا عَلَيْكُمُ المن والسلوى } في التيه وقلنا لكم .  <br />
