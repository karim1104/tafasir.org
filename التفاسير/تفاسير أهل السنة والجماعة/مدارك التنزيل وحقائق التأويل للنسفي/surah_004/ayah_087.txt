{ الله } مبتدأ { لاَ إله إِلاَّ هُوَ } خبره أو اعتراض والخبر { لَيَجْمَعَنَّكُمْ } ومعناه : الله والله ليجمعنكم { إلى يَوْمِ القيامة } أي ليحشرنكم إليه .   والقيامة القيام كالطلابة والطلاب وهي قيامهم من القبور ،   أو قيامهم للحساب { يَوْمَ يَقُومُ الناس لِرَبّ العالمين } [ المطففين : 6 ] { لاَ رَيْبَ فِيهِ } هو حال من يوم القيامة والهاء يعود إلى اليوم ،   أو صفة لمصدر محذوف أي جمعاً لا ريب فيه ،   والهاء يعود إلى الجمع { وَمَنْ أَصْدَقُ مِنَ الله حَدِيثاً } تمييز وهو استفهام بمعنى النفي أي لا أحد أصدق منه في إخباره ووعده ووعيده لاستحالة الكذب عليه لقبحه لكونه إخباراً عن الشيء بخلاف ما هو عليه .
