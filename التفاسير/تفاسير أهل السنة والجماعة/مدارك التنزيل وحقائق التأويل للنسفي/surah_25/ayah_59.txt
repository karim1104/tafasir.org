{ الذى خَلَقَ السماوات والأرض وَمَا بَيْنَهُمَا فِى سِتَّةِ أَيَّامٍ } أي في مدة مقدار هذه المدة لأنه لم يكن حينئذ ليل ونهار .   روي عن مجاهد : أو لها يوم الأحد وآخرها يوم الجمعة ،   وإنما خلقها في ستة أيام وهو يقدر على أن يخلقها في لحظة تعليماً لخلقه الرفق والتثبت { ثُمَّ استوى عَلَى العرش الرحمن } أي هو الرحمن ف { الرحمن } خبر مبتدأ محذوف أو بدل من الضمير في { استوى } أو { الذي خلق } مبتدأ و { الرحمن } خبره { فسئل } بلا همزة مكي وعلي { بِهِ } صلة «سل » كقوله { سَأَلَ سَائِلٌ بِعَذَابٍ وَاقِعٍ } [ المعارج : 1 ] كما تكون «عن » صلته في قوله تعالى { ثُمَّ لَتُسْئَلُنَّ يَوْمَئِذٍ عَنِ النعيم } [ التكاثر : 8 ] فسأل به كقولك اهتم به واشتغل به وسأل عنه كقولك بحث عنه وفتش عنه أو صلة { خَبِيراً } ويكون { خبيراً } مفعول { سل } أي فاسأل عنه رجلاً عارفاً يخبرك برحمته ،   أو فاسأل رجلاً خبيراً به وبرحمته ،   أو الرحمن اسم من أسماء الله تعالى مذكور في الكتب المتقدمة ولم يكونوا يعرفونه فقيل : فاسأل بهذا الاسم من يخبرك من أهل الكتب حتى تعرف من ينكره ،   ومن ثم كانوا يقولون ما نعرف الرحمن إلا الذي باليمامة يعنون مسيلمة وكان يقال له رحمان اليمامة .
