{ وإِذَا أُلْقُواْ مِنْهَا } من النار { مَكَاناً ضَيّقاً } { ضيقاً } مكي فإن الكرب مع الضيق كما أن الروح مع السعة ولذا وصفت الجنة بأن عرضها السماوات والأرض .   وعن ابن عباس رضي الله عنها أنه يضيق عليهم كما يضيق الزج في الرمح { مُقْرِنِينَ } أي وهم مع ذلك الضيق مسلسلون مقرّنون في السلاسل قرنت أيديهم إلى أعناقهم في الأغلال ،   أو يقرن مع كل كافر شيطانه في سلسلة وفي أرجلهم الأصفاد { دَعَوْاْ هُنَالِكَ } حينئذ { ثُبُوراً } هلاكاً أي قالوا واثبوراه أي تعال يا ثبور فهذا حينك فيقال لهم { لاَّ تَدْعُواْ اليوم ثُبُوراً واحدا وادعوا ثُبُوراً كَثِيراً }<br />
