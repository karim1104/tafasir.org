{ إلاّ من تاب } عن الشرك وهو استثناء من الجنس في موضع النصب { وآمن } بمحمد عليه الصلاة والسلام { وعمل عملاً صالحاً } بعد توبته { فأولئك يبدّل الله سيّئاتهم حسناتٍ } أي يوفقهم للمحاسن بعد القبائح أو يمحوها بالتوبة ويثبت مكانها الحسنات الإيمان والطاعة ،   ولم يرد به أن السيئة بعينها حسنة ولكن المراد ما ذكرنا .   { يبدل } مخففاً البرجمي { وكان الله غفوراً } يكفر السيئات { رّحيماً } يبدلها بالحسنات .  <br />
