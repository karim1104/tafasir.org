{ والذين لا يدعون مع الله إلهاً آخر } أي لا يشركون { ولا يقتلون النّفس التي حرّم الله } أي حرمها يعني حرم قتلها { إلاّ بالحقّ } بقود أو رجم أو ردة أو شرك أو سعي في الأرض بالفساد ،   وهو متعلق بالقتل المحذوف أو ب { لا يقتلون } { ولا يزّنون } ونفى هذه الكبائر عن عباده الصالحين تعريض لما كان عليه أعداؤهم من قريش وغيرهم كأنه قيل : والذي طهرهم الله مما أنتم عليه { ومن يفعل ذلك } أي المذكور { يلق أثاماً } جزاء الإثم<br />
