{ لَهُمْ فِيهَا مَا يَشَآءونَ } أي ما يشاؤونه { خالدين } حال من الضمير في { يشاؤون } والضمير في { كان } ل { ما يشاؤون } { على رَبّكَ وَعْداً } أي موعوداً { مَّسْئُولاً } مطلوباً أو حقيقاً أن يسأل أو قد سأله المؤمنون والملائكة في دعواتهم { رَبَّنَا وَءاتِنَا مَا وَعَدتَّنَا على رُسُلِكَ } [ آل عمران : 194 ] { رَبَّنَا ءاتِنَا فِى الدنيا حَسَنَةً وَفِي الآخرة حَسَنَةً } [ البقرة : 201 ] { رَبَّنَا وَأَدْخِلْهُمْ جنات عَدْنٍ التى وَعَدْتَّهُمْ }
