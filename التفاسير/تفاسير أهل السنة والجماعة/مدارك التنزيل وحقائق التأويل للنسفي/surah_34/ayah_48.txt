{ قُلْ إِنَّ رَبّى يَقْذِفُ بالحق } بالوحي .   والقذف توجيه السهم ونحوه بدفع واعتماد ويستعار لمعنى الإلقاء ومنه { وَقَذَفَ فِى قُلُوبِهِمُ الرعب } [ الأحزاب : 26 ] { أَنِ اقذفيه فِى التابوت } [ طه : 39 ] ومعنى يقذف بالحق يلقيه وينزله إلى أنبيائه أو يرمي به الباطل فيدمغه ويزهقه { علام الغيوب } مرفوع على البدل من الضمير في { يَقْذِفُ } أو على أنه خبر مبتدأ محذوف
