{ وَحِيلَ } وحجز { بَيْنَهُمْ وَبَيْنَ مَا يَشْتَهُونَ } من نفع الإيمان يومئذ والنجاة به من النار والفوز بالجنة أو من الرد إلى الدنيا كما حكي عنهم بقوله { فارجعنا نَعْمَلْ صالحا } [ السجدة : 12 ] والأفعال التي هي { فَزِعُواْ } { وَأُخِذُواْ } { وَحِيلَ } كلها للمضي والمراد بها الاستقبال لتحقق وقوعه { كَمَا فُعِلَ بأشياعهم مّن قَبْلُ } بأشباههم من الكفرة { إِنَّهُمْ كَانُواْ فِى شَكّ } من أمر الرسل والبعث { مُرِيبٍ } موقع في الريبة من أرابه إذا أوقعه في الريبة ،   هذا رد على من زعم أن الله لا يعذب على الشك والله أعلم .
