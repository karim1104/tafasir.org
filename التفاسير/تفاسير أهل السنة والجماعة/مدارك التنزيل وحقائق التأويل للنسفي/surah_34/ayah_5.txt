{ والذين سَعَوْا فِى ءاياتنا } جاهدوا في رد القرآن { معاجزين } مسابقين ظانين أنهم يفوتوننا .   { مُعَجِزِينَ } مكي وأبو عمرو أي مثبطين الناس عن اتباعها وتأملها أو ناسبين الله إلى العجز { أُوْلَئِكَ لَهُمْ عَذَابٌ مّن رّجْزٍ أَلِيمٌ } برفع { أَلِيمٌ } مكي وحفص ويعقوب صفة لعذاب أي عذاب أليم من سيء العذاب .   قال قتادة : الرجز سوء العذاب ،   وغيرهم بالجر صفة لرجز .  <br />
