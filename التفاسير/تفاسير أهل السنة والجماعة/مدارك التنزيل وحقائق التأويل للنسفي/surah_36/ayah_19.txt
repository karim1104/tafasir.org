{ قَالُواْ طائركم } أي سبب شؤمكم { مَّعَكُمْ } وهو الكفر { أئِن } بهمزة الاستفهام وحرف الشرط : كوفي وشامي { ذُكِّرْتُم } وعظتم ودعيتم إلى الإسلام ،   وجواب الشرط مضمر وتقديره «تطيرتم » ،   { آين } بهمزة ممدودة بعدها ياء مكسورة : أبو عمرو ،   و { أَيْنَ } بهمزة مقصورة بعدها ياء مسكورة : مكي ونافع .   { ذكرتم } بالتخفيف : يزيد { بَلْ أَنتُمْ قَوْمٌ مُّسْرِفُونَ } مجاوزون الحد في العصيان فمن ثم أتاكم الشؤم من قبلكم لا من قبل رسل الله وتذكيرهم ،   أو بل أنتم مسرفون في ضلالكم وغيكم حيث تتشاءمون بمن يجب التبرك به من رسل الله .  <br />
