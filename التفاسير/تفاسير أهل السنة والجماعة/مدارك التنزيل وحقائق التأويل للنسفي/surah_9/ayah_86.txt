{ وَإِذَا أُنزِلَتْ سُورَةٌ } يجوز أن يراد سورة بتمامها وأن يراد بعضها كما يقع القرآن والكتاب على كله وعلى بعضه { أَنْ ءامِنُواْ بالله } بأن آمنوا أو هي «أن » المفسرة { وجاهدوا مَعَ رَسُولِهِ استأذنك أُوْلُواْ الطول مِنْهُمْ } ذوو الفضل والسعة { وَقَالُواْ ذَرْنَا نَكُنْ مَّعَ القاعدين } مع الذين لهم عذر في التخلف كالمرضى والزمنى<br />
