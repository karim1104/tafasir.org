{ قُلْ هَلْ تَرَبَّصُونَ بِنَا } تنتظرون بنا { إِلا إِحْدَى الحسنيين } وهما النصرة والشهادة { وَنَحْنُ نَتَرَبَّصُ بِكُمْ } إحدى السوءيين إما { أَن يُصِيبَكُمُ الله بِعَذَابٍ مّنْ عِندِهِ } وهو قارعة من السماء كما نزلت على عاد وثمود { أَوْ } بعذاب { بِأَيْدِينَا } وهو القتل على الكفر { فَتَرَبَّصُواْ } بنا ما ذكرنا { إِنَّا مَعَكُمْ مُّتَرَبِّصُونَ } ما هو عاقبتكم<br />
