{ ثُمَّ أَنزَلَ الله سَكِينَتَهُ } رحمته التي سكنوا بها وأمنوا { على رَسُولِهِ وَعَلَى المؤمنين وَأَنزَلَ جُنُوداً لَّمْ تَرَوْهَا } يعني الملائكة وكانوا ثمانية آلاف أو خمسة أو ستة عشر ألفاً { وَعذَّبَ الذين كَفَرُواْ } بالقتل والأسر وسبي النساء والذراري .   { وذلك جَزَاء الكافرين } .  <br />
