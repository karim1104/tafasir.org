{ يأَيُّهَا الناس اذكروا } باللسان والقلب { نِعْمَتَ الله عَلَيْكُمْ } وهي التي تقدمت من بسط الأرض كالمهاد ،   ورفع السماء بلا عماد ،   وإرسال الرسل لبيان السبيل دعوة إليه وزلفة لديه ،   والزيادة في الخلق وفتح أبواب الرزق .   ثم نبه على رأس النعم وهو اتحاد المنعم بقوله { هَلْ مِنْ خالق غَيْرُ الله } برفع { غَيْرُ } على الوصف لأن { خالق } مبتدأ خبره محذوف أي لكم .  <br />
وبالجر : علي وحمزة على الوصف لفظاً { يَرْزُقُكُمْ } يجوز أن يكون مستأنفاً ويجوز أن يكون صفة ل { خالق } { مِّنَ السمآء } بالمطر { والأرض } بأنواع النبات { لآ إله إِلاَّ هُوَ } جملة مفصولة لا محل لها { فأنى تُؤْفَكُونَ } فبأي وجه تصرفون عن التوحيد إلى الشرك .  <br />
