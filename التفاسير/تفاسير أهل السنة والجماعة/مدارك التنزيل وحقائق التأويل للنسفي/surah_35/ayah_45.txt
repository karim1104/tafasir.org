{ وَلَوْ يُؤَاخِذُ الله الناس بِمَا كَسَبُواْ } بما اقترفوا من المعاصي { مَا تَرَكَ على ظَهْرِهَا } على ظهر الأرض لأنه جرى ذكر الأرض في قوله { لِيُعْجِزَهُ مِن شَىْء فِى السماوات وَلاَ فِى الأرض } [ فاطر : 44 ] { مِن دَآبَّةٍ } من نسمة تدب عليها { ولكن يُؤَخِرُهُمْ إلى أَجَلٍ مسمى } إلى يوم القيامة { فَإِذَا جَآءَ أَجَلُهُمْ فَإِنَّ الله كَانَ بِعِبَادِهِ بَصِيراً } أي لم تخف عليه حقيقة أمرهم وحكمة حكمهم والله الموفق للصواب .
