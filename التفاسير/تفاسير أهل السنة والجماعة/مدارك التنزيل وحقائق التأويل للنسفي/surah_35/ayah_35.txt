{ الذى أَحَلَّنَا دَارَ المقامة } أي الإقامة لا نبرح منها ولا نفارقها يقال أقمت إقامة ومقاماً ومقامة { مِن فَضْلِهِ } من عطائه وإفضاله لا باستحقاقنا { لاَ يَمَسُّنَا فِيهَا نَصَبٌ } تعب ومشقة { وَلاَ يَمَسُّنَا فِيهَا لُغُوبٌ } إعياء من التعب وفترة .   وقرأ أبو عبد الرحمن السلمي { لغُوبٌ } بفتح اللام وهو شيء يلغب منه أي لا نتكلف عملاً يلغبنا<br />
