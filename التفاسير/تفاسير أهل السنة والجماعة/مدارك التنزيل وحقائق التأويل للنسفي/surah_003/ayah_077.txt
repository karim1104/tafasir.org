{ إِنَّ الذين يَشْتَرُونَ } يستبدلون { بِعَهْدِ الله } بما عاهدوه عليه من الإيمان بالرسول المصدق لما معهم { وأيمانهم } وبما حلفوا به من قولهم «والله لنؤمنن به ولننصرنه » { ثَمَناً قَلِيلاً } متاع الدنيا من الترؤس والارتشاء ونحو ذلك ،   وقوله «بعهد الله » يقوي رجوع الضمير في «بعهده » إلى الله { أولئك لاَ خلاق لَهُمْ فِى الآخرة } أي لا نصيب { وَلاَ يُكَلّمُهُمُ الله } بما يسرهم { وَلاَ يَنظُرُ إِلَيْهِمْ يَوْمَ القيامة } نظر رحمة { وَلاَ يُزَكّيهِمْ } ولا يثني عليهم { وَلَهُمْ عَذَابٌ أَلِيمٌ } مؤلم .  <br />
