{ فَإِن كَذَّبُوكَ فَقَدْ كُذّبَ رُسُلٌ مّن قَبْلِكَ } فإن كذبك اليهود فلا يهولنك فقد فعلت الأمم بأنبيائها كذلك { جَاءُو بالبينات } بالمعجزات الظاهرات { والزبر } الكتب جمع زبور من الزبر وهو الكتابة .   «وبالزبر » : شامي { والكتاب } جنسه { المنير } المضيء .   قيل : هما واحد في الأصل وإنما ذكرا لاختلاف الوصفين ،   فالزبور كتاب فيه حكم زاجرة ،   والكتاب المنير هو الكتاب الهادي .  <br />
