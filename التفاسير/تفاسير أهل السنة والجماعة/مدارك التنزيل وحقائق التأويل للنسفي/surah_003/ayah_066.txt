{ هَاأَنتُمْ هَؤُلاَء } «ها » للتنبيه و«أنتم » مبتدأ و«هؤلاء » خبره { حاججتم } جملة مستأنفة مبينة للجملة الأولى يعني أنتم هؤلاء الأشخاص الحمقى .   وبيان حماقتكم وقلة عقولكم أنكم جادلتم { فِيمَا لَكُم بِهِ عِلمٌ } مما نطق به التوراة والإنجيل { فَلِمَ تُحَآجُّونَ فِيمَا لَيْسَ لَكُمْ بِهِ عِلْمٌ } ولا ذكر له في كتابيكم من دين إبراهيم .   وقيل : هؤلاء بمعنى «الذين » و«حاججتم » صلته .   «ها أنتم » بالمد وغير الهمز حيث كان : مدني وأبو عمرو .   { والله يَعْلَمُ } علم ما حاججتم فيه { وَأَنتُمْ لاَ تَعْلَمُونَ } وأنتم جاهلون به .  <br />
