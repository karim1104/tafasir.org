{ وَمَا لَكُمْ أَلاَّ تَأْكُلُواْ } «ما » استفهام في موضع رفع بالابتداء و { لَكُمْ } الخبر أي وأي غرض لكم في أن لا تأكلوا { مِمَّا ذُكِرَ اسم الله عَلَيْهِ وَقَدْ فَصَّلَ لَكُم } بين لكم { مَّا حَرَّمَ عَلَيْكُمْ } مما لم يحرم بقوله { حُرّمَتْ عَلَيْكُمُ الميتة } [ المائدة : 3 ] { فَصْلٌ } و { حَرَّمَ } كوفي غير حفص وبفتحهما مدني وحفص وبضمهما غيرهم { إِلاَّ مَا اضطررتم إِلَيْهِ } مما حرم عليكم فإنه حلال لكم في حال الضرورة أي شدة المجاعة إلى أكله { وَإِنَّ كَثِيرًا لَّيُضِلُّونَ } { ليضلون } كوفي { بِأَهْوَائِهِم بِغَيْرِ عِلْمٍ } أي يضلون فيحرمون ويحللون بأهوائهم وشهواتهم من غير تعلق بشريعة { إِنَّ رَّبَّكَ هُوَ أَعْلَمُ بالمعتدين } بالمتجاوزين من الحق إلى الباطل .
