{ وَيَوْمَ نَحْشُرُهُمْ } هو مفعول به والتقدير : واذكر يوم نحشرهم { جَمِيعاً } حال من ضمير المفعول { ثُمَّ نَقُولُ لِلَّذِينَ أَشْرَكُواْ } مع الله غيره توبيخاً ،   وبالياء فيهما : يعقوب { أَيْنَ شُرَكَاؤُكُمُ } آلهتكم التي جعلتموها شركاء الله { الذين كُنتُمْ تَزْعُمُونَ } أي تزعمونهم شركاء فحذف المفعولان<br />
