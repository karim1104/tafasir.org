{ قُلْ إِنَّنِي هَدَانِي رَبّي } { رَبّي } أبو عمرو ومدني { إلى صراط مُّسْتَقِيمٍ دِينًا } نصب على البدل من محل { إلى صراط مُّسْتَقِيمٍ } لأن معناه هداني صراطاً بدليل قوله { وَيَهْدِيَكُمْ صراطا مُّسْتَقِيماً } [ الفتح : 20 ] ( قِيِّماً ) «قيما » فيعل من قام كسيد من ساد وهو أبلغ من القائم { قَيِّماً } كوفي وشامي وهو مصدر بمعنى القيام وصف به { مِلَّةِ إبراهيم } عطف بيان { حَنِيفاً } حال من { إِبْرَاهِيمَ } { وَمَا كَانَ مِنَ المشركين } بالله يا معشر قريش .
