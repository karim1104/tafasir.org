{ وَهُوَ القاهر فَوْقَ عِبَادِهِ وَيُرْسِلَ عَلَيْكُمْ حَفَظَةً } ملائكة حافظين لأعمالكم وهم الكرام الكاتبون ليكون ذلك أزجر للعباد عن ارتكاب الفساد إذا تفكروا أن صحائفهم تقرأ على رؤوس الأشهاد { حتى إِذَا جَاء أَحَدَكُمُ الموت } «حتى » لغاية حفظ الأعمال أي وذلك دأب الملائكة مع المكلف مدة الحياة إلى أن يأتيه الممات { تَوَفَّتْهُ رُسُلُنَا } أي استوفت روحه وهم ملك الموت وأعوانه { توفيه } و { استوفيه } بالإمالة : حمزة { رُسُلُنَا } أبو عمرو { وَهُمْ لاَ يُفَرِّطُونَ } لا يتوانون ولا يؤخرون<br />
