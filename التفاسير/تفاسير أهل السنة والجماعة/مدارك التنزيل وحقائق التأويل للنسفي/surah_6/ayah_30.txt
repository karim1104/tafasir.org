{ وَلَوْ ترى إِذْ وُقِفُواْ على رَبِّهِمْ } مجاز عن الحبس للتوبيخ والسؤال كما يوقف العبد الجاني بين يدي سيده ليعاقبه ،   أو وقفوا على جزاء ربهم { قَالَ } جواب لسؤال مقدر كأنه قيل : ماذا قال لهم ربهم إذ وقفوا عليه ؟ فقيل : قال { أَلَيْسَ هذا } أي البعث { بالحق } بالكائن الموجود وهذا تعيير لهم على التكذيب للبعث .   وقولهم لما كانوا يسمعون من حديث البعث ما هو بحق { قَالُواْ بلى وَرَبِّنَا } أقروا و أكدوا الإقرار باليمين { قَالَ } الله تعالى { فَذُوقُواْ العذاب بِمَا كُنْتُمْ تَكْفُرُونَ } بكفركم .  <br />
