{ فَلَمَّا نَسُواْ مَا ذُكِّرُواْ بِهِ } من البأساء والضراء أي تركوا الاتعاظ به ولم يزجرهم { فَتَحْنَا عَلَيْهِمْ أبواب كُلِّ شَيْءٍ } من الصحة والسعة وصنوف النعمة { فَتَحْنَا } شامي { حتى إِذَا فَرِحُواْ بِمَا أُوتُواْ } من الخير والنعمة { أخذناهم بَغْتَةً فَإِذَا هُمْ مُّبْلِسُونَ } آيسون متحسرون وأصله الإطراق حزناً لما أصابه أو ندماً على مافاته و «إذا » للمفاجأة<br />
