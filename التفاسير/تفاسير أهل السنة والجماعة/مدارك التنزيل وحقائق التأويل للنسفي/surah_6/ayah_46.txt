ثم دل على قدرته وتوحيده بقوله { قُلْ أَرَءَيْتُمْ إِنْ أَخَذَ الله سَمْعَكُمْ وأبصاركم } بأن أصمكم وأعماكم { وَخَتَمَ على قُلُوبِكُمْ } فسلب العقول والتمييز { مَّنْ إله غَيْرُ الله يَأْتِيكُمْ بِهِ } بما أخذ وختم عليه .   { مِنْ } رفع بالابتداء و { إِلَهٌ } خبره و { غَيْرِ } صفة ل { إله } وكذا { يَأْتِيَكُمُ } والجملة في موضع مفعولي { أَرَءيْتُمْ } وجواب الشرط محذوف { انظر كَيْفَ نُصَرِّفُ } لهم { الآيات } نكررها { ثُمَّ هُمْ يَصْدِفُونَ } يعرضون عن الآيات بعد ظهورها ،   والصدوف الإعراض عن الشيء<br />
