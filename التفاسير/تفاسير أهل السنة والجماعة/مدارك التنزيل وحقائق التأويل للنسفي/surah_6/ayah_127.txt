{ لَهُمْ } أي لقوم يذكرون { دَارُ السلام } دار الله يعني الجنة أضافها إلى نفسه تعظيماً لها ،   أو دار السلامة من كل آفة وكدر ،   أو السلام التحية سميت دار السلام لقوله : { تَحِيَّتُهُمْ فِيهَا سلام } [ يونس : 10 ] .   { إِلاَّ قِيلاً سلاما سلاما } [ الواقعة : 26 ] { عِندَ رَبِّهِمْ } في ضمانة { وَهُوَ وَلِيُّهُم } محبهم أو ناصرهم على أعدائهم { بِمَا كَانُواْ يَعْمَلُونَ } بأعمالهم أو متوليهم بجزاء ما كانوا يعملون أو هو ولينا في الدنيا بتوفيق الأعمال وفي العقبى بتحقيق الآمال .
