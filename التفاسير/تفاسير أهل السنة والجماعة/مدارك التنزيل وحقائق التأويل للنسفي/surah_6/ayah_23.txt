{ ثُمَّ لَمْ تَكُنْ } وبالياء : حمزة وعلي { فِتْنَتُهُمْ } كفرهم { إِلاَّ أَن قَالُواْ والله رَبّنَا ما كُنَّا مُشْرِكِينَ } يعني ثم لم تكن عاقبة كفرهم الذي لزموه أعمارهم وقاتلوا عليه إلا جحوده والتبرؤ منه والحلف على الانتفاء من التدين به ،   أو ثم لم يكم جوابهم إلا أن قالوا : فسمي فتنة لأنه كذب .  <br />
وبرفع الفتنة مكي وشامي وحفص ؛ فمن قرأ { تَكُنْ } بالتاء ورفع الفتنة فقد جعل الفتنة اسم { تَكُنْ } و { أَن قَالُواْ } الخبر أي لم تكن فتنتهم إلا قولهم ،   ومن قرأ بالياء ونصب الفتنة جعل { أَن قَالُواْ } اسم { يَكُنِ } أي لم يكن فتنتهم إلا قولهم ،   ومن قرأ بالتاء ونصب الفتنة حمل على المقالة : { رَبَّنَا } حمزة وعلي ،   على النداء أي ياربنا وغيرهما بالجر على النعت من اسم الله<br />
