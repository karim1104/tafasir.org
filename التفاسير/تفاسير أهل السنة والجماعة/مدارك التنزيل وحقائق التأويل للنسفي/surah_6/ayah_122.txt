{ مَيْتًا } مدني { وَجَعَلْنَا لَهُ نُورًا يَمْشِي بِهِ فِي الناس } مستضيئاً به والمراد به اليقين { كَمَن مَّثَلُهُ } أي صفته { فِي الظلمات } أي خابط فيها { لَيْسَ بِخَارِجٍ مّنْهَا } لا يفارقها ولا يتخلص منها وهو حال .   قيل : المراد بهما حمزة وأبو جهل .   والأصح أن الآية عامة لكل من هداه الله ولكل من أضله الله ،   فبين أن مثل المهتدي مثل الميت الذي أحيي وجعل مستضيّئاً يمشي في الناس بنور الحكمة والإيمان ،   ومثل الكافر مثل من هو في الظلمات التي لا يتخلص منها { كذلك } أي كما زين للمؤمن إيمانه { زُيّنَ للكافرين } بتزيين الله تعالى كقوله { زَيَّنَّا لَهُمْ أعمالهم } [ النمل : 4 ] { مَا كَانُواْ يَعْمَلُونَ } أي أعمالهم .
