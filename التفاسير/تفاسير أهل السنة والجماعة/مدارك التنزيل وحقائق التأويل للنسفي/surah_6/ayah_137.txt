{ وكذلك زَيَّنَ لِكَثِيرٍ مِّنَ المشركين } أي كما زين لهم تجزئة المال زين وأد البنات { قَتْلَ } هو مفعول زين { أولادهم شُرَكَاؤُهُمْ } هو فاعل زين ،   { زُيِّنَ } بالضم { قَتْلَ } بالرفع { أولادهم } بالنصب { شُرَكَائِهِمْ } بالجر : شامي على إضافة القتل إلى الشركاء أي الشياطين والفصل بينهما بغير الظرف وهو المفعول وتقديره : زين لكثير من المشركين قتل شركائهم أولادهم { لِيُرْدُوهُمْ } ليهلكوهم بالإغواء { وَلِيَلْبِسُواْ عَلَيْهِمْ دِينَهُمْ } وليخلطوا عليهم ويشوبوه ودينهم ما كانوا عليه من دين إسماعيل حتى زلوا عنه إلى الشرك { وَلَوْ شَاء الله مَا فَعَلُوهُ } وفيه دليل على أن الكائنات كلها بمشيئة الله تعالى { فَذَرْهُمْ وَمَا يَفْتَرُونَ } وما يفترونه من الإفك ،   أو وافتراءهم لأن ضرر ذلك الافتراء عليهم لا عليك ولا علينا<br />
