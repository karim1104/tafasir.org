وانتصب { رَسُولاً } بفعل مضمر تقديره أرسل رسولاً أو بدل من { ذِكْراً } كأنه في نفسه ذكراً وعلى تقدير حذف المضاف أي قد أنزل الله إليكم ذا ذكر رسولاً ،   أو أريد بالذكر الشرف كقوله { وَإِنَّهُ لَذِكْرٌ لَّكَ وَلِقَوْمِكَ } [ الزخرف : 44 ] أي ذا شرف ومجد عند الله وبالرسول جبريل أو محمد عليهما السلام { يَتْلُواْ } أي الرسول أو الله عز وجل { عَلَيْكُمْ ءايات الله مبينات لّيُخْرِجَ } الله .  <br />
{ الذين ءامَنُواْ وَعَمِلُواْ الصالحات } أي ليحصل لهم ما هم عليه الساعة من الإيمان والعمل الصالح ،   أو ليخرج الذين علم أنهم يؤمنون { مِنَ الظلمات إِلَى النور } من ظلمات الكفر أو الجهل إلى نور الإيمان أو العلم { وَمَن يُؤْمِن بالله وَيَعْمَلْ صالحا يُدْخِلْهُ } وبالنون : مدني وشامي { جنات تَجْرِى مِن تَحْتِهَا الأنهار خالدين فِيهَا أَبَدًا } وحد وجمع حملاً على لفظ «من » ومعناه { قَدْ أَحْسَنَ الله لَهُ رِزْقاً } فيه معنى التعجب والتعظيم لما رزق المؤمنين من الثواب
