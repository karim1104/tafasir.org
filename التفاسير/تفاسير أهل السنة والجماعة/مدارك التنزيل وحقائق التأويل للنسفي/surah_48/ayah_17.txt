{ لَّيْسَ عَلَى الأعمى حَرَجٌ وَلاَ عَلَى الأعرج حَرَجٌ وَلاَ عَلَى المريض حَرَجٌ } نفي الحرج عن ذوي العاهات في التخلف عن الغزو { وَمَن يُطِعِ الله وَرَسُولَهُ } في الجهاد وغير ذلك { يُدْخِلْهُ جنات تَجْرِى مِن تَحْتِهَا الأنهار وَمَن يَتَوَلَّ } يعرض عن الطاعة { يُعَذِّبْهُ عَذَاباً أَلِيماً } { ندخله } و { نُعَذِّبُهُ } مدني وشامي .  <br />
