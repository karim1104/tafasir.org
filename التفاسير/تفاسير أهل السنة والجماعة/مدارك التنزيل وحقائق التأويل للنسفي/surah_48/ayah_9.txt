{ لِّتُؤْمِنُواْ بالله وَرَسُولِهِ } والخطاب لرسول الله صلى الله عليه وسلم ولأمته { وَتُعَزِّرُوهُ } وتقووه بالنصر { وَتُوَقِّرُوهُ } وتعظموه { وَتُسَبِّحُوهُ } من التسبيح أو من السبحة ،   والضمائر لله عز وجل .   والمراد بتعزيز الله تعزيز دينه ورسوله ،   ومن فرق الضمائر فجعل الأولين للنبي صلى الله عليه وسلم فقد أبعد { لِيُؤْمِنُواْ } مكي وأبو عمرو والضمير للناس وكذا الثلاثة الأخيرة بالياء عندهما { بُكْرَةً } صلاة الفجر { وَأَصِيلاً } الصلوات الأربع<br />
