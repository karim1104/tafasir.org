{ وَقَالَ فِرْعَوْنُ } تمويهاً على قومه أو جهلاً منه { ياهامان ابن لِى صَرْحاً } أي قصراً .   وقيل الصرح : البناء الظاهر الذي لا يخفى على الناظر وإن بعد ،   ومنه يقال : صرح الشيء إذا ظهر { لَّعَلِّى } وبفتح الياء : حجازي وشامي وأبو عمرو { أَبْلُغُ الأسباب } ثم أبدل منها تفخيماً لشأنها وإبانة أنه يقصد أمراً عظيماً<br />
