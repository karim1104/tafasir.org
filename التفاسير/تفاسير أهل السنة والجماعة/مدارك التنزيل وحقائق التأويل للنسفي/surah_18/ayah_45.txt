{ واضرب لَهُم مَّثَلَ الحياة الدنيا كَمَاء أنزلناه مِنَ السماء } أي هي كماء أنزلناه { فاختلط بِهِ نَبَاتُ الأرض } فالتف بسببه وتكاثف حتى خالط بعضه بعضاً أو أثر في النبات الماء فاختلط به حتى روى { فَأَصْبَحَ هَشِيمًا } يابساً متكسراً الواحدة هشيمة { تَذْرُوهُ الرياح } تنسفه وتطيره .   { الريح } حمزة وعلي { وَكَانَ الله على كُلّ شَىْء } من الإنشاء والإفناء { مُّقْتَدِرًا } قادراً ،   شبه حال الدنيا في نضرتها وبهجتها وما يتعقبها من الهلاك والإفناء بحال النبات يكون أخضر ثم يهيج فتطيره الريح كأن لم يكن .  <br />
