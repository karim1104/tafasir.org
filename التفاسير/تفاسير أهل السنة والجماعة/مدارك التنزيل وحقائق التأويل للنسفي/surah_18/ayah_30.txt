وبين جزاء من اختار الإيمان فقال :<br />
{ إِنَّ الذين ءامَنُواْ وَعَمِلُواْ الصالحات إِنَّا لاَ نُضِيعُ أَجْرَ مَنْ أَحْسَنَ عَمَلاً * أُوْلَئِكَ لَهُمْ جَنَّاتُ عَدْنٍ } كلام مستأنف بيان للأجر المبهم ،   ولك أن تجعل { إنَّا لا نضيع } و { أولئك } خبرين معاً .   والمراد من أحسن منهم عملاً كقولك «السمن منوان بدرهم » ،   أو لأن { من أحسن عملاً } و { الذين آمنوا وعملوا الصالحات } ينتظمهما معنى واحد فأقام من «أحسن » مقام الضمير { تَجْرِى مِن تَحْتِهِمُ الأنهار يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ } «من » للإبتداء ،   وتنكير أساور وهي جمع أسورة التي هي جمع سوار لإبهام أمرها في الحسن { مّن ذَهَبٍ } «من » للتبيين { وَيَلْبَسُونَ ثِيَابًا خُضْرًا مّن سُنْدُسٍ } ما رَقَّ من الديباج { وَإِسْتَبْرَقٍ } ما غلظ منه أي يجمعون بين النوعين { مُّتَّكِئِينَ فِيهَا على الأرائك } خص الاتكاء لأنه هيئة المتنعمين والملوك على أسرتهم { نِعْمَ الثواب } الجنة { وَحَسُنَتْ } الجنة والأرائك { مُرْتَفَقًا } متكأ .  <br />
