{ وَيَوْمَ } واذكر يوم { نُسَيّرُ الجبال } { تُسيَّر الجبال } مكي وشامي وأبو عمرو أي تسير في الجو ،   أو يذهب بها بأن تجعل هباء منثوراً منبثاً { وَتَرَى الأرض بَارِزَةً } ليس عليها ما يسترها مما كان عليها من الجبال والأشجار { وحشرناهم } أي الموتى { فَلَمْ نُغَادِرْ مِنْهُمْ أَحَداً } أي فلم نترك .   غادره أي تركه ومنه الغدر ترك الوفاء والغدير ما غادره السيل<br />
