{ قَالَ هذا رَحْمَةٌ مّن رَّبّى } أي هذا السد نعمة من الله ورحمة على عباده ،   أو هذا الإقدار والتمكين من تسويته { فَإِذَا جَاء وَعْدُ رَبّى } فإذا دنا مجيء يوم القيامة وشارف أن يأتي { جَعَلَهُ } أي السد { دَكَّاء } أي مدكوكا مبسوطاً مسوى بالأرض وكل ما انبسط بعد ارتفاع فقد اندك .   { دكاء } كوفي أي أرضاً مستوية { وَكَانَ وَعْدُ رَبّى حَقّاً } آخر قول ذي القرنين<br />
