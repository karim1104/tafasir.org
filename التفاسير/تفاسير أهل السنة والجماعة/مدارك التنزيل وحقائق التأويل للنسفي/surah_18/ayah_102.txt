{ أَفَحَسِبَ الذين كَفَرُواْ أَن يَتَّخِذُواْ عِبَادِى مِن دُونِى أَوْلِيَاء } أي أفظن الكفار اتخاذهم عبادي يعني الملائكة وعيسى عليهم السلام أولياء نافعهم بئس ما ظنوا .   وقيل : «أن » بصلتها سد مسد مفعولي { أفحسب } و { عبادي أولياء } مفعولاً { أن يتخذوا } وهذا أوجه يعني أنهم لا يكونون لهم أولياء { إِنَّا أَعْتَدْنَا جَهَنَّمَ للكافرين نُزُلاً } هو ما يقام للنزيل وهو الضيف ونحوه فبشرهم بعذاب أليم<br />
