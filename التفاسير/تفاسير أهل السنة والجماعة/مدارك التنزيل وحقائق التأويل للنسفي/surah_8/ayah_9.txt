{ إِذْ تَسْتَغِيثُونَ رَبَّكُمْ } بدل من { إِذْ يَعِدُكُمُ } أو متعلق بقوله { لِيُحِقَّ الحق وَيُبْطِلَ الباطل } واستغاثتهم أنهم لما علموا أنه لا بد من القتال طفقوا يدعون الله يقولون أي ربنا انصرنا على عدوك ،   يا غياث المستغيثين أغثنا .   وهي طلب الغوث وهو التخليص من المكروه { فاستجاب لَكُمْ } فأجاب .   وأصل { أَنّي مُمِدُّكُمْ } «بأني ممدكم » فحذف الجار وسلط عليه { استجاب } فنصب محله { بِأَلْفٍ مّنَ الملئكة مُرْدِفِينَ } { مُردفِينَ } مدني .   غيره بكسر الدال .   فالكسر على أنهم أردفوا غيرهم ،   والفتح على أنه أردف كل ملك ملكاً آخر .  <br />
يقال : ردفه إذا تبعه ،   وأردفته إياه إذا اتبعه<br />
