{ وَإِن يُرِيدُواْ } أي الأسرى { خِيَانَتَكَ } نكث ما بايعوك عليه من الإسلام بالردة أو منع ما ضمنوه من الفداء { فَقَدْ خَانُواْ الله مِن قَبْلُ } في كفرهم به ونقض ما أخذ على كل عاقل من ميثاقه { فَأَمْكَنَ مِنْهُمْ } فأمكنك منهم أي أظفرك بهم كما رأيتم يوم بدر فسيمكن منهم إن أعادوالخيانة { والله عَلِيمٌ } بالمال { حَكِيمٌ } فيما أمر في الحال .  <br />
