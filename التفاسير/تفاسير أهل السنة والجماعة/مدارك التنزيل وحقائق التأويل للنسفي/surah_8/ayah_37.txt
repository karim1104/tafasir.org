واللام في { لِيَمِيزَ الله الخبيث } الفريق الخبيث من الكفار { مِنَ الطيب } أي من الفريق الطيب من المؤمنين ،   متعلقة ب { يُحْشَرُونَ } { ليميّز } حمزة وعلي { وَيَجْعَلَ الخبيث } الفريق الخبيث { بَعْضَهُ على بَعْضٍ فَيَرْكُمَهُ جَمِيعاً } فيجمعه { فَيَجْعَلَهُ فِى جَهَنَّمَ } أي الفريق الخبيث { أولئك } إشارة إلى الفريق الخبيث { هُمُ الخاسرون } أنفسهم وأموالهم .  <br />
