{ إِنَّمَا تَعْبُدُونَ مِن دُونِ الله أوثانا } أصناماً { وَتَخْلُقُونَ } وتكذبون أو تصنعون .   وقرأ أبو حنيفة والسلمي رضي الله عنهما { وتخلّقون } من خلق بمعنى التكثير في خلق { إِفْكاً } وقرىء { أفكا } وهو مصدر نحو كذب ولعب .   والإفك مخفف منه كالكذب واللعب من أصلهما واختلاقهم الإفك تسميتهم الأوثان آلهة وشركاء لله { إِنَّ الذين تَعْبُدُونَ مِن دُونِ الله لاَ يَمْلِكُونَ لَكُمْ رِزْقاً } لا يستطيعون أن يرزقوكم شيئاً من الرزق { فابتغوا عِندَ الله الرزق } كله فإنه هو الرازق وحده لا يرزق غيره { واعبدوه واشكروا لَهُ إِلَيْهِ تُرْجَعُونَ } فاستعدوا للقائه بعبادته والشكر له على أنعمه ،   وبفتح التاء وكسر الجيم : يعقوب .  <br />
