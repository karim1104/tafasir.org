{ وَوَهَبْنَا لَهُ إسحاق } ولداً { وَيَعْقُوبَ } ولد ولد ولم يذكر إسماعيل لشهرته { وَجَعَلْنَا فِى ذُرّيَّتِهِ النبوة } أي في ذرية إبراهيم فإنه شجرة الأنبياء { والكتاب } والمراد به الجنس يعني التوراة والإنجيل والزبور والفرقان { وَءاتَيْنَاهُ } أي إبراهيم { أَجْرُهُ } الثناء الحسن والصلاة عليه إلى آخر الدهر ومحبة أهل الملل له ،   أو هو بقاء ضيافته عند قبره وليس ذلك لغيره { فِى الدنيا } فيه دليل على أنه تعالى قد يعطي الأجر في الدنيا { وَإِنَّهُ فِى الآخرة لَمِنَ الصالحين } أي من أهل الجنة : عن الحسن<br />
