{ وَعَاداً } منصوب بإضمار «أهلكنا » لأن قوله { فأخذتهم الرجفة } يدل عليه لأنه في معنى الإهلاك { وَثَمُودَاْ } حمزة وحفص وسهل ويعقوب { وَقَد تَّبَيَّنَ لَكُم } ذلك يعني ما وصفه من إهلاكهم { مّن مساكنهم } من جهة مساكنهم إذا نظرتم إليها عند مروركم بها ،   وكان أهل مكة يمرون عليها في أسفارهم فيبصرونها { وَزَيَّنَ لَهُمُ الشيطان أعمالهم } من الكفر والمعاصي { فَصَدَّهُمْ عَنِ السبيل } السبيل الذي أمروا بسلوكه هو الإيمان بالله ورسله { وَكَانُواْ مُسْتَبْصِرِينَ } عقلاء متمكنين من النظر وتمييز الحق من الباطل ولكنهم لم يفعلوا<br />
