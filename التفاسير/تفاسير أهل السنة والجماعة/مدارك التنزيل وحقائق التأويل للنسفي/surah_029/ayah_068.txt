{ وَمَنْ أَظْلَمُ مِمَّنِ افترى عَلَى الله كَذِباً } بأن جعل له شريكاً { أَوْ كَذَّبَ بالحق } بنبوة محمد عليه السلام والكتاب { لَمَّا جَاءهُ } أي لم يتلعثموا في تكذيبه حين سمعوه { أَلَيْسَ فِى جَهَنَّمَ مَثْوًى للكافرين } هذا تقرير لثوائهم في جهنم لأن همزة الإنكار إذا أدخلت على النفي صار إيجاباً يعني ألا يثوون فيها وقد افتروا مثل هذا التكذيب على الله وكذبوا بالحق مثل هذا التكذيب ؟ أو ألم يصح عندهم أن في جهنم مثوى للكافرين حين اجترؤوا مثل هذه الجراءة ؟ وذكر المثوى في مقابلة { لنبوئنهم } يؤيد قراءة الثاني<br />
