{ فَرَاغَ عَلَيْهِمْ ضَرْباً } فأقبل عليهم مستخفياً كأنه قال فضربهم ضرباً لأن راغ عليهم بمعنى ضربهم أو فراغ عليهم يضربهم ضرباً أي ضارباً { باليمين } أي ضرباً شديداً بالقوة لأن اليمين أقوى الجارحتين وأشدهما أو بالقوة والمتانة ،   أو بسبب الحلف الذي سبق منه وهو قوله { تالله لأَكِيدَنَّ أصنامكم } [ الأنبياء : 57 ]
