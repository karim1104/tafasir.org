{ واللائى يَئِسْنَ مِنَ المحيض مِن نّسَائِكُمْ } رُوي أن ناساً قالوا : قد عرفنا عدة ذوات الإقراء فما عدة اللائي لم يحضن ؟ فنزلت { إِنِ ارتبتم } أي أشكل عليكم حكمهن وجهلتم كيف يعتددن { فَعِدَّتُهُنَّ ثلاثة أَشْهُرٍ } أي فهذا حكمهن .  <br />
وقيل : إن ارتبتم في دم البالغات مبلغ اليأس ،   وقد قدروه بستين سنة وبخمس وخمسين أهو دم حيض أو استحاضة فعدتهن ثلاثة أشهر ،   وإذا كانت عدة المرتاب بها فغير المرتاب بها أولى بذلك { واللائي لَمْ يَحِضْنَ } هن الصغائر وتقديره واللائي لم يحضن فعدتهن ثلاثة أشهر فحذفت الجملة لدلالة المذكور عليها { وأولات الأحمال أَجَلُهُنَّ } عدتهن { أَن يَضَعْنَ حَمْلَهُنَّ } والنص يتناول المطلقات والمتوفي عنهم أزواجهن .   وعن علي وابن عباس رضي الله عنهم : عدة الحامل المتوفي عنها زوجها أبعد الأجلين { وَمَن يَتَّقِ الله يَجْعَل لَّهُ مِنْ أَمْرِهِ يُسْراً } ييسر له من أمره ويحلل من عقده بسبب التقوى<br />
