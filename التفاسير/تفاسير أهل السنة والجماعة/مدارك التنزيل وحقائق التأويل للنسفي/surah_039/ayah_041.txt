{ إِنَّا أَنزَلْنَا عَلَيْكَ الكتاب } القرآن { لِلنَّاسِ } لأجلهم ولأجل حاجتهم إليه ليبشروا وينذروا فتقوى دواعيهم إلى اختيار الطاعة على المعصية { بالحق فَمَنِ اهتدى فَلِنَفْسِهِ } فمن اختار الهدى فقد نفع نفسه { وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } ومن اختار الضلالة فقد ضرها { وَمَآ أَنتَ عَلَيْهِم بِوَكِيلٍ } بحفيظ .  <br />
