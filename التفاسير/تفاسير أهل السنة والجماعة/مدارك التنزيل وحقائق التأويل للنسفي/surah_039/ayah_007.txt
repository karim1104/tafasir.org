ثم بين أنه غني عنهم بقوله { إِن تَكْفُرُواْ فَإِنَّ الله غَنِىٌّ عَنكُمْ } عن إيمانكم وأنتم محتاجون إليه لتضرركم بالكفر وانتفاعكم بالإيمان { وَلاَ يرضى لِعِبَادِهِ الكفر } لأن الكفر ليس برضا الله تعالى وإن كان بإرادته { وَإِن تَشْكُرُواْ } فتؤمنوا { يَرْضَهُ لَكُمْ } أي يرض الشكر لكم لأنه سبب فوزكم فيثيبكم عليه الجنة { يرضه } بضم الهاء والإشباع : مكي وعلي : { يرضه } بضم الهاء بدون الإشباع : نافع وهشام وعاصم غير يحيى وحماد .   وغيرهم { يرضه } { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أخرى } أي لا يؤاخذ أحد بذنب آخر { ثُمَّ إلى رَبِّكُمْ مَّرْجِعُكُمْ } إلى جزاء ربكم رجوعكم { فَيُنَبّئُكُمْ بِمَا كُنْتُمْ تَعْمَلُونَ } فيخبركم بأعمالكم ويجازيكم عليها { إِنَّهُ عَلِيمٌ بِذَاتِ الصدور } بخفيات القلوب<br />
