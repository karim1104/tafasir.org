{ وَإِذَا مَسَّ الإنسان } هو أبو جهل أو كل كافر { ضُرٌّ } بلاء وشدة والمس في الأعراض مجاز { دَعَا رَبَّهُ مُنِيباً إِلَيْهِ } راجعاً إلى الله بالدعاء لا يدعو غيره { ثُمَّ إِذَا خَوَّلَهُ } أعطاه { نِعْمَةً مِّنْهُ } من الله عز وجل { نَسِىَ مَا كَانَ يَدْعُو إِلَيْهِ مِن قَبْلُ } أي نسى ربه الذي كان يتضرع إليه .   و «ما » بمعنى «من » كقوله : { وَمَا خَلَقَ الذكر والانثى } [ الليل : 3 ] أو نسي الضر الذي كان يدعو الله إلى كشفه { وَجَعَلَ لِلَّهِ أَندَاداً } أمثالاً { لِيُضِلَّ } { لَيِضل } مكي وأبو عمرو ويعقوب { عَن سَبِيلِهِ } أي الإسلام { قُلْ } يا محمد { تَمَتَّعَ } أمر تهديد { بِكُفْرِكَ قَلِيلاً } أي في الدنيا { إِنَّكَ مِنْ أصحاب النار } من أهلها .
