{ أَمِ اتخذوا } بل اتخذ قريش والهمزة للإنكار { مِن دُونِ الله } من دون إذنه { شُفَعَآءَ } حين قالوا { هؤلاءآء شفعاؤنا عِندَ الله } [ يونس : 18 ] ولا يشفع عنده أحد إلا بإذنه { قُلْ أَوَ لَّوْ كَانُواْ لاَ يَمْلِكُونَ شَيْئاً وَلاَ يَعْقِلُونَ } معناه أيشفعون ولو كانوا لا يملكون شيئاً قط ولا عقل لهم ؟
