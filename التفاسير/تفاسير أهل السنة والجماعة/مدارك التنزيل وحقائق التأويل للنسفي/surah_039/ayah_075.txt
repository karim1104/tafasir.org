{ وَتَرَى الملائكة حَآفِّينَ } حال من { الملائكة } { مِنْ حَوْلِ العرش } أي محدقين من حوله .   و«من » لابتداء الغاية أي ابتداء حفوفهم من حول العرش إلى حيث شاء الله { يُسَبِّحُونَ } حال من الضمير في { حَافّينَ } { بِحَمْدِ رَبِّهِمْ } أي يقولون : سبحان الله والحمد لله ولا إله إلا الله والله أكبر ،   أو سبوح قدوس رب الملائكة والروح ،   وذلك للتلذذ دون التعبد لزوال التكليف { وَقُضِىَ بَيْنَهُمْ } بين الأنبياء والأمم أو بين أهل الجنة والنار { بالحق } بالعدل { وَقِيلَ الحمد لِلَّهِ رَبِّ العالمين } أي يقول أهل الجنة شكراً حين دخولها ،   وتم وعد الله لهم كما قال { وآخر دعواهم أن الحمد لله رب العالمين } [ يونس : 10 ] ،   وكان رسول الله صلى الله عليه وسلم يقرأ كل ليلة بني إسرائيل والزمر .   الحوايم السبع كلها مكية عن ابن عباس رضي الله عنهما
