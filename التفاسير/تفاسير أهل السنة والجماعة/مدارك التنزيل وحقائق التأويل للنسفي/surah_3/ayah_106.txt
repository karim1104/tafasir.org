ونصب { يَوْمَ تَبْيَضُّ وُجُوهٌ } أي وجوه المؤمنين بالظرف وهو لهم أو بعظيم أو باذكروا { وَتَسْوَدُّ وُجُوهٌ } أي وجوه الكافرين .  <br />
والبياض من النور والسواد من الظلمة { فَأَمَّا الذين اسودت وُجُوهُهُمْ } فيقال لهم { أَكْفَرْتُمْ } فحذف الفاء ،   والقول جميعاً للعلم به والهمزة للتوبيخ والتعجب من حالهم { بَعْدَ إيمانكم } يوم الميثاق فيكون المراد به جميع الكفار وهو قول أبي وهو الظاهر ،   أو هم المرتدون أو المنافقون أي أكفرتم باطناً بعد إيمانكم ظاهراً ،   أو أهل الكتاب ،   وكفرهم بعد الإيمان تكذيبهم برسول الله صلى الله عليه وسلم بعد اعترافهم به قبل مجيئه { فَذُوقُواْ العذاب بِمَا كُنْتُمْ تَكْفُرُونَ *<br />
