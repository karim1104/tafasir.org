{ وَإِنَّ مِنْ أَهْلِ الكتاب لَمَن يُؤْمِنُ بالله } دخلت لام الابتداء على اسم «إن » لفصل الظرف بينهما { وَمَا أُنزِلَ إِلَيْكُمْ } من القرآن { وَمَا أُنزِلَ إِلَيْهِمْ } من الكتابين { خاشعين للَّهِ } حال من فاعل «يؤمن » لأن من يؤمن في معنى الجمع { لاَ يَشْتَرُونَ بئايات الله ثَمَناً قَلِيلاً } كما يفعل من لم يسلم من أحبارهم وكبارهم وهو حال بعد حال أي غير مشترين { أُوْلئِكَ لَهُمْ أَجْرُهُمْ عِندَ رَبّهِمْ } أي ما يختص بهم من الأجر وهو ما وعده في قوله<br />
{ أولئك يؤتون أجرهم مرتين } [ القصص : 54 ] { إِنَّ الله سَرِيعُ الحساب } لنفوذ علمه في كل شيء .
