{ وَقَالَت طَّائِفَةٌ مّنْ أَهْلِ الكتاب } فيم بينهم { ءامِنُواْ بالذى أُنزِلَ عَلَى الذين ءَامَنُواْ } أي القرآن { وَجْهَ النهار } ظرف أي أوله يعني أظهروا الإيمان بما أنزل على المسلمين في أول النهار { واكفروا ءاخِرَهُ } واكفروا به آخره { لَعَلَّهُمْ يَرْجِعُونَ } لعل المسلمين يقولون ما رجعوا وهم أهل كتاب وعلم إلا لأمر قد تبين لهم فيرجعون برجوعكم .  <br />
