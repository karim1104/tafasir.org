{ إِنَّ الذين تَوَلَّوْاْ مِنكُمْ } انهزموا { يَوْمَ التقى الجمعان } جمع محمد عليه السلام وجمع أبي سفيان للقتال بأحد { إِنَّمَا استزلهم الشيطان } دعاهم إلى الزلة وحملهم عليها { بِبَعْضِ مَا كَسَبُواْ } بتركهم المركز الذي أمرهم رسول الله صلى الله عليه وسلم بالثبات فيه فالإضافة إلى الشيطان لطف وتقريب والتعليل بكسبهم وعظ وتأديب .   وكان أصحاب محمد عليه السلام تولوا عنه يوم أحد إلا ثلاثة عشر رجلاً منهم أبو بكر وعلي وطلحة وابن عوف وسعد بن أبي وقاص والباقون من الأنصار { وَلَقَدْ عَفَا الله عَنْهُمْ } تجاوز عنهم { إِنَّ الله غَفُورٌ } للذنوب { حَلِيمٌ } لا يعاجل بالعقوبة<br />
