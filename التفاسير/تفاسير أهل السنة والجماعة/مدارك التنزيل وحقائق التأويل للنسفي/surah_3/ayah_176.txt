{ وَلاَ يَحْزُنكَ } «يحزنك » في كل القرآن : نافع إلا في سورة الأنبياء { لاَ يَحْزُنُهُمُ الفزع الأكبر } [ الأنبياء : 103 ] { الذين يسارعون فِى الكفر } يعني لا يحزنوك لخوف أن يضروك ألا ترى إلى قوله { إِنَّهُمْ لَن يَضُرُّواْ الله شَيْئاً } أي أولياء الله يعني أنهم لا يضرون بمسارعتهم في الكفر غير أنفسهم وما وبال ذلك عائداً على غيرهم .   ثم بين كيف يعود وباله عليهم بقوله { يُرِيدُ الله أَلاَّ يَجْعَلَ لَهُمْ حَظّاً فِى الآخرة } أي نصيباً من الثواب { وَلَهُمْ } بدل الثواب { عَذَابٌ عظِيمٌ } وذلك أبلغ ما ضر به الإنسان نفسه ،   والآية تدل على إرادة الكفر والمعاصي لأن إرادته أن لا يكون لهم ثواب في الآخرة لا تكون بدون إرادة كفرهم ومعاصيهم .
