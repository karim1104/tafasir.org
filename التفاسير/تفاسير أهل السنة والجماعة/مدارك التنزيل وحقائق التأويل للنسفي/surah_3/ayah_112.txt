{ ضُرِبَتْ } ألزمت { عَلَيْهِمُ الذلة } أي على اليهود { أَيْنَ مَا ثُقِفُواْ } وجدوا { إِلاَّ بِحَبْلٍ مِّنَ الله } في محل النصب على الحال ،   والباء متعلق بمحذوف تقديره إلا معتصمين أو متمسكين بحبل من الله { وَحَبْلٍ مّنَ الناس } والحبل العهد والذمة ،   والمعنى ضربت عليهم الذلة في كل حال إلا في حال اعتصامهم بحبل الله وحبل الناس يعني ذمة الله وذمة المسلمين أي لا عزّ لهم قط إلا هذه الواحدة وهي التجاؤهم إلى الذمة لما قبلوه من الجزية { وَبَاءُو بِغَضَبٍ مِّنَ الله } استوجبوه { وَضُرِبَتْ عَلَيْهِمُ المسكنة } الفقر عقوبة لهم على قولهم { إِنَّ الله فَقِيرٌ وَنَحْنُ أَغْنِيَاء } [ آل عمران : 181 ] أو خوف الفقر مع قيام اليسار { ذلك بِأَنَّهُمْ كَانُواْ يَكْفُرُونَ بئايات الله وَيَقْتُلُونَ الأنبياء بِغَيْرِ حَقٍّ } ذلك إشارة إلى ما ذكر من ضرب الذلة والمسكنة والبوء بغضب الله أي ذلك كائن بسبب كفرهم بآيات الله وقتلهم الأنبياء بغير حق .   ثم قال { ذلك بِمَا عَصَواْ وَّكَانُواْ يَعْتَدُونَ } أي ذلك الكفر وذلك القتل كائن بسبب عصيانهم لله واعتدائهم لحدوده .
