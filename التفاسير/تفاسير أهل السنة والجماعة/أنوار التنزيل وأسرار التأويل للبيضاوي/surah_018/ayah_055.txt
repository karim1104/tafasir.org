{ وما منع الناس أن يؤمنوا } من الإيمان .   { إذ جاءهم الهدى } وهو الرسول الداعي والقرآن المبين .   { ويستغفروا ربهم } ومن الاستغفار من الذنوب .   { إلا أن تأتيهم سنّة الأولين } إلا طلب أو انتظار أو تقدير أن تأتيهم سنة الأولين ،   وهي الاستئصال فحذف المضاف وأقيم المضاف إليه مقامه { أو يأتيهم العذاب } عذاب الآخرة .   { قُبلاً } عيانا .   وقرأ الكوفيون { قُبُلاً } بضمتين وهو لغة فيه أو جمع قبيل بمعنى أنواع ،   وقرئ بفتحتين وهو أيضا لغة يقال لقيته مقابلة وقبلاً وقبلاً وقبلياً ،   وانتصابه على الحال من الضمير أو { العذاب } .  <br />
