{ ووُضع الكتاب } صحائف الأعمال في الأيمان والشمائل أو في الميزان وقيل هو كناية عن وضع الحساب .   { فترى المجرمين مُشفقين } خائفين { ممّا فيه } من الذنوب .   { ويقولون يا ويلتنا } ينادون هلكتهم التي هلكوها من بين الهلكات .   { مالِ هذا الكتاب } تعجبا من شأنه .   { لا يغادر صغيرة } هنة صغيرة .   { ولا كبيرة إلا أحصاها } إلا عددها وأحاط بها .   { ووجدوا ما عملوا حاضرا } مكتوبا في الصحف .   { ولا يظلم ربك أحدا } فيكتب عليه ما لم يفعل أو يزيد في عقابه الملائم لعمله .  <br />
