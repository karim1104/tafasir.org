{ وعباد الرحمن }  مبتدأ خبره  { أولئك يجزون الغرفة } أو : { الذين يمشون على الأرض } وإضافتهم إلى { الرحمن } للتخصيص والتفضيل ،   أو لأنهم الراسخون في عبادته على أن عباد جمع عابد كتاجر وتجار .   { هونا } هينين أو مشيا هينا مصدر وصف به والمعنى أنهم يمشون بسكينة وتواضع { وإذا خاطبهم الجاهلون قالوا سلاما } تسلما منكم ومتاركة لكم لا خير بيننا ولا شر ،   أو سدادا من القول يسلمون فيه من الإيذاء والإثم ،   ولا ينافيه آية القتال لتنسخه فإن المراد به الإغضاء عن السفهاء وترك مقابلتهم في الكلام .  <br />
