{ وإذ قال لقمان لابنه } أنعم أو أشكم أو ماثان .   { وهو يعظه يا بني } تصغير إشفاق ،   وقرأ ابن كثير هنا وفي { يا بني أقم الصلاة } بإسكان الياء ،   وحفص فيهما وفي { يا بني إنها إن تك } بفتح الياء ومثله البزي في الأخير وقرأ الباقون في الثلاثة بكسر الياء .   { لا تشرك بالله } قيل كان كافرا فلم يزل به حتى أسلم ،   ومن وقف على { لا تشرك } جعل بالله قسما .   { إن الشرك لظلم عظيم } لأنه تسوية بين من لا نعمة إلا منه ومن لا نعمة منه .  <br />
