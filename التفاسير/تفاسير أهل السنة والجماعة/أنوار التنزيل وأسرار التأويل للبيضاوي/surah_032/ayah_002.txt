{ تنزيل الكتاب } على أن التنزيل بمعنى المنزل ،   وإن جعل تعديدا للحروف كان { تنزيل } خبر مبتدأ محذوف أو مبتدأ خبره : { لا ريب فيه } فيكون .   { من رب العالمين } حالا من الضمير في { فيه } لأن المصدر لا يعمل فيما بعد الخبر ،   ويجوز أن يكون خبرا ثانيا ولا { ريب فيه } حال من { الكتاب } ،   أو اعتراض والضمير فيه لمضمون الجملة ويؤيده قوله : { أم يقولون افتراه } .  <br />
