{ فما زالت تلك دعواهم } فما زالوا يرددون ذلك ،   وإنما سماه دعوى لأن المولول كأنه يدعوا الويل ويقول : يا ويل تعال فهذا أوانك ،   وكل من { تلك } و { دعواهم } يحتمل الاسمية والخبرية .   { حتى جعلناهم حصيدا }  مثل الحصيد وهو النبت المحصود ولذلك لم يجمع .   { خامدين } ميتين من خمدت النار وهو مع { حصيدا } بمنزلة المفعول الثاني كقولك : جعلته حلوا حامضا إذ المعنى : وجعلناهم جامعين لمماثلة الحصيد والخمود أو صفة له أو حال من ضميره .  <br />
