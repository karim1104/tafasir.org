{ مثل الذين كفروا بربهم } مبتدأ خبره محذوف أي فيما يتلى عليكم صفتهم التي هي مثل في الغرابة ،   أو قوله { أعمالهم كرماد } وهو على الأول جملة مستأنفة لبيان مثلهم .   وقيل { أعمالهم } بدل من ال { مثل } والخبر { كرماد } .   { اشتدّت به الريح } حملته وأسرعت الذهاب به وقرأ نافع  " الرياح "  .   { في يوم عاصفٍ } العصف اشتداد الريح وصف به زمانه للمبالغة كقولهم : نهاره صائم وليله قائم ،   شبه صنائعهم من الصدقة وصلة الرحم وإغاثة الملهوف وعتق الرقاب ونحو ذلك من مكارمهم في حبوطها وذهابها هباء منثورا ،   لبنائها على غير أساس من معرفة الله تعالى والتوجه بها إليه ،   أو أعمالهم للأصنام برماد طيرته الريح العاصف .   { فلا يقدرون } يوم القيامة .   { مما كسبوا } من أعمالهم .   { على شيء } لحبوطه فلا يرون له أثرا من الثواب وهو فذلكة التمثيل .   { ذلك } إشارة إلى ضلالهم مع حسبانهم أنهم محسنون .   { هو الضلال البعيد } فإنه الغاية في البعد عن طريق الحق .  <br />
