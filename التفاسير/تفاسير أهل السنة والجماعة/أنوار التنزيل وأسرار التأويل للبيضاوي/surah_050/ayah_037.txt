{ إن في ذلك } فيما ذكر في هذه السورة .   { لذكرى } لتذكرة .   { لمن كان له قلب } أي قلب واع يتفكر في حقائقه .   { أو ألقى السمع } أي أصغى لاستماعه .   { وهو شهيد } حاضر بذهنه ليفهم معانيه ،   أو شاهد بصدقه فيتعظ بظواهره وينزجر بزواجره ،   وفي تنكير ال { قلب } وإبهامه تفخيم وإشعار بأن كل قلب لا يتفكر ولا يتدبر كلا قلب .  <br />
