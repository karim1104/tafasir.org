{ ولما رأى المؤمنون الأحزاب قالوا هذا ما وعدنا الله ورسوله } بقوله تعالى : { أم حسبتم أن تدخلوا أن الجنة ولما يأتكم مثل الذين خلوا من قبلكم } الآية ،   وقوله عليه الصلاة والسلام  " سيشتد الأمر باجتماع الأحزاب عليكم والعاقبة لكم عليهم "  وقوله عليه الصلاة والسلام  " إنهم سائرون إليكم بعد تسع أو عشر "  وقرأ حمزة وأبو بكر بكسر الراء وفتح الهمزة .   { وصدق الله ورسوله } ظهر صدق خبر الله ورسوله أو صدقا في النصرة والثواب كما صدقا في البلاء ،   وإظهار الاسم للتعظيم .   { وما زادهم } فيه ضمير { لما رأوا } ،   أو الخطب أو البلاء .   { إلا إيمانا } بالله ومواعيده .   { وتسليما } لأوامره ومقاديره .  <br />
