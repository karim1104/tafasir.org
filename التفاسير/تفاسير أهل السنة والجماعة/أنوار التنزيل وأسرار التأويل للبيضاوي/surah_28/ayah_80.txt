{ وقال الذين أوتوا العلم } بأحوال الآخرة للمتمنين .   { ويلكم } دعاء بالهلاك استعمل للزجر عما لا يرتضى .   { ثواب الله } في الآخرة .   { خير لمن آمن وعمل صالحا } مما أوتي قارون بل من الدنيا وما فيها .   { ولا يلقاها } الضمير فيه للكلمة التي تكلم بها العلماء أو لل{ ثواب } ،   فإنه معنى المثوبة أو الجنة أو للإيمان والعمل الصالح فإنهما في معنى السيرة والطريقة .   { إلا الصابرون } على الطاعات وعن المعاصي .  <br />
