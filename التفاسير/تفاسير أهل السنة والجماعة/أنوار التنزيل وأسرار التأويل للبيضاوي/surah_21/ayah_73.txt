{ وجعلناهم أئمة }  يقتدى بهم .   { يهدون } الناس إلى الحق .   { بأمرنا } لهم بذلك وإرسالنا إياهم حتى صاروا مكملين .   { وأوحينا إليهم فعل الخيرات } ليحثوهم عليها فيتم كمالها بانضمام العمل إلى العلم ،   وأصله أن تفعل الخيرات ثم فعلا الخيرات ثم  { فعل الخيرات }  وكذلك قوله : { وإقام الصلاة وإيتاء الزكاة } وهو من عطف الخاص على العام للتفضيل ،   وحذفت تاء الإقامة المعوضة من إحدى الألفين لقيام المضاف إليه مقامها .   { وكانوا لنا عابدين }  موحدين مخلصين في العبادة ولذلك قدم الصلة .  <br />
