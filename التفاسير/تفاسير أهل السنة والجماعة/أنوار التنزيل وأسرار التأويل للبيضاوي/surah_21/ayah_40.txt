{ بل تأتيهم } العدة أو النار أو الساعة .   { بغتة } فجأة مصدر أو حال .   وقرىء بفتح الغين .   { فتبهتهم } فنغلبهم أو تحيرهم .   وقرىء الفعلان بالياء والضمير ل { الوعد } أو ال{ حين } وكذا في قوله : { فلا يستطيعون ردها } لأن الوعد بمعنى النار أو العدة والحين بمعنى الساعة ويجوز أن يكون ال{ لنار } أو لل{ بغتة } { ولا هم ينظرون } يمهلون وفيه تذكير بإمهالهم في الدنيا .  <br />
