{ ويرى الذين أتوا العلم } ويعلم أولو العلم من الصحابة ومن شايعهم من الأمة أو من مسلمي أهل الكتاب .   { الذي أنزل إليك من ربك } القرآن .   { هو الحق } ومن رفع { الحق } جعل هو مبتدأ و { الحق } خبره والجملة ثاني مفعولي { يرى } ،   وهو مرفوع مستأنف للاستشهاد بأولي العلم على الجهلة الساعين في الآيات .   وقيل منصوب معطوف على { ليجزي } أي وليعلم أولو العلم عند مجيء الساعة أنه الحق عيانا كما علموه الآن برهانا { ويهدي إلى صراط العزيز الحميد } الذي هو التوحيد والتدرع بلباس التقوى .  <br />
