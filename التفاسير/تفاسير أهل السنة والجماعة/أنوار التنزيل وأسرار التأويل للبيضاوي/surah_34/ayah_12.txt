{ ولسليمان الريح } أي وسخرنا له الريح ،   وقرئ { الريح } بالرفع أي ولسليمان الريح مسخرة وقرئ  " الرياح "  { غدوها شهر ورواحها شهر } جريها بالغداة مسيرة شهر وبالعشي كذلك ،   وقرئ  " غدوتها "   " وروحتها "  .   { وأسلنا له عين القطر } النحاس المذاب أساله من معدنه فنبع منه نبوع الماء من الينبوع ،   ولذلك سماه عينا وكان ذلك باليمن .   { ومن الجن من يعمل بين يديه } عطف على { الريح } { ومن الجن } حال مقدمة ،   أو جملة { من } مبتدأ وخبر .   { بإذن ربه } بأمره .   { ومن يزغ منهم } ومن يعدل منهم .   { عن أمرنا } عما أمرناه من طاعة سليمان ،   وقرئ { يزغ } من أزاغه .   { نذقه من عذاب السعير } عذاب الآخرة .  <br />
