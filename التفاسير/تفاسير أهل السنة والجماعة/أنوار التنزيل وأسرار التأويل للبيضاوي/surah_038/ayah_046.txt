{ إنا أخلصناهم بخالصة } جعلناهم خالصين لنا بخصلة خالصة لا شوب فيها هي : { ذكرى الدار }  تذكرهم الدار الآخرة دائما فإن خلوصهم في الطاعة بسببها ،   وذلك لأن مطمح نظرهم فيما يأتون ويذرون جوار الله والفوز بلقائه وذلك في الآخرة ،   وإطلاق { الدار } للإشعار بأنها الدار الحقيقة والدنيا معبر ،   وأضاف نافع وهشام { بخالصة } إلى { ذكرى } للبيان أو لأنه بمعنى الخلوص فأضيف إلى فاعله .  <br />
