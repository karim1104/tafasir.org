{ فأقم وجهك للدين القيم } البليغ الاستقامة .   { من قبل أن يأتي يوم لا مرد له } لا يقدر أن يرده أحد ،   وقوله : { من الله } متعلق ب { يأتي } ،   ويجوز أن يتعلق ب { مرد } لأنه مصدر على معنى لا يرده الله لتعلق إرادته القديمة بمجيئه .   { يومئذ يصدعون } يتصدعون أي يتفرقون { فريق في الجنة وفريق في السعير } كما قال : { من كفر فعليه كفره } .  <br />
