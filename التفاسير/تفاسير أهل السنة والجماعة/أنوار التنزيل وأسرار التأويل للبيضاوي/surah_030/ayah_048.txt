{ الله الذي يرسل الرياح فتثير سحابا فيبسطه } متصلا تارة .   { في السماء } في سمتها .   { كيف يشاء } سائرا أو واقفا مطبقا وغير مطبق من جانب دون جانب إلى غير ذلك .   { ويجعله كسفا } قطعا تارة أخرى ،   وقرأ ابن عامر بالسكون على أنه مخفف أو جمع كسفة أو مصدر وصف به .   { فترى الودق } المطر .   { يخرج من خلاله } في التارتين .   { فإذا أصاب به من يشاء من عباده } يعني بلادهم وأراضيهم .   { إذا هم يستبشرون } لمجيء الخصب .  <br />
