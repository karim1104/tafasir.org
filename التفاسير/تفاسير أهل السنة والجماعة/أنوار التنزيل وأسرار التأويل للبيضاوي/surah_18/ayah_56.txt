{ وما نُرسل المرسلين إلا مبشّرين ومنذرين } للمؤمنين والكافرين .   { ويجادل الذين كفروا بالباطل } باقتراح الآيات بعد ظهور المعجزات ،   والسؤال عن قصة أصحاب الكهف ونحوها تعنتا .   { ليُدحضوا به } ليزيلوا بالجدال .   { الحق } عن مقره ويبطلوه ،   من إدحاض القدم وهو إزلاقها وذلك قوهم للرسل { ما أنتم إلا بشر مثلنا } { ولو شاء الله لأنزل ملائكة } ونحو ذلك .   { واتخذوا آياتي } يعني القرآن .   { وما أُنذروا } وإنذارهم أو والذي أنذروا به من العقاب .   { هزُواً } استهزاء .   وقرئ  " هزأ "  بالسكون وهو ما يستهزأ به على التقديرين .  <br />
