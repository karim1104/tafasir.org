{ وعُرضوا على ربك } شبه حالهم بحال الجند المعروضين على السلطان لا ليعرفهم بل ليأمر فيهم .   { صفا } مصطفين لا يحجب أحد أحداً .   { لقد جئتمونا } على إضمار القول على وجه يكون حالا أو عاملا في يوم نسير .   { كما خلقناكم أول مرة } عراة لا شيء معكم من المال والولد كقوله { ولقد جئتمونا فرادى } أو أحياء كخلقتكم الأولى لقوله : { بل زعمتم أن لن نجعل لكم موعدا } وقتا لإنجاز الوعد بالبعث والنشور وأن الأنبياء كذبوكم به ،   وبل للخروج من قصة إلى أخرى .  <br />
