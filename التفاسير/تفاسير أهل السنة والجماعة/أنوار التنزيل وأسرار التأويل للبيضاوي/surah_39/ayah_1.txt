بسم الله الرحمن الرحيم  { تنزيل الكتاب }  خبر محذوف مثل هذا أو مبتدأ خبره { من الله العزيز الحكيم }  وهو على الأول صلة ل { تنزيل } ،   أو خبر ثان أو حال عمل فيها الإشارة أو ال { تنزيل } والظاهر أن { الكتاب } على الأول السورة وعلى الثاني القرآن ،   وقرئ  " تنزيل "  بالنصب على إضمار فعل نحو اقرأ أو الزم .  <br />
