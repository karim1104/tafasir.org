{ وأقسموا بالله جهد أيمانهم } إنكار للإمتناع عن حكمه .   { لئن أمرتهم } الخروج عن ديارهم وأموالهم .   { ليخرجن } جواب ل{ أقسموا } على الحكاية .   { قل لا تقسموا } على الكذب .   { طاعة معروفة } أي المطلوب منكم طاعة معروفة لا اليمين على الطاعة النفاقية المنكرة .   أو { طاعة معروفة } أمثل منها أو لتكن طاعة ،   وقرئت بالنصب على أطيعوا طاعة .   { إن الله خير بما تعلمون } فلا يخفى عليه سرائركم .  <br />
