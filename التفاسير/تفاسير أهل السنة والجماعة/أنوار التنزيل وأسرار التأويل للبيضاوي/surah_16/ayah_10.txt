{ هو الذي أنزل من السماء } من السحاب أو من جانب السماء .   { ماء لكم منه شرابٌ } ما تشربونه ،   { ولكم } صلة { أنزل } أو خبر { شراب } و{ من } تبعيضية متعلقة به ،   وتقديمها يوهم حصر المشروب فيه ولا بأس به لأن مياه العيون والآبار منه لقوله : { فسلكه ينابيع } وقوله : { فأسكناه في الأرض } { ومنه شجر } ومنه يكون شجر يعني الشجر الذي ترعاه المواشي .   وقيل كل ما نبت على الأرض شجر قال :<br />
يعلفها اللحم إذا عزّ الشجر *** والخيل في إطعامها اللحم ضرر<br />
