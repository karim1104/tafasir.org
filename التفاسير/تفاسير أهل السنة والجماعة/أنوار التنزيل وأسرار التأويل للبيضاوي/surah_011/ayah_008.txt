{ ولئن أخّرنا عنهم العذاب } الموعود .   { إلى أمّة معدودة } إلى جماعة من الأوقات قليلة .   { ليقولنّ } استهزاء .   { ما يحبسه } ما يمنعه من الوقوع .   { ألا يوم يأتيهم } كيوم بدر .   { ليس مصروفا عنهم } ليس العذاب مدفوعا عنهم ،   و{ يوم } منصوب بخير { ليس } مقدم عليه وهو دليل على جواز تقديم خبرها عليها .   { وحاق بهم } وأحاط بهم وضع الماضي موضع المستقبل تحقيقا ومبالغة في التهديد .   { ما كانوا به يستهزئون } أي العذاب الذي كانوا به يستعجلون ،   فوضع { يستهزئون } موضع يستعجلون لأن استعجالهم كان استهزاء .  <br />
