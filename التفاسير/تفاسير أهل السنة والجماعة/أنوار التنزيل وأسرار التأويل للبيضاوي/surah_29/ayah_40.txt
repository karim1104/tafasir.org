{ فكلا } من المذكورين .   { أخذنا بذنبه } عاقبناه بذنبه .   { فمنهم من أرسلنا عليه حاصبا }  ريحا عاصفا فيها حصباء ،   أو ملكا رماهم بها كقوم لوط .   { ومنهم من أخذته الصيحة } كمدين وثمود .   { ومنهم من خسفنا به الأرض } كقارون .   { ومنهم من أغرقنا }  كقوم نوح وفرعون وقومه .   { وما كان الله ليظلمهم } ليعاملهم معاملة الظالم فيعاقبهم بغير جرم إذ ليس ذلك من عادته عز وجل .   { ولكن كانوا أنفسهم يظلمون }  بالتعرض للعذاب .  <br />
