{ إن الله يعلم ما تدعون من دونه من شيء } على إضمار القول أي قل للكفرة إن الله يعلم ،   وقرأ البصريان بالياء حملا على ما قبله و { ما } استفهامية منصوبة ب { تدعون } و{ يعلم } معلقة عنها و{ من } للتبيين أو نافية و { من } مزيدة و { شيء } مفعول { تدعون } أو مصدرية و { شيء } مصدر أو موصولة مفعول ليعلم ومفعول { تدعون } عائدها المحذوف ،   والكلام على الأولين تجهيل لهم وتوكيد للمثل وعلى الأخيرين وعيد لهم .   { وهو العزيز الحكيم } تعليل على المعنيين فإن من فرط الغباوة إشراك ما لا يعد شيئا بمن هذا شأنه ،   وأن الجماد بالإضافة إلى القادر القاهر على كل شيء البالغ في العلم وإتقان الفعل الغاية كالمعدوم ،   وأن من هذا وصفه قادر على مجازاتهم .  <br />
