{ واذكر في الكتاب } في القرآن .   { مريم } يعني قصتها .   { إذ انتبذت } اعتزلت بدل من { مريم } بدل الاشتمال لأن الأحيان مشتملة على ما فيها ،   أو بدل الكل لأن المراد ب { مريم } قصتها وبالظرف الأمر الواقع فيه وهما واحد ،   أو ظرف لمضاف مقدر وقيل { إذ } بمعنى أن المصدرية كقولك : أكرمتك إذ لم تكرمني فتكون بدلا لا محالة .   { من أهلها مكانا شرقيا } شرقي بيت المقدس ،   أو شرقي دارها ،   ولذلك اتخذ النصارى المشرق قبلة ومكانا ظرف أو مفعول لأن { انتبذت } متضمن معنى أتت .  <br />
