{ والسابقون الأوّلون من المهاجرين } هم الذين صلوا إلى القبلتين أو الذين شهدوا بدراً أو الذين أسلموا قبل الهجرة .   { والأنصار } أهل بيعة العقبة الأولى .   وكانوا سبعة وأهل بيعة العقبة الثانية وكانوا سبعين والذين آمنوا حين قدم عليهم أبو زرارة مصعب بن عمير .   وقرئ عطفا على { والسابقون } .   { والذين اتبعوهم بإحسان } اللاحقون بالسابقين من القبيلتين ،   أو من اتبعوهم بالأيمان والطاعة إلى يوم القيامة .   { رضي الله عنهم } بقبول طاعتهم وارتضاء أعمالهم .   { ورضوا عنه } بما نالوا من نعمه الدينية والدنيوية .   { وأعدّ لهم جنات تجري تحتها الأنهار } وقرأ ابن كثير  " من تحتها الأنهار "  كما في سائر المواضع .   { خالدين فيها أبدا ذلك الفوز العظيم } .  <br />
