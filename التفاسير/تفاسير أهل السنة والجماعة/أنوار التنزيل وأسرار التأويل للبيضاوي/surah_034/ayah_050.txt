{ قل إن ضللت } عن الحق .   { فإنما أضل على نفسي } فإن وبال ضلالي عليها لأنه بسببها إذ هي الجاهلة بالذات والأمارة بالسوء ،   وبهذا الاعتبار قابل الشرطية بقوله : { وإن اهتديت فبما يوحي إلي ربي } فإن الاهتداء بهدايته وتوفيقه .   { إنه سميع قريب } يدرك قول كل ضال ومهتد وفعله وإن أخفاه .  <br />
