{ ويقول الذين آمنوا لولا نزلت سورة } أي هلا { نزلت سورة } في أمر الجهاد .   { فإذا أنزلت سورة محكمة } مبينة لا تشابه فيها .   { وذكر فيها القتال } أي الأمر به .   { رأيت الذين في قلوبهم مرض } ضعف في الدين وقيل نفاق .   { ينظرون إليك نظر المغشي عليه من  الموت } جبنا ومخافة .   { فأولى لهم } فويل { لهم } ،   أفعل من الولى وهو القرب ،   أو فعلى من آل ومعناه الدعاء عليهم بأن يليهم المكروه أو يؤول إليه أمرهم .  <br />
