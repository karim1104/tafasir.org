{ وقال الذين كفروا إن هذا إلا إفك } كذب مصروف عن وجهه .   { افتراه } اختلقه .   { أعانه عليه قوم آخرون } أي اليهود فإنهم يلقون إليه أخبار الأمم وهو يعبر عنها بعبارته ،   وقيل جبر ويسار وعداس وقد سبق في قوله { إنما يعلمه بشر } .   { فقد جاءوا ظلما } بجعل الكلام المعجز { إفك } مختلفا متلقفا من اليهود .   { وزورا } بنسبة ما هو بريء منه إليه وأتى وجاء يطلقان بمعنى فعل فيعديان تعديته .  <br />
