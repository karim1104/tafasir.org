{ ونادى فرعون } بنفسه أو بمناديه .   { في قومه }  في مجمعهم أو فيما بينهم بعد كشف العذاب عنهم مخافة أن يؤمن بعضهم .   { قال يا قوم أليس لي ملك مصر وهذه الأنهار }  أنهار النيل ومعظمها أربعة أنهر : نهر الملك ،   ونهر طولون ،   ونهر دمياط ،   ونهر تنيس .   { تجري من تحتي } تحت قصري أو أمري ،   أو بين يدي في جناني والواو إما عاطفة لهذه { الأنهار } على الملك و { تجري } حال منها .   أو واو حال وهذه مبتدأ و { الأنهار } صفتها و { تجري } خبرها .   { أفلا تبصرون } ذلك .  <br />
