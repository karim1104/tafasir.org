{ كلاًّ } كل واحد من الفريقين ،   والتنوين بدل من المضاف إليه .   { نُمدّ } بالعطاء مرة بعد أخرى ونجعل آنفه مدادا لسالفه .   { هؤلاء وهؤلاء } بدل من { كلا } .   { من عطاء ربك } من معطاه متعلق ب { نمد } .   { وما كان عطاء ربك محظورا } ممنوعا لا يمنعه في الدنيا من مؤمن ولا كافر تفضلا .  <br />
