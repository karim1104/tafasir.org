{ يوم يأتي } أي الجزاء أو اليوم كقوله : { أو تأتيهم الساعة } على أن { يوم } بمعنى حين أو الله عز وجل كقوله تعالى : { هل ينظرون إلا أن يأتيهم الله في ظلل } ونحوه .   وقرأ ابن عامر وعاصم وحمزة { يأت } بحذف الياء اجتراء عنها بالكسرة .   { لا تكلّم نفس } لا تتكلم بما ينفع وينجي من جواب أو شفاعة ،   وهو الناصب للظرف ويحتمل نصبه بإضمار اذكر أو بالانتهاء المحذوف .   { إلا بإذنه } إلا بإذن الله كقوله : { لا يتكلمون إلا من أذن له الرحمان } وهذا في موقف وقوله : { هذا يوم لا ينطقون ولا يؤذن لهم فيعتذرون } في موقف آخر أو المأذون فيه هي الجوابات الحقة والممنوع عنه هي الأعذار الباطلة .   { فمنهم شقيّ } وجبت له النار بمقتضى الوعيد .   { وسعيد } وجبت له الجنة بموجب الوعد والضمير لأهل الموقف وإن لم يذكر لأنه معلوم مدلول عليه بقوله : { لا تكلم نفس } أو للناس .  <br />
