{ أفحسبتم أنما خلقناكم عبثا } توبيخ على تغافلهم ،   و { عبثا } حال بمعنى عابثين أو مفعول له أي : لم نخلقكم تلهيا بكم وإنما خلقناكم لنتعبدكم ونجازيكم على أعمالكم وهو كالدليل على البعث .   { وأنكم إلينا لا ترجعون } معطوف على { أنما خلقناكم } أو { عبثا } ،   وقرأ حمزة والكسائي ويعقوب بفتح التاء وكسر الجيم .  <br />
