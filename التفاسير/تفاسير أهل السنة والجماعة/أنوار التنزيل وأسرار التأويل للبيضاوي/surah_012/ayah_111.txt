{ لقد كان في قصصهم } في قصص الأنبياء وأممهم أو في قصة يوسف وإخوته { عبرة لأولي الألباب } لذوي العقول - المبرأة من شوائب الإلف والركون إلى الحس .   { ما كان حديثا يُفترى } ما كان القرآن حديثا يفترى .   { ولكن تصديق الذي بين يديه } من الكتب الإلهية .   { وتفصيل كل شيء } يحتاج إليه في الدين إذ ما من أمر ديني إلا وله سند من القرآن بوسط أو بغير وسط .   { وهدى } من الضلال .   { ورحمة } ينال بها خير الدارين .   { لقوم يؤمنون } يصدقونه .  <br />
