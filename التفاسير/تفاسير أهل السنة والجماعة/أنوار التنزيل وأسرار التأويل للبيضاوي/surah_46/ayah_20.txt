{ ويوم يعرض الذين كفروا على النار } يعذبون بها .   وقيل تعرض النار عليهم فقلب مبالغة كقولهم : عرضت الناقة على الحوض .   { أذهبتم } أي يقال لهم أذهبتم ،   وهو ناصب اليوم وقرأ ابن كثير وابن عامر ويعقوب بالاستفهام غير أن ابن كثير يقرؤه بهمزة ممدودة وهما يقرآن بها وبهمزتين محققتين .   { طيباتكم } لذاتكم .   { في حياتكم الدنيا } باستيفائها .   { واستمتعتم بها }  فما بقي لكم منها شيء .   { فاليوم تجزون عذاب الهون } الهوان وقد قرئ به .   { بما كنتم تستكبرون في الأرض بغير الحق وبما كنتم تفسقون } بسبب الاستكبار الباطل والفسوق عن طاعة الله ،   وقرئ { تفسقون } بالكسر .  <br />
