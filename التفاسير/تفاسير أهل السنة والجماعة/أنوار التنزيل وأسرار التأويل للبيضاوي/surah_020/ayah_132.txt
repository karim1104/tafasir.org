{ وأمر أهلك بالصلاة } أمره بأن يأمر أهل بيته أو التابعين له من أمته بالصلاة بعد ما أمر بها ليتعاونوا على الاستعانة بها على خصاصتهم ولا يهتموا بأمر المعيشة ولا يلتفتوا لفت أرباب الثروة .   { واصطبر عليها } وداوم عليها .   { لا نسألك رزقا } أي أن ترزق نفسك ولا أهلك .   { نحن نرزقك } وإياهم ففرغ بالك لأمر الآخرة .    { والعاقبة } المحمودة .   { للتقوى } لذوي التقوى .   روي  " أنه عليه الصلاة والسلام كان إذا أصاب أهله ضر أمرهم بالصلاة وتلا هذه الآية .  <br />
