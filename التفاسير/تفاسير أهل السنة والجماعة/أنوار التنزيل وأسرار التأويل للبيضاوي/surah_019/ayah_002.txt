{ ذكر رحمت ربك } خبر ما قبله إن أول السورة أو بالقرآن ،   فإنه مشتمل عليه أو خبر محذوف أي : هذا المتلو { ذكر رحمة ربك } ،   أو مبتدأ حذف خبره أي فيما يتلى عليك ذكرها ،   وقرئ  { ذكر رحمة }  على الماضي و { ذكر } على الأمر .   { عبده } مفعول الرحمة أو الذكر على أن الرحمة فاعله على الاتساع كقولك : ذكرني جود زيد .   { زكريا } بدل منه أو عطف بيان له .  <br />
