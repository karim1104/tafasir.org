{ والبلد الطيب } الأرض الكريمة التربة .   { يخرج نباته بإذن ربه } بمشيئته وتيسيره ،   عبر به عن كثرة النبات وحسنه وغزارة نفعه لأنه أوقعه في مقابلة .   { والذي خبُث } أي كالحرة والسبخة .   { لا يخرج إلا نكدا } قليلا عديم النفع ،   ونصبه على الحال وتقدير الكلام ،   والبلد الذي خبث لا يخرج نباته إلا نكدا فحذف المضاف وأقيم المضاف إليه مقامه فصار مرفوعا مستترا وقرئ { يخرج } أي يخرجه البلد فيكون { إلا نكدا } مفعولا و{ نكدا } على المصدر أي ذا نكد و{ نكدا } بالإسكان للتخفيف .   { كذلك نصرّف الآيات } نرددها ونكررها .   { لقوم يشكرون } نعمة الله فيتفكرون فيها ويعتبرون بها ،   والآية مثل لمن تدبر الآيات وانتفع بها ،   ولمن لم يرفع إليها رأسا ولم يتأثر بها .  <br />
