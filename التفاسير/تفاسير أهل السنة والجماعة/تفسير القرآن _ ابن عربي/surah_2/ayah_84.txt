{ وإذ أخذنا ميثاقَكم لا تسفِكُون دِماءَكُم } بهواكم إلى مقارّ النفس وصفاتها وميلكم إلى هواها وطباعها، ومتاركتكم حياتكم الحقيقية، وخواص أفعالكم لأجل تحصيل مآربها ولذاتها { ولا تُخْرِجون أنفُسَكُم } أي: ذواتكم. إذ يعبر بالنفس عن الذات { من دِيَارِكُم } أي: مقارّكم الروحانية والروضات القدسية { ثم أقْرَرْتم } بقبولكم لذلك { وأنتُم تَشْهدون } عليه باستعداداتكم الأوليّة وعقولكم الفطرية.
