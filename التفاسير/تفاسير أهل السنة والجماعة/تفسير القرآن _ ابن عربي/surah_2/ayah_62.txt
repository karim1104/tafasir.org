{ إن الذينَ آمنُوا } الإيمان التقليديّ، والظاهريين والباطنيين والذين تعبدوا ملائكة العقول، لاحتجابهم بالمعقولات وكواكب القوى النفسانية لاحتجابهم بالوهميات والخياليات { مَن آمَن } منهم الإيمان الحقيقي { بالله } والمعاد وأيقنوا علم التوحيد والقيامة، وعملوا ما يصلحهم للقاء الله ونيل السعادة في المعاد، فلهم الثواب الباقي الروحانيّ عند ربهم من جنّات الأفعال والصفات { ولا خوفٌ عليهِم } من عقوبة أفعالهم { ولا هم يحزنون } بفوات تجليّات الصفات. والجملة اعتراض بين خطاب بني إسرائيل.
