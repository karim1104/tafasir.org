{ إنّ الذين كَفَرُوا } حجبوا عن الدين أو الحق { وماتُوا وهم كفّار } أي: بقوا على احتجابهم حتى زال استعدادهم وانطفأ نور فطرتهم بدين الحجاب، وانقطعوا عن الأسباب التي يمكن بها رفع حجاب الموت { أولئك عليهم لعنَة الله والملائكة والناس أجْمَعِين } أي: استحقوا البعد والحرمان والطرد الكليّ عن الحق وعن عالم الملكوت وعن الفطرة الإنسانية المعبر عنه بالطمس.
