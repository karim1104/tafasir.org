{ إذا زُلْزِلت } أرض البدن عند نزع الروح الإنساني باضطراب الروح الحيواني والقوى { زلزالها } الذي استوجبته في تلك الحالة المؤذنة بخرابها وانتقاض بنيتها. { وأخرجت الأرض أثقالها } أي: متاعها التي هي بها ذات قدر من القوى والأرواح وهيئات الأعمال والاعتقادات الراسخة في القلب جمع ثقل وهو متاع البيت. { وقال الإنسان ما لها } أي: ما لها زلزلت واضطربت ما طبّها، ما داؤها؟ ألانحراف المزاج أم لغلبة الأخلاط. { يومئذ تحدّث أخبارها } بلسان حالها { بأن ربّك } أشار إليها وأمرها بالاضطراب والخراب وإخراج الأثقال عند زهوق الروح وتحقق الموت.
