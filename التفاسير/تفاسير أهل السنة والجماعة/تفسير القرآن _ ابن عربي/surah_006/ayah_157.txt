{ ثم آتينا موسى الكتاب } أي: بعدما وصّاكم بسلوك طريق الفضيلة في قديم الدهر [البقرة، الآية: 153] { تماماً على الذي أحسن } أي: تتميماً لكرامة الولاية ونعمة النبوّة مزيداً على الذي أحسنه موسى من سلوك طريق الكمال وبلوغه إلى ما بلغ من مقام المكالمة والقرب بالوجود الموهوب بعد الفناء في الوحدة، كما قال تعالى: [الأعراف، الآية: 143] بالتكميل ودعوة الخلق إلى الحق { وتفصيلاً لكل شيء } يحتاج إليه الخلق في المعاد { وهدى } لهم إلى ربّهم في سلوك سبيله { ورحمة } عليهم بإفاضة كمالاته عليهم بواسطة موسى وكتابه { لعلهم بلقاء ربّهم يؤمنون } الإيمان العلمي أو العياني. { وهذا كتابٌ أنزلناه مُبَارك } بزيادة الهداية إلى محض التوحيد والإرشاد إلى سواء السبيل يهدي بأقرب الطرق إلى أرفع الدرجات من الكمال { فاتّبعوه واتّقوا } كل ما سوى الله حتى ذواتكم وصفاتكم { لعلكم ترحمون } رحمة الاستقامة بالله وفي الله بالوجود الموهوب. { أو تقولوا لو أنّا أُنْزِل علينا الكتاب لكنا أهدى منهم } لقوّة استعداداتنا وصفاء أذهاننا إن صدقتم { فقد جاءتكم بينة من ربكم } بيان لكيفية سلوككم { وهدى } إلى مقصدكم { ورحمة } بتسهيل طريقكم وتيسيرها إلى أشرف الكمالات.
