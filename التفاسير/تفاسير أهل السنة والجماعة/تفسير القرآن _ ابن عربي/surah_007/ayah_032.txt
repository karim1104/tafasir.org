{ خذوا زينتكم عند كل مسجد } أي: لازموها وتمسكوا بها، فزينة المقام الأول من السجود هي الإخلاص في العمل لله، وزينة المقام الثاني هي التوكل ومراعاة شرائطه، وزينة المقام الثالث هي القيام بحق الرضا، وزينة المقام الرابع هي التمكين في التحقيق بالحقيقة الحقيّة ومراعاة حقوق الاستقامة وشرائطها { وكلوا واشْرَبوا ولا تسرفوا } بالمحافظة على قانون العدالة فيها { قل من حرّم زينة الله التي أخرج لعباده } أي: من منعهم من جنس هذه الزينة المذكورة المطلقة وقال إنه لا يمكنهم التزين بها واستحال ذلك منهم تمسكاً بأن الله مانعهم. { والطيبات } من رزق علوم الإخلاص وعلوم مقام التوكل والرضا والتمكين { خالصة يوم القيامة } عن شوب التلوينات وظهور شيء من بقايا الأفعال والصفات والذات.  { قل إنما حرّم ربي الفواحش } أي: رذائل القوة البهيمية { والإثم والبغي } أي: رذائل القوّة السبعية { وأن تشركوا } إلى آخره، أي: رذائل القوّة النطقية الملكية لأنها صفات نفسانية مانعة عن الزينة المذكورة التي هي الكمالات الإنسانية مضادة لها.
