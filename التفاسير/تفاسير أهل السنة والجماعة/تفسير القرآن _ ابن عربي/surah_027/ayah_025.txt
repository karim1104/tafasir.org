{ ألا يسجدوا لله } أي: فصدّهم عن السبيل لئلا ينقادوا ويذعنوا في إخراج كمالاتهم إلى العقل { الذي يخرج الخبء } أي: المخبوء من الكمالات الممكنة في سموات الأرواح وأرض الجسم { ويعلم ما يخفون } مما فيهم بالقوة من الكمالات بالأعمال الحاجبة والمانعة لخروج ما في الاستعداد إلى العقل { وما يعلنون } من الهيئات المظلمة والأخلاق المردية. { الله لا إله إلا هو } فلا يجوز التعبّد والانقياد إلا له { ربّ العرش العظيم } المحيط بكل شيء، فما أصغر عرش بلقيس النفس في جنب عظمته، فكيف لا تطيعه وتحتجب بمحبة عرشها عن طاعته { سننظر أصدقت } في تضليلهم والإحاطة بأحوالهم بالطريق العقلي { أم كنت من الكاذبين } بموافقة الوهم وتركيب التخيلات الفاسدة.
