{ يدعون فيها بِكُل فَاكِهة } أي: كل ما يتلذذ به من لذائذ الجنان الثلاث { آمِنِين } من الفناء والحرمان عن تلك النعماء { لا يذوقون فيها الموت إلاَّ الموتة الأولى } أي: الطبيعة الجسمانية لا الفناء من الأفعال والصفات والذات فإنّ كل فناء منها وإن كان موتاً إرادياً لكنه حياة أصفى وألذ وأشهى وأبهج مما قبلها وكل منها في جنة { ووقاهم عذاب الجحيم } أي: جحيم الحرمان بوجود البقية فضلاً عن الخذلان في جحيم الطبيعة { فضلاً من ربّك } موهبة محضة وعطاء صرفاً من ربك بالوجود الحقاني عند تلاشي الآلات النفسانية { ذلِكَ هو الفَوْز العظيم } والله أعلم.
