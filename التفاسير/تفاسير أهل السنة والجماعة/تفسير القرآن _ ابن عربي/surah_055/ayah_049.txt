{ يعرف المجرمون } الذين غلبت عليهم الهيئات الجرمانية باكتساب الرذائل ورسوخها { بسيماهم } أي: بعلامات تلك الهيئات الظاهرة الغالبة عليهم { فيؤخذ بالنواصي } فيعذبون من فوق ويحجبون ويحبسون مقيدين أسراء من جهة رذيلة الجهل المركب ورسوخ الاعتقادات الفاسدة { والأقدام } أي: يعذبون من أسفل، ويجرّون ويسحبون على وجوههم، ويردّون إلى قعر جهنم كما قيل: يهوي أحدهم فيها سبعين خريفاً لرسوخ الهيئات البدنية والرذائل العملية من إفراط الحرص والشره والبخل والطمع وارتكاب الفواحش والآثام من قبيل الشهوة والغضب. { هذه جهنم } قعر بئر أسفل سافلين من الطبيعة الجسمانية { يطوفون بينهما وبين حميم } قد انتهى حره وإحراقه من الجهل المركب ولهذا قيل: يصبّ من فوق رؤوسهم الحميم، لأن العذاب المستحق من جهة العمل هو نار جهنم من تحت والمستحق من جهة العلم هو الحميم من فوق. { ولمن خاف مقام ربّه } أي: خاف قيامه على نفسه بكونه رقيباً، حافظاً، مهيمناً عليه كما قال: [الرعد، الآية:33] أو خاف ربه كما يقال: خدمت حضرة فلان أي: نفسه { جنتان } إحداهما جنة النفس، والثانية جنة القلب لأن الخوف من صفات النفس ومنازلها عند تنوّرها بنور القلب { ذواتا أفنان } لتفنن شعبهما من القوى والصفات المورقة للأعمال والأخلاق المثمرة للعلوم والأحوال، فإن الأفنان هي المغصنات التي تشعبت عن فروع الشجر عليها الأوراق والثمار.
