{ ها أنتم أولاء تحبونهم } بمقتضى التوحيد، إذ الموحد يحب الناس كلهم بالحق للحق، ويراهم متصلين بنفسه اتصال الأحماء والأقرباء بل اتصال الأجزاء، فينظر إليهم بنظر الرحمة الإلهية والرأفة الربانية، ويعطف عليهم مترحماً إذ يراهم أهل الرحمة شغلوا بالباطل، وابتلوا بالقدر ولا يحبونكم بمقتضى الحجاب والبقاء في ظلمة النفس وتضادّ الطبع. { وتُؤمِنون بالكتاب } أي بجنس الكتاب { كله } لشمول علمكم التوحيدي، ولا يؤمنون للتقيد بدينهم والاحتجاب بما هم عليه { وإذا لقوكم قالوا آمنا } لنفاقهم المستجلب لأغراضهم العاجلة { وإذا خلوا عضوا عليكم الأنامل من الغيظ } لحقدهم الذاتي وبغضهم الكامن والباقي ظاهر.
