قوله تعالى: { ٱلَّذِينَ يَجْتَنِبُونَ كَبَائِرَ ٱلإِثْمِ وَٱلْفَوَاحِشَ } [الآية: 32].  قال ذو النون: ذكر الفاحشة من العارف كفعلها من غيره.  قوله تعالى: { إِنَّ رَبَّكَ وَاسِعُ ٱلْمَغْفِرَةِ } [الآية: 32].  { وَاسِعُ ٱلْمَغْفِرَةِ } لمن استغفره ورأى تقصيره بالقيام بواجب أمره.  قوله تعالى: { هُوَ أَعْلَمُ بِكُمْ إِذْ أَنشَأَكُمْ مِّنَ ٱلأَرْضِ } [الآية: 32].  قال جعفر: أعلم بكم لأنه خلقكم وقدر عليكم السعادة والشقاء قبل إيجادكم فإنكم ستقبلون فى ما جرى عليكم فى السبق من الأجل والرزق والسعادة والشقاوة ولا تستجلب الطاعات سعادة ولا المخالفات ولكن سابق المقدور هو الذى يحتم بما بدأ به.  قوله تعالى: { فَلاَ تُزَكُّوۤاْ أَنفُسَكُمْ } [الآية: 32].  قال أبو عثمان رحمة الله عليه: من علم أين هو وإلى أين هو فى الوقت علم أنه ليس بمحل التزكية ومع هذا هو مخاطب بقوله: { فَلاَ تُزَكُّوۤاْ أَنفُسَكُمْ } وبماذا يزكى نفسه أبأخلاقه أم أفعاله أم أقواله أم أحواله؟ كلا لكن نفسه هى الأمارة بالسوء التى إلى أى جانب أبصر رأى نفص الرق وذل العبودية.
