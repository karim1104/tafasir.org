قوله عز وعلا: { إِنَّا لَنَنصُرُ رُسُلَنَا وَٱلَّذِينَ آمَنُواْ فِي ٱلْحَيَاةِ ٱلدُّنْيَا } [الآية: 51].  قال جعفر: ننصر رسلنا بالمؤمنين ظاهرًا وننصر المؤمنين بالرسل باطنًا.  وقال سهل فى قوله: { نَنصُرُ رُسُلَنَا.... فِي ٱلْحَيَاةِ ٱلدُّنْيَا } قال: يكرمهم بالمعرفة والعلم { وَيَوْمَ يَقُومُ ٱلأَشْهَادُ } قال: لم يرض بما ضمن لهم النصرة فى الدنيا حتى ضمن لهم النصرة فى القيامة ومن كان الله ناصره فى الدنيا والآخرة فلا سوء عليه.
