قوله تعالى: { أَلَمْ نَشْرَحْ لَكَ صَدْرَكَ } [الآية: 1].  قال سهل رحمه الله: ألم نوسع صدرك بنور الرسالة فجعلناه معدنًا للحقائق.  وقال: ألم نوسع صدرك لقبول ما يرد عليك وقال فى قوله: { وَوَضَعْنَا عَنكَ وِزْرَكَ } [الآية: 2]: أعباء النبوة والرسالة فكنت فيها محمولاً لا حاملاً.  وقال أيضًا: { وَوَضَعْنَا عَنكَ وِزْرَكَ } ألم نمنَّ عليك بالاحتمال من المخالفين، ووضعنا عنك وزرك، كادت نفسك أن تتلف عند حمل النبوة فأعنَّاك عليه، وقويناك عند الإبلاغ.  وقال جعفر: { أَلَمْ نَشْرَحْ لَكَ صَدْرَكَ } بمشاهدى ومطالعتى.  سمعت منصور بن عبد الله يقول: سمعت أبا القاسم يقول: قال ابن عطاء: فى قوله: { أَلَمْ نَشْرَحْ لَكَ صَدْرَكَ } قال: ألم نخل سرك عن الكل فغبت عن مشاهدة الكون وما سوى الحق، فشرح لك صدرك للنظر، وشرح صدر موسى للكلام صلى الله عليهما.  وقال فى قوله: { وَوَضَعْنَا عَنكَ وِزْرَكَ } ألم أزل ملاحظة المخلوقين عن سرك.  وقال بعضهم: خففنا عنك بحفظ ما استحفظت وحفظنا عنك.  وقال فى قوله: { وَوَضَعْنَا عَنكَ وِزْرَكَ } قال: حفظتك فى الأربعين من الأدناس إلى أن ظهرت لك النبوة وألقى إليك الرسالة.
