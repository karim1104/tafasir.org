قوله تعالى: { يُنَادُونَهُمْ أَلَمْ نَكُن مَّعَكُمْ } [الآية: 14].  قال الحسين بن معاذ: من خالف عقدك عقده خالف قلبك قلبه.  قال حاتم الأصم: لا تصلح الموافقة إلا بالأسرار فأما موافقة الظاهر فإنه الرياء والمدامجة والموافقة موافقة الدين ثم موافقة الاعتقاد ثم موافقة الأخوة ثم موافقة المؤانسة ثم موافقة الصحبة ثم موافقة السنن والشريعة فمن صحت شريعته وصحت موافقته فى هذه الأصول تصح عشرته وإلا فهو كما قال الله: { يُنَادُونَهُمْ أَلَمْ نَكُن مَّعَكُمْ } فى الظاهر { قَالُواْ بَلَىٰ وَلَـٰكِنَّكُمْ فَتَنتُمْ أَنفُسَكُمْ } بمخالفة الأصول فى الباطن.  قوله تعالى: { قَالُواْ بَلَىٰ وَلَـٰكِنَّكُمْ... } الآية.  قال أبو بكر الوراق: الفتنة من أربعة أشياء فمن فر منها ينبغى أن يمحو عنوانه منها وهو الكلام والصحبة والزىّ والفضائل فإن ترك الكلام جعل الفعل عوضاً منه وإن ترك زى النساك جعل أخلاقهم عوضاً منه، فذلك الناجى من الفتنة إن شاء الله.  قال أبو سعيد بن الأعرابى: { فَتَنتُمْ أَنفُسَكُمْ } بالمعاصى: { وَتَرَبَّصْتُمْ وَٱرْتَبْتُمْ } تشككتم و { وَغرَّتْكُمُ ٱلأَمَانِيُّ } فلم تستغفروا لما سلف منكم وركنتم إلى الدنيا { وَغَرَّكُم بِٱللَّهِ ٱلْغَرُورُ } الشيطان والنفس والهوى والدنيا.
