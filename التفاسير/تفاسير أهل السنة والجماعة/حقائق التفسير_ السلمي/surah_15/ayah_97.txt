قوله عز وجل: { وَلَقَدْ نَعْلَمُ أَنَّكَ يَضِيقُ صَدْرُكَ بِمَا يَقُولُونَ } [الآية: 97].  بجهلهم وحدهم فيكم ثم أمرهم بلزوم طاعته يقول: { فَسَبِّحْ بِحَمْدِ رَبِّكَ } [الآية: 98].  وقوله تعالى: { فَسَبِّحْ بِحَمْدِ رَبِّكَ وَكُنْ مِّنَ ٱلسَّاجِدِينَ } [الآية: 98].  قال الواسطى: { فَسَبِّحْ بِحَمْدِ رَبِّكَ } عن أن يظلمك فيما سلطه عليك، { وَكُنْ مِّنَ ٱلسَّاجِدِينَ } من الخاضعين لقضائه.
