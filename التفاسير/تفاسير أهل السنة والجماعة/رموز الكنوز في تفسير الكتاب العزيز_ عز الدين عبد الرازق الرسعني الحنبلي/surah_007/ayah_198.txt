ثم بيّن السبب الموجب لعدم اكتراثه فقال: { إِنَّ وَلِيِّـيَ ٱللَّهُ } إن الذي يتولى نصري وحفظي الله، { ٱلَّذِي نَزَّلَ ٱلْكِتَابَ } دليلاً على صدقي ومعجزةً شاهدةً برسالتي، { وَهُوَ يَتَوَلَّى ٱلصَّالِحِينَ }.  قال ابن عباس: هم الذين لا يعدلون بالله شيئاً.  والمعنى: هو يتولاهم بالنصر على أعدائهم.  قوله تعالى: { وَتَرَٰهُمْ يَنظُرُونَ إِلَيْكَ } أي: كأنهم ينظرون إليك بالأعين المصورة، { وَهُمْ لاَ يُبْصِرُونَ } على الحقيقة.
