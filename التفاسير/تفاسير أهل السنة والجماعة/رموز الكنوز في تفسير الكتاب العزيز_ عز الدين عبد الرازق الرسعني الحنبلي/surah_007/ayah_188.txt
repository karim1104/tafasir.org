{ قُل لاَّ أَمْلِكُ لِنَفْسِي نَفْعاً } فأتلقاه { وَلاَ ضَرّاً } فأتوقاه.  قال الكلبي: نزلت حين قال أهل مكة: يا محمد، ألا يخبرك ربك بالسعر الرخيص قبل أن يغلو، فتشتري من الرخيص لتربح عليه عند الغلاء؟ والأرض التي تريد أن تجدب فترتحل منها؟.  { إِلاَّ مَا شَآءَ ٱللَّهُ } أن أملكه. والمعنى: إذا كنت هكذا، فكيف أعلم متى تقوم الساعة؟ { وَلَوْ كُنتُ أَعْلَمُ ٱلْغَيْبَ } قبل وقوعه { لاَسْتَكْثَرْتُ مِنَ ٱلْخَيْرِ } من أسباب الرزق والنصر على الأعداء { وَمَا مَسَّنِيَ ٱلسُّوۤءُ } الفقر وغيره مما يسوء النفس ويؤلمها، { إِنْ أَنَاْ إِلاَّ نَذِيرٌ } فيه إضمار، تقديره: إن أنا إلا نذير للكفار من عذاب النار، { وَبَشِيرٌ } للمؤمنين بالجنة، وقيل: النذارة والبشارة للمؤمنين؛ لمكان انتفاعهم بها.
