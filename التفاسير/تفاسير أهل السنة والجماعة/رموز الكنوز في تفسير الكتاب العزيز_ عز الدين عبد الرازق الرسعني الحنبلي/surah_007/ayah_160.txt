قوله تعالى: { وَقَطَّعْنَاهُمُ } يعني: بني إسرائيل { ٱثْنَتَيْ عَشْرَةَ أَسْبَاطاً أُمَماً } إن قيل: ما فوق العشرة من العدد لا يفسر بالجمع، فكيف قال: أسباطاً؟  قلت: جعله نعتاً لمحذوف، باعتباره وقع التأنيث في العدد، تقديره: اثنتي عشرة فرقة أسباطاً. وقوله: " أمماً " بدل من " اثنتي عشرة ".  { وَأَوْحَيْنَآ إِلَىٰ مُوسَىٰ إِذِ ٱسْتَسْقَاهُ قَوْمُهُ } يعني: في التيه { أَنِ ٱضْرِب بِّعَصَاكَ ٱلْحَجَرَ } تقديره: فضرب، { فَٱنبَجَسَتْ } أي: انفجرت { مِنْهُ ٱثْنَتَا عَشْرَةَ عَيْناً } وقد سبق تفسير ما لم أذكره هاهنا في البقرة.
