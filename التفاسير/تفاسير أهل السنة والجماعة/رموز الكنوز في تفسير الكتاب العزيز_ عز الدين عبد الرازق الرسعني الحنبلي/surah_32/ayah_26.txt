قوله تعالى: { أَوَلَمْ يَهْدِ لَهُمْ } وقرأ أبو عبد الرحمن السلمي: " نَهْدِ " بالنون. وقد سبق تفسيره في آخر طه.  والضمير في قوله: { لَهُمْ } لأهل مكة، { يَمْشُونَ }. وقرئ شاذاً: " يُمَشُّونَ " بالتشديد، { فِي مَسَاكِنِهِمْ } أي: يمرّون في متاجرهم على مساكنهم.  قوله تعالى: { أَوَلَمْ يَرَوْاْ أَنَّا نَسُوقُ ٱلْمَآءَ } المطر أو السيل { إِلَى ٱلأَرْضِ ٱلْجُرُزِ } قال الزمخشري: هي التي جُرِزَ نباتها، أي: قُطِعَ؛ إما لعدم الماء، وإما لأنه رعي وأزيل، ولا يقال للتي لا تنبت كالسباخ: جُرُز. ويدل عليه قوله: { فَنُخْرِجُ بِهِ زَرْعاً }.
