قوله تعالى: { يَحْسَبُونَ ٱلأَحْزَابَ لَمْ يَذْهَبُواْ } أي: يظن المنافقون -لِمَا يداخلهم من الخوف المفرط وما عندهم من الجبن الشديد- أن الأحزاب لم يذهبوا راجعين إلى مكة.  { وَإِن يَأْتِ ٱلأَحْزَابُ } كرّة ثانية { يَوَدُّواْ } لما أصابهم في الكَرَّة الأولى { لَوْ أَنَّهُمْ بَادُونَ فِي ٱلأَعْرَابِ } وقرأ ابن عباس: " لو أنهم بُدَّىً " بتشديد الدال والتنوين، جمع باد؛ كغَازٍ وغُزَّىً. والمعنى: يحبوا لو أنهم في البادية مع الأعراب حذراً من القتال الذين لا يرجون بفعله ثواباً ولا يخافون بتركه عقاباً.  { يَسْأَلُونَ } كل وارد عليهم وداخل إليهم { عَنْ أَنبَآئِكُمْ } أما هلك محمد وأصحابه؟ ما فعل أبو سفيان وأحزابه؟.  وقرأت ليعقوب من رواية رويس: " يَسَّاءَلُوا " بالمد وتشديد السين، على معنى: يتساءلون ويقول بعضهم لبعض: ماذا سمعت.  { وَلَوْ كَانُواْ فِيكُمْ } ولم يرجعوا إلى المدينة وكان قتال { مَّا قَاتَلُوۤاْ إِلاَّ قَلِيلاً } أي: لم يقاتلوا إلا تعللاً رياءً وسمعة.  وفي هذا الكلام تسلية للنبي صلى الله عليه وسلم والمؤمنين، وإعلام لهم أن حضور المنافقين للقتال وعدم حضورهم سِيّان؛ لكونهم لا غنى عندهم في الحرب ولا يقع فيهم.
