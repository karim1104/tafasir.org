قوله تعالى: { تَلْكَ } إشارة إلى [ما] تقدم إنزاله من القرآن، أو إلى هذه الحجج المذكورة.  { ءَايَٰتُ ٱللَّهِ نَتْلُوهَا عَلَيْكَ بِٱلْحَقِّ } مُفسّر في سورة البقرة.  { فَبِأَيِّ حَدِيثٍ بَعْدَ ٱللَّهِ وَءَايَٰتِهِ يُؤْمِنُونَ } مُفسّر في الأعراف.  قرأ ابن كثير ونافع وأبو عمرو وحفص: " يؤمنون " بالياء حملاً على ما قبله من الغيبة. وقرأ الباقون بالتاء، حملاً على قوله تعالى: [الجاثية: 4]، أو على معنى: قل لهم يا محمد فبأي حديث بعد الله وآياته يؤمنون.  قوله تعالى: { وَيْلٌ لِّكُلِّ أَفَّاكٍ أَثِيمٍ } قال ابن عباس: نزلت في النضر بن الحارث.  و " الويل " مذكور في البقرة، و " الأفاك الأثيم " في الشعراء، والتي تليها في سورة لقمان.  قوله تعالى: { وَإِذَا عَلِمَ مِنْ ءَايَٰتِنَا } وقرأ ابن مسعود بضم العين وكسر اللام وتشديدها. والمعنى: وإذا أحس بشيء من جملة الآيات التي أنزلها الله على محمد صلى الله عليه وسلم { ٱتَّخَذَهَا هُزُواً }.  وقيل: المعنى: وإذا علم من آياتنا شيئاً يتشبث به المعاند اتخذها هزؤاً وسلّماً يرقى فيه إلى أغراضه الفاسدة، { أُوْلَـٰئِكَ } يشير إلى كل أفّاك أثيم.  قوله تعالى: { مِّن وَرَآئِهِمْ جَهَنَّمُ } مُفسّر في سورة إبراهيم. { وَلاَ يُغْنِي عَنْهُم مَّا كَسَبُواْ } من الأموال وزينة الدنيا { شَيْئاً } أي: لا ينفع ولا يدفع عنهم شيئاً من العذاب، كقوله تعالى: [المجادلة: 17]، { ولا ما اتخذوا من دون الله أولياء } يعني: آلهتهم لا تدفع عنهم أيضاً شيئاً من العذاب.  قوله تعالى: { هَـٰذَا هُدًى } يريد: القرآن { وَٱلَّذِينَ كَفَرُواْ } من هذه الأمة وغيرهم { بِآيَٰتِ رَبِّهِمْ } القرآن وغيره من كتب الله تعالى { لَهُمْ عَذَابٌ مِّن رِّجْزٍ أَلِيمٌ }. وقرئ: " أليمٌ " [بالرفع]. وقد [ذكرناه] في سورة سبأ، و " الرجز " في الأعراف.
