قوله: { يَٰأَيُّهَا ٱلَّذِينَ ءَامَنُواْ } خطاب للمسلمين، في قول الحسن.  ولأهل الكتابين، في قول الضحاك.  وللمنافقين، في قول مجاهد.  فالمعنى على القول الأول: { يَٰأَيُّهَا ٱلَّذِينَ ءَامَنُواْ ءَامِنُواْ بِٱللَّهِ } أي: دوموا على إيمانكم، كما تقول للقائم: قم حتى آتيك.  وعلى القول الثاني: { يَٰأَيُّهَا ٱلَّذِينَ ءَامَنُواْ } بالتوراة وموسى، والإنجيل وعيسى، { ءَامِنُواْ بِٱللَّهِ وَرَسُولِهِ } محمد وما جاء به من القرآن.  وعلى القول الثالث: { يَٰأَيُّهَا ٱلَّذِينَ ءَامَنُواْ } بألسنتهم، { ءَامِنُواْ } بقلوبكم بوحدانية الله ورسالة محمد صلى الله عليه وسلم.  { وَٱلْكِتَٰبِ ٱلَّذِي نَزَّلَ عَلَىٰ رَسُولِهِ وَٱلْكِتَٰبِ ٱلَّذِيۤ أَنزَلَ مِن قَبْلُ }: يريد: جنس الكتب، وإنما قال: " نزل على رسوله " و " أَنْزل من قبل "؛ لأن القرآن نزل نجوماً متفرقة في عشرين سنة، بخلاف سائر الكتب.
