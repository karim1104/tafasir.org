قوله تعالى: { لَوْ كَانَ عَرَضاً قَرِيباً } نزلت في المنافقين. والمعنى: لو كان الذي دُعوا إليه غنيمة قريبة، { وَسَفَراً قَاصِداً } وسطاً سهلاً { لاَّتَّبَعُوكَ } طمعاً في اكتساب المال، وخوفاً من انكشاف الحال، { وَلَـٰكِن بَعُدَتْ عَلَيْهِمُ ٱلشُّقَّةُ } وهي المسافة الشاقة، { وَسَيَحْلِفُونَ بِٱللَّهِ } عند رجوعكم إليهم اعتذاراً من تخلفهم عنكم { لَوِ ٱسْتَطَعْنَا لَخَرَجْنَا مَعَكُمْ } أي: لو قدرنا وكان لنا سعة في المال وما يتوصل به إلى الجهاد لخرجنا معكم، { يُهْلِكُونَ أَنْفُسَهُمْ } بالكذب والأَيْمان الفاجرة والنفاق، { وَٱللَّهُ يَعْلَمُ إِنَّهُمْ لَكَاذِبُونَ } فما يغني عنهم الاعتذار والكذب.
