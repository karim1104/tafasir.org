قوله تعالى: { وَإِنَّهُ لَتَنزِيلُ رَبِّ ٱلْعَالَمِينَ } يعني: القرآن.  { نَزَلَ بِهِ ٱلرُّوحُ ٱلأَمِينُ } وهو جبريل عليه السلام.  وقرأ أبن عامر وأهل الكوفة إلا حفصاً: " نَزَّلَ " بالتشديد، " الروحَ الأمينَ " بالنصب، على معنى: نزّل رب العالمين به الروح الأمين.  { عَلَىٰ قَلْبِكَ } قال الزجاج: ومعنى " على قلبك ": نزل عليك فوعاه قلبك وثَبَتَ فلا ينساه أبداً ولا شيئاً منه، كما قال الله تعالى: [الأعلى: 6].  قوله تعالى: { بِلِسَانٍ عَرَبِيٍّ مُّبِينٍ } الباء متعلقة بـ " نَزَلَ " ، أو بقوله: { لِتَكُونَ مِنَ ٱلْمُنْذِرِينَ } ، على معنى: لتكون من الذين أنذروا بهذا اللسان العربي، وهم خمسة: هود وصالح وشعيب وإسماعيل ومحمد صلوات الله عليهم أجمعين.
