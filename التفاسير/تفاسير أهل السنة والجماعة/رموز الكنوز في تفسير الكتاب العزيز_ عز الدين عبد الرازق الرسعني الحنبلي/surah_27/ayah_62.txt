{ أَمَّن يُجِيبُ ٱلْمُضْطَرَّ إِذَا دَعَاهُ } المُضْطَرُّ: المكروب الذي أحوجه [مرض أو فقر] أو نازلة من نوازل الدهر إلى التضرع إلى الله.  وقيل: المضطر: المُذْنِبُ إذا استغفر.  { وَيَكْشِفُ ٱلسُّوۤءَ } يعني: الضر، { وَيَجْعَلُكُمْ خُلَفَآءَ ٱلأَرْضِ } تتوارثون سكناها قرناً بعد قرن، { أَإِلَـٰهٌ مَّعَ ٱللَّهِ قَلِيلاً مَّا تَذَكَّرُونَ } " ما " زائدة، وقليلاً صفة مصدر مضمر، أي: تذكُّراً قليلاً تذكَّرون، فحذف الموصوف.  والمعنى: نفي التذكُّر، والقلَّة تستعمل في معنى النفي، وقد سبق تقريره فيما مضى.  قرأ أبو عمرو وهشام: " يذكّرون " بالياء، حملاً على قوله تعالى: [النمل: 61]، وقرأ الباقون بالتاء، اعتباراً بقوله: { وَيَجْعَلُكُمْ خُلَفَآءَ ٱلأَرْضِ }.
