قوله تعالى: { وَمَا كَانُواْ سَابِقِينَ } أي: ما كانوا يسبقون الله تعالى ويفوتونه أن يفعل بهم ما يريد.  { فَكُلاًّ أَخَذْنَا بِذَنبِهِ } أي: عاقبناه به. ثم فصَّل ما أجمل فقال: { فَمِنْهُم مَّن أَرْسَلْنَا عَلَيْهِ حَاصِباً } وهم قوم لوط، { وَمِنْهُمْ مَّنْ أَخَذَتْهُ ٱلصَّيْحَةُ } وهم ثمود ومدين، { وَمِنْهُمْ مَّنْ خَسَفْنَا بِهِ ٱلأَرْضَ } وهو قارون، { وَمِنْهُمْ مَّنْ أَغْرَقْنَا } وهم قوم نوح وفرعون.
