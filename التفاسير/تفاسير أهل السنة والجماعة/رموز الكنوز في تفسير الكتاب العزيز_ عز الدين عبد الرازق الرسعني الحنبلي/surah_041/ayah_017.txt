قوله تعالى: { وَأَمَّا ثَمُودُ فَهَدَيْنَاهُمْ } وقرأتُ لعاصم من رواية المفضل عنه: " ثموداً " بالنصب والتنوين.  قال المبرد: والوجه الرفع، تقول: زيد ضربته، والنصب بفعل مضمر يفسره ما بعده.  قال قتادة: المعنى: وأما ثمود فبينا لهم سبيل الخير والشر.  { فَٱسْتَحَبُّواْ ٱلْعَمَىٰ عَلَى ٱلْهُدَىٰ } أي: اختاروا الكفر على الإيمان { فَأَخَذَتْهُمْ } [الصاعقة { صَاعِقَةُ] ٱلْعَذَابِ } أي: قارعة العذاب { ٱلْهُونِ } والهُون والهوان بمعنى واحد. وقد سبق ذكره، ومجازه: فأخذتهم [صاعقة] العذاب ذي الهوان.
