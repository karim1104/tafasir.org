قوله: { بَلْ أَتَيْنَاهُمْ بِٱلْحَقِّ } وهو التوحيد، { وَإِنَّهُمْ لَكَاذِبُونَ } في دعواهم لله ولداً ومعه شريكاً، ثم نفاهما عنه فقال: { مَا ٱتَّخَذَ ٱللَّهُ مِن وَلَدٍ وَمَا كَانَ مَعَهُ مِنْ إِلَـهٍ }. ثم أقام على ذلك برهاناً قاطعاً وقال: { إِذاً لَّذَهَبَ كُلُّ إِلَـٰهٍ بِمَا خَلَقَ } أي: لاستبدَّ وانفرد كل واحد من الآلهة بخلقه الذي خلقه.  { وَلَعَلاَ بَعْضُهُمْ عَلَىٰ بَعْضٍ } بالقهر والغلبة والاستيلاء، كما تشاهدون حال ملوك الدنيا.  قال الزمخشري: فإن قلت: " إذاً " لا تدخل إلا على كلام هو جزاء وجواب، فكيف وقع قوله: " لذهب " جزاء وجواباً ولم يتقدمه شرط ولا [سؤال] سائل؟  قلت: الشرط محذوف، تقديره: ولو كان معه آلهة، وإنما حذف لدلالة قوله: " وما كان معه من إله " عليه.  ثم نزّه نفسه عما وصفوه به من الأنداد والأولاد فقال: { سُبْحَانَ ٱللَّهِ عَمَّا يَصِفُونَ }.  قوله تعالى: { عَالِمِ ٱلْغَيْبِ وَٱلشَّهَادَةِ } قرأ نافع وأهل الكوفة إلا حفصاً: " عَالِمُ " بالرفع، أي: هو عالم. وقرأ الباقون بالجر، جعلوه صفة لله في قوله: { سُبْحَانَ ٱللَّهِ عَمَّا يَصِفُونَ }.
