قوله تعالى: { أَرُونِي } بدل من " أرأيتم "؛ لأن معنى أرأيتم: أخبروني عن هؤلاء الشركاء أروني ما خلقوا من الأرض دوني.  { أَمْ لَهُمْ شِرْكٌ } أي: شركة { فِي } خلق { ٱلسَّمَٰوَٰتِ أَمْ آتَيْنَاهُمْ كِتَاباً } فجاؤكم به من عندي ينطق بأنهم شركائي.  وجمهور المفسرين على أنّ الضمير في «آتيناهم» للمشركين؛ كقوله تعالى: [الروم: 35].  قال مقاتل: المعنى: هل أعطينا أهل مكة { فَهُمْ عَلَىٰ بَيِّنَةٍ مِّنْهُ } [بأن مع الله عز وجل شريكاً من الملائكة].  وقرأ نافع وابن عامر وعاصم والكسائي: " بيناتٍ " على الجمع.  ثم استأنف فقال: { بَلْ إِن يَعِدُ ٱلظَّالِمُونَ بَعْضُهُم } وهم الرؤساء { بَعْضاً } وهم الأتباع { إِلاَّ غُرُوراً } وهو قولهم: [يونس: 18].  قوله تعالى: { إِنَّ ٱللَّهَ يُمْسِكُ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ أَن تَزُولاَ } قال الزمخشري: أي: كراهة أن تَزُولا، أو يكون المعنى: يمنعهما أن تزولا؛ لأن الإمساك منع.  { وَلَئِن زَالَتَآ } وقرئ: " ولو زالتا ". و { إِنْ أَمْسَكَهُمَا } جواب القسم في " ولئن زالتا " سدّ مسد الجوابين، و " من " الأولى مزيدة لتأكيد النفي، والثانية للابتداء.  و { مِّن بَعْدِهِ } من بعد إمساكه.  { إِنَّهُ كَانَ حَلِيماً غَفُوراً } غير معاجل بالعقوبة، حيث يمسكهما، وكانتا جديرتين بأن تهدّا هدّاً، لعظم كلمة الشرك، كما قال الله تعالى: [مريم: 90].
