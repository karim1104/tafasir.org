قوله تعالى: { أَلَمْ تَرَ } أي: ألم تعلم بطريق الوحي إليك أو الإنزال عليك { أَنَّ ٱللَّهَ يُسَبِّحُ لَهُ مَن فِي ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ } سبق تفسيره.  { وَٱلطَّيْرُ صَآفَّاتٍ } عطف على موضع " مَنْ في السماوات والأرض " ، تقديره: ويسبح له الطير صافات باسطات أجنحتها في الهواء.  ووجه اختصاصها بالذِّكْر من بين الأشياء؛ كونها بين الأرض والسماء.  { كُلٌّ قَدْ عَلِمَ صَلاَتَهُ وَتَسْبِيحَهُ } قال أكثر المفسرين: الصلاة لبني آدم، والتسبيح لما سواهم.  والضمير في " عَلِمَ " لله، أي: كلٌ قد عَلِمَ الله صلاته وتسبيحه. وهذا اختيار الزجاج.  وقيل: الضمير لـ " كل " على معنى: كلٌ قد علم صلاة نفسه وتسبيح نفسه، وعرف ما قد كُلِّفَ من ذلك.  وقيل: المعنى: كلٌ قد عَلِمَ صلاة الله وتسبيحه.  { وَٱللَّهُ عَلِيمٌ بِمَا يَفْعَلُونَ }.  قوله تعالى: { وَللَّهِ مُلْكُ ٱلسَّمَاوَاتِ وَٱلأَرْضِ } قال ابن السائب: يعني: خزائن المطر والرزق والنبات لا يملكها غيره.  { وَإِلَىٰ ٱللَّهِ ٱلْمَصِيرُ } بعد الموت.
