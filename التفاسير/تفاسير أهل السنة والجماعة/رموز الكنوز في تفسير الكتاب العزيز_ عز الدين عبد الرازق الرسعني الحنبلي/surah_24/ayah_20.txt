{ وَلَوْلاَ فَضْلُ ٱللَّهِ عَلَيْكُمْ وَرَحْمَتُهُ وَأَنَّ ٱللَّهَ رَءُوفٌ رَّحِيمٌ } عَطْفٌ على الذي قبله، وجواب " لولا " محذوف، تقديره: لعاجلكم بالعقوبة.  قوله تعالى: { لاَ تَتَّبِعُواْ خُطُوَاتِ ٱلشَّيْطَانِ } مُفسرٌ في البقرة.  والمعنى هاهنا: لا تتبعوه فيما زَيّنَ لكم من قذف عائشة.  { وَمَن يَتَّبِعْ خُطُوَاتِ ٱلشَّيْطَانِ فَإِنَّهُ يَأْمُرُ بِٱلْفَحْشَآءِ وَٱلْمُنْكَرِ } مُفسّر في النحل.  { وَلَوْلاَ فَضْلُ ٱللَّهِ عَلَيْكُمْ وَرَحْمَتُهُ } أيها القذفة { مَا زَكَىٰ مِنكُمْ مِّنْ أَحَدٍ } أي: ما تطهّر.  وقرأ الحسن ومجاهد وقتادة: " ما زَكَّى " بتشديد الكاف، على معنى: ما طَهَّرَ منكم من إثم الإفك.  " مِنْ أحدٍ " في موضع الرفع بإسناد الفعل إليه على القراءة الأولى، وفي موضع نصب على القراءة الثانية.  قال ابن عباس: ما قَبِلَ توبة أحد منكم { أَبَداً وَلَـٰكِنَّ ٱللَّهَ يُزَكِّي مَن يَشَآءُ وَٱللَّهُ سَمِيعٌ } لأقوالكم { عَلِيمٌ } بضمائركم وأفعالكم.
