ثم إن الله تعالى ذَكَّرَهُم نِعَمَهُ عليهم ليبعثهم على شكره باجتناب نهيه وامتثال أمره فقال: { وَٱذْكُرُوۤاْ إِذْ أَنتُمْ قَلِيلٌ } " إذ أنتم " مفعول به لا ظرف، تقديره: واذكروا وقت كونكم أقلّة. والمعنى: قليل عددكم، { مُّسْتَضْعَفُونَ فِي ٱلأَرْضِ } يعني: أرض مكة، { تَخَافُونَ } لقلّتكم وضعفكم { أَن يَتَخَطَّفَكُمُ ٱلنَّاسُ } كفار قريش وغيرهم، { فَآوَاكُمْ } إلى المدينة، { وَأَيَّدَكُم بِنَصْرِهِ } في يوم بدر وغيره، حتى خضعت لكم رقاب الفراعنة والجبابرة، وعنت لكم وجوه الأكاسرة والأقاصرة، { وَرَزَقَكُمْ مِّنَ ٱلطَّيِّبَاتِ } أحلّ لكم الغنائم وبسط لكم في الملاذّ.  قال قتادة: كان هذا الحي من العرب أذلّ الناس وأشقاهم عيشاً، وأعراهم جلداً، وأجوعهم بطناً، وأبينهم ضلالاً، يُؤكلون ولا يَأكلون، ومَكَّنَ لهم في البلاد، ووَسَّعَ لهم الرزق والغنائم، وجعلهم ملوكاً.
