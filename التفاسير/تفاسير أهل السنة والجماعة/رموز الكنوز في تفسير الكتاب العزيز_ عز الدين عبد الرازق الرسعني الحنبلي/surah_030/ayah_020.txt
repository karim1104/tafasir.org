قوله تعالى: { وَمِنْ آيَاتِهِ أَنْ خَلَقَكُمْ مِّن تُرَابٍ } أي: ومن دلائل قدرته وعظمته أن خلق أصلكم يا بني آدم من تراب، { ثُمَّ إِذَآ أَنتُمْ بَشَرٌ } من لحم ودم { تَنتَشِرُونَ } في الأرض.  { وَمِنْ آيَاتِهِ أَنْ خَلَقَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجاً } لأن حواء خلقت من ضلع آدم، والنساء خلقن من أصلاب الرجال. هذا قول قتادة.  وقال الكلبي: المعنى: خلق لكم أزواجاً من شكلكم وجنسكم.  { لِّتَسْكُنُوۤاْ إِلَيْهَا } أي: لتأووا إليها، { وَجَعَلَ بَيْنَكُم مَّوَدَّةً وَرَحْمَةً } بواسطة عصمة النكاح من غير سابقة معرفة ولا نسب.
