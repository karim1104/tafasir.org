وما بعده مفسر في القصص.  قوله: { لَّعَـلِّيۤ أَبْلُغُ ٱلأَسْبَابَ * أَسْبَابَ ٱلسَّمَٰوَٰتِ } يعني: أبوابها وطرقها. وهذا قول عامة المفسرين واللغويين. وأنشد الأخفش: { فَأَطَّلِعَ إِلَىٰ } وقرأ حفص: " فأطلعَ " بالنصب، على جواب الترجي تشبيهاً له بالتمني.  { وَكَـذَلِكَ } أي: ومثل ذلك التزين وذلك الصَّد { زُيِّنَ لِفِرْعَوْنَ سُوۤءُ عَمَلِهِ وَصُدَّ عَنِ ٱلسَّبِيلِ } ، والفاعل للتزيين والصد هو الله تعالى بالقدر والقضاء، أو الشيطان بالوسوسة والإغواء. وقد ذكرنا اختلاف القراء في " وصُدَّ " في سورة الرعد.  { وَمَا كَـيْدُ فِرْعَوْنَ إِلاَّ فِي تَبَابٍ } أي: خسران وهلاك.  ثم [عاد] إلى الإخبار عن نصيحة مؤمن آل فرعون، وما وَعَظَ به قومه وذكَّرَهُم به، فقال: { وَقَالَ ٱلَّذِيۤ آمَنَ يٰقَوْمِ ٱتَّبِعُونِ } وقرأ ابن كثير ويعقوب بإثبات الياء في الحالين، وافقهما في الوصل وَرْش وأبو جعفر والولي عن أبي عثمان عن الدوري، وعبد الوارث عن أبي عمرو، والباقون بغير ياء في الحالين.  { أَهْدِكُـمْ سَبِيـلَ ٱلرَّشَـادِ } طريق الهدى.  وفيه تعريض لفرعون وقومه بأنهم على نقيض ذلك، وهي الغي.  قوله تعالى: { مَنْ عَمِـلَ سَـيِّئَةً } يريد: الشرك. وقيل: المعاصي.  { فَلاَ يُجْزَىٰ إِلاَّ مِثْلَهَا } أي: بمقدارها.  قوله تعالى: { يَدْخُلُونَ ٱلْجَنَّةَ } قرئ: " يَدْخُلُون " و " يُدْخَلُون " على البناء للفاعل والمفعول. وقد سبق ذكره.  { يُرْزَقُونَ فِيهَا بِغَيْرِ حِسَابٍ } أي: بغير تقدير، بل ما شاؤوا من الزيادة وما لم تبلغه الأماني.
