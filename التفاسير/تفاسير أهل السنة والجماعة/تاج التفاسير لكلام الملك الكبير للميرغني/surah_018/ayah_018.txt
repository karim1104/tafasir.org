( وتحسبهم ) لو رأيتهم ( أيقاظا ) منتبهين بفتح عيونهم ( وهم رقود ) أي نيام ( ونقلبهم ) في كل عام مرة ( ذات اليمين ) على الجانب الأيمن ( وذات الشمال ) على الجانب الأيسر لئلا تأكل الأرض لحومهم ( وكلبهم ) المسمى بقطمير وهو كلب راع تبعهم فطردوه فقال إني أحب أحباء الله فناموا وأنا أحرسكم وقرئ وكالبهم ( باسط ذراعيه ) يديه ( بالوصيد ) بفناء الكهف قريبا من الباب ( لو اطلعت عليهم ) وقرئ لو بضم الواو ( لوليت منهم فرار ) لهربت منهم لما ألبسهم الله من الجلال والهيبة ( ولملئت منهم رعبا ) خوفا وقرئ ملئت مشددا وقرئ رعبا بضم العين<br />
