ورد الله عليهم فقال ( قل ) لهم أيها النبي الكريم ( الله اعلم بما لبثوا ) منذ قبض أرواحهم إلى يومنا هذا لا يعلمهم إلا هو ومن أعلمه ( له ) سبحانه ( غيب السموات والأرض ) ما غاب فيهما عن العباد ( أبصر به ) جل شأنه ما أبصره ( وأسمع ) به سبحانه ما أسمعه ( ما لهم ) الضمير لأهل السموات والأرض ( من دونه ) غيره ( من ولي ) يتولى أمرهم ( ولا يشرك ) وقرئ ولا تشرك بالتاء والجزم على أنه نهي ( في حكمه ) في قضائه ( أحدا ) وهو الغني الحميد<br />
