{ وإذا قيل } أي : قال فقراء الصحابة { لهم } للكفار { أنفقوا مما رزقكم الله } علينا في سبيل الله { قال الذين كفروا } بالله وبرسله { للذين آمنوا } لفقراء المؤمنين استهزاء { أنطعم من لو يشاء الله أطعمه } أي لو أراد الله إطعامه أطعمه على حسب اعتقادكم { إن أنتم } ما أنتم { إلا في ضلال مبين } حيث تطلبون ما يخالف مشيئة الله وما ذلك إلا لشدة جهلهم وغباوتهم فإن الأسباب لا تنكر وقد جرت عادة الله أن ينفع بأموال الأغنياء الفقراء .  <br />
