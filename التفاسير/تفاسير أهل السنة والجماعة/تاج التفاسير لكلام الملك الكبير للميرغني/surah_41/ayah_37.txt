{ ومن آياته } الدالة على وحدانيته وانفراده بالألوهية { الليل والنهار } وضوء أحدهما وظلام الآخر وتقلبها وأين يذهب أحدهما إذا جاء الآخر وفي الحديث قال رسول الله صلى الله عليه وسلم سبحان الله أين الليل إذا جاء النهار { والشمس والقمر } وما بينهما من الضوء وسيرهما في منازلهما { لا تسجدوا للشمس ولا للقمر } فإنهما من خلق الله { واسجدوا لله الذي خلقهن } الضمير لليل والنهار والشمس والقمر { إن كنتم إياه } له تعبدون } وتستدلون بخلقهن على أنه المستحق للعبادة<br />
