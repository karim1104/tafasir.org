( قال يا قوم أرأيتم ) أعلمتم ( إن كنت على بينة من ربي ) يشير إلى ما أعطى من العلم والنبوة ( ورزقني منه رزقا حسنا ) حلالا فما ينبغي لي مع هذه النعم ترك ما أمرني بالعمل به وتبليغه والدخول في بخسكم وتطفيفكم ( وما أريد أن أخالفكم ) وأذهب ( إلى ما أنهاكم عنه ) فأفعله ( إن أريد ) ما أريد ( إلا الإصلاح ) لكم بسلوك السبيل المستقيم ( ما استطعت ) حسب جهدي ( وما توفيقي ) لإصابة الحق والأمر به ( إلا بالله عليه توكلت ) في جميع أموري ( وإليه أنيب ) أرجع<br />
