{ يا أيها الذين آمنوا } بالله ورسوله { إذ جاءكم } من الكفار  ، { المؤمنات } بقولهن  ، { مهاجرات } لله ورسوله والأمر بعد صلح الحديبية  ، { فامتحنوهن } اختبروهن بتحليفهن إنهن ما خرجن لبغض أزواجهن ولا عشقا في رجال المسلمين ولكنه محبة في الإيمان  ، { الله أعلم ب } حقيقة { إيمانهن } وكان النبي صلى الله عليه وسلم يحلفن كما أمر  ، { فإن علمتموهن } بعد الحلف { مؤمنات } بظنكم { فلا ترجعوهن } تعيدوهن { إلى } أزواجهن { الكفار } بالله ورسوله{ لا هن } المؤمنات { حل لهم } أي الكفار { ولا هم } أي الكفار { يحلون لهن } فقد فارق بينهم وبينهن الإسلام  ، { وآتوهم } أعطوهن أزواجهن الكفار { ما أنفقوا } ما دفعوا إليهن من المهر  ، { ولا جناح } أي لا إثم { عليكم } بعد إعطاء أزواجهن المهر { أن تنكحوهن } لحيلولة الإسلام بينهما { إذ آتيتموهن أجورهن ولا تمسكوا } وقرئ بالتشديد { بعصم } زوجاتكم { الكوافر } فإن الإسلام قد نفى العصمة بينكم وبينهن  ، { واسألوا } واطلبوا { ما أنفقتم } من مهر نسائكم المرتدات إلى الكفر مما يتزوجهن من الكفار  ، { وليسألوا } وليطلبوا الأزواج الكفار { ما أنفقوا } من مهور نسائهم المهاجرات ممن يتزوجن منكم { ذلكم حكم الله } الحكم العدل { يحكم بينكم } وبينهم  ، { والله عليم } بما تعملون { حكيم } بإعطاء كل أحد حقه  .  <br />
