{ بسم الله الرحمن الرحيم قد سمع الله } سبحانه { قول التي تجادلك } أيها النبي وهي خولة بنت ثعلبة { في زوجها } وهو أوس بن الصامت وذلك حين  ظاهر منها واستفتت النبي صلى الله عليه وسلم { وتشتكي إلى الله } حين قال لها صلى الله عليه وسلم حرمت عليه فقال أشتكي إلى الله فاقتي ووحدتي وصبية صغار { والله يسمع تحاوركما } مراجعتكما حين يخبرها بتحريمها على زوجها واغتمامها بذلك واشتكائها إلى الله من ذلك { إن الله سميع } للأقوال { بصير } بالأحوال  .  <br />
