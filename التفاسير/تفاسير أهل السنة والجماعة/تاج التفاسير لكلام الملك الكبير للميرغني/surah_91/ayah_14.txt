{ فكذبوه } في تحذيره لهم الموجب لهم حلول العذاب إن عصوه { فعقروها } ولم يبالوا بكلامه للانتفاع بماء شربها { فدمدم } أي فأطبق { عليهم } أي على ثمود { ربهم } العذاب الموعد في قوله ولا تمسوها { بذنبهم } الذي أذنبوه وارتكابهم ما نهوا عنه { فسواها } أي فعمهم بها فلم يفلت منهم صغير ولا كبير والضمير راجع إلى الدمدمة<br />
