{ ثم ما أدراك ما يوم الدين } ثم عرفه سبحانه على طريق الإجمال بتعريف بين أنه يحتوي على جميع الشدائد والأهوال فقال { يوم } أي هو يوم قراءة الرفع { لا تملك نفس } عظيمة أو حقيرة إلا الشفاعة بإذن { لنفس } أخرى { شيئا } تنفعها به { والأمر } والحكم{ يومئذ } أي يوم القيامة { لله } لا لأحد غيره وإن كان كذلك في الدنيا لكن يظهر الأمر على حقيقته لمن كان يلتفت .  <br />
