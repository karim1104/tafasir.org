( يستفتونك ) أيها الحبيب الكريم في الكلالة ( قل الله يفتيكم في الكلالة ) فإني لا أحكم إلا بما أومر به ( إن امرؤ هلك ) مات ( ليس له ولد ) وكذا ليس له والد وهذا تفسير الكلالة ( وله أخت ) من أبوين أو أب ( فلها نصف ما ترك ) من التركة ( وهو ) أخوها ( يرثها ) أي يأخذ ميراثها كله ( إن لم يكن لها ولد ) فإن كان لها ولد ذكر فلا يأخذ شيئا فإن كانت أنثى فله من التركة م فضل عن نصيبها وأما إن كانت الأخت أو الأخ من الأم فحكمه ما تقدم في أول السورة ( فإن كانتا اثنتين ) أي إن كان له أختان أو أكثر ( فلهما الثلثان مما ترك ) أخوهما ( وإن كانوا ) ورثته ( إخوة رجالا ونساء ) أشقاء أو لأب ( فللذكر ) منهم ( مثل حظ ) نصيب ( الأنثيين ) فيعطى للذكر سهمان وللأنثى سهم واحد ( يبين الله لكم ) الأحكام رحمة بكم ( أن تضلوا ) في الحكم ( والله بكل شيء عليم ) فأحسنوا معاملته<br />
