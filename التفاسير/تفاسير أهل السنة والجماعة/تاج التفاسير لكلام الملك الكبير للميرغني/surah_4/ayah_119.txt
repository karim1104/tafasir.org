( ولأضلنهم ) عن سبيل الهدى ( ولأمنينهم ) الأماني الفاسدة كطول حياتهم في الدنيا وتكذيب البعث والنشور والعقاب ( ولآمرنهم ) طلبا لإضلالهم بنوع آخر ( فليبتكن ) يقطعن ( آذن الأنعام ) كما أغراهم بفعلهم بالبحائر ( ولآمرنهم ) بنوع آخر من الإضلال ( فليغيرن خلق الله ) كما وقع من التغايير من نحو ما قال النبي صلى الله عليه وسلم لعن الله الواشمات والمستوشمات والمتنمصات والمتفلجات للحسن المغيرات خلق الله رواه الشيخان وغيرهما ( ومن يتخذ الشيطان ) يجعله ( وليا ) له فيطعيه ( من دون الله ) أي غير الله ( فقد خسر ) في الدارين ( خسرانا مبينا ) ظاهرا<br />
