( ويقولون ) المنافقون إذا أمرتهم بأمر ( طاعة ) لأمرك ( فإذا برزوا ) خرجوا ( من عندك ) وانصرفوا من مجلسك ( بيت ) زورت ( طائفة منهم ) وقرئ بيت طائفة بإدغام التاء في الطاء ( غير الذي تقول ) لك أو غير الذي تقول لها ( والله يكتب ) في صحائف أعمالهم بأيدي حفظته ( ما يبيتون ) مما في ضمائرهم من السوء ( فأعرض عنهم ) لا تبال بهم ( وتوكل على الله ) وثق به في جميع أمورك ( وكفى بالله وكيلا ) يكفيك شرهم<br />
