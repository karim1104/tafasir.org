( يوصيكم الله ) يعهد إليكم ( في أولادكم ) في أمر ميراثهم أن تعطوا ( للذكر ) أي الولد الذكر منهم ( مثل حظ ) نصيب ( الأنثيين ) البنتين إذا اجتمعتا معه فيكون له النصف ولهما النصف ( فإن كن ) أولاد المتوفي ( نساء ) بنات دون ذكر وكان عددهم ( فوق اثنين فلهن ) للبنات مع عدم وجود الذكر ( ثلثا ما ترك ) المتوفي والإثنان كذلك لأن الأختين يعطيان الثلثين وهن أولى لأشدية القرابة ( وإن كانت ) البنت المتروكة ( واحدة ) وقرئ بالرفع ( فلها النصف ) نصف المال ( ولأبويه ) أبوي الميت ( لكل واحد منهما ) الضمير للأم والأب ( السدس مما ترك ) أي من التركة ( إن كان له ) أي للميت ( ولد ) سواء كان ذكرا أو أنثى لكن الأب يأخذ السدس مع الأنثى بالفريضة وما بقي من ذي الفروض يأخذه بالعصوبة ( فإن لم يكن له ) للمتوفى ( ولد وورثه أبواه ) دون زوج أو معه ( فلأمه ) وقرئ بكسر الهمزة ( الثلث ) ثلث المخلف والباقي للأب ( فإن كان له ) أي للميت ( إخوة ) إثنان فأكثر ذكورا أو إناثا ( فلأمه السدس ) وما بقي للأب وليس للإخوة شيء ( من بعد ) إمضاء ( وصية يوصى ) وقرئ بالبناء للفاعل ( بها ) لغير وارث ( أو دين ) لكن قضاء الدين مقدم على الوصية كما قال صلى الله عليه وسلم الدين قبل الوصية وليس لوارث وصية رواه البيهقي في سننه ( آباؤكم وأبناؤكم ) أيها العباد ( لا تدرون ) لا تعلمون ( أيهم أقرب لكم نفعا ) في دنياكم وآخرتكم وهذا الذي ذكره الله لكم من القسم ( فريضة من الله ) افترضها عليكم لا يسوغ لكم غيرها ( إن الله كان عليما ) بما يصلحكم ( حكيما ) في ترتيب ذلك<br />
