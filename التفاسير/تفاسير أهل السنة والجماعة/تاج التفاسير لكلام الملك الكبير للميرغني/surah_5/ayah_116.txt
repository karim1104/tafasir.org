( وإذ قال الله ) أي يقول يوم القيامة ( يا عيسى ابن مريم أأنت قلت للناس ) هذا توبيخ لقومه ( اتخذوني وأمي إليهن من دون الله ) أي غيره ( قال ) عيسى وقد ارتعد من الخوف ( سبحانك ) ننزهك عما لا يليق بك ( ما يكون لي ) ما ينبغي لي ( أن أقول ما ليس لي بحق ) أي ما لا يحق لي ( إن كنت قلته ) أنا ( فقد علمته ) أنت لا يخفى عليك شيء ( تعلم ما في نفسي ) أخفيه وأنا ما أخفيت نحو ذلك كما تعلم ( ولا اعلم ما في نفسك ) تخفيه ( إنك أنت علام الغيوب ) فلا يخفى عليك شيء<br />
