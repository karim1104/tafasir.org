( لقد كفر الذين قالوا ) جراءة على الله ( إن الله هو المسيح ابن مريم ) ونسبوه للألوهية ( وقال المسيح ) لهم لما قالوا ذلك ( يا بني إسرائيل اعبدوا الله ربي وربكم ) فإني عبد مخلوق مثلكم ( إنه من يشرك بالله ) يجعل له شريكا بعبادته ( فقد حرم الله عليه الجنة ) ومنعه دخولها ( ومأواه النار ) ومسكنه ومآله ( وما للظالمين ) الكافرين ( من أنصار ) يمنعونهم من العذاب<br />
