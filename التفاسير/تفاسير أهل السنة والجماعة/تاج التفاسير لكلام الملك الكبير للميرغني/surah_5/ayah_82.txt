( لتجدن ) أيها الحبيب العظيم ( أشد الناس عداوة للذين آمنوا اليهود ) قال صلى الله عليه وسلم :  " ما خلا يهودي قط بمسلم إلا حدثنه نفسه بقتله "  رواه الخطيب ( والذين أشركوا ) أي المشركين ( ولتجدن أقربهم مودة ) محبة ( للذين آمنوا الذين قالوا إنا نصارى ) أي النصارى ( ذلك ) أي قرب المودة منهم للمؤمنين ( بأن منهم ) أي بسبب أن منهم ( قسيسين ) علماء ( ورهبانا ) عبادا وزهادا ( وأنهم لا يستكبرون ) عن اتباع الحق<br />
