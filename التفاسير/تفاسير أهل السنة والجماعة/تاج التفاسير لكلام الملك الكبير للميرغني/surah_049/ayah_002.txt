{ يا أيها الذين آمنوا } المنيبون لله { لا ترفعوا أصواتكم } لا تجاوزوها فوق صوت النبي } إذا كلمكم ونزلت في ثابت بن قيس كان في أذنيه وقر وإذا تكلم مع النبي صلى الله عليه وسلم جهر بصوته فلما نزلت تخلف عن رسول الله صلى الله عليه وسلم فتفقده ودعاه فقال يا رسول الله لقد نزلت إليك هذه الآية وإني رجل جهير الصوت أخاف أن يكون عملي قد حبط فقال صلى الله عليه وسلم إنك لست هناك إنك تعيش بخير وتموت بخير وإنك من أهل الجنة { ولا تجهروا له بالقول } إذا خاطبتموه { كجهر بعضكم لبعض } بل اخفضوا صوتكم واجعلوه دون ذلك { أن تحبط } خشية أن تحبط { أعمالكم } التي ترجون بركتها { وأنتم لا تشعرون } بحبوطها<br />
