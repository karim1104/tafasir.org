( يا بني آدم ) نداء تحذير وتخويف ( لا يفتننكم ) فيضلكم ( الشيطان ) يخرجكم من الخير ( كما اخرج أبويكم ) حواء وآدم ( من الجنة ) حين فتنهم ( ينزع عنهما لباسهما ) أي تسبب في ذلك ( ليريهما سوءاتهما إنه يراكم هو وقبيله ) جنوده ( من حيث لا ترونهم ) فإن أجسامهم لطيفة وليس لهم لون يعرف ( إنا جعلنا الشياطين ) إبليس وأعوانه ( أولياء للذين لا يؤمنون ) لما بينهم من التناسب في الإدبار عن الله<br />
