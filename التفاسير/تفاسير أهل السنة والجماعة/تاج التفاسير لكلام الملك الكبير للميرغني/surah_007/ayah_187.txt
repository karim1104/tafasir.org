( يسألونك ) أيها النبي العظيم ( عن الساعة ) عن قيامها ( أيان مرساها ) متى إتيانها ( قل ) لهم ( إنما علمها ) علم قيامها ( عند ربي ) متى تقوم ( لا يجليها ) لا يظهرها ( لوقتها إلا هو ) الذي لا يخفي عليه شيء ( ثقلت ) عظمت ( في السموات والأرض ) أي على أهلها من جن و إنس وملائكة ( لا تأتيكم إلا بغتة ) فجأة .   قال صلى الله عليه وسلم إن الساعة تهيج بالناس والرجل يصلح حوضه والرجل يسقي ماشيته والرجل يقوم سلعته في سوقه والرجل يخفض ميزانه ويرفعه ( يسألونك كأنك حفي عنها ) بالغت في السؤال عنها حتى علمت وقتها ( قل إنما علمها عند الله ) العالم بكل خفي ( ولكن أكثر الناس لا يعلمون ) أن علمها عنده<br />
