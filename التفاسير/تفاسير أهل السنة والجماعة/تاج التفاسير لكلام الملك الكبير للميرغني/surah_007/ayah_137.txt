( وأورثنا ) ملكنا ( القوم الذين كانوا يستضعفون ) بقتل الأبناء واستخدام النساء وهم بنو إسرائيل ( مشارق الأرض ومغاربها ) فضلا منا ( التي بركنا فيها ) بالخصب وسعة المعيشة ( وتمت كلمة ربك الحسنى ) وهي قوله تعالى { ونريد أن نمن على الذين استضعفوا في الأرض } إلى آخره وقرئ كلمات ( على بني إسرائيل بما صبروا ) أي بسبب صبرهم على الأذى ( ودمرنا ) أهلكنا ( ما كان يصنع فرعون وقومه ) من عماراتهم ( وما كانوا يعرشون ) من بنيانهم وبساتينهم وقرئ يعرشون بالرفع<br />
