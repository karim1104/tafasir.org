( واختار موسى قومه ) أي من قومه ( سبعين رجلا ) بأمر الله ممن لم يعبد العجل ( لميقاتنا ) وسماع كلامه فقالوا أرنا الله جهرة ( فلما أخذتهم الرجفة ) بقولهم ذلك ( قال ) موسى ( رب لو شئت أهلكتهم من قبل وإياي ) قبل الخروج وكان بنو إسرائيل يرون ذلك ولا يتهموني ( أتهلكنا بما فعل السفهاء منا ) أي الجهال منا ( إن هي إلا فتنتك ) ابتلاؤك ( تضل بها من تشاء ) إضلاله ( وتهدي من تشاء ) هدايته ( أنت ولينا ) والى أمرنا ( فاغفر لنا ) ما ارتكبناه ( وارحمنا ) بفضلك ( وأنت خير الغافرين ) فبدل سيئاتنا حسنات يا ولي الهبات<br />
