( ولما رجع موسى ) من المكالمة ( إلى قومه غضبان ) مما ارتكبوه ( أسفا ) حزينا من خسارهم ( قال بئسما ) أي بئس خلافة ( خلفتموني من بعدي ) من بعد ذهابي ( أعجلتم أمر بكم ) سبقتم باتخاذكم العجل ميعاد ربكم ( وألقى الألواح ) التي فيها التوراة غضبا فتكسرت ( وأخذ برأس أخيه ) بشعر رأسه وبلحيته بيمينه ( يجره إليه ) توهما أنه قصر في نهيهم ( قال ابن أم ) ذكر الأم للحنة وعطف القلب وإلا فهو ابن والديه وقرئ أم ( إن القوم استضعفوني ) استذلوني ( وكادوا يقتلونني ) قاربوا قتلي ( فلا تشمت بي الأعداء ) تفرحهم بذلتك لي ( ولا تجعلني مع القوم الظالمين ) ولا تعذبني معهم بنسبة التقصير إلى فلما علم براءته من التقصير<br />
