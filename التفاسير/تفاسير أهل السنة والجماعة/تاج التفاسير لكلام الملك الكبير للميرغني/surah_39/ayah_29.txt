{ ضرب الله } للعبد المشرك والموحد { مثلا } يعلم به شأنهما وذلك { رجلا فيه شركاء متشاكسون } متنازعون كل واحد يستخدمه بقدر نصيبه وهذا المثل للمشرك { ورجلا سالما } خالصا { لرجل } وهذا مثال الموحد وقرئ سلما بفتحتين وقرئ بفتح السين وكسرها مع سكون اللام { هل يستويان } العبد للجماعة والعبد لواحد فالأول إذا طلب منه كل من مواليه خدمته في وقت واحد تحير فيمن يخدمه والثاني مستريح لأن مستخدمه واحد { مثلا } أي ضرب الله هذا مثلا وقرئ مثلين { الحمد لله } المستحق للحمد لكونه المنعم المالك { بل أكثرهم } أي الناس { لا يعلمون } فلذا يشركون<br />
