( نسائكم ) أزواجكم ( حرث لكم ) أي موضع زرعكم لأولادكم في محل الوطء وهو القبل ( فأتوا حرثكم ) زوجاتكم ( أنى شئتم ) أي كيف شئتم سواء كان قياما أو قعودا أو اضجاعا ( وقدموا ) التسمية{[17]} قبل النكاح ( لأنفسكم ) وكيفية التقديم ما روى في صحيح البخاري أن رسول الله صلى الله عليه وسلم قال أما إن أحدكم إذا أتى أهله وقال بسم الله اللهم جنبنا الشيطان وجنب الشيطان ما رزقتنا فرزق ولدا لم يضره الشيطان ( واتقوا الله ) فيما يأمركم وينهاكم ( واعلموا أنكم ملاقوه ) بالبعث فيجازيكم ما عملتموه ( وبشر ) أيها النبي الكريم ( المؤمنين ) بالجنة والنظر إلى وجه مولاهم العظيم
