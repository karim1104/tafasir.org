( والوالدات يرضعن ) خبر مراد به الأمر ( أولادهن ) سواء كن مطلقات أو غير مطلقات ( حولين كاملين ) تامين ( لمن أراد ) منهم ( أن يتم الرضاعة ) وهذا التحديد يقطع التنازع بين الزوجين إن تشاجروا في زمن الرضاع ( وعلى المولود له ) الأب ( رزقهن ) مؤنة الوالدات من الطعام ( وكسوتهن ) كذلك( بالمعروف ) بحسب ما يقتضيه نظر الحاكم الشرعي ويكون في وسعه ( لا تكلف نفس إلا وسعها ) لا يزاد على طاقتها ( لا تضار ) وقرئ بالرفع ( والدة بولدها ) فلا ينزع منها إلى غيرها إذا رضيت بإرضاعها له ( ولا ) يضار ( مولود له ) أي الأب ( بولده ) بأن يكلف فوق طاقته ( وعلى الوارث ) من نفقة المرضعات وكسوتهن ( مثل ذلك ) الذي على الوالد ( فإن أرادا ) الضمير للأب والأم ( فصالا ) فطاما للولد ( عن تراض منهما ) قبل الحولين ( وتشاور ) بينهما في ذلك ( فلا جناح عليهما ) فلا إثم ( وإن أردتم ) أيها الآباء ( أن تسترضعوا ) أي ترضعوا ( أولادكم ) نساء مرضعات غير الأمهات ( فلا جناح عليكم ) في ذلك ( إذا سلمتم ) إلى المرضعات ( ما آتيتم ) ما أردتم إعطاءه من الأجرة لهن ( بالمعروف ) بالوجه المستحسن شرعا ( واتقوا الله ) وارأفوا بأمر الأطفال والمرضعات ( واعلموا أن الله ) المحتاج إليه في كل الأطوار ( بما تعلمون بصير ) فلا يخفى عليه من ذلك شيء<br />
