{ وإذا قيل لهم } لليهود { آمنوا بما أنزل الله } على محمد وهو القرآن وما انزل على الرسل من الكتب القديمة { قالوا نؤمن بما أنزل علينا } أي التوراة { ويكفرون بما وراءه } أي بما سواه { وهو الحق } أي القرآن { مصدقا } أي موافقا { لما معهم } أي التوراة التي معهم { قل } لهم أيها النبي الكريم { فلم تقتلون } أي قتل آباؤكم { أنبياء الله } وقرئ بالهمزة التي معهم { قل } لهم أيها النبي الكريم { فلم تقتلون } أي قتل آباؤكم { أنبياء الله } وقرئ بالهمزة وأنتم راضون بفعل آبائكم ( من قبل إن كنتم مؤمنين ) بالتوراة فلم خالفتم ما فيها وهو النهي عن قتلهم .  <br />
