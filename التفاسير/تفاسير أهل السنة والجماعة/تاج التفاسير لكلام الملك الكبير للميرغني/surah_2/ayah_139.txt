{ قل أتحاجوننا } تجادلوننا{[7]} { في الله } أن اختار نبيا من العرب ونزلت حين قال اليهود للنبي صلى الله عليه وسلم الأنبياء كلهم منا فلو كنت نبيا لكنت منا { وهو ربنا وربكم } فله أن يختص برسالته من يشاء منا ومنكم { ولنا أعمالنا } فنجازى عليها { ولكم أعمالكم } تجازون عليها { ونحن له مخلصون }{[8]} ولطاعته منقادون .
