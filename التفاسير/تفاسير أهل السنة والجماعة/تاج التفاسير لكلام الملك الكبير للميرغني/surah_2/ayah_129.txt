{ ربنا وابعث } للدعوة إليك { فيهم } أي في سكان الحرم { رسولا منهم } فبعث الله نبينا محمدا صلى الله عليه وسلم واستجاب الدعوة وفي الخبر .   قال رسول الله صلى الله عليه وسلم :  "  أنا دعوة إبراهيم وكان آخر من بشر بي عيسى بن مريم  "  .  { يتلو عليهم آياتك } قرآنك العزيز فيجلو بصائرهم وينور أفئدتهم { ويعلمهم الكتاب } الذي هو القرآن المتلو عليهم فيعلمون أسراره ويدرون حكمه وأخباره { والحكمة } التي يعبرون بها عن حقائق الكمالات وينطقون فيها بأنواع الأسرار المخبآت { ويزكيهم } من درن المعاصي والسيئات { إنك أنت العزيز } الذي لا يغلبه شيء{ ( الحكيم } المربي بحكمته كل حي .  <br />
