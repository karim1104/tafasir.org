( وإذا قيل لهم ) للمنافقين ( آمنوا ) ظاهرا وباطنا ( كما آمن الناس ) الصحابة ( قالوا ) جوابا لذلك ( أنؤمن ) أنفعل ( كما آمن ) كما فعل ( السفهاء ) وتسفيهم لهم لاعتقادهم فساد رأيهم وتحقير شأنهم فإن كثيرا من المؤمنين كانوا فقراء ( ألا إنهم ) هذا رد من الله عليهم ( هم السفهاء ) الجهلاء بما ينفعهم ( ولكن لا يعلمون ) لا يشعرون بسفاهتهم التي أوجبت لهم فساد دنياهم وآخرتهم<br />
