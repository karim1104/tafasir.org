( إنا أنزلنا التوراة ) الكتاب الألهي ( فيها هدى ) من الضلالة ( ونور ) يظهر به الحق ( يحكم بها النبيون ) أنبياء بني إسرائيل ( الذين أسلموا ) انقادوا للحق ( للذين هادوا ) وتابوا من الكفر ( والربانيون ) العلماء العارفون ( والأحبار ) الفقهاء ( بما استحفظوا ) بما استودعوا ( من كتاب الله ) ولم يحرفوه ( وكانوا عليه شهداء ) بأنه صدق ( فلا تخشوا الناس ) أي الحكام ( واخشون ) خافوني واحكموا بأمري ( ولا تشتروا ) ولا تستبدلوا ( بآياتي ) بأحكامي ( ثمنا قليلا ) من زخارف دنياكم ( ومن لم يحكم ) منكم ( بما أنزل الله ) ويحكم من تلقاء نفسه معرضا عن الحق الصراح ( فأولئك هم الكافرون ) بالله ورسوله<br />
