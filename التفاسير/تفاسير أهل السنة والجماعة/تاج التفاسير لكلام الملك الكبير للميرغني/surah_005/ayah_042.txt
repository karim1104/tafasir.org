وصفهم الله فقال ( سماعون للكذب ) المفترى عليك ( أكالون للسحت ) أي الرشوة وهي ممنوعة في كل الملل وفيها يقول النبي صلى الله عليه وسلم لعن الله الراشي والمرتشي رواه الترمذي وزاد أحمد والرائش الذي يمشي بينهما ( فإن جاءوك ) يستحكمونك ( فاحكم بينهم ) بحكم الله ( أو أعرض عنهم ) وهو منسوخ بقوله تعالى { وأن احكم بينهم } الآية الآتية فإذا ترفعوا إلينا يجب علينا ان نحكم بينهم ( وإن تعرض عنهم ) أي عن الحكم بينهم ( فلن يضروك شيئا ) فإن الله كافيك شرهم ( وإن حكمت ) أيها النبي ( فاحكم بينهم بالقسط ) بالعدل الذي أمرناك به ( إن الله يحب المقسطين ) الواقفين مع حكمه<br />
