( لقد كان في قصصهم ) قصص إخوة يوسف ( عبرة لأولي الألباب ) أصحاب العقول السليمة ( ما كان ) القرآن ( حديثا يفتري ) يتقوله بشر ( ولكن ) كان ( تصديق الذي بين يديه ) مصدقا لما قبله من الكتب ( وتفصيل ) تبيين ( كل شيء ) يحتاج إليه من الأحكام ( وهدى ) من الغواية ( ورحمة لقوم يؤمنون ) فإنهم المنتفعون به .  <br />
