( وجاءت سيارة ) جماعة مسافرة من مدين إلى مصر ونزلوا بالقرب من الجب ( فأرسلوا واردهم ) الذي يرد لسقيهم ( فأدلى ) في البئر ( دلوه ) فتعلق به يوسف وخرج فلما رآه الوارد ( قال يا بشرى ) يا فرحتا ( هذا غلام ) وجدته في البئر وعلم إخوته فجاؤا ( وأسروه ) اخفوا ما وقع منهم له من السوء وقالوا ( بضاعة ) فهو عبد أبق منا وسكت يوسف خشية قتلهم له ( والله عليم بما يعملون ) لم يخف عليه أمرهم<br />
