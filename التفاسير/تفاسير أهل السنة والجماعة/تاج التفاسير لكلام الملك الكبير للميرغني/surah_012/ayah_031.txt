( فلما سمعت بمكرهن ) بذمهن لها ومقالتهن فيها ( أرسلت إليهن ) تدعوهن وزادت عليهن جماعة من النسوة ( وأعتدت ) أعدت ( لهن متكأ ) من الوسائد يتكئن ليه وقرئ متكا وقيل المتكأ هو الاترج ( وآتت كل واحدة منهن سكينا ) حتى يتكئن والسكاكين بأيديهن فإذا خرج عليهن يبهتن من جماله فيقطعن أيديهن ( وقالت ) له ( اخرج عليهن ) فخرج ( فلما رأينه أكبرنه ) أعظمنه وهبن حسنه الفائق ،  وفي الحديث مرفوعا أعطي يوسف شطر الحسن رواه أحمد وغيره ( وقطعن أيديهن ) بالسكاكين من الدهش ولم يشعرن بالألم ( وقلن حاش لله ) تنزيها له تعجبا من قدرته على خلق مثله وقرئ لله بغير لام ( ما هذا بشرا ) ليس هذا الجمال يشبه أن يكون في البشر وقرئ بشر بالرفع ( إن هذا ) ما هذا ( إلا ملك كريم ) فإن مثل هذا الجمال والعصمة عما لا يليق لا يكاد يكون إلا في ملك<br />
