( وراودته التي هو في بيتها ) امرأة العزيز زليخا ( عن نفسه ) طلبت منه أن يواقعها ( وغلقت الأبواب ) أغلقتها ( وقالت هيت لك ) هلم تهيأت لك وقرئ بفتح الهاء وضم التاء وقرئ بكسر الهاء ( قال معاذ الله ) أعوذ بالله من هذا الفعل ( إنه ربي ) سيدي الذي اشتراني ( أحسن مثواي ) أحسن إلي في مقامي معه ولا أخونه ( إنه لا يفلح الظالمون ) الذين يقابلون الحسنة بالسيئة<br />
