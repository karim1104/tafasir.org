( وقضى ربك ) أمر ( أن لا ) أي بأن لا ( تعبدوا إلا إياه ) تفردوه بالعبادة وأمر أيضا أن تحسنوا إلى الوالدين فقال ( وبالوالدين إحسانا ) وتبروهم حسب جهدكم ( إما يبلغن عندك الكبر أحدهما ) أحد الأبوين وقرئ يبلغان ( أو كلاهما ) معا ( فلا تقل لهما أف ) وقرئ بفتح الفاء غير منون أي تبا وقبحا ( ولا تنهرهما ) تزجرهما ( وقل لهما قولا كريما ) جميلا مطيبا لأنفسهما فمن أدرك أبواه أو أحدهما عنده الكبر ولم يدرك بهما غاية الخير ودخول الجنة فقد فرط حد التفريط وفي الحديث مرفوعا رغم أنف رجل ذكرت عنده فلم يصل على ورغم أنف رجل دخل عليه رمضان ثم انسلخ قبل أن يغفر له ورغم أنف رجل أدرك عنده أبواه الكبر فلم يدخلاه الجنة رواه الشيخان وعند مسلم في رواية أخرى احدهما أو كلاهما<br />
