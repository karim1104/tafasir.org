{ يوم يبعثهم الله جميعا } لا يبقى منهم أحد  ، { فيحلفون له } لله أنهم مؤمنون { كما } كانوا في الدنيا { يحلفون لكم } أنهم منكم { ويحسبون } بخيالاتهم الفاسدة { أنهم على شيء } ينفعهم من الحلف في الآخرة كالدنيا  ، { ألا إنهم هم الكاذبون } حيث بالغوا بظنهم أن كذبهم ينفعهم عند عالم السرائر والظواهر .  <br />
