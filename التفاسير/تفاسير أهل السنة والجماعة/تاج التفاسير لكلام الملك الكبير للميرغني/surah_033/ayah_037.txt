{ وإذ تقول للذي أنعم الله عليه } بالإسلام { وأنعمت عليه } بالإعتاق { أمسك عليك زوجك } زينب { واتق الله } في أمر طلاقها { وتخفى في نفسك ما الله مبدية } وهو نكاحها وإن طلقها { وتخشى الناس } وقولهم تزوج زوج ابنه { والله أحق أن تخشاه } إن كان فيما يخشى وليس فيه شيء { فلما قضى زيد منها وطرا } حاجة وملها وطلقها وانقضت عدتها { زوجناكها } فدخل عليها النبي صلى الله عليه وسلم بغير إذن وكانت تفتخر وتقول لنساء النبي إن الله تولى إنكاحي وأنتن زوجكن أولياؤكن وقرئ زوجتكها { لكيلا يكون على المؤمنين حرج } تضييق { في أزواج أدعيائهم } الذين ليسوا بأبنائهم حقيقة { إذا قضوا منهن وطرا } ثم طلقوهن { وكان أمر الله } الذي يريده { مفعولا } مكونا لا محالة<br />
