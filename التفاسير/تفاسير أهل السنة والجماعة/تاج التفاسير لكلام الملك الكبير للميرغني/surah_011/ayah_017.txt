( أفمن كان على بينة ) برهان ( من ربه ) وهو النبي عليه السلام ( ويتلوه ) يتبعه ( شاهد منه ) يصدقه والضمير لله ( ومن قبله ) من قبل القرآن ( كتاب موسى ) التوراة شاهد له أيضا ( إماما ) كتابا مؤتما به ( ورحمة ) للمنزل عليهم ( أولئك ) الذين كانوا على بينة من ربهم ( يؤمون به ) بالقرآن ( ومن يكفر به من الأحزاب ) المتحزبين على الرسول عليه الصلاة والسلام ( فالنار موعده ) مرده إليها ( فلاتك في مرية ) شك وقرئ مرية بالضم ( منه ) من القرآن ( إنه الحق من ربك ) لا شك فيه ( ولكن أكثر الناس لا يؤمنون ) لقلة نظرهم وتدبرهم<br />
