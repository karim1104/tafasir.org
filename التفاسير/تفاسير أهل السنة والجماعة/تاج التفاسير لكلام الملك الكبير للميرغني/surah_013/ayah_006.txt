( ويستعجلونك ) مستهزئين ( بالسيئة ) بنزول العذاب بهم ( قبل الحسنة ) قبل نزول الرحمة ( وقد خلت ) مضت ( من قبلهم المثلاث ) العقوبات بأمثالهم المكذبين فلم يعتبرون ( وإن ربك لذو مغفرة للناس على ظلمهم ) أي ظلمهم أنفسهم وغيرهم ( وإن ربك لشديد العقاب ) لمن خالف أوامره وفي الحديث مرفوعا لولا عفو الله وتجاوزه لما هنأ أحد العيش ولولا وعيده وعقابه لاتكل كل أحد رواه البيضاوي في تفسيره<br />
