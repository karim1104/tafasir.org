{ يا أيها الذين آمنوا } بعيسى وكتابه { واتقوا الله } اجتنبوا ما نهاكم عنه { وآمنوا } صدقوا { برسوله } محمد صلى الله عليه وسلم { يؤتكم كفلين } نصيبين أحدهما على إيمانكم الأول والثاني على إيمانكم بهذا الرسول محمد صلى الله عليه وسلم وكتابه { من رحمته } الخاصة { ويجعل لكم } ببركة إيمانكم { نورا تمشون به } على متن الصراط كما قال تعالى نورهم يسعى بين أيديهم أو نورا يوضح لكم طريق السلوك إلى مالك الملوك { ويغفر لكم } ما قصرتموه { والله غفور } لسيئات من تابع إليه { رحيم } بمن أقبل عليه<br />
