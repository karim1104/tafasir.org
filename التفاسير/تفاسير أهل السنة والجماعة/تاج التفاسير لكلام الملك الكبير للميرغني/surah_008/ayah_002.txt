( إنما المؤمنون ) أصحاب الإيمان الكامل ( الذين إذا ذكر الله ) أي إذا ذكروا بالله ( وجلت ) خافت ( قلوبهم ) منه أو إذا ذكر الله فزعت قلوبهم لرقتها ولينها استعظاما لذكره وهي قلوب القوم الطاهرين القائل فيها سيد المرسلين صلى الله عليه وسلم أن لله تعالى آنية من أهل الأرض وآنية ربكم قلوب عباده الصالحين وأحبها إليه ألينها وأرقها رواه الطبراني في الكبير ( وإذا تليت عليهم آياته ) أي القرآن ( زادتهم إيمانا ) يقينا واطمئنان نفس ( وعلى ربهم يتوكلون ) يسلمون الأمر إليه ولا ينازعون<br />
