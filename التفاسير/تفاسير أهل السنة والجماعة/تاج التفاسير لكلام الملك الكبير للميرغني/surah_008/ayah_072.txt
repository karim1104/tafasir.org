( إن الذين آمنوا وهاجروا ) والمهاجر هو من ترك وطنه حبا في الله ورسوله ( وجاهدوا بأموالهم ) أنفقوها ( وأنفسهم في سبيل الله ) طلبا لإعلاء كلمته ( والذين آووا ) النبي والمؤمنين إلى ديارهم ( ونصروا ) نصروهم على أعدائهم { وأولو الأرحام بعضهم أولى ببعض } ( والذين آمنوا ولم يهاجروا مالكم من ولايتهم ) أي من توليهم في الميراث وقرئ بفتح الواو ( من شيء حتى يهاجروا ) إلى دار الهجرة ( وإن استنصروكم في الدين فعليكم النصر ) أي فوجب نصركم لهم على الكفار ( إلا على قوم بينكم وبينهم ميثاق ) عهد فلا تنقضوا العهد لنصرهم ( والله بما تعملون بصير ) فيجازيكم عليه<br />
