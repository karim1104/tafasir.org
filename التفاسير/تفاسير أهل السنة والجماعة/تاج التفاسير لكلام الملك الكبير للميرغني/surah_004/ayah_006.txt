( وابتلوا ) اختبروا ( اليتامى ) في معاملتهم الدينية والدنيوية قبل بلوغهم ( حتى إذا بلغوا النكاح ) أي حده باحتلام أو استكمال خمس عشرة سنة لقوله صلى الله عليه وسلم إذا استكمل المولود خمس عشرة سنة كتب ماله وعليه وأقيمت عليه الحدود ( فإن آنستم ) رأيتم ( منهم رشدا ) صلاحا في متعلقاتهم الدنية والدنيوية ( فادفعوا إليهم أموالهم ) التي أقمتم عليها وكلاء ( ولا تأكلوها ) أصلحكم الله ( إسرافا ) بغير حق ( وبدرا ) ومبادرين خشية ( أن يكبروا ) فيلزمكم إعطاء أموالهم ( ومن كان غنيا ) منكم أيها الأولياء ( فليستعفف ) عن أكل مال اليتامى ( ومن كان فقيرا ) ليس عنده شيء يأكله ( فليأكل ) من مالهم ( بالمعروف ) بقدر أجرته بغير ضرر عليهم ( فإذا دفعتم ) سلمتم ( إليهم ) الضمير لليتامى ( أموالهم ) الموكلين عليها ( فأشهدوا عليهم ) حين تسليمكم لها شاهدين ( وكفى بالله حسيبا ) محاسبا لعباده<br />
