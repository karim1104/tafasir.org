( يا أيها الذين آمنوا ) بالله ورسوله ( آمنوا ) لازموا على إيمانكم ( بالله ) والإقرار له بالوحدانية ( ورسوله ) بأنه الرسول الحق ( والكتاب ) أي القرآن ( الذي نزل على رسوله ) محمد صلى الله عليه وسلم ( والكتاب الذي أنزل من قبل ) أي والكتب التي أنزلت على الرسل وقرئ الفعلان بالبناء للفاعل ( ومن يكفر بالله ) ويجعل له شريكا ( وملائكته ) فيقدح فيهم ( وكتبه ) فينكرها ( ورسله ) فيكذبهم أو يؤمن بالبعض ويكذب البعض ( واليوم الآخر ) ينكر البعث والحساب والعقاب ( فقد ضل ) عن الهدى والنجاة ( ضلالا بعيدا ) فلا يجتمع عليهما<br />
