( يا أيها الذين آمنوا ) المتحققون بالإيمان ( لا تقربوا الصلاة ) ولا تقوموا فيها ( وأنتم سكارى ) بالخمر وقرئ سكرى ( حتى تعلموا ما تقولون ) تصحوا من سكركم وهذه الآية قبل تحريم الخمر ( ولا جنبا ) أي ولا تقربوا الصلاة وأنتم مجنبون ( إلا عابري سبيل ) مجتازي طريق مسافرين ( حتى تغتسلوا ) فلكم أن تصلوا إذا لم تجدوا ماء ( وإن كنتم مرضى ) مرضا تخشون مع مس الماء فيه الضرر ( أو على سفر ) وليس عندكم ماء ( أو جاء أحد منكم من الغائط ) أي أحدث ( أو لامستم النساء ) جامعتموهن ( فلم تجدوا ماء ) تطهرون للصلاة به ( فتيمموا ) اقصدوا ( صعيدا طيبا ) ترابا طاهرا وكيفية التيمم ما روى في كشف الغمة عن عمار بن ياسر أنه قال بعثني رسول الله صلى الله عليه وسلم في حاجته فأجنبت فلم أجد الماء فتمرغت في الصعيد تمرغ الدابة ثم أتيت رسول الله صلى الله عليه وسلم فذكرت ذلك له فقال إنما كان يكفيك أن تصنع هكذا وضرب بكفيه ضربة واحدة على الأرض ثم نفضهما{[18]} ثم مسح بهما ظهر كفه بشماله أو ظهر شماله بكفه ثم مسح بها وجهه ثم ضرب بشماله على يمينه وبيمينه على شماله على الكفين ثم مسح بيديه وعند الحاكم عنه صلى الله عليه وسلم التيمم ضربتان ضربة للوجه وضربة لليدين إلى المرفقين ( إن الله كان عفوا ) ومن عفوه تيسير الأمور ( غفورا ) لعباده ما يقصرون فيه إن تابوا
