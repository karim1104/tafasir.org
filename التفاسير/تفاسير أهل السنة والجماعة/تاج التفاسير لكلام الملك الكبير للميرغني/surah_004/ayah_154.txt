( ورفعنا فوقهم الطور ) الجبل المعروف ( بميثاقهم ) أي بسبب ميثاقهم لعلهم يقبلونه ( وقلنا لهم ) وهو مشرف عليهم ( ادخلوا الباب ) باب البلد ( سجدا ) منحنين ( وقلنا لهم لا تعدوا ) وقرئ لا تعدوا بفتح العين وتشديد الدال أي لا تعتدوا ( في السبت ) أي منعناهم من اصطياد الحيتان يوم السبت ( وأخذنا منهم ) على ذلك ( ميثاقا غليظا ) عهدا أكيدا فنكثوا<br />
