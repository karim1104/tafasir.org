( قل هلم ) أحضروا ( شهداءكم الذين يشهدون أن الله حرم هذا ) أي الذي ذكرتموه ( فإن شهدوا ) بذلك ( فلا تشهد معهم ) ولا تصدقهم وأظهر لهم فساد دعواهم ( ولا تتبع أهواء الذين كذبوا بآياتنا ) بل أثبت على الحق ودعهم ( والذين لا يؤمنون بالآخرة ) فينكرون البعث ( وهم بربهم يعدلون ) يجعلون له شريكا<br />
