( وهو الذي يتوفاكم ) أي ينيمكم ( بالليل ) أي فيه وعبر جل شأنه بالتوفي لأن النوم أخو الموت وفي الخبر قال صلى الله عليه وسلم النوم أخو الموت وفي الخبر قال صلى الله عليه وسلم النوم أخو الموت ولا يموت أهل الجنة أخرجه البيهقي في الشعب ( ويعلم ما جرحتم ) أي كسبتم ( بالنهار ) أي فيه ( ثم يبعثكم ) يوقظكم من نومكم ( فيه ) الضمير للنهار ( ليقضي أجل مسمى ) أي ليبلغ كل أحد أجله المسمى له ( ثم إليه مرجعكم ) فتموتون ( ثم ينبئكم ) بعد أن يبعثكم ( بما كنتم تعملون ) فيجازيكم عليه<br />
