( قل أي شيء اكبر شهادة ) حجة وبرهانا من شهادة الله تعالى فإن لم يجيبوا ( قل ) لهم ( الله شهيد ) أي أكبر شهادة ( بيني وبينكم ) على صدقي وتكذيبكم ( وأوحي إلى هذا القرآن ) الكريم ( لأنذركم به ) أخوفكم ( ومن بلغ ) أي ومن بلغه القرآن من الناس أجمعين كما قال صلى الله عليه وسلم في الحديث بعثت إلى الناس كافة الحديث بطوله والجن كذلك ( أئنكم لتشهدون أن مع الله آلهة أخرى ) وهذا الاستفهام استنكاري ( قل ) لهم ( لا أشهد قل إنما هو إله واحد ) أي بل أشهد بوحدانيته ( وإنني برئ مما تشركون ) معه من الأوثان<br />
