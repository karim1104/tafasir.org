( ومن الإبل اثنين ومن البقر اثنين ) من ذكور النوعين وإناثهما ( قل آلذكرين حرم ) عليكم ربنا ( أم الأنثيين أم ما اشتملت عليه أرحام الأنثيين ) أخبروا ( أم كنتم شهداء ) بل أكنتم حاضرين مشاهدين ( إذ وصاكم الله بهذا ) التحريم بل أنتم كاذبون في دعواكم ( فمن أظلم ) لا أحد أظلم ( ممن افترى على الله كذبا ) فنسب إليه تحريم ما لم يحرم ( ليضل ) بذلك ( الناس بغير علم ) صحيح ( إن الله لا يهدي القوم الظالمين ) المهلكين لأنفسكم بجراءتهم على الله<br />
