( وأقسموا ) بعض الكفار ( بالله جهد أيمانهم ) بالغين جهدهم في أيمانهم ( لئن جاءتهم آية ) من الذي اقترحوه ( ليؤمنن بها ) ويتبعون الحق ( قل إنما الآيات عند الله ) هو القادر على إنزالها وإنه ولي الإنزال ( وما يشعركم ) أي وما يريكم أيها المؤمنون ( أنها ) الآية التي ( إذا جاءت لا يؤمنون ) لسبق الشقاوة لهم<br />
