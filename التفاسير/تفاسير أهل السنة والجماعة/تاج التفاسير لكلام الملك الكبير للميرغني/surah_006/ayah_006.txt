( ألم يروا كم أهلكنا ) بارتكاب التكذيب ( من قبلهم ) من قبل الأمم الذين كذبوا النبي صلى الله عليه وسلم ( من قرن ) أهل زمن ( مكناهم ) أولا ( في الأرض ) وجعلنا لهم قوة وسعة ( ما لم نمكن لكم ) أيها المكذبون الحاضرون فإن ما حصل من القوة لعاد وثمود ونحوهم لم يحصل للكفار الحاضرين ( وأرسلنا ) مع ذلك ( السماء عليهم ) أي أنزلنا المطر عليهم ( مدرارا ) كثيرا ( وجعلنا الأنهار تجري من تحتهم ) تحت بيوتهم ( فأهلكناهم ) وأخذناهم أخذ غضب ( بذنوبهم ) وتكذيبهم أنبياءنا ( وأنشأنا ) أحدثنا ( من بعدهم قرنا آخرين ) عمرنا بهم الأرض والمعنى كما أهلكنا أولئك لما كذبوا ،  نهلككم إن كذبتم<br />
