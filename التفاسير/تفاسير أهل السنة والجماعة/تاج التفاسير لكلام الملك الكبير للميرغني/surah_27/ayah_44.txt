{ قيل لها ادخلي الصرح } وهو سطح من زجاج أبيض شفاف تحته ماء جار فيه سمك جعله سليمان ليرى ساقيها وقدميها لما قيل له إن ساقيها شعرهما كثير وقدميها كقدمي حمار { فلما رأته حسبته لجة } من الماء { وكشفت عن ساقيها } لتخوض فرأى سليمان ساقيها وقدميها فإذا هي أحسن الناس ساقا وقدما ثم { قال } لها { إنه صرح ممرد } أملس { من قوارير } من زجاج ودعاها إلى الإسلام فأجابت { قالت رب إني ظلمت نفسي } بعبادة غيرك { وأسلمت مع سليمان لله رب العالمين } وأراد سليمان تزويجها وكره كثرة الشعر الذي بساقيها فعملت له الشياطين النورة فأزالته فتزوجها وأقرها على ملكها وكان سليمان أول من صنعت له النورة وفي الحديث قال صلى الله عليه وآله وسلم أول من دخل الحمامات وصنعت له النورة سليمان بن داود فلما دخل وجد حره وغمه فقال أواه من عذاب الله أواه قبل أن لا تكون أواه رواه ابن عدي وغيره<br />
