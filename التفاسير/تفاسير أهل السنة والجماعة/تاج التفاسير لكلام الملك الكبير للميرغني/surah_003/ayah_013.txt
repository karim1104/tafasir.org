( قد كان لكم آية ) دالة على صدق النبي صلى الله عليه وسلم ( في فئتين ) فريقين ( التقتا ) يوم بدر ( فئة ) مسلمة ( تقاتل في سبيل الله ) وهم النبي ومن معه من المسلمين وكانوا ثلثمائة وبضعة عشر ( وأخرى ) أي وفئة أخرى ( كافرة ) وكانوا نحو ألف ( يرونهم ) المؤمنون وقرئ ترونهم بالتاء وقرئ بهما مع البناء للمفعول ( مثليهم ) أي مثلي المؤمنين ( رأي العين ) أي رؤية ظاهرة ( والله يؤيد ) يقوي ( بنصره من يشاء ) وقد أيدكم ونصركم عليهم ( إن في ذلك لعبرة ) لعظة ( لأولي الأبصار ) أي أهل البصائر المجلية .  <br />
