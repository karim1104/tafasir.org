( وليعلم الذين نافقوا ) أيضا بذلك الاختبار ويظهر ما أخفوه ( وقيل لهم ) أي للمنافقين وهو عبد الله بن أبي ومن معه قال لهم المسلمون ( تعالوا قاتلوا ) الكفار معنا ( في سبيل الله ) وطلب إعلاء كلمته ( أو ادفعوا ) أو ادفعوهم عنا بتعزيركم لنا ( قالوا ) المنافقون ( لو نعلم قتالا ) أي إن ثم قتالا ( لاتبعناكم ) وقاتلنا معكم ما أنتم عليه ليس بقتال إنما هو إلقاء نفس في الهلاك ( هو للكفر يومئذ ) يوم قولهم هذا ( أقرب منهم للإيمان ) وكانوا قبل بحسب ما يظهرونه أقرب للإيمان من الكفر ( يقولون بأفواههم ) أي بألسنتهم ( ما ليس في قلوبهم ) فإنهم لو علموا أن ثم قتالا يتبعوكم ( والله أعلم بما يكتمون ) من سوء أفعالهم ونفاقهم<br />
