( قل ) أيها النبي لهم ( آمنا بالله ) وأفردناه بالتوحيد والعبادة ( وما أنزل علينا ) أي القرآن ( وما أنزل على إبراهيم ) الصحف ( وإسماعيل وإسحق ويعقوب والأسباط ) أي ما كانوا عليه من الشرائع من الله ( وما أوتي موسى ) التوراة ( وعيسى ) أي الإنجيل ( والنبيون من ربهم ) في شرائعهم الذين هم عليها من الله ( لا نفرق ) في الإيمان بهم ( بين أحد منهم ) فنؤمن ببعض ونكذب بعضا كما فعلت اليهود والنصارى ( ونحن له مسلمون ) مخلصون له العبادة .  <br />
