( والذين إذا فعلوا ) عملوا ( فاحشة ) ذنبا كبيرا كالزنا ( أو ظلموا أنفسهم ) بذنب صغير كالقبلة ( ذكروا الله ) ذكروا عظمته وما رتب من الوعيد في ذلك ( فاستغفروا ) الله ( لذنوبهم ) ندموا وتابوا ( ومن يغفر ) للمسئين ( الذنوب ) التي يرتكبونها ( إلا الله ) الذي رحمته وسعت كل شيء ( ولم يصروا ) ولم يقيموا ( على ما فعلوا ) من الذنوب بل يستغفرون الله كلما أحدثوا ذنبا ( وهم يعلمون ) أن ما ارتكبوه قبيح وأخرج أبو داود والترمذي عنه صلى الله عليه وسلم أنه قال ما أصر من استغفر وإن عاد في اليوم سبعين مرة<br />
