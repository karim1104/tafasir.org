( ورسولا ) ونبعثه رسولا ( إلى بني إسرائيل ) يدعوهم إلينا ويقول لهم ( إني قد جئتكم ) رسولا من عند الله ( بآية ) علامة تدلكم على صدقي ( من ربكم ) أعطيتها ( أنى ) وقرئ بالكسر ( أخلق ) أصور ( لكم من الطين كهيئة ) كمثل صورة ( الطير ) ثم أراد أن ينبههم على أن ذلك بإرادة الله <br />
( فأنفخ فيه ) في الطير ( فيكون طيرا ) وقرئ طائرا ( بإذن الله ) بإرادته فخلق بإذن الله طيرا ورواه يطير ( وأبرئ ) أشفي وأعافي ( الأكمة ) المولود أعمى ( والأبرص ) الذي به داء البرص وأعافي في يوم ألفا بشرط الإيمان ( وأحيي الموتى ) وأحيي جمعا ( بإذن الله ) فلا تتوهموا أني إله ( وأنبئكم ) أخبركم ( بما تأكلون ) من الطعام ( وما تدخرون في بيوتكم ) من غير أن أعاينه وكان يخبرهم بما أكلوا وبما يأكلون بعد ذلك ( إن في ذلك ) الذي ظهرت به لكم من المعجزات ( الآية لكم ) تدلكم على صدقي ( إن كنتم مؤمنين ) مؤهلين للإيمان .  <br />
