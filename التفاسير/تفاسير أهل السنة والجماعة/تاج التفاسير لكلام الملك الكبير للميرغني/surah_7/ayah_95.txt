( ثم بدلنا ) أعطيناهم ( مكان السيئة ) أي محل البؤس والفقر والمرض ( الحسنة ) الغنى والعافية وكل ذلك فعلناه ابتلاء ( حتى عفوا ) كثروا عددا وعددا ( وقالوا ) كافرين لنعمتنا ( قد مس آباءنا الضراء والسراء ) مثل ما مسنا وليس فيما أصابنا عقوبة فتمادوا على ضلالهم ( فأخذناهم ) أخذ غضب ( بغثة ) فجأة ( وهم لا يشعرون ) بوقت نزول عذابنا بهم<br />
