( وواعدنا موسى ) وقرئ بغير ألف ( ثلاثين ليلة ) لمكالمتنا أن يصوم هذا العدد ويخلي وكان شهر ذي القعدة فلما أتمها استاك فأنكرت الملائكة ريح فمه فقالوا له أفسدت أمرك بالسواك ( وأتممناها بعشر ) من أول ذي الحجة ( فتم ميقات ربه ) للمكالمة ( أربعين ليلة ) ومن هذا أخذ السادة الصوفية الخلوة الأربعينية ( وقال موسى ) عند مضيه للمكالمة في الجبل ( لأخيه هرون اخلفني ) كن خليفتي ( في قومي وأصلح ) أمورهم ( ولا تتبع سبيل المفسدين ) لا توافقهم على فسادهم<br />
