( قال ) زكريا ( رب اجعل لي ) على حمل زوجتي ( آية ) أي علامة ( قال ) الله له ( آيتك ) العلامة لك في ذلك ( أن لا تكلم الناس ) أن لا تقدر على الكلام مع الناس ( ثلاثة أيام ) متتابعة ( إلا رمزا ) بإشارة وقرئ رمزا كخدما ورمزا كرسلا ( واذكر ربك ) في تلك الأيام ( كثير ) ذكرا كثيرا <br />
( وسبح ) له ( بالعشي ) من العصر إلي المغرب ( والإبكار ) من طلوع الفجر إلى الضحى وقرئ بكسر الهمزة .  <br />
