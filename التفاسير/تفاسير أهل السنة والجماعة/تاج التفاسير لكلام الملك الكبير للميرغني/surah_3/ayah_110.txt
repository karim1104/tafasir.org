( كنتم خير أمة ) يا أمة محمد ( أخرجت ) أظهرت ( للناس ) من نعتكم أنكم ( تأمرون بالمعروف ) الذي يرضاه الله ( وتنهون عن المنكر ) الذي يأباه الله ( وتؤمنون بالله ) تذعنون له بالتوحيد ولا تشركوا كما أشرك أكثر الأمم الذين قبلكم ( ولو آمن أهل الكتاب ) بالله تعالى وبالنبي صلى الله عليه وسلم والقرآن ( لكان خيرا لهم ) لأنهم بذلك كانوا يدخلون الجنة في الآخرة ويصونون في الدنيا أموالهم ونسائهم وأبنائهم وأنفسهم ( منهم المؤمنون ) الذين فازوا بذلك ( وأكثرهم الفاسقون ) الذين تعدوا حدود الله فباءوا بعذابه في الدنيا والآخرة<br />
