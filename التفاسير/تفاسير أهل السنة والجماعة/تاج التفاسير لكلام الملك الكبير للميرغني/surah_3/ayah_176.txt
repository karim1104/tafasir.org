( ولا يحزنك ) وقرئ يحزنك بضم الياء وكسر الزاي ( الذين يسارعون في الكفر ) أي لا تخف من عدم نصرهم لك ووقوعهم في الكفر ( إنهم لن يضروا الله ) لن يضروا أولياءه ( شيئا ) بمسارعتهم إلى الكفر بل على أنفسهم ضررهم ( يريد الله ) بفعلهم ذلك ( أن لا يجعل لهم حظا ) نصيبا من الثواب ( في الآخرة ) في الجنة ( ولهم ) بما ارتكبوه ( عذاب عظيم ) وهو عذاب الجحيم<br />
