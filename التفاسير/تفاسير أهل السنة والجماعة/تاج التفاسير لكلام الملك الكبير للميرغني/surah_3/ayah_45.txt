( إذ قالت الملائكة ) قال جبريل ( يا مريم ) القانتة ( إن الله يبشرك ) بأن يتفضل عليك ( بكلمة منه ) ولد عن غير أب من سر كلمة كن ( اسمه المسيح ) المبارك ( عيسى بن مريم ) إشارة إلى أنها تلده عن غير أب ( وجيها ) له جاه كبير ( في الدنيا ) بالنبوة وما صحبها من المعجزات التي كانت معه العجيبة ( والآخرة ) بنيل الدرجات العلى والشفاعة في بعض الملا ( ومن المقربين ) أهل أعلى منزل القرب المحتوي على ألذ الخطاب والمشاهدة والحب .  <br />
