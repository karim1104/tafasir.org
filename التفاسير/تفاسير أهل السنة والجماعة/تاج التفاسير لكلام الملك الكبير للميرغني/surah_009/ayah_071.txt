( والمؤمنون والمؤمنات ) أصفياء الحق ( بعضهم أولياء بعض ) رحماء بينهم متحاببون في الله ولله متناصحون ( يأمرون بالمعروف ) بعضهم بعضا وأنفسهم ( وينهون عن المنكر ) أنفسهم وبعضهم بعضا فلا يزالون يتناصحون وفي الحديث مرفوعا { إن أحب عباد الله إلى الله أنصحهم لعباده } وكان أفضلهم عنده صلى الله عليه وسلم : أعمهم نصيحة أخرجهما الجد سيدي عبد الله الميرغني في كتابه زهر الرياحين ( ويقيمون الصلاة ) بقلوب حاضرة ( ويؤتون الزكاة ) بطيب نفس ( ويطيعون الله ورسوله ) فيما يأمرانهم ( أولئك ) الموصوفون ( سيرحمهم الله ) برحمته الواسعة ( إن الله عزيز ) لا يغلبه شيء ( حكيم ) في كل شيء ومنه إنزال الأولين منازل العذاب وإنزال هؤلاء منازل الرحمة<br />
