( اتخذوا أحبارهم ) علماء اليهود ( ورهبانهم ) عباد النصارى ( أربابا من دون الله ) فأطاعوهم في تحليل ما حرم الله وتحريم ما حلل ( والمسيح ابن مريم ) اتخذوه ربا ( وما أمروا ) في كتابيهما التوراة والإنجيل ( إلا ليعبدوا ) أن يطيعوا ( إلها واحدا ) وهو الله وطاعته ( لا إله إلا هو ) لا معبود بحق سواه ( سبحانه ) تنزه ( عما يشركون ) الكافرون<br />
