( إلا تنصروه ) الضمير للنبي صلى الله عليه وسلم ( فقد نصره الله ) وأيده ( إذ أخرجه ) اضطره إلى الخروج ( الذين كفروا ) من مكة كما مر في قوله وإذ يمكر بك الذين كفروا الآية ( ثاني اثنين ) أي واحد اثنين هو أبو بكر ( إذ هما في الغار ) في غار جبل ثور بمكة ( إذ يقول ) النبي صلى الله عليه وسلم ( لصاحبه ) أبي بكر الصديق حين رأى المشركين وقال لو نظر أحدهم تحت قدميه أبصرنا فقال النبي صلى الله عليه وسلم ما ظنك باثنين الله ثالثهما ( لا تحزن إن الله معنا ) ومنهم يحفظنا ( فأنزل الله سكينته ) طمأنينته ( عليه ) على نبيه وحبيبه ( وأيده بجنود لم تروها ) وهم الملائكة في الغار وفي حنين وبدر والأحزاب ( وجعل كلمة الذين كفروا ) التي هي الشرك ( السفلى ) المغلوبة ( وكلمة الله ) دعوة الإسلام ( هي العليا ) المرتفعة الظاهرة الغالبة وقرئ كلمة الله بالنصب ( والله عزيز ) لا يغلب ( حكيم ) فيما رتب<br />
