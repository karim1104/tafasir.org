{ ووصينا الإنسان بوالده } أمرناه ببرهما وفي بر الوالدين من الخير ما لا مزيد عليه وفي الحديث بر الوالدين يجزي عن الجهاد رواه السيوطي في الجامع الصغير { حملته أمه وهنا } ذات وهن أي ضعف { على وهن } أي على ضعف وقرئ محركا { وفصاله } فطمه وقرئ فصله بفتح الفاء وسكون الصاد { في عامين } انقضاء عامين وقلنا له { أن اشكر لي } لإبرازي لك من العدم ونعمي التي عليك لا تنساها { ولوالديك } لتربيتهما وإحسانهما وشفقتهما بك { إلي المصير } المرجع وأحاسبك على ذلك ويكفي في الزجر عن العقوق قوله صلى الله عليه وسلم ثلاث لا يدخلون الجنة العاق لوالديه والديوث ورجلة النساء .   رواه الحاكم<br />
