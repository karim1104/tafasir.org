{ وقل للمؤمنات يغضضن } يكففن ويخفضن { من أبصارهن } ولا ينظرن إلى ما لا يحل لهن { ويحفظن فروجهن } بالستر وترك الزنا { ولا يبدين } يظهرن { زينتهن } كالخلخالين والقرطين والقلائد والدمالج والثياب والأصباغ { إلا ما ظهر منها } وهو وجهها وكفها إن لم يخش فتنة { وليضربن بخمرهن } وليلقين مقانعهن { على جيوبهن } فيسترن أعناقهن وصدورهن ورؤوسهن وزينتهن { ولا يبدين } يكشفن { زينتهن } المذكورة { إلا لبعولتهن } أزواجهن { أو آبائهن } ولادة أو رضاعا { أو أباء بعولتهن } آباء أزواجهن { أو أبنائهن } أولادهن سواء كانوا ولادة أو رضاعا { أو أبناء بعولتهن } أولاد أزواجهن { أو إخوانهن } سواء كانوا لأبوين أو لأب أو لأم من الرضاع { أو بني إخوانهن } من الولادة أو من الرضاع { أو بني أخواتهن } كذلك من الولادة أو الرضاع { أو نسائهن } أي نسائهن المؤمنات { أو ما ملكت أيمانهن } من الإماء وقيل عبيدهن كذلك { أو التابعين } كالخادمين { غير أولي الإربة من الرجال } الذين لا حاجة لهم في النساء وهم الشيوخ الذين ذهبت شهوتهم { أو الطفل } أي الأطفال { الذين لم يظهروا } لم يطلعوا { على عورات النساء } لعدم تمييزهم وذلك ما عاد بين السرة والركبة { ولا يضربن } النساء { بأرجلهن } بأن تضرب رجلها الأخرى فيتقعقع الخلخال ويفعلن ذلك { ليعلم } يعلم الرجال { ما يخفين من زينتهن } النساء فيفتن الرجال بهن { وتوبوا إلى الله جميعا } من الاشتغال بما يضركم { أيها المؤمنون } الطالبون للنجاة { لعلكم تفلحون } تفوزون بخير الدارين<br />
