{ وليستعفف } يتعفف { الذين } لا يجدون نكاحا } أي لا يجدون ما لا يتزوجون به وينفقون منه { حتى يغنيهم الله من فضله } فيجدوا ما يتزوجون به { والذين يبتغون } يطلبون { الكتاب } المكاتبة { مما ملكت إيمانكم } من عبيدكم وإمائكم { فكاتبوهم } أعطوهم ما يطلبون من المكاتبة { إن علمتم فيهم خيرا } أمانة وقدرة على أداء ذلك وصلاحا في دينهم وكيفيتها مثلا كاتبتك على مائة في عشرة أشهر كل شهر تدفع عشرا فإذ أديتني جميع ذلك ووفيتني فأنت حر يقول لك قبلت وهو في ملكك ما بقي عليه شيء بقوله صلى الله عليه وسلم المكاتب عبد ما بقي من مكاتبته درهم رواه أبو داود { وآتاهم } أعطوهم أيها المكاتبون { من مال الذي آتاكم } تفضل عليكم به كأن تتركوا لهم شيئا من القيمة قال علي : يترك الربع وقال ابن عباس : الثلث والأمر للوجوب عند الأكثر وقيل للندب : { ولا تكرهوا فتياتكم } إماءكم { على البغاء } على الزنا { إن أردن تحصنا } تعففا عنه ويجب على كل مؤمن أن لا يترك أمته تزني وقد فرط أهل السودان في ذلك جدا حتى إن كثيرا منهم يتخذ الجواري لأجل ذلك مع أن النبي صلى الله عليه وسلم يقول من أخدم غير ما ينكح ثم بغين فعليه مثل آثامهن من غير أن ينقص من آثامهن شيء رواه البزار هذا مع عدم اتخاذه لهن للبغاء فكيف بمن يتخذن للبغاء { لتبتغوا } بذلك { عرض الحياة الدنيا } الأموال التي يأتين بهن من الزنا { ومن يكرههن } على ذلك { فإن الله من بعد إكراههن } على الزنا وفي مصحف ابن مسعود من بعد إكراههن لهن { غفور } ما فعلن { رحيم } بهن<br />
