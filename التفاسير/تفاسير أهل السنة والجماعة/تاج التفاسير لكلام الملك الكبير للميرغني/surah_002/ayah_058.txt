( وإذ قلنا ) لهم بعد خروجهم من التيه ( ادخلوا هذه القرية ) بيت المقدس أو أريحا ( فكلوا منها ) ،  الضمير للقرية أي مما فيها من النعم ( حيث شئتم رغدا ) واسعا ،  ( وادخلوا الباب ) باب القرية ( سجدا ) لله شكرا على إنجائكم من التيه .   ( وقولوا ) مسألتنا ( حطة ) نسألك أن تحط عنا خطايانا وقرئ بالنصب .   ( نغفر لكم ) وقرئ يغفر لكم وتغفر لكم بالبناء للمفعول ( خطاياكم ) ذنوبكم ( وسنزيد المحسنين ) بطاعتنا ثوابا جزيلا .  <br />
