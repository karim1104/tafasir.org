( إن الذين يكتمون ) ويخفون ويحرفون ( ما انزل الله من الكتاب ) وهو ما في التوراة من نعته صلى الله عليه وسلم ( ويشترون به ) بأن يستبدلوا ( ثمنا قليلا ) من حقير الدنيا وخسيسها( أولئك ) الفاعلون ذلك ( ما يأكلون في بطونهم ) الخبيثة ( إلا النار ) لأن عاقبتهم إليها ( ولا يكلمهم الله ) بل يحرمون لذة مناجاته ويبوءون بغضبه وكبير نقماته ( يوم القيامة ) يوم العرض على جنابه العزيز ( ولا يزكيهم ) يطهرهم من درن معاصيهم ( ولهم ) بما قدموا ( عذاب أليم ) شديد لا ينفك<br />
