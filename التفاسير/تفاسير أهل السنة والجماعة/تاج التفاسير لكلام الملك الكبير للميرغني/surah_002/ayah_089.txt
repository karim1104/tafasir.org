{ ولما جاءهم } على لسان رسولنا محمد صلى الله عليه وسلم { كتاب من عند الله } وهو القرآن { مصدق لما معهم } وهو التوراة { وكانوا من قبل } أي قبل ظهور بعث النبي صلى الله عليه وسلم ونزول القرآن { يستفتحون } يستنصرون { على الذين كفروا } ويقولون اللهم انصرنا بني آخر الزمان المنعوت في التوراة { فلما جاءهم ما عرفوا } وهو النبي صلى الله عليه وسلم المنعوت عندهم في التوراة { كفروا به } حسدا من عند أنفسهم وخوفا على رياستهم { فلعنة الله على الكافرين } الذين ستروا الحق واظهروا الباطل .  <br />
