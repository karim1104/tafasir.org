{ ثم أنتم } بعد ذلك { هؤلاء } نداء أي يا هؤلاء { تقتلون أنفسكم } أي يقتل بعضكم بعضا  ،  وقرئ تقتلون مشددا { وتخرجون فريقا } طائفة <br />
{ منكم من ديارهم } وتخربونها { تظاهرون } أي تتعاونون { عليهم } وقرئ تظاهرون بتشديد الظاء ،  وقرئ بتاءين { بالإثم } المعصية { والعدوان } العداوة ظلما بغير حق { وإن يأتوكم أسارى } وقرئ أسرى { تفادوهم } أي تنقذونهم من أسرهم بالمال ،  وقرئ تفدوهم { وهو } أي المعهود إليكم من الله { محرم عليكم إخراجهم } أي إخراجهم من ديارهم { أفتؤمنون ببعض الكتاب } أي فدائهم { وتكفرون ببعض } وهو القتل والإخراج والمظاهر ،  والقصة أن قريظة حالفوا الأوس  ،  والنضير حالفوا الخزرج  ،  فكان كل منهم يقاتل مع حلفائه ويخرب ديار الآخرين ويخرجهم فإذا أسروا فدوهم  ،  فإن قيل لم تفدونهم ؟ يقولون  : أمرنا بالفداء  ،  وإن قيل لهم لم تقاتلونهم ؟ .    يقولون :  لا نرضى أن يهان حلفاؤنا فهذا هو الإيمان بالبعض والكفر بالبعض .   وفي الحديث قال رسول الله صلى الله عليه وسلم  : " أخذ الله عليهم أربعة عهود  ؛ ترك القتل وترك الإخراج وترك المظاهرة وفداء أسراهم فأعرضوا عن كل ما أمروا إلا الفداء  "  .   { فما جزاء من يفعل ذلك منكم } معشر اليهود { إلا خزي }تعاملون به { في الحياة الدنيا } وقد وقع لهم ذلك فقتل بنو قريظة وسبوا وأجلى بنوا النظير وضربت الجزية على غيرهم فما أشده من خزي وذل { ويوم القيامة } مع ما وقع لهم في الدنيا { يردون } وقرئ بالتاء { إلى أشد العذاب } لارتكابهم أشد معصية لنقضهم العهود وتغيير ما جاء في وصف النبي صلى الله عليه وسلم المحمود { وما الله بغافل عما يعملون } بل هو بالمرصاد وقرئ بالياء .  <br />
