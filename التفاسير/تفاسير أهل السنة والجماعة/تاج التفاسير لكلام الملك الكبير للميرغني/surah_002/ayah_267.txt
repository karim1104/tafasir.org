( يا أيها الذين آمنوا ) المؤمنون بما لله عليكم في الأموال ( أنفقوا ) أعطوا الزكاة ( من طيبات ) أحسن وحلال ( ما كسبتم ) من أموالكم ( ومما أخرجنا لكم ) أي من طيبات ما أخرجنا لكم ( من الأرض ) من حبوب وثمار ومعادن ( ولا تيمموا الخبيث ) الردئ ( منه ) مما كسبتم ومما أخرجنا لكم ( تنفقون ) حين تجب عليكم الزكاة ( ولستم بآخذيه ) الضمير للخبيث ( إلا أن تغمضوا فيه ) وقرئ تغمضون بالتشديد أي تغضوا البصر ( واعلموا أن الله غني ) عن إنفاق مثل ذلك ( حميد ) يقبل ممن أنفق الطيب<br />
