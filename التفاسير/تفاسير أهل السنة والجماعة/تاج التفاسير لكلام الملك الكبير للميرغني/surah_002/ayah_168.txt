( يا أيها الناس كلوا ) يا عباد الله ( مما في الأرض ) أوجده الله لكم ( حلالا ) مباحا ( طيبا ) مباركا والآية نزلت فيمن حرموا أكل السوائب والوصائل والبحائر ( ولا تتبعوا خطوات ) وقرئ بسكون الطاء وقرئ بفتحتين سبل ( الشيطان ) وما يحسنه لكم ( إنه ) الضمير للشيطان ( لكم ) معشر الناس ( عدو مبين ) فلا تتبعوه وأنزلوه في منزل العداوة كما قال تعالى  " إن الشيطان لكم عدو فاتخذوه عدوا " <br />
