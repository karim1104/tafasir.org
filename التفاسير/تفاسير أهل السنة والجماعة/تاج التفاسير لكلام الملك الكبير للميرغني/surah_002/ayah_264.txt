( يا أيها الذين آمنوا ) الطالبين أجر الصدقات ( لا تطلبوا ) لا تحبطوا ( صداقتكم ) أي أجرها ( بالمن والأذى ) فلا تجدونه غدا عند الله فإن مثل ذلك ( كالذي ينفق ماله رئاء ) لأجل رئاء ( الناس ولا يؤمن بالله ) المرتجى ثوابه على الإنفاق بالإخلاص ( واليوم الآخر ) المعدود للجزاء على الإنفاق ( فمثله ) مثل المنفق المرئي ( كمثل صفوان ) حجر أملس ( عليه تراب فأصابه ) أصاب الصفوان ( وابل ) مطر كثير ( فتركه صلدا ) أملس نقيا لا شيء عليه من التراب ( لا يقدرون ) لا ينتفع المنفقون رياء ( على شيء مما كسبوا ) أي لا يجدون ثوابه يوم العرض على الله كما لا يوجد على الحجر الأملس بعد المطر الشديد شيء من التراب ( والله لا يهدي ) إلى الإنفاق الذي يوجب الثواب إليه في الآخرة ( القوم الكافرين ) لأنهم أعداء<br />
