( ألم تر ) ينته علمك ( إلى ) قصة ( الذين خرجوا من ديارهم ) وهم أهل داران حين وقع فيهم الطاعون فخرجوا هاربين ( وهم ألوف ) سبعون أو أقل ( حذر الموت ) خوفا من الطاعون المذكور ( فقال لهم الله ) حين فروا من قدره ( موتوا ) فماتوا عن آخرهم ( ثم أحياهم ) الله بدعاء نبيه حزقيل بعد ثمانية أيام وحكم الطاعون هو ما قاله صلى الله عليه وسلم الطاعون بقية رجز وعذاب أرسل على طائفة من بني إسرائيل فإذا وقع بأرض وأنتم بها فلا تخرجوا منها وإذا وقع بأرض ولستم بها فلا تهبطوا عليها رواه الشيخان ( إن الله لذو فضل ) لا حد له ( على الناس ) ومن فضله إحياء هؤلاء ( ولكن أكثر الناس ) لغفلتهم عن آلائه ( لا يشكرون ) جزيل نعمائه
