( وإذ قلتم ) لخبث طبيعتكم ( يا موسى ) كليم الله ( لن نصبر على طعام واحد ) وهو المن والسلوى ،  ( فادع ) تضرع واسأل ( لنا ربك ) المعتنى بك المجيب لدعواتك ،  ( يخرج لنا ) أي يوجد لنا ( مما تنبث الأرض ) بأمر الله لها ( من بقلها ) وهو ما تنبت الأرض من الخضروات  ،  ( وقثائها ) نوع منها وقرئ قثاؤها بالضم ،  ( وفومها ) وهو الثوم أو الحنطة ( وعدسها ) نوع من الحبوب ( وبصلها قال ) موسى ( أتستبدلون ) تتخذون بدلا  ،  ( الذي هو أدنى ) أحقر وأخس وقرئ أدنأ من الدناءة ( بالذي هو خير ) أي المن والسلوى فإنه أعظم وأرفع  .  <br />
( اهبطوا ) انحدروا ( مصرا ) من التيه وقرأ ابن مسعود غير منون ( فإن لكم ) في الأمصار ( ما سألتم ) من الطعام ،  ( وضربت ) جعلت ( عليهم الذلة ) والهوان والصغار ( والمسكنة ) ألزموها فلا يزالون في أثر البؤس والفقر  .  <br />
( وباءوا ) وانصرفوا وعادوا ( بغضب الله ) من فلق البحر وإظلال الغمام والآيات التي فيها وصف النبي صلى الله عليه وسلم وغير ذلك  ، ( ويقتلون النبيين ) كزكرياء وشعيب وغيرهما ( بغير الحق ) بل ظلما وعدوانا ( ذلك بما عصوا ) أى بسبب عصيانهم لرب العاملين ( وكانوا يعتدون ) حدوده فبئس مثال الظالمين<br />
