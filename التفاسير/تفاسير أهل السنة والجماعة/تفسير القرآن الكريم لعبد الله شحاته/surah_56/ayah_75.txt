إثبات النبوة وصدق القرآن<br />
{  فَلاَ أُقْسِمُ بِمَوَاقِعِ النُّجُومِ ( 75 ) وَإِنَّهُ لَقَسَمٌ لَوْ تَعْلَمُونَ عَظِيمٌ ( 76 ) إِنَّهُ لَقُرْآَنٌ كَرِيمٌ ( 77 ) فِي كِتَابٍ مَكْنُونٍ ( 78 ) لَا يَمَسُّهُ إِلَّا الْمُطَهَّرُونَ ( 79 ) تَنْزِيلٌ مِنْ رَبِّ الْعَالَمِينَ ( 80 ) أَفَبِهَذَا الْحَدِيثِ أَنْتُمْ مُدْهِنُونَ ( 81 ) وَتَجْعَلُونَ رِزْقَكُمْ أَنَّكُمْ تُكَذِّبُونَ ( 82 ) فَلَوْلَا إِذَا بَلَغَتِ الْحُلْقُومَ ( 83 ) وَأَنْتُمْ حِينَئِذٍ تَنْظُرُونَ ( 84 ) وَنَحْنُ أَقْرَبُ إِلَيْهِ مِنْكُمْ وَلَكِنْ لَا تُبْصِرُونَ ( 85 ) فَلَوْلاَ إِنْ كُنْتُمْ غَيْرَ مَدِينِينَ ( 86 ) تَرْجِعُونَهَا إِنْ كُنْتُمْ صَادِقِينَ ( 87 ) فَأَمَّا إِنْ كَانَ مِنَ الْمُقَرَّبِينَ ( 88 ) فَرَوْحٌ وَرَيْحَانٌ وَجَنَّةُ نَعِيمٍ ( 89 ) وَأَمَّا إِنْ كَانَ مِنْ أَصْحَابِ الْيَمِينِ ( 90 ) فَسَلَامٌ لَكَ مِنْ أَصْحَابِ الْيَمِينِ ( 91 ) وَأَمَّا إِنْ كَانَ مِنَ الْمُكَذِّبِينَ الضَّالِّينَ ( 92 ) فَنُزُلٌ مِنْ حَمِيمٍ ( 93 ) وَتَصْلِيَةُ جَحِيمٍ ( 94 ) إِنَّ هَذَا لَهُوَ حَقُّ الْيَقِينِ ( 95 ) فَسَبِّحْ بِاسْمِ رَبِّكَ الْعَظِيمِ ( 96 ) }<br />

المفردات : <br />
فلا أقسم :  هذا قسم تستعمله العرب في كلامها ،  ولا :  مزيدة للتأكيد . <br />
مواقع النجوم :  مغاربها أو منازلها . <br />
التفسير : <br />
75- {  فَلاَ أُقْسِمُ بِمَوَاقِعِ النُّجُومِ } . <br />
جمهور المفسرين على أن المعنى :  أقسم بمواقع النجوم . <br />
قال القرطبي : <br />
لا :  صلة في قول أكثر المفسرين ،  والمعنى :  فأقسم ،  بدليل قوله بعده :  {  وَإِنَّهُ لَقَسَمٌ لَوْ تَعْلَمُونَ عَظِيمٌ } .
