قوله تعالى :  {  يخربون بيوتهم بأيديهم وأيدي المؤمنين } [ 2 ] قال :  أي يخربون قلوبهم ويبطلون أعمالهم باتباعهم البدع وهجرانهم طريقة الاقتداء بالنبيين .  <br />
{  يخربون بيوتهم } [ 2 ] أي بمجانبة المؤمنين ومشاهدتهم ومجالستهم فيحرمون بركاتهم .  <br />
{  فاعتبروا يا أولي الأبصار } [ 2 ] {  فإن الله يضل من يشاء } [ فاطر :  8 ] بالخذلان {  ويهدي من يشاء } [ فاطر :  8 ] بالمعونة ،   وليس لكم من الأمر شيء .
