وقال {  وَإِلَى عَادٍ أَخَاهُمْ هُوداً } ( 65 ) {  وَإِلَى ثَمُودَ أَخَاهُمْ صَالِحاً } ( 73 ) فكل هذا - و الله أعلم - نصبه على الكلام الأول على قوله {  لَقَدْ أَرْسَلْنَا نُوحاً إِلَى قَوْمِهِ } ( 59 ) وكذلك {  لُوطاً } ( 80 ) ،  وقال بعضهم :   " واذْكُرْ لُوطاً "  .  وإنما يجيء هذا النصب على هذين الوجهين ،  أو يجيء على أن يكون الفعل قد عمل فيما قبله وقد سقط بعده فعل على شيء من سببه فيضمر له فعلا .  فإنما يكون على احد هذه الثلاثة وهو في القرآن كثير . <br />
وقال {  خَلاَئِفَ الأَرْضِ } وقال {  خُلَفَاءَ } ( 69 )و ( 74 ) وكل جائز وهو جماعة  " الخليفة "  .
