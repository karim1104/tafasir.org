وقال {  نَقُصُّ عَلَيْكَ مِنْ أَنبَائِهَا } ( 101 ) صيّر  " مِنْ "  زائدة وأراد  " قصَصْنا "  كما تقول  " هل لكَ في ذا "  وتحذف  " حاجة "  . <br />
وقال {  فَمَا كَانُواْ لِيُؤْمِنُواْ بِمَا كَذَّبُواْ مِن قَبْلُ } ( 101 ) فقوله {  بما كذبوا } و الله أعلم يقول :   " بِتَكْذِيبِهِم "  جعل - و الله أعلم - {  مَا كَذَّبُوا } اسما للفعل والمعنى :   " لَمْ يَكُونُوا لِيُؤْمِنُوا بالتكذيب "  أي لا نسميهم بالإيمان [ 120 ب ] بالتكذيب .
