وقال {  جَعَلَهُ دَكّاً } ( 143 ) لأَنَّهُ حين قال {  جَعَلَه } كان كأنه قال  " دَكَّهُ "  ويقال {  دَكّاء } وإذا أراد ذا ف[ قد ] أُجْرِيَ مُجْرَى {  وأَسْألِ الْقَرْيَةَ } لأنه يقال :   " نَاقَةٌ دَكّاءُ "  إذا ذهب سنامها . <br />
وقال {  فَلَمَّا تَجَلَّى رَبُّهُ لِلْجَبَلِ } ( 143 ) يقول  " تَجَلّى أَمْرُهُ "  نحو ما يقول الناس :   " بَرَزَ فُلانٌ لفُلانٍ "  وإِنَّما برز جُنْدُه . <br />
وأَمَّا قولُه {  رَبِّ أَرِنِي أَنظُرْ إِلَيْكَ } ( 143 ) فإنما أراد علما لا يدرك مثله إِلاّ في الآخرة فأَعْلَمَ اللهُ موسى إن ذلك لا يكون في الدنيا .  وقرأها بعضهم {  دَكّاء } جعله  " فَعْلاء "  وهذا لا يشبه أن يكون .  وهو في كلام العرب :   " ناقَةٌ دَكّاءُ "  أي :  ليس لها سنام .  والجبل مذكر إلا أن يكون  " جَعَلَهُ مِثْلَ دَكّاءَ "  وحذف  " مِثْل "  .
