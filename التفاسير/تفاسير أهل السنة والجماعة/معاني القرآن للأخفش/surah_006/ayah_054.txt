وقال :  {  كَتَبَ رَبُّكُمْ عَلَى نَفْسِهِ الرَّحْمَةَ أَنَّهُ مَن عَمِلَ } ( 54 ) و{  أَنَّهُ مَن عَمِلَه مِنكُمْ سُوءًا بِجَهَالَةٍ ثُمَّ تَابَ مِن بَعْدِهِ وَأَصْلَحَ فَأَنَّهُ غَفُورٌ رَّحِيمٌ } ( 54 ) فقوله {  أَنَّهُ } بَدَلٌ من قوله {  الرَّحْمَةَ } أي :  كَتَبَ أنَّهُ مَنْ عمِلَ .  وقوله {  فَأِنَّهُ } على الابتداء أي :  فَلَه المغفرة والرَّحْمَةُ فَهوَ غَفُورٌ رَحيم .  وقال بعضهم {  فأنَّهُ } أراد به الاسم وأضمر الخبر .  أراد  " فَأنَّ "  .
