وقال {  فَأَخْرَجْنَا مِنْهُ خَضِراً } ( 99 ) يريد  " الأَخْضَرَ "  كقول العرب :   " أرِنيِها نَمِرَةً أُرِكَها مَطِرَةً "  . <br />
وقال {  وَمِنَ النَّخْلِ مِن طَلْعِهَا قِنْوَانٌ دَانِيَةٌ } ( 99 ) ثم قال {  وَجَنَّاتٍ مِّنْ أَعْنَابٍ } ( 99 ) أي :   " وَأَخْرَجْنا بِهِ جَنّاتٍ مِنْ أَعنابٍ "  . <br />
ثم قال {  وَالزَّيْتُونَ } ( 99 ) وواحد :   " القِنْوانِ "  :  قِنْوٌ ،  وكذلك  " الصِّنْوانُ "  واحدها :  صِنْوٌ .
