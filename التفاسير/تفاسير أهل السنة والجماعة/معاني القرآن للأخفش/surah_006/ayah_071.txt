وأمَّا قوله {  حَيْرَانَ لَهُ أَصْحَابٌ } ( 71 ) فإِنَّ كلَّ  " فَعْلان "  له  " فَعْلى "  فَإِنَّه لا ينصرف في المعرفة ولا النكرة . <br />
وأمّا قَوْلُه {  إِلَى الْهُدَى ائْتِنَا } ( 71 ) فإن الألف التي في {  ائْتِنا } ألف وصل ولكن بعدها همزة من الأصل هي التي في  " أتَى "  وهي الياء التي في قولك  " إيتِنا "  ،  ولكنها لم تهمز حين ظهرت ألف الوصل .  لأن ألف الوصل مهموزة إذا استؤنفت فكرهوا اجتماع همزتين . <br />
وقال {  وَأُمِرْنَا لِنُسْلِمَ لِرَبِّ الْعَالَمِينَ } ( 71 ) يقول :  إِنَّما أُمِرْنا كَيْ نُسْلِمَ لِرَبِّ العالَمين "  كما قال {  وَأُمِرْتُ أَنْ أَكُونَ مِنَ الْمُؤْمِنِينَ } أي :  إِنما أُمِرت بذلك .
