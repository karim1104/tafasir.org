وقال {  فَالِقُ الإِصْبَاحِ } ( 96 ) جعله مصدرا من  " أَصْبَحَ "  .  وبعضهم يقول {  فالِقُ الأَصْباحِ } جماع  " الصُّبْح "  . <br />
وقال {  وَالشَّمْسَ وَالْقَمَرَ حُسْبَاناً } ( 96 ) أي :  بِحِسابٍ .  فحذف الباء كما حذفها من قوله {  أَعْلَمُ مَن يَضِلُّ عَن سَبِيلِهِ } أَيْ :  أَعْلَمُ بمن يَضِلّ .  و " الحُسْبانُ "  جماعة  " الحِسابِ "  مثل  " شِهاب "  و " شُهْبَان "  ،  ومثله  " الشَمْسُ والقَمرُ بِحُسْبانٍ "  أي :  بحساب .
