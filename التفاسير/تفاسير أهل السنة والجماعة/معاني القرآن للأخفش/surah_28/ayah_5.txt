وقال {  وَنُرِيدُ أَن نَّمُنَّ عَلَى الَّذِينَ اسْتُضْعِفُواْ فِي الأَرْضِ } ( 5 ) على قوله {  يَسْتَضْعِفُ طَائِفَةً مِّنْهُمْ يُذَبِّحُ أَبْنَاءَهُمْ } ( 4 ) ونحن {  نُرِيدُ أَن نَّمْنَّ عَلَى الَّذِينَ [ 158 ء ] اسْتُضْعِفُواْ فِي الأَرْضِ } أي :  فعل هذا فرعون ونحن {  وَنُرِيدُ أَن نَّمُنَّ عَلَى الَّذِينَ اسْتُضْعِفُواْ } .
