وقال {  وَصِيَّةً لأَزْوَاجِهِمْ } ( 240 ) كأنه [ قال ] :   " لأزْواجِهِمْ وَصِيَّةٌ {  مَّتَاعاً إِلَى الْحَوْلِ } ونَصَبَ {  مَتاعاً } لأنه حين قال {  لأزْواجِهِمْ }{  وَصِيَّةً } فكأنه قد قال :   " فَمَتِّعُوهُنَّ "  {  مَتاعاً } فعلى هذا انتصب قوله {  مَّتَاعاً إِلَى الْحَوْلِ غَيْرَ إِخْرَاجٍ } ( 240 ) يقول  " لا إخْراجاً "  أي :   " متاعاً لا إخْراجاً "  أي :  لا تُخْرِجُوهُن إخْراجاً .  وزعموا أنها في حرف ابن مسعود {  كُتِبَ عَلَيكُم وَصِيَّةٌ لأزْواجِكم } . <br />
وقال بعضهم {  وَصِيَّةٌ لأَزْوَاجِهِمْ } ( 240 ) [ 77ب ] فنصب على الأمر [ ورفع ] أي :  عَلَيْكُمْ وصيةٌ بذلك  "  [ و ]  " أَوْصُوا لَهُنَّ وَصِيَّةً "
