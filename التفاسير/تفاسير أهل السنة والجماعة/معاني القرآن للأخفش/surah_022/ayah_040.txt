وقال {  لَّهُدِّمَتْ صَوَامِعُ وَبِيَعٌ وَصَلَوَاتٌ وَمَسَاجِدُ } ( 40 ) فالصَّلَواتُ لا تهدم ولكن حمله على فعل آخر كأنه قال  " وَتُرِكَتْ صَلَواتٌ "  وقال بعضهم :   " إِنّما يعني مواضع الصلوات "  وقال رجل من رواة الحسن {  صُلُوتٌ } وقال :   " هي كنائس اليهود تدعى* بالعبرانية  " صُلُوثا "  فهذا معنى الصلوات فيما فسروا "  . <br />
وقال {  وَلَوْلاَ دَفْعُ اللَّهِ النَّاسَ بَعْضَهُمْ بِبَعْضٍ } ( 40 ) لأَنَّ {  بَعْضَهُم } بدل من {  الناس } .
