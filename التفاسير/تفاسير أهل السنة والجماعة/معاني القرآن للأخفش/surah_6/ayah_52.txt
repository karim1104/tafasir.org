وقال {  فَتَطْرُدَهُمْ فَتَكُونَ مِنَ الظَّالِمِينَ } ( 52 ) فالأولى أن ينصب جواباً لقوله {  مَا عَلَيْكَ مِنْ حِسَابِهِم مِّن شَيْءٍ وَمَا مِنْ حِسَابِكَ عَلَيْهِمْ مِّن شَيْءٍ فَتَطْرُدَهُمْ } ( 52 ) والأخرى [ أنْ ] ينصب بقوله {  وَلاَ تَطْرُدِ الَّذِينَ يَدْعُونَ رَبَّهُمْ } ( 52 ) {  فَتَكُونَ مِنَ الظَّالِمِينَ } .
