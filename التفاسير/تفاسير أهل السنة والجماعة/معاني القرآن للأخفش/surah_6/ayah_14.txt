[ وقال ] {  أَغَيْرَ اللَّهِ أَتَّخِذُ وَلِيّاً فَاطِرِ السَّمَاوَاتِ وَالأَرْضِ } ( 14 ) على النعت .  وقال بعضهم {  فاطرُ } بالرفع على الابتداء أيْ :  هُوَ فاطرُ . <br />
وقال بعضهم {  وهو يُطْعِمُ ولا يَطْعَم } ( 14 ) وقال بعضهم {  ولا يُطْعَمُ } و{  يَطْعَمُ } هو الوجه ،  لأَنَّكَ إنَّما تقول :   " هُوَ يُطْعَمُ "  لمن يَطْعَمُ فتخبر أنَّهُ لا يأكل شيئا .  وإنّما تقرأ {  يُطْعَمُ } لاجتماع الناس عليها . <br />
وقال {  إِنِّي أُمِرْتُ أَنْ أَكُونَ أَوَّلَ مَنْ أَسْلَمَ وَلاَ تَكُونَنَّ } ( 14 ) أي :  وقيل لي :   " لاَ تَكُونَنَّ "  .  وصارت {  أُمِرْتُ } بَدَلاً من ذلك لأنه حين قال {  أُمِرْتُ } قد أخبر أنَّهُ قد قيل له .
