وقال {  فَيَسُبُّواْ اللَّهَ عَدُوّاً بِغَيْرِ عِلْمٍ } ( 108 ) ثقيلة مشددة و{  عَدْواً } خفيفة ،  والأصل من  " العُدْوانِ "  .  وقال بعضهم {  عَدُوّاً } بغير علم .  أي :  سبّوه في هذه الحال .  ولكن  " العَدُوّ "  جماعة كما قال {  فَإِنَّهُمْ عَدُوٌّ لِي } وكما قال {  لاَ تَتَّخِذُواْ عَدُوِّي وَعَدُوَّكُمْ أَوْلِيَاءَ } ونقرأ {  عَدْواً } لأنها أكثر في القراءة وأجود في المعنى لأنك تقول :  [ عُدا ] عَدْواً علينا "  مثل  " ضَرَبَهُ ضَرْباً "  .
