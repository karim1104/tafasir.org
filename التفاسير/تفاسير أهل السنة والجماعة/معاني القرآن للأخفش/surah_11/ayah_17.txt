وقال {  أَفَمَن كَانَ عَلَى بَيِّنَةٍ مِّن رَّبِّهِ وَيَتْلُوهُ شَاهِدٌ مِّنْهُ } ( 17 ) وأضمر الخبر . <br />
وقال {  وَمِن قَبْلِهِ كِتَابُ مُوسَى إِمَاماً وَرَحْمَةً } ( 17 ) على خبر المعرفة . <br />
وقال {  فَالنَّارُ مَوْعِدُهُ } ( 17 ) فجعل النار هي الموعد وإنما الموعد فيها كما تقول العرب  " الليلةُ الهِلالُ "  ومثلها ( إِنَّ مَوْعِدَهُمُ الصُّبْحُ ) ( 81 ) . <br />
وقال {  فَلاَ تَكُ فِي مِرْيَةٍ مِّنْهُ } ( 17 ) وقال بعضهم ( مُرْيَةٍ ) تكسر وتضم وهما لغتان .
