وقال {  وَامْرَأَتُهُ حَمَّالَةَ الْحَطَبِ } ( 4 ) [ 186 ب ] يقول :   " وَتَصْلَى امرأتُه حمالةِ الحَطَب "  و{  حمالةُ الحَطَبِ } من صفتها .  ونصب بعضهم {  حمّالةَ الحَطَب } على الذم ،  كأنه قال  " ذكرتُها حمالةَ الحطبِ "  ويجوز أن تكون {  حمالةَ الحطبِ } نكرة نوى بها التنوين ،  فتكون حالا  " امرأته "  ،  وتنتصب بقوله {  تَصْلى } .
