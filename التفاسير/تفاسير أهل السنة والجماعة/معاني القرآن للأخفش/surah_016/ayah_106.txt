[ 144 ب ] وقال {  مَن كَفَرَ بِاللَّهِ مِن بَعْدِ إيمَانِهِ إِلاَّ مَنْ أُكْرِهَ وَقَلْبُهُ مُطْمَئِنٌّ بِالإِيمَانِ ولكن مَّن شَرَحَ بِالْكُفْرِ صَدْراً فَعَلَيْهِمْ غَضَبٌ مِّنَ اللَّهِ } ( 106 ) خبر لقوله ( وَلَكِنْ مَنْ شَرَحَ ) ثم دخل معه قوله {  مَن كَفَرَ بِاللَّهِ مِن بَعْدِ إيمَانِهِ } فأخبر عنهم بخبر واحد إذ كان ذلك يدل على المعنى .
