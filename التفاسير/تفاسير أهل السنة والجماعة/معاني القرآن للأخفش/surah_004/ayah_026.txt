وقال {  يُرِيدُ اللَّهُ لِيُبَيِّنَ لَكُمْ وَيَهْدِيَكُمْ } ( 26 ) يقول :   " وَلِيَهْدِيَكُمْ } "  ومعناه :  يريد كذا وكذا ليبين لكم .  وان شئت أوصلت الفعل باللام إلى  " أن "  المضمرة بعد اللام نحو {  إِن كُنتُمْ لِلرُّؤْيَا تَعْبُرُونَ } وكما قال {  وَأُمِرْتُ لأََِعْدِلَ بَيْنَكُمُ } فكسر اللام أي :  أمرت من أجل ذلك .
