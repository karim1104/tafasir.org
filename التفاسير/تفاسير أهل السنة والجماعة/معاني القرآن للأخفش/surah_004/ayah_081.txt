قال {  وَيَقُولُونَ طَاعَةٌ فَإِذَا بَرَزُواْ مِنْ عِندِكَ بَيَّتَ طَآئِفَةٌ مِّنْهُمْ } ( 81 ) أي :  ويقولون  " أَمْرُنا طَاعَةٌ "  .  وان شئت نصبت الطاعة على  " نُطيعُ طاعةً "  .  وقال {  بَيَّتَ } فذكّر فعلَ الطائفة [ 98ب ] لأنهم في المعنى رجال وقد أضافها إلى مذكرين .  وقال {  وَإِن كَانَ طَآئِفَةٌ مَّنكُمْ } .
