[ وقال ]** {  فَإِنْ آنَسْتُمْ منْهُمْ رُشْداً } ( 6 ) وقال {  آنَسْتُمْ } ممدودة .  تقول :   " آنَسْتُ منهُ رُشْداً وخيراً "  و{  آنَسْتُ نَارا } مثلها ممدودة وتقول :   " أنِسْتُ بالرَّجُلِ "   " أُنْساً "  فألف  " أَنِسْتُ "  مقصورة وألف  " أُنْساً "  مضمومة* .  ويقال  " أنَسَا "  . <br />
وقال {  إِسْرَافاً وَبِدَاراً أَن يَكْبَرُواْ } ( 6 ) يقول لا تأكُلُوها مبادرةَ أَنْ يَشُبُّوا .
