وقال {  وَإِذَا عَلِمَ مِنْ آيَاتِنَا شَيْئاً } ( 9 ) ثم قال {  مِّن وَرَائِهِمْ جَهَنَّمُ وَلاَ يُغْنِي عَنْهُم مَّا كَسَبُواْ شَيْئاً } ( 10 ) فجمع لأنه قد قال {  وَيْلٌ لِّكُلِّ أَفَّاكٍ أَثِيمٍ } ( 7 ) فهو في معنى جماعة مثل الأشياء التي تجيء في لفظ واحد ومعناها معنى [ 170 ب ] جماعة وقد جعل {  الذي } بمنزلة {  من } وقال {  وَالَّذِي جَاءَ بِالصِّدْقِ وَصَدَّقَ بِهِ أُوْلَائِكَ هُمُ الْمُتَّقُونَ } ف " الذي "  في لفظ واحد .  ثم قال {  أُوْلَائِكَ هُمُ الْمُتَّقُونَ } .
