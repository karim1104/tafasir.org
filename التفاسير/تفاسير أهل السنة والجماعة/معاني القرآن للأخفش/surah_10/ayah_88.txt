وقال {  رَبَّنَا اطْمِسْ عَلَى أَمْوَالِهِمْ وَاشْدُدْ عَلَى قُلُوبِهِمْ فَلاَ يُؤْمِنُواْ } ( 88 ) فنصبها لأن جواب الدعاءَ بالفاء نصب وكذلك في الدعاء إذا عَصَوا . <br />
وقال {  رَبَّنَا لِيُضِلُّواْ عَن سَبِيلِكَ } ( 88 ) أيّ :  فَضلُّوا .  كما قال {  فَالْتَقَطَهُ آلُ فِرْعَوْنَ لِيَكُونَ لَهُمْ عَدُوّاً وَحَزَناً } أيْ :  فَكَان .  وَهمُ لم يلقطوه ليكون لهم عدوا وحزنا [ و ] إنما لقطوه فكان [ ف ] هذه اللام تجيء في هذا المعنى . <br />
وقوله :  {  فَلاَ يُؤْمِنُواْ } عطف على ( ليضلوّا ) .
