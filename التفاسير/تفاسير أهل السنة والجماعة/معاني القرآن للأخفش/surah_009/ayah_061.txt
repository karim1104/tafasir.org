وقال {  قُلْ أُذُنُ خَيْرٍ لَّكُمْ } ( 61 ) أي :  هُوَ أُذُنُ خَيْرٍ لا أُذُنُ شرٍّ .  وقال بعضهم ( أُذُنٌ خَيْرٌ لَكُمْ ) والأولى أحسنهما لأنك لو قلت  " هو أُذُنٌ خَيْرٌ لَكُم "  لم يكن في حسن ( هو أَذُنُ خَيْرٍ لَكُم ) وهذا جائز على أن تجعل ( لكم ) صفة  " الأُذُنْ "  . <br />
وقال {  يُؤْمِنُ بِاللَّهِ وَيُؤْمِنُ لِلْمُؤْمِنِينَ } ( 61 ) أي :  يُصدقهم كا تقول للرجل  " أَنَا ما يُؤمِنُ لي بأَنْ أَقُولَ كذا وكذا "  أي :  ما يصدقني . <br />
وقال {  وَرَحْمَةٌ لِّلَّذِينَ آمَنُواْ مِنكُمْ } ( 61 ) أي :  وهو رحمة .
