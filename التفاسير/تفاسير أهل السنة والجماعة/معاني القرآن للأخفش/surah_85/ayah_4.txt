موضع قسمها - و الله أعلم - على {  قُتِلَ أَصْحَابُ الأُخْدُودِ } ( 4 ) أضمر اللام كما قال {  وَالشَّمْسِ وَضُحَاهَا } {  قَدْ أَفْلَحَ مَن زَكَّاهَا } يريد إن شاء الله  " لَقَدْ أَفْلَحَ مَنْ زَكَّاهَا "  وألقى اللام .  وإن شئت على التقديم كأنه قال {  قُتِلَ أَصْحَابُ الأُخْدُودِ } ( 4 ) {  وَالسَّمَاءِ ذَاتِ الْبُرُوجِ } ( 1 ) وقال بعضهم {  إِنَّ بَطْشَ رَبِّكَ لَشَدِيدٌ } ( 12 ) .
