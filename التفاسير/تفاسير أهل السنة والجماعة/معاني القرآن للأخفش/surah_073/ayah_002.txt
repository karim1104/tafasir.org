وقوله {  قُمِ الْلَّيْلَ إِلاَّ قَلِيلاً } ( 2 ) {  نِّصْفَهُ أَوِ انقُصْ مِنْهُ قَلِيلاً } ( 3 ) {  أَوْ زِدْ عَلَيْهِ } ( 4 ) فقال السائل عن هذا :  قد قال {  قُمِ الْلَّيْلَ إِلاَّ قَلِيلاً } فكيف قال {  نِصْفَهُ } ؟  إنما المعنى  " أَوْ نِصْفَه أَو زِدْ عَلَيْهِ "  لأنَ ما يكون في معنى تكلم به العرب بغير :   " أو "  تقول :   " أَعْطِهِ دِرْهَماً دِرْهَمَيْنِ ثلاثةً "  تريد :   " أَوْ دِرْهَمَيْنِ أَوْ ثَلاثَةً "  .
