وقوله {  وَلاَ جُنُباً } ( 43 ) في اللفظ [ 97ء ] واحد وهو للجمع كذلك ،  وكذلك هو للرجال والنساء ،  كما قال {  وَالْمَلاَئِكَةُ بَعْدَ ذَلِكَ ظَهِيرٌ } فجعل  " الظَهيرَ "  واحدا .  والعرب تقول :   " هُمْ لِي صَدِيقٌ "  .  وقال :  {  عَنِ الْيَمِينِ وَعَنِ الشِّمَالِ قَعِيدٌ } وهما قعيدان .  وقال {  إِنَّا رَسُولُ رَبِّك } وقال {  فَإِنَّهُمْ عَدُوٌّ لِي } لأنَ  " فَعُول "  و " فَعِيل "  مما يجعل واحدا للاثنين والجمع . <br />
وقال {  وَلاَ جُنُباً إِلاَّ عَابِرِي سَبِيلٍ } ( 43 ) لأنه قال {  لاَ تَقْرَبُواْ الصَّلاَةَ وَأَنْتُمْ سُكَارَى } ( 43 ) فقوله {  وأَنْتُمْ سُكَارَى } في موضع نصب على الحال ،  فقال {  وَلاَ جُنُباً } على العطف كأنه قال :   " وَلا تَقْرَبُوها جُنْباً إِلاّ عابِري سَبِيلٍ "  كما تقول :   " لا تَأْتِي إِلاّ رَاكِباً "  .
