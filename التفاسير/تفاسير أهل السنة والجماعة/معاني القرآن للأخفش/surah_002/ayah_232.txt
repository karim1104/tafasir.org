وقال {  فَلاَ تَعْضُلُوهُنَّ } ( 232 ) ينهى أزواجهن أن يَمْنَعُوهن من الأزواج . <br />
وقال {  ذلك يُوعَظُ بِهِ } ( 232 ) و{  ذالِكُمْ [ 77ء ] أَزْكَى لَكُمْ وَأَطْهَرُ } ( 232 ) لأنه خاطب رجالا ،  وقال في موضع آخر  " ذلِكُنَّ الذي لُمْتُنَّني فيه "  لأنه خاطب نساء ،  ولو ترك  " ذلك  "  ولم يلحق فيها أسماء الذين خاطب كان جائزا .  وقال {  مَن يَأْتِ مِنكُنَّ بِفَاحِشَةٍ مُّبَيِّنَةٍ يُضَاعَفْ لَهَا الْعَذَابُ ضِعْفَيْنِ وَكَانَ ذَلِكَ عَلَى اللَّهِ يَسِيراً } ولم يقل {  ذَلِكُنَّ } وقال {  فَاسْتَبْشِرُواْ بِبَيْعِكُمُ الَّذِي بَايَعْتُمْ بِهِ وَذَلِكَ هُوَ الْفَوْزُ الْعَظِيمُ } .  وقال في المجادلة {  ذَلِكَ خَيْرٌ لَّكُمْ وَأَطْهَرُ } وليس بأبعد من قوله {  حَتَّى إِذَا كُنتُمْ فِي الْفُلْكِ وَجَرَيْنَ بِهِم } فخاطب ثم حدّث عن غائب لان الغائب هو الشاهد في ذا المكان .  وقال {  هَلْ أُنَبِّئُكُمْ بِشَرٍّ مِّن ذلك مَثُوبَةً } .
