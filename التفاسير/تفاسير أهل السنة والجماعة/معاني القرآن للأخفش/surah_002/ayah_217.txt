وقال :  {  وَصَدٌّ عَن سَبِيلِ اللَّهِ } ( 217 ) . <br />
وقال :  {  وَكُفْرٌ بِهِ وَالْمَسْجِدِ الْحَرَامِ } ( 217 ) على  " وَصدٌّ عن المَسْجِدِ الحرامِ "  . <br />
ثم قال :  {  وَإِخْرَاجُ أَهْلِهِ مِنْهُ أَكْبَرُ } ( 217 ) على الابتداء .  وقال :  {  وَمَن يَرْتَدِدْ مِنكُمْ عَن دِينِهِ فَيَمُتْ وَهْوَ كَافِرٌ فَأُوْلئِكَ حَبِطَتْ أَعْمَالُهُمْ } ( 217 ) فضعَّف لأن أهل الحجاز إذا كانت لام الفعل ساكنة ضعفوا وهي ها هنا ساكنة أسكنها بالجزاء .  [ 74ب ] وقال :  {  وَمَنْ يَرْتَدَّ مِنْكُمْ عَنْ دِينِهِ فَسَوْفَ } فلم يضاعف في لغة من لا يضاعف لأن من لا يضاعف كثير .
