وقال {  وَإِن كَانَ ذُو عُسْرَةٍ فَنَظِرَةٌ إِلَى مَيْسَرَةٍ } ( 280 ) يقول :   " وانْ كانَ مِمَّن تُقاضُونَ ذو عسرة فعليكم أن تنظروا إلى الميسرة "  وقال بعضهم {  فَنَظْرَة } وان شئت لم تجعل ل " كان "  خبرا مضمرا وجعلت  " كانَ "  بمنزلة :   " وَقَعَ "  وقال بعضهم {  مَيْسُرِه } وليست بجائزة لأنه ليس في الكلام  " مَفْعُلٌ "  .  ولو قرأها {  مُوسَرِه } جاز لأنه من  " أيْسَرَ "  مثل :   " أدْخَلَ "  ف " هُو مُدْخَل "  .  وقال بعضهم {  فَناظِرْهُ إلى مَيْسَرَةٍ } و{  مَيْسَرَةٍ } فجعلها  " فاعِلْ "  [ 81ء ] مِنْ  " نَاظَرَ "  وجزمها للأمر . <br />
وقال {  وَأَن تَصَدَّقُواْ خَيْرٌ لَّكُمْ } ( 280 ) يقول :   " الصّدَقَةُ خَيْرٌ لَكُمْ "  .  جعل {  أَنْ تَصَدَّقُواْ } اسما مبتدأ وجعل {  خَيْرٌ لَّكُمْ } خبر المبتدأ .
