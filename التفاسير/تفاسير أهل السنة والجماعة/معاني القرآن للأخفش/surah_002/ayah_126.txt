وقال  : {  وَارْزُقْ أَهْلَهُ مِنَ الثَّمَرَاتِ مَنْ آمَنَ مِنْهُمْ } ( 126 ) ف{  مَنْ آمَنَ } بدل على التبيان كما تقول :   " أَخَذْتُ المالَ نِصْفَهُ "  و " رأيتُ القومَ ناساً مِنْهُم "  .  ومثل ذلك {  يسألونك عَنِ الشَّهْرِ الْحَرَامِ قِتَالٍ فِيهِ } يريد :  عنْ قِتالٍ فيه .  وجعله بدلا .  ومثله [ 64ب ] {  وَللَّهِ عَلَى النَّاسِ حِجُّ الْبَيْتِ مَنِ اسْتَطَاعَ إِلَيْهِ سَبِيلاً } ومثله {  قَالَ الْمَلأُ الَّذِينَ اسْتَكْبَرُواْ مِن قَوْمِهِ لِلَّذِينَ اسْتُضْعِفُواْ لِمَنْ آمَنَ مِنْهُمْ } شبيه هذا أيضا إلاّ أنه قدر فيه حرف الجرّ . <br />
وقال  :  {  وَمَن كَفَرَ فَأُمَتِّعُهُ قَلِيلاً } ( 126 )على الأمر {  ثُمَّ أَضْطَرُّهُ } ( 126 ) فجزم {  فَأَمْتِعْهُ } على الأمر وجعل الفاء جواب المجازاة .  وقال بعضهم {  فَأُمَتِّعُهُ } وبها نقرأ رفع على الخبر وجواب المجازاة الفاء .
