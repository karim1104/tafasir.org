وقال {  إِنَّهُ عَمَلٌ غَيْرُ صَالِحٍ } ( 46 ) منوّن لأنه حين قال - و الله اعلم - {  لاَ تَسْأَلْنِي مَا لَيْسَ لَكَ بِهِ عِلْمٌ } ( 46 ) كان في [ 134 ب ] معنى  " أَنْ تَسْأَلِني "  فقال {  إِنَّهُ عَمَلٌ غَيْرُ صَالِحٍ فَلاَ تَسْأَلْنِي مَا لَيْسَ لَكَ بِهِ عِلْمٌ } وقال بعضهم ( عَمِلَ غَيْرَ صالِحٍ ) وبه نقرأ .
