وقال {  وَغِيضَ الْمَاءُ } ( 44 ) لأنك تقول  " غِضْتُهُ "  ف " أَنَا أَغِيضُهُ "  وتقول :   " غَاضَتْهُ الأَرْحَامُ "  ف " هِيَ تَغِيضُه "  وقال {  وَمَا تَغِيضُ الأَرْحَامُ } .  وأما ( الجُودِيُّ ) ( 44 ) فثقل لأنها ياء النسبة فكأنه أضيف إلى  " الجُود "  كقولك :   " البَصْرِيّ "  و " الكُوفِيّ "  .
