قال {  وَالنَّازِعَاتِ غَرْقاً } ( 1 ) فأقسم - و الله أعلم - على {  إِنَّ فِي ذَلِكَ لَعِبْرَةً لِّمَن يَخْشَى } ( 26 ) وان شئت جعلته على {  يَوْمَ تَرْجُفُ الرَّاجِفَةُ } ( 6 ) {  قُلُوبٌ يَوْمَئِذٍ وَاجِفَةٌ } ( 8 ) {  وَالنَّازِعَاتِ } .  وإن شئت جعلته على {  وَالنَّازِعَاتِ } ل{  يَوْمَ تَرْجُفُ الرَّاجِفَةُ } {  تَتْبَعُهَا الرَّادِفَةُ } ( 7 ) فحذفت اللام وهو كما قال جل ذكره وشاء أن يكون في هذا وفي كل الأمور .
