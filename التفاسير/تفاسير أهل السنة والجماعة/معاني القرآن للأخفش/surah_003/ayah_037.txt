وقال تعالى {  فَتَقَبَّلَهَا رَبُّهَا بِقَبُولٍ حَسَنٍ وَأَنبَتَهَا نَبَاتاً حَسَناً وَكَفَّلَهَا زَكَرِيَّا } ( 37 ) وقال بعضهم {  وَكَفَلَها زكرياء } و{  كَفِلَها } أيضا {  زَكَريّا } وبه نقرأُ وهما لُغَتَانِ .  وقال بعضهم {  وَكَفِلَها زَكَرياء } بكسر الفاء .  ومن قال :   " كَفَلَ "  قال  " يَكْفُلُ "  ومن قال  " كَفِلَ "  [ قال ]  " يَكْفَلُ "  .  وأما  " كَفُلَ "  فلم أسمعها وقد ذكرت . <br />
وقال تعالى {  يَرْزُقُ مَن يَشَاءُ بِغَيْرِ حِسَابٍ } ( 37 ) فهذا مثل كلام العرب  " يأكُلُ بِغَيْرِ حسابٍ "  أي :  لا يَتَعصَّبُ عَلَيْه ولا يُضَيِّقُ عَلَيْهِ .  و{  سَرِيعُ الْحِسَابِ } و{  أَسْرَعُ الْحَاسِبِينَ } يقول :   " ليس في حسابه فكر ولا روية ولا تذّكر "  .
