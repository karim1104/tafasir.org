وقال تعالى {  وَلَئِنْ قُتِلْتُمْ فِي سَبِيلِ اللَّهِ أَوْ مُتُّمْ } ( 157 ) الآية .  فان قيل كيف يكون {  لَمَغْفِرَةٌ مِّنَ اللَّهِ } ( 157 ) جواب ذلك الأول ؟  فكأنه حين قال {  وَلَئِنْ قُتِلْتُمْ فِي سَبِيلِ اللَّهِ أَوْ مُتُّمْ } تذكر لهم مغفرة ورحمة إذ كان ذلك في السبيل فقال {  لَمَغْفِرَةٌ } يقول :   " لَتِلْكَ المغفرة {  خَيْرٌ مِمّا تَجْمَعُونَ } "  .
