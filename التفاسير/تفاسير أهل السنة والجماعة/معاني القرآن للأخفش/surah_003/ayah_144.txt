وقال تعالى {  أَفإِنْ مَّاتَ أَوْ قُتِلَ انْقَلَبْتُمْ } ( 144 ) ولم يقل {  انْقَلَبْتُمْ } فيقطع الألف لأنه جواب المجازاة الذي وقعت عليه {  إِنْ } وحرف الاستفهام قد وقع على {  إِنْ } فلا يحتاج خبره إلى الاستفهام لأن خبرها مثل خبر الابتداء .  ألا ترى انك تقول :   " أأَزَيْدٌ حَسَنٌ "  ولا تقول :   " أَزَيْدٌ أَحَسَنٌ "  وقال الله تعالى {  أَفَإِنْ مِّتَّ* فَهُمُ الْخَالِدُونَ } ولم يقل  " أََفهُمُ اْلْخالِدوُنَ "  لأنه جواب المجازاة .
