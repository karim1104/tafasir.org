قال الله تعالى {  لَمَا آتَيْتُكُم مِّن كِتَابٍ وَحِكْمَةٍ ثُمَّ جَاءَكُمْ رَسُولٌ مُّصَدِّقٌ لِّمَا مَعَكُمْ لَتُؤْمِنُنَّ بِهِ } ( 81 ) فاللام التي مع  " ما "  في أول الكلام هي لام الابتداء نحو  " لزَيدٌ أَفضَلُ مِنكَ "  ،  لأن {  مَا آتَيْتُكُمُ } اسم والذي بعده صلة .  واللام التي في {  لَتُؤْمِنُنَّ بِهِ وَلَتَنصُرُنَّهُ } لام القسم كأنه قال  " واللّهِ لَتُؤمِنُنَّ بِهِ "  فوكد في أول الكلام وفي آخره ،  كما تقول :   " أَمَا واللّهِ أَنْ لَوْ جِئْتَني لَكان كذا وكذا "  ،  وقد يستغنى عنها .  ووكّد في {  لَتُؤْمِنُنَّ } باللام في آخر الكلام وقد يستغنى عنها .  جعل خبر {  مَا آتَيْتُكُمْ مِّن كِتَابٍ وَحِكْمَةٍ } {  لَتُؤْمِنُنَّ بِهِ } مثل  " ما لِعَبْدِ الله ؟  واللّهِ لَتْأتِيَنَّه "  .  وان شئت جعلت خبر ( ما ) {  مِنْ كِتابٍ } تريد {  لَما آتَيْتُكُمْ كتابٌ وحِكْمَةٌ } وتكون  " مِنْ "  زائدة .
