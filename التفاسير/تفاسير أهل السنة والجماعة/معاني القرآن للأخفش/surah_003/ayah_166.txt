قال تعالى {  وَمَا أَصَابَكُمْ يَوْمَ الْتَقَى الْجَمْعَانِ فَبِإِذْنِ اللَّهِ } ( 166 ) فجعل الخبر بالفاء لأَنَّ {  ما } بمنزلة  " الذي "  وهو في معنى  " مَنْ "  ،  و " مَنْ "  تكون في المجازاة ويكون جوابها بالفاء . <br />
وقال {  فَبِإِذْنِ اللَّهِ وَلِيَعْلَمَ الْمُؤْمِنِينَ } ( 166 ) فجعل الخبر بالفاء لأنّ {  مَا أَصَابَكُمْ } :  الذي أصابكم .  وقال {  وَلِيَعْلَمَ الْمُؤْمِنِينَ } لأنَّ معناه :   " فَهُوَ بإِذن اللّهِ "   " وَهُوَ لِيَعْلَم "  .
