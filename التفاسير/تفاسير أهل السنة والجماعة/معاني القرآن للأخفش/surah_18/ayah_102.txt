وقال {  أَفَحَسِبَ الَّذِينَ كَفَرُواْ أَن يَتَّخِذُواْ عِبَادِي } ( 102 ) فجعلها {  أَنْ } التي تعمل في الأفعال فاستغنى بها  " حَسِبُوا "  كما قال {  إِن ظَنَّا أَن يُقِيمَا } و{  مَا أَظُنُّ أَن تَبِيدَ هَذِهِ } استغنى ها هنا بمفعول واحد لأن معنى {  مَا أَظُنُّ أَن تَبِيدَ } :  ما أظنها أَنْ تبيدَ . <br />
وقال بعضهم {  أَفَحَسْبُ الَّذِينَ كَفَرُواْ أَن يَتَّخِذُواْ عِبَادِي } ( 102 ) يقول :   " أَفَحَسْبُهُم ذلك  "  .
