وقال {  حَمَلَتْ حَمْلاً خَفِيفاً } ( 189 ) لأَنّ  " الحَمْلَ "  ما كان في الجَوْفِ و " الحِمْل "  ما كان على الظهر .  وقال {  وَتَضَعُ كُلُّ ذَاتِ حَمْلٍ حَمْلَهَا } وأما قوله {  أَثْقَلَتْ } ( 189 ) فيقول :   " صارت ذاتَ ثِقَلٍ "  كما تقول  " أَتْمَرْنا "  أيْ :   " صِرْنا ذَوِي تَمْرٍ "  و " أَلْبَنَّا "  [ أي :  صرنا ذوي لبن ] و " أَعْشَبَتِ الأَرْضُ "  و " أَكْمَأَتْ "  وقرأ بعضهم {  فَلَمّا أُثْقِلَتْ } .
