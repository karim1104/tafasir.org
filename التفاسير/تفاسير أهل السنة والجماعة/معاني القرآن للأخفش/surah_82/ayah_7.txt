قال {  فَعَدَلَكَ } ( 7 ) أي :  كذا خلقك ،  وبعضهم يخففها فمن ثقل {  عَدَّلَك } فإنما يقول  " عَدَّلَ خَلْقَكَ "  و " عَدَلَكَ "  أي :  عدل بعضك ببعضك فجعلك مستويا معتدلا وهو في معنى  " عدّلك "  . <br />
وقال {  خَلَقَكَ } ( 7 ) و{  رَكَّبَكَ } ( 8 ) {  كَلاَّ } ( 9 ) وإن شئت قلت {  خَلَقَك } و{  رَكَّبَكْ } {  كَلاَّ } فأدغمت لأنهما حرفان مثلان .  والمثلان يدغم أحدهما في صاحبه وإن شئت إذا تحركا جميعا أن تسكن الأول وتحرّك الآخر .  وإذا سكن الأول لم يكن الإدغام وإن تحرك الأول وسكن الآخر لم يكن الإدغام .
