{  فَسَيَقُولُونَ } حين تقيم عليهم الحجة في البعث :  {  مَنْ يُعِيدُنَا قُلِ الَّذِي فَطَرَكُمْ أَوَّلَ مَرَّةٍ } فكما فطركم ولم تكونوا شيئا مذكورا فإنه سيعيدكم خلقا جديدا {  كَمَا بَدَأْنَا أَوَّلَ خَلْقٍ نُعِيدُهُ } {  فَسَيُنْغِضُونَ إِلَيْكَ رُءُوسَهُمْ } أي :  يهزونها إنكارا وتعجبا مما قلت ،  {  وَيَقُولُونَ مَتَى هُوَ } أي :  متى وقت البعث الذي تزعمه على قولك ؟  لا إقرار منهم لأصل البعث بل ذلك سفه منهم وتعجيز .  {  قُلْ عَسَى أَنْ يَكُونَ قَرِيبًا } فليس في تعيين وقته فائدة ،  وإنما الفائدة والمدار على تقريره والإقرار به وإثباته وإلا فكل ما هو آت فإنه قريب . <br />
