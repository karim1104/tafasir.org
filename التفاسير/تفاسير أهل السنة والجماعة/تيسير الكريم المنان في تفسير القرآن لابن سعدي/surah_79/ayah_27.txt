{  27 - 33 } {  أَأَنْتُمْ أَشَدُّ خَلْقًا أَمِ السَّمَاءُ بَنَاهَا * رَفَعَ سَمْكَهَا فَسَوَّاهَا * وَأَغْطَشَ لَيْلَهَا وَأَخْرَجَ ضُحَاهَا * وَالْأَرْضَ بَعْدَ ذَلِكَ دَحَاهَا * أَخْرَجَ مِنْهَا مَاءَهَا وَمَرْعَاهَا * وَالْجِبَالَ أَرْسَاهَا * مَتَاعًا لَكُمْ وَلِأَنْعَامِكُمْ }<br />
يقول تعالى مبينا دليلا واضحا لمنكري البعث ومستبعدي إعادة الله للأجساد :  {  أَأَنْتُمْ } أيها البشر {  أَشَدُّ خَلْقًا أَمِ السَّمَاءُ } ذات الجرم العظيم ،  والخلق القوي ،  والارتفاع الباهر {  بَنَاهَا } الله .
