قوله تعالى : { إنا نحن نحيي ونميت وإلينا المصير } .  <br />
قد ذكرنا في سورة يس ما يتعلق بقوله : { إنا نحن } ،   وأما قوله : { نحيي ونميت } فالمراد من الإحياء الإحياء أولا { ونميت } إشارة إلى الموتة الأولى وقوله : { وإلينا } بيان للحشر فقدم { إنا نحن } لتعريف عظمته يقول القائل أنا أنا أي مشهور و{ نحيي ونميت } أمور مؤكدة معنى العظمة { وإلينا المصير } بيان للمقصود .  <br />
