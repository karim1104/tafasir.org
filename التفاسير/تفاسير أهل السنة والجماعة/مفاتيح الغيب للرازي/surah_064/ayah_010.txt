وقوله : { والذين كفروا } أي بوحدانية الله تعالى وبقدرته { وكذبوا بآياتنا } أي بآياته الدالة على البعث { أولئك أصحاب النار خالدين فيها وبئس المصير } ثم في الآية مباحث :<br />
الأول : قال : { فآمنوا بالله رسوله } بطريق الإضافة ،   ولم يقل : ونوره الذي أنزلنا بطريق الإضافة مع أن النور هاهنا هو القرآن والقرآن كلامه ومضاف إليه ؟ نقول : الألف واللام في النور بمعنى الإضافة كأنه قال : ورسوله ونوره الذي أنزلنا .  <br />
الثاني : بم انتصب الظرف ؟ نقول : قال الزجاج : بقوله : { لتبعثن } وفي الكشاف بقوله : { لتنبؤن } أو بخبير لما فيه من معنى الوعيد .   كأنه قيل : والله معاقبكم يوم يجمعكم أو بإضمار اذكر .  <br />
الثالث : قال تعالى في الإيمان : { ومن يؤمن بالله } بلفظ المستقبل ،   وفي الكفر وقال : { والذين كفروا } بلفظ الماضي ،   فنقول : تقدير الكلام : ومن يؤمن بالله من الذين كفروا وكذبوا بآياتنا يدخله جنات ومن لم يؤمن منهم أولئك أصحاب النار .  <br />
الرابع : قال تعالى : { ومن يؤمن } بلفظ الواحد و { خالدين فيها } بلفظ الجمع ،   نقول : ذلك بحسب اللفظ ،   وهذا بحسب المعنى .  <br />
الخامس : ما الحكمة في قوله : { وبئس المصير } بعد قوله : { خالدين فيها } وذلك بئس المصير فنقول : ذلك وإن كان في معناه فلا يدل عليه بطريق التصريح فالتصريح مما يؤكده .  <br />
