ثم ذكر تعالى ما به يتكامل هذا الوعيد فقال : { يوم يبعثهم الله جميعا فينبئهم بما عملوا أحصاه الله ونسوه والله على كل شيء شهيد } .  <br />
{ يوم } منصوب ينبئهم أو بمهين أو بإضمار اذكر ،   تعظيما لليوم ،   وفي قوله : { جميعا } قولان : ( أحدهما ) كلهم لا يترك منهم أحد غير مبعوث ( والثاني ) مجتمعين في حال واحدة ،   ثم قال : { فينبئهم بما عملوا } تجليلا لهم ،   وتوبيخا وتشهيرا لحالهم ،   الذي يتمنون عنده المسارعة بهم إلى النار ،   لما يلحقهم من الخزي على رؤوس الإشهاد وقوله : { أحصاه الله } أي أحاط بجميع أحوال تلك الأعمال من الكمية والكيفية ،   والزمان والمكان لأنه تعالى عالم بالجزئيات ،   ثم قال : { ونسوه } لأنهم استحقروها وتهاونوا بها فلا جرم نسوها : { والله على كل شيء شهيد } أي مشاهد لا يخفى عليه شيء البتة .  <br />
