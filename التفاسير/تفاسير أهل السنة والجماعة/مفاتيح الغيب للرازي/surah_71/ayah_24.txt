قال : { وقد أضلوا كثيرا } فيه وجهان : ( الأول ) أولئك الرؤساء ( قد أضلوا كثرا ) قبل هؤلاء الموصين بعبادة الأصنام وليس هذا أول مرة اشتغلوا بالإضلال ( الثاني ) يجوز أن يكون الضمير عائدا إلى الأصنام ،   كقوله : { إنهن أضللن كثيرا من الناس } وأجرى الأصنام على هذا القول مجرى الآدميين كقوله : { ألهم أرجل } .  <br />
وأما قوله تعالى : { ولا تزد الظالمين إلا ضلالا } ففيه سؤالان :<br />
الأول : كيف موقع قوله : { ولا تزد الظالمين } ؟ ( الجواب ) كأن نوحا عليه السلام لما أطنب في تعديد أفعالهم المنكرة وأقوالهم القبيحة امتلأ قلبه غيظا وغضبا عليهم فختم كلامه بأن دعا عليهم .  <br />
السؤال الثاني : إنما بعث ليصرفهم عن الضلال فكيف يليق به أن يدعو الله في أن يزيد في ضلالهم ؟ ( الجواب ) من وجهين : ( الأول ) لعله ليس المراد الضلال في أمر الدين ،   بل الضلال في أمر دنياهم ،   وفي ترويج مكرهم وحيلهم ( الثاني ) الضلال العذاب لقوله : { إن المجرمين في ضلال وسعر } .  <br />
