قوله تعالى : { سيهديهم ويصلح بالهم } .  <br />
إن قرئ { قتلوا } أو { قاتلوا } فالهداية محمولة على الآجلة والعاجلة ،   وإن قرئ { قتلوا } فهو الآخرة { سيهديهم } طريق الجنة من غير وقفة من قبورهم إلى موضع حبورهم .  <br />
وقوله : { ويصلح بالهم } .  <br />
قد تقدم تفسيره في قوله تعالى : { أصلح بالهم } والماضي والمستقبل راجع إلى أن هناك وعدهم ما وعدهم بسبب الإيمان والعمل الصالح ،   وذلك كان واقعا منهم فأخبر عن الجزاء بصيغة تدل على الوقوع ،   وهاهنا وعدهم بسبب القتال والقتل ،   فكان في اللفظ ما يدل على الاستقبال ،   لأن قوله تعالى : { فإذا لقيتم } يدل على الاستقبال فقال : { ويصلح بالهم } .  <br />
