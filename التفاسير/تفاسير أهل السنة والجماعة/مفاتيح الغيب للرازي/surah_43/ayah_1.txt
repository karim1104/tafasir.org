بسم الله الرحمن الرحيم<br />
{ حم * والكتاب المبين * إنا جعلناه قرآنا عربيا لعلكم تعقلون * وإنه في أم الكتاب لدينا لعلي حكيم * أفنضرب عنكم الذكر صفحا أن كنتم قوما مسرفين * وكم أرسلنا من نبي في الأولين * وما يأتيهم من نبي إلا كانوا به يستهزئون * فأهلكنا أشد منهم بطشا ومضى مثل الأولين } .  <br />
اعلم أن قوله { حم * والكتاب المبين } يحتمل وجهين ( الأول ) أن يكون التقدير هذه { حم والكتاب المبين } فيكون القسم واقعا على أن هذه السورة هي سورة { حم } ويكون قوله { إنا جعلناه قرءانا عربيا } ابتداء لكلام آخر ( الثاني ) أن يكون التقدير هذه { حم } .  <br />
