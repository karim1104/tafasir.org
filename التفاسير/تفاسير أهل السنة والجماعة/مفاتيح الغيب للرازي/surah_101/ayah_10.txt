ثم قال تعالى : { وما أدراك ما هيه } قال صاحب الكشاف : ( هيه ) ضمير الداهية التي دل عليها قوله : { فأمه هاوية } في التفسير ( الثالث ) : أو ضمير ( هاوية ) : والهاء للسكت فإذا وصل جاز حذفها والاختيار الوقف بالهاء لاتباع المصحف والهاء ثابتة فيه ،   وذكرنا الكلام في هذه الهاء عند قوله : { لم يتسنه } { فبهداهم اقتده } { ما أغنى عني ماليه } .  <br />
