وإنما قال : { فألقه إليهم } على لفظ الجمع لأنه قال : { وجدتها وقومها يسجدون للشمس } فقال : { فألقه إليهم } أي إلى الذين هذا دينهم .  <br />
أما قوله : { ثم تول عنهم } أي تنح عنهم إلى مكان قريب تتوارى فيه ليكون ما يقولونه بمسمع منك و{ يرجعون } من قوله تعالى : { يرجع بعضهم إلى بعض القول } ويقال دخل عليها من كوة وألقى إليها الكتاب وتوارى في الكوة .  <br />
