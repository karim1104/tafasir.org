ثم لما بين الرسالة والتوحيد بين الحشر بقوله تعالى : { ويقولون متى هذا الفتح إن كنتم صادقين } إلى آخر السورة ،   فصار ترتيب آخر السورة كترتيب أولها حيث ذكر الرسالة في أولها بقوله : { لتنذر قوما } وفي آخرها بقوله : { ولقد آتينا موسى الكتاب } وذكر التوحيد بقوله : { الذي خلق السماوات والأرض } وقوله : { الذي أحسن كل شيء خلقه وبدأ خلق الإنسان من طين } وفي آخر السورة ذكره بقوله : { أو لم يهد لهم } وقوله : { أو لم يروا أنا نسوق } وذكر الحشر في أولها بقوله : { وقالوا أئذا ضللنا في الأرض } وفي آخرها بقوله : { ويقولون متى هذا الفتح } .  <br />
