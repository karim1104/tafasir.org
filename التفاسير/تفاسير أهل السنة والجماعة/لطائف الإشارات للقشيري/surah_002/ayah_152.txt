الذكر استغراق الذاكر في شهود المذكور ،   ثم استهلاكه في وجود المذكور ،   حتى لا يبقى منك أثر يذكر ،   فيقال قد كان مرةً فلان .  <br />
{ فاذكروني أذكركم } أي كونوا مستهلكين في وجودنا ،   نذكركم بعد فنائكم عنكم ،   قال الله تعالى : { إنَّهُمْ كَانُوا قَبْلَ ذَلِكَ مُحْسِنِينَ } [ الذاريات : 16 ] كانوا وقتاً ولكنهم بانوا دائماً :<br />
أناس حديث حسن *** فكن حديثاً حسناً لمن وعنى<br />
وطريقة أهل العبارة { فاذكروني } بالموافقات { أذكركم } بالكرامات ،   وطريقة أهل الإشارة { فاذكروني } بِتَرْكِ كل حظ { أذكركم } بأن أقيمكم بحقي بعد فنائكم عنكم .  <br />
{ فاذكروني } مكتفين بي عن عطائي وأفضالي { أذكركم } راضياً بكم دون أفعالكم .  <br />
{ فاذكروني } بذكري لكم ما تذكرون ،   ولولا سابق ذكري لما كان لاحِقُ ذكركم .  <br />
{ فاذكروني } بقطع العلائق { أذكركم } بنعوت الحقائق .  <br />
ويقال اذكرني لكل مَنْ لَقِيتَه أذكرك لمن خاطَبتُه ،    "  فمن ذكرني في مَلأٍ ذكرته في ملأ خيرٍ منهم  "  .  <br />
ويقال { واشكروني } على عظيم المِنَّةِ عليكم بأن قُلْتُ : { فَاذْكُرُونِي أَذْكُرْكُمْ } .  <br />
ويقال الشكر من قبيل الذكر ،   وقوله : { ولا تكفرون } النهي عن الكفران أمرٌ بالشكر ،   والشكر ذكر ،   فكرر عليك الأمر بالذكر ،   والثلاث أول حدِّ الكثرة ،   والأمر بالذكر الكثير أمر بالمحبة لأنَّ في الخبر :  "  من أحب شيئاً أكثر ذكره  "  فهذا - في الحقيقة - أمرٌ بالمحبة أي أحْبِبْني أحبك ؛ { فاذكروني أذكركم } أي أحبوني أحببكم .  <br />
ويقال : { فاذكروني } بالتذلل { أذكركم } بالتفضُّل .  <br />
{ فاذكروني } بالانكسار { أذكركم } بالمبار .  <br />
{ فاذكروني } باللسان { أذكركم } بالجِنان .  <br />
{ فاذكروني } بقلوبكم { أذكركم } بتحقيق مطلوبكم .  <br />
{ فاذكروني } على الباب من حيث الخدمة { أذكركم } بالإيجاب على بساط القربة بإكمال النعمة .  <br />
{ فاذكروني } بتصفية السِّر { أذكركم } بتوفية البرِّ .  <br />
{ فاذكروني } بالجهد والعناء { أذكركم } بالجود والعطاء .  <br />
{ فاذكروني } بوصف السلامة { أذكركم } يومَ القيامة يومَ لا تنفع الندامة .  <br />
{ فاذكروني } بالرهبة { أذكركم } بتحقيق الرغبة .
