قوله جل ذكره : { يَا أَيُّهَا النَّاسُ اتَّقُوا رَبَّكُمْ وَاخْشَوْا يَوْمًا لَا يَجْزِي وَالِدٌ عَنْ وَلَدِهِ وَلَا مَوْلُودٌ هُوَ جَازٍ عَنْ وَالِدِهِ شَيْئًا إِنَّ وَعْدَ اللَّهِ حَقٌّ فَلَا تَغُرَّنَّكُمُ الْحَيَاةُ الدُّنْيَا وَلَا يَغُرَّنَّكُمْ بِاللَّهِ الْغَرُورُ } .  <br />
يخوِّفهم مرةً بأفعاله فيقول :{ وَاتَّقُواْ يَوْماً } [ البقرة : 48 ] ،   ومرةً بصفاته فيقول : { أَلَمْ يَعْلَم بِأَنَّ اللَّهَ يَرَى } [ العلق : 14 ] ومرةً بذاته فيقول : { وَيُحَذِّرُكُمُ اللَّهُ نَفْسَهُ } [ آل عمران : 28 ] .
