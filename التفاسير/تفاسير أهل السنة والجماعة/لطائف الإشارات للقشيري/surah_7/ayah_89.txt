نطقوا عن صحة عزائمهم حيث قالوا : { قَدِ افْتَرَيْنَا عَلَى اللهِ كَذِباً إِنْ عُدْنَا فِى مِلَّتِكُم } ،   ثم أقروا بالشكر حيث قالوا : { بَعْدَ إِذْ نَجَّانَا اللهُ مِنْهَا } ،   ثم تبرأوا عن حولهم وقوتهم حيث قالوا : { وَمَا يَكُونُ لَنَا أَن نَّعُودَ فِيهَا إِلاَّ أَن يَشَاءَ اللهُ رَبُّنَا } يعني إِنْ يُلْبِسنا لِباسَ الخذلان نُرَدُّ إلى الصغر والهوان .  <br />
ثم اشتاقوا إلى جميل التوكل فقالوا : { عَلَى اللهِ تَوَكَّلْنَا } أي به وَثِقْنَا ،   ومنه الخيرَ أَمَّلْنا .  <br />
ثم فوضوا أمورهم إلى الله فقالوا : { رَبَّنَا افْتَحْ بَيْنَنَا وَبَيْنَ قَوْمِنَا بِالحَقِّ } فتداركهم الحقُّ - سبحانه - عند ذلك بجميل العصْمة وحسن الكفاية .  <br />
