قوله جل ذكره : { إِنَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ لَهُمْ أَجْرٌ غَيْرُ مَمْنُونٍ } .  <br />
{ آمِناً } : شاهدوا ،   { وَعَمِلُواْ الصَّالِحَاتِ } : لازموا بِساط العبودية .  <br />
{ آمَنُواْ } : شهدوا الحضرة ،   { وَعَمِلُواْ الصَّالِحَاتِ } : وقفوا بالباب .  <br />
{ آمَنُواْ } : حضروا ،   { وَعَمِلُواْ الصَّالِحَاتِ } : بعد ما حضروا لم ينصرفوا .  <br />
{ لَهُمْ أَجرٌ غَيْرُ مَمْنُونٍ } : غير منقوص ؛ فأجرُ النفوسِ الجنةُ ،   وأجرُ القلوب الرضا بالله ،   وأجرُ الأرواح الاستئناسُ بالله ،   وأجرُ الأسرار دوام المشاهدة لله .  <br />
