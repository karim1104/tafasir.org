قوله جلّ ذكره : { وَأَنَّهُ هُوَ أَغْنَى وَأَقْنَى } .  <br />
{ أَغْنَى } : أعطى الغِنَى ،   { وََأقْنَى } : أكثر القنية أي المال : وقيل { وَأَقْنَى } : أي أحوجه إلى المال - فعلى هذا يكون المعنى : أنه خَلَقَ الغِنَى والفقر .  <br />
ويقال : { وََأقْنَى } أي أرضاه بما أعطاه .  <br />
ويقال : { أَغْنَى } أي أقنع ،   { وَأَقْنَى } : أي أرضى .  <br />
