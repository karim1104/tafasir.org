قوله جلّ ذكره : { وَأَقْبَلَ بَعْضُهُمْ عَلَى بَعْضٍ يَتَسَاءَلُونَ قَالُواْ إِنَّا كُنَّا قَبْلُ فِي أَهْلِنَا مُشْفِقِينَ فَمَنَّ اللَّهُ عَلَيْنَا وَوَقَانَا عَذَابَ السَّمُومٍ } .  <br />
لولا أَنهم قالوا : { فَمَنَّ اللهُ عَلَيْنَا } لكانوا قد لاحظوا إشفاقَهم ،   ولكن الحقّ - سبحانه - اختطفهم عن شُهود إِشفاقهم ؛ حيث أَشهدهم مِنَّتَه عليهم حتى قالوا : { فَمَنَّ اللهُ عَلَيْنَا وَوَقَانَا عَذَابَ السَّمُومِ } { إِنَّا كُنَّا مِن قَبْلُ نَدْعُوهُ إِنَّهُ هُوَ الْبَرُّ الرَّحِيمُ } .  <br />
