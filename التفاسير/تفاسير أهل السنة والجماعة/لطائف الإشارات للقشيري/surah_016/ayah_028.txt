{ ظَالِمِي أَنْفُسِهِمْ } : بارتكاب المعاصي وهم الكفار .  <br />
{ فَأَلْقُوا السَّلَمَ } : انقادوا واستسلموا لحكم الله .  <br />
{ مَا كُنَّا نَعْمَلُ مِن سُوءٍ } : جحدوا وأنكروا ما عملوا من المخالفات .  <br />
{ بَلَى إِنَّ اللهَ عَلِيمٌ بِمَا كُنتُمْ تَعْمَلُونَ } : هكذا قالت لهم الملائكة<br />
