قوله جل ذكره : { هُوَ الْأَوَّلُ وَالْآَخِرُ وَالظَّاهِرُ وَالْبَاطِنُ وَهُوَ بِكُلِّ شَيْءٍ عَلِيمٌ } .  <br />
{ الأول } : لاستحقاقه صفة القِدَم ،   و{ الآخرِ } لاستحالة نعت العدَم .  <br />
و{ الظاهر } : بالعلو والرفعة ،   و{ الباطن } : بالعلم والحكمة .  <br />
ويقال : { الأول } فلا افتتاحَ لوجوده و{ الآخر } فلا انقطاعَ لثبوته .  <br />
{ الظاهر } فلا خفاءَ في جلال عِزِّه ،   { الباطن } فلا سبيل إلى إدراك حقِّه .  <br />
ويقال { الأول } بلا ابتداء ،   و{ الآخِر } بلا انتهاء ،   و{ الظاهر } بلا خفاء ،   و{ الباطن } بنعت العلاء وعِزِّ الكبرياء .  <br />
ويقال { الأول } بالعناية ،   و{ الآخر } بالهداية ،   و{ الظاهر } بالرعاية ،   و{ الباطن } بالولاية .   ويقال : { الأول } بالخَلْق ،   و{ الآخِر } بالرزق ،   و{ الظاهر } بالإحياء ،   و{ الباطن } بالإماتة والإفناء .  <br />
قال تعالى : { اللَّهُ خَلَقَكُمْ ثُمَّ رَزَقَكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ } [ الروم : 40 ] .  <br />
ويقال : { الأول } لا بزمان ،   و{ الآخر } لا بأوان ،   و{ الظاهر } بلا اقتراب ،   و{ الباطن } بلا احتجاب .  <br />
ويقال : { الأول } بالوصلة ،   و{ الآخر } بالخلّة ،   و{ الظاهر } بالأدلة ،   و{ الباطن } بالبعد عن مشابهة الجملة .  <br />
ويقال : { الأول } بالتعريف ،   و{ والآخر } بالتكليف ،   و{ والظاهر } بالتشريف و{ والباطن } بالتخفيف .  <br />
ويقال : { الأول } بالإعلام ،   { والآخر } بالإلزام ،   { والظاهر } بالإنعام { والباطن } بالإكرام .  <br />
ويقال : { الأول } بأن اصطفاك { والآخر } بأن هداك ،   { والظاهر } بأن رعاك ،   { والباطن } بأن كفاك .  <br />
ويقال : مَنْ كان الغالبُ عليه اسمه { الأول } كانت فكرته في حديثِ سابقته : بماذا سمَّاه مولاه ؟ وما الذي أجرى له في سابق حُكْمه ؟ أبسعادته أم بشقائه ؟<br />
ومَنْ كان الغالبُ على قلبه اسمه { الآخِر } كانت فكرته فيه : بماذا يختم له حالَه ؟ وإلام يصير مآلُه ؟ أَعَلى التوحيد يَخْرُجُ من دنياه أو - والعياذُ بالله - في النارِ غداً - مثواه ؟<br />
ومَن كان الغالبُ على قلبه اسمُه { الظاهر } فاشتغاله بشكر ما يجري في الحال من توفيق الإحسان وتحقيق الإيمان وجميل الكفاية وحُسْنِ الرعاية .  <br />
ومَنْ كان الغالبُ على قلبه اسمه { الباطن } كانت فكرتُه في استبهام أمره عليه فيتعثَّر ولا يدري .   .   .   أَفَضْلٌ ما يعامله به ربُّ أم مَكْرٌ ما يستدرجه به ربُّه ؟<br />
ويقال : { الأول } علم ما يفعله عبادُه ولم يمنعه عِلْمُه من تعريفهم ،   { والآخِر } رأى ما عَمِلوا ولم يمنعه ذلك من غفرانهم { والظاهر } ليس يَخْفَى عليه شيءٌ من شأنهم ،   وليس يَدَعُ شيئاً من إحسانهم { والباطن } يعلم ما ليس لهم به عِلْمٌ من خسرانهم ونقصانهم فيدفع عنهم فنونَ مَحَنهم وأحزانهم .
