{ أَمْ عِندَهُمْ خَزَآئِنُ رَبِّكَ } .  <br />
- أي خزائن أرزاقه ومقدوراته ؟ { أَمْ هُمُ الْمُصَيْطِرونَ } المُتَسلِّطون عَلَى الناس ؟<br />
أم لهم سُلّمٌ يرتقون فيه فيستمعون ما يجري في السماوات ؟ { فَلْيَأْتِ مُسْتَمِعُهُم بِسُلْطَانٍ مُّبِينٍ } ثم إنه سفّهَ أحلامهم فقال :<br />
{ أَمْ لَهُ الْبَنَاتُ وَلَكُمُ الْبَنُونَ أَمْ تَسْئَلُهُمْ أَجْراً فَهُم مِّن مَّغْرَمٍ مُّثْقَلُونَ } .  <br />
