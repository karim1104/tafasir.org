{ أَرْسِلْهُ مَعَنَا غَداً يَرْتَعْ } [يوسف: 12] في مراتعنا، { وَيَلْعَبْ } [يوسف: 12] في ملاعبنا وهي الدنيا، فإنها لعب ولهو، { وَإِنَّا لَهُ لَحَافِظُونَ } [يوسف: 12] عن فتنة الدنيا وآفاتها، { قَالَ } [يوسف: 13] يعقوب الروح، { إِنِّي لَيَحْزُنُنِيۤ أَن تَذْهَبُواْ بِهِ } [يوسف: 13] أي: بيوسف القلب، { وَأَخَافُ أَن يَأْكُلَهُ ٱلذِّئْبُ } [يوسف: 13] ذئب الشيطان، فإن القلب إذا بعد عن الروح ونظره يقرب منه الشيطان ويتصرف فيه ويهلكه، { وَأَنْتُمْ عَنْهُ غَافِلُونَ } [يوسف: 13] لانشغالكم بتحصيل مرامكم.
