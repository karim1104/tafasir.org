{ قَالَ قَآئِلٌ مِّنْهُمْ } [يوسف: 10] وهو يهوذا المفكرة، { لاَ تَقْتُلُواْ يُوسُفَ } [يوسف: 10] القلب والقوة، { وَأَلْقُوهُ فِي غَيَٰبَتِ ٱلْجُبِّ } [يوسف: 10] جب القالب وسفل البشرية، { يَلْتَقِطْهُ بَعْضُ ٱلسَّيَّارَةِ } [يوسف: 10] أي: سيارة الجولات النفسانية، { إِن كُنتُمْ فَاعِلِينَ } [يوسف: 10] فاعلين به.  { قَالُواْ يَٰأَبَانَا مَا لَكَ لاَ تَأْمَنَّا عَلَىٰ يُوسُفَ } [يوسف: 11] يشير إلى كيد الحواس والقوى بيوسف القلب، فإن القلب ما دام في نظر الروح مراقب له غير مشغول باستعمال الحواس والقوى في اللعب والهوى والتمتع من مراتع البهيمي على صحته وسلامته، فاستدعى أكواس والقوى من الروح أن يرسل يوسف القلب معهم إلى مراتعهم الحيوانية؛ ليتمتعوا به في غيبة يعقوب الروح وهو لا يأمنهم عليه لأنه واقف على مكيدتهم وأنهم يدعون نصحه وحفظه عن الآفات كما قالوا: { وَإِنَّا لَهُ لَنَاصِحُونَ } [يوسف: 11].
