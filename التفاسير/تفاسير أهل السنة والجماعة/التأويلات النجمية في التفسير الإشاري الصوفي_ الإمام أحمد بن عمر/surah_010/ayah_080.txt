{ فَلَمَّا جَآءَهُمُ ٱلْحَقُّ مِنْ عِندِنَا } [يونس: 76] الذكر الذي هو من صفاتنا، فيعمل عمل الثعبان، ويظهر المعجزات مع فرعون النفس وصفاتها.  { قَالُوۤاْ إِنَّ هَـٰذَا لَسِحْرٌ مُّبِينٌ } [يونس: 76] يعني: فرعون النفس ترى معجزة ثعبان الذكر سحراً، { قَالَ مُوسَىٰ } [يونس: 77] أي: موسى القلب، { أَتقُولُونَ لِلْحَقِّ لَمَّا جَآءَكُمْ } [يونس: 77] أي: معجزات الذكر، { أَسِحْرٌ هَـٰذَا } [يونس: 77] أي: تشكون وتشبهونها بالسحر.  { وَلاَ يُفْلِحُ ٱلسَّاحِرُونَ } [يونس: 77] أي: لا فلاح في السحر، والفلاح هو الخلاص عن قيد الوجود المجازي والظفر بالوجود الحقيقي، وإنما الفلاح في الذكر بقوله: [الأنفال: 45]، { قَالُوۤاْ أَجِئْتَنَا لِتَلْفِتَنَا عَمَّا وَجَدْنَا عَلَيْهِ آبَاءَنَا } [يونس: 78] وهذا من كلام النفس وصفاتها مع القلب ذكر التصرف عن عبادة الدنيا والهوى، { وَتَكُونَ لَكُمَا } [يونس: 78] السر والقلب، { ٱلْكِبْرِيَآءُ } [يونس: 78] السلطنة والتصرف.  { فِي ٱلأَرْضِ } [يونس: 78] أي: أرض القالب، { وَمَا نَحْنُ لَكُمَا بِمُؤْمِنِينَ } [يونس: 78] بمتبعين ولا مصدقين، { وَقَالَ فِرْعَوْنُ } [يونس: 79] النفس، { ٱئْتُونِي بِكُلِّ سَاحِرٍ عَلِيمٍ } [يونس: 79] من الشياطين والنفوس المتمردة الساحرة في البيان، وبالوساوس والهواجس والتمويهات، { فَلَمَّا جَآءَ ٱلسَّحَرَةُ قَالَ لَهُمْ مُّوسَىٰ } [يونس: 80] القلب، { أَلْقُواْ مَآ أَنتُمْ مُّلْقُونَ } [يونس: 80] من تمويهاتكم.
