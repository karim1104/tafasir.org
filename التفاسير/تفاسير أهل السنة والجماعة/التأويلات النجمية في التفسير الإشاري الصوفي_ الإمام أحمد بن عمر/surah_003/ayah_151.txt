ثم أخبر عن طاعة الكافرين أنها خذلان الخاسرين بقوله تعالى: { يَا أَيُّهَا ٱلَّذِينَ آمَنُوۤاْ إِن تُطِيعُواْ ٱلَّذِينَ كَفَرُواْ } [آل عمران: 149]، إشارة في الآيتين: إن الخطاب مع القلوب المؤمنة المستخلصة من صفات النفس الأمارة بالسوء، إن تطيعوا النفوس الكافرة وتتبعوا هواها، { يَرُدُّوكُمْ عَلَىٰ أَعْقَابِكُمْ } [آل عمران: 149] إلى أسفل السافلين ببشريتكم ويمسكم كما كنتم، كقوله تعالى: [التين: 5]، { فَتَنقَلِبُواْ خَاسِرِينَ } [آل عمران: 149].  { بَلِ ٱللَّهُ مَوْلاَكُمْ } [آل عمران: 150]، كقوله تعالى: [البقرة: 257]، { وَهُوَ خَيْرُ ٱلنَّاصِرِينَ } [آل عمران: 150]، لا يحتمل عليه غير الله من الناصرين.  وقال تعالى: { سَنُلْقِي فِي قُلُوبِ ٱلَّذِينَ كَفَرُواْ ٱلرُّعْبَ بِمَآ أَشْرَكُواْ بِٱللَّهِ } [آل عمران: 151] أي: سبب إشراكهم بالله نظيره قوله تعالى: [الصف: 5]؛ أي: بسبب زيغهم، وقال تعالى: [السجدة: 24]؛ أي: بسبب صبرهم وأمثاله في القرآن كثيرة، ثم قال تعالى: { مَا لَمْ يُنَزِّلْ بِهِ سُلْطَاناً وَمَأْوَاهُمُ ٱلنَّارُ وَبِئْسَ مَثْوَىٰ ٱلظَّالِمِينَ } [آل عمران: 151]؛ أي: مرجع الذين أشركوا نار القطيعة وبئس مثواهم لظلم عظيم؛ ولهذا [النساء: 48].
