{ قَالَ } [الذاريات: 31]؛ يعني إبراهيم الروح: { فَمَا خَطْبُكُمْ أَيُّهَا ٱلْمُرْسَلُونَ } [الذاريات: 31]؛ يعني: التجليات { قَالُوۤاْ إِنَّآ أُرْسِلْنَآ إِلَىٰ قَوْمٍ مُّجْرِمِينَ } [الذاريات: 32] وهم النفس وصفاتها الذميمة؛ { لِنُرْسِلَ عَلَيْهِمْ حِجَارَةً مِّن طِينٍ * مُّسَوَّمَةً عِندَ رَبِّكَ } [الذاريات: 33-34]، هلاك { لِلْمُسْرِفِينَ } [الذاريات: 34]، وهي الأذكار والأوراد والمجاهدات والرياضات والمعاملات المهلكة للنفس وأوصافها؛ { فَأَخْرَجْنَا مَن كَانَ فِيهَا مِنَ ٱلْمُؤْمِنِينَ } [الذاريات: 35] سالمين من الهلاك، { فَمَا وَجَدْنَا فِيهَا } [الذاريات: 36]؛ أي: في مدينة الشخص الإنساني { غَيْرَ بَيْتٍ مِّنَ ٱلْمُسْلِمِينَ } [الذاريات: 36]؛ أي: القلب السليم وأوصافة الحميدة، { وَتَرَكْنَا فِيهَآ آيَةً } [الذاريات: 37] من تزكية النفس وتهذيب أخلاقها، عبرة { لِّلَّذِينَ يَخَافُونَ ٱلْعَذَابَ ٱلأَلِيمَ } [الذاريات: 37]، بوعيد قوله: [الشمس: 9-10].  ثم أخبر عن عذاب أهل العقاب بقوله تعالى: { وَفِي مُوسَىٰ إِذْ أَرْسَلْنَاهُ إِلَىٰ فِرْعَوْنَ بِسُلْطَانٍ مُّبِينٍ } [الذاريات: 38]، يشير إلى موسى القلب إذ أرسله إلى فرعون النفس بسلطان وهو عصا لا إله إلا الله مبين إعجازها بأن يتلقف ما تؤفكون من سحر تمويهات سحرة فرعون النفس، { فَتَوَلَّىٰ بِرُكْنِهِ } [الذاريات: 39]؛ أي: أعرض رؤية الإعجاز والإيمان به بجميع صفاته، { وَقَالَ } [الذاريات: 39] فرعون النفس لموسى القلب: { سَاحِرٌ أَوْ مَجْنُونٌ * فَأَخَذْنَاهُ وَجُنُودَهُ } [الذاريات: 39-40]؛ يعني: فرعون النفس وصفاتها، { فَنَبَذْنَاهُمْ فِي ٱلْيَمِّ } [الذاريات: 40]؛ أي: يم الدنيا ليهلكوا فيها، { وَهُوَ مُلِيمٌ } [الذاريات: 40]؛ أي: مستحق اللوم إنما هو فرعون النفس؛ لأنها هي الأمارة بالسوء والصفات تبع لها.
