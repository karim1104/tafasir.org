ثم قال { قُلْ مَن ذَا ٱلَّذِي يَعْصِمُكُمْ مِّنَ ٱللَّهِ إِنْ أَرَادَ بِكُمْ سُوۤءاً } [الأحزاب: 17] ومن الذي تحقق لكم من دونه مرجوا أو يمنعه منكم إن أراد بكم رحمة { وَلاَ يَجِدُونَ لَهُمْ مِّن دُونِ ٱللَّهِ وَلِيّاً وَلاَ نَصِيراً } [الأحزاب: 17] لو عرفوه حق المعرفة { قَدْ يَعْلَمُ ٱللَّهُ ٱلْمُعَوِّقِينَ مِنكُمْ } [الأحزاب: 18] عن قتال النفس وجهادها وهم الهوى والشيطان والدنيا وشهواتها، { وَ } هم { ٱلْقَآئِلِينَ لإِخْوَانِهِمْ } وهم الحواس الظاهرة والباطنة والجوارح والأعضاء { هَلُمَّ إِلَيْنَا } أي كونوا أتباعاً لنا لتنتفعوا { وَلاَ يَأْتُونَ ٱلْبَأْسَ إِلاَّ قَلِيلاً } [الأحزاب: 18] القتال والجهاد مع النفس وأعوانها الملازمة أحكام الشريعة على وفق الطريقة { إِلاَّ قَلِيلاً } من الأركان الظاهرة دفعاً للطعان والجدود.  ثم وصف المعوقين عن الطلب والمانعين عن الجهاد، فقال: { أَشِحَّةً عَلَيْكُمْ } [الأحزاب: 19] بخلاء فيما يصل إليكم يا أرباب الطلب من ثمرات المجاهدات، فإن المجاهدات تورث المشاهدات { فَإِذَا جَآءَ ٱلْخَوْفُ } من عذاب الآخرة عند تذكرها { رَأَيْتَهُمْ } أي: رأيت النفس وصفاتها { يَنظُرُونَ إِلَيْكَ تَدُورُ أَعْيُنُهُمْ } [الأحزاب: 19] بالحسرة والندامة، وقد طاشت من الرعب قلوبهم وطاحت بصائرهم { كَٱلَّذِي يُغْشَىٰ عَلَيْهِ مِنَ ٱلْمَوْتِ فَإِذَا } [الأحزاب: 19] جاءت الغفلة و { ذَهَبَ ٱلْخَوْفُ } أيها الطلاب { سَلَقُوكُمْ } [الأحزاب: 19] إخوان السوء وإخوان الشياطين { بِأَلْسِنَةٍ حِدَادٍ } بأنواع التعريفات وأصناف الفترات { أَشِحَّةً عَلَى ٱلْخَيْرِ } بأن يصيبكم من فضل الله وكرمه { أوْلَـٰئِكَ لَمْ يُؤْمِنُواْ } [الأحزاب: 19] يُشير به إلى مدعي الطلب إذا ارتد عن الطلب، فإن المشايخ قد قالوا: إن مرتد الطريقة شر من مرتد الشريعة؛ ولهذا قال تعالى: { فَأَحْبَطَ ٱللَّهُ أَعْمَالَهُمْ } [الأحزاب: 19] لأنها لم تكن في إيمان حقيقي بل كان بالتقليد والرياء والسمعة، وكان ذلك الرد والإبطال على الله يسيراً.
