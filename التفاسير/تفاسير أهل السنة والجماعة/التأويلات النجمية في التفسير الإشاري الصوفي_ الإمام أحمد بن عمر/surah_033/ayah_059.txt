وقوله: { وَٱلَّذِينَ يُؤْذُونَ ٱلْمُؤْمِنِينَ وَٱلْمُؤْمِنَاتِ بِغَيْرِ مَا ٱكْتَسَبُواْ فَقَدِ ٱحْتَمَلُواْ بُهْتَاناً وَإِثْماً مُّبِيناً } [الأحزاب: 58] يشير إلى أن إيذاء المؤمنين مقرون بإيذاء الرسول كما أن إيذاء الرسول مقرون بإيذاء الله فحقيقة معناه أن من أذى المؤمن، فكمن أذى الرسول فكمن أذى الله ومن أذى الله فهو مستحق الطرد واللعن في الدنيا والآخرة وقوله: { يٰأَيُّهَا ٱلنَّبِيُّ قُل لأَزْوَاجِكَ وَبَنَاتِكَ وَنِسَآءِ ٱلْمُؤْمِنِينَ يُدْنِينَ عَلَيْهِنَّ مِن جَلاَبِيبِهِنَّ } [الأحزاب: 59] تنبيه لهن على حفظ القسمين ورعاية حقه منهن بالتصاون والتعفف وفيه إثبات وقرهن وعزة قدرهن { ذٰلِكَ } [الأحزاب: 59] أي: ذلك التنبيه { أَدْنَىٰ أَن يُعْرَفْنَ } [الأحزاب: 59] أي: يعرفن أن لهن قدرا وعزةً في الحضرة { فَلاَ يُؤْذَيْنَ } [الأحزاب: 59] بالأطماع الفاسدة والأقوال الكاذبة { وَكَانَ ٱللَّهُ غَفُوراً رَّحِيماً } [الأحزاب: 59] لهن بامتثال الأوامر رحيماً بهن بإعلاء درجتهن.
