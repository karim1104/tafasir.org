{ قَالَ } [يوسف: 51] يعني: الروح للأوصاف الإنسانية، { مَا خَطْبُكُنَّ إِذْ رَاوَدتُّنَّ يُوسُفَ عَن نَّفْسِهِ } [يوسف: 51] أي: يوسف القلب هل رأيتن فيه مناسبة حتى ملن إليه؟ { قُلْنَ حَاشَ لِلَّهِ مَا عَلِمْنَا عَلَيْهِ مِن سُوۤءٍ } [يوسف: 51] يناسب حالنا، { قَالَتِ ٱمْرَأَتُ ٱلْعَزِيزِ ٱلآنَ حَصْحَصَ ٱلْحَقُّ } [يوسف: 51] ظهر الحق وخفي الباطل إذا الأوصاف الإنسانية شاهدة جمال يوسف القلب وعزته في طلب الحق وترك زليخاء الدنيا، { أَنَاْ رَاوَدْتُّهُ عَن نَّفْسِهِ } بكمال جماله حاله ونقصان قبيح حالي، { وَإِنَّهُ لَمِنَ ٱلصَّادِقِينَ } [يوسف: 51] في طلب الحق، وترك متابعة الهوى في طلب الدنيا.  { ذٰلِكَ } [يوسف: 52] الرد من الرسول لنفسه؛ أي: طلب الروح، { لِيَعْلَمَ أَنِّي لَمْ أَخُنْهُ بِٱلْغَيْبِ } [يوسف: 52] يشير به إلى كلام القلب المنظور بنظر العناية أنه لمَّا غاب عن حضرة الروح؛ لانشغاله بتربية النفس والقالب وتدبير مصالحهما ما خانه بالالتفات إلى الدنيا ونعيمها، { وَأَنَّ ٱللَّهَ لاَ يَهْدِي كَيْدَ ٱلْخَائِنِينَ } [يوسف: 52] أي: لا يرشد كيد من خانه؛ أي: بائع الدين بالدنيا.
