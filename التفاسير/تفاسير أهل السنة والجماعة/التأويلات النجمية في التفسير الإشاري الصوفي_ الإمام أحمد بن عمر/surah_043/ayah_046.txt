ثم أخبر عن حالة رسالة موسى عليه السلام بقوله: { وَلَقَدْ أَرْسَلْنَا مُوسَىٰ بِآيَـٰتِنَآ إِلَىٰ فِرْعَوْنَ وَمَلإِيْهِ فَقَالَ إِنِّي رَسُولُ رَبِّ ٱلْعَـٰلَمِينَ } [الزخرف: 46] يشير إلى ظلومية الإنسان وجهولية كفران نعمة ربه، إذ يرسل إليهم رسولاً كريماً بدلائله وحجته الظاهرة الباهرة، وهي معجزاته إلى فرعون، وهو فرعون النفس { وَمَلإِيْهِ }؛ أي: صفاتها، { فَلَمَّا جَآءَهُم بِآيَاتِنَآ } [الزخرف: 47]؛ ليسعدوا وينتبهوا وينتفعوا بها { إِذَا هُم مِّنْهَا يَضْحَكُونَ } [الزخرف: 47] فقوبل بالهزأ والضحك والتكذيب، { وَمَا نُرِيِهِم مِّنْ آيَةٍ إِلاَّ هِيَ أَكْبَرُ مِنْ أُخْتِهَا } [الزخرف: 48] والله تعالى لم يتبع تلك الآيات والدلالات بشيء إلا كان أوضح مما قبله، ولم يقابلوه إلا بجفاء أوحش مما قبله من ظلومية طبع الإنسان وكفوريته، وبقوله: { وَأَخَذْنَاهُم بِٱلْعَذَابِ لَعَلَّهُمْ يَرْجِعُونَ } [الزخرف: 48] يشير إلى أن من جهولية نفس الإنسان ألا يرجع إلى الله على أقدام العبودية إلا إن تجرد بسلاسل البأساء والضراء إلى الحضرة، كما قال تعالى: [فصلت: 51]، ولهذا لما عظم الأمر وضاق نطاق بشريتهم { وَقَالُواْ يَٰأَيُّهَ ٱلسَّاحِرُ } [الزخرف: 49] وما قالوا مع هذا الاضطرار بها يا أيها الرسول، { ٱدْعُ لَنَا رَبَّكَ } [الزخرف: 49]؛ لأنهم ما رجعوا إلى الله بصدق النية وخلوص العقيدة ليروه بنور الإيمان رسولاً ويرون الله ربهم، وإنما رجعوا بالاضطرار لخلاص أنفسهم لا لإخلاص قلوبهم قالوا: { ٱدْعُ لَنَا رَبَّكَ بِمَا عَهِدَ عِندَكَ إِنَّنَا لَمُهْتَدُونَ } [الزخرف: 49]؛ أي: لنؤمنن بك وبربك، فدعا موسى عليه السلام وأجابه ربه فكشف عنهم فعادوا إلى كفرهم ونقضوا عهدهم وذلك قوله تعالى: { فَلَمَّا كَشَفْنَا عَنْهُمُ ٱلْعَذَابَ إِذَا هُمْ يَنكُثُونَ } [الزخرف: 50].
