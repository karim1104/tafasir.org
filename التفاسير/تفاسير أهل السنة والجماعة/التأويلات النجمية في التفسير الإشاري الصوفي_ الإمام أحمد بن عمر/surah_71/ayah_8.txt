{ وَإِنِّي كُلَّمَا دَعَوْتُهُمْ لِتَغْفِرَ لَهُمْ جَعَلُوۤاْ أَصَابِعَهُمْ فِيۤ آذَانِهِمْ } [نوح: 7]؛ يعني: أصابع الغفلة في آذانهم؛ لئلا يسمعون دعائي وإنذاري { وَٱسْتَغْشَوْاْ ثِيَابَهُمْ } [نوح: 7]؛ يعني: ثياب الجهل؛ لئلا يصل إليهم برد تعليمي إياهم { وَأَصَرُّواْ } [نوح: 7] ظلماً من غاية ظلام وجودهم وكثافة استعدادهم المكدرة، { وَٱسْتَكْبَرُواْ } [نوح: 7] بالكبر والكفر { ٱسْتِكْبَاراً } [نوح: 7] عن قبول الحق.  { ثُمَّ إِنِّي دَعَوْتُهُمْ جِهَاراً } [نوح: 8]؛ يعني: الآثار الظاهرة والموعظة الحسنة { ثُمَّ إِنِّيۤ أَعْلَنْتُ لَهُمْ } [نوح: 9]؛ يعني: أعلمتهم ودللتهم على الأفعال بالمجادلة والمباحثة، { وَأَسْرَرْتُ لَهُمْ إِسْرَاراً } [نوح: 9]؛ يعني: بينت لهم حقائق الصفات بالحكمة؛ { فَقُلْتُ ٱسْتَغْفِرُواْ رَبَّكُمْ إِنَّهُ كَانَ غَفَّاراً * يُرْسِلِ ٱلسَّمَآءَ عَلَيْكُمْ مِّدْرَاراً } [نوح: 10-11]، يرسل بلطفه في سماء صدركم مطر الرحمة؛ لينبت في أراضي بشريتكم نبات المعرفة.
