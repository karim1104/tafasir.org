أنا عبد الرحمن، قال ثنا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد: { يُؤْتَىۤ أَحَدٌ مِّثْلَ مَآ أُوتِيتُمْ } [الآية: 73] حسداً من اليهود أَن تكون النبوة في غيرهم وأَرادوا / 10و / أَن يتابعوهم على دينهم، فقال: { قُلْ } يا محم { إِنَّ ٱلْفَضْلَ بِيَدِ ٱللَّهِ } [الآية: 73]. { يَخْتَصُّ بِرَحْمَتِهِ مَن يَشَآءُ } [الآية: 74]. يعني: بالنبوة.  أنبا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال: ثنا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { إِلاَّ مَا دُمْتَ عَلَيْهِ قَآئِماً } [الآية: 75]. قال: يعني مواظباً.  أنا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال ثنا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { يَلْوُونَ أَلْسِنَتَهُمْ بِٱلْكِتَابِ } [الآية: 78] يعني: يحرّفونه.
