أَنبا عبد الرحمن، حدثنا إِبراهيم، ثنا آدم، ثنا ورقاءُ عن ابن أَبي نجيح، عن مجاهد: { وَإِنْ أَحَدٌ مِّنَ ٱلْمُشْرِكِينَ ٱسْتَجَارَكَ فَأَجِرْهُ } يقول: إِنسان يأْتي فيسمع ما تقول، ويسمع ما أُنزل عليك فهو آمن، { حَتَّىٰ يَسْمَعَ كَلاَمَ ٱللَّهِ } ، وحتى { ثُمَّ أَبْلِغْهُ مَأْمَنَهُ } من حيث جاءَ [الآية: 6].  أنبا عبد الرحمن، نا إِبراهيم، ثنا آدم، نا ورقاءُ عن ابن أَبي نجيح عن مجاهد في قوله: { لاَ يَرْقُبُونَ فِي مُؤْمِنٍ إِلاًّ وَلاَ ذِمَّةً } [الآية: 10] قال: الإِلّ: العهد.  أنا عبد الرحمن، نا إِبراهيم، ثنا آدم، نا ورقاءُ عن عن ابن أَبي نجيح، عن مجاهد في قوله: { ٱشْتَرَوْاْ بِآيَاتِ ٱللَّهِ ثَمَناً قَلِيلاً } [الآية: 9]. قال: هو أَبو سفيان بن حرب، أَطعم حلفاءَه وترك حلفاءَ محمد، صلى الله عليه وسلم.  أَنا عبد الرحمن، قنا إِبراهيم، ثنا آدم، ثنا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { وَإِن نَّكَثُوۤاْ / 29و / أَيْمَانَهُمْ } [الآية: 12]. يعني: عهدهم.  أَنبا عبد الرحمن، قال: نا إِبراهيم، نا آدم، نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد: { وَهَمُّواْ بِإِخْرَاجِ ٱلرَّسُولِ } [الآية: 13]. قال: يأْثر الله ذلك { وَهُم بَدَءُوكُمْ أَوَّلَ مَرَّةٍ } [الآية: 13]. يعني: قريشاً حين قاتلوا حلفاءَ محمد، صلى الله عليه وسلم.  أَنبا عبد الرحمن، نا إِبراهيم، نا آدم، ثنا ورقاءُ عن ابن أَبي نجيح عن مجاهد في قوله: { وَيَشْفِ صُدُورَ قَوْمٍ مُّؤْمِنِينَ } [الآية: 14]. قال: خزاعة حلفاءَ محمد.  أَنا عبد الرحمن، ثنا إِبراهيم، نا آدم، ثنا ورقاءُ عن ابن أَبي نجيح عن مجاهد في قوله: { أَجَعَلْتُمْ سِقَايَةَ ٱلْحَاجِّ وَعِمَارَةَ ٱلْمَسْجِدِ ٱلْحَرَامِ } [الآية: 19]. قال: لما أُمروا بالهجرة قال العباس ابن عبد المطلب: أَنا أَسقي الحاج. وقال طلحة أَخو بني عبد الدار: أَنا أَحجب الكعبة فلا أُهاجر. فنزل: { يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ لاَ تَتَّخِذُوۤاْ آبَآءَكُمْ وَإِخْوَانَكُمْ أَوْلِيَآءَ } إِلى قوله: { فَتَرَبَّصُواْ حَتَّىٰ يَأْتِيَ ٱللَّهُ بِأَمْرِهِ } [الآية: 23-24].  أَنا عبد الرحمن، نا إِبراهيم، نا آدم، نا ورقاءُ عن ابن أَبي نجيح عن مجاهد في قوله: { فَتَرَبَّصُواْ حَتَّىٰ يَأْتِيَ ٱللَّهُ بِأَمْرِهِ } [الآية: 24]. قال: يعني بالفتح، فتح مكة. وهذا حين أُمروا بالهجرة. قال العباس وطلحة ما قالا، وهذا كله قبل فتح مكة.  أنا عبد الرحمن، نا إِبراهيم، نا آدم، نا ورقاءُ عن ابن أَبي نجيح عن مجاهد: { لَقَدْ نَصَرَكُمُ ٱللَّهُ فِي مَوَاطِنَ كَثِيرَةٍ } [الآية: 25]. قال: هذا أَول ما نزل من برآءَة. يعرفهم نصره أَو يوطئهم أَو يوطنهم لغزوة تبوك.
