أَخبرنا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { وَٱلذَّارِيَاتِ ذَرْواً } [الآية: 1]. قال: الرياح. { فَٱلْحَامِلاَتِ وِقْراً } [الآية: 2]. قال السحاب يحمل المطر. { فَٱلْجَارِيَاتِ يُسْراً } [الآية: 3]. قال: السفن. { فَٱلْمُقَسِّمَاتِ أَمْراً } [الآية: 4]. قال: الملائكة ينزلها على من يشاءُ.  أَنا عبد الرحمن، قال: نا إِبراهيم قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله، عز وجل: { إِنَّمَا تُوعَدُونَ لَصَادِقٌ } [الآية: 5]. يقول: إن [يَوْمَ] القيامة لكائن.  أَنا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال: ثنا ورقاءُ عن ابن أَبي نجيح، عن مجاهد: { وَإِنَّ ٱلدِّينَ لَوَاقِعٌ } [الآية: 6]. قال: إِن الحساب لكائن.
