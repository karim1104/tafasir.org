أَنبا عبد الرحمن، قال: ثنا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد / 24ظ / { وَلَقَدْ أَخَذْنَآ آلَ فِرْعَونَ بِٱلسِّنِينَ }. يعني: بالجوع، { وَنَقْصٍ مِّن ٱلثَّمَرَاتِ } [الآية: 130]. يعني: دون ذلك.  أنبا عبد الرحمن، قال: ثنا إِبراهيم، قال: ثنا آدم قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { فَإِذَا جَآءَتْهُمُ ٱلْحَسَنَةُ } ، قال: يعني العافية والرخاءُ { قَالُواْ لَنَا هَـٰذِهِ } أَي: نحن أَحق بها { وَإِن تُصِبْهُمْ سَيِّئَةٌ }. يعني: بلاءٌ وعقوبة { يَطَّيَّرُواْ }. يقول: يتشاءَموا { بِمُوسَىٰ وَمَن مَّعَهُ } [الآية: 131].
