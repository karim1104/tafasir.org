{ إِنَّ ٱلَّذِينَ آمَنُواْ } وصف الله تعالى اهل العناية الذين صدقوا فيها عاينوا فى علم الازل من مشاهدة القدم وفيها سمعوا من خطاب الحسن بنعت تعريفه لهم جلاله وجماله وعظمته وصمديته وكبرياءه وقدرته وحكمته { وَهَاجَرُواْ } من الحدثان الى مشاهدة الرحمٰن { وَجَاهَدُواْ } فى العبودية للزوم حق الربوبية عليهم { فِي سَبِيلِ ٱللَّهِ } ما بين مقاديره بنعت الرضا فى مراده { أُوْلـٰئِكَ يَرْجُونَ رَحْمَتَ ٱللَّهِ } وصاله وقربه { وَٱللَّهُ غَفُورٌ } تقصيره فى تزكية الاشباح { رَّحِيمٌ } بهم فى تربية الارواح.
