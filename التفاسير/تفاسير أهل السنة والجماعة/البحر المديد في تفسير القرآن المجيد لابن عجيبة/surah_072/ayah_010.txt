{ وأنَّا لا ندري أَشَرٌّ أُريد بمَن في الأرض } بحراسة السماء ،  { أم أراد بهم ربُّهم رشداً } ؛ خيراً ورحمة ،  ونسبة الخير إلى الله تعالى دون الشر من الآداب الشريفة القرآنية ،  كقوله تعالى : { وَإِذَا مَرِضْتُ فَهُوَ يَشْفِينِ } [ الشعراء : 80 ] وقوله : { مَّا أَصَابَكَ مِنْ حَسَنَةٍ فَمِنَ اللهِ وَمَا أَصَابَكَ مِن سَيِئَةٍ فَمِن نَّفْسِكَ } [ النساء : 79 ] بعد أن ذكر ما في نفس الأمر بقوله : { قُلْ كُلٌ مِنْ عِندِ اللهِ } [ النساء : 78 ] .  <br />
