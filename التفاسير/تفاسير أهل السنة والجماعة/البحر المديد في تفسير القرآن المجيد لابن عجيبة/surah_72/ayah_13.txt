{ وأنَّا لمَّا سمعنا الهُدى } ؛ القرآن { آمنا به } ؛ بالقرآن ،  أو بالله تعالى ،  { فمَن يؤمن بربه فلا يخافُ } أي : فهو لا يخاف { بَخْساً } ؛ نقصاً { ولا رَهَقَا } أي : ولا ترهقه ذلة ،  كقوله :<br />
{ وَلا يَرْهَقُ وُجُوهَهُمْ قَتَرٌ وَلا ذِلَّةُ } [ يونس : 26 ] ،  وفيه دليل على أنَّ العمل ليس من الإيمان ،  وأنَّ المؤمن لا يخلد في النار .  <br />
