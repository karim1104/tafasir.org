ثم ذكر عذاب أهل التكذيب ،  فقال :<br />
{ قَالَ ادْخُلُواْ فِيا أُمَمٍ قَدْ خَلَتْ مِن قَبْلِكُمْ مِّن الْجِنِّ وَالإِنْسِ فِي النَّارِ كُلَّمَا دَخَلَتْ أُمَّةٌ لَّعَنَتْ أُخْتَهَا حَتَّى إِذَا ادَّارَكُواْ فِيهَا جَمِيعاً قَالَتْ أُخْرَاهُمْ لأُولاَهُمْ رَبَّنَا هَؤُلاءِ أَضَلُّونَا فَآتِهِمْ عَذَاباً ضِعْفاً مِّنَ النَّارِ قَالَ لِكُلٍّ ضِعْفٌ وَلَاكِن لاَّ تَعْلَمُونَ وَقَالَتْ أُولاَهُمْ لأُخْرَاهُمْ فَمَا كَانَ لَكُمْ عَلَيْنَا مِن فَضْلٍ فَذُوقُواْ الْعَذَابَ بِمَا كُنتُمْ تَكْسِبُونَ }<br />
يقول الحقّ جلّ جلاله : { قال } الله تعالى أي : يوم القيامة للكفارٍ ،  بواسطة ملك ،  أو بغيرها : { ادخلوا في } جملة { أممٍ } كانوا من قبلكم ؛ { من الجن والإنس } متفقين معكم في الكفر والضلال ،  فادخلوا مصاحبين معهم { في النار } .   قال تعالى ،  مخبرًا عن حالهم : { كلما دخلت أمةٌ } منهم في النار { لعنت أختها } التي ضلت بالاقتداء بها ،  { حتى إذا ادَّاركوا } أي : تداركوا وتلاحقوا ،  { فيها جميعًا قالت أُخراهم } ؛ دخولاً أو منزلة ،  وهم الأتباع السفلة ،  { لأُولاهم } وهم المتبوعون الرؤساء  أي : قالت لأجلهم ؛ لأن الخطاب مع الله لا معهم ،  قالوا : { ربنا هؤلاء } الرؤساء { أضلونا } ؛ حيث سنُّوا لنا الضلال فاقتدينا بهم ،  { فآتِهم عذابًا ضِعفًا } أي : مضاعفًا { من النار } ؛ لأنهم ضلوا وأضلوا .   { قال } تعالى : { لكلٍّ } واحد منكم { ضِعفٌ } أي : عذابًا مضعفًا ،  أما القادة ؛ فلكفرهم وتضليلهم ،  وأما الأتباع ؛ فلكفرهم وتقليدهم ،  { ولكن لا تعلمون } ما لكم ،  أو ما لكل فريق منكم .  <br />
