ثم ذكر أضداد المنافقين ،  فقال :<br />
{ وَالْمُؤْمِنُونَ وَالْمُؤْمِنَاتِ بَعْضُهُمْ أَوْلِيَآءُ بَعْضٍ يَأْمُرُونَ بِالْمَعْرُوفِ وَيَنْهَوْنَ عَنِ الْمُنْكَرِ وَيُقِيمُونَ الصَّلاَةَ وَيُؤْتُونَ الزَّكَاةَ وَيُطِيعُونَ اللَّهَ وَرَسُولَهُ أُوْلَائِكَ سَيَرْحَمُهُمُ اللَّهُ إِنَّ اللَّهَ عَزِيزٌ حَكِيمٌ } * { وَعَدَ اللَّهُ الْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا الأَنْهَارُ خَالِدِينَ فِيهَا وَمَسَاكِنَ طَيِّبَةً فِي جَنَّاتِ عَدْنٍ وَرِضْوَانٌ مِّنَ اللَّهِ أَكْبَرُ ذالِكَ هُوَ الْفَوْزُ الْعَظِيمُ }<br />
يقول الحق جل جلاله : { والمؤمنون والمؤمناتُ بعضهم أولياءُ } أي : أصدقاء { بعضٍ } ،  وهذا في مقابلة قوله : { المنافقون والمنافقات بعضهم من بعض } ،  وخص المؤمنين بالوصف بالولاية ،  { يأمرون بالمعروف وينهَونَ عن المنكر } ؛ ضد ما فعله المنافقون ،  { ويُقيمون الصلاة وَيُؤتون الزكاة } ؛ ضد قوله : { وَيَقْبِضُون أَيْدِيَهُمْ } ،  { ويُطيعون الله ورسوله } في سائر الأمور ،  ضد قوله : { نَسُوا اللهَ فَنَسِيَهُمْ } ،  { أولئك سيرحمهم الله } لا محالة ؛ لأن السين مؤكدة للوقوع ،  { إن الله عزيزٌ } ؛ غالب على كل شيء ،  ولا يمتنع عليه ما يريده ،  { حكيم } يضع الأشياء مواضعها .  <br />
/خ72
