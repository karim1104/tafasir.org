ثم ذكر وقت ما أقسم عليه ،  فقال :<br />
{ يَوْمَ تَمُورُ السَّمَاءُ مَوْراً }*{ وَتَسِيرُ الْجِبَالُ سَيْراً }*{ فَوَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ }*{ الَّذِينَ هُمْ فِي خَوْضٍ يَلْعَبُونَ }*{ يَوْمَ يُدَعُّونَ إِلَى نَارِ جَهَنَّمَ دَعًّا }*{ هَذِهِ النَّارُ الَّتِي كُنتُم بِهَا تُكَذِّبُونَ }*{ أَفَسِحْرٌ هَذَا أَمْ أَنتُمْ لاَ تُبْصِرُونَ }*{ اصْلَوْهَا فَاصْبِرُواْ أَوْ لاَ تَصْبِرُواْ سَوَاءٌ عَلَيْكُمْ إِنَّمَا تُجْزَوْنَ مَا كُنتُمْ تَعْمَلُونَ } .  <br />
يقول الحق جلّ جلاله : واذكر { يومَ تَمورُ } أو : لواقع يوم تمور { السماءُ } أي : تدور كالرحى مضطربة { موراً } عظيماً تتكفأ بأهلها كالسفينة .  <br />
/خ16
