ثم ذكر قصة هود عليه السلام ،  فقال :<br />
{ وَإِلَى عَادٍ أَخَاهُمْ هُوداً قَالَ يا قَوْمِ اعْبُدُواْ اللَّهَ مَا لَكُمْ مِّنْ إِلَهٍ غَيْرُهُ إِنْ أَنتُمْ إِلاَّ مُفْتَرُونَ } * { يا قَوْمِ لا أَسْأَلُكُمْ عَلَيْهِ أَجْراً إِنْ أَجْرِيَ إِلاَّ عَلَى الَّذِي فَطَرَنِي أَفَلاَ تَعْقِلُونَ } * { وَيا قَوْمِ اسْتَغْفِرُواْ رَبَّكُمْ ثُمَّ تُوبُواْ إِلَيْهِ يُرْسِلِ السَّمَآءَ عَلَيْكُمْ مِّدْرَاراً وَيَزِدْكُمْ قُوَّةً إِلَى قُوَّتِكُمْ وَلاَ تَتَوَلَّوْاْ مُجْرِمِينَ }<br />
قلت :  " أخاهم "  : عطف على نوح في قوله : ( ولقد أرسلنا نوحاً ) ،  و( هوداً ) : بدل .  <br />
يقول الحق جل جلاله : { و } أرسلنا { إلى } قبيلة { عادٍ أخاهم هوداً قال يا قوم اعبدوا الله } وحده ،  { ما لكم من إله غيرُهُ } يستحق أن يعبد ،  { إن أنتم إلا مُفترون } على الله ،  باتخاذ الأوثان آلهة .  <br />
