ولما بشر نبيه –عليه الصلاة والسلام- مع المؤمنين ،  بالدفع والنصر على سائر الملل ،  سلاه عن تكذيب قومه بقوله :<br />
{ وَإِن يُكَذِّبُوكَ فَقَدْ كَذَّبَتْ قَبْلَهُمْ قَوْمُ نُوحٍ وَعَادٌ وَثَمُودُ } * { وَقَوْمُ إِبْرَاهِيمَ وَقَوْمُ لُوطٍ } * { وَأَصْحَابُ مَدْيَنَ وَكُذِّبَ مُوسَى فَأمْلَيْتُ لِلْكَافِرِينَ ثُمَّ أَخَذْتُهُمْ فَكَيْفَ كَانَ نَكِيرِ } * { فَكَأَيِّن مِّن قَرْيَةٍ أَهْلَكْنَاهَا وَهِيَ ظَالِمَةٌ فَهِيَ خَاوِيَةٌ عَلَى عُرُوشِهَا وَبِئْرٍ مُّعَطَّلَةٍ وَقَصْرٍ مَّشِيدٍ }<br />
يقول الحقّ جلّ جلاله : { وإن يُكذبوك } يا مُحمد ،  أي : أهل مكة ،  فلا تحزن ؛ فلست بأول من كُذب ،  { فقد كَذَّبت قبلهم } أي : قبل قومك { قومُ نوح } نوحًا ،  { وعادٌ } هودًا ،  { وثمودُ } صالحًا .  <br />
