قال الله تعالى :<br />
بسم الله الرحمان الرحيم .  <br />
{ الم } * { غُلِبَتِ الرُّومُ } * { فِي أَدْنَى الأَرْضِ وَهُم مِّن بَعْدِ غَلَبِهِمْ سَيَغْلِبُونَ } * { فِي بِضْعِ سِنِينَ لِلَّهِ الأَمْرُ مِن قَبْلُ وَمِن بَعْدُ وَيَوْمَئِذٍ يَفْرَحُ الْمُؤْمِنُونَ } * { بِنَصْرِ اللَّهِ يَنصُرُ مَن يَشَآءُ وَهُوَ الْعَزِيزُ الرَّحِيمُ } * { وَعْدَ اللَّهِ لاَ يُخْلِفُ اللَّهُ وَعْدَهُ وَلَكِنَّ أَكْثَرَ النَّاسِ لاَ يَعْلَمُونَ } * { يَعْلَمُونَ ظَاهِراً مِّنَ الْحَيَاةِ الدُّنْيَا وَهُمْ عَنِ الآخِرَةِ هُمْ غَافِلُونَ }<br />
يقول الحق جل جلاله : بعد التسمية { الم } أي : أيها المصطفى ،  أو : المرسل .  <br />
/خ7
