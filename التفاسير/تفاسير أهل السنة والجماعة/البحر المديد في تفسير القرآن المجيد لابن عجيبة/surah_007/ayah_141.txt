{ وإذ أنجيناكم من آل فرعون } أي : واذكروا صُنعه معكم في هذا الوقت حيث نجاكم من فرعون ورهطه { يسومُونَكم } أي : يذيقونكم { سوءَ العذاب } ،  ثم بينَّه بقوله : { يقتلون أبناءَكم } ذكورهم { ويستحيون نساءَكم } أي : بناتكم ،  { وفي ذلكم بلاءٌ من ربكم عظيم } أي : وفي ذلك القتل امتحان عظيم ،  أو في ذلك الإنجاء نعمة عظيمة وامتنان عظيم .  <br />
