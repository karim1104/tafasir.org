ثم ذكر لوطا عليه السلام ،  فقال :<br />
{ وَإِنَّ لُوطاً لَّمِنَ الْمُرْسَلِينَ } * { إِذْ نَجَّيْنَاهُ وَأَهْلَهُ أَجْمَعِينَ } * { إِلاَّ عَجُوزاً فِي الْغَابِرِينَ } * { ثُمَّ دَمَّرْنَا الآخَرِينَ } * { وَإِنَّكُمْ لَّتَمُرُّونَ عَلَيْهِمْ مُّصْبِحِينَ } * { وَبِالْلَّيْلِ أَفَلاَ تَعْقِلُونَ } .  <br />
يقول الحق جلّ جلاله : { وإِنَّ لوطاً لمنَ المرسلين إِذ نجيناه } أي : واذكر إذ نجيناه { وأهلَه أجمعين إِلا عجوزاً في الغابرين } في الباقين ؛ لأنها شاركتهم في عصيانهم ،  فحقّ عليهم العذاب مثل ما حقّ عليهم .  <br />
