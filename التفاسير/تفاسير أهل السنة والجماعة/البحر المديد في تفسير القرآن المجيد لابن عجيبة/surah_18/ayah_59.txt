{ وتلك القرى } ؛ أي : قرى عاد وثمود وأضرابها ،  أي : وأهل تلك القرى { أهلكناهم } بالعذاب { لمَّا ظلموا } أي : وقت ظلمهم ،  كما فعلت قريش بما حكى عنهم ،  { وجعلنا لمهلكهم } أي : عَيَّنَّا لهلاكهم { موعدًا } أي : وقتًا مُعَينًا ،  لا محيدَ لهم عن ذلك ،  فلتعتبر قريش بذلك ولا تغتر .   والله تعالى أعلم .  <br />
