{ أو } كراهة أن { تقولوا } أيضًا : { لو أنا أُنزل علينا الكتابُ } كما أنزل إليهم ،  { لكُنا أهدى منهم } لحدة أذهاننا وثقابة أفهامنا ،  ولذلك تلقفنا فنونًا من العلم ،  كالقصص والأشعار والخطب والأنساب ،  مع كوننا أميين ،  قال تعالى لهم : { فقد جاءكم بينة من ربكم } وهو القرآن ؛ حجة واضحة تعرفونها ؛ { وهدى ورحمةٌ } لمن تدبره وعمل به ،  { فمن أظلم } أي : لا أحد أظلم { ممّن كذَّب بآيات الله } بعد أن عرف صحتها ،  { وصَدَف } ؛ أعرض { عنها سنجزي الذين يصدفون عن آياتنا سوء العذاب } ؛ ألمه وقبحه ،  { بما كانوا يصدفون } أي : يعرضون ويصدون عنها .  <br />
