ثم رد على أهل الضلالة ما زعموا ،  من نفع الأصنام لهم ،  فقال :<br />
{ وَاتَّخَذُواْ مِن دُونِ اللَّهِ آلِهَةً لِّيَكُونُواْ لَهُمْ عِزّاً } * { كَلاَّ سَيَكْفُرُونَ بِعِبَادَتِهِمْ وَيَكُونُونَ عَلَيْهِمْ ضِدّاً } * { أَلَمْ تَرَ أَنَّآ أَرْسَلْنَا الشَّيَاطِينَ عَلَى الْكَافِرِينَ تَؤُزُّهُمْ أَزّاً } * { فَلاَ تَعْجَلْ عَلَيْهِمْ إِنَّمَا نَعُدُّ لَهُمْ عَدّاً }<br />
يقول الحقّ جلّ جلاله : واتخذ المشركون الأصنام { آلهةً } يعبدونها من دون الله { ليكونوا لهم عِزًّا } يوم القيامة ،  ووصلة عنده يشفعون لهم .  <br />
/خ84
