{ إِنْ هي } أي : هذه الأصنام { إِلاَّ أسماءٌ } وليس تحتها في الحقيقة مسميات ؛ لأنكم تدّعون لها الألوهية ،  وهي أبعد شيء منها ،  { سميتموها } آلهة ،  أو : سميتم بها هذه الأصنام ،  واعتقدتم أنها آلهة ،  بمقتضى أهوائكم الباطلة ،  { أنتم وآباؤكم ما أنزل اللّهُ بها } بعبادتها { من سلطان } من حجة .   { إِن يتبعونَ } فيما ذكر من التسمية والعمل بموجبها { إلاَّ الظنَّ } : إلا توهم أنَّ ما هم عليه حق ،  توهُّماً باطلاً ،  { وما تهوى الأنفُسُ } أي : ما تشتهيه أنفسهم الأمّارة ،  { ولقد جاءهم من ربهم الهدى } الرسول والكتاب فتركوه .  <br />
