ثم ذكر برهانا آخر على قدرته تعالى ،  فقال :<br />
{ وَمِنْ آيَاتِهِ الْجَوَارِ فِي الْبَحْرِ كَالأَعْلاَمِ } * { إِن يَشَأْ يُسْكِنِ الرِّيحَ فَيَظْلَلْنَ رَوَاكِدَ عَلَى ظَهْرِهِ إِنَّ فِي ذَلِكَ لآيَاتٍ لِّكُلِّ صَبَّارٍ شَكُورٍ } * { أَوْ يُوبِقْهُنَّ بِمَا كَسَبُوا وَيَعْفُ عَن كَثِيرٍ } * { وَيَعْلَمَ الَّذِينَ يُجَادِلُونَ فِي آيَاتِنَا مَا لَهُمْ مِّن مَّحِيصٍ } .  <br />
يقول الحق جلّ جلاله : { ومن آياته } للدلالة على قدرته ووحدانيته { الجواري } السفن الجارية { في البحر كالأعلام } ؛ كالجبال .  <br />
