قال تعالى :<br />
بسم الله الرحمان الرحيم<br />
{ الم } * { تِلْكَ آيَاتُ الْكِتَابِ الْحَكِيمِ } * { هُدًى وَرَحْمَةً لِّلْمُحْسِنِينَ } * { الَّذِينَ يُقِيمُونَ الصَّلاَةَ وَيُؤْتُونَ الزَّكَاةَ وَهُمْ بِالآخِرَةِ هُمْ يُوقِنُونَ } * { أُوْلَئِكَ عَلَى هُدًى مِّن رَّبِّهِمْ وَأُوْلَئِكَ هُمُ الْمُفْلِحُونَ } .  <br />
يقول الحق جل جلاله : { الم } ؛ أيها المصطفى المقرب .  <br />
