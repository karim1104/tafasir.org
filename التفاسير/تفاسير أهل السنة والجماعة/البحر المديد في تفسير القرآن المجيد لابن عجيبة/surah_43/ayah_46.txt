ثم سلى رسوله بقوله :<br />
{ وَلَقَدْ أَرْسَلْنَا مُوسَى بِآَيَاتِنَا إِلَى فِرْعَوْنَ وَمَلَئِهِ فَقَالَ إِنِّي رَسُولُ رَبِّ الْعَالَمِينَ }*{ فَلَمَّا جَاءَهُمْ بِآيَاتِنَا إِذَا هُمْ مِنْهَا يَضْحَكُونَ }*{ وَمَا نُرِيهِمْ مِنْ آَيَةٍ إِلَّا هِيَ أَكْبَرُ مِنْ أُخْتِهَا وَأَخَذْنَاهُمْ بِالْعَذَابِ لَعَلَّهُمْ يَرْجِعُونَ }*{ وَقَالُوا يَا أَيُّهَا السَّاحِرُ ادْعُ لَنَا رَبَّكَ بِمَا عَهِدَ عِنْدَكَ إِنَّنَا لَمُهْتَدُونَ }*{ فَلَمَّا كَشَفْنَا عَنْهُمُ الْعَذَابَ إِذَا هُمْ يَنْكُثُونَ } .  <br />
يقول الحق جلّ جلاله : { ولقد أرسلنا موسى بآياتنا } أي : متلبساً بآياتنا { إِلى فرعون وملَئِه فقال إِني رسولُ رب العالمين } فأجابوه بقولهم : { فأتنا بآية إن كنت من الصادقين } كما صرّح به في آية أخرى{[1008]} .  <br />
