ثم ذكر إقرار المشركين بالربوبية ،  فقال :<br />
{ وَلَئِنْ سَأَلْتَهُمْ مَنْ خَلَقَهُمْ لَيَقُولُنَّ اللَّهُ فَأَنَّى يُؤْفَكُونَ }*{ وَقِيلِهِ يَا رَبِّ إِنَّ هَؤُلَاءِ قَوْمٌ لَا يُؤْمِنُونَ }*{ فَاصْفَحْ عَنْهُمْ وَقُلْ سَلَامٌ فَسَوْفَ يَعْلَمُونَ } .  <br />
يقول الحق جلّ جلاله : { ولئن سألتَهُم } أي : المشركين ،  أو : العابدين والمعبودين { مَنْ خلقهمْ ليقولُونَّ اللّهُ } لا الأصنام والملائكة { فأنَّى يُؤفكون } فكيف يصرفون عن عبادته إلى عبادة غيره ،  مع كون الكل مخلوقاً له تعالى .  <br />
