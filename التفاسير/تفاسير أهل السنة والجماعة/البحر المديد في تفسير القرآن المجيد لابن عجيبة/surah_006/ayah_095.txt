ثم شرع يذكر دلائل توحيده وتعريف ذاته ،  فقال :<br />
{ إِنَّ اللَّهَ فَالِقُ الْحَبِّ وَالنَّوَى يُخْرِجُ الْحَيَّ مِنَ الْمَيِّتِ وَمُخْرِجُ الْمَيِّتِ مِنَ الْحَيِّ ذالِكُمُ اللَّهُ فَأَنَّى تُؤْفَكُونَ فَالِقُ الإِصْبَاحِ وَجَعَلَ الْلَّيْلَ سَكَناً وَالشَّمْسَ وَالْقَمَرَ حُسْبَاناً ذالِكَ تَقْدِيرُ الْعَزِيزِ الْعَلِيمِ }<br />
قلت : { ومُخرج } : معطوف على { فالق } ،  على المختار ؛ لأنَّ { يُخرج الحي }  واقع موقع البيان له .  <br />
يقول الحقّ جلّ جلاله : { إن الله فالق الحب والنوى } أي : يفلق الحب تحت الأرض لخروج النبات منها ،  ويفلق النوى لخروج الشجر منها ،  { يُخرج الحي } أي : كل ما ينمو من الحيوان والنبات ؛ ليطابق ما قبله ،  { من الميت } مما لا ينمو كالنطف والحب .   { ومُخرِج الميت من الحي } أي : ومخرج الحب والنُّطَف من الحي ،  { ذلكم الله } أي : ذلكم المخرج والمحيي المُميت هو الله المستحق للعبادة دون غيره ،  { فأَنَّى تُؤفكون } ؛ تُصرفون عنه إلى غيره .  <br />
