ثم أخبر عمن سبق له الشقاء ،  فلا ينفع فيه سؤال ولا صحبة ،  فقال :<br />
{ إِنَّ الَّذِينَ حَقَّتْ عَلَيْهِمْ كَلِمَتُ رَبِّكَ لاَ يُؤْمِنُونَ } * { وَلَوْ جَآءَتْهُمْ كُلُّ آيَةٍ حَتَّى يَرَوُاْ الْعَذَابَ الأَلِيمَ }<br />
يقول الحق جل جلاله : { إن الذين حقتْ } أي : ثبتت { عليهم كلمة ربك } بأنهم لا يؤمنون ،  أو بأنهم مخلدون في العذاب { لا يؤمنون } أبداً ؛ إذ لا يكذب كلامه ولا ينتقض قضاؤه .  <br />
