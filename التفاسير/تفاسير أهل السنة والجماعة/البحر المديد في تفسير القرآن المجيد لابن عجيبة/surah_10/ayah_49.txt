ثم أجاب عن قولهم متى هذا الوعد ،  فقال :<br />
{ قُل لاَّ أَمْلِكُ لِنَفْسِي ضَرّاً وَلاَ نَفْعاً إِلاَّ مَا شَآءَ اللَّهُ لِكُلِّ أُمَّةٍ أَجَلٌ إِذَا جَآءَ أَجَلُهُمْ فَلاَ يَسْتَأْخِرُونَ سَاعَةً وَلاَ يَسْتَقْدِمُونَ } * { قُلْ أَرَأَيْتُمْ إِنْ أَتَاكُمْ عَذَابُهُ بَيَاتاً أَوْ نَهَاراً مَّاذَا يَسْتَعْجِلُ مِنْهُ الْمُجْرِمُونَ } * { أَثُمَّ إِذَا مَا وَقَعَ آمَنْتُمْ بِهِ الآنَ وَقَدْ كُنتُم بِهِ تَسْتَعْجِلُونَ } * { ثُمَّ قِيلَ لِلَّذِينَ ظَلَمُواْ ذُوقُواْ عَذَابَ الْخُلْدِ هَلْ تُجْزَوْنَ إِلاَّ بِمَا كُنتُمْ تَكْسِبُونَ }<br />
/م49<br />
يقول الحق جل جلاله : { قل } لهم : { لا أملكُ لنفسي ضراً ولا نفعاً } ،  فكيف أملك لكم ما تستعجلون من طلب العذاب ؟ { إلا ما شاءَ اللهُ } : لكن ما شاء الله من ذلك يكون ،  أو : لا أملك إلا ما ملكني ربي بمشيئته وقدرته ،  { لكلِّ أمةٍ أجلٌ } مضروب إلى هلاكهم ،  { إذا جاء أجَلُهُمْ فلا يستأخرون } عنه { ساعةً } ،  { ولا } هم { يستقدمون } عنه فلا تستعجلوا ،  فسيحين وقتكم وينجز وعدكم .  <br />
