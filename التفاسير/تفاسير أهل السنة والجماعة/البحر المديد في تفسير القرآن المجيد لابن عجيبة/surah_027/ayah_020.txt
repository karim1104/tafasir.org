ثم قال تعالى :<br />
{ وَتَفَقَّدَ الطَّيْرَ فَقَالَ مَالِيَ لاَ أَرَى الْهُدْهُدَ أَمْ كَانَ مِنَ الْغَآئِبِينَ } * { لأُعَذِّبَنَّهُ عَذَاباً شَدِيداً أَوْ لأَذْبَحَنَّهُ أَوْ لَيَأْتِيَنِّي بِسُلْطَانٍ مُّبِينٍ } * { فَمَكَثَ غَيْرَ بَعِيدٍ فَقَالَ أَحَطتُ بِمَا لَمْ تُحِطْ بِهِ وَجِئْتُكَ مِن سَبَإٍ بِنَبَإٍ يَقِينٍ } * { إِنِّي وَجَدتُّ امْرَأَةً تَمْلِكُهُمْ وَأُوتِيَتْ مِن كُلِّ شَيْءٍ وَلَهَا عَرْشٌ عَظِيمٌ } * { وَجَدتُّهَا وَقَوْمَهَا يَسْجُدُونَ لِلشَّمْسِ مِن دُونِ اللَّهِ وَزَيَّنَ لَهُمُ الشَّيْطَانُ أَعْمَالَهُمْ فَصَدَّهُمْ عَنِ السَّبِيلِ فَهُمْ لاَ يَهْتَدُونَ } * { أَلاَّ يَسْجُدُواْ للَّهِ الَّذِي يُخْرِجُ الْخَبْءَ فِي السَّمَاوَاتِ وَالأَرْضِ وَيَعْلَمُ مَا تُخْفُونَ وَمَا تُعْلِنُونَ } * { اللَّهُ لاَ إِلَهَ إِلاَّ هُوَ رَبُّ الْعَرْشِ الْعَظِيمِ }<br />
يقول الحق جل جلاله : { وتفقَّدَ } سليمانُ { الطيرَ } أي : تعرف أحوال الطير تعرف َالمَلِك لمملكته ،  حسبما تقتضيه عناية الملك بمملكته ،  والاهتمام بكل جزء منها ،  أو : تفقده لمعرفته بالماء ،  أو لغير ذلك على ما يأتي .   فلما تفقده لم ير الهدهد فيما بينها .   والتفقد : طلب ما غاب عنك .   { فقال ماليَ لا أرى الهدهد } أساتر ستره ؟ { أم كان من الغائبين } ،  و  " أم "  : بمعنى  " بل "  .   كأنه قال : ما لي لا أراه ؟ ثم بدا له أنه غائب ،  فأضرب عنه ،  وقال : بل هو من الغائبين .  <br />
