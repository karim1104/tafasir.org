ثم ذكر ابتداء رسالة موسى عليه السلام ،  فقال :<br />
{ اذْهَبْ إِلَى فِرْعَوْنَ إِنَّهُ طَغَى } * { قَالَ رَبِّ اشْرَحْ لِي صَدْرِي } * { وَيَسِّرْ لِيا أَمْرِي } * { وَاحْلُلْ عُقْدَةً مِّن لِّسَانِي } * { يَفْقَهُواْ قَوْلِي } * { وَاجْعَل لِّي وَزِيراً مِّنْ أَهْلِي } * { هَارُونَ أَخِي } * { اشْدُدْ بِهِ أَزْرِي } * { وَأَشْرِكْهُ فِيا أَمْرِي } * { كَيْ نُسَبِّحَكَ كَثِيراً } * { وَنَذْكُرَكَ كَثِيراً } * { إِنَّكَ كُنتَ بِنَا بَصِيراً }<br />
يقول الحقّ جلّ جلاله : لنبيه موسى عليه السلام : { اذهبْ إِلى فرعونَ } بما رأيته من الآيات الكبرى .   وادعه إلى عبادتي وحدي ،  وحذره من نقمتي ،  { إِنه طغى } أي : جاوز الحد في التكبر والعتو والتجبر ،  حتى تجاسر على دعوى الربوبية .  <br />
