{ قُلْ } لأولئك الكفرة المتمردين : { كُلٌّ } أي : كل واحد منكم ومنا ،  { متربصٌ } : منتظر ما يؤول إليه أمرنا وأمركم ،  { فتربصوا } فانتظروا .   أو كُلٌّ منتظر دوائر الزمان ،  ولمن يكون النصر ،  { فتربصوا فستعلمون } عن قريب { من أصحابُ الصراطِ السَّوِيِّ } أي : المستقيم ،  أو السواء ،  أي : الوسط الجيد ،  { ومن اهتدى } من الضلالة ،  هل نحن أو أنتم .   والله تعالى أعلم .  <br />
