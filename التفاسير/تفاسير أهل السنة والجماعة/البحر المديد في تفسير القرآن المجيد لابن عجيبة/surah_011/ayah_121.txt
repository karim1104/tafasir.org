ثم أمره بتهديد من خالفه ،  فقال :<br />
{ وَقُل لِّلَّذِينَ لاَ يُؤْمِنُونَ اعْمَلُواْ عَلَى مَكَانَتِكُمْ إِنَّا عَامِلُونَ } * { وَانْتَظِرُواْ إِنَّا مُنتَظِرُونَ } * { وَللَّهِ غَيْبُ السَّمَاوَاتِ وَالأَرْضِ وَإِلَيْهِ يُرْجَعُ الأَمْرُ كُلُّهُ فَاعْبُدْهُ وَتَوَكَّلْ عَلَيْهِ وَمَا رَبُّكَ بِغَافِلٍ عَمَّا تَعْمَلُونَ }<br />
يقول الحق جل جلاله : { وقل للذين لا يؤمنون اعملوا على مكانتكم } : حالهم ،  { إنا عاملون } على حالنا .  <br />
