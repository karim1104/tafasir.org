{ وإن كنا لمبتلين } :  " إنْ "  : مخففة ،  واسمها : ضمير الشأن ،  واللام فارقة .  <br />
{ إِنَّ في ذلك } فيما فعل بنوح وقومه { لآياتِ } : لعبراً ومواعظ ،  { وإن كنا } أي : وإن الشأن والقصة كنا { لمبتلين } : مُصيبين قوم نوح ببلاء عظيم وعقاب شديد ،  أو : مختبرين بهذه الآيات عبادنا ،  لننظر من يعتبر ويذكر ،  كقوله : { وَلَقَدْ تَّرَكْنَاهَا آيَةً فَهَلْ مِن مُّدَّكِرٍ } [ القمر : 15 ] .   والله تعالى أعلم .  <br />
