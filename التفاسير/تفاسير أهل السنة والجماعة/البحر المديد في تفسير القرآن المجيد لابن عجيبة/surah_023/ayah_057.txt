ثم ذكر أهل القرب ،  إثر بيان أهل البعد ،  فقال :<br />
{ إِنَّ الَّذِينَ هُم مِّنْ خَشْيةِ رَبِّهِمْ مُّشْفِقُونَ } * { وَالَّذِينَ هُم بِآيَاتِ رَبَّهِمْ يُؤْمِنُونَ } * { وَالَّذِينَ هُم بِرَبِّهِمْ لاَ يُشْرِكُونَ } * { وَالَّذِينَ يُؤْتُونَ مَآ آتَواْ وَّقُلُوبُهُمْ وَجِلَةٌ أَنَّهُمْ إِلَى رَبِّهِمْ رَاجِعُونَ } * { أُوْلَئِكَ يُسَارِعُونَ فِي الْخَيْرَاتِ وَهُمْ لَهَا سَابِقُونَ } * { وَلاَ نُكَلِّفُ نَفْساً إِلاَّ وُسْعَهَا وَلَدَيْنَا كِتَابٌ يَنطِقُ بِالْحَقِّ وَهُمْ لاَ يُظْلَمُونَ }<br />
/م57<br />
يقول الحق جل جلاله : { إن الذين هم من خشية ربهم مشفقون } أي : من عذابه خائفون حذرون .  <br />
