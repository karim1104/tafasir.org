قال تعالى : { وما نُرسل المرسلين } إلى الأمم { إِلا مبشرين ومنذرين } أي : مبشرين للمؤمنين بالثواب ،  ومنذرين للكافرين بالعقاب ،  دون إظهار الآيات واقتراح المعجزات ،  { ويُجادل الذين كفروا بالباطل } ؛ باقتراح الآيات ؛ كالسؤال عن قصة أصحاب الكهف ونحوها .   يفعلون ذلك { ليُدْحِضُوا به } أي : بالجدال { الحقَّ } ،  أي : يزيلونه عن مركزه ويبطلونه ،  من إدحاض القدم وهو إزلاقها .   وجدالهم : قولهم لرسلهم عليهم السلام : { مَآ أَنتُمْ إِلاَّ بَشَرٌ } [ يس : 15 ] ،  { وَلَوْ شَآءَ اللَّهُ لأَنزَلَ مَلاَئِكَةً }<br />
[ المؤمنون : 24 ] ،  ونحوها .   { واتخذوا آياتي } التي تخرّ لها صُمُّ الجبال ،  وهو القرآن ،  { وما أنذروا } أي : وإنذاري لهم ،  أو : الذي أنذروا به من العذاب والعقاب ،  { هُزُوًا } ؛ مهزوءًا به ،  أو محل استهزاء .  <br />
