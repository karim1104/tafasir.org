ثم ذكر سير ذي القرنين إلى جهة المشرق ،  فقال :<br />
{ ثُمَّ أَتْبَعَ سَبَباً } * { حَتَّى إِذَا بَلَغَ مَطْلِعَ الشَّمْسِ وَجَدَهَا تَطْلُعُ عَلَى قَوْمٍ لَّمْ نَجْعَل لَّهُمْ مِّن دُونِهَا سِتْراً } * { كَذَلِكَ وَقَدْ أَحَطْنَا بِمَا لَدَيْهِ خُبْراً }<br />
يقول الحقّ جلّ جلاله : { ثم أَتْبَع } ذو القرنين { سببًا } : طريقًا راجعًا من مغرب الشمس ،  موصلاً إلى مشرقها .  <br />
