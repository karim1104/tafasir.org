ثم ذكر قصة هلاك قوم لوط ،  فقال :<br />
{ فَلَمَّا جَآءَ آلَ لُوطٍ الْمُرْسَلُونَ } * { قَالَ إِنَّكُمْ قَوْمٌ مُّنكَرُونَ } * { قَالُواْ بَلْ جِئْنَاكَ بِمَا كَانُواْ فِيهِ يَمْتَرُونَ } * { وَآتَيْنَاكَ بِالْحَقِّ وَإِنَّا لَصَادِقُونَ } * { فَأَسْرِ بِأَهْلِكَ بِقِطْعٍ مِّنَ اللَّيْلِ وَاتَّبِعْ أَدْبَارَهُمْ وَلاَ يَلْتَفِتْ مِنكُمْ أَحَدٌ وَامْضُواْ حَيْثُ تُؤْمَرُونَ } * { وَقَضَيْنَآ إِلَيْهِ ذَلِكَ الأَمْرَ أَنَّ دَابِرَ هَؤُلآءِ مَقْطُوعٌ مُّصْبِحِينَ } * { وَجَآءَ أَهْلُ الْمَدِينَةِ يَسْتَبْشِرُونَ } * { قَالَ إِنَّ هَؤُلآءِ ضَيْفِي فَلاَ تَفْضَحُونِ } * { وَاتَّقُواْ اللَّهَ وَلاَ تُخْزُونِ } * { قَالُواْ أَوَ لَمْ نَنْهَكَ عَنِ الْعَالَمِينَ } * { قَالَ هَؤُلآءِ بَنَاتِي إِن كُنْتُمْ فَاعِلِينَ } * { لَعَمْرُكَ إِنَّهُمْ لَفِي سَكْرَتِهِمْ يَعْمَهُونَ } * { فَأَخَذَتْهُمُ الصَّيْحَةُ مُشْرِقِينَ } * { فَجَعَلْنَا عَالِيَهَا سَافِلَهَا وَأَمْطَرْنَا عَلَيْهِمْ حِجَارَةً مِّن سِجِّيلٍ } * { إِنَّ فِي ذَلِكَ لآيَاتٍ لِلْمُتَوَسِّمِينَ } * { وَإِنَّهَا لَبِسَبِيلٍ مُّقِيمٍ } * { إِنَّ فِي ذَلِكَ لآيَةً لِلْمُؤْمِنِينَ }<br />
يقول الحق جل جلاله : { فلما جاء آلَ لوطٍ المرسلين } ،  وهم أضياف إبراهيم ،  فلما دخلوا عليه ولم يعرفهم .  <br />
