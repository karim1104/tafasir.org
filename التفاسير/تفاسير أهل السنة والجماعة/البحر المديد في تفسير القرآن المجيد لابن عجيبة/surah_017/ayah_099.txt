ثم ذكر دلائل عموم قدرته ،  فقال :<br />
{ أَوَلَمْ يَرَوْاْ أَنَّ اللَّهَ الَّذِي خَلَقَ السَّمَاوَاتِ وَالأَرْضَ قَادِرٌ عَلَى أَن يَخْلُقَ مِثْلَهُمْ وَجَعَلَ لَهُمْ أَجَلاً لاَّ رَيْبَ فِيهِ فَأَبَى الظَّالِمُونَ إِلاَّ كُفُوراً } * { قُل لَّوْ أَنْتُمْ تَمْلِكُونَ خَزَآئِنَ رَحْمَةِ رَبِّي إِذاً لأمْسَكْتُمْ خَشْيَةَ الإِنْفَاقِ وَكَانَ الإنْسَانُ قَتُوراً }<br />
قلت : { وجعل } : عطف على  " قادر "  ؛ لأنه في قوة قدر ،  أو استئناف .  <br />
يقول الحقّ جلّ جلاله : { أوَ لم يَروا } أي : أوَ لم يتفكروا ولم يعلموا { أنَّ الله الذي خلق السماواتِ والأرضَ } من غير مادة ،  مع عِظمها ،  { قادرٌ على أن يخلق مثلهم } في الصِّغر والحقارة .   على أن المثل مقحم ،  أي : على أن يخلقهم خلقًا جديدًا ؛ فإنهم ليسوا أشد خلقًا منهم ،  ولا الإعادة بأصعب من الإبداء ،  { وجعل لهم } أي : لموتهم وبعثهم { أجلاً } محققًا { لا ريب فيه } وهو : القيامة .   { فأبى الظالمون إِلا كفورًا } ؛ إلا جحودًا ،  وضع الظاهر موضع الضمير ؛ تسجيلاً عليهم بالظلم وتجاوز الحد فيه .  <br />
