ومن علامة السعادة : التمسك بما جاء به القرآن العظيم ،  كما قال تعالى :<br />
{ إِنَّ هَذَا الْقُرْآنَ يَِهْدِي لِلَّتِي هِيَ أَقْوَمُ وَيُبَشِّرُ الْمُؤْمِنِينَ الَّذِينَ يَعْمَلُونَ الصَّالِحَاتِ أَنَّ لَهُمْ أَجْراً كَبِيراً } * { وأَنَّ الَّذِينَ لاَ يُؤْمِنُونَ بِالآخِرَةِ أَعْتَدْنَا لَهُمْ عَذَاباً أَلِيماً }<br />
يقول الحقّ جلّ جلاله : { إِنَّ هذا القرآن يَهدي للتي } ؛ للطريق التي { هي أقومُ } الطرق وأعدلها ،  { ويُبشِّرُ المؤمنين الذين يعملون } الأعمال { الصالحاتِ أنَّ لهم أجرًا كبيرًا } وهو : الخلود في النعيم المقيم ،  وزيادة النظر إلى وجهه الكريم .  <br />
/خ10
