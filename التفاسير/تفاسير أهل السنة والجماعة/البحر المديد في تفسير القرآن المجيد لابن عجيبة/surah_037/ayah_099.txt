ثم ذكر هجرة إبراهيم ،  وما امتحن به ،  فقال :<br />
{ وَقَالَ إِنِّي ذَاهِبٌ إِلَى رَبِّي سَيَهْدِينِ } * { رَبِّ هَبْ لِي مِنَ الصَّالِحِينَ } * { فَبَشَّرْنَاهُ بِغُلاَمٍ حَلِيمٍ } * { فَلَمَّا بَلَغَ مَعَهُ السَّعْيَ قَالَ يا بُنَيَّ إِنِّي أَرَى فِي الْمَنَامِ أَنِّي أَذْبَحُكَ فَانظُرْ مَاذَا تَرَى قَالَ يا أَبَتِ افْعَلْ مَا تُؤمَرُ سَتَجِدُنِي إِن شَآءَ اللَّهُ مِنَ الصَّابِرِينَ } * { فَلَمَّا أَسْلَمَا وَتَلَّهُ لِلْجَبِينِ } * { وَنَادَيْنَاهُ أَن يا إِبْرَاهِيمُ } * { قَدْ صَدَّقْتَ الرُّؤْيَآ إِنَّا كَذَلِكَ نَجْزِي الْمُحْسِنِينَ } * { إِنَّ هَذَا لَهُوَ الْبَلاَءُ الْمُبِينُ } * { وَفَدَيْنَاهُ بِذِبْحٍ عَظِيمٍ } * { وَتَرَكْنَا عَلَيْهِ فِي الآخِرِينَ } * { سَلاَمٌ عَلَى إِبْرَاهِيمَ } * { كَذَلِكَ نَجْزِي الْمُحْسِنِينَ } * { إِنَّهُ مِنْ عِبَادِنَا الْمُؤْمِنِينَ } .  <br />
يقول الحق جلّ جلاله : { وقال } إبراهيمُ : { إِني ذاهبٌ إِلى ربي } إلى موضع أمرني ربي بالذهاب إليه ،  وهو الشام ،  أو : إلى مرضاة ربي ،  بامتثال أمره بالهجرة أو : إلى المكان الذي أتجرّد فيه إلى عبادة ربي ،  { سَيَهدين } أي : سيرشدني إلى ما فيه صلاح ديني ،  أو : إلى مقصدي ،  وإنما بتَّ القول لسبق وعده ؛ لأن الله وعده بالهداية ،  أو : لفرط توكله ،  أو : للبناء على عادته معه .   ولم يكن كذلك حال موسى عليه السلام حيث عبَّر بما يقتضي الرجاء{[934]} .  <br />
