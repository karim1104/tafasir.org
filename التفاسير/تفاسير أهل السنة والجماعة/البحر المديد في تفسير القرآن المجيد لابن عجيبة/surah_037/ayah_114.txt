ثم ذكر موسى وهارون ،  فقال :<br />
{ وَلَقَدْ مَنَنَّا عَلَى مُوسَى وَهَارُونَ } * { وَنَجَّيْنَاهُمَا وَقَوْمَهُمَا مِنَ الْكَرْبِ الْعَظِيمِ } * { وَنَصَرْنَاهُمْ فَكَانُواْ هُمُ الْغَالِبِينَ } * { وَآتَيْنَاهُمَا الْكِتَابَ الْمُسْتَبِينَ } * { وَهَدَيْنَاهُمَا الصِّرَاطَ الْمُسْتَقِيمَ } * { وَتَرَكْنَا عَلَيْهِمَا فِي الآخِرِينَ } * { سَلاَمٌ عَلَى مُوسَى وَهَارُونَ } * { إِنَّا كَذَلِكَ نَجْزِي الْمُحْسِنِينَ } * { إِنَّهُمَا مِنْ عِبَادِنَا الْمُؤْمِنِينَ } .  <br />
يقول الحق جلّ جلاله : { ولقد منَنَّا } أنعمنا { على موسى وهارونَ } بالنبوة وغيرها من المنافع الدينية والدنيوية .  <br />
