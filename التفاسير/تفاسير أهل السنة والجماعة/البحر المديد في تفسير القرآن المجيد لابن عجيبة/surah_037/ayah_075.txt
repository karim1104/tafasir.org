ثم ذكر أول المنذرين من أولي العزم ،  فقال :<br />
{ وَلَقَدْ نَادَانَا نُوحٌ فَلَنِعْمَ الْمُجِيبُونَ } * { وَنَجَّيْنَاهُ وَأَهْلَهُ مِنَ الْكَرْبِ الْعَظِيمِ } * { وَجَعَلْنَا ذُرِّيَّتَهُ هُمُ الْبَاقِينَ } * { وَتَرَكْنَا عَلَيْهِ فِي الآخِرِينَ } * { سَلاَمٌ عَلَى نُوحٍ فِي الْعَالَمِينَ } * { إِنَّا كَذَلِكَ نَجْزِي الْمُحْسِنِينَ } * { إِنَّهُ مِنْ عِبَادِنَا الْمُؤْمِنِينَ } * { ثُمَّ أَغْرَقْنَا الآخَرِينَ } .  <br />
يقول الحق جلّ جلاله : { ولقد نادانا } أي : دعانا { نوحٌ } حين أيس من قومه بقوله :<br />
{ أَنِّى مَغْلُوبٌ فَانتَصِرْ } [ القمر : 10 ] أو : دعانا ؛ لِنُنجيه من الغرق ،  { فَلَنِعْمَ المجيبون } أي : فأجبناه أحسن الإجابة ،  ونصرناه على أعدائه ،  وانتقمنا منهم بأبلغ ما يكون ،  فوالله لَنِعْمَ المجيبون نحنُ ،  فحذف القسم ؛ لدلالة اللام عليه .   وحذف المخصوص ،  والجمع ؛ دليل العظمة والكبرياء .  <br />
