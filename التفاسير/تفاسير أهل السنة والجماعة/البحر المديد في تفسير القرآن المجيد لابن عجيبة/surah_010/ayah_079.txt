ثم ذكر معارضة فرعون ،  فقال :<br />
{ وَقَالَ فِرْعَوْنُ ائْتُونِي بِكُلِّ سَاحِرٍ عَلِيمٍ } * { فَلَمَّا جَآءَ السَّحَرَةُ قَالَ لَهُمْ مُّوسَى أَلْقُواْ مَآ أَنتُمْ مُّلْقُونَ } * { فَلَمَّآ أَلْقُواْ قَالَ مُوسَى مَا جِئْتُمْ بِهِ السِّحْرُ إِنَّ اللَّهَ سَيُبْطِلُهُ إِنَّ اللَّهَ لاَ يُصْلِحُ عَمَلَ الْمُفْسِدِينَ } * { وَيُحِقُّ اللَّهُ الْحَقَّ بِكَلِمَاتِهِ وَلَوْ كَرِهَ الْمُجْرِمُونَ }<br />
يقول الحق جل جلاله : { وقال فرعونُ } لما أراد معارضة موسى عليه السلام : { ائتوني بكلِّ ساحرٍ } ،  في قراءة الأخوين  " سحَّار "  ،  { عليم } : حاذق في فنه .  <br />
