ثم ذكر عتو فرعون وطغيانه ،  فقال :<br />
{ وَقَالَ فَرْعَوْنُ يا هَامَانُ ابْنِ لِي صَرْحاً لَّعَلِّي أَبْلُغُ الأَسْبَابَ } * { أَسْبَابَ السَّمَاوَاتِ فَأَطَّلِعَ إِلَى إِلَهِ مُوسَى وَإِنِّي لأَظُنُّهُ كَاذِباً وَكَذَلِكَ زُيِّنَ لِفِرْعَوْنَ سُواءُ عَمَلِهِ وَصُدَّ عَنِ السَّبِيلِ وَمَا كَيْدُ فِرْعَوْنَ إِلاَّ فِي تَبَابٍ } .  <br />
يقول الحق جلّ جلاله : { وقال فرعونُ } تمويهاً على قومه ،  وجهلاً منه : { يا هامانِ } وزيره { ابنِ لي صَرْحاً } أي : قصراً عالياً ،  وقيل : الصرح : البناء الظاهر الذي لا يخفى على الناظر وإن بَعُد منه .   يقال : صَرِح الشيءُ : إذا ظهر .   { لعلِّي أبلُغُ الأسبابَ } أي : الطرق .  <br />
