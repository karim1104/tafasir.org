{ يعلمُ ما يَلِجُ } ما يدخل { في الأرض } من الأموات والدفائن ،  { وما يخرج منها } من النبات وجواهر المعادن ،  { وما ينزلُ من السماء } من الأمطار وأنواع البركات ،  { وما يعرجُ } يصعد { فيها } من الملائكة والدعوات ،  { وهو الرحيمُ } بإنزال ما يحتاجون إليه ،  { الغفورُ } بما يجترئون عليه .   قاله النسفي .  <br />
