ثم أمر نبيه بالجواب عما أنكروه من البعث ،  فقال :<br />
{ قُلْ كُونُواْ حِجَارَةً أَوْ حَدِيداً } * { أَوْ خَلْقاً مِّمَّا يَكْبُرُ فِي صُدُورِكُمْ فَسَيَقُولُونَ مَن يُعِيدُنَا قُلِ الَّذِي فَطَرَكُمْ أَوَّلَ مَرَّةٍ فَسَيُنْغِضُونَ إِلَيْكَ رُؤُوسَهُمْ وَيَقُولُونَ مَتَى هُوَ قُلْ عَسَى أَن يَكُونَ قَرِيباً } * { يَوْمَ يَدْعُوكُمْ فَتَسْتَجِيبُونَ بِحَمْدِهِ وَتَظُنُّونَ إِن لَّبِثْتُمْ إِلاَّ قَلِيلاً }<br />
يقول الحقّ جلّ جلاله : { قلْ } يا محمد لمن أنكر البعث : { كُونوا حجارة أو حديدًا أو خلقًا } .  <br />
