{ قالوا نعبد أصناماً } ،  وجواب { ما تعبدون } : هو قولهم : { أصناماً } ؛ لأن السؤال وقع عن المعبود لا عن العبادة ،  فكان حق الجواب أن يقولوا : أصناماً ،  كقوله تعالى :<br />
{ وَيَسْأَلُونَكَ مَاذَا يُنفِقُونَ قُلِ الْعَفْوَ } [ البقرة : 219 ] ،  وكقوله تعالى : { مَاذَا قَالَ رَبُّكُمْ قَالُواْ الْحَقَّ } [ سبأ : 23 ] .   لكنهم أطنبوا فيه بإظهار العامل ؛ قصداً إلى إبراز ما في نفوسهم الخبيثة من الابتهاج والافتخار بعبادتها ،  { فنظلُّ لها عاكفين } أي : فنقيم على عبادتها طول النهار .   وإنما قالوا : { فنظل } ؛ لأنهم كانوا يعبدونها بالنهار دون الليل : أو : يراد به الدوام .  <br />
