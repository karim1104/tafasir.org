ثم هددهم بنزول العذاب ،  فقال :<br />
{ أَفَبِعَذَابِنَا يَسْتَعْجِلُونَ } * { أَفَرَأَيْتَ إِن مَّتَّعْنَاهُمْ سِنِينَ } * { ثُمَّ جَآءَهُم مَّا كَانُواْ يُوعَدُونَ } * { مَآ أَغْنَى عَنْهُمْ مَّا كَانُواْ يُمَتَّعُونَ } * { وَمَآ أَهْلَكْنَا مِن قَرْيَةٍ إِلاَّ لَهَا مُنذِرُونَ } * { ذِكْرَى وَمَا كُنَّا ظَالِمِينَ }<br />
يقول الحق جل جلاله : توبيخاً لمن اقترح نزول العذاب ،  كقولهم : { فَأَمْطِرْ عَلَيْنَا حِجَارَةً مِّنَ السَّمَآءِ أَوِ ائْتِنَا بِعَذَابٍ أَلِيمٍ } [ الأنفال : 32 ] { أفبعذابنا يستعجلون } مع كونهم لا يطيقونه إذا نزل بهم ؟ وتقديم الجار ؛ للإيذان بأن مصب الإنكار والتوبيخ هو كون المُسْتَعْجَلِ به عذابَه ،  مع ما فيه من رعاية الفواصل .  <br />
