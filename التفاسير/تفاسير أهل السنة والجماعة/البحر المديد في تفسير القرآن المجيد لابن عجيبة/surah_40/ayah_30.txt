ثم قال تعالى :<br />
{ وَقَالَ الَّذِي آمَنَ يا قَوْمِ إِنِّي أَخَافُ عَلَيْكُمْ مِّثْلَ يَوْمِ الأَحْزَابِ } * { مِثْلَ دَأْبِ قَوْمِ نُوحٍ وَعَادٍ وَثَمُودَ وَالَّذِينَ مِن بَعْدِهِمْ وَمَا اللَّهُ يُرِيدُ ظُلْماً لِّلْعِبَادِ } * { وَيا قَوْمِ إِنِّي أَخَافُ عَلَيْكُمْ يَوْمَ التَّنَادِ } * { يَوْمَ تُوَلُّونَ مُدْبِرِينَ مَا لَكُمْ مِّنَ اللَّهِ مِنْ عَاصِمٍ وَمَن يُضْلِلِ اللَّهُ فَمَا لَهُ مِنْ هَادٍ } .  <br />
يقول الحق جلّ جلاله : { وقال الذي آمن } مخاطباً قومه : { يا قوم إِني أخافُ عليكم } في تكذيب موسى ،  والتعرُّض له بسوء ،  { مثلَ يومِ الأحزاب } أي : مثل أيام الأمم الماضية المتحزبة على رسلها ،  يعني وقائعهم .   وجمْعُ الأحزاب مع التفسير أغنى عن جمع اليوم ،  أي : بالإضافة ،  وفسره بقوله : { مثلَ دأبِ قومِ نوحٍ وعادٍ وثمودَ والذين من بعدهم } .  <br />
