{ ولو ترى } يا محمد { إذِ المجرمون } وهو الذين قالوا : { أئذا ضللنا في الأرض .   .   .   } إلخ ،  و " لو "  و " إذ "  للماضي ،  وإنما جاز هنا ؛ لأن المُتَرَقَّبَ محقق الوقوع ،  و " ترى "  هنا ،  تامة لا مفعول لها ،  أي : لو وقعت منك رؤيةٌ { إذ المجرمون ناكسوا رؤوسِهم } أي : وقت كون المجرمين ناكسي رؤوسهم من الذل والحياء والندم ،  { عند ربهم } ؛ عند حساب ربهم ،  قائلين : { ربنا أبصَرْنا وسَمِعْنا } أي : صدَّقنا الآن وعدك ووعيدك ،  وأبصرنا ما حدثَتْنا به الرسلُ ،  وسمعنا منك تصديق رسلك ،  { فارجعنا } إلى الدنيا { نعملْ صالحاً } من الإيمان والطاعة ،  { إِنا موقنون } بالبعث والحساب الآن .   وجواب  " لو "  : محذوف ،  أي : لرأيت أمراً فظيعاً .  <br />
