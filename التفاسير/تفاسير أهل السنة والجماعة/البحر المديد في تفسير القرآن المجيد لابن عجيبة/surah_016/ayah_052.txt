و{ واصبًا } : حال من { الدين } .  <br />
{ وله ما في السماوات والأرض } ؛ خلقًا وملكًا وعبيدًا ،  { وله الدين } أي : الطاعة والانقياد { واصباً } : لازماً ،  أو : واجباً وثابتاً ؛ لما تقرر أنه الإله وحده ،  والحقيق بأن يرهَبَ منه ،  فلا يُدَان لأحد إلا هو .   وقيل : { وله الدِّينُ } أي : الجزاء { واصِبًا } أي : دائمًا ،  فلا ينقطع ثوابه لمن آمن ،  ولا عقابه لمن كفر .   { أفغير الله تتقون } مع أنه ليس بيد غيره نفع ولا ضر ؟ !<br />
