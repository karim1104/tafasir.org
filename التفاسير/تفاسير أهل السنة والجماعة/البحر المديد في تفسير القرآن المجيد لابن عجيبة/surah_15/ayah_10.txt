ثم تمم تلك التسلية ،  فقال :<br />
{ وَلَقَدْ أَرْسَلْنَا مِن قَبْلِكَ فِي شِيَعِ الأَوَّلِينَ } * { وَمَا يَأْتِيهِم مِّن رَّسُولٍ إِلاَّ كَانُواْ بِهِ يَسْتَهْزِئُونَ } * { كَذَلِكَ نَسْلُكُهُ فِي قُلُوبِ الْمُجْرِمِينَ } * { لاَ يُؤْمِنُونَ بِهِ وَقَدْ خَلَتْ سُنَّةُ الأَوَّلِينَ } * { وَلَوْ فَتَحْنَا عَلَيْهِم بَاباً مِّنَ السَّمَاءِ فَظَلُّواْ فِيهِ يَعْرُجُونَ } * { لَقَالُواْ إِنَّمَا سُكِّرَتْ أَبْصَارُنَا بَلْ نَحْنُ قَوْمٌ مَّسْحُورُونَ }<br />
يقول الحق جل جلاله : في تسلية رسوله  عليه الصلاة والسلام  { ولقد أرسلنا مِن قبْلِكَ } رسلاً { في شِيَعٍ } : فرق { الأولين } أي : القرون الماضية ،  جمع شيعة ،  وهي : الفرقة المتفقة على طريق واحد ،  وتتشيع لمذهب أو رجل ،  من شاعه إذا تبعه ،  أي : نبأنا رجالاً فيهم ،  وجعلناهم رسلاً إليهم ،  فكذبوهم واستهزؤوا بهم ،  فكانوا : { ما يأتيهم من رسول إلا كانوا به يستهزئون } كما يفعل بك هؤلاء المجرمون .  <br />
