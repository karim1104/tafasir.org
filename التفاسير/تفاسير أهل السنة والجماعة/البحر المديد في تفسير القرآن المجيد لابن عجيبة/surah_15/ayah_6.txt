ثم أجاب من اقترح الآيات ،  فقال :<br />
{ وَقَالُواْ يا أَيُّهَا الَّذِي نُزِّلَ عَلَيْهِ الذِّكْرُ إِنَّكَ لَمَجْنُونٌ } * { لَّوْ مَا تَأْتِينَا بِالْمَلائِكَةِ إِن كُنتَ مِنَ الصَّادِقِينَ } * { مَا نُنَزِّلُ الْمَلائِكَةَ إِلاَّ بِالحَقِّ وَمَا كَانُواْ إِذاً مُّنظَرِينَ } * { إِنَّا نَحْنُ نَزَّلْنَا الذِّكْرَ وَإِنَّا لَهُ لَحَافِظُونَ }<br />
يقول الحق جل جلاله : { وقالوا } ؛ أي : كفار قريش : { يا أيها الذين نُزِّل عليه الذكْرُ } في زعمه ،  أو قالوه تَهكماً ،  { إنك لمجنون } أي : إنك لتقول قول المجانين ،  حين تدعي أنه ينزل عليك الذكر ،  أي : القرآن .  <br />
/خ9
