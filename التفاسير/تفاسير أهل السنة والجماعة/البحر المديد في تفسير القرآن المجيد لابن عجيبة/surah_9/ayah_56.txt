ثم ذكر وصف نفاق المنافقين ،  فقال :<br />
{ وَيَحْلِفُونَ بِاللَّهِ إِنَّهُمْ لَمِنكُمْ وَمَا هُم مِّنكُمْ وَلَكِنَّهُمْ قَوْمٌ يَفْرَقُونَ } * { لَوْ يَجِدُونَ مَلْجَئاً أَوْ مَغَارَاتٍ أَوْ مُدَّخَلاً لَّوَلَّوْاْ إِلَيْهِ وَهُمْ يَجْمَحُونَ }<br />
قلت : الفَرَقُ : الخوف .  <br />
يقول الحق جل جلاله : { ويحلفون } لكم { بالله إنهم لمنكم } أي : من جملة المسلمين ،  { وما هم منكم } ؛ لكفر قلوبهم ،  { ولكنهم قوم يَفْرقُون } : يخافون منكم أن تفعلوا بهم ما تفعلون بالمشركين ،  فيظهرون الإسلام تقية وخوفاً .  <br />
