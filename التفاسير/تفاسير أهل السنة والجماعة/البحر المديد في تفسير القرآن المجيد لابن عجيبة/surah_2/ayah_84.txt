ثم وبخهم على نقض عهد آخر ،  فقال :{ وَإِذْ أَخَذْنَا مِيثَاقَكُمْ لاَ تَسْفِكُونَ دِمَآءَكُمْ وَلاَ تُخْرِجُونَ أَنْفُسَكُمْ مِّن دِيَارِكُمْ ثُمَّ أَقْرَرْتُمْ وَأَنْتُمْ تَشْهَدُونَ } * { ثُمَّ أَنْتُمْ هَؤُلاءِ تَقْتُلُونَ أَنْفُسَكُمْ وَتُخْرِجُونَ فَرِيقاً مِّنْكُمْ مِّن دِيَارِهِمْ تَظَاهَرُونَ عَلَيْهِمْ بِالإِثْمِ وَالْعُدْوَانِ وَإِن يَأتُوكُمْ أُسَارَى تُفَادُوهُمْ وَهُوَ مُحَرَّمٌ عَلَيْكُمْ إِخْرَاجُهُمْ أَفَتُؤْمِنُونَ بِبَعْضِ الْكِتَابِ وَتَكْفُرُونَ بِبَعْضٍ فَمَا جَزَآءُ مَن يَفْعَلُ ذالِكَ مِنكُمْ إِلاَّ خِزْيٌ فِي الْحَيَاةِ الدُّنْيَا وَيَوْمَ الْقِيَامَةِ يُرَدُّونَ إِلَى أَشَدِّ الّعَذَابِ وَمَا اللَّهُ بِغَافِلٍ عَمَّا تَعْمَلُونَ }<br />
يقول الحقّ جلّ جلاله : { و } اذكروا أيضاً { إِذْ أَخْذْنَا ميثَاقَكُمْ } وقلنا لكم : { لا تَسْفِكُونَ دِمَاءَكُمْ } أي : لا يسفك بعضكم دم بعض ،  { وَلا تُخْرِجُونَ أَنفُسَكُم مِّن دِيَارِكُمْ } أي : لا يخرج أحدكم أخاه من داره ويجليه عنها ،  وجعلهم الحق نفساً واحدة ،  وذلك هو في الحقيقة ،  وفي ذلك يقول الشاعر :<br />
عُنْصُرُ الأنفاسِ مِنَّا واحِدٌ *** وكّذا الأجْسَامُ جِسْمٌ عَمَّنَا<br />
{ ثُمَّ أَقْرَرْتُمْ } بهذا العهد والتزمتموه لأنفسكم { وَأَنْتُمْ تَشْهَدُونَ } على أنفسكم بذلك .  <br />
