و{ إلا أن يعفون } مبنى ؛ لاتصاله بنون النسوة ،  ووزنه : يفعُلن كقوله تعالى : { السِّجْنُ أَحَبُّ إِلَى مِمَّا يَدْعُونَنِي إِلَيْهِ } [ يُوسُف : 33 ] ،  وقوله : { وَالْقَوَاعِدُ مِنَ النِّسآءِ الَّتي لاَ يَرْجُونَ نِكَاحاً } [ النُّور : 60 ] .  <br />
وإن طلقتموهن بعد المسيس فالصداق كامل ،  { وإن طلقتموهن من قبل أن تمسوهن وقد فرضتم لهن } صداقاً { فنصف ما فرضتم } يجب عليكم ،  { إلا أن يعفون } أي : النساء ،  عن نصف الصداق ،  { أو يعفو الذي بيده عقدة النكاح } ،  وهو الأب في ابنته البكر ؛ قاله مالك ،  أو الزوج بأن يدفعه كاملاً ،  قاله الشافعي ،  { وأن تعفوا } أيها الأولياء عن الزوج ،  فلا تقبضوا منه شيئاً ،  { أقرب للتقوى } ؛ لأن المرأة لم يذهب لها شيء فسلُعتُها قائمة ،  { ولا تنسوا الفضل } والإحسان { بينكم } فتسامحوا يسمح لكم ،  { إن الله بما تعملون بصير } لا يخفى عليه شيء من أعمالكم ،  فيجازي المحسن بإحسانه ،  { والله يحب المحسنين } .  <br />
