{ واقتلوهم حيث ثقفتموهم } أي : وجدتموهم ،  ولا تتحرجوا من قتالهم في الحرم ،  فإنهم هم الذين صدوكم وبدأوكم بالإذاية ،  { وأخرجوهم } من مكة { حيث أخرجوكم } منها ،  { والفتنة } أي : الكفر الذي هم فيه ،  { أشد من القتل } لهم في الحرم ،  { ولا تقاتلوهم عند المسجد الحرام } ابتداءً { حتى يقاتلوكم فيه ،  فإن قاتلوكم } فيه { فاقتلوهم } فيه ،  وفي غيره ،  { كذلك جزاء الكافرين } يفعل بهم ما فعلوا بغيرهم .  <br />
