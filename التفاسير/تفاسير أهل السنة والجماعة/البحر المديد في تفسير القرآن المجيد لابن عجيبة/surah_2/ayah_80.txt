ثم ذكر الحق تعالى بعض أمانيهم الفارغة ،  فقال :{ وَقَالُواْ لَن تَمَسَّنَا النَّارُ إِلاَّ أَيَّاماً مَّعْدُودَةً قُلْ أَتَّخَذْتُمْ عِندَ اللَّهِ عَهْداً فَلَنْ يُخْلِفَ اللَّهُ عَهْدَهُ أَمْ تَقُولُونَ عَلَى اللَّهِ مَا لاَ تَعْلَمُونَ } * { بَلَى مَن كَسَبَ سَيِّئَةً وَأَحَاطَتْ بِهِ خَطِيائَتُهُ فَأُوْلَئِكَ أَصْحَابُ النَّارِ هُمْ فِيهَا خَالِدُونَ } * { وَالَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ أُولَئِكَ أَصْحَابُ الْجَنَّةِ هُمْ فِيهَا خَالِدُونَ }<br />
يقول الحقّ جلّ جلاله : { وَقَالُوا } أي : بنو إسرائيل في أمانيهم الباطلة : { لَن تَمَسَّنَا النَّارُ إلاَّ أَيَّاماً مَّعْدُودَةً } أربعين يوماً مقدار عبادة العجل ،  ثم يخلفنا فيها المسلمون .  <br />
قال الحقّ جلّ جلاله : { قُلْ } لهم يا محمد : { أَتَّخَذْتُمْ } بذلك عهداً عند الله { فَلَن يُخْلِفَ اللّهُ عَهْدَهُ أَمْ تَقُولُونَ عَلَى اللّهِ مَا لا تَعْلَمُونَ } .  <br />
