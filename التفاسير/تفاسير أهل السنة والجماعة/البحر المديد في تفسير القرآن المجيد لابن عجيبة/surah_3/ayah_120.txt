ومن فرط عداوتهم أنهم { إن تمسسكم حسنة } كنصر وغنيمة { تسوءهم } أي ،  تحزنهم ،  { وإن تصبكم سيئة } كهزيمة أو قتل أو إصابة عدو منكم أو اختلاف بينكم ،  { يفرحوا بها وإن تصبروا } على عداوتهم وأذاهم ،  وتخافوا ربكم ،  { وتتقوا } ما نهاكم عنه ،  { لا يضركم كيدهم شيئاً } ،  بفضل الله وحفظه ،  الموعود للصابرين والمتقين ،  { إِنَّ اللَّهَ مَعَ الصَّابِرِينَ } [ البقرة : 153 ] ،  { إِنَّ اللَّهَ مَعَ الَّذِينَ اتَّقَواْ } [ النحل : 128 ] .   ومن كان الحق معه لا يضره شيء ،  { إن الله بما يعملون محيط } ؛ لا يخفى عليه ما يعمل أهل الكفر من العداوة والحقد ،  فيجازيهم عليه .  <br />
