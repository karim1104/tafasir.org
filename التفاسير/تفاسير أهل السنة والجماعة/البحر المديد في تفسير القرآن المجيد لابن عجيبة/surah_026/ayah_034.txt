{ قَالَ لِلْمَلإِ حَوْلَهُ إِنَّ هَذَا لَسَاحِرٌ عَلِيمٌ } * { يُرِيدُ أَن يُخْرِجَكُمْ مِّنْ أَرْضِكُمْ بِسِحْرِهِ فَمَاذَا تَأْمُرُونَ } * { قَالُواْ أَرْجِهْ وَأَخَاهُ وَابْعَثْ فِي الْمَدَآئِنِ حَاشِرِينَ } * { يَأْتُوكَ بِكُلِّ سَحَّارٍ عَلِيمٍ }<br />
قلت : ( حوله ) : ظرف وقع موقع الحال ،  أي : مستقرين حوله .  <br />
يقول الحق جل جلاله : { قال } فرعونُ ،  لَمَّا رأى ما بهته وحيّره ،  { للملإِ حولَه } ،  وهم أشراف قومه : { إنَّ هذا لساحِرٌ عليم } ؛ فائق في فن السحر .  <br />
