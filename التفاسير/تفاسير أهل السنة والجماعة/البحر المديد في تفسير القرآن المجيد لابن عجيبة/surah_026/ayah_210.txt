ثم تمم قوله : { وإنه لتنزيل رب العالمين } ،  بقوله :<br />
{ وَمَا تَنَزَّلَتْ بِهِ الشَّيَاطِينُ } * { وَمَا يَنبَغِي لَهُمْ وَمَا يَسْتَطِيعُونَ } * { إِنَّهُمْ عَنِ السَّمْعِ لَمَعْزُولُونَ } * { فَلاَ تَدْعُ مَعَ اللَّهِ إِلَهاً آخَرَ فَتَكُونَ مِنَ الْمُعَذَّبِينَ }<br />
يقول الحق جل جلاله : { وما تنزلت به } ؛ بالقرآن ،  { الشياطينُ } ،  رداً لما يزعمه الكفرة من أنه من قبيل ما تلقيه الشياطين على الكهنة ،  بعد تحقيق الحق فيه ،  ببيان أنه نزل به الروح الأمين .  <br />
