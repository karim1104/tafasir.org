اذكر يا أكمل الرسل { يَوْمَئِذٍ يَصْدُرُ } ويرجع ويعود { ٱلنَّاسُ } عن موقف العرض والحساب { أَشْتَاتاً } متفرقين، متحزبين حسب مراتبهم في الحساب، كل منهم مع شاكلته { لِّيُرَوْاْ أَعْمَالَهُمْ } [الزلزلة: 6] أي: أجزئتهم المعدة لهم في الجنة والنار.  وبالجملة: { فَمَن يَعْمَلْ مِثْقَالَ ذَرَّةٍ } أي: مقدار نملة صغيرة ووزنها { خَيْراً يَرَهُ } [الزلزلة: 7] أي: يرى جزاءها في الجنة.  { وَمَن يَعْـمَلْ مِثْقَالَ ذَرَّةٍ شَرّاً يَرَهُ } [الزلزلة: 8] أي: جاءها في النار.  وهذه الآية أحكم آية وأقسطها، من الآيات الدالة على كمال العدل الإلهي وأشملها حكماً، لذلك قال صلى الله عليه وسلم: " { إِذَا زُلْزِلَتِ } تعدل نصف القرآن، و: { قُلْ هُوَ ٱللَّهُ أَحَدٌ } تعدل ثلث القرآن، و: { قُلْ يٰأَيُّهَا ٱلْكَافِرُونَ } تعدل ربع القرآن ".  خاتمة السورة  عليك أيها المتوجه نحو الحق أن تأتي وتتصف بصوالح الأعمال، وتجتنب عن فواسدها؛ لترى أحسن الجزاء، وتزيد عليها على مقتضى إخلاصك فيها وخشوعك في إتيانها، فلك أن تجعل مضمون هذه الآية نصب عينيك في عموم أحوالك وأعمالك؛ لتكون على ذكر تام وفطنة كاملة، مما يترتب على أعمالك من الجزاء.  جعلنا الله من زمرة المتذكرين الممتثلين بمقتضى هذه الآية.
