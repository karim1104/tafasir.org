{ أَ } يشكون في نزول العذاب ويترددون و { لَمْ يَرَوْاْ كَمْ أَهْلَكْنَا مِن قَبْلِهِم مِّن قَرْنٍ } من أهل القرون الماضية كعاد وثمود وغيرهما مع أنا { مَّكَّنَّٰهُمْ فِي ٱلأَرْضِ } أي: قدرناهم فيها قادرين على أمور عظام وآثام جسام { مَا لَمْ نُمَكِّن لَّكُمْ } ولم نجعل في وسعكم من السعة وطول الملك والترفه والاستيلاء { وَ } مع ذلك { أَرْسَلْنَا ٱلسَّمَآءَ } المطر { عَلَيْهِم مِّدْرَاراً } مغزاراً كثيرة { وَجَعَلْنَا ٱلأَنْهَارَ تَجْرِي مِن تَحْتِهِمْ } دائماً متجدداً، وبالجملة: أمهلناهم زماناً طويلاً متنعمين مترفهين { فَأَهْلَكْنَٰهُمْ } بالمرة { بِذُنُوبِهِمْ } التي صدرت عنهم من تكذيب الأنبياء وما جاءوا به، وإفسادهم في الأرض بأنواع الفسادات { وَأَنْشَأْنَا مِن بَعْدِهِمْ قَرْناً آخَرِينَ } [الأنعام: 6].  ولا تبالِ يا أكرم الرسل بتكذيبهم واقتراحاتهم، ولا ترجُ منهم الإيمنا بلك وبكتابك؛ لأنهم من غاية انهماكهم في الضلال.  { وَلَوْ نَزَّلْنَا } من مقام جودنا { عَلَيْكَ كِتَٰباً } مكتوباً { فِي قِرْطَاسٍ } ورق { فَلَمَسُوهُ بِأَيْدِيهِمْ } حين نزوله { لَقَالَ ٱلَّذِينَ كَفَرُواْ } من خبث باطنهم وجهلهم الجبلي { إِنْ هَـٰذَآ } أي: ما هذا { إِلاَّ سِحْرٌ مُّبِينٌ } [الأنعام: 7] عظيم ظاهر؛ لأن الورق لا تنزل من جانب السماء إلا بسحر.  { وَقَالُواْ } من غاية شقاقهم ونفاقهم معك: إن كان نبياً { لَوْلاۤ } هلا { أُنزِلَ عَلَيْهِ مَلَكٌ } ويصدقه بنبوته فنصدقه، قل لهم في جوابهم نيابة عنا: { وَلَوْ أَنزَلْنَا مَلَكاً } على مقتضى سنتنا في الأمم الماضية { لَّقُضِيَ ٱلأَمْرُ } أي: لتحقق أمر إهلاكهم البتة { ثُمَّ } بعد نزول الملك بل تعذبون كالأمم السالفة { لاَ يُنظَرُونَ } [الأنعام: 8] ولا يمهلون ساعة ولينكرون ويعذبون البتة.
