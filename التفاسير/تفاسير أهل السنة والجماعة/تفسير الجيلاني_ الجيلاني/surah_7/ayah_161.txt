{ وَ } من جملة ظلمهم على نفوسهم: إنهم { إِذْ قِيلَ لَهُمُ } وأوصي إليهم إصلاحاً لحالهم: { ٱسْكُنُواْ هَـٰذِهِ ٱلْقَرْيَةَ } أي: بيت المقدس { وَكُلُواْ مِنْهَا } أي: من مأكولاتها المتسعة { حَيْثُ شِئْتُمْ } بلا موافقة ومنع { وَقُولُواْ } متضرعين إلينا، متوجهين نحونا: { حِطَّةٌ } أي: سؤالنا منك يا مولانا: حط ما صدر عنا من الآثام وجرى علينا من المعاصي { وَٱدْخُلُواْ ٱلْبَابَ } سجداً؛ أي: باب بيت المقدس { سُجَّداً } متذللين واضعين جباهكم على تراب المذلة والهوان؛ تأديباً وتعظيماً { نَّغْفِرْ لَكُمْ خَطِيۤئَاتِكُمْ } أي: جميعها إن امتثلتهم ما أمرناكم بها؛ بل { سَنَزِيدُ ٱلْمُحْسِنِينَ } [الأعراف: 161] منكم بالرضوان الأكبر منَّا.  { فَبَدَّلَ ٱلَّذِينَ ظَلَمُواْ مِنْهُمْ } أنفسهم بالخروج عمَّا أمرناهم { قَوْلاً } صداقاً صواباً قلنا لهم؛ لإصلح حالهم { غَيْرَ ٱلَّذِي قِيلَ لَهُمْ } على لسان رسلنا، بل حرفوها لفظاً ومعنى، كما مر بيانه في سورة البقرة { فَأَرْسَلْنَا عَلَيْهِمْ } بسبب تبديلهم وتحريفهم { رِجْزاً مِّنَ ٱلسَّمَآءِ } أي: عذاباً نازلاً من جانب السماء { بِمَا كَانُواْ يَظْلِمُونَ } [الأعراف: 162] أي: بشؤم خروجهم عن مقتضى أوامرنا وأحكامنا.
