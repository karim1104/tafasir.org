{ يَا أَهْلَ ٱلْكِتَابِ } أي: اليهود والنصارى المجبولين على الكفر والنفاق { قَدْ جَآءَكُمْ رَسُولُنَا } أضافه إلى نفسه؛ تعظيماً وتوقيراً { يُبَيِّنُ } ويظهر { لَكُمْ كَثِيراً مِّمَّا كُنْتُمْ تُخْفُونَ مِنَ ٱلْكِتَابِ } من أوامره ونواهيه، وأخباره المتعلقة بالزمان الماضي والآتي، سيما نعت خاتم الأنبياء والرسل - صلوات الله عليه وسلامه - وإنمَّا يبيِّن لكم المذكورات؛ لئلا يفوت منكم شيء من أمور الدين، ولا يؤخذون بها.  { وَ } مع ذلك { يَعْفُواْ } ويصفح { عَن } تبيين { كَثِيرٍ } من مخفياتكم من الكتب ممَّا لا يترتب عليه العذاب والنكال، فعليكم أن تؤمنوا به، وبما جاء به من عند ربه لإهدائكم إلى طريق توحيده؛ إذ { قَدْ جَآءَكُمْ مِّنَ ٱللَّهِ } معه { نُورٌ } واضح { وَ } هو { كِتَابٌ مُّبِينٌ } [المائدة: 15] ظاهر لائح هدايته وإرشاده.  { يَهْدِي بِهِ ٱللَّهُ } الهادي لعباده { مَنِ ٱتَّبَعَ } منهم { رِضْوَانَهُ } أي: يرضى به { سُبُلَ ٱلسَّلاَمِ } أي: طريق التوحيد الموصلة إلى سلامة الوحدة، المسماة عند بدار السلام { وَيُخْرِجُهُمْ } أيك المتبعين رضوان { مِّنِ ٱلظُّلُمَاتِ } ظلمة العدم، وظلمة الإمكان وظلمة التعينات { إِلَى ٱلنُّورِ } أي: الوجود البحث، الخالص عن شوب الظلمة؛ إذ هو نور على نور، يهدي الله لنوره من يشاء من أهل العناية، وإنما يخرجهم { بِإِذْنِهِ } وتوفيقه، وجذب { وَ } بالجملمة: { يَهْدِيهِمْ } أن سيق لهم العناية منه { إِلَىٰ صِرَاطٍ مُّسْتَقِيمٍ } [المائدة: 16] موصل إلى توحيده.
