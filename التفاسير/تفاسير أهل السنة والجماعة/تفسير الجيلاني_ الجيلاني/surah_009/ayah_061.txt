ثمَّ بيَّن سبحانه مصارف الصدقات فقال: { إِنَّمَا ٱلصَّدَقَاتُ } أي: الزكوات يصرف { لِلْفُقَرَآءِ } وهم الذين لا مال لهم ولا مكسب لهم من الحرث وغيره، كأنه يكسر فقار ظهرهم الفاقة والاحتياج { وَٱلْمَسَاكِينِ } الذين لهم مكسب وصنعة، لكن لا تفي لعيالهم كأن الاحتياج أسكنهم في زاوية المسكنة والهوان { وَٱلْعَامِلِينَ عَلَيْهَا } أي: الساعين لجمعها وإيصالها إلى مصارفها { وَٱلْمُؤَلَّفَةِ قُلُوبُهُمْ } وهم الذين قرب عهد إسلامهم، يجب على المسلمين مؤانستهم ومواساتهم؛ ليقروا على الإيمان { وَ } يصرف منها أيضاً { فِي ٱلرِّقَابِ } أي: فكها من الرق وتحريرها، وهو من أهم مهمات الإسلام { وَٱلْغَارِمِينَ } الذين استغرق أموالهم في ديونهم ولم تفِ لأدائها، يُصرف إليهم منها؛ ليؤديها.  { وَ } يُصرف منها سهم { فِي سَبِيلِ ٱللَّهِ } لتجهيز جيوش أهل الجهاد وتهيئة أسبابهم وعُددهم؛ إذ هو من أهم مهمات هذا الدين { وَٱبْنِ ٱلسَّبِيلِ } الذي انقطع عن الأهل والمال لمصلحة شرعية، إنماجرى هذه القسمة لهؤلاء المستحقين { فَرِيضَةً } صادرة { مِّنَ ٱللَّهِ } مقدرة من عنده؛ ليحافظ المؤمنون عليها { وَٱللَّهُ } المدبر لأمور عباده { عَلِيمٌ } بمصارف الصدقات { حَكِيمٌ } [التوبة: 60] في صرفها إياهم تقويةً لهم وإمداداً.  { وَمِنْهُمُ ٱلَّذِينَ يُؤْذُونَ ٱلنَّبِيَّ } ويسيئون الأدب معه { وَيِقُولُونَ } في حقه افتراءً واستهانةً: { هُوَ أُذُنٌ } أي: سمع كله ليس له دربة ودراية وتعمق في المعارف الحقائق، بل يسمع منَّا ويجري على ما سمع بلا تفتيش وتدبر { قُلْ } لهم يا أكمل الرسل: إنما أذن لكم لا أذن شر وفتنة، بل { أُذُنُ خَيْرٍ لَّكُمْ } إن صدر عنكم ما يتعلق بأمور دينكم، موافقاً لما أمر الله به يقبله منكم؛ لأنه صلى الله عليه وسلم { يُؤْمِنُ بِٱللَّهِ } أي: يقر ويصدق بوحدانيته { وَيُؤْمِنُ } أيضاً { لِلْمُؤْمِنِينَ } المخلصين فيما أتوا به من الأعمال والأقوال الصادرة عن الإخلاص { وَ } كيف لا يكون الرسول أذن خير؛ إذ هو كله { رَحْمَةٌ } أي: شفقة وعطف { لِّلَّذِينَ آمَنُواْ مِنكُمْ } وأخلصوا في إيمانهم؟! { وَ } بالجملة: { ٱلَّذِينَ يُؤْذُونَ رَسُولَ ٱللَّهِ } بأي وجه كان { لَهُمْ عَذَابٌ أَلِيمٌ } [التوبة: 61] في النشاة الأخرى؛ جزاءً لما أتوا به من إيذاء رسوله.
