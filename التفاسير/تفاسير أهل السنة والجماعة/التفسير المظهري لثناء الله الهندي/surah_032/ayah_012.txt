ثم ذكر الله سبحانه حالهم بعد الحشر فقال { ولو ترى } يا محمد { إذ المجرمون } أي المشركين الذين { قالوا إذا ضللنا في الأرض ءإنا لفي خلق } { ناكسوا رءوسهم } حال من الضمير في المجرمون { عند ربهم } ندامة وحزنا يقولون حال من فاعل ناكسوا أو حال مرادف له أو استئناف في جواب ما يقولون حينئذ { ربنا أبصرنا } ما وعدتنا وكان مكذبيه { وسمعنا } منك تصديق رسلك فيما كذبناهم وقيل معناه أبصرنا معاصينا وسمعنا ما قيل فينا { فارجعنا } إلى الدني { نعمل } عملا { صالحا } مجزوم في جواب الدعاء { إنا موقنون } الآن بما كنا شاكين فيه قبل وجواب لو محذوف تقديره لرأيت أمرا فظيعا ويجوز أن يكون لو للتمني والمضي في لو وإذا كان الثابت في علم الله بمنزلة الواقع ولا يقدر لترى مفعول لأن المعنى لو يكون منك رؤية في هذا الوقت أو يقدر ما دل عليه صلة إذ يعني لو ترى نكوس رؤوسهم<br />
