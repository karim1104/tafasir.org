{ وجعلنا منهم } أي من بني إسرائيل { أئمة } قادة في الخير يقتدى بهم يعني الأنبياء الذين كانوا فيهم وقال قتادة إتباع الأنبياء { يهدون } الناس على ما فيه من الأحكام { بأمرنا } إياهم أو بتوفيقنا لهم { لما صبروا } قرأ حمزة والكسائي لما بكسر اللام وتخفيف الميم أي لصبرهم والباقون بفتح اللام وتشديد الميم أي حين صبروا على دينهم وعلى البلاء من عدوهم بمصر وفيه دليل على أن الصبر يورث إمامة الناس { وكانوا بآياتنا يوقنون } لإمعانهم فيها بالنظر<br />
