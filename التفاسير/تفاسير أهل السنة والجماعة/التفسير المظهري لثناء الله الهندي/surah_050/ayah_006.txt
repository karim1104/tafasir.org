ثم رد تكذيبهم وأرشدهم إلا الاستدلال على قدرته على البعث بخلق العالم فقال : { أفلم ينظروا إلى السماء فوقهم كيف بنيناها وزيناها وما لها من فروج }{ أفلم ينظروا } الهمزة للإنكار والتوبيخ والفاء للعطف على محذوف تقديره أكذبوا بالبعث فلم ينظروا حين كذبوا به { إلى السماء فوقهم } حال من السماء أو ظرف متعلق بلم ينظروا { كيف } حال من مفعول { بنيناها } ورفعنا بلا عمد { وزيناها } بالكواكب وجملة بنيناها وزيناها بتأويل المفرد بدل من السماء والاستفهام بكيف للتقدير والمعنى ألم ينظروا إلى بنائها السماء فوقهم وتزيينها إياها بالكواكب متكيفة بكيفية بديعة راسخة { وما لها من فروج } أي شقوق ومن زائدة والجملة حال من مفعول بنيناها أي كائنة على حال ليس لها عيوب وشقوق<br />
