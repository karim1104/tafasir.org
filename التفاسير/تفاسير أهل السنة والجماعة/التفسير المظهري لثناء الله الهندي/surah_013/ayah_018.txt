{ للذين استجابوا } أي أجابوا { لربهم } دعوته إلى الإسلام وأطاعوه فيما أمرهم به { الحسنى } صفة لمصدر يعني الاستجابة الحسنى أو مفعول به يعني استجابوا لربهم الدعوة الحسنى { والذين لم يستجيبوا له } يعني الكفار واللام متعلقة بيضرب على أنه جعل ضرب المثل لشأن الفريقين ضرب المثل لهما ،  وقيل للذين استجابوا خبر الحسنى وهي التوبة الحسنى أو الجنة والذين لم يستجيبوا مبتدأ خبره { لو أن لهم ما في الأرض جميعا ومثله معه لاقتدوا به } يوم القيامة لفكاك أنفسهم من النار وعلى التأويل الثاني هذا كلام مبتدأ لمال غير المستجيبين { أولئك لهم سوء الحساب } وهو أن يناقش فيه ولا يغفر من ذنبه شيء كذا قال إبراهيم النخعي { ومأواهم جهنم وبئس المهاد } مهادهم وهو جهنم قال الله تعالى :{ لهم من جهنم مهاد ومن فوقهم غواش }18 .
