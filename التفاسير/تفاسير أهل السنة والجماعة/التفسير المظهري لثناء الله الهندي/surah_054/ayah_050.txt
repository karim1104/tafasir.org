{ وما أمرنا } في تكوين الأشياء وإعدامها وإعادتها { إلا واحدة } أي الأفعلة واحدة وهي الإيجاد والإمحاء بلا معالجة ومعناه أو إلا كلمة واحدة وهي قوله تعالى : كن في الإيجاد والصيحة في الإعدام والبعث كائنة في اليسر والسرعة { كلمح بالبصر } قال الكلبي عن ابن عباس وما أمرنا بمجيء في السرعة إلا كطرف البصر نظيره قوله تعالى { وما أمر الساعة إلا كلمح البصر أو هو أقرب } {[4782]}
