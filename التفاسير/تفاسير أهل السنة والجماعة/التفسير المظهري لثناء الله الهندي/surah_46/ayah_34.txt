{ ويوم يعرض الذين كفروا على النار } منصوب بقول مضمر تقديره يقال لهم { أليس هذا } إشارة إلى العذاب بالنار الذي ينكرونها في الدنيا { بالحق قالوا } أي الكفار في الجواب { بلى وربنا } يقسمون بالله ويعترفون به حين لا ينفعهم الإقرار { قال } أي يقول الله تعالى حينئذ { فذوقوا العذاب } الِفاء للسببية فإن كونها حقا مع إنكارهم إياها في الدنيا سبب للذوق { بما كنتم تكفرون } أي بسبب كفركم في الدنيا ومعنى الأمر هو الإهانة والتوبيخ وجملة ويوم يعرض إلى الخ متصلة بقوله { وَيَوْمَ يُعْرَضُ الَّذِينَ كَفَرُوا عَلَى النَّارِ أذهبتم طيباتكم }{[4518]} وما بينهما معترضات .
