{ فلما رأوه } الضمير عائد إلى ما تعدنا أو مبهم تفسيره { عارضا } أي هيئة سحاب يعرض أي يبدو في عرض السماء { مستقبل أوديتهم } وقد كانوا قد حبس عنهم المطر قبل ذلك سنتين ( وقد مر قصتهم في سورة الأعراف وغيرها ) استبشروا بها { قالوا هذا } الذي نراه { عارض } سحاب عرض { ممطرنا } أي يأتينا بالمطر قال الله تعالى أو قال هود ليس هذا سحابا ممطرا كما زعمتم { بل هو ما استعجلتم به } من العذاب { ريح } خبر مبتدأ محذوف أي هي أو بدل من الموصول { فيها عذاب } صفة لريح { أليم } صفة عذاب .  <br />
