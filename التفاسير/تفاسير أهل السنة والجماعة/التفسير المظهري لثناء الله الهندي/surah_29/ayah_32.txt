{ قال } إبراهيم { إن فيها لوطا } إعتراض علمهم بأن فيها من لم يظلم أو معارضة للموجب بالمانع وهو كون النبي بين أظهرهم { قالوا } أي الرسل وهم الملائكة { نحن أعلم } منك { بمن فيها لننجينه } قرأ حمزة والكسائي بالتخفيف من الأفعال والباقون بالتشديد من التفعيل { وأهله } تسليم لقوله مع إدعاء مزيد العلم وجواب عنه بتخصيص أهل القرية بمن عداه وعدى أهله أو تأقيت الإهلاك بإخراجهم عنها وفيه تأخير البيان عن الخطاب وذلك جائز وإنما لا يجوز تأخيره عن وقت الحاجة { إلا امرأته كانت } في علم الله تعالى { من الغابرين } الباقين في العذاب أو في القرية تعليل للاستثناء .  <br />
