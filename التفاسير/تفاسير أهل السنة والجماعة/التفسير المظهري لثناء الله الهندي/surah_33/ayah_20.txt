{ يحسبون الأحزاب لم يذهبوا }أي هؤلاء لجبنهم يظنون أن الأحزاب لم يذهبوا ففروا إلى داخل المدينة { وإن يأت الأحزاب } كرة ثانية { يودوا } تمنوا { لو أنهم بادون } يعني لو ثبت أنهم خارجون إلى البدو يقال بدا يبدأ بدوا وبداوة إذا خرج إلى البادية { في الأعراب } حال من الضمير في بادون أو خبر بعد خبر لأن أي كائنون في الإعراب { يسألون } كل قادم من المدينة { عن أنبائكم } أي عما جرى عليكم جملة يسألون خبر بعد خبر أو حال مترادف أو متداخل وجواب لو محذوف يعني لكان خيرا { ولو كانوا }يعني هؤلاء المنافقين { فيكم } ولم يفروا من عند كم في هذه الكرة وكان قتال { ما قاتلوا إلا قليلا }رياء وخوفا من التعيير كذا قال مقاتل<br />
