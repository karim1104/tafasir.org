{ تلك } الآيات آيات الله ،  دلائل قدرته ،  مبتدأ وخبر { نتلوها عليك } حال عاملها معنى الإشارة أو خبر ثان { بالحق } متلبسين به أو متلبسة به { فبأي حديث } الفاء جزائية تقديره فإن تؤمنوا بآيات الله فبأي حديث { بعد الله } أي بعد كتاب الله { وآياته } الدالة على وجوده { يؤمنون } أي كفار مكة لا يؤمنون .   قرأ ابن عامر وحمزة والكسائي وأبو بكر ويعقوب بالتاء الفوقانية على الالتفات من الغيبة إلى الخطاب والباقون بالتحتانية على الغيبة .  <br />
