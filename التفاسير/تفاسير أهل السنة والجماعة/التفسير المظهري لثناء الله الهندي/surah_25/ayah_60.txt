{ وإذا قيل لهم } عطف على قوله الذي خلق السماوات والأرض في ستة أيام ثم استوى على العرش الرحمان أو على جملة هو الرحمان { اسجدوا للرحمان قالوا وما الرحمن } لأنهم ما كانوا يطلقونه على الله وكانوا يقولون لا نعرف الرحمن إلا رحمن اليمامة يعنون مسيلمة الكذاب يسمونه رحمن لليمامة { أنسجد لما تأمرنا } أنت يا محمد كذا قرأ الجمهور بصيغة المخاطب خطابا  للنبي صلى الله عليه وسلم وقرأ حمزة والكسائي { لما يأمرنا } بصيغة الغائب يعنون لما يأمرنا محمد صلى الله عليه وسلم { وزادهم } عطف على قالوا يعني وزادهم الأمر بالسجود للرحمن { نفورا } عن الإيمان .  <br />
