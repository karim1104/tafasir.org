{ تبارك الذي جعل في السماء بروجا } قال الحسن ومجاهد وقتادة البروج هي النجوم الكبار سميت بروجا لظهورها وقال عطية العوفي بروجا قصورا فيها الحرس { وجعل فيها سراجا } يعني الشمس لقوله تعالى : { وجعل الشمس سراجا } {[3670]} قرأ حمزة والكسائي سرجا على الجمع وهي الشمس وسائر الكواكب سوى القمر فإنه ليس بسراج لأن السراج ما يضيء بنفسه والقمر نوره مستفاد من نور الشمس كما يدل عليه كماله ونقصانه على حسب مقابلة الشمس ويدل عليه العطف بقوله { وقمرا منيرا } مضيئا بالليل
