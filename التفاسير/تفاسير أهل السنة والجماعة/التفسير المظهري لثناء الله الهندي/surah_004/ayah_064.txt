{ وما أرسلنا من رسول إلا ليطاع } أي لإلزام طاعته على الناس فإنه المقصود من الرسالة { بإذن الله } أي بسبب إذنه وأمره المبعوث إليهم بأن يطيعوه فمن لم يرض بحكمه ولم يطعه استوجب القتل لأنه كأنه لم يقبل رسالته { ولو } ثبت { أنهم } أي المنافقون { إذ ظلموا أنفسهم } بالنفاق والتحاكم إلى الطاغوت { جاءوك } تائبين بالإخلاص وهو خبر أن والظرف متعلق به { فاستغفروا الله } بالتوبة عن النفاق واعتذروا إلى رسول الله النبي صلى الله عليه وسلم بالإخلاص { واستغفر لهم الرسول } عدل عن الخطاب إلى الغيبة تعظيما لشأنه وتنبيها على أن شأن الرسول يقتضي قبول العذر وإن عظم الجرم لوجدوا الله لعلموه توابا قابلا للتوبة { رحيما } عليهم ،  وجاز أن يكون وجد بمعنى صادف فحينئذ توابا منصوب على الحال ورحيما بدل منه أو حال من الضمير فيه أو حال مرادف له والله أعلم .  <br />
