{ قالوا ضلوا } أي غابوا { عنا } فلا نراهم وذلك قبل أن يقرن بهم آلهتهم أو المعنى ضاعوا عنا فلم نجد منهم ما كنا نتوقع منهم { بل لم نكن ندعو من قبل شيئًا } قيل هذا إنكار للإشراك مثل قولهم { والله ربنا ما كنا مشركين }{[4365]} وقيل معناه لم نكن ندعوا من قبل شيئا ينفعنا أو يدفع عنا المكروه ،  وقال الحسن بن الفضل أي لم نصنع من قبل شيئا أي ضاعت عبادتنا كما يقول من ضاع عمله ما كنت أعمل شيئا { كذلك } أي إضلالا مثل إضلال هؤلاء المشركين أو مثل إضلال القدرية { يضل الله الكافرين } أجمعين حتى لا يهتدوا إلى شيء ينفعهم
