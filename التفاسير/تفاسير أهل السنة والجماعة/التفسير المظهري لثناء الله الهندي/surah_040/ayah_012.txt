{ ذلكم } ويعني انتفاء سبيل للخروج وما أنتم فيه من العذاب { بأنه } أي بسبب أنه { إذا دعي الله وحده } { ذلكم } ويعني انتفاء سبيل للخروج وما أنتم فيه من العذاب { بأنه } أي بسبب أنه { إذا دعي الله وحده } أي متوحدا أو توحد وحده فحذف الفعل وأقيم في الحالية { كفرتم } يعني إذا قيل لا إله إلا الله أنكرتم وقلتم { أجعل الآلهة إلها واحدا }{[4320]} { وإن يشرك به } غيره { تؤمنوا } تصدقوا بالإشراك وإذا كان هذا سببا لدخولكم في النار { فالحكم لله } يعني هذا الحكم لله خاصة الذي هو المستحق للعبادة المنزه عن الشريك وهو قد حكم عليكم بالعذاب الشديد الدائم بسبب كفركم ولو كان له شريك مما عبدتموها أنجاكم من عذابه وكان لكم حينئذ سبيل إلى الخروج { العلي الكبير } من أن يشرك ويسوي به غيره .
