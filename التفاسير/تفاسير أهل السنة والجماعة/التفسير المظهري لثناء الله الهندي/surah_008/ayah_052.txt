{ كدأب آل فرعون } خبر مبتدأ محذوف يعني دأب هؤلاء الكفار يعني عملهم وطريقهم الذين دأبوا فيه أي داموا عليه كدأب آل فرعون { والذين من قبلهم } قوم نوح وعاد وثمود وغيرهم { كفروا بآيات الله } تفسير لدأبهم { فأخذهم الله } بالعذاب { بذنوبهم } كما أخذ هؤلاء { إن الله قوي شديد العقاب } لا يغلبه شيء ولا يدفع عذابه شيء<br />
