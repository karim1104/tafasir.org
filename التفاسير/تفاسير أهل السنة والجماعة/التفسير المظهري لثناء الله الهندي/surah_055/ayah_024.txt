{ وله } تعالى { الجوار } السفن الكبار جمع جارية { المنشآت } قرأ حمزة وأبو بكر بخلاف عنه بكسر الشين أي اللائي ابتدأن وأنشأن السير والباقون بفتح الشين أي المرفوعات اللاتي رفع خشبها بعض على بعض وقيل المنشآت المسخرات { في البحر } متعلق بالمنشآت وهي صفة للجوار وقوله { كالأعلام } صفة يعني كالجبال جمع علم وهو الحبل الطويل الجملة معطوفة على مرج البحرين خبر للرحمان بتبعيتها وغنما جعلها تابعة لها لكون الجواري تابعة للبحر .  <br />
