{ ذكر رحمة ربك } يظهر قال لفظة صاد عند الذال من ذكر نافع وعاصم والباقون يدغمونها .  ذكر خبر لما قبله أن كان المراد به السمرة أو القرآن فإنه مشتمل عليه أو خبر مبتدأ محذوف أي هذا المتلو { ذكر رحمة ربك } أو مبتدأ حذف خبره أي فيما يتلى عليك { ذكر رحمة ربك } { عبده } مفعول للرحمة أو الذكر على أن الرحمة فاعله على الاتساع كقولك ذكرني جود زيد { زكريا } بدل منه أو عطف بيان ،  قرأ حمزة والكسائي وحفص بالقصر والباقون بالمد<br />
