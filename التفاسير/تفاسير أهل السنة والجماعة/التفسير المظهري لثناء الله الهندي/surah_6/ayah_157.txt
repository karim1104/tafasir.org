{ أو تقولوا } عطف على الأول يعني أو كراهة أن تقولوا{ لو } تبت { أنا أنزل علينا الكتاب } كما أنزل على من قبلنا{ لكنا أهدى منهم } قال : البغوي : وقد ،  قال : جماعة من الكفار لو أنا أنزل علينا كما أنزل على اليهود والنصارى لكنا خيرا منهم قال : الله تعالى : { فقد جاءكم بينة من ربكم } حجة واضحة بلغة تعرفونها وتعجزون عن إتيان أقصر سورة مثلها{ وهدى } بيانا لمن تأمل فيها{ ورحمة } نعمة لمن عمل بها جزاء شرط محذوف يعني أن صدقتم فيما قلتم فقد جاءكم ما تمنيتم مع وضوح كونه حجة ساطعة وبرهانا قاطعا{ فمن } يعني لا أحد { أظلم ممن كذب بآيات الله } بعد وضوح كونها من الله وبعد تمني مجيئها { وصدف }يعني أعرض أو صد { عنها سنجزي الذين يصدفون عن آياتنا }وضع الظاهر موضع المضمر للمبالغة في ذمهم{ سوء العذاب } أي شدته{ بما كانوا يصدفون }أي بإعراضهم أو صدهم<br />
