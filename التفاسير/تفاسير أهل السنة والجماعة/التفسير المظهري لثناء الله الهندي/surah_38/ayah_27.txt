{ وَمَا خَلَقْنَا السَّمَاء وَالْأَرْضَ وَمَا بَيْنَهُمَا بَاطِلًا } لا حكمة فيه أو ذوي باطل يعني مبطلين عابثين أو للباطل الذي هو متابعة الهوى بل للحق الذي هو الاستدلال على وجود الصانع وشكر نعمته بامتثال أوامره وانتهاء مناهيه جملة معترضة وكذلك قوله { ذلك ظن الذين كفروا } حيث ينكرون البعث وينكرون ثواب المطيع لمن خلق وعذاب العاصي وذلك يقتضي كون خلقها عبثا لا حكمة فيه { فويل } التنكير للتعظيم والفاء للسببية { للذين كفروا } وضع المظهر موضع الضمير للذم والتقبيح { من النار } من للسببية<br />
