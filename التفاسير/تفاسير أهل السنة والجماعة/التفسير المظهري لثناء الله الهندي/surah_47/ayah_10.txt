{ أفلم يسيروا } يعني أهل مكة { في الأرض } الاستفهام للإنكار والفاء للعطف على محذوف تقديره ألم يخرجوا فلم يسيروا في الأرض { فينظروا } جواب للنفي أو معطوف عليه أي فلم ينظروا { كيف كان عاقبة الذين من قبلهم } من الأمم المكذبة للرسل { ودمر الله } أي استأصل { عليهم } على أنفسهم وأهليهم وأولادهم وأموالهم جملة مستأنفة { وللكافرين } يعني أهل مكة وضع الظاهر موضع الضمير للتسجيل على كفرهم { أمثالها } أي أمثال تلك العاقبة أو العقوبة أو الهلكة لأن التدمير يدل عليها .  <br />
