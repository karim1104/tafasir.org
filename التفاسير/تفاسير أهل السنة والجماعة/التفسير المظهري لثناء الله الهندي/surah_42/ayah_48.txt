{ فإن أعرضوا } عن إجابتك يا محمد { فما أرسلناك عليهم حفيظا } حذف جزاء الشرط و أقيم تعليله مقامه تقديره فلا تحزن لأن { ما أرسلناك عليهم رقيبا مؤاخذا } على إعراضهم { إن عليك إلا البلاغ } و قد بلغت تعليل لقوله : { ما أرسلناك عليهم حفيظا } { و إنا إذا أذقنا الإنسان } أراد به الجنس { منا رحمة } أي نعمة في الدنيا ،  قال ابن عباس يعني الغنى و الصحة { فرح بها و إن تصبهم سيئة } من القحط أو الفقر أو المرض { بما قدمت أيديهم } أي بسبب معاصيهم التي قدموه و عبر بالأيدي لأن أكثر الأفعال بها { فإن الإنسان كفور } بليغ الكفران لما تقدم من نعم الله عليه ينسى و يجحد بأقل شيء من الشدة جميع ما أسلف عليه من النعم و يذكر البلية و يعظمها و لا يتأمل في سببها ،  و هذا الحكم وإن اختص بالمجرمين جاز إسناده إلى الجنس لغلبتهم واندراجهم فيه و تصدير الشرطية الأولى بإذا و الثانية بأن لأن إذاقة النعمة محققة من حيث أنها عادة الله تعالى يقتضيه رحمته الذاتية بخلاف إصابة البلية و أقيم علة الجزاء مقامه ووضع الظاهر موضع الضمير في الثانية للدلالة على أن هذا الجنس موسوم بكفران النعمة<br />
