{ ينادونهم } يعني ينادي المنافقون المؤمنين من وراء السور حين حجب بينهم بالسور وبقوا في الظلمة { ألم نكن معكم } في الدنيا نصلي ونصوم { قالوا بلى ولكنكم فتنتم أنفسكم } أي أهلكتموها بالنفاق والكفر واستعملوها في المعاصي والشهوات وكلها فتنة { وتربصتم } بالمؤمنين الدوائر بمحمد صلى الله عليه وسلم الموت قتلتم يوشك أن يموت فتستريح منه { وارتبتم } شككتم في الدين وفيما أوعدكم به { وغرتكم الأماني } الأباطيل وما كنتم تتمنون من نزول الدوائر بالمؤمنين { حتى جاء أمر الله } يعني الموت { وغركم بالله الغرور } الشيطان أو الدنيا بأن الله كريم لا يعذبكم أو بأنه لا بعث ولا حساب ،  وقال قتادة ما زالوا على خدعتكم من الشيطان حتى قذفهم في النار<br />
