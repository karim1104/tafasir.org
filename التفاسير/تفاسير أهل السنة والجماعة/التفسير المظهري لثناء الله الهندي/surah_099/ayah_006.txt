{ يومئذ } ظرف لما بعده { يصدر } أي يرجع { الناس } عن موقع الحساب بعد عرض { أشتاتا } متفرقين ،  فأخذ ذات اليمين إلى الجنة ،  وأخذ ذات الشمال إلى النار ،  قوله تعالى : { يومئذ يتفرّقون }{[5627]} { ليروا } متعلق بيصدر ،  أي لكن يروا أعمالهم .   قال ابن عباس : أي ليروا جزاء { أعمالهم } ،  يعني يرجعون عن الموقف لينزلوا منازلهم من الجنة أو النار ،  وجملة يومئذ يصدر مستأنفة ،  وقوله { فمن يعمل } إلى آخر السورة تفصيل ليروا .
