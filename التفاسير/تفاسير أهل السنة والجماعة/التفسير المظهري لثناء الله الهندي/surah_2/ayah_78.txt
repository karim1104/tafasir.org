{ وَمِنْهُمْ أُمِّيُّونَ } أي جهالهم { لاَ يَعْلَمُونَ الْكِتَابَ } التوراة { إِلاَّ أَمَانِيَّ } استثناء منقطع ،  والأماني جمع أمنية وهي في الأصل : ما يقدره الإنسان في نفسه من منى والمراد الأكاذيب التي افتروها أحبارهم كذا قال مجاهد وقتادة ،  قال الفراء : الأماني الأحاديث المفتعلة ومنه قول عثمان رضي الله عنه ما تمنيت منذ أسلمت أي ما كذبت ،  أو المراد إلا ما تمناه أنفسهم من غير حجة مثل قوله { لَن يَدْخُلَ الْجَنَّةَ إِلاَّ مَن كَانَ هُوداً أَوْ نَصَارَى }{[193]} وقولهم : { لَن تَمَسَّنَا النَّارُ إِلاَّ أَيَّاماً مَّعْدُودَاتٍ }{[194]} كذا قال الحسن وأبو العالية ،  أو المراد به إلا ما يقرؤون الكتاب بألسنتهم غير عارفين في الكتاب منه قوله تعالى : { إِلَّا إِذَا تَمَنَّى أَلْقَى الشَّيْطَانُ فِي أُمْنِيَّتِهِ }{[195]} كذا قال ابن عباس ،  قرأ أبو جعفر { أماني } بتخفيف الياء في كل القرآن والباقون بالتشديد { وإن هم } ما هم { إلا } قوم { يظنون } بالتقديد لا علم عندهم .
