{ لأنتم  } أيها المسلمون { أشد رهبة } أي مرهوبة { في صدورهم } أي المنافقين { من الله } حيث يؤمنون باللسان دون القلب مخافة الناس دون الله تعالى العالم بما في الصدور { ذلك } الخوف منكم دون الله تعالى{ بأنهم قوم لا يفقهون } أي لا يعرفون الله تعالى وعظمته وأن الله تعالى : هو النافع والضار وأفعال العباد إنما هي مخلوقة له تعالى فهو الحقيق بأن يخشى دون غيره  .  <br />
