{ ومن كفر } ولم يسلم وجهه إلى الله { فلا يحزنك كفره } تقديره فقد أضر نفسه وأوبقه ولا يضرك شيئا لا في الدنيا ولا في الآخرة ولما كان عدم الضرر موجبا لعدم الحزن أورده في مورده قرأ نافع لا يحزنك بضم الياء وكسر الزاء من الإحزان { إلينا مرجعهم } في الدارين { فننبئهم بما عملوا } بالتعذيب { إن الله عليم بذات الصدور } من الاعتقادات والخطرات فضلا عما في الظاهر فيجازي كلا على حسب اعتقاده وعمله .  <br />
