{ ولا تصعر } قرأ نافع وأبو عمرو وحمزة والكسائي ولا تصاعر من المفاعلة وابن كثير وابن عامر وعاصم وأبو جعفر ويعقوب بتشديد العين من غير ألف { خدك للناس } أي لا تمل عنهم ولا تولهم صفحة وجهك تكبرا قال ابن عباس تقول لا تتكبر فتحقر وتعرض عنهم بوجهك إذا كلموك { ولا تمش في الأرض مرحا } أي فرحا وبطرا مصدر وقع موقع الحال أي يمرح مرحا أو العلة أي لأجل المرح { إن الله لا يحب كل مختال } متبختر في مشيه { فخور } على الناس علة للنهي نشر على غير ترتيب اللف لرعاية القافية .  <br />
