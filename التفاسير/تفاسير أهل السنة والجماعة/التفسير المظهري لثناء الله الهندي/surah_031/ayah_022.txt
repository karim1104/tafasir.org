{ ومن يسلم وجهه } أي توجهه { إلى الله } وأقبل بشراشره عليه يعني لا يفعل فعلا ولا يترك شيئا إلا ابتغاء مرضاته ويفوض أمره إليه { وهو محسن } في أعماله قال رسول الله صلى الله عليه وسلم  " الإحسان أن تعبد ربك كأنك تراه " {[3957]} يعني بالحضور التام { فقد استمسك بالعروة الوثقى } يعني تمسك بأوثق ما يتمسك به وأعتصم بأقوى ذريعة لا يحتمل إنقطاعه تمثيل لطيف للمتوكل على المتشبث بالعروة الوثقى { وإلى الله عاقبة الأمور } إذ الكل صائر إليه
