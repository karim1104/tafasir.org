{ وأنا منا المسلمون } الأبرار { ومنا القاسطون } أي الجائرون عن الحق يقال أقسط الرجل إذا عدل وقسط إذا جار فهو قاسط ،  إنما ذكر هذه الجمل ومع ذكر مضمون فيما سبق بقوله : { وأنا منا الصالحون ومنا دون ذلك } ليكون تمهيدا لتفصيل حال الفريقين والمقصود ها هنا تفصيل الحال وفيما سبق التفرق فحسب لدفع الإسلام أمرا مبدعا ويحتمل أن يكون الذين يستمعون القرآن بعضهم أسلموا وبعضهم لم يسلموا وهذا مقولة المسلمين منهم لما رجعوا إلى قومهم { فمن أسلم } بالله ورسله { فأولئك تحروا رشدا } قصدوا طريقا موصلا إلى الفلاح .  <br />
