ثم وصفهم الله تعالى فقال { وإذا يتلى } يعني القرآن { عليهم } الظرف متعلق بقوله : { قالوا آمنا به } أي بأنه كلام الله عطف على يؤمنون { إنه الحق من ربنا } استئناف لما أوجب إيمانه { إنا كنا من قبله } أي من قبل نزوله { مسلمين } مخلصين لله في التوحيد مؤمنين بمحمد صلى الله عليه وسلم انه نبي وذلك لما بشر به عيسى عليه السلام حيث قال { مبشرا برسول يأتي من بعدي اسمه أحمد } {[3843]} وكان ذكره في التوراة والإنجيل وهذا استئناف آخر للدلالة على أن إيمانهم به ليس مما أحدثوه حينئذ وإنما هو أمر تقادم عهده وجاز أن يكون هذه الجملة بيان لقوله : { ربنا آمنا } فإنه يحتمل البعيد والقريب وبهذه الآية حمل على البعيد وأندفع احتمال القريب .
