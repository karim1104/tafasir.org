{ وقالت } أم موسى عطف على أصبح { لأخته } مريم بنت عمران { قصيه }أي اتبعي أثره وتبتغي خبره { فبصرت به } عطف على محذوف معطوف على قالت تقديره فبصرت له { عن جنب } أي عن بعد حال من أحد الضميرين المرفوع أو المجرور وفي القصة أنها تمشي جانبا وتنظر إختلاسا ترى أنها لا تنظر { وهم لا يشعرون } أنها أخته أنها ترقبه .  <br />
