{ وراء المجرمون } أي المشركون { النار فظنوا } أيقنوا { أنهم مواقعوها } مخالطوها واقعون فيها ،  أخرج أحمد عن أبي سعيد الخدري عن رسول الله صلى الله عليه وسلم : ( في قوله تعالى : { فظنوا أنهم مواقعوها } قال : ينصب الكافر مقدار خمسين ألف سنة كما لم يعمل في الدنيا وإن الكافر ليرى جهنم ويظن أنها مواقعه من مسيرة أربعين سنة ) { ولم يجدوا عنها مصرفا } أي انصرافا أو مكانا ينصرفون إليها .  <br />
