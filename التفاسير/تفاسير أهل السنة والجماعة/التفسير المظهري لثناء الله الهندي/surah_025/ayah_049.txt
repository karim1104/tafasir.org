{ لنحيي به } أي بالماء { بلدة ميتا } ذكر ميتا لان البلدة بمعنى البلد أو بتأويل المكان أو لأن تأنينه غير حقيقي أو لأنه جار على الفعل كسائر أبنية المبالغة فأجري مجرى الجامد { ونسقيه } سقى وأسقى لغتان بمعنى واحد { مما خلقنا أنعاما وأناسي كثيرا } يعني أهل البوادي الذين يعيشون بالمطر ولذلك نكر الأنعام والأناسي وتخصيصهم لان أهل المدن والقرى يقيمون بقرب الأنهار والآبار والمنابع فيستغنون لأنفسهم ولأنعامهم عن سقي السماء ولأن سياق الآية لتعداد النعم على الإنسان وعامة منافعهم وغالب معايشهم منوط بالأنعام ولذلك قدم سقيها على سقيهم كما قدم عليها إحياء الأرض فإنه سبب لحياتها وتعيشها وأناسي جمع إنسي أو جمع إنسان كظرابي جمع ظربان على أن أصله أناسين كبساتين جمع بستان فقلبت النون ياء<br />
