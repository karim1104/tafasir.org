{ إن تقرضوا الله } إما تقديره المضاف يعني إن تقرضوا عباد الله والمراد به صرف المال في طاعة الله ورجاء من الله تعالى الثواب والجزاء { قرضا حسنا } يعني مقرونا بالإخلاص وطيب النفس بريا من الريا والسمعة والمن والأذى منصوب على المصدرية { يضاعفه لكم } أي يجعله لكم عشرا إلى سبعة مئة أو أكثر قال الله تعالى : { مثل الذين ينفقون أموالهم في سبيل الله كمثل حبة أنبتت سبع سنابل في كل سنبلة مائة حبة والله يضاعف لمن يشاء والله واسع عليم } {[5045]} قرأ ابن كثير وابن عامر ويعقوب يضعف من التفعيل والباقون من المفاعلة { ويغفر لكم } ببركة الإنفاق جملة إن تقرضوا تعليل الأمر بالاتفاق { والله شكور } يعطي الجزيل بالقليل { حليم } لا يعاجل بالعقوبة
