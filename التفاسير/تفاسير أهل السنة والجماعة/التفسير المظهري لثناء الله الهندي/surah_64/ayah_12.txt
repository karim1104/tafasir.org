{ وأطيعوا الله وأطيعوا الرسول } عطف على قوله آمنوا بالله وما بينهما معترضات { فإن توليتم } عن طاعة الله ورسوله والفاء للسببية فإن تبلغ الأمر بالإيمان والطاعة سبب لقوله إن توليتم { فإنما على رسولنا } محمد { البلاغ المبين } يعني توليكم لا يضر محمدا شيئا إذ ليس الواجب عليه إلا التبليغ وقد بلغ وضرر التولي يعود عليكم<br />
