{ فآمن } عطف على قال { له } أي لإبراهيم { لوط } لكونه معصوما عن تكذيب الأنبياء وهو أول من صدق إبراهيم وكان ابن أخيه هارون { وقال } إبراهيم { إني مهاجر } من قومي { إلى ربي } أي على حيث أمرني ربي أو إلى حيث يتيسر لي هناك عبادة ربي أو المعنى إني مهاجر من قومي معرض عنهم متوجها إلى ربي وهي السفر في الوطن على اصطلاح الصوفية قال المفسرون هاجر إبراهيم من كوثى ( وهو من سواد كوفة ) إلى حران ثم أتى الشام ومعه لوط وامرأته سارة وهو أول من هاجر فنزل إبراهيم فلسطين ولوط السدوم قالوا كان إبراهيم حين هاجر ابن خمس وسبعين سنة { إنه هو العزيز } الذي يمنعني من أعدائي { الحكيم } الذي لا يأمرني إلا بما فيه صلاحي .  <br />
