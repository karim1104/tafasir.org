{ قال } فرعون تعنتا ليلبس على قومه كيلا يعتقدوا أنهم آمنوا عن بصيرة وظهور حق { آمنتم له } قرأ حمزة والكسائي وابو بكر وروح ءامنتم بالهمزتين والباقون بهمزة واحد وحذف همزة الاستفهام الإنكاري { قبل أن آذن لكم إنه لكبيركم الذي علمكم السحر } فعلمكم شيئا دون شيء ولذلك غلبكم أو المعنى أنه وادعكم ذلك وتواطئتم عليه { فلسوف تعلمون } تهديدا إجمالا ثم فصله بقوله { لأقطعن أيديكم وأرجلكم من خلاف ولأصلبنكم أجمعين }<br />
