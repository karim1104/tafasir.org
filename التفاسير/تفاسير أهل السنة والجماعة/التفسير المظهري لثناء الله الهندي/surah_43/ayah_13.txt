{ لتستووا على ظهوره } أي ظهور ما تركبون وجمعه للمعنى { ثم تذكروا } بقلوبكم { نعمة ربكم إذا استويتم عليه } بتمليك المركب في البر والبحر وتسخيرها { وتقولوا } بألسنتكم حامدين على النعمة { سبحان } أي أسبح سبحان { الذي سخر لنا هذا وما كنا له مقرنين } مطيقين من أقرن الشيء إذا أطاقه وأصله وجده قرينه إذ الصعب لا يكون قرينا للضعيف جملة { وما كنا له مقرنين } حال من هذه أو من ضمير لنا .  <br />
