أخرج ابن أبي شيبة عن ابن مسعود قال إن الجن هبطوا على النبي صلى الله عليه وسلم وهو يقرأ القرآن ببطن نخلة فلما سمعوه قالوا أنصتوا قالوا صه وكانوا تسعة أحدهم رذبعة فأنزل الله { وإذ صرفنا } أي أهلنا { إليك } هذه الجملة إلى آخرها معترضة لتسلية النبي صلى الله عليه وسلم نفرا وهي جماعة دون العشرة وجمعه أنفار { من الجن } قال ابن عباس كانوا سبعة من جن نصيبين فجعلهم رسول الله صلى الله عليه وسلم رسلا إلى قومهم وقال الآخرون كانوا تسعة .  <br />
قال البغوي روى عاصم عن زر بن حبيش أن رذبعة من التسعة الذين استمعوا القرآن { يستمعون القرآن } حال من نفر { فلما حضروه } أي القرآن أو الرسول { قالوا أنصتوا } قال بعضهم لبعض اسكتوا نسمعه { فلما قضى } أي أتم وفرغ من قراءته { ولو } انصرفوا { إلى قومهم } من الجن { منذرين } مخوفين داعين بأمر رسول الله صلى الله عليه وسلم وقد ذكرنا القصة بوجوبها في سورة الجن لما سبق مني تفسيرها .  <br />
