{ قال } ذو القرنين امتثالا لأمره تعالى أو اختيارا لدعوتهم إلى الإسلام بعد التخيير { أما من ظلم } نفسه بالإصرار على الكفر بعدما دعوته إلى الإسلام واستمر على ظلمه الذي هو الشرك { فسوف نعذبه } أنا ومن معي في الدنيا بالقتل { ثم يرد إلى ربه فيعذبه } ربه في الآخرة { عذابا نكرا } أي منكرا لم يعهد مثله في نار جهنم<br />
