{ ويا قوم لا أسألكم عليه }أي على التبليغ فهو وإن لم يذكر لكنه معلوم مما ذكر { مالا } أي جعلا يثقل عليكم إن أديتم أو علي إن لم تؤدوا { إن أجري } قرأ نافع وابن عامر وأبو عمر وحفص بفتح الباء والباقون بإسكانها يعني ليس ثوابي { إلا على الله }بناء على وعده تفضلا { وما أنا بطارد الذين آمنوا } جواب لهم حين سألوا طردهم ليؤمنوا به أنفة من المجالسة معهم { إنهم ملاقوا ربهم } فيخاصمون طاردهم عنده ،  أو أنهم يلاقونه ويفوزون بقربه ،  فكيف أطرد أولياء الله ومقربيه { ولكني } قرأ نافع والبزي وأبو عمر بفتح الياء والباقون بإسكانها { أراكم قوما تجهلون }بلقائهم ربهم أو بمراتب قربهم من الله أو في التماس طردهم أو تتسفهون عليهم باز ،  تدعوهم أراذل أو تجهلون عاقبة أمركم<br />
