{ يا قوم لا أسألكم عليه } أي لا تبليغ الرسالة { أجرا } يمنعكم ثقل أدائه عن قبول الرسالة ،  أو يبعثني طعمه على الكذب { إن اجري } قرأ نافع وابن عامر وأبو عمرو وحفص بفتح الياء والباقون بإسكانها ،  يعني ما ثوابي { إلا على الذي فطرني } أي خلقني قرأ نافع والبزي بفتح الياء والباقون بإسكانها { أفلا تعقلون } أي أفلا تستعملون عقولكم فتعرفوا أن من هذا شأنه يجب تصديقه<br />
