فلما بشرت بالولد صكت وجهها أي ضربت تعجبا { قالت يا ويلتاي } يا عجبا أصله كلمة ندبة يقال في الشر ،  فأطلق في أمر فظيع وعند رؤية ما يتعجب منه والألف مبدلة من ياء الإضافة عليه قراءة الحسن يا ويلتاي بالياء على الأصل وقيل : الألف ألف الندبة أصله يا ويلتاه { أألد وأنا عجوز } كانت ابنة تسعين سنة في قول ابن إسحاق وتسع وتسعين سنة في قول مجاهد { وهذا بعلي } زوجي واصله القائم بالأمر { شيخا } ابن مائة وعشرين سنة في قول ابن إسحاق ومائة سنة في قول مجاهد وكان بين البشارة والولادة سنة ونصبه على الحال والعامل فيها معنى الإشارة { إن هذا } يعني الولد من الهرمين { لشيء عجيب } يعني خلاف العادة<br />
