{ وَإِذ نَتَقْنَا الْجَبَلَ } متعلق باذكر وأصل النتق الجدب والمعنى قلعناه ورفعناه { فَوْقَهُمْ } أي فوق بني إسرائيل حين أبوا أن يقبلوا أحكام التوراة لثقلها فرفع الله عليهم الجبل { كَأَنَّهُ ظُلَّةٌ } سقيفة وهي كل ما أظلك { وَظَنُّواْ } أي أيقنوا { وظنوا أَنَّهُ وَاقِعٌ بِهِمْ } وإنما أطلق الظن لأنه لم يقع متعلقه وقيل : لهم إن قبلتم ما فيها وإلا ليقعن عليكم { خُذُواْ } بإضمار القول أي وقلنا { خذوا ما أتيناكم بقوة } بجد وعزم على تحمل مشاقة حال من فاعل خذوا { وَاذْكُرُواْ مَا فِيهِ } بالعمل ولا تتركوه كالمنسي{ لَعَلَّكُمْ تَتَّقُونَ } قبائح الأعمال ورذائل الأخلاق .  <br />
