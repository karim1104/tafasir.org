{ وَإِذَا لَمْ تَأْتِهِم } يا محمد { بِآيَةٍ } من القرآن أو معجزة مما إقترحوه { قَالُواْ } يعني الكفار { لَوْلاَ اجْتَبَيْتَهَا } أي هلا جمعتها تقولا من نفسك يقول العرب اجتبيت الكلام إذا اختلقته أو هلا أخذتها من الله ،  قال : الكلبي كان أهل مكة يسألون النبي صلى الله عليه وآله وسلم الآيات تعنتا فإذا تأخرت اتهموه وقالوا لولا اجتبيتها أي هلا أنشأتها من عندك { قُلْ } لهم يا محمد { إِنَّمَا أَتَّبِعُ مَا يِوحَى إِلَيَّ مِن رَّبِّي } أي لست بمختلق للآيات أو لست بمقترح لها { هَذَا } القرآن { بَصَآئِرُ } وللقلوب بها تبصر الحق من الباطل والصواب من الخطأ أو حجج وبرهان يظهر بها صدق دعواي { مِن رَّبِّكُمْ وَهُدًى وَرَحْمَةٌ لِّقَوْمٍ يُؤْمِنُونَ }<br />
