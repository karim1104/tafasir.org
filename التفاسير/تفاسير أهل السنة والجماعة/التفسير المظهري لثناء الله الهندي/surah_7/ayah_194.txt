{ إن الذين تدعون } أيها المشركون { من دون الله } أي تعبدونهم وتسمونهم آلهة { عباد أمثالكم } أي مخلوقة مملوكة مذللة مسخرة لما أريد منهم قال مقاتل : أراد بها الملائكة والخطاب مع قوم يعبدون الملائكة والأول أصح ،  { فادعوهم فليستجيبوا لكم إن كنتم صادقين } أنها آلهة ويحتمل أنهم لما نحتوا الأصنام بصور الأناسي قال : لهم إن منتهى أمرهم أن يكونوا أحياء عقلاء أمثالهم فلا يستحقون عبادتكم كما لا يستحقها بعضكم من بعض ثم بين أنها دونكم منزلة فقال { ألهم أرجل يمشون بها أم لهم أيد يبطشون بها }<br />
