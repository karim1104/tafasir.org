{ يا بني آدم إما يأتينكم } ما زائدة زيدت لتأكيد الشرط ولذلك أكد فعلها بالنون ذكر الله سبحانه بحرف الشك للتنبيه على أن إتيان الرسل جائز غير واجب ولا يجب على الله شيء { رسل منكم } أي من بني آدم { بقصون } أي يقرؤون{ عليكم آياتي } من الكتب صفة لرسل وجواب الشرط { فمن اتقى } منكم يعني من الشرك وتكذيب الرسل { وأصلح } عمله أي أخلصه لله تعالى وأتى به كما أمر { فلا خوف عليهم } حين يخاف الناس في القبر ويوم القيامة { ولا هم يحزنون } إذا حزنوا في النار<br />
