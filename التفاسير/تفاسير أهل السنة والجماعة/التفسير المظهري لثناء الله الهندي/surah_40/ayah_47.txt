{ وإذ يتحاجون } أي أهل النار { في النار } أي أذكر يا محمد لقومك وقت مخاصمتهم في النار وجاز أن يكون الظرف عطفا على غدوا { فيقول الضعفاء للذين استكبروا } تفصيل للحاجة { إنا كنا لكم } في الدنيا { تبعا } والتبع يكون واحدا وجمعا لتابع كخدم جمع خادم على قول البصريين ،  وقيل معناه ذوي تبع بمعنى أتباع على الإضمار أو التجوز ،  وقال الكوفيون جمع لا واحد له وجمعه أتباع { فهل أنتم مغنون عنا نصيبا من النار } بالدفع استفهام بمعنى الأمر ونصيبا مفعول لما دل عليه مغنون أوله بالتضمين أو مصدر كشيئا في قوله تعالى : { لن تغني عنهم أموالهم ولا أولادهم من الله شيئا }{[4331]} فيكون صلة لمغنون
