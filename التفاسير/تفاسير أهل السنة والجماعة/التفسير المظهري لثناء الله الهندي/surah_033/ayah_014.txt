{ ولو دخلت } المدينة أي دخل هؤلاء الأحزاب { عليهم } في المدينة أو في بيوتهم وحذف الفاعل إيماء بأن دخول هؤلاء الأحزاب وغيرهم في اقتضاء الحكم المترتب عليه سواء { من أقطارها } أي جوانبها { ثم سئلوا الفتنة } أي الشرك أو مقاتلة المسلمين { لأتوها } قرأ أهل الحجاز بالقصر أي لجاءوها وفعلوها والباقون بالمد أي لأعطوا ما سألوا من الفتنة { وما تلبثوا بها } أي بالفتنة يعني بإتيانها وإعطائها { إلا يسيرا } أي زمانا يسيرا يعني زمان السؤال والجواب كذا قال أكثر المفسرين وقيل معناه ما أقاموا بالمدينة بعد إعطاء الكفر إلا زمانا قليلا ثم يهلكون أو يجلون<br />
