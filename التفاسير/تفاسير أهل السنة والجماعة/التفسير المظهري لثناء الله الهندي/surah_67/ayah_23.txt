{ قل } إنما ينصركم ويرزقكم { هو الذي أنشأكم } لتعرفوا ربكم وتبعدوه { وجعل لكم السمع } تسمعوا المواعظ { والأبصار } لتنظروا صنائعه { والأفئدة } لتتفكروا وتعتبروا .   ولما كان السمع في الأصل مصدرا ،  والمصدر لا يجمع ذكره بصيغة الإفراد ،  بخلاف البصر والفؤاد ،  وأيضا العلم الحاصل بالسمع نوع واحد ،  وهو الصوت ،  والحاصل بالبصر والفؤاد أنواع مختلفة .  { قليلا } أي شكرا قليلا ،  وزمانا قليلا .   { ما } زائدة لتأكيد القلة { تشكرون } والمراد بالقلة النفي رأسا مجازا .  <br />
