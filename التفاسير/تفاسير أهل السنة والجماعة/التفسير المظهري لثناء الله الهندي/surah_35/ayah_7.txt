ثم بين حال موافقيه ومخالفيه فقال { الَّذِينَ كَفَرُوا لَهُمْ عَذَابٌ شَدِيدٌ وَالَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ لَهُم مَّغْفِرَةٌ وَأَجْرٌ كَبِيرٌ }{ الذين كفروا } بالله وأتبعوا الشيطان لهم { عذاب شديد والذين آمنوا } بالله { وعملوا الصالحات } وخالفوا الشيطان { لهم مغفرة وأجر كبير } .  <br />
