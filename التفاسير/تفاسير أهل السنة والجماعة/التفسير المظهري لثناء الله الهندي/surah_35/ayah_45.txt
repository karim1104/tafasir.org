ولما سبق من أن كفرهم يقتضي استئصالهم كما هو سنة الله في الذين من قبلهم وقد كانوا أشد منهم قوة ذكر سبب إمهالهم فقال{ ولو يؤاخذ الله الناس } في الدنيا عاجلا { بما كسبوا } من المعاصي { ما ترك على ظهرها } أي ظهر الأرض { من دابة } نسمة تدب عليها بشؤم معاصيهم أومن دابة عاصية وهو الأظهر لقوله تعالى : { ولكن يؤخرهم } أي يؤخر مؤاخذتهم { إلى أجل مسمى } وهو ما بعد الموت أو يوم القيامة { فإذا جاء أجلهم فإن الله كان بعباده } قال ابن عباس يريد به جميع العباد أهل طاعته وأهل معصيته { بصيرا } فيجازيهم على حسب أعمالهم .  <br />
