{ هنالك } أي في ذلك المقام { تبلوا كل نفس ما أسلفت } أي تختبر وتعلم ما قدمت من عمل فيعاين نفعها وضررها قرأ حمزة والكسائي تتلوا بالتاءين الفوقانيتين من التلاوة أي تقرأ صحيفتها أو من العلو أي تتبع عملها فتقودها إلى الجنة أو النار { وردوا إلى الله } أي إلى حكمه أو إلى جزائه إياهم بما أسلفوا { مولاهم الحق } أي ربهم ومتولي أمورهم على الحقيقة لا ما اتخذوه أولياء فإن قيل : أليس الله قد قال { وأن الكافرين لا مولى لهم } {[2259]} قلنا المولى هنالك بمعنى الناصر وهاهنا بمعنى الرب والمالك { وضل عنهم } أي زال وبطل عنهم { ما كانوا يفترون } من أن آلهتهم يشفع لهم ،  أو ما كانوا يدعون أنها آلهة .
