{ وجاء رجل } عطف على ( قال يا موسى ) قال أكثر أهل التأويل هو حزئيل مؤمن آل فرعون وقيل اسمه شمعون وقيل سمعا { من أقصا المدينة } ظرف مستقر صفة لرجل وليس متعلقا بجاء لان تخصيصها ألحقه بالمعارف فصح أن يكون قوله { يسعى } حالا منه يعني جاء ذلك الرجل يسرع في مشيه فأخذ طريقا قريبا حتى سبق على موسى فأخبره وأنذره و { قال يا موسى إن الملأ يأتمرون } أي يأمر بعضهم بعضا متلبسا ذلك الأمر { بك ليقتلوك } أي لكي يقتلوك أو يأمر بعضهم بعضا بقتلك واللام زائدة وقيل معناه يتشاورون بك سمي التشاور ائتمارا لأن كلا من المتشاورين يأمر الآخر لكي يقتلوا { فأخرج }من المدينة { إني لك } متعلق بمحذوف خبر لان يعني أني نافع لك { من الناصحين } خبر ثان ولا يجوز أن يكون لك متعلقا بناصحين لأن معمول الصلة لا يتقدم على الموصول وقيل متعلق بناصحين والكلام محمول على التقديم والتأخير وقيل لك بيان لمبهم كأنه قال ( إني من الناصحين ) ثم أن يبين فقال لك أي أنصح لك واللام فيه لتقوية عمل فعل محذوف<br />
