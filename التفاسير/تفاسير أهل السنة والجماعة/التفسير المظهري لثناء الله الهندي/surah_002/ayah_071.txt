{ قَالَ إِنَّهُ يَقُولُ إِنَّهَا بَقَرَةٌ لاَّ ذَلُولٌ } أي غير مذللة بالعمل .  <br />
{ تُثِيرُ الأَرْضَ } تقلبها للزاعة .  <br />
{ وَلاَ تَسْقِي الْحَرْثَ } لا زائدة والفعلان صفتا ذلول يعني لا ذلول مثيرة وساقية .  <br />
{ مُسَلَّمَةٌ } سلمها الله تعالى من العيوب أو أهلها من العمل .  <br />
{ لاَّ شِيَةَ فِيهَا } أي لون يخالف لون جلدها ،  وهي في الأصل مصدر على وزن عدة وَشِيَ يَشِيُ وشْيا وشية فهو واش إذا خلط بلونه لونا آخر ،  قال الجزري : الوشي النقش .  <br />
{ قَالُواْ الآنَ جِئْتَ بِالْحَقِّ } أي بحقيقة وصف البقرة وتمام بيانها وطلبوها بكمال أوصافها فلم يجدوها إلا مع الفتى فاشتروها بملأ مسكها ذهبا .  <br />
{ فَذَبَحُوهَا } فيه اختصار تقديره فحصلوا البقرة فذبحوها { وَمَا كَادُواْ يَفْعَلُونَ } لكثرة مراجعاتهم أو لاختلافهم فيما بينهم أو لخوف الفضيحة في ظهور القاتل أو لعدم وجدانها بتلك الصفات أو لغلاء ثمنها .  <br />
