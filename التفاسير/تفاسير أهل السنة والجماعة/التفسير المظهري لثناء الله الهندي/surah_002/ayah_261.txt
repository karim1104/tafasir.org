{ مَّثَلُ الَّذِينَ يُنفِقُونَ أَمْوَالَهُمْ فِي سَبِيلِ اللّهِ } الجهاد أو غير ذلك من أبواب الخير { كمثل بحة } فيه تقدير المضاف إما في المبتدأ أو في الخبر يعني مثل نفقة { الذين ينفقون كمثل حبة } أو مثلهم باذر حبة { أنبتت سبع سنابل } أسند الإنباث إلى الحبة مجازا لما كانت من الأسباب عادة { في كل سنبلة مائة حبة } كما يكون في الدخن وغير ذلك { والله يضاعف } ما يشاء من الأضعاف { لمن يشاء } من عبادة في الدنيا والآخرة { والله واسع } لا يضيق عليه ما يتفضل به من الزيادة { عليم } بنيات المنفقين يجزي على حسب نياتهم .  <br />
