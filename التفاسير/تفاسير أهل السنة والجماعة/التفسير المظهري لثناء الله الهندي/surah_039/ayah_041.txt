{ إنا أنزلنا عليك الكتاب للناس } لأن يهتدوا به إلى مصالحهم في المعاش والمعاد { بالحق } أي متلبسا به هذه الجملة متصلة بقوله : { ولقد ضربنا للناس في هذا القرآن } وما بينهما معترضات { فمن اهتدى } بالكتاب { فلنفسه } ينتفع نفسه به { ومن ضل } طريق مصالح { فإنما يضل عليها } لا يتجاوز عنها وبال ضلاله { وما أنت عليهم بوكيل } أي ما وكلت عليهم لتجبرهم على الاهتداء به إنما أمرت بالبلاغ وقد بلغت فلا يضرك ضلالهم .  <br />
