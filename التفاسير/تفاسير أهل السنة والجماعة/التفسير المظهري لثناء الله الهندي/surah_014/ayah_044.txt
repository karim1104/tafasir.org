{ وأنذر } أي خوف يا محمد صلى الله عليه وسلم { الناس يوم } بيوم { يأتيهم العذاب } يعني يوم القيامة أو يوم الموت فإنه أول أيام عذابهم أو يأتيهم العذاب العاجل للاستيصال في الدنيا { فيقول الذين ظلموا } بالشرك والتكذيب { ربنا أخرنا } أي أمهلنا في الدنيا أو المعنى أخر العذاب عنا وردنا إلى الدنيا { إلى أجل قريب } أي إلى حد من الزمان قريب وأبقنا مقدار ما نؤمن بك ونجب دعوتك { نجب دعوتك ونتبع الرسل } جواب للأمر نظيره : { لولا أخرتني إلى أجل قريب فأصدق وأكن من الصالحين }66 فيجابون { أو لم تكونوا أقسمتم } حلفتم { من قبل } في دار الدنيا { ما لكم من زوال } جواب للقسم جاء بلفظ الخطاب على المطابقة دون الحكاية ،  والمعنى أنكم باقون في الدنيا لا تزالون بالموت ولعلهم قسموا بطرا وغرورا ،  أو حكاية عن دلالة حالهم حيث بنوا شديدا أو أملوا بعيدا ،  وقيل : معناه أقسموا أنهم لا ينقلون إلى دار أخرى ،  أو أنهم إذا ماتوا لا يزالون عن تلك الحالة يعني لا يبعثون بعد الموت نظيره قوله تعالى :{ وأقسموا بالله جهد أيمانهم لا يبعث الله من يموت }67 .
