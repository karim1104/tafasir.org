{ ألم ترى أن الله خلق السماوات } قرأ حمزة والكسائي { خلق السماوات } وفي سورة النور { خلق كل دابة } على وزن فاعل مضافا ،  والباقون خلق على الماضي { والأرض } قرأ حمزة والكسائي بالجر والباقون بالنصب { بالحق } أي بالحكمة البالغة والوجه الذي يحق أن يخلق له ،  وذلك أن يكون دليلا على وجود الصانع مرشدا للناس إلى الحق والإيمان { إن يشأ يذهبكم } أي يعدمكم { ويأت بخلق جديد } أي يخلق خلقا آخر أطوع منكم ،  رتب ذلك على كونه خالقا للسماوات والأرض مستدلا به عليه ،  فإن من خلق ذلك يقدر على أن يبد لهم بخلق آخر ،  ولم يمتنع ذلك كما قال : { وما ذلك على الله بعزيز20 }
