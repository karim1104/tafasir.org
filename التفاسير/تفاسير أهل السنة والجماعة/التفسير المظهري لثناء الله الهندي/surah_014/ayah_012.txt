{ وما لنا } أي المؤمنين { ألا نتوكل على الله } يعني أي عذر لنا في عدم التوكل { وقد هدانا } الله { سبلنا } التي بها نعرف ونعلم أن الأمور كلها بيد الله لا غير فآمنا به { ولنصبرن } نحن وجميع أتباعنا { على ما ءاذيتمونا } أيها الكفار جواب قسم محذوف أي والله لنصبرن ،  أكدوا بالقسم توكلهم وعدم مبالاتهم بما يفعل بهم الكفار { وعلى الله فليتوكل المتوكلون } يعني فليثبت على توكلهم الذي اقتضاه إيمانهم .  <br />
