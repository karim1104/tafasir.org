{ قالوا سبحانك } أي ننزهك تنزيها عن الشريك { أنت ولينا من دونهم } يعني أنت الذي خص موالاتنا به دونهم يعني لا موالاة بيننا وبينهم كأنهم بينوا بذلك براءتهم عن الرضاء بعبادتهم { بل كانوا يعبدون الجن } أي الشياطين الذين زينوا لهم عبادة الملائكة .  <br />
وقيل كانت الشياطين يتمثلون لهم ويجهلون إليهم أنهم الملائكة فيعبدونهم { أكثرهم } يعني أكثر الناس وهم المشركون أو المراد بالأكثر الكل والضمير للمشركين { بهم } أي بالجن { مؤمنون }<br />
