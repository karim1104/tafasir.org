{ أن أعمل } أي أمرنا أن اعمل أن مصدرية أو مفسرة { سابغات } أي دروعا كوامل واسعات طوال يجرها لا بسها على الأرض { وقدر في السرد } السرد خرز الجلد واستعير لنسج الدرع يعني قدر في نسجها بحيث تناسب حلقها ومساميرها فلا تجعلها رقاق فتغلق ولا غلاظا فتكسر الحلق { واعلموا } يا داوود وآله { صالحا } خالصا لله صالحا لقبوله منصوب على المفعولية والمصدرية { إني بما تعملون بصير } فأجازيكم عليه عن أبي هريرة قال قال رسول الله صلى الله عليه وسلم  " إن الله طيب لا يقبل إلا طيبا أمر المؤمنين بما أمر المرسلين فقال { يأيها الرسل كلوا من الطيبات واعملوا صالحا }{[4137]} الحديث رواه مسلم .
