{ ومن آياته خلق السموات والأرض واختلاف ألسنتكم } أي لغاتكم بأن علم كل صنف لغة وألهمه وأقدره عليها أو أجناس نطقكم وأشكاله وكيفيات أصواتكم بحيث لا يكاد يلتبس صوت أحد بغيره { وألوانكم } أي ألوان الجلد من السواد والبياض وغيرها أو مشخصات الأعضاء وهيئاتها وألوانها وجلاها بحيث لا يلتبس أحد بغيره { إن في ذلك لآيات للعالمين } لا يكاد يخفى على عاقل من ملك أو إنس أو جن وقرأ حفص بكسر اللام خصهم بالذكر لأنهم أحقاء بالمعرفة قال الله تعالى : { وما يعقلها إلا العالمون } {[3902]}
