{ فانظر إلى آثار رحمت الله } يعني آثار الغيث من النبات والأشجار والحبوب والثمار ولذلك جمعه ابن عامر وحفص وحمزة والكسائي وقرأ الجمهور أثر رحمت الله مفردا أي على إرادة الجنس { كيف يحيي الأرض } بالإنبات { بعد موتها } أي يبسها { إن ذلك } الذي قدر على إحياء الأرض بعد موتها { لمحيي الموتى } يحييهم بعدما يميتهم فما وجه إنكاركم أيها الكفار وبعدما تشاهدون ما يماثله { وهو على كل شيء قدير } أن نسبة قدرته إلى جميع الممكنات على السواء<br />
