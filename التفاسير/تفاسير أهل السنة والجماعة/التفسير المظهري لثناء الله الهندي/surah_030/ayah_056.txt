{ وقال } عطف على يقسم المجرمون { الذين أوتوا العلم والإيمان } أي الملائكة والأنبياء والمؤمنون ردا لقولهم { لقد لبثتم } زمانا كتب الله لكم لبثه { في كتاب الله } أو زمانا كائنا في كتاب الله أي مكتوبا فيه مدة لبثكم أو لبثتم لبثا كائنا في كتاب الله أي اللوح المحفوظ أو صحف الملائكة الموكلين بالأرحام حيث قال رسول الله صلى الله عليه وسلم :  " إن خلق أحدكم يجمع في بطن أمه أربعين يوما نطفة ثم يكون علقة مثل ذلك ثم يكون مضغة مثل ذلك ثم يبعث الله إليه ملكا بأربع كلمات فيكتب عمله وأجله "  الحديث أو القرآن وهو قوله تعالى : { ومن ورائهم برزخ إلى يوم يبعثون } {[3923]}{ إلى يوم البعث } متعلق بقوله لبثتم { فهذا يوم البعث } الذي كنتم تنكرونه في الدنيا جملة معترضة أو جواب شرط محذوف تقديره إن كنتم تنكرون البعث فهذا يوما لبعث أي فأنتم مبطلون وقد تبين بطلان إنكاركم { ولكنكم كنتم لا تعلمون } أنه حق لتفريطكم في النظر
