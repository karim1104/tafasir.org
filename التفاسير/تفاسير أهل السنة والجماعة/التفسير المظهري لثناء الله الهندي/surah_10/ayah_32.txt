{ فذلكم } أي من يفعل هذه الأشياء { الله } المستحق للعبادة { ربكم } الثابت ربوبيته بالوجدان والبرهان حيث خلقكم ورزقكم ودبر أموركم { الحق } الثابت المتحقق الذي لا شبهة في وجوده ولا في ألوهية { فماذا بعد الحق إلا الضلال } استفهام إنكار أي ليس غير الحق إلا الضلال فمن يخطئ الحق الذي هو عبادة الله تعالى وقع في الضلالة { فأنى تصرفون } عن الحق إلى الضلال مع قيام البرهان<br />
