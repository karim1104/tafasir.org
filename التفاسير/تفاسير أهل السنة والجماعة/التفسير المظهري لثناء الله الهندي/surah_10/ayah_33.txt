{ كذلك } يعني كما تحققت الربوبية لله تعالى وان ليس بعد الحق إلا الضلال أو كما صرف هؤلاء عن الإيمان { حقت } ثبتت ووجبت { كلمت ربك } أي حكمه السابق { لأملأن جهنم من الجنة والناس } {[2260]} قرأ أبو جعفر ونافع وابن عامر كلمات ربك على الجمع والباقون بالإفراد { على الذين فسقوا } خرجوا عن حد الاستصلاح وتمردوا في كفرهم { إنهم لا يؤمنون } بدل من الكلمة أو تعليل لحقيقتها والمراد بها العدة بالعذاب .
