{ قال } الله تعالى : { كلا فاذهبا } إجابة إلى الطلبين بوعده للدفع اللازم لروعه وضم أخيه إليه في الإرسال والخطاب في { فاذهبا } على تغليب الحاضر وهو معطوف على الفعل الذي دل عليه كلا كأنه قال ارتدع يا موسى عن توهم قتلك فاذهب أنت ومن طلبت ضمه إليك { بآياتنا إنا معكم } يعني مع موسى وهارون ومن تبعهما بالنصر أو معكما ومن عاداكما بالعلم { مستمعون } أي سامعون ما جرى بينكم من الكلام فأظهركما عليهم خبر ثان أو هو الخبر وحده ومعكم ظرف لغو<br />
