{ قل } يا محمد لمشركي مكة { إنما أنا منذر } جملة قل مع المقولة مستأنفة وإنما لقصر القلب متصل بقوله تعالى : { قال الكافرون هذا ساحر كذاب } يعني لست بساحر كذاب إنما أنا منذر أنذركم بعذاب الله { وما من إله إلا الله } عطف على أنه متصل بقوله : { أجعل الآلهة إلها واحدا } ،  { الواحد } الذي لا يقبل الشركة في ذاته ولا في صفة من صفاته { القهار } على كل شيء  ،  فيه وعيد للكفار .  <br />
