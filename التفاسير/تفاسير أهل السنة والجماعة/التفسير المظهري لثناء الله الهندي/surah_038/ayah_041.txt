{ واذكر عبدنا أيوب } عطف بيان لعبدنا والجملة عطف على واذكر عبدنا داود { إذ نادى ربه } بدل اشتمال من عبدنا { أني مسني } قرأ حمزة بإسكان الياء والباقون بفتحها وأن مع جملته حكاية لكلامه الذي نادى به { الشيطان بنصب } قرأ أبو جعفر بضم النون والصاد ويعقوب بفتحها والباقون بضم النون وسكون الصاد ومعنى الكل واحد أي بمشقة وضر { وعذاب } أي وألم ،  قال مقاتل وقتادة بنصب في الجسم وعذاب في المال ،  وقد ذكرنا قصة أيوب ومدة بلائه في سورة الأنبياء عليهم السلام فلما انقضت مدة بلائه أمره الله تعالى أن { ارْكُضْ بِرِجْلِكَ هَذَا مُغْتَسَلٌ بَارِدٌ وَشَرَابٌ } .  <br />
