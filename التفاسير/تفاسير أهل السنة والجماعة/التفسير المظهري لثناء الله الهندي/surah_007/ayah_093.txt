{ فتولى } أي أعرض { عنهم } شعيب شاخصا بين أظهرهم حين أتاهم العذاب { قال يا قوم لقد أبلغكم رسالات ربي ونصحت لكم } قال : ذلك تأسفا بهم بشدة حزنه عليهم ثم أنكر على نفسه فقال{ فكيف أسى } أحزن { على قوم كافرين } فإنهم ليسوا أهلا لأن يحزن عليهم لاستحقاقهم ما نزل بهم ،  أو قاله اعتذارا عن شدة حزنه عليهم يعني بعدما بلغت في الإبلاغ والنصيحة لما لم يتبعوني وآثروا لأنفسهم العذاب فكيف أسى عليهم<br />
