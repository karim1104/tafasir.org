{ فَلَمَّا كَشَفْنَا } بدعاء موسى { عَنْهُمُ الرِّجْزَ إِلَى أَجَلٍ } أي حد من الزمان { هُم بَالِغُوهُ } يعذبون فيه أو يهلكون وهو وقت الغرق أو الموت وقيل : إلى أجل عينوه لإيمانهم { إِذَا هُمْ يَنكُثُونَ } جواب للمّا أي فلما كشفنا عنهم الرجز فأتوا النكث ونقض العهد والإصرار على الكفر من غير توقف وتأمل فيه .  <br />
