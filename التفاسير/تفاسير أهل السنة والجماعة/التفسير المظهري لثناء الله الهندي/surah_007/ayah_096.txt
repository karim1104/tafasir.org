{ وَلَوْ أَنَّ أَهْلَ الْقُرَى }اللام للعهد الخارجي يعني أهل القرى التي أرسلنا فيها الأنبياء { آمَنُواْ } بالأنبياء { وَاتَّقَوا } عذاب الله بالطاعة وترك المعاصيْ { لَفَتَحْنَا } قرأ ابن عامر بالتشديد للتكثير والباقون بالتخفيف ،  { عَلَيْهِم بَرَكَاتٍ مِّنَ السَّمَاء وَالأَرْضِ } أي لوسعنا عليهم الخير من كل جانب وداومناه لهم وقيل : بركات السماء المطر وبركات الأرض النبات والزرع وأصل البركة الزيادة والمواظبة على شيء { والأرض كَذَّبُواْ } الرسل { فَأَخَذْنَاهُم } بالعقوبة { بِمَا كَانُواْ يَكْسِبُونَ } من الكفر والمعاصي<br />
