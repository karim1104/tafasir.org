{ وإذا قيل لهم } أي للمنافقين الذي يزعمون أنهم آمنوا ،  مقولة القول { تعالوا إلى ما أنزل الله } يعني القرآن { وإلى الرسول } عطف قوله إلى الرسول على قوله ما أنزل الله يدل على أن الرسول كان قد يحكم بعلمه سوى القرآن من الوحي الغير المتلو وبالاجتهاد ،  والظرف أعني إذا قيل لهم متعلق بقوله : { رأيت المنافقين } وضع المظهر موضع المضمر للتقبيح والتفضيح وبيان سبب الصد { يصدون } يعرضون { عنك } إلى غيرك لطمعهم بالحكم بالباطل بالرشوة ونحوها والجملة واقع موقع الحال من المنافقين { صدودا } مصدر أو اسم للمصدر الذي هو الصدر في الصحاح الصدود يكون انصرافا عن الشيء وامتناعا وقد يكون بمعنى الصرف والمنع نحو { فصدهم عن السبيل }{[1019]} .
