{ ومن جاء بالسيئة } أي الشركة { فكبت وجوههم } الفاء للعطف على محذوف لا للجزاء لا تدخل على الماضي بغير قد تقديره من جاء بالسيئة فله جزاء السيئة أو استحق العذاب { فكبت وجوههم } أي فكبوا على وجوههم { في النار } أو المراد بالوجوه أنفسهم { هل تجزون } يعني ما تجزون { إلا ما كنتم تعملون } أي إلا جزاؤه وفاقا لما عملوا فإن الشرك أعظم الجرائم لا شيء فوقه في السوء وجهنم أشد الأجزية فيه التفات من الغيبة إلى الخطاب والتقدير ويقول لهم خزنة جهنم { هل تجزون إلا ما كنتم تعلمون } .  <br />
