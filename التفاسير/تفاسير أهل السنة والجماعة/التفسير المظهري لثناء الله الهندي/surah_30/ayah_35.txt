{ أم أنزلنا عليهم سلطانا } أم منقطعة بمعنى بل والهمزة والاستفهام للإنكار عطف على { كل حزب بما لديهم فرحون } وجاز أن يكون متصلة معطوفة على مقدر تقديره أيشركون بلا حجة { أم أنزلنا عليهم سلطانا } قال ابن عباس يعني حجة وعذرا وقال قتادة كتابا وقيل ذو سلطان يعني ملكا معه برهان أو رسولا مؤيدا بالمعجزة { فهو يتكلم } نطقا أو دلالة كقوله تعالى : { كتابنا ينطق عليكم بالحق } {[3910]} { بما كانوا به يشركون } أي بإشراكهم وصحته أو بالأمر الذي بسببه يشركون به وبألوهيته والاستفهام في أم أنزلنا للتقرير يعني حمل المخاطب على الإقرار بأنهم يشركون بلا حجة
