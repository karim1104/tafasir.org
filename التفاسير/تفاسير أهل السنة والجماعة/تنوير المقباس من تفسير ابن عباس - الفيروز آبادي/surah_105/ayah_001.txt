وبإسناده عن ابن عباس في قوله تعالى { أَلَمْ تَرَ } يعني ألم تخبر في القرآن يا محمد { كَيْفَ فَعَلَ رَبُّكَ } كيف عذب ربك وأهلك ربك { بِأَصْحَابِ ٱلْفِيلِ } قوم النجاشي الذين أرادوا خراب بيت الله { أَلَمْ يَجْعَلْ كَيْدَهُمْ } صنيعهم { فِي تَضْلِيلٍ } في أباطيل وتخسير { وَأَرْسَلَ عَلَيْهِمْ } سلط عليهم { طَيْراً أَبَابِيلَ } متتابعة { تَرْمِيهِم } ترمي عليهم { بِحِجَارَةٍ مِّن سِجِّيلٍ } من سبخ وحل مطبوخ مثل الآجر ويقال سجيل من سماء الدنيا { فَجَعَلَهُمْ كَعَصْفٍ مَّأْكُولِ } كورق الزرع المدود إذا أكله الدود.
