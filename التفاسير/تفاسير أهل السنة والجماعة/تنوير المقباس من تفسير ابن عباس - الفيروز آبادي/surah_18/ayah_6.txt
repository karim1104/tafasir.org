وبإسناده عن ابن عباس في قوله تعالى { ٱلْحَمْدُ لِلَّهِ } يقول الشكر لله والإلهية لله { ٱلَّذِي أَنْزَلَ عَلَىٰ عَبْدِهِ } محمد صلى الله عليه وسلم { ٱلْكِتَابَ } جبريل بالقرآن { وَلَمْ يَجْعَل لَّهُ عِوَجَا } لم ينزله مخالفاً للتوراة والإنجيل وسائر الكتب بالتوحيد وصفة محمد صلى الله عليه وسلم ونعته نزلت في شأن اليهود حين قالوا القرآن مخالف لسائر الكتب { قَيِّماً } على الكتب ويقال مستقيماً { لِّيُنْذِرَ } محمد صلى الله عليه وسلم بالقرآن { بَأْساً } عذاباً { شَدِيداً مِّن لَّدُنْهُ } من عنده { وَيُبَشِّرَ } محمد بالقرآن { ٱلْمُؤْمِنِينَ } المخلصين { ٱلَّذِينَ يَعْمَلُونَ ٱلصَّالِحَاتِ } الطاعات فيما بينهم وبين ربهم { أَنَّ لَهُمْ أَجْراً حَسَناً } ثواباً كريماً في الجنة { مَّاكِثِينَ فِيهِ } مقيمين في الثواب لا يموتون ولا يخرجون { أَبَداً وَيُنْذِرَ } محمد صلى الله عليه وسلم بالقرآن { ٱلَّذِينَ قَالُواْ ٱتَّخَذَ ٱللَّهُ وَلَداً } يعني اليهود والنصارى وبعض المشركين { مَّا لَهُمْ بِهِ } من مقالتهم { مِنْ عِلْمٍ } من حجة ولا بيان { وَلاَ لآبَائِهِمْ } كان علم ذلك { كَبُرَتْ كَلِمَةً } عظمت كلمة الشرك { تَخْرُجُ مِنْ أَفْوَاهِهِمْ } تظهر على أفواههم { إِن يَقُولُونَ } ما يقولون { إِلاَّ كَذِباً } على الله { فَلَعَلَّكَ } يا محمد { بَاخِعٌ نَّفْسَكَ } قاتل نفسك { عَلَىٰ آثَارِهِمْ } لأجلهم { إِن لَّمْ يُؤْمِنُواْ بِهَـٰذَا ٱلْحَدِيثِ } بأن لم يؤمنوا بهذا القرآن { أَسَفاً } حزناً { إِنَّا جَعَلْنَا مَا عَلَى ٱلأَرْضِ } من الرجال والنساء { زِينَةً لَّهَا } زهرة للأرض { لِنَبْلُوَهُمْ } لنختبرهم { أَيُّهُم } من هم { أَحْسَنُ } أخلص { عَمَلاً } ويقال إنا جعلنا ما على الأرض من النبات والشجر والدواب والنعم زينة لها زهرة للأرض لنختبر أيهم أزهد في الدنيا وأترك لها { وَإِنَّا لَجَاعِلُونَ } مغيرون { مَا عَلَيْهَا } من الزهرة { صَعِيداً } تراباً { جُرُزاً } أملس لا نبات فيها { أَمْ حَسِبْتَ } أظننت يا محمد { أَنَّ أَصْحَابَ ٱلْكَهْفِ وَٱلرَّقِيمِ } والكهف هو الجبل الذي فيه الغار والرقيم هو اللوح من رصاص فيه أسماء الفتية وقصتهم ويقال الرقيم هو الوادي الذي فيه الكهف ويقال الرقيم هو مدينة { كَانُواْ مِنْ آيَاتِنَا } من عجائبنا { عَجَباً } الشمس والقمر والسماء والأرض والنجوم والجبال والبحار أعجب من ذلك { إِذْ أَوَى ٱلْفِتْيَةُ إِلَى ٱلْكَهْفِ } دخل غلمة في غار الكهف { فَقَالُواْ } حين دخلوا { رَبَّنَآ } يا ربنا { آتِنَا مِن لَّدُنكَ رَحْمَةً } أي ثبتنا على دينك { وَهَيِّئْ لَنَا مِنْ أَمْرِنَا رَشَداً } مخرجاً.
