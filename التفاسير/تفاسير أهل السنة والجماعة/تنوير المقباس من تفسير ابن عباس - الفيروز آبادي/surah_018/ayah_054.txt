{ مَّآ أَشْهَدتُّهُمْ } يعني الملائكة والشياطين { خَلْقَ ٱلسَّمَاوَاتِ وَٱلأَرْضِ } حين خلقتهما { وَلاَ خَلْقَ أَنْفُسِهِمْ } حين خلقتهم ويقال ما استعنت من الملائكة والشياطين في خلق السموات والأرض ولا في خلق أنفسهم { وَمَا كُنتُ مُتَّخِذَ ٱلْمُضِلِّينَ } الكافرين اليهود والنصارى وعبدة الأوثان { عَضُداً } عوناً { وَيَوْمَ } وهو يوم القيامة { يَقُولُ } لعبدة الأوثان { نَادُواْ شُرَكَآئِيَ ٱلَّذِينَ } يعني آلهتكم { زَعَمْتُمْ } عبدتم وقلتم إنهم شركائي حتى يمنعوكم من عذابي { فَدَعَوْهُمْ فَلَمْ يَسْتَجِيبُواْ لَهُمْ } فلم يجيبوا لهم { وَجَعَلْنَا بَيْنَهُم } بين العابد والمعبود { مَّوْبِقاً } وادياً في النار وجعلنا ما بينهم من الوصل والود في الدنيا موبقاً مهلكاً في الآخرة. { وَرَأَى ٱلْمُجْرِمُونَ } المشركون { ٱلنَّارَ فَظَنُّوۤاْ } فعلموا وأيقنوا { أَنَّهُمْ مُّوَاقِعُوهَا } داخلوها يعني النار { وَلَمْ يَجِدُواْ عَنْهَا مَصْرِفاً } مهرباً { وَلَقَدْ صَرَّفْنَا } بيّنا { فِي هَـٰذَا ٱلْقُرْآنِ لِلنَّاسِ } لأهل مكة { مِن كُلِّ مَثَلٍ } من كل وجه من الوعد والوعيد لكي يتعظوا فيؤمنوا { وَكَانَ ٱلإِنْسَانُ } أبي بن خلف الجمحي { أَكْثَرَ شَيْءٍ جَدَلاً } في الباطل ويقال ليس شيء أجدل من الإنسان { وَمَا مَنَعَ ٱلنَّاسَ } أهل مكة المطعمين يوم بدر { أَن يُؤْمِنُوۤاْ } بمحمد عليه الصلاة والسلام والقرآن { إِذْ جَآءَهُمُ ٱلْهُدَىٰ } محمد عليه الصلاة والسلام بالقرآن { وَيَسْتَغْفِرُواْ رَبَّهُمْ } يتوبوا من الكفر إلى الإيمان { إِلاَّ أَن تَأْتِيَهُمْ سُنَّةُ ٱلأَوَّلِينَ } عذاب الأولين بهلاكهم { أَوْ يَأْتِيَهُمُ ٱلْعَذَابُ } بالسيف { قُبُلاً } معاينة يوم بدر { وَمَا نُرْسِلُ ٱلْمُرْسَلِينَ إِلاَّ مُبَشِّرِينَ } بالجنة للمؤمنين { وَمُنذِرِينَ } عن النار للكافرين { وَيُجَادِلُ } يخاصم { ٱلَّذِينَ كَفَرُواْ } بالكتب والرسل { بِٱلْبَاطِلِ } بالشرك { لِيُدْحِضُواْ } ليبطلوا { بِهِ } بالباطل { ٱلْحَقَّ } والهدى { وَٱتَّخَذُوۤاْ آيَاتِي } كتابي ورسلي { وَمَا أُنْذِرُواْ } خوفوا من العذاب { هُزُواً } سخرية واستهزاء { وَمَنْ أَظْلَمُ } ليس أحد أظلم { مِمَّن ذُكِّرَ } وعظ { بِآيِاتِ رَبِّهِ فَأَعْرَضَ عَنْهَا } فصرف عنها جاحداً بها { وَنَسِيَ مَا قَدَّمَتْ يَدَاهُ } ترك ذكر ما عملت يداه من الذنوب { إِنَّا جَعَلْنَا عَلَىٰ قُلُوبِهِمْ أَكِنَّةً } أغطية { أَن يَفْقَهُوهُ } لكي لا يفقهوا الحق والهدى { وَفِي آذَانِهِمْ وَقْراً } صمماً لكي لا يسمعوا الحق والهدى { وَإِن تَدْعُهُمْ } يا محمد { إِلَىٰ ٱلْهُدَىٰ } إلى التوحيد { فَلَنْ يَهْتَدُوۤاْ } فلن يؤمنوا { إِذاً أَبَداً وَرَبُّكَ ٱلْغَفُورُ } المتجاوز { ذُو ٱلرَّحْمَةِ } بتأخير العذاب { لَوْ يُؤَاخِذُهُم بِمَا كَسَبُواْ } بشركهم { لَعَجَّلَ لَهُمُ ٱلْعَذَابَ } في الدنيا { بَل لَّهُم مَّوْعِدٌ } أجل لهلاكهم { لَّن يَجِدُواْ مِن دُونِهِ } من عذاب الله { مَوْئِلاٍ } ملجأ.
