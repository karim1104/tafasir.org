{ وَٱلَّذِينَ ٱتَّخَذُواْ } بنوا { مَسْجِداً } عبد الله بن أبي وجد بن قيس ومعتب بن قشير وأصحابهم نحو سبعة عشر رجلاً { ضِرَاراً } مضرة للمؤمنين { وَكُفْراً } في قلوبهم ثباتاً على كفرهم يعني النفاق { وَتَفْرِيقاً بَيْنَ ٱلْمُؤْمِنِينَ } لكي تصلي طائفة في مسجدهم وطائفة في مسجد الرسول { وَإِرْصَاداً } انتظاراً { لِّمَنْ حَارَبَ ٱللَّهَ وَرَسُولَهُ } لمن كفر بالله ورسوله { مِن قَبْلُ } من قبلهم أبو عامر الراهب الذي سماه رسول الله صلى الله عليه وسلم فاسقاً { وَلَيَحْلِفُنَّ إِنْ أَرَدْنَا } ما أردنا ببناء المسجد { إِلاَّ ٱلْحُسْنَىٰ } إلا الإحسان إلى المؤمنين لكي يصلي فيه من فاتته صلاته في مسجد قباء { وَٱللَّهُ يَشْهَدُ } يعلم { إِنَّهُمْ لَكَاذِبُونَ } في حلفهم { لاَ تَقُمْ فِيهِ } لا تصل في مسجد الشقاق { أَبَداً لَّمَسْجِدٌ } وهو مسجد قباء { أُسِّسَ عَلَى ٱلتَّقْوَىٰ } بني على طاعة الله وذكره { مِنْ أَوَّلِ يَوْمٍ } دخل النبي صلى الله عليه وسلم المدينة ويقال أول مسجد بني بالمدينة { أَحَقُّ } أصوب { أَن تَقُومَ } تصلي { فِيهِ } في مسجد قباء { فِيهِ رِجَالٌ يُحِبُّونَ أَن يَتَطَهَّرُواْ } أن يغسلوا أدبارهم بالماء { وَٱللَّهُ يُحِبُّ ٱلْمُطَّهِّرِينَ } بالماء من الأدناس { أَفَمَنْ أَسَّسَ بُنْيَانَهُ } بني أساسه { عَلَىٰ تَقْوَىٰ مِنَ اللَّهِ } على طاعة الله وذكره { وَرِضْوَانٍ } بنوا إرادة رضوان ربهم وهو مسجد قباء { خَيْرٌ أَم مَّنْ أَسَّسَ بُنْيَانَهُ } بني أساسه وهو مسجد الشقاق { عَلَىٰ شَفَا جُرُفٍ } على طرف هوي وليس له أصل { هَارٍ } غار { فَٱنْهَارَ بِهِ } فغار به يعني بانيه { فِي نَارِ جَهَنَّمَ وَٱللَّهُ لاَ يَهْدِي ٱلْقَوْمَ ٱلظَّالِمِينَ } لا يغفر للمنافقين ولا ينجيهم { لاَ يَزَالُ بُنْيَانُهُمُ } بعدما هدمت { ٱلَّذِي بَنَوْاْ رِيبَةً } حسرة وندامة { فِي قُلُوبِهِمْ إِلاَّ أَن تَقَطَّعَ قُلُوبُهُمْ } إلا أن يموتوا { وَٱللَّهُ عَلِيمٌ } ببنيانهم مسجد الضرار وبنياتهم { حَكِيمٌ } فيما حكم من هدم مسجدهم وحرقه بعث إليه رسول الله صلى الله عليه وسلم بعد رجوعه من غزوة تبوك عامر بن قيس ووحشياً مولى مطعم بن عدي حتى أحرقاه وهدماه { إِنَّ ٱللَّهَ ٱشْتَرَىٰ مِنَ ٱلْمُؤْمِنِينَ } المخلصين { أَنفُسَهُمْ وَأَمْوَالَهُمْ بِأَنَّ لَهُمُ ٱلّجَنَّةَ } بالجنة { يُقَاتِلُونَ فِي سَبِيلِ ٱللَّهِ } في طاعة الله { فَيَقْتُلُونَ } العدو { وَيُقْتَلُونَ } ويقتلهم العدو { وَعْداً عَلَيْهِ } على الله { حَقّاً } واجباً أن يوفيهم { فِي ٱلتَّوْرَاةِ وَٱلإِنْجِيلِ وَٱلْقُرْآنِ وَمَنْ أَوْفَىٰ بِعَهْدِهِ مِنَ ٱللَّهِ } ومن أوفر بوفاء عهده من الله { فَٱسْتَبْشِرُواْ بِبَيْعِكُمُ ٱلَّذِي بَايَعْتُمْ بِهِ } الله يعني الجنة { وَذَلِكَ هُوَ ٱلْفَوْزُ ٱلْعَظِيمُ } النجاء الوافر ثم بيَّن من هم فقال { ٱلتَّائِبُونَ } أي هم التائبون من الذنوب { ٱلْعَابِدُونَ } المطيعون { ٱلْحَامِدُونَ } الشاكرون { ٱلسَّائِحُونَ } الصائمون { ٱلرَّاكِعُونَ ٱلسَّاجِدونَ } في الصلوات الخمس { ٱلآمِرُونَ بِٱلْمَعْرُوفِ } بالتوحيد والإحسان { وَٱلنَّاهُونَ عَنِ ٱلْمُنكَرِ } عن الكفر وما لا يعرف في شريعة ولا سنة { وَٱلْحَافِظُونَ لِحُدُودِ ٱللَّهِ } لفرائض الله { وَبَشِّرِ ٱلْمُؤْمِنِينَ } بالجنة.
