{ لاَّ تَجْعَلُواْ دُعَآءَ ٱلرَّسُولِ بَيْنَكُمْ } أي لا تدعوا الرسول باسمه يا محمد { كَدُعَآءِ بَعْضِكُمْ بَعْضاً } اسمه ولكن عظموه ووقروه وشرفوه وقولوا له يا نبي الله ويا رسول الله ويا أبا القاسم { قَدْ يَعْلَمُ ٱللَّهُ ٱلَّذِينَ يَتَسَلَّلُونَ مِنكُمْ } يخرجون منكم من المسجد { لِوَاذاً } يلوذ بعضكم بعضاً وكان المنافقون إذا خرجوا من المسجد خرجوا بغير إذن إذا لم يرهم أحد { فَلْيَحْذَرِ ٱلَّذِينَ يُخَالِفُونَ عَنْ أَمْرِهِ } عن أمر رسول الله صلى الله عليه وسلم ويقال عن أمر الله { أَن تُصِيبَهُمْ فِتْنَةٌ } بلية { أَوْ يُصِيبَهُمْ عَذَابٌ أَلِيمٌ } بالضرب { أَلاۤ إِنَّ لِلَّهِ مَا فِي ٱلسَّمَاوَاتِ وَٱلأَرْضِ } من الخلق { قَدْ يَعْلَمُ } أي يعلم الله { مَآ أَنتُمْ عَلَيْهِ } من الكفر والإيمان والتصديق والتكذيب والإخلاص والنفاق والاستقامة والميل وغير ذلك { وَيَوْمَ يُرْجَعُونَ إِلَيْهِ } إلى الله وهو يوم القيامة { فَيُنَبِّئُهُمْ } يخبرهم الله { بِمَا عَمِلُواْ } في الدنيا { وَٱللَّهُ بِكُلِّ شَيْءٍ } من أعمالهم { عَلِيمُ }.
