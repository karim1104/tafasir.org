{ مَآ أَصَابَ مِن مُّصِيبَةٍ فِي ٱلأَرْضِ } من القحط والجدوبة وغلاء السعر وتتابع الجوع { وَلاَ فِيۤ أَنفُسِكُمْ } من الأمراض والأوجاع والبلايا وموت الأهل والولد وذهاب المال { إِلاَّ فِي كِتَابٍ } يقول مكتوب عليكم في اللوح المحفوظ { مِّن قَبْلِ أَن نَّبْرَأَهَآ } أن نخلقها تلك الأنفس والأرض { إِنَّ ذَٰلِكَ } حفظ ذلك { عَلَى ٱللَّهِ يَسِيرٌ } هين من غير كتاب ولكن كتب { لِّكَيْلاَ تَأْسَوْاْ } لا تحزنوا { عَلَىٰ مَا فَاتَكُمْ } من الرزق والعافية فتقولوا لم يكتب لنا.  { وَلاَ تَفْرَحُواْ } لا تبطروا { بِمَآ آتَاكُمْ } بما أعطاكم فتقولوا هو أعطانا { وَٱللَّهُ لاَ يُحِبُّ كُلَّ مُخْتَالٍ } في مشيته { فَخُورٍ } بنعم الله ويقال مختال في الكفر فخور في الشرك وهم اليهود { ٱلَّذِينَ يَبْخَلُونَ } يكتمون صفة محمد صلى الله عليه وسلم ونعته في التوراة { وَيَأْمُرُونَ ٱلنَّاسَ بِٱلْبُخْلِ } في التوراة بكتمان صفة محمد عليه الصلاة والسلام ونعته { وَمَن يَتَوَلَّ } عن الإيمان { فَإِنَّ ٱللَّهَ هُوَ ٱلْغَنِيُّ } عن الإيمان { ٱلْحَمِيدُ } لمن وحدوه ويقال المحمود في فعاله يشكر اليسير ويجزي الجزيل { لَقَدْ أَرْسَلْنَا رُسُلَنَا بِٱلْبَيِّنَاتِ } بالأمر والنهي والعلامات { وَأَنزَلْنَا مَعَهُمُ ٱلْكِتَابَ } وأنزلنا عليهم جبريل بالكتاب { وَٱلْمِيزَانَ } بينا فيه العدل { لِيَقُومَ } ليأخذ { ٱلنَّاسُ بِٱلْقِسْطِ } بالعدل { وَأَنزْلْنَا ٱلْحَدِيدَ } خلقنا الحديد { فِيهِ بَأْسٌ شَدِيدٌ } قوة شديدة لا تلينه إلا النار ويقال فيه بأس شديد للحرب والقتال { وَمَنَافِعُ لِلنَّاسِ } لأمتعتهم مثل السكاكين والفأس والمبرد وغير ذلك { وَلِيَعْلَمَ ٱللَّهُ } لكي يرى الله { مَن يَنصُرُهُ وَرُسُلَهُ بِٱلْغَيْبِ } بهذه الأسلحة { إِنَّ ٱللَّهَ قَوِيٌّ } بنصرة أوليائه { عَزِيزٌ } بنقمة أعدائه { وَلَقَدْ أَرْسَلْنَا نُوحاً } إلى قومه بعد آدم بثمانمائة سنة فلبث في قومه ألف سنة إلا خمسين عاماً فلم يؤمنوا فأهلكهم الله بالطوفان { وَإِبْرَاهِيمَ } وأرسلنا إبراهيم إلى قومه بعد نوح بألف ومائتي عام واثنتين وأربعين سنة { وَجَعَلْنَا فِي ذُرِّيَّتِهِمَا } في نسلهما نسل نوح وإبراهيم { ٱلنُّبُوَّةَ وَٱلْكِتَابَ } وكان فيهم الأنبياء وفيهم الكتاب { فَمِنْهُمْ مُّهْتَدٍ } مؤمن بالكتاب والرسول { وَكَثِيرٌ مِّنْهُمْ فَاسِقُونَ } كافرون بالكتاب والرسول { ثُمَّ قَفَّيْنَا عَلَىٰ آثَارِهِم } أتبعنا وأردفنا بعد نوح وإبراهيم في ذريتهما { بِرُسُلِنَا } بعضهم على أثر بعض { وَقَفَّيْنَا } على آثارهم اتبعنا وأردفنا بعد هؤلاء الرسل غير محمد عليه الصلاة والسلام { بِعِيسَى ٱبْنِ مَرْيَمَ وَآتَيْنَاهُ } أعطيناه { ٱلإِنجِيلَ وَجَعَلْنَا فِي قُلُوبِ ٱلَّذِينَ ٱتَّبَعُوهُ } اتبعوا دين عيسى { رَأْفَةً } رقة وتعطفاً يعطف بعضهم على بعض { وَرَحْمَةً } يرحم بعضهم بعضاً { وَرَهْبَانِيَّةً ٱبتَدَعُوهَا } أعدوا لها الصوامع والديور ليترهبوا فيها وينجوا من فتنة بولس اليهودي { مَا كَتَبْنَاهَا عَلَيْهِمْ } ما فرضنا عليهم الرهبانية { إِلاَّ ٱبْتِغَآءَ رِضْوَانِ ٱللَّهِ } إلا طلب رضا الله ويقال ابتدعوها إلا ابتغاء رضوان الله ما كتبناها عليهم ما فرضنا عليهم الرهبانية ولو فرضنا عليهم الرهبانية { فَمَا رَعَوْهَا } فما حفظوا الرهبانية { حَقَّ رِعَايَتِهَا } حق حفظها { فَآتَيْنَا } فأعطينا { ٱلَّذِينَ آمَنُواْ مِنْهُمْ } من الرهبان { أَجْرَهُمْ } ثوابهم مرتين بالإيمان والعبادة وهم الذين لم يخالفوا دين عيسى ابن مريم وبقي منهم أربعة وعشرون رجلاً في أهل اليمن جاؤوا إلى النبي صلى الله عليه وسلم وآمنوا به ودخلوا في دينه { وَكَثِيرٌ مِّنْهُمْ } من الرهبان { فَاسِقُونَ } كافرون وهم الذين خالفوا دين عيسى { يَٰأَيُّهَا ٱلَّذِينَ آمَنُواْ ٱتَّقُواْ ٱللَّهَ } اخشوا الله { وَآمِنُواْ بِرَسُولِهِ } اثبتوا على إيمانكم بالله ورسوله { يُؤْتِكُمْ } يعطكم { كِفْلَيْنِ } ضعفين { مِن رَّحْمَتِهِ } من ثوابه وكرامته { وَيَجْعَل لَّكُمْ نُوراً تَمْشُونَ بِهِ } بين الناس وعلى الصراط { وَيَغْفِرْ لَكُمْ } ذنوبكم في الجاهلية { وَٱللَّهُ غَفُورٌ } لمن تاب { رَّحِيمٌ } لمن مات على التوبة { لِّئَلاَّ يَعْلَمَ } لكي يعلم { أَهْلُ ٱلْكِتَابِ } عبد الله بن سلام وأصحابه { أَلاَّ يَقْدِرُونَ عَلَىٰ شَيْءٍ مِّن فَضْلِ ٱللَّهِ } من ثواب الله { وَأَنَّ ٱلْفَضْلَ } الثواب والكرامة { بِيَدِ ٱللَّهِ يُؤْتِيهِ } يعطيه { مَن يَشَآءُ } من كان أهلاً لذلك { وَٱللَّهُ ذُو ٱلْفَضْلِ } ذو المن { ٱلْعَظِيمِ } على المؤمنين بالثواب والكرامة نزلت من قوله { يَٰأَيُّهَا ٱلَّذِينَ آمَنُواْ } إلى ها هنا في شأن عبد الله بن سلام حيث افتخر على أبي بن كعب وأصحابه بأن لنا أجرين ولكم أجر واحد.
