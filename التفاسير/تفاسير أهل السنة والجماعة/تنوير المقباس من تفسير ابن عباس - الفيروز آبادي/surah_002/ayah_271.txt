{ يٰأَيُّهَا ٱلَّذِينَ آمَنُوۤاْ أَنْفِقُواْ مِن طَيِّبَاتِ } من حلالات { مَا كَسَبْتُمْ } ما جمعتم من الذهب والفضة { وَمِمَّآ أَخْرَجْنَا لَكُم مِّنَ ٱلأَرْضِ } من النبات يعني الحبوب والثمار { وَلاَ تَيَمَّمُواْ ٱلْخَبِيثَ } لا تعمدوا إلى الرديء من أموالكم { مِنْهُ تُنْفِقُونَ وَلَسْتُمْ بِآخِذِيهِ } بقابليه يعني الرديء إذا كان لكم حق على صاحبكم.  { إِلاَّ أَن تُغْمِضُواْ فِيهِ } تنغمصوا فيه وتتركوا بعض حقكم كذلك لا يقبل الله الرديء منكم { وَٱعْلَمُوۤاْ أَنَّ ٱللَّهَ غَنِيٌّ } عن نفقاتكم { حَمِيدٌ } محمود في فعاله ويقال يشكر اليسير ويجزي الجزيل نزلت هذه الآية في رجل بالمدينة صاحب الحشف { ٱلشَّيْطَانُ يَعِدُكُمُ ٱلْفَقْرَ } يخوفكم الفقر عند الصدقة { وَيَأْمُرُكُم بِٱلْفَحْشَآءِ } بمنع الزكاة { وَٱللَّهُ يَعِدُكُم مَّغْفِرَةً مِّنْهُ } لذنوبكم بإعطاء الزكاة { وَفَضْلاً } خلفاً وثواباً في الآخرة { وَٱللَّهُ وَاسِعٌ } بالخلف والمغفرة للذنوب { عَلِيمٌ } بنياتكم وصدقاتكم ثم ذكر كرامته فقال { يُؤْتِي ٱلْحِكْمَةَ مَن يَشَآءُ } يعني النبوة لمحمد عليه الصلاة والسلام ويقال تفسير القرآن ويقال إصابة القول والفعل والرأي { وَمَن يُؤْتَ ٱلْحِكْمَةَ } إصابة القول والفعل والرأي { فَقَدْ أُوتِيَ } أعطي { خَيْراً كَثِيراً وَمَا يَذَّكَّرُ } يتعظ بأمثال القرآن والحكمة { إِلاَّ أُوْلُواْ ٱلأَلْبَابِ } ذوو العقول من الناس { وَمَآ أَنفَقْتُمْ مِّن نَّفَقَةٍ } في سبيل الله { أَوْ نَذَرْتُمْ مِّن نَّذْرٍ } في طاعة الله فوفيتم به.  { فَإِنَّ ٱللَّهَ يَعْلَمُهُ } يقبله إذا كان لله ويثيب عليها { وَمَا لِلظَّالِمِينَ } للمشركين { مِنْ أَنْصَارٍ } من مانع من عذاب الله ثم ذكر صدقة السر والعلانية لقولهم أيهما أفضل فقال { إِن تُبْدُواْ } إن تظهروا { ٱلصَّدَقَاتِ } الواجبة { فَنِعِمَّا هِيَ } فنعم شيئاً هي { وَإِن تُخْفُوهَا } تسروها يعني التطوع { وَتُؤْتُوهَا } تعطوها { ٱلْفُقَرَآءَ } أصحاب الصفة { فَهُوَ خَيْرٌ لَّكُمْ } من العلانية وكلاهما مقبول منكم { وَيُكَفِّرُ عَنكُم مِّن سَيِّئَاتِكُمْ } ذنوبكم بقدر صدقاتكم { وَٱللَّهُ بِمَا تَعْمَلُونَ } تعطون من الصدقة { خَبِيرٌ } ثم رخص الصدقة على فقراء أهل الكتاب والمشركين لقولهم أيجوز لنا يا رسول الله أن نصدق على ذوي قرابتنا من غير أهل ديننا سألت عن ذلك أسماء بنت أبي بكر ويقال بنت أبي النضر فقال الله لنبيه { لَّيْسَ عَلَيْكَ هُدَاهُمْ } في الدين هدى فقراء أهل الكتاب { وَلَـٰكِنَّ ٱللَّهَ يَهْدِي مَن يَشَآءُ } لدينه.  { وَمَا تُنفِقُواْ مِنْ خَيْرٍ } من مال على الفقراء { فَلأَنفُسِكُمْ } ثواب ذلك { وَمَا تُنفِقُونَ } على الفقراء فلا تنفقون { إِلاَّ ٱبْتِغَآءَ وَجْهِ ٱللَّهِ } طلب مرضاة الله { وَمَا تُنفِقُواْ مِنْ خَيْرٍ } من مال على فقراء أصحاب الصفة { يُوَفَّ إِلَيْكُمْ } يوفر إليكم ثواب ذلك في الآخرة { وَأَنتُمْ لاَ تُظْلَمُونَ } لا ينقص من حسناتكم ولا يزاد على سيئاتكم.
