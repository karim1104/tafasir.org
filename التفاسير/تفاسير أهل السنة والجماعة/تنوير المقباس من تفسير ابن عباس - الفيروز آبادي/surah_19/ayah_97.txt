{ إِن كُلُّ مَن فِي ٱلسَّمَاوَاتِ وَٱلأَرْضِ } يقول ما من أحد في السموات والأرض { إِلاَّ آتِي ٱلرَّحْمَـٰنِ عَبْداً } إلا مقراً للرحمن بالعبودية مطيعاً له غير الكافر { لَّقَدْ أَحْصَاهُمْ } حفظهم { وَعَدَّهُمْ عَدّاً } عالم بعدهم { وَكُلُّهُمْ آتِيهِ } يجيء إلى الله { يَوْمَ ٱلْقِيَامَةِ فَرْداً } وحيداً بلا مال ولا ولد { إِنَّ ٱلَّذِينَ آمَنُواْ } بمحمد صلى الله عليه وسلم والقرآن { وَعَمِلُواْ ٱلصَّالِحَاتِ } الطاعات فيما بينهم وبين ربهم { سَيَجْعَلُ لَهُمُ ٱلرَّحْمَـٰنُ وُدّاً } يحبهم ويحببهم إلى المؤمنين { فَإِنَّمَا يَسَّرْنَاهُ بِلِسَانِكَ } هونا عليك قراءة القرآن { لِتُبَشِّرَ بِهِ } بالقرآن { ٱلْمُتَّقِينَ } الكفر والشرك والفواحش { وَتُنْذِرَ } تخوف { بِهِ } بالقرآن { قَوْماً لُّدّاً } جدلاً بالباطل { وَكَمْ أَهْلَكْنَا قَبْلَهُمْ } قبل قومك يا محمد { مِّن قَرْنٍ } من القرون الماضية { هَلْ تُحِسُّ مِنْهُمْ مِّنْ أَحَدٍ } هل ترى منهم أحداً بعد الهلاك { أَوْ تَسْمَعُ لَهُمْ رِكْزاً } صوتاً بعد ما هلكوا ودرسوا.
