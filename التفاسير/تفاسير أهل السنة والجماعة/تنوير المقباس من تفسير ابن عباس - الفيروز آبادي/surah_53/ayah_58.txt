{ وَأَنَّهُ هُوَ رَبُّ ٱلشِّعْرَىٰ } الكوكب الذي يتبع الجوزاء كان يعبده خزاعة { وَأَنَّهُ أَهْلَكَ عَاداً ٱلأُولَىٰ } قوم هود { وَثَمُودَ } قوم صالح { فَمَآ أَبْقَىٰ } فلم يترك منهم أحداً { وَقَوْمَ نُوحٍ } وأهلك قوم نوح { مِّن قَبْلُ } من قبل قوم صالح { إِنَّهُمْ } يعني قوم نوح { كَانُواْ هُمْ أَظْلَمَ } أشد في كفرهم { وَأَطْغَىٰ } أشد في طغيانهم ومعصيتهم { وَٱلْمُؤْتَفِكَةَ أَهْوَىٰ } وأهلك قريات لوط سدوم وصادوم وعمورا وصوائم والمؤتفكات المنخسفات وائتفكها خسفها أهوى هوت من السماء إلى الأرض { فَغَشَّاهَا مَا غَشَّىٰ } يعني الحجارة { فَبِأَيِّ آلاۤءِ رَبِّكَ } فبأي نعماء ربك أيها الإنسان غير محمد صلى الله عليه وسلم { تَتَمَارَىٰ } تتجاحد أنها ليست من الله { هَـٰذَا نَذِيرٌ } يعني محمداً عليه الصلاة والسلام رسول مخوف { مِّنَ ٱلنُّذُرِ ٱلأُوْلَىٰ } كالرسل الأولى الذين أرسلناهم إلى قومهم ويقال هذا نذير من النذر رسول من الرسل الأولى الذين هم مكتوبون في اللوح المحفوظ أن أرسلهم إلى قومهم { أَزِفَتِ ٱلآزِفَةُ } دنا قيام الساعة { لَيْسَ لَهَا } لقيامها { مِن دُونِ ٱللَّهِ } غير الله { كَاشِفَةٌ } مبين يبين قيامها ووقتها { أَفَمِنْ هَـٰذَا ٱلْحَدِيثِ } يقول أمن هذا القرآن الذي يقرأ عليكم محمد صلى الله عليه وسلم يا أهل مكة { تَعْجَبُونَ } تسخرون ويقال تكذبون { وَتَضْحَكُونَ } تهزؤون ويقال تسخرون { وَلاَ تَبْكُونَ } مما فيه من الزجر والوعيد والتخويف { وَأَنتُمْ سَامِدُونَ } لاهون عنه لا تؤمنون به { فَٱسْجُدُواْ لِلَّهِ } فاخضعوا لله بالتوحيد والتوبة { وَٱعْبُدُواْ } وحدوا الله لله فقد اقتربت الساعة.
