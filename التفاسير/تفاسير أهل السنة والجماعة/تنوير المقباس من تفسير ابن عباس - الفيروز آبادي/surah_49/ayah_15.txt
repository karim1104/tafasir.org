{ قَالَتِ ٱلأَعْرَابُ آمَنَّا } نزلت هذه الآية في بني أسد أصابتهم سنة شديدة فدخلوا في الإسلام متوافرين بأهاليهم وذراريهم وجاؤوا إلى النبي صلى الله عليه وسلم بالمدينة ليصيبوا من فضله فغلوا أسعار المدينة وأفسدوا طرقها بالعذرات وكانوا منافقين يقولون أطعمنا وأكرمنا يا رسول الله فإنا مخلصون مصدقون في إيماننا وكانوا منافقين في دينهم كاذبين في قولهم فذكر الله مقالتهم فقال قالت الأعراب بنو أسد آمنا صدقنا في إيماننا بالله ورسوله { قُل } لهم يا محمد { لَّمْ تُؤْمِنُواْ } لم تصدقوا في إيمانكم بالله ورسوله { وَلَـٰكِن قُولُوۤاْ أَسْلَمْنَا } أي استسلمنا من السيف والسبي { وَلَمَّا يَدْخُلِ ٱلإِيمَانُ } لم يدخل حب الإيمان وتصديق الإيمان { فِي قُلُوبِكُمْ وَإِن تُطِيعُواْ ٱللَّهَ وَرَسُولَهُ } في السر كما أطعتموهما في العلانية وتتوبوا من الكفر والسر والنفاق { لاَ يَلِتْكُمْ مِّنْ أَعْمَالِكُمْ } لا ينقصكم من ثواب حسناتكم { شَيْئاً إِنَّ ٱللَّهَ غَفُورٌ } لمن تاب منكم { رَّحِيمٌ } لمن مات على التوبة ثم بين نعت المؤمنين المصدقين في إيمانهم فقال { إِنَّمَا ٱلْمُؤْمِنُونَ } المصدقون في إيمانهم { ٱلَّذِينَ آمَنُواْ بِٱللَّهِ } صدقوا في إيمانهم بالله { وَرَسُولِهِ ثُمَّ لَمْ يَرْتَابُواْ } لم يشكوا في إيمانهم { وَجَاهَدُواْ بِأَمْوَالِهِمْ وَأَنفُسِهِمْ فِي سَبِيلِ ٱللَّهِ } في طاعة الله { أُوْلَـٰئِكَ هُمُ ٱلصَّادِقُونَ } المصدقون في إيمانهم وجهادهم { قُلْ } يا محمد لبني أسد { أَتُعَلِّمُونَ ٱللَّهَ } أتخبرون الله { بِدِينِكُمْ } الذي أنتم عليه أمصدقون به أم مكذبون { وَٱللَّهُ يَعْلَمُ مَا فِي ٱلسَّمَاوَاتِ وَمَا فِي ٱلأَرْضِ } ما في قلوب أهل السموات وما في قلوب أهل الأرض { وَٱللَّهُ بِكُلِّ شَيْءٍ عَلِيمٌ } من سر أهل السموات والأرض { يَمُنُّونَ عَلَيْكَ } يا محمد بنو أسد { أَنْ أَسْلَمُواْ } وهو قولهم أطعمنا وأكرمنا يا رسول الله فقد أسلمنا متوافرين { قُل } لهم يا محمد { لاَّ تَمُنُّواْ عَلَيَّ إِسْلاَمَكُم } بإسلامكم { بَلِ ٱللَّهُ يَمُنُّ عَلَيْكُمْ } بل لله المنة عليكم { أَنْ هَداكُمْ } أن دعاكم { لِلإِيمَانِ } لتصديق الإيمان { إِنُ كُنتُمْ صَادِقِينَ } بأنا مصدقون ولكن أنتم كاذبون لستم بمصدقين في إيمانكم { إِنَّ اللَّهَ يَعْلَمُ غَيْبَ ٱلسَّمَاوَاتِ وَٱلأَرْضِ } غيب ما يكون في السموات والأرض { وَٱللَّهُ بَصِيرٌ بِمَا تَعْمَلُونَ } في نفاقكم يا معشر المنافقين وبعقوبتكم إن لم تتوبوا.
