{ وَشَرَوْهُ } باعوه إخوته من مالك بن دعر { بِثَمَنٍ بَخْسٍ } نقصان بالوزن ويقال زيوف ويقال حرام { دَرَاهِمَ مَعْدُودَةٍ } عشرين درهماً ويقال اثنين وثلاثين درهماً { وَكَانُواْ فِيهِ } في ثمن يوسف { مِنَ ٱلزَّاهِدِينَ } لم يحتاجوا إليه ويقال كان إخوة يوسف في يوسف من الزاهدين لم يعرفوا قدره ومنزلته عند الله تعالى ويقال كان أهل القافلة في يوسف من الزاهدين { وَقَالَ ٱلَّذِي ٱشْتَرَاهُ } اشترى يوسف { مِن مِّصْرَ } في مصر وهو العزيز خازن الملك وهو صاحب جنود وكان يسمى قطفير { لاِمْرَأَتِهِ } زليخا { أَكْرِمِي مَثْوَاهُ } قدره ومنزلته { عَسَىٰ أَن يَنفَعَنَآ } في ضيعتنا { أَوْ نَتَّخِذَهُ وَلَداً } أو نتبناه وكان اشتراه من مالك بن دعر بعشرين درهماً وحلة ونعلين { وَكَذٰلِكَ } هكذا { مَكَّنَّا لِيُوسُفَ } ملكنا يوسف { فِي ٱلأَرْضِ } أرض مصر { وَلِنُعَلِّمَهُ مِن تَأْوِيلِ ٱلأَحَادِيثِ } تعبير الرؤيا { وَٱللَّهُ غَالِبٌ عَلَىٰ أَمْرِهِ } على مقدروه ولا يرد مقدوره أحد { وَلَـٰكِنَّ أَكْثَرَ ٱلنَّاسِ } أهل مصر { لاَ يَعْلَمُونَ } ذلك ولا يصدقون ويقال لا يعلمون أن الله غالب على أمره { وَلَمَّا بَلَغَ أَشُدَّهُ } والأشد من ثمان عشرة سنة إلى ثلاثين سنة { آتَيْنَاهُ } أعطيناه { حُكْماً وَعِلْماً } فهماً ونبوة { وَكَذٰلِكَ } هكذا { نَجْزِي ٱلْمُحْسِنِينَ } بالقول والفعل بالعلم والحكمة.  { وَرَاوَدَتْهُ } طلبته { ٱلَّتِي هُوَ فِي بَيْتِهَا عَن نَّفْسِهِ } أن تستمكن من نفسه { وَغَلَّقَتِ ٱلأَبْوَابَ } عليها وعلى يوسف { وَقَالَتْ } ليوسف { هَيْتَ لَكَ } هلم أنا لك ويقال تعال أنا لك ويقال تهيأت لك معناه إن قرأت بنصب الهاء والتاء هلم لك وإن قرأت بكسر الهاء وضم التاء والهمزة تهيأت لك وإن قرأت بنصب الهاء ورفع التاء تعال أنا لك { قَالَ } يوسف { مَعَاذَ ٱللَّهِ } أعوذ بالله من هذا الأمر { إِنَّهُ رَبِّيۤ } سيدي العزيز { أَحْسَنَ مَثْوَايَ } قدري ومنزلتي لا أخونه في أهله { إِنَّهُ لاَ يُفْلِحُ } لا يأمن ولا ينجو { ٱلظَّالِمُونَ } الزانون من عذاب الله { وَلَقَدْ هَمَّتْ بِهِ } المرأة { وَهَمَّ بِهَا } يوسف { لَوْلاۤ أَن رَّأَى بُرْهَانَ رَبِّهِ } عذاب ربه لازماً على نفسه ويقال رأى صورة أبيه ويقال لولا أن رأى برهان ربه لهم مقدم ومؤخر { كَذَلِكَ } هكذا { لِنَصْرِفَ عَنْهُ ٱلسُّوۤءَ } القبيح { وَٱلْفَحْشَآءَ } يعني الزنا { إِنَّهُ مِنْ عِبَادِنَا ٱلْمُخْلَصِينَ } المعصومين من الزنا.
