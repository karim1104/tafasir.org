{ وَٱتَّبَعْتُ مِلَّةَ آبَآئِـيۤ } استقمت على دين آبائي { إِبْرَاهِيمَ وَإِسْحَاقَ وَيَعْقُوبَ مَا كَانَ لَنَآ } ما جاز لنا { أَن نُّشْرِكَ بِٱللَّهِ مِن شَيْءٍ } شيئاً من الأصنام { ذٰلِكَ } الدين القيم النبوة والإسلام اللذان أكرمنا الله بهما { مِن فَضْلِ ٱللَّهِ عَلَيْنَا } منّ من الله علينا { وَعَلَى ٱلنَّاسِ } بإرسالنا إليهم ويقال على المؤمنين بالإيمان { وَلَـٰكِنَّ أَكْثَرَ ٱلنَّاسِ } أهل مصر { لاَ يَشْكُرُونَ } لا يؤمنون بذلك { يَٰصَاحِبَيِ ٱلسِّجْنِ } قال هذا للسجان ولأهل السجن { ءَأَرْبَابٌ مُّتَّفَرِّقُونَ خَيْرٌ } يقول أعبادة آلهة شتى خير { أَمِ ٱللَّهُ ٱلْوَاحِدُ ٱلْقَهَّارُ } أم عبادة الله الواحد بلا ولد ولا شريك القهار الغالب على خلقه { مَا تَعْبُدُونَ مِن دُونِهِ } من دون الله { إِلاَّ أَسْمَآءً } أصناماً أمواتاً { سَمَّيْتُمُوهَآ أَنتُمْ وَآبَآؤُكُمْ } الآلهة { مَّآ أَنزَلَ ٱللَّهُ بِهَا } بعبادتكم لها { مِن سُلْطَانٍ } من كتاب ولا حجة { إِنِ ٱلْحُكْمُ } ما الحكم بالأمر والنهي ويقال ما القضاء في الدنيا والآخرة { إِلاَّ لِلَّهِ أَمَرَ } في الكتب كلها { أَلاَّ تَعْبُدُوۤاْ } أن لا توحدوا { إِلاَّ إِيَّاهُ } إلا الله { ذٰلِكَ } التوحيد { ٱلدِّينُ ٱلْقَيِّمُ } وهو الدين القائم الذي يرضاه وهو الإسلام { وَلَـٰكِنَّ أَكْثَرَ ٱلنَّاسِ } أهل مصر { لاَ يَعْلَمُونَ } ذلك ولا يصدقون ثم بين تعبير رؤيا الفتيين فقال { يَٰصَاحِبَيِ ٱلسِّجْنِ أَمَّآ أَحَدُكُمَا } وهو الساقي فيرجع إلى مكانه وسلطانه الذي كان فيه { فَيَسْقِي رَبَّهُ } سيده الملك { خَمْراً وَأَمَّا ٱلآخَرُ } وهو الخباز يخرج من السجن { فَيُصْلَبُ فَتَأْكُلُ ٱلطَّيْرُ مِن رَّأْسِهِ } ففزعا لتعبير رؤيا الخباز وقالا جميعاً ما رأينا شيئاً قال لهما يوسف { قُضِيَ ٱلأَمْرُ ٱلَّذِي فِيهِ تَسْتَفْتِيَانِ } تسألان فكما قلتما وقلت لكما كذلك يكون رأيتما أو لم تريا { وَقَالَ لِلَّذِي ظَنَّ } علم { أَنَّهُ نَاجٍ مِّنْهُمَا } من السجن والقتل وهو الساقي { ٱذْكُرْنِي عِندَ رَبِّكَ } عند سيدك الملك أني مظلوم عدا عليَّ إخوتي فباعوني وأنا حر وحبست في السجن وأنا مظلوم { فَأَنْسَاهُ ٱلشَّيْطَانُ ذِكْرَ رَبِّهِ } فأشغله الشيطان حتى نسي ذكر يوسف عند سيده الملك ويقال وسوس له الشيطان إن ذكرت السجن للملك يرجعك إلى السجن فلذلك لم يذكره ويقال فأنساه الشيطان أنسى الشيطان يوسف ذكر ربه حتى ترك ذكر ربه وذكر مخلوقاً دونه { فَلَبِثَ } فمكث { فِي ٱلسِّجْنِ بِضْعَ سِنِينَ } عقوبة بترك ذكر الله وكان قبل هذا في السجن خمس سنين { وَقَالَ ٱلْمَلِكُ إِنِّيۤ أَرَىٰ } رأيت في المنام { سَبْعَ بَقَرَاتٍ سِمَانٍ } خرجن من نهر { يَأْكُلُهُنَّ } يبتلعهن { سَبْعٌ عِجَافٌ } بقرات هالكات من الهزال خرجن من بعد السمان ولم يستبن عليهن شيء { وَسَبْعَ سُنْبُلاَتٍ خُضْرٍ وَأُخَرَ يَابِسَاتٍ } التوين على الخضر وغلبن خضرتهن ولم يستبن عليهن شيء { يَٰأَيُّهَا ٱلْمَلأُ } يعني العرافين والسحرة والكهنة { أَفْتُونِي فِي رُؤْيَايَ } في تعبير رؤياي { إِن كُنتُمْ لِلرُّؤْيَا تَعْبُرُونَ } تعلمون.
