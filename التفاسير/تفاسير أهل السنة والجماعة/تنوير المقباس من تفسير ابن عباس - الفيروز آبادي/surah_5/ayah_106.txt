{ وَإِذَا قِيلَ لَهُمْ } قال لهم النبي صلى الله عليه وسلم لمشركى أهل مكة { تَعَالَوْاْ إِلَىٰ مَآ أَنزَلَ ٱللَّهُ } إلى تحليل ما بيَّن الله في القرآن { وَإِلَى ٱلرَّسُولِ } وإلى ما بيَّن لكم الرسول من التحليل { قَالُواْ حَسْبُنَا مَا وَجَدْنَا عَلَيْهِ آبَاءَنَآ } من التحريم { أَوَلَوْ كَانَ آبَاؤُهُمْ } وقد كان آباؤهم { لاَ يَعْلَمُونَ شَيْئاً } من التوحيد والدين { وَلاَ يَهْتَدُونَ } لسنة نبي ويقال أو ليس كان آباؤهم لا يعلمون شيئاً من الدين ولا يهتدون لسنة النبي فكيف هم يقتدون بهم { يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ عَلَيْكُمْ أَنْفُسَكُمْ } أقبلوا على أنفسكم { لاَ يَضُرُّكُمْ مَّن ضَلَّ } ضلالة من ضل { إِذَا ٱهْتَدَيْتُمْ } إلى الإيمان وبينتم ضلالتهم { إِلَى ٱللَّهِ مَرْجِعُكُمْ } بعد الموت { جَمِيعاً فَيُنَبِّئُكُمْ } يخبركم { بِمَا كُنْتُمْ تَعْمَلُونَ } وتقولون من الخير والشر نزلت هذه الآية من قوله { عَلَيْكُمْ أَنفُسَكُمْ } إلى ههنا في مشركي أهل مكة حين قبل النبي صلى الله عليه وسلم من أهل الكتاب الجزية ولم يقبل منهم وقد بينت قصة هذا في سورة البقرة { يِا أَيُّهَا ٱلَّذِينَ آمَنُواْ شَهَادَةُ بَيْنِكُمْ } عليكم بالشهادة فيما يكون بينكم في السفر والحضر { إِذَا حَضَرَ أَحَدَكُمُ ٱلْمَوْتُ حِينَ ٱلْوَصِيَّةِ } عند وصية الميت { ٱثْنَانِ } فليشهد شاهدان { ذَوَا عَدْلٍ مِّنْكُمْ } من أحراركم حران ويقال من قومكم { أَوْ آخَرَانِ مِنْ غَيْرِكُمْ } من غير أهل دينكم ويقال من غير قومكم ثم ذكر السفر وترك الحضر فقال { إِنْ أَنتُمْ ضَرَبْتُمْ } سرتم وسافرتم { فِي ٱلأَرْضِ فَأَصَابَتْكُم مُّصِيبَةُ ٱلْمَوْتِ } نزلت هذه الآية في ثلاثة نفر اصطحبوا في التجارة إلى البلد بلد الشام فمات أحدهم بالبلد يقال له بديل بن أبي مارية مولى عمرو بن العاص وكان مسلماً فأوصى صاحبيه عدي بن بداء وتميم بن أوس الداري وكانا نصرانيين فخانا في الوصية فقال الله لأولياء الميت { تَحْبِسُونَهُمَا } يعني النصرانيين { مِن بَعْدِ ٱلصَّلاَةِ } صلاة العصر { فَيُقْسِمَانِ بِٱللَّهِ } فيحلفان به { إِنِ ٱرْتَبْتُمْ } إن شككتم يا أولياء الميت إن المال أكثر مما أتيا به { لاَ نَشْتَرِي بِهِ } وليقولا لا نشتري باليمين { ثَمَناً } عوضاً يسيراً من الدنيا { وَلَوْ كَانَ ذَا قُرْبَىٰ } ولو كان الميت ذا قرابة منا في الرحم { وَلاَ نَكْتُمُ شَهَادَةَ ٱللَّهِ } وليقولا لا نكتم شهادة الله عندنا إذا سئلنا { إِنَّآ } إن كتمنا { إِذَاً } حينئذ { لَّمِنَ ٱلآَثِمِينَ } العاصين فتبين بعد ما حلفا خيانتهما وعلم بذلك أولياء الميت.
