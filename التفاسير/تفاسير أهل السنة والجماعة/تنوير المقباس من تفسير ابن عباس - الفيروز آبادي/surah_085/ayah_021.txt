وبإسناده عن ابن عباس في قوله تعالى { وَٱلسَّمَآءِ ذَاتِ ٱلْبُرُوجِ } يقول أقسم الله بالسماء ذات البروج ويقال ذات القصور اثنا عشر قصراً بين السماء والأرض يعلم الله ذلك { وَٱلْيَوْمِ ٱلْمَوْعُودِ } وهو يوم القيامة { وَشَاهِدٍ } وهو يوم الجمعة { وَمَشْهُودٍ } وهو يوم عرفة ويقال يوم النحر ويقال شاهد بنو آدم ومشهود هو يوم القيامة ويقال شاهد محمد عليه الصلاة والسلام ومشهود أمته أقسم الله بهؤلاء الأشياء إن بطش ربك عذاب ربك لشديد لمن لا يؤمن به { قُتِلَ أَصْحَابُ ٱلأُخْدُودِ ٱلنَّارِ ذَاتِ ٱلْوَقُودِ } بالنفط والزفت والحطب ويقال لعنوا ويقال هم قوم من المؤمنين قتلهم الكفار بالنار ذات الوقود بالنفط والزفت والحطب { إِذْ هُمْ } يعني الكفار { عَلَيْهَا } على الخندق ويقال على الكراسي { قُعُودٌ } جلوس حين أحرقهم الله بالنار { وَهُمْ عَلَىٰ مَا يَفْعَلُونَ بِٱلْمُؤْمِنِينَ شُهُودٌ } حضور ويقال كانوا يشهدون على المؤمنين أن هؤلاء قوم ضلال { وَمَا نَقَمُواْ مِنْهُمْ } من المؤمنين ولا طعنوا عليهم { إِلاَّ أَن يُؤْمِنُواْ بِٱللَّهِ } إلا لقبل إيمانهم بالله { ٱلْعَزِيزِ } بالنقمة لمن لا يؤمن به { ٱلْحَمِيدِ } لمن آمن به { ٱلَّذِي لَهُ مُلْكُ ٱلسَّمَاوَاتِ } خزائن السموات المطر { وَٱلأَرْضِ } النبات { وَٱللَّهُ عَلَى كُلِّ شَيْءٍ } من أعمالهم { شَهِيدٌ إِنَّ ٱلَّذِينَ فَتَنُواْ } أحرقوا وعذبوا { ٱلْمُؤْمِنِينَ } بالنار يعني المصدقين من الرجال بالإيمان { وَٱلْمُؤْمِنَاتِ } المصدقات من النساء بالإيمان { ثُمَّ لَمْ يَتُوبُواْ } من كفرهم وشركهم { فَلَهُمْ عَذَابُ جَهَنَّمَ } في الآخرة { وَلَهُمْ عَذَابُ ٱلْحَرِيقِ } الشديد في النار ويقال في الدنيا حيث أحرقهم الله بالنار وكان هؤلاء قوماً من نجران ويقال من أهل الموصل أخذوا قوماً من المؤمنين فعذبوهم وقتلوهم بالنار لكي يرجعوا إلى دينهم وكان ملكهم يسمى يوسف ويقال ذا النواس. ثم ذكر المؤمنين الذين لم يرجعوا عن الإيمان لقبل عذابهم فقال { إِنَّ ٱلَّذِينَ آمَنُواْ } بالله { وَعَمِلُواْ ٱلصَّالِحَاتِ } فيما بينهم وبين ربهم { لَهُمْ جَنَّاتٌ } بساتين { تَجْرِي مِن تَحْتِهَا } من تحت شجرها ومساكنها { ٱلأَنْهَارُ } أنهار الخمر والماء والعسل واللبن { ذَٰلِكَ ٱلْفَوْزُ ٱلْكَبِيرُ } النجاة الوافرة فازوا بالجنة ونجوا من النار { إِنَّ بَطْشَ رَبِّكَ } أخذ ربك لمن لا يؤمن به { لَشَدِيدٌ إِنَّهُ هُوَ يُبْدِىءُ } الخلق من النطفة { وَيُعِيدُ } بعد الموت خلقاً جديداً { وَهُوَ ٱلْغَفُورُ } المتجاوز لمن تاب من الكفر وآمن بالله { ٱلْوَدُودُ } المتودد لأوليائه ويقال المحب لأهل طاعته ويقال المتحبب إلى أهل طاعته { ذُو ٱلْعَرْشِ } ذو السرير { ٱلْمَجِيدُ } الحسن الجيد ويقال الكريم إن قرأت بضم الدال فهو الله { فَعَّالٌ لِّمَا يُرِيدُ } كما يريد يحيي ويميت { هَلُ أَتَاكَ } يا محمد استفهم نبيه بذلك ولم يأته قبل ذلك فأتاه بعد ذلك { حَدِيثُ ٱلْجُنُودِ } يقول خبر جموع { فِرْعَوْنَ وَثَمُودَ } والذين من قبلهم ومن بعدهم كيف فعلنا بهم عند التكذيب { بَلِ ٱلَّذِينَ كَفَرُواْ } كفار مكة { فِي تَكْذِيبٍ } بمحمد عليه الصلاة والسلام والقرآن { وَٱللَّهُ مِن وَرَآئِهِمْ مُّحِيطٌ } يقول عالم بهم وبأعمالهم { بَلْ هُوَ } يعني القرآن الذي يقرأ عليكم محمد صلى الله عليه وسلم { قُرْآنٌ مَّجِيدٌ } كريم شريف { فِي لَوْحٍ مَّحْفُوظٍ } يقول مكتوب في لوح محفوظ من الشياطين.
