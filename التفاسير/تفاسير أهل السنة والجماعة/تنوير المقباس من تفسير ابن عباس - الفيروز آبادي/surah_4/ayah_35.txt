{ ٱلرِّجَالُ قَوَّامُونَ عَلَى ٱلنِّسَآءِ } مسلطون على أدب النساء { بِمَا فَضَّلَ ٱللَّهُ بَعْضَهُمْ } الرجال بالعقل والقسمة في الغنائم والميراث { عَلَىٰ بَعْضٍ } يعني النساء { وَبِمَآ أَنْفَقُواْ مِنْ أَمْوَالِهِمْ } يعني بالمهر والنفقة التي عليهم دونهن { فَٱلصَّالِحَاتُ } يقول المحسنات إلى أزواجهن { قَانِتَاتٌ } مطيعات لله في أزواجهن { حَافِظَاتٌ } لأنفسهن ومال أزواجهن { لِّلْغَيْبِ } لغيب أزواجهن { بِمَا حَفِظَ ٱللَّهُ } بحفظ الله إياهن بالتوفيق { وَٱللاَّتِي تَخَافُونَ } تعلمون { نُشُوزَهُنَّ } عصيانهن في المضاجع معكم { فَعِظُوهُنَّ } بالعلم والقرآن { وَٱهْجُرُوهُنَّ فِي ٱلْمَضَاجِعِ } حولوا عنهن وجوهكم في الفراش { وَٱضْرِبُوهُنَّ } ضرباً غير مبرح ولا شائن { فَإِنْ أَطَعْنَكُمْ } في المضاجع { فَلاَ تَبْغُواْ } فلا تطلبوا { عَلَيْهِنَّ سَبِيلاً } في الحب { إِنَّ ٱللَّهَ كَانَ عَلِيّاً } أعلى كل شيء { كَبِيراً } أكبر كل شيء لم يكلفهم ذلك فلا تكلفوا النساء ما لا طاقة لهن به من المحبة { وَإِنْ خِفْتُمْ } علمتم { شِقَاقَ بَيْنِهِمَا } مخالفة بين الرجل والمرأة ولم تدروا من أيهما { فَٱبْعَثُواْ حَكَماً مِّنْ أَهْلِهِ } من أهل الرجل إلى الرجل حتى يسمع كلامه ويعلم ظالماً هو أو مظلوماً { وَحَكَماً مِّنْ أَهْلِهَآ } من أهل المرأة إلى المرأة حتى يسمع كلامها ويعلم ظالمة هي أو مظلومة { إِن يُرِيدَآ } الحكمان { إِصْلاَحاً } بين المرأة والرجل { يُوَفِّقِ ٱللَّهُ بَيْنَهُمَآ } بين الحكمين المرأة والرجل { إِنَّ ٱللَّهَ كَانَ عَلِيماً } بموافقة الحكمين ومخالفتهما { خَبِيراً } بفعل المرأة والرجل. نزلت من قوله إلى ههنا في بنت محمد بن سلمة بلطمة لطمها زوجها أسعد بن الربيع لقبل عصيانها في المضاجع فطلبت من النبي صلى الله عليه وسلم قصاصها من زوجها فنهاها الله عن ذلك.
