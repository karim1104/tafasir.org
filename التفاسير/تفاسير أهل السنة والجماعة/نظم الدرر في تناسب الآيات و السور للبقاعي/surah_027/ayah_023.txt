فكأنه قيل : ما هو ؟ فقال : { إني وجدت امرأة } وهي بلقيس بنت شراحيل { تملكهم } أي أهل سبأ .  <br />
ولما كانت قد أوتيت من كل ما يحتاج إليه الملوك أمراً كبيراً قال : { وأوتيت } بنى الفعل للمفعول إقراراً بأنها مع ملكها مربوبة { من كل شيء } تهويلاً لما رأى من أمرها .  <br />
ولما كان عرشها - أي السرير الذي تجلس عليه للحكم - زائداً في العظمة ،   خصه بقوله : { ولها عرش } أي سرير تجلس عليه للحكم { عظيم* } أي لم أر لأحد مثله .  <br />
