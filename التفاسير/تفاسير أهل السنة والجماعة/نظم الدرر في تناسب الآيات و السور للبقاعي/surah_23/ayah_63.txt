ولما كان التقدير : ولكنهم بذلك لا يعلمون ،   قال : { بل قلوبهم } أي الكفرة من الخلق ؛ ويجوز أن يكون هذا الإضراب بدلاً من قوله { بل لا يشعرون } { في غمرة } أي جهالة قد أغرقتها { من هذا } أي الذي أخبرنا به من الكتاب الحفيظ فهم به كافرون { ولهم أعمال } وأثبت الجار إشارة إلى أنه لا عمل لهم يستغرق الدون فقال : { من دون ذلك } أي مبتدئة من أدنى رتبة التكذيب من سائر المعاصي لأجل تكذيبهم بالكتاب المستلزم لتكذيبهم بالبعث المستلزم لعدم الخوف المستلزم للإقدام على كل معضلة { هم لها } أي دائماً { عاملون* } لا شيء يكفهم إلا عجزهم عنها .  <br />
