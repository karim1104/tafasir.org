ثم استانف الإخبار عن{[18774]} ملخص{[18775]} حالهم معهم فقال منبهاً أو {[18776]}مبدلاً الهاء من همزة{[18777]} الإنكار : { ها أنتم أولاء } أي المؤمنون المسلمون المستسلمون { تحبونهم } أي لاغتراركم بإقرارهم بالإيمان لصفاء بواطنكم{[18778]} { ولا{[18779]} } أي والحال أنهم لا { يحبونكم } لمخالفتهم لكم في الدين ،   فإنهم كاذبون في إقرارهم بالإيمان { وتؤمنون } أي أنتم { بالكتاب كله } أي ويكفرون هم به كله ،   إما بالقصد الأول وإما بالإيمان بالبعض والكفر بالبعض { وإذا لقوكم قالوا } أي لكم { آمنا } لتغتروا بهم { وإذا خلوا } أي منكم ،   وصوّر شدة حنقهم بقوله : { عضّوا عليكم } لما يرون من ائتلافكم{[18780]} وحسن أحوالكم { الأنامل من الغيظ } أي المفرط منكم ،   ومن جعل الهاء في { ها أنتم } بدلاً عن همزة الاستفهام{[18781]} فالمراد عنده{[18782]} : أأنتم يا هؤلاء {[18783]}القرباء مني{[18784]} تحبونهم والحال أنهم على ما هم عليه من منابذتكم وأنتم على ما أنتم عليه من الفطنة بصفاء الأفكار وعليّ الآراء بقبولكم الحق كله ،   لأن المؤمن كيس{[18785]} فطن ؛ فهو استفهام - وإن{[18786]} كان من وادي التوبيخ - المراد به التنبيه والتهييج{[18787]} المنقل من سافل الدركات إلى{[18788]} عالي الدرجات - والله الموفق .  <br />
ولما كانوا كأنهم قالوا : فما نفعل ؟ قال مخاطباً للرأس المسموع الأمر المجاب الدعاء : { قل } أي لهم{[18789]} { موتوا بغيظكم } أي{[18790]} ازدراء بهم{[18791]} ودعاء عليهم بدوام الغيظ من القهر وزيادته حتى يميتهم{[18792]} .   ولما كانوا يحلفون{[18793]} على نفي هذا ليرضوهم قال تعالى مؤكداً لما أخبر به لئلا يظن أنه أريد به غير الحقيقة : { إن الله } أي الجامع لصفات الكمال { عليم بذات الصدور * } أي فلا تظنوا أنه أراد بعض ما يتجوز{[18794]} بالغيظ عنه .
