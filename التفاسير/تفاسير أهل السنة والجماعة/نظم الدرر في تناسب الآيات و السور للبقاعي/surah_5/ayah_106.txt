ولما كان الإيصاء إذ ذاك أمراً متعارفاً ،   عرف فقال معلقاً بشهادة كما علق به { إذا } أو مبدلاً من { إذا } لأن الزمنين{[27986]} واحد : { حين الوصية } أي{[27987]} إن أوصى ،   ثم أخبر عن المبتدأ فقال : { اثنان } أي شهادة بينكم في ذلك الحين شهادة اثنين { ذوا عدل منكم } أي من قبيلتكم العارفين بأحوالكم { أو آخران } أي ذوا عدل { من غيركم } أي إن لم تجدوا قريبين يضبطان أمر الوصية من كل ما للوصي وعليه ،   وقيل : بل هما الوصيان أنفسهما احتياطاً بجعل الوصي اثنين ،   وقيل : آخران من غير أهل دينكم ،   وهو خاص بهذا الأمر الواقع في السفر للضرورة لا في غيره ولا في غير السفر ؛ ثم شرط هذه الشهادة بقوله{[27988]} : { إن أنتم ضربتم } أي بالأرجل { في الأرض } أي بالسفر ،   كأن الضرب بالأرجل لا يسمى ضرباً إلا فيه لأنه موضع الجد والاجتهاد { فأصابتكم } وأشار إلى أن الإنسان هدف لسهام الحدثان بتخصيصه بقوله : { مصيبة الموت } أي أصابت الموصي المصيبةُ التي لا مفرّ{[27989]} منها ولا مندوحة عنها .  <br />
