ولما أصابهم ذلك ،   سبب لهم الهجرة عن ديارهم ديار السوء والغضب واللعنة فقال تعالى إعلاماً لنا بذلك : { فتولى } أي كلف نفسه الإعراض { عنهم وقال } أي لما أدركه من أحوال البشر من الرقة على فوات إيمانهم وهم أصله وعشيرته { يا قوم } أي الذين يعز عليّ ما يؤذيهم { لقد أبلغتكم } ولعله وحد قوله : { رسالة ربي } لكون آيته واحدة { ونصحت } و{[32621]}قصر الفعل وعداه باللام فقال : { لكم } دلالة على أنه خاص بهم{[32622]} ،   روي {[32623]}أنه خرج عنهم{[32624]} في مائة وعشرة من المسلمين وهويبكي ،   وكان قومه ألفاً وخمسمائة دار ،   وروي أنه رجع بمن معه فسكنوا ديارهم{[32625]} .  <br />
ولما كان التقدير : ففعلت معكم{[32626]} ما هو مقتض لأن تحبوني لأجله ،   عطف عليه قوله : { ولكن } لم تحبوني{[32627]} ،   هكذا كان الأصل ولكنه عبر بما يفهم أن هذا كان دأبهم وخلقاً لهم مع كل ناصح فقال : { لا تحبون } أي{[32628]} حاكياً لحالهم الماضية { الناصحين } أي كل من فعل فعلي من النصح التام .
