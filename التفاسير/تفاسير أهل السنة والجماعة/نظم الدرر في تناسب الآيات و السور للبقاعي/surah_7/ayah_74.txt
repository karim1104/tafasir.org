ولما أمرهم ونهاهم ،   ذكر لهم ترغيباً مشيراً إلى ترهيب فقال : { واذكروا } أي نعمة الله عليكم { إذ جعلكم خلفاء } أي فيما أنتم فيه { من بعد عاد } أي إهلاكهم { وبوأكم في الأرض } أي جعل لكم في جنسها مساكن تبوءون أي ترجعون إليها وقت راحتكم ،   سهل عليكم من عملها في أي{[32574]} أرض أردتم ما لم يسهله{[32575]} على غيركم ،   ولهذا فسر المراد بقوله : { تتخذون } أي بما لكم من الصنائع { من سهولها قصوراً } أي أبنية {[32576]}بالطين واللبن والآجر واسعة عالية حسنة يقصر{[32577]} أمل الآمل ونظر الناظر عليها مما فيها من المرافق والمحاسن { وتنحتون الجبال } أي أيّ جبل أرتم تقدرونها { بيوتاً } .  <br />
ولما ذكرهم بهذه النعم مرغباً مرهباً ،   كرر ذلك إشارة وعبارة فقال مسبباً عما ذكرهم به : { فاذكروا } أي ذكر إذعان ورغبة ورهبة { آلاء } أي نعم { الله } أي الذي له{[32578]} صفات الكمال فلا حاجة به إلى أحد ،   فإحسانه هو الإحسان في الحقيقة { ولا تعثوا في الأرض } من العثي وهو الفساد ،   وهو مقلوب عن العيث - قاله ابن القطاع{[32579]} ،   وحينئذ يكون قوله : { مفسدين* } بمعنى متعمدين{[32580]} للفساد .
