ولما ذكر إنزاله ،   سبب عنه الدليل القرب على البعث فقال : { فأنشأنا } أي فأخرجنا وأحيينا { لكم } خاصة ،   لا لنا { به } أي بذلك الماء الذي جعلنا منه كل شيء حي { جنات } أي بساتين تجن - أي تستر - داخلها بما فيها { من نخيل وأعناب } صرح بهذين الصنفين لشرفهما ،   ولأنهما أكثر ما عند العرب من الثمار ،   سمي الأول باسم شجرته لكثرة ما فيهما من المنافع المقصودة بخلاف الثاني فإنه المقصود من شجرته ؛ وأشار إلى غيرهما بقوله : { لكم } أي خاصة { فيها } أي الجنات { فواكه كثيرة } ولكم فيها غير ذلك .  <br />
ولما كان التقدير : منها - وهي طرية - تتفكهون ،   عطف عليه قوله : { ومنها } أي بعد اليبس والعصر { تأكلون* } أي يتجدد لكم الأكل بالادخار ،   ولعله قدم الظرف تعظيماً للامتنان بها .  <br />
