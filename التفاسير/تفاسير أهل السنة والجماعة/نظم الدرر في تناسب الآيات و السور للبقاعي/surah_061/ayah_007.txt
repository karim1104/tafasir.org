ولما كان التقدير إعلاماً بأنهم أظلم الناس لتعمدهم للكذب : فمن أظلم منهم لتهتكهم في ذلك ،   عطف عليه قوله : { ومن أظلم } وعم{[65043]} كل من اتصف بوصفهم فقال : { ممن افترى } أي تعمد { على الله } أي الملك الأعلى { الكذب } الذي هو أقبح الأشياء { وهو } أي والحال أنه { يدعى } أي من أي داع كان { إلى الإسلام } الذي هو أحسن الأشياء فيكفي في الدعاء إليه أدنى تنبيه لأنه الاعتراف بالحق لمن هو له ،   فيجعل مكان الإجابة افتراء الكذب في تلك الحالة{[65044]} الحسنى .  <br />
ولما كان التقدير : فهو لا يهديه الله لأجل ظلمه ،   عطف عليه قوله : { والله } أي الذي له الأمر كله فلا أمر لأحد معه { لا يهدي القوم{[65045]} } أي لا يخلق الهداية في قلوب من فيهم قوة المحاولة للأمور الصعاب{[65046]} { الظالمين * } أي الذين يخبطون في عقولهم خبط من هو في الظلام .
