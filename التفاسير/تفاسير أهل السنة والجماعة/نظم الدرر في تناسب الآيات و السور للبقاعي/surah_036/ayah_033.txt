{ وآية } أي : علامة عظيمة { لهم } على قدرتنا على البعث وإيجادنا له { الأرض } أي :هذا الجنس الذي هم منه ،   ثم وصفها بما حقق وجه الشبه فقال : { الميتة } التي لا روح لها لأنه لا نبات بها أعم من أن يكون بها نبات وفني فتفتت وصار تراباً أو لم يكن بها شيء أصلاً .   ثم استأنف بيان كونها آية بقوله : { أحييناها } أي  :باختراع النبات فيها أو بإعادته بسبب المطر كما كان بعد اضمحلاله .  <br />
