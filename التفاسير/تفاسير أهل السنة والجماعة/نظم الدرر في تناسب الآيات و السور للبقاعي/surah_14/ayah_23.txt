ولما ذكر الظالمين .   أتبعه ذكر المؤمنين ،   فقال بانياً للمفعول لأن{[44931]} الدخول هو المقصود بالذات : { وأدخل } والإدخال : النقل إلى محيط - هذا أصله { الذين آمنوا } أي أوجدوا{[44932]} الإيمان { وعملوا الصالحات } أي تصديقاً لدعواهم{[44933]} الإيمان { جنات تجري } وبين أن الماء غير عام لجميع{[44934]} أرضها بإدخال الجار فقال : { من تحتها الأنهار } فهي{[44935]} لا تزال ريّاً ،   لا يسقط ورقها ولا ثمرها فداخلها{[44936]} لا يبغي بها بدلاً { خالدين فيها } .  <br />
