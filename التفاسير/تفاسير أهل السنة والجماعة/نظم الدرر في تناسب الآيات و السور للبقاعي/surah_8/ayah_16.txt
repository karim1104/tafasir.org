{ ومن يولهم } ولما كان الأغلب في وقوع القتال النهار ،   وكانت التولية مما لا يكون الظرف {[34692]}معياراً له{[34693]} لأنها مما لا يمتد زمنه ،   فالعصيان يقع بمجرد الالتفات بقصد الفرار ،   والتمادي تكرير أمثال ،   لا شرط في صحة إطلاق الاسم ،   عبر باليوم{[34694]} ،   وجرده عن  "  في  "  ندباً إلى الكر بعد الفر مع عدم الالتباس{[34695]} ،   فإن الظرف لا يكون معياراً للفعل إلا إذا كان ممتد الزمان كالصوم فقال{[34696]} { يومئذ } أي إذ{[34697]} لقيتم على هذه الحالة في أيّ وقت {[34698]}كان من{[34699]} أوقات القتال من ليل كان{[34700]} أو نهار { دبره } أي يجعل ظهره إليهم لشيء من الأشياء تولية لا يريد الإقبال إلى القتال منها { إلا } أي{[34701]} حال كونه { متحرفاً } أو{[34702]} الحال التحرف ،   وهو الزوال عن جهة الاستواء { لقتال } أي لا يتسهل{[34703]} له إلا بذلك أو يخيل إلى عدوه أنه منهزم خداعاً له ثم يكر عليه { أو متحيزاً } أي متنقلاً من حيز إلى آخر{[34704]} ومتنحياً { إلى فئة } أي جماعة أخرى من أهل حزبه هم أهل لآن يرجع إليهم ليستعين بهم{[34705]} أو يعينهم .  <br />
ولما كان هذا محل توقع السامع للجواب وتفريغ ذهنه له ،   أجاب رابطاً بالفاء{[34706]} إعلاماً بأن الفعل<br />
المحدث{[34707]} عنه سبب لهذا الجزاء فقال : { فقد باء } أي رجع { بغضب من الله } اي الحائز لجميع صفات الكمال { ومأواه جهنم } أي تتجهمه{[34708]} كما أنه هاب تجهم الكفار ولقاء الوجوه العابسة بوجه كالح عابس { وبئس المصير* } هذا إذا لم يزد الكفار عن الضعف - كما سيأتي النص به .
