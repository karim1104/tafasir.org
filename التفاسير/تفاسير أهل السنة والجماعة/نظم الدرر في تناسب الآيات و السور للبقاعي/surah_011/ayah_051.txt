ثم نفى أن يكون له في ذلك غرض غير نصحهم بقوله موضع  "  إني ناصح لكم بهذا الأمر فلا يسوءكم مواجهتي لكم فيه بما تكرهون  "  { يا قوم } مكرراً لاستعطاف { لا أسألكم } أي في المستقبل كما لم أسالكم في الماضي { عليه } أي على هذا الإنذار { أجراً } أي فلست موضع تهمة { إن } أي ما{[39443]} ؛ { أجري } ثم وصف من توكل عليه سبحانه بما يدل على الكفاية فعليّ وجوب شكره فقال{[39444]} : { إلا على الذي فطرني } أي أبتدأ خلقي {[39445]}ولم يشاركه فيّ{[39446]} أحد فهو الغني المطلق لا أوجه رغبتي إلى غيره كما يجب{[39447]} على كل أحد ذلك لكونه فطرة .  <br />
