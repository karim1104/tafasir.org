ولما ذكر جزاءهم على ما هو الحق المساوي{[58402]} لأعمالهم طبق الفعل بالفعل ،   علله بما لزم على{[58403]} أعمالهم فقال : { ذلكم } أي العذاب العظيم { بأنكم اتخذتم } أي بتكليف منكم لأنفسكم وقسر على خلاف ما أدى إليه العقل ،   وجاءت به الرسل ،   وساعدت عليه الفطر الأول{[58404]} { آيات الله } أي الملك الأعظم {[58405]}الذي لا شيء أعظم منه{[58406]} { هزواً } أي جعلتموها عين ما أنزلت للإبعاد منه { وغرتكم } لضعف عقولكم { الحياة الدنيا } أي الدنية فآثرتموها لكونها حاضرة وأنتم كالبهائم لا يعدو نظركم المحسوس فقلتم : لا حياة غيرها ولا بعث ولا حساب ،   ولو تعقلتم وصفكم لها لأداكم إلى الإقرار بالأخرى .  <br />
ولما أوصلهم إلى هذا الحد من الإهانة ،   سبب عنه زيادة في إهانتهم وتلذيذاً لأوليائه الذين {[58407]}عادوهم فيه{[58408]} وإشماتاً لهم بهم : { فاليوم } بعد إيوائهم فيها { لا يخرجون } بمخرج ما { منها } لأن الله لا يخرجهم ولا يقدر غيره على ذلك { ولا هم } خاصة{[58409]} { يستعتبون * } أي يطلب من طالب ما منهم الإعتاب ،   وهو الاعتذار بما يثبت لهم العذر ويزيل عنهم العتب الموجب للغضب بعمل من الأعمال الصالحات ؛ لأنهم في دار الجزاء لا دار العمل .
