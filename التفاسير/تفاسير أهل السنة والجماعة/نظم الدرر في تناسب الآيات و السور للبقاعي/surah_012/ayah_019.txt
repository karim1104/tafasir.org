ولما تم أمرهم هذا وشبوا على أبيهم عليه السلام{[40758]} نار الحزن ،   التفتت النفس إلى الخبر عن يوسف عليه الصلاة والسلام فيما أشار إليه قوله :<br />
{ لتنبئنهم }[ يوسف : 15 ] الآية ،   فقال تعالى مخبراً عن ذلك في أسبابه : { وجاءت سيارة } أي قوم بليغو السير إلى الأرض التي ألقوا يوسف عليه الصلاة والسلام في جبها { فأرسلوا واردهم } أي رسولهم الذي يرسلونه لأجل الإشراف على الماء إلى الجب ليستقي{[40759]} لهم { فأدلى } فيه { دلوه } أي أرسلها في البئر ليملأها - وأما  "  دلى  "  فأخرجها ملأى - فاستمسك{[40760]} بها يوسف عليه الصلاة والسلام فأخرجه ،   فكأنه قيل : ماذا قال{[40761]} حين أدلى للماء فتعلق{[40762]} يوسف بالحبل فأطلعه فإذا هو بإنسان أجمل ما يكون ؟ فقيل : { قال } أي الوارد{[40763]} يعلم أصحابه بالبشرى { يا بشرى } أي{[40764]} هذا أوانك فاحضري ،   فكأنه قيل{[40765]} :{[40766]} لم تدعوا{[40767]} البشرى ؟ فقال : { هذا غلام } فأتى به إلى جماعته فسروا به كما سر { وأسروه } أي الوارد وأصحابه { بضاعة } أي حال كونه متاعاً بزعمهم يتجرون فيه { والله } أي المحيط علماً وقدرة { عليم } أي بالغ العلم { بما يعملون * } وإن أسروه ؛ قال أبو حيان{[40768]} ونعم{[40769]} ما قال : وتعلقه بالحبل يدل على صغره إذ لو كان ابن ثمانية عشر أو سبعة عشر لم يحمله الحبل غالباً ،   ولفظة  "  غلام  "  ترجح ذلك إذ تطلق عليه ما بين الحولين إلى البلوغ حقيقة ،   وقد تطلق على الرجل الكامل - انتهى{[40770]} .
