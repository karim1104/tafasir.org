فكأنه قيل : هذا ما رأى أن يفعل في نفسه ،   فماذا{[42490]} رأى لإخوته ؟ فقيل{[42491]} : أمرهم بالرجوع ليعلموا أباهم لإمكان أن يريد القدوم إلى مصر ليرى ابنه أو يكون عنده رأي فيه فرج{[42492]} ،   فقال : { ارجعوا إلى أبيكم } أي دوني { فقولوا } أي له متلطفين في خطابكم { ياأبانا } وأكدوا مقالتكم فإنه ينكرها لكم{[42493]} فقولوا : { إن ابنك } أي شقيق يوسف عليه الصلاة والسلام الذي هو أكملنا في البنوة عندك { سرق } .  <br />
ولما كانوا في غاية الثقة من أن أحداً منهم لا يلم{[42494]} بمثل ذلك ،   أشاروا إليه بقولهم : { وما شهدنا } أي في ذلك { إلا بما علمنا } ظاهراً من رؤيتنا الصواع يخرج من وعائه ؛ والشهادة : الخبر عن إحساس قول أو فعل ،   وتجوز الشهادة بما أدى{[42495]} إليه الدليل القطعي { وما كنا للغيب } أي الأمر الذي غاب عنا { حافظين } فلعل حيلة دبرت في ذلك غاب عنا علمها كما صنع في رد بضاعتنا .
