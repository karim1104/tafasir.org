{ وما } أي هذه صفتنا والحال أنه ما { يأتيهم } أي الكفار { من ذكر } أي شيء من الوعظ والتذكير والتشريع يذكروننا به ،   فيكون سبب ذكرهم وشرفهم { من الرحمن } أي الذي أنكروه مع إحاطة نعمه بهم { محدث } أي بالنسبة إلى تنزيله وعلمهم به ؛ وأشار إلى دوام كبرهم بقوله : { إلا كانوا } أي كوناً هو كالخلق لهم ؛ وأشار بتقديم الجار والمؤذن بالتخصيص إلى ما لهم من سعة الأفكار وقوة الهمم لكل ما يتوجهون إليه ،   وإلى أن لإعراضهم عنه من القوة ما يعد الإعراض معه عن غيره عدماً فقال : { عنه } أي خاصة { معرضين* } أي إعراضاً هو صفة لهم لازمة .  <br />
