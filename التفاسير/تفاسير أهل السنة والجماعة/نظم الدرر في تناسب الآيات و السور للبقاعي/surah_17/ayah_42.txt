فكأنه قيل : فما يفعل بهم ؟ فقال تعالى : { قل } لهم ولا تيأس من رجوع بعضهم : { لو كان معه } أي ربكم الذي تقدم وصفه بالإحسان والتنزيه { ءالهة كما يقولون } من هذه الأقوال التي لو قالها أعظمكم في حق أدناكم وهو يريد بها حقيقتها لصار ضحكة للعباد { إذاً لابتغوا } أي طلبوا طلباً عظيماً { إلى ذي العرش } أي صاحب السرير الأعظم المحيط الذي من ناله كان منفرداً بالتدبير { سبيلاً * } أي طريقاً سالكاً يتوصلون به إليه ليقهروه ويزيلوا ملكه كما ترون من فعل ملوك الدنيا بعضهم مع بعض ،   أو ليتخذوا عنده يداً تقربهم إليه ،   وصرح بالعرش تصويراً لعظمته وتعييناً للمبتغي والمبتغى ؛<br />
