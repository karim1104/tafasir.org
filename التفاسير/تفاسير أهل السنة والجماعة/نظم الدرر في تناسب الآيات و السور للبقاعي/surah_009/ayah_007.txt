ولما كان الأمر بالنبذ مظنة لأن يعجب منه ،   عجب فقال : فمن يتعجب منه ؟ وأنكر عليه فقال : { كيف يكون للمشركين } أي أهل العراقة في الشرك الذين توجب عراقتهم فيه ومحبتهم لظهوره نكثَ العهد الذي لا أقبح منه عند العرب ولا أشنع { عهد عند الله } أي المستجمع لصفات الكمال ،   فهو لا يحب النقض من أوليائه{[35642]} فكيف به من أعدائه { وعند رسوله } أي الذي هو أكمل الخلق وأوفاهم وأحفظهم للعهود وأرعاهم فهم أضداده{[35643]} فأعمالهم أضداد أعماله ،   وقد بدا منهم الغدر .  <br />
ولما كان استفهام الإنكار في معنى النفي ،   صح{[35644]} الاستثناء منه ،   فكأنه قيل : لا يكون للمشركين عهد { إلا الذين عاهدتم } أي منهم كما تقدم { عند المسجد الحرام } أي الحرم يوم الحديبية ،   وهذا مما يدل على أن{[35645]} الاستثناء المتقدم من { الذين } في قوله { براءة من الله ورسوله إلى الذين عاهدتم من المشركين } ؛ قال البغوي ؛ قال السدي والكلبي وابن إسحاق : هم{[35646]} من قبائل بكر : بنو خزيمة وبنو مدلج وبنو ضمرة وبنو الديل وهم{[35647]} الذين كانوا قد دخلوا في عهد قريش يوم الحديبية ،   فلم يكن نقض العهد{[35648]} إلا قريش وبنو الديل من بني بكر فأمر بإتمام العهد لمن لم ينقض ،   ولما استثنى ،   بين حكم المستثني فقال : { فما استقاموا لكم } أي ركبوا{[35649]} الطريق الأقوم في الوفاء بعهدهم { فاستقيموا لهم } والقول في{[35650]} { إن الله } أي المحيط بالجلال والجمال { يحب المتقين* } كما سبق{[35651]} .
