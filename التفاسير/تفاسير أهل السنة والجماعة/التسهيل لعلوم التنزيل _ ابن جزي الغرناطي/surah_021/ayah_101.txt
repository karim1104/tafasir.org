{ إِنَّ ٱلَّذِينَ سَبَقَتْ لَهُمْ مِّنَّا ٱلْحُسْنَىٰ } سبقت أي: قُضيت في الأزل، والحسنى السعادة، ونزلت الآية لما اعترض ابن الزبعرى على قوله: [الأنبياء: 98]، فقال: إن عيسى وعزير والملائكة قد عُبدوا؛ فالمعنى إخراج هؤلاء من ذلك الوعيد، واللفظ مع ذلك على عمومه في كل من سبقت له السعادة { حَسِيسَهَا } أي صوتها { ٱلْفَزَعُ ٱلأَكْبَرُ } أهوال القيامة على الجملة، وقيل ذبح الموت وقيل: النفخة الأولى في الصور لقوله: [النمل: 87] { كَطَيِّ ٱلسِّجِلِّ لِلْكُتُبِ } السجل الصحيفة والكتاب مصدر: أي كما يطوي السجل ليكتب فيه، أو ليصان الكتاب الذي فيه، وقيل: السجل رجل كاتب وهذا ضعيف، وقيل: هو ملك في السماء الثانية: ترفع إليه الأعمال، وهذا أيضاً ضعيف { كَمَا بَدَأْنَآ أَوَّلَ خَلْقٍ نُّعِيدُهُ } أي كما قدرنا على البداءة نقدر على الإعادة، فهو كقوله: [يسۤ: 79]، وقيل: المعنى نعيدهم على الصورة التي بدأناهم كما جاء في الحديث: " يحشر الناس يوم القيامة حفاة عراة غرلاً " ثم قرأ: { كَمَا بَدَأْنَآ أَوَّلَ خَلْقٍ نُّعِيدُهُ } ، والكاف متعلقة بقوله بقوله { نُّعِيدُهُ }  { فَاعِلِينَ } تأكيداً لوقوع البعث.
