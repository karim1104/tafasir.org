{ وَيَسْتَعْجِلُونَكَ بِٱلْعَذَابِ } الضمير للكفار يعني قولهم: [الأعراف: 77]، وقولهم: [الأنفال: 32] وشبه ذلك { وَلَوْلاَ أَجَلٌ مُّسَمًّى } أي لولا أن الله قدّر لعذابهم أجلاً مسمى لجاءهم به حين طلبوه { وَلَيَأْتِيَنَّهُمْ بَغْتَةً وَهُمْ } يحتمل أن يريد القتل الذي أصابهم يوم بدر، أو الجوع الذي أصابهم بهم بتوالي القحط، أو يريد عذاب الآخرة، وهذا أظهر لقوله: { وَإِنَّ جَهَنَّمَ لَمُحِيطَةٌ بِٱلْكَافِرِينَ }.
