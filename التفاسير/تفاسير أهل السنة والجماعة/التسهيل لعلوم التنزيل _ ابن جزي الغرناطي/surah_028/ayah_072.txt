{ لَهُ ٱلْحَمْدُ فِي ٱلأُولَىٰ وَٱلآخِرَةِ } قيل إن الحمد في الآخرة قولهم: [الزمر: 74] أو قولهم: [فاطر: 34] وفي ذكر الأولى مع الآخرة مطابقة { سَرْمَداً } أي دائماً، والمراد بالآيات إثبات الوحدانية وإبطال الشرك، فإن قيل: كيف قال { يَأْتِيكُمْ بِضِيَآءٍ } ، وهلا قال: يأتيكم بنهار في مقابلة قوله { يَأْتِيكُمْ بِلَيْلٍ } فالجواب أنه ذكر الضياء لجملة ما فيه من المنافع والعبر { لِتَسْكُنُواْ فِيهِ } أي في الليل { وَلِتَبتَغُواْ مِن فَضْلِهِ } أي في النهار، ففي الآية لف ونشر.
