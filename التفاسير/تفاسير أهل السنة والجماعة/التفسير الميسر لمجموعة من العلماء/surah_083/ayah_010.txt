{  وَيْلٌ يَوْمَئِذٍ لِلْمُكَذِّبِينَ ( 10 ) الَّذِينَ يُكَذِّبُونَ بِيَوْمِ الدِّينِ ( 11 ) وَمَا يُكَذِّبُ بِهِ إِلاَّ كُلُّ مُعْتَدٍ أَثِيمٍ ( 12 ) إِذَا تُتْلَى عَلَيْهِ آيَاتُنَا قَالَ أَسَاطِيرُ الأَوَّلِينَ ( 13 ) كَلاَّ بَلْ رَانَ عَلَى قُلُوبِهِمْ مَا كَانُوا يَكْسِبُونَ ( 14 ) كَلاَّ إِنَّهُمْ عَنْ رَبِّهِمْ يَوْمَئِذٍ لَمَحْجُوبُونَ ( 15 ) ثُمَّ إِنَّهُمْ لَصَالُوا الْجَحِيمِ ( 16 ) ثُمَّ يُقَالُ هَذَا الَّذِي كُنتُمْ بِهِ تُكَذِّبُونَ ( 17 ) }<br />
