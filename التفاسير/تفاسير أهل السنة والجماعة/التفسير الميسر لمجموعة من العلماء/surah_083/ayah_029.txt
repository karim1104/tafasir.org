{  إِنَّ الَّذِينَ أَجْرَمُوا كَانُوا مِنْ الَّذِينَ آمَنُوا يَضْحَكُونَ ( 29 ) وَإِذَا مَرُّوا بِهِمْ يَتَغَامَزُونَ ( 30 ) وَإِذَا انقَلَبُوا إِلَى أَهْلِهِمْ انقَلَبُوا فَكِهِينَ ( 31 ) وَإِذَا رَأَوْهُمْ قَالُوا إِنَّ هَؤُلاءِ لَضَالُّونَ ( 32 ) وَمَا أُرْسِلُوا عَلَيْهِمْ حَافِظِينَ ( 33 ) فَالْيَوْمَ الَّذِينَ آمَنُوا مِنْ الْكُفَّارِ يَضْحَكُونَ ( 34 ) }<br />
