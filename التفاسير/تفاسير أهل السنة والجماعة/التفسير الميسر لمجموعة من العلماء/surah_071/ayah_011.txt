{  يُرْسِلْ السَّمَاءَ عَلَيْكُمْ مِدْرَاراً ( 11 ) وَيُمْدِدْكُمْ بِأَمْوَالٍ وَبَنِينَ وَيَجْعَلْ لَكُمْ جَنَّاتٍ وَيَجْعَلْ لَكُمْ أَنْهَاراً ( 12 ) مَا لَكُمْ لا تَرْجُونَ لِلَّهِ وَقَاراً ( 13 ) وَقَدْ خَلَقَكُمْ أَطْوَاراً ( 14 ) أَلَمْ تَرَوْا كَيْفَ خَلَقَ اللَّهُ سَبْعَ سَمَاوَاتٍ طِبَاقاً ( 15 ) وَجَعَلَ الْقَمَرَ فِيهِنَّ نُوراً وَجَعَلَ الشَّمْسَ سِرَاجاً ( 16 ) }<br />
