{  فَمَا لَهُمْ لا يُؤْمِنُونَ ( 20 ) وَإِذَا قُرِئَ عَلَيْهِمْ الْقُرْآنُ لا يَسْجُدُونَ ( 21 ) بَلْ الَّذِينَ كَفَرُوا يُكَذِّبُونَ ( 22 ) وَاللَّهُ أَعْلَمُ بِمَا يُوعُونَ ( 23 ) فَبَشِّرْهُمْ بِعَذَابٍ أَلِيمٍ ( 24 ) إِلاَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ لَهُمْ أَجْرٌ غَيْرُ مَمْنُونٍ ( 25 ) }<br />
فأيُّ شيء يمنعهم من الإيمان بالله واليوم الآخر بعد ما وُضِّحت لهم الآيات ؟
