{  وَإِنَّ مِنْ شِيعَتِهِ لإٍبْرَاهِيمَ ( 83 ) إِذْ جَاءَ رَبَّهُ بِقَلْبٍ سَلِيمٍ ( 84 ) إِذْ قَالَ لأَبِيهِ وَقَوْمِهِ مَاذَا تَعْبُدُونَ ( 85 ) أَئِفْكاً آلِهَةً دُونَ اللَّهِ تُرِيدُونَ ( 86 ) فَمَا ظَنُّكُمْ بِرَبِّ الْعَالَمِينَ ( 87 ) }<br />
