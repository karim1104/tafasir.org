{  وَالسَّمَاءِ ذَاتِ الْبُرُوجِ ( 1 ) وَالْيَوْمِ الْمَوْعُودِ ( 2 ) وَشَاهِدٍ وَمَشْهُودٍ ( 3 ) قُتِلَ أَصْحَابُ الأُخْدُودِ ( 4 ) النَّارِ ذَاتِ الْوَقُودِ ( 5 ) إِذْ هُمْ عَلَيْهَا قُعُودٌ ( 6 ) وَهُمْ عَلَى مَا يَفْعَلُونَ بِالْمُؤْمِنِينَ شُهُودٌ ( 7 ) وَمَا نَقَمُوا مِنْهُمْ إِلاَّ أَنْ يُؤْمِنُوا بِاللَّهِ الْعَزِيزِ الْحَمِيدِ ( 8 ) الَّذِي لَهُ مُلْكُ السَّمَوَاتِ وَالأَرْضِ وَاللَّهُ عَلَى كُلِّ شَيْءٍ شَهِيدٌ ( 9 ) }<br />
أقسم الله تعالى بالسماء ذات المنازل التي تمر بها الشمس والقمر ،
