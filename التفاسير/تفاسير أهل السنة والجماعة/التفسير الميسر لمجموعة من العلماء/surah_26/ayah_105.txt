{  كَذَّبَتْ قَوْمُ نُوحٍ الْمُرْسَلِينَ ( 105 ) إِذْ قَالَ لَهُمْ أَخُوهُمْ نُوحٌ أَلا تَتَّقُونَ ( 106 ) إِنِّي لَكُمْ رَسُولٌ أَمِينٌ ( 107 ) فَاتَّقُوا اللَّهَ وَأَطِيعُونِ ( 108 ) وَمَا أَسْأَلُكُمْ عَلَيْهِ مِنْ أَجْرٍ إِنْ أَجْرِي إِلاَّ عَلَى رَبِّ الْعَالَمِينَ ( 109 ) فَاتَّقُوا اللَّهَ وَأَطِيعُونِ ( 110 ) }<br />
كَذَّبت قوم نوح رسالة نبيهم ،  فكانوا بهذا مكذبين لجميع الرسل ؛  لأن كل رسول يأمر بتصديق جميع الرسل .
