قوله :  {  اقْتُلُواْ يُوسُفَ أَوِ اطْرَحُوهُ أَرْضًا يَخْلُ لَكُمْ وَجْهُ أَبِيكُمْ } قال إخوة يوسف بعضهم لبعض ،  أو قال أحدهم للآخرين {  اقتلوا يوسف } وذلك لتهدا نفوسهم منن سورة الحسد المركوم الذي يلسع قلوبهم ويقض أعصابهم {  أو اطرحوه أرضا } {  أرضا } ،  منصوب على أنه ظرف مكان{[2207]} ؛  أي ألقوه بعيدا في أرض منكورة مجهولة {  يخل لكم وجه أبيكم } أي خلص لكم وجه أبيكم ؛  فيقبل عليكم بكليته ،  فلا ينشغل عنكم بغيركم . <br />
قوله :  {  وَتَكُونُواْ مِن بَعْدِهِ قَوْمًا صَالِحِينَ } أي تكونوا من بعد مغيب يوسف عنكم بالقتال أو الإلقاء بعيدا {  قوما صالحين } أي تائبين إلى الله من جنابة القتل .  وقيل :  يصلح حالكم عند أبيكم فلا يؤثر عليكم أحدا غيركم .
