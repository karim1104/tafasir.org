قوله تعالى :  {  وَلَقَدْ نَادَانَا نُوحٌ فَلَنِعْمَ الْمُجِيبُونَ ( 75 ) وَنَجَّيْنَاهُ وَأَهْلَهُ مِنَ الْكَرْبِ الْعَظِيمِ ( 76 ) وَجَعَلْنَا ذُرِّيَّتَهُ هُمُ الْبَاقِينَ ( 77 ) وَتَرَكْنَا عَلَيْهِ فِي الْآَخِرِينَ ( 78 ) سَلامٌ عَلَى نُوحٍ فِي الْعَالَمِينَ ( 79 ) إِنَّا كَذَلِكَ نَجْزِي الْمُحْسِنِينَ ( 80 ) إِنَّهُ مِنْ عِبَادِنَا الْمُؤْمِنِينَ ( 81 ) ثُمَّ أَغْرَقْنَا الْآَخَرِينَ } . <br />
{  نادانا } من النداء وهو الالتماس والاستغاثة ؛  أي سألنا نوح أن نهلك قومه لفرط عتوهم وكفرانهم وشدة إعراضهم وعنادهم {  فَلَنِعْمَ الْمُجِيبُونَ } والمخصوص بالمدح محذوف ،  وتقديره :  فلنعم المجيبون نحن{[3962]} .  والمعنى :  فلنعم المجيبين كنا له .  فقد أجبنا له دعاءه فأهلكنا قومه بالطوفان والتغريق .
