قوله :  {  احْشُرُوا الَّذِينَ ظَلَمُوا وَأَزْوَاجَهُمْ } أزواجهم :  منصوب على العطف على الموصول {  الذين } وقيل :  الواو بمعنى مع فهو منصوب على أنه مفعول معه{[3943]}<br />
وهذا خطاب من الله للملائكة ؛  إذ يأمرهم :  أن اجمعوا الكافرين المكذبين {  وَأَزْوَاجَهُمْ } أي ونظراءهم وأشباههم وقرناءهم من الشياطين والعصاة والمجرمين ،  أو ونساءهم الكافرات {  وَمَا كَانُوا يَعْبُدُونَ ( 22 ) مِنْ دُونِ اللَّهِ }
