قوله تعالى :  {  قال ألقها يا موسى ( 19 ) فألقاها فإذا هي حية تسعى ( 20 ) قال خذها ولا تخف سنعيدها سيرتها الأولى ( 21 ) واضمم يدك إلى جناحك تخرج بيضاء من غير سوء آية أخرى ( 22 ) لنريك من آياتنا الكبرى ( 23 ) اذهب إلى فرعون إنه طغى ( 24 ) قال رب اشرح لي صدري ( 25 ) ويسر لي أمري ( 26 ) واحلل عقدة من لساني ( 27 ) يفقهوا قولي ( 28 ) واجعل لي وزيرا من أهلي ( 29 ) هارون أخي ( 30 ) اشدد به أزري ( 31 ) وأشركه في أمري ( 32 ) كي نسبحك كثيرا ( 33 ) ونذكرك كثيرا ( 34 ) إنك كنت بنا بصيرا ( 35 ) } . <br />
قال الله لكليمه موسى :  ( ألقها ) أي اطرحها ،  والمراد العصا .
