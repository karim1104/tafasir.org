{  جَنَّاتِ عَدْنٍ مُفَتَّحَةً لَهُمُ الْأَبْوَابُ } :  {  جَنَّاتِ } منصوب على البدل من قوله :  {  لَحُسْنَ مَآَبٍ } و {  مُفَتَّحَةً } منصوب ؛  لأنه وصف الجنات .  و {  الْأَبْوَابُ } ،  مرفوع على البدل من ضمير {  مُفَتَّحَةً }  .  وذلك جزاء المؤمنين المتقين ،  وهي دار النعيم المقيم الذي لا يفنى ولا يزول .  تلك هي جنة عدن بقصورها وبروجها وأبوابها الكثيرة الكبيرة الواسعة المفتحة . <br />
