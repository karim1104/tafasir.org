قوله تعالى :  {  فَأَتْبَعُوهُم مُّشْرِقِينَ ( 60 ) فَلَمَّا تَرَاءى الْجَمْعَانِ قَالَ أَصْحَابُ مُوسَى إِنَّا لَمُدْرَكُونَ ( 61 ) قَالَ كَلا إِنَّ مَعِيَ رَبِّي سَيَهْدِينِ ( 62 ) فَأَوْحَيْنَا إِلَى مُوسَى أَنِ اضْرِب بِّعَصَاكَ الْبَحْرَ فَانفَلَقَ فَكَانَ كُلُّ فِرْقٍ كَالطَّوْدِ الْعَظِيمِ ( 63 ) وَأَزْلَفْنَا ثَمَّ الآخَرِينَ ( 64 ) وَأَنجَيْنَا مُوسَى وَمَن مَّعَهُ أَجْمَعِينَ ( 65 ) ثُمَّ أَغْرَقْنَا الآخَرِينَ ( 66 ) إِنَّ فِي ذَلِكَ لآية وَمَا كَانَ أَكْثَرُهُم مُّؤْمِنِينَ ( 67 ) وَإِنَّ رَبَّكَ لَهُوَ الْعَزِيزُ الرَّحِيمُ } لحق فرعون وجنوده ببني إسرائيل {  مُّشْرِقِينَ } أي حين وقت الشروق .  وهو من أشرقت الشمس شروقا إذا طلعت .
