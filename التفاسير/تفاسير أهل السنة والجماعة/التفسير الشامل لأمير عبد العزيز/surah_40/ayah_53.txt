قوله :  {  وَلَقَدْ آَتَيْنَا مُوسَى الْهُدَى } أي ما يهتدي به من النبوة والمعجزات والشرائع {  وَأَوْرَثْنَا بَنِي إِسْرَائِيلَ الْكِتَابَ } {  الكتاب } اسم الجنس ؛  أي أورثناهم التوراة والإنجيل والزبور وقيل :  جعلنا لهم العاقبة وأورثناهم بلاد فرعون وأمواله وخزائنه وأرضه بصبرهم على دين الله واتباعهم رسول الله موسى عليه الصلاة والسلام . <br />
والأظهر المعنى الأول ويعززه قوله :  {  هُدًى وَذِكْرَى لِأُولِي الْأَلْبَابِ } . <br />
