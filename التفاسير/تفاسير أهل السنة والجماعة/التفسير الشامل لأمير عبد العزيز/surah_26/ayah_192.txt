قوله تعالى :  {  وَإِنَّهُ لَتَنزِيلُ رَبِّ الْعَالَمِينَ ( 192 ) نَزَلَ بِهِ الرُّوحُ الأمِينُ ( 193 ) عَلَى قَلْبِكَ لِتَكُونَ مِنَ الْمُنذِرِين ( 194 ) بِلِسَانٍ عَرَبِيٍّ مُّبِينٍ ( 195 ) وَإِنَّهُ لَفِي زُبُرِ الأولين ( 196 ) أَوَلَمْ يَكُن لَّهُمْ آيَةً أَن يَعْلَمَهُ عُلَمَاء بَنِي إِسْرَائِيلَ ( 197 ) وَلَوْ نَزَّلْنَاهُ عَلَى بَعْضِ الأعْجَمِينَ ( 198 ) فَقَرَأَهُ عَلَيْهِم مَّا كَانُوا بِهِ مُؤْمِنِينَ ( 199 ) كَذَلِكَ سَلَكْنَاهُ فِي قُلُوبِ الْمُجْرِمِينَ ( 200 ) لا يُؤْمِنُونَ بِهِ حَتَّى يَرَوُا الْعَذَابَ الألِيمَ ( 201 ) فَيَأْتِيَهُم بَغْتَةً وَهُمْ لا يَشْعُرُونَ ( 202 ) فَيَقُولُوا هَلْ نَحْنُ مُنظَرُونَ } . <br />
الضمير ،  في قوله :  {  وَإِنَّهُ } إلى الذكر الذي في قوله :  {  وما يأتيهم من ذكر الرحمن محدث } والمراد به القرآن ؛  فإنه تنزيل رب العالمين {  نَزَلَ بِهِ الرُّوحُ الأمين }
