قوله تعالى :  {  وَلَقَدْ مَنَنَّا عَلَى مُوسَى وَهَارُونَ ( 114 ) وَنَجَّيْنَاهُمَا وَقَوْمَهُمَا مِنَ الْكَرْبِ الْعَظِيمِ ( 115 ) وَنَصَرْنَاهُمْ فَكَانُوا هُمُ الْغَالِبِينَ ( 116 ) وَآَتَيْنَاهُمَا الْكِتَابَ الْمُسْتَبِينَ ( 117 ) وَهَدَيْنَاهُمَا الصِّرَاطَ الْمُسْتَقِيمَ ( 118 ) وَتَرَكْنَا عَلَيْهِمَا فِي الْآَخِرِينَ ( 119 ) سَلامٌ عَلَى مُوسَى وَهَارُونَ ( 120 ) إِنَّا كَذَلِكَ نَجْزِي الْمُحْسِنِينَ ( 121 ) إِنَّهُمَا مِنْ عِبَادِنَا الْمُؤْمِنِينَ } . <br />
بعد أن ذكر الله امتنانه على إبراهيم بإنجاء ولده إسماعيل من الذبح وجعله نبيّا مباركا بعد تنجيته – ذكر ما تفضّل به على موسى وهارون ابني عمران ؛  إذ جعلهما نبيين كريمين ونجاهما وقومهما المؤمنين المستضعفين {  مِنَ الْكَرْبِ الْعَظِيمِ } وهو الغرق .  أو هو ظلم فرعون وجنوده الذين استعبدوا بني إسرائيل وألحقوا بهم الهوان والإذلال .
