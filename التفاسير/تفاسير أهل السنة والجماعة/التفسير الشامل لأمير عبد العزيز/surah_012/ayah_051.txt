فأرسل الملك إلى النسوة وإلى المرأة العزيز ،  وكان العزيز قد مات ،  فدعاهن الملك ثم {  قَالَ مَا خَطْبُكُنَّ إِذْ رَاوَدتُّنَّ يُوسُفَ عَن نَّفْسِهِ } {  خطبكن } يعني شأنكن .  و {  راودتن } من المراودة وهي الطلب في تلطف ومخادعة ؛  أي ما خطبكن وما شأنكن {  أَنَاْ رَاوَدتُّهُ عَن نَّفْسِهِ } يوم الضيافة ؟  !  {  قُلْنَ حَاشَ لِلّهِ مَا عَلِمْنَا عَلَيْهِ مِن سُوءٍ } أي معاذ الله ما علمنا على يوسف من ذنب أو فاحشة . <br />
قوله :  {  قَالَتِ امْرَأَةُ الْعَزِيزِ الآنَ حَصْحَصَ الْحَقُّ أَنَاْ رَاوَدتُّهُ عَن نَّفْسِهِ وَإِنَّهُ لَمِنَ الصَّادِقِينَ } {  حصحص } أي بان وظهر{[2255]} .  فبعد اعتراف النسوة ببراءة يوسف وطهره بادرت امرأة العزيز لتقر مثلهن فقالت :  الآن ظهر الحق وانكشف {  أَنَاْ رَاوَدتُّهُ عَن نَّفْسِهِ } وإنه لصادق فما قاله .
