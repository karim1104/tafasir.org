قوله تعالى :  {  ألم تكن آياتي تتلى عليكم فكنتم بها تكذبون ( 105 ) قالوا ربنا غلبت علينا شقوتنا وكنا قوما ضالين ( 106 ) ربنا أخرجنا منها فإن عدنا فإنا ظالمون ( 107 ) قال اخسئوا فيها ولا تكلمون ( 108 ) } الاستفهام للتوبيخ والتقريع .  والمعنى :  ألم أرسل إليكم رسولي يتلو عليكم آيات القرآن فكذبتم وأعرضتم وكنتم من الظالمين .
