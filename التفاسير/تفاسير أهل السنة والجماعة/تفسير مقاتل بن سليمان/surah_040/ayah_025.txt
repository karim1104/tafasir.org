{ فلما جاءهم } موسى { بالحق من عندنا } يعني اليد والعصا آمنت به بنو إسرائيل ف { قالوا } أي قال فرعون وحده لقومه للملأ يعني الأشراف :{ اقتلوا أبناء الذين آمنوا معه } يعني مع موسى { واستحيوا نساءهم } يقول : اقتلوا أبناهم ودعوا البنات ، فلما هموا بذلك حبسهم الله عنهم حين اقطعهم البحر ، يقول الله عز وجل :{ وما كيد الكافرين إلا في ضلال } آية يعني خسار يقول : { وما كيد } فرعون الذي أراد ببني إسرائيل من قتل الأبناء واستحياء النساء { إلا في ضلال } يعني خسار . <br />
