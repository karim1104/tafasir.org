{ ومن آياته } يعني ومن علاماته عز وجل ، وإن لم تروه ، أن تعرفوا توحيده بصنعه عز وجل { أن يرسل الرياح مبشرات } يعني يستبشر بها الناس رجاء المطر { وليذيقكم من رحمته } يقول : وليعطيكم من نعمته يعني المطر { ولتجزي الفلك } في البحر { بأمره ولتبتغوا } في البحر { من فضله } يعني الرزق كل هذا بالرياح { ولعلكم تشكرون } آية رب هذه النعم فتوحدونه . <br />
