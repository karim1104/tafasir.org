[ الزمر :38 ] { واختلاف ألسنتكم } عربي وعجمي وغيره { و } اختلاف { وألوانكم } أبيض وأحمر وأسود { إن في ذلك لآيات } يعني أن في هذا الذي ذكر لعبرة { للعالمين } آية في توحيد الله عز وجل .
