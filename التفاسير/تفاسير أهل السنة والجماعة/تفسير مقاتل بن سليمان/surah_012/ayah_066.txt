{ قال } أبوهم : { لن أرسله معكم حتى تؤتون موثقا من الله } ، يعنى تعطوني عهدا من الله ، { لتأتنني به } ، يعني بنيامين ولا تضيعوه كما ضيعتم أخاه يوسف ، { إلا أن يحاط بكم } ، يعنى يحيط بكم الهلاك فتهلكوا جميعا ، { فلما ءاتوه موثقهم } يعنى عهدهم ، { قال } يعقوب : { الله على ما نقول وكيل } ، ( آية ) يعنى شهيدا بيني وبينكم ، نظيرها في القصص : { والله على ما نقول وكيل } [ القصص :28 ] .
