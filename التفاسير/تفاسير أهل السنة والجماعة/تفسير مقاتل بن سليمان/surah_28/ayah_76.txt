{ إن قارون كان من قوم موسى } يعنى من بني إسرائيل ، وكان ابن عمه ، قارون بن أصهر بن قوهت بن لاوي بن يعقوب ، وموسى بن عمران بن قوهت { فبغى عليهم } يقول : بغي قارون على بني إسرائيل من أجل كنزه ما له { وآتيناه } يعنى وأعطيناه { من الكنوز } يعنى من الأموال { ما إن مفاتحه } يعنى خزائنه { لتنوا بالعصبة أولى القوة } والعصبة من عشرة نفر إلى أربعين ، فإذا كانوا أربعين فهم أولو قوة يقول : لتعجز العصبة أولى القوة عن حمل الخزائن { إذ قال له قومه } بنو إسرائيل : { لا تفرح } يقول : لا تمرح ولا تبطر ولا تفخر بما أوتيت من الأموال ، { إن الله لا يحب الفرحين } آية يعنى المرحين البطرين . <br />
