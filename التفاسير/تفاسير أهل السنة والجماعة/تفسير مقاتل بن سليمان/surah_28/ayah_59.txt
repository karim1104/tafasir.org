ثم قال الله عز وجل : { وما كان ربك مهلك القرى } يعنى معذب أهل القرى الخالية { حتى يبعث في أمها رسولا } يعنى في أكبر تلك القرى رسولا ، وهي مكة { يتلوا عليهم ءاياتنا } يقول : يخبرهم الرسول بالعذاب بأنه نازل بهم في الدنيا إن لم يؤمنوا { وما كنا مهلكي القرى } يعنى معذبي أهل القرى في الدنيا { إلا وأهلها ظالمون } آية يقول : إلا وهم مذنبون ، يقول : لم نعذب على غير ذنب . <br />
