{ ولله غيب السماوات والأرض } ، يقول : ولله غيب نزول العذاب ، وغيب ما في الأرض ، { وإليه يرجع الأمر كله } ، يعنى : أمر العباد يرجع إلى الله يوم القيامة ، وذلك قوله : { وإلى الله ترجع الأمور } [ البقرة :210 ] ، يعنى : أمور العباد ، { فاعبده } ، يعنى : وحده ، { وتوكل عليه } ، يقول : وثق بالله ، { وما ربك بغافل عما تعملون } [ آية :123 ] هذا وعيد .
