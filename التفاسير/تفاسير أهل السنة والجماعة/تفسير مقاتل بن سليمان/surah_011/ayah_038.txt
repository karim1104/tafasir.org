{ ويصنع الفلك } ، يعنى يعمل فيها ، { وكلما مر عليه } ، يعنى كلما أتى عليه { ملأ } ، يعنى أشراف { من قومه سخروا منه } حين يزعم أنه يصنع بيتا يسير على الماء ، ولم يكونوا رأوا سفينة قط ، { قال } لهم نوح : { إن تسخروا منا } لصنعنا السفينة ، { فإنا نسخر منكم } إذا نزل بكم الغرق ، { كما تسخرون } [ آية :38 ] .
