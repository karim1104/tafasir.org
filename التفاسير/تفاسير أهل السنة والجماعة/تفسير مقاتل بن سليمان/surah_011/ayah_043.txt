{ قال } ابنه { سئاوى } يعنى سأنضم ، { إلى جبل } أصعده { يعصمني } يعني يمنعني { من } غرق { الماء قال } نوح : { لا عاصم اليوم } ، يعنى لا مانع اليوم { من أمر الله } يعنى به الغرق ، ثم استثنى ، فقال : { إلا من رحم } ربي ، يقول : من عصم من المؤمنين فركب معي في السفينة ، فإنه لن يغرق ، يقول الله تعالى : { وحال } يعنى وحجز { بينهما الموج } يعنى بين نوح وابنه كنعان ، { فكان من المغرقين } [ آية :43 ] وغضب الله على كنعان حين ظن أن الجبل يمنعه من الله فلا يغرق .
