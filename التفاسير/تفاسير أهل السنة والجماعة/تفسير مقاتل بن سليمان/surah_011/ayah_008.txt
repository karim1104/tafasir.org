{ ولئن أخرنا عنهم العذاب } يعنى كفار مكة ، { إلى أمة معدودة } ، يعنى إلى سنين معلومة ، نظيرها في يوسف : { واذكر بعد أمة } [ يوسف :45 ] يعنى بعد سنين ، يعنى القتل ببدر ، { ليقولن } يا محمد { ما يحبسه } عنا ، يعنون العذاب تكذيبا ، يقول الله : { ألا يوم يأتيهم } العذاب { ليس مصروفا عنهم } يقول : ليس أحد يصرف العذاب عنهم ، { وحاق } يعنى ودار { بهم ما كانوا به } يعنى بالعذاب { يستهزءون } [ آية :8 ] بأنه ليس بنازل بهم .
