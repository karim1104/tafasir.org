ثم خوفهم ليحذروا .  فقال :{ وكأين } يقول : وكم { من قرية } قد مضت فيما خلا كانت { هي أشد قوة } يعني أشد بطشا وأكثر عددا { من قريتك } يعني مكة { التي أخرجتك } يعني أهل مكة حين أخرجوا النبي صلى الله عليه وسلم ، ثم رجع إلى الأمم الخالية في التقديم . <br />
فقال :{ أهلكناهم } بالعذاب حين كذبوا رسلهم { فلا ناصر لهم } آية يقول : فلم يكن لهم مانع يمنعهم من العذاب الذي نزل بهم . <br />
