{ ولا تزر وازرة وزر أخرى } لا تحمل نفس خطيئة نفس أخرى { وإن تدع مثقلة }من الوزر { إلى حملها } من الخطايا أن يحمل عنها { لا يحمل منه } من وزرها { شيء ولو كان ذا قربى } ولو كان بينهما قرابة ما حملت عنها شيئا من وزرها { إنما تنذر } المؤمنين { الذين يخشون ربهم بالغيب } آمنوا به ولم يروه { وأقاموا الصلاة } أتموا الصلاة المكتوبة { ومن تزكى فإنما يتزكى لنفسه } ومن صلح فصلاحه لنفسه { وإلى الله المصير } آية فيجزى بالأعمال في الآخرة . <br />
