{ هو الذي جعلكم خلائف في الأرض } من بعد الأمم الخالية { فمن كفر } بتوحيد الله { فعليه } عاقبة { كفره ولا يزيد الكافرين كفرهم عند ربهم إلا مقتا } يقول : الكافر لا يزداد في طول العمل إلا ازداد الله جل وعز له بغضا ، ثم قال جل وعز :{ ولا يزيد الكافرين كفرهم إلا خسارا } آية لا يزداد الكافرون في طول العمل إلا ازدادوا بكفرهم خسارا . <br />
