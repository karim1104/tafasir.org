ثم دل جل وعز على نفسه ، فقال : { والله خلقكم } يعني بدأ خلقكم { من تراب } يعني آدم عليه السلام { ثم من نطفة } يعني نسله { ثم جعلكم } ذرية آدم { أزواجا وما تحمل من أنثى } يقول : لا تحمل المرأة الولد { ولا تضع } الولد { إلا بعلمه } ثم قال جل وعز :{ وما يعمر من معمر } يعني من قل عمره أو كثر فهو إلى أجله الذي كتب له ثم قال جل وعز :{ ولا ينقص من عمره } كل يوم حتى ينتهي إلى أجله { إلا في كتاب } اللوح المحفوظ مكتوب قبل أن يخلقه { إن ذلك على الله يسير } آية الأجل حين كتبه الله جل وعز في اللوح المحفوظ . <br />
