{ استكبارا في الأرض ومكر السيئ } قول الشرك { ولا يحيق المكر السيئ } ولا يدور قول الشرك { إلا بأهله } كقوله عز وجل { وحاق بهم } [ هود :8 ] ودار بهم الآية ، ثم خوفهم ، فقال :{ فهل ينظرون } ما ينظرون { إلا سنت الأولين } مثل عقوبة الأمم الخالية ينزل بهم العذاب ببدر كما نزل بأوائلهم { فلن تجد لسنت الله } في العذاب { تبديلا ولن تجد لسنت الله تحويلا } آية لا يقدر أحد أن يحول العذاب عنهم .
