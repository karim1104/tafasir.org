{ فاليوم } في الآخرة { لا يؤخذ منكم } معشر المنافقين { فدية ولا من الذين كفروا } بتوحيد الله تعالى يعني مشركي العرب { مأواكم النار } يعني مأوى المنافقين والمشركين في الناب { هي مولاكم } يعني وليكم { وبئس المصير } آية وذلك أنه يعطي كل مؤمن كافر ، فيقال : هذا فداؤك من النار ، فذلك قوله :{ لا يؤخذ منكم فدية } يعني من المنافقين ، ولا من الذين كفروا ، إنما تؤخذ الفدية من المؤمنين . <br />
