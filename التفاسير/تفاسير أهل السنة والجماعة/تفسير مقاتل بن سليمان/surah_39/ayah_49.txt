{ فإذا مس } يعني أصاب { الإنسان } يعني أبا حذيفة بن المغيرة { ضر } يعني بلاء أو شدة { دعانا } يعني دعا ربه منيبا يعني مخلصا بالتوحيد أن يكشف ما به من الضر { ثم إذا خولناه نعمة منا } يقول : ثم إذا آتيناه ، يعني أعطيناه الخير { قال إنما أوتيته } يعني إنما أعطيت الخير { على علم } عندي يقول : على علم عندي ، يقول : على علم علمه الله مني ، يقول الله عز وجل :{ بل هي فتنة } يعني بل تلك النعمة بلاء ابتلى به { ولكن أكثرهم لا يعلمون } ذلك . <br />
