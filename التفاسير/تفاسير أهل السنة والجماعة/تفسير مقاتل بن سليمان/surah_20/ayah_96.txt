{ قال } السامري : { بصرت بما لم يبصروا به } يقول : بما لم يفطنوا به يقول : عرفت ما لم يعرفوه من أمر فرس جبريل ، عليه السلام ، { فقبضت قبضة من أثر } فرس { الرسول } يعنى تحت فرس جبريل ، عليه السلام ، { فنبذتها } في النار على أثر الحلي { وكذلك سولت لي نفسي } آية ، يقول : هكذا زينت لي نفسي أن أفعل ذلك . <br />
