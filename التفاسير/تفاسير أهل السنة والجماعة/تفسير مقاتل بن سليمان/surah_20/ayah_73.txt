{ إنا ءامنا بربنا } يقول : إنا صدقنا بتوحيد الله عز وجل ، ليغفر لنا خطايانا يقول : سحرنا { و } يغفر لنا { ما } الذي { أكرهتنا عليه } يعنى ما جبرتنا عليه { من السحر والله خير وأبقى } آية ، يقول الله جل جلاله : أفضل منك وأدوم منك يا فرعون ، فإنك تموت ويبقى الرب وحده تعالى جده ؛ لقول فرعون : {  .  .  . أينا أشد عذابا وأبقى } [ طه :71 ] .
