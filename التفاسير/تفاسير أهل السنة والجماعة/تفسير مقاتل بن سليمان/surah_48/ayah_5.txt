{ ليدخل المؤمنين والمؤمنات } يعني لكي يدخل المؤمنين والمؤمنات بالإسلام { جنات تجري من تحتها الأنهار } من تحت البساتين { خالدين فيها } لا يموتون { و } لكي { ويكفر عنهم سيئاتهم } يعني يمحو عنهم ذنوبهم { وكان ذلك } الخير { عند الله فوزا عظيما } آية فأخبر الله تعالى نبيه بما يفعل بالمؤمنين ، فانطلق عبد الله بن أبي رأس المنافقين في نفر معه إلى النبي صلى الله عليه وسلم ، فقالوا : ما لنا عند الله ؟ فنزلت { بشر المنافقين بأن لهم عذابا أليما } يعني وجيعا . <br />
