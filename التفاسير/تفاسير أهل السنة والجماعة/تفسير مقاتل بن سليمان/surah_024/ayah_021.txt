{ يا أيها الذين ءامنوا لا تتبعوا خطوات الشيطان } يعنى تزيين الشيطان ، في قذف عائشة ، رضي الله عنها ، { ومن يتبع خطوات الشيطان فإنه يأمر بالفحشاء } يعنى بالمعاصي { والمنكر } يعنى ما لا يعرف { ولولا فضل الله عليكم ورحمته } يعنى نعمته { ما زكى } يعنى ما صلح { منكم من أحد أبدا ولكن الله يزكي } يعنى يصلح { من يشاء والله سميع } لقولهم لعائشة { عليم } آية ، به . <br />
