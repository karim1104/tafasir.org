{ يا أيها الذين آمنوا قوا أنفسكم وأهليكم } بالأدب الصالح النار في الآخرة { نارا وقودها الناس } يعني أهلها { والحجارة } تتعلق في عنق الكافر مثل جبل الكبريت تشتعل عليه النار بحرها على وجهه { عليها } يعني على النار { ملائكة } يعني خزنتها التسعة عشر { غلاظ شداد } يعني أقوياء وذلك أن ما بين منكبي أحدهم مسيرة سنة وقوة أحدهم أن يضرب بالمقمعة فيدفع بتلك الضربة سبعين ألفا عظم كل إنسان مسيرة أيام فيهوى في قعر جهنم أربعين سنة ، فيقع أحدهم لا حيا ولا ميتا .  { لا يعصون الله ما أمرهم ويفعلون ما يؤمرون } آية يعني خزنة جهنم . <br />
