ثم قال :{ لينفق } في المراضع { ذو سعة } في المال { من سعته } الذي أوسع الله له على قدره { ومن قدر } يعني فتر { عليه رزقه } مثل قوله :{ إذ ذهب مغاضبا فظن أن لن نقدر عليه } [ الأنبياء :87 ] يعني نضيق عليه في بطن الحوت ، { فلينفق } في المراضع قدر فقره { مما آتاه الله } يعني مما أعطاه الله من الرزق على قدر طاقته ، فذلك قوله :{ لا يكلف الله } في النفقة { نفسا إلا ما آتاها } يعني إلا ما أعطاها من الرزق { سيجعل الله بعد عسر يسرا } آية يعني من بعد الفقر سعة في الرزق .
