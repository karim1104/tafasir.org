{ أسكنوهن } يعني المطلقة الواحدة والثنتين { من حيث سكنتم من وجدكم } يعني من سعتكم في النفقة ، والمسكن ، { ولا تضاروهن لتضيقوا عليهن وإن كن أولات حمل } يعني المطلقة وهي حبلى { فأنفقوا عليهن حتى يضعن حملهن فإن أرضعن لكم } أولادكم إذا وضعن حملهن { فآتوهن أجورهن } يعني فأعطوهن أجورهن { وأتمروا بينكم } يعني الرجل والمرأة { بمعروف } يقول : حتى تنفقوا من النفقة على أمر بمعروف { وإن تعاسرتم } يعني الرجل والمرأة وإذا أراد الرجل أقل مما طلبت المرأة من النفقة فلم يتفقوا على أمر { فسترضع له } يعني للرجل امرأة { أخرى } آية يقول : ليلتمس غيرها من المراضع . <br />
