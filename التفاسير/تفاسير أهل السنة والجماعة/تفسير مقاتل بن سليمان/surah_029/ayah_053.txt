{ ويستعجلونك بالعذاب } استهزاء وتكذيبا به ، ونزلت في النضر بن الحارث ، حيث قال : { فأمطر علينا } في الدنيا { حجارة من السماء أو ائتنا بعذاب أليم } [ الأنفال :32 ] يقول : ذلك استهزاء وتكذيبا ، فنزلت فيه : <br />
{ ويستعجلونك بالعذاب ولولا أجل مسمى } في الآخرة { لجاءهم العذاب } الذين استعجلوه في الدنيا ، <br />
{ وليأتينهم } العذاب في الآخرة { بغتة } يعنى فجأة { وهم لا يشعرون } آية يعنى يعلمون به حتى ينزل بهم العذاب .
