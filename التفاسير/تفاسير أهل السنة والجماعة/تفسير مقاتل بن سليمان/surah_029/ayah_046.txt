{ ولا تجادلوا } يعنى النبي صلى الله عليه وسلم وحده { أهل الكتاب } البتة يعنى مؤمنيهم عبد الله بن سلام وأصحابه ، { إلا بالتي هي أحسن } فيها تقديم ، يقول : جادلهم قل لهم بالقرآن وأخبرهم عن القرآن ، نسختها آية السيف في براءة ، فقال تعالى : { قاتلوا الذين لا يؤمنون بالله ولا باليوم الآخر } [ التوبة :29 ] { إلا الذين ظلموا منهم وقولوا } لهم يعنى ظلمة اليهود { ءامنا بالذي أنزل إلينا } يعنى القرآن { وأنزل إليكم } يعنى التوراة { و } قولوا لهم : { وإلهنا وإلهكم واحد } ربنا وربكم واحد { ونحن له مسلمون } آية يعنى مخلصين بالتوحيد .
