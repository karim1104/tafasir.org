ثم قال عز وجل : { فيه آيات بينات مقام إبراهيم } ، يعني علامة واضحة أثر مقام إبراهيم صلى الله عليه وسلم ، { ومن دخله } في الجاهلية { كان آمنا } حتى يخرج منه ، { ولله على الناس } ، يعني المؤمنين { حج البيت من استطاع إليه سبيلا } ، يعني بالاستطاعة الزاد والراحلة ، { ومن كفر } من أهل الأديان بالبيت ولم يحج واجبا فقد كفر ، فذلك قوله سبحانه : { ومن كفر } { فإن الله غني عن العالمين } . <br />
