{ وقال الذين كفروا لولا نزل } يعني هلاّ نزل { عليه القرءان جملة واحدة } كما جاء به موسى وعيسى يقول : { كذلك لنثبت به فؤادك } يعني ليثبت القرآن في قلبك { ورتلناه ترتيلا } آية ، يعني نرسله ترسلا آيات ثم آيات ، ذلك قوله سبحانه : { وقرآناً فَرقْناه لتقرَأه على الناس على مُكْثٍ ونزّلناه تَنْزيلا } [ الإسراء :106 ] .
