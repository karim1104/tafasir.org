{ وقال الشيطان } ، يعني إبليس ، { لما قضي الأمر } ، يعني حين قضي العذاب ، وذلك أن إبليس لما دخل هو ومن معه على أثره النار ، قام خطيبا في النار ، فقال : يا أهل النار : { إن الله وعدكم } على ألسنة الرسل ، { وعد الحق } ، يعني وعد الصدق أن هذا اليوم كائن ، { ووعدتكم } أنه ليس بكائن ، { فأخلفتكم } الوعد ، { وما كان لي عليكم من سلطان } ، يعني من ملك في الشرك ، فأكرهكم على متابعتي ، يعني على ديني إلا في الدعاء . <br />
فذلك قوله عز وجل : { إلا أن دعوتكم } ، يعني إلا أن زينت لكم ، { فاستجبتم لي } بالطاعة وتركتم طاعة ربكم ، { فلا تلوموني } باتباعكم إياي ، { ولوموا أنفسكم } بترككم أمر ربكم ، { ما أنا بمصرخكم وما أنتم بمصرخي } ، يقول : ما أنا بمغيثكم وما أنتم بمغيثي ، { إني كفرت } ، يقول : تبرأت اليوم { بما أشركتمون } مع الله في الطاعة ، { من قبل } في الدنيا ، { إن الظالمين } ، يعني إن المشركين ، { لهم عذاب أليم } [ آية :22 ] ، يعني وجيع .
