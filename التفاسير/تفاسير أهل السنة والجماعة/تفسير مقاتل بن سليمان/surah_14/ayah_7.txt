{ وإذ تأذن ربكم } ، نظيرها في الأعراف : { وإذ تأذن ربك ليبعثن عليهم إلى يوم القيامة } [ الأعراف :167 ] ، وإذ قال ربكم : { لئن شكرتم لأزيدنكم } ، يعنى لئن وحدتم الله عز وجل ، كقوله سبحانه : { وسيجزى الله الشاكرين } [ آل عمران :144 ] ، يعني الموحدين ، لأزيدنكم خيرا في الدنيا ، { ولئن كفرتم } بتوحيد الله { إن عذابي لشديد } [ آية :7 ] لمن كفر بالله عز وجل في الآخرة .
