{ وعد الله الذين ءامنوا منكم وعملوا الصالحات } وذلك أن كفار مكة صدوا المسلمين عن العمرة عام الحديبية ، فقال المسلمون : لو أن الله عز وجل فتح علينا مكة ودخلناها آمنين ، فسمع الله عز وجل قولهم ، فأنزل الله تبارك وتعالى : { وعد الله الذين ءامنوا منكم وعملوا الصالحات } { ليستخلفنهم في الأرض } يعنى أرض مكة { كما استخلف الذين من قبلهم } من بني إسرائيل وغيرهم ، وعدهم أن يستخلفهم بعد هلاك كفار مكة { وليمكنن لهم دينهم } الإسلام حتى يشيع الإسلام { الذي ارتضى لهم } يعنى الذي رضي لهم { وليبدلنهم من بعد خوفهم } من كفار أهل مكة { آمنا } لا يخافون أحدا { يعبدونني } يعنى يوحدونني { لا يشركون بي شيئا } من الآلهة { ومن كفر بعد ذلك } التمكين في الأرض ، { فأولئك هم الفاسقون } آية ، يعنى العاصين . <br />
