ثم قال : { وقاتلوهم } أبدا { حتى لا تكون فتنة } ، يقول : حتى لا يكون فيهم شرك فيوحدوا ربهم ولا يعبدوا غيره ، يعني مشركي العرب خاصة ، { ويكون } ، يعني ويقوم { الدين لله } ، فيوحدوه ولا يعبدوا غيره ، { فإن انتهوا } عن الشرك ووحدوا ربهم ، { فلا عدوان } ، يعني فلا سبيل { إلا على الظالمين } الذين لا يوحدون ربهم ، نظيرها في القصص : { فلا عدوان علي } ، ( القصص : 28 ) ، يعني فلا سبيل علي .
