{ هو الله الذي لا إله إلا هو } فوحد نفسه ، فقال لنفسه :{ الملك } يعني يملك كل شيء دونه  ،{ القدوس } يعني الطاهر { السلام } يسلم عباده من ظلمه { المؤمن } يؤمن أولياءه من عذابه { المهيمن } يعني الشهيد على عباده بأعمالهم من خير أو شر ، كقوله :{ ومهيمنا عليه } [ المائدة :48 ] كقوله :{ شاهدا عليكم } [ المزمل :15 ] على عباده بأعمالهم من خير أو شر المصدق بكتابه الذي أنزله على محمد صلى الله عليه وسلم { العزيز } يعني المنيع بقدرته في ملكه { الجبار } يعني القاهر على ما أراد بخلقه { المتكبر } يعني المتعظم على كل شيء { سبحان الله } نزه الرب نفسه عن قولهم البهتان  ،{ عما يشركون } آية معه فنزه الرب نفسه أن يكون له شريك ، فقال :{  سبحان الله عما يشركون } معه غيره أن يكون له شريك .
