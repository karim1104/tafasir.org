{ أم حسبتم أن تتركوا } على الإيمان ولا تبتلوا بالقتل ، { ولما يعلم الله } ، يعنى ولما يرى الله { الذين جاهدوا } العدو { منكم } في سبيله ، يقول : لا يرى جهادكم حتى تجاهدوا ، { ولم يتخذوا من دون الله ولا } من دون { رسوله ولا } من دون { المؤمنين وليجة } يتولجها ، يعنى البطانة من الولاية للمشركين ، { والله خبير بما تعملون } [ آية :16 ] .
