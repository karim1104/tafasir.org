{ ومن الأعراب من يتخذ ما ينفق } في سبيل الله { مغرما } لا يحتسبها ، كان نفقته غرم يغرمها ، { ويتربص بكم الدوائر } ، يعنى يتربص بمحمد الموت ، يقول : يموت فنستريح منه ولا نعطيه أموالنا ، ثم قال : { عليهم } بمقالتهم { دائرة السوء } نزلت في أعراب مزينة ، { والله سميع } لمقالتهم ، { عليم } بها [ آية :98 ]  .
