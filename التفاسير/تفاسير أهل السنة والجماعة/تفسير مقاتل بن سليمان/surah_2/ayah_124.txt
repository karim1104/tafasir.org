{ وإذ ابتلى إبراهيم ربه بكلمات } ، يعني  : بذلك كل مسألة في القرآن مما سأل إبراهيم من قوله : { رب اجعل هذا بلدا آمنا وارزق أهله من الثمرات } ( البقرة : 126 ) ، ومن قوله : { ربنا واجعلنا مسلمين لك ومن ذريتنا أمة مسلمة لك وأرنا مناسكنا وتب علينا إنك أنت التواب الرحيم } ( البقرة : 128 ) وحين قال : { ربنا وابعث فيهم رسولا منهم يتلو عليهم آياتك } ( البقرة : 129 ) وحين قال لقومه حين حاجوه : { إني برئ مما تشركون } ( الأنعام : 78 ) .  وحين قال : { إني وجهت وجهي للذي فطر السماوات والأرض حنيفا } ( الأنعام : 79 ) ،وحين ألقى في النار ، وحين أراد ذبح ابنه ، وحين قال : { رب هب لي من الصالحين } ( الصافات : 100 ) ، وحين سأل الولد ، وحين قال : { واجنبني وبني أن نعبد الأصنام } ( إبراهيم : 37 ) ، وحين قال : { فاجعل أفئدة من الناس تهوي إليهم } ( إبراهيم : 37 ) وحين قال : { ربنا تقبل منا إنك أنت السميع العليم } ( البقرة : 127 ) ، وما كان نحو هذا في القرآن ، وما سأل إبراهيم فاستجاب له ، { فأتمهن } ثم زاده الله مما لم يكن في مسألته ، { قال إني جاعلك للناس إماما } في الدين يقتدى بسنتك ، { قال } إبراهيم : يا رب ، { ومن ذريتي } فاجعلهم أئمة ، { قال } الله : إن في ذريتك الظلمة ، يعني  : اليهود والنصارى ، { لا ينال عهدي الظالمين } يعني  : المشركين من ذريتك ، قال : لا ينال طاعتي الظلمة من ذريتك ، ولا أجعلهم أئمة ، أنحلها أوليائي وأجنبها أعدائي .
