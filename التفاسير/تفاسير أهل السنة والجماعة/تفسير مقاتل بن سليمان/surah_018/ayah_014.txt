{ وربطنا على قلوبهم } بالإيمان ، { إذ قاموا } ، على أرجلهم قياما ، { فقالوا ربنا } وهو { رب السماوات والأرض لن ندعوا } ، يعنى لن نعبد { من دونه إلاها } ، يعنى برا غير الله عز وجل ، كفعل قومنا ، ولئن فعلنا ، { لقد قلنا إذا } على الله { شططا } آية ، يعنى جورا ، نظيرها في ص : { ولا تشطط واهدنا } [ ص :22 ] ، وفي سورة الجن : { وأنه كان يقول سفيهنا على الله شططا } [ الجن :4 ] .
