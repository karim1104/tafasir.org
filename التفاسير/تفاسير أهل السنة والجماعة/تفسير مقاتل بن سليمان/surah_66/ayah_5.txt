ثم قال :{ عسى ربه } يعني رب محمد صلى الله عليه وسلم { إن طلقكن } النبي صلى الله عليه وسلم فطلقها النبي صلى الله عليه وسلم واحدة وراجعها { أن يبدله أزواجا خيرا منكن } ، ثم نعتهن ، فقال :{ مسلمات } يعني مخلصات { مؤمنات } يعني مصدقات بتوحيد الله تعالى { قانتات } يعني مطيعات { تائبات } من الذنوب { عابدات } يعني موحدات { سائحات } يعني صائمات { ثيبات } يعني أيمات لا أزواج لهن { وأبكارا } آية عذارى لم يمسسن . <br />
