{ وإذا أذقنا الناس } يعنى آتينا الناس ، يعنى كفار مكة ، { رحمة } يعنى المطر ، { من بعد ضراء } يعنى القحط وذهاب الثمار ، { مستهم } يعني المجاعة سبع سنين ، { إذا لهم مكر في ءاياتنا } يعنى تكذيبا ، يقول : إذ لهم قول في التكذيب بالقرآن تكذيبا واستهزاء ، { قل الله أسرع مكرا } يعنى الله أشد إخزاء ، { إن رسلنا } من الحفظة { يكتبون ما تمكرون } [ آية :21 ] يعنى ما تعلمون .
