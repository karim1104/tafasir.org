ثم أخبر عن المؤمنين فنعتهم لقول هؤلاء الأعراب آمنا ، فقال :{ إنما المؤمنون } المصدقون في إيمانهم { الذين آمنوا } يعني صدقوا { بالله } بأنه واحد لا شريك له { ورسوله } محمد صلى الله عليه وسلم أنه نبي رسول وكتابه حقه { ثم لم يرتابوا } يعني لم يشكوا في دينهم بعد الإيمان { وجاهدوا } العدو مع النبي صلى الله عليه وسلم { بأموالهم وأنفسهم } يعني باشروا القتال بأنفسهم { في سبيل الله } يعني في طاعة الله { أولئك هم الصادقون } آية في إيمانهم . <br />
