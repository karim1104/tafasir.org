{ ولقد أهلكنا القرون } بالعذاب في الدنيا ، { من قبلكم } يا أهل مكة ، { لما ظلموا } ، يعنى حين أشركوا ، يخوف كفار مكة بمثل عذاب الأمم الخالية لكي لا يكذبوا محمدا صلى الله عليه وسلم { وجاءتهم رسلهم بالبينات } ، يقول : أخبرتهم رسلهم بالعذاب أنه نازل بهم في الدنيا ، ثم قال : { وما كانوا ليؤمنوا } ، يقول : ما كان كفار مكة ليصدقوا بنزول العذاب بهم في الدنيا ، { كذلك } ، يعنى هكذا { تجزى } بالعذاب { القوم المجرمين } [ آية :13 ] ، يعنى مشركي الأمم الخالية .
