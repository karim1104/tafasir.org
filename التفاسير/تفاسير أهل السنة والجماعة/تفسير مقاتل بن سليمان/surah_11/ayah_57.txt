{ فإن تولوا } يعنى فإن تعرضوا عن الإيمان ، { فقد أبلغتكم ما أرسلت به إليكم } من نزول العذاب بكم في الدنيا ، { ويستخلف ربي } بعد هلاككم { قوما غيركم } أمثل وأطوع لله منكم ، { ولا تضرونه شيئا } يقول : ولا تنقصونه من ملكه شيئا ، إنما تنقصون أنفسكم ، { إن ربي على كل شيء } من أعمالكم { حفيظ } [ آية :57 ] .
