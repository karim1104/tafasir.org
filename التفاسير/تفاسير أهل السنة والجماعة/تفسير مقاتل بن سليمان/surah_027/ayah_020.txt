{ وتفقد الطير } يعني الهدهد حين سار من بيت المقدس قبل اليمن فلما مر بالمدينة وقف ، فقال إن الله عز وجل : سيبعث من هاهنا نبيا طوبى لمن تبعه ، فلما أراد أن ينزل { فقال مالي لا أرى الهدهد أم } والميم ها هنا صلة ، كقوله تعالى : { أم عندهم } يعنى أعندهم { الغيب فيهم يكتبون } [ الطور :41 ، والقلم :47 ] أم { كان من الغائبين }
