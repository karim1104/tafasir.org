{ خلقكم من نفس واحدة } يعني آدم ، عليه السلام { ثم جعل منها زوجها } يعني حواء { وأنزل لكم من الأنعام } يعني وجعل لكم من أمره مثل قوله في الأعراف :{ يا بني آدم قد أنزلنا عليكم لباسا } [ الأعراف :26 ] يقول جعلنا ، ومثل قوله :{ وأنزلنا الحديد } [ الحديد :25 ] يقول : وجعلنا الحديد { وأنزل لكم من الأنعام } يعني الإبل والبقر والغنم { ثمانية أزواج } يعني أصناف ، يعني أربعة ذكور ، وأربعة إناث { يخلقكم في بطون أمهاتكم خلقا من بعد خلق } يعني نطفة ، ثم علقة ، ثم مضغة ، ثم عظما ، ثم الروح { في ظلمات ثلاث } يعني البطن والرحم والمشيمة التي يكون فيها الولد ، ثم قال :{ ذلكم الله } الذي خلق هذه الأشياء هو { ربكم له الملك لا إله إلا هو فأنى تصرفون } آية يقول : فمن أين تعدلون عنه إلى غيره .
