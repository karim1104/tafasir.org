{ وأشرقت الأرض بنور ربها } يعني بنور ساقه ، فذلك قوله تعالى :{ يوم يكشف عن ساق } [ القلم :42 ] { ووضع الكتاب } الذي عملوا في أيديهم ليقرءوه { وجاء بالنبيين } فشهدوا عليهم بالبلاغ { والشهداء } يعني الحفظة من الملائكة ، فشهدوا عليهم بأعمالهم التي عملوها { وقضي بينهم بالحق } يعني بالعدل { وهم لا يظلمون } آية في أعمالهم .
