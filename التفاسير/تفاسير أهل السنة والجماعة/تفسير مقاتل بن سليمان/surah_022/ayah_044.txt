{ وأصحاب مدين } يعنى قوم شعيب ، عليه السلام ، كل هؤلاء كذبوا رسلهم { وكذب موسى } يعنى عصى موسى ، عليه السلام ، لأنه ولد فيهم كما ولد محمد صلى الله عليه وسلم فيهم { فأمليت } يعنى فأمهلت { للكافرين } فلم أعجل عليهم بالعذاب { ثم أخذتهم } بعد الإمهال بالعذاب { فكيف كان نكير } آية ، يعنى تغييري أليس وجدوه حقا ، فكذلك كذب كفار مكة كما كذبت مكذبي الأمم الخالية . <br />
