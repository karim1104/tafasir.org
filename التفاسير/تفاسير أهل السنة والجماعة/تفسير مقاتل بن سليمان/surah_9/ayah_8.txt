ثم حرض المؤمنين على قتال كفار مكة الذين لا عهد لهم ؛ لأنهم نقضوا العهد ، فقال : { كيف } لا تقاتلونهم ، { وإن يظهروا عليكم لا يرقبوا فيكم إلا ولا ذمة } يقول : لا يحفظوا فيكم قرابة ولا عهدا ، { يرضونكم بأفواههم } ، يعنى بألسنتهم ، { وتأبى قلوبهم } وكانوا يحسنون القول للمؤمنين ، فيرضونهم وفي قلوبهم غير ذلك ، فأخبر عن قولهم ، فذلك قوله : { يرضونكم بأفواههم } ، يعنى بألسنتهم ، { وتأبى قلوبهم } { وأكثرهم فاسقون } [ آية :8 ] .
