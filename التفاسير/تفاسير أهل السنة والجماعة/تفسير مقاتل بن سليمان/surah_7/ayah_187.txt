{ يسألونك عن الساعة } ، وذلك أن كفار قريش سألوا النبي صلى الله عليه وسلم عن الساعة ، { أيان مرساها } ، يعني متى حينها ، { قل } لهم : { إنما علمها عند ربي } ، وما لي بها من علم ، { لا يجليها لوقتها } ، يعني لا يكشفها ، { إلا هو } إذا جاءت ، ثم أخبر عن شأنها ، فقال : { ثقلت في السماوات والأرض } ، يقول : ثقل على من فيهما علمها ، { لا تأتيكم إلا بغتة } ، يعني فجأة ، ثم قال : { يسألونك } عنها في التقديم ، { كأنك حفي عنها } ، يقول : كأنك قد استحفيت عناه السؤال حتى علمتها ، { قل } : وما لي بها من علم ، { إنما علمها عند الله ولكن أكثر الناس لا يعلمون } ، يعني أكثر أهل مكة لا يعلمون أنها كائنة . <br />
