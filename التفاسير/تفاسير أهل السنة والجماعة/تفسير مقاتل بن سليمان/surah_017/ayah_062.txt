ثم { قال } إبليس لربه عز وجل : { أرأيتك هذا الذي كرمت على } ، يعنى فضلته على بالسجود ، يعنى آدم ، أنا ناري وهو طيني ، { لئن أخرتن } ، يقول : لئن متعتني { إلى يوم القيامة لأحتنكن } ، يعنى لأحتوين { ذريته } ذرية آدم ، { إلا قليلا } آية ، حتى يطيعوني ، يعنى بالقليل الذي أراد الله عز وجل ، فقال : { إن عبادي ليس لك عليهم سلطان } [ الحجر :42 ] ، يعنى ملكا .
