قوله :{ ليجزي } اللام متعلقة ب { تغشى } أو بجميع ما ذكر كأنه قيل : يفعل بالمجرمين ما يفعل ليجزي { الله كل نفس ما كسبت } قال الواحدي : أراد نفوس الكفار لأن ما سبق لا يليق إلا بهم .   ويحتمل أن يراد كل نفس مجرمة ومطيعة لأنه تعالى إذا عاقب المجرمين لإجرامهم علم أنه يثيب المطيعين لطاعتهم .   ثم أشار إلى القرآن إلى ما في السورة أو إلى ما مر من قوله : { ولا تحبسن الله غافلاً } إلى ههنا فقال { هذا بلاغ } كفاية { للناس } في التذكير والموعظة لينصحوا { ولينذروا به } بهذا البلاغ .   ثم رمز إلى استكمال القوّة النظرية بقوله : { وليعلموا أنما هو إله واحد } وإلى استكمال القوة العملية بقوله : { وليذكر أولوا الألباب } لأنهم إذا خافوا ما أنذروا به دعتهم المخافة إلى استكمال النفس بحسب القوتين والله ولي التوفيق .  <br />
