قال أهل النظم : وإن إنكاراً البعث يتولد تارة من الشبهة بأن يستبعد اجتماع الأجزاء بعد تفرقها وتلاشيها ،   وأخرى من التهور بأن ينكر المعاد باسترسال الطبع والميل إلى الفجور ،   فأشار إلى الجواب عن الشبهة بقوله { أيحسب الإنسان } إلى قوله { بناته } وأنكر على الثني بقوله { بل يريد } أن يكذب بما أمامه من البعث والحساب لئلا تنتقص عنه اللذات العاجلة { يسأل } سؤال تنعت { أيان يوم القيامة } .  <br />
