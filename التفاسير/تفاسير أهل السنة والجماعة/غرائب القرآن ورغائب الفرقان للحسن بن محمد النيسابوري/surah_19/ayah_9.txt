{ قال } الأمر { كذلك } تصديقاً له .   ثم ابتدأ قائلاً { قال ربك } فمحل { كذلك } رفع ،   ويحتمل أن يكون نصباً { قال } وذلك إشارة إلى مبهم يفسره قوله : { هو } أي خلق الغلام { عليّ هين } ويحتمل أن يكون إشارة إلى قول زكريا { أنى يكون لي غلام } أي كيف تعطيني الغلام أبأن تجعلني وزوجتي شابين أو بأن تتركنا على الشيخوخة ؟ فأجيب بقوله : { كذلك } أي نهب الولد لك مع بقائك وبقاء زوجتك على حالتكما .   ولفظ الهين مجاز عن كمال القدرة وهو فيعل من هان الشيء يهون إذا لم يصعب ولم يمتنع عن المراد { ولم تك شيئاً } لأن المعدوم ليس بشيء أو شيئاً يعتد به كالنطفة ،   أو كالجواهر التي لم تتألف بعد ،   فيه نفس استبعاد زكريا ،   لأن خلق الذات ثم تغييرها في أطوار الصفات ليس أهون من تبديل الصفات وهو أحداث القوة المولدة في زكريا وصاحبته بعد أن لم تكن .  <br />
