ثم مدح رسوله صلى الله عليه وسلم وذكر فائدة بعثته ليرتب عليه ذكر البيعة فقال { إنا أرسلناك شاهداً } على أمتك { ومبشراً ونذيراً } وقد مر في سورة الأحزاب مثله إلا أن قوله : { لتؤمنوا بالله ورسوله وتعزروه وتوقروه وتسبحوه بكرة وأصيلا } { لتؤمنوا بالله ورسوله } قائم مقام قوله هناك { وداعياً إلى الله بإذنه } [ الآية : 46 ].  <br />
