{ فكذب } بالقلب واللسان إذ نسب المعجز إلى السحر { وعصى } بإظهار التمرد الطغيان .  <br />
{ ثم أدبر } خوفاً من الثعبان { يسعى } هارباً أو يتحيل في دفع موسى أو تولى عن موسى إظهاراً للجحود .   وجوز أن يكون { أدبر } موضوعاً مكان  "  أقبل  "  مكان يقال : أقبل فلان يفعل كذا بمعنى طفق يفعل فكنى عن الإقبال بالإدبار إظهاراً للسخط ولقصد التفاؤل عليه .  <br />
ومعنى الفاء في { فكذب } أنه لم يلبث عقيب رؤية الآية الكبرى أن بادرها بنقيض مقتضاها لفرط عتوّه ورسوخ تفرعنه .  <br />
