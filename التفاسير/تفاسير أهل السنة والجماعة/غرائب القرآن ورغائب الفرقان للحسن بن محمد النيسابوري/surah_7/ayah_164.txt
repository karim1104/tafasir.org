والنوع الثالث قوله { وإذ قالت } وهو معطوف على { إذ يعدون } وحكمه حكمه في الإعراب { أمة منهم } جماعة من صلحاء أهل القرية الذين بالغوا في موعظتهم حتى آيسوا الآخرين كانوا لا يتركون وعظهم { لم تعظون قوماً الله مهلكهم } مدمرهم { أو معذبهم عذاباً شديداً } لعلمهم بأن عاقبة المعصية شؤم والمنهمك في الفساد لا يكاد يفلح { قالوا معذرة } من رفع فبتقدير هذه أو موعظتنا أو قولنا إبداء عذر إلى الله .   والمعذرة مصدر كالمغفرة ،   ومن نصب فعلى أنَّا نعتذر معذرة أو وعظناهم معذرة إلى ربكم أي إذا طولبنا بإقامة النهي عن المنكر قلنا قد فعلنا فنكون بذلك معذورين { ولعلهم يتقون } ولأنا نرجو أن يتقوا بعض الاتقاء فيتركوا الصيد في السبت .  <br />
