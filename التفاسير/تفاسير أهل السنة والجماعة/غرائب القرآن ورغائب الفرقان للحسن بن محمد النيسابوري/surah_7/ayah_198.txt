{ وإن تدعوهم إلى الهدى لا يسمعوا } لا سماع سمع ولا سماع إجابة { وتراهم } تحسبهم { ينظرون إليك } يشبهون الناظرين إليك لأنهم صوّروا أصنامهم بصورة من قلب حدقته إلى الشيء ينظر إليك { وهم لا يبصرون } لا يدركون المرئي .   وقيل : الضمير في قوله { وإن تدعوهم } إلى آخر الآية يعود إلى المشركين المار ذكرهم في قوله { قل ادعوا } والمراد أنهم بلغوا في الجهل والحماقة إلى أنك لو دعوتهم وأظهرت أنواع الحجة والبرهان لم يسمعوا بعقولهم البتة { وتراهم } إلى الناس وإليك ينظرون ولكنهم لشدّة إعراضهم عن قبول الحق لم ينتفعوا بذلك النظر فكأنهم عمي يصدقه قوله في موضع آخر { فإنها لا تعمى الأبصار ولكن تعمى القلوب التي في الصدور } [ الحج : 46 ] .  <br />
