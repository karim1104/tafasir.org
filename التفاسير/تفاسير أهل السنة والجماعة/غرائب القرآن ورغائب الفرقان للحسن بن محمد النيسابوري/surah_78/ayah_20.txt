وأما الجبال فإنه تعالى ذكر حالها بعبارات مختلفة ،   ويمكن الجمع بينها بأن تدرك أوّلاً { وحملت الأرض والجبال فدكتا دكة واحدة } [ الحاقة :14 ] ثم تصير كالعهن ثم تصير كالهباء { وبست الجبال بساً فكانت هباء منبثاً } وهي في كل هذه الأحوال باقية في مواضعها ثم تنسف بإرسال الرياح عليها { وإذا الجبال نسفت }<br />
[ الانفطار :4 ] ثم تطير هاهنا أحوال إذا برزت من تحتها { ويوم نسير الجبال وترى الأرض بارزة } [ الكهف :47 ] والثاني للجبال فتطيره في الهواء كالهباء فمن نظر إليها حسبها لتكاثفها أجساماً جامدة وهي بالحقيقة مارة بتحريك الهواء كما قال { وترى الجبال تحسبها جامدة وهي تمرّ مرّ السحاب }[ النمل :88 ] والثالث لها باعتبار أماكنها الأصلية فمن نظر إلى المواضع من بعيد ظن أن الجبال هناك حتى إذا دنا منها لم يجد فيها شيئاً{ كسراب بقيعة يحسبه الظمآن ماء حتى إذا جاءه لم يجده شيئاً } [ النور :39 ] وقد أشار إلى هذه الحالة بقوله { وسيرت الجبال فكانت سراباً } .  <br />
