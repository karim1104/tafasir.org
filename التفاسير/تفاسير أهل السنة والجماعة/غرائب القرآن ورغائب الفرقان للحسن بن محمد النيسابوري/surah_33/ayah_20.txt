ثم قرر طرفاً آخر من جبنهم وهو أنهم { يحسبون الأحزاب لم يذهبوا } وقد ذهبوا فانصرف المنافقون إلى المدينة منهزمين بناء على هذا الحسبان .   ومن جملة جبنهم وضعف احتمالهم أنه { أن يأت الأحزاب } كرة ثانية تمنوا { أنهم بادون } أي خارجون إلى اليد وحاصلون فيما بين الأعراب حذراً من عيان القتال فيكون حالهم إذ ذاك أنهم { يسألون عن أنبائكم } قانعين من العيان بالأثر ومن الحضور بالخبر { ولو كانوا فيكم } ولم ينصرفوا إلى المدينة وكان قتال لم يقاتلوا { إلا قليلاً } إبداء للعذر على سبيل الرياء والضرورة .  <br />
