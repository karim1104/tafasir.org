{ ما تعبدون من دونه إلا أسماء سميتموها } أي سميتم الآلهة بتلك الأسماء { أنتم وآباؤكم } والخطاب لهما ولمن على دينهما من أهل مصر فكأنهم لا يعبدون إلا أسماء فارغة عن المسميات { ما أنزل الله بها } بتسميتها { من سلطان } أي حجة .   ثم لما نفى معبودية الغير بين أن لا حكم في أمر الدين والعبادة إلا له فقال : { إن الحكم إلا لله } ثم ذكر ما حكم به فقال : { أمر ألا تعبدوا إلا إياه ذلك الدين القيم } الثابت بالبراهين { ولكن أكثر الناس لا يعلمون } أنه مبدأ المبادىء والمعاد الحقيقي فيتخذون غيره معبوداً ويجعلون لغيره من الأصنام والأجرام بالاستقلال فعلاً وتأثيراً .  <br />
