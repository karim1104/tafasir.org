ومعنى { منذر منهم } أي من جنسهم أو من بينهم فتوجه العجب إلى الإنذار بالبعث أوّلاً ثم إلى كون المنذر منهم ،   ولعل الأول أدخل عندهم في استحقاق التعجب منه فلهذا أشاروا إليه بقولهم { هذا } الرجع أو البعث { شيء عجيب } أبهم الضمير أوّلاً في { عجبوا } ثم فسره ثانياً في قوله { فقال الكافرون } أو اقتصر على الضمير أوّلاً للتعليم بهم ثم وضع الظاهر موضع المضمر تسجيلاً عليهم بالكفر .  <br />
