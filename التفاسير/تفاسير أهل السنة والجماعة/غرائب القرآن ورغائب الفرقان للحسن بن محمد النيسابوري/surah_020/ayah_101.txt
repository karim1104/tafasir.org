{ خالدين فيه } أي في ذلك الوزر أو في احتماله { وساء } فيه ضمير مبهم يفسره { حملاً } والمخصوص محذوف للقرينة أي ساء حملاً وزرهم .   واللام في { لهم } للبيان كما في { هيت لك } [ يوسف :23 ] ويجوز أن يكون  "  ساء  "  بمعنى  "  قبح  "  ويكون فيه ضمير الوزر .   وانتصب { حملاً } على التمييز و { لهم } حال من { حملاً } ولا أدري لم أنكره صاحب الكشاف ،   اللَّهم إلا أن يمنع وقوع الحال من التمييز وفيه نظر .   قال ابن السكيت : الحمل بالفتح ما كان في بطن أو على رأس شجرة ،   وبالكسر ما كان على ظهر أو رأس .  <br />
