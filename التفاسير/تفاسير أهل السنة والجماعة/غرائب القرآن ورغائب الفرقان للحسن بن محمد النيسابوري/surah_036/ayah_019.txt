{ قالوا طائركم } أي سبب شؤمكم { معكم } وهو كفركم ومعاصيكم { أئن ذكرتم } يعني أتطيرون إن ذكرتم .   ومن قرأ { أين } على وزن  "  كيف  "  ذكرتم بالتخفيف فالمراد شؤمكم معكم حيث جرى ذكركم فضلاً عن المكان الذي حللتم فيه .   ثم إن الرسل كأنهم قالوا لهم أنحن كاذبون أم نحن مشؤمون { بل أنتم قوم مسرفون } في عصيانكم أو ضلالكم فمن ثم أتاكم الشؤم ،   أو تشاءمتم بمن يجب التبرك بهم وقصدتموهم بالسوء .  <br />
