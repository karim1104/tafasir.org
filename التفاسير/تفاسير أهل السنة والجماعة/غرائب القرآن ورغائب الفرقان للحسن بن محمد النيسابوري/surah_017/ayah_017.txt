ثم ذكر عادته الجارية مع القرون الخالية فقال : { وكم أهلكنا } ف { كم } مفعول { أهلكنا } و{ من القرون } بيان لكم وتمييز له أراد بهم عاداً وثمود ونحوهما .   ثم خاطب رسوله بما هو ردع للناس كافة قائلاً { وكفى بربك } الآية .   قال الفراء : إنما يجوز إدخال الباء في المرفوع إذا كان يمدح به صاحبه أو يذم كقولك  "  كفاك به  "   "  وأكرم به رجلاً  "   "  وطاب بطعامك طعاماً  "  ولا يقال : قام بأخيك وأنت تريد قام أخوك .   وفي الآية بشارة عظيمة لأهل الطاعة وإنذار شديد لغيرهم لأن العلم التام مع القدرة الكاملة والحكمة الشاملة يقتضي إيصال الجزاء إلى كل أحد بقدر استحقاقه .   ثم أكد المعاني المذكورة من قوله : { وكل إنسان ألزمناه طائره } ومن قوله : { من اهتدى فإنما يهتدي لنفسه } بقوله : { من كان يريد العاجلة } .  <br />
