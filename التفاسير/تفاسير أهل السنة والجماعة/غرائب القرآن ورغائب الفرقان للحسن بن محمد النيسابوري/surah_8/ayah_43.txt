{ إذ يريكم } منصوب باذكر أو بدل آخر من يوم الفرقان أو متعلق بعليم أي يعلم تدابيركم إذ يريكهم { في منامك } أي في رؤياك { قليلاً } أراه وإياهم في رؤياه قليلاً فأخبر بذلك أصحابه فكان تثبيتاً لهم وتشجيعاً على عدوهم .   وقيل : في منامك أي في عينك في اليقظة لأن العين موضع النوم وفيه تكلف .   { ولو أراكهم كثيراً } على ما هم عليه { لفشلتم } والفشل الجبن والخور .   { ولتنازعتم في الأمر } أمر الحرب والإقدام { ولكن الله سلم } عصم من الفشل والتنازع { إنه عليم بذات الصدور } يعلم ما سيحدث فيها من مواجب الإقدام والإحجام .  <br />
