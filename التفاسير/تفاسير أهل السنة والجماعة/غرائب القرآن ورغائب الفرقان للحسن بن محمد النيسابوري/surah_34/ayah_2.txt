ثم أكد علمه بقوله { يعلم ما يلج في الأرض } أي يدخل فيها من المياه والحبات والكنوز والأموات { وما يخرج منها } من الشجر والنبات ومياه الآبار والجواهر والمعدنيات { وما ينزل من السماء } من الأمطار والأرزاق وأنواع البركات والوحي { وما يعرج فيها } من الملائكة وأعمال العباد .   وقد أشار بقوله { فيها } دون أن يقول  "  إليها  "  إلى أن الأعمال الصالحة مقبولة والنفوس الزكية واصلة ،   قد ينتهي الشيء إلى الشيء ولا ينفذ فيه ولا تصل به { وهو الرحيم } حين الإنزال { الغفور } وقت عروج الأعمال للمفرطين في الأقوال والأفعال .  <br />
