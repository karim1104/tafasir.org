{ وقال موسى } تثبيتاً لقومه { إن كنتم آمنتم بالله } صدقتم به وبآياته { فعليه توكلوا } خصوه بتفويض أموركم إليه { إن كنتم مسلمين } قال لعلماء : المؤخر في مثل هذه السورة مقدم في المعنى نظيره : إن ضربك زيد فاضربه إن كانت بك قوة .   والمراد إن كانت بك قوة فإن ضربك زيد فاضربه فكأنه قيل لهم في حال إسلامهم إن كنتم منقادين لتكاليف ربكم بالإخلاص مصدقين له بالتحقيق عارفين بأنه واجب الوجود لذاته وما سواه محدث مخلوق مقهور تحت حكمه وتدبيره ،   ففوضوا جميع أموركم إليه وحده .  <br />
