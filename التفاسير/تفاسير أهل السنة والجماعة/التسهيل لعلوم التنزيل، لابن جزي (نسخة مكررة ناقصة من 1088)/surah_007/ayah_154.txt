{ ولما سكت عن موسى الغضب } أي : سكن وكذلك قرأ بعضهم ،   وقال الزمخشري قوله : { سكت } مثل كأن الغضب كان يقول له ألق الألواح وجر برأس أخيك ،   ثم سكت عن ذلك .  <br />
{ وفي نسختها } أي : فيما ينسخ منها ،   والنسخة فعلة بمعنى مفعول .  <br />
{ لربهم يرهبون } أي : يخافون ،   ودخلت اللام لتقدم المفعول كقوله : { للرؤيا تعبرون } [ يوسف : 43 ] ،   وقال المبرد تتعلق بمصدر تقديره رهبتهم لربهم .
