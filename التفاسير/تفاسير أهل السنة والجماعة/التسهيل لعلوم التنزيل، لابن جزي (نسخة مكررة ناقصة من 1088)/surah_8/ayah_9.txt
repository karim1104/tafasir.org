{ إذ تستغيثون ربكم } { إذ } بدل من { إذ يعدكم } ،   وقيل : يتعلق بقوله : { ليحق الحق } أو بفعل مضمر واستغاثتهم دعاؤهم بالغوث والنصر .  <br />
{ ممدكم } أي : مكثركم .  <br />
{ مردفين } من قولك ردفه إذا تبعه ،   وأردفته إياه إذا أتبعته إياه والمعنى : يتبع بعضهم بعضا ،   فمن قرأه بفتح الدال فهو اسم مفعول ،   ومن قرأه بالكسر فهو اسم فاعل ،   وصح معنى القراءتين لأن الملائكة المنزلين يتبع بعضهم بعضا فمنهم تابعون ومتبوعون .  <br />
