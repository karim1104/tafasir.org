{ أولم يهد } أي : أولم يتبين .  <br />
{ للذين يرثون الأرض } أي : يسكنوها .  <br />
{ أن لو نشاء } هو فاعل { أولم يهد } ،   ومقصود الآية الوعيد .  <br />
{ ونطبع على قلوبهم } عطف على { أصبناهم } لأنه في معنى المستقبل ،   أو منقطع على معنى الوعيد وأجاز الزمخشري أن يكون عطفا على { يرثون الأرض } أو على ما دل عليه معنى { أولم يهد } كأنه قال : يغفلون عن الهداية ونطبع على قلوبهم .  <br />
