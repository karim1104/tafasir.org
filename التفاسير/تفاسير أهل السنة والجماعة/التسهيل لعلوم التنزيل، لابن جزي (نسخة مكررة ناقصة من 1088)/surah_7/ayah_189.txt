{ من نفس واحدة } يعني : آدم .  <br />
{ زوجها } يعني حواء .  <br />
{ ليسكن إليها } يميل إليها ويستأنس بها { تغشاها } كناية عن الجماع .  <br />
{ حملت حملا خفيفا } أي : خف عليها ولم تلق منه ما يلقى بعض الحوامل من حملهن من الأذى والكرب ،   وقيل : الحمل الخفيف المني في فرجها .  <br />
{ فمرت به } قيل : معناه استمرت به إلى حين ميلاده ،   وقيل : معناه : قامت وقعدت .  <br />
{ فلما أثقلت } أي : ثقل حملها وصارت به ثقيلة .  <br />
{ لئن آتينا صالحا } أي : ولدا صالحا سالما في بدنه .  <br />
