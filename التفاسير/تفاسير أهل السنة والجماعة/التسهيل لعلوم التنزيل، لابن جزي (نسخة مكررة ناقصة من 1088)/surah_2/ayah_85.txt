{ هؤلاء } منصوب على التخصيص بفعل مضمر ،   وقيل : { هؤلاء } مبتدأ وخبره { أنتم } ،   و{ تقتلون } حالا لازمة تم بها المعنى .  <br />
{ تقتلون أنفسكم } كانت قريظة حلفاء الأوس ،   والنضير : حلفاء الخزرج ،   وكان كل فريق يقاتل الآخر مع حلفائه ،   ويتقيه من موضعه إذا ظفر به .  <br />
{ تظاهرون } أي : تتفاوتون .  <br />
{ تفادوهم } قرئ بالألف وحذفها والمعنى واحد ،   وكذلك أسارى بالألف وحذفها جمع أسير .  <br />
{ وهو محرم } الضمير للإخراج من ديارهم وهو مبتدأ وخبره محرم .   { وإخراجهم } بدل والضمير للأمر والشأن ،   وإخراجهم : مبتدأ ،   ومحرم خبره ،   والجملة خبر الضمير .  <br />
{ أفتؤمنون ببعض الكتاب } فداؤهم الأسارى موافقة لما في كتبهم .  <br />
{ وتكفرون ببعض } القتل والإخراج من الديار مخالفة لما في كتبهم .  <br />
{ خزي } الجزية أو الهزيمة لقريظة والنضير وغيرهم ،   أو مطلق .  <br />
