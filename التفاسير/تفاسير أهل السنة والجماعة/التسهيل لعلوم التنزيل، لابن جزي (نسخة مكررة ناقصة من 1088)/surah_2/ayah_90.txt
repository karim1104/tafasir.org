{ بئسما } فاعل { بئس } مضمر و{ ما } مفسرة له و{ إن يكفروا } هو المذموم وقال الفراء :{ بئسما } مركب كحبك وقال الكاسي :{ ما } مصدرية : أي اشتراكهم فهي فاعله .  <br />
{ اشتروا } هنا بمعنى باعوا .  <br />
{ أن يكفروا } في موضع خبر ابتداء أو مبتدأ كاسم المذموم في { بئس } أو مفعول من أجله أو بدل من الضمير في { به } .  <br />
{ بما أنزل الله } القرآن أو التوراة لأنهم كفروا بما فيها من ذكر محمد صلى الله عليه وسلم .  <br />
{ أن ينزل } في موضع مفعول من أجله .  <br />
{ من فضله } القرآن والرسالة .  <br />
{ من يشاء } يعني محمد صلى الله عليه وسلم ،   والمعنى أنهم إنما كفروا حسدا لمحمد صلى الله عليه وآله وسلم لما تفضل الله عليه بالرسالة .  <br />
