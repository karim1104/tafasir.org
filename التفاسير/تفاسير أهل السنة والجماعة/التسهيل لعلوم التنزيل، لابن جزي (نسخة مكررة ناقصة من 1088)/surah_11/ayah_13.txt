{ أم يقولون افتراه } ،   { أم } هنا منقطعة بمعنى : بل والهمزة والضمير في { افتراه } لما يوحى إليه .  <br />
{ قل فأتوا بعشر سور مثله } تحداهم أولا بعشر سور فلما بان عجزهم تحداهم بسورة واحدة فقال : فأتوا بسورة من مثله ،   والمماثلة المطلوبة في فصاحته وعلومه .  <br />
{ مفتريات } صفة لعشر سور ،   وذلك مقابلة لقولهم : { افتراه } وليست المماثلة في الافتراء .  <br />
{ وادعوا من استطعتم } أي : استعينوا بمن شئتم .  <br />
