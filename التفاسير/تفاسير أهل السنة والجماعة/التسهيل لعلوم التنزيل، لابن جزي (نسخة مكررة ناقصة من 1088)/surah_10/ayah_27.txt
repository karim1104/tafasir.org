{ والذين كسبوا السيئات } مبتدأ على حذف مضاف تقديره جزاء { الذين كسبوا السيئات جزاء سيئة بمثلها } أو على تقدير لهم { جزاء سيئة بمثلها } ،   أو معطوفا على { الذين أحسنوا } ويكون .  <br />
{ جزاء سيئة } مبتدأ وخبره بمثلها .  <br />
{ ما لهم من الله من عاصم } أي : لا يعصمهم أحد من عذاب الله .  <br />
{ قطعا من الليل مظلما } من قرأ بفتح الطاء فهو جمع قطعة وإعراب مظلما على هذه القراءة : حال من الليل ،   ومن قرأ { قطعا } بإسكان الطاء ،   ف{ مظلما } صفة له أو حال من { الليل } .  <br />
