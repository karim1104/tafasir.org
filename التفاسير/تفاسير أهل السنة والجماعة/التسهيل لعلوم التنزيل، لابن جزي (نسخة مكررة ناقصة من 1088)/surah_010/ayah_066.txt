{ وما يتبع الذين يدعون من دون الله شركاء إن يتبعون إلا الظن } فيها وجهان :<br />
أحدهما : أن تكون { ما } نافية وأوجبت بقوله : { إلا الظن } وكرر { إن يتبعون } توكيدا ،   والمعنى : ما يتبع الكفار إلا الظن .  <br />
والوجه الثاني : أن تكون ما استفهامية ،   ويتم الكلام عند قوله : { شركاء } ،   والمعنى أي : شيء يتبعون على وجه التحقير لما يتبعونه ،   ثم ابتدأ الإخبار بقوله ،   { إن يتبعون إلا الظن } والعامل في { شركاء } على الوجهين يدعون .  <br />
