{ حتى إذا فتحت يأجوج ومأجوج } حتى هنا حرف ابتداء أو غاية متعلقة بيرجعون ،   وجواب { إذا } : { فإذا هي شاخصة } ،   وقيل : الجواب { يا ويلنا } لأن تقديره يقولون : يا ويلنا ،   وفتحت يأجوج ومأجوج أي : فتح سدها فحذف المضاف { وهم من كل حدب ينسلون } الحدب المرتفع من الأرض ،   وينسلون أي : يسرعون ،   والضمير ل{ يأجوج ومأجوج } أي : يخرجون من كل طريق لكثرتهم ،   وقيل لجميع الناس .  <br />
