{ كطي السجل للكتب } السجل الصحيفة والكتاب مصدر أي : كما يطوى السجل ليكتب فيه ،   أو ليصان الكتاب الذي فيه ،   وقيل : السجل رجل كاتب وهذا ضعيف ،   وقيل : هو ملك في السماء الثانية ترفع إليه الأعمال ،   وهذا أيضا ضعيف .  <br />
{ كما بدأنا أول خلق نعيده } أي : كما قدرنا على البداءة نقدر على الإعادة ،   فهو كقوله : { قل يحييها الذي أنشأها أول مرة } [ يس :79 ] وقيل : المعنى نعيدهم على الصورة التي بدأناهم كما جاء في الحديث : ( يحشر الناس يوم القيامة حفاة عراة غرلا ،   ثم قرأ : { كما بدأنا أول خلق نعيده } ) ،   والكاف متعلقة بقوله : { نعيده } .  <br />
{ فاعلين } تأكيدا لوقوع البعث .
