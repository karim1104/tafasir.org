{ قل للمخلفين من الأعراب ستدعون إلى قوم أولي بأس شديد تقاتلونهم أو يسلمون فإن تطيعوا يؤتكم الله أجرا حسنا وإن تتولوا كما توليتم من قبل يعذبكم عذابا أليما }<br />
{ قل للمخلفين من الأعراب } المذكورين اختباراً  { ستدعوْن إلى قوم أولي } أصحاب  { بأس شديد } قيل هم بنو حنيفة أصحاب اليمامة ،   وقيل فارس والروم  { تقاتلونهم } حال مقدرة هي المدعو إليها في المعنى  { أو } هم  { يسلمون } فلا تقاتلون  { فإن تطيعوا } إلى قتالهم  { يؤتكم الله أجراً حسناً وإن تتولوا كما توليتم من قبل يعذّبكم عذاباً أليماً } مؤلماً  .  <br />
