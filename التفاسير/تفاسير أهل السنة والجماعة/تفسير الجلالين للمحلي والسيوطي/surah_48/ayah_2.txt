{ ليغفر لك الله ما تقدم من ذنبك وما تأخر ويتم نعمته عليك ويهديك صراطا مستقيما }<br />
{ ليغفر لك الله } بجهادك  { ما تقدم من ذنبك وما تأخر } منه لترغب أمتك في الجهاد وهو مؤول لعصمة الأنبياء عليهم الصلاة والسلام بالدليل العقلي القاطع من الذنوب واللام للعلة الفائية فمدخولها مسبب لا سبب  { ويتم } بالفتح المذكور  { نعمته } إنعامه  { عليك ويهديك } به  { صراطاً } طريقاً  { مستقيماً } يثبتك عليه وهو دين الإسلام  .  <br />
