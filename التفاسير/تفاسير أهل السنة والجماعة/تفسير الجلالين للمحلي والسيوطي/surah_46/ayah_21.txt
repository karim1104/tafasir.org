{ واذكر أخا عاد إذ أنذر قومه بالأحقاف وقد خلت النذر من بين يديه ومن خلفه ألا تعبدوا إلا الله إني أخاف عليكم عذاب يوم عظيم }<br />
{ واذكر أخا عادِ } هو هود عليه السلام  { إذ } الخ بدل اشتمال  { أنذر قومه } خوَّفهم  { بالأحقاف } وادِ باليمن به منازلهم  { وقد خلت النذر } مضت الرسل  { من بين يديه ومن خلفه } أي من قبل هود ومن بعده إلى أقوامهم  { أن } ،   أي بأن قال  { لا تعبدوا إلا الله } وجملة وقد خلت معترضة  { إني أخاف عليكم } إن عبدتم غير الله  { عذاب يوم عظيم }  .  <br />
