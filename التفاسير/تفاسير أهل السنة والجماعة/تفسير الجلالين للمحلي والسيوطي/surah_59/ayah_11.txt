{ ألم تر إلى الذين نافقوا يقولون لإخوانهم الذين كفروا من أهل الكتاب لئن أخرجتم لنخرجن معكم ولا نطيع فيكم أحدا أبدا وإن قوتلتم لننصرنكم والله يشهد إنهم لكاذبون } .  <br />
{ ألم ترْ } تنظر  { إلى الذين نافقوا يقولون لإخوانهم الذين كفروا من أهل الكتاب } وهم بنو النضير وإخوانهم في الكفر  { لئن } لام قسم في الأربعة  { أخرجتم } من المدينة  { لنخرجن معكم ولا نطيع فيكم } في خذلانكم  { أحداً أبداً وإن قوتلتم } حذفت منه اللام الموطئة  { لننصرنكم والله يشهد إنهم لكاذبون }  .  <br />
