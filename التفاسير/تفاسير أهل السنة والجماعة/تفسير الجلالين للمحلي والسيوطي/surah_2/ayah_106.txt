{ ما ننسخ من آية أو ننسها نأت بخير منها أو مثلها ألم تعلم أن الله على كل شيء قدير } .  <br />
ولما طمع الكفار في النسخ وقالوا إن محمدا يأمر أصحابه اليوم بأمر وينهى عنه غدا نزل : { ما  } شرطية { نَنَسخ من آية  } نزل حكمها : إما مع لفظها أو لا .   وفي قراءة بضم النون من أنسخ : أي نأمرك أو جبريل بنسخها { أو نَنْسأها  } نؤخرها فلا ننزل حكمها ونرفع تلاوتها أو نؤخرها في اللوح المحفوظ وفي قراءة بلا همز في النسيان { نُنْسِها  } :  أي ننسكها  ،   أي نمحها من قلبك وجواب الشرط { نأت بخير منها } أنفع للعباد في السهولة أو كثرة الأجر { أو مثلها } في التكليف والثواب { ألم تعلم أن الله على كل شيء قدير } ومنه النسخ والتبديل  ،   والاستفهام للتقرير .  <br />
