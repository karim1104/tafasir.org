{ تلك أمة قد خلت لها ما كسبت ولكم ما كسبتم ولا تسألون عما كانوا يعملون } .  <br />
{ تلك } مبتدأ والإشارة إلى إبراهيم ويعقوب وبنيهما وأُنِّث لتأنيث خبره { أمة قد خلت }سلفت { لها ما كسبت } من العمل أي جزاؤه استئناف { ولكم } الخطاب لليهود { ما كسبتم ولا تسألون عما كانوا يعملون } كما لا يسألون عن عملكم والجملة تأكيد لما قبلها .  <br />
