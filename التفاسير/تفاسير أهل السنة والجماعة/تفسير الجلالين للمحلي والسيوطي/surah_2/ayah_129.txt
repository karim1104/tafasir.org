{ ربنا وابعث فيهم رسولا منهم يتلو عليهم آياتك ويعلمهم الكتاب والحكمة ويزكيهم إنك أنت العزيز الحكيم } .  <br />
{ ربنا وابعث فيهم } أي أهل البيت { رسولاً منهم } من أنفسهم  ،   وقد أجاب الله دعاءه بمحمد صلى الله عليه وسلم { يتلو عليهم آياتك } القرآن { ويعلمهم الكتاب } القرآن { والحكمة } أي ما فيه من الأحكام { ويزكيهم } يطهرهم من الشرك { إنك أنت العزيز } الغالب { الحكيم } في صنعه .  <br />
