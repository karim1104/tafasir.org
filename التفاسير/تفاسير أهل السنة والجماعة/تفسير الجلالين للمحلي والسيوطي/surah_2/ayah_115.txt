{ ولله المشرق والمغرب فأينما تولوا فثم وجه الله إن الله واسع عليم } .  <br />
ونزل لما طعن اليهود في نسخ القبلة أو في صلاة النافلة على الراحلة في السفر حيثما توجهت { ولله المشرق والمغرب } أي الأرض كلها لأنهما ناحيتاها { فأين ما تولوا } وجوهكم في الصلاة بأمره { فثم } هناك { وجه الله } قبلته التي رضيها { إن الله واسع } يسع فضله كل شيء { عليم } بتدبير خلقه .  <br />
