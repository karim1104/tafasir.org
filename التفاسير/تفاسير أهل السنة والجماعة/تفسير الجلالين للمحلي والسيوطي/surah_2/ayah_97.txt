{ قل من كان عدوا لجبريل فإنه نزله على قلبك بإذن الله مصدقا لما بين يديه وهدى وبشرى للمؤمنين } .  <br />
وسأل ابن صوريا النبيَّ أو عمرَ عمَّن يأتي بالوحي من الملائكة فقال جبريل فقال هو عدونا يأتي بالعذاب ولو كان ميكائيل لآمنا لأنه يأتي بالخصب والسلم فنزل :<br />
{ قل } لهم { من كان عدوا لجبريل } فليمت غيظا { فإنه نزله } أي القرآن { على قلبك بإذن } بأمر { الله مصدقا لما بين يديه } قبله من الكتب <br />
{ وهدى } من الضلالة { وبشرى } بالجنة { للمؤمنين } .  <br />
