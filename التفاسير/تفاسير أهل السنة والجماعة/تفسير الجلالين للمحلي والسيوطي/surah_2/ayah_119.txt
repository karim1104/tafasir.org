{ إنا أرسلناك بالحق بشيرا ونذيرا ولا تسأل عن أصحاب الجحيم } .  <br />
{ إنا أرسلناك } يا محمد { بالحق } بالهدى { بشيراً } من أجاب إليه بالجنة { ونذيراً } من لم يجب إليه بالنار { ولا تُسْأَلُ عن أصحاب الجحيم } النار ،   أي الكفار ما لهم لم يؤمنوا إنما عليك البلاغ  ،   وفي قراءة بجزم تسألْ نهياً .  <br />
