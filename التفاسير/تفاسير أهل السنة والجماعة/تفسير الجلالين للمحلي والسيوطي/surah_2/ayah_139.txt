{ قل أتحآجوننا في الله وهو ربنا وربكم ولنا أعمالنا ولكم أعمالكم ونحن له مخلصون } .  <br />
{ قل } لهم { أتحاجُّوننا } تخاصمونا { في الله } أن اصطفى نبيا من العرب { وهو ربنا وربكم } فله أن يصطفي من يشاء { ولنا أعمالنا } نجازى بها { ولكم أعمالكم } تجازون بها فلا يبعد أن يكون في أعمالنا ما نستحق به الإكرام { ونحن له مخلصون } الدين والعمل دونكم فنحن أولى بالإصطفاء والهمزة للإنكار والجمل الثلاث أحوال .  <br />
