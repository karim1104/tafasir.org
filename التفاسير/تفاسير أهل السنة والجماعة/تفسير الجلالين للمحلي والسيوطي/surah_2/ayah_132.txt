{ ووصى بها إبراهيم بنيه ويعقوب يا بني إن الله اصطفى لكم الدين فلا تموتن إلا وأنتم مسلمون } .  <br />
{ ووصَّى } وفي قراءة أوصى { بها } بالملة { إبراهيمُ بنيه ويعقوبُ } بنيه قال : { يا بني إن الله اصطفى لكم الدين } دين الإسلام { فلا تموتن إلا وأنتم مسلمون } نهى عن ترك الإسلام وأمر بالثبات عليه إلى مصادفة الموت .  <br />
