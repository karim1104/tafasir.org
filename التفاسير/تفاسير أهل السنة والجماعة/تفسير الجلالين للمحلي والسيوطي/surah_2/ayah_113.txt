{ وقالت اليهود ليست النصارى على شيء وقالت النصارى ليست اليهود على شيء وهم يتلون الكتاب كذلك قال الذين لا يعلمون مثل قولهم فالله يحكم بينهم يوم القيامة فيما كانوا فيه يختلفون } .  <br />
{ وقالت اليهود ليست النصارى على شيء } مُعْتدٍّ به وكفرت بعيسى { وقالت النصارى ليست اليهود على شيء } معتد به وكفرت بموسى<br />
 { وهم } أي الفريقان { يتلون الكتاب } المنزل عليهم  ،   وفي كتاب اليهود تصديق عيسى  ،   وفي كتاب النصارى تصديق موسى والجملة حال <br />
{ كذلك } كما قال هؤلاء { قال الذين لا يعلمون } أي المشركون من العرب وغيرهم { مثل قولهم } بيان لمعنى ذلك : أي قالوا لكل ذي دين ليسوا على شيء { فالله يحكم بينهم يوم القيامة فيما كانوا فيه يختلفون } من أمر الدين فيُدخِل المحقَّ الجنةَ والمبطل النار .  <br />
