{ وإما ينزغنك من الشيطان نزغ فاستعذ بالله إنه هو السميع العليم }<br />
{ وإما } فيه إدغام نون إن الشرطية في ما الزائدة  { ينزغنك من الشيطان نزغ } أي يصرفك عن الخصلة وغيرها من الخير صارف  { فاستعذ بالله } جواب الشرط وجواب الأمر محذوف ،   أي يدفعه عنك  { إنه هو السميع } للقول  { العليم } بالفعل  .  <br />
