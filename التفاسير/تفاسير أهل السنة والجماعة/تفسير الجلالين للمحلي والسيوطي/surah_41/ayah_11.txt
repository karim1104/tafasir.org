{ ثم استوى إلى السماء وهي دخان فقال لها وللأرض ائتيا طوعا أو كرها قالتا أتينا طائعين }<br />
{ ثم استوى } قصد  { إلى السماء وهي دخان } بخار مرتفع  { فقال لها وللأرض ائتيا } إلى مرادي منكما  { طوعاً أو كرهاً } في موضع الحال ،   أي طائعتين أو مكرهتين  { قالتا أتينا } بمن فينا  { طائعين } فيه تغليب المذكر العاقل أو نزلتا لخاطبهما منزلته  .  <br />
