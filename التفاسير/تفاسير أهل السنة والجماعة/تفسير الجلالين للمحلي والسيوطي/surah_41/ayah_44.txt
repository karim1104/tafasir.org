{ ولو جعلناه قرآنا أعجميا لقالوا لولا فصلت آياته أأعجمي وعربي قل هو للذين آمنوا هدى وشفاء والذين لا يؤمنون في آذانهم وقر وهو عليهم عمى أولئك ينادون من مكان بعيد }<br />
{ ولو جعلناه } أي الذكر  { قراناً أعجمياً لقالوا لولا } هلا  { فصلت } بينت  { آياته } حتى نفهمها  { أ } قرآن  { أعجمي و } نبي  { عربي } استفهام إنكار منهم بتحقيق الهمزة الثانية وقلبها ألف بإشباع ودونه  { قل هو للذين آمنوا هدىّ } من الضلالة  { وشفاءٌ } من الجهل  { والذين لا يؤمنون في آذانهم وقر } ثقل فلا يسمعونه  { وهو عليهم عمىً } فلا يفهمونه  { أولئك ينادون من مكان بعيد } أي هم كالمنادى من مكان بعيد لا يسمع ولا يفهم ما ينادى به  .  <br />
