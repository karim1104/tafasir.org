{ وقالوا أئذا ضللنا في الأرض أئنا لفي خلق جديد بل هم بلقاء ربهم كافرون }<br />
{ وقالوا } أي منكرو البعث  { أئذا ضللنا في الأرض } غبنا فيها ،   بأن صرنا تراباً مختلطاً بترابها  { أئنا لفي خلق جديد } استفهام إنكار بتحقيق الهمزتين وتسهيل الثانية وإدخال ألف بينهما على الوجهين في الموضعين ،   قال تعالى :  { بل هم بلقاء ربهم } بالبعث  { كافرون }  .  <br />
