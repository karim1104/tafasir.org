{ فاطر السماوات والأرض جعل لكم من أنفسكم أزواجا ومن الأنعام أزواجا يذرؤكم فيه ليس كمثله شيء وهو السميع البصير }<br />
{ فاطر السماوات والأرض } مبدعهما  { جعل لكم من أنفسكم أزواجاً } حيث خلق حواء من ضلع آدم  { ومن الأنعام أزواجاً } ذكوراً وإناثاً  { يذرؤكم } بالمعجمة يخلقكم  { فيه في الجعل المذكور ،   أي يكثركم بسببه بالتوالد والضمير للأناسي والأنعام بالتغليب  { ليس كمثله شيء } الكاف زائدة لأنه تعالى لا مثل له  { وهو السميع } لما يقال  { البصير } لما يفعل  .  <br />
