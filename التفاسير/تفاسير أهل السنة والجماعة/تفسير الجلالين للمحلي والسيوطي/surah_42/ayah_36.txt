{ فما أوتيتم من شيء فمتاع الحياة الدنيا وما عند الله خير وأبقى للذين آمنوا وعلى ربهم يتوكلون }<br />
{ فما أوتيتم } خطاب للمؤمنين وغيرهم  { من شيءٍ } من أثاث الدنيا  { فمتاع الحياة الدنيا } يتمتع به فيها ثم يزول  { وما عند الله } من الثواب  { خير وأبقى للذين آمنوا وعلى ربهم يتوكلون } ويعطف عليه  .  <br />
