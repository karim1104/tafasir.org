{ وكذلك أوحينا إليك روحا من أمرنا ما كنت تدري ما الكتاب ولا الإيمان ولكن جعلناه نورا نهدي به من نشاء من عبادنا وإنك لتهدي إلى صراط مستقيم }<br />
{ وكذلك } أي مثل إيحائنا إلى غيرك من الرسل  { أو حينا إليك } يا محمد  { روحاً } هو القرآن به تحيا القلوب  { من أمرنا } الذي نوحيه إليك  { ما كنت تدري } تعرف قبل الوحي إليك  { ما الكتاب } القرآن  { ولا الإيمان } أي شرائعه ومعالمه والنفي معلق للفعل عن العمل وما بعده سد مسد المفعولين  { ولكن جعلناه } أي الروح أو الكتاب  { نوراً نهدي به من نشاء من عبادنا وإنك لتهدي } تدعو بالوحي إليك  { إلى صراط } طريق  { مستقيم } دين الإسلام  .  <br />
