{ ولو بسط الله الرزق لعباده لبغوا في الأرض ولكن ينزل بقدر ما يشاء إنه بعباده خبير بصير }<br />
{ ولو بسط الله الرزق لعباده } جميعهم  { لبغوا } جميعهم أي طغوا  { في الأرض ولكن ينزل } بالتخفيف وضده من الأرزاق  { بقد ما يشاء } فيبسطها لبعض عباده دون ،   وينشأ عن البسط البغي  { إنه بعباده خبير بصير }  .  <br />
