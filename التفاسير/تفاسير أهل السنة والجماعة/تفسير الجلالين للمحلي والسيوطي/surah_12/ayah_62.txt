وقال لفتيانه اجعلوا بضاعتهم في رحالهم لعلهم يعرفونها إذا انقلبوا إلى أهلهم لعلهم يرجعون<br />
{ وقال لفتيته } وفي قراءة  " لفتيانه  "  غلمانه { اجعلوا بضاعتهم } التي أتوا بها ثمن الميرة وكانت دراهم { في رحالهم } أوعيتهم { لعلهم يعرفونها إذا انقلبوا إلى أهلهم } وفرغوا أوعيتهم { لعلهم يرجعون }إلينا لأنهم لا يستحلون إمساكها .  <br />
