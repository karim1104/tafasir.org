{ رسولا يتلو عليكم آيات الله مبينات ليخرج الذين آمنوا وعملوا الصالحات من الظلمات إلى النور ومن يؤمن بالله ويعمل صالحا يدخله جنات تجري من تحتها الأنهار خالدين فيها أبدا قد أحسن الله له رزقا }<br />
{ رسولاً } أي محمداً منصوب بفعل مقدر ،   أي وأرسل  { يتلو عليكم آيات الله مبيَّنات } بفتح الياء وكسرها كما تقدم  { ليخرج الذين آمنوا وعملوا الصالحات } بعد مجيء الذكر والرسول  { من الظلمات } الكفر الذي كانوا عليه  { إلى النور } الإيمان الذي قام بهم بعد الكفر } ومن يؤمن بالله ويعمل صالحاً يدخله } وفي قراءة بالنون  { جنات تجري من تحتها الأنهار خالدين فيها أبداً قد أحسن الله له رزقاً } هو رزق الجنة التي لا ينقطع نعيمها  .  <br />
