{ يا أيها النبي إذا طلقتم النساء فطلقوهن لعدتهن وأحصوا العدة واتقوا الله ربكم لا تخرجوهن من بيوتهن ولا يخرجن إلا أن يأتين بفاحشة مبينة وتلك حدود الله ومن يتعد حدود الله فقد ظلم نفسه لا تدري لعل الله يحدث بعد ذلك أمرا }<br />
{ يا أيها النبي } المراد أمته بقرينه ما بعده أو قل لهم  { إذا طلقتم النساء } أي أردتم الطلاق  { فطلقوهن لعدتهن } لأولها بأن يكون الطلاق في طهر لم تمس فيه لتفسيره بذلك ،   رواه الشيخان  { وأحصوا العدة } احفظوها لتراجعوا قبل فراغها  { واتقوا الله ربكم } أطيعوه في أمره ونهيه  { لا تخرجوهن من بيوتهن ولا يخرجن } منها حتى تنقضي عدتهن  { إلا إن يأتين بفاحشة } زنا  { مبيَّنة } بفتح الياء وكسرها ،   بينت أو بينة فيخرجن لإقامة الحد عليهن  { وتلك } المذكورات  { حدود الله ومن يتعدَّ حدود الله فقد ظلم نفسه لا تدري لعل الله يحدث بعد ذلك } الطلاق  { أمراً } مراجعة فيما إذا كان واحدة أو اثنتين .  <br />
