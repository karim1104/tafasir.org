{ وكأين من قرية عتت عن أمر ربها ورسله فحاسبناها حسابا شديدا وعذبناها عذابا نكرا }<br />
{ وكأين } هي كاف الجر دخلت على أي بمعنى كم  { من قرية } أي وكثير من القرى  { عتت } عصت يعني أهلها  { عن أمر ربها ورسله فحاسبناها } في الآخرة وإن لم تجيء لتحقيق وقوعها  { حساباً شديداً وعذبناها عذاباً نكراً } بسكون الكاف وضمها فظيعاً وهو عذاب النار  .  <br />
