{ من دون الله قالوا ضلوا عنا بل لم نكن ندعوا من قبل شيئا كذلك يضل الله الكافرين }<br />
{ من دون الله } معه وهي الأصنام  { قالوا ضلوا } غابوا  { عنا } فلا نراهم  { بل لم نكن تدعوا من قبل شيئاً } أنكروا عبادتهم إياها ثم أحضرت قال تعالى : ( إنكم وما تعبدون من دون الله حصب جهنم ) أي وقودها  { كذلك } أي مثل إضلال هؤلاء المكذبين  { يضل الله الكافرين }  .  <br />
