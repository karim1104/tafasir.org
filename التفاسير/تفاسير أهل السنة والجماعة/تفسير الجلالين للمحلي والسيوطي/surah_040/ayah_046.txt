{ النار يعرضون عليها غدوا وعشيا ويوم تقوم الساعة أدخلوا آل فرعون أشد العذاب }<br />
ثم ( النار يعرضون عليها ) يحرقون بها  { غدواً وعشياً } صباحاً ومساءً  { ويوم تقوم الساعة } يقال  { أُدخلُوا } يا  { آل فرعون } وفي قراءة : بفتح الهمزة وكسر الخاء أمر للملائكة  { أشد العذاب } عذاب جهنم  .  <br />
