{ الذين يحملون العرش ومن حوله يسبحون بحمد ربهم ويؤمنون به ويستغفرون للذين آمنوا ربنا وسعت كل شيء رحمة وعلما فاغفر للذين تابوا واتبعوا سبيلك وقهم عذاب الجحيم }<br />
{ الذين يحملون العرش } مبتدأ  { ومن حوله } ملابسين للحمد ،   أي يقولون : سبحان الله يصدقون عطف عليه  { يسبحون } خبره  { بحمد ربهم وبحمده ويؤمنون به } تعالى ببصائرهم أي بوحدانيته  { ويستغفرون للذين آمنوا } يقولون  { ربنا وسعت كل شيءٍ رحمة وعلماً } أي وسعت رحمتك كلَّ شيء وعلمك كل شيء  { فاغفر للذين تابوا } من الشرك  { واتبعوا سبيلك } دين الإسلام  { وقهم عذاب الجحيم } النار  .  <br />
