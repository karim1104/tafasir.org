{ كذبت قبلهم قوم نوح والأحزاب من بعدهم وهمت كل أمة برسولهم ليأخذوه وجادلوا بالباطل ليدحضوا به الحق فأخذتهم فكيف كان عقاب }<br />
{ كذبت قبلهم قوم نوح والأحزاب } كعاد وثمود وغيرهما  { من بعدهم وهمت كل أمة برسولهم ليأخذوه } يقتلوه  { وجادلوا بالباطل ليدحضوا } يزيلوا  { به الحق فأخذتهم } بالعقاب  { فكيف كان عقاب } لهم ،   أي هو واقع موقعه  .  <br />
