{ فاصبر إن وعد الله حق فإما نرينك بعض الذي نعدهم أو نتوفينك فإلينا يرجعون }<br />
{ فاصبر إن وعد الله } بعذابهم  { حق فإما نرينَّك } فيه إن الشرطية مدغمة وما زائدة تؤكد معنى الشرط أول الفعل والنون تؤكد آخره  { بعض الذي نعدهم } به من العذاب في حياتك وجواب الشرط محذوف ،   أي فذاك  { أو نتوفينك } أي قبل تعذيبهم  { فإلينا يرجعون } فنعذبهم أشد العذاب فالجواب المذكور للمعطوف فقط  .  <br />
