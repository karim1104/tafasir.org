{ إن الذين يجادلون في آيات الله بغير سلطان أتاهم إن في صدورهم إلا كبر ما هم ببالغيه فاستعذ بالله إنه هو السميع البصير }<br />
{ إن الذين يجادلون في آيات الله } القرآن  { بغير سلطان } برهان  { أتاهم إن } ما  { في صدورهم إلا كبْر } تكبّر وطمع أن يعلوا عليك  { ما هم ببالغيه فاستعذ } من شرِّهم  { بالله إنه هو السميع } لأقوالهم  { البصير } بأحوالهم ،   ونزل في منكري البعث  .  <br />
