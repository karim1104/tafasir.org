{ ولو ترى إذ المجرمون ناكسوا رؤوسهم عند ربهم ربنا أبصرنا وسمعنا فارجعنا نعمل صالحا إنا موقنون }<br />
{ ولو ترى إذ المجرمون } الكافرون  { ناكسوا رؤوسهم عند ربهم } مطأطئوها حياءً يقولون  { ربنا أبصرنا } ما أنكرنا من البعث  { وسمعنا } منك تصديق الرسل فيما كذبناهم فيه  { فارجعنا } إلى الدنيا  { نعمل صالحاً } فيها  { إنا موقنون } الآن فما نفعهم ذلك ولا يرجعون ،   وجواب لو : لرأيت أمراً فظيعاً<br />
