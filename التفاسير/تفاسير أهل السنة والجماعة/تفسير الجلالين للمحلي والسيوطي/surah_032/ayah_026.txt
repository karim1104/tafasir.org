{ أو لم يهد لهم كم أهلكنا من قبلهم من القرون يمشون في مساكنهم إن في ذلك لآيات أفلا يسمعون }<br />
{ أو لم يهدِ لهم كم أهلكنا من قبلهم } أي يتبيَّن لكفار مكة إهلاكنا كثيراً  { من القرون } الأمم بكفرهم  { يمشون } حال من ضمير لهم  { في مساكنهم } في أسفارهم إلى الشام وغيرها فيعتبروا  { إن في ذلك لآيات } دلالات على قدرتنا  { أفلا يسمعون } سماع تدبر واتعاظ .  <br />
