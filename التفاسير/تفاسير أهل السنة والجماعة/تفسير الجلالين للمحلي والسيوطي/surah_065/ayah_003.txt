{ ويرزقه من حيث لا يحتسب ومن يتوكل على الله فهو حسبه إن الله بالغ أمره قد جعل الله لكل شيء قدرا }<br />
{ ويرزقه من حيث لا يحتسب } يخطر بباله  { ومن يتوكل على الله } في أموره  { فهو حسبه } كافية  { إن الله بالغٌ أمرَه } مراده وفي قراءة بالإضافة  { قد جعل الله لكل شيء } كرخاء وشدة  { قدراً } ميقاتاً .  <br />
