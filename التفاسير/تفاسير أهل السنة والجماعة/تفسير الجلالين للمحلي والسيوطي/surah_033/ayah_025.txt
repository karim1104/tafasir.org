{ ورد الله الذين كفروا بغيظهم لم ينالوا خيرا وكفى الله المؤمنين القتال وكان الله قويا عزيزا }<br />
{ وردَّ الله الذين كفروا } أي الأحزاب  { بغيظهم لم ينالوا خيراً } مرادهم من الظفر بالمؤمنين  { وكفى الله المؤمنين القتال } بالريح والملائكة  { وكان الله قوياً } على إيجاد ما يريده  { عزيزاً } غالباً على أمره .  <br />
