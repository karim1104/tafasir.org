{ لقد كان لكم فيهم أسوة حسنة لمن كان يرجو الله واليوم الآخر ومن يتول فإن الله هو الغني الحميد } .  <br />
{ لقد كان لكم } يا أمة محمد جواب قسم مقدر  ،   { فيهم أسوة حسنة لمن كان } بدل اشتمال من كم بإعادة الجار   ،  { يرجوا الله واليوم الآخر } أي يخافهما أو يظن الثواب والعقاب ،    { ومن يتول } بأن يوالي الكفار  { فإن الله هو الغني } عن خلقه  { الحميد } لأهل طاعته  .  <br />
