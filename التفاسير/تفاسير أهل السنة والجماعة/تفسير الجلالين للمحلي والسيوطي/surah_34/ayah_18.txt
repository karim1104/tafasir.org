{ وجعلنا بينهم وبين القرى التي باركنا فيها قرى ظاهرة وقدرنا فيها السير سيروا فيها ليالي وأياما آمنين }<br />
{ وجعلنا بينهم } بين سبأ ،   وهم باليمن  { وبين القرى التي باركنا فيها } بالماء والشجر وهي قرى الشام التي يسيرون إليها للتجارة  { قرى ظاهرة } متواصلة من اليمن إلى الشام  { وقدرنا فيها السير } بحيث يقيلون في واحدة ويبيتون في أخرى إلى انتهاء سفرهم ولا يحتاجون فيه إلى حمل زاد وماء أي وقلنا  { سيروا فيها ليالي وأياماً آمنين } لا تخافون في ليل ولا في نهار  .  <br />
