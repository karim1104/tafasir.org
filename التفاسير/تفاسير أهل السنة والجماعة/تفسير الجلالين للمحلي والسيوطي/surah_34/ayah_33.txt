{ وقال الذين استضعفوا للذين استكبروا بل مكر الليل والنهار إذ تأمروننا أن نكفر بالله ونجعل له أندادا وأسروا الندامة لما رأوا العذاب وجعلنا الأغلال في أعناق الذين كفروا هل يجزون إلا ما كانوا يعملون }<br />
{ وقال الذين استضعفوا للذين استكبروا بل مكر الليل والنهار } أي مكر فيهما منكم بنا  { إذ تأمروننا أن نكفر بالله ونجعل له أنداداً } شركاء  { وأسرُّوا } أي الفريقان  { الندامة } على ترك الإيمان به  { لما رأوا العذاب } أي أخفاها كل عن رفيقه مخافة التعبير  { وجعلنا الأغلال في أعناق الذين كفروا } في النار  { هل } ما  { يجزون إلا } جزاء  { ما كانوا يعملون } في الدنيا  .  <br />
