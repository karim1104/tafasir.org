{ وقال الذين كفروا لن نؤمن بهذا القرآن ولا بالذي بين يديه ولو ترى إذ الظالمون موقوفون عند ربهم يرجع بعضهم إلى بعض القول يقول الذين استضعفوا للذين استكبروا لولا أنتم لكنا مؤمنين }<br />
{ وقال الذين كفروا } من أهل مكة  { لن نؤمن بهذا القرآن ولا بالذي بين يديه } أي تقدمه كالتوراة والإنجيل الدالين على البعث لإنكارهم له قال تعالى فيهم  { ولو ترى } يا محمد  { إذ الظالمون } الكافرين  { موقوفون عند ربهم يرجع بعضهم إلى بعض القول يقول الذين استضعفوا } الاتباع  { للذين استكبروا } الرؤساء  { لولا أنتم } صددتمونا عن الإيمان  { لكنا مؤمنين } بالنبي  .  <br />
