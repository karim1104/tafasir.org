{ ليعلم أن قد أبلغوا رسالات ربهم وأحاط بما لديهم وأحصى كل شيء عددا }<br />
{ ليعلم } الله علم ظهور  { أن } مخففة من الثقيلة أي أنه  { قد أبلغوا } أي الرسل  { رسالات ربهم } روعي بجمع الضمير معنى من  { وأحاط بما لديهم } عطف على مقدر ،   أي فعلم ذلك  { وأحصى كل شيء عدداً } تمييز وهو محول من المفعول والأصل أحصى عدد كل شيء .  <br />
