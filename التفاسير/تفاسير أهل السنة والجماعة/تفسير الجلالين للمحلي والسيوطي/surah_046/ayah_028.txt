{ فلولا نصرهم الذين اتخذوا من دون الله قربانا آلهة بل ضلوا عنهم وذلك إفكهم وما كانوا يفترون }<br />
{ فلولا } هلا  { نصرهم } بدفع العذاب عنهم  { الذين اتخذوا من دون الله } أي غيره  { قرباناً } متقرباً بهم إلى الله  { آلهةٌ } معه وهم الأصنام ومفعول اتخذ الأول ضمير محذوف يعود على الموصول أي هم ،   وقرباناً الثاني وآلهة بدل منه  { بل ضلوا } غابوا  { عنهم } عند نزول العذاب  { وذلك } أي اتخاذهم الأصنام آلهة قرباناً  { إفكهم } كذبهم  { وما كانوا يفترون } يكذبون ،   وما مصدرية أو موصولة والعائد محذوف ،   أي فيه  .  <br />
