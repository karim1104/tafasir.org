{ ما خلقنا السماوات والأرض وما بينهما إلا بالحق وأجل مسمى والذين كفروا عن ما أنذروا معرضون }<br />
{ ما خلقنا السماوات والأرض وما بينهما إلا } خلقا  { بالحق } ليبدل على قدرتنا ووحدانيتنا  { وأجل مسمى } إلى فنائهما يوم القيامة  { والذين كفروا عما أنذروا } خوفوا به من العذاب  { معرضون }  .  <br />
