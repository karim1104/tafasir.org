{ قل أرأيتم إن كان من عند الله وكفرتم به وشهد شاهد من بني إسرائيل على مثله فآمن واستكبرتم إن الله لا يهدي القوم الظالمين }<br />
{ قل أرأيتم } أخبروني ماذا حالكم  { إن كان } أي القرآن  { من عند الله وكفرتم به } جملة حالية  { وشهد شاهد من بني إسرائيل } هو عبد الله بن سلام  { على مثله } أي عليه أنه من عند الله  { فآمن } الشاهد  { واستكبرتم } تكبرتم عن الإيمان وجواب الشرط بما عطف عليه : ألستم ظالمين دل عليه  { إن الله لا يهدي القوم الظالمين }  .  <br />
