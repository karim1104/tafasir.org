{ وهم يصطرخون فيها ربنا أخرجنا نعمل صالحا غير الذي كنا نعمل أو لم نعمركم ما يتذكر فيه من تذكر وجاءكم النذير فذوقوا فما للظالمين من نصير }<br />
{ وهم يصطرخون فيها } يستغيثون بشدة وعويل يقولون  { ربنا أخرجنا } منها  { نعمل صالحاً غير الذي كنا نعمل } فيقال لهم  { أوَ لم نعمّركم ما } وقتاً  { يتذكر فيه من تذكر وجاءكم النذير } الرسول فما أجبتم  { فذوقوا فما للظالمين } الكافرين  { من نصير } يدفع العذاب عنهم  .  <br />
