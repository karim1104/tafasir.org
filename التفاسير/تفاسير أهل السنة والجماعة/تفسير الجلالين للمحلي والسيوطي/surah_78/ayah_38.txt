{ يوم يقوم الروح والملائكة صفا لا يتكلمون إلا من أذن له الرحمن وقال صوابا }<br />
{ يوم } ظرف ل لا يملكون  { يقوم الروح } جبريل أو جند الله  { والملائكة صفاً } حال ،   أي مصطفين  { لا يتكلمون } أي الخلق  { إلا من أذن له الرحمن } في الكلام  { وقال } قولاً  { صواباً } من المؤمنين والملائكة كأن يشفعوا لمن ارتضى .  <br />
