{ تنزع الناس كأنهم أعجاز نخل منقعر }<br />
{ تنزع الناس } تقلعهم من حفر الأرض المندسين فيها وتصرعهم على رؤوسهم فتدق رقابتهم فتبين الرأس عن الجسد  { كأنهم } وحالهم ما ذكر  { أعجاز } أصول  { نخل منقعر } منقطع ساقط على الأرض وشبهوا بالنخل لطولهم وذكر هنا وأنث في الحاقة  ( نخل خاوية  ) مراعاة للفواصل في الموضعين  .  <br />
