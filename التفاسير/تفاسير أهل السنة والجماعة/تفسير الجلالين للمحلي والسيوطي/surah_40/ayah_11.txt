{ قالوا ربنا أمتنا اثنتين وأحييتنا اثنتين فاعترفنا بذنوبنا فهل إلى خروج من سبيل }<br />
{ قالوا ربنا أمتَّنا اثنتين } إماتتين  { وأحييتنا اثنتين } إحياءتين لأنهم نطفٌ أموات فأحيوا ثم أميتوا ثم أحيوا للبعث  { فاعترفنا بذنوبنا } بكفرنا بالبعث  { فهل إلى خروج } من النار والرجوع إلى الدنيا لنطيع ربنا  { من سبيل } طريق وجوابهم : لا  .  <br />
