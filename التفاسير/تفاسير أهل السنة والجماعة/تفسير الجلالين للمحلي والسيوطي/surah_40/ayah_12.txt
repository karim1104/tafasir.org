{ ذلكم بأنه إذا دعي الله وحده كفرتم وإن يشرك به تؤمنوا فالحكم لله العلي الكبير }<br />
{ ذلكم } أي العذاب أنتم فيه  { بأنه } أي بسبب أنه في الدنيا  { إذا دعي الله وحده كفرتم } بتوحيده  { وإن يُشرَك به } يجعل له شريك  { تؤمنوا } تصدقوا بالإشراك  { فالحكم } في تعذيبكم  { لله العليِّ } على خلقه  { الكبير } العظيم  .  <br />
