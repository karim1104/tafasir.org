{ قالوا أو لم تك تأتيكم رسلكم بالبينات قالوا بلى قالوا فادعوا وما دعاء الكافرين إلا في ضلال }<br />
{ قالوا } أي الخزنة تهكماً  { أوَ لم تلك تأتيكم رسلكم بالبينات } بالمعجزات الظاهرات  { قالوا بلى } أي فكروا بهم  { قالوا فادعوا } أنتم فإنا لا نشفع للكافرين ،   قال تعالى :  { وما دعاءُ الكافرين إلا في ضلال } إنعدام  .  <br />
