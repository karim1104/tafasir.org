{ وقالوا لن تمسنا النار إلا أياما معدودة قل أتخذتم عند الله عهدا فلن يخلف الله عهده أم تقولون على الله ما لا تعلمون }<br />
{ وقالوا  } لما وعدهم النبي النار { لن تمسنا  } تصيبنا { النار إلا أياما معدودة  } قليلة أربعين يوما مدة عبادة آبائهم العجل { وقيل أربعة أيام  } ثم تزول { قل } لهم يا محمد { أتخذتم } حذفت منه همزة الوصل استغناء بهمزة الاستفهام { عند الله عهدا } ميثاقا منه بذلك { فلن يخلف الله عهده } به  ،   لا { أم } بل { تقولون على الله ما لا تعلمون } .  <br />
