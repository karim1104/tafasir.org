{ ومنهم أميون لا يعلمون الكتاب إلا أماني وإن هم إلا يظنون }<br />
{ ومنهم } أي اليهود { أميون } عوام { لا يعلمون الكتاب } التوراة { إلا } لكن { أمانيَّ } أكاذيبَ تَلَقَّوها من رؤسائهم فاعتمدوها { وإن } ما <br />
{ هم } في جحد نبوة النبي وغيره مما يختلقونه { إلا يظنون } ظنا ولا علم لهم .  <br />
