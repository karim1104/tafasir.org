{ بلى من أسلم وجهه لله وهو محسن فله أجره عند ربه ولا خوف عليهم ولا هم يحزنون } .  <br />
{ بلى } يدخل الجنة غيرهم { من أسلم وجهه لله } أي انقاد لأمره وخص الوجه لأنه أشرف الأعضاء فغيره أولى { وهو محسن } موحد { فله أجره عند ربه } أي ثواب عمله الجنة { ولا خوف عليهم ولا هم يحزنون } في الآخرة .  <br />
