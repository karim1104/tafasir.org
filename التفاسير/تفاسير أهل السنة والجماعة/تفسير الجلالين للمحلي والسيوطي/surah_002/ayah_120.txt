{ ولن ترضى عنك اليهود ولا النصارى حتى تتبع ملتهم قل إن هدى الله هو الهدى ولئن اتبعت أهواءهم بعد الذي جاءك من العلم ما لك من الله من ولي ولا نصير } .  <br />
{ ولن ترضى عنك اليهود ولا النصارى حتى تتبع ملتهم } دينهم { قل إن هدى الله } أي الإسلام { هو الهدى } وما عداه ضلال { ولئن } لام قسم { اتبعت أهواءهم } التي يدعونك إليها فرضاً { بعد الذي جاءك من العلم } الوحي من الله { ما لك من الله من ولي }يحفظك { ولا نصير } يمنعك منه .  <br />
