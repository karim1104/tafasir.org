{ أوكلما عاهدوا عهدا نبذه فريق منهم بل أكثرهم لا يؤمنون } .  <br />
{ أو كلما عاهدوا } الله { عهداً } على الإيمان بالنبي إن خرج  ،   أو النبي أن لا يعاونوا عليه المشركين { نبذه } طرحه { فريق منهم } بنقضه  ،   جواب كلما وهو محل الاستفهام الإنكاري { بل } للانتقال { أكثرهم لا يؤمنون } .  <br />
