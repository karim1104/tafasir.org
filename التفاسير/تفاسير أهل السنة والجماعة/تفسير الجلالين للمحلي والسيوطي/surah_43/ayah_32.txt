{ أهم يقسمون رحمة ربك } النبوة  { نحن قسمنا بينهم معيشتهم في الحياة الدنيا } فجعلنا بعضهم غنياً وبعضهم فقيراً  { ورفعنا بعضهم } بالغنى  { فوق بعض درجات ليتخذ بعضهم } الغني  { بعضاً } الفقير  { سخرياً } مسخراً في العمل له بالأجرة ،   والياء للنسب ،   وقرئ بكسر السين  { ورحمة ربك } أي الجنة  { خير مما يجمعون } في الدنيا  .  <br />
