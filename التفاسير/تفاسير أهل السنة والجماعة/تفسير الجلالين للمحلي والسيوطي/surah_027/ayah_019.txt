{ فتبسم ضاحكا من قولها وقال رب أوزعني أن أشكر نعمتك التي أنعمت علي وعلى والدي وأن أعمل صالحا ترضاه وأدخلني برحمتك في عبادك الصالحين }<br />
{ فتبسّم } سليمان ابتداء  { ضاحكا } انتهاء  { من قولها } وقد سمعه من ثلاثة أميال حملته إليه الريح فحبس جنده حين أشرف على واديهم حتى دخلوا بيوتهم وكان جنده ركباناً ومشاة في هذا السير  { وقال رب أوزعني } ألهمني  { أن أشكر نعمتك التي أنعمت } بها  { علىَّ وعلى والديَّ وأن أعمل صالحاً ترضاه وأدخلني برحمتك في عبادك الصالحين } الأنبياء والأولياء  .  <br />
