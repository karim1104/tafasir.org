{ قل اللهم فاطر السماوات والأرض عالم الغيب والشهادة أنت تحكم بين عبادك في ما كانوا فيه يختلفون }<br />
{ قل اللهم } بمعنى يا الله  { فاطر السماوات والأرض } مبدعهما  { عالم الغيب والشهادة } ما غاب وما شوهد  { أنت تحكم بين عبادك فيما كانوا فيه يختلفون } من أمر الدين اهدني لما اختلفوا فيه من الحق  .  <br />
