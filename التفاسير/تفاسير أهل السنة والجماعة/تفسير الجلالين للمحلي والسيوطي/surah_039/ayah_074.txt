{ وقالوا الحمد لله الذي صدقنا وعده وأورثنا الأرض نتبوأ من الجنة حيث نشاء فنعم أجر العاملين }<br />
{ وقالوا } عطف على دخولها المقدر  { الحمد لله الذي صدقنا وعده } بالجنة  { وأورثنا الأرض } أي أرض الجنة  { نتبوأ } ننزل  { من الجنة حيث نشاء } لأنها كلها لا يختار فيها مكان على مكان  { فنعم أجر العاملين } الجنة  .  <br />
