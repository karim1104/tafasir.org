{ وما قدروا الله حق قدره والأرض جميعا قبضته يوم القيامة والسماوات مطويات بيمينه سبحانه وتعالى عن ما يشركون }<br />
{ وما قدروا الله حق قدره } ما عرفوه حق معرفته ،   أو ما عظموه حق عظمته حين أشركوا به غيره  { والأرض جميعاً } حال : أي السبع  { قبضته } أي مقبوضة له : أي في ملكه وتصرفه  { يوم القيامة والسماوات مطويات } مجموعات  { بيمينه } بقدرته  { سبحانه وتعالى عما يشركون } معه  .  <br />
