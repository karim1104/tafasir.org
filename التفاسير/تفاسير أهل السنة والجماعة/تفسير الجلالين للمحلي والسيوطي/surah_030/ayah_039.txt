{ وما آتيتم من ربا ليربو في أموال الناس فلا يربو عند الله وما آتيتم من زكاة تريدون وجه الله فأولئك هم المضعفون }<br />
{ وما آتيتم من رِباً } بأن يعطي شيء هبة أو هدية ليطلب أكثر منه ،   فسمي باسم المطلوب من الزيادة في المعاملة  { ليربوَ في أموال الناس } المعطين ،   أي يزيد  { فلا يربو } يزكو  { عند الله } لا ثواب فيه للمعطين  { وما آتيتم من زكاة } صدقة  { تريدون } بها  { وجه الله فأولئك هم المضعفون } ثوابهم بما أرادوه ،   فيه التفات عن الخطاب .  <br />
