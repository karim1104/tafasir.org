{ ومن آياته يريكم البرق خوفا وطمعا وينزل من السماء ماء فيحيي به الأرض بعد موتها إن في ذلك لآيات لقوم يعقلون }<br />
{ ومن آياته يريكم } أي إراءتكم  { البرق خوفاً } للمسافر من الصواعق  { وطمعاً } للمقيم في المطر  { وينزل من السماء ماءً فيحيي به الأرض بعد موتها } أي : يبسطها بأن تنبت  { إن في ذلك } المذكور  { لآيات لقوم يعقلون } يتدبرون .  <br />
