{ وقال إنما اتخذتم من دون الله أوثانا مودة بينكم في الحياة الدنيا ثم يوم القيامة يكفر بعضكم ببعض ويلعن بعضكم بعضا ومأواكم النار وما لكم من ناصرين }<br />
{ وقال } إبراهيم  { إنما اتخذتم من دون الله أوثاناً } تعبدونها وما مصدرية  { مودةُ بينكم } خبر إن ،   وعلى قراءة النصب مفعول له وما كافة المعنى : تواددتم على عبادتها  { في الحياة الدنيا ثم يوم القيامة يكفر بعضكم ببعض } يتبرأ القادة من الأتباع  { ويلعن بعضكم بعضاً } يلعن الأتباع القادة  { ومأواكم } مصيركم جميعاً  { النار وما لكم من ناصرين } مانعين منها .  <br />
