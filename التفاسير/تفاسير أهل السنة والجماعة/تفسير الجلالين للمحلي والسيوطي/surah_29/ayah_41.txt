{ مثل الذين اتخذوا من دون الله أولياء كمثل العنكبوت اتخذت بيتا وإن أوهن البيوت لبيت العنكبوت لو كانوا يعلمون }<br />
{ مثل الذين اتخذوا من دون الله أولياء } أي أصناماً يرجون نفعها  { كمثل العنكبوت اتخذت بيتاً } لنفسها تأوي إليه  { وإن أوهن } أضعف  { البيوت لبيت العنكبوت } لا يدفع عنها حراً ولا برداً كذلك الأصنام لا تنفع عابديها  { لو كانوا يعلمون } ذلك ما عبدوها .  <br />
