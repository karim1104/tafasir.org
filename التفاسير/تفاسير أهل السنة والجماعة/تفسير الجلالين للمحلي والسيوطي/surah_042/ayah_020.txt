{ من كان يريد حرث الآخرة نزد له في حرثه ومن كان يريد حرث الدنيا نؤته منها وما له في الآخرة من نصيب }<br />
{ من كان يريد } بعمله  { حرث الآخرة } أي كسبها وهو الثواب  { نزد له في حرثه } بالتضعيف فيه الحسنة إلى العشرة وأكثر  { ومن كان يريد حرث الدنيا نؤته منها } بلا تضعيف ما قسم له  { وما له في الآخرة من نصيب }  .  <br />
