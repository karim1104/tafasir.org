{ أم يقولون افترى على الله كذبا فإن يشأ الله يختم على قلبك ويمح الله الباطل ويحق الحق بكلماته إنه عليم بذات الصدور }<br />
{ أم } بل  { يقولون افترى على الله كذباً } بنسبة القرآن إلى الله تعالى  { فإن يشأ الله يختم } يربط  { على قلبك } بالصبر على أذاهم بهذا القول وغيره ،   وقد فعل  { ويَمْحُ الله الباطل } الذي قالوه  { ويحق الحق } يثبته  { بكلماته } المنزلة على بنيه  { إنه عليم بذات الصدور } بما في القلوب  .  <br />
