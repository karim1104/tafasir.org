{ ووصينا الإنسان بوالديه حملته أمه وهنا على وهن وفصاله في عامين أن اشكر لي ولوالديك إلي المصير }<br />
{ ووصينا الإنسان بوالديه } أمرناه أن يبرهما  { حملته أمُه } فْوهنت  { وهناُ على وهنٍ } أي ضعفت للحمل وضعفت للطلق وضعفت للولادة  { وفصاله } أي فطامه  { في عامين } وقلنا له  { أنِ اشكر لي ولوالديك إلىَّ المصير } أي المرجع .  <br />
