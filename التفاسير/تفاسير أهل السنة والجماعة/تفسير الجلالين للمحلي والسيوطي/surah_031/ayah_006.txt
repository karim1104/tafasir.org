{ ومن الناس من يشتري لهو الحديث ليضل عن سبيل الله بغير علم ويتخذها هزوا أولئك لهم عذاب مهين }<br />
{ ومن الناس من يشتري لهو الحديث } أي ما يلهي منه عما يعني  { ليضلَّ } بفتح الياء وضمها  { عن سبيل الله } طريق الإسلام  { بغير علمٍ ويتخذها } بالنصب عطفاً على يضل ،   وبالرفع عطفاً على يشتري  { هزؤاً } مهزوءاً بها  { أولئك لهم عذاب مهين } ذو إهانة .  <br />
