{ وأن أتلو القرآن فمن اهتدى فإنما يهتدي لنفسه ومن ضل فقل إنما أنا من المنذرين }<br />
{ وأن أتلوَ القرآن } عليكم تلاوة الدعوى إلى الإيمان  { فمن اهتدى } له  { فإنما يهتدي لنفسه } أي لأجلها فإن ثواب اهتدائه له  { ومن ضل } عن الإيمان وأخطأ طريق الهدى  { فقل } له  { إنما أنا من المنذرين } المخوفين فليس عليَّ إلا التبليغ وهذا قبل الأمر بالقتال .  <br />
