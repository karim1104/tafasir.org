{ قل الحمد لله وسلام على عباده الذين اصطفى آلله خير أما يشركون }<br />
{ قل } يا محمد  { الحمد لله } على هلاك الكفار من الأمم الخالية  { وسلام على عباده الذين اصطفى } هم  { آلله } بتحقيق الهمزتين وإبدال الثانية ألفاً وتسهليها وإدخال ألف بين المسهلة والأخرى وتركه  { خير } لمن يعبده  { أمّا تشركون } بالتاء والياء أي أهل مكة به الآلهة خير لعابديها .  <br />
