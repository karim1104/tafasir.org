{ ألم يروا أنا جعلنا الليل ليسكنوا فيه والنهار مبصرا إن في ذلك لآيات لقوم يؤمنون }<br />
{ ألم يروا أنا جعلنا } خلقنا  { الليل ليسكنوا فيه } كغيرهم  { والنهار مبصراً } بمعنى يبصر فيه ليتصرفوا فيه  { إن في ذلك لآيات } دلالات على قدرته تعالى  { لقوم يؤمنون } خصوا بالذكر لانتفاعهم بها في الإيمان بخلاف الكافرين .  <br />
