{ حتى إذا أتوا على واد النمل قالت نملة يا أيها النمل ادخلوا مساكنكم لا يحطمنكم سليمان وجنوده وهم لا يشعرون }<br />
{ حتى إذا أتوْا على وادِ النمل } هو بالطائف أو بالشام ،   نملة صغار أو كبار  { قالت نملة } ملكة النمل وقد رأت جند سليمان  { يا أيها النمل ادخلوا مساكنكم لا يحطمنكم } يكسرنكم  { سليمان وجنوده وهم لا يشعرون } نزل النمل منزلة العقلاء في الخطاب بخطابهم  .  <br />
