{ قال يا قوم لم تستعجلون بالسيئة قبل الحسنة لولا تستغفرون الله لعلكم ترحمون }<br />
{ قال } للمكذبين  { ياقوم لمَ تستعجلون بالعذاب بالسيئة قبل الحسنة } أي بالعذاب قبل الرحمة حيث قلتم إن كان ما أتيتنا به حقاً فأتنا بالعذاب  { لولا } هلا  { تستغفرون الله } من الشرك  { لعلكم ترحمون } فلا تعذبون  .  <br />
