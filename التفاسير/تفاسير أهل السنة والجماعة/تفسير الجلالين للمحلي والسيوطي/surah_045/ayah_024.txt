{ وقالوا ما هي إلا حياتنا الدنيا نموت ونحيا وما يهلكنا إلا الدهر وما لهم بذلك من علم إن هم إلا يظنون }<br />
{ وقالوا } أي منكرو البعث  { ما هي } أي الحياة  { إلا حياتنا } التي في  { الدنيا نموت ونحيا } أي يموت بعض ويحيا بعض بأن يولدوا  { وما يهلكنا إلا الدهر } أي مرور الزمان ،   قال تعالى :  { وما لهم بذلك } المقول  { من علم إن } ما  { هم إلا يظنون }  .  <br />
