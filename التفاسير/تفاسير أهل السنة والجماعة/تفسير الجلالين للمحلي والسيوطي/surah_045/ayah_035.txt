{ ذلكم بأنكم اتخذتم آيات الله هزوا وغرتكم الحياة الدنيا فاليوم لا يخرجون منها ولا هم يستعتبون }<br />
{ ذلكم بأنكم اتخذتم آيات الله } القرآن  { هزؤاً وغرتكم الحياة الدنيا } حتى قلتم لا بعث ولا حساب  { فاليوم لا يَخرجون } بالبناء للفاعل وللمفعول  { منها } من النار  { ولا هم يستعتبون } لا يطلب منهم أن يرضوا ربهم بالتوبة والطاعة ؛ لأنها لا تنفع يومئذ  .  <br />
