{ فلما جاءهم الحق من عندنا قالوا لولا أوتي مثل ما أوتي موسى أو لم يكفروا بما أوتي موسى من قبل قالوا سحران تظاهرا وقالوا إنا بكل كافرون }<br />
{ فلما جاءهم الحق } محمد  { من عندنا قالوا لولا } هلا  { أوتي مثل ما أوتي موسى } من الآيات كاليد البيضاء والعصا وغيرهما أو الكتاب جملة واحدة قال تعالى  { أوَ لم يكفروا بما أوتيَ موسى من قبل } حيث  { قالوا } فيه وفي محمد  { ساحران } وفي قراءة سحران أي القرآن والتوراة  { تظاهراً } تعاوناً  { وقالوا إنا بكل } من النبيين والكتابين  { كافرون }  .  <br />
