{ وابتغ في ما آتاك الله الدار الآخرة ولا تنس نصيبك من الدنيا وأحسن كما أحسن الله إليك ولا تبغ الفساد في الأرض إن الله لا يحب المفسدين }<br />
{ وابتغ } اطلب  { فيما آتاك الله } من المال  { الدار الآخرة } بأن تنفقه في طاعة الله  { ولا تنس } تترك  { نصيبك من الدنيا } أي أن تعمل فيها للآخرة  { وأحسن } للناس بالصدقة  { كما أحسن الله إليك ولا تبغ } تطلب  { الفساد في الأرض } بعمل المعاصي  { إن الله لا يحب المفسدين } بمعنى أنه يعاقبهم .  <br />
