{ ونزعنا من كل أمة شهيدا فقلنا هاتوا برهانكم فعلموا أن الحق لله وضل عنهم ما كانوا يفترون }<br />
{ ونزعنا } أخرجنا  { من كل أمة شهيداً } وهو نبيهم يشهد عليم بما قالوا  { فقلنا } لهم  { هاتوا برهانكم } على ما قلتم من الإشراك  { فعلموا أن الحق } في الإلهية  { لله } لا يشاركه فيه أحد  { وضل } غاب  { عنهم ما كانوا يفترون } في الدنيا من أن معه شريكاً ،   تعالى عن ذلك .  <br />
