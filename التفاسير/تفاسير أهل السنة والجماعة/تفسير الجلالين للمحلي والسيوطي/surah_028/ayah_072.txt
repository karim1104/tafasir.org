{ قل أرأيتم إن جعل الله عليكم النهار سرمدا إلى يوم القيامة من إله غير الله يأتيكم بليل تسكنون فيه أفلا تبصرون }<br />
{ قل } لهم  { أرأيتم إن جعل الله عليكم النهار سرمداً إلى يوم القيامة من إله غير الله } بزعمكم  { يأتيكم بليل تسكنون } تستريحون  { فيه } من التعب  { أفلا تبصرون } ما أنتم عليه من الخطأ في الإشراك فترجعون عنه .  <br />
