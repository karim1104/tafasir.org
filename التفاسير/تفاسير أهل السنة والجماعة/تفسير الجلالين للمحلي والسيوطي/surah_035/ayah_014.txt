{ إن تدعوهم لا يسمعوا دعاءكم ولو سمعوا ما استجابوا لكم ويوم القيامة يكفرون بشرككم ولا ينبئك مثل خبير }<br />
{ إن تدعوهم لا يسمعوا دعائكم ولو سمعوا } فرضاً  { ما استجابوا لكم } ما أجابوكم  { ويوم القيامة يكفرون بشرككم } بإشراككم إياهم مع الله ،   أي يتبرؤون منكم ومن عبادتكم إياهم  { ولا يُنبئك } بأحوال الدارين  { مثل خبير } عالم هو الله تعالى  .  <br />
