{ وأقسموا بالله جهد أيمانهم لئن جاءهم نذير ليكونن أهدى من إحدى الأمم فلما جاءهم نذير ما زادهم إلا نفورا }<br />
{ وأقسموا } أي كفار مكة  { بالله جهد أيمانهم } غاية اجتهادهم فيها  { لئن جاءهم نذير } رسول  { ليكوننَّ أهدى من إحدى الأمم } اليهود والنصارى وغيرهم ،   أي أيَّ واحدة منها لما رأوا من تكذيب بعضهم بعضاً ،   إذ قالت اليهود : ليست النصارى على شيء ،    { فلما جاءهم نذير } محمد صلى الله عليه وسلم  { ما زادهم } مجيئه  { إلا نفوراً } تباعداً عن الهدى  .  <br />
