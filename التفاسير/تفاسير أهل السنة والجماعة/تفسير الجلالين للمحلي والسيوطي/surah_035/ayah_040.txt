{ قل أرأيتم شركاءكم الذين تدعون من دون الله أروني ماذا خلقوا من الأرض أم لهم شرك في السماوات أم آتيناهم كتابا فهم على بينة منه بل إن يعد الظالمون بعضهم بعضا إلا غرورا }<br />
{ قل أرأيتم شركاءكم الذين تدعون } تعبدون  { من دون الله } أي غيره ،   وهم الأصنام الذين زعمتم أنهم شركاء الله تعالى  { أروني } أخبروني  { ماذا خلقوا من الأرض أم لهم شرك } شركة مع الله  { في } خلق  { السماوات } { أم آتيناهم كتاباً فهم على بينة } حجة  { منه } بأن لهم معه شركة { بل إن } ما { يعد الظالمون } الكافرون  { بعضهم بعضاً إلا غروراً } باطلاً بقولهم الأصنام تشفع لهم .  <br />
