{ والله الذي أرسل الرياح فتثير سحابا فسقناه إلى بلد ميت فأحيينا به الأرض بعد موتها كذلك النشور }<br />
{ والله الذي أرسل الرياح } وفي قراءة الريح  { فتثير سحاباً } المضارع لحكاية الحال الماضية ،   أي تزعجه  { فسقناه } فيه التفات عن الغيبة  { إلى بلد ميت } بالتشديد والتخفيف لا نبات بها  { فأحيينا به الأرض } من البلد  { بعد موتها } يبسها ،   أي أنبتنا به الزرع والكلأ  { كذلك النشور } أي البعث والإحياء  .  <br />
