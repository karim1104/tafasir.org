{ والذين آمنوا وعملوا الصالحات وآمنوا بما نزل على محمد وهو الحق من ربهم كفر عنهم سيئاتهم وأصلح بالهم }<br />
{ والذين آمنوا } أي الأنصار وغيرهم  { وعلموا الصالحات وأمنوا بما نُزِّل على محمد } أي القرآن  { وهو الحق من ربهم كفَّر عنهم } غفر لهم  { سيئاتهم وأصلح بالهم } حالهم فلا يعصونه  .  <br />
