{ إنا بلوناهم كما بلونا أصحاب الجنة إذ أقسموا ليصرمنها مصبحين }<br />
{ إنا بلوناهم } امتحنا أهل مكة بالقحط والجوع  { كما بلونا أصحاب الجنة } البستان  { إذ أقسموا ليصرمنَّها } يقطعون ثمرتها  { مصبحين } وقت الصباح ،   كي لا يشعر بهم المساكين ،   فلا يعطونهم منها ما كان أبوهم يتصدق به عليهم منها .  <br />
