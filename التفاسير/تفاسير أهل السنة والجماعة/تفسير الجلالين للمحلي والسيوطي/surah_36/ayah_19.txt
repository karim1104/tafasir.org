{ قالوا طائركم معكم أئن ذكرتم بل أنتم قوم مسرفون }<br />
{ قالوا طائركم } شؤمكم  { معكم } بكفركم  { أئن } همزة استفهام دخلت على إن الشرطية ألف بينها بوجهيها وبين الأخرى  { ذكرتم } وعظتم وخوِّفتم ،   وجواب الشرط محذوف ،   أي تطيرتم وكفرتم وهو محل الاستفهام ،   والمراد به التوبيخ  { بل أنتم قوم مسرفون } متجاوزون الحدَّ بشرككم  .  <br />
