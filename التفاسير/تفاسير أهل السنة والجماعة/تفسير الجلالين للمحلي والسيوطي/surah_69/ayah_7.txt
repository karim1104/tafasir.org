{ سخرها عليهم سبع ليال وثمانية أيام حسوما فترى القوم فيها صرعى كأنهم أعجاز نخل خاوية }<br />
{ سخرها } أرسلها بالقهر  { عليهم سبع ليال وثمانية أيام } أولها من صبح يوم الأربعاء لثمان بقين من شوال ،   وكانت في عجز الشتاء  { حسوماً } متتابعات شبهت بتتابع فعل الحاسم في إعادة الكي على الداء كرة بعد أخرى حتى ينحسم  { فترى القوم فيها صرعى } مطروحين هالكين  { كأنهم أعجاز } أصول  { نخل خاوية } ساقطة فارغة .  <br />
