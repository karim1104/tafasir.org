{ وقال الذين أوتوا العلم ويلكم ثواب الله خير لمن آمن وعمل صالحا ولا يلقاها إلا الصابرون }<br />
{ وقال } لهم  { الذين أوتوا العلم } بما وعد الله في الآخرة  { ويلكم } كلمة زجر  { ثواب الله } في الآخرة بالجنة  { خير لمن آمن وعمل صالحاً } مما أوتي قارون في الدنيا  { ولا يلقاها } أي الجنة المثاب بها  { إلا الصابرون } على الطاعة وعن المعصية .  <br />
