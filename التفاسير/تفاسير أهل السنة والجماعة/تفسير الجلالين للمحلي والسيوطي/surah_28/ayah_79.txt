{ فخرج على قومه في زينته قال الذين يريدون الحياة الدنيا يا ليت لنا مثل ما أوتي قارون إنه لذو حظ عظيم }<br />
{ فخرج } قارون  { على قومه في زينته } بأتباعه الكثيرين ركباناً متحلين بملابس الذهب والحرير على خيول وبغال متحلية  { قال الذين يريدون الحياة الدنيا يا } للتنبيه  { ليت لنا مثل ما أوتي قارون } في الدنيا  { إنه لذو حظ } نصيب  { عظيم } واف فيها .  <br />
