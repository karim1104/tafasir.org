{ فلما أتاها نودي من شاطئ الوادي الأيمن في البقعة المباركة من الشجرة أن يا موسى إني أنا الله رب العالمين }<br />
{ فلما أتاها نودي من شاطئ } جانب  { الواد الأيمن } لموسى  { في البقعة المباركة } لموسى لسماعه كلام الله فيها  { من الشجرة } بدل من شاطئ بإعادة الجار لنباتها فيه وهي شجرة عناب أو عليق أو عوسج  { أن } مفسرة لا مخففة  { يا موسى إني أنا الله رب العالمين }  .  <br />
