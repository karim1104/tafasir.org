{ وقالوا لولا أنزل عليه آيات من ربه قل إنما الآيات عند الله وإنما أنا نذير مبين }<br />
{ وقالوا } أي كفار مكة  { لولا } هلا  { أنزل عليه } أي محمد  { آية من ربه } وفي قراءة : آيات كناقة صالح وعصا موسى ومائدة عيسى  { قل } لهم  { إنما الآيات عند الله } ينزلها كيف يشاء  { وإنما أنا نذير مبين } مظهر إنذاري بالنار أهل المعصية .  <br />
