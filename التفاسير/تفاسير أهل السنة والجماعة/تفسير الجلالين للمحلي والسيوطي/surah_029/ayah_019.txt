{ أو لم يروا كيف يبديء الله الخلق ثم يعيده إن ذلك على الله يسير }<br />
{ أَو لم يروْا } بالياء والتاء ينظروا  { كيف يُبدئ الله الخلق } هو بضم أوله وقرأ بفتحة من بدأ وأبدأ بمعنى أي يخلقهم ابتداءً { ثم } هو { يعيده } أي الخلق كما بدأه { إن ذلك } المذكور من الخلق الأول والثاني  { على الله يسير } فكيف ينكرون الثاني .  <br />
