{ والذين آمنوا بالله ورسله أولئك هم الصديقون والشهداء عند ربهم لهم أجرهم ونورهم والذين كفروا وكذبوا بآياتنا أولئك أصحاب الجحيم }<br />
{ والذين آمنوا بالله ورسله أولئك هم الصديقون } المبالغون في التصديق  { والشهداء عند ربهم } على المكذبين من الأمم  { لهم أجرهم ونورهم والذين كفروا وكذبوا بآياتنا } الدالة على وحدانيتنا  { أولئك أصحاب الجحيم } النار  .  <br />
