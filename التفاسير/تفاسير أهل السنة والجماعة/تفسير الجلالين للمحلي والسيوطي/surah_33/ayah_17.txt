{ قل من ذا الذي يعصمكم من الله إن أراد بكم سوء أو أراد بكم رحمة ولا يجدون لهم من دون الله وليا ولا نصيرا }<br />
{ قل من ذا الذي يعصمكم } يجيركم  { من الله إن أراد بكم سوءاً } هلاكاً وهزيمة  { أو } يصيبكم بسوء  { أراد } الله  { بكم رحمة } خيراً  { ولا يجدون لهم من دون الله } أي غيره  { ولياً } ينفعهم  { ولا نصيراً } يدفع الضُرَّ عنهم .  <br />
