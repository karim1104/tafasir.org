{ لئن لم ينته المنافقون والذين في قلوبهم مرض والمرجفون في المدينة لنغرينك بهم ثم لا يجاورونك فيها إلا قليلا }<br />
{ لئن } لام قسم  { لم ينته المنافقون } عن نفاقهم  { والذين في قلوبهم مرض } بالزنا  { والمرجفون في المدينة } المؤمنين بقولهم قد أتاكم العدو وسراياكم قتلوا أو هزموا  { لنغرينك بهم } لتسلطنك عليهم  { ثم لا يجاورونك } يساكنوك  { فيها إلا قليلاً } ثم يخرجون  .  <br />
