{ يا أيها النبي قل لأزواجك إن كنتن تردن الحياة الدنيا وزينتها فتعالين أمتعكن وأسرحكن سراحا جميلا }<br />
{ يا أيها النبي قل لأزواجك } وهن تسع وطلبن منه زينة الدنيا ما ليس عنده  { إن كنتنَّ تردن الحياة الدنيا وزينتها فتعالين أمتعكن } أي متعة الطلاق  { وأسرحكن سراحاً جميلاً } أطلقكنَّ من غير ضرار .  <br />
