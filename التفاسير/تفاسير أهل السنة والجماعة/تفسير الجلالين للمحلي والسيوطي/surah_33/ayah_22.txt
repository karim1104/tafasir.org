{ ولما رأى المؤمنون الأحزاب قالوا هذا ما وعدنا الله ورسوله وصدق الله ورسوله وما زادهم إلا إيمانا وتسليما }<br />
{ ولمَّا رأى المؤمنون الأحزاب } من الكفار  { قالوا هذا ما وعدنا الله ورسوله } من الابتلاء والنصر  { وصدق الله ورسوله } في الوعد  { وما زادهم } ذلك  { إلا إيماناً } تصديقاً بوعد الله  { وتسليماً } لأمره .  <br />
