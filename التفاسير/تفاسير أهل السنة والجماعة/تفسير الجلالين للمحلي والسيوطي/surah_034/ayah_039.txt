{ قل إن ربي يبسط الرزق لمن يشاء من عباده ويقدر له وما أنفقتم من شيء فهو يخلفه وهو خير الرازقين }<br />
{ قل إن ربي يبسط الرزق } يوسعه  { لمن يشاء من عباده } امتحاناً  { ويقدر } يضيقه  { له } بعد البسط أو لمن يشاء ابتلاءً  { وما أنفقتم من شيء } في الخير  { فهو يخلفه وهو خير الرازقين } يقال : كل إنسان يرزق عائلته ،   أي من رزق الله  .  <br />
