{ ويرى الذين أوتوا العلم الذي أنزل إليك من ربك هو الحق ويهدي إلى صراط العزيز الحميد }<br />
{ ويرى } يعلم  { الذين أوتوا العلم } مؤمنو أهل الكتاب كعبد الله بن سلام وأصحابه  { الذي أنزل إليك من ربك } أي القرآن  { هو } فصل  { الحق ويهدي إلى صراط } طريق  { العزيز الحميد } أي الله ذي العزة المحمود  .  <br />
