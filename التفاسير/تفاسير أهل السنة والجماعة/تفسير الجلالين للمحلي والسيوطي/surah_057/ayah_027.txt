{ ثم قفينا على آثارهم برسلنا وقفينا بعيس ابن وآتيناه الإنجيل وجعلنا في قلوب الذين اتبعوه رأفةٌ ورحمة ورهبانية } هي رفض النساء واتخاذ الصوامع  { ابتدعوها } من قبل أنفسهم  { ما كتبناها عليهم } ما أمرناهم بها  { إلا } لكن فعلوها  { ابتغاء رضوان } مرضاة  { الله فما رعوْها حق رعايتها } إذ تركها كثير منهم وكفروا بدين عيسى ودخلوا في دين ملكهم وبقي على دين عيسى كثير منهم فآمنوا بنبينا  { فآتينا الذين آمنوا } به  { منهم أجرهم وكثير منهم فاسقون }  .  <br />
