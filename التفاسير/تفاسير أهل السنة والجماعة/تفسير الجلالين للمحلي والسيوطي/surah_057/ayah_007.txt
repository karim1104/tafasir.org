{ آمنوا بالله ورسوله وأنفقوا مما جعلكم مستخلفين فيه فالذين آمنوا منكم وأنفقوا لهم أجر كبير }<br />
{ آمنوا } داوموا على الإيمان  { بالله ورسوله وأنفقوا } في سبيل الله  { مما جعلكم مستخلفين فيه } من مال من تقدمكم وسيخلفكم فيه من بعدكم ،   نزل في غزوة العسرة وهي غزوة تبوك  { فالذين آمنوا منكم وأنفقوا } إشارة إلى عثمان رضي الله عنه  { لهم أجر كبير }  .  <br />
