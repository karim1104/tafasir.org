{ لكي لا تأسوا على ما فاتكم ولا تفرحوا بما آتاكم والله لا يحب كل مختال فخور }<br />
{ لكيلا } كي ناصبة للفعل بمعنى أن ،   أي أخبر تعالى بذلك لئلا  { تأسوا } تحزنوا  { على ما فاتكم ولا تفرحوا } فرح بطر بل فرح شكر على النعمة  { بما آتاكم } بالمد أعطاكم وبالقصر جاءكم منه  { والله لا يحب كل مختال } متكبر بما أوتي  { فخور } به على الناس  .  <br />
