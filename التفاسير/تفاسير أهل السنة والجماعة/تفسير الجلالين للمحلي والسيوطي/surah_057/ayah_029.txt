{ لئلا يعلم أهل الكتاب ألا يقدرون على شيء من فضل الله وأن الفضل بيد الله يؤتيه من يشاء والله ذو الفضل العظيم }<br />
{ لئلا يعلم } أي أعلمكم بذلك ليعلم  { أهل الكتاب } بالتوراة الذين لم يؤمنوا بمحمد صلى الله عليه وسلم  { أن } مخففة من الثقيلة واسمها ضمير الشأن والمعنى أنهم  { لا يقدرون على شيءٍ من فضل الله } خلاف ما في زعمهم أنهم أحباء الله وأهل رضوانه  { وأن الفضل بيد الله يؤتيه } يعطيه  { من يشاء } فآتى المؤمنين منهم أجرهم مرتين كما تقدم  { والله ذو الفضل العظيم }  .  <br />
