{ يا أيها الناس اتقوا ربكم واخشوا يوما لا يجزي والد عن ولده ولا مولود هو جاز عن والده شيئا إن وعد الله حق فلا تغرنكم الحياة الدنيا ولا يغرنكم بالله الغرور }<br />
{ يا أيها الناس } أي أهل مكة  { اتقوا ربكم واخشوْا يوماً لا يجزي } يغني  { والد عن ولده } فيه شيئاً  { ولا مولود عن هو جاز عن والده } فيه  { شيئاً إن وعد الله حقٌ } بالبعث  { فلا تغرنكم الحياة الدنيا } عن الإسلام  { ولا يغرنكم بالله } في حلمه وإمهاله  { الغرور } الشيطان .  <br />
