{ ألم تر أن الله يولج الليل في النهار ويولج النهار في الليل وسخر الشمس والقمر كل يجري إلى أجل مسمى وأن الله بما تعملون خبير }<br />
{ ألم ترَ } تعلم يا مخاطب  { أن الله يُولج } يدخل  { الليل في النهار ويولج النهار } يدخله  { في الليل } فيزيد كل منهما بما نقص من الآخر  { وسخَّر الشمس والقمر كلُّ } منهما  { يجري } في فلكه  { إلى أجل مسمى } هو يوم القيامة  { وأن الله بما تعملون خبير }  .  <br />
