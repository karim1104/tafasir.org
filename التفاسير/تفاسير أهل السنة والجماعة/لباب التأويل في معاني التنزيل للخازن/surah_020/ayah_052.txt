{ قال } يعني موسى { علمها عند ربي } أي أعمالهم محفوظة عند الله يجازي بها ،   وقيل إنما رد موسى علم ذلك إلى الله تعالى لأنه لم يعلم ذلك لأن التوراة إنما نزلت بعد هلاك فرعون وقومه { في كتاب } يعني اللوح المحفوظ { لا يضل ربي } أي لا يخطئ وقيل لا يغيب عنه شيء { ولا ينسى } أي فيتذكر وقيل لا ينسى ما كان من أعمالهم حتى يجازيهم بها .  <br />
