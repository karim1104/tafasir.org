{ وَهَذَا كِتَابٌ أَنْزَلْنَاهُ مُبَارَكٌ فَاتَّبِعُوهُ وَاتَّقُوا لَعَلَّكُمْ تُرْحَمُونَ } : قوله عز وجل : { وهذا كتاب أنزلناه مبارك } يعني : القرآن لأنه كثير الخير والنفع والبركة ولا يتطرق إليه نسخ { فاتبعوه } يعني : فاعملوا بما فيه من الأوامر والنواهي والأحكام { واتقوا } يعني مخالفته { لعلكم ترحمون } يعني : ليكن الغرض بالتقوى رحمة الله وقيل معناه لكي ترحموا على جزاء التقوى .  <br />
