{ إذ قال } أي واذكر يا محمد إذ قال { موسى لأهله } أي في مسيره بأهله من مدين إلى مصر { إني آنست } أي أبصرت { ناراً سآتيكم منها بخبر } أي امكثوا مكانكم سآتيكم بخبر عن الطريق ،   وقد كان ضل عن الطريق { أو آتيكم بشهاب قبس } الشهاب شعلة النار والقبس النار المقبوسة منها ،   وقيل : القبس هو العود الذي في أحد طرفيه نار { لعلكم تصطلون } يعني تستدفئون من البرد كان في شدة الشتاء .  <br />
