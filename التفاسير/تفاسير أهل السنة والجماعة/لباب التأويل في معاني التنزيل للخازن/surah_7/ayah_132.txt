قوله تعالى : { وقالوا } يعني قوم فرعون وهم القبط لموسى عليه السلام { مهما تأتنا به من آية } يعني من عند ربك فهي عندنا سحر وهو قولهم { لتسحرنا بها } يعني لتصرفنا عما نحن عليه من الدين { فما نحن لك بمؤمنين } يعني بمصدّقين وكان موسى عليه الصلاة والسلام رجلاً حديداً مستجاب الدعوة فدعا عليهم فاستجاب الله عز وجل دعاءه فقال تعالى { فأرسلنا عليهم الطوفان } .  <br />
