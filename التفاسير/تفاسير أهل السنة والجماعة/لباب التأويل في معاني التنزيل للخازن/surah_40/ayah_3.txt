{ غافر الذنب } يعني ساتر الذنب { وقابل التوب } يعني التوبة قال ابن عباس غافر الذنب لمن قال لا إله إلا الله وقابل التوب ممن قال لا إله إلا الله { شديد العقاب } لمن لا يقول لا إله إلا الله { ذي الطول } يعني السعة والغنى وقيل ذي الفضل والنعم وأصل الطول الإنعام الذي تطول مدته على صاحبه { لا إله إلا هو } يعني هو الموقوف بصفات الوحدانية التي لا يوصف بها غيره { إليه المصير } أي مصير العباد إليه في الآخرة .  <br />
