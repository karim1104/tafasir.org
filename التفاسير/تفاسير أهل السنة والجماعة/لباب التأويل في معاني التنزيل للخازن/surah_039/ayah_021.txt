قوله تعالى : { ألم تر أن الله أنزل من السماء ماء فسلكه } أي أدخل ذلك الماء { ينابيع في الأرض } أي عيوناً وركايا ومسالك ومجاري في الأرض كالعروق في الجسد قال الشعبي كل ماء في الأرض فمن السماء نزل { ثم يخرج به } أي بالماء { زرعاً مختلفاً ألوانه } أي مثل أصفر وأخضر وأحمر وأبيض وقيل أصنافه مثل البر والشعير وسائر أنواع الحبوب { ثم يهيج } أي ييبس { فتراه } أي بعد خضرته ونضرته { مصفراً ثم يجعله حطاماً } أي فتاتاً متكسراً { إن في ذلك لذكرى لأولي الألباب } .  <br />
