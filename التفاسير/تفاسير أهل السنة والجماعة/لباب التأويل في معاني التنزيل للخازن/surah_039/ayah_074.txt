{ وقالوا الحمد لله الذي صدقنا وعده } أي بالجنة { وأورثنا الأرض } أي أرض الجنة نتصرف فيها كما نشاء تشبيهاً بحال الوارث وتصرفه فيما يرثه وهو قوله تعالى : { نتبوأ } أي نزل { من الجنة } أي في الجنة { حيث نشاء } فإن قلت فما معنى قوله { حيث نشاء } وهل يتبوأ أحدهم مكان غيره .   قلت يكون لكل واحد منهم جنة لا توصف سعة وحسناً وزيادة على الحاجة فيتبوأ من جنته حيث يشاء ولا يحتاج إلى غيره وقيل إن أمة محمد صلى الله عليه وسلم يدخلون الجنة قبل الأمم فينزلون فيها حيث شاؤوا ثم تنزل الأمم بعدهم فيما فضل منها قال الله عز وجل : { فنعم أجر العاملين } أي ثواب المطيعين في الدنيا الجنة في العقبى .  <br />
