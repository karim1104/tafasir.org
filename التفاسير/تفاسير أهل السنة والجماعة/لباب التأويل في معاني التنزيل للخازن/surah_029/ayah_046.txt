قوله عز وجل : { ولا تجادلوا أهل الكتاب } أي ولا تخاصموهم { إلا بالتي هي أحسن } أي القرآن والدعاء إلى الله بآياته والتنبيه على حججه وأراد بهم من قبل الجزية منهم { إلا الذين ظلموا منهم } يعني أبوا أن يعطوا الجزية ونصبوا الحرب فافجؤوهم بالسيف حتى يسلموا أو يعطوا الجزية ومعنى الآية إلا الذين ظلموكم لأن جميعهم ظالم بالكفر وقيل هم أهل الحرب ومن لا عهد له .   وقيل الآية منسوخة بآية السيف { وقولوا } أي للذين قبلوا الجزية إذا حدثوكم بشيء مما في كتبكم { آمنا بالذي أنزل إلينا وأنزل إليكم وإلهنا وإلهكم واحد ونحن له مسلمون } ( خ ) عن أبي هريرة قال كان أهل الكتاب يقرؤون التوراة بالعبرانية ويفسرونها بالعربية لأهل الإسلام فقال النبي صلى الله عليه وسلم : « لا تصدقوا أهل الكتاب ولا تكذبوهم وقولوا آمنا بالله وما أنزل إلينا  » الآية .  <br />
