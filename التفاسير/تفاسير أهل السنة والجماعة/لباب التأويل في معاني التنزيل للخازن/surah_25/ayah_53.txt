قوله تعالى : { وهو الذي مرج البحرين } أي خلطهما وأفاض أحدهما على الآخر وقيل أرسلهما في مجاريهما { هذا عذب فرات } أي شديد العذوبة يميل إلى الحلاوة { وهذا ملح أجاج } أي شديد الملوحة وقيل مر { وجعل بينهما برزخاً } أي حاجزاً بقدرته فلا يختلط العذب بالملح ولا الملح بالعذب { وحجراً محجوراً } أي ستراً ممنوعاً فلا يبغي أحدهما على الآخر ولا يفسد الملح العذب .  <br />
