قوله تعالى : { وإذا مس الإنسان ضر } أي بلاء وشدة { دعا ربه منيباً } أي راجعاً { إليه } مستغيثاً به { ثم إذا خوله } أي أعطاه { نعمة منه نسي } أي ترك { ما كان يدعو إليه من قبل } والمعنى نسي الضر الذي كان يدعو الله إلى كشفه { وجعل لله أنداداً } يعني الأصنام { ليضل عن سبيله } أي ليرد عن دين الله تعالى { قل } أي لهذا الكافر { تمتع بكفرك قليلاً } أي في الدنيا إلى انقضاء أجلك { إنك من أصحاب النار } قيل نزلت في عتبة بن ربيعة وقيل في أبي حذيفة المخزومي وقيل هو عام في كل كافر .  <br />
