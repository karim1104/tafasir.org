{ وأنفقوا مما رزقناكم } قال ابن عباس يريد زكاة الأموال { من قبل أن يأتي أحدكم الموت } أي دلائل الموت ومقدماته وعلاماته فيسأل الرجعة { فيقول رب لولا أخرتني } أي هلا أمهلتني وقيل لو أخرت أجلي { إلى أجل قريب فأصدق } أي فأزكي مالي { وأكن } وقرئ وأكون { من الصالحين } أي المؤمنين وقيل نزلت هذه الآية في المنافقين ويدل على هذا أن المؤمن لا يسأل الرجعة وقيل نزلت في المؤمنين والمراد بالصلاح هنا الحج قال ابن عباس : ما من أحد يموت وكان له مال ولم يؤد زكاته أو أطاق الحج ولم يحج إلا سأل الرجعة عند الموت وقرأ هذه الآية { وأكن من الصالحين } أي أحج وأزكي .  <br />
