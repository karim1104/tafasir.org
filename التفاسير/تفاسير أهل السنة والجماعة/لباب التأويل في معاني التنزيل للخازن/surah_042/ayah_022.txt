{ ترى الظالمين } يعني يوم القيامة { مشفقين } أي وجلين خائفين { مما كسبوا } أي من الشرك والأعمال الخبيثة { وهو واقع بهم } أي جزاء كسبهم واقع بهم { والذين آمنوا وعملوا الصالحات في روضات الجنات } لأن هذه الروضات أطيب بقاع الجنة فلذلك خص الذين آمنوا وعملوا الصالحات بها وفيه تنبيه على أن الجنة منازل غير الروضات هي لمن هو دون الذين عملوا الصالحات من أهل القبلة { لهم ما يشاؤون عند ربهم } أي من الكرامة { ذلك هو الفضل الكبير } .  <br />
