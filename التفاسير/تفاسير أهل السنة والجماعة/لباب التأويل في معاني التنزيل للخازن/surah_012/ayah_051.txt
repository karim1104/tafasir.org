جمع الملك النسوة وامرأة العزيز معهن و { قال } لهن { ما خطبكن } أي شأنكن وأمركن { إذ راودتن يوسف عن نفسه } إنما خاطب الملك جميع النسوة بهذا الخطاب ،   والمراد بذلك امرأة العزيز وحدها ليكون أستر لها وقيل إن امرأة العزيز راودته عن نفسه وحدها وسائر النسوة أمرنه بطاعتها فلذلك خاطبهن بهذا الخطاب { قلن } يعني النسوة جميعاً مجيبات للملك { حاش لله } يعني معاذ الله { ما علمنا عليه من سوء } يعني من خيانة في شيء من الأشياء { قالت امرأة العزيز الآن حصحص الحق } يعني ظهر وتبين وقيل إن النسوة أقبلن على امرأة العزيز فعزرنها وقيل خافت أن يشهد عليها فأقرت فقالت { أنا راودته عن نفسه وإنه لمن الصادقين } يعني في قوله هي راودتني عن نفسي .  <br />
