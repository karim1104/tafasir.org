{ فإن كذبوك } يعني هؤلاء اليهود { فقد كذب رسل من قبلك } يعني مثل نوح وهود وصالح وإبراهيم وغيرهم من الرسل { جاؤوا بالبينات } يعني بالدلالات الواضحات والمعجزات الباهرات { والزبر } أي الكتب واحدها زبور وكل كتاب فيه حكمة فهو زبور وأصله من الزبر وهو الزجر وسمي الكتاب الذي فيه الحكمة زبوراً لأنه يزبر عن الباطل ويدعو إلى الحق { والكتاب المنير } أي الواضح المضيء وإنما عطف الكتاب المنير على الزبر لشرفه وفضله وقيل أراد بالزبر الصحف وبالكتاب المنير التوراة والإنجيل .  <br />
