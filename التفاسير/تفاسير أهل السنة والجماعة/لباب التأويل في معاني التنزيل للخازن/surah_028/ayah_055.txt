{ وإذ سمعوا اللغو } أي القول القبيح { أعرضوا عنه } وذلك أن المشركين كانوا يسبون مؤمني أهل مكة ويقولون تباً لكم تركتم دينكم فيعرضون عنهم ولا يردون عليهم { وقالوا لنا أعمالنا ولكم أعمالكم } أي لنا ديننا ولكم دينكم { سلام عليكم } ليس المراد منه سلام التحية ولكن سلام المتاركة والمعنى سلمتم منا لا نعارضكم بالشتم { لا نبتغي الجاهلين } يعني لا نحب دينكم الذي أنتم عليه .   وقيل : لا نريد أن نكون من أهل الجهل والسفه وهذا قبل أن يؤمر المسلمون بالقتال ثم نسخ ذلك بالقتال .  <br />
