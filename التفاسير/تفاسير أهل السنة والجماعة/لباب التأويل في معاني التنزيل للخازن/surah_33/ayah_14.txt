{ ولو دخلت عليهم في أقطارها } يعني لو دخل هؤلاء الجيوش الذين يريدون قتالهم وهم الأحزاب من نواحي المدينة وجوانبها { ثم سئلوا الفتنة } أي الشرك { لأتوها } أي لجاؤوها وفعلوها ورجعوا عن الإسلام { وما تلبثوا بها } أي ما احتبسوا عن الفتنة { إلا يسيرا } أي لأسرعوا الإجابة إلى الشرك طيبة به نفوسهم ،   وقيل معناه وما أقاموا بالمدينة بعد إعطاء الكفر إلا قليلا حتى يهلكوا .  <br />
