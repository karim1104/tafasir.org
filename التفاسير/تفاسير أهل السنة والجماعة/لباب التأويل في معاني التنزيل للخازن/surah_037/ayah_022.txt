{ احشروا } أي اجمعوا { الذين ظلموا } أي أشركوا وقيل هو عام في كل ظالم { وأزواجهم } أي أشباههم وأمثالهم فكل طائفة مع مثلها فأهل الخمر مع أهل الخمر وأهل الزنا مع أهل الزنا وقيل أزواجهم أي قرناءهم من الشياطين يقرن كل كافر مع شيطانه في سلسلة وقيل أزواجهم المشركات { وما كانوا يعبدون } .  <br />
