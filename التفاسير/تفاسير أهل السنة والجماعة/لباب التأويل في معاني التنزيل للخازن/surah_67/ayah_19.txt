قوله عز وجل : { أولم يروا إلى الطير فوقهم صافات } أي باسطات أجنحتهن في الجو عند طيرانها { ويقبضن } أي يضممن أجنحتهن إذا ضربن بهن جنوبهن بعد البسط { ما يمسكهن } أي حال القبض والبسط { إلا الرحمن } والمعنى : أن الطير مع ثقلها وضخامة جسمها ،   لم يكن بقاؤها وثبوتها في الجو إلا بإمساك الله عز وجل إياها وحفظه لها { إنه بكل شيء بصير } يعني أنه تعالى لا تخفى عليه خافية .  <br />
