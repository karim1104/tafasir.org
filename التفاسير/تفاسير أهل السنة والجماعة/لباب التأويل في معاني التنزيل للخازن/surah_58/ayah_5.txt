قوله عز وجل : { إن الذين يحادون الله ورسوله } أي يعادون الله ورسوله ويشاقون ويخالفون أمرهما ،   { كبتوا } أي ذلوا وأخزوا وأهلكوا { كما كبت الذين من قبلهم } أي كما أخزي من كان قبلهم من أهل الشرك ،   { وقد أنزلنا آيات بينات } يعني فرائض وأحكاماً .   { وللكافرين } أي الذين لم يعملوا بها وجحدوها { عذاب مهين } .  <br />
