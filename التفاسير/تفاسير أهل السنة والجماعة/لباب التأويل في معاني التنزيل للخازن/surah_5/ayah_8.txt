وقوله عز وجل : { يا أيها الذين آمنوا كونوا قوامين لله } قال ابن عباس يريد أنهم يقومون لله بحقه ومعنى ذلك : هو أن يقوم لله بالحق في كل ما يلزمه القيام به من العمل بطاعته واجتناب نواهيه { شهداء بالقسط } يعني وتشهدون بالعدل يقول لا تحابِ في شهادتك أهل ودِّك وقرابتك ولا تمنع شهادتك أهل بغضك وأعداءك أقم شهادتك لهم وعليهم بالصدق والعدل .  <br />
{ ولا يجرمنكم شنآن قوم } ولا يحملنكم بغض قوم { على ألا تعدلوا } على ترك العدل فيهم لعدوانهم { اعدلوا } أمر الله بالعدل في كل أحد القريب والبعيد والصديق والعدو { هو أقرب للتقوى } أي العدل أقرب للتقوى { واتقوا الله إن الله خبير بما تعملون } أن الله تعالى خبير بجميع أعمالكم مطلع عليها وخبير بمن عدل ومن لم يعدل .  <br />
