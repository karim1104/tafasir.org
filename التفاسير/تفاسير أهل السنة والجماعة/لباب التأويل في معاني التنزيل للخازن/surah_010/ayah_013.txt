قوله سبحانه وتعال : { ولقد أهلكنا القرون من قبلكم } يعني أهلكنا الأمم الماضية من قبلكم يخوف بذلك كفارة مكة { لما ظلموا } يعني لما أشركوا { وجاءتهم رسلهم بالبينات } يعني فكذبوهم { وما كانوا ليؤمنوا } يعني : هذه الأمم برسلهم ويصدقوهم بما جاؤوا به من عند الله { كذلك نجزي القوم المجرمين } يعني : كما أهلكنا الأمم الخالية لما كذبوا رسلهم كذلك نهلككم أيها المشركون بتكذيبكم محمداً صلى الله عليه وسلم .  <br />
