{ قالت رسلهم } يعني مجيبين لأممهم { أفي الله شك } يعني وهل تشكون في الله وهو استفهام إنكار ونفي لما اعتقدوه { فاطر السموات والأرض } يعني وهل تشكون في كونه خالق السموات والأرض وخالق جميع ما فيهما { يدعوكم ليغفر لكم من ذنوبكم } يعني ليغفر لكم ذنوبكم إذا آمنتم وصدقتم وحرف ( من ) صلة وقيل : إنها أصل ليست بصلة ،   وعلى هذا إنه يغفر لهم ما بينهم وبينه من الكفر والمعاصي دون مظالم العباد { ويؤخركم إلى أجل مسمى } يعني إلى حين انقضاء آجالكم فلا يعاجلكم بالعذاب { قالوا } يعني الأمم مجيبين للرسل { إن أنتم } يعني ما أنتم { إلا بشر مثلنا } يعني في الصورة الظاهرة لستم ملائكة { تريدون أن تصدونا عما كان يعبد آباؤنا } يعني ما تريدون بقولكم : هذا إلا صدنا عن آلهتنا التي كان آباؤنا يعبدونها { فأتونا بسلطان مبين } يعني حجة بينة واضحة على صحة دعواكم .  <br />
