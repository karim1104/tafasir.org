{ ذلك } أي الذي نزل بهم من العذاب { بأنه كانت تأتيهم رسلهم بالبينات فقالوا أبشر يهدوننا } معناه أنهم أنكروا أن يكون الرسول بشراً وذلك لقلة عقولهم وسخافة أحلامهم ولم ينكروا أن يكون معبودهم حجراً { فكفروا } أي جحدوا وأنكروا { وتولوا } أي أعرضوا { واستغنى الله } أي عن إيمانهم وعبادتهم { والله غني } أي عن خلقه { حميد } أي في أفعاله ثم أخبر الله تعالى عن إنكارهم البعث .  <br />
