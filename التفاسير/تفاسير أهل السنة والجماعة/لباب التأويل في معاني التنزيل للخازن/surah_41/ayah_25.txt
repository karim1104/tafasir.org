{ وقيضنا لهم } أي بعثنا ووكلنا وقيل هيأنا لهم وسببنا لهم { قرناء } أي نظراء من الشياطين حتى أضلوهم { فزينوا لهم ما بين أيديهم } أي من أمر الدنيا حتى آثروهم على الآخرة { وما خلفهم } أي فدعوهم إلى التكذيب بالآخرة وإنكار البعث وقيل حسنوا لهم أعمالهم القبيحة الماضية والمستقبلة { وحق عليهم القول } أي وجب { في أمم } أي مع أمم { قد خلت من قبلهم من الجن والإنس إنهم كانوا خاسرين } .  <br />
