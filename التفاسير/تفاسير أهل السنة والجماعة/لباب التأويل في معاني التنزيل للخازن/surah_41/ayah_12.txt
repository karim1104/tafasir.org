وقوله تعالى : { فقضاهن سبع سموات } أي أتمهن وفرغ من خلقهن { في يومين } وهما الخميس والجمعة { وأوحى في كل سماء أمرها } قال ابن عباس خلق في كل سماء خلقاً من الملائكة وخلق ما فيها من البحار وجبال البرد وما لا يعلمه إلا الله تعالى وقيل أوحى إلى كل سماء ما أراد من الأمر والنهي { وزينا السماء الدنيا } أي التي تلي الأرض { بمصابيح } أي بكواكب تشرق كالمصابيح { وحفظاً } أي وجعلناها يعني الكواكب حفظاً للسماء من الشياطين الذين يسترقون السمع { ذلك } أي الذي ذكر من صنعه وخلقه { تقدير العزيز } أي في ملكه { العليم } أي بخلقه وفيه إشارة إلى كمال القدرة والعلم .  <br />
