{ إنما تعبدون من دون الله أوثاناً وتخلقون إفكاً } أي تقولون كذباً وقيل تصنعون أصناماً بأيديكم وتسمونها آلهة { إن الذين تعبدون من دون الله لا يملكون لكم رزقاً } أي لا يقدرون أن يرزقوكم { فابتغوا } أي فاطلبوا { عند الله الرزق } فإنه القادر على ذلك { واعبدوه } أي وحدوه { واشكروا له } لأنه المنعم عليكم الرزق { إليه ترجعون } أي في الآخرة .  <br />
