قوله تعالى : { وإذا تتلى عليهم آياتنا بينات } أي دلائل واضحات { قال الذين كفروا } يعني النضر بن الحارث ومن دونه من كفار قريش { للذين آمنوا } يعني فقراء أصحاب رسول الله صلى الله عليه وسلم وكانت فيهم قشافة وفي عيشهم خشونة وفي ثيابهم رثاثة ،   وكان المشركون يرجلون شعورهم ويدهنون رؤوسهم ويلبسون أفخر ثيابهم { أي الفريقين خير مقاماً } أي منزلاً ومسكناً وهو موضع الإقامة { وأحسن ندياً } أي مجلسا .  <br />
