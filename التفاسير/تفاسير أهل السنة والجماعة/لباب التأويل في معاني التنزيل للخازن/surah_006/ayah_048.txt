قوله عز وجل : { وما نرسل المرسلين إلا مبشرين } يعني لمن آمن بالثواب { ومنذرين } يعني لمن أقام على كفره بالعقاب والمعنى ليس في إرسالهم أن يأتوا الناس بما يقترحون عليهم من الآيات إنما أرسلوا بالبشارة والنذارة { فمن آمن وأصلح } يعني آمن بهم وأصلح العمل لله { فلا خوف عليهم } يعني حين يخاف أهل النار { ولا هم يحزنون } أي إذا حزن غيرهم .  <br />
