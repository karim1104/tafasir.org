{ وأنذر الناس } يعني وخوف الناس يا محمد بيوم القيامة وهو قوله سبحانه وتعالى { يوم يأتيهم العذاب فيقول الذين ظلموا } يعني ظلموا أنفسهم بالشرك والمعاصي { ربنا أخرنا إلى أجل قريب } يعني أمهلنا مدة يسيرة قال بعضهم : طلبوا الرجوع إلى الدنيا حتى يؤمنوا فينفعهم ذلك وهو قوله تعالى { نجب دعوتك ونتبع الرسل } فأجيبوا بقوله { أولم تكونوا أقسمتم من قبل } يعني في دار الدنيا { مالكم من زوال } يعني ما لكم عنها انتقال ولا بعث ولا نشور .  <br />
