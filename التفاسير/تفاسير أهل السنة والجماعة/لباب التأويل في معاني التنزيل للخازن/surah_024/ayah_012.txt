قوله عزّ وجلّ : { لولا إذ سمعتموه } يعني الحديث الكذب وهو قول أهل الإفك { ظن المؤمنون والمؤمنات بأنفسهم } بإخوانهم وأهل دينهم { خيراً } والمعنى كان الواجب على المؤمنين إذ سمعوا قول أهل الإفك أن يكذبوه ويحسنوا الظن ولا يسرعوا في التهمة وقول الزور فيمن عرفوا عفته وطهارته وفيه معاتبة للمؤمنين { وقالوا هذا إفك مبين } يعني كذب بين لا حقيقة له .  <br />
