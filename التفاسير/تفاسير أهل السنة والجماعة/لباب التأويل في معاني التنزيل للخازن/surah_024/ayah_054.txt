{ قل أطيعوا الله وأطيعوا الرسول } يعني بقلوبكم وصدق نياتكم { فإن تولوا } يعني أعرضوا عن طاعة الله ورسوله { فإنما عليه } أي على الرسول { ما حمل } أي ما كلف وأمر به من تبليغ الرسالة { وعليكم ما حملتم } أي ما كلفتم من الإجابة والطاعة { وإن تطيعوه تهتدوا } أي تصيبوا الحق والرشد في طاعته { وما على الرسول إلا البلاغ المبين } أي التبليغ الواضح البين .  <br />
