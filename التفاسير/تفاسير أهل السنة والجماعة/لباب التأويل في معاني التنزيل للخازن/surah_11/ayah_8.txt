{ ولئن أخرنا عنهم العذاب إلى أمة معدودة } يعني إلى أجل محدود وأصل الأمة في اللغة الجماعة من الناس فكأنه قال سبحانه وتعالى إلى انقراض أمة ومجيء أمة أخرى { ليقولن ما يحبسه } يعني : أي شيء يحبس العذاب وإنما يقولون ذلك استعجالاً بالعذاب واستهزاء يعنون أنه ليس بشي قال الله عز وجل : { ألا يوم يأتيهم } يعني العذاب { ليس مصروفاً عنهم } أي لا يصرفه عنهم شيء { وحاق بهم ما كانوا به يستهزئون } يعني ونزل بهم وبال استهزائهم .  <br />
