قوله تعالى : { وأمر أهلك } أي قومك وقيل من كان على دينك { بالصلاة } يعني بالمحافظة عليها { واصطبر عليها } يعني اصبر على الصلاة فإنها تنهى عن الفحشاء والمنكر وقيل اصبر عليها فإن الوعظ بلسان الفعل أبلغ منه بلسان القول { لا نسألك رزقاً } أي لا نكلفك أن ترزق أحداً من خلقنا ولا أن ترزق نفسك بل نكلفك عملاً { نحن نرزقك } أي بل نحن نرزقك ونرزق أهلك { والعاقبة للتقوى } أي الخصلة المحمودة لأهل التقوى قال ابن عباس الذين صدقوك واتبعوك وآمنوا بك وفي بعض المسانيد أن النبي صلى الله عليه وسلم كان إذا أصاب أهله ضر أمرهم بالصلاة وتلا هذه الآية قوله تعالى .  <br />
