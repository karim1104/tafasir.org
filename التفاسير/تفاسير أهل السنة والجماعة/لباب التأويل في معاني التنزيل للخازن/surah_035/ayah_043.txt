{ استكباراً في الأرض } يعني عتواً وتكبراً عن الإيمان به { ومكر السيئ } يعني عمل القبيح وهو اجتماعهم على الشرك وقيل هو مكرهم برسول الله صلى الله عليه وسلم { ولا يحيق المكر السيئ إلا بأهله } يعني لا يحل ولا يحيط إلا بأهله فقتلوا يوم بدر قال ابن عباس عاقبة الشرك لا تحل إلا بمن أشرك { فهل ينظرون } أي ينظرون { إلا سنة الأولين } يعني أن ينزل العذاب بهم كما نزل بمن مضى من الكفار { فلن تجد لسنة الله تبديلاً } أي تغييراً { ولن تجد لسنة الله تحويلاً } أي تحويل العذاب عنهم إلى غيرهم .  <br />
