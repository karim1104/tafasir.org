{ كذبت قبلهم قوم نوح والأحزاب من بعدهم } يعني الكفار الذين تحزبوا على أنبيائهم بالتكذيب من بعد قوم نوح { وهمت كل أمة برسولهم ليأخذوه } قال ابن عباس ليقتلوه ويهلكوه وقيل ليأسروه { وجادلوا } يعني خاصموا { بالباطل ليدحضوا } يعني ليبطلوا { به الحق } الذي جاءت به الرسل { فأخذتهم فكيف كان عقاب } يعني أنزلت بهم من الهلاك ما هموا هم بإنزاله بالرسل وقيل معناه فكيف كان عقابي إياهم أليس كان مهلكاً مستأصلاً .  <br />
