{ قال إنه يقول إنها بقرة لا ذلول } أي ليست مذللة بالعمل ،   { تثير الأرض } أي تقلبها للزراعة { ولا تسقي الحرث } أي ليست بسنانية والسانية هي التي تستسقي الماء من البئر لسقي الأرض { مسلمة } أي بريئة من العيوب ،   { لا شية فيها } أي لا لون فيها غير لونها  ،  { قالوا الآن جئت بالحق } أي بالبيان التام الذي لا إشكال فيه فطلبوها فلم يجدوا بقرة بكمال وصفها ،   إلا بقرة ذلك الفتى فاشتروها منه بملء مسكها ذهباً .   { فذبحوها وما كادوا يفعلون } أي وما قاربوا أن يفعلوا ما أمروا به ،   قيل لغلاء ثمنها وقيل : لخوف الفضيحة وقيل : لعزة وجودها بهذه الأوصاف جميعاً .  <br />
