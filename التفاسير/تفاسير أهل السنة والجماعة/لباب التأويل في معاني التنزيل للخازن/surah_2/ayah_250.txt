قوله عز وجل : { ولما برزوا } يعني طالوت وجنوده المؤمنين { لجالوت وجنوده } يعني الكافرين ومعنى برزوا صاروا بالبراز من الأرض وهو ما ظهر واستوى منها { قالوا } يعني المؤمنين أصحاب طالوت { ربنا أفرغ } أي اصبب { علينا صبراً وثبت أقدامنا } أي قو قلوبنا لتثبت أقدامنا { وانصرنا على القوم الكافرين } وذلك أن جالوت وقومه كانوا يعبدون الأصنام فسأل المؤمنون الله أن ينصرهم على القوم الكافرين .  <br />
