قوله عز وجل : { وإذ أخذنا ميثاقكم } قيل : هو خطاب لمن كان في زمن النبي صلى الله عليه وسلم من اليهود وقيل : هو خطاب لآبائهم وفيه تقريع لهم { لا تسفكون } أي لا تريقون { دماءكم } أي لا يسفك بعضكم دم بعض وقيل : معناه لا تسفكوا دماء غيركم فيسفك دماءكم فكأنكم أنتم سفكتم دماء أنفسكم { ولا تخرجون أنفسكم من دياركم } أي لا يخرج بعضكم بعضاً من داره ،   وقيل : لا تفعلوا شيئاً فتخرجوا بسببه من دياركم { ثم أقررتم } أي بهذا العهد أنه حق { وأنتم تشهدون } يعني أنتم يا معشر اليهود اليوم تشهدون على ذلك .  <br />
