قوله عز وجل : { إن الذين آمنوا } يعني صدقوا بالله ورسوله { وعملوا الصالحات } يعني التي أمرهم الله بها { وأقاموا الصلاة } يعني المفروضة بأركانها وحدودها في أوقاتها { وآتوا الزكاة } يعني المفروضة عليهم في أموالهم { لهم أجرهم عند ربهم } أي لهم ثواب أعمالهم في الآخرة { ولا خوف عليهم ولا هم يحزنون } أي يوم القيامة .  <br />
