{ قالوا } يعني الملائكة { سبحانك } تنزيهاً لك وذلك لما ظهر عجزهم { لا علم لنا إلاّ ما علمتنا } أي إنك أجل من نحيط بشيء من علمك إلاّ ما علمتنا { إنك أنت العليم } أي بخلقك وهو من أسماء الصفات التامة وهو المحيط بكل المعلومات { الحكيم } أي في أمرك ،   وله معنيان أحدهما أنه القاضي العدل والثاني المحكم للأمر كيلا يتطرق إليه الفساد .  <br />
