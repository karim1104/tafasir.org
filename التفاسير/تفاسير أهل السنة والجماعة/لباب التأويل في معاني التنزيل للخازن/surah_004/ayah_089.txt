قوله عز وجل : { ودوا } يعني تمنى أولئك الذين رجعوا عن الإيمان إلى الارتداد والكفر { لو تكفرون } يعني تكفرون أنتم يا معشر المؤمنين { كما كفروا فتكونون سواء } في الكفر { فلا تتخذوا منهم أولياء } يعني من الكفار  ،   منع المؤمنين من موالاتهم { حتى يهاجروا } يعني يسلموا أو يهاجروا { في سبيل الله } معكم وهي هجرة أخرى والهجرة على ثلاثة أوجه : <br />
الأولى هجرة المؤمنين في أول الإسلام من مكة إلى المدينة .   الثانية هجرة المؤمنين وهي الخروج مع رسول الله صلى الله عليه وسلم في سبيل الله مخلصين صابرين محتسبين كما حكى الله عنهم  ،   وفي هذه الآية منع المؤمنين من موالاة المنافقين حتى يهاجروا  ،   <br />
والهجرة الثالثة هجرة المؤمنين ما نهى الله عنه بقوله { فإن تولوا } يعني فإن أعرضوا عن الإسلام والهجرة  ،  واختاروا الإقامة على الكفر { فخذوهم } الخطاب للمؤمنين أي خذوهم أيها المؤمنون { واقتلوهم حيث وجدتموهم } يعني إن وجدتموهم في الحل والحرم { ولا تتخذوا منهم ولياً } يعني في هذه الحالة { ولا نصيراً } يعني ينصركم على أعدائكم لأنهم أعداء .  <br />
