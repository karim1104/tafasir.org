{ فلولا } يعني فهلا { نصرهم الذين اتخذوا من دون الله قرباناً آلهة } يعني أنهم اتخذوا الأغنام آلهة يتقربون بعبادتها إلى الله تعالى والقربان كل ما يتقرب به إلى الله تعالى : { بل ضلوا عنهم } يعني بل ضلت الآلهة عنهم فلم تنفعهم عند نزول العذاب بهم { وذلك إفكهم } يعني كذبهم الذي كانوا يقولون إنها تقربهم إلى الله تعالى وتشفع لهم عنده { وما كانوا يفترون } يعني يكذبون بقولهم إنها آلهة وإنها تشفع لهم .  <br />
