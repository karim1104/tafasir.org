{ وأقسموا بالله جهد أيمانهم } يعني كفار مكة وذلك لما بلغهم أن أهل الكتاب كذبوا رسلهم قالوا لعن الله اليهود والنصارى أتتهم الرسل فكذبوهم وأقسموا بالله لو جاءنا نذير لنكونن أهدى ديناً منهم وذلك قبل مبعث النبي صلى الله عليه وسلم فلما بعث محمد كذبوه فأنزل الله هذه الآية { وأقسموا بالله جهد أيمانهم } { لئن جاءهم نذير } يعني رسول { ليكونن أهدى من إحدى الأمم } يعني اليهود والنصارى { فلما جاءهم نذير } يعني محمداً صلى الله عليه وسلم { ما زادهم } مجيئه { إلا نفوراً } يعني تباعدا عن الهدى .  <br />
