قوله عز وجل { ولو ترى إذ المجرمون } أي المشركون { ناكسو رؤوسهم عند ربهم } أي يطأطئونها حياء من ربهم وندماً على ما فعلوا عند ربهم يقولون { ربنا أبصرنا } أي ما كنا به مكذبين { وسمعنا } يعني منك تصديق ما أتتنا به رسلك وقيل أبصرنا معاصينا وسمعنا ما قيل فيها { فارجعنا } أي فارددنا إلى الدنيا { نعمل صالحاً إنا موقنون } أي في الحال آمنا ولكن لا ينفع ذلك الإيمان .  <br />
