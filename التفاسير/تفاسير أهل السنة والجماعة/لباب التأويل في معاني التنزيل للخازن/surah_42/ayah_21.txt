قوله تعالى : { أم لهم } يعني كفار مكة { شركاء } يعني الأصنام وقيل الشياطين { شرعوا لهم ديناً من الدين } قال ابن عباس شرعوا لهم غير دين الإسلام { ما لم يأذن به الله } يعني أن تلك الشرائع بأسرها على خلاف دين الله تعالى الذي أمر به وذلك أنهم زينوا لهم الشرك وإنكار البعث والعمل للدنيا لأنهم لا يعلمون غيرها { ولولا كلمة الفصل } يعني أن الله حكم بين الخلق بتأخير العذاب عنهم إلى يوم القيامة { لقضي بينهم } أي لفرغ من عذاب الذين يكذبونك في الدنيا { وإن الظالمين } يعني المشركين { لهم عذاب أليم } أي في الآخرة .  <br />
