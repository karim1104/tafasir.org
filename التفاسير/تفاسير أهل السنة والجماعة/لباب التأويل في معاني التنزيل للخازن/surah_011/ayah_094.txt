{ ولما جاء أمرنا } يعني بعذابهم وإهلاكهم { نجينا شعيباً والذين آمنوا معه برحمة منا } يعني بفضل منا بأن هديناهم للإيمان ووفقناهم للطاعة { وأخذت الذين ظلموا } يعني ظلموا أنفسهم بالشرك والبخس { الصيحة } وذلك أن جبريل عليه السلام صاح بهم صيحة فخرجت أرواحهم وماتوا جميعاً ،   وقيل : أتتهم صيحة واحدة من السماء فماتوا جميعاً { فأصبحوا في ديارهم جاثمين } يعني ميتين وهو استعارة من قولهم جثم الطير إذا قعد ولطأ بالأرض .  <br />
