وقوله تعالى : { ويا يوم لا يجرمنكم شقاقي } أي لا يحملنكم خلافي وعداوتي { أن يصيبكم } يعني عذاب العاجلة على كفركم وأفعالكم الخبيثة { مثل ما أصاب قوم نوح } يعني الغرق { أو قوم هود } يعني الريح التي أهلكتهم { أو قوم صالح } يعني ما أصابهم من الصيحة حتى هلكوا جميعاً { وما قوم لوط منكم ببعيد } وذلك أنهم كانوا حديثي عهد بهلاكهم وقيل معناه وما ديار قوم لوط منكم ببعيد وذلك أنهم كانوا جيران قوم لوط وبلادهم قريبة من بلادهم .  <br />
