{ كل نفس ذائقة الموت } هذا العموم مخصوص بقوله تعالى : تعلم ما في نفسي ولا أعلم ما في نفسك فإن الله تعالى حي لا يموت ولا يجوز عليه الموت .   والذوق هاهنا عبارة عن مقدمات الموت وآلامه العظيمة قبل حلوله { ونبلوكم } أي نختبركم { بالشر والخير } أي بالشدة والرخاء والصحة والسقم والغنى والفقر ،   وقيل مما تحبون وما تكرهون { فتنة } أي ابتلاء لننظر كيف شكركم فيما تحبون وصبركم فيما تكرهون { وإلينا ترجعون } أي للحساب والجزاء .  <br />
