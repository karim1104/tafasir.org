{ لاهية قلوبهم } أي ساهية معرضة غافلة عن ذكر الله { وأسروا النجوى الذين ظلموا } أي بالغوا في إخفاء التناجي وهم الذين أشركوا ثم بين سرهم الذي تناجوا به ،   فقال تعالى مخبراً عنهم { هل هذا إلا بشر مثلكم } يعني أنهم أنكروا إرسال البشر وطلبوا إرسال الملائكة والأولى إرسال البشر إلى البشر لأن الإنسان إلى القبول من أشكاله أقرب { أفتأتون السحر } يعني أتحضرون السحر وتقبلونه { وأنتم تبصرون } يعني تعلمون أنه سحر .  <br />
