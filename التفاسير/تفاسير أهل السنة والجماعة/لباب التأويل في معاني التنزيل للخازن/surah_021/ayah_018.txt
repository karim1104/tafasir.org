{ بل } يعني دع ذلك الذي قالوا فإنه كذب وباطل { نقذف } يعني نرمي ونسلط { بالحق } يعني بالإيمان { على الباطل } يعني على الكفر ،   وقيل الحق قول الله أنه لا ولد له والباطل قولهم اتخذ الله ولداً { فيدمغه } فيهلكه { فإذا هو زاهق } يعني ذاهب والمعنى أنا نبطل كذبهم بما نبين من الحق حتى يذهب ويضمحل ،   ثم أوعدهم على كذبهم فقال تعالى { ولكم الويل } يا معشر الكفار { مما تصفون } الله بما لا يليق من الصحابة والولد .  <br />
