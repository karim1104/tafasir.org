ثم أخبر الله عن حال المنافقين فقال تعالى : { لئن أخرجوا لا يخرجون معهم ولئن قوتلوا لا ينصرونهم } وكان الأمر كذلك فإنهم أخرجوا ولم يخرج المنافقون معهم وقوتلوا فلم ينصروهم { ولئن نصروهم ليولن الأدبار } يعني لو قدروا نصرهم أو لو قصدوا نصر اليهود لولوا الأدبار منهزمين { ثم لا ينصرون } يعني بني النضير لا يصيرون منصورين إذا انهزم ناصروهم .  <br />
