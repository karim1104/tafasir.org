{ وإن منكم لمن ليبطئن } نزلت في المنافقين .   وإنما قال منكم لاجتماعهم مع أهل الإيمان في الجنسية والنسب وإظهار كلمة الإسلام لا في حقيقة الإيمان والمعنى وإن منكم لمن ليتأخرن وليتثاقلن عن الجهاد وهو عبد الله بن أبي ابن سلول المنافق وكان رأس المنافقين { فإن أصابتكم مصيبة } أي قتل وهزيمة { قال } يعني هذا المنافق { قد أنعم الله علي } يعني بالقعود { إذا لم أكن معهم } يعني مع المؤمنين { شهيداً } يعني حاضر الوقعة فيصيبني ما أصابهم .  <br />
