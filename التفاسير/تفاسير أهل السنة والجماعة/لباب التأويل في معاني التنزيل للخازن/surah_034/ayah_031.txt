{ وقال الذين كفروا لن نؤمن بهذا القرآن ولا بالذي بين يديه } يعني التوراة والإنجيل { ولو ترى } أي يا محمد { إذ الظالمون موقوفون عند ربهم يرجع بعضهم إلى بعض القول } معناه ولو ترى في الآخرة موقفهم وهم يتجاذبون أطراف المحاورة ويتراجعونها بينهم لرأيت العجب { يقول الذين استضعفوا } وهم الأتباع { للذين استكبروا } وهو القادة والأشراف { لولا أنتم لكنا مؤمنين } يعني أنتم منعتمونا عن الإيمان بالله ورسوله .  <br />
