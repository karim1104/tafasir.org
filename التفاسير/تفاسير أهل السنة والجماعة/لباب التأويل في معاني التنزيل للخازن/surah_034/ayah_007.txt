{ وقال الذين كفروا } أي المنكرين للبعث المتعجبين منه { هل ندلكم } أي قال بعضهم لبعض هل ندلكم { على رجل ينبئكم } يعنون محمداً صلى الله عليه وسلم معناه يحدثكم بأعجوبة من الأعاجيب وهي أنكم { إذا مزقتم كل ممزق } أي قطعتم كل تقطيع وفرقتم كل تفريق ،   وصرتم تراباً { إنكم لفي خلق جديد } أي يقول إنكم تبعثون وتنشئون خلقاً جديداً بعد أن تكونوا رفاتاً وتراباً .  <br />
