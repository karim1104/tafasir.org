قوله تعالى { وقال الذين كفروا لا تأتينا الساعة } معناه أنهم أنكروا البعث وقيل : استبطؤوا ما وعدوه من قيام الساعة على سبيل اللهو والسخرية { قل بلى وربي لتأتينكم } يعني الساعة { عالم الغيب } أي لا يفوت علمه شيء من الخفيات وإذا كان كذلك اندرج في علمه ،   وقت قيام الساعة وأنها آتية { لا يعزب عنه } أي لا يغيب عنه { مثقال ذرة } يعني وزن ذرة { في السموات ولا في الأرض ولا أصغر من ذلك } أي من الذرة { ولا أكبر إلا من كتاب مبين } يعني في اللوح المحفوظ .  <br />
