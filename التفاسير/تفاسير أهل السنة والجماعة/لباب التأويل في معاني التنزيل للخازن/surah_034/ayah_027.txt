{ قل أروني } أعلموني { الذين ألحقتم به } يعني بالله { شركاء } يعني الأصنام التي أشركوها معه في العبادة هل يخلقون أو يرزقون وأراد بذلك أن يريهم الخطأ العظيم في إلحاق الشركاء بالله { كلا } كلمة ردع لهم عن مذهبهم والمعنى ارتدعوا فإنهم لا يخلقون ولا يرزقون { بل هو العزيز } أي الغالب على أمره { الحكيم } أي تدبير خلقه فأنى يكون له شريك في ملكه .  <br />
