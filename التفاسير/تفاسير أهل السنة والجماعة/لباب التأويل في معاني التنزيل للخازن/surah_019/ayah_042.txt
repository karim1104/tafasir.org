{ إذ قال لأبيه } يعني آزر وهو يعبد الأصنام { يا أبت لم تعبد ما لا يسمع } يعني صوتاً { ولا يبصر } لا ينظر شيئاً { ولا يغني عنك } أي يكفيك { شيئاً } وصف الأصنام بثلاثة أشياء كل واحد منها قادح في الإلهية ،   وذلك أن العبادة هي غاية التعظيم للمعبود فلا يستحقها إلا من له ولاية الإنعام وله أوصاف الكمال وهو الله تعالى فلا يستحق العبادة إلا هو .  <br />
