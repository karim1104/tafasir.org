{ قل من كان في الضلالة فليمدد له الرحمن مداً } هذا أمر بمعنى الخبر معناه يدعه في طغيانه ويمهله في كفره { حتى إذا رأوا ما يوعدون إما العذاب } أي الأسر والقتل في الدنيا { وإما الساعة } يعني القيامة فيدخلون النار { فسيعلمون } أي عند ذلك { من هو شر مكاناً } أي منزلاً { وأضعف جنداً } أي أقل ناصراً والمعنى فسيعلمون أهم خير وهم في النار أم المؤمنون وهم في الجنة وهذا رد عليهم في قولهم أي الفريقين خير مقاماً وأحسن ندياً .  <br />
