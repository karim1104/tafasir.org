{ وَقَالَ مُوسَى } قراءة العامة بالواو ،   وقرأ أهل مكة بغير واو ،   وكذلك هو في مصاحفهم { رَبِّي أَعْلَمُ بِمَن جَآءَ بِالْهُدَى مِنْ عِندِهِ } بالمحق من المبطل { وَمَن تَكُونُ لَهُ } ( قرأ ) بالياء أهل الكوفة والباقون بالتاء .   { عَاقِبَةُ الدَّارِ } أي العقبى المحمودة في الدار الآخرة { إِنَّهُ لاَ يُفْلِحُ الظَّالِمُونَ } لا ينجح الكافرون .  <br />
