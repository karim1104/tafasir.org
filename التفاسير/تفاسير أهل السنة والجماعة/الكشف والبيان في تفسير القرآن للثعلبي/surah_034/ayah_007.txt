{ وَقَالَ الَّذِينَ كَفَرُواْ } منكرين للبعث متعجبين منه : { هَلْ نَدُلُّكُمْ عَلَى رَجُلٍ يُنَبِّئُكُمْ } : يخبركم ،   يعنون : محمداً ( عليه السلام ) { إِذَا مُزِّقْتُمْ } : قطعتم وفرقتم { كُلَّ مُمَزَّقٍ } وصرتم رفاتاً { إِنَّكُمْ } بالكسر على الابتداء والحكاية ،   مجازة يقول لكم : { إِنَّكُمْ لَفِي خَلْقٍ جَدِيدٍ } .  <br />
