{ وَإِذَا تُتْلَى عَلَيْهِمْ آيَاتُنَا بَيِّنَاتٍ قَالُواْ مَا هَذَا } يعني محمداً( عليه السلام ) { إِلاَّ رَجُلٌ يُرِيدُ أَن يَصُدَّكُمْ عَمَّا كَانَ يَعْبُدُ آبَآؤُكُمْ وَقَالُواْ مَا هَذَآ إِلاَّ إِفْكٌ مُّفْتَرًى } يعنون القرآن { وَقَالَ الَّذِينَ كَفَرُواْ لِلْحَقِّ لَمَّا جَآءَهُمْ إِنْ هَذَآ إِلاَّ سِحْرٌ مُّبِينٌ }<br />
