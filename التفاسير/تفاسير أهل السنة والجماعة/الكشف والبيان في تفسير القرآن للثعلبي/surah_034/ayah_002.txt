قوله : { يَعْلَمُ مَا يَلِجُ فِي الأَرْضِ } يدخل ويغيب فيها من الماء والموادّ والحيوانات ،   { وَمَا يَخْرُجُ مِنْهَا } من النبات ،   { وَمَا يَنزِلُ مِنَ السَّمَآءِ } من الأمطار ،   { وَمَا يَعْرُجُ } يصعد { فِيهَا } : من الملائكة وأعمال العباد ،   { وَهُوَ الرَّحِيمُ الْغَفُورُ } .  <br />
