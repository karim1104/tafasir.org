{ وَيَقُولُونَ مَتَى هَذَا الْوَعْدُ إِن كُنتُمْ صَادِقِينَ * قُل لَّكُم مِّيعَادُ يَوْمٍ لاَّ تَسْتَأْخِرُونَ عَنْهُ سَاعَةً وَلاَ تَسْتَقْدِمُونَ * وَقَالَ الَّذِينَ كَفَرُواْ لَن نُّؤْمِنَ بِهَذَا الْقُرْآنِ وَلاَ بِالَّذِي بَيْنَ يَدَيْهِ } من الكتب ،   ثم أخبر عن حالهم في مآلهم ،   فقال : { وَلَوْ تَرَى إِذِ الظَّالِمُونَ } : الكافرون { مَوْقُوفُونَ عِندَ رَبِّهِمْ يَرْجِعُ بَعْضُهُمْ إِلَى بَعْضٍ الْقَوْلَ } يتلاومون ويحاور بعضهم بعضاً { يَقُولُ الَّذِينَ اسْتُضْعِفُواْ لِلَّذِينَ اسْتَكْبَرُواْ لَوْلاَ أَنتُمْ لَكُنَّا مُؤْمِنِينَ }<br />
