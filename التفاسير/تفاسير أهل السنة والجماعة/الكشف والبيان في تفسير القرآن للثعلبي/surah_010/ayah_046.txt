وَإِمَّا نُرِيَنَّكَ } يا محمد في حياتك { بَعْضَ الَّذِي نَعِدُهُمْ } من العذاب { أَوْ نَتَوَفَّيَنَّكَ } قبل ذلك { فَإِلَيْنَا مَرْجِعُهُمْ } في الآخرة { ثُمَّ اللَّهُ شَهِيدٌ عَلَى مَا يَفْعَلُونَ } مجزيهم به .  <br />
