{ ثُمَّ بَدَّلْنَا مَكَانَ السَّيِّئَةِ } وهي البأساء والجواب والجوع { الْحَسَنَةَ } يعني النعمة والسعة والرخاء والخصب { حَتَّى عَفَوْاْ } أي كثروا وأثروا وكثرت أموالهم وأولادهم ،   قال ابن عباس : ( عفوا ) يعني [ جهدوا ] ،   وقال ابن زيد : يعني كثروا كما يكثر النبات والريش .  <br />
قال قتادة : ( حتّى عفوا ) : سروا بذلك ،   وقال مقاتل بن حيان : ( عفوا ) حتى كثروا وتركوا ولم يستكثروا وأصله من الكثرة .  <br />
وقال النبيّ صلى الله عليه وسلم :  "  أحفوا الشوارب وأعفوا اللحى  "  .  <br />
وقال الشاعر :<br />
يقول من بعد أُولاك أولات *** أتوا زماناً ليس عندهم بعيد<br />
وقال آخر :<br />
ولكنا نعض السيف منها *** بأسوق عافيات الشحم كوم<br />
{ وَّقَالُواْ } من جهلهم وغفلتهم { قَدْ مَسَّ آبَاءَنَا الضَّرَّآءُ وَالسَّرَّآءُ } فنحن مثلنا فقال الله تعالى { فَأَخَذْنَاهُمْ بَغْتَةً } [ فجأة عِبرة لمن بعدهم ] .   { وَهُمْ لاَ يَشْعُرُونَ } بنزول العذاب<br />
