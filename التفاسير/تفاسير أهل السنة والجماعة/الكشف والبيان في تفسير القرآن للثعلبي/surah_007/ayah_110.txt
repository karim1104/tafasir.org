{ يُرِيدُ أَن يُخْرِجَكُمْ } [ من القبط ] { مِّنْ أَرْضِكُمْ } مصر { فَمَاذَا تَأْمُرُونَ } هذا من قول فرعون للملأ ولم يذكر فرعون فيه كقوله<br />
{ الآنَ حَصْحَصَ الْحَقُّ } [ يوسف : 51 ]<br />
{ أَنَاْ رَاوَدْتُّهُ عَن نَّفْسِهِ وَإِنَّهُ لَمِنَ الصَّادِقِينَ * ذلِكَ لِيَعْلَمَ أَنِّي لَمْ أَخُنْهُ بِالْغَيْبِ } [ يوسف : 51-52 ] هذا من كلام يوسف ولم يذكر
