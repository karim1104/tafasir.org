{ تِلْكَ الْقُرَى } هذه القرى التي ذكرت لك وأهلكناهم وهي قرى نوح وعاد وثمود وقوم لوط وشعيب { نَقُصُّ عَلَيْكَ مِنْ أَنبَآئِهَا } نخبرك أخبارها { وَلَقَدْ جَآءَتْهُمْ رُسُلُهُم بِالْبَيِّنَاتِ } [ بالآيات والعلامات والدلالات ] { فَمَا كَانُواْ لِيُؤْمِنُواْ بِمَا كَذَّبُواْ مِن قَبْلُ } اختلف في تأويله .  <br />
قال أُبي بن كعب : معناه فما كانوا ليؤمنوا عند مجئ الرسل بما سبق في علم الله أنّهم يكذّبون به يوم أقرّوا له بالميثاق حين أخرجهم من صلب آدم .  <br />
وقال ابن عباس والسدي : يعني فما كان هؤلاء الكفار الذين أهلكناهم ليؤمنوا عند إرسال الرسل بما كذبوا من قبل يوم أخذ ميثاقهم حتّى أخرجهم من ظهر آدم فآمنوا كرهاً وأقروا باللسان وأظهروا التكذيب .  <br />
وقال مجاهد : معناه فما كانوا لو أحييناهم بعد هلاكهم ورددناهم إلى الدنيا ليؤمنوا بما كذبوا به من قبل هلاكهم كقوله<br />
{ وَلَوْ رُدُّواْ لَعَادُواْ لِمَا نُهُواْ عَنْهُ } [ الأنعام : 28 ] وقال يمان بن رئاب : هذا معنى أنّ كلّ نبي أخذ قومه بالعذاب ما كانوا ليؤمنوا بما كذب به أوائلهم من الأُمم الكفار بل كذّبوا كما كذب نظير قوله<br />
{ كَذَلِكَ مَآ أَتَى الَّذِينَ مِن قَبْلِهِمْ مِّن رَّسُولٍ إِلاَّ قَالُواْ سَاحِرٌ أَوْ مَجْنُونٌ * أَتَوَاصَوْاْ بِهِ } [ الذاريات : 52-53 ] .  <br />
وقيل : معناه : { وَلَقَدْ جَآءَتْهُمْ رُسُلُهُم بِالْبَيِّنَاتِ } يعني بالمعجزات والعجائب التي سألوهم فما كانوا ليؤمنوا بعد ما رأوا الآيات والعجائب بما كذبوا به من قبل رؤيتهم تلك العجائب نظيره قوله<br />
{ قَدْ سَأَلَهَا قَوْمٌ مِّن قَبْلِكُمْ ثُمَّ أَصْبَحُواْ بِهَا كَافِرِينَ } [ المائدة : 102 ]<br />
{ وَمَا مَنَعَنَآ أَن نُّرْسِلَ بِالآيَاتِ إِلاَّ أَن كَذَّبَ بِهَا الأَوَّلُونَ } [ الإسراء : 59 ] .  <br />
{ كَذَلِكَ يَطْبَعُ اللَّهُ عَلَى قُلُوبِ الْكَافِرِينَ } الذين كتب عليهم أن لا يؤمنون من قومك
