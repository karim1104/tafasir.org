{ وَقَطَّعْنَاهُمُ } يعني بني إسرائيل { اثْنَتَيْ عَشْرَةَ أَسْبَاطاً أُمَماً } روى أبان بن يزيد العطار عن عاصم : وقطعناهم بالتخفيف وأراد بالأسباط القبائل والفرق ولذلك أنشأ العدد والأسباط جمع مذكر .  <br />
قال الشاعر :<br />
وإن قريشاً كلّها عشر أبطن *** وأنت بريءٌ من قبائلها العشر<br />
فذهب بالبطن إلى القبيلة والفصيلة فلذلك كان [ البطن ] مذكر وإنما قال : ( أسباطاً أُمماً ) بالجمع ولا يقال : أتاني اثنا عشر رجالاً ،   لأنه أراد الأعداد والجموع فأقام كل عدد مقام واحد ،   وقيل : معناه وقطعناهم أسباطاً أمماً اثني عشر .  <br />
{ وَأَوْحَيْنَآ إِلَى مُوسَى إِذِ اسْتَسْقَاهُ قَوْمُهُ } في التيه { أَنِ اضْرِب بِّعَصَاكَ الْحَجَرَ } قال عطاء : كان الحجر أربعة وجوه لكل وجه ثلاثة أعين لكل سبط عين لا يُخالطهم سواه { فَانبَجَسَتْ } أخصبت وانفجرت .  <br />
قال أهل التفسير : انبجست وانفجرت واحد ،   وكان أبو عمرو بن العلاء يفرق بينهما فيقول انبجست عرفت وانفجرت [ سالت ] .  <br />
قال عطاء : كان يظهر على كل موضع من الحجر يضربه موسى ( عليه السلام ) مثل ثدي المرأة فيعرق أوّلاً ثمّ يسيل { قَدْ عَلِمَ كُلُّ أُنَاسٍ } من كل سبط { مَّشْرَبَهُمْ } لا يدخل سبط على غيره في شربه وكل سبط من أب واحد .   { وَظَلَّلْنَا عَلَيْهِمُ الْغَمَامَ } في التيه يقيهم من الشمس { وَأَنْزَلْنَا عَلَيْهِمُ الْمَنَّ وَالسَّلْوَى } إلى قوله : { نَّغْفِرْ لَكُمْ خَطِيئَاتِكُمْ } وقرأ أهل المدينة يغفر [ بياء ] مضمومة وخطاياكم بالرفع ،   وقرأ ابن [ عامر ] بتاء مضمومة .  <br />
