{ إِلَى رَبِّكَ يَوْمَئِذٍ الْمُسْتَقَرُّ } أي مستقر الخلق وأعمالهم وكل شي ،   وقال مقاتل : المنتهى فلا يجد عنه مرحلا نظيره<br />
{ وَأَنَّ إِلَى رَبِّكَ الْمُنتَهَى } [ النجم : 42 ] وقال يمان : المصير والمرجع ،   وهو قول ابن مسعود نظيره<br />
{ إِنَّ إِلَى رَبِّكَ الرُّجْعَى } [ العلق : 8 ] و<br />
{ وَإِلَى اللَّهِ الْمَصِيرُ } [ آل عمران : 28 ] وقوله سبحانه<br />
{ أَلاَ إِلَى اللَّهِ تَصِيرُ الأُمُورُ } [ الشورى : 53 ] .
