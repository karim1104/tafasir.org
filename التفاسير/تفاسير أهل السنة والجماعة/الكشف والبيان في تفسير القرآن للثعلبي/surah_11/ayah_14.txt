{ فَإِلَّمْ يَسْتَجِيبُواْ لَكُمْ } لفظه جمع والمراد به الرسول وحده كقوله : { يأَيُّهَا الرُّسُلُ } [ المؤمنون : 51 ] ويعني الرسول .  <br />
وقال مجاهد : عنى به أصحاب محمد صلى الله عليه وسلم { فَاعْلَمُواْ أَنَّمَآ أُنزِلَ بِعِلْمِ اللَّهِ } يعني القرآن { وَأَن لاَّ إِلَهَ إِلاَّ هُوَ فَهَلْ أَنتُمْ مُّسْلِمُونَ } لفظه استفهام ومعناه أمر .
