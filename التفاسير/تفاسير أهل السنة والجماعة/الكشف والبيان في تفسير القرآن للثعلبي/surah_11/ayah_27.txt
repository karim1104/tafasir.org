{ فَقَالَ الْمَلأُ الَّذِينَ كَفَرُواْ مِن قِوْمِهِ مَا نَرَاك } يا نوح { إِلاَّ بَشَراً مِّثْلَنَا } آدمياً مثلنا { وَمَا نَرَاكَ اتَّبَعَكَ إِلاَّ الَّذِينَ هُمْ أَرَاذِلُنَا } سفلتنا { بَادِيَ الرَّأْيِ } قال مجاهد وأبي المعين وحمزة أبو عمرو وبصير على معنى بادي الرأي من غير روية ولا فكرة يعني : آمنوا من غير روية .  <br />
