{ أَمِ اتَّخَذُواْ مِن دُونِهِ آلِهَةً قُلْ هَاتُواْ بُرْهَانَكُمْ } على ذلك ،   ثمَّ قال مستأنفاً { هَذَا } يعني القرآن { ذِكْرُ } خبر { مَن مَّعِيَ } بيان الحدود والأحكام والثواب والعقاب { وَذِكْرُ مَن قَبْلِي } من الأمم السالفة وما فعل الله بهم في الدنيا وما هو فاعل بهم في الآخرة { بَلْ أَكْثَرُهُمْ لاَ يَعْلَمُونَ الْحَقَّ فَهُمْ مُّعْرِضُونَ } عن القرآن .  <br />
