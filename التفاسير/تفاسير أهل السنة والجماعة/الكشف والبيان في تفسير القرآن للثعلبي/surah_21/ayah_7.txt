{ وَمَآ أَرْسَلْنَا قَبْلَكَ إِلاَّ رِجَالاً نُّوحِي إِلَيْهِمْ } وهذا جواب لقولهم { هَلْ هَذَآ إِلاَّ بَشَرٌ مِّثْلُكُمْ } { فَاسْئَلُواْ أَهْلَ الذِّكْرِ } أي التوراة والإنجيل يعني علماء أهل الكتاب { إِن كُنتُمْ لاَ تَعْلَمُونَ } وقال ابن زيد : أراد بالذكر القرآن يعني فاسألوا المؤمنين العالمين من أهل القرآن ،   قال جابر الجعفي : لما نزلت هذه الآية قال عليّ : نحن أهل الذكر .  <br />
