{ بَلْ نَقْذِفُ } نأتي ونرمي وننزل { بِالْحَقِّ } بالإيمان { عَلَى الْبَاطِلِ } الكفر { فَيَدْمَغُهُ } فيهلكه ،   وأصل الدمغ شجّ الرأس حتى يبلغ الدِماغ { فَإِذَا هُوَ زَاهِقٌ } ذاهب وهالك .  <br />
{ وَلَكُمُ الْوَيْلُ } يا معشر الكفّار { مِمَّا تَصِفُونَ } لله بما لا تليق به من الصاحبة والولد .   وقال مجاهد : ممّا تكذبون ،   ونظيره قوله { سَيَجْزِيهِمْ وَصْفَهُمْ } [ الأنعام : 139 ] أي تكذيبهم .
