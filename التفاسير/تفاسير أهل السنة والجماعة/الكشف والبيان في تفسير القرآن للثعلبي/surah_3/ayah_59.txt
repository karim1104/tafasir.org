قال مقاتل : { إِنَّ مَثَلَ عِيسَى عِندَ اللَّهِ كَمَثَلِ ءَادَمَ } الآية : وذلك أنّ وفد نجران قالوا : يا رسول اللّه مالك تشتم صاحبنا ؟ قال : وما أقول ؟ قالوا : تقول إنّه عبد ؟ قال : أجل هو عبد اللّه ورسوله وكلمته ألقاها إلى العذراء البتول .   فغضبوا وقالوا : هل رأيت إنساناً قط من غير أب ؟ فإن كنت صادقاً فأرنا مثله ؟ فأنزل اللّه عز وجّل { إِنَّ مَثَلَ عِيسَى عِندَ اللَّهِ } في كونه خلقاً من غير أب { كَمَثَلِ ءَادَمَ } في كونه خلقاً من غير أب ولا أم { خَلَقَهُ مِن تُرَابٍ } : تم الكلام .  <br />
{ ثُمَّ قَالَ لَهُ } : يعني لعيسى .  <br />
{ كُن فَيَكُونُ } : يعني فكان .  <br />
