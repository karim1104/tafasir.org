{ فَكَيْفَ إِذَا جَمَعْنَاهُمْ } : أي فكيف يصنعون { لِيَوْمٍ لاَّ رَيْبَ فِيهِ } : وهو يوم القيامة .  <br />
{ وَوُفِّيَتْ } : ذكرت .   { كُلُّ نَفْسٍ } : برَّ أو فاجر .   { مَّا كَسَبَتْ } : أي جزاء ما عملت من خير أو شر .   { وَهُمْ لاَ يُظْلَمُونَ } : لا ينقصون من حسناتهم ولا يُزداد على سيئاتهم .  <br />
روى الضحاك عن ابن عباس ،   قال :  " أوَّل راية تُرفع لأهل الموقف ذلك اليوم من رايات الكفار راية اليهود ،   فيقمعهم اللَّه على رؤوس الأشهاد ثم يأمر بهم إلى النار "  .  <br />
