{ إِن تَمْسَسْكُمْ حَسَنَةٌ } ،   قرأ السلمي بالياء .   الباقون بالتاء .   يعني : إن تصبكم أيها المؤمنون { حَسَنَةٌ } بظفركم على عدوكم وغنيمة تنالونها منهم وتتابع من الناس في الدخول في دينكم وخفض في معاشكم { تَسُؤْهُمْ } : تحزنهم { وَإِن تُصِبْكُمْ سَيِّئَةٌ } مساءة بإخفاق سريّة لكم ،   أو إصابة عدوّ فيكم أو اختلاف يكون منكم ،   أو حدث ونكبة { يَفْرَحُواْ بِهَا وَإِن تَصْبِرُواْ وَتَتَّقُواْ } وتخافوا ربّكم { لاَ يَضُرُّكُمْ } لا ينقصكم { كَيْدُهُمْ } شيئاً .  <br />
واختلفت القراءة فيه ؛ فقرأ نافع وابن كثير وأبو عمرو ويعقوب : { لاَ يَضِرُّكُمْ } بكسر الضاد [ وراء ] خفيفة واختاره أبو حاتم ،   يقال : ضار يضير ضيراً مثل باع يبيع بيعاً ،   ودليله في القرآن :<br />
{ لاَ ضَيْرَ } [ الشعراء : 5 ] .   وهو جزم على جواب الجزاء .  <br />
وقرأ الضحاك بضم الضاد وجزم الراء خفيفة من ( ضار يضور ) ،   وذكر الفرّاء عن الكسائي أنه سمع بعض أهل العالية يقول : لا ينفعني ذلك ولا يضورني .   وقرأ الباقون : بضم ( الضاد ،   والراء ) مشددة ،   واختاره .   وهو من ( ضرّ يضرّ ضراً ) ،   مثل ( ردّ يرد ردّاً ) .   وفي رائه وجهان :<br />
أحدهما : أنه أراد الجزم وأصله لا يضررْكم فأُدغمت الراء في الراء ،   ونقلت ضمة الراء الأُولى إلى الضاد وضُمت الراء الأخيره إتباعاً لأقرب الحركات إليها وهي الضاد ؛ طلباً للمشاكلة كقولهم : مرّ يا هذا .  <br />
والوجه الثاني : أن يكون { لا } بمعنى ليس ويضمر الفاء فيه ،   تقديره : وإن تصبروا وتتّقوا فليس يضركم .   قاله الفرّاء وأنشد :<br />
فإن كان لا يرضيك حتى تردني *** إلى قطري لا إخالك راضيا<br />
{ إِنَّ اللَّهَ بِمَا يَعْمَلُونَ مُحِيطٌ } قرأ الأعمش والحسن : بالتاء .   الباقون بالياء { مُحِيطٌ } عالم .
