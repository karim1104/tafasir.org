{ وَيَصْلَى سَعِيراً } قرأ أبو جعفر وأيوب وكوفي غير الكسائي بفتح الياء والتخفيف واختاره أبو عبيد لقوله سبحانه :<br />
{ إِلاَّ مَنْ هُوَ صَالِ الْجَحِيمِ } [ الصافات : 163 ] ،   وقوله<br />
{ يَصْلَى النَّارَ الْكُبْرَى } [ الأعلى : 12 ] وقرأ الباقون بضم الياء وتشديد اللام ،   واختاره أبو حاتم لقوله سبحانه<br />
{ ثُمَّ الْجَحِيمَ صَلُّوهُ } [ الحاقة : 31 ]<br />
{ وَتَصْلِيَةُ جَحِيمٍ } [ الواقعة : 94 ]
