{ لاَّ بَارِدٍ } بل حار لأنه من دخان سعير جهنم { وَلاَ كَرِيمٍ } ولا عذب عن الضحّاك ،   سعيد ابن المسيب والحسن : نظيره :<br />
{ مِن كُلِّ زَوْجٍ كَرِيمٍ } [ الشعراء : 7 ] .   مقاتل : طيب .   قتادة : { لاَّ بَارِدٍ } المنزل { وَلاَ كَرِيمٍ } المنظر .  <br />
قال الفراء : يجعل الكريم تابعاً لكل شيء نفت عنه فعلا فيه ذم .  <br />
وقال ابن كيسان : اليحموم اسم من أسماء النار .   وقال الضحّاك : النار سوداء وأهلها سود وكل شيء فيها أسود .
