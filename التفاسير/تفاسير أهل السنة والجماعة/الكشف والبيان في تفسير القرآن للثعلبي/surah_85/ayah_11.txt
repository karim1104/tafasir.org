{ إِنَّ الَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ لَهُمْ جَنَّاتٌ تَجْرِي مِن تَحْتِهَا الأَنْهَارُ ذَلِكَ الْفَوْزُ الْكَبِيرُ } واختلف العلماء في جواب القسم فقال بعضهم : جوابه { قُتِلَ أَصْحَابُ الأُخْدُودِ } وفيه إضمار يعني لقد قُتل ،   وقيل : فيه تقديم وتأخير تقديره : { قُتِلَ أَصْحَابُ الأُخْدُودِ } { وَالسَّمَآءِ ذَاتِ الْبُرُوجِ } .   وقال قتادة : جوابه قوله : { إِنَّ بَطْشَ رَبِّكَ لَشَدِيدٌ } أي أخذهُ بالعذاب والإنتقام .  <br />
