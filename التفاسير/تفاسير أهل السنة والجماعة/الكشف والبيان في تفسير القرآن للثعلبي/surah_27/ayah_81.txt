{ وَمَآ أَنتَ بِهَادِي الْعُمْيِ عَن ضَلالَتِهِمْ } قراءة العامة على الاسم ،   وقرأ يحيى والأعمش وحمزة يهدي العمي بالياء ونصب الياء على الفعل ههنا وفي سورة النمل { إِن تُسْمِعُ } وتفهم { إِلاَّ مَن يُؤْمِنُ بِآيَاتِنَا } بأدلّتنا وحجتنا { فَهُم مُّسْلِمُونَ } في علم الله سبحانه وتعالى .  <br />
