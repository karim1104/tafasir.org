{ فَأَنجَيْنَاهُ وَأَهْلَهُ إِلاَّ امْرَأَتَهُ } وأهله { قَدَّرْنَاهَا } قضينا عليها أنها { مِنَ الْغَابِرِينَ } أي الباقين في العذاب وقال أهل المعاني : معنى { قَدَّرْنَاهَا } جعلناها { مِنَ الْغَابِرِينَ } وإنّما قال ذلك لأنّ جرمها على مقدار جرمهم ،   فلمّا كان تقديرها كتقديرهم في الشرك والرضى بأفعالهم القبيحة ،   جرت مجراهم في إنزال العذاب بها<br />
