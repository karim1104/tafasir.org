{ فَأَتْبَعَ } : سلك وسار .   وقرأ أهل الكوفة : ( فأتبع ) ،   ( ثمّ اتبع ) بقطع الألف وجزم الثاني : لحق { سَبَباً } ،   قال ابن عباس : منزلاً ،   وقال مجاهد : طريقاً بين المشرق والمغرب ،   نظير قوله تعالى :<br />
{ لَّعَلِّي أَبْلُغُ الأَسْبَابَ * أَسْبَابَ السَّمَاوَاتِ } [ غافر : 36-37 ] يعني الطرق .
