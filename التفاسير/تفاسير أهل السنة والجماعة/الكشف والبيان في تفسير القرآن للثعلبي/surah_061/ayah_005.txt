{ وَإِذْ قَالَ مُوسَى لِقَوْمِهِ } من بني إسرائيل { يقَوْمِ لِمَ تُؤْذُونَنِي } وذلك حين رموه بالادرة  ،  { وَقَد تَّعْلَمُونَ أَنِّي رَسُولُ اللَّهِ إِلَيْكُمْ } والرسول يحترم ويعظم  ،  { فَلَمَّا زَاغُواْ أَزَاغَ اللَّهُ } عن الحق { قُلُوبَهُمْ } عن الدين { وَاللَّهُ لاَ يَهْدِي الْقَوْمَ الْفَاسِقِينَ  } .  <br />
