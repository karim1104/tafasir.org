{ قَالُواْ يوَيْلَنَا مَن بَعَثَنَا مِن مَّرْقَدِنَا } أي منامنا قال أُبي بن كعب وابن عباس وقتادة : إنما يقولون هذا ؛ لأن الله رفع عنهم العذاب فيما بين النفختين فيرقدون ،   وقال أهل المعاني : إنّ الكفار إذا عاينوا جهنم وأنواع عذابها صار ماعذبوا في القبور في جنبها كالنوم ،   فقالوا : { مَن بَعَثَنَا مِن مَّرْقَدِنَا } ؟ ثم قال : { هَذَا مَا وَعَدَ الرَّحْمنُ وَصَدَقَ الْمُرْسَلُونَ } : أقرّوا حين لم ينفعهم الإقرار ،   وقال مجاهد : يقول الكفار : { مَن بَعَثَنَا مِن مَّرْقَدِنَا } ؟ ويقول المؤمنون : { هَذَا مَا وَعَدَ الرَّحْمنُ وَصَدَقَ الْمُرْسَلُونَ } .  <br />
