{ وَمَآ أُبَرِّىءُ نَفْسِي } من الخطأ والزلل فاركبها ،   { إِنَّ النَّفْسَ لأَمَّارَةٌ بِالسُّوءِ } بالمعصية { إِلاَّ مَا رَحِمَ رَبِّي } يعني إلاّ من رحمه ربي فعصم ،   و { مَآ } بمعنى مَن كقوله تعالى : { فَانكِحُواْ مَا طَابَ لَكُمْ مِّنَ النِّسَآءِ } [ النساء : 3 ]أي مَن طاب ،   وقوله إلاّ استثناء منقطع عمّا قبله كقوله تعالى : { وَلاَ هُمْ يُنقَذُونَ * إِلاَّ رَحْمَةً مِّنَّا } [ يس : 43-44 ]يعني إلاّ أن يُرحموا ،   فإنّ إذا كانت في معنى المصدر تضارع ما ،   { إِنَّ رَبِّي غَفُورٌ رَّحِيمٌ } .
