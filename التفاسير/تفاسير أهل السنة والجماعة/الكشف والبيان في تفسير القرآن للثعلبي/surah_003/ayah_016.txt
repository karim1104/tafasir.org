{ الَّذِينَ يَقُولُونَ } : إن شئت جعلته محل ( الذين ) على الجر رداً على قوله { لِلَّذِينَ اتَّقَوْا } .   وإن شئت رفعته على الابتداء كقوله<br />
{ إِنَّ اللَّهَ اشْتَرَى مِنَ الْمُؤْمِنِينَ أَنفُسَهُمْ وَأَمْوَالَهُمْ } [ التوبة : 111 ] .   ثم قال في صفتهم مبتدئاً<br />
{ التَّائِبُونَ الْعَابِدُونَ } [ التوبة : 112 ] .  <br />
{ رَبَّنَآ إِنَّنَآ آمَنَّا } صدَّقنا .  <br />
{ فَاغْفِرْ لَنَا ذُنُوبَنَا } : استرها علينا وتجاوزها عنا .  <br />
{ وَقِنَا عَذَابَ النَّارِ }
