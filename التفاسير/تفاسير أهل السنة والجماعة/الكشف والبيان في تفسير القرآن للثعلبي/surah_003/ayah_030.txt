{ يَوْمَ تَجِدُ كُلُّ نَفْسٍ } : نصب يوماً ،   نزع حرف الصفة أي في يوم .   وقيل : نصب بإضمار فعل ،   أي : اذكروا واتقوا { يَوْمَ تَجِدُ كُلُّ نَفْسٍ مَّا عَمِلَتْ مِنْ خَيْرٍ مُّحْضَراً } : موفراً لم يبخس منه شيء .   قراءة العامة بنصب الضاد على المفعول قد صدَّهم قوله :<br />
{ وَوَجَدُواْ مَا عَمِلُواْ حَاضِراً } [ الكهف : 49 ] : وقرأ عبيد عن عُمير محضراً بكسر الضاد يريد أن عمله يحضره الجنَّة يسرع به من الحضور أو الحضر .  <br />
{ وَمَا عَمِلَتْ مِن سُوءٍ } : جعل بعضهم خبراً في موضع النصب ،   وأعمل فيها الوجود وجعل عملت صلة لها ،   أي : ويجد عملها ،   وجَعله بعضه خبراً مستأنفاً ،   وحينئذ يجوز في { تَوَدُّ } الرفع ،   والجزم ،   دليل هذا التأويل : قراءة عبد اللَّه { وَمَا عَمِلَتْ مِن سُوءٍ تَوَدُّ } .   { لَوْ أَنَّ بَيْنَهَا } : بين النفس { وَبَيْنَهُ } : يعني بين السوء { أَمَدَاً بَعِيداً } : والأمد : الأجل والغاية التَّي ينتهي إليها .   قال اللَّه :<br />
{ أَمْ يَجْعَلُ لَهُ رَبِّي أَمَداً } [ الجن : 25 ] ،   وقال :<br />
{ فَطَالَ عَلَيْهِمُ الأَمَدُ } [ الحديد : 16 ] .  <br />
قال النابغة :<br />
ألا لمثلك أو من أنت سابقه *** بسبق الجواد إذا استويا على الأمد<br />
قال السدي : أمداً بعيداً أي : مكان بعيد .  <br />
مقاتل : كما بين المشرق والمغرب .  <br />
قال الحسن : ليس أحدهم أن لا يلقى عمله أبداً ولا يوَدَّ لو أن يعلمه .  <br />
{ وَيُحَذِّرُكُمُ اللَّهُ نَفْسَهُ وَاللَّهُ رَؤُوفٌ بِالْعِبَادِ } : أي بالمؤمنين منهم .
