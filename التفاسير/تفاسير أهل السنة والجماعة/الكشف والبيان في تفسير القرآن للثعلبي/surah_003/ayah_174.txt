{ فَانْقَلَبُواْ } فانصرفوا ورجعوا ،   نظيره قوله :<br />
{ لَعَلَّهُمْ يَعْرِفُونَهَآ إِذَا انْقَلَبُواْ إِلَى أَهْلِهِمْ } [ يوسف : 62 ] أي رجعوا .  <br />
{ بِنِعْمَةٍ مِّنَ اللَّهِ } أي بعافية لم يلقوا بها عدواً وبراء جراحهم { وَفَضْلٍ } بربح وتجارة ،   وهو ما أصابوا من السوق فربحوا { لَّمْ يَمْسَسْهُمْ سُوءٌ } لم يصبهم قتل ولا جرح ولا ينالهم سوء ولا أذى ولا مكروه { وَاتَّبَعُواْ رِضْوَانَ اللَّهِ } في طاعة الله وطاعة رسوله ،   وذلك أنهم قالوا : هل يكون هذا غزواً ؟ فأعطاهم الله ثواب الغزو ورضى عنهم { وَاللَّهُ ذُو فَضْلٍ عَظِيمٍ *
