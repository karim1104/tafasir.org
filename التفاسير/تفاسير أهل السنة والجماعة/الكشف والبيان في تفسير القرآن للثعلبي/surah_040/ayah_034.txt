{ وَلَقَدْ جَآءَكُمْ يُوسُفُ } بن يعقوب( عليه السلام ) { مِن قَبْلُ بِالْبَيِّنَاتِ } أي من قبل موسى بالبينات .  <br />
قال وهب : إن فرعون موسى هو فرعون يوسف ،   عمّر إلى زمن موسى .   وقال الباقون : هو غيره .  <br />
{ فَمَا زِلْتُمْ فِي شَكٍّ مِّمَّا جَآءَكُمْ بِهِ حَتَّى إِذَا هَلَكَ قُلْتُمْ لَن يَبْعَثَ اللَّهُ مِن بَعْدِهِ رَسُولاً كَذَلِكَ يُضِلُّ اللَّهُ مَنْ هُوَ مُسْرِفٌ } مشرك { مُّرْتَابٌ } شاك<br />
