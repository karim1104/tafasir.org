{ يقَومِ لَكُمُ الْمُلْكُ الْيَوْمَ ظَاهِرِينَ } غالبين مستعلين على بني إسرائيل { فِي الأَرْضِ } أرض مصر { فَمَن يَنصُرُنَا مِن بَأْسِ اللَّهِ } عذاب الله { إِن جَآءَنَا قَالَ فِرْعَوْنُ مَآ أُرِيكُمْ } من الرأي والنصيحة { إِلاَّ مَآ أَرَى } لنفسي .  <br />
وقال الضحاك : ما أعلمكم إلاّ ما أعلم نظيره<br />
{ بِمَآ أَرَاكَ اللَّهُ } [ النساء : 105 ] .   { وَمَآ أَهْدِيكُمْ إِلاَّ سَبِيلَ الرَّشَادِ }
