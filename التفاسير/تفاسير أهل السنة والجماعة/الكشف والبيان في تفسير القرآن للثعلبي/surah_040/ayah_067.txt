{ هُوَ الَّذِي خَلَقَكُمْ مِّن تُرَابٍ ثُمَّ مِن نُّطْفَةٍ ثُمَّ مِنْ عَلَقَةٍ ثُمَّ يُخْرِجُكُمْ طِفْلاً } أي أطفالاً ،   نظيره :<br />
{ أَوِ الطِّفْلِ الَّذِينَ لَمْ يَظْهَرُواْ عَلَى عَوْرَاتِ النِّسَآءِ } [ النور : 31 ] .   { ثُمَّ لِتَبْلُغُواْ أَشُدَّكُمْ ثُمَّ لِتَكُونُواْ شُيُوخاً وَمِنكُمْ مَّن يُتَوَفَّى مِن قَبْلُ } أن يصير شيخاً { وَلِتَبْلُغُواْ } جميعاً { أَجَلاً مُّسَمًّى } وقتاً محدوداً لا تجاوزونه ولا تسبقونه { وَلَعَلَّكُمْ تَعْقِلُونَ } ذلك فتعرفوا أن لا إله غيره فعل ذلك { هُوَ الَّذِي يُحْيِي وَيُمِيتُ فَإِذَا قَضَى أَمْراً فَإِنَّمَا يَقُولُ لَهُ كُن فيَكُونُ }
