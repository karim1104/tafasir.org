{ وَإِذَا رَأَيْتَ الَّذِينَ يَخُوضُونَ فِي آيَاتِنَا } يعني القرآن الاستهزاء والكذب { فَأَعْرِضْ عَنْهُمْ } فاتركهم ولا تجالسهم { حَتَّى يَخُوضُواْ } يدخلوا { فِي حَدِيثٍ غَيْرِهِ } غير القرآن ،   وذلك إن المشركين كانوا إذا جالسوا المؤمنين وقعوا في رسول اللّه صلى الله عليه وسلم فسبوا واستهزؤا بالقرآن ،   فنهى اللّه المؤمنين عن مجالستهم { وَإِمَّا يُنسِيَنَّكَ } .  <br />
قرأ ابن عباس وابن عامر : ينسونك بالتشديد { فَلاَ تَقْعُدْ بَعْدَ الذِّكْرَى مَعَ الْقَوْمِ الظَّالِمِينَ } فقم من عندهم بعد ما ذكرت<br />
