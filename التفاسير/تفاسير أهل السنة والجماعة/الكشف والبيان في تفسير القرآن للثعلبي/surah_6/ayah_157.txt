{ أَوْ تَقُولُواْ لَوْ أَنَّآ أُنزِلَ عَلَيْنَا الْكِتَابُ لَكُنَّآ أَهْدَى مِنْهُمْ } يعني أصوب من اليهود والنصارى ديناً { فَقَدْ جَآءَكُمْ بَيِّنَةٌ مِّن رَّبِّكُمْ } حجّة واضحة لمن يعرفونها { وَهُدًى } وبيان { وَرَحْمَةٌ } ونعمة لمن اتبعه وعمل به { فَمَنْ أَظْلَمُ مِمَّن كَذَّبَ بِآيَاتِ اللَّهِ وَصَدَفَ } وأعرض عنها { سَنَجْزِي الَّذِينَ يَصْدِفُونَ عَنْ آيَاتِنَا سُوءَ الْعَذَابِ } شدة العذاب { بِمَا كَانُواْ يَصْدِفُونَ } يعرضون<br />
