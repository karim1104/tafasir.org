{ قُلْ إِنِّي عَلَى بَيِّنَةٍ } بيان وبرهان وبصيرة وحجة { مِّن رَّبِّي وَكَذَّبْتُم بِهِ } أي بربي { مَا عِندِي مَا تَسْتَعْجِلُونَ بِهِ } يعني العذاب ،   نزلت في النضر بن الحرث { إِنِ الْحُكْمُ } ما القضاء { إِلاَّ للَّهِ يَقُصُّ الْحَقَّ } قرأ أهل الحجاز ،   وعاصم يقص الحق بالصاد المشددة أي يقول الحق قالوا : لأنه مكتوب في جميع المصاحف بغير ياء ولأنه قال الحق فإنما يقال قضيت بالحق .   وقرأ الباقون : بالضاد أي يحكم بالحق دليله قوله { وَهُوَ خَيْرُ الْفَاصِلِينَ } والفصل جلب القضاء ،   والقرّاء إنما حذفوا الياء للإستثقال ثم [  .   .   .   ] كقوله<br />
{ صَالِ الْجَحِيمِ } [ الصافات : 163 ] وقوله<br />
{ يَمْحُواْ اللَّهُ مَا يَشَآءُ } [ الرعد : 39 ] و<br />
{ فَمَا تُغْنِ النُّذُرُ } [ القمر : 5 ]<br />
{ سَنَدْعُ الزَّبَانِيَةَ } [ العلق : 18 ] ونحوها وحذفوا الباء من الحق لأنه صفة المصدر فكأنه يقضي القضاء الحق .
