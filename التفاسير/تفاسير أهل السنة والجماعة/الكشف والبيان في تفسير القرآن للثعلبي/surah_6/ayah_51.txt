{ وَأَنذِرْ } خوّف { بِهِ } بالقرآن .  <br />
قال الضحّاك : به أي باللّه { الَّذِينَ يَخَافُونَ أَن يُحْشَرُواْ } يبعثوا ويحيوا { إِلَى رَبِّهِمْ } وقيل : يعلمون أن يحشروا لأن خوفهم بما كان من عملهم { لَيْسَ لَهُمْ مِّن دُونِهِ } من دون اللّه { وَلِيٌّ } يعني قريب ينفعهم { وَلاَ شَفِيعٌ } يشفع لهم { لَّعَلَّهُمْ يَتَّقُونَ }<br />
