{ لِمَن شَآءَ مِنكُمْ أَن يَتَقَدَّمَ } في الخير والطاعة { أَوْ يَتَأَخَّرَ } عنها في الشر والمعصية نظيره ودليله<br />
{ وَلَقَدْ عَلِمْنَا الْمُسْتَقْدِمِينَ مِنكُمْ } [ الحجر : 24 ] يعني في الخير<br />
{ وَلَقَدْ عَلِمْنَا الْمُسْتَأْخِرِينَ } [ الحجر : 24 ] عنه قاله الحسن ،   وهذا وعيد لهم كقوله :<br />
{ فَمَن شَآءَ فَلْيُؤْمِن وَمَن شَآءَ فَلْيَكْفُرْ } [ الكهف : 29 ] يعني أنّه نذير لهما جميعاً .
