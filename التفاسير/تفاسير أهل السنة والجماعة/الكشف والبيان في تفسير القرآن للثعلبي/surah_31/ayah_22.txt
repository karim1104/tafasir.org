قوله : { وَمَن يُسْلِمْ وَجْهَهُ إِلَى اللَّهِ } أي يخلص دينه لله ويفوّض أمره إليه ،   وقرأ أبو عبد الرحمن السلمي ( يُسلِّمْ ) بالتشديد ،   وقراءة العامّة بالتخفيف من الإسلام وهو الاختيار لقوله :<br />
{ بَلَى مَنْ أَسْلَمَ وَجْهَهُ للَّهِ } [ البقرة : 112 ] وأشباه ذلك .  <br />
{ وَهُوَ مُحْسِنٌ } في عمله { فَقَدِ اسْتَمْسَكَ بِالْعُرْوَةِ الْوُثْقَى } أي : اعتصم بالطريق الأوثق الذي لا يخاف انقطاعه .   وقال ابن عبّاس : هي :<br />
{ لاَ إِلَهَ إِلاَّ اللَّهُ } [ الصافات : 35 ] .  <br />
{ وَإِلَى اللَّهِ عَاقِبَةُ الأَمُورِ } يعني مرجعها .
