{ هُوَ الَّذِي يُسَيِّرُكُمْ فِي الْبَرِّ وَالْبَحْرِ } يبحر بكم ويحملكم على التسيير ،   وقرأ أبو جعفر وابن عامر : ينشركم بالنون من النشر ،   وهو [ البسط ] في البر على الظهر وفي البحر على الفلك { حَتَّى إِذَا كُنتُمْ فِي الْفُلْكِ } أي في السفن يكون واحد أو جمعاً ،   وقرأ عيسى الفلك بضم اللام .  <br />
{ وَجَرَيْنَ بِهِم } يعني جرت السفن بالناس وهذا خطاب تكوين رجع من الخطاب إلى الخبر { بِرِيحٍ طَيِّبَةٍ وَفَرِحُواْ بِهَا } أي الريح { جَآءَتْهَا } يعني الفلك وهو جواب لقوله حتى إذا جاءتها { رِيحٌ عَاصِفٌ } شديد يقال : عصفت الريح وأعصفت والريح ،   مذكر ومؤنث ،   وقيل : لم يقل : عاصفة لاختصاص الريح بالعصوف ،   وقيل : للنسب أي ذات صوف { وَجَآءَهُمُ } يعني سكان السفينة { الْمَوْجُ } وهو حركة الماء وأخلاطه { مِن كُلِّ مَكَانٍ وَظَنُّواْ } وأيقنوا { أَنَّهُمْ أُحِيطَ بِهِمْ } إذا أحاط بهم الهلاك { دَعَوُاْ اللَّهَ } هنالك { مُخْلِصِينَ لَهُ الدِّينَ } للدعاء دون أوثانهم وكان مفزعهم إلى الله دونها .  <br />
روى [ الثوري ] عن الأعمش عن عمرو بن مرة عن أبي عبيد في قوله تعالى : { مُخْلِصِينَ لَهُ الدِّينَ } قال : قالوا في دعائهم : أهيا شراهيا وتفسيره : يا حيُّ يا قيوم { لَئِنْ أَنْجَيْتَنَا } خلصتنا يا ربنا { مِنْ هَذِهِ } الريح العاصف { لَنَكُونَنَّ مِنَ الشَّاكِرِينَ } لك بالإيمان والطاعة<br />
