{ وَمِنَ النَّاسِ مَن يِقُولُ آمَنَّا بِاللَّهِ فَإِذَآ أُوذِيَ فِي اللَّهِ جَعَلَ فِتْنَةَ النَّاسِ } أي أذاهم وعدائهم { كَعَذَابِ اللَّهِ } في الآخرة فارتد عن إيمانه { وَلَئِنْ جَآءَ نَصْرٌ مِّن رَّبِّكَ لَيَقُولُنَّ } هؤلاء المرتدون { إِنَّا كُنَّا مَعَكُمْ } وهم كاذبون { أَوَ لَيْسَ اللَّهُ بِأَعْلَمَ بِمَا فِي صُدُورِ الْعَالَمِينَ }<br />
