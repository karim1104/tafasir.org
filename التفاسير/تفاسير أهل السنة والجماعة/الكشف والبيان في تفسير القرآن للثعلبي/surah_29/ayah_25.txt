{ وَقَالَ } يعني إبراهيم ( عليه السلام )لقومه : { إِنَّمَا اتَّخَذْتُمْ مِّن دُونِ اللَّهِ أَوْثَاناً مَّوَدَّةَ بَيْنِكُمْ } اختلف القرّاء فيها ،   فقرأ ابن كثير وأبو عمرو والكسائي ويعقوب { مَّوَدَّةَ } رفعاً { بَيْنِكُمْ } خفضاً بالإضافة ،   واختاره أبو عبيد وأبو حاتم على معنى : أنّ الذين اتخذتم من دون الله أوثاناً هي { مَّوَدَّةَ بَيْنِكُمْ } .   { فِي الْحَيَاةِ الدُّنْيَا } لم تنقطع ولا تنفع في الآخرة كقوله :<br />
{ لَمْ يَلْبَثُواْ إِلاَّ سَاعَةً مِّن نَّهَارٍ } [ الأحقاف : 35 ] ثم قال :<br />
{ بَلاَغٌ } [ الأحقاف : 35 ] أي هذا بلاغ ،   وقوله سبحانه :<br />
{ لاَ يُفْلِحُونَ } [ يونس : 69 ] ثم قال :<br />
{ مَتَاعٌ } [ يونس : 70 ] أي هو متاع ،   فكذلك أضمروا هاهنا هي ويجوز أن تكون خبر إن .  <br />
وقرأ عاصم في بعض الروايات { مَّوَدَّةَ } مرفوعة منونة { بَيْنِكُمْ } نصباً وهو راجع إلى معنى القراءة الأولى ،   وقرأ حمزة { مَّوَدَّةَ } بالنصب { بَيْنِكُمْ } بالخفض على الإضافة بوقوع الإتحاد عليها وجعل إنّما حرفاً واحداً وهي رواية حفص عن عاصم ،   وقرأ الآخرون : { مَّوَدَّةَ } نصباً منونة { بَيْنِكُمْ } بالنصب وهي راجعة إلى قراءة حمزة ومعنى الآية أنكم اتخذتم هذه الأوثان مودة بينكم في الحياة الدنيا .  <br />
{ مَّوَدَّةَ بَيْنِكُمْ فِي الْحَيَاةِ الدُّنْيَا } تتوادون وتتحابون على عبادتها وتتواصلون عليها .  <br />
{ ثُمَّ يَوْمَ الْقِيَامَةِ يَكْفُرُ بَعْضُكُمْ بِبَعْضٍ وَيَلْعَنُ بَعْضُكُمْ بَعْضاً } وتتبرأ الأوثان من عابديها { وَمَأْوَاكُمُ } جميعاً العابدون والمعبودون { النَّارُ وَمَا لَكُمْ مِّن نَّاصِرِينَ }
