{ هَؤُلاءِ قَوْمُنَا } ،   يعني أهل بلدهم { اتَّخَذُواْ مِن دُونِهِ } ،   أي من دون الله { آلِهَةً } ،   يعني الأصنام يعبدونها من دون الله { لَّوْلاَ يَأْتُونَ عَلَيْهِم } أي هلاّ يأتون على عبادتهم { بِسُلْطَانٍ بَيِّنٍ } : بحجة واضحة ؛ { فَمَنْ أَظْلَمُ مِمَّنِ افْتَرَى عَلَى اللَّهِ كَذِباً } ،   فزعم أنّ له شريكاً وولداً ؟<br />
