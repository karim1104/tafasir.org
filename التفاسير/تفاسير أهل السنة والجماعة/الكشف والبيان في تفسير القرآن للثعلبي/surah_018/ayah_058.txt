{ وَرَبُّكَ الْغَفُورُ ذُو الرَّحْمَةِ لَوْ يُؤَاخِذُهُم بِمَا كَسَبُواْ } من الذنوب { لَعَجَّلَ لَهُمُ الْعَذَابَ } في الدنيا { بَل لَّهُم مَّوْعِدٌ } وهو يوم الحساب { لَّن يَجِدُواْ مِن دُونِهِ مَوْئِلاً } : معدلاً ومنجىً ،   قال الأعشى :<br />
