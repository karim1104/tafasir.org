{ قُلْ يَأَهْلَ الْكِتَابِ لَسْتُمْ عَلَى شَيْءٍ } من الدين { حَتَّى تُقِيمُواْ التَّوْرَاةَ وَالإِنْجِيلَ وَمَآ أُنزِلَ إِلَيْكُمْ مِّن رَّبِّكُمْ وَلَيَزِيدَنَّ كَثِيراً مِّنْهُمْ مَّآ أُنْزِلَ إِلَيْكَ } يا محمد { مِن رَّبِّكَ طُغْيَاناً وَكُفْراً } حيث أمرهم بالقرآن مع قيام الدلالة والحجة عليهم { فَلاَ تَأْسَ } فلا تحزن { عَلَى الْقَوْمِ الْكَافِرِينَ }<br />
