{ يَهْدِي بِهِ اللَّهُ } مجاهد وعبيد بن عمير ومسلم بن جندب : يهدي به اللّه بضم الهاء على الأصل لأن أصل الهاء الضمة ،   وقرأ الآخرون بكسر الهاء إتباعاً .   { مَنِ اتَّبَعَ رِضْوَانَهُ } رضاه ومعنى رضاه بالشيء قبوله ومدحه له فأثابه عليه وهو خلاف السخط والغضب { سُبُلَ السَّلاَمِ } لطرف السلم وهو الله تعالى وسبيله دينه الذي شرع لعباده وبعث به رسله { وَيُخْرِجُهُمْ مِّنِ الظُّلُمَاتِ إِلَى النُّورِ } أي من ظلام الكفر إلى نور الإيمان { بِإِذْنِهِ } بتوفيقه وهدايته وإرادته ومشيئته { وَيَهْدِيهِمْ إِلَى صِرَاطٍ مُّسْتَقِيمٍ } ،  <br />
