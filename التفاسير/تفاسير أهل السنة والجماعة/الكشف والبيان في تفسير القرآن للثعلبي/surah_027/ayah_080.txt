{ إِنَّكَ لاَ تُسْمِعُ الْمَوْتَى } الكفار كقوله<br />
{ أَوَ مَن كَانَ مَيْتاً فَأَحْيَيْنَاهُ } [ الأنعام : 122 ] وقوله<br />
{ وَمَا يَسْتَوِي الأَحْيَآءُ وَلاَ الأَمْوَاتُ } [ فاطر : 22 ] .  <br />
{ وَلاَ تُسْمِعُ الصُّمَّ الدُّعَآءَ إِذَا وَلَّوْاْ مُدْبِرِينَ } نظيره<br />
{ صُمٌّ بُكْمٌ عُمْيٌ } [ البقرة : 18 ،   171 ] .
