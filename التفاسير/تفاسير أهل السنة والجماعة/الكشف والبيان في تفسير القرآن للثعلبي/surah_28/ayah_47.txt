{ وَلَوْلا أَن تُصِيبَهُم مُّصِيبَةٌ } عقوبة ونقمة { بِمَا قَدَّمَتْ أَيْدِيهِمْ } من الكفر والمعصية { فَيَقُولُواْ رَبَّنَا لَوْلا أَرْسَلْتَ إِلَيْنَا رَسُولاً فَنَتَّبِعَ آيَاتِكَ وَنَكُونَ مِنَ الْمُؤْمِنِينَ } وجواب لولا محذوف أي لعاجلناهم بالعقوبة ،   وقيل معناه : لما أرسلناك إليهم رسولا ،   ولكنا بعثناك إليهم<br />
{ لِئَلاَّ يَكُونَ لِلنَّاسِ عَلَى اللَّهِ حُجَّةٌ بَعْدَ الرُّسُلِ } [ النساء : 165 ] ،
