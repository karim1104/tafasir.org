{ وَقَالَتْ } أم موسى { لأُخْتِهِ } لأخت موسى واسمها مريم { قُصِّيهِ } ابتغي أثره حتى تعلمي خبره ،   ومنه القصص لأنّه حديث يتبع فيه الثاني الأول ،   { فَبَصُرَتْ بِهِ } أبصرته { عَن جُنُبٍ } بُعد ،   وقال ابن عباس : الجنب أن يسمو بصر الإنسان إلى الشيء البعيد وهو إلى جنبه لا يشعر به .  <br />
وقال قتادة : جعلت تنظر إليه كأنّها لا تريده ،   وكان يقرأ { عَن جُنُبٍ } بفتح الجيم وسكون النون ،   وقرأ النعمان بن سالم عن جانب أي عن ناحية { وَهُمْ لاَ يَشْعُرُونَ } أنها أُخته<br />
