{ فَلَمَّآ أَتَاهَا نُودِيَ مِن شَاطِىءِ } جانب { الْوَادِى الأَيْمَنِ } عن يمين موسى { فِي الْبُقْعَةِ الْمُبَارَكَةِ } وقرأ أشهب العقيلي { فِي الْبُقْعَةِ } بفتح الباء { مِنَ الشَّجَرَةِ } أي من ناحية الشجرة { أَن يمُوسَى إِنِّي أَنَا اللَّهُ رَبُّ الْعَالَمِينَ } قال عبد الله بن مسعود : كانت الشجرة سمرة خضراء ترق ،   قتادة ،   عوسجة ،   وهب : علّيق .  <br />
