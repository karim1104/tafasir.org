{ قَالَ } عند ذلك الشيخ لموسى { إِنِّي أُرِيدُ أَنْ أُنكِحَكَ إِحْدَى ابْنَتَيَّ هَاتَيْنِ } واسمهما صفورة ولباني ،   قول شعيب الجبّائي قال : امرأة موسى صفورة ،   وقال ابن إسحاق : صفورة وشرفا ،   وغيرهما : الكبرى صفرا والصغرى صفيرا { عَلَى أَن تَأْجُرَنِي } يعني آجرني ،   وقالت الأئمة : على أن تثيبني من تزويجها رعيّ ماشيتي { ثَمَانِيَ حِجَجٍ } سنين واحدتها حجة ،   جعل صداقها ذلك ،   قال : ( يقول العرب ) آجرك الله فهو يأجرك بمعنى أثابك { فَإِنْ أَتْمَمْتَ عَشْراً } أي عشر سنين { فَمِنْ عِندِكَ } وأنت به متبرع متفضل وليس مما اشترطه عليك في عقد النكاح { وَمَآ أُرِيدُ أَنْ أَشُقَّ عَلَيْكَ } .  <br />
