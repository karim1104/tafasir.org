{ الَّذِينَ يُجَادِلُونَ فِي آيَاتِ اللَّهِ بِغَيْرِ سُلْطَانٍ أَتَاهُمْ كَبُرَ مَقْتاً } أي كبر ذلك الجدال مقتاً كقوله :<br />
{ كَبُرَ مَقْتاً عِندَ اللَّهِ أَن تَقُولُواْ } [ الصف : 3 ] و<br />
{ كَبُرَتْ كَلِمَةً } [ الكهف : 5 ] { عِندَ اللَّهِ وَعِندَ الَّذِينَ آمَنُواْ كَذَلِكَ يَطْبَعُ اللَّهُ } يختم الله بالكفر { عَلَى كُلِّ قَلْبِ مُتَكَبِّرٍ جَبَّارٍ } .  <br />
وقرأ أبو عمرو وابن عامر : ( قلب ) منّوناً .  <br />
وقرأ الآخرون : بالإضافة .  <br />
[ واختاره أبو حاتم وأبو عبيد ] ،   وفي قراءة ابن مسعود : ( على قلب كل متكبر جبار ) .
