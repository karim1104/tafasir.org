{ الَّذِينَ آمَنُواْ يُقَاتِلُونَ فِي سَبِيلِ اللَّهِ } أي طاعته { وَالَّذِينَ كَفَرُواْ يُقَاتِلُونَ فِي سَبِيلِ الطَّاغُوتِ } أي في طاعة الشيطان { فَقَاتِلُواْ } أيها المؤمنين { أَوْلِيَاءَ الشَّيْطَانِ } أي حزبه وجنده { إِنَّ كَيْدَ الشَّيْطَانِ } ومكره وصنيعه ومكر من اتّبعه { كَانَ ضَعِيفاً } كما خذلهم يوم بدر .  <br />
