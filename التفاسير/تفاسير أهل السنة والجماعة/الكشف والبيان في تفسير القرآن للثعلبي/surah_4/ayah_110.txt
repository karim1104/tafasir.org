ثم استأنف وقال { وَمَن يَعْمَلْ سُوءاً } يعني يسرق الدرع { أَوْ يَظْلِمْ نَفْسَهُ } برميه البريء في السرقة ،   يقال : ومن يعمل سوءاً أي شركاً أو يظلم نفسه يعني بما دون الشرك { ثُمَّ يَسْتَغْفِرِ اللَّهَ } أي يتوب إلى الله { يَجِدِ اللَّهَ غَفُوراً رَّحِيماً } متجاوزاً { رَّحِيماً } به حين قبل توبته<br />
