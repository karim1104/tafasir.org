ثم أقبل على قوم طعمة وقال { هَا أَنْتُمْ هَؤُلاءِ } أي يا هؤلاء للتنبيه { جَادَلْتُمْ } أي خاصمتم عن [ أبي ] طعمة ،   ومتى سافر أبي بن كعب { عَنْهُمْ فِي الْحَيَاةِ الدُّنْيَا } والمطلب به في اللغة بشدة [ المخاصمة ] وهو من الجدل وهو [ شدّة الفتل وفيه : رجل مجدول الخلق ،   وفيه : الأجدل للصقر ] لأنّه من أشدّ الطيور قوّة .  <br />
{ فَمَن يُجَادِلُ اللَّهَ عَنْهُمْ } أي عن طعمة { يَوْمَ الْقِيَامَةِ } لما أخذه الله بعذابه وأدخله النار { أَمْ مَّن يَكُونُ عَلَيْهِمْ وَكِيلاً } كفيلاً .  <br />
