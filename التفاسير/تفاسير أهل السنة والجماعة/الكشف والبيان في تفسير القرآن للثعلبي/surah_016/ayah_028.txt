{ الَّذِينَ تَتَوَفَّاهُمُ الْمَلائِكَةُ } يقبض أرواحهم ملك الموت وأعوانه { ظَالِمِي أَنْفُسِهِمْ } بالكفر نصب على الحال ،   أي في حال كفرهم { فَأَلْقَوُاْ السَّلَمَ } أي استسلموا وانقادوا وقالوا : { مَا كُنَّا نَعْمَلُ مِن سُوء } شرك ،   فقالت لهم الملائكة : { بَلَى إِنَّ اللَّهَ عَلِيمٌ بِمَا كُنْتُمْ تَعْمَلُونَ } .  <br />
قال عكرمة : عَنى بذلك من قتل من قريش وأهل مكة ببدر وقد أُخرج إليها كرهاً .  <br />
