{ وَيَوْمَ نَبْعَثُ فِي كُلِّ أُمَّةٍ شَهِيداً عَلَيْهِمْ مِّنْ أَنْفُسِهِمْ } ،   يعني : عليها ،   وإنما قال : { مِّنْ أَنْفُسِهِمْ } ؛ لأنه كان يبعث إلى الأُمم أنبياءها منها ،   { وَجِئْنَا بِكَ } يا محمّد { شَهِيداً عَلَى هَؤُلآءِ } ،   الذين بُعثت إليهم ،   { وَنَزَّلْنَا عَلَيْكَ الْكِتَابَ تِبْيَاناً لِّكُلِّ شَيْءٍ } يحتاج إليه من الأمر والنهي ،   والحلال والحرام ،   والحدود والأحكام .   { وَهُدًى وَرَحْمَةً وَبُشْرَى لِلْمُسْلِمِينَ } .  <br />
