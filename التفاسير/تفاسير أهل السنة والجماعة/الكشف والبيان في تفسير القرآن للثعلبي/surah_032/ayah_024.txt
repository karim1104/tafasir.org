{ وَجَعَلْنَا مِنْهُمْ أَئِمَّةً } قادة في الخير يقتدى بهم { يَهْدُونَ } يدعون { بِأَمْرِنَا لَمَّا صَبَرُواْ } قرأ حمزة والكسائي ( لَمَّا ) بكسر اللام وتخفيف الميم أي لصبرهم ،   واختاره أبو عبيد اعتباراً بقراءة عبدالله { لَمَّا صَبَرُواْ } وقرأ الباقون بفتح اللام وتشديد الميم أي حين صبروا .  <br />
