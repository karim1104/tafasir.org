{ حم * وَالْكِتَابِ الْمُبِينِ * إِنَّا جَعَلْنَاهُ قُرْآناً عَرَبِيّاً } .   أي أنزلناه وسميناه وبيّناه ووصفناه .   كقوله تعالى : { مَا جَعَلَ اللَّهُ مِن بَحِيرَةٍ وَلاَ سَآئِبَةٍ } ،   وقوله : { وَجَعَلُواْ الْمَلاَئِكَةَ الَّذِينَ هُمْ عِبَادُ الرَّحْمَنِ إِنَاثاً } [ الزخرف : 19 ] ،   وقوله :<br />
{ الَّذِينَ جَعَلُواْ الْقُرْآنَ عِضِينَ } [ الحجر : 91 ] ،   وقوله تعالى :<br />
{ أَجَعَلْتُمْ سِقَايَةَ الْحَاجِّ } [ التوبة : 19 ] .   كلّها بمعنى الوصف والتسمية ويستحيل أن يكون بمعنى الخلق .   { لَّعَلَّكُمْ تَعْقِلُونَ }
