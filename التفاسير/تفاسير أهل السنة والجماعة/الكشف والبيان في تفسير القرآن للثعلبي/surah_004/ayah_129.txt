{ ولن تستطيعوا أن تعدلوا بين النساء } يقول : لن تقدروا ان تسوّوا بينهن في الحب { وَلَوْ حَرَصْتُمْ } على العدل { فَلاَ تَمِيلُواْ } إلى الشابة الجميلة التي تحبّونها { كُلَّ الْمَيْلِ } في النفقة والقسمة والإقبال عليها ( وتدّعوا الأخرى كالمعلّقة ) أي كالمنوطة لا أيمّاً ولا ذات متاع .  <br />
قتادة والكلبي : كالمعلقة كالمحبوسة وهي في امرأة أُبيّ بن كعب كأنها مسجونة .  <br />
وقال مجاهد : لن تستطيعوا العدل بينهن فلا يتعمدوا [ ذلك ] .  <br />
وذُكر لنا أن عمر بن الخطاب كان يقول : اللهم أما قلبي فلا أملك وأما ماسوى ذلك فأرجو أن أعدل .  <br />
{ وَإِن تُصْلِحُواْ } بالعدل في القسمة بينهن { وَتَتَّقُواْ } الجور { فَإِنَّ اللَّهَ كَانَ غَفُوراً رَّحِيماً } بما قلت إلى التي تحبّها بقلبك بعد العدل في القسمة<br />
