{ أَفَلَمْ يَسِيرُواْ فِي الأَرْضِ } يعني كفّار مكة فينظروا إلى مصارع المكذّبين من الأُمم الخالية .  <br />
{ فَتَكُونَ لَهُمْ قُلُوبٌ يَعْقِلُونَ بِهَآ } يعلمون بها { أَوْ آذَانٌ يَسْمَعُونَ بِهَا } فيتفكروا ويعتبروا .  <br />
{ فَإِنَّهَا لاَ تَعْمَى الأَبْصَارُ وَلَكِن تَعْمَى الْقُلُوبُ الَّتِي فِي الصُّدُورِ } تأكيد ،   كقوله سبحانه<br />
{ وَلاَ طَائِرٍ يَطِيرُ بِجَنَاحَيْهِ } [ الأنعام : 38 ] وقوله تعالى<br />
{ يَقُولُونَ بِأَفْوَاهِهِم } [ آل عمران : 167 ] .  <br />
قال ابن عباس ومقاتل : لمّا نزل<br />
{ وَمَن كَانَ فِي هَذِهِ أَعْمَى فَهُوَ فِي الآخِرَةِ أَعْمَى } [ الإسراء : 72 ] جاء ابن أم مكتوم النبي صلى الله عليه وسلم باكياً فقال : يا رسول الله أنا في الدنيا أعمى أفأكون في الآخرة أعمى ؟ فأنزل الله سبحانه وتعالى هذه الآية .   { وَيَسْتَعْجِلُونَكَ بِالْعَذَابِ }
