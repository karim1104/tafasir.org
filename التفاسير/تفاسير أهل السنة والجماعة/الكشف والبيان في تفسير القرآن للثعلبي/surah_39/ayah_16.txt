{ لَهُمْ مِّن فَوْقِهِمْ ظُلَلٌ } أطباق وسرادق { مِّنَ النَّارِ } ودخانها { وَمِن تَحْتِهِمْ ظُلَلٌ } مهاد وفراش من نار ،   وإنما سمّي الأسفل ظلاً ،   لأنها ظلل لمن تحتهم ،   نظيره قوله تعالى : { لَهُمْ مِّن جَهَنَّمَ مِهَادٌ وَمِن فَوْقِهِمْ غَوَاشٍ } [ الأعراف : 41 ] وقوله : { يَوْمَ يَغْشَاهُمُ الْعَذَابُ مِن فَوْقِهِمْ وَمِن تَحْتِ أَرْجُلِهِمْ } [ العنكبوت : 55 ] وقوله : { أَحَاطَ بِهِمْ سُرَادِقُهَا } [ الكهف : 29 ] وقوله : { وَظِلٍّ مِّن يَحْمُومٍ } [ الواقعة : 43 ] وقوله سبحانه وتعالى : { انطَلِقُواْ إِلَى ظِلٍّ ذِي ثَلاَثِ شُعَبٍ } [ المرسلات : 30 ] .   { ذَلِكَ يُخَوِّفُ اللَّهُ بِهِ عِبَادَهُ يعِبَادِ فَاتَّقُونِ }
