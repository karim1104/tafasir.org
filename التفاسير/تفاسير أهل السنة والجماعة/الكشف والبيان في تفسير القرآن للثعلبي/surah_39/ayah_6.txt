{ خَلَقَكُمْ مِّن نَّفْسٍ وَاحِدَةٍ ثُمَّ جَعَلَ مِنْهَا زَوْجَهَا وَأَنزَلَ } وأنشأ { وَأَنزَلَ لَكُمْ } وقال بعض أهل المعاني : جعلنا لكم نزلاً ورزقاً .  <br />
{ مِّنَ الأَنْعَامِ ثَمَانِيَةَ أَزْوَاجٍ } أصناف وأفراد ،   تفسيرها في سورة الأنعام { يَخْلُقُكُمْ فِي بُطُونِ أُمَّهَاتِكُمْ خَلْقاً مِّن بَعْدِ خَلْقٍ } نطفة ثم علقة ثم مضغة ،   كما قال : { وَقَدْ خَلَقَكُمْ أَطْوَاراً } [ نوح : 14 ] .   وقال ابن زيد : معناه يخلقكم في بطون أُمهاتكم من بعد الخلق الأول الذي خلقكم في ظهر آدم .  <br />
{ فِي ظُلُمَاتٍ ثَلاَثٍ } يعني البطن والرحم والمشيمة { ذَلِكُمُ اللَّهُ رَبُّكُمْ لَهُ الْمُلْكُ لا إِلَهَ إِلاَّ هُوَ فَأَنَّى تُصْرَفُونَ } عن عبادته إلى عبادة غيره
