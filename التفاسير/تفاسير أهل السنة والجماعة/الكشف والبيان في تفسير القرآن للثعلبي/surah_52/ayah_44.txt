{ وَإِن يَرَوْاْ كِسْفاً مِّنَ السَّمَآءِ سَاقِطاً } كسفاً قطعة وقيل : قطعاً واحدتها كسفة مثل سدرة وسدر { مِّنَ السَّمَآءِ سَاقِطاً } ذكره على لفظ الكسف { يَقُولُواْ } بمعاندتهم وفرط غباوتهم ودرك شقاوتهم هذا { سَحَابٌ مَّرْكُومٌ } موضوع بعضه على بعض .   هذا جواب لقولهم :<br />
{ فَأَسْقِطْ عَلَيْنَا كِسَفاً مِّنَ السَّمَآءِ } [ الشعراء : 187 ] وقولهم :<br />
{ أَوْ تُسْقِطَ السَّمَآءَ كَمَا زَعَمْتَ عَلَيْنَا كِسَفاً } [ الإسراء : 92 ] فقال : لو فعلنا هذا لقالوا : سحاب مركوم .
