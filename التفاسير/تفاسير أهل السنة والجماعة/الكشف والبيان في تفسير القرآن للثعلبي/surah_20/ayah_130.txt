{ فَاصْبِرْ عَلَى مَا يَقُولُونَ } نسختها آية القتال { وَسَبِّحْ بِحَمْدِ رَبِّكَ } وصلِّ بأمر ربّك ،   وقيل : بثناء ربك { قَبْلَ طُلُوعِ الشَّمْسِ } يعني صلاة الصبح { وَقَبْلَ غُرُوبِهَا } يعني صلاة العصر { وَمِنْ ءَانَآءِ الَّيْلِ } صلاة العشاء الآخر { فَسَبِّحْ وَأَطْرَافَ النَّهَارِ } صلاة الظهر والمغرب ،   وإنّما قال : أطراف لهاتين الصلاتين ؛ لأنّ صلاة الظهر في آخر الطرف الأول من النهار ،   وفي أول الطرف الآخر من النهار فهي في طرفين منه الطرف الثالث غروب الشمس ،   وعند ذلك يصلّي المغرب ،   فلذلك قال : أطراف ،   ونصب عطفاً على قوله : قبل طلوع الشمس .  <br />
{ لَعَلَّكَ تَرْضَى } بالشفاعة والثواب ،   قرأه العامة : بفتح التاء ،   ودليله قوله تعالى : { وَلَسَوْفَ يُعْطِيكَ رَبُّكَ فَتَرْضَى } [ الضحى : 5 ] وقرأ الكسائي وعاصم برواية أبي بكر بضم التاء .
