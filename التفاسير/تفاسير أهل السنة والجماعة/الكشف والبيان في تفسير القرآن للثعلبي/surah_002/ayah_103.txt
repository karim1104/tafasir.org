{ وَلَوْ أَنَّهُمْ آمَنُواْ } بمحمّد صلى الله عليه وسلم والقرآن .   { واتَّقَوْا } اليهودية والسّحر .   { لَمَثُوبَةٌ } [ ويجوز المثوبة بفتح الميم وفتح الواو كمشوُرة وكمشوَرة وهي مصدر من الثواب ] { مِّنْ عِندِ اللَّهِ } لكان ثواب الله عزّ وجلّ أياهم .   { خَيْرٌ لَّوْ كَانُواْ يَعْلَمُونَ } .  <br />
