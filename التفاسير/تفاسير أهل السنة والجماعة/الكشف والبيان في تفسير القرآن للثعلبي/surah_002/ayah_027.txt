ثمّ وصفهم فقال : { الَّذِينَ يَنقُضُونَ } أي يتركون ويخالفون ،   وأصل النقض : الكسر .   { عَهْدَ اللَّهِ } أمره الذي عَهِد إليهم يوم الميثاق بقوله تعالى : { أَلَسْتُ بِرَبِّكُمْ قَالُواْ بَلَى } [ الأعراف : 172 ] وما عهد إليهم في التوراة أن يؤمنوا بمحمد صلى الله عليه وسلم [ وضمّنه ] نعته وصفته .   { مِن بَعْدِ مِيثَاقِهِ } توكيده وتشديده ،   وهو مفعال من الوثيقة .   { وَيَقْطَعُونَ مَآ أَمَرَ اللَّهُ بِهِ أَن يُوصَلَ } يعني الأرحام ،   وقيل : هو الإيمان بجميع الرّسل والكتب ،   وهو نوع من الصّلة ؛ لأنهم قالوا : { نُؤْمِنُ بِبَعْضٍ وَنَكْفُرُ بِبَعْضٍ } [ النساء : 150 ] فقطعوا ،   وقال المؤمنون : { لاَ نُفَرِّقُ بَيْنَ أَحَدٍ مِّن رُّسُلِهِ } [ البقرة : 285 ] فوصلوا .   { وَيُفْسِدُونَ فِي الأرْضِ } بالمعاصي وتعويق الناس عن الإيمان بمحمد صلى الله عليه وسلم والقرآن .   { أُولَئِكَ هُمُ الْخَاسِرُونَ } : أي المغبونون بالعقوبة وفوت المثوبة ،
