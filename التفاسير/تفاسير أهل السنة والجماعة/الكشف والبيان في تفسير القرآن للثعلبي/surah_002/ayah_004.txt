{ والَّذِينَ يُؤْمِنُونَ } : أي يصدّقون { بِمَآ أُنْزِلَ إِلَيْكَ } : يا محمد يعني القرآن { وَمَآ أُنْزِلَ مِن قَبْلِكَ } : يعني الكتب المتقدمة مثل صحف إبراهيم وموسى والزّبور والأنجيل وغيرها .   { وَبِالآخِرَةِ } أي بالدار الآخرة ،   وسميّت آخرة لأنّها تكون بعد الدُّنيا ولأنّها أُخّرت حتى تفنى الدنيا ثم تكون .   { هُمْ يُوقِنُونَ } يعلمون ويتيقّنون أنها كائنة ،   ودخل ( هم ) تأكيداً ،   يُسمّيه الكوفيون عماداً والبصريون فصلا .  <br />
