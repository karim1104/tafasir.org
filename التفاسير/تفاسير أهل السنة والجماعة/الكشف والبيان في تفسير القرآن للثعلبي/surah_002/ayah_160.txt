{ إِلاَّ الَّذِينَ تَابُواْ } من الكفر .   { وَأَصْلَحُواْ } الأعمال فيما بينهم وبين ربّهم .   { وَبَيَّنُواْ } صفة محمّد صلى الله عليه وسلم وآية الرجم .   { فَأُوْلَئِكَ أَتُوبُ عَلَيْهِمْ } أتجاوز عنهم وأقبل توبتهم .   { وَأَنَا التَّوَّابُ } الرجّاع بقلوب عبادي المنصرفة عني .   { الرَّحِيمُ } بهم بعد إقبالهم عليّ .  <br />
