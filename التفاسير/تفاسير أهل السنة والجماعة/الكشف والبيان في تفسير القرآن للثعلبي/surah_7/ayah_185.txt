{ أَوَلَمْ يَتَفَكَّرُوا مَا بِصَاحِبِهِم مِّن جِنَّةٍ }  "  ما بمحمد من جنون .  <br />
{ إِنْ هُوَ } ما هو { إِلاَّ نَذِيرٌ مُّبِينٌ } مخوف { أَوَلَمْ يَنْظُرُواْ فِي مَلَكُوتِ } ملك { السَّمَاوَاتِ وَالأَرْضِ وَمَا خَلَقَ اللَّهُ } فيهما { مِن شَيْءٍ وَأَنْ عَسَى } وهي أن لعلّ { أَن يَكُونَ قَدِ اقْتَرَبَ أَجَلُهُمْ } فيهلكوا على الكفر ويصبروا إلى العذاب { فَبِأَيِّ حَدِيثٍ بَعْدَهُ } بعد القرآن { يُؤْمِنُونَ } ثمّ بيّن العلّة في إعراضهم عن القرآن وتركهم الإيمان<br />
