{ وَهُوَ الَّذِي يُرْسِلُ الرِّيَاحَ بُشْراً } قرأ عاصم بُشراً بالباء المضمومة والشين المجزومة يعني أنّها تبشّر بالمطر يدلّ عليه قوله :<br />
{ الرِّيَاحَ مُبَشِّرَاتٍ } [ الروم : 46 ] .  <br />
وروى عنه بُشُراً بضم الباء والشين على جمع البشير مثل نذير و[ نذار ] .  <br />
وهي قراءة ابن عباس .   وقرأ غيره من أهل الكوفة نشراً بفتح النون وجزم الشين وهو الريح الطيبة اللينة .  <br />
قال أمرؤ القيس :<br />
كان المدام وصوب الغمام *** وريح الخزامي ونشر القطر<br />
وهي قراءة ابن مسعود وابن عباس وزر بن حبيش ،   واختاره أبو عبيد لقوله :<br />
{ والنَّاشِرَاتِ نَشْراً } [ المرسلات : 3 ] وقرأ أهل الحجاز والبصرة نشراً بضم النون والشين واختاره أبو حاتم فقال : هي جمع نشور مثل صبور وصابر ،   وشكور وشاكر .  <br />
وهي الرياح التي تهب من كل ناحية وتجيء من كل [ وجه ] وقرأ الحسن وأبو رجاء وأبو عبد الرحمن وابن عامر نشراً بضم النون وجزم الشين على التخفيف .  <br />
وقرأ مسروق ( نشراً ) بفتحتين أراد منشوراً [ كالمقبض ] والقبض { بَيْنَ يَدَيْ رَحْمَتِهِ } يعني قدّام المطر { حَتَّى إِذَآ أَقَلَّتْ } حملت { سَحَاباً ثِقَالاً } المطر { سُقْنَاهُ } رد الكناية إلى لفظ السحاب { لِبَلَدٍ مَّيِّتٍ } يعني إلى بلد .  <br />
وقيل : معناه [ لأجل ] بلد لا نبات له { فَأَنْزَلْنَا بِهِ } أي السحاب وقيل : بالبلد { الْمَآءَ } يعني المطر ،   وقال أبو بكر بن عيّاش : لا تقطر من السماء قطرة حتّى يعمل فيها أربع : رياح الصبا تهيّجه والشمال تجمعه والجنوب تدرّه والدبور تفرّقة { كَذلِكَ نُخْرِجُ الْموْتَى } أحياء قال أبو هريرة وابن عباس : إذا مات الناس كلّهم في النفخة الأولى أمطر عليهم أربعين عاماً [ يسقى ] الرجال من ماء تحت العرش يُدعى ماء الحيوان فينبتون في قبورهم بذلك المطر كما ينبتون في بطون أُمهاتهم ،   وكما ينبت الزرع من الماء حتّى إذا استكملت أجسادهم نفخ فيهم الروح ثمّ يلقى عليهم نومة فينامون في قبورهم ،   فإذا نفخ في الصور الثانية عاشوا وهم يجدون طعم النوم في رؤوسهم وأعينهم كما يجد النائم إذا استيقظ من نومه فعند ذلك يقولون<br />
{ يوَيْلَنَا مَن بَعَثَنَا مِن مَّرْقَدِنَا } [ يس : 52 ] فيناديهم المنادي<br />
{ هَذَا مَا وَعَدَ الرَّحْمنُ وَصَدَقَ الْمُرْسَلُونَ } [ يس : 52 ] .
