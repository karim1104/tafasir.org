{ فَوَسْوَسَ } يعني إليهما ومعناه فحدث إليهما { الشَّيْطَانُ لِيُبْدِيَ لَهُمَا مَا وُورِيَ عَنْهُمَا مِن سَوْءَاتِهِمَا } يعني ليظهر لهما ما غطى وستر عنهما من عوراتهما ،   وقال وهب : كان عليهما نور لا يرى سوءاتهما ثمّ بين الوسوسة { وَقَالَ مَا نَهَاكُمَا } ياآدم وحواء { رَبُّكُمَا عَنْ هَذِهِ الشَّجَرَةِ إِلاَّ أَن تَكُونَا مَلَكَيْنِ } يعني إلاّ أن تكونا وكراهيّة أن يكونا من الملائكة يعملان الخير والشر .  <br />
وقرأ ابن عباس والضحاك ويحيى بن أبي معين : ملكين بكسر اللام من الملك أخذوها من قوله { هَلْ أَدُلُّكَ عَلَى شَجَرَةِ الْخُلْدِ وَمُلْكٍ لاَّ يَبْلَى } [ طه : 120 ] .   { أَوْ تَكُونَا مِنَ الْخَالِدِينَ } من الباقين الذين لا يموتون
