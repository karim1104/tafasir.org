{ قُل } يامحمد { لاَّ أَمْلِكُ لِنَفْسِي نَفْعاً وَلاَ ضَرّاً } أي اجتناب نفع ولا دفع { إِلاَّ مَا شَآءَ اللَّهُ } أي أملكه بتمليكه إياي { وَلَوْ كُنتُ أَعْلَمُ الْغَيْبَ لاَسْتَكْثَرْتُ مِنَ الْخَيْرِ } يعني المال وتهيأت لسنة القحط ما يكفيها { وَمَا مَسَّنِيَ السُّوءُ } وما مسّني الله [ بسوء ] .  <br />
وقال ابن جريج : { لاَّ أَمْلِكُ لِنَفْسِي نَفْعاً وَلاَ ضَرّاً } يعني الهدى والضلالة ولو كنت أعلم الغيب متى أموت لاستكثرت من الخير من العمل الصالح وما مسّني السوء .  <br />
قال ابن زيد : فاجتنبت ما يكون من الشر وأتقيه .   قال بعض أهل المعاني : ( لو كنت أعلم الغيب لاستكثرت من معرفته حتّى لا يخفى عليّ شيء { وَمَا مَسَّنِيَ السُّوءُ } يعني التكذيب .  <br />
وقال مقاتل : هذا متصل بالكلام الأول معناه : لا أقدر أن [ أسوق ] لنفسي خيراً أو أدفع عنها شراً حتّى ينزل بي فكيف أعلم وأملك علم الساعة ؟ وتمام الكلام قوله : لاستكثرت من الخير ،   ثم ابتدأ فقال : ( وما مسّني السوء ) [ يعني الجنون ] .  <br />
وقيل يعني لم يلحقني تكذيب { إِنْ أَنَاْ إِلاَّ نَذِيرٌ وَبَشِيرٌ لِّقَوْمٍ يُؤْمِنُونَ } يصدقون .  <br />
