وَلَقَدْ كُذِّبَتْ رُسُلٌ مِّن قَبْلِكَ } [ تسلية نبيه ] يقولون : كذبهم قومهم كما كذبتك قريش { فَصَبَرُواْ عَلَى مَا كُذِّبُواْ وَأُوذُواْ حَتَّى أَتَاهُمْ نَصْرُنَا وَلاَ مُبَدِّلَ لِكَلِمَاتِ اللَّهِ } قال الكلبي : يعني القرآن .  <br />
وقال عكرمة : يعني قوله<br />
{ وَلَقَدْ سَبَقَتْ كَلِمَتُنَا } [ الصافات : 171 ] { وَلاَ مُبَدِّلَ لِكَلِمَاتِ اللَّهِ } إلى قوله : { الْغَالِبُونَ } وقوله :<br />
{ إِنَّا لَنَنصُرُ رُسُلَنَا وَالَّذِينَ آمَنُواْ فِي الْحَيَاةِ الدُّنْيَا } [ غافر : 51 ] وقوله تعالى<br />
{ كَتَبَ اللَّهُ لأَغْلِبَنَّ أَنَاْ وَرُسُلِي } [ المجادلة : 21 ] العدل يعني لأخلفهما لعذابه { وَلَقدْ جَآءَكَ مِن نَّبَإِ الْمُرْسَلِينَ } من قبل كما يقول : أصابنا من مطر أي مطر .
