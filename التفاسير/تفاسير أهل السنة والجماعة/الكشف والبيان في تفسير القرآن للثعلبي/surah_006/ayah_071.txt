قُلْ أَنَدْعُواْ مِن دُونِ اللَّهِ } نزلت في عبد الرحمن بن أبي بكر حين دعا أباه إلى الكفر فأنزل اللّه تعالى قل أندعوا من دون اللّه { مَا لاَ يَنفَعُنَا } إن عبدناه { وَلاَ يَضُرُّنَا } إن تركناه { وَنُرَدُّ عَلَى أَعْقَابِنَا } إلى الشرك { بَعْدَ إِذْ هَدَانَا اللَّهُ } .  <br />
وتقول العرب لكل راجع خائب لم يظفر بحاجته : ردّ على عقبيه ونكص على عقبيه فيكون مثله { كَالَّذِي اسْتَهْوَتْهُ الشَّيَاطِينُ } أي أضلته .  <br />
وقال ابن عباس ( رضي الله عنه ) : كالذي استغوته الغيلان في المهامة وأضلوه وهو حائر بائر { فِي الأَرْضِ حَيْرَانَ } وحيران نصب على الحال .  <br />
وقرأ الأعمش ،   وحمزة : كالذي إستهوا به ،   بالباء .   وقرأ طلحة : إستهواه بالألف .  <br />
وقرأ الحسن : إستهوته الشياطون وفي مصحف عبد اللّه وأُبي إستهواه الشيطان على الواحد .  <br />
{ لَهُ أَصْحَابٌ يَدْعُونَهُ إِلَى الْهُدَى ائْتِنَا } يعني أتوا به ،   وقيل : أصحاب محمد صلى الله عليه وسلم { قُلْ إِنَّ هُدَى اللَّهِ هُوَ الْهُدَى وَأُمِرْنَا لِنُسْلِمَ } أي لأن نسلم { لِرَبِّ الْعَالَمِينَ *<br />
