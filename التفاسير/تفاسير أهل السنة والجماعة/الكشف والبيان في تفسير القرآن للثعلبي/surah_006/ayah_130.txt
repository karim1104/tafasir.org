{ يَامَعْشَرَ الْجِنِّ وَالإِنْسِ أَلَمْ يَأْتِكُمْ رُسُلٌ } .  <br />
قال الأعرج وابن أبي إسحاق : تأتكم بالتاء كقوله :<br />
{ لَقَدْ جَآءَتْ رُسُلُ رَبِّنَا بِالْحَقِّ } [ الأعراف : 43 ] .  <br />
قرأ الباقون : بالياء كقوله تعالى { مِثْلَ مَآ أُوتِيَ رُسُلُ اللَّهِ } { يَقُصُّونَ } يقرأون { عَلَيْكُمْ آيَاتِي وَيُنذِرُونَكُمْ لِقَآءَ يَوْمِكُمْ هَذَا } وهو يوم القيامة .  <br />
واختلف العلماء في الجن هل أُرسل إليهم رسول أم لا ؟ فقال عبيد بن سليمان : سئل الضحاك عن الجن هل كان فيهم مؤمن قبل أن يبعث النبي صلى الله عليه وسلم فقال : ألم تسمع قوله تعالى : { يَامَعْشَرَ الْجِنِّ وَالإِنْسِ أَلَمْ يَأْتِكُمْ رُسُلٌ مِّنْكُمْ } يعني بذلك رسلاً من الإنس ورسلاً من الجن .  <br />
قال الكلبي : كانت الرسل قبل أن يبعث النبي صلى الله عليه وسلم يبعثون إلى الجن والإنس جميعاً .  <br />
قال مجاهد : الرسل من الإنس .   والنذير من الجن ثم قرأ<br />
{ وَلَّوْاْ إِلَى قَوْمِهِم مُّنذِرِينَ } [ الأحقاف : 29 ] .  <br />
قال ابن عباس : هم الذين استمعوا القرآن وأبلغوه قومهم .  <br />
وقال أهل المعاني : لم يكن من الجن رسول وإنما الرسل من الإنس خاصة وهذا كقوله تعالى<br />
{ يَخْرُجُ مِنْهُمَا الُّلؤْلُؤُ وَالمَرْجَانُ } [ الرحمن : 22 ] وإنما يخرج من المالح دون العذب .  <br />
وقوله<br />
{ وَيَذْكُرُواْ اسْمَ اللَّهِ فِي أَيَّامٍ مَّعْلُومَاتٍ } [ الحج : 28 ] وهي أيام العشر وإنما الذبح في يوم واحد من العشر فهو يوم النحر .   وقوله<br />
{ وَجَعَلَ الْقَمَرَ فِيهِنَّ نُوراً } [ نوح : 16 ] وإنما هو في سماء واحدة { قَالُواْ شَهِدْنَا عَلَى أَنْفُسِنَا وَغَرَّتْهُمُ الْحَيَاةُ الدُّنْيَا وَشَهِدُواْ } أقروا { عَلَى أَنْفُسِهِمْ أَنَّهُمْ كَانُواْ كَافِرِينَ *
