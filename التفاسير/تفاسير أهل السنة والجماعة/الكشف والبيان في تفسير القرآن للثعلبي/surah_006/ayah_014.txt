{ قُلْ } يا محمد { أَغَيْرَ اللَّهِ أَتَّخِذُ وَلِيّاً } رباً معبوداً وناصراً ومعيناً { فَاطِرِ السَّمَاوَاتِ وَالأَرْضِ } أي خالقها ومبدعها ومبدئها وأصل الفطر الشق ومنه فطر ناب الجمل إذا شقق وابتدأ بالخروج .  <br />
قال مجاهد : سمعت ابن عباس يقول : كنت لا أدري ما فاطر السماوات والأرض حتى أتاني اعرابيان يختصمان في بعير .   فقال أحدهما لصاحبه : أنا فطرتها ،   أنا أحدثتها { وَهُوَ يُطْعِمُ وَلاَ يُطْعَمُ } أي وهو يرزق ولا يرزق وإليه قوله عز وجل<br />
{ مَآ أُرِيدُ مِنْهُم مِّن رِّزْقٍ وَمَآ أُرِيدُ أَن يُطْعِمُونِ } [ الذاريات : 57 ] .  <br />
وقرأ عكرمة والأعمش : ولا يَطعم بفتح الياء أي وهو يرزق ولا يأكل .  <br />
وقرأ أشهب العقيلي : وهو يُطعِم ولا يُطعَم كلاهما بضم الياء ،   وكسر العين .  <br />
قال الحسن بن الفضل : معناه هو القادر على الإطعام وترك الإطعام كقوله<br />
{ يَبْسُطُ الرِّزْقَ لِمَنْ يَشَآءُ وَيَقَدِرُ } [ الرعد : 26 ] .  <br />
وسمعت أبا القاسم الحبيبي يقول : سمعت أبا منصور الأزهري بهراة يقول : معناه وهو يطعم ولا يستطعم ،   يقول العرب : أطعمت غيري بمعنى استطعمت .  <br />
وأنشد :<br />
إنّا لنطعم من في الصيف مطعماً *** وفي الشتاء إذا لم يؤنس القرع<br />
أي استطعمنا وقيل : معناه وهو يطعم يعني اللّه ولا يطعم يعني الولي { قُلْ إِنِّي أُمِرْتُ أَنْ أَكُونَ أَوَّلَ مَنْ أَسْلَمَ } أخلص { وَلاَ تَكُونَنَّ } يعني وقيل لي : ولا تكونن { مِنَ الْمُشْرِكَينَ }
