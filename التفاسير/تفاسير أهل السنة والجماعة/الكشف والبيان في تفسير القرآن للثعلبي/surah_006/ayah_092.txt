{ وَهَذَا كِتَابٌ } يعني القرآن { أَنزَلْنَاهُ مُبَارَكٌ } أي وهذا كتاب مبارك أنزلناه { مُّصَدِّقُ الَّذِي بَيْنَ يَدَيْهِ وَلِتُنذِرَ } تخبر .  <br />
وقرأ عاصم : بالياء أي ولينذر الكتاب { أُمَّ الْقُرَى } يعني مكة سمّاها أم القرى لأن الأرض دحيت من تحتها { وَمَنْ حَوْلَهَا } تحمل الأرض كلها شرقاً وغرباً { وَالَّذِينَ يُؤْمِنُونَ بِالآخِرَةِ يُؤْمِنُونَ بِهِ } بالكتاب { وَهُمْ عَلَى صَلاَتِهِمْ } يعني الصلوات الخمس { يُحَافِظُونَ } يداومون<br />
