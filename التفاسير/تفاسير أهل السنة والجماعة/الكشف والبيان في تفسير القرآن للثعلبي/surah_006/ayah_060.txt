وَهُوَ الَّذِي يَتَوَفَّاكُم بِاللَّيْلِ } أي يقبض أرواحكم في منامكم { وَيَعْلَمُ مَا جَرَحْتُم بِالنَّهَارِ } وأصله من [ جارحة ] اليد .  <br />
ثم قيل لكل عليك جارح أي عضو من أعضائه عمل ومنه [ الزرع الجيد ] ،   ويقال لا ترك اللّه له جارحاً أي عبداً ولا أمة يكسب له { ثُمَّ يَبْعَثُكُمْ } أي ينشركم ويوقظكم { فِيهِ } في النار { لِيُقْضَى أَجَلٌ مُّسَمًّى } يعني أجل الحياة إلى الممات حتى ينقضي أثرها ورزقها .  <br />
فقرأ أبو طلحة وأبو رجاء بالنون المفتوحة أجلاً نصب ،   وفي هذا إقامة الحجة على منكري البعث يعني كما قدرت على هذا فكذلك أقدر على بعثكم بعد الموت .  <br />
وقال : مكتوب في التوراة : يا ابن آدم كما تنام كذلك تموت وكما توقظ كذلك تبعث { ثُمَّ إِلَيْهِ مَرْجِعُكُمْ } في الآخرة { ثُمَّ يُنَبِّئُكُم } يخبركم ويجازيكم { بِمَا كُنتُمْ تَعْمَلُونَ *<br />
