{ لَهُمْ دَارُ السَّلاَمِ عِندَ رَبِّهِمْ } يعني الجنة في الآخرة .  <br />
قال أكثر المفسرين : السلام هو اللّه عز وجل وداره الجنة .   وقيل : سميت الجنة دار السلام لسلامتها من الآفات والعاهات .  <br />
وقيل : لأن من دخلها سلم من البلايا والرزايا أجمع .  <br />
وقيل : لأنها سلمت من دخول أعداء اللّه كيلا ينتغص أولياء الله فيها كما يُنغّص مجاورتهم في الدنيا .  <br />
وقيل : سميت بذلك لأن كل حالة من حالات أهلها مقرونة بالسلام فاما ابتداء دخولها فقوله { لَهُمْ دَارُ السَّلاَمِ عِندَ رَبِّهِمْ } وبعد ذلك قوله<br />
{ وَالمَلاَئِكَةُ يَدْخُلُونَ عَلَيْهِمْ مِّن كُلِّ بَابٍ }<br />
الآية [ الرعد : 23 ] .   وبعده قوله<br />
{ وَتَحِيَّتُهُمْ فِيهَا سَلاَمٌ } [ يونس : 10 ] وبعده قوله<br />
{ لاَّ يَسْمَعُونَ فِيهَا لَغْواً إِلاَّ سَلاَماً } [ مريم : 62 ] وقوله<br />
{ لاَ يَسْمَعُونَ فِيهَا لَغْواً وَلاَ تَأْثِيماً * إِلاَّ قِيلاً سَلاَماً سَلاَماً } [ الواقعة : 25-26 ] وبعده قوله<br />
{ تَحِيَّتُهُمْ يَوْمَ يَلْقَوْنَهُ سَلاَمٌ } [ الأحزاب : 44 ] وبعد ذلك<br />
{ سَلاَمٌ قَوْلاً مِّن رَّبٍّ رَّحِيمٍ } [ يس : 58 ] .   فلما كان حالات أهل الجنة مقرونة بالسلام إما من الخلق وإما من الحق سمّاها اللّه دار السلام { وَهُوَ وَلِيُّهُمْ } ناصرهم ومعينهم { بِمَا كَانُواْ يَعْمَلُونَ } .  <br />
قال الحسن بن الفضل : يعني يتولاهم في الدنيا بالتوفيق وفي الآخرة بالجزاء .
