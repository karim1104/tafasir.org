{ سَرَابِيلُهُم } قمصهم واحدها سربال والفعل منه تسربلت وسربلت غيري { مِّن قَطِرَانٍ } وهو الذي تهنأ به الإبل ويقال له الخضخاض .  <br />
قال الحسن وقرأ عيسى بن عمر : { قَطرَانٍ } بفتح القاف وتسكين الطاء ،   وفيه لغة ثالثة قِطران بكسر القاف وجزم الطاء ،   ومنه قول أبي النجم :<br />
جون كأن العرق المنتوحا *** لبسه القطران والمسوحا<br />
وقرأ عكرمة : برواية زيد : قطران على كلمتين منونتين { قَطِرَانٍ } والقطر النحاس الصفر المذاب .   قال الله<br />
{ آتُونِي أُفْرِغْ عَلَيْهِ قِطْراً } [ الكهف : 96 ] والآن الذي انتهى خبره قال الله تعالى { يَطُوفُونَ بَيْنَهَا وَبَيْنَ حَمِيمٍ آنٍ } [ الرحمن : 44 ] { وَتَغْشَى وُجُوهَهُمُ النَّارُ } .
