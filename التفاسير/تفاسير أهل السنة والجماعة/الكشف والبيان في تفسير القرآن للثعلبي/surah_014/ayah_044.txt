{ وَأَنذِرِ النَّاسَ يَوْمَ يَأْتِيهِمُ الْعَذَابُ } وهو يوم القيامة { فَيَقُولُ } عطف على يوم يأتيهم وليس بجواب فلذلك وقع { الَّذِينَ ظَلَمُواْ } أشركوا { رَبَّنَآ أَخِّرْنَآ } أمهلنا { إِلَى أَجَلٍ قَرِيبٍ } وهو الدنيا يعني أرجعنا إليها { نُّجِبْ دَعْوَتَكَ وَنَتَّبِعِ الرُّسُلَ } فيجابون { أَوَلَمْ تَكُونُواْ أَقْسَمْتُمْ } حلفتم { مِّن قَبْلُ } في دار الدنيا { مَا لَكُمْ مِّن زَوَالٍ } فيها أي لا يبعثون ،   وهو قوله { وَأَقْسَمُواْ بِاللَّهِ جَهْدَ أَيْمَانِهِمْ لاَ يَبْعَثُ اللَّهُ مَن يَمُوتُ } [ النحل : 38 ] .
