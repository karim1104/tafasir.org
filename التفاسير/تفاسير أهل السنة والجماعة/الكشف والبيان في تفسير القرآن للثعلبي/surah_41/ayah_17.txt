{ وأما وَأَمَّا ثَمُودُ } قرأ الأعمش ويحيى بن وثاب ،   { ثَمُودُ } بالرفع والتنوين ،   وكانا يجران ثموداً في القرآن كله إلاّ قوله :<br />
{ وَآتَيْنَا ثَمُودَ النَّاقَةَ } [ الإسراء : 59 ] ،   فإنّهما كانا لا يجرانه هاهنا من أجل إنّه مكتوب في المصحف هاهنا بغير ألف ،   وقرأ ابن أبي إسحاق { وَأَمَّا ثَمُودُ } منصوباً غير منون ،   وقرأ الباقون مرفوعاً غير منون .  <br />
{ فَهَدَيْنَاهُمْ } دعوناهم وبيّنا لهم .   { فَاسْتَحَبُّواْ الْعَمَى عَلَى الْهُدَى } فاختاروا الكفر على الإيمان .   { فَأَخَذَتْهُمْ صَاعِقَةُ } مهلكة .   { الْعَذَابِ الْهُونِ } أي الهوان ،   ومجازه : ذي هون .   { بِمَا كَانُواْ يَكْسِبُونَ }
