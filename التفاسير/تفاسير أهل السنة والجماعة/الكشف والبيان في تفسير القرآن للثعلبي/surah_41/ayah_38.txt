{ فَإِنِ اسْتَكْبَرُواْ } عن السجود .   { فَالَّذِينَ عِندَ رَبِّكَ } يعني الملائكة .   { يُسَبِّحُونَ لَهُ بِاللَّيْلِ وَالنَّهَارِ وَهُمْ لاَ يَسْأَمُونَ } .   لقوله تعالى : { إِنَّ الَّذِينَ عِندَ رَبِّكَ لاَ يَسْتَكْبِرُونَ عَنْ عِبَادَتِهِ وَيُسَبِّحُونَهُ وَلَهُ يَسْجُدُونَ } .  <br />
