{ لِّيُدْخِلَ الْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا الأَنْهَارُ } قال أهل المعاني : وإنّما كرّر ( اللام ) في قوله : { لِّيُدْخِلَ الْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ } بتأويل تكرير الكلام مجازه { إِنَّا فَتَحْنَا لَكَ فَتْحاً مُّبِيناً لِّيَغْفِرَ لَكَ اللَّهُ مَا تَقَدَّمَ مِن ذَنبِكَ وَمَا تَأَخَّرَ } إنّا فتحنا لك { لِّيُدْخِلَ الْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا الأَنْهَارُ خَالِدِينَ فِيهَا وَيُكَفِّرَ عَنْهُمْ سَيِّئَاتِهِمْ وَكَانَ ذَلِكَ عِندَ اللَّهِ فَوْزاً عَظِيماً * }<br />
