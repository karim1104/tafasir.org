قال لهما : { لاَ يَأْتِيكُمَا طَعَامٌ تُرْزَقَانِهِ } في نومكما { إِلاَّ نَبَّأْتُكُمَا بِتَأْوِيلِهِ } في اليقظة .  <br />
هذا قول أكثر المفسّرين ،   وقال بعضهم : أراد به في اليقظة فقال : { لاَ يَأْتِيكُمَا طَعَامٌ تُرْزَقَانِهِ } تطعمانه وتأكلانه { إِلاَّ نَبَّأْتُكُمَا بِتَأْوِيلِهِ } بتفسيرة قال : إنّه أيّ طعام أكلتم ومتى أكلتُم وكم أكلتُم ،   فقالا له : هذا من فعل العَرّافين والكَهنة ،   فقال لهما ( عليه السلام ) : ما أنا بكاهن وإنّما { ذلِكُمَا } العلم { مِمَّا عَلَّمَنِي رَبِّي إِنِّي تَرَكْتُ مِلَّةَ قَوْمٍ لاَّ يُؤْمِنُونَ بِاللَّهِ وَهُمْ بِالآخِرَةِ هُمْ كَافِرُونَ } كرّرهُم على التأكيد .   وقيل : هم الأوّل جماد كقوله تعالى :<br />
{ أَيَعِدُكُمْ أَنَّكُمْ إِذَا مِتُّمْ وَكُنتُمْ تُرَاباً وَعِظاماً أَنَّكُمْ مُّخْرَجُونَ } [ المؤمنون : 35 ] فصارت الأولى المُلغاة والثانية ابتداء ،   وكافرون خبره .
