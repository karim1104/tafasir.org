{ أَفَأَمِنُواْ أَن تَأْتِيَهُمْ غَاشِيَةٌ مِّنْ عَذَابِ اللَّهِ } قال ابن عباس : مُجللة ،   مجاهد : عذاب يغشاهم ،   نظيره قوله :<br />
{ يَوْمَ يَغْشَاهُمُ الْعَذَابُ مِن فَوْقِهِمْ وَمِن تَحْتِ أَرْجُلِهِمْ } [ العنكبوت : 55 ] : قتادة : وقيعة ،   الضحّاك : يعني الصواعق والقوارع { أَوْ تَأْتِيَهُمُ السَّاعَةُ } القيامة { بَغْتَةً } فجأة ،   { وَهُمْ لاَ يَشْعُرُونَ } بقيامها ،   ابن عباس : تصيح الصيحة بالناس وهم في أسواقهم .
