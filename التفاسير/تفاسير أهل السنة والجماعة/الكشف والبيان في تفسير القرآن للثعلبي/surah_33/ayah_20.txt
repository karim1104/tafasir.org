قوله : { يَحْسَبُونَ } يعني هؤلاء المنافقين { الأَحْزَابَ } يعني قريشاً وغطفان واليهود الذين تحزبوا على عداوة رسول الله صلّى الله عليه وسلم ومخالفته أي اجتمعوا ،   والأحزاب الجماعات واحدهم حزب .  <br />
{ لَمْ يَذْهَبُواْ } ولم ينصرفوا عن قتالهم وقد انصرفوا منهم جماعةً وفرقاً .  <br />
{ وَإِن يَأْتِ الأَحْزَابُ } إن يرجعوا إليكم كرّةً ثانية .  <br />
{ يَوَدُّواْ } من الخوف والجبن { لَوْ أَنَّهُمْ بَادُونَ } خارجون إلى البادية { فِي الأَعْرَابِ } أي معهم { يَسْأَلُونَ } قراءة العامّة بالتخفيف ،   وقرأ عاصم الحجدري ويعقوب في رواية رويس وزيد مشدّدة ممدودة بمعنى يتساءلون أي يسأل بعضهم بعضاً .  <br />
{ عَنْ أَنبَآئِكُمْ } أخباركم وما آل إليه أمركم { وَلَوْ كَانُواْ فِيكُمْ } يعني هؤلاء المنافقين { مَّا قَاتَلُواْ إِلاَّ قَلِيلا } رياءً من غير حسبة ،   ولو كان ذلك القليل لله لكان كثيراً .  <br />
