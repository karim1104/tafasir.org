{ لِّيَجْزِيَ اللَّهُ الصَّادِقِينَ بِصِدْقِهِمْ وَيُعَذِّبَ الْمُنَافِقِينَ إِن شَآءَ أَوْ يَتُوبَ عَلَيْهِمْ إِنَّ اللَّهَ كَانَ غَفُوراً رَّحِيماً * وَرَدَّ اللَّهُ الَّذِينَ كَفَرُواْ } من قريش وغطفان { بِغَيْظِهِمْ لَمْ يَنَالُواْ خَيْراً } نصراً وظفراً { وَكَفَى اللَّهُ الْمُؤْمِنِينَ الْقِتَالَ } بالملائكة والريح { وَكَانَ اللَّهُ قَوِيّاً عَزِيزاً } .  <br />
