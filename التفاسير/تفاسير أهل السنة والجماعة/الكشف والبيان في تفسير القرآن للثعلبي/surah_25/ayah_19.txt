{ فَقَدْ كَذَّبُوكُمْ بِمَا تَقُولُونَ } أنّهم كانوا آلهة { فَمَا تَسْتَطِيعُونَ } قرأه العامة بالياء يعني الآلهة ،   وقرأ حفص بالتاء يعني العابدين { صَرْفاً وَلاَ نَصْراً } أي صرف العذاب عنهم ولا نصر أنفسهم .  <br />
وقال يونس : الصرف : الحيلة ومنه قول العرب : إنه ليتصرف أي يحتال .  <br />
وقال الأصمعي : الصرف : التوبة والعدل : الفدية .  <br />
{ وَمَن يَظْلِم } أي يشرك { مِّنكُمْ نُذِقْهُ عَذَاباً كَبِيراً }<br />
