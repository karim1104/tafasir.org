{ فَتَوَلَّى } فأعرض وأدبر عن الإيمان { بِرُكْنِهِ } بقوته وقومه ،   نظيره<br />
{ أَوْ آوِي إِلَى رُكْنٍ شَدِيدٍ } [ هود : 80 ] يعني المنعة والعشيرة ،   وقال المؤرخ : بجانبه { وَقَالَ سَاحِرٌ أَوْ مَجْنُونٌ } قال أبو عبيدة : ( أو ) بمعنى ( الواو ) ؛ لأنهم قد قالوهما جميعاً ،   وأنشد بيت جرير :<br />
أثعلبة الفوارس أو رياحاً *** عدلت بهم طهيّة والخشابا<br />
وقد يوضع ( أو ) بمعنى ( الواو ) كقوله :<br />
{ آثِماً أَوْ كَفُوراً } [ الإنسان : 24 ] و ( الواو ) بمعنى ( أو ) كقوله سبحانه :<br />
{ فَانكِحُواْ مَا طَابَ لَكُمْ مِّنَ النِّسَآءِ مَثْنَى وَثُلاَثَ وَرُبَاعَ } [ النساء : 3 ] .
