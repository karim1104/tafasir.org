ثمَّ ذكر الكفار فقال عزَّ من قائل { بَلْ قُلُوبُهُمْ فِي غَمْرَةٍ } عمى وغفلة { مِّنْ هَذَا } القرآن { وَلَهُمْ أَعْمَالٌ } خبيثة لا يرضاها الله من المعاصي والخطايا { مِّن دُونِ ذلِكَ } يعني من دون أعمال المؤمنين التي ذكرها الله سبحانه ،   قيل : وهي قوله { إِنَّ الَّذِينَ هُم مِّنْ خَشْيةِ رَبِّهِمْ مُّشْفِقُونَ } .  <br />
{ هُمْ لَهَا عَامِلُونَ } لابد لهم من أن يعملوها فيدخلوا بها النار لما سبق لهم من الشقاوة .  <br />
