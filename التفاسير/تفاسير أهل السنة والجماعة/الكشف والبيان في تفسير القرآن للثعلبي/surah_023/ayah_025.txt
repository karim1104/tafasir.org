{ إِنْ هُوَ } ما هو { إِلاَّ رَجُلٌ بِهِ جِنَّةٌ } جنون ،   نظيرها قوله سبحانه<br />
{ مَا بِصَاحِبِهِمْ مِّن جِنَّةٍ } [ الأعراف : 184 ] ويقال للجن أيضاً : جنّة ،   قال الله سبحانه<br />
{ وَجَعَلُواْ بَيْنَهُ وَبَيْنَ الْجِنَّةِ نَسَباً } [ الصافات : 158 ] وقال<br />
{ مِنَ الْجِنَّةِ وَالنَّاسِ } [ الناس : 6 ] يتفق الاسم والمصدر .  <br />
{ فَتَرَبَّصُواْ } فانتظروا { بِهِ حَتَّى حِينٍ } يعني إلى وقت ما ،   وقيل : الى حين الموت ،
