{ وَالَّذِينَ هُمْ لأَمَانَاتِهِمْ } التي ائتمنوا عليها { وَعَهْدِهِمْ } وعقودهم التي عاقدوا الناس عليها { رَاعُونَ } حافظون وافون .  <br />
وقرأ ابن كثير : لأمانتهم على الواحد لقوله : «وعهدهم » .   الباقون : بالجمع لقوله<br />
{ إِنَّ اللَّهَ يَأْمُرُكُمْ أَن تُؤدُّواْ الأَمَانَاتِ إِلَى أَهْلِهَا } [ النساء : 58 ] .
