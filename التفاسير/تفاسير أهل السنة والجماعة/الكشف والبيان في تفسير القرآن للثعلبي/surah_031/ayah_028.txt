قوله : { مَّا خَلْقُكُمْ وَلاَ بَعْثُكُمْ إِلاَّ كَنَفْسٍ وَاحِدَةٍ } يعني إلاّ كخلق نفس واحدة وبعثها لا يتعذر عليه شيء وهذا كقوله :<br />
{ تَدُورُ أَعْيُنُهُمْ كَالَّذِي يُغْشَى عَلَيْهِ مِنَ الْمَوْتِ } [ الأحزاب : 19 ] أي كدوران عين الذي يغشى عليه من الموت .  <br />
{ إِنَّ اللَّهَ سَمِيعٌ بَصِيرٌ }
