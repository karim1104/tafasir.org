{ لَّيْسَ عَلَى الضُّعَفَآءِ } قال ابن عباس : يعني الزمنى والمشايخ والعجزة { وَلاَ عَلَى الْمَرْضَى وَلاَ عَلَى الَّذِينَ لاَ يَجِدُونَ مَا يُنفِقُونَ } يعني الفقراء { حَرَجٌ } إثم { إِذَا نَصَحُواْ للَّهِ وَرَسُولِهِ } في مغيبهم { مَا عَلَى الْمُحْسِنِينَ مِن سَبِيلٍ وَاللَّهُ غَفُورٌ رَّحِيمٌ } .  <br />
