قال المفسّرون : سبب نزول هذه الآية : أنّ اليهود ادعوا دعاوى باطلة ،   حكاها الله تعالى عنهم في كتابه كقوله تعالى { وَقَالُواْ لَن تَمَسَّنَا النَّارُ إِلاَّ أَيَّاماً مَّعْدُودَةً } [ البقرة : 80 ] .  <br />
وقوله : { وَقَالُواْ لَن يَدْخُلَ الْجَنَّةَ إِلاَّ مَن كَانَ هُوداً أَوْ نَصَارَى } [ البقرة : 111 ] .  <br />
وقوله : { نَحْنُ أَبْنَاءُ اللَّهِ وَأَحِبَّاؤُهُ } [ المائدة : 18 ] فكذبهم الله تعالى ،   وألزمهم الحجة .   فقال : قل يا محمّد إن كانت لكم الدّار الآخرة عند الله .   <br />
{ خَالِصَةً مِّن دُونِ النَّاسِ } خاصّة ؛ لقوله تعالى { خَالِصَةٌ لِّذُكُورِنَا } [ الأنعام : 139 ] ،   قوله { خَالِصَةً يَوْمَ الْقِيَامَةِ } [ الأعراف : 32 ] ،   قوله { خَالِصَةً لَّكَ مِن دُونِ الْمُؤْمِنِينَ } [ الأحزاب : 50 ] أي خاصّة من دون النّاس .   { فَتَمَنَّوُاْ الْمَوْتَ } أي فأريدو وحَلّوه لأنّ من علم أنّ الجنّة مآبه حنَّ إليها ولا سبيل إلى دخولها إلاّ بعد الموت فاستعجلوه بالتمني .   { إِن كُنْتُمْ صَادِقِينَ } في قولكم محقين في دعواكم ،   وقيل في قوله تعالى { فَتَمَنَّوُاْ الْمَوْتَ } أيّ ادعوا بالموت على الفرقة الكاذبة .  <br />
روى ابن عبّاس عن النبيّ صلى الله عليه وسلم قال :  "  لو تمنّوا الموت لغصّ كل إنسان منهم بريقه ،   وما بقي على وجه الأرض يهودي إلاّ مات  "  .
