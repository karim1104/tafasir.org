{ مَّنِ اهْتَدَى فَإِنَّمَا يَهْتَدي لِنَفْسِهِ } لها نوليه { وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } لأن عليها عقابه { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَى } ولا يحمل حامله عمل أخر من الأثام { وَمَا كُنَّا مُعَذِّبِينَ حَتَّى نَبْعَثَ رَسُولاً } إقامة للحجة عليهم بالآيات التي تقطع عذرهم<br />
