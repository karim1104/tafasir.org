{ وَإِذَا مَسَّكُمُ الْضُّرُّ } أصابكم [ الجهد ] { فِي الْبَحْرِ } وخفتم الغرق { ضَلَّ مَن تَدْعُونَ إِلاَّ إِيَّاهُ } إلا دعاؤكم إياه فلم تجدوا ما يكفيكم سواه { فَلَمَّا نَجَّاكُمْ } من البحر وأخرجكم { إِلَى الْبَرِّ أَعْرَضْتُمْ } عن الايمان والطاعة وكفرتم بما جاءكم { وَكَانَ ا  ؛لإِنْسَانُ كَفُوراً }<br />
