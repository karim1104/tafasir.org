{ وَمَنْ أَظْلَمُ مِمَّنْ افْتَرَى عَلَى اللَّهِ كَذِباً } فزعموا أنّ لله شريكاً ،   وقالوا إذا فعلوا فاحشة ،  <br />
{ قَالُواْ وَجَدْنَا عَلَيْهَآ آبَاءَنَا وَاللَّهُ أَمَرَنَا بِهَا } [ الأعراف : 28 ] .  <br />
{ أَوْ كَذَّبَ بِالْحَقِّ } بمحمد والقرآن { لَمَّا جَآءَهُ أَلَيْسَ فِي جَهَنَّمَ مَثْوًى } منزل { لِّلْكَافِرِينَ }
