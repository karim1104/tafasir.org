{ فَكُلاًّ أَخَذْنَا } عاقبنا { بِذَنبِهِ فَمِنْهُم مَّن أَرْسَلْنَا عَلَيْهِ حَاصِباً } ريحاً تأتي في الحصباء ،   وهي الحصى الصغار ،   وهم قوم لوط { وَمِنْهُمْ مَّنْ أَخَذَتْهُ الصَّيْحَةُ } يعني ثموداً .   { وَمِنْهُمْ مَّنْ خَسَفْنَا بِهِ الأَرْضَ } قارون وأصحابه { وَمِنْهُمْ مَّنْ أَغْرَقْنَا } فرعون وقومه وقوم نوح .  <br />
{ وَمَا كَانَ اللَّهُ لِيَظْلِمَهُمْ وَلَكِن كَانُواْ أَنفُسَهُمْ يَظْلِمُونَ } .  <br />
