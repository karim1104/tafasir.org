{ أَصْطَفَى } .   قرأ العامة بقطع الألف ؛ لأنه ألف استفهام دخلت على ألف الوصل فحذفت ألف الوصل وبقيت ألف الاستفهام مفتوحة على حالها مثل<br />
{ أَسْتَكْبَرْتَ } [ ص : 75 ] و<br />
{ أَسْتَغْفَرْتَ } [ المنافقون : 6 ] و<br />
{ أَذْهَبْتُمْ } [ الأحقاف : 20 ] ونحوها .  <br />
وقرأ أبو جعفر ونافع في بعض الروايات ( الكاذبون اصطفى ) موصولة على الخبر والحكاية عن قول المشركين ،   مجازه : { لَيَقُولُونَ * وَلَدَ اللَّهُ } ويقولون { أَصْطَفَى } { الْبَنَاتِ عَلَى الْبَنِينَ }
