{ الر كِتَابٌ } قيل { الر } مبتدأ وكتاب خبره ،   وقيل : كتاب رفع على خبر ابتداء مضمر تقديره : هذا كتاب { أُحْكِمَتْ آيَاتُهُ } قال ابن عباس : أُحكمت آياته : لم تنسخ بكتاب كما نسخت الكتب والشرائع بها { ثُمَّ فُصِّلَتْ } بُيّنت بالأحكام والحلال والحرام ،   قال الحسن وأبو العالية : فُصّلت : فُسِّرت { مِن لَّدُنْ حَكِيمٍ خَبِيرٍ * }<br />
