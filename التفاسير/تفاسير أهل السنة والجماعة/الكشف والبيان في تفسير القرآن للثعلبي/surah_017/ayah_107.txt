{ قُلْ آمِنُواْ بِهِ أَوْ لاَ تُؤْمِنُواْ } أمر وعد وتهديد { إِنَّ الَّذِينَ أُوتُواْ الْعِلْمَ مِن قَبْلِهِ } أي من قبل نزول القرآن وخروج محمد صلى الله عليه وسلم وهم مؤمنو أهل الكتاب { إِذَا يُتْلَى عَلَيْهِمْ } يعني القرآن { يَخِرُّونَ } يسقطون { لِلأَذْقَانِ } على الأذقان وهي جمع الذقن وهو مجتمع اللحيين ،   قال ابن عباس أراد الوجوه { سُجَّداً }<br />
