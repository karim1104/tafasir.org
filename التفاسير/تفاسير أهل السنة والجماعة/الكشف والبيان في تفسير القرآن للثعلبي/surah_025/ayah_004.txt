{ وَقَالَ الَّذِينَ كَفَرُواْ } يعني النضر بن الحرث واصحابه { إِنْ هَذَا } ما هذا القرآن { إِلاَّ إِفْكٌ افْتَرَاهُ } اختلقه محمد { وَأَعَانَهُ عَلَيْهِ قَوْمٌ آخَرُونَ } يعني اليهود عن مجاهد ،   وقال الحسن بن عبيد بن الحضر : الحبشي الكاهن ،   وقيل : جبر ويسار وعدّاس مولى حويطب بن عبد العزى ،   قال الله سبحانه وتعالى { فَقَدْ جَآءُوا } يعني ما يلي هذه المقالة { ظُلْماً وَزُوراً } بنسبتهم كلام الله سبحانه الى الإفك والافتراء<br />
