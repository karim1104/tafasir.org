{ لَن يَنَالَ اللَّهَ لُحُومُهَا وَلاَ دِمَآؤُهَا } وذلك أنّ أهل الجاهلية كانوا إذا نحروا البدن لطّخوا حيطان الكعبة بدمائها فأنزل الله سبحانه { لَن يَنَالَ اللَّهَ } أي لن يصل إلى الله { لُحُومُهَا وَلا دِمَآؤُهَا } .  <br />
{ وَلَكِن يَنَالُهُ التَّقْوَى مِنكُمْ } أي النيّة وإلاخلاص وما أُريد به وجه الله عزّ وجلّ ،   وقرأ يعقوب تنال وتناله بالتاء ،   غيره : بالياء .  <br />
{ كَذلِكَ } هكذا { سَخَّرَهَا } يعني البدن { لَكُمْ لِتُكَبِّرُواْ اللَّهَ عَلَى مَا هَدَاكُمْ } لإعلام دينه ومناسك حجّه وهو أن يقول : الله أكبر على ما هدانا والحمد لله على ما أبلانا وأولانا .  <br />
