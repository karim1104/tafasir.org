{ اللَّهُ يَصْطَفِي } يختار { مِنَ الْمَلاَئِكَةِ رُسُلاً } كجبرئيل وميكائيل وغيرهما { وَمِنَ النَّاسِ } أيضاً رسلاً مثل إبراهيم وموسى وعيسى ومحمد وغيرهم من الأنبياء صلوات الله عليهم ،   يقال : نزلت هذه الآية لمّا قال المشركون<br />
{ أَأُلْقِيَ الذِّكْرُ عَلَيْهِ مِن بَيْنِنَا } [ القمر : 25 ] فأخبر أن الاختيار إليه ،   يختار من يشاء من خلقه .  <br />
{ إِنَّ اللَّهَ سَمِيعٌ } لقولهم { بَصِيرٌ } بمن يختاره لرسالته .
