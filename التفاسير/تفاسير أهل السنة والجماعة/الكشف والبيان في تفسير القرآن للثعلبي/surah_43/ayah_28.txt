{ وَجَعَلَهَا } يعني هذه الكلمة والمقالة { كَلِمَةً بَاقِيَةً فِي عَقِبِهِ } قال مجاهد وقتادة : يعني لا إله إلاَّ الله ،   وقال القرظي : يعني وجعل وصية إبراهيم الّتي أوصى بها بنيه باقية في نسله وذريته وهي الّتي ذكرها الله تعالى في سورة البقرة :<br />
{ وَوَصَّى بِهَآ إِبْرَاهِيمُ بَنِيهِ } [ البقرة : 132 ] ،   وقال ابن زيد : يعني قوله :<br />
{ أَسْلَمْتُ لِرَبِّ الْعَالَمِينَ } [ البقرة : 131 ] وقرأ<br />
{ هُوَ سَمَّاكُمُ الْمُسْلِمِينَ } [ الحج : 78 ] .  <br />
{ لَعَلَّهُمْ يَرْجِعُونَ } من كفرهم إلى الطاعة ويتوبون
