{ تَرَى الظَّالِمِينَ } المشركين يوم القيامة { مُشْفِقِينَ } وجلين .   { مِمَّا كَسَبُواْ وَهُوَ وَاقِعٌ بِهِمْ } أي نازل بهم لا محالة .   { وَالَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ فِي رَوْضَاتِ الْجَنَّاتِ لَهُمْ مَّا يَشَآءُونَ عِندَ رَبِّهِمْ ذَلِكَ هُوَ الْفَضْلُ الْكَبِيرُ }<br />
