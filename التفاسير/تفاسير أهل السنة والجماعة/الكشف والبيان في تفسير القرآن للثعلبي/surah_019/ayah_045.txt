{ يأَبَتِ إِنِّي أَخَافُ } أعلم { أَن يَمَسَّكَ } يصيبك { عَذَابٌ مِّنَ الرَّحْمَنِ } لقوله :<br />
{ إِلاَّ أَن يَخَافَآ } [ البقرة : 229 ] وقوله<br />
{ فَإِنْ خِفْتُمْ أَلاَّ يُقِيمَا } [ البقرة : 229 ] وقيل : معناه إنّي أخاف أن ينزل عليك عذاباً في الدنيا { فَتَكُونَ لِلشَّيْطَانِ وَلِيّاً } قريناً في النار ،
