{ وَإِذَا مَآ أُنزِلَتْ سُورَةٌ فَمِنْهُمْ مَّن يَقُولُ أَيُّكُمْ } قراءة العامة : برفع الياء لمكان الهاء وقرأ عبيد بن عمير : أيكم بفتح الياء وكلّ صواب { زَادَتْهُ هَذِهِ إِيمَاناً } قال الله تعالى : { فَأَمَّا الَّذِينَ آمَنُواْ فَزَادَتْهُمْ إِيمَاناً } يقيناً وإخلاصاً وتصديقاً .  <br />
وقال الربيع : خشية { وَهُمْ يَسْتَبْشِرُونَ } يفرحون بنزول القرآن .   عن الضحاك عن ابن عباس : ( فإذا ما أنزلت سورة ) يعني سورة محكمة فيها الحلال والحرام { فَمِنْهُمْ مَّن يَقُولُ أَيُّكُمْ زَادَتْهُ هَذِهِ إِيمَاناً فَأَمَّا الَّذِينَ آمَنُواْ فَزَادَتْهُمْ إِيمَاناً } وتصديقاً بالفرائض مع إيمانهم بالرحمن { وَهُمْ يَسْتَبْشِرُونَ } بنزول الفرائض<br />
