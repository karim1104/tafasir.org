{ وَإِذَا مَآ أُنزِلَتْ سُورَةٌ } فيها عيب المنافقين وتوبيخهم { نَّظَرَ بَعْضُهُمْ إِلَى بَعْضٍ } كلام مختصر تقديره نظر بعضهم في بعض وقالوا أو أشاروا { هَلْ يَرَاكُمْ مِّنْ أَحَدٍ } إن قمتم فإن لم يرهم أحد خرجوا من المسجد وإن علموا أحداً يراهم قاموا فانصرفوا { ثُمَّ انصَرَفُواْ } عن الإيمان بها ،   وقال الضحاك : هل يراكم من أحد يعني أطلع أحد منهم على سرائركم مخافة القتل قال الله { صَرَفَ اللَّهُ قُلُوبَهُم } عن الإيمان بالقرآن { بِأَنَّهُمْ قَوْمٌ لاَّ يَفْقَهُونَ } قال ابن عباس : لا تقولوا إذا صليتم : انصرفنا من الصلاة فإن قوماً انصرفوا فصرف الله قلوبهم ،   لكن قولوا قضينا الصلاة .  <br />
