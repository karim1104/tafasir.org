{ إِنْ هِيَ } يعني هذه الأوثان { إِلاَّ أَسْمَآءٌ سَمَّيْتُمُوهَآ أَنتُمْ وَآبَآؤُكُم مَّآ أَنزَلَ اللَّهُ بِهَا مِن سُلْطَانٍ إِن يَتَّبِعُونَ } قرأ العامة بالياء ،   وقرأ عيسى بالتاء { إِلاَّ الظَّنَّ } في قولهم : إنّها آلهة وإنّها شفعاؤهم { وَمَا تَهْوَى الأَنفُسُ وَلَقَدْ جَآءَهُم مِّن رَّبِّهِمُ الْهُدَى } لبيان أنّها ليست بآلهة وأن العبادة لا تصلح إلاّ لله الواحد القهار .  <br />
