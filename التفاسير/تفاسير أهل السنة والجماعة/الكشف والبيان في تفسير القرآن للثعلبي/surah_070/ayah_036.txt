{ فَمَالِ الَّذِينَ كَفَرُواْ } فما بالهم كقوله سبحانه :<br />
{ فَمَا لَكُمْ فِي الْمُنَافِقِينَ فِئَتَيْنِ } [ النساء : 88 ] وقوله سبحانه :<br />
{ فَمَا لَهُمْ عَنِ التَّذْكِرَةِ مُعْرِضِينَ } [ المدثر : 49 ] .  <br />
