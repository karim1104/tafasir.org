{ لاَ يَذُوقُونَ فِيهَا الْمَوْتَ إِلاَّ الْمَوْتَةَ الأُولَى } يعني سوى { الْمَوْتَةَ الأُولَى } وبعدها وضع { إِلاَّ } موضع بعد كقوله :<br />
{ وَلاَ تَنكِحُواْ مَا نَكَحَ آبَاؤُكُمْ مِّنَ النِّسَآءِ إِلاَّ مَا قَدْ سَلَفَ } [ النساء : 22 ] .   يعني بعدما قد فعل آباؤكم وسواه ،   وهذا كما يقول في الكلام : ما ذقت اليوم طعاماً سوى ما أكلته أمس .  <br />
{ وَوَقَاهُمْ عَذَابَ الْجَحِيمِ }
