{ يُرِيدُونَ أَن يَخْرُجُواْ مِنَ النَّارِ } قرأه العامة بفتح الياء كقوله { وَمَا هُم بِخَارِجِينَ مِنْهَا وَلَهُمْ عَذَابٌ مُّقِيمٌ } قائم .  <br />
وقرأ أبو واقدة ،   والجرّاح يخرجوا بضمّ الياء كقوله<br />
{ رَبَّنَآ أَخْرِجْنَا مِنْهَا فَإِنْ عُدْنَا فَإِنَّا ظَالِمُونَ } [ المؤمنون : 107 ]<br />
{ وَمَا هُمْ مِّنْهَا بِمُخْرَجِينَ } [ الحجر : 48 ]
