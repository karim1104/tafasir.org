{ وَلَوْ أَنَّهُمْ أَقَامُواْ التَّوْرَاةَ وَالإِنْجِيلَ } يعني أقاموا أحكامهما وحدودهما وعملوا بما فيهما { وَمَآ أُنزِلَ إِلَيهِمْ مِّن رَّبِّهِمْ } أي القرآن .   وقيل : كُتب بني إسرائيل { لأَكَلُواْ مِن فَوْقِهِمْ } يعني المطر { وَمِن تَحْتِ أَرْجُلِهِم } يعني النبات .  <br />
وقال الفرّاء : إنما أراد به التوسعة كما يقال : فلان في خير من قرنه إلى قدمه ،   نظيره<br />
{ وَلَوْ أَنَّ أَهْلَ الْقُرَى آمَنُواْ وَاتَّقَواْ لَفَتَحْنَا عَلَيْهِمْ بَرَكَاتٍ مِّنَ السَّمَآءِ } [ الأعراف : 96 ] { مِّنْهُمْ أُمَّةٌ مُّقْتَصِدَةٌ } يعني مؤمني أهل الكتاب .   ابن سلام وأصحابه وثمانية وأربعون رجلاً من النصارى وهم النجاشي وبحيرا وسلمان الفارسي وخير مولى قريش وأصحابهم .  <br />
قال ابن عباس : هم العاملة غير العالية ولا الحافية { وَكَثِيرٌ مِّنْهُمْ } كعب بن الأشرف وأصحابه ،   وأهل الروم .   { سَآءَ مَا يَعْمَلُونَ } .
