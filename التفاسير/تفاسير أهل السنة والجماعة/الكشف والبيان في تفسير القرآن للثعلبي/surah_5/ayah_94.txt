{ يَأَيُّهَا الَّذِينَ آمَنُواْ لَيَبْلُوَنَّكُمُ اللَّهُ بِشَيْءٍ مِّنَ الصَّيْدِ } الآية<br />
 نزلت عام الحديبية ابتلاهم اللّه بالصيد فكان الوحش يغشي رجالهم كثير وهم محرمون ،   فبينما هم يسيرون بين مكة والمدينة إذ عرض إليهم حمار وحش ،   فحمل عليه أبو اليسر بن عمرو فطعنه برمحه فقتله ،   فقيل له : إنك قتلت الصيد وأنت حرم ،   فأتى رسول اللّه صلى الله عليه وسلم فسأله عن ذلك فأنزل اللّه { يَأَيُّهَا الَّذِينَ آمَنُواْ لَيَبْلُوَنَّكُمُ اللَّهُ } ليختبرنكم اللّه { بِشَيْءٍ مِّنَ الصَّيْدِ } ،   وإنما بعض فقال بشيء لأنه إبتلاهم بصيد البرّ خاصة  ،  { تَنَالُهُ أَيْدِيكُمْ } وهي الفراخ والبيض وما لا يستطيع أن يفر من الصيد الوحش ،   { وَرِمَاحُكُمْ } وهي الوحش وكبار الصيد { لِيَعْلَمَ اللَّهُ } ليرى اللّه من يخافه بالغيب ولم يره  ،   { مَن يَخَافُهُ بِالْغَيْبِ } فلا يصطاد في حال الإحرام ،   { فَمَنِ اعْتَدَى بَعْدَ ذلِكَ } أي صاده بعد تحريمه فاستحلّه { فَلَهُ عَذَابٌ أَلِيمٌ  }*<br />
