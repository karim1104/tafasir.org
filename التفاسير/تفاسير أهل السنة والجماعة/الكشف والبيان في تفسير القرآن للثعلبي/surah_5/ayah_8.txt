{ يَا أَيُّهَآ الَّذِينَ آمَنُواْ كُونُواْ قَوَّامِينَ للَّهِ شُهَدَآءَ بِالْقِسْطِ } أمرهم بالصدق والعدل في أقوالهم وأفعالهم { وَلاَ يَجْرِمَنَّكُمْ شَنَآنُ قَوْمٍ } ولا يحملنكم بغض قوم { عَلَى أَلاَّ تَعْدِلُواْ } أي على ترك العدل فيهم لعداوتهم ،   ثم قال : { اعْدِلُواْ } بين أوليائكم وأعدائكم { هُوَ أَقْرَبُ لِلتَّقْوَى } يعني إلى التقوى { وَاتَّقُواْ اللَّهَ إِنَّ اللَّهَ خَبِيرٌ } عالم { بِمَا تَعْمَلُونَ } مجازيكم به<br />
