{ مَا قُلْتُ لَهُمْ إِلاَّ مَآ أَمَرْتَنِي بِهِ أَنِ اعْبُدُواْ اللَّهَ } وحّدوه وأطيعوه ولا تشركوا به شيئاً { وَكُنتُ عَلَيْهِمْ شَهِيداً مَّا دُمْتُ فِيهِمْ } أقمت فيهم { فَلَمَّا تَوَفَّيْتَنِي } قبضتني إليك .  <br />
قال الحسن : الوفاة في كتاب اللّه على ثلاثة أوجه ،   وفاة الموت وذلك قوله  :{ اللَّهُ يَتَوَفَّى الأَنفُسَ حِينَ مَوْتِهَا } [ الزمر : 42 ] يعني وجعل نقصان أجلها وفاة النوم ،   وذلك قوله  : { وَهُوَ الَّذِي يَتَوَفَّاكُم بِاللَّيْلِ } [ الأنعام : 60 ] يعني ينيمكم ،   ووفاة بالرفع كقوله  : { إِنِّي مُتَوَفِّيكَ وَرَافِعُكَ } [ آل عمران : 55 ] .
