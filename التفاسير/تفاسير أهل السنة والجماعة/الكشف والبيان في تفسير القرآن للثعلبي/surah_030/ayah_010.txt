{ ثُمَّ كَانَ عَاقِبَةَ الَّذِينَ أَسَاءُواْ } العمل { السُّوأَى } يعني الخلّة التي تسوؤهم وهي النار .   وقيل : ( السّوأى ) اسم لجهنّم كما أنّ ( الحسنى ) اسم للجنة .  <br />
{ أَن كَذَّبُواْ } يعني لأن كذّبوا .   وقيل : تفسير ( السّوأى ) ما بعدها وهو قوله : { أَن كَذَّبُواْ } يعني : ثمّ كان عاقبة المسيئين التكذيب حملهم تلك السيئات على أنْ كذَّبوا { بِآيَاتِ اللَّهِ وَكَانُواْ بِهَا يَسْتَهْزِئُونَ } استهزءوا بها .  <br />
