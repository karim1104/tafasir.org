{ وَقَوْمَ نُوحٍ } قرأ أبو عمرو والاعمش وحمزة والكسائي وخلف ( وقوم ) بجرّ الميم في { وَقَوْمَ نُوحٍ } ،   وقرأ الباقون بالنصب ،   وله وجوه : أحدهما : أن يكون مردوداً على الهاء والميم في قوله { فَأَخَذَتْهُمُ الصَّاعِقَةُ } أي وأخذت قوم نوح ،   والثاني : وأهلكنا قوم نوح ،   والثالث : واذكر قوم نوح { مِّن قَبْلُ } أي من قبل عاد وثمود وقوم فرعون { إِنَّهُمْ كَانُواْ قَوْماً فَاسِقِينَ } .  <br />
