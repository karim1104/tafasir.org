{ الدِّينُ الْخَالِصُ } قال قتادة : شهادة ان لا إله إلاّ الله .   قال أهل المعاني : لايستحق الدين الخالص إلاّ الله .  <br />
{ وَالَّذِينَ اتَّخَذُواْ مِن دُونِهِ أَوْلِيَآءَ } يعني الأصنام { مَا نَعْبُدُهُمْ } مجازه قالوا ما نعدهم .  <br />
{ إِلاَّ لِيُقَرِّبُونَآ إِلَى اللَّهِ زُلْفَى } :قال قتادة : وذلك أنهم كانوا إذا قيل لهم من ربكم ومن خلقكم وخلق السماوات والأرض ونزل من السماء ماء ؟<br />
قالوا : الله .   فيقال لهم : فما يعني عبادتكم الأوثان ؟ قالوا : ليقربونا إلى الله زلفى وتشفع لنا عند الله .   قال الكلبي : وجوابه في الأحقاف :<br />
{ فَلَوْلاَ نَصَرَهُمُ الَّذِينَ اتَّخَذُواْ مِن دُونِ اللَّهِ قُرْبَاناً آلِهَةَ } [ الأحقاف : 28 ] الآية .  <br />
{ إِنَّ اللَّهَ يَحْكُمُ بَيْنَهُمْ } يوم القيامةِّ { فِي مَا هُمْ فِيهِ يَخْتَلِفُونَ } من أمر الدين { إِنَّ اللَّهَ لاَ يَهْدِي } لدينه وحجته { مَنْ هُوَ كَاذِبٌ كَفَّارٌ }
