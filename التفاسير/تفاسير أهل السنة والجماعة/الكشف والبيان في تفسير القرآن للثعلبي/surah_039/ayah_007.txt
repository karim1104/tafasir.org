{ إِن تَكْفُرُواْ فَإِنَّ اللَّهَ غَنِيٌّ عَنكُمْ وَلاَ يَرْضَى لِعِبَادِهِ الْكُفْرَ } .   فإن قيل : كيف ؟ قال : ولا يرضى لعباده الكفر وقد كفروا .   قلنا : معناه لا يرضى لعباده أن يكفروا به ،   وهذا كما يقول : لست أحب الاساءة وإن أحببت أن يسيء فلان فلانا فيعاقب .   وقال ابن عبّاس والسدي : معناه ولا يرضى لعباده المخلصين المؤمنين الكفر ،   وهم الذين قال : { إِنَّ عِبَادِي لَيْسَ لَكَ عَلَيْهِمْ سُلْطَانٌ } [ الحجر : 42 ] [ الإسراء : 65 ] فيكون عاماً في اللفظ خاصاً في المعنى كقوله : { عَيْناً يَشْرَبُ بِهَا عِبَادُ اللَّهِ } [ الإنسان : 6 ] وإنما يريد به بعض العباد دون البعض .  <br />
{ وَإِن تَشْكُرُواْ } تؤمنوا ربّكم وتطيعوه { يَرْضَهُ لَكُمْ } ويثيبكم عليه { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَى ثُمَّ إِلَى رَبِّكُمْ مَّرْجِعُكُمْ فَيُنَبِّئُكُمْ بِمَا كُنتُمْ تَعْمَلُونَ إِنَّهُ عَلِيمٌ بِذَاتِ الصُّدُورِ }
