ثم يقول الحق سبحانه : <br />
{  وإن أدري لعله فتنة لكم ومتاع إلى حين ( 111 ) } : <br />
أي :  لعل الإمهال وبقاءكم دون عذاب وتباطؤ الساعة عنكم فتنة واختبار ،  يا ترى أتوفقون وتفوزون في هذا الاختبار ،  كما قال سبحانه في موضع آخر : <br />
{  فلا تعجبك أموالهم ولا أولادهم إنما يريد الله ليعذبهم بها في الحياة الدنيا وتزهق أنفسهم وهم كافرون ( 55 ) } [ التوبة ] . <br />
وقال تعالى :  {  ولا يحسبن الذين كفروا أنما نملي لهم خير لأنفسهم إنما نملي لهم ليزدادوا إثما ولهم عذاب مهين ( 178 ) } [ آل عمران ] . <br />
وقوله تعالى :  {  ومتاع إلى حين ( 111 ) } [ الأنبياء ] :  أي :  لن يدوم هذا النعيم وهذا المتاع ،  لأن له مدة موقوتة .
