ثم يقول الحق سبحانه :  {  فَتَنَازَعُوا أَمْرَهُم بَيْنَهُمْ وَأَسَرُّوا النَّجْوَى ( 62 ) } . <br />
يبدو أن تخويف موسى لهم بقوله : {  وَيْلَكُمْ لَا تَفْتَرُوا عَلَى اللَّهِ كَذِبًا فَيُسْحِتَكُمْ بِعَذَابٍ .  .  ( 61 ) } ( طه ) قد أثر فيهم وأخافهم {  فتنازعوا أمرهم .  .  ( 62 ) } ( طه ) . <br />
أخذوا يتساومون القول ويتبادلون الآراء . <br />
{  وأسروا النجوى ( 62 ) } ( طه ) :  تحدثوا سرا ،  وهذا دليل خوفهم من كلام موسى ،  ودليل ما فيهم من استعداد للخير ،  لكن انتهى رأيهم إلى الاستمرار في الشوط إلى آخره .
