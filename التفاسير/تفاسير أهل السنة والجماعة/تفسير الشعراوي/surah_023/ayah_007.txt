ثم يقول الحق سبحانه : <br />
{  فمن ابتغى وراء ذلك فأولئك هم العادون ( 7 ) } : <br />
{  ابتغى } :  طلب ،  {  وراء ذلك } :  غير ما ذكرناه من الأزواج وملك اليمين . <br />
وسبق أن ذكرنا أن كلمة {  وراء } استعملت في القرآن لمعان عدة ،  فهي هنا بمعنى غير الأزواج وملك اليمين ،  ومن ذلك أيضا قوله سبحانه :  {   .  .  وأحل لكم ما وراء ذلكم ( 24 ) } [ النساء ] :  يعني :  حرمت عليكم كذا وكذا ،  وأحللت لكم غير ما ذكر . <br />
وتستعمل وراء بمعنى بعد ،  لأن الغيرية قد تتحد في الزمن ،  فيوجد الاثنان في وقت واحد ،  أما البعدية فزمنها مختلف ،  كما في قوله تعالى :  {  وامرأته قائمة فضحكت{[4565]} فبشرناها بإسحاق ومن وراء إسحاق يعقوب ( 71 ) } [ هود ] :  يعني :  من بعده ،  لأن الزمن مختلف . <br />
وتأتي وراء بمعنى :  خلف ،  كما في قوله تعالى :  {  وإذ أخذ الله ميثاق الذين أوتوا الكتاب لتبيننه للناس ولا تكتمونه فنبذوه وراء ظهورهم واشتروا به ثمنا قليلا فبئس ما يشترون ( 187 ) } [ آل عمران ] :  يعني :  جعلوه خلف ظهورهم . <br />
وتأتي وراء أيضا بمعنى أمام ،  كما في قوله تعالى :  {  وكان وراءهم ملك يأخذ كل سفينة غصبا ( 79 ) } [ الكهف ] : ومعلوم أن الملك كان أمامهم ينتظر كل سفينة تمر به فيأخذها غصبا . <br />
وقوله تعالى :  {  من ورائه جهنم .  .  ( 16 ) } [ إبراهيم ] : وجهنم أمامه ،  وستأتي فيما بعد ،  ولم تمض فتكون خلفه . <br />
ومعنى :  {  فأولئك هم العادون ( 7 ) } [ المؤمنون ] :  أي :  المعتدون المتجاوزون لما شرع لهم ،  وربنا- تبارك وتعالى- حينما يحذرنا من التعدي يفرق بين التعدي في الأوامر ،  والتعدي في النواهي ،  فإن كان في الأوامر يقول :  {  فلا تعتدوها ( 229 ) } [ البقرة ] . <br />
وإن كان في النواهي يقول :  {  فلا تقربوها ( 187 ) } [ البقرة ] .
