ثم يقول سبحانه : <br />
{  وَلَوْ دُخِلَتْ عَلَيْهِم مِّنْ أَقْطَارِهَا ثُمَّ سُئِلُوا الْفِتْنَةَ لَآتَوْهَا وَمَا تَلَبَّثُوا بِهَا إِلَّا يَسِيرًا ( 14 ) } . <br />
{  دُخِلَتْ عَلَيْهِم ( 14 ) } [ الأحزاب ] أي :  البيوت {  مِّنْ أَقْطَارِهَا ( 14 ) } [ الأحزاب ] من نواحيها {  ثُمَّ سُئِلُوا الْفِتْنَةَ ( 14 ) } [ الأحزاب ] أي :  طلب منهم الكفر {  لَآتَوْهَا ( 14 ) } [ الأحزاب ] يعني :  لكفروا .  {  وَمَا تَلَبَّثُوا بِهَا إِلَّا يَسِيرًا ( 14 ) } [ الأحزاب ] يعني :  ما يجعل الله لهم لبثا وإقامة إلا يسيرا ،  ثم ينتقم الله منهم{[5687]} .
