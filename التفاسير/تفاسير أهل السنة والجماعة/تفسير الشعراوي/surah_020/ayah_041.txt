ثم يقول الحق سبحانه لموسى :  {  وَاصْطَنَعْتُكَ لِنَفْسِي ( 41 ) } . <br />
أي :  نجيتك وحافظت عليك ؛  لأنني أعدك لمهمة عندي ،  هي إرسالك رسولا بمنهجي إلى فرعون وإلى قومك . <br />
وقد حاول العلماء إحصاء المطالب التي طلبها موسى عليه السلام من ربه فوجدوها ثمانية :  {  قَالَ رَبِّ اشْرَحْ لِي صَدْرِي ( 25 ) وَيَسِّرْ لِي أَمْرِي ( 26 ) وَاحْلُلْ عُقْدَةً مِّن لِّسَانِي ( 27 ) يَفْقَهُوا قَوْلِي ( 28 ) وَاجْعَل لِّي وَزِيرًا مِّنْ أَهْلِي ( 29 ) هَارُونَ أَخِي ( 30 ) اشْدُدْ بِهِ أَزْرِي ( 31 ) وَأَشْرِكْهُ فِي أَمْرِي ( 32 ) كَيْ نُسَبِّحَكَ كَثِيرًا ( 33 ) وَنَذْكُرَكَ كَثِيرًا ( 34 ) } ( طه ) . <br />
ثم وجدوا أن الله تعالى أعطاه ثمانية أخرى دون سؤال منه :  {  إِذْ أَوْحَيْنَا إِلَى أُمِّكَ مَا يُوحَى ( 38 ) أَنِ اقْذِفِيهِ فِي التَّابُوتِ فَاقْذِفِيهِ فِي الْيَمِّ فَلْيُلْقِهِ الْيَمُّ بِالسَّاحِلِ يَأْخُذْهُ عَدُوٌّ لِّي وَعَدُوٌّ لَّهُ وَأَلْقَيْتُ عَلَيْكَ مَحَبَّةً مِّنِّي وَلِتُصْنَعَ عَلَى عَيْنِي ( 39 ) إِذْ تَمْشِي أُخْتُكَ فَتَقُولُ هَلْ أَدُلُّكُمْ عَلَى مَن يَكْفُلُهُ فَرَجَعْنَاكَ إِلَى أُمِّكَ كَيْ تَقَرَّ عَيْنُهَا وَلَا تَحْزَنَ وَقَتَلْتَ نَفْسًا فَنَجَّيْنَاكَ مِنَ الْغَمِّ وَفَتَنَّاكَ فُتُونًا فَلَبِثْتَ سِنِينَ فِي أَهْلِ مَدْيَنَ ثُمَّ جِئْتَ عَلَى قَدَرٍ يَا مُوسَى ( 40 ) } .  ( طه ) . <br />
فإن كان موسى عليه السلام قد طلب من ربه ثمانية مطالب فقد أعطاه ربه عز وجل ثمانية أخرى دون أن يسألها موسى ،  ليجمع له بين العطاء بالسؤال ،  والعطاء تكرما من غير سؤال ،  لأنك إن سألت الله فأعطاك دل ذلك على قدرته تعالى في إجابة طلبك ،  لكن إن أعطاك بدون سؤال منك دل ذلك على محبته لك .
