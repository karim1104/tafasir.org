ثم يقول الحق سبحانه :  {  قَالَ رَبِّي يَعْلَمُ الْقَوْلَ فِي السَّمَاء وَالأَرْضِ وَهُوَ السَّمِيعُ الْعَلِيمُ ( 4 ) } . <br />
كأن سائلا قال :  من أين لك يا محمد بكل هذا وقد أسره القوم ؟ {  قَالَ رَبِّي يَعْلَمُ الْقَوْلَ فِي السَّمَاء وَالأَرْضِ .  .  ( 4 ) } ( الأنبياء ) :  فلا تخفى عليه خافية {  وَهُوَ السَّمِيعُ الْعَلِيمُ ( 4 ) } ( الأنبياء ) :  السميع لما يقال ويسر العليم بما يفعل ،  فالأحداث أقوال وأفعال . <br />
ومما قالوه أيضا :  {  بَلْ قَالُواْ أَضْغَاثُ{[4256]}أَحْلاَمٍ بَلِ افْتَرَاهُ بَلْ هُوَ شَاعِرٌ فَلْيَأْتِنَا بِآيَةٍ كَمَا أُرْسِلَ الأَوَّلُونَ ( 5 ) } .
