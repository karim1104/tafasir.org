شرح الكلمات : <br />
{  لا يقاتلونكم جميعا } :  أي لا يقاتلكم يهود بني النضير مجتمعين . <br />
{  الا فى قرىً محصنة } :  أي بالأسوار العالية . <br />
{  أو من وراء جُدُر } :  أي من وراء المباني والجدران أما المواجهة فلا يقدرون عليها . <br />
{  بأسهم بينهم شديد } :  أي العداوة بينهم شديدة والبغضاء أشد . <br />
{  تحسبهم جميعا } ً :  أي مجتمعين . <br />
{  وقلوبهم شتى } :  أي متفرقة خلاف ما تحسبهم عليه . <br />
{  بأنهم قوم لا يعقلون } :  إذ لو كانوا يعقلون لاجتمعوا على الحق ولا ما كفروا به وتفرقوا فيه فهذا دليل عدم عقلهم . <br />
المعنى : <br />
وقوله تعالى :  {  لا يقاتلونكم جميعا } أي اليهود والمنافقون {  إلا في قرى محصنة } بأسوار وحصون أو من وراء جدر أي في المباني ووراء الجدران .  وقوله تعالى بأسهم بينهم شديد أي العداوة بينهم قوية والبغضاء شديدة تحسبهم جميعاً في الظاهر وأنهم مجتمعون ولكن {  وقلوبهم شتَّى } أي متفرقة لا تجتمع على غير عداوة الإِسلام وأهله ،  وذلك لكثرة أطماعهم وأغراضهم وأنانيتهم وأمراضهم النفسية والقلبية . <br />
وقوله تعالى {  ذلك بأنهم قوم لا يعقلون } إذ لو كانوا يعقلون لما حاربوا الحق وكفروا به وهم يعملون فعرضوا أنفسهم لغضب الله ولعنته وعذابه . <br />
الهداية<br />
من الهداية : <br />
- عامة الكفار يبدون متحدين ضد الإِسلام وهم كذلك  ،  ولكنهم فيما بينهم تمزقهم العداوات وتقطعهم الأطماع وسوء الأغراض والنيات . <br />
