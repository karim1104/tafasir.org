شرح الكلمات : <br />
{  أو يرسل عليكم حاصباً } :  أي ريحاً ترمي بالحصباء لشدتها . <br />
{  ثم لا تجدوا لكم وكيلا } :  أي حافظاً منه أي من الخسف أو الريح الحاصب . <br />
المعنى : <br />
وقوله تعالى :  وهو يخاطبهم لهدايتهم {  أفأمنتم أن يخسف بكم جانب البر } يقرعهم على إعراضهم فيقول {  أفأمنتم } الله تعالى {  أن يخسف بكم } جانب الأرض الذي نزلتموه عند خروجكم من البحر {  أو يرسل عليكم حاصباً } أي ريحاً شديدة تحمل الحصباء فيهلككم كما أهلك عاداً {  ثم لا تجدوا لكم } من غير الله {  وكيلاً } يتولى دفع العذاب عنكم . <br />
