شرح الكلمات : <br />
{  خشية إملاق } :  أي خوف الفقر وشدته . <br />
{  خطئاً كبيراً } :  أي خصلة قبيحة شديدة القبح ،  وسبيلاً بئس السبيل . <br />
المعنى : <br />
وقوله تعالى :  {  ولا تقتلوا أولادكم خشية إملاق } أي ومما حكم به وقضى ووصى {  ألا تقتلوا أولادكم } أي أطفالكم {  خشية إملاق } أي مخافة الفاقة والفقر ،  إذ كان العرب يئدون البنات خشية العار ويقتلون الأولاد كالإناث مخافة الفاقة فأوصى تعالى بمنع ذلك وقال متعهداً متكفلاً برزق الأولاد وآبائهم فقال :  {  نحن نرزقهم وإياكم } واخبر تعالى أن قتل الأولاد {  كان خطئاً كبيراً } أي إنما عظيماً فكيف يقدم عليه المؤمن . <br />
الهداية : <br />
- حرمة القتل قتل الأولاد بعد الولادة أو إجهاضها قبلها خوفاً من الفقر أو العار . <br />
