{  قاصفاً من الريح } :  أي ريحاً شديدة تقصف الأشجار وتكسرها لقوتها . <br />
{  علينا به تبيعاً } :  أي نصيراً ومعيناً ليثأر لكم منا . <br />
المعنى : <br />
ويقول :  {  أم أمنتم } الله تعالى {  أن يعيدكم فيه } أي في البحر {  تارة أخرى } أي مرة أخرى {  فيرسل عليكم قاصفاً من الريح } أي ريحاً شديدة تقصف الأشجار وتحطمها {  فيغركم بما كفرتم } أي بسبب كفركم كما أغرق آل فرعون {  ثم لا تجدوا لكم علينا به تبيعاً } أي تابعاً يثأر لكم منا ويتبعنا مطالباً بما نلنا منكم من العذاب .  فما لكم إذا لا تؤمنون وتوحدون وبالباطل تكفرون . <br />
