{  أرأيتك } :  أي أخبرني . <br />
{  كرمت على } :  أي فضلته علي بالأمر بالسجود له . <br />
{  لأحتنكن } :  لأستولين عليهم فأقودهم إلى الغواية كالدابة إذا جعل الرسن في حنكها ،  تقاد حيث شاء راكبها !  . <br />
المعنى : <br />
ثم قال في صلفه وكبريائه {  أرايتك } أي أخبرني أهذا {  الذي كرمت علي } ؟  !  قال هذا استصغار لآدم واستخفافا بشأنه ،  ( لئن أخرتني ) أي وعزتك لئن أخرت موتي {  إلى يوم يبعثون لأحتنكن ذريته } أي لأستولين عليهم وأسوقهم إلى أودية الغواية والضلال حتى يهلكوا مثلي {  إلا قليلاً } منهم ممن تستخلصهم لعبادتك . <br />
