شرح الكلمات : <br />
{  نمتعهم قليلاً } :  أي متاعاً في هذه الدنيا قليلا أي إلى نهاية آجالهم . <br />
{  ثم نضطرهم إلى عذاب غليظ } :  أي ثم نُلجئهم في الآخرة إلى عذاب النار والغليظ :  الثقيل . <br />
المعنى<br />
وقوله تعالى :  {  نمتعهم قليلاً } أي نمهل هؤلاء المشركين فلا نعاجلهم بالعقوبة فيتمتعون مدة آجالهم وهو متاع قليل {  ثم نضطرهم } بعد موتهم ونشرهم {  إلى عذاب غليظ } أي نلجئهم إلجاءً غلى عذاب غليظ ثقيل لا يحتمل ولا يطاق وهو عذاب النار .  نعوذ بالله منها ومن كل عمل يؤدي إليها . <br />
