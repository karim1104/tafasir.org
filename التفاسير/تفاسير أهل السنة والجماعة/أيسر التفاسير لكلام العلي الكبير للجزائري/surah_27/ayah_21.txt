شرح الكلمات : <br />
{  لأعذبنه عذاباً شديداً } :  أي بِنَتْفِ ريشه ورميه في الشمس فلا يمتنع من الهوام . <br />
{  بسلطان مبين } :  أي بحجة واضحة على عذرة في غيبته . <br />
المعنى : <br />
{  لأعذبنه عذاباً شديداً } بأن ينتف ريشه ويتركه للهوام تأكله فلا يمتنع منها {  أو لأذبحنه } بقطع حلقومه ،  {  أو ليأتيني بسلطان مبين } أي بحجة واضحة على سبب غيبته . <br />
