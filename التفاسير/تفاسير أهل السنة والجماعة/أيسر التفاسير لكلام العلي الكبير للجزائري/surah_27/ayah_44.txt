شرح الكلمات : <br />
{  ادخلي الصرح } :  أي بهو الصرح إذ الصرح القصر العالي وفي بهوه بكرة ماء كبيرة مغطاة بسقف زجاجي يرى وكأنه ماء . <br />
{  فكشفت عن ساقيها } :  ظانة أنها تدخل ماء تمشي عليه فرفعت ثيابها . <br />
{  حسبته لجة } :  أي من ماء غمر يجري . <br />
{  صرح ممرد من قوارير } :  أي مملّس من زجاج . <br />
المعنى :  {  فلما رأته حسبته لجة } ماء {  فكشفت عن ساقيها } فقال لها سليمان {  إنه صرح ممرد } أي مملّس {  من قوارير } زجاجية وهنا وقد بهرها الموقف وعرفت أنها كانت ضالة وظالمة نطقت قائلة {  رب إني ظلمت نفسي وأسلمت مع سليمان لله رب العالمين } وبهذا أصبحت مسلمة صالحة .  ولم يذكر القرآن عنها بعد شيئاً فلنسكت عما سكت عنه القرآن . <br />
الهداية<br />
من الهداية : <br />
- حرمة كشف المرأة ساقيها حتى ولو كانت كافرة فكيف بها إذا كانت مسلمة . <br />
- فضيلة الاِئتساء بالصالحين كما ائتست بلقيس بسليمان في قولها {  وأسلمت مع سليمان لله رب العالمين } . <br />
