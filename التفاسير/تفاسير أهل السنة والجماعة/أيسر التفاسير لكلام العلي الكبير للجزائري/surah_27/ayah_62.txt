شرح الكلمات : <br />
{  ويكشف السوء } :  أي الضر ،  المرض وغيره . <br />
{  قليلاً ما تذكرون } :  أي ما تتعظون إلا قليلاً . <br />
المعنى : <br />
وقوله تعالى :  {  أمن يجيب المضطر إذا دعاه } أي ليكشف ضره {  ويشكف السوء } أي يبعده والسوء هو ما يسوء المرء من مرض وجوع وعطش وقحط وجدب . <br />
{  ويجعلكم خلفاء الأرض } جعل جيلاً يخلف جيلاً وهكذا الموجود خلف لمن سلف وسيكون سلفاً لمن خلف {  أإله مع الله والجواب لا إله مع الله } {  قليلاً ما تذكرون } أي ما تتعظون إلا قليلاً بما تسمعون وترون من آيات الله . <br />
