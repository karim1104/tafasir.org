شرح الكلمات : <br />
{  بيوتهم خاوية } :  أي فارغة ليس فيها أحد . <br />
{  بما ظلموا } :  أي بسبب ظلمهم وهو الشرك والمعاصي . <br />
{  لآية } :  أي عبرة . <br />
المعنى : <br />
{  فتلك بيوتهم خاوية بما ظلموا } أي بسبب ظلمهم أنفسهم بالشرك وظلمهم صالحاً والمؤمنين .  وقوله تعالى {  إن في ذلك } أي الإهلاك للرهط التسعة ولثمود قاطبة {  لآية } أي علامة على قدرة الله وعلمه وحسن تدبيره {  لقوم يعلمون } إذ هم الذين يرون الآية ويدركونها . <br />
