شرح الكلمات : <br />
{  ويوم نحشر } :  أي اذكر يوم نحشر أي نجمع . <br />
{  من كل أمة فوجاً } :  أي طائفة وهم الرؤساء المتبعون في الدنيا . <br />
{  فهم يوزعون } :  أي يجمعون برد أولهم على آخرهم . <br />
المعنى : <br />
وقوله تعالى :  {  ويوم نحشر من كل أمة فوجاً } أي واذكر يا رسولنا {  يوم نحشر من كل أمة } من الأمم البشرية {  فوجاً } أي جماعة {  ممن يكذب بآياتنا فهم يوزعون } بأن يرد أولهم على آخرهم لينتظم سيرهم<br />
