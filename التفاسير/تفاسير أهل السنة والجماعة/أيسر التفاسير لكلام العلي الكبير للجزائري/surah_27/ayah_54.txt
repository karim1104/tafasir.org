شرح الكلمات : <br />
{  ولوط } :  أي واذكر لقومك لوطاً إذ قال لقومه . <br />
{  لقومه } :  هم سكان مدن عمورية وسدوم . <br />
{  الفاحشة } :  أي الخصلة القبيحة الشديدة القبح وهي اللواط . <br />
{  وأنتم تبصرون } :  إذ كانوا يأتونها في أنديتهم عياناً بلا ستر ولا حجاب . <br />
المعنى : <br />
هذا بداية قصص لوط عليه السلام مع قومه اللوطيين فقال تعالى {  ولوطاً } أي واذكر كما ذكرت صالحاً وقومه اذكر لوطاً {  إذ قال لقومه } منكراً عليهم موبخاً مؤنباً لهم على فعلتهم الشنعاء {  أتأتون الفاحشة وأنتم تبصرون } أي قبحها وشناعتها ببصائركم وبأبصاركم حيث كانوا يأتونها علناً وعياناً وهم ينظرون<br />
