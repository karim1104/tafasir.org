شرح الكلمات : <br />
{  مقاعد للسمع } :  أي من أجل أن نسمع ما يحدث وما يكون في الكون . <br />
{  شهابا رصداً } :  أي أرصد وأعد لرمي الشياطين وإبعادهم عن السمع . <br />
المعنى : <br />
قالوا :  {  وأنا كنا نقعد منها } أي من السماء {  مقاعد } أي أماكن معينة لهم {  للسمع } أي لأجل الاستماع من ملائكة السماء .  {  فمن يستمع الآن يجد له شهاباً رصداً } أي أرصد له خاصة فيرمى به فيحرقه أو يخبله . <br />
