شرح الكلمات : <br />
{  كنا طرائق قددا } :  أي مذاهب مختلفة إذا الطرائق جمع طريقة ،  والقدد جمع قدة وهي الضروب والأجناس المختلفة . <br />
المعنى : <br />
وقالوا {  وإنا منا الصالحون } أي المؤمنون المستقيمون على الإِيمان والطاعة {  ومنَّا دون ذلك } ضعف إيمان وقلة طاعة ،  {  كنَّا طرائق قددا } أي مذاهب وأهواء مختلفة . <br />
