شرح الكلمات : <br />
{  ذلك بيني وبينك } :  أنا أفي بشرطي وأنت تفي بشرطك . <br />
{  أيما الأجلين قضيت } :  أي الأجلين الثمانية أو العشرة أتممت . <br />
{  فلا عدوان علي } :  وذلك بطلب الزيادة فوق الثمانية أو فوق العشرة . <br />
{  والله على ما نقول وكيل } :  أي وكيل وحفيظ أي أشهد الله على العقد بشطريه أي النكاح ورعي الغنم وبذلك تم العقد . <br />
المعنى : <br />
فقال موسى رداً على كلامه {  ذلك بيني وبينك } أنا عليَّ أن أفي بما اشترطت عليَّ وأنت عليك أن تفي بما اشترطت لي على نفسك {  أيما الأجلين } الثمانية أو العشرة {  قضيت } أي وفيت وأديت {  فلا عدوان عليّ } أي بطلب الزيادة على الثمانية ولا على العشرة . <br />
فقال شعيب :  نعم {  والله على ما نقول وكيل } فأشهد الله تعالى على صحة العقد وبذلك أصبح موسى زوجاً لابنة شعيب التي عيّنها له والغالب أنها الكبرى التي شهدت له بالأمانة والقوة . <br />
الهداية : <br />
- مشروعية إشهاد الله تعالى على العقود بمثل {  والله على ما نقول وكيل } . <br />
- فضيلة موسى عليه السلام بإيجار نفسه على شبع بطنه وإحصان فرجه . <br />
