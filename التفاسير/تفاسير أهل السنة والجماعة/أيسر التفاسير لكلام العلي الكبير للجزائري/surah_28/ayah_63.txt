شرح الكلمات : <br />
{  حق عليهم القول } :  أي بالعذاب في النار وهم أئمة الضلال . <br />
{  أغويناهم } :  أي فَغَوَوْا ولم نكرههم على الغي . <br />
{  تبرأنا إليك } :  أي منهم ما كانوا يعبدوننا بل كانوا يعبدون أهواءهم . <br />
المعنى : <br />
وقوله تعالى {  قال الذين حق عليهم القول } أي نطق الرؤساء من أئمة الضلال وهم الذين حق عليهم العذاب في نار جهنم {  ربنا هؤلاء الذين أغوينا } {  أغويناهم } فغووا {  كما غوينا } أي ما أكرهناهم على الغواية ،  {  تبرأنا إليك } أي منهم .  {  ما كانوا إيانا يعبدون } أي بل كانوا يعبدون أهواءهم لا غير . <br />
الهداية : <br />
- براءة الرؤساء في الضلالة من المرؤوسين . <br />
- التحذير من الغواية وهي الضلال والانغماس في الذنوب والآثام . <br />
