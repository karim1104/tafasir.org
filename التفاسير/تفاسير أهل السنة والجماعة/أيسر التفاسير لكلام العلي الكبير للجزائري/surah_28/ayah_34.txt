شرح الكلمات : <br />
{  أفصح مني لساناً } :  أي أبين مني قولاً . <br />
{  ردءاً } :  أي معيناً لي . <br />
المعنى : <br />
{  وأخي هارون هو أفصح مني لساناً } أي أبين مني قولاً وأكثر إفهاماً لفرعون وملئه {  فأرسله معي ردءاً } أي عوناً {  يصدقني } أي يلخص قولي ويحرره لهم فيكون ذلك تصديقاً منه لي ،  لا مجرد أني إذا قلت قال صدق موسى .  وقوله {  إني أخاف أن يكذبون } فيما جئتهم به . <br />
الهداية : <br />
- مشروعية طلب العون عند التكليف بما يشق ويصعب من المسئولين المكلفين . <br />
