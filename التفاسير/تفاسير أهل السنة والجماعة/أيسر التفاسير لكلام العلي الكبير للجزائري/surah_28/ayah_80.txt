شرح الكلمات : <br />
{  وقال الذين أوتوا العلم } :  أي أعطوا العلم الديني بمعرفة الله والدار الآخرة وموجبات السعادة والشقاء . <br />
{  ويلكم } :  أي حضر ويلكم وهلاككم بتمنيكم المال وزخرف الدنيا . <br />
{  ثواب الله خير لمن آمن وعمل صالحاً } :  أي ما عند الله من جزاء للمؤمنين العاملين الصالحات وهو الجنة خير من حطام الدنيا الفاني . <br />
{  ولا يلقاها إلا الصابرون } :  أي ولا يوفق لقول هذه الكلمة وهي ثواب الله خير لمن آمن وعمل صالحاً إلا الصابرون على الإِيمان والتقوى . <br />
المعنى : <br />
{  وقال الذين أوتوا العلم } أي الشرعي الديني العالمون بالدنيا والآخرة .  وأسباب السعادة والشقاء في كل منهما قالوا ما أخبر تعالى به عنهم في قوله :  {  ويلكم ثواب الله خير لمن آمن وعمل صالحاً } أي ويحكم هلكتم إن كنتم تؤثرون هذا الفاني على الباقي {  ثواب الله } وهو الجنة خير من هذا الزخرف الفاني {  لمن آمن وعمل صالحاً } ولازم وذلك أنه ترك الشرك والعاصي ،  وقوله تعالى :  {  ولا يلقاها } أي هذه الجملة من الكلام :  {  ثواب الله خير لمن آمن } بربه {  وعمل صالحاً } في حياته بأداء الفرائض والنوافل وترك المحرمات والرذائل أي ولا يلقى هذه الكلمة {  إلا الصابرون } من أهل الإِيمان والتقوى هم الذين يلقنهم الله إياها فيقولونها الصفاء أرواحهم وزكاة أنفسهم . <br />
الهداية : <br />
- بيان موقف أهل العلم الديني وأنهم رُشَّد أي حكماء يأمرون بالمعروف وينهون عن المنكر . <br />
