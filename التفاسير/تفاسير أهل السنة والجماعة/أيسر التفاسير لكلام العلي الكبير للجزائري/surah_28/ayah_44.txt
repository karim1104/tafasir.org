شرح الكلمات : <br />
{  وما كنت بجانب الغربي } :  أي لم تكن يا رسولنا حاضراً بالجانب الغربي من موسى . <br />
{  إذ قضينا إلى موسى الأمر } :  أي بالرسالة إلى فرعون وقومه . <br />
{  وما كنت من الشاهدين } :  حتى تعلمه وتخبر به . <br />
المعنى : <br />
بعد انتهاء قصص موسى مع فرعون وإنزال التوراة {  بصائر للناس وهدى ورحمة لعلهم يتذكرون } وكان القصص كله شاهداً على نبوة الرسول محمد صلى الله عليه وسلم خاطب الله تعالى رسوله فقال :  {  وما كنت } أي حاضراً {  بجانب الغربي } أي بالجبل الغربي من موسى {  إذ قضينا إلى موسى الأمر } بإرساله رسولاً إلى فرعون وملئه {  وما كنت من الشاهدين } أي الحاضرين إذاً فكيف علمت هذا وتتحدث به لولا أنك رسول حق ؟  ! <br />
