شرح الكلمات : <br />
{  فعميت عليهم الأنباء } :  أي فخفيت عليهم الأنباء التي يمكنهم أن يحتجوا بها . <br />
{  فهم لا يتساءلون } :  أي انقطعوا عن الكلام . <br />
المعنى : <br />
قال تعالى :  {  فعميت عليهم الأنباء يومئذ } أي فخفيت عليهم الأخبار التي يمكنهم أن يحتجوا بها فلم يجدوا حجة واحدة ولذا {  فهم لا يتساءلون } أي لا يسأل بعضهم بعضاً لأنه سقط في أيديهم وعلموا أنهم صالوا الجحيم لا محالة . <br />
