شرح الكلمات : <br />
{  تجرى بأعيننا } :  أي بِمرأىً منا أي محفوظة بحفظنا لها . <br />
{  جزاء لمن كان كفر } :  أي أغرقناهم انتصاراً لمن كان كفر وهو نوح كفروا نبوته وكماله<br />
المعنى : <br />
وقوله تعالى {  تجرى } وهي حاملة لعوالم شتى {  بأعيننا } أي بمرأىً منّا محفوظة بحفظنا لها وقوله {  جزاء لمن كان كفر } أي أغرقناهم انتصاراً لعبدنا نوح وجزاء له على صبره مع طول الزمن لقد أقام فيهم ألف سنة إلا خمسين عاماً . <br />
