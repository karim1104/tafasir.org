شرح الكلمات : <br />
{  تغرب في عين حمئة } :  ذات حمأة وهي الطين الأسود وغروبها إنما هو نظر العين وإلا فالشمس في السماء والبحر في الأرض . <br />
{  قوماً } :  أي كافرين . <br />
المعنى : <br />
وهكذا تابعه بين أسباب الغزو والفتح والسير في الأرض {  حتى إذا بلغ مغرب الشمس وجدها تغرب في عين حمئة } وهي على ساحل المحيط الأطلنطي ،  وكونها تغرب فيها هو بحسب رأي العين ،  وإلا فالشمس في السماء والعين الحمئة والمحيط إلى جنبها في الأرض وقوله تعالى :  {  ووجد عندها } أي عند تلك العين في ذلك الإقليم المغربي {  قوماً } أي كافرين غير مسلمين فأذن الله تعالى له في التحكم والتصرف فيهم إذ يسر له أسباب الغلبة عليهم وهن معنى قوله تعالى :  {  قلنا يا ذا القرنين } وقد يكون نبياً ويكون قوله الله تعالى هذا له وحياً وهو {  إما أن تعذب } بالأسر والقتل ،  {  وإما أن تتخذ فيهم حسناً } وهذا بعد حربهم والتغلب عليهم . <br />
