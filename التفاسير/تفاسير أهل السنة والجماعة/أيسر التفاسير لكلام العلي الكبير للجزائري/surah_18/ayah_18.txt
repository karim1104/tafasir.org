شرح الكلمات : <br />
{  أيقاظاً } :  جمع يقظ أي منتبهين لأن أعينهم منفتحة . <br />
{  بالوصيد } :  فناء الكهف . <br />
{  رُعباً } :  منعهم الله بسببه من الدخول عليهم . <br />
المعنى : <br />
وقوله تعالى :  {  وتحسبهم أيقاظاً وهم رقود } أي أنك إذا نظرت إليهم تظنهم أيقاظاً أي منتبهين لأن أعينهم متفتحة وهم رقود نائمون لا يحسون بأحد ولا يشعرون ،  وقوله تعالى :  {  ونقلبهم ذات اليمين } أي جهة اليمين {  وذات الشمال } أي جهة الشمال حتى لا تعدو التربة على أجسادهم فتبليها .  وقوله {  وكلبهم باسط ذراعيه بالوصيد } أي :  وكلبهم الذي خرج معهم ،  وهو كلب صيد {  باسط ذراعيه بالوصيد } أي :  بفناء الكهف .  وقوله تعالى :  {  لو اطلعت عليهم } أي لو شاهدتهم وهم رقود أعينهم مفتحة {  لوليت منهم فراراً } لرجعت فاراً منهم {  ولملئت منهم رعباً } أي خوفاً وفزعاً ،  ذلك أن الله ألقى عليهم من الهيبة والوقار حتى لا يدنو منهم أحد ويسمهم بسوء إلى أن يوقظهم عند نهاية الأجل الذي ضرب لهم ،  ليكون أمرهم آية من آيات الله الدالة على قدرته وعظيم سلطانه وعجيب تدبيره في خلقه . <br />
من الهداية : <br />
- بيان عجيب تدبير الله تعالى وتصرفه في مخلوقاته فسبحانه من إله عظيم عليم حكيم . <br />
