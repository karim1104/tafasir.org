{  يرجموكم } :  أي يقتلوكم رمياً بالحجارة . <br />
المعنى : <br />
{  إنهم إن يظهروا عليكم } .  أي يطلعوا {  يرجموكم } أو يقتلوكم رجماً بالحجارة {  أو يعيدوكم في ملتهم } ملة الشرك بالقسر والقوة .  {  ولن تفلحوا إذاً أبداً } أي ولن تفلحوا بالنجاة من النار ودخول الجنة إذا أنتم عدتم للكفر والشرك .  .  فكفرتم وأشركتم بربكم . <br />
