{  واضرب لهم مثلاً } :  أي اجعل لهم مثلاً هو رجلين .  .  .  الخ .  {  جنتين } :  أي بستانين . <br />
{  وحففناهما بنخل } :  أي أحطناهما بخل . <br />
المعنى : <br />
يقول تعالى لرسوله صلى الله عليه وسلم واضرب لأولئك المشركين المتكبرين الذين اقترحوا عليك أن تطرد الفقراء المؤمنين من حولك حتى يجلسوا إليك ويسمعوا منك {  اضرب لهم } أي اجعل لهم مثلا :  {  رجلين } مؤمناً وكافرا {  جعلنا لأحدكما } وهو الكافر {  جنتين من أعناب وحففناهما بنخل } أي أحطناهما بنخل ،  {  وجعلنا بينهما } أي بين الكروم والنخيل {  زرعاً } . <br />
