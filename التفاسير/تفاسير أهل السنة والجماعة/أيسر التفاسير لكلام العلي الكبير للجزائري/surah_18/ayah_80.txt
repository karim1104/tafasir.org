شرح الكلمات : <br />
{  أن يرهقهما طغياناً وكفراً } :  أي يغشاهما :  ظلماً وجحوداً . <br />
المعنى : <br />
{  وأما الغلام } الذي قتلت وأنكرت عليّ قتله {  فكان أبواه مؤمنين فخشينا } إن كبر {  أن يرهقهما } أي يغشيهما {  طغيانا وكفراً فأردنا أن يبدلهما ربهما خيراً منه زكاة } أي طهراً وصلاحاً {  وأقرب رحماً } أي رحمة وبراً فلذا قتلته . <br />
الهداية : <br />
من الهداية : <br />
- بيان حسن تدبير الله تعالى لأوليائه بما ظاهره عذاب ولكن في باطنه رحمة . <br />
