شرح الكلمات : <br />
{  خيراً منها منقلباً } :  أي مرجعاً في الآخرة . <br />
المعنى : <br />
{  ودخل جنته } والحال أنه {  ظالم لنفسه } بالكفر والكبر وقال :  {  ما أظن أن تبيد هذه } يشير إلى جنته {  أبداً } أي لا تفنى .  {  وما أظن الساعة قائمة ولئن ردت إلى ربي } كما تقول أنت {  لأجدن خيراً منها } أي من جنتي {  منقلباً } أي مرجعاً إن قامت الساعة وبعث الناس معهم .  هذا القول من هذا الرجل هو ما يسمى بالغرور النفسي الذي يصاب به أهل الشرك والكبر . <br />
الهداية : <br />
من الهداية : <br />
- تقرير عقيدة التوحيد والبعث والجزاء . <br />
- التنديد بالكبر والغرور حيث يفضيان بصاحبهما إلى الشرك الكفر . <br />
