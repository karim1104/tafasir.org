شرح الكلمات : <br />
{  وليحملن أثقالهم } :  أي أوزارهم ،  والأوزار الذنوب . <br />
{  وأثقالاً مع أثقالهم } :  أي من أجل قولهم للمؤمنين اتبعوا سبيلنا . <br />
{  عما كانوا يفترون } :  أي يكذبون . <br />
المعنى : <br />
وقال تعالى مقسماً بعزته وجلاله :  {  وليحملن أثقالهم } أي أوزارهم {  وأثقالاً مع أثقالهم } أي وأوزاراً أي ذنوباً مع أوزارهم التي هي ذنوبهم وذلك من أجل ما قالوا لهم .  {  وليسئلن يوم القيامة } أي ذنوباً مع أوزارهم التي هي ذنوبهم وذلك من أجل ما قالوا لهم .  {  وليسئلن يوم القيامة عما كانوا يفترون } أي يكذبون من أنهم يحملون خطايا المؤمنين يوم القيامة . <br />
