شرح الكلمات : <br />
{  سيء بهم } :  أي حصلت لهم مساءة وغم بسبب مخافة أن يقصدهم قومه بسوء . <br />
{  وضاق بهم ذرعاً } :  أي عجز عن احتمال الأمر لخوفه من قومه أن ينالوا ضيفه بسوء . <br />
{  رجزاً } :  أي عذاباً من السماء . <br />
{  بما كانوا يفسقون } :  أي بسب فسقهم وهو إتيان الفاحشة . <br />
المعنى : <br />
وقوله تعالى :  {  ولما أن جاءت رسلنا لوطاً } أي ولما وصلت الملائكة لوطاً قادمين من عند إبراهيم من فلسطين {  سيء بهم وضاق بهم ذرعاً } أي استاء بهم وأصابه غم وهم خوفاً من قومه أن يسيئوا إليهم ،  وهم ضيوفه نازلون عليه ولما رأت ذلك الملائكة من طمأنوه بما أخبر به تعالى في قوله :  {  وقالوا لا تخف } أي علينا {  ولا تحزن } على من سيهلك من اهلك مع قومك الظالمين .  {  إنا منجوك } من العذاب أنت وأهلك أي زوجتك المؤمنة وبنتيك ،  {  إلا امرأتك أي العجوز الظالمة فإنها {  من الغابرين } الذين طالت أعمارهم وستهلك مع الهالكين . <br />
