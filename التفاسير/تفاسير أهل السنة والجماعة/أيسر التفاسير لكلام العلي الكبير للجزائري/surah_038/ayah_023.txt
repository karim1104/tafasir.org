شرح الكلمات : <br />
{  إن هذا أخي } :  أي على ديني في الإِسلام . <br />
{  فقال اكفلنيها } :  أي اجعلني كافلها بمعنى تنازل لي عنها وملكنيها . <br />
{  وعزني في الخطاب } :  أي غلبني في الكلام الجدلي فأخذها مني . <br />
المعنى : <br />
ثم عرضا عليه القضية فقال أحدهما وهو المظلوم عارضاً مظلمته {  إن هذا أخي } أي في الإسلام {  له تسع وتسعون نعجة ولي نعجة واحدة فقال لي أكفلنيها } أي ملكنيها أضمها إلى نعاجي ،  {  وعزني في الخطاب } أي وغلبني في الكلام والجدال وأخذها مني . <br />
