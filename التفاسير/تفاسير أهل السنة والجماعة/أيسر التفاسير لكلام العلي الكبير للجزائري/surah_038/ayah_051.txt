شرح الكلمات : <br />
{  متكئين فيها } :  أي على الأرائك . <br />
{  يدعون فيها بفاكهة } :  أي يطالبون فيها بفاكهة وذكر الفاكهة دون الطعام والشراب إيذاناً بأن طعامهم وشرابهم لمجرد التلذذ لا للتغذية كما في الدنيا . <br />
المعنى : <br />
{  متكئين فيها } أي :  على الأرائك الأسرة بالحجلة ،  {  يدعون فيها } أي :  يُطالبون فيها {  بفاكهة كثيرة وشراب } ولم يذكر الطعام إشارة إلى أن مآكلهم ومشاربهم لمجرد التلذذ لا للتغذي بها كما في الدنيا . <br />
