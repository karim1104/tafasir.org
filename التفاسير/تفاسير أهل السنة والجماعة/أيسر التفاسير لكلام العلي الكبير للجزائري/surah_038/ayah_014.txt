شرح الكلمات : <br />
{  إن كل إلا كذب الرسل } :  أي ما كل واحد منهم إلا كذب الرسل ولم يصدقهم فيما دعوا إليه . <br />
{  فحق عقاب } :  أي وجبت عقوبتي عليهم . <br />
المعنى : <br />
{  إن كُلٌّ إلاَّ كذب الرسل } أي ما كل واحد منها إلا كذبت الرسل {  فحق عقاب } أي وجب عقابي لهم فعاقبتهم ،  وما ينظر هؤلاء من قومك {  إلا صيحة واحدة مالها من فواق } . <br />
