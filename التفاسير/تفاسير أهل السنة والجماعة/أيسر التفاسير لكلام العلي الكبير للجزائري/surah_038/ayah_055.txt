شرح الكلمات : <br />
{  هذا } :  أي المذكور للمتقين . <br />
{  وإن للطاغين } :  أي الذين طغوا في الكفر والشر والفساد . <br />
{  لشر مآب } :  أي جهنم يصلونها . <br />
المعنى : <br />
بعد ذكر نعيم أهل الإِيمان والتقوى ناسب ذكر شقاء أهل الكفر والفجور وهو أسلوب الترهيب والترغيب الذي امتاز به القرآن الكريم في هداية العباد .  فقال تعالى {  هذا } أي ما تقدم ذكره من نعيم أهل السعادة {  وإن للطاغين } وهم المشركون الظلمة كأبي جهل وعتبة بن معيط والعاص بن وائل {  لشر مآب } أي لأسوأ مرجع وأقبحه وهو {  جهنم يصلونها وبئس المهاد } . <br />
الهداية : <br />
من الهداية : <br />
- ذم الطغيان وهو مجاوزة الحد في الظلم والكفر وبيان جزاء أهله يوم القيامة . <br />
