شرح الكلمات : <br />
{  هذا ذكر } :  أي لهم بالثناء الحسن الجميل هنا في الدنيا . <br />
{  وإن للمتقين } :  أي هم وغيرهم من سائر المؤمنين والمؤمنات . <br />
{  لحسن مآب } :  أي مرجع أي عندما يرجعون إلى ربهم بالوفاة . <br />
المعنى : <br />
وقوله {  هذا ذكر } أي لهم بالثناء الحسن لهم في الدنيا ،  {  وان للمتقين } هم وغيرهم من المؤمنين والمؤمنات {  لحسن مآب } أي مرجع وهو الجنة حيث يرجعون إلى الله تعالى بعد الموت ،  وفسر ذلك المرجع بقوله تعالى {  جنات عدن } . <br />
