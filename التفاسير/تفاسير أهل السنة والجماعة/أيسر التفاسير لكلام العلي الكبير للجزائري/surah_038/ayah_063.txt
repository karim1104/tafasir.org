شرح الكلمات : <br />
{  اتخذناهم سخريا } :  أي كنا نسخر منهم في الدنيا . <br />
{  أم زاغت عنهم الأبصار } :  أي أمفقودون هم أم زاغت عنهم الأبصار ؟  فلم نرهم . <br />
المعنى : <br />
{  اتخذناهم } في الدنيا {  سخريا } نسخر منهم يعنون فقراء المسلمين كبلال وعمّار وصهيب وخبيب ،  أمفقودون هم {  أم زاغت عنهم } أبصارنا فلم نرهم . <br />
