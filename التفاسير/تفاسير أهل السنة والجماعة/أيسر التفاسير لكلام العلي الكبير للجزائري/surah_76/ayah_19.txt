شرح الكلمات : <br />
{  مخلدون } :  أي بصفة الولدان لا يشيبون . <br />
{  لؤلؤا منثورا } :  أي من سلكه أو من صدفه لحسنهم وجمالهم وانتشارهم في الخدمة . <br />
المعنى : <br />
وقوله تعالى {  ويطوف عليهم ولدان مخلدون } أي ويطوف على أولئك الأبرار في الجنة ولدان غلمان مخلدون لا يهرمون ولا يموتون حالهم دائما حال الغلمان لا تتغير {  إذا رأيتهم } ونظرت إليهم {  حسبتهم } في جمالهم وانتشارهم في الخدمة هنا وهناك {  لؤلؤا منثورا } . <br />
