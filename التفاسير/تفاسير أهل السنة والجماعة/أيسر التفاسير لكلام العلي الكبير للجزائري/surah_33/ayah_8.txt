شرح الكلمات : <br />
{  ليسأل الصادقين عن صدقهم } :  أي أخذ الميثاق من أجل أن يسأل الصادقين وهم الأنبياء عن صدقهم في تبليغ الرسالة تبكيتاً للكافرين بهم . <br />
{  وأعدّ للكافرين عذابا أليما } :  أي فأثاب المؤمنين وأعد للكافرين عذابا أليماً أي موجعا . <br />
المعنى : <br />
{  ليسأل } تعالى يوم القيامة {  الصادقين } وهم الأنبياء {  عن صدقهم } في تبليغ رسالتهم تقريعاً لأممهم الذين كفروا وكذبوا .  فأثاب المؤمنين {  وأعد للكافرين عذاباً أليما } أي موجعاً وهو عذاب النار . <br />
