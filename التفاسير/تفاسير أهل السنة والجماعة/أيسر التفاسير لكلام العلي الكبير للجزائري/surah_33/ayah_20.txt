شرح الكلمات : <br />
{  يحسبون الأحزاب } :  أي يحسب أولئك المنافقون الجبناء الأحزاب وهم قريش وغطفان . <br />
{  لم يذهبوا } :  أي لم يعودوا إلى بلادهم خائبين . <br />
{  وإن يأت الأحزاب } :  أي مرة أخرى فرضاً . <br />
{  يودوا لو أنهم بادون في الأعراب } :  أي من جبنهم وخوفهم يتمنَّون أن لو كانوا في البادية مع سكانها . <br />
{  يسألون عن أنبائكم } :  أي إِذَا كانوا في البداية لو عاد الأحزاب يسألون عن أنبائكم أي أخباركم هل انهزمتم أو انتصرتم . <br />
{  ولو كانوا فيكم ما قاتلوا إلا قليلا } :  أي لو كانوا بينكم في الحاضرة ما قاتلوا معكم إلا قليلا . <br />
المعنى : <br />
ما زال السياق في سرد أحداث غزوة الأحزاب فقوله تعالى {  يحسبون الأحزاب لم يذهبوا } أي بحسب أولئك المنافقون الجبناء الذين قالوا إن بيوتنا عورة وقالوا لإِخوانهم هلم إلينا أي اتركوا محمداً في الواجهة وحده إنهم لجبنهم ظنوا أن الأحزاب لم يعودوا إلى بلادهم مع أنهم قد رحلوا وهذا منتهى الجبن والخوف وقوله تعالى {  وإن يأت الأحزاب } أي مرة أخرى على فرض وتقدير {  يودوا } يومئذ {  لو أنهم بادون في الأعراب } أي خارج المدينة مع الأعراب في البادية لشدة خوفهم من الأحزاب الغزاة ،  وقوله تعالى {  يسألون عن أنبائكم } أي أخباركم هل ظَفِرَ بكم الأحزاب أو لا ،  {  ولو كانوا فيكم } أي بينكم ولم يكونوا في البادية {  وما قاتلوا إلا قليلا } وذلك لجبنهم وعدم إيمانهم بفائدة القتال لكفرهم بلقاء الله تعالى وما عنده من ثواب وعقاب هذا ما تضمنته الآية الأولى ( 20 ) . <br />
