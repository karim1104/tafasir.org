شرح الكلمات : <br />
{  في المدينة } :  أي عاصمة مصر يومئذ . <br />
{  تراود فتاها } :  أي عبدها الكنعاني . <br />
{  قد شغفها حبا } :  أي دخل حبّه شغاف قلبها أي أحاط بقلبها فتملكه عليها . <br />
{  إنا لنراها في ضلال مبين } :  أي في خطأ بيّن بسبب حبها إياه . <br />
المعنى : <br />
/د30<br />
قال تعالى {  وقال نسوة في المدينة } أي عاصمة مصر يومئذ {  امرأة العزيز تراود فتاها } أي عبدها {  عن نفسه قد شغفها حبا } أي قد بلغ حبها إياه شغفا قلبها أي غشاءه .  {  إنا لنراها } أي نظنها {  في ضلال مبين } أي خطأ واضح :  إذ كيف تحب عبداً وهي من هي في شرفها وعلّو مكانتها . <br />
