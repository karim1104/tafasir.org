شرح الكلمات : <br />
{  فيكيدوا لك } :  أي يحتالوا عليك بما يضرك . <br />
{  عدو مبين } :  أي بين العداوة ظاهرها . <br />
المعنى : <br />
وقوله تعالى {  قال يا بنيّ } أي قال يعقوب لولده يوسف {  لا تقصص رؤياك على إخوتك } وهم إخوة له من أبيه دون أمه {  فيكيدوا لك كيداً } أي يحملهم الحسد على أن يكيدوك بما يضرك بطاعتهم للشيطان حين يغريهم بك {  إن الشيطان للإِنسان عدو مبين } إذ أخرج آدم وحواء من الجنة بتزيينه لهما الأكل من الشجرة التي ينهاهما الله تعالى عن الأكل منها . <br />
