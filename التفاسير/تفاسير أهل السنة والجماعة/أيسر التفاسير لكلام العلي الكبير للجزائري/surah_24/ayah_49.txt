{  مذعنين } :  أي مسرعين منقادين مطيعين . <br />
المعنى : <br />
وقوله :  {  وإن يكن لهم الحق } أي وإن يكن لهم في الخصومة التي بينهم وبين غيرهم {  يأتوا إليه } أي إلى رسول الله {  مذعنين } أي منقادين طائعين أي لعلمهم أن الرسول يقضي بينهم بالحق وسوف يأخذون حقهم وافياً<br />
