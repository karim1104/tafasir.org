شرح الكلمات : <br />
{  إنَّا تطيرنا بكم } :  أي تشاءمنا بكم وذلك لانقطاع المطر عنا بسببكم . <br />
المعنى : <br />
{  إنا تطيرنا بكم } أي تشاءمنا بكم حيث انقطع عنا المطر بسببكم فرد عليهم المرسلون بقولهم {  طائركم معكم } . <br />
