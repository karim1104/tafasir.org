شرح الكلمات : <br />
{  يوم الآزفة } :  أي يوم القيامة . <br />
{  إذ القلوب لدى الحناجر } :  أي من شدة الخوف تكون القلوب قد ارتفعت حتى وصلت عند الحناجر . <br />
{  كاظمين } :  أي لقلوبهم يريدون ردها فلم يقدروا . <br />
{  ما للظالمين من حميم } :  أي ليس للمشركين من محب قريباً كان أو بعيداً . <br />
المعنى : <br />
بعد بيان الموقف الصعب في عرصات القيامة في الآيات السابقة قال تعالى لرسوله {  وأنذرهم } يا رسولنا أي خوف قومك {  يوم الآزفة } وهي القيامة القريبة والتي قد قربت فعلاً وكل ما هو اتٍ قريب أنذرهم قربها حتى لا يوافوها بالشرك والمعاصي فيخسروا خسراناً مبيناً ،  أنذرهم يوم الآزفة إذ القلوب من شدة الخوف ترتفع إلى الحناجر وهم يكظمونها فلا هي تخرج فيموتوا ولا هي تعود إلى أماكنها فيستريحوا . <br />
{  ما للظالمين } وهم أهل الشرك والمعاصي {  من حميم } قريب أو حبيب يدفع عنهم العذاب {  ولا شفيع } يشفع لهم وتقبل شفاعته ويطاع فيها لا ذا ولا ذاك يا لفظاعة الحال . <br />
الهداية : <br />
من الهداية : <br />
1- بيان هول يوم القيامة وصعوبة الموقف فيه . <br />
2- انعدام الحميم والشفيع للظالمين يوم القيامة .
