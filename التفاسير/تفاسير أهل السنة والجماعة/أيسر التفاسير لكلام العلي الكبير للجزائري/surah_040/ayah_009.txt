شرح الكلمات : <br />
{  وقهم السيئات } :  أي احفظهم من جزاء السيئات التي عملوها فلا تؤاخذهم بها . <br />
{  ومن تق السيئات يومئذ } :  أي ومن تقه جزاء سيئاته يوم القيامة فلم تؤاخذه . <br />
{  فقد رحمته } :  أي حيث سترته ولم تفضحه وعفوت عنه ولم تعذبه . <br />
{  وذلك } :  أي الوقاية من العذاب وإدخال الجنة هو الفوز العظيم . <br />
المعنى : <br />
وقوله :  {  وقهم السيئات } أي واحفظهم من جزاء سيئاتهم بأن تغفرها لهم وتسترها عليهم حتى يتأهّلوا للحاق بأبنائهم الذين نسألك أن تلحقهم بِهِمْ ،  {  ومن تق السيئات يومئذ } أي يوم القيامة {  فقد رحمته } {  وذلك هو الفوز العظيم } أي النجاة من النار ودخول الجنة هو الفوز العظيم لقوله تعالى :  {  فمن زحزح عن النار وأدخل الجنة فقد فاز } ومعنى ومن تق السيئات أي تقيه عذابها وذلك بأن يغفرها لهم ويعفو عنهم فلا يؤاخذهم بها ،  فينجوا من النار ويدخلوا الجنة وذلك أي النجاة من النار ودخول الجنة هو الفوز العظيم . <br />
