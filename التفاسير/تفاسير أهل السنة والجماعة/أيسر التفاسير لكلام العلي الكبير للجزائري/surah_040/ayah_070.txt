شرح الكلمات : <br />
{  الذين كذبوا بالكتاب } :  أي بالقرآن . <br />
{  وبما أرسلنا به رسلنا } :  من وجوب الإسلام لله بعبادته وحده وطاعته في أمره ونهيه والإِيمان بلقائه . <br />
{  فسوف يعلمون } :  أي عقوبة تكذيبهم . <br />
المعنى : <br />
وقوله {  الذين كذبوا بالكتاب } الذي هو القرآن {  وبما أرسلنا به رسلنا } من التوحيد والإِيمان {  فسوف يعلمون } عاقبة تكذيبهم وقت ما تكون الأغلال في أعناقهم والسلاسل في أرجلهم يسحبون . <br />
