شرح الكلمات : <br />
{  قل يجمع ربُّنا ثم يفتح بيننا بالحق } :  أي قل لهم سيجمع بيننا ربُّنا يوم القيامة ويفصل بيننا بالحق وهذا أيضا تلطق بهم وهو الحق . <br />
المعنى : <br />
وقوله :  {  قل يجمع بيننا ربُّنا } أي يوم القيامة {  ثم يفتح بيننا } أي يحكم ويفصل بيننا {  بالحق وهو الفتاح } أي الحاكم العليم بأحوال خلقه فأحكامه ستكون عادلة لعلمه بما يحكم فيه ظاهراً وباطناً .  وفي هذا جذب لهم بلطف ودون عنف ليقروا بالبعث الآخر الذي ينكرونه بشدة . <br />

من الهداية : <br />
