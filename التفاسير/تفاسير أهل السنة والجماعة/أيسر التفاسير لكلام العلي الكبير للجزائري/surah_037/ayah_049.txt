شرح الكلمات : <br />
{  بيض مكنون } :  أي كأنهن بيض مكنون أي مستور لا يصله غُبار ولا غيره . <br />
المعنى : <br />
{  كأنهن بيض مكنون } هذا وصف لنساء الجنة وأنهن بيض الأجسام بياضاً كبياض بيض النعام إذ هو أبيض مشرب بصفرة وهو من أحسن أنواع الجمال في النساء ومعنى {  مكنون } مستور لا ينالهُ غبار ولا أي أذىً . <br />
