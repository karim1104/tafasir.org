شرح الكلمات : <br />
{  ولقد نادانا نوح } :  أي قال إني مغلوب فانتصر  "  من سورة القمر  "  . <br />
{  فلنعم المجيبون } :  أي له إذ نجيناه وأهلكنا الكافرين من قومه . <br />
المعنى : <br />
على إثر ذكره تعالى إهلاك المنذرين وإنجائه المؤمنين من عباده المخلصين ذكر قصة تاريخية لذلك وهي نوح وقومه حيث أنذر نوح قومه ولما جاء العذاب أنجى الله عباده المخلصين وأهلك المكذبين المنذرين فقال تعالى في ذكر هذه القصة الموجزة {  ولقد نادانا نوح } أي دعانا لنصرته من قومه {  فقال رب انصرني بما كذبون } {  وقال إني مغلوب فانتصر } {  فلنعم المجيبون } نحن له . <br />
