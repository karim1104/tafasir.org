{  وفديناه بذبح عظيم } :  أي كبش كبير . <br />
المعنى : <br />
وهو قوله تعالى {  وفديناه بذبح عظيم } ،  وقوله تعالى {  وناديناه أن يا إبراهيم قد صدقت الرؤيا إنا كذلك نجزي المحسنين إن هذا لهو البلاء المبين } أي الاختبار البيّن وبذلك تأهل للخلة وأصبح خليل الرحمن ،  وقوله تعالى {  وفديناه } أي إسماعيل {  بذبح عظيم } أي بكبش عظيم .  وهو الذي ذبحه إبراهيم وترك إسماعيل . <br />
