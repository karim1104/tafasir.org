{  وجلت قلوبهم } :  أي خافت من اله تعالى أن تكون قصَّرتْ في طاعته . <br />
المعنى : <br />
فقال {  الذين إذا ذكر الله } لهم أو بينهم {  وجلت قلوبهم } أي خافت شعوراً بالتقصير في طاعته وعدم أداء شكره والغفلة عن ذكره {  والصابرين على ما أصابهم } من البلاء فلا يجزعون ولا يتسخطون ولكن يقولون إنا لله وإنا إليه راجعون {  والمقيمي } الصلاة أي بأدائها في أوقاتها في بيوت الله مع عباده المؤمنين ومع كامل شرائطها وأركانها وسننها {  ومما رزقناهم ينفقون } مما قل أو كثير ينفقون في مرضاة ربهم شكراً لله على ما آتاهم وتسليماً بما شرع لهم وفرض عليهم . <br />
