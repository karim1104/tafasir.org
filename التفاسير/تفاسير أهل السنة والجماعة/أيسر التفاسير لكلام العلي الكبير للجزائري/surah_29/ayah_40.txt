شرح الكلمات : <br />
{  فكلاً أخذنا بذنبه } :  أي فكل واحد من المذكورين أخذناه بذنبه ولم يفلت منا . <br />
{  ومنهم من أرسلنا عليه حاصباً } :  أي ريحاً شديدة ،  كعاد . <br />
{  ومنهم من خسفنا به الأرض } :  أي كقارون . <br />
{  ومنهم من أغرقنا } :  كقوم نوح وفرعون . <br />
المعنى : <br />
ثم في الآية الأربعين من هذا السياق بين تعالى أنواع العذاب الذي أهلك به هؤلاء الأقوام ،  فقال :  {  فكلاً } أي فكل واحد من هؤلاء المكذبين {  أخذنا بذنبه فمنهم من أرسلنا عليه حاصباً } أي ريحاً شديدة كعاد {  ومنهم من أخذته الصيحة } كثمود {  ومنهم من خسفنا به الأرض } كقارون {  ومنهم من أغرقنا } كفرعون ،  وقوله تعالى .  {  وما كان الله ليظلمهم } أي لم يكن من شأن الله تعالى الظلم فيظلمهم ،  {  ولكن كانوا } أي أولئك الأقوام {  أنفسهم يظلمون } بالشرك والكفر والتكذيب والمعاصي فأهلكوها بذلك ،  فكانوا هم الظالمين . <br />
الهداية : <br />
من الهداية : <br />
