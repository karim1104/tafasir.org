شرح الكلمات : <br />
{  كتاب } :  أي هذا كتاب . <br />
{  حرج } :  ضيق . <br />
{  وذكرى } :  تذكرة بها يذكرون الله وما عنده وما لديه فيقبلون على طاعته . <br />
المعنى : <br />
وقوله {  كتاب } أي هذا كتاب {  أنزل إليك } يا رسولنا {  فلا يكن في صدرك حرج منه } أي ضيق منه {  لتنذر به } قومك عواقب شركهم وضلالهم ،  وتذكر به المؤمنين منهم ذكرى وقل لهم {  اتبعوا ما أنزل إليكم من ربكم } . <br />

من الهداية : <br />
