شرح الكلمات : <br />
{  أرجه } :  أي أمهله و أخوه لا تعجل عليه قبل اتخاذ ما يلزم من الاحتياطات . <br />
{  في المدائن } :  مدن المملكة الفرعونية . <br />
{  حاشرين } :  رجلاً يجمعون السحرة الخبراء في فن السحر للمناظرة . <br />
المعنى : <br />
فأجابوا قائلين {  أَرْجِهْ وَ أَخَاه } أي أوقفهما عندك {  و أَرْسِلْ فِي المَدَائِنِ حَاشِرِين } أي رجالا من الشرط يحشرون أي يجمعون . <br />
