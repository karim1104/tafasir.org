شرح الكلمات : <br />
{  على أن تأجرني } :  أي تكون أجيراً لي في رعي غنمي . <br />
{  ثماني حجج } :  أي ثماني سنوات إذ الحجة عام والجمع حجج . <br />
{  فإن أتممت عشراً فمن عندك } :  أي جعلت الثمانية عشراً فرغبت عشراً فهذا من كرمك . <br />
{  ستجدني إن شاء الله من الصالحين } :  أي الذين يوفون ولا ينقضون ولا ينقصون . <br />
المعنى : <br />
فصدقها شعيب وقال لموسى :  {  إني أريد أن أنكحك } أي أزوجك {  إحدى ابنتي هاتين } {  على أن تأجرني ثماني حجج } أي سنين جمع حجة وهي السُّنَهْ وقوله {  فإن أتممت عشراً فمن عندك } أي إحساناً منك وكرماً ،  {  وما أريد أن أشق عليك } بطلب العشرة {  ستجدني إن شاء الله من الصالحين } أي الذين يوفون بعهودهم . <br />
الهداية : <br />
- مشروعية عرض الرجل ابنته على من يرى صدقه وأمانته ليزوجه بها . <br />
