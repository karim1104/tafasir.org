شرح الكلمات : <br />
{  ثم ننجي رسلنا والذين آمنوا } :  أي من العذاب المنتظر . <br />
{  كذلك } :  أي كذلك الإِنجاء ننج المؤمنين . <br />
المعنى : <br />
{  ثم ننجى رسلنا والذين آمنوا ،  كذلك } إي الإِنجاء {  حقاً علينا ننج المؤمنين } . <br />
