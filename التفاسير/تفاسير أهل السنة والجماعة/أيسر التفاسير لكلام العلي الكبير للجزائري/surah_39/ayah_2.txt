{  مخلصا له الدين } :  أي مفرداً إياه بالعبادة فلا تشرك بعبادته أحداً . <br />
المعنى : <br />
{  إنا أنزلنا إليك الكتاب } أي القرآن العظيم {  بالحق } في كل ما جاء فيه ودعا إليه من العقائد والعبادات والأحكام وعليه {  فاعبد الله مخلصاً له الدين } أي العبادة فلا تعبد معه غيره فإِن العبادة لا تصلح لغيره أبداً . <br />
