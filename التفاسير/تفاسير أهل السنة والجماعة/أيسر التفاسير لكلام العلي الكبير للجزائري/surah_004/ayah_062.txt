شرح الكلمات : <br />
{  مصيبة } :  عقوبة بسبب كفرهم ونفاقهم . <br />
{  إن يريدون } :  أي ما يريدون . <br />
{  إلا إحسانا } :  أي صلحاً بين المتخاصمين . <br />
{  وتوفيقا } :  جمعا وتأليفا بين المختلفين . <br />
المعنى : <br />
{  فكيف إذا أصابتهم مصيبة } وحلت بهم قارعة بسبب ذنوبهم أيبقون معرضين عنك ؟  أم ماذا ؟  {  ثم جاءوك يحلفون بالله } قائلين ،  ما أردنا إلا الإحسان في عملنا ذلك والتوفيق بين المتخاصمين .  هذا ما دلت عليه الآيات الثلاث . <br />
