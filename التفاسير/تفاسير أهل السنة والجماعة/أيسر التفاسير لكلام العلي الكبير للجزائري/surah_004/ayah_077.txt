{  ألم تر إلى الذين قيل لهم كفوا أيديكم } أ عن القتال {  وأقيموا الصلاة وآتوا الزكاة } ريثما يأذن الله بالقتال عندما تتوفر إمكانياته ،  فلما فرض القتال ونزل قوله تعالى : {  أذن للذين يقاتلون بأنهم ظلموا } جبنوا ولم يخرجوا للقتال ،  وقالوا {  لولا أخرتنا إلى أجل قريب } يريدون أن يدافعوا الأيام حتى يموتوا ولم يلقوا عدواً خوراً وجبناً فأمر تعالى الرسول أن يقول لهم :  {  متاع الدنيا قليل والآخرة خير لمن اتقى } فعيشكم في الدنيا مهما طابت لكم الحياة هو قليل {  والآخرة خير لمن اتقى } الله فعل أمره وترك نهيه بعد الإيمان به وبرسوله ،  وسوف تحاسبون على أعمالكم وتجزون بها {  ولا تظلمون فتيلا } بنقص حسنة ولا بزيادة سيئة هذا ما تضمنته الآية الأولى . <br />
