{  أولئك } أي السامون أنفساً العالون أرواحاً {  يجزون الغرقة } وهي الدرجة العليا في الجنة {  بما صبروا } على طاعة مولاهم ،  وما يلحقهم من أذى في ذات ربهم {  ويلقون فيها } أي تتلقاهم الملائكة بالتهاني والتحيات {  تحية وسلاماً } أي بالدعاء بالحياة السعيدة والسلامة من الآفات إذ هي حياة بلا ممات ،  وسعادة بلا منغصات . <br />
