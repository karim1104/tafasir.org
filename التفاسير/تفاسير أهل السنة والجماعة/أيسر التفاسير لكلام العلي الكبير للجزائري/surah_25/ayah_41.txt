شرح الكلمات : <br />
{  إن يتخذونك } :  أي ما يتخذونك . <br />
{  إلا هزواً } :  أي مهزوءاً به . <br />
{  أهذا الذي بعث الله رسولاً } :  أي في دعواه لا أنهم معترفون برسالته والاستفهام للتهكم والاحتقار . <br />
المعنى : <br />
قوله تعالى {  وإذا رأوك إن يتخذونك إلا هزواً } يخبر تعالى رسوله عن أولئك المشركين المكذبين بالبعث أنهم إذا رأوه في مجلس أو طريق ما يتخذونه لا هزوا أي مهزوءاً به احتقاراً وازدراءً له فيقولون فيما بينهم ،  {  أهذا الذي بعث الله رسولاً } وهو استفهام احتقار وازدراء لأنهم لا يعتقدون أنه رسول الله ويقولون {  إن كاد ليضلنا عن آلهتنا } . <br />
