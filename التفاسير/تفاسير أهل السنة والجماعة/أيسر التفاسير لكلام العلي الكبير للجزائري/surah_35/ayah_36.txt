شرح الكلمات : <br />
{  لا يقضى عليهم } :  أي بالموت فيموتوا ويستريحوا . <br />
{  كذلك نجزي كل كفور } :  أي كذلك الجزاء نجزى كل كفور بنا وبآياتنا ولقاءنا . <br />
المعنى : <br />
بعدما ذكر تعالى جزاء أهل الإِيمان والعمل الصالح ذكر جزاء أهل الكفر والمعاصي فقال :  {  والذين كفروا } أي بالله وآياته ولقائه {  لهم نار جهنم } أي جزاء لهم {  لا يقضى عليهم } أي بالموت فيموتوا حتى يستريحوا ولا يخفف عنهم من عذابها ولا طرفة عين .  وقوله تعالى {  كذلك } أي الجزاء {  نجزي كل كفور } أي مبالغ في الكفر مكثر منه . <br />
