شرح الكلمات : <br />
{  بما أغويتني } :  أي بسبب إغوائك لي أي إضلالك وإفسادك لي . <br />
المعنى : <br />
فلما سمع اللعين ما حكم به الرب تعالى عليه قال ما أخبر الله عنه بقوله :  {  قال رب بما أغويتني } أي بسبب إغوائك {  لأزينن لهم في الأرض } أي الكفر والشرك وكبائر الذنوب ،  و {  لأغوينهم } أي لأضلنهم {  أجمعين } . <br />
الهداية : <br />
- أمضى سلاح يغوي به إبليس بني آدم هو التزين الأشياء حتى ولو كانت ذميمة قبيحة يصيرها بوسواسه زينة حسنة حتى يأتيها الآدمي . <br />
