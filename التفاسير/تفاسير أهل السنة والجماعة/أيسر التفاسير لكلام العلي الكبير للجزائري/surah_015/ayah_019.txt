شرح الكلمات : <br />
{  والأرض مددناها } :  أي بسطناها . <br />
{  وألقينا فيها رواسي } :  أي جبالاً ثوابت لئلا تتحرك الأرض . <br />
{  موزون } :  أي مقدر معلوم المقدار لله تعالى . <br />
المعنى : <br />
ما زال السياق في ذكر مظاهر قدرة الله وعلمه وحكمته ورحمته وهي موجبات الإيمان به وعبادته وتوحيده والتقرب إليه بفعل محابه وترك مساخطه . <br />
قوله تعالى :  {  والأرض مددناها } أي بسطناها {  وألقينا فيها رواسي } أي جبالاً ثوابت تثبت الأرض حتى لا تتحرك أو تميد بأهلها فيهلكوا ،  {  وأنبتنا فيها من كل شيء موزون } أي مقدر معلوم المقدار لله تعالى . <br />
