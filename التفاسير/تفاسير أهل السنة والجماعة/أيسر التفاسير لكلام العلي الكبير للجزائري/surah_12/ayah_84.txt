شرح الكلمات : <br />
{  وتولى عنهم } :  أي معرضاً عن حديثهم . <br />
{  وقال يا أسفى } :  أي يا حزني أحضر هذا أوان حضورك . <br />
{  فهو كظيم } :  أي مغموم مكروب لا يظهر كربه . <br />
المعنى : <br />
{  وتولى عنهم } أي أعرض عن مخاطبتهم {  وقال يا أسفى } أي يا أسفي وشدة حزني أحضر فهذا أوان حضورك {  على يوسف } قال تعالى مخبراً عن حاله بعد ذلك {  وابيضت عيناه من الحزن } فغلب بياضهما على سوادهما ومعنى هذا أنه فقد الإِبصار بما أصاب عينيه من البياض {  فهو كظيم } أي ممتلئ من الهم والكرب والحزن مكظوم لا يبثه لأحد ولا يشكوه لغير ربه تعالى . <br />
