شرح الكلمات : <br />
{  كل نفس } :  أي مأمورة منهية . <br />
{  رهينة } :  أي مرهونة مأخوذة بعملها في جهنم . <br />
المعنى : <br />
ما زال السياق الكريم في تقرير عقيدة البعث والجزاء فقال تعالى {  كل نفس } أي يوم القيامة {  رهينة } بمعنى مرهونة محبوسة أي كل نفس مأمورة منهية بمعنى مكلفة بخلاف نفوس غير المكلفين من أطفال ومجانين . <br />
