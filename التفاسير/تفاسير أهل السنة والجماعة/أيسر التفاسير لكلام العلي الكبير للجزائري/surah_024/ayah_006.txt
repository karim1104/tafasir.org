شرح الكلمات : <br />
{  يرمون أزواجهم } :  أي يقذفونهن بالزنا كأن يقول زنت أو الحمل الذي في بطنها ليس منه . <br />
{  إنه لمن الصادقين } :  أي فيما رماها به من الزنى . <br />
المعنى : <br />
بعد بيان حكم حد القذف العام ذكر تعالى حكم القذف الخاص وهو قذف الرجل زوجته فقال تعالى :  {  والذين يرمون أزواجهم } أي بالفاحشة {  ولم يكن لهم شهداء } أي من يشهد معهم إلا أنفسهم أي إلا القاذف وحده فالذي يقول مقام الأربعة شهود هو أن يشهد أربع شهادات قائلاً :  أشهد بالله لقد رأيتها تزني أو زنت أو هذا الولد أو الحمل ليس لي . <br />
