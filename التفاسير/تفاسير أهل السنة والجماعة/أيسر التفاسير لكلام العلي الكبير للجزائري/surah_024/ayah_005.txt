شرح الكلمات : <br />
{  إلا الذين تابوا } :  فإنهم بعد توبتهم يعود إليهم اعتبارهم وتصح شهادتهم . <br />
المعنى : <br />
{  إلا الذين تابوا من بعد ذلك وأصلحوا } بأن كذبوا أنفسهم بأنهم ما رأوا الفاحشة وقوله :  {  فإن الله غفور } فيغفر لهم بعد التوبة {  رحيم } بهم يرحمهم ولا يعذبهم بهذا الذنب العظيم بعدما تابوا منه . <br />
الهداية : <br />
- قبول توبة التائب إن كانت توبته صادقة نصوحاً . <br />
