شرح الكلمات : <br />
{  ظالمي أنفسهم } :  بالشرك والمعاصي . <br />
{  فألقوا السلم } :  أي استسلموا وانقادوا . <br />
المعنى : <br />
/د26<br />
وقوله تعالى :  {  الذين تتوفاهم الملائكة ظالمي أنفسهم } بالشرك والمعاصي ومن جملة المعاصي ترك الهجرة والبقاء بين ظهراني الكافرين والفساق المجرمين حيث لا يتمكن المؤمن من عبادة الله تعالى بترك المعاصي والقيام بالعبادات .  وقوله {  فألقوا السلم } أي عند معاينتهم ملك الموت وأعوانه أي استسلموا وانقادوا وحاولوا الاعتذار بالكذب وقالوا {  ما كنا نعمل من سوء } فترد عليهم الملائكة قائلين :  {  بلى } أي كنتم تعملون السوء {  أن الله عليم بما كنتم تعملون } . <br />
الهداية : <br />
- بيان استسلام الظلمة عند الموت وانهزامهم وكذبهم .
