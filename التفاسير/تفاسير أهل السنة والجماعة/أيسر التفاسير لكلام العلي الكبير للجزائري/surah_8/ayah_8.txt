شرح الكلمات : <br />
{  يبطل الباطل } :  أي يظهر بطلانه بقمع أهله وكسر شوكتهم وهزيمتهم . <br />
{  ولو كره المجرمون } :  كفار قريش المشركون . <br />
المعنى : <br />
وقوله {  ليحق الحق } أي لينصره ويقرره وهو الإِسلام {  ويبطل الباطل } وهو الشرك {  ولو كره } ذلك {  المجرمون } أي المشركون الذين أجرموا على أنفسهم فأفسدوها بالشرك ،  وعلى غيرهم أيضاً حيث منعوهم من قبول الإِسلام وصرفوه عنه بشتى الوسائل . <br />
