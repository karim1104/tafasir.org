شرح الكلمات : <br />
{  في قلوبهم مرض } :  أي شك ونفاق وشرك . <br />
{  فزادتهم رجساً } :  أي نجساً إلى نجس قلوبهم ونفوسهم . <br />
المعنى : <br />
{  وأما الذين في قلوبهم مرض } أي شك ونفاق {  فزادتهم رجساً } أي شكاً ونفاقاً {  إلى رجسهم وماتوا وهم كافرون } . <br />

من الهداية : <br />
