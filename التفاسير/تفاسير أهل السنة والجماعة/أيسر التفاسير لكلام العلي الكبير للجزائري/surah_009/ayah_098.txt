شرح الكلمات : <br />
{  مغرما } :  أي غرامة وخسراناً . <br />
{  ويتربص } :  أي ينتظر . <br />
{  الدوائر } :  جمع دائرة :  ما يحيط بالإِنسان من مصيبة أو نكبة . <br />
{  دائرة السوء } :  أي المصيبة التي تسوءهم ولا تسرهم وهي الهلاك . <br />
المعنى : <br />
وقوله تعالى في الآية الثانية ( 98 ) الجهاد غرامة لزمَتْه وخسارة لحقَتْه في ماله وذلك لأنه لا يؤمن بالثواب والعقاب الأخروي لأنه كافر بالله ولقاء الله تعالى .  وقوله عز وجل {  ويتربص بكم الدوائر } أي وينتظر بكم أيها المسلمون الدوائر متى تنزل بكم فيتخلص منكم ومن الإنفاق لكم والدوائر جمع دائرة المصيبة والنازلة من الأحداث وقوله تعالى {  عليهم دائرة السوء } هذه الجملة دعاء عليهم .  جزاء ما يتربصون بالمؤمنين .  وقوله {  والله سميع عليم } أي سميع لأقوالهم عليم بنياتهم فلذا دعا عليهم بما يستحقون . <br />
