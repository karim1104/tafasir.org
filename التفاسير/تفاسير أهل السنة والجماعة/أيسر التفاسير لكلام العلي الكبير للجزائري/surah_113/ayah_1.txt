{  أعوذ } :  أي استجير واتحصن . <br />
{  الفلق } :  أي الصبح . <br />
المعنى : <br />
قوله تعالى : {  قل أعوذ برب الفلق } أنه لما سحر لبيد بن معصم اليهودي بالمدينة النبي صلى الله عليه وسلم أنزل تعالى المعوذتين ،  فرقاه بهما جبريل ،  فشفاه الله تعالى ،  ولذا فالسورتان مدنيتان . <br />
 وقوله تعالى {  قل أعوذ برب الفلق } أي قل يا رسولنا :  {  أعوذ } أي أستجير وأتحصن {  برب الفلق } وهو الله عز وجل ؛  إذ هو {  فالق الإِصباح } و{  فالق الحب والنوى } ،  ولا يقدر على ذلك إلا هو لعظيم قدرته وسعة علمه . <br />
