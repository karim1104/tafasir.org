شرح الكلمات : <br />
{  أشحة عليكم } :  أي بخلاء لا ينفقون على مشاريعكم الخيرية كنفقة الجهاد وعلى الفقراء . <br />
{  تدور أعينهم كالذي يغشى من الموت } :  أي تدور أعينهم من شدة الخوف لجبنهم كالمحتضر عليه الذي يغشى عليه أي يغمى عليه من آلام سكرات الموت . <br />
{  سلقوكم بألسنة حداد } :  أي آذوكم بألسنة حادة كأنها الحديد وذلك بكثرة كلامهم وتبجحهم بالأقوال دون الأفعال . <br />
{  أشحة على الخير } :  أي بخلاء بالخير لا يعطونه ولا يفعلونه بل ولا يقولونه حتى القول . <br />
{  أولئك لم يؤمنوا } :  أي إنهم لم يؤمنوا الإِيمان الصحيح فلذا هم جبناء عند اللقاء بخلاء عند العطاء . <br />
المعنى : <br />
وقوله تعالى {  أشحة عليكم } وصفهم بالبخل بعد وصفهم بالجبن وهما شر صفات المرء أي الجبن والبخل أشحة عليكم أي بخلاء لا ينفقون معكم لا على الجهاد ولا على الفقراء والمحتاجين وقوله تعالى {  فإِذا جاء الخوف } أي بسبب هجوم العدو {  رأيتهم } أيها الرسول {  ينظرون إليك } لائذين بك {  تدور أعينهم } من الخوف {  كالذي يغشى عليه من الموت } وهو المحتضر يُغمى عليه لما يعاني من سكرات الموت وهذا تصوير هائل لمدى ما عليه المنافقون من الجبن والخوف وعلة هذا هو الكفر وعدم الإِيمان بالقدر والبعث والجزاء . <br />
وقوله {  فإِذا ذهب الخوف } أي راحت أسبابه بانتهاء الحرب {  سلقوكم بألسنة } أي سلقكم أولئك الجبناء عند اللقاء أي ضربوكم بألسنة ذربة حادة كالحديد بالمطالبة بالغنيمة أو بالتبجح الكاذب بأنهم فعلوا وفعلوا .  وهذا حالهم إلى اليوم . <br />
وقوله {  أشحة على الخير } أي بخلاء على مشاريع الخير وما ينفق في سبيل الله فلا ينفقون لأنهم لا يؤمنون بالخلف ولا بالثواب والأجر وذلك لكفرهم بالله ولقائه .  ولذا قال تعالى {  أولئك لم يؤمنوا } فسجل عليهم وصف الكفر ورتب عليه نتائجه فقال {  فأحبط الله أعمالهم } أي أبطلها فلا يثابون عليها لأنها أعمال مشرك وأعمال المشرك باطلة ،  وقوله {  وكان ذلك على الله يسيرا } أي إبطال أعمالهم وتخييبهم فيها وحرمانهم من جزائها يسير على الله ليس بالعسير .  ولذا هو واقع كما أخبر تعالى . <br />
