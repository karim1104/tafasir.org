شرح الكلمات : <br />
{  ولو دخلت عليهم } :  أي المدينة أي دخلها العدو الغازي . <br />
{  ثم سئلوا الفتنة } :  أي ثم طلب إليهم الردة غلى الشرك لآتوها أي أعطوها وفعلوها . <br />
{  وما تلبثوا بها إلا يسيرا } :  أي ما تريثوا ولا تمهلوا بل أسرعوا الإِجابة وارتدوا . <br />
المعنى : <br />
{  ولو دخلت عليهم } المدينة {  من أقطارها } أي من جميع نواحيها من شرق وغرب وشمال وجنوب {  ثم سئلوا الفتنة } أي ثم طلب منهم العدو الغازي الذي دخل عليهم المدينة الردة أي العودة إلى الشرك {  لآتوها } أعطوها فوراً {  وما تلبثوا بها إلا يسيراً } حتى يرتدوا عن الإِسلام ويصبحوا كما كانوا مشركين والعياذ بالله من النفاق والمنافقين . <br />
