شرح الكلمات : <br />
{  ذرني ومن يكذب } :  أي دعني ومن يكذب أي لا يصدق . <br />
{  بهذا الحديث } :  أي بالقرآن الكريم . <br />
{  سنستدرجهم } :  أي نستنزلهم درجة درجة حتى نصل بهم إلى العذاب . <br />
المعنى : <br />
بعد ذلك التقريع الشديد للمشركين المكذبين الذي لم يؤثر في نفوسهم أدنى تأثير قال تعالى لرسوله {  فذرني } أي بناء على ذلك فذرني ومن يكذب بهذا الحديث أي دعني وإياهم ،  والمراد من الحديث القرآن الكريم {  سنستدرجهم } أي نستنزلهم درجة درجة {  من حيث لا يعلمون } حتى تنتهي بهم إلى عذابهم المترتب على تكذيبهم وشركهم . <br />
