{  كل حلاف مهين } :  أي كثير الحلف بالباطل حقير . <br />
المعنى : <br />
وقوله تعالى {  ولا تطع كل حلاف مهين } بعدما نهاه عن إطاعة الكافرين عامة نهاه عن طاعة أفراد شريرين لا خير فيهم البتة كالوليد بن المغيرة فقال :  {  ولا تطع كل حلاف } كثير الحلف بالباطل {  مهين } أي حقير . <br />
