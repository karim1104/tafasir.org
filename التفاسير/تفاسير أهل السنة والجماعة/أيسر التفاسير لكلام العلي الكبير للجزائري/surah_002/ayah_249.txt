شرح الكلمات : <br />
{  فصل طالوت } :  انفصل من الديار وخرج يريد العدو . <br />
{  بالجنود } :  العسكر وتعداده - كما قيل :  سبعون ألف مقاتل . <br />
{  مبتليكم بنهر } :  مختبركم بنهر جار لعله هو نهر الأردن الآن . <br />
{  ومن لم يطعمه } :  الم يشرب منه . <br />
{  غرفة } :  الغرفة بالفتح المرة وبالضم الاسم من الاغتراف .  {  الذي آمنوا معه } :  هم الذين لم يشربوا من النهر ،  أما من شرب فقد كفر وأشرك . <br />
{  أنهم مُلاَقوُ اللَّهِ } :  أي يوم القيامة فهم يؤمنون بالبعث الآخر . <br />
{  كم من فئة } :  كم للتكثير والفئة :  الجماعة يفيىء بعضها إلى بعض . <br />
{  والله مع الصابرين } :  يسددهم ويعينهم وينصرهم . <br />
