شرح الكلمات : <br />
{  لا يكلف الله نفسا } :  التكليف الإِلزام مما فيه كلفة ومشقة تحتمل . <br />
{  إلا وسعها } :  إلا ما تتسع لها طاقتها ويكون في قدرتها . <br />
{  لها ما كسبت } :  من الخير . <br />
{  وعليها ما اكتسبت } :  من الشر . <br />
{  لا تؤاخذنا } :  لا تعاقبنا . <br />
{  إن نسينا } :  فتركنا ما أمرتنا به أو فعلنا ما نهيتنا عنه نسياناً منا غير عمد . <br />
{  أو أخطأنا } :  فعلنا غير ما أمرتنا خطأ منا بدون إرادة فعل منا له ولا عزيمة . <br />
{  إصراً } :  تكليفا شاقا يثقل علينا ويأسرنا فيحبسنا عن العمل . <br />
{  مولانا } :  مالكنا وسيدنا ومتولي أمرنا لا مولى لنا سواك . <br />
