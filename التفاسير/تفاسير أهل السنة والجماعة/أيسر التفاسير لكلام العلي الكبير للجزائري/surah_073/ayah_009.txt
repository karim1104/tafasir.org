شرح الكلمات : <br />
{  لا إله إلا هو } :  أي لا معبود بحق سواه ولا تنبغي العبادة لغيره . <br />
{  فاتخذه وكيلا } :  أي فوض جميع أمورك إليه فإِنه يكفيك . <br />
المعنى : <br />
وقوله {  رب المشرق والمغرب } أي هو تعالى ربّ المشرق والمغرب أي مالك المشرقين والمغربين {  لا إله إلا هو } فلا تنبغي العبادة إلا له ولا تصح الألوهية إلا له أيضاً وقوله {  فاتخذه وكيلا } أي من كل ما يهمك فإِنه يكفيك وهو على كل شيء قدير . <br />
