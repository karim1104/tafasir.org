شرح الكلمات : <br />
{  وذرني } :  أي اتركني . <br />
{  والمكذبين } :  أي صناديد قريش فإِني أكفكهم . <br />
{  أولي النعمة } :  أي أهل التنعم والترف . <br />
{  ومهلهم قليلا } :  أي انتظرهم قليلا من الزمن حتى يهلكوا ببدر . <br />
المعنى : <br />
وقوله {  وذرني والمكذبين أولي النعمة } أي اتركني والمكذبين من صناديد قريش أولي النعمة أي النعم والترف {  ومهلهم قليلا } أي أنظرهم ولا تستعجل فإِني كافيكهم ،  ولم يمض إلا زمن يسير حتى هلكوا في بدر على أيدي المؤمنين . <br />
