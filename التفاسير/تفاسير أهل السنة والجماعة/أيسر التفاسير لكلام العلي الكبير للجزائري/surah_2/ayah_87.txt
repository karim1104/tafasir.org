{  موسى } :  موسى بن عمران نبي مرسل إلى بني إسرائيل . <br />
{  الكتاب } :  التوراة . <br />
{  قفينا } :  أرسلناهم يَقْفُو بعضهم بعضاً أي واحداً بعدَ واحد . <br />
{  الرسل } :  جمع رسول :  ذكر من بني آدم أوحي إليه بشرع وأمر بتبلغيه . <br />
{  البينات } :  المعجزات وآيات الله في الإِنجيل . <br />
{  روح القدس } :  جبريل عليه السلام . <br />
/د87<br />
ففي الآية ( 87 ) يذكر تعالى منته بإعطاء موسى التوراة وإرسال الرسل بعده بعضهم على أثر بعض ،  وبإعطاء عيسى البينات وتأييده بروح القدس جبريل عليه السلام ومع هذا فإنهم لم يستقيموا بل كانوا يقتلون الأنبياء ويكذبونهم فوبخهم الله تعالى على ذلك قوله :  {  أفكلما جاءكم رسول بما لا تهوى أنفسكم استكبرتم ففريقاً كذبتم وفريقاً تقتلون } . <br />
