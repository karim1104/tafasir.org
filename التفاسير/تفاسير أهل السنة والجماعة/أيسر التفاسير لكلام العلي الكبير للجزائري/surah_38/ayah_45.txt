شرح الكلمات : <br />
{  واذكر عبدنا } :  أي اذكر صبرهم على ما أصابهم فإِن لك بهم أسوة . <br />
{  أولى الأيدي } :  أي أصحاب القوى في العبادة . <br />
{  والأبصار } :  أي البصائر في الدين بمعرفة الأسرار والحكم . <br />
المعنى : <br />
ما زال السياق في ذكر الأنبياء وما أُكرموا به على صبرهم ليكون ذلك مثبتاً للنبي صلى الله عليه وسلم على دعوته والصبر عليها والتحمل في سبيل الوصول بها إلى غاياتها فقال تعالى له {  واذكر } أي يا نبيّنا {  عبادنا } لتتأسى بهم وهم {  إبراهيم واسحق } وولده {  يعقوب } حفيده {  أولي } أي أصحاب {  الأيدي } أي القوى في العبادة والطاعة {  والأبصار } اي أبصار القلوب وذلك بالفقه في الدين ومعرفة أسرار التشريع . <br />
الهداية : <br />
من الهداية : <br />
- فضيلة القوة في العبادة والبصيرة في الدين وفي الحديث  "  المؤمن القوي خير وأحب إلى الله من المؤمن الضعيف وفي كل خير  "  . <br />
