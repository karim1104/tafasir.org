شرح الكلمات : <br />
{  بغى بعضنا على بعض } :  أي تعدّى بعضنا على بعض . <br />
{  فاحكم بيننا بالحق ولا تشطط } :  أي احكم بالعدل ولا تجر في حكمك . <br />
{  واهدنا إلى سواء الصراط } :  أي أرشدنا إلى العدل في قضيتنا هذه ولا تمل بنا إلى غير الحق . <br />
المعنى : <br />
وقوله {  إذ دخلوا على داود- وهو في محرابه- ففزع منهم }  أي ارتاع واضطرب نفسا {  فقالوا لا تخف خصمان } أي نحن خصمان {  بغى بعضنا على بعض } أي اعتدى بعضنا على بعض جئنا نتحاكم إليك {  فاحكم بيننا بالحق ولا تشطط } أي لا تجر في الحكم {  واهدنا إلى سواء الصراط } أي إلى وسط الطريق فلا تمل بنا عن الحق . <br />
