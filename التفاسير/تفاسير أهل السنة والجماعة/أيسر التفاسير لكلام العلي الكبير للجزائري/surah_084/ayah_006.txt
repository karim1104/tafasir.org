شرح الكلمات : <br />
{  إنك كادح } :  أي عامل كاسب للخير أو الشر . <br />
{  إلى ربك كدحا } :  أي إلى أن تلقى ربك وأنت تعمل وتكسب فليكن عملك مما يرضي عنك ربك<br />
{  فملاقيه } :  أي ملاق ربك بعد موتك وبعملك خيره وشره . <br />
المعنى : <br />
قوله تعالى {  يا أيها الإِنسان } أي يا بن آدم {  إنك كادح إلى ربك كدحا } أي إنك عامل تعمل يوميا وليل نهار إلى أن تمون وتلقى ربك إنك لا تبرح تعمل لا محالة وتكسب بجوارحك الخير والشر إلى الموت حيث تنتقل إلى الدار الآخرة وتلقى ربك وتلاقيه هذا يشهد له قول الرسول صلى الله عليه وسلم في الصحيح  "  كلكم يغدو فبائع نفسه فمعتقها أو موبقها  " <br />
إذا فمن الخير لك أيها الإِنسان المكلف أن تعمل عملك صالحا وانظر إلى الصورة التالية {  فأما من أوتي كتابه بيمينه } . <br />
