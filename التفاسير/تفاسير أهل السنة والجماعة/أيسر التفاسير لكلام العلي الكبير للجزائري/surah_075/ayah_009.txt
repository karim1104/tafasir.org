شرح الكلمات : <br />
{  وجمع الشمس والقمر } :  أي ذهب ضوءهما وذلك في بداية الانقلاب الكوني الذي تنتهي فيه هذه الحياة . <br />
{  أين المفر } :  أي إلى أين الفرار . <br />
{  كلا } :  ردع له عن طلب الفرار . <br />
{  لا وزر } :  أي لا ملجأ يتحصن به . <br />
{  بل الإِنسان على نفسه بصرة } :  أي هو شاهد على نفسه حيث تنطق جوارحه بعمله . <br />
{  ولو ألقى معاذيره } :  أي فلا بد من جزائه ولو ألقى معاذيره . <br />
