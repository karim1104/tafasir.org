شرح الكلمات : <br />
{  رواسي } :  أي جبالاً ثابتة . <br />
{  أي تميد بهم } :  أي تتحرك فتميل بهم . <br />
{  فجاجا سبلا } :  أي طرقاً واسعة يسلكونها تصل بهم إلى حيث يريدون . <br />
المعنى : <br />
وقوله تعالى :  {  وجعلنا في الأرض رواسي } أي جبالاً ثوابت كيلا تميد أي تتحرك وتضطرب بسكانها ،  {  وجعلنا فيها } أي في الأرض {  فجاجاً سبلاً } أي طرقاً سابلة للسير فيها {  لعلهم يهتدون } أي كي يهتدوا إلى مقاصدهم في أسفارهم . <br />
الهداية<br />
من الهداية : <br />
- بيان الحكمة من خلق الجبال الرواسي . <br />
- بيان دقة النظام الإلهي ،  وعظيم العلم والحكمة له سبحانه وتعالى . <br />
