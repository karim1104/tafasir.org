شرح الكلمات : <br />
{  بل تأتيهم بغتة } :  أي تأتيهم القيامة بغتة أي فجأة . <br />
{  فتبهتهم } :  أي تُحيرهم . <br />
{  ولا هم ينظرون } :  أي يمهلون ليتوبوا . <br />
المعنى : <br />
وقوله تعالى :  {  بل تأتيهم بغتة فتبهتهم فلا يستطيعون ردها ولا هم ينظرون } أي أن القيامة لا تأتيهم على علم منهم يوقتها وساعتها فيمكنهم بذلك التوبة ،  وإنما تأتيهم {  بغتة } أي فجأة {  فتبهتهم } أي فتحيرهم {  فلا يستطيعون ردها ،  ولا هم ينظرون } أي يمهلون ليتوبوا من الشرك والمعاصي فينجوا من عذاب النار . <br />
الهداية : <br />
من الهداية : <br />
- تقرير أن الساعة لا تأتي إلا بغتة . <br />
- تقرير عقيدة البعث والجزاء . <br />
