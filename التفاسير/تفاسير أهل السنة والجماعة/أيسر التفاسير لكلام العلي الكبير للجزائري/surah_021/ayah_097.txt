شرح الكلمات : <br />
{  الوعد الحق } :  يوم القيامة . <br />
{  في غفلة من هذا } :  أي من يوم القيامة وما فيه من أحداث . <br />
المعنى : <br />
وقوله تعالى :  {  واقترب الوعد الحق } وهو يوم الدين والحساب والجزاء وقوله :  {  فإذا هي شاخصة أبصارهم الذين كفروا } وذلك بعد قيامهم من قبورهم وحشرهم إلى أرض المحشر وهم يقولون في تأسف وتحسر {  يا ويلنا } أي يا هلاكنا {  قد كنا في غفلة } أي في دار الدنيا {  بل كنا ظالمين } فاعترفوا بذنبهم حيث لا ينفعهم الاعتراف إذ لا توبة تقبل يومئذ . <br />
