شرح الكلمات : <br />
{  قال كذلك } :  أي الأمر كذلك أتتك آياتنا فنسيتها فكما نسيتها تنسى في جهنم . <br />
المعنى : <br />
فيجيبه ربه تعالى :  {  كذلك } أي الأمر كذلك بصيرا وأصبحت أعمى لأنك {  أتتك آياتنا } تحملها كتبنا وتبينها رسلنا {  فنسيتها } أي تركتها ولم تلتفت إليها معرضا عنها فاليوم تترك في جهنم منسياً كذلك . <br />
