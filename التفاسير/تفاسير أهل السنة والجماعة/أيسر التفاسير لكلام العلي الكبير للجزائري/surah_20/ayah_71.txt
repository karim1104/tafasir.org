شرح الكلمات : <br />
{  إنه لكبيركم } :  أي لمعلمكم الذي علمكم السحر . <br />
{  من خلاف } :  أي يد يمنى مع رجل يسرى . <br />
{  في جذوع النخل } :  أي على أخشاب النخل . <br />
{  أينا أشد عذاباً وأبقى } :  يعني نفسه - لعنه الله - ورب موسى أشد عذاباً وأدومه على مخالفته وعصيانه . <br />
المعنى : <br />
وهنا صاح فرعون مزمجراً مهدداً ليتلافى في نظره شر الهزيمة فقال للسحرة {  آمنتم له قبل أن آذن لكم } بذلك {  إنه لكبيركم } أي معلمكم العظيم {  الذي علمكم السحر } فتواطأتهم معه على الهزيمة .  {  فلأقطعن أيديكم وأرجلكم من خلاف } تعذيباً وتنكيلاً فأقطع يمين أحدكم مع يسرى رجليه ،  أو العكس {  ولأصلبنكم في جذوع النخل } أي لأشدنكم على أخشاب النخل وأترككم معلقين عبرة ونكالا لغيركم {  ولتعلمن أينا أشد عذاباً وأبقى } أي أدومه :  رب موسى الذي آمنتم به أو أنا  "  فرعون عليه لعائن الله  " <br />
