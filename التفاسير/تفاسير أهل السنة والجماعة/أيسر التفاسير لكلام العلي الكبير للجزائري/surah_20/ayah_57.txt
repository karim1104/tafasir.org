شرح الكلمات : <br />
{  من أرضنا } :  أي أرض مصر التي فرعون ملك عليها . <br />
{  بسحرك يا موسى } :  يشير إلى العصا واليد البيضاء . <br />
المعنى : <br />
وقال ما أخبر تعالى به عنه :  {  قال أجئتنا } أي يا موسى {  لتخرجنا من أرضنا } أي منازلنا وديارنا ومملكتنا {  بسحرك } الذي انقلبت به عصاك حية تسعى . <br />
