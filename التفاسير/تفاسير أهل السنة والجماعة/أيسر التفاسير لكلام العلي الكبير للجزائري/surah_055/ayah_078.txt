شرح الكلمات : <br />
{  تبارك اسم ربك } :  أي تقدس وكثرت بركة اسم ربك الرحمن . <br />
{  ذي الجلال والإِكرام } :  أي ذي العظمة الإِكرام لأوليائه والإِحسان إلى عباده . <br />
المعنى : <br />
وقوله تعالى {  تبارك اسم ربك ذي الجلال والإِكرام } أي تبارك اسم ربك أي تقدس وكثرت بركات اسم ربك الرحمن ذي الجلال أي العظمة والإِكرام لأوليائه وصالحي عباده . <br />
