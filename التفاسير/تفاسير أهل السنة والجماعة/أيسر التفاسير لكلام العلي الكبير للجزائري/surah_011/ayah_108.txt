{  عطاء غير مجذوذ } :  أي غير مقطوع بل هو دائم أبداً . <br />
المعنى : <br />
وقوله {  وأما الذين سعدوا } أي حكم الله تعالى بسعادتهم } لما وفقهم الله من الإِيمان والعمل الصالح وترك الشرك والمعاصي {  ففي الجنة خالدين فيها ما دامت السماوات والأرض إلا ما شاء ر‍َبُّك } إذ إرادة الله مطلقة لا تحد إلا بمشيئته العليا وقوله {  عطاء غير مجذوذ } أي عطاء من ربك لأهل طاعته غير مقطوع أبداً وهذا دليل خلودهم فيها أبدا . <br />
