شرح الكلمات : <br />
{  يا ويلتا } :  أي يا ويلتي أحضري هذا أوان حضورك . <br />
{  وهذا بعلي شيخا } :  إشارة إلى إبراهيم إذ هو بعلها أي زوجها . <br />
{  إن هذا لشيء عجيب } :  أي أمر يتعجب منه استبعاداً له واستغراباً . <br />
المعنى : <br />
فلما سمعت البشرى صكت وجهها تعجبا على عادة النساء وقالت {  يا ويلتا أألد وأنا عجوز وهذا بعلي } تشير إلى زوجها إبراهيم {  شيخا } أي كبير السن إذ كانت سنة يومئذ مائة سنة وسنها فوق التسعين .  {  إن هذا لشيء عجيب } أي ولادتي في هذه السن أمر يتعجب منه . <br />
