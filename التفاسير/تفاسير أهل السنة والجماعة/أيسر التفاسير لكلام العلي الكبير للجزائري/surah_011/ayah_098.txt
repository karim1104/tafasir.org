شرح الكلمات : <br />
{  يقدم قومه } :  أي تقدمهم إلى النار فأوردهم النار . <br />
{  بئس الورد المورود } :  أي قبح وساء ورداً يورد النار . <br />
المعنى : <br />
قال تعالى {  يقدم قومه يوم القيامة } أي يتقدمهم إلى النار فيوردهم حياضها {  وبئس الورد المورود } أي نار جهنم . <br />

من الهداية : <br />
