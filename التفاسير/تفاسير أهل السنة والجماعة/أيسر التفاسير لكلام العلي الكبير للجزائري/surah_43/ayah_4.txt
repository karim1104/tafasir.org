شرح الكلمات : <br />
{  وإنه في أم الكتاب لدينا } :  أي في اللوح المحفوظ كتاب المقادير كلِّها عندنا . <br />
{  لعلي حكيم } :  أي لذو علو وشأن على الكتب قبله لا يوصل إلى مستواه في علوه ورفعته حكيم أي ذو حكمة بالغة عالية لا يرام مثلها . <br />
المعنى : <br />
وقوله {  وإنه } أي القرآن {  في أم الكتاب } أي اللوح المحفوظ لدينا عندنا {  لعلي } أي ذو علو وشأن على سائر الكتب قبله حكيم ذو حكمة بالغة عالية لا يرام مثلها . <br />
