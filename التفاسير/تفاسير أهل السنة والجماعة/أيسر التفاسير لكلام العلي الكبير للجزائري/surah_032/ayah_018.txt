شرح الكلمات : <br />
{  أفمن كان مؤمنا } :  أي مصدقا بالله ورسوله ولقاء ربّه . <br />
{  كمن كان فاسقا } :  أي كافراً لا يستوون . <br />
المعنى : <br />
قوله تعالى {  أفمن كان مؤمناً كمن كان فاسقاً } أي كافراً ينفي تعالى استواء الكافر مع المؤمن فلذا بعد الاستفهام الإِنكار أجاب بقوله تعالى :  {  لا يستوون } ثم بيّن تعالى جزاء الفريقين وبذلك تأكد بُعد ما بينهما فقال {  أما الذين آمنوا } . <br />
الهداية : <br />
من الهداية : <br />
- بيان خطأ من يسوي بين المؤمن والكافر والبار والفاجر والمطيع والفاسق . <br />
