شرح الكلمات : <br />
{  واضرب لهم مثلا } :  أي واجعل مثلا . <br />
{  أصحاب القرية } :  أي انطاكية عاصمة بلا يقال لها العواصم بأرض الروم . <br />
{  إذ جاءها المرسلون } :  أي رسل عيسى عليه السلام . <br />
المعنى : <br />
قوله تعالى :  {  واضرب لهم مثلا } أي واضرب أيها الرسول لقومك المصرين على الشرك والتكذيب لك ولما جئتهم به من الهدى ودين الحق {  مثلا أصحاب القرية } فإن حالهم في التكذيب والغُلوَّ في الكفر والعناد كحال هؤلاء .  إذ جاءها المرسلون وهم رسل عيسى عليه السلام إذ بعث برسولين ثم لما آذوهما بالضرب والسجن بعث بشمعون الصَّفي رأس الحواريين تعزيزاً لموقفهما كما قال تعالى {  فكذبوهما فعززنا بثالث } . <br />
