شرح الكلمات : <br />
{  قالوا طائركم معكم } :  أي شؤمكم معكم وهو كفركم بربكم . <br />
{  أئن ذكرتم } :  أي وعظتم وخوفتم تطيرتم وهذا توبيخ لهم . <br />
{  بل أنتم قوم مسرفون } :  أي متجاوزون للحد في الشرك والكفر . <br />
المعنى : <br />
{  طائركم معكم } أي شؤمكم في كفركم وتكذيبكم ،  ولذا حبس الله المطر عليكم .  ثم قالوا لهم موبخين لهم :  {  أئن ذكرتم } أي وعظتم وخُوِّفتم بالله لعلكم تتقون تطيَّرتُم .  بل أنتم أيها القوم {  مسرفون } أي متجاوزون الحد في الكفر والشرك والعدوان . <br />
