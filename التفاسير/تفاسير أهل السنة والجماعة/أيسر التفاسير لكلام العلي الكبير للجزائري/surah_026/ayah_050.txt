شرح الكلمات : <br />
{  لا ضير } :  أي لا ضرر علينا . <br />
{  منقلبون } :  أي راجعون بعد الموت وذلك يسر ولا يضر . <br />
المعنى : <br />
قوله تعالى {  قالوا لا ضير } هذا قول السحرة لفرعون بعد أن هددهم وتوعدهم {  قالوا لا ضير } أي لا ضرر علينا بتقطيعك أيدينا وأرجلنا وتصليبك إيانا {  إنا إلى ربنا منقلبون } أي راجعون إن كل الذي تفعله معنا إنك تعجل برجوعنا إلى ربنا وذاك أحب شيء إلينا . <br />
الهداية : <br />
- قوة الإيمان مصدر شجاعة خارقة للعادة بحيث يفرح المؤمن بالموت لأنه يوصله إلى ربه . <br />
