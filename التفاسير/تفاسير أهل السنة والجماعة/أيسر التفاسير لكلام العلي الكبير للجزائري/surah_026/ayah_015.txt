شرح الكلمات : <br />
{  قال كلا } :  أي قال الله تعالى له كلا أي لا يقتلونك . <br />
{  فاذهبا } :  أنت وهرون . <br />
المعنى : <br />
فأجابه الرب تعالى {  كلا } أي لن يقتلوك .  وأمرهما بالسير إلى فرعون فقال {  فاذهبا بآياتنا } وهي العصا واليد {  إنا معكم مستمعون } أي فبلغاه ما أمرتكما ببلاغه وإنا معكم مستمعون لما تقولان ولما يقال لكما . <br />
