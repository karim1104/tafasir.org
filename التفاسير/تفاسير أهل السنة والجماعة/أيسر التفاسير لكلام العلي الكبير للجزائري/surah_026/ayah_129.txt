شرح الكلمات : <br />
{  وتتخذون مصانع } :  أي حصوناً منيعة وقصوراً رفيعة . <br />
{  لعلكم تخلدون } :  أي كأنكم تأملون الخلود في الأرض وترجونه . <br />
المعنى : <br />
قوله {  وتتخذون مصانع } وهي مبان عالية كالحصون أو خزانات الماء أو الحصون {  لعلكم تخلدون } أي كيما تخلدون ،  وما أنتم بخالدين .  وإنما مقامكم فيها قليل . <br />
