شرح الكلمات : <br />
{  أوفوا الكيل } :  أي أتموه . <br />
{  ولا تكونوا من المخسرين } :  الذين ينقصون الكيل والوزن . <br />
المعنى : <br />
وأمرهم بترك أشهر معصية كانت شائعة بينهم وهي تطفيف الكيل والوزن فقال لهم {  أوفوا الكيل } أي أتموها ولا تنقصوها {  ولا تكونوا من المخسرين } أي الذين ينقصون الكيل والوزن . <br />
