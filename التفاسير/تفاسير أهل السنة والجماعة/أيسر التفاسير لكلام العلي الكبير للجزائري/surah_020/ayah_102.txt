شرح الكلمات : <br />
{  يوم ينفخ في الصور } :  أي النفخة الثانية وهي نفخة البعث ،  والصور هو القرن . <br />
{  زرقا } :  أي عيونهم زرق ووجوههم سود آية أنهم أصحاب الجحيم . <br />
المعنى : <br />
وقوله {  يوم ينفخ في الصور ونحشر المجرمين } أي المكذبين بالدين الحق العاملين بالشرك والمعاصي {  يومئذ } أي يوم ينفخ في الصور النفخة الثانية {  زرقا } أي الأعين مع اسوداد الوجوه . <br />
