شرح الكلمات : <br />
{  وعنت الوجوه للحي القيوم } :  أي ذلت وخضعت للرب الحي الذي لا يموت . <br />
{  من حمل ظلما } :  أي جاء يوم القيامة يحمل أوزار الظلم وهو الشرك . <br />
المعنى : <br />
وقوله :  {  وعنت الوجوه للحي القيوم } أي ذلت وخضعت كما يعنو بوجهه الأسير ،  والحي القيوم هو الله جل جلاله وقوله تعالى :  {  وقد خاب } أي خسر {  من حمل ظلماً } ألا وهو الشرك والعياذ بالله . <br />
الهداية<br />
من الهداية : <br />
- بيان خيبة المشركين وفوز الموحدين يوم القيامة . <br />
