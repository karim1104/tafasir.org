شرح الكلمات : <br />
{  ومن أعرض عن ذكري } :  أي عن القرآن فلم يؤمن به ولم يعمل بما فيه . <br />
{  معيشة ضنكا } :  أي ضيقة تضيق بها نفسه ولم يسعد بها ولو كانت واسعة . <br />
{  أعمى } :  أي أعمى البصر لا يبصر . <br />
المعنى : <br />
{  ومن أعرض عن ذكري } أي فلم يؤمن به ولم يعمل بما فيه {  فإن له } أي جزاءً منا له {  معيشة ضنكا } أي ضيقة تضيق بها نفسه فلم يشعر بالغبطة والسعادة وإن اتسع رزقه كما يضيق عليه قبره ويشقى فيه طيلة حياة البرزخ ،  ويحشر يوم القيامة أعمى لا حجة له ولا بصر يبصر به . <br />
