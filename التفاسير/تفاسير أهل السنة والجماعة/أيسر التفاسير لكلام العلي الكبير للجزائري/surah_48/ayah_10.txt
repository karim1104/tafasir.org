شرح الكلمات : <br />
{  إن الذين يبايعونك } :  أي بيعة الرضوان بالحديبية . <br />
{  إنما يبايعون الله } :  لأن طاعة الرسول طاعة لله تعالى . <br />
{  يد الله فوق أيديهم } :  أي لأنهم كانوا يبايعون الله إذ هو الذي يجاهدون من أجله ويتلقون الجزاء من عنده . <br />
{  فمن نكث } :  أي نقض عهده فلم يقاتل مع الرسول والمؤمنين . <br />
{  فإِنما ينكث على نفسه } :  أي وبال عهده عائد عليه إذ هو الذي يجزي به . <br />
{  فسيؤتيه أجرا عظيما } :  أي الجنة إذ هي الأجر العظيم الذي لا أعظم منه إلا رضوان الله عز وجل . <br />
المعنى : <br />
وقوله تعالى {  إن الذين يبايعونك إنما يبايعون الله يد الله فوق أيديهم } يخبر تعالى رسوله بأن الذين يبايعونه على قتال أهل مكة وأن لا يفروا عند اللقاء {  إنّما يبايعون الله } إذ هو تعالى الذي أمرهم بالجهاد وواعدهم الأجر فالعقد وإن كانت صورته مع رسول الله فإنه في الحقيقة مع الله عز وجل ،  ولذا قال {  يد الله فوق أيديهم } وقوله تعالى {  فمن نكث } أي نقض عهده فلم يقاتل {  فإنما ينكث على نفسه } {  ومن أوفى } بمعنى وفىّ {  بما عاهد عليه الله } من نصرة الرسول والقتال تحت رايته حتى النصر {  فسيؤتيه } الله {  أجراً عظيماً } الذي هو الجنة دار السلام . <br />
