شرح الكلمات : <br />
{  لتؤمنوا بالله ورسوله } :  أي هذا علة للإِرسال . <br />
{  وتعزروه وتوقروه } :  أي ينصروه ويعظموه وهذا لله وللرسول . <br />
{  وتسبحوه بكرة وأصيلا } :  أي الله تعالى بالصلاة والذكر والتسبيح . <br />
المعنى : <br />
وقوله تعالى {  لتؤمنوا بالله ورسوله } أي أرسلناه كذلك لتؤمنوا بالله ورسوله {  وتعزروه } بمعنى تنصروه {  وتوقروه } بمعنى تجلوه وتعظموه وهذه واجبة لله ولرسوله الإِيمان والتعزير والتوقير ،  وأما التسبيح والتقديس .  فهو لله تعالى وحده ويكون بكلمة سبحان الله وبالصلاة وبالذكر لا إله إلا الله ،  وبدعاء الله وحده .  وقوله {  بكرة وأصيلا } أي تسبحون الله {  بكرة } أي صباحاً {  وأصيلا } أي عشية . <br />
الهداية : <br />
من الهداية : <br />
- وجوب الإِيمان بالله ورسوله ووجوب نصرة الرسول وتعظيمه صلى الله عليه وسلم . <br />
- وجوب تسبيح الله وهو تنزيهه عن كل ما لا يليق بجلاله وكماله مع الصلاة ليلا ونهارا . <br />
