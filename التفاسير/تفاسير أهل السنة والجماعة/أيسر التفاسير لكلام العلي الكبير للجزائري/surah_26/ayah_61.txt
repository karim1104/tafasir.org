شرح الكلمات : <br />
{  فلما تراءى الجمعان } :  أي رأى بعضهما بعضاً لتقاربهما والجمعان جمع بني إسرائيل وجمع فرعون . <br />
{  إنا لمدركون } :  أي قال أصحاب موسى من بني إسرائيل إنا لمدركون أي سيلحقنا فرعون وجنده . <br />
المعنى : <br />
هذا آخر قصة موسى عليه السلام مع فرعون قال تعالى في بيان نهاية الظالمين وفوز المؤمنين {  فلما تراءى الجمعان } جمع موسى وجمع فرعون وتقاربا بحيث رأى بعضها بعضا {  قال أصحاب موسى } أي بنو إسرائيل {  إنا لمدركون } أي خافوا لما رأوا جيوش فرعون تتقدم نحوهم صاحوا {  إنا لمدركون } . <br />
الهداية<br />
من الهداية : <br />
- ظهور آثار الاستعباد في بني إسرائيل متجلية في خوفهم 0مع مشاهدة الآيات .
