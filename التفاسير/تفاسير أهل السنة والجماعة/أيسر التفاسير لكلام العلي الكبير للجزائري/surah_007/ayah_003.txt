شرح الكلمات : <br />
{  أولياء } :  رؤساؤهم في الشرك . <br />
{  وما تذكرون } :  أي تتعظون فترجعون إلى الحق . <br />
المعنى : <br />
{  اتبعوا ما أنزل إليكم من ربكم } من الهدى والنور ،  {  ولا تتبعوا من دونه } أي من غيره {  أولياء } لا يأمرونكم إلا بالشرك والشر والفساد ،  وهم رؤساء الضلال في قريش {  قليلاً ما تذكرون } أي تتعظون فترجعون إلى الحق الذي جانبتموه . <br />
