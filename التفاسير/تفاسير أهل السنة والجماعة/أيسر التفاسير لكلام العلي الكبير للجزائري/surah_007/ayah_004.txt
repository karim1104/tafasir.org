شرح الكلمات : <br />
{  وكم من قرية } :  أي كثيراً من القرى . <br />
{  بأسنا بياتا } :  عذابنا ليلاً وهم نائمون . <br />
{  أو هم قائلون } :  أي نائمون بالقيلولة وهم مستريحون . <br />
المعنى : <br />
{  وكم من قرية } أي وكثيرا من القرى أهلكنا أهلها لما جانبوا الحق ولازموا الباطل {  فجاءها بأسنا } أي عذابنا الشديد .  {  بياتاً أو هم قائلون } أي ليلاً أو نهاراً . <br />
