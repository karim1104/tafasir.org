شرح الكلمات : <br />
{  فكذبوه } :  أي فيما أخبرهم به من شأن الناقة . <br />
{  فعقروها } :  أي قتلوها ليخلص لهم ماء شربها في يومها . <br />
{  فدمدم } :  أي أطبق عليهم العذاب فأهلكهم . <br />
{  بذنبهم } :  أي بسبب ذنوبهم التي هي الشرك والتكذيب وقتل الناقة . <br />
{  فسواها } :  أي سوى الدمدم عليهم فلم يفلت منهم أحد . <br />

المعنى : <br />
{  فكذبوه } في ذلك وفي غيره من رسالته ودعوته إلى عبادة الله وحده {  فعقروها } أي فذبحوها {  فدمدم عليهم ربهم } اي أطبق عليهم العذاب وعمهم به فلم ينج منهم أحد وذلك بذنبهم لا بظلم منه تعالى ،  {  فسواها } في النقمة والعذاب . <br />
