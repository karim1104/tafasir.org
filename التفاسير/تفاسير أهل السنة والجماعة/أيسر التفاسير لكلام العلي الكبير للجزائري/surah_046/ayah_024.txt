شرح الكلمات : <br />
{  فلما رأوه عارضا } :  أي رأوا العذاب سحابا يعرض في الأفق . <br />
{  مستقبل أوديتهم } :  أي متجها نحو أوديتهم التي فيها مزارعهم . <br />
{  قالوا هذا عارض ممطرنا } :  قالوا مشيرين إلى السَّحاب هذا عارض ممطرنا . <br />
{  بل هو ما استعجلتم به } :  أي ليس هو بالعارض الممطر بل العذاب الذي استعجلتموه . <br />
المعنى : <br />
قوله تعالى {  فلما رأوه عارضا مستقبل أوديتهم } أي فلما رأى قوم هود العذاب متجها نحو أوديتهم التي بها مزارعهم ومنازلهم {  قالوا هذا عارض ممطرنا } أي هذا سحاب يعرض في السماء ذاهباً صوب وادينا ليسقينا ،  وهو معنى قوله {  هذا عارض ممطرنا } أي ممطر أراضينا المصابة بالجفاف الشديد . <br />
قال تعالى {  بل هو ما استعجلتم به } أي ليس بالسحاب الممطر بل هو العذاب الذي طالبتم به لجهلكم وخفة أحلامكم .  وبيّنه بقوله {  ريح فيها عذاب أليم } أي تحمل في ثناياها العذاب الموجع ،  تدمر كل شيء تمر به فتهلكه {  بأمر ربها } . <br />
