شرح الكلمات : <br />
{  إن هي إلا حياتنا الدنيا } :  أي ما هي إلا حياتنا الدنيا وليس وراءها حياة أخرى . <br />
المعنى : <br />
إنها ما {  هي إلا حياتنا الدنيا } أي {  نموت ونحيا } جيل يموت وجيل يحيا {  وما نحن بمبعوثين } . <br />

من الهداية : <br />
