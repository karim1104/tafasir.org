شرح الكلمات : <br />
{  الملأ } :  أي أعيان البلاد وكبراء القوم . <br />
{  ما هذا إلا بشر مثلكم } :  أي ما نوح إلا بشر مثلكم فكيف تطيعونه بقبول ما يدعوكم إليه . <br />
المعنى : <br />
فأجابه قومه المشركون بما أخبر تعالى به عنهم في قوله :  {  فقال الملأ الذين كفروا من قومه } أي فرد عليه قوله أشرافهم وأهل الحل والعقد فيهم من أغنياء وأعيان ممن كفروا من قومه {  ما هذا } أي نوح {  إلا بشر مثلكم يريد أن يتفضل عليكم } أي يسود ويشرف فادعى أنه رسول الله إليكم {  ولو شاء الله } أي أن لا نعبد معه سواه {  لأنزل ملائكة } تخبرنا بذلك {  ما سمعنا بهذا } أي بالذي جاء به نوح ودعا إليه من ترك عبادة آلهتنا {  في آبائنا الأولين } أي لم يقل به أحد من أجدادنا السابقين . <br />
