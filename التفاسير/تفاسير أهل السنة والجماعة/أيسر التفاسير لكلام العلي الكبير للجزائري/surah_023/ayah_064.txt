شرح الكلمات : <br />
{  إذا هم يجأرون } :  أي يصرخون بأعلى أصواتهم ضاجينّ مستغيثين ممَّا حلَّ تعالى بهم . <br />
المعنى : <br />
وقوله تعالى :  {  حتى إذا أخذنا مترفيهم بالعذاب إذا هم يجأرون } أي استمرت الأعمال الشركية الإِجرامية حتى أخذ الله تعالى مترفيهم في بدر بعذاب القتل والأسر {  إذا هم يجأرون } يضجون بالصراخ مستغيثين . <br />
