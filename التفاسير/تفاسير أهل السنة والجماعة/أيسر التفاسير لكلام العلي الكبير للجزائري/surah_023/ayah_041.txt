شرح الكلمات : <br />
{  فأخذتهم الصيحة } :  أي صيحة العذاب والهلاك . <br />
{  فجعلناهم غثاء } :  كغثاء السيل وهو ما يجمعه الوادي من العيدان والنبات اليابس .  {  فبعداً } :  أي هلاكاً لهم . <br />
المعنى : <br />
ولم يمض إلا قليل زمن حتى أخذتهم الصيحة صيحة الهلاك ضمن ريح صرصر في أيام نحسات فإذا هم غثاء كغثاء السبيل لا حياة فيهم ولا فائدة ترجى منهم {  فبعداً للقوم الظالمين } أي هلاكاً للظالمين بالشرك والتكذيب والمعاصي<br />
