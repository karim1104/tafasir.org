شرح الكلمات : <br />
{  قل أرأيتم } :  أي أخبروني . <br />
{  ومن معي } :  أي من المؤمنين . <br />
{  أو رحمنا } :  أي لم يهلكنا . <br />
{  فمن يجير الكافرين } :  أي فمن يحفظ ويقي الكافرين العذاب . <br />
المعنى : <br />
ما زال السياق الكريم في مطلب هداية كفار قريش فقال تعالى لرسوله قل لهؤلاء المشركين الذين تمنوا موتك وقالوا نتربص به ريب المنون قل لهم {  أرأيتم } أي أخبروني {  إن أهلكني الله ومن معي } من المؤمنين ،  {  أو رحمنا } فلم يهلكنا بعذاب {  فمن يجير الكافرين من عذاب أليم ؟  } والجواب :  لا أحد إذاً فماذا تنتفعون بهلاكنا . <br />

من الهداية : <br />
