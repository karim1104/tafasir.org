{  فصدهم عن السبيل } :  أي طريق الحق والهدى . <br />
المعنى : <br />
وقوله {  وجدتها وقومها يسجدون للشمس من دون الله } أخبر أولاً عن أحوالهم الدنيوية وأخبر ثانياً عن أحوالهم الدينية وقوله {  وزين لهم الشيطان أعمالهم } أي الباطلة الشركية {  فصدهم } بذلك {  عن السبيل } أي سبيل الهدى والحق فهم لذلك لا يهتدون لأن يسجدوا لله . <br />
الهداية<br />
من الهداية : <br />
