شرح الكلمات : <br />
{  وقع القول عليهم } :  أي حق عليهم العذاب . <br />
{  بما ظلموا } :  أي بسبب الظلم الذي هو شركهم بالله تعالى . <br />
{  فهم لا ينطقون } :  أي لا حجة لهم . <br />
المعنى : <br />
قال تعالى {  ووقع القول عليهم } أي وجب العذاب {  بِما ظلموا } أي بسبب ظلمهم {  فهم لا ينطقون } .  أي بمعجزهم عن الدفاع عن أنفسهم لأنهم ظَلَمَه مشركون . <br />
