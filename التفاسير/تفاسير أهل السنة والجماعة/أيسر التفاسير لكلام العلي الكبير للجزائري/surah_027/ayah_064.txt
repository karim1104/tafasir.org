شرح الكلمات : <br />
{  أمن يبدأ الخلق ثم يعيده } :  أي يبدؤه في الأرحام ،  ثم يعيده يوم القيامة . <br />
{  هاتوا برهانكم إن كنتم صادقين } :  أي حجتكم إن كنتم صادقين أن مع الله إلهاً آخر فعل ما ذكر . <br />
المعنى : <br />
قوله تعالى :  {  أمن يبدأ الخلق } أي نطفاً في الأرحام ،  ثم بعد حياته يميته ،  ثم يعيده وهو معنى {  ثم يعيده } . <br />
{  ومن يرزقكم من السماء } بالمطر {  والأرض } بالنبات .  والجواب :  الله إذاً {  أ إله مع الله } والجواب :  لا ،  لا وإن قلتم هناك آلهة مع الله {  قل هاتوا برهانكم } أي حججكم {  إن كنتم صادقين } أن غير الله يفعل شيئاً مما ذُكر في هذا السياق الكريم . <br />
