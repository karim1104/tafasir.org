شرح الكلمات : <br />
{  إرجع إليهم } :  أي بما أتيت به من الهدية . <br />
{  بجنود لا قبل لهم بها } :  أي لا طاقة لهم بقتالها . <br />
{  ولنخرجنهم منها } :  أي من مدينتهم سبأ المسماة باسم رجل يقال له سبأ . <br />
{  أذلة وهم صاغرون } :  أي إن لم يأتوني مسلمين أي منقادين خاضعين . <br />
المعنى : <br />
وقال لرسول الملكة {  ارجع إليهم } أي بما أتيت به من الهدية ،  وعلمهم أنهم إن لم يأتوا إلي مسلمين {  فلنأتينهم بجنود لا قبل لهم بها } أي لا قدرة لهم على قتالهم ،  {  ولنخرجنهم منها } أي من مدينتهم سبأ {  أذلة وهم صاغرون } أي خاضعون منقادون . <br />
الهداية<br />
من الهداية : <br />
- استعمال أسلوب الإِرهاب والتخويف مع القدرة على إنفاذه مع العدو أليق . <br />
