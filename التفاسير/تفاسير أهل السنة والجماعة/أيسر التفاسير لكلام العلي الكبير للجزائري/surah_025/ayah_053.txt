شرح الكلمات : <br />
{  مرج البحرين } :  أي خلط بينهما وفي نفس الوقت منع الماء الملح أن يفسد الماء العذب . <br />
{  وجعل بينهما برزخاً } :  أي حاجزاً بين الملح منهما والعذب . <br />
{  وحجراً محجوراً } :  أي وجعل بينهما سداً مانعاً فلا يحلو الملح ،  ولا يملح العذب . <br />
المعنى : <br />
{  وهو الذي مرج البحرين } الملح والعذب أي أرسلهما مع بعضهما بعضاً {  هذا عذب فرات } أي حلو {  سائغ شرابه ،  وهذا ملح أجاج } أي لا يشرب {  وجعل بينهما برزخاً وحجراً محجوراً } أي ساتراً مانعا من اختلاط العذب بالملح مع وجودهما في مكان واحد ،  فلا يبغي هذا على هذا بأن يعذب الملح أو يملح العذب . <br />
الهداية : <br />
من الهداية : <br />
- مظاهر العلم والقدرة الإلهية في عدم اختلاط البحرين مع وجودهما في مكان واحد . <br />
