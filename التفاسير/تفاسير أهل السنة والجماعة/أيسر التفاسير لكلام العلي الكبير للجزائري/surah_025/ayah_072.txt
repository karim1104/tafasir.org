شرح الكلمات : <br />
{  لا يشهدون الزور } :  أي لا يحضرون مجالسة ولا يشهدون بالكذب والباطل . <br />
{  وإذا مروا باللغو } :  أي بالكلام السيئ القبيح وكل مالا خير فيه . <br />
{  مروا كراماً } :  أي معرضين عنه مكرمين أنفسهم عن سماعة أو المشاركة فيه . <br />
المعنى : <br />
/د71<br />
والسادسة :  في قوله تعالى {  والذين لا يشهدون الزور } الزور هو الباطل والكذب وعباد الرحمن لا يحضرون مجالسة ولا يقولونه ولا يشهدونه ولا ينطقون به {  وإذا أمروا باللغو } وهو كل عمل وقول لا خير فيه {  مروا كراماً } أي مكرمين أنفسهم من التلوث به ،  بالوقوع فيه . <br />
