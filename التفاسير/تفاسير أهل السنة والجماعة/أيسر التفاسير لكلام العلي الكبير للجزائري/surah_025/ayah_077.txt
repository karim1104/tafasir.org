شرح الكلمات : <br />
{  ما يعبأ بكم ربي } :  أي ما يكترث ولا يعتد بكم ولا يبالي . <br />
{  لولا دعاؤكم } :  إياه ،  ودعاؤه إياكم لعبادته بذكره وشكره . <br />
{  فسوف يكون لزاماً } :  أي العذاب لزاماً أي لازماً لكم في بدر ويوم القيامة . <br />
المعنى : <br />
وقوله تعالى :  {  قل ما يعبأ بكم ربي لولا دعاؤكم } أي قل يا رسولنا لأولئك المشركين المنكرين للرحمن {  ما يعبأ بكم ربي } أي ما يكترث لكم أو يبالي بكم {  لولا دعاؤكم } إياه أي عبادة من يعبده منكم إذ الدعاء هو العبادة ما أبالي بكم ولا أكترث لكم .  أما وقد كذبتم بي وبرسولى فلم تعبدوني ولم توحدوني وإذاً {  فسوف يكون } العذاب {  لزاماً } وقد أذقتموه يوم بدر ،  وسوف يلازمهم في قبورهم إلى نشورهم ،  وسوف يلاحقهم حتى مستقرهم في جهنم . <br />
