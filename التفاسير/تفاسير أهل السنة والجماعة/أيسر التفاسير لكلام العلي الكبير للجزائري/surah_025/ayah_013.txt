شرح الكلمات : <br />
{  مقرنين } :  أي مقرونة أيديهم مع أعناقهم في الأصفاد . <br />
{  دعوا هنالك ثبوراً } :  أي نادوا يا ثبورنا أي يا هلاكنا إذ الثبور الهلاك . <br />
المعنى : <br />
{  وإذا ألقوا منها مكاناً ضيقاً مقرنين } مشدودة أيديهم إلى أعناقهم بالأصفاد {  دَعَوْا هنالك } أي نادوا بأعلى أصواتهم يا ثبوراه أي يا هلاكاه أحضر فهذا وقت حضورك :  فيقال لهم :  خزياً وتبكيتا وتحسيراً :  {  لا تدعوا اليوم ثبوراً واحداً وادعوا ثبوراً كثيراً } . <br />
