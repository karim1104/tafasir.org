شرح الكلمات : <br />
{  وإذ قال موسى } :  أي اذكر إذ قال موسى . <br />
{  يسومونكم } :  يذيقونكم . <br />
{  ويستحون نساءكم } :  أي يستبقونهنَّ . <br />
{  بلاء من ربكم عظيم } :  أي ابتلاء واختبار ،  ويكون الخير والشر . <br />
المعنى : <br />
{  وإذ قال موسى لقومه } أي اذكر يا رسولنا إذ قال موسى لقومه من بني إسرائيل {  اذكروا نعمة الله عليكم } أي لتشكروها بتوحيده وطاعته ،  فإن من ذكر شكر وبين لهم نوع النعمة وهي إنجاؤهم من فرعون وملائه إذ كانوا يعذبونهم بالاضطهاد والاستعباد ،  فقال :  {  يسومونكم سوء العذاب } أي يذيقونكم سوء العذاب وهو أسوأه وأشده ،  {  ويذبحون أبناءكم } أي الأطفال المولودين ،  لان الكهنة أو رجال السياسة قالوا لفرعون :  لا يبعد أن يسقط عرشك وتزول دولتك على أيدي رجل من بني إسرائيل فأمر بقتل المواليد فور ولادتهم فيقتلون الذكور ويستبقون الإناث للخدمة ولعدم الخوف منهن وهو معنى قوله :  {  ويستحيون نساءكم } وقوله تعالى :  {  وفي ذلكم بلاء من ربكم عظيم } فهو بالنظر إلى كونه عذاباً بلاء الشر ،  وفي كونه نجاة منه ،  بلاء الخير . <br />
