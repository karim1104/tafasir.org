شرح الكلمات : <br />
{  يوم يسمعون الصيحة بالحق } :  أي نفخة إسرافيل الثانية وهي نفخة البعث يعلمون عاقبة تكذيبهم<br />
{  ذلك يوم الخروج } :  أي من القبور . <br />
{  يوم تشقق الأرض عنهم سراعا } :  أي يخرجون من قبورهم مسرعين بعد تشقق القبور عنهم . <br />
{  ذلك حشر علينا يسير } :  أي ذلك حشر للناس وجمع لهم في موقف الحساب يسير سهل علينا . <br />
{  نحن أعلم بما يقولون } :  أي من الكفر والباطل فلا تيأس لذلك سننتقم منهم . <br />
{  وما أنت عليهم بجبار } :  أي بحيث تجبرهم على الإِيمان والتقوى . <br />
{  فذكر بالقرآن } :  أي عظ مرغبا مرهبا بالقرآن فاقرأه على المؤمنين فهم الذين يخافون وعيد الله تعالى ويطمعون في وعده . <br />
المعنى : <br />
وقوله {  يوم يسمعون الصيحة بالحق } وهي نفخة إسرافيل الثانية نفخة البعث {  ذلك يوم الخروج } من القبور ويوم يرى المكذبون عاقبة تكذيبهم . <br />
