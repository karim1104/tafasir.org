شرح الكلمات : <br />
{  جاءتهم رسلهم بالبينات } :  أي بالحجج والأدلة الواضحة . <br />
{  وبالزبر وبالكتاب المنير } :  أي وبالصحف كصحف إبراهيم وبالكتاب المنير كالتوراة والإِنجيل . <br />
المعنى : <br />
{  وإن يكذبوك } فلم يكونوا أول من كذب فقد كذب الذين من قبلهم {  جاءتهم رسلهم بالبينات والزبر والكتاب المنير } أي جاءتهم رسلهم بالحجج القواطع والبراهين السواطع ،  والمعجزات الخوارق ،  وبالصحف والكتب المنيرة لسبيل الهداية وطريق النجاة والفلاح . <br />
