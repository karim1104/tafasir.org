شرح الكلمات : <br />
{  بصائر من ربكم } :  البصائر جمع بصيرة :  والمراد هنا الآيات المعرفة بالحق المثبتة له بطريق الحجج العقلية فهي في قوة العين المبصرة لصاحبها . <br />
{  حفيظ } :  وكيل مسئول . <br />
المعنى : <br />
ما زال السياق في طلب هداية المشركين وبيان الطريق لهم ففي هذه الآية يقول {  قد جاءكم } أي أيها الناس {  بصائر من ربكم } وهي آيات القرآن الموضحة لطريق النجاة {  فمن أبصر } بها وهي كالعين المبصرة {  فلنفسه } إبصاره إذ هو الذي ينجو ويسعد {  ومن عمي } فلم يبصر فعلى نفسه عماه إذ هي التي تهلك وتشقى وقل لهم يا رسولنا {  وما أنا عليكم بحفيظ } أي بوكيل مسئول عن هدايتكم . <br />

من الهداية : <br />
