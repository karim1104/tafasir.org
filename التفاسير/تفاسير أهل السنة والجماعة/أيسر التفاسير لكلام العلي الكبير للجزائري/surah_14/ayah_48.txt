شرح الكلمات : <br />
{  يوم تبدل الأرض } :  أي اذكر يا رسولنا للظالمين يوم تبدل الأرض . <br />
{  وبرزوا لله } :  أي خرجوا من القبور لله ليحاسبهم ويجزيهم . <br />
المعنى : <br />
واذكر {  يوم تبدل الأرض غير الأرض والسموات } كذلك {  وبرزوا } أي ظهروا بعد خروجهم من قبورهم في طريقهم إلى المحشر إجابة منهم لدعوة الداعي وقد برزوا {  لله والواحد القهار } . <br />
