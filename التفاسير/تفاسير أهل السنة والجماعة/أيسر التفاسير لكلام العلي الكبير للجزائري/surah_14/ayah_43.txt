{  مهطعين مقنعي رؤوسهم } :  أي مسرعين إلى الداعي الذي دعاهم إلى الحشر ،  رافعي رؤوسهم . <br />

{  مهطعين } أي مسرعين {  مقنعي رؤوسهم } أي حال كونهم مهطعين مقنعي رؤوسهم أي رافعين رؤوسهم مسرعين للداعي الذي دعاهم إلى المحشر ،  قال تعالى : {  واستمع يوم يناد المنادي من مكان قريب } {  لا يرتد إليه م طرفهم } أي لا تغمض أعينهم من الخوف {  وأفئدتهم } أي قلوبهم {  هواء } أي فارغة من الوعي والإدراك لما أصابها من الفزع والخوف . <br />
