شرح الكلمات : <br />
{  كلا } :  أي ليس الأمر كما يزعم ويظن . <br />
{  لينبذن } :  أي ليطرحن في الحطمة . <br />
{  في الحطمة } :  أي النار التي تحطم كل ما يلقى فيها . <br />
المعنى : <br />
وقوله تعالى {  كلا } لا يخلده ماله ؛  بل وعزتنا وجلالنا {  لينبذن } أي يطرحن {  في الحطمة } . <br />
