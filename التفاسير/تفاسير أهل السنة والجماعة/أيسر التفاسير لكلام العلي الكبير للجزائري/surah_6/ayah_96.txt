شرح الكلمات : <br />
{  فالق الإِصباح } :  الإِصباح :  بمعنى الصبح وفلقه :  شقه ليتفجر منه النور والضياء . <br />
{  سكنا } :  يسكن فيه الناس ويخلدون للراحة . <br />
{  حسباناً } :  أي حسابا بهما تعرف الأوقات الأيام والليالي والشهور والسنون . <br />
{  تقدير العزيز العليم } :  إيجاد وتنظيم العزيز الغالب على أمره العليم بأحوال وأفعال عباده . <br />
المعنى : <br />
ويقول :  {  فالق الإِصباح } أي هو الله الذي يفلق ظلام الليل فيخرج منه ضياء النهار {  وجعل الليل سكناً } :  أي ظرف سكن وسكون وراحة تسكن فيه الأحياء من تعب النهار والعمل فيه ليستريحوا ،  وقوله :  {  والشمس والقمر حسباناً } أي وجعل الشمس والقمر يدوران في فلكيهما بحساب تقدير لا يقدر عليه إلا هو ،  وبذلك يعرف الناس الأوقات وما يتوقف عليها من عبادات وأعمال وآجال وحقوق ثم يشير إلى فعله ذلك فيقول :  {  ذلك تقدير العزيز } الغالب على أمره {  العليم } بسائر خلقه وأحوالهم وحاجاتهم وقد فعل ذلك لأجلهم فكيف إذاً لا يستحق عبادتهم وتأليههم ؟  عجباً لحال بني آدم ما أضلهم ؟  ! <br />
