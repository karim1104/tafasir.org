{  سفهاً بغير بعلم } :  حمقاً وطيشاً وعدم رشد وذلك لجهلهم . <br />
المعنى : <br />
أما الخامسة ( 140 ) فقد أخبر تعالى بخسران أولئك المشرعين وضلالهم وعدم هدايتهم بقوله {  قد خسر الذين قتلوا أولادهم سفهاً } أي جهلاً {  بغير علم ،  وحرموا ما رزقهم الله } مما سبق ذكره {  افتراءً على الله } كذباً {  قد ضلوا وما كانوا مهتدين } . <br />
