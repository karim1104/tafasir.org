شرح الكلمات : <br />
{  رسلا إلى قومهم } :  أي كنوح وهو وصالح وإبراهيم ولوط وشعيب عليهم السلام . <br />
{  فجاءوهم بالبينات } :  أي بالحجج والمعجزات . <br />
{  الذين أجرموا } :  أي أفسدوا نفوسهم فخبثوها بآثار الشرك والمعاصي . <br />
{  حقا علينا نصر المؤمنين } :  أي ونصر المؤمنين أحققناه حقاً وأوجبناه علينا فهو كائن لا محالة . <br />
المعنى : <br />
وقوله :  {  ولقد أرسلنا من قبلك } يا رسولنا {  رسلاً إلى قومهم } كنوح وهود وصالح وإبراهيم ولوط وشعيب عليهم السلام فجاءوا أقوامهم بالبيّنات والحجج النيرات كما جئت أنت وقومك فكذبت تلك الأقوام رسلهم {  فانتقمنا من الذين أجرموا } فأهلكناهم ،  ونجينا الذين آمنوا {  وكان حقا علينا نصر المؤمنين } ألا فلتعتبر قريش بهذا وإلا فستحلُّ بها نقمة الله فيهلك الله المجرمين وينجي رسوله والمؤمنين كما هي سنته في الأولين والحمد لله رب العالمين . <br />
الهداية : <br />
من الهداية : <br />
- بيان أن الله منتقم من المجرمين وإن طال الزمن ،  وناصر المؤمنين كذلك . <br />
