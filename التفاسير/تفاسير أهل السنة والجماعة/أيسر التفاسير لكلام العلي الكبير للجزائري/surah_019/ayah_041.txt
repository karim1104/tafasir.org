{  اذكر في الكتاب } :  أي في القرآن . <br />
{  إنه كان صديقاً } :  أي كثير الصدق بالغ الحد الأعلى فيه . <br />
المعنى : <br />
هذه بداية قصة إبراهيم الخليل عليه السلام مع والده آزر عليه لعائن الرحمن قال تعالى لرسوله محمد صلى الله عليه وسلم {  واذكر } يا نبينا {  في الكتاب } أي القرآن الكريم {  إبراهيم } خليلنا {  إنه كان صديقا } أي صادقاً في أقواله وأعماله بالغاً مستوى عظيماً في الصدق {  نبيا } من أنبيائنا فهو جدير بالذكر في القرآن ليكون قدرة صالحة للمؤمنين . <br />
