شرح الكلمات : <br />
{  ولم يمسني بشر } :  أي لم أتزوج . <br />
{  ولم أك بغياً } :  أي زانية . <br />
المعنى : <br />
فأجابت بما أخبر تعالى عنها في قوله :  {  أنى يكون لي غلام } أي من أي وجه يأتيني الولد ،  {  ولم يمسسني بشر } أي وأنا لم أتزوج ،  {  ولم أك بغياً } أي ولم أك زانية . <br />
