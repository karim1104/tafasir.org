شرح الكلمات : <br />
{  فناداها من تحتها } :  أي عيسى عليه السلام بعدما وضعته . <br />
{  تحتك سريا } :  أي نهراً يُقال له سري . <br />
المعنى : <br />
و هنا {  فناداها } عيسى عليه السلام {  من تحتها ألا تحزني } يحملها على الصبر و العزاء و قوله تعالى :  {  قد جعل ربك تحتك سريا } أي نهر ماء يقال له سري . <br />
