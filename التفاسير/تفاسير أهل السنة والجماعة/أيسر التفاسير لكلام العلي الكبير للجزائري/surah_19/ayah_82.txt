شرح الكلمات : <br />
{  سيكفرون بعبادتهم } :  أي يوم القيامة أنهم كانوا يعبدونهم . <br />
{  ضداً } :  أي أعداء لهم وأعوانا عليهم . <br />
المعنى : <br />
{  كلا } أي ليس الأمر كما يظنون {  سيكفرون بعبادتهم } وذلك يوم القيامة حيث ينكرون أنهم أمروهم بعبادتهم ،  {  ويكونون عليهم ضداً } أي خصوماً ،  ومن ذلك قولهم .  {  وقال شركائهم ما كنتم إيانا تعبدون } وقولهم :  {  بل كانوا يعبدون الجن وأكثرهم بهم مؤمنون } . <br />
