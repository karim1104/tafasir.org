شرح الكلمات : <br />
{  فأجَاءها المخاض } :  أي ألجأها الطلق و اضطرها وجع الولادة . <br />
{  إلى جذع النخلة } :  لتعتمد عليها و هي تعاني من آلام الولادة . <br />
{  نسياً منسياً } :  أي شيئا متروكا لا يعرف و لا يذكر . <br />
المعنى : <br />
{  فأجاءها المخاض } أي ألجأها وجع النفاس {  إلى جذع النخلة } لتعتمد عليه و هي تعاني من آلام الطلق و أوجاعه ،  و لما وضعته قالت متأسفة متحسرة ما أخبر تعالى به :  {  قالت يا ليتني مت قبل هذا } أي الوقت الذي أصبحت فيه أم ولد ،  {  و كنت نسيا منسيا } أي شيئاً متروكا لا يذكر و لا يعرف . <br />
