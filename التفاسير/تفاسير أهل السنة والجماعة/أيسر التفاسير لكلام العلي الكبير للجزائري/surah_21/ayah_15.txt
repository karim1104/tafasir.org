شرح الكلمات : <br />
{  تلك دعواهم } :  أي دعوتهم التي يرددونها وهي :  {  يا ويلنا إنا كنا ظالمين } . <br />
{  حصيداً خامدين } :  أي لم يبق منهم قائدهم فهم كالزرع المحصود خامدين لا حراك لهم كالنار إذا أخمدت . <br />
المعنى : <br />
قال تعالى : <br />
{  فما زالت تلك دعواهم } أي ما زال قولهم {  يا ويلنا إنا كنا ظالمين } تلك دعوتهم التي يرددونها {  حتى جعلناهم حصيدا خامدين } أي مجتثين من أصولهم ساقطين في الأرض خامدين لا حراك لهم كالنار إذا أخمدت فلم يبق لها لهيب . <br />
