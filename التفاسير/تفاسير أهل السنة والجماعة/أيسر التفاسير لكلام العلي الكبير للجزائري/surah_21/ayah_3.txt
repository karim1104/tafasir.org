شرح الكلمات : <br />
{  لاهية قلوبهم } :  مشغولة عند بما لا يغني من الباطل والشر والفساد . <br />
{  وأسروا النجوى } :  أي أخفوا مناجاتهم بينهم . <br />
المعنى : <br />
وقوله تعالى :  {  لاهية قلوبهم } أي مشغولة عنه منصرفة عما تحمل الآيات المحدثة النزول من هدى ونور ،  {  وأسروا النجوى الذين ظلموا } وهم المشركون قالوا في تناجيهم بينهم :  {  هل هذا إلا بشر مثلكم } أي ما محمد إلا إنسان مثلكم فكيف تؤمنون به وتتابعونه على ما جاء به ،  إنه ما هو إلا ساحر {  أفتأتون السحر وأنتم تبصرون } ما لكم أين ذهبت عقولكم ؟ <br />
