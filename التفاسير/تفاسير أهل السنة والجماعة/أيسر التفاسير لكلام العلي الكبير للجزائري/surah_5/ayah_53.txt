{  جهد أيمانهم } :  أقصاها وأبلغها . <br />
{  حبطت أعمالهم } :  بطلت وفسدت فلم ينتفعوا منها بشيء لأنها ما كانت لله تعالى . <br />
المعنى : <br />
أما الآية الثالثة ( 53 ) وهي قوله تعالى :  {  ويقول الذين آمنوا } عندما يأتي الله بالفتح أو أمر من عنده فيه نصرة المؤمنين وهزيمة الكافرين ،  ويصبح المنافقون نادمين يقول المؤمنون مشيرين إلى المنافقين :  {  أهؤلاء الذين أقسموا بالله } أغلظ الأَيمان {  إنهم لمعكم حبطت أعمالهم } لأنها لم تكن لله {  فأصبحوا خاسرين } . <br />
