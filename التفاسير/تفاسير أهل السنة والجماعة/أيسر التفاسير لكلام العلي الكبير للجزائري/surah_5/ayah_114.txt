شرح الكلمات : <br />
{  عيداً } :  أي يوماً يعود علينا كل عام نذكر الله تعالى فيه ونشكره . <br />
{  وآية منك } :  علامة منك على قدرتك ورحمتك ،  ونبوة نبيك . <br />
المعنى : <br />
وهنا قال عيسى عليه السلام داعياً ربه ضارعاً إليه {  اللهم } أي يا الله {  ربنا أنزل علينا مائدة من السماء ،  تكون لنا عيداً لأولنا } أي للموجودين الآن منا {  وآخرنا } أي ولمن يأتون بعدنا ،  {  وآية منك } ،  أي وتكون آية منك أي علامة على وحدانيتك وعظيم قدرتك ،  وعلى صدقي في إرسالك لي رسولاً إلى بني إسرائيل ،  {  وارزقنا } وأدم علينا رزقك وفضلك {  وأنت خير الرازقين } . <br />
