شرح الكلمات : <br />
{  أهل قرية } :  مدينة أنطاكية . <br />
{  استطعما أهلها } :  أي طلبا منهم الطعام الواجب للضيف . <br />
{  يريد أن ينقض } :  أي قارب السقوط لميلانه . <br />
{  فأقامه } :  أي الخضر بمعنى أصلحه حتى لا يسقط . <br />
{  أجراً } :  أي جعلا على إقامته وإصلاحه . <br />
المعنى : <br />
قال تعالى :  {  فانطلقا } في سفرهما {  حتى أتيا أهل قرية }  "  أي مدينة  "  قيل إنها انطاكية ووصلاها في الليل والجو بارد فاستطعما أهلها أي طلباً منهم الضيف الواجب له {  فأبوا أن يضيفوهما ،  فوجدا فيها } أي في القرية {  جداراً يريد أن ينقض } أي يسقط فأقامه الخضر وأصلحه فقال موسى له :  {  لو شئت لاتخذت عليه أجراً } أي جعل مقابل إصلاحه ،  لاسيما أن أهل هذه القرية لم يعطونا حقنا من الضيافة . <br />
