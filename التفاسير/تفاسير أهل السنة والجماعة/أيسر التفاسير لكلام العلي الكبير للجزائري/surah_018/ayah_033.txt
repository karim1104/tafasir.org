شرح الكلمات : <br />
{  آتت أكلها } :  أي أعطت ثمارها وهو ما يؤكل . <br />
{  ولم تظلم منه شيئاً } :  أي ولم تنقص منه شيئاً بل أتت به كاملاً ووافياً . <br />
{  خلالهما نهراً } :  أي خلال الأشجار والنخيل نهراً جارياً . <br />
المعنى : <br />
{  كلتا الجنتين آتت أكلها ولم تظلم منه شيئاً } أي لم تنقص منه شيئاً {  وفجرنا خلالهما نهراً } ليسقيهما . <br />
