شرح الكلمات : <br />
{  نبأهم بالحق } :  أي خبرهم العجيب بالصدق واليقين . <br />
{  وزنادهم هدى } :  أي أيماناً وبصيرة في دينهم ومعرفة ربهم حتى صبروا على الهجرة .  {  وربطنا على قلوبهم } :  أي شددنا عليها فقويت عزائمهم حتى قالوا كلمة الحق عند سلطان جائر . <br />
المعنى : <br />
بعد أن ذكر تعالى موجز قصة أصحاب الكهف أخذ في تفصيلها {  نحن نقص عليكم نبأهم بالحق } أي نحن رب العزة والجلال نقص عليك أيها الرسول خبر أصحاب الكهف بالحق الثابت الذي لا شك فيه {  إنهم فتية } ،  جمع فتى {  آمنوا بربهم } أي صدقوا بوجوده ومكارهه . <br />
