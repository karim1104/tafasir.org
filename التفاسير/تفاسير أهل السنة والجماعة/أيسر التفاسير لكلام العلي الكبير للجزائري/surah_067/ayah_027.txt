شرح الكلمات : <br />
{  فلما رأوه زلفة } :  أي لما رأوه العذاب قريباً منهم في عرصات القيامة . <br />
{  سيئت وجوه الذين كفروا } :  أي تغيرت مسودة . <br />
{  هذا الذي كنتم به تدعون } :  أي هذا العذاب الذي كنتم بإنذاره تكذبون وتطالبون بهد تحدياً منكم . <br />
المعنى : <br />
وقوله تعالى {  فلما رأوه } أي عذاب يوم القيامة {  زلفة } أي قريباً منهم {  سيئت وجوه الذين كفروا } أي أساءها الله فتغيرت بالاسوداد والكآبة والحزن .  وقيل لهم أو قالت لهم الملائكة هذا العذاب الذي كنتم به تطالبون متحدين رسولنا والمؤمنين وتقولون :  {  متى هذا الوعد إن كنتم صادقين } . <br />
