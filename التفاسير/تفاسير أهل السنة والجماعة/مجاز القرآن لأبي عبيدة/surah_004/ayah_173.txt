{  فَأَمَّا الّذِينَ آمَنُوا وَعَمِلوا الصَّالَحِاتِ فَيُوَفِّيهِمْ أُجُورَهُمْ } الألف مفتوحة وكذلك كل شيء في القرآن إذا كان تمامُ كلامه بالفاء ،  وإذا كان تخييراً فألف {  إما } مكسورة كقوله :  {  إمَّا أَنْ تُعَذِّبَ وَإمَّا أنْ تَتَّخِذَ } ،  وإذا كان في موضع {  إن } فكذلك الألف مكسورة ؛  من ذلك {  فَإِمَّا تَرَيَنَّ مِنَ البَشَر أحَداً } . <br />
