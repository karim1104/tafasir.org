ثم استثنى فقال :  {  إلا الذين آمنوا } ثم لم يدعهم وذاك{[1]} حتى قال :  {  وعملوا الصالحات } ثم لم يدعهم وذاك حتى قال :  {  وتواصوا بالحق } ثم لم يدعهم وذاك حتى قال :  {  وتواصوا بالصبر } شروطا يشترط عليهم .  <br />
عبد الرزاق عن معمر عن الحسن في قوله تعالى :  {  وتواصوا بالحق وتواصوا بالصبر } قال :  الحق كتاب الله ،   والصبر طاعة الله .
