وقوله تعالى :<br />
{ الله لا إله إلا هو } مبتدأ وخبر وقوله تعالى : { ليجمعنكم } اللام لام القسم أي : والله ليجمعنكم الله من قبوركم { إلى } في { يوم القيامة } وسميت بذلك ؛ لأنّ الناس يقومون من قبورهم قال تعالى : { يوم يخرجون من الأجداث سراعاً } ( المعارج ،   43 ) .  <br />
وقيل : لقيامهم إلى الحساب قال تعالى : { يوم يقوم الناس لرب العالمين } ( المطففين ،   6 ) .  <br />
{ لا ريب } أي : لا شك { فيه } أي : في ذلك اليوم أو في الجمع { ومن أصدق من الله حديثاً } أي : قولاً .  <br />
فإن قيل : الصدق لا يتفاوت كالعلم إذ لا يقال : هذا الصدق أصدق من هذا الصدق كما لا يقال : هذا العلم أعلم من هذا المعلم ،   أجيب : بأنّ الصدق صفة للقائل لا صفة للحديث أي : لا أحد غير الله أصدق منه ؛ لأنّ غيره يتطرّق إلى خبره الكذب ،   وذلك مستحيل في حقه تعالى ،   والأنبياء مخبرون عن الله تعالى ،   وقرأ حمزة والكسائيّ بإشمام الصاد أي : بحرف متولد بين الصاد والزاي .
