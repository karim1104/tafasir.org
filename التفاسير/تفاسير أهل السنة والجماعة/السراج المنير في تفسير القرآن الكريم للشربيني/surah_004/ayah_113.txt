{ ولولا فضل الله عليك } يا محمد { ورحمته } بالعصمة { لهمت طائفة منهم } أي : من قوم طعمة أي : هماً مؤثراً عندك { أن يضلوك } أي : عن القضاء بالحق مع علمهم بالحال بتلبيسهم عليك فلا ينافي ذلك أنهم قد هموا بذلك ؛ لأنّ الهم المؤثر لم يوجد { وما يضلون إلا أنفسهم } إذ وبال ذلك عليهم { وما يضرونك من شيء } فإنّ الله عصمك وما خطر ببالك كان اعتماداً منك على ظاهر الأمر لا ميلاً في الحكم .  <br />
تنبيه : ( من شيء ) في موضع نصب على المصدر أي : شيئاً من الضر فمن مزيدة { وأنزل الله عليك الكتاب } أي : القرآن { والحكمة } أي : السنة فإنها ليست قرآناً يتلى وفسرت أيضاً بأنها علم الشرائع وكل كلام وافق الحق { وعلمك ما لم تكن تعلم } أي : من المشكلات وغيرها غيباً وشهادة من أحوال الدين والدنيا { وكان فضل الله عليك عظيماً } أي : بهذا وبغيره من أمور لا تدخل تحت الحصر ،   وفي هذا دليل على أن العلم من أشرف الفضائل .  <br />
