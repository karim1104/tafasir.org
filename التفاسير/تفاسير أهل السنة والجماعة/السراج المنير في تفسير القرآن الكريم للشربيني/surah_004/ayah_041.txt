{ فكيف } حال الكفار ؟ { إذا جئنا من كل أمّة بشهيد } يشهد عليها بعملها وهو نبيها لقوله تعالى : { وكنت عليهم شهيداً ما دمت فيهم } ( المائدة ،   117 ) .  <br />
{ وجئنا بك } يا محمد { على هؤلاء } الشهداء { شهيداً } أي : شاهداً تشهد على صدقهم لعلمك بعقائدهم واستجماع شرعك على مجامع قواعدهم ،   وقيل : هؤلاء إشارة إلى المؤمنين لقوله تعالى : { لتكونوا شهداء على الناس ويكون الرسول عليكم شهيداً } ( البقرة ،   143 ) .  <br />
وقيل : إلى الكافرين المستفهم عن حالهم .  <br />
وعن ابن مسعود أنه قرأ سورة النساء على رسول الله صلى الله عليه وسلم حتى بلغ قوله : { وجئنا بك على هؤلاء شهيداً } فبكى رسول الله صلى الله عليه وسلم وقال : ( حسبك ) .
