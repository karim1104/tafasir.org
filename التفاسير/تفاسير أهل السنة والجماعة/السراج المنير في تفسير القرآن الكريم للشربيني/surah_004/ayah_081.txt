{ ويقولون } أي : المنافقون إذا أمرتهم بشيء من أمرنا وهم بحضرتك { طاعة } أي : أمرنا وشأننا طاعة أي : نطيعك فيما تأمرنا به { فإذا برزوا } أي : خرجوا { من عندك بيت طائفة منهم } أي : أضمرت { غير الذي تقول } لك في حضورك من الطاعة أي : عصتك ،   وقرأ أبو عمرو وحمزة بإدغام التاء في الطاء فإنها عندهما ساكنة أي : التاء فإذا سكنت التاء قبل الطاء وجب إدغامها فيها ،   والباقون بالإظهار فإن التاء عندهم مفتوحة { والله يكتب } أي : يأمر بكتب { ما يبيتون } أي : ما يسرون من النفاق في صحائفهم ليجازوا عليها { فأعرض عنهم } أي : قلل المبالاة بهم { وتوكل على الله } أي : ثق به فإنه كافيك معرتهم وينتقم لك منهم { وكفى بالله وكيلاً } أي : مفوّضاً إليه .  <br />
