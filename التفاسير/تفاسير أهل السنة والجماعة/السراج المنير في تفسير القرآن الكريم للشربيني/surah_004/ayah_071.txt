{ يا أيها الذين آمنوا } أي : أقرّوا بالإيمان { خذوا حذركم } من عدوّكم أي : احترزوا منه ،   وتيقظوا له والحذر الحذر كالأثر الأثر { فانفروا } أي : اخرجوا إلى قتاله مسرعين { ثبات } أي : جماعات متفرّقين سرية في أثر سرية جمع ثبة ،   وهي الجماعة من الرجال فوق العشرة { أو انفروا جميعاً } أي : مجتمعين كوكبة واحدة ،   قال البيضاوي : والآية وإن نزلت في الحرب لكن يقتضي إطلاق لفظها وجوب المبادرة إلى الخيرات كلها كيفما أمكن قبل الفوات .  <br />
