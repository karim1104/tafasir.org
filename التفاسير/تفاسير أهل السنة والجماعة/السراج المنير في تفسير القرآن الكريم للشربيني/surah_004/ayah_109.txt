وقوله تعالى :<br />
{ ها أنتم هؤلاء } خطاب لقوم طعمة أي : يا هؤلاء { جادلتم } أي : خاصمتم { عنهم } أي : عن طعمة وذويه { في الحياة الدنيا } أي : بما جعل لكم من الأسباب { فمن يجادل الله عنهم يوم القيامة } إذا عذبهم { أم من يكون عليهم وكيلاً } يتولى أمرهم ويذب عنهم أي : لا أحد يفعل ذلك .  <br />
فائدة : اتفق كتاب المصاحف على قطع ( أم ) عن ( من ) .  <br />
