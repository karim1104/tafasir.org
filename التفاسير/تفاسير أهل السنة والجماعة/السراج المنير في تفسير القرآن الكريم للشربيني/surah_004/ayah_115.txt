{ ومن يشاقق الرسول } أي : يخالفه فيما جاء به مأخوذ من الشق ،   فإنّ كلاً من المتخالفين في شق غير شق الآخر { من بعدما تبين } أي : ظهر { له الهدى } أي : الدليل الذي هو سببه { ويتبع } طريقاً { غير سبيل المؤمنين } أي : طريقهم الذي هم عليه من الدين بأن يتبع غير دين الإسلام { نوله ما تولى } أي : نجعله والياً لما تولاه بأن نخلي بينه وبينه في الدنيا { ونصله } أي : ندخله في الآخرة { جهنم } يحترق فيها { وساءت مصيراً } أي : مرجعاً هي ،   وقرأ أبو عمرو وشعبة وحمزة ( نوله ) و( نصله ) بسكون الهاء ،   واختلس كسرة الهاء قالون ولهشام وجهان : الإختلاس كقالون ،   وإشباع الحركة كباقي القرّاء .  <br />
فإن قيل : ما الحكمة في فك الإدغام في قوله تعالى : { ومن يشاقق الرسول } والإدغام في سورة الحشر في قوله : { ومن يشاق الله } ( الحشر ،   4 ) ؟ أجيب : بأن أل في لفظ الجلالة لازم بخلافه في الرسول واللزوم يقتضي الثقل ،   فخفف بالإدغام فيما صحبته الجلالة بخلاف ما صحبه لفظ الرسول .  <br />
فإن قيل : يرد هذا قوله تعالى في سورة الأنفال : { ومن يشاقق الله ورسوله } ( الأنفال ،   13 ) أجيب : أنه لما انضم الرسول إلى الله صار المعطوف والمعطوف عليه كالشيء الواحد .
