{ سنة الله } أي : سنّ المحيط بكل شيء علماً غلبة أنبيائه وأتباعهم { التي قد خلت من قبل } أي : فيمن مضى من الأمم .   كما قال تعالى : { لأغلبنّ أنا ورسلي } [ المجادلة : 21 ] { ولن تجد } أيها السامع { لسنة الله } أي : الذي لا يخلف قوله ،   لأنه محيط بجميع صفات الكمال { تبديلاً } أي : تغييراً من مغيّر ما يغيرها بما يكون بدلها ثم عطف على ما تقديره هو الذي سنّ هذه السنة العامة .
