{ وما كان قولهم } عند قتل نبيهم مع ثباتهم وصبرهم وكونهم ربانيين { إلا أن قالوا ربنا اغفر لنا ذنوبنا وإسرافنا } أي : تجاوزنا الحدّ وقولهم : { في أمرنا } إيذان بأنّ ما أصابهم لسوء فعلهم وهضماً لأنفسهم { وثبت أقدامنا } أي : بالقوّة على الجهاد { وانصرنا على القوم الكافرين } أي : فهلا قلتم وفعلتم مثل ذلك يا أصحاب محمد صلى الله عليه وسلم .  <br />
