ولما نفى تعالى الشريك مطلقاً ،   ثم مقيداً بالولدية أتبعه التهديد على ادّعائه بتعذيب المتبوع الموجب لتعذيب التابع بقوله تعالى : { ومن يقل منهم } أي : من الخلائق حتى العباد المكرمين الذين وصف كرامتهم وقرب منزلتهم عنده ،   وأثنى عليهم { إني إله من دونه } أي : الله أي غيره ،   والذي قال ذلك كما قال الجلال المحلي هو إبليس دعا إلى عبادة نفسه ،   وأمر بطاعتها { فذلك } أي : اللعين الذي لا يصلح للتقريب أصلاً { نجزيه جهنم } لظلمه { كذلك } أي : مثل هذا الجزاء الفظيع جدّاً { نجزي الظالمين } أي : المشركين .  <br />
