ولما ذكر تعالى أنه الوكيل الذي لا كافي غيره أتبعه بعض أفعاله الدالة على ذلك بقوله تعالى : { ربكم } أي : المتصرف فيكم هو { الذي يزجي } أي : يجري { لكم الفلك } ومنها التي حملكم فيها مع أبيكم نوح عليه الصلاة والسلام { في البحر لتبتغوا } أي : لتطلبوا { من فضله } الربح وأنواع الأمتعة التي لا تكون عندكم ثم إنه تعالى علل ذلك بقوله عز وجل : { إنه } أي : فعل سبحانه وتعالى ذلك لأنه { كان } أي : أزلاً وأبداً { بكم رحيماً } حيث هيأ لكم ما تحتاجون إليه وسهل عليكم ما يعسر من أسبابه .  <br />
تنبيه : الخطاب في قوله ربكم وفي قوله إنه كان بكم عام في حق الكل والمراد من الرحمة منافع الدنيا ومصالحها .  <br />
