{ وإذ } أي : إذ يا محمد { نتقنا } أي : رفعنا { الجبل فوقهم } أي : من أصله { كأنه ظلة } قال ابن عباس رضي الله تعالى عنهما : كأنه سقيفة والظلة كل ما أظلك من سقف بيت أو سحابة أو جناح حائط والجمع ظلل وظلال { وظنوا } أي : أيقنوا { أنه واقع بهم } أي : ساقط عليهم بوعد الله بوقوعه إن لم يقبلوا أحكام التوراة .  <br />
روي أنهم لم يقبلوا أحكام التوراة لعظمها وثقلها فرفع الله تعالى الطور على رؤوسهم مقدار عسكرهم فكان فرسخاً في فرسخ ،   وقيل لهم : إن قبلتموها بما فيها وإلا ليقعنّ عليكم فلما نظروا إلى الجبل خرّ كل واحد منهم ساجداً على حاجبه وهو ينظر بعينه اليمنى خوفاً من سقوطه فلذلك لا ترى يهودياً يسجد إلا على حاجبه الأيسر ويقولون : هي السجدة التي رفعت عنا بها العقوبة ،   وقوله تعالى : { خذوا } هو على إضمار القول أي : قلنا لهم خذوا أو قائلين خذوا { ما آتيناكم } أي : من الكتاب وقوله تعالى : { بقوّة } أي : بجد وعزم على تحمل مشاقه حال من واوخذوا { واذكروا ما فيه } أي : بالعمل به ولا تتركوه كالمنسي { لعلكم تتقون } أي : فضائح الأعمال ورذائل الأخلاق .  <br />
