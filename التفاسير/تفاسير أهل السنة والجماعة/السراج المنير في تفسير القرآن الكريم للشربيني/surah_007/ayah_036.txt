{ والذين كذبوا بآياتنا } أي : جحدوها وكذبوا رسلنا { واستكبروا } أي : تكبروا { عنها } أي : عن الإيمان بها لأنّ كل مكذب وكافر متكبر قال تعالى : { إنهم كانوا إذا قيل لهم لا إله إلا الله يستكبرون } ( الصافات ،   35 ) { أولئك } هؤلاء البعداء البغضاء { أصحاب النار هم فيها خالدون } أي : لا يخرجون منها أبداً وإدخال الفاء في خبر المبتدأ الأوّل دون خبر الثاني للمبالغة في الوعد والمسامحة في الوعيد .
