{ وإن تدعوهم } أي : الأصنام { إلى الهدى لا يسمعوا } دعاءكم { وتراهم } يا محمد { ينظرون إليك } أي : يقابلونك كالناظر { وهم لا يبصرون } لأنهم صوّروا بصورة من ينظر إلى من يواجهه ،   وقال الحسن : المراد بهذا المشركون ،   ومعناه إن تدعوا أيها المؤمنون المشركين إلى الهدى لا يسمعوا دعاءكم ؛ لأنّ آذانهم قد صمت عن سماع الحق وتراهم ينظرون إليك يا محمد وهم لا يبصرون أي : ببصائر قلوبهم .  <br />
