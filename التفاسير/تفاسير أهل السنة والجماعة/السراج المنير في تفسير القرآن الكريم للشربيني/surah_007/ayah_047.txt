{ وإذا صرفت أبصارهم } أي : أصحاب الأعراف { تلقاء } أي : جهة { أصحاب النار } فنظروا لهم وإلى سواد وجوههم وما هم فيه من العذاب { قالوا ربنا لا تجعلنا مع القوم الظالمين } أي : الكافرين في النار قال ابن عباس : إنّ أصحاب الأعراف إذا نظروا إلى أصحاب النار وما هم فيه تضرّعوا إلى الله تعالى وسألوه أن لا يجعلهم منهم .   وقرأ قالون وأبو عمرو والبزي بإسقاط الهمزة الأولى وأبدلها ورش وقنبل حرف مدّ وسهلاها والباقون بالتحقيق .  <br />
