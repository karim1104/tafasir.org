ولما كان ضلال بني إسرائيل بعد إنقاذهم من عبودية فرعون وقومه أعجب قال تعالى تسلية لنبيه صلى الله عليه وسلم : { ولقد آتينا } أي : بعظمتنا { موسى الكتاب } أي : التوراة { لعلهم } أي : قوم موسى وهارون عليهما السلام { يهتدون } من الضلالة إلى المعارف والأحكام ،   ولا يصح عود الضمير إلى فرعون وملئه ؛ لأنّ التوراة إنما أوتيها بنو إسرائيل بعد إغراق فرعون وملئه بدليل قوله تعالى : { ولقد آتينا موسى الكتاب من بعد ما أهلكنا القرون الأولى } [ القصص ،   43 ] .
