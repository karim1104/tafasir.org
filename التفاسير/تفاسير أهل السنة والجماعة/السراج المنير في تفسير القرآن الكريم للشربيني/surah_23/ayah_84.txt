ولما أنكروا البعث هذا الإنكار المؤكد ونفوه هذا النفي المحتم أمره الله تعالى أنّ يقررهم بثلاثة أشياء هم بها مقرون ،   ولها عارفون يلزمهم من تسليمها الإقرار بالبعث قطعاً :<br />
أحدها : قوله تعالى : { قل } أي : مجيباً لإنكارهم البعث ملزماً لهم { لمن الأرض } أي : على سعتها وكثرة عجائبها { ومن فيها } على كثرتهم واختلافهم { إن كنتم } أي : مما هو كالجبلة لكم { تعلمون } أي : أهلاً للعلم وفيه تنبيه على أنهم أنكروا شيئاً لا ينكره عاقل .  <br />
