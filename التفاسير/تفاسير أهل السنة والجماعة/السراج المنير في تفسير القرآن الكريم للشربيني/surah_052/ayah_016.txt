{ اصلوها } أي : إذا لم يمكنكم إنكارها وتحققتم أنه ليس بسحر ولا خلل في أبصاركم فقاسوا شدّتها { فاصبروا } على هذا الذي لا طاقة لكم به { أو لا تصبروا } فإنه لا محيص لكم عنه { سواء عليكم } أي : الصبر والجزع فإنّ صبركم لا ينفعكم .   وقوله تعالى : { إنما تجزون ما كنتم تعملون } تعليل للاستواء فإنه لما كان الجزاء واجباً كان الصبر وعدمه سيين في عدم النفع .  <br />
