ثم بين تعالى أحوال المطيعين بقوله تعالى : { فأما الذين آمنوا } أي : من الأمم الجاثية { وعملوا } أي : تصديقاً لدعواهم الإيمان { الصالحات } أي : الطاعات فوصفهم بالعمل الصالح بعد وصفهم بالإيمان يدل على أن العمل الصالح مغاير للإيمان زائد عليه { فيدخلهم } أي : في ذلك اليوم { ربهم } أي : المحسن إليهم بالتوفيق بالإيمان { في رحمته } التي من جملتها الجنة والنظر إلى وجهه الكريم الذي هو الغاية القصوى ،   وتقول لهم الملائكة تشريفاً : سلام أيها المؤمنون .   ودل على عظمة الرحمة بقوله تعالى : { ذلك } أي : الإحسان العالي المنزلة { هو } أي : لا غيره { الفوز المبين } أي : الظاهر الذي لا يخفى على أحد شيء من أمره ؛ لأنّه لا يشوبه كدر أصلاً ولا نقص بخلاف ما كان من أسبابه في الدنيا فإنها مع كونها كانت فوزاً كانت خفية جداً على غير الموقنين .  <br />
