{ وكيف أخاف ما أشركتم } به أي : الأصنام وهي لا تبصر ولا تسمع ولا تضر ولا تنفع { ولا تخافون } أنتم { أنكم أشركتم بالله } وهو تعالى حقيق بأن يخاف منه كل الخوف لأنه إشراك للمصنوع مع الصانع وتسوية بين المقدور العاجز والقادر الضارّ النافع { ما لم ينزل به } أي : بعبادته { عليكم سلطاناً } أي : حجة وبرهاناً وهو القادر على كلّ شيء { فأيّ الفريقين } أي : حزب الله وحزب ما أشركتم ولم يقل فأينا تعميمها للمغنيّ { أحق بالأمن } أهم الموحدون أو المشركون { إن كنتم تعلمون } من الأحق أي : إن كان لكم علم فأخبروني عما سألتكم عنه والأحق بذلك هم الموحدون فاتبعوهم .  <br />
