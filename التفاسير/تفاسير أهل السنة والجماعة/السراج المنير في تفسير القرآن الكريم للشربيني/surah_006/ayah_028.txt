وقوله تعالى :<br />
{ بل بدا لهم } أي : ظهر لهم { ما كانوا يخفون من قبل } للإضراب عن إرادة الإيمان المفهوم من التمني والمعنى : أنهم ظهر لهم ما كانوا يخفون من نفاقهم وقبائح أعمالهم فتمنوا ذلك ضجراً لا عزماً على أنهم لو ردّوا لآمنوا كما قال تعالى : { ولو ردّوا } إلى الدنيا أي : لو فرض ذلك بعد الوقوف والظهور { لعادوا لما نهوا عنه } من الكفر والمعاصي { وإنهم لكاذبون } في قولهم : لو رددنا إلى الدنيا لم نكذب بآيات ربنا وكنا من المؤمنين .  <br />
