{ فلولا } أي : فهلا ولم لا { نصرهم الذين } أي : نصر هؤلاء المهلكين الذين { اتخذوا } أي : اجتهدوا في صرف أنفسهم عن دواعي العقل حتى أخذوا .   { من دون الله } أي : الملك الذي هو أعظم من كل عظيم { قرباناً } أي : متقرباً بهم إلى الله تعالى : { آلهة } معه وهم الأصنام ومفعول اتخذوا الأوّل ضمير محذوف يعود على الموصول أي : هم ،   وقرباناً المفعول الثاني ،   وآلهة بدل منه { بل ضلوا } أي : غابوا { عنهم } وقت نزول النقمة .   وقرأ الكسائي بإدغام اللام في الضاد ،   والباقون بالإظهار { وذلك } أي : اتخاذهم الأصنام آلهة قرباناً { إفكهم } أي : كذبهم { وما كانوا } أي : على وجه الدوام لكونه في طباعهم { يفترون } أي : يتعمدون كذبه ،   لأنّ إصرارهم عليه بعد مجيء الآيات لا يكون إلا كذلك ،   لأنّ من نظر فيها مجرداً نفسه عن الهوى اهتدى .  <br />
