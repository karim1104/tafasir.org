{ ما خلقنا } أي ؛ على ما لنا من العظمة الموجبة للتفرّد بالكبرياء { السماوات والأرض } على ما فيهما من الآيات { وما بينهما إلا } خلقاً ملتبساً { بالحق } أي : الأمر الثابت من القدرة التامة والتصرّف المطلق ليدل على قدرتنا ووحدانيتنا { وأجل } أي وبتقدير أجل { مسمى } ينتهي إليه وهو يوم القيامة .  <br />
{ والذين كفروا عما أنذروا } أي : خوفوا به من القرآن من هول ذلك اليوم الذي لا بدّ لكل خلق من انتهائه إليه { معرضون } أي لا يؤمنون به ولا يهتمون للاستعداد له .  <br />
