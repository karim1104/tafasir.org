ولما أفهم كلامهم أنهم إن لم يجيبوا ينتقم منهم بالعذاب الأليم ،   أتبعوه ما هو أغلظ إنذاراً منه فقالوا { ومن لا يجب } أي : لا يتجدد منه أن يجيب { داعي الله } أي : الملك الذي لا كفء له { فليس بمعجز } أي : لا يعجز الله عز وجلّ بالهرب منه { في الأرض } فيفوته فإنه أيّ مكان سلك فيها فهو في ملكه وملكه وقدرته محيطة به { وليس له من دونه } أي : الله تعالى الذي لا مجير عليه { أولياء } يفعلون لأجله ما يفعل القريب مع قريبه من الذب عنه والاستشفاع له والافتداء { أولئك } البعيدون من كل خير { في ضلال مبين } ظاهر في نفسه أنه ضلال مظهر لكل أحد قبح إحاطته بهم .  <br />
تنبيه : ههنا همزتان مضمومتان من كلمتين ولا نظير لهما في القرآن العظيم قرأ قالون والبزي بتسهيل الأولى كالواو مع المدّ والقصر وسهل الثانية ورش وقنبل بعد تحقيق الأولى ولهما أيضاً إبدال الثانية ألفاً وأسقط الأولى أبو عمرو مع المدّ والقصر والباقون بتحقيقهما وهم على مراتبهم في المدّ .  <br />
