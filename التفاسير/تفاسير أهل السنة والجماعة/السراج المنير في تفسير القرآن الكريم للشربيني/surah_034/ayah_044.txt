ولما بارزوا بهذا القول من غير أثارة من علم ولا خبر من سمع بين ذلك بقوله تعالى : { وما } أي : قالوا ذلك والحال أنا ما { آتيناهم } أي : هؤلاء العرب { من كتب } أصلاً لأنهم لم ينزل عليهم قط قبل القرآن كتاب ،   وأتى بصيغة الجمع مع تأكيد النفي قبل كتابك الجامع { يدرسونها } أي : يجددون دراستها كل حين فيها دليل على صحة الإشراك { وما أرسلنا } أي : إرسالاً لا شبهة فيه لمناسبته لما لنا من العظمة { إليهم } أي : خاصة بمعنى أن ذلك الرسول مأمور بهم بأعيانهم فهم مقصودون بالذات لا أنهم داخلون في عموم أو مقصودون من باب الأمر بالمعروف وفي جميع الزمان الذي { قبلك } أي : قبل رسالتك الجامعة لكل رسالة { من نذير } أي : ليكون عندهم قول منه يدعوهم إلى الإشراك أو ينذرهم على تركه وهذا في غاية التجهيل لهم والتسفيه لرأيهم .  <br />
