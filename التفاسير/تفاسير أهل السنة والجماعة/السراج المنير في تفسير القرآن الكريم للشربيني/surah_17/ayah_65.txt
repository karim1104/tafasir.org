ولما قال الله تعالى له افعل ما تقدر عليه قال تعالى : { إنّ عبادي } أي : الذين أهلتهم للإضافة إليّ فقاموا بحق عبوديتي بالتقوى والإحسان { ليس لك عليهم سلطان } أي : فلا تقدر أن تغويهم وتحملهم على ذنب لا يغفر فإني وفقتهم للتوكل عليّ فكفيتهم أمرك { وكفى بربك } أي : الموجد لك { وكيلاً } ،   أي : حافظاً لهم منك .  <br />
