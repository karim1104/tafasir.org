ثم إنه تعالى بين أن عيسى عبد من عبيده الذين أنعم عليهم بقوله تعالى : { إن } أي : ما { هو } أي : عيسى عليه السلام { إلا عبد } أي : وليس هو بإله { أنعمنا } أي : بما لنا من العظمة { عليه } أي : بالنبوة والإقدار على الخوارق { وجعلناه } أي : بما خرقنا به العادة في ميلاده وغير ذلك من آياته { مثلاً } أي : أمراً عجيباً كالمثل لغرابته من أنثى فقط بلا واسطة ذكر كما خلقنا آدم من غير ذكر وأنثى وشرفناه بالنبوة { لبني إسرائيل } الذين هم أعرف الناس به ،   بعضهم بالمشاهدة ،   وبعضهم بالنقل القريب المتواتر فيعرفون به قدرة الله تعالى على ما يشاء حيث خلقه من غير أبٍ .  <br />
