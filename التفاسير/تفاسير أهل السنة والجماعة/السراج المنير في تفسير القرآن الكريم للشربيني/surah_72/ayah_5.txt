{ وأنا } أي : يا معشر المسلمين من الجنّ { ظننا } أي : حسبنا لسلامة فطرتنا { أن } أي : أنه وزادوا في التأكيد فقالوا { لن تقول } وبدؤوا بأفضل الجنسين فقالوا { الإنس } وأتبعوهم قرناءهم ،   فقالوا { والجنّ على الله } أي : الملك الأعلى الذي بيده النفع والضرّ { كذباً } أي : قولاً هو لعراقته في مخالفة الواقع نفس الكذب ،   وإنما كنا نظنهم صادقين في قولهم إنّ لله صاحبة وولداً حتى سمعنا القرآن وتبينا به الحق قيل انقطع الإخبار عن الجنّ هاهنا .  <br />
