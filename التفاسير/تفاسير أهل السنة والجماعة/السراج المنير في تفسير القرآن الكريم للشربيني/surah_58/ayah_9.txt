{ يا أيها الذين آمنوا } أي : ادعوا أنهم أوجدوا هذه الحقيقة { إذا تناجيتم } أي : اطلع كل منكم الكلام من نفسه فرفعه وكشفه لصاحبه سرّاً { فلا تتناجوا } أي : توجدوا هذه الحقيقة { بالإثم والعدوان ومعصيت الرسول } أي : الكامل في الرسالة كفعل المنافقين واليهود ،   وقال مقاتل : أراد تعالى بقوله :{ آمنوا } المنافقين آمنوا بلسانهم ،   وقال عطاء : يريد الذين آمنوا بزعمهم ،   وقيل : يا أيها الذين آمنوا بموسى{ وتناجوا بالبرّ والتقوى } أي : الطاعة والعفاف عما نهى الله تعالى عنه{ واتقوا الله } أي : اقصدوا قصداً يتبعه العمل بأن تجعلوا بينكم وبين سخط الملك الأعظم وقاية  ،  { الذي إليه } خاصة { تحشرون } أي : تجمعون بأيسر أمر وأسهله بقهر وكره وهو يوم القيامة ،   فيتجلى فيه سبحانه للحكم بين الخلق والإنصاف بينهم بالعدل ومحاسبتهم على النقير والقطمير ،   لا تخفى عليه خافية ولا تقي منه واقية .  <br />
