ولما وصف الله تعالى الآخرة بوصف يوجب الرغبة العظيمة فيها وصف الدنيا بصفات توجب اشتداد النفرة عنها بقوله تعالى : { ألم تر } أي : تعلم { أن الله } أي : الذي له كمال القدرة { أنزل من السماء } أي : التي لا يستمسك الماء فيها إلا بقدرة باهرة تقهر الماء على ذلك ،   والمراد بالسماء : الجرم أو السحاب { ماء } وهو المطر ،   قال الشعبي : كل ماء في الأرض فمن السماء نزل ثم إنه تعالى ينزله إلى بعض المواضع ثم يقسمه { فسلكه } أي : أدخل ذلك الماء خلال التراب حال كونه { ينابيع في الأرض } أي : عيوناً ومجاري ومسالك كالعروق في الأجسام { ثم يخرج } الله تعالى { به } أي : بالماء { زرعاً مختلفاً ألوانه } من خضرة وحمرة وصفرة وبياض وغير ذلك ومختلفاً أصنافه من بر وشعير وسمسم وغيرها { ثم يهيج } أي : ييبس { فتراه } بعد الخضرة مثلاً { مصفراً } من يبسه لأنه إذا تم جفافه حان له أن يفصل عن منابته { ثم يجعله حطاماً } أي : فتاتاً { إن في ذلك } أي : التدبير على هذا الوجه { لذكرى } أي : تذكيراً وتنبيهاً { لأولي الألباب } أي : أصحاب العقول الصافية جداً فيتذكرون هذه الأحوال في النبات فيعلمون بدلالته على وحدانية الله تعالى شأنه وقدرته وأحوال الحيوان والإنسان ،   وإنه وإن طال عمره فلابد من الانتهاء إلى أن يصير مصفر اللون منحطم الأعضاء والأجزاء ثم تكون عاقبته الموت ،   فإذا كانت مشاهدة هذه الأحوال في النبات مذكرة حصول مثل هذه الأحوال في نفسه في حياته فحينئذ تعظم نفرته عن الدنيا ولذاتها .  <br />
