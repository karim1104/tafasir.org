ثم إنه تعالى بين نوعاً آخر من قبائح أفعالهم بقوله تعالى : { فمن } أي : لا أحد { أظلم } أي : منهم هكذا كان الأصل ،   ولكن قال تعالى : { ممن كذب } تعميماً { على الله } أي : الذي الكبرياء رداؤه والعظمة إزاره بنسبة الولد والشريك إليه { وكذّب } أي : أوقع التكذيب لكل من أخبره { بالصدق } أي : بالأمر الذي هو الصدق بعينه وهو ما جاء به محمد صلى الله عليه وسلم { إذ جاءه } أي : فاجأه بالتكذيب لما سمع من غير وقفة ولا إعمال روية بتمييز بين حق وباطل كما يفعل أهل النصفة فيما يستمعون ،   وقرأ نافع وابن كثير وابن ذكوان وعاصم بإظهار الذال عند الجيم والباقون بالإدغام ،   ثم أردف ذلك بالوعيد فقال : { أليس في جهنم } أي : النار التي تلقى داخلها بالتجهم والعبوسة كما كان يلقى الحق وأهله { مثوى } أي : مأوى { للكافرين } أي : لهؤلاء الذين كذبوا على الله وكذبوا بالصدق ،   واللام في للكافرين إشارة إليهم والاستفهام بمعنى التقرير .  <br />
