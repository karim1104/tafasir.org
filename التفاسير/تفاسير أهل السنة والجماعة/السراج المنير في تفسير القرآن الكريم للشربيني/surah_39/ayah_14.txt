{ قل الله } أي : المحيط بصفات الكمال وحده { أعبد مخلصاً له } وحده { ديني } من الشرك .  <br />
قال الرازي : فإن قيل : ما معنى التكرير في قوله تعالى { قل إني أمرت أن أعبد الله مخلصاً له الدين } وقوله تعالى : { قل الله أعبد مخلصاً له ديني } قلنا : ليس هذا بتكرير لأن الأول إخبار بأنه مأمور من جهة الله تعالى بالإيمان بالعبادة ،   والثاني : إخبار بأنه أمر أن لا يعبد أحداً غير الله تعالى ،   وذلك أن قوله { أمرت أن أعبد الله } لا يفيد الحصر وقوله تعالى : { قل الله أعبد } يفيد الحصر أي : الله أعبد ولا أعبد أحداً سواه .  <br />
ويدل عليه أنه لما قال { قل الله أعبد } قال بعده : { فاعبدوا }.  <br />
