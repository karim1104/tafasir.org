ثم إنه تعالى وصف عذاب هؤلاء الكافرين من وجه آخر فقال سبحانه وتعالى : { الذين تتوفاهم الملائكة } أي : يقبض أرواحهم ملك الموت وأعوانه عليهم السلام .   وقرأ حمزة في هذه الآية وفي الآية الآتية بالياء في الموضعين على التذكير لأن الملائكة ذكور والباقون بالتاء على التأنيث لأن لفظ الجمع مؤنث .   { ظالمي أنفسهم } أي : بأن عرضوها للعذاب المخلد بكفرهم { فالقوا السلم } أي : استسلموا وانقادوا حين عاينوا الموت قائلين : { ما كنا نعمل من سوء } أي : شرك وعدوان فتقول لهم الملائكة : { بلى } أي : بل كنتم تعملون أعظم السوء ثم علل تكذيبهم بقوله تعالى : { إنّ الله عليم بما كنتم تعملون } أي : فلا فائدة لكم في إنكاركم فيجازيكم به .  <br />
