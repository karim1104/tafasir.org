ثم إن الله تعالى أمر نبيه صلى الله عليه وسلم أن يجيبهم بقوله تعالى : { قل الله } أي : المحيط علماً وقدرة { يحييكم } أي : حين كنتم نطفاً { ثم يميتكم } أي : بأن يخرج أرواحكم من أجسادكم فتكونون كما كنتم قبل الإحياء كما تشاهدون { ثم يجمعكم } أي : بعد التمزق فيعيد فيكم أرواحكم كما كانت بعد طول مدة الرقاد منتهين { إلى يوم القيامة } أي : القيام الأعظم لكونه عاماً لجميع الخلائق { لا ريب } أي : لا شك بوجه من الوجوه { فيه } بل هو معلوم علماً قطعياً ضرورياً { ولكن أكثر الناس } أي : وهم القائلون ما ذكر { لا يعلمون } أي : لا يتجدد لهم علم لما لهم من النفوس والتردد والسفول عن أوج العقل إلى حضيض الجهل ،   فهم واقفون مع المحسوسات لا يلوح لهم ذلك مع ما له من الظهور .  <br />
