وقوله تعالى : { يا أيها الناس } خطاب عامّ .   وقيل : لأهل مكة { قد جاءتكم موعظة من ربكم } أي : كتاب فيه ما لكم وعليكم وهو القرآن { وشفاء } أي : دواء { لما في الصدور } أي : القلوب من داء الجهل ؛ لأنّ داء الجهل أضرّ للقلب من المرض للبدن ،   وأمراض القلب هي الأخلاق الذميمة والعقائد الفاسدة والجهالات المهلكة ،   والقرآن مزيل لهذه الأمراض كلها ؛ لأنّ فيه المواعظ والزواجر والتخويف والترغيب والترهيب والتحذير والتذكير ،   فهو الشفاء لهذه الأمراض القلبية ،   وإنما خص تعالى الصدر بالذكر ؛ لأنه موضع القلب وغيره وهو أعز موضع في الإنسان لمكان القلب فيه { وهدى } من الضلالة { ورحمة } أي : إكرام عظيم { للمؤمنين } لأنهم هم الذين انتفعوا به دون غيرهم .  <br />
