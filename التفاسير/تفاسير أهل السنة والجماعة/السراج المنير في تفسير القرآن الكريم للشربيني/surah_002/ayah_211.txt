{ سل } أمر للرسول أو لكل أحد { بني إسرائيل } توبيخاً { كم آتيناهم } كم استفهامية معلقة سل عن المفعول الثاني وهي ثاني مفعولي آتيناهم ومميزها { من آية } أي : معجزة { بينة } أي : ظاهرة في الدلالة على صدق من جاء بها كقلب العصا حية ،   وإبراء الأكمه والأبرص وفلق البحر وإنزال المنّ والسلوى فبدّلوها كفراً .  <br />
{ ومن يبدّل نعمة الله } أي : ما أنعم به عليه من الآيات لأنها سبب الهداية التي هي أجل النعم كفراً { من بعدما جاءته } أي : وصلته وتمكن من معرفتها { فإنّ الله شديد العقاب } فيعاقبه أشدّ عقوبة لأنه ارتكب أشدّ جريمة وهي التبديل .  <br />
