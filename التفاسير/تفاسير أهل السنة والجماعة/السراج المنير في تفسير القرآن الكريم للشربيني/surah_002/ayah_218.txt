ولما ظنّ السرية أنهم إن سلموا من الإثم فلا يحصل لهم أجر أنزل الله تعالى .  <br />
{ إن الذين آمنوا والذين هاجروا } أي : فارقوا عشائرهم ومنازلهم وأموالهم { وجاهدوا } المشركين { في سبيل الله } لإعلاء دينه ،   وكرّر سبحانه وتعالى الموصول لتعظيم الهجرة والجهاد ،   وكأنهما مستقلان في تحقيق الرجاء { أولئك يرجون رحمة الله } أي : ثوابه أثبت لهم الرجاء إشعاراً بأنّ العمل غير موجب ،   ولا قاطع في الدلالة ،   سيما والعبرة بالخواتيم { والله غفور } للمؤمنين لما فعلوه خطأ وقلة احتياط { رحيم } بهم بأن يجزل لهم الأجر والثواب .  <br />
