{ وقاتلوا } أي : جاهدوا { في سبيل الله } لإعلاء كلمته وإعزاز دينه { الذين يقاتلونكم } من الكفار { ولا تعتدوا } عليهم بالابتداء بالقتال { إنّ الله لا يحب المعتدين } أي : لا يريد بهم الخير ؛ لأنه غاية المحبة إذ المحبة حقيقتها محال في حقه تعالى ؛ لأنها ميل النفس ،   وسبب ذلك أنهم كانوا منعوا من قتال الكفار وأمروا بالصبر على أذاهم بقوله تعالى : { لتبلون في أموالكم } ( آل عمران ،   186 ) الآية ،   ثم أمروا به إذا ابتدؤوا به بهذه الآية ،   ثم أبيح لهم ابتداؤه في غير الأشهر الحرم بقوله تعالى : { فإذا انسلخ الأشهر الحرم } ( التوبة ،   5 ) الآية .
