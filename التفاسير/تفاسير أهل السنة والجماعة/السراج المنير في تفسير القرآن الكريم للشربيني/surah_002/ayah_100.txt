{ أو كلما عاهدوا عهداً } الهمزة للإنكار والواو للعطف على محذوف تقديره أكفروا بالآيات وكلما عاهدوا الله عهداً على الإيمان بالنبيّ أو إن خرج النبيّ أن لا يعاونوا عليه المشركين وقوله تعالى { نبذه } أي : طرحه { فريق منهم } أي : اليهود بنقضه جواب كلما وهو محل الاستفهام الإنكاري وإنما قال فريق ؛ لأنّ بعضهم لم ينقض وقوله تعالى : { بل } للانتقال { أكثرهم لا يؤمنون } ردّ لِما يتوهم أنّ الفريق هم الأقلون .  <br />
