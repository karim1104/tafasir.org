ثم بين كون البنات أبغض إليهم بقوله تعالى : { وإذا } أي : جعلوا ذلك والحال أنه إذا { بشر } أي : من أي : مبشر كان { أحدهم } أي : أحد هؤلاء البعداء البغضاء { بما ضرب } أي : جعل { للرحمن } الذي لا نعمة على شيء من الخالق ألا وهي منه { مثلاً } أي : شبهاً بنسبة البنات إليه لأن الولد يشبه الوالد ،   والمعنى إذا أخبر أحدهم بالبنت تولد له { ظل } أي : صار { وجهه مسوداً } أي : شديد السواد لما يعتريه من الكآبة { وهو كظيم } أي : ممتلئ غماً فكيف تنسب البنات إليه تعالى ،   هذا ما لا يرضى عاقل أن يمر بفكره فضلاً عن أن يتفوه به .  <br />
