ولما ذكر تعالى كيفية عذابهم في الآخرة ذكر بعده كيفية مكرهم وفساد باطنهم في الدنيا فقال تعالى : { أم أبرموا } أي : أحكم كفار مكة { أمراً } أي : في المكر برسول الله صلى الله عليه وسلم وفي رد أمرنا ومعاداة أوليائنا مع علمهم بأنا مطلعون عليهم { فإنا مبرمون } أي : محكمون أمراً في مجازاتهم أي : مبرمون كيدنا كما أبرموا كيدهم كقوله تعالى : { أم يريدون كيداً فالذين كفروا هم المكيدون } ( الطور : 42 ) قال مقاتل : نزلت في تدبيرهم المكر في دار الندوة .  <br />
