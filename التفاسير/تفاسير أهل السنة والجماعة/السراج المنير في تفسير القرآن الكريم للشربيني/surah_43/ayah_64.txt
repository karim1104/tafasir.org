{ إن الله } أي : الذي اختص بالجلال والجمال فكان أهلاً لأن يُتقى { هو } أي : وحده { ربي وربكم } أي : المحسن إلي وإليكم { فاعبدوه } أي : بما أمركم به لأنه صدقني في أمركم باتباعي بما أظهره على يدي فصار هو الآمر لكم لا أنا { هذا } أي : الأمر العظيم الذي دعوتكم إليه { صراط } أي : طريق واسع جداً واضح { مستقيم } لا عوج فيه .  <br />
