{ وأنا منا } أي : الجن { المسلمون } أي : المخلصون في صفة الإسلام { ومنا القاسطون } أي : الجائرون أي : وإنا بعد سماع القرآن مختلفون فمنا من أسلم ومنا من كفر ،   والقاسط الجائر لأنه عدل عن الحق ،   والمقسط العادل إلى الحق ،   قسط إذا جار ،   وأقسط إذا عدل فقسط الثلاثي بمعنى جار ،   وأقسط الرباعي بمعنى عدل .  <br />
وعن سعيد بن جبير : أنّ الحجاج قال له حين أراد قتله : ما تقول فيّ ؟ قال : قاسط عادل .   فقال القوم : ما أحسن ما قال ،   حسبوا أنه يصفه بالقسط والعدل .   فقال الحجاج : يا جهلة إنما سماني ظالماً مشركاً وتلا لهم قوله تعالى : { وأما القاسطون فكانوا لجهنم حطباً } .   { ثم الذين كفروا بربهم يعدلون } [ الأنعام : 1 ] .  <br />
{ فمن أسلم } أي : أوقع الإسلام كله بأن أسلم ظاهره وباطنه من الجن وغيرهم { فأولئك } أي : العالو الرتبة { تحرّوا } أي : توخوا وقصدوا مجتهدين { رشداً } أي : صواباً عظيماً وسداداً كان لما عندهم من النقائص شارداً عنهم ،   فعالجوا أنفسهم حتى ملكوه فجعلوه لهم منزلاً .
