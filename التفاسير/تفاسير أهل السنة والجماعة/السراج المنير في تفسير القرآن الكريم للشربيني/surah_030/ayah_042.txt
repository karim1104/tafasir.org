ولما بين تعالى حالهم بظهور الفساد في أحوالهم بسبب فساد أقوالهم بين لهم ضلال أمثالهم وأشكالهم الذين كانت أفعالهم كأفعالهم بقوله تعالى لنبيه محمد صلى الله عليه وسلم : { قل } أي : لهؤلاء الذين لا همّ لهم سوى الدنيا { سيروا في الأرض } فإنّ سيركم الماضي لكونه لم تصحبه عبرة عدمٌ { فانظروا } نظرَ اعتبار { كيف كان عاقبة الذين من قبل } أي : من قبل أيامكم لتروا منازلهم ومساكنهم خالية فتعلموا أنّ الله تعالى أذاقهم وبال أمرهم وأوقعهم في حفائر مكرهم { كان أكثرهم مشركين } أي : فلذلك أهلكناهم ولم تغن عنهم كثرتهم وأنجينا المؤمنين وما ضرّتهم قلتهم .  <br />
