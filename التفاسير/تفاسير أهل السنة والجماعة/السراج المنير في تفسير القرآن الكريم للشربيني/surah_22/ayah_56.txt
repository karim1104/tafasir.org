{ الملك يومئذٍ } أي : يوم القيامة { لله } أي : المحيط بجميع صفات الكمال وحده ،   ولما كان كأنه قيل : ما معنى اختصاصه به ،   وكل الأيام له قيل : { يحكم بينهم } أي : المؤمنين والكافرين بالأمر الفصل الذي لا حكم فيه ظاهراً ولا باطناً لغيره كما ترونه الآن بل يمشي فيه الأمر على أتم شيء من العدل { فالذين آمنوا وعملوا } أي : وصدّقوا دعواهم الإيمان بأن عملوا { الصالحات } وهي ما أمرهم الله به { في جنات النعيم } فضلاً منه ورحمة لهم بما رحمهم الله تعالى من توفيقهم للأعمال الصالحات .  <br />
