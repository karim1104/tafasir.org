ثم إنه تعالى أخبر عن أساس إمامة بني إسرائيل مقسماً عليه مع الافتتاح بحرف التوقع بقوله : { ولقد آتينا } أي : بما لنا من الجلال والكمال { موسى الكتاب } أي : التوراة الجامعة للهدى والخير في الدارين ،   قال أبو حيان : وهو أوّل كتاب نزلت فيه الفرائض والأحكام .  <br />
{ من بعدما أهلكنا القرون الأولى } أي : من قوم نوح إلى قوم فرعون وقوله تعالى { بصائر للناس } حال من الكتاب جمع بصيرة وهي نور القلب أي : أنوار القلوب فيبصر بها الحقائق ويميز بين الحق والباطل كما أنّ البصر نور العين الذي تبصر به { وهدى } أي : للعامل بها إلى كل خير { ورحمة } أي : نعمة هنيئة شريفة لأنها قائدة إليهما .   ولما ذكر حالها ذكر حالهم بعد إنزالها بقوله تعالى : { لعلهم يتذكرون } أي : ليكون حالهم حال من يرجى تذكره .  <br />
