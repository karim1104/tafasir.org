{ ولا يصدنك عن آيات الله } أي : قراءتها والعمل بها { بعد إذ أنزلت إليك } أي : لا ترجع إليهم في ذلك { وادع } أي : أوجد الدعاء { إلى ربك } أي : إلى عبادته وتوحيده { ولا تكونن من المشكرين } أي : بإعانتهم ،   ولم يؤثر الجازم في الفعل لبنائه بخلافه في يصدنك فإنه حذف منه نون الرفع إذ أصله يصدوننك حذفت نون الرفع للجازم ثم حذفت الواو لالتقاء الساكنين .  <br />
