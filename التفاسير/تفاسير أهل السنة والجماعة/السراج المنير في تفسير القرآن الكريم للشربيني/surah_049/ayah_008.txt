وقوله تعالى : { فضلاً } مصدر منصوب بفعله المقدّر أي فضل وقيل : تعليل لكرّه أو حبب ،   وما بينهما اعتراض فهو امتنان عظيم ودرجة عالية { من الله } أي : الملك الأعظم الذي بيده كل شيء { ونعمة } أي : وعيشاً حسناً ناعماً وكرامة { والله } أي : المحيط بصفات الكمال { عليم } أي : محيط العلم يعلم أحوال المؤمنين وما بينهم من التفاضل .   { حكيم } أي : بالغ الحكمة ،   فهو يضع الأشياء في أوفق محالها وأتقنها فكذلك وضع نعمته من الرسالة والإيمان على حسب علمه وحكمته ونزل في قضية .  <br />
