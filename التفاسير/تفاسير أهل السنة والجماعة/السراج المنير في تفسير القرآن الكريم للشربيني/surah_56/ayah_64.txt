{ أأنتم تزرعونه } أي : تنشئونه بعد طرحكم وتجعلونه زرعاً فيكون فيه السنبل والحب { أم نحن } خاصة { الزارعون } أي : المنبتون له والحافظون ؛ روى أنه عليه الصلاة والسلام قال : «لا يقولنّ أحدكم زرعت وليقل حرثت » .   قال أبو هريرة أرأيتم إلى قوله تعالى : { أفرأيتم } الآية .  <br />
ولما كان الجواب قطعاً أنت الفعال لذلك وحدك قال تعالى موضحاً لأنه ما زرعه غيره { لو نشاء لجعلناه حطاما فظلتم تفكهون } .  <br />
