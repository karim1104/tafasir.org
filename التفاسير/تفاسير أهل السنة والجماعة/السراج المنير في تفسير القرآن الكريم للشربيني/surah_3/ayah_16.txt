وقوله تعالى :<br />
{ الذين } نعت للذين اتقوا أو للعباد أو بدل من الذين قبله { يقولون } يا { ربنا إننا آمنا } أي : صدّقنا { فاغفر لنا ذنوبنا } أي : استرها علينا وتجاوز عنا { وقنا عذاب النار } .  <br />
تنبيه : في ترتيب سؤال المغفرة وما عطف عليها وسيلة على مجرّد الإيمان دليل على أنّ مجرّد الإيمان كاف في استحقاق المغفرة والاستعداد لأسبابها وأسباب ما عطف عليها .  <br />
