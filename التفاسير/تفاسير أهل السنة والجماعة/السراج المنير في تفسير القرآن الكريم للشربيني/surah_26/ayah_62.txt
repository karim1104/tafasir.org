{ قال } أي : موسى عليه السلام وثوقاً بوعد الله تعالى { كلا } أي : لا يدركونكم أصلاً ،   ثم علل ذلك تسكيناً لهم بقوله { إن معي ربي } أي : بنصره فكأنهم قالوا وما عساه يفعل وقد وصلونا قال { سيهدين } أي : يدلني على طريق النجاة ،   روي : أن مؤمن آل فرعون كان بين يدي موسى عليه السلام فقال أين تذهب فهذا البحر أمامك وقد غشيك آل فرعون قال : أمرت بالبحر ولعلي أؤمر بما أصنع .  <br />
