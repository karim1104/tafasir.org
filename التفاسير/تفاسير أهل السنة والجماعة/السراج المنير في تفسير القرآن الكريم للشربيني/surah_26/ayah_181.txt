ثم نصحهم بقوله : { أوفوا الكيل } أي : أتموه إتماماً لا شبهة فيه إذا كلتم كما توفونه إذا اكتلتم { ولا تكونوا من المخسرين } أي : الناقصين لحقوق الناس في الكيل والوزن كما قال تعالى : { ويل للمطففين ( 1 ) الذين إذا اكتالوا على الناس يستوفون } ( المطففين : 1 ،   2 ) أي : الكيل { وإذا كالوهم } ( المطففين : 2 ) أي : كالوا لهم { أو وزنوهم } أي : وزنوا لهم { يخسرون } ( المطففين : 3 ) ينقصون الكيل أو الوزن .
