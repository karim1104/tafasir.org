{ وأن } أي : وأمرت أن { أتلو القرآن } عليكم تلاوة الدعوة إلى الإيمان ،   أو أن أواظب على تلاوته لتنكشف لي حقائقه في تلاوته شيئاً فشيئاً { فمن اهتدى } أي : باتباع هذا القرآن الداعي إلى الجنان { فإنما يهتدي لنفسه } أي : لأجلها لأنّ ثواب هدايته له { ومن ضلّ } أي : عن الإيمان الذي هو الطريق المستقيم { فقل } أي : له كما تقول لغيره { إنما أنا من المنذرين } أي : المخوّفين له عواقب صنعه فلا عليّ من وبال ضلاله شيء إذ ما على الرسول إلا البلاغ وقد بلغت .  <br />
