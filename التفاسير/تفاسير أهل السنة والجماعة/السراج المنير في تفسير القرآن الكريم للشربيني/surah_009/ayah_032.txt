{ يريدون } أي : رؤساء اليهود والنصارى { أن يطفئوا نور الله } أي : شرعه وبراهينه الدالة على واحدانيته وتقديسه عن الولد أو القرآن أو نبوّة محمد صلى الله عليه وسلم { بأفواههم } أي : بأقوالهم الكاذبة وشركهم وفي تسمية دينه أو القرآن أو نبوّة محمد صلى الله عليه وسلم نوراً ومعاندتهم إطفاءه بأفواههم تمثيل لحالهم في طلبهم أن يبطلوا نور الله بالتكذيب بالشرك بحال من يريد أن ينفخ في نور عظيم منبث في الآفاق يريد الله أن يزيده ويبلغه الغاية القصوى في الإشراق والإضاءة ليطفئه بنفخه ويطمسه { ويأبى الله } أي : لا يرضى { إلا أن يتمّ نوره } بإعلاء التوحيد وإعزاز الإسلام .  <br />
فإن قيل : كيف جاز أبى الله إلا كذا ولا يقال كرهت أو أبغضت إلا زيداً ؟ أجيب : بأنه أجرى أبى مجرى لم يرد ألا ترى كيف قوبل { يريدون أن يطفئوا } بقوله : { ويأبى الله } وكيف أوقع موقع ولا يريد الله إلا أن يتم نوره وقوله تعالى : { ولو كره الكافرون } محذوف الجواب لدلالة ما قبله أي : ولو كرهوا غلبته .  <br />
