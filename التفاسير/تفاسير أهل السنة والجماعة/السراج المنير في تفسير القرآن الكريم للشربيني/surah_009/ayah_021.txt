{ يبشرهم } أي : يخبرهم { ربهم } والبشارة الخبر السار الذي يفرح الإنسان عند سماعه وتستبشر بشرة وجهه عند سماع ذلك الخبر السار ،   ثم ذكر سبحانه وتعالى الذي يبشرهم به بقوله تعالى : { برحمة منه ورضوان } ،   فهذا أعظم البشارات ؛ لأنّ الرحمة والرضوان من الله تعالى سبحانه وتعالى على العبد نهاية مقصودة { وجنات } أي : بساتين كثيرة الأشجار والثمار { لهم فيها } أي : الجنات { نعيم } أي : جزاء خالص عن كدر مّا { مقيم } أي : غير منقطع .  <br />
