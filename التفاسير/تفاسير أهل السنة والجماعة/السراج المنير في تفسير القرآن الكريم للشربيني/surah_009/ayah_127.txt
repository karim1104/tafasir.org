{ وإذا ما أنزلت سورة } فيها عيب المنافقين وتوبيخهم وقرأها صلى الله عليه وسلم { نظر بعضهم إلى بعض } أي : تغامزوا بالعيون إنكاراً لها وسخرية أو غيظاً لما فيها من عيوبهم ويريدون الهرب يقولون : { هل يراكم من أحد } أي : من المؤمنين إذا قمتم فإن لم يرهم أحد قاموا وخرجوا من المسجد وإن علموا أنّ أحداً يراهم ثبتوا على تلك الحالة { ثم انصرفوا } على كفرهم ونفاقهم وقيل : انصرفوا عن مواضعهم التي يسمعون فيها ما يكرهون وقوله تعالى : { صرف الله قلوبهم } أي : عن الهدى يحتمل الإخبار والدعاء { بأنهم } أي : بسبب أنهم { قوم لا يفقهون } أي : لسوء فهمهم وعدم تدبرهم .  <br />
