وقوله عز من قائل :<br />
{ ألم يأتهم } فيه رجوع من الخطاب إلى الغيبة أي : ألم يأت هؤلاء المنافقين والكفار وهو استفهام بمعنى التقرير أي : قد أتاهم { نبأ } أي : خبر { الذين من قبلهم } من الأمم الماضية الذين خلوا من قبلهم كيف أهلكناهم حين خالفوا أمرنا وعصوا رسلنا ،   ولما شبه تعالى المنافقين بالكفار المتقدّمين في الرغبة في الدنيا وفي تكذيب الأنبياء والمبالغة في إيذائهم لرسلهم بين منهم ستة طوائف :<br />
الأولى : { قوم نوح } أهلكوا بالطوفان .  <br />
{ و } الثانية : { عاد } وهم قوم هود أهلكوا بالريح .  <br />
{ و } الثالثة : { ثمود } ،   وهم قوم صالح أهلكوا بالرجفة .  <br />
{ و } الرابعة : { قوم إبراهيم } أهلكوا بسلب النعمة وأهلك نمروذ ببعوضة سلطها الله تعالى على دماغه فقتلته .  <br />
{ و } الخامسة : { أصحاب مدين } وهم قوم شعيب ويقال إنهم من ولد مدين بن إبراهيم أهلكوا بعذاب يوم الظلة .  <br />
{ و } السادسة : { المؤتفكات } وهم قوم لوط أي : أهلها أهلكوا بأن جعل الله تعالى أعالي أرضهم سافلها وأمطر عليهم حجارة ،   وإنما ذكر الله تعالى هذه الطوائف الستة لأن آثارهم باقية وبلادهم بالشام والعراق واليمن وكل ذلك قريب من بلاد العرب فكانوا يمرّون عليهم ويعرفون أخبارهم وقوله تعالى : { أتتهم رسلهم } راجع إلى كل هؤلاء الطوائف { بالبينات } أي : المعجزات الباهرات والحجج الواضحات الدالة على صدقهم فكذبوهم وخالفوا أمرنا كما فعلتم أيها الكفار والمنافقون فاحذروا أن يصيبكم مثل ما أصابهم فتعجل لكم النقمة كما عجلت لهم .   وقرأ أبو عمرو بسكون السين والباقون بالرفع { فما كان الله ليظلمهم } بتعجيل العقوبة لهم { ولكن كانوا أنفسهم يظلمون } حيث عرضوها للعقاب بالكفر والتكذيب .  <br />
