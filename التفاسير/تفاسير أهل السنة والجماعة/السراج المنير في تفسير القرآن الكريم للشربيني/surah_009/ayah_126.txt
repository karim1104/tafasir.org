وقوله تعالى :<br />
{ أو لا يرون } قرأه حمزة بالتاء أي : أيها المؤمنون والباقون بالياء على الغيبة أي : المنافقون { أنهم يفتنون } أي : يبتلون { في كل عام مرّة أو مرّتين } بالأمراض والقحط والحرب { ثم لا يتوبون } من نفاقهم ونقض عهودهم إلى الله تعالى { ولا هم يذكرون } أي : ولا يتعظون بما يرون من نصرته صلى الله عليه وسلم وتأييده .  <br />
