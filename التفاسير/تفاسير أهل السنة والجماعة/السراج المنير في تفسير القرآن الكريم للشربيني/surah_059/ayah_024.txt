{ هو } أي : الذي لا شيء يستحق أن يطلق عليه هذا الضمير غيره لأنّ وجوده من ذاته ،   ولا شيء غيره إلا وهو ممكن ولما ابتدأ بهذا الغيب المحض الذي هو أظهر الأشياء أخبر عنه بأشهر الأشياء الذي لم يقع فيه شركة بوجه .   فقال تعالى : { الله } أي : الذي ليس له سميّ فلا كفء له فهو المعبود بالحق فلا شريك له بوجه { الخالق } أي : المقدر للأشياء على مقتضى حكمته { البارئ } أي : المخترع المنشئ للأشياء من العدم إلى الوجود برياً من التفاوت وقوله تعالى : { المصور } أي : الذي يخلق صور الأشياء على ما يريد بكسر الواو ورفع الراء إما صفة ،   وإمّا خبر واحترزت بهذا الضبط عن قراءة أمير المؤمنين علي بن أبي طالب والحسن فإنهما قرأا بفتح الواو ونصب الراء ،   وهي قراءة شاذة وإنما تعرّضت لها لأبين وجهها ،   وهو أن تخرّج هذه القراءة على أن يكون المصور منصوباً بالبارئ ،   والمصوّر هو الإنسان إمّا آدم وإما هو وبنوه وعلى هذه القراءة يحرم الوقف على المصوّر بل يجب الوصل ليظهر النصب في الراء ،   وإلا فقد يتوهم منه في الوقف ما لا يجوز { له } أي : خاصة { الأسماء الحسنى } التسعة والتسعون الوارد فيها الحديث ،   وقد ذكرتها في سورة الإسراء .   والحسنى تأنيث الأحسن { يسبح } أي : يكرّر التنزيه الأعظم عن كل شيء من شوائب النقص على سبيل التجدّد والاستمرار { له } أي : على وجه التخصيص { ما في السماوات } أي السماوات وما فيها { والأرض } وما فيها { وهو } أي : والحال أنه وحده { العزيز } أي : الذي يغلب كل شيء ولا يغلبه شيء { الحكيم } أي : الجامع الكمالات بأسرها فإنها راجعة إلى الكمال في القدرة والعلم .  <br />
