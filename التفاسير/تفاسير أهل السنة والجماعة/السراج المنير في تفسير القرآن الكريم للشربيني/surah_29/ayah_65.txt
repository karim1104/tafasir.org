{ فإذا } أي : فتسبب عن عدم عقلهم المستلزم لعدم علمهم أنهم إذا { ركبوا } البحر { في الفلك } أي : السفن { دعوا الله } أي : الملك الأعلى { مخلصين } بالتوحيد { له الدين } معرضين عن الشركاء بالقلب واللسان حيث لا يذكرون إلا الله ولا يدعون سواه لعلمهم بأنه لا يكشف الشدائد إلا هو { فلما نجاهم } أي : الله سبحانه وتعالى موصلاً لهم { إلى البرّ إذا هم } أي : حين الوصول إلى البرّ { يشركون } كما كانوا فهذا إخبار عنهم بأنهم عند الشدائد مقرون أن القادر على كشفها هو الله عز وجل وحده فإذا زالت عادوا إلى كفرهم .  <br />
قال عكرمة : كان أهل الجاهلية إذا ركبوا في البحر حملوا معهم الأصنام فإذا اشتدّ عليهم الريح ألقوها في البحر وقالوا يا رب يا رب ،   وقال الرازي في اللوامع : وهذا دليل على أن معرفة الرب في فطرة كل إنسان وأنهم إن غفلوا في السراء فلا شك أنهم يلوذون إليه في حال الضراء انتهى ،   فعلم أن الاشتغال بالدنيا هو الصادّ عن كل خير وأن الانقطاع عنها معين للفطرة الأولى المستقيمة ولهذا تجد الفقراء أقرب إلى كل خير .  <br />
