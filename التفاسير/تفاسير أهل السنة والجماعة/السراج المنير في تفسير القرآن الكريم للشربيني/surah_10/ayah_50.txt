قال الله تعالى : { قل } أي : قل لهم يا محمد أيضاً { أرأيتم إن أتاكم عذابه } الذي تستعجلون به { بياتاً } أي : في الليل بغتة كما يفعل العدوّ { أو نهاراً } أي : وقت أنتم فيه تشتغلون بطلب المعاش والكسب { ماذا } أي : أيّ شيء { يستعجل منه } أي : من عذابه وعذاب كل مكروه لا يحتمل شيء منه { المجرمون } أي : المشركون ،   وضع المجرمون موضع المضمر للدّلالة على أنهم لجرمهم ينبغي أن يفزعوا من مجيء الوعيد لا أن يستعجلوا ،   وجملة الاستفهام متعلقة بأرأيتم ،   وجواب الشرط محذوف وهو تندموا على الاستعجال أو تعرفوا الخطأ فيه .  <br />
