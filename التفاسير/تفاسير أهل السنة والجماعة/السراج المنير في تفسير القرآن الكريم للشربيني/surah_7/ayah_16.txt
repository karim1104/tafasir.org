{ قال } أي : إبليس { فبما أغويتني } أي : فبإغوائك لي والباء للقسم أي : أقسم بإغوائك وجوابه { لأقعدنّ لهم } أي : لبني آدم { صراطك المستقيم } أي : على الطريق الموصل إليك وإنما أقسم بالإغواء لأنه كان تكليفاً والتكليف من أحسن أفعال الله تعالى لكونه تعريضاً لسعادة الأبد فكان جديراً لأن يقسم به ويجوز أن تتعلق الباء بفعل القسم المحذوف تقديره : فبما أغويتني أقسم بالله لأقعدنّ أي : فبسبب إغوائك أقسم .  <br />
