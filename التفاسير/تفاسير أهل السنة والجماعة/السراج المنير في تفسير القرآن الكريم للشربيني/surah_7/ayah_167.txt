{ وإذا } عطف على واسألهم أي : واذكر لهم حين { تأذن } أي : اعلم { ربك } وأجري مجرى القسم كعلم الله وشهد الله ولذلك أجيب بجوابه وهو { ليبعثن عليهم } أي : اليهود { إلى يوم القيامة من يسومهم سوء العذاب } أي : بالإهانة والذل وأخذ الجزية منهم فبعث الله تعالى عليهم سليمان وبعده بختنصر فقتلهم وسباهم وضرب عليهم الجزية ،   وكانوا يؤدونها إلى المجوس إلى أن بعث الله تعالى نبينا محمداً صلى الله عليه وسلم فضربها عليهم ولا تزال مضروبة عليهم إلى آخر الدهر حتى ينزل عيسى بن مريم فإنه لا يقبل الجزية ولا يقبل إلا الإسلام .  <br />
فإن قيل : إنه يحكم بشريعة نبينا محمد صلى الله عليه وسلم وشريعته أخذ الجزية أو الإسلام أجيب : بأنّ شريعته بذلك مغياة بنزول عيسى عليه السلام وقوله تعالى : { إنّ ربك سريع العقاب } أي : لمن أقام على الكفر كهيئة الدليل على أنه يجمع لهم مع ذل الدنيا عذاب الآخرة فيكون العذاب مستمراً عليهم في الدنيا والآخرة ،   ثم إنه تعالى ختم الآية بقوله : { وإنه لغفور } أي : لمن آمن منهم ورجع عن الكفر واليهودية ودخل في دين الإسلام { رحيم } بهم .  <br />
