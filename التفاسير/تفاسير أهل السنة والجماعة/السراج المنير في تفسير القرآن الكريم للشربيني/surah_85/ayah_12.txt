{ إنّ بطش ربك } أي : أخذ المحسن إليك المربي لك المدبر لأمرك الجبابرة والظلمة { لشديد } كقوله تعالى : { وكذلك أخذ ربك إذا أخذ القرى وهي ظالمة إنّ أخذه أليم شديد } [ هود : 102 ] قال المبردّ : { إنّ بطش ربك } جواب القسم ،   والبطش هو الأخذ بعنف فإذا وصف بالشدّة فقد تضاعف .   ولما كان هذا البطش لا يتأتى إلا لكامل القدرة دل على كمال قدرته واختصاصه بذلك بقوله تعالى مؤكداً لما له من الإنكار : { إنه هو يبدئ ويعيد } .
