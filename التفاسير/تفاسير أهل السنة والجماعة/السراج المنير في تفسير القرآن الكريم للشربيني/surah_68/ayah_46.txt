{ أم تسألهم } أي : أنت يا أعف الخلق وأعلاهم همماً { أجراً } على تبليغ الرسالة { فهم } أي : فتسبب عن ذلك وتعقب أنهم { من مغرم } أي : غرامة كلفتهم بها { مثقلون } أي : ثقل حمل الغرامات عليهم في بذل المال فثبطهم ذلك عن الإيمان .   والمعنى : ليس عليهم كلفة في متابعتك بل يستولون بالإيمان على خزائن الأرض ويصلون إلى جنات النعيم .  <br />
