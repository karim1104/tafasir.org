ويقال لهم عند دخولهم النار بأتباعهم : { هذا فوج } أي : جمع كثيف { مقتحم } أي : داخل ومفعوله محذوف أي : مقتحم النار { معكم } بشدة ،   فيقول المتبوعون : { لا مرحباً بهم } أي : لاسعة عليهم أو لا سمعوا مرحباً وقولهم : { إنهم صالو النار } أي : داخلون النار بأعمالهم مثلنا تعليل لاستجابة الدعاء عليهم ونظير هذه الآية قوله تعالى : { كلما دخلت أمة لعنت أختها } ( الأعراف : 38 ) وقال الكلبي : إنهم يضربون بالمقامع حتى يوقعوا أنفسهم في النار خوفاً من تلك المقامع .
