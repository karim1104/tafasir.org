ثم علل الإنذار بقوله تعالى : { ذكرى } أي : تنبيهاً عظيماً على ما فيه النجاة ،   أو جعل المنذرين نفس الذكرى ،   كما قال تعالى { قد أنزلنا إليكم ذكراً ( 10 ) رسولاً } ( الطلاق : 10 - 11 ) وذلك إشارة إلى إمعانهم في التذكير حتى صاروا إياه { وما كنا ظالمين } أي : في إهلاك شيء منها لأنهم كفروا نعمتنا وعبدوا غيرنا بعد الإعذار إليهم ومتابعة الحجج ومواصلة الوعيد .  <br />
تنبيه : الواو في قوله : { وما كنا } واو الحال من نون أهلكنا فإن قيل : كيف عزلت الواو عن الجملة بعد إلا ولم تعزل عنها في قوله تعالى : { وما أهلكنا من قرية إلا ولها كتاب معلوم } ؟ ( الحجر : 4 ) أجيب : بأنّ الأصل عزل الواو لأنّ الجملة صفة لقرية وإذا زيدت فلتأكيد وصل الصفة بالموصوف كما في قوله تعالى : { سبعة وثامنهم كلبهم } ( الكهف : 22 ) .
