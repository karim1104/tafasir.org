{ لا يستطيعون } أي : الآلهة المتخذة { نصرهم } أي : العابدين { وهم } أي : العابدون { لهم } أي : للآلهة { جند محضرون } أي : الكفار جند الأصنام فيغضبون لها ويحضرونها في الدنيا وهي لا تسوق لهم خيراً ولا تستطيع لهم نصراً ،   وقيل : هذا في الآخرة يؤتى بكل معبود من دون الله تعالى ومعه أتباعه الذين عبدوه كأنهم جنده يحضرون في النار وهذا كقوله تعالى : { إنكم وما تعبدون من دون الله حصب جهنم } ( الأنبياء : 98 ) وقوله تعالى : { احشروا الذين ظلموا وأزواجهم وما كانوا يعبدون ( 22 ) من دون الله فاهدوهم إلى صراط الجحيم } ( الصافات : 22  23 ) .
