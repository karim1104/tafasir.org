ثم بين الله تعالى الأقل الناجي ؛ لأنه المقصود بالذات بقوله تعالى : { إنما تنذر } أي : إنذاراً ينفع المنذر فتتأثر عنه النجاة { من اتبع الذكر } أي : القرآن بالتأمل فيه والعمل به { وخشي الرحمان } أي : خاف عقابه { بالغيب } أي : قبل موته ومعاينة أهواله أو في سريرته ولا يغتر برحمته فإنه تعالى كما هو رحمن رحيم منتقم جبار { فبشّره } أي : بسبب خشيته بالغيب { بمغفرة } أي : لذنوبه وإن عظمت وتكررت .  <br />
ولما حصل العلم بمحو الذنوب عينها وأثرها قال تعالى { وأجر كريم } أي : هو الجنة فإنها دار لا كدر فيها بوجه ،   والمقصود منها هو النظر لوجهه الكريم ،   اللهم متعنا ومحبينا بالنظر إلى وجهك الكريم .  <br />
