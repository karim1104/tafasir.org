{ وتكون الجبال } على ما هي عليه من الشدّة والصلابة ،   وأنها صخور راسخة { كالعهن } أي : الصوف المصبوغ ألواناً ؛ لأنها ملوّنه قال تعالى : { ومن الجبال جدد بيض وحمر } [ فاطر : 27 ] أي : وغير ذلك { المنفوش } أي : المندوف المفرّق الأجزاء ،   فتراها لذلك متطايرة في الجوّ كالهباء المنثور ،   كما قال تعالى في موضع آخر : { هباءً منبثاً } [ الواقعة : 6 ] حتى تعود الأرض كلها لا عوج فيها ولا أمّتا .
