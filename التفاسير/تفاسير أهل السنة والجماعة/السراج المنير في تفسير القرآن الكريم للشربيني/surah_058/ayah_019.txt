{ استحوذ } أي : استولى { عليهم الشيطان } مع أنه طريد ومحترق  ،  ووصل منهم إلى ما يريده وملكهم ملكاً لم يبق لهم معه اختيار فصاروا رعيته وصار هو محيطاً بهم من كل جهة غالباً عليهم  ،   ظاهراً وباطناً من قولهم حذت الإبل وحذذتها إذا استوليت عليها ،   والحوذ أيضاً : السوق السريع ومنه الأحوذي الخفيف في الشيء لحذقه ،   واستحوذ مما جاء على الأصل وهو ثبوت الواو دون قلبها ألفاً  ،  { فأنساهم } أي : فتسبب عن استحواذه عليهم أن أنساهم { ذكر الله } أي : الذي له الأسماء الحسنى والصفات العليا  ،  { أولئك } أي : البعداء البغضاء { حزب الشيطان } أي : أتباعه وجنوده وطائفته وأصحابه  ،  { ألا إنّ حزب الشيطان } أي : الطريد المحترق{ هم الخاسرون } أي : العريقون في هذا الوصف ؛ لأنهم لم يظفروا بغير الطرد والاحتراق .  <br />
