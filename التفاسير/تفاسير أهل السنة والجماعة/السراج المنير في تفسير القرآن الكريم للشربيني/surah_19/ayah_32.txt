الصفة السادسة قوله : { وبرّا } أي : وجعلني بارا ولما كان السياق لبراءة والدته قال : { بوالدتي } أي : التي أكرمها الله تعالى بإحصان الفرج والحمل بي من غير ذكر وفي ذلك إشارة إلى تنزيه أمّه عن الزنا إذ لو كانت زانية لما كان الرسول المعصوم مأموراً بتعظيمها .  <br />
الصفة السابعة : قوله : { ولم يجعلني جباراً } متعاظماً { شقياً } أي : عاصياً بأن أفعل فعل الجبارين بغير استحقاق إنما أفعل ذلك بمن يستحق وروي عن عيسى عليه السلام أنه قال قلبي لين وإني ضعيف في نفسي وعن بعض العلماء لا أجد العاق إلا جباراً شقياً ولا أجد سيء الملكة إلا مختالاً فخوراً وتلا { وما ملكت أيمانكم أنّ الله لا يحب من كان مختالاً فخوراً } [ النساء : 36 ] .
