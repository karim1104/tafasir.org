وقوله تعالى : { وتلك } مبتدأ وقوله تعالى : { القرى } أي : الماضية من عاد وثمود ومدين وقوم لوط وأشكالهم صفته لأنّ أسماء الإشارة توصف بأسماء الأجناس والخبر { أهلكناهم } والمعنى وتلك أصحاب القرى أهلكناهم { لما ظلموا وجعلنا لمهلكهم موعداً } أي : وقتاً معلوماً لا يستأخرون عنه ساعة ولا يستقدمون ،   وقرأ شعبة بفتح الميم واللام أي : لهلاكهم ،   وقرأ حفص بفتح الميم وكسر اللام والباقون بضم الميم وفتح اللام أي : لإهلاكهم ،   ثم عطف سبحانه وتعالى على قوله تعالى : { وإذ قلنا للملائكة } [ الكهف ،   50 ] .
