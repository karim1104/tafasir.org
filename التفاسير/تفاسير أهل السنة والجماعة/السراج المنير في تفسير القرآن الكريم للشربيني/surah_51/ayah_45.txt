{ فما } أي : فتسبب عن ذلك أنهم ما { استطاعوا } أي : تمكنوا ،   وأكد النفي بقوله تعالى : { من قيام } أي : فما قاموا بعد نزول العذاب وما قدروا على نهوض ،   قال قتادة : لم ينهضوا من تلك الصرعة كقوله تعالى : { فأصبحوا في ديارهم جاثمين } [ الأعراف : 78 ] وقيل : هو من قولهم ما يقوم به إذا عجز عن دفعه { وما كانوا } أي : كوناً ما { منتصرين } أي : لم يكن فيهم أهلية الانتصار بوجه لا بأنفسهم ولا بناصر ينصرهم فيطاوعونه في النصرة ،   لأن تهيؤهم لذلك سقط بكل اعتبار .
