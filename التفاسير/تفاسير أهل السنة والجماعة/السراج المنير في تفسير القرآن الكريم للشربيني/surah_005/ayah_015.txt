وقوله تعالى : { يا أهل الكتاب } خطاب لليهود والنصارى ووحد الكتاب لأنه للجنس { قد جاءكم رسولنا } وهو أفضل الخلق محمد صلى الله عليه وسلم { يبين لكم } أي : يوضح إيضاحاً شافياً { كثيراً مما كنتم تخفون } أي : تكتمون { من الكتاب } أي : التوراة والإنجيل كنعت محمد صلى الله عليه وسلم وآية الرجم في التوراة وبشارة عيسى وأحمد في الإنجيل { ويعفو عن كثير } أن مما تخفونه فلا يبينه إذا لم يكن فيه مصلحة في أمر ديني أو عن كثير منكم فلا يؤاخذه بجرمه { قد جاءكم من الله نور } هو محمد صلى الله عليه وسلم الذي جلا ظلمات الشك والشرك { وكتاب } هو القرآن العظيم { مبين } أي : بين في نفسه مبين لما كان خافياً على الناس من الحق .  <br />
