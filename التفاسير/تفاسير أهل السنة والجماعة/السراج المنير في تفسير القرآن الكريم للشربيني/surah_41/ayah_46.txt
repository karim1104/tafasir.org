ثم قال تعالى لنبيه صلى الله عليه وسلم : { من عمل صالحاً } أي : كائناً من كان { فلنفسه } أي : فنفع عمله لها لا لأحد يتعداها والنفس فقيرة إلى التزكية بالأعمال الصالحة لأنها محل النقائص فلذا عبر بها { ومن أساء } في عمله { فعليها } أي : على نفسه خاصة ليس عليك منه شيء فخفف عن نفسك إعراضهم فإنهم إن آمنوا فنفع إيمانهم يعود إليهم ،   وإن كفروا فضرر كفرهم يعود إليهم ،   والله سبحانه وتعالى يوصل إلى كل أحد ما يليق به من الجزاء { وما ربك } أي : المحسن إليك بإرسالك لتتميم مكارم الأخلاق { بظلام } أي : بذي ظلم { للعبيد } أي : هذا الجنس فلا يتصور أن يقع ظلم لأحد منهم أصلاً لأن له الغنى المطلق والحكمة البالغة .  <br />
