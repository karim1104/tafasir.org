ولما جمعهم الله فيما اجتمعوا فيه حتى كأنهم تواصوا به ،   فصّلهم وفصّل ما اختلفوا فيه فقال مسبباً عما مضى من مقالاتهم : { فأما عاد } أي : قوم هود عليه السلام { فاستكبروا } أي : طلبوا الكبر وأوجدوه { في الأرض } أي : كلها التي كانوا فيها بالفعل وغيرها بالقوة أو في الكل بالفعل لكونهم ملكوها كلها ،   ثم بين كبرهم أنه { بغير الحق } أي : الذي لم يطابق الواقع ،   ثم ذكر تعالى سبب الاستكبار بقوله تعالى : { وقالوا من أشد منا قوة } وذلك أن هوداً عليه السلام هددهم بالعذاب ،   فقالوا : نحن نقدر على دفع العذاب بفضل قوتنا ،   وكانوا ذوي أجسام طوال طول الطويل منهم أربعمائة ذراع كما سيأتي في سورة الفجر .   قال الله تعالى رداً عليهم : { أولم يروا } أي : يعلموا علماً هو كالمشاهدة { أن الله } أي : المحيط بكل شيء قدرة وعلماً { الذي خلقهم } ولم يكونوا شيئاً { هو أشد منهم قوة } ومن علم أن غيره أقوى منه وكان عاقلاً انقاد له فيما ينفعه ولا يضره ،   وقوله تعالى : { وكانوا بآياتنا يجحدون } أي : يعرفون أنها حق وينكرونها ،   عطف على فاستكبروا .  <br />
