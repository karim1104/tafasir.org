ثم أمر الله تعالى نبيه محمداً صلى الله عليه وسلم بقوله تعالى : { قل } أي : لهؤلاء المعرضين { أرأيتم } أي : أخبروني { إن كان } أي : هذا القرآن { من عند الله } الذي له الإحاطة بجميع صفات الجلال والجمال { ثم كفرتم به } أي : من غير نظر واتباع دليل { من أضل } منكم هكذا كان الأصل ولكنه قال : { ممن هو في شقاق } أي : خلاف لأولياء الله تعالى { بعيد } أي : عن الحق تنبيها على أنهم صاروا كذلك ومن صار كذلك فقد عرض نفسه لسطوات الله عز وجل .  <br />
