{ وقالوا } أي : كثير من أهل الكتاب من اليهود والنصارى { لن يدخل الجنة إلا من كان هوداً } جمع هائد كعائد وعود { أو نصارى } قال ذلك يهود المدينة ونصارى نجران لما تناظروا بين يدي النبيّ صلى الله عليه وسلم أي قالت اليهود : لن يدخل الجنة إلا اليهود ولا دين إلا دين اليهودية ،   وقالت النصارى : لن يدخل الجنة إلا النصارى ولا دين إلا دين النصرانية ،   فجمع الله بين القولين ثقة بأنّ السامع يرد إلى كلّ فريق قوله وأمنا من الإلباس لما علم من التعادي بين الفريقين وتضليل كلّ واحد منهما لصاحبه ونحوه { تلك } أي : القولة { أمانيهم } أي : شهواتهم الباطلة التي تمنوها على الله تعالى بغير حق { قل } لهم يا محمد { هاتوا برهانكم } أي : حجتكم على اختصاصكم بدخول الجنة { إن كنتم صادقين } في دعواكم إذ كل قول لا دليل عليه فهو غير صحيح وهذا متصل بقولهم : لن يدخل الجنة إلا من كان هوداً أو نصارى وتلك أمانيهم اعتراض .  <br />
