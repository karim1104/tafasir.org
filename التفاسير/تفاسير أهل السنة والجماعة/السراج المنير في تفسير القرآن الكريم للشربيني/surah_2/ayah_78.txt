{ ومنهم } أي : اليهود { أمّيون } أي : عوام جهلة { لا يعلمون الكتاب } أي : لا يعرفون التوراة أو الكتابة فيطالعوا التوراة ويتحققوا ما ،   فيها ،   وقوله تعالى : { إلا أمانيّ } استثناء منقطع ،   أي : لكن أكاذيب تلقوها من رؤسائهم فاعتمدوها { وإن هم } أي : ما هم { إلا } قوم { يظنون } ظناً لا علم لهم وقد يطلق الظنّ بإزاء العلم على كل رأي واعتقاد من غير قاطع وإن جزم به صاحبه كاعتقاد المقلد وكالزائغ عن الحق بسبب شبهة قامت عنده .  <br />
