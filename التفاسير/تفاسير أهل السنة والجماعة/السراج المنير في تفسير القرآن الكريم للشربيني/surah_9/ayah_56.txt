ولما بين تعالى كون المنافقين مستجمعين لكل مضار الدنيا والآخرة خالين عن جميع منافع الآخرة والدنيا عاد إلى ذكر فضائحهم وقبائحهم فمنها إقدامهم على الأيمان الكاذبة كما قال تعالى :<br />
{ ويحلفون } أي : المنافقون { بالله } للمؤمنين إذا جاؤوا معهم { إنهم لمنكم } أي : على دينكم وملتكم { وما هم منكم } أي : لكفر قلوبهم { ولكنهم قوم يفرقون } أي : يخافون منكم أن تفعلوا بهم ما تفعلوا بالمشركين فيظهرون الإسلام تقية .  <br />
