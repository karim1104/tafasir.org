{ ومن يفعل ذلك } أي : ما نهى عنه من قتل النفس وغيره من المحرمات ،   وقوله تعالى : { عدواناً } حال أي : متجاوزاً للحلال وقوله تعالى : { وظلماً } تأكيد وقيل : أراد بالعدوان التعدّي على الغير وبالظلم ظلم الشخص نفسه بتعريضها للعقاب { فسوف نصليه } أي : ندخله { ناراً } يحترق فيها { وكان ذلك على الله يسيراً } أي : هيناً لا عسر عليه فيه .  <br />
