ولما ذكر ضلالهم بالإرادة ورغبتهم في التحاكم إلى الطاغوت ذكر فعلهم فيه في نفرتهم عن التحاكم إلى رسول الله صلى الله عليه وسلم فقال :<br />
{ وإذا قيل لهم } أي : من أي قائل كان ،   وقرأ هشام والكسائي بضم القاف والباقون بالكسر وتقدّم ذكر الإدغام لأبي عمرو { تعالوا } أي : أقبلوا رافعين أنفسكم من وهاد الجهل إلى شرف العلم { إلى ما أنزل الله } أي : الذي عنده كل شيء { وإلى الرسول } أي : الذي تجب طاعته لأجل مرسله مع إنه أكمل الرسل الذين هم أكمل الخلق رسالة { رأيت المنافقين يصدون } أي : يعرضون { عنك } إلى غيرك وأكد ذلك بقوله : { صدوداً } أي : هو أعلى طبقات الصدود .  <br />
