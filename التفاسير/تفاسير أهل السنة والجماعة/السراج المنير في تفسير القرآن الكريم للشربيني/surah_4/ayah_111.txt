{ ومن يكسب إثماً } أي : ذنباً { فإنما يكسبه على نفسه } أي : لأنّ وباله راجع عليه إذ الله له بالمرصاد فهو مجازية عليه فلا يتعدّاه وباله قال تعالى : { وإن أسأتم فلها } ( الإسراء ،   7 ) .  <br />
{ وكان الله عليماً } بالغ العلم بدقيق ذلك وجليله فلا يترك شيئاً منه { حكيماً } في صنعه فلا يجازيه إلا بمقدار ذنبه .
