وقوله تعالى :<br />
{ الذين } بدل أو نعت للمنافقين { يتخذون الكافرين أولياء من دون المؤمنين } لما يتوهمون فيهم من القوّة وقوله تعالى : { أيبتغون } أي : أيطلبون { عندهم العزة } استفهام إنكاري أي : لا يجدونها عندهم { فإن العزة لله جميعاً } في الدنيا والآخرة ولا ينالهما إلا أولياؤه قال الله تعالى : { ولله العزة ولرسوله وللمؤمنين } ( المنافقون ،   8 ) .
