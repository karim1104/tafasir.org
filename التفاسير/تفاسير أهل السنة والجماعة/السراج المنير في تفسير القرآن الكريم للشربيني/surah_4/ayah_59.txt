{ يا أيها الذين آمنوا } أي : أقروا بالإيمان ،   وبدأ بما هو العمدة في الحمل على ذلك فقال : { أطيعوا الله } أي : فيما أمركم به { وأطيعوا الرسول } أي : فيما بينه لكم { و } أطيعوا { أولي } أي : أصحاب { الأمر } أي : الولاة { منكم } أي : إذا أمروكم بإطاعة الله ورسوله ،   وسواء كان ذلك في عهد رسول الله صلى الله عليه وسلم أم بعده ،   ويندرج فيهم الخلفاء والقضاة وأمراء السرية .  <br />
روي أنه صلى الله عليه وسلم قال : ( السمع والطاعة على المرء فيما أحب وكره ما لم يؤمر بمعصية فلا سمع ولا طاعة ) .  <br />
وروي أنه صلى الله عليه وسلم خطب في حجة الوداع فقال : ( اتقوا الله وصلوا رحمكم وصلوا خمسكم وصوموا شهركم وأدّوا زكاة أموالكم وأطيعوا إذا أمركم تدخلوا جنة ربكم ) .   وقيل : ( المراد بأولي الأمر أبو بكر وعمر لقوله صلى الله عليه وسلم : ( اقتدوا باللذين من بعدي أبي بكر وعمر ) وقال عطاء هم المهاجرون والأنصار والتابعون لهم بإحسان بدليل قوله تعالى : { والسابقون الأوّلون من المهاجرين والأنصار والذين اتبعوهم بإحسان } ( التوبة ،   100 ) .  <br />
روي أنه صلى الله عليه وسلم قال : ( مثل أصحابي وأمّتي كالملح في الطعام ولا يصلح الطعام إلا بالملح ) ،   قال الحسن : فقد ذهب ملحنا فكيف نصلح وقيل : المراد علماء الشرع لقوله تعالى : { ولو ردّوه إلى الرسول وإلى أولي الأمر منهم لعلمه الذين يستنبطونه منهم } ( النساء ،   83 ) .  <br />
{ فإن تنازعتم } أي : اختلفتم { في شيء فردوه إلى الله } أي : كتابه { والرسول } أي : مدّة حياته وبعد وفاته إلى سنته أي : اكشفوا عليه منهما والردّ إلى الكتاب والسنة واجب إن وجد فيهما ،   فإن لم يوجد فسبيله الاجتهاد .   وقيل : الرد إلى الله والرسول أن يقول لما لا يعلم : الله ورسوله أعلم { إن كنتم تؤمنون بالله واليوم الآخر } أي : فإن الإيمان يوجب هذا { ذلك } أي : من الردّ إليهما { خير } لكم من التنازع والقول بالرأي { وأحسن تأويلاً } أي : تأويلكم بلا رد أو عاقبة .
