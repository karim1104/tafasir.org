ثم استثنى أهل العذر منهم فقال :<br />
{ إلا المستضعفين } أي : الذين وجد ضعفهم في نفس الأمر وعدّوا ضعفاء وتقوّى عليهم غيرهم { من الرجال والنساء والولدان } ثم بين ضعفهم بقوله : { لا يستطيعون حيلة } أي : لا قوّة لهم على الهجرة ولا نفقة لهم { ولا يهتدون سبيلاً } أي : طريقاً إلى أرض الهجرة .  <br />
