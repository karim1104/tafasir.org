{ إن } أي : ما { يدعون } أي : يعبد المشركون { من دونه } أي غير الله { إلا إناثاً } وهي اللات والعزى ومناة ،   وعن الحسن لم يكن حيّ من أحياء العرب إلا ولهم صنم يعبدونه ويسمونه أنثى بني فلان ،   وقيل : كانوا يقولون في أصنامهم هنّ بنات الله ،   وقيل : المراد الملائكة لقولهم : الملائكة بنات الله { وإن } أي ما { يدعون } أي يعبدون بعبادتها { إلا شيطاناً مريداً } أي : خارجاً عن الطاعة وهو إبليس ؛ لأنه الذي أمرهم بعبادتها وأغراهم عليها ،   فكانت طاعته في ذلك عبادة له .  <br />
