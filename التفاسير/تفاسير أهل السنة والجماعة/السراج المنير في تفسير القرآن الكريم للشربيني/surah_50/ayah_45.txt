وقوله تعالى : { نحن أعلم } أي : عالمون { بما يقولون } أي : في الحال والاستقبال من التكذيب بالبعث وغيره تسلية النبي صلى الله عليه وسلم وتهديد لهم { وما أنت عليهم بجبار } أي : بمسلط تجبرهم على الإسلام إنما أنت منذر وقد فعلت ما أمرت به ونحن القادرون على ردهم بما لنا من العلم المحيط وهذا قبل الأمر بالقتال { فذكر } أي : بطريق البشارة والنذارة { بالقرآن } أي : الجامع بمجده لكل خير المحيط بكل صلاح { من يخاف وعيد } فإنه لا ينتفع به غيره وهم المؤمنون .   وقرأ ورش بإثبات الياء بعد الدال وصلاً لا وقفاً وحذفها الباقون وصلا ووقفاً .  <br />
