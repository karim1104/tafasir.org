{ ويقول الذين كفروا } من أهل مكة { لولا } ،   أي : هلا { أنزل عليه } ،   أي : على هذا الرسول { آية } ،   أي : علامة بينة { من ربه } ،   أي : المحسن إليه ،   كالعصا واليد لموسى والناقة لصالح لنهتدي بها فنؤمن به وأمره الله تعالى أن يجيبهم بقوله : { قل } ،   أي : لهؤلاء المعاندين { إن الله يضل من يشاء } إضلاله فلا تغني عنه الآيات شيئاً وإن أنزلت كل آية { ويهدي } ،   أي : يرشد { إليه } ،   أي : إلى دينه { من أناب } ،   أي : رجع إليه كأبي بكر الصديق وغيره ممن تبعه من العشرة المشهود لهم بالجنة وغيرهم ولو حصلت آية واحدة فلا تشتغلوا بطلب الآيات ولكن تضرعوا إلى الله تعالى في طلب الهداية .  <br />
