{ فمن يعمل } أي : منهم الآن { من الصالحات وهو } أي : والحال أنه { مؤمن } أي : يأتي بعمله على الأساس الصحيح { فلا كفران } أي : لا جحود { لسعيه } بل يشكر ويثاب عليه .  <br />
تنبيه : قوله تعالى : فلا كفران نفى الجنس ليكون أبلغ من أن يقول : فلا نكفر سعيه { وإنّا له } أي : لسعيه { كاتبون } أي : مثبتون في صحيفة عمله وما أثبتناه فهو غير ضائع فلا يفقد منه شيئاً قل أو جل ،   ومن المعلوم أنّ قسيمه وهو من يعمل من السيئات وهو كافر ،   فلا نقيم له وزناً ،   ومن يعمل منها وهو مؤمن فهو تحت مشيئتنا قال البقاعيّ : ولعله حذف هذين القسمين ترغيباً في الإيمان .  <br />
