وذكر الفريقين لأنّ صدر الكلام وسياقه للمشركين ،   وإنما ذكر المؤمنين وثوابهم بقوله :  { فالذين آمنوا } أي : أقرّوا بالإيمان { وعملوا } أي : تصديقاً لدعواهم تلك { الصالحات لهم مغفرة } أي : لما فرط منهم { ورزق } أي : في الدنيا بالغنائم وغيرها ،   وفي الآخرة بما لا عين رأت ولا أذن سمعت ولا خطر على قلب بشر { كريم } أي : لا خسة فيه ولا دناءة بانقطاع ولا غيره زيادة في غيظهم .  <br />
