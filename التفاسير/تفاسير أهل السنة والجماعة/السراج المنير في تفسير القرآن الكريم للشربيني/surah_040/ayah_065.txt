ثم نبه تعالى بقوله سبحانه : { هو الحي } بما يفيد الحصر بأنه لا حي على الدوام إلا هو ثم نبه تعالى على وحدانيته بقوله سبحانه : { لا إله إلا هو } ثم أمر العباد بالإخلاص في الدعاء فقال تعالى : { فادعوه } أي : اعبدوه { مخلصين له الدين } أي : من كل شرك جلي أو خفي .  <br />
ولما كان تعالى موصوفاً بصفات الجلال والعزة استحق لذاته أن يقال له : { الحمد } أي : الإحاطة بأوصاف الكمال { لله } أي : المسمى بهذا الاسم الجامع لمجامع معاني الأسماء الحسنى { رب العالمين } أي : الذي رباهم هذه التربية ،   وقال الفراء : هو خبر وفيه إضمار الأمر ومجازه فادعوه واحمدوه ،   وعن ابن عباس رضي الله عنهما : من قال لا إله إلا الله فليقل : على أثرها الحمد لله رب العالمين .  <br />
