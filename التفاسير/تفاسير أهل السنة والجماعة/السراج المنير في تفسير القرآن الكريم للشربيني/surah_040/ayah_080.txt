ولما كان التصرف فيها غير منضبط أجمله بقوله تعالى : { ولكم فيها } أي : كلها { منافع } أي : كثيرة بغير ذلك من الدر والوبر والصوف وغيرها { ولتبلغوا عليها } وهي في غاية الذل والطواعية ونبههم على نقصهم وعظم نعمته عليهم بقوله تعالى : { حاجة } أي : جنس الحاجة ،   وقوله تعالى : { في صدوركم } إشارة إلى أن حاجة واحدة ضاقت عنها قلوب الجميع حتى فاضت منها فملأت مساكنها { وعليها } أي : الإبل في البر { وعلى الفلك } أي : في البحر { تحملون } أي : تحملون أمتعتكم الثقيلة من مكان إلى مكان آخر وأما حمل الإنسان نفسه فقد مر بالركوب ،   فإن قيل : لِمَ لم يقل وفي الفلك كما قال تعالى في سورة هود : { قلنا احمل فيها من كل زوجين اثنين } ( هود : 40 )<br />
أجيب : بأن كلمة على للاستعلاء فالشيء الذي يوضع على الفلك كما صح أن يقال وضع فيه صح أن يقال وضع عليه ،   ولما صح الوجهان كانت لفظة على أولى حتى تتم المزاوجة في قوله تعالى { وعليها وعلى الفلك تحملون } ( المؤمنون : 22 ) وقال بعضهم : أن لفظ فيها هناك أليق لأن سفينة نوح عليه السلام كما قيل مطبقة عليهم وهي محيطة بهم كالوعاء وأما غيرها فالاستعلاء فيه واضح لأن الناس على ظهرها .
