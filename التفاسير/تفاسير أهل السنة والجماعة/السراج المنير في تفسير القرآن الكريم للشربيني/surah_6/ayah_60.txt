{ وهو الذي يتوفاكم بالليل } أي : يقبض أرواحكم عند النوم { ويعلم ما جرحتم } أي : كسبتم { بالنهار ثم يبعثكم } أي : يوقظكم بردّ أرواحكم { فيه } أي : النهار .  <br />
فإن قيل : لِمَ خص الليل بالنوم والنهار بالكسب مع أنّ ذلك يقع في غير هذا ؟ أجيب : بأنّ ذلك جرى على الغالب { ليقضي أجل مسمى } أي : ليبلغ المستيقظ آخر أجله المسمى له في الدنيا { ثم إليه مرجعكم } بالموت والبعث { ثم ينبئكم بما كنتم تعملون } فيجازيكم به .  <br />
