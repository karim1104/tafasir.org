{ أولئك الذين آتيناهم الكتاب } أي : أولئك الذين سميناهم من الأنبياء وهم ثمانية عشر نبياً أعطيناهم الكتاب فالمراد بالكتاب الجنس { والحكم } أي : العمل المتقن بالعلم { والنبوّة } أي : وشرّفناهم بالنبوّة والرسالة { فإن يكفر بها } أي : بهذه الثلاثة { هؤلاء } أي : أهل مكة الذين أنت بين أظهرهم { فقد وكلنا بها } أي : وفقنا للإيمان بها والقيام بحقوقها { قوماً ليسوا بها بكافرين } كما يوكل الرجل بالشيء ليقوم به ويتعهده ويحافظ عليه ،   واختلف في ذلك القوم فقال ابن عباس : هم الأنصار وأهل المدينة ،   وقال الحسن وقتادة : هم الأنبياء الثمانية عشر الذين تقدّم ذكرهم واختاره الزجاج .  <br />
