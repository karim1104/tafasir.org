{ وهو الذي جعل } أي : خلق { لكم النجوم لتهتدوا بها في ظلمات البرّ والبحرّ } أي : في ظلمات الليل في البرّ والبحر وإضافتها إليهما للملابسة أو في مشتبهات الطرق وسماها ظلمات على الاستعارة وهو إفراد لبعض منافعها بالذكر بعدما أجملها بقوله : لكم ،   ومن منافعها أنها زينة للسماء كما قال تعالى : { ولقد زينا السماء الدنيا بمصابيح } ( الملك : 5 ) ومنها رمي الشياطين كما قال تعالى : { وجعلناها رجوماً للشياطين } ( الملك ،   5 ) .  <br />
{ قد فصلنا } أي : بينا { الآيات } أي : الدالات على قدرتنا وتوحيدنا { لقوم يعلمون } أي : يتدبرون فإنهم المنتفعون به .
