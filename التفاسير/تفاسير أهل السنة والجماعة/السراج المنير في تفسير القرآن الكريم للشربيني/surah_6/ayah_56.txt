{ قل } يا محمد لهؤلاء المشركين { إني نهيت أن أعبد الذين تدعون } أي : تعبدون { من دون الله } وهي الأصنام التي يعبدونها أو ما تدعونها آلهة أي : تسمونها لأنّ الجمادات أخس من أن تدعى وقوله تعالى : { قل لا أتبع أهواءكم } تأكيد لقطع أطماعهم وبيان لمبدأ ضلالهم وأنّ ما هم عليه هوى وليس بهدى { قد ضللت إذاً } أي : إن اتبعت أهواءكم فأنا ضال { وما أنا من المهتدين } أي : وما أنا من المهديين في شيء أي : لأنكم كذلك .  <br />
