{ لهم } أي : المتذكرين { دار السلام } هي الجنة وأضافها لنفسه في قول جميع المفسرين فإنّ السلام كما قال الحسن هو الله تعالى تشريفاً لهم أو { وتحيتهم فيها سلام } ( يونس ،   10 ) أو أراد بها دار السلامة { عند ربهم } أي : ذخيرة لهم عنده لا يعلم كنهها غيره { وهو وليهم } أي : المتكفل بتولي أمورهم ولا يكلهم إلى أحد سواه { بما } أي : بسبب ما { كانوا يعملون } من الأعمال الصالحة التي كانوا يتقرّبون بها إليه في الدنيا .
