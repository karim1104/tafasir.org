وقوله تعالى :<br />
{ ولو ترى } يا محمد { إذ وقفوا } أي : عرضوا { على النار } جوابه محذوف أي : لو تراهم حين يقفون على النار فيعرفون مقدار عذابها لرأيت أمراً شنيعاً { فقالوا } أي : الكفار { يا } للتنبيه { ليتنا نرد } أي : إلى الدنيا { ولا نكذب بآيات ربنا ونكون من المؤمنين } تمنوا أن يردّوا إلى الدنيا ولا يكذبوا بآيات ربهم ،   وقرأ حفص وحمزة بنصب الياء من نكذب على جواب التمني والباقون بالرفع على الاستئناف ،   وقرأ ابن عامر وحفص وحمزة بفتح النون من تكون على جواب التمني والباقون بالضمّ على العطف .  <br />
