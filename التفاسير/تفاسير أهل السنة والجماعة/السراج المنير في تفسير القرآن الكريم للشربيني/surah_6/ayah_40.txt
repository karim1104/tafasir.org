{ قل } يا محمد لأهل مكة ،   وقوله تعالى : { أرأيتكم } استفهام تعجيب والكاف حرف خطاب أي : أخبروني { إن أتاكم عذاب الله } أي : في الدنيا كما أتى من قبلكم من الغرق أو الخسف والمسخ والصواعق ونحو ذلك من العذاب { أو أتتكم الساعة } أي : القيامة المشتملة على العذاب { أغير الله تدعون } في كشف العذاب عنكم { إن كنتم صادقين } أنّ الأصنام آلهة وجواب الاستفهام محذوف أي : فادعوه وهو تبكيت لهم .  <br />
