{ وقالوا ما في بطون هذه الأنعام } أي : أجنة البحائر والسوائب وقوله تعالى : { خالصة } حلال { لذكرونا } أي : خاصة بهم دون الإناث كما قال تعالى : { ومحرم على أزواجنا } أي : النساء ،   وحذف الهاء من ( محرم ) إما حملاً على اللفظ أو تخفيفاً لأنّ المراد ب( خالصة ) المبالغة { وإن يكن } أي : ما في بطونها { ميتة فهم فيه شركاء } أي : الذكور والإناث فيه سواء أي : أنّ ما ولد منها حياً فهو للذكور دون الإناث وما ولد منها ميتاً أكله الذكور والإناث جميعاً ،   وقرأ ابن عامر وشعبة بالتأنيث في تكن والباقون بالتذكير ،   وقرأ ابن كثير وابن عامر ميتة بالرفع على أنّ تكن تامة والباقون بالنصب على أنها ناقصة { سيجزيهم } الله { وصفهم } أي : سيكافئهم على وصفهم بالكذب على الله تعالى بالتحليل والتحريم { إنه } أي : الله { حكيم } في صنعه { عليم } بخلقه .  <br />
