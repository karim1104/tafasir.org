{ فلما رأى أيديهم } ،   أي : الأضياف { لا تصل إليه } ،   أي : لا يمدّون أيديهم إليه { نكرهم } أي : أنكرهم وأنكر حالهم لامتناعهم من الطعام { وأوجس } ،   أي : أضمر في نفسه { منهم خيفة } ،   أي : خوفاً .   قال قتادة : وذلك أنهم كانوا إذا نزل بهم ضيف فلم يأكل من طعامهم ظنوا أنه لم يأت بخير وإنما جاء بشر .   { قالوا لا تخف } يا إبراهيم { إنا } ملائكة الله { أرسلنا إلى قوم لوط } بالعذاب وإنما لم نمد له أيدينا لأنا لا نأكل .  <br />
