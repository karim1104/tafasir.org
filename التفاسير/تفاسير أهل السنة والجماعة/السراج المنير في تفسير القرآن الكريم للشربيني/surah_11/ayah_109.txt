ولما شرح الله تعالى أقاصيص عبدة الأوثان ثم أتبعه بأحوال الأشقياء وأحوال السعداء شرح للرسول صلى الله عليه وسلم أحوال الكفار من قومه فقال :<br />
{ فلا تك } يا محمد { في مرية } ،   أي : شك { مما يعبد هؤلاء } المشركون من الأصنام أننا نعذبهم كما عذبنا من قبلهم ،   وهذه تسلية للنبيّ صلى الله عليه وسلم { ما يعبدون إلا كما يعبد آباؤهم } ،   أي : كعبادتهم { من قبل } وقد عذبناهم { وإنا لموفوهم } مثلهم { نصيبهم } ،   أي : حظهم من العذاب { غير منقوص } ،   أي : كاملاً غير ناقص .  <br />
