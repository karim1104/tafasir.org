{ إن في ذلك } أي : فيما ذكر في هذه السورة من الأساليب العجيبة والطرق الغريبة { لذكرى } أي : تذكيراً عظيماً جدّاً { لمن كان } أي : كوناً عظيماً { له قلب } أي عقل في غاية العظمة فهو بحيث يفهم ما يراه ويعتبر به ومن لم يكن كذلك فلا قلب له سليم بل له قلب لاه { أو ألقى السمع } أي : استمع الوعظ بغاية إصغائه حتى كأنه يرمي بشيء ثقيل من علو إلى سفل { وهو } أي : والحال أنه في حال إلقائه { شهيد } أي : حاضر بكليته فهو في غاية ما يكون من تصويب الفكر وجمع الخاطر فلا يغيب عنه شيء مما تلي عليه وألقي إليه فيتذكر .  <br />
