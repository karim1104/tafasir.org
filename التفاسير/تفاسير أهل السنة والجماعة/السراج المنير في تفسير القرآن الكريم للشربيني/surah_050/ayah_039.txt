{ فاصبر } يا أشرف الخلق { على ما يقولون } أي : اليهود وغيرهم من إنكار البعث والتشبيه وغير ذلك فإنّ من قدر على خلق العالم بلا إعياء قدر على البعث وغيره { وسبح } أي : أوقع التنزيه عن كل شائبة نقص ملتبساً { بحمد ربك } أي : بإثبات الإحاطة بجميع صفات الكمال للسيد المدبر المحسن إليك بجميع هذه البراهين التي خصك بها مفضلاً لك على جميع الخلق وقوله تعالى : { قبل طلوع الشمس وقبل الغروب } إشارة إلى طرفي النهار .  <br />
