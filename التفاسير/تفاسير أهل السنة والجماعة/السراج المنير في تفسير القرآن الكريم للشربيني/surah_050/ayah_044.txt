وقوله تعالى : { يوم } يدل من يوم قبله وما بينهما اعتراض .   وقرأ { تشقق الأرض } نافع وابن كثير وابن عامر بتشديد الشين والباقون بالتخفيف { عنهم } أي : مجاوزة لهم بعد أن كانوا في بطنها فيخرجون منها أحياء كما كانوا على ظهرها أحياء حال كونهم { سراعاً } أي : إجابة منادينا وهو جمع سريع وأشار إلى عظمة الأمر بقوله تعالى { ذلك } أي : الإخراج العظيم جدّاً { حشر } أي : جمع بكره وزاد في بيان عظمة هذا الأمر بدلالته على اختصاصه بتقدم الجار فقال تعالى : { علينا } أي : خاصة { يسير } فكيف يتوقف فيه عاقل فضلاً عن أن ينكره وأما غيرنا فلا يمكنه ذلك بوجه .  <br />
تنبيه : علينا متعلق بيسير ففصل بمعمول الصفة بينها وبين موصوفها ولا يضرّ ذلك .   وقال الزمخشريّ : التقديم للاختصاص وهو ما أشرت إليه أي لا يتيسر ذلك إلا على الله تعالى وحده وهو إعادة جواب قولهم ذلك رجع بعيد .  <br />
