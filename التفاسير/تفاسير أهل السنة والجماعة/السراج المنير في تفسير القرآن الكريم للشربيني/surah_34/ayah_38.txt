ثم بين حال المسيء وهو من يبعده ماله وولده من الله تعالى بقوله سبحانه وتعالى : { والذين يسعون } أي : يجددون السعي من غير توبة بأموالهم وأولادهم { في } إبطال { آياتنا } أي : حجتنا على ما لها من عظمة الانتساب إلينا { معجزين } أي : طالبين تعجيزها أي : تعجيز الآتين بها عن إنفاذ مرادهم بها بما يلقون من الشبه فيضلون غيرهم بما أوسعنا عليهم وأعززناهم به من الأموال والأولاد { أولئك } أي : هؤلاء البعداء البغضاء { في العذاب } أي : المزيل للعذوبة { محضرون } أي : يحضرهم فيه الموكلون بهم من جندنا على أهون وجه وأسهله .  <br />
