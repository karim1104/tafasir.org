{ فلما رأوه } أي : العذاب بعد الحشر { زلفة } أي : ذا قرب عظيم منهم { سيئت } قال ابن عباس رضي الله عنهما : أي : اسودّت { وجوه } وأظهر في موضع الإضمار تعميماً وتعليقاً للحكم بالوصف ،   فقال تعالى : { الذين كفروا } أي : أظهروا السوء وغاية الكراهة في وجوه من أوقع هذا الوصف .  <br />
تنبيه : الأصل ساء ،   أي : أحزن وجوههم العذاب ورؤيته ،   ثم بني للمفعول ،   وساء هنا ليست المرادفة لبئس .  <br />
وأشم كسرة السين نافع وابن عامر والكسائي والباقون بإخلاص الكسرة .   وقيل : أي : قال لهم الخزنة تقريعاً وتوبيخاً { هذا الذي كنتم } أي : جبلة وطبعاً { به } أي : بسببه ومن أجله { تدّعون } أي : تتمنون وتسألون وتزعمون أنكم لا تبعثون ،   وهذه حكاية حال تأتي ،   عبر عنها بطريق المضي لتحقق وقوعها ،   وقرأ هشام والكسائي بضم القاف ،   والباقون بكسرها .  <br />
