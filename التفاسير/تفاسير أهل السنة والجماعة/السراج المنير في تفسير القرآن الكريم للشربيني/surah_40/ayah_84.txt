{ فلما رأوا } أي : عاينوا { بأسنا } أي : عذابنا الشديد ومنه قوله تعالى : { بعذاب بئيس } ( الأعراف : 165 ) { قالوا آمنا بالله } أي : الذي له مجامع العظمة ومعاقد العز ونفوذ الكلمة { وحده } لا نشرك به شيئاً { وكفرنا بما كنا } أي : جبلة وطبعاً { به مشركين } يعنون الأصنام أي : لأنا علمنا أنه لا يغني من دون الله شيء .
