ثم قال ذلك المؤمن لقومه : { من عمل سيئة } أي : ما يسوء من أي صنف كان الذكور والإناث المؤمنين والكافرين { فلا يجزى } أي : من الملك الذي لا ملك سواه { إلا مثلها } عدلاً منه لا يزاد عليها مقدار ذرة ولا أصغر منها { ومن عمل صالحاً } أي : ولو قل { من ذكر أو أنثى وهو } أي : والحال أنه { مؤمن } إذ لا يصح عمل بدون إيمان { فأولئك } أي : العالو الرتبة والهمة { يدخلون الجنة } أي : بأمر من له الأمر كله بعد أن تضاعف لهم أعمالهم ،   وقرأ ابن كثير وأبو عمرو وشعبة بضم الياء وفتح الخاء والباقون بفتح الياء وضم الخاء { يرزقون فيها } أي : الجنة من غير احتياج إلى تحيل ولا إلى أسباب { بغير حساب } لخروج ما فيها لكثرته عن الحصر فإن أدنى أهلها منزلة لو أضاف كل أهل الأرض لكفاهم من غير أن ينقص من ملكه شيء ،   وهذا من باب الفضل وفضل الله لا حد له ورحمته غلبت غضبه ،   وأما جزاء السيئة فمن باب العدل فلذلك وقع الحساب فيها لئلا يقع الظلم ،   قال الأصبهاني : فإذا عارضنا عمومات الوعيد بعمومات الوعد ترجح الوعد بسبق الرحمة الغضب فانهدمت قواعد المعتزلة .  <br />
