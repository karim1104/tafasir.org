{  ولما وقع عليهم الرجز قالوا يا موسى ادع لنا ربك بما عهد عندك لئن كشفت عنا الرجز لنؤمنن لك ولنرسلن معك بني إسرائيل 134 فلما كشفنا عنهم الرجز إلى أجل هم بالغوه إذا هم ينكثون 135 } [ الأعراف :  الآيتان 134 ،  135 ] . <br />
هذه الآية كأنها تقرأ عند كل واحدة من الآيات السابقة {  ولقد أخذنا آل فرعون بالسنين ونقص من الثمرات لعلهم يذكرون 130 } [ الأعراف :  آية 130 ] قوله :  {  فأرسلنا عليهم الطوفان } [ الأعراف :  آية 133 ]<br />
أي :  ولما عذبوا بالطوفان ووقع عليهم رجز الطوفان {  قالوا يا موسى ادع لنا ربك } فلما رفعه عنهم ووقع عليهم رجز الجراد {  قالوا يا موسى ادع لنا ربك } [ الأعراف :  آية 134 ] . <br />
لما أنهكهم الجراد وكاد يهلكهم جاؤوا إلى فرعون وشكوا إليه ،  فذهب فرعون إلى موسى وقال له :  {  يا موسى ادع لنا ربك بما عهد عندك لئن كشفت عنا الرجز } يعني الجراد {  لنؤمن لك .  .  .  } [ الأعراف :  آية 134 ] إلى آخر القصة .
