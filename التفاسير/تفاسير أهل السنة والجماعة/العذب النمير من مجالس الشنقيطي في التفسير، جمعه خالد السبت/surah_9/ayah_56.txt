وقوله :  {  ويحلفون بالله إنهم لمنكم } [ التوبة :  آية 56 ] هذه عادة المنافقين يتقون بالأيمان الكاذبة {  ويحلفون } للنبي والمسلمين {  بالله إنهم لمنكم } في الباطن والظاهر ،  والله يقول :  {  وما هم منكم } بل هم أعداؤكم ولا عاشروكم إلا مرغمين على ذلك لا يجدون عنه مفرا ،  كما يأتي في الآية الآتية بعد هذا {  ويحلفون } للنبي وأصحابه قائلين {  إنهم لمنكم } باطنا وظاهرا ،  والله يقول :  {  وما هم منكم } هم كفرة أعداء ليسوا منكم {  ولكنهم قوم يفرقون } يفرقون معناه :  يخافون .  العرب تقول :  فرق الرجل بكسر الراء يفرق بفتحها على القياس بفتحتين فهو فرق إذا كان خائفا شديد الخوف {[821]} .  وهو معنى معروف في كلام العرب ،  ومنه قول أبي محجن الهذلي في أبياته المشهورة {[822]} : <br />
