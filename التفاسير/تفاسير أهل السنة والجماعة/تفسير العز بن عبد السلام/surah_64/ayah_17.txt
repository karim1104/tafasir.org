{ قَرْضًا } نفقة الأهل أو النفقة في سبيل الله أو قول سبحان الله والحمد لله ولا إله إلا الله والله أكبر .   { حَسَنًا } طيبة بها نفسه أو لا يمتن بها { يضاعفه } بالحسنة عشراً أو ما لا يحد من تفضله { شكور } للقليل من أفعالنا { حليم } عن ذنوبنا أو { عالم } بمضاعفة الصدقة { حليم } بأن لا يعاجل عقوبة مانع الزكاة .  <br />
