{ ابلعي ماءك } بلعت ماءها وماء السماء ،   أو ماءها وحده وصار ماء السماء بحاراً وأنهاراً ،   لأنه قال : { ابلعي ماءك } { اقلعي } عن المطر ،   أقلع عن الشيء تركه .   { وغيض الماء } نقص فذهبت زيادته عن الأرض .   { وقُضي الأمر } بإهلاكهم بالغرق .   { الجودي } جبل بالموصل ،   أو الجزيرة أو اسم لكل جبل .  <br />
