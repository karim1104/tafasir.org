{ دعواهم } إذا دعوا شيئاً يشتهونه قالوا : { سبحانك اللهم } فيأتيهم ذلك وإذا سألوا الله شيئاً قالوا : { سبحانك اللهم } { وتحيتهم } ملكهم سالم ،   التحية : الملك .   أو يُحيي بعضهم بعضا بالسلام أي سلمت مما بلى به أهل النار .   { وآخر دعواهم أن الحمد } كما أن أول دعائهم { سبحانك اللهم } كان آخره بالحمد له .   أو إذا أجاب سؤالهم فيما ادعوه وأتاهم ما اشتهوه شكروا بالحمد له .  <br />
