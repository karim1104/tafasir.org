{ ما استطعتم } جهدكم أو أن يطاع فلا يعصى أو ما يتطوع به من نافلة أو صدقة لما نزلت { اتقوا الله حق تقاته } [ آل عمران : 102 ] اشتد عليهم فقاموا حتى ورمت عراقيبهم وتقرحت جباههم فنسخها الله تعالى بهذه الآية .   { واسمعوا } كتاب الله تعالى { وأنفقوا } في الجهاد أو الصدقة  " ع "  أو نفقة المؤمن لنفسه { شُحَّ نفسه } هواها أو ظلمها أو منع الزكاة فمن أعطاها فقد وقي شح نفسه .
