{ وصَدّوكم } عام الحديبية { معكوفا } محبوساً ،   أو واقفاً ،   أو مجموعاً { مَحِلّه } منحره أو الحرم المحل بالكسر غاية الشيء وبالفتح الموضع الذي يحله الناس وكان الهدي سبعين بدنة .   { لم تعلموهم } لم تعلموا إيمانهم { تطؤوهم } بخيلكم ورجلكم فتقتلوهم ،   أو لولا أن في أصلاب الكفار وأرحام نسائهم رجال مؤمنون ونساء مؤمنات لم تعلموهن أن تطؤوا آبائهم فيهلك الأبناء { مَعَرّة } إثم ،   أو غرم الدية ،   أو كفارة قتل الخطأ ،   أو الشدة ،   أو العيب ،   أو الغم { تزيّلوا } تميزوا ،   أو تفرقوا ،   أو زايلوا حتى لا يختلطوا بمشركي مكة { لعذبنا الذين كفروا } بالقتل بالسيف ولكن الله يدفع بالمؤمنين عن الكفار .  <br />
