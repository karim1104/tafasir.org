{ آمنوا } بالله { وهاجروا } من ديارهم في طاعته { وجاهدوا بأموالهم } بإنفاقها { وأنفسهم } بالقتال أراد المهاجرين مع الرسول صلى الله عليه وسلم إلى المدينة { والذين آووا } المهاجرين في منازلهم { ونصروا } النبي صلى الله عليه وسلم والمهاجرين معه ،   يريد الأنصار .   { أولياء بعض } أعوان بعض عند الجمهور [ أو ] أولى بميراث بعض ،   جعل الله -تعالى- الميراث للمهاجرين والأنصار دون الأرحام .   { والذين آمنوا ولم يهاجروا ما لكم } من ميراثهم من شيء { حتى يهاجروا } .   فعملوا بذلك حتى نسخت بقوله -تعالى- { وأولوا الأرحام بعضهم أولى ببعض في كتاب الله } [ 75 ] يعني في الميراث ،   فصار الميراث لذوي الأرحام .
