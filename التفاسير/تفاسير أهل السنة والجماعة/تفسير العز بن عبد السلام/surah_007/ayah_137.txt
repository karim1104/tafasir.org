{ مشارق الأرض } الشرق والغرب ،   أو أرض الشام ومصر ،   أو الشام وحدها شرقها وغربها .   { باركنا فيها } بالخصب ،   أو بكثرة الثمار والأشجار والأنهار .   { وتمت كلمة ربك } بإهلاك عدوهم واستخلافهم أو بما وعدهم به بقوله -تعالى- { ونريد أن نَمُنّ } الآيتين [ القصص : 5 ،   6 ] { الحسنى } لأنها وعد بما يحيون .   { بما صبروا } على طاعة الله -تعالى- أو على أذى فرعون .
