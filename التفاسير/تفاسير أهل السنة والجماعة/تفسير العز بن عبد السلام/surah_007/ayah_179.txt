{ كثيرا من الجن والإنس } عام ،   أو يراد به أولاد الزنا ،   لمسارعتهم إلى الكفر لخبث نطفهم .   { لا يفقهون } الحق بقلوبهم و { لا يبصرون } الرشد بأعينهم ،   و { لا يسمعون } الوعظ بآذانهم .   { كالأنعام } همهم الأكل والشرب ،   أو لا يعقلون الوعظ .   { هم أضل } لعصيانهم ،   أو لتوجه الأمر إليهم دونها .  <br />
