{ ما في السماوات وما في الأرض } خلقاً ،   أو ملكاً { الحمد في الآخرة } حمد أهل الجنة - { الحمد لله الذي أذهب عنا الحَزَن } [ فاطر : 34 ] { الحمد لله الذي صَدَقَنا وعده } [ الزمر : 74 ] ،   أو له الحمد في السماء والأرض لأنه خلق السموات قبل الأرض فصارت هي الأولى والأرض الآخرة ،   أو له ' الحمد في الأولى على الهداية ' وفي الآخرة على الثواب والعقاب .   { الحكيم } في أمره { الخبير } بخلقه .
