{ وسعها } طاقتها { كسبت } من الحسنات { اكتسبت } من السيئات .   { نسينا } أمرك أو تركناه .   { أخطأنا } أصبنا من المعاصي بالشبهات ،   أو تعمدنا .   { إصرا } عهدا نعجز عن القيام به ،   أو لا تمسخنا قردة وخنازير ،   أو الذنب الذي لا توبة له ولا كفارة ،   أو الثقل العظيم .   { الذين من قبلنا } بنو إسرائيل فيما حُملوه من قتل أنفسهم .   { لا طاقة لنا به } من العذاب ،   أو مما كلفته بنو إسرائيل .   { مولانا } ولينا وناصرنا .  <br />
