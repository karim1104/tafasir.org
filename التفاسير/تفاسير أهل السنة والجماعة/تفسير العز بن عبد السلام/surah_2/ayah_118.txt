{ الذين لا يعلمون } اليهود ،   أو النصارى ،   أو مشركو العرب { الذين من قبلهم } اليهود ،   أو اليهود والنصارى .   { تشابهت قلوبهم } شابهت قلوب النصارى قلوب اليهود ،   أو قلوب مشركي العرب لقلوب اليهود والنصارى .  <br />
{ إنآ أرسلناك بالحق بشيراً ونديراً ولا تسئل عن أصحاب الجحيم ( 119 ) ولن ترضى عنك اليهود ولا النصارى حتى تتبع ملتهم قل إن هدى الله هو الهدى ولئن اتبعت أهوآءهم بعد الذي جآءك من العلم ما لك من الله من ولي ولا نصير ( 120 ) الذين آتنياهم الكتاب يتلونه حق تلاوته أولئك يؤمنون به ومن يكفر به فأولئك هم الخاسرون ( 121 ) يا بني إسرآءيل اذكروا نعمتي التي أنعمت عليكم وأني فضلتكم على العالمين ( 122 ) واتقوا يوماً لا تجزي نفس عن نفس شيئاً ولا يقبل منها عدل ولا تنفعها شفاعة ولا هم ينصرون ( 123 ) }
