{ بَوَّأْنا } وطأنا ،   أو عرفناه بعلامة سحابة تطوقت حيال الكعبة فبنى على ظلها أو ريح فكنست حول البيت يقال لها : الخجوج { وطَهِّر بيتي } من الشرك وعبادة الأوثان .   أو من الأنجاس كالفرث والدم الذي كان يطرح حول البيت ،   أو قول الزور { للطائفين } بالبيت { والقائمين } في الصلاة ،   أو المقيمين بمكة { والركع السجود } في الصلاة .  <br />
