{ والموءودة } المدفونة حية خوف سبيها واسترقاقها أو خشية الفقر وكان أشرافهم لا يفعلون ذلك سميت بذلك لموتها بثقل التراب .   { ولا يؤوده حفظهما } [ البقرة : 255 ] لا يثقله .   { سُئلت } لم قتلت توبيخاً للقاتل تقول لا ذنب لي وقرأ ابن عباس رضي الله تعالى عنهما { سألت } أي سألت قاتلها لم قتلتني فلا يكون له عذر .
