{ إن تتوبا } يا عائشة وحفصة من الإذاعة والمظاهرة أو من السرور بما ذكره الرسول صلى الله عليه وسلم من التحريم .   { صغت } زاغت أو مالت أو أثمت { تظاهرا } تتعاونا على معصيته { مولاه } وليه { وصالح المؤمنين } الأنبياء أو الملائكة أو الصحابة أو علي أو أبو بكر وعمر - رضي الله تعالى عنهم - { ظهير } أعوان للرسول صلى الله عليه وسلم .  <br />
