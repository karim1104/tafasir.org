{ ولكل } أهل ملة { وجهة } قبلة ،   أو صلاة { هو موليها } أي المصلي ،   أو الله يوليه إليها ،   ويأمره باستقبالها .   { فاستبقوا الخيرات } سارعوا إلى الأعمال الصالحة ،   أو لا تغلبكم اليهود على قبلتكم بقولهم : ' إن اتبعتم قبلتنا اتبعناكم ' .   { يأت بكم } يوم القيامة جميعاً .   { إن الله على كل شيء قدير } من إعادتكم بعد الموت والبلى .  <br />
