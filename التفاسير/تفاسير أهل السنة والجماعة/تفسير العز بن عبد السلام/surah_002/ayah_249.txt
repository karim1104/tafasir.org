{ بنهَر } نهر بين الأردن وفلسطين ،   أو نهر فلسطين ابتلوا به لشكايتهم قلة الماء وخوف العطش .   { مني } من أهل ولايتي .   { غرفة } الفعل والغرفة اسم المغروف .   { قليلا } ثلاثمائة وبضعة عشر عدة أهل بدر ،   ومن استكثر منه عطش .   { جاوزه } مع المؤمنين والكافرين ثم انخزلوا عن المؤمنين ،   وقالوا : لا طاقة لنا اليوم بجالوت ،   أو لم يجاوزه إلا مؤمن .   { قالوا لا طاقة } قاله الكفار المنخزلون ،   أو من قلت نصرته من المؤمنين .   { يظنون } يوقنون ،   أو يتوقعون { أنهم ملاقوا الله } بالقتل في تلك الواقعة .   { مع الصابرين } بالنصر والمعونة .  <br />
