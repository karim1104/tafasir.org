{ وألق عصاك } ليعلم بذلك أن الذي سمعه كلام الله تعالى .   { ولم يُعقّب } لم يثبت مأخوذ من العقب الذي يثبت به القدم أو لم يتأخر لسرعة مبادرته .   { الآمنين } من الخوف فلا يصير رسولاً إلا بقوله { فذانِك برهانان من ربك إلى فرعون } ،   أو الآمنين المرسلين لقوله : { لا تخف إني لا يخاف لديّ المرسَلون } [ النمل : 10 ] فيصير بذلك رسولاً .   { برهانان } اليد والعصا { الرهب } الكم ،   أو الخوف .
