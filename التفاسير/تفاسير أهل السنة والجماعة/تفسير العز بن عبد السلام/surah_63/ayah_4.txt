{ تعجبك أجسامهم } لحسن منظرهم { تسمع لقولهم } لحسن منطقهم { خُشُبٌ } شبهوا بالنخل القائمة لحسن منظرهم أو بالخشب النخرة لسوء مخبرهم أو لأنهم لا ينتفعون بسماع الهدى فصاروا كالخشب { مُسَنّدة } لاستنادهم إلى الإيمان لحقن دمائهم { يحسبون كل صيحة عليهم } لخبثهم لا يسمعون صيحة إلا ظنوا أن العدو قد اصطلمهم وأن القتل قد حل بهم أو يظنون عند كل صيحة أن قد فطن بهم وعلم نفاقهم لأن المريب خائف ،   أو يظنون عند كل صياح في المسجد أن الرسول صلى الله عليه وسلم قد أمر بقتلهم فهم أبداً وجلون .   { فاحذرهم } أن تثق بقولهم أو احذر ممايلتهم لأعدائك وتخذيلهم لأصحابك { قاتلهم } لعنهم أو أحلهم محل من قاتله ملك قاهر لقهر الله تعالى لكل معاند { يؤفكون } يكذبون أو يعدلون عن الحق أو يصرفون عن الرشد أو كيف تضل عقولهم عن هذا ؟<br />
