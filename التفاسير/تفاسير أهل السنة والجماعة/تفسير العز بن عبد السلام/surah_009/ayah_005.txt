{ فإذا انسلخ الأشهر الحرم } رجب وذو القعدة وذو الحجة والمحرم عند الجمهور ،   أو أشهر السياحة عشرون من ذي الحجة إلى العشر من ربيع الآخر ،   قاله الحسن - رضي الله عنه- { وجدتموهم } في حل أو حرم ،   أو في أشهر الحرم وغيرها .   { وخذوهم } الواو بمعنى ' أو ' خذوهم أو تقديره : ' فخذوا المشركين حيث وجدتموهم واقتلوهم ' مقدم ومؤخر .   { واحصروهم } بالاسترقاق ،   أو بالفداء .   { كل مرصد } اطلبوهم في كل مكان ،   فالقتل إذا وجدوا والطلب إذا بعدوا ،   أو افعلوا بهم كل ما أرصده الله لهم من قتل أو استرقاق أو مَنّ ،   أو فداء .   { تابوا } أسلموا { وأقاموا الصلاة } أدوها ،   أو اعترفوا بها { وآتوا الزكاة } اعترفوا بها لا غير إذ لا يُقتل تاركها لا بل تُؤخذ منه قهراً .  <br />
