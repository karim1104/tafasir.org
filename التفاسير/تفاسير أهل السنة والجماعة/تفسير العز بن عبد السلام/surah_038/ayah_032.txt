{ حبِّ الخير } حب المال ،   أو حب الخيل ،   أو حب الدنيا { أحببتُ حبّ الخير } آثرت حب الخير ،   أو تقديره أحببت حباً الخير ثم أضافه فقال حب الخير { ذِكْرِ ربي } ذكر الله -تعالى-  " ع "  ،   أو صلاة العصر سُئل الرسول صلى الله عليه وسلم عن الصلاة الوسطى فقال : هي صلاة العصر التي فرط فيها نبي الله سليمان - عليه الصلاة والسلام - { توارت } الشمس { بالحجاب } وهو جبل أخضر محيط بالدنيا ،   أو توارت الخيل بالحجاب والحجاب : الليل لستره ما فيه .  <br />
