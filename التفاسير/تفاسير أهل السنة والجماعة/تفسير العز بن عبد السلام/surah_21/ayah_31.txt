{ رواسي } لأنها رست في الأرض وثبتت ،   أو لأن الأرض رست بها فالرواسي الثوابت ،   أو الثقال { تميد } تزول ،   أو تضطرب { فِجاجا } أعلاماً يُهتدى بها ،   أو جمع فج وهو الطريق الواسع بين الجبلين { سُبُلا } للاعتبار ،   أو مسالك للسابلة { يهتدون } بالاعتبار بها إلى دينهم ،   أو ليهتدوا طرق بلادهم .  <br />
