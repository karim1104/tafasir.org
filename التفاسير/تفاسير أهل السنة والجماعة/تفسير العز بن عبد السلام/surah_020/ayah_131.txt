{ تَمُدَّنّ } لا تأسفن ،   أو لا تنظرن .   { أزواجا } أشكالاً من المزاوجة { زهرة الحياة } زينتها { لنفتنهم } لنعذبهم { ورزق ربك } القناعة بما تملكه والزهد فيما لا تملكه ،   أو ثواب الآخرة { خير وأبقى } مما مُتّعوا به ،   نزلت لما أبى اليهودي أن يُسلف الرسول صلى الله عليه وسلم الطعام إلا برهن فشق ذلك على الرسول صلى الله عليه وسلم .  <br />
