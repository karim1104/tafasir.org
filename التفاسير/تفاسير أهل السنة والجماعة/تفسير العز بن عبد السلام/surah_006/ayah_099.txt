{ نبات كل شيء } رزق كل شيء من الحيوان ،   أو نبات كل شيء من الثمار .   { خضرا } زرعاً خضراً .   { متراكبا } سنبلا تراكب حبه .   { قنوان } جمع قنو وهو الطلع ،   أو العذق .   { دانية } من مجتنيها لقصرها ،   أو قرب بعضها من بعض .   { مشتبها } ورقه مختلفا ثمره ،   أو { مشتبها } لونه ،   مختلفا طعمه .   { ثمرة } الثمر جمع ثمار ،   والثمر جمع ثمرة ،   أو الثُّمر المال ،   والثَمَر ثمر النخل ،   قرئ بهما .   { وينعه } نضجه وبلوغه .  <br />
