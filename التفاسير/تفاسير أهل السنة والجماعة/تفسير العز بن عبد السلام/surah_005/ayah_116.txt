{ وإذ قال الله يا عيسى } قاله لما رفعه إلى السماء في الدنيا ،   أو يقوله يوم القيامة فيكون { إذ } بمعنى { إذا } وهذا أصح لقوله : { هذا يوم ينفع الصادقين صدقهم } [ 119 ] { أأنت قلت } سؤال توبيخ لقومه ،   أو ليعرف المسيح - عليه الصلاة والسلام - أنهم غيروا وقالوا عليه ما لم يقل .   { إلهين } لما قالوا إنها ولدت الإله لزمهم أن يقولوا بإلاهيتها للبعضية فصاروا بمثابة القائل بإلاهيتها .
