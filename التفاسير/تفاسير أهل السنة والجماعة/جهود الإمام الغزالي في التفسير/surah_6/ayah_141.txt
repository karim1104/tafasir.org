{  كلوا من ثمره إذا أثمر وآتوا حقه يوم حصاده } ( 142 ) . <br />
418- {  كلوا من ثمره } إباحة ،  وقوله بعده {  وآتوا حقه يوم حصاده } إيجاب .  [ المستصفى :  2/71 ] . <br />
419- {  وآتوا حقه يوم حصاده } الحق :  هو العشر .  [ نفسه :  1/340 ] . <br />
420- {  وآتوا حقه يوم حصاده } يعرف منه وجوب الإتيان ووقته ،  وأنه حق في المال [ نفسه :  1/376 ] . <br />
421- {  وآتوا حقه يوم حصاده } بين الوقت والمحل ،  وبقي المقدار مجملا .  [ المنخول :  168 ] .
