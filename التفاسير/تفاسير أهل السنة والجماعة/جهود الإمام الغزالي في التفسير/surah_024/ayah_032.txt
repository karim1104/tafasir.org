{  وأنكحوا الأيامى منكم } ( 32 )<br />
779- هذا أمر .  ( نفسه :  2/25 )<br />
780- قال [ الإمام الشافعي ] في كتاب أحكام القرآن :  لم يتبين لي وجوب إنكاح العبد لأنه لم فيه النهي عن العضل ،  بل لم يرد إلا قوله تعالى :  {  وأنكحوا الأيامى منكم } الآية فهذا أمر ،  وهو محتمل للوجوب والندب .  ( المستصفى :  1/426 )<br />
{  والذين يبتغون الكتاب مما ملكت أيمانكم فكاتبوهم إن علمتم فيهم خيرا وآتوهم من مال الله الذي آتاكم }( 31 )<br />
781- {  فكاتبوهم } استحباب .  ( المستصفى :  2/71 )<br />
782- {  وءاتوهم من مال الله الذي ءاتاكم } إيجاب .  ( نفسه :  2/72 )
