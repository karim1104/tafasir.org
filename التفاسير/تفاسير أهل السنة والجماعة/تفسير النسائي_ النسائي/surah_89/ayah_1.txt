{ وَٱلْفَجْرِ } [1] 691- أنا محمدُ بن رافعٍ، نا زيدُ بنُ حُبابٍ، أخبرني عياشُ ابن عُقبة، قال: أناني خيرُ بنُ نُعيمٍ، عن أبي الزُّبير، عن جابرٍ: أن رسول اللهِ صلى الله عليه وسلم قال: " { وَٱلْفَجْرِ * وَلَيالٍ عَشْرٍ } [1-2]، قال: " عَشْرُ " النَّحْرِ، { وَٱلْوَتْرِ } يَوْمُ عَرَفَةَ، { وَٱلشَّفْعِ } يَوْمُ النّحْرِ ".
