{ فلما دخلوا عليه قالوا يا أيها العزيز مسنا وأهلنا الضر } أصابنا ومن يختص بنا الجوع ،   { وجئنا ببضاعة مزجاة } ندافع بها الأيام ونتقوت وليست مما يتشبع به وكانت دراهم زيوفا  ،  { فأوف لنا الكيل } سألوه مساهلتهم في النقد وإعطاءهم بدارهمهم مثل ما يعطي بغيرها من الجياد { وتصدق علينا } بما بين القيمتين { إن الله يجزي } يتولى جزاء { المتصدقين } .  <br />
