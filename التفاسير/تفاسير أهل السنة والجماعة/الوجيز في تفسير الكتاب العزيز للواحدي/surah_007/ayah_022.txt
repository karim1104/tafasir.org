{ فدلاهما بغرور } غرهما باليمين ومعنى دلاهما جرأهما على أكل الشجرة بما غرهما به من يمينه { فلما ذاقا الشجرة بدت لهما سوآتهما } تهافت لباسهما عنهما فأبصر كل واحد منهما عورة صاحبه فاستحييا { وطفقا يخصفان } أقبلا وجعلا يرقعان الورق كهيئة الثوب ليستترا به { وناداهما ربهما ألم أنهكما عن تلكما الشجرة وأقل لكما إن الشيطان لكما عدو مبين }<br />
