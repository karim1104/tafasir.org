{ قال ادخلوا } أي قال الله تعالى لهم ادخلوا النار { في أمم } أي مع { أمم قد خلت من قبلكم } { كلما دخلت أمة } النار { لعنت أختها } يعني الأمم التي سبقتها إلى النار لأنهم ضلوا باتباعهم { حتى إذا اداركوا فيها } أي تداركوا وتلاحقوا واجتمعوا جميعا في النار { قالت أخراهم } أي أخراهم دخولا إلى النار { لأولاهم } دخولا يعني قالت الأتباع للقادة { ربنا هؤلاء أضلونا } لأنهم شرعوا لنا أن نتخذ من دونك الها { فآتهم عذابا ضعفا } أضعف عليهم العذاب بأشد مما تعذبنا به { قال } الله تعالى { لكل ضعف } للتابع والمتبوع عذاب مضاعف { ولكن لا تعلمون } يا أهل الكتاب في الدنيا مقدار ذلك<br />
