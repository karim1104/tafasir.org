{ الذين يتبعون الرسول النبي الأمي } وهو الذي لا يكتب ولا يقرأ وكانت هذه الخلة مؤكدة لمعجزته في القران { الذي يجدونه } بنعته وصفته { مكتوبا عندهم في التوراة والإنجيل يأمرهم بالمعروف } بالتوحيد وشرائع الإسلام { وينهاهم عن المنكر } عبادة الأوثان وما لا يعرف في شريعة { ويحل لهم الطيبات } يعني ما حرم عليهم في التوراة من لحوم الإبل وشحوم الضأن { ويحرم عليهم الخبائث } الميتة والدم وما ذكر في سورة المائدة { ويضع عنهم إصرهم } ويسقط عنهم ثقل العهد الذي أخذ عليهم { والأغلال التي كانت عليهم } الشدائد التي كانت عليهم كقطع آثر البول وقتل النفس في التوبة وقطع الأعضاء الخاطئة { فالذين آمنوا به } من اليهود { وعزروه } ووقروه { ونصروه } على عدوه { واتبعوا النور الذي أنزل معه } يعني القرآن الآيتين<br />
