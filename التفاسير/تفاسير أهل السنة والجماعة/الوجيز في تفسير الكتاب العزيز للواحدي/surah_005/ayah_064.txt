{ وقالت اليهود يد الله مغلولة } مقبوضة عن العطاء وإسباغ النعم علينا قالوا هذا حين كف الله تعالى عنهم بكفرهم بمحمد عليه السلام ماكان يسلط عليهم من الخصب والنعمة فقالوا لعنهم الله على جهة الوصف بالبخل { يد الله مغلولة } وقوله { غلت أيديهم } أي جعلوا بخلاء وألزموا البخل فهم أبخل قوم { ولعنوا بما قالوا } عذبوا في الدنيا بالجزية والذلة والصغار والقحط والجلاء وفي الآخرة بالنار { بل يداه مبسوطتان } قيل معناه الوصف بالمبالغة في الجود والإنعام وقيل معناه نعمه مبسوطة ودلت التثنية على الكثرة كقولهم لبيك وسعديك وقيل نعمتاه أي نعمة الدنيا ونعمة الاخرة { مبسوطتان ينفق كيف يشاء } يرزق كما يريد إن شاء قتر وإن شاء وسع { وليزيدن كثيرا منهم ما أنزل إليك من ربك طغيانا وكفرا } كلما أنزل عليك شيء من القرآن كفروا به فيزيد كفرهم { وألقينا بينهم العداوة والبغضاء } بين طوائف<br />
