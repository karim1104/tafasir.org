{ وأقم الصلاة طرفي النهار } بالصبح والمغرب { وزلفا من الليل } صلاة العشاء قرب أول الليل والزلف أول ساعات الليل وقيل صلاة طرفي النهار الفجر والظهر والعصر وأما المغرب والعشاء فإنهما من صلاة زلف الليل { إن الحسنات يذهبن السيئات } إن الصلوات الخمس تكفر ما بينها من الذنوب إذا اجتنبت الكبائر { ذلك ذكرى } أي هذه موعظة { للذاكرين }<br />
