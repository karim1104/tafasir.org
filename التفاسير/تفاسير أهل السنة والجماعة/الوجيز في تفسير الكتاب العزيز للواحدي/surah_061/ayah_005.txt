{ وإذ قال موسى } أي اذكر يا محمد لقومك قصة موسى اذ قال لقومه { يا قوم لم تؤذونني } وذلك حين رموه بالأدرة  ،  { وقد تعلمون أني رسول الله إليكم } والرسول يعظم ولا يؤذى { فلما زاغوا } عدلوا عن الحق  ،  { أزاغ الله قلوبهم } أضلهم الله وصرف قلوبهم عن الحق  ،  { والله لا يهدي القوم الفاسقين } أي من سبق في عمله أنه فاسق  .  <br />
