ولما ذكر عري آدم وحواء من علينا بما خلق لنا من اللباس فقال<br />
{ يا بني آدم قد أنزلنا عليكم } أي خلقنا لكم { لباسا يواري سوآتكم } يستر عوراتكم { وريشا } أي مالا وما تتجملون به من الثياب الحسنة { ولباس التقوى } أي ستر العورة لمن يتقي الله فيواري عورته { ذلك خير } لصاحبه إذا أخذ به أو خير من التعري وذلك أن جماعة من المشركين كانوا يتعبدون بالتعري وخلع الثياب في الطواف بالبيت { ذلك من آيات الله } أي من فرائضه التي أوجبها بآياته يعني ستر العورة { لعلهم يذكرون } لكي يتعظوا<br />
