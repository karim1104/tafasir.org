{ نحن أعلم بما يستمعون به } نزلت حين دعا علي رضي الله عنه أشراف قريش إلى طعام اتخذه لهم ودخل عليهم النبي صلى الله عليه وسلم وقرأ عليهم القرآن ودعاهم إلى الله سبحانه وهم يقولون فيما بينهم متناجين هو ساحر وهو مسحور فأنزل الله تعالى { نحن أعلم بما يستمعون به } أي يستمعونه أخبر الله سبحانه أنه عالم بتلك الحال وبذلك الذين كان يستمعونه { إذ يستمعون } إلى الرسول { وإذ هم نجوى } يتناجون بينهم بالتكذيب والاستهزاء { إذ يقول الظالمون } المشركون { إن تتبعون } ما تتبعون { إلا رجلا مسحورا } مخدوعا أن اتبعتموه<br />
