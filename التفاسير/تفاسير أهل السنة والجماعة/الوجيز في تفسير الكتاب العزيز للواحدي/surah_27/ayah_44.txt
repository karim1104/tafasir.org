{ قيل لها ادخلي الصرح } وذلك أنه قيل لسليمان عليه السلام إن قدميها كحافر الحمار فأراد سليمان أن يرى قدميها فاتخذ له ساحة من زجاج تحته الماء والسمك وجلس سليمان في صدر الصرح وقيل لها ادخلي الصرح { فلما رأته حسبته لجة } ماء وهي معظمه { وكشفت عن ساقيها } لدخول الماء فرأى سليمان قدمها وإذا هي أحسن الناس ساقا وقدما و { قال } لها { إنه صرح ممرد } أملس { من قوارير } ثم إن سليمان عليه السلام دعاها إلى الإسلام فأجابت و { قالت رب إني ظلمت نفسي } بالكفر { وأسلمت مع سليمان لله رب العالمين }<br />
