{ له } لله سبحانه { معقبات } ملائكة حفظة تتعاقب في النزول إلى الأرض بعضهم بالليل وبعضهم بالنهار { من بين يديه } يدي الإنسان { ومن خلفه يحفظونه من أمر الله } أي بأمره سبحانه مما لم يقدر فإذا جاء القدر خلوا بينه وبينه { إن الله لا يغير ما بقوم حتى يغيروا ما بأنفسهم } لا يسلب قوما نعمة حتى يعملوا بمعاصيه { وإذا أراد الله بقوم سوءا } عذابا { فلا مرد له } فلا رد له { وما لهم من دونه من وال } يلي أمرهم ويمنع العذاب عنهم<br />
