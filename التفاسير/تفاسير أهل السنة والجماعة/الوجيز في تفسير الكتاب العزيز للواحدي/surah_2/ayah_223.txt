{ نساؤكم حرث لكم } أي مزرع ومنبت للولد { فأتوا حرثكم أنى شئتم } أي كيف شئتم ومن أين شئتم بعد أن يكون في صمام واحد فنزلت هذه الاية تكذيبا لليهود وذلك أن المسلمين قالوا إنا نأتي النساء باركات وقائمات ومستلقيات ومن بين أيديهن ومن خلفهن بعد أن يكون المأتي واحدا فقالت اليهود ما أنتم إلا أمثال البهائم لكنا نأتيهن على هيئة واحدة وإنا لنجد في التوراة أن كل إتيان يؤتى النساء غير الاستلقاء دنس عند الله فأكذب الله تعالى اليهود { وقدموا لأنفسكم } أي العمل لله بما يحب ويرضى { واتقوا الله } فيما حد لكم من الجماع وأمر الحائض { واعلموا أنكم ملاقوه } أي راجعون إليه { وبشر المؤمنين } الذين خافوه وحذروا معصيته<br />
