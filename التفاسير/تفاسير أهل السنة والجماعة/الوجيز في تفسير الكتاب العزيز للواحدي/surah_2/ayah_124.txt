{ وإذ ابتلى إبراهيم ربه } اختبره أي عامله معاملة المختبر { بكلمات } هي عشر خصال خمس في الرأس وهي الفرق والمضمضة والاستنشاق والسواك وقص الشارب وخمس في الجسد وهي تقليم الأظفار وحلق العانة والختان والاستنجاء ونتف الرفغين { فأتمهن } أداهن تامات غير ناقصات { قال } الله تعالى { إني جاعلك للناس إماما } يقتدي بك الصالحون فقال إبراهيم { ومن ذريتي } أي ومن أولادي أيضا فاجعل أئمة يقتدى بهم فقال الله عز وجل { لا ينال عهدي الظالمين } يريد من كان من ولدك ظالما لا يكون إ ما ما و معنى { عهدي } أي نبوتي .  <br />
