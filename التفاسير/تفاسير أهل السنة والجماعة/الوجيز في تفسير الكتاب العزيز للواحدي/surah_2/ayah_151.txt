{ كما أرسلنا فيكم } المعنى ولأتم نعمتي عليكم كإرسالي إليكم رسولا أي أتم هذه كما أتممت تلك بإرسالي { رسولا منكم } تعرفون صدقه ونسبه { يتلو عليكم آياتنا } يعني القرآن وهذا احتجاج عليهم لأنهم عرفوا أنه أمي لا يقرأ ولا يكتب فلما قرأ عليهم القرآن تبين لهم صدقه في النبوة { ويزكيكم } أي يعرضكم لما تكونوا به أزكياء من الأمر بطاعة الله تعالى<br />
