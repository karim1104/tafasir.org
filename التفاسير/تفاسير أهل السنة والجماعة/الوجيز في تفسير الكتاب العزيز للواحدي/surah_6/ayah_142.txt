{ ومن الأنعام } وأنشأ من الأنعام { حمولة } وهي كل ما حمل عليها مما أطاق العمل والحمل { وفرشا } وهو الصغار التي لا يحمل عليها كالغنم والبقر والإبل الصغار { كلوا مما رزقكم الله } أي أحل لكم ذبحه { ولا تتبعوا خطوات الشيطان } في تحريم شيء مما أحله الله { إنه لكم عدو مبين } بين العداوة أخرج أباكم من الجنة وقال لأحتنكن ذريته<br />
