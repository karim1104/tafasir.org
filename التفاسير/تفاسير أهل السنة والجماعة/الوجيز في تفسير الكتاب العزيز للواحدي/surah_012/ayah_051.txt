فدعا الملك النسوة فقال { ما خطبكن } ما قصتكن وما شأنكن { إذ راودتن يوسف عن نفسه } جمعهن في المراودة لأنه لم يعلم من كانت المراودة { قلن حاش لله } بعد يوسف عما يتهم به { ما علمنا عليه من سوء } من زنا فلما برأنه أقرت امرأة العزيز فقالت { الآن حصحص الحق } أي بان ووضح وذلك أنها خافت إن كذبت شهدت عليها النسوة فقالت { أنا راودته عن نفسه وإنه لمن الصادقين } في قوله { هي راودتني عن نفسي }<br />
