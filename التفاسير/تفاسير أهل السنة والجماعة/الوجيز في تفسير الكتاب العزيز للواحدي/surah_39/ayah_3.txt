{ ألا لله الدين الخالص } أي الطاعة لا يستحقها إلا الله تعالى ثم ذكر الذين يعبدون غيره فقال { والذين اتخذوا من دونه أولياء ما نعبدهم } أي ويقولون { ما نعبدهم إلا ليقربونا إلى الله زلفى } أي قربى { إن الله يحكم بينهم فيما هم فيه يختلفون } من أمر الدين ثم ذكر أنه لا يهدي هؤلاء فقال { إن الله لا يهدي من هو كاذب } في إضافة الولد إلى الله تعالى { كفار } يكفر نعمته بعبادة غيره .  <br />
