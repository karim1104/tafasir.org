{ وقال الشيطان } يعني ابليس { لما قضي الأمر } فصار أهل الجنة في الجنة وأهل النار في النار وذلك أن أهل النار حينئذ يجتمعون باللائمة على ابليس فيقوم خطيبا ويقول { إن الله وعدكم وعد الحق } يعني كون هذا اليوم فصدقكم وعده { ووعدتكم } أنه غير كائن { فأخلفتكم وما كان لي عليكم من سلطان } أي ما أظهرت لكم حجة على ما وعدتكم { إلا أن دعوتكم } لكن دعوتكم { فاستجبتم لي } فصدقتموني { فلا تلوموني ولوموا أنفسكم } حيث أجبتموني من غير برهان { ما أنا بمصرخكم } بمغيثكم { وما أنتم بمصرخي إني كفرت بما أشركتمون من قبل } باشراككم اياي مع الله سبحانه في الطاعة اني جحدت أن أكون شريكا لله فيما أشركتموني { إن الظالمين } يريد المشركين<br />
