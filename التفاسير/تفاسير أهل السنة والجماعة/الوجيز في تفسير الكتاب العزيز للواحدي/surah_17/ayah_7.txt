{ إن أحسنتم } أي وقلنا إن أحسنتم { أحسنتم لأنفسكم } إن أطعتم الله فيما بقي عفا عنكم المساوىء { وإن أسأتم } بالفساد وعصيان الأنبياء وقتلهم { فلها } فعليها يقع الوبال { فإذا جاء وعد الآخرة } المرة الأخيرة من إفسادكم وجواب إذا محذوف على تقدير بعثناهم { ليسوؤوا وجوهكم } وهو أنه بعث عليهم بختنصر فسبى وقتل وخرب ومعنى ليسوءوا وجوهكم ليخزوكم خزيا يظهر أثره في وجوهكم كسبي ذراريكم وإخراب مساجدكم { وليتبروا ما علوا } وليدمروا ويخربوا ما غلبوا عليه<br />
