وقوله { لا تجعلوا دعاء الرسول بينكم كدعاء بعضكم بعضا } أي لا تقولوا إذا دعوتموه يا محمد كما يقول أحدكم لصاحبه ولكن قولوا يا رسول الله يا نبى الله { قد يعلم الله الذين يتسللون } يخرجون في خفية من بين الناس { لواذا } يستتر بغيره فيخرج مختفيا { فليحذر الذين يخالفون عن أمره } أي يخالفون أمر الرسول صلى الله عليه وسلم وينصرفون بغير إذنه { أن تصيبهم فتنة } بلية تظهر نفاقهم { أو يصيبهم عذاب أليم } عاجل في الدنيا<br />
