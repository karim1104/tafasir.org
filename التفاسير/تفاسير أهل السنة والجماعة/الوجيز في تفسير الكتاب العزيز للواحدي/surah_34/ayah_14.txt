{ فلما قضينا عليه الموت ما دلهم } الآية كان سليمان عليه السلام يقول اللهم عم على الجن موتي ليعلم الإنس أن الجن لا يعلمون الغيب فمات سليمان عليه السلام متوكئا على عصاه سنة ولم تعلم الجن ذلك حتى أكلت الأرضة عصاه فسقط ميتا وهو قوله { ما دلهم على موته إلا دابة الأرض تأكل منسأته } عصاه { فلما خر } سقط { تبينت الجن } علمت { أن لو كانوا يعلمون الغيب ما لبثوا } بعد موت سليمان { في العذاب المهين } فيما سخرهم فيه سليمان عليه السلام واستعملهم<br />
