{ النبي أولى بالمؤمنين من أنفسهم } إذا دعاهم النبي صلى الله عليه وسلم إلى شيء ودعتهم أنفسهم إلى شيء كانت طاعة النبي صلى الله عليه وسلم أولى { وأزواجه أمهاتهم } في حرمة نكاحهن عليهم { وأولو الأرحام } والأقارب { بعضهم أولى ببعض } في الميراث { في كتاب الله } في حكمه { من المؤمنين والمهاجرين } وذلك أنهم كانوا في ابتداء الإسلام يرثون بالإيمان والهجرة { إلا أن تفعلوا إلى أوليائكم معروفا } لكن إن يوصوا لهم بشيء من الثلث فهو جائز { كان ذلك في الكتاب مسطورا } كان هذا الحكم في اللوح المحفوظ مكتوبا<br />
