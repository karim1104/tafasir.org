{ ادعوهم لآبائهم } أي انسبوهم إلى الذين ولدوهم { هو أقسط عند الله } أعدل عند الله { فإن لم تعلموا آباءهم } من هم { فإخوانكم في الدين } أي فهم إخوانكم في الدين { ومواليكم } وبنو عمكم وقيل أولياؤكم في الدين { وليس عليكم جناح فيما أخطأتم به } وهو أن يقول لغير ابنه يا بني من غير تعمد أن يجريه مجرى الولد في الميراث وهو قوله { ولكن ما تعمدت قلوبكم } يعني ولكن الجناح في الذي تعمدت قلوبكم<br />
