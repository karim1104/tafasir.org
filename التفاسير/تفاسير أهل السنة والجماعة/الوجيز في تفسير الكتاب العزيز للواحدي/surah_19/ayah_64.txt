{ وما نتنزل } كان جبريل عليه السلام قد احتبس عن النبي صلى الله عليه وسلم أياما فلما نزل قال له الا زرتنا فأنزل الله سبحانه { وما نتنزل إلا بأمر ربك له ما بين أيدينا } من أمر الآخرة { وما خلفنا } ما مضى من أمر الدنيا { وما بين ذلك } ما يكون من هذا الوقت إلى قيام الساعة وقيل { له ما بين أيدينا } يعني الدنيا { وما خلفنا } يعني السموات { وما بين ذلك } الهواء { وما كان ربك نسيا } تاركا لك منذ أبطأ عنك الوحي<br />
