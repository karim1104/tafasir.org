وقوله { ربنا ليضلوا عن سبيلك } أي جعلت هذه الأموال سببا لضلالهم لأنهم بطروا فاستكبروا عن الإيمان { ربنا اطمس على أموالهم } امسخها وأذهبها عن صورتها فصارت دراهمهم ودنانيرهم حجارة منقوشة صحاحا وأنصافا وكذلك سائر أموالهم { واشدد على قلوبهم } اطبع عليها حتى لا تلين ولا تنشرح للإيمان { فلا يؤمنوا } دعاء عليهم { حتى يروا العذاب الأليم } يعني الغرق فاستجيب في ذلك فلم يؤمن فرعون حتى أدركه الغرق<br />
