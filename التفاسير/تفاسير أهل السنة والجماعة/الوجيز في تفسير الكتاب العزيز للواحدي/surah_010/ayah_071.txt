{ إن كان كبر عليكم مقامي } أي عظم وشق عليكم مكثي ولبثي فيكم { وتذكيري بآيات الله } وعظي وتخويفي إياكم عقوبة الله { فعلى الله توكلت } فافعلوا ما شئتم وهو قوله { فأجمعوا أمركم وشركاءكم } أي اعزموا على أمر محكم تجتمعون عليه { وشركاءكم } مع شركائكم وقيل معناه وادعوا شركاءكم يعني آلهتكم { ثم لا يكن أمركم عليكم غمة } أي ليكن أمركم ظاهرا منكشفا تتمكنون فيه مما شئتم لا كمن يكتم أمرا ويخفيه فلا يقدر أن يفعل ما يريد { ثم اقضوا إلي } افعلوا ما تريدون وامضوا إلي بمكروهكم { ولا تنظرون } ولا تؤخروا أمري والمعنى ولا تألوا في الجمع والقوة فإنكم لا تقدرون على مساءتي لأن لي الها يمنعني وفي هذا تقوية لقلب محمد صلى الله عليه وسلم لأن سبيله مع قومه كسبيل الأنبياء من قبله<br />
