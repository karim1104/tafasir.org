{ قل هل من شركائكم } يعني آلهتكم { من يهدي } يرشد { إلى الحق } إلى دين الإسلام { قل الله يهدي للحق } أي إلى الحق { أفمن يهدي إلى الحق أحق أن يتبع أم من لا يهدي } أي الله الذي يهدي ويرشد إلى الحق أهل الحق أحق أن يتبع أمره أم الأصنام التي لا تهدي أحدا { إلا أن يهدى } يرشد وهي وإن هديت لم تهتد ولكن الكلام نزل على أنها ان هديت اهتدت لأنهم لما اتخذوها آلهة عبر عنها كما يعبر عمن يعلم { فما لكم } أي شيء لكم في عبادة الأوثان وهذا كلام تام { كيف تحكمون } يعني كيف تقضون حين زعمتم أن مع الله شريكا<br />
