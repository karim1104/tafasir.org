{ لا يقاتلونكم جميعا } أي اليهود { إلا في قرى محصنة أو من وراء جدر } أي لما ألقى الله في قلوبهم من الرعب لا يقاتلونكم الا متحصنين بالقرى والجدران ولا يبرزن لقتالكم { بأسهم بينهم شديد } خلافهم بينهم عظيم { تحسبهم جميعا } مجتمعين متفقين { وقلوبهم شتى } مختلفة متفرقة و { ذلك بأنهم قوم لا يعقلون } عن الله أمره  .  <br />
