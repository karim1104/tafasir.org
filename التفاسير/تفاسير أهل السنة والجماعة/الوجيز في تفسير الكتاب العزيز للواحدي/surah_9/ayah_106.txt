{ وآخرون مرجون لأمر الله } مؤخرون ليقضي الله فيهم ما هو قاض وهم كعب بن مالك وهلال بن أمية ومرارة بن الربيع كانوا تخلفوا من غير عذر ثم لم يبالغوا في الاعتذار كما فعل أولئك الذين تصدقوا بأموالهم فوقف رسول الله صلى الله عليه وسلم أمرهم وهم مهجورون حتى نزل قوله { وعلى الثلاثة الذين خلفوا } الايات { إما يعذبهم } بعقابه جزاء لهم { وإما يتوب عليهم } بفضله { والله عليم } بما يؤول إليه حالهم { حكيم } فيما يفعله بهم<br />
