{ ومنهم الذين يؤذون النبي } بنقل حديثه وعيبه { ويقولون هو أذن } أنهم قالوا فيما بينهم نقول ما شئنا ثم نأتيه فنخلف له فيصدقنا لأنه أذن والاذن الذي يسمع كل ما يقال له فقال الله تعالى { قل أذن خير لكم } أي مستمع خير وصلاح لا مستمع شر وفساد ثم أكد هذا وبينه فقال { يؤمن بالله } أي يسمع ما ينزله الله عليه فيصدق به { ويؤمن للمؤمنين } ويصدق المؤمنين فيما يخبرونه لا الكافرين { ورحمة للذين آمنوا منكم } أي وهو رحمة لأنه كان سبب إيمانهم<br />
