{ إن عدة الشهور عند الله اثنا عشر شهرا } عدد شهور المسلمين التي تعبدوا بأن يجعلوها لسنتهم اثنا عشر شهرا على منازل القمر واستهلال الأهلة لا كما يعده أهل الروم وفارس { في كتاب الله } في الإمام الذي عند الله كتبه يوم خلق السموات والأرض { منها أربعة حرم } رجب وذو القعدة وذو الحجة والمحرم يعظم انتهاك المحارم فيها بأشد مما يعظم في غيرها { ذلك الدين القيم } الحساب المستقيم { فلا تظلموا فيهن أنفسكم } تحفظوا من أنفسكم في الحرم فإن الحسنات فيهن تضعف وكذلك السيئات { وقاتلوا المشركين كافة كما يقاتلونكم كافة } قاتلوهم كلهم ولا تحابوا بعضهم بترك القتال كما إنهم يستحلون قتال جميعكم { واعلموا أن الله مع المتقين } مع أوليائه الذين يخافونه<br />
