{ إلا تنفروا } تخرجوا مع نبيكم إلى الجهاد { يعذبكم عذابا أليما } بالقحط وحبس المطر { ويستبدل قوما غيركم } يأت بقوم آخرين ينصر بهم رسوله { ولا تضروه شيئا } لأن الله عصمه عن الناس ولا يخذله أن تثاقلتم كما لم يضره قلة ناصريه حين كان بمكة وهم به الكفار فتولى الله نصره وهو قوله { إلا تنصروه فقد نصره الله إذ أخرجه الذين كفروا }<br />
