{ قال } داود عليه السلام { لقد ظلمك بسؤال نعجتك } أي بسؤاله إياك نعجتك امرأتك أن يضمها { إلى نعاجه وإن كثيرا من الخلطاء } الشركاء { ليبغي بعضهم على بعض إلا الذين آمنوا وعملوا الصالحات وقليل ما هم } وقليل هم { وظن داود } علم عند ذلك { أنما فتناه } ابتليناه بتلك المرأة التي أحب أن يتزوجها ثم تزوجها بعد قتل زوجها { فاستغفر ربه } مما فعل وهو محبته أن يتزوج امرأة من له امرأة واحدة وله تسع وتسعون امرأة { وخر راكعا } سقط للسجود بعد ما كان راكعا { وأناب } رجع إلى الله سبحانه بالتوبة<br />
