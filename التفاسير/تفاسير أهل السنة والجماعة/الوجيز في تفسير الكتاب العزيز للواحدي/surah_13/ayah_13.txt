{ ويسبح الرعد } وهو الملك الموكل بالسحاب { بحمده } وهو ما يسمع من صوته وذلك تسبيح لله تعالى { والملائكة من خيفته } أي وتسبح الملائكة من خيفة الله تعالى وخشيته { ويرسل الصواعق } وهو التي تحرق من برق السحاب وينتشر على الأرض ضوؤه { فيصيب بها من يشاء } كما أصاب أربد حين جادل النبي صلى الله عليه وسلم وهو قوله { وهم يجادلون في الله } والواو للحال وكان أربد جادل النبي صلى الله عليه وسلم فقال أخبرني عن ربنا أمن نحاس أم حديد فأحرقته الصاعقة { وهو شديد المحال } العقوبة أي القوة<br />
