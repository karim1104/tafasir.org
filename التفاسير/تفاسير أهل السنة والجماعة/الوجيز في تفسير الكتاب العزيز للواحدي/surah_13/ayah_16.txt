{ قل } يا محمد للمشركين { من رب السماوات والأرض } ثم أخبرهم فقل { الله } لأنهم لا ينكرون ذلك ثم ألزمهم الحجة فقل { أفاتخذتم من دونه أولياء } توليتم غير رب السماء والأرض أصناما { لا يملكون لأنفسهم نفعا ولا ضرا } ثم ضرب مثلا للذي يعبدها والذي يعبد الله سبحانه فقال { قل هل يستوي الأعمى } المشرك { والبصير } المؤمن { أم هل تستوي الظلمات } الشرك { والنور } الإيمان { أم جعلوا لله شركاء } الآية يعني أجعلوا لله شركاء خلقوا مثل ما خلق الله فتشابه خلق الشركاء بخلق الله عندهم وهذا استفهام إنكار أي ليس الأمر على هذا حتى يشتبه الأمر بل الله سبحانه هو المتفرد بالخلق وهو قوله { قل الله خالق كل شيء }<br />
