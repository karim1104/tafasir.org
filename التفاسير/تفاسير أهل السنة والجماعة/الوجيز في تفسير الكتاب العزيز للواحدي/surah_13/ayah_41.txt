{ أولم يروا } يعني مشركي مكة { أنا نأتي الأرض } نقصد أرض مكة { ننقصها من أطرافها } بالفتوح على المسلمين يقول أولم ير أهل مكة أنا نفتح لمحمد ص ما حولها من القرى أفلا يخافون أن تنالهم يا محمد { والله يحكم } بما يشاء { لا معقب لحكمه } لا احد يتتبع ما حكم به فيغيره ،   والمعنى لا ناقض لحكمه ولا راد له { وهو سريع الحساب } أي المجازاة .  <br />
