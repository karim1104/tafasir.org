{ وابتلوا اليتامى } أي اختبروهم في عقولهم وأديانهم { حتى إذا بلغوا النكاح }<br />
أي حال النكاح من الاحتلام { فإن آنستم } أبصرتم { منهم رشدا } صلاحا للعقل وحفظا للمال { ولا تأكلوها إسرافا وبدارا أن يكبروا } أي لا تبادروا بأكل مالهم كبرهم ورشدهم حذر أن يبلغوا فيلزمكم تسليم المال إليهم { ومن كان غنيا } من الأوصياء { فليستعفف } عن مال اليتيم ولا يأكل منه شيئا { ومن كان فقيرا فليأكل بالمعروف } يقدر أجرة عمله { فإذا دفعتم } أيها الأولياء { إليهم } إلى اليتامى { أموالهم فأشهدوا عليهم } لكي إن وقع اختلاف أمكن الولي أن يقيم البينة على رد المال إليه { وكفى بالله حسيبا } محاسبا ومجازيا للمحسن والمسيء<br />
