{ لا إكراه في الدين } بعد إسلام العرب لأنهم أكرهوا على الإسلام فلم يقبل منهم الجزية لأنهم كانوا مشركين فلما أسلموا أنزل الله تعالى هذه الاية { قد تبين الرشد من الغي } ظهر الإيمان من الكفر والهدى من الضلالة بكثرة الحجج { فمن يكفر بالطاغوت } بالشيطان والأصنام {  } واليوم الآخر { فقد استمسك } أي تمسك { بالعروة الوثقى } عقد لنفسه عقدا وثيقا وهو الإيمان وكلمة الشهادتين { لا انفصام لها } أي لا انقطاع لها { والله سميع } لدعائك يا محمد إياي بإسلام أهل الكتاب وكان رسول الله صلى الله عليه وسلم يحب إسلام أهل الكتاب الذين حول المدينة ويسأل الله ذلك { عليم } بحرصك واجتهادك<br />
