ثم قرر مثل المرائي في النفقة والمفرط في الطاعة إلى أن يموت بقوله { أيود أحدكم } الآية يقول مثلهم كمثل رجل كانت له جنة فيها من كل الثمرات { وأصابه الكبر } فضعف عن الكسب وله أطفال لا يجدون عليه ولا ينفعونه { فأصابها إعصار } وهي ريح شديدة { فيه نار فاحترقت } ففقدها أحوج ما كان إليها عند كبر السن وكثرة العيال وطفولة الولد فبقي هو وأولاده عجزة متحيرين { لا يقدرون على } حيلة كذلك يبطل الله عمل المنافق والمرائي حتى لا توبة لهما ولا إقالة من ذنوبهما { كذلك يبين الله } كمثل بيان هذه الأقاصيص { يبين الله لكم الآيات } في أمر توحيده<br />
