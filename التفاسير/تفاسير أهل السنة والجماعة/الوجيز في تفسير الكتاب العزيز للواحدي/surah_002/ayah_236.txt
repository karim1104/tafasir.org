{ لا جناح عليكم إن طلقتم النساء ما لم تمسوهن } نزلت في رجل من الأنصار تزوج امرأة ولم يسم لها مهرا ثم طلقها قبل أن يمسها فأعلم الله تعالى أن عقد التزويج بغير مهر جائز ومعناه لاسبيل للنساء عليكم إن طلقتموهن من قبل المسيس والفرض بصداق ولا نفقة وقوله { أو تفرضوا لهن فريضة } أي توجبوا لهن صداقا { ومتعوهن } أي زودوهن وأعطوهن من ما لكم ما يتمتعن به فالمرأة إذا طلقت قبل تسمية المهر وقبل المسيس فانها تستحق المتعة بإجماع العلماء ولا مهر لها و { على الموسع } أي الغني الذي يكون في سعة من غناه { قدره } أي قدر إمكانه { وعلى المقتر } الذي في ضيق من فقره قدر إمكانه أعلاها خادم وأوسطها ثوب وأقلها أقل ماله ثمن قال الشافعي وحسن ثلاثون درهما { متاعا } أي متعوهن متاعا { بالمعروف } بما تعرفون أنه القصد وقدر الإمكان { حقا } واجبا { على المحسنين }<br />
