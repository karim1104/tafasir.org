{ شهر رمضان } أي هي شهر رمضان يعني تلك الأيام المعدودات شهر رمضان { الذي أنزل فيه القرآن } أنزل جملة واحدة من اللوح المحفوظ في ليلة القدر من شهر رمضان فوضع في بيت العزة في سماء الدنيا ،   ثم نزل به جبريل عليه السلام على محمد ص نجوما نجوما عشرين سنة { هدى للناس } هاديا للناس { وبينات من الهدى } وآيات واضحات من الحلال والحرام والحدود  والأحكام ،   { والفرقان } الفرق بين الحق والباطل  ،  { فمن شهد منكم الشهر } فمن حضر منكم بلده في الشهر { فليصمه } { فمن كان منكم مريضا أو على سفر فعدة من أيام أخر } أعاد هاهنا تخيير المريض والمسافر لأن الآية الأولى وردت في التخيير للمريض والمسافر والمقيم ،   وفي هذه الآية نسخ تخيير المقيم فأعيد ذكر تخيير المريض والمسافر ليعلم أنه باق على ما كان { يريد الله بكم اليسر } بالرخصة للمسافر والمريض { ولا يريد بكم العسر } لأنه لم يشدد ولم يضيق عليكم { ولتكملوا } عطف على محذوف والمعنى يريد الله بكم اليسر ولا يريد بكم العسر ليسهل عليكم { ولتكملوا العدة } أي ولتكملوا عدة ما أفطرتم بالقضاء اذا أقمتم وبرأتم { ولتكبروا الله } يعني التكبير ليلة الفطر إذا رئي هلال شوال { على ما هداكم } أرشدكم من شرائع الدين .  <br />
