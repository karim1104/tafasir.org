{ ولا جناح عليكم فيما عرضتم به } أي تكلمتم به من غير تصريح وهو أن يضمن الكلام دلالة على ما يريد { من خطبة النساء } أي التماس نكاحهن في العدة يعني المتوفى عنها الزوج يجوز التعريض بخطبتها في العدة وهو أن يقول لها وهي في العدة إنك لجميلة وإنك لنافقة وإنك لصالحة وإن من عزمي أن أتزوج وما أشبه ذلك { أو أكننتم } أسررتم وأضمرتم { في أنفسكم } من خطبتهن ونكاحهن { علم الله أنكم ستذكرونهن } يعني الخطبة { ولكن لا تواعدوهن سرا } أي لا تأخذوا ميثاقهن أن لا ينكحن غيركم { إلا أن تقولوا قولا معروفا } أي التعريض بالخطبة كما ذكرنا { ولا تعزموا عقدة النكاح } أي لا تصححوا عقدة النكاح { حتى يبلغ الكتاب أجله } حتى تنقضي العدة المفروضة { واعلموا أن الله يعلم ما في أنفسكم } أي مطلع على ما في ضمائركم { فاحذروه } فخا فوه<br />
