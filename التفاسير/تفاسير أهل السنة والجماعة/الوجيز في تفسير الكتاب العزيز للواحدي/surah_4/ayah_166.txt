{ لكن الله يشهد } الآية نزلت حين قالت اليهود لما سئلوا عن نبوة محمد ما نشهد له بذلك فقال الله تعالى { لكن الله يشهد } أي يبين نبوتك { بما أنزل إليك } من القرآن ودلائله { أنزله بعلمه } أي وهو يعلم أنك أهل لإنزاله عليك لقيامك به { والملائكة يشهدون } لك بالنبوة إن جحدت اليهود وشهادة الملائكة إنما تعرف بقيام المعجزة فمن ظهرت معجزته شهدت الملائكة بصدقه { وكفى بالله شهيدا } أي كفى الله شهيدا<br />
