{ يستفتونك قل الله يفتيكم في الكلالة } فيمن مات ولا ولد له ولا والد { إن امرؤ هلك ليس له ولد } أراد ولا والد فاكتفى بذكر أحدهما لأنه الكلالة<br />
{ وله أخت } يعني من أب وأم أو أب لأن ذكر ولد الأم قد مضى في أول السورة { فلها نصف ما ترك وهو يرثها } الأخ يرث الأخت جميع المال { إن لم يكن لها ولد فإن كانتا } أي الأختان { فلهما الثلثان مما ترك وإن كانوا إخوة رجالا ونساء } من أب وأم أو من أب { فللذكر مثل حظ الأنثيين } وقوله { يبين الله لكم أن تضلوا } أي أن لا تضلوا أو كراهة أن تضلوا { والله بكل شيء عليم } من قسمه المواريث<br />
