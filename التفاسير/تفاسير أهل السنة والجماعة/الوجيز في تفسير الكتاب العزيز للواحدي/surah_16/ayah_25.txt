{ ليحملوا أوزارهم } هذه لام العاقبة لأن قولهم للقرآن أساطير الأولين أداهم الى أن حملوا أوزارهم كاملة لم يكفر منها شيء بنكبة أصابتهم في الدنيا لكفرهم { ومن أوزار الذين يضلونهم } لأنهم كانوا دعاة الضلالة فعليهم مثل أوزار من اتبعهم وقوله { بغير علم } أي يضلونهم جهلا منهم بما كانوا يكسبون من الاثم ثم ذم صنيعهم فقال { ألا ساء ما يزرون } أي يحملون<br />
