{ وكذلك } وكما فعلنا بهم هذه الأشياء { بعثناهم } أيقظناهم من تلك النومة التي تشبه الموت { ليتساءلوا بينهم } ليكون بينهم تساؤل عن مدة لبثهم { قال قائل منهم كم لبثتم } كم مر علينا منذ دخلنا الكهف { قالوا لبثنا يوما أو بعض يوم } وذلك أنهم دخلوا الكهف غدوة وبعثهم الله في آخر النهار لذلك قالوا يوما فلما رأوا الشمس قالوا أو بعض يوم وكان قد بقيت من النهار بقية فقال تمليخا { ربكم أعلم بما لبثتم } رد علم ذلك إلى الله سبحانه { فابعثوا أحدكم بورقكم } بدراهمكم { هذه إلى المدينة فلينظر أيها } أي أهلها { أزكى طعاما } أحل من جهة أنه ذبيحة مؤمن أو من جهة أنه غير مغصوب وقوله { وليتلطف } في دخول المدينة وشراء الطعام حتى لا يطلع عليه أحد { ولا يشعرن بكم } و لا يخبرن بكم ولا بمكانكم { أحدا }<br />
