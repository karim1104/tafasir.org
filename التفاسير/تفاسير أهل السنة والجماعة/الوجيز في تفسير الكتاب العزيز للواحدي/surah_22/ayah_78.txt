{ وجاهدوا في الله } في سبيل الله { حق جهاده } بنية صادقة { هو اجتباكم } اختاركم لدينه { وما جعل عليكم في الدين من حرج } ضيق لأنه سهل الشريعة بالترخيص { ملة أبيكم } اتبعوا ملة أبيكم { إبراهيم } كان هو في الحرمة كالأب صلى الله عليه وسلم ولذلك جعل أبا المسلمين { هو سماكم } أي الله تعالى سماكم { المسلمين من قبل } أي من قبل القرآن في سائر الكتب { وفي هذا } يعني القرآن { ليكون الرسول شهيدا عليكم } وذلك أنه يشهد لمن صدقه وعلى من كذبه { وتكونوا شهداء على الناس } تشهدون عليهم أن رسلهم قد بلغتهم وقوله { واعتصموا بالله } أي تمسكوا بدينه { هو مولاكم } ناصركم ومتولي أموركم { فنعم المولى ونعم النصير }<br />
