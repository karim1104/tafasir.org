{ ولا تطرد الذين يدعون ربهم } الآية نزلت في فقراء المؤمنين لما قال رؤساء الكفار للنبي صلى الله عليه وسلم نح هؤلاء عنك لنجالسك ونؤمن بك ومعنى { يدعون ربهم بالغداة والعشي } يعبدون الله بالصلوات المكتوبة { يريدون وجهه } يطلبون ثواب الله { ما عليك من حسابهم } من رزقهم { من شيء } فتملهم وتطردهم { وما من حسابك عليهم من شيء } أي ليس رزقك عليهم ولا رزقهم عليك وإنما يرزقك وإياهم الله الرازق فدعهم يدنوا منك ولا تطردهم { فتكون من الظالمين } لهم بطردهم<br />
