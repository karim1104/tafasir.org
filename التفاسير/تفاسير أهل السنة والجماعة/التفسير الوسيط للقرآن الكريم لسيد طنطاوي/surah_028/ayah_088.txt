{  ولا تدع مع الله } تعالى {  إلها آخر } أي :  واحذر أن تعبد مع الله تعالى إلها آخر .  فإن الحال والشأن والحق أنه {  لا إله } مستحق للعبادة {  إلا هو } وحده عز وجل . <br />
{  كل شيء } في هذا الوجود {  هالك } ومعدوم وزائل {  إلا وجهه } عز وجل . <br />
{  له } سبحانه {  الحكم } النافذ الذي لا مرد له . <br />
{  وإليه } وحده {  ترجعون } أيها الناس فيحاسبكم على ما قدمتم وما أخرتم {  يوم لا تملك نفس لنفس شيئا والأمر يومئذ لله } . <br />
وبعد :  فهذه سورة القصص وهذا تفسير لها ،  نسأل الله تعالى أن يجعله خالصا لوجهه .  ونافعا لعباده . <br />
وصلى الله على سيدنا محمد وعلى آله وصحبه وسلم . <br />
