ثم بين - سبحانه - الحكمة من هذا الابتلاء والاختبار فقال :  {  لِّيَجْزِيَ الله الصادقين بِصِدْقِهِمْ } . <br />
أى :  فعل - سبحانه - ما فعل فى غزوة الأحزاب من أحداث ،  ليجزى الصادقين فى إيمانهم الجزاء الحسن الذى يستحقونه بسبب صدقهم ووفائهم . <br />
{  وَيُعَذِّبَ المنافقين إِن شَآءَ } أى :  إن شاء تعذيبهم بسبب موتهم على نفاقهم . <br />
{  أَوْ يَتُوبَ عَلَيْهِمْ } من نفاقهم بفضله وكرمه فلا يعذبهم . <br />
قال الجمل :  وقوله :  {  وَيُعَذِّبَ المنافقين إِن شَآءَ } جوابه محذوف ،  وكذلك مفعول {  شَآءَ } محذوف - أيضا - إن شاء تعذيبهم عذبهم . <br />
والمراد بتعذيبهم إماتتهم على النفاق ،  بدليل العطف فى قوله {  أَوْ يَتُوبَ عَلَيْهِمْ } . <br />
{  إِنَّ الله } - تعالى - {  كَانَ } وما زال {  غَفُوراً رَّحِيماً } أى :  واسع المغفرة والرحمة لمن يشاء من عباده . <br />
