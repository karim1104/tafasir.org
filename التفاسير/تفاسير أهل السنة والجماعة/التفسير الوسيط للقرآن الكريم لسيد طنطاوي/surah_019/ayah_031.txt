وقوله :  {  وَجَعَلَنِي نَبِيّاً } أدعو الناس إلى عبادته وحده {  وَجَعَلَنِي } أيضاً بجانب نبوتى {  مُبَارَكاً } أى :  كثير الخير والبركة {  أَيْنَ مَا كُنتُ } أى :  حينما حللت جعلنى مباركاً ،  فأينما شرطية وجوابها محذوف لدلالة ما قبله عليه . <br />
{  وَأَوْصَانِي بالصلاة والزكاة } أى :  بالمحافظة على أدائهما {  مَا دُمْتُ حَيّاً } فى هذه الدنيا . <br />
