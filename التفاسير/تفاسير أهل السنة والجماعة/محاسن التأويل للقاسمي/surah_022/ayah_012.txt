وقوله تعالى :<br />
{ يَدْعُو مِن دُونِ اللَّهِ مَا لَا يَضُرُّهُ وَمَا لَا يَنفَعُهُ ذَلِكَ هُوَ الضَّلَالُ الْبَعِيدُ } . <br />
{ يَدْعُو مِن دُونِ اللَّهِ مَا لَا يَضُرُّهُ وَمَا لَا يَنفَعُهُ } أي حال ثابتة من فاعل { انقلب } والأولى { خسر } ولذلك قرئ { خاسر } أي ارتد عن دين الله يدعو من دونه آلهة لا تضره ،  إن لم يعبدها في الدنيا ،  ولا تنفعه في الآخرة إن عبدها .  وقال أبو السعود { يدعو } استئناف مبين لعظيم الخسران { ذَلِكَ هُوَ الضَّلَالُ الْبَعِيدُ } أي عن الحق والهدى . <br />
