{ وَقَالَ الَّذِينَ كَفَرُوا لَن نُّؤْمِنَ بِهَذَا الْقُرْآنِ وَلَا بِالَّذِي بَيْنَ يَدَيْهِ } وهو ما نزل قبل القرآن من كتبه تعالى { وَلَوْ تَرَى إِذِ الظَّالِمُونَ مَوْقُوفُونَ عِندَ رَبِّهِمْ يَرْجِعُ بَعْضُهُمْ إِلَى بَعْضٍ الْقَوْلَ } أي يتجاذبون أطراف المحادثة ويتراجعونها بينهم .  ثم أبدل من { يرجع } قوله : { يَقُولُ الَّذِينَ اسْتُضْعِفُوا } وهم الأتباع { لِلَّذِينَ اسْتَكْبَرُوا } وهم قادتهم وسادتهم { لَوْلَا أَنتُمْ لَكُنَّا مُؤْمِنِينَ } . <br />
