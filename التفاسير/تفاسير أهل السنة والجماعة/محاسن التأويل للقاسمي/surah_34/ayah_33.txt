{ وَقَالَ الَّذِينَ اسْتُضْعِفُوا لِلَّذِينَ اسْتَكْبَرُوا بَلْ مَكْرُ اللَّيْلِ وَالنَّهَارِ } أي مكركم فيها وإغراؤكم وتمنيتكم لنا { إِذْ تَأْمُرُونَنَا أَن نَّكْفُرَ بِاللَّهِ وَنَجْعَلَ لَهُ أَندَادًا } أي نظراء وآلهة معه { وأسروا } أي الجميع من السادة والأتباع { الندامة لما رأوا العذاب وجعلنا الأغلال في أعناق الذين كفروا } وهي السلاسل التي تجمع أيديهم مع أعناقهم { هَلْ يُجْزَوْنَ إِلَّا مَا كَانُوا يَعْمَلُونَ } أي بأعمالهم كل بحسبه .  للقادة عذاب بحسبهم .  وللأتباع بحسبهم . <br />
