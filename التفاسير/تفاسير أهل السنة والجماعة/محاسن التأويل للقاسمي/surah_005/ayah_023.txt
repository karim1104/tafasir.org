[ 23 ] { قال رجلان من الذين يخافون أنعم الله عليهما ادخلوا عليهم الباب فإذا دخلتموه فإنكم غالبون وعلى الله فتوكلوا إن كنتم مؤمنين ( 23 ) } . <br />
{ قال رجلان } هما يوشع بن نون وكالب بن يفنا { من الذين يخافون } أي : يخافون الله تعالى دون العدو ،  ويتقونه في مخالفة أمره ونهيه . <br />
وقال العلامة البقاعي : أي من الذين يوجد منهم الخوف من الجبارين .  ومع ذلك لم يخافا . <br />
{ أنعم الله عليهما } أي : بالتثبيت والثقة بوعده تعالى ومعرفة مقام أوامره تعلى { ادخلوا عليهم الباب } أي : باب بلدهم ،  أي : باغتوهم وامنعوهم من البروز إلى الصحراء لئلا يجدوا للحرب مجالا { فإذا دخلتموه } – أي : باب بلدهم- { فإنكم غالبون } عليهم { وعلى الله فتوكلوا } أي : لا على قوة أنفسكم { إن كنتم مؤمنين } أي : بكمال قدرته ووعده النصر .
