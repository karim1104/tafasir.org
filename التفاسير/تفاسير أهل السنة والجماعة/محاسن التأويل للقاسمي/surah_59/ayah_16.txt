{ كمثل الشيطان } أي مثل المنافقين في إغراء بني النضير على القتال ووعدهم النجدة أو الخروج معهم ومثل اخداع بني النضير بوعد أولئك الكاذب كمثل الشيطان { إذ قال للإنسان اكفر } أي إذا غر إنسانا ووعده على اتباعه وكفره بالله ،  النصرة عند الحاجة إليه { فلما كفر } أي بالله واتبعه وأطاعه { قال } أي مخافة أن يشركه في عذابه مسلما له خاذلا { إني بريء منك } أي فلا أعينك { إني أخاف الله رب العالمين } أي في نصرتك فلم ينفعه التبرؤ ،  كما لم ينفع الأول وعده الإعانة <br />
