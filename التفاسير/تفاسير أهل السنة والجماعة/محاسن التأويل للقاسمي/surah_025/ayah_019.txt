ثم أشار تعالى لاحتجاجه على عبدتهم وإلزامهم ما يبكتهم ،  بقوله :<br />
{ فَقَدْ كَذَّبُوكُم } أي المعبودون ،  أيها الكفرة { بِمَا تَقُولُونَ } أي في قولكم إنهم آلهة .  أو في قولكم هؤلاء أضلونا { فَمَا تَسْتَطِيعُونَ } أي ما تملكون { صَرْفًا } أي دفعا للعذاب عنكم بوجه ما { وَلَا نَصْرًا } أي لأنفسكم من البوار { وَمَن يَظْلِم مِّنكُمْ } أيها المكلفون ،  كدأب هؤلاء { نُذِقْهُ عَذَابًا كَبِيرًا } . <br />
