{ وَالَّذِينَ لَا يَدْعُونَ مَعَ اللَّهِ إِلَهًا آخَرَ } أي لا يشركون بعبادة ربهم أحدا ،  فالدعاء بمعنى العبادة { وَلَا يَقْتُلُونَ النَّفْسَ الَّتِي حَرَّمَ اللَّهُ } أي حرمها بمعنى حرم قتلها .  ومنه الوأد وغيره { إِلَّا بِالْحَقِّ } أي المزيل لحرمتها وعصمتها { وَلَا يَزْنُونَ ،  وَمَن يَفْعَلْ ذَلِكَ } أي ما ذكر من هذه القبائح العظام { يَلْقَ أَثَامًا } أي يجد في الآخرة جزاء إثمه<br />
