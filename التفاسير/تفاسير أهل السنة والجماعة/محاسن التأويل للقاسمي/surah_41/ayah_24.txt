{ فَإِن يَصْبِرُوا فَالنَّارُ مَثْوًى لَّهُمْ وَإِن يَسْتَعْتِبُوا فَمَا هُم مِّنَ الْمُعْتَبِينَ } . <br />
{ فَإِن يَصْبِرُوا } أي على النار { فَالنَّارُ مَثْوًى لَّهُمْ } أي منزل ومسكن { وَإِن يَسْتَعْتِبُوا } أي يسألوا العتبى وهي الرجعة إلى الذين يحبون { فَمَا هُم مِّنَ الْمُعْتَبِينَ } أي المجابين إليه ،  فلا يخفف عنهم العذاب . <br />
