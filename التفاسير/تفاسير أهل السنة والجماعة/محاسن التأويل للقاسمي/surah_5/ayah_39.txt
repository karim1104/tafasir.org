وقوله تعالى : [ 39 ] { فمن تاب من بعد ظلمه وأصلح فإن الله يتوب عليه إن الله غفور رحيم ( 39 ) } . <br />
{ فمن تاب } أي : رجع من السراق إلى الله { من بعد ظلمه } أي : سرقته { وأصلح } أي : عمله { فإن الله يتوب عليه } أي : يقبل توبته فلا يعذبه في الآخرة { إن الله غفور رحيم } أي : مبالغ في المغفرة ولذلك يقبل توبته .  وهو تعليل لما قبله . <br />
قال أبو السعود : وإظهار الاسم الجليل للإشعار بعلة الحكم وتأييد استقلال الجملة .
