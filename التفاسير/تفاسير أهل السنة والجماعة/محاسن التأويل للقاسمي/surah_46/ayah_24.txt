{ فلما رأوه عارضا مستقبل أوديتهم } أي فلما جاءهم عذاب الله الذي استعجلوه ،  / فرأوه عارضا في ناحية من نواحي السماء ،  متجها نحو مزارعهم { قالوا هذا عارض } أي سحاب عارض { ممطرنا } أي بغيث نحيا به { بل هو } أي قال هود بل هو { ما استعجلتم به } أي من العذاب { ريح } أي هي ريح .  أو بدل من ( ما ) ،  { فيها عذاب أليم * تدمر } أي تهلك { كل شيء } أي من أموالهم وأنفسهم { بأمر ربها } أي إذنه الذي لا يعارض ،  فلم تدفع عنهم آلهتهم ،  بل دمرتهم { فأصبحوا لا يرى إلا مساكنهم } أي بيوتهم . <br />
ثم أشار إلى أن هذا لا يقتصر على عاد ،  بل ينتظر لمن كان على شاكلتهم من أهل مكة وغيرها ،  بقوله { كذلك نجزي القوم المجرمين } أي الكافرين إذا تمادوا في غيهم ،  وطغوا على ربهم . <br />
