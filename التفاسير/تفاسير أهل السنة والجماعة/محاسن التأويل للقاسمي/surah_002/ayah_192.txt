{ فإن انتهوا فإن الله غفور رحيم 192 } . <br />
{ فإن انتهوا } أي : عن القتال { فإن الله غفور رحيم } أي : فكفّوا عنهم ولا تتعرّضوا لهم تخلقا بصفتي الحق تعالى المذكورتين وهما : المغفرة والرحمة ،  هذا ظاهر المساق . <br />
وقال بعضهم : { فإن انتهوا } أي : عن الشرك والقتال { فإن الله غفور } لما سلف من طغيانهم { رحيم } بقبول توبتهم وإيمانهم .
