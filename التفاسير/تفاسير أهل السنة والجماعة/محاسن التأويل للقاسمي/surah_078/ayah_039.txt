وقوله تعالى { لا يتكلمون إلا من أذن له الرحمن وقال صوابا } أي لا يتكلمون في الشفاعة ،  كقوله {[7329]} { يوم يأت لا تلكم نفس إلا بإذنه } . <br />
قال الزمخشري هما شريطتان أن يكون المتكلم منهم مأذونا له في الكلام وأن يتكلم بالصواب فلا يشفع لغير مرتضى لقوله تعالى {[7330]} { ولا يشفعون إلا لمن ارتضى } . <br />
{ ذلك اليوم الحق } أي الواقع الذي لا يمكن إنكاره { الحق } صفة أو خبر { فمن شاء اتخذ إلى ربه مئابا } قال ابن جرير{[7331]} أي فمن شاء اتخذ بالتصديق بهذا اليوم الحق والاستعداد له والعمل بما فيه النجاة له من أهواله مرجعا حسنا يؤوب إليه .
