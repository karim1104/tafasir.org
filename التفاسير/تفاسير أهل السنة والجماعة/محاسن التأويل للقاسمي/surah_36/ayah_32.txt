{ وَإِن كُلٌّ لَّمَّا جَمِيعٌ لَّدَيْنَا مُحْضَرُونَ } . <br />
{ وَإِن كُلٌّ } أي  :من هؤلاء المتفرقين { لَّمَّا جَمِيعٌ لَّدَيْنَا مُحْضَرُونَ } أي : إلا جميعهم محضرون للحساب والجزاء ،  وإنما أخبر عن { كل } بجميع ومعناهما واحد ؛ لأن { كلا } تفيد الإحاطة حتى لا ينفلت عنهم أحد .  و { جميع } تفيد الاجتماع ،  وهو فعيل بمعنى مفعول ،  وبينهما فرق .  ومن ثم وقع أجمع في التوكيد تابعا ل ( الكل ) ؛ لأنه أخص منه وأزيد معنى . <br />
