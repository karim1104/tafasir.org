{ وَامْتَازُوا الْيَوْمَ أَيُّهَا الْمُجْرِمُونَ } أي عن المؤمنين في موقفهم .  كقوله تعالى : {[6336]} { ويوم نحشرهم جميعا ثم نقول للذين أشركوا مكانكم أنتم وشركاؤكم فزيلنا بينهم } وقوله :{[6337]} { ويوم تقوم الساعة يومئذ يتفرقون } { يومئذ يصدعون } أي يصيرون صدعين فرقتين{[6338]} { احشروا الذين ظلموا وأزواجهم وما كانوا يعبدون * من دون الله فاهدوهم إلى صراط الجحيم } .
