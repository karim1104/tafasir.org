{ أَلَمْ يَرَوْا كَمْ أَهْلَكْنَا قَبْلَهُم مِّنْ الْقُرُونِ أَنَّهُمْ إِلَيْهِمْ لاَ يَرْجِعُونَ } . <br />
{ ألم يروا } أي : يخبروا { كَمْ أَهْلَكْنَا قَبْلَهُم مِّنْ الْقُرُونِ } أي : من الأمم الخالية { أَنَّهُمْ إِلَيْهِمْ لاَ يَرْجِعُونَ } أي  :كيف لم يكن لهم إلى هذه الدنيا كرة ولا رجعة . <br />
