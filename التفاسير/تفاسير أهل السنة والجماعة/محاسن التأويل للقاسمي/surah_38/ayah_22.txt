{ إذ دخلوا عَلَى دَاوُودَ فَفَزِعَ مِنْهُمْ قَالُوا لَا تَخَفْ } أي منا .  فلسنا فاتكين وإنما نحن { خصمان } أي شخصان متخاصمان تحاكمنا إليك { بَغَى بَعْضُنَا عَلَى بَعْضٍ } أي تعدى { فَاحْكُم بَيْنَنَا بِالْحَقِّ } أي بما يطابق أمر الله { وَلَا تشطط } أي ولا تبعد عن الحق ولا تجاوزه { وَاهْدِنَا إِلَى سَوَاء الصِّرَاطِ } أي بحيث لا تميل عن الحق أصلا . <br />
