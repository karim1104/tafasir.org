[ 44 ] { وأنذر الناس يوم يأتيهم العذاب فيقول الذين ظلموا ربنا أخرنا إلى أجل قريب نجب دعوتك ونتبع الرسل أو لم تكونوا أقسمتم من قبل ما لكم من زوال 44 } . <br />
قوله : { وأنذر الناس يوم يأتيهم العذاب } يعني يوم القيامة { فيقول الذين ظلموا ربنا أخرنا } أي ردنا إلى الدنيا وأمهلنا { إلى أجل قريب } أي أمد من الزمان قريب { نجب دعوتك } أي إلى الإقرار بتوحيدك وأسمائك الحسنى .  { ونتبع الرسل } أي فيما دعونا إليه من الشرائع . <br />
{ أو لم تكونوا أقسمتم } على إضمار القول .  أي فيقال لهم توبيخا وتبكيتا  أو لم تكونوا تحلفون { من قبل } يعني في الدنيا { ما لكم من زوال } أي من دار الدنيا إلى دار أخرى للجزاء .  كقوله تعالى{[5163]} : { وأقسموا بالله جهد أيمانهم لا يبعث الله من يموت } .
