[ 26 ] { الله يبسط الرزق لمن يشاء ويقدر وفرحوا بالحياة الدنيا وما الحياة الدنيا في الآخرة إلا متاع 26 } . <br />
{ الله يبسط الرزق لمن يشاء ويقدر ؛ وفرحوا بالحياة الدنيا وما الحياة الدنيا في الآخرة إلا متاع } هذا كقوله تعالى{[5089]} : { أيحسبون أنما نمدهم به من مال وبنين * نسارع لهم في الخيرات بل لا يشعرون } .  وتنكير { متاع } للتقليل كما في آية{[5090]} : { قل متاع الدنيا قليل والآخرة خير لمن اتقى ولا تظلمون فتيلا } وقال{[5091]} : { بل توثرون الحياة الدنيا * والآخرة خير وأبقى } .
