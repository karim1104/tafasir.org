ثم بين بركته تعالى على إبراهيم بقوله :<br />
{ وَوَهَبْنَا لَهُ إِسْحَقَ وَيَعْقُوبَ نَافِلَةً وَكُلًّا جَعَلْنَا صَالِحِينَ } . <br />
{ وَوَهَبْنَا لَهُ إِسْحَقَ } أي بدعوته : { رب هب لي من الصالحين } { وَيَعْقُوبَ نَافِلَةً } أي زيادة وفضلا من غير سؤال .  ثم أشار إلى أن منشأ البركة فيهما الصلاح بقوله : { وَكُلًّا جَعَلْنَا صَالِحِينَ } بالاستقامة والتمكين في الهداية . <br />
