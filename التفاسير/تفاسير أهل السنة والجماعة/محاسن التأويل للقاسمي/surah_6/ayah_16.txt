[ 16 ] { من يصرف عنه يومئذ فقد رحمه وذلك الفوز المبين ( 16 ) } . <br />
{ من يصرف } بالبناء للمفعول ،  أي العذاب ،  { عنه يومئذ فقد رحمه } أي : نجاه وأنعم عليه ،  أو أدخله الجنة ،  لقوله : { فمن زحزح عن النار وأدخل الجنة }{[3376]} . <br />
وقوله : { يدخل من يشاء في رحمته }{[3377]} والجملة مستأنفة مؤكدة لتهويل العذاب .  { وذلك } أي الصرف أو الرحمة ،  { والفوز المبين } أي : الظاهر .
