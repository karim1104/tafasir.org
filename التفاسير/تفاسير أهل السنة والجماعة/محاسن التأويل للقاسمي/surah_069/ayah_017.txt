{ والملك على أرجائها } أي جوانبها وأطرافها حين تنشق { ويحمل عرش ربك فوقهم } أي فوق الملائكة الذين هم على أرجائها { يومئذ ثمانية } أي من الملائكة أو من صفوفها . <br />
قال ابن كثير يحتمل أن يكون المراد بهذا العرش ( العرش العظيم ) أو العرش الذي وضع في الأرض يوم القيامة ،  لفصل القضاء والله أعلم انتهى . <br />
ومثله من الغيوب التي يؤمن بها ولا يجب اكتناهها وتقدم في سورة الأعراف في تفسير آية{[7219]} { ثم استوى على العرش } كلام لبعض علماء الفلك على هذه الآية فتذكره . <br />
وذهب بعض منهم إلى أن المراد بالعرش ملكه تعالى للسموات والأرض وب ( الثمانية ) السموات السبع والأرض .  وعبارته { ويحمل } بالجدب { عرش ربك } أي ملك ربك للأرض والسموات { فوقهم يومئذ } أي فوق الملائكة الذين هم على أرجائها يوم القيامة { ثمانية } أي السموات السبع والأرض . <br />
قال وهذا يدل على أن ( السبع ) ليس للكثرة بل المراد به الحقيقة فهم ثمانية يحملون العرش ،  أي ملك الأرض والسموات السبع بالجذب كما هو حاصل اليوم ولكن ذلك يكون بشكل عظيم جدا . <br />
ثم قال ولا وجه لمعترض يقول إن حملة العرش مسبحة ،  لقوله تعالى {[7220]} { الذين يحملون العرش ومن حوله يسبحون بحمد ربهم } فكيف تسبح السماوات والأرض ؟ لأنه يجاب بقوله تعالى{[7221]} { يسبح له السماوات السبع والأرض ومن فيهن } اه .
