{ آتُونِي زُبَرَ الْحَدِيدِ } أي ناولوني قطعة { حَتَّى إِذَا سَاوَى بَيْنَ الصَّدَفَيْنِ } أي بين جانبي الجبلين { قَالَ انفُخُوا } أي في الأكوار والحديد { حَتَّى إِذَا جَعَلَهُ } أي المنفوخ فيه { نَارًا } أي كالنار بالإحماء { قَالَ آتُونِي أُفْرِغْ عَلَيْهِ قِطْرًا } أي نحاسا مذابا ليلصق بالحديد ،  ويتدعم البناء به ويشتد . <br />
