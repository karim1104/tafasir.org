وقوله تعالى :<br />
{ فَلَمَّا بَلَغَا مَجْمَعَ بَيْنِهِمَا نَسِيَا حُوتَهُمَا فَاتَّخَذَ سَبِيلَهُ فِي الْبَحْرِ سَرَبًا ( 61 ) } . <br />
{ فَلَمَّا بَلَغَا مَجْمَعَ بَيْنِهِمَا } أي البحرين { نَسِيَا حُوتَهُمَا } أي خبر حوتهما ،  وتفقد أمره ،  وكانا تزوداه . <br />
{ فَاتَّخَذَ سَبِيلَهُ } أي طريقه { فِي الْبَحْرِ سَرَبًا } أي مثل السرب في الأرض ،  واضح مسلك ،  معجزة جعلت علامة للمطلوب .
