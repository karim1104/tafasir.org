{ قَالَ إِنَّكَ لَن تَسْتَطِيعَ مَعِيَ صَبْرًا ( 67 ) } . <br />
{ وَكَيْفَ تَصْبِرُ عَلَى مَا لَمْ تُحِطْ بِهِ خُبْرًا ( 68 ) } . <br />
{ قَالَ إِنَّكَ لَن تَسْتَطِيعَ مَعِيَ صَبْرًا } أي بوجه من الوجوه . <br />
ثم علل معتذرا بقوله : { وَكَيْفَ تَصْبِرُ عَلَى مَا لَمْ تُحِطْ بِهِ خُبْرًا } أي من أمور ستراها ،  إن صحبتني ،  ظواهرها مناكير وبواطينها لم يحط بها خبرك .
