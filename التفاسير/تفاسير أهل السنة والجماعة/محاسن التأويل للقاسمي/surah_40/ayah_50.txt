{ قَالُوا أَوَلَمْ تَكُ تَأْتِيكُمْ رُسُلُكُم بِالْبَيِّنَاتِ قَالُوا بَلَى قَالُوا فَادْعُوا وَمَا دُعَاء الْكَافِرِينَ إِلَّا فِي ضَلَالٍ } . <br />
{ قَالُوا أَوَلَمْ تَكُ تَأْتِيكُمْ رُسُلُكُم بِالْبَيِّنَاتِ } أي المتكاثرة على صدقهم ،  المنذرة بهذه الشدة { قَالُوا بَلَى } أي جاءوا بها وأخبروا مع البينات { قَالُوا فَادْعُوا } أي إن كان ينفعكم ،  وهيهات { وَمَا دُعَاء الْكَافِرِينَ إِلَّا فِي ضَلَالٍ } أي في ضياع لا يجاب . <br />
