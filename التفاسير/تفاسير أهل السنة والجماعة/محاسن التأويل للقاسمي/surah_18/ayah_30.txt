ثم علل الحث على الإيمان المفهوم من التخيير المتقدم ،  بقوله سبحانه :<br />
{ إِنَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ إِنَّا لَا نُضِيعُ أَجْرَ مَنْ أَحْسَنَ عَمَلًا ( 30 ) } . <br />
{ أُوْلَئِكَ لَهُمْ جَنَّاتُ عَدْنٍ تَجْرِي مِن تَحْتِهِمُ الْأَنْهَارُ يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ مِن ذَهَبٍ وَيَلْبَسُونَ ثِيَابًا خُضْرًا مِّن سُندُسٍ وَإِسْتَبْرَقٍ مُّتَّكِئِينَ فِيهَا عَلَى الْأَرَائِكِ نِعْمَ الثَّوَابُ وَحَسُنَتْ مُرْتَفَقًا ( 31 ) } . <br />
{ إِنَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ إِنَّا لَا نُضِيعُ أَجْرَ مَنْ أَحْسَنَ عَمَلًا * { أُوْلَئِكَ لَهُمْ جَنَّاتُ عَدْنٍ تَجْرِي مِن تَحْتِهِمُ الْأَنْهَارُ يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ مِن ذَهَبٍ وَيَلْبَسُونَ ثِيَابًا خُضْرًا مِّن سُندُسٍ } ،  وهو ما رق من الديباج { وَإِسْتَبْرَقٍ } وهو ما كثف منه { مُّتَّكِئِينَ فِيهَا عَلَى الْأَرَائِكِ } أي السرر على هيئة المتنعمين { نِعْمَ الثَّوَابُ } أي الجنات المذكورة { وَحَسُنَتْ مُرْتَفَقًا } أي متكئا .  وقيل المرتفق المنزل والمستقر ،  لآية<br />
{ إنها ساءت مستقرا ومقاما } وآية : { حسنت مستقرا ومقاما } .
