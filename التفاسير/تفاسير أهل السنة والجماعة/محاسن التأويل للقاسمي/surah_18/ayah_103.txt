{ قُلْ هَلْ نُنَبِّئُكُمْ بِالْأَخْسَرِينَ أَعْمَالًا * الَّذِينَ ضَلَّ سَعْيُهُمْ فِي الْحَيَاةِ الدُّنْيَا } / أي ضاع وبطل { وَهُمْ يَحْسَبُونَ أَنَّهُمْ يُحْسِنُونَ صُنْعًا * أُولَئِكَ الَّذِينَ كَفَرُوا بِآيَاتِ رَبِّهِمْ } أي التي جاءت بالعمل بها رسلهم { وَلِقَائِهِ } أي بالبعث والحساب والجزاء { فَحَبِطَتْ أَعْمَالُهُمْ } لكفرهم المذكور { فَلَا نُقِيمُ لَهُمْ يَوْمَ الْقِيَامَةِ وَزْنًا } أي فنزدرهم ولا نجعل لهم مقدارا واعتبارا ،  لأن مداره الأعمال الصالحة ،  وقد حبطت بالمرة { ذَلِكَ } أي الأمر ذلك .  وقوله : { جَزَاؤُهُمْ جَهَنَّمُ } جملة مبينة له ،  أو ( ذلك ) مبتدأ والجملة خبره ،  والعائد محذوف .  أي جزاؤهم به .  أو { جَزَاؤُهُمْ } خبر و { جَهَنَّمُ } عطف بيان له { بِمَا كَفَرُوا وَاتَّخَذُوا آيَاتِي وَرُسُلِي هُزُوًا } أي مهزوءا بهما .  وذلك موجب لشدة المقت والغضب والنكال . <br />
