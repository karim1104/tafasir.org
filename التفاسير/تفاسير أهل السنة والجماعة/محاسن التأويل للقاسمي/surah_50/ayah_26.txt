{ الذي جعل مع الله إلها آخر فألقياه في العذاب الشديد 26 } . <br />
{ الذي جعل مع الله إلها آخر } أي : عبد معه معبودا آخر من خلقه { فألقياه في العذاب الشديد } أي عذاب جهنم . <br />
لطيفة :<br />
الموصول إما مبتدأ مضمن معنى الشرط ،  وخبره { فألقياه } أو مفعول لمضمر يفسره { فألقياه } أو بدل من { كل كفار } فيكون { فألقياه } تكريرا للتوكيد .  قيل على الأخير : إنه مخالف لما ذكره أهل المعاني من أن بين المؤكد والمؤكد شدة اتصال تمنع من العطف .  وأجيب : بأنه من باب ( وحقك ثم حقك ) نزل التغاير بين المؤكد والمؤكد ،  والمفسِّر والمفسَّر ،  منزلة التغاير بين الذاتين بوجه خطابيّ .  ولو جعل { العذاب الشديد } نوعا من عذاب جهنم ومن أهواله ،  على أنه من باب{[6767]} { وملائكته ورسله وجبريل } كان حسنا . <br />
