/ [ 106 ] { ولا تدع من دون الله ما لا ينفعك ولا يضرك فإن فعلت فإنك إذا من الظالمين 106 } . <br />
{ ولا تدع } أي لا تعبد { من دون الله ما لا ينفعك } أي لا في الدنيا ولا في الآخرة إن عبدته { ولا يضرك } إن لم تعبده { فإن فعلت } أي عبدته { فإنك إذا من الظالمين } أي الضارين لنفسك ،  أو بوضع الأمر في غير موضعه{[4793]} { إن الشرك لظلم عظيم } .
