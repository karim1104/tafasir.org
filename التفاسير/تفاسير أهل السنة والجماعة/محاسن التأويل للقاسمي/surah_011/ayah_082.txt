[ 82 ] { فلما جاء أمرنا جعلنا عاليها سافلها وأمطرنا عليها حجارة من سجيل منضود 82 } . <br />
{ فلما جاء أمرنا } أي عذابنا { جعلنا عاليها سافلها } أي فقلبت تلك المدن ونبتها بسكانها جميعا { وأمطرنا عليها حجارة من سجيل } أي طين متحجر ،  كقوله{[4877]} : { حجارة من طين } ،  { منضود } أي يرسل بعضه في إثر بعض متتابعا . <br />
قال المهايمي : اتصل بعضه ببعض ،  ليرجموا رجم الزناة ،  بما يناسب قسوتهم ورينهم الذي اتصل بقلوبهم .
