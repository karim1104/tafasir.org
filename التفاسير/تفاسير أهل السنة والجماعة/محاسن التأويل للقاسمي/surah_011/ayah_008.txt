/ [ 8 ] { ولئن أخرنا عنهم العذاب إلى أمة معدودة ليقولن ما يحبسه ألا يوم يأتيهم ليس مصروفا عنهم وحاق بهم ما كانوا به يستهزئون 8 } . <br />
{ ولئن أخرنا عنهم العذاب إلى أمة معدودة } أي جماعة من الأوقات محصورة .  والعذاب هو عقاب الآخرة ،  أو عذاب الدنيا ببدر ،  أو هلاك المستهزئين الذين ماتوا قبل بدر { ليقولن } أي استهزاء { ما يحبسه } أي عنا .  { ألا يوم يأتيهم ليس مصروفا عنهم وحاق بهم } أي دار ونزل بهم { ما كانوا به يستهزئون } أي العذاب الذي كانوا به يستعجلون . <br />
لطيفة :<br />
( الأمة ) تستعمل في الكتاب والسنة في معان متعددة .  فيراد بها الأمد ،  كما هنا وقوله في يوسف{[4807]} : { وادّكر بعد أمة } .  والإمام المقتدى به ،  كقوله{[4808]} : { إن إبراهيم كان أمة قانتا لله } .  والملة والدين كآية{[4809]} : { إنا وجدنا آباءنا على أمة } .  والجماعة كآية{[4810]} : { ولما ورد ماء مدين وجد عليه أمة من الناس يسقون } .  وقوله تعالى{[4811]} : { ولقد بعثنا في كل أمة رسولا أن اعبدوا الله واجتنبوا الطاغوت }  أفاده ابن كثير  .
