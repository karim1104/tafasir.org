{ ولقد آتينا بني إسرائيل الكتاب والحكم والنبوة ورزقناهم من الطيبات وفضلناهم على العالمين 16 } . <br />
{ ولقد آتينا بني إسرائيل الكتاب } أي التوراة { والحكم } أي الفهم بالكتاب والعلم بالسنن التي لم تنزل بالكتاب { والنبوة } أي جعلنا منهم أنبياء ورسلا إلى الخلق { ورزقناهم من الطيبات } يعني المنّ والسلوى { وفضلناهم على العالمين } أي عالمي أهل زمانهم ،  بإيتائهم ما لم يؤت غيرهم ،  كما قال تعالى : { وآتيناهم بينات من الأمر فما اختلفوا إلا من بعد ما جاءهم العلم بغيا بينهم إن ربك يقضي بينهم يوم القيامة فيما كانوا فيه يختلفون 17 } .
