{ فَكُلًّا أَخَذْنَا بِذَنبِهِ فَمِنْهُم مَّنْ أَرْسَلْنَا عَلَيْهِ حَاصِبًا } أي ريحا عاصفا فيها حصباء وهم قوم لوط { وَمِنْهُم مَّنْ أَخَذَتْهُ الصَّيْحَةُ } كمدين وثمود { وَمِنْهُم مَّنْ خَسَفْنَا بِهِ الْأَرْضَ } كقارون { وَمِنْهُم مَّنْ أَغْرَقْنَا } كقوم نوح وفرعون وقومه { وَمَا كَانَ اللَّهُ لِيَظْلِمَهُمْ وَلَكِن كَانُوا أَنفُسَهُمْ يَظْلِمُونَ } أي بفعل ما يوجب ذلك ،  من البغي والفساد . <br />
