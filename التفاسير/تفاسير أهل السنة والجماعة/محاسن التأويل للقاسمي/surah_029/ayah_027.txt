{ وَوَهَبْنَا لَهُ } أي لإبراهيم { إِسْحَقَ وَيَعْقُوبَ } أي ولدا ونافلة ،  بمباركة الذرية { وَجَعَلْنَا فِي ذُرِّيَّتِهِ النُّبُوَّةَ وَالْكِتَابَ وَآتَيْنَاهُ أَجْرَهُ فِي الدُّنْيَا } أي بإيتاء الولد والذرية الطيبة واستمرار النبوة فيهم وانتماء أهل الملك إليه والثناء إلى آخر الدهر والصلاة عليه { وَإِنَّهُ فِي الْآخِرَةِ لَمِنَ الصَّالِحِينَ } . <br />
