{ وَهَذَا } أي القرآن الكريم { ذِكْرٌ } أي يتذكر به من يتذكر { مُّبَارَكٌ } أي كثير الخير والنفع { أَنزَلْنَاهُ أَفَأَنتُمْ لَهُ مُنكِرُونَ } أي مع ظهوره كون إنزاله كإيتاء التوراة .  وفي الاستفهام الإنكاري توبيخ لهم بأنه لا ينبغي لهم إنكاره وهم عارفون بمزايا إعجازه .  وتقديم { له } للفاصلة أو للحصر .  لأنهم معترفون بغيره مما في أيدي أهل الكتاب . <br />
