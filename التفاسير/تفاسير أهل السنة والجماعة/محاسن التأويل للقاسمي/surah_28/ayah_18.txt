{ فَأَصْبَحَ فِي الْمَدِينَةِ خَائِفًا يَتَرَقَّبُ } أي الاستقادة أو الأجناد .  { فَإِذَا الَّذِي اسْتَنصَرَهُ بِالْأَمْسِ } أي استعانه فقتل من أجله منازعه القبطي { يَسْتَصْرِخُهُ } أي يستغيثه من قبطي آخر { قَالَ لَهُ مُوسَى إِنَّكَ لَغَوِيٌّ مُّبِينٌ } أي بمخاصمتك الناس مع عجزك ،  وجرك إليهم ما لا تحمد عقباه<br />
