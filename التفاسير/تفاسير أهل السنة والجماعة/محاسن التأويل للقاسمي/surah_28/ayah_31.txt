{ وَأَنْ أَلْقِ عَصَاكَ فَلَمَّا رَآهَا تَهْتَزُّ } أي تتحرك { كَأَنَّهَا جَانٌّ } أي حية صغيرة ،  في سرعة الحركة { وَلَّى مُدْبِرًا } أي أعرض بوجهه عنها ،  جاعلا ظهره إليها { وَلَمْ يُعَقِّبْ } أي لم يرجع { يَا مُوسَى أَقْبِلْ وَلَا تَخَفْ إِنَّكَ مِنَ الْآمِنِينَ } أي من المخاوف . <br />
