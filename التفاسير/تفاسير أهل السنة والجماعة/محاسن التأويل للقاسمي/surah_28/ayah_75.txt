{ وَنَزَعْنَا } أي وأخرجنا { مِن كُلِّ أُمَّةٍ شَهِيدًا } أي نبيا يشهد عليهم بما كانوا عليه .  كقوله تعالى  {[6017]} { فكيف إذا جئنا من كل أمة بشهيد } { فَقُلْنَا } أي لكل أمة من تلك الأمم { هَاتُوا بُرْهَانَكُمْ } أي على ما أنتم عليه .  أحق هو أم لا ؟ فعجزوا عن آخرهم .  وظهر برهان النبي ،  كما قال تعالى : { فَعَلِمُوا أَنَّ الْحَقَّ لِلَّهِ } أي في الألوهية ،  لا يشاركه فيها أحد { وَضَلَّ عَنْهُم } أي غاب عنهم غيبة الضائع { مَّا كَانُوا يَفْتَرُونَ } أي من الباطل والمذاهب المختلفة ،  والطرق المتشعبة المتفرقة .
