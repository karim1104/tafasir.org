{ أَوَلَمْ يَرَوْا أَنَّا نَسُوقُ الْمَاء إِلَى الْأَرْضِ الْجُرُزِ } وهي التي جزر نباتها ،  أي قطع { فَنُخْرِجُ بِهِ زَرْعًا تَأْكُلُ مِنْهُ أَنْعَامُهُمْ وَأَنفُسُهُمْ } معنى العشب والثمار والبقول { أَفَلَا يُبْصِرُونَ } أي فيستدلون به على كمال قدرته ووجوب انفراده بالإلهية .  وهذه كآية {[6114]} : { فلينظر الإنسان إلى طعامه * أنا صببنا الماء صبا } الآية .
