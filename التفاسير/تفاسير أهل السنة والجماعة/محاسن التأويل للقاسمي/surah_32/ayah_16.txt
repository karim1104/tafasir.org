{ تَتَجَافَى جُنُوبُهُمْ عَنِ الْمَضَاجِعِ } أي ترتفع وتتنحى عن الفرش ومواضع النوم .  والجملة مستأنفة لبيان بقية محاسنهم ،  وهم المتهجدون بالليل { يَدْعُونَ رَبَّهُمْ } أي داعين له { خَوْفًا } من عذابه { وَطَمَعًا } في رحمته { وَمِمَّا رَزَقْنَاهُمْ } أي من المال { يُنفِقُونَ } أي في وجوه البر والحسنات . <br />
