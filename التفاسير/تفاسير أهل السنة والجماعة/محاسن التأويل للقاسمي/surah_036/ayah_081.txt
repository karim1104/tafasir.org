{ أَوَلَيْسَ الَّذِي خَلَقَ السَّمَاوَاتِ وَالْأَرْضَ بِقَادِرٍ عَلَى أَنْ يَخْلُقَ مِثْلَهُم بَلَى وَهُوَ الْخَلَّاقُ الْعَلِيمُ } . <br />
{ أَوَلَيْسَ الَّذِي خَلَقَ السَّمَاوَاتِ وَالْأَرْضَ } أي مع كبر جرمهما { بِقَادِرٍ عَلَى أَنْ يَخْلُقَ مِثْلَهُم } أي في الصغر والضعف ثانيا ،  بعدما خلقهم أولا { بلى } أي هو القادر { وَهُوَ الْخَلَّاقُ } أي الكثير الخلق مرة بعد أخرى { الْعَلِيمُ } أي الواسع المعلومات . <br />
