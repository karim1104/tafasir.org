{ سَلَامٌ قَوْلًا مِن رَّبٍّ رَّحِيمٍ } أي ولهم سلام يقال لهم قولا كائنا منه تعالى .  فيكون { سلام } مبتدأ محذوف الخبر .  أو هو بدل من ( مّا ) أو خبر لمحذوف ،  أي : هو سلام .  أو مبتدأ خبره الناصب ل { قولا } أي : سلام يقال لهم قولا .  أو مبتدأ وخبره { من رّبّ } و { قولا } مصدر مؤكد لمضمون الجملة .  وهو مع عامله معترض بين المبتدأ والخبر . <br />
والمعنى أنه تعالى يسلم عليهم تعظيما لهم .  كقوله :{[6335]} { تحيتهم يوم يلقونه سلام } .
