{ وَلَوْ تَرَى إِذِ الْمُجْرِمُونَ } وهم القائلون تلك المقالة الشنعاء { نَاكِسُو رُؤُوسِهِمْ عِندَ رَبِّهِمْ } أي مطأطئوها من الحياء والخزي ،  لما قدمت أيديهم { رَبَّنَا } أي يقولون ربنا { أَبْصَرْنَا وَسَمِعْنَا } أي علمنا ما لم نعلم ،  وأيقنا بما لم نكن موقنين { فَارْجِعْنَا } أي إلى الدنيا { نَعْمَلْ صَالِحًا إِنَّا مُوقِنُونَ } أي مقرون بك وبكتابك ورسولك والجزاء . <br />
