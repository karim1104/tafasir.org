قوله تعالى :  {  وَمَا جَعَلْنَا الْقِبْلَةَ الَّتِي كُنْتَ عَلَيْهَا .  .  .  } [ البقرة :  143 ] .  ؟ <br />
إن قلتَ :  كيف قال :  {  إِلَّا لِنَعْلَمَ مَنْ يَتَّبِعُ الرَّسُولَ } [ البقرة :  143 ] وهو لم يزل عالما بذلك ؟ <br />
قلتُ :  هذا ونحوه باعتبار التعلّق ،  والمعنى :  ليتعلّق علمنا به موجودا ،  أو المعنى :  ليعلم رسولنا والمؤمنون ،  لأنهم أخصّاؤه ،  أو لتميّز الثابت عن المتزلزل ،  كقوله {  لِيَمِيزَ اللَّهُ الْخَبِيثَ مِنَ الطَّيِّبِ } [ الأنفال :  37 ] . <br />
قوله تعالى :  {  وَمَا كَانَ اللَّهُ لِيُضِيعَ إِيمَانَكُمْ .  .  .  } [ البقرة :  143 ] . <br />
 " كان "  للماضي وهو هنا للحال ،  وتأتي في القرآن لخمسة معان : <br />
أ- للحال ومنه {  إِنَّ الصَّلَاةَ كَانَتْ عَلَى الْمُؤْمِنِينَ كِتَابًا مَوْقُوتًا } [ النساء :  103 ] و {  وَكَانَ اللَّهُ بِمَا تَعْمَلُونَ بَصِيرًا } [ الأحزاب :  9 ] . <br />
ب- وللماضي المنقطع ومنه {  وَكَانَ فِي الْمَدِينَةِ تِسْعَةُ رَهْطٍ } [ النمل :  48 ] وهو الأصل في معانيها . <br />
ج- وللاستقبال ومنه {  يُوفُونَ بِالنَّذْرِ وَيَخَافُونَ يَوْمًا كَانَ شَرُّهُ مُسْتَطِيرًا } [ الإنسان :  7 ] . <br />
د- وللدوام ومنه {  وَكَانَ اللَّهُ عَلِيمًا حَكِيمًا } [ الفتح :  4 ] . <br />
ه- وبمعنى صار ومنه {  وَكَانَ مِنَ الْكَافِرِينَ }( {[54]} ) [ البقرة :  34 ] .
