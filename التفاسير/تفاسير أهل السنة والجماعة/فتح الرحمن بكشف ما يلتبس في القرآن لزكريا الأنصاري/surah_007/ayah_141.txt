قوله تعالى :  {  وفي ذلكم بلاء من ربّكم عظيم } [ الأعراف :  141 ] . <br />
أي نعمة عظيمة ،  إن جعلت الإشارة راجعة إلى الإنجاء في قوله تعالى :  {  وإذ أنجيناكم من آل فرعون } [ الأعراف :  141 ] . <br />
أو محنة عظيمة ،  إن جعلتَ الإشارة راجعة إلى قتل الأبناء ،  واستحياء النساء( {[232]} ) ،  في قوله تعالى :  {  يقتّلون أبناءكم ويستحيون نساءكم } [ الأعراف :  141 ] .  إذِ  البلاء بين  " النِّعمة "  و " المحنة "  قال تعالى :  {  وبلوناهم بالحسنات والسّيّئات } [ الأعراف :  168 ] وقال :  {  ونبلوكم بالشرّ والخير فتنة وإلينا ترجعون } [ الأنبياء :  35 ] .
