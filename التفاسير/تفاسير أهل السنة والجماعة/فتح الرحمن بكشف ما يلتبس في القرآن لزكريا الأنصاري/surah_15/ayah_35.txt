قوله تعالى :  {  وإن عليك اللعنة إلى يوم الدين } [ الحجر :  35 ] . <br />
قال ذلك هنا بتعريف الجنس ،  ليناسب ما قبله من التعبير بالجنس ،  في قوله تعالى {  ولقد خلقنا الإنسان } [ الحجر :  26 ] {  والجان خلقناه } [ الحجر :  27 ] {  فسجد الملائكة } [ الحجر :  30 ] . <br />
وقال في ( ص ) :  {  وإن عليك لعنتي إلى يوم الدين } [ ص :  78 ] .  بالإضافة ،  ليناسب ما قبله من قوله :  {  ما منعك أن تسجد لما خلقت بيديّ } ؟  [ ص :  75 ] .
