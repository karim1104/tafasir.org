قوله تعالى :  {  فإذا جاء أمر الله قُضي بالحقّ وخسر هنالك المبطلون } [ غافر :  78 ] . <br />
ختمها بقوله :  {  المبطلون } وختم السورة بقوله :  {  وخسر هنالك الكافرون } [ غافر :  85 ] لأن الأول متّصل بقوله :  {  قُضي بالحقّ } ونقيض الحقّ :  الباطل ،  والثاني متّصل بإيمان غير نافع ،  ونقيض الإيمان :  الكفر .
