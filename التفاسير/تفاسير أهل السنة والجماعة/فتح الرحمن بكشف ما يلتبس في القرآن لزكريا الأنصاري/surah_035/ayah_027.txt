قوله تعالى :  {  فأخرجنا به ثمرات مختلفا ألوانها } [ فاطر :  27 ] . <br />
قاله هنا بتأنيث الضمير لعوده إلى الثمرات ،  وقال ثانيا :  {  مختلف ألوانها } [ فاطر :  27 ] بتأنيثه( {[522]} ) أيضا ،  لعوده إلى الجبال ،  وقال ثالثا :  {  مختلف ألوانه } [ فاطر :  28 ] بتذكيره( {[523]} ) ،  لعوده إلى بعض المفهوم من اللفظ من قوله :  {  ومن الناس والدّواب والأنعام } [ فاطر :  28 ] .
