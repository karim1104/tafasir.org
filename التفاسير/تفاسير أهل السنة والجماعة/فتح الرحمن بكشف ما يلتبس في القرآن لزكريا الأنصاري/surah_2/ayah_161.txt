قوله تعالى :  {  أُولَئِكَ عَلَيْهِمْ لَعْنَةُ اللَّهِ وَالْمَلَائِكَةِ وَالنَّاسِ أَجْمَعِينَ } [ البقرة :  161 ] . <br />
إن قلتَ :  كيف قال :  {  وَالنَّاسِ أَجْمَعِينَ } وأهل دين من مات كافرا لا يلعنونه ؟ <br />
قلتُ :  المراد بالناس المؤمنون ،  أو هم وغيرهم .  وأهل دينه يلعنونه في الآخرة ،  قال تعالى :  {  ثُمَّ يَوْمَ الْقِيَامَةِ يَكْفُرُ بَعْضُكُمْ بِبَعْضٍ وَيَلْعَنُ بَعْضُكُمْ بَعْضًا } [ العنكبوت :  25 ] وقال :  {  دَخَلَتْ أُمَّةٌ لَعَنَتْ أُخْتَهَا } [ الأعراف :  38 ] .
