قوله تعالى :  {  ثُمَّ تُوَفَّى كُلُّ نَفْسٍ مَا كَسَبَتْ وَهُمْ لَا يُظْلَمُونَ } [ البقرة :  281 ] . <br />
قال فيه وفي الجاثية ب {  مَا كَسَبَتْ } ( {[84]} ) [ الجاثية :  22 ] وقال في آخر النحل :  {  وَتُوَفَّى كُلُّ نَفْسٍ مَا عَمِلَتْ }( {[85]} ) [ النحل :  111 ] وفي آخر الزمر :  {  وَوُفِّيَتْ كُلُّ نَفْسٍ مَا عَمِلَتْ }( {[86]} ) [ الزمر :  70 ] .  .  .  موافقة لما قبل كلّ منها ،  أو بعده ،  أو قبله وبعده . <br />
إذ ما هنا قبله {  أَنْفِقُوا مِنْ طَيِّبَاتِ مَا كَسَبْتُمْ } [ البقرة :  267 ] وبعده :  {  لَهَا مَا كَسَبَتْ وَعَلَيْهَا مَا اكْتَسَبَتْ } [ البقرة :  286 ] . <br />
وقبله في آخر النحل :  {  مَنْ عَمِلَ صَالِحًا .  .  .  .  وَلَنَجْزِيَنَّهُمْ أَجْرَهُمْ بِأَحْسَنِ مَا كَانُوا يَعْمَلُونَ } [ النحل :  97 ] . <br />
وبعده :  {  ثُمَّ إِنَّ رَبَّكَ لِلَّذِينَ عَمِلُوا السُّوءَ } [ النحل :  119 ] . <br />
وقبل ما في الجاثية :  {  وَلَا يُغْنِي عَنْهُمْ مَا كَسَبُوا شَيْئًا } [ الجاثية :  10 ] . <br />
وبعد ما في الزمر :  {  فَنِعْمَ أَجْرُ الْعَامِلِينَ } [ الزمر :  74 ] .
