{  وَلَا تُمْسِكُوهُنَّ ضِرَارًا لِتَعْتَدُوا .  .  .  } [ البقرة :  231 ] . <br />
هو هنا بالتخفيف ،  من  " أمسك "  وفي الممتحنة بالتخفيف والتشديد( {[74]} ) ،  لمناسبة تخفيف لما هنا ما قبله من قوله :  {  فَإِمْسَاكٌ بِمَعْرُوفٍ } [ البقرة :  229 ] وقوله :  {  فَأَمْسِكُوهُنَّ } [ البقرة :  231 ] . <br />
ومناسبة تخفيف وتشديد ما هناك ما قبله من قوله :  {  وَلَمْ يُخْرِجُوكُمْ } [ الممتحنة :  8 ] وقوله :  {  أَنْ تَبَرُّوهُمْ } [ الممتحنة :  8 ] وخُفّف في الطلاق قوله :  {  فَأَمْسِكُوهُنَّ بِمَعْرُوفٍ } [ الطلاق :  2 ] لمناسبة تخفيفه ما قبله من قوله :  {  لَا تُخْرِجُوهُنَّ مِنْ بُيُوتِهِنَّ } [ الطلاق :  1 ] .
