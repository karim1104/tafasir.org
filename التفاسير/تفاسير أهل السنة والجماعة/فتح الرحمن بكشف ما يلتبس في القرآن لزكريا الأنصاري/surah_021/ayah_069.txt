قوله تعالى :  {  قلنا يا نار كوني بردا وسلاما على إبراهيم } [ الأنبياء :  69 ] . <br />
إن قلتَ :  كيف خاطب النار مع أنها لا تعقل ؟   ! <br />
قلتُ :  خطاب التّحويل والتكوين ،  لا يختصّ بمن يعقل كما مرّ ،  قال تعالى :  {  يا جبال أوّبي معه والطّير } [ سبأ :  10 ] وقال :  {  فقال لها وللأرض ائتيا طوعا أو كرها } [ فصلت :  11 ] وقال :  {  وقيل يا أرض ابلعي ماءك } [ هود :  44 ] .
