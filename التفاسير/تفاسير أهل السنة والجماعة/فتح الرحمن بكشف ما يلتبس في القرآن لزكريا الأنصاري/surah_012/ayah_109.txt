قوله تعالى :  {  أفلم يسيروا في الأرض فينظروا كيف كان عاقبة الذين من قبلهم .  .  .  } [ يوسف :  109 ] .  قاله هنا ،  وفي الحج( {[318]} ) ،  وفي آخر غافر( {[319]} ) بالفاء ،  وقاله في الروم( {[320]} ) ،  وفاطر( {[321]} ) ،  وأول غافر( {[322]} ) بالواو . <br />
لأن ما في الثلاثة الأول ،  تقدّمه التعبير في الإنكار بالفاء في قوله هنا {  أفأمنوا أن تأتيهم غاشية } [ يوسف :  107 ] وفي الحج {  فهي خاوية على عروشها } [ الحج :  45 ] وفي آخر غافر {  فأيّ آيات الله تنكرون } ؟  [ غافر :  81 ] . <br />
وما في الثلاثة الأخيرة ،  تقدّمه التعبير بالواو في قوله في الروم :  {  أولم يتفكروا في أنفسهم } [ الروم :  8 ] وفي فاطر {  أو لم نعمّرهم مّا يتذكر فيه من تذكّر } [ فاطر :  37 ] وفي أول غافر {  وأنذرهم يوم الآزفة } [ غافر :  18 ] {  وما تخفي الصدور } [ غافر :  19 ] {  والله يقضي بالحق والذين يدعون من دونه لا يقضون بشيء } [ غافر :  20 ] .
