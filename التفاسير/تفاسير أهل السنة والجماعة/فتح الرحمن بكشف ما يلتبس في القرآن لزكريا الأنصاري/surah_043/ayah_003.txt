قوله تعالى :  {  إنا جعلناه قرآنا عربيا لعلكم تعقلون } [ الزخرف :  3 ] . <br />
إن قلتَ :  القرآن ليس بمجعول ،  لأن الجَعْل هو الخلق ،  فلم لم يقل :  قلناه ،  أو أنزلناه( {[568]} ) ؟ <br />
قلتُ :  الجَعْلُ يأتي  بمعنى القول أيضا ،  كقوله تعالى :  {  ويجعلون لله البنات } [ النحل :  57 ] وقوله :  {  وجعلوا لله أندادا } [ إبراهيم :  30 ] .
