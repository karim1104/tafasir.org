قوله تعالى :  {  ولا تجادلوا أهل الكتاب إلا بالتي هي أحسن إلا الذين ظلموا منهم } [ العنكبوت :  46 ] . <br />
إن قلتَ :  كيف قال :  {  إلا الذين ظلموا } مع أن جميع أهل الكتاب ظالمون ،  لأنهم كافرون قال تعالى :  {  والكافرون هم الظالمون } [ البقرة :  254 ] ؟   ! <br />
قلتُ :  المراد بالظلم هنا :  الامتناع عن قبول عقد الذمّة ،  أو نقض العهد بعد قبوله( {[494]} ) .
