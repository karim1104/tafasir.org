قوله : { فَأَخَذْنَاهُ وَجُنُودَهُ فَنَبَذْنَاهُمْ فِي اليم } وهذا من الكلام المفحم الذي يدل على عظمة شأنه وكبرياء سلطانه ،   شبههم - استحقاراً لهم واستقلالاً لعددهم - وإن كانوا الجم الغفير - كحصيات{[40371]} أخذهن آخذ{[40372]} في كفه وطرحهُنَّ في البحر ،   ونحو ذلك قوله { وَجَعَلْنَا فِيهَا رَوَاسِيَ شَامِخَاتٍ } [ المرسلات : 27 ] { وَحُمِلَتِ الأرض والجبال فَدُكَّتَا دَكَّةً وَاحِدَةً } [ الحاقة : 14 ] { وَمَا قَدَرُوا الله حَقَّ قَدْرِهِ والأرض جَمِيعاً قَبْضَتُهُ يَوْمَ القيامة والسموات مَطْوِيَّاتٌ بِيَمِينِهِ } [ الزمر : 67 ] .   وليس الغرض منها إلا تصوير أنَّ كلَّ مقدور وإن عظم{[40373]} فهو حقير بالنسبة إلى قدرته{[40374]} { فانظر كَيْفَ كَانَ عَاقِبَةُ الظالمين } .
