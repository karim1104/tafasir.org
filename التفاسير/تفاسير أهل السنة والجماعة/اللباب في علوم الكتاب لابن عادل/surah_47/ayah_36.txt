ثم حضَّ على طلب الآخرة فقال : { إِنَّمَا الحياة الدنيا لَعِبٌ وَلَهْوٌ } باطل وغرور { وَإِن تُؤْمِنُواْ وَتَتَّقُواْ } الفواحش { يُؤْتِكُمْ أُجُورَكُمْ } جزاء أعمالكم في الآخرة { وَلاَ يَسْأَلْكُمْ } ربكم { أَمْوَالَكُمْ } لإيتاء الأجر بل يأمركم بالإيمان والطاعة ليثيبكم عليها الجنة .   نظيره قوله : { مَا أُرِيدُ مِنْهُم مِّن رِّزْقٍ } [ الذاريات : 57 ] . وقيل : لا يسألكم محمد أموالكم نظيره : { قُلْ مَا أَسْأَلُكُمْ عَلَيْهِ مِنْ أَجْرٍ } [ ص : 86 ] .   وقيل : معنى الآية لا يسألكم الله ورسوله أموالكم كلها في الصدقات إنما يسألانِكم غيضاً من فيض رُبع العشر فطيبوا بها نفساً .   قاله ابن عُيَيْنَةَ .   ويدل عليه سياق الآية .
