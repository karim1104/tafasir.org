قوله تعالى : { وَإِذَا الجبال نُسِفَتْ } أي : ذهب بها كلها بسرعة ،   من أنسفت الشيء إذا اختطفته ،   وقيل : تنشق كالحب المغلق إذا نسف بالمنسف ،   ومنه قوله تعالى : { لَّنُحَرِّقَنَّهُ ثُمَّ لَنَنسِفَنَّهُ فِي اليم نَسْفاً } [ طه : 97 ] ،   ونظيره : { وَبُسَّتِ الجبال بَسّاً } [ الواقعة : 5 ] { وَكَانَتِ الجبال كَثِيباً مَّهِيلاً } [ المزمل : 14 ] { فَقُلْ يَنسِفُهَا رَبِّي نَسْفاً } [ طه : 105 ] .  <br />
