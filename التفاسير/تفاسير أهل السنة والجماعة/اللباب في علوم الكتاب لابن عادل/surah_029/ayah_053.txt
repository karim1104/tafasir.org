قوله : «وَيَسْتَعْجِلُونَكَ بِالْعَذَابِ » نزلت في النضر بن الحارث{[41610]} حين قال : { فَأَمْطِرْ عَلَيْنَا حِجَارَةً مِنَ السماء }{[41611]} { وَلَوْلاَ أَجَلٌ مُسَمًّى } قال ابن عباس : ما وعدتك أني لا أعذب قومك ولا أستأصلهم وأؤخر عذابهم إلى يوم القيامة كما قال : { بَلِ الساعة مَوْعِدُهُمْ }{[41612]} وقيل : يوم بدر .   ولولا ذلك الأجل المسمى الذي اقتضته حكمته { لَجَاءَهُمُ العذاب وَلَيَأْتِيَنَّهُمْ بَغْتَةً } يعني العذاب .   وقيل : الأجل بغتة { وَهُمْ لاَ يَشْعُرُونَ } بإتيانه ،   وقوله : { وهم لا يشعرون } يحتمل وجهين :<br />
أحدهما : معنى تأكيد{[41613]} قوله : «بغتة » ،   كما يقول القائل : أتيته على غفلة منه بحيث لم يدرِ .  <br />
فقوله : { بحيث لم يدر } أكد معنى الغفلة .  <br />
والثاني : أنه يفيد فائدة مستقلة وهي أن العذاب يأتيهم بغتة { وهم لا يشعرون } هذا الأمر ،   ويظنون أن العذاب لا يأتيهم أصلاً .
