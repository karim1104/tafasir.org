قوله : { لَّوْ أَرَادَ الله أَن يَتَّخِذَ وَلَداً لاصطفى } لاختار { مِمَّا يَخْلُقُ مَا يَشَآءُ } يعني الملائكة كما قال : { لَوْ أَرَدْنَآ أَن نَّتَّخِذَ لَهْواً لاَّتَّخَذْنَاهُ مِن لَّدُنَّآ } [ الأنبياء : 17 ] ثم نزه نفسه فقال : { سُبْحَانَهُ } تنزيهاً له عن ذلك وعما لا يليق بطهارته { هُوَ الله الواحد القهار } .   والمراد من هذا الكلام إقامة الدلائل القاهرة على كونه منزهاً عن الولد .
