قوله : { قُلْ سِيرُواْ فِي الأرض } لما بين حالهم بظهور الفساد في أحوالهم بسبب فساد أقوالهم بين لهم ضلال أمثالهم وأشكالهم الذين كانت أفعالهم كأفعالهم فقال : { قُلْ سِيرُواْ فِي الأرض فانظروا كَيْفَ كَانَ عَاقِبَةُ الذين مِن قَبْلُ } أي قوم نوحٍ وعادٍ وثَمودَ لِيَرَوْا مَنَازِلَهُمْ ومساكنهم خاوية { كَانَ أَكْثَرُهُمْ مُشْرِكِينَ } فأهلكوا بكفرهم .  <br />
