{ خَطِيئَةً } صغيرة { أَوْ إِثْماً } أو كبيرة { ثُمَّ يَرْمِ بِهِ بَرِيئاً } كما رمى طعمة زيداً { فَقَدِ احتمل بهتانا وَإِثْماً } لأنه بكسب الإثم «آثم » وبرمي البريء «باهت » فهو جامع بين الأمرين .   وقرأ معاذ بن جبل رضي الله عنه : «ومن يكسب » ،   بكسر الكاف والسين المشددة وأصله يكتسب .  <br />
