فقال : { ذُكْرَاناً وإناثا } كما قال : { إِنَّا خلقناكم مّن ذَكَرٍ وأنثى } [ الحجرات : 13 ] ،   { فَجَعَلَ مِنْهُ الزوجين الذكر والانثى } [ القيامة : 39 ] وقيل : نزلت في الأنبياء صلوات الله عليهم وسلامه ،   حيث وهب لشعيب ولوط إناثاً ،   ولإبراهيم ذكوراً ،   ولمحمد ذكوراً وإناثاً ،   وجعل يحيى وعيسى عقيمين { إِنَّهُ عَلِيمٌ } بمصالح العباد { قَدِيرٌ } على تكوين ما يصلحهم .
