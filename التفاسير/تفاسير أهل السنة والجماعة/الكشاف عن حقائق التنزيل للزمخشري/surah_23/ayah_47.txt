البشر يكون واحداً وجمعاً : { بَشَراً سَوِيّاً } [ مريم : 17 ] ،   { لِبَشَرَيْنِ } ،   { فَإِمَّا تَرَيِنَّ مِنَ البشر } [ مريم : 26 ] و«مثل » و«غير » يوصف بهما : الاثنان ،   والجمع ،   والمذكر ،   والمؤنث : { إِنَّكُمْ إِذاً مّثْلُهُمْ } [ النساء : 140 ] ،   { وَمِنَ الأرض مِثْلَهُنَّ } [ الطلاق : 12 ] ويقال أيضاً : هما مثلاه ،   وهم أمثاله : { إِنَّ الذين تَدْعُونَ مِن دُونِ الله عِبَادٌ أَمْثَالُكُمْ } [ الأعراف : 194 ] .   { وَقَوْمُهُمَا } يعني بني إسرائيل ،   كأنهم يعبدوننا خضوعاً وتذللاً .   أو لأنه كان يدعي الإلهية فادعى للناس العبادة ،   وأن طاعتهم له عبادة على الحقيقة .
