{ تَنزِيلُ الكتاب } وإن جعلتها تعديداً للحروف ارتفع { تَنزِيلُ الكتاب } بأنه خبر مبتدأ محذوف : أو هو مبتدأ خبره { لاَ رَيْبَ فِيهِ } والوجه أن يرتفع بالابتداء ،   وخبره { مِن رَّبّ العالمين } و { لاَ رَيْبَ فِيهِ } : اعتراض لا محل له .   والضمير في { فِيهِ } راجع إلى مضمون الجملة ،   كأنه قيل : لا ريب في ذلك ،   أي في كونه منزلاً من رب العالمين ويشهد لوجاهته .  <br />
