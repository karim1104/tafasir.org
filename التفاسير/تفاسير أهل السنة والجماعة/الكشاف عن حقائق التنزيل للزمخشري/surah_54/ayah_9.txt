{ قَبْلَهُمْ } قبل أهل مكة { فَكَذَّبُواْ عَبْدَنَا } يعني نوحاً .  <br />
فإن قلت : ما معنى قوله تعالى : { فَكَذَّبُواْ } بعد قوله : { كَذَّبَتْ } ؟ قلت : معناه : كذبوا فكذبوا عبدنا أي : كذبوه تكذيباً على عقب تكذيب ،   كلما مضى منهم قرن مكذب تبعه قرن مكذب .   أو كذبت قوم نوح الرسل فكذبوا عبدنا ،   أي : لما كانوا مكذبين بالرسل جاحدين للنبوّة رأساً ،   كذبوا نوحًا ؛ لأنه من جملة الرسل { مَّجْنُونٍ } هو مجنون { وازدجر } وانتهروه بالشتم والضرب والوعيد بالرجم في قولهم { لَتَكُونَنَّ مِنَ المرجومين } [ الشعراء : 116 ] وقيل : هو من جملة قيلهم ،   أي : قالوا هو مجنون ،   وقد ازدجرته الجن وتخبطته وذهبت بلبه وطارت بقلبه .
