والخير الوحي ،   وكذلك الرحمة كقوله تعالى : { أَهُمْ يَقْسِمُونَ رَحْمَةَ ر بِكَ } [ الزخرف : 32 ] والمعنى : أنهم يرون أنفسهم أحق بأن يوحى إليهم فيحسدونكم وما يحبون أن ينزل عليكم شيء من الوحي { والله } يختصّ بالنبوة { مَن يَشَآء } ولا يشاء إلا ما تقتضيه الحكمة { والله ذُو الفضل العظيم } إشعار بأنّ إيتاء النبوّة من الفضل العظيم كقوله تعالى : { إِنَّ فَضْلَهُ كَانَ عَلَيْكَ كَبِيرًا } [ الإسراء : 87 ] .
