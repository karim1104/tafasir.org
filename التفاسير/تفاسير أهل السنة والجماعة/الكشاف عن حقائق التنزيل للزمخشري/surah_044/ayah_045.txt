{ كالمهل } قرىء : بضم الميم وفتحها ،   وهو دردي الزيت .   ويدل عليه قوله تعالى : { يَوْمَ تَكُونُ السماء كالمهل } [ المعارج : 8 ] مع قوله : { فَكَانَتْ وَرْدَةً كالدهان } [ الرحمن : 37 ] وقيل : هو ذائب الفضة والنحاس ،   والكاف رفع خبر بعد خبر ،   وكذلك { يَغْلِي } وقرىء : بالتاء للشجرة ،   وبالياء للطعام .
