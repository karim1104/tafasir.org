ألا ترى إلى قوله تعالى : { فَمَنْ أَظْلَمُ مِمَّن كَذَبَ علَى الله } وقوله تعالى : { والذى جَاء بالصدق وَصَدَّقَ بِهِ } [ الزمر : 33 ] وما هو إلا بيان وتفسير للذين يكون بينهم الخصومة { كَذَبَ علَى الله } افترى عليه بإضافة الولد والشريك إليه { وَكَذَّبَ بالصدق } بالأمر الذي هو الصدق بعينه ،   وهو ماء جاء به محمد صلى الله عليه وسلم { إِذْ جَاءهُ } فاجأه بالتكذيب لما سمع به من غير وقفة ،   لإعمال روية واهتمام بتمييز بين حق وباطل ،   كما يفعل أهل النصفة فيما يسمعون { مَثْوًى للكافرين } أي : لهؤلاء الذين كذبوا على الله وكذبوا بالصدق ،   واللام في { للكافرين } إشارة إليهم .
