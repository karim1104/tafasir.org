{ وَلَوْ أَنَّنَا نَزَّلْنَا إِلَيْهِمُ الملائكة } كما قالوا { لَوْلاَ أُنزِلَ عَلَيْنَا الملائكة } [ الفرقان : 21 ] ،   { وَكَلَّمَهُمُ الموتى } كما قالوا : { فَأْتُواْ بآبائنا } [ الدخان : 36 ] ،   { وَحَشَرْنَا عَلَيْهِمْ كُلَّ شَىْء قُبُلاً } كما قالوا { أَوْ تَأْتِىَ بالله والملائكة قَبِيلاً } [ الإسراء : 92 ] قبلاً كفلاء بصحة ما بشرنا به وأنذرنا ،   أو جماعات .   وقيل : { قُبُلاً } مقابلة .   وقرىء : «قبلا » أي عياناً { إلا أَن يَشَاء الله } مشيئة إكراه واضطرار { ولكن أَكْثَرَهُمْ يَجْهَلُونَ } فيقسمون بالله جهد إيمانهم على ما لا يشعرون من حال قلوبهم عند نزول الآيات .   أو ولكن أكثر المسلمين يجهلون أن هؤلاء لا يؤمنون إلا أن يضطّرهم فيطمعون في إيمانهم إذا جاءت الآية المقترحة .
