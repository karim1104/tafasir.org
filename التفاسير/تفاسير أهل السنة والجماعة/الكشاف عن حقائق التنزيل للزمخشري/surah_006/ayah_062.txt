{ ثُمَّ رُدُّواْ إلى الله } أي إلى حكمه وجزائه { مولاهم } مالكهم الذي يلي عليهم أمورهم { الحق } العدل الذي لا يحكم إلاّ بالحق { أَلاَ لَهُ الحكم } يومئذ لا حكم فيه لغيره { وَهُوَ أَسْرَعُ الحاسبين } لا يشغله حساب عن حساب .   وقرىء : «الحقَّ » بالنصب على المدح كقولك : الحمد لله الحقَّ .  <br />
