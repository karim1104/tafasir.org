وكذلك : { فَلَمْ يَكُ يَنفَعُهُمْ إيمانهم } تابع لإيمانهم لما رأوا بأس الله { سُنَّةَ الله } بمنزلة { وَعَدَ الله } [ النساء : 95 ] وما أشبهه من المصادر المؤكدة .   و { هُنَالِكَ } مكان مستعار للزمان ،   أي : وخسروا وقت رؤية البأس ،   وكذلك قوله : { وَخَسِرَ هُنَالِكَ المبطلون } [ غافر : 78 ] بعد قوله : { فَإِذَا جَاء أَمْرُ الله قُضِىَ بالحق } [ غافر : 78 ] أي : وخسروا وقت مجيء أمر الله ،   أو وقت القضاء بالحق .
