{ تِلْكَ } إشارة إلى الآيات المتقدّمة ،   أي : تلك الآيات آيات الله .   و { نَتْلُوهَا } في محل الحال ،   أي : متلوة { عَلَيْكَ بالحق } والعامل ما دل عليه تلك من معنى الإشارة .   ونحوه : { هذا بعلي شيخاً } [ هود : 72 ] وقرىء «يتلوها » بالياء { بَعْدَ الله وءاياته } أي بعد آيات الله كقولهم : أعجبني زيد وكرمه ،   يريدون : أعجبني كرم زيد .   ويجوز أن يراد : بعد حديث الله ،   وهو كتابه وقرآنه ،   كقوله تعالى ؛ { الله نَزَّلَ أَحْسَنَ الحديث } [ الزمر : 23 ] .   وقرىء { يُؤْمِنُونَ } بالتاء والياء .
