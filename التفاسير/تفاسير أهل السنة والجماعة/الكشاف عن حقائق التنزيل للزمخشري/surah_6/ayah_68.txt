{ يَخُوضُونَ فِى ءاياتنا } في الاستهزاء بها والطعن فيها ؛ وكانت قريش في أنديتهم يفعلون ذلك { فَأَعْرِضْ عَنْهُمْ } فلا تجالسهم وقم عنهم { حتى يَخُوضُواْ فِى حَدِيثٍ غَيْرِهِ } فلا بأس أن تجالسهم حينئذ { وَإِمَّا يُنسِيَنَّكَ الشيطان } وإن شغلك بوسوسته حتى تنسى النهي عن مجالستهم { فَلاَ تَقْعُدْ } معهم { بَعْدَ الذكرى } بعد أن تذكر النهي .   وقرىء : «ينسينك » بالتشديد .   ويجوز أن يراد : وإن كان الشيطان ينسينك قبل النهي قبح مجالسة المستهزئين لأنها مما تنكره العقول { فَلاَ تَقْعُدْ بَعْدَ الذكرى } بعد أن ذكرناك قبحها ونبهناك عليه معهم .  <br />
