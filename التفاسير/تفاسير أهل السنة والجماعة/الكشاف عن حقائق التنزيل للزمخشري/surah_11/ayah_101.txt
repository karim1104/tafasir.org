{ وَمَا ظلمناهم } بإهلاكنا إياهم { ولكن ظَلَمُواْ أَنفُسَهُمْ } بارتكاب ما به أهلكوا { فَمَا أَغْنَتْ عَنْهُمْ ءالِهَتَهُمُ } فما قدرت أن ترد عنهم بأس الله { يَدْعُونَ } يعبدون وهي حكاية حال ماضية .   و { لَّمَّا } منصوب بما أغنت { أَمْرُ رَبّكَ } عذابه ونقمته { تَتْبِيبٍ } تخسير .   يقال تبّ إذا خسر .   وتببه غيره ،   إذا أوقعه في الخسران .  <br />
