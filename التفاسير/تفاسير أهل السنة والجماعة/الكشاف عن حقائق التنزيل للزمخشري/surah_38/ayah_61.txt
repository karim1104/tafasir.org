{ وقَالُواْ } هم الأتباع أيضاً { فَزِدْهُ عَذَاباً ضِعْفاً } أي : مضاعفاً ،   ومعناه : ذا ضعف : ونحوه قوله تعالى : { رَبَّنَا هَؤُلاء أَضَلُّونَا فَئَاتِهِمْ عَذَابًا ضِعْفًا } [ الأعراف : 38 ] وهو أن يزيد على عذابه مثله فيصير ضعفين ،   كقوله عزّ وجلّ { رَبَّنَا ءاتِهِمْ ضِعْفَيْنِ مِنَ العذاب } [ الأحزاب : 68 ] وجاء في التفسير { عَذَاباً ضِعْفاً } حيات وأفاعي .
