{ ياأيها الذين ءَامَنُواْ } يجوز أن يكون خطاباً للذين آمنوا من أهل الكتاب والذين آمنوا من غيرهم ،   فإن كان خطاباً لمؤمني أهل الكتاب .   فالمعنى : يا أيها الذين آمنوا بموسى وعيسى آمنوا بمحمد { يُؤْتِكُمْ } الله { كِفْلَيْنِ } أي نصيبين { مّن رَّحْمَتِهِ } لإيمانكم بمحمد وإيمانكم بمن قبله { وَيَجْعَل لَّكُمْ } يوم القيامة { نُوراً تَمْشُونَ بِهِ } وهو النور المذكور في قوله : { يسعى نُورُهُم } [ الحديد : 12 ] .   { وَيَغْفِرْ لَكُمْ } ما أسلفتم من الكفر والمعاصي .
