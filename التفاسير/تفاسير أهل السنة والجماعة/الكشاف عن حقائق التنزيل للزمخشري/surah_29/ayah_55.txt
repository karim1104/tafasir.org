{ يَوْمَ يغشاهم العذاب } أو هي محيطة بهم في الدنيا : لأنّ المعاصي التي توجبها محيطة بهم .   أو لأنها مآلهم ومرجعهم لا محالة فكأنها الساعة محيطة بهم .   و { يَوْمَ يغشاهم } على هذا منصوب بمضمر ،   أي : يوم يغشاهم العذاب كان كيت وكيت .   { مِن فَوْقِهِمْ وَمِن تَحْتِ أَرْجُلِهِم } كقوله تعالى : { لَهُمْ مّن فَوْقِهِمْ ظُلَلٌ مّنَ النار وَمِن تَحْتِهِمْ ظُلَلٌ } [ الزمر : 16 ] ،   { وَيَقُولُ } قرىء بالنون والياء { مَا كُنتُمْ تَعْمَلُونَ } أي جزاءه .
