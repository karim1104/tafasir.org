{ بالحق } أي بالغرض الصحيح الذي هو حق لا باطل ،   وهو أن تكونا مساكن عبادة وعبرة للمعتبرين منهم ،   ودلائل على عظم قدرته : ألا ترى إلى قوله : { إِنَّ فِى ذَلِكَ لآيَةً لِلْمُؤْمِنِينَ } ونحوه قوله تعالى : { وَمَا خَلَقْنَا السماء والأرض وَمَا بَيْنَهُمَا باطلا } [ ص : 27 ] ثم قال : { ذلك ظَنُّ الذين كَفَرُواْ } [ ص : 27 ] .
