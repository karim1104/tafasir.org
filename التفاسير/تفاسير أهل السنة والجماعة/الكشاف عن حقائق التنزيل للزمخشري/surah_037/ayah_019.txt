{ فَإِنَّمَا } جواب شرط مقدّر تقديره : إذا كان ذلك فما { هِىَ } إلا { زَجْرَةٌ واحدة } وهي لا ترجع إلى شيء ،   إنما هي مبهمة موضحها خبرها .   ويجوز : فإنما البعثة زجرة واحدة وهي النفخة الثانية .   والزجرة : الصيحة ،   من قولك : زجر الراعي الإبل أو الغنم : إذا صاح عليها فريعت لصوته .   ومنه قوله :<br />
زَجْرَ أَبِي عُرْوَةَ السِّبَاعَ إذَا *** أَشْفَقَ أَنْ يَخْتَلِطْنَ بِالغَنَمِ<br />
يريد تصويته بها { فَإِذَا هُم } أحياء بصراء { يُنظَرُونَ } .  <br />
