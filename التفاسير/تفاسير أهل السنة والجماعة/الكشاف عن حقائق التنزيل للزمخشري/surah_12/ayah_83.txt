فرجعوا إلى أبيهم فقالوا له ما قال لهم أخوهم ف : { قَالَ بَلْ سَوَّلَتْ لَكُمْ أَنفُسُكُمْ أَمْرًا } أردتموه وإلا فما أدرى ذلك الرجل أنّ السارق يؤخذ بسرقته لولا فتواكم وتعليمكم { بِهِمْ جَمِيعًا } بيوسف وأخيه وروبيل أو غيره { إِنَّهُ هُوَ العليم } بحالي في الحزن والأسف { الحكيم } الذي لم يبتلني بذلك إلا لحكمة ومصلحة .  <br />
