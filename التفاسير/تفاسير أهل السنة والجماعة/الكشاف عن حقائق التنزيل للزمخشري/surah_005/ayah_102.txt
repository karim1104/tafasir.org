ثم قال : { قَدْ سَأَلَهَا } ولم يقل .   قد سأل عنها ؟ قلت : الضمير في { سَأَلَهَا } ليس براجع إلى أشياء حتى تَجب تعديته بعن ،   وإنما هو راجع إلى المسألة التي دل عليها { لاَ تَسْئَلُواْ } يعني قد سأل قوم هذه المسألة من الأولين { ثُمَّ أَصْبَحُواْ بِهَا } أي بمرجوعها أو بسببها { كافرين } وذلك أنّ بني إسرائيل كانوا يستفتون أنبيائهم عن أشياء ،   فإذا أمروا بها تركوها فهلكوا .  <br />
