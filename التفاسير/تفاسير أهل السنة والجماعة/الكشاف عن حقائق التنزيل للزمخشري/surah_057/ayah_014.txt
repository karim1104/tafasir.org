{ أَلَمْ نَكُن مَّعَكُمْ } يريدون موافقتهم في الظاهر { فَتَنتُمْ أَنفُسَكُمْ } محنتموها بالنفاق وأهلكتموها { وَتَرَبَّصْتُمْ } بالمؤمنين الدوائر { وَغرَّتْكُمُ الامانى } طول الآمال والطمع في امتداد الأعمار { حتى جَاءَ أَمْرُ الله } وهو الموت { وَغَرَّكُم بالله الغرور } وغرّكم الشيطان بأنّ الله عفوّ كريم لا يعذبكم .   وقرىء : «الغرور » بالضم .  <br />
