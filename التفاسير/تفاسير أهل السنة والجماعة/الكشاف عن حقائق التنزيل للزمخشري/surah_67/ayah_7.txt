{ إِذَا أُلْقُواْ فِيهَا } أي طرحوا كما يطرح الحطب في النار العظيمة ،   ويرمى به .   ومثله قوله تعالى : { حَصَبُ جَهَنَّمَ } [ الأنبياء : 98 ] .   { سَمِعُواْ لَهَا شَهِيقًا } إمّا لأهلها ممن تقدم طرحهم فيها .   أو من أنفسهم ،   كقوله : { لَهُمْ فِيهَا زَفِيرٌ وَشَهِيقٌ } [ هود : 106 ] وإما للنار تشبيهاً لحسيسها المنكر الفظيع بالشهيق { وَهِىَ تَفُورُ } تغلي بهم غليان المرجل بما فيه .
