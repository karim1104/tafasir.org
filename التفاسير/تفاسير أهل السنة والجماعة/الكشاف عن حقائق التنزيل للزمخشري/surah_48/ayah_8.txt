{ شاهدا } تشهد على أمّتك ،   كقوله تعالى : { وَيَكُونَ الرسول عَلَيْكُمْ شَهِيدًا } [ البقرة : 143 ] .   { لّتُؤْمِنُواْ } الضمير للناس { وَتُعَزّرُوهُ } ويقووه بالنصرة { وَتُوَقّرُوهُ } ويعظموه { وَتُسَبّحُوهُ } من التسبيح .   أو من السبحة ،   والضمائر لله عز وجلّ والمراد بتعزيز الله : تعزيز دينه ورسوله صلى الله عليه وسلم .   ومن فرق الضمائر فقد أبعد .
