{ فانقلبوا } فرجعوا من بدر { بِنِعْمَةٍ مّنَ الله } وهي السلامة وحذر العدوّ منهم { وفضل } وهو الربح في التجارة ،   كقوله { لَيْسَ عَلَيْكُمْ جُنَاحٌ أَن تَبْتَغُواْ فَضْلاً مّن رَّبّكُمْ } [ البقرة : 198 ] .   { لَّمْ يَمْسَسْهُمْ سُوءٌ } لم يلقوا ما يسوءهم من كيد عدوّ { واتبعوا رضوان الله } بجرأتهم وخروجهم { والله ذُو فَضْلٍ عَظِيمٍ } قد تفضل عليهم بالتوفيق فيما فعلوا .   وفي ذلك تحسير لمن تخلف عنهم ،   وإظهار لخطأ رأيهم حيث حرموا أنفسهم ما فاز به هؤلاء .   وروي أنهم قالوا : هل يكون هذا غزوا ،   فأعطاهم الله ثواب الغزو ورضي عنهم .
