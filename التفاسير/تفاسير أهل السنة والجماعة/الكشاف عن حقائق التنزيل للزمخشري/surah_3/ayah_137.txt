{ قَدْ خَلَتْ مِن قَبْلِكُمْ سُنَنٌ } يريد ما سنه الله في الأمم المكذبين من وقائعه ،   كقوله : { وَقُتّلُواْ تَقْتِيلاً سُنَّةَ الله فِى الذين خَلَوْاْ مِن قَبْل } [ الأحزاب : 61 ] { ثُمَّ لاَ يَجِدُونَ وَلِيّاً وَلاَ نَصِيراً } [ الفتح : 22 ] ،   { سُنَّةَ الله التى قَدْ خَلَتْ مِن قَبْلُ } [ الفتح : 23 ] .
