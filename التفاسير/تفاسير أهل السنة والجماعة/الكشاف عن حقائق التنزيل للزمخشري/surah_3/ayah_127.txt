{ لِيَقْطَعَ طَرَفاً مّنَ الذين كَفَرُواْ } ليهلك طائفة منهم بالقتل والأسر ،   وهو ما كان يوم بدر من قتل سبعين وأسر سبعين من رؤساء قريش وصناديدهم { أَوْ يَكْبِتَهُمْ } أو يخزيهم ويغيظهم بالهزيمة { فَيَنقَلِبُواْ خَائِبِينَ } غير ظافرين بمبتغاهم .   ونحوه { وَرَدَّ الله الذين كَفَرُواْ بِغَيْظِهِمْ لَمْ يَنَالُواْ خَيْراً } [ الأحزاب : 25 ] ويقال : كبته ،   بمعنى كبده إذا ضرب كبده بالغيظ والحرقة .   وقيل في قول أبي الطيب :<br />
لأَكْبِتَ حَاسِداً وَأرى عَدُوًّا***<br />
هومن الكبد والرئة ،   واللام المتعلقة بقوله : { وَلَقَدْ نَصَرَكُمُ الله } أو بقوله : { وَمَا النصر إِلاَّ مِنْ عِندِ الله } { أَوْ يَتُوبَ } عطف على ما قبله .
