{ إِنَّ هاؤلآء } الكفرة { يُحِبُّونَ العاجلة } يؤثرونها على الآخرة ،   كقوله : { بَلْ تُؤْثِرُونَ الحياة الدنيا } [ الأعلى : 16 ] ،   { وَرَآءَهُمْ } قدّامهم أو خلف ظهورهم لا يعبأون به { يَوْماً ثَقِيلاً } استعير الثقيل لشدّته وهولِه ،   من الشيء الثقيل الباهظ لحامله .   ونحوه : { ثَقُلَتْ فِى السموات والأرض } [ الأعراف : 187 ] .
