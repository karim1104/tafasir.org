{ شَرَعَ لَكُم مّنَ الدين } دين نوح ومحمد ومن بينهما من الأنبياء ،   ثم فسر المشروع الذي اشترك هؤلاء الأعلام من رسله فيه بقوله : { أَنْ أَقِيمُواْ الدين وَلاَ تَتَفَرَّقُواْ فِيهِ } والمراد : إقامة دين الإسلام الذي هو توحيد الله وطاعته ،   والإيمان برسله وكتبه ،   وبيوم الجزاء ،   وسائر ما يكون الرجل بإقامته مسلماً ،   ولم يرد الشرائع التي هي مصالح الأمم على حسب أحوالها ،   فإنها مختلفة متفاوتة .   قال الله تعالى : { لِكُلّ جَعَلْنَا مِنكُمْ شِرْعَةً ومنهاجا } [ المائدة : 48 ] ومحل { أَنْ أَقِيمُواْ } إما نصب بدل من مفعول شرع والمعطوفين عليه ،   وإما رفع على الاستئناف ،   كأنه قيل : وما ذلك المشروع ؟ فقيل : هو إقامة الدين ،   ونحوه قوله تعالى : { إِنَّ هذه أُمَّتُكُمْ أُمَّةً وَاحِدَةً } [ الأنبياء : 92 ] { كَبُرَ عَلَى المشركين } عظم عليهم وشق عليهم { مَا تَدْعُوهُمْ إِلَيْهِ } من إقامة دين الله والتوحيد { يَجْتَبِى إِلَيْهِ } يجتلب إليه ويجمع .   والضمير للدين بالتوفيق والتسديد { مَن يَشَآءُ } من ينفع فيهم توفيقه ويجرى عليهم لطفاً .
