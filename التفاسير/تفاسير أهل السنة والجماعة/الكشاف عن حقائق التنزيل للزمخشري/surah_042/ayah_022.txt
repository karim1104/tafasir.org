{ تَرَى الظالمين } في الآخرة { مُشْفِقِينَ } خائفين خوفاً شديداً أرق قلوبهم { مِمَّا كَسَبُواْ } من السيئات { وَهُوَ وَاقِعٌ بِهِمْ } يريد : ووباله واقع بهم وواصل إليهم لا بدّ لهم منه ،   أشفقوا أو لم يشفقوا .   كأن روضة جنة المؤمن أطيب بقعة فيها وأنزهها { عِندَ رَبِّهِمْ } منصوب بالظرف لا بيشاؤون .  <br />
