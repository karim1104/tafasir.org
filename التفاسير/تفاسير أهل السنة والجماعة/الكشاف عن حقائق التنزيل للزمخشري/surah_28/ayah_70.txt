{ وهُوَ الله } وهو المستأثر بالإلهية المختص بها ،   و { لاَ إله إِلاَّ هُوَ } تقرير لذلك ،   كقولك : الكعبة القبلة ،   لا قبلة إلا هي .  <br />
فإن قلت : الحمد في الدنيا ظاهر فما الحمد في الآخرة ؟ قلت : هو قولهم : { الحمد للَّهِ الذى أَذْهَبَ عَنَّا الحزن } [ فاطر : 34 ] ،   { الحمد للَّهِ الذى صَدَقَنَا وَعْدَهُ } [ الزمر : 74 ] { وَقِيلَ الحمد لِلَّهِ رَبّ العالمين } [ الزمر : 75 ] والتحميد هناك على وجه اللذة لا الكلفة .   وفي الحديث : « يلهمونَ التسبيحَ والتقديس  » { وَلَهُ الحكم } القضاء بين عباده .
