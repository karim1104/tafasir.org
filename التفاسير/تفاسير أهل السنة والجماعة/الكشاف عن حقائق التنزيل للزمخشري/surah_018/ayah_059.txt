{ وَتِلْكَ القرى } يريد قرى الأوّلين من ثمود وقوم لوط وغيرهم : أشار لهم إليها ليعتبروا .   { تِلْكَ } مبتدأ ،   و { القرى } صفة : لأنّ أسماء الإشارة توصف بأسماء الأجناس ،   و { أهلكناهم } خبر .   ويجوز أن يكون { تِلْكَ القرى } نصباً بإضمار أهلكنا على شريطة التفسير .   والمعنى وتلك أصحاب القرى أهلكناهم { لَمَّا ظَلَمُواْ } مثل ظلم أهل مكة { وَجَعَلْنَا لِمَهْلِكِهِم مَّوْعِدًا } وضربنا لإهلاكهم وقتاً معلوماً لا يتأخرون عنه كما ضربنا لأهل مكة يوم بدر والمهلك الإهلاك ووقته .   وقرىء : «لمَهلكهم » بفتح الميم ،   واللام مفتوحة أو مكسورة ،   أي : لهلاكهم أو وقت هلاكهم .   والموعد : وقت ،   أو مصدر .  <br />
