قَوْلُهُ تَعَالَى: { وَإِذَا مَسَّ ٱلنَّاسَ ضُرٌّ دَعَوْاْ رَبَّهُمْ }؛ أي إذا أصَابَ الناسَ شدَّةٌ وبَلِيَّةٌ وقحطٌ وغلاءٌ يعني كفَّارَ مكَّة، دَعَوا ربَّهم لدفعِ الشِّدة، { مُّنِيبِينَ إِلَيْهِ }؛ أي رَاجِعين إليه، مُنقَطِعين من الْخَلْقِ، لا يَلجَأُونَ في شَدائدِهم إلى أوثَانِهم، { ثُمَّ إِذَآ }؛ أذهبَ عنهُم تلكَ الشدَّةَ و { أَذَاقَهُمْ مِّنْهُ رَحْمَةً }؛ أي أعطَاهم من عندهِ المطرَ، { إِذَا فَرِيقٌ مِّنْهُمْ بِرَبِّهِمْ يُشْرِكُونَ }؛ أي يَعُودُونَ إلى الشِّركِ { لِيَكْفُرُواْ بِمَآ آتَيْنَاهُمْ }؛ فيبدِّلُوا الشُّكرَ كُفراً، { فَتَمَتَّعُواْ }؛ أي تلَذذُوا في الدُّنيا، { فَسَوْفَ تَعْلَمُونَ } ، مَاذا ينْزِلُ بكم.
