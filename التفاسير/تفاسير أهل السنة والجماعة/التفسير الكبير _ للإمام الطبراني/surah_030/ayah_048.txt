قَوْلُهُ تَعَالَى: { ٱللَّهُ ٱلَّذِي يُرْسِلُ ٱلرِّيَاحَ فَتُثِيرُ سَحَاباً }؛ أي تُزْعِجُهُ مِن حيث هو، وذلك أنَّ اللهَ يُحْدِثُ السَّحابَ عُقيبَ الرياحِ فترفعهُ الرياحُ في الهواءِ، { فَيَبْسُطُهُ فِي ٱلسَّمَآءِ كَيْفَ يَشَآءُ وَيَجْعَلُهُ كِسَفاً } أي قِطَعاً بعضُها فوق بعضٍ، { فَتَرَى ٱلْوَدْقَ } يعني المطرَ، { يَخْرُجُ مِنْ خِلاَلِهِ }؛ أي من وَسَطِهِ إلى قومٍ دونَ قوم، { فَإِذَآ أَصَابَ بِهِ }؛ بذلك المطرِ، { مَن يَشَآءُ مِنْ عِبَادِهِ إِذَا هُمْ يَسْتَبْشِرُونَ }؛ يفرَحُون بالمطرِ، { وَإِن كَانُواْ مِن قَبْلِ أَن يُنَزَّلَ عَلَيْهِمْ }؛ المطرُ { مِّن قَبْلِهِ لَمُبْلِسِينَ }؛ أي يائسين من ذلك، كرَّرَهُ للتأكيدِ، والْمُبْلِسُ هو الآيسُ القَانِطُ.
