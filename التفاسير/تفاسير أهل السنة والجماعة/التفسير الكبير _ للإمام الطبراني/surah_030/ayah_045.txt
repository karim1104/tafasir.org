قَوْلُهُ تَعَالَى: { مَن كَفَرَ فَعَلَيْهِ كُفْرُهُ } أي ضَرَرُ كُفْرِهِ، { وَمَنْ عَمِلَ صَالِحاً فَلأَنفُسِهِمْ يَمْهَدُونَ }؛ أي يَطَأُونَ لأنفسهم منازلَهم في الجنةِ، { لِيَجْزِيَ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ }؛ ثوابَهم، ثُم يزيدَهم { مِن فَضْلِهِ }؛ أي يُثِيبَهُمْ أكثرَ مِن أعمالِهم، { إِنَّهُ لاَ يُحِبُّ ٱلْكَافِرِينَ }؛ أي يُكرِمُهم ولا يُثيبهم ولا يرضَى عنهم.
