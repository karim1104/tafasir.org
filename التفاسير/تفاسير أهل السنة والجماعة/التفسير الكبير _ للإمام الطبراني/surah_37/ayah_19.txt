قَوْلُهُ تَعَالَى: { وَإِذَا ذُكِّرُواْ لاَ يَذْكُرُونَ }؛ وإذا وُعِظُوا بالقرآنِ لا يتَّعظون، { وَإِذَا رَأَوْاْ آيَةً يَسْتَسْخِرُونَ }؛ إذا رأوا معجزةَ مثلَ انشقاقِ القَمَرِ وغيره اتَّخذوهُ سُخرِيَةً، ونسَبُوا ما دلَّهم على توحيدِ الله تعالى إلى السِّحرِ، { وَقَالُوۤاْ إِن هَـٰذَآ إِلاَّ سِحْرٌ مُّبِينٌ }. وقالوا أيضاً على وجهِ الإنكار: { أَءِذَا مِتْنَا وَكُنَّا }؛ صِرْنا؛ { تُرَاباً وَعِظَاماً }؛ بَالِيَةً، { أَءِنَّا لَمَبْعُوثُونَ }؛ أي أنُبعَثُ بعدَ الموتِ، { أَوَ آبَآؤُنَا ٱلأَوَّلُونَ }؛ الذين مضَوا قبلَنا، { قُلْ }؛ لَهم يا مُحَمَّد: { نَعَمْ }؛ تُبعَثون { وَأَنتُمْ دَاخِرُونَ }؛ أنتُم وآباؤُكم؛ أي وأنتم أذلاَّءُ صاغِرُون، والدُّخُورُ أشَدُّ الذُّلِّ.  ثم ذكَرَ أنَّ بعثَهم يقعُ بزَجرَةٍ واحدةٍ؛ أي بصَيحَةٍ واحدةٍ، فإذا هم قيامٌ ينظُرون ماذا يُؤمَرون به، وقولهُ تعالى: { فَإِنَّمَا هِيَ زَجْرَةٌ وَاحِدَةٌ }؛ أي فإنَّما قضيةُ البعثِ صيحةٌ واحدة من إسرافيلَ، يعني نفخةَ البعثِ، { فَإِذَا هُمْ يَنظُرُونَ }؛ أي بُعِثَ الذي كذبوا به.  فلما عايَنُوا البعثَ ذكَرُوا قولَ الرسُلِ في الدُّنيا أنَّ البعثَ حقٌّ، فدَعَوا بالويلِ، { وَقَالُواْ يٰوَيْلَنَا }؛ من العذاب، { هَـٰذَا يَوْمُ ٱلدِّينِ }؛ أي هذا يومُ الحساب والجزاء نُجازَى فيه بأعمالِنا. فقالت الملائكةُ: { هَـٰذَا يَوْمُ ٱلْفَصْلِ }؛ يومُ القضاءِ، { ٱلَّذِي كُنتُمْ بِهِ تُكَذِّبُونَ }؛ يُفْصَلُ به بين الْمُسِيءِ والْمُحْسِنِ، والْمُحِقِّ والْمُبْطِلِ، وهو اليومُ الذي كنتم به تكذِّبون في الدُّنيا.
