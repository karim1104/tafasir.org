قَوْلُهُ تَعَالَى: { جَنَّاتُ عَدْنٍ يَدْخُلُونَهَا }؛ يعني الأصنافَ الثلاثةَ: الظالِمُ؛ والمقتصدُ؛ والسابقُ. ومعنى الآيةِ: { جَنَّاتُ عَدْنٍ } أي بساتينُ إقامةٍ لا تزولُ, { يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ مِن ذَهَبٍ }؛ أي يُلبَسُونَ أقُلْبُةً من ذهبٍ وسِوَارُ القُلْبِ. وقولهُ تعالى: { وَلُؤْلُؤاً وَلِبَاسُهُمْ فِيهَا حَرِيرٌ }؛ مَن قرأ بالكسرِ فالمعنى مِن ذهبٍ ومن لؤلؤٍ، ومَن قرأ بالنصب فمعناهُ: ويحلَّونَ لُؤلُؤاً.
