قَوْلُهُ تَعَالَى: { وَإِن نَّشَأْ نُغْرِقْهُمْ فَلاَ صَرِيخَ لَهُمْ }؛ أي أنَّ اللهَ سُبْحَانَهُ وَتَعَالَى ذكَرَ تفَضُّلَهُ أنَّهُ يحفَظُهم، ولو شاءَ أغرقَهم فلم يُغنِهم أحدٌ ولم يُنقِذْهُم من الغرقِ، ومعنى قولهِ تعالى: { فَلاَ صَرِيخَ لَهُمْ } أي فلا مُغِيثَ لَهم، { وَلاَ هُمْ يُنقَذُونَ }؛ من المكروهِ والغرَقِ.  والصَّرِيخُ: بمعنى الصَّارخِ لهم بالاستغاثةِ. وَقِيْلَ: الصَّريخُ الْمُعِينُ على الصُّراخ، كأنه قالَ: فلا مُعينَ لَهم { وَلاَ هُمْ يُنقَذُونَ } أي ولا هم يُخَلَّصُون من الغرقِ، { إِلاَّ رَحْمَةً مِّنَّا وَمَتَاعاً إِلَىٰ حِينٍ } ، إلاّ أنْ تدارَكَهم رحمةُ اللهِ فتنقذهم إلى حين آجالِهم.
