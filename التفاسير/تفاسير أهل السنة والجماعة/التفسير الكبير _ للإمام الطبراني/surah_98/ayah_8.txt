قَوْلُهُ تَعَالَى: { إِنَّ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ أُوْلَـٰئِكَ هُمْ خَيْرُ ٱلْبَرِيَّةِ }؛ أي خيرُ الخليقةِ، { جَزَآؤُهُمْ عِندَ رَبِّهِمْ جَنَّاتُ عَدْنٍ }؛ أي بساتِين إقامةٍ، { تَجْرِى مِنْ تَحْتِهَا ٱلأَنْهَارُ }؛ الأربعةُ، { خَالِدِينَ فِيهَآ أَبَداً رِّضِىَ ٱللَّهُ عَنْهُمْ }؛ بإيمانِهم، { وَرَضُواْ عَنْهُ }؛ بالثَّواب الذي أكرمَهم اللهُ به، { ذَلِكَ لِمَنْ خَشِيَ رَبَّهُ }؛ بامتثالِ أوامره، واجتناب معاصيه.
