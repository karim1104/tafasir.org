قَوْلُهُ تَعَالَى: { أَمْ لَهُمْ شُرَكَاءُ شَرَعُواْ لَهُمْ مِّنَ ٱلدِّينِ مَا لَمْ يَأْذَن بِهِ ٱللَّهُ }؛ يعني كفارَ مكَّة ألَهُمْ آلِهةٌ سَنُّوا من الدينِ والشريعةِ ما لَم يعلمِ اللهُ به؟ قال ابنُ عبَّاس: (شَرَعُوا لَهُمْ دِيْناً غَيْرَ دِينِ الإسْلاَمِ) { وَلَوْلاَ كَلِمَةُ ٱلْفَصْلِ لَقُضِيَ بَيْنَهُمْ }؛ أي لولاَ حكمُ الله بأن يَفصِلَ بينهم يومَ القيامةِ لعاجَلَهم بالعقوبةِ، { وَإِنَّ ٱلظَّالِمِينَ لَهُمْ عَذَابٌ أَلِيمٌ }؛ أي وجيعٌ في الآخرةِ { تَرَى ٱلظَّالِمِينَ } ، الذين يكذبونك خائفين يوم القيامة، { مُشْفِقِينَ مِمَّا كَسَبُواْ }؛ مِن الكفرِ والتكذيب، { وَهُوَ وَاقِعٌ بِهِمْ }؛ أي وجزاؤهُ واقعٌ بهم.  قَوْلُهُ تَعَالَى: { وَٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ فِي رَوْضَاتِ ٱلْجَنَّاتِ }؛ الرَّوضَةُ: هي البستانُ الجامع لأنواعِ الرَّياحينِ، والجنَّةُ هي البستانُ الجامِعُ لأنواعِ الشَّجرِ، { لَهُمْ مَّا يَشَآءُونَ عِندَ رَبِّهِمْ }؛ مِن النعيمِ في حكمةِ ربهم، { ذَلِكَ هُوَ ٱلْفَضْلُ ٱلْكَبِيرُ }؛ أي الْمَنُّ العظيمُ من اللهِ تعالى.
