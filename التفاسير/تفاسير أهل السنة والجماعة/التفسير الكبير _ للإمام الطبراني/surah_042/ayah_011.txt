قَوْلُهُ تَعَالَى: { فَاطِرُ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ }؛ أي هو مُبتَدِعُهما ومدبرُهما، { جَعَلَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجاً }؛ أي خَلَقَ لكم من مثلِ خَلقِكم نساءً، وَخلقَ لكم، { وَمِنَ ٱلأَنْعَامِ أَزْواجاً }؛ ذُكوراً وإناثاً لتَكمَلَ منافعُكم بها، يعني خلقَ الذكرِ والأنثى من الحيوانِ كلِّه. قَوْلُهُ تَعَالَى: { يَذْرَؤُكُمْ فِيهِ }؛ أي يَخلقُكم في الرَّحِم ويُكثِرُكم بالتزويجِ، ولولاهُ لم يكنِ الناسُ.  وقولهُ تعالى: { لَيْسَ كَمِثْلِهِ شَيْءٌ }؛ في العلمِ والقدرةِ والتدبيرِ، { وَهُوَ ٱلسَّمِيعُ }؛ بمقالَةِ العبادِ، { ٱلْبَصِيرُ }؛ بأعمالِهم، والكافُ في { كَمِثْلِهِ } زائدةٌ مُؤكِّدَةٌ، والمعنى: ليس مثلهُ شيءٌ، إذ لا يجوزُ أن يقالَ: ليس مثلَ مثلهِ شيءٌ؛ لأن مَن قال ذلكَ فقد أثبتَ المثلَ للهِ سُبْحَانَهُ وَتَعَالَى عَنْ ذلِكَ عُلُوّاً كَبيراً.
