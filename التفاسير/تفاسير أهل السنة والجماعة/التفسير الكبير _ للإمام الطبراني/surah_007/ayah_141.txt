قَوْلُهُ تَعَالَى: { وَإِذْ أَنْجَيْنَاكُمْ مِّنْ آلِ فِرْعَونَ يَسُومُونَكُمْ سُوۤءَ ٱلْعَذَابِ } أي يُوَلُّونَكُمْ سُوءَ العذاب { يُقَتِّلُونَ أَبْنَآءَكُمْ }؛ أي يَذبَحونَهم، { وَيَسْتَحْيُونَ نِسَآءَكُمْ }؛ أي يَستَبْقُونَهُمْ للاستخدامِ، { وَفِي ذٰلِكُمْ بَلاۤءٌ مِّن رَّبِّكُمْ عَظِيمٌ }؛ قرأ حمزةُ والكسائي: (يَعْكِفُونَ) بكسرِ الكاف والباقون بضَمِّها وهما لُغتان. وقرأ أهلُ الشَّام (وَإذْ أنْجَاكُمْ مِنْ آلِ فِرْعَوْنَ). وقرا الباقونَ على التكثيرِ (أنْجَيْنَاكُمْ). وقوله تعالى: { يُقَتِّلُونَ أَبْنَآءَكُمْ } قرأ نافعُ بالتخفيفِ، وقرأ الباقونَ بالتشديدِ على التَّكثيرِ.
