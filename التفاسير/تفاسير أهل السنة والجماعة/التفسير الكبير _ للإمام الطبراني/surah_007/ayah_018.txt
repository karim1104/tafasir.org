قَوْلُهُ تَعَالَى: { قَالَ ٱخْرُجْ مِنْهَا مَذْءُوماً مَّدْحُوراً }؛ أي أُخْرُجْ من الجنَّةِ. وَقِيْلَ: من السَّمَاءِ، { مَذْءُوماً } أي مَذْؤُماً مَعِيباً، والذأمُ والذِّيْمُ: شِدَّةُ الْعَيْب، يقال: ذامَتِ الرَّجُلَ ذوْمَةٌ وَذأْمَةٌ؛ إذا عِبْتُهُ وَذِمْتُهُ. قولهُ: { مَّدْحُوراً } أي مُبعداً من الخيرِ والرحمة. والدَّحْرُ: الدَّفْعُ على وجهِ الْهَوَانِ وَالذُّلِّ.  وقال ابنُ عبَّاسٍ: { مَذْءُومًا } مَمْقُوتاً. وقال مجاهدُ: { مَذْءَومًا } صَاغِراً. وقال أبُو العاليةِ: { مَذْءُومًا } أي مُزْدَراً. وقال عطاءُ: { مَدْءُومًا } أيْ مَلْعُوناً. وقال الكسائيُّ: (الْمَذْمُومُ: الْمَقْبُوحُ).  قَوْلُهُ تَعَالَى: { لَّمَن تَبِعَكَ مِنْهُمْ لأَمْلأَنَّ جَهَنَّمَ مِنكُمْ أَجْمَعِينَ }؛ واللاَّمُ في قولهِ: (لَمَنْ) لام القَسَمِ دخَلتْ على لفظِ الشَّرطِ والجزاء بمعنى التأكيدِ والمبالغَةِ؛ كأنهُ قال تَعَالَى: مَنْ تَبعَكَ لأَُبَالغَِنَّ في تعذيبهِ عذاباً شَديداً، كذلك قَوْلُهُ تَعَالَى: { لأَمْلأَنَّ جَهَنَّمَ مِنكُمْ أَجْمَعِينَ } أي مِنكَ ومن ذُرِّيَّتِكَ ومن كفَّار ذُرِيَّةِ آدمَ عليه السلام.
