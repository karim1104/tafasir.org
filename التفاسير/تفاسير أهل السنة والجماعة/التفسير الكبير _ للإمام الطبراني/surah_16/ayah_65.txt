قَوْلُهُ تَعَالَى: { وَمَآ أَنْزَلْنَا عَلَيْكَ ٱلْكِتَابَ إِلاَّ لِتُبَيِّنَ لَهُمُ ٱلَّذِي ٱخْتَلَفُواْ فِيهِ }؛ أي لتُبيِّن لهم الحقَّ من الباطلِ، وَأنزلناهُ، { وَهُدًى } ، دلالةً، { وَرَحْمَةً لِّقَوْمٍ يُؤْمِنُونَ }؛ أي للمؤمنين. قَوْلُهُ تَعَالَى: { وَٱللَّهُ أَنْزَلَ مِنَ ٱلْسَّمَآءِ مَآءً }؛ يعني المطرَ، { فَأَحْيَا بِهِ ٱلأَرْضَ بَعْدَ مَوْتِهَآ }؛ أي يُبسِها، { إِنَّ فِي ذٰلِكَ لآيَةً لِقَوْمٍ يَسْمَعُونَ }؛ أدِلَّةَ اللهِ، ويتفكَّرون فيها.
