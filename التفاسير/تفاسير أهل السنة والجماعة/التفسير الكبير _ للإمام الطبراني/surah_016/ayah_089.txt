قَوْلُهُ تَعَالَى: { وَيَوْمَ نَبْعَثُ فِي كُلِّ أُمَّةٍ شَهِيداً عَلَيْهِمْ مِّنْ أَنْفُسِهِمْ }؛ فيه بيانٌ أنَّ كلَّ عصرٍ لا يخلو من شهيدٍ على الناس، { وَجِئْنَا بِكَ }؛ يا مُحَمَّدُ، { شَهِيداً عَلَىٰ هَـٰؤُلآءِ }؛ يعني قومَهُ. قَوْلُهُ تَعَالَى: { وَنَزَّلْنَا عَلَيْكَ ٱلْكِتَابَ }؛ أي القرآنَ، { تِبْيَاناً لِّكُلِّ شَيْءٍ }؛ من أمورِ الدِّين، { وَهُدًى وَرَحْمَةً وَبُشْرَىٰ } وبشارةً، { لِلْمُسْلِمِينَ }.
