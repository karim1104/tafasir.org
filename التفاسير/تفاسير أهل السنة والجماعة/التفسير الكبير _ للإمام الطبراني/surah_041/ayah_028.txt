يقولُ اللهُ تعالى: { فَلَنُذِيقَنَّ ٱلَّذِينَ كَفَرُواْ عَذَاباً شَدِيداً }؛ أي في الدُّنيا بالقتلِ والأسرِ، { وَلَنَجْزِيَنَّهُمْ أَسْوَأَ ٱلَّذِي كَانُواْ يَعْمَلُونَ } ، ولنُعاقِبَنَّهم في الآخرةِ بعذابٍ أشدَّ مِن عذابهم في الدُّنيا، { ذَلِكَ }؛ العذابُ، { جَزَآءُ أَعْدَآءِ ٱللَّهِ }. وقولهُ تعالى: { ٱلنَّارُ }؛ بدلٌ مِن العذاب؛ أي بدلٌ من قولهِ { جَزَآءُ أَعْدَآءِ ٱللَّهِ }. وَقَوْلُهُ تَعَالَى: { لَهُمْ فِيهَا دَارُ الخُلْدِ }؛ أي لَهم في النَّار دارُ الإقامةِ، { جَزَآءً بِمَا كَانُوا بِآياتِنَا يَجْحَدُونَ }؛ يعني الْقُرْآنَ جَحَدُوا أنه مِن عند اللهِ.
