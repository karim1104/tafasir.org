قَوْلُهُ تَعَالَى: { وَمَا ظَلَمْنَاهُمْ وَلَـٰكِن ظَلَمُوۤاْ أَنفُسَهُمْ }؛ أي ما ظلَمنَاهم بإهلاكِهم، ولكن ظلَمُوا أنفُسَهم بسوءِ اختيارِهم، { فَمَا أَغْنَتْ عَنْهُمْ آلِهَتُهُمُ }؛ أي فما نفعَتهُم آلهتُهم، { ٱلَّتِي يَدْعُونَ }؛ التي كانوا يعبُدونَها، { مِن دُونِ ٱللَّهِ مِن شَيْءٍ لَّمَّا جَآءَ أَمْرُ رَبِّكَ وَمَا زَادُوهُمْ غَيْرَ تَتْبِيبٍ }؛ أي تَخْسِيرٍ ومنهُ: [المسد: 1] أي خَسِرَتْ يداهُ وخَسِرَ هو.
