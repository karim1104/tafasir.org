قَوْلُهُ تَعَالَى: { قَالَ ٱهْبِطَا مِنْهَا جَمِيعاً }؛ قد تقدم تفسيره، قوله تعالى: { بَعْضُكُمْ لِبَعْضٍ عَدُوٌّ }؛ يعني آدمَ وذريَّته وإبليسَ وذريَّته، قَوْلُهُ تَعَالَى: { فَإِمَّا يَأْتِيَنَّكُم مِّنِّي هُدًى }؛ أرادَ به الكتابَ والرَّسُولَ، { فَمَنِ ٱتَّبَعَ هُدَايَ }؛ أي مَنِ اتَّبَعَ الكتابَ والرسول، { فَلاَ يَضِلُّ } في الدُّنيا، { وَلاَ يَشْقَىٰ } في الآخرةِ. قال ابنُ عبَّاس رضي الله عنه: (ضَمِنَ اللهُ لِمَنْ قَرَأ الْقُرْآنَ وَعَمِلَ بهِ أنْ لاَ يَضِلَّ وَلاَ يَشْقَى).
