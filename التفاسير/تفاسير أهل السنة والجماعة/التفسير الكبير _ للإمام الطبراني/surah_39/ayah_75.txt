قَوْلُهُ تَعَالَى: { وَتَرَى ٱلْمَلاَئِكَةَ حَآفِّينَ مِنْ حَوْلِ ٱلْعَرْشِ }؛ أي مُحَدِّقِينَ حولَ العرشِ مُحِيطيِنَ به، { يُسَبِّحُونَ بِحَمْدِ رَبِّهِمْ }؛ إجْلاَلاًَ لعظَمتهِ، { وَقُضِيَ بَيْنَهُمْ }؛ الخلائقِ، { بِٱلْحَقِّ }؛ أي بالعدلِ وانتصفَ بعضُهم من بعضٍ، { وَقِيلَ } ، ويقالُ لهم بعد الفراغِ: { ٱلْحَمْدُ لِلَّهِ رَبِّ ٱلْعَالَمِينَ }؛ وذلك أنَّ اللهَ تعالى ابتدأ خلقَ الأشياءِ بالحمدِ فقالَ: [الأنعام: 1] فلمَّا بعثَ الخلقَ واستقرَّ أهلُ الجنَّة في الجنةِ، وأهلُ النار في النار، ختمَهُ بقولهِ: { ٱلْحَمْدُ لِلَّهِ رَبِّ ٱلْعَالَمِينَ }.
