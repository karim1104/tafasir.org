قَوْلُهُ تَعَالَى: { قَالَ كَلاَّ }؛ أي كَلاَّ لا يقتلونَكَ لأنِّي لا أُسَلِّطُهُمْ عليكَ، { فَٱذْهَبَا }؛ أنتَ وأخُوكَ، { بِآيَاتِنَآ }؛ يعني بما أعطَاهُما من المعجرةِ، { إِنَّا مَعَكُمْ مُّسْتَمِعُونَ }؛ وإنَّما قالَ (مَعَكُمْ) لأنه أجْرَاها مجرَى الجماعةِ، والمعنى: أسْمَعُ ما يقولونَهُ وما يُجِيبُونَكَ به.  وَقِيْلَ: إنَّ معنى قولهِ (كَلاَّ) أي قالَ اللهُ لِمُوسَى: إرتَدِعْ عَنْ هذا الظَّنِّ وهذا الخوفِ، { فَٱذْهَبَا بِآيَاتِنَآ } أي بدلاَئِلنا { إِنَّا مَعَكُمْ مُّسْتَمِعُونَ } أي شَاهِدُونَ بحفْظِكُم ونَصَرِكُمْ.
