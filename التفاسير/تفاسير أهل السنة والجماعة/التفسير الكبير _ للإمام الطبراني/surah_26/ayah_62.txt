قَوْلُهُ تَعَالَى: { فَأَتْبَعُوهُم مُّشْرِقِينَ }؛ يعني قومَ فرعون أدرَكُوا موسى وقومه حين أشْرَقَتِ الشمسُ. قَوْلُهُ تَعَالَى: { فَلَمَّا تَرَاءَى ٱلْجَمْعَانِ قَالَ أَصْحَابُ مُوسَىٰ إِنَّا لَمُدْرَكُونَ }؛ أي فلَمَّا تَوافى الفريقانِ، وتقابَلاَ بحيثُ يرى كلُّ فريقٍ صاحبه، وعايَنَ بعضُهم بعضاً، قال أصحابُ موسَى: سَيدْرِكُنَا قومُ فرعونَ، ولا طاقةَ لنا بهم! { قَالَ } لَهم موسى: { كَلاَّ }؛ أي لن يُدْرِكْنَا، ارتَدِعُوا وانزَجِرُوا عن هذه المقالةِ، { إِنَّ مَعِيَ رَبِّي }؛ نَاصِري وحَافِظِي، { سَيَهْدِينِ }؛ إلى طريقِ النَّجاةِ منهم.
