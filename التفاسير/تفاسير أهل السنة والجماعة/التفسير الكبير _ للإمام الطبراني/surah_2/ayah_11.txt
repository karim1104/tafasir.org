قولهُ عَزَّ وَجَلَّ: { وَإِذَا قِيلَ لَهُمْ لاَ تُفْسِدُواْ فِي ٱلأَرْضِ }؛ قرأ الكسائيُّ؛ ويعقوبُ؛ وهشام: { قِيلَ } وَ { حِيلَ } [سبأ: 54]، وَ { سِيقَ } [الزمر: 71]، و { جِيْئَ } ، وَ { سِيۤءَ } [هود: 77] بإشْمام الضمَّة. ومعنى الآيةِ: وإذا قِيْلَ للمنافقين وقيلَ لليهود؛ أي إذا قال لَهمُ المؤمنونَ: لا تُفسِدُوا في الأرضِ بالكُفْرِ والمعصيةِ والمداهنةِ وتعويقِ النَّاسِ عن الإيْمان بمُحَمَّدٍ صلى الله عليه وسلم والقُرْآنِ، { قَالُوۤاْ إِنَّمَا نَحْنُ مُصْلِحُونَ }؛ أي عامِلُون بالطَّاعةِ ومُصلِحُونَ بالمداهنةِ؛ لأنَّهم كانوا يقولون: لا نُعادي المؤمنينَ ولا الكفارَ؛ نُداري هؤلاءِ وهؤلاء؛ حتى إذا غلبَ أحدُ الفريقين لا يأتينا من دائرتِهم شيءٌ.
