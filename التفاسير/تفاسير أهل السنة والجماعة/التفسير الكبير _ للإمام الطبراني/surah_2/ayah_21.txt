قوله عَزَّ وَجَلَّ: { يَٰـأَيُّهَا ٱلنَّاسُ ٱعْبُدُواْ رَبَّكُمُ ٱلَّذِي خَلَقَكُمْ وَٱلَّذِينَ مِن قَبْلِكُمْ لَعَلَّكُمْ تَتَّقُونَ } ، قالَ ابنُ عبَّاس: ( { يَٰـأَيُّهَا ٱلنَّاسُ } خِطَابٌ لأَهْلِ مَكَّةَ؛ و { يَا أيُّهَا الَّذِيْنَ آمَنُواْ } خِطَابٌ لأَهْلِ الْمَدِيْنَةِ). وهو ها هُنا عامٌّ؛ وقَوْلُهُ تَعَالَى: { ٱعْبُدُواْ رَبَّكُمُ } أي وَحِّدُوهُ وأطيعوهُ. وقُوْلُهُ تَعَالَى: { ٱلَّذِي خَلَقَكُمْ } أي أوجدَكم وأنشأَكم بعد أن لم تكونوا شيئاً. وقَوْلُهُ تَعَالَى: { وَٱلَّذِينَ مِن قَبْلِكُمْ } أي وخَلَقَ الذين مِن قبلكم. { لَعَلَّكُمْ تَتَّقُونَ } أي لكي تَنْجُوا من العذاب والسَّخَطِ. قال سيبويه: (لَعَلَّ وَعَسَى حَرْفَا تَرَجٍّ) وهُما من اللهِ تعالى واجبان.
