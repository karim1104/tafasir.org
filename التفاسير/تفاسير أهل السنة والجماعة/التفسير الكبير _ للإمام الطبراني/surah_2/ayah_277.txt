قوله عَزَّ وَجَلَّ: { إنَّ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّٰلِحَٰتِ وَأَقَامُواْ ٱلصَّلَٰوةَ وَآتَوُاْ ٱلزَّكَٰوةَ لَهُمْ أَجْرُهُمْ عِندَ رَبِّهِمْ وَلاَ خَوْفٌ عَلَيْهِمْ وَلاَ هُمْ يَحْزَنُونَ }؛ معناهُ: { إنَّ ٱلَّذِينَ آمَنُواْ } باللهِ وكتبهِ ورسله وتحريمِ الربا { وَعَمِلُواْ ٱلصَّٰلِحَٰتِ } فيما بينهم وبينَ ربهم، وأتَّمُّوا الصلواتَ الخمس، وأعطوا الزكاة المفروضةَ من أموالهم، فلهُم جزاؤهم وثوابُهم في الآخرة { عِندَ رَبِّهِمْ وَلاَ خَوْفٌ عَلَيْهِمْ } إذا ذبحَ الموتُ { وَلاَ هُمْ يَحْزَنُونَ } إذا أطبقتِ النارُ على أهلها.
