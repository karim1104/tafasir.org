قَوْلُهُ تَعَالَى: { أَلَمْ يَأْتِكُمْ نَبَأُ ٱلَّذِينَ كَفَرُواْ مِن قَبْلُ فَذَاقُواْ وَبَالَ أَمْرِهِمْ وَلَهُمْ عَذَابٌ أَلِيمٌ }؛ أي ألَمْ يأتِكُم خبَرُ الذين كفَرُوا من قبلِكم من الأُمم الخاليةِ كيف أذاقَهم اللهُ عقوبةَ تكذيبهم في الدُّنيا ولَهم في الآخرةِ عذابٌ. جميعُ، { ذَلِكَ }؛ العذاب، { بِأَنَّهُ كَانَت تَّأْتِيهِمْ رُسُلُهُم بِٱلْبَيِّنَاتِ }؛ أي بالمعجزات، { فَقَالُوۤاْ أَبَشَرٌ يَهْدُونَنَا }؛ فقالوا آدَمِيٌّ مِثلُنا يَدعُونا إلى خلافِ دينِ آبائنا، { فَكَفَرُواْ }؛ بالكتُب والرُّسل وأعرَضُوا عن القبولِ منهم، { وَتَوَلَّواْ وَّٱسْتَغْنَىٰ ٱللَّهُ }؛ عن إيمانِهم وطاعتهم، { وَٱللَّهُ غَنِيٌّ }؛ عن أفعالِ العباد، { حَمِيدٌ }؛ في إنعامهِ عليهم.  ومعنى قولهِ { وَبَالَ أَمْرِهِمْ } أصلُ الْوَبَالِ مِنَ الثُّقْلِ، يقالُ: أمرٌ وَبيلٌ؛ أي ثقيلٌ، يسمى جزاءُ المعصية وَبَالاً لِثِقَلِهِ.
