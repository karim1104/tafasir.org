قولهُ تعالى: { ثُمَّ شَقَقْنَا ٱلأَرْضَ شَقّاً }؛ أي صدَّعنا الأرضَ بالنَّباتِ، { فَأَنبَتْنَا فِيهَا حَبّاً }؛ يعني الحبوبَ كلَّها يُتغذى بها، { وَعِنَباً }؛ أي كَرْماً، { وَقَضْباً }؛ للدواب، { وَزَيْتُوناً }؛ هو الذي يُعصَرُ منه الزيتُ، وقال الحسنُ: ((الْقَضْبُ: الْعَلَفُ))، { وَنَخْلاً }؛ جمعُ نَخلَةٍ، { وَحَدَآئِقَ غُلْباً }؛ الحدائقُ: جمعُ الحديقةِ، وهو البستانُ الذي أُحْدِقَ بالحيطانِ، والغُلْبُ: الشَّجَرُ العظامُ الغِلاَظُ، وَقِيْلَ: الغُلْبُ الملتفَّةُ بالأشجار بعضُها في بعضٍ، يقالُ: شجرةٌ غَلْبَاءُ إذا كانت عظيمةً غليظة، ورجلٌ غَلْبٌ إذا كان غليظَ العُنقِ.
