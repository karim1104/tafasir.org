قَوْلُهُ عَزَّ وَجَلَّ: { وَلاَ تُجَادِلْ عَنِ ٱلَّذِينَ يَخْتَانُونَ أَنْفُسَهُمْ }؛ ولا تُخَاصِمْ عن الذين يَظْلِمُونَ أنفسهَم بالخيانةِ والسَّرقة ورميِ اليهوديِّ بها، { إِنَّ ٱللَّهَ لاَ يُحِبُّ مَن كَانَ خَوَّاناً }؛ أي خَائِناً في الدِّرعِ؛ { أَثِيماً }؛ في رَمْيهِ اليهوديَّ. وَقِيْلَ: الْخَوَّانُ: المكتسبُ للإثْمِ، والآثِمُ الفاجرُ بالكذب ورمي البريءِ، وإنَّما قال: { يَخْتَانُونَ أَنْفُسَهُمْ } وإنْ كانوا خَانُوا غيرَهم؛ لأن مضرَّةَ خيانتِهم راجعةٌ إليهم، كما يقالُ: فَمَنْ ظَلَمَ غَيْرَهُ مَا ظَلَمَ إلاَّ نَفْسَهُ، وإنَّما قال: { خَوَّاناً } ولم يقل خَائِناً لعظيمِ أمرِ الخيانَةِ.
