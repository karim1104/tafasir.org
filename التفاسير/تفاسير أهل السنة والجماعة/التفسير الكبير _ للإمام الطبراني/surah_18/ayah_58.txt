قَوْلُهُ تَعَالَى: { وَرَبُّكَ ٱلْغَفُورُ ذُو ٱلرَّحْمَةِ }؛ أي الغافرُ السَّاتِرُ على عبادهِ، والرحمةُ حين لا يُعَجِّلُهُمْ بالعقوبةِ، { لَوْ يُؤَاخِذُهُم } بعقاب، { بِمَا كَسَبُواْ لَعَجَّلَ لَهُمُ ٱلْعَذَابَ }؛ في الحالِ؛ { بَل لَّهُم مَّوْعِدٌ }؛ أي لعذابهم أجْلٌ ضَرَبَهُ اللهُ، { لَّن يَجِدُواْ مِن دُونِهِ مَوْئِلاً }؛ أي مَلْجَأً وَمَنْجاً.
