قَوْلُهُ تَعَالَى: { قَالُواْ فَمَا جَزَآؤُهُ إِن كُنتُمْ كَاذِبِينَ }؛ أي ما جزاءُ مَنْ سَرَقَ إنْ كنتم كَاذِبين، { قَالُواْ جَزَآؤُهُ } السارقُ، { مَن وُجِدَ فِي رَحْلِهِ } أُخِذ عَبداً لسَرِقته، { فَهُوَ جَزَاؤُهُ } استِرقاقهُ، { كَذٰلِكَ نَجْزِي ٱلظَّالِمِينَ } أي هكَذا جزاءُ السَّارقين في أرضِنا وهي سُنَّةُ يعقوبَ عليه السلام، حَكَمُوا على أنفُسِهم بما كان يطلبُ يوسُفَ من احتباسِ أخيه.
