قَوْلُهُ تَعَالَى: { قَالَ }؛ لهم يعقوبُ: { لَنْ أُرْسِلَهُ }؛ بنيامين، { مَعَكُمْ حَتَّىٰ تُؤْتُونِ مَوْثِقاً }؛ أي تُعطونِي عَهْداً وثيقاً، { مِّنَ ٱللَّهِ لَتَأْتُنَّنِي بِهِ }؛ لتَرُدُّنَّهُ عليَّ، { إِلاَّ أَن يُحَاطَ بِكُمْ } ، يُنْزِلُ بكُم أمِينُ السَّماءِ والأرض لا تَقدِرُون على دفعِ ذلك، { فَلَمَّآ آتَوْهُ مَوْثِقَهُمْ }؛ أي لما حَلَفوا، { قَالَ }؛ لَهم يعقوبُ: { ٱللَّهُ عَلَىٰ مَا نَقُولُ وَكِيلٌ }؛ أي شهيدٌ حفيظ.
