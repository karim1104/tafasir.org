قَوْلُهُ تَعَالَى: { وَيَقُولُ ٱلَّذِينَ كَفَرُواْ }؛ أي يقولون على جِهة التَّعَنُّتِ: { لَوْلاَ }؛ هَلاَّ، { أُنزِلَ عَلَيْهِ }؛ على مُحَمَّدٍ، { آيَةٌ مِّن رَّبِّهِ }؛ يعني الآياتِ التي يَقترِحونَها عليه، { قُلْ } يا مُحَمَّدُ: { إِنَّ ٱللَّهَ يُضِلُّ مَن يَشَآءُ } عن ثوابهِ وكرامته، { وَيَهْدِيۤ } ، لدِينه مَن أقبَلَ، { إِلَيْهِ }؛ إلى اللهِ و، { مَنْ أَنَابَ }؛ رجَعَ عن الكفر.
