قَوْلُهُ تَعَالَى: { وَلَقَدِ ٱسْتُهْزِئَ بِرُسُلٍ مِّن قَبْلِكَ }؛ أي ولقدِ استُهزئَ بالأنبياءِ من قبلِكَ كما استهزَأ بكَ قومُكَ، { فَأَمْلَيْتُ } فأمهَلتُ، { لِلَّذِينَ كَفَرُواْ } بعد استهزائِهم بالرُّسل، { ثُمَّ أَخَذْتُهُمْ } بذُنوبهم، { فَكَيْفَ كَانَ عِقَابِ } فانظُرْ كيف كان عاقبةُ ما حلَّ من عقاب الله بهم، فلا يكن في صدرِكَ حرجٌ من استهزائِهم.
