قَوْلُهُ تَعَالَى: { فَلَمَّا رَأَوْهُ زُلْفَةً سِيئَتْ وُجُوهُ ٱلَّذِينَ كَفَرُواْ }؛ معناهُ: فلمَّا رأوا العذابَ قريباً تبيَّن السُّوءُ في وُجوهِهم وسَاءَهم ذلك. وَقِيْلَ: أُحرِقَتْ وجوهُ الذين كفَرُوا، فاسودَّتْ وَعَلَتها الكآبةُ والقَتْرَةُ. وَقِيْلَ: معنى { سِيئَتْ } قََبُحَتْ وجوهُهم بالسَّوادِ، { وَقِيلَ }؛ لَهم: { هَـٰذَا }؛ العذابُ، { ٱلَّذِي كُنتُم بِهِ }؛ من أجلهِ، { تَدَّعُونَ }؛ الأباطيلَ والأكاذيبَ أنَّكم إذا مِتُّمْ. وكنتم تُراباً وعظاماً أنَّكم لا تُبعثون. وقرأ الضحَّاك وقتادةُ ويعقوب (تَدْعُونَ) مخفَّفاً؛ أي تَدْعُونَ اللهَ أنْ يأتِيَكم به، من الدُّعاء وهو قولهم [الأنفال: 32] الآية.
