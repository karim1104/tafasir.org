قَوْلُهُ تَعَالَى: { فَرَجَعُوۤاْ إِلَىٰ أَنفُسِهِمْ }؛ أي فرَجَعُوا إلى أنفسهم بالْمَلاَمَةِ، { فَقَالُوۤاْ إِنَّكُمْ أَنتُمُ ٱلظَّالِمُونَ }؛ في سؤالهِ؛ لأنَّها لو كانت آلِهةً لَم يَصِلْ إلى كسرِها أحدٌ؛ { ثُمَّ نُكِسُواْ عَلَىٰ رُءُوسِهِمْ }؛ أي أدركَتْهُم حيرةٌ فَنَكَّسُوا لأجلِها رؤوسَهُم، وأقرُّوا بما هو حُجَّةٌ عليهم، فقالوا: { لَقَدْ عَلِمْتَ }؛ يا إبراهيم، { مَا هَـٰؤُلاۤءِ يَنطِقُونَ }؛ فكسَرْتُهم لذلكَ.  وَقِيْلَ: معنى الآيةِ: تذكَّروا بقلوبهم، ورجَعُوا إلى عقولِهم، فقالوا: ما نراهُ إلاّ كما قالَ إنَّكُمْ أنْتُمُ الظَّالِمُونَ بعبادتِكم آلِهَةً لا تنطقُ ولا تبطشُ، ثُم أدركَتْهم الشقاوةُ، فعادوا إلى قولِهم الأوَّل وضلالِهم القديم، وهو قوله { ثُمَّ نُكِسُواْ عَلَىٰ رُءُوسِهِمْ } أي رُدُّوا إلى الكفرِ بعد أن أقَرُّوا على أنفسِهم بالظُّلم، فقالوا لإبراهيم: لَقَدْ عَلِمْتَ مَا هَؤلاَء يَنْطِقُونَ فلذلِكَ كسرتَهم.  فلما اتَّجهت الْحُجَّةُ عليهم بإقرارهم، وبَّخَهُمْ إبراهيمُ و { قَالَ أَفَتَعْبُدُونَ مِن دُونِ ٱللَّهِ مَا لاَ يَنفَعُكُمْ شَيْئاً }؛ ولا يرزقُكم { وَلاَ يَضُرُّكُمْ }؛ إذا لَم تعبدوهُ، { أُفٍّ لَّكُمْ }؛ أي تَبّاً لكم، { وَلِمَا تَعْبُدُونَ مِن دُونِ ٱللَّهِ أَفَلاَ تَعْقِلُونَ }؛ أنَّ هذه الأصنامَ لا تستحقُّ العبادةَ، إذ هي أحجارٌ لا حركةَ لَها ولا بيانَ، أفليس لكم ذهنُ الإنسانيَّةِ.
