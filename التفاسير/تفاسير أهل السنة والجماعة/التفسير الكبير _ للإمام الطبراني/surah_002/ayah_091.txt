قَوْلُهُ تَعَالَى: { وَإِذَا قِيلَ لَهُمْ آمِنُواْ بِمَا أَنْزَلَ اللَّهُ }؛ أي إذا قِيْلَ ليهودِ المدينة: صدِّقوا بالقُرْآنِ؛ { قَالُواْ نُؤْمِنُ بِمَآ أُنْزِلَ عَلَيْنَا }؛ يعنونَ التوراةَ، { وَيَكْفُرونَ بِمَا وَرَآءَهُ }؛ أي ويجحدون بما سِوَى الذي أُنزلَ عليهم كقولهِ تعالى: [المؤمنون: 7] أي سِوَاهُ. وَقَوْلُهُ تَعَالَى: { وَهُوَ ٱلْحَقُّ }؛ يعني الْقُرْآنَ، { مُصَدِّقاً لِّمَا مَعَهُمْ }؛ أي مُوافِقاً للتوراةِ وسائر الكتب. ونصبَ { مُصَدِّقاً } على الحالِ.  وقَوْلُهُ تَعَالَى: { قُلْ فَلِمَ تَقْتُلُونَ أَنْبِيَآءَ ٱللَّهِ }؛ أي قُل لَهم يا مُحَمَّدُ: إنْ كنتم تصدِّقون التوراةِ فلِمَ تقتلون أنبياءَ اللهِ، { مِن قَبْلُ }؛ وليس فيما أُنزلَ عليكم قتلُ الأنبياءِ، قَوْلُهُ تَعَالَى: { إِن كُنْتُمْ مُّؤْمِنِينَ }؛ أي فلِمَ تقتلونَ أنبياءَ الله إنْ كنتم مؤمنينَ بالتوراةِ وقد نُهيتم فيها عن قتلِهم. وقوله (لِمَ) أصله (لِمَا) فحذفت الألفُ فَرقاً بين الخبر والاستفهامِ؛ كقوله (فِيْمَ) و(بمَ) و(مِمَّ) و(عَلاَمَ) و(حتَّى مَ).
