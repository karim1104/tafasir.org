قوله عَزَّ وَجَلَّ: { وَمَآ أَرْسَلْنَا مِن رَّسُولٍ إِلاَّ لِيُطَاعَ بِإِذْنِ ٱللَّهِ }؛ أي لِيُطَاعَ ذلك الرسولُ بأمرِ الله، { وَلَوْ أَنَّهُمْ إِذ ظَّلَمُوۤاْ أَنْفُسَهُمْ }؛ بمُطَالَبَةِ الحُكمِ إلى الطاغوتِ، { جَآءُوكَ }؛ أيُّهَا الرسُولُ، { فَٱسْتَغْفَرُواْ ٱللَّهَ }؛ وتابوا إليه، { وَٱسْتَغْفَرَ لَهُمُ ٱلرَّسُولُ }؛ عند ذلكَ، { لَوَجَدُواْ ٱللَّهَ تَوَّاباً }؛ قَابلاً للتوبةِ، { رَّحِيماً }؛ بهم بعدَ التوبةِ.
