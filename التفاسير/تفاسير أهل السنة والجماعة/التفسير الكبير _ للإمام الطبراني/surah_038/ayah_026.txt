قَوْلُهُ تَعَالَى: { يٰدَاوُودُ إِنَّا جَعَلْنَاكَ خَلِيفَةً فِي ٱلأَرْضِ }؛ أي قال اللهُ له بعدَ المغفرةِ، { يٰدَاوُودُ إِنَّا جَعَلْنَاكَ خَلِيفَةً فِي ٱلأَرْضِ } أي نَبيّاً مَلِكاً على بني إسرائيلَ، والخليفةُ هو المدبرُ للأمرِ والمقيم. يا داودُ إنَّا صيَّرناكَ خليفةً في الأرضِ تدبرُ أمورَ العبادِ مِن قِبَلِنَا، { فَٱحْكُمْ بَيْنَ ٱلنَّاسِ بِٱلْحَقِّ }؛ أي العدلِ الذي هو حكمُ الله بين خلقهِ، { وَلاَ تَتَّبِعِ ٱلْهَوَىٰ } ، في الحكمِ بين النَّاس، { فَيُضِلَّكَ عَن سَبِيلِ ٱللَّهِ } ، أي فيصرِفُكَ الهوَى عن طاعةِ الله، { إِنَّ ٱلَّذِينَ يَضِلُّونَ عَن سَبِيلِ ٱللَّهِ } ، أي عن دين الله، { لَهُمْ عَذَابٌ شَدِيدُ } ، في الآخرة، { بِمَا نَسُواْ يَوْمَ ٱلْحِسَابِ } أي ترَكُوا العملَ ليومِ الحساب.
