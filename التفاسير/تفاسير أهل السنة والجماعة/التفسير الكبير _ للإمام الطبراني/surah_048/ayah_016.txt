قَوْلُهُ تَعَالَى: { قُل لِّلْمُخَلَّفِينَ مِنَ ٱلأَعْرَابِ }؛ أي قُل لهؤلاء المخلَّفين عن الحديبيةِ: { سَتُدْعَوْنَ }؛ بعدَ موتِ النبي صلى الله عليه وسلم { إِلَىٰ }؛ قتالِ؛ { قَوْمٍ أُوْلِي بَأْسٍ شَدِيدٍ }؛ أي أهلِ اليمَامَةِ، قال الزهريُّ: (هُمْ أهْلُ الْيَمَامَةِ بَنُو حَنِيفَةَ أتْبَاعُ مُسَيْلَمَةَ، فَأَتَاهُ أبُو بَكْرٍ رضي الله عنه)، قال رافعُ بن خَديج: (كُنَّا نَقْرَأُ هَذِهِ الآيَةَ وَلاَ نَعْلَمُ مَنْ هُمْ حَتَّى دَعَا أبُو بَكْرٍ رضي الله عنه إلَى قِتَالِ بَنِي حَنِيفَةَ فَعَلِمْنَا أنَّهُمْ هُمْ).  وقال ابنُ جُريج: (سَيَدْعُوكُمْ عُمَرُ رضي الله عنه إلَى قِتَالِ فَارسَ وَالرُّومَ) { تُقَاتِلُونَهُمْ أَوْ يُسْلِمُونَ }؛ معناهُ: تُقاتِلُوهم أن يكون منهم الإسلام، { فَإِن تُطِيعُواْ }؛ أبَا بكرٍ وعمر، { يُؤْتِكُمُ ٱللَّهُ أَجْراً حَسَناً }؛ عَظيماً في الجنَّة، { وَإِن تَتَوَلَّوْاْ كَمَا تَوَلَّيْتُمْ مِّن قَبْلُ }؛ عن طاعةِ مُحَمَّدٍ صلى الله عليه وسلم في المسيرِ إلى الحديبية، { يُعَذِّبْكُمْ }؛ في الآخرةِ، { عَذَاباً أَلِيماً }؛ شَديداً.  قرأ أُبَيُّ (أوْ يُسْلِمُوا) بحذفِ النُّون؛ أي حتى يُسلِمُوا، وكقولِ امرئِ القيسِ: (أوْ نَمُوتَ)، وقرأ الكافَّة بإثباتِ النُّون في محل الرفعِ عطفاً على { تُقَاتِلُونَهُمْ }.
