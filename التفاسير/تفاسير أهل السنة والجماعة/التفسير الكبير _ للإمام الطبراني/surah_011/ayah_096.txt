قَوْلُهُ تَعَالَى: { وَلَقَدْ أَرْسَلْنَا مُوسَىٰ بِآيَاتِنَا وَسُلْطَانٍ مُّبِينٍ }؛ أي أرسَلنا مُوسَى بدَلائِلنا، والآيةُ العلامةُ التي فيها العِبرَةُ، وقولهُ تعالى: { وَسُلْطَانٍ مُّبِينٍ } أي وحجَّة بيِّنَةٍ مسلَّطة على إبطَال الفاسد. وقولهُ تعالى: { إِلَىٰ فِرْعَوْنَ وَمَلَئِهِ }؛ وأشرافِ قَومِهِ، { فَٱتَّبَعُوۤاْ أَمْرَ فِرْعَوْنَ }؛ أي اتَّبعوا قولَهُ وترَكُوا أمرَ الله، { وَمَآ أَمْرُ فِرْعَوْنَ بِرَشِيدٍ }؛ أي ما هو بصَائبٍ، إلا أنَّهم اتبعوا وخالَفُوا أمرَ موسى.
