قَوْلُهُ تَعَالَِى: { قَالَ فَبِمَآ أَغْوَيْتَنِي }؛ أي فَبمَا أضْلَلْْتَنِي عنِ الْهُدَى، { لأَقْعُدَنَّ لَهُمْ صِرَاطَكَ ٱلْمُسْتَقِيمَ }؛ أي لأَرْصُدَنَّ علَى طريقِ بَنِي آدمَ، وأصُدَّهُمْ عن دِيْنِكَ المستقيمِ. وقال الحسنُ: (مَعْنَى: { أَغْوَيْتَنِي } لَعَنْتَنِي). وَقِيْلَ: { أَغْوَيْتَنِي } خَيَّبْتَنِي، وقد يكونُ الغِوَى بمعنى الْخَيْبَةِ. وَقِيْلَ: { أَغْوَيْتَنِي } أي أهْلَكتَنِي.
