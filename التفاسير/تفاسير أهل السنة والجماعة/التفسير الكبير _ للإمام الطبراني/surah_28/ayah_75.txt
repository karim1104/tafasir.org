قَوْلُهُ تَعَالَى: { وَنَزَعْنَا مِن كُلِّ أُمَّةٍ شَهِيداً }؛ أي وأخرَجْنا من كلِّ أُمَّةٍ رسُولَها الذي يشهدُ عليهم بالتبليغِ وما كان منهم، { فَقُلْنَا هَاتُواْ بُرْهَانَكُمْ }؛ أي فقُلْنَا للمَشهُودِ عليهم: { هَاتُواْ بُرْهَانَكُمْ } أي حُجَّتَكُمْ بأنَّ معي شَريكاً، { فَعَلِمُوۤاْ أَنَّ ٱلْحَقَّ لِلَّهِ }؛ أي أنَّ التوحيدَ للهِ، { وَضَلَّ عَنْهُمْ }؛ أي زالَ عنهم وبَطَلَ في الآخرةِ، { مَّا كَانُواْ يَفْتَرُونَ }؛ في الدُّنيا من قولِهم: إنَّ مع اللهِ شريكاً.
