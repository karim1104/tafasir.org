قَوْلُهُ تَعَالَى: { وَقَالَ فِرْعَوْنُ يٰأَيُّهَا ٱلْملأُ مَا عَلِمْتُ لَكُمْ مِّنْ إِلَـٰهٍ غَيْرِي }؛ أي قالَ فرعونُ لخَوَاصِّ قومهِ: { مَا عَلِمْتُ لَكُمْ مِّنْ إِلَـٰهٍ غَيْرِي } وهذه إحدَى كَلِمَتَيْهِ اللَّتين أخذهُ الله بهما، والأُخرى قولهُ [النازعات: 24].  وقولهُ تعالى: { فَأَوْقِدْ لِي يٰهَامَانُ عَلَى ٱلطِّينِ }؛ أي اتَّخِذْ لِي آجُرّاً، { فَٱجْعَل لِّي صَرْحاً }؛ أي قَصْراً طَويلاً متَّسِعاً مرتفعاً، { لَّعَلِّيۤ أَطَّلِعُ إِلَىٰ إِلَـٰهِ مُوسَىٰ }؛ أي أصعدُ إليه، ظَنَّ بجهلهِ أنه يَتَهَيَّأُ له أنْ يبلُغَ بصرحهِ إلى السَّماءِ، وظنَّ أن إلهَ مُوسَى جِسْماً مشاهَداً كما تقولُ الْمُشَبهَةُ، تَعَالَى اللهُ عَنْ ذلِكََ.  قال المفسِّرون: لَمَّا أمرَ فرعونُ وزيرَهُ هامانَ ببناء الصَّرح، جَمَعَ خمسين ألفَ بَنَّاءٍ سِوَى الاتباعِ والأُجَرَاءِ ممن يطبخُ الآجُرَّ والجصَّ، وينحتُ الخشبَ والأبوابَ، ويضربُ المساميرَ. قَوْلُهُ تَعَالَى: { وَإِنِّي لأَظُنُّهُ مِنَ ٱلْكَاذِبِينَ }؛ أي في ادِّعاء (إلَهاً غَيْرِي) وأنه رسولهُ، وهذا اعترافٌ مِن فرعونَ بالشَّكِّ لأنه شَاكٌّ لا يدري مَن في السَّماء، ولو كان إلَهاً لَمْ يجهَلْ ولَم يشُكَّ، والمبطلُ تظهرُ عليه الْمُنَاقَضَةُ.
