{ فتعالى الله } أي تعاظم وتنزه عن الصاحبة والولد والشريك والعبث وجميع النقائص ،   بل هو { الملك الحق } الثابت هو وصفاته العلي و { الكريم } صفة للعرش لتنزل الخيرات منه أو لنسبته إلى أكرم الأكرمين .  <br />
وقرأ أبان بن تغلب وابن محيصن وأبو جعفر وإسماعيل عن ابن كثير { الكريم } بالرفع صفة لرب العرش أو { العرش } ،   ويكون معطوفاً على معنى المدح .  <br />
