التمثال : الصورة المصنوعة مشبهة بمخلوق من مخلوقات الله تعالى ،   مثلت الشيء بالشيء إذا شبهته به .  <br />
قال الشاعر :<br />
ويا رب يوم قد لهوت وليلة *** بآنسة كأنها خط تمثال<br />
و { إذ } معمولة لآتينا أو { رشدة } و { عالمين } وبمحذوف أي اذكر من أوقات رشده هذا الوقت ،   وبدأ أولاً بذكر أبيه لأنه الأهم عنده في النصيحة وإنقاذه من الضلال ثم عطف عليه { قومه } كقوله { وأنذر عشيرتك الأقربين } وفي قوله { ما هذه التماثيل } تحقير لها وتصغير لشأنها وتجاهل بها مع علمه بها وبتعظيمهم لها .  <br />
وفي خطابه لهم بقوله { أنتم } استهانة بهم وتوقيف على سوء صنيعهم ،   وعكف يتعدى بعلى كقوله { يعكفون على أصنام لهم } فقيل { لها } هنا بمعنى عليها كما قيل في قوله { وإن أسأتم فلها } والظاهر أن اللام في { لها } لام التعليل أي لتعظيمها ،   وصلة { عاكفون } محذوفة أي على عبادتها .  <br />
وقيل : ضمن { عاكفون } معنى عابدين فعداه باللام .  <br />
وقال الزمخشري : لم ينو للعاكفين محذوفاً وأجراه مجرى ما لا يتعدى كقوله فاعلون العكوف لها أو واقفون لها انتهى .  <br />
