و { قيماً } تأكيد لإثبات الاستقامة إن كان مدلوله مستقيماً وهو قول ابن عباس والضحاك .  <br />
وقيل : { قيماً } بمصالح العباد وشرائع دينهم وأمور معاشهم ومعادهم .  <br />
وقيل : { قيماً } على سائر الكتب بتصديقها .  <br />
واختلفوا في هذه الجملة المنفية ،   فزعم الزمخشري أنها معطوفة على { أنزل } فهي داخلة في الصلة ،   ورتب على هذا أن الأحسن في انتصاب { قيماً } أن ينتصب بفعل مضمر ولا يجعل حالاً من { الكتاب } لما يلزم من ذلك وهو الفصل بين الحال وذي الحال ببعض الصلة ،   وقدره جعله { قيماً } .  <br />
وقال ابن عطية : { قيماً } نصب على الحال من { الكتاب } فهو بمعنى التقديم مؤخر في اللفظ ،   أي أنزل الكتاب { قيماً } واعترض بين الحال وذي الحال قوله { ولم يجعل له عوجاً } ذكره الطبري عن ابن عباس ،   ويجوز أن يكون منصوباً بفعل مضمر تقديره أنزله أو جعله { قيماً } .  <br />
أما إذا قلنا بأن الجملة المنفية اعتراض فهو جائز ،   ويفصل بجمل للاعتراض بين الحال وصاحبها .  <br />
وقال العسكري : في الآية تقديم وتأخير كأنه قال : احمدوا الله على إنزال القرآن { قيماً } لا عوج فيه ،   ومن عادة البلغاء أن يقدّموا الأهم .  <br />
وقال أبو عبد الله الرازي : { ولم يجعل له عوجاً } يدل على كونه مكملاً في ذاته .  <br />
وقوله قيماً يدل على كونه مكملاً بغيره ،   فثبت بالبرهان العقلي أن الترتيب الصحيح هو الذي ذكره الله ،   وأن ما ذكروه من التقديم والتأخير فاسد يمتنع العقل من الذهاب إليه .  <br />
وقال الكرماني : إذ جعلته حالاً وهو الأظهر فليس فيه تقديم ولا تأخير ،   والصحيح أنهما حالان من { الكتاب } الأولى جملة والثانية مفرد انتهى .  <br />
وهذا على مذهب من يجوز وقوع حالين من ذي حال واحد بغير عطف ،   وكثير من أصحابنا على منع ذلك انتهى .  <br />
واختاره الأصبهاني وقال : هما حالان متواليان والتقدير غير جاعل له { عوجاً قيماً } وقال صاحب حل العقد : يمكن أن يكون قوله قيماً بدلاً من قوله { ولم يجعل له عوجاً } أي جعله مستقيماً { قيماً } انتهى .  <br />
ويكون بدل مفرد من جملة كما قالوا في عرفت زيداً أبو من أنه بدل جملة من مفرد وفيه خلاف .  <br />
وقيل : { قيماً } حال من الهاء المجرورة في { ولم يجعل له } مؤكدة .  <br />
وقيل : منتقلة ،   والظاهر أن الضمير في { له } عائد على { الكتاب } وعليه التخاريج الإعرابية السابقة .  <br />
وزعم قوم أن الضمير في { له } عائد على { عبده } والتقدير { على عبده } وجعله { قيماً } .  <br />
وحفص يسكت على قوله { عوجاً } سكتة خفيفة ثم يقول { قيماً } .  <br />
وفي بعض مصاحف الصحابة { ولم يجعل له عوجاً } لكن جعله قيماً ويحمل ذلك على تفسير المعنى لا أنها قراءة .  <br />
وأنذر يتعدى لمفعولين قال { إنا أنذرناكم عذاباً قريباً } وحذف هنا المفعول الأول وصرح بالمنذر به لأنه هو الغرض المسوق إليه فاقتصر عليه ،   ثم صرح بالمنذر في قوله حين كرر الإنذار فقال : { وينذر الذين قالوا اتخذ الله ولداً } فحذف المنذر أولاً لدلالة الثاني عليه ،   وحذف المنذر به لدلالة الأول عليه ،   وهذا من بديع الحذف وجليل الفصاحة ،   ولما لم يكرر البشارة أتى بالمبشر والمبشر به ،   والظاهر أن { لينذر } متعلقة بأنزل .  <br />
وقال الحوفي : تتعلق بقيماً ،   ومفعول لينذر المحذوف قدره ابن عطية { لينذر } العالم ،   وأبو البقاء { لينذر } العباد أو لينذركم .  <br />
والزمخشري قدره خاصاً قال : وأصله { لينذر } الذين كفروا { بأساً شديداً } ،   والبأس من قوله { بعذاب بئيس } وقد بؤس العذاب وبؤس الرجل بأساً وبأسة انتهى .  <br />
وكأنه راعي في تعيين المحذوف مقابله وهو { ويبشر المؤمنين الذين } والبأس الشديد عذاب الآخرة ويحتمل أن يندرج فيه ما يلحقهم من عذاب الدنيا .  <br />
ومعنى من { لدنه } صادر من عنده .  <br />
وقرأ أبو بكر بسكون الدال وإشمامها الضم وكسر النون ،   وتقدّم الكلام عليها في أول هود .  <br />
وقرئ { ويبشر } بالرفع والجمهور بالنصب عطفاً على { لينذر } والأجر الحسن الجنة ،   ولما كنى عن الجنة بقوله { أجراً حسناً }<br />
