الصخرة معروفة وهي حجر كبير .  <br />
وقال الزمخشري : { أرأيت } بمعنى أخبرني فإن قلت : فما وجه التئام هذا الكلام فإن كل واحد من { أرأيت } و { إذ أوينا } و { فإني نسيت الحوت } لا متعلق له ؟ قلت : لما طلب موسى الحوت ذكر يوشع ما رأى منه وما اعتراه من نسيانه إلى تلك الغاية فدهش فطفق يسأل موسى عن سبب ذلك ،   كأنه قال : { أرأيت } ما دهاني { إذ أوينا إلى الصخرة فإني نسيت الحوت } فحذف ذلك انتهى .  <br />
وكون أرأيتك بمعنى أخبرني ذكره سيبويه : وقد أمعنا الكلام في ذلك في سورة الأنعام وفي شرحنا لكتاب التسهيل .  <br />
وأما ما يختص بأرأيت في هذا الموضع فقال أبو الحسن الأخفش : إن العرب أخرجتها عن معناها بالكلية فقالوا : أرأيتك وأريتك بحذف الهمزة إذا كانت بمعنى أخبرني ،   وإذا كانت بمعنى أبصرت لم تحذف همزتها قال : وشذت أيضاً فألزمتها الخطاب على هذا المعنى ،   ولا تقول فيها أبداً أراني زيد عمراً ما صنع ،   وتقول هذا على معنى أعلم .  <br />
وشذت أيضاً فأخرجتها عن موضعها بالكلية بدليل دخول الفاء ألا ترى قوله { أرأيت إذ أوينا إلى الصخرة فإني نسيت الحوت } فما دخلت الفاء إلاّ وقد أخرجت لمعنى إما أو تنبه ،   والمعنى أما { إذ أوينا إلى الصخرة } فالأمر كذا ،   وقد أخرجتها أيضاً إلى معنى أخبرني كما قدمنا ،   وإذا كانت بمعنى أخبرني فلا بد بعدها من الاسم المستخبر عنه وتلزم الجملة التي بعدها الاستفهام ،   وقد يخرج لمعنى أما ويكون أبداً بعدها الشرط وظرف الزمان فقوله { فإني نسيت الحوت } معناه أما { إذ أوينا } { فإني نسيت الحوت } أو تنبه { إذ أوينا } وليست الفاء إلاّ جواباً لأرأيت ،   لأن إذ لا يصح أن يجازى بها إلاّ مقرونة بما بلا خلاف انتهى كلام الأخفش .  <br />
وفيه إن { أرأيت } إذا كانت بمعنى أخبرني فلا بد بعدها من الاسم المستخبر عنه ،   وتلزم الجملة التي بعدها الاستفهام وهذان مفقودان في تقدير الزمخشري { أرأيت } هنا بمعنى أخبرني ،   ومعنى { نسيت الحوت } نسيت ذكر ما جرى فيه لك .  <br />
وفي قوله { وما أنسانيه إلاّ الشيطان } حسن أدب سبب النسيان إلى المتسبب فيه بوسوسته و { أن أذكره } بدل اشتمال من الضمير العائد على الحوت ،   والظاهر أن الضمير في { واتخذ سبيله في البحر عجباً } عائد على الحوت كما عاد في قوله { فاتخذ سبيله في البحر سرباً } وهو من كلام يوشع .  <br />
وقيل : الضمير عائد على موسى أي اتخذ موسى .  <br />
ومعنى { عجباً } أي تعجب من ذلك أو اتخاذاً { عجباً } وهو أن أثره بقي إلى حيث سار .  <br />
وقدره الزمخشري { سبيله } { عجباً } وهو كونه شبيه السرب قال : أو قال { عجباً } في آخر كلام تعجباً من حاله في رؤية تلك العجيبة ونسيانه لها ،   أو مما رأى من المعجزتين وقوله : { وما أنسانيه إلاّ الشيطان أن أذكره } اعتراض بين المعطوف والمعطوف عليه .  <br />
وقيل : إن { عجباً } حكاية لتعجب موسى وليس بذلك انتهى .  <br />
وقال ابن عطية : { واتخذ سبيله في البحر عجباً } يحتمل أن يكون من قول يوشع لموسى أي اتخذ الحوت سبيلاً عجباً للناس ،   ويحتمل أن يكون قوله { واتخذ سبيله في البحر } تمام الخبر ثم استأنف التعجب فقال من قبل نفسه { عجباً } لهذا الأمر ،   وموضع العجب أن يكون حوت قد مات وأكل شقه ثم حيي بعد ذلك .  <br />
قال أبو شجاع في كتاب الطبري رأيته أتيت به فإذا هو شق حوت وعين واحدة وشق آخر ليس فيه شيّ .  <br />
قال ابن عطية : وأنا رأيته والشق الذي فيه شيّ عليه قشرة رقيقة ليست تحتها شوكة ،   ويحتمل أن يكون { واتخذ سبيله } الآية إخباراً من الله تعالى وذلك على وجهين : إما أن يخبر عن موسى أنه اتخذ سبيل الحوت من البحر { عجباً } أي تعجب منه ،   وإما أن يخبر عن الحوت أنه اتخذ سبيله { عجباً } للناس انتهى .  <br />
وقرأ حفص : { وما أنسانيه } بضم الهاء وفي الفتح عليه الله وذلك في الوصل وأمال الكسائي فتحة السين ،   وفي مصحف عبد الله وقراءته { أن أذكره } { إلاّ الشيطان } .  <br />
