الكسف القطع واحدها كسفة ،   تقول العرب : كسفت الثوب ونحوه قطعته ،   وما زعم الزجاج من أن كسف بمعنى غطى ليس بمعروف في دواوين اللغة .  <br />
وقرأ الجمهور : { تسقط } بتاء الخطاب مضارع أسقط السماء نصباً ،   ومجاهد بياء الغيبة مضارع سقط السماء رفعاً ،   وابن كثير وأبو عمرو وحمزة والكسائي { كسْفاً } بسكون السين وباقي السبعة بفتحها .  <br />
وقولهم { كما زعمت } إشارة إلى قوله تعالى { إن نشأ نخسف بهم الأرض أو نسقط عليهم كسفاً من السماء } وقيل : { كما زعمت } إن ربك إن شاء فعل .  <br />
وقيل : هو ما في هذه السورة من قوله { أفأمنتم أن يخسف بكم جانب البر أو يرسل عليكم حاصباً } قال أبو عليّ { قبيلاً } معاينة كقوله { لولا أنزل علينا الملائكة أو نرى ربنا } وقال غيره : { قبيلاً } كفيلاً من تقبله بكذا إذا كفله ،   والقبيل والزعيم والكفيل بمعنى واحد .  <br />
وقال الزمخشري : { قبيلاً } كفيلاً بما تقول شاهداً لصحته ،   والمعنى أو تأتي بالله { قبيلاً } والملائكة { قبيلاً } كقوله :<br />
كنت منه ووالدي بريا .   .   .  ***<br />
