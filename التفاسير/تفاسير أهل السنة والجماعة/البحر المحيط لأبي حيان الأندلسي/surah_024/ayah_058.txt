روي أن عمر بعث إليه رسول الله صلى الله عليه وسلم غلاماً من الأنصار يقال له مدلج ،   وكان نائماً فدق عليه الباب ودخل ،   فاستيقظ وجلس فانكشف منه شيء فقال عمر : وددت أن الله نهى أبناءنا ونساءنا عن الدخول علينا في هذه الساعات إلاّ بإذن .  <br />
ثم انطلق إلى الرسول فوجد هذه الآية قد نزلت فخرّ ساجداً .  <br />
وقيل : نزلت في أسماء بنت أبي مرثد قيل : دخل عليها غلام لها كبير في وقت كرهت دخوله ،   فأتت رسول الله صلى الله عليه وسلم فقالت : إن خدمنا وغلماننا يدخلون علينا حالاً نكرهها .  <br />
{ ليستأذنكم } أمر والظاهر حمله على الوجوب والجمهور على الندب .  <br />
وقيل : بنسخ ذلك إذ صار للبيوت أبواب روي ذلك عن ابن عباس وابن المسيب والظاهر عموم { الذين ملكت أيمانكم } في العبيد والإماء وهو قول الجمهور .  <br />
وقال ابن عمر وآخرون ،   العبيد دون الإماء .  <br />
وقال السلمي : الإماء دون العبيد .  <br />
{ والذين لم يبلغوا الحلم منكم } عام في الأطفال عبيد كانوا أو أحراراً .  <br />
وقرأ الحسن وأبو عمر وفي رواية وطلحة { الحلْم } بسكون اللام وهي لغة تميم .  <br />
وقيل { منكم } أي من الأحرار ذكوراً كانوا أو إناثاً .  <br />
والظاهر من قوله { ثلاث مرات } ثلاث استئذانات لأنك إذا ضربت ثلاث مرات لا يفهم منه إلاّ ثلاث ضربات ويؤيده قوله عليه الصلاة والسلام : « الاستئذان ثلاث  » والذي عليه الجمهور أن معنى { ثلاث مرات } ثلاث أوقات وجعلوا ما بعده من ذكر تلك الأوقات تفسيراً لقوله { ثلاث مرات } ولا يتعين ذلك بل تبقى { ثلاث مرات } على مدلولها .  <br />
{ من قبل صلاة الفجر } لأنه وقت القيام من المضاجع وطرح ما ينام فيه من الثياب ولبس ثياب اليقظة وقد ينكشف النائم .  <br />
{ وحين تضعون ثيابكم من الظهيرة } لأنه وقت وضع الثياب للقائلة لأن النهار إذ ذاك يشتد حره في ذلك الوقت .  <br />
و { من } في { من الظهيرة } قال أبو البقاء : لبيان الجنس أي حين ذلك هو الظهيرة ،   قال : أو بمعنى من أجل حر الظهيرة و { حين } معطوف على موضع { من قبل } { ومن بعد صلاة العشاء } لأنه وقت التجرد من ثياب اليقظة والالتحاف بثياب النوم { ثلاث عورات لكم } سمى كل واحد منها عورة لأن الناس يختل تسترهم وتحفظهم فيها ،   والعورة الخلل ومنه أعور الفارس وأعور المكان ،   والأعور المختل العين .  <br />
وقرأ حمزة والكسائي { ثلاث } بالنصب قالوا : بدل من { ثلاث عورات } وقدره الحوفي والزمخشري وأبو البقاء أوقات { ثلاث عورات } وقال ابن عطية : إنما يصح يعنى البدل بتقدير أوقات { عورات } فحذف المضاف وأقيم المضاف إليه مقامه .  <br />
وقرأ باقي السبعة بالرفع أي هن { ثلاث عورات } وقرأ الأعمش { عَوَرات } بفتح الواو وتقدم أنها لغة هذيل بن مدركة وبني تميم وعلى رفع { ثلاث } .  <br />
قال الزمخشري : يكون { ليس عليكم } الجملة في محل رفع على الوصف والمعنى هن { ثلاث عورات } مخصوصة بالاستئذان ،   وإذا نصبت لم يكن له محل وكان كلاماً مقرراً بالاستئذان في تلك الأحوال خاصة .  <br />
{ بعدهن } أي بعد استئذانهم فيهن حذف الفاعل وحرف الجر بفي بعد استئذانهن ثم حذف المصدر وقيل { ليس } على العبيد والإماء ومن لم يبلغ الحلم في الدخول { عليكم } بغير استئذان { جناح } بعد هذه الأوقات الثلاث { طوافون } يمضون ويجيؤون وهو خبر مبتدأ محذوف تقديره هم { طوافون } أي المماليك والصغار { طوافون عليكم } أي يدخلون عليكم في المنازل غدوة وعشية بغير إذن إلاّ في تلك الأوقات .  <br />
وجوّزوا في { بعضكم على بعض } أن يكون مبتدأ وخبراً لكن الجر قدروه طائف على بعض وهو كون مخصوص فلا يجوز حذفه .  <br />
قال الزمخشري : وحذف لأن طوافون يدل عليه وأن يكون مرفوعاً بفعل محذوف تقديره يطوف بعضكم .  <br />
وقال ابن عطية { بعضكم } بدل من قوله { طوافون } ولا يصح لأنه إن أراد بدلاً من { طوافون } نفسه فلا يجوز لأنه يصير التقدير هم { بعضكم على بعض } وهذا معنى لا يصح .  <br />
وإن جعلته بدلاً من الضمير في { طوافون } فلا يصح أيضاً إن قدر الضمير ضمير غيبة لتقدير المبتدأ هم لأنه يصير التقدير هم يطوف { بعضكم على بعض } وهو لا يصح .  <br />
فإن جعلت التقدير أنتم يطوف { عليكم بعضكم على بعض } فيدفعه أن قوله { عليكم } بدل على أنهم هم المطوف عليهم ،   وأنتم طوافون ،   يدل على أنهم طائفون فتعارضا .  <br />
وقرأ ابن أبي عبلة طوافين بالنصب على الحال من ضمير { عليهم } .  <br />
وقال الحسن : إذا بات الرجل خادمه معه فلا استئذان عليه ولا في هذه الأوقات الثلاثة .  <br />
