واللام في { ليجزيهم } متعلقة بمحذوف أي فعلوا ذلك { ليجزيهم } ويجوز أن تتعلق بيسبح وهو الظاهر .  <br />
وقال الزمخشري : والمعنى يسبحون ويخافون { ليجزيهم } انتهى .  <br />
والظاهر أن قوله { يخافون } صفة لرجال كما أن { لا تلهيهم } كذلك .  <br />
{ أحسن } هو على حذف مضاف أي ثواب أحسن ما عملوا ،   أو { أحسن } جزاء ما عملوا .  <br />
{ ويزيدهم من فضله } على ما تقتضيه أعمالهم ،   فأهل الجنة أبداً في مزيد .  <br />
وقال الزمخشري : { ليجزيهم } ثوابهم مضاعفاً { ويزيدهم } على الثواب تفضيلاً وكذلك معنى قوله { الحسنى } وزيادة المثوبة الحسنى ،   وزيادة عليها من التفضل وعطاء الله عز وجل إما تفضل وإما ثواب وإما عوض .  <br />
{ والله يرزق من يشاء } ما يتفضل به { بغير حساب } فأما الثواب فله حسنات لكونه على حسب الاستحقاق انتهى .  <br />
وفي قوله على حسب الاستحقاق دسيسة اعتزال .  <br />
