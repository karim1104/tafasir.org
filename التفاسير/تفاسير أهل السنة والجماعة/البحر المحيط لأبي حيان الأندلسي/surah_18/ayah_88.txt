ولما ذكر ما يستحقه { من آمن وعمل صالحاً } ذكر جزاء الله له في الآخرة وهو { الحسنى } أي الجنة لأن طمع المؤمن في الآخرة ورجاءه هو الذي حمله على أن آمن لأجل جزائه في الآخرة ،   وهو عظيم بالنسبة للإحسان في الدنيا ثم أتبع ذلك بإحسانه له في الدنيا بقوله { وسنقول له من أمرنا يسراً } أي لا نقول له ما يتكلفه مما هو شاق عليه أي قولاً ذا يسر وسهولة كما قال قولاً ميسوراً .  <br />
ولما ذكر ما أعد الله له من الحسنى جزاء لم يناسب أن يذكر جزاءه بالفعل بل اقتصر على القول أدباً مع الله تعالى وإن كان يعلم أنه يحسن إليه فعلاً وقولاً .  <br />
وقرأ حمزة والكسائي وحفص وأبو بحرية والأعمش وطلحة وابن مناذر ويعقوب وأبو عبيد وابن سعدان وابن عيسى الأصبهاني وابن جبير الأنطاكي ومحمد بن جرير { فله جزاء } بالنصب والتنوين وانتصب { جزاء } على أنه مصدر في موضع الحال أي مجازي كقولك في الدار قائماً زيد .  <br />
وقال أبو علي قال أبو الحسن : هذا لا تكاد العرب تكلم به مقدماً إلاّ في الشعر .  <br />
وقيل : انتصب على المصدر أي يجزي { جزاء } .  <br />
وقال الفراء : ومنصوب على التفسير والمراد بالحسنى على قراءة النصب الجنة .  <br />
وقرأ باقي السبعة { جزاء الحسنى } برفع { جزاء } مضافاً إلى { الحسنى } .  <br />
قال أبو عليّ جزاء الخلال الحسنة التي أتاها وعملها أو يراد بالحسنى الحسنة والجنة هي الجزاء ،   وأضاف كما قال دار الآخرة و { جزاء } مبتدأ وله خبره .  <br />
وقرأ عبد الله بن إسحاق { فله جزاء } مرفوع وهو مبتدأ وخبر و { الحسنى } بدل من { جزاء } .  <br />
وقرأ ابن عباس ومسروق { جزاء } نصب بغير تنوين { الحسنى } بالإضافة ،   ويخرج على حذف المبتدأ لدلالة المعنى عليه ،   أي { فله } الجزاء { جزاء الحسنى } وخرجه المهدوي على حذف التنوين لالتقاء الساكنين .  <br />
وقرأ أبو جعفر { يسراً } بضم السين حيث وقع .  <br />
