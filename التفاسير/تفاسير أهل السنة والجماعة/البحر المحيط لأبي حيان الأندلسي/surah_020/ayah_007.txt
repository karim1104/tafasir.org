ولما ذكر تعالى أولاً إنشاء السموات والأرض وذكر أن جميع ذلك وما فيهما ملكه ذكر تعالى صفة العلم وأن علمه لا يغيب عنه شيء والخطاب بقوله : { وإن تجهر بالقول } للرسول ظاهر أو المراد أمته ،   ولما كان خطاب الناس لا يتأتى إلاّ بالجهر بالكلام جاء الشرط بالجهر وعلق على الجهر علمه بالسر لأن علمه بالسر يتضمن علمه بالجهر ،   أي إذا كان يعلم السر فأحرى أن يعلم الجهر والسر مقابل للجهر كما قال { يعلم سركم وجهركم } والظاهر أن { أخفى } أفعل تفضيل أي { وأخفى } من السر .  <br />
قال ابن عباس : { السر } ما تسره إلى غيرك ،   والأخفى ما تخفيه في نفسك وقاله الفراء .  <br />
وعن ابن عباس أيضاً { السر } ما أسره في نفسه ،   والأخفى ما خفي عنه مما هو فاعله وهو لا يعلمه .  <br />
وعن قتادة : قريب من هذا .  <br />
وقال مجاهد : { السر } ما تخفيه من الناس { وأخفى } منه الوسوسة .  <br />
وقال ابن زيد { السر } سر الخلائق { وأخفى } منه سره تعالى وأنكر ذلك الطبري .  <br />
وقيل : { السر } العزيمة { وأخفى } منه ما لم يخطر على القلب ،   وذهب بعض السلف إلى أن قوله { وأخفى } هو فعل ماض لا أفعل تفضيل أي { يعلم } أسرار العباد { وأخفى } عنهم ما يعلمه هو كقوله { يعلم ما بين أيديهم وما خلفهم ولا يحيطون بشيء من علمه } وقوله { ولا يحيطون به علماً } قال ابن عطية : وهو ضعيف .  <br />
وقال الزمخشري : وليس بذلك قال : فإن قلت : كيف طابق الجزاء الشرط ؟ قلت : معناه إن تجهر بذكر الله من دعاء أو غيره فاعلم أنه غني عن جهرك فإما أن يكون نهياً عن الجهر كقوله { واذكر ربك في نفسك تضرعاً وخيفة ودون الجهر من القول } وإما تعليماً للعباد أن الجهر ليس لإسماع الله وإنما هو لغرض آخر انتهى .  <br />
