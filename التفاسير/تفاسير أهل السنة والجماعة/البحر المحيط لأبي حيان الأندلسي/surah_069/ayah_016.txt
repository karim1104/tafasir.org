{ وانشقت السماء } : أي انفطرت وتميز بعضها من بعض ،   { فهي يومئذ إذٍ } انشقت ،   { واهية } : ضعيفة لتشققها بعد أن كانت شديدة ،   { أأنتم أشد خلقاً أم السماء } أو منخرقة ،   كما يقال : وهي السقاء انخرق .  <br />
وقيل انشقاقها لنزول الملائكة ،   قال تعالى : { ويوم تشقق السماء بالغمام ونزل الملائكة تنزيلاً } وقيل : انشقاقها لهول يوم القيامة .  <br />
