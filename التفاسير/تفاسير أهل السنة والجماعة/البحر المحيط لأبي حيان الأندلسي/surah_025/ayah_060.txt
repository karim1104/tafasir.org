{ وإذا قيل لهم اسجدوا للرحمن } وكانت قريش لا تعرف هذا في أسماء الله غالطت قريش بذلك فقالت : إن محمداً يأمرنا بعبادة رحمن اليمامة نزلت { وإذا قيل لهم } و { ما } سؤال عن المجهول ،   فيجوز أن يكون سؤالاً عن المسمى به لأنهم ما كانوا يعرفونه بهذا الاسم ،   ويجوز أن يكون سؤالاً عن معناه لأنه لم يكن مستعملاً في كلامهم كما يستعمل الرحيم والرحوم والراحم ،   أو لأنهم أنكروا إطلاقه على الله قاله الزمخشري .  <br />
والذي يظهر أنهم لما قيل لهم { اسجدوا للرحمن } فذكرت الصفة المقتضية للمبالغة في الرحمة والكلمة عربية لا ينكر وضعها ،   أظهروا التجاهل بهذه الصفة التي لله مغالطة منهم ووقاحة فقالوا : { وما الرحمن } وهم عارفون به وبصفته الرحمانية ،   وهذا كما قال فروعون<br />
{ وما رب العالمين } حين قال له موسى : { إني رسول من رب العالمين } على سبيل المناكرة وهو عالم برب العالمين .  <br />
كما قال موسى { لقد علمت ما أنزل هؤلاء إلاّ رب السموات والأرض بصائر } فكذلك كفار قريش استفهموا عن { الرحمن } استفهام من يجهله وهم عالمون به ،   فعلى قول من قال : لم يكونوا يعرفون { الرحمن } إلاّ مسيلمة وعلى قول من قال : من لا يعرفون الرحمن إلاّ مسيلمة .  <br />
فالمعنى أنسجد لمسيلمة وعلى قول من قال : لا يعرفون { الرحمن } بالكلية فالمعنى { أنسجد لما تأمرنا } من غير علم ببيانه .  <br />
والقائل { اسجدوا } الرسول أو الله على لسان رسوله .  <br />
وقرأ ابن مسعود والأسود بن يزيد وحمزة والكسائي يأمر بالياء من تحت أي يأمرنا محمد ،   والكناية عنه أو المسمى { الرحمن } ولا نعرفه .  <br />
وقرأ باقي السبعة بالتاء خطاباً للرسول .  <br />
ومفعول { تأمرنا } الثاني محذوف لدلالة الكلام عليه تقديره يأمرنا سجوده نحو قولهم : أمرتك الخير .  <br />
{ وزادهم } أي هذا القول وهو الأمر بالسجود للرحمن { زادهم } ضلالاً يختص به مع ضلالهم السابق ،   وكان حقه أن يكون باعثاً على فعلي السجود والقبول .  <br />
وقال الضحاك : سجد أبو بكر وعمر وعثمان وعليّ وعثمان بن مظعون وعمرو ابن غلسة ،   فرآهم المشركون فأخذوا في ناحية المسجد يستهزئون ،   فهذا المراد بقوله { وزادهم نفوراً } ومعنى { نفوراً } فراراً .  <br />
