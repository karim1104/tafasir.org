وانتصب { وقوم نوح } على الاشتغال وكان النصب أرجح لتقدم الجمل الفعلية قبل ذلك ،   ويكون { لما } في هذا الإعراب ظرفاً على مذهب الفارسي .  <br />
وأما إن كانت حرف وجوب لوجوب فالظاهر أن { أغرقناهم } جواب لما فلا يفسر ناصباً لقوم فيكون معطوفاً على المفعول في { فدمرناهم } أو منصوباً على مضمر تقديره اذكر .  <br />
وقد جوز الوجوه الثلاثة الحوفي .  <br />
{ لما كذبوا الرسل } كذبوا نوحاً ومن قبله أو جعل تكذيبهم لنوح تكذيباً للجميع ،   أو لم يروا بعثه الرسل كالبراهمة والظاهر عطف { وعاداً } على و { قوم } .  <br />
