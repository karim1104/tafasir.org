{ إِنَّمَا كَانَ قَوْلَ الْمُؤْمِنِينَ إِذَا دُعُوا إِلَى اللَّهِ وَرَسُولِهِ لِيَحْكُمَ بَيْنَهُمْ أَنْ يَقُولُوا سَمِعْنَا وَأَطَعْنَا وَأُولَئِكَ هُمُ الْمُفْلِحُونَ }<br />
وقرأ عليّ وابن أبي إسحاق والحسن { إنما كان قول } بالرفع والجمهور بالنصب .  <br />
قال الزمخشري : والنصب أقوى لأن أولى الاسمين بكونه اسماً لكان أو غلهما في التعريف و { أن يقولوا } أو غل لأنه لا سبيل عليه للتنكير بخلاف قول المؤمنين .  <br />
وكان هذا من قبيل كان في قوله { ما كان لله أن يتخذ من ولد } { ما يكون لنا أن نتكلم بهذا } انتهى .  <br />
ونص سيبويه على أن اسم كان وخبرها إذا كانتا معرفتين فأنت بالخيار في جعل ما شئت منهما الاسم والآخر الخبر من غير اعتبار شرط في ذلك ولا اختيار .  <br />
وقرأ أبو جعفر والجحدري وخالد بن الياس { ليحكم بينهم } مبنياً للمفعول ،   والمفعول الذي لم يسم فاعله هو ضمير المصدر أي { ليحكم } هو أي الحكم ،   والمعنى ليفعل الحكم { بينهم } ومثله قولهم : جمع بينهما وألف بينهما وقوله تعالى { وحيل بينهم } قال الزمخشري : ومثله { لقد تقطع بينكم } فيمن قرأ { بينكم } منصوباً أي وقع التقطع بينكم انتهى .  <br />
ولا يتعين ما قاله في الآية إذ يجوز أن يكون الفاعل ضميراً يعود على شيء قبله وتقدم الكلام في ذلك في موضعه .  <br />
{ أن يقولوا سمعنا } أي قول الرسول { وأطعنا } أي أمره .  <br />
وقرىء { ويتقه } بالإشباع والاختلاس والإسكان .  <br />
وقرىء { ويتقه } بسكون القاف وكسر الهاء من غير إشباع أجرى خبر كان المنفصل مجرى المتصل ،   فكما يسكن علم فيقال علم كذلك سكن ويتقه لأنه تقه كعلم وكما قال السالم :<br />
قالت سليمى اشتر لنا سويقاً***<br />
