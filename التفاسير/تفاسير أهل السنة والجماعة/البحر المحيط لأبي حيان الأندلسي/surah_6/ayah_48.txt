{ وما نرسل المرسلين إلا مبشرين ومنذرين } أي { مبشرين } بالثواب { ومنذرين } بالعقاب وانتصب { مبشرين ومنذرين } على الحال وفيهما معنى العلية ،   أي أرسلناهم للتبشير والإنذار لا لأن تقترح عليهم الآيات بعد وضوح ما جاؤوا به وتبيين صحته .  <br />
{ فمن آمن وأصلح } أي من صدق بقلبه وأصلح في عمله .  <br />
