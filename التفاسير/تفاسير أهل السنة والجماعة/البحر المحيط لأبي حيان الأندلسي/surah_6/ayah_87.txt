{ ومن آبائهم وذرّياتهم وإخوانهم } المجرور في موضع نصب .  <br />
فقال الزمخشري : عطفاً على { كلاًّ } بمعنى وفضلنا بعض آبائهم ،   وقال ابن عطية : وهدينا { من آبائهم وذرياتهم وإخوانهم } جماعات فمن للتبعيض والمراد من آمن نبياً كان أو غير نبي ويدخل عيسى في ضمير قوله : { ومن آبائهم } ولهذا قال محمد بن كعب : الخال والخالة انتهى ،   { ومن آبائهم } كآدم وإدريس ونوح وهود وصالح { وذرياتهم } كذرية نوح عليه السلام المؤمنين { وإخوانهم } كإخوة يوسف ذكر الأصول والفروع والحواشي .  <br />
{ واجتبيناهم وهديناهم إلى صراط مستقيم } الظاهر عطف { واجتبيناهم } على { فضلنا } أي اصطفيناهم وكرر الهداية على سبيل التوضيح للهداية السابقة ،   وأنها هداية إلى طريق الحق المستقيم القويم الذي لا عوج فيه وهو توحيد الله تعالى وتنزيهه عن الشرك .  <br />
