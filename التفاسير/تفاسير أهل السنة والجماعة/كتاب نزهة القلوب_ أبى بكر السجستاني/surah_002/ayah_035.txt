{ قُلْنَا لِلْمَلَٰئِكَةِ }: مذهب العرب إذا أخبر الرئيس منها عن نفسه قال: فعلنا وصنعنا لعلمه أن أتباعه يفعلون بأمره كفعله ويجرون على مثل أمره، ثم كثر الإستعمال حتى صار الرجل من السُّوَق يقول: فعلنا وصنعنا. والأصل ما ذكرت { إِبْلِيسَ }: إفعيل من أبلس؛ أي بئس. ويقال هو اسم أعجمي فلذلك لا ينصرف { رَغَداً }: كثيرا واسعا بلا عناء.  { أَزَلَّهُمَا ٱلشَّيْطَٰنُ } أي استزلهما؛ يقال أزللته فزل؛ وأزالهما نحاهما؛ يقال أزلته فزال.  { مَتَٰعٌ إِلَىٰ حِينٍ } أي سعة إلى أجل.  { حِينٍ } أي غاية ووقت وزمان غير محدود، وقد يجيء محدودا.  { تَلَقَّىٰ ءَادَمُ مِن رَّبِّهِ كَلِمَٰتٍ }: أي قبل وأخذ (تواب): أي الله يتوب على العباد؛ والتواب من الناس التائب.  { ٱهْبِطُواْ مِنْهَا } الهبوط: الانحطاط من علو إلى أسفل بالضم والكسر جميعا.
