(إذا) وقت مستقبل. { يَشْعُرُونَ } يفطنون. { مُسْتَهْزِءُونَ } أي ساخرون. وقوله: { ٱللَّهُ يَسْتَهْزِئُ بِهِمْ } أي يجازيهم جزاء استهزائهم { طُغْيَانِهِمْ يَعْمَهُونَ } يقول: في غيهم وكفرهم يحارون ويترددون. ويعمهون في اللغة: يركبون رءوسهم متحيرين حائرين عن الطريق؛ يقال: رجل عمه وعامه: أي متحير وحائر عن الطريق.
