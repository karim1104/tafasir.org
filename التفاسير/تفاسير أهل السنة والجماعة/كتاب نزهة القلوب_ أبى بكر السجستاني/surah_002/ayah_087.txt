{ قَفَّيْنَا } أي أتبعنا، وأصله من القفا، يقال: قفوت الرجل إذا سرت في أثره { أَيَّدْنَاهُ } قويناه { تَهْوَىٰ أَنْفُسُكُمْ }: أي تميل، ومنه قوله: [الجاثية: 23] أي ما تميل إليه نفسه، وكذلك الهوى في المحبة، وهو ميل النفس إلى ما تحبه.  { غُلْفٌ } جمع أغلف، وهو كل شيء جعلته في غلاف: أي قلوبنا محجوبة عما تقول كأنها في غلف. ومن قرأ غلف بضم اللام أراد جمع غلاف، وتسكين اللام فيها جائز أيضا مثل كتب وكتب: أي أوعية للعلم فكيف تجيئنا بما ليس عندنا { لَّعَنَهُمُ ٱللَّهُ } أي طردهم وأبعدهم { يَسْتَفْتِحُونَ } أي يستنصرون.
