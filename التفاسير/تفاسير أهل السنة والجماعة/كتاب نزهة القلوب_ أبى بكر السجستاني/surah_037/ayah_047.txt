{ غَوْلٌ } مذهب الشيء، يقال: الغضب غول للحلم، والحرب غول للنفوس ومنه { لاَ فِيهَا غَوْلٌ } أي لا تغتال عقولهم فتذهب بها { قَاصِرَاتُ ٱلطَّرْفِ } أي قصرن أبصارهن على أزواجهن، أي حسن أبصارهن عليهم ولم يطمحن إلى غيرهم.  { يُنزَفُونَ } وينزفون، يقال: نزف الرجل إذا ذهب عقله، ويقال للسكران: نزيف ومنزوف، وأنزف الرجل إذا ذهب شرابه وإذا ذهب عقله أيضا، وأنشد: { عِينٌ } أي واسعات الأعين، الواحدة عيناء.
