{ إِنَّمَا ٱلصَّدَقَاتُ لِلْفُقَرَآءِ وَٱلْمَسَاكِينِ }: الفقراء: الذين لهم بلغة، والمساكين: الذين لا شيء لهم { وَٱلْعَامِلِينَ عَلَيْهَا } العمال على الصدقة { وَٱلْمُؤَلَّفَةِ قُلُوبُهُمْ } الذين كان النبي صلى الله عليه وسلم يتألفهم على الإسلام. { وَفِي ٱلرِّقَابِ } أي فك الرقاب: يعني المكاتبين. { وَٱلْغَارِمِينَ } الذين عليهم الدين ولا يجدون القضاء. { وَفِي سَبِيلِ ٱللَّهِ } أي فيما لله فيه طاعة. { وَٱبْنِ ٱلسَّبِيلِ } الضيف، والمنقطع به وأشباه ذلك.
