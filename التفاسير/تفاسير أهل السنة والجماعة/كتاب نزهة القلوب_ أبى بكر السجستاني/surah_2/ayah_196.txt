(تهلكة) أي هلاك. { أُحْصِرْتُمْ } أي منعتم من السير لمرض أو عدو أو سائر العوائق. { ٱسْتَيْسَرَ } أي تيسر وسهل. (هدى وهديّ): ما أهدي إلى البيت الحرام؛ واحدتها هدْية وهِدية، قال أبو محمد: يقال لما يهدى إلى البيت هدى وهَدِي، وواحد هدْى هدْية؛ وواحد هدى هَدِية: { نُسُكٍ } أي ذبائح، واحدتها نسيكة { مَحِلَّهُ } أي منحره، يعني الموضع الذي يحل نحره فيه.
