{ ذَلِكَ } أي ما تقدم من الأخذ { بِأَنَّهُمْ } أي بسبب أنهم { كَانَتْ تَأْتِيهِمْ رُسُلُهُمْ بِالْبَيِّنَاتِ } أي بالحجج الواضحة والمعجزات الظاهرة { فَكَفَرُوا } بما جاؤوهم به { فَأَخَذَهُمُ اللَّهُ إِنَّهُ قَوِيٌّ } يفعل كل ما يريده لا يعجزه شيء { شَدِيدُ الْعِقَابِ } لمن عصاه ولم يرجع إليه ، <br />
