{ قَالَ أَبَشَّرْتُمُونِي عَلَى أَن مَّسَّنِيَ الْكِبَرُ فَبِمَ تُبَشِّرُونَ ( 54 ) }<br />
{ قَالَ أَبَشَّرْتُمُونِي } قرئ بألف الاستفهام وبغيرها { عَلَى أَن مَّسَّنِيَ الْكِبَرُ } أي مع حالة الكبر والهرم { فَبِمَ تُبَشِّرُونَ } استفهام إنكار أو تعجب كأنه عجب من حصول الولد له مع ما قد صار إليه من الهرم الذي جرت العادة بأنه لا يولد لمن بلغ إليه ،  والمعنى فبأي شيء تبشرون ،  فإن البشارة بما لا يكون عادة لا تصح
