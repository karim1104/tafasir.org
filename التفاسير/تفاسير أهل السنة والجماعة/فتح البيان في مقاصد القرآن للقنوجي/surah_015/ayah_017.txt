{ وَحَفِظْنَاهَا مِن كُلِّ شَيْطَانٍ رَّجِيمٍ ( 17 ) }<br />
{ وَحَفِظْنَاهَا } أي السماء بالشهب { مِن } دخول { كُلِّ شَيْطَانٍ رَّجِيمٍ } قال أبو عبيدة الرجيم المرجوم بالنجوم كما في قوله : { رجوما للشياطين } والرجم في اللغة هو الرمي بالحجارة ،  ثم قيل للعن والطرد والإبعاد رجم ،  لأن الرمي بالحجارة يوجب هذه المعاني وقال قتادة : الرجيم الملعون .
