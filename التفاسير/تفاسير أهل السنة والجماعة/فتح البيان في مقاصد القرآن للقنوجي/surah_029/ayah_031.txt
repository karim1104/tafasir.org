{ وَلَمَّا جَاءتْ رُسُلُنَا إِبْرَاهِيمَ بِالْبُشْرَى قَالُوا إِنَّا مُهْلِكُو أَهْلِ هَذِهِ الْقَرْيَةِ إِنَّ أَهْلَهَا كَانُوا ظَالِمِينَ ( 31 ) قَالَ إِنَّ فِيهَا لُوطًا قَالُوا نَحْنُ أَعْلَمُ بِمَن فِيهَا لَنُنَجِّيَنَّهُ وَأَهْلَهُ إِلَّا امْرَأَتَهُ كَانَتْ مِنَ الْغَابِرِينَ ( 32 ) وَلَمَّا أَن جَاءتْ رُسُلُنَا لُوطًا سِيءَ بِهِمْ وَضَاقَ بِهِمْ ذَرْعًا وَقَالُوا لَا تَخَفْ وَلَا تَحْزَنْ إِنَّا مُنَجُّوكَ وَأَهْلَكَ إِلَّا امْرَأَتَكَ كَانَتْ مِنَ الْغَابِرِينَ ( 33 ) إِنَّا مُنزِلُونَ عَلَى أَهْلِ هَذِهِ الْقَرْيَةِ رِجْزًا مِّنَ السَّمَاء بِمَا كَانُوا يَفْسُقُونَ ( 34 ) }<br />
{ ولما جاءت رسلنا إبراهيم بالبشرى } أي : بالبشارة بالولد وهو إسحق وبولد الولد وهو يعقوب { قالوا } لإبراهيم : { إنا مهلكو أهل هذه القرية } وهي سدوم التي كان فيها قوم لوط قيل : كانت على مسيرة يوم وليلة من موضع إبراهيم عليه السلام { إن أهلها كانوا ظالمين } تعليل للإهلاك أي : إهلاكنا لهم بهذا السبب .
