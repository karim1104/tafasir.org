{ وقالوا ما في بطون هذه الأنعام خالصة لذكورنا ومحرم على أزواجنا وإن يكن ميتة فهم فيه شركاء سيجزيهم وصفهم إنه حكيم عليم 139 قد خسر الذين قتلوا أولادهم سفها بغير علم وحرموا ما رزقهم الله افتراء على الله قد ضلوا وما كانوا مهتدين 140 } . <br />
ثم بين سبحانه نوعا آخر من جهالاتهم فقال : { وقالوا ما في بطون هذه الأنعام } يعنون أجنة البحائر والسوائب وقيل هو اللبن { خالصة لذكورنا } أي حلال لهم ،  والهاء في خالصة للمبالغة في الخلوص كعلامة ونسابة ،  قاله الكسائي والأخفش ،  وقال الفراء : تأنيثها لتأنيث الأنعام ورد بأن الأجنة ،  ( وما ) عبارة عنها فيكون تأنيث خالصة باعتبار المعنى . <br />
{ ومحرم على } جنس { أزواجنا } وهي النساء فيدخل في ذلك البنات والأخوات ونحوهن وتذكير محرم باعتبار لفظ ما { وإن يكن } أي الذي في بطون الأنعام { ميتة فهم فيه } أي في الذي في البطون { شركاء } يأكل منه الذكور والإناث { سيجزيهم } الله { وصفهم } أي بوصفهم الكذب على الله ،  وقيل المعنى سيجزيهم جزاء وصفهم { إنه حكيم عليم } فلأجل حكمته وعلمه لا يترك جزاءهم الذي هو من مقتضيات الحكمة .
