{ وَقِيلَ لَهُمْ } على سبيل التوبيخ { أَيْنَمَا } أي في أيّ مكان { كُنتُمْ تَعْبُدُونَ مِن دُونِ اللَّهِ } من الأصنام والأنداد وهذا سؤال تبكيت لا يتوقع له جواب . <br />
{ هَلْ يَنصُرُونَكُمْ ؟ } فيدفعون عنكم العذاب { أَوْ يَنتَصِرُونَ } بدفعه عن أنفسهم ،  وهذا كله توبيخ وتقريع لهم . <br />
