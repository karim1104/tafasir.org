{ مَنْ عَمِلَ سَيِّئَةً } من كلام الرجل المؤمن ،  والمعنى من عمل في دار الدنيا معصية من المعاصي كائنة ما كانت { فَلَا يُجْزَى إِلَّا مِثْلَهَا } ولا يعذب إلا بقدرها والظاهر شمول الآية لكل ما يطلق عليه اسم السيئة ،  وقيل : هي خاصة بالشرك ،  ولا وجه لذلك . <br />
{ وَمَنْ عَمِلَ } عملا { صَالِحًا } قيل : هو لا إله إلى الله { مِنْ ذَكَرٍ أَوْ أُنْثَى وَهُوَ مُؤْمِنٌ } أي مع كونه مؤمنا بما جاءت به رسله { فَأُولَئِكَ } الذين جمعوا بين الإيمان والعمل الصالح { يَدْخُلُونَ الْجَنَّةَ } بفتح الياء وضم الخاء .  وبالعكس سبعيتان { يُرْزَقُونَ فِيهَا } رزقا واسعا { بِغَيْرِ حِسَابٍ } أي بغير تقدير ومحاسبة قال مقاتل : يقول لا تبعة عليهم فيما يعطون في الجنة من الخير ثم كرر ذلك الرجل المؤمن دعاءهم إلى الله . <br />
