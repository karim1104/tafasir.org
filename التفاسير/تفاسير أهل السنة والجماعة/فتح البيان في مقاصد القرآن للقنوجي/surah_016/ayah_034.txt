{ فَأَصَابَهُمْ سَيِّئَاتُ مَا عَمِلُواْ وَحَاقَ بِهِم مَّا كَانُواْ بِهِ يَسْتَهْزِؤُونَ ( 34 ) } . <br />
{ فَأَصَابَهُمْ سَيِّئَاتُ مَا عَمِلُواْ } أي أجزية أعمالهم السيئة أو جزاء سيئات أعمالهم معطوف على فعل الذين من قبلهم وما بينهم اعتراض { وَحَاقَ } أي نزل { بِهِم } على وجه الإحاطة والحيق لا يستعمل إلا في الشر ،  قاله البيضاوي فلا يقال حاقت به النعمة بل النقمة . <br />
قاله الشهاب { مَّا } أي العذاب الذي { كَانُواْ بِهِ يَسْتَهْزِؤُونَ } أو عقاب استهزائهم .
