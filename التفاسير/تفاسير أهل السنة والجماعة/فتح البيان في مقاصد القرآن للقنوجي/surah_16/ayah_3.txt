{ خَلَقَ السَّمَاوَاتِ وَالأَرْضَ بِالْحَقِّ تَعَالَى عَمَّا يُشْرِكُونَ ( 3 ) }<br />
ثم إنه سبحانه لما أرشدهم إلى توحيده ذكر دلائل التوحيد فقال : { خَلَقَ السَّمَوَاتِ وَالأَرْضَ } أي أوجدهما على هذه الصفة التي هما عليها { بِالْحَقِّ } أي للدلالة على قدرته ووحدانيته ،  وقيل المراد بالحق هنا الفناء والزوال { تَعَالَى } الله { عَمَّا يُشْرِكُونَ } أي تقدس وترفع عن إشراكهم أو عن شريكه الذي يجعلونه شريكا له ،  وقيل عما يشركونه من الأصنام أو منها أي السموات والأرض .
