{ لِيُبَيِّنَ لَهُمُ الَّذِي يَخْتَلِفُونَ فِيهِ وَلِيَعْلَمَ الَّذِينَ كَفَرُواْ أَنَّهُمْ كَانُواْ كَاذِبِينَ ( 39 ) }<br />
{ لِيُبَيِّنَ } أي ليظهر { لَهُمُ } وهو غاية لما دل عليه بلى من البعث والضمير في لهم راجع إلى من يموت { الَّذِي يَخْتَلِفُونَ فِيهِ } أي الأمر الذي وقع الخلاف بينهم فيه وبيانه إذ ذاك يكون بما جاءتهم به الرسل ونزلت عليهم فيه كتب الله ،  وقيل ليبين متعلق بقوله ولقد بعثنا { وَلِيَعْلَمَ الَّذِينَ كَفَرُواْ } بالله سبحانه وأنكروا البعث { أَنَّهُمْ كَانُواْ كَاذِبِينَ } في جدالهم وإنكارهم البعث بقولهم لا يبعث الله من يموت .
