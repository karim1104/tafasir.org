{ أَمْ أَمِنتُمْ أَن يُعِيدَكُمْ فِيهِ تَارَةً أُخْرَى فَيُرْسِلَ عَلَيْكُمْ قَاصِفا مِّنَ الرِّيحِ فَيُغْرِقَكُم بِمَا كَفَرْتُمْ ثُمَّ لاَ تَجِدُواْ لَكُمْ عَلَيْنَا بِهِ تَبِيعًا ( 69 ) } . <br />
{ أَمْ } متصلة أي أي الأمرين كائن أو منقطعة أي بل { أَمِنتُمْ أَن يُعِيدَكُمْ فِيهِ } أي في البحر بأن يقوي دواعيكم ويوفر حوائجكم إلى ركوبه وجاء بفي ولم يقل إلى البحر للدلالة على استقرارهم فيه { تَارَةً } أي مرة { أُخْرَى } وهو مصدر ويجمع على تيرة وتارات وألفها واو أو ياء . <br />
{ فَيُرْسِلَ عَلَيْكُمْ قَاصِفا مِّنَ الرِّيحِ } القاصف الريح الشديدة التي تكسر بشدة من قصف الشيء يقصفه من باب ضرب أي كسره بشدة والقصف الكسر أو هو الريح التي لها قصف أي صوت شديد من قولهم رعد قاصف أي شديد الصوت ،  وقال ابن عباس : الريح التي تغرق ؛ وقال ابن عمرو : القاصف والعاصف في البحر . <br />
{ فَيُغْرِقَكُم } وقرئ بالفوقية على أن فاعله الريح { بِمَا كَفَرْتُمْ } أي بسبب كفركم أو بالسبب الذي كفرتم به وما مصدرية أو بمعنى الذي { ثُمَّ لاَ تَجِدُواْ لَكُمْ عَلَيْنَا بِهِ تَبِيعًا } أي نصيرا قاله ابن عباس أو ثائرا يطالبنا بما فعلنا انتصارا لكم قال الزجاج : لا تجدوا من يتبعنا بإنكار ما نزل بكم قال النحاس : وهو من الثأر وكذا يقال لكل من طلب بثأر أو غيره تبيع وتابع .
