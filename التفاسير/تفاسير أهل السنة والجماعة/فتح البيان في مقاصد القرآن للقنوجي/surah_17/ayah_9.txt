{ إِنَّ هَذَا الْقُرْآنَ يِهْدِي لِلَّتِي هِيَ أَقْوَمُ وَيُبَشِّرُ الْمُؤْمِنِينَ الَّذِينَ يَعْمَلُونَ الصَّالِحَاتِ أَنَّ لَهُمْ أَجْرًا كَبِيرًا ( 9 ) }<br />
{ إِنَّ هَذَا الْقُرْآنَ يِهْدِي } الناس { لِلَّتِي } أي للطريقة التي { هِيَ أَقْوَمُ } وأصوب من غيرها من الطرق وهي ملة الإسلام .  وقال الزجاج : للحال التي هي أقوم الحالات ،  وهي توحيد الله والإيمان برسله ،  وكذا قال الفراء ،  وقيل للكلمة التي هي أعدل وهي شهادة أن لا إله إلا الله ،  فبعضهم يصل بهدايته وهم المؤمنون وبعضهم لا يصل وهم الكافرون . <br />
{ وَيُبَشِّرُ الْمُؤْمِنِينَ } بما اشتمل عليه من الوعيد بالخير آجلا وعاجلا { الَّذِينَ يَعْمَلُونَ الصَّالِحَاتِ } التي أرشد إلى عملها القرآن { أَنَّ لَهُمْ } أي بأن لهم { أَجْرًا كَبِيرًا } وهو الجنة
