{ إنا نحن نرث الأرض ومن عليها وإلينا يرجعون ( 40 ) واذكر في الكتاب إبراهيم إنه كان صديقا نبيا ( 41 ) إذ قال لأبيه يا أبت لم تعبد ما لا يسمع ولا يبصر ولا يغني عنك شيئا ( 42 ) يا أبت إني قد جاءني من العلم ما لم يأتيك فاتبعني أهدك صراطا سويا ( 43 ) يا أبت لا تعبد الشيطان إن الشيطان كان للرحمان عصيا ( 44 ) يا أبت إني أخاف أن يمسك عذاب من الرحمان فتكون للشيطان وليا ( 45 ) قال أراغب أنت عن آلهتي يا إبراهيم لئن لم تنته لأرجمنك واهجرني مليا ( 46 ) قال سلام عليك سأستغفر لك ربي إنه كان بي حفيا ( 47 ) } . <br />
{ إنا نحن } تأكيد للضمير في إنا لأنه بمعناه { نرث الأرض } أي نميت سكانها فلا يبقى بها أحد يرث الأموات ،  فكأنه سبحانه ورث الأرض { ومن عليها } حيث أماتهم جميعا { وإلينا يرجعون } أي يردون إلينا يوم القيامة فنجازي كلا بعمله ،  وقد تقدم مثل هذا في سورة الحجر .
