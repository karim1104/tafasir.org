{ إن الذين كفروا وظلموا لم يكن الله ليغفر لهم ولا ليهديهم طريقا ( 168 ) إلا طريق جهنم خالدين فيها أبدا وكان ذلك على الله يسيرا ( 169 ) يا أيها الناس قد جاءكم الرسول بالحق من ربكم فآمنوا خيرا لكم وإن تكفروا فإن لله ما في السماوات والأرض وكان الله عليما حكيما ( 170 ) } . <br />
{ إن الذين كفروا } بجحدهم { وظلموا } غيرهم بصدهم عن السبيل أو ظلموا محمدا : كتمانهم نبوته أو ظلموا أنفسهم بكفرهم ،  ويجوز الحمل على جميع هذه المعاني { لم يكن الله ليغفر لهم } إذا استمروا على كفرهم وماتوا كافرين { ولا ليهديهم طريقا } من الطرق
