فلما قالت لهم ذلك( قالوا ) مجيبين لها :<br />
{ نحن أولوا قوة } في العدد والعدة { وأولو بأس شديد } عند الحرب واللقاء ؛ ولنا منة الشجاعة والنجدة ما نمنع به أنفسنا ؛ وبلدنا ،  ومملكتنا ،  يعني أشاروا عليها بالقتال ،  ثم فوضوا الأمر إليها لعلمهم بصحة رأيها ،  وقوة عقلها فقالوا :<br />
{ والأمر } موكل { إليك } أي إلى رأيك ونظرك { فانظري } أي : تأملي { ماذا تأمرين } إيانا به ،  فنحن سامعون لأمرك مطيعون له . <br />
