{ وَإِذْ قَالَ رَبُّكَ لِلْمَلاَئِكَةِ إِنِّي خَالِقٌ بَشَرًا مِّن صَلْصَالٍ مِّنْ حَمَإٍ مَّسْنُونٍ ( 28 ) }<br />
{ وَ } اذكر { إِذْ قَالَ رَبُّكَ لِلْمَلاَئِكَةِ } بين سبحانه بعد ذكره لخلق الإنسان ما وقع له عند خلقه ،  وقد تقدم تفسير ذلك في البقرة { إِنِّي خَالِقٌ بَشَرًا } مأخوذ من البشرة وهي ظاهر الجلد { مِّن صَلْصَالٍ } قد تقدم تفسيره قريبا مستوفى
