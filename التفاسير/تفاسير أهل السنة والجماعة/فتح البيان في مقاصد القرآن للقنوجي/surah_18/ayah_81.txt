{ فَأَرَدْنَا أَن يُبْدِلَهُمَا رَبُّهُمَا خَيْرًا مِّنْهُ زَكَاةً وَأَقْرَبَ رُحْمًا ( 81 ) وَأَمَّا الْجِدَارُ فَكَانَ لِغُلَامَيْنِ يَتِيمَيْنِ فِي الْمَدِينَةِ وَكَانَ تَحْتَهُ كَنزٌ لَّهُمَا وَكَانَ أَبُوهُمَا صَالِحًا فَأَرَادَ رَبُّكَ أَنْ يَبْلُغَا أَشُدَّهُمَا وَيَسْتَخْرِجَا كَنزَهُمَا رَحْمَةً مِّن رَّبِّكَ وَمَا فَعَلْتُهُ عَنْ أَمْرِي ذَلِكَ تَأْوِيلُ مَا لَمْ تَسْطِع عَّلَيْهِ صَبْرًا ( 82 ) وَيَسْأَلُونَكَ عَن ذِي الْقَرْنَيْنِ قُلْ سَأَتْلُو عَلَيْكُم مِّنْهُ ذِكْرًا ( 83 ) } . <br />
{ فأردنا أن يبدلهما } الإبدال رفع الشيء ووضع آخر مكانه ،  قال الزجاج : معنى فأردنا فأراد الله ومثله في القرآن ،  وقيل المعنى أردنا أن يرزقهما الله { ربهما } بدل هذا الولد ولدا { خيرا منه } والتفضيل ليس على بابه { زكاة } أي دينا وصلاحا وتقوى وطهارة من الذنوب { وأقرب رحما } بسكون الحاء وقرئ بضمها الرحمة يقال رحمه الله رحمة ورحما والألف للتأنيث قال ابن عباس : رحما مودة فأبدلا جارية ولدت نبيا .
