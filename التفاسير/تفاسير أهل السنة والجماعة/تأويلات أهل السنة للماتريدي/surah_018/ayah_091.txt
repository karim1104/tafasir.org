الآية 91 :  وقوله تعالى :  {  كذلك وقد أحطنا بما لديه خبرا } اختلف في قوله :  {  كذلك } قال بعضهم :  قوله :  {  كذلك } أي كذلك أخبرنا رسول الله من نبإ ذي القرنين وخبره على ما كان .   وقال بعضهم :  {  كذلك } أعطينا له من السبب حتى بلغ مطلع الشمس كما بلغ مغربها بالسبب الذي ذكر .   وقال بعضهم :  {  كذلك } قيل له في المطلع من قوله :  {  إما أن تعذب وإما أن تتخذ فيهم حسنا } ( الكهف : 86 ) كما قيل له في المغرب ،   والله أعلم .  <br />
وقوله تعالى :  {  وقد أحطنا بما لديه خبرا } قال بعضهم :  ( هو ){[11820]} صلة قوله :  {  قل سأتلوا عليكم منه ذكرا } ( الكهف : 83 ) {  وقد أحطنا بما لديه خبرا } أي عن علم سأتلوا عليكم :  وقال بعضهم :  هو على الابتداء ليس على الربط والصلة على الأول ؛  أي قد أحطنا علما{[11821]} بما لديه .
