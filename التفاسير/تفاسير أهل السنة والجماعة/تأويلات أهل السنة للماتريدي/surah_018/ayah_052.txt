الآية52 :  وقوله تعالى :  {  ويوم يقول{[11675]} نادوا شركائي الذين زعمتم } قال : {  شركائي } على زعمهم ،   وإلا لم يكن الله شركاء .   {  فدعوهم } يعني دعوا الأصنام التي عبدوها {  فلم يستجيبوا لهم } .  <br />
قال أبو بكر الأصم :  لم يجيبوهم في وقت ،   وقد أجابوهم في وقت آخر ،   وهو ما قالوا :  {  إن كنا عن عبادتكم لغافلين } ( يونس : 29 ) ولكن قوله :  {  فلن يستجيبوا لهم } لما كانوا يعبدونها في الدنيا ،   وإنما كانوا يعبدونها طمعا أن يكونوا شفعاء وأنصارا كقولهم :  {  هؤلاء شفعاؤنا عند الله } ( يونس : 18 ) وكقولهم{[11676]} :  {  ما نعبدهم إلا ليقربونا إلى الله زلفى } وكقوله :  {  واتخذوا من دون الله آلهة ليكونوا لهم عزا } {  كلا } ( مريم : 81و82 ) فيكون قوله {  فلم يستجيبوا لهم } ما طمعوا بعبادتهم الأصنام من الشفاعة والنصرة ودفع ما حل بهم عنهم والمنع عن عذاب الله ،   والله أعلم .  <br />
وقوله تعالى :  {  وجعلنا بينهم موبقا } أي بين أولئك وبين الأصنام موبقا .   قال بعضهم :  مهلكا .   وقال بعضهم :  الموبق الذي يفرق بينهم وبين آلهتهم في جهنم .   وقال بعضهم :  نهر فيها .  <br />
وقال بعضهم :  جعلنا وصلهم في الدنيا الذي كان بين المشركين وبين الأصنام موبقا أي مهلكا .
