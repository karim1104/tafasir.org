الآية 7 وقوله تعالى :  {  وإذا تتلى عليه آياتنا ولي مستكبرا } أي أعرض متعظما متجبرا {  كأن لم يسمعها كأن في أذنيه وقرا } ويحتمل قوله :  {  كأن لم يسمعها كأن في أذنيه وقرا } على التقريب( {[16160]} ) ،   فهو على ترك الاستماع .  <br />
وإن كان على حقيقة النفي فقد ذكر في كثير من الآي ذلك كقوله( {[16161]} ) :  {  صم بكم عمي } [ البقرة :  18و .   .   ] وذلك يحتمل الوجهين( {[16162]} ) ،   والله أعلم .  <br />
ثم أوعده العذاب الشديد حين( {[16163]} ) قال :  {  فبشره بعذاب أليم } .
