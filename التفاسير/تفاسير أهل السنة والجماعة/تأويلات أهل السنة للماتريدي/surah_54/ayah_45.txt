الآيتان 45 و46 ثم قوله{[20215]} على الابتداء {  سيُهزَم الجمع ويُوَلّون الدُّبُر } {  بل الساعة موعدهم والساعة أدهى وأَمَرّ } فيه [ أدلّة : <br />
أحدها ]{[20216]} :  أخبر أن لهم جميعا يُهزَم {  ويُوَلّون الدُّبر } ما ذكر ،   وقد كان .   [ وقال ]{[20217]} أهل التأويل :  {  سيُهزم الجمع ويولّون الدُّبر } هو جمع أهل بدر ،   أخبر أنهم يُهزَمون {  ويولّون الدّبر } وقد كان ما أخبر رسول الله صلى الله عليه وسلم دلّ أنه علم بالله تعالى .  <br />
والثاني :  أخبر أن الساعة موعد إهلاكهم واستئصالهم لا الدنيا بقوله :  {  والساعة أدهى وأَمَرّ } وكان كما أخبر .  <br />
[ والثالث :  ]{[20218]} دلالة إثبات الرسالة ،   والله أعلم .  <br />
وقوله تعالى :  {  أدهى وأَمَرّ } أي أعظم وأشدّ .
