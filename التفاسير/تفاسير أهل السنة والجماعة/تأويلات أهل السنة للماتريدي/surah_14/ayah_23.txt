الآية 23 :  وقوله تعالى :  {  وأُدخل الذين آمنوا وعملوا الصالحات جنات تجري من تحتها الأنهار } أي آذن لهم بالدخول في الجنة .  <br />
وقوله تعالى :  {  خالدين فيها بإذن ربهم } الإذن ههنا كأنه الرحمة ،   أي خالدين فيها برحمة ربهم {  تحياتهم فيها سلام } يحتمل السلام الثناء ،   أي يُثنون على ربهم كقوله :  {  الحمد لله الذي أذهب عنا الحزن } الآية :  [ فاطر :  34 ] .  <br />
وقوله تعالى :  {  تحياتهم فيها سلام } قال بعضهم :  [ يسلم بعضهم ]{[9580]}على عض ،   ويحيي بعضهم بعضا بالسلام .  <br />
[ وقال بعضهم :  السلام ]{[9581]} هو اسم كل خير ويمن وبركة كما قال :  {  لا يسمعون فيها لغوا ولا سلاما } [ مريم :  62 ] والله أعلم .
