الآية 8 وقوله تعالى :  {  فأهلكنا أشد منهم بطشا ومضى مثل الأولين } فيه تحذير أولئك الكفرة أن يُنزل بهم بتكذيبهم الرسول وسوء معاملتهم إياه كما أنزل{[18869]} بأولئك المتقدّمين بتكذيب الرسل وسوء معاملتهم إياه ،   والله أعلم .  <br />
وقوله تعالى :  {  فأهلكنا أشد منهم بطشا } يحتمل وجهين : <br />
أحدهما :  أي أهلكنا من كان أشد قوة وبطشا من هؤلاء ،   ثم لم يتهيأ لهم الامتناع [ مع شدة ]{[18870]} قوتهم وبطشهم عما نزل بهم من العذاب .   فعلى ذلك لو نزل بهؤلاء لم يتهيأ لهم الامتناع مع ضعفهم .  <br />
والثاني أن يكون قوله :  {  أشد منهم بطشا } وصف ذلك العذاب الذي نزل بهم أي ذلك العذاب {  أشد منهم بطشا } وهو كقوله :  {  إن عذابي لشديد } [ إبراهيم :  7 ] والله أعلم .  <br />
وقوله تعالى :  {  ومضى مثل الأولين } هذا يُخرّج على وجهين : <br />
أحدهما :  {  ومضى مثل الأولين } أي صار عذاب الأولين عبرة وعظة ومثلا للمتأخّرين كقوله :  {  فجعلناها نكالا لما بين يديها وما خلفها وموعظة للمتقين } [ البقرة :  66 ] .  <br />
والثاني :  {  ومضى مثل الأولين } أي مضى عذاب الأولين ،   وهو عذاب الاستئصال ،   فلا يعذّب هذه الأمة بمثل عذابهم لفضيلة نبينا محمد صلى الله عليه وسلم .   وبركته ورحمته ،   وهو لما قال الله عز وجل :  {  وما أرسلناك إلا رحمة للعالمين } [ الأنبياء :  107 ] بفضله ورحمته أبقى هذه الأمة إلى يوم القيامة والله أعلم .
