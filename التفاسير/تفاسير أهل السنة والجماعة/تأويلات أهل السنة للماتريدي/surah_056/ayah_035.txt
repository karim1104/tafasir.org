الآية 35 وقوله تعالى : {  إنا أنشأناهن إنشاء } قال الأصم وغيره :  إن هذا صلة قوله :  {  وحور عين } {  كأمثال اللؤلؤ المكنون } [ الآيتان :  22 و23 ] كأنه قاله{[20449]} على إثره<br />
وقال القتبي :  إنه لما ذكر على إثر قوله تعالى :  {  وفرش مرفوعة } {  إنا أنشأناهن إنشاء } دل أن الفرش كناية عن الأزواج  ؛  إذ هن اللواتي{[20450]} تفرش ،   وواحدة الفرش فريش .  <br />
وقيل :  قد استفرشت الناقة إذا اشتهت الجمل .  <br />
والأشبه أن يكون هذا على صلة {  وحور عين } {  كأمثال اللؤلؤ المكنون } إذ ذكر قوله{[20451]} :  {  وحور عين } على [ إثر ذكر ]{[20452]} المجالس والزوجات ،   فلا{[20453]} معنى لذكرهن في هذا الموضع .  <br />
وقوله تعالى :  {  إنا أنشأناهن إنشاء } أي أنشأناهن في الابتداء على هيئة الإستمتاع ،   ليس كنساء الدنيا ،   وهو كما ذكرنا في قوله في صفة الفواكه أنها غير مقطوعة ولا ممنوعة ،   أي أنها تخرج أول ما تخرج [ مهيئة للأكل ]{[20454]} لا كثمار الدنيا .
