الآية 3 وقوله تعالى :  {  خافضة رافعة } قال بعضهم :  {  خافضة } تسمع القريب {  رافعة } تسمع البعيد .   وقال صاحب هذا التأويل ،   إذ يفسر الواقعة :  [ إنها ]{[20400]} هي الصيحة ،   وتلك {  خافضة رافعة } .  <br />
وقال بعضهم :  {  خافضة } أناسا في النار ،   و{  رافعة } أناسا في الجنة .  <br />
ويحتمل {  خافضة } لمن تكبر ،   وتعظم على الخلق ،   [ رادّة إياه ]{[20401]} و{  رافعة } لمن تواضع للخلق ،   وانقاد له ،   وقبله .  <br />
وقيل :  {  خافضة } لأهل النار في النار كقوله تعالى :  {  يوم يسحبون في النار } [ القمر :  48 ] و{  رافعة } لأهل الجنة كقوله تعالى :  {  في مقعد صدق عند مليك مقتدر } [ القمر :  55 .
