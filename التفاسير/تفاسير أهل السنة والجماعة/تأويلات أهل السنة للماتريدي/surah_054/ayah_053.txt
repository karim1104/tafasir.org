الآية 53 وقوله تعالى :  {  وكل صغير وكبير مُستطَر } هذا أيضا يخرّج على هذين الوجهين : <br />
أحدهما :  {  مُستطَر } في الكتب التي قبلهم .  <br />
[ والثاني :  {  مُستطَر } في كتب ]{[20229]} الذين يُملون على الحَفَظة كقوله تعالى :  {  ما يلفِظ من قول إلا لديه رقيب عتيد } [ ق :  18 ] وقوله تعالى :  {  إن المجرمين في ضلال وسُعُر } {  يوم يُسحَبون في النار } [ القمر :  47 و48 ] وقوله{[20230]} في موضع آخر :  {  إن المجرمين في عذاب جهنم خالدون } [ الزخرف :  74 ] .
