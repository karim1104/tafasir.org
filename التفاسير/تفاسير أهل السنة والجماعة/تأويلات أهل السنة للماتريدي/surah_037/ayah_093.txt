الآية 93 وقوله تعالى :  {  فراغ عليهم ضربا باليمين } أي مال ،   ورجع عليهم .   وقوله :  {  ضربا باليمين } اختلف فيه :  قال بعضهم {  ضربا باليمين } وفاء{[17825]} ليمينه التي كانت منه حين{[17826]} قال :  {  وتالله لأكيدن أصنامكم بعد أن تولّوا مدبرين } [ الأنبياء :  57 ] والله أعلم .  <br />
وقال بعضهم :  {  ضربا باليمين } بالقوة .   وقد يعبَّر /454-أ/ باليمين عن القوة كما يعبّر باليد عن القوة .  <br />
وقال بعضهم :  {  ضربا باليمين } أي باليد اليمنى نفسها{[17827]} على ما يعمل المرء [ أكثر ]{[17828]} أعماله باليمين .
