الآية 43 وقوله تعالى :  {  فأقم وجهك للدين القيّم } قد ذكرنا في ما تقدم في قوله :  {  فأقم وجهك للدين حنيفا } [ يونس : 105 والروم30 ] .  <br />
وقوله تعالى :  {  من قبل أن يأتي يوم لا مرد له من الله } قال بعض أهل التأويل :  لا يقدر أحد على رد ذلك اليوم من الله ،   ثم يخرّج على وجهين : <br />
أحدهما :  {  لا مرد له من الله } أي لا يردّون من ذلك اليوم إلى ابتداء المحنة كقولهم :  {  يا ليتنا نرد } الآية :  [ الأنعام : 27 ] .   قولهم :  {  ربنا أخرجنا نعمل صالحا غير الذي كنا نعمل } [ فاطر : 37 ] .  <br />
وقد أخبر عنهم ،   فقال :  {  ولو ردوا لعادوا لما نهوا } [ الأنعام : 28 ] فعلى ذلك جائز أن يكون قوله :  {  لا مرد له من الله } أي لا يردون إلى ما يسألون الرد .  <br />
والثاني :  {  لا مرد له من الله } أي لا إقامة لهم من الله ،   ولا عفو ،   ولا توبة ،   إذا أتاهم ذلك اليوم كقوله :  {  لا ينفع نفسا إيمانها } الآية [ الأنعام : 158 ] .  <br />
وقوله تعالى :  {  يومئذ يصّدّعون } أي يتفرقون كقوله :  {  ويوم تقوم الساعة يومئذ يتفرقون } [ الروم : 14 ] هو {  يوم الجمع } [ الشورى : 7 والتغابن : 9 ] و{  يوم الفصل } [ الصافات : 21و .   .   .   ] على اختلاف الأحوال والأوقات ،   والله أعلم .
