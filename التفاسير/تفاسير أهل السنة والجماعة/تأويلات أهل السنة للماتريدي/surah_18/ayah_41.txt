الآية41 :  وقوله تعالى :  {  أو يصبح ماؤها غورا } هذا يخرج على وجهين .  <br />
أحدهما :  يقول :  {  ويرسل عليها حسبانا من السماء } أي عذابا ،   فتصير صعيدا زلقا أملس .  <br />
والثاني{[11603]} :  يذهب بمائها ،   فتهلك بذهاب الماء ؛  إذ هلاك البساتين يكون بذهاب الماء مرة وبالعذاب النازل .  <br />
وقوله تعالى :  {  فلن تستطيع له طلبا } هذا يحتمل وجهين : <br />
أحدهما :  {  فلن تستطيع له طلبا } أي تصير بحال لا تستطيع له طلبا .  <br />
والثاني{[11604]} :  لن تستطيع له وجودا .  <br />
وقال في قوله :  {  إن ترن أنا أقل منك مالا وولدا } بالنصب{[11605]} ،   لأن الكلام مبني عل قوله :  {  إن ترن } وجعل {  أنا } صلة .   وأما قوله {  أنا أكثر } ( الكهف : 34 ) فوَصْفُ {  أنا } أكثر ،   فارتفع .
