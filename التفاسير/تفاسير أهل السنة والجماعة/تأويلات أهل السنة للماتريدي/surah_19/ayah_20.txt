الآية 20 :  وقوله تعالى :  {  أنى يكون لي غلام ولم يمسسني بشر } إن قالت لم يمسسني بشر يعلم أنه /324-أ/ لم يمسها بشر :  لا ( تقي ولا غير تقي ){[11941]} .   لكن كأنها قالت :  {  ولم يمسسني بشر } نكاحا {  ولم أك بغيا } ولا بغيا .   فمن أنى يكون لي ولد ؟  كأنها لم تعرف الولد إلا بسبب .   لذلك قالت :  {  أنى يكون لي غلام } ؟
