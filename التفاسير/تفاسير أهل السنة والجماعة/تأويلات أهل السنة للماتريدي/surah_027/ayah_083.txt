[ الآية 83 ] وقوله تعالى :  {  ويوم نحشر من كل أمة فوجا ممن يكذب بآياتنا } يجمع القادة منهم والأتباع والمتبوعين ،   فيساقون إلى النار جميعا كقوله :  {  احشروا الذين ظلموا وأزواجهم } الآية [ الصافات :  22 ] وكقوله :  {  وسيق الذين كفروا } الآية [ الزمر : 71 ] وكقوله :  {  ويوم يحشر أعداء الله إلى النار فهم يوزعون } [ فصلت :  19 ] .  <br />
قال أهل التأويل :  {  يوزعون } أي يحبس أولهم على آخرهم حتى يجتمعوا .   وقد ذكرنا الوزع في ما تقدم وما قيل فيه{[15149]} .
