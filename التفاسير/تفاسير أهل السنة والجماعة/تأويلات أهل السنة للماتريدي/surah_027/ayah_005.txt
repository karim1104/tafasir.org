[ الآية 5 ] [ وقوله تعالى ]{[14895]} :  {  أولئك الذين لهم سوء العذاب } أي لهم ما يسوءهم من العذاب في الآخرة لاختيارهم سوء الأفعال في الدنيا {  وهم في الآخرة هم الأخسرون } [ والخاسرون ]{[14896]} واحد .  <br />
وجائز أن يقال :  {  هم الأخسرون } للقادة منهم والرؤساء لأنهم ضلوا بأنفسهم ،   وأضلوا غيرهم ،   هم أخسر من{[14897]} الأتباع كقوله :  {  ليحملوا أوزارهم كاملة يوم القيامة ومن أوزار الذين يضلونهم } [ النحل : 25 ] .
