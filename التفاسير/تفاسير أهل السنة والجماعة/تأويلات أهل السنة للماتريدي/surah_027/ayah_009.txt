[ الآية 9 ] وقوله تعالى :  {  يا موسى إنه أنا الله العزيز الحكيم } أي الذي أعطاك ذلك {  الله العزيز الحكيم } أو يقول :  إن الذي جعل لك ذلك {  الله العزيز الحكيم } أو يقول :  إنه الذي جعل لك ذلك {  العزيز الحكيم } العزيز :  الذي لا يعجزه شيء ،   الحكيم :  المصيب في فعله ،   غير المخطئ{[14913]} ،   أو يقول :  العزيز [ الذي ]{[14914]} لا يذل أبدا قط لأنه عزيز بذاته ،   الحكيم [ الذي ]{[14915]} يضع كل شيء موضعه ،   لا يخطئ .  <br />
قال أبو معاذ :  قال مقاتل بن سليمان {  يا موسى } يقول :  إن النور الذي رأيت {  أنا الله } .   وهذا محال لأوجه : <br />
أحدهما{[14916]} :  لأنك لا تقول :  إن الذي رأيت أنا الإنسان ،   رآه ،   أو لشيء آخر ،   ولكن تقول :  أنا الذي رأيت .  <br />
[ والثاني ]{[14917]} :  محال أيضا قوله لما ذكر في حرف ابن مسعود :  نودي {  يا موسى } لا تخف [ {  إنه أنا الله العزيز الحكيم } ]{[14918]} يكلمه الله ،   ويخاطبه ،   ثم يقول :  إن النور الذي رأيت أنا .  <br />
[ والثالث ]{[14919]} :  محال أيضا لقول الله {  آنست نارا سآتيكم منها بخبر } قال الله :  [ {  منها بخبر } وقال :  {  فلما جاءها } ]{[14920]} ولم يقل :  [ منه بخبر .   .   .   جاءه ]{[14921]} .  <br />
[ والرابع ]{[14922]} :  محال أيضا أن يكون {  الله } نعتا لأنك لا تقول :  [ إن الذي ]{[14923]} رأيت أنا أخوك .  <br />
فقال{[14924]} :  قول مقاتل محال من أربعة أوجه [ خلافا لظاهر ]{[14925]} الآية .  <br />
وأصله :  ما ذكرنا في ما تقدم .
