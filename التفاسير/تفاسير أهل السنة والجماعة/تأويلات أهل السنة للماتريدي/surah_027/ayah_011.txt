[ الآية 11 ] وقوله تعالى :  فقال :  {  إلا من ظلم ثم بدل حسنا بعد سوء } هذا [ أيضا ]{[14931]} يخرج على وجوه : <br />
أحدها :  {  لا يخاف لدي المرسلون } {  إلا من ظلم } إذا بدل حسنا بعد{[14932]}  سوء .  <br />
والثاني :  {  لا يخاف لدي المرسلون } ولكن من ظلم ممن سواهم {  ثم بدل حسنا بعد سوء فإني غفور رحيم } .   رجاء المغفرة وطمع العفو في مكان منه .  <br />
والثالث :  {  لا يخاف لدي المرسلون } {  إلا من ظلم } منهم من نحو موسى بقتله النفس وإخوة يوسف {  ثم بدل حسنا } وتاب عن ذلك ،   فإنه يخاف أيضا ،   والله أعلم .
