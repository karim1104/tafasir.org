الآية 196 وقوله تعالى :  {  إن وليّي الله الذي نزّل الكتاب } الآية ذكر هذا على إثر قوله {  ثم كيدوني فلا تنظرون } كما ذكر هود {  إني أشهد الله واشهدوا أني بريء مما تشركون } {  من دونه فكيدوني جميعا ثم لا تنظرون } {  إني توكلت على الله ربي وربكم } [ هود :  54-56 ] وكما قال نوح {  إن كان كبر عليكم مقامي وتذكيري بآيات الله فعلى الله توكلت فأجمعوا أمركم وشركاءكم ثم لا يكن أمركم عليكم غمّة ثم اقضوا إليّ ولا تنظرون } [ يونس :  71 ] فزعوا إلى الله عز وجل عند وعيد قومهم بالإهلاك ،   وعليه اعتمدوا ،   وبه وثقوا .  <br />
فعلى ذلك رسول الله [ حين ]{[9248]} قال :  {  إن وليّي الله الذي نزّل الكتاب وهو يتولّى الصالحين } أي [ وهو ]{[9249]} وليّي يحفظني ،   وهو يتولّى حفظ الصالحين ،   أي بتولّيه صلحوا ،   أو يتولّى ،   ويحفظ الصالحين [ معا .   بل هو وليّ ]{[9250]}من ذكرنا من الرسل وقومهم{[9251]} .  <br />
ثم قوله تعالى :  {  إن وليّي الله } يحتمل حافظي وناصري ،   أو وليّ تدبيري {  الله الذي نزّل الكتاب } [ ووليّ أمري ]{[9252]} أو أولى بي {  الله الذي نزّل الكتاب } الذي عجزت الخلائق عن إتيان مثله {  وهو يتولّى الصالحين } .
