الآية 142 وقوله تعالى :  {  وواعدنا موسى ثلاثين ليلة وأتممناها بعشر } ذكر ههنا {  ثلاثين ليلة } ثم ذكر التمام بالعشر .  <br />
وذكر في السورة التي [ فيها ]{[8884]} ذكر البقرة {  أربعين ليلة } بقوله تعالى :  {  وإذ واعدنا موسى أربعين ليلة } [ الآية :  51 ] .   وهو واحد .   [ فالميعاد له أربعون ]{[8885]} ليلة ،   لكنه يحتمل ذكر {  ثلاثين ليلة } وعشرا وجهين .  <br />
أحدهما :  أن ثلاثين ليلة كان لأمر وعشرا كان لأمر آخر ،   فذكرها{[8886]} متفرقة لما كان لأمرين مختلفين .  <br />
والثاني :  أنه كان في وقتين ؛  كان هذا في وقت ،   والآخر في وقت ،   والقصة واحدة ،   والميعاد واحد .  <br />
فذكر التمام {  بعشر } كقوله تعالى :  {  فمن لم يجد فصيام ثلاثة أيام في الحج وسبعة إذا رجعتم تلك عشرة كاملة } [ البقرة :  196 ] أي ثلاثة {  أيام في الحج } وسبعة {  إذا رجعتم تلك عشرة كاملة } وإن كان في وقتين ،   والله أعلم .  <br />
وقوله تعالى :  {  فتمّ ميقات ربه أربعين ليلة } .  <br />
وقوله تعالى :  {  وقال موسى لأخيه هارون اخلفني في قومي } فإن قيل :  ما معنى قول موسى لأخيه هارون {  اخلفني في قومي } وهو كان مبعوثا [ رسولا معه ]{[8887]} إلى فرعون مشتركا في تبليغ الرسالة إلى فرعون كقوله :  {  وأشركه في أمري } [ طه :  32 ] وقوله :  {  إنا رسول رب العالمين } [ الشعراء :  16 ] وقوله :  {  فأتياه فقولا إنا رسولا ربك } [ طه :  47 ] وقوله :  {  وأخي هارون هو أفصح مني لسانا فأرسله معي ردءا } [ القصص :  34 ] .   فإذا كان هو رسولا كموسى في تبليغ الرسالة كيف احتاج إلى أن يقول موسى {  اخلفني في قومي } وهما شرعا سواء في الرسالة ؟  قيل :  يحتمل هذا وجهين .  <br />
يحتمل أن يكونا كما ذكر رسولين .   لكن من ولّى اثنين أمرا لم يكن لواحد منهما أن يتفرد به إلا بأمر الآخر .   فعلى ذلك هذا .   كأنه قال :  اخلفني في الحكم بينهم ،   وأصلح ذات بينهم ،   ولا تتّبع من دعاك إلى سبيل المفسدين .   أو يحتمل أن يكون موسى كان هو الرسول ،   إذن ،   وكان إليه الحكم ،   وهارون كان دخيلا في أمره ردءا على ما قال :  {  فأرسله معي ردءا يصدّقني } [ القصص :  34 ] [ كان موسى ]{[8888]} هو المأمور بها أولا والمبعوث إليهم دونه .  <br />
ألا ترى أنه هو المناجي ربه دون هارون [ وكان هو المعطى الألواح دون هارون ]{[8889]} كقوله {  وكتبنا له في الألواح من كل شيء } [ الأعراف :  145 ] وهو الذي قال :  {  إني آنست نارا } [ طه :  10 ] وهو الذي نودي بالبركة دون هارون ،   وغير ذلك من الآيات .   فإذا كان كذلك استخلفه موسى في قومه .
