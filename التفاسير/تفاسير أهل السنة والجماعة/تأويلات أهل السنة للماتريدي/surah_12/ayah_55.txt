قوله تعالى :  {  قَالَ اجْعَلْنِي عَلَى خَزَائِنِ الأَرْضِ } سأل هذا لما علم أنه ليس في وسعهم القيام بإصلاح ذلك الطعام ،   وعلم أنه لو ولي غيره الخزائن لم يعرف إنزال الناس من منازلهم في تقديم من يجب تقديمه ،   والقيام بحاجة الأحق من غيره ،   وعلم أنه إليه يرجع ،   وتقع حوائج أكثر الناس [ في ][ ساقطة من الأصل وم ] منازلهم ،   وبه قوام أبدانهم ،   فسأله ليقوم بذلك كله ،   وعلى يديه يجري .  <br />
وكذلك قال :  {  إني حفيظ عليم } قال بعضهم :  {  حفيظ } بما وليت {  عليم } بأمره .   وقيل {  حفيظ } لما في الأرض [ من ][ ساقطة من الأصل وم ] غلة {  عليم } بها .  <br />
وعن ابن عباس رضي الله عنه {  حفيظ } لما تحت يدي {  عليم } بالناس .   وقيل :  {  حفيظ } بصير بتقديره {  عليم } بساعات الجوع حين يقع {  إني حفيظ } لما استحفظت {  عليم } بحوائج الناس ،   أو {  عليم } بتقديم الأحق .  <br />
