الآية 30 [ وقوله تعالى ]( {[16453]} ) :  {  فأعرض عنهم } محمد إلى مدة {  وانتظر } بهم العذاب أي القتل وهلاكهم {  إنهم منتظرون } هلاككم .   وقال بعضهم :  {  فأعرض عنهم } إلى ذلك اليوم {  وانتظر } بهم فتح مكة {  إنهم منتظرون } هلاكك .  <br />
[ ويحتمل ]( {[16454]} ) أن يكون قوله :  {  فأعرض عنهم } أي لا تكافئهم لأذاهم إياك {  وانتظر } مكافأتنا إياهم {  إنهم منتظرون } .   والله أعلم [ بالصواب ] ( {[16455]} ) .
