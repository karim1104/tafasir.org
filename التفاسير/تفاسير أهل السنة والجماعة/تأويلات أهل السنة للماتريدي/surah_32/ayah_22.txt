الآية 22 وقوله تعالى :  {  ومن أظلم ممن ذكر بآيات ربه ثم أعرض عنها } قوله :  {  ومن أظلم } أي [ لا ]( {[16427]} ) أحد {  أظلم ممن ذكر بآيات ربه } ووقع له المعرفة والعلم أنها آيات ربه {  ثم أعرض عنها } بعد ما عرفها ،   وعلم بها .   ليس أحد أظلم من ذلك المذكر( {[16428]} ) بآياته ما ذكرنا .   إنهم يذكرون ليقع لهم أنها آياته .  <br />
ثم يحتمل آيات وحدانيته وآيات الرسالة وآيات البعث أو آيات القرآن ،   والله أعلم .  <br />
وقوله تعالى :  {  إنا من المجرمين منتقمون } جرمهم ههنا جرم كفر ؛  ينتقم منهم انتقام الكفر والتكذيب .
