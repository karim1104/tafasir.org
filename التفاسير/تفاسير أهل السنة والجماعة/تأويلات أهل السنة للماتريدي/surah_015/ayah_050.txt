الآية 50 :  ( وقوله تعالى ) {[9896]} {  وأن عذابي هو العذاب الأليم } لمن عصاني ،   ولم يستغفر ،   ولم يتب إلي {[9897]} .  <br />
ويحتمل غير هذا ،   وهو أن يقول :  {  نبئ عبادي أني أنا الغفور الرحيم } لئلا ييأسوا من رحمتي ،   ولا يقنطوا مني ،   ولكن يرجون رحمته وعفوه ،   ويخافون عذابه ونقمته ،   ونبئهم أيضا :  {  وأن عذابي هو العذاب الأليم } لئلا يكونوا {[9898]} آمنين أبدا .   فيكون فيه أمر بأن يبشر وأن ينذر ،   كأنه قال :  بشر أوليائي {  أني أنا الغفور الرحيم } لأوليائي {  وأن عذابي هو العذاب الأليم } لأعدائي .  <br />
وفي قوله :  {  نبئ عبادي } بشارة {[9899]} ونذارة .   أما البشارة فهي{[9900]} قوله :  {  إني أنا الغفور الرحيم } وأما النذارة فهي {[9901]} قوله :  {  وان عذابي هو العذاب الأليم } .
