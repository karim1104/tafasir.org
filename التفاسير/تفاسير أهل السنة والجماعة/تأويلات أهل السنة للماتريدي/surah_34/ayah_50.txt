الآية 50 وقوله تعالى :  {  إن ضللت } بكسر اللام{[17100]} ونصبها ،   كلاهما لغتان .   قال الكسائيّ :  تقول العرب :  ضَلّ يضِلّ ضَلَالةً ،   وضَلّ يضِلّ بالخفض والنصب جميعا .  <br />
ثم قوله :  {  إن ضللت فإنما أضل على نفسي } يخرّج على وجهين : <br />
أحدهما :  {  إن ضللت } فإنما{[17101]} يكون ضرر ضلالي على نفسي ،   لا يكون على الله من ذلك شيء كقوله :  {  إن أحسنتم أحسنتم لأنفسكم وإن أسأتم فلها } [ الإسراء :  7 ] وقوله :  {  من عمل صالحا فلنفسه ومن أساء فعليها } [ فصلت :  46 والجاثية :  15 ] .  <br />
والثاني :  {  إن ضللت } فإنما يكون ذلك على نفسي ،   ولا يكون على أنفسكم من ضلالي شيء كقوله :  {  إن افتريته فعلى إجرامي وأنا بريء مما تُجرمون } [ هود :  35 ] ونحوه .  <br />
وقوله تعالى :  {  وإن اهتديت فبما يوحي إليّ ربي } هذا يخرّج أيضا على وجهين : <br />
أحدهما :  {  وإن اهتديت } إلى طاعة الله وشرائع الدين {  فبما يوحي إليّ ربي } في ذلك ،   أي فبوحيه اهتديت إلى ذلك .  <br />
والثاني :  {  إن اهتديت } إلى دينه فبهدايته وبتوفيقه إياي وعصمته اهتديت .  <br />
أضاف الهداية إلى الله والضلال إلى نفسه ،   فهو لما ذكرنا :  أن كان من الله إليه لطف في ذلك [ ليس ذلك ]{[17102]} في الضلال .   وعلى قول المعتزلة يجيء أن يكون المعنى فيهما واحدا لأنهم يقولون :  إنه لا يكون من الله سوى [ الأمر ]{[17103]} والنهي ،   فلا يكون منه إليه في الهداية إلا كما منه في الضلال ،   والله أعلم .  <br />
وقوله تعالى :  {  إنه سميع قريب } قال بعضهم :  {  سميع } أي مجيب الداعي كقوله {  وإذا سألك عبادي عني فإني قريب أجيب دعوة الداع إذا دعانِ } الآية [ البقرة :  186 ] وقال بعضهم :  {  سميع } لمقالتكم لمحمد [ حين قلتم ]{[17104]} له :  لقد ضللت حين تركت دين آبائك {  قريب } أي مجيب له .   وقيل :  سميع الدعاء ،   قريب الإجابة ،   والله أعلم .
