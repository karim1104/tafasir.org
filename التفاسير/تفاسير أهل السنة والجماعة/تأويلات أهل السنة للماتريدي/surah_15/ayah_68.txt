الآية 68 :  وقوله تعالى :  {  قال إن هؤلاء ضيفي فلا تفضحون } يحتمل هذا وجهين :  [ يحتمل ]{[9932]} {  فلا تفضحون } في ضيفي فإنهم إنما نزلوا بنا على أمن منا {  فلا تفضحون } عندهم ،   وهو ما قال في آية أخرى {  ولا تخزون في ضيفي } ( هود :  78 ) .  <br />
ويحتمل :  {  فلا تفضحون } في الخلق ،   يقولوا{[9933]} :  إن في أهل بيت لوط يفعل بالأضياف كذا ،   وإنما عرف أهل بيتي عند الخلق بالصلاح ،   وإلا {  فلا تفضحون } في الخلق ،   واتقوا الله في صنيعكم بالرجال {  ولا تخزون في ضيفي } عند الخلق ( هود :  78 ) قيل :  هو الهوان ؟
