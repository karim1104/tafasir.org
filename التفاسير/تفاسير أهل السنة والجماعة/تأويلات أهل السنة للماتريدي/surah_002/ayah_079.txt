الآية 79 وقوله تعالى :  {  فويل للذين يكتبون بأيديهم } قيل :  الويل :  الشدة ،   وقيل :  الويل :  واد في جهنم ،   وقيل :  الويل :  هو قول كل مكروب وملهوف يقول :  ويل له بكذا .  <br />
وقوله :  {  يكتبون الكتاب بأيديهم } يحتمل وجهين{[1029]} :  يحتمل ( يكتبون ) يمحون بعثه{[1030]} وصفته عن التوراة ،   ويحتمل <br />
يكتبون } يحدثون كتابة على غير بعثه{[1031]} وصفته .  <br />
[ وقوله ]{[1032]} {  ثم يقولون هذا من عند الله } فتكون الكتابة في هذا إثباتا{[1033]} كقوله :  {  كتب في قلوبهم الإيمان } [ المجادلة :  22 ] .   والمثبت هو ذلك الملحق ليظن أنه كذلك في الأصل .  <br />
وقوله :  {  ليشتروا به ثمنا قليلا } قد ذكرنا هذا في ما تقدم{[1034]} .  <br />
وقوله :  {  فويل لهم مما كتبت أيديهم وويل لهم مما يكسبون } ذكر لهم ثلاث ويلات :  [ احدها ]{[1035]} ويل بإحداث كتابة ببعث رسول الله صلى الله عليه وسلم ونحوه وتغييره ،   والثاني :  بقولهم :  {  هذا من عند الله } والثالث :  {  وويل لهم مما يكسبون } من المأكلة والهدايا .
