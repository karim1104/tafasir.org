الآيتان 106 و107 :  وقوله تعالى :  {  فيذرها قاعا صفصفا } {  لا ترى فيها عوجا ولا أمتا } قيل :  لا واديا {  ولا أمتا } ولا رابية .  <br />
وقال بعضهم :  العوج الارتفاع ،   والأمت الهبوط .   وقال بعضهم :  العوج انحناء الأودية ،   والأمت التلال .   وقيل :  لا انخفاضا ولا ارتفاعا [ وقيل ] {[12438]} :  والقاع الصفصف ،   هو تفسير {  لا ترى فيها عوجا ولا أمتا } [ وقوله :  {  لا ترى فيها عوجا ولا أمات } تفسير قوله :  {  قاعا صفصفا } ]{[12439]} .  <br />
وقال أبو عبيدة :  الهضم النقصان ،   وقال :  {  قاعا صفصفا } [ طه :  106 ] القاع الأرض التي يعلوها الماء ،   وهو قريب مما ذكرنا والله أعلم .
