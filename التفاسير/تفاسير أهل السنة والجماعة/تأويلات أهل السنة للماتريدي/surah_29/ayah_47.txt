الآية 47 وقوله تعالى :  {  وكذلك أنزلنا إليك الكتاب } أي كما أخبرناك في الكتاب فقل لهم [ ما ذكرنا ]( {[15813]} ) أو جادلهم .  <br />
وقوله تعالى :  {  فالذين آتيناهم الكتاب يؤمنون به } يخرج على وجهين : <br />
أحدهما :  {  فالذين آتيناهم الكتاب } فيتلونه حق تلاوته ،   فهم يؤمنون به على ما ذكر في آية أخرى :  {  الذين آتيناهم الكتاب يتلونه حق تلاوته أولئك يؤمنون به } [ البقرة :  121 ] فتكون هذه الآية تفسيرا للأولى .   وأما من لم يتله( {[15814]} ) حق تلاوته [ فلا يؤمن ] ( {[15815]} ) به .  <br />
والثاني :  {  فالذين آتيناهم الكتاب } وانتفعوا به ،   أي [ يؤمن به ] ( {[15816]} ) الذين أوتوا منافع الكتاب .  <br />
[ وقوله تعالى :  ]( {[15817]} ) :  {  ومن هؤلاء من يؤمن به } يحتمل قوله :  {  ومن هؤلاء } أي من أهل مكة {  من يؤمن به } وقد آمن كثير منهم .  <br />
وجائز أن يكون إشارة إلى قوم كانوا بحضرته ،   فقال :  {  ومن هؤلاء من يؤمن به } والله أعلم .  <br />
[ وقوله تعالى ] ( {[15818]} ) :  {  وما يجحد بآياتنا إلا الكافرون } قال( {[15819]} ) قتادة :  لا يكون الجحود إلا بعد معرفة ؛  إن اليهود والنصارى عرفوه كما عرفوا أبناءهم ،   لكنهم جحدوه ،   وكل من أنكر شيئا فقد جحده ،   عرفه أو لم يعرفه .
