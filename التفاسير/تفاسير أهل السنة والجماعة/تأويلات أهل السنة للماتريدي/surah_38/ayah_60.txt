أجابهم الأتباع :  {  قَالُوا بَلْ أَنْتُمْ لَا مَرْحَبًا بِكُمْ أَنْتُمْ قَدَّمْتُمُوهُ لَنَا فَبِئْسَ الْقَرَارُ } .   قال بعضهم :  قالت الخزنة لمن في النار {  هذا فوج مقتحم } فيردون على الخزنة {  لا مرحبا بهم إنهم صالوا النار } فيرد عليهم القوم الذين اقتحموا النار بعدهم {  بل أنتم لا مرحبا بكم } .  <br />
وأصل هذا أن هذا نمهم لعن ،   يلعن بعضهم بعضا كقوله عز وجل :  {  ثم يوم القيامة يكف بعضكم ببعض } [ العنكبوت :  25 ] ونحو ذلك من الآيات .
