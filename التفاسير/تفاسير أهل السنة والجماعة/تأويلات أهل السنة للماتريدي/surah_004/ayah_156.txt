الآية 156<br />
وقوله تعالى : {  وبكفرهم وقولهم على مريم بهتانا عظيما } قال ابن عباس رضي الله عنه :  قذفوها بالزنى ،   وهو قولهم :  {  لقد جئت شيئا فريا } ( مريم : 27 ) وقيل :  قوله تعالى : {  وبكفرهم } أي كفرهم بمحمد صلى الله عليه وسلم ،   وبالقرآن {  وقولهم على مريم } ما{  قالوا يا مريم لقد جئت شيئا فريا } ( مريم :  27 ) .
