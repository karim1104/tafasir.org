الآية 79 :  وكان يطمع أن يزاد{[12084]} له في الدنيا أبدا ،   فقال عز وجل :  {  كلا } ردا على ذلك .  <br />
وقال هاهنا :  {  أطلع الغيب } إنه يكون له في الآخرة ؛  ذلك على التأويل الأول ،   أو في الدنيا في وقت آخر :  ذلك على تأويل الحسن {  أم اتخذ عند الرحمان عهدا } أي له بذلك عند الله عهد .  <br />
[ وقوله تعالى ]{[12085]} {  كلا } رد{[12086]} على ما ادعوا {  سنكتب ما يقول } أي سنحفظ {  ونمد له من العذاب مدا } قال بعضهم :  قوله :  {  ونمد له } أي نزيد له {  من العذاب } في كل يوم كقوله :  {  فذوقوا فلن نزيدكم إلا عذابا } [ النبأ :  30 ] .  <br />
وقال بعضهم :  {  ونمد له من العذاب مدا } أي نعذب [ بلا انقطاع ] {[12087]} له ،   والله أعلم .
