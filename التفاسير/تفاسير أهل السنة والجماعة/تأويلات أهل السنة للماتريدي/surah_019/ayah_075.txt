الآية75 :  وقوله تعالى :  {  قل من كان في الضلالة فليمدد له الرحمان مدا } أي خيرا وسعة في الدنيا {  حتى إذا رأوا ما يوعدون إما العذاب } هو العذاب والهلاك وعدهم رسول الله في الدنيا {  وإما الساعة } القيامة .  <br />
وقوله تعالى :  {  فسيعلمون من هو شر مكانا وأضعف جندا } هذا يدل أن قولهم {  أي الفريقين خير مقاما وأحسن نديا } [ مريم :  73 ] أرادوا الخدم والحواشي حين{[12067]} قال {  وأضعف جندا } .  <br />
قال أبو عوسجة :  {  حتما مقضيا } ( مريم : 81 ) أي واجبا {  نديا } [ مريم :  73 ] أي مجلسا ،   والأندية{[12068]} جمع ،   والأثاث المتاع {  ورئيا } [ مريم :  74 ] منظرا {  ونمد له من العذاب مدا } [ مريم :  79 ] أي نطيل عذابه .  <br />
وقال القتبي :  {  نديا } أي مجلسا ؛  يقال للمجلس :  ندي وناد ،   ومنه قيل :  دار الندوة التي كان المشركون يجلسون ،   ويتشاورون في رسول الله ،   الأثاث المتاع ،   والرِّئيُ المنظر والشارة{[12069]} والهيئة ،   وقوله تعالى :  {  فليمدد له الرحمان مدا } أي يمد له في ضلالته {  ونرثه ما يقول } ( مريم :  80 ) أي نرثه المال والولد الذي قال :  {  لأوتين مالا وولدا } [ مريم :  77 ] وقوله تعالى :  {  ويأتينا فردا } [ مريم :  80 ] أي لا شيء معه .
