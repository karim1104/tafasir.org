الآية 12 وقوله تعالى :  {  ولو ترى إذ المجرمون ناكسوا رءوسهم عند ربهم } يقول :  والله أعلم ،   لو ترى يا محمد ما نزل بالمجرمين يومئذ من العذاب وفي ما هم فيه من الحال الشديدة والهوان بالتكذيب الذي كان منهم وإساءتهم إليك لرحمتهم ،   ولم تتكلف مكافأة إساءتهم وتكذيبهم( {[16393]} ) لعظم ما نزل من العذاب والشدائد {  ناكسوا رءوسهم عند ربهم } ندامة وحسرة وحزنا على ما كان منهم .  <br />
على مثل هذا يخرج التأويل ،   وإلا ليس في ظاهر الآية جواب قوله :  {  ولو ترى إذ المجرمون ناكسوا رءوسهم عند ربهم } فجوابه ما ذكرنا ونحوه ،   والله أعلم .  <br />
وقوله تعالى :  {  ربنا أبصرنا وسمعنا } هذا يخرج على وجهين : <br />
أحدهما :  قوله :  {  أبصرنا } بالحجج والبراهين عيانا بعد ما كنا أبصرناها في الأولى بالدلالة {  وسمعنا } أي قبلنا ،   وأجبنا {  فارجعنا } إلى الأولى إذ المحنة {  نعمل صالحا إنا موقنون } .  <br />
والثاني :  {  أبصرنا } صدق الرسل ،   وأيقنا بما وعدونا ،   وأوعدونا في الدنيا ،   {  وسمعنا } سماع إيقان وعيان {  فارجعنا نعمل صالحا إنا موقنون } والله أعلم .
