[ الآية 22 ] وقوله تعالى :  {  فمكث غير بعيد } أي لم يمكث طويلا حتى جاءه .   وفي حرف ابن مسعود :  {  فمكث غير بعيد } ثم جاءه {  فقال أحطت بما لم تحط به } كأنه سأل :  أين كنت ؟  فقال عند ذلك له :  {  أحطت بما لم تحط به } وفي حرف أبي :  {  أحطت بما لم تحط به } أنت ولا واحد من جنودك ،   أي بلغت ما لم تبلغ أنت ،   أي{[14970]} علمت ما لم تعلم أنت ولا واحد من جنودك .  <br />
ثم قال :  {  وجئتك من سبإ بنبإ يقين } لا شك فيه .  <br />
