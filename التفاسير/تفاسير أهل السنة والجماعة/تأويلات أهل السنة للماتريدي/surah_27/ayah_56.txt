[ الآية 56 ] وقوله تعالى :  {  فما كان جواب قومه إلا أن قالوا أخرجوا آل لوط من قريتكم } قوله :  {  فما كان جواب قومه إلا أن قالوا } كذا في وقت لا في الأوقات كلها ،   لأنه قد كان منهم قول وجوابات نحو ما {  قالوا ائتنا بعذاب الله } الآية [ العنكبوت : 29 ] ونحو وقولهم :  {  إنهم أناس يتطهرون } .  <br />
دل هذا منهم أنهم قد علموا أن ما يأتون ويعملون ،   أنه خبث وفحش ومنكر حين{[15065]} قالوا :  {  إنهم أناس يتطهرون } .  <br />
ثم يحتمل قوله هذا وجوها : <br />
أحدهما :  أنهم قالوا ذلك استهزاء منهم بهم<br />
والثاني :  {  قالوا أخرجوا آل لوط } فإنهم يستقذرون{[15066]}  أعمالنا وأفعالنا .  <br />
الثالث :  على التحقيق :  {  إنهم أناس يتطهرون } .
