الآية 154 ( وقوله تعالى :  {  ثم أنزل عليكم من بعد الغم آمنة نعاسا تغشى طائفة منكم وطائفة قد همتهم أنفسهم } قيل فيه بوجهين :  قيل :  الطائفة التي أتاها النعاس ،   هم المؤمنون سمعوا بانصراف العدو ) {[4514]} عنهم فصدقوا الخبر فناموا لأن الخوف إذا غلب يمنع النوم ،   وأما الطائفة التي قد أهمتهم أنفسهم ،   هم المنافقون ،   لم يصدقوا الخبر ،   فلم يذهب عنهم ،   فلم ينعسوا وذلك كقوله عز وجل :  {  يحسبون الأحزاب لم يذهبوا } الآية ،   ( الأحزاب : 20 ) وقيل :  كانت الطائفتان جميعا من المؤمنين لكن إحداهما قد أتاها النعاس لما آمنوا العدو والأخرى لا ،   بعصيانهم رسول الله صلى الله عليه وسلم وتركهم أمره منع ذلك النوم عنهم ،   إن كيف تلقون رسول الله صلى الله عليه وسلم ؟  وكيف تعتذرون إليه ؟  والله أعلم .  <br />
وعن ابن مسعود رضي الله عنه أنه قال :  ( النعاس في الصلاة من الشيطان في القتال أمنة ) .  <br />
وقوله تعالى :  {  يظنون بالله غير الحق ظن الجاهلية } قيل :  {  يظنون بالله } ألا ينصر محمدا صلى الله عليه وسلم وأصحابه ذا في غير المؤمنين ،   وقيل :  {  يظنون بالله غير الحق } ظنونا كاذبة إنما هم أهل شرك وريبة في أمر الله {  يقولون لو كان لنا من الأمر شيء ما قتلنا ههنا } .  <br />
وقوله تعالى :  {  يقولون هل لنا من الأمر من شيء } قيل {  يقولون } بعضهم لبعض :  {  هل لنا من الأمر من شيء } يعني بالأمر النصر والغنيمة .   وقيل قالوا ذلك للمؤمنين {  قل إن الأمر كله لله } يعني النصر والفتح كله بيد الله {  يخفون في أنفسهم ما لا يبدون لك } والذين يخفون قولهم :  لو أقمنا في منازلنا {  ما قتلنا ههنا } وقيل :  {  يقولون لو كان لنا من الأمر شيء } قالوا :  ليس {  لنا من الأمر من شيء } إنما الأمر إلى محمد ( ولو ما ){[4515]} كان الأمر ما خرجنا إلى هؤلاء حتى {  قتلنا ههنا }<br />
قال الله عز وجل :  {  قل لو كنتم في بيوتكم لبرز الذين كتب عليهم القتل إلى مضاجعهم } قيل :  {  لو كنتم في بيوتكم } كما يقولون لبرز } يعني لخرج من البيوت {  الذين كتب عليهم القتل } لظهر الذي كتب عليه ( القتل ) {[4516]} حيث كان ،   وقيل :  إذا كتب على احد القتل أتاه ،   ولو كان في البيت ،   ( وهو ){[4517]} كقوله {  أينما تكونوا يدرككم الموت ولو كنتم في بروج مشيدة } ( النساء :  78 ) وقيل متى كتب الله على قوم القتل فلم يموتوا أبدا .   وفي هذا بيان الآجال المكتوبة ( وهي ) {[4518]} التي تنقضي بها الأعمار {[4519]} وإن كان ( البيان ) {[4520]} قتلا فقتل وإن كان موتا فموت لا على ما قالت المعتزلة :  إن القتل تعجيل عن أجله المكتوب{[4521]} له عليه ،   والله أعلم .  <br />
وقوله تعالى {  وليبتلي الله ما في صدوركم } والابتلاء هو الاستظهار كقوله {  يوم تبلى السرائر } ( الطارق 9 ) يبدي ويظهر وذلك يكون بوجهين :  يظهر بالجزاء مرة ومرة بالكتاب يعلم الخلق من كانت سريرته حسنة بالجزاء .   وكذلك إذا كانت سيئة ويعلم بالكتاب .  <br />
وقوله تعالى :  {  وليبتلي الله ما في صدوركم } مما مضى ،   وليجعله لهم {  وليمحص ما في قلوبكم } من الذنوب وعن ابن عباس رضي الله عنه أنه قال :  ( الابتلاء والتحميص هما واحد .  <br />
وقوله تعالى :  {  والله عليم بذات الصدور } يقول :  هو عالم بما في صدورهم من سرائرهم ولكن يجعلها ظاهرة {[4522]} عندكم ،   ويحتمل الابتلاء ههنا الأمر بالجهاد ليعلموا المنافق منهم من المؤمن والله أعلم .
