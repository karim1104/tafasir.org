الآيتان 196- 197 وقوله تعالى :  {  لا يغرنك تقلب الذين كفروا في البلاد } {  متاع قليل } يحتمل تقلبهم وجوها : <br />
( أحدهما :  ذلك ) {[4762]} نعمة من الله عليهم لتركهم يتجرون في البلدان مع كف رهم بربهم .  <br />
والثاني :  أعطاهم أموالا يتنعمون فيها ويتلذذون .  <br />
والثالث :  ما أخر عنهم العذاب والهلاك إلى وقت .   يقول :  لا يغرنك يا محمد ذلك غنما متاع يسير مصيرهم إلى النار كقوله تعالى :  {  فلا يعجبنك أموالهم ولا أولادهم } الآية {  التوبة 55- 58 ) وكقوله تعالى :  {  ولا يحسبن الذين كفروا أنما نملي لهم خير لأنفسهم إنما نملي لهم ليزدادوا إثما } الآية ( آل عمران 178 ) قال :  وليس الاغترار في نفس التقلب لأنه جهد ومشقة ولكن لما فيه من الأمن والسعة والقوة دليله قوله تعالى {  متاع قليل } ثم قوله{[4763]} :  {  ولكن الذين اتقوا } منهم :  سعيهم{[4764]} للآخرة متاع لا ينقطع .
