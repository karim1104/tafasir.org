الآية 145 وقوله تعالى{[4482]} :  {  وما كان لنفس أن تموت إلا بإذن الله } يحتمل قوله :  {  إلا بإذن الله } أي لا يموت إلا بقبض المسلط على قبض الأرواح كقوله :  {  قل يتوفاكم ملك الموت الذي وكل بكم } ( السجدة 11 ) إن مات ،   أو قتل ويحتمل {  إلا بإذن الله } إلا بعلم الله {  كتابا مؤجلا } قيل :  وقتا مؤقتا لا يتقدم ،   ولا يتأخر مات أو قتل ،   ما لم تستوف رزقها وأجلها وقيل :  {  كتابا مؤجلا } أي مبينا{[4483]} في اللوح المحفوظ مكتوبا فيه .  <br />
وقوله تعالى :  {  ومن يرد ثواب الدنيا نؤته منها } أي أراد بمحاسن أعماله الدنيا {  نؤته منها ومن يرد ثواب الآخرة نؤته منها } أي {  ومن يرد } بأعماله الصالحات ومحاسنه {  الآخرة نؤته منها وسنجزي الشاكرين } وهو كقوله :  {  من كان يريد حرث الآخرة نزد له في حرثه ومن كان يريد حرث الدنيا نؤته منها } على قدر ما قدر {  وماله في الآخرة من نصيب } ( الشورى 2020 ) فكذلك هذا أيضا والله أعلم .
