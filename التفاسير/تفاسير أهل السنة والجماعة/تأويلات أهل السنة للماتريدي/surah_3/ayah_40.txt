الآية 40 [ وقوله تعالى ]{[3801]} :  {  قال رب أنى يكون لي غلام وقد بلغني الكبر } الآية ؛  يحتمل هذا الكلام وجوها : <br />
أحدها :  لا على الإنكار أي لا يكون ،   لكن ههنا{[3802]} يحتمل لأنه كان أعلم بالله وقدرته أن ينطق به ،   أو يخطر بباله .  <br />
والثاني :  {  أنى يكون لي غلام } أي كيف وجهه وسببه ؟  وكذلك قوله :  {  أنى لك هذا } وقوله{[3803]} :  {  أنى يحيي هذه الله بعد موتها } <br />
[ البقرة :  259 ] وقوله{[3804]} :  {  أنى يكون له الملك علينا } [ البقرة :  247 ] أي كيف وجهه ؟  وما سببه ؟ <br />
والثالث :  {  أنى يكون لي غلام } في الحال التي أنا عليها ،   أو أرد إلى الشباب ،   فيكون لي{[3805]} الولد{[3806]} .  <br />
وقوله تعالى :  {  وقد بلغني الكبر وامرأتي عاقر } وذكر في سورة مريم {  رب أنى يكون لي غلام وكانت امرأتي عاقرا وقد بلغني من الكبر عتيا } <br />
[ الآية 8 ] ذكر على التقديم والتأخير ،   وكذلك قوله :  {  ثلاثة أيام إلا رمزا } [ آل عمران :  41 ] وقوله{[3807]} :  {  ثلاث ليال سويا } [ مريم :  10 ] ،   والقصة واحدة ،   وذكر على التقديم والتأخير وعلى اختلاف الألفاظ واللسان .   دل أنه ليس على الخلق حفظ اللفظ واللسان <br />
[ وإنما ]{[3808]} عليهم حفظ المعاني المدرجة المودعة{[3809]} فيها ،   وبالله التوفيق وعلم{[3810]} أنه لم يكن على كلا{[3811]} القولين ،   ولم يكن بهذا اللسان .  <br />
وقال تعالى :  {  قال كذلك الله يفعل ما يشاء } كقوله{[3812]} :  {  قال كذلك قال ربك هو على هين } [ مريم :  21 ] وإن اختلف اللسان .
