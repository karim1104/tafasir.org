الآية 5 :  وقوله تعالى :  {  والأنعام خلقها لكم } يحتمل قوله :  {  خلقها لكم } على الظاهر أن خلق هذه الأشياء لنا {  فيها دفء ومنافع } كقوله :  {  هو الذي خلق لكم ما في الأرض جميعا } ( البقرة :  29 ) وقوله :  {  وسخر لكم ما في السماوات ومال في الأرض جميعا منه } ( الجاثية :  13 ) .  <br />
ويحتمل قوله :  {  والأنعام خلقها } أي هو خلقها ،   ثم أخبر [ أنها ]{[10035]} {  لكم فيها دفء ومنافع } بذكر أنواع المنافع والنعم التي أنعم علينا مفسرة مبينة واحدة بعد واحدة في هذه السورة وفي غيرها من السور .   إنما ذكرها مجملة غير مشار{[10036]} إلى كل واحدة منها على ما أشار إليها{[10037]} في هذه السورة ليقوموا بشكره{[10038]} ،   وليعلموا قدرته على خلق هذه الأشياء لا من الأشياء .  <br />
ثم قوله :  {  فيها دفء } قال بعضهم :  الدفء نسل كل دابة ،   وقال بعضهم :  ما ينتج منه .  <br />
وقال القتبي :  الدفء :  ما استدفأت به .   ويشبه أن يكون تفسير الدفء والمنافع التي ذكر{[10039]} ما فسر في آية أخرى ،   وهو قوله :  {  والله جعل لكم من بيوتكم سكنا وجعل لكم من جلود الأنعام بيوتا تستخفونها يوم ظعنكم ويوم إقامتكم } الآية ( النحل :  80 ) جعل الله عز وجل الأنعام وما ذكر وقاية جميع أنواع الأذى من السماوي وغيره مما يهيج من الأنفس من الحر والبرد والجوع وغير ذلك مما يكثر [ عددها ،   ويطول أمدها ]{[10040]} وذكرها .  <br />
وجعل فيها منافع كثيرة من الركوب والشرب والأكل كما قال :  {  ولكم فيها منافع } ( غافر :  80 ) وقال :  {  وإن لكم في الأنعام لعبرة نسقيكم مما في بطونها ولكم فيها منافع كثيرة } ( المؤمنون :  21 ) [ وقال ]{[10041]} :  {  لكم فيها منافع إلى أجل مسمى } ( الحج :  33 ) .
