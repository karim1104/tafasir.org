الآية 127 وقوله تعالى :  {  لهم دار السلام عند ربهم } يحتمل السلام اسم الجنة كقوله تعالى :  {  والله يدعو إلى دار السلام } [ يونس :  25 ] ويحتمل السلام اسم{[7747]} الله ؛  أي لهم دار الله ،   وهو الجنة .  <br />
وقوله تعالى :  {  وهو وليهم بما كانوا يعملون } قيل :  وهو أولى بهم أي أولى بالمؤمنين كقوله تعالى :  {  فالله أولى بهما } [ النساء :  135 ] ويحتمل قوله :  {  وهو وليهم } حافظهم وناصرهم .   وقد ذكرنا في ما تقدم {  يصعد } [ الآية :  125 ] .  <br />
ويصاعد ويصعد كله لغات{[7748]} ،   والمعنى واحد .  <br />
والضيق :  قال الكسائي :  الضيق من الضيق في المعاش ؛  فأما في الأمر فإنه الضيق ،   ومنه قوله تعالى :  {  ولا تك في ضيق مما يمكرون } [ النحل :  127 ] .   وأما قوله تعالى :  {  حرجا } ففيه{[7749]} لغتان{[7750]} :  حرج وحرج .   قال القتبي :  الحرج الذي ضاق فلم يجد [ به ]{[7751]} منفذا .   وقال أبو عوسجة :  الحرج الضيق ؛  يقال فيه :  حرج يحرج ،   فهو حرج .
