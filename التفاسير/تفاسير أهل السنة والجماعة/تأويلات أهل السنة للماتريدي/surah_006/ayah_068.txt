الآية 68 وقوله تعالى :  {  وإذا رأيت الذين يخوضون في آياتنا فأعرض عنهم حتى يخوضوا في حديث غيره } يشبه أن يكون قوله :  {  يخوضون في آياتنا فأعرض عنهم } أي يكفرون بها ،   ويستهزئون بها كما قال في سورة النساء :  {  وقد نزل عليكم في الكتاب أن إذا سمعتم آيات الله يكفر بها ويستهزأ بها فلا تقعدوا معهم حتى يخوضوا في حديث غيره } [ الآية :  140 ] فيكون الخوض في آيات [ الله ]{[7230]} الكفر بها والاستهزاء بها ،   ويكون قوله تعالى :  {  فأعرض عنهم } أي لا تقعد معهم كما قال :  {  فلا تقعدوا معهم حتى يخوضوا في حديث غيره إنكم إذا مثلهم } [ النساء :  140 ] .  <br />
وقوله تعالى :  {  فأعرض عنهم } يحتمل النهي عن القعود معهم على ما ذكر من قوله :  {  فلا تقعدوا معهم } ويحتمل الإعراض الصفح عنهم وترك المجازاة لمساوئهم كقوله تعالى :  {  فاصفح عنهم وقل سلام } [ الزخرف :  89 ] وكقوله{[7231]} تعالى :  {  فأعرض عنهم وعظهم وقل لهم في أنفسهم قولا بليغا } [ النساء :  63 ] [ فيه النهي ]{[7232]} عن القعود معهم ،   وفيه الأمر بالتبليغ .  <br />
وقوله تعالى :  {  وإما ينسينك الشيطان فلا تقعد بعد الذكرى مع القوم الظالمين } معناه ،   والله أعلم :  أن الشيطان إذا أنساك القعود معهم بعد ذكر الذكرى [ فلا تقعد ]{[7233]} ومعناه النهي بعدما أنساه الشيطان :  أي لا تكن بالمحل الذي يجد الشيطان إليك سبيلا في ذلك .
