[ الآية 66 ] وقوله تعالى :  {  إنها ساءت مستقرا ومقاما } أي جهنم ،   بئس المستقر ،   وبئس المقام لأهلها ،   وهو{[14539]} مقابل ما ذكر لأهل الطاعة الجنة حين{[14540]} قال :  {  حسنت مستقرا ومقاما } [ الفرقان : 76 ] .  <br />
وقال بعضهم :  {  غراما } غرموا في الآخرة مانعوا في الدنيا .   وفي حرف ابن مسعود {  كان غراما } إنا أنبئنا أنها {  ساءت مستقرا ومقاما } .  <br />
وقال أبو عوسجة :  {  هونا } هو من الرفق ،   يقال :  هان يهون هونا ،   فهو هائن [ ومنه يقال :  ]{[14541]} إذا عز أخوك فهن :  أي إذا اشتد فارفق به ،   والغرام الهلاك .   وكذلك قال القتبي {  غراما } أي هلكة ،   وقال :  مشيا {  هونا } رويدا {  سلاما } أي سدادا من القول ؛  لا رفث فيه ،   ولا هجر .
