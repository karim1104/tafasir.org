[ الآية 15 ] وقوله تعالى :  {  قل أذلك خير أم جنة الخلد التي وعد المتقون } يشبه أن يكون قال هذا لقولهم :  {  لولا أنزل إليه ملك فيكون معه نذيرا } {  أو يلقى إليه كنز أو تكون له جنة يأكل منها } [ الفرقان :  7و8 ] فيقول :  أذلك الذي سألتموه أنتم {  خير أم جنة الخلد التي وعد المتقون } ؟  أو يكون قال ذلك لما رأوا لأنفسهم الفضل والمنزلة في الدنيا لما وسع عليهم الدنيا ،   وأعطوا من حطامها ،   فقال :  {  أذلك } الذي أعطيتم في الدنيا من السعة {  خير أم جنة الخلد التي وعد المتقون } ؟  والله أعلم .
