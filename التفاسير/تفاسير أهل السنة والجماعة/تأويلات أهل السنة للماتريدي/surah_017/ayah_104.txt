الآية 104 :  وقوله تعالى : {  وقلنا من بعده لبني إسرائيل } أي بعد هلاك فرعون {  اسكنوا الأرض } اختلف فيه : <br />
قال بعضهم :  قوله {  اسكنوا الأرض } أرض مصر التي{[11299]} كان يسكن فرعون ،   وهو كقوله :  {  وأورثكم أرضهم }( الأحزاب : 27 ) .  <br />
وقال بعضهم :  {  اسكنوا الأرض } أرض الشام والأرض المقدسة كقوله :  {  يا قوم ادخلوا الأرض المقدسة التي كتب الله لكم } ( المائدة : 21 ) .  <br />
وقال بعضهم :  {  اسكنوا الأرض } ليس في أرض دون أرض ،   ولكن اسكنوا أي أرض شئتم مشارقها ومغاربها آمنين ،   لا خوف عليكم على ما أراد{[11300]}  أن يخرجكم من مشارق الأرض ومغاربها ،   بالقتل كقوله :  {  وأورثناها } الآية( الشعراء :  59والدخان : 28 ) وهو قال ابن عباس رضي الله عنه .   وعلى{[11301]} هذا قال في قوله تعالى : {  فإذا جاء وعد الآخرة } بعث عيسى ابن مرين : {  جئنا بكم لفيفا }أي جميعا مجتمعين من مشارق الأرض ومغاربها على ما تفرقوا .  <br />
وقال بعضهم :  {  فإذا جاء وعد الآخرة } يعني حياة عيسى ونزوله من السماء{  جئنا بكم لفيفا } أي جميعا منتزعين{[11302]}  من القرى ههنا وههنا ،   ولُوُّا جميعا ،   وهو مثل الأول .  <br />
وأما عامة أهل التأويل فإنهم قالوا :  {  فإذا جاء وعد الآخرة } يوم القيامة{  جئنا بكم لفيفا } أي جميعا :  أنتم وفرعن وجنوده حتى يروا كراماتكم التي أُكْرِمْتُمْ بها ،   ويروا هوانَهُم .
