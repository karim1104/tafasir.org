الآيتان 49 و50 :  وقوله تعالى :  {  قال فمن ربكما يا موسى } {  قال ربنا الذي أعطى كل شيء خلقه ثم هدى } وقال في آية أخرى :  {  قال فرعون وما رب العالمين } {  قال رب السماوات والأرض وما بينهما إن كنتم موقنين } الآية [ الشعراء :  23 و24 ] [ وقال في آية أخرى ]{[12278]} {  قال رب المشرق والمغرب وما بينهما } [ الشعراء :  28 ] .  <br />
سأله عن ماهيته ،   فأجابه موسى عن آثار صنعه في خلقه ،   وأنه رب كل شيء ورب ما ذكر .   لم يجبه عما سأله من ماهيته وكيفيته حين{[12279]} {  قال فمن ربكما يا موسى } فجوابه عن الماهية :  {  ربنا } فلان وأنه كذا .   ففيه دلالة أن الله ،   لا يُعرف من جهة الماهية والكيفية ؛  إذ لا ماهية له ،   ولا كيفية ،   إذ هما أوصاف الخلق ؛  فالله ،   سبحانه ،   يتعالى عن أن يوصف بشيء من صفات الخلق .  <br />
ثم يحتمل قوله :  {  أعطى كل شيء خلقه ثم هدى } وجوها : <br />
أحدها :  {  أعطى كل شيء خلقه } [ صورته وهيئته .   والثاني :  {  أعطى كل شيء خلقه ثم هدى } جنسه وشكله .   والثالث :  {  أعطى كل شيء خلقه } معاشه وقوامه .   والرابع :  {  أعطى كل شيء خلقه } ما يكون بعد الفناء صورة ما قد كان ] {[12280]} ليُعْلَمَ أنه قادر على بعثهم على الصورة التي كانت .  <br />
وقوله تعالى :  {  ثم هدى } [ هو مبني ] {[12281]} على قوله :  {  أعطى كل شيء خلقه } .  <br />
