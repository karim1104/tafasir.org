الآيتان 51 و52 :  وقوله تعالى :  {  قال فما بال القرون الأولى } {  قال علمها عند ربي في كتاب } قال بعضهم :  إنما سأل فرعون موسى عن القرون الأولى لأنه سمع من ذلك الرجل المؤمن حين قال :  {  يا قوم إني أخاف عليكم مثل يوم الأحزاب } [ غافر :  30 ] ولم يكن لموسى بهم علم ،   فوكل علمهم إلى الله ،   ثم أنزل الله عليه التوراة ،   فبين له فيها أمرهم .  <br />
وقال بعضهم :  سأل /331-ب/ فرعون موسى ذلك لأن موسى أخبر أنه يُبعث ،   وخوفه على ذلك .   فعند ذلك :  {  قال فما بال القرون الأولى } لم يُبعثوا منذ أهلكوا ،   فقال له ما قال .  <br />
وقال بعضهم :  قوله :  {  قال فما بال القرون الأولى } أهم في الجنة ،   أم في النار ؟  فقال :  {  علمها عند ربي } .  <br />
وقال بعضهم :  إنما سأله عن أعمالهم :  فما أعمال القرون الأولى ؟  فقال :  {  علمها عند ربي } أي أعمالهم {  عند ربي } [ وقوله تعالى :  {  في كتاب } كقوله ] {[12288]} :  {  كتاب مرقوم } [ المطففين :  9 و20 ] وقوله :  {  سائق وشهيد } [ ق :  21 ] .  <br />
وقوله تعالى :  {  في كتاب } قال بعضهم :  الكتاب الذي كتبت فيه أعمالهم .   وقال بعضهم :  في اللوح المحفوظ .  <br />
[ وقوله تعالي ]{[12289]} :  {  لا يضل ربي ولا ينسى } هما واحد [ أي ] {[12290]} لا يضل ،   ولا ينسى ذلك الكتاب .  <br />
[ وقرئ ] {[12291]} :  لا يضل{[12292]} من ختم بالهدى ،   وقرئ{[12293]} :  لا يضل {  ربي } [ في ] {[12294]} ذلك الكتاب الذي ذكر لأنه{[12295]} يرجع إلى قوله :  {  فلا يضل ولا يشقى } [ طه :  123 ]
