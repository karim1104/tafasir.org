الآية 106 :  وقوله تعالى :  {  إن في هذا لبلاغا لقوم عابدين } يحتمل قوله في هذا أي في ما ذكر من قوله :  {  ولقد كتبنا في الزبور من بعد الذكر أن الأرض يرثها عبادي الصالحون } في ذلك بلاغا {  لقوم عابدين } أي لقوم همهم العبادة أو لقوم مطيعين موحدين .  <br />
وجائز أن يكون قوله :  {  إن في هذا } في ما تقدم من الآيات ،   وهو قوله :  {  واقترب الوعد الحق فإذا هي شاخصة أبصار الذين كفروا } إلى قوله :  {  أنتم لها واردون } [ الأنبياء :  97 و98 ] ما ذكر من قوله :  {  إن الذين سبقت لهم منا الحسنى } إلى آخر ما ذكر كله {  لبلاغا لقوم عابدين } .  <br />
وجائز أن يكون بلاغا للناس جميعا كقوله :  {  هذا بلاغ للناس } [ إبراهيم :  52 ] فيكون قوله :  {  لقوم عابدين } أي لقوم يلزمهم العبادة .  <br />
وقال بعضهم :  {  إن في هذا } أي هذا القرآن {  لبلاغا } أبلغهم عن الله {  لقوم عابدين } .  <br />
وفي حرف ابن مسعود :  إن في هذا لذكرى{[12854]}  /344-ب/ لقوم عابدين .
