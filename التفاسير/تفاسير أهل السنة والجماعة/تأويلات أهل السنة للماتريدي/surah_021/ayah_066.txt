الآية 66 :  [ وقوله تعالى ] {[12699]} :  {  قال أفتعبدون من  دون الله [ ما لا ينفعكم شيئا ولا يضركم } فإن قيل :  إن إبراهيم لم يحتج عليهم أن كيف تعبدون من دون الله ] {[12700]} ما لا ينطق ؟  ولكن {  قال أفتعبدون من دون الله ما لا ينفعكم شيئا ولا يضركم } ؟  قيل :  قد كان احتج عليهم [ من ذلك النوع حين{[12701]} {  قال هل يسمعونكم إن تدعون } {  أو ينفعونكم أو يضرون } ؟  [ الشعراء :  72 و73 ] .  <br />
وبعد فإنه قد احتج عليهم ] {[12702]} يعجزهم عن النطق حين{[12703]} قال :  {  فسألوهم إن كانوا ينطقون } [ الأنبياء :  63 ] .   ثم قال هاهنا {  أفتعبدون من دون الله ما لا ينفعكم شيئا } إن عبدتموهم {  ولا يضركم } إن تركتم عبادته .
