الآية 72 :  وقوله تعالى :  {  ووهبنا له إسحاق ويعقوب نافلة } قال بعضهم :  النافلة العطية .   وقال بعضهم :  النافلة الفضل .  <br />
وأصل النافلة الغنيمة كقوله :  {  يسألونك عن الأنفال } [ الأنفال :  1 ] أي الغنائم .   والولد وولد الولد فضل منه وعطية وغنية ،   لأنه سمى الولد هبة بقوله :  {  يهب لمن يشاء إناثا ويهب لمن يشاء الذكور } [ الشورى :  49 ] وسمى [ الوالد مُوهَبا ] {[2]} وخاصة إبراهيم [ إذا ] {[3]} لم يكن يطمع أن يولد له الولد ،   فكيف يطمع بولد{[4]} الولد ؟ <br />
وقوله تعالى :  {  وكلا جعلنا صالحين } يحتمل قوله :  {  صالحين } رسلا ،   أو {  صالحين } في كل أمر وكل شيء .
