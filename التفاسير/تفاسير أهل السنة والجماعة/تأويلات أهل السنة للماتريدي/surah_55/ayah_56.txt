الآيتان 56 و57 وقوله تعالى :  {  فيهن قاصرات الطرف لم يطمثهن إنس قبلهم ولا جان } [ {  فبأي آلاء ربكما تكذبان } ]{[20364]} {  فيهن قاصرات الطرف } أي قصرت الطرف{[20365]} على أزواجهن ،   ولا ينظرن إلى غيرهم ،   ولا تشتهيهم كقوله في آية أخرى :  {  حور مقصورات في الخيام } [ الآية : 72 ] ذكر هذا لأن أهل الدين يكونون من أهل غيرة ،   لا يريدون أن تنظر زوجاتهم{[20366]} إلى غيرهم ،   ولا غيرهم ينظرون إليهن .   فأخبر بالآيتين أنهن لا ينظرن إلى غير أزواجهن ،   ولا غيرهم [ ينظرون ]{[20367]} إليهن حين{[20368]} وصفهن بأنهن {  قاصرات الطرف } و {  حور مقصورات في الخيام }<br />
وقوله تعالى :  {  لم يطمثهن إنس قبلهم ولا جان } قرئ {  لم يطمثهن } بضم الميم{[20369]} وكسره .  <br />
قال الفراء :  {  لم يطمثهن } أي لم يقبضهن ،   والطمث النكاح بالرومية .  <br />
