الآية 16 وقوله تعالى :  {  فَأَرْسَلْنَا عَلَيْهِمْ رِيحًا صَرْصَرًا } ذكر ما أهلكهم من العذاب ،   وهو الريح الصرصر الباردة .   كذا قال أبو عوسجة .  <br />
وقوله تعالى :  {  فِي أَيَّامٍ نَحِسَاتٍ } وهو ما ذكر في سورة الحاقة حيث قال :  {  وَأَمَّا عَادٌ فَأُهْلِكُوا بِرِيحٍ صَرْصَرٍ عَاتِيَةٍ } {  سَخَّرَهَا عَلَيْهِمْ سَبْعَ لَيَالٍ وَثَمَانِيَةَ أَيَّامٍ حُسُومًا } [ الحاقة :  6 و7 ] وقال في موضع آخر {  في يوم نحس مستمر } [ القمر :  19 ]<br />
ثم اختلف في تأويلها :  قال بعضهم :  {  نحِسَاتٍ } مشؤومات نكدات ،   وهو قول القتبي .   وقال بعضهم :  {  نحسات } أي شداد .   وقيل {  نحسات } من النّحس ،   يقال :  نحس فلان{[18469]} .   والنّحس الغبار في الأصل .  <br />
وقوله تعالى :  {  لِنُذِيقَهُمْ عَذَابَ الْخِزْيِ فِي الْحَيَاةِ الدُّنْيَا } أي عذابا يُذلّهم ،   ويفضحهم عند الخلق جميعا .  <br />
قوله تعالى :  {  وَلَعَذَابُ الْآَخِرَةِ أَخْزَى } عليهم أذلّ وأفضح وأشد من عذاب الدنيا .  <br />
وقوله تعالى :  {  وَهُمْ لَا يُنْصَرُونَ } يحتمل لا ينصرون بقوتهم التي كانت لهم ،   [ واعتمدوا عليها بقولهم ]{[18470]} :  {  من أشد منا قوة } ويحتمل لا يُنصرون بالأصنام التي عبدوها على رجاء النصر لهم والشفاعة .
