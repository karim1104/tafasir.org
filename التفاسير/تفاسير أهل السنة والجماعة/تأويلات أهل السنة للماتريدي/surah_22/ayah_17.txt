الآية 17 :  وقوله تعالى :  {  إن الذين آمنوا والذين هادوا والصابئين والنصارى والمجوس والذين أشركوا } أما الصائبون فإن الناس اختلفوا فيهم :  قال أهل التأويل :  هم عباد الملائكة ،   وقد ذكرنا أقاويلهم فيه في سورة المائدة ،   فتركنا ذكره هاهنا لذلك .   {  والذين أشركوا } قيل :  هم مشركي العرب ،   وهم عَبَدَةُ الأوثان والأصنام .  <br />
وقوله تعالى :  {  إن الله يفصل بينهم يوم القيامة } يحتمل قوله :  {  يفصل بينهم } يحكم بين هؤلاء يوم القيامة لاختلافهم في الدنيا كقوله :  {  وقالت اليهود ليست النصارى على شيء وقالت النصارى ليست اليهود على شيء } [ البقرة :  113 ] وقوله{[12945]} :  {  فالله يحكم بينهم } أي يحكم بين هؤلاء {  يوم القيامة } [ البقرة :  113 ] .  <br />
فالفصل بينهم يوم القيامة ،   هو الحكم الذي ذكر في الآية .  <br />
ويحتمل قوله :  {  يفصل بينهم يوم القيامة } في المقام ؛  يبعث هؤلاء إلى الجنة وهؤلاء إلى النار .   فذلك الفصل بينهم .   وجائز أن يكون قوله :  {  يفصل } أي يبين لهم الحق من الباطل حتى يقروا{[12946]} جميعا بالحق ،   ويؤمنوا{[12947]} به .   ولكن لا ينفعهم ذلك يومئذ .  <br />
وقوله تعالى :  {  إن الله على كل شيء شهيد } من أعمالهم وأفعالهم وأقرارهم وأقوالهم وجميع ما كان منهم .
