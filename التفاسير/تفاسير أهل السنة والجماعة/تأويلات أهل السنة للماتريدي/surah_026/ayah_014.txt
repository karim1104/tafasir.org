[ الآيتان 13 و14 ] وقوله تعالى :  {  فأرسل إلى هارون } {  ولهم علي ذنب فأخاف أن يقتلون } :  قوله :  {  فأرسل إلى هارون } كسؤاله إياه حين{[14608]} قال :  {  واجعل لي وزيرا من أهلي } {  هارون أخي } {  اشدد به أزري } {  وأشركه في أمري } [ طه :  29-32 ] فعلى ذلك قوله :  {  فأرسل إلى هارون } يكون معي في الرسالة ،   وقوله{[14609]} :  {  هو أفصح مني لسانا فأرسه معي ردءا } الآية [ القصص :  34 ] .  <br />
وذنبه الذي ذكر أنه عليه ،   وهو قتل ذلك القبطي ،   وهو قوله :  {  فوكزه موسى فقضى عليه } [ القصص :  15 ] ذلك ذنبه الذي لهم عليه .
