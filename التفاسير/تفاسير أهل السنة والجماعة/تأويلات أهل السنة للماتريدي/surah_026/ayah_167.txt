[ الآية 167 ] وقوله تعالى :  {  قالوا لئن لم تنته يا لوط لتكونن من المخرجين } ذكر الانتهاء ،   ولم يبين مماذا ؟  فجائز أن يكونوا {  قالوا لئن لم تنته يا لوط } من تعييرك الذي تعيرنا به {  لتكونن من المخرجين } بقولك{[14782]} :  {  إنكم لتأتون الفاحشة ما سبقكم بها من أحد من العالمين } [ العنكبوت :  28 ] وقولك{[14783]} :  {  وتذرون ما خلق لكم ربكم من أزواجكم } [ الشعراء : 166 ] .  <br />
ويحتمل :  {  لئن لم تنته يا لوط } من دعائك الذي تدعونا إليه {  لتكونن } كذا .  <br />
وقوله تعالى :  {  لتكونن من المخرجين } يحتمل نفس الإخراج ،   أي نخرجك من القرية ومن بيننا .  <br />
وجائز أن يكونوا{[14784]}  أرادوا بالإخراج إخراجا بالقتل كقوله{[14785]}  قوم نوح حين{[14786]} {  قالوا لئن لم تنته يا نوح لتكونن من المرجومين } [ الشعراء : 116 ] وهو أشبه .
