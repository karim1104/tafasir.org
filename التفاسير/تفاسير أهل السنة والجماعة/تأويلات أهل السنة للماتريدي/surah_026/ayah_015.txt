[ الآية 15 ] [ وقوله تعالى ]{[14610]} :  {  قال كلا فاذهبا بآياتنا إنا معكم مستمعون } وقوله :  {  كلا } رد على قول موسى {  فأخاف أن يقتلون } كأنه قال :  لا تخف ،   وهو ما قال في آية أخرى حين{[14611]} {  قلا ربنا إننا نخاف أن يفرط علينا } بالفعل {  أو يطغى } [ طه :  45 ] فقال عند ذلك {  قال لا تخافا إنني معكما أسمع وأرى } [ طه :  46 ] .  <br />
فعلى ذلك قوله :  {  كلا فاذهبا } [ أي لا تخافا ]{[14612]} / 381-ب/ {  فاذهبا بآياتنا إنا معكم مستمعون } .  <br />
وقال في تلك الآية :  {  إنني معكما أسمع وأرى } [ طه : 46 ] أي أسمع ما يقولون لكما ،   وأرى ما يفعلون بكما{[14613]} ،   فأمنعهم عنكما ؛  لأنهما ذكرا الخوف منه من شيئين :  من الفعل والقول حين{[14614]} {  قالا ربنا إننا نخاف أن يفرط علينا } بالفعل {  أو أن يطغى } [ طه :  45 ] باللسان .
