[ الآية 72 ] [ وقوله تعالى ]{[14680]} :  {  قال هل يسمعونكم إذ تدعون } [ يبين سفههم ]{[14681]} :  يحتمل قوله :  {  هل يسمعونكم } أي هل يجيبونكم إذ تدعونهم ،   ويحتمل :  {  هل يسمعونكم } على السماع نفسه ،   أي هل يسمعون دعاءكم إذ تدعونهم كقوله :  {  لا يسمعوا دعاءكم } الآية ؟  [ فاطر : 14 ] .  <br />
وقوله تعالى :  {  إذ تدعون } يحتمل تعبدون ،   ويحتمل الدعاء نفسه ،   فإن كان على العبادة فلا يحتمل السماع .
