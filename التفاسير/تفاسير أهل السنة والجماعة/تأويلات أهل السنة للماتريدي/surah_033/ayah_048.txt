الآية 48 وقوله تعالى :  {  ولا تطع الكافرين والمنافقين } هذا قد ذكرناه في أول السورة .  <br />
وقوله تعالى :  {  ودع أذاهم } هذا يحتمل أعرض عنهم ،   ولا تكافئهم بما يؤذونك ،   ويحتمل( {[16726]} ) :  {  ودع أذاهم } [ أي اصبر على أذاهم ]( {[16727]} ) .  <br />
وقوله تعالى :  {  وتوكل على الله } أي اعتمد بالله {  وكفى بالله وكيلا } أي كفر بالله معتمدا ،   ويحتمل( {[16728]} ) :  {  وكفى بالله وكيلا } أي حافظا أو مانعا ،   والله أعلم .
