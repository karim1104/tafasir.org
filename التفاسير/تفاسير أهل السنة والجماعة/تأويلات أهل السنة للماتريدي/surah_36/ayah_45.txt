الآية 45 وقوله تعالى :  {  وإذا قيل لهم اتقوا ما بين أيديكم وما خلفكم لعلكم ترحمون } اختلف في قوله :  {  وما بين أيديكم وما خلفكم } قال قائلون :  {  ما بين أيديكم } ما كان من عقوبات الله ووقائعه في من كان قبلكم من عنادهم في آياته وتكذيبهم رسله ،   يقول :  اتقوا ذلك ،   واحذروا نزوله عليكم .   فسمّى {  بين أيديكم } ؛  لأنه مضى بين أيديهم {  وما خلفكم } من أمر الساعة وعذابها [ سمّاه خلفا لأنه لم يجيء ]{[17487]} بعد [ وما ]{[17488]} وراءهم غير مأتيّ ،   يقول :  احذروا ذلك .  <br />
وقال قائلون :  {  ما بين أيديكم } هو عقوبات الآخرة ،   هي بين أيديهم [ ستأتيهم ،   وستنزل بهم ]{[17489]} {  وما خلفكم } ما مضى من العقوبات التي نزلت بمن كان قبلكم ،   فصار ذلك وراء وخلفا ،   يقول :  احذروا أيضا ما تسنّون أيضا لمن بعدكم كقوله :  {  علمت نفس ما قدّمت وأخّرت } [ الانفطار :  5 ] {  ما قدّمت } :  ما عمل هو {  وأخّرت } :  ما سنّ لغيره من بعده .  <br />
وقوله تعالى :  {  لعلكم ترحمون } أي :  إذا فعلتم ذلك استوجبتم الرحمة بفضله ،   والله أعلم .
