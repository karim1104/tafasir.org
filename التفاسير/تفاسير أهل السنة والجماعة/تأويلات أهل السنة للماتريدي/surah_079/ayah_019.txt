الآية 19 :  وقوله تعالى :  {  وأهديك إلى ربك فتخشى } فتهتدي ،   ثم تخشاه إذا اهتديت ،   أي عرفت عظمته وجلاله {  فتخشى } عقوبته ،   فيكون العلم مثمرا للخشية .  <br />
ألا ترى إلى قوله تعالى :  {  إنما يخشى الله من عباده العلماء } ؟  [ فاطر :  28 ] .  <br />
أو [ يكون ]{[23074]} {  وأهديك } إلى طاعة ربك ،   وأنذرك عقابه إذا عصيته {  فتخشى } فلا تعصيه .
