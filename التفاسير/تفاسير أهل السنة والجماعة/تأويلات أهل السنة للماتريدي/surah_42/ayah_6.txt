الآية 6 وقوله تعالى :  {  والذين اتخذوا من دونه أولياء } يحتمل قوله :  {  أولياء } الأصنام التي عبدوها دون الله كقوله تعالى :  {  لا يتخذ المؤمنون الكافرين أولياء من دون المؤمنين } [ آل عمران :  28 ] وقوله تعالى :  {  لا تتخذوا عدوّي وعدوّكم أولياء } [ الممتحنة :  1 ] وقوله تعالى :  {  إنهم اتخذوا الشياطين أولياء من دون الله } [ الأعراف :  30 ] .  <br />
وقوله تعالى :  {  الله حفيظ عليهم } يُخبر أنه لا عن غفلة وجهل منه يعملون ما يعملون ،   ولكنه حفيظ عليهم وعلى أعمالهم ،   لكنه يؤخر ذلك عنهم لحكمة ،   والله أعلم .  <br />
وقوله تعالى :  {  وما أنت عليهم بوكيل } يحتمل وجهين :  أحدهما :  {  وما أنت عليهم بوكيل } أي لا تؤاخذ أنت بمكانهم كقوله :  {  فإنما عليه ما حُمّل وعليكم ما حُمّلتم } [ النور :  54 ] .  <br />
والثاني :  {  وما أنت عليهم بوكيل أي بمسلّط عليهم ولا حفيظ .   إنما أنت رسول .   فعليك البلاغ كقوله تعالى :  {  إن عليك إلا البلاغ } [ الشورى :  48 ] وقوله :  {  ما على الرسول إلا البلاغ } [ المائدة :  99 ] والله أعلم .
