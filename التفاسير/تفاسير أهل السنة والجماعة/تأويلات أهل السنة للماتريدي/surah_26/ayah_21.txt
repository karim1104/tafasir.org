[ الآية 21 ] وقوله تعالى :  {  ففررت منكم لما خفتكم } وهو حين قال له ذلك الرجل {  إن الملأ يأتمرون بك ليقتلوك فاخرج } الآية {  فخرج منها خائفا يترقب } [ القصص :  20 و21 ] وذلك فراره منهم .  <br />
وقوله تعالى :  {  فوهب لي ربي حكما وجعلني من المرسلين } قال بعضهم :  {  حكما } أي علما بالحكم {  وجعلني من المرسلين } وقد كان ذلك له كله .
