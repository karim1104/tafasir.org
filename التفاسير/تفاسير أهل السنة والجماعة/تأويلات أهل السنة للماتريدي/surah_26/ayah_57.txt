[ الآيات 57- 60 ] وقوله تعالى :  {  فأخرجناهم } يعني فرعون وقومه {  من جنات وعيون } {  وكنوز ومقام كريم } أي حسن {  كذلك وأورثناها بني إسرائيل } {  فأتبعوهم مشرقين } أي تبع فرعون وقومه حين شرقت [ الشمس ]{[14664]} أي طلعت ،   وقيل{[14665]} :  {  مشرقين } أي كانوا في الشمس ،   أي قوم موسى صاروا في الشمس .   يقال :  أشرقوا{[14666]} إذا صاروا فيها .
