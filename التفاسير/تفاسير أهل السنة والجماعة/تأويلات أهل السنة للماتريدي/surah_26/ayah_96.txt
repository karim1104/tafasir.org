[ الآية 96 ] وقوله تعالى :  {  قالوا وهم فيها يختصمون } ذكر أنهم يختصمون في النار ،   ولم يذكر فيم تكون خصومتهم ؟  [ وجائز أن تكون ما ذكر ]{[14714]} في آية أخرى :  {  يقول الذين استضعفوا للذين استكبروا لولا أنتم لكنا مؤمنين } [ سبإ : 31 ] إلى آخر ما ذكر ،   وقوله :  {  قالوا ربنا من قدم لنا هذا فزده عذابا ضعفا في النار } [ ص :  61 ] وقوله :  {  ربنا هؤلاء أضلونا فآتهم عذابا } الآية [ الأعراف :  38 ] وأمثاله [ كثير في القرآن ]{[14715]} من المجادلات التي تجري في ما بين الأتباع والمتبوعين .  <br />
وقال بعضهم :  اختصامهم ما ذكر على إثره :  {  تالله إن كنا لفي ضلال مبين } {  إذ نسويكم برب العالمين } [ الشعراء :  97 و98 ] هذه مخاصمتهم .
