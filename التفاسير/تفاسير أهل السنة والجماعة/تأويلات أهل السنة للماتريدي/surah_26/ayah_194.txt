[ الآية 194 ] وقوله تعالى :  {  على قلبك } يحتمل وجوها : <br />
أحدهما :  أن جبريل لما ينزل من القرآن إنما ينزل على قلبه .  <br />
والثاني :  {  على قلبك } أي لا يذهب عنه ،   بل الله يجمعه في قلبك ،   كقوله :  {  لا تحرك به لسانك لتعجل به } {  إن علينا جمعه وقرآنه } [ القيامة :  16و17 ] .  <br />
[ والثالث ] {[14814]} :  أن يكون قوله :  {  على قلبك } أي يثبته على قلبك لقولهم :  {  لولا نزل عليه القرآن جملة } [ وقوله تعالى ] {[14815]} :  {  كذلك لنثبت به فؤادك } [ الفرقان : 32 ] .  <br />
[ والرابع ] {[14816]} :  أن يكون قال ذلك لما انتهى إلى قلبه ،   وحفظه غاية حفظه قال {  على قلبك } كأنه ألقي في قلبه .   وكذلك يقال .
