الآية 107 :  وقوله تعالى : {  ربنا أخرجنا منها فإنا عدنا فإنا ظالمون }ظلم عيان ( وظلما ظاهرا ){[13576]} وإلا قد كانوا أقروا بالظلم بقولهم : {  فاعترفوا بذنبهم } ( الملك : 11 ) .  <br />
وقوله تعالى : {  وما كنا قوما ضالين } قد أقروا بالظلم ،   لكنهم أقروا بظلم خبر وظلم سماع لا ظلم عيان ،   فقالوا : {  ربنا أخرجنا منها فإنا عدنا فإنا ظالمون } ظلم عيان .
