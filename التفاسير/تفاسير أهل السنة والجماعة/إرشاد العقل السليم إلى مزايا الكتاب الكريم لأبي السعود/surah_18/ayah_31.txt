{ أولئك } المنعوتون بالنعوت الجليلة { لَهُمْ جَنَّاتُ عَدْنٍ تَجْرِي مِن تَحْتِهِمُ الأنهار } استئنافٌ لبيان الأجر ،  أو هو الخبرُ وما بينهما اعتراضٌ أو هو خبرٌ بعد خبر { يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ مِن ذَهَبٍ } من الأولى ابتدائيةٌ والثانيةُ صفةٌ لأساور والتنكيرُ للتفخيم وهو جمعُ أَسوِرة أو إسْوار جمع سِوار { وَيَلْبَسُونَ ثِيَابًا خُضْرًا } خُصت الخُضرة بثيابهم لأنها أحسنُ الألوان وأكثرُها طراوة { مِن سُندُسٍ وَإِسْتَبْرَقٍ } أي مما رقّ من الديباج وغلُظ ،  جمعَ بين النوعين للدِلالة على أن فيها ما تشتهي الأنفسُ وتلَذّ الأعين { مُّتَّكِئِينَ فِيهَا على الأرائك } على السرُر على ما هو شأن المتنعمين { نِعْمَ الثواب } ذلك { وَحَسُنَتْ } أي الأرائك { مُرْتَفَقًا } أي متكأ .  <br />
