{ وَكَانَ لَهُ } لصاحب الجنتين { ثَمَرٌ } أنواعٌ من المال غيرُ الجنتين ،  من ثمر مالَه إذا كثّره ،  قال ابن عباس رضي الله عنهما : هو جميعُ المال من الذهب والفضة والحيوانِ وغير ذلك ،  وقال مجاهد : هو الذهبُ والفضة خاصة { فَقَالَ لصاحبه } المؤمن { وَهُوَ } أي القائلُ { يحاوره } أي صاحبَه المؤمنَ وإن جاز العكسُ أي يراجعه في الكلام من حار إذا رجع { أَنَاْ أَكْثَرُ مِنكَ مَالاً وَأَعَزُّ نَفَراً } حشَماً وأعواناً أو أولاداً ذُكوراً لأنهم الذين ينفِرون معه .  <br />
