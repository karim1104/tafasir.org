{ فَكَيْفَ تَتَّقُونَ } أي كيفَ تقونَ أنفسكمُ { إِن كَفَرْتُمْ } أي بِقيتُم على الكفرِ { يَوْماً } أي عذابَ يومٍ { يَجْعَلُ الولدان } من شدةِ هولِه وفظاعةِ ما فيهِ من الدَّواهي { شِيباً } شيوخاً جمعُ أشيبَ إما حقيقةً أو تمثيلاً وأصلهُ أنَّ الهمومَ والأحزانَ إذا تفاقمتْ على المرء ضعفتْ قُواه وأسرعَ فيه الشيبُ وقد جُوِّزَ أنْ يكونَ ذلك وصفاً لليومِ بالطولِ وليس بذاكَ .  <br />
