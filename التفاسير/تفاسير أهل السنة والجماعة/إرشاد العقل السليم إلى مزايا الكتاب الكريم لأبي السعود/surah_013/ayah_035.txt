{ مثَلُ الجنة } أي صفتُها العجيبة الشأنِ التي في الغرابة كالمثل { التي وُعِدَ المتقون } عن الكفر والمعاصي وهو مبتدأ خبرُه محذوفٌ عند سيبوبه أي فيما قصصنا عليك مثلُ الجنة وقوله تعالى : { تَجْرِى مِن تَحْتِهَا الأنهار } تفسير لذلك المثَل على أنه حالٌ من الضمير المحذوف من الصلة العائدِ إلى الجنة أي وعدها وهو الخبرُ عند غيره ،  كقولك : شأنَ زيد يأتيه الناسُ ويعظمونه أو على حذف موصوفٍ أي مثلُ الجنة جنةٌ تجري الخ { أُكُلُهَا } ثمرُها { دَائِمٌ } لا ينقطع { وِظِلُّهَا } أيضاً كذلك لا تنسخه الشمسُ كما تنسخ ظلالَ الدنيا { تِلْكَ } الجنة المنعوتةُ بما ذكر { عقبى الذين اتقوا } الكفرَ والمعاصيَ أي ما لهم ومنتهى أمرِهم { وعُقْبَى الكافرين النار } لا غيرُ ،  وفيه ما لا يخفى من إطماع المتقين وإقناطِ الكافرين .  <br />
