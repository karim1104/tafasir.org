{ استكبارا فِي الأرض } بدلٌ من نُفوراً أي مفعولٌ له { وَمَكْرَ السيئ } أصلُه وإنْ مكرُوا السَّيئَ أي المكرَ السَّيئ ثم ومكراً السَّيئَ ثم ومكرَ السيئ وقرئ بسكونِ الهمزةِ في الوصلِ ولعلَّه اختلاسٌ ظُنَّ سُكوتاً أو وقفةٌ خفيفةٌ وقرئ مكراً سيِّئاً { وَلاَ يَحِيقُ المكر السيئ إِلاَّ بِأَهْلِهِ فَهَلْ يَنظُرُونَ } أي ما ينتظرونَ { إِلاَّ سُنَّةَ الأوَّلِينَ } أي سُنَّة الله فيهم بتعذيبِ مكذِّبيهم { فَلَن تَجِدَ لِسُنَّةِ الله تَبْدِيلاً } بأنْ يضع موضعَ العذابِ غيرَ العذابِ { وَلَن تَجِدَ لِسُنَّةِ الله تَحْوِيلاً } بأنْ ينقله من المكذِّبين إلى غيرِهم .   والفاءُ لتعليلِ ما يُفيدُه الحكمُ بانتظارِهم العذابَ من مجيئهِ ونفيُ وجدانِ التَّبديلِ والتَّحويلِ عبارةٌ عن نفيِ وجودِها بالطَّريقِ البُرهانِّي وتخصيصُ كلَ منُهما بنفيٍ مستقلَ لتأكيدِ انتفائِهما .  <br />
