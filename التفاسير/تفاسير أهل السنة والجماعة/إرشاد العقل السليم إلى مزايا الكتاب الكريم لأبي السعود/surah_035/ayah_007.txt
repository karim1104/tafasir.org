{ الذين كَفَرُواْ لَهُمْ } بسببِ كفرِهم وإجابتِهم لدعوةِ الشَّيطانِ واتِّباعِهم لخطواتِه { عَذَابٌ شَدِيدٌ } لا يُقَادر قَدُره مديدٌ لا يُبلغ مداهُ { والذين آمَنُواْ وَعَمِلُواْ الصالحات لَهُم } بسببِ ما ذُكر من الإيمانِ والعملِ الصَّالحِ الذي من جُملتِه عداوةُ الشِّيطانِ { مَغْفِرَةٌ } عظيمةٌ { وَأَجْرٌ كَبِيرٌ } لا غايةَ لهما .  <br />
