{ وَقَالَ الذين كَفَرُواْ لَن نُّؤْمِنَ بهذا القرآن وَلاَ بالذي بَيْنَ يَدَيْهِ } أي من الكتبِ القديمةِ الدَّالَّةِ على البعث وقيل : إنَّ كُفَّار مكَّةَ سألُوا أهلَ الكتابِ عن رسولِ الله صلى الله عليه وسلم فأخبرُوهم أنَّهم يجدون نعتَهُ في كتبهم فغضبُوا فقالُوا ذلكَ وقيل : الذي بين يديه القيامة { وَلَوْ تَرَى إِذِ الظالمون } المنكرون للبعث { مَوْقُوفُونَ عِندَ رَبّهِمْ } أي في موقفِ المحاسبة { يَرْجِعُ بَعْضُهُمْ إلى بَعْضٍ القول } أي يتحاورونَ ويتراجعون القولَ { يَقُولُ الذين استضعفوا } بدل من يرجع الخ أي يقول الأتباع { لِلَّذِينَ استكبروا } في الدُّنيا واستتبعوهم في الغيِّ والضَّلالِ { لَوْلاَ أَنتُمْ } أي لولا إضلالُكم وصدُّكم لنا عن الإيمانِ { لَكُنَّا مُؤْمِنِينَ } باتباع الرَّسولِ عليه الصَّلاةُ والسَّلامُ<br />
