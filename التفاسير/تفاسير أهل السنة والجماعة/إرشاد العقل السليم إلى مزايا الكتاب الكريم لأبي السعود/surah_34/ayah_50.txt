{ قُلْ إِن ضَلَلْتُ } عن الطَّريقِ الحقِّ { فَإِنَّمَا أَضِلُّ على نَفْسِي } فإنَّ وبالَ ضلالِي عليها لأنَّه بسببها إذ هيَ الجاهلةُ بالذَّاتِ والأمَّارةُ بالسُّوءِ وبهذا الاعتبارِ قُوبل الشَّرطيةُ بقولِه تعالى : { وَإِنِ اهتديت فَبِمَا يُوحِي إِليَّ رَبّي } لأنَّ الاهتداءَ بهدايتِه وتوفيقِه .   وقرئ ربِّيَ بفتح الياء { إِنَّهُ سَمِيعٌ قَرِيبٌ } يعلم قولَ كلَ من المُهتدي والضَّالِّ وفعلَه وإنْ بالغَ في إخفائِهما .  <br />
