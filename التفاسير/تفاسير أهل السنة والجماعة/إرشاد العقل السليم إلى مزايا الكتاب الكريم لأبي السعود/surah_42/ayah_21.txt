{ أَمْ لَهُمْ شُرَكَاء } أي بلْ ألهُم شركاءُ من الشياطينِ ،  والهمزةُ للتقرير والتقريعِ { شَرَعُوا لَهُمْ } بالتسويل { منَ الدين مَا لَمْ يَأْذَن بِهِ الله } كالشرك وإنكارِ البعثِ والعملِ للدُّنيا ،  وقيلَ : شركاؤُهم أوثانُهم وإضافتُها إليهم لأنَّهم الذينَ جعلُوها شركاءَ لله تعالَى وإسنادُ الشرعِ إليها لأنَّها سببُ ضلالتِهم وافتتانِهم كقوله تعالى : { إِنَّهُنَّ أَضْلَلْنَ كَثِيرًا }[ سورة إبراهيم ،  الآية 36 ] أو تماثيلُ مَنْ سنَّ الضلالَة لهُم { وَلَوْلاَ كَلِمَةُ الفصل } أي القضاءِ السابقِ بتأخيرِ الجزاءِ أو العدةُ بأنَّ الفصلَ يكونُ يومَ القيامةِ { لَقُضِيَ بَيْنَهُمْ } أي بين الكافرينَ والمؤمنينَ أو بينَ المشركينَ وشركائِهم { وَإِنَّ الظالمين لَهُمْ عَذَابٌ أَلِيمٌ } وقُرِئ بالفتحِ عطفاً على كلمة الفصلِ أي ولولا كلمةُ الفصلِ وتقديرُ عذابِ الظالمينَ في الآخرةِ لقُضيَ بينهم في الدُّنيا فإنَّ العذابَ الأليمَ غالبٌ في عذابِ الآخرةِ .
