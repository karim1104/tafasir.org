{ والذين كَفَرُواْ لَهُمْ نَارُ جَهَنَّمَ لاَ يقضى عَلَيْهِمْ } لا يُحكم عليهم بموتٍ ثانٍ { فَيَمُوتُواْ } ويستريحُوا .   ونصبُه بإضمارِ أنْ وقرئ فيموتونَ عطفاً على يقضي كقوله تعالى : { وَلاَ يُؤْذَنُ لَهُمْ فَيَعْتَذِرُونَ } [ سورة المرسلات ،  الآية36 ] { وَلاَ يُخَفَّفُ عَنْهُمْ مّنْ عَذَابِهَا } بل كلَّما خبتْ زيد إسعارُها { كذلك } أي مثلَ ذلكَ الجزاءِ الفظيعِ { نَجْزِي كُلَّ كَفُورٍ } مبالغٍ في الكفرِ أو الكفرانِ لا جزاء أخف وأدنى منه .   وقرئ يُجزى على البناءِ للمفعولِ وإسناده إلى الكلِّ وقرئ يجازى .
