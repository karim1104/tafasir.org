{ ونادى أصحاب الأعراف } كرر ذكرهم مع كفاية الإضمار لزيادة التقرير { رِجَالاً } من رؤساء الكفارِ حين رأَوْهم فيما بين أصحابِ النار { يَعْرِفُونَهُمْ بسيماهم } الدالةِ على سوء حالِهم يومئذ وعلى رياستهم في الدنيا { قَالُوا } بدلٌ من نادى { مَا أغنى عَنكُمْ } ( ما ) استفهامية للتوبيخ والتقريع أو نافية { جَمْعُكُمْ } أي أتباعُكم وأشياعُكم أو جمعُكم للمال { وَمَا كُنتُمْ تَسْتَكْبِرُونَ } ما مصدريةٌ أي ما أغنى عنكم جمعُكم واستكبارُكم المستمرُّ عن قَبول الحقِّ ،  أو على الخلق وهو الأنسبُ بما بعده ،  وقرئ تستكثرون من الكثرة أي من الأموال والجنود .  <br />
