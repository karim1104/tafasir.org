{ يُعَذّبُ } أي بعد النَّشأةِ الآخرةِ { مَن يَشَاء } أن يعذبه وهم المنكرون لها حَتماً { وَيَرْحَمُ مَن يَشَاء } أنْ يرحمَه وهم المصدِّقُون بها والجملةُ تكملة لما قبلها .   وتقديمُ التَّعذيبِ لما أنَّ التَّرهيبَ أنسبُ بالمقام من الترَّغيبِ { وَإِلَيْهِ تُقْلَبُونَ } عند ذلك لا إلى غيرهِ فيفعلُ بكم ما يشاءُ من التَّعذيبِ والرَّحمةِ<br />
