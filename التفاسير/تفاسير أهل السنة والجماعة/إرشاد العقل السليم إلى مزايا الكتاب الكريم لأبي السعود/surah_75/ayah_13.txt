{ ينبأُ الإنسان يَوْمَئِذِ } أيْ يُخبرُ كلُّ امرئ براً كانَ أو فاجراً عندَ وزنِ الأعمالِ { بِمَا قَدَّمَ } أيْ عملَ منْ عملٍ خيراً كانَ أو شراً فيثابُ بالأولِ ويعاقبُ بالثاني { وَأَخَّرَ } أيْ لَمْ يعملْ خيراً كانَ أو شراً فيعاقبُ بالأولِ ويثابُ بالثانِي أو بما قدمَ منْ حسنةٍ أوْ سيئةٍ وبما أخَّر منْ سنةٍ حسنةٍ أوْ سيئةٍ فعملَ بَها بعدَهُ أو بما قدمَ منْ مالٍ تصدقَ بهِ في حياتِه وبما أخَّر فخلفَهُ أو وقفَهُ أو أوْصَى بهِ أو بأولِ عملِه وآخرِه .  <br />
