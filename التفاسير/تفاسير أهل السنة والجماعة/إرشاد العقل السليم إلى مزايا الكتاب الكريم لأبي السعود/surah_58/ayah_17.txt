{ لَن تُغْنِي عَنْهُمْ أموالهم وَلاَ أولادهم منَ الله } أي منْ عذابِه تَعَالى { شَيْئاً } منَ الإغناءِ  ، رُوي أنَّ رجلاً منهم قالَ : لنُنصَرَنَّ يومَ القيامَةِ بأنفسنا وأموالِنا وأولادِنا { أولئك } الموصوفونَ بما ذكرَ منَ الصفاتِ القبيحةِ { أصحاب النار } أيْ ملازمُوهَا ومقارنُوهَا { هُمْ فِيهَا خالدون } لا يخرجونَ منها أبداً .  <br />
