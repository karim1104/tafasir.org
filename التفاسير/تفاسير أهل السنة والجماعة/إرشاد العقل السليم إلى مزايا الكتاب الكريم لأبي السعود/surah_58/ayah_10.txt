{ إِنَّمَا النجوى }المعهودةُ التِي هِيَ التناجِي بالإثمِ وَالعدوانِ{ مِنَ الشيطان } لاَ مِنْ غَيْرِهِ  ، فإنَّه المزينُ لَها والحاملُ عَليهَا وقولِهِ تَعَالى : { لِيَحزنَ الذين آمَنُوا } خبرٌ آخرُ أيْ إنَّما هِيَ ليحزنَ المؤمنينَ بتوهمهمْ أنَّها فِي نكبةٍ أصابتهُمْ { وَلَيْسَ بِضَارّهِمْ } أي الشيطانُ أو التناجِي بضارِّ المؤمنينَ { شَيْئاً } مِنَ الأشياءِ أو شيئاً منَ الضررِ { إِلاَّ بِإِذْنِ الله } أيْ بمشيئتِه{ وَعَلَى الله فَلْيَتَوَكَّلِ المؤمنون }ولا يبالُوا بنجواهُم فإنَّه تعالى يعصمُهم منْ شرِّهِ وضرِّهِ .  <br />
