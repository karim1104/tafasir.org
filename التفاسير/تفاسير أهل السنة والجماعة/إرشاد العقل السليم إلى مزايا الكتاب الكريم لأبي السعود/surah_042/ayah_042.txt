{ إِنَّمَا السبيل عَلَى الذين يَظْلِمُونَ الناس } يبتدئونَهُم بالإضرارِ أوْ يعتدونَ في الانتقامِ .   { وَيَبْغُونَ فِي الأرض بِغَيْرِ الحق } أيْ يتكبرونَ فيَها تجبُّراً وفساداً { أولئك } الموصوفونَ بما ذُكِرَ من الظُّلمِ والبغيِ بغيرِ الحقِّ { لَهُمْ عَذَابٌ أَلِيمٌ } بسببِ ظُلمهم وبغيِهم .  <br />
