وذلك قولُه تعالى { فَأَوْحَيْنَا إلى مُوسَى أَنِ اضرب بّعَصَاكَ البحر } القُلزمِ أو النِّيلَ { فانفلق } الفاء فصيحةٌ أي فضربَ فانفلق فصارَ اثني عشر فِرقاً بعددِ الأسباطِ بينهنّ مسالكُ { فَكَانَ كُلُّ فِرْقٍ } حاصلٍ بالانفلاق { كالطود العظيم } كالجبلِ المُنيف الثَّابتِ مقرِّه فدخلُوا في شعابِها ،  كلُّ سِبْطٍ في شعبٍ منها .  <br />
