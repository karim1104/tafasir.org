{ وجنات وَعُيُونٍ إِنّي أَخَافُ عَلَيْكُمْ } إنْ لم تقوموا بشكرِ هذهِ النِّعم { عَذَابَ يَوْمٍ عَظِيمٍ } في الدُّنيا والآخرةِ فإنَّ كُفران النِّعمةِ مستتبعٌ للعذاب كما أنَّ شكرَها مستلزمٌ لزيادتِها قال تعالى : { لَئِن شَكَرْتُمْ لأزِيدَنَّكُمْ وَلَئِن كَفَرْتُمْ إِنَّ عَذَابِي لَشَدِيدٌ } [ سورة إبراهيم ،  الآية7 ] .
