{ وَكَأَين من قَرْيَةٍ } أي كثيرٌ من أهلِ قريةٍ { عَتَتْ } أي أعرضتْ { عَنْ أَمْرِ رَبّهَا وَرُسُلِهِ } بالعُتوِّ والتمردِ والعنادِ { فحاسبناها حِسَاباً شَدِيداً } بالاستقصاءِ والتنفيرِ والمناقشةِ في كلِّ نقيرٍ وقِطْميرٍ { وعذبناها عَذَاباً نُكْراً } أي مُنكراً عظيماً .   وقُرِئَ نكراً ،  والمرادُ حسابُ الآخرةِ وعذابُها ،  والتعبيرُ عنهما بلفظِ الماضِي للدلالةِ على تحققِهِما كما في قولِه تعالَى : { وَنَادَى أصحاب الجنة }[ سورة الأعراف ،  الآية 44 ] .
