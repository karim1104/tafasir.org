{ ذلك } أي ما ذُكِرَ من التعسِ وإضلالِ الأعمالِ { بِأَنَّهُمْ } بسببِ أنَّهم { كَرِهُوا مَا أَنزَلَ الله } من القرآنِ لما فيهِ من التوحيدِ وسائرِ الأحكامِ المخالفةِ لما ألِفُوه واشتهتْهُ أنفسُهم الأمارةُ بالسُّوءِ { فَأَحْبَطَ } لأجلِ ذلكَ { أعمالهم } التي لو كانُوا عملوها مع الإيمان لأُثيبُوا عليَها .  <br />
