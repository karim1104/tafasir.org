{ وَمِنْ آياته أَنَّكَ تَرَى الأرض خاشعة } يابسةً متطامنةً مستعارٌ من الخشوع بمعنى التذللِ { فَإِذَا أَنزَلْنَا عَلَيْهَا الماء } أي المطرَ { اهتزت وَرَبَتْ } أي تحركتْ بالنبات وانتفختْ ،  لأنَّ النبتَ إِذَا دَنا أنْ يظهرَ ارتفعتْ له الأرضُ وانتفختْ ثم تصدعتْ عن النباتِ ،  وقيلَ : تزخرفتْ بالنباتِ .   وقُرئ رَبَأَتْ أي ارتفعتْ { إِنَّ الذي أحياها } بما ذُكِرَ بعدَ موتِها { لَمُحْييِ الموتى } بالبعث { أَنَّهُ على كُلّ شَيْء } من الأشياءِ التي منْ جُملتها الإحياءُ { قَدِيرٌ } مبالغٌ في القُدرة .  <br />
