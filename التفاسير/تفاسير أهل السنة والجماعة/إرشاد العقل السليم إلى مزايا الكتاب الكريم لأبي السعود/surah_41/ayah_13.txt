{ فَإِنْ أَعْرَضُواْ } متصلٌ بقولِه تعالَى : { قُلْ أَئِنَّكُمْ } [ سورة السجدة ،  الآية9 ] الخ أي فإنْ أعرضُوا عن التدبرِ فيما ذُكِرَ من عظائمِ الأمورِ الداعيةِ إلى الإيمانِ أو عن الإيمانِ بعد هذا البيانِ { فَقُلْ } لهم { أَنذَرْتُكُمْ } أي أنذركُم وصيغةُ الماضِي للدلالةِ على تحقيقِ الإنذارِ المنبئ عن تحقيقِ المنذَرِ به { صاعقة } أي عذاباً هائلاً شديدَ الوقع كأنه صاعقةٌ { مثْلَ صاعقة عَادٍ وَثَمُودَ } وقُرِئ صعقةً مثلَ صعقةِ عادٍ وثمودٍ{[708]} وهي المرةُ من الصعْقِ أو الصَّعَقُ يقالَ صعقتْهُ الصاعقةُ صعْقاً فصَعِقَ صعْقاً وهو من باب فعلته فَفَعِلَ
