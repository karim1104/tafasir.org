{ الله الذي يُرْسِلُ الرياح } استئنافٌ مسوقٌ لبيانِ ما أُجمل فيما سبقَ من أحوالِ الرِّياحِ { فَتُثِيرُ سَحَاباً فَيَبْسُطُهُ } متصلاً تارةً { فِي السماء } في جوِّها { كَيْفَ يَشَاء } سائراً وواقفاً مُطبقاً وغيرَ مطبقٍ من جانبٍ دون جانبٍ إلى غيرِ ذلك .   { وَيَجْعَلُهُ كِسَفاً } تارةً أُخرى أي قِطعاً .   وقرئ بسكونِ السِّينِ على أنَّه مخففٌ ،  جمعُ كِسْفة أو مصدرٌ وصفَ به { فَتَرَى الودق } المطرَ { يَخْرُجُ مِنْ خِلاَلِهِ } في التارتين .   { فَإِذَا أَصَابَ بِهِ مَن يَشَاء مِنْ عِبَادِهِ } أي بلادَهم وأراضيَهم { إِذَا هُمْ يَسْتَبْشِرُونَ } فاجؤا الاستبشارَ بمجيء الخِصْبِ<br />
