{ فَأَقِمْ وَجْهَكَ لِلدّينَ القيم } أي البليغِ الاستقامة { مِن قَبْلِ أَن يَأْتِيَ يَوْمٌ لا مَرَدَّ لَهُ } لا يقدرُ أحدٌ على ردِّه { مِنَ الله } متعلق بيأتِي أو بمردِّ لأنه مصدرٌ والمعنى لا يردُّه الله تعالى لتعلُّقِ إرادتِه القديمةِ بمجيئِه { يَوْمَئِذٍ يَصَّدَّعُونَ } أصله يتصدَّعون أي يتفرَّقُون فريقٌ في الجَّنةِ وفريقٌ في السَّعيرِ .  <br />
