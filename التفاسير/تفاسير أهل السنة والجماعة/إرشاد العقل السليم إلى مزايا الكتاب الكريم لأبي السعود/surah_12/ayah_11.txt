فقيل : { قَالُواْ يا أَبَانَا } خاطبوه بذلك تحريكاً لسلسلة النسبِ بينه وبينهم وتذكيراً لرابطة الأخوّة بينهم وبين يوسفَ عليه الصلاة والسلام ليتسببوا بذلك إلى استنزاله عليه السلام عن رأيه في حفظه منهم لمّا أحس منه بأمارات الحسد والبغي فكأنهم قالوا : { مَا لَكَ } أي أيُّ شيء لك { لاَ تَأْمَنَّا } أي لا تجعلنا أمناءَ { على يُوسُفَ } مع أنك أبونا ونحن بنوك وهو أخونا { وَإِنَّا لَهُ لناصحون } مريدون له الخيرَ ومشفقون عليه ليس فينا ما يُخلُّ بالنصيحة والمِقَة{[433]} قطُّ والقراءة المشهورةُ بالإدغام والإشمام .   وعن نافع رضي الله عنه تركُ الإشمام ومن الشواذ ترك الإدغام .
