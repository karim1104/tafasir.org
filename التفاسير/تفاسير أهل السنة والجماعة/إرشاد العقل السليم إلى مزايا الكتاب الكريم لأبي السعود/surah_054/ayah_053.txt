{ وَكُلُّ صَغِيرٍ وَكَبِيرٍ } من الأعمالِ { مُسْتَطرٌ } مسطورٌ في اللوحِ المحفوظِ بتفاصيلِه ،  ولما كانَ بيانُ سوءِ حالِ الكفرةِ بقولِه تعالى { إِنَّ المجرمين } الخ مِمَّا يستدعِي بيانَ حُسنِ حالِ المؤمنينَ ليتكافأَ الترهيبُ والترغيبُ بيّن ما لَهُم من حسنِ الحالِ بطريقِ الإجمالِ فقيلَ : { إِنَّ المتقين } بالإيمانِ .  <br />
