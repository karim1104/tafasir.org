{ وَلَوْلا أَن تُصِيبَهُم مُّصِيبَةٌ } أي عقوبةٌ { بِمَا قَدَّمَتْ أَيْدِيهِمْ } أي بما اقترفُوا من الكفرِ والمعَاصي { فَيَقُولُواْ } عطفٌ على تُصيبَهم داخلٌ في حيِّزِ لولا الامتناعيَّةِ على أنَّ مدارَ انتفاءِ ما يُجاب به هو امتناعُه لا امتناعُ المعطُوفِ عليه وإنما ذكرَه في حيِّزِها للإيذانِ بأنَّه السببُ الملجئُ لهم إلى قولِهم : { رَبَّنَا لَوْلا أَرْسَلْتَ إِلَيْنَا رَسُولاً } أي هلاَّ أرسلتَ إلينا رسولاً مؤيداً مِن عندك بالآياتِ { فَنَتَّبِعَ آياتك } الظَّاهرةَ على يدِه وهو جوابُ لولا الثَّانيةِ { وَنَكُونَ مِنَ المؤمنين } بهَا وجوابُ لولا الأُولى محذوفٌ ثقةً بدلالةِ الحالِ عليهِ والمَعْنى لولا قولُهم هذا عندَ إصابةِ عقوبةِ جناياتِهم التي قدَّمُوها ما أرسلناكَ لكن لمَّا كانَ قولُهم ذلكَ محقَّقاً لا محيدَ عنه أرسلناك قطعاً لمعاذيرِهم بالكُلِّيةِ<br />
