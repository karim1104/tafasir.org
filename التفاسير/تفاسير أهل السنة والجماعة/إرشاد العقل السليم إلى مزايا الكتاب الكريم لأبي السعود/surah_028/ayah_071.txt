{ قُلْ } تقريراً لما ذُكر { أَرَأيْتُمْ } أي أخبرونِي { إِن جَعَلَ الله عَلَيْكُمُ اللَّيْلَ سَرْمَداً } دائماً من السَّرد وهو المتابعةُ والاطِّرادِ والميمُ مزيدةٌ كما في دلامص من الدِّلاص يقال : درع دلاصٌ أي ملساءُ لينةٌ { إلى يَوْمِ القيامة } بإسكانِ الشَّمس تحت الأرضِ أو تحريكها حول الأُفقِ الغائر { مَّنْ إله غَيْرُ الله } صفةٌ لإله { يَأْتِيكُمْ بِضِيَاء } صفةٌ أخرى لها عليها يدورُ أمرُ التبكيتِ والإلزامِ كما في قوله تعالى : { قُلْ مَن يَرْزُقُكُم مّنَ السماء والأرض } [ سورة يونس ،  الآية31 ] وقوله تعالى : { فَمَن يَأْتِيكُمْ بِمَاء مَّعِينٍ } [ سورة الملك ،  الآية30 ] ونظائرِهما خلا أنَّه قُصدَ بيانُ انتفاءِ الموصوفِ بانتفاءِ الصِّفة ولم يُقَل : هل إله الخ لإيرادِ التَّبكيت والإلزامِ على زعمِهم .   وقرئ بضئاءٍ بهمزتينِ { أَفَلاَ تَسْمَعُونَ } هذا الكلامَ الحقَّ سماعَ تدبُّرٍ واستبصارٍ حتَّى تُذعنوا له وتعملوا بموجبِه .
