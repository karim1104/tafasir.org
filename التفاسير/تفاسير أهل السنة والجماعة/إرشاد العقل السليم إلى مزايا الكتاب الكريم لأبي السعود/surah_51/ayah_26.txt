{ فَرَاغَ إلى أَهْلِهِ } أيْ ذهبَ إليهمْ عَلى خُفيةٍ منْ ضيفِه فإنَّ منْ أدبِ المضيفِ أنْ يبادَرهُ بالقِرى ويبادرَ بهِ حذاراً مِنْ أن يكفَهُ ويعذَرهُ أو يصيرَ مُنتْظراً والفاءُ في قولِه تعالَى : { فَجَاء بِعِجْلٍ سَمِينٍ } فصيحةٌ مفصحةٌ عنْ جُمَلٍ قَدْ حُذفتْ ثقةً بدلالةِ الحالِ عَلَيْها وإيذاناً بكمالِ سرعةِ المجيء بالطعامِ كما في قولِه تعالَى : { أَنِ اضرب بعَصَاكَ البحر فانفلق } [ سورة الشعراء ؛ الآية : 63 ] أيْ فذبحَ عجلاً فحنذَهُ فجاءَ بهِ{ فَقَرَّبَهُ إِلَيْهِمْ } .
