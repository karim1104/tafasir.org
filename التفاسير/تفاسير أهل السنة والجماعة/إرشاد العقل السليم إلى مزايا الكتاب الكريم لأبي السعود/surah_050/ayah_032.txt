{ هذا مَا تُوعَدُونَ } إشارةٌ إِلى الجَنَّةِ ،  والتذكيرُ لَمَا أنَّ المشارَ إليهِ هُوَ المُسمَّى منْ غيرِ أنْ يخطرَ بالبالِ لفظٌ يدلُّ عليهِ فضلاً عنْ تذكيرِه وتأنيثِه فإنَّهُمَا منْ أحكامِ اللفظِ العربيِّ كَما مرَّ في وقولِه تعالَى : { فَلَماَّ رَأَى الشمس بَازِغَةً قَالَ هذا رَبّي } [ سورة الأنعام ؛ الآية : 78 ] وقولُه تعالَى : { وَلَمَّا رَأَى المؤمنون الأحزاب قَالُوا هذا مَا وَعَدَنَا الله وَرَسُولُهُ } [ سورة الأحزاب ؛ الآية : 22 ] ويجوزُ أنْ يكونَ ذلكَ لتذكيرِ الخبرِ ،  وقيلَ : هُو إشارةٌ إلى الثوابِ وقيلَ : إلى مصدرِ أزلفتْ وقُرِئ يُوعَدُونَ والجملةُ إمَّا اعتراضٌ بينَ البدلِ والمبدلِ مِنْهُ وإمَّا مقدرٌ بقولٍ هُوَ حالٌ منَ المتقينَ أو منَ الجنَّةِ والعاملُ أزلفتْ أيْ مقولاً لهُمْ أو مقولاً في حَقِّها هَذا ما توعدونَ { لِكُلّ أَوَّابٍ } أيْ رجّاع إلى الله تعالَى بدلٌ منْ المتقينَ بإعادةِ الجارِّ { حَفِيظٌ } حافظٌ لتوبتةِ من النقضِ وقيلَ : هُوَ الذَّي يحفظُ ذنوبَهُ حتَّى يرجعَ عنْهَا ويستغفرَ مِنْها وقيلَ : هُو الحافظُ لأوامرِ الله تعالَى وقيلَ : لِمَا استودَعَهُ الله تعالَى مِنْ حقوقِها .
