{ وَلِكُلّ أُمَّةٍ } من الأمم الخالية { رسُولٌ } يُبعث إليهم بشريعة خاصةٍ مناسبة لأحوالهم ليدعُوَهم إلى الحق { فَإِذَا جَاء رَسُولُهُمْ } فبلغهم ما أُرسل به فكذبوه وخالفوه { قُضِىَ بَيْنَهُمْ } أي بين كلِّ أمةٍ ورسولِها { بالقسط } بالعدل وحُكم بنجاة الرسول والمؤمنين به وإهلاك المكذِبين كقوله تعالى : { وَمَا كُنَّا مُعَذّبِينَ حتى نَبْعَثَ رَسُولاً } [ الإسراء : 15 ] { وَهُمْ لاَ يُظْلَمُونَ } في ذلك القضاءِ المستوجِب لتعذبهم لأنه من نتائج أعمالِهم أو ولكل أمةٍ من الأمم يوم القيامةِ رسولٌ تُنسَبُ إليه وتدعى به فإذا جاء رسولُهم الموقفَ ليشهدَ عليهم بالكفر والإيمان كقوله عز وجل : { وجيء بالنبيين والشهداء وَقُضِىَ بَيْنَهُمْ } [ الزمر : 69 ] .
