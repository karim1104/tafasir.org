{ وَإِذْ قَالَ لُقْمَانُ لابْنِهِ } أنعمَ وقيل أشكمَ وقيل ماثانَ { وَهُوَ يَعِظُهُ يا بني } تصغيرُ إشفاقٍ .   وقرئ يا بنيْ بإسكانِ الياءِ وبكسرِها { لاَ تُشْرِكْ بالله } قيل : كانَ ابنُه كافراً فلم يزلْ به حتَّى أسلم ومن وقفَ على لا تُشركْ جعلَ بالله قسماً { إِنَّ الشرك لَظُلْمٌ عَظِيمٌ } تعليلٌ للنَّهي أو للانتهاءِ عن الشِّركِ<br />
