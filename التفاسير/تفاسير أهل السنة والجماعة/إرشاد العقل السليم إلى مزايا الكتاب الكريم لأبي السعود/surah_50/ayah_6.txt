{ أَفَلَمْ يَنظُرُوا } أيْ أغفلُوا أو أَعمُوا فلمْ ينظرُوا { إِلَى السماء فَوْقَهُمْ } بحيثُ يشاهدونَها كلَّ وقتٍ { كَيْفَ بنيناها } أيْ رفعناهَا بغيرِ عمدٍ { وزيناها } بمَا فيهَا منَ الكواكبِ المرتبةِ على نظامٍ بديعٍ { وَمَا لَهَا مِن فُرُوجٍ } منْ فتوقٍ لملاستِها وسلامتِها من كُلِّ عيبٍ وخللٍ ،  ولعل تأخيرَ هَذا لمراعاةِ الفواصلِ .  <br />
