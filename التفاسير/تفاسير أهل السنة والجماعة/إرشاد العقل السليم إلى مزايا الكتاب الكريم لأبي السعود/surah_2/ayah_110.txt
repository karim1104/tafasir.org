{ وأقيموا الصلاة وآتوا الزكاة } عطفٌ على ( فاعفوا ) أُمروا بالصبر والمداراةِ واللَّجَإ إلى الله تعالى بالعبادة البدنية والمالية { وَمَا تُقَدّمُواْ لأنْفُسِكُم منْ خَيْرٍ } كصلاة أو صدقةٍ أو غيرِ ذلك أيْ أيُّ شيءٍ من الخيرات تقدّموه لمصلحة أنفسِكم { تَجِدُوهُ عِندَ الله } أي تجدوا ثوابه وقرئ ( تُقْدِموا ) من أقدم { إِنَّ الله بِمَا تَعْمَلُونَ بَصِيرٌ } فلا يَضيعُ عنده عملٌ فهو وعدٌ للمؤمنين ،   وقرئ بالياء فهو وعيدٌ للكافرين .  <br />
