{ واتقوا } إن لم تؤمنوا { يَوْمًا لاَ تَجْزِي } في ذلك اليوم { نَفْسٌ } من النفوس { عَن نفْسٍ } أخرى { شَيْئاً } من الأشياء أو شيئاً من الجزاء { وَلاَ يُقْبَلُ مِنْهَا عَدْلٌ } أي فدية { وَلاَ تَنفَعُهَا شفاعة وَلاَ هُمْ يُنصَرُونَ } وتخصيصُهم بتكرير التذكيرِ وإعادةِ التحذير للمبالغة في النُصحِ ،   وللإيذان بأن ذلك فذلكةُ القضية والمقصودُ من القصة لِما أن نعمَ الله عز وجل عليهم أعظمُ وكفرَهم بها أشدُّ وأقبحُ .  <br />
