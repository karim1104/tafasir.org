{ وقاتلوهم حتى لاَ تَكُونَ فِتْنَةٌ } أي شِرْكٌ { وَيَكُونَ الدين للَّهِ } خالصاً ليس للشيطان فيه نصيب { فَإِنِ انْتَهَوْاْ } بعد مقاتَلتِكم عن الشِّرك { فَلاَ عدوان إِلاَّ عَلَى الظالمين } أي فلا تعتَدوا عليهم إذ لا يحسُن الظلمُ إلا لمن ظَلَم ،   فوضعُ العلة موضعَ الحُكم وتسميةُ الجزاءِ بالعُدوان للمشاكلة كما في قوله عز وجل : { فَمَنِ اعتدى عَلَيْكُمْ فاعتدوا عَلَيْهِ } [ البقرة : 195 ] أو إنكم إنْ تعرَّضتم للمنتهين صِرْتم ظالمين وتنعكس الحالُ عليكم ،   والفاءُ الأولى للتعقيب والثانيةُ للجزاء .
