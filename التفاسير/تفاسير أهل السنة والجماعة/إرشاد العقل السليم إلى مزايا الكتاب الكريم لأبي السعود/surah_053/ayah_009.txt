{ فَكَانَ } أي مقدارُ امتدادِ ما بينَهما { قَابَ قَوْسَيْنِ } أي مقدارَهُما فإنَّ القابَ والقِيْبَ والقادَ والقِيْدَ والقِيْسَ المقدارُ ،  وقيلَ : فكانَ جبريلُ عليهِ السَّلامُ كَما في قولكَ هو مِنِّي معقدُ الإزارِ .   { أَوْ أدنى } أيْ عَلى تقديرِكم كَما في قولِه تعالى : { أَوْ يَزِيدُونَ } [ سورة الصافات ،  الآية 147 ] والمرادُ تمثيلُ ملَكةِ الاتصالِ وتحقيقُ استماعِه لما أُوحيَ إليه بنفِي البُعدِ المُلبسِ .
