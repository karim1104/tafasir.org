أي وكثيرٌ من أهلِ قريةٍ كانت حالُهم كحالِ هؤلاءِ في الأمنِ وخفضِ العيشِ والدَّعةِ حتَّى أشِرُوا فدمَّرنا عليهم وخرَّبنا ديارَهم { فَتِلْكَ مساكنهم } خاويةٌ بما ظلمُوا { لَمْ تُسْكَن مّن بَعْدِهِمْ } من بعدِ تدميرِهم { إِلاَّ قَلِيلاً } أي إلا زماناً قليلاً إذْ لا يسكنُها إلا المارَّةُ يوماً أو بعضَ يومٍ أو لم يبقَ من يسكنُها إلا قليلاً من شؤمِ معاصيِهم { وَكُنَّا نَحْنُ الوارثين } منهم إذ لم يخلفهم أحدٌ يتصرَّفُ تصرَّفَهم في ديارِهم وسائرِ ذاتِ أيديهم .   وانتصابُ معيشتَها بنزعِ الخافضِ أو بجعلِها ظرفاً بنفسِها كقولِك : زيدٌ ظنِّي مقيمٌ أو بإضمارِ زمانٍ مضافٍ إليه أو بجعلِه مفعولاً لبطرتْ بتضمينِ معنى كفرتْ<br />
