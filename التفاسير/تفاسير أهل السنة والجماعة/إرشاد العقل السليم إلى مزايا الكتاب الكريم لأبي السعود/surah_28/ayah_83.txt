{ تِلْكَ الدار الآخرة } إشارةُ تعظيمٍ وتفخيمٍ كأنَّه قيل تلك التي سمعتَ خبَرها وبلغَك وصفُها { نَجْعَلُهَا لِلَّذِينَ لاَ يُرِيدُونَ عُلُوّاً فِي الأرض } أي غلبةً وتسلطاً { وَلاَ فَسَاداً } أي ظُلماً وعدُواناً على العبادِ كدأبِ فرعونَ وقارونَ وفي تعليق الموعد بترك إرادتهما لا بتركِ أنفسهما مزيدُ تحذير منهما .   وعن عليَ رضي الله عنه أنَّ الرَّجلَ ليعجبه أنْ يكونَ شِراكُ نعلِه أجودَ من شراكَ نعلِ صاحبِه فيدخلُ تحتَها { والعاقبة } الحميدة { لّلْمُتَّقِينَ } أي الذين يتَّقون ما لا يرضاهُ الله من الأفعالِ والأقوالِ { مَن جَاء بالحسنة فَلَهُ } بمقابلتِها { خَيْرٌ مّنْهَا } ذاتاً ووصفاً وقدراً<br />
