{ فَلَمَّا أتاها } أي النَّارَ التي آنسَها { نُودِيَ مِن شَاطِئ الوادي الأيمن } أي أتاهُ النِّداءُ من الشاطئِ الأيمنِ بالنسبةِ إلى مُوسى عليهِ السَّلامُ { فِي البقعة المباركة } متصلٌ بالشَّاطئ أو صلةٌ لنُوديَ { مِنَ الشجرة } بدلُ اشتمالٍ من شاطئٍ لأنَّها كانتْ نابتةً على الشَّاطئِ { أَن يا موسى إِنّي أَنَا الله رَبُّ العالمين } وهذا وإنْ خالفَ لفظاً لما في طه والنَّملِ لكنَّه موافقٌ له في المَعنى المرادِ<br />
