{ يَدْعُوا مِن دُونِ الله } استئنافٌ مبيِّنٌ لعِظم الخُسرانِ أي يعبد مُتجاوزاً عبادةَ الله تعالى { مَا لاَ يَضُرُّهُ } إذا لم يعبدْهُ { وَمَا لاَ يَنفَعُهُ } إنْ عبدَهُ أي جماداً ليسَ من شأنِه النَّفعُ كما يُلوِّحُ به تكريرُ كلمةِ ما { ذلك } الدُّعاءُ { هُوَ الضلال البعيد } عن الحقِّ والهُدى مستعارٌ من ضلالِ مَن أبعدَ في التَّيهِ ضالاًّ عن الطَّريقِ .  <br />
