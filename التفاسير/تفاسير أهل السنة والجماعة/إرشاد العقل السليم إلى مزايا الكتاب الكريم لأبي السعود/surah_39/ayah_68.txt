{ وَنُفِخَ فِي الصور } هي النَّفخةُ الأولى { فَصَعِقَ مَن فِي السموات وَمَن فِي الأرض } أي خرُّوا أمواتاً أو مغشيّاً عليهم { إِلاَّ مَن شَاء الله } قيل : هم جبريلُ وميكائيلُ وإسرافيلُ فإنَّهم لا يموتُون بعد وقيل : حَمَلةُ العرشِ .   { ثُمَّ نُفِخَ فِيهِ أخرى } نفخةٌ أخرى هي النَّفخةُ الثَّانيةُ .   وأُخرى يحتملُ النَّصبَ والرَّفعَ .   { فَإِذَا هُمْ قِيَامٌ } قائمون من قبورِهم أو متوقفون .   وقرئ بالنَّصبِ على أنَّ الخبرَ { يُنظَرُونَ } وهو حالٌ من ضميرِه والمعنى يُقلِّبون أبصارَهم في الجوانبِ كالمبهوتينَ أو ينتظرون ما يفعل بهم .  <br />
