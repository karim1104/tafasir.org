{ أَمْ يَحْسَبُونَ } أي بلْ أيحسبونَ { أَنَّا لاَ نَسْمَعُ سِرَّهُمْ } وهو ما حدَّثُوا به أنفسَهُم أو غيرَهُم في مكانٍ خالٍ { ونجواهم } أي ما تكلمُوا به فيما بينهم بطريقِ التَّناجِي { بلى } نحن نسمعُهما ونطَّلِعُ عليهما { وَرُسُلُنَا } الذينَ يحفظونَ عليهم أعمالَهم ويلازمونَهم أينَما كانُوا { لَدَيْهِمْ } عندَهُم { يَكْتُبُونَ } أي يكتبونهما أو يكتبونَ كلَّ ما صدرَ عنهُم من الأفعالِ والأقوالِ التي من جُمْلتِها ما ذُكرَ من سرِّهم ونجواهم .   والجملةُ إما عطفٌ على ما يترجمُ عنْهُ بَلَى ،  أو حالٌ ،  أي نسمعُهما والحالُ أنَّ رسلَنا يكتبونَ<br />
