{ والذين جاهدوا فِينَا } أي في شأنِنا ولوجهِها خالصاً .   أطلقَ المُجاهدةَ ليعمَّ جهادَ الأعادِي الظاهرةِ والباطنةِ { لَنَهْدِيَنَّهُمْ سُبُلَنَا } سُبُلَ السَّيرِ إلينا والوصولِ إلى جنابِنا أو لنزيدنَّهم هدايةً إلى سُبُلِ الخيرِ وتوفيقاً لسلُوكها كقولِه تعالى : { والذين اهتدوا زَادَهُمْ هُدًى } [ سورة محمد ،  الآية17 ] وفي الحديثِ : ( من عَمِل بما عَلِم ورَّثه الله علمَ ما لم يعلَم ) { وَإِنَّ الله لَمَعَ المحسنين } معيةَ النَّصرِ والمعُونة .
