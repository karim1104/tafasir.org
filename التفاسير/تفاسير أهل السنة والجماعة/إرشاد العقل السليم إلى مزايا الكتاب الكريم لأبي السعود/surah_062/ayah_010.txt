{ فَإِذَا قُضِيَتِ الصلاة } أي أُدِّيتْ وفُرغَ منهَا { فانتشروا فِي الأرض } لإقامةِ مصالِحِكم { وابتغوا مِن فَضْلِ الله } أي الربحَ فالأمرُ للإطلاقِ بعدَ الحظرِ وعنِ ابنِ عباسٍ رضيَ الله عنهُمَا لَمْ يؤمُروا بطلبِ شيءٍ من الدُّنيا إنَّما هو عيادةُ المرضَى وحضورُ الجنائزِ وزيارةُ أخٍ في الله وعنِ الحسنِ وسعيدِ بنِ المسيِّبِ طلبُ العلمِ وقيلَ صلاةُ التطوعِ { واذكروا الله كَثِيراً } ذِكراً كثيراً أو زماناً كثيراً ولا تخصوا ذكرَهُ تعالَى بالصلاةِ { لَعَلَّكُمْ تُفْلِحُونَ } كي تفوزُوا بخيرِ الدارينِ .  <br />
