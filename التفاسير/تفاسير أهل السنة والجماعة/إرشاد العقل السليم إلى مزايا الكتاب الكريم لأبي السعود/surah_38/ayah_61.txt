{ قَالُواْ } أي الأتباعُ أيضاً وتوسيطُه بين كلاميهم لما بينهُما من التَّباينِ البيِّنِ ذاتاً وخِطِاباً أي قالُوا مُعرضين عن خصومتِهم متضرِّعين إلى الله تعالى { رَبَّنَا مَن قَدَّمَ لَنَا هذا فَزِدْهُ عَذَاباً ضِعْفاً فِي النار } كقولِهم { رَبَّنَا هَؤُلاء أَضَلُّونَا فَآتِهِمْ عَذَابًا ضِعْفًا منَ النار } [ سورة الأعراف ،  الآية38 ] أي عذاباً مُضاعفاً أي ذا ضعفٍ وذلك بأنْ يزيدَ عليه مثلَه ويكون ضعفينِ كقولِه { رَبَّنَا آتِهِمْ ضِعْفَيْنِ مِنَ العذاب } [ سورة الأحزاب ،  الآية68 ] وقيل : المرادُ بالضِّعفِ الحيَّاتُ والأَفَاعي .
