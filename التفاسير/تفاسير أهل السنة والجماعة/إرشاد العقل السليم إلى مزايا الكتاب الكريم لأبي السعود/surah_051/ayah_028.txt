{ فَأَوْجَسَ مِنْهُمْ } أضمرَ في نفسِه { خِيفَةً } لتوهمِ أنَّهم جاءُوا للشرِّ وقيلَ وقعَ في قلبِه أنَّهم ملائكةٌ جاءوا للعذابِ { قَالُوا لاَ تَخَفْ } قيلَ مسحَ جبريلُ عليهِ السلامُ العجلَ بجناحِه فقامَ يدرُجُ حتَّى لحقَ بأُمِّهِ فعرفَهُم وأمِنَ منهُم { وَبَشَّرُوهُ } وفي سورةِ الصافاتِ وبشرناهُ أيْ بواسطتِهم { بغلام } هو إسحاقُ عليهِ السَّلامُ { عَلِيمٌ } عند بلوغِه واستوائِه .  <br />
