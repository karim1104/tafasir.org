{ فتولى بِرُكْنِهِ } أيْ فأعرضَ عنِ الإيمانِ بهِ وازورّ كقولِه تعالَى : { وَنَأَى بِجَانِبِهِ } [ سورة الإسراء ؛ الآية : 83 وسورة فصلت ؛ الآية : 51 ] وقيلَ فتولَّى بما يتقوَّى بهِ منْ مُلْكِه وَعساكِره فإنَّ الركنَ اسمٌ لمَا يركنُ إليهِ الشيءُ وَقُرئ برُكُنِهِ بضمِّ الكافِ { وَقَالَ ساحر } أيْ هُو ساحرٌ { أَوْ مَجْنُونٌ } كأنَّه نسبَ ما ظهرَ على يديهِ عَلَيهِ الصَّلاةُ والسَّلامُ من الخوارقِ العجيبةِ إلى الجنِّ وترددَ في أنَّه حصل باختيارِه وسعيهِ أو بغيرِهما .
