{ فتنازعوا } أي السحرةُ حين سمعوا كلامَه عليه الصلاة والسلام كأن ذلك غاظهم فتنازعوا { أَمَرَهُمْ } الذي أريد منهم مِنْ مغالبته عليه الصلاة والسلام وتشاوروا وتناظروا { بَيْنَهُمْ } في كيفية المعارضةِ وتجاذبوا أهدابَ القول في ذلك { وَأَسَرُّواْ النجوى } أي من موسى عليه الصلاة والسلام لئلا يقِفَ عليه فيدافعَه
