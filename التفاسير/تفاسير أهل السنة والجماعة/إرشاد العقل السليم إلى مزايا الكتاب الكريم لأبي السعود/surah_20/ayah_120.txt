{ فَوَسْوَسَ إِلَيْهِ الشيطان } أي أنهى إليه وسوسته أو أسرها إليه { قَالَ } إما بدلٌ من وسوس أو استئنافً وقع جواباً عن سؤال نشأ منه ،  كأنه قيل : فماذا قال في وسوسته ؟ فقيل : قال : { يا آدم هَلْ أَدُلُّكَ على شَجَرَةِ الخلد } أيْ شجرةٍ مَنْ أكل منها خلّد ولم يمُت أصلاً سواءٌ كان عن حاله أو بأن يكون ملَكاً لقوله تعالى : { إِلا أَن تَكُونَا مَلَكَيْنِ أَوْ تَكُونَا مِنَ الخالدين } { وَمُلْكٍ لاَّ يبلى } أي لا يزول ولا يختلّ بوجه من الوجوه .  <br />
