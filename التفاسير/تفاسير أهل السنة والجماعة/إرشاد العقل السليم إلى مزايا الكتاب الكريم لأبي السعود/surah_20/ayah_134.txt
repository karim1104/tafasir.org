وقوله تعالى : { وَلَوْ أَنَّا أهلكناهم بِعَذَابٍ } إلى آخر الآية جملةٌ مستأنفةٌ سيقت لتقرير ما قبلها من كون القرآن آيةً بينةً لا يمكن إنكارُها ببيان أنهم يعترفون بها يوم القيامة ،  والمعنى لو أنا أهلكناهم في الدنيا بعذاب مستأصِل { مِن قَبْلِهِ } متعلقٌ بأهلكنا أو بمحذوف هو صفةٌ لعذاب أي بعذاب كائنٍ من قبل إتيانِ البينة أو قبلِ محمد عليه الصلاة والسلام { لَقَالُواْ } أي يوم القيامة { رَبَّنَا لَوْلا أَرْسَلْتَ إِلَيْنَا } في الدنيا { رَسُولاً } مع كتاب { فَنَتَّبِعَ آياتك } التي جاءنا بها { مِن قَبْلِ أَن نَّذِلَّ } بالعذاب في الدنيا { ونخزى } بدخول النار اليوم ولكنا لم نُهلكهم قبل إتيانِها فانقطعت معذِرتُهم فعند ذلك قالوا : بلى ،  قد جاءنا نذيرٌ فكذبنا وقلنا ما نزل الله من شيء .  <br />
