{ هُوَ الذي أَرْسَلَ رَسُولَهُ } ملتبساً { بالهدى } أي القرآن الذي هو هدى للمتقين { وَدِينِ الحق } الثابتِ وهو دينُ الإسلام { لِيُظْهِرَهُ } أي رسولُه { عَلَى الدين كُلّهِ } أي على أهل الأديانِ كلِّهم أو ليُظهرَ الدينَ الحقِّ على سائر الأديان بنسخه إياها حسبما تقتضيه الحِكمةُ ،  والجملةُ بيانٌ وتقريرٌ لمضمون الجملةِ السابقة ،  والكلامُ في قوله عز وجل : { وَلَوْ كَرِهَ المشركون } كما فيما سبق خلاً أن وصفَهم بالشرك بعد وصفِهم بالكفر للدلالة على أنهم ضمُّوا الكفرَ بالرسول إلى الكفر بالله .  <br />
