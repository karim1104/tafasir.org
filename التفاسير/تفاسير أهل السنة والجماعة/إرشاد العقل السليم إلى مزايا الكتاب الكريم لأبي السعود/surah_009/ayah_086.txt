{ وَإِذَا أُنزِلَتْ سُورَةٌ } من القرآن ويجوز أن يُراد بها بعضُها { أَنْ آمِنُواْ بِاللهِ } ( أنْ ) مفسرةٌ لما في الإنزال من معنى القولِ والوحي ،  أو مصدريةٌ حذف عنها الجارُّ أي بأن آمِنوا { وجاهدوا مَعَ رَسُولِهِ } لإعزاز دينِه وإعلاءِ كلمتِه { استأذنك أُوْلُواْ الطول مِنْهُمْ } أي ذووا الفضل والسَّعةِ والقُدرة على الجهاد بدناً ومالاً { وَقَالُواْ } عطفٌ تفسيريٌّ لاستأذنك مغنٍ عن ذكر ما استأذنوا فيه يعني القعودَ { ذَرْنَا نَكُنْ معَ القاعدين } أي الذين قعدوا عن الغزو لما بهم من عذر .  <br />
