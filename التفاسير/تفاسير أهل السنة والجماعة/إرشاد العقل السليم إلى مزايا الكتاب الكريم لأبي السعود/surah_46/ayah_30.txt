{ قَالُوا } أي عندَ رجوعِهم إلى قومِهم { يا قومنا إِنَّا سَمِعْنَا كتابا أُنزِلَ مِن بَعْدِ موسى } قيلَ : قالُوه لأنَّهم كانُوا على اليهوديةِ .   وعنِ ابن عبَّاسٍ رضي الله عنهُمَا : إنَّ الجنَّ لم تكُن سمعت بأمرِ عِيْسَى عليه السَّلامُ .   { مُصَدقا لمَا بَيْنَ يَدَيْهِ } أرادُوا به التوراةَ { يَهْدِي إِلَى الحق } من العقائدِ الصحيحةِ { وإلى طَرِيقٍ مسْتَقِيمٍ } مُوصلٍ إليهِ وهُو الشَّرائعُ والأعمالُ الصالحةُ .  <br />
