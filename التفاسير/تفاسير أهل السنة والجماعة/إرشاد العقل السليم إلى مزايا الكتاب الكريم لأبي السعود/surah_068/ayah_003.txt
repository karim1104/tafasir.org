{ وَإِنَّ لَكَ } بمقابلةِ مقاساتِكَ ألوانَ الشدائدِ منْ جهتِهِم وتحملِك لأعباءِ الرسالةِ { لأَجْرًا } لثواباً عظيماً لا يُقادَرُ قَدرُهُ { غَيْرُ مَمْنُونٍ } معَ عظمِهِ كقولِهِ تعالَى : { عَطَاء غَيْرَ مَجْذُوذٍ } [ سورة هود ،  الآية 108 ] أو غيرَ ممنونٍ عليكَ من جهةِ الناسِ فإنَّهُ عطاؤُه تعالى بلاَ توسطٍ .
