{ كَلاَّ } ردعٌ عنْ إعراضِهم { إِنَّهُ } أي القرآنَ { تَذْكِرَةٌ } وأيُّ تذكرةٍ { فَمَن شَاء } أن يذكرَهُ { ذَكَرَهُ } وحازَ بسببهِ سعادةَ الدارينِ { وَمَا يَذْكُرُونَ } بمجرد مشيئتِهم للذكر كما هُو المفهومُ من ظاهرِ قولِه تعالى فمَنْ شاءَ ذكرَهُ إذْ لا تأثيرَ لمشيئةِ العبدِ وإرادتِه في أفعالِه .  <br />
