وقوله تعالى : { لاَ يَسْتَطِيعُونَ نَصْرَهُمْ } الخ استئنافٌ سيق لبيانُ بُطلانِ رأيهم وخيبةِ رجائِهم وانعكاسِ تدبيرِهم أي لا تقدرُ آلهتُهم على نصرِهم { وَهُمْ } أي المشركون { لَهُمْ } أي لآلِهتهم { جُندٌ مٌّحْضَرُونَ } يشيِّعونهم عند مساقِهم إلى النَّارِ ،  وقيل : مُعَدُّون في الدُّنيا لحفظِهم وخدمتِهم والذبِّ عنهم ،  ولا يساعده مساقُ النَّظمِ الكريم<br />
