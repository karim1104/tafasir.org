{ أَوْ خَلْقًا } آخرَ { مّمَّا يَكْبُرُ في صُدُورِكُمْ } أي يعظُم عندكم عن قبول الحياة لكمال المباينةِ والمنافاةِ بينها وبينه ،  فإنكم مبعوثون ومُعادون لا محالة { فَسَيَقُولُونَ مَن يُعِيدُنَا } مع ما بيننا وبين الإعادةِ من مثل هذه المباعدةِ والمباينة { قُلْ } لهم تحقيقاً للحق وإزاحةً للاستبعاد وإرشاداً لهم إلى طريقة الاستدلال { الذي } أي يعيدكم القادرُ العظيم الذي { فَطَرَكُمْ } اخترعكم { أَوَّلَ مَرَّةٍ } من غير مثالِ يحتذيه ولا أسلوبٍ ينتحيه وكنتم تراباً ما شمّ رائحةَ الحياة ،  أليس الذي يقدِر على ذلك بقادر على أن يعيدَ العظامَ الباليةَ إلى حالتها المعهودة ؟ بلى إنه على كل شيء قدير { فَسَيُنْغِضُونَ إِلَيْكَ رُؤُوسَهُمْ } أي سيحركونها نحوَك تعجباً وإنكاراً { وَيَقُولُونَ } استهزاءً { متى هُوَ } أي ما ذكرتَه من الإعادة { قُلْ } لهم { عسى أَن يَكُونَ } ذلك { قَرِيبًا } نُصب على أنه خبرٌ ليكون أو ظرفٌ على أن كان تامةٌ أي أن يقعَ في زمان قريب ،  ومحلُّ أن مع ما في حيزها إما نصبٌ على أنه خبرٌ لعسى وهي ناقصة واسمُها ضميرٌ عائد إلى ما عاد إليه هو أي عسى كونُه قريباً ،  أو وقوعُه في زمان قريب .  <br />
