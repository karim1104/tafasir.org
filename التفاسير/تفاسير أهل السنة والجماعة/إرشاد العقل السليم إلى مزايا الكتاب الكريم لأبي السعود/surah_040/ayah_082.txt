{ أَفَلَمْ يَسِيرُواْ } أي أقعدُوا فلم يسيُروا { فِي الأرض فَيَنظُرُواْ كَيْفَ كَانَ عاقبة الذين مِن قَبْلِهِمْ } من الأممِ المُهلكةِ .   وقولُه تعالَى : { كَانُواْ أَكْثَرَ مِنْهُمْ وَأَشَدَّ قُوَّةً } الخ استئنافٌ مسوقٌ لبيان مبادِي أحوالِهم وعواقِبها { وَآثَاراً فِى الأرض } باقيةً بعدَهُم من الأبنيةِ والقصورِ والمصانعِ ،  وقيل هي آثارُ أقدامِهم في الأرضِ لعظمِ أجرامِهم { فَمَا أغنى عَنْهُمْ ما كَانُواْ يَكْسِبُونَ } مَا الأُولى نافيةٌ أو استفهاميةٌ منصوبةٌ بأَغْنَى ،  والثانيةُ موصولةٌ أو مصدريةٌ مرفوعةٌ ،  أيْ لَم يُغنِ عنهُم أو أيَّ شيءٍ أغنَى عنهُم مكسوبُهم أو كسبُهم .  <br />
