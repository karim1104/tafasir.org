{ فاصبر } إلى أنْ يُلاقُوا ما أُعدَّ لهمُ من العذابِ { إِنَّ وَعْدَ الله } بتعذيبِهم { حَقّ } كائنٌ لا محالَة { فَإِمَّا نُرِيَنَّكَ } أي فإنْ نُرِكَ ومَا مزيدةٌ لتأكيدِ الشرطيةِ ولذلكَ لحقتِ النونُ الفعلَ ولا تلحقُه مع إنْ وحدَها { بَعْضَ الذي نَعِدُهُمْ } وهو القتلُ والأسرُ { أَوْ نَتَوَفَّيَنَّكَ } قبلَ ذلكَ { فَإِلَيْنَا يُرْجَعُونَ } يومَ القيامةِ فنجازِيهم بأعمالِهم وهُو جوابُ نتوفينكَ وجوابُ نرينك محذوفٌ مثلُ فذاكَ ويجوزُ أن يكونَ جواباً لهما بَمعْنى إنْ نُعذبهم في حياتِك أو لم نُعذبْهم فإنَّا نعذبهم في الآخرةِ أشدَّ العذابِ وأفظَعه كما ينبئُ عنْهُ الاقتصارُ على ذكِر الرجوعِ في هذا المعرضِ .  <br />
