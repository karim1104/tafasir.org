{ وَكَانَ يَأْمُرُ أَهْلَهُ بالصلاة والزكاة } اشتغالاً بالأهم وهو أن يُقْبل الرجلُ بالتكميل على نفسه مَنْ هو أقربُ الناس إليه قال تعالى : { وَأَنذِرْ عَشِيرَتَكَ الأقربين } { وَأْمُرْ أَهْلَكَ بالصلاة } { قُواْ أَنفُسَكُمْ وَأَهْلِيكُمْ نَاراً } وقصد إلى تكميل الكل بتكميلهم لأنهم قدوةٌ يؤتسى بهم ،  وقيل : أهلُه أمتُه فإن الأنبياءَ عليهم السلام آباءُ الأمم { وَكَانَ عِندَ رَبّهِ مَرْضِيّاً } لاتصافه بالنعوت الجليلةِ التي من جملتها ما ذكر من خصاله الحميدة .  <br />
