{ قَالُواْ } عندما شاهدوا مخايلَ أخْذِ بنيامين مستعطِفين { قَالُواْ يا يأَيُّهَا العزيز إِنَّ لَهُ أَبًا } لم يريدوا بذلك الإخبارَ بأن له أباً ذلك معلومٌ مما سبق وإنما أرادوا الإخبار بأن له أباً { شَيْخًا كَبِيرًا } في السن لا يكاد يستطيع فراقَه وهو عَلالةٌ به يتعلل عن شقيقه الهالك { فَخُذْ أَحَدَنَا مَكَانَهُ } فلسنا عنده بمنزلته من المحبة والشفقة { إِنَّا نَرَاكَ مِنَ المحسنين } إلينا فأتمم إحسانَك بهذه التتمة أو المتعوّدين بالإحسان فلا تغيّر عادتك .  <br />
