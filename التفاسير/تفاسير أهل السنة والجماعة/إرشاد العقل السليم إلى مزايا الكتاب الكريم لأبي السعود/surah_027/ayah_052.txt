{ فَتِلْكَ بُيُوتُهُمْ } جملةً مقررةٌ لما قبلها .   وقولُه تعالى : { خَاوِيَةٍ } أي خاليةً أو ساقطةً متهدمةً { بِمَا ظَلَمُواْ } أي بسببِ ظلمِهم المذكورِ ،  حالٌ من بيوتُهم والعاملُ معنى الإشارةِ .   وقرئ خاويةٌ بالرَّفعِ على أنَّه خبرٌ لمبتدأٍ محذوفٍ { إِنَّ فِي ذَلِكَ } أي فيَما ذُكر من التَّدميرِ العجيبِ بظلِمهم { لآيَةً } لعبرةً عظيمةً { لِقَوْمٍ يَعْلَمُونَ } أي ما من شأنِه أنْ يُعلم من الأشياءِ أو لقومٍ يتصفونَ بالعلم<br />
