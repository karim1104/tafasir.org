{ يُصْلِحْ لَكُمْ أعمالكم } يُوفقكم للأعمالِ الصَّالحةِ أو يُصلحها بالقَبُولِ والإثابةِ عليها { وَيَغْفِرْ لَكُمْ ذُنُوبَكُمْ } ويجعلُها مكفرةً باستقامتِكم في القولِ والعملِ .   { وَمَن يُطِعِ الله وَرَسُولَهُ } في الأوامرِ والنَّواهِي التي مِن جُملتِها هذه التكليفاتُ { فَقَدْ فَازَ } في الدَّارينِ { فَوْزاً عَظِيماً } لا يُقادرُ قَدرُه ولا يُبلغ غايتُه .  <br />
