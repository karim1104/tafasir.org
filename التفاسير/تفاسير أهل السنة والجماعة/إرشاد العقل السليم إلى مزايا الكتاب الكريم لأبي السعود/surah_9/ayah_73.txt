{ يا أيها النبي جاهد الكفار } أي المجاهرين منهم بالسيف { والمنافقين } بالحجة وإقامة الحدود { واغلظ عَلَيْهِمْ } في ذلك ولا تأخُذْك بهم رأفة .   قال عطاء : نسَخت هذه الآيةُ كلَّ شيء من العفو والصفح { وَمَأْوَاهُمْ جَهَنَّمُ } جملةٌ مستأنفةٌ لبيان آجل أمرِهم إثرَ بيانِ عاجلِه ،  وقيل : حالية { وَبِئْسَ المصير } تذييلٌ لما قبله والمخصوصُ بالذم محذوف .  <br />
