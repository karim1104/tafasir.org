وقوله تعالى : { يَعْلَمُ مَا يَلْجُ فِي الأرض } الخ ،  تفصيلٌ لبعض ما يحيط به علمُه من الأمور التي نِيطتْ بها مصالحهم الدُّنيويةُ والدِّينيةُ أي يعلم ما يدخل فيها من الغيثِ والكُنوزِ والدَّفائنِ والأموات ونحوها { وَمَا يَخْرُجُ مِنْهَا } كالحيوان والنبات وماء العيون ونحوها { وَمَا يَنزِلُ مِنَ السماء } كالملائكةِ والكتبِ والمقاديرِ ونحوِها .   وقرئ وما نُنزِّل بالتَّشديدِ ونونِ العظمةِ { وَمَا يَعْرُجُ فِيهَا } كالملائكةِ وأعمالِ العبادِ والأبخرةِ والأَدْخنةِ { وَهُوَ الرحيم } للحامدينَ على ما ذُكر من نِعَمِه { الغفور } للمفرِّطين في ذلك بلُطفِه وكرمِه .  <br />
