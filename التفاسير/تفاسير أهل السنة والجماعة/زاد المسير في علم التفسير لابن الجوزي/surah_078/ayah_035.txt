قوله تعالى : { لاَّ يَسْمَعُونَ فِيهَا } أي : في الجنة إذا شربوها { لَغْواً } وقد ذكرناه في [ الطُّور :23 ] وغيرها { وَلاَ كِذباً } أي : لا يكذب بعضهم بعضا ،   لأن أهل الدنيا إذا شربوا الخمر تكلموا بالباطل ،   وأهل الجنة منزهون عن ذلك .  <br />
قال الفراء : وقراءة علي رضي الله عنه { كِذَابا } بالتخفيف كأنه  والله أعلم  لا يتكاذبون فيها .   وكان الكسائي يخفف هذه ويشدد ،   { وكذَّبوا بآياتنا كذِّابا } لأن { كذَّبوا } يقيد { الكذاب } بالمصدر ،   وهذه ليست مقيدة بفعل يصيرها مصدرا .  <br />
وقد ذكرنا عن أبي عبيدة أن الكذاب بالتشديد والتخفيف مصدر المكاذبة .   وقال أبو علي الفارسي :  " الكِذَاب "  بالتخفيف مصدر  " كَذَب "  مثل  " الكتاب "  مصدر  " كَتَبَ "  .
