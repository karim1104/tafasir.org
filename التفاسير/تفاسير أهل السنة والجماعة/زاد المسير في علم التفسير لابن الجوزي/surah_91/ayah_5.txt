قوله تعالى : { وَالسَّمَاء وَمَا بَنَاهَا } في { ما } قولان :<br />
أحدهما : بمعنى { من } تقديره { ومن بناها } قاله الحسن ،   ومجاهد ،   وأبو عبيدة ،   وبعضهم يجعلها بمعنى الذي .  <br />
والثاني : أنها بمعنى المصدر ،   تقديره : وبنائها ،   وهذا مذهب قتادة ،   والزجاج .   وكذلك القول في { وما طحاها } { وما سَّواها } وقد قرأ أبو عمران الجوني في آخرين { ومن بناها } { ومن طحاها } { ومن سواها } كله بالنون .  <br />
