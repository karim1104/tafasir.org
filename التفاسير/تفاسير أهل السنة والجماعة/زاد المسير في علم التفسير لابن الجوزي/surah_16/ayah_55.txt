قوله تعالى : { لِيَكْفُرُواْ بِمَآ آتَيْنَاهُمْ } قال الزجاج : المعنى : ليكفروا بأنا أنعمنا عليهم ،   فجعلوا نعمنا سببا إلى الكفر ،   وهو كقوله تعالى : { رَبَّنَا إِنَّكَ آتَيْتَ فِرْعَوْنَ } إلى قوله : { لِيُضِلُّواْ عَن سَبِيلِكَ } [ يونس : 88 ] ،   ويجوز أن يكون  " ليكفروا "  ،   أي : ليجحدوا نعمة الله في ذلك .  <br />
قوله تعالى : { فَتَمَتَّعُواْ } تهدد ،   { فَسَوْفَ تَعْلَمُونَ } عاقبة أمركم .
