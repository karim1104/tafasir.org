قوله تعالى : { فَرِيقًا هَدَى } قال الفراء : نصب الفريق ب { تَعُودُونَ } .   وقال ابن الأنباري : نصب { فَرِيقاً } و{ فَرِيقاً } على الحال من الضمير الذي في { تَعُودُونَ } ،   يريد : تعودون كما ابتدأ خلقكم مختلفين ،   بعضكم سعداء ،   وبعضكم أشقياء .  <br />
قوله تعالى : { حَقَّ عَلَيْهِمُ الضَّلَالَةُ } أي : بالكلمة القديمة ،   والإرادة السابقة .
