{ وَلَوْ أَنَّا أَهْلَكْنَاهُمْ } يعني مشركي مكة { بِعَذَابٍ مّن قَبْلِهِ } في الهاء قولان :<br />
أحدهما : أنها ترجع إلى الكتاب ،   قاله مقاتل .  <br />
والثاني : إلى الرسول ،   قاله الفراء .  <br />
قوله تعالى : { لَقَالُواْ } يوم القيامة { رَبَّنَا لَوْلا } أي : هلا { أَرْسَلْتَ إِلَيْنَا رَسُولاً } يدعونا إلى طاعتك { فَنَتَّبِعَ آيَاتِكَ } أي : نعمل بمقتضاها { مِن قَبْلِ أَن نَّذِلَّ } بالعذاب { وَنَخْزَى } في جهنم .   وقرأ ابن عباس ،   وابن السميفع ،   وأبو حاتم عن يعقوب :  " نذل "  و " نخزى "  برفع النون فيهما ،   وفتح الذال .  <br />
