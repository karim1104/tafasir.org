قوله تعالى : { ذَلِكَ جَزَاؤُهُم } أي : الأمر ذلك الذي ذكرت من بطلان عملهم وخسة قدرهم ،   ثم ابتدأ فقال { جَزَاؤُهُمْ جَهَنَّمُ } ،   وقيل : المعنى : ذلك التصغير لهم ،   وجزاؤهم جهنم ،   فأضمرت واو الحال .  <br />
قوله تعالى : { بِمَا كَفَرُواْ } أي : بكفرهم واتخاذهم { آيَاتِي } التي أنزلتها { وَرُسُلِي هُزُواً } أي : مهزوءا به .  <br />
