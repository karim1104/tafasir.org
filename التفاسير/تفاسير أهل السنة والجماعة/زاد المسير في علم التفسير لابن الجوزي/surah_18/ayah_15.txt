ثم قال الفتية : { هَؤُلاء قَوْمُنَا } يعنون الذين كانوا في زمن دقيانوس { اتَّخَذُواْ مِن دُونِهِ آلِهَةً } أي : عبدوا الأصنام { لَوْلاَ } أي : هلا { يَأْتُونَ عَلَيْهِم } أي : على عبادة الأصنام { بِسُلْطَانٍ بَيّنٍ } أي : بحجة .   وإنما قال : { عليهم } والأصنام مؤنثة ،   لأن الكفار نحلوها العقل والتمييز ،   فجرت مجرى المذكرين من الناس .  <br />
قوله تعالى : { فَمَنْ أَظْلَمُ مِمَّنِ افْتَرَى عَلَى اللَّهِ كَذِبًا } فزعم أن له شريكا ؟<br />
