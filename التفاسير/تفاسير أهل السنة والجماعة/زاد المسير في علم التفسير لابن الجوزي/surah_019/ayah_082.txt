قوله تعالى : { كَلاَّ } أي : ليس الأمر كما قدروا ،   { سَيَكْفُرُونَ } يعني الأصنام بجحد عبادة المشركين ،   كقوله تعالى : { مَا كَانُواْ إِيَّانَا يَعْبُدُونَ } [ القصص : 63 ] لأنها كانت جماداً لا تعقل العبادة ،   { وَيَكُونُونَ } يعني : الأصنام { عَلَيْهِمْ } يعني : المشركين { ضِدّاً } أي : أعوانا عليهم في القيامة ،   يكذبونهم ويلعنونهم .
