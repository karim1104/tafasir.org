قوله تعالى : { فَاذْكُرُونِي } .   قال ابن عباس ،   وابن جبير : اذكروني بطاعتي أذكركم بمغفرتي ،   وقال إبراهيم بن السري : كما أنعمت عليكم بالرسالة ،   فاذكروني بتوحيدي وتصديق نبيي .   قال : فإن قيل : كيف يكون جواب : { كَمَا أَرْسَلْنَا } : { فَاذْكُرُونِي } ؟ فإن قوله : { فَاذْكُرُونِي } أمر .   وقوله : { أَذْكُرْكُمْ } جزاؤه ؛ فالجواب : أن المعنى : إن تذكروني أذكركم .  <br />
قوله تعالى : { وَاشْكُرُواْ لِي } الشكر : الاعتراف بحق المنعم ،   مع الثناء عليه .  <br />
