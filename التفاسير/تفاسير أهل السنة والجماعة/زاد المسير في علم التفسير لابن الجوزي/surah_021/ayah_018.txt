قوله تعالى : { بَلِ } أي : دع ذاك الذي قالوا ،   فإنه باطل { نَقْذِفُ بِالْحَقّ } أي : نسلط الحق وهو القرآن { عَلَى الْبَاطِلِ } وهو كذبهم { فَيَدْمَغُهُ } قال ابن قتيبة : أي : يكسره ،   وأصل هذا إصابة الدماغ بالضرب ،   وهو مقتل { فَإِذَا هُوَ زَاهِقٌ } أي : زائل ذاهب .   قال المفسرون : والمعنى : إنا نبطل كذبهم بما نبيّن من الحق حتى يضمحل ،   { وَلَكُمُ الْوَيْلُ مِمَّا تَصِفُونَ } أي : من وصفكم الله بما لا يجوز .  <br />
