قوله تعالى : { أَمْ يَقُولُونَ افْتَرَاهُ } في { أم } قولان : أحدهما : أنها بمعنى الواو ،   قاله أبو عبيدة .   والثاني : بمعنى بل ،   قاله الزجاج .  <br />
قوله تعالى : { فَأْتُواْ بِسُورَةٍ مّثْلِهِ } قال الزجاج : المعنى : فأتوا بسورة مثل سورة منه ،   فذكر المثل لأنه إنما التمس شبه الجنس ،   { وَادْعُواْ مَنِ اسْتَطَعْتُمْ } ممن هو في التكذيب مثلكم { إن كنتم صادقين } أنه اختلقه .  <br />
