قوله تعالى : { قَالُواْ اتَّخَذَ اللَّهُ وَلَدًا } قال ابن عباس : يعني أهل مكة ،   جعلوا الملائكة بنات الله .  <br />
قوله تعالى : { سُبْحَانَهُ } تنزيه له عما قالوا .   { هُوَ الْغَنِىُّ } عن الزوجة والولد .   { إِنْ عِندَكُمْ } أي : ما عندكم { مّن سُلْطَانٍ } أي : حجة بما تقولون .  <br />
