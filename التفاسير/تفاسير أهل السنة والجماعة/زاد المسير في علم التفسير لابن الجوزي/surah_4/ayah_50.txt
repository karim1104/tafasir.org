قوله تعالى : { انظُرْ كَيفَ يَفْتَرُونَ عَلَى اللَّهِ الكَذِبَ } وهو قولهم { نَحْنُ أَبْنَاء اللَّهِ وَأَحِبَّاؤُهُ } وقولهم { لَن يَدْخُلَ الْجَنَّةَ إِلاَّ مَن كَانَ هُودًا أَوْ نَصَارَى } وقولهم : لا ذنب لنا ونحو ذلك مما كذبوا فيه { وَكَفَى بِهِ } أي : وحسبهم بقيلهم الكذب { إِثْماً مُّبِيناً } يتبين كذبهم لسامعيه .  <br />
