قوله تعالى : { أَمْ يَقُولُونَ } قال الزجاج : المعنى : أيقولون : { افْتَرَاهُ } ؟ قال ابن قتيبة : الافتراء : الاختلاق .   { فَعَلَىَّ إجرامي } أي : جرم ذلك الاختلاق إن كنت فعلت .   { وَأَنَاْ بريء مّمَّا تُجْرَمُونَ } في التكذيب .   وقرأ أبو المتوكل ،   وابن السميفع :  " فَعَلَىَّ أجرامي "  بفتح الهمزة .  <br />
