70 - قوله تعالى :  {  وذر الذين اتخذوا دينهم لعبا ولهوا وغرتهم الحياة الدنيا } : <br />
اختلف فيه هل هو منسوخ أو محكم .  فقيل :  هو منسوخ بقوله عز وجل :  {  فاقتلوا المشركين حيث وجدتموهم } [ التوبة :  5 ] وهو قول قتادة{[8094]} .  وقيل :  هو محكم والمراد :  التهديد والتوعد فهي كقوله تعالى :  {  ذرني ومن خلقت وحيدا ( 11 ) } [ المدثر :  11 ] وهو قول مجاهد{[8095]} .
