{ يا أيها الذين آمنوا كونوا قوامين بالقسط } إلى قوله : { فالله أولى بهما } يقول : اشهدوا على أنفسكم وعلى أبنائكم [ وعلى آبائكم ] وأمهاتكم وقراباتكم ؛ أغنياء كانوا أو فقراء { إن يكن غنيا أو فقيرا فالله أولى بهما } أي أولى بغناه وفقره منكم .   قال قتادة : يقول : لا يمنعنك غنى غني ،   ولا فقر فقير أن تشهد عليه بما تعلم .  <br />
{ فلا تتبعوا الهوى أن تعدلوا } [ فتدعوا ] الشهادة { وإن تلووا } ألسنتكم فتحرفوا الشهادة { أو تعرضوا } فلا تشهدوا بها { فإن الله كان بما تعملون خبيرا } .  <br />
