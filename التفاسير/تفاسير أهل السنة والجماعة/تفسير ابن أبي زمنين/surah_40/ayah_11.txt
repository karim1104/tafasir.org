{ قالوا ربنا أمتنا اثنتين وأحييتنا اثنتين } وهو قوله في سورة البقرة { كيف تكفرون بالله وكنتم أمواتا فأحياكم ثم يميتكم ثم يحييكم }[ البقرة :28 ] .  <br />
يقول : كنتم أمواتا في أصلبة آبائكم نطفا { فأحياكم } يعني : هذه الحياة الدنيا { ثم يميتكم } يعني : موتهم { ثم يحييكم } يعني : البعث .  <br />
{ فهل إلى خروج من سبيل( 11 ) } تفسير الحسن : فيها إضمار ( قال الله : لا ) .
