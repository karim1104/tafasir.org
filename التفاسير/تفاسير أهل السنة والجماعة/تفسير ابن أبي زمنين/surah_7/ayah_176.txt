{ ولو شئنا لرفعناه بها } أي : بآياتنا { ولكنه أخلد إلى الأرض } أي : ركن إلى الدنيا { واتبع هواه } أي : أبى أن يصحب الهدى .  <br />
{ فمثله كمثل الكلب إن تحمل عليه } أي : تطرده { يلهث أو تتركه يلهث } تفسير الكلبي ،   قال : هو ضال على كل حال ؛ وعظته أو تركته .  <br />
قال محمد : قيل : ضرب الله مثلا لتارك أمره أخس مثل ،   فقال عز وجل : مثله كمثل الكلب لاهثا -واختصر ( لاهثا )- { إن تحمل عليه يلهث أو تتركه يلهث }<br />
ولهثانه : اضطراب لسانه وصوته الذي يردد عند ذلك ؛ كأنه معيى أو عطشان ؛ وإذا كان الكلب بهذه الحال ،   فهي أخس أحواله .  <br />
