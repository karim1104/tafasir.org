{ نحن نقص عليك أحسن القصص } قال قتادة : من الكتب الماضية ،   وأمور الله السالفة في الأمم { بما أوحينا إليك هذا القرآن } أي : بوحينا إليك هذا القرآن { وإن كنت من قبله } أي : من قبل أن ينزل عليك القرآن { لمن الغافلين } كقوله : { وكذلك أوحينا إليك روحا من أمرنا ما كنت تدري ما الكتاب ولا الإيمان } [ الشورى : 52 ] .
