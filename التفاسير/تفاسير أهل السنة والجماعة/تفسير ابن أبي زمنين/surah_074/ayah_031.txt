{ وما جعلنا أصحاب النار إلا ملائكة } أي : فمن يطيقهم ؟ { وما جعلنا عدتهم إلا فتنة } بلية { للذين كفروا ليستيقن الذين أوتوا الكتاب } لأنهم في كتبهم تسعة عشر { ويزداد الذين آمنوا إيمانا } تصديقا { ولا يرتاب } يشك { الذين أوتوا الكتاب والمؤمنون } فيما أنزل الله من عددهم { وليقول الذين في قلوبهم مرض } شك { والكافرون } الجاحدون { ماذا أراد الله بهذا مثلا } أي : ذكرا ،   وذلك منهم استهزاء وتكذيب .   قال الله : { كذلك يضل الله من يشاء ويهدي من يشاء وما يعلم جنود ربك إلا هو }<br />
يحيى : عن صاحب له ،   عن أبان بن أبي عياش ،   عن الحسن  " أن سائلا سأل رسول الله عن خلق الملائكة من أي شيء خلقت ؟ فقال : من نور الحجب السبعين التي تلي الرب ؛ كل حجاب منها مسيرة خمسمائة عام ،   فليس ملك إلا وهو يدخل في نهر الحياة فيغتسل فيكون من كل قطرة من ذلك الماء ملك ،   فلا يحصي أحد ما يكون في يوم واحد " {[1473]} فهو قوله { وما يعلم جنود ربك إلا هو } .   { وما هي إلا ذكرى للبشر( 31 ) } رجع إلى قوله : { سأصليه سقر وما أدراك ما سقر } .
