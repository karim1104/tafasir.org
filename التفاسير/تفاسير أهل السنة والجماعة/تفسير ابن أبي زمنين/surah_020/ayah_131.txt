{ ولا تمدن عينيك إلى ما متعنا به أزواجا } أصنافا منهم ،   يعني الأغنياء .  <br />
{ زهرة الحياة الدنيا } يعني : زينة { لنفتنهم فيه } أي : نختبرهم ،   أمره أن يزهد في الدنيا .   قال محمد : ( زهرة ) منصوب بمعنى : جعلنا لهم الحياة الدنيا زهرة .  <br />
{ ورزق ربك } في الجنة { خير } من الدنيا { وأبقى } يقول : لا نفاد له .  <br />
