{ ويوم نحشرهم جميعا } يعني : المشركين وأوثانهم جميعا { ثم نقول للذين أشركوا مكانكم أنتم وشركاؤكم } يعني : الأوثان { فزيلنا بينهم } بالسيئات ،   يعني : المشركين على حدة والأوثان على حدة { وقال شركاؤهم ما كنتم إيانا تعبدون } الأوثان تقول هذا للمشركين : ما كانت عبادتكم إيانا عن دعاء كان منا لكم ،   وإنما دعاكم إلى عبادتنا الشيطان .  <br />
قال محمد : يجوز النصب في قوله عز وجل : { مكانكم } على الأمر ،   كأنهم يقال لهم : انتظروا مكانكم حتى يفصل بينكم ؛ وهي كلمة جرت على الوعيد ؛ تقول العرب : ( مكانك ) تتوعد بذلك .  <br />
وقوله عز وجل : { فزيلنا بينهم } أي : ميزنا ؛ يقال : أزلت الشيء من الشيء أزيله ؛ أي : مزته منه أميزه .  <br />
