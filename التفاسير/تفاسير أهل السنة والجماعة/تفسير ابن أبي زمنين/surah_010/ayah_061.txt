{ وما تكون في شأن } من حوائجك للدنيا { وما تتلوا منه من قرآن } خاطب بهذا النبي صلى الله عليه وسلم { ولا تعملون } يعني : العامة { من عمل إلا كنا عليكم شهودا إذ تفيضون فيه } يخبرهم أنه شاهد لأعمالهم { وما يعزب عن ربك } أي : يغيب عن ربك { من مثقال ذرة } وزن ذرة { في الأرض ولا في السماء } حتى لا يعلمه ويعلم موضعه { ولا أصغر من ذلك ولا أكبر إلا في كتاب مبين } بين عند الله -عز وجل- .  <br />
