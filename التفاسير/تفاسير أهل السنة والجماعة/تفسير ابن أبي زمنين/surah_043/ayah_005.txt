{ أفنضرب عنكم الذكر } يعني : القرآن { صفحا } تفسير الكلبي يقول : أنذر الذكر من أجلكم ؟ ! { أن كنتم قوما مسرفين( 5 ) } مشركين أي : لا نذره .  <br />
قال محمد : تقرأ { أن كنتم } بالفتح وبالكسر ،   فمن فتح فالمعنى : لأن كنتم ومن كسر فعلى الاستقبال ؛ المعنى : إن تكونوا مسرفين نضرب عنكم الذكر .  <br />
ويقال : ضربت عنه الذكر وأضربت بمعنى واحد إذا أمسكت وقوله :<br />
{ صفحا } أي : إعراضا يقال : صفحت عن فلان أي : أعرضت عنه ،   والأصل في ذلك أنك توليه صفحة عنقك .
