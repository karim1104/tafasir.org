{ آتوني زبر الحديد حتى إذا ساوى بين الصدفين }{[685]} يعني : رأس الجبلين ،   في تفسير مجاهد ،   أي : سد ما بينهما { قال انفخوا } أي : على الحديد { حتى إذا جعله نارا } يعني : أحماه بالنار { قال آتوني } أعطوني { أفرغ عليه قطرا } فيها تقديم : أعطوني قطرا أفرغ عليه والقطر : النحاس ،   فجعل أساسه الحديد ،   وجعل ملاطه النحاس .  <br />
