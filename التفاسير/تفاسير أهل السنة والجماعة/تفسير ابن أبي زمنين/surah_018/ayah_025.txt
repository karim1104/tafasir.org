{ ولبثوا في كهفهم ثلاثمائة } ثم أخبر ما تلك الثلاثمائة ،   فقال : { سنين } قال محمد : ( سنين ) عطف على ثلاثمائة ،   وهذا العطف يسميه النحويون : عطف البيان والتوكيد .   قوله : { وازدادوا تسعا } أي تسع سنين .   تفسير قتادة : يقول : قال : هذا قول أهل الكتاب ،   رجع إلى أول الكلام { سيقولون ثلاثة رابعهم كلبهم ويقولون خمسة سادسهم كلبهم رجما بالغيب ويقولون سبعة وثامنهم كلبهم } ويقولون { ولبثوا في كهفهم ثلاثمائة سنين وازدادوا تسعا } .  <br />
