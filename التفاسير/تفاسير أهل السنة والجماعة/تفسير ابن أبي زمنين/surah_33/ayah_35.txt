{ إن المسلمين والمسلمات والمؤمنين والمؤمنات } هو كلام واحد ؛ كقوله : { فأخرجنا من كان فيها من المؤمنين فما وجدنا فيها غير بيت من المسلمين }{[1096]} والإسلام هو اسم الدين ،   قال : { ومن يبتغ غير الإسلام دينا فلن يقبل منه }{[1097]}وهو الإيمان بالله { والقانتين والقانتات } القنوت : الطاعة { والصادقين والصادقات والصابرين والصابرات } على ما أمرهم الله به { والخاشعين والخاشعات } وهو الخوف الثابت في القلب { والمتصدقين والمتصدقات } يعني : الزكاة المفروضة { والصائمين والصائمات } .  <br />
قال يحيى : بلغني أنه من صام رمضان وثلاثة أيام من كل شهر فهو من الصائمين والصائمات { والحافظين فروجهم والحافظات } مما لا يحل لهن .  <br />
{ والذاكرين الله كثيرا والذاكرات } يعني : باللسان ؛ وليس في هذا الذكر وقت .
