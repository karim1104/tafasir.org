{ ادعوهم لآبائهم هو أقسط عند الله } أي : أعدل { فإن لم تعلموا آباءهم فإخوانكم في الدين ومواليكم } يقول : قولوا : [ ولينا فلان ] ،   وأخونا فلان .   { وليس عليكم جناح } إثم { فيما أخطأتم به } إن أخطأ الرجل بعد النهي فنسبه إلى [ الذي ] تبناه ناسيا ؛ فليس عليه في ذلك إثم { ولكن ما تعمدت قلوبكم } أن تدعوهم إلى غير آبائهم .  <br />
