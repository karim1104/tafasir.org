{ ظاهرين في الأرض } يعني : غالبين على أرض مصر في القهر لهم { فمن ينصرنا } يمنعنا { من بأس الله } عذابه { إن جاءنا } يقوله على الاستفهام- أي : أنه لا يمنعنا منه أحد .  <br />
{ قال فرعون ما أريكم إلا ما أرى } أي : ما أرى لنفسي { وما أهديكم إلا سبيل الرشاد( 29 ) } يعني : جحود ما جاء به موسى والتمسك بما هم عليه .
