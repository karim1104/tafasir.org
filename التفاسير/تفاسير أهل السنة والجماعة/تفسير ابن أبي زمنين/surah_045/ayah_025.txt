قوله : { وإذا تتلى عليهم آياتنا } القرآن { بينات ما كان حجتهم إلا أن قالوا ائتوا بآبائنا } أحيوا آباءنا حتى يصدقوكم بمقالتكم ،   بأن الله يحيي الموتى } .  <br />
قال محمد : من قرأ { حجتهم } بالنصب جعل اسم كان ( أن ) مع صلتها ،   ويكون المعنى : ما كان حجتهم إلا مقالتهم ،   ومن قرأ ( حجتهم ) بالرفع جعل ( حجتهم ) اسم كان و { أن قالوا } خبر كان .  <br />
