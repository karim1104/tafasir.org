{ يحسبون الأحزاب لم يذهبوا وإن يأت الأحزاب يودوا } المنافقون { لو أنهم بادون في الأعراب } أي : في البادية مع الأعراب { يسألون عن أنبائكم } وهو كلام موصول .  <br />
قال محمد : قوله : { يحسبون الأحزاب لم يذهبوا } قيل : المعنى : يحسبون الأحزاب بعد انهزامهم وذهابهم لم يذهبوا ؛ لجبنهم وخوفهم .  <br />
