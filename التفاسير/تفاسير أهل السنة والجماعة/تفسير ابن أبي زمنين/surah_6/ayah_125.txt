{ فمن يرد الله أن يهديه يشرح } أي : يوسع { صدره للإسلام } { ومن يرد أن يضله يجعل صدره ضيقا حرجا } الحرج والضيق معناهما واحد .  <br />
{ كأنما يصعد في السماء } أي : كأنما يكلف أن يصعد إلى السماء ،   يقول : يثقل عليه ما يدعى إليه من الإيمان .  <br />
{ كذلك يجعل الله الرجس } يعني : رجاسة الكفر { على الذين لا يؤمنون } .  <br />
