{ وأقسموا بالله جهد أيمانهم } ( بمبلغ أيمانهم ) { لئن جاءتهم آية ليؤمنن بها } قال الله لنبيه { قل إنما الآيات عند الله وما يشعركم } أي : ما يدريكم { أنها إذا جاءت لا يؤمنون } .  <br />
قال محمد : تقرأ ( إنها ) بكسر الألف ؛ على الابتداء ،   وتقرأ ( أنها ) بالفتح{[334]} ؛ بمعنى : لعلهم ؛ ذكره أبو عبيد .
