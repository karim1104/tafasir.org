{ أنت ولينا من دونهم } أي : أنا لم نكن نواليهم على عبادتهم إيانا { بل كانوا يعبدون الجن } الشياطين هي التي دعتهم إلى عبادتنا ؛ فهم بطاعتهم الشياطين عابدون لهم { أكثرهم } يعني : جماعة المشركين { بهم } أي : بالشياطين { مؤمنون( 41 ) } مصدقون بما وسوسوا إليهم بعبادة من عبدوا ؛ فعبدوهم .
