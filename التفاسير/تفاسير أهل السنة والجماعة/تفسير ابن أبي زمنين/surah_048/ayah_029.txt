{ أشداء على الكفار رحماء بينهم } يعني : متوادين { تراهم ركعا سجدا } يعني : الصلوات الخمس { يبتغون فضلا من الله ورضوانا } بالصلاة والصوم والدين كله { سيماهم في وجوههم من أثر السجود } قال بعضهم : سيماهم في الآخرين يقومون غرا محجلين من أثر الوضوء { ذلك مثلهم في التوراة } أي : نعتهم { ومثلهم في الإنجيل } أي : ونعتهم في الإنجيل { كزرع أخرج شطأه } النعت الأول في التوراة ،   والنعت الآخر في الإنجيل و( شطأه ) : فراخه { فآزره } فشده { فاستغلظ } أي : فاشتد { فاستوى على سوقه } أي : أصوله .   قال محمد : يقال : قد أشطأ الزرع فهو مشطئ إذا أفرخ .   ومعنى ( آزره ) : أعانه وقواه ،   و( السوق ) جمع : ساق{[1284]} .  <br />
{ يعجب الزراع ليغيظ بهم الكفار } أي : يخرجون فيكونون قليلا كالزرع حين يخرج ضعيفا فيكثرون ويقوون ،   فشبههم بالزرع يعجب الزراع ليغيظ بهم الكفار .   يقولون : إنما يفعل ذلك بهم ليغيظ بهم الكفار { وعد الله الذين آمنوا وعملوا الصالحات منهم مغفرة وأجرا عظيما( 29 ) } يعني : الجنة .
