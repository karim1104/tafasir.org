{ فأرسله معي ردءا } أي : عونا { يصدقني } أي : يكون معي في الرسالة { إني أخاف أن يكذبون( 34 ) } .  <br />
قال محمد : يقال : ردأته على كذا ،   أي : أعنته ،   ومن قرأ ( يصدقني ) بالجزم فهو على جواب المسألة : أرسله يصدقني ،   ومن رفع ( يصدقني ) فالمعنى : ردءا مصدقا لي{[1024]} .  <br />
وذكر ابن مجاهد أن نافعا وحده قرأ ( ردا ) منونة بغير همز ،   وأن سائر القراء يقرءون : ( ردءا ) بالهمز .
