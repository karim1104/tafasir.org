{ وإذا مس الإنسان ضر } يعني : مرضا { دعا ربه منيبا إليه } أي : دعاه بالإخلاص أن يكشف عنه { ثم إذا خوله نعمة منه } أي : عافاه من ذلك المرض { نسي ما كان يدعو إليه من قبل } هو كقوله { مر كأن لم يدعنا إلى ضر مسه }[ يونس :12 ] .  <br />
قال محمد : كل شيء أعطيته فقد خولته ومن هذا قول زهير :<br />
                                هنالك إن يستخولوا المال يخولوا ***  وإن يسألوا يعطوا وإن ييسروا يغلوا<br />
ويقال : فلان يخول أهله إذا رعى غنمهم ،   أو ما أشبه ذلك .  <br />
{ وجعل لله أندادا } يعني : الأوثان ؛ الند في اللغة : العدل { ليضل عن سبيله } أي يتبعه على ذلك غيره { قل } يا محمد للمشرك { تمتع } في الدنيا { بكفرك قليلا } أي أن بقاءك في الدنيا قليل { إنك من أصحاب النار( 8 ) } .
