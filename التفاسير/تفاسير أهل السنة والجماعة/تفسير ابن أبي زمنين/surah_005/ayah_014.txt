{ ومن الذين قالوا إنا نصارى أخذنا ميثاقهم } أي : كما أخذنا ميثاق اليهود { فنسوا حظا مما ذكروا به } هي مثل الأولى .  <br />
{ فأغرينا بينهم العداوة } أي : ألقينا بينهم العداوة { والبغضاء } قال الحسن : يعني به عامتهم .  <br />
قال محمد : { أغرينا } حقيقته في اللغة : ألصقنا ،   وتأويل العداوة والبغضاء ؛ أي صاروا فرقا يكفر بعضهم بعضا .  <br />
