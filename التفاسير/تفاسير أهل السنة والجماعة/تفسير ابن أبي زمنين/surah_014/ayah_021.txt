{ وبرزوا لله جميعا } يعني : يوم القيامة { فقال الضعفاء } وهم الأتباع { للذين استكبروا } وهم الرؤساء : { إنا كنا لكم تبعا } لدعائكم إيانا إلى الشرك .  <br />
قال محمد : ( تبعا ) جمع تابع ،   وجائز أن يكون مصدرا سمي به ؛ أي : كنا ذوي تبع .   { سواء علينا أجزعنا أم صبرنا ما لنا من محيص } أي : مهرب ،   ولا معزل عن العذاب .  <br />
