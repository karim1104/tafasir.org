{ ومن يدع مع الله إلها آخر لا برهان له به } أي : لا حجة له بذلك { فإنما حسابه عند ربه } يعني : فإنما جزاؤه عند ربه { إنه لا يفلح الكافرون( 117 ) } وهي تقرأ : ( إنه ) بالكسر{[880]} على معنى : فإنما حسابه عند ربه أن يدخله النار ،   ثم قال : { إنه لا يفلح الكافرون( 117 ) }<br />
قال محمد : ومن قرأ بالفتح ،   فالمعنى بأنه .
