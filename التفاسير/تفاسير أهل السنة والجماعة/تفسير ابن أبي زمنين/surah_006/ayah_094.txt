{ ولقد جئتمونا فرادى كما خلقناكم أول مرة } يقول : خلقنا كل إنسان فردا ويأتينا يوم القيامة فردا .  <br />
قال محمد : { فرادى } جمع فرد ،   وكأنه جمع ( فردان ) ؛ كما قالوا : كسلان وكسالى .   { وتركتم ما خولناكم } أي : ما أعطيناكم { وراء ظهوركم } يعني : في الدنيا .  <br />
{ وما نرى معكم شفعاءكم } يعني : آلهتكم { الذين زعمتم أنهم فيكم شركاء } أي : أنهم شركاء لله فيكم ،   فعبدتموهم من دون الله { لقد تقطع بينكم } أي : وصلكم الذي كان يواصل به بعضكم بعضا على عبادة الأوثان .  <br />
هذا تفسير من قرأها بالرفع ومن قرأها بالنصب{[328]} فالمعنى : لقد تقطع ما بينكم من المواصلة .   { وضل عنكم ما كنتم تزعمون } أنها تشفع لكم .
