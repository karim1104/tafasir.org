{ فالق الإصباح } خالق الإصباح ،   يعني الصبح حين يضيء وكان الحسن يقرؤها : ( الأصباح ) جمع : صبح{[329]} .  <br />
و{ جعل الليل سكنا } يسكن فيه الخلق { والشمس والقمر حسبانا } قال الكلبي : يعني : حساب منازل الشمس والقمر ،   كل يوم بمنزل .  <br />
قال محمد : القراءة بالنصب : ( والشمس والقمر ) أي : وجعل الشمس والقمر ومن كلامهم : حد كل شيء بحسبانه أي بحسابه .
