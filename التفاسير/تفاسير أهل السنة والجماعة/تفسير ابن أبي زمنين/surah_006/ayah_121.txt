{ ولا تأكلوا مما لم يذكر اسم الله عليه وإنه لفسق } لشرك ؛ يقول : إن أكل الميتة على الاستحلال شرك .  <br />
{ وإن الشياطين ليوحون إلى أوليائهم } من المشركين { ليجادلوكم } تفسير مجاهد : قال : كان المشركون يجادلون المسلمين ( في ) الذبيحة ،   فيقولون : أما ما ذبحتم ( وقتلتم ) فتأكلونه وأما ما قتل الله فلا تأكلونه .   وأنتم بزعمكم تتبعون أمر الله ؟ فأنزل الله : { وإن أطعتموهم } فاستحللتم الميتة { إنكم لمشركون } .  <br />
