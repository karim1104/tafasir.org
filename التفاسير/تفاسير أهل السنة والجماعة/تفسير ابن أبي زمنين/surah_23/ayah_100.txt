{ لعلي أعمل صالحا فيما تركت } يعني : فيما ضيعت .   قال الله : لست براجع إلى الدنيا ،   ثم قال : { كلا إنها كلمة هو قائلها } يعني : هذه الكلمة : { رب ارجعون( 99 ) لعلي أعمل صالحا فيما تركت } .  <br />
{ ومن ورائهم برزخ إلى يوم يبعثون( 100 ) } قال السدي : البرزخ : ما بين النفختين .  <br />
قال محمد : وكل شيء بين شيئين فهو برزخ .
