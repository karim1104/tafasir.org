{ ومن قبله } من قبل القرآن { كتاب موسى إماما } يعني : التوراة ؛ يهتدون به { ورحمة } لمن آمن به { وهذا كتاب } يعني : القرآن { مصدق } للتوراة والإنجيل { لسانا عربيا لينذر{[1255]} الذين ظلموا } أشركوا { وبشرى للمحسنين( 12 ) } المؤمنين بالجنة .  <br />
قال محمد : { إماما } منصوب على الحال ،   { ورحمة } عطف عليه ،   { لسانا عربيا } منصوب أيضا على الحال ،   المعنى : مصدق لما بين يديه عربيا وذكر ( لسانا ) توكيدا .
