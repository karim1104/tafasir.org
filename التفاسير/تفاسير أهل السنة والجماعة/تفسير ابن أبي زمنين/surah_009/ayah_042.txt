فأنزل الله عز وجل فقال :{ لو كان عرضا قريبا } يعني : غنيمة قريبة { وسفرا قاصدا } أي : قريبا { لاتبعوك ولكن بعدت عليهم الشقة } يعني : السفر { وسيحلفون بالله لو استطعنا } يعني : لو وجدنا سعة في المال { لخرجنا معكم يهلكون أنفسهم } بالكذب { والله يعلم إنهم لكاذبون } أي : إنما اعتلوا بالكذب .  <br />
