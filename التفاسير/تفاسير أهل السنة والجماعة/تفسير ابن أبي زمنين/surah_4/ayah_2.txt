{ وآتوا اليتامى أموالهم } يعني إذا بلغوا { ولا تتبدلوا الخبيث بالطيب } قال الحسن { الخبيث } : أكل أموال اليتامى ظلما ،   و{ بالطيب } : الذي رزقكم الله ،   يقول : لا تذروا الطيب ،   وتأكلوا الخبيث { ولا تأكلوا أموالهم إلى أموالكم } يعني مع أموالكم { إنه كان حوبا كبيرا } أي ذنبا .   قال محمد : وفيه لغة أخرى : حوبا بفتح الحاء ،   وقد قرئ بها{[246]} .
