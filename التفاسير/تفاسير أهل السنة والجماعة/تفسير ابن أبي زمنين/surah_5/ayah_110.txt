{ إذ قال الله يا عيسى ابن مريم }<br />
 أي : يقوله يوم القيامة .   { اذكر نعمتي عليك وعلى والدتك إذ أيدتك } أعنتك .   { بروح القدس } يعني : جبريل { تكلم الناس في المهد } يعني : حجر أمه ،   { وكهلا } أي : كبيرا  ،   { وإذ تخلق من الطين كهيئة الطير } يعني : كشبه الطير ،   { وتبرئ الأكمه } يعني : الأعمى ( الذي تلده ) أمه وهو مضموم العينين .  <br />
