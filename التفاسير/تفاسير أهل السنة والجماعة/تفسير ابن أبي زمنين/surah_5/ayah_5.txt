{ اليوم أحل لكم الطيبات وطعام الذين أوتوا الكتاب حل لكم } يعني : ذبائحهم { وطعامكم حل لهم والمحصنات من المؤمنات والمحصنات من الذين أوتوا الكتاب من قبلكم } المحصنات هاهنا : الحرائر ولا يحل نكاح إماء أهل الكتاب { إذا آتيتموهن أجورهن } يعني الصداق إذا سمى ولا بأس أن يدخل عليها قبل أن يعطيها إياه .  <br />
{ محصنين غير مسافحين } يعني : ناكحين غير زانين { ولا متخذي أخدان } يعني : الخليل والخليلة في السر .  <br />
{ ومن يكفر بالإيمان فقد حبط عمله } قال قتادة : لما نزل تحليل نساء أهل الكتاب ذكر لنا أن رجالا قالوا : كيف نتزوج نساء على غير ديننا ؟ فأنزل الله { ومن يكفر بالإيمان } الآية .  <br />
