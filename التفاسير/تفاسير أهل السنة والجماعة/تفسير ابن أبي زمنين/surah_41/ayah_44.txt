{ ولو جعلناه قرآنا أعجميا لقالوا لولا } هلا { فصلت آياته } أي : بينت { أعجمي وعربي } أي : بالعجمية والعربية على مقرإ من قرأها بغير استفهام ومن قرأها على الاستفهام مدها { آأعجمي وعربي } أي : لقالوا : كتاب أعجمي ( ونبي ) عربي يحتجون بذلك ؛ أي : كيف يكون هذا ؟ !<br />
قال محمد : من قرأها بلا مد فالمعنى : جعل بعضه بيانا للعجم ،   وبعضه بيانا للعرب .  <br />
قال الله : { قل هو للذين آمنوا هدى وشفاء } لصدورهم يشفيهم مما كانوا فيه من الشك والشرك { والذين لا يؤمنون في آذانهم وقر } أي : صمم عن الإيمان { وهو عليهم عمى } [ يزدادون عمى ]{[1203]} إلى عماهم إذ لم يؤمنوا { أولئك ينادون } بالإيمان { من مكان بعيد( 44 ) } تفسير بعضهم بعيد من قلوبهم .
