{ وقال الذين لا يعلمون } وهم مشركو العرب { لولا } هلا { يكلمنا الله أو تأتينا آية كذلك قال الذين من قبلهم مثل قولهم } يعني قول قوم موسى لموسى عليه السلام : { أرنا الله جهرة } [ النساء : 153 ] وما سألوا من الآيات { تشابهت قلوبهم } في الكفر مثل قوله : { يضاهئون قول الذين كفروا من قبل } [ التوبة : 30 ] { قد بينا الآيات لقوم يوقنون } يصدقون .   قال محمد : يعني الآيات التي أتي بها صلوات الله عليه في نحو انشقاق القمر ،   وغير ذلك من آياته .
