{ وجاهدوا في الله حق جهاده } هي مثل قوله : { اتقوا الله حق تقاته }{[848]} وهما منسوختان ،   نسختهما الآية التي في التغابن { فاتقوا الله ما استطعتم }{[849]} .  <br />
{ وما جعل عليكم في الدين من حرج } أي : من ضيق .   { ملة أبيكم إبراهيم هو سماكم المسلمين } يقول الله : سماكم المسلمين من قبل ،   أي : من قبل هذا القرآن في الكتب كلها وفي الذكر ،   { وفي هذا } القرآن .   قال محمد : ( ملة أبيكم ) المعنى : اتبعوا ملة أبيكم{[850]} .  <br />
{ ليكون الرسول شهيدا عليكم } بأنه قد بلغ { وتكونوا شهداء على الناس } .  <br />
بأن الرسل قد بلغت قومها .  <br />
{ واعتصموا بالله } أي : بدين الله { هو مولاكم } وليكم { فنعم المولى } الولي { ونعم النصير( 78 ) } وعدهم النصر على أعدائهم من المشركين .
