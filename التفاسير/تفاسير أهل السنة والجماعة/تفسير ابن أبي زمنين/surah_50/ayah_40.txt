{ ومن الليل فسبحه } يعني : صلاة المغرب وصلاة العشاء  { وأدبار السجود( 40 ) } يحيى : عن عثمان ،   عن أبي إسحاق الهمداني ،   عن الحارث ،   عن علي قال :  " سئل رسول الله صلى الله عليه وسلم عن { أدبار السجود } فقال : هما ( الركعتين ) بعد صلاة المغرب ،   وسئل عن { إدبار النجوم } فقال : هما الركعتان قبل صلاة الصبح " {[1305]} .  <br />
قال محمد : ومن قرأ { وأدبار } بكسر الألف فعلى المصدر ،   يقول : أدبر إدبارا .
