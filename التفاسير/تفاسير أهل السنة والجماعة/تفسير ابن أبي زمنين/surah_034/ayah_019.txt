{ فقالوا ربنا باعد بين أسفارنا } قال الحسن : ملوا النعمة كما ملت بنو إسرائيل المن والسلوى .  <br />
قال الله : { وظلموا أنفسهم } بشركهم { فجعلناهم أحاديث } لمن بعدهم { ومزقناهم كل ممزق } أي : بددنا عظامهم وأوصالهم فأكلهم التراب .   قال محمد : وقد قيل في قوله : { ومزقناهم كل ممزق } أي : مزقناهم في البلاد ؛ لأنهم لما أذهب الله جنتيهم وغرق مكانهم تبددوا في البلاد ؛ فصارت العرب تتمثل بهم في الفرقة فتقول : تفرقوا أيدي سبأ ،   وأيادي سبأ ،   إذا أخذوا في وجوه مختلفة .  <br />
{ إن في ذلك لآيات لكل صبار } على أمر الله { شكور } لنعمة الله وهو المؤمن .  <br />
