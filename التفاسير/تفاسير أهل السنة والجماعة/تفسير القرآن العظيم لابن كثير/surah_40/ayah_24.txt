{ إِلَى فِرْعَوْنَ } هو : ملك القبط بالديار المصرية ،   { وَهَامَانَ } وهو : وزيره في مملكته { وَقَارُونَ } وكان أكثر الناس في زمانه مالا وتجارة { فَقَالُوا سَاحِرٌ كَذَّابٌ } أي : كذبوه وجعلوه ساحرًا مُمَخْرِقًا مموهًا كذابًا في أن الله أرسله .   وهذه كقوله [ تعالى ] {[25488]} : { كَذَلِكَ مَا أَتَى الَّذِينَ مِنْ قَبْلِهِمْ مِنْ رَسُولٍ إِلا قَالُوا سَاحِرٌ أَوْ مَجْنُونٌ أَتَوَاصَوْا بِهِ بَلْ هُمْ قَوْمٌ طَاغُونَ } [ الذاريات 52 ،   53 ] .
