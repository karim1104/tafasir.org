وقوله{[28624]} { هُوَ اللَّهُ الَّذِي لا إِلَهَ إِلا هُوَ الْمَلِكُ } أي : المالك لجميع الأشياء المتصرف فيها بلا ممانعة ولا مدافعة .  <br />
وقوله : { الْقُدُّوسُ } قال وهب بن منبه : أي الطاهر .   وقال مجاهد ،   وقتادة : أي المبارك : وقال ابن جريج : تقدسه الملائكة الكرام .  <br />
{ السَّلامُ } أي : من جميع العيوب والنقائص ؛ بكماله{[28625]} في ذاته وصفاته وأفعاله .  <br />
وقوله : { الْمُؤْمِنُ } قال الضحاك ،   عن ابن عباس : [ أي ] {[28626]} أمن خلقه من أن يظلمهم .   وقال قتادة : أمَّن بقوله : إنه حق .   وقال ابن زيد : صَدّق عبادَه المؤمنين في أيمانهم به .  <br />
وقوله : { الْمُهَيْمِنُ } قال ابن عباس وغير واحد : أي{[28627]} الشاهد على خلقه بأعمالهم ،   بمعنى : هو رقيب عليهم ،   كقوله : { وَاللَّهُ عَلَى كُلِّ شَيْءٍ شَهِيدٌ } [ البروج : 9 ] ،   وقوله { ثُمَّ اللَّهُ شَهِيدٌ عَلَى مَا يَفْعَلُونَ } [ يونس : 46 ] .  <br />
وقوله : { أَفَمَنْ هُوَ قَائِمٌ عَلَى كُلِّ نَفْسٍ بِمَا كَسَبَتْ } الآية [ الرعد : 33 ] .  <br />
وقوله : { الْعَزِيزُ } أي : الذي قد عزّ كل شيء فقهره ،   وغلب الأشياء فلا ينال جنابه ؛ لعزته وعظمته وجبروته وكبريائه ؛ ولهذا قال : { الْجَبَّارُ الْمُتَكَبِّرُ } أي : الذي لا تليق الجَبْرّية إلا له ،   ولا التكبر إلا لعظمته ،   كما تقدم في الصحيح :  " العَظَمة إزاري ،   والكبرياء ردائي ،   فمن نازعني واحدًا منهما عَذَّبته "  .  <br />
وقال قتادة : { الجبار  } : الذي جَبَر خلقه على ما يشاء .  <br />
وقال ابن جرير : { الجبار  } : المصلحُ أمورَ خلقه ،   المتصرف فيهم بما فيه صلاحهم .  <br />
وقال قتادة : { المتكبر  } : يعني عن كل سوء .  <br />
ثم قال : { سُبْحَانَ اللَّهِ عَمَّا يُشْرِكُونَ } {[28628]} .
