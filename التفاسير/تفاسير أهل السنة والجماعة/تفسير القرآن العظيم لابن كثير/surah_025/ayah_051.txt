يقول تعالى : { وَلَوْ شِئْنَا لَبَعَثْنَا فِي كُلِّ قَرْيَةٍ نَذِيرًا } يدعوهم إلى الله عز وجل ،   ولكنا خصصناك - يا محمد - بالبعثة إلى جميع أهل الأرض ،   وأمرناك أن تبلغ الناس هذا القرآن ،   { لأنْذِرَكُمْ بِهِ وَمَنْ بَلَغَ } [ الأنعام : 19 ] ،   { وَمَنْ يَكْفُرْ بِهِ مِنَ الأحْزَابِ فَالنَّارُ مَوْعِدُهُ } [ هود : 17 ] { وَلِتُنْذِرَ أُمَّ الْقُرَى وَمَنْ حَوْلَهَا } [ الأنعام : 92 ] ،   { قُلْ يَا أَيُّهَا النَّاسُ إِنِّي رَسُولُ اللَّهِ إِلَيْكُمْ جَمِيعًا } [ الأعراف : 158 ] .   وفي الصحيحين :  " بعثت إلى الأحمر والأسود "  وفيهما :  " وكان النبي يبعث إلى قومه خاصة وبعثت إلى الناس عامة "  ؛ ولهذا قال : { فَلا تُطِعِ الْكَافِرِينَ وَجَاهِدْهُمْ بِهِ }
