يذكر تعالى أنه فرقهم في الأرض أمما ،   أي : طوائف وفرقًا ،   كما قال [ تعالى ]{[12287]} { وَقُلْنَا مِنْ بَعْدِهِ لِبَنِي إِسْرَائِيلَ اسْكُنُوا الأرْضَ فَإِذَا جَاءَ وَعْدُ الآخِرَةِ جِئْنَا بِكُمْ لَفِيفًا } [ الأسراء : 104 ]<br />
{ مِنْهُمُ الصَّالِحُونَ وَمِنْهُمْ دُونَ ذَلِكَ } أي : فيهم الصالح وغير ذلك ،   كما قالت الجن : { وَأَنَّا مِنَّا الصَّالِحُونَ وَمِنَّا دُونَ ذَلِكَ كُنَّا طَرَائِقَ قِدَدًا } [ الجن : 11 ] ،   { وَبَلَوْنَاهُمْ } أي : اختبرناهم { بِالْحَسَنَاتِ وَالسَّيِّئَاتِ } أي : بالرخاء والشدة ،   والرغبة والرهبة ،   والعافية والبلاء ،   { لَعَلَّهُمْ يَرْجِعُونَ }
