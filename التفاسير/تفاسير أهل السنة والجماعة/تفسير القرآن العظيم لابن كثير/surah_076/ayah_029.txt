ثم قال تعالى : { إِنَّ هَذِهِ } يعنى : هذه السورة { تَذْكِرَةٌ فَمَنْ شَاءَ اتَّخَذَ إِلَى رَبِّهِ سَبِيلا } أي طريقا ومسلكا ،   أي : من شاء اهتدى بالقرآن ،   كقوله : { وَمَاذَا عَلَيْهِمْ لَوْ آمَنُوا بِاللَّهِ وَالْيَوْمِ الآخِرِ وَأَنْفَقُوا مِمَّا رَزَقَهُمُ اللَّهُ وَكَانَ اللَّهُ بِهِمْ عَلِيمًا } [ النساء : 39 ] .
