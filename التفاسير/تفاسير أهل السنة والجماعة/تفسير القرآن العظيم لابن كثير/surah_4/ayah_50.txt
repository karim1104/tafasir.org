وقوله : { انْظُرْ كَيْفَ يَفْتَرُونَ عَلَى اللَّهِ الْكَذِبَ } أي : في تزكيتهم أنفسهم ودعواهم أنهم أبناء الله وأحباؤه وقولهم : { لَنْ يَدْخُلَ الْجَنَّةَ إِلا مَنْ كَانَ هُودًا أَوْ نَصَارَى } [ البقرة : 111 ] وقولهم : { لَنْ تَمَسَّنَا النَّارُ إِلا أَيَّامًا مَعْدُودَةً } [ البقرة : 80 ] واتكالهم{[7741]} على أعمال آبائهم الصالحة ،   وقد حكم الله أن أعمال الآباء لا تجزي عن الأبناء شيئا ،   في قوله : { تِلْكَ أُمَةٌ قَدْ خَلَتْ لَهَا مَا كَسَبَتْ وَلَكُمْ مَا كَسَبْتُمْ [ وَلا تُسْأَلُونَ عَمَّا كَانُوا يَعْمَلُونَ ]{[7742]} } [ البقرة : 141 ] .  <br />
ثم قال : { وَكَفَى بِهِ إِثْمًا مُبِينًا } أي : وكفى بصنعهم{[7743]} هذا كذبا وافتراء ظاهرا .
