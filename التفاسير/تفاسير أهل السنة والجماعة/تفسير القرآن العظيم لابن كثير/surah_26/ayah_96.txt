{ قَالُوا وَهُمْ فِيهَا يَخْتَصِمُونَ تَاللَّهِ إِنْ كُنَّا لَفِي ضَلالٍ مُبِينٍ إِذْ نُسَوِّيكُمْ بِرَبِّ الْعَالَمِينَ } أي : يقول الضعفاء الذين استكبروا : { إِنَّا كُنَّا لَكُمْ تَبَعًا فَهَلْ أَنْتُمْ مُغْنُونَ عَنَّا نَصِيبًا مِنَ النَّارِ } [ غافر : 47 ] .   ويقولون وقد عادوا على أنفسهم بالملامة : { تَاللَّهِ إِنْ كُنَّا لَفِي ضَلالٍ مُبِينٍ إِذْ نُسَوِّيكُمْ بِرَبِّ الْعَالَمِينَ } أي : نجعل أمركم مطاعًا كما يطاع أمر رب العالمين ،   وعبدناكم مع ربِ العالمين .
