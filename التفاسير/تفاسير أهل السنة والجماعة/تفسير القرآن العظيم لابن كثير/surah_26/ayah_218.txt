وقوله : { الَّذِي يَرَاكَ حِينَ تَقُومُ } أي : هو معتن بك ،   كما قال تعالى : { وَاصْبِرْ{[21912]} لِحُكْمِ رَبِّكَ فَإِنَّكَ بِأَعْيُنِنَا } [ الطور : 48 ] .  <br />
قال ابن عباس : { الَّذِي يَرَاكَ حِينَ تَقُومُ } يعني : إلى الصلاة .  <br />
وقال عكرمة : يرى قيامه وركوعه وسجوده .  <br />
وقال الحسن : { الَّذِي يَرَاكَ حِينَ تَقُومُ } : إذا صليت وحدك .  <br />
وقال الضحاك : { الَّذِي يَرَاكَ حِينَ تَقُومُ .   } أي : من فراشك أو مجلسك .  <br />
وقال قتادة : { الَّذِي يَرَاكَ } : قائما وجالسا وعلى حالاتك .
