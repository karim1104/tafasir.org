بسم الله الرحمن الرحيم<br />
يقول تعالى : { الَّذِينَ كَفَرُوا } أي : بآيات الله ،   { وصدوا } غيرهم { عَنْ سَبِيلِ اللَّهِ أَضَلَّ أَعْمَالَهُمْ } أي : أبطلها وأذهبها ،   ولم يجعل لها جزاء ولا ثوابا ،   كقوله تعالى : { وَقَدِمْنَا إِلَى مَا عَمِلُوا مِنْ عَمَلٍ فَجَعَلْنَاهُ هَبَاءً مَنْثُورًا } [ الفرقان : 23 ] .
