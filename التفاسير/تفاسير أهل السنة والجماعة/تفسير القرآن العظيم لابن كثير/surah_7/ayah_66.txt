{ قَالَ الْمَلأ الَّذِينَ كَفَرُوا مِنْ قَوْمِهِ } - والملأ هم : الجمهور والسادة والقادة منهم - : { إِنَّا لَنَرَاكَ فِي سَفَاهَةٍ وَإِنَّا لَنَظُنُّكَ مِنَ الْكَاذِبِينَ } أي : في ضلالة حيث دعوتنا إلى ترك عبادة الأصنام ،   والإقبال إلى عبادة الله وحده [ لا شريك له ]{[11868]} كما تعجب الملأ من قريش من الدعوة إلى إله واحد { فقالوا } { أَجَعَلَ الآلِهَةَ إِلَهًا وَاحِدًا [ إِنَّ هَذَا لَشَيْءٌ عُجَابٌ{[11869]} ] } [ صّ : 5 ] .
