وقوله : { وَإِنْ كَانَ طَائِفَةٌ مِنْكُمْ آمَنُوا بِالَّذِي أُرْسِلْتُ بِهِ وَطَائِفَةٌ لَمْ يُؤْمِنُوا } أي : [ قد ]{[11964]} اختلفتم عليّ { فاصبروا } أي : انتظروا { حَتَّى يَحْكُمَ اللَّهُ بَيْنَنَا } أي : يفصل ،   { وَهُوَ خَيْرُ الْحَاكِمِينَ } فإنه سيجعل العاقبة للمتقين ،   والدمار على الكافرين .
