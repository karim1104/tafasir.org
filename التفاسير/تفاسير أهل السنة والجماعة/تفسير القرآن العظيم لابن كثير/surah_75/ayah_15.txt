وقال مجاهد : { وَلَوْ أَلْقَى مَعَاذِيرَهُ } ولو جادل عنها فهو بصير عليها .   وقال قتادة : { وَلَوْ أَلْقَى مَعَاذِيرَهُ } ولو اعتذر يومئذ بباطل لا يقبل منه .   وقال السدي : { وَلَوْ أَلْقَى مَعَاذِيرَهُ } حجته .   وكذا قال ابن زيد ،   والحسن البصري ،   وغيرهم .   واختاره ابن جرير .  <br />
وقال قتادة ،   عن زرارة ،   عن ابن عباس : { وَلَوْ أَلْقَى مَعَاذِيرَهُ } يقول : لو ألقى ثيابه .  <br />
وقال الضحاك : ولو أرخى ستوره ،   وأهل اليمن يسمون الستر : المعذار .  <br />
والصحيح قول مجاهد وأصحابه ،   كقوله : { ثُمَّ لَمْ تَكُنْ فِتْنَتُهُمْ إِلا أَنْ قَالُوا وَاللَّهِ رَبِّنَا مَا كُنَّا مُشْرِكِينَ } [ الأنعام : 23 ] وكقوله { يَوْمَ يَبْعَثُهُمُ اللَّهُ جَمِيعًا فَيَحْلِفُونَ لَهُ كَمَا يَحْلِفُونَ لَكُمْ وَيَحْسَبُونَ أَنَّهُمْ عَلَى شَيْءٍ أَلا إِنَّهُمْ هُمُ الْكَاذِبُونَ } [ المجادلة : 18 ] .  <br />
وقال العوفي ،   عن ابن عباس : { وَلَوْ أَلْقَى مَعَاذِيرَهُ } هي الاعتذار{[29545]}  ألم تسمع أنه قال : { لا يَنْفَعُ الظَّالِمِينَ مَعْذِرَتُهُمْ } [ غافر : 52 ] وقال { وَأَلْقَوْا إِلَى اللَّهِ يَوْمَئِذٍ السَّلَمَ } [ النحل : 87 ] { فَأَلْقَوُا السَّلَمَ مَا كُنَّا نَعْمَلُ مِنْ سُوءٍ } [ النحل : 28 ] وقولهم { وَاللَّهِ رَبِّنَا مَا كُنَّا مُشْرِكِينَ }
