ثم قال تعالى : { يُنَبَّأُ الإنْسَانُ يَوْمَئِذٍ بِمَا قَدَّمَ وَأَخَّرَ } أي : يخبر بجميع أعماله قديمها وحديثها ،   أولها وآخرها ،   صغيرها وكبيرها ،   كما قال تعالى : { وَوَجَدُوا مَا عَمِلُوا حَاضِرًا وَلا يَظْلِمُ رَبُّكَ أَحَدًا } [ الكهف : 49 ] وهكذا قال هاهنا : { بَلِ الإنْسَانُ عَلَى نَفْسِهِ بَصِيرَةٌ وَلَوْ أَلْقَى مَعَاذِيرَهُ }
