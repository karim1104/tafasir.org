يقول تعالى : ولقد أرسلنا { إِلَى ثَمُودَ } وهم الذين كانوا يسكنون{[14707]} مدائن الحجر بين تبوك والمدينة ،   وكانوا بعد عاد ،   فبعث الله منهم{[14708]} { أَخَاهُمْ صَالِحًا } فأمرهم{[14709]} بعبادة الله وحده [ لا شريك له الخالق الرازق ]{[14710]} ؛ ولهذا قال : { هُوَ أَنْشَأَكُمْ مِنَ الأرْضِ } أي : ابتدأ خلقكم منها ،   [ من الأرض التي ]{[14711]} خلق منها أباكم آدم ،   { وَاسْتَعْمَرَكُمْ فِيهَا } أي : جعلكم [ فيها ]{[14712]} عُمَّارا تعمرونها وتستغلونها ،   لسالف ذنوبكم ،   { ثُمَّ تُوبُوا إِلَيْهِ } فيما تستقبلونه ؛ { إِنَّ رَبِّي قَرِيبٌ مُجِيبٌ } كما قال تعالى : { وَإِذَا سَأَلَكَ عِبَادِي عَنِّي فَإِنِّي قَرِيبٌ أُجِيبُ دَعْوَةَ الدَّاعِ إِذَا دَعَانِ } الآية [ البقرة : 186 ] .
