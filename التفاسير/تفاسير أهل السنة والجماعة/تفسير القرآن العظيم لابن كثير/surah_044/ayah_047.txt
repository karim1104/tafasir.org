وقوله : { خُذُوهُ فَاعْتِلُوهُ } أي : [ خذوا ] {[26270]} الكافر ،   وقد ورد أنه تعالى إذا قال للزبانية { خُذُوهُ } ابتدره سبعون ألفًا منهم .  <br />
{ فَاعْتِلُوهُ } أي : سوقوه سحبا ودفعا في ظهره .  <br />
قال مجاهد : { خُذُوهُ فَاعْتِلُوهُ } أي : خذوه فادفعوه .  <br />
وقال الفرزدق :<br />
لَيسَ الكِرَامُ بِنَاحِلِيكَ أَبَاهُمُ*** حَتَّى تُرَدَّ إلى عَطيَّة تُعْتَلُ{[26271]}  {[26272]}<br />
{ إِلَى سَوَاءِ الْجَحِيمِ } أي : وسطها .
