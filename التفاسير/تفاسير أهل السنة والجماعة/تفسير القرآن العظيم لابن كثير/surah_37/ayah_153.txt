قال منكرا عليهم : { أَصْطَفَى الْبَنَاتِ عَلَى الْبَنِينَ } أي : أيّ شيء يحمله عن أن يختار البنات دون البنين ؟ كقوله : { أَفَأَصْفَاكُمْ رَبُّكُمْ بِالْبَنِينَ وَاتَّخَذَ مِنَ الْمَلائِكَةِ إِنَاثًا إِنَّكُمْ لَتَقُولُونَ قَوْلا عَظِيمًا } [ الإسراء : 40 ] ،  ولهذا قال : { مَا لَكُمْ كَيْفَ تَحْكُمُونَ }
