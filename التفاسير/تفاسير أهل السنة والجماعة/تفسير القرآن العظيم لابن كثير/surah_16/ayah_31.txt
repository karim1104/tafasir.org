وقوله : { جَنَّاتُ عَدْنٍ } بدل من [ قوله ]{[16411]} : { دَارُ الْمُتَّقِينَ } أي : لهم في [ الدار ]{[16412]} الآخرة { جَنَّاتُ عَدْنٍ } أي : إقامة{[16413]} يدخلونها { تَجْرِي مِنْ تَحْتِهَا الأنْهَارُ } أي : بين أشجارها وقصورها ،   { لَهُمْ فِيهَا مَا يَشَاءُونَ } كما قال تعالى : { وَفِيهَا مَا تَشْتَهِيهِ{[16414]} الأنْفُسُ وَتَلَذُّ الأعْيُنُ وَأَنْتُمْ فِيهَا خَالِدُونَ } [ الزخرف : 71 ] ،   وفي الحديث :  " إن السحابة لتمر بالملأ من أهل الجنة وهم جلوس على شرابهم{[16415]} ،   فلا يشتهي أحد منهم شيئًا إلا أمطرته عليهم ،   حتى إن منهم لمن يقول : أمطرينا كواعب أترابًا ،   فيكون ذلك{[16416]} "  {[16417]} .  <br />
{ كَذَلِكَ يَجْزِي اللَّهُ الْمُتَّقِينَ } أي : كذلك{[16418]} يجزي الله كل من آمن به واتقاه وأحسن عمله .
