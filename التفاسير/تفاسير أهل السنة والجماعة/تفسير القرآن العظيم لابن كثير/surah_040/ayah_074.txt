{ قَالُوا ضَلُّوا عَنَّا } أي : ذهبوا فلم ينفعونا ،   { بَلْ لَمْ نَكُنْ نَدْعُو مِنْ قَبْلُ شَيْئًا } أي : جحدوا عبادتهم ،   كقوله تعالى : { ثُمَّ لَمْ تَكُنْ فِتْنَتُهُمْ إِلا أَنْ قَالُوا وَاللَّهِ رَبِّنَا مَا كُنَّا مُشْرِكِينَ } [ الانعام : 23 ] ؛ ولهذا قال : { كَذَلِكَ يُضِلُّ اللَّهُ الْكَافِرِينَ } .
