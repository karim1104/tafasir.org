وأخبر تعالى أن منهم { مَنْ يَتَّخِذُ مَا يُنْفِقُ } أي : في سبيل الله { مَغْرَمًا } أي : غرامة وخسارة ،   { وَيَتَرَبَّصُ بِكُمُ الدَّوَائِرَ } أي : ينتظر بكم{[13797]} الحوادث والآفات ،   { عَلَيْهِمْ دَائِرَةُ السَّوْءِ } أي : هي منعكسة عليهم والسوء دائر عليهم ،   { وَاللَّهُ سَمِيعٌ عَلِيمٌ } أي : سميع لدعاء عباده ،   عليم بمن يستحق النصر ممن يستحق الخذلان .
