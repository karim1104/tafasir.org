يقول تعالى :  " وَقَفَّيْنَا "  أي : أتبعنا { عَلَى آثَارِهِمْ } يعني : أنبياء بني إسرائيل [ عليه السلام ]{[9918]} { بِعِيسَى ابْنِ مَرْيَمَ مُصَدِّقًا لِمَا بَيْنَ يَدَيْهِ مِنَ التَّوْرَاةِ } أي : مؤمنًا بها حاكمًا بما فيها { وَآتَيْنَاهُ الإنْجِيلَ فِيهِ هُدًى وَنُورٌ } أي : هدى إلى الحق ،   ونور يستضاء به في إزالة الشبهات وحل المشكلات .   { وَمُصَدِّقًا لِمَا بَيْنَ يَدَيْهِ مِنَ التَّوْرَاةِ } أي : متبعًا لها ،   غير مخالف لما فيها ،   إلا في القليل مما بين لبني إسرائيل بعض ما كانوا يختلفون فيه ،   كما قال تعالى إخبارًا عن المسيح أنه قال لبني إسرائيل : { وَلأحِلَّ لَكُمْ بَعْضَ الَّذِي حُرِّمَ عَلَيْكُمْ } [ آل عمران : 50 ] ؛ ولهذا كان المشهور من قولي العلماء أن الإنجيل نسخ بَعْضَ أحكام التوراة .  <br />
وقوله : { وَهُدًى وَمَوْعِظَةٌ لِلْمُتَّقِينَ } أي : وجعلنا الإنجيل { هُدًى } يهتدى به ،   { وَمَوْعِظَةً } أي : وزاجرًا{[9919]} عن ارتكاب المحارم والمآثم { لِلْمُتَّقِينَ } أي : لمن اتقى الله وخاف وعيده وعقابه .
