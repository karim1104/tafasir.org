{ قُلْ نَعَمْ وَأَنْتُمْ دَاخِرُونَ } أي : قل لهم يا محمد : نعم تبعثون يوم القيامة بعد ما تصيرون ترابا وعظاما ،   { وَأَنْتُمْ دَاخِرُونَ } أي : حقيرون تحت القدرة العظيمة ،   كما قال تعالى { وَكُلٌّ أَتَوْهُ دَاخِرِينَ } [ النمل : 87 ] ،   وقال : { إِنَّ الَّذِينَ يَسْتَكْبِرُونَ عَنْ عِبَادَتِي سَيَدْخُلُونَ جَهَنَّمَ دَاخِرِينَ } [ غافر : 60 ] .
