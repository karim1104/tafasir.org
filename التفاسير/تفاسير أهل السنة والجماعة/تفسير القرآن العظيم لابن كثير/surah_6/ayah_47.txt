وقوله : { قُلْ أَرَأَيْتَكُمْ إِنْ أَتَاكُمْ عَذَابُ اللَّهِ بَغْتَةً } أي : وأنتم لا تشعرون به حتى بغتكم وفجأكم .  <br />
{ أَوْ جَهْرَةً } أي : ظاهرًا عيانًا { هَلْ يُهْلَكُ إِلا الْقَوْمُ الظَّالِمُونَ } أي : إنما : كان يحيط بالظالمين أنفسهم بالشرك بالله [ عَزَّ وجل ]{[10691]} وينجو الذين كانوا يعبدون الله وحده لا شريك له ،   فلا خوف عليهم ولا هم يحزنون .   كما قال تعالى { الَّذِينَ آمَنُوا وَلَمْ يَلْبِسُوا إِيمَانَهُمْ بِظُلْمٍ [ أُولَئِكَ لَهُمُ الأمْنُ وَهُمْ مُهْتَدُونَ ] {[10692]} } [ الأنعام : 82 ] .
