البصائر : هي البينات والحجج التي اشتمل عليها القرآن ،   وما جاء به الرسول صلى الله عليه وسلم { فَمَنْ أَبْصَرَ فَلِنَفْسِهِ } مثل قوله : { مَنِ اهْتَدَى فَإِنَّمَا يَهْتَدِي لِنَفْسِهِ وَمَنْ ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } [ الإسراء : 15 ] ؛ ولهذا قال : { وَمَنْ عَمِيَ فَعَلَيْهَا } لما ذكر البصائر قال :<br />
{ وَمَنْ عَمِيَ فَعَلَيْهَا } أي : فإنما يعود وبال ذلك عليه ،   كقوله : { فَإِنَّهَا لا تَعْمَى الأبْصَارُ وَلَكِنْ تَعْمَى الْقُلُوبُ الَّتِي فِي الصُّدُورِ } [ الحج : 46 ] .  <br />
{ وَمَا أَنَا عَلَيْكُمْ بِحَفِيظٍ } أي : بحافظ ولا رقيب ،   بل أنا مبلغ والله يهدي من يشاء ويضل من يشاء .
