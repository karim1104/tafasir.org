يقول تعالى مخبرًا عن إبليس وتمرده وعتوه أنه قال للرب : { بِمَا أَغْوَيْتَنِي } قال بعضهم : أقسم بإغواء الله له .  <br />
قلت : ويحتمل أنه بسبب ما أغويتني وأضللتني { لأزَيِّنَنَّ لَهُمْ } أي : لذرية آدم ،   عليه السلام { فِي الأرْضِ } أي : أحبب إليهم المعاصي وأرغّبهم فيها ،   وأؤزّهم إليها ،   وأزعجهم إزعاجًا ،   { وَلأغْوِيَنَّهُمْ } أي : كما أغويتني ونَدَّرت على ذلك ،   { أَجْمَعِينَ إِلا عِبَادَكَ مِنْهُمُ الْمُخْلَصِينَ } كَمَا قَالَ { أَرَأَيْتَكَ هَذَا الَّذِي كَرَّمْتَ عَلَيَّ لَئِنْ أَخَّرْتَنِي إِلَى يَوْمِ الْقِيَامَةِ لأحْتَنِكَنَّ ذُرِّيَّتَهُ إِلا قَلِيلا } [ الإسراء : 62 ]
