وقوله : { ذَرْهُمْ يَأْكُلُوا وَيَتَمَتَّعُوا } تهديد لهم شديد ،   ووعيد أكيد ،   كقوله تعالى : { قُلْ تَمَتَّعُوا فَإِنَّ مَصِيرَكُمْ إِلَى النَّارِ } [ إبراهيم : 30 ] وقوله : { كُلُوا وَتَمَتَّعُوا قَلِيلا إِنَّكُمْ مُجْرِمُونَ } [ المرسلات : 46 ] ولهذا قال : { وَيُلْهِهِمُ الأمَلُ } أي : عن التوبة والإنابة ،   { فَسَوْفَ يَعْلَمُونَ } أي : عاقبة أمرهم .
