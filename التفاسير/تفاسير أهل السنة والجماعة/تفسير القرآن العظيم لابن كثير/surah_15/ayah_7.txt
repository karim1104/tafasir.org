{ لَوْ مَا } أي : هلا{ تَأْتِينَا بِالْمَلائِكَةِ } أي : يشهدون لك بصحة ما جئت به { إِنْ كُنْتَ مِنَ الصَّادِقِينَ } كما قال فرعون : { فَلَوْلا أُلْقِيَ عَلَيْهِ أَسَاوِرَةٌ مِنْ ذَهَبٍ أَوْ جَاءَ مَعَهُ الْمَلائِكَةُ مُقْتَرِنِينَ } [ الزخرف : 53 ] { وَقَالَ الَّذِينَ لا يَرْجُونَ لِقَاءَنَا لَوْلا أُنزلَ عَلَيْنَا الْمَلائِكَةُ أَوْ نَرَى رَبَّنَا لَقَدْ اسْتَكْبَرُوا فِي أَنْفُسِهِمْ وَعَتَوْا عُتُوًّا كَبِيرًا يَوْمَ يَرَوْنَ الْمَلائِكَةَ لا بُشْرَى يَوْمَئِذٍ لِلْمُجْرِمِينَ وَيَقُولُونَ حِجْرًا مَحْجُورًا } [ الفرقان : 21 ،   22 ]
