يقول تعالى : { قُلْ } يا محمد لهؤلاء المكذبين المشركين : { إِنَّمَا أَنَا بَشَرٌ مِثْلُكُمْ يُوحَى إِلَيَّ أَنَّمَا إِلَهُكُمْ إِلَهٌ وَاحِدٌ } لا كما تعبدونه{[25627]}  من الأصنام والأنداد والأرباب المتفرقين ،   إنما الله إله واحد ،   { فَاسْتَقِيمُوا إِلَيْهِ } أي : أخلصوا له العبادة على منوال ما أمركم به على ألسنة الرسل ،   { وَاسْتَغْفِرُوهُ } أي : لسالف الذنوب ،   { وَوَيْلٌ لِلْمُشْرِكِينَ } أي : دمار لهم وهلاك عليهم .
