وقوله : { وَمِنْ آيَاتِهِ } أي : على قدرته على إعادة الموتى { أَنَّكَ تَرَى الأرْضَ خَاشِعَةً } أي : هامدة لا نبات فيها ،   بل هي ميتة { فَإِذَا أَنزلْنَا عَلَيْهَا الْمَاءَ اهْتَزَّتْ وَرَبَتْ } أي : أخرجت من جميل ألوان الزروع والثمار ،   { إِنَّ الَّذِي أَحْيَاهَا لَمُحْيِي الْمَوْتَى إِنَّهُ عَلَى كُلِّ شَيْءٍ قَدِيرٌ }<br />
