{ قَالَ كَلا } أي : قال الله له : لا تخف من شيء من ذلك كما قال : { قَالَ سَنَشُدُّ عَضُدَكَ بِأَخِيكَ وَنَجْعَلُ لَكُمَا سُلْطَانًا } أي : برهانا { فَلا يَصِلُونَ إِلَيْكُمَا بِآيَاتِنَا أَنْتُمَا وَمَنِ اتَّبَعَكُمَا الْغَالِبُونَ } [ القصص : 35 ] .  <br />
{ فَاذْهَبَا بِآيَاتِنَا إِنَّا مَعَكُمْ مُسْتَمِعُونَ } كما قال تعالى : { إِنَّنِي مَعَكُمَا أَسْمَعُ وَأَرَى } [ طه : 46 ] أي : إنني معكما بحفظي وكلاءتي ونصري وتأييدي .
