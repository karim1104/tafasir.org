{ وَإِنَّ رَبَّكَ لَيَعْلَمُ مَا تُكِنُّ صُدُورُهُمْ وَمَا يُعْلِنُونَ } أي : يعلم السرائر والضمائر ،   كما يعلم الظواهر ،   { سَوَاءٌ مِنْكُمْ مَنْ أَسَرَّ الْقَوْلَ وَمَنْ جَهَرَ بِهِ } [ الرعد : 10 ] ،   { يَعْلَمُ السِّرَّ وَأَخْفَى } [ طه : 7 ] ،   { أَلا حِينَ يَسْتَغْشُونَ ثِيَابَهُمْ يَعْلَمُ مَا يُسِرُّونَ وَمَا يُعْلِنُونَ } [ هود : 5 ] .
