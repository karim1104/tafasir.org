يقول تعالى : { وَكَذَّبَ بِهِ } أي : بالقرآن الذي جئتهم به ،   والهدى والبيان .   { قَوْمُكَ } يعني : قريشا { وَهُوَ الْحَقُّ } أي : الذي ليس وراءه حق { قُلْ لَسْتُ عَلَيْكُمْ بِوَكِيلٍ } أي : لست عليكم بحفيظ ،   ولست بموكل بكم ،   كقوله { وَقُلِ الْحَقُّ مِنْ رَبِّكُمْ فَمَنْ شَاءَ فَلْيُؤْمِنْ وَمَنْ شَاءَ فَلْيَكْفُرْ } [ الكهف : 29 ] أي : إنما علي البلاغ ،   وعليكم السمع والطاعة ،   فمن اتبعني ،   سعد في الدنيا والآخرة ،   ومن خالفني ،   فقد شقي في الدنيا والآخرة ؛ ولهذا قال : { لِكُلِّ نَبَإٍ مُسْتَقَرٌّ }
