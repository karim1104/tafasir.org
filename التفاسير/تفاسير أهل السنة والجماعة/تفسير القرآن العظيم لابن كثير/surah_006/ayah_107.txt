واعلم أن لله حكمة في إضلالهم ،   فإنه لو شاء لهدى الناس كلهم جميعا [ ولو شاء الله لجمعهم على الهدى ]{[11031]}<br />
{ وَلَوْ شَاءَ اللَّهُ مَا أَشْرَكُوا } أي : بل له المشيئة والحكمة فيما يشاؤه ويختاره ،   لا يسأل عما يفعل وهم يسألون .  <br />
وقوله : { وَمَا جَعَلْنَاكَ عَلَيْهِمْ حَفِيظًا } أي : حافظا تحفظ أعمالهم وأقوالهم { وَمَا أَنْتَ عَلَيْهِمْ بِوَكِيلٍ } أي : موكل على أرزاقهم وأمورهم { إِنْ عَلَيْكَ إِلا الْبَلاغُ } كما قال تعالى : { فَذَكِّرْ إِنَّمَا أَنْتَ مُذَكِّرٌ * لَسْتَ عَلَيْهِمْ بِمُسَيْطِرٍ } [ الغاشية : 21 ،   22 ] ،   وقال { فَإِنَّمَا عَلَيْكَ الْبَلاغُ وَعَلَيْنَا الْحِسَابُ } [ الرعد : 40 ]
