ثم قال { وَلَوْ تَرَى إِذْ وُقِفُوا عَلَى رَبِّهِمْ } أي : أوقفوا بين يديه قال : { أَلَيْسَ هَذَا بِالْحَقِّ } أي : أليس هذا المعاد بحق وليس بباطل كما كنتم تظنون ؟ { قَالُوا بَلَى وَرَبِّنَا قَالَ فَذُوقُوا الْعَذَابَ بِمَا كُنْتُمْ تَكْفُرُونَ } أي : بما{[10634]} كنتم تكذبون به ،   فذوقوا اليوم مَسّه{[10635]} { أَفَسِحْرٌ هَذَا أَمْ أَنْتُمْ لا تُبْصِرُونَ } [ الطور : 15 ]
