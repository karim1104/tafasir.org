وهذا جنس ،   أي : كُلّ كذّبَ رسول الله إليهم .   كما قال : { كُلٌّ كَذَّبَ الرُّسُلَ فَحَقَّ وَعِيدِ } [ ق : 14 ] .  {[29267]}  ومن كذب رسول الله فقد كذب بالجميع ،   كما قال : { كَذَّبَتْ قَوْمُ نُوحٍ الْمُرْسَلِينَ } [ الشعراء : 105 ] ،   { كَذَّبَتْ عَادٌ الْمُرْسَلِينَ } [ الشعراء : 123 ] .   { كَذَّبَتْ ثَمُودُ الْمُرْسَلِينَ } [ الشعراء : 141 ] وإنما جاء إلى كل أمة رسول واحد ؛ ولهذا قال هاهنا : { فَعَصَوْا رَسُولَ رَبِّهِمْ فَأَخَذَهُمْ أَخْذَةً رَابِيَةً } أي : عظيمة شديدة أليمة .  <br />
قال مجاهد : { رابية } شديدة .   وقال السدي : مهلكة .
