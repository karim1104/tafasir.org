{ لِنُرْسِلَ عَلَيْهِمْ حِجَارَةً مِنْ طِينٍ مُسَوَّمَةً } أي : معلمة { عِنْدَ رَبِّكَ لِلْمُسْرِفِينَ } أي : مكتتبة عنده بأسمائهم ،   كل حجر عليه اسم صاحبه ،   فقال في سورة العنكبوت : { قَالَ إِنَّ فِيهَا لُوطًا قَالُوا نَحْنُ أَعْلَمُ بِمَنْ فِيهَا لَنُنَجِّيَنَّهُ وَأَهْلَهُ إِلا امْرَأَتَهُ كَانَتْ مِنَ الْغَابِرِينَ } [ العنكبوت : 32 ] .
