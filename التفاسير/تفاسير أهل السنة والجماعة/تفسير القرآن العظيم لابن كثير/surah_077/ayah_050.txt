ثم قال : { فَبِأَيِّ حَدِيثٍ بَعْدَهُ يُؤْمِنُونَ } ؟ أي : إذا لم يؤمنوا بهذا القرآن ،   فبأي كلام يؤمنون به ؟ ! كقوله تعالى : { فَبِأَيِّ حَدِيثٍ بَعْدَ اللَّهِ وَآيَاتِهِ يُؤْمِنُونَ } [ الجاثية : 6 ] .  <br />
قال ابن أبي حاتم : حدثنا ابن أبي عمر ،   حدثنا سفيان ،   عن إسماعيل بن أمية : سمعت رجلا أعرابيا بَدَويا يقول : سمعت أبا هريرة يرويه إذا قرأ : { وَالْمُرْسَلاتِ عُرْفًا } فقرأ : { فَبِأَيِّ حَدِيثٍ بَعْدَهُ يُؤْمِنُونَ } ؟ فليقل : آمنت بالله وبما أنزل .  <br />
