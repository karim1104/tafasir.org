وقوله : { وَإِذَا الرُّسُلُ أُقِّتَتْ } قال العوفي ،   عن ابن عباس : جمعت .   وقال ابن زيد : وهذه كقوله تعالى : { يَوْمَ يَجْمَعُ اللَّهُ الرُّسُلَ } [ المائدة : 109 ] .   وقال مجاهد : { أُقِّتَت } أجلت .  <br />
وقال الثوري ،   عن منصور ،   عن إبراهيم : { أُقِّتَت } أوعدت .   وكأنه يجعلها كقوله : { وَأَشْرَقَتِ الأرْضُ بِنُورِ رَبِّهَا وَوُضِعَ الْكِتَابُ وَجِيءَ بِالنَّبِيِّينَ وَالشُّهَدَاءِ وَقُضِيَ بَيْنَهُمْ بِالْحَقِّ وَهُمْ لا يُظْلَمُونَ } [ الزمر : 69 ] .
