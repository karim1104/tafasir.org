ثم قال : { وَمِنْ قَبْلِهِ كِتَابُ مُوسَى } وهو التوراة { إِمَامًا وَرَحْمَةً وَهَذَا كِتَابٌ } يعني : القرآن { مُصَدِّقٌ } أي : لما قبله من الكتب { لِسَانًا عَرَبِيًّا } أي : فصيحا بينا واضحا ،   { لِيُنْذِرَ الَّذِينَ ظَلَمُوا وَبُشْرَى لِلْمُحْسِنِينَ } أي : مشتمل على النّذارة للكافرين والبشارة للمؤمنين .  <br />
