وهكذا تقول الملائكة : { سُبْحَانَكَ } أي : تعاليتَ وتقدست عن أن يكون معك إله { أَنْتَ وَلِيُّنَا مِنْ دُونِهِمْ } أي : نحن عبيدك ونبرأ إليك من هؤلاء ،   { بَلْ كَانُوا يَعْبُدُونَ الْجِنَّ } يعنون : الشياطين ؛ لأنهم هم الذين{[24392]} يزينون لهم عبادة الأوثان ويضلونهم{[24393]} ،   { أَكْثَرُهُمْ بِهِمْ مُؤْمِنُونَ } ،   كما قال تعالى : { إِنْ يَدْعُونَ{[24394]} مِنْ دُونِهِ إِلا إِنَاثًا وَإِنْ يَدْعُونَ{[24395]} إِلا شَيْطَانًا مَرِيدًا } [ النساء : 117 ] .
