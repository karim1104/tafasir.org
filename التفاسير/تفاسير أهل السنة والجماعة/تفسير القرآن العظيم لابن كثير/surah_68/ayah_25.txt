قال الله تعالى : { وَغَدَوْا عَلَى حَرْدٍ } أي : قوة وشدة .   وقال مجاهد : { وَغَدَوْا عَلَى حَرْدٍ } أي : جد وقال عكرمة : غيظ .   وقال الشعبي : { عَلَى حَرْدٍ } على المساكين .   وقال السدي : { عَلَى حَرْدٍ } أي : كان اسم قريتهم حرد .   فأبعد السدي في قوله هذا !<br />
{ قَادِرِينَ } أي : عليها فيما يزعمون ويَرومون .  <br />
