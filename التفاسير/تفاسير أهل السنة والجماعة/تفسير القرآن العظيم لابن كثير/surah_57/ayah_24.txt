ثم قال : { الَّذِينَ يَبْخَلُونَ وَيَأْمُرُونَ النَّاسَ بِالْبُخْلِ } أي : يفعلون المنكر ويحضون الناس عليه ،   { وَمَنْ يَتَوَلَّ } أي : عن أمر الله وطاعته { فَإِنَّ اللَّهَ هُوَ الْغَنِيُّ الْحَمِيدُ } كما قال موسى عليه السلام : { إِنْ تَكْفُرُوا أَنْتُمْ وَمَنْ فِي الأرْضِ جَمِيعًا فَإِنَّ اللَّهَ لَغَنِيٌّ حَمِيدٌ } [ إبراهيم : 8 ] .
