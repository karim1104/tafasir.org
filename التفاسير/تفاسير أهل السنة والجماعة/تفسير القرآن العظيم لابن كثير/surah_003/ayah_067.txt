ثم قال تعالى : { مَا كَانَ إِبْرَاهِيمُ يَهُودِيًّا وَلا نَصْرَانِيًّا وَلَكِنْ كَانَ حَنِيفًا مُسْلِمًا } أي : مُتَحَنفًا عن الشرك قَصْدًا إلى الإيمان { وَمَا كَانَ مِنَ الْمُشْرِكِينَ } [ البقرة : 135 ]<br />
وهذه الآية كالتي{[5159]} تقدمت في سورة البقرة : { وَقَالُوا كُونُوا هُودًا أَوْ نَصَارَى تَهْتَدُوا [ قُلْ بَلْ مِلَّةَ إِبْرَاهِيمَ حَنِيفًا وَمَا كَانَ مِنَ الْمُشْرِكِينَ ]{[5160]} } [ البقرة : 135 ] .
