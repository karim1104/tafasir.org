وهذه الآية كقوله تعالى : { كُلُّ شَيْءٍ هَالِكٌ إِلا وَجْهَهُ } [ القصص : 88 ] ،   وقد نعت تعالى وجهه الكريم في هذه الآية الكريمة بأنه { ذُو الْجَلالِ وَالإكْرَامِ } أي : هو أهل أن يجل فلا يعصى ،   وأن يطاع فلا يخالف ،   كقوله : { وَاصْبِرْ نَفْسَكَ مَعَ الَّذِينَ يَدْعُونَ رَبَّهُمْ بِالْغَدَاةِ وَالْعَشِيِّ يُرِيدُونَ وَجْهَهُ } [ الكهف : 28 ] ،   وكقوله إخبارا عن المتصدقين : { إِنَّمَا نُطْعِمُكُمْ لِوَجْهِ اللَّهِ } [ الإنسان : 9 ]<br />
قال ابن عباس : { ذُو الْجَلالِ وَالإكْرَامِ } ذو العظمة والكبرياء .
