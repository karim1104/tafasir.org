وقوله : { إِنْ تُقْرِضُوا اللَّهَ قَرْضًا حَسَنًا يُضَاعِفْهُ لَكُمْ وَيَغْفِرْ لَكُمْ } أي : مهما أنفقتم من شيء فهو يخلفه ،   ومهما تصدقتم من شيء فعليه جزاؤه ،   ونزل ذلك منزلة القرض له ،   كما ثبت في الصحيح أن الله تعالى يقول :  " من يقرض غير ظلوم ولا عديم  " {[28940]} ولهذا قال : { يُضَاعِفْهُ لَكُمْ } كما تقدم في سورة البقرة : { فَيُضَاعِفَهُ لَهُ أَضْعَافًا كَثِيرَةً } [ البقرة : 245 ]<br />
{ وَيَغْفِرْ لَكُمْ } أي : ويكفر عنكم السيئات .   ولهذا قال : { وَاللَّهُ شَكُورٌ } أي : يجزي على القليل بالكثير { حليم } أي : [ يعفو و ] {[28941]} يصفح ويغفر ويستر ،   ويتجاوز عن الذنوب والزلات والخطايا والسيئات .
