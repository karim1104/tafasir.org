ثم علل ذلك فقال : { ذَلِكَ بِأَنَّهُ كَانَتْ تَأْتِيهِمْ رُسُلُهُمْ بِالْبَيِّنَاتِ } أي : بالحجج والدلائل والبراهين { فَقَالُوا أَبَشَرٌ يَهْدُونَنَا } ؟ أي : استبعدوا أن تكون الرسالة في البشر ،   وأن يكون هداهم على يدي بشر مثلهم ،   { فَكَفَرُوا وَتَوَلَّوْا } أي : كذبوا بالحق ونكلوا عن العمل ،   { وَاسْتَغْنَى اللَّهُ } أي : عنهم { وَاللَّهُ غَنِيٌّ حَمِيدٌ }<br />
