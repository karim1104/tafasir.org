يقول تعالى : { إِنَّ هَذِهِ } أي : السورة { تَذْكِرَةٌ } أي : يتذكر بها أولو الألباب ؛ ولهذا قال : { فَمَنْ شَاءَ اتَّخَذَ إِلَى رَبِّهِ سَبِيلا } أي : ممن شاء الله هدايته ،   كما قيده في السورة الأخرى : { وَمَا تَشَاءُونَ إِلا أَنْ يَشَاءَ اللَّهُ إِنَّ اللَّهَ كَانَ عَلِيمًا حَكِيمًا } [ الإنسان : 30 ] .
