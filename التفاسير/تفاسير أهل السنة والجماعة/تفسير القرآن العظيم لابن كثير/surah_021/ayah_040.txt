وقوله : { بَلْ تَأْتِيهِمْ بَغْتَةً } {[19634]} أي :  " تأتيهم النار بغتة "  ،   أي : فجأة { فَتَبْهَتُهُمْ } أي : تذعرهم{[19635]} فيستسلمون لها حائرين ،   لا{[19636]} يدرون ما يصنعون ،   { فَلا يَسْتَطِيعُونَ رَدَّهَا } أي : ليس لهم حيلة في ذلك ،   { وَلا هُمْ يُنْظَرُونَ } أي : ولا يؤخر عنهم ذلك ساعة واحدة .
