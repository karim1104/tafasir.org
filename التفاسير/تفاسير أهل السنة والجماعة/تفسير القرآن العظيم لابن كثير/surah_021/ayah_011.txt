وقوله : { وَكَمْ قَصَمْنَا مِنْ قَرْيَةٍ كَانَتْ ظَالِمَةً } هذه صيغة تكثير ،   كما قال { وَكَمْ أَهْلَكْنَا مِنَ الْقُرُونِ مِنْ بَعْدِ نُوحٍ } [ الإسراء : 17 ] .  <br />
وقال تعالى : { فَكَأَيِّنْ{[19599]} مِنْ قَرْيَةٍ أَهْلَكْنَاهَا وَهِيَ ظَالِمَةٌ فَهِيَ خَاوِيَةٌ عَلَى عُرُوشِهَا وَبِئْرٍ مُعَطَّلَةٍ وَقَصْرٍ مَشِيدٍ } [ الحج : 45 ] .   وقوله : { وَأَنْشَأْنَا بَعْدَهَا قَوْمًا آخَرِينَ } أي : أمة أخرى بعدهم .
