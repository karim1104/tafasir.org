{ قَالَ لا تَثْرِيبَ عَلَيْكُمُ الْيَوْمَ } يقول : لا تأنيب عليكم ولا عَتْب عليكم اليوم ،   ولا أعيد{[15286]} ذنبكم في حقي بعد اليوم .  <br />
ثم زادهم الدعاء لهم بالمغفرة فقال : { يَغْفِرُ اللَّهُ لَكُمْ وَهُوَ أَرْحَمُ الرَّاحِمِينَ }<br />
قال السدي : اعتذروا إلى يوسف ،   فقال : { لا تَثْرِيبَ عَلَيْكُمُ الْيَوْمَ } يقول : لا أذكر لكم ذنبكم .  <br />
وقال ابن إسحاق والثوري : { لا تَثْرِيبَ عَلَيْكُمُ [ الْيَوْمَ ] } {[15287]} أي : لا تأنيب عليكم اليوم عندي فيما صنعتم { يَغْفِرُ اللَّهُ لَكُمْ } أي : يستر الله عليكم فيما فعلتم ،   { وَهُوَ أَرْحَمُ الرَّاحِمِينَ }
