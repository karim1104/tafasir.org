وقوله : { حِكْمَةٌ بَالِغَةٌ } أي : في هدايته تعالى لمن هداه وإضلاله لمن أضله ،   { فَمَا تُغْنِ النُّذُرُ } يعني {[27771]} : أي شيء تغني النذر عمن كتب الله عليه الشقاوة ،   وختم على قلبه ؟ فمن الذي يهديه من بعد الله ؟ وهذه الآية كقوله تعالى : { قُلْ فَلِلَّهِ الْحُجَّةُ الْبَالِغَةُ فَلَوْ شَاءَ لَهَدَاكُمْ أَجْمَعِينَ } [ الأنعام : 149 ] ،   وكذا قوله تعالى : { وَمَا تُغْنِي {[27772]} الآيَاتُ وَالنُّذُرُ عَنْ قَوْمٍ لا يُؤْمِنُونَ } [ يونس : 101 ] .
