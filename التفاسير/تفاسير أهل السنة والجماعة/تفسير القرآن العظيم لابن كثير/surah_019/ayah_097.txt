وقوله : { فَإِنَّمَا يَسَّرْنَاهُ } يعني : القرآن ،   { بِلِسَانِكَ } أي : يا محمد ،   وهو اللسان العربي المبين الفصيح الكامل ،   { لِتُبَشِّرَ بِهِ الْمُتَّقِينَ } أي : المستجيبين لله المصدقين لرسوله ،   { وَتُنْذِرَ بِهِ قَوْمًا لُدًّا } أي : عوجًا عن الحق مائلين إلى الباطل .  <br />
وقال ابن أبي نَجِيح ،   عن مجاهد : { قَوْمًا لُدًّا } لا يستقيمون .  <br />
وقال الثوري ،   عن إسماعيل - وهو السُّدِّي - عن أبي صالح : { وَتُنْذِرَ بِهِ قَوْمًا لُدًّا } عوجًا عن الحق .  <br />
[ وقال الضحاك : هو الخصم ،   وقال القرظي : الألد : الكذاب ]{[19181]}<br />
وقال الحسن البصري : { قَوْمًا لُدًّا } صمًّا .  <br />
وقال غيره صم آذان القلوب{[19182]}<br />
وقال قتادة : { قَوْمًا لُدًّا } يعني قريشًا .  <br />
وقال العوفي ،   عن ابن عباس : { قَوْمًا لُدًّا } فجارًا ،   وكذا روى ليث بن أبي سليم عن مجاهد .  <br />
وقال ابن زيد : الألد : الظلوم ،   وقرأ قول الله : { وَهُوَ أَلَدُّ الْخِصَامِ } [ البقرة : 204 ] .
