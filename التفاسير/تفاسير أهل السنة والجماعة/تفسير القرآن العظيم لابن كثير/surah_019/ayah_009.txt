{ قَالَ } أي الملك مجيبًا لزكريا عما استعجب منه : { كَذَلِكَ قَالَ رَبُّكَ هُوَ عَلَيَّ هَيِّنٌ } أي : إيجاد الولد منك ومن زوجتك هذه لا من غيرها { هَيِّنٌ } أي : يسير سهل على الله .  <br />
ثم ذكر له ما هو أعجب مما سأل عنه ،   فقال : { وَقَدْ خَلَقْتُكَ مِنْ قَبْلُ وَلَمْ تَكُ شَيْئًا } كما قال تعالى : { هَلْ أَتَى عَلَى الإنْسَانِ حِينٌ مِنَ الدَّهْرِ لَمْ يَكُنْ شَيْئًا مَذْكُورًا } [ الإنسان : 1 ]
