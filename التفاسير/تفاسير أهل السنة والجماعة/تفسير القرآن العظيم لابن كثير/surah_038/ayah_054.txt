ثم أخبر عن الجنة أنه لا فراغ لها ولا انقضاء ولا زوال ولا انتهاء فقال : { إِنَّ هَذَا لَرِزْقُنَا مَا لَهُ مِنْ نَفَادٍ } كقوله تعالى : { مَا عِنْدَكُمْ يَنْفَدُ وَمَا عِنْدَ اللَّهِ بَاقٍ } [ النحل : 96 ] وكقوله { عَطَاءً غَيْرَ مَجْذُوذٍ } [ هود : 108 ] وكقوله { لَهُمْ أَجْرٌ غَيْرُ مَمْنُونٍ } [ فصلت : 8 ] أي : غير مقطوع وكقوله : { أُكُلُهَا دَائِمٌ وَظِلُّهَا تِلْكَ عُقْبَى الَّذِينَ اتَّقَوْا وَعُقْبَى الْكَافِرِينَ النَّارُ } [ الرعد : 35 ] والآيات في هذا كثيرة جدا .
