قوله : { هَذَا فَوْجٌ مُقْتَحِمٌ مَعَكُمْ لا مَرْحَبًا بِهِمْ إِنَّهُمْ صَالُوا النَّارِ } : هذا إخبار عن قيل أهل النار بعضهم لبعض كما قال تعالى : { كُلَّمَا دَخَلَتْ أُمَّةٌ لَعَنَتْ أُخْتَهَا } [ الأعراف : 38 ] يعني بدل السلام يتلاعنون ويتكاذبون ويكفر بعضهم ببعض فتقول الطائفة التي تدخل قبل الأخرى إذا أقبلت التي بعدها مع الخزنة من الزبانية : { هَذَا فَوْجٌ مُقْتَحِمٌ } أي : داخل معكم { لا مَرْحَبًا بِهِمْ إِنَّهُمْ صَالُوا النَّارِ } أي : لأنهم من أهل جهنم { قَالُوا بَلْ أَنْتُمْ لا مَرْحَبًا بِكُمْ } .
