وقوله : { وَإِنْ جَادَلُوكَ فَقُلِ اللَّهُ أَعْلَمُ بِمَا تَعْمَلُونَ } ،   كقوله : { وَإِنْ كَذَّبُوكَ فَقُلْ لِي عَمَلِي وَلَكُمْ عَمَلُكُمْ أَنْتُمْ بَرِيئُونَ مِمَّا أَعْمَلُ وَأَنَا بَرِيءٌ مِمَّا تَعْمَلُونَ } [ يونس : 41 ] .  <br />
وقوله : { اللَّهُ أَعْلَمُ بِمَا تَعْمَلُونَ } تهديد شديد ،   ووعيد أكيد ،   كقوله : { هُوَ أَعْلَمُ بِمَا تُفِيضُونَ فِيهِ كَفَى بِهِ شَهِيدًا بَيْنِي وَبَيْنَكُمْ } [ الأحقاف : 8 ]  ؛ ولهذا قال : { اللَّهُ{[20411]} يَحْكُمُ بَيْنَكُمْ يَوْمَ الْقِيَامَةِ فِيمَا كُنْتُمْ فِيهِ تَخْتَلِفُونَ }
