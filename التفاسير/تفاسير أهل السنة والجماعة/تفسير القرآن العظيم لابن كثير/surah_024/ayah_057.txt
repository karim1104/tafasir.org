وقوله { لا تَحْسَبَنَّ } أي : [ لا تظن ]{[21343]} يا محمد { الَّذِينَ كَفَرُوا } أي : خالفوك وكذبوك ،   { مُعْجِزِينَ فِي الأرْضِ } أي : لا يعجزون الله ،   بل الله قادر عليهم ،   وسيعذبهم على ذلك أشد العذاب ؛ ولهذا قال : { وَمَأْوَاهُمُ } أي : في الدار الآخرة { النَّارُ وَلَبِئْسَ الْمَصِيرُ } أي : بئس المآل مآلُ الكافرين ،   وبئس القرار وبئس المهاد .
