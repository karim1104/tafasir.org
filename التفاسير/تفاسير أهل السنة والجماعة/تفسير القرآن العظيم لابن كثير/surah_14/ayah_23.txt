ثم لما ذكر تعالى مآل الأشقياء وما صاروا إليه من الخزي والنَّكَال .   وأن خطيبهم إبليس ،   عطف بحال السعداء وأنهم يدخلون يوم القيامة جنات تجري من تحتها الأنهار سارحة فيها حيث ساروا وأين ساروا{[15815]} { خَالِدِينَ فِيهَا } ماكثين أبدا لا يحولون ولا يزولون ،   { بِإِذْنِ رَبِّهِمْ تَحِيَّتُهُمْ فِيهَا سَلامٌ } كما قال تعالى : { حَتَّى إِذَا جَاءُوهَا وَفُتِحَتْ أَبْوَابُهَا وَقَالَ لَهُمْ خَزَنَتُهَا سَلامٌ عَلَيْكُمْ } [ الزمر : 73 ] ،   وقال تعالى : { وَالْمَلائِكَةُ يَدْخُلُونَ عَلَيْهِمْ مِنْ كُلِّ بَابٍ سَلامٌ عَلَيْكُمْ } [ الرعد : 23 ،   24 ] وقال تعالى : { وَيُلَقَّوْنَ فِيهَا تَحِيَّةً وَسَلامًا } [ الفرقان : 75 ] ،   وقال : { دَعْوَاهُمْ فِيهَا سُبْحَانَكَ اللَّهُمَّ وَتَحِيَّتُهُمْ فِيهَا سَلامٌ وَآخِرُ دَعْوَاهُمْ أَنِ الْحَمْدُ لِلَّهِ رَبِّ الْعَالَمِينَ } [ يونس : 10 ] .
