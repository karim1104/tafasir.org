قالت لهم رسلهم : { إِنْ نَحْنُ إِلا بَشَرٌ مِثْلُكُمْ } أي : صحيح أنا بشر مثلكم في البشرية { وَلَكِنَّ اللَّهَ يَمُنُّ عَلَى مَنْ يَشَاءُ مِنْ عِبَادِهِ } أي : بالرسالة والنبوة { وَمَا كَانَ لَنَا أَنْ نَأْتِيَكُمْ بِسُلْطَانٍ } على وفق ما سألتم { إِلا بِإِذْنِ اللَّهِ } أي : بعد سؤالنا إياه ،   وإذنه لنا في ذلك ،   { وَعَلَى اللَّهِ فَلْيَتَوَكَّلِ الْمُؤْمِنُونَ } أي : في جميع أمورهم .  <br />
