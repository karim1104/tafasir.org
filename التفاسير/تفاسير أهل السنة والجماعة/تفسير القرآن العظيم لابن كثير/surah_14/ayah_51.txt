وقوله : { لِيَجْزِيَ اللَّهُ } أي : يوم{[16056]} القيامة ،   كما قال : { لِيَجْزِيَ الَّذِينَ أَسَاءُوا بِمَا عَمِلُوا وَيَجْزِيَ الَّذِينَ أَحْسَنُوا بِالْحُسْنَى } [ النجم : 31 ] .  <br />
{ إِنَّ اللَّهَ سَرِيعُ الْحِسَابِ } يحتمل أن يكون كقوله{[16057]} تعالى : { اقْتَرَبَ لِلنَّاسِ حِسَابُهُمْ وَهُمْ فِي غَفْلَةٍ مُعْرِضُونَ } ويحتمل أنه في حال محاسبته{[16058]} لعبده سريع النَّجاز ؛ لأنه يعلم كل شيء ،   ولا يخفى عليه خافية ،   وإن جميع الخلق{[16059]} بالنسبة إلى قدرته كالواحد منهم ،   كقوله تعالى : { مَا خَلْقُكُمْ وَلا بَعْثُكُمْ إِلا كَنَفْسٍ وَاحِدَةٍ } [ لقمان : 28 ] ،   وهذا معنى قول مجاهد : { سَرِيعُ الْحِسَابِ } [ إحصاء ]{[16060]} .  <br />
ويحتمل أن يكون المعنيان مرادين ،   والله أعلم .
