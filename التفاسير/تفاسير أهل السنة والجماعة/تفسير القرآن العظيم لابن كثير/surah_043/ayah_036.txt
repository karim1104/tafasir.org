يقول تعالى : { وَمَنْ يَعْشُ } أي : يتعامى ويتغافل ويعرض ،   { عَنْ ذِكْرِ الرَّحْمَنِ } والعشا في العين : ضعف بصرها .   والمراد هاهنا : عشا البصيرة ،   { نُقَيِّضْ لَهُ شَيْطَانًا فَهُوَ لَهُ قَرِينٌ } كقوله : { وَمَنْ يُشَاقِقِ الرَّسُولَ مِنْ بَعْدِ مَا تَبَيَّنَ لَهُ الْهُدَى وَيَتَّبِعْ غَيْرَ سَبِيلِ الْمُؤْمِنِينَ نُوَلِّهِ مَا تَوَلَّى وَنُصْلِهِ جَهَنَّمَ وَسَاءَتْ مَصِيرًا } [ النساء : 115 ] ،   وكقوله : { فَلَمَّا زَاغُوا أَزَاغَ اللَّهُ قُلُوبَهُمْ } [ الصف : 5 ] ،   وكقوله : { وَقَيَّضْنَا لَهُمْ قُرَنَاءَ فَزَيَّنُوا لَهُمْ مَا بَيْنَ أَيْدِيهِمْ وَمَا خَلْفَهُمْ وَحَقَّ عَلَيْهِمُ الْقَوْلُ فِي أُمَمٍ قَدْ خَلَتْ مِنْ قَبْلِهِمْ مِنَ الْجِنِّ وَالإنْسِ إِنَّهُمْ كَانُوا خَاسِرِينَ } [ فصلت : 25 ] ؛  ولهذا قال هاهنا : { وَإِنَّهُمْ لَيَصُدُّونَهُمْ عَنِ السَّبِيلِ وَيَحْسَبُونَ أَنَّهُمْ مُهْتَدُونَ .   حَتَّى إِذَا جَاءَنَا } .   أي : هذا الذي تغافل عن الهدى نقيض له من الشياطين من يضله ،   ويهديه إلى صراط الجحيم .
