وقوله : { إِنَّ هَذَا كَانَ لَكُمْ جَزَاءً وَكَانَ سَعْيُكُمْ مَشْكُورًا } أي : يقال لهم ذلك تكريما لهم وإحسانا إليهم كقوله : { كُلُوا وَاشْرَبُوا هَنِيئًا بِمَا أَسْلَفْتُمْ فِي الأيَّامِ الْخَالِيَةِ } [ الحاقة : 24 ] وكقوله : { وَنُودُوا أَنْ تِلْكُمُ الْجَنَّةُ أُورِثْتُمُوهَا بِمَا كُنْتُمْ تَعْمَلُونَ } [ الأعراف : 43 ]<br />
وقوله : { وَكَانَ سَعْيُكُمْ مَشْكُورًا } أي : جزاكم الله على القليل بالكثير .
