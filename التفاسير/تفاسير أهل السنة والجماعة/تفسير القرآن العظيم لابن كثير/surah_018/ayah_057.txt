يقول تعالى : وأي عباد الله أظلم{[18298]} ممن ذكر بآيات الله{[18299]} فأعرض عنها ،   أي : تناساها وأعرض عنها ،   ولم يصغ{[18300]} لها ،   ولا ألقى إليها بالا { وَنَسِيَ مَا قَدَّمَتْ يَدَاهُ } أي : من الأعمال السيئة والأفعال القبيحة .   { إِنَّا جَعَلْنَا عَلَى قُلُوبِهِمْ } أي : قلوب هؤلاء { أَكِنَّةً } أي : أغطية وغشاوة ،   { أَنْ يَفْقَهُوهُ } أي : لئلا يفهموا{[18301]} هذا القرآن والبيان ،   { وَفِي آذَانِهِمْ وَقْرًا } أي : صمم معنوي عن الرشاد ،   { وَإِنْ تَدْعُهُمْ إِلَى الْهُدَى فَلَنْ يَهْتَدُوا إِذًا أَبَدًا } .
