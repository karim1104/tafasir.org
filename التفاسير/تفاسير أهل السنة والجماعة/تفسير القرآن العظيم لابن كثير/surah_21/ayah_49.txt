ثم وصفهم فقال : { الَّذِينَ يَخْشَوْنَ رَبَّهُمْ بِالْغَيْبِ } كقوله { مَنْ خَشِيَ الرَّحْمَنَ بِالْغَيْبِ وَجَاءَ بِقَلْبٍ مُنِيبٍ } [ ق : 33 ] ،   وقوله : { إِنَّ الَّذِينَ يَخْشَوْنَ رَبَّهُمْ بِالْغَيْبِ لَهُمْ مَغْفِرَةٌ وَأَجْرٌ كَبِيرٌ } [ الملك : 12 ] ،   { وَهُمْ مِنَ السَّاعَةِ مُشْفِقُونَ } أي : خائفون وجلون .
