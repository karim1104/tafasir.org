وقوله : { وَالَّذِينَ يَبِيتُونَ لِرَبِّهِمْ سُجَّدًا وَقِيَامًا } أي : في عبادته وطاعته ،   كما قال تعالى : { كَانُوا قَلِيلا مِنَ اللَّيْلِ مَا يَهْجَعُونَ وَبِالأسْحَارِ هُمْ يَسْتَغْفِرُونَ } [ الذاريات : 17 - 18 ] ،   وقال { تَتَجَافَى جُنُوبُهُمْ عَنِ الْمَضَاجِعِ يَدْعُونَ رَبَّهُمْ خَوْفًا وَطَمَعًا وَمِمَّا رَزَقْنَاهُمْ يُنْفِقُونَ } [ السجدة : 16 ] وقال { أَمَّنْ هُوَ قَانِتٌ آنَاءَ اللَّيْلِ سَاجِدًا وَقَائِمًا يَحْذَرُ الآخِرَةَ وَيَرْجُو رَحْمَةَ رَبِّهِ } الآية [ الزمر : 9 ] ولهذا قال : { وَالَّذِينَ يَقُولُونَ رَبَّنَا اصْرِفْ عَنَّا عَذَابَ جَهَنَّمَ إِنَّ عَذَابَهَا كَانَ غَرَامًا }
