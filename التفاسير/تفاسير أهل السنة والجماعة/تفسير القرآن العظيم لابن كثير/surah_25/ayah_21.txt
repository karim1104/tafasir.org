يقول تعالى مخبرا عن تَعَنُّت الكفار في كفرهم ،   وعنادهم في قولهم : { لَوْلا أُنزلَ عَلَيْنَا الْمَلائِكَةُ } {[21442]} أي : بالرسالة كما نزل{[21443]} على الأنبياء ،   كما أخبر عنهم تعالى في الآية الأخرى : { قَالُوا لَنْ نُؤْمِنَ حَتَّى نُؤْتَى مِثْلَ مَا أُوتِيَ رُسُلُ اللَّهِ } [ الأنعام : 124 ] ،   ويحتمل أن يكون مرادهم هاهنا : { لَوْلا أُنزلَ عَلَيْنَا الْمَلائِكَةُ } فنراهم عيانا ،   فيخبرونا أن محمدا رسول الله ،   كقولهم{[21444]} : { أَوْ تَأْتِيَ بِاللَّهِ وَالْمَلائِكَةِ قَبِيلا } [ الإسراء : 92 ] .   وقد تقدم تفسيرها في سورة  " سبحان "  ؛ ولهذا قال{[21445]} : { أَوْ نَرَى رَبَّنَا } ولهذا قال الله تعالى : { لَقَدِ اسْتَكْبَرُوا فِي أَنْفُسِهِمْ وَعَتَوْا عُتُوًّا كَبِيرًا } .   وقد قال [ الله ]{[21446]} تعالى : { وَلَوْ أَنَّنَا نزّلْنَا إِلَيْهِمُ الْمَلائِكَةَ وَكَلَّمَهُمُ الْمَوْتَى وَحَشَرْنَا عَلَيْهِمْ كُلَّ شَيْءٍ قُبُلا مَا كَانُوا لِيُؤْمِنُوا إِلا أَنْ يَشَاءَ اللَّهُ وَلَكِنَّ أَكْثَرَهُمْ يَجْهَلُونَ } [ الأنعام : 111 ] .
