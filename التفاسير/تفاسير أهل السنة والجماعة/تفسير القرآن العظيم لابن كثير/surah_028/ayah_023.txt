{ وَلَمَّا وَرَدَ مَاءَ مَدْيَنَ } أي : ولما وصل إلى مدين وورد ماءها ،   وكان لها بئر تَرده رعاء الشاء { وَجَدَ عَلَيْهِ أُمَّةً مِنَ النَّاسِ } أي : جماعة { يَسْقُونَ وَوَجَدَ مِنْ دُونِهِمُ امْرَأتَيْنِ تَذُودَانِ } أي : تكفكفان غنمهما أن ترد مع غنم أولئك الرعاء لئلا يُؤذَيا .   فلما رآهما موسى ،   عليه السلام ،   رق لهما ورحمهما ،   { قَالَ مَا خَطْبُكُمَا } أي : ما خبركما لا تردان مع هؤلاء ؟ { قَالَتَا لا نَسْقِي حَتَّى يُصْدِرَ الرِّعَاءُ } أي : لا يحصل لنا سقي إلا بعد فراغ هؤلاء ،   { وَأَبُونَا شَيْخٌ كَبِيرٌ } أي : فهذا الحال الملجئ لنا إلى ما ترى .  <br />
