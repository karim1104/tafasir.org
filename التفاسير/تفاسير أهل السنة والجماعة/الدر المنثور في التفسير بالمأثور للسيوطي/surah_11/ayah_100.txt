أخرج ابن جرير وابن أبي حاتم عن ابن عباس رضي الله عنهما في قوله { منها قائم } يعني بها قرى عامرة { وحصيد } يعني قرى خامدة .  <br />
وأخرج أبو الشيخ عن قتادة في قوله { ذلك من أنباء القرى نقصه عليك } قال : قال الله ذلك لنبيه محمد صلى الله عليه وسلم { قائماً } يرى مكانه { وحصيد } لا يرى له أثر ،   وقال في آية أخرى { هل تحس منهم من أحد أو تسمع لهم ركزاً } [ مريم : 98 ] .  <br />
وأخرج أبو الشيخ عن ابن جريج { منها قائم } خاو على عروشه { وحصيد } ملصق بالأرض .  <br />
وأخرج أبو الشيخ عن الضحاك { منها قائم وحصيد } قال : الحصيد الذي قد خرب ودمر .
