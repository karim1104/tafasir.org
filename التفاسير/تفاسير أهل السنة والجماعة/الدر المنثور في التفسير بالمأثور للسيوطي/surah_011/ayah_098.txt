أخرج ابن جرير وابن المنذر وأبو الشيخ عن ابن عباس رضي الله عنهما في قوله { يقدم قومه يوم القيامة } يقول : أضلهم فأوردهم النار .  <br />
وأخرج عبد الرزاق وابن جرير وأبو الشيخ عن قتادة رضي الله عنه في قوله { يقدم قومه يوم القيامة } قال : فرعون يمضي بين يدي قومه حتى يهجم بهم على النار .  <br />
وأخرج عبد الرزاق وابن جرير وابن المنذر وابن أبي حاتم عن ابن عباس في قوله { فأوردهم النار } قال { الورود } الدخول .  <br />
وأخرج ابن جرير وابن أبي حاتم عن ابن عباس قال { الورود } في القرآن أربعة .   في هود { وبئس الورد المورود } ،   وفي مريم { وإن منكم إلا واردها } [ مريم : 71 ] ،   وفيها أيضاً { ونسوق المجرمين إلى جهنم ورداً } [ مريم : 86 ] ،   وفي الأنبياء { حصب جهنم أنتم لها واردون } [ الأنبياء : 98 ] قال : كل هذا الدخول .
