وأخرج ابن جرير وأبو الشيخ عن ابن جريج رضي الله عنه في قوله { ولئن أذقنا الإِنسان منا رحمة .   .   .   } الآية .   قال : يا ابن آدم إذا كانت بك نعمة من الله من السعة والأمن والعافية فكفور لما بك منها ،   وإذا نزعت منك يبتغي لك فراغك فيؤوس من روح الله قنوط من رحمته ،   كذلك أمر المنافق والكافر .   وفي قوله { ولئن أذقناه نعماء } إلى قوله { ذهب السيئات عني } قال : غره بالله وجرأه عليه أنه لفرح والله لا يحب الفرحين ،   فخور لما أعطى لا يشكر الله ،   ثم استثنى فقال { إلا الذين صبروا } يقول : عند البلاء { وعملوا الصالحات } عند النعمة { أولئك لهم مغفرة } لذنوبهم { وأجر كبير } قال : الجنة { فلعلك تارك بعض ما يوحى إليك } إن تفعل فيه ما أمرت وتدعو إليه كما أرسلت { أن يقولوا : لولا أنزل عليه كنز } لا ترى معه مالاً { أو جاء معه ملك } ينذر معه { إنما أنت نذير } فبلغ ما أمرت به فإنما أنت رسول { أم يقولون افتراه } قد قالوه { فأتوا بعشر سور مثله } مثل القرآن { وادعوا شهداءكم } يشهدوا إنها مثله .  <br />
