وأخرج ابن جرير وابن مردويه عن ابن عباس قال : كان رسول الله صلى الله عليه وسلم لا يفتر عن القرآن مخافة أن ينساه فقال الله : لا تحرك به لسانك { إن علينا جمعه } أن نجمعه لك { وقرآنه } أن تقرأه فلا تنسى { فإذا قرأناه } عليك { فاتبع قرآنه } يقول : إذا يتلى عليك فاتبع ما فيه { ثم إن علينا بيانه } يقول : حلاله وحرامه فذلك بيانه .  <br />
وأخرج ابن جرير وابن المنذر وابن مردويه عن ابن عباس قال : كان النبي صلى الله عليه وسلم إذا نزل عليه القرآن تعجل بقراءته ليحفظه فنزلت هذه الآية { لا تحرك به لسانك } وكان رسول الله صلى الله عليه وسلم لا يعلم ختم سورة حتى ينزل عليه بسم الله الرحمن الرحيم .  <br />
وأخرج ابن جرير وابن مردويه عن ابن عباس قال : كان رسول الله صلى الله عليه وسلم لا يفتر عن القرآن مخافة أن ينساه فقال الله : لا تحرك به لسانك { إن علينا جمعه } أن نجمعه لك { وقرآنه } أن تقرأه فلا تنسى { فإذا قرأناه } عليك { فاتبع قرآنه } يقول : إذا يتلى عليك فاتبع ما فيه { ثم إن علينا بيانه } يقول : حلاله وحرامه فذلك بيانه .  <br />
وأخرج عبد بن حميد وابن جرير وابن المنذر عن مجاهد في قوله : { لا تحرك به لسانك } قال : كان يستذكر القرآن مخافة النسيان ،   فقيل له : كفيناكه يا محمد .  <br />
وأخرج عبد بن حميد وابن المنذر عن قتادة { لا تحرك به لسانك لتعجل به } قال : كان نبي الله صلى الله عليه وسلم يحرك لسانه بالقرآن مخافة النسيان .   فأنزل الله ما تسمع { إن علينا جمعه وقرآنه } يقول : إن علينا حفظه وتأليفه { فإذا قرأناه فاتبع قرآنه } يقول اتبع حلاله واجتنب حرامه { ثم إن علينا بيانه } قال : بيان حلاله وحرامه وطاعته ومعصيته .  <br />
