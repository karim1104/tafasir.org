وأخرج ابن أبي حاتم عن عطاء في قوله { وإذا قيل لهم اسجدوا للرحمن قالوا وما الرحمن } قال : قالوا ما نعرف الرحمن إلا رحمن اليمامة .   فأنزل الله { وإلهكم إله واحد لا إله إلا هو الرحمن الرحيم } [ البقرة : 163 ] .  <br />
وأخرج ابن أبي حاتم عن حسين الجحفي في قوله { قالوا وما الرحمن } قال : جوابها { الرحمن علم القرآن } [ الرحمن : 1-2 ] .  <br />
وأخرج سعيد بن منصور وعبد بن حميد عن إبراهيم قال : قرأ الأسود { أنسجد لما تأمرنا } فسجد فيها قال : وقرأها يحيى { أنسجد لما تأمرنا } .  <br />
وأخرج عبد بن حميد عن سليمان قال : قرأ إبراهيم في الفرقان { أنسجد لما يأمرنا } بالياء .   وقرأ سليمان كذلك .
