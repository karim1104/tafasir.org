أخرج ابن جرير عن ابن عباس في قوله { أتبنون بكل ريع } قال : طريق { آية } قال : علماً { تعبثون } قال : تلعبون .  <br />
وأخرج ابن جرير وابن المنذر وابن أبي حاتم عن ابن عباس في قوله { أتبنون بكل ريع } قال : شرف .  <br />
وأخرج عبد الرزاق وعبد بن حميد وابن جرير عن قتادة { أتبنون بكل ريع } قال : طريق .  <br />
وأخرج ابن أبي حاتم عن أبي صخر قال { الريع } ما استقبل الطريق بين الجبال والظراب .  <br />
وأخرج الفريابي وسعيد بن منصور وابن أبي شيبة وعبد بن حميد وابن جرير وابن المنذر وابن أبي حاتم عن مجاهد في قوله { أتبنون بكل ريع } قال : بكل فج بين جبلين { آية } قال : بنيانا{ وتتخذون مصانع } قال : بروج الحمام .  <br />
وأخرج ابن جرير عن الضحاك في قوله { تعبثون } قال : تلعبون .  <br />
