أخرج ابن جرير وأبو الشيخ ،   عن سعيد بن جبير - رضي الله عنه - في قوله { والذين صبروا } يعني على أمر الله { إبتغاء وجه ربهم } يعني ابتغاء رضا ربهم { وأقاموا الصلاة } يعني وأتموها { وأنفقوا مما رزقناهم } يعني من الأموال { سرا وعلانية } يعني في حق الله وطاعته { ويدرؤون } يعني يدفعون { بالحسنة السيئة } يعني يردون معروفا على من يسيء إليهم { أولئك لهم عقبى الدار } يعني دار الجنة .  <br />
وأخرج ابن أبي شيبة وابن المنذر وابن أبي حاتم وأبو الشيخ ،   عن الضحاك - رضي الله عنه - { ويدرؤون بالحسنة السيئة } قال : يدفعون بالحسنة السيئة .  <br />
وأخرج ابن جرير عن ابن زيد - رضي الله عنه - في قوله { ويدرؤون بالحسنة السيئة } قال : يدفعون الشر بالخير ،   لا يكافئون الشر بالشر ،   ولكن يدفعونه بالخير .  <br />
