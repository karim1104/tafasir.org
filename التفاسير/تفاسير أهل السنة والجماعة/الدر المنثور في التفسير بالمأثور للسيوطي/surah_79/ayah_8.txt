وأخرج عبد الرزاق وعبد بن حميد عن قتادة { قلوب يومئذ واجفة } قال : خائفة .  <br />
وأخرج عبد بن حميد وابن المنذر عن مجاهد { قلوب يومئذ واجفة } قال : وجلة وفي قوله : { أئنا لمردودون في الحافرة } قال : الأرض نبعث خلقاً جديداً { أئذا كنا عظاماً نخرة } قال : مدقوقة .  <br />
وأخرج عبد بن حميد وابن المنذر عن قتادة في قوله : { قلوب يومئذ واجفة } قال : وجفت مما عاينت { يومئذ أبصارها خاشعة } قال : ذليلة { يقولون أئنا لمردودون في الحافرة } أننا لمبعوثون خلقاً جديداً إذا متنا تكذيباً بالبعث { أئذا كنا عظاماً نخرة } قال : بالية .  <br />
