أخرج ابن أبي حاتم عن ابن عباس في قوله { قال أخرج منها مذءوماً } قال : ملوماً { مدحوراً } قال : مقيتاً .  <br />
وأخرج أبو الشيخ عن ابن عباس في قوله { مذءوماً } قال : مذموماً { مدحوراً } قال : منفياً .  <br />
وأخرج عبد بن حميد وابن المنذر وابن أبي حاتم وأبو الشيخ عن مجاهد في قوله { مذءوماً } قال : منفياً { مدحوراً } قال : مطروداً .  <br />
وأخرج ابن المنذر وعبد بن حميد وابن أبي حاتم عن قتادة في قوله { مذءوماً } قال : معيباً { مدحوراً } قال : منفياً .  <br />
