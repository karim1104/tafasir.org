وأخرج ابن أبي حاتم عن سعيد بن جبير في قوله { والذين هم للزكاة فاعلون } يعني : الأموال { والذين هم لفروجهم حافظون } يعني : الفواحش { إلا على أزواجهم أو ما ملكت أيمانهم } يعني .   ولائدهم { فإنهم غير ملومين } قال : لا يلامون على جماع أزواجهم وولائدهم { فمن ابتغى وراء ذلك } يعني : فمن طلب الفواحش بعد الأزواج والولائد طلب مالم يحل { فأولئك هم العادون } يعني : المعتدين في دينهم { والذين هم لأماناتهم } يعني : بهذا ما ائتمنوا عليه فيما بينهم وبين الناس { وعهدهم } قال : يوفون العهد { راعون } قال : حافظوْن .  <br />
