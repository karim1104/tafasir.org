وأخرج ابن المنذر والحاكم وصححه عن ابن مسعود قال : قسم { والسماء ذات البروج } إلى قوله : { وشاهد ومشهود } قال : هذا قسم على أن بطش ربك لشديد إلى آخرها .  <br />
وأخرج ابن المنذر عن ابن جريج في قوله : { إن بطش ربك لشديد } قال : ههنا القسم { إنه هو يبدئ ويعيد } قال : يبدئ الخلق ثم يعيده { وهو الغفور الودود } قال : يود على طاعته من أطاعه .  <br />
