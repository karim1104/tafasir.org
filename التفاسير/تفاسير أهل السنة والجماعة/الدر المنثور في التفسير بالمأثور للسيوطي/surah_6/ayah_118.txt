أخرج أبو داود والترمذي وحسنه والبزار وابن جرير وابن المنذر وابن أبي حاتم وأبو الشيخ وابن مردويه عن ابن عباس قال : جاءت اليهود إلى النبي صلى الله عليه وسلم فقالوا : أنأكل مما قتلنا ولا نأكل مما يقتل الله ؟ فأنزل الله { فكلوا مما ذكر اسم الله عليه إن كنتم بآياته مؤمنين } إلى قوله { وإن أطعتموهم إنكم لمشركون } .  <br />
وأخرج ابن أبي حاتم عن سعيد بن جبير في قوله { فكلوا مما ذكر اسم الله عليه } فإنه حلال { إن كنتم بآياته مؤمنين } يعني بالقرآن مصدقين { وما لكم ألا تأكلوا مما ذكر اسم الله عليه } يعني الذبائح { وقد فصل لكم ما حرم عليكم إلا ما اضطررتم إليه } يعني ما حرم عليكم من الميتة { وإن كثيراً } من مشركي العرب { ليضلون بأهوائهم بغير علم } يعني في أمر الذبائح وغيره { إن ربك هو أعلم بالمعتدين } .  <br />
