أخرج ابن مردويه عن ابن عباس رضي الله عنهما في قوله { آلر } قال : فواتح السور ،   أسماء من أسماء الله .  <br />
أخرج ابن جرير وابن المنذر وابن أبي حاتم وأبو الشيخ والبيهقي في الأسماء والصفات وابن النجار في تاريخه عن ابن عباس رضي الله عنهما في قوله { آلر } قال : أنا الله أرى .  <br />
وأخرج ابن المنذر عن سعيد بن جبير في قوله { آلر } قال : أنا الله أرى .  <br />
وأخرج ابن أبي حاتم عن الضحاك في قوله { آلر } قال : أنا الله أرى .  <br />
وأخرج ابن مردويه عن ابن عباس رضي الله عنهما في قوله { آلر } و { حم } و { ن } قال : اسم مقطع .  <br />
وأخرج ابن جرير وابن أبي حاتم وأبو الشيخ عن ابن عباس رضي الله عنهما قال : { الر } و { حم } و { ن } قال : حروف الرحمن مفرقة .  <br />
وأخرج أبو الشيخ عن محمد بن كعب القرظي وفي قوله { الر } قال : ألف ولام وراء من الرحمن .  <br />
أما قوله : { تلك آيات الكتاب الحكيم } .  <br />
أخرج ابن أبي حاتم عن أنس بن مالك رضي الله عنه في قوله تعالى { تلك } يعني هذه .  <br />
وأخرج ابن أبي حاتم عن قتادة في قوله تعالى { تلك آيات الكتاب } قال : الكتب التي خلت قبل القرآن .  <br />
