قوله تعالى : { وإبراهيم الذي وفى } .  <br />
أخرج سعيد بن منصور وعبد بن حميد وابن جرير وابن أبي حاتم وابن مردوية والشيرازي في الألقاب والديلمي بسند ضعيف عن أبي أمامة عن النبي صلى الله عليه وسلم قال : « أتدرون ما قوله { وإبراهيم الذي وفى } قالوا : الله ورسوله أعلم .   قال : وفى عمل يومه بأربع ركعات كان يصليهن من أول النهار وزعم أنها صلاة الضحى  » .  <br />
وأخرج ابن المنذر وابن أبي حاتم عن ابن عباس في قوله { وإبراهيم الذي وفى } قال : وفى الله بالبلاغ .  <br />
وأخرج الفريابي وعبد بن حميد وابن جرير عن مجاهد في قوله { وإبراهيم الذي وفى } قال : وفى ما فرض عليه .  <br />
وأخرج الحاكم وصححه وابن مردوية عن ابن عباس قال : سهام الإِسلام ثلاثون سهماً لم يمسها أحد قبل إبراهيم عليه الصلاة والسلام ،   قال الله { وإبراهيم الذي وفى } .  <br />
وأخرج ابن جرير عن قتادة { وإبراهيم الذي وفى } قال : وفى طاعة الله وبلغ رسالة ربه إلى خلقه .  <br />
وأخرج ابن جرير عن مجاهد وعكرمة { وإبراهيم الذي وفى } قال : بلغ هذه الآية { أن لا تزر وازرة وزر أخرى } .  <br />
وأخرج ابن جرير عن سعيد بن جبير { وإبراهيم الذي وفى } قال : بلغ ما أمر به .  <br />
وأخرج ابن جرير عن ابن عباس { وإبراهيم الذي وفى } يقول : الذي استكمل الطاعة فيما فعل بابنه حين رأى الرؤيا والذي في صحف موسى { أن لا تزر وازرة وزر أخرى } إلى آخر الآية .  <br />
وأخرج ابن جرير عن القرظي { وإبراهيم الذي وفى } قال : وفى بذبح ابنه .  <br />
وأخرج ابن مردوية عن ابن عباس في قوله { وإبراهيم الذي وفى } قال : وفى سهام الإِسلام كلها ولم يوفها أحد غيره ،   وهي ثلاثون سهماً منها عشرة في براءة { إن الله اشترى من المؤمنين أنفسهم وأموالهم } [ التوبة : 111 ] الآيات كلها وعشرة في الأحزاب { إن المسلمين والمسلمات } [ الأحزاب : 35 ] الآيات كلها وستة في { قد أفلح المؤمنين } [ المؤمنون : 1 ] من أولها الآيات كلها وأربع في { سأل سائل } [ المعارج : 1 ] { والذين يصدقون بيوم الدين } [ المعارج : 26 ] { والذين هم من عذاب ربهم مشفقون } [ المعارج : 27 ] الآيات كلها فذلك ثلاثون سهماً فمن وافى الله بسهم منها فقد وافاه بسهم من سهام الإِسلام ولم يوافه بسهام الإِسلام كلها إلا إبراهيم عليه الصلاة والسلام ،   قال الله { وإبراهيم الذي وفى } .
