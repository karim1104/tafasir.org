وتنبيها إلى عدل الله في عقابه للظالمين الذين ظلموا أنفسهم وظلموا غيرهم وظلموا ربهم ،  وتمسكوا بالتقليد الأعمى للآباء والأجداد في ضلالهم ،  وأصروا على اتباع آثارهم وحمل أوزارهم ،  قال تعالى تعقيبا على ما سبق :  {  إنهم ألفوا -آباءهم ضالين( 69 ) } ،  أي :  وجدوهم على ضلال فاقتدوا بهم ،  {  فهم على آثارهم يهرعون( 70 ) } ،  أي :  يسيرون عليها سيرا حثيثا ،  {  ولقد ضل قبلهم أكثر الأولين( 71 ) ولقد أرسلنا فيهم منذرين( 72 ) فانظر كيف كان عاقبة المنذرين( 73 ) } ،  ثم قال تعالى :  {  إلا عباد الله المخلصين( 74 ) } ،  استثناء من قوله تعالى :  {  أكثر الأولين } ،  عقب قوله :  {  ولقد ضل قبلهم } ،  أو استثناء من قوله تعالى :  {  عاقبة المنذرين } ،  عقب قوله {  فانظر كيف كان } .  ويصح أن يكون الاستثناء منهما معا ،  لأن  " عباد الله المخلصين "  اهتدوا فلم يكونوا ،  {  من الضالين } ،  وسبقت لهم الحسنى والبشرى فلم يكونوا ،  {  من المنذرين } .
