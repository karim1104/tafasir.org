قوله: { وَلاَ يَزَالُ ٱلَّذِينَ كَفَرُواْ } رجوع لذكر حال الكفار وما هم عليه. قوله: (أي القرآن) أشار بذلك إلى أن الضمير عائد على القرآن، وقيل عائد على الرسول، أي في شك من أمر الرسول من كونه صادقاً أو لا. قوله: (بما ألقاه الشيطان على لسان النبي) هذا خلاف الصواب، والصواب أن يقول بما ألقاه الشيطان في قلوب من أضلهم الله. قوله: { يَوْمٍ عَقِيمٍ } العقم في الأصل عدم الولادة، فشبه اليوم الذي لا خير فيه بمرأة عقيم، وطوى ذكر المشبه به، ورمز له بشيء من لوازمه وهو العقم، فإثباته تخييل، والجامع عدم الثمرة في كل.  قوله: { يَوْمَئِذٍ } التنوين عوض عن جملة أي الملك يوم تأتيهم الساعة بغتة، أو يأتيهم العذاب يوم القيامة لله، ومعنى كونه لله، عدم نسبة شيء في الملك لأحد سواه في ذلك اليوم. قوله: (ناصب للظرف) أي قوله: { يَوْمَئِذٍ }. قوله: { يَحْكُمُ بَيْنَهُمْ } جملة مستأنفة سيقت جواباً لسؤال مقدر تقديره ماذا يصنع بهم. قوله: (فضلاً من الله) أي لا بسبب أعمالهم.  قوله: { وَٱلَّذِينَ هَاجَرُواْ } مبتدأ وخبره { لَيَرْزُقَنَّهُمُ ٱللَّهُ } ، وخصهم بالذكر وإن كانوا داخلين في جملة المؤمنين تعظيماً لشأنهم. قوله: { ثُمَّ قُتِلُوۤاْ } أي في الحروب، وقوله: { أَوْ مَاتُواْ } أي على فراشهم من غير قتل. قوله: (هو رزق الجنة) أي التنعم فيها. قوله: (أفضل المعطين) أي فالمراد بالرزق الإعطاء، وهو ينسب للخلق كما ينسب للخالق، إلا أن نسبته للخالق حقيقة، ولغيره مجاز. قوله: { لَيُدْخِلَنَّهُمْ } الخ، إما مستأنف أو بدل من قوله ليرزقنهم. قوله: (بضم الميم وفتحها) أي فهما قراءتان سبعيتان. قوله: { حَلِيمٌ } أي فلا يعجل بالعقوبة على من عصاه، بل يمهله ليتوب فيستحق الجنة.
