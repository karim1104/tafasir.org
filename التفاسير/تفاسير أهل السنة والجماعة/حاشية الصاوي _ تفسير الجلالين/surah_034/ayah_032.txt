قوله: { قَالَ ٱلَّذِينَ ٱسْتَكْبَرُواْ } أي جواباً للمستضعفين. قوله: { أَنَحْنُ صَدَدنَاكُمْ } أي منعناكم. قوله: (لا) أشار بذلك إلى أن الاستفهام انكاري.  قوله: { وَقَالَ ٱلَّذِينَ ٱسْتُضْعِفُواْ } ترك العاطف فيما سبق لأنه مر أولاً كلامهم، فأتى بالجواب مستأنفاً من غير عاطف، ثم أتى بكلام آخر للمستضعفين معطوفاً على كلامهم الأول. قوله: { بَلْ مَكْرُ ٱلَّيلِ وَٱلنَّهَارِ } ردَّ وإبطال لكلام المستكبرين، ومكر فاعل بفعل محذوف، أي صددنا مكركم بنا في الليل والنهار، فحذف المضاف إليه، وأقيم الظرف مقامه على الاتساع، والإسناد مجازي. قوله: { إِذْ تَأْمُرُونَنَآ } ظرف للمكر، أي مكركم وقت أمركم لنا، إلخ. قوله: { وَأَسَرُّواْ ٱلنَّدَامَةَ } جملة حالية، أو مستأنفة. قوله: (أي أخفاها كل عن رفيقه) أي فكل أخفى الندم على فعله في الدنيا من الكفر والمعاصي مخافة أن يعيره الآخر. قوله: { وَجَعَلْنَا ٱلأَغْلاَلَ فِيۤ أَعْنَاقِ ٱلَّذِينَ كَفَرُواْ } أي زيادة على تعذيبهم بالنار.  قوله: { وَمَآ أَرْسَلْنَا } إلخ، هذا تسلية له صلى الله عليه وسلم. قوله: { إِلاَّ قَالَ مُتْرَفُوهَآ } حال من قرية وإن كانت نكرة، لوقوعها في سياق النفي، فنعم فقد وجد المسوغ. قوله: { بِمَآ أُرْسِلْتُمْ بِهِ } متعلق بكافرون، قدم للاهتمام ورعاية للفواصل. قوله: { وَقَالُواْ نَحْنُ أَكْثَـرُ أَمْوَالاً وَأَوْلاَداً } أي فلو لم يكن راضياً بما نحن عليه، لما أعطانا الأموال والأولاد، في الدنيا، وإذا كان كذلك، فلا يعذبنا في الآخرة. قوله: { وَمَا نَحْنُ بِمُعَذَّبِينَ } أي لأنا لما أكرمنا في الدنيا، فلا يهيننا في الآخرة على فرض وجودها.
