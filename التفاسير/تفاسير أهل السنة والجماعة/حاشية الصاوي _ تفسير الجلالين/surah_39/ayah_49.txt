قوله: { مِنْ هَـٰؤُلاَءِ } بيان للذين ظلموا. قوله: (فقحطوا سبع سنين) أي أوائل سني الهجرة، حتى أكلوا الجيف والعظم المحرق. قوله: (ثم وسع عليهم) أي استدراجاً لهم، ولا رضاً عليهم.  قوله: { أَوَلَمْ يَعْلَمُوۤاْ } أي القائلون: إنما أوتيته على علم عندي. قوله: { يَبْسُطُ ٱلرِّزْقَ لِمَن يَشَآءُ } أي وإن كان لا حيلة له ولا قوة، طائعاً أو عاصياً. وقوله: { وَيَقْدِرُ } أي لمن يشاء، وإن كان قوياً شديداً، طائعاً أو عاصياً، فليس لبس الرزق الدنيوي ولا لقبضه، مدخل في محبة الله ولا بغضه، بل بحكمته تعالى. قوله: { إِنَّ فِي ذَلِكَ } أي المذكور.
