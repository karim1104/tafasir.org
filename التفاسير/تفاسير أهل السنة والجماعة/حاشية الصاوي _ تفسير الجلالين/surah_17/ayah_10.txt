قوله: { إِنَّ هَـٰذَا ٱلْقُرْآنَ } أي الذي أنزل على محمد. قوله: { يَِهْدِي } أي يرشد ويوصل. قوله: { لِلَّتِي هِيَ أَقْوَمُ } أي فمن تمسك به نجا، ومن حاد عنه هلك ففي الحديث " إني تارك فيكم ثقلين، ما إن تمسكتم بهما لن تضلوا أبداً، كتاب الله وعترتي " قوله: { أَجْراً كَبِيراً } أي لا يعلم قدره غيره تعالى، وهذا الأجر ثابت لمن عمل الصالحات، وإن لم يكن حافظاً لألفاظ القرآن، بل المدار على امتثال الأوامر واجتناب النواهي. قوله: { وَ } (يخبر) أشار بذلك إلى أن قوله: { وأَنَّ ٱلَّذِينَ لاَ يُؤْمِنُونَ } الخ، معطوف على { وَيُبَشِّرُ } فهو غير داخل في حيز البشارة. قوله: (أعددنا) أي هيأنا وأحضرنا.
