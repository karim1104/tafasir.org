قوله: { إِذَا وَقَعَتِ ٱلْوَاقِعَةُ }  { إِذَا } إما ظرف ليس فيه معنى الشرط، وعامله ليس لوقعتها كاذبة من حيث إنها تضمنت معنى النفي كأنه قيل: انتفى التكذيب وقت وقوعها، أو شرطية وجوابها محذوف تقديره يحصل كذا وكذا وهو العامل فيها، وقوله: (قامت القيامة) أي فالواقعة من جملة أسماء القيامة. قوله: { لَيْسَ لِوَقْعَتِهَا } اللام بمعنى في على حذف مضاف، والمعنى: ليس نفس كاذبة توجد في وقت وقوعها. قوله: { خَافِضَةٌ رَّافِعَةٌ } خبر مبتدأ محذوف كما أفاده المفسر بقوله: (أي هي) الخ. قوله: (لخفض أقوام) الخ، أي حساً ومعنى: فأهل الجنة ترفعهم حساً ومعنى، وأهل النار تخفضهم كذلك، ونسبة الخفض والرفع إليها مجاز من إسناد الفعل لمحله وزمانه.
