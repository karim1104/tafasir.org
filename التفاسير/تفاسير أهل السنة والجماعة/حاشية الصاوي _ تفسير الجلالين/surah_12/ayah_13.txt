قوله: { لَيَحْزُنُنِيۤ } الحزن ألم القلب بفراق المحبوب.  قوله: { وَأَخَافُ أَن يَأْكُلَهُ ٱلذِّئْبُ } بالهمز وتركه قراءتان سبعيتان، وسبب خوفه، أنه كان رأى في المنام أن ذئباً تعرض ليوسف، فكان يخاف عليه الذئب. قوله: { قَالُواْ لَئِنْ أَكَلَهُ ٱلذِّئْبُ } هذا جواب عن عذره الثاني وهو قوله: { وَأَخَافُ أَن يَأْكُلَهُ ٱلذِّئْبُ } وأما الأول وهو قوله: { إِنِّي لَيَحْزُنُنِيۤ } إلخ، فلا يجيبوا عنه، لأن غرضهم حصوله. قوله: { وَنَحْنُ عُصْبَةٌ } الجملة حالية. قوله: (عاجزون) أي فالخسران مجاز عن الضعف والعجز لأنه يشبهه.
