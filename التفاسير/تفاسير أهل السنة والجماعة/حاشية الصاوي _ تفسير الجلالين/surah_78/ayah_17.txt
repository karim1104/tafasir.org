قوله: { أَلَمْ نَجْعَلِ ٱلأَرْضَ مِهَٰداً }  { ٱلأَرْضَ } مفعول أول، و { مِهَٰداً } مفعول ثان إن جعلت بمعنى التصيير، وإن جعلت بمعنى الخلق فيكون { مِهَٰداً } حالاً، وكذا يقال في قوله: { أَوْتَاداً } وما بعده. قوله: (كالمهد) أي للصبي، وهو ما يفرش له لينام عليه. قوله: (للتقرير) أي مما بعد النفي. قوله: { سُبَاتاً } بالضم كغراب، النوم الثقيل، وأصله الراحة، وفعله سبت كقتل. قوله: (ساتراً بسواده) أي ظلمته، ففيه تشبيه بليغ بحذف الأداة، أي كاللباس بجامع الستر في كل. قوله: (وقتاً للمعايش) أي تنصرفون فيه في حوائجكم.  قوله: { وَهَّاجاً } أي مضيئاً. قوله: (يعني الشمس) أي لأنها كوكب نهاري، ينسخ ضوؤها ظلمة الليل. قوله: (التي حان لها أن تمطر) أي جاء وقت إمطارها المقدر لها. قوله: (الجارية) المراد بها مطلق الأنثى. قوله: (صباباً) أي بشدة وقوة. قوله: { حَبّاً وَنَبَاتاً } أي فالمراد ما يقتات به، وما يعلف به من التبن والحشيش. قوله: (جمع لفيف) وقيل جمع لف بكسر اللام، وقيل لا واحد له. قوله: { إِنَّ يَوْمَ ٱلْفَصْلِ } الخ، كلام مستأنف واقع في جواب سؤال مقدر تقديره: ما وقت البعث الذي أثبت بالأدلة المتقدمة فقال: { إِنَّ يَوْمَ ٱلْفَصْلِ } وأكده بإن لتردد الكفار فيه. قوله: { كَانَ مِيقَاتاً } أي في علمه وقضائه. قوله: (وقتاً للثواب والعقاب) أشار بذلك إلى أن الميقات زمان مقيد، بكونه وقت ظهور ما وعد الله به من الثواب والعقاب.
