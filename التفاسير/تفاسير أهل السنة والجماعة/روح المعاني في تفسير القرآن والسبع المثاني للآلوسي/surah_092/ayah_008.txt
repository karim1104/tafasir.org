{ وَأَمَّا مَنْ بخل } بما له فلم يبذله في سبيل الخير وقيل أي بخل بفعل ما أمر به وفيه ما فيه { واستغنى } أي وزهد فيما عنده عز وجل كأنه مستغن عنه سبحانه فلم يتقه جل وعلا أو استغنى بشهوات الدنيا عن نعيم العقبى لأنه في مقابلة { واتقى } كما أن قوله تعالى : { أَحْسَنُواْ بالحسنى } في مقابلة { وصدق بالحسنى } [ الليل : 6 ] والمراد بالحسنى فيه ما مر في الأقوال قبل .
