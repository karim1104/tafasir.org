{ ذلك } أي الهدى إلى الطريق المستقيم أو ما يفهم من النظم الكريم من مصادر الأفعال المذكورة أو ما دانوا به ،  وما في ذلك من معنى البعد لما مر مراراً { هُدَى الله } الإضافة للتشريف { يَهْدِى بِهِ مَن يَشَاء } هدايته { مِنْ عِبَادِهِ } وهم المستعدون لذلك ،  وفي تعليق الهداية بالموصول إشارة إلى علية مضمون الصلة ويفيد ذلك أنه تعالى متفضل بالهداية { وَلَوْ أَشْرَكُواْ } أي أولئك المذكورون { لَحَبِطَ } أي لبطل وسقط { عَنْهُمْ } مع فضلهم وعلو شأنهم { مَا كَانُواْ يَعْمَلُونَ } أي ثواب أعمالهم الصالحة فكيف بمن عداهم وهم هم وأعمالهم أعمالهم .  <br />
( هذا ومن باب الإشارة ) :{ ذلك هُدَى الله يَهْدِى بِهِ مَن يَشَاء مِنْ عِبَادِهِ } وهم أهل السابقة الذين سألوه سبحانه الهداية بلسان الاستعداد الأزلي { وَلَوْ أَشْرَكُواْ } بالميل إلى السوى وهو شرك الكاملين كما أشار إليه سيدي عمر بن الفارض قدس سره بقوله :<br />
ولو خطرت لي في سواك إرادة ***  على خاطري سهواً حكمت بردتي<br />
{ لَحَبِطَ عَنْهُمْ مَّا كَانُواْ يَعْمَلُونَ } [ الأنعام : 88 ] لعظم ما أتوا به { إِنَّ الشرك لَظُلْمٌ عَظِيمٌ } [ لقمان : 13 ]
