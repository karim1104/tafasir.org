{ ينادونهم } استئناف مبني على السؤال كأنه قيل : فماذا يفعلون بعد ضرب السور ومشاهدة العذاب ؟ فقيل : ينادي المنافقون والمنافقات المؤمنين والمؤمنات { أَلَمْ نَكُن } في الدنيا { مَّعَكُمْ } يريدون به موافقتهم لهم في الظاهر { قَالُواْ بلى } كنتم معناكما تقولون { ولكنكم فَتَنتُمْ أَنفُسَكُمْ } محنتموها بالنفاق وأهلكتموها { وَتَرَبَّصْتُمْ } بالمؤمنين الدوائر { وارتبتم } وشككتم في أمور الدين { وَغرَّتْكُمُ الأماني } الفارغة التي من جملتها الطمع في انتكاس الإسلام ،  وقال ابن عباس : { فَتَنتُمْ أَنفُسَكُمْ } بالشهوات واللذات { وَتَرَبَّصْتُمْ } بالتوبة { وارتبتم } قال محبوب الليثي : شككتم في الله { وَغرَّتْكُمُ الأماني } طول الآمال ،  وقال أبو سنان : قلتم سيغفر لنا { حتى جَاء أَمْرُ الله } أي الموت { وَغَرَّكُم بالله الغرور } الشيطان قال لكم : إن الله عفو كريم لا يعذبكم . <br />
وعن قتادة كانوا على خدعة من الشيطان والله ما زالوا عليها حتى قذفهم الله تعالى في النار . <br />
وقرأ سماك بن حرب الغرور بالضم ،  قال ابن جنى : وهو كقوله : وغركم بالله تعالى الاغترار ،  وتقديره على حذف المضاف أي وغركم بالله تعالى سلامة الاغترار ومعناه سلامتكم منه اغتراركم . <br />
