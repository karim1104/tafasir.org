{ وَلاَ يَصُدُّنَّكَ } أي الكافرون { عَنْ ءايات الله } أي قراءتها والعمل بها . <br />
{ بَعْدَ إِذْ أُنزِلَتْ إِلَيْكَ } أي بعد وقت إنزالها وإيحائها إليك المقتضى لنبوتك ومزيد شرفك ،  وقرأ يعقوب { يَصُدُّنَّكَ } بالنون الخفيفة وقرئ { يَصُدُّنَّكَ } مضارع أصد بمعنى صدّ حكاه أبو زيد عن رجل من كلب قال : وهي لغة قومه وقال الشاعر :<br />
أناس أصدوا الناس بالسيف عنهم *** صدود السواقي عن أنوف الحوائم<br />
{ وادع } الناس { إلى رَبّكَ } إلى عبادته جل وعلا وتوحيده سبحانه { وَلاَ تَكُونَنَّ مِنَ المشركين } بمظاهرتهم . <br />
