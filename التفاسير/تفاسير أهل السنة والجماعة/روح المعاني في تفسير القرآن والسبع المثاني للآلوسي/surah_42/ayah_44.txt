{ وَمَن يُضْلِلِ الله فَمَا لَهُ مِن وَلِىّ مّن بَعْدِهِ } أي ما له من ناصر يتولاه من بعد خذلان أن الله تعالى إياه فضمير { بَعْدِهِ } لله تعالى بتقدير مضاف فيه ،  وقيل للخذلان المفهوم من { يُضْلِلِ } والجملة عطف على قوله تعالى : { أُوْلَئِكَ لَهُمْ عَذَابٌ أَلِيمٌ } [ الشورى : 42 ] وكنى بمن عن الظالم الباغي تسجيلاً بأنه ضال مخذول أو أتى به مبهماً ليشمله شمولاً أولياً فقوله سبحانه : { وَلَمَن صَبَرَ } [ الشورى : 43 ] الخ اعتراض لما أشرنا إليه { وَتَرَى الظالمين لَمَّا رَأَوُاْ العذاب } أي حين يرونه ،  وصيغة الماضي للدلالة على التحقق { يَقُولُونَ هَلْ إلى مَرَدّ } أي رجعة إلى الدنيا { مّن سَبِيلٍ } حتى نؤمن ونعمل صالحاً وجوز أن يكون المعنى هل إلى رد للعذاب ومنع منه من سبيل ،  وتنكير { مَرَدَّ } وكذا { سَبِيلٍ } للمبالغة والجملة حال وقيل مفعول ثان لترى .
