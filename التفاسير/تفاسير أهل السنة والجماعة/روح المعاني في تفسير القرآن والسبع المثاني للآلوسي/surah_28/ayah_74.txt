{ وَيَوْمَ يُنَادِيهِمْ } منصوب باذكر . <br />
{ فَيَقُولُ أَيْنَ شُرَكَائِىَ الذين كُنتُمْ تَزْعُمُونَ } تقريع إثر تقريع للإشعار بأنه لا شيء أجلب لغضب الله تعالى من الإشراك كما لا شيء أدخل في مرضاته من توحيده عز وجل ،  أو أن الأول لبيان فساد رأيهم كما يشير إليه قوله تعالى هناك : { حَقَّ عَلَيْهِمُ القول } [ القصص : 63 ] ،  وهذا لبيان أن إشراكهم لم يكن عن سند بل عن محض هوى كما يشير إليه قوله تعالى بعد : { هَاتُواْ برهانكم } [ القصص : 75 ] أو الأول إحضار للشركاء بعدم الصلوح لقوله سبحانه بعده : { ادعوا شُرَكَاءكُمْ فَدَعَوْهُمْ } [ القصص : 64 ] وهذا تحسير بأنهم لم يكونوا في شيء من اتخاذهم ألا ترى قوله تعالى : { وَضَلَّ عَنْهُمْ مَّا كَانُواْ يَفْتَرُونَ } [ القصص : 75 ] .
