{ وَنَزَعْنَا } عطف على { يناديهم } [ القصص : 74 ] وصيغة الماضي للدلالة على التحقق أو حال من فاعله بإضمار قد أو بدونه والالتفات إلى نون العظمة لإبراز كمال العناية بشأن النزع وتهويله أي أخرجنا بسرعة { مِن كُلّ أمَّةٍ } من الأمم { شَهِيداً } شاهداً يشهد عليهم بما كانوا عليه وهو نبي تلك الأمة كما روي عن مجاهد ،  وقتادة ،  ويؤيده قوله تعالى : { فَكَيْفَ إِذَا جِئْنَا مِن كُلّ أمَّةٍ بِشَهِيدٍ وَجِئْنَا بِكَ على هَؤُلاء شَهِيداً } [ النساء : 41 ] وهذا في موقف من مواقف يوم القيامة فلا يضر كون الشهيد في موقف آخر غير الأنبياء عليهم السلام وهم أمة محمد صلى الله عليه وسلم أو الملائكة عليهم السلام لقوله تعالى : { وَجيء بالنبيين والشهداء } [ الزمر : 69 ] فإنه دال في الظاهر على مغايرة الشهداء للأنبياء عليهم السلام . <br />
وقيل : يجوز اتحاد الموقف والدلالة على المغايرة غير مسلمة ولو سلمت فشهادة الأنبياء عليهم السلام لا تنافي شهادة غيرهم معهم ،  وقوله تعالى : { مِن كُلّ أمَّةٍ } وإفراد شهيد ظاهر فيما تقدم ،  ومن هنا قال في البحر » قيل : أي عدولاً وخياراً ،  والشهيد عليه اسم جنس { فَقُلْنَا } لكل من تلك الأمم { هَاتُواْ برهانكم } على صحة ما كنتم تدينون به . <br />
{ فَعَلِمُواْ } ،  يومئذٍ ،  { أَنَّ الحق لِلَّهِ } ،  في الألوهية لا يشاركه سبحانه فيها أحد . <br />
{ وَضَلَّ عَنْهُم } أي وغاب عنهم غيبة الشيء الضائع فضل مستعار لمعنى غاب استعارة تبعية . <br />
{ مَّا كَانُواْ يَفْتَرُونَ } ،  في الدنيا من الباطل .
