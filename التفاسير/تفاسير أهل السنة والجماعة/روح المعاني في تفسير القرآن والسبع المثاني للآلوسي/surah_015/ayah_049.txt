{ نَبّىء } قيل : مطلقاً ،  وقيل : الذين عبر عنهم بالمتقين أي أخبرهم { عِبَادِى أَنّى أَنَا الغفور الرحيم } .  <br />
( ومن باب الإشارة ) : فيما تقدم من الآيات : ما قالوه مما ملخصه { نَبّىء عبادي أَنّى أَنَا الغفور الرحيم } [ الحجر : 49 ] أي أخبرهم بأني أغفر خطرات قلوب العارفين بعد إدراكهم مواضع خطرها وتداركهم ما هو مطلوب منهم وأرحمهم بأنواع الفيوضات وأوصلهم إلى أعلى المكاشفات والمشاهدات<br />
