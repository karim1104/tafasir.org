{ وَأَوْحَيْنَا إلى موسى أَنْ أَسْرِ بعبادي } وذلك بعد سنين أقام بين ظهرانيهم يدعوهم إلى الحق ويظهر لهم الآيات فلم يزيدوا إلا عتواً وعناداً حسبما فصل في سورة الأعراف بقوله تعالى : { وَلَقَدْ أَخَذْنَا ءالَ فِرْعَوْنَ بالسنين } [ الأعراف : 130 ] الآيات .   وقرئ { أَنْ أَسْرِ } بكسر النون ووصل الألف من سرى .   وقرأ اليماني { أن } أمراً من سار يسير { بِعِبَادِي إِنَّكُم مّتَّبِعُونَ } تعليل للأمر بالإسراء أي يتبعكم فرعون وجنوده مصبحين فأسر ليلاً بمن معك حتى لا يدركوكم قبل الوصول إلى البحر بل يكونون على أثركم حين تلجون البحر فيدخلون مداخلكم فأطبقه عليهم فأغرقهم .
