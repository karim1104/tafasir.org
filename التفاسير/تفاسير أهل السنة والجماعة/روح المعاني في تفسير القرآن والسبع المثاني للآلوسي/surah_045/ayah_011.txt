{ هذا } أي القرآن كما يدل عليه ما بعد وكذا ما قبل ك { يسمع آيات الله } [ الجاثية : 8 ] و { إذا علم من آياتنا } [ الجاثية : 9 ] و { تِلْكَ آيات الله نَتْلُوهَا } [ الجاثية : 6 ] { هُدًى } في غاية الكمال من الهداية كأنه نفسها { والذين كَفَرُواْ بئايات رَبّهِمْ } يعني القرآن أيضاً على أن الإضافة للعهد ،  وكان الظاهر الإضمار لكن عدل عنه إلى ما في النظم الجليل لزيادة تشنيع كفرهم به وتفظيع حالهم ،  وجوز أن يراد بالآيات ما يشمله وغيره .  <br />
{ لَهُمْ عَذَابٌ مّن رّجْزٍ } من أشد العذاب { أَلِيمٌ } بالرفع صفة { عَذَابِ } أخر للفاصلة .  <br />
وقرأ غير واحد من السبعة { أَلِيمٌ } بالجر على أنه صفة { رِجْزَ } ،  وجعله صفة { عَذَابِ } أيضاً والجر للمجاورة مما لا ينبغي أن يلتفت إليه ،  وقيل : على قراءة الرفع إن الرجز بمعنى الرجس الذي هو النجاية ،  والمعنى لهم عذاب أليم من تجرع رجس أو شرب رجس والمراد به الصديد الذي يتجرعه الكافر ولا يكاد يسيغه ولا داعي لذلك كما لا يخفى ،  وتنوين { عَذَابِ } في المواقع الثلاثة للتفخيم ،  ورفعه إما على الابتداء وإما على الفاعلية للظرف .
