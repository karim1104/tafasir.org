{ مَّنْ عَمِلَ صالحا } بأن آمن بالكتب وعمل بموجبها { فَلِنَفْسِهِ } أي فلنفسه يعمله أو فلنفسه نفعه لا لغيره ،  و { مِنْ } يصح فيها الشرطية والموصولية وكذا في قوله تعالى : { وَمَنْ أَسَاء فَعَلَيْهَا } ضره لا على الغير { وَمَا رَبُّكَ بظلام لّلْعَبِيدِ } اعتراض تذييلي مقرر لمضمون ما قبله مبني على تنزيل ترك إثابة المحسن بعمله أو إثابة الغير بعمله وتنزيل التعذيب بغير إساءة أو بإساءة غيره منزلة الظلم الذي يستحيل صدوره عنه تعالى ولم يحتج بعضهم إلى التنزيل ،  وقد مر الكلام في ذلك وفي توجيه النفي والمبالغة فتذكر . <br />
