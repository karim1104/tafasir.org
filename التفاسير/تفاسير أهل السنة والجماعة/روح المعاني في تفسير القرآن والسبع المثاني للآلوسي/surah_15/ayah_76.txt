{ وَإِنَّهَا } أي المدينة المهلكة وقيل القرى { لَبِسَبِيلٍ مُّقِيمٍ } أي طريق ثابت يسلكه الناس ويرون آثارها وقيل : الضمير للآيات ،  وقيل : للحجارة ،  وقيل : للصيحة أي وإن الصيحة صد لمن يعمل عملهم لقوله تعالى : { وَمَا هِى مِنَ الظالمين بِبَعِيدٍ } [ هود : 83 ] و { مُّقِيمٌ } قيل معلوم ،  وقيل : معتد دائم السلوك .
