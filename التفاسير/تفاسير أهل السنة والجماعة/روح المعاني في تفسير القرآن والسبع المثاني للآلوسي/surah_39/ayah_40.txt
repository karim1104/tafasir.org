{ مَن يَأْتِيهِ عَذَابٌ يُخْزِيهِ وَيَحِلُّ عَلَيْهِ عَذَابٌ مُّقِيمٌ } فإن الأول اشارة إلى العذاب الدنيوي وقد نالهم يوم بدر والثاني إشارة إلى العذاب الأخروي فإن العذاب المقيم عذاب النار فلو قيل إني عامل على مكانتي وكان إذ ذاك غير غالب بل الأمر بالعكس لم يلائم المقصود ،  و { مِنْ } تحتمل الاستفهامية والموصولية وجملة { يُخْزِيهِ } صفة { عَذَابِ } والمراد بمقيم دائم وفي الكلام مجاز في الظرف أو الإسناد وأصله مقيم فيه صاحبه . <br />
