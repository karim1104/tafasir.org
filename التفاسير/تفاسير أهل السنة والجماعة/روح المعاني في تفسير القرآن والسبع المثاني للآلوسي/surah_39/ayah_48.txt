{ بِمُسْتَيْقِنِينَ وَبَدَا لَهُمْ } حين تعرض عليهم صحائفهم { عَنْهُم مَّا كَسَبُواْ } أي الذي كسبوه وعملوه على أن { مَا } موصولة أو كسبهم وعملهم على أنها مصدرية ،  وإضافة { سَيّئَاتُ } على معنى من أو اللام { وَحَاقَ } أي أحاط { بِهِم مَّا كَانُواْ بِهِ } أي جزاء ذلك على أن الكلام على تقدير المضاف أو على أن هناك مجازاً بذكر السبب وإرادة مسببه ،  و { مَا } محتملة للموصولية والمصدرية أيضاً . <br />
