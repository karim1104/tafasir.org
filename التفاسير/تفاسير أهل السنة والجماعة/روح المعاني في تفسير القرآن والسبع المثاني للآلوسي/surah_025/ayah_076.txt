{ خالدين فِيهَا } لا يموتون ولا يخرجون ،  وهو حال من ضمير { يُجْزَوْنَ } [ الفرقان : 75 ] أو من ضمير { يُلْقُون } [ الفرقان : 75 ] .  <br />
{ حَسُنَتْ مُسْتَقَرّاً وَمُقَاماً } مقابل { سَاءتْ مُسْتَقَرّاً } [ الفرقان : 66 ] معنى ومثله إعراباً فتذكر ولا تغفل .  <br />
ومن باب الإشارة : { خالدين فِيهَا حَسُنَتْ مُسْتَقَرّاً وَمُقَاماً } [ الفرقان : 76 ] لأنها مشهد الحق ومحل رضا المحبوب المطلق ،  نسأل الله تعالى أن يمن علينا برضائه ويمنحنا بسوابغ نعمائه وآلائه بحرمة سيد أنبيائه وأحب أحبائه صلى الله عليه وسلم وشرق قدره وعظم .
