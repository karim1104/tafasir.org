{ وهذا } الذي تليت عليكم أوامره ونواهيه أي القرآن { كِتَابٌ } عظيم الشأن لا يقادر قدره { أنزلناه } بواسطة الروح الأمين مشتملاً على فوائد الفنون الدينية والدنيوية التي فصلت عليكم طائفة منها ،  والجملة صفة { كِتَابٌ } وقوله سبحانه : { مُّبَارَكٌ } أي كثير الخير ديناً ودنيا صفة أخرى ،  وإنما قدمت الأولى عليها مع أنها غير صريحة لأن الكلام مع منكري الإنزال ،  وجوز أن يكون هذا وما قبله خبرين عن اسم الإشارة أيضاً ؛ والفاء في قوله تعالى : { فاتبعوه } لترتيب ما بعدها على ما قبلها فإن عظم شأن الكتاب في نفسه وصفته موجب لاتباعه أي فاعملوا بما فيه أو امتثلوا أوامره { واتقوا } مخالفته أو نواهيه { لَعَلَّكُمْ تُرْحَمُونَ } أي لترحموا جزاء ذلك ،  وقيل : المراد اتقوا على رجاء الرحمة أو اتقوا ليكون الغرض بالتقوى رحمة الله تعالى .  <br />
