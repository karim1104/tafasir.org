{ الذين كَفَرُواْ لَهُمْ عَذَابٌ شَدِيدٌ } بسبب كفرهم وإجابتهم لدعوة الشيطان واتباعهم لخطواته ،  ولعل تنكير { عَذَابِ } لتعظيمه بحسب المدة فكأنه قيل : لهم عذاب دائم شديد { والذين ءامَنُواْ وَعَمِلُواْ الصالحات لَهُم مَّغْفِرَةٌ } عظيمة { وَأَجْرٌ كَبِيرٌ } لا غاية لهما بسبب ما ذكر من الإيمان والعمل الصالح ،  و { الذين كَفَرُواْ } مبتدأ خبره { لَهُمْ عَذَابَ } وكذا { الذين آمنوا .  وَلَهُمْ مَغْفِرَةٍ } الخ ،  وجوز بعضهم كون { الذين كَفَرُواْ } في موضع خفض بدلاً من { أصحاب السعير } أو صفة له أو في موضع نصب بدلاً من { حِزْبَهُ } أو صفة له أو في موضع رفع بدلاً من ضمير { لّيَكُونُواْ } والكل مفوت لجزالة التركيب كما لا يخفي على الأريب . <br />
