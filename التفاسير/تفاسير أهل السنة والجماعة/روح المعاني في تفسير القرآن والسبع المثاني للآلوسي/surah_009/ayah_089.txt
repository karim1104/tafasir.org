{ أَعَدَّ الله لَهُمْ } استئناف لبيان كونهم مفلحين ،  وقيل : يجوز أن يكون بياناً لما لهم من المنافع الأخروية ويخص ما قبل بمنافع الدنيا بقرينة المقابلة ،  والاعداد التهيئة أي هيأ لهم { جنات تَجْرِي مِن تَحْتِهَا الانهار خالدين فِيهَا } حال مقدرة من الضمير في { لَهُمْ } والعامل { أَعَدَّ } { ذلك } إشارة إلى ما فهم من الكلام من نيل الكرامة العظمى { الفوز } أي الظفر { العظيم } الذي لا فوز وراءه .  <br />
