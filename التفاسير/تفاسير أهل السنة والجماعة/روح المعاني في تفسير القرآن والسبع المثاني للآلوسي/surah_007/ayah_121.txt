وجوز أبو البقاء كونه حالاً من ضمير { انقلبوا } [ الأعراف : 119 ] وليس بشيء ،  وقيل : هو حال من { السحرة } [ الأعراف : 120 ] أو من ضميرهم المستتر في { ساجدين } [ الأعراف : 120 ] أي أنهم ألقوا ساجدين حال كونهم قائلين { ءامَنَّا بِرَبّ العالمين } أي مالك أمرهم والمتصرف فيهم .
