{ متاع قَلِيلٌ } أي منفعتهم التي قصدوها بذلك الافتراء منفعة قليلة منقطعة عن قريب فمتاع خبر مبتدأ محذوف و { قَلِيلٌ } صفته والجملة استئناف بياني كأنه لما نفي عنهم الفوز بمطلوب قيل : كيف ذلك وهم قد تحصل لهم منفعة بالافتراء ؟ فقيل : ذاك متاع قليل لا عبر به ويرجع الأمر بالآخرة إلى أن المراد نفي الفوز بمطلوب يعتد به ،  وإلى كون { متاع } خبر مبتدأ محذوف ذهب أبو البقاء إلا أنه قال : أي بقاؤهم متاع قليل ونحو ذلك .   وقال الحوفي : { متاع قَلِيلٌ } مبتدأ وخبر ،  وفيه أن النكرة لا يبتدأ بها بدون مسوغ وتأويله بمتاعهم ونحوه بعيد { وَلَهُمْ } في الآخرة { عَذَابٌ أَلِيمٌ } لا يكتنه كنهه .  <br />
