{ الذي جَعَلَ لَكُمُ الارض مَهْداً } مكاناً ممهداً أي موطأ ومآله بسطها لكم تستقرون فيها ولا ينافي ذلك كريتها لمكان العظم ،  وعن عاصم أنه قرأ { مهادا } بدون ألف { وَجَعَلَ لَكُمْ فِيهَا سُبُلاً } طرقاً تسكلونها في أسفاركم { لَعَلَّكُمْ تَهْتَدُونَ } أي لكي تهتدوا بسلوكنها إلى مقاصدكم أو بالتفكر فيها إلى التوحيد الذي هو المقصد الأصلي .  <br />
