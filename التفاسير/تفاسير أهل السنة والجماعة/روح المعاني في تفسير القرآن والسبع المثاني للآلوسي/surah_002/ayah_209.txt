{ فَإِن زَلَلْتُمْ } أي ملتم عن الدخول في السلم وتنحيتم ،  وأصله السقوط وأريد به ما ذكر مجازاً { مّن بَعْدِ مَا جَاءتْكُمُ البينات } أي الحجج الظاهرة الدالة على أنه الحق ،  أو آيات الكتاب الناطقة بذلك الموجبة للدخول { فاعلموا أَنَّ الله عَزِيزٌ } غالب على أمره لا يعجزه شيء من الانتقام منكم { حَكِيمٌ } .   لا يترك ما تقتضيه الحكمة من مؤاخذة المجرمين .  <br />
( ومن باب الإشارة ) : { فَإِن زَلَلْتُمْ } عن مقام التسليم والرضا بالقضاء { مِن بَعْدِ } دلائل تجليات الأفعال والصفات ،  { البينات فاعلموا أَنَّ الله } تعالى { عَزِيزٌ } غالب يقهركم ،  { حَكِيمٌ } [ البقرة : 209 ] لا يقهر إلا على مقتضى الحكمة .
