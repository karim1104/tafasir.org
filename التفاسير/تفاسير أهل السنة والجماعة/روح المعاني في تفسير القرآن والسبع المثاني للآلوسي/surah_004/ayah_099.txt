{ فَأُوْلَئِكَ } أي المستضعفون { عَسَى الله أَن يَعْفُوَ عَنْهُمْ } فيه إيذان بأن ترك الهجرة أمر خطير حتى أن المضطر الذي تحقق عدم وجوبها عليه ينبغي أن يعد تركها ذنباً ،  ولا يأمن ،  ويترصد الفرصة ويعلق قلبه بها .   { وَكَانَ الله عَفُوّاً غَفُوراً } تذييل مقرر لما قبله بأتم وجه .  <br />
( ومن باب الإشارة ) :{ فَأُوْلَئِكَ عَسَى الله أَن يَعْفُوَ عَنْهُمْ } بمحو تلك الهيئات المظلمة لعدم رسوخها وسلامة عقائدهم { وَكَانَ الله عَفُوّاً } عن الذنوب ما لم تتغير الفطرة { غَفُوراً } [ النساء : 99 ] يستر بنور صفاته صفات النفوس القابلة لذلك
