{ إِنَّ الذين كَفَرُواْ } بما أنزل إليك ،  أو بكل ما يجب الإيمان به ويدخل ذلك فيه دخولاً أولياً ،  والمراد بهم اليهود ،  وكأن الجملة لبيان حكم الله سبحانه فيهم بعد بيان حالهم وتعنتهم { وَصَدُّواْ عَن سَبِيلِ الله } أي دين الإسلام من أراد سلوكه بإنكارهم نعت النبي صلى الله عليه وسلم وقولهم : لا نعرفه في كتابنا ،  وأن شريعة موسى عليه السلام لا تنسخ ،  وأن الأنبياء لا يكونون إلا من أولاد هارون وداود عليهما السلام .   وقرىء { *صدوا } بالبناء للمفعول { الله قَدْ ضَلُّواْ } بالكفر والصد { ضلالا بَعِيداً } لأنهم جمعوا بين الضلال والإضلال ولأن المضل يكون أقوى وأدخل في الضلال وأبعد عن الانقلاب عنه .  <br />
( وهذا ومن باب الإشارة ) : في الآيات : { إِنَّ الذين كَفَرُواْ } ستروا ما اقتضاه استعدادهم { وَصُدُّواْ } ومنعوا غيرهم { عَنْ } سلوك { سَبِيلِ الله } أي الطريق الموصلة إليه { قَدْ ضَلُّواْ ضلالا بَعِيداً } [ النساء : 167 ] لحرمانهم أنفسهم وغيرهم عما فيه النجاة
