{ الذين ءامَنُواْ يقاتلون فِى سَبِيلِ الله } كلام مستأنف سيق لتشجيع المؤمنين وترغيبهم في الجهاد أي المؤمنون إنما يقاتلون في دين الله تعالى الموصل لهم إليه عز وجل وفي إعلاء كلمته فهو وليهم وناصرهم لا محالة .   { والذين كَفَرُواْ يقاتلون فِى سَبِيلِ الطاغوت } فيما يبلغ بهم إلى الشيطان وهو الكفر فلا ناصر لهم سواه { فقاتلوا } يا أولياء الله تعالى إذا كان الأمر كذلك .   { أَوْلِيَاء الشيطان } جميع الكفار فإنكم تغلبونهم .   { إِنَّ كَيْدَ الشيطان كَانَ ضَعِيفاً } في حد ذاته فكيف بالقياس إلى قدرة الله تعالى الذي يقاتلون في سبيله وهو سبحانه وليكم ،  ولم يتعرض لبيان قوة جنابه تعالى إيذاناً بظهورها ،  وفائدة { كَانَ } التأكيد ببيان أن كيده مذ كان ضعيف ،  وقيل : هي بمعنى صار أي صار ضعيفاً بالإسلام ،  وقيل : إنها زائدة وليس بشيء .  <br />
( هذا ومن باب الإشارة ) : في هذه الآيات : { الذين ءامَنُواْ يقاتلون } أنفسهم { فِى سَبِيلِ الله } فيهلكونها بسيوف المجاهدة ليصلوا إليه تعالى شأنه : { والذين كَفَرُواْ يقاتلون } عقولهم وينازعونها { فِى سَبِيلِ } طاغوت أنفسهم ليحصلوا اللذات ويغنموا في هذه الدار الفانية أمتعة الشهوات { فقاتلوا أَوْلِيَاء الشيطان } وهي القوى النفسانية أو النفس وقواها<br />
