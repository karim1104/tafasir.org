قوله - تعالى - : ( قل لا يستوي الخبيث والطيب ) قال السدي : يعني الكافر والمؤمن .   وقال غيره : الخبيث : الحرام ،   والطيب : الحلال ،   وفي الخبر : «حلوان الكاهن خبيث ومهر البغي خبيث »( {[1224]} ) أي : حرام ( ولو أعجبك ) معناه : ولو سرك ( كثرة الخبيث ) .  <br />
( فاتقوا الله يا أولي الألباب لعلكم تفلحون ) وفي المثل : حرام يأتي جزفا ( والحلال ) ( {[1225]} ) يأتي قوتا .   وعن أبي هريرة أنه قال : «درهم من الحلال خير من مائة ألف [ درهم ] ( {[1226]} ) وقر من الحرام »( {[1227]} ) .
