قوله تعالى : { وإذا قيل لهم اتقوا ما بين أيديكم وما خلفكم } أي : اتقوا ما بين أيديكم أي : القيامة فاحذروها { وما خلفكم } أي : الدنيا فلا تغتروا بها .  <br />
والقول الثاني : أن معنى قوله : { اتقوا ما بين أيديكم } أي : اتقوا مثل عذاب الأمم الذين كانوا بين أيديكم ؛ لئلا يصيبكم مثل ما أصابهم .  <br />
قوله : { وما خلفكم } أي : اتقوا عذاب النار ،   وقوله : { لعلكم ترحمون } أي : كونوا على رجاء الرحمة .  <br />
