وقوله تعالى : ( فتلقى آدم من ربه كلمات ) التلقي : هو قبول عن فطنة وفهم دليل : فتلقى هو [ أي : تعلم ] ( {[85]} ) : ( ظلمنا أنفسنا ) ( {[86]} ) إلى آخره .  <br />
قال عبيد بن عمير : هي كلمات قالها آدم حين ابتلاه الله بالمعصية .  <br />
( من ربه كلمات ) قال ابن عباس والأكثرون : الكلمات هي قوله : ربنا أي : تعلم بالمعصية يارب  هذا شيء كتبته عليَّ [ أم ] ( {[87]} ) ابتدعته من تلقاء نفسي ؟ فقال : بل شيء كتبته عليك .   فقال آدم : ( فكما ) ( {[88]} ) كتبته علي فاغفره .  <br />
( فتاب عليه ) فقبل توبته ( إنه هو التواب الرحيم ) هو القابل للتوبة من العباد ؛ الرحيم بهم .
