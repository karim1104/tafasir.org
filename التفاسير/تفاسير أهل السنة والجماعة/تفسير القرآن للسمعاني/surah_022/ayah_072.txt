قوله تعالى : ( وإذا تتلى عليهم آياتنا بينات تعرف في وجوه الذين كفروا المنكر ) أي : الإنكار .  <br />
وقوله : ( يكادون ( يسطون ) ( {[2792]} ) ) أي : يقعون .  <br />
وقوله : ( بالذين يتلون عليهم آياتنا ) يعني : المؤمنين ،   وقيل : يتناولون بالشتم والمكروه .  <br />
وقوله : ( قل أفأنبئكم بشر من ذلكم ) أي : بشر عليكم وأكره لكم .  <br />
وقوله : ( النار ) كأنهم سألوا ما ذلك ؟ فقال : أجب ،   وقل : النار .  <br />
وقوله : ( وعدها الله الذين كفروا وبئس المصير ) أي : بئس المرجع .
