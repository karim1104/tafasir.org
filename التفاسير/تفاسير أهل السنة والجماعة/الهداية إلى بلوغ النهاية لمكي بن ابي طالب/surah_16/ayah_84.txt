قوله :  {  ويوم نبعث من كل أمة شهيدا } إلى قوله  {[39626]} {  وبشرى للمسلمين } [ 84-89 ] . <br />
المعنى :  ثم ينكرونها وسينكرونها يوم نبعث  {[39627]} من كل أمة شهيدا ،  أي :  شهد  {[39628]} عليها بما أجابت  {[39629]} به داعي  {[39630]} الله [ عز وجل  {[39631]} ] وهو رسولهم الذي أرسل إليهم {  ثم لا يوذن للذين كفروا } [ 84 ] يعني :  لا يؤذن لهم في الاعتذار ،  {  ولا هم يستعتبون } [ 84 ] .  أي :  ولا يتركون الرجوع إلى الدنيا فيتوبوا ومثله قوله تعالى :  {  هذا يوم لا ينطقون }   {[39632]} أي :  يعذر :  {  ولا يوذن لهم فيعتذرون }   {[39633]}   {[39634]} .
