قوله :  {  ولقد جاءهم رسول منهم فكذبوه } [ 113 ] إلى قوله :  {  لمن الصالحين } [ 122 ] . <br />
أي :  ولقد جاء أهل هذه القرية ،  يعني مكة ،  {  رسول منهم } أي :  من أنفسهم يعرفونه ويعرفون نسبه وصدق لهجته فدعاهم إلى الحق {  فكذبوه فأخذهم العذاب } وهو :  لباس الجوع والخوف ،  وقتلهم يوم بدر بالسيف {  وهم ظالمون } أي :  مشركون{[40013]} .
