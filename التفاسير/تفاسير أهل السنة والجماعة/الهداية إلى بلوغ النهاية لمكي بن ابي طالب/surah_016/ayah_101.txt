قوله :  {  وإذا بدلنا آية مكان آية } [ 101 ] إلى قوله :  {  وأولئك هم الكاذبون } [ 105 ] . <br />
المعنى عند مجاهد :  وإذا رفعنا آية وأنزلنا أخرى{[39844]} .  وعنه [ أيضا{[39845]} ] :  وإذا رفعنا آية فنسخناها وأثبتنا غيرها{[39846]} .  وقال قتادة وهو قوله :  {  ما ننسخ من آية أو ننسها }{[39847]} .  وقيل معناه :  وإذا بدلنا حكم آية بحكم آية أخرى {  والله أعلم بما ينزل } [ 101 ] مما هو أصلح لخلقه .  قال المشركون لك يا محمد {  إنما أنت مفتر } [ 101 ] أي :  متخرص الكذب على الله {  بل أكثرهم لا يعلمون } حقيقة ذلك لجهالتهم .
