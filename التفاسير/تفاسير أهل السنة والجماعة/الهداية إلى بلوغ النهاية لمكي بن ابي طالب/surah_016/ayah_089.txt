ثم قال [ تعالى{[39686]} ] :  {  ويوم نبعث من كل أمة شهيدا }{[39687]} [ 89 ]{[39688]} . <br />
أي :  [ واذكر يا محمد يوم نبعث من كل أمة شهيدا ،  أي ]{[39689]} :  نبعث إليهم نبيهم الذي أرسل إليها .  ومعنى {  من أنفسهم } أي :  من قبيلتهم لأنه تعالى أكثر ما أرسل الرسل إلى الأمم من قبيلتها . <br />
ثم قال :  {  وجئنا بك شهيدا على هؤلاء } [ 89 ] . <br />
أي :  على أمتك يا محمد الذين أرسلت إليهم {  ونزلنا عليك الكتاب } [ 89 ] أي :  القرآن . <br />
{  تبيانا لكل شيء } ] 89 ] أي :  بيانا{[39690]} للناس لما بهم إليه من{[39691]} الحاجة [ من معرفة{[39692]} ] الحلال والحرام والثواب والعقاب {  وهدى } [ 89 ] أي :  هدى من الضلالة {  ورحمة } أي :  ورحمة لمن صدق به وعمل بما فيه {  وبشرى للمسلمين } [ 89 ] ،  أي :  وبشارة لمن أطاع الله وخضع له التوحيد .
