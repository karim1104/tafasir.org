قوله :  {  أولئك الذين كفروا بآيات ربهم ولقائه } [ 100 ] إلى قوله{[43711]} :  {  عنها حولا } [ 103 ] . <br />
أي :  الذين تقدمت صفتهم واعمالهم ضلت هم {  الذين كفروا بآيات ربهم ولقائه [ 100 ] أي :  جحدوا ذلك {  فحبطت أعمالهم } [ 100 ] أي :  بطلت {  فلا نقيم لهم يوم القيامة وزنا } أي :  لا يثقل لهم ميزان بعمل صالح . <br />
روى أبو هريرة أن النبي صلى الله عليه وسلم قال :   " يؤتى يوم القيامة بالعظيم الطويل الأكول الشروب فلا يزن/جناح بعوضة ،  واقرؤوا إن شئتم{[43712]} :  {  فلا نقيم لهم يومئذ وزنا{[43713]} } [ 100 ] . <br />
ثم قال :  أبو محمد{[43714]} :  وهذا النص يدل على وزن أعمال الكفار .  فلا يثقل{[43715]} بها ميزان إذا كانت لغير الله وإذ[ كان ]{[43716]} لا يصحبها توحيد ولا إيمان بالرسل .  [ قال :  تعالى ]{[43717]} :  {  لهم سوء الحساب }{[43718]} وقال :  فيهم :  {  وعلينا الحساب }{[43719]} أي حساب من كفر .  وقال :  الله عز وجل {  فوفاه حسابه }{[43720]} وقال :  عن الكفار :  {  ولم أدر ما حسابيه }{[43721]} .  وقال :  عن الكفار أنهم قالوا :  {  عجل لنا قطنا قبل يوم الحساب }{[43722]} وقال  {  فوربك لنسألنهم أجمعين عما كانوا يعملون }{[43723]}  وقال :  {  فلنسألن الذين أرسل إليهم ولنسألن المرسلين }{[43724]}وقال :  {  وكل إنسان ألزمناه طائره في عنقه }{[43725]} أي :  كتاب عمله .  وقد ذكر تعالى ذكره وزن أعمال الكفار في غير ما موضع من كتابه .  وذلك ما عظم الحساب ،  وهو كثير في القرآن مكرر يدل على محاسبة الكفار .
