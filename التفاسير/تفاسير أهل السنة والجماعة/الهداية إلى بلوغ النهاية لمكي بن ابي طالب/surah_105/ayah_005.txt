ثم قال تعالى :  {  فجعلهم كعصف ماكول } . <br />
أي :  فجعل الله أصحاب الفيل كزرع أكلته الدواب [ فراثته ] (   {[77683]} ) ويبس(   {[77684]} ) وتفرقت أجزاؤه ،  فشبه تقطع(   {[77685]} ) أوصالهم بالعقوبة التي [ حلت ] (   {[77686]} ) ( بهم ) (   {[77687]} ) [ بتفرق ] (   {[77688]} ) أجزاء [ الروث ] (   {[77689]} ) الذي حدث من (   {[77690]} ) أكل الزرع(   {[77691]} ) . <br />
وقال مجاهد :  {  كعصف ماكول }  " كورق الحنطة " (   {[77692]} ) . <br />
وقال قتادة :   " هو التبن " (   {[77693]} ) . <br />
وقال ابن زيد :  هو [ ورق ] (   {[77694]} ) الزرع [ وورق ] (   {[77695]} ) البقل إذا أكلته(   {[77696]} ) البهائم(   {[77697]} ) وراثته(   {[77698]} ) . <br />
قال(   {[77699]} ) ابن عباس :  هو قشر البُر ،  يعني الغلاف الذي يكون فوق(   {[77700]} ) حبة القمح(   {[77701]} ) . <br />
فمعنى :  {  مّاكول } :  قد أكل ما فيه من الحب(   {[77702]} ) . <br />
وروي أن الحجر كان يقع على أحدهم فيخرج كل ما في بطنه [ فيبقى ] (   {[77703]} ) كقشر(   {[77704]} ) الحبة إذا بقا(   {[77705]} ) بعد خروج الجبة منه(   {[77706]} ) ،  فالتقدير :  مأكول ما فيه ،  أو مأكول حبّهُ . <br />
ومن جعله الروث بعينه حذفا ،  [ لأن ] (   {[77707]} ) المعنى :  فجعلهم كورق قد أكلته الدواب وارثته(   {[77708]} ) .
