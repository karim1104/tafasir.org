وقيل :  {  جبل من مسد } ،  أي :   " حبل من نار في رقبتها " (   {[78106]} ) .  وقال(   {[78107]} ) السدي :  المسد :  الليف(   {[78108]} ) . <br />

وقال عكرمة :  {  من مسد }(   {[78112]} ) هي :   " [ الحديدة ] (   {[78113]} ) التي في وسط البكرة " (   {[78114]} ) وروي ذلك أيضا عن مجاهد(   {[78115]} ) . <br />
وقال قتادة :  {  حبل من مسد } :   " [ قلادة ] (   {[78116]} ) من ودع(   {[78117]} ) . <br />

وم جعله بمعنى قد مضى مثل [ مشيها ] (   {[78119]} ) بالنمائم وحملها الشوك(   {[78120]} ) لطريق رسول الله ،  ف {  حمالة الحطب } معرفة يحسن أن [ تكون ] (   {[78121]} ) صفة ل {  امرأته } .  والوقف في هذه السورة على مقدار ما تقدر مما تقدم ذكره من النعت والخبر(   {[78122]} ) .
