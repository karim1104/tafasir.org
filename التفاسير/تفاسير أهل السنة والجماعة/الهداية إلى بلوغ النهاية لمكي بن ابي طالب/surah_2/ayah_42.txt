قوله :  ( وَلاَ تَلْبِسُوا الحَقَّ بِالْبَاطِلِ )(   {[1836]} ) [ 42 ] . <br />
أي :  [ لا تخلطوا الحق بالباطل ،  وهو إظهار ](   {[1837]} ) المنافق الإيمان بلسانه وجحوده(   {[1838]} ) بقلبه .  وقيل :  هو قول(   {[1839]} ) بعض اليهود :   " محمد(   {[1840]} ) نبي مرسل(   {[1841]} ) مبعوث إلا أنه(   {[1842]} ) لم يبعث إلينا "  ، / فيقرون ثم يجحدون(   {[1843]} ) . <br />
وقال مجاهد :   " لا تخلطوا اليهودية والنصرانية بالإسلام " (   {[1844]} ) . <br />
وقال ابن زيد(   {[1845]} ) :   " الحق التوراة ،  والباطل [ ما كتبوه وغيروه ](   {[1846]} ) بأيديهم " (   {[1847]} ) . <br />
قوله :  ( وَتَكْتُمُوا(   {[1848]} ) الْحَقَّ وَأَنْتُمْ تَعْلَمُونَ ) [ 41 ] . <br />
أي تكتمون أمر محمد(   {[1849]} ) وأنتم تعلمون أنه نبي مبعوث صلى الله عليه وسلم إلى الخلق كافة ،  تجدونه مكتوباً عندكم كذلك(   {[1850]} ) في التوراة والإنجيل .
