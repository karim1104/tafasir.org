( يَهْدِي بِهِ )(   {[15307]} ) أي :  بالكتاب ،  ( مَنِ اتَّبَعَ رِضْوَانَهُ ) أي :  يهدي الله بالكتاب ( سُبُلَ السَّلاَمِ ) من اتَّبع رضى(   {[15308]} ) الله عز وجل في قبول ما أتاه من ربه(   {[15309]} ) . <br />
و[ ( السَّلاَمِ ) ](   {[15310]} ) هنا :  اسم الله جلت عظمته ،  أي :  سبل الله(   {[15311]} ) . <br />
وقيل [ السلام ](   {[15312]} ) –هنا- السلامة ،  أي :  طرق السلامة(   {[15313]} ) ،  والرضى(   {[15314]} ) من الله القبول للعبد(   {[15315]} ) .  وقيل :  هو خلاف السخط(   {[15316]} ) . <br />
( وَيُخْرِجُهُم مِّنَ الظُّلُمَاتِ ) أي :  من الكفر ( إِلَى النُّورِ ) أي :  إلى الإسلام ،  ( بِإِذْنِهِ ) أي :  بأمره ،  أي :  [ بأمر ](   {[15317]} ) الله له بذلك(   {[15318]} ) .
