قوله :  ( لَوْلاَ يَنْهاهُمُ الرَّبَّانِيُّونَ وَالاَحْبَارُ ) الآية [ 65 ] . <br />
المعنى :  هلاَّ ينهاهم(   {[17049]} ) عن ذلك الربانيون ،  وهم أئمتهم وعلماؤهم(   {[17050]} ) . <br />
وقيل :  وُلاتهم .  ( والأحبار ) ( و )(   {[17051]} ) هم الفقهاء والعلماء(   {[17052]} ) . <br />
( عَن قَوْلِهِمُ الاِثْمَ ) وهو الكفر(   {[17053]} ) .  وقيل(   {[17054]} ) :  ( وَأَكْلِهِمُ السُّحْتَ ) وهو الرشوة في الأحكام(   {[17055]} ) . <br />
( لَبِيسَ(   {[17056]} ) مَا كَانُوا يَصْنَعُونَ ) أي :  لبئس صنيع الربانيين والأحبار إذ لا ينهون عامتهم عن ذلك(   {[17057]} ) . <br />
وهذه الآية أشد آية وُبِّخ فيها العلماء ،  قال ابن عباس :  ما في القرآن آيةٌ أَشَدُّ توبيخاً(   {[17058]} ) من هذه ،  والمعنى :  أقسم [ لبئس ما ](   {[17059]} ) كانوا يصنعون(   {[17060]} ) . <br />
وقرأ أبو(   {[17061]} ) الجراح ( الرِّبِّيُّون )(   {[17062]} ) وهم [ الجماعات ](   {[17063]} ) ،  مأخوذ من الرِّبَّة ،  والرَّبَّةُ :  الجماعة ،  ونُسب إليها فقيل :  رِبِّيٌّ ،  ثم جُمع فقيل(   {[17064]} ) :  رِبِّيُّونَ(   {[17065]} ) .
