قوله(   {[17436]} ) :  ( وَلَوْ كَانُوا يُومِنُونَ بِاللَّهِ ) الآية [ 83 ] . <br />
المعنى :  ولو كان هؤلاء الذين يتولون الذين كفروا/ ( يُومِنُونَ بِاللَّهِ وَالنَّبِيءِ وَمَا أُنْزِلَ إِلَيْهِ(   {[17437]} ) مَا اتَّخَذُوهُمُ أَوْلِيَاءَ وَلَكِنَّ كَثِيراً مِّنْهُمْ فَاسِقُونَ ) أي :  خارجون(   {[17438]} ) عن طاعة الله(   {[17439]} ) .  وقال مجاهد :  المنافقون(   {[17440]} ) .  ولم يبين(   {[17441]} ) .
