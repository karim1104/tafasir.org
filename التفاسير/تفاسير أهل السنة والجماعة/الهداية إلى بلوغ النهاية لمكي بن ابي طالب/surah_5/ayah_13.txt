قوله(   {[15219]} ) ( فَبِمَا نَقْضِهِم مِّيثَاقَهُمْ لَعَنَّاهُمْ ) الآية [ 14 ] . <br />
( ما ) زائدة مؤكدة للقصة(   {[15220]} ) ،  أو نكرة(   {[15221]} ) .  و( نَقْضِهِم )(   {[15222]} ) بدل منها . <br />
و( قَاسِيَةً ) و( قسِيّة ) لغتان(   {[15223]} ) ،  كعالم وعليم ،  ويؤيد(   {[15224]} ) قراءة(   {[15225]} ) ( قَاسِيَةً ) قوله :  ( فَوَيْلٌ لِلْقَاسِيَةِ قُلُوبُهُم )(   {[15226]} ) .  ويؤيد(   {[15227]} ) قَرَأَةَ ( قسية ) أن  " فعيلاً "  أبلغ –في المدح والذم- من  " فاعل "  ،  فعليم أبلغ من عالم ،  وسميع أبلغ من سامع ،  فالمعنى :  من أجل نقضهم للميثاق(   {[15228]} ) –الذي أخذ عليهم- لعنهم الله ،  أي :  أبعدهم من رحمته(   {[15229]} ) ،  وجعل ( الله(   {[15230]} ) ) قلوبهم قسية(   {[15231]} ) ،  أي :  غليظة [ نابية ](   {[15232]} ) عن الإيمان والتوفيق بطاعة(   {[15233]} ) الله(   {[15234]} ) . <br />
والقاسية والعاتية(   {[15235]} ) :  واحد(   {[15236]} ) . <br />
وقوله :  ( يُحَرِّفُونَ الكَلِمَ عَن مَّوَاضِعِهِ ) أخبر الله عز وجل عن فعلهم أنهم يبدلون ما في التوراة ويكتبون بأيديهم غير الذي أنزل الله(   {[15237]} ) ،  ويقولون لجهالهم(   {[15238]} ) :  هذا كلام الله .  وهذا من صفة القرون(   {[15239]} ) ( التي(   {[15240]} ) ) كانت بعد موسى من اليهود ،  ومنهم من أدرك عصر نبينا ،  فأخبره الله عنهم بما [ يعملون ](   {[15241]} ) ،  وأدخلهم في ذكر من كانوا قبلهم إذ كانوا من أبنائهم(   {[15242]} ) وعلى منهاجهم(   {[15243]} ) . <br />
وقيل :  معنى ( يُحَرِّفُونَ الكَلِمَ عَن مَّوَاضِعِهِ ) يتأولونه على غير تأويله(   {[15244]} ) . <br />
وقيل :  معنى ( [ وَجَعَلْنَا ] قُلُوبَهُمْ قَاسِيَةً )(   {[15245]} ) :  ( أي وصفناهم بهذا )(   {[15246]} ) . <br />
وقوله :   " ( وَنَسُوا حَظّاً مِمَّا ذُكِّرُوا بِهِ ) أي :  تركوا نصيباً مما أُمِرُوا بِهِ " (   {[15247]} ) . <br />
قال الحسن :  تركوا عُرى(   {[15248]} ) دينهم ،  أي :  تركوا ( الأخذ والعمل )(   {[15249]} ) بالتوراة(   {[15250]} ) . <br />
وقوله :  ( وَلاَ تَزَالُ تَطَّلِعُ(   {[15251]} ) عَلَى خَائِنَةٍ مِّنْهُمُ ) أي :  لا تزال يا محمد تطلع من اليهود(   {[15252]} ) –الذين نقضوا الميثاق- على خيانة(   {[15253]} ) ( إِلاَّ قَلِيلاً مِّنْهُمْ ) ،  والخائنة(   {[15254]} ) ،  الخيانة ،  وضع الاسم موضع المصدر(   {[15255]} ) ،  كقولهم  " خاطئة "  في موضع  " خطيئة " (   {[15256]} ) و " قائلة "  في  " قيلولة " (   {[15257]} ) .  وقيل :  ( التقدير )(   {[15258]} ) :  على فرقة خائنة(   {[15259]} ) .  وقيل على رجل خائنة ،  كما يقال :  رجل راوية(   {[15260]} ) ،  يريد لا تزال يا محمد تطلع على مثل الذين هموا بقتلك(   {[15261]} ) . <br />
وقيل :  المعنى على نسمة(   {[15262]} ) خائنة منهم(   {[15263]} ) .  ويجوز أن يكون التقدير :  على فرقةٍ خائنة ،  أو :  على طائفة خائنة(   {[15264]} ) .  وقيل :  الهاء للمبالغة ،  وقيل :  ( المعنى )(   {[15265]} ) :  على خائن منهم(   {[15266]} ) . <br />
( فَاعْفُ عَنْهُمْ وَاصْفَحِ ) :  أمر النبي صلى الله عليه وسلم بالعفو عن هؤلاء الذين أرادوا قتله من اليهود .  وقال قتادة :  هي منسوخة بآية القتال في  " براءة " (   {[15267]} ) .  وقيل :  هي منسوخة بقوله :  ( وَإِمَّا تَخَافَنَّ مِن(   {[15268]} ) قَوْمٍ خِيَانَةً فَانبِذِ اِلَيْهِمْ عَلَى سَوَاءٍ )(   {[15269]} ) .  وقيل :  المعنى :  فاعف عنهم واصفح ما دام/ بينك وبينهم ذمة وعهد(   {[15270]} ) .
