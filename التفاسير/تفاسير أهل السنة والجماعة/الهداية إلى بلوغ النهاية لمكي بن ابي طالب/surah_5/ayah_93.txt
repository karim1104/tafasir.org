قوله :  ( لَيْسَ عَلَى الذِينَ ءَامَنُوا ) الآية [ 95 ] . <br />
المعنى :  في قول ابن عباس وغيره :  - :  أن المؤمنين قالوا لما نزل تحريم الخمر :  ( يا رسول )(   {[17944]} ) الله ،  فكيف بأصحابنا الذين ماتوا وهم يشربون الخمر ؟  ،  فنزلت :  ( لَيْسَ عَلَى الذِينَ ءَامَنُوا وَعَمِلُوا الصَّالِحَاتِ جُنَاحٌ فِيمَا طَعِمُوا ) الآية(   {[17945]} ) . <br />
( إِذَا مَا اتَّقَوا ) أي :  اتقى(   {[17946]} ) اللّهَ الأحياء منهم في اجتناب ما حرم عليهم ،  ( وَّءَامَنُوا ) أي :  وصدقوا الله ورسوله فيما أمرهم(   {[17947]} ) به ،  ( وَعَمِلُوا الصَّالِحَاتِ ) أي :  واكتسبوا من الأعمال ما يرضاه الله ، / ( ثُمَّ اتَّقَوْا وَّ ءَامَنُوا ) أي :   " وَ " (   {[17948]} ) اتقوا محارمه وصدقوا فثبتوا(   {[17949]} ) على ذلك ،  ( ثُمَّ اتَّقَوا وَّأَحْسَنُوا ) أي :  اتقوا الله ،  فدعاهم تقواهم إلى الإحسان ،  وهو العمل بما ( لم )(   {[17950]} ) يفرض عليهم :  من الخير والنوافل(   {[17951]} ) .  فالاتقاء الأول :  اتقاء(   {[17952]} ) تلقي أمر الله وقبوله ،  والثاني :  الاتقاء(   {[17953]} ) بالثبات على الاتقاء الأول وترك التبديل ،  والاتقاء الثالث :  الاتقاء بالإحسان والتقرب بالنوافل(   {[17954]} ) . <br />
فهذه الآية نزلت –في قول الجميع- فيمن مات منهم وهو يشربها ،  أُعلِموا أنه لا جناح عليهم(   {[17955]} ) .  وقال جابر بن عبد الله(   {[17956]} ) :  صبح ناس غداة أُحد الخمر فقتلوا من يومهم جميعاً شهداء ،  وذلك قبل تحريمها ،  يريد :  فنزلت الآية فيهم(   {[17957]} ) . <br />
وقيل :  نزلت فيما أكلوا من الحرام بالميسر و( ما شربوا )(   {[17958]} ) من الخمر فأُعلِموا أنه لا جناح عليهم في ذلك إذا ما اتقوا فيما يستقبلون(   {[17959]} ) . <br />
وقيل :  معنى ( إِذَا مَا اتَّقَوا وَّءَامَنُوا ) أي :  اتقوا شرب(   {[17960]} ) الخمر ،  وآمنوا بتحريمها " (   {[17961]} ) ( ثُمَّ ( اتَّقَوا وَّءَامَنُوا ) ) أي : (   {[17962]} ) :  اتقوا الكبائر وازدادوا(   {[17963]} ) إيماناً ،   " ( ثُمَّ اتَّقَوْا ) "  أي :  اتقوا الصغائر ،  ( وَّأَحْسَنُوا ) بالنوافل(   {[17964]} ) . <br />
وقيل :  ( إِذَا مَا اتَّقَوْا ) الكفر(   {[17965]} ) ،  ( ثُمَّ اتَّقَوْا ) الكبائر ،  ( ثُمَّ اتَّقَوْا ) الصغائر(   {[17966]} ) . <br />
وقيل :  [ معنى هذا :  ( إِذَا مَا  اتَّقَوْا ) فيما مضى :  على إضمار  " كان "  مع  " إذا "  ،  ( ثُمَّ اتَّقَوْا ) في الحال التي هم فيها ،  ( ثُمَّ اتَّقَوْا ) فيما يستقبلون(   {[17967]} ) . <br />
