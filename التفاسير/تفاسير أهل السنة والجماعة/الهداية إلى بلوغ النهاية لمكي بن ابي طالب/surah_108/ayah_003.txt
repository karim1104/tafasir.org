ثم قال تعالى :  {  إن شانئك هو الأبتر } أي :  إن مبغضك يا محمد وعدوك هو الأبتر ،  أي هو الذي لا عقب له(   {[77910]} ) ،  عني بذلك العاصي بن وائل السهمي(   {[77911]} ) . <br />
وقال قتادة :  {  هو الأبتر } أي :  هو الحقير الذليل(   {[77912]} ) .  قال ابن زيد :  قال رجل :  إنما(   {[77913]} ) محمد أبتر ليس له –كما ترون- عقب ،  فأنزل الله :  {  إن شانئك هو الأبتر }(   {[77914]} ) . <br />
( وقيل :  نزلت في عبقة بن أبي معيط(   {[77915]} ) ،  كان يقول :  إنه لا يبقى لنبي الله صلى الله عليه وسلم  ولد وهو أبتر فأنزل الله جل ذكره :  {  إن شانئك هو الأبتر }(   {[77916]} ) وقال ابن عباس :   " لما قدم كعب ابن الأشرف(   {[77917]} ) مكة أتوه –يعني قريشا- فقالوا له :  نحن أهل السَّدانة والسقاية ،  وأنت سيد أهل المدينة ،  فنحن خير أم(   {[77918]} ) هذا [ الصُّبُور ](   {[77919]} ) [ المنتبر ](   {[77920]} ) من قومه ،  ( يزعم أنه )(   {[77921]} ) .  [ خير ](   {[77922]} ) منا ،  فقال :  بل أنتم خير منه ،  ونزلت(   {[77923]} ) :  {  إن شانئك هو الأبتر } قال :  ونزلت(   {[77924]} ) عليه {  ألم تر الذين أوتوا نصيبا من الكتاب يومنون بالجبت والطااغوت } إلى قوله :  {  نصيرا }(   {[77925]} ) . <br />
عن ابن عباس أنها نزلت في أبي جهل قال :  والمعنى أن عدوك أبا جهل هو الأبتر(   {[77926]} ) .
