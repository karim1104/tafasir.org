قال ابن عباس : ( أكلا لما ) أي : سفا {[75554]} وجما {[75555]} : شديدا {[75556]} .<br />
وقال الحسن : معنى ( لما ) أي : يخلطون الحلال بالحرام {[75557]}<br />
وقال ابن زيد : ( ويا كلون التراث أكلا لما ) أي : تأكلون كل شيء تجدونه من الميراث وغيره ، لا تسألون عنه ، يأكل الذي له والذي لصاحبه {[75558]} .<br />
[ قال ] {[75559]} : كانوا لا [ يورثون ] {[75560]} النساء ولا [ يورثون ] {[75561]} الصغار ، وقرأ ( ويستفتونك في النساء قل الله يفتيكم فيهم ، وما يتلى عليكم فيي يتامى النساء ) إلى قوله/ ( عليما ) {[75562]} .<br />
فقوله {[75563]} : ( والمستضعفين من الولدان ) {[75564]} يعني : يستضعفوهم [ فلا يؤتونهم ] {[75565]} .<br />
قال : وقوله : ( وتحبون المال حبا جما ) أي : وتحبون جمع المال {[75566]} واقتناءه حبا كثيرا {[75567]} .<br />
