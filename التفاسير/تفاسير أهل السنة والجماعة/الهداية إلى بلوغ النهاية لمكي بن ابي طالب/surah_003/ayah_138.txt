قوله :  ( هَذَا بَيَانٌ لِلنَّاسِ ) الآية [ 138 ] . <br />
وقال الحسن :  ( هَذَا ) إشارة إلى القرآن ،  وقاله قتادة(   {[10906]} ) . <br />
وقال الربيع :  ( هَذَا بَيَانٌ لِلنَّاسِ ) عامة وهو القرآن ( وَهُدىً وَمَوْعِظَةٌ لِلْمُتَّقِينَ ) خاصة(   {[10907]} ) . <br />
وقال ابن اسحاق :  ( هذا ) إشارة إلى قوله ( قَدْ خَلَتْ ) الآية(   {[10908]} ) . <br />
وقال الشعبي :  ( وَهُدىً ) من الضلال ( وَمَوْعِظَةٌ ) من الجهل وذلك لمن اتقى المحارم(   {[10909]} ) .
