ثم قال :  {  يصلح لكم أعمالكم } أي :  يوفقكم لصالح الأعمال . <br />
{  ويغفر لكم ذنوبكم } أي :  لا يعذبكم عليها بعد توبتكم منها . <br />
{  ومن يطع الله ورسوله } أي :  فيما أمر به ونهي عنه . <br />
{  فقد فاز } أي :  نجا وظفر بالكرامة . <br />
{  فوزا عظيما } أي :  نجا نجاة عظيمة . <br />
