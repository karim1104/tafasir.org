قوله تعالى :  {  قالوا سمعنا فتى يذكرهم }[ 60 ] إلى قوله :  {  فجعلناهم الأخسرين }[ 69 ] . <br />
أي :  قال الذين سمعوه [ حين ]{[46046]} قال :  {  وتالله لأكيدن أصنامكم بعد أن تولوا مدبرين } ،  {  سمعنا فتى يذكرهم } أي :  يذكرهم بسوء . <br />
وقيل{[46047]} :  يذكرهم :  يسبهم ويعيبهم . <br />
{  يقال له إبراهيم } أي :  يقال له يا إبراهيم . <br />
