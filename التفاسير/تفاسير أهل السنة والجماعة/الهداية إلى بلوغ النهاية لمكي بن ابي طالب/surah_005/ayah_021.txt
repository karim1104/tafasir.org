قوله :  ( يَا قَوْمِ ادْخُلُوا الاَرْضَ المُقَدَّسَةَ ) الآية [ 23 ] . <br />
قال ابن عباس :  هي فلسطين والأردُنُّ(   {[15408]} ) ( و )(   {[15409]} ) عنه وعن مجاهد :  الأرض المقدسة :  الطور وما حوله(   {[15410]} ) أمرهم موسى بدخولها عن أمر الله لهم(   {[15411]} ) .  وقيل :  هي الشام ،  قاله قتادة(   {[15412]} ) . <br />
وقيل :  هي دمشق ( و )(   {[15413]} ) فلسطين(   {[15414]} ) ،  ( و )(   {[15415]} ) قال مقاتل(   {[15416]} ) .  هي أريحا(   {[15417]} ) أرض الأردن . <br />
والمقدسة :  المطهرة(   {[15418]} )(   {[15419]} ) ،  وقيل :  المباركة(   {[15420]} ) . <br />
وقوله :  ( التِي كَتَبَ اللَّهُ لَكُمْ ) أي :  التي كتبها الله لبني إسرائيل ،  وقد سكنها بنو إسرائيل ولم يسكنها(   {[15421]} ) هؤلاء الذين خاطبهم موسى صلى الله عليه وسلم لقوله ( فَإِنَّهَا مُحَرَّمَةٌ عَلَيْهِمُ(   {[15422]} ) ) ،  ولم يعن(   {[15423]} ) موسى صلى الله عليه وسلم أن الله كتبها للذين(   {[15424]} ) خاطبهم ،  وإنما عنى(   {[15425]} ) أن الله تعالى كتبها لبني إسرائيل(   {[15426]} ) وقيل :  معناه :  التي وهب(   {[15427]} ) الله لكم(   {[15428]} ) وأعلم بها أباكم(   {[15429]} ) إبراهيم(   {[15430]} ) . <br />
وقال السدي :  التي أمركم الله بدخولها(   {[15431]} ) . <br />
( وَلاَ تَرْتَدُّوا عَلَى أَدْبَارِكُمْ ) أي :  امضوا لأمر الله في قتالهم ولا ترجعوا القَهْقَري(   {[15432]} ) ،  ( فَتَنقَلِبُوا خَاسِرِينَ ) لِنكولكم عن قتال عدوكم الذي أمركم الله به(   {[15433]} ) .
