قوله :  {  ما قلت لهم إلا ما أمرتني به } الآية [ 119 ] . <br />
قوله :  {  أن اعبدوا الله{[18990]} } :  ( أن ) مفسرة{[18991]} لا موضع لها من الإعراب ،  بمنزلة ( أن امشوا ){[18992]} ،  وقيل :  هي في موضع نصب على معنى :  ما ذكرت لهم إلا عبادة الله{[18993]} . <br />
قوله :  {  ما دمت فيهم } :  ( ما ) في موضع نصب ،  {  و }{[18994]} المعنى :  مدة{[18995]} دوامي{[18996]} ،  فهو ظرفٌ عمل فيه {  شهيدا }{[18997]} أي{  و{[18998]} كنت عليهم شهيدا{[18999]} } ،  {  ما دمت } أي :  مدة{[19000]} دوامي{[19001]} . <br />
{  فلما توفيتني } أي :  قبضتني{[19002]} إليك ،  {  كنت أنت الرقيب عليهم{[19003]} } أي :  الحفيظ عليهم{[19004]} .
