قوله تعالى :  {  والعاديات ضبحا } إلى آخر السورة . <br />
قال ابن عباس ومجاهد :  هي الخيل تعدو(   {[77121]} ) وهي [ تحمعهم ](   {[77122]} ) . <br />
وقال علب بن أبي طالب عليه السلام :  هي الإبل تغدو(   {[77123]} ) من عرفة إلى المزدلفة ومن مزدلفة على منى(   {[77124]} ) . <br />
وقال محمد بن كعب القرظي :   " العاديات ضبحا "  :  الدفع من غرفة ،  {  فالماوريت قدحا } إلى المزدلفة ،  {  فالمغيرت صبحا } تغير حين تصبح ،  {  تغير حين تصبح ،  فأثرن به ،  نفعا فوسطن به جمعا } هي يوم منى(   {[77125]} ) . <br />
[ وممن ](   {[77126]} ) قال هي الإبل أيضا :  ابن مسعود وإبراهيم وعبيد بن [ عمير ](   {[77127]} ) . <br />
وقال عكرمة :   " والعاديات ضبحا "  الفرس يصبح إذا جرى(   {[77128]} ) . <br />
قال عطاء الخرساني(   {[77129]} ) :   " ليس شيء من الدواب يضبح(   {[77130]} ) غير الكلب والفر(   {[77131]} ) . <br />
وقال(   {[77132]} ) قتادة ومجاهد :  هي الخيل تضبح(   {[77133]} ) .  وهو قول سالم(   {[77134]} ) والضحاك(   {[77135]} ) .  وهو اختيار الطبرين قال :   " لأن الإبل ( لا )(   {[77136]} ) تضبح ،  إنما تضبح الخيل(   {[77137]} ) . <br />
وقال أبو صالح :  الضبح من الخيل [ الحمحمة ](   {[77138]} ) ،  ومن الإبل التنفس(   {[77139]} ) . <br />
قال(   {[77140]} ) قتادة :  [ تضبح ](   {[77141]} ) إذا عدت(   {[77142]} ) ،  أي [ تحمحم ](   {[77143]} ) . <br />
قال الفراء :  الضبح صوت أنفاس الخيل إذا عدت(   {[77144]} ) . <br />
