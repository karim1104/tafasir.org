881- البدن عند مالك من الإبل وحدها ،  والذكور والإناث بدن كلها ،  لقوله تعالى :  {  والبدن جعلناها لكم من شعائر الله } ولم يفصل .  ( الذخيرة :  3/360 ) . <br />
882- قوله تعالى :  {  فاذكروا اسم الله عليها صواف } .  قال مالك :   " تصف أيدي البدن بالقيود{[856]} لقوله تعالى :  {  فاذكروا اسم الله عليها صواف } .  ( نفسه :  3/365 ) . <br />
883- قوله تعالى :  {  فإذا وجبت جنوبها } أي :  سقطت .  ( نفسه :  2/365 و4/139 ) . <br />
884- قوله تعالى :  {  فكلوا منها وأطعموا القانع والمعتر } .  القانع :  الفقير{[857]} .  المعتر :  الزائر{[858]} .  ( نفسه :  4/158 ) .
