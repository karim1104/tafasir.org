1216- قوله تعالى :  {  فإن علمتموهن مؤمنات } يجوز إطلاق العلم ويراد به الظن مجازا كقوله تعالى :  {  فإن علمتموهن مؤمنات } أي :  ظننتموهن .  ( الفروق :  3/61 ) . <br />
1217- قوله تعالى :  {  فلا ترجعوهن إلى الكفار } يرد من جاء مسلما إلى الكفار وفاء بالعهد من الرجال دون النساء لقوله تعالى :  {  فلا ترجعوهن إلى الكفار } ولأن ردتهن أقرب ،  وقيل :  يمنع الجميع لحرمة الإسلام .  ( الذخيرة :  13/449 ) . <br />
1218- قوله تعالى :  {  ولا تمسكوا بعصم الكوافر } أي :  من كفر من أزواجكم .  ( نفسه :  4/335 ) .
