وقوله : { أَن تَزُولاَ } أي : لئلا تزولا ومعنى الزوال هنا : التنقلُ من مكانها ،   والسُّقُوطُ من عُلُوَّهَا .   وعن ابن مسعودٍ أن السَّماءَ لا تدورُ وإنما تَجْرِي فيها الكواكبُ .  <br />
وقوله تعالى : { وَلَئِن زَالَتَا } قيل : أراد يوم القيامة .   وقوله تعالى : { إِنْ أَمْسَكَهُمَا مِنْ أَحَدٍ مِّن بَعْدِهِ } أي : من بعد تركه الإمساك .  <br />
قال ( ص ) : { إِن أَمْسَكَهُمَا } : ( إن ) : نافية بمعنى ،   ما وأمسَك : جواب القسم المقدَّرِ قبل اللام الموطئة في { لَئِنْ } ،   وهو بمعنى : يمسك ؛ لدخول أن الشرطية ؛ كقوله تعالى : { وَلَئِنْ أَتَيْتَ الذين أُوتُواْ الكتاب بِكُلِّ آيَةٍ مَّا تَبِعُواْ قِبْلَتَكَ } [ البقرة : 145 ] أي : ما يتبعون وكقوله : { وَلَئِنْ أَرْسَلْنَا رِيحًا } إلى قَوْلِهِ : { لَّظَلُّواْ مِن بَعْدِهِ } [ الروم : 51 ] أي : لَيَظُلْونَ ،   وحذف جواب إن في هذه المواضع لدلالةِ جوابِ القَسَمِ عليه .  <br />
وقوله : { مِنْ إِحْدَى } { مِن } : زائدة لتأكيد الاستغراق انتهى .
