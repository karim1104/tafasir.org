قال الثعلبِيُّ : { ومِن بَيْنِ أَيْدِيهِمْ وَمِنْ خَلْفِهِمْ } يعني : قبلهم وبعدهم ،   وقامت الحُجَّةُ عليهم في أَنَّ الرسالة والنذارة عمتهم خبراً ومباشرة ،   وقال ( ع ) : قوله : { وَمِنْ خَلْفِهِمْ } أي : جاءهم رسول بعد اكتمال أعمارهم وبعد تَقَدُّمِ وجودهم في الزَّمَنِ ،   فلذلك قال : { وَمِنْ خَلْفِهِمْ } ولا يتوجه أنْ يجعل { وَمِنْ خَلْفِهِمْ } عبارة عَمَّا أتى بعدهم ؛ لأنَّ ذلك لا يلحقهم منه تقصير .  <br />
( ت ) : وما تقدم للثعلبيِّ وغيره أَحْسَنُ ؛ لأَنَّ مقصد الآية اتصال النذارة بهم وبمن قبلهم وبمن بعدهم ؛ إذ ما من أُمَّةٍ إلاَّ وفيها نذير ،   وكما قال تعالى : { رُسُلَنَا تَتْرَا } .  <br />
