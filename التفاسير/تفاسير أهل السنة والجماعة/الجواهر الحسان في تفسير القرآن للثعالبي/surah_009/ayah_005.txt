قوله سبحانه : { فَإِذَا انسلخ الأشهر الحرم } : الانسلاخ : خروجُ الشيء عن الشيء المتلبِّس به ؛ كانسلاخ الشاة عن الجِلْدِ ،   فشبه انصرام الأشهر بذلك .  <br />
وقوله سبحانه : { فاقتلوا المشركين حَيْثُ وَجَدتُّمُوهُمْ } .  <br />
قال ابن زَيْد : هذه الآية ،   وقوله سبحانه : { فَإِمَّا مَنًّا بَعْدُ وَإِمَّا فِدَاءً } [ محمد : 4 ] : هما مُحْكَمَتان ؛ أي : ليستْ إِحداهما بناسخةٍ للأخرى .  <br />
قال ( ع ) : هذا هو الصواب .  <br />
وقوله : { وَخُذُوهُمْ } معناه : الأسْر .  <br />
وقوله : { كُلَّ مَرْصَدٍ } : معناه : مواضع الغرَّة ؛ حيث يرصدون ونصب { كُلَّ } على الظرف أو بإسقاط الخافِضِ ،   التقدير : في كُلِّ مَرْصَد .  <br />
وقوله : { فَإِن تَابُوا } ،   أي : عن الكُفْر .
