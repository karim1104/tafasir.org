وقوله : { أهدى مِنْهُمَا } [ القصص : 49 ] .  <br />
قال الثعلبي : يعني : أهدى من كتابِ محمدٍ صلى الله عليه وسلم وكتابِ موسى انتهى .  <br />
( ت ) : ويحتملُ أنْ يكونَ الضميرُ في { يَكْفُرُوا } لقريشٍ كما أشار إليه الثعلبيُّ ،   وكذا في { قَالُوا } لقريشٍ عندَه .   و{ ساحران } يريدونَ موسى ومحمداً عليهما السلام وهو ظاهرُ قولِهم : { إِنَا بِكُلٍّ كَافِرُونَ } [ القصص : 48 ] لأن اليهودَ لا يقولون ذلك في موسى في عصر نبينا محمد عليه السلام ،  <br />
ويُبيِّن هذَا كلَّه قولُه تعالى : { فَإِن لَّمْ يَسْتَجِيبُوا لَكَ } [ القصص : 50 ] .  <br />
فإنَّ ظاهرَ الآيةِ أنَّ المرادَ قريشٌ وعَلَى هذا كله مَرّ الثَّعْلَبيُّ انتهى .
