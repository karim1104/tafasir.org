قوله تعالى : { تَبَارَكَ الذي بِيَدِهِ الملك } { تبارك } مِنَ البركةِ وهي التَزَيُّدِ في الخيراتِ ،   الثعلبي : { تَبَارَكَ الذي بِيَدِهِ الملك } أي : تَعَالَى وتَعَاظَمَ وَقَالَ الحسنُ : تَقَدَّسَ الذي بيده الملكُ في الدنيا والآخرة ،   وقال ابن عباس : { بِيَدِهِ الملك } : يُعِزُّ مَنْ يَشاء ويذل من يشاء .   انتهى .  <br />
