وقوله تعالى : { مِّمَّا خطيئاتهم أُغْرِقُواْ } ابتداء إخْبَارٍ مِنَ اللَّهِ تعالى لمحمَّد عليه السلام ( وما ) في قوله : { مِّمَّا } : زائدةٌ فكأَنه قال : مِنْ خطِيئَاتِهِم ،   وهي لابتداءِ الغَايَةِ ،   ( ص ) : { مِّمَّا خطيئاتهم } من للسببِ ،   ( ع ) : لابتداءِ الغايةِ ( وما ) زائِدة للتَوْكيد ،   انتهى .   { فَأُدْخِلُواْ نَاراً } يعني جَهَنَّمَ .  <br />
