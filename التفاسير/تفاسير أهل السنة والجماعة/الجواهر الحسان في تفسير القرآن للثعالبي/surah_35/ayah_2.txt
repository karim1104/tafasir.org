وَقَوْلهُ تَعَالَى : { مَّا يَفْتَحِ الله } { ما } شَرْطٌ و{ يُفْتَحْ } مَجْزُومٌ بِالشَّرْطِ .  <br />
وقوله : { مِن رَّحْمَةِ } عَامٌ فِي كُلِّ خَيْرٍ يُعْطِيهِ اللّهُ تَعَالَى لِعِبَادِهِ .  <br />
وَقَوْلُه : { مِن بَعْدِهِ } فيه حَذْفٌ مُضَافٍ ،   أي : مِنْ بَعْدِ إمْسَاكِهِ وَمِنْ هَذِهِ الآيةِ سَمَّتِ الصُّوفِيَّةُ مَا تُعْطَاهُ مِنَ الأَمْوَالِ وَالمَطَاعِمِ وَغَيْرِ ذَلِكَ «الفُتُوحَاتِ » .  <br />
