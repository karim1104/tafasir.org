وقوله تعالى : { فَكَيْفَ تَتَّقُونَ } معناه : كَيْفَ تَجْعَلُونَ وِقَايةً لأنفسِكم ،   و{ يَوْماً } مفعولٌ ب { تَتَّقُونَ } ،   وقِيلَ : هو مفعولٌ ب { كَفَرْتُمْ } ويكونُ { كَفَرْتُمْ } بمعنى : جَحَدْتم ،   ف { تَتَّقُونَ } على هذا منَ التقوى ،   أي : تتقونَ عذابَ اللَّهِ ،   ويجوزُ أن يكونَ { يَوْماً } ظرفاً والمعنى : تتقونَ عِقَابَ اللَّه يوماً ،   وعبارةُ الثعلبي : { فَكَيْفَ تَتَّقُونَ إِن كَفَرْتُمْ } أي كيف تَتَحَصَّنُونَ من عذابِ يَوْمٍ يَشِيبُ فيه الطفلُ لهولِه إنْ كفرتُم ،   ثم ذَكَرَ نحو ما تقدم ،   انتهى .   وحَكَى ( ص ) : ،   عن بعضِ الناسِ جَوازَ أنْ يكونَ { يَوْماً } ظرفَاً أي : فكيفَ لَكُمْ بالتقوَى في يومِ القيامَةِ إنْ كفرتم في الدنيا ،   ( ت ) : وهَذَا هُوَ مُرَادُ ( ع ) ،   قَالَ أبو حيان : و{ شِيباً } مفعولٌ ثانٍ ل { يَجْعَلُ } وهُو جَمْع أشْيَب ،   انتهى .  <br />
