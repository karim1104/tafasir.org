وقوله عز وجل : { وَمَا لَهُمْ أَلاَّ يُعَذِّبَهُمُ الله } [ الأنفال : 34 ] .  <br />
تُوعُّد بعذاب الدنيا ،   والضميرُ في قوله : { أَوْلِيَاؤُهُ } عائدٌ على { اللَّه } سبحانه ،   أو على { المسجدِ الحرامِ } ،   كلُّ ذلك جيِّد ،   ورُوِيَ الأخير عن الحسن ،   وقال الطبريُّ : عن الحسنِ بْنِ أَبي الحسنِ أن قوله سبحانه : { وَمَا لَهُمْ أَلاَّ يُعَذِّبَهُمُ الله } ناسخ لقوله : { وَمَا كَانَ الله مُعَذِّبَهُمْ وَهُمْ يَسْتَغْفِرُونَ } [ الأنفال : 33 ] .  <br />
قال ( ع ) : وفيه نظر ؛ لأنه خبر لا يدخلُهُ نَسْخٌ .
