وقوله سبحانه : { وَإِذَا رَءَا الذين أَشْرَكُوا شُرَكَاءَهُمْ } [ النحل : 86 ] .   أي : إِذا رأَوْهم بأبصارِهِمْ ،   { قَالُوا رَبَّنَا هَؤُلاءِ شُرَكَاؤُنَا } ،   كأنهم أرادوا بهذه المقالة تذنيبَ المَعْبُودين .  <br />
وقوله سبحانه : { فَألْقَوا إِلَيْهِمُ القول } ،   الضميرُ في : { أَلْقَوا } ،   للمعبودينَ أنطقهم اللَّه بتكذيب المُشْركين ،   وقد قال سبحانه في آية أخرى : { فَزَيَّلْنَا بَيْنَهُمْ وَقَالَ شُرَكَاؤُهُم مَّا كُنتُمْ إِيَّانَا تَعْبُدُونَ } [ يونس : 28 ] ،   انظر تفسيرها في سورة يونس وغيرها .
