وقوله سبحانه : { إِنَّمَا يَفْتَرِي الكذب } [ النحل : 105 ] .  <br />
بمعنى : إنما يكْذِبُ ،   وهذه مقاومةٌ للذين قالوا للنبيِّ صلى الله عليه وسلم : { أَنتَ مُفْتَرٍ بل } [ النحل :101 ] ،   ومَنْ في قوله : { مَن كَفَرَ } [ النحل : 106 ] ،   بدلٌ مِنْ قوله : { مطمئن } ،   فروي : أن قوله سبحانه : { وأولئك هُمُ الكاذبون } [ النحل : 105 ] ،   يراد به : مِقْيَسُ بنُ ضَبَابَةَ وأشباهه ممَّن كان آمن ،   ثم ارتد باختياره مِنْ غيرِ إِكراه .
