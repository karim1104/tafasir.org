وقوله سبحانه : { قُلْ أَرَءَيْتُم مَّا أَنزَلَ الله لَكُمْ مِّن رِّزْقٍ فَجَعَلْتُم مِّنْهُ حَرَامًا وَحَلاَلاً } [ يونس : 59 ] .  <br />
قال ( ص ) : { أَرَأيْتُم } : مضمَّن معنى : أَخْبِروني ،   و«ما » موصولة .  <br />
قال ( ع ) : ( هذه المخاطبة لكفَّار العرب الذين جعلوا البحائِرَ والسَّوائب وغَيْرَ ذلك ) ،   وقوله : { أَنَزلَ } : لفظةً فيها تجوُّز .
