وقوله تعالى : { نِّصْفَهُ } يحتملُ : أن يكونَ بَدَلاً من قوله قليلاً ،   ( ص ) : { إِلاَّ قَلِيلاً } استثناءٌ من الليلِ ،   و{ نِّصْفَهُ } قيل : بَدَلٌ من الليل وعلى هذا يكون استثناءُ { إِلاَّ قَلِيلاً } منه ،   أي : قم نصفَ الليل إلا قليلاً منه ،   والضميرُ في قوله : { أَوِ انقص مِنْهُ } .  <br />
