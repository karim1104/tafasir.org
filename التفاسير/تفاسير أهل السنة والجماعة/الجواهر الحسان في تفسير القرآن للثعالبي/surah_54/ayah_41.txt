قوله تعالى : { وَلَقَدْ جَاء آلَ فِرْعَوْنَ } يعني القبط { النُّذُرُ } فيهم قولان :<br />
أحدهما : أنه جمع نذير ،   وهي الآيات التي أنذرهم بها موسى .  <br />
والثاني : أن النذر بمعنى الإنذار ،   وقد بيناه آنفا ،   { فَأَخَذْنَاهُمْ } بالعذاب { أَخْذَ عِزِيزٍ } أي : غالب في انتقامه { مُّقْتَدِرٍ } قادر على هلاكهم .  <br />
