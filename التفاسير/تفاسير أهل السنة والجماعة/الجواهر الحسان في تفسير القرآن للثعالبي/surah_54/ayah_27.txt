قوله تعالى : { إِنَّا مُرْسِلُواْ النَّاقَةِ } وذلك أنهم سألوا صالحا أن يظهر لهم ناقة من صخرة ،   فقال الله تعالى : { إنا مرسلو الناقة } أي : مخرجوها كما أرادوا { فِتْنَةً لَّهُمْ } أي : محنة واختبارا { فَارْتَقِبْهُمْ } أي : فانتظر ما هم صانعون { وَاصْطَبِرْ } على ما يصيبك من الأذى .  <br />
