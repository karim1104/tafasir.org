و{ الذين حُمِّلُواْ التوراة } هم بنو إسرائيل الأحبارُ المعاصرون للنبي صلى الله عليه وسلم ،   و{ حُمِّلُواْ } معناه كُلِّفُوا القيامَ بأوامرِها ونواهيها ،   فهذا كما حُمِّلَ الإنسانُ الأمانَةَ ،   وذكر تعالى أنهم { لم يحملوها } أي : لم يُطِيعُوا أمْرَها ويَقِفُوا عند حدودِها حين كذَّبُوا نبيَّه محمداً صلى الله عليه وسلم ،   والتوراةُ تنطقُ بنبوتهِ ،   فكان كلُّ حَبْرٍ لم ينتَفِعْ بما حُمِّلَ كَمَثَلِ حِمَارٍ عليه أسفارٌ ،   وفي مصحف ابن مسعود ( كَمَثَلِ حِمَارٍ بِغَيْرِ تعريفٍ ) ،   و( السِّفْرُ ) الكتَابُ المجتمعُ الأوراقِ منضدة .  <br />
وقوله : { بِئْسَ مَثَلُ القوم } التقدير : بِئْسَ المثلُ مثلُ القومِ { الذين كذبوا بآياتِ اللَّه } ،   ( ص ) : وَرُدَّ بأَنَّ فيه حدفَ الفاعلِ ولا يجوزُ ،   والظاهرُ أنَّ { مَثَلُ القوم } فَاعِلُ { بِئْسَ } ،   و{ الذين كَذَّبُواْ } هو المخصوصُ بالذَّمِّ على حذف مضافٍ ؛ أي : مثَلُ الذينَ كذَّبوا ،   انتهى .  <br />
