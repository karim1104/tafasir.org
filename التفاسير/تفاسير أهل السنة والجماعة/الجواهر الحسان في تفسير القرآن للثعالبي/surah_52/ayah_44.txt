وقوله : { وَإِن يَرَوْاْ كِسْفاً } أي : قطعةً يقولون لشدة معاندتهم هذا { سحاب مَّرْكُومٌ } : بعضُه على بعض ،   وهذا جوابٌ لقولهم : { فَأَسْقِطْ عَلَيْنَا كِسَفاً مِّنَ السماء } وقولهم : { أَوْ تُسْقِطَ السماء كَمَا زَعَمْتَ عَلَيْنَا كِسَفًا } يقول : لو فعلنا هذا بهم لما آمنوا ،   ولقالوا : سحاب مركوم .  <br />
