وقوله تعالى : { وَجَعَلُواْ بَيْنَهُ وَبَيْنَ الجنة نَسَباً } : { الجِنَّةُ } هنا : قيل : همُ الملائِكَةُ : لأنها مُسْتَجِنَّةٌ ،   أي : مُسْتَتِرَةٌ ،   وقيل : الجِنَّةُ همُ الشياطينُ ،   والضميرُ في { وَجَعَلُواْ } لفِرْقَةٍ من كفارِ قريشٍ والعَرَبِ .  <br />
{ وَلَقَدْ عَلِمَتِ الجنة إِنَّهُمْ لَمُحْضَرُونَ } أي : سَتَحْضُرُ أَمْرَ اللَّهِ وثوابَه وعقابَه ،   ثم نَزَّهَ تعالى نفسَه عما يصِفُهُ الكفرةُ ،   ومِنْ هَذا استثنى عبادَه المُخْلَصِينَ ؛ لأنّهُمْ يَصِفُونَهُ بِصِفَاتِهِ العُلاَ ،   وقالت فرقة : اسْتَثْنَاهُمْ من قولِه : { لَمُحْضَرُونَ } ،   وعبارةُ الثعلبي : { وَلَقَدْ عَلِمَتِ الجنة } أي : الملائكة أنَّ قائِلي هذه المقالةِ مِنَ الكفرةِ ،   { لَمُحْضَرُونَ } في النَّارِ ،   وقيل للحسابِ ،   والأولُ أوْلَى لأنَّ الإحْضَارَ متَى جَاء في هذه الصُّورة عُنِيَ بهِ العذابُ { إِلاَّ عِبَادَ الله المخلصين } فإنَّهُمْ ناجُونَ مِنَ النَّار ،   انتهى ،   وفي البخاريِّ { لَمُحْضَرُونَ } أي : سيُحْضَرُونَ للحِسَابِ ،   انتهى .  <br />
