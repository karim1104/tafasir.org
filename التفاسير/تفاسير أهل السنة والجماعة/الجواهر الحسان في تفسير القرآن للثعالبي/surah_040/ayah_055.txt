وقوله تعالى : { واستغفر لِذَنبِكَ وَسَبِّحْ بِحَمْدِ رَبِّكَ بالعشي والإبكار } قال الطبريُّ : { الإبكار } : من طلوع الفَجْرِ إلى طلُوعِ الشَّمْسِ ،   وقيلَ : مِنْ طلوعِ الشمْسِ إلى ارْتِفَاعِ الضحى ،   وقال الحَسَنُ : { بالعشى } يريدُ صلاةَ العَصْرِ ،   { والإبكار } يريدُ صلاةَ الصُّبْحِ .  <br />
