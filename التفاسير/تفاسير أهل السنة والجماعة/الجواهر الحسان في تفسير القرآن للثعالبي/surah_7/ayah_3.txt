قوله سبحانه : { اتبعوا مَا أُنزِلَ إِلَيْكُم مِنْ رَّبِّكُمْ } [ الأعراف :3 ] .  <br />
أَمْرٌ يعمُّ جَمِيعَ الناس ،   { وَلاَ تَتَّبِعُواْ مِن دُونِهِ } ،   أي : من دون ربَكُمُ { أَوْلِيَاءَ } يريد : كل مَنْ عُبِدَ ،   واتبعَ من دون اللَّه ،   { وقليلاً } : نعت لمصدر نصب بفعل مُضْمَر .  <br />
وقال مكي : هو منصوب بالفِعْلِ الذي بَعْدَهُ ،   و{ ما } في قوله : { مَّا تَذَكَّرُونَ } مصدرية .
