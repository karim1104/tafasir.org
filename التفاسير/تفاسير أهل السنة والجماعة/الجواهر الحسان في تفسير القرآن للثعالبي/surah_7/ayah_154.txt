قرأ معاوية بنُ قُرَّة { وَلَمَّا سَكَنَ عَنْ مُوسَى الغَضَبُ }[ الأعراف :154 ] قال أبو حَيَّان : واللام في { لِرَبِّهِمْ يَرْهَبُونَ } مُقَوِّية لوصولِ الفعْلِ ،   وهو { يَرْهَبُونَ } إلى مفعوله المتقدِّم .  <br />
وقال الكوفيُّون : زائدةٌ ،   وقال الأخفشُ : لام المفعول له ،   أي : لأجْلِ ربِّهم ،   انتهى .  <br />
قلْتُ : قال ابنُ هِشَامٍ في «المُغْني » : ولام التقْويَةِ هي المَزِيدَةُ لتقويةٍ عاملٍ ضَعُفَ ،   إِما لتأخيرٍ ،   نحو : { لِرَبِّهِمْ يَرْهَبُونَ } ،   و{ إِن كُنتُمْ لِلرُّءْيَا تَعْبُرُونَ } [ يوسف : 43 ] أو لكَوْنِهِ فرعاً في العمل ،   نحو : { مُصَدِّقاً لِّمَا مَعَهُمْ } [ البقرة : 91 ] { فَعَّالٌ لِّمَا يُرِيدُ } [ هود :107 ] وقد اجتمع التأخيرُ والفرعيةُ في : { وَكُنَّا لِحُكْمِهِمْ شاهدين } [ الأنبياء : 78 ] انتهى .
