{ فَدَعَا } عليهم نوح { رَبَّهُ } ب { أَنّي مَغْلُوبٌ فَانتَصِرْ } أي : فانتقم لي ممن كذبني .   قال الزجاج : وقرأ عيسى بن عمر النحوي : { إني } بكسر الألف ،   وفسرها سيبويه فقال : هذا على إرادة القول ،   فالمعنى : قال : إني مغلوب ؛ ومن فتح ،   وهو الوجه ،   فالمعنى : دعا ربه ب { أَنّي مَغْلُوبٌ } .  <br />
