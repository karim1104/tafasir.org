قوله تعالى : { وليحملن أثقالهم } أوزار أعمالهم التي عملوها بأنفسهم ،   { وأثقالاً مع أثقالهم } أي : أوزار من أضلوا وصدوا عن سبيل الله مع أوزارهم .   نظيره قوله عز وجل : { ليحملوا أوزارهم كاملة يوم القيامة ومن أوزار الذين يضلونهم بغير علم } { وليسألن يوم القيامة عما كانوا يفترون } سؤال توبيخ وتقريع .  <br />
