قوله تعالى : { ولقد آتينا موسى الكتاب فاختلف فيه } فمصدق ومكذب كما اختلف قومك في كتابك ،   { ولولا كلمة سبقت من ربك } في تأخير العذاب عن المكذبين بالقرآن ،   { لقضي بينهم } لفرغ من عذابهم وعجل إهلاكهم ،   { وإنهم لفي شك منه } من صدقك { مريب } موقع لهم الريبة .  { من عمل صالحا فلنفسه ومن أساء فعليها وما ربك بظلام للعبيد } .  <br />
