قوله تعالى : { أم من جعل الأرض قراراً } لا تميد بأهلها ،   { وجعل خلالها } وسطها { أنهاراً } تطرد بالمياه ،   { وجعل لها رواسي } جبالاً ثوابت ،   { وجعل بين البحرين } العذب والمالح ،   { حاجزاً } مانعاً لئلا يختلط أحدهما بالآخر ،   { أإله مع الله بل أكثرهم لا يعلمون } توحيد ربه وسلطانه .  <br />
