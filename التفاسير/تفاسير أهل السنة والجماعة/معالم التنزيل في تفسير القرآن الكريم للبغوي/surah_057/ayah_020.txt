قوله عز وجل :{ اعلموا أنما الحياة الدنيا } أي : أن الحياة الدنيا  " وما "  صلة ،   أي : إن الحياة في هذه الدار ،   أي : إن الحياة في هذه الدار ،   { لعب } باطل لا حاصل له ،   { ولهو } فرح ثم ينقضي ،   { وزينة } منظر تتزينون به ،   { وتفاخر بينكم } يفخر به بعضكم على بعض ،   { وتكاثر في الأموال والأولاد } أي : مباهاة بكثرة الأموال والأولاد ،   ثم ضرب لها مثلاً فقال : { كمثل غيث أعجب الكفار } أي : الزراع ،   { نباته } ما نبت من ذلك الغيث ،   { ثم يهيج } ييبس ،   { فتراه مصفراً } بعد خضرته ونضرته ،   { ثم يكون حطاماً } يتحطم ويتكسر بعد يبسه ويفنى ،   { وفي الآخرة عذاب شديد } قال مقاتل : لأعداء الله ،   { ومغفرة من الله ورضوان } لأوليائه وأهل طاعته .   { وما الحياة الدنيا إلا متاع الغرور } قال سعيد بن جبير : متاع الغرور لمن لم يشتغل فيها بطلب الآخرة ،   ومن اشتغل بطلبها فله متاع بلاغ إلى ما هو خير منه .  <br />
