قوله تعالى : { إذ قال الله يا عيسى ابن مريم اذكر نعمتي عليك } ،   قال الحسن : ذكر النعمة شكرها ،   وأراد بقوله : { نعمتي } ،   أي نعمي ،   لفظه واحد ومعناه جمع .   كقوله تعالى : { وإن تعدوا نعمة الله لا تحصوها } .  <br />
قوله تعالى : { وعلى والدتك } ،   مريم ،   ثم ذكر النعم فقال :<br />
قوله تعالى : { إذ أيدتك } ،   قويتك .  <br />
قوله تعالى : { بروح القدس } ،   يعني جبريل عليه السلام .  <br />
قوله تعالى : { تكلم الناس } ،   يعني :وتكلم الناس .  <br />
قوله تعالى : { في المهد } ،   صبيا .  <br />
قوله تعالى : { وكهلاً } ،   نبياً قال ابن عباس : أرسله الله وهو ابن ثلاثين سنة ،   فمكث في رسالته ثلاثين شهراً ،   ثم رفعه الله إليه .  <br />
قوله تعالى : { وإذ علمتك الكتاب } ،   يعني الخط .  <br />
قوله تعالى : { والحكمة } ،   يعني : العلم والفهم .  <br />
قوله تعالى : { والتوراة والإنجيل وإذ تخلق } ،   تجعل وتصور .  <br />
قوله تعالى : { من الطين كهيئة الطير } ،   كصورة الطير .  <br />
قوله تعالى : { بإذني فتنفخ فيها فتكون طيرا } حيا يطير .  <br />
قوله تعالى : { بإذني وتبرئ } وتصحح .  <br />
قوله تعالى : { الأكمه والأبرص بإذني وإذ تخرج الموتى } ،   من قبورهم أحياء .  <br />
قوله تعالى : { بإذني وإذ كففت } ،   منعت وصرفت .  <br />
قوله تعالى : { بني إسرائيل } ،   يعني اليهود .  <br />
قوله تعالى : { عنك } ،   حين هموا بقتلك .  <br />
قوله تعالى : { إذ جئتهم بالبينات } ،   يعني : بالدلالات الواضحات والمعجزات ،   وهي التي ذكرنا ،   وسميت بالبينات لأنها مما يعجز عنها سائر الخلق الذين ليسوا بمرسلين .  <br />
قوله تعالى : { فقال الذين كفروا منهم إن هذا } ،   ماهذا .  <br />
قوله تعالى : { إلا سحر مبين } ،   يعني : ما جاءهم به من البينات ،   قرأ حمزة والكسائي { ساحر مبين } هاهنا وفي سورة هود والصف ،   فيكون راجعاً إلى عيسى عليه السلام ،   وفي هود يكون راجعاً إلى محمد صلى الله عليه وسلم .  <br />
