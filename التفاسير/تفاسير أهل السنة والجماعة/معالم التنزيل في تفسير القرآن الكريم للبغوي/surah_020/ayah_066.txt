قوله تعالى : { قال } موسى { بل ألقوا } أنتم أولاً { فإذا حبالهم } وفيه إضمار أي : فألقوا حبالهم { وعصيهم } جمع العصا { يخيل إليه } قرأ ابن عامر ،   و يعقوب ( تخيل ) بالتاء رداً إلى الحبال والعصي ،   وقرأ الآخرون : بالياء ردوه إلى الكيد والسحر { من سحرهم أنها تسعى }حتى تظن أنها تسعى أي : تمشي وذلك أنهم كانوا لطخوا حبالهم وعصيهم بالزئبق ،   فلما أصابه حر الشمس انهمست واهتزت ،   فظن موسى أنها تقصده .   وفي القصة أنهم لما ألقوا الحبال والعصي أخذوا أعين الناس ،   فرأى موسى والقوم كأن الأرض امتلأت حيات وكانت قد أخذت ميلاً من كل جانب ،   ورأوا أنها تسعى .  <br />
