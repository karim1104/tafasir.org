قوله تعالى : { ألم تر أن الله أنزل من السماء ماءً فسلكه } أدخل ذلك الماء { ينابيع } ،   عيوناً وركايا .   { في الأرض } قال الشعبي : كل ماء في الأرض فمن السماء نزل .   { ثم يخرج به } بالماء .   { زرعاً مختلفاً ألوانه } أحمر وأصفر وأخضر .   { ثم يهيج } ييبس { فتراه } بعد خضرته ونضرته { مصفراً ثم يجعله حطاماً } فتاتاً متكسراً .   { إن في ذلك لذكرى لأولي الألباب } .  <br />
