ثم خاطب المؤمنين فقال : { وإن تدعوهم إلى الهدى } ،   وإن تدعوا المشركين إلى الإسلام .  <br />
قوله تعالى : { لا يتبعوكم } ،   قرأ نافع بالتخفيف ،   { وكذلك يتبعهم الغاوون } [ الشعراء : 244 ] وقرأ الآخرون بالتشديد فيهما ،   وهما لغتان ،   يقال : تبعه تبعاً واتبعه اتباعاً .   قوله تعالى : { سواء عليكم أدعوتموهم } ،   إلى الدين .  <br />
قوله تعالى : { أم أنتم صامتون } ،   عن دعائهم لا يؤمنون ،   كما قال : { سواء عليهم أأنذرتهم أم لم تنذرهم لا يؤمنون } [ البقرة : 6 ] وقيل : { وإن تدعهم إلى الهدى } يعني : الأصنام ،   { لا يتبعوكم } لأنها غير عاقلة .
