42- قوله تعالى :  {  يَأَيُّهَا اَلذِينَ ءَامَنُواْ خُذُواْ حِذْرَكُمْ فَانفِرُواْ ثُبَاتٍ اَوِ ِانفِرُواْ جَمِيعًا } ( 71 ) . <br />
47- ( ذكر ابن خويز منداد :  وقيل إن هذه الآية منسوخة بقوله تعالى :  {  اِنفِرُواْ خِفَافًا وَثِقَالاً }{[103]}  وبقوله :  {  إِلاَّ تَنفِرُواْ يُعَذِّبْكُمْ }{[104]} ؛  ولأن يكون {  اِنفِرُواْ خِفَافًا وَثِقَالاً }{[105]} منسوخا بقوله :  {  فَانفِرُواْ ثُبَاتٍ اَوِ اِنفِرُواْ جَمِيعًا }{[106]} وبقوله :  {  وَمَا كَانَ اَلْمُؤمِنُونَ لِيَنفِرُواْ كَافَّةً }{[107]} أولى لأن فرض الجهاد تقرر على الكفاية ،  فمتى سَدَّ الثغور بعضُ المسلمين أسقط الفرض عن الباقين ){[108]} .
