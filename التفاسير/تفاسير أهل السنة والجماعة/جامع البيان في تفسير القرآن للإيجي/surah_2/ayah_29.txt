{ هُوَ الَّذِي خَلَقَ لَكُم } : لأجل انتفاعكم { مَّا فِي الأَرْضِ جَمِيعاً } لكي تنتفعوا به وتعتبروا ،   جميعاً حال من ما ،   { ثُمَّ اسْتَوَى {[55]} إِلَى السَّمَاء } ،   قصد وارتفع إليه فخلق السماء بعد خلق الأرض لكن دحوها متأخر هكذا ذكره ابن عباس وفيه إشكال سنذكره في سورة ( والنازعات ) والأولى أن ثم للتراخي الرتبي لا الزماني على أن فيه أيضا ما ستقف عليه ،   { فَسَوَّاهُنَّ } : الضمير للسماء لأنه في معنى الجمع عدلهن مصونة عن العوج والفتور { سَبْعَ سَمَاوَاتٍ {[56]} } : بدل أو تفسير ،   { وَهُوَ بِكُلِّ شَيْءٍ عَلِيمٌ  } فإن بالعلم يصح الخلق ويحكم الفعل .
