{ وَإِذَا قِيلَ لَهُمْ } : اليهود ،   { آمِنُواْ بِمَا أَنزَلَ اللّهُ } : القرآن ،   { قَالُواْ نُؤْمِنُ بِمَا أُنزِلَ عَلَيْنَا } : التوراة ،   { وَيَكْفُرونَ بِمَا وَرَاءهُ } : بما سواه أو بما بعده ،   { وَهُوَ } ،   أي : ما وراءه ،   { الْحَقُّ مُصَدِّقاً لِّمَا مَعَهُمْ } ،   فإن القرآن مصدق للتوراة ،   { قُلْ } : يا محمد إن كنتم صادقين في دعوى الإيمان بالتوراة ،   { فَلِمَ تَقْتُلُونَ أَنبِيَاءَ اللّهِ مِن قَبْلُ إِن كُنتُم مُّؤْمِنِينَ } ،   وفعل آبائهم فعلهم مع أنهم رضوا به .  <br />
