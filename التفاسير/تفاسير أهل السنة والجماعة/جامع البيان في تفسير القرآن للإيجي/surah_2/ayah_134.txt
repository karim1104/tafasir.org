{ تِلْكَ } ،   أي : إبراهيم ويعقوب وبنوها ،   { أُمَّةٌ قَدْ خَلَتْ } : مضت ،   { لَهَا مَا كَسَبَتْ } : من العمل ،   { وَلَكُم } : يا معشر اليهود ،   { مَّا كَسَبْتُمْ } ،   أي : انتسابكم إليهم لا يوجب انتفاعكم بأعمالهم ،   { وَلاَ تُسْأَلُونَ عَمَّا كَانُوا يَعْمَلُونَ } : لا تؤاخذون بسيئاتهم ،   كما لا تثابون بحسناتهم .  <br />
