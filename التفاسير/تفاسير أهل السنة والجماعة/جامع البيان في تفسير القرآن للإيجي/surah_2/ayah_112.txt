{ بَلَى } : إثبات لما نفوا من دخول غيرهم الجنة ،   { مَنْ أَسْلَمَ وَجْهَهُ لِلّهِ } : أخلص له نفسه ،   أو دينه أو عمله ،   { وَهُوَ مُحْسِنٌ } : متبع نبي {[183]} الله عليه الصلاة والسلام ،   قيل : مؤمن ،   { فَلَهُ أَجْرُهُ عِندَ رَبِّهِ } : ثابت لا ينقص ،   { وَلاَ خَوْفٌ عَلَيْهِمْ } : في الآخرة عند الفزع الأكبر ،   { وَلاَ هُمْ يَحْزَنُونَ } : على ما مضى .
