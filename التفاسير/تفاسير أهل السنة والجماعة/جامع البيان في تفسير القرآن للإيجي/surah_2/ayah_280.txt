{ وَإِن كَانَ ذُو عُسْرَةٍ } : وقع غريم ذو عسرة ،   { فَنَظِرَةٌ } أي : فعليكم تأخير ،   { إِلَى مَيْسَرَةٍ } : يسار ،   لا كفعل الجاهلية إذا حل الدين ،   يطالب إما بالقضاء وإما بالربا ،   { وَأَن تَصَدَّقُواْ } بإبراء رأس المال ،   { خَيْرٌ لَّكُمْ } : أكثر ثوابا ،   وقيل : خير مما تأخذونه ،   { إِن كُنتُمْ تَعْلَمُونَ } ما فيه من الأجر .  <br />
