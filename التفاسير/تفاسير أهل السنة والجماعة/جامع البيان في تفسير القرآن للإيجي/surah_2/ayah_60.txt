{ وَإِذِ اسْتَسْقَى مُوسَى لِقَوْمِهِ } ،   أي : اذكروا {[90]} نعمتي في إجابتي دعاء نبيكم في شأنكم لما عطشتم في التيه ،   { فَقُلْنَا اضْرِب بِّعَصَاكَ الْحَجَرَ } : حجر خفيف مربع {[91]} قيل إذا ساروا حملوه على ثور فاستمسك الماء ،   وعند بعض أنه لم يكن حجراً معيناً ،   بل يضرب أي حجر كان فينشق { فَانفَجَرَتْ } ،   تقديره فضرب فانشقت ،   { مِنْهُ اثْنَتَا عَشْرَةَ عَيْناً قَدْ عَلِمَ كُلُّ أُنَاسٍ } : كل سبط ،   { مَّشْرَبَهُمْ {[92]} } : عينهم التي يشربون منها خاصة بهم ،   { كُلُواْ وَاشْرَبُواْ } ،   أي : قلنا لهم ذلك ،   { مِن رِّزْقِ اللَّهِ } ،   أي : ما رزقكم الله من المن والسلوى وماء العين ،   { وَلاَ تَعْثَوْاْ } : لا تعتدوا ،   { فِي الأَرْضِ مُفْسِدِينَ } : حال إفسادكم {[93]} .
