{ الَّذِينَ يَنقُضُونَ } : يفسدون ويتركون { عَهْدَ اللَّهِ } : هو قوله : ( ألست بربكم(  {[54]} ،   أو عدم كتمان شيء نزل من عند الله في الكتب { مِن بَعْدِ مِيثَاقِهِ } : توكيد العهد من الآيات في الكتب { وَيَقْطَعُونَ مَا أَمَرَ اللَّهُ بِهِ أَن يُوصَلَ } : أي : كقطع الأرحام والقرابات أو أعم كالإعراض عن موالاة المؤمنين والتفرقة بين الآيات في التصديق وهو بدل من ضمير به ،   { وَيُفْسِدُونَ فِي الأَرْضِ } : بأنواع المعاصي ،   { أُولَئِكَ هُمُ الْخَاسِرُونَ } : باشتراء الفساد والعقاب بالصلاح والثواب .
