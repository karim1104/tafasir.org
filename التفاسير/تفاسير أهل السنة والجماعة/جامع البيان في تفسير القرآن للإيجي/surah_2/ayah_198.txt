{ لَيْسَ عَلَيْكُمْ جُنَاحٌ } : إثم ،   { أَن تَبْتَغُواْ } ،   أي : في أن تبتغوا ،   { فَضْلاً مِّن رَّبِّكُمْ } : عطاء ورزقاً منه بالتجارة حين الإحرام ،   كان المسلمون كرهوا التجارة في الحج ،   فنزلت ،   وأيضا روى أنه سئل هل للجالبين حج ؟ فنزلت ،   { فَإِذَا أَفَضْتُم مِّنْ عَرَفَاتٍ } : انصرفتم عنها ،   { فَاذْكُرُواْ اللّهَ عِندَ الْمَشْعَرِ الْحَرَامِ } ،   بالدعاء والتلبية ،   { وَاذْكُرُوهُ } ،   بالتوحيد والتعظيم ،   { كَمَا هَدَاكُمْ {[345]} } : كما ذكركم بالهداية فهداكم أو كما علمكم ،   { وَإِن كُنتُم مِّن {[346]} قَبْلِهِ } ،   أي : الهدي ،   { لَمِنَ الضَّآلِّينَ } : الجاهلين بالطاعة ،   وإن : هي المخففة ،   واللام : هي الفارقة .
