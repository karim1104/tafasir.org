{ وَقَالَ الَّذِينَ لاَ يَعْلَمُونَ } : مشركوا العرب أو بعض اليهود والنصارى ،   { لَوْلاَ يُكَلِّمُنَا اللّهُ } ،   أي : هلا يكلمنا عيانا ،   { أَوْ تَأْتِينَا آيَةٌ } ،   كما قال تعالى : {  لن نؤمن لك حتى تفجر لنا من الأرض } الآية ( الإسراء : 90 ) ،   { كَذَلِكَ قَالَ الَّذِينَ مِن قَبْلِهِم } : من كفار الأمم الماضية ،   { مِّثْلَ قَوْلِهِمْ تَشَابَهَتْ قُلُوبُهُمْ } : في العناد ،   { قَدْ بَيَّنَّا الآيَاتِ لِقَوْمٍ يُوقِنُونَ } : أيقنوا وطلبوا الحق لا من عاند واستكبر .
