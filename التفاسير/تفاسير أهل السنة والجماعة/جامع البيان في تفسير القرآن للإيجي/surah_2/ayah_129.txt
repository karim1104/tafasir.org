{ رَبَّنَا وَابْعَثْ فِيهِمْ } : في الأمة المسلمة ،   { رَسُولاً مِّنْهُمْ {[215]} } ،   وهو محمد صلى الله عليه وسلم ،   { يَتْلُو } : يقرأ ،   { عَلَيْهِمْ آيَاتِكَ وَيُعَلِّمُهُمُ الْكِتَابَ } : القرآن ،   { وَالْحِكْمَةَ } : السنة أو الفهم في الدين أو العلم والعمل به {[216]} ،   { وَيُزَكِّيهِمْ } : عن الشرك ،   { إِنَّكَ أَنتَ العَزِيزُ } : الغالب ،   { الحَكِيمُ } : واضع الأشياء في محالها .
