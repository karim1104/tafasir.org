{ وَاتَّقُواْ يَوْماً } : احذروا ما فيه من العقاب { لاَّ تَجْزِي } : لا تقضي فيه { نَفْسٌ عَن نَّفْسٍ شَيْئاً } : من الحقوق أو من الجزاء فنصبه على المصدر حينئذ والجملة صفة يوما ،   { وَلاَ يُقْبَلُ مِنْهَا شَفَاعَةٌ } : في شأن الكفار رد عليهم حيث قالوا : آباؤنا الأنبياء شفعاء لنا ،   { وَلاَ يُؤْخَذُ مِنْهَا عَدْلٌ {[84]} } : فداء وقيل بدل ،   { وَلاَ هُمْ يُنصَرُونَ } ولا لهم ناصر يمنعهم من العذاب .
