{ وَبَشِّرِ } البشارة خير سار يظهر أثر السرور في البشرة {[46]} { الَّذِين آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ } : عملاً بلا رياء ،   أو كل ما حسنه الشرع { أَنَّ لَهُمْ } : بأن لهم { جَنَّاتٍ } : دار الثواب وهي سبعة {[47]} { تَجْرِي مِن تَحْتِهَا } : تحت أشجارها وغرفها { الأَنْهَارُ كُلَّمَا رُزِقُواْ مِنْهَا } مبتدأ من الجنات { مِن ثَمَرَةٍ } : بيان تقدم كرأيت منك أسداً {[48]} } : ليس لهم خوف فوات نعمة .  <br />
ولما قالت الجهلة : الله أجل من أن يضرب الأمثال بالصيب والمستوقد وبيت العنكبوت والذباب فنزلت {[49]} .
