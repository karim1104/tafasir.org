{ وَمَثَلُ الَّذِينَ يُنفِقُونَ أَمْوَالَهُمُ ابْتِغَاء مَرْضَاتِ اللّهِ وَتَثْبِيتاً مِّنْ أَنفُسِهِمْ } : تصديقا وتيقنا من أصل أنفسهم أن الله سيجزيهم على ذلك ،   أو يثبتون أين يضعون صدقاتهم { كَمَثَلِ {[526]} جَنَّةٍ } ،   أي : مثلهم في الزكاة كمثل بستان ،   { بِرَبْوَةٍ } : بموضع مرتفع ،   زاد ابن عباس والضحاك : فيها الأنهار { أَصَابَهَا وَابِلٌ } : مطر شديد { فَآتَتْ } : أعطت ،   { أُكُلَهَا } : ثمرتها ،   { ضِعْفَيْنِ } ،   بالنسبة إلى غيرها من البساتين { فَإِن لَّمْ يُصِبْهَا وَابِلٌ فَطَلٌّ } أي : فيصيبها طل وهو المطر الصغير القطر ،   يعني : نفقاتهم زاكية عند الله ،   وإن كانت تتفاوت بسبب أحوالهم ،   كما أن الجنة تثمر قلّ المطر أو كثر ،   أو يضعف ثواب صدقاتهم قلّت النفقة أو كثرت { وَاللّهُ بِمَا تَعْمَلُونَ بَصِيرٌ } ،   تحذير عن الرياء وترغيب في الإخلاص .
