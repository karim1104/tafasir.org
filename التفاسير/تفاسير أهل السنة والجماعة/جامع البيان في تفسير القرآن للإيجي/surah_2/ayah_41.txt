{ وَآمِنُواْ بِمَا أَنزَلْتُ } ،   أي : القرآن { مُصَدِّقاً لِّمَا مَعَكُمْ } فإنكم تجدون محمداً مكتوباً عندكم في التوراة والإنجيل ،   { وَلاَ تَكُونُواْ أَوَّلَ كَافِرٍ بِهِ } : أول فوج يكفر بما أنزلت من أهل الكتاب ،   { وَلاَ تَشْتَرُواْ } : لا تستبدلوا ،   { بِآيَاتِي } : بالإيمان بها { ثَمَناً قَلِيلاً } : الدنيا بحذافيرها ،   أو ما يصيب العلماء من السفلة فإنهم عينوا كل سنة للعلماء شيئا فخافوا إن أسلموا يفوت ذلك  عنهم وتفوت الرياسة {[80]} أيضا ،   فكتموا صفة محمد صلى الله عليه وسلم ،   { وَإِيَّايَ فَاتَّقُونِ } : أي : فاخشون لا فوات الرياسة .
