{ فَلَمَّا فَصَلَ طَالُوتُ بِالْجُنُودِ } ،   انفصل بهم عن بلده لقتال العمالقة ،   وكانوا ثمانين ألفا ،   { قَالَ } ،   لهم طالوت ،   { إِنَّ اللّهَ مُبْتَلِيكُم } : يعاملكم معاملة المختبر ،   { بِنَهَرٍ } : هو بين الأردن وفلسطين ،   { فَمَن شَرِبَ مِنْهُ } ،   أي : شرب بفمه من النهر ،   { فَلَيْسَ مِنِّي } : ليس من أشياعي فلا يصحبني ،   { وَمَن لَّمْ يَطْعَمْهُ فَإِنَّهُ مِنِّي } ،   من طعم الشيء ،   إذا ذاقه مأكولا أو مشروبا ،   { إِلاَّ مَنِ اغْتَرَفَ غُرْفَةً بِيَدِهِ } ،   استثناء منقطع {[492]} من قوله فمن شرب ،   { فَشَرِبُواْ مِنْهُ إِلاَّ قَلِيلاً مِّنْهُمْ } ،   أي : وقع أكثرهم في النهر وكرعوا إلا قليلا ،   أو أفرطوا إلا قليلا ،   فإنه أيام الحر فكان من اغترف روى ،   ومن شرب منه لم يرو ،   والقليل ثلاث مائة وبضعة عشر ،   أو أربعة آلاف من ثمانين ألفا ،   { فَلَمَّا جَاوَزَهُ } ،   أي : النهر ،   { هُوَ وَالَّذِينَ آمَنُواْ مَعَهُ } ،   أي : القليل الذي لم يخالفوه ،   { قَالُواْ } : بعضهم لبعض ،   أو ضمير قالوا للذين خالفوا وشربوا ،   { لاَ طَاقَةَ لَنَا الْيَوْمَ بِجَالُوتَ وَجُنودِهِ } : لكثرتهم وقلتنا ،   { قَالَ الَّذِينَ يَظُنُّونَ } : يعلمون ،   { أَنَّهُم مُّلاَقُو اللّهِ } : تيقنوا لقاءه وثوابه ،   وهم العلماء من القليل ،   ومن قال ضمير قالوا للذين خالفوا ،   يقول : المراد من الذين يظنون ،   هم القليل بجملتهم ،   فهم والكثيرون تقاولوا بذلك والنهر بينهما ،   { كَم مِّن فِئَةٍ } : فرقة ،   وكم خبرية ،   أو استفهامية ،   ومن زائدة أو مبينة ،   { قَلِيلَةٍ غَلَبَتْ فِئَةً كَثِيرَةً بِإِذْنِ اللّهِ } : بحكمه وأمره ،   { وَاللّهُ مَعَ الصَّابِرِينَ } : بالنصر والإثابة .
