{ فَقَالَ الْمَلَأُ } : الأشراف ،   { الَّذِينَ كَفَرُوا مِن قَوْمِهِ } : لعوامّهم ،   { مَا هَذَا إِلَّا بَشَرٌ مِّثْلُكُمْ يُرِيدُ أَن يَتَفَضَّلَ عَلَيْكُمْ } : إن يطلب الفضل عليكم فيكون متبوعا لكم ،   { وَلَوْ شَاء اللَّهُ } ،   إرسال رسول ،   { لَأَنزَلَ مَلَائِكَةً } : للرسالة ،   { مَّا سَمِعْنَا بِهَذَا } : الذي يدعونا إليه أو ببعث البشر رسولا ،   { فِي{[3425]} آبَائِنَا الْأَوَّلِينَ
