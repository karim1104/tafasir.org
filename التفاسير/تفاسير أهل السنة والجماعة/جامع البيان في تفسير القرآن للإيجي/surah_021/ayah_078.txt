{ وَدَاوُدَ وَسُلَيْمَانَ } أي : اذكرهما ،   { إِذْ يَحْكُمَانِ } بدل منهما ،   { فِي الْحَرْثِ } كان ذلك كرما انثنت{[3295]} عناقيده ،   وقيل زرعا{[3296]} ،   { إِذْ نَفَشَتْ } : رعت ليلا{[3297]} ،   { فِيهِ غَنَمُ الْقَوْمِ } : فأفسدته ،   { وَكُنَّا لِحُكْمِهِمْ شَاهِدِينَ } : عالمين ،   وجمع الضمير لأنه أرداها والمتحاكمين إليهما ،   أو لأن الاثنين جمع ،
