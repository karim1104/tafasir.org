{ الْمَالُ وَالْبَنُونَ } : اللذان يفتخر بهما الأغنياء { زِينَةُ الْحَيَاةِ الدُّنْيَا } : لا زينة الآخرة { وَالْبَاقِيَاتُ الصَّالِحَاتُ } أي : الأعمال الصالحة ،   و عن كثير من السلف{[2970]} إنها سبحان الله والحمد لله ولا إله إلا الله والله أكبر ولا حول ولا قوة إلا بالله {[2971]} { خَيْرٌ عِندَ رَبِّكَ ثَوَابًا } أفضل جزاء وثوابا { وَخَيْرٌ أَمًَلا } ،   لأن صاحبها ينال ما يؤمل بها في الدنيا .
