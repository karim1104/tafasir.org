{ قُلْ إِنَّمَا أَنَا بَشَر{[3039]} مِّثْلُكُمْ يُوحَى إِلَيَّ أَنَّمَا إِلَهُكُمْ إِلَهٌ وَاحِدٌ } خصصت بالوحي وتميزت عنكم به{[3040]} { فَمَن كَانَ يَرْجُو لِقَاء رَبِّهِ } يخاف المصير إليه أو يأمل لقاء الله ورؤيته { فَلْيَعْمَلْ عَمَلا صَالِحًا } وهو ما كان موافقا لشرع الله { وَلَا يُشْرِكْ بِعِبَادَةِ{[3041]}  رَبِّهِ أحدا } أي : لا يرائي بعمله بل لابد أن يرد به وجه الله وحده لا شريك له .  <br />
