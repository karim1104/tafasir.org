{ وَيَوْمَ يَقُولُ } أي : الله للكافرين : { نَادُوا شُرَكَائِيَ الَّذِينَ زَعَمْتُمْ } : أنهم شركائي أو أنهم شفعاؤكم { فَدَعَوْهُمْ } : للإغاثة { فَلَمْ يَسْتَجِيبُوا لَهُمْ وَجَعَلْنَا بَيْنَهُم مَّوْبِقًا } : مهلكا فلا وصول لهم إلى آلهتهم ،   بل بينهما مهلك وعن بعضهم هو واد في النار أو نهر من قيح ودم ،   وعن بعض السلف أن ضمير بينهم إلى المؤمنين والكافرين أي نفرق نجعل بينهم حاجزا .  <br />
