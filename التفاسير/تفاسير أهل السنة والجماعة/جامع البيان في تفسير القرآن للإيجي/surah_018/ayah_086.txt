{ حَتَّى إِذَا بَلَغَ مَغْرِبَ الشَّمْسِ وَجَدَهَا تَغْرُبُ فِي عَيْنٍ حَمِئَةٍ } أي : رأى الشمس{[3020]} في منظره تغرب في عين ذات حمئة أي : طين أسود ،   ومن قرأ حامية ،   أي : حارة والجمع بين القراءتين أن تكون العين جامعة للوصفين { وَوَجَدَ عِندَهَا } : عند تلك العين { قَوْمًا } أمة عظيمة من الأمم كفار { قُلْنَا{[3021]}  يَا ذَا الْقَرْنَيْنِ إِمَّا أَن تُعَذِّبَ } : بقتلهم وسبيهم { وَإِمَّا أَن تَتَّخِذَ فِيهِمْ حُسْنًا } : بإرشادهم وتعليمهم الشرائع أو بالمن والفداء ؟ أو بأسرهم ؛ فإنه إحسان في جنب القتل .
