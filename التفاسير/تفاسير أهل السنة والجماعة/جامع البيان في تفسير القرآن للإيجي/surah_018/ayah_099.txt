{ وَتَرَكْنَا بَعْضَهُمْ } أي : بعض يأجوج ومأجوج { يَوْمَئِذٍ } : يوم فتح السد { يَمُوجُ فِي بَعْضٍ } : يختلط بعضهم ببعض كموج الماء لكثرتهم ،   أو جعلنا بعض الخلق من الإنس والجن يوم قيام الساعة يختلط إنسهم بجهنم حيارى{[3032]} { وَنُفِخَ فِي الصُّورِ } : قرن ينفخ فيه إسرافيل لقيام الساعة { فَجَمَعْنَاهُمْ جَمْعًا } : للحساب .
