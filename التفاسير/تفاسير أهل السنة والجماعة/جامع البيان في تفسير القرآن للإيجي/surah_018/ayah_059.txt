{ وَتِلْكَ الْقُرَى } أي : أصحابها أي قرى عاد وثمود وأضرابهم مرفوع بالمبتدأ وقوله : { أَهْلَكْنَاهُمْ } خبره أو منصوب بشريطة التفسير { لَمَّا ظَلَمُوا } بأن كفروا وعاندوا { وَجَعَلْنَا لِمَهْلِكِهِم } : لهلاكهم { مَّوْعِدًا } : وقتا معينا لا يزيد ولا ينقص فكذلك أنتم يا قريش احذروا أن يصيبكم ما أصابهم فقد ظلمتم مثل ما ظلموا ،   بل أشد ومن قرأ المهلك بكسر اللام أي : وقت هلاكهم أو مصدر كالمرجع والمحيص .  <br />
