{ قُلِ } : يا محمد { اللَّهُ أَعْلَمُ بِمَا لَبِثُوا{[2955]} } فلا تختلفوا بعد ما أخبركم الله بمدته { لَهُ غَيْبُ السَّمَاوَاتِ وَالْأَرْضِ } جملة مستأنفة لتعليل الأعلمية وعن قتادة أن قوله ولبثوا في كهفهم ثلاثمائة حكاية قول أهل الكتاب{[2956]} وقد رده الله بقوله :  " قل الله أعلم "  والأول قول أكثر السلف والخلف { أَبْصِرْ بِهِ وَأَسْمِعْ } هما صيغتا التعجب أي : ما أبصره وما أسمعه ،   فالضمير الراجع إلى الله فاعل والباء صلة { مَا لَهُم } الضمير لأهل السماوات والأرض { مِّن دُونِهِ مِن وَلِيٍّ } : يلي أمرهم { وَلا يُشْرِكُ } : الله { فِي حُكْمِهِ } : قضائه { أَحَدًا } : منهم .
