{ وَمَا نُرْسِلُ الْمُرْسَلِينَ إِلا مُبَشِّرِينَ } : للمؤمنين ،   { وَمُنذِرِينَ } : للكافرين ،   { وَيُجَادِلُ الَّذِينَ كَفَرُوا بِالْبَاطِل } كما قالوا :  " أبعث الله بشرا رسولا "  ( الإسراء : 94 ) ،    " ولولا نزل هذا القرآن على رجل من القريتين عظيم "  ( الزخرف :31 ) ،   وأمثال ذلك { لِيُدْحِضُوا } : ليزيلوا ،   { بِهِ } : الجدال ،   { الْحَقَّ } الذي جاءهم عن مقره ويبطلوه { وَاتَّخَذُوا آيَاتِي } الحجج والبراهين { وَمَا أُنذِرُوا } أي : ما أنذروه من العقاب أو ما مصدرية أي : إنذارهم { هُزُوًا } : استهزاء .
