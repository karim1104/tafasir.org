{ هَذَا } أي : القرآن ،   { بَلاَغٌ } كفاية في الموعظة ،   { لِّلنَّاسِ وَلِيُنذَرُواْ بِهِ } تقديره بلاغ لينصحوا ولينذروا به{[2605]} ،   أو تقدير به أنزل ،   { وَلِيَعْلَمُواْ أَنَّمَا هُوَ إِلَهٌ وَاحِدٌ } يستدلوا بالآيات على وحدانيته ،   { وَلِيَذَّكَّرَ أُوْلُواْ الأَلْبَابِ } ذووا العقول الخالصة .
