{ وَلَقَدْ آتَيْنَا مُوسَى الْكِتَابَ{[3855]} } التوراة { مِن بَعْدِ مَا أَهْلَكْنَا الْقُرُونَ الْأُولَى } قوم فرعون ونوح وعاد وثمود وغيرهم { بَصَائِرَ لِلنَّاسِ } من عمى القلب والغي ،   نصب على الحال من الكتاب { وَهُدًى } إلى الطريق المستقيم { وَرَحْمَةً } لو علموا به نالوا رحمة الله { لَّعَلَّهُمْ يَتَذَكَّرُونَ } ليكونوا على حال يرجى منهم التذكر
