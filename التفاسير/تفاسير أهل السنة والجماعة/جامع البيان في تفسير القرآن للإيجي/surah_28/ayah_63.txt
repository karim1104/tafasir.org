{ قَالَ الَّذِينَ حَقَّ عَلَيْهِمُ الْقَوْلُ } وجب عليهم العذاب ،   أي : شياطينهم وسادتهم في الضلال خوفا من أن يقول السفلة لا ذنب إنما الذنب لسادتنا { رَبَّنَا هَؤُلَاء الَّذِينَ أَغْوَيْنَا } أي : أغويناهم { أَغْوَيْنَاهُمْ كَمَا غَوَيْنَا } أي : أغويناهم فغووا غيّا مثل ما غوينا هي خبر هؤلاء والذين مع صلته صفته أو الموصول خبره وهذه مستأنفة { تَبَرَّأْنَا إِلَيْكَ } منهم { مَا كَانُوا إِيَّانَا يَعْبُدُونَ } فإنهم يعبدون أهواءهم فنحن وهم سواء في الغواية شهدوا على أنفسهم بالغواية والإغواء ثم تبرءوا من عبادتهم ،   قال تعالى : { إذ تبرأ الذين اتبعوا من الذين اتبعوا } الآية [ البقرة : 166 ] ،
