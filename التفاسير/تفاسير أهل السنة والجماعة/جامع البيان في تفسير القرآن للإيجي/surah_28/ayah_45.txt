{ وَلَكِنَّا أَنشَأْنَا قُرُونًا } خلقنا أمما بعد موسى { فَتَطَاوَلَ عَلَيْهِمُ الْعُمُرُ } فخربوا الشرائع ،   وكذبوا الرسل وأفسدوا ،   ونسوا عهودهم فلذلك كذبوك وإن كانت دلائل نبوتك ظاهرة { وَمَا كُنتَ ثَاوِيًا } مقيما { فِي أَهْلِ مَدْيَنَ } هم شعيب{[3856]}( * ) والمؤمنون به { تَتْلُو عَلَيْهِمْ } تقرأها عليهم تعلما منهم { آيَاتِنَا } التي فيها قصتهم فتحكي ما رأيت ،   وتعلمت قال بعض المفسرين معناه : ما كنت فيهم رسولا تتلوا عليهم آياتنا فتقص ما قد رأيت منهم { وَلَكِنَّا كُنَّا مُرْسِلِينَ } إليك أخبارهم بوحينا
