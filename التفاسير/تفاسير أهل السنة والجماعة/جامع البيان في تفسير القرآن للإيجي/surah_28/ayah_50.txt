{ فَإِن لَّمْ يَسْتَجِيبُوا لَكَ } دعائك إلى الإتيان بكتاب أهدى { فَاعْلَمْ أَنَّمَا يَتَّبِعُونَ أَهْوَاءهُمْ } لأنهم ما رجعوا بعد ما ألزمتهم بالحجة عن العناد { وَمَنْ أَضَلُّ مِمَّنِ اتَّبَعَ هَوَاهُ } استفهام إنكار { بِغَيْرِ هُدًى مِّنَ اللَّهِ } حال التوكيد وقيل للتقييد فإن هوى النفس قد يكون من الله { إِنَّ اللَّهَ لَا يَهْدِي الْقَوْمَ الظَّالِمِينَ } المتبعين للهوى .  <br />
