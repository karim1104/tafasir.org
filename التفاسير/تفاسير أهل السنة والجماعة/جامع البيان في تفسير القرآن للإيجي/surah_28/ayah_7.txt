{ وَأَوْحَيْنَا{[3820]} } ألهمنا{[3821]} { إِلَى أُمِّ مُوسَى أَنْ أَرْضِعِيهِ } ما دامت غير خائفة عليه { فَإِذَا خِفْتِ عَلَيْهِ } من أن يحس فرعون به { فَأَلْقِيهِ فِي الْيَمِّ{[3822]} } بحر نيل { وَلَا تَخَافِي } عليه فعلينا حفظه { وَلَا تَحْزَنِي } في هجره { إِنَّا رَادُّوهُ{[3823]} إِلَيْكِ وَجَاعِلُوهُ مِنَ الْمُرْسَلِينَ فَالْتَقَطَهُ آلُ فِرْعَوْنَ } فإن أمه جعلته في تابوت ،   وسيرته في النيل فوقع التابوت في نهر كان يجري منه إلى بيت فرعون فأخذه أهل داره { لِيَكُونَ لَهُمْ عَدُوًّا وَحَزَنًا } اللام لام العاقبة { إِنَّ فِرْعَوْنَ وَهَامَانَ وَجُنُودَهُمَا كَانُوا خَاطِئِينَ } مذنبين فعاقبهم الله بأن ربي عدوهم على أيديهم ،   أو خاطئين في الأفكار فأخطئوا في تربية عدوهم
