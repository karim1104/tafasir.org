{ وَيَسْتَعْجِلُونَكَ بِالسَّيِّئَةِ } : بالعقوبة ،   { قَبْلَ الْحَسَنَةِ } أي : العافية سألوا نزول العذاب استهزاء أو يطلبون النقمة لا النعمة كقولهم :  " عجل لنا قطنا قبل يوم الحساب "  ،   { وَقَدْ خَلَتْ } مضت { مِن قَبْلِهِمُ الْمَثُلاَتُ } : عقوبات أمثالهم من المكذبين فما لهم لم يعتبروا ،   { وَإِنَّ رَبَّكَ لَذُو مَغْفِرَةٍ لِّلنَّاسِ } أي : لذو إمهال وستر ،   { عَلَى ظُلْمِهِمْ } : على كفرهم ومعاصيهم ،   وإن فسرت المغفرة بالعفو فعلى ظلمهم خال ولابد أن يفسر الظلم بمعاصي غير الكفر ،   ولا يناسب المقام فإنه إن فسرت بما يعمه فلا يخفى{[2486]} أن العفو من غير توبة فلا يصح بمذهب ،   وإن كان بعد التوبة فلا يلائم ،   لأنهم بعد التوبة ليسوا على الظلم ،   { وَإِنَّ رَبَّكَ لَشَدِيدُ الْعِقَابِ } : لمن شاء .
