ويُزكّيهم } : من دنس الشرك والجهل ،   { ويُعلّمهم الكتاب } : القرآن ،   { والحكمة } : السنة ،   { وإن كانوا من قبل } ،   إن هي المخففة أي : إن الشأن كانوا قبل بعثته ،   { لفي ضلال مبين } : ظاهر .
