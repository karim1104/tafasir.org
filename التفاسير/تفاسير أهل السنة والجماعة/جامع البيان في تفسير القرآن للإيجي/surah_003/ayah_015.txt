{ قل } : يا محمد .   { أؤنبّئكم بخير من ذلكم } أأخبر بخير مما زين للناس ؟ ! { للذين اتقوا } : الشرك .   { عند ربهم جنات{[630]} تجري من تحتها } : من تحت أشجارها .   { الأنهار خالدين فيها أزواج مطهّرة } : من الحيض وسائر الدنس .   { ورضوان من الله } : فلا يسخط عليهم أبدا .   <br />
{ والله بصير بالعباد } بأعمالهم وأحوالهم ،   فيعطيهم ما يستحقونه .
