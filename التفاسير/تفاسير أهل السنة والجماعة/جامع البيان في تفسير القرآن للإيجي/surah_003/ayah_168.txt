{ الذين } ،   بدل من فاعل يكتمون أو نصب أو رفع على الذم ،   { قالوا لإخوانهم } أي : لأجل أقاربهم المقتولين يوم أحد أو قالوا لإخوانهم من المنافقين ،   { وقعدوا } أي : والحال أنهم قعدوا عن الحرب ،   { لو أطاعونا } أي : شهداء أحد في الانصراف ،   { ما قُتلوا } : كما لم نقتل ،   { قل فادرءوا } : ادفعوا { عن أنفسكم الموت إن كنتم صادقين } : إنكم تقدرون دفع القتل عمن كتب عليه .  <br />
