{ لَكُمْ فِيهَا } : في الشعائر وهي البدن ،   { مَنَافِعُ } : درها وصوفها وظهرها ،   { إِلَى أَجَلٍ مُّسَمًّى } : وقت{[3369]} النحر وإن سماها وجعلها هدايا أو الأجل المسمى تسمينها{[3370]} وجعلها هديا فما لم تسم بدنا ينتفع به ،   { ثُمَّ مَحِلُّهَا } : منحرها ،   { إِلَى الْبَيْتِ الْعَتِيق } ،   أي عنده يعني الحرم مطلقا .
