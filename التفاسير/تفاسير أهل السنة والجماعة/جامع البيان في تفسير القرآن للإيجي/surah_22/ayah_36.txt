{ وَالْبُدْنَ } : جمع بدنة وهي الإبل أو البقر ،   وانتصابه على شريطة التفسير ،   { جَعَلْنَاهَا لَكُم مِّن شَعَائِرِ اللَّهِ } : أعلام دينه ،   { لَكُمْ فِيهَا خَيْرٌ } : منافع الدارين ،   { فَاذْكُرُوا اسْمَ اللَّهِ عَلَيْهَا } : عند نحرها يقول : بسم الله والله أكبر لا إله إلا الله اللهم منك ولك ،   { صَوَافَّ } : قائمات على ثلاثة قوائم{[3373]} معقولة يدها اليسرى أو رجلها اليسرى ،   { فَإِذَا وَجَبَتْ } : سقطت ،   { جُنُوبُهَا } : على الأرض أي : ماتت ،   { فَكُلُوا مِنْهَا وَأَطْعِمُوا الْقَانِعَ } : السائل من قنع قنوعا إذا سأل ،   أو فقيرا لا يسأل من القناعة ،   { وَالْمُعْتَرَّ } :الذي يتعرض للمسألة ولا يسأل أو السائل ،   { كَذَلِكَ } : مثل ما وصفنا من نحرها قياما ،   { سَخَّرْنَاهَا لَكُمْ } : مع عظمها ،   { لَعَلَّكُمْ تَشْكُرُونَ } : لكي تشكروا إنعامنا ،
