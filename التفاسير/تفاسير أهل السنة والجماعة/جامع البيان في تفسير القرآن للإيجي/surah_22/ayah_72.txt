{ وَإِذَا{[3397]} تُتْلَى عَلَيْهِمْ } : على أمتك ،   أو على المشركين ،   { آيَاتُنَا بَيِّنَاتٍ } : ظاهرات الدلالة على العقائد الحقّة ،   { تَعْرِفُ فِي وُجُوهِ الَّذِينَ كَفَرُوا الْمُنكَرَ } : الإنكار ،   ،  أو العبوس والكراهة ،   { يَكَادُونَ يَسْطُونَ } : يبطشون ،   { بِالَّذِينَ يَتْلُونَ عَلَيْهِمْ{[3398]} آيَاتِنَا قُلْ أَفَأُنَبِّئُكُم بِشَرٍّ مِّن ذَلِكُمُ } : بطشكم وقهركم عليهم ،   أو من القرآن الذي تكرهونه ،   { النَّارُ } كأنه قيل : ما هو ؟ قال : النار أي : هو النار ،   { وَعَدَهَا اللَّهُ الَّذِينَ كَفَرُوا } استئناف ،   أو النار مبتدأ وهذه الجملة خبره { وَبِئْسَ الْمَصِيرُ } : النار .
