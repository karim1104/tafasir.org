{ ألم يروا كم } : قوم ،   { أهلكنا من قبلهم من قرن{[1359]} } والقرن أهل كل عصر أو مدة أعمار الناس ،   { مكّناهم في الأرض } : أعطيناهم من العمر ،   والمال ،   { ما لم نُمكّن لكم } : ما لم نعطه لكم ،   { وأرسلنا السماء } : المطر والسحاب { عليهم مدرارا } : كثير الدر أي : النصب ،   { وَجَعَلْنَا الأَنْهَارَ تَجْرِي مِنْ تَحْتِهِمْ فَأَهْلَكْنَاهُمْ بِذُنُوبِهِمْ } : بالعذاب من القحط والصواعق وغيرهما ،   { وأنشأنا من بعدهم قرنا آخرين } : بدلا منهم فليخافوا أن نفعل بهم كما فعلنا بهؤلاء .
