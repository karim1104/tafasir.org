{ وما لكم } : أيُّ غرض لكم ،   { ألا تأكلوا مما ذُكر عليه اسم الله } أي : منه وحده وتأكلوا من غيره ،   { وقد فصّل لكم ما حرّم عليكم } : في ( حرمت عليكم الميتة ) الآية ( المائدة : 3 ) ،   { إلا ما اضطُررتم إليه } ( ما ) موصولة والاستثناء من ضمير حرم ،   أو ( ما ) مصدرية في معنى المدة أي : الأشياء التي حرمت عليكم إلا وقت الاضطرار إليها ،   { وإن كثيرا ليُضلّون } : بتحليل الحرام وتحريم الحلال ،   { بأهوائهم } : بتشهيهم ،   { بغير علم } : غير متعلقين بدليل ،   { إن ربك هو أعلم بالمعتدين{[1516]} } : المتجاوزين الحق إلى الباطل .
