{ قل هلُمّ شهداءكم } : أحضروهم ،   اسم فعل متعد ويكون لازما ،   { الذين يشهدون أن الله حرّم هذا } : وهم قدوتهم ليلزمهم الحجة ،   { فإن شهدوا } : عنادا ،   { فلا تشهد معهم } : لا تصدقهم فيه وبين فسادهم ،   { ولا تتّبع أهواء الذين كذّبوا بآياتنا } أي : لا تتبعهم فإنهم يكذبون بآياتنا ،   { والذين لا يؤمنون بالآخرة } : كعبدة الأوثان ،   { وهم بربهم يعدلون } : يجعلون له عديلا سبحانه !<br />
