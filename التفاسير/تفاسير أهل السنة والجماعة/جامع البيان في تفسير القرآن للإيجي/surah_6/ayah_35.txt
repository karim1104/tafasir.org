{ وإن كان كبُر } : عظم وشق ،   { عليك إعراضهم } : عن الإيمان ،   { فإن استطعت أن تبتغي نفقًا } : تطلب منفذا ،   { في الأرض } : تنفذ فيه إلى جوفه ،   { أو سُلّما } : مصعدا ،   { في السماء } : تصعد به إليه ،   { فتأتيهم } : من الأرض أو السماء ،   { بآية } ،   وجواب الشرط الثاني مقدر أي : فافعل ،   والجملة جواب الأول يعني لا مغير لحكم الله فاصبر ،   ولا تذهب نفسك عليهم حسرات ،   { ولو شاء الله لجمعهم على الهدى } أي : لو أراد جمعهم على الهدى لجمعهم وهداهم ،   ولكن لم يتعلق به مشيئته { فلا تكونن من الجاهلين } : بالحرص على خلاف مرادنا والجزع فإنه دأب الجهلة .  <br />
