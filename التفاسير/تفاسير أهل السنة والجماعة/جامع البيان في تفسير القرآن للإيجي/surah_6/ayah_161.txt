{ قل إنني هداني ربي } : بالوحي{[1565]} ،   { إلى صراط مستقيم دينا } أعني دينا أو بدل من محل ( صراط ) إذ معناه وهداني صراطا : { قيما } : مصدر بمعنى القيام أي : قائما ثابتا لا زوال له كرجل عدل ،   { ملّة إبراهيم } ،   عطف بيان لدينا لما في الإضافة من زيادة التوضيح ،   { حنيفا } : مائلا عن غير الصواب حال عن إبراهيم فإنه بمنزلة الحال من المضاف الذي هو معمول الفعل ،   { وما كان من المشركين } : كما يقول المشركون .
