{ وأنّ هذا } : إشارة إلى ما في الآيتين ،   وقيل إلى ما في السورة ،   { صراطي } : ديني ،   { مستقيما } : لا عوج فيه ،   { فاتّبعوه } : عطف على لا تشركوا ( وأن هذا صراطي ) إلخ علة الاتباع أي : لأن ( هذا ) إلخ ،   والجمع بين حرف العطف الواو والفاء عند تقديم المعمول فصلا بينهما شائع ،   وربك فكبر ،   وقيل عطف على لعلكم تذكرون أي وصاكم به لأن هذا ديني المستقيم ،   { ولا تتّبعوا السُّبُل } أي : الطرق المختلفة التي عدا هذا الطريق ،   { فتفرّق بكم } الباء للتعدية ،   { عن سبيله } : الذي هو اتباع الحق ،   { ذلكم } : الاتباع ،   { وصّاكم به لعلكم تتّقون{[1555]} } : الضلال .
