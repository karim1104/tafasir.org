{ قال الملأ } الأشراف { الذين استكبروا } عن الإيمان { من قومه للذين استُضعفوا } أي : الرعايا { لمن آمن منهم } بدل من للذين بدل البعض ؛ لأن ضمير منهم راجع إلى للذين فإن المستضعفين كثيرون والمؤمنون أربعة آلاف { أتعلمون أن صالحا مُرسل من ربه } قيل قالوه على الطنز{[1642]} والسخرية .   { قالوا إنا بما أُرسل به المؤمنون } عدلوا به عن مثل نعم إشارة إلى أن إرساله معلوم مسلم إنما الملام في الإيمان به ونحن مؤمنون .
