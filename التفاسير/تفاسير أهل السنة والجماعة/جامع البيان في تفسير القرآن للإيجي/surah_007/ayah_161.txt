{ وإذ قيل لهم } أي : واذكر هذا الزمان { اسكنوا هذه القرية{[1745]} } بيت المقدس أو ريحا { وكلوا منها حيث شئتم وقولوا حِطّة } أي : مغفرة يعني استغفروا أو اقروا بالذنب أو احطط عنا الخطايا { وادخلوا الباب } باب البلد { سُجّدا } شكرا لله تعالى على الفتح والإنقاد من التيه { نغفر لكم خطيئاتكم سنزيد المحسنين } ثوابا وهو استئناف{[1746]} ولم يأت بالعطف إشعارا على أنه تفضل محض .
