{ فوسوس لهما } فعل الوسوسة لأجلهما { الشيطان } والوسوسة حديث يلقيه في القلب { ليُبدي لهما } ليظهر لهما ،   واللام إما للعاقبة وإما للغرض ،   فإن اللعين يعلم أن العصيان في الجنة سبب لسلب اللباس والفضيحة { ما وُوري عنهما } ما غطى عنهما وستر { من سوءاتهما وقال ما نهاكما ربكما عن } أكل { هذه الشجرة إلا } كراهة { أن تكونا ملكين } يحصل لكما ما للملائكة من القوة والاستغناء عن الغذاء وغيره { أو تكونا من الخالدين } في الجنة .  <br />
