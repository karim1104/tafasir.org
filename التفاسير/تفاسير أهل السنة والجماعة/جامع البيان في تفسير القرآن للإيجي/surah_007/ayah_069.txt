{ أَوَعَجِبْتُمْ أَنْ جَاءَكُمْ ذِكْرٌ مِنْ رَبِّكُمْ عَلَى رَجُلٍ مِنْكُمْ لِيُنْذِرَكُمْ } قد مر تفسيره قريبا فلا نعيده { واذكروا إذ جعلكم خلفاء من بعد قوم نوح } في مساكنهم أو في الأرض بأن أخذ منهم وأعطاكم { وزادكم في الخلق بسطة } قامة وقوة { فاذكروا آلاء الله } تعميم بعد تخصيص { لعلكم تُفلحون } بسبب ذكر النعم وشكره .  <br />
