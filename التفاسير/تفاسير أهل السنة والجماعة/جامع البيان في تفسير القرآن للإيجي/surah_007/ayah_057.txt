{ وهو الذي يرسل الرياح بُشرا } جمع بشير يبشر بالمطر ،   أي : باشرات ،   أو للبشارة ،   ومن قرأ نشرا بالنون وضمها وشين مضمومة أو ساكنة أو فتح النون وسكون الشين فمن النشر أي : ناشرات للسحاب الثقال { بين يدي رحمته } قدام المطر قيل : الصبا تثير السحاب والشمال تجمعه والجنوب تدره والدبور تفرقه { حتى إذا أقلّت } حملت الرياح { سحابا } أي : سحائب { ثقالا } بما فيها من الماء { سُقناه } أي : السحاب { لبلد ميّت } لأجل أرض لا نبات فيها { فأنزلنا به } بالبلد أو بسبب السحاب { الماء فأخرجنا به } بسبب الماء أو بالبلد فالباء للظرفية { من كل } أنواع { الثمرات كذلك } مثل إخراج الثمرات وإحياء البلد { نُخرج الموتى } من قبورهم بعد إحيائهم { لعلكم تذكرون } أن من قدر على ذلك قدر على هذا .  <br />
