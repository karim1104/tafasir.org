{ يا بني آدم خذوا زينتكم } ثيابكم التي تستر عورتكم { عند كل مسجد } بصلاة وطواف { وكلوا واشربوا } نزلت حين كان بنو عامر لا يأكلون دسما في أيام حجهم ،   ولا يأكلون إلا قوتا فقال المسلمون : نحن أحق أن نفعل ذلك : أي : كلوا ما طاب ،   { ولا تُسرفوا } : بتحريم الحلال { إنه لا يحب } لا يرتضي فعل { المسرفين{[1606]} } المعتدين حده في حلال أو حرام ،   أو معناه لا تسرفوا بإفراط الطعام والشراب .
