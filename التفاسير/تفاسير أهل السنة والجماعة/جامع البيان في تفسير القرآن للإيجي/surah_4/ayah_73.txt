{ ولئن أصابكم فضل من الله } كفتح وغنيمة { ليقولن } أكد تنبيها على فرط تحسرهم { كأن } مخففة من الثقيلة { لم تكن بينكم وبينه مودّة } اعتراض بين الفعل ومفعوله وهو { يا ليتني كنت معهم فأفوز } منصوب بجواب التمني { فوزا عظيما } نصيبا وافرا من الغنيمة يعني أن قولهم هذا قول من لا مواصلة بينكم وبينه وليس من أهل دينكم فإن الحظ من المال غاية بغيتهم لا إعانتكم وأجرهم .  <br />
