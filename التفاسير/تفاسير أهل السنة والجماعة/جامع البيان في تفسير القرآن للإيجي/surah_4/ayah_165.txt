{ رسلا } نصب على المدح أو على الحال أو على تقدير أرسلنا .   { مبشّرين } بالثواب على الطاعة { ومنذرين } بالعقاب على المعصية { لئلا يكون للناس على الله حجة بعد الرسل } فيقولوا ما أرسلت إلينا رسول يعلمنا الدين متعلق : ب ( أرسلنا ) وب ( بمنذرين ) ومبشرين وأحد المجرورين خبر كان ،   والآخر حال والظرف لحجة { وكان الله عزيزا حكيما } فيما أراد ودبر .  <br />
