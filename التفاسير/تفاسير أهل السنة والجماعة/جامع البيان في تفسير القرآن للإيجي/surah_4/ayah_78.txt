{ أينما تكونوا يُدرككم الموت ولو كنتم في بروج مشيّدة } حصون مرفوعة منيعة عالية قيل : نزلت في المنافقين الذين قالوا في قتلى أحد : لو كانوا عندنا ما ماتوا { وإن تصبهم } المنافقين واليهود { حسنة } كخصب ورزق من ثمار وأولاد { يقولوا هذه من عند الله وإن تُصبهم سيئة } كجدب ونقص من هلاك ثمار وموت أولاد { يقولوا هذه من عندك } قالوا : ما هي إلا بشؤم محمد وأصحابه { قل كلٌّ } من الحسنة والسيئة { من عند{[1069]} الله } بإرادته وقضائه يبسط ويقبض { فمال هؤلاء القوم لا يكادون يفقهون حديثا } أي : القرآن فإنه لو فهموه لعلموا أن الكل{[1070]}منه تعالى ،   أو حديثا ما كبهائم لا أفهام لهم .
