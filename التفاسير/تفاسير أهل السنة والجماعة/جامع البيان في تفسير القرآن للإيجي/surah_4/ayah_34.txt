{ الرِّجَالُ{[999]} قَوَّامُونَ عَلَى النِّسَاءِ } قيام الولاة على الرعايا { بما فضّل الله بعضهم على بعض } فضلهم عليهن بكمال العقل والدين والقوة { وبما أنفقوا من{[1000]} أموالهم } كالمهر والنفقة ،   اشتكت امرأة عن زوجها بأنه لطمها فأمر رسول الله صلى الله عليه وسلم بالقصاص فنزلت فقال عليه الصلاة والسلام : أردت أمرا وأراد الله غيره فرجعت بغير قصاص{[1001]} { فالصالحات قانتات } مطيعات لأزواجهن { حافظات للغيب } تحفظ في غيبته نفسها وماله { بما حفظ الله } بحفظ الله إياها فالمحفوظ من حفظه ،   أو بما حفظ الله لها من إيجاب حقوقهن على الرجال { واللاتي تخافون نُشوزهن } عصيانهن على أزواجهن { فعِظوهن } بعقاب الله في عصيانها { واهجروهن في المضاجع } بأن يوليها ظهره ولا يجامعها ولا يكلمها ،   أو معناه لا يضاجعها { واضربوهن } إن لم يرتدعن بالموعظة ولا بالهجران ضربا غير شديد{[1002]} { فإن أطعنكم فلا تبغُوا عليهن سبيلا } بالإيذاء ،   وقيل : لا تكلفوهن محبتكم فالقلب بيد الله { إن الله كان عليا كبيرا } فهو أقدر عليكم منكم على أزواجكم ،   ويتجاوز عنكم ليلا ونهارا .
