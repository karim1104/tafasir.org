{ وَاتَّبَعْتُ{[2396]} مِلَّةَ آبَآئِي إِبْرَاهِيمَ وَإِسْحَاقَ وَيَعْقُوبَ مَا كَانَ } : ما صح وما استقام ،   { لَنَا أَن نُّشْرِكَ بِاللّهِ مِن شَيْءٍ } أي شيء{[2397]} كان { ذَلِكَ } : التوحيد { مِن فَضْلِ اللّهِ عَلَيْنَا وَعَلَى النَّاسِ } : على الرسل والمرسل إليهم فإنهم أرشدوهم إلى فضل الله ونبهوهم عليه { وَلَكِنَّ أَكْثَرَ النَّاسِ لاَ يَشْكُرُونَ } ذلك الفضل ،   بل يعرضون عنه .
