{ وَقَالَ الَّذِي اشْتَرَاهُ مِن مِّصْرَ } وهو العزيز{[2378]} الذي كان على خزائن مصر ،   { لاِمْرَأَتِهِ } : راعيل أو زليخا ،   { أَكْرِمِي مَثْوَاهُ } : منزله ،   أي : أحسني تعهده ،   { عَسَى أَن يَنفَعَنَا } : يكفينا أمورنا أو نبعه بالربح ،   { أَوْ نَتَّخِذَهُ وَلَدًا } وكان عقيما ،   { وَكَذَلِكَ مَكَّنِّا لِيُوسُفَ فِي الأَرْضِ } أي : مكناه في مصر ،   وجعلناه ملكا ،   مثل ما أنجبناه وعطفنا عليه العزيز ،   { وَلِنُعَلِّمَهُ } ،   عطف على مقدر أي : مكنا لمصالح ولنعلمه ،   { مِن تَأْوِيلِ الأَحَادِيثِ } تعبير الرؤيا وقيل : معاني كتب الله تعالى ،   { وَاللّهُ غَالِبٌ عَلَى أَمْرِهِ } : يفعل ما يشاء لا يغلبه شيء قيل : الضمير ليوسف أي : أراد إخوته شيئا والله أراد شيئا آخر ولا راد لما أراد ،   { وَلَكِنَّ أَكْثَرَ النَّاسِ لاَ يَعْلَمُونَ } : إن الأمر كله بيده ،   والمراد منه الكفار أو لا يعلمون لطائف تدبيره ،   فالمراد منه أعم .
