{ وَكَذَلِكَ } ،   كما اجتباك بهذه الرؤيا العظيمة ،   { يَجْتَبِيكَ رَبُّكَ } : يصطفيك ،   { وَيُعَلِّمُكَ } : كلام برأسه غير داخل في التشبيه ،   { مِن تَأْوِيلِ الأَحَادِيثِ } تعبير الرؤيا ،   وقيل : تأويل آيات كتب الله - تعالى ،   { وَيُتِمُّ نِعْمَتَهُ عَلَيْكَ } بالنبوة ،   { وَعَلَى آلِ يَعْقُوبَ } أراد سائر أولاده ،   { كمَا أَتَمَّهَا عَلَى أَبَوَيْكَ مِن قَبْلُ } : من قبل هذا الوقت ،   { إِبْرَاهِيمَ وَإِسْحَاقَ } عطف بيان لأبويك ،   { إِنَّ رَبَّكَ عَلِيمٌ } : بمن يستحق النبوة ،   { حَكِيمٌ } : في أفعاله .  <br />
