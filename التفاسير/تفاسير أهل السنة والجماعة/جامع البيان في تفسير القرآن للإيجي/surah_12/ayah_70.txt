{ فَلَمَّا جَهَّزَهُم بِجَهَازِهِمْ } : أصلحهم بعدتهم ،   { جَعَلَ السِّقَايَةَ } : المشربة{[2434]} ،   { فِي رَحْلِ {[2435]}أَخِيهِ } : من أبويه وهي من فضة أو ذهب أو من زبرجد وكان يشرب فيها ويكيل بها للناس من عزة الطعام ،   { ثُمَّ أَذَّنَ مُؤَذِّنٌ } : نادى مناد ،   { أَيَّتُهَا الْعِيرُ } أيك القافلة ،   { إِنَّكُمْ لَسَارِقُونَ } : قال بعضهم : إن كان النداء بأمر يوسف فعلى{[2436]} تأويل إنهم سرقوا يوسف من أبيه  عليه السلام  أو النداء برضى أخيه .
