{ وَلَمَّا دَخَلُواْ مِنْ حَيْثُ أَمَرَهُمْ أَبُوهُم } أي : من أبواب متفرقة في البلد ،   { مَّا كَانَ يُغْنِي } : يدفع دخولهم متفرقين ،   { عَنْهُم مِّنَ اللّهِ } : من قضائه عليهم ،   { مِن شَيْءٍ إِلاَّ حَاجَةً فِي نَفْسِ يَعْقُوبَ قَضَاهَا } استثناء منقطع أي : لكن حاجة أي : شفقة في قضاها أي : أظهرها ووصى بها ،   أو معناه ما دفع عنهم بسبب دخولهم كذلك إلا إصابة العين وهي الحاجة التي{[2432]} في نفس يعقوب ،   { وَإِنَّهُ لَذُو عِلْمٍ } : لذو يقين أو لذو عمل ،   { لِّمَا عَلَّمْنَاهُ وَلَكِنَّ أَكْثَرَ النَّاسِ لاَ يَعْلَمُونَ } أن يعقوب لذو علم فإن المشركين لا يعلمون ما ألهم الله أولياءه .
