{ استكبارا } ،   بدل من نفورا أو مفعول له قيل استكبروا استكبارا ،   { في الأرض ومكر السيئ } ،   من إضافة الموصوف إلى الصفة بدليل قوله : { ولا يحيق } : يحيط ،   { المكر السيئ{[4224]} إلا بأهله } : بالماكر ،   { فهل ينظرون } : ينتظرون ،   { إلا سنة الأولين } : سنة الله فيهم بتعذيب المكذبين جعل استقبالهم لذلك انتظارا له منهم ،   { فلن تجد لسنة الله تبديلا{[4225]} ولن تجد لسنة الله تحويلا } : فيصل العذاب البتة ،   ويصل إليهم لا إلى غيرهم ،
