{ وَقَالَ الْمَلَأُ } : الأشراف ،   { مِن قَوْمِهِ الَّذِينَ كَفَرُوا وَكَذَّبُوا بِلِقَاء الْآخِرَةِ } : المعاد الجسماني ،   { وَأَتْرَفْنَاهُمْ }{[3434]} : أنعمناهم ،   { فِي الْحَيَاةِ الدُّنْيَا مَا هَذَا إِلَّا بَشَرٌ مِّثْلُكُمْ يَأْكُلُ مِمَّا تَأْكُلُونَ مِنْهُ وَيَشْرَبُ مِمَّا تَشْرَبُون } : تشربونه أو منه ،
