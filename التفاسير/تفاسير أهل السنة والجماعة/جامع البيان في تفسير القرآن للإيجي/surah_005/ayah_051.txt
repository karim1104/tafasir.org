{ يَا أَيُّهَا الَّذِينَ{[1264]} آَمَنُوا لَا تَتَّخِذُوا الْيَهُودَ وَالنَّصَارَى أَوْلِيَاءَ } فلا تعاشروهم معاشرة الأجانب { بعضهم أولياء بعض } فهم متفقون على مخالفتكم ومعاداتكم { ومن يتولّهم منكم فإنه{[1265]} منهم } يحشر معهم { إن الله لا يهدي القوم الظالمين{[1266]} } فاحذر عن موالاة من ظلم نفسه فإنهم الظالمون .
