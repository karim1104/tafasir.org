{ ترى كثيرا منهم{[1299]} } : من أهل الكتب { يتولّون } : يوالون { الذين كفروا } فإن المنافقين يوالون المشركين { لبئس ما قدمت لهم أنفسهم أن سخط الله عليهم } ما بعد أن هو المخصوص بالذم كأنه قال : لبئس زادهم إلى الآخرة سخط الله عليهم أي موجب سخطه { وفي العذاب هم خالدون ولو كانوا يؤمنون بالله والنبيّ } أي : محمد عليه الصلاة والسلام .
