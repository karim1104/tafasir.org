{ وَإِلَى مَدْيَنَ أَخَاهُمْ شُعَيْبًا } عطف على نوحا إلى قومه { فَقَالَ يَا قَوْمِ اعْبُدُوا اللَّهَ وَارْجُوا } اخشوا { الْيَوْمَ الْآخِرَ } وقيل : افعلوا ما ترجون به ثواب يوم الآخر من إقامة المسبب مقام السبب { وَلَا تَعْثَوْا } العثو أشد الفساد { فِي الْأَرْضِ مُفْسِدِينَ } يعني لا تزيدوا{[3916]} في الفساد حال كونكم مفسدين
