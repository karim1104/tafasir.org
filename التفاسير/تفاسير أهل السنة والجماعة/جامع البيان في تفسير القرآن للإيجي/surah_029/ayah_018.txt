{ وَإِن تُكَذِّبُوا } أي : تكذبوني { فَقَدْ كَذَّبَ أُمَمٌ مِّن قَبْلِكُمْ } رسلهم كقوم شيث وإدريس ونوح ،   ولم يضرهم تكذيبهم فلا يضرني تكذيبهم { وَمَا عَلَى الرَّسُولِ } اللام للجنس { إِلَّا الْبَلَاغُ الْمُبِينُ } وهذه الآية والتي بعدها إلى قوله : { فما كان جواب قومه } الأظهر أنها من جملة قول إبراهيم لقومه ،   ويحتمل أن يكون معترضة تسلية لرسول الله صلى الله عليه وسلم وتنفيسا بين نصيحته وجواب قومه ،   أي : وإن تكذبوا محمدا إلخ<br />
