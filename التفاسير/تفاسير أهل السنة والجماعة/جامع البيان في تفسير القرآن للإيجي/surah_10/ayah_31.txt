{ قل من{[2165]} يرزقكم من السماء } بالمطر ،   { والأرض } بنبات قيل : تقديره من أهل السماء والأرض ،   { أمن يملك السمع والأبصار } أي : من يملك خلقهما أو حفظهما من الآفات ،   ،   { ومن يخرج الحي } الحيوان ،   { من الميت } النطفة ،   { ويخرج الميت } النطفة ،   { من الحي } الحيوان وقيل : من يحي ويميت ،   { ومن يدبر الأمر } يلي تدبير أمر العالم ،   { فسيقولون الله } إذ الأمر أوضح من أن ينكر ،   { فقل أفلا تتقون } الشرك مع هذا الإقرار .
