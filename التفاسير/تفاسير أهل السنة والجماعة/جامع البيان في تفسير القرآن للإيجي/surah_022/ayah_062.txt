{ ذَلِكَ } : القدرة التامة والعلم الكامل ،   { بِأَنَّ اللَّهَ هُوَ الْحَقُّ } : الثابتة إلهيته ،   { وَأَنَّ مَا يَدْعُونَ مِن دُونِهِ هُوَ الْبَاطِلُ } وكل ما يدعون إلها دونه باطل الألوهية فلا إله سواه ،   { وَأَنَّ اللَّهَ هُوَ الْعَلِيُّ الْكَبِيرُ{[3389]} } : لا شيء أعلى منه وأكبر شأنا فلا محالة يكون قديرا عليما ،
