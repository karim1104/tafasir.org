{ الَّذِينَ أُخْرِجُوا } ،   بدل من للذين ،   أو صفة ،   { مِن دِيَارِهِمْ } : مكة ،   { بِغَيْرِ حَقٍّ } ،   موجب استحقوا الإخراج به ،   { إِلاَّ أَن يَقُولُوا رَبُّنَا اللَّهُ } : سوى التوحيد الذي هو موجب للتمكين والتعظيم فالاستثناء بدل من حق ،   وهذا من باب .  <br />
لا عيب فيهم غير أن سيوفهم *** بهن فلول من قراع الكتائب<br />
وقيل منقطع ،   { وَلَوْلا دَفْعُ اللَّهِ النَّاسَ بَعْضَهُم بِبَعْضٍ } : بالجهاد وإقامة الحدود ،   { لَّهُدِّمَتْ } : خربت ،   { صَوَامِعُ } : الرهبان ،   { وَبِيَعٌ } : كنائس النصارى ،   { وَصَلَوَاتٌ{[3376]} } : كنائس اليهود سميت بها لأنهم لا يصلون إلا فيها ،   { وَمَسَاجِدُ } : للمسلمين ،   { يُذْكَرُ فِيهَا } ،   صفة لمساجد خصت بها تفضيلا ،   وقيل : صفة للأربع ،   { اسْمُ اللَّهِ كَثِيرًا } ،   يعني : لولاه لهدم في زمن موسى وعيسى ومحمد عليهم السلام مواضع عباداتهم باستيلاء الكفرة ،   { وَلَيَنصُرَنَّ اللَّهُ مَن يَنصُرُهُ } : من ينصر دينه ويعلي كلمته ،   { إِنَّ اللَّهَ لَقَوِيٌّ } : على خلقه ،   { عَزِيزٌ } : لا يغلبه غالب ،
