{ أَلَمْ تَرَ أَنَّ اللَّهَ سَخَّرَ لَكُم مَّا فِي الأَرْضِ{[3392]} } : فتنتفعون به ،   { وَالْفُلْكَ } عطف على ما ،   { تَجْرِي فِي الْبَحْرِ بِأَمْرِهِ } ،   حال ،   { وَيُمْسِكُ السَّمَاء } : من ،   { أَن تَقَعَ عَلَى الأَرْضِ إِلاَّ بِإِذْنِهِ } : بمشيئته كما تقع يوم القيامة ،   { إِنَّ اللَّهَ بِالنَّاسِ لرءوف رَّحِيمٌ } حيث أثبت لهم المنافع ،   ودفع عنهم المضار ،
