{ وَإِذْ قَالَت طَّائِفَةٌ مِّنْهُمْ } وهم المنافقون : { يَا أَهْلَ يَثْرِبَ } كان اسما للمدينة أي : أهل المدينة ،   { لَا مُقَامَ لَكُمْ } : لا موضع قيام لكم هاهنا أي عند النبي المصطفى في مقام المرابط ،   { فَارْجِعُوا } : إلى بيوتكم ،   { وَيَسْتَأْذِنُ فَرِيقٌ مِّنْهُمُ النَّبِيَّ } للرجوع فإنه كان عليه السلام خارجا من المدينة بحيث أسند المسلمون ظهورهم إلى سلع ووجوههم نحو العدو والخندق بينهم ،   { يَقُولُونَ إِنَّ بُيُوتَنَا عَوْرَةٌ } : غير حصينة نخاف عليها السراق ،   { وَمَا هِيَ بِعَوْرَةٍ } : فإنها حصينة ،   { إِن يُرِيدُونَ إِلَّا فِرَارًا{[4061]} } : من القتال ،
