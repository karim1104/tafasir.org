{ ثُمَّ يَوْمَ الْقِيَامَةِ يُخْزِيهِمْ } يذلهم ،   { وَيَقُولُ } الله تعالى تقريعا{[2691]} وتوبيخا ،   { أَيْنَ شُرَكَائِيَ } في زعمكم ليدفعوا العذاب عنكم ،   { الَّذِينَ كُنتُمْ تُشَاقُّونَ } : تحاربون ،   { فِيهِمْ } في سبيلهم ،   { قَالَ الَّذِينَ أُوتُواْ الْعِلْمَ } هم السادة في الدارين إظهارا للشماتة وزيادة للإهانة ،   { إِنَّ الْخِزْيَ الْيَوْمَ وَالْسُّوءَ } العذاب ،   { عَلَى الْكَافِرِينَ } .
