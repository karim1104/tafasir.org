{ إِلاَّ مَن رَّحِمَ رَبُّكَ } وهم أتباع الرسل تمسكوا بما أمروا به ،   { وَلِذَلِكَ } أي : للرحمة{[2351]} أو للاختلاف{[2352]} أو لهما{[2353]} ،   { خَلَقَهُمْ } الضمير لمن على الأول وللناس على الآخرين ،   { وَتَمَّتْ كَلِمَةُ رَبِّكَ } قضاؤه وقدره ،   { لأَمْلأنَّ جَهَنَّمَ مِنَ الْجِنَّةِ وَالنَّاسِ } : من عصاتهما ،   { أَجْمَعِينَ } أو منهما أجمعين لا من أحدهما .
