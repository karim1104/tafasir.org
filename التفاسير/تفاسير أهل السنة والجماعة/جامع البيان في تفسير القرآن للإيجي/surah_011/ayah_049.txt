{ تِلْكَ } إشارة إلى قصة نوح ،   { مِنْ أَنبَاء الْغَيْبِ } أي : من أخباره ،   { نُوحِيهَا إِلَيْكَ } خبر ثان لتلك أو حال ،   { مَا كُنتَ تَعْلَمُهَا أَنتَ وَلاَ قَوْمُكَ مِن قَبْلِ هَذَا } خبر ثالث أوحال ،   { فَاصْبِرْ } : كما صبر نوح ،   { إِنَّ الْعَاقِبَة } في الدنيا والآخرة بالنصرة ،   { لِلْمُتَّقِين } .  <br />
