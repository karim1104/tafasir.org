{ يَوْمَ يَأْتِ{[2326]} } ذلك اليوم المعين على أن يوم بمعنى حين ،   { لاَ تَكَلَّمُ } : لا تتكلم ،   { نَفْسٌ } وهو الناصب للظرف ،   { إِلاَّ بِإِذْنِهِ } : بإذن الله تعالى ،   وهذا في موقف ويوم لا ينطقون في موقف آخر ،   { فَمِنْهُمْ } الضمير لأهل الموقف دل عليه قوله لا تكلم نفس ،   { شَقِيٌّ } منهم{[2327]} { وَسَعِيدٌ } .
