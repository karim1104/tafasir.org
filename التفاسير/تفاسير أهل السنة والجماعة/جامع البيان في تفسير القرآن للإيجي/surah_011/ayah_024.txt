{ مَثَلُ{[2260]} الْفَرِيقَيْنِ } الكافر والمؤمن ،   { كالأَعْمَى وَالأَصَمِّ } هو مثل الكافر ،   { وَالْبَصِيرِ {[2261]}وَالسَّمِيعِ } هو مثل المؤمن يميز بين الحق والباطل ويفرق بين البرهان والشبهة ،  { هَلْ يَسْتَوِيَانِ مَثَلاً } أي : تمثيلا{[2262]} ،   { أَفَلاَ تَذَكَّرُونَ } فتفرقوا بين وهؤلاء .
