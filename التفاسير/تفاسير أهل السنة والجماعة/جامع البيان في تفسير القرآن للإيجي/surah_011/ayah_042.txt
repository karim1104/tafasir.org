{ وَهِيَ تَجْرِي بِهِمْ } أي : ركبوا فيها وهي تجري وهم فيها ،   { فِي مَوْجٍ كَالْجِبَالِ } كل موجة كجبل ،   { وَنَادَى نُوحٌ ابْنَهُ } كنعان ،   { وَكَانَ فِي مَعْزِلٍ } مكان عزل وأبعد فيه نفسه عن أبيه ،   { يَا بُنَيَّ ارْكَب مَّعَنَا } في السفينة ،   { وَلاَ تَكُن مَّعَ الْكَافِرِينَ } في الدين والبعد عنا .  <br />
