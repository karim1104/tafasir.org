{ وَإِلَى ثَمُودَ } عطف على ( وإلى عاد ) ،   { أَخَاهُمْ } واحد منهم ،   { صَالِحًا } عطف بيان ،   { قَالَ يَا قَوْمِ اعْبُدُواْ اللّهَ مَا لَكُم مِّنْ إِلَهٍ غَيْرُهُ } صفة تابعة لمحل الموصوف ،   { هُوَ أَنشَأَكُم مِّنَ الأَرْضِ } فإنهم من آدم وآدم من تراب ،   { وَاسْتَعْمَرَكُمْ فِيهَا } أقدركم على عمارتها ،   وعن الضحاك أطال عمركم فيها فإن الواحد منهم يعيش ثلاثمائة إلى ألف سنة ،   { فَاسْتَغْفِرُوهُ } لما مضى ،   { ثُمَّ تُوبُواْ إِلَيْهِ } فيما بقي ،   { إِنَّ رَبِّي قَرِيبٌ } يسمع أو قريب الرحمة ،   { مُّجِيبٌ } لداعيه .  <br />
