{ وَكُلاًّ } التنوين عوض ،   أي كل نبأ ،   { نَّقُصُّ عَلَيْكَ } وقوله : { مِنْ أَنبَاء الرُّسُلِ } بيان لكلا أو صفة لنبأه المحذوف ومن للتبعيض ،   { مَا نُثَبِّتُ بِهِ فُؤَادَكَ } بدل بعض من كلا أو مفعول نقص ،   وكلا مفعول مطلق حينئذ ،   أي : كل نوع من أنواع الاقتصاص نقص عليك و تثبيت فؤاده زيادة بقينه واحتمال الأذى ،   { وَجَاءكَ فِي هَذِهِ } السورة ،   { الْحَقُّ } خص هذه السورة تشريفا وإن كان قد جاءه الحق في جميع السور أو جاءك في هذه السورة لك لأمتك ،   { وَمَوْعِظَةٌ وَذِكْرَى } جاءتك فيها ،   { لِلْمُؤْمِنِينَ } أي : عمت فائدة تلك السورة لك ولأمتك .  <br />
