{ إِنَّ فِي ذَلِكَ } أي : هلاك تلك الأمم أو الأنباء بإهلاكهم ،   { لآيَةً } : عبرة ،   { لِّمَنْ خَافَ عَذَابَ الآخِرَةِ } فيجعلها أنموذجا ودليلا على صدق ما أعد الله تعالى للمجرمين ،   { ذَلِكَ } إشارة إلى ما دل عليه عذاب الآخرة ،   أي : يوم القيامة ،   { يَوْمٌ مَّجْمُوعٌ لَّهُ النَّاسُ } لأن يجازيهم ،   { وَذَلِكَ يَوْمٌ مَّشْهُودٌ } فيه الخلائق البر والفاجر اتسع في الظرف بإجرائه مجرى المفعول به ،   أو المراد بالمشهود الذي كثر شاهدوه .  <br />
