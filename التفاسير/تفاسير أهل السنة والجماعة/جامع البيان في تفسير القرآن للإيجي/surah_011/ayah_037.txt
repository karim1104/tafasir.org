{ وَاصْنَعِ الْفُلْكَ بِأَعْيُنِنَا } أي : متلبسا{[2271]} بأعيننا كأن لله تعالى معه أعينا تحفظه عن الميل في صنعته عن الصواب وحاصله اصنعها وأنت محفوظ ،   { وَوَحْيِنَا } إليك كيفية صنيعها ،   { وَلاَ تُخَاطِبْنِي } بالدعاء ،   { فِي الَّذِينَ ظَلَمُواْ } أي : في شأنهم ودفع العذاب عنهم ،   { إِنَّهُم مُّغْرَقُونَ } بالطوفان لا سبيل لهم إلى الخلاص .
