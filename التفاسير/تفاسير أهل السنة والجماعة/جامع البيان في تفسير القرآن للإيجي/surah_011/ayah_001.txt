{ الَر{[2243]} كِتَابٌ } خبر ( الر ) أو هذا كتاب ،   { أُحْكِمَتْ آيَاتُهُ ثُمَّ فُصِّلَتْ } أي : هي محكمة في لفظها مفصلة في معناها أو أحكمت بأنها لم تنسخ بكتاب{[2244]} ثم فصلت بالأحكام والعقائد والمواعظ والأخبار أو نزلت شيئا فشيئا ،   { مِن لَّدُنْ حَكِيمٍ خَبِيرٍ } صفة أخرى لكتاب{[2245]} أو متعلق بأحكمت وفصلت أو خبر بعد خبر .
