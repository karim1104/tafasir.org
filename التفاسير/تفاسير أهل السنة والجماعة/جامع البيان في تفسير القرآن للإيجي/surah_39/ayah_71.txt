{ وسيق الذين كفروا إلى جهنم } ،   كما يفعل بالأسارى يساقون إلى حبس{[4338]} وقتل ،   { زمرا } : أفواجا ،   بعضها على إثر بعض ،   { حتى إذا جاءوها فُتحت أبوابها } : السبعة التي كانت مغلقة قبل ذلك ،   { وقال لهم خزنتها } ،   توبيخا وتنكيلا ،   { ألم يأتيكم رسل منكم } : من جنسكم ،   { يتلون عليكم آيات ربكم وينذروكم لقاء يومكم هذا } ،   أي وقتكم هذا ،   أو وقت دخولهم النار ،   { قالوا بلى ولكن حقت } : وجبت ،   { كلمة العذاب } ،   في قوله : { لأملأن جهنم من الجنة والناس } ( هود : 119 ) ،   أو المراد حكم الله تعالى بشقاوتهم ،   { على الكافرين } ،   من وضع المظهر بدل المضمر ،  أي : علينا .
