{ إِنَّ قَارُونَ{[3875]} كَانَ مِن قَوْمِ مُوسَى{[3876]} } ابن عمه آمن به ثم نافق { فَبَغَى } تكبر { عَلَيْهِمْ وَآتَيْنَاهُ مِنَ الْكُنُوزِ مَا إِنَّ مَفَاتِحَهُ{[3877]} } جمع مفتح وهو ما يفتح به { لَتَنُوءُ } تثقل { بِالْعُصْبَةِ } الجماعة الكثيرة { أُولِي الْقُوَّة } ما الموصولة مع صلته التي هي أن واسمها وخبرها ثاني مفعولي { آتينا } { إِذْ قَالَ } ظرف لتنوء { لَهُ قَوْمُهُ لَا تَفْرَحْ } بدنياك ،   فإن الفرح بها مدة قصيرة وهو يورث غمّا سرمدا { إِنَّ اللَّهَ لَا يُحِبُّ الْفَرِحِينَ } الأشرين البطرين بالدنيا
