{ وَابْتَغِ فِيمَا آتَاكَ اللَّهُ } من المال { الدَّارَ الْآخِرَةَ } بأن تصرفه في مرضاة الله { وَلَا تَنسَ نَصِيبَكَ مِنَ الدُّنْيَا } فإن نصيب كل أحد ليس إلا ما يأكل ويلبس ،   أو النصيب ما ينفعك مالا وما هو إلا أعمال الخير ،   قيل النصيب الكفن { وَأَحْسِن } إلى الناس { كَمَا{[3878]} أَحْسَنَ اللَّهُ إِلَيْكَ } قيل : أحسن بالشكر كما أحسن الله بالإنعام إليك { وَلَا تَبْغِ الْفَسَادَ } الظلم والكبر والمعاصي { فِي الْأَرْضِ إِنَّ اللَّهَ لَا يُحِبُّ الْمُفْسِدِين }
