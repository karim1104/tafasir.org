{ أَفَمَن{[3868]} وَعَدْنَاهُ وَعْدًا حَسَنًا } حسن الوعد بحسن الموعود كالجنة { فَهُوَ لَاقِيهِ } مدركه { كَمَن مَّتَّعْنَاهُ مَتَاعَ الْحَيَاةِ الدُّنْيَا } الذي هو مشروب بأنواع الغصص { ثُمَّ هُوَ يَوْمَ الْقِيَامَةِ مِنَ الْمُحْضَرِينَ } للحساب والعذاب وهذه الآية كالنتيجة لما قبلها ،   ولذلك رتب عليها بالفاء نزلت في النبي عليه السلام وأبي جهل أو في علي وحمزة وأبي جهل
