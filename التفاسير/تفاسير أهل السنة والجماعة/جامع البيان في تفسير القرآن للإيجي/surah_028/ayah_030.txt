{ فَلَمَّا أَتَاهَا نُودِي مِن شَاطِئِ } جانب { الْوَادِي{[3848]} الْأَيْمَنِ } عن يمين موسى { فِي الْبُقْعَةِ الْمُبَارَكَةِ } متصل بالشاطئ ،   أو صلة لنودي { مِنَ الشَّجَرَةِ{[3849]} } بدل اشتمال من شاطئ فإنها نابتة على الشاطئ { أَن يَا مُوسَى } أن مفسرة { إِنِّي أَنَا اللَّهُ رَبُّ الْعَالَمِينَ{[3850]} } أي : الذي يكلمك رب العالمين
