{ وَقَالَ الَّذِينَ أُوتُوا الْعِلْمَ } أي : الأحبار لمن تمنى ويلكم { وَيْلَكُمْ } دعاء بالهلاك مستعمل في الزجر { ثَوَابُ اللَّهِ } في الآخرة { خَيْرٌ لِّمَنْ آمَنَ وَعَمِلَ صَالِحًا } مما أوتي قارون { وَلَا يُلَقَّاهَا } الثواب والتأنيث لأنه بمعنى المثوبة أو الجنة { إِلَّا الصَّابِرُونَ } على حكم الله ،   وهو من تتمة النصيحة أو المعنى ما يلقى هذه الكلمة التي تكلم بها العلماء إلا الصابرون فعلى هذا من كلام الله منقطع عن الأول<br />
