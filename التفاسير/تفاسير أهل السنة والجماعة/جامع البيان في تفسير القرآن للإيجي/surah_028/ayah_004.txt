{ إِنَّ فِرْعَوْنَ } استئناف يبين بعض النبأ { عَلَا فِي الْأَرْضِ } استكبر في أرض مصر { وَجَعَلَ أَهْلَهَا شِيَعًا } أصنافا يصرف كل صنف فيما يريد { يَسْتَضْعِفُ } حال من فاعل جعل { طَائِفَةً مِّنْهُمْ } يعني : بني إسرائيل { يُذَبِّحُ أَبْنَاءهُمْ } بدل من يستضعف { وَيَسْتَحْيِي نِسَاءهُمْ } يخليهن أحياء للخدمة { إِنَّهُ كَانَ مِنَ الْمُفْسِدِينَ }<br />
