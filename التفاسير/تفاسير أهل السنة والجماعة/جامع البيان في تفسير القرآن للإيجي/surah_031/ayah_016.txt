{ يَا بُنَيَّ إِنَّهَا } أي : الخصلة السيئة قيل : إن لقمان قال{[4001]} ذلك في جواب ابنه حين قال له : إن عملت خطيئة حيث لا يراني أحد كيف يعلمها الله ؟ { إِن تَكُ مِثْقَالَ حَبَّةٍ{[4002]} مِّنْ خَرْدَلٍ فَتَكُن فِي صَخْرَةٍ } : في أخفى مكان وأحرزه ،   وعن بعض{[4003]} إن المراد منها : صخرة تحت الأرضين السبع وهي التي يكتب فيها أعمال الفجار ،   { أَوْ فِي السَّمَاوَاتِ أَوْ فِي الْأَرْضِ } ،   أو في أعلى مكان أو أسفله ،   { يَأْتِ{[4004]} بِهَا اللَّهُ } : يحضرها يوم القيامة للجزاء ،   { إِنَّ اللَّهَ لَطِيفٌ خَبِيرٌ } : يصل عمله إلى كل{[4005]} خفي ،
