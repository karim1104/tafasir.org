{ وَلَا تُصَعِّرْ خَدَّكَ } : لا تمله ،   { لِلنَّاسِ } ،   كما يعمله المتكبرون ،   يعني : لا تعرض عن الناس بوجهك إذا كلموك تكبرا ،   { وَلَا تَمْشِ فِي الْأَرْضِ مَرَحًا } أي : لا تمرح مرحا أو للمرح والبطر كما قال تعالى : { ولا تكونوا كالذين خرجوا من ديارهم بطرا ورئاء الناس } [ الأنفال : 47 ] ،   { إِنَّ اللَّهَ لَا يُحِبُّ كُلَّ مُخْتَالٍ } : ذي تكبر ،   { فَخُورٍ } : يفتخر{[4007]} على الناس ،   ولا يتواضع
