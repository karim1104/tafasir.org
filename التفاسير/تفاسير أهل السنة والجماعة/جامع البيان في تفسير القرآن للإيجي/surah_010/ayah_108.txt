{ قُلْ يَا أَيُّهَا النَّاسُ قَدْ جَاءكُمُ الْحَقُّ } القرآن ،   { مِن رَّبِّكُمْ فَمَنِ اهْتَدَى } فإنمَا يَهْتَدِي لِنَفْسِهِ } بالإيمان به ،   { وَمَن ضَلّ } بالكفر به ،  َ { فَإِنَّمَا يَضِلُّ عَلَيْهَا } وبال الضلال عليها ،   { وَمَا أَنَاْ عَلَيْكُم بِوَكِيلٍ } بموكول إلى أمركم ،   أو بكفيل أحفظ أعمالكم إنما أنا نذير .  <br />
