{ ثُمَّ بَعَثْنَا مِن بَعْدِه } من بعد نوح ،   { رُسُلا ً إِلَى قَوْمِهِمْ فَجَاؤُوهُم بِالْبَيِّنَاتِ } المعجزات الظاهرات ،   { فَمَا كَانُواْ } ما استقام لهم ،   { لِيُؤْمِنُواْ } لشدة عنادهم وكفرهم ،   { بِمَا كَذَّبُواْ بِهِ مِن قَبْلُ } أي : بما كذب به قوم نوح وقد علموا حالهم فهم وآباؤهم على منهاج واحد والباء للسببية ،   أي : لم يؤمنوا بسبب تعودهم تكذيب الحق قبل بعثة الرسل ،   { كَذَلِكَ نَطْبَعُ عَلَى قُلوبِ الْمُعْتَدِينَ } نختم عليها فلا يدخلها رشاد ولا سداد .  <br />
