{ كُلُوا } أي : قائلين كلوا { مِن طَيِّبَاتِ مَا رَزَقْنَاكُمْ } : من لذائذه أو حلالاته { وَلَا تَطْغَوْا فِيهِ } : بأن تكفروا نعمتي فتنفقوا في معصيتي ولم تشكروا { فَيَحِلَّ عَلَيْكُمْ } : يلزمكم ،   ومن قرأ يحل فمعناه ينزل { غَضَبِي وَمَن يَحْلِلْ{[3183]} عَلَيْهِ غَضَبِي فَقَدْ هَوَى } : هلك ،   وعن ابن عباس{[3184]} في جهنم قصر يرمى الكافر من أعلاه فيهوى أربعين خريفا قبل أن يبلغ الصلصال ،   وذلك ق وله :  " فقد هوى "  .
