{ قَالَ لَهُم } : للسحرة { مُّوسَى } وفي عددهم اختلاف كثير قيل سبعون رجلا ،   وقيل ثمانون ألفا ،   أو ثلاثون أو تسعة عشر ألفا ،   أو خمسة عشر ألفا ،   أو اثنا عشر ألفا { وَيْلَكُمْ لَا تَفْتَرُوا عَلَى اللَّهِ كَذِبًا } ،   بأن تخيلوا للناس ما لا حقيقة له ،   فتقولوا إنه مخلوق لله وأن تدعوا معجزاته سحرا أو تدعوا له ندا { فَيُسْحِتَكُمْ } : يستأصلكم { بِعَذَابٍ وَقَدْ خَابَ } : خسر { مَنِ افْتَرَى } : على الله .  <br />
