{ وَما أَرْسَلْنَا قَبْلَكَ مِنَ الْمُرْسَلِينَ إِلَّا } : رسلا ،   { إِنَّهُمْ لَيَأْكُلُونَ الطَّعَامَ وَيَمْشُونَ فِي الْأَسْوَاقِ } ،   ما بعد إلا صفة أقيمت مقام موصوفها ،   وهذا جواب قولهم : { ما لهذا الرسول } الآية ،   { وَجَعَلْنَا بَعْضَكُمْ } : أيها الناس ،   { لِبَعْضٍ فِتْنَةً } : ابتلاء ،   وامتحانا كابتلاء المرسلين بالمرسل إليهم ،   والفقراء بالأغنياء ،   { أَتَصْبِرُونَ{[3609]} } ،   علة للجعل أي : لنعلم أيكم يصبر كقوله تعالى : { ليبلوكم أيكم أحسن عملا } [ هود : 7 ،   الملك : 2 ] ،   وقيل : حث على الصبر على ما افتتنوا به { وَكَانَ رَبُّكَ بَصِيرًا } ،   عالما بالصواب فيما يبتلي به وغيره ،   فلا يضيقن صدرك ،   أو بمن يصبر .
