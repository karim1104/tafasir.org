{ قَالَ } : إبليس ،   { أَرَأَيْتَكَ } أي : أخبرني والكاف لتأكيد الخطاب لا محل له من الإعراب ،   { هَذَا } مفعول أرأيت ،   { الَّذِي } صفة هذا ،   { كَرَّمْتَ عَلَيَّ } أي : أخبرني عن هذا الذي فضلته علي بأن أمرتني بسجوده لم كرمته علي فمتعلق الاستخبار محذوف يدل عليه الصلة ،   { لَئِنْ أَخَّرْتَنِ إِلَى يَوْمِ الْقِيَامَةِ } اللام توطئة القسم وجوابه ،   { لأَحْتَنِكَنَّ } لأستأصلن ،   { ذُرِّيَّتَهُ } : بالإغواء ،   { إَلاَّ قَلِيلاً } لا أقدر أن أقاومهم وكأنه لعنه الله تفرس من خلقه فإنه قد جبل بشهوة ووهم وغضب .  <br />
