{ إِنْ أَحْسَنتُمْ أَحْسَنتُمْ لِأَنفُسِكُمْ وَإِنْ أَسَأْتُمْ فَلَهَا } أي : الإحسان والإساءة كلاهما مختصان{[2805]} بها لا يتعدى النفع والضر إلى غيركم ،   وقيل : أتى باللام دون على في قوله وإن أسأتم فلها للازدواج ،   { فَإِذَا جَاء وَعْدُ } عقوبة المرة ،   { الآخِرَةِ لِيَسُوؤُواْ } تقديره بعثناهم ليسوءوا ،   { وُجُوهَكُمْ } يهينوكم ومن قرأ ليسوء فالضمير لله أو للوعد أو للبعث ،   { وَلِيَدْخُلُواْ الْمَسْجِدَ } عطف على ليسوؤا ،   { كَمَا دَخَلُوهُ أَوَّلَ مَرَّةٍ } أي : كما خربوا أولا بيت المقدس بعثناهم ليخربوا ثانيا ،   { وَلِيُتَبِّرُواْ } : يهلكوا ،   { مَا عَلَوْاْ } مفعول يتبروا ،   أي : ليهلكوا كل شيء غلبوه ،   { تَتْبِيرًا } .
