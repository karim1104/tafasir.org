{ قُلِ ادْعُواْ الَّذِينَ زَعَمْتُم } أنها آلهة ،   { مِّن دُونِهِ } كالملائكة وغيره ،   { فَلاَ يَمْلِكُونَ } فلا يستطيعون ،   { كَشْفَ الضُّرِّ عَنكُمْ } بالكلية ،   { وَلاَ تَحْوِيلاً } إلى غيركم أو تحويل حال من العسر إلى حال اليسر نزلت جين شكى المشركون قحطهم إلى رسول الله صلى الله عليه وسلم .  <br />
