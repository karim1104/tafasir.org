{ وَقَضَيْنَا } : أوحينا وحيا مقضيا مقطوعا ،   { إِلَى بَنِي إِسْرَائِيلَ فِي الْكِتَابِ } : التوراة ،   { لَتُفْسِدُنَّ } جواب قسم محذوف ،   { فِي الأَرْضِ } بالمعاصي ،   { مَرَّتَيْنِ{[2804]} } مخالفة أحكام التوراة ،   ثم قتل يحيى وزكريا ،   { وَلَتَعْلُنَّ عُلُوًّا كَبِيرًا } تستكبرن عن طاعة الله أو تظلمن الناس .
