{ وَكَمْ } أي : كثيرا مفعول ،   { أَهْلَكْنَا مِنَ الْقُرُونِ } تمييز لكم ،   { مِن بَعْدِ نُوحٍ } كعاد وثمود فإن بين آدم ونوح عشر قرون كلهم على الإسلام ،   { وَكَفَى بِرَبِّكَ } الباء مزيدة على الفاعل ،   { بِذُنُوبِ عِبَادِهِ } متعلق بقوله ،   { خَبِيرًَا {[2822]}بَصِيرًا } وهما منصوبان على التمييز أو الحال فإن الذنوب هي أسباب الهلكة وهو تعالى علم بها فمعاقب عليها .
