{ وَإِذَا مَسَّكُمُ الْضُّرُّ } : خوف الغرق ،   { فِي الْبَحْرِ ضَلَّ } : زال عن خاطركم ،   { مَن تَدْعُونَ } : كل من تدعونه ،   { إِلاَّ إِيَّاهُ } : الله وحده فحينئذ لا يخطر ببالكم سواه فتدعونه وحده ،   { فَلَمَّا نَجَّاكُمْ } ،   من الغرق ،   { إِلَى الْبَرِّ أَعْرَضْتُمْ } : عن التوحيد ،   { وَكَانَ الإِنْسَانُ كَفُورًا } يعني سجية الإنسان نسيان النعم وجحدها .  <br />
