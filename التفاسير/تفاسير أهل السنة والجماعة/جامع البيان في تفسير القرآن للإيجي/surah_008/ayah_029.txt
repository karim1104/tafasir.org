{ يا أيها الذين{[1838]} آمنوا إن تتقوا الله يجعل لكم فرقانا } : مخرجا ونجاة في الدنيا والآخرة ،   أو فصلا بين الحق والباطل أو يفرق بينكم وبين ما تخافون ،   أو ظهورا يعلى قدركم { ويكفر عنكم سيئاتكم } : يسترها عن أعين الناس { ويغفر لكم } لا يؤاخذكم بها { والله ذو الفضل العظيم } فبمحض إحسانه يفي بما وعدكم على التقوى .
