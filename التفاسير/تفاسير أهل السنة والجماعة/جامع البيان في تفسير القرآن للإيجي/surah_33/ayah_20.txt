{ يَحْسَبُونَ الْأَحْزَابَ لَمْ يَذْهَبُوا } : يحسب هؤلاء المنافقون لجبنهم أن الأحزاب لم ينهزموا وقد انهزموا ،   { وَإِن يَأْتِ الْأَحْزَابُ } : كرة ثانية مع ما رأوا من كيفية فرارهم وعدم ظهورهم وقرارهم ،   { يَوَدُّوا } : تنموا ،   { لَوْ أَنَّهُم بَادُونَ } : خارجون إلى البدو ،   { فِي الْأَعْرَابِ } : حاصلون فيهم ،   { يَسْأَلُونَ } : الناس ،   { عَنْ أَنبَائِكُمْ } يعني : يتمنون إن لم يكونوا بينكم ويسألوا الناس عما جرى عليكم ،   { وَلَوْ كَانُوا فِيكُم } ،   هذه الكَرّة ولم يفرّوا ولم يرجعوا إلى المدينة ،   { مَّا قَاتَلُوا إِلَّا قَلِيلًا{[4064]} } : رياء .
