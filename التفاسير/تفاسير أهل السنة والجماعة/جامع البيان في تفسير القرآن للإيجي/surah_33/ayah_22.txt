{ وَلَمَّا رَأَى الْمُؤْمِنُونَ الْأَحْزَابَ قَالُوا هَذَا مَا وَعَدَنَا اللَّهُ وَرَسُولُهُ } عن ابن عباس وغيره يعنون قوله تعالى : { أم حسبتم أن تدخلوا الجنة ولما يأتكم مثل الذين خلوا من قبلكم } [ البقرة : 214 ] ،   { وَصَدَقَ اللَّهُ وَرَسُولُهُ{[4068]} } : في الوعد ،   { وَمَا زَادَهُمْ } ذلك البلاء والضيق ،   { إِلَّا إِيمَانًا } بالله ،   { وَتَسْلِيمًا } : انقيادا لأوامره ،
