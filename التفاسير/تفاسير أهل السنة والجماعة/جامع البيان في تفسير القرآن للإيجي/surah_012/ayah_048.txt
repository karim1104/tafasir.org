{ ثُمَّ يَأْتِي مِن بَعْدِ ذَلِكَ } : السبيع ،   { سَبْعٌ شِدَادٌ يَأْكُلْنَ } : أصناف الأكل إلى السنين وهو لأهلهن على المجاز ،   { مَا قَدَّمْتُمْ لَهُنَّ } : ما ادخرتم لأجلهن ،   { إِلاَّ قَلِيلاً مِّمَّا تُحْصِنُونَ } تحرزون للبذر والظاهر أن قوله :  " تزرعون "  على أصله بدليل قوله :  " ثم يأتي "  لا أنه{[2416]} خبر بمعنى الأمر وقوله :  " فما حصدتم "  اعترض لاهتمامه عليه الصلاة والسلام بشأنهم يأمرهم بما فيه صلاحهم في أثناء التأويل .
