{ وَرَاوَدَتْهُ الَّتِي هُوَ فِي بَيْتِهَا عَن نَّفْسِهِ } : طلبت{[2379]}منه أن يواقعها ،   { وَغَلَّقَتِ الأَبْوَابَ } وكانت سبعة ،   { وَقَالَتْ هَيْتَ لَكَ } : أقبل وبادر اسم فعل واللام للتبيين كما في سقيا لك ،   { قَالَ مَعَاذَ اللّهِ } : أعوذ بالله معاذا ،   { إِنَّهُ } ،   أي : الشأن ،   { رَبِّي } : سيدي الذي اشتراني ،   { أَحْسَنَ مَثْوَايَ } : أكرمني فلا أخونه وقيل إن الله ربي أحسن منزلتي فلا أعصيه ،   { إِنَّهُ لاَ يُفْلِحُ الظَّالِمُونَ } : المجازون الحسن بالسيئ أو يسعد الزناة .
