{ وَلَقَدْ هَمَّتْ {[2380]}بِهِ } : قصدت مخالطته ،   { وَهَمَّ بِهَا } : قصد مخالطتها لميل الطبع والشهوة الغير الاختياري ،   { لَوْلا أَن رَّأَى بُرْهَانَ رَبِّهِ } : جوابه{[2381]} محذوف أي : لخالطها وما ذكره أكثر السلف هو أن رأى صورة أبيه عاضا على أصبعه{[2382]} يعظه ،   { كَذَلِكَ } : مثل ذلك التثبيت ثبتناه ،   { لِنَصْرِفَ عَنْهُ السُّوءَ } : خيانة صاحبه ،   { وَالْفَحْشَاء } : الزنا ،  { إِنَّهُ مِنْ عِبَادِنَا الْمُخْلَصِينَ } ،   من الذين أخلصهم الله تعالى لعبادته .
