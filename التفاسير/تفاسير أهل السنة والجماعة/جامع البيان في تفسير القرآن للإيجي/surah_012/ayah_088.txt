{ فَلَمَّا دَخَلُواْ } : بعدما رجعوا إلى مصر ،   { عَلَيْهِ قَالُواْ يَا أَيُّهَا الْعَزِيزُ مَسَّنَا وَأَهْلَنَا الضُّرُّ } : شدة الجوع ،   { وَجِئْنَا بِبِضَاعَةٍ{[2460]} مُّزْجَاةٍ } : رديئة أو قليلة كانت دراهم رديئة أو الغرايئر والحبائل أو الصوف والأقط أو حبة الخضراء أو الأدم والنعال ،   { فَأَوْفِ لَنَا الْكَيْلَ } : أتمه لنا ،   { وَتَصَدَّقْ عَلَيْنَا } : برد أخينا أو بقبض هذه البضاعة المزجاة أو بالزيادة على ما يساويها ،   { إِنَّ اللّهَ يَجْزِي الْمُتَصَدِّقِينَ } : أحسن الجزاء .
