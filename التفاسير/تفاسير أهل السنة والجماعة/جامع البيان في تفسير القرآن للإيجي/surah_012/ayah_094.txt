{ وَلَمَّا فَصَلَتِ } : خرجت ،   { الْعِيرُ } : من مصر{[2466]} ،   { قَالَ أَبُوهُمْ } : لمن حضره{[2467]} ،   { إِنِّي لَأَجِدُ رِيحَ يُوسُفَ } هاجت ريح فجاءت برائحة قميصه من مسيرة ثمانية أيام ،   { لَوْلاَ أَن تُفَنِّدُونِ{[2468]} } أي : لولا تسفهوني وتنسبوني إلى نقصان عقل للهرم لصدقتموني وجواب لولا محذوف .
