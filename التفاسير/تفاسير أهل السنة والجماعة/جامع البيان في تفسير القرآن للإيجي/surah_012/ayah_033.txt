{ قَالَ رَبِّ السِّجْنُ أَحَبُّ إِلَيَّ مِمَّا يَدْعُونَنِي إِلَيْهِ } : من المعصية أصناف الدعوة إليهن تنصحن له مطاوعتها ،   { وَإِلاَّ } أي : وإن لم ،   { تَصْرِفْ عَنِّي كَيْدَهُنَّ أَصْبُ } : أمل ،   { إِلَيْهِنَّ } بإجابة كلامهن ،   وقيل : إنهن جميعا دعونه إلى أنفسهن ،   { وَأَكُن مِّنَ الْجَاهِلِينَ{[2392]} } : من السفهاء الذين يعملون القبائح .
