{ رَبِّ{[2473]} قَدْ آتَيْتَنِي مِنَ الْمُلْكِ } أي : بعضه وهو ملك مصر ،   { وَعَلَّمْتَنِي مِن تَأْوِيلِ الأَحَادِيثِ } : بعض تعبير الرؤيا ،   { فَاطِرَ } : مبدع ،   { السَّمَاوَاتِ وَالأَرْضِ } : منصوب بالمنادى ،   { أَنتَ وَلِيِّي } : ناصري ومتولى أمري ،   { فِي الدُّنُيَا وَالآخِرَةِ وتَوَفَّنِي } : اقبضني ،   { مُسْلِمًا وَأَلْحِقْنِي بِالصَّالِحِينَ{[2474]} } : من آبائي وغيرهم سأل الوفاة على الإسلام واللحاق بالصالحين إذا حان أجله وانقضى عمره وكلام بعض السلف وهو أنه ما تمنى نبي قط الموت قبل يوسف عليه السلام يشعر بأنه سأل منجزا وهو جائز في ملتهم ويحتمل أن مراده أنه أول من سأل الوفاة على الإسلام كما أن نوحا عليه السلام أول من قال :  " رب اغفر لي ولوالدي ولمن دخل بيتي "  الآية ( نوح :28 ) ،   وقالوا : أقام يعقوب عند يوسف أربعا وعشرين سنة ثم مات وحمل جسده الشريف عند أبيه إسحاق عليه السلام بالشام .
