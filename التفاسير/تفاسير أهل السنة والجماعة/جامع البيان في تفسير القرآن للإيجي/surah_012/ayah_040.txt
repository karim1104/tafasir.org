{ ما تَعْبُدُونَ مِن دُونِهِ } : من دون الله خطاب لهما ولمن على دينهما ،   { إِلاَّ أَسْمَاء سَمَّيْتُمُوهَا أنتم وَآبَاؤُكُم } إلا أسماء خالية عن المعنى لا مسميات تحتها فإنهم سموا ما لا يستحق الإلهية آلهة ثم يعبدونها ،   { مَّا أَنزَلَ اللّهُ بِهَا } : بتسميتها ،   { مِن سُلْطَانٍ } : حجة ،   { إِنِ الْحُكْمُ } : الأمر والنهي ،   { إِلاَّ لِلّهِ أَمَرَ } : على لسان أنبيائه ،   { أَلاَّ تَعْبُدُواْ إِلاَّ إِيَّاهُ ذَلِكَ الدِّينُ الْقَيِّمُ } المستقيم الذي لا عوج فيه ،   { وَلَكِنَّ أَكْثَرَ النَّاسِ لاَ يَعْلَمُونَ } : فيهلكون في جهالتهم .  <br />
