{ وَإِن {[2542]}مَّا نُرِيَنَّكَ بَعْضَ الَّذِي نَعِدُهُمْ } ،   أي : كيفما دارت الحال أريناك بعض ما أوعدناهم من عذابهم ،   { أَوْ نَتَوَفَّيَنَّكَ } : قبل نزول عذابهم ،   { فإنمَا عَلَيْكَ الْبَلاَغُ } : ما يجب عليك إلا تبليغ الرسالة ،   { وَعَلَيْنَا } : عليك ،   { الْحِسَابُ } ،   أي : حسابهم وجزاؤهم فلا تستعجل بعذابهم ولا يهمنك إعراضهم ،
