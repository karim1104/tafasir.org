{ وَالَّذِينَ آتَيْنَاهُمُ الْكِتَابَ } المراد مسلموا أهل الكتاب من اليهود والنصارى ،   { يَفْرَحُونَ بِمَا أُنزِلَ إِلَيْكَ } : من القرآن لما في كتبهم من الشواهد على صدقه ،   { وَمِنَ الأَحْزَابِ } أي : ومن أحزاب اليهود والنصارى ،   { مَن يُنكِرُ بَعْضَهُ } أي : ما يخالف كتبهم أو رأيهم ،   قال بعضهم : هذا في مؤمني أهل الكتاب حزنوا بقلة ذكر لفظ الرحمن في القرآن مع كثرة ذكره في التوراة فلما نزل  " قل ادعوا الله أو ادعوا الرحمن "  ( الإسراء :110 ) ،   فرحوا و كفر المشركون به فقالوا : وما الرحمن ،   { قُلْ } : لهم ،   { إِنَّمَا أُمِرْتُ أَنْ أَعْبُد{[2536]} اللّهَ } : وحده ،   { وَلا أُشْرِكَ بِهِ إِلَيْهِ أَدْعُو } : لا إلى غيره ،   { وَإِلَيْهِ } : لا إلى غيره ،   { مَآبِ } : مرجعي للجزاء ،   يعني قل لهم : هذا شغلي و أمري حتى يعلموا أن إنكارهم عبادة الله مع ادعائهم واتفاقهم وجوبها .
