{ يَمْحَقُ اللّهُ الْرِّبَا } : يذهب بركته ،   فلا ينتفع في الدنيا والآخرة به ،   قد ورد :  " ما أحد أكثر من الربا إلا كان عاقبة أمره إلى قلة {[559]} "  { وَيُرْبِي الصَّدَقَاتِ } : يكثرها وينميها ،   وقد {[560]} ورد  " إن الله ليربي لأحدكم التمرة واللقمة ،   كما يربي أحدكم فلوه أو فصيله حتى يكون مثل أحد {[561]} "  ،   { وَاللّهُ لاَ يُحِبُّ } : لا يرتضي ،   { كُلَّ كَفَّارٍ } : مصر على تحليل الحرام { أَثِيمٍ } : فاجر بارتكابه .
