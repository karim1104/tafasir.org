{ قَدْ نَرَى تَقَلُّبَ وَجْهِكَ فِي السَّمَاء } ،   أي : تردد وجهك في جهة السماء انتظاراً لجبريل والوحي بتغيير القبلة ،   فإنه يحب أن تكون  " قبلة "  قبلة أبيه إبراهيم ،   { فَلَنُوَلِّيَنَّكَ } ،   نمكنك استقبال قبلة من وليته كذا ،   أي صيرته واليا له ،   { قِبْلَةً تَرْضَاهَا } ،   تحبها ،   { فَوَلِّ } : اصرف ،   { وَجْهَكَ شَطْرَ الْمَسْجِدِ الْحَرَامِ } ،   أي : نحوه ،   { وَحَيْثُ مَا كُنتُمْ } ،   من بر وبحر ،   وهو بمعنى الشرط ،   أي : أينما كنتم {[242]} فالفاء ،   { فَوَلُّواْ } ،   للجزاء ،   { وُجُوِهَكُمْ شَطْرَهُ } ،   حين الصلاة ،   { وَإِنَّ الَّذِينَ أُوْتُواْ الْكِتَابَ } : اليهود ،   { لَيَعْلَمُونَ أَنَّهُ } : أمر الكعبة ،   { الْحَقُّ مِن رَّبِّهِمْ } ،   ليقينهم بحقية محمد عليه الصلاة والسلام ،   وبأن الكعبة قبلة إبراهيم ،   { وَمَا اللّهُ بِغَافِلٍ عَمَّا يَعْمَلُونَ }
