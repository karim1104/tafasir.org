{ فَأَزَلَّهُمَا الشَّيْطَانُ عَنْهَا } : الضمير للشجرة ،   أي : حملهما على الزلة بسببها أو للجنة أي فبعدهما عن الجنة ،   { فَأَخْرَجَهُمَا مِمَّا كَانَا فِيهِ } : من النعيم والكرامة ،   { وَقُلْنَا اهْبِطُواْ } : انزلوا على الأرض جمع الضمير لأنهما أصلا الإنس فكأنهما الجنس أو المراد هما والشيطان { بَعْضُكُمْ لِبَعْضٍ عَدُوٌّ } أي : متعادين والعداوة بين ذريتهما لقوله تعالى : (  قال اهبطا منها جميعا بعضكم لبعض عدو (  {[76]} ،   أو بين المؤمنين والشيطان ،   { وَلَكُمْ فِي الأَرْضِ مُسْتَقَرٌّ } : موضع قرار { وَمَتَاعٌ } : تمتع { إِلَى حِينٍ } : الموت وقيل القيامة .
