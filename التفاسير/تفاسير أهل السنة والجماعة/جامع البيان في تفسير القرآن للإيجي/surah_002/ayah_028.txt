{ كَيْفَ تَكْفُرُونَ بِاللَّهِ } : معناه التعجب أي : أخبروني على أي حال تكفرون ،   { وَكُنتُمْ أَمْوَاتاً } : تراباً أو نطفاً في أصلاب الآباء ،   { فَأَحْيَاكُمْ } : بخلق الحياة فيكم أو في الأرحام ،   ومعنى الفاء في الثاني أظهر ،   { ثُمَّ يُمِيتُكُمْ } : في الدنيا ،   { ثُمَّ يُحْيِيكُمْ } : عند نفخ الصور ،   { ثُمَّ إِلَيْهِ تُرْجَعُونَ } : بعد الحشر لجزاء العمل .  <br />
