{ وَإِذْ أَخَذْنَا مِيثَاقَكُمْ } : في التوراة ،   { لاَ تَسْفِكُونَ دِمَاءكُمْ } : بأن لا يقتل بضعكم بعضاً ،   { وَلاَ تُخْرِجُونَ أَنفُسَكُم مِّن دِيَارِكُمْ } : ولا يخرجه من منزله ،   { ثُمَّ أَقْرَرْتُمْ {[129]} } ،   اعترفتم بلزوم الميثاق ،   { وَأَنتُمْ تَشْهَدُونَ } : على أنفسكم بذلك أو أنتم أيها الموجودون تشهدون على إقرار أسلافكم .
