{ آمَنَ الرَّسُولُ بِمَا أُنزِلَ إِلَيْهِ مِن رَّبِّهِ وَالْمُؤْمِنُونَ } وجه نزول الآية قد ذكرناه وهو أنهم قالوا :  " سمعنا وأطعنا "  لا كما قال أهل الكتاب :  " سمعنا وعصينا "  {[584]} قوله :  " والمؤمنون "  عطف على الرسول ،   { كُلٌّ } : من الرسول والمؤمنين ،   { آمَنَ بِاللّهِ وَمَلآئِكَتِهِ وَكُتُبِهِ وَرُسُلِهِ } يقولون ،   { لاَ نُفَرِّقُ بَيْنَ أَحَدٍ مِّن رُّسُلِهِ } في الإيمان بهم ،   ولا نقول :  " نؤمن ببعض ونكفر ببعض "  {[585]} ،   { وَقَالُواْ سَمِعْنَا } ،   قول الله ،   { وَأَطَعْنَا } أمره ،   نسأل ،   أو اغفر ،   { غُفْرَانَكَ رَبَّنَا وَإِلَيْكَ الْمَصِيرُ } : المرجع بعد الموت .
