{ قُلْنَا اهْبِطُواْ مِنْهَا جَمِيعاً } كرر للتأكيد وليترتب عليه قوله { فَإِمَّا يَأْتِيَنَّكُم } : يا بني آدم ،   { مِّنِّي هُدًى } أنبياء والبيان ،   { فَمَن تَبِعَ هُدَايَ } : أقبل على الهدى وقبل { فَلاَ خَوْفٌ عَلَيْهِمْ } حين يشتد الأمر على العصاة ،   { وَلاَ هُمْ يَحْزَنُونَ } على ما فاتهم من أمور الدنيا ،   والشرط الثاني مع جوابه جواب للشرط الأول .  <br />
