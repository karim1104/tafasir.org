{ وَإِذَا قِيلَ لَهُمْ آمِنُواْ كَمَا آمَنَ النَّاسُ } : المهاجرون والأنصار أو مؤمنو أهل الكتاب ،   { قَالُواْ أَنُؤْمِنُ كَمَا آمَنَ السُّفَهَاء } : الهمزة للإنكار واللام {[36]} للناس والسفه خفة رأى وهذا قول سرهم فيما بينهم فأفضحهم الله ،   { أَلا إِنَّهُمْ هُمُ السُّفَهَاء وَلَكِن لاَّ يَعْلَمُونَ } .
