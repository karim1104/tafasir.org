{ فَجَعَلْنَاهَا } : المسخة أو القردة أو القرية ،   { نَكَالاً } : عبرة ،   { لِّمَا بَيْنَ يَدَيْهَا } : لمعاصريهم أو لما بحضرتها من القرى أو لأهل {[100]} تلك القرية أو لأجل ما تقدم  من ذنوبهم وهو قول كثير من السلف ،   { وَمَا خَلْفَهَا } ،   من بعدهم أو ما تباعد عنها أو ما حواليها أو لما تأخر من الذنوب {[101]} ،   { وَمَوْعِظَةً } : وزجراً ،   { لِّلْمُتَّقِينَ {[102]} } : الذين من بعدهم إلى يوم القيامة .
