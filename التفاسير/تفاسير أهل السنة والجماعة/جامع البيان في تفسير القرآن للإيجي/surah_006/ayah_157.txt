{ أو تقولوا } ،   عطف على ما تقولوا ،   { لو أنّا أُنزل علينا الكتاب لكنا أهدى منهم فقد جاءكم بينة{[1558]} من ربكم } أي : إن صدقتم{[1559]} فيما قلتم فقد جاءتكم حجة واضحة فيها بيان الحلال والحرام ،   { وهدى ورحمة } : لمن عمل به ،   { فمن أظلم ممن كذّب بآيات الله } : بعد ما تمكن من معرفته ،   { وصدف عنها } : أعرض أو صد الناس عنها ،   { سنجزي الذين يصدفون عن آياتنا سوء العذاب بما كانوا يصدفون } : بسبب إعراضهم أو صدهم .
