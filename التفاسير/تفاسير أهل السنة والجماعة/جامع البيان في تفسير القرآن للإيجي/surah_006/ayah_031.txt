{ قد خسر الذين كذّبوا بلقاء الله } : بالبعث ،   وما يتبعه ،   { حتى إذا جاءتهم الساعة } : غاية لكذبوا ،   أو من مات فقد قامت قيامته ،   { بغتة } : فجأة ،   مفعول مطلق لأنها نوع من المجيء أو حال ،   { قالوا يا حسرتنا{[1384]} } : تعالى فهذا أوانك ،   { على ما فرّطنا } : قصرنا ،   { فيها } : في الدنيا أو في الساعة أي : في شأنها ،   { وهم يحملون أوزارهم } : آثامهم ،   { على ظهورهم } : تمثل ذنوبهم بأقبح صورة منتنة فتركب عليهم وتسوقهم{[1385]} إلى النار ،   { ألا ساء ما يزرون } : بئس شيئا يزرونه وزرهم .
