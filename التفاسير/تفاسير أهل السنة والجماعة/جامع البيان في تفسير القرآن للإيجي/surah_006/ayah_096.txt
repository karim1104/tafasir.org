{ فالق{[1484]} الإصباح{[1485]} } : شاق عمود الصبح عن ظلمة الليل ،   { وجعل الليل } ،   إعمال اسم الفاعل ،   لأنه بمعنى الدوام التجددي نحو :<br />
( ولقد أمر على اللئيم يسبني ){[1486]}<br />
لا بمعنى الثبوت الدائمي ك( مالك يوم الدين ) ( الفاتحة : 4 ) ،   { سكَنًا } : يسكن فيه خلقه ،   ويستريح ،   { والشمس والقمر حسبانا{[1487]} } أي : تجريان بحساب معين لا تتجاوزان ،   أو معناه جعلهما علمى حسبان ،   لأن حساب الأوقات يعرف بدورهما ،   { ذلك } أي : المذكور من فلق الصبح ،   وجعل الليل ،   والشمس ،   والقمر ،   { تقدير العزيز } : الذي يفعل ما يريد ،   { العليم } : بما قدر وأراد .
