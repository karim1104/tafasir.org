{ وَالْقَوَاعِدُ مِنَ النِّسَاء } : العجائز اللاتي قعدن عن الحيض ،   { اللَّاتِي لَا يَرْجُونَ نِكَاحًا } : لا يطمعن فيه لكبرهن ،   { فَلَيْسَ عَلَيْهِنَّ جُنَاحٌ أَن يَضَعْنَ ثِيَابَهُنَّ } : الثياب الظاهرة كالجلباب يعني ليس على العجائز من التستر ما على غيرها من النساء ،   { غَيْرَ مُتَبَرِّجَاتٍ } : مظاهرات ،   { بِزِينَةٍ } ،   أمر بإخفائها أو غير قاصدات بوضع الثياب{[3569]} تبرج الزينة ،   { وَأَن يَسْتَعْفِفْنَ } :فلا يضعن الجلباب أيضا ،   { خَيْرٌ لَّهُنَّ } : لأنه أبعد من التهمة ،   { وَاللَّهُ سَمِيعٌ } : لمقالهن للرجال ،   { عَلِيمٌ } : بمقاصدهن ،
