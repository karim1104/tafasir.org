{ وَأَقْسَمُوا{[3555]} بِاللَّهِ جَهْدَ{[3556]} أَيْمَانِهِمْ } : قسما غليظا ،   { لَئِنْ أَمَرْتَهُمْ } : بالخروج إلى الغزو ،   { لَيَخْرُجُنّ } ،   جواب لأقسموا ،   { قُل } : لهم ،   { لَّا تُقْسِمُوا } : على الكذب ،   { طَاعَةٌ مَّعْرُوفَةٌ } ،   أي : طاعتكم طاعة مشهورة معلومة بأنها قول لا فعل معه ،   أو الذي يطلب منكم طاعة معروفة لا إيمان بمجرد الأفواه أو طاعة معروفة أولى وأمثل من هذا الإيمان ،   { إِنَّ اللَّهَ خَبِيرٌ بِمَا تَعْمَلُونَ } : فلا يخفي عليه سرائركم ،
