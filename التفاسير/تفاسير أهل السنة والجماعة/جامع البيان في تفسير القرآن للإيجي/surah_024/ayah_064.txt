{ أَلَا إِنَّ لِلَّهِ مَا فِي السَّمَاوَاتِ وَالْأَرْضِ } : ملكا وخلقا ،   { قَدْ يَعْلَمُ مَا أَنتُمْ{[3590]} عَلَيْهِ } ،   من النفاق والإخلاص أكد عمله بقد لتأكيد الوعيد يعني من خَلَقَ جميع الخلق وملكهم كيف يخفي عليه أحوال المنافقين ،   وإن اجتهدوا في الإخفاء ،   { وَيَوْمَ يُرْجَعُونَ } ،   المنافقون ،   { إِلَيْهِ } : للجزاء ،   يوم ظرف{[3591]} لقوله : { فَيُنَبِّئُهُم بِمَا عَمِلُوا } : بالمجازات ،   { وَاللَّهُ بِكُلِّ شَيْءٍ عَلِيمٌ{[3592]} } .
