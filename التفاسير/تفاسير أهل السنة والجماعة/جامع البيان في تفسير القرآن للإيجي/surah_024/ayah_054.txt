{ قُلْ أَطِيعُوا اللَّهَ وَأَطِيعُوا الرَّسُولَ فَإِن{[3557]} تَوَلَّوا } : تتولوا عن الطاعة ،   { فَإِنَّمَا عَلَيْهِ } : على محمد : { مَا حُمِّلَ } : من تبليغ الرسالة ،   فإذا أدى خرج عن عهدته ،   { وَعَلَيْكُم مَّا حُمِّلْتُمْ } : من القبول فإن أعرضتم فقد تعرضتم لسخط الله ،   { وَإِن تُطِيعُوهُ تَهْتَدُوا } : إلى الحق ،   { وَمَا عَلَى الرَّسُولِ إِلَّا الْبَلَاغُ الْمُبِينُ } : التبليغ الموضح فضرر عدم القبول ليس إلا لكم ،
