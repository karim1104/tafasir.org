{ قَالَ } فرعون : { آمَنتُمْ لَهُ } أي : لموسى واللام لتضمين معنى الإتباع { قَبْلَ أَنْ آذَنَ لَكُمْ } : في اتباعه { إِنَّهُ لَكَبِيرُكُمُ } : أستاذكم { الَّذِي{[3175]} عَلَّمَكُمُ السِّحْرَ فَلَأُقطِّعَنَّ أَيْدِيَكُمْ وَأَرْجُلَكُم مِّنْ خِلَافٍ } أي : مختلفات من اليد اليمنى ومن الرجل اليسرى ،   ومن للابتداء ،   فإن القطع ناشئ من مخالفة العضو العضو .   أي من وضع المخالفة فقد لابس المخالفة أيضا وقيل من أجل خلاف ظهر منكم { وَلَأُصَلِّبَنَّكُمْ فِي جُذُوعِ النَّخْلِ } أي : عليها شبه تمكن المصلوب بالجذوع بيتمكن المظروف بالظرف ،   فقال : قي جذوع { وَلَتَعْلَمُنَّ أَيُّنَا } : أنا أو موسى وأراد به الهزء فإنه لم يكن من التعذيب في شيء وقيل أينا أي : أنا أو رب موسى الذي ّآمنتم به { أَشَدُّ عَذَابًا وَأَبْقَى } .
