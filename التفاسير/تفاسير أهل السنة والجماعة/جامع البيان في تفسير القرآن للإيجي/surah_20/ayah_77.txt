{ وَلَقَدْ أَوْحَيْنَا إِلَى مُوسَى أَنْ أَسْرِ } ،   أن مفسرة أو مصدرية { بِعِبَادِي } : من مصر { فَاضْرِبْ } : اتخذ واجعل { لَهُمْ طَرِيقًا فِي الْبَحْرِ } : بأن تضرب البحر بعصاك { يَبَسًا } أي : طريقا يابسا { لَّا تَخَافُ دَرَكًا } أي : من أن يدركك فرعون حال من ضمير فاضرب ،   أو صفة ثانية لطريقا ،   أي : طريقا لا تخاف فيه { وَلَا تَخْشَى } ،   من قرأ لا تخف بالجزم{[3179]} فلا تخشى إما استئناف ،   أي : وأنت لا تخشى ،   أو عطف على لا تخف والألف زائدة للفاصلة كالظنونا .
