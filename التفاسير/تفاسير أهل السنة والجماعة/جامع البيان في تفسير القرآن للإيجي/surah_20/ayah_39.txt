{ أَنِ اقْذِفِيهِ } : بأن ألقيه وضعيه .   { فِي التَّابُوتِ فَاقْذِفِيهِ فِي الْيَمِّ } : بحر النيل { فَلْيُلْقِهِ الْيَمُّ بِالسَّاحِلِ } جعل البحر كأنه ذو تمييز فأمره وأخرج الجواب مخرج الأمر { يَأْخُذْهُ عَدُوٌّ لِّي وَعَدُوٌّ لَّهُ{[3152]} } جواب فيلقيه وتكرير عدو للمبالغة .   { وَأَلْقَيْتُ عَلَيْكَ مَحَبَّةً } : كائنة { مِّنِّي } قد ركزتها في القلوب ،   يحبك كل من يراك ،   أو مني ظرف لألقيت ،   أي : أحببتك ومن أحبه الله أحبته القلوب { وَلِتُصْنَعَ عَلَى عَيْنِي } : لتربى و يحسن إليك بمرأى ،   ومنظر مني كما يراعى الرجل الشيء بعينيه إذا اعتنى به ،   تقديره ليتعطف{[3153]} عليك ولتصنع ،   أو تقديره ولتصنع فعلت ذلك .
