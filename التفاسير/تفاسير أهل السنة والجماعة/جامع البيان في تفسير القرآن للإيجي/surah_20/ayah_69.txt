{ وَأَلْقِ مَا فِي يَمِينِكَ } لم يقل عصاك تحقيرا لها أي العويدة التي في يدك ولا تبال بعصيهم { تَلْقَفْ } تبتلع جواب الأمر وقراءة تلقف بالرفع أي : تتلقف فبالحال أو الاستئناف .   { مَا صَنَعُوا إِنَّمَا صَنَعُوا } أي : إن الذي زوروا { كَيْدُ سَاحِر } ،   وحد الساحر لأن المراد به الجنس ،   وقراءة سحر كعلم فقه بأن الإضافة للبيان أو جعل الساحر سحر للمبالغة ٍ{ وَلَا يُفْلِحُ السَّاحِرُ حَيْثُ أَتَى } : حيث كان .  <br />
