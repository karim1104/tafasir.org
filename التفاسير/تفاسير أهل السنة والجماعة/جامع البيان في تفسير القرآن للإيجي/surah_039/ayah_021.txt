{ ألم تر أن الله أنزل من السماء ماء فسلكه } : نظمه { ينابيع } : عيونا ،   ومجاري ،   نصب على الظرف ،   { في الأرض } ،   صفة ينابيع ،   { ثم يخرج به } : بالماء ،   { زرعا مختلفا ألوانه } : أصفر ،   وأحمر وأخضر ،   أو أنواعه من بر وشعير وحمص ،   { ثم يهيج } : يتم جفافه ،   { فتراه مصفرا ثم يجعله حطاما } : خشبة مسودة ،   { إنّ في ذلك لذكرى } : لعظة ،   { لأولي الألباب } ،   فيعرف أنه مثل الحياة الدنيا ،   ويستدل به على كمال حكمته وقدرته .  <br />
