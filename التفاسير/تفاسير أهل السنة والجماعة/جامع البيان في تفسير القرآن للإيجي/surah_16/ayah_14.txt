{ وَهُوَ الَّذِي سَخَّرَ الْبَحْرَ } جعله بحيث تتمكنون من الانتفاع به ،   { لِتَأْكُلُواْ مِنْهُ لَحْمًا طَرِيًّا } أي : السمك ،   { وَتَسْتَخْرِجُواْ مِنْهُ حِلْيَةً } كاللؤلؤ والمرجان ،   { تَلْبَسُونَهَا وَتَرَى الْفُلْكَ مَوَاخِرَ } المخر شق الماء بصدرها أو صوت جري الفلك بالرياح ،   { فِيهِ وَلِتَبْتَغُواْ مِن فَضْلِهِ } سعة رزقه أي : سخر البحر للأكل والاستخراج والتجارة للربح ،   { وَلَعَلَّكُمْ تَشْكُرُونَ{[2685]} } نعمه وإحسانه .
