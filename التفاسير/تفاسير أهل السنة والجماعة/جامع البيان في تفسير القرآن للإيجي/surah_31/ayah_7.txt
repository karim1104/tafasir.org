{ وَإِذَا تُتْلَى عَلَيْهِ آيَاتُنَا وَلَّى } : أعرض عنها ،   { مُسْتَكْبِرًا } متكبرا ،   { كَأَن } أي : كأنه ،   { لَّمْ يَسْمَعْهَا } ،   حال أي : مشابها حاله بحاله أو استئناف ،   { كَأَنَّ فِي أُذُنَيْهِ وَقْرًا } ،   ثقلا مانعا عن الاستماع بدل من كان أو حال من فاعل لم يسمع أو استئناف ،   { فَبَشِّرْهُ بِعَذَابٍ أَلِيمٍ } فيه تهكم{[3989]} ،
