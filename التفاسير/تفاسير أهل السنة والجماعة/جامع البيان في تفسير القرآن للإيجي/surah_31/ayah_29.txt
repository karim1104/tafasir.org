{ أَلَمْ تَرَ أَنَّ اللَّهَ يُولِجُ اللَّيْلَ فِي النَّهَارِ } : فيطول النهار ويقصر الليل ،   { وَيُولِجُ النَّهَارَ فِي اللَّيْلِ وَسَخَّرَ الشَّمْسَ وَالْقَمَرَ كُلٌّ } : منهما ،   { يَجْرِي } : في فكله ،   { إِلَى أَجَلٍ مُّسَمًّى } : إلى وقت معين الشمس إلى آخر السنة ،   والقمر إلى آخر الشهر ،   أو الأجل المسمى يوم القيامة فحينئذ ينقطع جريهما ،   { وَأَنَّ اللَّهَ بِمَا تَعْمَلُونَ خَبِيرٌ ذَلِكَ } أي : اختصاصه تعالى بسعة العلم ،   وشمول القدرة ،   وعجائب الصنع ،   { بِأَنَّ اللَّهَ هُوَ الْحَقُّ } بسبب أنه الثابت إلاهيته ،   { وَأَنَّ مَا يَدْعُونَ مِن دُونِهِ الْبَاطِلُ } : إلاهيته ،   { وَأَنَّ اللَّهَ هُوَ الْعَلِيُّ الْكَبِير } مترفع ومتسلط على كل شيء أو معناه ذلك الذي أوحى إليك بسبب بيان أنه هو الحق وأن إلها غيره باطل وأنه علي كبير أن يشرك به .  <br />
