{ قَالَ يَا قَوْمِ أَرَأَيْتُمْ إِن كُنتُ عَلَى بَيِّنَةً } يقين وبصيرة ،   { مِّن رَّبِّي } وحرف الشك باعتبار المخاطبين ،   { وَآتَانِي مِنْهُ رَحْمَةً } نبوة ،   { فَمَن يَنصُرُنِي مِنَ اللّهِ } يمنعني من عذابه ،   { إِنْ عَصَيْتُهُ } في تبليغ الرسالة ،   { فَمَا تَزِيدُونَنِي } إذن حينئذ ،   { غَيْرَ تَخْسِيرٍ } غير أن تخسروا أعمالي وتبطلوا أو ما تزيدونني بما تقولون إلا أن أنسبكم إلى الخسران .  <br />
