{ فإن تَوَلَّوْاْ } تتولوا ،   { فَقَدْ أَبْلَغْتُكُم مَّا أُرْسِلْتُ بِهِ إِلَيْكُمْ } فلا على شيء فإني بلغت الرسالة وما على إلا الإبلاغ ،   { وَيَسْتَخْلِفُ رَبِّي قَوْمًا غَيْرَكُمْ } هذا وعيد بإهلاكهم واستخلاف قوم آخرين مطيعين في ديارهم ،   { وَلاَ تَضُرُّونَه } بإعراضكم ،   { شَيْئًا } من الضرر و قيل : لا تنقصونه شيئا إذا أهلككم ،   { إ ِنَّ رَبِّي عَلَىَ كُلِّ شَيْءٍ حَفِيظٌ } فيحفظ أعمالكم ويجازيكم أو هو الحافظ للأشياء فهو الضار النافع فيستحيل أن يضره أو هو الحافظ يحفظني من كيدكم .  <br />
