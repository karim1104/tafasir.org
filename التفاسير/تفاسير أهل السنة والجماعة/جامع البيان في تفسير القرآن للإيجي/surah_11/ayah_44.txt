{ وَقِيلَ } بعدما تناهى أمر الطوفان ،   { يَا أَرْضُ ابْلَعِي } أنشفي ،   { مَاءكِ وَيَا سَمَاء أَقْلِعِي } أمسكي عن المطر ،   { وَغِيضَ } نقص ،   { الْمَاء وَقُضِيَ الأَمْر } أي : إهلاك الكافرينُ وإنجاء المؤمنين ،   { وَاسْتَوَتْ } استقرت السفينة ،   { عَلَى الْجُودِيّ } جبل شامخ قريب الموصل أو الشام ،   { وَقِيلَ بُعْداً لِّلْقَوْمِ الظَّالِمِينَ } أي هلاكا لهم .  <br />
