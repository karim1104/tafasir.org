{ قَالَ يَا قَوْمِ أَرَهْطِي أَعَزُّ عَلَيْكُم مِّنَ اللّهِ } فإنكم تبقون علي لرهطي ولا تبقون علي لله وأنا رسوله ،   { وَاتَّخَذْتُمُوهُ } أي : الله ،   { وَرَاءكُمْ ظِهْرِيًّا } جعلتموه كالشيء الملقي وراء الظهر وهو منسوب إلى الظهر والكسر من تغيرات النسب كالإمسي في الأمس ،   { إِنَّ رَبِّي } ،   أي : علمه ،   { بِمَا تَعْمَلُونَ مُحِيطٌ } فيجازي عليه .  <br />
