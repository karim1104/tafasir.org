{ أَمَّنْ } بل أمّن ،   { خَلَقَ السَّمَاوَاتِ وَالْأَرْضَ } قيل : تقديره أما يشركون خير أمّن خلق السماوات والأرض ،   { وَأَنزَلَ لَكُم مِّنَ السَّمَاء مَاء فَأَنبَتْنَا بِهِ } عدل إلى التكلم ،   للتنبيه على أن الإنبات الذي هو عندكم من أنفع الأشياء مختص لا يقدر عليه غيره ،   { حَدَائِقَ ذَاتَ بَهْجَةٍ } : بساتين ذات حسن ،   { مَّا كَانَ لَكُمْ } ليس في قدرتكم ،   { أَن تُنبِتُوا شَجَرَهَا أَإِلَهٌ مَّعَ اللَّهِ } : أغيره يقرن به ،   { بَلْ هُمْ قَوْمٌ يَعْدِلُونَ } عن الحق ،  <br />
