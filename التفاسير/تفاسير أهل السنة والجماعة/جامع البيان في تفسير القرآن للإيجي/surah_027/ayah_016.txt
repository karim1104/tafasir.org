{ وَوَرِثَ سُلَيْمَانُ دَاوُودَ } نبوته ،   وعلمه وملكه دون سائر{[3746]} أولاده ،   { وَقَالَ } سليمان يعدد نعم الله عليه { يَا أَيُّهَا النَّاسُ عُلِّمْنَا{[3747]} مَنطِقَ الطَّيْرِ } : نفهم ما يقصد بصوته ،   { وَأُوتِينَا مِن كُلِّ شَيْءٍ{[3748]} } أي : أوتينا ما يحتاج إليه الملك ،   أو المراد الكثرة كما تقول : فلان يعلم كل شيء ،   { إِنَّ هَذَا لَهُوَ الْفَضْلُ الْمُبِينُ{[3749]} }
