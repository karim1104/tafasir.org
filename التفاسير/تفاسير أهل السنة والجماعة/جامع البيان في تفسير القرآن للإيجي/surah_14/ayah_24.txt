{ أَلَمْ {[2576]}تَرَ كَيْفَ ضَرَبَ اللّهُ } أي : قصد{[2577]} ،   { مَثَلاً } : ووضعه ،   { كلِمَةً طَيِّبَةً } هي كلمة التوحيد ،   ونصبها بتقدير جعل كلمة ،   ويكون تفسيرا لقوله ضرب الله ،   { كَشَجَرةٍ طَيِّبَةٍ } : هي النخلة{[2578]} أو شجرة في الجنة ،   { أَصْلُهَا ثَابِتٌ } : في الأرض ،   { وَفَرْعُهَا } : غصونها ورأسها ،   { فِي السَّمَاء } .
