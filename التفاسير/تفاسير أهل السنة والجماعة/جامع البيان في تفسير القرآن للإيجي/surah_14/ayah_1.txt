{ الَر كِتَابٌ } أي : هو كتاب ،   { أَنزَلْنَاهُ إِلَيْكَ لِتُخْرِجَ النَّاسَ } : بدعوتك إياهم إلى ما فيه ،   { مِنَ الظُّلُمَاتِ } : أنواع الضلال ،   { إِلَى النُّورِ } : الهدى ،   { بِإِذْنِ رَبِّهِمْ } : بأمره وتوفيقه ،   { إِلَى صِرَاطِ } بدل من إلى النور ،   { الْعَزِيزِ } : الغالب ،   { الْحَمِيد } : المستحق للحمد .  <br />
