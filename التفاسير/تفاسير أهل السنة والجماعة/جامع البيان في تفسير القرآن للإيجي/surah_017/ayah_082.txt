{ وَنُنَزِّلُ مِنَ الْقُرْآنِ } من للبيان قدم على المبين لكونه أهم ،   { مَا هُوَ شِفَاء } : لأمراض القلوب من الشك والنفاق والزيغ ،   { وَرَحْمَةٌ لِّلْمُؤْمِنِينَ } : يحصل في القلب الإيمان والحكمة والرغبة في الخير ،   { وَلاَ يَزِيدُ } : القرآن ،   { الظَّالِمِينَ } : الكافرين ،   { إَلاَّ خَسَارًا } : نقصانا وخذلانا لكفرهم به .  <br />
