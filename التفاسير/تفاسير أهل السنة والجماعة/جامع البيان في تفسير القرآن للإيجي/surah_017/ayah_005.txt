{ فَإِذَا جَاء وَعْدُ } : عقاب ،   { أُولاهُمَا } ،   أي : أولى الإفسادتين ،   { بَعَثْنَا عَلَيْكُمْ عِبَادًا لَّنَا } هم جالوت وجنوده ،   أو ملك الموصل سنجاريب أو بخت نصر فأذلهم وقهرهم وقتلهم ،   { أُوْلِي } : ذوي ،   { بَأْسٍ } : قوة ،   { شَدِيدٍ فَجَاسُواْ } : ترددوا لطلبكم ،   { خِلاَلَ } : وسط ،   { الدِّيَارِ } للقتل والغارة والسبي ،   { وَكَانَ وَعْدًا مَّفْعُولاً } فإنه قضاء مبرم .  <br />
