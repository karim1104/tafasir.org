{ وَتَوَكَّلْ عَلَى الْحَيِّ الَّذِي لَا يَمُوتُ } : في الاستغناء عن أجورهم واستكفاء شرورهم فإنه باق حقيق بالتوكل عليه ،   { وَسَبِّحْ } : نزهه عن كل نقص ،   { بِحَمْدِهِ } ،   ملتبسا مثنيا بنعوت كماله ،   { وَكَفَى بِهِ } : كفى{[3639]} الله ،   { بِذُنُوبِ عِبَادِهِ خَبِيرًا } : مطلعا فلا عليك إن آمنوا أو كفروا ،
