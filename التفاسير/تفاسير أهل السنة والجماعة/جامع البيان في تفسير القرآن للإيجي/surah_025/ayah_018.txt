{ قَالُوا سُبْحَانَكَ } : تعجب منهم مما قيل لهم ،   أو سبحانك من أن يكون لك ند ،   { مَا كَانَ يَنبَغِي } : ما يصح ويستقيم ،   { لَنَا أَن نَّتَّخِذَ مِن دُونِكَ مِنْ أَوْلِيَاء } أي : نحن لا نعبد إلا أنت ،   فيكف ندعو أحدا أن يتولى غيرك ؟ قيل : أرادوا من ضمير المتكلم جميع الخلائق ،   { وَلَكِن مَّتَّعْتَهُمْ وَآبَاءهُمْ } : في الدنيا بالنعم ،   { حَتَّى نَسُوا الذِّكْرَ } أي : نسوا ما أنزلته إليهم أو غفلوا عن ذكرك ،   { وَكَانُوا } : في علمك ،   { قَوْمًا بُورًا } ،   : هالكين أشقياء راعوا الأدب ،   وما قالوا : أنت أضللتهم صريحا ،   لأن المقام غير مقام البسط{[3606]}( * ) كما قال موسى في مقام الانبساط : { إن هي إلا فتنتك } [ الأعراف : 155 ] ،
