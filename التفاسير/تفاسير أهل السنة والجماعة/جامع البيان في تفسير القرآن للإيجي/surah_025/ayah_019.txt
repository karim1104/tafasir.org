{ فَقَدْ{[3607]} كَذَّبُوكُم } التفات ،   أي : قال الله لهم فقد كذبكم المعبودون ،   { بِمَا تَقُولُونَ } : في قولكم ،   إنهم آلهة أو هؤلاء أضلونا ،   فالباء بمعنى في أو بما تقولون بدل اشتمال من مفعول كذبوا ككذبوا بالحق ،   وفي قراءة ( يقولون ) بالياء فمعناه كذبوكم بقولهم : { سبحانك ما كان ينبغي } إلخ ،   { فَمَا تَسْتَطِيعُونَ صَرْفًا } : للعذاب عنكم ،   { وَلَا نَصْرًا } وقراءة التاء فمعناه ،   فما تستطيعون أيها العابدون صرف العذاب عن أنفسكم ولا نصر أنفسكم ،   { وَمَن يَظْلِم } ،   يشرك{[3608]} ،   { مِّنكُمْ نُذِقْهُ عَذَابًا كَبِيرًا }
