{ اللَّهُ الَّذِي يُرْسِلُ الرِّيَاحَ فَتُثِيرُ سَحَابًا } : تخرجه من أماكنه ،   { فَيَبْسُطُهُ فِي السَّمَاء } : في سمتها ،   { كَيْفَ يَشَاء } : سائرا ووافقا مطبقا وغيره إلى غير ذلك ،   { وَيَجْعَلُهُ كِسَفًا } أي : تارة يبسطه وتارة يجعله قطعا ،   { فَتَرَى الْوَدْقَ } : المطر ،   { يَخْرُجُ } : في التارتين ،   { مِنْ خِلَالِهِ } : وسطه ،   { فَإِذَا أَصَابَ بِهِ مَن يَشَاء مِنْ عِبَادِهِ إِذَا هُمْ يَسْتَبْشِرُونَ } فاجأوا بالاستبشار ،  <br />
