{ أَوَلَمْ يَسِيرُوا فِي الْأَرْضِ } : ألم يسافروا ؟ ! { فَيَنظُرُوا كَيْفَ كَانَ عَاقِبَةُ الَّذِينَ مِن قَبْلِهِمْ } : فينظروا مصارع الأمم السالفة المكذبة ،   فيعتبروا ،   { كَانُوا أَشَدَّ مِنْهُمْ قُوَّةً } ،   كعاد وثمود ،   { وَأَثَارُوا الْأَرْضَ } ،   قلبوها للزراعة ،   { وَعَمَرُوهَا } : بالأبنية أو بالزراعة ،   { أَكْثَرَ مِمَّا عَمَرُوهَا } ،   فإنهم في واد غير ذي زرع ،   { وَجَاءتْهُمْ رُسُلُهُم بِالْبَيِّنَاتِ } : فكذبوهم ،   { فَمَا كَانَ اللَّهُ لِيَظْلِمَهُمْ } ،   فإنه حرم الظلم على نفسه ،   { وَلَكِن كَانُوا أَنفُسَهُمْ يَظْلِمُونَ } ،   حيث عملوا ما استحقوا{[3943]} به التدمير ،
