{ وَلَمَّا أَن جَاءتْ } أن صلة زيدت لاتصال الفعلين ،   وتأكيدهما { رُسُلُنَا لُوطًا } بعدما ساروا من عند إبراهيم في صورة أمارد حسان { سِيءَ بِهِمْ } جاءته المساءة والغم بسببهم { وَضَاقَ{[3915]} بِهِمْ ذَرْعًا } أي : عجز وضاق بسببهم وتدبير أمرهم طاقته فإنه خاف عليهم من قومه { وَقَالُوا } لما رأوا غمه { لَا تَخَفْ } علينا { وَلَا تَحْزَنْ إِنَّا مُنَجُّوكَ وَأَهْلَكَ } نصب أهلك لعطفه على محل الكاف أو بإضمار فعل { إِلَّا امْرَأَتَكَ كَانَتْ مِنَ الْغَابِرِينَ }
