{ وَوَصَّيْنَا الْإِنسَانَ بِوَالِدَيْهِ } بإيتاء أو بإيلاء والديه { حُسْنًا } أي : فعلا ذا حسن أو للمبالغة جعل الفعل حسنا لفرط حسنه ،   قيل تقديره : وصيناه بتعهد{[3896]} الوالدين افعل بهما حسنا ،   وعلى هذا يحسن الوقف على بوالديه { وَإِن جَاهَدَاكَ } أي : وقلنا إن جاهداك { لِتُشْرِكَ بِي مَا لَيْسَ لَكَ بِهِ } بإلاهيته { عِلْمٌ } فإن ما لا يعلم صحته لا يتبع سيما إن علم بطلانه { فَلَا تُطِعْهُمَا } في ذلك فلا طاعة في معصية { إِلَيَّ مَرْجِعُكُمْ } مرجع الكل المؤمن والمشرك والبار والعاق { فَأُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ } بالجزاء عليه ،   نزلت{[3897]} في سعد بن أبي وقاص حلفت أمه ،   إنها لا تأكل ولا تشرب حتى تموت إن لم يرجع ابنها{[3898]}( * ) من الإسلام
