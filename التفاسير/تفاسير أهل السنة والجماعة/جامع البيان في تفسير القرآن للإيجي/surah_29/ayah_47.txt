{ وَكَذَلِكَ } مثل ذلك الإنزال { أَنزَلْنَا إِلَيْكَ الْكِتَابَ } كتابا مصدقا لسائر الكتب قال ابن جرير : معناه أنزلنا إليك الكتاب يا محمد كما أنزلنا على من قبلك من الرسل { فَالَّذِينَ آتَيْنَاهُمُ الْكِتَابَ يُؤْمِنُونَ بِهِ } كمؤمني أهل الكتاب { وَمِنْ هَؤُلَاء } الذين بين ظهرانيك { مَن يُؤْمِنُ بِهِ } كمؤمني العرب { وَمَا يَجْحَدُ بِآيَاتِنَا } مع ظهور معجزاتها { إِلَّا الْكَافِرُونَ } المتوغلون فيه<br />
