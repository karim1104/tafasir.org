{ ولله ما في السماوات وما في الأرض } فله السعة وكمال القدرة { ولقد وصينا الذين أوتوا الكتاب } من اليهود والنصارى وغيرهم { من قبلكم } متعلق بأوتوا أو بوصينا { وإياكم } عطف على الذين { أن اتقوا الله } أي : بتقوى الله وجاز أن يكون مفسرة ،   فإن التوصية في معنى القول { وإن تكفُروا } أي : وقلنا لهم ولكم : إن تكفروا { فإن لله ما في السماوات وما في  والأرض } مالك الملك كله لا يضره كفركم كما لا ينفعه شكركم فما الوصية إلا لحاجتكم وصلاحكم { وكان الله غنيا } عن الخلق { حميدا } في ذاته حمد أو لم يحمد .  <br />
