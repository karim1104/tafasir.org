{ وآتوا اليتامى{[929]} أموالهم } : نزلت في رجل معه مال لابن أخ يتيم  له فطلبه بعد البلوغ ومنعه { ولا تتبدّلوا الخبيث بالطيّب } : ولا تستبدلوا حرام أموالهم بحلال أموالكم ،   نقل أنهم كانوا يأخذون الجيد من مال اليتامى ويجعلون مكانه الردى فنزلت ،   وعلى هذا أيضا الجيد هو الخبيث باعتبار حرمته فلا يرد عليه شيء { ولا تأكلوا أموالهم } : منضمة .   { إلى أموالكم } أي{[930]} : لا تنفقوهما معا { إنه } : الضمير للأكل .   { كان حوبا } : إثما { كبيرا } .
