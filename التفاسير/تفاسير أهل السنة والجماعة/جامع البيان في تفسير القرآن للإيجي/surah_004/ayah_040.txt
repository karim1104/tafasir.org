{ إن{[1014]} الله لا يظلم مثقال ذرّة } زنة نملة صغيرة ،   أو جزء من أجزاء الهباء إن كان مؤمنا فله الأجر في الدارين ،   وإن كان كافرا فمقصور على الدنيا ،   أو تخفيف في عذابه فلا يظلم وهو قادر عليه { وإن تكُ } مثقال ذرة { حسنة } وحذف النون من غير قياس تشبيها بحرف العلة { يُضاعفها } أي : ثوابها { ويُؤت } صاحبها { من لدُنه } من عنده بفضله { أجرا عظيما } جزيلا وهو الجنة .
