{ ولو أنّا كتبنا عليهم أن اقتلوا أنفسكم } كما كتبنا على بني إسرائيل ،   وأن{[1057]} مصدرية { أو اخرُجوا من دياركم } كما أمرناهم من ديار مصر { ما فعلوه } أي : المكتوب ،   أو الضمير لمصدر أحد{[1058]} الفعلين { إلا قليل منهم } وهم المخلصون ،   نزلت حين افتخر صحابي ويهودي فقال اليهودي : لقد كتب الله علينا القتل فقتلنا أنفسنا ،   فقال الصحابي : لو كتب الله علينا لقتلنا{[1059]} { ولو أنهم فعلوا ما يوعظون به } من مطاوعة النبي ومتابعته طوعا { لكان خيرا لهم } في الدارين { وأشد تثبيتا } لإيمانهم وتصديقهم .
