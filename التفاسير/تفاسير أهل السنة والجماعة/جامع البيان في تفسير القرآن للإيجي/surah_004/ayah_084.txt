{ فقاتل في سبيل الله } ولو كنت وحدك { لا تُكلّف إلا نفسك{[1075]} } إلا فعل نفسك فتقدم إلى الجهاد وإن لم يساعدك أحد فالله ناصرك { وحرِّض المؤمنين } أي : على القتال فما عليك إلا التحريض { عسى الله أن يكُفّ بأس الذين كفروا } أي : شدة المشركين بتحريضك إياهم على القتال ،   وقد فعل بان ألقى الرعب في قلوبهم فرجعوا عن الطريق في البدر الثاني { والله أشد بأسا } صولة وشدة من قريش { وأشد تنكيلا } عقوبة .
