{ وإن امرأة } مرفوع بفعل يفسره قوله { خافت بعلها } علمت منه { نُشوزا } تجافيا عنها ومنعا لحقوقها { أو إعراضا } بأن يقل مجالستها { فلا جناح عليهما } على المرأة والزوج { أن يُصلحا بينهما صلحاً } بأن تحط له بعض المهر أو القسم أو النفقة ،   وصلحا مصدر ،   وبينهما مفعول به ومن قرأ : يصالحا فمعناه : يتصالحا { والصُّلح خير } من الفرقة وسوء العشرة { وأحضرت الأنفس الشح } يعني أن النفس مطبوعة على البخل لا يغيب عنها ،   فلا تكاد المرأة تسمح بحط شيء ممن مهرها وقسمها ولا الزوج يسمح بأن يمسكها ويقوم بحقها إذا لم يردها ،   وهو وقوله : ( الصلح خير ) اعتراض للترغيب في المصالحة وتمهيد العذر في المماكسة { وإن تحسنوا } في العشرة { وتتقوا } النشوز ونقص الحق { فإن الله كان بما تعملون } من الإحسان { خبيرا } فيثيبكم .  <br />
