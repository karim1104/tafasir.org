{ وليست التوبة } أي : منفية قبولها { لِلَّذِينَ يَعْمَلُونَ السَّيِّئَاتِ حَتَّى إِذَا حَضَرَ أَحَدَهُمُ الْمَوْتُ قَالَ إِنِّي تُبْتُ الْآَنَ وَلَا الَّذِينَ يَمُوتُونَ وَهُمْ كُفَّارٌ } أي : لا توبة لهؤلاء الفريقين ؛ فإنه كما لا تقبل توبة الآخرة لا تقبل توبة الدنيا حين الاحتضار { أولئك أعتدنا{[961]} لهم عذابا أليما } الاعتداد : التهيئة .
