{ واعبدوا{[1006]} الله ولا تُشركوا{[1007]} به شيئا } من المخلوقات{[1008]} أو من الإشراك قليلا وكثيرا جليا وخفيًّا { و } أحسنوا { بالوالدين إحسانا وبذي القربى } صاحب القرابة { واليتامى والمساكين } من لا يجد ما يكفيه وعياله { والجار ذي القربى } من جمع بين القرابة والجوار ،   أو الجار الأقرب أو الجار المسلم { والجار الجُنب } الأجنبي والذي جواره بعيد ،   أو أهل الكتاب { والصاحب بالجَنب } المرأة ،   أو رفيق السفر ،   أو الحضر أيضا { وابن السبيل } المسافر ،   أو الضعيف { وما ملكت أيمانُكم } المماليك{[1009]} { إن الله لا يحب من كان مختالا } متكبرا { فخورا } يتفاخر{[1010]} على المسلمين .
