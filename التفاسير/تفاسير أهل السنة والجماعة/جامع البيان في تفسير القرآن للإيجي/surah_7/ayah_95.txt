{ ثُمَّ بَدَّلْنَا مَكَانَ السَّيِّئَةِ الْحَسَنَةَ } أعطينا السلامة والسعة مكان البلاء والشدة ابتلاء واستدراجا { حتى{[1662]} عفوا } كثروا عددا ومالا { وَقَالُوا قَدْ مَسَّ آَبَاءَنَا الضَّرَّاءُ وَالسَّرَّاءُ } فأصابنا مثل ما أصابهم وهذا عادة الدهر ولم ينتبهوا وغفلوا { فأخذناهم بغتة } فجأة مصدر أي : هذا النوع من الأخذ { وهم لا يشعرون } بنزول العذاب .
