{ فأرسلنا عليهم الطوفان } أرسل الله تعالى مطرا{[1693]} سبعة أيام امتلأت بيوت القبط حتى قاموا في الماء إلى تراقيهم ولم يدخل بيوت بني إسرائيل مع أن بيوتهم مشتبكة{[1694]} أو المراد من الطوفان الوباء أو الجدري{[1695]} ثم فزعوا إلى موسى وعهدوا بالإيمان إن كشف عنهم العذاب ،   فلما كشف نقضوا عهودهم { والجراد } فأرسل الله إليهم الجراد فأكل زروعهم وثيابهم حتى{[1696]} مسامير أبوابهم ثم عهدوا وكشف فنقضوا { والقُمّل } فأرسل الله إليهم السوس{[1697]} أو أولاد الجراد قبل أجنحتها أو الحمنان{[1698]} صغار القردان أو دواب سود صغار أو القمل بفتح القاف حتى أكلت أبدانهم ومصت{[1699]} دماءهم فعهدوا فلما كشف نقضوا { والضفادع } فأرسل الله تعالى إليهم الضفادع حتى لا يستطيعوا الطبخ والأكل فإنه يمتلئ قدورهم وظروفهم وأفواههم فعهدوا ونقضوا { والدم } صارت مياههم دما وسالت النيل عليهم بالدم أو المراد بالدم الرعاف فعطشوا فعهدوا ونقضوا { آيات مفصّلات } مبينات لا يشتبه على أحد أنها نقمة من الله ونصبها على الحال { فاستكبروا } عن الإيمان { وكانوا قوما مجرمين }
