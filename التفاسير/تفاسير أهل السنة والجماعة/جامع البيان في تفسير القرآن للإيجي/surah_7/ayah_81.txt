{ إنكم } الهمزة للإنكار { لتأتون الرجال } من أتى المرأة إذا غشيها { شهوة } للاشتهاء أنكر أن يكون الحامل على هذه القباحة مجرد الشهوة ،   أو حال أبي : مشتهين  غير ملتفتين إلى سماجتها { من دون النساء } المخلوق لكم { بل أنتم قوم مسرفون } إضراب على الإنكار إلى الإخبار عن طريقتهم وعادتهم كأنه قال : بل أنتم قوم لكم الإسراف في الأمور كلها وهو الباعث لكم إلى تلك القبيحة .  <br />
