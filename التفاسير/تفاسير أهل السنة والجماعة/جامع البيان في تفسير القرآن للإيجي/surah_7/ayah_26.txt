{ يا بني{[1592]} آدم قد أنزلنا عليكم } أي : خلقنا لكم ولما كان بقضاء سماوي ،   وأسباب من السماء{[1593]} قال : ( وأنزلنا ) وكم مثله في القرآن { لباسا يواري } يستر { سوءاتكم{[1594]} } فأغناكم عن خصف الورق { وريشا{[1595]} } مالا أو ما يتجمل{[1596]} به من الثياب ،   أو جمالا ،   { ولباس التقوى } خشية الله أو الإيمان أو العمل الصالح ،   أو العفاف ،   أو هو اللباس الأول يعني لباسا يواري عوراتكم ،   أو لباس الحرب وهو مبتدأ { ذلك خير } خبره { ذلك } أي : خلق اللباس ،   { من آيات الله } الدالة على فضله { لعلهم يذكّرون } يتعظون فيتورعون عن كشف العورة .
