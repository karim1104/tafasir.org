{ قل إنما حرّم ربي الفواحش } ما تزايد قبحه كالكبائر { ما ظهر منها وما بطن } جهرها وسرها { والإثم } كل ذنب ،   أو الصغائر أو الخمر{[1607]} { والبغي } الظلم { بغير الحق } متعلق بالبغي مؤكد له معنى { وأن تُشركوا بالله ما لم ينزّل به سلطانا } برهانا ومن المحال إنزال البرهان على الإشراك فيكون هذا تهكما واستهزاء { وأن تقولوا على الله{[1608]} ما لا تعلمون } بالافتراء عليه .
