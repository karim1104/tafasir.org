{ قل من حرّم زينة الله } التي حرمتموها على أنفسكم في الطواف { التي أخرج } من النبات والحيوان والمعادن كالقطن والحرير والدروع { لعباده الطيبين من الرزق } المستلذات من المآكل والمشارب كما حرمتم من عند أنفسكم في أيام الحج { قل هي } : أي : الطيبات مخلوقة { للذين آمنوا في الحياة الدنيا } بالأصالة والكفرة  شريكهم تبعا { خالصة يوم القيامة } لا يشاركهم الكافرون وقيل : خالصة في الآخرة من التنغيص والغم خلافا للدنيا ،   ونصبه على الحال من المستكن في الظرف { كذلك } كتفصيلنا هذا الحكم { نفصّل } جميع { الآيات لقوم يعلمون } أن الله هو الذي يحرم ويحلل أو لقوم غير جاهلين .  <br />
