{ لا يزال بينانهم } أي : مبنيهم مصدر أريد به المفعول ،   { الذي بنوا } صفة لبنيانهم وجاز أن يكون بنيانهم على معناه المصدري والذي بنوا مفعوله ،   { ريبة في قلوبهم } سبب شك ونفاق فإنهم بنوا للكفر والتفريق فلما خربوه ازدادوا غيظا وحسدا وعضا ،   { إلا أن تقطع قلوبهم } بالموت والاستثناء من أعم الأزمنة ،   أي : يسألون عنه حينئذ ،   { والله عليم } بأعمال الخلائق ،   { حكيم } في مجازاتهم من خير وشر .  <br />
