{ يا أيها الذين آمنوا كونوا قوّامين لله } أي : قائمين بالحق لله لا للرياء { شهداء بالقسط } بالعدل لا بالجور { ولا يجرِمنّكم } يحملنكم { شنآن قوم } عداوتهم { على ألا تعدلوا } بل الزموا العدل مع العدو والصديق { اعدلوا هو } أي : العدل { أقرب للتقوى } اللام للاختصاص واستعمل أفعل التفضيل في محل ليس في الجانب الآخر منه شيء كقوله تعالى : ( أصحاب الجنة يومئذ خير مستقر وأحسن مقيلا ) ( الفرقان : 24 ) وكم مثله في كلام البلغاء { واتقوا الله إن الله خبير بما تعملون } فيجازيكم به .
