{ وإذا رأيتهم تعجبك أجسامهم } فإنهم  أشكال حسنة { وإن يقولوا تسمع لقولهم } لفصاحتهم { كأنهم خشب مسندة } أي : تسمع لما يقولون مشبهين بأخشاب منصوبة إلى حائط في الخلو عن الفهم والنفع ،   فإن الخشب إذا انتفع به كان في سقف أو غيره من مظان الانتفاع ،   وما دام متروكا أسند إلى الحائط فلا ينتفع به { يحسبون كل صيحة عليهم } أي : واقعة عليهم لجبنهم فهم أجسام لا قلوب لهم ،   أو لأنهم على وجل من أن ينزل الله أمرا يهتك أستارهم { هم العدو فاحذرهم } لا تأمنهم { قاتلهم الله } دعاء عليهم وطلب من ذاته أن يلعنهم ،   أو تعليم للمؤمنين { أنى يؤفكون } كيف يصرفون عن الهدى<br />
