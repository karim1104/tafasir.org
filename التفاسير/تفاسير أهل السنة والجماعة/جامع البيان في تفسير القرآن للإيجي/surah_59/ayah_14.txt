{ لا يقاتلونكم } اليهود { جميعا } مجتمعين { إلا في قرى محصنة أو من وراء جدر } لا يبرزون لقتالكم لفرط خشيتهم منكم وإن كانوا مجتمعين { بأسهم } شدتهم في الحرب { بينهم شديد } يعني إذا حارب بعضهم بعضا فيشتد بأسهم لكن إن قاتلوكم لم يبق لهم تلك الشدة { تحسبهم جميعا } متفقين { وقلوبهم شتى } متفرقة وأصل الحرب الاتفاق { ذلك بأنهم قوم لا يعقلون } فإن العقل هو الداعي إلى الإتحاد والاتفاق ،   وعن بعض{[4974]} تحسبهم أي : اليهود والمنافقين  .
