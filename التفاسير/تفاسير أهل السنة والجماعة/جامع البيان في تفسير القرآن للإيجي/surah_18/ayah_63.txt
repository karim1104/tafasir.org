{ قَالَ أَرَأَيْتَ } : ما دهاني{[2991]} { إِذْ أَوَيْنَا إِلَى الصَّخْرَةِ } : التي في الموضع الموعود { فَإِنِّي نَسِيتُ الْحُوتَ وَمَا أَنسَانِيهُ } أي : ذكره { إِلا الشَّيْطَانُ أَنْ أَذْكُرَهُ } : بدل من الضمير{[2992]} { وَاتَّخَذَ سَبِيلَهُ فِي الْبَحْرِ عَجَبًا } أي : سبيلا عجبا ،   وهو كالأول ثاني مفعولي اتخذ وقيل : تقديره أعجب عجبا ،   قاله يوشع في آخر كلامه تعجبا .
