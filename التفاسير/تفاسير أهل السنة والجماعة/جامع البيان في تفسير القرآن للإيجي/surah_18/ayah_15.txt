{ هَؤُلاء } مبتدأ { قَوْمُنَا } عطف بيانه { اتَّخَذُوا مِن دُونِه{[2932]}  آلِهَةً لَّوْلا } : هلا { يَأْتُونَ عَلَيْهِم } أي : على عبادتهم{[2933]} { بِسُلْطَانٍ بَيِّنٍ } : بدليل واضح فإن دينا لا دليل عليه فهو باطل { فَمَنْ أَظْلَمُ مِمَّنِ افْتَرَى عَلَى اللَّهِ كَذِبًا } : فإنهم افتروا عليه أن له شركاء .
