{ وَرَبُّكَ الْغَفُورُ } : البليغ المغفرة ،   { ذُو الرَّحْمَةِ لَوْ يُؤَاخِذُهُم بِمَا كَسَبُوا } : من الذنوب ،   { لَعَجَّلَ لَهُمُ الْعَذَابَ } : في الدنيا ،   { بَل لَّهُم مَّوْعِدٌ } هو يوم القيامة وقيل : بدر { لَّن يَجِدُوا مِن دُونِهِ } : من دون الله في ذلك الموعد ،   { مَوْئِلا } : منجا ،   وقيل : لن يجدوا من دون ذلك الموعد ومن عنده منجا ومهربا .  <br />
