{ قَالُوا يَا ذَا{[3025]} الْقَرْنَيْنِ } عن بعض السلف أنه يعلم جميع الألسنة { إِنَّ يَأْجُوجَ{[3026]} وَمَأْجُوجَ مُفْسِدُونَ فِي الأَرْضِ } أي : في أرضنا بأنواع المفاسد { فَهَلْ نَجْعَلُ لَكَ خَرْجًا } : جعلا نخرجه من أموالنا { عَلَى أَن تَجْعَلَ بَيْنَنَا وَبَيْنَهُمْ سَدًّا } : فلا يمكن لهم الوصول إلينا .
