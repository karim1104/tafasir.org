{ وَاصْبِرْ نَفْسَكَ } : احبسها { مَعَ الَّذِينَ يَدْعُونَ رَبَّهُم بِالْغَدَاةِ وَالْعَشِيِّ } : طرفي النهار { يُرِيدُونَ وَجْهَهُ } : يريدون الله لا عوضا من الدنيا نزلت في أشرف قريش حين طلبوا أن يفرد لهم مجلسا لا يكون فيه فقراء الصحابة{[2958]} فيه ولذلك قال الله : { وَلا تَعْدُ عَيْنَاكَ عَنْهُمْ } : لا تصرف بصرك إلى غيرهم من ذوي الغنى والزينة ،   واستعماله بعن مع أنه مستعمل بغير واسطة لتضمينه معنى نبا{[2959]} يقال : نبت عنه عينه إذا ازدرته ولم تتعلق به { تُرِيدُ } حال من كاف عيناك { زِينَةَ الْحَيَاةِ الدُّنْيَا } أي : مجالسة الأشراف { وَلا تُطِعْ } : في تبعيد الفقراء { مَنْ أَغْفَلْنَا قَلْبَهُ } : جعلنا قلبه غافلا { عَن ذِكْرِنَا وَاتَّبَعَ هَوَاهُ وَكَانَ أَمْرُهُ فُرُطًا } : متقدما للصواب نابذا له وراء ظهره يقال : فرس فرط ،   أي : متقدم للخيل .
