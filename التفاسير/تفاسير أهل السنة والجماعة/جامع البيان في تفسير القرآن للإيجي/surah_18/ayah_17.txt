{ وَتَرَى الشَّمْسَ } : لو رأيتهم { إِذَا طَلَعَت تَّزَاوَرُ } : تميل{[2937]} { عَن كَهْفِهِمْ } فلا يقع شعاعها عليهم لتحترق أبدانهم ولباسهم { ذَاتَ الْيَمِينِ } : جهته ،   { وَإِذَا غَرَبَت تَّقْرِضُهُمْ } : تقطعهم وتعدل عنهم ،   { ذَاتَ الشِّمَالِ وَهُمْ فِي فَجْوَةٍ } : متسع ،   { مِّنْهُ } : من الكهف فلا يؤذيهم حر الشمس وينالهم روح الهواء وذلك إذا كان باب الكهف على بنات{[2938]} النعش فيقع الشعاع على جنبيه وهم في وسطه فيحلل عفونته ويعدل هواءه ،   وعند بعضهم أن الله صرف عنهم الشمس بقدرته وحال بينها وبينهم لا لأن باب الكهف على جانب لا تقع الشمس إلا على جنبيه { ذَلِكَ مِنْ آيَاتِ اللَّهِ } حيث أرشدهم إلى غار كذلك { مَن يَهْدِ اللَّهُ فَهُوَ الْمُهْتَدِي وَمَن يُضْلِلْ } : ولم يرشده { فَلَن تَجِدَ لَهُ وَلِيًّا مُّرْشِدًا } : من يلي أمرهم ويرشده .
