{ أَفَحَسِبَ } همزة الاستفهام للإنكار { الَّذِينَ كَفَرُوا أَن يَتَّخِذُوا عِبَادِي } : كالملائكة وعيسى أو الشياطين { مِن دُونِي أَوْلِيَاء } : معبودين وثاني حسب محذوف للقرينة أي : ظنوا اتخاذهم معبودين نافعا لهم { إِنَّا أَعْتَدْنَا جَهَنَّمَ لِلْكَافِرِينَ نُزُلا } أي : منزل أو ما يهيأ للضيف حين نزوله مما حضر ،   وفيه تنبيه على أن لهم وراءها عذابا أشد .  <br />
