{ فانطلقا حتى إِذَا أَتَيَا أَهْلَ قَرْيَةٍ } هي أنطاكية ،   وقيل أيلة { اسْتَطْعَمَا{[3004]} أَهْلَهَا } : سألاهم الطعام { فَأَبَوْا أَن يُضَيِّفُوهُمَا{[3005]} فَوَجَدَا فِيهَا جِدَارًا يُرِيدُ أَنْ يَنقَضَّ } استعار الإرادة للمداناة والمشارفة ،   كما استعير الهم والعزم لذلك ،   يقال : عزم السراج أن إذا قرب ،   وانقض : إذا أسرع سقوطه ،   { فَأَقَامَهُ } قال : بيده فأقامه{[3006]} أو هدمه فبناه { قَالَ لَوْ شِئْتَ } : أن تأخذ جعلا { لاتَّخَذْتَ عَلَيْهِ أَجْرًا } والتاء من تخذ أصل كتبع ،   وليس من الأخذ يعني : قد علمت أنا جياع حتى افتقرنا إلى المسألة ،   فما وجدنا مواسيا فلو أخذت على عملك أجرا .
