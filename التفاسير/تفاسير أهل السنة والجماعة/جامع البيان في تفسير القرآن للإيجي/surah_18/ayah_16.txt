{ وَإِذِ اعْتَزَلْتُمُوهُمْ{[2934]} } خطاب بعضهم لبعض والعامل فيه الجزاء { وَمَا يَعْبُدُونَ إِلا اللَّهَ } عطف على مفعول اعتزل ،   وهم يعبدون الأصنام مع الله { فَأْوُوا إِلَى الْكَهْفِ يَنشُرْ } : يبسط { لَكُمْ رَبُّكُم مِّن رَّحمته } : رحمة يستركم بها من قومكم { ويُهَيِّئْ لَكُم مِّنْ أَمْرِكُم } : الذي أنتم فيه { مِّرْفَقًا{[2935]} } : ما تنتفعون به{[2936]} .
