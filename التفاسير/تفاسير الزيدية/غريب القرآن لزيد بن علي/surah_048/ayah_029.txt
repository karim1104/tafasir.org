وقوله تعالى :  {  سِيمَاهُمْ فِي وُجُوهِهِمْ } معناه الخِشوعُ .  والسِّيماءُ :  العَلامةُ . <br />
وقوله تعالى :  {  كَزَرْعٍ أَخْرَجَ شَطْأَهُ } معناه جَوانبُهُ . <br />
 وقوله تعالى :  {  فَآزَرَهُ } معناه سَاواهُ فَصارَ مِثلَ الأُمِّ .  {  فَاسْتَغْلَظَ } معناه غَلُظَ {  فَاسْتَوَى عَلَى سُوقِهِ } قال زيدُ بن علي عليهما السَّلامُ :  فالسَّاقُ :  حَاملةُ الشَّجرِ .
