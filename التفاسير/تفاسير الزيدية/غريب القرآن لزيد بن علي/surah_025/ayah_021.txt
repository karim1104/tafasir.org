وقوله تعالى :  {  وَقَالَ الَّذِينَ لاَ يَرْجُونَ لِقَآءَنَا } معناه لا يَخافُون لِقاءَنا . <br />
وقوله تعالى :  {  لَوْلاَ أُنْزِلَ عَلَيْنَا الْمَلاَئِكَةُ أَوْ نَرَى رَبَّنَا } يَقولون ألا أنزل علينا الملائكةُ .  أو نرى ربَّنَا كما لو قالتْ بنو إسرائيل لموسى عليه السّلامُ :  {  أَرِنَا اللَّهَ جَهْرَةً } [ النساء :  153 ] فقال الله عزّ وجلّ {  يَوْمَ يَرَوْنَ الْمَلاَئِكَةَ لاَ بُشْرَى يَوْمَئِذٍ لِّلْمُجْرِمِينَ }
