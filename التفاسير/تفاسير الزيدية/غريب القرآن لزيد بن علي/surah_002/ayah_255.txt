وقولهُ تعالى :  {  الْحَيُّ الْقَيُّومُ } قالَ زيدُ بن علي عليهما السلامُ :  فالحيُّ :  الباقيُ ،  والقَيّومُ :  الدَائمُ الذي لا يَزولُ . <br />
وقولهُ تعالى :  {  لاَ تَأْخُذُهُ سِنَةٌ وَلاَ نَوْمٌ } فالسِّنةُ :  النُّعاسُ :  وكذلكَ الوَسنَةُ وجمعُها سِناتٌ . <br />
وقولهُ تعالى :  {  مَن ذَا الذِي يَشْفَعُ عِنْدَهُ إِلاَّ بِإِذْنِهِ } قالَ زيدُ بن علي عليهما السَّلامُ :  معناهُ يتكلمُ . <br />
وقولهُ تعالى :  {  وَسِعَ كُرْسِيُّهُ السَّمَ'وَتِ وَالأَرْضَ } قالَ وسِعَ عِلمُهُ السَّمَ'وَتِ والأَرضَ .  والكراسيُّ :  العُلماءُ .  ويقالُ :  إِنَّ الكُرسيَّ :  موضعُ العَرشِ . <br />
وقولهُ تعالى :  {  وَلاَ يَؤُودُهُ حِفْظُهُمَا } معناه لا يَكُد بِه ولاَ يَثقُلُ عَليهِ . <br />
