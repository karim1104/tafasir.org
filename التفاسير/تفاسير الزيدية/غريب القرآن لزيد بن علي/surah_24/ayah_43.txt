وقوله تعالى :  {  أَلَمْ تَرَ أَنَّ اللَّهَ يُزْجِي سَحَاباً } معناه يَسوقُ {  ثُمَّ يَجْعَلُهُ رُكَاماً } معناه مُتراكمٌ بَعضُهُ على بعضٍ . <br />
وقوله تعالى :  {  فَتَرَى الْوَدْقَ يَخْرُجُ مِنْ خِلاَلِهِ } والوَدَقُ :  المَطرُ وخلالُهُ :  بينَ السَّحابِ . <br />
وقوله تعالى :  {  سَنَا بَرْقِهِ } معناه ضَوءُ بَرقهِ . <br />
