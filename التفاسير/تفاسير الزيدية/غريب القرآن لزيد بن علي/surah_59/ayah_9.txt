وقوله تعالى :  {  وَالَّذِينَ تَبَوَّءُوا الدَّارَ } معناه نَزَلوها . <br />
وقوله تعالى :  {  وَلَوْ كَانَ بِهِمْ خَصَاصَةٌ } معناه فَقرٌ وحَاجةٌ . <br />
وقوله تعالى :  {  وَلاَ يَجِدُونَ فِي صُدُورِهِمْ حَاجَةً } معناه حَسدٌ . <br />
وقوله تعالى :  {  وَمَن يُوقَ شُحَّ نَفْسِهِ } معناه يَمنعُ بُخلَ نَفسِهِ والشُّحُّ :  البُخلُ . <br />
