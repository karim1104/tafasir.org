{ فَلَماَّ رَأَى } أي : العزيز { قَمِيصِهِ } أي : قميص يوسف { قُدَّ مِن دُبُرٍ قَالَ إِنَّهُ } أي : هذا الأمر الذي وقع فيه الاختلاف بينكما ،  أو أن قولك : { مَا جَزَاء مَنْ أَرَادَ بِأَهْلِكَ سُوءا } { مِن كَيْدِكُنَّ } أي : من جنس كيدكنّ يا معشر النساء { إِنَّ كَيْدَكُنَّ عَظِيمٌ } والكيد : المكر والحيلة .  <br />
