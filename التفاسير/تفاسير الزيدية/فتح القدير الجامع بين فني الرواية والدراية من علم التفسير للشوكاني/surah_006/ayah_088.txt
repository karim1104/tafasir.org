والإشارة بقوله : { ذلك هُدَى الله } إلى الهداية والتفضيل والاجتباء المفهومة من الأفعال السابقة { يَهْدِي بِهِ } الله { مَن يَشَاء مِنْ عِبَادِهِ } وهم الذين وفقهم للخير واتباع الحق { وَلَوْ أَشْرَكُواْ } أي هؤلاء المذكورون بعبادة غير الله { لَحَبِطَ عَنْهُمْ } من حسناتهم { مَا كَانُواْ يَعْمَلُونَ } والحبوط البطلان .   وقد تقدّم تحقيقه في البقرة .  <br />
