{ وَإِذَا أَذَقْنَا الناس رَحْمَةً } أي خصباً ونعمة وسعة وعافية { فَرِحُواْ بِهَا } فرح بطر وأشر ،  لا فرح شكر بها وابتهاج بوصولها إليهم { قُلْ بِفَضْلِ الله وَبِرَحْمَتِهِ فَبِذَلِكَ فَلْيَفْرَحُواْ } [ يونس : 58 ] .   ثم قال سبحانه : { وَإِن تُصِبْهُمْ سَيّئَةٌ } شدة على أي صفة { بِمَا قَدَّمَتْ أَيْدِيهِمْ } أي بسبب ذنوبهم { إِذَا هُمْ يَقْنَطُونَ } القنوط : الإياس من الرحمة ،  كذا قال الجمهور .   وقال الحسن : القنوط : ترك فرائض الله سبحانه .   قرأ الجمهور :  "  يقنطون  "  بضم النون .   وقرأ أبو عمرو والكسائي ويعقوب بكسرها .  <br />
