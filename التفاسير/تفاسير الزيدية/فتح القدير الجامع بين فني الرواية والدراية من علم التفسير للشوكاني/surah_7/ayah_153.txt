{ والذين عَمِلُواْ السيئات } أي : سيئة كانت { ثُمَّ تَابُواْ } عنها { مِن بَعْدِ } عمل { ها وَآمَنُواْ } بالله { إِنَّ رَبَّكَ مِن بَعْدِهَا } أي : من بعد هذه التوبة ،  أو من بعد عمل هذه السيئات التي قد تاب عنها فاعلها وآمن بالله { لَغَفُورٌ رَّحِيمٌ } أي : كثير الغفران لذنوب عباده وكثير الرحمة لهم .  <br />
