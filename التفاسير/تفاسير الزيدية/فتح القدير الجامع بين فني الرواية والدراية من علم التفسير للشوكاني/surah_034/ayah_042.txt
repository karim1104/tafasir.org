{ فاليوم لاَ يَمْلِكُ بَعْضُكُمْ لِبَعْضٍ نَّفْعاً وَلاَ ضَرّاً } يعني العابدين والمعبودين لا يملك بعضهم ،  وهم المعبودون لبعض ،  وهم العابدون { نَفْعاً } أي شفاعة ونجاة { وَلاَ ضَرّا } أي عذاباً وهلاكاً ،  وإنما قيل لهم : هذا القول إظهاراً لعجزهم ،  وقصورهم ،  وتبكيتاً لعابديهم ،  وقولهم : { وَلاَ ضَرّا } هو على حذف مضاف ،  أي لا يملكون لهم دفع ضرّ ،  وقوله : { وَنَقُولُ لِلَّذِينَ ظَلَمُواْ } عطف على قوله : { نَّقُولُ للملائكة } أي للذين ظلموا أنفسهم بعبادة غير الله { ذُوقُواْ عَذَابَ النار التى كُنتُم بِهَا تُكَذّبُونَ } في الدنيا .  <br />
