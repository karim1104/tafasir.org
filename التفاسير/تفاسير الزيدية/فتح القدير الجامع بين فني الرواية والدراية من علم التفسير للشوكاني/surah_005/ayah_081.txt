{ وَلَوْ كَانُوا يُؤْمِنُونَ بِالْلهِ والنَّبِي } أي نبيهم { وَمَا أُنْزِلَ إِلَيْهِ } من الكتاب { مَا اتَّخَذُوهُمْ } أي المشركين { أَوْلِيَاء } لأن الله سبحانه ،  ورسوله المرسل إليهم ،  وكتابه المنزل عليهم قد نهوهم عن ذلك { ولكن كَثِيراً منْهُمْ فاسقون } أي خارجون عن ولاية الله وعن الإيمان به وبرسوله وبكتابه .  <br />
