{ هَلْ يَنظُرُونَ إِلاَّ الساعة } أي هل يرتقب هؤلاء الأحزاب وينتظرون إلا الساعة { أَن تَأْتِيَهُمْ بَغْتَةً } أي فجأة { وَهُمْ لاَ يَشْعُرُونَ } أي : لا يفطنون بذلك ،  وقيل : المراد بالأحزاب : الذين تحزّبوا على النبي صلى الله عليه وسلم وكذبوه ،  وهم المرادون بقوله : { هَلْ يَنظُرُونَ إِلاَّ الساعة } والأوّل أولى .  <br />
