{ وَمَا أَرْسَلْنَا مِن قَبْلِكَ مِن رَّسُولٍ إِلاَّ يُوحَى إِلَيْهِ } قرأ حفص وحمزة والكسائي : { نوحي } بالنون ،  وقرأ الباقون بالياء أي : نوحي إليه { أَنَّهُ لا إله إِلا أَنَا } وفي هذا تقرير لأمر التوحيد وتأكيد لما تقدّم من قوله : { هذا ذِكْرُ مَن مَعِي } وختم الآية بالأمر لعباده بعبادته ،  فقال : { فاعبدون } فقد اتضح لكم دليل العقل ،  ودليل النقل وقامت عليكم حجة الله .  <br />
