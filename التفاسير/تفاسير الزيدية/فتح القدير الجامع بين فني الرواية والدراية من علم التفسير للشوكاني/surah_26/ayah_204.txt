{ أَفَبِعَذَابِنَا يَسْتَعْجِلُونَ } ولا يخفى ما في هذا من البعد والمخالفة للمعنى الظاهر ،  فإن معنى { هَلْ نَحْنُ مُنظَرُونَ } طلب النظرة والإمهال ،  وأما قوله : { أَفَبِعَذَابِنَا يَسْتَعْجِلُونَ } فالمراد به الردّ عليهم ،  والإنكار لما وقع منهم من قولهم { فَأَمْطِرْ عَلَيْنَا حِجَارَةً مّنَ السماء أَوِ ائتنا بِعَذَابٍ أَلِيمٍ } [ الأنفال : 32 ] ،  وقولهم : { فَأْتِنَا بِمَا تَعِدُنَا } [ الأعراف : 70 ] .  <br />
