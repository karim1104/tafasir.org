{ وَإِذَا قِيلَ لَهُمُ اتقوا مَا بَيْنَ أَيْدِيكُمْ وَمَا خَلْفَكُمْ } أي ما بين أيديكم من الآفات والنوازل ،  فإنها محيطة بكم ،  وما خلفكم منها .   قال قتادة : معنى { اتقوا مَا بَيْنَ أَيْدِيكُمْ } أي من الوقائع فيمن كان قبلكم من الأمم { وَمَا خَلْفَكُمْ } في الآخرة .   وقال سعيد بن جبير ومجاهد : { مَا بَيْنَ أَيْدِيكُمْ } ما مضى من الذنوب { وَمَا خَلْفَكُمْ } ما بقي منها .   وقيل : { مَا بَيْنَ أَيْدِيكُمْ } الدنيا { وَمَا خَلْفَكُمْ } الآخرة ،  قاله سفيان .   وحكى عكس هذا القول الثعلبي عن ابن عباس .   وقيل : { مَا بَيْنَ أَيْدِيكُمْ } ما ظهر لكم { وَمَا خَلْفَكُمْ } ما خفي عنكم ،  وجواب إذا محذوف ،  والتقدير : إذا قيل لهم ذلك أعرضوا كما يدلّ عليه { إِلاَّ كَانُواْ عَنْهَا مُعْرِضِينَ } { لَعَلَّكُمْ تُرْحَمُونَ } أي رجاء أن ترحموا ،  أو كي ترحموا ،  أو راجين أن ترحموا .  <br />
