وقوله : { طَاعَةٌ وَقَوْلٌ مَّعْرُوفٌ } كلام مستأنف ،  أي أمرهم طاعة ،  أو طاعة وقول معروف خير لكم .   قال الخليل وسيبويه : إن التقدير : طاعة وقول معروف أحسن ،  وأمثل لكم من غيرهما .   وقيل : إن { طاعة } خبر أولى ،  وقيل : إن { طاعة } صفة ل { سورة } ،  وقيل : إن { لهم } خبر مقدّم ،  و { طاعة } مبتدأ مؤخر ،  والأول أولى { فَإِذَا عَزَمَ الأمر } عزم الأمر جدّ الأمر : أي جدّ القتال ووجب وفرض ،  وأسند العزم إلى الأمر ،  وهو لأصحابه مجازاً ،  وجواب «إذا » قيل هو : { فَلَوْ صَدَقُواْ الله } وقيل محذوف تقديره كرهوه .   قال المفسرون معناه إذا جدّ الأمر ولزم فرض القتال خالفوا وتخلفوا { فلو صدقوا الله } في إظهار الإيمان والطاعة { لَكَانَ خَيْراً لَّهُمْ } من المعصية والمخالفة .  <br />
