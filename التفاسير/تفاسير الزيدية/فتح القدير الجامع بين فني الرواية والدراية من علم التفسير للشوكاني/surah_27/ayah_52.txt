وجملة : { فَتِلْكَ بُيُوتُهُمْ خَاوِيَةً } مقرّرة لما قبلها .   قرأ الجمهور : { خاوية } بالنصب على الحال .   قال الزجاج : المعنى فانظر إلى بيوتهم حال كونها خاوية ،  وكذا قال الفراء والنحاس : أي خالية عن أهلها خراباً ليس بها ساكن .   وقال الكسائي وأبو عبيدة : نصب { خاوية } على القطع .   والأصل فتلك بيوتهم الخاوية ،  فلما قطع منها الألف ،  واللام نصبت كقوله : { وَلَهُ الدين وَاصِبًا } [ النحل : 52 ] .   وقرأ عاصم بن عمر ونصر بن عاصم والجحدري وعيسى بن عمر برفع { خاوية } على أنه خبر اسم الإشارة ،  وبيوتهم بدل ،  أو عطف بيان ،  أو خبر لاسم الإشارة ،  وخاوية خبر آخر ،  والباء في { بِمَا ظَلَمُواْ } للسببية : أي بسبب ظلمهم { إِنَّ فِي ذَلِكَ } التدمير والإهلاك { لآيَةً } عظيمة { لِقَوْمٍ يَعْلَمُونَ } أي يتصفون بالعلم بالأشياء .  <br />
