{ فَأَمَّا الذين ءامَنُوا وَعَمِلُوا الصالحات فَيُوَفّيهِمْ أُجُورَهُمْ } من غير أن يفوتهم منها شيء : { وَأَمَّا الذين استنكفوا واستكبروا فَيُعَذّبُهُمْ عَذَاباً أَلُيماً } بسبب استنكافهم واستكبارهم { وَلاَ يَجِدُونَ لَهُمْ مّن دُونِ الله وَلِيّاً } يواليهم { وَلاَ نَصِيراً } ينصرهم .  <br />
