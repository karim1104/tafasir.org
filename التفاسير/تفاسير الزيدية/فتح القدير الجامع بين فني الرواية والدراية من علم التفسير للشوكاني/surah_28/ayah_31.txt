وقوله : { وَأَنْ أَلْقِ عَصَاكَ } معطوف على { أَن يا موسى } وقد تقدّم تفسير هذا وما بعده في طه والنمل ،  وفي الكلام حذف ،  والتقدير : فألقاها فصارت ثعباناً فاهتزت { فَلَمَّا رَءَاهَا تَهْتَزُّ كَأَنَّهَا جَانٌّ } في سرعة حركتها مع عظم جسمها { ولى مُدْبِراً } أي منهزماً ،  وانتصاب { مدبراً } على الحال وقوله : { وَلَمْ يُعَقّبْ } في محل نصب أيضاً على الحال أي لم يرجع { يا موسى أَقْبِلْ وَلاَ تَخَفْ إِنَّكَ مِنَ الآمنين } قد تقدّم تفسير جميع ما ذكر هنا مستوفى فلا نعيده .  <br />
