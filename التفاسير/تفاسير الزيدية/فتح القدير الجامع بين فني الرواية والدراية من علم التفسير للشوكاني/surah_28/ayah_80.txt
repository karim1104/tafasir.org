{ وَقَالَ الذين أُوتُواْ العلم } ،  وهم : أحبار بني إسرائيل قالوا للذين تمنوا : { وَيْلَكُمْ ثَوَابُ الله خَيْرٌ } أي ثواب الله في الآخرة خير مما تمنونه { لّمَنْ ءَامَنَ وَعَمِلَ صالحا } فلا تمنوا عرض الدنيا الزائل الذي لا يدوم { وَلاَ يُلَقَّاهَا } أي هذه الكلمة التي تكلم بها الأحبار ،  وقيل : الضمير يعود إلى الأعمال الصالحة .   وقيل إلى الجنة { إِلاَّ الصابرون } على طاعة الله والمصبرون أنفسهم عن الشهوات .  <br />
