{  الله يتوفى الأنفس حين موتها } يعني يقبضها عن التصرف ويمسكها ويحفظها حين موتها {  والتي لم تمت في منامها } يريد ويتوفى الأنفس التي لم تمت في منامها ،  أي يتوفاها حين منامها ،  وشبَّه النائمين بالموتى ،  ومنه :  {  وهو الذي يتوفاكم بالليل } [ الأنعام :  60 ] حيث لا يميزون ولا يتصرفون والموتى كذلك {  فيمسك } الأنفس {  التي قضى عليها الموت } الحقيقي إلى يوم القيامة {  ويرسل الأخرى } النائمة {  إلى أجل مسمى } إلى وقت ضربه لموتها {  إن في ذلك لآيات لقوم يتفكرون } في الأدلة
