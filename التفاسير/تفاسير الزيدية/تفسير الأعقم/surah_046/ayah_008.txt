{  أم يقولون افتراه } واختلقه من عنده كذباً {  قل إن افتريته } يعني كذبت في هذا القرآن أنه منزّل {  فلا تملكون لي من الله شيئاً } أي لا تقدرون على دفع ما يريد الله بي {  هو أعلم بما تفيضون فيه } أي تتحاورون به بينكم وتخوضون فيه {  كفى به شهيداً بيني وبينكم وهو الغفور } لذنوب التائبين {  الرحيم } بعباده قيل :  يخوضون في أمر محمد ( صلى الله عليه وآله وسلم ) وتكذيبه ،  وقيل :  في القرآن غفور لم يعاجلهم بل انظرهم ،  رحيم يقبل توبتهم<br />
