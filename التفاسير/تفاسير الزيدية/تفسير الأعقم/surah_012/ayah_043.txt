قوله تعالى :  {  وقال الملك إني أرى سبع بقرات سمان } خرجن من نهر يابس وسبع بقرات {  عجاف } فابتلعت العجاف السمان ورأى {  سبع سنبلات خضر } قد انعقد حبها وسبعاً {  أخر يابسات } قد استحصدت فأدركت ،  فالتوت اليابسات على الخضر حتى غلبن عليها ،  فاستعبرها فلم يجد من قومه من يحسن عبارتها ،  وقوله تعالى :  {  يأيها الملأ } يعني الأشراف ،  وروي أنه جمع السحرة والكهنة فقصّها عليهم فقالوا :  ما حكى الله سبحانه عنهم {  أضغاث أحلام }<br />
