{  الصابرين } على الطاعة وعن المعصيَّة {  والصادقين } في أفعالهم وأقوالهم واعتقادهم في السرّ والعلانية {  والقانتين } قيل :  المطيعين ،  وقيل :  الدائم على العبادة ،  وقيل :  القنوت القيام بالواجب على التمام {  والمنفقين } المؤَدون الزكاة ،  قيل :  في السر {  والمستغفرين بالأسحار } قيل :  هم المصلّون وقت السحر ،  وقيل :  السائلون المغفرة ،  وقيل :  المصلّون الفجر جماعات ،  روي أن داوود ( عليه السلام ) سأل جبريل ( عليه السلام ) :  أي الليل أفضل ؟  فقال :  لا أدري إلا أن العرش يهتز عند السحر . <br />
