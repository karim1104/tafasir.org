{  سخّرها } سلطها {  عليهم سبع ليال وثمانية أيام حسوماً } قال وهب :  هي التي تسمى للعرب أيام العجوز ذات برد ورياح شديدة ،  ونسبت إلى العجوز لأن عجوزاً دخلت سرباً فتبعتها فقتلتها اليوم الثامن وانقطع العذاب ،  وهي آخر الشتاء ،  والحسوم القاطعة كأنه يتابع عليهم الشر حتى استأصلهم ،  وقيل :  {  فترى القوم فيها صرعى } مصروعين هلكى {  كأنهم أعجاز } قيل :  أصول النخل {  خاوية } خالية إلا خراب ،  وشبهوا قيل :  شبهوا بذلك لعظم أجسامهم ،  وقيل :  لما أرسل عليهم الريح قاموا واعتمدوا على أجلهم ليدفعوا الريح فزمعتهم بين السماء والأرض وأهلكتهم<br />
