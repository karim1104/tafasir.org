قوله تعالى :  {  ولتصغى اليه } أي لتميل إليه قلوب هؤلاء {  الذين لا يؤمنون بالآخرة وليرضوه } قال ابن عباس :  يرجع ،  يقال :  صغى يصغي صغياً {  وليقترفوا ما هم مقترفون } أي ليكتسبوا ما هم مكتسبون في عداوة النبي ( صلى الله عليه وآله وسلم ) والمؤمنين ،  يقال :  اقترف فلان مالاً أي اكتسبه ،  قال تعالى :  {  ومن يقترف حسنةً } [ الشورى :  23 ] وقال الشاعر : <br />
