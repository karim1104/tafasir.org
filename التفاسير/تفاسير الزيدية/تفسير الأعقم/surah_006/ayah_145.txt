ثم بين سبحانه المحرمات فقال :  {  قل } يا محمد {  لا أجد فيما أُوحي إلي محرما } أي شيئاً محرماً {  على طاعم يطعمه } أكل يأكله ،  قوله تعالى :  {  إلاَّ أن يكون ميتةً أو دماً مسفوحاً } أي مصبوباً كدم العروق فأما الكبد والطحال فدمٌ جامدٌ غير مسفوح ،  وكذا الدم الذي يخالط اللحم فليسَ بمسفوح {  أو لحم خنزير فانه رجسٌ } اي نجس خبيث حرام {  أو فسقاً } معصية {  أهل لغير الله به } يعني ما ذبح وذكر عنده اسم الأوثان {  فمن اضطر } قيل :  بلغ الضرورة في المجاعة {  غير باغ } طالب التلذذ بأكله {  ولا عاد } مجاوز قدر حاجته {  فان ربك غفور رحيم } . <br />
