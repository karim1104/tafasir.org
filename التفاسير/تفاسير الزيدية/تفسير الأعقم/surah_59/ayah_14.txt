{  لا يقاتلونكم جميعاً } يعني اليهود لا يقاتلون المسلمين {  إلا في قرى محصنة أو من وراء جدر } قيل :  لاختلاف قلوبهم لا يحشدون البروز للحرب إلا في مواضع حصنة وخلف جدار {  بأسهم بينهم شديد } قيل :  عداوة بعضهم شديدة {  تحسبهم جميعاً وقلوبهم شتى } أي يحسب الناظر أنهم مجتمعون وقلوبهم متفرقة ،  وقيل :  قلوبهم شتى أي قلوب المنافقين وأهل الكتاب ،  وقيل :  أهل الباطل مختلفة أهواءهم وهم مجتمعون على عداوة أهل الحق {  ذلك بأنهم قوم لا يعقلون } أمر الله  . <br />
