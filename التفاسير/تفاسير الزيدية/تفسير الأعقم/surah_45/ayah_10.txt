{  أولئك لهم عذاب مهين } ثم فسَّره فقال سبحانه :  {  من ورائهم جهنم } عبر بلفظ الجمع ومرة بلفظ الواحد ؛  لأنه أراد الجنس ،  والمعنى بين أيديهم جهنم يصيرون إليها {  ولا يغني عنهم } ولا يكفي في المنع من عظم عذاب الله {  ما كسبوا شيئاً } من أموالهم {  ولا ما اتخذوا من دون الله أولياء } ،  قيل :  الأوثان ،  وقيل :  الرؤساء وعلماء السوء {  ولهم عذاب عظيم } . <br />
