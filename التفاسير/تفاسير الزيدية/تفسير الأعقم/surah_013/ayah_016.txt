{  قل } يا محمد لهؤلاء الكفار {  من رب السماوات والأرض } يعني خالقهما ومدبرهما فلا يمكنهم أن يقولوا الأصنام فقل أنت هو الله {  قل أفاتخذتم من دونه أولياء } ،  قيل :  أرباباً {  لا يملكون لأنفسهم نفعاً ولا ضراً } فكيف ينتفع غيرها {  قل هل يستوي الأعمى والبصير } كذلك لا يستوي المؤمن والكافر {  أم هل تستوي الظلمات والنور } أي لا تستوي ظلمات الجهل ونور العلم والهدى {  أم جعلوا لله شركاء خلقوا كخلقه فتشابه الخلق عليهم } يعني هذه الأصنام قد خلقوا مثل خلق الله فتشابه عليهم خلق الله وخلقهم فدل على أنه المستحق للعبادة دونها لأنهم لم يخلقوا شيئاً<br />
