قوله تعالى :  {  لقد سمع الله قول الذين قالوا إن الله فقير ونحن أغنياء } الآية نزلت في فنحاص اليهودي وذلك أنه لما نزل قوله تعالى :  {  من ذا الذي يقرض الله قرضاً حسناً } [ البقرة :  245 ] قال فنحاص اليهودي :  إن الله فقير يحتاج الى قرض فنزلت الآية ،  ومعنى {  سمع الله قولهم } أنه لم يُخْف عليه وأنه أعدَّ له كناية من العقاب {  سنكتب ما قالوا } في صحائف اعمالهم وهذا على جهة الوعيد {  ونقول لهم } يوم القيامة {  ذوقوا عذاب الحريق } كما أذقتم المسلمين الغصَص
