{  ويعلمه الكتاب } قيل :  الخط {  والحكمة } سنن الأنبياء ( عليهم السلام ) ،  وقيل :  قسم الله الخط عشرة أجزاء جعل للمخلوقين جزءاً ولعيسى <br />
( عليه السلام ) تسعة أجزاء ولما رفع عيسى ( عليه السلام ) بكت عليه مريم بكاءاً عظيماً فهبط بعد سبعة أيام وأخبرها بحاله وعاشت أمه بعد رفعه ثلاث سنين ،  وقيل :  ستاً وحملت به ولها ثلاث عشرة سنة ورفع ( عليه السلام ) وله ثلاث وثلاثون سنة . <br />
