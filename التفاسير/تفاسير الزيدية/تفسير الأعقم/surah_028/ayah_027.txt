{  قال } الشيخ لموسى :  {  إني أريد أن أنكحك إحدى ابنتي هاتين } ،  قيل :  الصغيرة ،  وقيل :  الكبيرة صفراء والصغيرة صفيرا {  على أن تأجرني } يعني على أن تكون أجيري {  ثماني حجج } ،  قيل :  جعل مهر بنته هذا الذي عقد عليه ،  وقيل :  بل زوجه بمهر واستأجره للرعاء ولم يجعل ذلك مهراً ،  ولكن شرط ذلك عليه {  فإن أتممت عشراً } فمن عندك أي أنت متبرع به {  وما أريد أن أشق عليك } أي أضيق {  ستجدني إن شاء الله من الصالحين } ،  قيل :  من الموفين بالعهد فقال موسى ( عليه السلام ) :  {  ذلك بيني وبينك أيّما الأجلين قضيت }<br />
