{  ولكل أمة رسول } يبعث إليهم ينبِّههم على التوحيد ويدعوهم إلى دين الحق {  فإذا جاء رسولهم } بالبيَّنات كذبوه ولم يتبعوه {  قضي بينهم } أي بين النبي ومكذبيه {  بالقسط } أي بالعذاب فأنجى الرسول وعذب المكذبون أو يكون المعنى لكل أمة من الأمم رسول يوم القيامة تنسب إليه فإذا جاء رسولهم قضى بينهم في الموقف ليشهد عليهم بالكفر والإِيمان قضي بينهم<br />
