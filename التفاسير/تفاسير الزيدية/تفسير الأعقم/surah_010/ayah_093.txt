قوله تعالى :  {  ولقد بوَّأنا بني إسرائيل } أي مكنّا ،  وقيل :  هيّأنا لهم منازل يرجعون إليها ،  وقوله تعالى :  {  مبوّأ صدق } منزلاً صالحاً وهو مصر والشام {  ورزقناهم من الطيبات } الحلال وهو مواريث أهل مصر والشام فإنهم أخرجوا وتركوا أموالهم وديارهم فأغرقوا {  فما اختلفوا } يعني بني إسرائيل وهم اليهود الذين كانوا زمن النبي ( صلى الله عليه وآله وسلم ) كانوا على الاقرار بالنبي قبل مبعثه<br />
