{  يسبح لله ما في السماوات وما في الأرض } أي ينزهه كل شيء ويشهد بالوحدانية والربوبيَّة بما ركب فيه من التدابير العجيبة والصنيع البديع الدال على أنه عالمٌ حيٌ سميعٌ بصيرٌ لا يشبهه شيء وإنه حكيم ،  وأما قوله مرة سبَّح ومرة يسبّح إشارة إلى دوام تنزيهه بالماضي والمستقبل {  الملك } القادر على جميع الأشياء {  القدوس } الطاهر المنزه عن المثل والشبه والأفعال القبيحة {  العزيز } القادر الذي لا يمتنع عليه شيء {  الحكيم } العالم<br />
