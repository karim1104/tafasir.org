{  وإذ قال موسى لقومه اذكروا نعمة الله عليكم إذ أنجاكم } خلصكم {  من آل فرعون } يعني قومه واتباعه ومن كان على دينه {  يسومونكم } قيل :  يعذبونكم ،  وقيل :  يذيقونكم {  سوء العذاب } أي أشده {  ويذبحون أبناءكم ويستحيون نساءكم } أي يستبقون النساء للخدمة أحياء {  وفي ذلكم } أي ما تقدم ذكره {  بلاء من ربكم عظيم } ،  قيل :  نعمة عظيمة منّ الله بها عليكم ،  وقيل :  بلاء وشدة ومحنة ،  وقيل :  امتحان بالتخلية والترك قال :  أنجاكم والأول أقرب وهو لن المراد به النعمة وهو الذي يوافق صدر الآية وهو قوله :  {  واذكروا نعمة الله عليكم }<br />
