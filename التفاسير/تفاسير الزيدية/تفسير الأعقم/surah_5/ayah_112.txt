قوله تعالى :  {  إذ قال الحواريون يا عيسى ابن مريم هل يستطيع ربك } قال جار الله :  فإن قلتَ :  كيف قالوا :  {  هل يستطيع } بعد إيمانهم وإخلاصهم ؟  قلتُ :  ما وصفهم الله بالايمان والاخلاص وإنما حكى ادعاءهم لذلك ،  وقوله :  {  هل يستطيع ربك } كلام لا يرد مثله عن مؤمنين مطيعين لربهم ،  ولذلك قال ( عليه السلام ) :  {  اتقوا الله إن كنتم مؤمنين } ،  ولا تشكّوا في اقتداره واستطاعته ولا تقترحوا عليه الآيات فتهلكوا إذا عصيتموه بعدها {  إن كنتم مؤمنين } أي كانت دعواكم للإِيمان صادقة<br />
