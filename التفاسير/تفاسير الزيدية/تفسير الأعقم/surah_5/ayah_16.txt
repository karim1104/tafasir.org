وقوله :  {  يهدي به الله } قيل :  بالنبي ( صلى الله عليه وآله وسلم ) ،  وقيل :  بالقرآن {  من اتبع رضوانه } يعني الإِيمان وتصديق النبي ( صلى الله عليه وآله وسلم ) ،  {  سبل السلام } هو دين الله الذي شرعه للعباد وهو الإِسلام ،  وقيل :  يهديه إلى طريق الجنة وهو دار الإِسلام {  ويخرجهم من الظلمات إلى النور } يعني يخرج بالقرآن وبالرسول عباده من ظلمة الكفر إلى نور الإِسلام {  بإذنه } بأمره {  ويهديهم إلى صراط مستقيم } قيل :  طريق وهو دين الإِسلام ،  وقيل :  إلى طريق الجنة<br />
