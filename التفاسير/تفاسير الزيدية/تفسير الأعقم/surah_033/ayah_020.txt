{  يحسبون الأحزاب لم يذهبوا } أي ظنّ المنافقون أن جماعات قريش وغطفان وغيرهم من اليهود والذين تحزبوا على رسول الله ( صلى الله عليه وآله وسلم ) لم يذهبوا ولم ينصرفوا ،  وإنما ظنوا ذلك لشدة خبثهم وقلَّة إيمانهم وقد انهزموا بالريح {  وإن يأت الأحزاب } أي رجعوا مرة ثانية {  يودوا لو أنهم بادون في الأعراب } أي كانوا بالبادية مع الأعراب ولم يشهدوا هذا المقام لكراهة الجهاد {  يسألون عن أنبائكم } أي عن أخباركم ،  قيل :  يسأل بعضهم بعضاً :  {  ولو كانوا فيكم } يعني المنافقين {  ما قاتلوا إلا قليلاً } منهم يراؤون بأنهم فيكم وقصدهم الغنيمة . <br />
