{  الذين يتّخِذُون الكافرين أولياءَ } أنصاراً {  من دون المؤمنين } قيل :  هم اليهود ،  وقيل :  مشركي العرب بمكة وقيل :  سائر الكفار {  أيبتغون } أيطلبون {  عندهم } أي عند الكفار {  العزَّة } أي العزَّة والنصرة على محمد والغلبة عليه {  فإن العزَّة لله جميعاً } يريد لأوليائه الذين كتب لهم العزَّة والغلبة على اليهود وغيرهم ،  قال تعالى :  {  ولله العزَّة ولرسوله وللمؤمنين } [ المنافقون :  8 ]
