قوله تعالى :  {  فكيف إذا جئنا من كل أمة بشهيدٍ } يشهد عليهم بما فعلوا وهو نبيهم كقوله تعالى :  {  وكنت عليهم شهيداً ما دمت فيهم } [ المائدة :  117 ] قوله تعالى :  {  وجئنا بك على هؤلاء } المكذبين {  شهيداً } وعن ابن مسعود أنه قرأ سورة النساء على رسول الله ( صلى الله عليه وآله وسلم ) حتى بلغ قوله :  {  وجئنا بك على هؤلاء شهيداً } فبكى ( صلى الله عليه وآله وسلم ) وقال :   "  حسبُنَا  "
