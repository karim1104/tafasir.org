{  وكم من قرية } أي من أهل قرية {  أهلكناها } بالعذاب ،  قوله تعالى :  {  فجاءها بأسنا } قيل :  عذاب الله ،  وقيل :  اهلكناها بإرسال الملائكة فجاءها العذاب {  بياتا } أي ليلاً {  او هم قائلون } أي وقت القائلة وهو نصف النهار وإنما خصّ الوقتين لأنهما وقت راحة ،  قال :  أخذ بالشدة فيه أعظم في العقوبة<br />
