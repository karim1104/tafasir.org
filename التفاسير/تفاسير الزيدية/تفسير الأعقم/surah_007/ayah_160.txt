{  وقطعناهم } أي صيرناهم قطعاً ،  أي فرقاً {  اثنتي عشرة أسباطاً أمماً } يعني اثني عشر قبيلة من اثني عشر ولداً من ولد يعقوب ،  أمماً لأن كل سبط كان أمة عظيمة قوله تعالى :  {  وأوحينا إلى موسى إذ استسقاه قومه أن اضرب بعصاك الحجر } ،  قيل :  كان له أربعة أوجه لكل وجه ثلاث أعين {  فانبجست } أي فانفجرت وهو الانفتاح {  قد علم كل أناس } أي كل سبط {  مشربهم وظللنا عليهم الغمام } في التيه يقيهم حرّ الشمس<br />
