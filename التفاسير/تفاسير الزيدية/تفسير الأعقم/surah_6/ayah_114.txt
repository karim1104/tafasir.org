{  أفغير الله أبتغي حكماً } فيه إضمار ،  أي قل يا محمد :  أفغير الله أطلب حاكماً يحكم بيني وبينكم {  وهو الذي أنزل إليكم الكتاب } ،  يعني القرآن {  مفصلاً } بين الحلال والحرام والكفر والإِيمان ،  وقيل :  يفصل بين الصادق والكاذب {  والذين آتيناهم الكتاب } هم أهل التوراة والانجيل {  يعلمون أنه } نبي وأن القرآن {  منزَّل } وقيل :  هم كبراء الصحابة ،  وأصحاب بدر والكتاب القرآن . <br />
