قوله تعالى :  {  قد خسر } قد غبن وهلك {  الذين كذبوا بلقاء الله } يعني بالبعث بعد الموت {  حتى إذا جاءتهم الساعة بغتة } يعني فجأة {  قالوا يا حسرتنا على ما فرَّطنا فيها } يعني على ما فرطنا في الدنيا من طاعة الله ،  ومنه ما فرطت في جنب الله {  وهم يحملون أوزارهم على ظهورهم } آثامهم وأثقالهم كقوله تعالى :  {  فبما كسبت أيديكم } [ الشورى :  30 ] والأوزار عبارة عن جملة الذنوب {  ألا ساء ما يزرون } بئس شيئاً يزرون وزرهم كقوله تعالى :  {  ساء مثلاً القوم } ،  وقيل :  المؤمن إذا خرج من قبره جاءه عمله فيركب ظهر الكافر ،  والوزر الثقيل من الإِثم ،  وجمعه أوزار ،  ومنه حتى تضع الحرب أوزارها أي أثقالها
