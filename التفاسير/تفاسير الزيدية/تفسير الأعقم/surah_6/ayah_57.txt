قوله تعالى :  {  قل إني على بينة من ربي } أي على حجة ومعجزة {  وكذبتم به } ،  قيل :  بالقرآن ،  وقيل :  بالبينات ،  وقيل :  بربكم {  ما عندي ما تستعجلون به } الآية نزلت في النضر بن الحرث حين قال :  {  فأمطر علينا حجارة من السماء } [ الأنفال :  32 ] وقيل :  في الذين اقترحوا الآيات {  إن الحكم إلا لله } الحكم الذي يفصل بين المحقين والمبطلين {  يقصُّ الحق } بالصاد معناه بقوله ويخبر وبالضاد المعجمة من القضاء ،  أي يفصل بالحق من الباطل {  وهو خير الفاصلين }
