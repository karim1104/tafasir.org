قوله تعالى :  {  ووهبنا له اسحاق } أي اعطينا إبراهيم اسحاق وهو ابنه من سارة {  ويعقوب } بن اسحاق {  كُلاًّ هدينا } وفقنا وأرشدنا ،  وقيل :  هدينا بالنبوة ،  وقيل :  بالكرامة والمدح والثواب {  ونوحاً هدينا من قبل } أي من قبل إبراهيم وولده {  ومن ذريته } أي من ذرية نوح ( عليه السلام ) لأنه أقرب المذكورين ،  وقيل :  من ذرية ابراهيم ولوطاً لم يكن من ذرية ابراهيم {  داوود } ابن آشا {  وسليمان } ابنه {  وأيوب } ابن أموص {  ويوسف } ابن يعقوب {  وموسى } هو موسى بن عمران بن يصهره {  وهارون } هو أخو موسى وأكبر منه سناً بسنةٍ {  وكذلك } أي وكما جزينا إبراهيم على توحيده كذلك {  نجزي المحسنين }<br />
