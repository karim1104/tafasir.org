قوله تعالى :  {  فأخرجنا منه خضراً } قيل :  من الماء ،  وقيل :  من النبات يعني ورقاً خضراً وهو رطب البقول {  نخرج منه } أي من الخضرة {  حبّاً متراكباً } يعني سنابل الحبوب تركب بعض الحبوب بعضاً {  ومن النخل } أي ونخرج من النخل {  من طلعها قنوان } أي :  من ثمرها وهو جمع قنو وهو العذق مثل صنوٍ وصنوان قال أبو عبيدة :  ولا نظير لها في كلام العرب {  دانية } أي قريبة ينالها القائم والقاعد {  وجنات } يعني وأخرجنا منه جناتٍ {  من أعناب والزيتون والرمان مُشتبِهاً وغير متشابه } ،  قيل :  متشابهاً ورقه مختلفاً ثمره ،  وقيل :  متشابهاً في المنظر مختلفاً في المطعم ،  قوله تعالى :  {  إذا أثمر وينعه } يعني نضجه وأدركه {  إن في ذلك لآيات لقوم يؤمنون }<br />
