{  قل } يا محمد {  آلذكرين حرم ام الانثيين } يعني ذكر الضأن والمعز حرمهما الله تعالى أو أُنثاهما فان كانت الذكور حرمهما في مواكل ذكر وان كانت الأنوثة فحرموا كل انثى {  أمَّا اشتملت عليه أرحام الانثيين } وهو النعاج والماعز أم حرم ما خصَّهما الرحم من الانثيين ولا تشتمل الرحم إلاَّ على اما ذكر أو انثى فلم تحرمون بعضاً وتحلون بعضاً ؟  {  نبئوني بعلم } أي أخبروني بأمر معلوم من جهة الله تعالى يدل على تحريم ما حرمتم {  ان كنتم صادقين } في ان الله تعالى حرمه ،  وكانوا يقولون ان الله حرم هذا الذي نحرمه فقال تعالى :  {  أم كنتم شهداء } على معنى عرفتم الوصية مشاهدين على أنكم لا تؤمنون بالله ورسوله {  فمن أظلم ممن افترى على الله كذباً } ينسب إليه تحريم ما لم يحرم {  ليضل النَّاس بغير علم } وهو عمرو بن لحي الذي بحر البحائر وسيب السوائب<br />
