ثم بيَّن تعالى أخبار المنافقين فقال تعالى :  {  وإذا أنزلت سورة } من القرآن على رسول الله ( صلى الله عليه وآله وسلم ) وفيها الأمر بالايمان والجهاد {  مع رسوله استأذنك } أي طلب منك الإذن في القعود {  أولو الطول منهم } ،  قيل :  أولو المال والقدرة ،  وقيل :  الطول الغنى ،  وقيل :  هم الكبراء {  وقالوا ذرنا نكن مع القاعدين } ،  قيل :  النساء والصبيان ،  فقال سبحانه :  {  رضوا بأن يكونوا مع الخوالف }<br />
