{  ألم يأتهم نبأ الذين من قبلهم } يعني قبل هؤلاء المنافقين والكافرين أي خبر الذين من قبلهم من الأمم الماضية حين عصوا الله ورسوله وخالفوا أمره حتى أهلكهم الله تعالى لأن قوم نوح أهلكوا بالطوفان {  وعاد } وهم قوم هود أهلكوا بالريح الصرصر {  وثمود } قوم صالح أهلكوا بالرجفة {  وقوم ابراهيم } بسلب النعمة وهلك نمرود {  وأصحاب مدين } قوم شعيب هلكوا بالعذاب يوم الظلّة ومدين اسم للبلد التي كان فيها شعيب ( عليه السلام ) {  والمؤتفكات } المتقلبات وهم قوم لوط {  أتتهم رسلهم بالبينات } الآية ،  ولما تقدم ذكر المنافقين عقبه بذكر المؤمنين وما أعد لهم فقال تعالى :  {  والمؤمنون والمؤمنات بعضهم أولياء بعض }<br />
