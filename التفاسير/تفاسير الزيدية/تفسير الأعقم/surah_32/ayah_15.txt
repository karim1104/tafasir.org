{  إنما يؤمن بآياتنا } أي بالقرآن وسائر الحجج {  الذين إذا ذكروا بها } أي وعظوا سجدوا تواضعاً لله وخشوعاً وشكروا على ما رزقهم من الإِسلام {  وسبّحوا بحمد ربهم } ونزهوا الله من نسبة القبائح اليه وأثنوا عليه حامدين له {  وهم لا يستكبرون } كما من يصرّ مستكبراً كأن لم يسمعها ومثله قوله :  {  إن الذين أوتوا العلم من قبله إذا يتلى عليهم يخرون للأذقان سجداً } [ الإسراء :  107 ] {  ويقولون سبحان ربنا }
