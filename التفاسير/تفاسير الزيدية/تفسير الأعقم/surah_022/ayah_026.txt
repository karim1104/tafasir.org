{  وإذ بوَّأنا لإِبراهيم } .  قال جار الله :  واذكر حين جعلنا لإِبراهيم {  مكان البيت } ودللناه عليه قيل :  أراه جبريل مكانه لأنه رفع إلى السماء أيام الطوفان وكان من ياقوتة حمراء فأعلم الله إبراهيم مكانه {  وطهّر بيتي } من الأصنام والأوثان والأقذار أن يطرح حوله {  للطائفين } أي من يطوف بالبيت {  والقائمين } في الصلاة {  والركع السجود } لمن يعبد الله ويخضع<br />
