ثم عاد الكلام إلى الجهاد فقال سبحانه :  {  فلا تهنوا وتدعوا إلى السلم } قيل :  لا تضعفوا وتملوا لقاء العدو ،  وقوله :  {  وتدعوا إلى السلم } إلى الصلح والمسالمة {  وأنتم الأعلون } أي القاهرون والغالبون إشارة إلى أن الغلبة للمؤمن في الدنيا والثواب في الآخرة {  والله معكم } أي ناصركم {  ولن يتركم أعمالكم } ،  قيل :  لا ينقصكم أجوركم بل يثيبكم عليها ويزيدكم من فضله . <br />
