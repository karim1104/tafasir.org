{  والذين جاهدوا فينا } في طلب رضانا ،  أو جاهدوا الأعداء باليد واللسان ،  أو جاهدوا أنفسهم {  لنهدينهم سبلنا } يعني سبيل الجنة والثواب ،  وقيل :  سبل الخير بالتوفيق {  لنهدينهم } هداية إلى الخيرات وتوفيقاً كقوله :  {  والذين اهتدوا زادهم هدىً } [ محمد :  17 ] {  وإن الله لمع المحسنين } لناصرهم ومعينهم .
