قوله تعالى :  {  إنما المؤمنون الذين آمنوا بالله ورسوله } يعني ليس المؤمن المستحق للمدح إلا من كان بهذه الصفة {  وإذا كانوا معه على أمر جامع } الأمر الجامع هو الحرب والغزو والأمور التي يحتاج فيها إلى العدد والقوة {  لم يذهبوا } ولم يتفرقوا عنه {  حتى يستأذنوه } حتى يطلبوا إذنه في الخروج {  إن الذين يستأذنونك أولئك الذين يؤمنون بالله ورسوله فإذا استأذنوك لبعض شأنهم } أمرهم وحاجتهم {  فأذن لمن شئت منهم واستغفر لهم الله إن الله غفور رحيم }<br />
