{  قل } يا محمد {  لا تقسموا } أي لا تحلفوا بأن حدّه {  طاعة } بالقول دون الاعتقاد وهي {  معروفة } عندكم ،  يعني أنكم تكذبون ،  أو طاعة معروفة أمثل لكم وأولى لكم من هذه الايمان الكاذبة {  إن الله خبير بما تعملون } تحذير لهم ،  أي عليم بأعمالكم فيجازيكم بها {  قل أطيعوا الله } فيما أمركم به {  وأطيعوا الرسول } فيما أتاكم {  فإن تولوا } انحرفوا عن طاعة الله وطاعة رسوله {  إنما عليه } أي على الرسول {  ما حمل } من الطاعة والمتابعة ،  فإن لم تطيعوا وتوليتم فقد عرضتم نفوسكم لسخط الله وعذابه {  وإن تطيعوه } أي تطيعوا الرسول {  تهتدوا } إلى الحق {  وما على الرسول إلا البلاغ المُبين } أي ليس عليه إلا آداء الرسالة وبيان الشريعة<br />
