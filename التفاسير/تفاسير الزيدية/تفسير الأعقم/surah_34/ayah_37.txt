{  وما أموالكم ولا أولادكم بالتي تقربكم عندنا زلفى } أي لا يغرنكم ثواب الله ورضائه كثرة أموالكم وأولادكم ،  والزلفى القربى {  إلا من آمن } إلا بمعنى لكن الذي يقرب من ثوابه من آمن {  وعمل صالحاً } وهو استثناء ،  والمعنى أن الأموال لا تقرب أحد إلا المؤمن الصالح الذي ينفقها في سبيل الله {  فأولئك لهم جزاء الضعف } أي جزاء الأضعاف بقوله :  {  فله عشر أمثالها } [ الأنعام :  160 ] {  بما عملوا وهم في الغرفات آمنون } قيل :  القصور آمنون من زوالها ومن كل ما يخاف
