{  سيقول المخلفون } ،  قيل :  عن الحديبية ،  وقيل :  عن تبوك {  إذا انطلقتم إلى مغانم } خيبر على أنه في شأن الحديبية ،  وقيل :  غنائم مطلقة إذا ان المسلمين غالبون غانمون {  لتأخذوها } أي تلك الغنائم {  يريدون أن يبدلوا كلام الله } قيل :  ما وعد الله أهل الحديبية أن الغنيمة [ غنيمة خ ] خيبر لهم خاصة ،  وقيل :  النفير كقوله :  {  لن تخرجوا معي أبداً ولن تقاتلوا معي عدواً } [ التوبة :  83 ] عن الحسن وأبي علي فإذا خرجوا كان ذلك نبذاً لكلام الله تعالى :  {  كذلكم قال الله من قبل } أنكم لا تخرجون معنا {  فسيقولون بل تحسدوننا } أن نصيب معكم من الغنائم {  بل كانوا لا يفقهون إلاَّ قليلاً } يعني قالوا ذلك لجهلهم ولما نهاهم رسول الله ( صلى الله عليه وآله وسلم ) عن الخروج معه أمرهم بالخروج مع داع آخر فقال سبحانه :  {  قل }
