{  وأن استغفروا ربكم ثم توبوا إليه } من ذنوبكم {  يمتعكم متاعاً حسناً } يطول نفعكم في الدنيا بمنافع حسنة مرضية من عيشة واسعة ونعمة متتابعة {  إلى أجل مسمى } إلى أن يتوفاكم كقوله تعالى :  {  فلنحيينه حياة طيبة } [ النحل :  97 ] {  ويؤت كل ذي فضل فضله } يعني ويعطي في الآخرة كل من كان له فضل في العمل وزيادة فيه جزاء فضله {  وإن تولَّوا } عن اتباعي .
