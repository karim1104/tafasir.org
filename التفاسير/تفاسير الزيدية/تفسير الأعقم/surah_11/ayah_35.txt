{  أم يقولون } يعني الكفار {  افتراه } يعني افتراء نوح الكذب فيما يقول عن ابن عباس ،  وقيل :  يعنون محمداً ( صلى الله عليه وآله وسلم ) افتراء فيما يقصُّه علينا من نبأ نوح وغيره يعني فعله من نفسه {  قل } يا محمد {  إن افتريته } من نفسي {  فعلي إجرامي } أي عذاب جرمي ولا تؤاخذون {  وأنا بريء مما تجرمون } أي لا أؤاخذ بجرمكم<br />
