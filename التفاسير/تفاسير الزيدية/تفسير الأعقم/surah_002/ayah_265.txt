قوله تعالى :  {  ومثل الذين ينفقون أموالهم ابتغاء مرضاة الله } أي طلباً لرضائه {  وتثبيتاً من أنفسهم } لقوة اليقين والبصيرة في الدين ومعناه وتثبتوا منها ببذل المال الذي هو شقيق الروح وبذله أشق شيء على النفس {  كمثل جنةٍ } وهو البستان {  بربوةٍ } بمكان مرتفع مستوي تجري فيه الانهار وخص ذلك لأن نبتها أحسن {  أصابها وابلٌ } أي مطر عظيم القطر {  فأتت أُكلها ضعفين } أي مثلين ،  وقيل :  أربعة أمثاله {  فإن لم يصبها وابل فطل } أي مطر صغير القطر يكفيها ،  وقيل :  هو النداوهة أمثل لعمل المؤمن يعني كما ان الجنة تروح في كل حال قل المطر أو كثر كذلك يضعف الله ثواب صدقة المؤمن قلّت نفقته أو كثرت<br />
