{  الذين يأكلون الربا لا يقومون } الآية أي إذا بعثوا من قبورهم لا يقومون {  إلاَّ كما يقوم الَّذي يتخبطه الشيطان } يعني المصروع ،  قوله تعالى :  {  من المس } أي من الجنون ،  وقيل :  مسه الشيطان بالاذاءِ والوسوسة لأن العرب يزعمون ان الشيطان يتخبط الانسان وان الجني يمسه فيختلط عقله ولو كان يقدر على ذلك لكان يتخبط جميع المؤمنين مع شدة عداوته لهم {  ذلك } العقاب سبب قولهم {  إنما البيع مثل الربا وأحل الله البيع وحرم الربا } انكارٌ لتسويتهم بينهما عفى الله عما سلف أي لا يؤاخذ بما مضى منه لانه اخذه قبل نزول التحريم {  ومن عاد } يعني إلى الربا {  فأولئك } الآية<br />
