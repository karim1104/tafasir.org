{  قال } سبحانه {  فالحق والحق أقول } والمراد بالحق أنا اسمه في قوله تعالى :  {  إن الله هو الحق المبين } [ النور :  25 ] والحق الذي هو يقبض الباطل ،  وقيل :  لما أقسم على اغوائهم أقسم الله تعالى أنه يدخله ومن معه النار فقال سبحانه :  {  فالحق والحق أقول لأملأن جهنم منك وممن تبعك منهم أجمعين } من بني آدم
