{  غافر الذنب } يعني غافر ذنب من قال لا إله إلا الله {  وقابل } توبة من قال لا إله إلا الله {  شديد العقاب } لمن لم يقل لا إله إلا الله ،  وقيل :  غافر ذنب المذنبين بالتوبة والطاعة ،  وقيل :  يقبل توبة التائبين {  شديد العقاب } على المصرين {  ذي الطول } ،  قيل :  ذي النعم ،  وقيل :  ذي الفضل على المؤمن ،  وقيل :  ذي السعة ،  وقيل :  ذي القدرة {  لا إله إلا هو } أي هو الموصوف بهذه الصفات دون غيره {  إليه المصير } أي المرجع للجزاء<br />
