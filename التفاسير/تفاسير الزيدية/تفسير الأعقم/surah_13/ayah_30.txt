{  كذلك أرسلناك } يا محمد {  في أمة قد خلت } الآية نزلت في عبد الله بن أميَّة المخزومي وأصحابه حين نزل {  اسجدوا للرحمان } قالوا :  وما نعرف الرحمان إلاَّ صاحب اليمامة يعني مسيلمة ،  وقيل :  نزلت في مشركي العرب قالوا :  أما الله فنعرفه وأما الرحمان فلا نعرفه ،  وقيل :   "  نزلت في صلح الحديبية لما كتب رسول الله ( صلى الله عليه وآله وسلم ) بسم الله الرحمان الرحيم فقال سهيل :  لا نعرف الرحمان اكتب يا محمد باسمك اللهم وكذلك كانوا يكتبون فقال ( صلى الله عليه وسلم ) :   "  أكتب هذا ما صالح عليه محمد رسول الله  "  فقال لإن كتب رسول الله وأنكرناك لقد ظلمناك اكتب هذا ما صالح عليه محمد بن عبد الله  "  ،  وقوله :  كذلك أرسلناك أي هكذا أرسلناك يا محمد ،  وقيل :  كما أرسلنا في الأمم {  أرسلناك في أمة قد خلت من قبلها أمم } قرون وجماعات {  لتتلوا عليهم } القرآن {  الذي أوحينا إليك وهم يكفرون بالرحمان } يجحدونه {  قل } يا محمد {  هو ربي } أي الرحمان الذي أنكرتموه ربي ومبدئي {  لا إله إلا هو عليه توكلت } فوّضت أمري إليه {  وإليه متاب } مرجعي . <br />
