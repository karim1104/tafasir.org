{ ووصينا الإنسان بوالديه إحسانا } يعني : برا { حملته أمه كرها ووضعته كرها } حملته بمشقة ،   ووضعته بمشقة { وحمله } في البطن { وفصاله } فطامه { ثلاثون شهرا } .   قال محمد : { إحسانا } نصب على المصدر ،   المعنى : أمرناه بأن يحسن إليهما إحسانا .   و{ كرها } منصوب بمعنى : حملته أمه على مشقة ،   ووضعته على مشقة .

{ حتى إذا بلغ أشده } يعني : احتلم ،   وبعضهم يقول : عشرين سنة .   قال محمد : وجاء في الأشد ها هنا أنه بضع وثلاثون سنة ،   وهو الأكثر .   قوله : { وبلغ أربعين سنة } أي : في سنه { قال رب أوزعني } يعني : ألهمني { أن أشكر نعمتك } الآية .
