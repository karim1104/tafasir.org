{ وأصبح الذي تمنوا مكانه بالأمس يقولون ويكأن الله } أي : أن الله { يبسط الرزق لمن يشاء } .

{ ويكأنه لا يفلح الكافرون( 82 ) } أي : وإنه لا يفلح الكافرون .   قال محمد : قوله : { ويكأن الله } قال أبو عبيدة : سبيلها سبيل : ( ألم تر ) وقد رأيت بين النحويين وأصحاب اللغة في هذه اللفظة ( ويكأنه ) اختلافا كثيرا ؛ فالله أعلم بما أراد .
