{ إذ دخلوا عليه } في صورة الآدميين { فقالوا سلاما } أي : سلموا عليه { قال سلام } رد عليهم { قوم منكرون( 25 ) } أنكرهم حين لم يأكلوا من طعامه .   قال محمد : { فقالوا سلاما } منصوب [ بتقدير ] : سلمنا عليك سلاما .

وقوله : { قال سلام } مرفوع بمعنى : قال سلام عليكم ،   ويجوز أن يكون على معنى : أمرنا سلام .
