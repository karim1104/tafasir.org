{ فأصابهم سيئات ما كسبوا } ما عملوا من الشرك ؛ يقول : نزل بهم جزاء أعمالهم ؛ يعني : الذي أهلك من الأمم { والذين ظلموا } أشركوا { من هؤلاء } يعني : هذه الأمة { سيصيبهم سيئات ما كسبوا } يعني : الذين تقوم عليهم الساعة كفار آخر هذه الأمة ،   وقد أهلك أوائلهم ؛ أبا جهل وأصحابه بالسيف يوم بدر { وما هم بمعجزين( 51 ) } أي : بالذين يسبقوننا حتى لا نقدر عليهم فنبعثهم ثم نعذبهم .
