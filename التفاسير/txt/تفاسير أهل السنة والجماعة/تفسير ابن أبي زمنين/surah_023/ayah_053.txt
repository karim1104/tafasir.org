{ فتقطعوا أمرهم بينهم } يعني : دينهم الذي أمر الله به { زبرا } وهي تقرأ على وجهين { زبرا } بفتح الباء ورفعها ،   فمن قرأها بالفتح فالمعنى : قطعا ،   ومن قرأها بالرفع فالمعنى : كتبا ،   يقول : فرقوا كتاب الله فحرفوه وبدلوه ،   وكتبوه على ما حرفوا { كل حزب } أي : قوم منهم { بما لديهم } بما عندهم مما اختلفوا فيه { فرحون( 53 ) } أي : راضون
