{ وقيله يا رب إن هؤلاء قوم لا يؤمنون( 88 ) } هذا قول النبي يشكو قومه إلى الله .

قال يحيى : وهي تقرأ على ثلاثة أوجه : { قيلَه } و { قيلُه } و { قيلِه } .

فمن قرأها بالنصب رجع إلى قوله : { أم يحسبون أنا لا نسمع سرهم ونجواهم } ولا نسمع قيله ،   ومن قرأها بالجر رجع إلى قوله : { وتبارك الذي له ملك السماوات والأرض وما بينهما وعنده علم الساعة } وعلم قيله ،   ومن قرأها بالرفع فهو كلام مبتدأ يخبر بقوله .
