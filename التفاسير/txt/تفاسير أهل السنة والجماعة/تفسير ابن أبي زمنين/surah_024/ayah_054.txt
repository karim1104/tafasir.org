{ قل أطيعوا الله وأطيعوا الرسول } يعني : المنافقين ،   ثم قال : { فإن تولوا } يعني : فإن أعرضتم عنهما { فإنما عليه } يعني : الرسول { ما حمل } من البلاغ { وعليكم ما حملتم } من طاعته { وإن تطيعوه } يعني : النبي صلى الله عليه وسلم { تهتدوا وما على الرسول إلا البلاغ المبين( 54 ) } كقوله :{ وما جعلناك عليهم حفيظا } تحفظ عليهم أعمالهم حتى تجازيهم بها .
