{ [ ولا تنكحوا المشركات حتى ] يؤمن ولأمة مؤمنة } يتزوجها المسلم إذا لم يجد طولا { خير [ من مشركة ولو أعجبتكم } ثم ] نسخ المشركات من أهل الكتاب في سورة المائدة ،   فأحلهن ،   فقال : { والمحصنات من الذين أوتوا الكتاب من قبلكم } [ المائدة :5 ] { والمحصنات } في هذه الآية : الحرائر { ولا تنكحوا المشركين حتى يؤمنوا } [ فحرم ] الله أن يتزوج المسلمة أحد من المشركين ،   فقال : { ولعبد مؤمن } تتزوجه المسلمة { خير من مشرك ولو أعجبكم أولئك يدعون إلى النار } يعني المشركين يدعون إلى النار ،   أي إلى دينهم ،   قال : { والله يدعو إلى الجنة والمغفرة بإذنه } بأمره { ويبين آياته للناس } يعني الحلال والحرام { لعلهم يتذكرون } لكي يتذكروا .
