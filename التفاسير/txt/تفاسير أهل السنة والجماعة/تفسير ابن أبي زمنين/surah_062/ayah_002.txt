{ هو الذي بعث في الأميين } العرب { رسولا منهم } كانوا أميين ليس عندهم كتاب من عند الله كما مع أهل الكتاب ،   وقد كانوا يخطون بأيديهم { يتلو عليهم آياته } القرآن { ويزكيهم ويعلمهم الكتاب والحكمة } تفسير قتادة : الكتاب : القرآن ،   والحكمة : السنة ،   والزكاة : العمل الصالح { وإن كانوا من قبل } أن يأتيهم محمد { لفي ضلال مبين( 2 ) } بين .
