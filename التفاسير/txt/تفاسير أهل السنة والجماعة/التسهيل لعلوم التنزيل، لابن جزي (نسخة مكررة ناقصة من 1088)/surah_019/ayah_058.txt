{ أولئك } إشارة إلى كل من ذكر في هذه السورة من زكريا إلى إدريس .

{ من النبيين } من هنا للبيان ،   والتي بعدها للتبعيض .

{ من ذرية آدم } : يعني نوحا وإدريس .

{ وممن حملنا } : يعني إبراهيم .

{ ومن ذرية إبراهيم } : يعني إسماعيل وإسحاق ويعقوب .

{ وإسرائيل } : يعني أن من ذريته موسى وهارون ومريم وعيسى وزكريا ويحيى .   { وممن هدينا } يحتمل العطف على من الأولى أو الثانية .

{ بكيا } جمع باك ووزنه فعول .
