وقوله :  {  وَأَنَّكَ لاَ تَظْمأ فِيها 119 } نَصْب أيضاً .  ومَن قرأ {  وَإِنَّكَ لاَ تَظْمأ } جعله مردودا على قوله ( إنَّ ) التي قبل ( لك ) ويجوز أَن تسْتأنفَها فتكسرها بغير عَطف على شَيء ولو جعلت {  وَأَنَّكَ لاَ تَظْمأ } بالفتح مستأنفة تنوي بها الرفع على قولك ولك أنك لا تظمأ فيها ولا تضحَى كان صَوَاباً .

وقوله :  {  وَلاَ تَضْحَى } :  لا تصيبك شمس مؤذية وذكر في بعض التفسير ( وَلاَ تَضْحَى ) :  لا تَعْرق والأول أشبه بالصواب قال الشاعر :

                                     رأت رجلا أما إذا الشمس أعرضت *** فيَضْحَى وأما بالعَشِيْ فيَخصر

فقد بيّن .  ويقال :  ضحِيت .
