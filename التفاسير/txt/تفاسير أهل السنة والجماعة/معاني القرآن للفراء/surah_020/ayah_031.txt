وقوله :  {  اشْدُدْ بِهِ 31 } دعاء :  ( اشدُدْ به ) يا ربّ ( أَزْري وأشركه ) يا رب ( في أمري ) .  دعاء من موسَى وهي في إحدى القراءتين {  أُشْدُدْ بِهِ أزْرِى وأُشْرِكْه في أَمري } بضم الألف .  وذكر عن الحسن {  أَشْدُدْ به } جزاء للدعاء لقوله {  اجعل لي } {  وأُشْرِكه } بضم الألف في ( أشركه ) لأنها فعل لموسى .
