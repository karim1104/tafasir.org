وقوله :  {  وَجَعَلَ فِيها سُرُجاً61 } قراءة العوام {  سِرَاجاً } حَدِّثنا أبُو العباس قال حدثنا محمد قال حدثنا [ الفرّاء ] قال حدَّثني هُشَيم عن مُغيرة عن إبراهيم أنه قرأ ( سُرُجاً ) .  وكذلكَ قراءة أصحاب عبد الله فمن قرأ {  سراجاً } ذهب إلى الشمس وهو وجه حَسَن ؛  لأنه قد قال {  وَجَعَلَ الشَّمْسَ سِرَاجاً } ومَن قال {  سُرُجاً } ذهب إلى المصَابيح إِذا كانت يُهتدى بها ،  جعلها كالسُرُج والمصْباح كالسراج في كلام العرب 132 ا وقد قال الله {  المِصْبَاحُ في زُجَاجَةٍ }
