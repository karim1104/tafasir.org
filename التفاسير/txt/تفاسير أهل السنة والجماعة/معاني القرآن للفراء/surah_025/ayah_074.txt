وقوله :  {  وَذُرِّيَّاتِنا74 } قرأ أصحاب عبد الله ( وَذُرِّيَّتِنا ) والأكثر {  وذُرِّيَّاتِنا } وقوله {  قُرَّةَ أَعْيُنٍ } ولو قيل :  {  عَيْنٍ } كان صَوَاباً كَما قالت {  قُرَّةُ عَيْنٍ لِي وَلَكَ } ولو قرئت :  قُرَّاتِ أَعْيُن لأنهم كثير كانَ صَوَاباً .  والوجه التقليل {  قُرَّة أعين } لأنه فِعْلٌ والفِعْل لا ( يَكَادُ يجمعُ ) ألاَ تَرى أنه قالَ {  لا تَدْعُوا اليَوْمَ ثُبُوراً وَاحِداً وادْعُوا ثُبُوراً كَثِيراً } فلم يجمعهُ وهو كثيرٌ .  والقُرَّةُ مَصْدَرٌ .  تقول :  قَرَّت عينُكَ قُرّةً .

وقوله {  لِلْمُتَّقِينَ إِماما } ولم يقل :  أئمَّةً وهو واحدٌ يجوز في الكلام أن تقول :  أصْحاب مُحمد أئمَّةُ الناسِ وإمامُ الناسِ كَما قَالَ {  إنا رَسُولُ رَبِّ العالمينَ } للاثنين وَمَعْناه :  اجعنا أئمّةً يُقْتَدَى بنا .  وقال مجاهد :  اجعلنا نقتدِي بمن قبلنا حتى يَقْتدى بنا مَن بعدنا .
