وقوله :  {  فَلَما أَسْلَما وَتَلَّهُ لِلْجَبِينِ103 } يقول :  أسْلما أي فَوَّضَا وأطاعَا وفي قراءة عبد الله ( سلَّما ) يقول سَلّما من التسليم ،  كما تقول :  إذا أصابتك مُصيبةٌ فسَلِّم لأمر الله أي فارْضَ به .

وقد قال {  افْعَلْ ما تُؤْمَرُ } ولم يقل ( به ) كأنه أراد :  افعلِ الأمرَ الذي تؤمره .  ولو كانت ( به ) كان وجها جيّدا وفي قراءة عبد الله ( إني أَرى في المَنامِ افعلْ ما أُمِرْت به ) .  ويقال أين جواب قوله {  فَلَما أسْلَما ؟  } .

وَجَوابها في قوله {  وَنادَيْناهُ } والعرب 160 ا تدخل الواو في جواب فَلَما {  وحَتّى إذا } وتُلْقيَها .  فمن ذلكَ قوله الله {  حَتَّى إذَا جاءوها فُتِحَتْ } وفي موضع آخر {  وَفُتِحَتْ } وكلّ صَوَابٌ .  وفي قراءة عبد الله ( فَلَما جَهَّزَهُمْ بجَهازِهِمْ وجَعَل السِّقَايَةَ } وفي قراءتِنا بغير واو وقد فسرناه في الأنبيَاء .
