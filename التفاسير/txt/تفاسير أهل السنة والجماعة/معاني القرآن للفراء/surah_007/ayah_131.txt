وقوله :  {  فَإِذَا جَاءتْهُمُ الْحَسَنَةُ قَالُواْ لَنا هذه }

والحسنة ها هنا الخفض .

وقوله :  {  لَنا هَذِهِ } يقولون :  نستحقّها {  وَإِن تُصِبْهُمْ سَيِّئَةٌ } يعنى الجدوبة ( يّطّيروا ) يتشاءموا ( بِموسى ) كما تشاءمت اليهود بالنبي صلى الله عليه وسلم بالمدينة ،  فقالوا :  غلت أسعارنا وقلّت أمطارنا مذ أتانا .
