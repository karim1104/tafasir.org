وقوله :  {  مِن بَعْدِ ما كَادَ يَزِيغُ }

و( كاد تزيغ ) .  [ من ] قال :  ( كاد يزيغ ) جعل في ( كاد يزيِغ ) اسما مثل الذي في قوله :  {  عسى أن يكونوا خيرا منهم } وجعل ( يزيغ ) به ارتفعت القلوب مذكّرا ؛  كما قال الله تبارك وتعالى :  {  لن ينالَ اللهَ لحومُها } و {  لا يحل لك النساء من بعد } ومن قال ( تزيغ ) جعل فعل القلوب مؤنّثا ؛  كما قال :  {  نريد أن نأكل مِنها وتطمئن قلوبنا } وهو وجه الكلام ،  ولم يقل ( يطمئن ) وكل فعل كان لجماع مذكر أو مؤنث فإن شئت أنّثت فعله إذا قدمته ،  وإن شئت ذكَّرته .
