وقوله :  {  يا أَيُّها الناسُ إِنَّما بَغْيُكُمْ على أَنفُسِكُمْ }

إن شئت جعلت خبر ( البغي ) في قوله ( على أنفسكم ) ثم تنصب ( متاعَ الحياةِ الدنيا ) كقولك :  مُتْعَةً في الحياة الدنيا .  ويصلح الرفع ها هنا على الاستئناف ؛ كما قال {  لم يلبثوا إِلا ساعة من نهارٍ بلاغ } أي ذلك ( بلاغ ) وذلك ( متاع الحياةِ الدنيا ) وإن شئت جعلت الخبر في المتاع .  وهو وجه الكلام .

{  لِّلَّذِينَ أَحْسَنُواْ الْحُسْنَى وَزِيَادَةٌ وَلاَ يَرْهَقُ وُجُوهَهُمْ قَتَرٌ وَلاَ ذِلَّةٌ أولئك أَصْحابُ الْجَنَّةِ هُمْ فِيها خَالِدُونَ }

وقوله :  {  لِّلَّذِينَ أَحْسَنُواْ الْحُسْنَى }

في موضع رفع .  يقال إن الحسنى الحَسَنة . ( وزيادة ) حدّثنا محمد قال حدّثنا الفرّاء قال حدثني أبو الأحوص سلاّم بن سُلَيم عن أَبى إسحاق السَبِيعيّ عن رجل عن أبى بكر الصدِّيق رحمه الله قال :  للذين أحسنوا الحسنى وزيادة :  النظر إلى وجه الرب تبارك وتعالى .  ويقال ( للذين أحسنوا الحسنى ) يريد حَسَنة مثل حسناتهم ( وزيادة ) زيادة التضعيف كقوله {  فله عَشْرُ أَمثالها } .
