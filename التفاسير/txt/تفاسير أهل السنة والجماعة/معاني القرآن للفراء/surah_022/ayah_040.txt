وقوله :  {  الَّذِينَ أُخْرِجُواْ مِن دِيَارِهِم بِغَيْرِ حَقٍّ40 } يقول لم يخرجوا إلاّ بقولهم :  لا إله إلا الله .  فإن شئت جِعَلت قوله :  {  لاَّ أَن يَقُولُواْ رَبُّنا اللَّهُ } في موضع خَفضٍ تَردَّه على الباء في ( بِغَيْرِ حَقٍّ ) وإن شئِتَ جْعَلت ( أن ) مستثناةً ؛  كما قال {  إلاَّ ابْتغاء وَجْهِ ربِّه الأعلى } .

وقوله :  {  لَّهُدِّمَتْ صَوَامِعُ وَبِيَعٌ } وهي مُصَلّى النصَارى والصوامع للرهبان وأما الصلوات فهي كنائس اليهود والمساجد ( مساجد الإسلام ) ومعنى التهديم أن الله قال قبل ذلك {  وَلَوْلاَ دَفْعُ اللَّهِ الناسَ بَعْضَهُمْ بِبَعْضٍ } يدفع بأمره وأتباعهِ عن دين كل نبيّ ؛  إلى أن بعث الله محمَّد صَلى الله عَليه وسلم .
