وقوله :  {  يَضْرِبُونَ وُجُوهَهُمْ وَأَدْبَارَهُمْ وَذُوقُواْ }

يريد :  ويقولون ،  مضمرة ؛  كما قال :  {  ولَوْ تَرَى إذِ المُجْرِمُونَ ناكِسُو رُءُوسِهم عِنْدَ رَبِّهِم رَبَّنا } يريد يقولون :  ( رَبَّنا ) .  وفي قراءة عبد الله {  وَإِذْ يرفع إِبراهِيمُ القواعِدَ من البيتِ وإِسماعيلُ } يقولان {  رَبَّنا } .
