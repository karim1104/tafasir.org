وقوله :  {  وَاسْتَفْزِزْ64 } يقول اسْتَخِفَّ ( بِصَوْتِكَ ) بدعائك {  وَأَجْلِبْ عَلَيْهِم بِخَيْلِكَ وَرَجِلِكَ } يعنى خيل المشركين ورجالَهم .

وقوله {  وَشَارِكْهُمْ فِي الأَمْوَالِ وَالأَوْلادِ } كلّ مال خالطه حرام فهو شِرْكُهُ .  وقوله {  وَعِدْهُمْ } أي قل لهم :  لا جَنَّة ولا نار .  ثم قال الله تبارك وتعالى {  وَما يَعِدُهُمُ الشَّيْطَانُ إِلاَّ غُرُوراً } .
