وقوله :  {  وَجَعَلْنا السَّماء سَقْفاً مَّحْفُوظاً32 } ولو قيل :  محفوظة يُذهب بالتأنيث إلى السَّماء وبالتذكير إلى السقف كما قال {  أَمَنَةً نُعَاساً تَغْشَى } و ( يَغْشَى ) وقيل ( سَقْفاً ) وهي سموات لأنها سَقْف على الأرض كالسَّقْف على البَيت .  ومعنى قوله ( مَّحْفُوظاً ) :  حُفظت ( منَ الشياطين ) بالنجوم .

وقوله :  {  وَهُمْ عَنْ آيَاتِها مُعْرِضُونَ } فآياتُها قمرها وشمسَها ونجومها .  قد قرأ مجاهد ( وهم عن آياتِها مُعْرِضونَ ) فَوَحَّد ( وَجَعَلَ ) السماء بما فيها آية وكلٌ صواب .
