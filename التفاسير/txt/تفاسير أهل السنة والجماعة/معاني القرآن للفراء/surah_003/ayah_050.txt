وقوله :  {  وَمُصَدِّقاً }

نصبت ( مصدّقا ) على فِعل ( جئت ) ،  كأنه قال :  وجِئتكم مصدّقا لِما بين يدىّ من التوراة ،  وليس نصبُه بتابع لقوله ( وَجِيها ) لأنه لو كان كذلك لكان ( ومصدّقا لما بين يديه ) .

وقوله :  {  وَلأُحِلَّ لَكُم } الواو فيها بمنزلة قوله {  وكذَلِكَ نُرِى إِبرَاهِيمَ مَلَكُوتَ السَّمَاوَاتِ وَالأَرْضِ وَلِيَكُونَ مِنَ الْمُوقِنِين } .
