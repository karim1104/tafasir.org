وقوله :  {  وَلَئِن زَالَتَا41 } بمنزلة قوله :  ولو زالتا {  إِنْ أَمْسَكَهُما } ( إنْ ) بمعنَى ( ما ) وهو بمنزلة قوله :  {  وَلَئِنْ أَرْسَلْنا رِيحا فَرَأَوْهُ مُصْفَرّاً لَظَلُّوا مِنْ بَعْدِه } .

وقوله :  {  وَلَئِنْ أَتَيْتَ الَّّذِينَ أُوتُوا الكتابَ بكُلّ آيةٍ ما تَبِعُوا قِبْلَتَكَ } المعنى معنى ( لو ) وهما متآخِيتان يجابان بجواب وَاحِدٍ .
