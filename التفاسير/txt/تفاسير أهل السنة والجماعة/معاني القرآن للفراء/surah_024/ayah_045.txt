وقوله :  {  وَاللَّهُ خَالقَ كُلَّ دَابَةٍ 45 } و( خَلَق ) وأصحاب عبد الله قرأوا ( خالق ) ذُكر من أبى إسحاق السَّبِيِعيّ - قال الفَراء :  وهو الهَمْداني - أنه قال :  صَليت إلى جنب عبد الله بن مَعْقِل فسمعته يقول ( واللّهُ خَالِقُ كلّ دابَّة ) والعوامُّ بعدُ {  خَلَق كُلَّ } .

وقوله {  كُلَّ دَابَّةٍ مِّن ماء فَمِنْهُمْ مَّن يَمْشِي على بَطْنِهِ } يقال :  كيفَ قال {  مَّن يَمْشِي } وإنما تكون ( مَن ) للناس وقد جعلها ها هنا للبهائم ؟

قلت :  لما قال {  خالق كل دابَّة } فدخل فيهم الناسُ كنى عنهم فقال ( منهم ) لمخالطتهم الناس ،  ثم فسَّرهم بَمن لما كنى عنهم كناية الناس خَاصّة ،  وَأنْت قائل في الكلام :  من هذان المقبلان لرجل وَدَابَّته ،  أو رجلٍ وبعيره .  فتَقوله بِمَن وبما لاختلاطهما ،  ألا ترى أنك تقول :  الرجل وَأباعِرهُ مقبلون فكأنهم ناس إذا قلت :  مقبلونَ .
