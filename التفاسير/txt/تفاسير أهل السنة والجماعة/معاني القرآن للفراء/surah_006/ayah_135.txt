وقوله :  {  فَسَوْفَ تَعْلَمُونَ مَن تَكُونُ لَهُ عَاقِبَةُ الدَّارِ }

( مَنْ تَكُونُ لَهُ ) في موضع رفع ،  ولو نصبتها كان صوابا ؛  كما قال الله تبارك وتعالى :  {  وَاللّهُ يَعْلَمُ المُفْسِدَ مِنَ الْمُصْلِحِ } .

وقوله :  {  مَن تَكُونُ لَهُ عَاقِبَةُ الدَّارِ } إذا كان الفعل في مذهب مصدر مؤنثا مثل العاقبة ،  والموعظة ،  والعافية ،  فإنك إذا قدّمت فعله قبله أنَّثته وذكّرته ؛  كما قال الله عزّ وجلّ :  {  فَمَنْ جَاءهُ مَوْعِظَةٌ مِنْ رَبِّهِ } بالتذكير ،  وقال :  {  قَدْ جَاءتْكُمْ مَوْعِظَةٌ مِنْ رَبِّكُمْ } بالتأنيث .  وكذلك {  وَأَخَذَ الَّذِينَ ظَلَمُوا الصَّيْحَةُ } {  وَأَخَذَتِ } فلا تهابنّ من هذا تذكيرا ولا تأنيثا .
