وقوله :  {  وَاعْبُدُواْ اللَّهَ وَلاَ تُشْرِكُواْ بِهِ شَيْئاً وَبِالْوَالِدَيْنِ إِحْسَانا }

أمرهم بالإحسان إلى الوالدين .  ومثله {  وقضى ربُّك ألاّ تَعْبُدوا إلا إيّاه وبالوالدين إحسانا } ولو رفع الإحسان بالباء إذ لم يظهر الفعل كان صوابا ؛  كما تقول في الكلام :  أحسِنْ إلى أخيك ،  وإلى المسيء الإساءة .

{  وَالْجَارِ ذِي الْقُرْبَى } بالخفض .  وفي بعض ( مصاحف أهل الكوفة وعُتُق المصاحف ) ( ذا القربى ) مكتوبة بالألف .  فينبغي لمن قرأها على الألف أن ينصب ( والجارَ ذا القربى ) فيكون مثل قوله {  حافظوا على الصلواتِ والصلاَة الوسطى } يضمر فعلا يكون النصب به .

{  وَالْجَارِ الْجُنُبِ } :  الجار الذي ليس بينك وبينه قرابة {  وَالصَّاحِبِ بِالجَنْبِ } :  الرفيق {  وَابْنِ السَّبِيلِ } :  الضيف .
