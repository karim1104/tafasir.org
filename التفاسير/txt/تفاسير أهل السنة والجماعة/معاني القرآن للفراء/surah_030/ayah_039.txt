وقوله :  {  لِّيَرْبُوَ39 } قرأها عاصم والأعمش ويحيَى بن وَثَّابٍ باليَاء ونصْب الواو .  وقرأها أهل الحجاز {  لِتُرْبُوَ } أنتم .  وكلّ صواب ومن قرأ {  ليَرْبوَ } كان الفِعل للربا .  ومن قال {  لتُرْبُوا } فالفعْل للقوم الذين خُوطبُوا .  دَلّ على نصبه سُقوطُ النُّون .  ومعناه يقول :  وما أعطيتم من شيء لتأخذوا أكثر منْهُ فَلَيسَ ذلكَ بزاكٍ عند الله {  وَما آتَيْتُمْ مِّن زَكَاةٍ تُرِيدُونَ } بها {  وَجْهَ اللَّهِ } فتلك تَرْبو للتضعيف .

وقوله :  {  هُمُ الْمُضْعِفُونَ } أهل للمضاعفة ؛  كما تقول العرب أصبحتم مُسْمِنينَ مُعْطِشين إذا عطِشت إليهم أو سَمنت .  وسمع الكسائي العرب تقول :  أصْبحتَ مُقْوياً أي إبلك قويَّة ،  وأصبحتَ مُضعفاً أي إبلكَ ضعاف تريد ضعيفة من الضُّعف .
