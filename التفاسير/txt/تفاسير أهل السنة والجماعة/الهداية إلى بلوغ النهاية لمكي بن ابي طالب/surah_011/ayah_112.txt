ثم قال تعالى :  {  فاستقم كما أمرت } :  أي دم يا محمد على ما أنت عليه .

{  ومن تاب معك } :  أي :  رجع إلى عبادة ربك ،  يدوم على ذلك .  {  ولا تطغوا } :  أي :  ولا تتعدوا أمره إلى ما نهاكم عنه .

{  إنه بما ( تعملون ) بصير } :  أي :  ذو علم ،  لا يخفى عليه شيء من عملكم .  وقال سفيان :  معنى {  فاستقم كما أمرت } :  أي :  ( استقم على القرآن ) ،  {  ولا تطغوا } :  وقف .
