قوله :  ( لَيْسَ عَلَى الذِينَ ءَامَنُوا ) الآية  .

المعنى :  في قول ابن عباس وغيره :  - :  أن المؤمنين قالوا لما نزل تحريم الخمر :  ( يا رسول )(    ) الله ،  فكيف بأصحابنا الذين ماتوا وهم يشربون الخمر ؟  ،  فنزلت :  ( لَيْسَ عَلَى الذِينَ ءَامَنُوا وَعَمِلُوا الصَّالِحَاتِ جُنَاحٌ فِيمَا طَعِمُوا ) الآية(    ) .

( إِذَا مَا اتَّقَوا ) أي :  اتقى(    ) اللّهَ الأحياء منهم في اجتناب ما حرم عليهم ،  ( وَّءَامَنُوا ) أي :  وصدقوا الله ورسوله فيما أمرهم(    ) به ،  ( وَعَمِلُوا الصَّالِحَاتِ ) أي :  واكتسبوا من الأعمال ما يرضاه الله ، / ( ثُمَّ اتَّقَوْا وَّ ءَامَنُوا ) أي :   " وَ " (    ) اتقوا محارمه وصدقوا فثبتوا(    ) على ذلك ،  ( ثُمَّ اتَّقَوا وَّأَحْسَنُوا ) أي :  اتقوا الله ،  فدعاهم تقواهم إلى الإحسان ،  وهو العمل بما ( لم )(    ) يفرض عليهم :  من الخير والنوافل(    ) .  فالاتقاء الأول :  اتقاء(    ) تلقي أمر الله وقبوله ،  والثاني :  الاتقاء(    ) بالثبات على الاتقاء الأول وترك التبديل ،  والاتقاء الثالث :  الاتقاء بالإحسان والتقرب بالنوافل(    ) .

فهذه الآية نزلت –في قول الجميع- فيمن مات منهم وهو يشربها ،  أُعلِموا أنه لا جناح عليهم(    ) .  وقال جابر بن عبد الله(    ) :  صبح ناس غداة أُحد الخمر فقتلوا من يومهم جميعاً شهداء ،  وذلك قبل تحريمها ،  يريد :  فنزلت الآية فيهم(    ) .

وقيل :  نزلت فيما أكلوا من الحرام بالميسر و( ما شربوا )(    ) من الخمر فأُعلِموا أنه لا جناح عليهم في ذلك إذا ما اتقوا فيما يستقبلون(    ) .

وقيل :  معنى ( إِذَا مَا اتَّقَوا وَّءَامَنُوا ) أي :  اتقوا شرب(    ) الخمر ،  وآمنوا بتحريمها " (    ) ( ثُمَّ ( اتَّقَوا وَّءَامَنُوا ) ) أي : (    ) :  اتقوا الكبائر وازدادوا(    ) إيماناً ،   " ( ثُمَّ اتَّقَوْا ) "  أي :  اتقوا الصغائر ،  ( وَّأَحْسَنُوا ) بالنوافل(    ) .

وقيل :  ( إِذَا مَا اتَّقَوْا ) الكفر(    ) ،  ( ثُمَّ اتَّقَوْا ) الكبائر ،  ( ثُمَّ اتَّقَوْا ) الصغائر(    ) .
