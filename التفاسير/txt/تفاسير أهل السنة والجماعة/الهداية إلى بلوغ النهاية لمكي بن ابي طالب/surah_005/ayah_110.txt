قوله :  {  إذ قال الله يا عيسى ابن مريم اذكر نعمتي } الآية  .

قرأ ابن محيصن {  إذ أيدتك } ،  وكذلك روي عن مجاهد ،  وهما لغتان .

والمعنى :  واحذروا يوم يجمع الله {  الرسل } ،  فيقول كذا وكذا ،  إذ قال الله يا عيسى ابن مريم .

( و ) قوله :  {  أيدتك ) بروح القدس } أي :  أعنتك بجبريل .  وقوله :  {  وإذ علمتك الكتاب } هو الخط ،  {  والحكمة } :  الفهم بمعاني الكتاب ،  {  والتوراة } :  هو ما أنزل على موسى ،  {  والإنجيل } وهو الذي أنزل عليه ،  ومعنى {  بإذني } :  أي :  بعوني لك .

ومعنى {  تخلق } تعمل وقيل :  تُقَدِّر .

{  وتبرئ الأكمه } هو الذي يولد أعمى ،  وقيل :  يكون الأكمه أيضا ( الذي ) يعمى بعد البصر .

{  وإذ تخرج الموتى } أي :  تخرجهم أحياء من قبورهم ،  {  بإذني } أي :  بعوني {  وإذ كففت بني إسرائيل عنك } أي :  منعتهم إذ هموا بقتلك لما جئتهم بالبينات .  وهذا كله تعديد نِعم الله على عيسى .  والبينات :  الأدلّة المعجزة الدّالّة على نبوتك .

{  إن هذا إلا سحر مبين } :  من قرأ {  سحر } فمن أجل أن بَعْدَه {  مبين } ،  والسحر مما يوصف بالبيان .

ومعنى {  سحر }أي :  عمله ،  وما أظهره سحر .  ومن قرأ :  ( ساحر ) ،  فلأن المذكور في الكلام هو عيسى ،  وليس مما يوصف بأنه سحر ،  لأن الإنسان لا يكون سحرا ،  إنما يكون ساحرا ،  وكل ساحر لا يسمى بذلك حتى يعمل السحر ،  وكل من أضيف إليه سحر فهو ساحر فالقراءتان  متقاربتان .

والكهل :  ابن أربعين سنة ،  وقيل :  ابن أربع وثلاثين سنة .

ومعنى النعمة على عيسى في أن يكلم الناس كهلا :  أنه مد في عمره إلى أن بلغ الكهولية .
