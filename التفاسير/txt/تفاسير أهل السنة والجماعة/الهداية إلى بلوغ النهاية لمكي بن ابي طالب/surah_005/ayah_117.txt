قوله :  {  ما قلت لهم إلا ما أمرتني به } الآية  .

قوله :  {  أن اعبدوا الله } :  ( أن ) مفسرة لا موضع لها من الإعراب ،  بمنزلة ( أن امشوا ) ،  وقيل :  هي في موضع نصب على معنى :  ما ذكرت لهم إلا عبادة الله .

قوله :  {  ما دمت فيهم } :  ( ما ) في موضع نصب ،  {  و } المعنى :  مدة دوامي ،  فهو ظرفٌ عمل فيه {  شهيدا } أي{  و كنت عليهم شهيدا } ،  {  ما دمت } أي :  مدة دوامي .

{  فلما توفيتني } أي :  قبضتني إليك ،  {  كنت أنت الرقيب عليهم } أي :  الحفيظ عليهم .
