ثم قال :  {  بل إياه تدعون } الآية  .

أي إليه تستغيثون ،  {  فيكشف ما تدعون إليه إن شاء } ( أي ) فيكشف الضر الذي من أجله دعوتم .  {  وتنسون ما تشركون } أي :  تنسون شرككم إذا أتاكم العذاب .  فقوله :  {  إن شاء } مشيئة قدرة ،  و( هو لا يشاء أن يكشف ) عنهم العذاب عند نزوله ،  ( لقوله ) :  {  فلم يك ينفعهم إيمانهم لما رأوا بأسنا } .
