قوله :  {  قل أغير الله أبغي ( ربا ) } الآية  .

( و ) المعنى :  {  قل } ( يا محمد لهم ) :  {  أغير الله أبغي ربا } ،  أي :  طلب ربا {  وهو رب كل شيء } أي :  مالك كل شيء .

وأصل ( الرب ) أنه مصدر ( ربه يربه ( ربا ) ،  إذا قام بصلاحه .  وإنما سمي به ،  كما قيل :  ( رجل عدلٌ ) و( رضى ) ،  فرّبٌّ الدار ،  معناه :  مالكها ،  وحقيقته ذو ملكها .

{  ولا تكسب كل نفس إلا عليها } ( أي لا تجترح ( إثما إلا ) عليها ) ،  أي :  لا تؤخذ نفس إلا بما كسبت ،  {  ولا تزر وازرة وزر أخرى } أي :  لا يؤخذ أحد بذنب آخر ،  كل ذي إثم معاقب بإثمه .

وحقيقة / معناه :  أن الله أمر نبيه عليه السلام أن يخبر المشركين أنهم مأخوذون بآثامهم ،  وأنّا لسنا مأخوذين ،  بإجرامكم ولا معاقبين بها ،  {  ثم إلى ربكم مرجعكم فينبئكم بما كنتم فيه تختلفون } .
