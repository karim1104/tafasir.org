قوله :  {  قل إنني هداني ربي إلى صراط مستقيم } الآية [ 162 و163 ] .

قوله :  {  دينا } نصب عند الأخفش ( ب( هداني ) .  وقيل :  المعنى :  أنه نصب ب( عَرَّفَني دينا ) .  كما تقول :  ( ( هو يَدَعُهُ ) ترْكا ) .

وقيل :  هو بدل من ( صراط ) على الموضع .  وقيل :  هو منصوب على المصدر ،  والعنى :  فَدِنْتُ دينا .  وقيل :  المعنى :  هداني فاهتديت دينا ،  ودل ( هداني ) على ( اهتديت ) .

و{  ملة إبراهيم } مثله في التقدير .  وقيل :  هو بدل من ( دين ) .  وشاهد من قرأ ( قيّما ) – بالتشديد – قوله :  {  ذلك الدين القيم } و{  دين القيمة } ،  و{  كتب قيمة } ،  فأجمعوا على تشديد ذلك .

ومن قرأ ( قِيَماً ) بالتخفيف ،  جعله مصدرا ،  مثل :  الصِّغَر والكِبَر .  و{  حنيفا } حال من {  إبراهيم } :  هو نصب بإضمار ( أعني ) .

ومعنى الآية :  {  قل } يا محمد لهؤلاء العادلين :  {  إنني هداني ربي } أي :  أرشدين ودلني على الصراط المستقيم ،  أي :  الطريق القويم ،  وذلك الحنيفية .
