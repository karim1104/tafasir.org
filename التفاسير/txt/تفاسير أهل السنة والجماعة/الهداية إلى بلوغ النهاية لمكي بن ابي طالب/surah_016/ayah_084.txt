قوله :  {  ويوم نبعث من كل أمة شهيدا } إلى قوله   {  وبشرى للمسلمين } [ 84-89 ] .

المعنى :  ثم ينكرونها وسينكرونها يوم نبعث   من كل أمة شهيدا ،  أي :  شهد   عليها بما أجابت   به داعي   الله [ عز وجل   ] وهو رسولهم الذي أرسل إليهم {  ثم لا يوذن للذين كفروا }  يعني :  لا يؤذن لهم في الاعتذار ،  {  ولا هم يستعتبون }  .  أي :  ولا يتركون الرجوع إلى الدنيا فيتوبوا ومثله قوله تعالى :  {  هذا يوم لا ينطقون }    أي :  يعذر :  {  ولا يوذن لهم فيعتذرون }       .
