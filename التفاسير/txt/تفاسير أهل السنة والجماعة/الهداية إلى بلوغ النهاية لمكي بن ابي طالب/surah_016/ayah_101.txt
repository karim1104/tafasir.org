قوله :  {  وإذا بدلنا آية مكان آية }  إلى قوله :  {  وأولئك هم الكاذبون }  .

المعنى عند مجاهد :  وإذا رفعنا آية وأنزلنا أخرى .  وعنه [ أيضا ] :  وإذا رفعنا آية فنسخناها وأثبتنا غيرها .  وقال قتادة وهو قوله :  {  ما ننسخ من آية أو ننسها } .  وقيل معناه :  وإذا بدلنا حكم آية بحكم آية أخرى {  والله أعلم بما ينزل }  مما هو أصلح لخلقه .  قال المشركون لك يا محمد {  إنما أنت مفتر }  أي :  متخرص الكذب على الله {  بل أكثرهم لا يعلمون } حقيقة ذلك لجهالتهم .
