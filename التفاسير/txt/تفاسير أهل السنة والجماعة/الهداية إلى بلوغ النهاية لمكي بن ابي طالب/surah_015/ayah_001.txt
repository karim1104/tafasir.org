قوله :  {  ألر تلك آيات الكتاب وقرآن مبين }  إلى قوله {  وما يستأخرون }  .

قد تقدم ذكر {  ألر } وشبهها .  والمعنى :  هذه تلك ،  أي :  هذه الآيات {  آيات الكتاب }  أي :  آيات الكتب التي كانت قبل القرآن كالتوراة والإنجيل .  قال[ ه ] :  مجاهد وقتادة .

{  وقرآن مبين }  أي :  وآيات قرآن مبين لمن تدبره وتأمله .
