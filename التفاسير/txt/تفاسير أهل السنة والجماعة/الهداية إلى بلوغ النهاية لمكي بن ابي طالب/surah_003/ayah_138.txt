قوله :  ( هَذَا بَيَانٌ لِلنَّاسِ ) الآية  .

وقال الحسن :  ( هَذَا ) إشارة إلى القرآن ،  وقاله قتادة(    ) .

وقال الربيع :  ( هَذَا بَيَانٌ لِلنَّاسِ ) عامة وهو القرآن ( وَهُدىً وَمَوْعِظَةٌ لِلْمُتَّقِينَ ) خاصة(    ) .

وقال ابن اسحاق :  ( هذا ) إشارة إلى قوله ( قَدْ خَلَتْ ) الآية(    ) .

وقال الشعبي :  ( وَهُدىً ) من الضلال ( وَمَوْعِظَةٌ ) من الجهل وذلك لمن اتقى المحارم(    ) .
