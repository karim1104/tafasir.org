{  قل(    ) أعوذ برب الناس } إلى آخرها .

( المعنى :  اقرأ يا محمد :  {  قل أعوذ برب الناس } فَأَثْبَتَ  " قُلْ "  في قراءته كما أُمِر ،  أي ) (    ) :  قل [ يا ] (    ) محمد ،  أستعيذ برب الناس ،  وهو الله جل ذكره ،  {  ملك الناس } ،  وهو الله .

وخصَّ الناسَ بالذكر وهو تعالى جلّ ذِكره ربُّ جميع الخلق ومَلِكُهم ؛  لأن بعض الناس كان يُعظِّم بعضَ الناس تعظيمَ المؤمنين ربَّهم ،  فأعلمهم [ الله ] (    ) أنه رب مَنْ [ يعظمونه ] (    ) ومَلِكُهم(    ) [ يَجري ] (    ) عليهم [ سلطانه ] (    ) وقدرته .
