وقالوا له :  {  أضغاث أحلام } :  أي :  هي أضغاث .  ووقع في نفسه أنها رؤيا كائنة ( لا بد ) من ذلك .

ومعنى :  {  أضغاث أحلام } :  ( أي :  أخلاط أحلام ) كاذبة .

{  وما نحن بتاويل الأحلام } الكاذبة {  بعالمين } :  وتقديره :  وما نحن بعالمين بتأويل الأحلام والأضغاث .  ( والباء ) في {  بعالمين } :  لتأكيد النفي ،  ( والباء في {  بتاويل } للتعدية ،  متعلقة بعالمين ) ففي الكلام تقديم وتأخير .
