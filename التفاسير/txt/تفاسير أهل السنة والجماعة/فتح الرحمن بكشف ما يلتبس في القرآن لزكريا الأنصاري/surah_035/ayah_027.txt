قوله تعالى :  {  فأخرجنا به ثمرات مختلفا ألوانها } [ فاطر :  27 ] .

قاله هنا بتأنيث الضمير لعوده إلى الثمرات ،  وقال ثانيا :  {  مختلف ألوانها } [ فاطر :  27 ] بتأنيثه(  ) أيضا ،  لعوده إلى الجبال ،  وقال ثالثا :  {  مختلف ألوانه } [ فاطر :  28 ] بتذكيره(  ) ،  لعوده إلى بعض المفهوم من اللفظ من قوله :  {  ومن الناس والدّواب والأنعام } [ فاطر :  28 ] .
