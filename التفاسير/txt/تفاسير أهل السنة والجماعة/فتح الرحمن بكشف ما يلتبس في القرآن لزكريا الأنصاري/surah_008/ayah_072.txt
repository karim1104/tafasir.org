قوله تعالى :  {  إن الذين آمنوا وهاجروا وجاهدوا بأموالهم وأنفسهم في سبيل الله } [ الأنفال :  72 ] .  قدّم هنا {  بأموالهم وأنفسهم } على قوله :  {  في سبيل الله } وعكس في  " براءة " (  ) لأن ما هنا تقدَّمه ذكر المال والأنفس ،  في قوله تعالى :  {  تريدون عرض الدنيا } وقوله :  {  لولا كتاب من الله سبق لمسّكم فيما أخذتم } [ الأنفال :  68 ] أي من الفداء ،  وقوله :  {  فكلوا مما غنمتم } [ الأنفال :  69 ] وما في براءة تقدَّمه ذكر {  في سبيل الله } [ الأنفال :  72 ] فناسب تقديم {  بأموالهم وأنفسهم } [ الأنفال :  72 ] وتقديم {  في سبيل الله } ثَمَّ .
