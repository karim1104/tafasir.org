قوله تعالى :  {  ليكفروا بما آتيناهم فتمتّعوا فسوف تعلمون } [ النحل :  55 ] .  قاله هنا ،  وفي الروم(  ) بالتّاء ،  بإضمار القول ،  أي قل لهم :  تمتَّعوا ،  كما في قوله تعالى :  {  قل تمتّعوا فإن مصيركم إلى النار } [ إبراهيم :  30 ] وقوله {  قل تمتّع بكفرك قليلا } [ الزمر :  8 ] .

وقال في العنكبوت(  ) :  {  وليتمتّعوا فسوف يعلمون } [ العنكبوت :  66 ] باللام والياء ،  على القياس ،  إذ هو معطوف على اللام ومدخولها في قوله :  {  ليكفروا بما آتيناهم } [ العنكبوت :  66 ] ومدخولها غائب .
