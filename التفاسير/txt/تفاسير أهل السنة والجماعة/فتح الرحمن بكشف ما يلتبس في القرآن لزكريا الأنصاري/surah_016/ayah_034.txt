قوله تعالى :  {  فأصابهم سيّئات ما عملوا وحاق بهم ما كانوا به يستهزؤون } [ النحل :  34 ] قال فيه وفي الجاثية(  ) {  ما عملوا } [ الجاثية :  33 ] وفي الزّمر(  ) {  بما كسبوا } [ الزمر :  51 ] موافقة لما قبل كلّ منها ،  أو بعده ،  أو قبله وبعده ،  إذ ما هنا قبله {  ما كنا نعمل من سوء } [ النحل :  18 ] و " تعملون "  مرّتين .

وقبلَ ما في الجاثية {  بما كنتم تعملون } [ الجاثية :  28 ] {  وعملوا الصالحات } [ الجاثية :  30 ] وبعده {  سيئات ما عملوا } [ الجاثية :  33 ] .

وقبل ما في الزمر {  ذوقوا ما كنتم تكسبون } [ الزمر :  24 ] وبعده {  فما أغنى عنهم ما كانوا يكسبون } [ الحجر :  84 ] .
