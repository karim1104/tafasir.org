قوله تعالى :  {  لَا يَسْأَلُونَ النَّاسَ إِلْحَافًا .  .  .  } [ البقرة :  273 ] .

فإن قلتَ :  هذا يفهم أنهم كانوا يسألون برفق ،  مع أنه قال :  {  يَحْسَبُهُمُ الْجَاهِلُ أَغْنِيَاءَ مِنَ التَّعَفُّفِ } [ البقرة :  273 ] ؟

قلتُ :  المراد نفي المقيّد والقيد جميعا كما في قوله تعالى :  {  لاَ ذَلُولٌ تُثِيرُ الأَرْضَ } [ البقرة :  71 ] وقوله :  {  اللَّهُ الَّذِي رَفَعَ السَّمَاوَاتِ بِغَيْرِ عَمَدٍ } [ الرعد :  2 ] .
