قوله تعالى :  {  كذّبت قبلهم قوم نوح وعاد وفرعون ذو الأوتاد } إلى قوله :  {  فحقّ عقاب } [ ص :  12-14 ] .

ختم أواخر آياته هنا ،  بما قبل آخره ألف(  ) ،  وآيات قوله في ق :  {  كذّبت قبلهم قوم نوح وأصحاب الرّس وعاد وفرعون وإخوان لوط } إلى قوله :  {  فحقّ وعيد } [ ق :  12-14 ] بما قبل آخره ياء أو واو ،  موافقة لبقية فواصل السورتين .
