قوله تعالى :  {  فأما اليتيم فلا تقهر وأما السائل فلا تنهر وأما بنعمة ربك فحدّث } [ الضحى :  9-11 ] كرّر فيه  " أما "  ثلاث مرات ،  لوقوعها في مقابلة ثلاث آيات مناسبات لها وهي :  {  ألم يجدك يتيما فآوى ووجدك ضالا فهدى ووجدك عائلا فأغنى } [ الضحى :  6-8 ] فقال :  {  فأما اليتيم فلا تقهر } واذكر يُتْمك ،  {  وأما السائل فلا تنهر } واذكر فقرك {  وأما بنعمة ربّك } التي هي النبوة والإسلام ،  فحدّث واذكر ضلالك .
