{ من يصرف عنه يومئذ فقد رحمه وذلك الفوز المبين ( 16 ) } .

{ من يصرف } بالبناء للمفعول ،  أي العذاب ،  { عنه يومئذ فقد رحمه } أي : نجاه وأنعم عليه ،  أو أدخله الجنة ،  لقوله : { فمن زحزح عن النار وأدخل الجنة } .

وقوله : { يدخل من يشاء في رحمته } والجملة مستأنفة مؤكدة لتهويل العذاب .  { وذلك } أي الصرف أو الرحمة ،  { والفوز المبين } أي : الظاهر .
