{ فاسْتَفْتِهِمْ } أي فاستخبر مشركي مكة { أَهُمْ أَشَدُّ خَلْقًا } أي أقوى خلقة وأمتن بنية { أَم مَّنْ خَلَقْنَا } أي من السماوات والأرض والجبال .  كقوله تعالى :  { أأنتم أشد خلقا أم السماء } الآية وقوله :  { لخلق السماوات والأرض أكبر من خلق الناس } وفي اضطرارهم إلى الجواب بصغر خلقهم وتضاؤله عما ذكر ،  اعتراف بأنه لا يتعالى عليه أمر بعد هذا .  كشأن البعث وغيره .  وإليه الإشارة بقوله تعالى : { إنا خلقناهم من طين لازب } أي لزج ضعيف لا قوة فيه .
