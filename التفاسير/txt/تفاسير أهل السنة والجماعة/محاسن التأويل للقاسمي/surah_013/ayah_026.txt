{ الله يبسط الرزق لمن يشاء ويقدر ؛ وفرحوا بالحياة الدنيا وما الحياة الدنيا في الآخرة إلا متاع } هذا كقوله تعالى : { أيحسبون أنما نمدهم به من مال وبنين * نسارع لهم في الخيرات بل لا يشعرون } .  وتنكير { متاع } للتقليل كما في آية : { قل متاع الدنيا قليل والآخرة خير لمن اتقى ولا تظلمون فتيلا } وقال : { بل توثرون الحياة الدنيا * والآخرة خير وأبقى } .
