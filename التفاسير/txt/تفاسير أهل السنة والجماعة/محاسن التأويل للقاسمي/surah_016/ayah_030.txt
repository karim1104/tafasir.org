{ * وقيل للذين اتقوا ماذا أنزل ربكم قالوا خيرا للذين أحسنوا في هذه الدنيا حسنة ولدار الآخرة خير ولنعم دار المتقين 30 } .

{ وقيل للذين اتقوا } وهم المؤمنون { ماذا أنزل ربكم قالوا خيرا } أي أنزل خيرا ،  أي رحمة وبركة لمن اتبعه وآمن به .  ثم أخبر سبحانه عما وعد به عباده بقوله : { للذين أحسنوا في هذه الدنيا حسنة ولدار الآخرة خير } أي لمن أحسن عمله ،  مكافأة في الدنيا بإحسانهم .  ولهم في الآخرة ما هو خير منها .  فقوله : { في هذه الدنيا } متعلق ب { حسنة } كتعلقه ب { أحسنوا } .  قال الشهاب : والحسنة التي في الدنيا الظفر وحسن السيرة وغير ذلك .  وهذه الآية كقوله تعالى : { من عمل صالحا من ذكر أو أنثى وهو مؤمن لنحيينّه حياة طيبة ،  ولنجزينهم أجرهم بأحسن ما كانوا يعملون } وقوله : { فآتاهم الله ثواب الدنيا وحسن ثواب الآخرة } وقال تعالى : { وما عند الله خير / للأبرار } وقال : { والآخرة خير وأبقى } ،  ثم وصف تعالى الدار الآخرة بقوله : { ولنعم دار المتقين } .
