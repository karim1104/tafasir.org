{ فَاصْبِرْ إِنَّ وَعْدَ اللَّهِ حَقٌّ وَاسْتَغْفِرْ لِذَنبِكَ وَسَبِّحْ بِحَمْدِ رَبِّكَ بِالْعَشِيِّ وَالْإِبْكَارِ } .

{ فاصبر } أي إذا تلوت ما قصصناه عليك للناس ،  فاصبر على أذى المشركين واصدع بما تؤمر { إِنَّ وَعْدَ اللَّهِ حَقٌّ } أي بنصرك على من خالف لا خُلف له وهو منجزه واذكر نبأ موسى وفرعون { وَاسْتَغْفِرْ لِذَنبِكَ } أي سله غفرانه وعفوه { وَسَبِّحْ بِحَمْدِ رَبِّكَ بِالْعَشِيِّ وَالْإِبْكَارِ } كقوله تعالى  : { وسبح بحمد ربك قبل طلوع الشمس وقبل الغروب } .
