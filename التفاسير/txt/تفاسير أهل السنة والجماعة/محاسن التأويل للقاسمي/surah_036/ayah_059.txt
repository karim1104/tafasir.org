{ وَامْتَازُوا الْيَوْمَ أَيُّهَا الْمُجْرِمُونَ } أي عن المؤمنين في موقفهم .  كقوله تعالى :  { ويوم نحشرهم جميعا ثم نقول للذين أشركوا مكانكم أنتم وشركاؤكم فزيلنا بينهم } وقوله : { ويوم تقوم الساعة يومئذ يتفرقون } { يومئذ يصدعون } أي يصيرون صدعين فرقتين { احشروا الذين ظلموا وأزواجهم وما كانوا يعبدون * من دون الله فاهدوهم إلى صراط الجحيم } .
