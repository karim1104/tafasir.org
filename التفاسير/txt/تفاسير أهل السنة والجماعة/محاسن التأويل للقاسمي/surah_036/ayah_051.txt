{ وَنُفِخَ فِي الصُّورِ فَإِذَا هُم مِّنَ الْأَجْدَاثِ إِلَى رَبِّهِمْ يَنسِلُونَ } .

{ وَنُفِخَ فِي الصُّورِ } أي للبعث { فَإِذَا هُم مِّنَ الْأَجْدَاثِ } أي :من القبور { إِلَى رَبِّهِمْ يَنسِلُونَ } أي : يعدون مسرعين .  كما في قوله تعالى : { يوم يخرجون من الأجداث سراعا } ولا منافاة بين هذا وما في آية { فإذا هم قيام ينظرون } لأنهما في زمان واحد متقارب .
