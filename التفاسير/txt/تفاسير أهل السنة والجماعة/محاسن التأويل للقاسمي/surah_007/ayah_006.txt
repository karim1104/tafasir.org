ثم تأثر تعالى عذابهم الدنيوي ببيان عذابهم الأخروي ،  بقوله سبحانه :

{ فلنسألن الذين أرسل إليهم ولنسألن المرسلين ( 6 ) } .

{ فلنسألن الذين أرسل إليهم } أي : المرسل إليهم وهم الأمم ،  يسألهم عما أجابوا عنه رسلهم كما قال : { ويوم يناديهم فيقول ماذا أجبتهم المرسلين } .  { ولنسألن المرسلين } أي : عما أجيبوا به ،  كما قال سبحانه : { يوم يجمع الله الرسل فيقول ماذا أجبتم } .  والمراد بالسؤال  توبيخ الكفرة وتقريعهم .
