{ وَلَمَّا أَن جَاءتْ رُسُلُنَا } أي المذكورون بعد مفارقتهم لإبراهيم عليه السلام { لُوطًا سِيءَ بِهِمْ } أي اعترته المساءة بسببهم مخافة أن يقصدوهم { وَضَاقَ بِهِمْ ذَرْعًا } أي ضاق بشأنهم ذرعه ،  أي طاقته { وَقَالُوا لَا تَخَفْ وَلَا تَحْزَنْ إِنَّا مُنَجُّوكَ وَأَهْلَكَ } أي مما يصيبهم من العذاب { إِلَّا امْرَأَتَكَ كَانَتْ مِنَ الْغَابِرِينَ } .
