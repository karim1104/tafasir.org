{ ينادونهم ألم نكن معكم قالوا بلى ولكنكم فتنتم أنفسكم وتربصتم وارتبتم وغرتكم الأماني حتى جاء أمر الله وغركم بالله الغرور }

{ ينادونهم الم نكن معكم } يريدون موافقتهم في الظاهر { قالوا بلى ولكنكم فتنتم أنفسكم } أي محنتموها بالنفاق وأهلكتموها { وتربصتم } أي بالمؤمنين الدوائر ليظهر الكفر فتظهروا ما في أنفسكم { وارتبتم } أي في توحيد الله ونبوة نبيه أو في البعث بعد الموت ،  أو في قوله { ليظهره على الدين كله } ووعده بنصر المؤمنين أو في جميع ذلك { وغرتكم الأماني } أي طول الآمال والطمع في امتداد الأعمار أو قولهم { سيغفر لنا } { حتى جاء أمر الله } يعني الموت أو مصداق وعده بنصره رسوله وإظهاره دينه أو عذاب النار { وغركم بالله الغرور } أي الشيطان فأطمعكم بالنجاة والفوز والغلبة ،  وقرىء { الغرور } بالضم
