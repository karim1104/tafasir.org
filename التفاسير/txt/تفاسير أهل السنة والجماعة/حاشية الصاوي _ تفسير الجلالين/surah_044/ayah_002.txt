قوله: { وَٱلْكِتَابِ } الواو للقسم، و { ٱلْكِتَابِ } مقسم به، وجواب القسم هو قوله: { إِنَّآ أَنزَلْنَاهُ } إلخ: وأما قوله: { إِنَّا كُنَّا مُنذِرِينَ } فهو تعليل للجواب، وهو أحسن من جعل الجواب قوله: { إِنَّا كُنَّا مُنذِرِينَ } وقوله: { إِنَّآ أَنزَلْنَاهُ } جملة معترضة بين القسم وجوابه. قوله: (القرآن) هذا أحد أقوال في تفسير الكتاب وهو أقواها، وعليه فقد أقسم بالقرآن أنه أنزل القرآن في ليلة مباركة، وهذا من أبلغ الكلام الدال على غاية تعظيم القرآن، كما تقول للعظيم: أتشفع بك لك، وفي الحديث: " أعوذ برضاك من سخطك، ويعفوك من عقوبتك، وبك منك " وقيل المراد به في اللوح المحفوظ.
