قوله: { رَهْواً } حال من البحر، وهو في الأصل مصدر رها يرهو رهواً، وإما بمعنى سكن، وإما بمعنى انفرج، والمفسر جمع بينهما. قوله: (فاطمأن بذلك) أي بقوله: { إِنَّهُمْ جُندٌ مُّغْرَقُونَ } والضمير في اطمأن عائد على موسى. قوله: { كَمْ تَرَكُواْ مِن جَنَّاتٍ }  { كَمْ } مفعول لتركوا، والمعنى: تركوا أموراً كثيرة بينها بقوله: { مِن جَنَّاتٍ } إلخ. قوله: (مجلس حسن) أي محافل مزينة ومنازل حسنة، كما هو مشاهد في منازل الملوك الآن. قوله: (متعة) أي أمور يتمتعون بها وينتفعون بها، كالملابس والمراكب. قوله: { فَاكِهِينَ } العامة بالألف، وقرئ شذوذاً بغير ألف، معنى الأولى (ناعمين) كما قال المفسر أي متنغمين، ومعنى الثانية مستخفين ومستهزئين بنعمة الله. قوله: (خبر مبتدأ) أي والوقف على كذلك، والجملة معترضة لتوكيد ما قبلها. قوله: (أي الأمر) أي وهو هلاك فرعون وقومه. قوله: { وَأَوْرَثْنَاهَا } معطوف على { كَمْ تَرَكُواْ } والمعنى: تركوا أموراً كثيراً، وأورثنا تلك الأمور بني إسرائيل. قوله: (أي بني إسرائيل) فقد رجعوا إلى مصر بعد هلاك فرعون إن قلت: كيف قال تعالى: { وَأَوْرَثْنَاهَا قَوْماً آخَرِينَ } مع أنه تقدم أن أموالهم طمست ومسخت حجارة؟ قلت: لعل الجواب أنها بعد غرقهم، أعيدت كما كانت، اكراماً لبني إسرائيل، فحين رجعوا وجدوها كما كانت قبل الطمس.
