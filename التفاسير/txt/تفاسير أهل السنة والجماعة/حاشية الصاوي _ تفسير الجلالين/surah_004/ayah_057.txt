قوله: { وَٱلَّذِينَ آمَنُواْ } ذكر للمقابل وهو راجع لقوله: { فَمِنْهُمْ مَّنْ آمَنَ بِهِ } كما أن قوله: { إِنَّ ٱلَّذِينَ كَفَرُواْ } راجع لقوله: { وَمِنْهُمْ مَّن صَدَّ عَنْهُ } على عادته سبحانه إذا ذكر الوعيد أعقبه بالوعد.  قوله: (وكل قذر) أي كالنفائس وغيره. قوله: (لا تنسخه شمس) أي لعدم وجودها. قال تعالى: [الإنسان: 13].
