قوله: { لَقَدْ أَخَذْنَا مِيثَاقَ بَنِيۤ إِسْرَائِيلَ } أي في التوراة، والمقصود من ذلك إقامة الحجة على من كان في زمنه صلى الله عليه وسلم من اليهود والنصارى، وتقدم أن الميثاق هو العهد المؤكد باليمين.  قوله: { وَأَرْسَلْنَآ } معطوف على أخذنا. قوله: { رُسُلاً } أي كشعباء وأرمياء ويوشع. قوله: { كُلَّمَا جَآءَهُمْ رَسُولٌ } كلما شرطية وجاءهم فعل الشرط، وقوله: { بِمَا لاَ تَهْوَىٰ } متعلق بجاء وما اسم موصول، وقوله: { لاَ تَهْوَىٰ } صلته، والعائد محذوف تقديره لا تهواه، وجواب الشرط محذوف قدره المفسر بقوله: (كذبوه) والأوضح له أن يقول عادوه وعصوه، وقوله: { فَرِيقاً كَذَّبُواْ } الخ مستأنف بيان لوجه العصيان والمعاداة. قوله: (منهم) قدره إشارة إلى أن الجملة الشرطية صفة لرسلاً، والعائد محذوف ولو جعلت استئنافية لما احتيج لتقديره. قوله: (من الحق) بيان لما. قوله: { كَذَّبُواْ } أي غير قتل، كداود وسليمان ويوشع وعيسى ومحمد. قوله: (كزكريا ويحيى) أي وشعياء. قوله: (دون قتلوا) أي لمراعاة كذبوا. قوله: (حكاية للحال الماضية) أي كأنها حاصلة الآن. قوله: (للفاصلة) أي المحافظة على رؤوس الآي وتناسبها مع بعضها، ولعل فيه حذف الواو ويكون على ثانية.
