ويقول: { ٱلَّذِينَ آمَنُواْ } تعجباً من كذب المنافقين، هكذا ذكر المفسر، والمناسب أن يقول عطفاً على فيصبحوا، لأنه نتيجة ما قبله، لأن تعجب المؤمنين ناشئ عن الفتح لهم والفضيحة للمنافقين.  قوله: { أَهُـۤؤُلاۤءِ } الهمزة للاستفهام التعجبي، والهاء للتنبيه، وأولاء اسم إشارة مبتدأ، و { ٱلَّذِينَ } خبره، و { أَقْسَمُواْ } صلته، وقوله: { إِنَّهُمْ لَمَعَكُمْ } جملة تفسيرية لمعنى أقسموا، لأن يمينهم إنا معكم. قوله: (غاية اجتهادهم) أشار بذلك إلى أن جهد صفة لمصدر محذوف مفعول مطلق لأقسموا، والتقدير إقساماً. { جَهْدَ أَيْمَانِهِمْ } أي أغلظها. قوله: (تعالى) أشار بذلك إلى أن قوله: { حَبِطَتْ أَعْمَالُهُمْ } من كلامه تعالى إخبار عن المنافقين، لا من كلام المؤمنين، لأنهم لا علم لهم بذلك. قوله: (الصالحة) أي بحسب الظاهر.
