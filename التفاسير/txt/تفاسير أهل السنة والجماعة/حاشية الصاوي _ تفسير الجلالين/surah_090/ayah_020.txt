قوله: { ثُمَّ كَانَ مِنَ ٱلَّذِينَ آمَنُواْ } أتى بـ { ثُمَّ } إشارة لبعد رتبة الإيمان وعلوها، عن رتبة العتق والصدقة. قوله: (وثم للترتيب الذكري) أي لأن الإيمان هو السابق، لا يصح عمل إلا به. قوله: { بِٱلصَّبْرِ } (على الطاعة) الخ، أي ما أصابه من المحن والشدائد. قوله: { أُوْلَـٰئِكَ } مبتدأ، وقوله: { أَصْحَابُ ٱلْمَيْمَنَةِ } خبره، وأتى باسم الإشارة تكريماً لهم بأنهم حاضرون عنده، في مقام قربه وكرامته، فذكرهم بما يشار به للبعيد، تعظيماً لهم وإشارة لعلو درجاتهم وارتفاعها.  قوله: { أَصْحَابُ ٱلْمَيْمَنَةِ } أي الذين يؤتون كتبهم بأيمانهم، أو لأن منزلتهم عن يمين العرش. قوله: { هُمْ أَصْحَابُ ٱلْمَشْأَمَةِ } ذكرهم بضمير الغيبة، إشارة إلى أنهم غائبون عن حضرة قدسه وكرامة أنسه. قوله: (الشمال) أي لأنهم يأخذون كتبهم بشمائلهم، أو لأن منزلتهم عن الشمال. قوله: { عَلَيْهِمْ نَارٌ } خبر ثان أو مستأنف. قوله: (بالهمز والواو) أي فهما قراءتان سبعيتان ولغتان جيدتان، يقال: آصدت الباب وأوصدت إذا أغلقته وأطبقته. قوله: (مطبقة) أي عليهم تفسير لكل من القراءتين، والمعنى: لا يخرجون منها أبداً، ولا يدخلها روح وريحان.
