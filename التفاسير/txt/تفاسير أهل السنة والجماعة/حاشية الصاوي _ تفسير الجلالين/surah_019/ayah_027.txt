قوله: { فَأَتَتْ بِهِ } أي في يوم وضعه، وقيل بعد أربعين يوماً لما طهرت من نفاسها. قوله: (فرأوه) أي أبصروه. قوله: { قَالُواْ } أي أهلها وكانوا أهل بيت صالحين، بمصدوق قوله تعالى: [آل عمران: 33-34]. قوله: { لَقَدْ جِئْتِ } أي فعلت وأتيت. قوله: { فَرِيّاً } من فريت الجلد قطعته، أي شيئاً قاطعاً وخارقاً للعادة، ومقطعاً للعرض. قوله: (هو رجل صالح) أي في بني إسرائيل، شبهت به في عفتها وصلاحها، قيل إنه تبع جنازته يوم مات أربعون ألفاً من بني إسرائيل، كلهم يسمون هارون سوى سائر الناس. قوله: { مَا كَانَ أَبُوكِ } أي عمران، وقوله: { وَمَا كَانَتْ أُمُّكِ } أي حنة.
