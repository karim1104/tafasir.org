قوله: { ذٰلِكُمُ } مبتدأ، و { ٱللَّهُ } خبر أول، و { رَبُّكُمْ } خبر ثان، و { لاۤ إِلَـٰهَ إِلاَّ هُوَ } خبر ثالث، و { خَٰلِقُ كُلِّ شَيْءٍ } خبر رابع، وقوله: { فَٱعْبُدُوهُ } مفرع على ما ذكر من هذه الأوصاف، فالمعنى أن المتصف بالألوهية، الخالق لكل شيء، هو أحق بالعبادة وحده. فقوله: { خَٰلِقُ كُلِّ شَيْءٍ } توطئة لقوله: { فَٱعْبُدُوهُ }. وأما قوله: { خَٰلِقُ كُلِّ شَيْءٍ } فهو رد لما زعموه من الولد له سبحانه وتعالى. قوله: { فَٱعْبُدُوهُ } أي متصرف في خلقه ومتولي أمورهم، فالواجب قصر العبادة عليه، وتفويض الأمور إليه.
