قوله: { سَخَّرَ لَكُم مَّا فِي ٱلأَرْضِ } أي ذلل لكم ما فيها من الدواب لتنتفعوا بها. قوله: { وَٱلْفُلْكَ } بالنصب في قراءة العامة، عطف على ما في قوله: { مَّا فِي ٱلأَرْضِ } أي وسخر لكم الفلك وأفردها بالذكر، لكون تسخيرها أعجب من سائر المسخرات، والفك يطلق على الواحد والجمع بلفظ واحد، فوزن الواحد قفل، ووزن الجمع بدن. قوله: (من) { أَن } (أو لئلا) { تَقَعَ } أشار بذلك إلى أن { أَن تَقَعَ } إما في محل نصب على المفعول لأجله، أي لأجل أن لا تقع، أو في محل جر على حذف حرف الجر، والتقدير من أن تقع أي من وقوعها. قوله: { إِلاَّ بِإِذْنِهِ } استثناء مفرغ من معنى قوله: { وَيُمْسِكُ ٱلسَّمَآءَ أَن تَقَعَ عَلَى ٱلأَرْضِ } والتقدير لا يتركها تقع في حال من الأحوال، إلا في حال كونها ملتبسة بمشيئة الله تعالى. قوله: { وَهُوَ ٱلَّذِيۤ أَحْيَاكُمْ } أي أوجدكم من العدم لتسعدوا أو تشقوا، فكل من الإحياء الأول والثاني، إما نعمة أو نقمة. قوله: { ثُمَّ يُحْيِيكُمْ } (عند البعث) أي للثواب أو العقاب. قوله: { إِنَّ ٱلإِنْسَانَ لَكَفُورٌ } أي جحود لنعم خالقه.
