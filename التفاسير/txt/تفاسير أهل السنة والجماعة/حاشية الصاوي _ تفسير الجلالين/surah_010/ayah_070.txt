قوله: { سُبْحَانَهُ } أي تقدس وتنزه عن ذلك، قال تعالى: [مريم: 90-92] الآية. قوله: { هُوَ ٱلْغَنِيُّ } أي المستغني عن كل ما سواه، المفتقر إليه كل ما عداه، وهو دليل لما قبله.  قوله: { لَهُ مَا فِي ٱلسَّمَٰوَٰت } إلخ. دليل لقوله: { هُوَ ٱلْغَنِيُّ }. قوله: (استفهام توبيخ) أي تقريع وتهديد لهم, قوله: { قُلْ } أمر من الله لنبيه صلى الله عليه وسلم، أن ينبههم على سوء عاقبتهم، لعلهم ينزجرون عما هم عليه. قوله: (لا يسعدون) أي لا يفوزون بمطلوبهم، بل هم خائبون خاسرون، وإن تكاثرت عليهم النعم فمآلها للزوال. قوله: { مَتَاعٌ } مبتدأ خبره محذوف، قدره المفسر بقوله: (لهم) وحينئذ فالوقف على قوله: { لاَ يُفْلِحُونَ } وهذا جواب عما يقال: إنا نراهم في حظوظ كثيرة، وسعة عيش وسلامة بدن، وغير ذلك من أنواع النعم الدنيوية، فدفع ذلك بقوله: { مَتَاعٌ } (قليل) فلا يستمر، وليس بنافع في الآخرة. قوله: { بِمَا كَانُواْ يَكْفُرُونَ } أي بسبب كفرهم.
