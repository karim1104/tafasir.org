قوله: { قُلْ إِن كَانَ آبَاؤُكُمْ } نزلت لما قال الذين أسلموا ولم يهاجروا، نحن إن هاجرنا ضاعت أموالنا وذهبت تجارتنا، وتخربت ديارنا، وتقطعت أرحامنا، ويؤخذ من ذلك، أنه إذا تعارض أمر من أمور الدين، مع مصالح الدنيا، يقدم أمر الدين، ولو لزم عليه تعطيل أمر الدنيا. قوله: { وَإِخْوَانَكُمْ } أي حواشيكم، والمراد هنا إخوان النسب، وإن شاع جمع أخ النسب على إخوة، وأخ الدين على إخوان. قوله: (أقربائكم) وقيل هم من بينك وبينهم معاشرة مطلقاً ولو غير قريب، فهو عطف عام على ما قبله على كل حال. قوله: (وفي قراءة عشيراتكم) أي وهي سبعية، وقرأ الحسن عشائركم. قوله: { تَرْضَوْنَهَآ } أي ترضون الإقامة فيها. قوله: { أَحَبَّ إِلَيْكُمْ } خبر كان، واسمها { آبَاؤُكُمْ } وما عطف عليه. قوله: (فقعدتم لأجله) قدره ليرتب عليه قوله: { فَتَرَبَّصُواْ } وجملة { فَتَرَبَّصُواْ } جواب الشرط.  قوله: { حَتَّىٰ يَأْتِيَ ٱللَّهُ بِأَمْرِهِ } قال ابن عباس هو فتح مكة. إذا علمت ذلك، تعلم أن هذا مشكل مع ما تقدم، ومع ما يأتي من أن السورة نزلت بعد الفتح، إلا أن يقال إن بعض السورة نزل قبل الفتح، بحسب الوقائع والسورة بتمامها نزلت بعد الفتح، ولا غرابة في ذلك فتدبر. قوله: (تهديد لهم) أي تخويف. قوله: { ٱلْفَاسِقِينَ } عبر عنهم أولاً بالظالمين. إشارة إلى أن الكفار موصوفون بكل وصف قبيح.
