ولما فضحهم بما أخفوه من توليهم قبح عليهم ما أظهروه فقال تعالى معبراً بأداة التحقيق : { وإذا دعوا } أي : الفريق الذين ادعوا الإيمان من أيّ داعٍ كان { إلى الله } أي : إلى ما نصب الملك الأعظم من أحكامه { ورسوله } وأفرد الضمير في قوله تعالى : { ليحكم } وقد تقدمه اسمان وهما الله ورسوله ،   فهو كقوله تعالى : { والله ورسوله أحق أن يرضوه } [ التوبة ،   62 ] ؛ لأن حكم رسوله هو حكمه .   قال الزمخشري : كقولك : أعجبني زيد وكرمه ،   تريد كرم زيد ومنه قوله :

ومنهل من الفلا في أوسطه *** غلسته قبل القطا خرّطه

أي : قبل فرط القطا { بينهم } أي : بما أراه الله { إذا فريق منهم } أي : ناس مجبولون على الأذى { معرضون } أي : فاجؤوا الإعراض إذا كان الحق عليهم لعلمهم بأنك لا تحكم لهم وهو شرح للتولي ومبالغة فيه .
