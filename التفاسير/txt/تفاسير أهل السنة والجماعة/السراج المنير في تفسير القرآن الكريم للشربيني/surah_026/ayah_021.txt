{ ففررت } أي : فتسبب عن فعلها أني فررت { منكم } أي : منك لسطوتك ومن قومك لإغرائهم إياك عليّ { لما خفتكم } على نفسي أن تقتلوني بذلك القتيل الذي قتلته خطأً وأنا ابن اثنتي عشرة سنة مع كونه كافراً مهدر الدم { فوهب لي ربي } الذي أحسن إليّ بتربيتي عندكم تحت كنف أمي آمنة عليّ مما أحدثتم من الظلم { حكماً } أي : علماً وفهماً ،   وقيل نبوّة { وجعلني من المرسلين } أي : فاجهد الآن جهدك فإني لا أخافك لقتل ولا غيره .
