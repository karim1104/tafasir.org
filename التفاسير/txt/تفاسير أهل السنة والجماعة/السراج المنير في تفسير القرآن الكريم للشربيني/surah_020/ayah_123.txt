{ قال } الرب سبحانه وتعالى : الذي انتهكت حرمة داره { اهبطا } أي : آدم وحواء بما اشتملتما عليه من ذريتكما { منها } أي : الجنة { جميعاً } وقيل : الخطاب لآدم ومعه ذريته ،   ولإبليس ،   فقوله تعالى : { بعضكم لبعض عدوٌّ } يكون على التفسير الأول بعض الذرية لبعض عدوٌّ من ظلم بعضهم لبعض ،   وعلى الثاني آدم وذريته ،   وإبليس وذريته ،   وقوله تعالى : { فإما } فيه إدغام نون أن الشرطية في ما المزيدة { يأتينكم مني هدى } أي : كتاب ورسول { فمن اتبع هداي } الذي أسعفته به من أوامر الكتاب والرسول { فلا يضل } أي : بعد ذلك عن طريق السداد في الدنيا { ولا يشقى } في الآخرة ؛ قال ابن عباس : من قرأ القرآن ،   واتبع ما فيه هداه الله تعالى من الضلالة ،   ووقاه الله تعالى يوم القيامة سوء الحساب ،   وذلك أن الله تعالى يقول : { فمن اتبع هداي فلا يضل ولا يشقى } .
