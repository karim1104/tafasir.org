قال تعالى قاضياً بينهما :

{ الذين آمنوا ولم يلبسوا إيمانهم بظلم } أي : لم يخلطوا إيمانهم بشرك .   .

روي أنه لما نزلت هذه الآية شق ذلك على المسلمين فقالوا : ( يا رسول الله فأينا لم يظلم نفسه فقال : ( ليس ذلك إنما هو الشرك ألم تسمعوا إلى ما قال لقمان لابنه : { يا بني لا تشرك بالله إنّ الشرك لظلم عظيم } ( لقمان ،   13 ) { أولئك } أي : الموصوفون بما ذكر { لهم الأمن } أي : من العذاب المؤبد { وهم مهتدون } .
