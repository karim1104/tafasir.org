{ وكذب به } أي : القرآن أو العذاب { قومك } أي : الذين من حقهم أن يقوموا بجميع أمرك ويسرّوا بسيادتك فإنّ القبيلة إذا ساد أحدهم عزت به فإن عزه عزها وشرفه شرفها ولا سيما إذا كان من بيت الشرف ومعدن السيادة وإذا سفل أحدها اهتمت به غاية الاهتمام وسترت عيوبها مهما أمكنها فإنّ عاره لاحق لها فهو من عظيم التوبيخ لهم ودقيق التقريع لهم وزاد ذلك بقوله : { وهو } أي : والحال أنه { الحق } أي : الثابت الذي لا يضره التكذيب به ولا يمكن زواله { قل } لهم { لست عليكم بوكيل } أي : حفيظ وكل إلي أموركم فأجازيكم أو أمنعكم من التكذيب إنما أنا منذر والله الحفيظ .
