{ وكذلك } أي : كما جعلنا فساق أهل مكة أكابرها { جعلنا في كل قرية أكابر مجرميها } أي : عظماءها ،   وأكابر جمع أكبر كأفضل وأفاضل وأسود وأساود وذلك سنة الله تعالى أنه جعل في كل قرية أتباع الرسل ضعفاءهم كما قال في قصة نوح : { أنؤمن لك واتبعك الأرذلون } ( الشعراء ،   111 ) وجعل فساقهم أكابرهم { ليمكروا فيها } بالصدّ عن الإيمان وذلك أنهم أجلسوا على طرق مكة أربع نفر ليصرفوا الناس عن الإيمان بمحمد صلى الله عليه وسلم يقولون لكل من يقدم : إياكم وهذا الرجل فإنه كاهن ساحر كذاب فكان هذا مكرهم { وما يمكرون إلا بأنفسهم } لأنّ وباله يحيق بهم { وما يشعرون } أي : وما لهم نوع شعور بذلك .
