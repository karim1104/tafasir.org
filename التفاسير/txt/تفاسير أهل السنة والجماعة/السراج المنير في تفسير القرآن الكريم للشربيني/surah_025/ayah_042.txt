وقولهم : { إنْ } مخففة من الثقيلة أي : إنه { كاد ليضلنا } أي : يصرفنا { عن آلهتنا } أي : عن عبادتها بفرط اجتهاده في الدعاء إلى التوحيد وكثرة ما يورد مما سبق إلى الذهن أنها حجج ومعجزات { لولا أن صبرنا } أي : بما لنا من الاجتماع والتعاضد { عليها } أي : على التمسك بعبادتها قال الله تعالى : { وسوف يعلمون } أي : في حال لا ينفعهم فيه العمل ولا العلم وإن طالت مدة الإمهال في التمكين { حين يرون العذاب } عياناً في الآخرة { من أضل سبيلاً } أي : أخطأ طريقاً أهم أم المؤمنون .
