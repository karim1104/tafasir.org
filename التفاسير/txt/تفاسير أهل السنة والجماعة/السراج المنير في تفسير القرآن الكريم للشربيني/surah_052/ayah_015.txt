وقوله تعالى : { أفسحر } خبر مقدّم وقوله تعالى { هذا } هو المبتدأ وقدّم الخبر لأنه المقصود بالإنكار والتوبيخ ،   وذلك أنهم كانوا ينسبون محمداً صلى الله عليه وسلم إلى السحر وأنه يغطي الأبصار بالسحر وأنّ انشقاق القمر وأمثاله سحر فوبخوا به ،   وقيل لهم : { أفسحر هذا } أي الذي أنتم فيه من العذاب مع هذا الإحراق الذي تصلون فيه { أم أنتم } في منام أو نحوه { لا تبصرون } بالقلوب كما كنتم تقولون في الدنيا قلوبنا في أكنة ،   ولا بالأعين كما كنتم تقولون للمنذر { بيننا وبينك حجاب فاعمل أننا عاملون } [ فصلت : 5 ] .
