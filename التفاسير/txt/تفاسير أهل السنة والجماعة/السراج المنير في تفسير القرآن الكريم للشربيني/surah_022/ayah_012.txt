ثم بين هذا الخسران الذي ردّه إلى ما كان فيه قبل الإيمان الحرفيّ بقوله تعالى :   { يدعو } أي : يعبد حقيقة أو مجازاً { من دون اللَّه } أي : غير من الصنم { ما لا يضرّه } إن لم يعبده { وما لا ينفعه } إن عبده { ذلك } أي : الدعاء { هو الضلال البعيد } عن الحق والرشاد استعير الضلال البعيد من ضلال من أبعد في التيه ضالاً فطالت وبعدت مسافة ضلاله .
