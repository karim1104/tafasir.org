{ وكأين من قرية أمليت لها } أي : أمهلتها كما أمهلتكم { وهي ظالمة } كظلمكم بالاستعجال وغيره { ثم أخذتها } أي : بالعذاب والمراد أهلها { وإليّ المصير } أي : المرجع فينقطع كل حكم دون حكمي ففيه وعيد وتهديد .

فإن قيل : لم قال : { فكأين من قرية أهلكناها } [ الحج ،   45 ] بالفاء ،   وقال هنا بالواو ؟ أجيب : بأنّ الأولى وقعت بدلاً عن قوله تعالى : { فكيف كان نكير } ،   وأما هذه فحكمها حكم ما تقدّم من الجملتين المعطوفتين بالواو أعني قوله تعالى : { ولن يخلف الله وعده وإنّ يوماً عند ربك كألف سنة مما تعدون } ،
