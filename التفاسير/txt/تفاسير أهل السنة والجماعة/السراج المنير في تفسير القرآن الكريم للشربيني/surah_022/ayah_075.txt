ولما ذكر سبحانه وتعالى ما يتعلق بالإلهيات ذكر ما يتعلق بالنبوّات بقوله تعالى : { الله } أي : الملك الأعلى { يصطفي } أي : يختار ويختص { من الملائكة رسلاً } كجبريل وميكائيل وإسرافيل وعزرائيل عليهم الصلاة والسلام { ومن الناس } كإبراهيم وموسى وعيسى ومحمد صلى الله عليه وسلم وعليهم نزلت حين قال المشركون : { أأنزل عليه الذكر من بيننا } [ ص ،   8 ] فأخبر تعالى أنّ الاختيار إليه يختار من يشاء من خلقه { إنّ الله } أي : الذي له الجلال والجمال { سميع } لمقالتهم { بصير } بمن يتخذه رسولاً .
