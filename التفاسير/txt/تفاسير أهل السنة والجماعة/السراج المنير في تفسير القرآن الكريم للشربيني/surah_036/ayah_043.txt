{ وإن نشأ } أي : لأجل ما لنا من القوة الشاملة والقدرة التامة { نغرقهم } أي : مع أن هذا الماء الذي يركبونه ليس كالماء الذي حملنا آباءهم { فلا صريخ لهم } أي : مغيث لهم لينجيهم مما نريد بهم من الغرق أو فلا إغاثة كقولهم : أتاهم الصريخ { ولا هم } أي : بأنفسهم من غير صريخ { ينقذون } أي : يكون لهم إنقاذ أي : خلاص لأنفسهم أو غيرها .
