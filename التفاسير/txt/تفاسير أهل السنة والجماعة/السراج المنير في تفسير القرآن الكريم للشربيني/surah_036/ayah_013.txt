وقوله سبحانه وتعالى : { واضرب } بمعنى واجعل { لهم } وقوله تعالى { مثلاً } مفعول أول ،   وقوله تعالى : { أصحاب } مفعول ثان والأصل : واضرب لهم مثلاً مثل أصحاب { القرية } فترك المثل وأقيم الأصحاب مقامه في الإعراب كقوله تعالى { واسأل القرية } ( يوسف : 82 ) قال الزمخشري : وقيل لا حاجة إلى الإضمار بل المعنى : اجعل أصحاب القرية لهم مثلاً ،   أو مثل أصحاب القرية بهم قال المفسرون : المراد بالقرية أنطاكية وقوله تعالى { إذ جاءها } إلخ بدل اشتمال من أصحاب القرية أي : إذ جاء أهلها { المرسلون } أي : رسل عيسى عليه السلام .
