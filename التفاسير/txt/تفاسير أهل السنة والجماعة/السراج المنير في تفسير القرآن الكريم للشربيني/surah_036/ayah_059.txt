ولما ذكر ما للمؤمنين من النعيم ذكر ما للكافرين من الجحيم بقوله تعالى : { وامتازوا } أي : ويقال للمجرمين امتازوا أي : انفردوا { اليوم أيها المجرمون } عن المؤمنين عند اختلاطهم بهم قال الضحاك : لكل كافر في النار بيت يدخل ذلك البيت فيردم بابه بالنار فيكون فيه أبد الآبدين لا يرى ولا يرى ،   وقيل : إن قوله تعالى { وامتازوا } أمر تكوين فحين يقول { امتازوا اليوم } فيميزون بسيماهم ويظهر على جباههم وفي وجوههم سواد كما قال تعالى { يعرف المجرمون بسيماهم } ( الرحمان : 41 ) .
