ولما ذكر تعالى المرسِل وهو الله تعالى ،   والمرسل وهو النبي صلى الله عليه وسلم والمرسل به وهو القرآن ذكر المرسل لهم بقوله تعالى : { لتنذر قوماً } أي : ذوي بأس وقوة وذكاء وفطنة { ما أنذر } أي : لم تنذر أصلاً { آباؤهم } أي : لم ينذروا في زمن الفترة { فهم } أي : بسبب زمان الفترة { غافلون } أي : عن الإيمان والرشد .
