{ وقال إني ذاهب إلى ربي } أي : إلى حيث أمرني ربي ونظيره قوله تعالى { وقال إني مهاجر إلى ربي } ( العنكبوت : 26 ) أي : مهاجر إليه من دار الكفر { سيهدين } أي : إلى ما فيه صلاح ديني أو إلى مقصدي وهو الشام ،   وإنما بتّ القول لسبق وعده ولفرط توكله أو للبناء على عادته تعالى معه ولم يكن كذلك حال موسى عليه السلام حيث قال { عسى ربي أن يهديني سواء السبيل } ( القصص : 22 ) فلذلك ذكر بصيغة التوقع .
