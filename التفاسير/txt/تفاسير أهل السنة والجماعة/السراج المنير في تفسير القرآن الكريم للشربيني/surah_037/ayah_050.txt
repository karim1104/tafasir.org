{ فأقبل بعضهم } أي : بعض أهل الجنة { على بعض يتساءلون } معطوف على يطاف عليهم أي : يشربون فيتحادثون على الشراب قال القائل :

وما بقيت من اللذات إلا *** محادثة الكرام على المدام

وأتى بقوله تعالى : { فأقبل } ماضياً لتحقق وقوعه كقوله تعالى { ونادى أصحاب الجنة أصحاب النار } ( الأعراف : 44 ) وقوله تعالى { يتساءلون } حال من فاعل أقبل وتساؤلهم عن المعارف والفضائل وما جرى لهم وعليهم في الدنيا .
