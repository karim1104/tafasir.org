{ ولقد جاءكم موسى بالبينات } أي : الآيات التسع في قوله تعالى : { ولقد آتينا موسى تسع آيات بينات كالعصا } ( الإسراء ،   101 ) واليد وفلق البحر { ثم اتخذتم العجل } أي : إلهاً { من بعده } أي : من بعد ذهابه إلى الميقات ،   وقوله تعالى : { وأنتم ظالمون } أي : باتخاذه ،   حال أي : اتخذتم العجل ظالمين بعبادته ،   أو بالإخلال بآيات الله ،   أو اعتراض أي : وأنتم عادتكم الظلم .
