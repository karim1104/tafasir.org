{ وَقَالَ مُوسَى } كلام مبتدأ مسوق لتفصيل ما أجمل فيما قبله .

يا فرْعَوْنُ إِنِّي رَسُولٌ } أي إليكم كما يشعر به { قَدْ جِئْتُكُمْ } [ الأعراف : 105 ] أو إليك كما يشعر به { فأرسل } [ الأعراف : 105 ] أي إليكم كما يشعر به قد جئتكم أو إليك كما يشعر به فأرسل { مِن رَّبّ العالمين } أي سيدهم ومالك أمرهم .
