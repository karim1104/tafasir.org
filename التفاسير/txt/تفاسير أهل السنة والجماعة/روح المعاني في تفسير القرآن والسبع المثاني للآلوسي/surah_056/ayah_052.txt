{ لآَكِلُونَ } بعد البعث والجمع ودخولهم جهنم { مِن شَجَرٍ مّن زَقُّومٍ } { مِنْ } الأولى لابتداء الغاية والثانية لبيان الشجر وتفسيره أي مبتدءون للأكل من شجر هو زقوم ،  وجوز كون الأولى تبعيضية و { مِنْ } الثانية على حالها ،  وجوز كون { مّن زَقُّومٍ } بدلاً من قوله تعالى : { مِن شَجَرٍ } فمن تحتمل الوجهين ،  وقيل : الأولى زائدة ،  وقرأ عبد الله من شجرة فوجه التأنيث ظاهر في قوله تعالى : { فَمَا فَمَالِئُونَ مِنْهَا البطون } .
