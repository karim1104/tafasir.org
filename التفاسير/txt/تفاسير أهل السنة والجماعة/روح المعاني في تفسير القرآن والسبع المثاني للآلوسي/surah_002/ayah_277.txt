{ إِنَّ الذين ءامَنُواْ } بما وجب الإيمان به { وَعَمِلُواْ } الأعمال { الصالحات } على الوجه الذي أمروا به { وَأَقَامُواْ الصلاة وَءاتَوُاْ الزكواة } تخصيصهما بالذكر مع اندراجهما في الأعمال للتنبيه على عظم فضلهما ،  فإن الأولى : أعظم الأعمال البدنية والثانية : أفضل الأعمال المالية { لَهُمْ أَجْرُهُمْ } الموعود لهم حال كونه { عِندَ رَبّهِمْ } وفي التعبير بذلك مزيد لطف وتشريف { وَلاَ خَوْفٌ عَلَيْهِمْ وَلاَ هُمْ يَحْزَنُونَ } لوفور حظهم .
