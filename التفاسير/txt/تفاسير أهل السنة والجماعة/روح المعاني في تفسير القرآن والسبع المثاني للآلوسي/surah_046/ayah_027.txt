{ وَلَقَدْ أَهْلَكْنَا } مَا حَوْلَكُمْ يا أهل مكة { مّنَ القرى } كحجر ثمود وقرى قوم صالح ،  والكلام بتقدير مضاف أو تجوز بالقرى عن أهلها لقوله تعالى : { وَصَرَّفْنَا الايات } أي كررناها { لَعَلَّهُمْ يَرْجِعُونَ } وأمر { مَا } سهل ،  والترجي مصروف لغيره تعالى أو { لَعَلَّ } للتعليل أي لكي يرجعوا عما هم فيه من الكفر والمعاصي إلى الإيمان والطاعة .
