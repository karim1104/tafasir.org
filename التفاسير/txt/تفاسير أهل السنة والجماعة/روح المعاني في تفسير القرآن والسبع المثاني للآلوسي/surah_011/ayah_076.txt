{ يإِبْرَاهِيم } على تقدير القول ليرتبط بما قبل أي قالت الملائكة ،  أو قلنا { ضَيْفِ إِبْرَاهِيمَ }

{ أَعْرِضْ عَنْ هذا } الجدال { أَنَّهُ } أي الشأن { قَدْ جَاء أَمْرُ رَبّكَ } أي قدره تعالى المقضى بعذابهم ،  وقد يفسر بالعذاب ،  ويراد بالمجيء المشارفة فلا يتكرر مع قوله سبحانه :

{ وَإِنَّهُمْ ءاتِيهِمْ عَذَابٌ غَيْرُ مَرْدُودٍ } أي لا بجدال ولا بدعاء ولا بغيرهما إذ حاصل ذلك حينئذ شارفهم ثم وقع بهم ،  وقيل : لا حاجة إلى اعتبار المشارفة ،  والتكرار مدفوع بأن ذاك توطئة لذكر كونه غير مردود .

وقرأ عمرو بن هرم وإنهم أتاهم بلفظ الماضي ،  و { عَذَابِ } فاعل به ،  وعبر بالماضي لتحقيق الوقوع .
