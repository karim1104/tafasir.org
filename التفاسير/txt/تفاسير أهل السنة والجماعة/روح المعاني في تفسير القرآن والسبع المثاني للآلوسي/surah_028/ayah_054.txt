{ أولئك } الموصوفون بما ذكر من النعوت { يُؤْتُونَ أَجْرَهُم مَّرَّتَيْنِ } مرة على إيمانهم بكتابهم ومرة على إيمانهم بالقرآن { بِمَا صَبَرُواْ } أي بصبرهم وثباتهم على الإيمانين أو على الإيمان بالقرآن قبل النزول وبعده أو على أذى من هاجرهم وعاداهم من أهل دينهم ومن المشركين { وَيَدْرَءونَ } أي يدفعونَ { بالحسنة } أي بالطاعة { السيئة } أي المعصية فإن الحسنة تمحو السيئة قال صلى الله عليه وسلم لمعاذ : أتبع السيئة الحسنة تمحها ،  وقيل : أي يدفعون بالحلم الأذى وقال ابن جبير : بالمعروف المنكر وقال ابن زيد : بالخير الشر وقال ابن سلام : بالعلم الجهل وبالكظم الغيظ وقال ابن مسعود : بشهادة أن لا إله إلا الله الشرك { وَمِمَّا رزقناهم يُنفِقُونَ } أي في سبيل الخير كما يقتضيه مقام المدح .
