{ إِنَّمَا السبيل } أي بالمعاتبة والمعاقبة { عَلَى الذين يَسْتَأْذِنُونَكَ } في التخلف { وَهُمْ أَغْنِيَاء } واجدون للأهبة قادرون على الخروج معك { رَضُواْ } استئناف بياني كأنه قيل : لم استأذنوا أو لم استحقوا ما استحقوا ؟ فأجيب بأنهم رضوا { بِأَن يَكُونُواْ مَعَ الخوالف } تقدم معناه { وَطَبَعَ الله على قُلُوبِهِمْ } خذلهم فغفلوا عن سوء العاقبة { فَهُمُ } بسبب ذلك { لاَّ يَعْلَمُونَ } أبداً وخامة ما رضوا به وما يستتبعه عاجلاً كما لم يعلموا نجاسة شأنه آجلا .
