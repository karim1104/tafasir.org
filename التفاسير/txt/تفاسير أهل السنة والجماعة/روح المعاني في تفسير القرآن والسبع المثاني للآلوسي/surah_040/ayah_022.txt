{ ذلك } الأخذ { بِأَنَّهُمْ } أي بسبب أنهم { كَانَت تَّأْتِيهِمْ رُسُلُهُم بالبينات } بالمعجزات والأحكام الواضحة { فَكَفَرُواْ } ريثما أتتهم رسلهم بذلك { فَأَخَذَهُمُ الله إِنَّهُ قَوِىٌّ } متمكن مما يريده عز وجل غاية التمكن { شَدِيدُ العقاب } لا يعتد بعقاب عند عقابه سبحانه ،  وهذا بيان للإجمال في قوله تعالى : { فَأَخَذَهُمُ الله بِذُنُوبِهِمْ } [ غافر : 21 ] إن كانت الباء هناك سببية وبيان لسبب الأخذ إن كانت للملابسة أي أخذهم ملابسين لذنوبهم غير تائبين عنها فتأمل .
