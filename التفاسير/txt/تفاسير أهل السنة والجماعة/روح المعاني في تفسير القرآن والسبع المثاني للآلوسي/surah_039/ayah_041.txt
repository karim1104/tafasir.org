{ إِنَّا أَنزَلْنَا عَلَيْكَ الكتاب لِلنَّاسِ } لأجلهم فإنه مناط مصالحهم في المعاش والمعاد { بالحق } حال من مفعول { أَنزَلْنَا } أو من فاعله أي أنزلنا الكتاب ملتبساً أو ملتبسين بالحق { فَمَنُ اهتدى } بأن عمل بما فيه { فَلِنَفْسِهِ } إذ نفع به نفسه { وَمَن ضَلَّ } بأن لم يعمل بموجبه { فَإِنَّمَا يَضِلُّ عَلَيْهَا } لما أن وبال ضلاله مقصور عليها { وَمَا أَنتَ عَلَيْهِم بِوَكِيلٍ } لتجبرهم على الهدى وما وظيفتك إلا البلاغ وقد بلغت أي بلاغ .
