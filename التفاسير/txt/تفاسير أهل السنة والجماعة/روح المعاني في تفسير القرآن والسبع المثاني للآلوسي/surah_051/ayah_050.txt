{ فَفِرُّواْ إِلَى الله } تفريع على قوله سبحانه : { لَعَلَّكُمْ تَذَكَّرُونَ } [ الذاريات : 49 ] وهو تمثيل للاعتصام به سبحانه وتعالى وبتوحيده عز وجل ،  والمعنى قل يا محمد : { فَفِرُّواْ إِلَى الله } لمكان { إِنّى لَكُمْ مّنْهُ } أي من عقابه تعالى المعد لمن لم يفر إليه سبحانه ولم يوحده { نَذِيرٌ مُّبِينٌ } بين كونه منذراً من الله سبحانه بالمعجزات ،  أو { مُّبِينٌ } ما يجب أن يحذر عنه .

ومما قاله بعض أهل الإشارة : { فَفِرُّواْ إِلَى الله } [ الذاريات : 50 ] بترك ما سواه عز وجل
