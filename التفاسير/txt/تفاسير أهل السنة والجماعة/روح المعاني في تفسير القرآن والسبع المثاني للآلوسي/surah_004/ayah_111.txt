{ وَمَن يَكْسِبْ } أي يفعل { إثِماً } ذنباً من الذنوب { فَإِنَّمَا يَكْسِبُهُ على نَفْسِهِ } بحيث لا يتعدى ضرره إلى غيرها فليحترز عن تعريضها للعقاب والوبال { وَكَانَ الله عَلِيماً } بكل شيء ومنه الكسب { حَكِيماً } في كل ما قدر وقضى ،  ومن ذلك لا تحمل وازرة وزر أخرى ،  وقيل : { عَلِيماً } بالسارق { حَكِيماً } في إيجاب القطع عليه ،  والأولى أولى .
