وقوله تعالى :

{ وَلَقَدْ ءاتَيْنَا موسى الكتاب } الخ جملة مستأنفة سيقت لتأكيد ما مر من التسلية والوعد بالهداية والنصر في قوله تعالى : { وكفى بِرَبّكَ هَادِياً وَنَصِيراً } [ الفرقان : 31 ] على ما قدمناه بحكاية ما جرى بين من ذكر من الأنبياء عليهم السلام وبين قومهم حكاية إجمالية كافية فيما هو المقصود .   واللام واقعة في جواب القسم أي وبالله تعالى لقد آتينا موسى التوراة أي أنزلناها عليه بالآخرة ،  وقيل : المراد بالكتاب الحكم والنبوة ولا يخفى بعده { وَجَعَلْنَا مَعَهُ } الظرف متعلق بجعلنا ،  وقوله تعالى : { أَخَاهُ } مفعول أول له وقوله سبحانه : { هارون } بدل من { أَخَاهُ } أو عطف بيان له وقوله عز وجل : { وَزِيراً } مفعول ثان له وتقدم معنى الوزير ولا ينافي هذا قوله تعالى : { وَوَهَبْنَا لَهُ [ من رحمتنا ] أَخَاهُ هارون نَبِيّاً } [ مريم : 53 ] لأنه وإن كان نبياً فالشريعة لموسى عليه السلام وهو تابع له فيها كما أن الوزير متبع لسلطانه .
