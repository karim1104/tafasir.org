– قوله تعالى :  {  فتول عنهم فما أنت بملوم ( 54 ) } :

ذكر بعضهم عن الضحاك أنها منسوخة بآية الجهاد .  وذكر بعضهم عنه أنها منسوخة بالإقبال عليهم والموعظة لهم .  قال تعالى :  {  يا أيها الرسول بلغ ما أنزل إليك من ربك وإن لم تفعل فما بلغت رسالته } [ المائدة :  67 ] .  وقد يحتمل أن يكون معنى قوله تعالى :  {  فتول عنهم } أي عند شدة الحرص عليهم وحسرة النفس لبقائهم على الكفر ،  ثم أمرهم بالتذكير مع ذلك ،  فلا يكون في الآية نسخ .  وقال قتادة :  بلغنا أنها لما نزلت :  {  فتول عنهم فما أنت بملوم ( 54 ) } اغتم المسلمون وخافوا نزول العذاب حتى نزلت :  {  فإن الذكرى تنفع المؤمنين }  [ الذاريات :  55 ] .
