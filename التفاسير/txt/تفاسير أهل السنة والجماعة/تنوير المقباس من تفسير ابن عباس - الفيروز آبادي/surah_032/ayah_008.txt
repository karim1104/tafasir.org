وبإسناده عن ابن عباس في قوله تعالى { الۤـمۤ } يقول أنا الله أعلم ويقال قسم أقسم به { تَنزِيلُ ٱلْكِتَابِ } إن هذا الكتاب تكليم من الله { لاَ رَيْبَ فِيهِ } لا شك فيه أنه { مِن رَّبِّ ٱلْعَالَمِينَ أَمْ يَقُولُونَ } بل يقولون كفار مكة { ٱفْتَرَاهُ } اختلق محمد القرآن من تلقاء نفسه { بَلْ هُوَ ٱلْحَقُّ } يعني القرآن { مِن رَّبِّكَ } نزل به جبريل عليك { لِتُنذِرَ } به لكي تخوف بالقرآن { قَوْماً } يعني قريشاً { مَّآ أَتَاهُم مِّن نَّذِيرٍ مِّن قَبْلِكَ } لم يأتهم رسول مخوف قبلك يا محمد { لَعَلَّهُمْ يَهْتَدُونَ } من الضلالة { ٱللَّهُ ٱلَّذِي خَلَقَ ٱلسَّمَاوَاتِ وَٱلأَرْضَ وَمَا بَيْنَهُمَا } من الخلق والعجائب { فِي سِتَّةِ أَيَّامٍ } من أيام أول الدنيا طول كل يوم ألف سنة مما تعدون من سنين الدنيا أول يوم منها يوم الأحد وآخر يوم منها يوم الجمعة { ثُمَّ ٱسْتَوَىٰ عَلَى ٱلْعَرْشِ } وكان الله على العرش قبل أن خلقهما { مَا لَكُمْ } يا أهل مكة { مِّن دُونِهِ } من دون الله { مِن وَلِيٍّ } من قريب ينفعكم { وَلاَ شَفِيعٍ } يشفع لكم من عذاب الله { أَفَلاَ تَتَذَكَّرُونَ } تتعظون بالقرآن فتؤمنوا { يُدَبِّرُ ٱلأَمْرَ مِنَ ٱلسَّمَآءِ إِلَى ٱلأَرْضِ } يبعث الملائكة بالوحي والتنزيل والمصيبة { ثُمَّ يَعْرُجُ إِلَيْهِ } يصعد إليه يعني الملائكة { فِي يَوْمٍ كَانَ مِقْدَارُهُ } مقدار صعوده على غير الملائكة { أَلْفَ سَنَةٍ مِّمَّا تَعُدُّونَ } من سنين الدنيا { ذٰلِكَ } المدبر { عَالِمُ ٱلْغَيْبِ } ما غاب عن العباد وما يكون { وَٱلشَّهَادَةِ } ما علمه العباد وما كان { ٱلْعَزِيزُ } بالنقمة من الكفار { ٱلرَّحِيمُ } بالمؤمنين { ٱلَّذِيۤ أَحْسَنَ كُلَّ شَيْءٍ خَلَقَهُ } أحكم كل شيء خلقه { وَبَدَأَ خَلْقَ ٱلإِنْسَانِ } يعني آدم { مِن طِينٍ } أخذ من أديم الأرض { ثُمَّ جَعَلَ نَسْلَهُ } ذريته { مِن سُلاَلَةٍ } نطفة { مِّن مَّآءٍ مَّهِينٍ } من نطفة ضعيفة من ماء الرجل والمرأة { ثُمَّ سَوَّاهُ } جمع خلقه في بطن أمه { وَنَفَخَ فِيهِ مِن رُّوحِهِ } جعل الروح فيه { وَجَعَلَ لَكُمُ ٱلسَّمْعَ } خلق لكم السمع لكي تسمعوا به الحق والهدى { وَٱلأَبْصَارَ } لكي تبصروا بها الحق والهدى { وَٱلأَفْئِدَةَ } يعني القلوب لكي تفقهوا بها الحق والهدى { قَلِيلاً مَّا تَشْكُرُونَ } شكركم بما صنع إليكم قليل.
