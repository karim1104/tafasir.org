{ وَكَأِيِّن مِّن قَرْيَةٍ } وكم من أهل قرية { عَتَتْ } عصت وأبت { عَنْ أَمْرِ رَبِّهَا } عن قبول أمر ربها وطاعة ربها { وَرُسُلِهِ } عن إجابة الرسل وعما جاءت به الرسل { فَحَاسَبْنَاهَا } في الآخرة { حِسَاباً شَدِيداً وَعَذَّبْنَاهَا } في الدنيا { عَذَاباً نُّكْراً } شديداً مقدم ومؤخر { فَذَاقَتْ وَبَالَ أَمْرِهَا } عقوبة أمرها في الدنيا بالهلاك { وَكَانَ عَاقِبَةُ أَمْرِهَا } في الآخرة { خُسْراً } إلى خسران  { أَعَدَّ ٱللَّهُ لَهُمْ } في الآخرة { عَذَاباً شَدِيداً } غليظاً لوناً بعد لون { فَٱتَّقُواْ ٱللَّهَ } فاخشوا الله { يَٰأُوْلِي ٱلأَلْبَابِ } يا ذوي العقول من الناس { ٱلَّذِينَ آمَنُواْ } بمحمد صلى الله عليه وسلم والقرآن { قَدْ أَنزَلَ ٱللَّهُ إِلَيْكُمْ ذِكْراً رَّسُولاً } ذكراً مع الرسول { يَتْلُو عَلَيْكُمْ } محمد عليه الصلاة والسلام { آيَاتِ ٱللَّهِ } القرآن { مُبَيِّنَاتٍ } واضحات بينات بالأمر والنهي { لِّيُخْرِجَ ٱلَّذِينَ آمَنُواْ } قد أخرج الذين آمنوا بمحمد صلى الله عليه وسلم والقرآن { وَعَمِلُواْ ٱلصَّالِحَاتِ } الطاعات فيما بينهم وبين ربهم { مِنَ ٱلظُّلُمَاتِ إِلَى ٱلنُّورِ } من الكفر إلى الإيمان { وَمَن يُؤْمِن بِٱللَّهِ } وبمحمد عليه الصلاة و السلام والقرآن { وَيَعْمَلْ صَالِحاً } خالصاً فيما بينه وبين ربه { يُدْخِلْهُ } في الآخرة { جَنَّاتٍ } بساتين { تَجْرِي مِن تَحْتِهَا } من تحت شجرها وغرفها { ٱلأَنْهَارُ } أنهار الخمر والماء والعسل واللبن { خَالِدِينَ فِيهَآ } مقيمين في الجنة لا يموتون فيها ولا يخرجون منها { أَبَداً قَدْ أَحْسَنَ ٱللَّهُ لَهُ رِزْقاً } قد أعد الله له ثواباً في الجنة { ٱللَّهُ ٱلَّذِي خَلَقَ سَبْعَ سَمَاوَاتٍ } بعضها فوق بعض مثل القبة { وَمِنَ ٱلأَرْضِ مِثْلَهُنَّ } سبعاً ولكنها منبسطة { يَتَنَزَّلُ ٱلأَمْرُ بَيْنَهُنَّ } يقول تتنزل الملائكة بالوحي والتنزيل والمصيبة من السموات من عند الله { لِّتَعْلَمُوۤاْ } لكي تعلموا وتقروا { أَنَّ ٱللَّهَ عَلَىٰ كُلِّ شَيْءٍ } من أهل السموات والأرضين { قَدِيرٌ وَأَنَّ ٱللَّهَ قَدْ أَحَاطَ بِكُلِّ شَيْءٍ عِلْمَاً } أي قد أحاط علمه بكل شيء.
