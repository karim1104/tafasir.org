{ وَٱلَّذِينَ آمَنُواْ } بمحمد عليه الصلاة والسلام والقرآن { وَهَاجَرُواْ } من مكة إلى المدينة { وَجَاهَدُواْ فِي سَبِيلِ ٱللَّهِ } في طاعة الله { وَٱلَّذِينَ آوَواْ } وطنوا محمداً صلى الله عليه وسلم وأصحابه بالمدينة { وَّنَصَرُوۤاْ } محمداً عليه الصلاة والسلام يوم بدر { أُولَـٰئِكَ هُمُ ٱلْمُؤْمِنُونَ حَقّاً } صدقاً يقيناً { لَّهُمْ مَّغْفِرَةٌ } لذنوبهم في الدنيا { وَرِزْقٌ كَرِيمٌ } ثواب حسن في الجنة { وَٱلَّذِينَ آمَنُواْ } بمحمد عليه الصلاة والسلام والقرآن { مِن بَعْدُ } من بعد المهاجرين الأولين { وَهَاجَرُواْ } من مكة إلى المدينة { وَجَاهَدُواْ مَعَكُمْ } العدو { فَأُوْلَـٰئِكَ مِنكُمْ } معكم في السر والعلانية { وَأْوْلُواْ ٱلأَرْحَامِ } ذوو القرابة في النسب الأول فالأول { بَعْضُهُمْ أَوْلَىٰ بِبَعْضٍ } في الميراث { فِي كِتَابِ ٱللَّهِ } في اللوح المحفوظ نسخ بهذه الآية الآية الأولى { إِنَّ ٱللَّهَ بِكُلِّ شَيْءٍ } من قسمة المواريث وصلاحكم وغيرهما { عَلِيمٌ } يعلم نقض عهود المشركين، والله أعلم بأسرار كتابه.
