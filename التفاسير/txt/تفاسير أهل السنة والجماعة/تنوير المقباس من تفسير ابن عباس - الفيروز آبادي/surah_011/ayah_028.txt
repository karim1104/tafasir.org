{ إِنَّ ٱلَّذِينَ آمَنُواْ } بمحمد صلى الله عليه وسلم والقرآن { وَعَمِلُواْ ٱلصَّالِحَاتِ } الطاعات فيما بينهم وبين ربهم { وَأَخْبَتُوۤاْ إِلَىٰ رَبِّهِمْ } أخلصوا لربهم وخضعوا لربهم وخشعوا من ربهم { أُوْلَـٰئِكَ أَصْحَابُ ٱلجَنَّةِ هُمْ فِيهَا خَالِدُونَ } مقيمون { مَثَلُ ٱلْفَرِيقَيْنِ } الكافر والمؤمن { كَٱلأَعْمَىٰ وَٱلأَصَمِّ } يقول مثل الكافر كالأعمى لا يبصر الحق والهدى وكالأصم لا يسمع الحق والهدى { وَٱلْبَصِيرِ وَٱلسَّمِيعِ } يقول ومثل المؤمن كمثل البصير يبصر الحق والهدى كالسميع يسمع الحق والهدى { هَلْ يَسْتَوِيَانِ مَثَلاً } في المثل يقول هل يستوي الكافر مع المؤمن في الطاعة والثواب { أَفَلاَ تَذَكَّرُونَ } أفلا تتعظون بأمثال القرآن فتؤمنوا { وَلَقَدْ أَرْسَلْنَا نُوحاً إِلَىٰ قَوْمِهِ } فلما جاءهم قال لهم { إِنَّي لَكُمْ } من الله { نَذِيرٌ } رسول مخوف { مُّبِينٌ } بلغة تعلمونها { أَن لاَّ تَعْبُدُوۤاْ } أن لا توحدوا { إِلاَّ ٱللَّهَ إِنِّيۤ أَخَافُ عَلَيْكُمْ } أعلم بأن يكون عليكم إن لم تؤمنوا { عَذَابَ يَوْمٍ أَلِيمٍ } وجيع وهو الغرق { فَقَالَ ٱلْمَلأُ } الرؤساء { ٱلَّذِينَ كَفَرُواْ مِن قِوْمِهِ } من قوم نوح { مَا نَرَاكَ } يا نوح { إِلاَّ بَشَراً } آدمياً { مِّثْلَنَا وَمَا نَرَاكَ ٱتَّبَعَكَ } آمن بك { إِلاَّ ٱلَّذِينَ هُمْ أَرَاذِلُنَا } سفلتنا وضعفاؤنا { بَادِيَ ٱلرَّأْيِ } ظاهر الرأي الضعيف ويقال سَوء رأيهم حملهم على ذلك { وَمَا نَرَىٰ لَكُمْ عَلَيْنَا مِن فَضْلٍ } بما تقولون تأكلون وتشربون كما نأكل ونشرب { بَلْ نَظُنُّكُمْ كَاذِبِينَ } بما تقولون { قَالَ } نوح { يَٰقَوْمِ أَرَأَيْتُمْ إِن كُنتُ } يقول إني { عَلَىٰ بَيِّنَةٍ مِّن رَّبِّيۤ } على بيان نزل من ربي { وَآتَانِي رَحْمَةً مِّنْ عِندِهِ } أكرمني بالنبوة والإسلام { فَعُمِّيَتْ } التبست وإن قرأت فعميت يقول ألبست { عَلَيْكُمْ } نبوتي وديني { أَنُلْزِمُكُمُوهَا } أنلهكموها ونعرفكموها { وَأَنتُمْ لَهَا كَارِهُونَ } جاحدون { وَيَٰقَوْمِ لاۤ أَسْأَلُكُمْ عَلَيْهِ } على التوحيد { مَالاً } جعلا { إِنْ أَجْرِيَ } ما ثوابي { إِلاَّ عَلَى ٱللَّهِ وَمَآ أَنَاْ بِطَارِدِ ٱلَّذِينَ آمَنُوۤاْ } بقولكم { إِنَّهُمْ مُّلاَقُو } معاينو { رَبِّهِمْ } فيخاصمونني عنده { وَلَـٰكِنِّيۤ أَرَاكُمْ قَوْماً تَجْهَلُونَ } أمر الله { وَيٰقَوْمِ مَن يَنصُرُنِي } من يمنعني { مِنَ ٱللَّهِ } من عذاب الله { إِن طَرَدتُّهُمْ } بقولكم { أَفَلاَ تَذَكَّرُونَ } أفلا تتعظون بما أقول لكم فتؤمنوا { وَلاَ أَقُولُ لَكُمْ عِندِي خَزَآئِنُ ٱللَّهِ } مفاتيح خزائن الله في الرزق { وَلاَ أَعْلَمُ ٱلْغَيْبَ } متى نزول العذاب وما غاب عني { وَلاَ أَقُولُ إِنِّي مَلَكٌ } من السماء { وَلاَ أَقُولُ لِلَّذِينَ تَزْدَرِيۤ أَعْيُنُكُمْ } لا تأخذهم أعينكم يقول يحتقرون في أعينكم { لَن يُؤْتِيَهُمُ ٱللَّهُ خَيْراً } لن يكرمهم الله بتصديق الإيمان { ٱللَّهُ أَعْلَمُ بِمَا فِي أَنْفُسِهِمْ } بما في قلوبهم من التصديق { إِنِّيۤ إِذاً } إن طردتهم { لَّمِنَ ٱلظَّالِمِينَ } الضارين بنفسي.
