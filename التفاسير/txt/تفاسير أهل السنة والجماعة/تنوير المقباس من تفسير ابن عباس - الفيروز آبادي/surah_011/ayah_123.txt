{ وَٱنْتَظِرُوۤاْ } هلاكي { إِنَّا مُنتَظِرُونَ } هلاككم { وَللَّهِ غَيْبُ ٱلسَّمَاوَاتِ وَٱلأَرْضِ } ما غاب عن العباد { وَإِلَيْهِ يُرْجَعُ ٱلأَمْرُ } وإلى الله يرجع أمر العباد { كُلُّهُ } في الآخرة { فَٱعْبُدْهُ } فأطعه { وَتَوَكَّلْ عَلَيْهِ } ثق به { وَمَا رَبُّكَ بِغَافِلٍ عَمَّا تَعْمَلُونَ } من المعاصي ويقال بتارك عقوبة ما تعملون كما لم يغفل.
