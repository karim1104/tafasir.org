{ قَالَ يَٰقَوْمِ أَرَهْطِيۤ } قومي { أَعَزُّ عَلَيْكُم مِّنَ ٱللَّهِ } من كتابه ودينه ويقال عقوبة رهطي أشد عليكم من عقوبة الله { وَٱتَّخَذْتُمُوهُ } نبذتموه { وَرَآءَكُمْ ظِهْرِيّاً } خلف ظهركم ما جئت به من الكتاب { إِنَّ رَبِّي بِمَا تَعْمَلُونَ } بعقوبة ما تعملون { مُحِيطٌ } عالم { وَيَٰقَوْمِ ٱعْمَلُواْ عَلَىٰ مَكَانَتِكُمْ } على دينكم في منازلكم بهلاكي { إِنِّي عَامِلٌ } بهلاككم { سَوْفَ تَعْلَمُونَ مَن يَأْتِيهِ } إلى ما يأتيه { عَذَابٌ يُخْزِيهِ } يذله ويهلكه { وَمَنْ هُوَ كَاذِبٌ } على الله { وَٱرْتَقِبُوۤاْ } انتظروا لهلاكي { إِنِّي مَعَكُمْ رَقِيبٌ } منتظر لهلاككم { وَلَمَّا جَآءَ أَمْرُنَا } عذابنا { نَجَّيْنَا شُعَيْباً وَٱلَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مِّنَّا } بنعمة منا { وَأَخَذَتِ ٱلَّذِينَ ظَلَمُواْ } أشركوا يعني قوم شعيب { ٱلصَّيْحَةُ } بالعذاب { فَأَصْبَحُواْ فِي دِيَارِهِمْ } فصاروا في مساكنهم { جَاثِمِينَ } ميتين رماداً { كَأَن لَّمْ يَغْنَوْاْ فِيهَآ } كأن لم يكونوا في الأرض قط { أَلاَ بُعْداً لِّمَدْيَنَ } لقوم شعيب من رحمة الله { كَمَا بَعِدَتْ ثَمُودُ } قوم صالح من رحمة الله وكان عذاب قوم صالح وقوم شعيب سواء كلاهما كان الصيحة بالعذاب أصابهم حر شديد وقوم صالح أتاهم من تحت أرجلهم العذاب وقوم شعيب أتاهم من فوق رؤوسهم العذاب { وَلَقَدْ أَرْسَلْنَا مُوسَىٰ بِآيَاتِنَا } التسع { وَسُلْطَانٍ مُّبِينٍ } حجة بينة الآيات هي حجة بينة { إِلَىٰ فِرْعَوْنَ وَمَلَئِهِ } رؤسائه { فَٱتَّبَعُوۤاْ أَمْرَ فِرْعَوْنَ } وتركوا قول موسى { وَمَآ أَمْرُ فِرْعَوْنَ } قول فرعون { بِرَشِيدٍ } بصواب { يَقْدُمُ قَوْمَهُ } يتقدم ويقود قومه { يَوْمَ ٱلْقِيَامَةِ فَأَوْرَدَهُمُ ٱلنَّارَ } فأدخلهم النار { وَبِئْسَ ٱلْوِرْدُ ٱلْمَوْرُودُ } بئس المدخل فرعون وبئس المدخل قومه ويقال بئس الداخل فرعون وبئس المدخل قومه ويقال بئس الداخل فرعون وقومه وبئس المدخل النار { وَأُتْبِعُواْ فِي هَـٰذِهِ لَعْنَةً } أهلكوا في هذه الدنيا بالغرق { وَيَوْمَ ٱلْقِيَامَةِ } لهم لعنة أخرى وهي النار { بِئْسَ ٱلرِّفْدُ ٱلْمَرْفُودُ } يقول بئس الغرق ورفده النار ويقال بئس العون وبئس المعان { ذَلِكَ } الذي ذكرت { مِنْ أَنْبَآءِ ٱلْقُرَىٰ } في الدنيا من أخبار القرى الماضية { نَقُصُّهُ عَلَيْكَ } ننزل عليك جبريل بأخبارها { مِنْهَا قَآئِمٌ } ينظر إليها قد باد أهلها { وَحَصِيدٌ } منها ما قد خرب وهلك أهلها { وَمَا ظَلَمْنَاهُمْ } بإهلاكهم { وَلَـٰكِن ظَلَمُوۤاْ أَنفُسَهُمْ } بالكفر والشرك وعبادة الأوثان { فَمَا أَغْنَتْ عَنْهُمْ آلِهَتُهُمُ ٱلَّتِي يَدْعُونَ } يعبدون { مِن دُونِ ٱللَّهِ } من عذاب الله { مِن شَيْءٍ لَّمَّا جَآءَ أَمْرُ رَبِّكَ } حين جاء عذاب ربك { وَمَا زَادُوهُمْ } عبادة الأوثان { غَيْرَ تَتْبِيبٍ } غير تخسير { وَكَذٰلِكَ أَخْذُ رَبِّكَ } عذاب ربك { إِذَا أَخَذَ ٱلْقُرَىٰ } عذاب أهل القرى { وَهِيَ ظَالِمَةٌ } مشركة كافرة { إِنَّ أَخْذَهُ } عذابه { أَلِيمٌ } وجيع { شَدِيدٌ إِنَّ فِي ذٰلِكَ } فيما ذكرت لك { لآيَةً } لعبرة { لِّمَنْ خَافَ عَذَابَ ٱلآخِرَةِ } فلا يقتدي بهم { ذٰلِكَ } يوم القيامة { يَوْمٌ مَّجْمُوعٌ لَّهُ ٱلنَّاسُ } يجمع فيه الأولون والآخرون { وَذَلِكَ يَوْمٌ مَّشْهُودٌ } يشهده أهل السماء وأهل الأرض.
