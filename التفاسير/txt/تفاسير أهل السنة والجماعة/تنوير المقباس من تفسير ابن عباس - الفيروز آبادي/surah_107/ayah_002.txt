وبإسناده عن ابن عباس في قوله تعالى { أَرَأَيْتَ ٱلَّذِي يُكَذِّبُ بِٱلدِّينِ } ويقال يكذب بحساب يوم القيامة وهو العاص بن وائل السهمي { فَذَٰلِكَ ٱلَّذِي يَدُعُّ ٱلْيَتِيمَ } يقول يدفع اليتيم عن حقه ويقال يمنع حقه { وَلاَ يَحُضُّ } لا يحث ولا يحافظ { عَلَىٰ طَعَامِ ٱلْمِسْكِينِ } على صدقة المساكين { فَوَيْلٌ } شدة عذاب في النار { لِّلْمُصَلِّينَ } للمنافقين ثم بينهم فقال { ٱلَّذِينَ هُمْ عَن صَلاَتِهِمْ سَاهُونَ } لاهون تاركون لها { ٱلَّذِينَ هُمْ يُرَآءُونَ } بصلاتهم إذا رأوا الناس صلوا وإذا لم يروا لم يصلوا { وَيَمْنَعُونَ ٱلْمَاعُونَ } المعروف ويقال الزكاة ويقال العواري بين الناس مثل القدر والأواني مما ينتفع به الناس وغير ذلك.
