{ فَأَمَّا ٱلَّذِينَ آمَنُواْ بِٱللَّهِ } وبمحمد والقرآن { وَٱعْتَصَمُواْ بِهِ } تمسكوا بتوحيد الله { فَسَيُدْخِلُهُمْ فِي رَحْمَةٍ مِّنْهُ } في جنة { وَفَضْلٍ } كرامة منه مقدم ومؤخر { وَيَهْدِيهِمْ إِلَيْهِ صِرَاطاً مُّسْتَقِيماً } يثبتهم على طريق مستقيم في الدنيا مقدم ومؤخر يقول يثبتهم في الدنيا على الإيمان ويدخلهم في الآخرة الجنة { يَسْتَفْتُونَكَ } يسألونك يا محمد. نزلت هذه الآية في جابر بن عبد الله الأنصاري سأل النبي صلى الله عليه وسلم أن لي أختاً ما لي منها إن ماتت فقال الله يسألونك يا محمد عن ميراث الكلالة { قُلِ ٱللَّهُ يُفْتِيكُمْ } يبين لكم { فِي ٱلْكَلاَلَةِ } في ميراث الكلالة والكلالة ما خلا الوالد والولد ثم بين فقال { إِن ٱمْرُؤٌ هَلَكَ } مات { لَيْسَ لَهُ وَلَدٌ } ولا والد { وَلَهُ أُخْتٌ } من أبيه وأمه أو من أبيه { فَلَهَا نِصْفُ مَا تَرَكَ } الميت من المال { وَهُوَ يَرِثُهَآ } إن ماتت { إِن لَّمْ يَكُنْ لَّهَآ وَلَدٌ } ذكر أو أنثى { فَإِن كَانَتَا ٱثْنَتَيْنِ } أختين من أب وأم أو أب { فَلَهُمَا ٱلثُّلُثَانِ مِمَّا تَرَكَ } ما ترك الميت من المال { وَإِن كَانُوۤاْ إِخْوَةً رِّجَالاً وَنِسَآءً } ذكراً أو أنثى من أب وأم أو من أب { فَلِلذَّكَرِ مِثْلُ حَظِّ } نصيب { ٱلأُنثَيَيْنِ يُبَيِّنُ ٱللَّهُ لَكُمْ } قسمة المواريث { أَن تَضِلُّواْ } لكي لا تخطئوا في قسمة المواريث { وَٱللَّهُ بِكُلِّ شَيْءٍ } من قسمة المواريث وغيرها { عَلِيمٌ }.
