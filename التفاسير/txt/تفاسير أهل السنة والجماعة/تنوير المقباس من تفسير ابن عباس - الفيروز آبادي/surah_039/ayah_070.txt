{ وَوُفِّيَتْ } وفرت { كُلُّ نَفْسٍ } برة أو فاجرة { مَّا عَمِلَتْ } من خير أو شر { وَهُوَ أَعْلَمُ بِمَا يَفْعَلُونَ } من الخير والشر.  { وَسِيقَ ٱلَّذِينَ كَـفَرُوۤاْ إِلَىٰ جَهَنَّمَ زُمَراً } أمماً الأول فالأول { حَتَّىٰ إِذَا جَآءُوهَا } يعني النار { فُتِحَتْ أَبْوَابُهَا } طرقها لهم ولم تكن قبل ذلك مفتوحة { وَقَالَ لَهُمْ خَزَنَتُهَآ } يعني الزبانية { أَلَمْ يَأْتِكُمْ } يا معشر الكفار { رُسُلٌ مِّنكُمْ } آدميون مثلكم { يَتْلُونَ } يقرؤون { عَلَيْكُمْ آيَاتِ رَبِّكُمْ } بالأمر والنهي { وَيُنذِرُونَكُمْ } يخوفونكم { لِقَـآءَ } عذاب { يَوْمِكُمْ هَـٰذَا قَالُواْ بَلَىٰ } قد أتونا بالرسالة { وَلَـٰكِنْ حَقَّتْ } وجبت { كَلِمَةُ ٱلْعَذَابِ عَلَى ٱلْكَافِرِينَ } قبل ذلك { قِيلَ } يقول لهم الزبانية { ٱدْخُلُوۤاْ أَبْوَابَ جَهَنَّمَ خَالِدِينَ فِيهَا } دائمين في النار { فَبِئْسَ مَثْوَى ٱلْمُتَكَـبِّرِينَ } منزل المتعظمين عن الإيمان بالكتاب والرسول { وَسِيقَ ٱلَّذِينَ ٱتَّقَوْاْ } أطاعوا { رَبَّهُمْ إِلَى ٱلّجَنَّةِ زُمَراً } فوجاً فوجاً { حَتَّىٰ إِذَا جَآءُوهَا } أي الجنة { وَفُتِحَتْ أَبْوَابُهَا } وقد كانت مفتوحة قبل ذلك { وَقَالَ لَهُمْ خَزَنَتُهَا } خزان الجنان على باب الجنان { سَلاَمٌ عَلَيْكُـمْ } يسلمون عليكم بالتحية والسلام { طِبْتُمْ } فزتم ونجوتم ويقال طهرتم وصلحتم { فَٱدْخُلُوهَا } يعني الجنة { خَالِدِينَ } دائمين مقيمين فيها لا تموتون ولا تخرجون منها { وَقَـالُواْ } بعد ذلك حين علموا كرامة الله { ٱلْحَـمْدُ لِلَّهِ } المنة لله { ٱلَّذِي صَدَقَنَا وَعْدَهُ } أنجزنا وعده { وَأَوْرَثَنَا ٱلأَرْضَ } أنزلنا أرض الجنة { نَتَبَوَّأُ } ننزل { مِنَ ٱلْجَنَّةِ حَيْثُ نَشَآءُ } نشتهي { فَنِعْمَ أَجْرُ ٱلْعَامِلِينَ } ثواب العاملين لله في الدنيا { وَتَرَى ٱلْمَلاَئِكَةَ حَآفِّينَ } محدقين { مِنْ حَوْلِ ٱلْعَرْشِ يُسَبِّحُونَ بِحَمْدِ رَبِّهِمْ } بأمر ربهم { وَقُضِيَ بَيْنَهُمْ } بين النبيين والأمم { بِٱلْحَقِّ } بالعدل { وَقِيلَ } لهم بعد الفراغ من الحساب قولوا { ٱلْحَمْدُ لِلَّهِ رَبِّ ٱلْعَالَمِينَ } سيد الجن والإنس على ما فرق بيننا وبين أعدائنا وهو منزل حم وهو العزيز العليم.
