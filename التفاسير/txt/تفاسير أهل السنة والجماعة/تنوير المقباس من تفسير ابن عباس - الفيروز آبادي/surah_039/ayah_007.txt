{ إِن تَكْفُرُواْ } بمحمد صلى الله عليه وسلم والقرآن يا أهل مكة { فَإِنَّ ٱللَّهَ غَنِيٌّ عَنكُمْ } عن إيمانكم { وَلاَ يَرْضَىٰ لِعِبَادِهِ ٱلْكُفْرَ } ولا يقبل منهم الكفر بمحمد صلى الله عليه وسلم والقرآن لأنه ليس دينه { وَإِن تَشْكُرُواْ } تؤمنوا { يَرْضَهُ لَكُمْ } يقبله منكم لأنه دينه { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَىٰ } لا تحمل حاملة حمل أخرى ما عليها من الذنوب ويقال لا تؤخذ نفس بذنب نفس أخرى كل مأخوذ بذنبه ويقال لا تعذب نفس بغير ذنب { ثُمَّ إِلَىٰ رَبِّكُمْ مَّرْجِعُكُـمْ } بعد الموت { فَيُنَبِّئُكُـمْ } يخبركم يوم القيامة { بِمَا كُنتُمْ تَعْمَلُونَ } وتقولون في الدنيا { إِنَّهُ عَلِيمٌ بِذَاتِ ٱلصُّدُورِ } بما في القلوب من الخير والشر { وَإِذَا مَسَّ } أصاب { ٱلإِنسَانَ } الكافر أبا جهل وأصحابه { ضُرٌّ } شدة وبلاء { دَعَا رَبَّهُ } برفع الشدة والبلاء عنه { مُنِيباً إِلَيْهِ } مقبلاً إليه بالدعاء { ثُمَّ إِذَا خَوَّلَهُ } بدله { نِعْمَةً مِّنْهُ نَسِيَ مَا كَانَ يَدْعُوۤ إِلَيْهِ مِن قَبْلُ } من قبل النعمة { وَجَعَلَ لِلَّهِ أَندَاداً } أشكالاً وأعدالاً { لِّيُضِلَّ } بذلك الناس { عَن سَبِيلِهِ } عن دينه وطاعته { قُلْ } لأبي جهل { تَمَتَّعْ بِكُفْرِكَ } عش في كفرك { قَلِيلاً } يسيراً في الدنيا { إِنَّكَ مِنْ أَصْحَابِ ٱلنَّارِ } من أهل النار { أَمَّنْ هُوَ قَانِتٌ } مطيع لله وهو النبي صلى الله عليه وسلم وأصحابه { آنَآءَ ٱللَّيْلِ } ساعات الليل { سَاجِداً وَقَآئِماً } في الصلاة { يَحْذَرُ ٱلآخِرَةَ } يخاف عذاب الآخرة { وَيَرْجُواْ رَحْمَةَ رَبِّهِ } جنة ربه كأبي جهل وأصحابه { قُلْ } لهم يا محمد { هَلْ يَسْتَوِي } في الثواب والطاعة { ٱلَّذِينَ يَعْلَمُونَ } توحيد الله وأمره ونهيه وهو أبو بكر وأصحابه { وَٱلَّذِينَ لاَ يَعْلَمُونَ } توحيد الله وأمره ونهيه وهو أبو جهل وأصحابه { إِنَّمَا يَتَذَكَّرُ } يتعظ بأمثال القرآن { أُوْلُواْ ٱلأَلْبَابِ } ذوو العقول من الناس { قُلْ } لهم يا محمد { يَٰعِبَادِ ٱلَّذِينَ آمَنُواْ } أبو بكر الصديق وعمر الفاروق وعثمان ذو النورين وعلي المرتضى وأصحابهم { ٱتَّقُواْ رَبَّكُمْ } أطيعوا ربكم في الصغير من الأمور والكبير { لِلَّذِينَ أَحْسَنُواْ } وحدوا { فِي هَـٰذِهِ ٱلدُّنْيَا حَسَنَةٌ } لهم جنة يوم القيامة { وَأَرْضُ ٱللَّهِ } أرض المدينة { وَاسِعَةٌ } آمنة من العدو فاخرجوا إليها وهذا قبل الهجرة { إِنَّمَا يُوَفَّى ٱلصَّابِرُونَ } على المرازي { أَجْرَهُمْ } ثوابهم { بِغَيْرِ حِسَابٍ } بلا كيل ولا هنداز ولا منة.
