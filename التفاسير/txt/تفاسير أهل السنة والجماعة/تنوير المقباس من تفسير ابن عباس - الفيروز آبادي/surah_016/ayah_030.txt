{ وَقِيلَ لِلَّذِينَ ٱتَّقَوْاْ } الكفر والشرك والفواحش عبد الله بن مسعود وأصحابه { مَاذَا أَنْزَلَ رَبُّكُمْ } ماذا يقول لكم محمد عليه الصلاة والسلام من ربكم { قَالُواْ خَيْراً } توحيداً وصلة { لِّلَّذِينَ أَحْسَنُواْ فِي هٰذِهِ ٱلْدُّنْيَا حَسَنَةٌ } الجنة يوم القيامة { وَلَدَارُ ٱلآخِرَةِ } يعني الجنة { خَيْرٌ } من الدنيا وما فيها { وَلَنِعْمَ دَارُ ٱلْمُتَّقِينَ } الكفر والشرك والفواحش الجنة { جَنَّاتُ عَدْنٍ } وهي مقصورة الرحمن { يَدْخُلُونَهَا } يوم القيامة { تَجْرِي مِن تَحْتِهَا } من تحت شجرها ومساكنها { ٱلأَنْهَارُ } أنهار الخمر والماء والعسل واللبن { لَهُمْ فِيهَا } في الجنة { مَا يَشَآؤونَ } ما يشتهون ويتمنون { كَذَلِكَ } هكذا { يَجْزِي ٱللَّهُ ٱلْمُتَّقِينَ } الكفر والشرك والفواحش { ٱلَّذِينَ تَتَوَفَّاهُمُ ٱلْمَلاۤئِكَةُ } قبضتهم الملائكة { طَيِّبِينَ } طاهرين من الشرك { يَقُولُونَ سَلامٌ عَلَيْكُمُ } من الله { ٱدْخُلُواْ ٱلْجَنَّةَ } بإيمانكم واقتسموها { بِمَا كُنْتُمْ تَعْمَلُونَ } وتقولون من الخيرات في الدنيا { هَلْ يَنْظُرُونَ } ما ينتظرون أهل مكة إذ لا يؤمنون { إِلاَّ أَن تَأْتِيَهُمُ ٱلْمَلائِكَةُ } لقبض أرواحهم { أَوْ يَأْتِيَ أَمْرُ رَبِّكَ } عذاب ربك بهلاكهم { كَذَلِكَ } كما فعل بك قومك كذبوك وشتموك { فَعَلَ ٱلَّذِينَ مِن قَبْلِهِمْ } من قبل قومك بأنبيائهم كذبوهم وشتموهم { وَمَا ظَلَمَهُمُ ٱللَّهُ } بهلاكهم { وَلـٰكِن كَانُواْ أَنْفُسَهُمْ يَظْلِمُونَ } بالشرك وتكذيب الرسل { فَأَصَابَهُمْ سَيِّئَاتُ مَا عَمِلُواْ } عقوبة ما عملوا وقالوا من المعاصي { وَحَاقَ بِهِم } دار ونزل بهم ووجب عليهم { مَّا كَانُواْ بِهِ يَسْتَهْزِئُونَ } عقوبة استهزائهم بالأنبياء ويقال العذاب الذي كانوا به يستهزئون { وَقَالَ ٱلَّذِينَ أَشْرَكُواْ } بالله الأوثان يعني أهل مكة { لَوْ شَآءَ ٱللَّهُ مَا عَبَدْنَا مِن دُونِهِ مِن شَيْءٍ } من الأصنام { نَّحْنُ وَلاۤ آبَاؤُنَا } قبلنا { وَلاَ حَرَّمْنَا مِن دُونِهِ } من دون الله { مِن شَيْءٍ } من البحيرة والسائبة والوصيلة والحام ولكن حرم الله وأمرنا بذلك { كَذٰلِكَ } كما فعل كذب قومك على الله بتحريم الحرث والأنعام { فَعَلَ } كذب { ٱلَّذِينَ مِن قَبْلِهِمْ } على الله { فَهَلْ عَلَى ٱلرُّسُلِ } ما على الرسل { إِلاَّ ٱلْبَلاغُ } عن الله رسالة الله { ٱلْمُبِينُ } بلغة تعلمونها ظاهرة { وَلَقَدْ بَعَثْنَا فِي كُلِّ أُمَّةٍ } إلى كل قوم { رَّسُولاً } كما أرسلناك إلى قومك { أَنِ ٱعْبُدُواْ ٱللَّهَ } وحدوا الله { وَٱجْتَنِبُواْ ٱلْطَّاغُوتَ } اتركوا عبادة الأصنام ويقال الشيطان ويقال الكاهن { فَمِنْهُم } من أرسلنا إليهم الرسل { مَّنْ هَدَى ٱللَّهُ } لدينه فأجاب الرسل إلى الإيمان { وَمِنْهُمْ مَّنْ حَقَّتْ } وجبت { عَلَيْهِ ٱلضَّلالَةُ } فلم يجب الرسل إلى الإيمان { فَسِيرُواْ } سافروا { فِي ٱلأَرْضِ فَٱنظُرُواْ } فاعتبروا { كَيْفَ كَانَ عَاقِبَةُ ٱلْمُكَذِّبِينَ } آخر أمر المكذبين بالرسل.
