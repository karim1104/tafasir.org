وبإسناده عن ابن عباس في قوله تعالى { سَأَلَ سَآئِلٌ } يقول دعا داع وهو النضر بن الحارث { بِعَذَابٍ وَاقِعٍ } نازل { لِّلْكَافِرِينَ } على الكافرين وهو من الكافرين { لَيْسَ لَهُ } للعذاب { دَافِعٌ } مانع فقتل يوم بدر صبراً { مِّنَ ٱللَّهِ } يأتي هذا العذاب على الكافرين { ذِي ٱلْمَعَارِجِ } خالق السموات { تَعْرُجُ ٱلْمَلاَئِكَةُ وَٱلرُّوحُ } يعني جبريل { إِلَيْهِ } إلى الله { فِي يَوْمٍ كَانَ مِقْدَارُهُ } مقدار الصعود على غير الملائكة { خَمْسِينَ أَلْفَ سَنَةٍ } ويقال من الله يأتي هذا العذاب على الكافرين في يوم كان مقداره خمسين ألف سنة ويقال لو ولي محاسبة الخلائق إلى أحد غير الله لم يفرغ منه خمسين ألف سنة { فَٱصْبِرْ } على أذاهم يا محمد { صَبْراً جَمِيلاً } بلا جزع ولا فحش ويقال فاعتزل عنهم اعتزالاً جميلاً بلا جزع ولا فحش فأمر بعد ذلك بالقتال { إِنَّهُمْ } كانوا يعني كفار مكة { يَرَوْنَهُ } يعني العذاب يوم القيامة { بَعِيداً } غير كائن.
