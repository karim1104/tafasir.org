{ قَالُوۤاْ } إخوة يوسف { إِن يَسْرِقْ } إن سرق بنيامين سقاية الملك { فَقَدْ سَرَقَ أَخٌ لَّهُ مِن قَبْلُ } من قبله أخوه لأبيه وأمه صنماً { فَأَسَرَّهَا يُوسُفُ } جواب هذه الكلمة { فِي نَفْسِهِ وَلَمْ يُبْدِهَا لَهُمْ } جوابها { قَالَ } في نفسه { أَنْتُمْ شَرٌّ مَّكَاناً } صنيعاً من يوسف { وَٱللَّهُ أَعْلَمْ بِمَا تَصِفُونَ } تقولون من أمر يوسف { قَالُواْ يَٰأَيُّهَا ٱلْعَزِيزُ إِنَّ لَهُ أَباً شَيْخاً كَبِيراً } يفرح به إن رددناه { فَخُذْ أَحَدَنَا } رهناً { مَكَانَهُ إِنَّا نَرَاكَ } إن فعلت ذلك { مِنَ ٱلْمُحْسِنِينَ } إلينا { قَالَ } لهم يوسف { مَعَاذَ ٱللَّهِ } أعوذ بالله { أَن نَّأْخُذَ } بالسرقة { إِلاَّ مَن وَجَدْنَا مَتَاعَنَا عِندَهُ إِنَّـآ إِذاً لَّظَالِمُونَ } بحبس من لم نجد متاعنا عنده { فَلَمَّا ٱسْتَيْأَسُواْ مِنْهُ } أيسوا منه { خَلَصُواْ نَجِيّاً } خلوا نجياً للمناجاة فيما بينهم { قَالَ كَبِيرُهُمْ } أفضلهم في العقل وهو يهوذا { أَلَمْ تَعْلَمُوۤاْ } يا إخوتاه { أَنَّ أَبَاكُمْ قَدْ أَخَذَ عَلَيْكُمْ مَّوْثِقاً مِّنَ ٱللَّهِ } لتردنه عليَّ { وَمِن قَبْلُ } من قبل هذا الغلام { مَا فَرَّطتُمْ } ما تركتم عهده وميثاقه { فِي يُوسُفَ فَلَنْ أَبْرَحَ ٱلأَرْضَ } أرض مصر { حَتَّىٰ يَأْذَنَ لِيۤ أَبِيۤ } بالرجوع ويقال يأذن لي أبي حتى أناجزهم القتال { أَوْ يَحْكُمَ ٱللَّهُ لِي } في رد أخي { وَهُوَ خَيْرُ } أفضل { ٱلْحَاكِمِينَ } في رده إلي ثم قال لهم يهوذا { ٱرْجِعُوۤاْ } يا إخوتي { إِلَىٰ أَبِيكُمْ فَقُولُواْ يَٰأَبَانَا إِنَّ ٱبْنَكَ سَرَقَ } صواع الملك إناء من ذهب ويقال أخذ بالسرقة إن قرأت بضم السين وخفض الراء بالتشديد { وَمَا شَهِدْنَآ إِلاَّ بِمَا عَلِمْنَا } رأينا أن السرقة أخرجت من رحله { وَمَا كُنَّا لِلْغَيْبِ حَافِظِينَ } يقول لو علمنا الغيب ما ذهبنا به ويقال ما كنا له بالليل حافظين.  { وَسْئَلِ ٱلْقَرْيَةَ } أهل القرية { ٱلَّتِي كُنَّا فِيهَا } وهي قرية من قرى مصر { وَٱلّعِيْرَ } أهل العير { ٱلَّتِيۤ أَقْبَلْنَا فِيهَا } جئنا معهم وكان صحبهم قوم من كنعان { وَإِنَّا لَصَادِقُونَ } فيما قلنا لك فقالوا ليعقوب هذا القول { قَالَ } يعقوب لهم { بَلْ سَوَّلَتْ } زينت { لَكُمْ أَنفُسُكُمْ أَمْراً } ففعلتموه { فَصَبْرٌ جَمِيلٌ } فعلي صبر جميل بلا جزع { عَسَى ٱللَّهُ } لعل الله { أَن يَأْتِيَنِي بِهِمْ جَمِيعاً } بيوسف وأخيه من أبيه وأمه بنيامين ويهوذا { إِنَّهُ هُوَ ٱلْعَلِيمُ } بمكانهم { ٱلْحَكِيمُ } بردهم علي { وَتَوَلَّىٰ عَنْهُمْ } خرج من بينهم { وَقَالَ يَٰأَسَفَىٰ } يا حزنا { عَلَى يُوسُفَ وَٱبْيَضَّتْ عَيْنَاهُ مِنَ ٱلْحُزْنِ } من البكاء { فَهُوَ كَظِيمٌ } مغموم يتردد حزنه في جوفه.
