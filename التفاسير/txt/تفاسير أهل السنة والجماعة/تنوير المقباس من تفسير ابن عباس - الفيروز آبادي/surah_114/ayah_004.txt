وبإسناده عن ابن عباس في قوله تعالى { قُلْ أَعُوذُ } يقول قل يا محمد امتنع ويقال أستعيذ { بِرَبِّ ٱلنَّاسِ } بسيد الجن والإنس { مَلِكِ ٱلنَّاسِ } مالك الجن والإنس { إِلَـٰهِ ٱلنَّاسِ } خلق الجن والإنس { مِن شَرِّ ٱلْوَسْوَاسِ } يعني الشيطان { ٱلْخَنَّاسِ ٱلَّذِى } إذا ذكر الله خنس نفسه وسترها وإذا لم يذكر { يُوَسْوِسُ فِي صُدُورِ ٱلنَّاسِ } في صدور الخلق { مِنَ ٱلْجِنَّةِ وَٱلنَّاسِ } يقول يوسوس في صدور الجن كما يوسوس في صدور الناس. نزلت هاتان السورتان في شأن لبيد بن الأعصم اليهودي الذي سحر النبي فقرأ النبي صلى الله عليه وسلم على سحره ففرج الله عنه فكأنما نشط من عقال.
