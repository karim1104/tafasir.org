{ وَعَدَ الله الْمُنَافِقِينَ } من الرجال { وَٱلْمُنَافِقَاتِ } من النساء { وَٱلْكُفَّارَ نَارَ جَهَنَّمَ خَالِدِينَ فِيهَا } مقيمين في النار { هِيَ حَسْبُهُمْ } مصيرهم { وَلَعَنَهُمُ ٱللَّهُ } عذبهم الله { وَلَهُمْ عَذَابٌ مُّقِيمٌ } دائم { كَٱلَّذِينَ } كعذاب الذين { مِن قَبْلِكُمْ } من المنافقين { كَانُواْ أَشَدَّ مِنكُمْ قُوَّةً } بالبدن { وَأَكْثَرَ أَمْوَالاً وَأَوْلاَداً فَٱسْتَمْتَعُواْ بِخَلاقِهِمْ } فأكلوا بنصيبهم من الآخرة في الدنيا { فَٱسْتَمْتَعْتُمْ بِخَلاَقِكُمْ } فأكلتم بنصيبكم من الآخرة في الدنيا { كَمَا ٱسْتَمْتَعَ } كما أكل { ٱلَّذِينَ مِن قَبْلِكُمْ } من المنافقين { بِخَلاَقِهِمْ } بنصيبهم من الآخرة في الدنيا { وَخُضْتُمْ } في الباطل { كَٱلَّذِي خَاضُوۤاْ } وكذبتم محمداً صلى الله عليه وسلم في السر كالذين خاضوا وكذبوا أنبياءه يعني أنبياء الله { أُوْلَـٰئِكَ حَبِطَتْ أَعْمَالُهُمْ } بطلت حسناتهم { فِي ٱلدنْيَا وَٱلآخِرَةِ وَأُوْلَـٰئِكَ هُمُ ٱلْخَاسِرُونَ } المغبونون بالعقوبة { أَلَمْ يَأْتِهِمْ نَبَأُ } خبر { ٱلَّذِينَ مِن قَبْلِهِمْ } كيف أهلكناهم { قَوْمِ نُوحٍ } أهلكناهم بالغرق { وَعَادٍ } قوم هود أهلكناهم بالريح { وَثَمُودَ } قوم صالح أهلكناهم بالرجفة { وَقَوْمِ إِبْرَاهِيمَ } أهلكناهم بالهدم { وِأَصْحَابِ مَدْيَنَ } قوم شعيب أهلكناهم بالرجفة { وَٱلْمُؤْتَفِكَاتِ } المكذبات المنخسفات يعني قوم لوط أهلكناهم بالخسف والحجارة { أَتَتْهُمْ رُسُلُهُمْ بِٱلْبَيِّنَاتِ } بالأمر والنهي والعلامات فلم يؤمنوا بهم فأهلكهم الله { فَمَا كَانَ ٱللَّهُ لِيَظْلِمَهُمْ } بهلاكهم { وَلَـٰكِن كَانُوۤاْ أَنْفُسَهُمْ يَظْلِمُونَ } الكفر وتكذيب الأنبياء { وَٱلْمُؤْمِنُونَ } المصدقون من الرجال { وَٱلْمُؤْمِنَاتِ } المصدقات من النساء { بَعْضُهُمْ أَوْلِيَآءُ بَعْضٍ } على دين بعض في السر والعلانية { يَأْمُرُونَ بِٱلْمَعْرُوفِ } بالتوحيد واتباع محمد صلى الله عليه وسلم { وَيَنْهَوْنَ عَنِ ٱلْمُنْكَرِ } عن الكفر والشرك وترك أتباع محمد صلى الله عليه وسلم { وَيُقِيمُونَ ٱلصَّلاَةَ } يتمون الصلوات الخمس { وَيُؤْتُونَ ٱلزَّكَاةَ } يعطون زكاة أموالهم { وَيُطِيعُونَ ٱللَّهَ وَرَسُولَهُ } في السر والعلانية { أُوْلَـٰئِكَ سَيَرْحَمُهُمُ ٱللَّهُ } لا يعذبهم الله { إِنَّ ٱللَّهَ عَزِيزٌ } في ملكه وسلطانه { حَكِيمٌ } في أمره وقضائه { وَعَدَ ٱللَّهُ ٱلْمُؤْمِنِينَ } المصدقين من الرجال { وَٱلْمُؤْمِنَاتِ } المصدقات من النساء { جَنَّاتٍ } بساتين { تَجْرِي مِن تَحْتِهَا } من تحت شجرها ومساكنها { ٱلأَنْهَارُ } أنهار الخمر والماء والعسل واللبن { خَالِدِينَ فِيهَا } مقيمين في الجنة { وَمَسَاكِنَ طَيِّبَةً } منازل حسنة قد طيبها الله بالمسك والريحان ويقال جميلة ويقال طاهرة ويقال عامرة { فِي جَنَّاتِ عَدْنٍ } درجة العليا { وَرِضْوَانٌ مِّنَ ٱللَّهِ أَكْبَرُ } رضا ربهم أعظم مما هم فيه { ذٰلِكَ } الذي ذكرت { هُوَ ٱلْفَوْزُ ٱلْعَظِيمُ } النجاة الوافرة.
