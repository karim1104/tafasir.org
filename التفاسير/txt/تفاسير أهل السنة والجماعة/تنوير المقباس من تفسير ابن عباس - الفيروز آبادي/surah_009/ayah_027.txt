{ ثُمَّ يَتُوبُ ٱللَّهُ مِن بَعْدِ ذٰلِكَ } القتال والهزيمة { عَلَىٰ مَن يَشَآءُ } على من تاب منهم { وَٱللَّهُ غَفُورٌ } متجاوز { رَّحِيمٌ } لمن تاب { يَٰأَيُّهَا ٱلَّذِينَ آمَنُوۤاْ إِنَّمَا ٱلْمُشْرِكُونَ نَجَسٌ } قذر { فَلاَ يَقْرَبُواْ ٱلْمَسْجِدَ ٱلْحَرَامَ } بالحج والطواف { بَعْدَ عَامِهِمْ هَـٰذَا } عام البراءة يوم النحر { وَإِنْ خِفْتُمْ عَيْلَةً } الفقر والحاجة { فَسَوْفَ يُغْنِيكُمُ ٱللَّهُ مِن فَضْلِهِ } من رزقه من وجه آخر { إِن شَآءَ } حيث شاء ويغنيكم عن تجارة بكر بن وائل { إِنَّ ٱللَّهَ عَلِيمٌ } بأرزاقكم { حَكِيمٌ } فيما حكم عليكم { قَاتِلُواْ ٱلَّذِينَ لاَ يُؤْمِنُونَ بِٱللَّهِ وَلاَ بِٱلْيَوْمِ ٱلآخِرِ } ولا بنعيم الجنة { وَلاَ يُحَرِّمُونَ } في التوراة { مَا حَرَّمَ ٱللَّهُ وَرَسُولُهُ وَلاَ يَدِينُونَ دِينَ ٱلْحَقِّ } لا يخضعون لله بالتوحيد ثم بيَّن من هم فقال { مِنَ ٱلَّذِينَ أُوتُواْ ٱلْكِتَابَ } أعطوا الكتاب يعني اليهود والنصارى { حَتَّىٰ يُعْطُواْ ٱلْجِزْيَةَ عَن يَدٍ } عن قيام من يد في يد { وَهُمْ صَاغِرُونَ } ذليلون { وَقَالَتِ ٱلْيَهُودُ } يهود أهل المدينة { عُزَيْرٌ ٱبْنُ ٱللَّهِ وَقَالَتْ ٱلنَّصَارَى } نصارى أهل نجران { ٱلْمَسِيحُ ٱبْنُ ٱللَّهِ ذٰلِكَ قَوْلُهُم بِأَفْوَاهِهِمْ } بألسنتهم { يُضَاهِئُونَ } يشابهون { قَوْلَ ٱلَّذِينَ كَفَرُواْ مِن قَبْلُ } من قبلهم يعني أهل مكة لأن أهل مكة قالوا اللات والعزى ومناة بنات الله وكذلك قالت اليهود عزير ابن الله وقالت النصارى قال بعضهم المسيح ابن الله وقال بعضهم شريكه وقال بعضهم هو الله وقال بعضهم ثالث ثلاثة { قَاتَلَهُمُ ٱللَّهُ } لعنهم الله { أَنَّىٰ يُؤْفَكُونَ } من أين يكذبون { ٱتَّخَذُوۤاْ أَحْبَارَهُمْ } علماءهم يعني اليهود { وَرُهْبَانَهُمْ } واتخذت النصارى أصحاب الصوامع { أَرْبَاباً } أطاعوهم بالمعصية { مِّن دُونِ ٱللَّهِ وَٱلْمَسِيحَ ٱبْنَ مَرْيَمَ } واتخذوا المسيح ابن مريم إلهاً { وَمَآ أُمِرُوۤاْ } في جملة الكتب { إِلاَّ لِيَعْبُدُوۤاْ } ليوحدوا { إِلَـٰهاً وَاحِداً لاَّ إِلَـٰهَ إِلاَّ هُوَ سُبْحَانَهُ } نزه نفسه { عَمَّا يُشْرِكُونَ يُرِيدُونَ أَن يُطْفِئُواْ } يبطلوا { نُورَ ٱللَّهِ } دين الله { بِأَفْوَاهِهِمْ } بتكذيبهم ويقال بألسنتهم { وَيَأْبَىٰ ٱللَّهُ } لا يترك الله { إِلاَّ أَن يُتِمَّ نُورَهُ } إلا أن يظهر دينه الإسلام { وَلَوْ كَرِهَ } وإن كره { ٱلْكَافِرُونَ } أن يكون ذلك { هُوَ ٱلَّذِيۤ أَرْسَلَ رَسُولَهُ } محمداً عليه الصلاة والسلام { بِٱلْهُدَىٰ } بالقرآن والإيمان { وَدِينِ ٱلْحَقِّ } دين الإسلام شهادة أن لا إله إلا الله { لِيُظْهِرَهُ عَلَى ٱلدِّينِ كُلِّهِ } ليظهر دين الإسلام على الأديان كلها من قبل أن تقوم الساعة { وَلَوْ كَرِهَ } وإن كره { ٱلْمُشْرِكُونَ } أن يكون ذلك.
