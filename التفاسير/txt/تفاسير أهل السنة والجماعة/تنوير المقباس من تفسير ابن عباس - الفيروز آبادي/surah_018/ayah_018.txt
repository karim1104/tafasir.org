{ فَضَرَبْنَا عَلَىٰ آذَانِهِمْ } ألقينا عليهم النوم وأنمناهم { فِي ٱلْكَهْفِ سِنِينَ عَدَداً } ثلاثمائة سنة وتسع سنين { ثُمَّ بَعَثْنَاهُمْ } أيقظناهم كما ناموا { لِنَعْلَمَ } لكي نرى { أَيُّ الحِزْبَيْنِ } أي الفريقين المؤمنون والكافرون { أَحْصَىٰ لِمَا لَبِثُواْ } أحفظ لما مكثوا في الكهف { أَمَداً } أجلاً { نَحْنُ نَقُصُّ عَلَيْكَ } نبين لك { نبَأَهُم } خبرهم { بِٱلْحَقِّ } بالقرآن { إِنَّهُمْ فِتْيَةٌ } غلمة { آمَنُواْ بِرَبِّهِمْ وَزِدْنَاهُمْ هُدًى } بصيرة في أمر دينهم ويقال ثبتناهم في أمر دينهم ويقال ثبتناهم على الإيمان { وَرَبَطْنَا عَلَىٰ قُلُوبِهِمْ } حفظنا قلوبهم بالإيمان ويقال ألهمناهم الصبر { إِذْ قَامُواْ } إذ خرجوا من عند الملك دفيانوس الكافر { فَقَالُواْ رَبُّنَا رَبُّ ٱلسَّمَاوَاتِ وَٱلأَرْضِ لَن نَّدْعُوَاْ مِن دُونِهِ } لن نعبد من دون الله { إِلـٰهاً } ربّاً { لَّقَدْ قُلْنَا إِذاً شَطَطاً } كذباً وزوراً على الله { هَـٰؤُلاۤءِ قَوْمُنَا ٱتَّخَذْواْ مِن دُونِهِ } عبدوا من دون الله { آلِهَةً } من الأوثان { لَّوْلاَ يَأْتُونَ عَلَيْهِم } هلا يأتون على عبادتهم { بِسُلْطَانٍ بَيِّنٍ } بحجة بينة أن الله أمرَهم بذلك { فَمَنْ أَظْلَمُ } فليس أحد أظلم { مِمَّنِ ٱفْتَرَىٰ } اختلق { عَلَى ٱللَّهِ كَذِباً } بأن له شريكاً { وَإِذِ ٱعْتَزَلْتُمُوهُمْ } تركتموهم وتركتم دينهم { وَمَا يَعْبُدُونَ } من دون الله من الأوثان فلا تعبدوا { إِلاَّ ٱللَّهَ فَأْوُوا إِلَى ٱلْكَهْفِ } فادخلوا هذا الغار { يَنْشُرْ لَكُمْ } يهب لكم { رَبُّكُم مِّن رَّحْمَتِهِ } من نعمته { وَيُهَيِّئْ لَكُمْ مِّنْ أَمْرِكُمْ مِّرْفَقاً } ما يرفق بكم غداً وهذا كله قول الفتية { وَتَرَى ٱلشَّمْسَ إِذَا طَلَعَت تَّزَاوَرُ } تميل { عَن كَهْفِهِمْ ذَاتَ ٱلْيَمِينِ } يمين الغار { وَإِذَا غَرَبَت تَّقْرِضُهُمْ } تتركهم { ذَاتَ ٱلشِّمَالِ } شمال الغار { وَهُمْ فِي فَجْوَةٍ مِّنْهُ } في ناحية من الكهف ويقال في فضاء منه من الضوء { ذٰلِكَ } الذي ذكرت من قصتهم { مِنْ آيَاتِ ٱللَّهِ } من عجائب الله { مَن يَهْدِ ٱللَّهُ } لدينه { فَهُوَ ٱلْمُهْتَدِ } لدينه { وَمَن يُضْلِلْ } عن دينه { فَلَن تَجِدَ لَهُ وَلِيّاً مُّرْشِداً } موفقاً يوفقه للهدى { وَتَحْسَبُهُمْ } يا محمد { أَيْقَاظاً } غير نيام { وَهُمْ رُقُودٌ } نيام { وَنُقَلِّبُهُمْ ذَاتَ ٱليَمِينِ وَذَاتَ ٱلشِّمَالِ } في كل عام مرة لكي لا تأكل الأرض لحومهم { وَكَلْبُهُمْ } قطمير { بَاسِطٌ ذِرَاعَيْهِ بِٱلوَصِيدِ } بفناء الباب { لَوِ ٱطَّلَعْتَ } هجمت { عَلَيْهِمْ } في تلك الحال { لَوْلَّيْتَ مِنْهُمْ } لأدبرت عنهم { فِرَاراً وَلَمُلِئْتَ مِنْهُمْ رُعْباً } لأخذت منهم خوفاً { وَكَذٰلِكَ } هكذا { بَعَثْنَاهُمْ } أيقظناهم بعد ما مضى ثلاثمائة سنة وتسع سنين { لِيَتَسَآءَلُوا بَيْنَهُمْ } ليتحدثوا فيما بينهم { قَالَ قَائِلٌ مِّنْهُمْ } سيدهم وكبيرهم وهو مكسلمينا { كَم لَبِثْتُمْ } مكثتم في هذا الغار بعد النوم { قَالُواْ لَبِثْنَا يَوْماً } فلما خرجوا فنظروا إلى الشمس وقد بقي منها شيء قالوا { أَوْ بَعْضَ يَوْمٍ قَالُواْ } يعني مكسلمينا { رَبُّكُمْ أَعْلَمُ بِمَا لَبِثْتُمْ } بعد النوم { فَٱبْعَثُواْ أَحَدَكُمْ } تمليخا { بِوَرِقِكُمْ هَـٰذِهِ } بدراهمكم هذه { إِلَىٰ ٱلْمَدِينَةِ } مدينة أفسوس { فَلْيَنْظُرْ أَيُّهَآ أَزْكَىٰ طَعَاماً } أكثر طعاماً ويقال أطيب خبزاً وأحل ذبيحة { فَلْيَأْتِكُمْ بِرِزْقٍ مِّنْهُ } بطعام منه { وَلْيَتَلَطَّفْ } برفق في الشراء { وَلاَ يُشْعِرَنَّ بِكُمْ } لا يعلمن بكم { أَحَداً } من المجوس.
