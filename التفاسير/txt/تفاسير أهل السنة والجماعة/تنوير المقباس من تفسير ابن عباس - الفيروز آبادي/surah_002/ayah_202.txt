{ ثُمَّ أَفِيضُواْ مِنْ حَيْثُ أَفَاضَ ٱلنَّاسُ } يقول ارجعوا من حيث رجع أهل اليمن { وَٱسْتَغْفِرُواْ ٱللَّهَ } لذنوبكم { إِنَّ ٱللَّهَ غَفُورٌ } لمن تاب { رَّحِيمٌ } لمن مات على التوبة، نزلت في أناس يقال لهم الحمسيون كانوا لا يريدون الخروج من الحرم إلى عرفات لحجهم فنهاهم الله عن ذلك وأمرهم أن يذهبوا إلى عرفات ويرجعوا من ثم { فَإِذَا قَضَيْتُمْ مَّنَاسِكَكُمْ } فإذا فرغتم من سنن حجكم { فَٱذْكُرُواْ ٱللَّهَ } فقولوا يا الله { كَذِكْرِكُمْ آبَآءَكُمْ } بيا أبه ويقال اذكروا الله بالإحسان إليكم كذكركم آباءكم كما ذكرتم آباءكم في الجاهلية بالإحسان { أَوْ أَشَدَّ ذِكْراً } بل أكثر ذكراً من ذكر آبائكم { فَمِنَ ٱلنَّاسِ مَن يَقُولُ } في الموقف { رَبَّنَآ آتِنَا } أعطنا { فِي ٱلدُّنْيَا } إبلاً وبقراً وغنماً وعبيداً وإماءً ومالاً { وَمَا لَهُ فِي ٱلآخِرَةِ مِنْ خَلاَقٍ } من نصيب في الجنة بحجه { وَمِنْهُم مَّن يَقُولُ رَبَّنَآ آتِنَا } أعطنا { فِي ٱلدُّنْيَا حَسَنَةً } العلم والعبادة والعصمة من الذنوب والشهادة والغنيمة { وَفِي ٱلآخِرَةِ حَسَنَةً } الجنة ونعيمها { وَقِنَا عَذَابَ ٱلنَّارِ } ادفع عنا عذاب القبر وعذاب النار { أُوْلَـٰئِكَ } أهل هذه الصفة { لَهُمْ نَصِيبٌ } حظ وافر في الجنة { مِّمَّا كَسَبُواْ } من حجهم { وَٱللَّهُ سَرِيعُ ٱلْحِسَابِ } يقول إذا حاسب فحسابه سريع ويقال سريع الحفظ ويقال شديد العقاب لأهل الرياء { وَٱذْكُرُواْ ٱللَّهَ } بالتكبير والتهليل والتمجيد { فِيۤ أَيَّامٍ مَّعْدُودَاتٍ } معلومات أيام التشريق وهي خمسة أيام يوم عرفة ويوم النحر وثلاثة أيام بعدهما { فَمَن تَعَجَّلَ } برجوعه إلى أهله { فِي يَوْمَيْنِ } بعد يوم النحر { فَلا إِثْمَ عَلَيْهِ } بتعجيله { وَمَن تَأَخَّرَ } إلى اليوم الثالث { فَلاۤ إِثْمَ عَلَيْهِ } بتأخيره ويقال فلا عتب عليه بتأخيره يخرج مغفوراً له { لِمَنِ ٱتَّقَىٰ } يقول التعجيل لمن اتقى الصيد إلى اليوم الثالث { وَٱتَّقُواْ ٱللَّهَ } واخشوا الله في أخذ الصيد إلى اليوم الثالث { وَٱعْلَمُوۤاْ أَنَّكُمْ إِلَيْهِ تُحْشَرُونَ } بعد الموت { وَمِنَ ٱلنَّاسِ مَن يُعْجِبُكَ قَوْلُهُ } كلامه وحديث وعلانيته { فِي ٱلْحَيَاةِ ٱلدُّنْيَا } في الدنيا { وَيُشْهِدُ ٱللَّهَ عَلَىٰ مَا فِي قَلْبِهِ } يحلف بالله إني أحبك وأتابعك { وَهُوَ أَلَدُّ ٱلْخِصَامِ } جدل بالباطل شديد الخصومة.
