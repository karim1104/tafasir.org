{ لاَ شَرِيكَ لَهُ وَبِذٰلِكَ أُمِرْتُ وَأَنَاْ أَوَّلُ ٱلْمُسْلِمِينَ } المخلصين بالعبادة والتوحيد { قُلْ } يا محمد { أَغَيْرَ ٱللَّهِ أَبْغِي رَبّاً } أعبد ربّاً { وَهُوَ رَبُّ كُلِّ شَيْءٍ } بائن منه { وَلاَ تَكْسِبُ كُلُّ نَفْسٍ } من الذنوب { إِلاَّ عَلَيْهَا } عقوبة ذلك { وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَىٰ } لا تحمل حاملة حمل أخرى من الذنوب ويقال لا تؤخذ نفس بذنب نفس أخرى ويقال لا تعذب نفس بغير ذنب ويقال لا تحمل حمالة ذنب أخرى بطيبة النفس ولكن يحمل عليها بالكره { ثُمَّ إِلَىٰ رَبِّكُمْ مَّرْجِعُكُمْ } بعد الموت { فَيُنَبِّئُكُمْ } يخبركم { بِمَا كُنتُمْ فِيهِ } في الدين { تَخْتَلِفُونَ } تخالفون { وَهُوَ ٱلَّذِي جَعَلَكُمْ خَلاَئِفَ ٱلأَرْضِ } خلف الأمم الماضية في الأرض { وَرَفَعَ بَعْضَكُمْ فَوْقَ بَعْضٍ دَرَجَاتٍ } فضائل بالمال والخدم { لِّيَبْلُوَكُمْ } ليختبركم { فِي مَآ آتَاكُمْ } أعطاكم من المال والخدم { إِنَّ رَبَّكَ سَرِيعُ ٱلْعِقَابِ } لمن كفر به ولا يشكره { وَإِنَّهُ لَغَفُورٌ } متجاوز { رَّحِيمٌ } لمن آمن به.
