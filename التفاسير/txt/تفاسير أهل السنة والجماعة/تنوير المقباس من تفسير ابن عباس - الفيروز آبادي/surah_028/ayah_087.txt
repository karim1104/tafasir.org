{ تِلْكَ ٱلدَّارُ ٱلآخِرَةُ } الجنة { نَجْعَلُهَا } نعطيها { لِلَّذِينَ لاَ يُرِيدُونَ عُلُوّاً } عتواً وتكبراً { فِي ٱلأَرْضِ } بالمال { وَلاَ فَسَاداً } بالنقش والتصاوير والمعاصي { وَٱلْعَاقِبَةُ } الجنة { لِلْمُتَّقِينَ } الكفر والشرك والعلو والفساد في الأرض { مَن جَآءَ بِٱلْحَسَنَةِ } بلا إله إلا الله مخلصاً بها { فَلَهُ خَيْرٌ مِّنْهَا } فله منها خير { وَمَن جَآءَ بِٱلسَّيِّئَةِ } بالشرك بالله { فَلاَ يُجْزَى ٱلَّذِينَ عَمِلُواْ ٱلسَّيِّئَاتِ } في الشرك بالله { إِلاَّ مَا كَانُواْ يَعْمَلُونَ } النار { إِنَّ ٱلَّذِي فَرَضَ عَلَيْكَ ٱلْقُرْآنَ } نزل عليك جبريل بالقرآن { لَرَآدُّكَ إِلَىٰ مَعَادٍ } إلى مكة ويقال الجنة { قُل } يا محمد { رَّبِّيۤ أَعْلَمُ مَن جَآءَ بِٱلْهُدَىٰ } بالتوحيد والقرآن { وَمَنْ هُوَ فِي ضَلاَلٍ مُّبِينٍ } في كفر بيِّن وخطأ بيِّن { وَمَا كُنتَ } يا محمد { تَرْجُوۤ أَن يُلْقَىٰ إِلَيْكَ ٱلْكِتَابُ } أن ينزل عليك جبريل بالقرآن وتكون نبياً { إِلاَّ رَحْمَةً مِّن رَّبِّكَ } ولكن منة وكرامة من ربك إذ أرسل عليك جبريل بالقرآن وجعلك نبياً { فَلاَ تَكُونَنَّ ظَهيراً } عوناً { لِّلْكَافِرِينَ } بالكفر { وَلاَ يَصُدُّنَّكَ } لا يصرفنك { عَنْ آيَاتِ ٱللَّهِ } القرآن { بَعْدَ إِذْ أُنزِلَتْ إِلَيْكَ } جبريل بها { وَٱدْعُ إِلَىٰ رَبِّكَ } إلى توحيد ربك وكتاب ربك { وَلاَ تَكُونَنَّ مِنَ ٱلْمُشْرِكِينَ } مع المشركين على دينهم منهم { وَلاَ تَدْعُ مَعَ ٱللَّهِ إِلَـٰهاً آخَرَ } لا تعبد من دون الله أحداً ولا تدع الخلق إلى أحد دون الله { لاَ إِلَـٰهَ إِلاَّ هُوَ } وحده لا شريك له { كُلُّ شَيْءٍ } كل عمل لغير وجه الله { هَالِكٌ } مردود { إِلاَّ وَجْهَهُ } إلا ما ابتغى به وجهه ويقال كل وجه متغير إلا وجهه وكل ملك زائل إلا ملكه { لَهُ ٱلْحُكْمُ } القضاء بين خلقه { وَإِلَيْهِ تُرْجَعُونَ } بعد الموت فيجازيكم بأعمالكم.
