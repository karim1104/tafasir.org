{ وَلَقَدْ أَرْسَلْنَآ إِلَىٰ ثَمُودَ أَخَاهُمْ } نبيهم { صَالِحاً أَنِ ٱعْبُدُواْ ٱللَّهَ } أن قل لهم وحدوا الله وتوبوا إليه من الكفر والشرك { فَإِذَا هُمْ فَرِيقَانِ } فصاروا فرقتين مؤمنة وكافرة { يَخْتَصِمُونَ } يتخاصمون في الدين { قَالَ } صالح للفرقة الكافرة { يَٰقَوْمِ لِمَ تَسْتَعْجِلُونَ بِٱلسَّيِّئَةِ } بالعذاب { قَبْلَ ٱلْحَسَنَةِ } قبل العافية والرحمة { لَوْلاَ تَسْتَغْفِرُونَ ٱللَّهَ } هلا تتوبون من الشرك والكفر وتوحدون الله { لَعَلَّكُمْ تُرْحَمُونَ } لكي ترحموا فلا تعذبوا { قَالُواْ ٱطَّيَّرْنَا بِكَ } تشاءمنا بك { وَبِمَن مَّعَكَ } من قومك يعنون شدتنا من شؤمك وشؤم من آمن بك { قَالَ } صالح { طَائِرُكُمْ } شدتكم ورخاؤكم { عِندَ ٱللَّهِ } من عند الله { بَلْ أَنتُمْ قَوْمٌ تُفْتَنُونَ } تختبرون بالشدة والرخاء ويقال تخذلون ولا توفقون { وَكَانَ فِي ٱلْمَدِينَةِ تِسْعَةُ رَهْطٍ } نفر من الفساق من أبناء رؤسائهم قدار بن سالف ومصدع بن دهو وأصحابهما { يُفْسِدُونَ فِي ٱلأَرْضِ } بالمعاصي { وَلاَ يُصْلِحُونَ } لا يأمرون بالصلاح ولا يعملون به { قَالُواْ تَقَاسَمُواْ بِٱللَّهِ } يقول توافقوا وتخالفوا بالله ثم قال { لَنُبَيِّتَنَّهُ وَأَهْلَهُ } لندخلن عليه وعلى أهله ليلاً ولنقتلنه وأهله { ثُمَّ لَنَقُولَنَّ لِوَلِيِّهِ } لورثته وقرابته { مَا شَهِدْنَا مَهْلِكَ أَهْلِهِ } قتل صالح وأهله { وَإِنَّا لَصَادِقُونَ } يصدقوننا في قولنا ولا يرد قولنا أحد { وَمَكَرُواْ مَكْراً } أرادوا قتل صالح ومن آمن معه { وَمَكَرْنَا مَكْراً } أردنا قتلهم { وَهُمْ لاَ يَشْعُرُونَ } بمكرنا ويقال قتلتهم الملائكة في دار صالح بالحجارة وهم لا يشعرون من الملائكة { فَٱنظُرْ } يا محمد { كَيْفَ كَانَ عَاقِبَةُ مَكْرِهِمْ } عقوبة مكرهم بصالح { أَنَّا دَمَّرْنَاهُمْ } أهلكناهم بالحجارة { وَقَوْمَهُمْ أَجْمَعِينَ } وأهلكنا قومهم أجمعين { فَتِلْكَ بُيُوتُهُمْ خَاوِيَةً } خالية ساقطة { بِمَا ظَلَمُوۤاْ } أشركوا { إِنَّ فِي ذٰلِكَ } فيما فعلنا بهم { لآيَةً } لعلامة وعبرة { لِّقَوْمٍ يَعْلَمُونَ } يصدقون ما فعل بهم { وَأَنجَيْنَا ٱلَّذِينَ آمَنُواْ } بصالح { وَكَانُواْ يَتَّقُونَ } الكفر والشرك والفواحش وقتل الناقة { وَلُوطاً } أرسلنا لوطاً إلى قومه { إِذْ قَالَ لِقَوْمِهِ أَتَأْتُونَ ٱلْفَاحِشَةَ } اللواط { وَأَنتُمْ تُبْصِرُونَ } تعلمون أنها فاحشة { أَإِنَّكُمْ لَتَأْتُونَ ٱلرِّجَالَ } أدبار الرجال { شَهْوَةً } اشتهاء لكم { مِّن دُونِ ٱلنِّسَآءِ } من فروج النساء { بَلْ أَنتُمْ قَوْمٌ تَجْهَلُونَ } أمر الله { فَمَا كَانَ جَوَابَ قَوْمِهِ } فلم يكن جواب قومه { إِلاَّ أَن قَالُوۤاْ أَخْرِجُوۤاْ آلَ لُوطٍ } لوطاً وابنتيه زعورا وريثا { مِّن قَرْيَتِكُمْ } سدوم { إِنَّهمْ أُنَاسٌ يَتَطَهَّرُونَ } يتنزهون عن أدبار الرجال.
