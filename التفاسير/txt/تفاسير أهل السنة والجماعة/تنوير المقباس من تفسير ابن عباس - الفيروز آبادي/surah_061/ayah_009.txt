{ هُوَ ٱلَّذِيۤ أَرْسَلَ رَسُولَهُ } محمداً صلى الله عليه وسلم { بِٱلْهُدَىٰ } بالتوحيد ويقال بالقرآن { وَدِينِ ٱلْحَقِّ } شهادة أن لا إله إلا الله { لِيُظْهِرَهُ عَلَى ٱلدِّينِ كُلِّهِ } على الأديان كلها فلا تقوم الساعة حتى لا يبقى أحد إلا دخل في الإسلام أو أدى إليهم الجزية { وَلَوْ كَرِهَ ٱلْمُشْرِكُونَ } وإن كره اليهود والنصارى ومشركو العرب أن يكون ذلك { يَٰأَيُّهَا ٱلَّذِينَ آمَنُواْ } وقد بينهم في أول السورة { هَلْ أَدُلُّكمْ عَلَىٰ تِجَارَةٍ تُنجِيكُم مِّنْ عَذَابٍ أَلِيمٍ } وجيع في الآخرة باللظى { تُؤْمِنُونَ بِٱللَّهِ وَرَسُولِهِ } تصدقون بإيمانكم بالله ورسوله إن فسرت على المنافقين { وَتُجَاهِدُونَ فِي سَبِيلِ ٱللَّهِ } في طاعة الله { بِأَمْوَالِكُمْ وَأَنفُسِكُمْ } بنفقة أموالكم وخروج أنفسكم { ذَٰلِكُمْ } الجهاد { خَيْرٌ لَّكُمْ } من الأموال { إِن كُنتُمْ تَعْلَمُونَ } تصدقون بثواب الله { يَغْفِرْ لَكُمْ ذُنُوبَكُمْ } بالجهاد والنفقة في سبيل الله { وَيُدْخِلْكُمْ جَنَّاتٍ } بساتين { تَجْرِي مِن تَحْتِهَا } من تحت شجرها ومساكنها { ٱلأَنْهَارُ } أنهار الخمر و الماء والعسل واللبن { وَمَسَاكِنَ طَيِّبَةً } حلالاً لكم ويقال طاهرة ويقال حسنة جميلة ويقال طيبة قد طيبها الله بالمسك والريحان { فِي جَنَّاتِ عَدْنٍ } في دار الرحمن { ذَٰلِكَ } الذي ذكرت { ٱلْفَوْزُ ٱلْعَظِيمُ } النجاة الوافرة فازوا بالجنة ونجوا من النار { وَأُخْرَىٰ } وتجارة أخرى { تُحِبُّونَهَا } تتمنون وتشتهون أن تكون لهم { نَصْرٌ مِّن ٱللَّهِ } بمحمد عليه الصلاة والسلام على كفار قريش { وَفَتْحٌ قَرِيبٌ } عاجل فتح مكة { وَبَشِّرِ ٱلْمُؤْمِنِينَ } المخلصين بالجنة إن كانوا كذلك { يَٰأَيُّهَا ٱلَّذِينَ آمَنُواْ } بمحمد صلى الله عليه وسلم والقرآن { كُونُوۤاْ أَنصَارَ ٱللَّهِ } لمحمد عليه الصلاة والسلام على عدوه ويقال أعوان الله على أعدائه { كَمَا قَالَ عِيسَى ٱبْنُ مَرْيَمَ لِلْحَوَارِيِّينَ } لأصفيائه { مَنْ أَنَّصَارِيۤ إِلَى ٱللَّهِ } من أعواني مع الله على أعدائه { قَالَ ٱلْحَوَارِيُّونَ } أصفياؤه { نَحْنُ أَنصَارُ ٱللَّهِ } أعوانك مع الله على أعدائه وكانوا اثني عشر رجلاً أول من آمنوا به ونصروه على أعدائه وكانوا قصارين { فَآمَنَت طَّآئِفَةٌ } جماعة { مِّن بَنِيۤ إِسْرَائِيلَ } بعيسى ابن مريم { وَكَفَرَت طَّآئِفَةٌ } جماعة بعيسى ابن مريم وهم الذين أضلهم بولس والذين لم يؤمنوا به { فَأَيَّدْنَا } أعنا وقوينا { ٱلَّذِينَ آمَنُواْ } بعيسى ابن مريم وهم الذين لم يخالفوا دين عيسى { عَلَىٰ عَدُوِّهِمْ } الذين خالفوا دين عيسى { فَأَصْبَحُواْ } فصاروا { ظَاهِرِينَ } غالبين بالحجة على أعدائهم لصلاتهم لله ويقال لأنهم ممن يسبح.
