{ والذين يُحَآجُّونَ فِى الله } يخاصمون في دينه { مِن بَعْدِ مَا استجيب لَهُ } من بعد ما استجاب له الناس ودخلوا في الإسلام ليردوهم إلى دين الجاهلية كقوله : { وَدَّ كَثِيرٌ مّنْ أَهْلِ الكتاب لَوْ يَرُدُّونَكُم مِن بَعْدِ إيمانكم كُفَّارًا } [ البقرة : 109 ] .   كان اليهود والنصارى يقولون للمؤمنين : كتابنا قبل كتابكم ونبينا قبل نبيكم فنحن خير منكم وأولى بالحق .   وقيل : من بعد ما استجيب لمحمد عليه السلام دعاؤه على المشركين يوم بدر { حُجَّتُهُمْ دَاحِضَةٌ } باطلة وسماها حجة وإن كانت شبهة لزعمهم أنها حجة { عِندَ رَبِّهِمْ وَعَلَيْهِمْ غَضَبٌ } بكفرهم { وَلَهُمْ عَذَابٌ شَدِيدٌ } في الآخرة .
