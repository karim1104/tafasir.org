{ وَأَنَّا لَمَّا سَمِعْنَا الهدى } القرآن { ءَامَنَّا بِهِ } بالقرآن أو بالله { فَمَن يُؤْمِن بِرَبِّهِ فَلاَ يَخَافُ } فهو لا يخاف مبتدأ وخبر { بَخْساً } نقصاً من ثوابه { وَلاَ رَهَقاً } أي ولا ترهقه ذلة من قوله : { وَتَرْهَقُهُمْ ذِلَّةٌ } [ يونس : 27 ] وقوله : { وَلاَ يَرْهَقُ وُجُوهَهُمْ قَتَرٌ وَلاَ ذِلَّةٌ } [ يونس : 26 ] .   وفيه دليل على أن العمل ليس من الإيمان
