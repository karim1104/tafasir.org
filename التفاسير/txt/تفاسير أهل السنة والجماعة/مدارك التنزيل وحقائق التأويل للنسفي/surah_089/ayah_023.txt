{ وَجِاْىءَ يَوْمَئِذٍ بِجَهَنَّمَ } قيل : إنها برزت لأهلها كقوله : { وَبُرّزَتِ الجحيم لِلْغَاوِينَ } [ الشعراء : 91 ] .   وقيل : هو مجرى على حقيقته ففي الحديث « يؤتى بجهنم يومئذ لها سبعون ألف زمام مع كل زمام سبعون ألف ملك يجرونها  » { يَوْمَئِذٍ يَتَذَكَّرُ الإنسان } أي يتعظ { وأنى لَهُ الذكرى } ومن أين له منفعة الذكرى ؟
