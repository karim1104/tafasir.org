{ وَلَقَدْ ءاتَيْنَا موسى الكتاب } التوراة { بَعْدِ مَا أَهْلَكْنَا القرون الأولى } قوم نوح وهود وصالح ولوط عليهم السلام { بَصَائِرَ لِلنَّاسِ } حال من { الكتاب } والبصيرة نور القلب الذي يبصر به الرشد والسعادة كما أن البصر نور العين الذي يبصر به الأجساد .   يريد آتيناه التوراة أنواراً للقلوب لأنها كانت عمياء لا تستبصر ولا تعرف حقاً من باطل { وهدى } وإرشاداً لأنهم كانوا يخبطون في ضلال { وَرَحْمَةً } لمن اتبعها لأنهم إذا عملوا بها وصلوا إلى نيل الرحمة { لَعَلَّهُمْ يَتَذَكَّرُونَ } يتعظون .
