{ والذى أَطْمَعُ } طمع العبيد في الموالي بالإفضال لا على الاستحقاق بالسؤال { أَن يَغْفِرَ لِى خَطِيئَتِى } قيل : هو قوله { إِنّى سَقِيمٌ } [ الصافات : 89 ] { بَلْ فَعَلَهُ كَبِيرُهُمْ } [ الأنبياء : 63 ] { هذا رَبّى } [ الأنعام : 67 ] للبازغ هي أختي لسارة ،   وما هي إلا معاريض جائزة وليست بخطايا يطلب لها الاستغفار ،   واستغفار الأنبياء تواضع منهم لربهم وهضم لأنفسهم وتعليم للأمم في طلب المغفرة ،   { يَوْمَ الدين } يوم الجزاء .
