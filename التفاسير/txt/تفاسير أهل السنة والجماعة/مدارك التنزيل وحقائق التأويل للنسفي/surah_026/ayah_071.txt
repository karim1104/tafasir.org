{ قَالُواْ نَعْبُدُ أَصْنَاماً } وجواب مَا تَعْبُدُونَ أَصْنَاماً ك .   { يَسْئَلُونَكَ مَاذَا يُنفِقُونَ قُلِ العفو } [ البقرة : 219 ] { مَاذَا قَالَ رَبُّكُمْ قَالُواْ الحق } [ سبأ : 23 ] لأنه سؤال عن المعبود لا عن العبادة .   وإنما زادوا { نعبد } في الجواب افتخاراً ومباهاة بعبادتها ولذا عطفوا على { نعبد } { فَنَظَلُّ لَهَا عاكفين } فنقيم على عبادتها طول النهار .   وإنما قالوا { فنظل } لأنهم كانوا يعبدونها بالنهار دون الليل أو معناه الدوام
