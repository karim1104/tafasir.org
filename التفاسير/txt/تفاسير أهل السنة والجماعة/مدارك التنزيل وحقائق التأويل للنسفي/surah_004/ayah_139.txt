{ الذين } نصب على الذم أو رفع بمعنى أريد الذين أو هم الذين { يَتَّخِذُونَ الكافرين أَوْلِيَاءَ مِن دُونِ المؤمنين أَيَبْتَغُونَ عِندَهُمُ العزة } كان المنافقون يوالون الكفرة يطلبون منهم المنعة والنصرة ويقولون : لا يتم أمر محمد عليه السلام { فَإِنَّ العزة للَّهِ جَمِيعاً } ولمن أعزه كالنبي عليه السلام والمؤمنين كما قال

{ وَلِلَّهِ العزة وَلِرَسُولِهِ وَلِلْمُؤْمِنِينَ } [ المنافقون : 8 ] .
