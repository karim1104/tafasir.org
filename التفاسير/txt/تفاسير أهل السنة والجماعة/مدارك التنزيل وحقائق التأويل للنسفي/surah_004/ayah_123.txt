{ لَّيْسَ بأمانيكم } ليس الأمر على شهواتكم وأمانيكم أيها المشركون أن تنفعكم الأصنام { وَلا أَمَانِيّ أَهْلِ الكتاب } ولا على شهوات اليهود والنصارى حيث قالوا : { نَحْنُ أَبْنَاء الله وَأَحِبَّاؤُهُ } [ المائدة : 18 ] .   { لَن تَمَسَّنَا النار إِلاَّ أَيَّامًا مَّعْدُودَةً } [ البقرة : 80 ] .   { مَن يَعْمَلْ سُوءاً يُجْزَ بِهِ } أي من المشركين وأهل الكتاب بدليل قوله { وَلاَ يَجِدْ لَهُ مِن دُونِ الله وَلِيّاً وَلاَ نَصِيراً } وهذا وعيد للكفار لأنه قال بعده
