ثم بين غناه وقدرته بقوله { وَللَّهِ مَا فِي السموات وَمَا فِي الأرض } خلقاً والمتملكون عبيده رقا .   { وَلَقَدْ وَصَّيْنَا الذين أُوتُواْ الكتاب } هو اسم للجنس فيتناول الكتب السماوية { مِن قَبْلِكُم } مّن الأمم السالفة وهو متعلق ب « وصينا »أو ب «أتوا » { وإياكم } عطف على «الذين أوتوا » { أَنِ اتقوا الله } بأن اتقوا أو تكون «أن » المفسرة لأن التوصية في معنى القول ،   والمعنى أن هذه وصية قديمة ما زال يوصي الله بها عباده ولستم بها مخصوصين لأنهم بالتقوى يسعدون عنده { وَإِن تَكْفُرُواْ } عطف على «اتقوا » لأن المعنى أمرناهم وأمرناكم بالتقوى وقلنا لهم ولكم إن تكفروا { فَإِنَّ للَّهِ مَا فِي السموات وَمَا فِي الأرض وَكَانَ الله غَنِيّاً } عن خلقه وعن عبادتهم { حَمِيداً } مستحقاً لأن يحمد لكثرة نعمه وإن لم يحَمده أحد .
