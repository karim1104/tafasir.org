{ وَدُّواْ لَوْ تَكْفُرُونَ كَمَا كَفَرُواْ } الكاف نعت لمصدر محذوف و «ما » مصدرية أي ودوا لو تكفرون كفراً مثل كفرهم { فَتَكُونُونَ } عطف على «تكفرون » «سَوَآء » أي مستوين أنتم وهم في الكفر { فَلاَ تَتَّخِذُواْ مِنْهُمْ أَوْلِيَاء حتى يُهَاجِرُواْ فِى سَبِيلِ الله } فلا توالوهم حتى يؤمنوا لأن الهجرة في سبيل الله بالإسلام { فَإِن تَوَلَّوْاْ } عن الإيمان { فَخُذُوهُمْ واقتلوهم حَيْثُ وَجَدتُّمُوهُمْ } كما كان حكم سائر المشركين { وَلاَ تَتَّخِذُواْ مِنْهُمْ وَلِيّاً وَلاَ نَصِيراً } وإن بذلوا لكم الولاية والنصرة فلا تقبلوا منهم
