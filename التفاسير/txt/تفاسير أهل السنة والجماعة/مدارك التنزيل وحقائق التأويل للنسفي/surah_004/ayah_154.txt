{ وَرَفَعْنَا فَوْقَهُمُ الطور بميثاقهم } بسبب ميثاقهم ليخافوا فلا ينقضوه { وَقُلْنَا لَهُمُ } والطور مطل عليهم { ادخلوا الباب سُجَّداً } أي ادخلوا باب إيلياء مطأطئين عند الدخول رؤوسكم { وَقُلْنَا لَهُمْ لاَ تَعْدُواْ } لا تجاوزوا الحد «تَعدّوُا » : ورش «تعدوا » بإسكان العين وتشديد الدال : مدني غير ورش وهما مدغماً «تعتدوا » وهي قراءة أبي إلا أنه أدغم التاء في الدال وأبقى العين ساكنة في رواية ،   وفي رواية نقل فتح التاء إلى العين { فِى السبت } بأخذ السمك { وَأَخَذْنَا مِنْهُمْ ميثاقا غَلِيظاً } عهداً مؤكداً .
