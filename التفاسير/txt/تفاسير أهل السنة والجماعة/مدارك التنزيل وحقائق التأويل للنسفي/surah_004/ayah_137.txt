{ إِنَّ الذين ءَامَنُواْ } بموسى عليه السلام { ثُمَّ كَفَرُواْ } حين عبدوا العجل { ثُمَّ ءَامَنُواْ } بموسى بعد عوده { ثُمَّ كَفَرُواْ } بعيسى عليه السلام { ثُمَّ ازدادوا كُفْراً } بكفرهم بمحمد صلى الله عليه وسلم { لَّمْ يَكُنْ الله لِيَغْفِرَ لَهُمْ وَلاَ لِيَهْدِيَهُمْ سَبِيلاً } إلى النجاة أو إلى الجنة ،   أو هم المنافقون آمنوا في الظاهر وكفروا في السر مرة بعد أخرى ،   وازدياد الكفر منهم ثباتهم عليه إلى الموت يؤيده قوله { بَشِّرِ المنافقين }
