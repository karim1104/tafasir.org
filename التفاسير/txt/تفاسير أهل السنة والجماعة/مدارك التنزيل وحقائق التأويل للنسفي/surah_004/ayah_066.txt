{ وَلَوْ أَنَّا كَتَبْنَا عَلَيْهِمْ } على المنافقين أي ولو وقع كتبنا عليهم { أَنِ اقتلوا } «أن » هي المفسرة { أَنفُسَكُمْ } أي تعرضوا للقتل بالجهاد .

أو ولو أوجبنا عليهم مثل ما أوجبنا على بني إسرائيل من قتلهم أنفسهم { أَوِ اخرجوا مِن دياركم } بالهجرة { مَّا فَعَلُوهُ } لنفاقهم .   والهاء ضمير أحد مصدري الفعلين وهو القتل أو الخروج أو ضمير المكتوب لدلالة كتبنا «عليه » { إِلاَّ قَلِيلٌ مّنْهُمْ } «قليلاً » : شامي على الاستثناء والرفع على البدل من واو «فعلوه » { وَلَوْ أَنَّهُمْ فَعَلُواْ مَا يُوعَظُونَ بِهِ } من اتباع رسول الله عليه السلام والانقياد لحكمه { لَكَانَ خَيْراً لَّهُمْ } في الدارين { وَأَشَدَّ تَثْبِيتاً } لإيمانهم وأبعد عن الاضطراب فيه
