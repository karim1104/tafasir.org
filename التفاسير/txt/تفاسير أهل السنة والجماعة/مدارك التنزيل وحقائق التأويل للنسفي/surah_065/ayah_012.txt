{ الله الذى خَلَقَ } مبتدأ وخبر { سَبْعَ سماوات } أجمع المفسرون على أن السماوات سبع { وَمِنَ الأرض مِثْلَهُنَّ } بالنصب عطفاً على { سَبْعَ سموات } قيل : ما في القرآن آية تدل على أن الأرضين سبع إلا هذه الآية ،   وبين كل سماءين مسيرة خمسمائة عام وغلظ كل سماء كذلك ،   والأرضون مثل السماوات .

 وقيل : الأرض واحدة إلا أن الأقاليم سبعة { يَتَنَزَّلُ الأمر بَيْنَهُنَّ } أي يجري أمر الله وحكمه بينهن وملكه ينفذ فيهن { لّتَعْلَمُواْ أَنَّ الله على كُلّ شَىْء قَدِيرٌ } اللام يتعلق ب { خُلِقَ } { وَأَنَّ الله قَدْ أَحَاطَ بِكُلّ شَىْء عِلْمَا } هو تمييز أو مصدر من غير لفظ الأول أي قد علم كل شيء علماً وهو علام الغيوب .
