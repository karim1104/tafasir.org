الكاف في { كَمَا أَرْسَلْنَا فِيكُمْ } إما أن يتعلق بما قبله أي ولأتم نعمتي عليكم في الآخرة بالثواب كما أتممتها عليكم في الدنيا بإرسال الرسول ،   أو بما بعده أي كما ذكرتكم بإرسال الرسول فاذكروني بالطاعة أذكركم بالثواب ،   فعلى هذا يوقف على «تهتدون » وعلى الأول لا .   { رَسُولاً مِّنْكُمْ } من العرب { يَتْلُواْ عَلَيْكُمْ } يقرأ عليكم { ءاياتنا } القرآن { وَيُزَكِيكُمْ وَيُعَلِّمُكُمُ الكتاب } القرآن { والحكمة } السنة والفقه { وَيُعَلِّمُكُم مَّا لَمْ تَكُونُواْ تَعْلَمُونَ } ما لا سبيل إلى معرفته إلا بالوحي .
