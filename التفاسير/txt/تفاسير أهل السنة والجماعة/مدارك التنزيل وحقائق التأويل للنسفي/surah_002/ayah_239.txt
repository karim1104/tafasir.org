{ فَإِنْ خِفْتُمْ } فإن كان بكم خوف من عدو أو غيره { فَرِجَالاً } حال أي فصلوا راجلين وهو جمع راجل كقائم وقيام { أَوْ رُكْبَانًا } وحداناً بإيماء ويسقط عنه التوجه إلى القبلة { فَإِذَا أَمِنتُمْ } فإذا زال خوفكم { فاذكروا الله } فصلوا صلاة الأمن { كَمَا عَلَّمَكُم } أي ذكراً مثل ما علمكم { مَّا لَمْ تَكُونُواْ تَعْلَمُونَ } من صلاة الأمن .
