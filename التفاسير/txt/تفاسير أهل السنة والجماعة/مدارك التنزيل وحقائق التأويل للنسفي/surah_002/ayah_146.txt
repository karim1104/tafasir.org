{ الذين ءاتيناهم الكتاب } صفة للظالمين .   وهو مبتدأ والخبر { يَعْرِفُونَهُ } أي محمداً عليه السلام أو القرآن أو تحويل القبلة .   والأول أظهر لقوله { كَمَا يَعْرِفُونَ أَبْنَاءَهُمْ } قال عبد الله بن سلام : أنا أعلم به مني بابني فقال له عمر : ولم ؟ قال : لأني لست أشك في محمد أنه نبي فأما ولدي فلعل والدته خانت فقبل عمر رأسه .   { وَإِنَّ فَرِيقًا مِّنْهُمْ } أي الذين لم يسلموا { لَيَكْتُمُونَ الحق } حسداً وعناداً { وَهُمْ يَعْلَمُونَ } لأن الله تعالى بينه في كتابهم .
