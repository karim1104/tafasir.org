{ فَأَرْسَلْنَا فِيهِمْ } الإرسال يعدى ب «إلى » ولم يعد ب «في » هنا وفي قوله { كَذَلِكَ أَرْسَلْنَاكَ فِى أُمَّةٍ } [ الرعد : 30 ] { وَمَا أَرْسَلْنَا فِى قَرْيَةٍ } [ الأعراف : 94 ] ولكن الأمة والقرية جعلت موضعا للإرسال كقول رؤبة :

أرسلت فيها مصعباً ذا إقحام .   .   .   { رَسُولاً } هو هود { مِنْهُمْ } من قومهم { أَنِ اعبدوا الله مَا لَكُمْ مّنْ إله غَيْرُهُ أَفَلاَ تَتَّقُونَ } «أن » مفسرة ل { أرسلنا } أي قلنا لهم على لسان الرسول اعبدوا الله .
