{ مِّن وَرَآئِهِمْ } من قدامهم .   الوراء اسم للجهة التي يواريها الشخص من خلف أو قدام { جَهَنَّمُ وَلاَ يُغْنِي عَنْهُم مَّا كَسَبُواْ } من الأموال { شَيْئاً } من عذاب الله { وَلاَ مَا اتخذوا } «ما » فيهما مصدرية أو موصولة { مِن دُونِ الله } من الأوثان { أَوْلِيَآءَ وَلَهُمْ عَذَابٌ عَظِيمٌ } في جهنم .
