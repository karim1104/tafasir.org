{ وَإِذَا تتلى عَلَيْهِمْ ءاياتنا } أي القرآن يعني ما فيه من ذكر البعث { بينات مَّا كَانَ حُجَّتَهُمْ } وسمى قولهم حجة وإن لم يكن حجة ؛ لأنه في زعمهم حجة { إِلاَّ أَن قَالُواْ ائتوا بِآبَآءِنَا } أي أحيوهم .

ّ{  إِن كُنتُمْ صادقين } في دعوى البعث ،   و { حُجَّتَهُمْ } خبر «كان » واسمها { أَن قَالُواْ } والمعنى ما كان حجتهم إلا مقالتهم : { ائتوا بِئَابَائِنَا } وقرىء { حُجَّتَهُمْ } بالرفع على أنها اسم «كان » و { أَن قَالُواْ } الخبر .
