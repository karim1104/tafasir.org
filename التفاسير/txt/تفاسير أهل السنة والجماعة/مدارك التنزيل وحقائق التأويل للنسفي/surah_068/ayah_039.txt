{ أَمْ لَكُمْ أيمان عَلَيْنَا } عهود مؤكدة بالأيمان { بالغة } نعت { أيمان } ويتعلق { إلى يَوْمِ القيامة } ببالغة أي أنها تبلغ ذلك اليوم وتنتهي إليه وافرة لم تبطل منها يمين إلى أن يحصل المقسم عليه من التحكيم ،   أو بالمقدر في الظرف أي هي ثابتة لكم علينا إلى يوم القيامة لا تخرج من عهدتها إلا يومئذ إذا حكمناكم وأعطيناكم ما تحكمون { إِنَّ لَكُمْ لَمَا تَحْكُمُونَ } به لأنفسكم وهو جواب القسم لأن معنى { أَمْ لَكُمْ أيمان عَلَيْنَا } أم أقسمنا لكم بأيمان مغلظة متناهية في التوكيد .
