{ فَكَذَّبُوهُ } فيما حذرهم منه من نزول العذاب إن فعلوا { فَعَقَرُوهَا } أي الناقة أسند الفعل إليهم وإن كان العاقر واحداً لقوله : { فَنَادَوْاْ صاحبهم فتعاطى فَعَقَرَ } [ القمر : 29 ] .   لرضاهم به { فَدَمْدمَ عَلَيْهِمْ رَبُّهُمْ } أهلكهم هلاك استئصال { بِذَنبِهِمْ } بسبب ذنبهم وهو تكذيبهم الرسول وعقرهم الناقة { فَسَوَّاهَا } فسوى الدمدمة عليهم لم يفلت منها صغيرهم ولا كبيرهم
