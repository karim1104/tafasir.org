{ هَلُ أَتَاكَ } تفخيم للحديث وتنبيه على أنه ليس من علم رسول الله صلى الله عليه وسلم وإنما عرفه بالوحي وانتظامها بما قبلها باعتبار أنه قال { وَفِى الأرض ءايات } وقال في آخر هذه القصة { وَتَرَكْنَا فِيهَا ءايَةً } { حَدِيثُ ضَيْفِ إبراهيم } الضيف للواحد والجماعة كالصوم والزور لأنه في الأصل مصدر ضافه ،   وكانوا اثني عشر ملكاً .   وقيل : تسعة عاشرهم جبريل .   وجعلهم ضيفاً لأنهم كانوا في صورة الضيف حيث أضافهم إبراهيم أو لأنهم كانوا في حسبانه كذلك { المكرمين } عند الله لقوله { بَلْ عِبَادٌ مُّكْرَمُونَ } [ الأنبياء : 26 ] وقيل : لأنه خدمهم بنفسه وأخدمهم امرأته وعجل لهم القرى
