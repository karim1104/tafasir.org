{ وَيَوْمَ القيامة تَرَى الذين كَذَبُواْ عَلَى الله } وصفوه بما لا يجوز عليه من إضافة الشريك والولد إليه ،   ونفى الصفات عنه { وُجُوهُهُمْ } مبتدأ { مُّسْوَدَّةٌ } خبر والجملة في محل النصب على الحال إن كان ترى من رؤية البصر ،   وإن كان من رؤية القلب فمفعول ثانٍ { أَلَيْسَ فِى جَهَنَّمَ مَثْوًى } منزل { لِّلْمُتَكَبِّرِينَ } هو إشارة إلى قوله { واستكبرت }
