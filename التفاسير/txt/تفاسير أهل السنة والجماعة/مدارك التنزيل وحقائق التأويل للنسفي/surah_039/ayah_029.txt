{ ضَرَبَ الله مَثَلاً رَّجُلاً } بدل { فِيهِ شُرَكَآءُ متشاكسون } متنازعون ومختلفون { وَرَجُلاً سَلَماً } مصدر سلم والمعنى ذا سلامة { لِرَجُلٍ } أي ذا خلوص له من الشركة .   { سالماً } مكي وأبو عمرو أي خالصاً له { هَلْ يَسْتَوِيَانِ مَثَلاً } صفة وهو تمييز ،   والمعنى هل تستوي صفتاهما وحالاهما .   وإنما اقتصر في التمييز على الواحد لبيان الجنس وقريء { مثلين } .   { الحمد للَّهِ } الذي لا إله إلا هو { بَلْ أَكْثَرُهُمْ لاَ يَعْلَمُونَ } فيشركون به غيره .   مثل الكافر ومعبوديه بعبد اشترك فيه شركاء بينهم تنازع واختلاف ،   وكل واحد منهم يدعي أنه عبده فهم يتجاذبونه ويتعاورونه في مهن شتى وهو متحير لا يدري أيهم يرضي بخدمته ،   وعلى أيهم يعتمد في حاجاته ،   وممن يطلب رزقه ،   وممن يلتمس رفقه ،   فهمه شعاع وقلبه أوزاع ،   والمؤمن بعبد له سيد واحد فهّمه واحد وقلبه مجتمع
