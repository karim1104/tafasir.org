{ إِنَّا أَنزَلْنَا إِلَيْكَ الكتاب بالحق } هذا ليس بتكرار لأن الأول كالعنوان للكتاب والثاني لبيان ما في الكتاب { فاعبد الله مُخْلِصاً } حال { لَّهُ الدين } أي ممحضاً له الدين من الشرك والرياء بالتوحيد وتصفية السر ،   ف { الدين } منصوب ب { مُخْلِصاً } وقرىء { الدين } بالرفع وحق من رفعه أن يقرأ { مُخْلِصاً } .
