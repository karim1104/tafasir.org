{ والتى } أي واذكر التي { أَحْصَنَتْ فَرْجَهَا } حفظته من الحلال والحرام { فَنَفَخْنَا فِيهَا مِن رُّوحِنَا } أجرينا فيها روح المسيح أو أمرنا جبريل فنفخ في جيب درعها فأحدثنا بذلك النفخ عيسى في بطنها ،   وإضافة الروح إليه تعالى لتشريف عيسى عليه السلام { وجعلناها وابنها ءايَةً } مفعول ثان { للعالمين } وإنما لم يقل آيتين كما قال { وَجَعَلْنَا اليل والنهار ءايَتَيْنِ } [ الإسراء : 12 ] لأن حالهما بمجموعهما آية واحدة وهي ولادتها إياه من غير فحل ،   أو التقدير وجعلناها آية وابنها كذلك ف { آية } مفعول المعطوف عليه ويدل عليه قراءة من قرأ { آيتين } .
