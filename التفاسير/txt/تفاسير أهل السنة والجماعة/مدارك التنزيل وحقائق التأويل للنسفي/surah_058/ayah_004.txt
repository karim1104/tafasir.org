{ فَمَن لَّمْ يَجِدْ } الرقبة { فَصِيَامُ شَهْرَيْنِ } فعليه صيام شهرين { مُتَتَابِعَيْنِ مِن قَبْلِ أَن يَتَمَاسَّا فَمَن لَّمْ يَسْتَطِعْ } الصيام { فَإِطْعَامُ } فعليه إطعام { سِتّينَ مِسْكِيناً }  ،   لكل مسكين نصف صاع من بر أو صاع من غيره ،   ويجب أن يقدمه على المسيس ولكن لا يستأنف إن جامع في خلال الإطعام { ذلك } البيان والتعليم للأحكام { لّتُؤْمِنُواْ } لتصدقوا { بالله وَرَسُولِهِ } في العمل بشرائعه التي شرعها من الظهار وغيره ورفض ما كنتم عليه في جاهليتكم { وَتِلْكَ } أي الأحكام التي وصفنا في الظهار والكفارة { حُدُودَ الله } التي لا يجوز تعديها { وللكافرين } الذين لا يتبعونها { عَذَابٌ أَلِيمٌ } مؤلم  .
