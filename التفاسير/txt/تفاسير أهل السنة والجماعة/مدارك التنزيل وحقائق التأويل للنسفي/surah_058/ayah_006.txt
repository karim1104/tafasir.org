{ يَوْمَ يَبْعَثُهُمُ } منصوب ب { مُّهِينٌ } أو بإضمار «اذكر » تعظيماً لليوم { الله جَمِيعًا } كلهم لا يترك منهم أحداً غير مبعوث أو مجتمعين في حال واحدة { فَيُنَبّئُهُمْ بِمَا عَمِلُواْ } تخجيلاً لهم وتوبيخاً وتشهيراً بحالهم يتمنون عنده المسارعة بهم إلى النار لما يلحقهم من الخزي على رؤوس الأشهاد { أحصاه الله } أحاط به عدداً لم يفته منه شيء { وَنَسُوهُ } لأنهم تهاونوا به حين ارتكبوه وإنما تحفظ معظمات الأمور { والله على كُلّ شَىْء شَهِيدٌ } لا يغيب عنه شيء .
