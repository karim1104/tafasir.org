{ وإبراهيم } أي وفي صحف إبراهيم { الذى وفى } أي وفر وأتم كقوله { فَأَتَمَّهُنَّ } [ البقرة : 124 ] وإطلاقه ليتناول كل وفاء وتوفية .   وقرىء مخففاً والتشديد مبالغة في الوفاء .   وعن الحسن : ما أمره الله بشيء إلا وفى به ،   وعن عطاء بن السائب : عهد أن لا يسأل مخلوقاً فلما قذف في النار قال له جبريل : ألك حاجة ؟ فقال أما إليك فلا .   وعن النبي صلى الله عليه وسلم : « وفي عمله كل يوم بأربع ركعات في صدر النهار وهي صلاة الضحى  »

ورُوي  "  ألا أخبركم لم سمى الله خليله الذي وفى ؟ كان يقول إذا أصبح وإذا أمسى : { فَسُبْحَانَ الله حِينَ تُمْسُونَ } إلى { حِينٍ تُظْهِرُونَ } [ الروم : 18 ]  "  وقيل : وفي سهام الإسلام وهي ثلاثون : عشرة في «التوبة » { التائبون } [ التوبة : 112 ] ،   وعشرة في «الأحزاب » { إِنَّ المسلمين } [ الآية : 35 ] وعشرة في «المؤمنين » { قَدْ أَفْلَحَ المؤمنون } [ المؤمنون : 1 ]
