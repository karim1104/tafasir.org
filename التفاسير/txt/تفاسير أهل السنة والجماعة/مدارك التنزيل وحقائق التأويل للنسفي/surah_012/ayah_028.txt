{ فَلَماَّ رَأَى } قطفير { قَمِيصُهُ قُدَّ مِن دُبُرٍ } وعلم براءة يوسف وصدقه وكذبها

{ قَالَ إِنَّهُ } إن قولك { ما جزاء من أراد بأهلك سوءاً } أو إن هذا الأمر وهو الاحتيال لنيل الرجال { مِن كَيْدِكُنَّ } الخطاب لها ولأمتها { إِنَّ كَيْدَكُنَّ عَظِيمٌ } لأنهن ألطف كيداً وأعظم حيلة وبذلك يغلبن الرجال ،   والقصريات منهن معهن ما ليس مع غيرهن من البوائق .   وعن بعض العلماء : إني أخاف من النساء أكثر مما أخاف من الشيطان ،   لأن الله تعالى قال : { إِنَّ كَيْدَ الشيطان ضَعِيفاً } [ النساء : 76 ] وقال لهن { إِنَّ كَيْدَكُنَّ عَظِيمٌ }
