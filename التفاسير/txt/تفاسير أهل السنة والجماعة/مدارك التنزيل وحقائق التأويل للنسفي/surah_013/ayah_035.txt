{ مَّثَلُ الجنة التى وُعِدَ المتقون } صفتها التي هي في غرابة المثل وارتفاعه بالابتداء والخبر محذوف أي فيما يتلى عليكم مثل الجنة أو الخبر { تَجْرِى مِن تَحْتِهَا الأنهار } كما تقول صفة زيد أسمر { أُكُلُهَا دَائِمٌ } ثمرها دائم الوجود لا ينقطع { وِظِلُّهَا } دائم لا ينسخ كما ينسخ في الدنيا بالشمس { تِلْكَ عقبى الذين اتقوا } أي الجنة الموصوفة عقبى تقواهم يعني منتهى أمرهم { وَّعُقْبَى الكافرين النار }
