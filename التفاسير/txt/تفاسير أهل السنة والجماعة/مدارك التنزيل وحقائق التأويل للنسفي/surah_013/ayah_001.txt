بسم الله الرحمن الرحيم

{ المر } أنا الله أعلم وأرى عن ابن عباس رضي الله عنهما { تِلْكَ } إشارة إلى آيات السورة { آياتالكتاب } أريد بالكتاب السورة أي تلك الآيات آيات السورة الكاملة العجيبة في بابها { والذي أُنزِلَ إِلَيْكَ مِن رَّبِّكَ } أي القرآن كله { الحق } خبر { والذي } { ولكن أَكْثَرَ الناس لاَ يُؤْمِنُونَ } فيقولون تقوَّله محمد
