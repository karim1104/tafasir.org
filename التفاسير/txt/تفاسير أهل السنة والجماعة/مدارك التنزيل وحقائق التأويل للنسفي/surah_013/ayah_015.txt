{ وَللَّهِ يَسْجُدُ مَن فِي السماوات والأرض } سجود تعبد وانقياد { طَوْعاً } حال يعني الملائكة والمؤمنين { وَكَرْهًا } يعني المنافقين والكافرين في حال الشدة والضيق { وظلالهم } معطوف على { من } جمع ظل { بالغدو } جمع غداة كقنىً وقناة { والآصال } جمع أصل أصيل .   قيل ظل كل شيء يسجد لله بالغدو والآصال ،   وظل الكافر يسجد كرهاً وهو كاره ،   وظل المؤمن يسجد طوعاً وهو طائع
