{ لِيُوَفّيَهُمْ } متعلق ب { لَّن تَبُورَ } أي ليوفيهم بنفاقها عنده { أُجُورَهُمْ } ثواب أعمالهم { وَيَزِيدَهُم مّن فَضْلِهِ } بتفسيح القبور أو بتشفيعهم فيمن أحسن إليهم أو بتضعيف حسناتهم أو بتحقيق وعد لقائه .   أو { يَرْجُونَ } في موضع الحال أي راجين .   واللام في { لِيُوَفّيَهُمْ } تتعلق ب { يَتْلُونَ } وما بعده أي فعلوا جميع ذلك من التلاوة وإقامة الصلاة والإنفاق لهذا الغرض وخبر «إنّ » { إِنَّهُ غَفُورٌ } لفرطاتهم { شَكُورٍ } أي غفورٌ لهم شكور لأعمالهم أي يعطي الجزيل على العمل القليل
