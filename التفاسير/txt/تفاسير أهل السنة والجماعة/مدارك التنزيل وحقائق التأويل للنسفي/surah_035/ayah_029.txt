{ إِنَّ الذين يَتْلُونَ كتاب الله } يداومون على تلاوة القرآن { وَأَقَامُواْ الصلاة وَأَنفَقُواْ مِمَّا رَزَقْنَاهُمْ سِرّاً وَعَلاَنِيَةً } أي مسرين النفل ومعلنين الفرض يعني لا يقتنعون بتلاوته عن حلاوة العمل به { يَرْجُونَ } خبر «إنّ » { تجارةً } هي طلب الثواب بالطاعة { لَّن تَبُورَ } لن تكسد يعني تجارة ينتفى عنها الكساد وتنفق عند الله
