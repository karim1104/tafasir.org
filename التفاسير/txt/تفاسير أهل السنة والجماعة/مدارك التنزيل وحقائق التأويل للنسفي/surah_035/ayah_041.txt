{ إِنَّ الله يُمْسِكُ السماوات والأرض أَن تَزُولاَ } يمنعهما من أن تزولا لأن الإمساك منع { وَلَئِن زَالَتَآ } على سبيل الفرض { إِنْ أَمْسَكَهُمَا } ما أمسكهما { مِنْ أَحَدٍ مِّن بَعْدِهِ } من بعد إمساكه .   و«من » الأولى مزيدة لتأكيد النفي والثانية للابتداء { إِنَّهُ كَانَ حَلِيمًا غَفُورًا } غير معاجل بالعقوبة حيث يمسكهما وكانتا جديرتين بأن تهدَّا هدًّا لعظم كلمة الشرك كما قال { تَكَادُ السماوات يَتَفَطَّرْنَ مِنْهُ وَتَنشَقُّ الأرض } [ مريم : 90 ] الآية .
