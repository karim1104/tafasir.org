{ وَلَهُ } ولله { الجوار } السفن جمع جارية .   قال الزجاج : الوقف عليها بالياء والاختيار وصلها ،   وإن وقف عليها واقف بغير ياء فذا جائز على بعد ولكن يروم الكسر في الراء ليدل على حذف الياء { المنشآت } المرفوعات الشرع { المنشآت } بكسر الشين ،   حمزة ويحيى الرافعات الشرع أو اللاتي ينشئن الأمواج بجريهن { فِى البحر كالأعلام } جمع علم وهو الجبل الطويل
