{ خَلَقَ الإنسان مِن صلصال } طين يابس له صلصلة { كالفخار } أي الطين المطبوخ بالنار وهو الخذف .   ولا اختلاف في هذا وفي قوله { مّنْ حَمَإٍ مَّسْنُونٍ } [ الحجر : 26 ] { مّن طِينٍ لاَّزِبٍ } [ الصافات : 11 ] { مّن تُرَابٍ } [ غافر : 67 ] لاتفاقها معنى لأنه يفيد أنه خلقه من تراب ثم جعله طيناً ثم حمأ مسنوناً ثم صلصالاً
