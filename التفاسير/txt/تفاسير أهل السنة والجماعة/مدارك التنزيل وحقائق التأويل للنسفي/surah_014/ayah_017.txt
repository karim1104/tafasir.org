{ يَتَجَرَّعُهُ } يشربه جرعة جرعة { وَلاَ يَكَادُ يُسِيغُهُ } ولا يقارب أن يسيغه فكيف تكون الإساغة كقوله : { لم يكد يراها } [ النور : 40 ] أي لم يقرب من رؤيتها فكيف يراها { وَيَأْتِيهِ الموت مِن كُلِّ مَكَانٍ } أي أسباب الموت من كل جهة أو من كل مكان من جسده وهذا تفظيع لما يصيبه من الآلام أي لو كان ثمة موت لكان كل واحد منها مهلكاً { وَمَا هُوَ بِمَيِّتٍ } لأنه لو مات لاستراح { وَمِن وَرَائِهِ } ومن بين يديه { عَذَابٌ غَلِيظٌ } أي في كل وقت يستقبله يتلقى عذاباً أشد مما قبله وأغلظ .   وعن الفضيل هو قطع الأنفاس وحبسها في الأجساد .
