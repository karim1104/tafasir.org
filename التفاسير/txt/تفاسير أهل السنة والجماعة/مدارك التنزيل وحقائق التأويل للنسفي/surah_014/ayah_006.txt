{ وَإِذْ قَالَ موسى لِقَوْمِهِ اذكروا نِعْمَةَ الله عَلَيْكُمْ إِذْ أَنجَاكُمْ مّنْ ءَالِ فِرْعَوْنَ يَسُومُونَكُمْ سُوء العذاب } «إذ » ظرف للنعمة بمعنى الإنعام أي إنعامه عليكم ذلك الوقت ،   أو بدل اشتمال من نعمة الله أي اذكروا وقت إنجائكم { وَيُذَبّحُونَ أَبْنَاءكُمْ } ذكر في البقرة { يذبحون } [ البقرة : 49 ] وفي الأعراف { يقتلون } [ الأعراف : 141 ] بلا واو ،   وهنا مع الواو .   والحاصل أن التذبيح حيث طرح الواو جعل تفسيراً للعذاب وبياناً له ،   وحيث أثبت الواو جعل التذبيح من حيث إنه زاد على جنس العذاب كأنه جنس آخر { وَيَسْتَحْيُونَ نِسَاءكُمْ وَفِى ذلكم بَلاء مِّن رَّبّكُمْ عَظِيمٌ } الإشارة إلى العذاب والبلاء المحنة أو إلى الإنجاء والبلاء النعمة .   { وَنَبْلُوكُم بالشر والخير فِتْنَةً {  } [ الأنبياء : 35 ]
