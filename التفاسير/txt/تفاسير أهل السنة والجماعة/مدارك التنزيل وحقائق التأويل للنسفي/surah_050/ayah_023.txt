{ وَقَالَ قَرِينُهُ } الجمهور على أنه الملك الكاتب الشهيد عليه { هذا } أي ديوان عمله ،   مجاهد : شيطانه الذي قيض له في قوله { نُقَيّضْ لَهُ شَيْطَاناً فَهُوَ لَهُ قَرِينٌ } [ الزخرف : 36 ] .   هذا أي الذي وكلت به { مَا لَدَىَّ عَتِيدٌ } { هذا } مبتدأ و { مَا } نكرة بمعنى شيء والظرف بعده وصف له وكذلك { عَتِيدٌ } و { مَا } وصفتها خبر { هذا } والتقدير هذا شيء ثابت لديّ عتيد .
