{ إِنَّا خَلَقْنَا الإنسان } أي ولد آدم ،   وقيل الأول ولد آدم أيضاً و { حِينٌ مِّنَ الدهر } على هذا مدة لبثه في بطن أمه إلى أن صار شيئاً مذكوراً بين الناس { مِن نُّطْفَةٍ أَمْشَاجٍ } نعت أو بدل منها أي من نطفة قد امتزج فيها الماآن .   ومشجه ومزجه بمعنى و { نُّطْفَةٍ أَمْشَاجٍ } كبرمة أعشار فهو لفظ مفرد غير جمع ولذا وقع صفة للمفرد { نَّبْتَلِيهِ } حال أي خلقناه مبتلين أي مريدين ابتلاءه بالأمر والنهي له { فجعلناه سَمِيعاً بَصِيراً } ذا سمع وبصر .
