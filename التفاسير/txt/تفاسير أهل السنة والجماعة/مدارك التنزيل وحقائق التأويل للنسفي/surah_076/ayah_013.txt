{ مُتَّكِئِينَ } حال من «هم » في { جزاهم } { فِيهَا } في الجنة { على الأرآئك } الأسرة جمع الأريكة { لاَ يَرَوْنَ } حال من الضمير المرفوع في { مُتَّكِئِينَ } غير رائين { فِيهَا } في الجنة { شَمْساً وَلاَ زَمْهَرِيراً } لأنه لا شمس فيها ولا زمهرير فظلها دائم وهواؤها معتدل ،   لا حر شمس يحمي ولا شدة برد تؤذي .   وفي الحديث :  "  هواء الجنة سجسج لا حر ولا قرّ  "  فالزمهرير البرد الشديد .   وقيل : القمر أي الجنة مضيئة لا يحتاج فيها إلى شمس وقمر
