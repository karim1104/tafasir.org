{ وَدَانِيَةً عَلَيْهِمْ ظلالها } قريبة منهم ظلال أشجارها عطفت على جنة أي وجنة أخرى دانية عليهم ظلالها كأنهم وعدوا بجنتين لأنهم وصفوا بالخوف بقوله : { إِنَّا نَخَافُ مِن رَّبّنَا } { وَلِمَنْ خَافَ مَقَامَ رَبّهِ جَنَّتَانِ } [ الرحمن : 46 ] { وَذُلِّلَتْ } سخرت للقائم والقاعد والمتكىء وهو حال من { دَانِيَةٌ } أي تدنو ظلالها عليهم في حال تذليل قطوفها عليهم ،   أو معطوفة عليها أي ودانية عليهم ظلالها ومذللة { قُطُوفُهَا } ثمارها جمع قطف .   { تَذْلِيلاً *
