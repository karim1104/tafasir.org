{ تِلْكَ } إشارة إلى قصة نوح عليه السلام ومحلها الرفع على الابتداء والجمل بعدها وهي { مِنْ أَنْبَاء الغيب نُوحِيهَا إِلَيْكَ مَا كُنتَ تَعْلَمُهَا أَنتَ وَلاَ قَوْمُكَ } أخبار أي تلك القصة بعض أنباء الغيب موحاة إليك مجهولة عندك وعند قومك { مّن قَبْلِ هذا } الوقت أو من قبل إيحائي إليك وإخبارك بها { فاصبر } على تبليغ الرسالة وأذى قومك كما صبر نوح ،   وتوقع في العاقبة لك ولمن كذبك نحو ما كان لنوح وقومه { إِنَّ العاقبة } في الفوز والنصر والغلبة { لّلْمُتَّقِينَ } عن الشرك .
