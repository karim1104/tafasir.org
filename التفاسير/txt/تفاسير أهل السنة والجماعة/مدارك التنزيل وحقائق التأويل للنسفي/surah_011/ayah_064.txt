{ ياقوم هذه نَاقَةُ الله لَكُمْ ءايَةً } نصب على الحال قد عمل فيها ما دل عليه اسم الإشارة من معنى الفعل و { لكم } متعلق { بآية } حالاً منها متقدمة ،   لأنها لو تأخرت لكانت صفة لها فلما تقدمت انتصبت على الحال { فَذَرُوهَا تَأْكُلْ فِى أَرْضِ الله } أي ليس عليكم رزقها مع أن لكم نفعها { وَلاَ تَمَسُّوهَا بِسُوء } عقر أو نحر { فَيَأْخُذَكُمْ عَذَابٌ قَرِيبٌ } عاجل
