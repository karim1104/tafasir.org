{ كَأَن لَّمْ يَغْنَوْاْ فِيهَا } كأن لم يقيموا في ديارهم أحياء متصرفين مترددين { أَلاَ بُعْدًا لّمَدْيَنَ } البعد بمعنى البعد وهو الهلاك كالرشد بمعنى الرشد ألا ترى إلى قوله : { كَمَا بَعِدَتْ ثَمُودُ } وَقرىء { كما بعُدت } والمعنى في البناءين واحد وهو نقيض القرب إلا أنهم فرقوا بين البعد من جهة الهلاك وبين غيره ،   فغيروا البناء كما فرقوا بين ضماني الخير والشر فقالوا : وعد وأوعد .
