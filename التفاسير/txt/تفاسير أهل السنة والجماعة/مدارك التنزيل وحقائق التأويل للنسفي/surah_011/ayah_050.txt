{ وإلى عَادٍ أَخَاهُمْ } واحداً منهم ،   وانتصابه للعطف على { أرسلنا نوحاً } أي وأرسلنا إلى عاد أخاهم { هُودًا } عطف بيان { قَالَ يَا قََوْم اعبدوا الله } وحدوه { مَا لَكُم مّنْ إله غَيْرُهُ } بالرفع : نافع صفة على محل الجار والمجرور ،   وبالجر : عليّ على اللفظ { إِنْ أَنتُمْ إِلاَّ مُفْتَرُونَ } تفترون على الله الكذب باتخاذكم الأوثان له شركاء
