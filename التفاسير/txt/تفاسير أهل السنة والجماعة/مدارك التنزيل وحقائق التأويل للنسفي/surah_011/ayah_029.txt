{ وياقوم لاَّ أَسْئَلُكُمْ عَلَيْهِ } على تبليغ الرسالة لأنه مدلول قوله { إني لكم نذير } { مَالاً } أجراً يثقل عليكم إن أديتم أو عليّ أن أبيتم { إِنْ أَجْرِىَ } مدني وشامي وأبو عمرو وحفص { إلا على الله وما أنا بطارد الذين آمنو } جواب لهم حين سألوا طردهم ليؤمنوا به أنفة من المجالسة معهم { أَنَّهُم ملاقوا رَبّهِمْ } فيشكونني إليه إن طردتهم { ولكنى أَرَاكُمْ قَوْمًا تَجْهَلُونَ } تتسافهون على المؤمنين وتدعونهم أراذل ،   أو تجهلون لقاء ربكم أو أنهم خير منكم
