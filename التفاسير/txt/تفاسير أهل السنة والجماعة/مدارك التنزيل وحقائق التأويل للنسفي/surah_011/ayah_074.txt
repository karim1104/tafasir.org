{ فَلَمَّا ذَهَبَ عَنْ إبراهيم الروع } الفزع وهو ما أوجس من الخيفة حين نكر أضيافه { وَجَاءتْهُ البشرى } بالولد { يجادلنا فِى قَوْمِ لُوطٍ } أي لما اطمأن قلبه بعد الخوف وملىء سروراً بسبب البشرى فرغ للمجادلة .   وجواب { لما } محذوف تقديره أقبل يجادلنا ،   أو { يجادلنا } جواب { لما } وإنما جيء به مضارعاً لحكاية الحال ،   والمعنى يجادل رسلنا .   ومجادلته إياهم أنهم قالوا إنا مهلكو أهل هذه القرية فقال : أرأيتم لو كان فيها خمسون مؤمناً أتهلكونها ؟ قالوا : لا ،   قال : فأربعون ؟ قالوا : لا ،   قال : فثلاثون ؟ قالوا : لا حتى بلغ العشرة قالوا : لا قال : أرأيتم إن كان فيها رجل واحد مسلم أتهلكونها ؟ قالوا : لا فعند ذلك قال { إن فيها لوطاً قالوا نحن أعلم بمن فيها لننجينه وأهله } العنكبوت : 32 )
