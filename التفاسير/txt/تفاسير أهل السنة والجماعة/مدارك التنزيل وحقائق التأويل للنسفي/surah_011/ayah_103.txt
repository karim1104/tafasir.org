{ إِنَّ فِى ذَلِكَ } فيما قص الله من قصص الأمم الهالكة { لآيَةً } لعبرة { لّمَنْ خَافَ عَذَابَ الآخرة } أي اعتقد صحته ووجوده { ذلك } إشارة إلى يوم القيامة لأن عذاب الآخرة دل عليه { يَوْمٌ مَّجْمُوعٌ لَّهُ الناس } وهو مرفوع بمجموع كما يرفع فعله إذا قلت يجمع له الناس .   وإنما آثر اسم المفعول على فعله لما في اسم المفعول من دلالته على ثبات معنى الجمع لليوم .   وإنه أثبت أيضاً لإسناد الجمع إلى الناس وأنهم لا ينفكون منه يجمعون للحساب والثواب والعقاب { وذلك يَوْمٌ مَّشْهُودٌ } أي مشهود فيه فاتسع في الظرف بإجرائه مجرى المفعول به أي يشهد فيه الخلائق الموقف لا يغيب عنه أحد
