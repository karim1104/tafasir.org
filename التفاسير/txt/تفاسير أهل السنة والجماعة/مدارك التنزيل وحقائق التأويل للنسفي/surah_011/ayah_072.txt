{ قَالَتْ ياويلتا} الألف مبدلة من ياء الإضافة وقرأ الحسن يا ويلتي بالياء على الأصل { ءأَلِدُ وَأَنَاْ عَجُوزٌ } ابنة تسعين سنة { وهذا بَعْلِى شَيْخًا } ابن مائة وعشرين سنة ،   { هذا } مبتدأ و { بعلي } خبره و { شيخا } ً حال ،   والعامل معنى الإشارة التي دلت عليه ذا أو معنى التنبيه الذي دل عليه «هذا » { إِنَّ هذا لَشَىْء عَجِيبٌ } أن يولد ولد من هرمين وهو استبعاد من حيث العادة .
