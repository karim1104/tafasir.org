{ وَلَمَّا جَاء أَمْرُنَا نَجَّيْنَا شُعَيْبًا والذين ءامَنُواْ مَعَهُ بِرَحْمَةٍ مّنَّا وَأَخَذَتِ الذين ظَلَمُواْ الصَّيْحَةُ } صاح بهم جبريل صيحة فهلكوا .   وإنما ذكر في آخر قصة عاد ومدين { ولما جاء } وفي آخر قصة ثمود ولوط { فلما جاء } لأنهما وقعا بعد ذكر الموعد وذلك قوله : { إن موعدهم الصبح } { ذلك وعد غير مكذوب } فجيء بالفاء الذي هو للتسبيب كقولك«وعدته فلما جاء الميعاد كان كيت وكيت » .   وأما الأخريان فقد وقعتا مبتدأتين فكان حقهما أن تعطفا بحرف الجمع على ما قبلهما كما تعطف قصة على قصة { فَأَصْبَحُواْ فِى دِيَارِهِمْ جاثمين } الجاثم اللازم لمكانه لا يريم يعني أن جبريل صاح بهم صيحة فزهق روح كل واحد منهم بحيث هو بغتة
