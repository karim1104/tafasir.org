{ الر كِتَابٌ } أي هذا كتاب فهو خبر مبتدأ محذوف { أُحكمت ءاياته } صفة له أي نظمت نظماً رصيناً محكماً لا يقع فيه نقص ولا خلل كالبناء المحكم { ثُمَّ فُصّلَتْ } كما تفصل القلائد بالفرائد من دلائل التوحيد والأحكام والمواعظ والقصص أو جعلت فصولاً سورة سورة وآية وآية أو فرقت في التنزيل ولم تنزل جملة ،   أو فصل فيها ما يحتاج إليه العباد أي بين ولخص .   وليس معنى « ثم » التراخي في الوقت ولكن في الحال { مِن لَّدُنْ حَكِيمٍ خَبِيرٍ } صفة أخرى ل { كتاب } أو خبر بعد خبر أوصلة ل { أحكمت } و { فصلت } أي من عنده أحكامها وتفصيلها
