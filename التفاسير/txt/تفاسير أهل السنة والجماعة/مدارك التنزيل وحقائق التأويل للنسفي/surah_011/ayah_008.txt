{ وَلَئِن قُلْتَ إِنَّكُمْ مَّبْعُوثُونَ مِن بَعْدِ الموت لَيَقُولَنَّ الذين كَفَرُواْ إِنْ هذا إِلاَّ سِحْرٌ مُّبِينٌ } أشار بهذا إلى القرآن لأن القرآن هو الناطق بالبعث فإذا جعلوا سحراً فقد اندرج تحته إنكار ما فيه من البعث وغيره { ساحر } حمزة وعلي يريدون الرسول والساحر كاذب مبطل { وَلَئِنْ أَخَّرْنَا عَنْهُمُ العذاب } عذاب الآخرة أو عذاب يوم بدر { إلى أُمَّةٍ } إلى جماعة من الأوقات { مَّعْدُودَةً } معلومة أو قلائل والمعنى إلى حين معلوم { لَّيَقُولُنَّ مَا يَحْبِسُهُ } ما يمنعه من النزول استعجالاً له على وجه التكذيب والاستهزاء { أَلاَ يَوْمَ يَأْتِيهِمْ } العذاب { لَّيْسَ } العذاب { مَصْرُوفاً عَنْهُمْ } ويوم منصوب ب { مصروفاً } أي ليس العذاب مصروفاً عنهم يوم يأتيهم { وَحَاقَ بِهِم } وأحاط بهم { مَّا كَانُواْ بِهِ يَسْتَهْزِءونَ } العذاب الذي كانوا به يستعجلون وإنما وضع يستهزئون موضع يستعجلون لأن استعجالهم كان على وجه الاستهزاء .
