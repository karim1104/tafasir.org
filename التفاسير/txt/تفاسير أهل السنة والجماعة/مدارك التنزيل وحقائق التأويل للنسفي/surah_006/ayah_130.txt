{ يامعشر الجن والإنس أَلَمْ يَأْتِكُمْ رُسُلٌ مِّنْكُمْ } عن الضحاك : بعث إلى الجن رسلا منهم كما بعث إلى الإنس رسلاً منهم لأنهم بهم آنس وعليه ظاهر النص ،   وقال آخرون : الرسل من الإنس خاصة وإنما قيل { رُسُلٌ مّنكُمْ } لأنه لما جمع الثقلين في الخطاب صح ذلك وإن كان من أحدهما كقوله : { يَخْرُجُ مِنْهُمَا الُّلؤْلُؤُ وَالمَرْجَانُ } [ الرحمن : 22 ] أو رسلهم رسل نبينا كقوله { وَلَّوْاْ إلى قَوْمِهِم مُّنذِرِينَ } [ الأحقاف : 29 ] { يَقُصُّونَ عَلَيْكُمْ ءاياتي } يقرءون كتبي { وَيُنذِرُونَكُمْ لِقَاءَ يَوْمِكُمْ هذا } يعني يوم القيامة { قَالُواْ شَهِدْنَا عَلَى أَنْفُسِنَا } بوجوب الحجة علينا وتبليغ الرسل إلينا { وَغَرَّتْهُمُ الحياة الدنيا وَشَهِدُواْ عَلَى أَنفُسِهِمْ أَنَّهُمْ كَانُواْ كافرين } بالرسل .
