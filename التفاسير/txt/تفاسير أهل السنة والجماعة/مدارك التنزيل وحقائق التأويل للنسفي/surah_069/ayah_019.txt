{ فَأَمَّا } تفصيل للعرض { مَنْ أُوتِىَ كتابه بِيَمِينِهِ فَيَقُولُ } سروراً به لما يرى فيه من الخيرات خطاباً لجماعته { هَاؤُمُ } اسم للفعل أي خذوا { اقرؤا كتابيه } تقديره هاؤم كتابي اقرؤا كتابيه فحذف الأول لدلالة الثاني عليه ،   والعامل في { كتابيه } { اقرءوا } عند البصريين لأنهم يعملون الأقرب .   والهاء في { كتابيه } و { حِسَابِيَهْ } و { مَالِيَهْ } و { سلطانيه } للسكت ،   وحقها أن تثبت في الوقف وتسقط في الوصل ،   وقد استحب إيثار الوقف إيثاراً لثباتها لثبوتها في المصحف
