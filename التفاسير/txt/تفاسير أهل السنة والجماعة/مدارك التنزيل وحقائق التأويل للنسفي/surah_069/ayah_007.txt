{ سَخَّرَهَا } سلطها { عَلَيْهِمْ سَبْعَ لَيَالٍ وثمانية أَيَّامٍ } وكان ابتداء العذاب يوم الأربعاء آخر الشهر إلى الأربعاء الأخرى { حُسُوماً } أي متتابعة لا تنقطع جمع حاسم كشهود تمثيلاً لتتابعها بتتابع فعل الحاسم في إعادة الكي على الداء بعد أخرى حتى ينحسم ،   وجاز أن يكون مصدراً أي تحسم حسوماً بمعنى تستأصل استئصالاً { فَتَرَى } أيها المخاطب { القوم فِيهَا } في مهابها أو في الليالي والأيام { صرعى } حال جمع صريع { كَأَنَّهُمْ } حال أخرى { أَعْجَازُ } أصول { نَخْلٍ } جمع نخلة { خَاوِيَةٍ } ساقطة أو بالية
