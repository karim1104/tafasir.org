{ مَا قُلْتُ لَهُمْ إِلاَّ مَآ أَمَرْتَنِي بِهِ } أي ما أمرتهم إلا بما أمرتني به .   ثم فسر ما أمر به فقال : { أَنِ اعبدوا الله رَبّي وَرَبَّكُمْ } ف «أن » مفسرة بمعنى «أي » { وَكُنتُ عَلَيْهِمْ شَهِيداً } رقيباً { مَّا دُمْتُ فِيهِمْ } مدة كوني فيهم { فَلَمَّا تَوَفَّيْتَنِي كُنتَ أَنتَ الرَّقِيبَ عَلَيْهِمْ } الحفيظ { وَأَنتَ على كُلّ شَيْءٍ شَهِيدٌ } من قولي وفعلي وقولهم وفعلهم
