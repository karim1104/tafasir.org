{ فَتَرَى الذين فِي قُلُوبِهِم مَّرَضٌ } نفاق { يسارعون } حال أو مفعول ثانٍ لاحتمال أن يكون «فترى » من رؤية العين أو القلب { فِيهِمْ } في معاونتهم على المسلمين وموالاتهم { يَقُولُونَ } أي في أنفسهم لقوله على «ما أسروا » { نخشى أَن تُصِيبَنَا دَائِرَةٌ } أي حادثة تدور بالحال التي يكونون عليها { فَعَسَى الله أَن يَأْتِيَ بالفتح } لرسول الله صلى الله عليه وسلم على أعدائه وإظهار المسلمين { أَوْ أَمْرٍ مّنْ عِندِهِ } أي يؤمر النبي عليه السلام بإظهار إسرار المنافقين وقتلهم { فَيُصْبِحُواْ } أي المنافقون { على مَا أَسَرُّواْ فِي أَنفُسِهِمْ } من النفاق { نادمين } خبر «فيصبحوا »
