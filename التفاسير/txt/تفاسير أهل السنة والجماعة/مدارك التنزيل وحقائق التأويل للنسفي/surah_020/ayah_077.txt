{ وَلَقَدْ أَوْحَيْنَا إلى موسى أَنْ أَسْرِ بِعِبَادِى } لما أراد الله تعالى إهلاك فرعون وقومه أمر موسى أن يخرج بهم من مصر ليلاً ويأخذ بهم طريق البحر { فاضرب لَهُمْ طَرِيقاً فِى البحر } اجعل لهم من قولهم ضرب له في ماله سهماً { يَبَساً } أي يابساً وهو مصدر وصف به يقال : يبس يَبسا ويُبسا { لاَّ تَخَافُ } حال من الضمير في { فاضرب } أي اضرب لهم طريقاً غير خائف .   { لاَ تَخَفْ } حمزة على الجواب { دَرَكاً } هو اسم من الإدراك أي لا يدركك فرعون وجنوده ولا يلحقونك { وَلاَ تخشى } الغرق وعلى قراءة حمزة { وَلاَ تخشى } استئناف أي وأنت لا تخشى أو يكون الألف للإطلاق كما في { وَتَظُنُّونَ بالله الظنونا } [ الأحزاب : 10 ]
