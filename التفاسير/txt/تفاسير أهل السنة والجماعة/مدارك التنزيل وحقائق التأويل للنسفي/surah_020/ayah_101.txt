{ خالدين } حال من الضمير في { يَحْمِلُ } وإنما جمع على المعنى ووحد في { فَإِنَّهُ } حملاً على لفظ من { فِيهِ } في الوزر أي في جزاء الوزر وهو العذاب { وَسَاء لَهُمْ يَوْمَ القيامة حِمْلاً } ساء في حكم بئس وفيه مبهم يفسره { حِمْلاً } وهو تمييز واللام في { لَهُمْ } للبيان كما في { هَيْتَ لَكَ } [ يوسف : 23 ] والمخصوص بالذم محذوف لدلالة الوزر السابق عليه تقديره ساء الحمل حملاً وزرهم .
