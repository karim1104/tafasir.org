{ إِلاَّ امرأته } مستثنى من الضمير المجرور في { لمنجوهم } وليس باستثناء من الاستثناء ،   لأن الاستثناء من الاستثناء إنما يكون فيما اتحد الحكم فيه بأن يقول «أهلكناهم إلا آل لوط إلا امرأته » وهنا قد اختلف الحكمان لأن إلا آل لوط متعلق ب { أرسلنا } أو ب { مجرمين } و { إلا امرأته } متعلق ب { منجوهم } فكيف يكون استثناء من استثناء .   { لمنجوهم } بالتخفيف : حمزة وعلي { قَدَّرْنَآ } وبالتخفيف : أبو بكر { إِنَّهَا لَمِنَ الغابرين } الباقين في العذاب .   قيل : لو لم تكن اللام في خبرها لوجب فتح «إن » لأنه مع اسمه وخبره مفعول { قدرنا } ولكنه كقوله { وَلَقَدْ عَلِمَتِ الجنة إِنَّهُمْ لَمُحْضَرُونَ } { الصافات : 158 ) وإنما أسند الملائكة فعل التقدير إلى أنفسهم ولم يقولوا قدر الله لقربهم كما يقول خاصة الملك أمرنا بكذا والآمر هو الملك .
