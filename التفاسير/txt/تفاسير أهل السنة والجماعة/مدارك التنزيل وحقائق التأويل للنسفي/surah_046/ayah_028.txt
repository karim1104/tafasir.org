{ فَلَوْلا } فهلا { نَصَرَهُمُ الذين اتخذوا مِن دُونِ الله قُرْبَاناً ءَالِهَةً } القربان ما تقرب به إلى الله تعالى أي اتخذوهم شفعاء متقرباً بهم إلى الله تعالى حيث قالوا { هؤلاء شفعاؤنا عند الله } [ يونس : 18 ] وأحد مفعولي «اتخذ » الراجع إلى «الذين » محذوف أي اتخذوهم والثاني { ءالِهَةً } و { قُرْبَاناً } حال { بَلْ ضَلُّواْ عَنْهُمْ } غابوا عن نصرتهم { وَذَلِكَ إِفْكُهُمْ وَمَا كَانُواْ يَفْتَرُونَ } { وَذَلِكَ } إشارة إلى امتناع نصرة آلهتهم وضلالهم عنهم أي وذلك أثر إفكهم الذي هو اتخاذهم إياها آلهة وثمرة شركهم وافترائهم على الله الكذب .
