{ إِلاَّ الذين عاهدتم مّنَ المشركين } استثناء من قوله

{ فَسِيحُواْ فِى الأرض } والمعنى : براءة من الله ورسوله إلى الذين عاهدتم من المشركين فقولوا لهم سيحوا إلا الذين عاهدتم منهم { ثُمَّ لَمْ يَنقُصُوكُمْ شَيْئاً } من شروط العهد أي وفوا بالعهد ولم ينقضوه .   وقرىء { لَمْ ينقضوكم } أي عهدكم وهو أليق لكن المشهورة أبلغ لأنه في مقابلة التمام { وَلَمْ يظاهروا عَلَيْكُمْ أَحَداً } ولم يعاونوا عليكم عدواً { فَأَتِمُّواْ إِلَيْهِمْ عَهْدَهُمْ } فأدوه إليهم تاماً كاملاً { إلى مُدَّتِهِمْ } إلى تمام مدتهم ،   والاستثناء بمعنى الاستدراك كأنه قيل بعد أن أمروا في الناكثين : لكن الذين لم ينكثوا فأتموا إليهم عهدهم ولا تجروهم مجراهم ولا تجعلوا الوفي كالغادر { إِنَّ الله يُحِبُّ المتقين } يعني أن قضية التقوى ألا يسوّي بين الفريقين فاتقوا الله في ذلك .
