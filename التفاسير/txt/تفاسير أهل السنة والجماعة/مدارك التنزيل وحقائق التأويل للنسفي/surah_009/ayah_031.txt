{ اتخذوا } أي أهل الكتاب { أحبارهم } علماءهم { ورهبانهم } نساكهم { أَرْبَابًا } آلهة { مِّن دُونِ الله } حيث أطاعوهم في تحليل ما حرم الله وتحريم ما أحل الله كما يطاع الأرباب في أوامرهم ونواهيهم { والمسيح ابن مَرْيَمَ } عطف على { أحبارهم } أي اتخذوه رباً حيث جعلوه ابن الله { وَمَا أُمِرُواْ إِلاَّ لِيَعْبُدُواْ إلها واحدا } يجوز الوقف عليه لأن ما بعده يصلح ابتداء يصلح وصفاً لواحداً { لاَّ إله إِلاَّ هُوَ سبحانه عَمَّا يُشْرِكُونَ } تنزيه له عن الإشراك
