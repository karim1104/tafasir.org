{ الأعراب } أهل البدو { أَشَدُّ كُفْرًا وَنِفَاقًا } من أهل الحضر لجفائهم وقسوتهم وبعدهم عن العلم والعلماء { وَأَجْدَرُ أَلاَّ يَعْلَمُواْ } وأحق بأن لا يعلموا { حُدُودَ مَا أَنزَلَ الله على رَسُولِهِ } يعني حدود الدين وما أنزل الله من الشرائع والأحكام ومنه قوله عليه السلام : « إن الجفاء والقسوة في الفدادين  » يعني الأكرة لأنهم يفدون أي يصيحون في حروثهم والفديد الصياح { والله عَلِيمٌ } بأحوالهم { حَكِيمٌ } في إمهالهم
