{ فَإِن تَوَلَّوْاْ } فإن أعرضوا عن الإيمان بك وناصبوك { فَقُلْ حَسْبِيَ الله } فاستعن بالله وفوض إليه أمورك فهو كافيك معرتهم وناصرك عليهم { لا إله إِلاَّ هُوَ عَلَيْهِ تَوَكَّلْتُ } فوضت أمري إليه { وَهُوَ رَبُّ العرش } هوأعظم خلق الله ،   خلق مطافاً لأهل السماء وقبلة للدعاء { العظيم } بالجر وقرىء بالرفع على نعت الرب جل وعز .
