{ لاَ تَعْتَذِرُواْ } لا تشتغلوا باعتذاراتكم الكاذبة فإنها لا تنفعكم بعد ظهور سركم { قَدْ كَفَرْتُمْ } قد أظهرتم كفركم باستهزائكم { بَعْدَ إيمانكم } بعد إظهاركم الإيمان { إن نَّعْفُ عَن طَائِفَةٍ مّنْكُمْ } بتوبتهم وإخلاصهم الإيمان بعد النفاق { نُعَذِّبْ طَائِفَةً بِأَنَّهُمْ كَانُواْ مُجْرِمِينَ } مصرين على النفاق غير تائبين منه { أَن يُعفَ تُعَذّبَ طَائِفَةٌ } غير عاصم .
