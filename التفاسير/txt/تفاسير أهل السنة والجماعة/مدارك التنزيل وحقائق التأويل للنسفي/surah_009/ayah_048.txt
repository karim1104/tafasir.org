{ لَقَدِ ابتغوا الفتنة } بصد الناس أو بأن يفتكوا به عليه السلام ليلة العقبة ،   أو بالرجوع يوم أحد { مِن قَبْلُ } من قبل غزوة تبوك { وَقَلَّبُواْ لَكَ الأمور } ودبروا لك الحيل والمكايد ودوّروا الآراء في إبطال أمرك { حتى جَاءَ الحق } وهو تأييدك ونصرك { وَظَهَرَ أَمْرُ الله } وغلب دينه وعلا شرعه { وَهُمْ كارهون } أي على رغم منهم .
