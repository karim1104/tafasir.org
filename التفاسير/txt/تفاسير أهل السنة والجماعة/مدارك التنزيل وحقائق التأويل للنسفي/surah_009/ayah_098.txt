{ وَمِنَ الأعراب مَن يَتَّخِذُ مَا يُنفِقُ } أي يتصدق { مَغْرَمًا } غرامة وخسراناً لأنه لا ينفق إلا تقيّة من المسلمين ورياء لا لوجه الله وابتغاء المثوبة عنده { وَيَتَرَبَّصُ بِكُمُ الدوآئر } أي دوائر الزمان وتبدل الأحوال بدور الأيام لتذهب غلبتكم عليه فيتخلص من إعطاء الصدقة { عَلَيْهِمْ دَائِرَةُ السوء } أي عليهم تدور المصائب والحروب التي يتوقعون وقوعها في المسلمين .

{ السوء } مكي وأبو عمرو وهو العذاب ،   و { السوء } بالفتح ذم للدائرة كقولك «رجل سوء » في مقابلة قولك «رجل صدق » { والله سَمِيعٌ } لما يقولون إذا توجهت عليهم الصدقة { عَلِيمٌ } بما يضمرونه .
