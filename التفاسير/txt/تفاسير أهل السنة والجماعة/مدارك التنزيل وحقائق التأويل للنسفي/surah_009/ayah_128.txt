{ لَقَدْ جَاءَكُمْ رَسُولٌ } محمد عليه السلام { مّنْ أَنفُسِكُمْ } من جنسكم ومن نسبكم عربي قرشي مثلكم { عَزِيزٌ عَلَيْهِ مَا عَنِتُّمْ } شديد عليه شاق لكونه بعضاً منكم عنتكم ولقاؤكم المكروه ،   فهو يخاف عليكم الوقوع في العذاب { حَرِيصٌ عَلَيْكُمْ } على إيمانكم { بالمؤمنين } منكم ومن غيركم { رَءُوفٌ رَّحِيمٌ } قيل : لم يجمع الله اسمين من أسمائه لأحد غير رسول الله صلى الله عليه وسلم
