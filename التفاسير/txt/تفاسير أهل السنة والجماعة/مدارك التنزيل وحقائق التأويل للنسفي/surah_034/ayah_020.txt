{ وَلَقَدْ صَدَّقَ عَلَيْهِمْ إِبْلِيسُ ظَنَّهُ } بالتشديد : كوفي أي حقق عليهم ظنه أو وجده صادقاً ،   وبالتخفيف : غيرهم أي صدق في ظنه { فاتبعوه } الضمير في { عَلَيْهِمْ } و { اتبعوه } لأهل سبإ أو لبني آدم .   وقلل المؤمنين بقوله { إِلاَّ فَرِيقاً مّنَ المؤمنين } لقلتهم بالإضافة إلى الكفار { وَلاَ تَجِدُ أَكْثَرَهُمْ شاكرين } [ الأعراف : 17 ]
