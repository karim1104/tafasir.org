حتى إِذَا بَلَغَ بَيْنَ السَّدَّيْنِ } بين الجبلين وهما جبلان سد ذو القرنين ما بينهما .   { السَّدين } و { سًداً } مكي وأبو عمرو وحفص { السُّدين } و { سدا } حمزة وعلي ،   وبضمهما : غيرهم .   قيل : ما كان مسدوداً خلقة فهو مضموم ،   وما كان من عمل العباد فهو مفتوح .   وانتصب { بين } على أنه مفعول به ل { بلغ } كما انجر بالإضافة في { هذا فراق بيني وبينك } وكما ارتفع في { لقد تقطع بينكم } [ الأنعام : 94 ] لأنه من الظروف التي تستعمل أسماء وظروفاً وهذا المكان في منقطع أرض الترك مما يلي المشرق { وَجَدَ مِن دُونِهِمَا } من ورائهما { قَوْماً } هم الترك { لاَّ يَكَادُونَ يَفْقَهُونَ قَوْلاً } أي لا يكادون يفهمونه إلا بجهد ومشقة من إشارة ونحوها .   { يُفقهون } حمزة وعلي أن لا يفهمون السامع كلامهم ولا يبينونه لأن لغتهم غريبة مجهولة .
