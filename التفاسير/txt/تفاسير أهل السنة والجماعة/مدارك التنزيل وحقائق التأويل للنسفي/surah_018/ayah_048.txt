{ وَعُرِضُواْ على رَبّكَ صَفَّا } مصطفين ظاهرين ترى جماعتهم كما يرى كل واحد لا يحجب أحد أحداً ،   شبهت حالهم بحال الجند المعروضين على السلطان { لَّقَدْ جِئْتُمُونَا } أي قلنا لهم لقد جئتمونا ،   وهذا المضمر يجوز أن يكون عامل النصب في { يوم نسير } { كَمَا خلقناكم أَوَّلَ مَرَّةٍ } أي لقد بعثناكم كما أنشأناكم أول مرة ،   أو جئتمونا عراة لا شيء معكم كما خلقناكم أولاً .   وإنما قال : { وحشرناهم } ماضياً بعد { نسير } و { ترى } للدلالة على حشرهم قبل التسيير وقبل البروز ليعاينوا تلك الأهوال .   كأنه قيل : وحشرناهم قبل ذلك { بَلْ زَعَمْتُمْ أَلَّن نَّجْعَلَ لَكُمْ مَّوْعِدًا } وقتاً لإنجاز ما وعدتم على ألسنة الأنبياء من البعث والنشور أو مكان وعد للمحاسبة .
