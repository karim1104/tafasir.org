{ مَّا أَشْهَدتُّهُمْ } أي إبليس وذريته { خَلَقَ السماوات والأرض } يعني أنكم اتخذتموهم شركاء لي في العبادة وإنما يكونون شركاء فيها لو كانوا شركاء في الإلهية فنفى مشاركتهم الإلهية بقوله { ما أشهدتهم خلق السماوات والأرض } لأعتضد بهم في خلقها أو أشاورهم فيه أي تفردت بخلق الأشياء فأفردوني في العبادة { وَلاَ خَلْقَ أَنفُسِهِمْ } أي ولا أشهدت بعضهم خلق بعض كقوله : { ولا تقتلوا أنفسكم } [ النساء : 29 ] { وَمَا كُنتُ مُتَّخِذَ المضلين } أي وما كنت متخذهم { عَضُداً } أي أعواناً فوضع { المضلين } موضع الضمير ذمًّا لهم بالإضلال ،   فإذا لم يكونوا عضداً لي في الخلق فمالكم تتخذونهم شركاء لي في العبادة ؟
