والضمير في { أَنَّهُمْ } راجع إلى الأهل المقدر في { أيها } { إِن يَظْهَرُواْ عَلَيْكُمْ } يطلعوا عليكم { يَرْجُمُوكُمْ } يقتلوكم أخبث القتلة { أَوْ يُعِيدُوكُمْ فِى مِلَّتِهِمْ } بالإكراه ،   والعود بمعنى الصيرورة كثير في كلامهم { وَلَن تُفْلِحُواْ إِذًا أَبَدًا } { إذاً } يدل على الشرط أي ولن تفلحوا إن دخلتم في دينهم أبداً .
