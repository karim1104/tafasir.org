{ هَؤُلاء } مبتدأ { قَوْمُنَا } عطف بيان { اتخذوا مِن دُونِهِ ءالِهَةً } خبر وهو إخبار في معنى الإنكار { لَّوْلاَ يَأْتُونَ عَلَيْهِم } هلا يأتون على عبادتهم فحذف المضاف { بسلطان بَيّنٍ } بحجة ظاهرة وهو تبكيت لأن الإتيان بالسلطان على عبادة الأوثان محال { فَمَنْ أَظْلَمُ مِمَّنِ افترى عَلَى الله كَذِبًا } بنسبة الشريك إليه .
