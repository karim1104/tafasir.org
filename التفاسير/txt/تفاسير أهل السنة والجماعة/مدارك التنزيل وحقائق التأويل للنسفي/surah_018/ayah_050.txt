{ وَإِذْ قُلْنَا للملائكة اسجدوا لآِدَمَ } فسجود تحية أو سجود انقياد { فَسَجَدُواْ إِلاَّ إِبْلِيسَ كَانَ مِنَ الجن } وهو مستأنف كأن قائلاً قال : ما له لم يسجد ؟ فقيل : كان من الجن { فَفَسَقَ عَنْ أَمْرِ رَبّهِ } خرج عما أمره ربه به من السجود وهو دليل على أنه كان مأموراً بالسجود مع الملائكة { أَفَتَتَّخِذُونَهُ وَذُرّيَّتَهُ } الهمزة للإنكار والتعجب كأنه قيل : أعقيب ما وجد منه تتخذونه وذريته { أَوْلِيَاء مِن دُونِى } وتستبدلونهم بي ؟ ومن ذريته «لا قيس » موسوس الصلاة و«الأعور » صاحب الزنا و«بتر » صاحب المصائب ومطوس صاحب الأراجيف و«داسم » يدخل ويأكل مع من لم يسم الله تعالى { وَهُمْ لَكُمْ عَدُوٌّ } أعداء { بِئْسَ للظالمين بَدَلاً } بئس البدل من الله إبليس لمن استبدله فأطاعه بدل طاعة الله
