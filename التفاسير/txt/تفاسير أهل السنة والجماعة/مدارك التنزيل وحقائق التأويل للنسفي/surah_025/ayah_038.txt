{ وَعَاداً } دمرنا عاداً { وَثَمُودَ } حمزة وحفص على تأويل القبيلة وغيرهما ،   وثموداً على تأويل الحي أو لأنه اسم الأب الأكبر { وأصحاب الرس } هم قوم شعيب كانوا يعبدون الأصنام فكذبوا شعيباً فبيناهم حول الرس وهي البئر غير مطوية انهارت بهم فخسف بهم وبديارهم ،   وقيل : الرس قرية قتلوا نبيهم فهلكوا ،   أو هم أصحاب الأخدود والرس الأخدود { وَقُرُوناً } وأهلكنا أمماً { بَيْنَ ذلك } المذكور { كَثِيراً } لا يعلمها إلا الله أرسل إليهم فكذبوهم فأهلكوا { وَكُلاًّ ضَرَبْنَا لَهُ الأمثال } بينا له القصص العجيبة من قصص الأولين { وَكُلاًّ تَبَّرْنَا تَتْبِيراً } أي أهلكنا إهلاكاً ،
