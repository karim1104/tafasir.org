{ وَهُوَ الذى مَرَجَ البحرين } خلاّهما متجاورين متلاصقين .   تقول : مرجت الدابة إذا خليتها ترعى ،   وسمى الماءين الكثيرين الواسعين بحرين { هذا } أي أحدهما { عَذْبٌ فُرَاتٌ } صفة ل { عذب } أي شديد العذوبة حتى يقرب إلى الحلاوة { وهذا مِلْحٌ أُجَاجٌ } صفة ل { ملح } أي شديد الملوحة { وَجَعَلَ بَيْنَهُمَا بَرْزَخاً } حائلاً من قدرته يفصل بينهما ويمنعهما التمازج فهما في الظاهر مختلطان وفي الحقيقة منفصلان { وَحِجْراً مَّحْجُوراً } وستراً ممنوعاً عن الأعين كقوله { حجاباً مستورا } [ الإسراء : 45 ] }
