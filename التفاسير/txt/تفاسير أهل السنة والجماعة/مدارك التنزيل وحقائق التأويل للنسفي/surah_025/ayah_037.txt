{ وَقَوْمَ نُوحٍ } أي ودمرنا قوم نوح { لَّمَّا كَذَّبُواْ الرسل } يعني نوحاً وإدريس وشيثاً أو كان تكذيبهم لواحد منهم تكذيباً للجميع { أغرقناهم } بالطوفان { وجعلناهم } وجعلنا إغراقهم أو قصتهم { لِلنَّاسِ ءايَةً } عبرة يعتبرون بها { وَأَعْتَدْنَا } وهيأنا { للظالمين } لقوم نوح وأصله وأعتدنا لهم إلا أنه أراد تظليمهم فأظهر ،   أو هو عام لكل من ظلم ظلم شرك ويتناولهم بعمومه { عَذَاباً أَلِيماً } أي النار .
