{ قُلْ أذلك خَيْرٌ } أي المذكور من صفة النار خير { أَمْ جَنَّةُ الخلد التى وَعِدَ المتقون } أي وعدها فالراجع إلى الموصول محذوف ،   وإنما قال : { أذلك خير } ،   ولا خير في النار توبيخاً للكفار { كَانَتْ لَهُمْ جَزَاء } ثواباً { وَمَصِيراً } مرجعاً .   وإنما قيل { كانت } لأن ما وعد الله كأنه كان لتحققه أو كان ذلك مكتوباً في اللوح قبل أن خلقهم
