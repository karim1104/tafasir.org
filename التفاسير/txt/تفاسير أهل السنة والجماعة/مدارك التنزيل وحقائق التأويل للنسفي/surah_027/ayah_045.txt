{ وَلَقَدْ أَرْسَلْنَا إلى ثَمُودَ أَخَاهُمْ } في النسب { صالحا } بدل { أَنِ اعبدوا الله } بكسر النون في الوصل : عاصم وحمزة وبصري ،   وبضم النون : غيرهم اتباعاً للباء ،   والمعنى بأن اعبدوا الله وحدوه { فَإِذَا } للمفاجأة { هُمْ } مبتدأ { فَرِيقَانِ } خبر { يَخْتَصِمُونَ } صفة وهي العامل في { إِذَا } والمعنى فإذا قوم صالح فريقان مؤمن به وكافر به يختصمون فيقول كل فريق الحق معي وهو مبين في قوله : { قَالَ الملأ الذين استكبروا مِن قَوْمِهِ لِلَّذِينَ استضعفوا لِمَنْ ءامَنَ مِنْهُمْ أَتَعْلَمُونَ أَنَّ صالحا مُّرْسَلٌ مّن رَّبّهِ قَالُواْ إِنَّا بما أرسل به مؤمنون قال الذين استكبروا إنا بالذي أمنتم به كافرون } [ الأعراف : 75 ] وقال الفريق الكافر : { ياصاح ائتنا بِمَا تَعِدُنَا إِن كُنتَ مِنَ المرسلين } { [ الأعراف : 77 ]
