{ أَمَّن جَعَلَ الأرض } وما بعده بدل من { أمن خلق } فكان حكمها حكمه { قَرَاراً } دحاها وسواها للاستقرار عليها { وَجَعَلَ خِلاَلَهَا } ظرف أي وسطها وهو المفعول الثاني والأول { أَنْهَاراً } وبين البحرين مثله { وَجَعَلَ لَهَا } للأرض { رَوَاسِىَ } جبالاً تمنعها عن الحركة { وَجَعَلَ بَيْنَ البحرين } العذب والمالح { حَاجِزاً } مانعاً أن يختلطا { أءلاه مَّعَ الله بَلْ أَكْثَرُهُمْ لاَ يَعْلَمُونَ } التوحيد فلا يؤمنون
