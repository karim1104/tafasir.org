{ وَيَوْمَ } واذكر يوم { يُنفَخُ فِى الصور } وهو قرن أو جمع صورة والنافخ إسرافيل عليه السلام { فَفَزِعَ مَن فِى السماوات وَمَن فِى الأرض } اختير «فزع » على «يفزع » للإشعار بتحقق الفزع وثبوته وأنه كائن لا محالة ،   والمراد فزعهم عند النفخة الأولى حين يصعقون { إِلاَّ مَن شَاء الله } إلا من ثبت الله قلبه من الملائكة قالوا : هم جبريل وميكائيل وإسرافيل وملك الموت عليهم السلام لأنه صعق مرة ،   ومثله { وَنُفِخَ فِى الصور فَصَعِقَ مَن فِى السماوات وَمَن فِى الأرض إِلاَّ مَن شَاء الله } ) الزمر : 68 ) { وَكُلٌّ أَتَوْهُ } حمزة وحفص وخلف ،   { اتوه } غيرهم وأصله «آتيوه » { داخرين } حال أي صاغرين ومعنى الإتيان حضورهم الموقف ورجوعهم إلى أمره تعالى وانقيادهم له .
