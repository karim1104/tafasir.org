{ إِن رَبَّكَ يَقْضِى بَيْنَهُم } بين من آمن بالقرآن ومن كفر به { بِحُكْمِهِ } بعدله لأنه لا يقضي إلا بالعدل فسمى المحكوم به حكماً ،   أو بحكمته ويدل عليه قراءة من قرأ { بحكمه } جمع حكمة { وَهُوَ العزيز } فلا يرد قضاؤه { العليم } بمن يقضي له وبمن يقضي عليه أو العزيز في انتقامه من المبطلين العليم بالفصل بينهم وبين المحقين
