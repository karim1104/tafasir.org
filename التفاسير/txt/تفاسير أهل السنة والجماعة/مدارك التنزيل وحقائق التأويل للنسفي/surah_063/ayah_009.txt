ياأيها الذين ءامَنُواْ لاَ تُلْهِكُمْ } لا تشغلكم { أموالكم } والتصرف فيها والسعي في تدبير أمرها بالنماء وطلب النتاج { وَلاَ أولادكم } وسروركم بهم وشفقتكم عليهم والقيام بمؤنهم { عَن ذِكْرِ الله } أي عن الصلوات الخمس أو عن القرآن { وَمَن يَفْعَلْ ذلك } يريد الشغل بالدنيا عن الدين .   وقيل : من يشتغل بتثمير أمواله عن تدبير أحواله وبمرضاة أولاده عن إصلاح معاده { فَأُوْلَئِكَ هُمُ الخاسرون } في تجارتهم حيث باعوا الباقي بالفاني .
