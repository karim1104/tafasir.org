{ وَقَدْ أَضَلُّواْ } أي الأصنام كقوله { إِنَّهُنَّ أَضْلَلْنَ } [ ابراهيم : 36 ] { كَثِيراً } من الناس أو الرؤساء { وَلاَ تَزِدِ الظالمين } عطف على { رَّبّ إِنَّهُمْ عصونى } على حكاية كلام نوح عليه السلام بعد { قَالَ } وبعد الواو النائبة عنه ،   ومعناه قال رب إنهم عصوني وقال لا تزد الظالمين أي قال هذين القولين وهما في محل النصب لأنهما مفعولاً { قَالَ } { إِلاَّ ضَلاَلاً } هلاكاً كقوله { وَلاَ تَزِدِ الظالمين إِلاَّ تَبَاراً }
