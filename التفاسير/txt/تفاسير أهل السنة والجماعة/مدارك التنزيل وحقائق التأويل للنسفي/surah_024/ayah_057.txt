ثم ذكر الكافرين فقال { لاَ تَحْسَبَنَّ الذين كَفَرُواْ مُعْجِزِينَ فِى الأرض } أي فائتين الله بأن لا يقدر عليهم فيها ،   فالتاء خطاب للنبي عليه الصلاة والسلام وهو الفاعل والمفعولان { الذين كفروا } و { معجزين } وبالياء شامي وحمزة والفاعل النبي صلى الله عليه وسلم لتقدم ذكره والمفعولان { الذين كَفَرُواْ } و { معجزين } { وَمَأْوَاهُمُ النار } معطوف على { لاَ تَحْسَبَنَّ الذين كَفَرُواْ مُعْجِزِينَ } كَأَنَّهُ قِيلَ : الذين كَفَرُواْ لاَ يفوتون الله وَمَأْوَاهُمُ النار { وَلَبِئْسَ المصير } أي المرجع النار .
