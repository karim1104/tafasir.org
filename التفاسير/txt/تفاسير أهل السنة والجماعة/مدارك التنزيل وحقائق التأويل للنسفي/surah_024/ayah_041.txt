{ أَلَمْ تَرَ } ألم تعلم يا محمد علماً يقوم مقام العيان في الإيقان { أَنَّ الله يُسَبّحُ لَهُ مَن فِى السماوات والأرض والطير } عطف على { من } { صافات } حال من { الطير } أي يصففن أجنحتهن في الهواء { كُلٌّ قَدْ عَلِمَ صَلاَتَهُ وَتَسْبِيحَهُ } الضمير في { علم } ل { كل } أو لله ،   وكذا في صلاته وتسبيحه .   والصلاة الدعاء ولم يبعد أن يلهم الله الطير دعاءه وتسبيحه كما ألهمها سائر العلوم الدقيقة التي لايكاد العقلاء يتهتدون إليها { والله عَلِيمٌ بِمَا يَفْعَلُونَ } لا يعزب عن علمه شيء
