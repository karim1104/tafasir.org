{ زَعَمَ الذين كَفَرُواْ } أي أهل مكة ،   والزعم ادعاء العلم ويتعدى تعدي العلم { أَن لَّن يُبْعَثُواْ } «أن » مع ما في حيزه قائم مقام المفعولين وتقديره أنهم لن يبعثوا { قُلْ بلى } هو إثبات لما بعد «لن » وهو البعث { وَرَبِّى لَتُبْعَثُنَّ } أكد الإخبار باليمين .   فإن قلت : ما معنى اليمين على شيء أنكروه ؟ قلت : هو جائز لأن التهديد به أعظم موقعاً في القلب فكأنه قيل لهم : ما تنكرونه كائن لا محالة .   { ثُمَّ لَتُنَبَّؤُنَّ بِمَا عَمِلْتُمْ وَذَلِكَ } البعث { عَلَى الله يَسِيرٌ } هين
