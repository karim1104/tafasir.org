{ ذلك } إشارة إلى ما ذكر من الوبال الذي ذاقوه في الدنيا وما أعد لهم من العذاب في الآخرة { بِأَنَّهُ } بأن الشأن والحديث { كَانَت تَّأْتِيهِمْ رُسُلُهُم بالبينات } بالمعجزات { فَقَالُواْ أَبَشَرٌ يَهْدُونَنَا } أنكروا الرسالة للبشر ولم ينكروا العبادة للحجر { فَكَفَرُواْ } بالرسل { وَتَوَلَّواْ } عن الإيمان { واستغنى الله } أطلق ليتناول كل شيء ومن جملته أيمانهم وطاعتهم { والله غَنِىٌّ } عن خلقه { حَمِيدٌ } على صنعه .
