{ إِن كُلُّ مَن } نكرة موصوفة صفتها { فِى السماوات والأرض } وخبر { كل } { إِلاَّ ءَاتِي الرحمن } ووحد { آتى } و { آتيه } حملاً على لفظ { كل } وهو اسم فاعل من أتى وهو مستقبل أي يأتيه { عَبْداً } حال أي خاضعاً ذليلاً منقاداً ،   والمعنى ما كل من في السموات والأرض من الملائكة والناس إلا هو يأتي الله يوم القيامة مقراً بالعبودية ،   والعبودية والبنوة تتنافيان حتى لو ملك الأب ابنه يعتق عليه ونسبة الجميع إليه نسبة العبد إلى المولى فكيف يكون البعض ولداً والبعض عبداً ! وقرأ ابن مسعود { آت الرحمن } على أصله قبل الإضافة
