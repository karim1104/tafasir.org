{ يَاأُخْتَ هارون } وكان أخاها من أبيها ومن أفضل بني إسرائيل ،   أو هو أخو موسى عليه السلام وكانت من أعقابه وبينهما ألف سنة وهذا كما يقال يا أخا همدان أي يا واحداً منهم ،   أو رجل صالح أو طالح من زمانها شبهوها به في الصلاح أو شتموها به { مَا كَانَ أَبُوكِ } عمران { امرأ سَوْء } زانياً { وَمَا كَانَتْ أُمُّكِ } حنة { بَغِيّاً } زانية
