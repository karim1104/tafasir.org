{ لَن تَنفَعَكُمْ أرحامكم } قراباتكم { وَلاَ أولادكم } الذين توالون الكفار من أجلهم وتتقربون إليهم محاماة عليهم ثم قال  :{ يَوْمَ القيامة يَفْصِلُ بَيْنَكُمْ } وبين أقاربكم وأولادكم  ،  { يَوْمَ يَفِرُّ المرء مِنْ أَخِيهِ }[ عبس : 34 ] الآية .   فما لكم ترفضون حق الله مراعاة لحق من يفرّ منكم غداً .   { يُفَصّلُ } : عاصم .   { يُفَصّلُ } حمزة وعلي والفاعل هو الله عز وجل { يُفَصّلُ } ابن ذكوان غيرهم { يُفَصّلُ }  ،  { والله بِمَا تَعْمَلُونَ بَصِيرٌ } فيجازيكم على أعمالكم .
