{ رَّبَّنَا عَلَيْكَ تَوَكَّلْنَا } متصل بما قبل الاستثناء وهو من جملة الأسوة الحسنة .   وقيل : معناه قولوا ربنا فهو ابتداء أمر من الله للمؤمنين بأن يقولوه { وَإِلَيْكَ أَنَبْنَا } أقبلنا { وَإِلَيْكَ المصير } المرجع { رَبَّنَا لاَ تَجْعَلْنَا فِتْنَةً لّلَّذِينَ كَفَرُواْ } أي لا تسلطهم علينا فيفتنونا بعذاب { واغفر لَنَا رَبَّنَا إِنَّكَ أَنتَ العزيز الحكيم } أي الغالب الحاكم .
