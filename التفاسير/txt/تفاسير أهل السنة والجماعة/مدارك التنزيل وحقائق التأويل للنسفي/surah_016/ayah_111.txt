{ يَوْمَ تَأْتِي } ،   منصوب ب : { رحيم } أو ب : «اذكر » { كُلُّ نَفْسٍ تجادل عَن نَّفْسِهَا } ،   وإنما أضيفت النفس إلى النفس ؛ لأنه يقال لعين الشيء وذاته نفسه ،   وفي نقيضه غيره  ،  والنفس الجملة كما هي ،   فالنفس الأولى هي الجملة ،   والثانية عينها وذاتها فكأنه قيل : يوم يأتي كل إنسان يجادل عن ذاته لا يهمه شأن غيره كلٌّ يقول : نفسي نفسي .   ومعنى المجادلة عنها الاعتذار عنها ،   كقولهم : { هَؤُلاء أَضَلُّونَا } [ الأعراف : 38 ] ،   { ربنا إنا أطعنا سادتنا وكبراءنا } [ الأحزاب : 67 ] الآية ،   { والله ربنا ما كنا مشركين } [ الأنعام : 23 ] ،   { وتوفى كُلُّ نَفْسٍ مَّا عَمِلَتْ } ،   تعطى جزاء عملها وافياً ،   { وَهُمْ لاَ يُظْلَمُونَ } في ذلك .
