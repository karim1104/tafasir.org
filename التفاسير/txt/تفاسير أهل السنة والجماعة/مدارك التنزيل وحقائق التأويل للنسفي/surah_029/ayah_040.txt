{ فَكُلاًّ أَخَذْنَا بِذَنبِهِ } فيه رد على من يجوز العقوبة بغير ذنب { فَمِنْهُم مَّن أَرْسَلْنَا عَلَيْهِ حَاصِباً } هي ريح عاصف فيها حصباء وهي لقوم لوط { وَمِنْهُمْ مَّنْ أَخَذَتْهُ الصيحة } هي لمدين وثمود { وَمِنْهُمْ مَّنْ خَسَفْنَا بِهِ الأرض } يعني قارون { وَمِنْهُمْ مَّنْ أَغْرَقْنَا } يعني قوم نوح وفرعون { وَمَا كَانَ الله لِيَظْلِمَهُمْ } ليعاقبهم بغير ذنب { ولكن كَانُواْ أَنفُسَهُمْ يَظْلِمُونَ } بالكفر والطغيان .
