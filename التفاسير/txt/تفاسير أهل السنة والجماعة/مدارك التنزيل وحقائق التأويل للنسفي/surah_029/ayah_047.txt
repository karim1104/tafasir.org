{ وكذلك } ومثل ذلك الإنزال { أَنزَلْنَا إِلَيْكَ الكتاب } أي أنزلناه مصدقاً لسائر الكتب السماوية ،   أو كما أنزلنا الكتب إلى من قبلك أنزلنا إليك الكتاب { فالذين ءاتيناهم الكتاب يُؤْمِنُونَ بِهِ } هم عبد الله بن سلام ومن معه { وَمِنْ هَؤُلاء } أي من أهل مكة { مَن يُؤْمِنُ } أو أراد بالذين أوتوا الكتاب الذين تقدموا عهد رسول الله صلى الله عليه وسلم من أهل الكتاب ومن هؤلاء الذين كانوا في عهد رسول الله صلى الله عليه وسلم { وَمَا يَجْحَدُ بئاياتنا } مع ظهورها وزوال الشبهة عنها { إِلاَّ الكافرون } إلا المتوغلون في الكفر المصممون عليه ككعب بن الأشرف وأضرابه
