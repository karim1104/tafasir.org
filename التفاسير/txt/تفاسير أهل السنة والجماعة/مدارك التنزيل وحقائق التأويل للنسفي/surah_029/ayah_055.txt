{ يَوْمَ يغشاهم العذاب مِن فَوْقِهِمْ وَمِن تَحْتِ أَرْجُلِهِمْ } لقوله تعالى : { مّن فَوْقِهِمْ ظُلَلٌ مّنَ النار وَمِن تَحْتِهِمْ ظُلَلٌ } [ الزمر : 16 ] ولا وقف على { بالكافرين } لأن { يوم } ظرف إحاطة النار بهم { وَيَقُولُ } بالياء : كوفي ونافع ،   وقوله { ذُوقُواْ مَا كُنْتُمْ تَعْمَلُونَ } أي جزاء أعمالكم
