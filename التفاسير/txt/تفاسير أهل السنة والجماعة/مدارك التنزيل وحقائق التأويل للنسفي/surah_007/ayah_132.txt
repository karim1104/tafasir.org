{ وَقَالُواْ مَهْمَا تَأْتِنَا بِهِ مِن ءايَةٍ لّتَسْحَرَنَا بِهَا فَمَا نَحْنُ لَكَ بِمُؤْمِنِينَ } أصل «مهما » ما ما ،   فما الأولى للجزاء ضمت إليها «ما » المزيدة المؤكدة للجزاء في قوك «متى » ما تخرج أخرج { أَيْنَمَا تَكُونُواْ } [ النساء : 78 ] { فَإِمَّا نَذْهَبَنَّ بِكَ } [ الزخرف : 41 ] إلا أن الألف قلبت هاء استثقالاً لتكرير المتجانسين وهو المذهب السديد البصري ،   وهو في موضع النصب ب { تَأْتِنَا } أي أيما شيء تحضرنا تأتنا به ،   و { مّنْ ءايَةٍ } تبيين ل { مَهْمَا } والضمير في { بِهِ } و { بِهَا } راجع إلى { مَهْمَا } إلا أن الأول ذكر على اللفظ والثاني أنث على المعنى لأنها في معنى الآية ،   وإنما سموها آية اعتباراً لتسمية موسى أو قصدوا بذلك الاستهزاء
