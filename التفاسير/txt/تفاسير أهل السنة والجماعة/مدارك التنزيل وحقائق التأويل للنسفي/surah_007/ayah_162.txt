فَبَدَّلَ الذين ظَلَمُواْ مِنْهُمْ قَوْلاً غَيْرَ الذى قِيلَ لَهُمْ فَأَرْسَلْنَا عَلَيْهِمْ رِجْزًا مّنَ السماء بِمَا كَانُواْ يَظْلِمُونَ } ولا تناقض بين قوله { اسكنوا هذه القرية وَكُلُواْ مِنْهَا } في هذه السورة وبين قوله في سورة«البقرة » { ادخلوا هذه القرية فَكُلُواْ } [ البقرة : 85 ] لوجود الدخول والسكنى .   وسواء قدموا الحطة على دخول الباب أو أخروها فهم جامعون بينهما .   وترك ذكر الرغد لا يناقض إثباته ،   وقوله { نَّغْفِرْ لَكُمْ خطاياكم سَنَزِيدُ المحسنين } موعد بشيئين بالغفران وبالزيادة ،   وطرح الواو لا يخل بذلك لأنه استئناف مرتب على قول القائل : وماذا بعد الغفران ؟ فقيل له : { سَنَزِيدُ المحسنين } وكذلك زيادة { مِنْهُمْ } زيادة بيان و { أَرْسَلْنَا } و { أَنزَلْنَا } و { يَظْلِمُونَ } و { يَفْسُقُونَ } من وادٍ واحد .
