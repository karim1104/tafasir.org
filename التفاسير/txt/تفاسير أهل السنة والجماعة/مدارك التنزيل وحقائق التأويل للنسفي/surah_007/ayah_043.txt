وَنَزَعْنَا مَا فِى صُدُورِهِم مّنْ غِلّ } حقد كان بينهم في الدنيا فلم يبق بينهم إلا التواد والتعاطف ،   وعن علي رضي الله عنه : إني لأرجو أن أكون أنا وعثمان وطلحة والزبير منهم { تَجْرِى مِن تَحْتِهِمُ الأضنهار } حال من «هم » في { صُدُورُهُمْ } والعامل فيها معنى الإضافة { وَقَالُواْ الحمد لِلَّهِ الذى هَدَانَا لهذا } لما هو وسيلة إلى هذا الفوز العظيم وهو الإيمان { وَمَا كُنَّا } { مَا كُنَّا } بغير «واو » : شامي على أنها جملة موضحة للأولى { لِنَهْتَدِىَ لَوْلا أَنْ هَدَانَا الله } اللام لتوكيد النفي أي وما كان يصح أن نكون مهتدين لولا هداية الله ،   وجواب «لولا » محذوف دل عليه ما قبله { لَقَدْ جَاءتْ رُسُلُ رَبّنَا بالحق } فكان لطفاً لنا وتنبيهاً على الاهتداء فاهتدينا ،   يقولون ذلك سروراً بما نالوا وإظهاراً لما اعتقدوا { وَنُودُواْ أَن تِلْكُمُ الجنة } «أن » مخففة من الثقيلة واسمها محذوف ،   والجملة بعدها خبرها تقديره ونودوا بأنه تلكم الجنة .   والهاء ضمير الشأن ،   أو بمعنى أي كأنه قيل ،   لهم تلكم الجنة { أُورِثْتُمُوهَا } أعطيتموها وهو حال من { الجنة } والعامل فيها ما في { تِلْكَ } من معنى الإشارة { بِمَا كُنْتُمْ تَعْمَلُونَ } سماها ميراثاً لأنها لا تستحق بالعمل بل هي محض فضل الله وعده على الطاعات كالميراث من الميت ليس بعوض عن شيء بل هو صلة خالصة .   وقال الشيخ أبو منصور رحمه الله : إن المعتزلة خالفوا الله فيما أخبر ونوحاً عليه السلام وأهل الجنة والنار وإبليس ،   لأنه قال الله تعالى { يُضِلُّ مَن يَشَآء وَيَهْدِى مَن يَشَآء } [ النحل : 93 ] وقال نوح عليه السلام : { وَلاَ يَنفَعُكُمْ نُصْحِى إِنْ أَرَدْتُّ أَنْ أَنصَحَ لَكُمْ إِن كَانَ الله يُرِيدُ أَن يُغْوِيَكُمْ } [ هود : 34 ] وقال أهل الجنة : { وَمَا كُنَّا لِنَهْتَدِىَ لَوْلا أَنْ هَدَانَا الله } وقال أهل النار : { لَوْ هَدَانَا الله لَهَدَيْنَاكُمْ } [ ابراهيم : 21 ] وقال إبليس { فَبِمَا أَغْوَيْتَنِى }
