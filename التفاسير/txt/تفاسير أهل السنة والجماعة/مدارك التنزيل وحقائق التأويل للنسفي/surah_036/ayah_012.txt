{ إِنَّا نَحْنُ نُحْيىِ الموتى } نبعثهم بعد مماتهم أو نخرجهم من الشرك إلى الإيمان { وَنَكْتُبُ مَاَ قَدَّمُواْ } ما أسلفوا من الأعمال الصالحات وغيرها { وَءَاثَارَهُمْ } ما هلكوا عنه من أثر حسن كعلم علّموه أو كتاب صنّفوه أو حبيس حبّسوه أو رباط أو مسجد صنعوه أو سيء كوظيفة وظفها بعض الظلمة ،   وكذلك كل سنة حسنة أو سيئة يستن بها ونحوه قوله تعالى { يُنَبَّأُ الإنسان يَوْمَئِذِ بِمَا قَدَّمَ وَأَخَّرَ } [ القيامة : 13 ] قدم من أعماله وأخر من آثاره .   وقيل : هي خطاهم إلى الجمعة أو إلى الجماعة { وَكُلَّ شىْءٍ أحصيناه } عددناه وبيناه { فِى إِمَامٍ مُّبِينٍ } يعني اللوح المحفوظ لأنه أصل الكتب ومقتداها .
