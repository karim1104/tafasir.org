{ وَلَقَدْ أَضَلَّ مِنْكُمْ جِبِلاًّ } بكسر الجيم والباء والتشديد : مدني وعاصم وسهل { جبلاً } بضم الجيم والباء والتشديد : يعقوب { جُبْلاًّ } مخففاً : شامي وأبو عمرو .   و { جُبُلاًّ } بضم الجيم والباء وتخفيف اللام : غيرهم ،   وهذه لغات في معنى الخلق { كَثِيراً أَفَلَمْ تَكُونُواْ تَعْقِلُونَ } استفهام تقريع على تركهم الانتفاع بالعقل
