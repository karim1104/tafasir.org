{ وَلَقَدْ أَهْلَكْنَا القرون مِن قَبْلِكُمْ } يا أهل مكة { لَمَّا ظَلَمُواْ } أشركوا وهو ظرف { أهلكنا } والواو في { وَجَاءتْهُمْ رُسُلُهُم } للحال أي ظلموا بالتكذيب وقد جاءتهم رسلهم { بالبينات } بالمعجزات { وَمَا كَانُواْ لِيُؤْمِنُواْ } إن بقوا ولم يهلكوا لأن الله علم منهم أنهم يصرون على كفرهم ،   وهو عطف على { ظلموا } أو اعتراض ،   واللام لتأكيد النفي يعني أن السبب في إِهلاكهم تكذيبهم للرسل ،   وعلم الله أنه لا فائدة في إمهالهم بعد أن ألزموا الحجة ببعثة الرسل { كذلك } مثل ذلك الجزاء يعني الإهلاك { نَجْزِي القوم المجرمين } وهو وعيد لأهل مكة على إجرامهم بتكذيب رسول الله صلى الله عليه وسلم
