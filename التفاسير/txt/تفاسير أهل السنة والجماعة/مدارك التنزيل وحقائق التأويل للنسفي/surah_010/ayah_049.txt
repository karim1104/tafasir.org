{ قُلْ } يا محمد { لاَّ أَمْلِكُ لِنَفْسِي ضَرّا } من مرض أو فقر { وَلاَ نَفْعاً } من صحة أو غنى { إِلاَّ مَا شَاء الله } استثناء منقطع أي ولكن ما شاء الله من ذلك كائن فكيف أملك لكم الضر وجلب العذاب { لِكُلّ أُمَّةٍ أَجَلٌ إِذَا جَاء أَجَلُهُمْ فَلاَ يَسْتَأْخِرُونَ سَاعَةً وَلاَ يَسْتَقْدِمُونَ } لكل أمة وقت معلوم للعذاب مكتوب في اللوح فإذا جاء وقت عذابهم لا يتقدمون ساعة ولا يتأخرون فلا تستعجلوا
