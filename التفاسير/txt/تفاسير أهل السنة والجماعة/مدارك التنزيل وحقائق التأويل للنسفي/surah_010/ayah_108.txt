{ قُلْ يا أَيُّهَا الناس } يا أهل مكة { قَدْ جَاءكُمُ الحق } القرآن أو الرسول { مِن رَّبّكُمْ فَمَنُ اهتدى } اختار الهدى واتبع الحق { فَإِنَّمَا يَهْتَدِى لِنَفْسِهِ } فما نفع باختياره إلا لنفسه { وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } ومن آثر الضلال فما ضر إلا نفسه ودل اللام و«على » على معنى النفع والضرر { وَمَا أَنَاْ عَلَيْكُمْ بِوَكِيلٍ } بحفيظ موكول إلى أمركم إنما أنا بشير ونذير .
