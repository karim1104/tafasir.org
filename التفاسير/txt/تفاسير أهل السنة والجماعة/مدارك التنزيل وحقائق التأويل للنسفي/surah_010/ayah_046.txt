{ وَإِمَّا نُرِيَنَّكَ بَعْضَ الذى نَعِدُهُمْ } من العذاب { أَوْ نَتَوَفَّيَنَّكَ } قبل عذابهم { فَإِلَيْنَا مَرْجِعُهُمْ } جواب { نتوفينك } وجواب { نرينك } محذوف أي وإما نرينك بعض الذي نعدهم في الدنيا فذاك ،   أو نتوفينك قبل أن نريكه فنحن نريكه في الآخرة { ثُمَّ الله شَهِيدٌ على مَا يَفْعَلُونَ } ذكرت الشهادة والمراد مقتضاها وهو العقاب كأنه قيل : ثم الله معاقب على ما يفعلون .   وقيل : «ثم » هنا بمعنى «الواو » .
