{ أَثُمَّ إِذَا مَا وَقَعَ } العذاب { ءَامنتُم بِهِ } جواب الشرط و { ماذا يستعجل منه المجرمون } اعتراض .   والمعنى إن أتاكم عذابه آمنتم به بعد وقوعه حين لا ينفعكم الإيمان .   ودخول حرف الاستفهام على « ثم » كدخوله على «الواو » و«الفاء » في { أفأمن أهل القرى } { أو أمن أهل القرى } { الئان } على إرادة القول أي قيل لهم إذا آمنوا بعد وقوع العذاب آلآن آمنتم به { وَقَدْ كُنتُم بِهِ تَسْتَعْجِلُونَ } َأي بالعذاب تكذيباً واستهزاء .   { آلان } بحذف الهمزة التي بعد اللام وإلقاء حركتها على اللام : نافع
