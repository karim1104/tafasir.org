{ وأخرى } معطوفة على { هذه } أي فعجل لكم هذه المغانم و { مَغَانِمَ أخرى } هي مغانم هوازن في غزوة حنين { لَمْ تَقْدِرُواْ عَلَيْهَا } لما كان فيها من الجولة { قَدْ أَحَاطَ الله بِهَا } أي قدر عليها واستولى وأظهركم عليها ،   ويجوز في { أخرى } النصب بفعل مضمر يفسره { قَدْ أَحَاطَ الله بِهَا } تقديره : وقضى الله أخرى قد أحاط بها ،   وأما { لَمْ تَقْدِرُواْ عَلَيْهَا } فصفة ل { أخرى } والرفع على الابتداء لكونها موصوفة ب { لَمْ تَقْدِرُواْ } ،   و { قَدْ أَحَاطَ الله بِهَا } خبر المبتدأ { وَكَانَ الله على كُلِّ شَىْءٍ قَدِيراً } قادراً
