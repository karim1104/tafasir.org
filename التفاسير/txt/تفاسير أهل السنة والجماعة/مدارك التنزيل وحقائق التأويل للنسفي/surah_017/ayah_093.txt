{ أَوْ يَكُونَ لَكَ بَيْتٌ مِّن زُخْرُفٍ } ذهب { أَوْ ترقى في السَّمَآءِ } تصعد إليها { وَلَنْ نُّؤْمِنَ لِرُقِيِّكَ } لأجل رقيك { حتى تُنَزِّلَ عَلَيْنَا } وبالتخفيف : أبو عمرو { كِتاباً } أي من السماء فيه تصديقك { تقرؤُه } صفة كتاب { قُلْ } { قال } مكي وشامي أي قال الرسول { سُبْحَانَ رَبِّي } تعجب من اقتراحاتهم عليه { هَلْ كُنْتُ إِلاَّ بَشَراً رَّسُولاً } أي أنا رسول كسائر الرسل بشر مثلهم ،   وكان الرسل لا يأتون قومهم إلا بما يظهره الله عليهم من الآيات فليس أمر الآيات إلى إنما هو إلى الله ،   فما بالكم تتخيرونها علي
