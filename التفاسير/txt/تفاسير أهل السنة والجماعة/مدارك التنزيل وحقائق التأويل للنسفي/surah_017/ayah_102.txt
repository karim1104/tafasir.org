{ قَالَ } أي موسى { لَقَدْ عَلِمْتَ } يا فرعون { مَآ أَنزَلَ هَؤُلاءِ } الآيات { إِلاَّ رَبُّ السَّمَاوَاتِ وَالأرْضِ } خالقهما { بَصَآئِرَ } حال أي بينات مكشوفات إلا أنك معاند ونحوه { وجحدوا بها واستيقنتها أنفسهم ظلماً وعلواً } [ النمل : 14 ] { علمت } بالضم : عليّ أي إني لست بمسحور كما وصفتني بل أنا عالم بصحة الأمر ،   وأن هذه الآيات منزلها رب السماوات والأرض .   ثم قارع ظنه بظنه بقوله : { وَإِنِّي لأظُنُّكَ يَافرِعَوْنُ مَثْبُوراً } كأنه قال : إن ظننتني مسحوراً فأنَا أظنك مثبوراً هالكاً وظني أصح من ظنك لأن له أمارة ظاهرة وهي إنكارك ما عرفت صحته ومكابرتك لآيات الله بعد وضوحها ،   وأما ظنك فكذب بحت ،   لأن قولك مع علمك بصحة أمري { إني لأظنك مسحوراً } قول كذب .   وقال الفراء : مثبوراً مصروفاً عن الخير من قولهم «ما ثبرك عن هذا » أي ما منعك وصرفك ؟
