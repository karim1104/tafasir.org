{ وَجَعَلْنَا على قُلُوبِهِمْ أَكِنَّةً } جمع كنان وهو الذي يستر الشيء { أَن يَفْقَهُوهُ } كراهة أن يفقهوه { وفي ءاذانهم وقراً } ثقلاً يمنع عن الاستماع { وإذا ذكرت ربك في القرآن وحده } يقال : وحد يحد وحداً وحدة نحو وعد يعد وعداً وعدة فهو مصدر سد مسد الحال أصله يحد وحده بمعنى واحداً { وَلَّوْاْ على أدبارهم } رجعوا على أعقابهم { نُفُورًا } مصدر بمعنى التولية أو جمع نافر كقاعد وقعود أي يحبون أن تذكر معه آلهتهم لأنهم مشركون فإذا سمعوا بالتوحيد نفروا .
