{ أولئك } مبتدأ { الذين يَدْعُونَ } صفة أي يدعونهم آلهة أو يعبدونهم والخبر { يَبْتَغُونَ إلى رَبّهِمُ الوسيلة } يعني أن آلهتهم أولئك يبتغون الوسيلة وهي القربة إلى الله عز وجل { أَيُّهُم } بدل من واو يبتغون و«أي » موصولة أي يبتغي من هو { أَقْرَبُ } منهم الوسيلة إلى الله فكيف بغير الأقرب أو ضمن يبتغون الوسيلة معنى يحرصون فكأنه قيل : يحرصون أيهم يكون أقرب إِلى الله وذلك بالطاعة وازدياد الخير { وَيَرْجُونَ رَحْمَتَهُ ويخافون عَذَابَهُ } كغيرهم من عباد الله فكيف يزعمون أنهم آلهة { إِنَّ عَذَابَ رَبّكَ كَانَ مَحْذُورًا } حقيقاً بأن يحذره كل أحد من ملك مقرب ونبي مرسل فضلاً عن غيرهم
