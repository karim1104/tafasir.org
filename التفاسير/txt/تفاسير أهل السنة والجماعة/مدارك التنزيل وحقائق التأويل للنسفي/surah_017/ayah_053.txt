{ وَقُل لّعِبَادِى } وقل للمؤمنين { يَقُولُواْ } للمشركين الكلمة { التى هِىَ أَحْسَنُ } وألين ولا يخاشنوهم وهي أن يقولوا يهديكم الله { إِنَّ الشيطان يَنزَغُ بَيْنَهُمْ } يلقي بينهم الفساد ويغري بعضهم على بعض ليوقع بينهم المشاقة .   والنزغ : إيقاع الشر وإفساد ذات البين .   وقرأ طلحة : { ينزغ } بالكسر وهما لغتان { إِنَّ الشيطان كَانَ للإنسان عَدُوّا مُّبِينًا } ظاهر العداوة أو فسر { التي هي أحسن } بقوله : { رَّبُّكُمْ أَعْلَمُ بِكُمْ إِن يَشَأْ يَرْحَمْكُمْ }
