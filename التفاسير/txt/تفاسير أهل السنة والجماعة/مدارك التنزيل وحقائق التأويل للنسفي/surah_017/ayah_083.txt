{ وَإِذَا أَنْعَمْنَا عَلَى الإنسان } بالصحة والسعة { أَعْرَضَ } عن ذكر الله أو أنعمنا بالقرآن أعرض { وَنَأَى بِجَانِبِهِ } تأكيد للإعراض لأن الإعراض عن الشيء أن يوليه عرض وجهه والنأي بالجانب أي يلوي عنه عطفه ويوليه ظهره ،   أو أراد الاستكبار لأن ذلك من عادة المستكبرين { نأى } بالأمالة : حمزة وبكسرها عليَّ { وَإِذَا مَسَّهُ الشر } الفقر والمرض أو نازلة من النوازل { كَانَ يَئُوساً } شديد اليأس من روح الله
