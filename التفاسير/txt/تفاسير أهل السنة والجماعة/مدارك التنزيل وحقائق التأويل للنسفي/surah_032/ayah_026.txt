{ أو لم } الواو للعطف على معطوف عليه منوي من جنس المعطوف أي أو لم يدع { يهد } يبين والفاعل الله بدليل قراءة زيد عن يعقوب { نهد } { لهم } لأهل مكة { كم } لا يجوز أن يكون «كم » فاعل { يهدى } لأن «كم » للاستفهام فلا يعمل فيه ما قبله ومحله نصب بقوله { أهلكنا من قبلهم مّن القرون } كعاد وثمود وقوم لوط { يمشون في مساكنهم } أي أهل مكة يمرون في متاجرهم على ديارهم وبلادهم { إنّ في ذلك لآياتٍ أفلا يسمعون } المواعظ فيتعظوا
