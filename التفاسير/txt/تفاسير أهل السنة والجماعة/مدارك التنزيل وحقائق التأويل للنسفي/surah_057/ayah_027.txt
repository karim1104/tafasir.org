{ ثُمَّ قَفَّيْنَا على ءاثارهم } أي نوح وإبراهيم ومن مضى من الأنبياء { بِرُسُلِنَا وَقَفَّيْنَا بِعِيسَى ابن مَرْيَمَ وءاتيناه الإنجيل وَجَعَلْنَا فِى قُلُوبِ الذين اتبعوه رَأْفَةً } مودة وليناً { وَرَحْمَةً } تعطفاً على إخوانهم كما قال في صفة أصحاب النبي صلى الله عليه وسلم { رُحَمَاء بَيْنَهُمْ } [ الفتح : 29 ] { وَرَهْبَانِيَّةً } هي ترهبهم في الجبال فارّين من الفتنة في الدين مخلصين أنفسهم للعبادة وهي الفعلة المنسوبة إلى الرهبان وهو الخائف .   فعلان من رهب كخشيان من خشي .

وانتصابها بفعل مضمر يفسره الظاهر تقديره وابتدعوا رهبانية { ابتدعوها } أي أخرجوها من عند أنفسهم ونذروها { مَا كتبناها عَلَيْهِمْ } لم نفرضها نحن عليهم { إِلاَّ ابتغاء رضوان الله } استثناء منقطع أي ولكنهم ابتدعوها ابتغاء رضوان الله { فَمَا رَعَوْهَا حَقَّ رِعَايَتِهَا } كما يجب على الناذر رعاية نذره لأنه عهد مع الله لا يحل نكثه { فَئَاتَيْنَا الذين ءَامَنُواْ مِنْهُمْ أَجْرَهُمْ } أي أهل الرأفة والرحمة الذين اتبعوا عيسى عليه السلام و الذين آمنوا بمحمد صلى الله عليه وسلم { وَكَثِيرٌ مِّنْهُمْ فاسقون } الكافرون .
