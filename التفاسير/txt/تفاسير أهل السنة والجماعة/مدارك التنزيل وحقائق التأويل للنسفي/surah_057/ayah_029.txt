لّئَلاَّ يَعْلَمَ } ليعلم { أَهْلِ الكتاب } الذين لم يسلموا و «لا » مزيدة { أَلاَّ يَقْدِرُونَ } «أن » مخففة من الثقيلة أصله أنه لا يقدرون يعني أن الشأن لا يقدرون { على شَىْءٍ مّن فَضْلِ الله } أي لا ينالون شيئاً مما ذكر من فضل الله من الكفلين والنور والمغفرة لأنهم لم يؤمنوا برسول الله صلى الله عليه وسلم فلم ينفعهم إيمانهم بمن قبله ولم يكسبهم فضلاً قط { وَأَنَّ الفضل } عطف على { أَن لا يَقْدِرُونَ } { بِيَدِ الله } أي في ملكه وتصرفه { يُؤْتِيهِ مَن يَشَاء } من عباده { والله ذُو الفضل العظيم } ،   والله أعلم .
