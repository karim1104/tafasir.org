{ والذين ءامَنُواْ بالله وَرُسُلِهِ أُوْلَئِكَ هُمُ الصديقون والشهداء عِندَ رَبّهِمْ } يريد أن المؤمنين بالله ورسله هم عند الله بمنزلة الصديقين والشهداء وهم الذين سبقوا إلى التصديق واستشهدوا في سبيل الله { لَهُمْ أَجْرُهُمْ وَنُورُهُمْ } أي مثل أجر الصديقين والشهداء ومثل نورهم ،   ويجوز أن يكون { والشهداء } مبتدأ و { لَهُمْ أَجْرُهُمْ } خبره { والذين كَفَرُواْ وَكَذَّبُواْ بئاياتنا أولئك أصحاب الجحيم } .
