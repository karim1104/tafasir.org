{ مَّن ذَا الذى يُقْرِضُ الله قَرْضًا حَسَنًا } بطيب نفسه والمراد الإنفاق في سبيله واستعير لفظ القرض ليدل على التزام الجزاء { فَيُضَاعِفَهُ لَهُ } أي يعطيه أجره على إنفاقه أضعافاً مضاعفة من فضله { وَلَهُ أَجْرٌ كَرِيمٌ } أي وذلك الأجر المضموم إليه الأضعاف كريم في نفسه .   { فيضعّفُهُ } مكي { فيضعفَهُ } شامي { فَيُضَاعِفَهُ } : عاصم وسهل { فيضاعفُهُ } غيرهم .   فالنصب على جواب الاستفهام ،   والرفع على فهو يضاعفه أو عطف على { يُقْرِضُ }
