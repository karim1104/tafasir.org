قوله : { أفلم يهد لهم } ( 128 ) .

[ ا ] سعيد عن قتادة [ وهو تفسير السدي قالا ] : أفلم نبين لهم ،  ومن قرأها بالياء يقول : { أفلم يهد لهم } أفلم يبين [ الله ] لهم .

( قال يحيى ) : ولا أعرض أي المقرأتين قرأ قتادة .

{ كم أهلكنا قبلهم من القرون } ( 128 ) .

قال الحسن : أي بينا لهم ،  ( فقرأه ) على النون ،  كيف أهلكنا القرون الأولى نحذرهم ونخوفهم العذاب إن لم يؤمنوا .

قال : { يمشون في مساكنهم } ( 128 ) تمشي هذه الأمة في مساكن من مضى أي يمرون عليها وإن لم تكن الديار قائمة ولكن المواضع كقوله :{ ذلك من أنباء القرى نقصه عليك } ثم قال :{ منها قائم } تراه { وحصيد } لا تراه .

[ وقتال السدي : { يمشون في مساكنهم } يعني يمرون ،  يعني ممر أهل مكة على مساكنهم ،  يعني على قراهم ] .

قال : { إن في ذلك لآيات لأولي النهى } ( 128 ) لأولي الورع في تفسير قتادة .

وقال الحسن : لأولي العقول ،  وهم المؤمنون .
