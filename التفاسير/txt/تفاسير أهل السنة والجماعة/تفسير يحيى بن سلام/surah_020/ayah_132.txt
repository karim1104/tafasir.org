قوله : { وأمر أهلك بالصلاة } ( 132 ) وأهله في هذا الموضع : أمته .  { واصطبر عليها لا نسألك رزقا } ( 132 ) .  قال بعضهم : لا نسألك على ما أعطيناك من النبوة رزقا .

وتفسير الحسن في التي في الذاريات : { ما أريد منهم من رزق } أن يرزقوا أنفسهم .

قال يحيى : فإن كانت هذه عند الحسن مثلها فهو : { لا نسألك رزقا } أن ترزق نفسك وهو أعجب إلي .

قال يحيى : { نحن نرزقك والعاقبة للتقوى } ( 132 ) أي لأهل التقوى ،  والعاقبة : الجنة كقوله : { والآخرة عند ربك للمتقين }  .
