{ قال } ( 97 ) له موسى .  { ( فاذهب ) فإن لك في الحياة } ( 97 ) .  ( يعني )حياة الدنيا .  { أن تقول لا مساس } ( 97 ) ( لا )  تماس الناس ولا ( يماسونك ) ،  فهذه عقوبتك في الدنيا ومن كان على دينك إلى يوم القيامة ،  والسامرة صنف من اليهود .

وقال قتادة : بقايا السامرة حتى الآن بأرض الشام يقولون : لا مساس .

قال : { وإن لك موعدا لن تخلفه } ( 97 ) يعني يوم القيامة { لن تخلف } ،  أي توافيه فيجزيك الله فيه بأسوأ عملك .  وقال قتادة : { لن تخلفه } أي لن تغيب عنه .

قوله : { وانظر إلى إلهك الذي ظلت } ( 97 ) [ صرت ] .  { عليه عاكفا } ( 97 ) عابدا .  وقال السدي : { ظلت عليه عاكفا } يعني أقمت عليه عابدا ] .

قال : { لنحرقنه } ( 97 ) .  قال يحيى : سمعت بعض الكوفيين يقول : لنبردنه .  { ثم لننسفنه في اليم نسفا } ( 97 ) .

[ و ] قال الكلبي : ذبحه موسى ،  ثم أحرقه بالنار ،  ثم ذراه في البحر ،  وهو في قوله من قال هذا أنه تحول لحما ودما .  وقوله : { لننسفنه } هو حين ذراه في البحر .
