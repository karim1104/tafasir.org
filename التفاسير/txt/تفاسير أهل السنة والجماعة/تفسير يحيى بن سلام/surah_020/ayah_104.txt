قال الله : { نحن أعلم بما يقولون إذ يقول أمثلهم طريقة } ( 104 ) .  وقال في آية أخرى : { ويذهبا بطريقتكم المثلى } .  قال قتادة : كانوا أكثر عددا وأموالا .

( وقال ) : بعضهم : { نحن أعلم بما يقولون إذ يقول أمثلهم طريقة } : أعقلهم .  { إن لبثتم إلا يوما } ( 104 ) .

[ قال قتادة : في الدنيا ] وهي مواطن ،  قالوا : { إلا يوما } ،  و{ إلا عشرا } ،  و{ قالوا لبثنا يوما أو بعض يوم } ،  وقال : { كأنهم يوم يرونها لم يلبثوا إلا عشية أو ضحاها } ،  وقال : { كأنهم يوم يرون ما يوعدون لم يلبثوا إلا ساعة من نهار } .  [ وقال ] : { يوم تقوم الساعة يقسم المجرمون } يحلف المجرمون ،  المشركون { ما لبثوا غير ساعة } أي في الدنيا ،  وذلك لتصاغر الدنيا عندهم وقلتها في طول الآخرة .
