{ قال }71 ( فرعون ) .  { آمنتم له } ( 71 ) [ فرعون ]  يقول على الاستفهام ،  أصدقتموه ؟ { قبل أن آذان لكم } ( 71 ) أي قد فعلتم .  { إنه لكبيركم } ( 71 ) في السحر .  { الذي علمكم السحر } ( 71 ) .

[ وقال السدي يعني لعالمكم في علم السحر ولم يكن أكبرهم في السن ] .

{ فلأقطعن أيديكم وأرجلكم من خلف } ( 71 ) اليد اليمنى والرجل اليسرى .

{ ولأصلبنكم في جذوع النخل } ( 71 ) [ يعني ] على جذوع النخل ،  [ وهو تفسير السدي ] .

{ ولتعلمن أينا أشد عذابا وأبقى } ( 71 ) أنا أو موسى .
