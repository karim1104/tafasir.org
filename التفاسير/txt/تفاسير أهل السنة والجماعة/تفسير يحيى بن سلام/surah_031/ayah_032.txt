قوله [ عز وجل ] : { وإذا غشيهم موج كالظلل }( 32 ) كالجبال .  وقال في آية أخرى { وهي تجري بهم في موج كالجبال } .  وقال [ في آية أخرى ] : { وإذ نتقنا الجبل فوقهم كأنه ظلة } .

قال : { دعوا الله مخلصين له الدين }( 32 ) يعني التوحيد .  وهو تفسير السدي .  { فلما نجاهم إلى البر فمنهم مقتصد }( 32 ) و( هو ) المؤمن .  وأما الكافر فعاد في كفره .  قال مجاهد : { فمنهم مقتصد } في القول وهو كافر .

وقال : { وما يجحد بآياتنا إلا كل ختار كفور }( 32 ) غدار [ في تفسير مجاهد ] .

{ كفور } ( 32 ) اخلص لله في البحر للمخافة من الغرق ،  ثم غدر فأشرك كقوله : { فإذا ركبوا في الفلك دعوا الله مخلصين له الدين فلما نجاهم إلى البر إذا هم يشركون } .
