قوله [ عز وجل ] : { يا بني }( 16 ) رجع إلى كلام لقمان ( يعني الكلام ) الأول : { وإذ قال لقمان لابنه وهو يعظه يا بني لا تشرك بالله } .

( وقوله ) : { إنها إن تك مثقال حبة ( من خردل ) } ( 16 ) أي وزن حبة من خردل .

{ فتكن في صخرة }( 16 ) بلغنا أنها الصخرة التي عليها الحوت ،  التي عليها قرار الأرضين .

قال : { أو في السماوات أو في الأرض يأت بها الله }( 16 ) أي احذر ،  فإنه سيحصي عليك عملك ،  ويعلمه كما علم هذه الحبة من الخردل .  لقمان يقوله لابنه .

قال : { إن الله لطيف خبير }( 16 )( قال ) { لطيف } باستخراجها { خبير } بمكانها .
