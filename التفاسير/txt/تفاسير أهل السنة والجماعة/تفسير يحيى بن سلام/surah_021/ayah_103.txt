قوله : { لا يحزنهم الفزع الأكبر } ( 103 )

قال الحسن : النفخة الآخرة .

قال سفيان الثوري : بلغني أنه إذا أخرج من النار من أخرج فلم يبق فيها إلا أهل الخلود ،  فعند ذلك يقول أهل النار : { ربنا أخرجنا منها فإن عدنا فإنا ظالمون } .

فيقول الله تبارك وتعالى : { اخسئوا فيها ولا تكلمون }  فإذا قال ذلك أطبقت عليهم فلم يخرج منها أحد ،  فذلك الفزع الأكبر .

قوله : { وتتلقاهم الملائكة } ( 103 )

قال الحسن : تلقاهم بالبشارة حين يخرجون من قبورهم وتقول :

{ هذا يومكم الذي كنتم توعدون } ( 103 )
