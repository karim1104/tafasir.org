قال الله ( تبارك وتعالى ) : { فما زالت تلك دعواهم } ( 15 ) ( يعني ) قولهم : { يا ويلنا إنا كنا ظالمين } [ يعني فما زال ذلك قولهم ] .  { حتى جعلناهم حصيدا خامدين } ( 15 ) .

[ ا ] سعيد عن قتادة قال : يقول : لما رأوا العذاب لم يكن لهم ( هجيرى ) إلا قولهم :{ يا ويلنا إنا كنا ظالمين }  ،  { يا ويلنا إنا كنا ظالمين } ،  حتى ( أهلكوا ) .

[ و ] قوله : { حتى جعلناهم حصيدا خامدين } ] حتى أهلكوا .
