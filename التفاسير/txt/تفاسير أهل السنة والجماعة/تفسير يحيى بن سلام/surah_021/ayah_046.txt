قوله : { ولئن مستهم نفحة من عذاب ربك } ( 46 ) .

قال قتادة : عقوبة ( من عذاب ربك ) .

قال يحيى : ( وهي ) النفخة الأولى [ التي ] ( يهلك الله بها ) كفار آخر هذه الأمة بكفرهم وجحودهم .

{ ليقولن } ( 46 ) إذا جاءهم العذاب .

{ يا ويلنا إنا كنا ظالمين } ( 46 ) وهي مثل الآية الأولى ( في أول السورة ) .  { فما كان دعواهم إذ جاءهم بأسنا } عذابنا { قل أغير الله إنا كنا ظالمين } .
