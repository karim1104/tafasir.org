{ وتالله } ( 57 ) يمين أقسم ( به ) .  { لأكيدن أصنامكم بعد أن تولوا مدبرين } ( 57 ) .

قال قتادة : نرى أنه قال ( ذلك حيث لا يسمعون .  استنفعوه ليوم عيد لهم يخرجون فيه من المدينة ) [ فأبى ] ( فقال ) :

{ إني سقيم }  اعتل لهم بذلك ثم قال لما ولوا .  { وتالله لأكيدن أصنامكم بعد أن تولوا مدبرين } ( 57 ) فسمع وعيده لأصنامهم رجل ( منهم ) استأخر ( من القوم ) ،  وهو الذي قال : { سمعنا فتى يذكرهم يقال له إبراهيم } .
