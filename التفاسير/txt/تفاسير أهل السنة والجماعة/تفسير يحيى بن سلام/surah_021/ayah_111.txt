قوله : { وإن أدري لعله فتنة لكم } ( 111 ) .

تفسير الحسن : لعل ما أنتم فيه من الدنيا من السعة والرخاء ،  وهو منقطع زائل .

{ فتنة لكم } ( 111 ) يعني بلية لكم .  { ومتاع } ( 111 ) تستمتعون به ،  يعني بذلك المشركين .  وقوله : { إلى حين } ( 111 ) إلى يوم القيامة .  تفسير الحسن .  وقال قتادة : إلى الموت .
