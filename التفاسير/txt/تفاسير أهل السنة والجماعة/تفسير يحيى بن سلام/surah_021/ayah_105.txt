قوله : { ولقد كتبنا في الزبور من بعد الذكر } ( 105 ) تفسير مجاهد : يعني بالزبور الكتب : التوراة ،  والإنجيل ،  والقرآن ،  { من بعد الذكر } الكتاب عند الله الذي في السماء ،  وهو أم الكتاب .

{ أن الأرض } ( 105 ) يعني أرض الجنة .  { يرثها عبادي الصالحين } ( 105 ) .

وفي تفسير ابن عباس : { ولقد كتبنا في الزبور } يعني زبور داود { من بعد الذكر } من بعد التوراة { أن الأرض يرثها عبادي الصالحون } يعني أمة محمد .
