قال : { فاستجبنا له ووهبنا له يحيى وأصلحنا له زوجه } ( 90 ) .

قال قتادة : كانت عاقرا فجعلها الله ولودا .

( وقال سفيان عن بعض التابعين ) قال : كان في لسانها طول ،  ووهب له منها يحيى .

قال : { إنهم كانوا يسارعون في الخيرات } ( 90 ) ( يعني )  الأعمال الصالحة .  { ويدعوننا رغبا ورهبا } ( 90 ) ( يعني )  طمعا وخوفا .  { وكانوا لنا خاشعين } ( 90 ) [ ا ] عاصم بن حكيم أن مجاهدا قال : متواضعين .
