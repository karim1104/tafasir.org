قوله : { بالبينات والزبر } ( 44 ) .  قال السدي : { بالبينات } يعني : بالآيات التي كانت تجيء بها الأنبياء إلى  قومهم/ .

قال : { والزبر } يعني : ( وحديث الكتاب ) وما كان قبلهم من المواعظ .

قال يحيى : وفيها تقديم : وما أرسلنا من قبلك بالبينات والزبر ،  الكتب ،  إلا رجالا يوحى إليهم .  قال : { وأنزلنا إليك الذكر } ( 44 ) القرآن .  { لنبين للناس ما نزل إليهم ولعلهم يتفكرون } ( 44 ) .
