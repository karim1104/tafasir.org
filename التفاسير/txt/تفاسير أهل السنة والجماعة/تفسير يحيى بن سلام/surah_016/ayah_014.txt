قوله : { وهو الذي سخ البحر } ( 14 ) خلف البحر .  { لتأكلوا منه لحما طريا } ( 14 )

قال قتادة : حيتان البحر .  { وتستخرجوا منه حلية تلبسونها } ( 14 ) اللؤلؤ .  { وترى الفلك } ( 14 ) السفن .  { مواخر فيه } ( 14 ) .

سعيد عن قتادة قال : يعني سفن البحر مقبلة ومدبرة تجري فيه بريح واحدة .  وقال مجاهد : ولا تمخر الريح من السفن إلا العظام .  وبعضهم يقول : { مواخر فيه } يعني شقها الماء في وقت جريها .  قال : { ولتبتغوا من فضله } ( 14 ) .  قال مجاهد : طلب التجارة في السفن .  { ولعلكم تشكرون } ( 14 ) ولكي تشكروا ،  هي مثل قوله : { لعلكم تسلمون } .
