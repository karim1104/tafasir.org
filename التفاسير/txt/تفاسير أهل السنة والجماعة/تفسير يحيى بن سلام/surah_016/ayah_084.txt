قوله : { ويوم نبعث ( من ) كل أمة } ( 84 ) ،  ( يعني : من كل أمة } .  { شهيدا } ،  ( 84 ) [ وهم الأنبياء ،  تفسير السدي .  قال يحيى : شهيدا ] يعني : نبيهم يشهد عليهم أنه قد بلغهم .

{ ثم لا يؤذن للذين كفروا ولا هم يستعتبون } ( 84 ) .  هي مثل قوله : { هذا يوم لا ينطقون ( 35 ) ولا يؤذن لهم فيعتذون( 36 ) } بحجة ،  وهي مواطن لا يؤذن لهم في موطن في الكلام ،  ويؤذن لهم في موطن .
