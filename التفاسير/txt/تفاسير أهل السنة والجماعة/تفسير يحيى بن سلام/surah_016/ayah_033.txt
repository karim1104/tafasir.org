قوله : { هل ينظرون } ( 33 ) ما ينظرون .  { إلا أن تأتيهم الملائكة } ( 33 ) وهو عند الموت .  { أو يأتي أمر ربك } ( 33 ) ذاك يوم القيامة .  وهذا تفسير قتادة .

وتفسير الحسن : { هل ينظرون إلا أن تأتيهم الملائكة } بعذابهم يعني مشركي العرب .  { أو يأتي أمر ربك } ( 33 ) يعني النفخة الأولى التي يهلك الله بها آخر كفار هذه الأمة الدائنين بدين أبي جهل وأصحابه قبل عذاب الآخرة .

قال : { كذلك فعل الذين من قبلهم } ( 33 ) كذلك كذب الذين من قبلهم مشركي العرب كما كذب مشركو العرب فأهلكناهم بالعذاب .  قال : { وما ظلمهم الله ولكن كانوا أنفسهم يظلمون } ( 33 ) يضرون .  وقال الحسن : ينقصون .
