قوله : { وعلى الله قصد السبيل } ( 9 ) والسبيل قصد الطريق ،  الهدى  إلى الجنة كقوله : { إن علينا للهدى }  وكقوله : { قال هذا صراط علي مستقيم } ( 41 ) .

وقال سعيد عن قتادة : { قصد السبيل } البيان ،  حلاله ،  وحرامه ،  وطاعته ،  ومعصيتة .

وقال ابن مجاهد عن أبيه : { قصد السبيل } الطريق الحق على الله .

قوله : { ومنها جائر } ( 9 ) ومن السبيل جائر أي عن السبيل جائر ،  وهو الكافر ،  جار عن سبيل الهدى .  وجار عنها وجار منها واحد .

قال قتادة : وهي في قراءة عبد الله بن مسعود : { ومنكم جائر }  .

قال قتادة : جائر من السبيل أي عن سبيل الهدى ،  ناكب عنها .  قال قتادة : وذلك تفسيرها .

قال : { ولو شاء لهداكم أجمعين } ( 9 ) مثل قوله : { ولو شاء ربك لآمن من في الأرض كلهم جميعا }  وكقوله : { أفلم ييأس الذين آمنوا } أفلم يتبين   للذين آمنوا { أن لو يشاء لهدى الناس جميعا }  .
