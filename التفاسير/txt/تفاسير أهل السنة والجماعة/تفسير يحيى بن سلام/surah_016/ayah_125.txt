قوله : { ادع إلى سبيل ربك } ( 125 ) الهدى ،  الطريق إلى الجنة .  [ وقال السدي : يعني : إلى دين ربك ] .  { بالحكمة } ( 125 ) [ يعني : القرآن : تفسير السدي ] .  { ( والموعظة )  الحسنة } ( 125 ) القرآن .  { وجادلهم بالتي هي أحسن } ( 125 ) .

يأمرهم بما أمرهم الله وينهاهم عما نهاهم الله عنه .  { إن ربك هو أعلم بمن ضل عن سبيله وهو أعلم بالمهتدين } ( 125 ) .

أي : أنهم مشركون ضالون ،  وأن محمدا [ صلى الله عليه وسلم ]  وأصحابه مؤمنون مهتدون .
