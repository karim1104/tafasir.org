قوله عز وجل : { إن كانت }( 53 ) ( يعني ) ما كانت .

{ إلا صيحة واحدة } ( 53 ) تفسير السدي قال : وكذلك كل { إن } خفيفة تستقبلها إلا .

وقوله : { إن كانت إلا صيحة واحدة } من اسرافيل يعني النفخة الثانية ،  يعني القيامة .

{ فإذا هم جميع لدينا محضرون }( 53 ) المؤمنون والكافرون { لدينا } عندنا { محضرون } .
