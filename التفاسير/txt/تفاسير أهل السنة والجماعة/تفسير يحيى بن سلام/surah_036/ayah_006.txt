( قوله عز وجل ) : { لتنذر قوما }( 6 ) [ يعني ] قريشا .

{ ما أنذر ( آباؤهم ) } ( 6 )

( ا ) سعيد عن قتادة قال : قال ( بعضهم ) : لتنذر قوما لم ينذر ( آباؤهم ) .  وقال بعضهم : ( بالذي ) انذر آباؤهم .

قال يحيى [ من قال ] : لم ينذر آباؤهم يعني مثل قوله : { ما أتاهم من نذير من قبلك } يعني قريشا .  ومن قال : ( مثل ) الذي انذر آباؤهم فيأخذها من هذه الآية :{ أفلم يتدبروا القول أم جاءهم ما لم يأت آباءهم الأولين }/ يعني من كانوا قبل قريش .

وتفسير السدي : { لتنذر قوما } [ يعني ] لتحذر قوما ما في القرآن من الوعيد ( { ما أنذر آباؤهم } ) كما انذر آباؤهم ،  يعني كما حذر آباؤهم .  قال : { فهم غافلون }( 6 ) عما جاءهم به النبي ( صلى الله عليه وسلم ) في غفلة من  البعث .
