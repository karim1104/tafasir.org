{ وقالوا أئذا كنا ( عظاما ) ورفاتا } ( 49 ) ترابا في تفسير مجاهد .  { أئنا لمبعوثون خلقا جديدا } ( 49 ) على الاستفهام .  أي لا نبعث .  وهو كقوله : { وضرب لنا مثلا ونسي خلقه قال من يُحيي ( العظام ) وهي رميم } ( 78 ) .

كان أبي بن خلف أتى النبي [ صلى الله عليه وسلم ] ( بعظم ) نخر ( ففتّه ) فقال : يا محمد أيحيي الله هذا ؟ قال الله : { قل يحييها الذي أنشأها أول مرة }
