قال : { يوم يدعوكم } ( 52 ) من قبوركم .  ينادي صاحب الصور ينفخ فيه .  [ قال السدي : يوم يناديكم إسرافيل ] .  { فتستجيبون بحمده } ( 52 ) بمعرفته في تفسير الحسن وقتادة .  وقال قتادة : بمعرفته وطاعته يومئذ .

قال يحيى : والاستجابة [ منهم ] خروجهم من قبورهم إلى الداعي صاحب الصور إلى بيت المقدس .  { وتظنون } ( 52 ) في الآخرة .  { إن لبثتم } ( 52 ) في الدنيا .  { إلا قليلا } ( 52 ) مثل قوله : { قالوا لبثنا يوما أو بعض يوم } تصاغرت الدنيا عندهم .  ومثل قوله : { ويوم تقوم الساعة يقسم المجرمون } المشركون .  { ما لبثوا } في الدنيا ،  { غير ساعة } .  قال الله : { كذلك كانوا يؤفكون } ( 55 ) يصدون عن الهدى .  { وقال الذين أوتوا العلم والإيمان لقد لبثتم في كتاب الله إلى يوم البعث } وهي مقدمة يقول : { وقال الذين أوتوا العلم } في كتاب الله { والإيمان لقد لبثتم } إلى يوم البعث .  وقال في الآية الأولى : { إن لبثتم إلا قليلا } أي إن الذين كانوا فيه في الدنيا قليل في الآخرة لأنها لا تنقضي ،  فعلموا ( هناك ) في الآخرة ( أنه ) كذلك .

سعيد عن قتادة قال : و ( ذلك ) مما تحاقرت الدنيا في أنفسهم حين عاينوا يوم القيامة .
