قوله : { قل لو كان معه آلهة كما ( يقولون ) } ( 42 ) وهي تقرأ أيضا بالتاء .  فمن قرأها ( بالتاء ) فيقول للنبي : قل لهم : لو كان معه آلهة [ ثم أقبل على النبي [ صلى الله عليه وسلم ] : فقال ] : كما تقولون .  ومن قرأها ( بالياء ) يقول للنبي [ صلى الله عليه وسلم ] : قل لهم لو كان معه آلهة كما ( يقولون ) .  { إذا لابتغوا } ( 42 ) يعني الآلهة لو كانت آلهة .  { إلى ذي العرش سبيلا } ( 42 ) إذا لطلبوا إليه الوسيلة والقربة .

وقال قتادة : إذا لعرفوا له فضله عليهم ولابتغوا إليه ما يقربهم إليه .
