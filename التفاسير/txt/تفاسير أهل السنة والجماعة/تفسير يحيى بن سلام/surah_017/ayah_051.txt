{ أو خلقا مما يكبر في صدوركم } ( 51 ) .  سفيان عن خصيف عن عكرمة ومجاهد قالا : الموت ،  إذا لأمتكم ثم بعثتكم .  وقال قتادة : فإن الله يميتكم ثم يبعثكم يوم القيامة .  { فسيقولون من يعيدنا } ( 51 ) خلقا جديدا .  { قل الذي فطركم } ( 51 ) [ خلقكم ] .  { أول مرة فسينغضون إليك رءوسهم } ( 51 ) .

سعيد عن قتادة قال : أي ( فسيحركون ) أرؤسهم تكذيبا واستهزاء .  { ويقولون متى هو } ( 51 ) يعنون البعث .  { قل عسى أن يكون قريبا } ( 51 ) وعسى من الله واجبة ،  وكل ما هو آت قريب .
