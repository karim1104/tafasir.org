{ فإذا جاء وعد أولاهما } ( 5 ) : أولى العقوبتين .  { بعثنا عليكم عبادا لنا أولى بأس شديد } ( 5 ) ( تفسير مجاهد ) .  فارس .  { فجاسوا خلال الديار } ( 5 ) ( فقتلوهم ) في الديار وهدموا بيت المقدس وألقوا فيه الجيف والعذرة .  { وكان وعدا مفعولا } ( 5 ) أي أنه كائن .

[ وقال ابن مجاهد عن أبيه ] : { وقضينا إلى بني إسرائيل في الكتاب } كتبنا عليهم .  { لتفسدن في الأرض [ مرتين ] } إلى قوله : { أولى بأس شديد } قال : ذلك بيان من جاءهم من فارس يتحسسون أخبارهم ويسمعون حديثهم ومعهم بختنصر ،  فوعى أحاديثهم من بين أصحابه ثم  رجعت فارس ،  فلم ( يكن ) قتال ونصرت عليهم بنو إسرائيل .  فهذا وعد الأولى .

{ فإذا جاء وعد الآخرة ليسألوا وجوهكم } ( 7 ) بعث مالك فارس ببابل جيشا وأمر عليهم بختنصر ،  فأتوا ( بني ) اسرائيل فدمروهم .  فكانت هذه الآخرة ووعدها .

[ وقال السدي : { فإذا جاء وعد الآخرة } يعني : الموت الأخير من العذاب الذي وعدهم ] .

سعيد عن قتادة قال : عوقب القوم على ( غلوّهم ) وفسادهم ،  فبعث [ الله ] عليهم في الأولى جالوت ( الخزري ) فسبى وقتل وجاسوا خلال الديار كما قال الله ،  ثم ( روجع ) القوم على دخن فيهم كثير .
