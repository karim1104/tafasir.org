قوله : { ولا تقربوا مال اليتيم إلا بالتي هي أحسن } ( 34 ) والتي هي أحسن أن يوفر ماله حتى إذا بلغ أشده دفع إليه ماله إن ( آنس ) منه رشدا .

سعيد عن قتادة قال : لما نزلت هذه الآية اشتدت عليهم فكانوا لا ( يخالطونهم ) في ( المال ولا في المأكل ،  فجهدهم ذلك ،  فنسختها هذه الآية ) .  { وإن تخالطوهم فإخوانكم والله يعلم المفسد من المصلح } .

قوله : { وأوفوا بالعهد } ( 34 ) يعني ما عاهدتم عليه فيما وافق الحق .  { إن العهد كان مسئولا } ( 34 ) مطلوبا يُسأل عنه أهل الذين أعطوه .
