قوله : ( مَنِ ) اهتدى فإنما يهتدي لنفسه ،  ومن ضل فإنما يضل عليها } ( 15 ) على نفسه .  { ولا تزر وازرة وزر أخرى } ( 15 ) لا يحمل أحد ذنب ( أحد ) .

قوله : { وما كنا معذبين حتى نبعث رسولا } ( 15 ) .  تفسير الحسن : ( لا ) يعذب ( قوما ) ( بالاستئصال ) حتى يحتجّ عليهم بالرسول .  كقوله : { وما كان ربك مهلك القرى حتى يبعث في أمها رسولا }  .  وكقوله : { وإن من أمة إلا خلا فيها نذير }  يعني الأمم التي أهلك الله بالعذاب .
