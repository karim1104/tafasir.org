قوله : { ومن أراد الآخرة وسعى لها سعيها } ( 19 ) عمل لها عملها .  { وهو مؤمن }( 19 ) مخلص بالإيمان .

خالد عن الحسن قال : قال رسول الله صلى الله عليه و سلم :   » لا يقبل ( الله ) عمل عبد حتى يرضى قوله  » .  قال : { فأولئك كان سعيهم } ( 19 ) [ يعني عملهم ] .  { مشكورا } ( 19 ) يعني [ ( يشكر ) الله أعمالهم حتى ] يثيبهم الله ( به ) الجنة .  [ وقال السدي حتى يجزيهم بها ] .
