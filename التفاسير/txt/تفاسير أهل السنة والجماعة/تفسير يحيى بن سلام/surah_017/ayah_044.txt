( يسبح له السماوات السبع } ( 44 ) أي ومن فيهن .  { والأرض ومن فيهن } ( 44 ) من المؤمنين ومن يسبح له من الخلق .  { وإن من شيء إلا يسبح بحمده ولكن لا تفقهون تسبيحهم إنه كان حليما غفورا } ( 44 ) ( كان ) الحسن يقول : إن الجبل يسبح فإذا قطع منه شيء لم يسبح المقطوع ويسبح الأصل ( وكذلك ) ( الشجرة ) ( ما ) قطع منها لم يسبح وتسبح هي .

قال : { ولكن لا تفقهون تسبيحهم إنه كان حليما غفورا } ( 44 ) كقوله : { ولو يؤاخذ الله الناس بظلمهم ما ترك عليها من دابة } إذا يحبس القطر عنهم فأهلكهم .

قال : { غفورا } لهم ( أن ) تابوا .  ( سعيد عن قتادة قال : { حليما } عن خلقه فلا يعجل كعجلة بعضهم على بعض { غفورا } لهم إذا تابوا ) وراجعوا الحق .
