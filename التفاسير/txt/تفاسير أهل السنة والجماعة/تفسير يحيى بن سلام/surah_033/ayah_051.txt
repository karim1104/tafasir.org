قوله [ عز وجل ] : { ترجى من تشاء منهن وتؤوي إليك من تشاء ومن ابتغيت ممن عزلت فلا جناح عليك }( 51 ) تفسير الحسن : { ترجى من تشاء منهن } : يذكر النبي [ صلى الله عليه وسلم ] ( المرأة ( للتزوج ) ثم يرجيها ،  أي يتركها فلا يتزوجها .

قال : { وتؤوي إليك من تشاء } ( تتزوج من تشاء ) .  وكان النبي صلى الله عليه وسلم إذا ذكر امرأة ليتزوج لم يكن لأحد أن يعرض بذكرها حتى يتزوجها رسول الله [ صلى الله عليه وسلم ] أو يتركها .

وأما قوله : { ومن ابتغيت ممن عزلت } ،  يقول : ليست عليك لهن قسمة .  ومن ابتغيت من نسائك للحاجة ممن عزلت فلم ترد منها الحاجة .

{ فلا جناح عليك ذلك أدنى أن تقر أعينهن }( 51 ) إذا علمن أنه من قبل الله .

{ ولا يحزن }( 51 ) على أن تخص واحدة منهن دون الأخرى .

{ ويرضين بما آتيتهن ( كلهن ) } ( 51 ) من ( الحاجة ) التي تخص منهن لحاجتك .  وهذا تفسير الحسن .

وقال مجاهد : { ترجى من تشاء } تعزل { وتؤوي } تمسك .

وتفسير الكلبي : { ترجى من تشاء منهن } يعني من اللائي أحل له ،  إن شاء أن يتزوج منهن { وتؤوي إليك من تشاء } ( يتزوج ) منهن من ( شاء ) { ومن ابتغيت ممن عزلت فلا جناح عليك ذلك أدنى أن تقر أعينهن } يعني نساءه اللائي عنده يومئذ ،  يعني التسع ،  { ولا تحزن } إذا عرفن ألا ( تنكح ) عليهن .

{ ( والله ) يعلم ما في قلوبكم وكان الله عليما حليما }( 51 )
