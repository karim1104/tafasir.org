{ إنما تعبدون من دون الله أوثانا وتخلقون }( 17 ) أي وتصنعون .  { إفكا }( 17 ) ( يعني ) كذبا كقوله : { أتعبدون ما تنحتون } .  وقال ( مجاهد ) : [ قال ] : { وتخلقون إفكا } ( يقول ) كذبا .  [ وقال السدي : { وتخلقون إفكا } يعني تخرصون كذبا ] .

قال : { إن الذين تعبدون من دون الله لا يملكون لكم رزقا فابتغوا عند الله الرزق }( 17 ) ( فإن ) هذه الأوثان لا تملك لكم رزقا .

{ ( واعبدوه ) واشكروا له }( 17 ) أي فابتغوا عند الله الرزق بأن تعبدوه وتشكروه يرزقكم .  قال : { ( إليه ) ترجعون }( 17 ) يوم القيامة .
