قال الله ( تبارك وتعالى ) : { فكلا أخذنا بذنبه }( 40 ) يعني من أهلك من الأمم الذين قص في هذه السورة  إلى هذا الموضع .

( و ) قال السدي : { فكلا أخذنا بذنبه } ( يعني ) فكلا ( عذبناه ) بذنبه .

قال : { فمنهم من أرسلنا عليه حاصبا } ( 40 ) يعني قوم لوط [ يعني ] ( الحجارة ) التي رمي بها من كان خارجا من مدينتهم وأهل السفر منهم وخسف بمدينتهم .  قال : { ومنهم من أخذته الصيحة }( 40 ) ( يعني ) ثمود .  { ومنهم من خسفنا به الأرض }( 40 ) مدينة ثوم لوط وقارون .  { ومنهم من أغرقنا }( 40 ) قوم نوح وفرعون ( وقومه ) .

قال : { وما كان الله ليظلمهم ولكن كانوا أنفسهم يظلمون } ( 40 ) أي يضرون .  وفي تفسير الحسن ينقصون بشركهم وجحودهم رسلهم .
