قوله [ عز وجل ] : { ولقد أرسلنا نوحا إلى قومه فلبث فيهم ألف سنة إلا خمسين عاما }( 14 ) [ يقول : { ولقد أرسلنا نوحا إلى قومه فلبث فيهم ألف سنة إلا خمسين عاما } ] .

أبو ( سهل ) عن الحسن بن دينار عن الحسن قال : كان جميع عمره ألف سنة إلا خمسين عاما .  بقول : { ولقد أرسلنا نوحا إلى قومه فلبث فيهم } من يوم ولد إلى يوم مات { ألف سنة إلا خمسين عاما } .

( قال ) : وحدثني عن الحسن بن دينار عن حميد بن هلال أن كعبا قال : لبث نوح في قومه ألف سنة إلا خمسين عاما ،  ثم لبث بعد الطوفان ستمائة ( عام ) .

( قال ) : { فأخذهم الطوفان وهم ظالمون } ( 14 ) والطوفان ) الماء .  فأغرقهم به .

{ وهم ظالمون } ( 14 ) أي مشركون ،  ظالمون لأنفسهم ( وبظلمهم ضروا أنفسهم ) .
