قال : { ولما أن جاءت رسلنا }( 33 ) ( يعني ) الملائكة .  { لوطا سيء بهم وضاق بهم ذرعا }( 33 ) ( سيء ) بقومه الظن ( بما ) كانوا يأتون الرجال في أدبارهم ( تخوفا ) على أضيافه ،  وهو يظن أنهم آدميون .

قال : { وضاق بهم ذرعا }( 33 ) ضاق بأضيافه الذرع لما يتخوف عليهم منهم .  { وقالوا }( 33 ) الملائكة قالته للوط .  { لا تخف ولا تحزن إنا منجوك وأهلك إلا امرأتك كانت من الغابرين( 33 ) إنا منزلون على أهل هذه القرية ( رجزا من السماء ) } يعنون قرية قوم لوط .  { رجزا } : عذابا .
