قوله [ عز وجل ] : { وقالوا لولا }( 50 ) هلا .  { أنزل عليه آيات من ربه قل إنما الآيات عند الله }( 50 ) كانوا يسألون النبي ( عليه السلام ) أن يأتيهم بالآيات كقولهم : { فليأتنا بآية كما أرسل الأولون } وأشباه ذلك .  قال الله ( تبارك وتعالى ) : { قل إنما الآيات عند الله } إذا أراد أن ينزل آية انزلها كقوله : { قل إن الله قادر على أن ينزل آية ولكن أكثرهم لا يعلمون } .

( وقال ) الله : { قل إنما الآيات عند الله وإنما أنا نذير مبين }( 50 )

ثم قال ( تبارك وتعالى ) : { أولم يكفهم أنا أنزلنا عليك للكتاب يتلى عليهم }( 51 ) أي تتلوه ( و ) تقرؤه عليهم وأنت لا تقرأ ولا تكتب ( فكفاك ) ذلك لو عقلوا .
