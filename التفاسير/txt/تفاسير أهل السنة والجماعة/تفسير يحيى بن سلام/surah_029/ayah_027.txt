قال : { ووهبنا له إسحاق ويعقوب وجعلنا في ذريته النبوة والكتاب }( 27 ) فكان أول كتاب انزل ( بعد ) كتاب موسى وما بعده من الكتب .

[ حدثنا أبو القاسم الفروبي : قال : حدثنا الحسن بن علي بن عفان قال : حدثنا معاوية بن هشام قال : حدثنا سفيان عن ابن أبي نجيح عن مجاهد : { وآتيناه أجره في الدنيا } قال : الثناء .

قال : { اجعل لي لسان صدق في الآخرين }  قال : الثناء ] .  قال : { وآتيناه ( أجره ) } ( 27 ) أعطيناه أجره .  { في الدنيا }( 27 ) فليس من أهل دين إلا وهم يتولونه ويحبونه وهو مثل قوله : { وتركنا عليه في الآخرين } أي أبقينا عليه في ( الآخرين ) الثناء الحسن .

قال : { وإنه في الآخرة لمن الصالحين }( 27 ) لمن أهل الجنة .
