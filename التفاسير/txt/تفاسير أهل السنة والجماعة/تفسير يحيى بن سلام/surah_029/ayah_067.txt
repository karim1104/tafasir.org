قوله [ عز وجل ] : { أولم يروا أنا جعلنا حرما آمنا }( 67 ) أي بلى قد رأوا ذلك .

{ ويتخطف الناس من حولهم }( 67 ) يعني أهل الحرم أنهم آمنون والعرب حولهم يقتل بعضهم بعضا ويسبي بعضهم بعضا .

قال : { أفبالباطل يؤمنون }( 67 ) أي ( أفبإبليس ) { يؤمنون } يصدقون ،  يعبدونه بما وسوس إليهم من عبادة الأوثان وهي عبادته .  قال :{ ألم أعهد إليكم يا بني آدم أن لا تعبدوا الشيطان إنه لكم عدو مبين( 60 ) وأن اعبدوني هذا صراط مستقيم ( 61 ) } .

قال : { وبنعمة الله يكفرون }( 67 ) [ و ] هذا على الاستفهام .

( بلى ) قد فعلوا .  ( و ) قوله [ عز وجل ] : { وبنعمة الله يكفرون } يعني ما  جاء به النبي ( عليه السلام ) من الهدى .
