قوله [ عز وجل ] : { وهو الذي يبدأ الخلق ثم يعيده } ( 27 ) بعد الموت ،  يعني البعث .

{ وهو أهون عليه }( 27 ) ( يعني ) [ وهو ] أسرع عليه .  بدأ الخلق خلقا بعد خلق .  ثم  يبعثهم ( مرة ) واحدة .

[ حدثني الحسن بن دينار عن الحسن قال : الله { يبدأ الخلق ثم يعيده } قال : خلقا بعد خلق { وهو أهون عليه } قال : أسرع وأظنه قال : يجمعهم ] .

قوله [ عز وجل ] : { وله المثل الأعلى في السماوات والأرض }( 27 ) عما قال المشركون .  أي أنه ليس له ند ولا شبه .

[ قال ] : { وهو العزيز الحكيم }( 27 ) { العزيز } في نقمته ،  { الحكيم } في أمره .  ينزه نفسه عما قال المشركون [ أن ] جعلوا ( لله ) الأنداد فعبدوهم دونه .
