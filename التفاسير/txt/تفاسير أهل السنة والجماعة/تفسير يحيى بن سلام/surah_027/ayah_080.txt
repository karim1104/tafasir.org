قوله [ عز وجل ] : { إنك لا تسمع الموتى }( 80 ) يعني الكفار [ لأنهم بمنزلة الأموات في سمع الإيمان .  تفسير السدي .

قال يحيى : يعني ] الذين يلقون الله بكفرهم .

( قال يحيى ) : مثلهم فيما يدعوهم إليه مثل الأموات الذين لا يسمعون .

قال : { ( ولا تسمع الصم ) الدعاء إذا ولوا مدبرين } ( 80 ) يعنيهم .

وهي تقرأ على وجه آخر : ( ( ولا يسمع الصم ) الدعاء إذا ولوا مدبرين ) .

يقول : إن الأصم لا يسمع الدعاء ( إلا ) ولّي مدبرا .

[ عن أبيه ] : سعيد عن قتادة قال : هذا مثل ضربه الله .  ( فالكافر ) لا يسمع ( الهدي ولا يفهمه ) كما لا يسمع الميت ،  ولا يسمع الأصم الدعاء ( إلا ) ولى مدبرا .

[ عن أبيه ] : ( قال ) : ( و ) حدثني إسماعيل بن مسلم قال : سألت الحسن عن هذا الحرف فقال : { ولا يسمع الصم  الدعاء  إذا ولوا مدبرين } .
