قوله : { أمن يبدأ الخلق ثم يعيده }( 64 ) يعني البعث .

{ ومن يرزقكم من السماء والأرض }( 64 ) وهو على الاستفهام .  يقول : أمن يفعل هذا خير  ( أو ) أوثانهم .  وهذا تبع لقوله : { ألله خير أما يشركون } أي الله خير من أوثانهم .

قال : { أئله مع الله } ( 64 ) على الاستفهام .  أي ليس معه إله .

{ قل هاتوا برهانكم } ( 64 ) يقول للنبي [ صلى الله عليه وسلم ] ( أي ) يقول للمشركين { هاتوا برهانكم } حجتكم .  في تفسير  الحسن .  وفي تفسير قتادة : بيّنتكم .

[ وقال السدي : برهانكم ،  يعني حجّتكم ( أن ) معه إلها ] .

{ إن كنتم صادقين } ( 64 ) إن هذه الأوثان خلقت شيئا أو صنعت شيئا من هذا .

قوله [ عز وجل ] : { قل لا يعلم  من في السماوات والأرض الغيب إلا الله }( 65 ) الغيب ها هنا القيامة ،  لا يعلم مجيئها إلا الله .
