قوله [ عز وجل ] : { إذ قال موسى لأهله إني آنست نارا }( 7 )

قال قتادة أني أحسست نارا .  وقال في آية أخرى : { إذ رأى نارا } رآها نارا عند نفسه ،  وإنما كانت نورا .

وتفسير السدي :{ ( إني ) آنست نارا } [ يعني ] أني رأيت ( نورا ) .

{ سآتيكم منها بخبر }( 7 ) الطريق .  وكان على غير ( طريق ) .  وقال في آية أخرى : { أو أجد على النار هدى } أي هداة يهدون [ إلى ] الطريق .

{ أو يأتيكم ( بشهاب ) قبس }( 7 ) .  وقال في آية أخرى : { أو جذوة من النار } ،  وهو أصل الشجرة .  { لعلكم تصطلون } ( 7 ) لكي تصطلوا .  قال قتادة : وكان شاتيا .
