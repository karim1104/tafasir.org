{ وما كان لنا عليكم سلطان }( 30 ) كقوله : { فإنكم } يا بني إبليس { وما تعبدون ( 161 ) ما أنتم عليه بفاتنين }( 162 ) ليس لكم سلطان { إلا } على { من هو صال الجحيم } .

{ بل كنتم قوما طاغين }( 30 ) يعني ضالين .  تفسير السدي ،  تقوله الشياطين للمشركين من الإنس .

وقال السدي : { وما كان لنا عليكم من سلطان } من ملك / فنقهركم به على الشرك { بل كنتم قوما طاغين } .

{ فحق علينا قول ربنا }( 31 ) هذا قول الشياطين ،  والقول ها هنا قوله : { ولكن حق علينا القول مني } صدق القول مني { لأملأن جهنم من الجنة والناس  أجمعين } .
