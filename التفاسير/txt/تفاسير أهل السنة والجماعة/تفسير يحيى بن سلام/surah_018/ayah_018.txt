قال : { وتحسبهم أيقاظا وهم رقود } ( 18 ) مفتحة أعينهم وهم موتى .

{ ونقلبهم ذات اليمين وذات الشمال } ( 18 ) .  قال قتادة ذاك في رقدتهم الأولى قبل أن يموتوا .  قال قتادة : وقال أبو عياض : لهم في كل عام تقليبتان .  { وكلبهم باسط ذراعيه بالوصيد } ( 18 ) قال قتادة : بفناء الكهف .  { لو اطلعت عليهم لوليت منهم فرارا ولملأت منهم رعبا } ( 18 ) لحالهم .
