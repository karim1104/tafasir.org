{ وما أظن الساعة قائمة } ( 36 ) وما أوقن أن الساعة قائمة ،  يجحد بالبعث .  { ولئن رددت إلى ربي لأجدن خيرا ( منها ) } ( 36 ) من جنتي .

{ منقلبا } ( 36 ) في الآخرة إن كانت آخرة ،  كقوله : { ولئن رجعت إلى ربي أن لي عنده للحسنى }  الجنة إن كانت جنة ،  أي ولكن ليس جنة ولا مردّ .  وهي تقرأ على وجه آخر : { لأجدنّ خيرا منهما منقلبا } يعني الجنتين وهي في موضع جنة وفي موضع جنتان .  قال : { ودخل جنته } وقال : { جعلنا لأحدهما جنتين } ( فهي جنة بينهما نهر فصارت جنتين ،  وهي جنة ،  وهي جنتان ) .
