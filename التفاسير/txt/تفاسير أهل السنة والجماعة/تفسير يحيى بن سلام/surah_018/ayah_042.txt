قال الله : { وأحيط بثمره } ( 42 ) من الليل .  { فأصبح } ( 42 ) من الغد قائما .  { يقلب كفيه } يسفق كفيه في تفسير الحسن وقتادة .  وقال الحسن : يضرب إحداهما على الأخرى ندامة .  { على ما أنفق فيها } ( 42 ) .  وقال قتادة : تلهفا على ما فاته .

وقال ابن مجاهد عن أبيه : { وأحيط بثمره } مثل قوله : { وكان له ثمر } : ذهب وفضة .

قال : { وهي خاوية على عروشها }( 42 ) .  قال الحسن : عروشها ،  التراب ،  قد ذهب ما فيها من النبات .  وبعضهم يقول : مقلوبة على رؤوسها .  { ويقول } ( 42 ) في الآخرة .  { يا ليتني لم أشرك بربي } ( 42 ) في الدنيا .  { أحدا } ( 42 ) .
