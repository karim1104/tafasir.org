{ وكذلك بعثناهم ليتساءلوا بينهم قال قائل منهم كم لبثتم قالوا لبثنا يوما أو بعض يوم } ( 19 ) وكانوا  دخلوا الكهف في أول النهار .  قال : فنظروا فإذا هو قد بقي من الشمس بقية فقالوا : { أو بعض يوم } ،  ثم  أنهم شكوا فردوا علم ذلك إلى الله .  { قالوا ربكم أعلم بما لبثتم } ( 19 ) يقوله بعضهم لبعض .  { فابعثوا أحدكم بورقكم هذه } ( 19 ) أي بدراهمكم هذه .  { إلى المدينة } ( 19 ) وكانت معهم دراهم .  { فلينظروا أيها أزكى طعاما } ( 19 ) .  سفيان الثوري عن أبي حصين عن سعيد بن جبير قال : أيها أحلّ .

قال يحيى : وقد كان من طعام قومهم ما لا يستحلون أكله .  وقال بعضهم : أطيب .  { فليأتكم برزق منه وليتلطف ولا يشعرن } ( 19 ) ( لا يعلمنّ ) .  { بكم أحدا ( 19 ) }
