{ ومن أظلم } ( 57 ) يقوله على الاستفهام .  وهذا استفهام على معرفة .  { ممن ذكر بآيات ربه فأعرض عنها } ( 57 ) لم يؤمن بها .  { ونسي ما قدمت يداه } ( 57 ) .

قال قتادة : أي ما سلف من الذنوب الكثيرة .  قال : وقال الحسن : عمله السوء .  أي لا أحد أظلم منه .  قوله : { إنا جعلنا على قلوبهم أكنة } ( 57 ) غلفا .  { أن يفقهوه } ( 57 ) يعني لئلا يفقهوه .  وهو تفسير السدي .  { وفي آذانهم وقرا } ( 57 ) وهو الصّمم عن الهدى .  { وإن تدعهم إلى الهدى فلن يهتدوا إذا أبدا } ( 57 ) يعني الذين يموتون على شركهم .
