{ وربك الغفور ذو الرحمة } ( 58 ) لمن آمن ولا يغفر أن يشرك به .  { لو يؤاخذكم بما كسبوا } ( 58 ) بما عملوا .  { لعجّل لهم العذاب بل لهم موعد لن يجدوا من دونه موئلا } ( 58 ) .  قال الحسن : ملجأ .  وقال قتادة : وليا ولا ملجأ .  وقال المعلى عن أبي يحيى عن مجاهد : ما لهم ملجأ .

وقال عاصم بن حكيم وابن مجاهد عن أبيه : محرزا .

قوله : { وتلك القرى أهلكناهم لما ظلموا } لما أشركوا وجحدوا رسلهم .

[ وقال السدي : { أهلكناهم } يعني عذبناهم { لما ظلموا } لما أشركوا ] .
