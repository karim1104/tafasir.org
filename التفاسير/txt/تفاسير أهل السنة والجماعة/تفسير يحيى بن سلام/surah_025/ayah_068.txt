قوله :{ والذين لا يدعون مع الله آخر } ( 68 ) وأنتم أيها المشركون تدعون معه الآلهة .  تفسير الحسن .

قال :{ ولا يقتلون النفس التي حرم الله إلا بالحق ولا يزنون } ( 68 ) .

حدثني الحسن بن دينار عن الحسن قال : لما نزل في قاتل المؤن قوله : { ومن يقتل مؤمنا متعمدا فجزاؤه جهنم خالدا فيها } إلى آخر الآية ،  اشتد ذلك عليهم فأتوا رسول اله وذكروا / الفواحش وقالوا : قد ( قبلنا ) .  وفعلنا وفعلنا فأنزل الله :{ والذين لا يدعون مع الله إلها آخر } بعد إسلامهم ،  { ولا يقتلون النفس التي حرم الله إلا بالحق } بعد إسلامهم { ولا يزنون } بعد إسلامهم .  { ومن يفعل ذلك يلق آثاما } ( 68 )
