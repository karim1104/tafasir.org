قوله [ عز وجل ] : { أولم ( نهد ) لهم }( 26 ) أي أولم ( نبين ) لهم .  [ وهو تفسير السدي ] .  وهي تقرأ على وجه آخر ،  بالياء : { أولم يهد لهم } أي أولم يبين [ الله ] لهم .

{ كم أهلكنا من قبلهم من القرون }( 26 ) يعني ما قص مما أهلك به الأمم السالفة حين كذبوا رسلهم .

قال : { يمشون في مساكنهم }( 26 ( يعني ) يمرون ( فيها ) كقوله : { وإنكم لتمرون عليه مصبحين }نهارا و( ليلا يعني ) في مساكنهم التي كانوا فيها ،  منها ما يرى ومنها ما لا يرى ،  كقوله : { منها قائم } تراه { وحصيد } لا تراه .
