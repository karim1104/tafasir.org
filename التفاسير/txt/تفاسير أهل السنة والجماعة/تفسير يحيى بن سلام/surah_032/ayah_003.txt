قوله : { أم يقولون افتراه }( 3 ) يعني المشركين يقولون إن محمدا افترى  القرآن ،  أي قد قالوه .  هو على الاستفهام .  قال : { بل هو }( 3 ) [ يعني القرآن ] .  { الحق من ربك }( 3 ) يقوله للنبي ( عليه السلام ) .  { لتنذر }( 3 ) لكي تنذر .  { قوما }( 3 ) وهو تفسير السدي .

[ قال ] : { قوما ما أتاهم من نذير من قبلك }( 3 ) يعني قريشا ( تنذرهم ) العذاب .  { لعلهم يهتدون }( 3 ) لكي يهتدوا .
