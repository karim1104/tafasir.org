{ إن هذا }( 137 ) أي الذي جئتنا به .  { إلا خلق الأولين }( 137 ) في تفسير الحسن .

[ عن أبيه ] ( قال ) ( و ) ( حدثني ) إسماعيل بن مسلم قال : اختلفت أنا ومالك بن دينار في هذا الحرف فقلت [ أنا ] : { إن هذا إلا خلق الأولين } .  وقال مالك [ بن دينار ] : { خلق الأولين } .  فأتيت الحسن فسألته فقال : { إن هذا إلا  ( خلق ) الأولين } .  ( قال ) : ( خلقهم ) ( الكذب ) .

وقال السدي : ( ( إلا خلق ) إني الأولين ) يعني تخلق الأولين وتخرّصهم للكذب .

[ وعن ] سعيد عن قتادة قال : { إن هذا إلا ( خلق ) الأولين } أي هكذا كان الناس قبلنا يعيشون ما عاشوا ثم يموتون ،  ولا بعث عليهم ولا حساب .

قال يحيى : يعنون أن هكذا كان [ الخلق ] قبلنا ،  ونحن مثلهم .

وبعضهم يقول : { خلق الأولين } دين الأولين ،  ويعنون ما هم عليه من ( شرك ) .
