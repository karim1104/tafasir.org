قوله : { فإنما يسرناه } ( 97 ) [ يعني القرآن .  { بلسانك } ( 97 ) يا محمد .  وهو تفسير السدي وغيره ] .  قال الحسن : لولا أن الله يسره بلسان محمد ما كانوا ليقرءوه ولا ليفهموه .  قوله : { لتبشر به } ( 97 ) بالقرآن .  { المتقين } ( 97 ) بالجنة .  { وتنذر به } ( 97 ) بالقرآن النار .  { قوما لدا } ( 97 ) .  سعيد عن قتادة قال : [ أي ] جدلاء بالباطل ( و )  ذوي لدد وخصومة .

قال يحيى : يعني فريشا ( و )  كقوله : { إذا قومك منه يصدون } إلى قوله : { بل هم قوم خاصمون }  .  وقال مجاهد : { لدا } ،  لا يستقيمون .
