{ فأجاءها المخاض } ( 23 ) .  عاصم بن حكيم أن مجاهدا قال : ألجأها المخاض .  { إلى جذع النخلة قالت يا ليتني مت قبل هذا } ( 23 ) .  قال الحسن : مما خشيت من الفضيحة .  { وكنت نسيا } ( 23 ) لا أذكر .  { منسيا } ( 23 ) لم أذكر .  سعيد عن قتادة : ( قالت ) : أس شيء لا يعرف ولا يذكر .

وحدثني حماد بن سلمة عن أبي عمران الجوني عن نوف البكالي قال : وكنت حيضة نسيتها ،  وذكر حماد المرأة النسوء ،  وقال حماد : ( النسوء الذي يظن بها حمل فلا يكون كذلك ) .

وقال الكلبي : { وكنت نسيا منسيا } قال : القوم ينزلون المنزل ثم يرتحلون وينسون الشيء فيسمى ذلك الشيء : ( النّسا ) .
