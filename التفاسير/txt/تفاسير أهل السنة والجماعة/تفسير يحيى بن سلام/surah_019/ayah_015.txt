{ وسلام عليه يوم ولد } ( 15 ) يعني حين ولد .  { ويوم يموت } ( 15 ) ( يعني ) [ و ] حين يموت .  { ويوم يبعث حيا } ( 15 ) يوم  القيامة .  وهو تفسير السدي .

سعيد عن قتادة عن الحسن أن يحيى وعيسى التقيا ،  فقال له عيسى : استغفر لي أنت خير مني .  و( قال )  له الآخر : استغفر لي ،  أنت خير مني .  فقال ( له ) [ 22أ ] عيسى : أنت خير مني .  [ قال عيسى : إني ] سلمت على/ نفسي وسلم الله عليك .  قال الحسن : عرف والله فضلها .

قال يحيى : يعني قول الله ( تبارك وتعالى ) في يحيى : { وسلام عليه يوم ولد ويم يموت ويم يبعث  حيا }  .

وقال عيسى : { قال إني عبد الله أتاني الكتاب وجعلني نبيا ( 30 ) وجعلني مباركا أين ما كنت } إلى قوله : { والسلام عليّ يوم ولدت ويوم أموت ويوم أبعث حيا ( 33 ) } .
