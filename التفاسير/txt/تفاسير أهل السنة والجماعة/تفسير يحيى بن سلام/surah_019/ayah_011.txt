قوله : { فخرج على قومه من المحراب } ( 11 ) .  قال الحسن : ( من )  المسجد .  { فأوحى إليهم } ( 11 ) أي أومأ إليهم .  وقال مجاهد : أشار إليهم  وهو واحد .  وقال السدي : { فأوحى إليهم } يقول : كتب لهم .  { أن سبحوا بكرة وعشيا } ( 11 ) يعني به الصلاة ،  صلاة الغداة وصلاة العصر .  وقال الحسن : { أن سبحوا بكرة وعشيا } ( 11 ) أي أن صلّوا لله بالغداة والعشي .
