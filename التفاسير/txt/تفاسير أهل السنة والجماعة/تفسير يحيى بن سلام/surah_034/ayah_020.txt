قوله [ عز وجل ] : { ولقد صدق عليهم إبليس ( ظنه ) } ( 20 ) يعني جميع المشركين .

{ فاتبعوه إلا فريقا  من المؤمنين }( 20 ) وذلك أنه كان يطيف بجسد آدم قبل أن ينفخ فيه الروح ،  فلما رأوه أجوف عرف أنه لا يتمالك ،  ثم وسوس بعد إلى آدم فأكل من الشجرة ،  فقال في نفسه : إن نسل هذا ( سيكون ) مثله في الضعف ،  فلذلك قال : { لأحتنكن ذريته إلا قليلا } وقال : { فبعزتك لأغوينهم أجمعين } قال : { ولا تجد أكثرهم شاكرين } وأشباه ذلك .

وبعضهم يقول : إن إبليس قال : خلقت من نار وخلق آدم من طين .  والنار ( تأكل ) الطين فلذلك ( ظن ) أنه سيضل عامتهم .

( وحدثني ) سليمان بن أرقم عن الحسن أنه كان يقرأ هذا الحرف { ولقد صدق عليهم إبليس ( ظنه ) } أي ولقد صدق عليهم ( ظن ) إبليس فيها تقديم ،  ثم قال : ظن ظنه ولم يقل ذلك بعلم ،  يقول : فصدق ظنه فيهم .

[ قرة بن خالد عن عبد الله بن القاسم : { ولقد صدق عليهم إبليس ظنه } .

وكان مجاهدا يقرأها : { ولقد صدق عليهم إبليس ظنه } يقول : صدق إبليس ظنه فيهم حيث ( جاء ) أمرهم على ما ظن .
