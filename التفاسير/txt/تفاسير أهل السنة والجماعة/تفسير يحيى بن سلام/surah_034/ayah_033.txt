{ وقال الذين استضعفوا للذين استكبروا }( 33 )

أبو حفص عن عمرو عن الحسن : قال الذين استضعفوا ،  بنو آدم ،  للذين استكبروا الشياطين .

{ وقال الذين استضعفوا للذين استكبروا بل مكر الليل والنهار }( 33 ) أي بل مكركم بالليل والنهار ،  أي ( كذبكم ) وكفركم .

{ إذ تأمروننا أن نكفر بالله }( 33 ) في تفسير الحسن .

وتفسير الكلبي :{ بل مكر الليل والنهار } بل قولكم لنا بالليل والنهار .

{ ( إذ ) تأمروننا أن نكفر بالله ونجعل له أندادا } ( 33 ) يعني أوثانهم عدلوها بالله ( فعبدوها ) دونه .

قال : { ( وأسروا ) الندامة }( 33 ) في أنفسهم يوم القيامة .

{ لما رأوا العذاب وجعلنا الأغلال في أعناق الذين كفروا هل يجزون ( إلا ) } ( 33 ) على الاستفهام .

{ ما كانوا يعملون }( 33 ) أي أنهم لا يجزون إلا ما كانوا يعملون .
