قال : { والذين سعوا }( 5 ) عملوا .

{ في آياتنا معاجزين }( 5 )

تفسير الحسن : ( يظنون ) أنهم ( سبقونا ) حتى لا نقدر عليهم فنبعثهم ( ونعذبهم ) ،  كقوله : { وما كانوا سابقين } .

وتفسير الكلبي : { معاجزين } يثبطون الناس عن الإيمان بآياتنا ولا يؤمنون بها .

[ وقال السدي : { سعوا } عملوا { في آياتنا } ،  في القرآن { معاجزين } مبطئين .  يعني يثبطون الناس عن الإيمان بالقرآن ] .

قوله [ عز وجل ] : { أولئك لهم عذاب من رجز }( 5 ) والرجز ،  العذاب .

{ أليم } ( 5 ) ( موجع ) [ لهم عذاب من عذاب موجع ] .
