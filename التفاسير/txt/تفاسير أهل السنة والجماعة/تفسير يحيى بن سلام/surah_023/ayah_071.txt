قوله : { ولو اتبع الحق أهواءهم }( 71 ) أهواء المشركين .  { لفسدت }( 71 ) يعني لهلكت .  { السماوات والأرض ومن فيهن } ( 71 ) .

وتفسير الحسن : لو كان الحق في أهوائهم ،  لوقعت أهواؤهم على هلاك السماوات والأرض ومن فيهن .

وقال بعضهم : الحق هاهنا : الله ،  كقوله : { وتواصوا بالحق } .  عني بالحق الله { وتواصوا بالصبر } ( على ) فرائضه .

قال : { بل آتيناهم بذكرهم } ( 71 ) بشرفهم ،  شرف لمن آمن به .

قال السحن وقتادة : يعني القرآن ،  أنزلنا عليهم فيه ما يأتون ،  وما يتقون ،  وما يحرمون ،  وما يحلون .  { فهم عن ذكرهم } ( 71 ) عما بينا لهم .  { معرضون } ( 71 )وقال قتادة : معرضون عن القرآن .

وقال السدي : { بل أتيناهم بذكرهم } : بشرفهم { فهم عن ذكرهم } يعني عن شرفهم { معرضون } .

قال يحيى : سمعت سفيان الثوري يذكر في هذه الآية :{ لقد أنزلنا إليكم كتابا فيه ذكركم } : فيه شرفكم .
