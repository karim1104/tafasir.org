قال الله : { فلما جاءهم الحق من عندنا }( 48 ) يعني القرآن [ وهو تفسير السدي ] .

{ قالوا لولا أوتي }( 48 ) يعنون النبي [ عليه السلام ] .

{ مثل ما أوتي موسى }( 48 ) هلا أنزل عليه القرآن جملة واحدة كما أنزلت التوراة على موسى جملة واحدة .

قال الله : { أولم يكفروا بما أوتي موسى من قبل }( 48 ) وقد كان كتاب موسى عليهم حجة في تفسير الحسن .

{ قالوا سحران تظاهرا }( 48 ) موسى ومحمد في تفسير الحسن .  وهذا قول مشركي العرب .

{ وقالوا إنا بكل كافرون }( 48 ) بالتوراة والقرآن .

عاصم [ بن حكيم ] عن إسماعيل بن أبي خالد عن سعيد بن جبير .

[ قال ] : { قالوا سحران تظاهرا } موسى وهارون .

[ المعلى عن أبي يحيى عن مجاهد قال : { قالوا لولا } هلا { أوتي مثل ما أوتي موسى } قال : هم أهل الكتاب ] .

وتفسير ( مجاهد ) [ قال ] : { قالوا لولا } ( هلا ) { أوتي مثل ما أوتي موسى } من قبل هذا .  قول يهود تأمر قريشا أن يسألوا محمدا مثل ما أوتي موسى .

يقول الله ( لمحمد ) : قل لقريش ( يقولون ) لهم : { أولم يكفروا بما/ أوتي موسى من قبل قالوا سحران تظاهرا } .  قول يهود لموسى وهارون .

وبعضهم يقرؤها : سحران تظاهرا ،  التوراة والقرآن .

{ وقالوا }( 48 ) يهود تقوله .

{ إنا بكل كافرون }( 48 ) ( كفرت ) أيضا بما أوتي محمد ( صلى الله عليه وسلم ) .
