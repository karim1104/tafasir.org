قوله [ عز وجل ] : { ولما ورد ماء مدين وجد عليه أمة ( من الناس ) } ( 23 ) جماعة من الناس .  { يسقون ووجد من دونهم امرأتين تذودان }( 23 ) [ قال قتادة : تذودان ] الناس عن شائهما .

وفي بعض ( الحروف ) : ( تذودان ) الناس عن شائهما : أي حابستين شاءهما تذودان الناس عنها في تفسير قتادة .

وقال بعضهم ( يمنعان ) غنمهما أن تختلط بأغنام الناس .

{ قال }( 23 ) لهما موسى : { ما خطبكما }( 23 ) ما أمركما ؟ { قالتا لا نسقي حتى يصدر الرعاء }( 23 ) [ قال قتادة } أي حتى يسقي الناس ثم ( نتتبع ) فضالتهم ( في ) تفسير الحسن .  { وأبونا شيخ كبير }( 23 ) [ قال السدي يعني ( كبيرا ) في السن ] .
