قوله[ عز وجل ] :{ والذين كفروا لهم نار جهنم لا يقضى عليهم فيموتوا }( 36 ) تفسير السدي : ( يعني ) لا ينزل بهم الموت فيموتوا .

قال : { ولا يخفف عنهم من عذابها } ( 36 ) وقال في آية أخرى : { ( فذوقوا ) فلن نزيدكم إلا عذابا } .

( اخبرنا ) سعيد عن قتادة أن عبد الله بن ( عمرو ) كان يقول : ما نزل في أهل النار آية هي أشد من هذه .  ( قال ) : { كذلك نجزي كل كفور }( 36 ) ( حدثنا ) سعيد عن قتادة قال : ( { كذلك نجزي كل كفور } ) كل كفور بربه .
