{ استكبارا في الأرض }( 43 ) عن عبادة الله .  { ومكر السيئ }( 43 ) الشرك وما يمكرون برسول الله [ صلى الله عليه وسلم } .  وبدينه .  وقال في آية أخرى : { وإذ يمكر بك الذين كفروا } .  قال : { ولا يحيق المكر السيئ إلا بأهله }( 43 ) وهذا وعيد لهم .

قال : { فهل ينظرون إلا سنة الأولين }( 43 ) سنة الله في الأولين كقوله : { سنة الله التي قد خلت في عباده } المشركين أنهم [ كانوا ] إذا كذبوا ( رسولهم ) أهلكهم ( الله ) ( فيؤمنون ) عند نزول العذاب ،  فلا يقبل ذلك منهم .

قال : { فلن تجد لسنة الله تبديلا }( 43 ) لا ( تبدل ) بها غيرها .  { ولن تجد لسنة الله تحويلا }( 43 ) لا تحول .  وأخّر عذاب كفار آخر هذه الأمة إلى النفخة الأولى بالاستئصال ،  بها يكون هلاكهم .  وقد عذب أوائل مشركي هذه الأمة بالسيف يوم بدر .
