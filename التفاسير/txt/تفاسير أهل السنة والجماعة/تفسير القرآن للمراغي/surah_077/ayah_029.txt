{ انطلقوا إلى ما كنتم به تكذبون ( 29 ) انطلقوا إلى ظل ذي ثلاث شعب ( 30 ) لا ظليل ولا يغني من اللهب ( 31 ) إنها ترمي بشرر كالقصر ( 32 ) كأنه جمالات صفر ( 33 ) ويل يومئذ للمكذبين ( 34 ) هذا يوم لا ينطقون ( 35 ) ولا يؤذن لهم فيعتذرون ( 36 ) ويل يومئذ للمكذبين ( 37 ) هذا يوم الفصل جمعناكم والأولين ( 38 ) فإن كان لكم كيد فكيدون ( 39 ) ويل يومئذ للمكذبين } [ المرسلات : 29-40 ] .
