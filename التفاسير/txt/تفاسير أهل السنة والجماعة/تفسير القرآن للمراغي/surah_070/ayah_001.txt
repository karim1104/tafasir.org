بسم الله الرحمن الرحيم

{ سأل سائل بعذاب واقع ( 1 ) للكافرين ليس له دافع ( 2 ) من الله ذي المعارج ( 3 ) تعرج الملائكة والروح إليه في يوم كان مقداره خمسين ألف سنة ( 4 ) فاصبر صبرا جميلا ( 5 ) إنهم يرونه بعيدا ( 6 ) ونراه قريبا ( 7 ) يوم تكون السماء كالمهل ( 8 ) وتكون الجبال كالعهن ( 9 ) ولا يسأل حميم حميما ( 10 ) يبصرونهم يود المجرم لو يفتدي من عذاب يومئذ ببنيه ( 11 ) وصاحبته وأخيه ( 12 ) وفصيلته التي تأويه ( 13 ) ومن في الأرض جميعا ثم ينجيه ( 14 ) كلا إنها لظى ( 15 ) نزاعة للشوى ( 16 ) تدعوا من أدبر وتولى ( 17 ) وجمع فأوعى } [ المعارج : 1-18 ] .

شرح المفردات : سأل سائل : أي دعا داع ، من قولك : دعا بكذا إذا استدعاه وطلبه ، كما جاء في قوله : { يدعون فيها بكل فاكهة آمنين } [ الدخان : 55 ] ليس له دافع : أي إنه واقع لا محالة .

/م1

الإيضاح :{ سأل سائل بعذاب واقع* للكافرين ليس له دافع } أي طلب طالب عذابا واقعا لا محالة ، سواء طلب أم لم يطلب ، لأنه نازل بالكافرين في الآخرة لا يدفعه عنهم أحد ، فلماذا هم يطلبونه استهزاء ؟ .
