{ وَمَا عَمِلَتْهُ أَيْدِيهِمْ } على ثمره أي ليأكلوا من الثمر { وَمَا عَمِلَتْهُ أَيْدِيهِمْ } بالحرث والزراعة والغراسة، وقيل { مَا } نافية وقرئ { مَا عَمِلَتْ } من غيرها وما على هذا معطوفة { ٱلأَزْوَاجَ } يعني أصناف المخلوقات ثم فسرها بقوله: { مِمَّا تُنبِتُ ٱلأَرْضُ } وما بعده، فمن في المواضع الثلاثة للبيان { وَمِمَّا لاَ يَعْلَمُونَ } يعني أشياء لا يعلمها بنو آدم كقوله: [النحل: 8].
