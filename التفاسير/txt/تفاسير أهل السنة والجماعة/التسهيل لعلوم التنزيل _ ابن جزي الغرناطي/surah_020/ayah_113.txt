{ وَعَنَتِ ٱلْوُجُوهُ } أي ذلت يوم القيامة { وَلاَ هَضْماً } أي بخساً ونقصاً لحسناته { أَوْ يُحْدِثُ لَهُمْ ذِكْراً } أي تذكراً، وقيل: شرفاً وهو هنا بعيد { وَلاَ تَعْجَلْ بِٱلْقُرْآنِ مِن قَبْلِ أَن يُقْضَىٰ إِلَيْكَ وَحْيُهُ } أي إذا أقرأك جبريل القرآن؛ فاستمع إليه واصبر حتى يفرغ، وحينئذ تقرأه أنت. فالآية: كقوله [القيامة: 16]، وقيل كان النبي صلى الله عليه وسلم إذا أوحي إليه القرآن يأمر بكتبه في الحين، فأمر بأن يتأنى حتى تفسر له المعاني، والأول أشهر.
