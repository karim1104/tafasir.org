{ يُنادونهم } أي : ينادي المنافقون المؤمنين : { ألم نكن معكم } في الدنيا ؟ يريدون موافقتهم لهم في الظاهر ،  { قالوا } أي : المؤمنون : { بلى } كنتم معنا في الظاهر { ولكنكم فتنتم أنفسَكم } أي : محنتموها وأهلكتموها بالنفاق والكفر ،  { وتربصتم } بالمؤمنين الدوائر ،  { وارتبتم } في أمر الدين { وغرتكم الأمانيُّ } الفارغة ،  التي من جملتها أطماعكم في انتكاس الإسلام ،  أو : طول الأمل وامتداد الأعمار { حتى جاء أمرُ الله } ؛ الموت ،  { وغرَّكم بالله } الكريم { الغَرُورُ } أي : الشيطان بأنَّ الله غفور كريم لا يعذبكم ،  أو : بأنه لا بعث ولا حساب .
