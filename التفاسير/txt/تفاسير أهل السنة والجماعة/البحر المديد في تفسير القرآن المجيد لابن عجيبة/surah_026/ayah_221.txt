ثم كمل قوله : { وما تنزلت به الشياطين } ،  فقال :

{ هَلْ أُنَبِّئُكُمْ عَلَى مَن تَنَزَّلُ الشَّيَاطِينُ } * { تَنَزَّلُ عَلَى كُلِّ أَفَّاكٍ أَثِيمٍ } * { يُلْقُونَ السَّمْعَ وَأَكْثَرُهُمْ كَاذِبُونَ } * { وَالشُّعَرَآءُ يَتَّبِعُهُمُ الْغَاوُونَ } * { أَلَمْ تَرَ أَنَّهُمْ فِي كُلِّ وَادٍ يَهِيمُونَ } * { وَأَنَّهُمْ يَقُولُونَ مَا لاَ يَفْعَلُونَ } * { إِلاَّ الَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ وَذَكَرُواْ اللَّهَ كَثِيراً وَانتَصَرُواْ مِن بَعْدِ مَا ظُلِمُواْ وَسَيَعْلَمْ الَّذِينَ ظَلَمُواْ أَيَّ مُنقَلَبٍ يَنقَلِبُونَ } .

يقول الحق جل جلاله : { هل أُنَبِّئُكم } أي : أخبركم أيها المشركون { على من تَنزَّلُ الشياطينُ } ،  ودخل حرف الجار على  " من "  الاستفهامية ؛ لأنها ليست للاستفهام بالأصالة .
