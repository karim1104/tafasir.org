ثم رجع إلى الكلام مع المشركين والرد عليهم ،  فقال :

{ قُلِ ادْعُواْ الَّذِينَ زَعَمْتُم مِّن دُونِهِ فَلاَ يَمْلِكُونَ كَشْفَ الضُّرِّ عَنْكُمْ وَلاَ تَحْوِيلاً } * { أُولَائِكَ الَّذِينَ يَدْعُونَ يَبْتَغُونَ إِلَى رَبِّهِمُ الْوَسِيلَةَ أَيُّهُمْ أَقْرَبُ وَيَرْجُونَ رَحْمَتَهُ وَيَخَافُونَ عَذَابَهُ إِنَّ عَذَابَ رَبِّكَ كَانَ مَحْذُوراً }

يقول الحقّ جلّ جلاله : { قلْ } لهم : { ادعوا الذين زعمتم } أنهم آلهة تعبدونهم { من دونه } كالملائكة والمسيح وعُزير ،  أو كالأصنام والأوثان ،  { فلا يملكون } ؛ لا يستطيعون { كشف الضر عنكم } ،  كالمرض والفقر والقحطِ ،  { ولا تحويلاً } لذلك عنكم إلى غيركم .
