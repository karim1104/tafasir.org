ثم ذكر استعجالهم البعث ،  فقال :

{ وَيَقُولُونَ مَتَى هَذَا الْوَعْدُ إِن كُنتُمْ صَادِقِينَ } * { مَا يَنظُرُونَ إِلاَّ صَيْحَةً وَاحِدَةً تَأْخُذُهُمْ وَهُمْ يَخِصِّمُونَ } * { فَلاَ يَسْتَطِيعُونَ تَوْصِيَةً وَلاَ إِلَى أَهْلِهِمْ يَرْجِعُونَ } * { وَنُفِخَ فِي الصُّورِ فَإِذَا هُم مِّنَ الأَجْدَاثِ إِلَى رَبِّهِمْ يَنسِلُونَ } * { قَالُواْ يا وَيْلَنَا مَن بَعَثَنَا مِن مَّرْقَدِنَا هَذَا مَا وَعَدَ الرَّحْمانُ وَصَدَقَ الْمُرْسَلُونَ } * { إِن كَانَتْ إِلاَّ صَيْحَةً وَاحِدَةً فَإِذَا هُمْ جَمِيعٌ لَّدَيْنَا مُحْضَرُونَ } * { فَالْيَوْمَ لاَ تُظْلَمُ نَفْسٌ شَيْئاً وَلاَ تُجْزَوْنَ إِلاَّ مَا كُنْتُمْ تَعْمَلُونَ } .

يقول الحق جلّ جلاله : { ويقولون }  استهزاء  : { متى هذا الوعْدُ } أي : وعد البعث والقيامة { إِن كنتم صادقين } فيما تقولون .   خطاب للنبي صلى الله عليه وسلم وأصحابه .
