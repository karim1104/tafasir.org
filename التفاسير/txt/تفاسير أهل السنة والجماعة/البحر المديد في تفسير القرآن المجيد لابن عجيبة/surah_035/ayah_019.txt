ثم ضرب المثل لمن تزكى ،  ومن لم يتزك ،  فقال :

{ وَمَا يَسْتَوِي الأَعْمَى وَالْبَصِيرُ } * { وَلاَ الظُّلُمَاتُ وَلاَ النُّورُ } * { وَلاَ الظِّلُّ وَلاَ الْحَرُورُ } * { وَمَا يَسْتَوِي الأَحْيَآءُ وَلاَ الأَمْوَاتُ إِنَّ اللَّهَ يُسْمِعُ مَن يَشَآءُ وَمَآ أَنتَ بِمُسْمِعٍ مَّن فِي الْقُبُورِ } * { إِنْ أَنتَ إِلاَّ نَذِيرٌ } * { إِنَّآ أَرْسَلْنَاكَ بِالْحَقِّ بَشِيراً وَنَذِيراً وَإِن مِّنْ أُمَّةٍ إِلاَّ خَلاَ فِيهَا نَذِيرٌ } .

يقول الحق جلّ جلاله : { وما يستوي الأعمى والبصيرُ } أي : لا يستوي الكافر والمؤمن ،  أو الجاهل والعالم .   وقيل : هما مثلان للصنم ولله تعالى .
