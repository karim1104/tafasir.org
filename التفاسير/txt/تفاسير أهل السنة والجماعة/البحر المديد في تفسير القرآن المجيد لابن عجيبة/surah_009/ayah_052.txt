{ قل } لهم : { هل تربّصُون } أي : تنتظرون { بنا إحدى الحُسنيين } أي : إلا إحدى العاقبتين اللتين كل منهما حسنى : إما النصر وإما الشهادة ،  { ونحنُ نتربصُ بكم } أيضاً إحدى العاقبتين السُوأتين : إما { أن يصيبَكم اللَّهُ بعذابٍ من عنده } بقارعة من السماء ،  { أو بأيدينا } أي : أو بعذاب بأيدينا ،  وهو القتل على الكفر ،  { فتربصُوا } ما هو عاقبتنا ،  { إنا معكم مُتَربِّصون } ما هو عاقبتكم .
