{ ومن آياته } أيضاً { أنك ترى الأرضَ خاشعةً } ؛ يابسةً مغبرة .   والخشوع : التذلُّل ،  فاستعير للأرض إذا كانت قحطة لا نبات فيها ،  { فإِذا أنزلنا عليها الماء } ؛ المطر { اهتزّتْ } أي : تحركت { ورَبَتْ } ؛ انتفخت ؛ لأن النبات إذا دنا أن يظهر ارتفعت به وانتفخت ،  ثم تصدّعت عن النبات ،  وقيل : تزخرفت وارتفعت بارتفاع نباتها ،  { إِنَّ الذي أحياها لمحيي الموتَى } بالبعث ،  { إِنه على كل شيءٍ قديرٌ } ،  ومن جملة الأشياء : البعث والحساب .
