ثم استثنى المخلصين ،  فقال :

{ إِلاَّ عِبَادَ اللَّهِ الْمُخْلَصِينَ } * { أُوْلَئِكَ لَهُمْ رِزْقٌ مَّعْلُومٌ } * { فَوَاكِهُ وَهُم مُّكْرَمُونَ } * { فِي جَنَّاتِ النَّعِيمِ } * { عَلَى سُرُرٍ مُّتَقَابِلِينَ } * { يُطَافُ عَلَيْهِمْ بِكَأْسٍ مِّن مَّعِينٍ } * { بَيْضَآءَ لَذَّةٍ لِّلشَّارِبِينَ } * { لاَ فِيهَا غَوْلٌ وَلاَ هُمْ عَنْهَا يُنزَفُونَ } * { وَعِندَهُمْ قَاصِرَاتُ الطَّرْفِ عِينٌ } * { كَأَنَّهُنَّ بَيْضٌ مَّكْنُونٌ } * { فَأَقْبَلَ بَعْضُهُمْ عَلَى بَعْضٍ يَتَسَآءَلُونَ }

يقول الحق جلّ جلاله : { إِلا عبادَ الله المخلصين }  بفتح اللام ،  وكسرها  أي : لكن عباد الله المخلصين في أعمالهم ،  أو : الذين أخلصهم الله ونجاهم من الشرك ،  فليسوا مع أولئك المعذّبين .
