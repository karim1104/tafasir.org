بسم الله الرحمان الرحيم

{ الم } * { تَنزِيلُ الْكِتَابِ لاَ رَيْبَ فِيهِ مِن رَّبِّ الْعَالَمِينَ } * { أَمْ يَقُولُونَ افْتَرَاهُ بَلْ هُوَ الْحَقُّ مِن رَّبِّكَ لِتُنذِرَ قَوْماً مَّآ أَتَاهُم مِّن نَّذِيرٍ مِّن قَبْلِكَ لَعَلَّهُمْ يَهْتَدُونَ }

/م1

يقول الحق جل جلاله : { الم } ؛ أيها المصطفى المقرب ،  هذا الذي تتلوه هو { تنزيلُ الكتاب لا ريبَ فيه } .

/خ3
