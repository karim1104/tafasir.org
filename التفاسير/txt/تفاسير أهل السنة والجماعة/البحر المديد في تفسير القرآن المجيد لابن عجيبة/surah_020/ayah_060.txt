ثم ذكر جمعهم ،  وما كان من شأنهم ،  فقال :

{ فَتَوَلَّى فِرْعَوْنُ فَجَمَعَ كَيْدَهُ ثُمَّ أَتَى } * { قَالَ لَهُمْ مُّوسَى وَيْلَكُمْ لاَ تَفْتَرُواْ عَلَى اللَّهِ كَذِباً فَيُسْحِتَكُم بِعَذَابٍ وَقَدْ خَابَ مَنِ افْتَرَى } * { فَتَنَازَعُواْ أَمْرَهُمْ بَيْنَهُمْ وَأَسَرُّواْ النَّجْوَى } * { قَالُواْ إِنْ هَذَانِ لَسَاحِرَانِ يُرِيدَانِ أَن يُخْرِجَاكُمْ مِّنْ أَرْضِكُمْ بِسِحْرِهِمَا وَيَذْهَبَا بِطَرِيقَتِكُمُ الْمُثْلَى } * { فَأَجْمِعُواْ كَيْدَكُمْ ثُمَّ ائْتُواْ صَفّاً وَقَدْ أَفْلَحَ الْيَوْمَ مَنِ اسْتَعْلَى } * { قَالُواْ يا مُوسَى إِمَّآ أَن تُلْقِيَ وَإِمَّآ أَن نَّكُونَ أَوَّلَ مَنْ أَلْقَى } * { قَالَ بَلْ أَلْقُواْ فَإِذَا حِبَالُهُمْ وَعِصِيُّهُمْ يُخَيَّلُ إِلَيْهِ مِن سِحْرِهِمْ أَنَّهَا تَسْعَى } * { فَأَوْجَسَ فِي نَفْسِهِ خِيفَةً مُّوسَى } * { قُلْنَا لاَ تَخَفْ إِنَّكَ أَنتَ الأَعْلَى } * { وَأَلْقِ مَا فِي يَمِينِكَ تَلْقَفْ مَا صَنَعُواْ إِنَّمَا صَنَعُواْ كَيْدُ سَاحِرٍ وَلاَ يُفْلِحُ السَّاحِرُ حَيْثُ أَتَى }

يقول الحقّ جلّ جلاله : { فتولَّى فرعونُ } أي : انصرف عن المجلس ،  ورجع إلى وطنه ،  { فجمعَ كيده } أي : حِيلَه وسَحرته ؛ ليكيد به موسى عليه السلام ،  { ثم أتى } الموعد ،  ومعه ما جمعه من كيده وسحرته ،  وسيأتي عددهم .
