ثم ذكر زكريا عليه السلام ،  فقال :

{ وَزَكَرِيَّآ إِذْ نَادَى رَبَّهُ رَبِّ لاَ تَذَرْنِي فَرْداً وَأَنتَ خَيْرُ الْوَارِثِينَ } * { فَاسْتَجَبْنَا لَهُ وَوَهَبْنَا لَهُ يَحْيَى وَأَصْلَحْنَا لَهُ زَوْجَهُ إِنَّهُمْ كَانُواْ يُسَارِعُونَ فِي الْخَيْرَاتِ وَيَدْعُونَنَا رَغَباً وَرَهَباً وَكَانُواْ لَنَا خاشِعِينَ }

يقول الحقّ جلّ جلاله : { و } اذكر خبر { زكريا إِذ نادى ربَّهُ } في طلب الولد ،  وقال : { ربِّ لا تذرني فَرْدًا } ؛ وحيدًا بلا ولد يرثني ،  ثم ردّ أمره إليه ؛ مستسلمًا ،  فقال : { وأنت خيرُ الوارثين } ،  فحسبي أنت ،  وإِنْ لم ترزقني وارثًا فلا أبالي ؛ فإنك خير وارث .
