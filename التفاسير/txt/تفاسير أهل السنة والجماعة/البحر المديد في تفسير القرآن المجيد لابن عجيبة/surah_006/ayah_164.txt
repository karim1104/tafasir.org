{ قل } لهم : { أغير الله أبغي ربًا } فأشرك مع الله ،  { وهو ربُّ كل شيء } ؛ لأن كل شيء مربوب لا يصلح للربوبية .   وهو جواب عن دعائهم له إلى عبادة آلهتهم .   { ولا تَكسِبُ كلُّ نفس } من شرك أو غيره { إلا عليها } وزره ،  فلا ينفعني ضمانكم وكفالتكم من عقاب ربي ،  وهو رد على الكفار حيث قالوا له : اعبد آلهتنا ونحن نتكفل لك بكل تباعة تتوقعها في دنياك وأخراك ،  ثم أوضح ذلك بقوله : { ولا تزر } أي : تحمل نفس { وازرة } أي : آثمة { وزر } نفس { أخرى } أي : لا يحمل أحد ذنوب أحد ،  { ثم إلى ربكم مرجعكم } بالبعث والحساب ،  { فينبئُكم } ،  أي : يُخبركم { بما كنتم فيه تختلفون } من أمر الدين ؛ فيبين الرشد من الغي ،  والمحق من المبطل .
