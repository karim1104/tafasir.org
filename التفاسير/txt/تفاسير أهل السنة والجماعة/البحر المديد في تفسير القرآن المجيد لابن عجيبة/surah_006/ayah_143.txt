و{ ثمانية أزواج } : بدل من حَمولة ،  و{ من الضأن اثنين } : بدل من ثمانية .

ثم فصلها فقال : { ثمانية أزواج } ؛ ذكر وأنثى من كل صنف ،  والصنف : ما معه آخر من جنسه يزاوجه ،  ثم بيَّنها فقال : { من الضأن اثنين } ؛ ذكر وأنثى ؛ كبش ونعجة ،  { ومن المعز اثنين } ؛ التيس وهو الذكر ،  والعنز وهي الأنثى ،  { قل } لهم { آلذكرين } أي : ذكر الضأن والمعز ،  { حرَّم أم الأنثيين } منهما ؟ { أما اشتملت عليه أرحام الأنثيين } من الأجنة ذكرًا كان أو أنثى ؟ { نبّئوني بعلم } يدل على أن الله تعالى حرم شيئًا من ذلك ،  { إن كنتم صادقين } في دعوى التحريم عليه .
