ثم هددهم بعد تبيين عنادهم ،  فقال :

{ وَإِن يَرَوْاْ كِسْفاً مِّنَ السَّمَاءِ سَاقِطاً يَقُولُواْ سَحَابٌ مَّرْكُومٌ }*{ فَذَرْهُمْ حَتَّى يُلاَقُواْ يَوْمَهُمُ الَّذِي فِيهِ يُصْعَقُونَ }*{ يَوْمَ لاَ يُغْنِي عَنْهُمْ كَيْدُهُمْ شَيْئاً وَلاَ هُمْ يُنصَرُونَ }*{ وَإِنَّ لِلَّذِينَ ظَلَمُواْ عَذَاباً دُونَ ذَلِكَ وَلَكِنَّ أَكْثَرَهُمْ لاَ يَعْلَمُونَ } .

يقول الحق جلّ جلاله : { وإِن يَرَوا كِسْفاً } قطعة { من السماء ساقطاً } عليهم لتعذيبهم ،  { يقولوا } من فرط طغيانهم وعنادهم : هذا { سَحَابٌ مركومٌ } أي : تَرَاكَم بعضها على بعض لمطرنا ،  ولم يُصدقوا أنه ساقط عليهم لعذابهم ،  يعني : أنهم بلغوا في الطغيان بحث لو أسقطناه عليهم حسمنا قالوا : { أَوْ تُسْقِطَ السَّمَاءَ كَمَا زَعَمْتَ عَلَيْنَا كِسَفاً } [ الإسراء : 92 ] لعاندوا وقالوا سحاب مركوم .

/خ47
