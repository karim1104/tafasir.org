{ ثُمَّ أَنشَأْنَا مِن بَعْدِهِمْ قُرُوناً آخَرِينَ } * { مَا تَسْبِقُ مِنْ أُمَّةٍ أَجَلَهَا وَمَا يَسْتَأْخِرُونَ } * { ثُمَّ أَرْسَلْنَا رُسُلَنَا تَتْرَى كُلَّ مَا جَآءَ أُمَّةً رَّسُولُهَا كَذَّبُوهُ فَأَتْبَعْنَا بَعْضَهُمْ بَعْضاً وَجَعَلْنَاهُمْ أَحَادِيثَ فَبُعْداً لِّقَوْمٍ لاَّ يُؤْمِنُونَ }

قلت : القرن : أهل العصر ،  سُموا به ؛ لِقران بعضهم البعض .

يقول الحق جل جلاله : { ثم أنشأنا من بعدهم } أي : من بعد قوم هود ،  { قروناً آخرين } ؛ قوم صالح ولوط وشعيب وغيرهم .
