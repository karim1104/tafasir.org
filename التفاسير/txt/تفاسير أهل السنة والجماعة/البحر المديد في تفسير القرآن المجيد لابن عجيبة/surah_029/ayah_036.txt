ثم ذكر قصة شعيب ،  فقال :

{ وَإِلَى مَدْيَنَ أَخَاهُمْ شُعَيْباً فَقَالَ يا قَوْمِ اعْبُدُواْ اللَّهَ وَارْجُواْ الْيَوْمَ الأَخِرَ وَلاَ تَعْثَوْاْ فِي الأَرْضِ مُفْسِدِينَ } * { فَكَذَّبُوهُ فَأَخَذَتْهُمُ الرَّجْفَةُ فَأَصْبَحُواْ فِي دَارِهِمْ جَاثِمِينَ }

يقول الحق جل جلاله : { و } أرسلنا { إلى مدينَ أخاهم شعيباً فقال يا قوم اعبدوا الله } وحده ،  { وارجُوا اليومَ الآخر } أي : خافوه ،  واعملوا ما ترجون به الثواب فيه ،  { ولا تعثوا في الأرض مفسدين } ؛ قاصدين الفساد .
