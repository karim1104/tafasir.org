و{ هؤلاء } : مبتدأ ،  وفي اسم الإشارة تحقير لهم ،  و{ قومنا } : عَطْفُ بيانٍ له .   و{ اتخذوا } : خبر .

{ هؤلاء قومُنَا } قد { اتخذوا من دونه آلهةً } ،  فيه معنى الإنكار ،  { لولا } : هلا { يأتونَ عليهم } : على ألوهيتهم { بسلطان بَيِّن } : بحجة ظاهرة ،  { فمن أظلمُ } أي : لا أحد أظلم { ممن افترى على الله كذبًا } بنسبة الشريك إليه ؛ فإنه أظلم من كل ظالم .
