وجملة { وما يشعرون } حالية ،  أي : غير شاعرين ،  والشعور : التفطن ،  وفعله من باب كَرُمَ ونَصَرَ .   وليت شعري : أي : ليت فطنتي تدرك هذا .

{ يُخَادِعُونَ } بزعمهم { اللَّهَ والَّذينَ آمَنُوا } بما يظهرون من الإيمان ،  { وَمَا يَخْدَعُونَ } في الحقيقة { إلاَّ أَنفُسَهُمْ } ؛ لأن وبال خداعهم راجع إليهم ،  { وَمَا يَشْعُرُونَ } أن خداعهم وبال عليهم ،  وإنما حصلت لهم هذه المخادعة لأن { في قُلُوبِهِم مرض } .
