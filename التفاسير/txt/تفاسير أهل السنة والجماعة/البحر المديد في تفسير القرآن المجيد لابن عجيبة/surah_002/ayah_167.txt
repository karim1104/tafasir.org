و{ حسَرات } : حال ،  إن كانت بصرية ،  على مذهب أهل السنّة ،  أو مفعول ثالث إن كانت عِلمية على مذهب المعتزلة القائلين بعدم تشخص الأعمال .

{ وقال } حينئذٍ الضعفاء { الذين اتبعوا } شياطينهم في الكفر والضلال : { لو أن لنا كَرَّة } أي : رجعة للدنيا { فنتبرأ منهم } أي : من كبرائهم { كما تبرءوا منا } اليوم .   { كذلك } أي : مثل ذلك الإبراء الفظيع { يريهم الله أعمالهم حسرات } ونَدَامات { عليهم } فيدخلون النار على سبيل الخلود ،  { وما هم بخارجين من النار } .
