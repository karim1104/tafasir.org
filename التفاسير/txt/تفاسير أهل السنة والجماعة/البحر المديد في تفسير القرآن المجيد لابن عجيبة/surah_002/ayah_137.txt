والباء في { بمثل } : يحتمل أن تكون زائدة كقوله تعالى : { جَزَآءُ سَيِّئَةِ بِمِثْلِهَا } [ يونس : 27 ] ،  أو { مثل } مُقْحَم ،  أي : فإن آمنوا بما آمنتم به ،  كقوله تعالى : { وَشَهِدَ شَاهِدٌ مِّن بَنِى إِسْرَائيلَ عَلَى مِثْلِهِ } [ الأحقاف : 10 ] .   والشقاق : المخالفة ،  كأن كل واحد من المتخالفين في شق غير شق الآخر .

يقول الحقّ جلّ جلاله : { فإن آمنوا } أي : أهل الكتاب إيماناً مثل إيمانكم ،  { فقد اهتدوا } إلى الحق والصواب ،  وإن أعرضوا عن ذلك فاتركهم حتى نأمرك فيهم ،  { فإنما هم في شقاق } وخلاف لك ،  فلا تهتم بشأنهم ،  { فسيكفيكهم الله } أي سيكفيك شرهم وينصرك عليهم ،  { وهو السميع } لدعائكم ،  { العليم } بإخلاصكم .
