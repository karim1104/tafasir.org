{ وإذ قال موسى لقومه اذكروا نعمةَ الله عليكم إذ أنجاكم } : حين أنجاكم { من آلِ فرعونَ } : رهطه ،  { يسومونكم } : يُولونكم { سُوء العذابِ } : أقبحه يستعبدونكم ويُكلفونكم مشاق الأعمال ،  { ويُذبِّحُون أبناءكم ويستحْيون نساءكم } ،  قال البيضاوي : المراد بالعذاب هنا غير المراد به في سورتَيْ البقرة والأعراف ؛ لأنه هناك مفسر بالتذبيح والقتل ،  ومعطوف عليه هنا ،  فهو هنا إما جنس العذاب ،  أو استعبادهم واستعمالهم بالأعمال الشاقة .   ه .   { وفي ذلكم } الامتحان { بلاء } أي : ابتلاء { من ربكم عظيم } ؛ اختبركم به حتى أنقذكم منه ،  ليعظم شكركم ،  أو : في ذلك الإنجاء بلاء ،  أي : نعمة واختبار عظيم ،  لينظر كيف تعملون في شكر هذه النعمة .
