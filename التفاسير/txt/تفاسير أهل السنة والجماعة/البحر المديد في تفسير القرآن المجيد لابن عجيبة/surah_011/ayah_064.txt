ثم ذكر معجزة الناقة ،  فقال :

{ وَيا قَوْمِ هَذِهِ نَاقَةُ اللَّهِ لَكُمْ آيَةً فَذَرُوهَا تَأْكُلْ فِيا أَرْضِ اللَّهِ وَلاَ تَمَسُّوهَا بِسُواءٍ فَيَأْخُذَكُمْ عَذَابٌ قَرِيبٌ } * { فَعَقَرُوهَا فَقَالَ تَمَتَّعُواْ فِي دَارِكُمْ ثَلاَثَةَ أَيَّامٍ ذالِكَ وَعْدٌ غَيْرُ مَكْذُوبٍ } * { فَلَمَّا جَآءَ أَمْرُنَا نَجَّيْنَا صَالِحاً وَالَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مِّنَّا وَمِنْ خِزْيِ يَوْمِئِذٍ إِنَّ رَبَّكَ هُوَ الْقَوِيُّ الْعَزِيزُ } * { وَأَخَذَ الَّذِينَ ظَلَمُواْ الصَّيْحَةُ فَأَصْبَحُواْ فِي دِيَارِهِمْ جَاثِمِينَ } * { كَأَن لَّمْ يَغْنَوْاْ فِيهَآ أَلاَ إِنَّ ثَمُودَ كَفرُواْ رَبَّهُمْ أَلاَ بُعْداً لِّثَمُودَ }

قلت :  " آية "  : نصبت على الحال ،  والعامل فيها : معنى الإشارة .   و( لكم ) : حال منها ،  تقدمت عليها لتنكيرها .

يقول الحق جل جلاله : قال صالح لقومه بعد ظهور آية الناقة ،  وقد تقدم في الأعراف قصتها : { هذه ناقةُ الله لكم آيةً } تدل على صدقي ،  { فذرُوها تأكل في أرض الله } ؛ أي : ترعى نباتها وتشرب ماءها ،  { ولا تمسوها بسوء فيأخذكم عذابٌ قريب } : عاجل ،  لا يتأخر عن مسكم لها بالسوء إلا ثلاثة أيام .
