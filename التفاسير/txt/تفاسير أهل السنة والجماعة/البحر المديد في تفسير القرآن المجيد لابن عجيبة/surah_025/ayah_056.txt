ثم ذكر شأن الواسطة ،  التي هي سبب لركوب البحرين ،  فقال :

{ وَمَآ أَرْسَلْنَاكَ إِلاَّ مُبَشِّراً وَنَذِيراً } * { قُلْ مَآ أَسْأَلُكُمْ عَلَيْهِ مِنْ أَجْرٍ إِلاَّ مَن شَآءَ أَن يَتَّخِذَ إِلَى رَبِّهِ سَبِيلاً }

يقول الحق جل جلاله : { وما أرسلناك } يا محمد { إلا مبشراً } للمؤمنين { ونذيراً } للكافرين .
