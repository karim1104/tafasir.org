قرر تحقيق الرسالة والوحدانية ،  فقال : { قُلْ إِنَّمَآ أَنَاْ مُنذِرٌ وَمَا مِنْ إِلَهٍ إِلاَّ اللَّهُ الْوَاحِدُ الْقَهَّارُ }  :

يقول الحق جلّ جلاله : { قُلْ } يا محمد للمشركين : { إِنما أنا مُنذِر } من جهته تعالى ،  أُنذركم عذابه ،  { وما من إِلهٍ } في الوجود { إِلا اللهُ الواحدُ } الذي لا يقبل الشركة أصلاً ،  { القهَّارُ } لكل شيء سواه .
