{ ذلك } أي : نصرُ المؤمنين وهلاكُ الكافرين في الحال أو المآل { بأنَّ اللّهَ مولى الذين آمنوا } أي : ناصِرُهم ومعِزَّهُم { وأنَّ الكافرين لا مولى لهم } فيدفع عنهم ما حَلّ بهم من العقوبة ،  ولا يخالف هذا قوله : { ثُمَّ رُدُّواْ إِلَى اللَّهِ مَوْلاَهُمُ الْحَقِّ } [ الأنعام : 62 ] لأن المولى هناك بمعنى المالك .
