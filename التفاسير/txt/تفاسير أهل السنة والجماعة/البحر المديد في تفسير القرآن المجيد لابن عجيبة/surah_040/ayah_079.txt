ثم ذكرهم بالنعم الحسية ،  فقال :

{ اللَّهُ الَّذِي جَعَلَ لَكُمُ الأَنْعَامَ لِتَرْكَبُواْ مِنْهَا وَمِنْهَا تَأْكُلُونَ } * { وَلَكُمْ فِيهَا مَنَافِعُ وَلِتَبْلُغُواْ عَلَيْهَا حَاجَةً فِي صُدُورِكُمْ وَعَلَيْهَا وَعَلَى الْفُلْكِ تُحْمَلُونَ } * { وَيُرِيكُمْ آيَاتِهِ فَأَيَّ آيَاتِ اللَّهِ تُنكِرُونَ } .

يقول الحق جلّ جلاله : { الله الذي جعل } ؛ خلق { لكم الأنعامَ } ؛ الإبل { لتركبوا منها ومنها تأكلون } أي : لتركبوا بعضها ،  وتأكلوا بعضها ،  وليس المراد : أن الركوب والأكل مختص ببعض معين منها ،  بحيث لا يجوز تعلُّقه بالآخر ،  بل على أن بعضاً منها صالح لكل منهما .
