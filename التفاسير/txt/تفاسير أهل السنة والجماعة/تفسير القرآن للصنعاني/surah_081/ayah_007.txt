عبد الرزاق قال :  أنا معمر عن قتادة في قوله تعالى[  :  {  وإذا النفوس زوجت } قال :  بأشكالهم .

عبد الرزاق عن الثوري عن سماك بن حرب عن النعمان بن بشير قال :  سمعت عمر يقول :  {  وإذا النفوس زوجت } قال :  هما الرجلان يعملان العمل يدخلان به الجنه أو النار .   عبد الرزاق عن الثوري عن أبيه عن الربيع بن خثيم في قوله تعالى :  {  إذا الشمس كورت } قال :  رمي بها {  وإذا النجوم انكدرت } قال :  تناثرت {  وإذا البحار سجرت } قال :  فاضت ] {  وإذا النفوس زوجت } قال :  يجيء المرء إلا مع صاحب عمله يقول :  مع شكله ،   {  وإذا العشار عطلت } يقول :  لم تحلب ولم تصر وتخلى منها أهلها ،   {  وإذا الجحيم سعرت } {  وإذا الجنة أزلفت } ،   قال :  إلى هاتين ما جرى الحديث فريق في الجنة وفريق في السعير .
