وقوله تعالى : ( فتلقى آدم من ربه كلمات ) التلقي : هو قبول عن فطنة وفهم دليل : فتلقى هو [ أي : تعلم ] (  ) : ( ظلمنا أنفسنا ) (  ) إلى آخره .

قال عبيد بن عمير : هي كلمات قالها آدم حين ابتلاه الله بالمعصية .

( من ربه كلمات ) قال ابن عباس والأكثرون : الكلمات هي قوله : ربنا أي : تعلم بالمعصية يارب  هذا شيء كتبته عليَّ [ أم ] (  ) ابتدعته من تلقاء نفسي ؟ فقال : بل شيء كتبته عليك .   فقال آدم : ( فكما ) (  ) كتبته علي فاغفره .

( فتاب عليه ) فقبل توبته ( إنه هو التواب الرحيم ) هو القابل للتوبة من العباد ؛ الرحيم بهم .
