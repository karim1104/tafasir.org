{ ولكل أمة } من الأمم الماضية .   { رسول } يبعث إليهم ليدعوهم إلى الحق .   { فإذا جاء رسولهم } بالبينات فكذبوه .   { قُضي بينهم } بين الرسول ومكذبيه .   { بالقسط } بالعدل فأنجى الرسول وأهلك المكذبون .   { وهم لا يُظلمون } وقيل معناه لكل أمة يوم القيامة رسول تنسب إليه فإذا جاء رسولهم الموقف ليشهد عليهم بالكفر والإيمان قضى بينهم بإنجاء المؤمنين وعقاب الكفار لقوله : { وجيء بالنبيين والشهداء وقضي بينهم } .
