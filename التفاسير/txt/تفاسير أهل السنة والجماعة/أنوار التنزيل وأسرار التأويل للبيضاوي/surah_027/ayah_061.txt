{ أمن جعل الأرض قرارا } بدل من { أمن خلق السماوات } وجعلها قرارا بإبداء بعضها من الماء وتسويتها بحيث يتأتى استقرار الإنسان والدواب عليها .   { وجعل خلالها }  وسطها .   { أنهارا } جارية .   { وجعل لها رواسي } جبالا تتكون فيها المعادن وتنبع من حضيضها المنابع .   { وجعل بين البحرين } العذب والمالح ،   أو خليجي فارس والروم .   { حاجزا } برزخا وقد مر بيانه في سورة  " الفرقان "   { أإله مع الله بل أكثرهم لا يعلمون } الحق فيشركون به .
