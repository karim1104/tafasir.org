{ وترى كثيرا منهم } أي من اليهود أو من المنافقين .   { يسارعون في الإثم } أي الحرام وقيل الكذب لقوله : { عن قولهم الإثم } { والعدوان } الظلم ،   أو مجاوزة الحد في المعاصي .   وقيل { الإثم } ما يختص بهم والعدوان ما يتعدى إلى غيرهم .   { وأكلهم السحت } أي الحرام خصه بالذكر للمبالغة .   { لبئس ما كانوا يعملون } لبئس شيئا عملوه .
