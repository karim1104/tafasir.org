{ اتّبعوا ما أُنزل إليكم من ربكم } يعم القرآن والسنة لقوله سبحانه وتعالى : { وما ينطق عن الهوى إن هو إلا وحي يوحى } { ولا تتّبعوا من دونه أولياء } يضلونكم من الجن والإنس وقيل الضمير في { من دونه } ل { ما أنزل } أي : ولا تتبعوا من دون دين الله دين أولياء .   وقرئ  " ولا تبتغوا "  .   { قليلا ما تذكّرون } أي تذكرا قليلا أو زمانا قليلا تذكرون حيث تتركون دين الله وتتبعون غيره ،   و " ما "  مزيدة لتأكيد القلة وإن جعلت مصدرية لم ينتصب { قليلا } ب { تذكرون } .   وقرأ حمزة والكسائي وحفص عن عاصم { تذكرون } بحذف التاء وابن عامر  " يتذكرون "  على أن الخطاب بعد مع النبي صلى الله عليه وسلم .
