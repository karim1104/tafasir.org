شرح الكلمات :

{  لولا } :  أداة تحضيض وحث بمعنى هَلاّ .

{  سبحانك } :  كلمة تقال عند التعجب والمراد بها تنزيه الله تعالى عما لا يليق به .

{  بهتان عظيم } :  البهتان الكذب الذي يحيّر من قيل فيه .

المعنى :

/د11

وقوله تعالى :  {  ولولا إذ سمعتموه قلتم ما يكون لنا أن نتكلم بهذا } إذ هذه مما لا يصح لمؤمن أن يقول فيه لخطره وعظم شأنه ،  وقلتم متعجبين من مثله كيف يقع {  سبحانك } أي يا رب {  هذا } أي الإفك {  بهتان عظيم } بهتوا به أم المؤمنين وصفوان .
