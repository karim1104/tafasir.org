شرح الكلمات :

{  جن عليه الليل } :  أظلم .

{  فلما أفل } :  أي غاب .

المعنى :

في الثالثة ( 76 ) فصّل الله تعالى ما أجمله في قوله {  نري إبراهيم ملكوت السموات والأرض } فقال تعالى {  فلما جن عليه الليل } أي أظلم {  رأى كوكباً } قد يكون الزهرة {  قال هذا ربي فلما أفل } أي غاب الكوكب {  قال لا أحب الآفلين } .
