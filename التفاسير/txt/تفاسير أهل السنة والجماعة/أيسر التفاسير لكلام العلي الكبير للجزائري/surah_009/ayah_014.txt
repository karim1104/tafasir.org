شرح الكلمات :

{  ويخزهم } :  أي يذلهم ويهينهم .

{  ويشف صدور } :  أي يذهب الغيظ الذي كان بها على المشركين الظالمين .

المعنى :

وفي الآية الثانية ( 14 ) يقول تعالى :  {  قاتلوهم } وهو أمر صريح بالقتال ،  وبذكر الجزاء المترتب على قتالهم فيقول {  يعذّبهم الله بأيدكم ويخزهم وينصركم عليهم ويشف صدور قوم مؤمنين } وهم خزاعة .
