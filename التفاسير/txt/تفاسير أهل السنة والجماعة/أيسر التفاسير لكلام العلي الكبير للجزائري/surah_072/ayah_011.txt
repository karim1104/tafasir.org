شرح الكلمات :

{  كنا طرائق قددا } :  أي مذاهب مختلفة إذا الطرائق جمع طريقة ،  والقدد جمع قدة وهي الضروب والأجناس المختلفة .

المعنى :

وقالوا {  وإنا منا الصالحون } أي المؤمنون المستقيمون على الإِيمان والطاعة {  ومنَّا دون ذلك } ضعف إيمان وقلة طاعة ،  {  كنَّا طرائق قددا } أي مذاهب وأهواء مختلفة .

/ذ15
