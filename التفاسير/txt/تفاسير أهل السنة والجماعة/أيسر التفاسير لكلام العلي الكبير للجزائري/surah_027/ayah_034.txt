شرح الكلمات :

{  إذا دخلوا قرية } :  أي مدينة وعاصمة ملك .

{  أفسدوها } :  أي خربوها إذا دخلوها عنوة بدون مصالحة .

{  وكذلك يفعلون } :  أي وكالذي ذكرت لكم يفعل مرسلو هذا الكتاب .

المعنى :

فأجابتهم بما حكاه الله تعالى عنها {  قالت إن الملوك إذا دخلوا قرية } أي مدينة عنوة بدون صلح .  {  أفسدوها } أي خربوا معالمها وبدلوا وغيروا فيها ،  {  وجعلوا أعزة أهلها أذلة } بضربهم وإهانتهم وخلعهم من مناصبهم .  {  وكذلك } أصحاب هذا الكتاب {  يفعلون } .
