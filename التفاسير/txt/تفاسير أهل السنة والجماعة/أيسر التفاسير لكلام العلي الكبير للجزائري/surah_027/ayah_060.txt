شرح الكلمات :

{  حدائق ذات بهجة } :  أي بساتين ذات منظر حسن لخضرتها وأزهارها .

{  يعدلون } :  أي بربهم غيره من الأصنام والأوثان .

المعنى :

فقوله {  أمن خلق السموات والأرض وأنزل لكم من السماء ماء } أي لحاجتكم إليه غسلاً وشرباً وسقيا {  فأنبتنا به حدائق } أي بساتين محدقة بالجدران والحواجز {  ذات بهجة } أي حسن وجمال ،  رما كان لكم أن تنبتوا شجرها } أي لم يكن في استطاعتكم أن تنبتوا شجرها {  أ إله مع الله } لا والله {  بل هم قوم يعدلون } أي يشركون بربهم أصناما ويُسَوُّونها به في العبادات
