شرح الكلمات :

{  ويوم نحشر } :  أي اذكر يوم نحشر أي نجمع .

{  من كل أمة فوجاً } :  أي طائفة وهم الرؤساء المتبعون في الدنيا .

{  فهم يوزعون } :  أي يجمعون برد أولهم على آخرهم .

المعنى :

وقوله تعالى :  {  ويوم نحشر من كل أمة فوجاً } أي واذكر يا رسولنا {  يوم نحشر من كل أمة } من الأمم البشرية {  فوجاً } أي جماعة {  ممن يكذب بآياتنا فهم يوزعون } بأن يرد أولهم على آخرهم لينتظم سيرهم

من الهداية :

- تقرير عقيدة البعث والجزاء بذكر وصف لها .
