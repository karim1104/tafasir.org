قوله تعالى : { ألم يأتهم } ،   يعنى المنافقين ،   { نبأ } ،   خبر ،   { الذين من قبلهم } ،   حين عصوا رسلنا ،   وخالفوا أمرنا كيف عذبناهم وأهلكناهم .   ثم ذكرهم ،   فقال : { قوم نوح } ،   أهلكوا بالطوفان ،   { وعاد } ،   أهلكوا بالريح { وثمود } ،   بالرجفة ،   { وقوم إبراهيم } ،   بسلب النعمة وهلاك نمرود ،   { وأصحاب مدين } ،   يعنى قوم شعيب أهلكوا بعذاب يوم الظلة ،   { والمؤتفكات } المنقلبات التي جعلنا عاليها سافلها وهم قوم لوط ،   { أتتهم رسلهم بالبينات } ،   فكذبوهم وعصوهم كما فعلتم يا معشر الكفار ،   فاحذروا تعجيل النقمة ،   { فما كان الله ليظلمهم ولكن كانوا أنفسهم يظلمون } .
