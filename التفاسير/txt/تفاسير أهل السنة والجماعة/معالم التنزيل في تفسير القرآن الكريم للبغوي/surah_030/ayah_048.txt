قوله تعالى : { الله الذي يرسل الرياح فتثير سحاباً } أي : ينشره ،   { فيبسطه في السماء كيف يشاء } مسيرة يوم أو يومين أو أكثر على من يشاء ،   { ويجعله كسفاً } قطعاً متفرقة ،   { فترى الودق } المطر ،   { يخرج من خلاله } وسطه ،   { فإذا أصاب به } أي : بالودق ،   { من يشاء من عباده إذا هم يستبشرون } يفرحون بالمطر .
