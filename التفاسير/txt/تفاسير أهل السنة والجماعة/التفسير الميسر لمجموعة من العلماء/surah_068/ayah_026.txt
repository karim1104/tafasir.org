{  فَلَمَّا رَأَوْهَا قَالُوا إِنَّا لَضَالُّونَ ( 26 ) بَلْ نَحْنُ مَحْرُومُونَ ( 27 ) قَالَ أَوْسَطُهُمْ أَلَمْ أَقُلْ لَكُمْ لَوْلا تُسَبِّحُونَ ( 28 ) قَالُوا سُبْحَانَ رَبِّنَا إِنَّا كُنَّا ظَالِمِينَ ( 29 ) فَأَقْبَلَ بَعْضُهُمْ عَلَى بَعْضٍ يَتَلاوَمُونَ ( 30 ) قَالُوا يَا وَيْلَنَا إِنَّا كُنَّا طَاغِينَ ( 31 ) عَسَى رَبُّنَا أَنْ يُبْدِلَنَا خَيْراً مِنْهَا إِنَّا إِلَى رَبِّنَا رَاغِبُونَ ( 32 ) كَذَلِكَ الْعَذَابُ وَلَعَذَابُ الآخِرَةِ أَكْبَرُ لَوْ كَانُوا يَعْلَمُونَ ( 33 ) }

فلما رأوا حديقتهم محترقة أنكروها ،  وقالوا :  لقد أخطأنا الطريق إليها ،  فلما عرفوا أنها هي جنتهم ،
