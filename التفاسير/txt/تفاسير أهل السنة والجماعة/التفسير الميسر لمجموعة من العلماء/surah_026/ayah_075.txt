{  قَالَ أَفَرَأَيْتُمْ مَا كُنْتُمْ تَعْبُدُونَ ( 75 ) أَنْتُمْ وَآبَاؤُكُمْ الأَقْدَمُونَ ( 76 ) فَإِنَّهُمْ عَدُوٌّ لِي إِلاَّ رَبَّ الْعَالَمِينَ ( 77 ) الَّذِي خَلَقَنِي فَهُوَ يَهْدِينِ ( 78 ) وَالَّذِي هُوَ يُطْعِمُنِي وَيَسْقِينِ ( 79 ) وَإِذَا مَرِضْتُ فَهُوَ يَشْفِينِ ( 80 ) وَالَّذِي يُمِيتُنِي ثُمَّ يُحْيِينِ ( 81 ) وَالَّذِي أَطْمَعُ أَنْ يَغْفِرَ لِي خَطِيئَتِي يَوْمَ الدِّينِ ( 82 ) }

قال إبراهيم :  أفأبصرتم بتدبر ما كنتم تعبدون من الأصنام التي لا تسمع ولا تنفع ولا تضر ،
