{  إِنَّهَا شَجَرَةٌ تَخْرُجُ فِي أَصْلِ الْجَحِيمِ ( 64 ) طَلْعُهَا كَأَنَّهُ رُءُوسُ الشَّيَاطِينِ ( 65 ) فَإِنَّهُمْ لآكِلُونَ مِنْهَا فَمَالِئُونَ مِنْهَا الْبُطُونَ ( 66 ) ثُمَّ إِنَّ لَهُمْ عَلَيْهَا لَشَوْباً مِنْ حَمِيمٍ ( 67 ) ثُمَّ إِنَّ مَرْجِعَهُمْ لإٍلَى الْجَحِيمِ ( 68 ) }
