{  يَسْأَلُونَكَ عَنْ السَّاعَةِ أَيَّانَ مُرْسَاهَا ( 42 ) فِيمَ أَنْتَ مِنْ ذِكْرَاهَا ( 43 ) إِلَى رَبِّكَ مُنتَهَاهَا ( 44 ) إِنَّمَا أَنْتَ مُنذِرُ مَنْ يَخْشَاهَا ( 45 ) كَأَنَّهُمْ يَوْمَ يَرَوْنَهَا لَمْ يَلْبَثُوا إِلاَّ عَشِيَّةً أَوْ ضُحَاهَا ( 46 ) }

يسألك المشركون يا محمد- استخفافا- عن وقت حلول الساعة التي تتوعدهم بها .
