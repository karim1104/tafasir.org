{  إِنَّ الأَبْرَارَ لَفِي نَعِيمٍ ( 22 ) عَلَى الأَرَائِكِ يَنظُرُونَ ( 23 ) تَعْرِفُ فِي وُجُوهِهِمْ نَضْرَةَ النَّعِيمِ ( 24 ) يُسْقَوْنَ مِنْ رَحِيقٍ مَخْتُومٍ ( 25 ) خِتَامُهُ مِسْكٌ وَفِي ذَلِكَ فَلْيَتَنَافَسْ الْمُتَنَافِسُونَ ( 26 ) وَمِزَاجُهُ مِنْ تَسْنِيمٍ ( 27 ) عَيْناً يَشْرَبُ بِهَا الْمُقَرَّبُونَ ( 28 ) }
