{  كُلُّ نَفْسٍ بِمَا كَسَبَتْ رَهِينَةٌ ( 38 ) إِلاَّ أَصْحَابَ الْيَمِينِ ( 39 ) فِي جَنَّاتٍ يَتَسَاءَلُونَ ( 40 ) عَنْ الْمُجْرِمِينَ ( 41 ) مَا سَلَكَكُمْ فِي سَقَرَ ( 42 ) قَالُوا لَمْ نَكُ مِنَ الْمُصَلِّينَ ( 43 ) وَلَمْ نَكُ نُطْعِمُ الْمِسْكِينَ ( 44 ) وَكُنَّا نَخُوضُ مَعَ الْخَائِضِينَ ( 45 ) وَكُنَّا نُكَذِّبُ بِيَوْمِ الدِّينِ ( 46 ) حَتَّى أَتَانَا الْيَقِينُ ( 47 ) }

كل نفس بما كسبت محبوسة بعملها ،  مرهونة بكسبها ،  لا تُفَكُّ حتى تؤدي ما عليها من الحقوق والعقوبات ،
