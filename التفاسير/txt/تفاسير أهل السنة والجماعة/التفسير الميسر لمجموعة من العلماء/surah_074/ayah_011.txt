{  ذَرْنِي وَمَنْ خَلَقْتُ وَحِيداً ( 11 ) وَجَعَلْتُ لَهُ مَالاً مَمْدُوداً ( 12 ) وَبَنِينَ شُهُوداً ( 13 ) وَمَهَّدْتُ لَهُ تَمْهِيداً ( 14 ) ثُمَّ يَطْمَعُ أَنْ أَزِيدَ ( 15 ) كَلاَّ إِنَّهُ كَانَ لآيَاتِنَا عَنِيداً ( 16 ) سَأُرْهِقُهُ صَعُوداً ( 17 ) }
