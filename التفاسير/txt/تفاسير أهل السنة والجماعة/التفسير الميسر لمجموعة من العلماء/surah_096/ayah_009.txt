{  أَرَأَيْتَ الَّذِي يَنْهَى ( 9 ) عَبْداً إِذَا صَلَّى ( 10 ) أَرَأَيْتَ إِنْ كَانَ عَلَى الْهُدَى ( 11 ) أَوْ أَمَرَ بِالتَّقْوَى ( 12 ) أَرَأَيْتَ إِنْ كَذَّبَ وَتَوَلَّى ( 13 ) أَلَمْ يَعْلَمْ بِأَنَّ اللَّهَ يَرَى ( 14 ) كَلاَّ لَئِنْ لَمْ يَنْتَهِ لَنَسْفَعَ بِالنَّاصِيَةِ ( 15 ) نَاصِيَةٍ كَاذِبَةٍ خَاطِئَةٍ ( 16 ) فَلْيَدْعُ نَادِيَه ( 17 ) سَنَدْعُ الزَّبَانِيَةَ ( 18 ) كَلاَّ لا تُطِعْهُ وَاسْجُدْ وَاقْتَرِبْ ( 19 ) }

أرأيت أعجب مِن طغيان الذي ينهى ( وهو أبو جهل ) .
