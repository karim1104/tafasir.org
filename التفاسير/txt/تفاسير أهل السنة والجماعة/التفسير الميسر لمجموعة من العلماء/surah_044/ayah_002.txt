{  وَالْكِتَابِ الْمُبِينِ ( 2 ) إِنَّا أَنزَلْنَاهُ فِي لَيْلَةٍ مُبَارَكَةٍ إِنَّا كُنَّا مُنذِرِينَ ( 3 ) فِيهَا يُفْرَقُ كُلُّ أَمْرٍ حَكِيمٍ ( 4 ) أَمْراً مِنْ عِنْدِنَا إِنَّا كُنَّا مُرْسِلِينَ ( 5 ) رَحْمَةً مِنْ رَبِّكَ إِنَّهُ هُوَ السَّمِيعُ الْعَلِيمُ ( 6 ) رَبِّ السَّمَوَاتِ وَالأَرْضِ وَمَا بَيْنَهُمَا إِنْ كُنْتُمْ مُوقِنِينَ ( 7 ) لا إِلَهَ إِلاَّ هُوَ يُحْيِ وَيُمِيتُ رَبُّكُمْ وَرَبُّ آبَائِكُمْ الأَوَّلِينَ ( 8 ) }

أقسم الله تعالى بالقرآن الواضح لفظًا ومعنى .
