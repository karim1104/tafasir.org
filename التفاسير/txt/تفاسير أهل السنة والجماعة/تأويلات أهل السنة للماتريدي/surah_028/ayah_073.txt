[ الآية 73 ] وهو ما ذكر :  {  ومن رحمته لكم الليل والنهار لتسكنوا فيه ولتبتغوا من فضله ولعلكم تشكرون } وقوله تعالى :  {  أفلا تسمعون } وقوله :  {  أفلا تبصرون } إنما هو سمع عقل وقلب وبصر عقل وقلب ؛  كأنه يقول :  {  أفلا تسمعون } هذا بالعقل ،   ويقول :  {  أفلا تبصرون } بالعقل ،   والله أعلم ،   كقوله :  {  فإنها لا تعمى الأبصار ولكن تعمى القلوب التي في الصدور } [ الحج :  46 ] .
