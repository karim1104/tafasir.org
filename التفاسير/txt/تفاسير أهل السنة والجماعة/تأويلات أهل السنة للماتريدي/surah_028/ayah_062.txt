[ الآية 62 ] وقوله تعالى :  {  ويوم يناديهم فيقول أين شركائي الذين كنتم تزعمون } قوله :  {  شركائي الذين } في زعمكم أنهم شركائي حين  أشركتموهم في العبادة وتسمية الألوهية .   وإلا لم يكن لله شريك {  فيقول أين شركائي الذين } زعمتم أنهم  شركائي ؟

ثم قوله :  {  أي شركائي } إنما يقول لهم لقولهم :  {  ما نعبدهم إلا ليقربونا إلى الله زلفى } [ الزمر :  3 ] وقولهم :  {  هؤلاء شفعاؤنا عند الله } [ يونس :  18 ] فيقول :  أين شفاعة من زعمتم أنهم شفعاؤكم عند الله ؟  وأين قربتكم وزلفاكم بعبادتكم إياها زعمتم أن عبادتكم إياها تقربكم إلى الله زلفى ؟  أين ذلك لكم منهم ؟
