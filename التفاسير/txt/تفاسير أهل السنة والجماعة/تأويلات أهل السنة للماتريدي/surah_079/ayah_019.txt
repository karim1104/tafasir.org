الآية 19 :  وقوله تعالى :  {  وأهديك إلى ربك فتخشى } فتهتدي ،   ثم تخشاه إذا اهتديت ،   أي عرفت عظمته وجلاله {  فتخشى } عقوبته ،   فيكون العلم مثمرا للخشية .

ألا ترى إلى قوله تعالى :  {  إنما يخشى الله من عباده العلماء } ؟  [ فاطر :  28 ] .

أو [ يكون ] {  وأهديك } إلى طاعة ربك ،   وأنذرك عقابه إذا عصيته {  فتخشى } فلا تعصيه .
