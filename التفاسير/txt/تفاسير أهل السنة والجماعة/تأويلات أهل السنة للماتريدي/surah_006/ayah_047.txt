الآية 47 وقوله تعالى :  {  قل أرأيتكم إن أتاكم عذاب الله بغتة أو جهرة هل يهلك إلا القوم الظالمون } معناه ،   والله أعلم :  أنهم يعلمون أن العذاب لا يأتي ،   ولا يأخذ إلا الظالم ،   ثم أنهم ظلمة لعبادتهم غير الله مع علمهم أنهم لا يملكون نفعا ولا ضرا يسألون العذاب بقوله :  {  سأل سائل بعذاب واقع } [ المعارج : 1 ] وقوله :  {  ويستعجلونك بالعذاب } [ الحج :  47 ] وقوله :  {  عجل لنا قطنا قبل يوم الحساب } [ ص : 16 ] .
