الآية 154 وقوله تعالى :  {  ثم آتينا موسى الكتاب تماما } اختلف فيه :  قال الحسن :  قوله تعالى :  {  تماما على الذي أحسن } أي أحسن صحبته ،   تمت نعمة الله وكرامته عليه في الآخرة .   وقيل :  {  تماما على الذي أحسن } يعني على المحسنين والمؤمنين .   وعلى [ الذي أحسن بمعنى للذي ] آمن .   ويجوز على في موضع اللام كقوله تعالى :  {  وما ذبح على النصب } [ المائدة :  3 ] أي للنصب .   وقتادة قال :  فمن أحسن في ما آتاه الله تمت عليه كرامة الله في جنته ورضوانه ،   ومن لم يحسن في ما آتاه الله [ ولا عذر له ] نزع الله ما في يده ،   ثم أبلاه .

وقال أبو بكر الكيساني في قوله تعالى :  {  ثم آتينا موسى الكتاب تماما على الذي أحسن } أي ثم آتيناكم من الحجج والبيان تماما من موسى وكتابه ؛  أي موسى وكتابه مصدق وموافق لما أعطاكم كقوله تعالى :  {  أفمن كان على بينة من ربه ويتلوه شاهد منه ومن قبله كتاب موسى إماما ورحمة } الآية [ هود :  17 ] .

ويحتمل [ {  تماما } تمام ما ذكرنا ] بالنعمة والكرامة ،   ويحتمل {  تماما } بالحجة والبيان و{  تماما } بالحكمة والعلم .

وقوله تعالى :  {  على الذي أحسن } أي للذي أحسن .   وفي حرف ابن مسعود رضي الله عنه {  تماما على } الذين أحسنوا {  وتفصيلا لكل شيء } أي تبيانا لكل شيء {  وهدى } من الضلالات والشبهات ونعمة {  ورحمة } من العذاب والعقاب {  لعلهم بلقاء ربهم يؤمنون } أي وليكونوا {  بلقاء ربهم يؤمنون } على التحقيق .

وعن ابن عباس رضي الله عنه [ أنه ] قال :  {  تماما على الذي أحسن تفصيلا } يقول :  أتم له الكتاب على أحسنه على الذي بلغ من رسالته وتفصيل كل شيء [ أي ] بيان كل شيء {  وهدى } أي تبيانا من الضلالة {  ورحمة } أي نعمة {  لعلهم بلقاء ربهم يؤمنون } أي بالبعث بعد الموت يؤمنون أي ليكونوا بالبعث [ يؤمنون ] .

ومنهم من يقول في قوله تعالى :  {  ثم آتينا موسى الكتاب } إنه ،   وإن أتى بحرف الترتيب فإنه على الإخبار ،   كأنه قال :  ثم قد كنا {  آتينا موسى الكتاب تماما } معناه :  وقد آتيناه .
