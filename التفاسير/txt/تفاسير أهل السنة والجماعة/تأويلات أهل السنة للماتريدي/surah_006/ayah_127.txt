الآية 127 وقوله تعالى :  {  لهم دار السلام عند ربهم } يحتمل السلام اسم الجنة كقوله تعالى :  {  والله يدعو إلى دار السلام } [ يونس :  25 ] ويحتمل السلام اسم الله ؛  أي لهم دار الله ،   وهو الجنة .

وقوله تعالى :  {  وهو وليهم بما كانوا يعملون } قيل :  وهو أولى بهم أي أولى بالمؤمنين كقوله تعالى :  {  فالله أولى بهما } [ النساء :  135 ] ويحتمل قوله :  {  وهو وليهم } حافظهم وناصرهم .   وقد ذكرنا في ما تقدم {  يصعد } [ الآية :  125 ] .

ويصاعد ويصعد كله لغات ،   والمعنى واحد .

والضيق :  قال الكسائي :  الضيق من الضيق في المعاش ؛  فأما في الأمر فإنه الضيق ،   ومنه قوله تعالى :  {  ولا تك في ضيق مما يمكرون } [ النحل :  127 ] .   وأما قوله تعالى :  {  حرجا } ففيه لغتان :  حرج وحرج .   قال القتبي :  الحرج الذي ضاق فلم يجد [ به ] منفذا .   وقال أبو عوسجة :  الحرج الضيق ؛  يقال فيه :  حرج يحرج ،   فهو حرج .
