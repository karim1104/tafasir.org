بسم الله الرحمان الرحيم

الآيات 1 و2 و3 قوله تعالى :  {  والصّافّات صفًّا } {  فالزّاجرات زجرا } {  فالتاليات ذِكرا } اختلف فيه :  قال بعضهم :  الصافات هي الطير إذا صفّت أجنحتها بين السماء والأرض .   وذُكر عن ابن مسعود [ أنه ] قال :  الصافات والزاجرات والتاليات ،   كلها الملائكة .   قال :  الصافّات ،   اصطفّت الملائكة صفا لعبادة الله عز وجل وتسبيحه .   وكذلك ذكر عن ابن عباس وغيره .

إلا أن غيرهما ،   يفسر الزاجرات والتاليات أي ملائكة هم .   ولسنا نذكر عن ابن مسعود وابن عباس [ هذا ] التفسير .

وقال بعضهم :  الزاجرات هم الملائكة الذي يزجرون السحاب والأمطار {  فالتاليات ذكرا } هم الملائكة يتلون القرآن والوحي على الرسل والأنبياء عليهم السلام .

وقال قتادة :  {  والصافات صفا } أقسم الله عز وجل بخلق ممن خلق ،   قال :  الصافات الملائكة صفوفا في السماء {  فالزاجرات زجرا } ما ذكر في القرآن من زواجر عن المعاصي والمساوئ {  فالتاليات ذكرا } قال :  ما يتلى عليكم في القرآن من أخبار الرسل عليهم السلام وأنباء الأمم التي كانت قبلكم .

وجائز أن يكون {  والصافّات صفا } هم الملائكة الذي يصلون لله عز وجل صفوفا على ما ذكر ،   {  فالزاجرات زجرا } هم الملائكة الموكلون بأرزاق الخلق وسوقها إليهم سوقا {  فالتاليات ذكرا } هم الملائكة الموكلون بالتسبيح والتحميد وجميع الأذكار .

ثم وجه القسم بالملائكة الذين ذكر ،   والله أعلم ،   أنه عز وجل قد عظّم شأن الملائكة وأمرهم في قلوب أولئك الكفرة حتى قالوا :  {  لولا أنزل مَلَك فيكون معه نذير } [ الفرقان :  7 ] وقالوا :  {  لولا أنزل علينا الملائكة أو نرى ربنا } [ الفرقان :  21 ] [ وصفهم ] الله عز وجل أنهم {  لا يعصون الله ما أمرهم } الآية [ التحريم :  6 ] وأنهم {  لا يستكبرون عن عبادته } الآية [ الأعراف :  206 والأنبياء 19 ] وأنهم {  يسبّحون الليل والنهار } [ الأنبياء :  20 ] الخ .

عظّم الله عز وجل أمر الملائكة [ وشأنهم في ] قلوب أولئك الكفرة وصدقهم عندهم .
