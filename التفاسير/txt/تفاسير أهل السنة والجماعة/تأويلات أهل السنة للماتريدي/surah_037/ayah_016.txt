الآيات 16 و17 و18 وقوله تعالى :  {  أئذا متنا وكنا ترابا وعظاما أءنا لمبعوثون } {  أوَ آباؤنا الأولون } {  قل نعم وأنتم داخرون } قد ذكرنا أنهم يقولون ذلك ،   وما تقدم على العناد والتّعنُّت وعلم منهم أنهم لا يؤمنون أبدا ،   وإن بيّن لهم جهة الإحياء والقدرة عليهم .   لذلك اكتفى بقوله :  {  قل نعم وأنتم داخرون } قد ذكرنا أنهم كانوا يقولون ذلك ،   ولم يذكر شيئا من الحجاج سوى قوله :  {  نعم } [ وقوله :  ] {  وأنتم داخرون } أي صاغرون ذليلون كقوله عز وجل {  وترهقهم ذلّة } [ يونس :  27 ] والله أعلم .
