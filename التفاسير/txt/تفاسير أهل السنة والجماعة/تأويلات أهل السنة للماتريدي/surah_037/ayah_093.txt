الآية 93 وقوله تعالى :  {  فراغ عليهم ضربا باليمين } أي مال ،   ورجع عليهم .   وقوله :  {  ضربا باليمين } اختلف فيه :  قال بعضهم {  ضربا باليمين } وفاء ليمينه التي كانت منه حين قال :  {  وتالله لأكيدن أصنامكم بعد أن تولّوا مدبرين } [ الأنبياء :  57 ] والله أعلم .

وقال بعضهم :  {  ضربا باليمين } بالقوة .   وقد يعبَّر /454-أ/ باليمين عن القوة كما يعبّر باليد عن القوة .

وقال بعضهم :  {  ضربا باليمين } أي باليد اليمنى نفسها على ما يعمل المرء [ أكثر ] أعماله باليمين .
