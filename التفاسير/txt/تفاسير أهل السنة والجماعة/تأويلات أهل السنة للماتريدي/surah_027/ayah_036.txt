[ الآية 36 ] وقوله تعالى :  {  فلما جاء سليمان } الرسول الذي [ بعثته بلقيس إليه بالهدية ] ويحتمل {  فلما جاء سليمان } المال الذي بعث إليه .   يحتمل ذا أو ذا .

وقوله تعالى :  {  قال أتمدونن بمال } أي أتقطعونني بمال .   وقال أهل الأدب :  {  أتمدونن بمال } من المدد ،   والمدد الزيادة كما يمد القوم ،   ويكون الإعطاء كقوله :  {  وأمددناهم بفاكهة ولحم مما يشتهون } [ الطور : 22 ] ويحتمل هذا الزيادة ،   والله أعلم .

وقوله تعلى :  {  فما آتاني الله خير مما آتاكم } أي ما آتاني الله من النبوة والعلم والحكمة {  خير مما آتاكم } من الأموال .   ويحتمل {  فما آتاني الله } فاديتكم إذا أتيتموني مسلمين {  خير مما آتاكم } إن لم تؤتوني [ مسلمين ] أو أبيتم الإسلام ،   أو كلام نحو هذا .

وقال بعض أهل التأويل :  {  فما آتاني الله } من الملك {  خير مما آتاكم } من الملك لأنه سخر له الجن والإنس والشياطين والطيور والرياح وجميع الأشياء .   فذلك خير له وأعظم من ملكها .

والأول أشبه وأقرب ؛  إذ لا يحتمل أن يفتخر سليمان بملكه على غيره ،   إنما يكون افتخاره بالدين والنبوة ،   والله أعلم .

وقوله تعالى :  {  بل أنتم بهديتكم تفرحون } قال بعضهم :  {  بل أنتم بهديتكم تفرحون } إذا ردت إليكم .   لكن هذا بعيد [ لأن المهدي ]  لا يفرح برد الهدية إذا ردت عليه هديته ،   ولم تقبل [ بل يحزن ] على ذلك ،   ويهتم .   لكنه يقول ،   والله أعلم {  بل أنتم بهديتكم تفرحون } بل أنتم أولى بالفرح بالمال والهدايا منا ؛  إذ مرادكم المال والدنيا ،   ومرادنا الدين والدار الآخرة ،   أو كلام نحو هذا ،   والله أعلم بذلك .
