[ الآية 35 ] وقوله تعالى :  {  ولقد آتينا موسى الكتاب } أي التوراة {  وجعلنا معه أخاه هارون وزيرا } ذكر ههنا أنه كان وزيرا له ،   وذكر في آية أخرى :  {  فأتيناه فقولا إنا رسولا ربك } [ طه :  47 ] وفي آية أخرى :  {  إنه كان مخلصا وكان رسولا نبيا } [ مريم :  51 ] حين قال :  {  ووهبنا له من رحمتنا أخاه هارون نبيا } [ مريم : 53 ] .

فكان [ في ] ما ذكر ذلك كله نبيا ورسولا .   وكان له وزيرا ،   والوزير هو العون والعضد ،   كأنه قال :  وجعلنا معه أخاه هارون وزيرا عونا وعضدا كقوله :  {  واجعل لي وزيرا من أهلي } {  هارون أخي } {  اشدد به أزري } {  وأشركه في أمري } [ طه : 29 و32 ] سأل ربه المعونة له والإشراك في أمره .

وقال :  {  فأرسله معي ردءا يصدقني } [ القصص :  34 ] .

وقال الزجاج :  الوزير هو الذي يلتجأ إليه في النوائب ،   ويعتصم بأمره ،   وهو واحد .
