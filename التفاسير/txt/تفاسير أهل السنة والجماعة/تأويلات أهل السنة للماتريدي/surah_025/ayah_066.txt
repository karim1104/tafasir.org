[ الآية 66 ] وقوله تعالى :  {  إنها ساءت مستقرا ومقاما } أي جهنم ،   بئس المستقر ،   وبئس المقام لأهلها ،   وهو مقابل ما ذكر لأهل الطاعة الجنة حين قال :  {  حسنت مستقرا ومقاما } [ الفرقان : 76 ] .

وقال بعضهم :  {  غراما } غرموا في الآخرة مانعوا في الدنيا .   وفي حرف ابن مسعود {  كان غراما } إنا أنبئنا أنها {  ساءت مستقرا ومقاما } .

وقال أبو عوسجة :  {  هونا } هو من الرفق ،   يقال :  هان يهون هونا ،   فهو هائن [ ومنه يقال :  ] إذا عز أخوك فهن :  أي إذا اشتد فارفق به ،   والغرام الهلاك .   وكذلك قال القتبي {  غراما } أي هلكة ،   وقال :  مشيا {  هونا } رويدا {  سلاما } أي سدادا من القول ؛  لا رفث فيه ،   ولا هجر .
