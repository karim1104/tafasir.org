الآية 65 وقوله تعالى :  {  وَلَقَدْ أُوحِيَ إِلَيْكَ وَإِلَى الَّذِينَ مِنْ قَبْلِكَ لَئِنْ أَشْرَكْتَ لَيَحْبَطَنَّ عَمَلُكَ } يحتمل هذا وجهين :

أحدهما :  كأنه يقول :  {  وَلَقَدْ أُوحِيَ إِلَيْكَ وَإِلَى الَّذِينَ مِنْ قَبْلِكَ } وقيل لكل رسول {  لَئِنْ أَشْرَكْتَ لَيَحْبَطَنَّ عَمَلُكَ } ذكر هذا ليُعلم أن الشرك ليُحبِط العمل ،   وإن أتى به من جل قدره ،   وعظُمت منزلته عنده .

والثاني :  {  وَلَقَدْ أُوحِيَ إِلَيْكَ وَإِلَى الَّذِينَ } من كان {  مِنْ قَبْلِكَ لَئِنْ أَشْرَكْتَ } أنت {  لَيَحْبَطَنَّ عَمَلُكَ } .
