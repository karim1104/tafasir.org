الآية 82 :  وقوله تعالى :  {  وإني لغفار لمن تاب وآمن وعمل صالحا ثم اهتدى } يحتمل قوله :  {  لغفار لمن تاب } [ وجهين :  أحدهما ]  :  {  لغفار لمن تاب } عن الشرك ورجع عنه {  وآمن } بتوحيده {  وعمل صالحا } في ما بين ذلك {  ثم اهتدى } في حفظ أمره ،   وانتهى عما نهى .

والثاني :  {  لغفار لمن تاب } عن جميع المناهي {  وآمن } بجميع ما أمر [ {  ثم اهتدى } أي ]  ما دام على ذلك ،   وثبت ،   كقوله :  {  إن الذين قالوا ربنا الله ثم استقاموا } [ فصلت : 30 ] .
