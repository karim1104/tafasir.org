الآية 73 :  وقوله تعالى :  {  إنا آمنا بربنا ليغفر لنا خطايانا وما أكرهتنا عليه من السحر والله خير وأبقى } يحتمل قوله :  {  والله خير } والله خير معبود ،   وثوابه {  وأبقى } أبقى من ثواب غيره .   أو أن يكون هذا جواب قوله :  {  ولتعلمن أينا أشد عذابا وأبقى } فيقول [ السحرة ] :  عذاب الله [ أشد ]  وأبقى ،   والله أعلم .

قال أبو عوسجة :  {  جذوع النخل } [ سوق النخل وأصولها ]  .
