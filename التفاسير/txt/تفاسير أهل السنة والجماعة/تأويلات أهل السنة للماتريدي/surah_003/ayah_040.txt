الآية 40 [ وقوله تعالى ] :  {  قال رب أنى يكون لي غلام وقد بلغني الكبر } الآية ؛  يحتمل هذا الكلام وجوها :

أحدها :  لا على الإنكار أي لا يكون ،   لكن ههنا يحتمل لأنه كان أعلم بالله وقدرته أن ينطق به ،   أو يخطر بباله .

والثاني :  {  أنى يكون لي غلام } أي كيف وجهه وسببه ؟  وكذلك قوله :  {  أنى لك هذا } وقوله :  {  أنى يحيي هذه الله بعد موتها }

[ البقرة :  259 ] وقوله :  {  أنى يكون له الملك علينا } [ البقرة :  247 ] أي كيف وجهه ؟  وما سببه ؟

والثالث :  {  أنى يكون لي غلام } في الحال التي أنا عليها ،   أو أرد إلى الشباب ،   فيكون لي الولد .

وقوله تعالى :  {  وقد بلغني الكبر وامرأتي عاقر } وذكر في سورة مريم {  رب أنى يكون لي غلام وكانت امرأتي عاقرا وقد بلغني من الكبر عتيا }

[ الآية 8 ] ذكر على التقديم والتأخير ،   وكذلك قوله :  {  ثلاثة أيام إلا رمزا } [ آل عمران :  41 ] وقوله :  {  ثلاث ليال سويا } [ مريم :  10 ] ،   والقصة واحدة ،   وذكر على التقديم والتأخير وعلى اختلاف الألفاظ واللسان .   دل أنه ليس على الخلق حفظ اللفظ واللسان

[ وإنما ] عليهم حفظ المعاني المدرجة المودعة فيها ،   وبالله التوفيق وعلم أنه لم يكن على كلا القولين ،   ولم يكن بهذا اللسان .

وقال تعالى :  {  قال كذلك الله يفعل ما يشاء } كقوله :  {  قال كذلك قال ربك هو على هين } [ مريم :  21 ] وإن اختلف اللسان .
