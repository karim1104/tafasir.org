الآية 171 وقوله تعالى :  {  يستبشرون بنعمة من الله وفضل } ( يحتمل {  بنعمة من الله } الجنة {  و فضل } زيادات لهم وكرامات من الله عز وجل .

وقوله تعالى :  {  وأن الله لا يضيع أجر المؤمنين } أي لا يضيع من حسناتهم وخيراتهم وإن قل وصغر كقوله عز وجل :  {  نتقبل عنهم أحسن ما عملوا } ( الأحقاف 16 ) ( وكقوله تعالى )  {  فمن يعمل مثقال ذرة خيرا يره } ( الزلزلة 7 ) وكقوله تعالى {  إن الله لا يظلم مثقال ذرة } الآية ( النساء 40 ) .
