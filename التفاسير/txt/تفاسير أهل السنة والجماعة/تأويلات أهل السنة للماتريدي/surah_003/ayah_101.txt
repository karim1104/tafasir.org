الآية 101 وقوله تعالى :  {  وكيف تكفرون وأنتم تتلى عليكم آيات الله } وهو على وجه التعجب ظاهره ؟  ولكنه على طلب الحجة في كفرهم {  وفيكم رسوله } يدفع عنكم الشبهة التي عرضت لكم بإلقاء الكفار إليكم {  ومن يعتصم بالله } أي من جعل الله جل وعلا ملجأ له ومفزعا عند الشبه والإشكال {  فقد هدي إلى صراط مستقيم } أي يحفظه عن الشبه ،   ويرشده {  إلى صراط مستقيم } والله أعلم ،   ويحتمل {  ومن يعتصم بالله } يتمسك بالذي جاء من القرآن {  فقد هدي إلى صراط مستقيم } .
