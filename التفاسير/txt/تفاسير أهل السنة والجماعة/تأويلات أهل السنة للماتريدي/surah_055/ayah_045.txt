الآية 45 وقوله تعالى :  {  فبأي آلاء ربكما تكذبان } من الناس من قال في قوله {  فبأي آلاء ربكما تكذبان } على إثر الوعيد إنما يقال لهم في الآخرة :  {  فبأي آلاء ربكما تكذبان } في الدنيا كقوله عز وجل :  {  وسيق الذين كفروا إلى جهنم زمرا } إلى قوله :  {  وقال لهم خزنتها ألم يأتكم رسل منكم } الآية [ الزمر :  71 ] .
