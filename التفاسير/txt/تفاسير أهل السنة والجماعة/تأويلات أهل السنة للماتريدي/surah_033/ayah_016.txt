الآية 16 وقوله تعالى :  {  قل لن ينفعكم الفرار إن فررتم من الموت أو القتل } قال أهل التأويل :  إن قضى عليكم الموت أو القتل فلن ينفعكم الفرار .   وقال بعضهم :  إن جعل القضاء آجالكم الموت أو القتل فلن(  ) ينفعكم الفرار ،   بل ينقضي .

وأصله :  إن كان المكتوب عليكم [ الموت ](  ) أو القتل فلن(  ) ينفعكم الفرار منه ،   بل يأتي ،   لا محالة ،   كقوله :  {  لبرز الذين كتب عليهم القتل إلى مضاجعهم } الآية [ آل عمران :  154 ] أي لا محالة ،   والمكتوب عليهم القتل ،   وإن كانوا في بيوتهم لبرزوا فيقتلون .

[ وقوله تعالى ](  ) :  {  وإذا لا تمتعون إلا قليلا } قال بعضهم :  إن الدنيا قليل إلى آجالكم .   وجائز أن يكون معناه :  ولئن نفعكم الفرار عنه فلا تمتعون إلا قليلا كقوله :  {  أفرأيت إن متعناهم سنين } {  ثم جاءهم ما كانوا يوعدون } [ الشعراء : 205 و206 ] .

قال أبو عوسجة والقتبي :  {  أدعياءكم } [ الأحزاب :  4 ] من [ تبنيتموهم ،   واتخذتموهم ](  ) ولدا ،   ما جعلهم بمنزلة [ ولد ](  ) الصلب ،   وكانوا يورثون من ادعوا {  ذلكم قولكم بأفواهكم } إن قولكم على التشبيه والمجاز ،   ليس على التحقيق ،   {  والله يقول الحق } [ الأحزاب :  4 ] .   وقوله :  {  أقسط } [ الأحزاب :  5 ] أعدل [ وقوله ](  ) :  {  وإذ زاغت الأبصار } عدلت ومالت :  {  وبلغت القلوب الحناجر } [ الأحزاب :  10 ] أي كادت تبلغ الحلقوم من الخوف ،   والحناجر جماعة الحنجرة ،   وهي المذبح .   وقوله :  {  وزلزلوا زلزالا شديدا } [ الأحزاب :  11 ] شدد عليهم ،   وهوّلوا ،   والزلزال :  الشدائد ،   وأصلها من التحريك [ وقوله ](  ) :  {  اللائي تظاهرون منهم } [ الأحزاب :  4 ] اللائي :  ما لها واحد ،   والله أعلم .
