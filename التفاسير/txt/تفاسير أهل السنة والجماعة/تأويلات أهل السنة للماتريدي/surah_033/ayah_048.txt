الآية 48 وقوله تعالى :  {  ولا تطع الكافرين والمنافقين } هذا قد ذكرناه في أول السورة .

وقوله تعالى :  {  ودع أذاهم } هذا يحتمل أعرض عنهم ،   ولا تكافئهم بما يؤذونك ،   ويحتمل(  ) :  {  ودع أذاهم } [ أي اصبر على أذاهم ](  ) .

وقوله تعالى :  {  وتوكل على الله } أي اعتمد بالله {  وكفى بالله وكيلا } أي كفر بالله معتمدا ،   ويحتمل(  ) :  {  وكفى بالله وكيلا } أي حافظا أو مانعا ،   والله أعلم .
