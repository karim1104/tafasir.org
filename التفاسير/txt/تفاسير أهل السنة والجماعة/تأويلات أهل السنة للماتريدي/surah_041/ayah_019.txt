الآية 19 وقوله تعالى :  {  وَيَوْمَ يُحْشَرُ أَعْدَاءُ اللَّهِ إِلَى النَّارِ } أي يُجمع ،   الحشر الجمع ،   يُجعلون في النار ،   وهو كقوله {  احْشُرُوا الَّذِينَ ظَلَمُوا وَأَزْوَاجَهُمْ وَمَا كَانُوا يَعْبُدُونَ مِنْ دُونِ اللَّهِْ } [ الصافات :  22 ] .

وقوله تعالى :  {  فَهُمْ يُوزَعُونَ } أي يساقون /484 –أ/ كقوله تعالى :  {  وسيق الذين كفروا إلى جهنم زُمرًا } [ الزمر :  71 ] وقال بعضهم :  يوزعون أي يُدفعون كقوله تعالى :  {  يوم يدعّون إلى نار جهنم دعًّا } [ الطور :  13 ] والوزع الدّفع .   وقال بضعهم :  {  يوزَعُون } أي يُحبَسون ،   أي يحبس أولهم على آخرهم حتى إذا اجتمعوا جميعا فعند ذلك يجعلون في النار كقوله تعالى :  {  ليميز الله الخبيث من الطّيب } [ الأنفال :  37 ] .
