[ الآيتان 61 و62 وقوله تعالى :  {  فلما تراءى الجمعان } جمع موسى وجمع فرعون ،   أي رأى بعضهم بعضا {  قال أصحاب موسى إنا لمدركون } {  قال } موسى {  قال كلا إن معي ربي سيهدين } .   كان قوم موسى لم يعلموا بالبشارة التي بشرها الله موسى أنهم لا يدركون ،   وهو ما قال :  {  لا تخاف دركا ولا تخشى } [ طه : 77 ] أي لا تخاف دركهم ،   ولا تخشى فرعون وقومه .   لذلك قالوا :  {  إنا لمدركون } .

وكانت البشارة لهم لا لموسى خاصة .   يدل [ على ] ذلك قول موسى {  كلا إن معي ربي سيهدين } على إثر قولهم {  إنا لمدركون } أي كلا إنهم لا يدركونكم .
