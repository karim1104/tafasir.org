[ الآية 167 ] وقوله تعالى :  {  قالوا لئن لم تنته يا لوط لتكونن من المخرجين } ذكر الانتهاء ،   ولم يبين مماذا ؟  فجائز أن يكونوا {  قالوا لئن لم تنته يا لوط } من تعييرك الذي تعيرنا به {  لتكونن من المخرجين } بقولك :  {  إنكم لتأتون الفاحشة ما سبقكم بها من أحد من العالمين } [ العنكبوت :  28 ] وقولك :  {  وتذرون ما خلق لكم ربكم من أزواجكم } [ الشعراء : 166 ] .

ويحتمل :  {  لئن لم تنته يا لوط } من دعائك الذي تدعونا إليه {  لتكونن } كذا .

وقوله تعالى :  {  لتكونن من المخرجين } يحتمل نفس الإخراج ،   أي نخرجك من القرية ومن بيننا .

وجائز أن يكونوا  أرادوا بالإخراج إخراجا بالقتل كقوله  قوم نوح حين {  قالوا لئن لم تنته يا نوح لتكونن من المرجومين } [ الشعراء : 116 ] وهو أشبه .
