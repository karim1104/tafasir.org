[ الآيتان 92 و93 ] وقوله تعالى :  {  وقيل لهم أين ما كنتم تعبدون } {  من دون الله } في الدنيا/383- ب/ أي ثم يقال لهم :  {  أين ما كنتم تعبدون } {  ومن دون الله } في الدنيا ؟  {  هل ينصرونكم } ويمنعونكم من عذاب الله {  أو ينتصرون } هم من العذاب ؟  لأنهم يطرحون جميعا :  العابدون والمعبودون في النار كقوله :  {  إنكم وما تعبدون من دون الله حصب جهنم } [ الأنبياء : 98 ] .

وإنما قالوا ذلك لهم [ لأنهم ]  كانوا يقولون في الدنيا {  هؤلاء شفعاؤنا عند الله } [ يونس :  18 ] [ ويقولون :  ] {  ما نعبدهم إلا ليقربونا إلى الله زلفى } [ الزمر : 3 ] فيقال لهم مقابل ذلك في الآخرة :  {  هل ينصرونكم } الآية ؟
