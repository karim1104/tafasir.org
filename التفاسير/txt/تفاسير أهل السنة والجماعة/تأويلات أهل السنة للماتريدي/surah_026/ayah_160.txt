[ الآية 160و161و162و163و164و165 ] وقوله تعالى :  {  كذبت قوم لوط المرسلين } قد ذكر بالتأنيث على إضمار :  جماعة ؛  كأنه قال :  كذبت [ جماعة ]  قوم لوط المرسلين {  إذ قال لهم أخوهم لوط ألا تتقون } إلى قوله :  {  العالمين } قد ذكرنا في ما تقدم .

وقوله تعالى :  {  أتأتون الذكران من العالمين } كقوله  في آية أخرى :  {  إنكم لتأتون الفاحشة ما سبقكم بها من أحد من العالمين } [ العنكبوت : 28 ] .
