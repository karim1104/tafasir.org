الآية :  63 وقوله تعالى :  {  قالوا بل جئناك بما كانوا فيه يمترون } هذا ليس بجواب لما سبق من قومه من قوله :  {  قال إنكم قوم منكرون } ولكن قالوا ذلك له ،   والله أعلم بعد ما كان بين لوط وبين قومه مجادلات ومخاصمات :  من ذلك قوله  :  {  قال إن هؤلاء ضيفي فلا تفضحون } {  واتقوا الله ولا تخزون } ( الحجر :  68 و 69 ) وغير ذلك من المخاصمات .   وقد كان لوط يعدهم العذاب بصنيعهم الذي كانوا يصنعون .   ولذلك قالوا له :  {  فاتنا بما تعدنا إن كنت من الصادقين } ( الأعراف :  70 ) فعند ذلك قالوا :  {  بل جئناك بما كانوا فيه يمترون } .

قال بعضهم :  بما كانوا فيه يشكون بما كان يعدهم من العذاب .   وقال بعضهم :  {  بما كانوا فيه يمترون } يجادلون ،   وينازعون .   أو يقول :  {  بل جئناك } بجزاء ما {  كانوا فيه يمترون } .

ثم امتراؤهم يحتمل مجادلتهم إياه وما كانوا عليه من الريبة .
