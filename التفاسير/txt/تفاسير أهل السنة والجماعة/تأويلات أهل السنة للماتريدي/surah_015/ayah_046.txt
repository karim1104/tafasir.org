الآية 46 :  وقوله تعالى :  {  ادخلوها بسلام آمنين } قال بعضهم :  قوله :  {  ادخلوها بسلام } أي اجعلوا دخولكم فيها بسلام على ما أمرهم في الدنيا أن يجعلوا الدخول في المنازل كقوله :  {  فإذا دخلتم بيوتا فسلموا على أنفسكم تحية } الآية ( النور :  61 ) وعلى ما أخبر أن الملائكة يسلمون عليهم كقوله : {  سلام عليكم طبتم } ( الزمر :  3 ) وكقوله :  {  ونبئهم عن ضيف إبراهيم } {  إذ دخلوا عليه فقالوا سلاما } ( الحجر :  51 و 52 ) .

وقال بعضهم :  قوله :  {  ادخلوها بسلام آمنين } أي ادخلوها بسلام ،   لا يصيبكم مكروه {  آمنين } لا ينغصكم خوف ولا حزن على ما أخبر :  {  فلا خوف عليهم ولا هم يحزنون } ( البقرة :  38 و .   .   .   .   .   .   .   .   ) .
