الآية :  58 :  {  قالوا إنا أرسلنا إلى قوم مجرمين } لم يحتمل أن يكون أول ما أخبروا إبراهيم ،   وقالوه ،   هذا ،   ولكن كان فيه ما ذكر في آية أخرى قالوا :  {  إنا مهلكوا أهل هذه القرية إن أهلها كانوا ظالمين } ( العنكبوت :  31 ) وقالوا ( 12 ) :  {  إنا منزلون على أهل هذه القرية رجزا من السماء بما كانوا يفسقون } ( العنكبوت :  34 ) فقال إبراهيم :  {  إن فيها لوطا قالوا نحن أعلم بمن فيها } ( العنكبوت :  32 ) .
