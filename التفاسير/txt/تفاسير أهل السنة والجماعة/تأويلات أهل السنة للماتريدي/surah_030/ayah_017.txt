الآية 17 وقوله تعالى :  {  فسبحان الله حين تمسون وحين تصبحون } قوله :  {  فسبحان الله } فهمت الأمة من قوله :  {  فسبحان الله } الصلاة ،   أي صلوا لله .   ولو كانت أفهام أهل زماننا هذا لكانوا لا يفهمون سوى التسبيح المذكور .

ثم يحتمل تسميتهم التسبيح صلاة وفهمهم منه ذلك لوجهين :

أحدهما :  لما في الصلاة تسبيح ،   فسموها بذلك لما فيها ذلك .

[ والثاني ](  ) :  لما أن التسبيح تنزيه ،   والصلاة من أولها إلى أخرها تنزيه الرب لأن فيها إظهار الحاجات إليه والعجز والضعف ،   ومنها تعظيم الرب وإجلاله ووصفه بالجلال والرفعة .   ففهموا من التسبيح الصلاة لما ذكرنا لما هي في(  ) تنزيه الرب من أولها إلى آخرها .

ثم منهم من قال :  إن الصلوات الخمس ذكرت في هذه الآية [ والتي تليها ](  ) بقوله :  {  فسبحان الله حين تمسون } صلاة المغرب والعشاء الآخرة {  وحين تصبحون } صلاة الفجر {  وعشيا } صلاة العصر {  وحين تظهرون } صلاة الظهر .

ومنهم من يقول :  لا بل ذكرت [ فيهما أربع ](  ) صلوات {  حين تمسون } المغرب {  وحين تصبحون } الفجر {  وعشيا } العصر {  وحين تظهرون } الظهر .   وأما العشاء الآخرة ففي قوله :  {  ومن بعد صلاة العشاء ثلاث عورات لكم } [ النور :  58 ] والله أعلم .
