الآية 81 :  وقوله تعالى :  {  فأردنا أن يبدلهما ربهما خيرا منه زكاة وأقرب رحما } قال بعضهم :  {  خيرا منه زكاة } أي صلاحا {  وأقرب رحما } وأبر بوالديه .   وقال بعضهم :  {  خيرا منه زكاة } أي عملا {  وأقرب رحما } أي وأحسن منه برا لوالديه .

وقال أبو عوسجة :  {  رحما } من الرحم والقرابة .   وقال القتبي :  {  رحما } أي رحمة وعطفا .   وذكر أنهما قد أعطيا خيرا منه ،   أي خيرا من القتيل ،   والله أعلم .
