الآية 273 وقوله تعالى :  {  للفقراء الذين أحصروا في سبيل الله } ؛  قيل :  [ {  للفقراء الذين أحصروا في سبيل الله ] أي } :  من سبيل الله ،   يعني حسبوا بالفقراء عن الجهاد .   وهو كقوله :  {  ولا على الذين لا يجدون ما ينفقون حرج } [ التوبة :  91 ] ،   والعرب تستعمل حروف الخفض بعضها في [ موضع ] بعض .   ويحتمل قوله :  تعالى {  أحصروا في سبيل الله } أي حبسوا أنفسهم في طاعة الله .   لا يجدون ما يتجرون ولا ما يحترفون ولا ما يكتسبون .

وقوله تعالى :  {  لا يستطيعون ضربا في الأرض } للتجارة .

وقوله تعالى :  {  لا يسألون الناس إلحافا } يحتمل وجهين :  يحتمل لا يظهرون السؤال ،   أي لا يسألون كقوله تعالى :  {  ولا تنفعها شفاعة } [ البقرة :  123 ] أي لا يشفع لهم ،   ويحتمل :  فإن كان على السؤال فإنهم إذا سألوا لم يحلفوا ؛  دليله قوله صلى الله عليه وسلم :  ( من فتح على نفسه بابا من المسألة فتح عليه بابا من الفقر ) [ البيهقي في شعب الإيمان 3526 ] وما ذكر في الخبر :  ( من استغنى أغناه الله ،   ومن استعف أعفه الله ) [ النسائي 5/98 ] وإن كان على التعريض ففيه إباحة التعريض بين يدي أهل الجود والسخاء .

وقوله تعالى :  {  تعرفهم بسيماهم } ؛  [ قيل :  {  بسيماهم } يعني التشجيع ] وقيل {  بسيماهم } بسيماء الفقر [ عليهم ] {  لا يسألونك الناس إلحافا } وقيل :  {  تعرفهم بسيماهم } أي بتحملهم {  لا يسألون الناس إلحافا } إي إلحاحا ولا غير إلحاح .
