الآية 268 وقوله تعالى :  {  الشيطان يعدكم الفقر ويأمركم بالفحشاء } ؛  قوله :  {  يعدكم الفقر } في الدنيا بالتصدق والأنفاق {  ويأمركم بالفحشاء } بترك الصدقة ،   ويحتمل {  يعدكم الفقر } في الدنيا بطول الأمل وفناء المال ،   {  ويأمركم بالفحشاء } بسوء الظن بربه ،   {  والله يعدكم مغفرة منه } بالصدقة {  وفضلا } وذكرا في الدنيا ،   ويحتمل /39- ب/ قوله :  {  والله يعدكم مغفرة منه } في الآخرة {  وفضلا } في الدنيا ؛  يعني خلفا ،   وقيل :  {  مغفرة } لكم لفحشائكم {  وفضلا } لفقركم .

وقوله تعالى :  {  والله واسع عليم } أي غني يقدر على إخلاف ما أنفقتم {  عليم } بجزاء صدقاتكم ،   ويحتمل {  عليم } ما تنفقون من الصدقة والهبة .   وفي قوله :  {  والله واسع عليم } و {  والله غني حميد } [ البقرة :  266 ] ونحوه [ دلالة أن الله تعالى ] إنما رغب الناس على الصدقات والنفقات ابتلاء ومحنة منه لا حاجة وفقرا .
