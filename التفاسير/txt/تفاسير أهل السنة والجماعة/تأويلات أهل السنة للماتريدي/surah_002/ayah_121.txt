الآية 121 وقوله تعالى :  {  الذين آتيناهم الكتاب يتلونه حق تلاوته أولئك يؤمنون به } قيل :  {  الكتاب } أراد به التوراة [ أو الإنجيل ،   وقيل :

{  الكتاب } أراد به القرآن ،   وقيل :  {  الكتاب } أراد به التوراة والإنجيل ] .   ومن حمله على التوراة والإنجيل قال :  فيه إضمار ،   وكأنه قال :  الذين آتيناهم الكتاب [ التوراة والإنجيل ] {  يتلونه حق تلاوته [ أولئك ] يؤمنون به } [ أي ] إذا تلوا حق التلاوة فحينئذ يؤمنون به .   وقيل :  {  يتلونه حق تلاوته } يعني يعملون به حق عمله ،   ولا يكتمون بعثه صلى الله عليه وسلم ولا يحرفونه {  أولئك يؤمنون به } وهم الذين أسلموا منهم ،   وقيل :  يتبعونه حق اتباعه ،   وهو واحد .   ومن حمله على القرآن فالذين

{  يتلونه حق تلاوته } أصحاب رسول الله صلى الله عليه وسلم .

[ وقوله :  {  ومن يكفر به فأولئك هم الخاسرون } قد ذكرنا في ما تقدم .
