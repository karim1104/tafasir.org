الآية 53 وقوله تعالى :  {  وكل صغير وكبير مُستطَر } هذا أيضا يخرّج على هذين الوجهين :

أحدهما :  {  مُستطَر } في الكتب التي قبلهم .

[ والثاني :  {  مُستطَر } في كتب ] الذين يُملون على الحَفَظة كقوله تعالى :  {  ما يلفِظ من قول إلا لديه رقيب عتيد } [ ق :  18 ] وقوله تعالى :  {  إن المجرمين في ضلال وسُعُر } {  يوم يُسحَبون في النار } [ القمر :  47 و48 ] وقوله في موضع آخر :  {  إن المجرمين في عذاب جهنم خالدون } [ الزخرف :  74 ] .
