الآية 26 وهو قوله تعالى :  {  قل الله يُحييكم ثم يُميتكم ثم يجمعكم إلى يوم القيامة } يحتمل قوله :  {  قل الله يُحييكم } أي يُحييكم في قبوركم {  ثم يُميتكم } فيها {  ثم يجمعكم إلى يوم القيامة } أو يقول :  الله يُحييكم في ابتداء الأمر ،   ثم يُميتكم في الدنيا عند انقضاء آجالكم {  ثم يجمعُكم إلى يوم القيامة } .

وقوله تعالى :  {  ولكن أكثر الناس لا يعلمون } أي ولكن أكثر الناس لا [ ينتفعون بما ] يعلمون لما تركوا النظر والتأمّل في أسباب العلم .
