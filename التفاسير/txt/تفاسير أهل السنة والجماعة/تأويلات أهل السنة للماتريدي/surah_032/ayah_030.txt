الآية 30 [ وقوله تعالى ](  ) :  {  فأعرض عنهم } محمد إلى مدة {  وانتظر } بهم العذاب أي القتل وهلاكهم {  إنهم منتظرون } هلاككم .   وقال بعضهم :  {  فأعرض عنهم } إلى ذلك اليوم {  وانتظر } بهم فتح مكة {  إنهم منتظرون } هلاكك .

[ ويحتمل ](  ) أن يكون قوله :  {  فأعرض عنهم } أي لا تكافئهم لأذاهم إياك {  وانتظر } مكافأتنا إياهم {  إنهم منتظرون } .   والله أعلم [ بالصواب ] (  ) .
