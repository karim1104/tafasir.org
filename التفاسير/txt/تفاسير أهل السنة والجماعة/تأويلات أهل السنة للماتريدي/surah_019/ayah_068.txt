الآية 68 :  ثم أقسم أنهم يبعثون ،   فقال :  {  فوربك لنحشرنهم والشياطين } أي لنجعلنهم والشياطين الذي أضلوهم كقوله :  {  احشروا الذين ظلموا وأزواجهم وما كانوا يعبدون } {  من دون الله } الآية [ الصافات :  22 و23 ] .

وقوله تعالى :  {  ثم لنحضرنهم حول جهنم جثيا } قال بعضهم :  {  جثيا } جماعات كقوله :  {  وسيق الذين كفروا إلى جهنم زمرا } [ الزمر :  71 ] وقال بعضهم :  {  جثيا } على الركب لأن أقدامهم لا تحملهم لشدة هول ذلك اليوم .
