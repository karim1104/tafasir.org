الآيتان 121و122 وقوله تعالى :  {  قالوا آمنا برب العالمين } {  رب موسى وهارون } قال بعض أهل التأويل :  إنهم لمّا {  قالوا آمنا برب العالمين } قال لهم فرعون :  إياي تعنون ؟  فعند ذلك قالوا :  لا ،   ولكن {  رب موسى وهارون } ولكن لا ندري هذا ،   وموسى أول ما جاء فرعون ،   ودعاه إلى دينه ،   قال له :  {  يا فرعون إني رسول من رب العالمين } [ الأعراف :  104 ] فلا يحتمل أن يشكل عليه قولهم :  {  آمنا برب العالمين } [ فيظن ] أنهم إياه عنوا بذلك .

وجائز أن يكون {  آمنا برب العالمين } الذي أرسل موسى وهارون رسولين .
