الآية19 :  وقوله تعالى {  ومن أراد الآخرة وسعى سعيها وهو مؤمن } تفسير قوله :  {  من كان يريد العجلة عجلنا له فيها ما نشاء لمن نريد } كأنه قال :  من كان يريد العاجلة وهو كافر بربه مكذب بالآخرة {  عجلنا له فيها ما نشاء لمن نريد } {  ومنكم من يريد الآخرة } وهو مؤمن بربه مصدق بالآخرة {  وسعى لها سعيها وهو مؤمن } بها {  فأولئك كان سعيهم مشكورا } أي مجزيا مقبولا .
