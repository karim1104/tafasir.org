الآية 95 :  وقوله تعالى :  وحرم{  على قرية أهلكناها } و{  حرام } بالألف أيضا .   ثم قوله :  وحرم {  وحرام } على قول أهل اللسان واللغة واحدة .   يقول :  حرم عليك كذا ،   وحرام ،   كما يقال :  حل وحلال .

وأما على قول أهل التأويل فإنهم يفرقون بينهما ،   فيقولون :  وحرم حتم وواجب {  على قرية أهلكناها أنهم لا يرجعون } أو حكم وواجب {  على قرية } إهلاكهم بعدما علم {  أنهم لا يرجعون } أي لا يتوبون ،   لأنه إنما يهلكهم لما علم منهم أنهم لا يتوبون .

أو يكون قوله :  {  وحرام على قرية } أراد الله إهلاكها {  أنهم لا يرجعون } [ وظاهر قوله :  {  وحرام على قرية أهلكناها أنهم لا يرجعون } ] أن يكون لهم الرجوع لأنه يقول :  {  وحرام على قرية أهلكناها أنهم لا يرجعون } .

ألا ترى إلى قوله :  {  حتى إذا فتحت يأجوج ومأجوج } ؟  [ الأنبياء :  96 ] وظاهره {  أنهم لا يرجعون } {  حتى إذا فتحت يأجوج ومأجوج } {  واقترب الوعد الحق } [ الأنبياء :  96 و97 ] فعند ذلك يرجعون لقوله :  {  فإذا هي شاخصة أبصار الذين كفروا } [ الأنبياء :  97 ] .

أو يكون ذكر هذا {  أنهم لا يرجعون } لقول قوم :  لأن قوما يقولون :  إن الخلق كالنبات ينبت ،   ثم ييبس ،   ثم ينبت .   فعلى ذلك الخلق يموتون ،   ثم يعودون ،   ويرجعون .

وبعض من الروافض يقولون :  يرجع علي وفلان ،   فأخبر أنهم لا يرجعون ردا عليهم وتكذيبا لخبرهم لأن القرآن قد صار حجة عليهم ،   وإن أنكروه ،   لما عجزوا عن أن يأتوا بمثله ،   والله أعلم بذلك كله .
