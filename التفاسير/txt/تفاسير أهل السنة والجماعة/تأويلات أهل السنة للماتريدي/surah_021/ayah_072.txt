الآية 72 :  وقوله تعالى :  {  ووهبنا له إسحاق ويعقوب نافلة } قال بعضهم :  النافلة العطية .   وقال بعضهم :  النافلة الفضل .

وأصل النافلة الغنيمة كقوله :  {  يسألونك عن الأنفال } [ الأنفال :  1 ] أي الغنائم .   والولد وولد الولد فضل منه وعطية وغنية ،   لأنه سمى الولد هبة بقوله :  {  يهب لمن يشاء إناثا ويهب لمن يشاء الذكور } [ الشورى :  49 ] وسمى [ الوالد مُوهَبا ]  وخاصة إبراهيم [ إذا ]  لم يكن يطمع أن يولد له الولد ،   فكيف يطمع بولد الولد ؟

وقوله تعالى :  {  وكلا جعلنا صالحين } يحتمل قوله :  {  صالحين } رسلا ،   أو {  صالحين } في كل أمر وكل شيء .
