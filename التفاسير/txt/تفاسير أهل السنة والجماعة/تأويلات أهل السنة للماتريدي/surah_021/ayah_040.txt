الآية 40 :  وقوله تعالى :  {  بل تأتيهم بغتة } أي فجأة ،   لا يعلم أهلها عن وقت وقوعها {  فتبهتهم } قال أهل التأويل :  {  فتبهتهم } فتفجأهم .   والبهتة كأنها حيرة .   يقول :  {  تأتيهم بغتة } فجأة ،   فتُحيرهم ،   وهو ما أخبر :  {  وترى الناس سكارى وما هم بسكارى } [ الحج :  2 ] وذلك لحيرتهم في أنفسهم ،   وهو ما ذكر :  {  إنما يؤخرهم ليوم تشخص فيه الأبصار } الآية [ إبراهيم :  42 ] يصيرون حيارى لشدة أهوالها .

وقوله تعالى :  {  فلا يستطيعون ردها ولا هم ينظرون } أخبر أنهم لا يملكون دفعها إذا وقعت بهم {  ولا هم ينظرون } في وقوعها .   إن من ابتُلي بالبلايا في الشاهد فإنما يملك دفعها عن نفسه إما بقوة نفسه وإما بأنصار وأعوان ،   ينصرونه ،   ويعينونه في دفعها عنه وإما بالتضرع والابتهال والاستسلام كقوله :  {  فلولا إذ جاءهم بأسنا تضرعوا } الآية [ الأنعام :  43 ] فأخبر عز وجل [ أنهم ]  لا يملكون دفعها بقوى أنفسهم ولا بأنصارهم الذين استنصروا [ بهم حين ]  قال :  {  ولا هم ينظرون } بالتضرع والاستسلام .
