الآية 38 :  [ وقوله تعالى ]  :  {  ويقولون متى هذا الوعد إن كنتم صادقين } ويقولون أيضا :  متى هذا الوعد الذي تعدنا {  إن كنتم صادقين } بأنا نُعَذَّبُ ؟

وجائز أن تكون الآية فيهم بتكذيبهم الساعة والقيامة وإنكارهم إياها .   فقال :  {  سأوريكم آياتي } التي تكون قبل وقوعها {  فلا تستعجلون } وقوعها ومجيئها .

دليله ما ذكر {  لو يعلم الذين كفروا حين لا يكفون عن وجوههم النار ولا عن ظهورهم ولا هم ينصرون } [ الأنبياء :  39 ] وقوله تعالى :  {  بل تأتيهم بغتة } الآية [ الأنبياء :  40 ] .
