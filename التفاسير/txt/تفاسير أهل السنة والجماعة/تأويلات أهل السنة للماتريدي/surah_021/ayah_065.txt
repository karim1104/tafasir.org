الآية 65 :  وقوله تعالى :  {  ثم نكسوا على رؤوسهم لقد علمت ما هؤلاء ينطقون } قوله :  {  ثم نكسوا على رؤوسهم } للتفكر والنظر في قول إبراهيم حين {  قال بل فعله كبيرهم هذا فسألوهم إن كانوا ينطقون } [ الأنبياء :  63 ] إنما علق فعل الكبير بهم إن نطقوا ،   فقالوا :  {  لقد علمت } /341-أ/ يا إبراهيم {  ما هؤلاء ينطقون } فكيف قلت :  {  بل فعله كبيرهم هذا فسألوهم } ؟  فإذا كانوا لا ينطقون لم يفعل كبيرهم .
