الآية 44 وقوله تعالى :  {  وأنه هو أمات وأحيا } قوله :  {  أمات وأحيا } يحتمل وجهين :

أحدهما :  أي جعلهم بحيث يموتون وبحيث يحيَون .

والثاني :  {  أمات } بإخراج الرّوح {  وأحيا } بإدخال الروح فيهم ،   وهو كقوله تعالى :  {  خلق الموت والحياة } [ الملك :  2 ] وقوله :  {  خلقكم ثم رزقكم ثم يُميتكم ثم يُحييكم } [ الروم :  40 ] فيحتمل إماتتهم في لدنيا وإحياءهم في الآخرة .   وأصل ذلك أنه يفعل بهم كل ما ذكرنا .
