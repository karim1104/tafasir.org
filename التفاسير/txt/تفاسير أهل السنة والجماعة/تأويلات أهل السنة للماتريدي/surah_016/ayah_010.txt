الآية 10 :  وقوله تعالى :  {  هو الذي أنزل من السماء ماء } موصول بقوله :  {  خلق السماوات والأرض بالحق } ( الآية :  3 ) وقوله :  {  خلق الإنسان من نطفة } ( الآية :  4 ) وقوله :  والأنعام خلقها } ( الآية :  5 ) [ وقوله ] :  {  والخيل والبغال والحمير } ( الآية :  8 ) يقول :  الذي خلق لكم ما ذكر [ من ] الأشياء {  هو الذي أنزل من السماء ماء لكم منه شراب ومنه شجر } هذا يحتمل ما ذكرناه أنه {  أنزل من السماء ماء } لنا [ ثم ] أخبر{  لكم منه شراب ومنه شجر } .

ثم يحتمل قوله :  {  منه شراب } جميع ما يشرب من الأشربة ؛  إذ منه تكون الأشربة وجميع الأشياء .   ويحتمل {  منه شراب } الماء خاصة {  ومنه شجر } الشجر معروف ؛  هو الذي يعلو ،   ويرتفع على الأرض ،   لا يسمى الحشيش ،   وما ينبسط على وجه الأرض [ يسمى حشيشا ] .   فظاهر هذا أن يرجع إلى ذلك المعروف إلا أنه ذكر شجرا {  فيه تسيمون } أي تزرعون .

دل أنه إنما أراد بالشجر المنبسط على وجه الأرض والمرتفع عليها .

وقال القتبي :  السائمة الراعية ،   وكذلك قال أبو عوسجة .   وقال أبو عبيدة :  أسمت سائمتي أي رعيتها ،   وكذلك قوله :  {  والخيل المسومة } ( آل عمران :  14 ) أي الراعية .
