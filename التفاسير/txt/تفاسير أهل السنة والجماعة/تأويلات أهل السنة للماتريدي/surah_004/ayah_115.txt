الآية 115

وقوله تعالى : {  ومن يشاقق الرسول من بعد ما تبين له الهدى ويتبع غير سبيل المؤمنين }قيل :  ( لما تبينت ) خيانته لرسول الله صلى الله عليه وسلم استحيى أن يقيم بالمدينة ،   فارتد ،   ولحق بمكة كافرا ،   فنزل قوله تعالى : {  ومن يشاقق الرسول } ؛  يقول :  يخالف الرسول{  من بعد ما تبين له الهدى ويتبع غير سبيل المؤمنين } .

وعن ابن عباس رضي الله عنه ( أنه قال ) :  ( {  من بعد ما تبين له الهدى } من بعد ما كان كافرا تبين الإسلام ) وقال :  ( لما بان أمر طعمه ( بن أبيرق ) ،   وعلم أنه سرق الدرع ،   وأنزل الله تعالى : {  والسارق والسارقة فاقطعوا أيديهما } ( المائدة : 38 ) ،   قيل له :  يا طعمة إن رسول الله صلى الله عليه وسلم ( قاطع يدك ،   فخرج ) هاربا إلى مكة ) .

وقوله تعالى : {  ويتبع غير سبيل المؤمنين } يعني غير دين المؤمنين .   وفي حرف ابن مسعود رضي الله عنه :  ( ويسلك غير سبيل المؤمنين ) .

وقوله تعالى : {  نوله ما تولى } أي نتركه وما تولى من ولاية الشيطان .   وقيل :  ندعه وما اختار غير دن المؤمنين {  ونصله جهنم } أي ندخله جهنم في الآخرة .   وقيل :  قوله تعالى : {  نزله ما تولى } أي نوله في الآخرة ما تولى في الدنيا {  وساءت مصيرا } يقول :  بئس المصير ( الذي ) صار إليه .

وقوله تعالى : {  نوله ما تولى } إنه تولى الشيطان ،   فجعله الله وليا( له ) كقوله تعالى : {  ومن يتخذ الشيطان وليا } ( النساء :  119 ) وغير ذلك .   ويكون : {  يتخذ } له في ما اختاره ،   ويكون :  ( ما تلوى ) جزاء توليه ،   ويكون ( له من الخلق ) جورا باطلا مهلكا له ،   والله أعلم .
