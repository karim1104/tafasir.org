الآية 110

وقوله تعالى : {  ومن يعمل سواء أو يظلم نفسه } هما سواء ؛  أي من عمل سواء فقد ظلم نفسه ،   ومن ظلم نفسه فقد عمل سوءا .   ويحتمل ما قال ابن عباس :  ( {  ومن يعمل سوءا }إلى الناس{  أو يظلم نفسه } في ما بينه وبين الله ) .

ثم روي عن عبد الله بن مسعود رضي الله عنه ( أنه ) قال :  ( أرجى آية  في القرآن هذه :  قوله تعالى : {  ومن يعمل سوءا أو يظلم نفسه } الآية ) .   وروي عنه أيضا ( أنه قال ) :  ( أربع آيات من كتاب الله تعالى أحب إلي من حمر النعم وسودها :  قوله تعالى : {  إن الله لا يظلم مثقال ذرة وإن تك حسنة يضاعفها } إلى آخره ( النساء :  40 ) وقوله تعالى : {  إن الله لا يغفر أن يشرك به ويغفر ما دون ذلك لمن يشاء } ( النساء :  48و116 ) وقوله تعالى : {  ولو أنهم إذا ظلموا أنفسهم جاؤوك فاسغفروا الله }( النساء :  64 ) وقوله تعالى : {  ومن يعمل سوءا أو يظلم نفسه } الآية ) ( النساء :  110 ) .

وعن علقمة والأسود ( أنهما ) قالا :  ( قال عبد الله :  إن في كتاب الله لآيتين ،   ما أصاب عبد ذنبا ،   فقرأهما ،   ثم استغفر الله إلا غفر له :  ( الأولى ) {  والذين إذا فعلوا فاحشة أو ظلموا أنفسهم } إلى آخر الآية ( آل عمران :  135 ) ( والثانية :  ) {  ومن يعمل سوءا أو يظلم نفسه ثم يستغفر الله } ( النساء : 110 ) .   وقوله تعالى : {  ومن يكسب خطيئة أو إنما } ( النساء : 112 ) يحتمل كل واحد منهما أنه الآخر ،   كرر على التأكيد ما جرى له الذكر .   ويحتمل التفريق أن يكون سوءا إلى الناس وخطيئة إليهم ،   أو يظلم نفسه بما يأثم بينه وبين الله .
