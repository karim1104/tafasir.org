{  هل جزاء الإحسان إلا الإحسان } ( 59 )

1078- قد تكون [ هل ] بمعنى قد ،  كقوله تعالى :  {  هل أتى على الإنسان }  والمختار أن معناه :  استدعاء التقرير ،  كقوله :  {  هل جزاء الإحسان إلا الإحسان } .  ( المنخول :  91 )

1079- {  هل جزاء الإحسان إلا الإحسان } قيل :  الإحسان في الدنيا :  قول لا إله إلا الله ،  وفي الآخرة :  الجنة .  ( الإحياء :  1/345 )

1080- {  هل جزاء الإحسان إلا الإحسان } ومنتهى الإحسان رضا الله عن عبده ،  وهو ثواب رضا العبد عن الله تعالى .  ( نفسه :  4/363 )
