قوله تعالى : { وسيق الذين كفروا إلى جهنم } يعني سوقاً عنيفاً { زمراً } أفواجاً بعضهم على أثر بعض كل أمة على حدة وقيل جماعات متفرقة واحدتها زمرة { حتى إذا جاؤوها فتحت أبوابها } يعني السبعة وكانت قبل ذلك مغلقة { وقال لهم خزنتها } يعني توبيخاً وتقريعاً { ألم يأتكم رسل منكم } أي من أنفسكم ومن جنسكم { يتلون عليكم آيات ربكم وينذرونكم لقاء يومكم هذا قالوا بلى ولكن حقت كلمة العذاب } أي وجبت { على الكافرين } وهي قوله { لأملأن جهنم من الجنة أجمعين } .  { قيل ادخلوا أبواب جهنم خالدين فيها فبئس مثوى المتكبرين } .
