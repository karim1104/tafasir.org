قوله تعالى : { يا أيها الناس اتقوا ربكم } يعني خافوا ربكم { واخشوا } يعني وخافوا { يوماً لا يجزي } يعني لا يقضي ولا يغني { والد عن ولده ولا مولود هو جاز عن والده شيئاً } قيل معنى الآية إن الله ذكر شخصين في غاية الشفقة والمحبة وهما الوالد والولد فنبه بالأعلى على الأدنى وبالأدنى على الأعلى فالوالد يجزي عن ولده لكمال شفقته عليه والولد يجزي عن والده لما له من حق التربية وغيرها فإذا كان يوم القيامة فكل إنسان يقول نفسي ولا يهتم بقريب ولا بعيد كما قال ابن عباس كل امرئ تهمه نفسه { إن وعد الله حق } قيل إنه تحقيق اليوم معناه اخشوا يوماً هذا شأنه وهو كائن بوعد الله به ووعده حق وقيل الآية تحقيق بعدم الجزاء يعني لا يجزي والد عن ولده في ذلك اليوم والقول الأول أحسن وأظهر { فلا تغرنكم الحياة الدنيا } يعني لأنها فانية { ولا يغرنكم بالله الغرور } يعني الشيطان : قال سعيد بن جبير يعمل بالمعاصي ويتمنى المغفرة .
