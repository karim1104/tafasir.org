{ يوسف } أي يا يوسف { أيها الصديق } إنما سماه صديقاً لأنه لم يجرب عليه كذباً قط والصديق الكثير الصدق والذي ل يكذب قط وقيل سماه صديقاً لأنه صدق في تعبيره رؤياه التي رآها في السجن { أفتنا في سبع بقرات سمان يأكلهن سبع عجاف وسبع سنبلات خضر وأخر يابسات } فإن الملك رأى هذه الرؤيا { لعلي أرجع إلى الناس } يعني أرجع بتأويل هذه الرؤيا إلى الملك وجماعته { لعلهم يعلمون } يعني بتأويل هذه الرؤيا وقيل لعلهم يعلمون منزلتك في العلم .
