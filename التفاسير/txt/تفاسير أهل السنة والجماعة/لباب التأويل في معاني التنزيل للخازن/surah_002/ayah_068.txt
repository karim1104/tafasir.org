{ قالوا ادع لنا ربك يبين لنا ما هي } أي ما سنها ،   { قال } يعني موسى { إنه يقول } يعني الله عز وجل : { إنها بقرة لا فارض ولا بكر } أي لا كبيرة ولا صغيرة والفارض المسنة التي لم تلد ،   والبكر الفتية التي لم تلد { عوان } أي نصف { بين ذلك } أي بين السنين { فافعلوا ما تؤمرون } أي من ذبح البقرة ولا تكثروا السؤال .
