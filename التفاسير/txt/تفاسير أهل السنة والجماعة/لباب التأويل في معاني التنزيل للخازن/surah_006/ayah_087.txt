قوله تعالى : { ومن آبائهم } يعني ومن آباء الذين سميناهم ومَن هنا للتبعيض لأن من آباء بعضهم من لم يكن مسلماً { وذرياتهم } يعني ومن ذرياتهم أي بعضهم لأن عيسى ويحيى لم يكن لهما ولد وكان في ذرية بعضهم من هو كافر كابن نوح { وإخوانهم } يعني ومن إخوانهم والمعنى أن الله تعالى وفق من آباء المذكورين ومن أخوانهم وذرياتهم للهداية وخالص الدين وهو قوله تعالى : { واجتبيناهم } يعني اخترناهم واصطفيناهم { وهديناهم } يعني وأرشدناهم { إلى صراط مستقيم } أي إلى دين الحق .
