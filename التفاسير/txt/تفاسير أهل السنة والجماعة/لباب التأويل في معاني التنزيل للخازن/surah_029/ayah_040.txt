{ فكلاًّ أخذنا بذنبه فمنهم من أرسلنا عليه حاصباً } وهم قوم لوط رموا بالحصباء وهي الحصى الصغار { ومنهم من أخذته الصيحة } يعني ثمود { ومنهم من خسفنا به الأرض } يعني قارون وأصحابه { ومنهم من أغرقنا } يعني قوم نوح وفرعون وقومه { وما كان الله ليظلمهم } أي بالهلاك { ولكن كانوا أنفسهم يظلمون } أي بالإشراك .
