{ قل } أي قل يا محمد لهؤلاء الذين قالوا هذه المقالة { إن كان آباؤكم وأبناؤكم وإخوانكم وأزواجكم وعشرتكم } وقرئ على الجمع وعشيراتكم العشيرة هم الأدنون من أهل الإنسان الذين يعاشرونه دون غيرهم { وأموال اقترفتموها } يعني اكتسبتموها { وتجارة تخشون كسادها } يعني بفراقكم لها { ومساكن ترضونها } يعني تستوطنوها راضين بسكناها { أحب إليكم من الله ورسوله } يعني أحب إليكم من الهجرة إلى الله ورسوله { وجهاد في سبيله } فبين الله سبحانه وتعالى أنه يجب تحمل جميع المضار في الدنيا ليبقى الدين سليماً وأخبر أنه كانت رعاية هذه المصالح الدنيوية عندكم أولى من طاعة الله وطاعة رسوله من المجاهدة في سبيل الله { فتربصوا } أي فانتظروا { حتى يأتي الله بأمره } يعني بقضائه وهذا أمر تهديد وتخويف وقال مجاهد ومقاتل يعني بفتح مكة { والله لا يهدي القوم الفاسقين } يعني الخارجين عن طاعته ،   وفي هذا دليل على أنه إذا وقع تعارض بين مصالح الدين ومصالح الدنيا وجب على المسلمين ترجيح مصالح الدين على مصالح الدنيا .
