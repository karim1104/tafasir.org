قوله عز وجل : { فلما قضى موسى الأجل } أي أتمه وفرغ منه { وسار بأهله } قيل مكث موسى بعد الأجل عند شعيب عشر سنين أخرى ثم استأذنه في العود إلى مصر فأذن له فسار بأهله أي بزوجته قاصداً إلى مصر { آنس } أي أبصر { من جانب الطور ناراً } وذلك أنه كان في البرية في ليلة مظلمة شديدة البرد وأخذ امرأته الطلق { قال لأهله امكثوا إني آنست ناراً لعلي آتيكم منها بخبر } أي عن الطريق لأنه كان قد أخطأ الطريق { أو جذوة من النار } أي قطعة وشعلة من النار وقيل : الجذوة العود الذي اشتعل بعضه { لعلكم تصطلون } أي تستدفئون .
