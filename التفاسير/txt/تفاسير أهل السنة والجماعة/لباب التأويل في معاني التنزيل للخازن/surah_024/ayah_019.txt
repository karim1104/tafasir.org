قوله عزّ وجلّ { إن الذين يحبون أن تشيع الفاحشة } أي يظهر الزنا ويذيع { في الذين آمنوا } قيل الآية مخصوصة بمن قذف عائشة والمراد بالذين آمنوا جميع المؤمنين { لهم عذاب أليم في الدنيا } يعني الحد والذم على فعله { والآخرة } أي وفي الآخرة لهم النار { والله يعلم } أي كذبهم وبراءة عائشة وما خاضوا فيه من سخط الله { وأنتم لا تعلمون } وقيل معناه يعلم ما في قلب من يحب أن تشيع الفاحشة فيجازيه على ذلك وأنتم لا تعلمون ذلك .
