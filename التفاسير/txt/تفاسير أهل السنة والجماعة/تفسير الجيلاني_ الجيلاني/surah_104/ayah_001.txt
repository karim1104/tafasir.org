{ ويْلٌ } عظيم وهلاك هائل شديد لكل فرد من أفراد الأقوام { لِّكُلِّ هُمَزَةٍ } يمشي بين الناس بالهمز وكسر الأعراض، وصارت له هذه الديدنة القبيحة عادة راسخة مستمرة، وأيضاً لكل { لُّمَزَةٍ } [الهمزة: 1] يطعن في أنساب الأنام، وينسبهم إلى أنواع البغي والآثام افتراءً ومراءً.  وما جرَّأه وحمله على هذه الخصلة القبيحة والفعلة الوقحة إلاَّ ثروته وماله وجاهه وسيادته، فإنه { ٱلَّذِى جَمَعَ مَالاً } وأمتعة من الزخارف الدنية الدنيوية التي مالت قلوب أبنائها وأصحابها إليها { وَعَدَّدَهُ } [الهمزة: 2].  { يَحْسَبُ أَنَّ مَالَهُ أَخْلَدَهُ } [الهمزة: 3] أي: أدام وأبقى ماله نفسه وجعله مخلداً في الدنيا، مستمراً فيها أبداً، بحيث لا يطرأ عليه زوال وانتقال.  وبالجملة: اغتر بماله وجاهه إلى حيث خيل له الخلود به فيها والدوام عليها بطراً وغروراً.
