{ وَٱلْعَصْرِ } [العصر: 1] أقسم سبحانه بالعصر والدهر الذي هو عبارة عن بقاء الوجود الأزلي الأبدي ودوامه السرمدي.  { إِنَّ ٱلإِنسَانَ } المجبول على فطرة المعرفة والإيمان حسب حصته اللاهوتية { لَفِى خُسْرٍ } [العصر: 2] عظيم، وخيبة بيِّنة؛ بسبب اشتغاله بما لا يعنيه من لوازم بشريته المتعلقة بحصة الناسوت.  { إِلاَّ } الموقنين { ٱلَّذِينَ آمَنُواْ } بوحدة الحق، وتفطنوا باستقلاله في التصرفات الجارية في ملكه وملكوته { وَ } مع الإيمان والإذعان { عَمِلُواْ ٱلصَّالِحَاتِ } الدالة على إخلاصهم ويقينهم ونياتهم { وَ } مع ذلك { تَوَاصَوْاْ بِٱلْحَقِّ } أي: أوصى بعضهم بعضاً لسلوك طريق الحق وتوحيده وَتَوَاصَوْاْ } أيضاً { بِٱلصَّبْرِ } [العصر: 3] على مشاق الطاعات ومتاعب الرياضات الطارئة عليهم، من قطع المألوفات الإماكنية، وترك اللذات البهيمية اللازمة للقوى البشرية.  وفقنا الله على قلعها وقطعها.  خاتمة السورة  عليكم أيها المحمدي القاص لقطع العلائق الإمكانية أن تتصبر على عموم البلوى العارضة لك في نشأتك الأولى، وتسترجع إلى الله في جميعها، وتسنده إليه سبحانه أولاً وبالذات بلا رؤية الوسائل في البين، وتوطن قلبك مع ربك في جميع حالاتك، وترضى عن الله في عموم ما جرى عليك في مقتضيات قضائه، وبالجملة: كن فانياً في الله تفز بخير الدارين وفلاح النشأتين.
