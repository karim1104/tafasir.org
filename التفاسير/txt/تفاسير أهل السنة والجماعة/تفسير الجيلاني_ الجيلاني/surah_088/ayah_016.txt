{ وُجُوهٌ } أخر { يَوْمَئِذٍ نَّاعِمَةٌ } [الغاشية: 8] متنعمة مبتهجة مسرورة.  { لِّسَعْيِهَا } الذي تحملته من أنواع المتاعب والمشاق في نشأة الدنيا { رَاضِيَةٌ } [الغاشية: 9] سيما بعدما رأت ما ترتب على سعيها من الجزاء.  وكيف لا ترضى؛ إذ هي متنعمة بسبب ذلك بالسعي { فِي جَنَّةٍ عَالِيَةٍ } [الغاشية: 10] متعالية أوصاف نزاهتها ونضارتها عن مدارك العقول ومشاعر الحواس، مصفاة عن مطلق المكاره بحيث { لاَّ تَسْمَعُ فِيهَا } كلمة { لاَغِيَةً } [الغاشية: 11] لا فائدة لها.  ولتتميم نزاهتها ونضارتها { فِيهَا عَيْنٌ } ماؤها في غاية البياض والصفاء { جَارِيَةٌ } [الغاشية: 12] في خلالها وأنهارها أبداً.  ولتتميم ترفههم وتنعمهم { فِيهَا سُرُرٌ مَّرْفُوعَةٌ } [الغاشية: 13] مرتفعة عن الأرض على قوائم طوال.  { وَأَكْوَابٌ } أوان لا عروة لها { مَّوْضُوعَةٌ } [الغاشية: 14] بين أيديهم.  { وَنَمَارِقُ } وسائد في غاية الصفاء، متلونة بالألوان المطبوعة { مَصْفُوفَةٌ } [الغاشية: 15] مفروشة بعضها في جنب بعض.  { وَزَرَابِيُّ } بسط أخر فاخرة متلونة { مَبْثُوثَةٌ } [الغاشية: 16] مبسوطة بين أيديهم، فلا تستبعدوا ولا تستغربوا عن قدرة الله أمثال هذا.
