{ يٰأَيُّهَا ٱلنَّبِيُّ } المؤيَّد من عند الله بالنصر والظفر على الأعداء { حَسْبُكَ ٱللَّهُ } المولي لأمورك { وَمَنِ ٱتَّبَعَكَ } بإذن الله ومشيئته { مِنَ ٱلْمُؤْمِنِينَ } [الأنفال: 64] الموقنين بتوحيد الله، الموفين بعهوده، الباذلين مهجهم في سبيله.  { يٰأَيُّهَا ٱلنَّبِيُّ } المظفر المنصور بنصر الله { حَرِّضِ } ورغب { ٱلْمُؤْمِنِينَ } الموحدين { عَلَى ٱلْقِتَالِ } في سبيل الله؛ لترويج توحيده، وقل لهم نيابةً عنا ووعداً منا: { إِن يَكُن مِّنكُمْ } أيها المؤمنون { عِشْرُونَ صَابِرُونَ } مستقرون ثابتون تجاه العدو { يَغْلِبُواْ مِئَتَيْنِ } منهم بتأييد منَّا وعون { وَإِن يَكُنْ مِّنكُمْ مِّئَةٌ } صابرة راسخة، متمكنة { يَغْلِبُوۤاْ أَلْفاً مِّنَ ٱلَّذِينَ كَفَرُواْ } بإمدادنا إياكم إلى حيث يقاوم واحد منكم عشرة منهم، ذلك المغلوبية والانهزام إنما عرض عليهم { بِأَنَّهُمْ قَوْمٌ لاَّ يَفْقَهُونَ } [الأنفال: 65] أي: لا يصلون إلى مرتبة العلم اليقيني بالله وكتبه ورسله، حتى يترقوا منه إلى مرتبة العين والحق، بل يبقون على مرتبة الحيوانية مهانين مغلوبين مخذولين.  هذا في بدء الإسلام وضعف المسلمين وقلتهم، وبعدما ارتفع قدره وعلا رتبته وكثر أ÷له وانتشر في الآفاق قال سبحانه: { ٱلآنَ } أي: حين كثر عددكم وعُددكم، وثقل عليكم ما أمرتم { خَفَّفَ ٱللَّهُ } الميسر لأموركم أثقالكم { عَنكُمْ وَعَلِمَ } بعلمه الحضوري { أَنَّ فِيكُمْ ضَعْفاً } تستثقلون بتحمل المأمور به، أمركم ثابتاً بقوله: { فَإِن يَكُنْ مِّنكُمْ مِّئَةٌ صَابِرَةٌ } ثابتة { يَغْلِبُواْ مِئَتَيْنِ } منهم { وَإِن يَكُن مِّنكُمْ أَلْفٌ يَغْلِبُوۤاْ أَلْفَيْنِ بِإِذْنِ ٱللَّهِ } ونصره وتأييده { وَٱللَّهُ } المراقب لأحوال عباده { مَعَ ٱلصَّابِرِينَ } [الأنفال: 66] المتجملين في متاعب أمور الدين.
