{ وَ } من جملة ما يعين عليكم ويمد لنصركم: تغرير الشيطان وإغراؤه على أعدائكم إمداداً لكم فيصير وبالاً عليهم، اذكروا { إِذْ زَيَّنَ } أي: حسن وحبب { لَهُمُ ٱلشَّيْطَانُ أَعْمَالَهُمْ } أي: عداوتهم وقتالهم معكم { وَقَالَ } الشيطان تحريضاً لهم على القتال ملقياً في روعهم على سبيل الوسوسة، حتى خيلوا أنهم لا يغلبون أصلاً اعتماداً على كثرة عددهم وعُددهم: { لاَ غَالِبَ لَكُمُ ٱلْيَوْمَ مِنَ ٱلنَّاسِ } فلكم اليد والغلبة { وَإِنِّي جَارٌ لَّكُمْ } مجير لكم { فَلَمَّا تَرَآءَتِ ٱلْفِئَتَانِ } أي: تلافيا وتلاحقا فرأى اللعين من صفوف الملائكة ما رأى { نَكَصَ عَلَىٰ عَقِبَيْهِ } أي: رجع قهقرى { وَقَالَ إِنِّي بَرِيۤءٌ مِّنْكُمْ } ومن جواركم { إِنَّيۤ أَرَىٰ } من جنود السماء { مَا لاَ تَرَوْنَ } ينزلون منها؛ لإمداد هؤلاء بإذن الله { إِنَّيۤ أَخَافُ ٱللَّهَ } من قهره وغضبه { وَٱللَّهُ } القادر على جميع وجوه الانتقام { شَدِيدُ ٱلْعِقَابِ } [الأنفال: 48] أليم العذاب، لا نجاة للعصاة الغواة من عذابه وعقابه.  اذكروا { إِذْ يَقُولُ ٱلْمُنَافِقُونَ وَٱلَّذِينَ فِي قُلُوبِهِم مَّرَضٌ } أي: الذين لم يصفوا عن شوب الشبهة، ولم يصلوا إلى مرتبة الاطمئنان في الإيمان، حين خرجتم نحو العدو مجزئين مع قلتكم وكثرة عددكم: { غَرَّ هَـٰؤُلاۤءِ دِينُهُمْ } فألقوا أنفسهم إلى التهلكة بأيديهم بخروج ثلاثمائة عزل بلا عدة إلى زهاء ألف مستعدين، لا تبالوا أيها المطمئنون بالإيمان بهم وبقولهم، لا تفتروا وتضعفوا من هذياناتهم، بل توكلوا على ربكم وفوضوا الأمر إليه { وَمَن يَتَوَكَّلْ عَلَى ٱللَّهِ } فهو حسبه { فَإِنَّ ٱللَّهَ عَزِيزٌ } غالب في ذاته، قادر على إعانة من استعان منه { حَكِيمٌ } [الأنفال: 49] متقن في فعله وأمره، ويأمر ما تستبعده العقول وتدهش فيه الأحلام.
