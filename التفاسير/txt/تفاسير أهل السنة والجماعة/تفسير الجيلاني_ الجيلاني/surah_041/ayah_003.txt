{ حـمۤ } [فصلت: 1] يا حافظ وحي اللهن المؤيَّد من عنده لحفظ حدوده بمقتضى أوارمه ونواهيه، هذا القرآن الجامع لمصالح عموم المظاهر والأكوان.  { تَنزِيلٌ } صارد { مِّنَ ٱلرَّحْمَـٰنِ } أي: من الذات الأحدية بمقتضى اسم الرحمن المستوي به على عروش عموم الأكوان؛ لإصلاح حال كل ما لاح عليه شمس ذاته تتميماً لتربيته إياه؛ إذ ما من رطب ولا يابس إلا وهو سبحانه مشتمل عليه ومتكفل لتربيته وتدبيره { ٱلرَّحِيمِ } [فصلت: 2] بإنزاله لخواص عباده؛ ليتنبهوا من رموزه وإشاراته إلى وحدة الحق كمال أسمائه وصفاته.  وإنما صار القرآن جامعاً بين مرتبتي الظاهر والباطن والأول والآخر؛ لأنه { كِتَابٌ } شامل كامل { فُصِّلَتْ } بُينت وأُوحضت { آيَاتُهُ } المشتملة على دلائل التوحيد بشواهد القصص والأحكام، ومبنهات العز والحكم، ومحاسن الأخلاق والأعمال، ومقابيح المناهي من الأفعال والأحوال في النشأة الأولى والأخرى، ولهذا صار { قُرْآناً } فرقاناً واضحاً تبياناً { عَرَبِيّاً } بياناً؛ إذ لا لغهة أحسن منه وأشمل وأفضل وأكمل، وإنما فصلت وأوضحت { لِّقَوْمٍ يَعْلَمُونَ } [فصلت: 3] أي: يوفقون من لدنه سبحانه على العلم اللدني والفطرة الأصلية التي هي المعرفة والتوحيد.  ولهذا صار { بَشِيراً } يبشر أهل العناية والسعاة والفوز العظيم الذي هو يحققهم بمقام الرضا والتسليم { وَنَذِيراً } ينذر أصحاب الشقاوة والحرمان عن خلود النيران ولعذاب الأليم، ومع علو شأنه ووضح تبيانه وبرهانه.  { فَأَعْرَضَ } عنه، وانصرف عن قبوله وسماعة سمع تدبر وتأمل { أَكْثَرُهُمْ } أي: أكثر المكلفين المأمورين من عنده سبحانه بامتثال ما فيه من الأوامر والنواهي والأحكام، وباتصاف ما ذكر فيه من الأخلاق والأعمال، وما رمز إليه من المعارف والأحوال { فَهُمْ } من شدة قساوتهم وغفلتهم { لاَ يَسْمَعُونَ } [فصلت: 4] ولا يلتفتون نحوه عتوّاً وعناداً، فكيف عن فحصه وقبوله، ودراية ما فيه من الرموز والإشارات.  { وَ } من غاية عمههم وسكرتهم، ونهاية عتوهم، وإعراضهم عن استماع كلمة الحق والالتفات إليه { قَالُواْ } على سبيل التهكم والتسخر: { قُلُوبُنَا } التي في وعاء الإيمن والاعتقاد { فِيۤ أَكِنَّةٍ } وأغيطة كثيفة وغشاوة غليظة { مِمَّا تَدْعُونَا إِلَيْهِ } من المعرفة والتوحيد، لا نتنبه ولا نتفطن بحقيته { وَ } أيضاً { فِي آذانِنَا } التي هي وسائل العظة والتذكير { وَقْرٌ } صمم مانع عن استماع آياتك الدالة على صدقك في دعواك المبينة المثبتة لدعواك.  { وَ } بالجملة: حال { مِن بَيْنِنَا وَبَيْنِكَ } أيها المؤيَّد بالوحي والإلهام { حِجَابٌ } عظيم يمنعنا عما تدعونا إليه؛ بحث لا يتيسر لنا رفعه، ولا نقدر على انكشافه { فَٱعْمَلْ } أيها المدعي بمقتضى ما أوحاك إليك ربك وألهمك عليه { إِنَّنَا } أيضاً { عَامِلُونَ } [فصلت: 5] بما تيسر لنا ووفقنا عليه؛ إذ كل ميسر لما خُلق له.
