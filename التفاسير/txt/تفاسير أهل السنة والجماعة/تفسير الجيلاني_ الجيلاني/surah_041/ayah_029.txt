{ وَ } من شدة غيهم وضلالهم والمفضي إلى الخسران العظيم { قَالَ ٱلَّذِينَ كَفَرُواْ } بك وبدينك وبكتابك - يا أكمل الرسل - حين تلاوتك وتبليغك عليهم آيات القرآن { لاَ تَسْمَعُواْ لِهَـٰذَا ٱلْقُرْآنِ } ولا تلفتوا إلى محمد حين قرأ، بل { وَٱلْغَوْاْ فِيهِ } بالصياح، وإنشاد الأشعار، وخلط الأصوات والخرفات { لَعَلَّكُمْ تَغْلِبُونَ } [فصلت: 26] محمداً، وتدفعون قراءتهم، وتخجلونه فيسكت.  وهم من شدة شكيمتهم وغيظهم، وإن بالغوا في تخجيلك وتخذيلك يا أكمل الرسل لا تبالِ بهم وبفعلهم هذا { فَلَنُذِيقَنَّ } لهولاء { ٱلَّذِينَ كَفَرُواْ } بك وأساءوا الأدب معك { عَذَاباً شَدِيداً } منتقمين عنهم في النشأة الأولى { وَلَنَجْزِيَنَّهُمْ } في النشأة الأخرى { أَسْوَأَ } وأشد وأقبح من { ٱلَّذِي كَانُواْ يَعْمَلُونَ } [فصلت: 27] معك بأضعافها وآلافها.  { ذَلِكَ } العذاب الأسوأ الأشد { جَزَآءُ } أعمال { أَعْدَآءِ ٱللَّهِ } الذين عاندوا معك يا أكمل الرسل، واستهزءوا بك وبكتابك، بطرين بما معهم من الجاه والثروة، وهي { ٱلنَّارُ } المسعرة المعدَّة لدخولهم ونزولهم؛ إذ { لَهُمْ فِيهَا } أي: في النار { دَارُ الخُلْدِ } أي: إقامة على وجه الخلود، وإنما صارت كذلك ليكون { جَزَآءً بِمَا كَانُوا بِآياتِنَا يَجْحَدُونَ } [فصلت: 28] وينكرون بها، ويكذبكون بمن أنزل إليه ويستهزئون.  { وَ } بعدم استقر أهل النار في النار بأنواع السلاسل والأغلال { قَال الَّذِينَ كَفَرُواْ } بالله ورسله وكتبه في النشأة الأولى، متحسرين متأسفين، متضرعين إلى الله، مناجين له: { رَبَّنَآ } يا من ربانا على فطرة الإسلام والتوحيد، فكفرنا بك وأشركنا معك غيرك في ألوهيتك بإضلال قرنائنا الضالين المضلين { أَرِنَا } الشياطين { ٱلَّذَيْنِ أَضَلاَّنَا } عن طريق توحيد كتبك ورسلك الكائنين { مِنَ ٱلْجِنِّ وَٱلإِنسِ } أي: المضلِّين اللذين أضلانا من هذين الجنسين بأنواع الوساوس والزخارف، والتغريرات والتزيينات { نَجْعَلْهُمَا تَحْتَ أَقْدَامِنَا } لننتقم عنهم جزاء ما فوتوا عنَّا سعادة الدارين وصلاح النشأتين، وإنما نرجو منك هذا يا مولانا { لِيَكُونَا مِنَ ٱلأَسْفَلِينَ } [فصلت: 29] المستتبعين لنا، كما كنا كذلك بالنسبة إليهم، وإنما قالوا ما قالوا تحسراً وتضجراً.
