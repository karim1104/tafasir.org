ثمَّ قال سبحانه: { مَا كَانَ } أي: ما صحّ وجاز { لِلْمُشْرِكِينَ } المصرين على الشرك والعناد { أَن يَعْمُرُواْ مَسَٰجِدَ ٱللهِ } المعدة لأهل الإيمان ليعبدوا فيها حتى يتحققوا بمقام المعرفة والتوحيد حال كونهم { شَٰهِدِينَ عَلَىٰ أَنْفُسِهِمْ بِالْكُفْرِ } والشرك قولاً وفعلاً وشركهم منافٍ لتعميرها؛ إذ { أُوْلَئِكَ } البعداء الهالكون في تيه الضلال { حَبِطَتْ } أي: سقطت عن درجة الاعتبار { أَعْمَٰلُهُمْ } الصالحة عند الله بحيث لا ينفعهم أصلاً؛ لمقارنتها بالشرك بل { وَ } مآل أمرهم { فِي ٱلنَّارِ } المعدة لأهل الشرك والضلال { هُمْ خَٰلِدُونَ } [التوبة: 17] لا نجاة لهم أصلاً، سواء صدر عنهم الأعمال الصالحة أم لا.  بل { إِنَّمَا يَعْمُرُ مَسَٰجِدَ ٱللَّهِ } المعدة لخلاء العبادة والتوجه نحو الحق والمناجاة معه { مَنْ ءَامَنَ بِٱللَّهِ } وتحقق بمرتبة اليقين العلمي في توحيده { وَٱلْيَوْمِ ٱلآخِرِ } الذي يصير الكل إليه { وَأَقَامَ ٱلصَّلَٰوةَ } أي: أدام الميل والرجوع نحو الحق دائماً { وَءَاتَىٰ ٱلزَّكَٰوةَ } تخفيفاً وتطهيراً لنفسها عن العلائق العائقة عن التوجه الحقيقي الحقي { وَلَمْ يَخْشَ إِلاَّ ٱللَّهَ } أي: لم يكن في قلبه خضية من فوات شيء أصلاً إلاَّ من عدم قبول الله أعماله، ومن عدم رضاه سبحانه منه { فَعَسَىٰ } وقرب { أُوْلَـٰئِكَ } السعداء الأماء، الباذلون جهدهم في طريق التوحيد، المشتاقون إلى فضاء الفناء { أَن يَكُونُواْ مِنَ ٱلْمُهْتَدِينَ } [التوبة: 18] المتحققين في مقام الرضا والتسليم وإن وفقوا بالإخلاص من عنده.  اصنع بنا ما تحب أنت وترضى يا دليل الحائرين.
