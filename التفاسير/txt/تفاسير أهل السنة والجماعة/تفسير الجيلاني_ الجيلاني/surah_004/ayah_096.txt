ثم قال سبحانه: { لاَّ يَسْتَوِي ٱلْقَٰعِدُونَ } عن الحرب { مِنَ ٱلْمُؤْمِنِينَ } حال كونكم { غَيْرُ أُوْلِي ٱلضَّرَرِ } من الدم والمرض الذمامة وغيرها { وَٱلْمُجَٰهِدُونَ فِي سَبِيلِ ٱللَّهِ بِأَمْوَٰلِهِمْ وَأَنْفُسِهِمْ } ابتغاء لوجه الله وطلباً لمرضاته { فَضَّلَ ٱللَّهُ ٱلْمُجَٰهِدِينَ بِأَمْوَٰلِهِمْ وَأَنْفُسِهِمْ عَلَى ٱلْقَٰعِدِينَ دَرَجَةً } عظيمة وفاء لحق ما اجتهدوا في سبيه { وَ } إن كان { كُـلاًّ } منهم ممن { وَعَدَ ٱللَّهُ } لهم المثوبة { ٱلْحُسْنَىٰ } والمراتب العظمى والدرجة العليا { وَفَضَّلَ ٱللَّهُ ٱلْمُجَٰهِدِينَ } زيادة { عَلَى ٱلْقَٰعِدِينَ أَجْراً عَظِيماً } [النساء: 95] هو الفوز بمرتبة الشهادة.  وفضل الله لهم في تلك المرتبة { دَرَجَاتٍ مِّنْهُ } بعضها قريب، وبعضها أقرب إلى ما يشاء الله { وَمَغْفِرَةً } لذنوبهم بالمرة كيوم الولادة { وَرَحْمَةً } خاصة لهم بأن يكونوا عند ربهم يرزقون، فرحين بما آتاهم الله من فضله { وَكَانَ ٱللَّهُ } المراقب لأحوال عباده { غَفُوراً } لذنوبهم { رَّحِيماً } [النساء: 96] لهم يرحمهم حسب فضله وطوله.
