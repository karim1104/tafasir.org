قوله تعالى: { لَهُمْ قُلُوبٌ لاَّ يَفْقَهُونَ بِهَا وَلَهُمْ أَعْيُنٌ لاَّ يُبْصِرُونَ بِهَا وَلَهُمْ آذَانٌ لاَّ يَسْمَعُونَ بِهَآ } [الآية: 179].  قال: { قُلُوبٌ لاَّ يَفْقَهُونَ بِهَا } شواهد الحق و { أَعْيُنٌ لاَّ يُبْصِرُونَ بِهَا } دلائل الحق، و { آذَانٌ لاَّ يَسْمَعُونَ بِهَآ } دعوة الحق.  قوله عز وعلا { أُوْلَـٰئِكَ كَٱلأَنْعَامِ بَلْ هُمْ أَضَلُّ }.  قيل: الأنعام والبهائم لا تحس بالاستتار والتجلى، والأرواح نعيمها فى التجلى وغذاؤها فى الاستتار. قال الله تعالى: [الفرقان: 44].
