قوله تعالى: { إِنَّ ٱلَّذِينَ لاَ يَرْجُونَ لِقَآءَنَا } [الآية: 7].  قال: لا يخافون الموقف الأعظم [الطارق: 9].  وتظهر الخفايا { وَرَضُواْ بِٱلْحَياةِ ٱلدُّنْيَا } ركنوا إلى مذموم عيشهم { وَٱطْمَأَنُّواْ بِهَا } نسوا مفاجأة الموت { وَٱلَّذِينَ هُمْ عَنْ آيَاتِنَا غَافِلُونَ } تقليب القلوب وعقوبات الجوارح.
