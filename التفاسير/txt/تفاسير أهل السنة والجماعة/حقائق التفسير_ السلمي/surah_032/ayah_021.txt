قوله عز وعلا: { وَلَنُذِيقَنَّهُمْ مِّنَ ٱلْعَذَابِ ٱلأَدْنَىٰ دُونَ ٱلْعَذَابِ ٱلأَكْبَرِ } [الآية: 21].  قال أبو سليمان الدارانى: { ٱلْعَذَابِ ٱلأَدْنَىٰ } الخذلان والعذاب الأكبر الخلود فى النيران.  وقال بعضهم: { ٱلْعَذَابِ ٱلأَدْنَىٰ }: الهوان، و { ٱلْعَذَابِ ٱلأَكْبَرِ } الخلود فى النيران.  وقال بعضهم: العذاب الأدنى الهوان والعذاب الأكبر الخذلان.
