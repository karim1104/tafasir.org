قوله تعالى: { يآءَادَمُ إِنَّ هَـٰذَا عَدُوٌّ لَّكَ وَلِزَوْجِكَ } [الآية: 117].  قال الواسطى رحمة الله عليه: أضمر عداوته ولم يفزع إلى ربه مبتهلاً فى الكفاية والاستكفاء فأصغى إلى قوله وقسمه.  قوله تعالى: { فَلاَ يُخْرِجَنَّكُمَا مِنَ ٱلْجَنَّةِ فَتَشْقَىٰ } [الآية: 117].  قال ابن عطاء فى هذه الآية: { فَلاَ يُخْرِجَنَّكُمَا مِنَ ٱلْجَنَّةِ فَتَشْقَىٰ } ولم يقل فتشقيا لأن آدم كان عالمًا بمراتب المحاورة، واختصاص الدنو، ولم تكن حواء تعلم من ذلك ما علم آدم. فقال لآدم: { فَتَشْقَىٰ } لأنك المخصوص بهذه الرتبة الجليلة، وحواء تبعًا لك فيه، وليس الأصل فيه كالفرع.
