{  اسْلُكْ يَدَكَ فيِ جَيْبِكَ } مجازه :  أدخل وهما لغتان سلكته وأسلكته وقد فسرناه فوق هذا .

{  بَيْضَاءَ مِنْ غَيْرِ سُوءٍ } أي من غير برص .

{  وَاضْمُمْ إِلَيْكَ جَنَاحَكَ } أي يدك .  و {  الرَّهْبِ } مثل الرهبة ومعناهما الخوف والفرق .

{  فَذَانِّكَ بُرْهَانَانِ } واحدهما برهان وهو البيان يقال :  هات على ما تقول ببرهان ونون قوله {  فذانّك } مشددة لأنها أشد مبالغة منه إذا خففتها وقد يخفف في الكلام .
