{  وَلاَ يَحْسَبَنَّ الَّذِينَ كَفَرُوا أنَّ مَا نُمْلِى لَهُمْ خَيْرٌ لأنْفُسِهِمْ } :  ألف {  أن } مفتوحة ،  لأن {  يحسبن } قد عمِلت فيها ،  {  وما } :  في هذا الموضع بمعنى {  الذي } فهو اسم ،  والمعنى من الإملاء ومن الإطالة ،  ومنها قوله :  {  واهْجُرْني مَلِيّاً } :  أي دهراً ؛  وتمليت حبيبك ؛  والمَلَوَان :  النهار والليل كما ترى ،  قال ابن مُقْبِل :

ألا يا دِيارَ الحَيّ بالسَّبُعانِ *** أمَلَّ عليها بالبِلَى المَلَوَانِ

يعنى الليل والنهار ،  و " أملّ عليها بالبلى } :  أي رجع عليها حتى أبلاها ،  أي طال عليها ،  ثم أستأنفتَ الكلام فقلت :  {  إنّمَا تمَلي لهُمْ ليزْدَادُوا إثماً } فكسرتَ ألف {  إنما } للابتداء فإنما أبقيناهم إلى وقت آجالهم ليزدادوا إثماً ؛  وقد قيل في الحديث :  المَوْتُ خيْرٌ لِلُمْؤِمن لِلنَّجَاةِ مِن الفِتْنةِ ،  وَالمَوْتُ خيرٌ لِلكَافِرِ لِئَلاَّ يزْدَادَ إثماً .

{  عَذَابٌ مُهِينٌ } :  فذلك من الهَوَان .
