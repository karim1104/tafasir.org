{  وَحَشَرْنَا عَلَيْهِمْ كُلَّ شَيْءٍ قُبُلاً } ومجاز {  حَشَرْنَا } :  سُقنا وجمعنا ؛

{  قُبُلاً } :  جميع ،  قبيل قبيل ؛  أي :  صنف صنف ؛  ومن قرأها {  قِبَلاً } ؛  فإنه يجعل مجازها عياناً ،  كقولهم :   " من ذي قِبَل "  ،  وقال آخرون {  قُبُلاً } أي مقابلة ،  كقولهم :  {  أقبَلَ قُبُلَهُ ،  وسقاها قُبُلاً ،  لم يكن أعدَّ لها الماء ،  فاستأنفتْ سقيها ،  وبعضهم يقول :   " منْ ذيِ قَبَلٍ "  .
