قوله تعالى : { وَعِبَادُ الرَّحْمَنِ الَّذِينَ يَمْشُونَ عَلَى الأَرْضِ هَوْناً } ؛ رَوَى ابن أبي نجيح عن مجاهد : { هَوْناً } قال :  " بالوقار والسكينة "  { وإِذَا خَاطَبَهُمُ الجَاهِلُونَ قَالُوا سَلاماً } قال :  " سداداً "  .

وعن الحسن أيضاً : { يَمْشُونَ عَلَى الأَرْضِ هَوْناً }  " حلماء لا يجهلون على أحد وإن جهل عليهم ،   حلموا قد براهم الخوف كأنهم القداح ،   هذا نهارهم ينتشرون به في الناس "  { وَالَّذِينَ يَبِيتُونَ لِرَبِّهِمْ سُجَّداً وَقِيَاماً } قال :  " هذا ليلهم إذا دخل يراوحون بين أطرافهم فهم بينهم وبين ربهم "  .

وعن ابن عباس : { يَمْشُونَ عَلَى الأَرْضِ هَوْناً } قال :  " بالتواضع لا يتكبرون "  .
