قوله تعالى : { مَثَلُ الَّذِينَ حُمِّلُوا التَّوْرَاةَ ثُمَّ لَمْ يَحْمِلُوهَا } الآية .   رُوي أنه أراد اليهود الذين أُمِرُوا بتعلم التوراة والعمل بها فتعلّموها ثم لم يعملوا بها ،   فشبّههم الله بالحمار الذي يحمل الكتب  وهي الأسفار  إذا لم ينتفعوا بما حملوه كما لا ينتفع الحمار بالكتب التي حملها ؛ وهو نحو قوله : { إن هم إلا كالأنعام بل هم أضلّ سبيلاً } [ الفرقان : 44 ] وقوله : { واتل عليهم نبأ الذي آتيناه آياتنا فانسلخ منها } [ الأعراف : 175 ] إلى قوله : { كمثل الكلب } [ الأعراف : 176 ] .
