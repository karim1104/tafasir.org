ثم { قال } ذو القرنين { هذا } السد أو هذا الإقرار والتمكين نعمة من الله عز وجل ورحمة على عباده { فإذا جاء } أي دنا مجيء القيامة { جعله دكاً } مدكوكاً مبسوطاً مستوي بالأرض وكل ما انبسط بعد ارتفاع فقد اندك .   ومن قرأ { دكاء } بالمد فعلى الوصف أي جعله أرضاً مستوية { وكان وعد ربي حقاً } وهذا آخر حكاية ذي القرنين .
