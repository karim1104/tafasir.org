{ فلما جاءت قيل أهكذا } أي مثل ذا { عرشك } لئلا يكون شبه تلقين فقالت { كأنه هو } ولم تقل : هو هو مع أنها عرفته ليكون دليلاً على وفور عقلها حيث لم تقطع في المحتمل وتوقفت في مقام التوقف .   أما قوله { وأوتينا العلم } فمعطوف على مقدر كأنهم قالوا عند قولها كأنه هو قد أصابت في جوابها وطابقت المفصل وهي عاقلة لبيبة وقد رزقت الإسلام وعلمت قدرة الله وصحة نبوة سليمان بهذه الخوارق .   { وأوتينا } نحن { العلم } بالله وبقدرته قبل علمها ولم نزل على دين الإسلام .
