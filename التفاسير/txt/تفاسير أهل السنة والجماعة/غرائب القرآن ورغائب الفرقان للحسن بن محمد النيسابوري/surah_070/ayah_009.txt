{ وتكون الجبال كالعهن } أي الصوف المصبوغ ألواناً لقوله { ومن الجبال جدد بيض وحمر مختلف ألوانها وغرابيب سود } [ فاطر :27 ] وجوز جار الله أن ينتصب { يوم } ب { قريباً } أو بإضمار يقع لدلالة واقع عليه ،   أو يراد به يوم تكون السماء كالمهل كان كيت وكيت ،   أو هو بدل من يوم القيامة فيمن علقه { بواقع } .
