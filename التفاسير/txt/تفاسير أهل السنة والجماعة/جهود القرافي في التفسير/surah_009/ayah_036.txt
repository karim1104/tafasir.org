672- قال المازري :   " قال ابن المسيب وغيره :  القتال فرض عين على الأعيان لقوله تعالى :  {  وقاتلوا المشركين كافة كما يقاتلونكم كافة } .

وجوابه :  أنه منسوخ بقوله تعالى :  {  وما كان المؤمنون لينفروا كافة } وقوله :  {  لا يستوي القاعدون من المؤمنين غير أولي الضرر والمجاهدون } ثم قال :  {  وكلا وعقد الله الحسنى } ولو أنه على الأعيان لما وعد القاعد الحسنى .  ولم تزل الأمة بعده عليه السلام ينفر بعض دون بعض .  ( الذخيرة :  3/385 )

673- إن ظواهر النصوص تقتضي ترتيب القتال على الكفر والشرك كقوله تعالى :  {  قاتلوا المشركين كافة } .  ( الذخيرة :  3/387 )
