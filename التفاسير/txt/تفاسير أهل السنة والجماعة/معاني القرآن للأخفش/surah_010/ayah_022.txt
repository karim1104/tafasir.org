وقال {  حَتَّى إِذَا كُنتُمْ فِي الْفُلْكِ وَجَرَيْنَ بِهِم } ( 22 ) وإنما قال {  وَجَرَيْنَ بِهِم } لأنْ ( الفُلْكَ ) يكون واحدا وجماعة .  قال {  فِي الْفُلْكِ الْمَشْحُونِ } وهو مذكر .  وأما ( حتَّى إذا كُنْتُمْ في الفُلْكِ ) فجوابه قوله {  جَاءَتْهَا رِيحٌ عَاصِفٌ } ( 22 ) .

وأما قوله {  دَعَوُاْ اللَّهَ } ( 22 ) فجواب لقوله {  وَظَنُّواْ أَنَّهُمْ أُحِيطَ بِهِمْ } ( 22 ) وإنما قال {  بِهِم } وقد قال {  كُنْتُمْ } لأنه يجوز أن تذكر غائبا ثم تخاطب إذا كنت تعنيه ،  وتخاطب ثم تجعله في لفظ غائب كقول الشاعر :  [ من الطويل وهو الشاهد العاشر بعد المئة ] :
