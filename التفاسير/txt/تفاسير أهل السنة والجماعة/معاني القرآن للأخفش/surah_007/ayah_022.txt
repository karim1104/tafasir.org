وقال {  وَطَفِقَا } ( 22 ) وقال بعضُهم {  وَطَفقَا } فمن قال :   " طَفَقَ "  قال :   " يَطْفِقُ "  ومن قال  " طَفِقَ "  قال  " يَطْفَقُ "  .

وقال {  يَخْصِفَانِ } ( 22 ) جعلها من  " يَخْتَصِفانِ "  فادغم التاء في الصاد فسكنت وبقيت الخاء ساكنة فحركت الخاء بالكسر لاجتماع الساكنين .  ومنهم من يفتح الخاء ويحول عليها حركة التاء وهو كقوله {  أَمَّن لاَّ يَهِدِّي } وقال بعضهم {  يَهِدِّي إلا أن يُهْدَى } .
