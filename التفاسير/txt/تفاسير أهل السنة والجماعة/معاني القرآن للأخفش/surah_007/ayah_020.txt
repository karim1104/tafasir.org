وقال {  فَوَسْوَسَ لَهُمَا الشَّيْطَانُ } ( 20 ) والمعنى :  فوسوس إليهما الشيطان .  ولكن العرب توصل بهذه الحروف كلها الفعل ،  ومنهم من تقول :   " غَرِضْتُ "  في معنى :  اشتقت إليه .  وتفسيرها [ 116 ء ] :  غَرِضْتُ مِنْ هؤلاءِ إِلَيْهِ .

وقال {  إِلاَّ أَنْ تَكُونَا مَلَكَيْنِ } ( 20 ) يقول :  {  ما نَهاكُما إلاّ } كَراهَة {  أَن تَكُونَا } كما تقول :   " إِيَاكَ أَنْ تَفْعَلَ "  أي :  كَراهَة أَنْ تَفْعَلَ .
