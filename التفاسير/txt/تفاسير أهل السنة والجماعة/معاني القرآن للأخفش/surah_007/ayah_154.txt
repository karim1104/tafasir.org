وقال {  وَلَماَّ سَكَتَ عَن مُّوسَى الْغَضَبُ } ( 154 ) وقال بعضهم {  سَكَنَ } إِلاّ أَنَّها ليست على الكتاب فتقرأ {  سَكَتَ } وكلٌّ من كلام العرب .

وقال {  لِّلَّذِينَ هُمْ لِرَبِّهِمْ يَرْهَبُونَ } ( 154 ) كما قال {  إِن كُنتُمْ لِلرُّؤْيَا تَعْبُرُونَ } أوصل الفعل باللام .  وقال بعضهم {  مِنْ أَجْلِ رَبِّهِم يَرْهَبُون } .
