وقال {  وَذَرُواْ الَّذِينَ يُلْحِدُونَ فِي أَسْمَائِهِ } ( 180 ) وقال بَعْضُهُم {  يُلْحَدُونَ } جعله من  " لَحَدَ "  [ 123 ء ]  " يَلْحَدُ "  وهي لغة .  وقال في موضع آخر {  لِّسَانُ الَّذِي يُلْحِدُونَ } و{  يَلْحَدُون } وهما لغتان و{  يُلْحدُونَ } أكثر وبها نقرأ ويقوّيها {  وَمَن يُرِدْ فِيهِ بِإِلْحَادٍ بِظُلْمٍ } .
