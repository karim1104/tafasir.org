وقال {  إِنَّهَا لإِحْدَى الْكُبَرِ } ( 35 ) {  نَذِيراً لِّلْبَشَرِ }* ( 36 ) فانتصب {  نَذِيراً } لأنه خبر ل{  إِحْدَى الكُبَر } فانتصب {  نَذِيراً } لأنه خبر للمعرفة وقد حسن عليه السكوت فصار حالا وهي  " النَذِير "  كما تقول  " إِنَّهُ لَعَبْدُ اللهِ قَائِماً "  وقال بعضهم  " إِنَّما هُوَ "   " قُمْ نَذِيراً فَأَنْذِر "  .
