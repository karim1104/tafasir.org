وقال {  خُلِقَ الإنْسَانُ مِنْ عَجَلٍ سَأُوْرِيكُمْ آيَاتِي فَلاَ تَسْتَعْجِلُونِ } ( 37 ) يقول :   " من تعجيلٍ من الأمْرِ ،  لأَنَّه قال :  {  إِنَّمَا قَوْلُنَا لِشَيْءٍ إِذَآ أَرَدْنَاهُ أَن نَّقُولَ لَهُ كُنْ } فهذا العجل كقوله {  فَلاَ تَسْتَعْجِلُوهُ } وقوله {  فَلاَ تَسْتَعْجِلُونِ } فإِنَّني {  سَأُوْرِيكُمْ آيَاتِي } .
