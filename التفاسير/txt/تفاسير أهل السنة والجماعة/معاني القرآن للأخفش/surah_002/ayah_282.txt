وقال {  وَاسْتَشْهِدُواْ شَهِيدَيْنِ مِّن رِّجَالِكُمْ فَإِن لَّمْ يَكُونَا رَجُلَيْنِ } ( 282 ) أيْ :  إنْ لَمْ يَكُنِ الشّهِيدانِ رَجُلَيْنِ .  {  فَرَجُلٌ وَامْرَأَتَانِ } ( 282 ) فالذي يُسْتَشْهَدُ رَجُلٌ وامرأتان .

وقال {  وَلاَ تَسْأَمُواْ } ( 282 ) لأنها من  " سَئِمْت "   " تَسْأَمُ "   " سَآمةً "  و " سَأْمَةً "  و " سَآماً "  و " سَأْماً "  .

[ وقال ] {  وَلاَ يَأْبَ الشُّهَدَاءُ } ( 282 ) جزم لأنه نهي وإذا وقفت قلت  " يَأْبَ "  فتقف بغير ياء .

وقال {  إِلاَّ أَن تَكُونَ تِجَارَةٌ حَاضِرَةٌ } ( 282 ) أي :  تَقَع تِجَارَةٌ حاضِرةٌ .  وقد يكون فيها النصب على ضمير الاسم  " إلاّ أنْ تَكُونَ تلكَ تِجارةً .

وقال {  وَلاَ يُضَارَّ كَاتِبٌ وَلاَ شَهِيدٌ } ( 282 ) على النهي والرفع على الخبر .  وهو مثل {  لاَ تُضَارَّ وَالِدَةٌ بِوَلَدِهَا } إلاّ إنَهُ لَمْ يُقْرأ {  لا تُضارُّ } رفعا .

وقوله {  إِذَا تَدَايَنتُم بِدَيْنٍ } ( 282 ) فقوله {  بِدَيْنٍ } تأكيد نحو قوله {  فَسَجَدَ الْمَلائِكَةُ كُلُّهُمْ أَجْمَعُونَ } لأنَّكَ تَقُول  " تَدايَنَّا "  فيدل على قولك  " بِدَيْنٍ "  قال الشاعر :  [ من الرجز وهو الشاهد الحادي والخمسون بعد المائة ] :

دَايَنْتُ أَرْوَى والدُّيونُ تُقْضَى *** [ فَمَطَلَتْ بَعْضاً وَأَدَّتْ بَعْضَا ]

تقوله :   " دَايَنْتُها ودايَنَتْنِي فقد تَدايَنَّا "  كما تقول :   " قابَلْتُها وقَابَلَتْنِي فقد تَقَابَلْنا "  .

وقال {  82ء ] {  أَن تَكْتُبُوهُ صَغِيراً أَو كَبِيراً إِلَى أَجَلِهِ } ( 282 ) فأضمر  " الشاهد "  .  وقال {  إِلَى أَجَلِهِ } إلى الأجل الذي تجوز فيه شهادته والله أعلم .
