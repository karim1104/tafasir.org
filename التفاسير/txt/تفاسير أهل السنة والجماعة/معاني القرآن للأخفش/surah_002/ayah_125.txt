وقال {  وَإِذْ جَعَلْنَا الْبَيْتَ مَثَابَةً لِّلنَّاسِ وَأَمْناً } ( 125 ) على {  اذْكُرُواْ نِعْمَتِي الَّتِي أَنْعَمْتُ عَلَيْكُمْ } ( 122 ) {  وَإِذْ جَعَلْنَا الْبَيْتَ مَثَابَةً لِّلنَّاسِ } وأُلْحِقَتْ الهاءُ في  " المَثابة "  لما كُثُر مَنْ يَثُوب إليه كما تقول :   " نَسَّابَة "  و " سيّارَة "  لِمَنْ يكثُر ذلك منه .

وقال  :  {  وَاتَّخِذُواْ مِن مَّقَامِ إِبْرَاهِيمَ مُصَلًّى } ( 125 ) يُريدُ {  واتَّخَذُوا } كَأَنَّهُ يقولُ :    " واذْكُروا نِعْمَتي وإذْ اتَّخَذُوا مُصَلى من مَقامِ إبراهيمَ "

و{  اتخَِّذُوا } بالكسر وبها نقرأ لأنَّها تدلّ على الغَرْض .

وقال  : {  وَالرُّكَّعِ السُّجُودِ } ( 125 ) ف{  السُّجُودِ } جماعة  " السَّاجد "  كما تقول :   " قَوْمٌ قُعُودٌ "  و " جُلوسٌ "  .
