وأما قوله {  رَبِّ أَرِنِي كَيْفَ تُحْيِي الْمَوْتَى } ( 260 ) فلم يكن ذلك شكّاً منه ولم يُرِد .  به رؤية القلب وإنما أراد به رؤية العين .

وقوله الله عز وجل له {  أَوَلَمْ تُؤْمِن } ( 260 ) يقول :   " أَلَسْتَ قَدْ صَدّقتَ "  أَيْ :  أنت كذاك .  قال الشاعر :  [ من الوافر وهو الشاهد الثالث والثلاثون ] :

أَلَسْتُمْ خيرَ مَنْ رَكِبَ المطَايا *** وَأَنْدى العالمِينَ بُطُونَ راحِ

وقوله {  لِّيَطْمَئِنَّ قَلْبِي } ( 260 ) أي :  قلبي ينازعني إلى النظر فإذا نظرت اطمأن قلبي .

قال {  فَخُذْ أَرْبَعَةً مِّنَ الطَّيْرِ فَصُرْهُنَّ إِلَيْكَ } ( 260 ) أي :  قَطِّعْهُنَّ وتقول منها :   " صارَ "   " يَصُورُ "  .  وقال بعضهم {  فَصُرْهُنَّ } فجعلها من  " صارَ "   " يَصِيرُ "  [ 79ب ] وقال {  إِلَيْكَ } لأنه يريد :   " خُذْ أربعةً إليكَ فَصرهُنَّ "  .
