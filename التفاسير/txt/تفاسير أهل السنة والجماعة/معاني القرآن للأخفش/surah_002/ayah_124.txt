وقال {  وَإِذِ ابْتَلَى إِبْرَاهِيمَ رَبُّهُ بِكَلِمَاتٍ } ( 124 ) أي :  اختبره .  و{  إِبْرَاهِيمَ } هو المبتلي فلذلك انتصب .

وقال {  لاَ يَنَالُ عَهْدِي الظَّالِمِينَ } ( 124 ) لأنَّ العَهْدَ هو الذي لا يَنالُهُم ،  وقال بعضهم {  لا ينالُ عهدي الظالِمُون } والكتاب بالياء .  وإنما قالوا

{  الظالمونَ } لأنهم جعَلوهُم الذينَ لا ينالون .
