وقال  : {  صِبْغَةَ اللَّهِ } ( 138 ) بالنصب .  لأنهم حين قالوا* لهم {  كُونُواْ هُوداً } ( 135 ) كأنه قيل لهم :   " اتَّخِذُوا هِذِهِ المِلَّةَ "  فقالوا :   " لا {  بَلْ مِلَّةَ إِبْرَاهِيمَ } أي :  نَتَّبِعُ مِلَّةَ إبْراهيم ،  ثم أبدل  " الصِّبْغَةَ "  من  " المِلَّة "  فقال {  صِبْغَةَ اللَّهِ } بالنصب .  أو يكون أراد :   " كونوا أصحابَ مِلَّةٍ "  ثم حذف  " أَصْحاب "  كما قال :  {  ولكنَّ الْبِرَّ مَنْ آمَنَ بِاللَّهِ } يريد :   " بِرَّ مَنْ آمَن باللّهِ "  .  والصِِّبْغَةُ :  هي الدين .
