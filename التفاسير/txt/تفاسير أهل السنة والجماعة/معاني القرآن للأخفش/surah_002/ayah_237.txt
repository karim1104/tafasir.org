قال {  فَنِصْفُ مَا فَرَضْتُمْ } ( 237 ) أي :  فعليكم نصفُ ما فرضتم {  إِلاَّ أَنْ يَعْفُونَ } ( 237 ) وإنْ شئتَ نَصَبْتَ {  نصفَ ما فَرضْتُمْ } على الأمر .

قال {  وَأَن تَعْفُواْ أَقْرَبُ لِلتَّقْوَى وَلاَ تَنسَوُاْ الْفَضْلَ بَيْنَكُمْ } ( 237 ) وقال بعضهم {  ولا تَناسَوْا } ،  وكلٌّ صَوابٌ .  وقال بعضهم {  وَلا تَنْسَوِا الفَضْلَ } فكسر الواو لاجتماع الساكنين كما قال {  اشْتَرُواْ الضَّلاَلَةَ } .
