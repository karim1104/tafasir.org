وقال  : {  أَمْ كُنتُمْ شُهَدَاءَ } استفهام مستأنف .

وقال  : {  إِذْ حَضَرَ يَعْقُوبَ الْمَوْتُ إِذْ قَالَ لِبَنِيهِ } ( 133 ) فأبْدَلَ  " إذْ "  الآخرة من الأولى .

وقال  : {  إلهك وَإله آبَائِكَ إِبْرَاهِيمَ وَإِسْمَاعِيلَ وَإِسْحَاقَ } ( 133 ) على البدل وهو في موضع جر إلا أَنها [ 65ب ] أعجمية فلا تنصرف .

وقوله  : {  إلها وَاحِداً } ( 133 ) على الحال .
