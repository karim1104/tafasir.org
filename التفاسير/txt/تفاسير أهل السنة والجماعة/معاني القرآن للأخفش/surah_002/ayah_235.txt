وقال {  لاَ جُنَاحَ عَلَيْكُمْ فِيمَا عَرَّضْتُمْ بِهِ مِنْ خِطْبَةِ النِّسَاءِ } ( 235 ) ف " الخِطْبَةِ "  الذِكر ،  و " الخُطْبَةَ "  :  التَشَهُّد .

وقال {  ولكن لاَّ تُوَاعِدُوهُنَّ سِرّاً } ( 235 )لأنه لما قال {  لاَ جُنَاحَ عَلَيْكُمْ } كأنه قال :   " تذكرون {  ولكن لاَّ تُوَاعِدُوهُنَّ سِرّاً إِلاَّ أَن تَقُولُواْ } ( 235 ) استثناء خارج على  " ولكنْ "  .
