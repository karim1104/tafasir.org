[ 168 ء ] وقال {  إِنَّ الَّذِينَ كَفَرُواْ بِالذِّكْرِ لَمَّا جَاءَهُمْ } ( 41 ) فزعم بعض المفسرين أن خبره {  أُوْلَائِكَ يُنَادَوْنَ مِن مَّكَانٍ بَعِيدٍ } ( 44 ) وقد يجوز أن يكون على الأخبار التي في القرآن يستغنى بها كما استغنت أشياء عن الخبر إذ طال الكلام وعرف المعنى نحو قوله {  وَلَوْ أَنَّ قُرْآناً سُيِّرَتْ بِهِ الْجِبَالُ } وما أشبهه .  وحدثني شيخ من أهل العلم قال :   " سمعت عيسى بن عمر يسأل عمرو بن عبيد "  :  {  إِنَّ الَّذِينَ كَفَرُواْ بِالذِّكْرِ لَمَّا جَاءَهُمْ } أين خبره ؟  "  فقال عمرو :   " معناه في التفسير {  إِنَّ الَّذِينَ كَفَرُواْ بِالذِّكْرِ لَمَّا جَاءَهُمْ } كفروا به {  وَإِنَّهُ لَكِتَابٌ عَزِيزٌ } ( 41 ) "  فقال عيسى :   " جَاءَ يا أَبا عثمان "  .
