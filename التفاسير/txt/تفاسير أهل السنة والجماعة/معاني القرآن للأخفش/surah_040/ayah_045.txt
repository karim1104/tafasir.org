وقال {  وَحَاقَ بِآلِ فِرْعَوْنَ سُوءُ الْعَذَابِ } ( 45 ) {  النَّارِ } ( 46 ) فإن شئت جعلت {  النُارِ } بدلا من {  سوءُ العذاب } ورفعتها على {  حاقَ } وإن شئت جعلتها تفسيرا ورفعتها على الابتداء [ 166 ء ] كأنك تقول :   " هي النار "  وان شئت جررت على أن تجعل {  النار } بدلا من {  العذاب } كأنك أردت :   " سوءُ النارِ "  .
