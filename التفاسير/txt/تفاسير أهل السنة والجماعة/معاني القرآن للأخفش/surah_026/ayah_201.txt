وقال {  لاَ يُؤْمِنُونَ بِهِ حَتَّى يَرَوُاْ الْعَذَابَ الأَلِيمَ } ( 201 ) {  فَيَأْتِيَهُم } ( 202 ) ليس بمعطوف على {  حَتَّى } إنَّما هو جوابٌ لقوله {  لاَ يُؤْمِنُونَ بِهِ } فلما كان جوابا للنفي انتصب وكذلك {  فَيَقُولُواْ } ( 203 ) إنما هو جواب للنفي .

وقال {  إِنِّي آمَنتُ بِرَبِّكُمْ فَاسْمَعُونِ } أَيْ :  فَاْسْمَعُوا مني .
