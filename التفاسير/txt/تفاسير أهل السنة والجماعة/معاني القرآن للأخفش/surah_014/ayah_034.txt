وقال {  وَآتَاكُم مِّن كُلِّ مَا سَأَلْتُمُوهُ } ( 34 ) أي :  آتاكم من كُلِّ شَيُءٍ سَأَلْتُمُوهُ شَيْئاً "  وأَضمر الشيء كما قال {  وَأُوتِيَتْ مِن كُلِّ شَيْءٍ } أيْ :   " أُوتِيَتْ من كلِّ شَيءٍ في زمانِها شَيْئاً "  قال بعضُهم :   " إِنما ذا على التكثير "  نحو قولك :   " هُوَ يَعْلَمُ كُلَّ شيء "  و " أتاه كلُّ الناسِ "  وهو يعني بعضهم :  وكذلك {  فَتَحْنَا عَلَيْهِمْ أَبْوَابَ كُلِّ شَيْءٍ } .  وقال بعضهم :   " لَيْسَ من شَيْءٍ إِلاّ وَقَدْ سأله بعضُ الناس فقال {  وَآتَاكُم مِّن كُلِّ مَا سَأَلْتُمُوهُ } أي :   " مِن كل ما سألتُمُوهُ قد آتى بعضَكُم منهُ شيئا وآتى آخَر شَيْئاً مما قد سأَل "  .

ونون بضعهم {  مِّن كُلٍّ } ( 34 ) يقول {  مِّن كُلٍّ } ثم قال  " لَمْ تَسْأَلُوهُ إيّاه "  كما تقول :   " قَدْ سَأَلْتُك مِنْ كُلٍّ "  و " قَدْ جَاءَنِي مِنْ كُلٍّ "  لأنَّ  " كُلّ "  قد تفرد وحدها .
