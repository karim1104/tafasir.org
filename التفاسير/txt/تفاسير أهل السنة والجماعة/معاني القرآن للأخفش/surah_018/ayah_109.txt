وقال {  قُل لَّوْ كَانَ الْبَحْرُ مِدَاداً لِّكَلِمَاتِ رَبِّي } ( 109 ) يقول [ 149 ء ]  " مِدَاداً يكتب به "  {  لَنَفِدَ الْبَحْرُ قَبْلَ أَن تَنفَدَ كَلِمَاتُ رَبِّي وَلَوْ جِئْنَا بِمِثْلِهِ مَدَداً } ( 109 ) يقول :   " مَدَدٌ لَكُم "  وقال بعضهم {  مِدَادَا } تكتب به .  ويعني بالمداد أنه مدد للمداد يمد به ليكون معه .
