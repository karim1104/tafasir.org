وقال {  لاَّ يُحِبُّ اللَّهُ الْجَهْرَ بِالسُّوءِ مِنَ الْقَوْلِ إِلاَّ مَن ظُلِمَ } ( 148 ) لأنه حين قال {  لاَّ يُحِبُّ اللَّهُ } قد أخبر أنه لا يحل .  ثم قال {  إِلاَّ مَن ظُلِمَ } فانه يحل له أن يجهر بالسوء لمن ظلمه .  وقال بعضهم {  ظَلَم } على قوله {  مَّا يَفْعَلُ اللَّهُ بِعَذَابِكُمْ } ( 147 ) [ فيكون ] {  إِلاَّ مَن ظَلَم } [ على معنى ]  " إِلاّ بِعَذابِ مَنْ ظَلَم "  .
