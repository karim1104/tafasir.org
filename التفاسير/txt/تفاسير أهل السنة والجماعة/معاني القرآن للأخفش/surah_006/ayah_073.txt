وقال {  وَيَوْمَ يَقُولُ كُن فَيَكُونُ } ( 73 ) قال {  يَوْم } مضاف إلى قوله {  كُنْ فَيَكُونُ } وهو نصب [ 110 ب ] وليس له خبر ظاهر و الله اعلم .  وهو على ما فسرت لك .

وكذلك {  يَوْمَ يُنفَخُ فِي الصُّوَرِ } ( 73 ) وقال بعضهم {  يَوْمَ يُنْفَحُ في الصُّورِ } وقال بعضهم {  يَنْفُخُ } {  عَالِمُ الْغَيْبِ وَالشَّهَادَةِ } ( 73 ) .
