وقال تعالى {  وَمَا كَانَ قَوْلَهُمْ إِلاَّ أَن قَالُواْ } ( 147 ) وقال {  وَمَا كَانَ جَوَابَ قَوْمِهِ إِلاَّ أَن قَالُواْ } و [ قال ] {  مَّا كَانَ حُجَّتَهُمْ إِلاَّ أَن قَالُواْ } ف{  أَنْ قَالُواْ } هو الاسم الذي يرفع ب{  وَكَانَ } لأن {  أَنْ } الخفيفة وما عملت فيه بمنزلة اسم تقول :   " أعْجَبَنِي أَنْ قالوا "  وإنْ شئت رفعت أول هذا كله وجعلت الآخر في موضع نصب على خبر كان .  قال الشاعر :  [ من الطويل وهو الشاهد الستون بعد المائة ] :

لَقَدْ عَلِمَ الأَقْوامُ ما كانَ دَاءَها *** بِثَهْلانَ إلاَّ الخِزْيُ مِمَّنْ يَقُودُها

وإن شئت  " ما كانَ داؤُها إلا الخِزْيَ "  .
