وقال تعالى {  فَنَادَتْهُ الْمَلائِكَةُ [ وَهُوَ قَائِمٌ يُصَلِّي فِي الْمِحْرَابِ* ] أَنَّ اللَّهَ يُبَشِّرُكَ } ( 39 ) لأَنَّهُ كأنه قال {  نَادَتْهُ الْمَلائِكَةُ } فقالت :  {  إِنَّ اللَّهَ يُبَشِّرُكَ } وما بعد القول حكاية [ 85ء ] .  وقال بعضهم {  أَنَّ اللّهَ } يقول :   " فنادته الملائكة بذلك  "  .

وقال تعالى {  بِيَحْيَى مُصَدِّقاً بِكَلِمَةٍ مِّنَ اللَّهِ وَسَيِّداً وَحَصُوراً } ( 39 ) وقوله {  وَسَيِّداً وَحَصُوراً } معطوف على  " مُصَدِّقاً "  على الحال .
