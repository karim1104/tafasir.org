وقال تعالى {  لاَ يَأْلُونَكُمْ خَبَالاً } ( 118 ) لأنها من  " ألَوْتُ "  و " ما آلُو "   " أَلْواً "  .

وقال تعالى {  وَدُّواْ مَا عَنِتُّمْ } ( 118 ) يقول {  لاَ تَتَّخِذُواْ بِطَانَةً } {  وَدُّواْ } أي :  أحَبُّوا {  مَا عَنِتُّمْ } جعله من صفة  " البِطانةَ "  ،  جعل {  مَا عَنِتُّمْ } في موضع  " العَنَتِ "  .
