وقال {  لاَّ يَتَّخِذِ الْمُؤْمِنُونَ الْكَافِرِينَ } ( 28 ) بكسر {  يَتَّخِذِ } لأنه لقيته لام ساكنة وهي نهي فكسرته .

وقال تعالى {  إِلاَّ أَن تَتَّقُواْ مِنْهُمْ تَقِيَّةً } ( 28 ) وقال بعضهم {  تُقَاةً } وكلٌّ عربي و{  تُقَاةٌ } أجْوَدُ ،  مثل :   " اِتَّكَأَ "   " تُكَأَةً "  و " اِتَّخم "   " تُخَمَةً "  و " اِتَّحَفَ "   " تُحْفَةً "  .
