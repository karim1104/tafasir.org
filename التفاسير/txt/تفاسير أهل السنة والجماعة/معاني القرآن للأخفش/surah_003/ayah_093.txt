وقال تعالى {  كُلُّ الطَّعَامِ كَانَ حِلاًّ لِّبَنِي إِسْرَائِيل } ( 93 ) لأنه يقال :   " هذا حَلالٌ "  و :   " هذا حِلٌّ "  ،  و " هذا حَرام "  و " هذا حِرْمٌ "  ويقال* {  وَحَرَامٌ عَلَى قَرْيَةٍ } [ ويقال ] {  وحِرْمٌ على قرية } وتقول :   " حِرْمٌ عَليّكُم ذاك "  ولو قال {  وحُرْمٌ على قريةٍ } كان جائزا [ ولو قال ] {  وحَرْمٌ على قريةٍ } كان جائزاً أيضاً .
