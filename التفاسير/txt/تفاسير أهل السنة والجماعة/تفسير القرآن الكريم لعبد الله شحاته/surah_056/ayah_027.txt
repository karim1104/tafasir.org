أصحاب اليمين

{  وَأَصْحَابُ الْيَمِينِ مَا أَصْحَابُ الْيَمِينِ ( 27 ) فِي سِدْرٍ مَخْضُودٍ ( 28 ) وَطَلْحٍ مَنْضُودٍ ( 29 ) وَظِلٍّ مَمْدُودٍ ( 30 ) وَمَاءٍ مَسْكُوبٍ ( 31 ) وَفَاكِهَةٍ كَثِيرَةٍ ( 32 ) لاَ مَقْطُوعَةٍ وَلاَ مَمْنُوعَةٍ ( 33 ) وَفُرُشٍ مَرْفُوعَةٍ ( 34 ) إِنَّا أَنْشَأْنَاهُنَّ إِنْشَاءً ( 35 ) فَجَعَلْنَاهُنَّ أَبْكَارًا ( 36 ) عُرُبًا أَتْرَابًا ( 37 ) لِأَصْحَابِ الْيَمِينِ ( 38 ) ثُلَّةٌ مِنَ الْأَوَّلِينَ ( 39 ) وَثُلَّةٌ مِنَ الْآَخِرِينَ ( 40 ) }

/م27

التفسير :

27- {  وَأَصْحَابُ الْيَمِينِ مَا أَصْحَابُ الْيَمِين } .

يبدأ الحديث هنا عن أصحاب اليمين ،  وهم من أهل الجنة ممن يأخذون كتابهم باليمين ،  ومع ذلك فما أعظم حالهم ،  وما أكرم مآلهم ،  والاستفهام للتهويل والتخويف والتفخيم .

والمعنى :  وأصحاب اليمين لا يعلم أحد جزاءهم ولا ثوابهم ،  إنه شيء عظيم .
