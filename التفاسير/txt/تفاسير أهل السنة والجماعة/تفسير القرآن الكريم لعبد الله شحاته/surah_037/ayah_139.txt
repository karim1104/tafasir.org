قصة يونس عليه السلام

{  وإن يونس لمن المرسلين ( 139 )إذ أبق إلى الفلك المشحون ( 140 ) فساهم فكان من المدحضين ( 141 ) فالتقمه الحوت وهو مليم ( 142 )فلولا أنه كان المسبحين ( 143 )للبث في بطنه إلى يوم يبعثون ( 144 ) * فنبذناه بالعراء وهو سقيم ( 145 ) وأنبتنا عليه شجرة من يقطين ( 146 ) وأرسلناه إلى مائة ألف أو يزيدون ( 147 ) فآمنوا فمتعناهم إلى حين ( 148 ) }

/م139

التفسير :

139- {  وإن يونس لمن المرسلين } .

وإن يونس لمن جماعة المرسلين ،  فاذكر أيها الرسول قصته وخبره لقومك .
