{ اسلك } يعنى ادخل { يدك } اليمنى { في جيبك } فجعلها في جيبه من قبل الصدر ، وهى مدرعة من صوف مضربة { تخرج } يدك من الجيب { بيضاء من غير سوء } يعني من غير برص لها شعاع كشعاع الشمس ، يغشى البصر { واضمم إليك جناحك } يعني عضدك من يدك { من الرهب فذانك برهانان من ربك } يعني آيتين من ربك يعني اليد والعصا { إلى فرعون وملإيه إنهم كانوا قوما فاسقين } آية يعني عاصين .
