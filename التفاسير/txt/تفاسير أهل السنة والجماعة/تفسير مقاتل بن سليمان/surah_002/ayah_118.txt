{ وقال الذين لا يعلمون } بتوحيد ربهم ، يعني  : مشركي العرب للنبي صلى الله عليه وسلم ، { لولا } يعنون هلا { يكلمنا الله } يخبرنا بأنك رسوله ، { أو تأتينا آية } كما كانت الأنبياء تأتيهم الآيات تجئ إلى قومهم ، يقول الله : { كذلك قال الذين من قبلهم مثل قولهم } ، يقول : هكذا قالت بنو إسرائيل من قبل مشركي العرب ، فقالوا في سورة البقرة ، والنساء لموسى : { أرنا الله جهرة } ( النساء : 103 ) ، وأتوا بالآيات وسمعوا الكلام فحرفوه ، فهل هؤلاء إلا مثل أولئك ؟ فذلك قوله سبحانه : { تشابهت قلوبهم } ، ثم قال : وإن كذب مشركو العرب بمحمد ، { قد بينا الآيات } ، أي :  فقد بينا الآيات ، فذلك قوله سبحانه في العنكبوت : { بل هو آيات } ، يعني  : بيان أمر محمد آيات { بينات } ( العنكبوت : 49 ) ، يعني  : واضحات في التوراة أنه أمي لا يقرأ الكتاب ولا يخط بيمينه ، { لقوم يوقنون } يعني  : مؤمني أهل التوراة .
