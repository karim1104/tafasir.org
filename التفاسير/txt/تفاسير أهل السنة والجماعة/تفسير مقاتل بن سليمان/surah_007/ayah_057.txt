{ وهو الذي يرسل الرياح بشرا بين يدي رحمته } ، يقول : الرياح نشرا للسحاب ، كقوله : { يرسل الرياح فتثير سحابا } ( الروم : 48 ) ، يسير السحاب قدام الرياح ، { حتى إذا أقلت } ، يعني إذا حملت الريح { سحابا ثقالا } من الماء ، { سقناه لبلد ميت } ، ليس فيه نبات ، { فأنزلنا به الماء فأخرجنا به } بالماء من الأرض ، { من كل الثمرات كذلك } ، يعني هكذا ، { نخرج } ، يخرج الله { الموتى } من الأرض بالماء ، كما أخرج النبات من الأرض بالماء ، { لعلكم } ، يعني لكي { تذكرون } فتعتبروا في البعث أنه كائن ، نظيرها في الروم والملائكة .
