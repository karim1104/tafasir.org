{ قالوا } لها : { نحن أولوا قوة } يعنى عدة كثيرة في الرجال كقوله : { فأعينوني بقوة } [ الكهف :95 ] ، يعنى بالرجال { وأولوا بأس شديد } في الحرب/ يعنى الشجاعة { والأمر إليك } يقول : قد أخبرناك بما عندنا وما نجاوز ما تقولين ، { فانظري ماذا تأمرين } آية ، يعنى ماذا تشيرين علينا ، كقول فرعون لقومه : { فماذا تأمرون } [ الشعراء :35 ] يعنى ماذا تشيرون علي .
