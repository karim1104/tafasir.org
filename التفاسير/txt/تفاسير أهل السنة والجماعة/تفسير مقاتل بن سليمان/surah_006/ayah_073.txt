ثم خوفهم ، فقال : { وهو الذي خلق السماوات والأرض بالحق } ، يعني بأنه لم يخلقهما باطلا لغير شيء ، ولكن خلقهما لأمر هو كائن ، { ويوم يقول } الله للبعث مرة واحدة : { كن فيكون } ، لا يثنى الرب القول مرتين ، { قوله } في البعث { الحق } ، يعني الصدق ، وأنه كائن ، { وله الملك يوم ينفخ } ، أي ينفخ إسرافيل ، { في الصور عالم الغيب } ، يعلم غيب ما كان وما يكون ، ثم قال : { والشهادة } ، يعني شاهد كل نجوى وكل شيء ، { وهو الحكيم } ، يعني حكم البعث ، { الخبير } بالبعث متى يبعثهم .
