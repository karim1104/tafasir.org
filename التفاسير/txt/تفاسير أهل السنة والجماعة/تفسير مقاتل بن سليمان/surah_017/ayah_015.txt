{ من اهتدى فإنما يهتدى لنفسه } الخير ، { ومن ضل } عن الهدى ، { فإنما يضل عليها } ، أي على نفسه ، يقول : فعلى نفسه إثم ضلالته ، { ولا تزر وزارة وزر أخرى } ، يقول : لا تحمل نفس خطيئة نفس أخرى ، { وما كنا معذبين } في الدنيا أحدا ، { حتى نبعث رسولا } [ آية :15 ] لينذرهم بالعذاب في الدنيا بأنه نازل بهم ، كقوله سبحانه : { وما أهلكنا } في الدنيا { من قرية إلا لها منذرون } [ الشعراء :208 ] .
