{ ووهبنا } عطف على { آتينا } [ الأنعام : 83 ] و { إسحاق } ابنه من سارة ،   { ويعقوب } هو ابن إسحاق ،   و { كلاً } و { نوحاً } منصوبان على المفعول مقدمان على الفعل ،   وقوله : { من قبل } لقومه صلى الله عليه وسلم ،   وقوله : { ومن ذريته } المعنى وهدينا من ذريته ،   والضمير في { ذريته } قال الزجّاج جائز أن يعود على إبراهيم ،   ويعترض هذا بذكر «لوط » عليه السلام وهو ليس من ذرية إبراهيم بل هو ابن أخيه وقيل ابن أخته ويتخرج عند من يرى الخال أباً وقيل : يعود الضمير على نوح وهذا هو الجيد ،   و { داود } يقال هو ابن أيشى { وسليمان } ابنه ،   { وأيوب } هما فيما يقال أيوب بن رازح بن عيصو بن إسحاق بن إبراهيم ،   { ويوسف } هو ابن يعقوب بن إسحق ،   { وموسى وهارون } ها ابنا عمران بن يصهر بن قاهث بن لاوي بن يعقوب ،   ونصب { دواد } يحتمل أن يكون ب { وهبنا } ويحتمل أن يكون ب { هدينا } وهذه الأسماء كلها فيها العجمة والتعريف ،   فهي غير مصروفة ،   { وموسى } عند سيبويه وزنه مفعل فعلى هذا يتصرف في النكرة ،   وقيل وزنه فعلى ،   فعلى هذا لا يتصرف في معرفة ولا نكرة ،   { وكذلك نجزي المحسنين } وعد من الله عز وجل لمن أحسن في عمله وترغيب في الإحسان .
