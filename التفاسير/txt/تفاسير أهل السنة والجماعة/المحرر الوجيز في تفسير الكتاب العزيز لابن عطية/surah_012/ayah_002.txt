والضمير في قوله : { أنزلناه } ل { الكتاب } ،   والإنزال : إما بمعنى الإثبات ،   وإما أن تتصف به التلاوة والعبارة ؛ وقال الزجاج : الضمير في { أنزلناه } يراد به خبر يوسف .

قال القاضي أبو محمد : وهذا ضعيف ،   وقوله : { لعلكم } يحتمل أن تتعلق ب { أنزلناه } أي أنزلناه لعلكم ،   ويحتمل أن تتعلق بقوله : { عربياً } أي جعلناه { عربياً لعلكم تعقلون } ،   إذ هو لسانكم .   و { قرآناً } حال ،   و { عربياً } صفة له ،   وقيل : إن { قرآناً } بدل من الضمير - وهذا فيه نظر - وقيل : { قرآناً } توطئة للحال و { عربياً } حال ،   وهذا كما تقول : مررت بزيد رجلاً صالحاً .
