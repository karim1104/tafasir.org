{ هو الأول } الذي ليس لوجوده بداية مفتتحة .   { والآخر } الدائم الذي ليس له نهاية منقضية .   قال أبو بكر الوراق { هو الأول } بالأزلية ،   { والآخر } بالأبدية ،   و { هو الأول } بالوجود ،   إذ كل موجود فبعده وبه .   { والآخر } إذا ترقى العقل في الموجودات حتى يكون إليه منتهاها ،   قال عز وجل : { وأن إلى ربك المنتهى } [ النجم : 42 ] .   { والظاهر } معناه بالأدلة ونظر العقول في صنعته .   { والباطن } بلطفه وغوامض حكمته وباهر صفاته التي لا يصل إلى معرفتها على ما هي عليه الأوهام .

ويحتمل أن يريد بقوله : { الظاهر والباطن } أي الذي بهر وملك فيما ظهر للعقول وفيما خفي عنها فليس في الظاهر غيره حسب قيام الأدلة ،   وليس في باطن الأمر وفيما خفي عن النظرة مما عسى أن يتوهم غيره .

وقوله تعالى : { وهو بكل شيء عليم } عام في الأشياء عموماً تاماً .
