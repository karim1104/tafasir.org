وقوله : { يقدم قومه يوم القيامة } الآية ،   أخبر الله تعالى في هذه الآية عن فرعون أنه يأتي يوم القيامة مع قومه المغرقين معه ،   وهو يقدمهم إلى النار : وأوقع الفعل الماضي في { أوردهم } موقع المستقبل ،   لوضوح الأمر وارتفاع الإشكال عنه ،   ووجه الفصاحة من العرب في أنها تضع أحياناً الماضي موضع المستقبل أن الماضي أدل على وقوع الفعل وحصوله ،   و «الورود » في هذه الآية هو ورود الدخول وليس بورود الإشراف على الشيء والإشفاء لقوله تعالى : { ولما ورد ماء مدين } وقال ابن عباس : في القرآن أربعة أوراد : { وإن منكم إلا واردها } وقوله : { ونسوق المجرمين إلى جهنم ورداً } وهذه في مريم ،   وفي الأنبياء : { إنكم وما تعبدون من دون الله حصب جهنم أنتم لها واردون } قال : وهي كلها ورد دخول ،   ثم ينجي الله الذين اتقوا و { المورود } صفة لمكان الورد - على أن التقدير : { وبئس } مكان { الورد المورود } - وقيل : { المورود } ابتداء والخبر مقدم ،   والمعنى : المورود بئس الورد .
