وقوله { وقل جاء الحق } الآية ،   قال قتادة : { الحق } القرآن ،   و { الباطل } الشيطان ،   وقالت فرقة : { الحق } الإيمان ،   { والباطل } الكفر ،   وقال ابن جريج : { الحق } الجهاد ،   { والباطل } الشرك ،   وقيل غير ذلك ،   والصواب تعميم اللفظ بالغاية الممكنة ،   فيكون التفسير جاء الشرع بجميع ما نطوى فيه ،   { وزهق } الكفر بجميع ما انطوى فيه ،   و { الباطل } كل ما لا تنال به غاية نافعة .   وقوله { كان زهوقاً } ليست { كان } إشارة إلى زمن مضى ،   بل المعنى كان وهو يكون ،   وهذا كقولك كان الله عليماً قادراً ونحو هذا ،   وهذه الآية نزلت بمكة ،   ثم إن رسول الله كان يستشهد بها يوم فتح مكة وقت طعنه الأصنام وسقوطها لطعنه إياها بالمخصرة حسبما في السيرة لابن هشام وفي غيرها .
