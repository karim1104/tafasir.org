{ وَلَقَدْ عَلِمْتُمُ ٱلَّذِينَ ٱعْتَدَواْ مِنْكُمْ فِي ٱلسَّبْتِ } علم هنا تعدي إلى واحد أي عرفتم أعيانهم واعتداؤهم فيه أنه حرم عليهم العمل فيه وصيد الحيتان فيه فكان يكثر ظهورها فيه وتذهب بعد ذهابه فتحيلوا في صيده بنوع من الحيل كحفر حفيرة أو ربط الحوت بخرمة فإِذا مضى السبت أخذوه ثم كثر ذلك حتى صادوه يوم السبت علانية وباعوه في الأسواق. ومنكم: في موضع الحال أي كائنين منكم. وفي السبت: متعلق باعتدوا أي في العمل يوم السبت بالاصطياد منه.  { فَقُلْنَا لَهُمْ كُونُواْ قِرَدَةً } أمر يدل على سرعة الكون بهذا الوصف وكأنهم ممتثلون ذلك وإلا فليسوا بقادرين على ذلك والظاهر صيرورتهم قردة حقيقة وقد جاء في الحديث أن أمة مسخت ولا ينكر ذلك من قدرة الله تعالى ألا ترى إلى انقلاب عصا موسى حية ثم عودها عصا. والقرد حيوان معروف. وفعل الاسم القياس فيه فعول نحو قرود وجمعه على فعلة لا ينقاس نحو قردة وحسلة في جمع قرد وحسل والخسؤ الصغار والطرد وفعله خسأ يجيىء متعدياً ولازماً.  { فَجَعَلْنَاهَا } أي الكينونة قردة.  { نَكَالاً } عبرة. واصل النكال: المنع. والنكل: القيد.  { لِّمَا بَيْنَ يَدَيْهَا } أي لمن قرب منها.  { وَمَا خَلْفَهَا } أي من جاء بعدهم.  { وَمَوْعِظَةً } أي إذكاراً.  { لِّلْمُتَّقِينَ } لأن الذين ينتفعون بالموعظة إنما هم المتقون.
