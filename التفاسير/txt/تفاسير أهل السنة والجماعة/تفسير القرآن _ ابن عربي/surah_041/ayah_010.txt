{ قُلْ أئنكم لتكفرون بالذي خلق الأرض في يومين } أي: في حادثين كما ذكر أنّ اليوم معبّر به عن الحادث لنسبته إليه في قولهم: الحوادث اليومية لتشابهها في الظهور والخفاء، وهما الصورة والمادّة { وبارك فيها } أي: أكْثَرَ خيرها { وقدَّر فيها } معايشها وأرزاقها { في أربعة أيام } هي الكيفيات الأربع والعناصر الأربعة التي خلق منها المركبات بالتركيب والتعديل { سواء } مستوية بالامتزاج والاعتدال للطالبين للأقوات والمعايش، أي: قدّرها لهم { ثم استوى إلى السماء } أي:قصد إلى إيجادها وثم للتفاوت بين الخلقين في الإحكام وعدمه، واختلافهما في الجهة والجوهر لا للتراخي في الزمان إذ لا زمان هناك { وهي دخان } أي: جوهر لطيف بخلاف الجواهر الكثيفة الثقيلة الأرضية { فقال لها وللأرض ائتيا طوعاً أو كرهاً } أي: تعلق أمره وإرادته بإيجادهما فوجدتا في الحال معاً كالمأمور المطيع إذ ورد عليه أمر الآمر المطاع لم يلبث في امتثاله، وهو من باب التمثيل إذ لا قول ثمة.
