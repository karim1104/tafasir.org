{ أفمن شرح الله صدره للإسلام } بنوره حال البقاء بعد الفناء ونقى قلبه بالوجود الموهوب الحقاني فيسع صدره الحق والخلق من غير احتجاب بأحدهما عن الآخر فيشاهد التفصيل في عين الوحدة والتوحيد في عين الكثرة، والإسلام هو الفناء في الله وتسليم الوجه إليه، أي: شرح صدره في البقاء لإسلامه وجهه حال الفناء { فهو على نور من ربّه } يرى ربّه { فويل } للذين قست قلوبهم من قبول ذكر الله لشدّة ميلها إلى اللذات البدنية وإعراضها عن الكمالات القدسية { أولئك في ضلال مبين } عن طرين الحق { متشابهاً } في الحق والصدق { مثاني } لتنزلها عليك في مقام القلب قبل الفناء وبعده فتكون مكرّرة باعتبار الحق والخلق، فتارة يتلوها الحق وتارة يتلوها الخلق { تقشعرّ منه جلود } أهل الخشية من العلماء بالله لانفعالها بالهيئات النوراينة الواردة على القلب النازل أثرها إلى البدن { ثم تلين جلودهم وقلوبهم } وأعضاؤهم بالانقياد والسكينة والطمأنينة { إلى ذكر الله ذلك هدى الله } بالأنوار اليقينية { يهدي به من يشاء } من أهل عنايته { ومن يضلل الله } يحجبه عن النور فلا يفهم كلامه ولا يرى معناه { فما له من هاد أفمن يتقي بوجهه سوء العذاب } مع كونه أشرف الأعضاء لكون سائر جوارحه مقيدة بهيئات لا يتأتي له التحرّز بها ولا يتهيأ، مغلّلة بأغلال لا يتيسر له بها الحركة في الدفع ولا يتسنى كمن أمن العذاب. { مثلاً } في التوحيد والشرك { رجلاً فيه شركاء متشاكسون } سيِّئو الأخلاق لا يتسالمون في شيء يوجهه هذا في حاجة ويمنعه هذا ويجذبه أحدهما إلى جهة والآخر إلى ما يقابلها، فيتنازعون ويتجاذبون وهذا صفة من تستولي عليه صفات نفسه المتجاذبة لاحتجابه بالكثرة المتخالفة فهو في عين التفرقة همّه شعاع وقلبه أوزاع { ورجلاً سلماً لرجل } لا يبعثه إلا إلى جهته، وهذا مثل الموحد الذي تسالمت له مشايعة السرّ إلى جناب الربّ ليس له إلا همٌّ واحد ومقصد واحد في عين الجمعية مجموع ناعم البال خافض العيش والحال.
