{ والذين إذا فَعَلوا فاحشة } كبيرة من الكبائر، برؤية أفعالهم صادرة عن قدرتهم { أو ظلموا أنفسهم } نقصوا حقوقها بارتكاب الصغائر وظهور أنفسهم فيها { ذكروا الله } في صدور أفعالهم برؤيتها واقعة بقدرة الله وتبرأ عنها إليه لرؤيتهم ابتلاءه إياهم بها { فاستغفروا } طلبوا ستر أفعالهم التي هي ذنوبهم بأفعاله بالتبرّي عن الحول والقوّة إليه { ومن يغفر الذنوب } أي وجودات الأفعال { إلا الله } أي علموا أن لا غافر إلا هو { ولم يصرّوا على ما فَعَلوا } في غفلتهم وحالة ظهور أنفسهم، بل تابوا ورجعوا إليه في أفعالهم { وهم يَعْلمُون } أن لا فعل إلا الله { ونِعْمَ أجر العاملين } بمقتضى توحيد الأفعال.
