{ يا أيها الذين أوتُوا الكتاب } كتاب الاستعداد { آمنُوا } إيماناً حقيقياً عيانياً بإخراج ما في كتاب استعدادكم إلى الفعل من توحيد الذات { من قَبل أنْ نطمس وجُوهاً } بإزالة استعدادها ومحوه { فنردها على أدبارها } التي هي أسفل سافلي عالم الجسم الذي هو خلف كل عالم { أو نَلْعَنهم } نعذبهم بالمسخ كما مسخنا { أصحاب السبتِ }  { وكان أمر الله مفعولاً } أي: مقضياً إلى الأبد، لا يغيّره أحد ولا ينقضه.
