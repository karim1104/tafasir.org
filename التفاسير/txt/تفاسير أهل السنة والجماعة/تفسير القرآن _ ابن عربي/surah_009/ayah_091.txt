{ وعد الله المُؤمنين والمؤمنات جنات تجري من تحتها الأنهار } وهي جنات النفوس { ومساكن طيبة } مقامات أرباب التوكل في جنات الأفعال بدليل قوله تعالى: { وَرِضْوَانٌ مِّنَ ٱللَّهِ أَكْبَرُ } [التوبة، الآية: 72]، فإن الرضوان من جنات الصفات { ذلك } أي الرضوان { هو الفوز العظيم } لكرامة أهله عند الله وشدّة قربهم منه.
