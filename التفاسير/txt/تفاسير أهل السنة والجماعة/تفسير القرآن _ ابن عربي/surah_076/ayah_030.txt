{ إنّ هذه } تذكير لسلوك طريقي والسير فيّ { فمن شاء اتّخذ } سبيلاً إليّ { وما تشاؤون إلاَّ } بمشيئتي بأن أريدهم فيريدوني فتكون إرادتهم مسبوقة بإرادتي، بل عين إرادتي الظاهرة في مظاهرهم { إنّ الله كان عليماً } بما أودع فيهم من العلوم { حكيماً } بكيفية إيداعها وإبرازها فيهم بإظهار كمالهم. { يدخل من يشاء في رحمته } بإفاضة ذلك الكمال المودع فيه عليه وإظهاره { والظالمين } الباخسين حقهم الناقصين حظهم منها بالاحتجاب عنها، أو الواضعين نور فطرتهم الذي هو النور الإلهي الأصلي الحاصل من اسمه المبدىء في غير موضعه من محبة الأنداد والاحتجاب بالآثار وعبادة الأغيار { أعدّ لهم عذاباً } بالوقف على الربّ لوقوفهم مع الغير ثم على النار لوقوفهم مع الآثار مؤلماً إيلاماً شديداً.
