قرىء «كما تقولون » بالتاء والياء .   و { إِذَا } دالة على أن ما بعدها وهو { لاَّبْتَغَوْاْ } جواب عن مقالة المشركين وجزاء ل ( لو ) ومعنى { لاَّبْتَغَوْاْ إلى ذِى العرش سَبِيلاً } لطلبوا إلى من له الملك والربوبية سبيلاً بالمغالبة كما يفعل الملوك بعضهم مع بعض ،   كقوله { لَوْ كَانَ فِيهِمَا الِهَةٌ إِلاَّ الله لفسدتا } [ الأنبياء : 22 ] وقيل : لتقرّبوا إليه ،   كقوله { أولئك الذين يَدْعُونَ يَبْتَغُونَ إلى رَبّهِمُ الوسيلة } [ الإسراء : 57 ] .
