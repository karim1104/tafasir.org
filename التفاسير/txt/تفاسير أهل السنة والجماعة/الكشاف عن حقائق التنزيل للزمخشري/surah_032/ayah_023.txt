{ الكتاب } للجنس والضمير في { لّقَائِهِ } له .   ومعناه : إنا آتينا موسى عليه السلام مثل ما آتيناك من الكتاب ،   ولقيناه مثل ما لقيناك من الوحي ،   فلا تكن في شك من أنك لقيت مثله ولقيت نظيره كقوله تعالى : { فَإِن كُنتَ فِي شَكّ مّمَّا أَنزَلْنَا إِلَيْكَ فَاسْأَلِ الذين يَقْرَءونَ الكتاب مِن قَبْلِك } [ يونس : 94 ] ونحو قوله : { مّن لّقَائِهِ } وقوله : { وَإِنَّكَ لَتُلَقَّى القرءان مِن لَّدُنْ حَكِيمٍ عَلِيمٍ } [ النمل : 6 ] وقوله : { وَنُخْرِجُ لَهُ يَوْمَ القيامة كِتَابًا يلقاه مَنْشُوراً } [ الإسراء : 13 ] .   وجعلنا الكتاب المنزل على موسى عليه السلام { هُدًى } لقومه .
