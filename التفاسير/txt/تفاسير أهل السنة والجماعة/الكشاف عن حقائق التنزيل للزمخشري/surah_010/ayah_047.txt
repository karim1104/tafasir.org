{ وَلِكُلّ أُمَّةٍ رَّسُولٌ } يبعث إليهم لينبههم على التوحيد ،   ويدعوهم إلى دين الحق { فَإِذَا جَاء } هم { رَسُولَهُمْ } بالبينات فكذبوه ،   ولم يتبعوه { قُضِىَ بَيْنَهُمْ } أي بين النبيّ ومكذّبيه { بالقسط } بالعدل ،   فأنجى الرسول وعذّب المكذّبون ،   كقوله ؛ { وَمَا كُنَّا مُعَذّبِينَ حتى نَبْعَثَ رَسُولاً } [ الإسراء : 15 ] أو لكل أمّة من الأمم يوم القيامة رسول تنسب إليه وتدعى به ،   فإذا جاء رسولهم الموقف ليشهد عليهم بالكفر والإيمان ،   كقوله تعالى : { وَجِىء بالنبيين والشهداء وَقُضِىَ بَيْنَهُمْ بالحق } [ الزمر : 69 ] .
