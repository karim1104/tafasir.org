{ أن } الأولى نصب .   والثانية رفع ،   وقبلها مضاف محذوف تقديره { وَمَا مَنَعَ الناس } الإيمان والاستغفار { إِلا } انتظار { أَن تَأْتِيَهُمْ سُنَّةُ الأولين } وهي الإهلاك { أَوْ } انتظار أن { يَأْتِيهِمُ العذاب } يعني عذاب الآخرة { قُبُلاً } عياناً .   وقرىء : «قِبَلا » أنواعاً : جمع قبيل .   و «قَبَلا » ،   بفتحتين : مستقبلاً .
