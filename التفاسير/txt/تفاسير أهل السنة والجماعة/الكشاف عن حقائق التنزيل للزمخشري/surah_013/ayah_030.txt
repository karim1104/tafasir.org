{ كَذَلِكَ أَرْسَلْنَاكَ } مثل ذلك الإرسال أرسلناك ،   يعني : أرسلناك إرسالاً له شأن وفضل على سائر الإرسالات ،   ثم فسر كيف أرسله فقال : { فِى أُمَّةٍ قَدْ خَلَتْ مِن قَبْلِهَا أُمَمٌ } أي أرسلناك في أمة قد تقدمتها أمم كثيرة فهي آخر الأمم وأنت خاتم الأنبياء { لّتَتْلُوَ عَلَيْهِمُ الذي أَوْحَيْنَا إِلَيْكَ } لتقرأ عليهم الكتاب العظيم الذي أوحينا إليك { وَهُمْ يَكْفُرُونَ } وحال هؤلاء أنهم يكفرون { بالرحمن } بالبليغ الرحمة الذي وسعت رحمته كل شيء ،   وما بهم من نعمة فمنه ،   فكفروا بنعمته في إرسال مثلك إليهم وإنزال هذا القرآن المعجز المصدق لسائر الكتب عليهم { قُلْ هُوَ رَبّى } الواحد المتعالي عن الشركاء { عَلَيْهِ تَوَكَّلْتُ } في نصرتي عليكم { وَإِلَيْهِ مَتَابِ } فيثيبني على مصابرتكم ومجاهدتكم .
