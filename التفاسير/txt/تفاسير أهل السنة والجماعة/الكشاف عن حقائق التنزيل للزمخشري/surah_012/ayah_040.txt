{ مَا تَعْبُدُونَ } خطاب لهما ولمن على دينهما من أهل مصر { إِلاَّ أَسْمَاء } يعني أنكم سميتم ما لا يستحق الإلهية آلهة ،   ثم طفقتم تعبدونها ،   فكأنكم لا تعبدون إلا أسماء فارغة لا مسميات تحتها .   ومعنى { سَمَّيْتُمُوهَا } سميتم بها .   يقال : سميته بزيد ،   وسميته زيداً { مَّا أَنزَلَ الله بِهَا } أي بتسميتها { مّن سلطان } من حجة { إِنِ الحكم } في أمر العبادة والدين { أَلاَ لِلَّهِ } ثم بين ما حكم به فقال { أَمَرَ أَلاَّ تَعْبُدُواْ إِلاَّ إِيَّاهُ ذلك الدين القيم } الثابت الذي دلت عليه البراهين .
