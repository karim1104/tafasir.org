{ اخسئوا فِيهَا } ذلوا فيها وانزجروا كما تنزجر الكلاب إذا زجرت .   يقال : خسأ الكلب وخسأ بنفسه .   { وَلاَ تُكَلّمُونِ } في رفع العذاب ،   فإنه لا يرفع ولا يخفف .   قيل : هو آخر كلام يتكلمون به ،   ثم لا كلام بعد ذلك إلا الشهيق والزفير والعواء كعواء الكلاب لا يفهمون ولا يُفهمون .   وعن ابن عباس : إنّ لهم ست دعوات : إذا دخلوا النار قالوا : ألف سنة : { رَبَّنَا أَبْصَرْنَا وَسَمِعْنَا } [ السجدة : 12 ] فيجابون : { حَقَّ القول مِنْى } [ السجدة : 12 ] ،   فينادُون ألفاً { رَبَّنَا أَمَتَّنَا اثنتين } [ غافر : 11 ] ،   فيجابون : { ذَلِكُم بِأَنَّهُ إِذَا دُعِىَ الله وَحْدَهُ كَفَرْتُمْ } [ غافر : 12 ] ،   فينادون ألفاً : { وَنَادَوْاْ يامالك لِيَقْضِ عَلَيْنَا رَبُّكَ } [ الزخرف : 77 ] ،   فيجابون : { إِنَّكُمْ ماكثون } [ الزخرف : 77 ] : فينادون ألفاً : { رَبَّنَا أَخّرْنَا } [ إبراهيم : 44 ] ،   فيجابون : { أَوَ لَمْ تَكُونُواْ } ،   فينادون ألفاً : { رَبَّنَا أَخْرِجْنَا نَعْمَلْ صالحا } [ فاطر : 37 ] ،   فيجابون : { أَوَ لَمْ نُعَمّرْكُمْ } [ فاطر : 37 ] ،   فينادون : { رَبّ ارجعون } [ المؤمنون : 99 ] ،   فيجابون : { اخسئوا فِيهَا } [ المؤمنون : 108 ] .
