{ قُلْ أَرَأَيْتُمْ إِنْ أَخَذَ اللَّهُ سَمْعَكُمْ وَأَبْصَارَكُمْ } فذهب بها { وَخَتَمَ عَلَى قُلُوبِكُمْ } وطبع عليها يعني لا يفقهوا قولاً ولا يبصروا حجة { مَّنْ إِلَهٌ غَيْرُ اللَّهِ يَأْتِيكُمْ بِهِ } يعني بما أخذ منكم { انْظُرْ كَيْفَ نُصَرِّفُ } نبين لهم { الآيَاتِ ثُمَّ هُمْ يَصْدِفُونَ } يعرضون عنها مكذبين بها
