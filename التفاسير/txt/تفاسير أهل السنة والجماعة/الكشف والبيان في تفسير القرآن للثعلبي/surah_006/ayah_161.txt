{ قُلْ } يا محمد { إِنَّنِي هَدَانِي رَبِّي إِلَى صِرَاطٍ مُّسْتَقِيمٍ دِيناً قِيَماً }  "  قرأ أهل الكوفة والشام : قِيَمَاً بكسر القاف وفتح الياء مخففاً .   وقرأ الباقون : قَيّماً بفتح القاف وكسر الياء مشدداً وهما لغتان وتصديق التشديد قوله تعالى

{ ذلِكَ الدِّينُ الْقَيِّمُ } [ التوبة : 36 ] .   و { دِيناً قِيَماً } معناهما : ذلك الدين القويم المستقيم .

واختلف النحّاة في وجه انتصابه فقال الأخفش : معناه هداني ديناً قيّماً ،   وقيل : عرفت ديناً قيّماً ،   وقيل : أعني ديناً قيّماً ،   وقيل : نصب على الآخر يعني ابتغوا ديناً قيّماً .

وقال قطرب : نصب على الحال ( وضع ) { مِّلَّةَ إِبْرَاهِيمَ } بدل من الدين { حَنِيفاً } نصب على الحال { وَمَا كَانَ مِنَ الْمُشْرِكِينَ }
