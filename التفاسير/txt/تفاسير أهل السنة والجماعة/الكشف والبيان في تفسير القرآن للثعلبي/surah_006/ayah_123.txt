{ وَكَذلِكَ } أي وكما زيّنا للكافرين أعمالهم كذلك جعلنا .

وقيل : وكما جعلنا فسّاق مكة أكابرها كذلك { جَعَلْنَا فِي كُلِّ قَرْيَةٍ أَكَابِرَ } يعني عظماء ،   جمع أكبر مثل أفضل وأحمر وأحامر وأسود وأساود { مُجَرِمِيهَا } إن شئت نصبته على التقديم تقديره وكذلك جعلنا في كل قرية مجرميها أكابر ،   كما تقول : جعلت زيداً رئيسها وإن شئت خفضته على الإضافة { لِيَمْكُرُواْ فِيهَا وَمَا يَمْكُرُونَ إِلاَّ بِأَنْفُسِهِمْ } لأن وبال مكرهم وجزاءه راجع إليهم { وَمَا يَشْعُرُونَ } إنه كذلك
