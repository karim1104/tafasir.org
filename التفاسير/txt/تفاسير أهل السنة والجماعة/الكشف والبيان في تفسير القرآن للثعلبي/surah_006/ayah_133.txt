{ وَرَبُّكَ الْغَنِيُّ } بعلمه { ذُو الرَّحْمَةِ } بهم { إِن يَشَأْ يُذْهِبْكُمْ } ثم يميتكم ويهلككم { وَيَسْتَخْلِفْ } يخلق { مِن بَعْدِكُمْ مَّا يَشَآءُ } خلقاً غيركم أمثل وأطوع منكم .

وقال عطاء : يريد الصحابة والتابعين { كَمَآ أَنشَأَكُمْ مِّن ذُرِّيَّةِ قَوْمٍ آخَرِينَ } قرناً بعد قرن ،   وقال مقاتل : يعني أهل سفينة نوح .   وقرأ زيد بن ثابت : ذرية بكسر الذال مشدّدة .

وقال أبان بن عثمان : ذرية بفتح الذال وكسر الراء خفيفة على قدر فعله ،   الباقون : بضم الذال مشددة ،   وهي لغات صحيحة .   وقال ثعلب : الذرية بالكسر الأصل ،   والذرية بالضم الولد
