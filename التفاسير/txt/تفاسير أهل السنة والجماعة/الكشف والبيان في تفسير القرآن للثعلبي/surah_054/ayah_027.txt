{ إِنَّا مُرْسِلُواْ النَّاقَةِ } باعثوها ومخرجوها من الهضبة التي سألوا { فِتْنَةً } محنة { لَّهُمْ فَارْتَقِبْهُمْ } وانتظرهم وننظر ما هم صانعون { وَاصْطَبِرْ } واصبر على ظلمهم وأذاهم ،   ولا تعجل حتى يأتيهم أمري ،   واصطبر : افتعل من الصبر ،   وأصل ( الطاء ) فيه ( تاء ) فحوّلت ( طاء ) لأجل ( الصاد ) .
