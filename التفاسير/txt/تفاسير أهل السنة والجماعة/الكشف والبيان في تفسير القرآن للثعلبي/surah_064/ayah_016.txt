{ فَاتَّقُواْ اللَّهَ مَا اسْتَطَعْتُمْ } ناسخة لقوله

{ اتَّقُواْ اللَّهَ حَقَّ تُقَاتِهِ } [ آل عمران : 102 ] وقد مرّ ذكره .

{ وَاسْمَعُواْ وَأَطِيعُواْ وَأَنْفِقُواْ خَيْراً لأَنفُسِكُمْ } مجازه : يكن الإنفاق خيراً لأنفسكم .   { وَمَن يُوقَ شُحَّ نَفْسِهِ } ومنعها عن الحقّ { فَأُوْلَئِكَ هُمُ الْمُفْلِحُونَ } قال ابن عمر :  "  ليس الشّح أن يمنع الرجل ماله ،   وإنّما الشّح أن يطمع الرجل إلى ما ليس له  "  .

{ إِن تُقْرِضُواْ اللَّهَ قَرْضاً حَسَناً يُضَاعِفْهُ لَكُمْ وَيَغْفِرْ لَكُمْ وَاللَّهُ شَكُورٌ حَلِيمٌ } .

 { عَالِمُ الْغَيْبِ وَالشَّهَادَةِ الْعَزِيزُ الْحَكِيمُ } .
