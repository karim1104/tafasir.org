{ قُلْ مَن كَانَ فِي الضَّلاَلَةِ فَلْيَمْدُدْ لَهُ الرَّحْمَنُ مَدّاً } أي فليدعه في طغيانه ويمهله في كفره { حَتَّى إِذَا رَأَوْاْ مَا يُوعَدُونَ } من العذاب { إِمَّا العَذَابَ } في الدنيا { وَإِمَّا السَّاعَةَ } يعني القيامة { فَسَيَعْلَمُونَ مَنْ هُوَ شَرٌّ مَّكَاناً وَأَضْعَفُ جُنداً } أهم أم المؤمنون .
