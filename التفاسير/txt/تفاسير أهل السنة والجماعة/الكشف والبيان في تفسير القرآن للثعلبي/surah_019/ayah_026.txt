{ فَكُلِي } يا مريم من الرطب { وَاشْرَبِي } من النهر { وَقَرِّي عَيْناً } وطيبي نفساً { فَإِمَّا تَرَيِنَّ مِنَ البَشَرِ أَحَداً } فسألك عن ولدكِ أو لامكِ عليه { فَقُولِي إِنِّي نَذَرْتُ لِلرَّحْمَنِ صَوْماً } يقال : إنّ الله أمرها أن تقول هذا اشارة ويقال : أمرها أن تقوله نطقاً ثم تمسك عن الكلام بعد هذا .

{ فَلَنْ أُكَلِّمَ الْيَوْمَ إِنسِيّاً } يقال : كانت تكلّم الملائكة ولا تكلّم الإنس .
