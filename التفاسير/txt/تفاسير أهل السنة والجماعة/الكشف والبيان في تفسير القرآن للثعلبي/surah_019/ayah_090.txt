{ تَكَادُ السَّمَاوَاتُ } قرأ نافع والكسائي بالياء لتقديم الفعل ،   وقرأ الباقون بالتاء لتأنيث السماوات { يَتَفَطَّرْنَ } يتشقّقن منه وقرأ أبو عمرو ينفطرن بالنون من الانفطار وهو اختيار أبي عبد اللَّه لقوله عز وجل

{ إِذَا السَّمَآءُ انفَطَرَتْ } [ الإنفطار : 1 ] وقوله

{ السَّمَآءُ مُنفَطِرٌ بِهِ } [ المزمل : 18 ] الباقون بالتاء من التفطّر { وَتَنشَقُّ الأَرْضُ وَتَخِرُّ الْجِبَالُ هَدّاً } قال ابن عباس : وقرأ مقاتل : وقطعاً وقال عطاء : هدماً ،   أبو عبيد : سقوطاً
