{ وَقُلِ الْحَمْدُ للَّهِ } على نعمه ،   { سَيُرِيكُمْ آيَاتِهِ } يعني يوم بدر ،   نظيرها في سورة الأنبياء :

{ سَأُوْرِيكُمْ آيَاتِي فَلاَ تَسْتَعْجِلُونِ } [ الأنبياء : 37 ] وقال مجاهد : { سَيُرِيكُمْ آيَاتِهِ } في أنفسكم وفي السماء والأرض والرزق ،   دليله قوله :

{ سَنُرِيهِمْ آيَاتِنَا فِي الآفَاقِ وَفِي أَنفُسِهِمْ } [ فصلت : 53 ] وقوله :

 { وَفِي الأَرْضِ آيَاتٌ لِّلْمُوقِنِينَ * وَفِي أَنفُسِكُمْ } [ الذاريات : 20-21 ] { فَتَعْرِفُونَهَا وَمَا رَبُّكَ بِغَافِلٍ عَمَّا تَعْمَلُونَ } .
