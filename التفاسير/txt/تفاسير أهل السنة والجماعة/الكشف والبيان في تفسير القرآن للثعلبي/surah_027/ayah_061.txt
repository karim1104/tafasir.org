{ أَمَّن جَعَلَ الأَرْضَ قَرَاراً } لا تميد بأهلها { وَجَعَلَ خِلاَلَهَآ } وسطها { أَنْهَاراً } تطّرد بالمياه { وَجَعَلَ لَهَا رَوَاسِيَ } جبالا ثوابت { وَجَعَلَ بَيْنَ الْبَحْرَيْنِ } العذب والملح { حَاجِزاً } مانعاً لئلاّ يختلطا ولا يبغي أحدهما على صاحبه ،   وقيل : أراد الجزائر { أَإِلَهٌ مَّعَ الله بَلْ أَكْثَرُهُمْ لاَ يَعْلَمُونَ }
