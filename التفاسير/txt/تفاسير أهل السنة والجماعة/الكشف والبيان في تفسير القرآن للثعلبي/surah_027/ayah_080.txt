{ إِنَّكَ لاَ تُسْمِعُ الْمَوْتَى } الكفار كقوله

{ أَوَ مَن كَانَ مَيْتاً فَأَحْيَيْنَاهُ } [ الأنعام : 122 ] وقوله

{ وَمَا يَسْتَوِي الأَحْيَآءُ وَلاَ الأَمْوَاتُ } [ فاطر : 22 ] .

{ وَلاَ تُسْمِعُ الصُّمَّ الدُّعَآءَ إِذَا وَلَّوْاْ مُدْبِرِينَ } نظيره

{ صُمٌّ بُكْمٌ عُمْيٌ } [ البقرة : 18 ،   171 ] .
