{ أَمَّنْ } قال أبو حاتم : فيه إضمار كأنّه قال : آلهتكم خير أم الذي { خَلَقَ السَّمَاوَاتِ وَالأَرْضَ وَأَنزَلَ لَكُمْ مِّنَ السَّمَآءِ مَآءً فَأَنبَتْنَا بِهِ حَدَآئِقَ ذَاتَ بَهْجَةٍ } حُسْن .

{ مَّا كَانَ لَكُمْ أَن تُنبِتُواْ شَجَرَهَا } هو ( مَّا ) النفي ،   يعني ما قدرتم عليه { أَإِلَهٌ مَّعَ اللَّهِ } يعينه على ذلك ،   ثمّ قال : { بَلْ هُمْ قَوْمٌ يَعْدِلُونَ } يشركون
