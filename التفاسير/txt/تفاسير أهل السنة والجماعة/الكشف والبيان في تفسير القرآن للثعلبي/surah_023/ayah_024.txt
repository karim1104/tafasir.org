{ فَقَالَ الْمَلأُ الَّذِينَ كَفَرُواْ مِن قَوْمِهِ مَا هَذَا إِلاَّ بَشَرٌ مِّثْلُكُمْ يُرِيدُ أَن يَتَفَضَّلَ } يتشرف { عَلَيْكُمْ } فيكون أفضل منكم فيصير متبوعاً وأنتم له تبعاً .

{ وَلَوْ شَآءَ اللَّهُ لأَنزَلَ مَلاَئِكَةً مَّا سَمِعْنَا بِهَذَا } الذي يدعونا إليه نوح { فِي آبَآئِنَا الأَوَّلِينَ }
