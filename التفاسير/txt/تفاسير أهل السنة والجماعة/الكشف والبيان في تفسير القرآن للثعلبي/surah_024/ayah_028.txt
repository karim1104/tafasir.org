{ فَإِن لَّمْ تَجِدُواْ فِيهَآ } أي في البيوت { أَحَداً } يأذن لكم في دخولها { فَلاَ تَدْخُلُوهَا حَتَّى يُؤْذَنَ لَكُمْ وَإِن قِيلَ لَكُمْ ارْجِعُواْ فَارْجِعُواْ } ولا تقفوا على أبوابهم ولا تلازموها { هُوَ } أي الرجوع { أَزْكَى } أطهر وأصلح {  لَكُمْ وَاللَّهُ بِمَا تَعْمَلُونَ عَلِيمٌ } .

فلمّا نزلت هذه الآية قال أبو بكر : يا رسول الله أرأيت الخانات والمساكن في طرق الشام ليس فيها ساكن ؟
