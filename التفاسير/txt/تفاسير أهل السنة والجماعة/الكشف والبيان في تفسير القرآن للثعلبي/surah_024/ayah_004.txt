{ وَالَّذِينَ يَرْمُونَ الْمُحْصَنَاتِ } أي يشتمون المسلمات الحرائر العفائف فيقذفونهن بالزنى { ثُمَّ لَمْ يَأْتُواْ } على ما رموهن به { بِأَرْبَعَةِ شُهَدَآءَ } عدول يشهدون عليهنّ أنهم رأوهنّ يفعلن ذلك { فَاجْلِدُوهُمْ } يعني القاذفين اضربوا كلّ واحد منهم { ثَمَانِينَ جَلْدَةً وَلاَ تَقْبَلُواْ لَهُمْ شَهَادَةً أَبَداً وَأُوْلَئِكَ هُمُ الْفَاسِقُونَ } .
