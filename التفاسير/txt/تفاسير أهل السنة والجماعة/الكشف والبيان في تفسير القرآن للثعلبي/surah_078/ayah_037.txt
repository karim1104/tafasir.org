{ رَّبِّ السَّمَاوَاتِ وَالأَرْضِ وَمَا بَيْنَهُمَا الرَّحْمَنِ } قرأ ابن مسعود والأشهب وأبو جعفر وشيبة ونافع وأبو عمرو سلام ويعقوب برفع الباء والنون ،   وقرأ ابن عامر وعيسى وعاصم كلاهما خفضاً واختاره أبو حاتم ،   وقرأ ابن كثير ومحيض ويحيى وحمزة والكسائي { رَّبِّ } خفضاً و { الرَّحْمَنِ } رفعاً ،   واختاره أبو عبيد ،   وقال : هذه أعدلها عندي أن يخفض الأوّل منهما لقربه من قوله : { جَزَآءً مِّن رَّبِّكَ } فتكون نعتاً له ونرفع { الرَّحْمَنِ } لبعده منه .

{ لاَ يَمْلِكُونَ مِنْهُ خِطَاباً } كلاماً وقال الكلبي : شفاعة إلاّ بإذنه .
