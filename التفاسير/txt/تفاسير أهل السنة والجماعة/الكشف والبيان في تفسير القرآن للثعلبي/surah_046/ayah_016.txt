{ أُوْلَئِكَ الَّذِينَ نَتَقَبَّلُ عَنْهُمْ أَحْسَنَ مَا عَمِلُواْ } يعني أعمالهم الصالحة فيثيبهم عليها .

{ وَنَتَجَاوَزُ عَن سَيِّئَاتِهِمْ } فلا يعاقبهم بها .   { فِي أَصْحَابِ الْجَنَّةِ } أي مع أصحاب الجنّة ،   و( في ) بمعنى مع { وَعْدَ الصِّدْقِ الَّذِي كَانُواْ يُوعَدُونَ } وهو قوله :

{ وَعَدَ اللَّهُ الْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا الأَنْهَارُ } [ التوبة : 72 ]
