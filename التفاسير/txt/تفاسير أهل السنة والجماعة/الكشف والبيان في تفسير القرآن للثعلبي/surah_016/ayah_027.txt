{ ثُمَّ يَوْمَ الْقِيَامَةِ يُخْزِيهِمْ } يذلّهم بالعذاب .   { وَيَقُولُ أَيْنَ شُرَكَآئِيَ الَّذِينَ كُنْتُمْ تُشَاقُّونَ فِيهِمْ } تحالفون فيهم لاينقذونكم فيدفعوا عنكم العذاب .

وقرأ العامّة على فتح النون من قوله : { تُشَاقُّونَ } إلاّ نافع فإنه كسرها على الإضافة { قَالَ الَّذِينَ أُوتُواْ الْعِلْمَ } وهم المؤمنون { إِنَّ الْخِزْيَ الْيَوْمَ وَالْسُّوءَ } العذاب
