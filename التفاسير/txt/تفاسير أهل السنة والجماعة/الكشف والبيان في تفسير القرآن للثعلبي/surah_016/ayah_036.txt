{ وَلَقَدْ بَعَثْنَا فِي كُلِّ أُمَّةٍ رَّسُولاً أَنِ اعْبُدُواْ اللَّهَ } يعني بأن اعبدوا الله { وَاجْتَنِبُواْ الْطَّاغُوتَ } وهو كل معبود من دون الله { فَمِنْهُم مَّنْ هَدَى اللَّهُ } في دينه { وَمِنْهُمْ مَّنْ حَقَّتْ } أي وجبت عليه الضلالة حتّى مات على كفره { فَسِيرُواْ فِي الأَرْضِ فَانظُرُواْ كَيْفَ كَانَ عَاقِبَةُ الْمُكَذِّبِينَ } أي خراب منازلهم وديارهم بالعذاب والهلاك
