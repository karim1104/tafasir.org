ثمّ ذكر المؤمنين وتصديقهم بوعود الله تعالى فقال : { وَلَمَّا رَأَى الْمُؤْمِنُونَ الأَحْزَابَ قَالُواْ } تسليماً لأمر الله وتصديقاً لوعده { هَذَا مَا وَعَدَنَا اللَّهُ وَرَسُولُهُ وَصَدَقَ اللَّهُ وَرَسُولُهُ } .

ووعد الله تعالى إيّاهم قوله :

{ أَمْ حَسِبْتُمْ أَن تَدْخُلُواْ الْجَنَّةَ وَلَمَّا يَأْتِكُم مَّثَلُ الَّذِينَ خَلَوْاْ مِن قَبْلِكُم }

إلى قوله :

{ أَلا إِنَّ نَصْرَ اللَّهِ قَرِيبٌ } [ البقرة : 214 ] .

{ وَمَا زَادَهُمْ } ذلك { إِلاَّ إِيمَاناً وَتَسْلِيماً } .
