قوله : { أَشِحَّةً عَلَيْكُمْ } أي بخلاء بالخير والنفقة في سبيل الله وعند قَسم الغنيمة ،   وهي نصب على الحال والقطع من قوله : { وَلاَ يَأْتُونَ الْبَأْسَ إِلاَّ قَلِيلاً } وصفهم الله بالجبن والبخل .

{ فَإِذَا جَآءَ الْخَوْفُ رَأَيْتَهُمْ يَنظُرُونَ إِلَيْكَ تَدُورُ أَعْيُنُهُمْ } في رؤوسهم من الخوف والجبن { كَالَّذِي } أي كدوران عين الذي { يُغْشَى عَلَيْهِ مِنَ الْمَوْتِ فَإِذَا ذَهَبَ الْخَوْفُ سَلَقُوكُمْ } عصوكم ورموكم { بِأَلْسِنَةٍ حِدَادٍ } ذربة جمع حديد ،   ويقال للخطيب الفصيح اللسان الذرب اللسان ،   مسلق ومصلق وسلاق وصلاق وأصل السلق الضرب .

وقال قتادة : يعني بسطوا ألسنتهم فيكم وقت قسم الغنيمة ،   يقولون : أعطونا أعطونا فإنّا قد شهدنا معكم القتال فلستم بأحقّ بالغنيمة منّا ،   فأمّا عند الغنيمة فأشحّ قوم وأسوأ مقاسمة ،   وأمّا عند البأس فأجبن قوم وأخذلهم للحقّ .

{ أَشِحَّةً عَلَى الْخَيْرِ } يعني الغنيمة { أوْلَئِكَ لَمْ يُؤْمِنُواْ فَأَحْبَطَ اللَّهُ أَعْمَالَهُمْ وَكَانَ ذَلِكَ عَلَى اللَّهِ يَسِيراً } .
