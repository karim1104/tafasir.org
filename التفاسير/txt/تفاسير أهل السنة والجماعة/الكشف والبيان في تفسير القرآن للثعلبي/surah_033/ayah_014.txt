{ وَلَوْ دُخِلَتْ عَلَيْهِمْ } يقول لو دخل عليهم هؤلاء الجيوش الذين يريدون قتالهم المدينة { مِّنْ أَقْطَارِهَا } جوانبها ونواحيها ،   واحدها قطر وفيه لغة أخرى قطرٌ وأقطار .

{ ثُمَّ سُئِلُواْ الْفِتْنَةَ } الشرك { لآتَوْهَا } قراءة أهل الحجاز بقصر الألف ،   أي لجاؤوها وفعلوها ورجعوا عن الإسلام وكفروا ،   وقرأ الآخرون بالمدّ ،   أي لأعطوها .   وقالوا : إذا كان سؤال كان إعطاء { وَمَا تَلَبَّثُواْ بِهَآ } وما احتبسوا عن الفتنة { إِلاَّ يَسِيراً } ولأسرعوا الإجابة إليها طيبة بها أنفسهم ،   هذا قول أكثر المفسِّرين ،   وقال الحسن والفراء : وما أقاموا بالمدينة بعد إعطاء الكفر إلاّ قليلاً حتى يهلكوا
