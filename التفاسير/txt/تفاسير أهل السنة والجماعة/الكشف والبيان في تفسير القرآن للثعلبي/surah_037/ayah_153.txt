{ أَصْطَفَى } .   قرأ العامة بقطع الألف ؛ لأنه ألف استفهام دخلت على ألف الوصل فحذفت ألف الوصل وبقيت ألف الاستفهام مفتوحة على حالها مثل

{ أَسْتَكْبَرْتَ } [ ص : 75 ] و

{ أَسْتَغْفَرْتَ } [ المنافقون : 6 ] و

{ أَذْهَبْتُمْ } [ الأحقاف : 20 ] ونحوها .

وقرأ أبو جعفر ونافع في بعض الروايات ( الكاذبون اصطفى ) موصولة على الخبر والحكاية عن قول المشركين ،   مجازه : { لَيَقُولُونَ * وَلَدَ اللَّهُ } ويقولون { أَصْطَفَى } { الْبَنَاتِ عَلَى الْبَنِينَ }
