{ أَلَمْ تَرَ أَنَّ اللَّهَ أَنزَلَ مِنَ السَّمَآءِ } أي من السحاب { مَآءً فَسَلَكَهُ } فادخله { يَنَابِيعَ } عيوناً { فِي الأَرْضِ } قال : [ الشعبي والضحاك : كل ماء في الأرض فمن السماء نزل إنما ينزل ] من السماء إلى الصخرة ثم يقسم منها العيون والركايا { ثُمَّ يُخْرِجُ بِهِ زَرْعاً مُّخْتَلِفاً أَلْوَانُهُ ثُمَّ يَهِيجُ } ييبس { فَتَرَاهُ } بعد خضرته { مُصْفَرّاً ثُمَّ يَجْعَلُهُ حُطَاماً } أي فتاتا منكسراً متفتتاً { إِنَّ فِي ذَلِكَ لَذِكْرَى لأُوْلِي الأَلْبَابِ * أَفَمَن شَرَحَ اللَّهُ } فتح الله { صَدْرَهُ لِلإِسْلاَمِ } للإيمان { فَهُوَ عَلَى نُورٍ } على دلالة { مِّن رَّبِّهِ } قال قتادة : النور كتاب الله منه تأخذ وإليه ننتهي ومجاز الآية
