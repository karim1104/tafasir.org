{ قَالَ } ذو القرنين لمّا فرغ من بنائه يعني هذا السّد : { هَذَا } السّد { رَحْمَةٌ } : نعمة { مِّن رَّبِّي }  ؛ فلذلك لم يقل : هذه .   { فَإِذَا جَآءَ وَعْدُ رَبِّي جَعَلَهُ دَكَّآءَ } ملتزقة مستوية بالأرض من قولهم : ناقة دكّاء أي مستوية الظهر لا سنام لها .   ومن قرأ : ( دكّاً ) بلا مدّ فمعناه : مدكوك يومئذ ،   { وَكَانَ وَعْدُ رَبِّي حَقّاً } .
