{ وَيَوْمَ نُسَيِّرُ الْجِبَالَ } : نزيلها عن أماكنها .   وقرأ ابن كثير وأبو عمرو : ( تُسيَّر ) بالتاء وفتح الياء ( الجبال ) رفعاً على المجهول ،   { وَتَرَى الأَرْضَ بَارِزَةً } ظاهرة كرأي العين ليس عليها شجر ولا جبل ولا ثمر ولا شيء يسترها .   وقال عطاء : ترى باطن الأرض ظاهراً قد برز الذين كانوا في بطنها فصاروا على ظهرها ،   { وَحَشَرْنَاهُمْ } : جمعناهم إلى الموقف للحساب ،   { فَلَمْ نُغَادِرْ } : نترك ونخلف { مِنْهُمْ أَحَداً }
