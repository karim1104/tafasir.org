{ وَمَنْ أَظْلَمُ مِمَّن ذُكِّرَ بِآيَتِ رَبِّهِ فَأَعْرَضَ عَنْهَا } : لم يؤمن بها { وَنَسِيَ مَا قَدَّمَتْ يَدَاهُ } ،   أي عملت يداه من الذنوب { إِنَّا جَعَلْنَا عَلَى قُلُوبِهِمْ أَكِنَّةً أَن يَفْقَهُوهُ } ،   يعني القرآن { وَفِي آذَانِهِمْ وَقْراً } : ثقلاً وصمماً { وَإِن تَدْعُهُمْ } يا محمد { إِلَى الْهُدَى } يعني إلى الدين { فَلَنْ يَهْتَدُواْ إِذاً أَبَداً } : لن يرشدوا ولن يقبلوه .
