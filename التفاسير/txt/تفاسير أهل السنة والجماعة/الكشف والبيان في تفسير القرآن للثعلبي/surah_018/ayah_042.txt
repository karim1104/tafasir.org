{ وَأُحِيطَ بِثَمَرِهِ } أي أحاط الهلاك بثمر جنّتيه ،   وهي جميع صنوف الثمار .   وقال مجاهد : هي ذهب وفضة ؛ وذلك أن الله أرسل عليها ناراً فأهلكها وغار ماؤها ،   { فَأَصْبَحَ } صاحبها الكافر { يُقَلِّبُ كَفَّيْهِ } : يصفق يده على الأُخرى ،   وتقليب كفيه ظهراً لبطن ؛ تأسفاً وتلهّفاً { عَلَى مَآ أَنْفَقَ فِيهَا } يعني : عليها كقوله :

{ وَلأُصَلِّبَنَّكُمْ فِي جُذُوعِ النَّخْلِ } [ طه : 71 ] أي عليها { وَهِيَ خَاوِيَةٌ عَلَى عُرُوشِهَا } ساقطة على سقوفها ،   خالية من غرسها وبنائها { وَيَقُولُ يلَيْتَنِي لَمْ أُشْرِكْ بِرَبِّي أَحَداً } .
