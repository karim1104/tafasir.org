{ وَقَالَ الَّذِينَ اسْتُضْعِفُواْ لِلَّذِينَ اسْتَكْبَرُواْ بَلْ مَكْرُ الْلَّيْلِ وَالنَّهَارِ } أي مكركم بنا .   فهما كما يُقال : عزم الأمر وفلان نهاره صائم وليله قائم .

قال الشاعر :

ونمت وما ليل المطي بنائم

وقيل : مكر الليل والنهار بهم طول السلامة فيهما كقوله : { فَطَالَ عَلَيْهِمُ الأَمَدُ } ،   ونحوه .   { إِذْ تَأْمُرُونَنَآ أَن نَّكْفُرَ بِاللَّهِ وَنَجْعَلَ لَهُ أَندَاداً وَأَسَرُّواْ } : أظهروا { النَّدَامَةَ } ،   وهو من الأضداد ؛ يكون بمعنى الإخفاء ،   والإبداء { لَمَّا رَأَوُاْ الَعَذَابَ وَجَعَلْنَا الأَغْلاَلَ } : الجوامع من النار { فِي أَعْنَاقِ الَّذِينَ كَفَرُوا } : الأتباع والمتبوعين ،   { هَلْ يُجْزَوْنَ إِلاَّ مَا كَانُواْ يَعْمَلُونَ } في الدنيا ؟
