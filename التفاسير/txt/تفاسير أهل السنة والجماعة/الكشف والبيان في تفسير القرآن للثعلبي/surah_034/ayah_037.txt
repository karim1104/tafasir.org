{ وَمَآ أَمْوَالُكُمْ وَلاَ أَوْلاَدُكُمْ بِالَّتِي تُقَرِّبُكُمْ عِندَنَا زُلْفَى إِلاَّ مَنْ آمَنَ } : لكن من آمن { وَعَمِلَ صَالِحاً فَأُوْلَئِكَ لَهُمْ جَزَآءُ الضِّعْفِ بِمَا عَمِلُواْ } من الثواب بالواحد عشرة ،   و { من } يحتمل وجهين : أحدهما : أن يكون محله نصباً بوقوع { تقرب } عليه ،   والآخر : رفع تقديره : وما هو إلاّ من آمن .

{ وَهُمْ فِي الْغُرُفَاتِ } الدرجات { آمِنُونَ } .

وقراءة العامة : { جَزَآءُ الضِّعْفِ } بالإضافة ،   وقرأ يعقوب : ( جزاءً ) منصوباً منّوناً .   الضعف رفع مجازه : فأُولئك لهم الضعف جزاء على التقديم والتأخير ،   وقراءة العامة : الغرفات بالجمع ،   واختاره أبو عبيد قال : لقوله : { لَنُبَوِّئَنَّهُمْ مِّنَ الْجَنَّةِ غُرَفَاً } ،   وقرأ الأعمش وحمزة : ( في الغرفة ) على الواحدة .
