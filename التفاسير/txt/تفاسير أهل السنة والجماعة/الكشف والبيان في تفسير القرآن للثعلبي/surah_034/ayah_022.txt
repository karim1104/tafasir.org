{ قُلِ } يا محمد لهؤلاء المشركين الذين أنت بين ظهرانيهم : { ادْعُواْ الَّذِينَ زَعَمْتُمْ } أنهم آلهة { مِّن دُونِ اللَّهِ } ،   ثم وصفها فقال : { لاَ يَمْلِكُونَ مِثْقَالَ ذَرَّةٍ فِي السَّمَاوَاتِ وَلاَ فِي الأَرْضِ } من خير وشر وضرّ ونفع ،   فكيف يكون إلهاً من كان كذلك ؟ { وَمَا لَهُمْ فِيهِمَا } أي في السماوات والأرض { مِن شِرْكٍ } شركة { وَمَا لَهُ } أي لله { مِنْهُمْ مِّن ظَهِيرٍ } : عون .
