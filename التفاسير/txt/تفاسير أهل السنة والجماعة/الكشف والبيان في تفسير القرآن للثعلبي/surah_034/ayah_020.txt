قوله : { وَلَقَدْ صَدَّقَ عَلَيْهِمْ } ،   قرأ أهل الكوفة : بتشديد الدال وهي قراءة ابن عباس واختيار أبي عبيد ،   أي ظن فيهم ظناً حيث قال :

{ فَبِعِزَّتِكَ لأُغْوِيَنَّهُمْ أَجْمَعِينَ } [ ص : 82 ] ،   وقال :

{ وَلاَ تَجِدُ أَكْثَرَهُمْ شَاكِرِينَ } [ الأعراف : 17 ] ،   فصدّق ظنه وحقّقه لفعله ذلك بهم واتّباعهم إياه ،   وقرأ الآخرون : { صَدَقَ } بالتخفيف أي صدق عليهم في ظنه بهم .

{ عَلَيْهِمْ } أي على أهل سبأ ،   وقال مجاهد : على الناس كلّهم إلاّ من أطاع الله { فَاتَّبَعُوهُ إِلاَّ فَرِيقاً مِّنَ الْمُؤْمِنِينَ }
