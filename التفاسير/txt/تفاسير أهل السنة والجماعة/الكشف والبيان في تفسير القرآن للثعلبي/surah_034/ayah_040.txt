{ وَيَوْمَ يَحْشُرُهُمْ جَمِيعاً } يعني هؤلاء الكفّار { ثُمَّ يَقُولُ لِلْمَلاَئِكَةِ أَهَؤُلاَءِ إِيَّاكُمْ كَانُواْ يَعْبُدُونَ } في الدُّنيا ؟ فتتبرأ منهم الملائكة فتقول : { سُبْحَانَكَ } : تنزيهاً لك .   { أَنتَ وَلِيُّنَا } : ربنا { مِن دُونِهِمْ بَلْ كَانُواْ يَعْبُدُونَ الْجِنَّ } أي يطيعون إبليس وذريته وأعوانه في معصيتك .   { أَكْثَرُهُم بِهِم مُّؤْمِنُونَ } : مصدقون .

قال قتادة : هو استفهام تقديره كقوله لعيسى :{ أَأَنتَ قُلتَ لِلنَّاسِ اتَّخِذُونِي .   .   .   } [ المائدة : 116 ] .
