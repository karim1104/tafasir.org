{ وَيَرَى } يعني : وليرى { الَّذِينَ أُوتُواْ الْعِلْمَ } يعني : مؤمني أهل الكتاب : عبد الله بن سلام وأصحابه ،   وقال قتادة : هم أصحاب محمد ( عليه السلام ) .

{ الَّذِي أُنزِلَ إِلَيْكَ مِن رَّبِّكَ } يعني : القرآن { هُوَ الْحَقَّ وَيَهْدِي } يعني : القرآن { إِلَى صِرَاطِ الْعَزِيزِ الْحَمِيدِ } وهو الإسلام .
