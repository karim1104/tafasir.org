قال : { طَاعَةٌ } مجازه ،   ويقول هؤلاء المنافقون قبل نزول الآية المحكمة ( طاعةٌ ) رفع على الحكاية أي أمرنا طاعة أو منّا طاعة .

{ وَقَوْلٌ مَّعْرُوفٌ } حسن وقيل : هو متصل بالكلام الأوّل ،   ( واللام ) في قوله ( لهم ) بمعنى ( الباء ) مجازه فأولى بهم طاعة لله ورسوله { وَقَوْلٌ مَّعْرُوفٌ } بالإجابة والطاعة .

{ فَإِذَا عَزَمَ الأَمْرُ } أي جدّ الأمر وعُزم عليه وأُمروا بالقتال .   { فَلَوْ صَدَقُواْ اللَّهَ } في إظهار الإيمان والطاعة { لَكَانَ خَيْراً لَّهُمْ }
