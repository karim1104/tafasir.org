{ وَلَمَّا دَخَلُواْ مِنْ حَيْثُ أَمَرَهُمْ أَبُوهُم } وكان لمصر أربعة أبواب فدخلوها من أبوابها كلّها ،   { مَّا كَانَ يُغْنِي عَنْهُمْ مِّنَ اللَّهِ مِن شَيْءٍ } صدّق الله تعالى يعقوب فيما قال { إِلاَّ حَاجَةً } حزازة وهمّة في نفس يعقوب { قَضَاهَا } أشفق عليهم إشفاق الآباء على أبنائهم { وَإِنَّهُ } يعقوب { لَذُو عِلْمٍ لِّمَا } : أي مما { عَلَّمْنَاهُ } يعني لتعليمنا إيّاه ،   قاله قتادة ،   وروى سفيان عن ( ابن ) أبي عروة قال : إنّه العامل بما علم ،   قال سفيان : من لا يعمل لا يكون عالماً ،   وقيل : إنّه لذو حظّ لِما علّمناه .

{ وَلَكِنَّ أَكْثَرَ النَّاسِ لاَ يَعْلَمُونَ } ما يعلم يعقوب ،   أي لا يعرفون مرتبته في العلم .
