فأقبل عليهما وعلى أهل السجن وكان بين أيديهم أصناماً يعبودنها فقال إلزاماً للحُجّة{ يصَاحِبَيِ السِّجْنِ } جعلهما صاحبي السجن لكونهما فيه كقوله تعالى لسكّان الجنّة

{ أَصْحَابُ الْجَنَّةِ } [ الأعراف : 44 ] ولسكّان النار :

{ أَصْحَابَ النَّارِ } [ الأعراف : 44 ] .

{ ءَأَرْبَابٌ مُّتَّفَرِّقُونَ خَيْرٌ } آلهة شتى لا تنفع ولا تضرّ { خَيْرٌ أَمِ اللَّهُ الْوَاحِدُ } الذي لا ثاني له { الْقَهَّارُ } قد قهر كلّ شيء ،   نظيرها ،   قوله :

{ ءَآللَّهُ خَيْرٌ أَمَّا يُشْرِكُونَ } [ النمل : 59 ]
