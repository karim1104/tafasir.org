{ قَالَ بَلْ سَوَّلَتْ } في الآية اختصار معناها ،   فرجعوا إلى أبيهم وقالوا له ذلك ،   فقال : بل سوّلت أي زيّنت { لَكُمْ أَنفُسُكُمْ أَمْراً } أردتموه { فَصَبْرٌ جَمِيلٌ عَسَى اللَّهُ أَن يَأْتِيَنِي بِهِمْ جَمِيعاً } يوسف وبنيامين وأخيهما المقيم بمصر { إِنَّهُ هُوَ الْعَلِيمُ } بحزني ووجدي على فقدهم { الْحَكِيمُ } في تدبير خلقه .
