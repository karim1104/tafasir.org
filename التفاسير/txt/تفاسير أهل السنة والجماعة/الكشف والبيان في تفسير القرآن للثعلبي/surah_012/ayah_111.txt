{ لَقَدْ كَانَ فِي قَصَصِهِمْ } أي في خبر يوسف وأخوته { عِبْرَةٌ } عِظة { لأُوْلِي الأَلْبَابِ مَا كَانَ } يعني القرآن { حَدِيثاً يُفْتَرَى } يُختلق { وَلَكِن تَصْدِيقَ } يعني ولكن كان تصديق { الَّذِي بَيْنَ يَدَيْهِ } أي ما قبله من الكتب { وَتَفْصِيلَ كُلِّ شَيْءٍ } ممّا يحتاج إليه العباد { وَهُدًى وَرَحْمَةً لِّقَوْمٍ يُؤْمِنُونَ } .
