{ وَيُعَلِّمُهُ } : قرأ أهل المدينة ومجاهد وحميد والحسن وعاصم : بالياء ،   واختاره أبو عبيد وأبو حاتم لقوله تعالى { كَذَلِكَ اللَّهُ يَخْلُقُ مَا يَشَآءُ } : قد جرى ذكره عز وجّل .

وقال المبرد : ردّوه على قوله { إنّ الله يبشرك ويعلّمهُ } وقرأ الباقون بالنون على التعظيم ،   واحتجّ أبو عمرو في ذلك لقوله { ذلِكَ مِنْ أَنَبَآءِ الْغَيْبِ نُوحِيهِ إِلَيكَ } .

{ الْكِتَابَ } : أي الكتابة والخط والعلم .

{ وَالْحِكْمَةَ وَالتَّوْرَاةَ وَالإِنْجِيلَ }
