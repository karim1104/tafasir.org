{ يَوْمَ تَجِدُ كُلُّ نَفْسٍ } : نصب يوماً ،   نزع حرف الصفة أي في يوم .   وقيل : نصب بإضمار فعل ،   أي : اذكروا واتقوا { يَوْمَ تَجِدُ كُلُّ نَفْسٍ مَّا عَمِلَتْ مِنْ خَيْرٍ مُّحْضَراً } : موفراً لم يبخس منه شيء .   قراءة العامة بنصب الضاد على المفعول قد صدَّهم قوله :

{ وَوَجَدُواْ مَا عَمِلُواْ حَاضِراً } [ الكهف : 49 ] : وقرأ عبيد عن عُمير محضراً بكسر الضاد يريد أن عمله يحضره الجنَّة يسرع به من الحضور أو الحضر .

{ وَمَا عَمِلَتْ مِن سُوءٍ } : جعل بعضهم خبراً في موضع النصب ،   وأعمل فيها الوجود وجعل عملت صلة لها ،   أي : ويجد عملها ،   وجَعله بعضه خبراً مستأنفاً ،   وحينئذ يجوز في { تَوَدُّ } الرفع ،   والجزم ،   دليل هذا التأويل : قراءة عبد اللَّه { وَمَا عَمِلَتْ مِن سُوءٍ تَوَدُّ } .   { لَوْ أَنَّ بَيْنَهَا } : بين النفس { وَبَيْنَهُ } : يعني بين السوء { أَمَدَاً بَعِيداً } : والأمد : الأجل والغاية التَّي ينتهي إليها .   قال اللَّه :

{ أَمْ يَجْعَلُ لَهُ رَبِّي أَمَداً } [ الجن : 25 ] ،   وقال :

{ فَطَالَ عَلَيْهِمُ الأَمَدُ } [ الحديد : 16 ] .

قال النابغة :

ألا لمثلك أو من أنت سابقه *** بسبق الجواد إذا استويا على الأمد

قال السدي : أمداً بعيداً أي : مكان بعيد .

مقاتل : كما بين المشرق والمغرب .

قال الحسن : ليس أحدهم أن لا يلقى عمله أبداً ولا يوَدَّ لو أن يعلمه .

{ وَيُحَذِّرُكُمُ اللَّهُ نَفْسَهُ وَاللَّهُ رَؤُوفٌ بِالْعِبَادِ } : أي بالمؤمنين منهم .
