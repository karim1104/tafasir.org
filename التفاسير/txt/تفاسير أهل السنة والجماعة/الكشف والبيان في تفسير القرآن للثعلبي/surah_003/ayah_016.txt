{ الَّذِينَ يَقُولُونَ } : إن شئت جعلته محل ( الذين ) على الجر رداً على قوله { لِلَّذِينَ اتَّقَوْا } .   وإن شئت رفعته على الابتداء كقوله

{ إِنَّ اللَّهَ اشْتَرَى مِنَ الْمُؤْمِنِينَ أَنفُسَهُمْ وَأَمْوَالَهُمْ } [ التوبة : 111 ] .   ثم قال في صفتهم مبتدئاً

{ التَّائِبُونَ الْعَابِدُونَ } [ التوبة : 112 ] .

{ رَبَّنَآ إِنَّنَآ آمَنَّا } صدَّقنا .

{ فَاغْفِرْ لَنَا ذُنُوبَنَا } : استرها علينا وتجاوزها عنا .

{ وَقِنَا عَذَابَ النَّارِ }
