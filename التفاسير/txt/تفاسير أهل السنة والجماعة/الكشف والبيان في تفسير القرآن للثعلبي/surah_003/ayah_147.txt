{ وَمَا كَانَ قَوْلَهُمْ } .

قرأ الحسن وابن أبي إسحاق : ( قولهم ) بالرفع على اسم كان وخبره في قوله : إن قالوا .

وقرأ الباقون : بالنصب على خبر كان والاسم في أن ،   قالوا تقديره : وما كان قولهم إلاّ قولهم كقوله :

{ وَمَا كَانَ جَوَابَ قَوْمِهِ } [ الأعراف : 82 ] و{ مَّا كَانَ حُجَّتَهُمْ } [ الجاثية : 25 ] ونحوهما ،   ومعنى الآية : وما كان قولهم عند قتل نبيّهم { إِلاَّ أَن قَالُواْ ربَّنَا اغْفِرْ لَنَا ذُنُوبَنَا وَإِسْرَافَنَا فِي أَمْرِنَا } يعني خطايانا الكبار ،   وأصله مجاوزة الحد { وَثَبِّتْ أَقْدَامَنَا } كيلا تزول { وانْصُرْنَا عَلَى الْقَوْمِ الْكَافِرِينَ } فهلاّ فعلتم وقلتم مثل ذلك يا أصحاب محمد
