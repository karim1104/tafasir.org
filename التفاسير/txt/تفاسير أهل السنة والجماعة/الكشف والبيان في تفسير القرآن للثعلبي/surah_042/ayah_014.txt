{ وَمَا تَفَرَّقُواْ } يعني أهل الأديان المختلفة ،   وقال ابن عباس : يعني أهل الكتاب .   دليله ونظيره في سورة المُنفكّين

{ إِلاَّ مِن بَعْدِ مَا جَآءَتْهُمُ الْبَيِّنَةُ } [ البينة : 4 ] .

{ إِلاَّ مِن بَعْدِ مَا جَآءَهُمُ الْعِلْمُ } من قبل بعث محمد وصفته .   { بَغْياً بَيْنَهُمْ وَلَوْلاَ كَلِمَةٌ سَبَقَتْ مِن رَّبِّكَ } تأخير العذاب .

{ إِلَى أَجَلٍ مُّسَمًّى } وهو يوم القيامة .   { لَّقُضِيَ بِيْنَهُمْ } بالعذاب .   { وَإِنَّ الَّذِينَ أُورِثُواْ الْكِتَابَ مِن بَعْدِهِمْ } يعني من بعد الأمم الخالية ،   وقال مجاهد : معناه من قبلهم أي من قبل مشركي مكّة وهم اليهود والنصارى .   { لَفِي شَكٍّ مِّنْهُ مُرِيبٍ }
