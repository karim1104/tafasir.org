{ فَمَالِ الَّذِينَ كَفَرُواْ } فما بالهم كقوله سبحانه :

{ فَمَا لَكُمْ فِي الْمُنَافِقِينَ فِئَتَيْنِ } [ النساء : 88 ] وقوله سبحانه :

{ فَمَا لَهُمْ عَنِ التَّذْكِرَةِ مُعْرِضِينَ } [ المدثر : 49 ] .

{ قِبَلَكَ مُهْطِعِينَ } مقبلين مسرعين عليك مادّي أعناقهم مديمي النظر إليك متطلّعين نحوك .   وقد مرّ تفسير الإهطاع وهو نصب على الحال
