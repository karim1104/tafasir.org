{ وَجَعَلَهَا } يعني هذه الكلمة والمقالة { كَلِمَةً بَاقِيَةً فِي عَقِبِهِ } قال مجاهد وقتادة : يعني لا إله إلاَّ الله ،   وقال القرظي : يعني وجعل وصية إبراهيم الّتي أوصى بها بنيه باقية في نسله وذريته وهي الّتي ذكرها الله تعالى في سورة البقرة :

{ وَوَصَّى بِهَآ إِبْرَاهِيمُ بَنِيهِ } [ البقرة : 132 ] ،   وقال ابن زيد : يعني قوله :

{ أَسْلَمْتُ لِرَبِّ الْعَالَمِينَ } [ البقرة : 131 ] وقرأ

{ هُوَ سَمَّاكُمُ الْمُسْلِمِينَ } [ الحج : 78 ] .

{ لَعَلَّهُمْ يَرْجِعُونَ } من كفرهم إلى الطاعة ويتوبون
