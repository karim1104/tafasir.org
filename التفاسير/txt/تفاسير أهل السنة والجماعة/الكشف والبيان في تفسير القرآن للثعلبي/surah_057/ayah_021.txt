{ سَابِقُواْ } : سارعوا { إِلَى مَغْفِرَةٍ مِّن رَّبِّكُمْ وَجَنَّةٍ عَرْضُهَا } : سعتها { كَعَرْضِ السَّمَآءِ وَالأَرْضِ } لوصل بعضها ببعض .

وقال ابن كيسان : عنى به جنّة واحدة من الجنان .

{ أُعِدَّتْ لِلَّذِينَ آمَنُواْ بِاللَّهِ وَرُسُلِهِ ذَلِكَ فَضْلُ اللَّهِ يُؤْتِيهِ مَن يَشَآءُ وَاللَّهُ ذُو الْفَضْلِ الْعَظِيمِ }
