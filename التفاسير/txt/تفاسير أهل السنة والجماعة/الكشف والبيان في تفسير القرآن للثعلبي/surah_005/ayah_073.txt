{ لَّقَدْ كَفَرَ الَّذِينَ قَالُواْ إِنَّ اللَّهَ ثَالِثُ ثَلاَثَةٍ } هي النسطورية وذلك إنهم قالوا أباً وإبناً وروحاً قدسياً { وَمَا مِنْ إِلَهٍ إِلاَّ إِلَهٌ وَاحِدٌ } إلى قوله { لَيَمَسَّنَّ } لتصيبن { الَّذِينَ كَفَرُواْ مِنْهُمْ } خص الكفر لعلمه أن بعضهم [ لهم ] { عَذَابٌ أَلِيمٌ * أَفَلاَ يَتُوبُونَ } الآية .
