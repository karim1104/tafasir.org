{ قَالُواْ } إنما سألنا لأنا { نُرِيدُ أَن نَّأْكُلَ مِنْهَا } نستيقن قدرته ،   { وَتَطْمَئِنَّ } تسكن { قُلُوبُنَا وَنَعْلَمَ أَن قَدْ صَدَقْتَنَا } بأنك رسول اللّه .

{ وَنَكُونَ عَلَيْهَا مِنَ الشَّاهِدِينَ } للّه بالوحدانية والقدرة ولك بالنبوة والرسالة ،   وقيل : ونكون عليها من الشاهدين لك عند بني إسرائيل ،   إذا رجعنا إليهم .
