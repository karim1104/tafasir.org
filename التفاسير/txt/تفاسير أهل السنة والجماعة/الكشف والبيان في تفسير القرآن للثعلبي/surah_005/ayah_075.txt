{ مَّا الْمَسِيحُ ابْنُ مَرْيَمَ } إلى قوله { وَأُمُّهُ صِدِّيقَةٌ } الآية ،   تصدق ،   وقال مقاتل : إنما سميت صديقة لأنها لما أتاها جبرئيل ،   وهي في منجم وقال لها : إنما أنا رسول ربك صدّقته { كَانَا يَأْكُلاَنِ الطَّعَامَ } في هذا المعنى هذا عبارة عن الحدث ومن أكل وأحدث لا يستحق أن يكون إلهاً { انْظُرْ } يا محمد { كَيْفَ نُبَيِّنُ } إلى قوله { أَنَّى يُؤْفَكُونَ } [ يرتدون ] عن الحق { قُلْ أَتَعْبُدُونَ } الآية
