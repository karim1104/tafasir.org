{ يَوْمَ } أي إذكروا واحذروا يوم { يَجْمَعُ اللَّهُ الرُّسُلَ } وهو يوم القيامة ،    { فَيَقُولُ } لهم { مَاذَآ أُجِبْتُمْ } أي ما الذي أجابتكم أمتكم وما الذي ردّ عليكم قومكم حين دعوتموهم إلى توحيدي وطاعتي ،   { قَالُواْ } أي فيقولون { لاَ عِلْمَ لَنَآ } قال ابن عباس : لا علم لنا إلاّ علم أنت أعلم به منا .

وقال ابن جريح : معنى قوله { مَاذَآ أُجِبْتُمْ } أي ما حملوا ويصدقوا بعدكم فيقولوا : لا علم لنا .

الحسن ومجاهد ،   السدي ممن يقول ذلك اليوم يفزعون ويذهلون عن الجواب ،   ثم يحتسبون بعدما تثوب إليهم عقولهم بالشهادة على أمتهم .
