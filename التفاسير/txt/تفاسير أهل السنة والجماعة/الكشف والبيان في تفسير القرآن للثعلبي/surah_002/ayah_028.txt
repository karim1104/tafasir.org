ثمّ قال : لمشركي مكة على التعجّب : { كَيْفَ تَكْفُرُونَ بِاللَّهِ وَكُنْتُمْ }

واو الحال { أَمْوَاتاً } نطفاً في أصلاب آبائكم { فَأَحْيَاكُمْ } في الأرحام في الدنيا { ثُمَّ يُمِيتُكُمْ } عند انقضاء آجالكم .   { ثُمَّ يُحْيِيكُمْ } للبعث .   { ثُمَّ إِلَيْهِ تُرْجَعُونَ } تأتون في الآخرة فيجزيكم بأعمالكم .

وقرأ يعقوب : ترجعون ،   وبيانه بفتح الأول وكسر الجيم جعل الفعل لهم .
