{ وَقَالَ الَّذِينَ لاَ يَعْلَمُونَ } يعني اليهود قاله ابن عبّاس .

مجاهد : هم النّصارى .   قتادة : هم مشركو العرب .   { لَوْلاَ } هلاّ { يُكَلِّمُنَا اللَّهُ } عياناً بأنك رسوله .   { أَوْ تَأْتِينَآ آيَةٌ } دلالة وعلامة على صدقك .

قال الله تعالى : { كَذَلِكَ قَالَ الَّذِينَ مِن قَبْلِهِمْ } أي كفّار الأمم الخالية { مِّثْلَ قَوْلِهِمْ تَشَابَهَتْ قُلُوبُهُمْ } أشبه بعضها بعضاً في الكفر والفرقة والقسوة .   { قَدْ بَيَّنَّا الآيَاتِ لِقَوْمٍ يُوقِنُونَ }
