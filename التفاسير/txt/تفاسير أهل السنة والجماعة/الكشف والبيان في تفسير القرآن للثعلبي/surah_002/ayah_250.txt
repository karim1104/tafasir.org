{ وَلَمَّا بَرَزُواْ } يعني طالوت وجنوده المؤمنين { لِجَالُوتَ وَجُنُودِهِ } المشركين ومعنى { بَرَزُواْ } صاروا بالبراز من الأرض وهو ما ظهر واستوى { قَالُواْ } وهم أهل البصيرة والطاعة { رَبَّنَآ أَفْرِغْ } أنزل وأصبب { عَلَيْنَا صَبْراً } كما يفرغ الدلو { وَثَبِّتْ أَقْدَامَنَا } وقوّ قلوبنا { وَانْصُرْنَا عَلَى الْقَوْمِ الْكَافِرِينَ } وفي الآية إضمار تقديرها : فأنزل الله عليهم صبراً ونصراً
