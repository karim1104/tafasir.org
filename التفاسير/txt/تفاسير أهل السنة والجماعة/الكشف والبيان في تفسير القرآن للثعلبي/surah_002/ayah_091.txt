{ وَإِذَا قِيلَ لَهُمْ آمِنُواْ بِمَا أَنْزَلَ اللَّهُ } يعني القرآن .   { قَالُواْ نُؤْمِنُ بِمَآ أُنْزِلَ عَلَيْنَا } يعني التوراة .   { وَيَكْفُرونَ بِمَا وَرَآءَهُ } أي بما سواه وبعده .   { وَهُوَ الْحَقُّ } يعني القرآن .   { مُصَدِّقاً } نصب على الحال .   { لِّمَا مَعَهُمْ } قل لهم يا محمّد : { قُلْ فَلِمَ تَقْتُلُونَ أَنْبِيَآءَ اللَّهِ مِن قَبْلُ } ولمَ أصله ولما فحذفت الألف فرقاً بين الخبر والأستفهام كقولهم : فيم وبم ولم وممّ وعلام وحقام ،   وهذا جواب لقولهم : نؤمن بما أنُزل علينا .

فقال الله عزّ وجلّ { فَلِمَ تَقْتُلُونَ أَنْبِيَآءَ اللَّهِ مِن قَبْلُ } .   { إِن كُنْتُمْ مُّؤْمِنِينَ } بالتوراة وقد خنتم فيها من قتل الأنبياء
