{ أَمْ تَقُولُونَ } قرأ ابن عامر وحمزة والكسائي وخلف وحفص : بالتاء واختاره أبو عبيد ،   وقرأ الباقون بالياء ،   واختاره أبو حاتم .   فمن قرأ بالتاء فاللمخاطبة التي قبلها { قُلْ أَتُحَآجُّونَنَا فِي اللَّهِ } والتي بعدها { قُلْ أَأَنْتُمْ أَعْلَمُ أَمِ اللَّهُ } ومن قرأ بالياء فهو أخبار عن اليهود والنّصارى .   { إِنَّ إِبْرَاهِيمَ وَإِسْمَاعِيلَ وَإِسْحَاقَ وَيَعْقُوبَ وَالأَسْبَاطَ كَانُواْ هُوداً أَوْ نَصَارَى } قال الله : { قُلْ } يا محمّد .   { أَأَنْتُمْ أَعْلَمُ } بدينهم .   { أَمِ اللَّهُ } وقد أخبرني الله إنّه لم يكن يهوديّاً ولا نصرانيّاً ولكن كان حنيفاً مسلماً .   { وَمَنْ أَظْلَمُ مِمَّنْ كَتَمَ } أخفى .   { شَهَادَةً عِندَهُ مِنَ اللَّهِ } وهو علمهم إنّ إبراهيم وبنيّه كانوا مسلمين ،   وأن محمّداً صلى الله عليه وسلم حق ورسول .   { وَمَا اللَّهُ بِغَافِلٍ عَمَّا تَعْمَلُونَ } { تِلْكَ أُمَّةٌ قَدْ خَلَتْ لَهَا مَا كَسَبَتْ } الآية .
