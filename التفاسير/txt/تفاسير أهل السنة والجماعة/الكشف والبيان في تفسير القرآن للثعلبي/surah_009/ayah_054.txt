{ وَمَا مَنَعَهُمْ أَن تُقْبَلَ مِنْهُمْ } قرأ نافع وعاصم ويحيى والأعمش وحمزة والكسائي : ( أن يقبل ) بالياء لنعتهم الفعل ،   الباقون بالتاء { نَفَقَاتُهُمْ } صدقاتهم { إِلاَّ أَنَّهُمْ كَفَرُواْ بِاللَّهِ وَبِرَسُولِهِ } الاولى في موضع نصب ،   و«أن » الثانية في محل رفع تقديره : ومامنعهم قبول نفقاتهم إلاّ كفرهم { وَلاَ يَأْتُونَ الصَّلاَةَ إِلاَّ وَهُمْ كُسَالَى } مستاؤون لأنهم لا يرجون بأدائها ثواباً ،   ولايخافون بتركها عقاباً { وَلاَ يُنفِقُونَ إِلاَّ وَهُمْ كَارِهُونَ } لأنهم يتخذونها مغرماً ومنعها مغنماً .
