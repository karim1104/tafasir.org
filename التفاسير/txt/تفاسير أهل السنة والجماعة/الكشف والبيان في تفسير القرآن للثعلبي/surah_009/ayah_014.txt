{ قَاتِلُوهُمْ يُعَذِّبْهُمُ اللَّهُ } يقتلْهم الله { بِأَيْدِيكُمْ وَيُخْزِهِمْ } يذلّهم بالأسر والقهر { وَيَنْصُرْكُمْ } ويظهركم { عَلَيْهِمْ وَيَشْفِ صُدُورَ } ويبرئ قلوب { قَوْمٍ مُّؤْمِنِينَ } بما كانوا ينالونه من الأذى والمكروه منهم .   قال مجاهد والسدي : أراد صدور خزاعة حلفاء رسول الله صلى الله عليه وسلم
