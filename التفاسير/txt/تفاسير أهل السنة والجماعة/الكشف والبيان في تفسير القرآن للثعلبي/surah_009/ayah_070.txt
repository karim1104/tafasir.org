{ أَلَمْ يَأْتِهِمْ } يعني المنافقين والكافرين { نَبَأُ } خبر { الَّذِينَ مِن قَبْلِهِمْ } حين عصوا رسلنا وخالفوا أمرنا كيف أهلكناهم وعذّبناهم ثم ذكرهم .   فقال { قَوْمِ نُوحٍ } بالمعنى بدلا من الذين أهلكوا بالطوفان { وَعَادٍ } أُهلكوا بالريح { وَثَمُودَ } أُهلكوا بالرجفة { وَقَوْمِ إِبْرَاهِيمَ } بسلب النعمة وهلاك نمرود { وِأَصْحَابِ مَدْيَنَ } يعني قوم شعيب بعذاب يوم الظلّة { وَالْمُؤْتَفِكَاتِ } المنقلبات التي جعلت عاليها سافلها ،   وهم قوم لوط { أَتَتْهُمْ رُسُلُهُمْ بِالْبَيِّنَاتِ } فكذبوهم وعصوهم كما فعلتم يامعشر الكفّار فاحذروا بتعجيل النقمة .
