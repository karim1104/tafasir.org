ثم قال حاضّاً المسلمين على جهاد المشركين { أَلاَ تُقَاتِلُونَ قَوْماً نَّكَثُواْ أَيْمَانَهُمْ } نقضوا عهودهم { وَهَمُّواْ بِإِخْرَاجِ الرَّسُولِ } محمد صلى الله عليه وسلم من مكة { وَهُم بَدَءُوكُمْ } بالقتال { أَوَّلَ مَرَّةٍ } يعني يوم بدر ،   وقال أكثر المفسرين : أراد بدؤوكم بقتال خزاعة حلفاء رسول الله { أَتَخْشَوْنَهُمْ } أتخافونهم فتتركون قتالهم { فَاللَّهُ أَحَقُّ أَن تَخْشَوْهُ } تخافوه في ترككم قتالهم { إِن كُنتُمْ مُّؤُمِنِينَ * .
