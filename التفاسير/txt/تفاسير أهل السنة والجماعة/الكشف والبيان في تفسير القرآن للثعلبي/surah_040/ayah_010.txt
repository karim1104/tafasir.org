{ إِنَّ الَّذِينَ كَفَرُواْ يُنَادَوْنَ } يوم القيامة وهم في النار وقد مقتوا أنفسهم حين عاينوا العذاب فيقال لهم : { لَمَقْتُ اللَّهِ } إياكم في الدُّنيا إذ تدعون إلى الإيمان فتكفرون { أَكْبَرُ مِن مَّقْتِكُمْ } اليوم { أَنفُسَكُمْ } عند حلول العذاب بكم { إِذْ تُدْعَوْنَ إِلَى الإِيمَانِ فَتَكْفُرُونَ }
