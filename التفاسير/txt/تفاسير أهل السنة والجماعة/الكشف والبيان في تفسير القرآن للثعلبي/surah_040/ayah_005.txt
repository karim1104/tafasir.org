ثم قال : { كَذَّبَتْ قَبْلَهُمْ قَوْمُ نُوحٍ وَالأَحْزَابُ } والكفار الذين تحزبوا على أنبيائهم بالمخالفة والعداوة { مِن بَعْدِهِمْ } ،   أي من بعد قوم نوح { وَهَمَّتْ كُلُّ أُمَّةٍ بِرَسُولِهِمْ لِيَأْخُذُوهُ } ويقتلوه .

قال الفراء : كان حقه أن يقول برسولها وكذلك هي في قراءة عبد الله ،   ولكنه أراد بالأمة الرجال فكذلك قال : ( برسولهم ) .

{ وَجَادَلُوا بِالْبَاطِلِ لِيُدْحِضُواْ } ليبطلوا ويزيلوا { بِهِ الْحَقَّ فَأَخَذْتُهُمْ فَكَيْفَ كَانَ عِقَابِ }
