{ فَكَذَّبُوهُ } يعني صالحاً ( عليه السلام ) ،   { فَعَقَرُوهَا } يعني الناقة { فَدَمْدَمَ } دمّر { عَلَيْهِمْ } وأهلكهم { رَبُّهُمْ بِذَنبِهِمْ } بتكذيبهم رسوله وعقرهم ناقته .

{ فَسَوَّاهَا } فسوّى الدمدمة عليهم جميعاً ،   عمّهم بها ،   فلم يفلت منهم أحد .   وقال المروج : الدمدمة : إهلاك باستئصال ،   وقال بعض أهل اللغة : الدمدمة : الإدامة .   تقول العرب : ناقة مدمومة أي سمينة مملوءة ،   وقرأ عبد الله بن الزبير ( فدهدم عليهم ) بالهاء ،   وهما لغتان ،   كقولك امتقع لونه واهتقع إذا تغير .
