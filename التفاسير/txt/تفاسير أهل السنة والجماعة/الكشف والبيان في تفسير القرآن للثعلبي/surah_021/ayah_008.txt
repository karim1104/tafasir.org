{ وَمَا جَعَلْنَاهُمْ } يعني الرسل الأولين { جَسَداً } قال الفرّاء : لم يقل أجساداً لأنّه اسم الجنس { لاَّ يَأْكُلُونَ الطَّعَامَ } يقول : لم نجعلهم ملائكة ،   بل جعلناهم بشراً محتاجين إلى الطعام ،   وهذا جواب لقولهم

{ مَالِ هَذَا الرَّسُولِ يَأْكُلُ الطَّعَامَ } [ الفرقان : 7 ] { وَمَا كَانُواْ خَالِدِينَ } في الدنيا
