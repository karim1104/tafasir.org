قال له ابنه : { سَآوِي } سأصير وأرجع { إِلَى جَبَلٍ يَعْصِمُنِي } يمنعني { مِنَ الْمَآءِ } ومنه عصام القربة الذي [ يربط ] رأسها فيمنع الماء أن يسيل منها .

{ قَالَ } نوح { لاَ عَاصِمَ الْيَوْمَ مِنْ أَمْرِ اللَّهِ } عذاب الله إلاّ من رحمناه ،   وأنقذناه منه ،   ومن في محل رفع ،   وقيل : في محل النصب ومعناه لا معصوم اليوم من أمر الله إلاّ من رحمه الله ،   كقوله تعالى

{ عِيشَةٍ رَّاضِيَةٍ } [ الحاقة : 21 ] [ القارعة : 7 ] و { مَّآءٍ دَافِقٍ } [ الطارق : 6 ] قال الشاعر :
