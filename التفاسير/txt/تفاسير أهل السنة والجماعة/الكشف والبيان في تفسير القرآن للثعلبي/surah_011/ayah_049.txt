{ تِلْكَ } الذي ذكرت { مِنْ أَنْبَآءِ الْغَيْبِ نُوحِيهَآ إِلَيْكَ } يا محمد { وَلاَ قَوْمُكَ مِن قَبْلِ هَذَا } من قبل إخباري إياك { فَاصْبِرْ } على القيام بأمر الله وتبليغ رسالته وما تلقى من أذى الكفار كما صبر نوح { إِنَّ الْعَاقِبَةَ } آخر الأمر بالسعادة والظفر والمغفرة { لِلْمُتَّقِينَ } كما كان لمؤمني قوم نوح وسائر الأمم .
