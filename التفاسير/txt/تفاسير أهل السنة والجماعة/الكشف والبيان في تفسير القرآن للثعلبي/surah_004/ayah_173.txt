{ فَأَمَّا الَّذِينَ آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ فَيُوَفِّيهِمْ أُجُورَهُمْ وَيَزيدُهُمْ مِّن فَضْلِهِ } في [ التضعيف ] ما لا عين رأت ولا أُذن سمعت ولا خطر على قلب بشر .

{ وَأَمَّا الَّذِينَ اسْتَنكَفُواْ } عن عبادته { وَاسْتَكْبَرُواْ } عن السجود { فَيُعَذِّبُهُمْ عَذَاباً أَلِيماً وَلاَ يَجِدُونَ لَهُمْ مِّن دُونِ اللَّهِ وَلِيّاً وَلاَ نَصِيراً } ثم قال ( الله ولي الذين آمنوا ) .
