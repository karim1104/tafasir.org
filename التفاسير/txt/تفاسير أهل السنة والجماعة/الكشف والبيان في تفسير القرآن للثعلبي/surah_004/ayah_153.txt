{ يَسْأَلُكَ أَهْلُ الْكِتَابِ أَن تُنَزِّلَ عَلَيْهِمْ كِتَاباً مِّنَ السَّمَآءِ } الآية ،   وذلك أن كعب بن الأشرف وفنحاص بن عازورا قالا لرسول الله صلى الله عليه وسلم إن كنت نبياً حقاً فأتنا بكتاب من السماء كما أتى به موسى فأنزل الله عز وجل { يَسْأَلُكَ أَهْلُ الْكِتَابِ أَن تُنَزِّلَ عَلَيْهِمْ كِتَاباً مِّنَ السَّمَآءِ } { فَقَدْ سَأَلُواْ مُوسَى أَكْبَرَ مِن ذلِكَ } يعني السبعين الذين خرج بهم موسى( عليه السلام ) إلى الجبل { فَقَالُواْ أَرِنَا اللَّهَ جَهْرَةً } عياناً { فَأَخَذَتْهُمُ الصَّاعِقَةُ بِظُلْمِهِمْ ثُمَّ اتَّخَذُواْ الْعِجْلَ مِن بَعْدِ مَا جَآءَتْهُمُ الْبَيِّنَاتُ فَعَفَوْنَا عَن ذلِكَ } ولم نستأصلهم { وَآتَيْنَا مُوسَى سُلْطَاناً مُّبِيناً } الآية .   يعني الآيات التسع
