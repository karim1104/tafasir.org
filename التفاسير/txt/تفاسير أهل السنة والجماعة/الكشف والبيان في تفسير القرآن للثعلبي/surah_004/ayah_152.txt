قال الله تعالى : { وَالَّذِينَ آمَنُواْ بِاللَّهِ وَرُسُلِهِ } كلهم { وَلَمْ يُفَرِّقُواْ بَيْنَ أَحَدٍ مِّنْهُمْ } يعني بين الرسل وهم المؤمنون ،   قالوا :

{ لاَ نُفَرِّقُ بَيْنَ أَحَدٍ مِّنْهُمْ وَنَحْنُ لَهُ مُسْلِمُونَ } [ البقرة : 136 ] كما علمهم الله ،   فقال { قُولُواْ آمَنَّا .   .   .   } إلى قوله : { لاَ نُفَرِّقُ بَيْنَ أَحَدٍ مِّنْهُمْ وَنَحْنُ لَهُ مُسْلِمُونَ } [ البقرة : 136 ] { أُوْلَئِكَ سَوْفَ يُؤْتِيهِمْ أُجُورَهُمْ } بايمانهم بالله وكتبه ورسله { وَكَانَ اللَّهُ غَفُوراً رَّحِيماً } كما كان منهم في الشرك .
