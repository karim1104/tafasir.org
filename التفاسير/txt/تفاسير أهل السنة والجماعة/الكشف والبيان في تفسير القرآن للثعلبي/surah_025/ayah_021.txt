{ وَقَالَ الَّذِينَ لاَ يَرْجُونَ لِقَآءَنَا لَوْلاَ أُنْزِلَ عَلَيْنَا الْمَلاَئِكَةُ } فتخبرنا أنَّ محمداً صادق محقّ { أَوْ نَرَى رَبَّنَا } فيخبرنا بذلك نظيرها قوله سبحانه :

{ وَقَالُواْ لَن نُّؤْمِنَ لَكَ } [ الإسراء : 90 ] الى قوله :

{ وَالْمَلائِكَةِ قَبِيلاً } [ الإسراء : 92 ] .

قال الله تعالى { لَقَدِ اسْتَكْبَرُواْ فِي أَنفُسِهِمْ } بهذه المقالة { وَعَتَوْا عُتُوّاً كَبِيراً } قال مقاتل : غلوّاً في القول ،   والعتو : أشدّ الكفر وأفحش الظلم .
