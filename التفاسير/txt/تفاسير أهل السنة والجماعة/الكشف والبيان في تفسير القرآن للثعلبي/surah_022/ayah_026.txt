{ وَإِذْ بَوَّأْنَا } وطّأنا .   قال ابن عباس : جعلنا ،   الحسن : أنزلنا ،   مقاتل بن سليمان : دللناه عليه ،   ابن حبان : هيأنا ،   نظيره

{ تُبَوِّئُ الْمُؤْمِنِينَ } [ آل عمران : 121 ]

{ وَبَوَّأَكُمْ فِي الأَرْضِ } [ الأعراف : 74 ] وقوله

{ لَنُبَوِّئَنَّهُمْ مِّنَ الْجَنَّةِ غُرَفَاً } [ العنكبوت : 58 ] .   { لإِبْرَاهِيمَ مَكَانَ الْبَيْتِ } والمكان جوهر يمكن أن يثبت عليه غيره ،   كما أن الزمان عرض يمكن أن يحدث فيه غيره ،   وأراد بالبيت الكعبة .

{ أَن لاَّ تُشْرِكْ } يعني أمرناه وعهدنا إليه أن لا تشرك { بِي شَيْئاً وَطَهِّرْ بَيْتِيَ لِلطَّآئِفِينَ وَالْقَآئِمِينَ } يعني المصلّين { وَالرُّكَّعِ السُّجُودِ } .
