كما يشير لذلك قوله تعالى :  {  إِنَّ هَؤُلآءِ ضَيْفِي فَلاَ تَفْضَحُونِ } [ الحجر : 68 ] وقوله تعالى :  {  وَلَقَدْ رَاوَدُوهُ عَن ضَيْفِهِ فَطَمَسْنَآ أَعْيُنَهُمْ } [ القمر : 37 ] الآية وقوله :  {  وَجَآءَهُ قَوْمُهُ يُهْرَعُونَ إِلَيْهِ وَمِن قَبْلُ كَانُواْ يَعْمَلُونَ السَّيِّئَاتِ } [ هود : 78 ] إلى غير ذلك من الآيات .
