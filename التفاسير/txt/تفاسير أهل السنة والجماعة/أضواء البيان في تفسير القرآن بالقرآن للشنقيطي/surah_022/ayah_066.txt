قوله تعالى :  {  وَهُوَ الَّذِى أَحْيَاكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ إِنَّ الإِنْسَانَ لَكَفُورٌ } .  قوله :  {  وَهُوَ الَّذِى أَحْيَاكُمْ } أي بعد أن كنتم أمواتاً في بطون أمهاتكم قبل نفخ الروح فيكم فهما إحياءتان ،  وإماتتان كما بينه بقوله :  {  كَيْفَ تَكْفُرُونَ بِاللَّهِ وَكُنتُمْ أَمْوَاتًا فَأَحْيَاكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ ثُمَّ إِلَيْهِ تُرْجَعُونَ } [ البقرة :  28 ] وقوله تعالى :  {  قَالُواْ رَبَّنَآ أَمَتَّنَا اثْنَتَيْنِ وَأَحْيَيْتَنَا اثْنَتَيْنِ } [ غافر :  11 ] .

ونظير آية الحج المذكورة هذه قوله تعالى ،  في الجاثية :  {  قُلِ اللَّهُ يُحْيِيكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يَجْمَعُكُمْ إِلَى يَوْمِ الْقِيَامَةِ لاَ رَيْبَ فِيهِ } [ الجاثية :  26 ] ،  وكفر الإنسان المذكور في هذه الآية في قوله :  {  إِنَّ الإِنْسَانَ لَكَفُورٌ } مع أن الله أحياء مرتين ،  وأماته مرتين ،  هو الذي دل القرآن على استعباده وإنكاره مع دلالة الإماتتين والإحياءتين على وجوب الإيمان بالمحيي المميت ،  وعدم الكفر به في قوله :  {  كَيْفَ تَكْفُرُونَ بِاللَّهِ وَكُنتُمْ أَمْوَاتًا فَأَحْيَاكُمْ } [ البقرة :  28 ] .
