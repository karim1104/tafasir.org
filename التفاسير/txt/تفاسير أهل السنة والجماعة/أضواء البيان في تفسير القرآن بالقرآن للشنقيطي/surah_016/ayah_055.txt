قوله تعالى :  {  فَتَمَتَّعُواْ فَسَوْفَ تَعْلَمُونَ } .

صيغة الأمر في قوله {  فَتَمَتَّعُواْ } للتهديد .  وقد تقرر في «فن المعاني ،  في مبحث الإنشاء » ،  وفي «فن الأصول ،  في مبحث الأمر » :  أن من المعاني التي تأتي لها صيغة افعل التهديد ؛  كقوله هنا :  {  فَتَمَتَّعُواْ فَسَوْفَ تَعْلَمُونَ } ،  وتشهد لهذا المعنى آيات أخر ،  كقوله ؛  {  قُلْ تَمَتَّعْ بِكُفْرِكَ قَلِيلاً إِنَّكَ مِنْ أَصْحَابِ النَّارِ } [ الزمر : 8 ] ،  وقوله :  {  قُلْ تَمَتَّعُواْ فَإِنَّ مَصِيرَكُمْ إِلَى النَّارِ } [ إبراهيم :  30 ] ،  وقوله :  {  ذَرْهُمْ يَأْكُلُواْ وَيَتَمَتَّعُواْ وَيُلْهِهِمُ الأمَلُ فَسَوْفَ يَعْلَمُونَ } [ الحجر : 3 ] ،  وقوله :  {  فَذَرْهُمْ يَخُوضُواْ وَيَلْعَبُواْ حَتَّى يُلَاقُواْ يَوْمَهُمُ الَّذِي يُوعَدُونَ } [ الزخرف :  83 ] ،  وقوله :  {  كُلُواْ وَتَمَتَّعُواْ قَلِيلاً إِنَّكُمْ مُّجْرِمُونَ } [ المرسلات :  46 ] ،  وقوله :  {  فَذَرْهُمْ حَتَّى يُلَاقُواْ يَوْمَهُمُ الَّذِي فِيهِ يُصْعَقُونَ } [ الطور :  45 ] ،  إلى غير ذلك من الآيات .
