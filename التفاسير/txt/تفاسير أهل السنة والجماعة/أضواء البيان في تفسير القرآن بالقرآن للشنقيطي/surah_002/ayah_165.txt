قوله تعالى :  {  وَلَوْ يَرَى الَّذِينَ ظَلَمُواْ إِذْ يَرَوْنَ الْعَذَابَ } الآية .

المراد بالذين ظلموا الكفار وقد بيّن ذلك بقوله في آخر الآية :  {  وَمَا هُم بِخَارِجِينَ مِنَ النَّارِ 167 } ،  ويدلّ لذلك قوله تعالى عن لقمان مقررًا له :  {  يا بني لاَ تُشْرِكْ بِاللَّهِ إِنَّ الشّرْكَ لَظُلْمٌ عَظِيمٌ 13 } ،  وقوله جلّ وعلا :  {  وَالْكَافِرُونَ هُمُ الظَّالِمُونَ 254 } ،  وقوله :  {  وَلاَ تَدْعُ مِن دُونِ اللَّهِ مَا لاَ يَنفَعُكَ وَلاَ يَضُرُّكَ فَإِن فَعَلْتَ فَإِنَّكَ إِذًا مّنَ الظَّالِمِينَ 106 } .
