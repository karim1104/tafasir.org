قوله تعالى : {  وَقِفُوهُمْ إِنَّهُمْ مَّسْئُولُونَ * مَا لَكُمْ لاَ تَنَاصَرُونَ } .

قد قدّمنا الآيات الموضحة له في سورة «الأعراف » ،  في الكلام على قوله تعالى :  {  فَلَنَسْئَلَنَّ الَّذِينَ أُرْسِلَ إِلَيْهِمْ وَلَنَسْئَلَنَّ الْمُرْسَلِينَ } [ الأعراف :  6 ] ،  وبيَّنا هناك وجه الجمع بين الآيات في نحو قوله تعالى :  {  وَلاَ يُسْأَلُ عَن ذُنُوبِهِمُ الْمُجْرِمُونَ } [ القصص :  78 ] ،  وقوله تعالى :  {  فَيَوْمَئِذٍ لاّ َيُسْئَلُ عَن ذَنبِهِ إِنسٌ وَلاَ جَانٌّ } [ الرحمن :  39 ] ،  مع قوله تعالى :  {  فَوَرَبّكَ لَنَسْئَلَنَّهُمْ أَجْمَعِينَ * عَمَّا كَانُوا يَعْمَلُونَ } [ الحجر :  92-93 ] ،  وقوله تعالى :  {  فَلَنَسْئَلَنَّ الَّذِينَ أُرْسِلَ إِلَيْهِمْ } [ الأعراف :  6 ] الآية .  وقوله هنا :  {  وَقِفُوهُمْ إِنَّهُمْ مسئولون } .
