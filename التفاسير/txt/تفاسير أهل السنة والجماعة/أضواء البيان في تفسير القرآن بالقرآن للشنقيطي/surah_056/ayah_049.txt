قوله تعالى :  {  قُلْ إِنَّ الأولين والآخرين لَمَجْمُوعُونَ إِلَى مِيقَاتِ يَوْمٍ مَّعْلُومٍ } .

لما أنكر الكفار بعثهم وآباءهم الأولين في الآية المتقدمة ،  أمر الله نبيه صلى الله عليه وسلم أن يخبرهم خبراً مؤكداً بأن الأولين والآخرين كلهم مجموعون يوم القيامة للحساب والجزاء بعد بعثهم .

وما تضمنته هذه الآية الكريمة من بعث الأولين والآخرين وجمعهم يوم القيامة جاء موضحاً في آيات كثيرة كقوله :  {  يَوْمَ يَجْمَعُكُمْ لِيَوْمِ الْجَمْعِ ذَلِكَ يَوْمُ التَّغَابُنِ } [ التغابن :  9 ] ،  وقوله تعالى :  {  اللَّهُ لا إِلَهَ إِلاَّ هُوَ لَيَجْمَعَنَّكُمْ إِلَى يَوْمِ الْقِيَامَةِ } [ النساء :  87 ] وقوله تعالى :  {  رَبَّنَآ إِنَّكَ جَامِعُ النَّاسِ لِيَوْمٍ لاَّ رَيْبَ فِيهِ } [ آل عمران :  9 ] الآية ،  وقوله تعالى :  {  ذلِكَ يَوْمٌ مَّجْمُوعٌ لَّهُ النَّاسُ } [ هود :  103 ] وقوله تعالى :  {  هَذَا يَوْمُ الْفَصْلِ جَمَعْنَاكُمْ والأولين } [ المرسلات :  38 ] ،  وقوله تعالى :  {  وَحَشَرْنَاهُمْ فَلَمْ نُغَادِرْ مِنْهُمْ أَحَداً } [ الكهف :  47 ] .

وقد قدمنا هذا موضحاً في سورة الحجر في الكلام على قوله تعالى :  {  وَحَفِظْنَاهَا مِن كُلِّ شَيْطَانٍ رَّجِيمٍ } [ الحجر :  17 ] .
