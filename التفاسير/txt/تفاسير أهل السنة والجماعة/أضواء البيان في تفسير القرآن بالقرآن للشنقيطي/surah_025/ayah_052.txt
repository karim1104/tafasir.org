وقوله :  {  فَلاَ تُطِعِ الْكَافِرِينَ } ،  ذكره أيضًا في غير هذا الموضع ؛  كقوله تعالى :  {  وَلاَ تُطِعِ الْكَافِرِينَ وَالْمُنَافِقِينَ } [ الأحزاب :  48 ] الآية ،  وقوله :  {  وَلاَ تُطِعْ مِنْهُمْ آثِماً أَوْ كَفُوراً } [ الإنسان :  24 ] ،  وقوله تعالى :  {  وَلاَ تُطِعْ مَنْ أَغْفَلْنَا قَلْبَهُ عَن ذِكْرِنَا وَاتَّبَعَ هَوَاهُ } [ الكهف :  28 ] ،  وقوله تعالى :  {  وَلاَ تُطِعْ كُلَّ حَلاَّفٍ مَّهِينٍ } [ القلم :  10 ] .

وقوله في هذه الآية الكريمة :  {  وَجَاهِدْهُمْ بِهِ } ،  أي :  بالقرآن ،  كما روي عن ابن عباس .

والجهاد الكبير المذكور في هذه الآية هو المصحوب بالغلظة عليهم ؛  كما قال تعالى :  {  يا أَيُّهَا الَّذِينَ آمَنُواْ قَاتِلُواْ الَّذِينَ يَلُونَكُمْ مّنَ الْكُفَّارِ وَلِيَجِدُواْ فِيكُمْ غِلْظَةً } [ التوبة :  123 ] الآية ،  وقال تعالى :  {  يا أَيُّهَا النَّبِىُّ جَاهِدِ الْكُفَّارَ وَالْمُنَافِقِينَ وَاغْلُظْ عَلَيْهِمْ } [ التوبة :  73 ] ،  وقوله تعالى :  {  فَلاَ تُطِعِ الْكَافِرِينَ } ،  من المعلوم أنه صلى الله عليه وسلم لا يطيع الكافرين ،  ولكنه يأمر وينهى ليشرّع لأُمّته على لسانه ،  كما أوضحناه في سورة «بني إسرائيل » .
