قوله تعالى :  {  وَمَن يَأْتِهِ مُؤْمِناً قَدْ عَمِلَ الصَّالِحَاتِ فَأُوْلَئِكَ لَهُمُ الدَّرَجَاتُ الْعُلَى 75 } .

ذكر جل وعلا في هذه الآية الكريمة :  «أن » {  وَمَن يَأْتِهِ } يوم القيامة في حال كونه {  مُؤْمِناً قَدْ عَمِلَ الصَّالِحَاتِ } أي في الدنيا حتى مات على ذلك {  فَأُوْلَئِكَ لَهُمُ } عند الله {  الدَّرَجَاتُ الْعُلَى 75 } والعلى :  جمع علياً وهي تأنيث الأعلى .  وقد أشار إلى هذا المعنى في غير هذا الموضع ؛  كقوله تعالى :  {  وللآخرة أَكْبَرُ دَرَجَاتٍ وَأَكْبَرُ تَفْضِيلاً 21 } ،  وقوله :  {  وَلِكُلٍّ دَرَجَاتٌ مِّما عَمِلُواْ } ونحو ذلك من الآيات .
