قوله تعالى :  {  إِنَّهُ مَن يَأْتِ رَبَّهُ مُجْرِما فَإِنَّ لَهُ جَهَنَّمَ لاَ يَمُوتُ فِيهَا وَلاَ يَحْيَى 74 } .  ذكر الله جل وعلا في هذه الآية الكريمة :  {  إنَّهُ } أي الأمر والشأن {  إِنَّهُ مَن يَأْتِ } يوم القيامة في حال كونه {  مُجْرِما } أي مرتكباً الجريمة في الدنيا حتى مات على ذلك كالكافر عياذاً بالله تعالى {  فَإِنَّ لَهُ }عند الله {  جَهَنَّمَ } يعذب فيها ف{  لاَ يَمُوتُ } فيستريح {  وَلاَ يَحْيَى 74 } حياة فيها راحة .

وهذا الذي ذكره هنا  أوضحه في غير هذا الموضع :  كقوله :  {  وَالَّذِينَ كَفَرُواْ لَهُمْ نَارُ جَهَنَّمَ لاَ يُقْضَى عَلَيْهِمْ فَيَمُوتُواْ وَلاَ يُخَفَّفُ عَنْهُمْ مِّنْ عَذَابِهَا كَذَلِكَ نَجْزِى كُلَّ كَفُورٍ 36 } ،  وقوله تعالى :  {  وَاسْتَفْتَحُواْ وَخَابَ كُلُّ جَبَّارٍ عَنِيدٍ 15 مِّن وَرَآئِهِ جَهَنَّمُ وَيُسْقَى مِن ماء صَدِيدٍ 16 يَتَجَرَّعُهُ وَلاَ يَكَادُ يُسِيغُهُ وَيَأْتِيهِ الْمَوْتُ مِن كُلِّ مَكَانٍ وَما هُوَ بِمَيِّتٍ وَمِن وَرَآئِهِ عَذَابٌ غَلِيظٌ 17 } ،  وقوله تعالى :  {  كُلَّما نَضِجَتْ جُلُودُهُمْ بَدَّلْنَاهُمْ جُلُوداً غَيْرَهَا لِيَذُوقُواْ الْعَذَابَ } ،  وقوله تعالى :  {  وَيَتَجَنَّبُهَا الأشقى 11 الذي يَصْلَى النَّارَ الْكُبْرَى 12 ثُمَّ لاَ يَمُوتُ فِيهَا وَلاَ يَحْيَى 13 } ،  وقوله تعالى :  {  وَنَادَوْاْ يا مالِكُ لِيَقْضِ عَلَيْنَا رَبُّكَ قَالَ إِنَّكُمْ ماكِثُونَ 77 } إلى غير ذلك من الآيات .  ونظير ذلك من كلام العرب قول عبيد الله بن عبد الله بن عتبة بن مسعود أحد فقهاء المدينة السبعة :
