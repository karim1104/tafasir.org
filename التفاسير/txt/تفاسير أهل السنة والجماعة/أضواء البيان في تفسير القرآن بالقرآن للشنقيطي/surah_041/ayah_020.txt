قوله تعالى :  {  حَتَّى إِذَا مَا جَآءُوهَا شَهِدَ عَلَيْهِمْ سَمْعُهُمْ وَأَبْصَارُهُمْ وَجُلُودُهُم بِمَا كَانُواْ يَعْمَلُونَ } .

قد قدمنا الآيات الموضحة له في سورة يس في الكلام على قوله تعالى :  {  الْيَوْمَ نَخْتِمُ عَلَى أَفْوَاهِهِمْ وَتُكَلِّمُنَآ أَيْدِيهِمْ } [ يس :  65 ] الآية ،  وفي سورة النساء في الكلام على قوله تعالى :  {  وَلاَ يَكْتُمُونَ اللَّهَ حَدِيثاً } [ النساء :  42 ] .

وبينا هناك وجه الجمع بين قوله تعالى :  {  وَلاَ يَكْتُمُونَ اللَّهَ حَدِيثاً } [ النساء :  42 ] مع قوله {  ثُمَّ لَمْ تَكُنْ فِتْنَتُهُمْ إِلاَّ أَن قَالُواْ وَاللَّهِ رَبِّنَا مَا كُنَّا مُشْرِكِينَ } [ الأنعام :  23 ] .
