وذيّل بقوله :  { وإن كل ذلك لما متاع الحياة الدنيا } أي كل ما ذكر من السّقُف والمعارج والأبواب والسُرر من الفضة والذهب متاع الدنيا لا يعود على من أُعطِيه بالسعادة الأبدية وأما السعادة الأبدية فقد ادخرها الله للمتقين وليست كمثل البهارج والزينة الزائدة التي تصادف مختلِف النفوس وتكثر لأهل النفوس الضئيلة الخسيسة وهذا كقوله تعالى :  { زُين للنّاس حبّ الشهوات من النّساء والبنين والقناطير المقنطرة من الذهب والفضّة والخيل المسوَّمة والأنعامِ والحرث ذلك متاع الحياة الدّنيا والله عنده حسن المئاب }  [ آل عمران :  14 ] .

وقرأ الجمهور { لما } بتخفيف الميم فتكون { إنْ } التي قبلها مخففة من ( إنّ ) المشددة للتوكيد وتكون اللام الداخلة على { لَمَا } اللامَ الفارقة بين ( إنْ ) النافية و ( إنْ ) المخففة و ( ما ) زائدة للتوكيد بين المضاف والمضاف إليه .  وقرأ عاصم وحمزة وهشام عن ابن عامر { لَمَّا } بتشديد الميم فهي { لَمَّا } أخت ( ألاَّ ) المختصة بالوقوع في سياق النفي فتكون { إِنْ } نافية ،  والتقدير :  وما كل ذلك إلا متاع الحياة الدنيا .
