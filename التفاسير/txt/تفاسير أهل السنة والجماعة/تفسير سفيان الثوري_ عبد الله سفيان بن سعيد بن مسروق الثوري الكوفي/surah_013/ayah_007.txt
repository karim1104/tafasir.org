437: 5: 3- سفين عن منصور عن أبي الضحى قال { إِنَّمَآ أَنتَ مُنذِرٌ وَلِكُلِّ قَوْمٍ هَادٍ } قال، محمد صلى الله عليه وسلم. [الآية 7].  438: 6: 4- سفين عن السدي عن عكرمة مثله.  439: 7: 5- سفين عن أبي رزين عن الضحاك { إِنَّمَآ أَنتَ مُنذِرٌ وَلِكُلِّ قَوْمٍ هَادٍ } قال، الله تبارك وتعالى.  440: 8: 6- سفين عن ليث عن مجاهد { إِنَّمَآ أَنتَ مُنذِرٌ } يا محمد { وَلِكُلِّ قَوْمٍ هَادٍ } قال، النبيين عليهم السلام.  441: 9: 7- سفين عن إسمعيل عن أبي صالح في قوله { إِنَّمَآ أَنتَ مُنذِرٌ } يا محمد { وَلِكُلِّ قَوْمٍ هَادٍ } داعي إلى هدى أو ضلالة.
