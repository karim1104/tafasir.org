وقوله تعالى :  {  يوم يقوم الروح والملائكة صفا38 } ،  أي :  يوم يقوم جبريل والملائكة معه ،  استنادا إلى قوله تعالى عن جبريل :  {  نزل به الروح الأمين على قلبك لتكون من المنذرين بلسان عربي مبين } ( الشعراء :  193 ) .

وقوله تعالى :  {  لا يتكلمون إلا من أذن له الرحمان } ،  يشابه قوله تعالى في  " آية الكرسي "  :  {  من ذا الذي يشفع عنده إلا بإذنه } ( البقرة :  254 ) وقوله تعالى في آية أخرى :  {  يوم يأت لا تكلم نفس إلا بإذنه } ( هود :  105 ) .
