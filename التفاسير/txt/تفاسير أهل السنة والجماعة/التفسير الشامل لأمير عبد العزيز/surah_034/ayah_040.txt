قوله تعالى :  {  وَيَوْمَ يَحْشُرُهُمْ جَمِيعًا ثُمَّ يَقُولُ لِلْمَلائِكَةِ أَهَؤُلاءِ إِيَّاكُمْ كَانُوا يَعْبُدُونَ ( 40 ) قَالُوا سُبْحَانَكَ أَنْتَ وَلِيُّنَا مِنْ دُونِهِمْ بَلْ كَانُوا يَعْبُدُونَ الْجِنَّ أَكْثَرُهُمْ بِهِمْ مُؤْمِنُونَ ( 41 ) فَالْيَوْمَ لا يَمْلِكُ بَعْضُكُمْ لِبَعْضٍ نَفْعًا وَلا ضَرًّا وَنَقُولُ لِلَّذِينَ ظَلَمُوا ذُوقُوا عَذَابَ النَّارِ الَّتِي كُنْتُمْ بِهَا تُكَذِّبُونَ } .

ذلك تذكير من الله بيوم القيامة حيث القواصم والأهوال ،  إذ يجمع الله الخلائق جميعا {  ويوم } منصوب بفعل مقدر ،  أي واذكر يوم يحشرهم جميعا ليلاقوا الحساب .  وهو قوله :  {  ثُمَّ يَقُولُ لِلْمَلائِكَةِ أَهَؤُلاءِ إِيَّاكُمْ كَانُوا يَعْبُدُونَ } الاستفهام لتوبيخ المشركين الذين كانوا يعبدون المخلوقات كالملائكة ،  إذ يسألهم الله {  أَهَؤُلاءِ إِيَّاكُمْ كَانُوا يَعْبُدُونَ } أأنتم أمرتم هؤلاء المشركين بعبادتكم {  سُبْحَانَكَ أَنْتَ وَلِيُّنَا مِنْ دُونِهِمْ }
