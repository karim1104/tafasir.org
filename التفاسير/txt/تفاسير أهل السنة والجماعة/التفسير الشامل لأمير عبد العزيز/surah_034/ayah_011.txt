قوله :  {  أَنِ اعْمَلْ سَابِغَاتٍ } {  أَنِ } مفسرة بمعنى أي و {  سَابِغَاتٍ } جمع سابغة وهي الدرع الواسعة .

والمعنى :  اعمل دروعا من الحديد اللين {  وَقَدِّرْ فِي السَّرْدِ } {  السَّرْدِ } ،  معناه الثقب ،  والمسرودة المثقوبة والمعنى في قول المفسرين :  لا تغلظ المسامير فيتسع الثقب ولا توسع الثقب فتقلقل المسامير منها .

قوله :  {  وَاعْمَلُوا صَالِحًا إِنِّي بِمَا تَعْمَلُونَ بَصِيرٌ } المخاطب داود وأهله .  والمعنى :  اعملوا بطاعة الله فإن الله رقيب عليكم ،  خبير بأعمالكم .
