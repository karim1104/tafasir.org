قوله تعالى :  {  وَإِنَّ مِنْ شِيعَتِهِ لَإِبْرَاهِيمَ ( 83 ) إِذْ جَاءَ رَبَّهُ بِقَلْبٍ سَلِيمٍ ( 84 ) إِذْ قَالَ لِأَبِيهِ وَقَوْمِهِ مَاذَا تَعْبُدُونَ ( 85 ) أَئِفْكًا آَلِهَةً دُونَ اللَّهِ تُرِيدُونَ ( 86 ) فَمَا ظَنُّكُمْ بِرَبِّ الْعَالَمِينَ ( 87 ) فَنَظَرَ نَظْرَةً فِي النُّجُومِ ( 88 ) فَقَالَ إِنِّي سَقِيمٌ ( 89 ) فَتَوَلَّوْا عَنْهُ مُدْبِرِينَ } .

{  شِيعَتِهِ } في اللغة بمعنى أتباعه وأنصاره والمراد بشيعة نوح في الآية ،  أهل دينه .  والمعنى :  وإن من أهل دين نوح ،  الذين هم على ملته ومنهاجه لهو إبراهيم خليل الرحمن عليه الصلاة والسلام {  إِذْ جَاءَ رَبَّهُ بِقَلْبٍ سَلِيمٍ }
