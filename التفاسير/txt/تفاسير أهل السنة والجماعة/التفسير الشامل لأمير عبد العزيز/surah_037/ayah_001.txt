بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ

قوله تعالى :  {  وَالصَّافَّاتِ صَفًّا ( 1 ) فَالزَّاجِرَاتِ زَجْرًا ( 2 ) فَالتَّالِيَاتِ ذِكْرًا ( 3 ) إِنَّ إِلَهَكُمْ لَوَاحِدٌ ( 4 ) رَبُّ السَّمَاوَاتِ وَالْأَرْضِ وَمَا بَيْنَهُمَا وَرَبُّ الْمَشَارِقِ ( 5 ) إِنَّا زَيَّنَّا السَّمَاءَ الدُّنْيَا بِزِينَةٍ الْكَوَاكِبِ ( 6 ) وَحِفْظًا مِنْ كُلِّ شَيْطَانٍ مَارِدٍ ( 7 ) لا يَسَّمَّعُونَ إِلَى الْمَلإ الْأَعْلَى وَيُقْذَفُونَ مِنْ كُلِّ جَانِبٍ ( 8 ) دُحُورًا وَلَهُمْ عَذَابٌ وَاصِبٌ ( 9 ) إِلاَّ مَنْ خَطِفَ الْخَطْفَةَ فَأَتْبَعَهُ شِهَابٌ ثَاقِبٌ } .

أقسم الله بالصافات وهي الملائكة تصف أقدامها في الصلاة ،  وقيل :  تصف أجنحتها في الهواء تنتظر الأمر من الله و {  صفًّا } مصدر مؤكد .
