قوله تعالى :  {  فَرَاغَ إِلَى آَلِهَتِهِمْ فَقَالَ أَلا تَأْكُلُونَ ( 91 ) مَا لَكُمْ لا تَنْطِقُونَ ( 92 ) فَرَاغَ عَلَيْهِمْ ضَرْبًا بِالْيَمِينِ ( 93 ) فَأَقْبَلُوا إِلَيْهِ يَزِفُّونَ ( 94 ) قَالَ أَتَعْبُدُونَ مَا تَنْحِتُونَ ( 95 ) وَاللَّهُ خَلَقَكُمْ وَمَا تَعْمَلُونَ ( 96 ) قَالُوا ابْنُوا لَهُ بُنْيَانًا فَأَلْقُوهُ فِي الْجَحِيمِ ( 97 ) فَأَرَادُوا بِهِ كَيْدًا فَجَعَلْنَاهُمُ الْأَسْفَلِينَ } .

راغ يروغ روغا وروغانا ،  أي مال أو أقبل أي مال إبراهيم إلى آلهة القوم بعد خروجهم عنه {  فَقَالَ أَلا تَأْكُلُونَ } قال ذلك على سبيل السخرية والاستهزاء فهو يعلم أن هذه الأصنام صماء لا تبصر ولا تسمع .  وكذا قوله :  {  مَا لَكُمْ لا تَنْطِقُونَ }
