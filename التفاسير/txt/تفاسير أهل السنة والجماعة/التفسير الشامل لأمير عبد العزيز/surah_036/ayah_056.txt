قوله :  {  وَأَزْوَاجُهُمْ فِي ظِلالٍ عَلَى الْأَرَائِكِ مُتَّكِئُونَ } {  هم } في موضع مبتدأ ،  و {  أَزْوَاجُهُمْ } معطوف عليه .  وفي {  فِي ظِلالٍ } خبره .  أو {  مُتَّكِئُونَ } خبره و {  الأرائك } جمع أريكة وهي السرير .  وذلك وصف من الله للنعيم الذي يقيم في المؤمنون وأزواجهم ؛  فهم جميعا مبتهجون سعداء في ظلال الجنة حيث الأرائك التي يتكئون عليها وغير ذلك من أسباب السعادة والرخاء والاستقرار {  لَهُمْ فِيهَا فَاكِهَةٌ وَلَهُمْ مَا يَدَّعُونَ }
