قوله :  {  يا إبراهيم أعرض عن هذا } يخبر الله عن قيل الملائكة لإبراهيم حين جادلهم في قوم لوط فقالوا له :  دع عنك الجدال في أمر هؤلاء المؤتفكين الفاسقين ؛  فقد جاءهم حكم الله بالعذاب ومضى فيهم قضاؤه بالإهلاك والتدمير .  وهو قوله :  {  إنه قد جاء أمر ربك } أي عذابه .  وقوله :  {  وإنهم آتاهم عذاب غير مردود } {  عذاب } ،  فاعل لاسم الفاعل الذي هو {  آتاهم }  إن هؤلاء المؤتفكين الفاسقين القذرين نازل من الله عذاب أليم ومذل {  غير مردود } غير مصروف عنهم ولا مدفوع .
