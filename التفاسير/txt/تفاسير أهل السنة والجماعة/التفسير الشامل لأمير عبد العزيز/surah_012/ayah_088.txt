قوله :  {  فلَمَّا دَخَلُواْ عَلَيْهِ قَالُواْ يَا أَيُّهَا الْعَزِيزُ مَسَّنَا وَأَهْلَنَا الضُّرّ } دخل بنو يعقوب على يوسف وشكوا إليه ما حل ببلادهم من قحط وجدب وجهد وحاجة وقالوا له أيضا :  {  وَجِئْنَا بِبِضَاعَةٍ مُّزْجَاةٍ } المراد بالبضاعة ثمن الطعام الذي جاءوا ليمتروه .  و {  مزجاة } أي مدفوعة يدفعها كل واحد عنه لزهادته فيها ،  ومنه قوله :  {  ألم تر أن الله يزجي سحابا } أي يسوقه بالريح ؛  أي جئناك ومعنا ثمن الطعام الذي نمتاره {  فَأَوْفِ لَنَا الْكَيْلَ } أي التمسوا منه إيفاءهم الكيل فقالوا به :  أتم لنا الكيل {  وتصدق علينا } أي بالمسامحة والإغماض عن رداءة البضاعة .  أو زدنا على حقنا .  {  إِنَّ اللّهَ يَجْزِي الْمُتَصَدِّقِينَ } يجزيهم الثواب والخير عن تصدقهم .
