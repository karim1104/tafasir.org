قوله تعالى :  {  وَهَلْ أَتَاكَ نَبَأُ الْخَصْمِ إِذْ تَسَوَّرُوا الْمِحْرَابَ } :  {  الْخَصْمِ } يستوي فيه المذكر والمؤنث والجمع والتثنية والإفراد ؛  لأنه في الأصل مصدر والمراد بالخصم ههنا ملكان {  إِذْ تَسَوَّرُوا الْمِحْرَابَ } أي وقت تسور المحراب .  و {  تَسَوَّرُوا الْمِحْرَابَ } ،  يعني أتوه من أعلى سوره .  نقول :  تسور الحائط ،  أي تسلّقه .  و {  الْمِحْرَابَ } معناه هنا الغرفة ؛  فقد تسلقوا على داود وهو فيها .  وهو قوله :  {  إِذْ دَخَلُوا عَلَى دَاوُودَ فَفَزِعَ مِنْهُمْ }
