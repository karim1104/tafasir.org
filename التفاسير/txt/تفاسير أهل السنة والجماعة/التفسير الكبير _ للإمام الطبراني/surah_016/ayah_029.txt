قَوْلُهُ تَعَالَى: { ثُمَّ يَوْمَ ٱلْقِيَامَةِ يُخْزِيهِمْ وَيَقُولُ أَيْنَ شُرَكَآئِيَ ٱلَّذِينَ كُنْتُمْ تُشَاقُّونَ فِيهِمْ }؛ تُشرِكُونَهم معي في العبادةِ، وقولهُ تعالى: { قَالَ ٱلَّذِينَ أُوتُواْ ٱلْعِلْمَ }؛ أي قالَ المؤمنون: { إِنَّ ٱلْخِزْيَ ٱلْيَوْمَ وَٱلْسُّوۤءَ عَلَى ٱلْكَافِرِينَ } إنَّ الذُّلَّ اليومَ والهوانَ على الكافرين، { ٱلَّذِينَ تَتَوَفَّاهُمُ ٱلْمَلائِكَةُ ظَالِمِي أَنْفُسِهِمْ } تقبضُ أرواحَهم في حالِ ظُلمِهم لأنفُسِهم بالكفر، { فَأَلْقَوُاْ ٱلسَّلَمَ } ، واستَسلَمُوا وانقادوا للمذلَّةِ والهوانِ، يقولون: { مَا كُنَّا نَعْمَلُ مِن سُوۤءٍ }؛ أي مِن معصيةٍ في الدُّنيا، فيقول المؤمنون: { بَلَىٰ }؛ قد فَعَلتُمْ ذلكَ، { إِنَّ ٱللَّهَ عَلِيمٌ بِمَا كُنْتُمْ تَعْمَلُونَ }؛ وتقولُ لهم خَزَنَةُ جهنَّمَ، { فَٱدْخُلُوۤاْ أَبْوَابَ جَهَنَّمَ خَالِدِينَ فِيهَا فَلَبِئْسَ مَثْوَى ٱلْمُتَكَبِّرِينَ }؛ عن توحيدِ الله وعبادته.
