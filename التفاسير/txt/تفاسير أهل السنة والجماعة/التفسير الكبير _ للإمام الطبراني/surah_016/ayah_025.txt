قَوْلُهُ تَعَالَى: { لِيَحْمِلُواْ أَوْزَارَهُمْ }؛ أي آثامَهم، { كَامِلَةً } ، أي وافرةً، { يَوْمَ ٱلْقِيَامَةِ }؛ ليَحمِلُوا، { وَمِنْ أَوْزَارِ }؛ أي آثامِ، { ٱلَّذِينَ يُضِلُّونَهُمْ } ، يصرِفونَهم عن مُحَمَّدٍ صلى الله عليه وسلم والقرآنِ، { بِغَيْرِ عِلْمٍ } ، بلا عِلْمٍ ولا حجَّة، يعني يكونُ عليهم إثْمُ إضلالِهم غيرَهم لا أن يحملوا ذنوبَ غيرِهم، كما قَالَ اللهُ تَعَالَى: [الأنعام: 164]. وقوله تعالى: { أَلاَ سَآءَ مَا يَزِرُونَ }؛ ظاهر المعنى.
