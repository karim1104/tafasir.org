قَوْلُهُ تَعَالَى: { وَلاَ تَتَّخِذُوۤاْ أَيْمَانَكُمْ دَخَلاً بَيْنَكُمْ }؛ أي مَكْراً وخديعةً، { فَتَزِلَّ قَدَمٌ }؛ فتَزِلُّوا عن طاعةِ الله كما تَزِلُّ قدمُ الرجلِ، { بَعْدَ ثُبُوتِهَا } جعلَ اللهُ زلَّةَ القدَمِ عبارةً عن سُخطِ الله، وثَبَاتَ القَدَمِ عبارةٌ عن رِضَى اللهِ.  وَقِيْلَ: معنى قولهِ تعالى: { فَتَزِلَّ قَدَمٌ بَعْدَ ثُبُوتِهَا } أي فتهلَكُوا بعد أنْ كنتم آمنين، وقال ابنُ عبَّاس: (فَتَزِلَّ عَنِ الإيْمَانِ بَعْدَ الْمَعْرِفَةِ). قَوْلُهُ تَعَالَى: { وَتَذُوقُواْ ٱلْسُّوۤءَ }؛ يعني العذابَ، { بِمَا صَدَدتُّمْ عَن سَبِيلِ ٱللَّهِ }؛ أي بما منَعتُم الناسَ عن دينِ الله، { وَلَكُمْ عَذَابٌ عَظِيمٌ }؛ في الآخرةِ.
