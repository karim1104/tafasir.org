قَوْلُهُ تَعَالَى: { وَإِذَا رَأى ٱلَّذِينَ أَشْرَكُواْ }؛ أي إذا رأى الذين أشرَكوا الأصنامَ مع اللهِ في العبادةِ، { شُرَكَآءَهُمْ } ، يعني الأصنامَ، { قَالُواْ رَبَّنَا هَـٰؤُلآءِ }؛ الأصنام، { شُرَكَآؤُنَا ٱلَّذِينَ كُنَّا نَدْعُوْا مِن دُونِكَ }؛ التي أشرَكناها معكَ في العبادةِ، فألقَى الأصنامَ { فَألْقَوْا إِلَيْهِمُ ٱلْقَوْلَ إِنَّكُمْ لَكَاذِبُونَ } في أنَّا آلهةً وفي أنَّا أمَرنَاكم بالعبادةِ، { وَأَلْقَوْاْ إِلَىٰ ٱللَّهِ يَوْمَئِذٍ ٱلسَّلَمَ } ، واستَسلَمُوا كلُّهم لأمرِ الله يومئذ، { وَضَلَّ عَنْهُم مَّا كَانُواْ يَفْتَرُونَ }. والفائدةُ في إعادةِ الأصنام يومئذ: أنْ يُعَيِّرَهم اللهُ بها، وأن يُعذِّبَهم بها في الدُّنيا.
