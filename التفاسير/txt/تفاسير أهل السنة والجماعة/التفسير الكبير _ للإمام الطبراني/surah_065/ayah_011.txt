قَوْلُهُ تَعَالَى: { فَذَاقَتْ وَبَالَ أَمْرِهَا }؛ أي فذاقُوا جزاءَ كُفرِهم، { وَكَانَ عَاقِبَةُ أَمْرِهَا خُسْراً }؛ أي هلاكَ النُّفوس وهي رأسُ أموالهم، { أَعَدَّ ٱللَّهُ لَهُمْ }؛ في الآخرةِ، { عَذَاباً شَدِيداً }؛ يعني الذي نزَلَ بهم في الدُّنيا، { فَٱتَّقُواْ ٱللَّهَ يٰأُوْلِي ٱلأَلْبَابِ }؛ أي يا أُولي العقُولِ لا تَسِيرُوا بسَيرِهم فينْزِلُ بكم ما نزلَ بهم.  قَوْلُهُ تَعَالَى: { ٱلَّذِينَ آمَنُواْ قَدْ أَنزَلَ ٱللَّهُ إِلَيْكُمْ ذِكْراً * رَّسُولاً }  { ٱلَّذِينَ آمَنُواْ } نعتُ أُولِي الألباب، وقولهُ تعالى { قَدْ أَنزَلَ ٱللَّهُ إِلَيْكُمْ ذِكْراً * رَّسُولاً } أي أنزلَ إليكم كِتَاباً آتاهُ رسُولاً ليؤدِّيَهُ إليكم. وَقِيْلَ: معناهُ: قد أنزلَ الله إليكم قُرآناً وأرسلَ رَسُولاً، { يَتْلُواْ عَلَيْكُمْ آيَاتِ ٱللَّهِ مُبَيِّنَاتٍ }؛ يعني الرسولَ، { لِّيُخْرِجَ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ مِنَ ٱلظُّلُمَاتِ إِلَى ٱلنُّورِ وَمَن يُؤْمِن بِٱللَّهِ وَيَعْمَلْ صَالِحاً يُدْخِلْهُ جَنَّاتٍ تَجْرِي مِن تَحْتِهَا ٱلأَنْهَارُ خَالِدِينَ فِيهَآ أَبَداً }. وقولهُ تعالى: { قَدْ أَحْسَنَ ٱللَّهُ لَهُ رِزْقاً } يعني الجنَّةَ التي لا ينقطعُ نَعِيمُها.
