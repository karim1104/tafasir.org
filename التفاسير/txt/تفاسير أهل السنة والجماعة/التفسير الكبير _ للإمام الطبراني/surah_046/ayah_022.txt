قَوْلُهُ تَعَالَى: { قَالُوۤاْ أَجِئْتَنَا لِتَأْفِكَنَا عَنْ آلِهَتِنَا }؛ أي قالوا: يا هودُ أجِئتَنا لتَصرِفَنا عن عبادةِ آلهتنا بالإفكِ، { فَأْتِنَا بِمَا تَعِدُنَآ }؛ من العذاب، { إِن كُنتَ مِنَ ٱلصَّادِقِينَ } إنَّ العذابَ نازلٌ بنا، { قَالَ }؛ لَهم هودٌ: { إِنَّمَا ٱلْعِلْمُ } بمجيءِ العذاب، { عِندَ ٱللَّهِ }؛ يعلمُ متى يأتيكم العذابُ وَأنا { وَأُبَلِّغُكُمْ مَّآ أُرْسِلْتُ بِهِ }؛ إليكم من الوحيِ والإنذار، والمعنى: إنما أنا مُبَلِّغٌ، والعلمُ بوقتِ العذاب عند الله، { وَلَـٰكِنِّيۤ أَرَاكُمْ قَوْماً تَجْهَلُونَ }؛ أي أمرَ اللهِ وعقابه.
