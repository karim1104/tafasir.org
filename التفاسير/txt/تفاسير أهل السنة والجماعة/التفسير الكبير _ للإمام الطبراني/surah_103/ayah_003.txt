فهؤلاء همُ الذين يتمسَّكون بما يؤدِّيهم إلى الفوز بالثواب، والنجاةِ من العقاب، فإنَّهم لا يُقصِرون على طاعةِ أنفسهم بل يحثُّون غيرَهم على الطاعةِ لِيُقْتَدَى بهم وليَكُونوا سَبباً في طاعةِ غيرهم. وقَوْلُهُ تَعَالَى: { وَتَوَاصَوْاْ بِٱلْحَقِّ } أي أوصَى بعَضُهم بعضاً باتِّباع القرآنِ، وطاعة اللهِ، { وَتَوَاصَوْاْ بِٱلصَّبْرِ } على الشَّدائد في ذاتِ اللهِ.  وعن أُبَيِّ بن كعبٍ قال: قَرَأتُ عَلَى رَسُولِ اللهِ صلى الله عليه وسلم { وَٱلْعَصْرِ } فَقُلْتُ: يَا رَسُولَ اللهِ مَا تَفْسِيرُهَا؟ فَقَالَ: " أقْسَمَ رَبُّكَ بآخِرِ النَّهَار { إِنَّ ٱلإِنسَانَ } وَهُوَ أبُو جَهْلٍ { لَفِى خُسْرٍ } ، { إِلاَّ ٱلَّذِينَ آمَنُواْ } يَعْنِي أبَا بَكْرٍ الصِّدِّيقِ { وَعَمِلُواْ ٱلصَّالِحَاتِ } يَعْنِي عُمَرَ بْنَ الْخَطَّاب، { وَتَوَاصَوْاْ بِٱلْحَقِّ } يَعْنِي عُثْمَانَ بْنَ عَفَّانٍ، { وَتَوَاصَوْاْ بِٱلصَّبْرِ } يَعْنِي عَلِيَّ بْنَ أبي طَالِبٍ " رضْوَانُ اللهِ عَلَيْهِمْ أجْمَعِينَ.
