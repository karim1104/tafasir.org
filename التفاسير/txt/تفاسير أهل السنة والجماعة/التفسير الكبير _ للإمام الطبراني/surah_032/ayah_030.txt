قَوْلُهُ تَعَالَى: { فَأَعْرِضْ عَنْهُمْ }؛ أي عن جوابهم، { وَٱنتَظِرْ } ، الفريضةَ فيهم، { إِنَّهُمْ مُّنتَظِرُونَ }؛ الفرصةَ فيك. قال ابنُ عبَّاس: ((قَوْلُهُ تَعَالَى: { فَأَعْرِضْ عَنْهُمْ } نَسَخَتْهُ آيَةُ السَّيْفِ)). وَقَوْلُهُ تَعَالَى: { إِنَّهُمْ مُّنتَظِرُونَ } أيْ مُنْتَظِرُونَ لَكَ حَوَادِثَ الأَزْمَانِ مِنْ مَوْتٍ أوْ قَتْلٍ فَيَسْتَرِيحُونَ مِنْكَ.
