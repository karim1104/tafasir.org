{ الۤمۤر تِلْكَ آيَاتُ ٱلْكِتَابِ وَٱلَّذِيۤ أُنزِلَ إِلَيْكَ مِن رَّبِّكَ ٱلْحَقُّ }؛ قال ابنُ عبَّاس: (مَعْنَى المر: أنَا اللهُ أعْلَمُ وَأرَى). وقولهُ تعالى: { تِلْكَ آيَاتُ ٱلْكِتَابِ } أي هذهِ آياتُ القرآنِ، وقولهُ تعالى: { وَٱلَّذِيۤ أُنزِلَ إِلَيْكَ مِن رَّبِّكَ ٱلْحَقُّ } هو القرآنُ أيضاً، وقال قتادةُ: (الْمُرَادُ بقَوْلِهِ { تِلْكَ آيَاتُ ٱلْكِتَابِ } الآيَات الَّتِي أُنْزِلَتْ قَبْلَ الْقُرْآنِ مِنَ التَّوْرَاةِ وَالإنْجِيلِ وَسَائِرِ الْكُتُب، وَالْمُرَادُ بـ { وَٱلَّذِيۤ أُنزِلَ إِلَيْكَ } الْقُرْآنُ)، { وَلَـٰكِنَّ أَكْثَرَ ٱلنَّاسِ لاَ يُؤْمِنُونَ }.
