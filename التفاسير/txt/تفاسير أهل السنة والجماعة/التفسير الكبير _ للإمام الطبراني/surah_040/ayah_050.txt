قولهُ تعالى: { قَالَ ٱلَّذِينَ ٱسْتَكْبَرُوۤاْ إِنَّا كُلٌّ فِيهَآ }؛ أي إنا نحنُ وأنتم قد استَوَينا في العذاب، { إِنَّ ٱللَّهَ قَدْ حَكَمَ بَيْنَ ٱلْعِبَادِ }؛ أي قضَى بهذا علينا وعليكم وحَكَمَ أنْ لا يتحملَ أحدٌ عذابَ أحدٍ.  فلما رأوا شدَّة العذاب، { وَقَالَ ٱلَّذِينَ فِي ٱلنَّار } ، قالوا، { لِخَزَنَةِ جَهَنَّمَ ٱدْعُواْ رَبَّكُمْ يُخَفِّفْ عَنَّا يَوْماً مِّنَ ٱلْعَذَاب }؛ أي يُهَوِّنْ عنَّا العذابَ قدر يومٍ من أيَّام الدُّنيا، { قَالُوۤاْ } ، فيقول الزبانية: { أَوَلَمْ تَكُ تَأْتِيكُمْ رُسُلُكُمْ بِٱلْبَيِّنَاتِ }؛ أي بالدَّلالاتِ الظاهرةِ على وحدانيَّة اللهِ، { قَالُواْ بَلَىٰ } ، فيقولون: بلَى قد أتَتْنا الرسُل، { قَالُوا } ، فتقولُ لَهم الزبانيةُ: { فَٱدْعُواْ } ، أنتم فإنَّ اللهَ تعالى لم يأْذنْ لنا في الدُّنيا، { وَمَا دُعَاءُ ٱلْكَافِرِينَ إِلاَّ فِي ضَلاَلٍ }؛ أي في ضياعٍ لا ينفعُهم.
