قَوْلُهُ تَعَالَى: { كَـذَّبَتْ قَبْلَهُمْ }؛ أي قبلَ قَومِكَ، { قَوْمُ نُوحٍ }؛ وَقَوْلُهُ تَعَالَى: { وَٱلأَحْزَابُ مِن بَعْدِهِمْ }؛ وهم الذين تحزَّبُوا على أنبيائِهم بالتكذيب نحوُ عادٍ وثَمود؛ أي كذبُوا رُسلَهم كما كذبك قومُكَ، { وَهَمَّتْ كُـلُّ أُمَّةٍ بِرَسُولِهِمْ لِيَأْخُذُوهُ }؛ فيقتلوهُ، { وَجَادَلُوا بِٱلْبَاطِلِ لِيُدْحِضُواْ بِهِ ٱلْحَقَّ }؛ أي وخاصَمُوا الرُّسلَ بالباطلِ ليُبطِلُوا به الحقَّ الذي جاءَت به الرسلُ، { فَأَخَذْتُهُمْ } ، بعاقبةِ الاستئصالِ، { فَكَيْفَ كَانَ عِقَابِ }؛ لَهم.
