قًوْلُهُ عَزَّ وَجَلَّ: { قُلْ إِن كَانَ آبَاؤُكُمْ وَأَبْنَآؤُكُمْ وَإِخْوَانُكُمْ وَأَزْوَاجُكُمْ وَعَشِيرَتُكُمْ }؛ أي قُل يا مُحَمَّدُ للذِينَ ترَكُوا الهجرةَ إنْ كان آباؤُكم وأبناؤُكم وإخوانكم ونساؤكُم وقراباتُكم، { وَأَمْوَالٌ ٱقْتَرَفْتُمُوهَا }؛ اكتسَبتُموها بمكَّة وأصبتُموها، { وَتِجَارَةٌ تَخْشَوْنَ كَسَادَهَا }؛ أي عدمَ نفاقِها إذا اشتغَلتُم بطاعةِ اللهِ، { وَمَسَاكِنُ تَرْضَوْنَهَآ }؛ ومنازلُ تعجِبُكم الإقامة بها بمكَّة، { أَحَبَّ إِلَيْكُمْ مِّنَ }؛ طاعةِ، { ٱللَّهِ وَرَسُولِهِ }؛ بالهجرةِ إلى المدينةِ، { وَجِهَادٍ فِي سَبِيلِهِ } ، وأحبَّ إليكم من الجهادِ في طاعة اللهِ، { فَتَرَبَّصُواْ حَتَّىٰ يَأْتِيَ ٱللَّهُ بِأَمْرِهِ } ، أي فانتَظِروا حتى يأْتيَ اللهُ بفتحِ مكَّة، ويقال: حتى يأتي اللهُ بعذابٍ عاجل أو آجِلٍ، { وَٱللَّهُ لاَ يَهْدِي ٱلْقَوْمَ ٱلْفَاسِقِينَ }؛ أي لا يرشدُ الخارجِين عن طاعتهِ إلى معصيتهِ، ولا يهديهم إلى جنَّتهِ وثوابه.
