قَوْلُهُ تَعَالَى: { وَمَا كَانَ ٱللَّهُ لِيُعَذِّبَهُمْ وَأَنتَ فِيهِمْ وَمَا كَانَ ٱللَّهُ مُعَذِّبَهُمْ وَهُمْ يَسْتَغْفِرُونَ }؛ قال ابنُ عبَّاس: (قَالَ الحَارْثُ بْنُ عَامِرِ بْنِ نَوْفَل: يَا مُحَمَّدُ، وَاللهِ إنَّكَ فِينَا لَصَادِقٌ وَلاَ نَتَّهِمُكَ، وَلَكِنَّا مَتَى نُؤْمِنُ بكَ غَزَانَا الْعَرَبُ، فَنَزَلَ { وَمَا كَانَ ٱللَّهُ لِيُعَذِّبَهُمْ وَأَنتَ فِيهِمْ } ) أي مُقيماً بين أظهُرِهم، ولَم تُعَذبْ أُمَّة قط ونبيُّها بين أظهُرِها حتى يخرجَ منها. { وَمَا كَانَ ٱللَّهُ مُعَذِّبَهُمْ } أي وما كان اللهُ ليُسَلِّطَ عليهم عدُوَّهم { وَهُمْ يَسْتَغْفِرُونَ } أي يُصَلُّونَ.
