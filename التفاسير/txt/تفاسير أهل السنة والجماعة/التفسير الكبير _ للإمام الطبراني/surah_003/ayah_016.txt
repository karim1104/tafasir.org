قَوْلُهُ تَعَالَى: { ٱلَّذِينَ يَقُولُونَ رَبَّنَآ إِنَّنَآ آمَنَّا فَٱغْفِرْ لَنَا ذُنُوبَنَا وَقِنَا عَذَابَ ٱلنَّارِ } ، { ٱلَّذِينَ } في موضعِ خَفْضٍ رَدَاً على قولهِ { لِلَّذِينَ ٱتَّقَوْا } أي للمتَّقينَ { ٱلَّذِينَ يَقُولُونَ رَبَّنَآ إِنَّنَآ آمَنَّا } وَصَدَّقْنَا بالله وبالرسولِ فاغفِرْ لنا خطايَانا، وادفَع عنَّا عذابَ النار، ويجوز أن يكونَ موضع { الَّذِينَ } رفعاً على معنى هُم { ٱلَّذِينَ يَقُولُونَ رَبَّنَآ } كقولِهِ تعالى: [التوبة: 111] ثم قال في صفتِهم مبتَدِئاً: [التوبة: 112].
