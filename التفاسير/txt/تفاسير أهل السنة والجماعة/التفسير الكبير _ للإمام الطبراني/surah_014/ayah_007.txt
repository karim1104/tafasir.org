قَوْلُهُ تَعَالَى: { وَإِذْ تَأَذَّنَ رَبُّكُمْ }؛ هذه عطفٌ على قولهِ [ابراهيم: 6] كأنه قالَ: اذكرُوا نعمةَ اللهِ عليكم إذ أنْجَاكُم، وإذ تأذنَ ربُّكم، وهذا إخبارٌ عن ما قالَ موسى لقومهِ؛ أي أعلَمَكم في الكتاب، { لَئِن شَكَرْتُمْ } نعمَتي { لأَزِيدَنَّكُمْ } نعمةً، { وَلَئِن كَفَرْتُمْ }؛ نِعمَتي، { إِنَّ عَذَابِي لَشَدِيدٌ }؛ لِمَن كفرَ.  قال ابنُ عبَّاس: (مَعْنَى الآيَةِ: لَئِنْ وَحَّدْتُمُونِي وَأطَعْتُمُونِي، لأَزيدَنَّكُمْ نِعْمَةً)، قال قتادةُ: (حَقُّ اللهِ أنْ يُعْطِي مَنْ سَأَلَهُ، وَيَزِيدَ مَنْ شَكَرَهُ)، وقولهُ تعالى { وَلَئِن كَفَرْتُمْ } أي جَحَدتُّم حقِّي وحقَّ نِعْمَتي إنَّ عذابي لشديدٌ.
