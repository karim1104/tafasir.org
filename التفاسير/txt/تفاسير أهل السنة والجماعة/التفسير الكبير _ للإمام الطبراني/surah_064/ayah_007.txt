قَوْلُهُ تَعَالَى: { زَعَمَ ٱلَّذِينَ كَفَرُوۤاْ أَن لَّن يُبْعَثُواْ }؛ أي قال كفارُ مكَّة قولاً بالظنِّ غير يقينٍ أنَّهم لا يُبعَثون بعد الموتِ، { قُلْ }؛ لَهم يا مُحمَّدُ: { بَلَىٰ وَرَبِّي لَتُبْعَثُنَّ }؛ بعدَ الموتِ، { ثُمَّ لَتُنَبَّؤُنَّ بِمَا عَمِلْتُمْ }؛ في الدُّنيا { وَذَلِكَ }؛ الجزاءُ والبعثُ، { عَلَى ٱللَّهِ يَسِيرٌ }؛ أي سهلٌ هيِّن، { فَآمِنُواْ }؛ يا أهلَ مكَّة، { بِٱللَّهِ وَرَسُولِهِ }؛ مُحَمَّدٍ صلى الله عليه وسلم، { وَٱلنّورِ ٱلَّذِيۤ أَنزَلْنَا }؛ يعني القرآنَ، { وَٱللَّهُ بِمَا تَعْمَلُونَ خَبِيرٌ }.
