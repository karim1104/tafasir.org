يقولُ الله تعالى: { فَإِنَّهُمْ يَوْمَئِذٍ فِي ٱلْعَذَابِ مُشْتَرِكُونَ }؛ أي لا ينفَعُهم التنازعُ والتخاصمُ، وكِلاَ الفريقين مشتركون في العذاب، { إِنَّا كَذَلِكَ نَفْعَلُ بِٱلْمُجْرِمِينَ }؛ أي هكَذا نُعاقِبُ المشركين.  وقولهُ تعالى: { إِنَّهُمْ كَانُوۤاْ إِذَا قِيلَ لَهُمْ لاَ إِلَـٰهَ إِلاَّ ٱللَّهُ يَسْتَكْبِرُونَ }؛ أي إنَّهم كانوا يستَكبرون عن كلمةِ التوحيد، { وَيَقُولُونَ أَئِنَّا لَتَارِكُوۤاْ آلِهَتِنَا }؛ أنَتركُ آلِهَتنا وعِبادتَها، { لِشَاعِرٍ مَّجْنُونٍ }؛ يَعنُونَ النبيَّ صلى الله عليه وسلم نَسَبوهُ إلى الشِّعرِ والجنون.  فأكذبَهم اللهُ تعالى بقولهِ: { بَلْ جَآءَ بِٱلْحَقِّ وَصَدَّقَ ٱلْمُرْسَلِينَ }؛ أي ما هو يقولِ شاعر وما صَاحِبُكم بمجنون { بَلْ جَآءَ بِٱلْحَقِّ } أي بالقُرآن والتوحيدِ، { وَصَدَّقَ ٱلْمُرْسَلِينَ } الذين كانوا قبلَهُ؛ أي أتَى بما أتَوا بهِ من الأيمانِ وقول الحقِّ.
