{  وَلَقَدْ فَتَنَّا  قَبْلَهُمْ قَوْمَ فِرْعَوْنَ وَجَاءهُمْ رَسُولٌ كَرِيمٌ ( 17 ) أَنْ أَدُّوا إِلَيَّ  عِبَادَ اللهِ إِنِّي لَكُمْ رَسُولٌ أَمِينٌ ( 18 ) وَأَنْ لاَّ تَعْلُوا عَلَى اللهِ إِنِّي آتِيكُم بِسُلْطَانٍ مُّبِينٍ ( 19 ) وَإِنِّي عُذْتُ بِرَبِّي وَرَبِّكُمْ أَن تَرْجُمُونِ ( 20 ) وَإِنْ لَّمْ تُؤْمِنُوا لِي فَاعْتَزِلُونِي ( 21 ) فَدَعَا رَبَّهُ أَنَّ هَؤُلاء قَوْمٌ مُّجْرِمُونَ ( 22 ) فَأَسْرِ بِعِبَادِي لَيْلا إِنَّكُم مُّتَّبَعُونَ ( 23 ) وَاتْرُكْ الْبَحْرَ رَهْوًا  إِنَّهُمْ جُندٌ مُّغْرَقُونَ ( 24 ) كَمْ تَرَكُوا مِن جَنَّاتٍ وَعُيُونٍ ( 25 ) وَزُرُوعٍ وَمَقَامٍ كَرِيمٍ ( 26 ) وَنَعْمَةٍ  كَانُوا فِيهَا فَاكِهِينَ ( 27 ) كَذَلِكَ وَأَوْرَثْنَاهَا قَوْمًا آخَرِينَ ( 28 ) فَمَا بَكَتْ عَلَيْهِمُ السَّمَاء وَالأَرْضُ وَمَا كَانُوا مُنظَرِينَ ( 29 ) وَلَقَدْ نَجَّيْنَا بَنِي إِسْرَائِيلَ مِنَ الْعَذَابِ الْمُهِينِ ( 30 ) مِن فِرْعَوْنَ إِنَّهُ كَانَ عَالِيًا مِّنَ الْمُسْرِفِينَ ( 31 ) وَلَقَدِ اخْتَرْنَاهُمْ عَلَى عِلْمٍ  عَلَى الْعَالَمِينَ ( 32 ) وَآتَيْنَاهُم مِّنَ الْآيَاتِ مَا فِيهِ بَلَاء مُّبِينٌ ( 7 ) ( 33 ) } [ 17 – 33 ] .
