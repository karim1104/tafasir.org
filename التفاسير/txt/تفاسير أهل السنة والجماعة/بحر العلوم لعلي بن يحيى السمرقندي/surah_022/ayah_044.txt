{ وأصحاب مَدْيَنَ } كذبوا شعيباً ،   { وَكُذّبَ موسى } يعني : كذبه قومه .   { فَأمْلَيْتُ للكافرين }  ؛ يعني : أمهلتهم .   { ثُمَّ أَخَذْتُهُمْ }  ؛ يعني : عاقبتهم بعد المهل بالعذاب .   { فَكَيْفَ كَانَ نَكِيرِ } ؟ يعني : كيف رأيت تغييري وإنكاري عليهم ؟ يعني : أليس قد وجدوا حقاً ؟ فكذلك كفار مكة تصيبهم العقوبة ،   كما أصابهم .
