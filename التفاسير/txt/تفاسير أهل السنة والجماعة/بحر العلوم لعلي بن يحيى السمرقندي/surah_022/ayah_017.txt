{ إِنَّ الذين ءامَنُواْ } ،   يعني : أصحاب محمد صلى الله عليه وسلم ومن كان مثل حالهم ،   { والذين هَادُواْ }  ؛ يعني : مالوا عن الإسلام يعني : اليهود { والصابئين }  ؛ وقد ذكرناه من قبل ،   { والنصارى والمجوس } ،   يعني : عبدة النيران ،   { والذين أَشْرَكُواْ }  ؛ يعني : عبدة الأوثان والأديان ستة : فواحد لله تعالى ،   والخمسة للشيطان .   { إِنَّ الله يَفْصِلُ بَيْنَهُمْ } ،   يعني : يقضي ويحكم بينهم { يَوْمُ القيامة } ،   يعني : بين هذه الأديان الستة ؛ وقال بعضهم : إن الفاء مضمرة في الكلام ومعناه : فإن الله يفصل بينهم على معنى جواب الشرط ؛ ويقال : جوابه في قوله : { فالذين كَفَرُواْ } .

ثم قال : { إِنَّ الله على كُلّ شَىْء شَهِيدٌ } ،   من أعمالهم .
