{ ذلكم } ،   أي الهلاك والهزيمة للكفار ،   ويقال معناه الأمر من ربكم .   { ذلكم } ثم ابتدأ فقال : { وَأَنَّ الله مُوهِنُ كَيْدِ الكافرين } ،   يعني مضعف كيد الكافرين ،   يعني صنيع الكافرين ببدر .   قرأ ابن كثير ونافع وأبو عمرو { مُوهِنُ كَيْدِ الكافرين } بنصب الواو والتشديد منونة { كَيْدَ } بنصب الدال ،   وقرأ عاصم في رواية حفص { مُوهِنُ } بضم النون بغير تنوين { كَيْدَ } بكسر الدال على معنى الإضافة ،   وقرأ الباقون { مُوهِنُ } بالتنوين والتخفيف { كَيْدَ } بالنصب والمُوهِنُ والمُوهَنُ واحد ؛ ويقال : وهنت الشيء وأوهنته ،   إذا جعلته واهناً ضعيفاً .
