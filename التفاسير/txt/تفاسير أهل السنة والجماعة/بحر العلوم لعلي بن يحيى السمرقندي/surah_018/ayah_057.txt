{ وَمَنْ أَظْلَمُ } أي فلا أحد أظلم ؛ ويقال : أشد في كفره { مِمَّن ذُكّرَ بئايات رَبّهِ } ،   أي وعظ بالقرآن ،   { فَأَعْرَضَ عَنْهَا } .   يقول : فكذب بها ولم يؤمن بها ،   { وَنَسِىَ مَا قَدَّمَتْ يَدَاهُ }  ؛ أي نسي ذنوبه التي أسلفها .   { إِنَّا جَعَلْنَا على قُلُوبِهِمْ أَكِنَّةً } ،   أي جعلنا أعمالهم على قلوبهم أكنة { أَن يَفْقَهُوهُ } ،   أي لكيلا يعرفوه ولا يفهموه .   { وفي آذانهم وقرا } ،   أي صمماً وثقلاً مجازاة لكفرهم .   { وَإِن تَدْعُهُمْ إلى الهدى } ،   أي إِلى الإسلام ،   { فَلَنْ يَهْتَدُواْ }  ؛ أي لن يؤمنوا .
