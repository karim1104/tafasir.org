{ وَوُضِعَ الكتاب } أي وضع كتاب كل امرىء منهم بيمينه أو بشماله ،   { فَتَرَى المجرمين }  ؛ أي المشركين والمنافقين والعاصين .   { مُشْفِقِينَ مِمَّا فِيهِ } ،   أي خائفين مما في الكتاب من الإحصاء .   { وَيَقُولُونَ ياويلتنا } ،   يا ندامتنا { مَّالِ  هذا الكتاب لاَ يُغَادِرُ صَغِيرَةً وَلاَ كَبِيرَةً } ؟ يعني : الزلل والكبائر ويقال : تبسماً وضحكاً ،   { إِلاَّ أَحْصَاهَا }  ؛ يقول : حفظها عليهم ،   { وَوَجَدُواْ مَا عَمِلُواْ } في الكتاب { حَاضِرًا } من خير أو شر مكتوباً .   { وَلاَ يَظْلِمُ رَبُّكَ أَحَدًا } ،   أي لا ينقص من ثواب أعمالهم ولا يزيد في سيّئاتهم .
