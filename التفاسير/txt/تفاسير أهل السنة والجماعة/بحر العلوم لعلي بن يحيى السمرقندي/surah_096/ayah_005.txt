{ عَلَّمَ الإنسان مَا لَمْ يَعْلَمْ } يعني : علم آدم عليه السلام أسماء كل شيء ،   يعني : ألهمه ،   ويقال : { عَلَّمَ الإنسان } يعني : محمداً صلى الله عليه وسلم { مَا لَمْ يَعْلَمْ } يعني : القرآن كقوله { وَكَذَلِكَ أَوْحَيْنَآ إِلَيْكَ رُوحاً مِّنْ أَمْرِنَا مَا كُنتَ تَدْرِي مَا الكتاب وَلاَ الإيمان ولكن جعلناه نُوراً نَّهْدِي بِهِ مَن نَّشَآءُ مِنْ عِبَادِنَا وَإِنَّكَ لتهدى إلى صراط مُّسْتَقِيمٍ } [ الشورى : 52 ] ويقال : علم الإنسان ما لم يعلم ،   يعني : علم بني آدم ما لم يعلموا كقوله : { والله أَخْرَجَكُم مِّن بُطُونِ أمهاتكم لاَ تَعْلَمُونَ شَيْئًا وَجَعَلَ لَكُمُ السمع والأبصار والأفئدة لَعَلَّكُمْ تَشْكُرُون } [ النحل : 78 ] .
