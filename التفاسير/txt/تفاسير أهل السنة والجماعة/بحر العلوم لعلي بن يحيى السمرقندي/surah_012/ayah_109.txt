قوله تعالى : { وَمَا أَرْسَلْنَا مِنْ قَبْلِكَ إلاَّ رِجَالاً نُّوحِي إلَيْهِمْ } يعني : الأنبياء كانوا من الآدميين ،   ولم يكونوا من الملائكة .   قرأ عاصم في رواية حفص : { نُوحِي إلَيْهِمْ } بالنون .   وقرأ الباقون بالياء { يُوحَى إِلَيْهِمْ } ،   ومعناهما واحد { مِنْ أهْلِ الْقُرَى } يعني : منسوبين إليها .   ثم أمرهم بأن يعتبروا ،   فقال تعالى : { أَفَلَمْ يَسِيرُوا } يعني : يسافروا { فِي الأرض } ويقال : يقرؤوا القرآن { فَيَنْظُرُوا } يعني : يعتبروا { كَيْفَ كَانَ عَاقِبَةُ الَّذِينَ مِنْ قَبْلِهِمْ } يعني : كيف كان آخر المنذرين من قبلهم من الأمم الخالية { وَلَدَارُ الآخِرَةِ } وهي الجنة { خَيْرٌ لِلَّذِينَ اتَّقَوْا } الشرك { أَفَلاَ تَعْقِلُونَ } أن الآخرة أفضل من الدنيا .
