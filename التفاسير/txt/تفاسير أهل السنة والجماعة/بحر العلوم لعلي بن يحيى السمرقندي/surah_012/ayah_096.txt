قوله تعالى : { فَلَمَّا أَنْ جَاءَ الْبَشِيرُ } يعني : جاء يهوذا بالبشارة { أَلْقَاهُ عَلَى وَجْهِهِ } يعني : دفع القميص إليه ،   ووضعه على وجهه ،   { فَارْتَدَّ بَصِيراً } يعني : رجع بصيراً كما كان { قَالَ } يعقوب لولد ولده { أَلَمْ أَقُلْ لَّكُمْ إنَّي أَعْلَمُ مِنَ الله مَا لاَ تَعْلَمُونَ } ويقال : قال لولده : ألم أقل لكم حين قلت لكم : { إنَّمَا أشْكُو بَثِّي وَحُزْنِي إلَى الله وَأَعْلَمُ مِنَ الله مَا لاَ تَعْلَمُونَ } أن يوسف في الأحياء
