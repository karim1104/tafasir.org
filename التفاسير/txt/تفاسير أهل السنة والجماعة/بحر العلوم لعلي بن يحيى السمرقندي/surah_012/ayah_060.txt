{ فَإِن لَّمْ تَأْتُونِى بِهِ } أي : بالأخ { فَلاَ كَيْلَ لَكُمْ عِندِى } فيما تستقبلون { وَلاَ تَقْرَبُونِ } يعني : ولا تستقبلوا إليَّ مرة أخرى ،   فإني لا أعطي لكم الطعام .   قال الزجاج : القراءة بالكسر يعني : بكسر النون وهو الوجه .   ويجوز { وَلاَ تَقْرَبُونِ } بفتح النون ،   لأنها نون الجماعة كما قال : { قَالَ أَبَشَّرْتُمُونِى على أَن مَّسَّنِىَ الكبر فَبِمَ تُبَشِّرُونَ } [ الحجر : 54 ] بفتح النون .   قال : ويكون { وَلاَ تَقْرَبُونِ } لفظه لفظ الخبر ،   ومعناه : النهي .
