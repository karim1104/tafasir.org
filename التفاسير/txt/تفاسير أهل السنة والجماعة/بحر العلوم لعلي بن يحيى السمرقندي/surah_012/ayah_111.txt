قوله تعالى : { لَقَدْ كَانَ فِي قَصَصِهِمْ } يعني : في قصة يوسف وإخوته { عِبْرَةٌ لأولِى الأَلْبَابِ } يعني : لذوي العقول .   يعني : عجيبة لمن له عقل ،   لكيلا يحسد أحد أحداً .   ويقال : لمن أراد أن يعتبر بيوسف ،   ويقتدي به ،   ولا يكافىء أحداً بسيئة .   ويقال : { عبرة } يعني : دلالة لنبوة محمد صلى الله عليه وسلم لمن أراد أن يؤمن به { مَا كَانَ حَدِيثاً يُفْتَرَى } يعني : مثل هذا الكلام لا يكون اختلاقاً وكذباً { وَلَكِنْ تَصْدِيقَ الَّذِي بَيْنَ يَدَيْهِ } من الكتب التوراة والإنجيل { وَتَفْصِيلَ كُلِّ شَيْءٍ } يعني : بيان الحلال والحرام { وَهُدًى } من الضلالة { وَرَحْمَةً } يعني : رحمة من العذاب { لِقَوْمٍ يُؤْمِنُونَ } يعني : يصدقون بتوحيد الله تعالى ،   وبمحمد صلى الله عليه وسلم ،   وبالقرآن .
