{ وَدَّت طَّائِفَةٌ مّنْ أَهْلِ الكتاب } يعني أرادت ،   وتمنت جماعة من أهل الكتاب { لَوْ يُضِلُّونَكُمْ } أي يصرفونكم عن دين الإسلام { وَمَا يُضِلُّونَ إِلا أَنفُسَهُمْ } أي وَبَالُ ذلك يرجع إلى أنفسهم .   ويقال : وما يضلون إلا أنفسهم ،   أمثالهم كقوله عزّ وجلّ : { وَإِذْ قَالَ موسى لِقَوْمِهِ يا قوم إِنَّكُمْ ظَلَمْتُمْ أَنفُسَكُمْ باتخاذكم العجل فتوبوا إلى بَارِئِكُمْ فاقتلوا أَنفُسَكُمْ ذلكم خَيْرٌ لَّكُمْ عِندَ بَارِئِكُمْ فَتَابَ عَلَيْكُمْ إِنَّهُ هُوَ التواب الرحيم } [ سورة البقرة : 54 ] أي بعضكم بعضاً { وَمَا يَشْعُرُونَ } قال مقاتل : أي { وما يشعرون } أنهم يضلون أنفسهم .   وقال الكلبي : { وما يشعرون } أن الله يَدُلُّ نبيَّه عليه السلام على ضلالتهم أي يُطْلِعُه .
