قوله عز وجل : { أَلَمْ تَرَ أَنَّ الله أَنزَلَ مِنَ السماء مَاء فَسَلَكَهُ يَنَابِيعَ في الأرض } أي : فأدخله في الأرض فجعله { ينابيع } .   يعني : عيوناً في الأرض تنبع .   ويقال : { فَسَلَكَهُ يَنَابِيعَ في الأرض } يعني : جارياً في الأرض ،   وهي تجري فيها .   ويقال : جعل فيها أنهاراً وعيوناً { ثُمَّ يُخْرِجُ بِهِ زَرْعاً مُّخْتَلِفاً أَلْوَانُهُ } أحمر ،   وأصفر ،   وأخضر ،   { ثُمَّ يَهِيجُ } أي : يتغير { فَتَرَاهُ مُصْفَرّاً } أي : يابساً بعد الخضرة .   ويقال : { ثُمَّ يَهِيجُ } يعني : ييبس .   ويقال : { يَهِيجُ } أي : يتم ،   ويشتد من هاج يهيج .   أي : تم يتم { فَتَرَاهُ مُصْفَرّاً } متغيراً عن حاله ،   { ثُمَّ يَجْعَلُهُ حطاما } قال القتبي : { حطاما } مثل الرفات ،   والفتات .   وقال الزجاج : الحطام ما تفتت ،   وتكسر من النبت .   وقال مقاتل : { حطاما } يعني : هالكاً { إِنَّ في ذَلِكَ لذكرى } أي : فيما ذكر لعظة { لأوْلِي الألباب } يعني : لذوي العقول من الناس .
