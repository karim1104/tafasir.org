قوله تعالى : { إِنَّ هَؤُلاء مُتَبَّرٌ مَّا هُمْ فِيهِ } يعني : مهلك مفسد ما هم فيه من عبادة الأصنام { وباطل } يعني : ضلال { مَا كَانُواْ يَعْمَلُونَ } والتبار : الهلاك .   كقوله تعالى : { رَّبِّ اغفر لِي ولوالدي وَلِمَن دَخَلَ بيتي مُؤْمِناً وَلِلْمُؤْمِنِينَ والمؤمنات وَلاَ تَزِدِ الظالمين إِلاَّ تَبَاراً } [ نوح : 28 ] أي : هلاكاً .
