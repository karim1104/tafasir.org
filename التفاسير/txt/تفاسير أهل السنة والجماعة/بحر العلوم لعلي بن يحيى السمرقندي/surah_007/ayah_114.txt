{ قَالَ } لهم فرعون { نِعْمَ } لكم الجعل { وَإِنَّكُمْ لَمِنَ المقربين } يعني : لكم المنزلة به سوى العطية يعني : إنكم تكونون أول من يدخل علي بالسلام قرأ أبو عمرو { آينَّ لنا لأجْرا } بمد الألف .

وقرأ عاصم في رواية حفص إن بهمزة واحدة بغير ياء وقرأ الباقون بهمزتين وقرأ ابن كثير ونافع { إنَّ لَنَا } بهمزة واحدة بغير ياء .   وقرأ عاصم وحمزة والكسائي { أإن لنا } بهمزتين فلما اجتمع السحرة وغدوا للخروج يوماً وأعلن الناس بخروجهم ليجتمعوا عند سحرهم كما قال في آية أخرى : { قَالَ مَوْعِدُكُمْ يَوْمُ الزينة وَأَن يُحْشَرَ الناس ضُحًى } [ طه : 59 ] أي : يوم عيد كان لهم ويقال : يوم النيروز .
