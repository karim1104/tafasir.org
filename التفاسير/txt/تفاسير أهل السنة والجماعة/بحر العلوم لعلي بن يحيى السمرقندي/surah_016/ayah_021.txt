ثم قال تعالى : { أموات غَيْرُ أَحْيَاء } قال في رواية الكلبي : يعني : أن الأصنام أموات ليس فيها روح { وَمَا يَشْعُرُونَ } يعني : الأصنام { أَيَّانَ يُبْعَثُونَ } أي : متى يحيون فيحاسبون ويقال { أَمْوَاتٌ } يعني : أن الكفار غير أحياء .   يعني : كأنهم أموات لا يعقلون شيئاً { وما يشعرون أيَّان يبعثون } غيره
