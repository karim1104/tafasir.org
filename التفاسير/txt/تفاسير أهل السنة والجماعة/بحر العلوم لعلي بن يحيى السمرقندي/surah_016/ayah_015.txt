ثم قال : { وألقى فِى الأرض رَوَاسِىَ } يعني : الجبال الثوابت { أَن تَمِيدَ بِكُمْ } يعني : لكيلا تميد بكم ،   وقد يحذف لا ويراد إثباته ،   كما قال هاهنا : { أَن تَمِيدَ بِكُمْ } أي لا تميل بأهلها .   وروى معمر عن قتادة أنه قال لما خلقت الأرض كادت تميد فقالت الملائكة ما هذه بمقرة على ظهرها أحداً فأصبحوا وقد خلقت الجبال فلم تدر الملائكة مم خلقت الجبال وقال القتبي الميد الحركة والميل ويقال { أَن تَمِيدَ } أي كراهة أن تميد بكم { وأنهارا } أي : وجعل لكم أنهاراً { وَسُبُلاً } أي : طرقاً { لَعَلَّكُمْ تَهْتَدُونَ } أي : تعرفون بها الطرق { وعلامات } أي : جعل في الأرض علامات من الجبال ،   وغيرها تهتدون به الطرق في حال السفر .
