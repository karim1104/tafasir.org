ثم قال : { وَهُوَ الذى سَخَّرَ البحر } أي : ذلّل لكم البحر .   ويقال : ذلّل لكم ما في البحر { لِتَأْكُلُواْ مِنْهُ } أي : من البحر { لَحْمًا طَرِيّا } أي : السمك الطري { وَتَسْتَخْرِجُواْ مِنْهُ } يعني : من البحر { حِلْيَةً تَلْبَسُونَهَا } يعني : لؤلؤاً تتزينون بها .   يعني : زينة للنساء { وَتَرَى الفلك مَوَاخِرَ فِيهِ } أي : مقبلة ،   ومدبرة فيه .   ويقال : تذهب ،   وتجيء بريح واحدة .   وقال عكرمة : يعني : السفينة حين تشق الماء يقال : مخرت السفينة إذا جرت ،   لأنها إذا جرت تشق الماء { وَلِتَبْتَغُواْ مِن فَضْلِهِ } أي : لكي تطلبوا من رزقه ،   حين تركبون السفينة للتجارة { وَلَعَلَّكُمْ تَشْكُرُونَ } أي : لكي تشكروا الله فيما صنع لكم من النعمة .
