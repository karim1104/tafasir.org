قوله : { ثُمَّ يَوْمَ القيامة يُخْزِيهِمْ } أي : يعذبهم ،   وما أصابهم في الدنيا ،   لم يكن كفارة لذنوبهم .   { وَيَقُولُ أَيْنَ شُرَكَآئِىَ الذين كُنتُمْ تشاقون فِيهِمْ } أي : تعادونني ،   وتخالفونني فيهم ،   يعني : بسببهم وعبادتهم قرأ نافع { تشاقون } بكسر النون على معنى الإضافة .   والباقون : بنصب النون لأنها نون الجماعة .   { قَالَ الذين أُوتُواْ العلم } أي : الملائكة .   ويقال : يعني : المؤمنين { إِنَّ الخزى اليوم } أي : العقاب { والسوء } أي : الشدة من العذاب { عَلَى الكافرين } .
