قوله تعالى : { وَلَوْ أَنَّنَا نَزَّلْنَا إِلَيْهِمُ الملائكة } هذا جواب لقولهم : { وَقَالُواْ لولا أُنزِلَ عَلَيْهِ مَلَكٌ وَلَوْ أَنزَلْنَا مَلَكاً لَّقُضِيَ الأمر ثُمَّ لاَ يُنظَرُونَ } [ الأنعام : 8 ] { وَيَوْمَ يَعَضُّ الظالم على يَدَيْهِ يَقُولُ يا ليتني اتخذت مَعَ الرسول سَبِيلاً } [ الفرقان : 27 ] قال الله تعالى .   { ولو أننا أنزلنا إليهم الملائكة } كما سألوا حتى يشهدوا بأنك رسول الله { وَكَلَّمَهُمُ الموتى } بأنك رسول الله { وَحَشَرْنَا عَلَيْهِمْ كُلَّ شَيْء قُبُلاً } قرأ نافع وابن عامر { قُبُلاً } بكسر القاف ونصب الباء .   وقرأ الباقون بالضم ،   فمن قرأ بالضم فمعناه جماعة القبيل .   والقبيل الكفيل .   ويقال { قبلاً } : أي أصنافاً من الآدميين ومن الملائكة ومن الوحش .   ومن قرأ { قُبُلاً } بالكسر معناه : وحشرنا عليهم كل شيء معاينة فعاينوه .   { مَّا كَانُواْ لِيُؤْمِنُواْ } وهذا إعلام للنبي صلى الله عليه وسلم بأنهم لا يؤمنون كما أعلم نوحاً عليه السلام { وَأُوحِيَ إلى نُوحٍ أَنَّهُ لَن يُؤْمِنَ مِن قَوْمِكَ إِلاَّ مَن قَدْ آمَنَ فَلاَ تَبْتَئِسْ بِمَا كَانُواْ يَفْعَلُونَ } [ هود : 36 ] .

ثم قال : { إِلاَّ أَن يَشَاء الله } يعني : إلا من هو أهل لذلك فيوفقه الله تعالى .   ويقال : { إِلاَّ أَن يَشَاء الله } يقول : قد شاء الله أن لا يؤمنوا حيث خذلهم ولم يوفقهم .   { ولكن أَكْثَرَهُمْ يَجْهَلُونَ } عن ذلك ويقال : { أكثرهم يجهلون الحق } أنه من الله تعالى .   ويقال : { يجهلون } ما في العلامة من وجوب هلاكهم بعد العلامة إن لم يؤمنوا .
