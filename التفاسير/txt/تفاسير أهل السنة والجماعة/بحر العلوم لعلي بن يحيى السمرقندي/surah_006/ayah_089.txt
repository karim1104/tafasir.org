ثم قال : { أولئك الذين آتيناهم الكتاب والحكم } يعني : العلم والفهم والفقه { والنبوة فَإِن يَكْفُرْ بِهَا } أي : الأنبياء { هَؤُلاء } يعني : أهل مكة { فَقَدْ وَكَّلْنَا بِهَا } يعني : ألزمنا بها { قَوْماً لَّيْسُواْ بِهَا بكافرين } .

قال سعيد بن جبير هم الأنصار .   ويقال { فَإِن يَكْفُرْ بِهَا } يعني : بآياتنا { فَقَدْ وَكَّلْنَا بِهَا } يعني : بالإيمان بها { قَوْماً لَّيْسُواْ بِهَا بكافرين } يعني : الأنبياء الذين سبق ذكرهم .   ويقال : الملائكة .   وروى عبد الرزاق عن معمر عن قتادة : { فَإِن يَكْفُرْ بِهَا هَؤُلاء } يعني : أمة محمد عليه السلام { فَقَدْ وَكَّلْنَا بِهَا قوما }ً ليسوا بها كافرين .   يعني : النبيين الذين قصّ الله عنهم .
