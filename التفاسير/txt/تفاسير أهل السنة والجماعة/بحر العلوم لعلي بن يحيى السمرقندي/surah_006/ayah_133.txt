قوله تعالى : { وَرَبُّكَ الغني ذُو الرحمة } يعني : { الغني } عن عبادة خلقه ،   { ذُو الرحمة } بتأخير العذاب عنهم ويقال : { ذُو الرحمة } يعني : ذو التجاوز عمن تاب ورجع إليه بالتوبة { إِن يَشَأْ يُذْهِبْكُمْ } يعني : يهلككم { وَيَسْتَخْلِفْ مِن بَعْدِكُم مَّا يَشَاء } خلقاً بعدكم من بعد إهلاككم { مَا يَشَاء } إن يشأ مثلكم ،   وإن يشأ أطوع منكم .   { كَمَا أَنشَأَكُمْ } يقول : كما خلقكم { مِن ذرية قوم آخرين } قرناً من بعد قرن ولكنه لم يهلككم رحمة منه ،   لترجعوا وتتوبوا .
