ثم قال { وَتِلْكَ حُجَّتُنَا آتيناها إبراهيم على قَوْمِهِ } يعني : أعطيناها إبراهيم على قومه .   يعني : وفقناه للحجة يخاصم بها قومه { نَرْفَعُ درجات مَّن نَّشَاء } يعني : فضائل من نشاء في الدنيا بالحجة ،   وفي الآخرة بالدرجات { إِنَّ رَبَّكَ حَكِيمٌ } في أمره { عَلِيمٌ } بخلقه من يصلح للنبوة .   قرأ أهل الكوفة عاصم وحمزة والكسائي { درجات } بالتنوين وقرأ الباقون { درجات } على معنى الإضافة .
