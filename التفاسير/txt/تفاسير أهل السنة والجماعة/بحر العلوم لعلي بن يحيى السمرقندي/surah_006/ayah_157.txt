{ أَوْ تَقُولُواْ } يعني : لكي لا تقولوا { لَوْ أَنَّا أُنزِلَ عَلَيْنَا الكتاب لَكُنَّا أهدى مِنْهُمْ } يعني : أصوب ديناً منهم { فَقَدْ جَاءكُمْ بَيّنَةٌ مّن رَّبّكُمْ } يعني : حجة من ربكم وهو محمد عليه السلام والقرآن .   وإنما قال : { جَاءكُمْ } ولم يقل : جاءتكم لأنه انصرف إلى المعنى يعني : البيان ،   ولأن الفعل مقدم .   { وَهُدًى وَرَحْمَةٌ } بمعنى : { هدى } من الضلالة { ورحمة } من العذاب .   ويقال : قد جاءكم ما فيه من البيان وقطع الشبهات عنكم .

ثم قال : { فَمَنْ أَظْلَمُ مِمَّن كَذَّبَ بآيات الله } يعني : لا أحد أظلم وأشد في كفره ممن كذب بآيات الله تعالى { وَصَدَفَ عَنْهَا } يعني : أعرض عن الإيمان بها .   { سَنَجْزِي الذين يَصْدِفُونَ } يعني : يعرضون { عَنْ آياتنا سُوء العذاب بِمَا كَانُواْ يَصْدِفُونَ } أي : شدة العذاب بما كانوا يعرضون عن الآيات .
