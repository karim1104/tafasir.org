ثم قال : { وَهُوَ الذي أَنشَأَكُم } يعني : خلقكم { مّن نَّفْسٍ واحدة } وهو آدم .   { فَمُسْتَقَرٌّ وَمُسْتَوْدَعٌ } يعني : في الرحم { ومستودع } في الصلب .   ويقال : { مستقر } في الصلب { ومستودع } في الرحم .   ويقال : { مستقر } في الدنيا { ومستودع } في القبر .   قرأ ابن كثير وأبو عمرو { فَمُسْتَقَرٌّ } بكسر القاف ،   وقرأ الباقون بالنصب .   فمن قرأ بالنصب فمعناه فلكم مستقر ولكم مستودع يعني : موضع قرار وموضع إيداع ومن قرأ بالكسر فعلى معنى الفاعل يقال قَرّ الشيء واستقر بمعنى واحد يعني كنتم مستقرين { قَدْ فَصَّلْنَا الآيات لِقَوْمٍ يَفْقَهُونَ } يعني : بيّنا الآيات لمن له عقل وذهن .
