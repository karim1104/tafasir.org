ثم وعظهم ليخافوا ويرجعوا فقال : { أَلَمْ يَرَوْاْ كَمْ أَهْلَكْنَا مِن قَبْلِهِم مّن قَرْنٍ } يعني : من قبل كفار مكة { مكناهم في الأرض } يعني : مكنّاهم وأعطيناهم من المال والولد { مَا لَمْ نُمَكّن لَّكُمْ } يا أهل مكة { وَأَرْسَلْنَا السماء عَلَيْهِم مَّدْرَاراً } يعني : المطر متتابعاً كلما احتاجوا إليه .   { وَجَعَلْنَا الأنهار تَجْرِي مِن تَحْتِهِمْ فأهلكناهم } يعني : عذبناهم { بِذُنُوبِهِمْ } وبتكذيبهم رسلهم { وَأَنْشَأْنَا مِن بَعْدِهِمْ } يعني : وجعلنا من بعد هلاكهم { قَرْنا آخرين } قال الزجاج : القرن أهل كل مدة فيها نبي أو فيها طبقة من أهل العلم .   كما قال النبي صلى الله عليه وسلم : « خَيْرُ الْقُرونِ أَصْحَابِي ثُمَّ الَّذِينَ يَلُونَهُمْ ثُمَّ الَّذِينَ يَلُونَهُمْ  »
