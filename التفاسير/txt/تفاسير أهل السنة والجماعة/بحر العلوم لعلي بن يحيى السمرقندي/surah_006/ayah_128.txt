قوله تعالى : { وَيَوْمَ يَحْشُرُهُمْ } يقول : واذكر يوم يجمعهم الله { جَمِيعاً } يعني : الجن والإنس .   قرأ عاصم في رواية حفص { يَحْشُرُهُمْ } بالياء يعني : أن الله يحشرهم وقرأ الباقون { نَحْشُرُهُمْ } بالنون { يا معشر الجن } يقول لهم يا معشر الجن { قَدِ استكثرتم مّنَ الإنس } يعني : قد أضللتم كثيراً من الإنس { وَقَالَ أَوْلِيَاؤُهُم مّنَ الإنس } الذين أضلوهم { رَبَّنَا استمتع بَعْضُنَا بِبَعْضٍ } يعني : انتفع بعضنا ببعض وكان استمتاع الإنس بالجن في الدنيا أن أهل الجاهلية كانوا إذا سافر واحد منهم فأدركه المساء بأرض قفر وخاف بالليل فقال : أعوذ بسيد أهل هذا الوادي من سفهاء قومه ،   فأمن ،   ولبث في جوارهم حتى يصبح .   وكان استمتاع الجن بالإنس أن قالوا : لقد سوّدنا الإنس والجن فيزيدون شرفاً في قومهم يعني : فيما بين الجن والإنس .

{ وَبَلَغْنَا أَجَلَنَا الذي أَجَّلْتَ لَنَا } يعني : الموت الذي جعلته أجلنا في هذه الدنيا وهذا قول الكلبي .   وقال الضحاك : { رَبَّنَا استمتع بَعْضُنَا بِبَعْضٍ } يعني : خدع بعضنا بعضاً عن دينك يعني : أن الجن قد خدعنا وأضَلَّنَا { وَبَلَغْنَا أَجَلَنَا الذي أَجَّلْتَ لَنَا } يعني : ما كتبت علينا من الشقاوة { قَالَ النار مَثْوَاكُمْ } يعني : منزلكم وهم الجن والإنس { خالدين فِيهَا } مقيمين في النار { إِلاَّ مَا شَاء الله } قال الكلبي : مشيئة الله من كل شيء ،   ويقال : إلا ما شاء الله البرزخ والقيامة قد شاء الله لهم الخلود فيها .   ويقال { إِلاَّ مَا شَاء الله } يخرج منها من أهل التوحيد { إِنَّ رَبَّكَ حَكِيمٌ عَلِيمٌ } .
