قوله تعالى : { وَتَمَّتْ كَلِمَتُ رَبّكَ } يقول وجب قول ربك بأنه ناصر محمد صلى الله عليه وسلم وأن عاقبة الأمر به { صِدْقاً وَعَدْلاً } يعني : { صِدْقاً } فيما وعد الله له من النصرة { وَعَدْلاً } فيما حكم به { لاَ مُبَدّلَ لكلماته } يقول : لا مغيّر لوعده كقوله { إِنَّا لَنَنصُرُ رُسُلَنَا والذين آمَنُواْ فِي الحياة الدنيا وَيَوْمَ يَقُومُ الأشهاد } [ غافر : 51 ] ويقال : { لاَ مُبَدّلَ لكلماته } يعني : لا ينقض بعضها بعضاً ولا يشبه كلام البشر .   وروى أنس بن مالك عن رسول الله صلى الله عليه وسلم أنه قال : { وَتَمَّتْ كَلِمَةُ رَبّكَ صِدْقاً وَعَدْلاً } قال : « هُوَ قَوْلُ لاَ إله إِلاَّ الله  » { وَهُوَ السميع العليم } { السميع } بما سألوا { العليم } بهم .
