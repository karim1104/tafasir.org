ثم قال : { وَمَا نُرْسِلُ المرسلين إِلاَّ مُبَشّرِينَ وَمُنذِرِينَ } يعني : ليس لهم أن يقترحوا من أنفسهم ،   وإنما أرسلهم بتبليغ الرسالة مبشرين بالجنة لمن أطاعه ،   ومنذرين بالنار لمن عصاه .   { فَمَنْ آمَنَ } يعني : صدق بالرسل { وَأَصْلَحَ } يعني : سلك طريقهم ،   وأصلح العمل .   ويقال : أخلص العمل بعد الإيمان { فَلاَ خَوْفٌ عَلَيْهِمْ وَلاَ هُمْ يَحْزَنُونَ } يعني : { لا خوف عليهم } من أهوال القيامة { ولا هم يحزنون } عند الصراط .
