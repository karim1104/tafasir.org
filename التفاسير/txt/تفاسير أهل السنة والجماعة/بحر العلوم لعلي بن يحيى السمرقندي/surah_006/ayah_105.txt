ثم قال : { وكذلك نُصَرّفُ الآيات } يعني : نبين لهم الآيات في القرآن في كل وجه .   { وَلِيَقُولُواْ دَرَسْتَ } قرأ ابن كثير وأبو عمرو { دَارَسْتَ } يعني : ذاكرت أهل الكتاب وقرأ نافع وعاصم وحمزة والكسائي { الآيات وَلِيَقُولُواْ دَرَسْتَ } يعني : قرأت الكتب .   ويقال : تعلمت من جبر ويسار وكانا غلامين بمكة عبرانيين فقال أهل مكة : إنما يتعلم منهما وقرأ ابن عامر { دَرَسْتَ } بنصب الراء والسين يعني : هذا شيء قديم قد خلفت وقرأ بعضهم { دَرَسْتَ } أي قرئت .   وروي عن عبد الله بن مسعود أنه قرأ { لّيَقُولواْ } بغير واو { درس } بغير تاء يعني : لكي يقولوا دَرَسَ النبي صلى الله عليه وسلم .   وكان نزول هذه الآيات سبباً لقولهم هذا ،   فأضاف قولهم إلى الآيات .   ثم قال { دَرَسْتَ وَلِنُبَيّنَهُ لِقَوْمٍ يَعْلَمُونَ } يعني : أصحاب محمد عليه السلام .
