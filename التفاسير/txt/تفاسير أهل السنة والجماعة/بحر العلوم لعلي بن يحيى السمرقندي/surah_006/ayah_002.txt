ثم قال : { هُوَ الذي خَلَقَكُمْ مّن طِينٍ } يعني : آدم ،   وأنتم من ذريته ومن نسله { ثُمَّ قَضَى أَجَلاً } يعني : أجل ابن آدم منذ يوم ولد إلى يوم يموت .   { وَأَجَلٌ مُّسمًّى عِندَهُ } يعني : البرزخ منذ يموت إلى يوم البعث ،   فهو مكتوب في اللوح المحفوظ ؛ فهذا قول مقاتل والحسن .   وقال عكرمة : { أَجَلاً } يعني : أجل الدنيا { وَأَجَلٌ مُّسَمًّى } يعني : أجل الآخرة .   وهكذا قال سعيد بن جبير : ويقال { أَجَلاً } يعني : أجل واحد { وَأَجَلٌ مُّسَمًّى } يعني : يوم القيامة { ثُمَّ أَنتُمْ تَمْتَرُونَ } يعني : تشكون في البعث بعد الموت وفي الأجل المسمى .
