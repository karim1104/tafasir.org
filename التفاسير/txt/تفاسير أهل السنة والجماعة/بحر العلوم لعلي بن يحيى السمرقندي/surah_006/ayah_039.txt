ثم قال :

{ وَالَّذِينَ كَذَّبُوا بِآيَاتِنَا } يعني : محمداً صلى الله عليه وسلم والقرآن { صُمٌّ } عن الخبر فلا يسمعون الهدى { وَبُكْمٌ } يعني : خرساً فلا يتكلمون بخير { فِي الظلمات } يعني : في الضلالات { مَن يَشَاء الله يُضْلِلْهُ } يعني : يخذله فيموت على الكفر { وَمَن يَشَأْ يَجْعَلْهُ على صراط مُّسْتَقِيمٍ } يعني : يستنقذه من الكفَر فيوفّقه للإسلام .
