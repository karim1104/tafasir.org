ثم قال عز وجل : { وَآية لَّهُمُ } يعني : علامة لكفار مكة على معرفة وحدانية الله تعالى ،   { أَنَّا حَمَلْنَا ذُرّيَّتَهُمْ } يعني : آباءهم ،   واسم الذرية يقع على الآباء والنسوة ،   والصبيان ،   وأصله الخلق ،   كقوله عز وجل : { وَلَقَدْ ذَرَأْنَا لِجَهَنَّمَ كَثِيرًا مِّنَ الجن والإنس لَهُمْ قُلُوبٌ لاَّ يَفْقَهُونَ بِهَا وَلَهُمْ أَعْيُنٌ لاَّ يُبْصِرُونَ بِهَا وَلَهُمْ آذَانٌ لاَّ يَسْمَعُونَ بِهَآ أولئك كالأنعام بَلْ هُمْ أَضَلُّ أولئك هُمُ الغافلون } [ الأعراف : 179 ] يعني : خلقنا .   ويقال : { ذُرّيَّتُهُم } خاصة .

ثم قال : { في الفلك المشحون } يعني : في سفينة نوح عليه السلام الموقرة المملوءة .   يعني : حملنا ذريتهم في أصلاب آبائهم قرأ نافع وابن عامر : { ذُرّياتِهِمْ } بلفظ الجماعة .   وقرأ الباقون : { ذُرّيَّتُهُم } وأراد به الجنس .
