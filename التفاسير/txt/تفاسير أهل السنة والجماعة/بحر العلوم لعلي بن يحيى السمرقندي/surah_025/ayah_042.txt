{ إِن كَادَ لَيُضِلُّنَا } يعني : أراد أن يصرفنا { عَنْ ءالِهَتِنَا } يعني : عن عبادة آلهتنا { لَوْلاَ أَن صَبْرَنَا عَلَيْهَا } يعني : ثبتنا على عبادتها لأدخلنا في دينه حكى قولهم ثم بين مصيرهم فقال : { وَسَوْفَ يَعْلَمُونَ حِينَ يَرَوْنَ العذاب } يعني : يوم القيامة { مَنْ أَضَلُّ سَبِيلاً } يعني : أخطأ طريقاً يعني : تبين لهم أن الذي قلت لهم كان حقاً
