قوله عز وجل : { وَيَوْمَ نَحْشُرُهُمْ } يعني : نجمعهم { وَمَا يَعْبُدُونَ } يعني : ونحشر ما يعبدون { مِن دُونِ الله } يعني : الأصنام .   ويقال المسيح وعزير .   ويقال : الملائكة عليهم السلام { فَيَقُولُ أَءنتُمْ أَضْلَلْتُمْ } يعني : أأنتم أمرتم { عِبَادِى هَؤُلاَء } أن يعبدوكم { أَمْ هُمْ ضَلُّوا السبيل } يعني : أم هم أخطؤوا الطريق ،   فتبرأت الملائكة والأصنام .
