{ إِذَا رَأَتْهُمْ } جهنم { مِن مَّكَانِ بَعِيدٍ } يعني : من مسيرة خمسمائة عام .   ويقال : من مسيرة خمسمائة سنة { سَمِعُواْ لَهَا } يعني : منها { تَغَيُّظاً } على الكفار { وَزَفِيراً } يعني : صوتاً كصوت الحمار .   وقال قوم : معناه يسمعون منها تغيظ المعذبين وزفيرهم ،   كما قال : { فَأَمَّا الذين شَقُواْ فَفِى النار لَهُمْ فِيهَا زَفِيرٌ وَشَهِيقٌ } [ هود : 106 ] وقال عامة المفسرين : التغيظ زفير يسمع من النار ،   ألا ترى أنه قال : { سَمِعُواْ لَهَا } ،   ولم يقل : سمعوا منها ،   ولا فيها .   وقال في آية أخرى : { وهي تفور تَكَادُ تَمَيَّزُ مِنَ الغَيْظِ كُلَّمَا أُلْقِىَ فِيهَا فَوْجٌ سَأَلَهُمْ خَزَنَتُهَآ أَلَمْ يَأْتِكُمْ نَذِيرٌ } [ الملك : 8 ] وروي في الخبر « أن جهنم تزفر زفرة لا يبقى ملك مقرَّب ولا نبيٌّ مرسل إلا خرَّ على وجهه ترعد فرائصهم حتى إن إبراهيم الخليل عليه السلام ليجثو على ركبتيه ويقول : يا رب لا أسألك إلا نفسي  »
