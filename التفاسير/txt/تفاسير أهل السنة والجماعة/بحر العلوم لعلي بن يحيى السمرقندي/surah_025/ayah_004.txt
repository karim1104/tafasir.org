ثم قال عز وجل : { وَقَالَ الذين كَفَرُواْ } يعني : كفار مكة { إِنْ هذا إِلاَّ إِفْكٌ } يعني : ما القرآن إلا كذب { افتراه } يعني : كذباً اختلقه من ذات نفسه { وَأَعَانَهُ عَلَيْهِ ءاخَرُونَ } يعني : جبراً ويساراً { فَقَدْ جَاءوا ظُلْماً وَزُوراً } وقال بعضهم : هذا قول الله تعالى ردّاً على الكفار بقولهم هذا { فَقَدْ جَاءوا ظُلْماً وَزُوراً } يعني : شركاً وكذباً
