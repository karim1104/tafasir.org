ثم قال عز وجل : { وَإَذَا أُلْقُواْ مِنْهَا } يعني : فيها { مَكَاناً ضَيّقاً } يعني : يضيق عليهم المكان كتضييق الزُّجِّ من الرُّمح { مُقْرِنِينَ } أي : مسلسلين في القيود ،   موثقين في الحديد قرنوا مع الشياطين { دَعَوْاْ هُنَالِكَ ثُبُوراً } فعند ذلك دعوا بالويل ،   يعني : يقولون : واهلاكاه ،   فتقول لهم الخزنة { لاَّ تَدْعُواْ اليوم ثُبُوراً واحدا وادعوا ثُبُوراً كَثِيراً }
