قوله عز وجل : { واتخذوا مِن دُونِهِ ءالِهَةً } يعني : تركوا عبادة الله الذي خلق هذه الأشياء ،   وعبدوا غيره .   { لاَ يَخْلُقُونَ شَيْئًا } يعني : عبدوا شيئاً لا يقدر أن يخلق ذباباً ،   ولا غيره { وَهُمْ يُخْلَقُونَ } يتخذونها بأيديهم { وَلاَ يَمْلِكُونَ لاِنفُسِهِمْ ضَرّاً } أي : لا تقدر الآلهة أن تمتنع ممن أراد بها سوءاً { وَلاَ نَفْعاً } أي لا تقدر أن تسوق إلى نفسها خيراً .   ويقال : لا يملكون دفع مضرة ،   ولا جر منفعة .   { وَلاَ يَمْلِكُونَ مَوْتاً } يعني : لا يقدرون أن يميتوا أحداً { وَلاَ حياة } أي : ولا يحيون أحداً { وَلاَ نُشُوراً } يعني : بعث الأموات .   ويقال : ولا يملكون موتاً ،   يعني : الموت الذي كان قبل أن يخلقوا ،   ولا حياة ،   يعني : أن يزيدوا في الأجل ،   ولا نشوراً بعد الموت .   ويقال : { لاَّ يَمْلِكُونَ *** مَوْتاً وَلاَ حياة } يعني : أن يبقوا أحداً { وَلاَ نُشُوراً } يعني : أن يحيوه بعد الموت .   وإنما ذكر الأصنام بلفظ العقلاء ،   لأن الكفار يجعلونهم بمنزلة العقلاء ،   فخاطبهم بلغتهم .
