قوله تعالى : { وَهِىَ تَجْرِى بِهِمْ فِى مَوْجٍ } يعني : أمواجاً { كالجبال ونادى نُوحٌ ابنه } كنعان ،   وقرأ بعضهم : ابنها ،   يعني : ابن امرأته ،   وقرأ بعضهم : { ونادى نُوحٌ ابنه } بضم الألف ،   وهي بلغة طيىء .   ويقال : إنه لم يكن ابنه ،   ولكن كان ابن امرأته .   وقراءة العامة : { ونادى نُوحٌ ابنه } قالوا : { وَكَانَ } ابن نوح { فِى مَعْزِلٍ } يعني : في ناحية من السفينة ،   ويقال : من الجبل ،   { مَعْزِلٍ يابنى اركب مَّعَنَا } أسلم ،   واركب في السفينة معنا { وَلاَ تَكُن مَّعَ الكافرين } يعني : لا تثبت على الكفر ،   ولا تتخلف مع الكافرين .

قرأ عاصم : { مَعْزِلٍ يابنى اركب } بنصب الياء قرأ الباقون { مَعْزِلٍ يابنى اركب } بالكسر .   وقال أبو عبيدة : القراءة عندنا بالكسر ،   للإضافة إلى نفسه كما اتفقوا في قوله : { قَالَ يا بنى لاَ تَقْصُصْ رُءْيَاكَ على إِخْوَتِكَ فَيَكِيدُواْ لَكَ كَيْدًا إِنَّ الشيطان للإنسان عَدُوٌّ مُّبِينٌ } [ يوسف : 5 ] وفي لقمان : { يابنى إِنَّهَآ إِن تَكُ مِثْقَالَ حَبَّةٍ مِّنْ خَرْدَلٍ فَتَكُنْ فِى صَخْرَةٍ أَوْ فِى السماوات أَوْ فِى الأرض يَأْتِ بِهَا الله إِنَّ الله لَطِيفٌ خَبِيرٌ } [ لقمان : 16 ] وإنما فرق عاصم فيما يرى الألف الخفيفة الحقيقة التي في قوله اركب .
