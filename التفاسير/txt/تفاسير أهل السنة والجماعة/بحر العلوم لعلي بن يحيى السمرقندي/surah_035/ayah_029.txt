قوله عز وجل : { إِنَّ الذين يَتْلُونَ كتاب الله } يعني : يقرؤون القرآن .   ويقال : معناه يتبعون كتاب الله تعالى .   يقال : تلا يتلو إذا تبعه كقوله تعالى : { والقمر إِذَا تلاها } [ الشمس : 2 ] { وأقاموا الصلاة } يعني : أتموا الصلوات في مواقيتها { وَأَنْفَقُواْ مِمَّا رَزَقْنَاهُمْ } يعني : تصدقوا مما أعطيناهم من الأموال { سِرّاً وَعَلاَنِيَةً يَرْجُونَ تجارة لَّن تَبُورَ } يعني : لن تهلك ولن تخسر .   ومعناه : { يَرْجُونَ تجارة } رابحة وهي الجنة مكان الحياة الدنيا .
