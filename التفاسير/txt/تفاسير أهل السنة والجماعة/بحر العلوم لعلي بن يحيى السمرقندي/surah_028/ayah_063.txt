{ قَالَ الذين حَقَّ عَلَيْهِمُ القول } وجبت عليهم الحجة فوجب عليهم العذاب ويقال وجب عليهم القول وهو قوله { قَالَ اخرج مِنْهَا مَذْءُومًا مَّدْحُورًا لَّمَن تَبِعَكَ مِنْهُمْ لأَمْلأَنَّ جَهَنَّمَ مِنكُمْ أَجْمَعِينَ } [ الأعراف : 18 ] { رَبَّنَا هَؤُلاء الذين أَغْوَيْنَا أغويناهم } يعني : القادة يقولون ربنا هؤلاء الذين أضللنا يعني : السفلة أغويناهم { كَمَا غَوَيْنَا } أي : أضللناهم كما كنا ضالين .   ويقال : يقول الكافرون { رَبَّنَا هَؤُلاء الذين أَغْوَيْنَا } يعني : الشياطين .   فقالت الشياطين : أغويناهم .   يعني : أضللناهم كما غوينا ،   أي أضللنا { تَبَرَّأْنَا إِلَيْكَ } من عبادتهم { مَا كَانُواْ إِيَّانَا يَعْبُدُونَ } يعني : ما كانوا يأمرونا بعبادة الآلهة
