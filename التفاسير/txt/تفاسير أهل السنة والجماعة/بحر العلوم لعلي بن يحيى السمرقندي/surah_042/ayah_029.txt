قوله عز وجل : { وَمِنْ آياته } يعني : من علامات وحدانيته { خُلِقَ السماوات والأرض } يعني : خلقين عظيمين ،   لا يقدر عليهما بنو آدم ،   ولا غيرهم { وَمَا بَثَّ فِيهِمَا مِن دَابَّةٍ } يعني : ما خلق في السماوات والأرض من خلق أو بشر فيهما { وَهُوَ على جَمْعِهِمْ } يعني : على إحيائهم للبعث { إِذَا يَشَاء قَدِيرٌ } يعني : قادر على ذلك .   ويقال : { وَمَا بَثَّ فِيهِمَا مِن دَابَّةٍ } يعني : في الأرض خاصة كما قال : { يَخْرُجُ مِنْهُمَا الُّلؤْلُؤُ وَالمَرْجَانُ } [ الرحمن : 22 ] يعني : من أحدهما .
