قوله عز وجل : { وَيَوْمَ تَقُومُ الساعة يُقْسِمُ المجرمون } يعني : يحلف المشركون { مَا لَبِثُواْ } { غَيْرَ سَاعَةٍ } في الدنيا .

يقول الله عز وجل : كذلك كانوا يكذبون بالبعث كما أنهم كذبوا حيث قالوا { مَا لَبِثُواْ } يعني : في القبور غير ساعة ويقال : { كَذَلِكَ كَانُواْ يُؤْفَكُونَ } لأنهم يقولون مرة : { إِن لَّبِثْتُمْ إِلاَّ عَشْراً } [ طه : 103 ] ومرة يقولون : { لبثنا يوما أو بعض يوم } [ الكهف : 119 ] ومرة يقولون : مَا لَبِثْنَا غَيْرَ سَاعَةٍ فيقول الله تعالى : هكذا كانوا في الدنيا .
