قوله عز وجل : { مُّنِيبِينَ إِلَيْهِ } انصرف إلى قوله { فَأَقِمْ وَجْهَكَ } يعني : فأقبل بوجهك منيباً إليه .   ويجوز أن يخاطب الرئيس بلفظ الجماعة ،   لأن له أتباعاً .   وإنما يراد به هو وأتباعه كما قال : { يا أيها النبي إذا طلقتم النساء } [ الطلاق : 10 ] { مُّنِيبِينَ إِلَيْهِ } يعني : راجعين إليه من الكفر إلى التوحيد .   { واتقوه وَأَقِيمُواْ الصلاة } يعني : وأتموا الصلوات الخمس { وَلاَ تَكُونُواْ مِنَ المشركين } على دينهم .
