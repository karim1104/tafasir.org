{ قَالَ } الله تعالى { كَلاَّ } أي لا تخف .   وقال الزجاج : كلا رَدْعٌ وتنبيه ،   أي : لا يقدرون على ذلك { فاذهبا بئاياتنا } خاطب به موسى خاصة بأن يذهب مع أخيه إلى فرعون بآياتنا التسع { إِنَّا مَعَكُمْ مُّسْتَمِعُونَ } يعني : سامعين ،   وقد بيّن ذلك في موضع آخر وهو قوله : { قَالَ لاَ تَخَافَآ إِنَّنِى مَعَكُمَآ أَسْمَعُ وأرى } [ طه : 46 ] والاستماع سبب للسمع فيعبر به عنه .
