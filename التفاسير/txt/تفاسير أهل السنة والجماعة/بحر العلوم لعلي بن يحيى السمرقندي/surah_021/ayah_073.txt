ثم قال عز وجل : { وجعلناهم أَئِمَّةً } ،   يعني : قادة في الخير ؛ ويقال : أكرمناهم بالأمانة والنبوة .   { يَهْدُونَ بِأَمْرِنَا } ،   يعني : يدعون الخلق { بِأَمْرِنَا } إلى أمرنا وإلى ديننا .   { وَأَوْحَيْنَا إِلَيْهِمْ فِعْلَ الخيرات } ،   يعني : أمرناهم بالأعمال الصالحة ،   ويقال : بالدعاء إلى الله تعالى ،   أي قول لا إله إلا الله .   { وإقام الصلاة } ،   يعني : تمام الصلاة ،   { وإيتاء الزكاة }  ؛ يعني : الزكاة المفروضة وصدقة التطوع .   { وَكَانُواْ لَنَا عابدين } ،   يعني : مطيعين .
