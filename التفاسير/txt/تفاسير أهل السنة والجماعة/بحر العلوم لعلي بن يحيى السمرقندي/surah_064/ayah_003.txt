ثم قال عز وجل : { خُلِقَ السماوات والأرض بالحق } يعني : بالحق والحجة والثواب والعقاب .   { وَصَوَّرَكُمْ } يعني : خلقكم ،   { فَأَحْسَنَ صُوَرَكُمْ } يعني : خلقكم على أجمل صورة .   وهذا كقوله : { لَقَدْ خَلَقْنَا الإنسان في أَحْسَنِ تَقْوِيمٍ } [ التين : 4 ] وكقوله : { وَلَقَدْ كَرَّمْنَا بَنِي آدَمَ وحملناهم في البر والبحر ورزقناهم مِّنَ الطيبات وفضلناهم على كَثِيرٍ مِّمَّنْ خَلَقْنَا تَفْضِيلاً } [ الإسراء : 70 ] ثم قال : { وَإِلَيْهِ المصير } يعني : إليه المرجع في الآخرة ،   فهذا التهديد يعني : كونوا على الحذر .   لأن مرجعكم إليه .
