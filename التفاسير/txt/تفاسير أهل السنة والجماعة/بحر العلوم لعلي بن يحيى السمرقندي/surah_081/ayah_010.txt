قوله تعالى : { وَإِذَا الصحف نُشِرَتْ } يعني ؛ تطايرت الصحف ،   وهي الكتب التي فيها أعمال بني آدم .   قرأ ابن كثير وأبو عمرو { سجرت } و{ سعرت } مخففتين ،   و{ نشرت } مشددة .   وقرأ نافع وابن عامر وحفص عن عاصم : { سجرت } و{ سعرت } مشددتين و{ نشرت } مخففة .   وقرأ حمزة والكسائي : { سجرت } و{ نشرت } مخففتين و{ سعرت } مشددة .   فمن شددها فللتكثير ومن خففها فعلى غير التكثير .
