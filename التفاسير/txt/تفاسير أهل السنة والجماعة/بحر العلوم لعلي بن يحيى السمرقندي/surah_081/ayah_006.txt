{ وَإِذَا البحار سُجّرَتْ } يعني : فجرت بعضها إلى بعض فصارت بحراً واحداً ،   فملئت وكثر ماؤها كقوله : { والبحر المسجور } [ الطور : 6 ] يعني : الممتلئ ويقال : { سجرت } أي أحميت بالكواكب إذا تساقطت فيها .   وقال ابن عباس :  " إذا كان يوم القيامة كوَّر الله تعالى الشمس والقمر والنجوم في البحر ثم بعث الله تعالى عليها ريحاً دبوراً فتنفخها فتصير ناراً وهو قوله "  : { وَإِذَا البحار سُجّرَتْ } أي : أحميت .   وقال قتادة : { سجرت } أي : غار ماؤها ،   وقال الزجاج : وقد قيل إنه جعل مياهها ناراً يعذب بها الكفار ،   فهذه الأشياء الست التي ذكرها قبل النفخة الأخيرة ،   والتي ذكرها بعدها تكون بعد النفخة الأخيرة وهو قوله : { وَإِذَا النفوس زُوّجَتْ } .
