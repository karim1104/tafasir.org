{ وَإِذَا النفوس زُوّجَتْ } قال الكلبي ومقاتل : يعني : نفوس المؤمنين قرنت بالحور العين ،   ونفوس الكفار بالشياطين .   وقال عمر بن الخطاب رضي الله عنه : { وَإِذَا النفوس زُوّجَتْ } قال :  " الفاجر مع الفاجر ،   والصالح مع الصالح "  .   وقال أبو العالية الرياحي :  " قرنت الأجساد بالأرواح "  وقال القتبي الزوج القرين كقوله : { احشروا الذين ظَلَمُواْ وأزواجهم } [ الصافات : 22 ] يعني : قرناءهم .   ثم قال : { وَإِذَا النفوس زُوّجَتْ } أي : قرنت نفوس الكفار بعضها ببعض والعرب تقول : زوجت إبلي إذا قرنت بعضها ببعض ويقال : { وإذا النفوس زوجت } يعني : الأبرار مع الأبرار في زمرة والأشرار مع الأشرار في زمرة .
