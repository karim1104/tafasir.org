قوله تعالى : { وَأَنَّا مِنَّا المسلمون } يعني : المصدقين بوحدانية الله تعالى { وَمِنَّا القاسطون } يعني : العادلين عن طريق الهدى ؛ ويقال : { القاسطون } يعني : الجائرين .   يقال : قسط الرجل ،   إذا جار .   وأقسط ،   إذا عدل .   كقوله تعالى : { إِنَّ الله يُحِبُّ المقسطين } .   ثم قال : { فَمَنْ أَسْلَمَ } يعني : أقر بوحدانية الله تعالى وأخلص بالتوحيد له ،   { فَأُوْلَئِكَ تَحَرَّوْاْ رَشَداً } يعني : نوراً وتمنوا وقصدوا ثواباً .
