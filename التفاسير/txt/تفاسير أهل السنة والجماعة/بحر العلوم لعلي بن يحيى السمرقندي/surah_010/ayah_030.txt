ثم قال تعالى : { هُنَالِكَ تَبْلُواْ * كُلُّ نَفْسٍ } ،   قرأ حمزة والكسائي { تَتْلُواْ كل نفس } بالتاءين ،   يعني : عند ذلك تقرأ كل نفس برة أو فاجرة { مَّا أَسْلَفَتْ } ،   يعني : ما عملت من خير أو شر .   وهذا قوله : { يَوْمَ نَدْعُواْ كُلَّ أُنَاسٍ بإمامهم فَمَنْ أُوتِىَ كتابه بِيَمِينِهِ فأولئك يَقْرَءُونَ كتابهم وَلاَ يُظْلَمُونَ فَتِيلاً } [ لإسراء : 71 ] ويقال : تتلو يعني : تتبع ،   كقوله : { والقمر إِذَا تلاها } [ الشمس : 2 ] يعني : تبعها ،   والباقون { تَبْلُواْ } بالتاء والباء ،   يعني : عند ذلك تجد .   ويقال : تظهر ،   كقوله { يَوْمَ تبلى السرآئر } [ الطارق : 9 ] وقال القتبي : أي يختبر .   ثم قال : { وَرُدُّواْ إِلَى الله مولاهم الحق } ،   يعني : رجعوا في الآخرة إلى الله مولاهم الحق .   { وَضَلَّ عَنْهُم } ،   يعني : اشتغل عنهم آلهتهم بأنفسها { مَّا كَانُواْ يَفْتَرُونَ } يعني : يختلقون من الأوثان فلا يكون لهم شفاعة ويقال بطل افتراؤهم واضمحل .
