قوله تعالى : { أُولَئِكَ الذين يَعْلَمُ الله مَا في قُلُوبِهِمْ } من الضمير .   وقال الزجاج : معناه قد علم الله أنهم منافقون ،   والفائدة لنا أن اعلموا أنهم منافقون .   قال : ومعنى قوله : { وَتَوْفِيقاً } أي طلباً لما وافق الحق .   ثم قال تعالى : { فَأَعْرِضْ عَنْهُمْ } ولا تعاقبهم { وَعِظْهُمْ } بلسانك { وَقُل لَّهُمْ في أَنفُسِهِمْ قَوْلاً بَلِيغاً } يقول : خوفهم وهددهم إن فعلتم الثاني عاقبتكم .   قال مقاتل : تقدم إليه تقدماً وثيقاً ثم نسخ بقوله { يا أيها النبي جاهد الكفار والمنافقين واغلظ عَلَيْهِمْ وَمَأْوَاهُمْ جَهَنَّمُ وَبِئْسَ المصير } [ سورة التوبة : 73 ] .
