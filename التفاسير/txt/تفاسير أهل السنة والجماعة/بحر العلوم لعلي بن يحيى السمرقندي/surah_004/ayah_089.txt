ثم قال تعالى : { وَدُّواْ لَوْ تَكْفُرُونَ } أي ترجعون عن هجرتكم { كَمَا كَفَرُواْ } أي كما رجعوا { فتكونوا } أنتم وهم على الكفر { فِيهِ سواء } ومن هذا يقال في المثل : إن من أحرق يوماً كدسه يتمنى حرق أكداس الأمم ،   فكذلك الكفار كانوا يتمنون أن يكون الناس كلهم كفاراً ،   حتى يحترقوا معهم .   قال الله تعالى : { فَلاَ تَتَّخِذُواْ مِنْهُمْ أَوْلِيَاء } في الدين والنصرة { حتى يُهَاجِرُواْ في سَبِيلِ الله } حتى يتوبوا ويرجعوا إلى دار الهجرة بالمدينة { فَإِن تَوَلَّوْاْ } يعني : أبوا الهجرة { فَخُذُوهُمْ } يعني : فأسروهم { واقتلوهم حَيْثُ وَجَدتُّمُوهُمْ } يعني : أين وجدتموهم من الأرض { وَلاَ تَتَّخِذُواْ مِنْهُمْ وَلِيّاً وَلاَ نَصِيراً } في العون .
