ثم قال عز وجل : { فَأَمَّا الذين آمَنُواْ وَعَمِلُواْ الصالحات } أي الطاعات فيما بينهم وبين ربهم { فَيُوَفّيهِمْ أُجُورَهُمْ } أي يوفر لهم ثواب أعمالهم { وَيَزِيدَهُم مّن فَضْلِهِ } أي من رزقه في الجنة { وَأَمَّا الذين استنكفوا واستكبروا } عن عبادة الله تعالى { فَيُعَذّبُهُمْ عَذَاباً أَلُيماً } أي وجيعاً دائماً { وَلاَ يَجِدُونَ لَهُمْ مّن دُونِ الله } يعني من عذاب الله { وَلِيّاً } يعينهم { وَلاَ نَصِيراً } مانعاً يمنعهم .
