قوله تعالى : { يَسْأَلُكَ أَهْلُ الكتاب أَن تُنَزّلَ عَلَيْهِمْ كتابا مّنَ السماء } يعني جملة واحدة كما جاء به موسى عليه السلام .   ويقال : إن كعب بن الأشرف وفنحاص بن عازوراء وأصحابهما قالوا : لن نؤمن لك حتى تنزل علينا كتاباً تحمله الملائكة إلينا فتقرؤه .   قال الله تعالى لمحمد صلى الله عليه وسلم : { فَقَدْ سَأَلُواْ موسى أَكْبَرَ مِن ذلك } يعني إن هؤلاء من أصل أولئك القوم الذين { فَقَالُواْ } لموسى عليه السلام { أَرِنَا الله جَهْرَةً } يعني عياناً ،   وهم القوم الذين ساروا مع موسى عليه السلام إلى طور سيناء { فَأَخَذَتْهُمُ الصاعقة } أي أحرقتهم النار { بِظُلْمِهِمْ } أي بقولهم وسؤالهم { ثُمَّ اتخذوا العجل } أي ومع ذلك ،   قد عبدوا العجل وهم قوم موسى في حال غيبته { مِن بَعْدِ مَا جَاءتْهُمُ البينات } أي جاءهم موسى بالآيات والعلامات { فَعَفَوْنَا عَن ذلك } كله ولم نستأصلهم { وآتينا موسى سلطانا مبينا } أي حجة بينة ،   وهي اليد والعصا .
