وقوله تعالى : { والذين آمَنُواْ بالله وَرُسُلِهِ } يعني أقروا بوحدانية الله تعالى وصدقوا بجميع الرسل { وَلَمْ يُفَرّقُواْ بَيْنَ أَحَدٍ مّنْهُمْ } في الإيمان والتصديق ،   يعني لم يكفروا ولم يجحدوا بأحد من الأنبياء والرسل عليهم السلام ،   ويصدقون بجميع الكتب { أولئك } يعني أهل هذه الصفة { سَوْف نؤتّيهِمْ أُجُورَهُمْ } أي سنعطيهم ثوابهم في الجنة { وَكَانَ الله غَفُوراً } لذنوبهم { رَّحِيماً } بهم لما كان منهم في الشرك .   قرأ عاصم في رواية حفص : { يُؤْتِيهِمْ } بالياء ؛ وقرأ الباقون { نؤتيهم } بالنون .
