ثم قال عز وجل : { سَتَجِدُونَ آخَرِينَ يُرِيدُونَ أَن يَأْمَنُوكُمْ وَيَأْمَنُواْ قَوْمَهُمْ } وهم أسد وغطفان ،   كانوا إذا أتوا إلى النبي صلى الله عليه وسلم يقولون : آمنا بك ،   وإذا رجعوا إلى قومهم قالوا : آمنا بالعقرب والخنفساء .

 يقول : إنهم لم يريدوا بذلك تصديق النبي صلى الله عليه وسلم ،   وإنما أرادوا به الاستهزاء .   وقال مجاهد : هم ناس من أهل مكة ،   كانوا يأتون النبي صلى الله عليه وسلم ويسلمون رياء ،   ثم يرجعون إلى قريش فيرتكسون بالأوثان ،   ويريدون أن يأمنوا ها هنا وها هنا .

فذلك قوله تعالى : { كُلَّمَا رُدُّواْ إِلَى الفتنة } يقول : كلما دعوا إلى الشرك { أُرْكِسُواْ فِيِهَا } يقول : عادوا إليه ودخلوا فيه { فَإِن لَّمْ يَعْتَزِلُوكُمْ } في القتال { وَيُلْقُواْ إِلَيْكُمُ السلم } أي لم يلقوا إليكم الصلح { وَيَكُفُّواْ أَيْدِيَهُمْ } عن قتالكم ،   يعني إن لم يكفوا أيديهم { فَخُذُوهُمْ } يعني أسروهم { واقتلوهم حَيْثُ ثَقِفْتُمُوهُمْ } يعني : حيث أدركتموهم ووجدتموهم { وَأُوْلَئِكُمْ } يعني أهل هذه الصفة { جَعَلْنَا لَكُمْ عَلَيْهِمْ سلطانا } يعني : حجة { مُّبِيناً } أي حجة مبينة في القتال .
