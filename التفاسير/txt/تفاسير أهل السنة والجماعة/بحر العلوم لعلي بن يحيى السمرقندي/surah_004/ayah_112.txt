ثم قال : { وَمَن يَكْسِبْ خَطِيئَةً أَوْ إِثْماً } يعني عمل بالمعصية { ثُمَّ يَرْمِ بِهِ بَرِيئاً } قال مقاتل : وهو طعمة حين رمى بالدرع في دار الأنصاري واتهمه به ،   وهو قوله { ثُمَّ يَرْمِ بِهِ بَرِيئاً } .   وقال الضحاك : يعني به المنافقين حيث قالوا في عائشة رضي الله عنها قولاً عظيماً ،   فقال : { وَمَن يَكْسِبْ خَطِيئَةً أَوْ إِثْماً } بالمعاصي { ثُمَّ يَرْمِ بِهِ بَرِيئاً } يعني عائشة وصفوان .   ثم قال تعالى : { فَقَدِ احتمل بهتانا } يقول : فقد قال كذباً { وَإِثْماً مُّبِيناً } ذنباً طاهراً .
