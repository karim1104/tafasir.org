ثم قال عز وجل : { أولئك } ،   يعني : إبراهيم وموسى وإسماعيل وإدريس وسائر الأنبياء { الذين أَنْعَمَ الله عَلَيْهِم مّنَ النبيين مِن ذُرّيَّةِ *** ءادَمَ **وَمِمَّنْ حَمَلْنَا مَعَ نُوحٍ } من سائر الأنبياء وهم ولد نوح إلا إدريس ،   يعني : حملناهم على السفينة وهم في صلب نوح وأولاده ،   { وَمِن ذُرّيَّةِ إبراهيم وإسراءيل } وهو يعقوب ؛ { وَمِمَّنْ هَدَيْنَا } يعني : أكرمنا بالنبوة ،   ويقال : أكرمنا بالإسلام ،   { واجتبينا }  ؛ يعني : واصطفينا بعد هؤلاء .   { إذا تتلى عليهم آيات الرحمان } ،   يعني : القرآن ،   { خَرُّواْ سُجَّداً وَبُكِيّاً }  ؛ يعني : يسجدون ويبكون من خوف الله عز وجل .   بكيّ : جمع باكي .   وقوله : { سُجَّداً وَبُكِيّاً } منصوب على الحال ،   وقال بعضهم : { ***بُكِياً } مصدر بكى يبكي بكياً ،   وقال الزجاج : من قال مصدر فهو خطأ ،   لأن { لِلاْذْقَانِ سُجَّدًا } جمع ساجد { وَبُكِيّاً } عطف عليه فهو جمع باك .
