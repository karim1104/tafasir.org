{ قَالَ كذلك قَالَ رَبُّكَ هُوَ عَلَىَّ هَيّنٌ } ولكن الله عز وجل { قَالَ رَبُّكَ هُوَ عَلَىَّ هَيّنٌ } ،   يعني : خلقه عليَّ يسير { وَقَدْ خَلَقْتُكَ مِن قَبْلُ } يحيى { وَلَمْ تَكُ شَيْئاً } قرأ حمزة والكسائي { وَقَدْ خلقناك } بالألف مؤخرة والنون مقدمة والباقون { وَقَدْ خَلَقْتُكَ } وهو اختيار أبي عبيدة
