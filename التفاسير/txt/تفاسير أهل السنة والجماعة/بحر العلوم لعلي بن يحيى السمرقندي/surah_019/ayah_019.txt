{ قَالَ } لها جبريل : { إِنَّمَا أَنَاْ رَسُولُ رَبّكِ لاِهَبَ لَكِ غلاما زَكِيّاً } ،   يعني : ولداً صالحاً .   قرأ أبو عمرو ونافع في إحدى الروايتين { أَحْلَلْنَا لَكَ } بالياء ،   وقرأ الباقون { لاِهَبَ } .   فمن قرأ { ***لِيَهَبَ لك } ،   فمعناه ليهب الله لك ومن قرأ { رَبّكِ لاِهَبَ لَكِ } يكون فيه مضمر .   ومعناه : إنما أنا رسول ربك قال : { لاِهَبَ لَكِ غلاما زَكِيّاً } يعني : قال ربك وهذا اختيار أبي عبيدة ،   وهو موافق لخط المصاحف .
