ثم قال عز وجل : { قُلْ مَن كَانَ فِى الضلالة } يعني : قل يا محمد من كان في الكفر والشرك { فَلْيَمْدُدْ لَهُ الرحمن مَدّاً } يعني : يزيد له مالاً وولداً .   قوله : { فَلْيَمْدُدْ } هذا لفظ الأمر ،   ومعناه الخبر ،   وتأويله أن الله عز وجل جعل جزاء ضلالته أن يتركه فيها ،   ويمده فيها ،   كما قال { الله يَسْتَهْزِىءُ بِهِمْ وَيَمُدُّهُمْ فِي طغيانهم يَعْمَهُونَ } [ البقرة : 15 ] { حتى إِذَا رَأَوْاْ مَا يُوعَدُونَ } يعني في الآخرة من العذاب والثواب { إِمَّا العذاب } في الدنيا { وَإِمَّا الساعة } أي قيام الساعة { فَسَيَعْلَمُونَ } يعني : فسيعرفون يوم القيامة { مَنْ هُوَ شَرٌّ مَّكَاناً } يعني : صنيعاً في الدنيا ،   ومنزلاً في الآخرة { وَأَضْعَفُ جُنداً } يعني : أقل عدداً وقوة ومنعة أهم أم المؤمنون
