{ نَكَالَ الآخرة } عذاب الدنيا والآخرة ،   في الدنيا بالغرق وبالنار في الآخرة أو عذاب أول عمره وآخره أو الأول قوله { ما علمت لكم من إله غيري } [ القصص : 38 ] والآخر قوله { أنا ربكم الأعلى } وكان بينهما أربعون سنة   " ع "  أو ثلاثون وبقي بعد الآخرة ثلاثين سنة أو عذاب أول النهار وآخره بالنار { النار يُعْرَضون عليها غُدُوّا وعشيا } [ غافر : 46 ] .
