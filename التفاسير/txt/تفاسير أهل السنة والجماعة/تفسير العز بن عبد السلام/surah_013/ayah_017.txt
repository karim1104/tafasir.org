{ بقَدَرها } الكبير بقدره والصغير بقدره { رابياً } مرتفعاً { حلية } الذهب والفضة { أو متاع } الصفر والنحاس .   { زبد } خبث كزبد الماء الذي لا ينتفع به { جفاء } منتشفاً ،   أو جافياً على وجه الأرض ،   أو ممحقاً ومن قرأ { جُفالاً } أخذه من قولهم : انجفلت القدر إذا قذفت بزبدها .   شبه الله -تعالى- الحق بالماء وما خلص من المعادن فإنهما يبقيان للانتفاع بهما ،   وشبه الباطل بزبد الماء وخبث الحديد الذاهبين غير منتفع بهما .
