{ وبرزوا لله } ظهروا بين يديه في القيامة ،   والضعفاء : الأتباع والذين استكبروا : قادتهم .   { تَبَعا } في الكفر { مُغْنون } دافعون ،   أغنى عنه : دفع عنه الأذى وأغناه : أوصل إليه النفع { لو هدانا الله } إلى الإيمان لهديناكم إليه ،   أو إلى الجنة لهديناكم إليها ،   أو لو نجّانا من العذاب لنجيناكم منه .   { محيص } ملجأ ومنجى يقول بعضهم لبعض : إن قوماً جزعوا وبكوا ففازوا فيجزعون ويبكون ،   ثم يقولون : إن قوماً صبروا في الدنيا ففازوا فيصبرون فعند ذلك يقولون : { سواء علينا } الآية .
