{ خلقنا الإنسان } كل بني آدم اتفاقاً { نطفة } إذا اختلط ماء الرجل وماء المرأة فهما نطفة أو النطفة ماء الرجل فإذا اختلط في الرحم بماء المرأة صار أمشاجاً { أمشاج } اختلاط المائين أو ألوان  " ع "  قال الرسول صلى الله عليه وسلم ' ماء الرجل غليظ أبيض وماء المرأة رقيق أصفر ' وقيل نطفة الرجل حمراء وبيضاء ونطفة المرأة صفراء وخضراء أو الأمشاج العروق التي في النطفة أو الأطوار نطفة ثم علقة ثم مضغة ثم عظماً ثم كسوتها باللحم { نبتليه } نختبره بالخير والشرّ أو نختبره بشكره في السرّاء وصبره في الضرّاء أو نكلفه العمل بعد خلقه أو نأمره بالطاعة وننهاه عن المعصية أو فيه تقديره فجعلناه سميعاً بصيراً لنبتليه بالاختبار أو التكليف أو بالسمع والبصر .
