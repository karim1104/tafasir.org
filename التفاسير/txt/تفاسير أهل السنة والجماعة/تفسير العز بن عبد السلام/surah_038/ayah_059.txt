{ فوجٌ } يدخلونها قوم بعد قوم فالفوج الأول بنو إبليس والثاني بنو آدم  " ح "  ،   أو كلاهما بنو آدم الأول الرؤساء والثاني الأتباع أو الأول قادة المشركين ومطعموهم ببدر والثاني أتباعهم ببدر يقول الله -تعالى- للفوجِ الأول عن دخول الفوج الثاني { هذا فوجٌ مقتحمٌ معكم } فيقولون { لا مرحباً بهم } فيقول الفوج الثاني بل أنتم { لا مرحباً بكم } أو قالت الملائكة لبني إبليس { هذا فوج مقتحم } إشارة إلى بني آدم لما أدخلوا عليهم فقال بنو إبليس لا مرحباً بهم فقال بنو آدم بل أنتم لا مرحباً بكم { قدَّمتموه } شرعتموه وجعلتم لنا إليهدماً ،   أو قدمتم لنا هذا العذاب بإضلالنا عن الهدى ،   أو قدمتم لنا الكفر ،   الموجب لعذاب النار { فبئس القرار } بئس الدار النار .   { من قدَّم لنا هذا } من سنه وشرعه ،   أو من زينه { مرحبا } المرحب والرحب السعة ومنه الرحبة لسعتها معناه لا اتسعت لكم أماكنكم .
