{ قاسية } من القسوة وهو الصلابة و{ قَسِيّة } أبلغ من قاسية ،   أو بمعنى فاسدة { يُحرّفون الكلِم } بالتغيير والتبديل وسوء التأويل { حظاً } نصيبهم من الميثاق المأخوذ عليهم .   { خائنة } خيانة ،   أو فرقة خائنة { فاعف عنهم واصفح } { نسختها } { قاتلوا الذين لا يؤمنون } [ التوبة : 29 ] أو { وإما تخافن من قوم خيانة } [ الأنفال : 58 ] أو هي محكمة في العفو والصفح إذا رآه .
