{ إنّ المسلمين } قالت أم سلمة للرسول صلى الله عليه وسلم : ما للرجال يُذكَرون في القرآن ولا تذكر النساء فنزلت { المسلمين } المتذللين { والمؤمنين } المصدقين ،   أو المسلمين في أديانهم ،   والمسلم والمؤمن واحد ،   أو الإسلام الإقرار باللسان والإيمان التصديق بالقلب ،   أو الإسلام اسم الدين والإيمان التصديق به والعمل عليه .   { والقانتين } المطيعين ،   أو الداعين  " ع "  { والصادقين } في أيمانهم أو عهودهم { والصابرين } على أمر الله ونهيه ،   أو في البأساء والضراء { والخاشعين } المتواضعين لله ،   أو الخائفين منه ،   أو المصلين { والمتصدقين } بأنفسهم في طاعة الله ،   أو بأموالهم في الزكاة المفروضة أو بإعطاء النوافل بعد الفرض { والصائمين } عن المعاصي والقبائح أو الصوم الشرعي المفروض ،   أو رمضان وثلاثة أيام من كل شهر { فروجهم } عن الحرام والفواحش ،   أو منافذ الجسد كلها يحفظون السمع عن اللغو والخنا ' والأعين عن النظر إلى ما لا يحلّ ' والفروج عن الفواحش والأفواه عن قول الزور وأكل الحرام { والذّاكرين الله } باللسان أو التالين لكتابه ،   أو المصلين { مغفرة } لذنوبهم { وأجرا عظيما } لأعمالهم .
