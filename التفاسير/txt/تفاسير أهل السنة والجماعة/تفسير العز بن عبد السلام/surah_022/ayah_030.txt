{ حُرُمات الله } فعل المناسك ،   أو منهيات الإحرام { ما يُتلى عليكم } من { والمُنخنقة } إلى قوله { على النُّصُب } [ المائدة : 3 ] ،   أو { غير محلي الصيد وأنتم حُرُم } ،   [ المائدة : 1 ] { الرّجس من الأوثان } من للجنس ،   أو اجتنبوا منها رجسها وهو عبادتها { قول الزور } الشرك ،   أو الكذب ،   أو شهادة الزور ،   أو أعياد المشركين .
