{ الذين كفروا } عبدة الأوثان ،   أو كل كافر من كتابي أو مشرك إذا لم يكن ذمة أو عهد .   { فضربَ الرقاب } بالقتل صبراً عند القدرة ،   أو قتالهم بالسلاح واليدين .   { أثخنتموهم } ظفرتم بهم { فشُدّوا الوثاق } بالأسر { مَنّاً } بالعفو والإطلاق { فداء } بمال ،   أو أسير ،   أو بالبيع { الحرب أوزارها } أثقالها من السلاح .   الوزر الثقل ،   وزير الملك يحمل أثقاله ،   أو يضعون السلاح بالهزيمة ،   أو الموادعة ،   أو أوزار كفرهم بالإسلام ،   أو يظهر الإسلام على الدين كله ،   أو ينزل عيسى بن مريم .   وهي منسوخة بقوله { فشَرِّد بهم من خلفهم } [ الأنفال : 57 ] أو محكمة فتخير الإمام بين المن والفداء ،   والقتل والاسترقاق { لانتصر منهم } بالملائكة ،   أو بغير قتال { والذين قُتلوا } قيل قتلى أُحد .
