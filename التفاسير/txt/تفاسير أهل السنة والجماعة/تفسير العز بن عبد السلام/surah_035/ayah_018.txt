{ ولا تَزِرُ } لا تحمل نفس ذنوب أخرى ومنه الوزير لتحمله أثقال الملك بتدبيره { وإن تَدْعُ } نفس مثقلة بالذنوب إلى تحمل ذنوبها لم تجد من يحمل عنها شيئاً وإن كان المدعو للتحمل قريباً مناسباً ولو تحمل ما قبل تحمله لقوله -تعالى- { ولا تزر وازرة } { بالغيب } في السر حيث لا يراه أحد أو في التصديق بالآخرة .
