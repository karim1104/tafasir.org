{ الذين تتوفاهم الملائكة ظالمي أنفسهم } قيل نزلت فيمن أسلم بمكة ولم يهاجر فأخرجتهم قريش إلى بدر فقُتلوا { تتوفاهم } تقبض أرواحهم { ظالمي أنفسهم } بالمقام بمكة وترك الهجرة { فألقوا السّلَم } في خروجهم معهم { من سوء } كفر { بلى } علمكم أعمال الكفار ،   والسَّلَم : الصلح ،   أو الاستسلام ،   أو الخضوع .
