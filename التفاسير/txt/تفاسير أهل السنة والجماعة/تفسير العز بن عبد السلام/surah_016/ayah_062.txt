{ ما يكرهون } البنات { الحسنى } البنين ،   أو جزاء الحسنى { لا جَرَم } حقاً أو قطعاً ،   أو اقتضى فعلهم أن لهم النار [ أو ] بلى إن لهم النار { مَفرَطون } منسيون ،   أو مضيعون ،   أو مبعدون في النار ،   أو متروكون فيها أو مقدمون إليها ومنه ' أنا فرطكم على الحوض ' أي متقدمكم ،   { مُفْرِطون } مسرفون في الذنوب من الإفراط فيها ،   { مُفْرَطون } في الواجب .
