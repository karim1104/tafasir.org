{ للمُخَلَّفين } المنافقون ثلاثة أحدهم : لا يؤمن { سنعذبهم مرتين } [ التوبة : 101 ] والثاني : تابوا { عسى الله أن يتوب عليهم } [ التوبة : 102 ] فقبلت توبتهم والثالث : قوم بين الخوف والرجاء وهم المدعوون .   { إلى قوم أولي بأس } فارس ،   أو الروم ،   أو غطفان وهوازن بحنين ،   أو بنو حنيفة مع مسيلمة ،   أو قوم لم يأتوا بعد .
