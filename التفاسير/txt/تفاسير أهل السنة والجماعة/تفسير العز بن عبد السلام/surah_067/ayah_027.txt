{ زُلفة } قريباً أو عياناً { سِيئت وجوه الذين كفروا } ظهرت عليها المساءة لما شاهدوه أو ظهر عليها سمة تدل على كفرهم كقوله { وتَسْوَدُّ وجوه } [ آل عمران : 160 ] { تَدَّعون } تمترون فيه وتختلفون أو تسألون في الدنيا وتزعمون أنه لا يكون أو تستعجلون بالعذاب أو دعاؤهم بذلك لأنفسهم افتعال من الدعاء يقول لهم ذلك خزنة جهنم .
