{ يا أيها النبي } خوطب به وهو عام لأمته نزلت لما طلق الرسول صلى الله عليه وسلم حفصة فأوحي إليه أن يراجعها فإنها صوامة قوامة وهي من أزواجك في الجنة { لعدتهن } في الطهر من غير جماع وجمع الثلاث بدعة أو ليس ببدعة فإن طلقها حائضاً أو في طهر جماع وقع أو لا يقع { واتقوا الله } في المطلقات { لا تخرجوهن } في عدتهن { بفاحشة } الزنا فتخرج لإقامة الحد أو بُذَاء على أحمائها  " ع "  أو كل معصية لله أو خروجها من بيتها تقديره إلا أن يأتين بفاحشة بخروجهن { وتلك حدود الله } طاعته أو شروطه أو سننه وأمره { يتعدَّ حدود الله } لم يرض بها أو خالفها { ظلم نفسه } بترك الرضا لأنه يأثم به أو بإضراره بالمرأة بإيقاع الطلاق في غير الطهر المشروع { أمرا } بالرجعة اتفاقاً .
