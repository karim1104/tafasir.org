{ وُجْدِكم } سعتكم أو قوتكم أو طاقتكم أو مما تجدون { لتضيِّقوا عليهن } في المساكن أو النفقة { فإن أرضعن } أي المطلقات { فآتوهن } أجرة الرضاع لوجوب النفقة على الآباء { وائتمروا } تشاوروا أو تراضوا في إرضاع الولد إذا وقعت بينكما الفرقة { تعاسرتم } تضايقتم أو اختلفتم { فسترضع له أخرى } وإن اختلفا فطلبت الأم الإرضاع وامتنع الأب أو طلبه الأب فامتنعت الأم والولد لا يقبل ثدي غيرها أجبر الممتنع وإن أعسر الأب بالأجرة لزمها الإرضاع للولد .
