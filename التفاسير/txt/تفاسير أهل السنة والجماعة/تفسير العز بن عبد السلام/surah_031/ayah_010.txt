{ بغير عَمَد } وأنتم ترونها ،   أو بعمد لا ترونها .   { أنْ تَمِيدَ } تزول ،   أو تتحرك .   { وبَثّ } بسط ،   أو فرق { دابة } سمي به الحيوان لدبيبه والدبيب الحركة .   { فأنبتنا } الناس نبات الأرض فالكريم من دخل الجنة واللئيم من دخل النار ،   أو الأشجار والزروع { زوج } نوع { كريم } حسن أو الثمر الطيب ،   والنافع .
