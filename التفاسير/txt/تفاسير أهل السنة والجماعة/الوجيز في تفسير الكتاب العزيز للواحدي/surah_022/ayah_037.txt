{ لن ينال الله لحومها ولا دماؤها } كان المشركون يلطخون جدار الكعبة بدماء القرابين فقال الله تعالى { لن ينال الله لحومها ولا دماؤها } أي لن يصل إلى الله لحومها ولا دماؤها { ولكن يناله التقوى منكم } أي النيه والإخلاص وما أريد به وجه الله تعالى { لتكبروا الله على ما هداكم } إلى معالم دينه { وبشر المحسنين } الموحدين
