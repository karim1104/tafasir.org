{ وهو الذي خلق السماوات والأرض في ستة أيام } ذكرنا تفسيره في سورة الأعراف { وكان عرشه على الماء } يعني قبل خلق السموات والأرض { ليبلوكم } أي خلقها لكم لكي يختبركم بالمصنوعات فيها من آياته ليعلم إحسان المحسن وإساءة المسيء وهو قوله تعالى { أيكم أحسن عملا } أي أعمل بطاعة الله تعالى { ولئن قلت } للكفار بعد خلق الله السموات والأرض وبيان قدرته { إنكم مبعوثون من بعد الموت } كذبوا بذلك وقالوا { إن هذا إلا سحر مبين }
