{ ولا أقول لكم عندي خزائن الله } يعني مفاتيح الغيب وهذا جواب لقولهم اتبعوك في ظاهر ما نرى منهم وهم في الباطن على خلافك فقال مجيبا لهم { ولا أقول لكم عندي خزائن الله } غيوب الله { ولا أعلم الغيب } ما يغيب عني مما يسترونه في نفوسهم فسبيلي قبول ما ظهر منهم { ولا أقول إني ملك } جواب لقولهم { ما نراك إلا بشرا مثلنا } { ولا أقول للذين تزدري } تستصغر وتستحقر { أعينكم } يعني المؤمنين { لن يؤتيهم الله خيرا الله أعلم بما في أنفسهم } أي بضمائرهم وليس علي أن أطلع على ما في نفوسهم { إني إذا لمن الظالمين } إن طردتهم تكذيبا لهم بعد ما ظهر لي منهم الإيمان
