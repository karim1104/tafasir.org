{ ولما رجع موسى إلى قومه غضبان } عليهم { أسفا } حزينا لأن الله تعالى فتنهم { قال بئسما خلفتموني من بعدي } بئسما عملتم من بعدي حين اتخذتم العجل إلها وكفرتم بالله { أعجلتم أمر ربكم } أسبقتم باتخاذ العجل ميعاد ربكم يعني الأربعين ليلة وذلك أنه كان قد وعدهم أن يأتيهم بعد ثلاثين ليلة فلما لم يأتهم على رأس الثلاثين قالوا إنه قد مات { وألقى الألواح } التي فيها التوراة { وأخذ برأس أخيه } بذؤابته وشعره { يجره إليه } إنكارا عليه إذ لم يلحقه فيعرفه ما فعل بنو إسرائيل كما قال في سورة طه { قال يا هارون ما منعك إذ رأيتهم ضلوا ألا تتبعن } الآية فأعلمه هارون أنه إنما أقام بين أظهرهم خوفا على نفسه من القتل وهو قوله { قال ابن أم } وكان أخاه لأبيه وأمه ولكنه قال يا ابن أم ليرققه عليه { إن القوم استضعفوني } استذلوني وقهروني { وكادوا } وهموا أن { يقتلونني فلا تشمت بي الأعداء } يعني أصحاب العجل بضربي وإهانتي { ولا تجعلني } في موجدتك وعقوبتك لي { مع القوم الظالمين } الذين عبدوا العجل
