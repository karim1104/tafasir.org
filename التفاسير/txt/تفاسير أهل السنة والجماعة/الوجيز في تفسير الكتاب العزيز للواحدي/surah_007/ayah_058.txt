ثم ضرب مثلا للمؤمن والكافر فقال { والبلد الطيب } يعني العذب التراب { يخرج نباته بإذن ربه } وهذا مثل المؤمن يسمع القرآن فينتفع به ويحسن أثره عليه { والذي خبث } ترابه وأصله { لا يخرج } نباته { إلا نكدا } عسرا مبطئا وهو مثل الكافر يسمع القرآن ولا يؤثر فيه أثرا محمودا كالبلد الخبيث لا يؤثر فيه المطر { كذلك نصرف الآيات } نبينها { لقوم يشكرون } نعم الله ويطيعونه
