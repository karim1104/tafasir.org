{ ولما وقع عليهم الرجز } أي العذاب وهو ما كانوا فيه من الجراد وما ذكر بعده { قالوا يا موسى ادع لنا ربك بما عهد عندك } بما أوصاك به وتقدم إليك أن تدعوه به { لئن كشفت عنا الرجز لنؤمنن لك ولنرسلن معك بني إسرائيل } { إلى أجل هم بالغوه } يعني إلى الأجل الذي غرقهم فيه { إذا هم ينكثون } ينقضون العهد ولا يوفون
