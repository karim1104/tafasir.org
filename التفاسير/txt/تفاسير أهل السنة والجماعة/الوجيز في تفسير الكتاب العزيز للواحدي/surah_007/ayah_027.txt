{ يا بني آدم لا يفتننكم الشيطان } لا يخدعنكم ولا يضلنكم { كما أخرج أبويكم من الجنة ينزع عنهما لباسهما } أضاف النزع إليه وإن لم يتول ذلك لأنه كان بسب منه { إنه يراكم هو وقبيله } يعني ومن كان من نسله { إنا جعلنا الشياطين أولياء للذين لا يؤمنون } سلطناهم عليهم ليزيدوا في غيهم كما قال { أنا أرسلنا الشياطين على الكافرين } الآية
