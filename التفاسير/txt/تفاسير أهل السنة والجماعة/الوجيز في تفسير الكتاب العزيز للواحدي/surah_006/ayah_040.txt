{ قل } يا محمد لهؤلاء المشركين بالله { أرأيتكم } معناه أخبروني { إن أتاكم عذاب الله } يريد الموت { أو أتتكم الساعة } القيامة { أغير الله تدعون } أي أتدعون هذه الأصنام والأحجار التي عبدتموها من دون الله { إن كنتم صادقين } جواب لقوله { أرأيتكم } لأته بمعنى أخبروني كأنه قيل إن كنتم صادقين أخبروا من تدعون عند نزول البلاء بكم
