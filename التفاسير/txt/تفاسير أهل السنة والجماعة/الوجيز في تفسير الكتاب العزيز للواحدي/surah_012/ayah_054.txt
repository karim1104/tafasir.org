{ وقال الملك ائتوني به } بيوسف { أستخلصه لنفسي } أجعله خالصا لي لا يشركني فيه أحد { فلما كلمه } يوسف { قال إنك اليوم لدينا مكين } وجيه ذو مكانة { أمين } قد عرفنا أمانتك وبراءتك .   ثم سأله الملك أن يعبر رؤياه شفاها فأجابه يوسف بذلك فقال له ما ترى أن نصنع قال تجمع الطعام في السنين المخصبة ليأتيك الخلق فيمتارون منك بحكمك فقال من لي بهذا ومن يجمعه ؟ قال يوسف { اجعلني على خزائن الأرض } .
