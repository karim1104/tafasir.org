{ يا أيها الذين آمنوا لا تكونوا كالذين كفروا } أي المنافقين { وقالوا لإخوانهم } أي في شأن إخوانهم في النسب { إذا ضربوا في الأرض } أي سافروا فماتوا وهلكوا { أو كانوا غزى } جمع غاز فقتلوا { لو كانوا عندنا ما ماتوا وما قتلوا } تكذيبا منهم بالقضاء والقدر { ليجعل الله ذلك حسرة في قلوبهم } أي ليجعل ظنهم أنهم لو لم يحضروا الحرب لاندفع عنهم القتل { حسرة في قلوبهم } ينهى المؤمنين أن يكونوا كهؤلاء الكفار في هذا القول منهم ليجعل اللة ذلك حسرة في قلوبهم دون قلوب المؤمنين { والله يحيي ويميت } فليس يمنع الإنسان تحرزه من إتيان أجله
