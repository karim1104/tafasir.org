{ الله ولي الذين آمنوا } أي ناصرهم ومتولي أمورهم { يخرجهم من الظلمات } من الكفر والضلالة إلى الإيمان والهداية { والذين كفروا } أي اليهود { أولياؤهم الطاغوت } يعني رؤساءهم كعب بن الأشرف وحيي بن أخطب { يخرجونهم من النور } يعني مما كانوا عليه من الإيمان بمحمد عليه السلام قبل بعثه { إلى الظلمات } إلى الكفر به بعد بعثه
