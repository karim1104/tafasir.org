{ يسألونك عن الأنفال } الغنائم لمن هي نزلت حين اختلفوا في غنائم بدر فقال الشبان هي لنا لأنا باشرنا الحرب وقالت الأشياخ كنا ردءا لكم لأنا وقفنا في المصاف مع رسول الله صلى الله عليه وسلم ولو انهزمتهم لانحزتم إلينا فلا تذهبوا بالغنائم دوننا فأنزل الله تعالى { قل الأنفال لله والرسول } يضعها حيث يشاء من غير مشاركة فيها فقسمها بينهم على السواء { فاتقوا الله } بطاعته واجتناب معاصيه { وأصلحوا ذات بينكم } حقيقة وصلكم أي لا تخالفوا { وأطيعوا الله ورسوله } سلموا لهما في الأنفال فإنهما يحكمان فيها ما أرادا { إن كنتم مؤمنين }
