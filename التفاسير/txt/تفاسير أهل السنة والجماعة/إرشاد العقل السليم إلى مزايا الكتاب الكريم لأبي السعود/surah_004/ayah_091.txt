{ سَتَجِدُونَ آخَرِينَ يُرِيدُونَ أَن يَأْمَنُوكُمْ وَيَأْمَنُوا قَوْمَهُمْ } هم قومٌ من أسَد وغطَفانَ كانوا إذا أتَوا المدينةَ أسلموا وعاهَدوا ليأْمَنوا المسلمين فإذا رجعوا إلى قومهم ونكَثوا عُهودَهم ليأمَنوا قومَهم ،   وقيل : هم بنو عبدِ الدارِ وكان ديدنَهم ما ذكر { كُلَّمَا رُدُّوا إِلَى الفتنة } أي دُعوا إلى الكفر وقتالِ المسلمين { أُرْكِسُوا فِيِهَا } قُلبوا فيها أقبحَ قلْبٍ وأشنَعَه وكانوا فيها شراً من كل عدو شرّيرٍ  .

{ فَإِن لَمْ يَعْتَزِلُوكُمْ } بالكف عن التعرُّض لكم بوجه ما { وَيُلْقُوا إِلَيْكُمُ السّلم } أي لم يُلْقوا إليكم الصُلْحَ والعهدَ بل نَبَذوه إليكم { وَيَكُفُّوا أَيْدِيَهُمْ } أي لم يكفّوها عن قتالكم { فَخُذُوهُمْ واقتلوهم حَيْثُ ثِقِفْتُمُوهُمْ } أي تمكّنتم منهم  .

{ وَأُوْلَئِكُمْ } الموصوفون بما ذُكر من الصفات القبيحةِ { جَعَلْنَا لَكُمْ عَلَيْهِمْ سلطانا مُبِيناً } حُجةً واضحةً في الإيقاع بهم قتلاً وسبْياً لظهور عداوتِهم وانكشافِ حالِهم في الكفر والغدرِ وإضرارِهم بأهل الإسلامِ أو تسلطاً ظاهراً حيث أذِنّا لكم في أخذهم وقتلِهم .
