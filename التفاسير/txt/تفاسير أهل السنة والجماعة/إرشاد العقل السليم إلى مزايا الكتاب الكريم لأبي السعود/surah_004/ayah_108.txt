{ يَسْتَخْفُونَ مِنَ الناس } يستترون منهم حياءً وخوفاً من ضررهم { وَلاَ يَسْتَخْفُونَ مِنَ الله } أي لا يستحيون منه سبحانه وتعالى وهو أحقُّ بأن يُستحيا منه ويُخافَ من عقابه { وَهُوَ مَعَهُمْ } عالمٌ بهم وبأحوالهم فلا طريقَ إلى الاستخفاء منه سوى تركِ ما يستقبِحُه ويؤاخِذُ به { إِذْ يُبَيّتُونَ } يدبرون ويزورون { مَا لاَ يَرْضَى مِنَ القول } مِنْ رَمْي البريءِ والحلِفِ الكاذب وشهادةِ الزور { وَكَانَ الله بِمَا يَعْمَلُونَ } من الأعمال الظاهرةِ والخافية { مُحِيطاً } لا يعزُب عنه شيءٌ منها ولا يفوت .
