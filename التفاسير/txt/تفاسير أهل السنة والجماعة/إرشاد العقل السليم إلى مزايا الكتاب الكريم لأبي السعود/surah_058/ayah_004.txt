{ فَمَن لَمْ يَجِدْ } أيْ الرقبةَ { فَصِيَامُ شَهْرَيْنِ } أيْ فعليهِ صيامُ شهرينِ { مُتَتَابِعَيْنِ مِن قَبْلِ أَن يَتَمَاسَّا } ليلاً أوْ نهاراً عمداً أَوْ خطأً { فَمَن لَمْ يَسْتَطِعْ } أيْ الصيامَ لسببٍ منَ الأسبابِ { فَإِطْعَامُ سِتينَ مِسْكِيناً } لكُلِّ مسكينٍ نصفُ صاعٍ منْ بُرَ أَوْ صاعٌ منْ غيرِهِ ويجبُ تقديمُهُ عَلَى المسيسِ لكن لا يستأنفُ إنْ مسَّ في خلالِ الإطعامِ { ذلك } إِشارةٌ إِلى مَا مرَّ من البيانِ والتعليمِ للأحكامِ والتنبيُهُ عليهَا وَمَا فيهِ منْ معنى البُعدِ قَد مَرَّ سرُّهُ مِراراً ومحلُّه إمَّا الرفعُ عَلَى الابتداءِ أو النصبُ بمضمرٍ معللٌ بَما بعدَهُ أيْ ذلكَ واقعٌ أو فعلُنَا ذلكَ { لتُؤْمِنُوا بالله وَرَسُولِهِ } وتعملُوا بشرائعِهِ التي شرعَهَا لكُم وترفضُوا ما كنتُم عليه في جاهليتِكُم { وَتِلْكَ } إشارةٌ إِلى الأحكامُ المذكورةِ وما فيه من مَعْنى البُعدِ لتعظيمِها كما مَرَّ غيرَ مرةٍ { حُدُودَ الله } التِي لا يجوزُ تعدِّيهَا { وللكافرين } أي الذينَ لا يعملونَ بَها { عَذَابٌ أَلِيمٌ } عبرَ عنْهُ بذلكَ للتغليظِ عَلَى طريقةِ قولِهِ تَعَالَى : { وَمَن كَفَرَ فَإِنَّ الله غَنِيٌّ عَنِ العالمين } [ سورة آل عمران ،  الآية 97 ] .
