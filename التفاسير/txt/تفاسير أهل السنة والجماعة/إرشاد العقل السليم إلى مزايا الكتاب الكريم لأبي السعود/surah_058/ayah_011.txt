{ يا أيها الذين آمَنُوا إِذَا قِيلَ لَكُمْ تَفَسَّحُوا } أيْ توسعُوا وليفسحْ بعضُكُمْ عنْ بعضِ ولا تتضامُّوا منْ قولِهم أفسحْ عَنِّي أيْ تنحَّ  ، وقُرِئَ تفاسحُوا وقولِهِ تَعَالى :{ فِي المجالس } متعلقٌ بقيلَ وقُرِئََ في المجلسِ عَلى أنَّ المرادَ بِهِ الجنسُ وقيلَ : مجلسُ الرسولِ عليهِ الصلاةُ والسلامُ وكانُوا يتضامُّون تنافساً في القُربِ منهُ عليهِ الصلاةُ والسَّلامُ حِرْصاً على استماعِ كلامِهِ وقيلَ : هو المجلسُ منْ مجالسِ القتالِ وهيَ مركزُ الغُزاةِ كقولِهِ تَعَالى :{ مَقَاعِدَ لِلْقِتَالِ }[ سورة آل عمران ،  الآية : 121 ]  ،  قيلَ : كانَ الرجلُ يأتي الصفَّ ويقولُ : تفسحُوا فيأبَونَ لِحرصِهم عَلى الشهادةِ وقُرِئَ فِي المجلَسِ بفتح اللامِ فَهُو متعلقٌ بتفسحُوا قطعاً أيْ توسعُوا فِي جلوسِكم ولا تتضايقُوا فيه  ، { فافسحوا يَفْسَحِ الله لَكُمْ } أي فِي كلِّ ما تريدونَ التفسحَ فيهِ منَ المكانِ والرزقِ والصدرِ والقَبرِ وغيرِهَا { وَإِذَا قِيلَ انشزوا } أي انهضُوا للتوسعةِ عَلى المقبلينَ أوْ لِمَا أمرتمْ بِهِ منْ صلاةٍ أو جهادٍ أو غَيرِهِمَا منْ أعمالِ الخيرِ { فَانشُزُوا } فانهضُوا ولا تتثبطُوا ولا تفرطُوا وقرئَ بكسرِ الشينِ { يَرْفَعِ الله الذين آمَنُوا مِنكُمْ } بالنصرِ وحسنِ الذكرِ في الدُّنيا والإيواءِ إلى غُرفِ الجنانِ في الآخرةِ { والذين أُوتُوا العلم } منهُمْ خصوصاً { درجات } عالية بما جمعُوا منْ أثرتي العلمِ والعملِ فإنَّ العلمَ معَ علوِّ رتبتِه يقتضِي العملُ المقرونُ بهِ مزيدَ رفعةٍ لا يدركُ شأوَهُ العملُ العارِيُّ عَنْهُ وإنْ كانَ في غايةِ الصلاحِ  ، ولذلكَ يقتدى بالعالمِ في أفعالِه ولا يقتدَى بغيرِهِ وفي الحديثِ : «فضلُ العالمِ عَلى العابِدِ كفضلِ القمرِ ليلة البدرِ عَلى سائرِ الكواكبِ »  ، { والله بِمَا تَعْمَلُونَ خَبِيرٌ } تهديدٌ لمنْ لمْ يمتثل بالأمرِ وقُرِئَ يعملونَ بالياءِ التحتانيةِ .
