{ إِنَّ الذين آمَنُواْ } بالله ورسوله وبما جاءهم به { وَعَمِلُواْ الصالحات وَأَقَامُواْ الصلاة وَآتَوُا الزكاة } تخصيصُهما بالذكر مع اندراجهما في الصالحات لإنافتهما على سائر الأعمالِ الصالحة على طريقة ذكرِ جبريلَ وميكالَ عَقيبَ الملائكةِ عليهم السلام { لَهُمْ أَجْرُهُمْ } جملةٌ من مبتدإٍ وخبرٍ واقعةٌ خبراً لإنَّ أي لهم أجرُهم الموعودُ لهم وقولُه تعالى : { عِندَ رَبّهِمْ } حال من أجرهم ،   وفي التعرُّض لعنوان الربوبية مع الإضافة إلى ضميرهم مزيدُ لطفٍ وتشريفٍ لهم { وَلاَ خَوْفٌ عَلَيْهِمْ } من مكروه آتٍ { وَلاَ هُمْ يَحْزَنُونَ } من محبوبٍ فات .
