{ ثُمَّ بَعَثْنَا } عطفٌ على قوله تعالى : { ثُمَّ بَعَثْنَا مِن بَعْدِهِ رُسُلاً إلى قَوْمِهِمْ } [ يونس : الآية 74 ] عطفَ قصةٍ على قصة { مّن بَعْدِهِمْ } أي من بعد أولئك الرسلِ عليهم السلام { موسى وهارون } خُصّت بعثتُهما عليهما السلام بالذكر ولم يُكتفَ باندراج خبرِهما فيما أشير إليه إجمالاً من أخبار الرسل عليهم السلام مع أقوامهم وأُوثر في ذلك ضربُ تفصيلٍ إيذاناً بخطر شأنِ القصةِ وعِظَمِ وقعها كما في نبأ نوح عليه السلام { إلى فِرْعَوْنَ وَمَلإِيهِ } أي أشرافِ قومِه ،  وتخصيصُهم بالذكر لأصالتهم في إقامة المصالحِ والمُهمّات ومراجعةِ الكل إليهم في النوازل والملمات { بئاياتنا } أي ملتبسين بها وهي الآياتُ المفصّلات في الأعراف { فاستكبروا } الاستكبارُ ادعاءُ الكِبْر من غير استحقاقٍ والفاءُ فصيحة أي فأتيَاهم فبلغاهم الرسالةَ فاستكبروا عن اتباعهما وذلك قولُ اللعين لموسى عليه السلام : { أَلَمْ نُرَبّكَ فِينَا وَلِيداً وَلَبِثْتَ فِينَا مِنْ عُمُرِكَ سِنِينَ } [ الشعراء ،  الآية 18 ] الخ ،  { وَكَانُواْ قَوْماً مجْرِمِينَ } اعتراضٌ مقرِّرٌ لمضمون ما قبله أي كانوا معتادين لارتكاب الذنوبِ العظامِ فإن الإجرامَ مؤذنٌ بعظم الذنبِ ومنه الجِرمُ أي الجثة فلذلك اجترأوا على ما اجترأوا عليه من الاستهانة برسالةِ الله تعالى ،  وحملُ الاستكبارِ على الامتناع عن قَبول الآيات لا يساعده قولُه عز وعلا : { فَلَمَّا جَاءهُمُ الحق مِنْ عِندِنَا قَالُواْ إِنَّ هذا لَسِحْرٌ مُّبِينٌ }
