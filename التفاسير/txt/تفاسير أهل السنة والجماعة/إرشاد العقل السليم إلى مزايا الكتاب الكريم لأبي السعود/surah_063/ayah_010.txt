{ وَأَنفِقُوا مِمَّا رزقناكم } أي بعضَ ما أعطينَاكُم تفضلاً منْ غيرِ أنْ يكونَ حصولُهُ من جهتِكُم ادخاراً للآخرةِ { من قَبْلِ أَن يَأْتِي أَحَدَكُمُ الموت } بأنْ يشاهدَ دلائلَهُ ويعاينَ أماراتِهِ ومخايلَهُ ،  وتقديمُ المفعولِ على الفاعلِ لما مرَّ مراراً من الاهتمامِ بما قُدِّمَ والتشويقِ إلى ما أُخِّر { فَيَقُولُ } عند تيقنِه بحلولِهِ { رَب لَوْلا أَخَّرْتَنِي } أي أمهلتَنِي { إلى أَجَلٍ قَرِيبٍ } أي أمدٍ قصيرٍ { فَأَصَّدَّقَ } بالنصبِ على جوابِ التمنِي وقُرِئَ فأتصدقَ { وَأَكُن منَ الصالحين } بالجزمِ عطفاً على محلِّ فأصدقَ كأنه قيلَ إنْ أخرتنِي أصدقْ وأكنْ وقُرِئَ وأكونَ بالنصبِ عطفاً على لفظِهِ وقُرِئَ وأكونُ بالرفعِ أي وأنَا أكونَ ،  عِدة منه بالصلاحِ .
