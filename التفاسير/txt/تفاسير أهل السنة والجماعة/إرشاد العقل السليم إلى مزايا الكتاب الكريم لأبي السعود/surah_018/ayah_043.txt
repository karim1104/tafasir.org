{ وَلَمْ تَكُنْ لَّهُ } وقرئ بالياء التحتانية { فِئَةٌ يَنصُرُونَهُ } يقدِرون على نصره بدفع الإهلاكِ أو على رد المهلِك أو الإتيانِ بمثله ،  وجمعُ الضميرِ باعتبار المعنى كما في قوله عز وعلا : { يَرَوْنَهُمْ مّثْلَيْهِمْ } { مِن دُونِ الله } فإنه القادرُ على ذلك وحده { وَمَا كَانَ } في نفسه { مُنْتَصِراً } ممتنعاً بقوته عن انتقامه سبحانه .
