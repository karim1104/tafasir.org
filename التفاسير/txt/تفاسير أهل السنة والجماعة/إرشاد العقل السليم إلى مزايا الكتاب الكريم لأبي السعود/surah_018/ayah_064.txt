{ قَالَ } أي موسى عليه السلام { ذلك } الذي ذكرتَ من أمر الحوت { مَا كُنَّا نَبْغِ } وقرئ بإثبات الياء ،  والضميرُ العائد إلى الموصول محذوفٌ ،  أصلُه نبغيه أي نطلبه لكونه أَمارةً للفوز بالمرام { فارتدا } أي رجعا { على آثَارِهِمَا } طريقِهما الذي جاءا منه { قَصَصًا } يقُصان قَصصاً أي يتّبعان آثارَهما إتباعا أو مقتصّين حتى أتيا الصخرة .
