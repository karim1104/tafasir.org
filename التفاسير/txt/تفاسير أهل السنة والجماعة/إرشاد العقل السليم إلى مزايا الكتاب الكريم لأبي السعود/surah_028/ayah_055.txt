{ وَإِذَا سَمِعُواْ اللغو } من اللاغينَ { أَعْرَضُواْ عَنْهُ } عن اللَّغو تكرماً كقولِه تعالى : { وَإِذَا مَرُّواْ بِاللَّغْوِ مَرُّواْ كِراماً } [ سورة الفرقان ،  الآية72 ] { وَقَالُواْ } لهم { لَنَا أعمالنا وَلَكُمْ أعمالكم سلام عَلَيْكُمْ } بطريقِ المُتاركةِ والتَّوديعِ { لاَ نَبْتَغِي الجاهلين } لا نطلبُ صحبتَهم ولا نريدُ مخالطتَهم .
