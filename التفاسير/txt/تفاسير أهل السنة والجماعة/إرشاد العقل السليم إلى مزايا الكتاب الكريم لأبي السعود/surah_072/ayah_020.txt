{ قُلْ إِنَّمَا أَدْعُو } أي أعبدُ { رَبي وَلاَ أُشْرِكُ بِهِ } بربِّي في العبادةِ { أَحَدًا } فليسَ ذلكَ ببدعٍ ولا مستنكرٍ يوجبُ التعجبَ أو الإطباقَ على عداوتِي .   وقُرِئَ قالَ على أنَّه حكايةٌ لقولِه عليهِ الصَّلاةُ والسَّلامُ للمتراكمينَ عليهِ والأولُ هُو الأظهرُ والأوفقُ لقولِه تعالى : { قُلْ إِنّي لاَ أَمْلِكُ لَكُمْ ضَرّاً وَلاَ رَشَداً } .
