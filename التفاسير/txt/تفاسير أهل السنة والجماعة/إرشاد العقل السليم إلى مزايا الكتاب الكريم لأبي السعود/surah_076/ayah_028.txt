{ نحْنُ خلقناهم } لا غيرُنا { وَشَدَدْنَا أَسْرَهُمْ } أي أحكمنَا ربطَ مفاصلِهم بالأعصابِ .   { وَإِذَا شِئْنَا بَدَّلْنَا أمثالهم } بعدَ إهلاكِهم { تَبْدِيلاً } بديعاً لا ريبَ فيهِ هو البعثُ كما ينبئُ عنه كلمةُ إذَا أو بدَّلنا غيرَهُم ممن يطيعُ .   كقولِه تعالى : { يَسْتَبْدِلْ قَوْماً غَيْرَكُمْ } [ سورة التوبة ،  الآية 39 ] وإذَا للدلالةِ على تحققِ القُدرةِ وقوةِ الداعيةِ .
