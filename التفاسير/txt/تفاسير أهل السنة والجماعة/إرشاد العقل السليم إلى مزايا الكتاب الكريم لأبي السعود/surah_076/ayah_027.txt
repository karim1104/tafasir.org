{ إِنَّ هَؤُلاء } الكفرةَ { يُحِبُّونَ العاجلة } وينهمكونَ في لذاتِها الفانيةِ { وَيَذَرُونَ وَرَاءهُم } أي أمامَهم لا يستعدونَ أو ينبذون وراءَ ظُهورهم { يَوْماً ثَقِيلاً } لا يعبأونَ به ووصفُه بالثقل لتشبيه شدتِه وهولِه بثقل شيءٍ فادحٍ باهظٍ لحامله بطريقِ الاستعارةِ وهو كالتعليل لما أُمرَ به ونهيٌ عنه .
