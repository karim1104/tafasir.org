{ وقطعناهم } أي فرقنا بني إسرائيلَ { في الأرض } وجعلنا كل فِرقةٍ منهم في قُطر من أقطارها بحيث لا تخلو ناحيةٌ منها منهم تكملةً لأدبارهم حتى لا تكون لهم شوكةٌ ،  وقوله تعالى : { أُمَمًا } إما مفعولٌ ثانٍ لقطّعنا أو حال من مفعوله { منْهُمُ الصالحون } صفةٌ لأمماً أو بدلٌ منه وهم الذين آمنوا بالمدينة ومن يسير بسيرتهم { وَمِنْهُمْ دُونَ ذلك } أي ناسٌ دون ذلك الوصفِ أي منحطّون عن الصلاح وهم كَفرتُهم وفَسَقتُهم { وبلوناهم بالحسنات والسيئات } بالنعم والنقم { لَعَلَّهُمْ يَرْجِعُونَ } عما كانوا فيه من الكفر والمعاصي .
