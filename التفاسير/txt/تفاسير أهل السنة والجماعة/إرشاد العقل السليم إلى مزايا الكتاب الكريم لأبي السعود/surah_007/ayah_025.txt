{ قَالَ } أُعيد الاستئنافُ إما للإيذان بعدم اتصالِ ما بعده بما قبله كما في قوله تعالى : { قَالَ فَمَا خَطْبُكُمْ أَيُّهَا المرسلون } [ الحجر ،  الآية 87 ] إثرَ قوله تعالى : { قَالَ وَمَن يَقْنَطُ مِن رَحْمَةِ رَبّهِ إِلاَّ الضالون } [ الحجر ،  الآية 56 ] وقوله تعالى : { قَالَ أَرَأيْتَكَ هذا الذي كَرَّمْتَ عَلَيّ } [ الإسراء ،  الآية 62 ] بعد قوله تعالى : { قَالَ أَأسْجُدُ لِمَنْ خَلَقْتَ طِينًا } [ الإسراء ،  الآية 61 ] وإما لإظهار الاعتناءِ بمضمون ما بعده من قوله تعالى : { فِيهَا تَحْيَوْنَ وَفِيهَا تَمُوتُونَ وَمِنْهَا تُخْرَجُونَ } أي للجزاءِ كقوله تعالى : { مِنْهَا خلقناكم وَفِيهَا نُعِيدُكُمْ وَمِنْهَا نُخْرِجُكُمْ تَارَةً أخرى } [ طه ،  الآية 55 ] .
