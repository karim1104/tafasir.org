{ وَمِنْ آياته أَن يُرْسِلَ الرياح } أي الشَّمالَ والصَّبَا والجَنوبَ فإنَّها رياحُ الرَّحمةِ وأما الدَّبُورُ فريحُ العذابِ ومنه قولُه عليه الصَّلاة والسَّلام : ( اللهمَّ اجعلْهَا رياحاً ولا تجعلْها ريحاً ) وقرئ الرِّيحَ على إرادةِ الجنسِ { مبشرات } بالمطرِ { وَلِيُذِيقَكُمْ مّن رَّحْمَتِهِ } وهي المنافعُ التَّابعةُ لها وقيل : الخصبُ التَّابعُ لنزولِ المطرِ المسبَّبِ عنها أو الرَّوح الذي هو مع هبُوبِها .   واللامُ متعلقةٌ بيرسل والجملةُ معطوفةٌ على مبشِّراتٍ على المعنى كأنَّه قيل ليبشركم بها وليذيقَكم أو بمحذوفٍ يُفهم من ذكرِ الإرسالِ تقديرُه وليذيقكم وليكون كذا وكذا يُرسلها لا لأمرٍ آخرَ لا تعلق له بمنافعِكم { وَلِتَجْرِيَ الفلك } بسوقِها { بِأَمْرِهِ وَلِتَبْتَغُواْ مِن فَضْلِهِ } بتجارةِ البحرِ { وَلَعَلَّكُمْ تَشْكُرُونَ } ولتشكروا نعمةَ الله فيما ذُكر من الغاياتِ الجليلةِ .
