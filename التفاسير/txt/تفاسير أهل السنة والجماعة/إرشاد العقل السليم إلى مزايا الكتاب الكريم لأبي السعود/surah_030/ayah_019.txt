{ يُخْرِجُ الحي مِنَ الميت } كالإنسان من النطفة والطير من البيضة .   { وَيُخْرِجُ الميت مِنَ الحي } النُّطفةَ والبيضةَ من الحيوانِ { ويُحْيِي الأرض } بالنباتَ { بَعْدَ مَوْتِهَا } يُبسها { وكذلك } ومثلَ ذلك الإخراجُ { تُخْرَجُونَ } من قبورِكم .   وقرئ تَخرُجون بفتح التَّاءِ وضمِّ الرَّاءِ .   وهذا نوعُ تفصيلٍ لقوله تعالى { الله يبدأُُ الخلقَ ثم يُعيده }
