{ وَإِن يُكَذّبُوكَ } أي تموا على تكذيبكَ فلا تُبالِ بهم وبتكذيِبهم { فَقَدْ كَذَّبَ الذين مِن قَبْلِهِمْ } من الأممِ العاتيةِ { جَاءتْهُمْ رُسُلُهُم بالبينات } أي المعجزاتِ الظَّاهرةِ الدَّالةِ على نُبوُّتهم { وبالزبر } كصُحفِ إبراهيمَ { وبالكتاب المنير } كالتَّوارةِ والإنجيلِ والزَّبورِ على إرادةِ التَّفصيلِ دُون الجمعِ ويجوزُ أنْ يُرادَ بهما واحدٌ والعطفُ لتغايرِ العُنوانينِ
