{ إِنَّا أرسلناك بالحق } أي محقَّين أو محقّاً أنتَ أو إرسالاً مصحُوباً بالحقِّ ويجوزُ أنْ يتعلَّق بقوله { بَشِيراً وَنَذِيراً } أي بشيراً بالوعدِ الحقِّ ونذيراً بالوعيدِ الحقِّ { وَإِن مّنْ أُمَّةٍ } أي ما من أمةٍ من الأممِ الدَّارجةِ في الأزمنةِ الماضيةِ { إِلاَّ خَلاَ } أي مَضَى { فِيهَا نَذِيرٌ } من نبيَ أو عالمٍ يُنذرهم .   والاكتفاءُ بذكرهِ للعلمِ بأنَّ النَّذارةَ قرينةُ البشارةِ لاسيِّما وقد اقترنا آنِفاً ولأنَّ الإنذارَ هو الأنسبُ بالمقَامِ
