{ قُمِ } أي من مضجعكَ أوْ قُمْ قيامَ عَزْمٍ وَتصميمٍ { فَأَنذِرْ } أي افعلِ الإنذارَ وَأَحْدِثْهُ وقيلَ : أنذرْ قومَكَ كقولِه تعالَى : { وَأَنذِرْ عَشِيرَتَكَ الأقربين } [ سورة الشعراء ،   الآية 214 ] أو جميعَ النَّاسِ حسبَمَا ينبئُ عَنْهُ قولُه تعالى : { وَمَا أرسلناك إِلا كَافَّةً للناسِ بَشِيراً وَنَذِيراً } [ سورة سبأ ،   الآية 28 ] .
