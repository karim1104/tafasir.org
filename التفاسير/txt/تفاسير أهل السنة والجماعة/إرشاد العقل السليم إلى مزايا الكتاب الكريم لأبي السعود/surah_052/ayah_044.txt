{ وَإِن يَرَوْا كِسْفاً } قطعةً { مّنَ السماء ساقطا } لتعذيبِهم { يَقُولُوا } من فرطِ طغيانِهم وعنادِهم { سحاب مرْكُومٌ } أي هُم في الطغيانِ بحيثُ لو أسقطناهُ عليهم حسبَما قالُوا : { أَوْ تُسْقِطَ السماء كَمَا زَعَمْتَ عَلَيْنَا كِسَفًا } [ سورة الإسراء : الآية : 92 ] لقالُوا هذا سحابٌ تراكمَ بعضُه على بعضٍ يُمطرنا ولم يُصدِّقُوا أنه كِسَفٌ ساقطٌ للعذابِ .
