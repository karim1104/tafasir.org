{ وَإِذَا قِيلَ إِنَّ وعْدَ الله } أي ما وعدَهُ من الأمورِ الآتيةِ أو وعدُه بذلكَ { حَقّ } أي واقعٌ لا محالةَ أو مطابقٌ للواقعِ { والساعة } التي هيَ أشهرُ ما وعدَهُ { لاَ رَيْبَ فِيهَا } أي في وقوعِها .   وقُرِئَ والساعةَ بالنصبِ عطفاً على اسمِ إنَّ وقراءةُ الرفعِ للعطفِ على محلِّ إنَّ واسمِها .   { قُلْتُمْ } لغايةِ عُتوِّكُم { ما نَدْرِي مَا الساعة } أيْ أيُّ شيءٍ هي استغراباً لَها { إِن نظُنُّ إِلاَّ ظَنّاً } أيْ ما نفعلُ إلا ظناً  ، وقد مرَّ تحقيقُه في قولِه تعالى : { إِنْ أَتَّبِعُ إِلاَّ مَا يوحى إِلَيَّ }[ سورة الأنعام ،  الآية 50 ] وقيلَ : ما نعتقدُ إلا ظناً أي لا علماً وقيلَ : ما نحنُ إلا نظنُّ ظناً ،  وقيلَ : ما نظنُّ إلا ظناً ضعيفا ، ً ويردُّه قولُه تعالى { وَمَا نَحْنُ بِمُسْتَيْقِنِينَ } أي لإمكانِه فإنَّ مقابلَ الاستيقانِ مطلقُ الظنِّ لا الضعيفُ منه ولعلَّ هؤلاءِ غيرُ القائلينَ ما هيَ إلا حياتُنا الدُّنيا .
