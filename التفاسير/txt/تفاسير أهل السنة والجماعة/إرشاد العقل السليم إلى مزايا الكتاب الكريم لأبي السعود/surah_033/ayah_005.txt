{ ادعوهم لآبَائِهِمْ } أي أنسبُوهم إليهم وخُصُّوهم بهم .

وقولُه تعالى : { هُوَ أَقْسَطُ عِندَ الله } تعليلٌ له والضَّميرُ لمصدرِ ادعُوا كما في قولِه تعالى : { اعدلوا هُوَ أَقْرَبُ للتقوى } [ سورة المائدة ،  الآية8 ] وأقسطُ أفعلُ تفضيلٍ قُصد به الزيادةَ مطلقاً من القسطِ بمعنى العدلِ أي الدُّعاء لآبائِهم بالغٌ في العدلِ والصِّدقِ في حُكمِ الله تعالى وقضائِه { فَإِنْ لَمْ تَعْلَمُوا آبَاءَهُم } فتنسبُوهم إليهم { فَإِخوَانُكُمْ } فهم إخوانُكم { فِي الدين ومواليكم } وأولياؤكم فيه أي فادعُوهم بالأخوَّةِ الدِّينيةِ والمولوية { وَلَيْسَ عَلَيْكُمْ جُنَاحٌ } أي إثمٌ { فِيمَا أَخْطَأْتُمْ بِهِ } أي فيما فعلتمُوه من ذلك مخطئينَ بالسَّهوِ أو النِّسيانِ أو سبقِ اللِّسانِ { ولكن مَّا تَعَمَّدَتْ قُلُوبُكُمْ } أي ولكن الجناحُ فيما تعمَّدت قلوبُكم بعد النَّهي أو ما تعمَّدت قلوبُكم فيه الجناحَ { وَكَانَ الله غَفُوراً رحِيماً } لعفوهِ عن المخطئ وحكمُ التبنِّي بقولِه هو ابني إذا كان عبداً لقائلِ العتقِ على كلِّ حالٍ ولا يثبُت نسبُه منه إلاَّ إذا كان مجهولَ النَّسبِ وكان بحيثُ يُولد مثلُه لمثلِ المتبنِّي ولم يُقرَّ قبله بنسبِه من غيرهِ .
