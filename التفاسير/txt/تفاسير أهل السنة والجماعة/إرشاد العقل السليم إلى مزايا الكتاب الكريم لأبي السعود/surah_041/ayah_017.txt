{ وَأَمَّا ثَمُودُ فهديناهم } فدللناهُم على الحقِّ بنصبِ الآياتِ التكوينيةِ وإرسالِ الرسلِ وإنزالِ الآياتِ التشريعيةِ وأزحنَا عللَهمُ بالكليةِ وقد مرَّ تحقيقُ مَعنى الهُدى في تفسيرِ قولِه تعالى : { هُدًى للْمُتَّقِينَ } [ سورة البقرة ،  الآية2 ] .   وقُرِىءَ ثمودَ بالنصبِ بفعلِ يفسرُه ما بعدَهُ ومنوناً في الحالينِ وبضمِّ الثاءِ { فاستحبوا العمى عَلَى الهدى } أي اختارُوا الضلالةَ على الهدايةِ { فَأَخَذَتْهُمْ صاعقة العذاب الهون } داهيةُ العذابِ وقارعةُ العذابِ والهُون الهَوانُ وصفَ به العذابُ مبالغةً أو أُبدلَ منْهُ { بِمَا كَانُواْ يَكْسِبُونَ } منَ اختيارِ الضلالةِ
