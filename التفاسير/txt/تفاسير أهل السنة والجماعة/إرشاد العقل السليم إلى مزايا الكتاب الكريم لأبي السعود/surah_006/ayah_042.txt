وقولُه تعالى : { وَلَقَدْ أَرْسَلنَا } كلام مستأنفٌ مَسوقٌ لبيان أن منهم من لا يدعو الله تعالى عند إتيانِ العذاب أيضاً لتماديهم في الغيِّ والضلال لا يتأثرون بالزواجر التكوينية كما لا يتأثرون بالزواجر التنزيلية .   وتصديرُه بالجملة القَسَمية لإظهار مزيدِ الاهتمام بمضمونه ،   ومفعول ( أرسلنا ) محذوف لما أن مقتضى المقام بيانُ حال المرسَل إليهم لا حالِ المرسلين ،   أي وبالله لقد أرسلنا رسلاً { إلى أُمَمٍ } كثيرة { مِن قَبْلِكَ } أي كائنة من زمان قبلَ زمانك { فأخذناهم } أي فكذبوا رسلهم فأخذناهم { بالبأساء } أي بالشدة والفقر { والضراء } أي الضرر والآفات وهما صيغتا تأنيثٍ لا مذكر لهما { لَعَلَّهُمْ يَتَضَرَّعُونَ } أي لكي يدعُوا الله تعالى في كشفها بالتضرّع والتذلل ويتوبوا إليه من كفرهم ومعاصيهم .
