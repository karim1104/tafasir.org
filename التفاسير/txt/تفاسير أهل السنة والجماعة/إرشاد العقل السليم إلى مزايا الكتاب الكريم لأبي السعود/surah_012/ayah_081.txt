{ ارجعوا } أنتم { إلى أَبِيكُمْ فَقُولُواْ يا أَبَانَا إِنَّ ابنك سَرَقَ } على ظاهر الحالِ وقرىء سُرق أي نسب إلى السرقة { وَمَا شَهِدْنَا } عليه { إِلاَّ بِمَا عَلِمْنَا } وشاهدنا أن الصُواعَ استُخرجت من وعائه { وَمَا كُنَّا لِلْغَيْبِ } أي باطن الحال { حافظين } فما ندري أن حقيقةَ الأمرِ كما شاهدنا أم بخلافه ،  أو وما كنا عالمين حين أعطيناك المَوْثِقَ أنه سيسرِق أو أن نلاقيَ هذا الأمر أو أنك تصاب به كما أُصبت بيوسف .
