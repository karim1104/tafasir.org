{ عالم الغيب } أي الغائبِ عن الحس { والشهادة } أي الحاضرِ له عبر عنهما بهما مبالغةً ،  وقيل : أريد بالغيب المعدومُ وبالشهادة الموجودُ وهو خبرُ مبتدأ محذوفٍ أو خبرٌ بعد خبر ،  وقرئ بالنصب على المدح وهذا كالدليل على ما قبله من قوله تعالى : { الله يَعْلَمُ } الخ { الكبير } العظيمُ الشأنِ الذي كلُّ شيء دونه { المتعال } المستعلي على كل شيء بقدرته أو المنزَّهُ عن نعوت المخلوقات .
