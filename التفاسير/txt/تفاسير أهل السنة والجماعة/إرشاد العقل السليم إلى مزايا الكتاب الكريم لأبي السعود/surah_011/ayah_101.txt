{ وَمَا ظلمناهم } بأن أهلكناهم { ولكن ظَلَمُواْ أَنفُسَهُمْ } بأن جعلوها عُرضةً للهلاك باقتراف ما يوجبه { فَمَا أَغْنَتْ عَنْهُمْ } فما نفعتهم ولا دفعتْ بأسَ الله تعالى عنهم { التي يَدْعُونَ مِن } أي يعبدونها { دُونِ الله } أُوثر صيغةُ المضارعِ حكايةً للحال الماضيةِ أو دِلالةً على استمرار عبادتِهم لها { مِن شيء } في موضع المصدرِ أي شيئاً من الإغناء { لمَّا جَاء أَمْرُ رَبّكَ } أي حين مجيءِ عذابِه وهو منصوبٌ بأغنت ،  وقرىء آلهتُهم اللاتي ويُدْعَون على البناء للمجهول { وَمَا زَادُوهُمْ غَيْرَ تَتْبِيبٍ } أي إهلاك وتخسير فإنهم إنما هلكوا وخسِروا بسبب عبادتِهم لها .
