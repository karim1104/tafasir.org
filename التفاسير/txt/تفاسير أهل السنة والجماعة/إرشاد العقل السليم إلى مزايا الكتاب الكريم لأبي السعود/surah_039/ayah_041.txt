{ إِنَّا أَنزَلْنَا عَلَيْكَ الكتاب لِلنَّاسِ } لأجلِهم فإنَّه مناطُ مصالحِهم في المعاشِ والمعادِ { بالحق } حال من فاعل أنزلَنا أو من مفعولِه { فَمَن اهتدى } بأنْ عملَ بما فيه { فَلِنَفْسِهِ } أي إنَّما نفعَ به نَفسه { وَمَن ضَلَّ } بأنْ لم يعمل بموجبِه { فَإِنَّمَا يَضِلُّ عَلَيْهَا } لما أنَّ وبالَ ضلاله مقصورٌ عليها .

{ وَمَا أَنتَ عَلَيْهِم بِوَكِيلٍ } لتُجبرَهم على الهُدى ،  وما وضيفتُك إلاَّ البلاغُ وقد بلَّغت أيَّ بلاغٍ
