{ لكن الذين اتقوا رَبَّهُمْ لَهُمْ غُرَفٌ من فَوْقِهَا غُرَفٌ } وهم الذين خُوطبوا بقوله تعالى : { يَا عِبَادِ فاتقون } [ سورة الزمر ،  الآية16 ] ووُصفوا بما عُدِّد من الصِّفاتِ الفاضلةِ وهم المخاطَبون أيضاً فيما سبق بقوله تعالى : { قُلْ يا عبادي الذين آمَنُواْ اتقوا رَبَّكُمْ } [ سورة الزمر ،  الآية10 ] الآيةَ وبينَّ أنَّ لهم درجاتٍ عاليةً في جنَّاتِ النَّعيمِ بمقابلة ما للكفرةِ من دَرَكاتٍ سافلةٍ في الجحيم أي لهم علالي بعضُها فوقَ بعضٍ { مَّبْنِيَّةٌ } بناءَ المنازلِ المبنية المؤسَّسةِ على الأرضِ في الرَّصانةِ والإحكام { تَجْرِي مِن تَحْتِهَا } من تحت تلك الغرفِ { الأنهار } من غيرِ تفاوتٍ بين العُلوِّ والسُّفلِ { وَعَدَ الله } مصدرٌ مؤكّدٌ لقولِه تعالى لهم غُرف الخ فإنه وعدٌ وأيُّ وعدٍ { لاَ يُخْلِفُ الله الميعاد } لاستحالتِه عليه سبحانه .
