{ فَأَذَاقَهُمُ الله الخزي } أي الذُّلَّ والصَّغارَ { فِي الحياة الدنيا } كالمسخِ والخسفِ والقتلِ والسَّبي والإجلاءِ ونحوِ ذلك من فنون النَّكالِ .   { وَلَعَذَابُ الآخرة } المعدِّ لهم { أَكْبَرَ } لشدَّتِه وسرمدَّيتهِ { لَوْ كَانُواْ يَعْلَمُونَ } أي لو كانَ من شأنِهم أنْ يعلمُوا شيئاً لعلمُوا ذلكَ واعتبرُوا به .
