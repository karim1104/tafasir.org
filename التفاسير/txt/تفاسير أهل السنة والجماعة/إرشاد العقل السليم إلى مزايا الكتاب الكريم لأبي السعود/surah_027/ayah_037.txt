{ اْرجِعِ } أفردَ الضميرَ هَهُنا بعد جمعِ الضمائر الخمسةِ فيما سبقَ لاختصاصِ الرجوعِ بالرَّسولِ ،  وعموم الإمدادِ ونحوِه للكلِّ أي ارجعْ أَيُّها الرَّسُولُ { إِلَيْهِمُ } أي إلى بلقيسَ وقومِها { فَلَنَأْتِيَنَّهُم } أي فو الله لنأتينَّهم { بِجُنُودٍ لاَّ قِبَلَ لَهُمْ بِهَا } أي لا طاقةَ لَهمُ بمقاومتِها ولا قدرةَ لهم على مقابلتِها .   وقرئ بهم { وَلَنُخْرِجَنَّهُم } عطفٌ على جوابِ القسمِ { مِنْهَا } من سبأٍ { أَذِلَّةٍ } أي حالَ كونِهم أذلةً بعدما كانُوا فيه من العزِّ والتمكينِ .   وفي جمعِ القِلَّةِ تأكيدٌ لذِلَّتِهم .   وقولُه تعالى : { وَهُمْ صاغرون } أي أُسارَى مُهَانون ،  حالٌ أخرى مفيدةٌ لكونِ إخراجِهم بطريقِ الأسرِ لا بطريقِ الإجلاءِ .   وعدمُ وقوعِ جوابِ القسمِ لأنَّه كانَ معلَّقاً بشرطٍ قد حُذفَ عندَ الحكايةِ ثقةً بدلالةِ الحالِ عليه كأنَّه قيلَ ارجعْ إليهم فليأتُوا مسلمينَ وإلا فلنأتينَّهم الخ .
