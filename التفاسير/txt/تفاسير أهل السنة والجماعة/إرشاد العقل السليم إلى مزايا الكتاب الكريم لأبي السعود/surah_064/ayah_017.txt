{ إِن تُقْرِضُوا الله } بصرفِ أموالِكُم إلى المصارفِ التي عينها { قَرْضًا حَسَنًا } مقروناً بالإخلاصِ وطيبِ النفسِ { يضاعفه لَكُمْ } بالواحدِ عشرةً إلى سبعمائةٍ وأكثرَ .   وقُرِئَ يُضعّفهُ لكُم { وَيَغْفِرْ لَكُمْ } ببركةِ الإنفاقِ ما فرطَ منكُم من بعضِ الذنوبِ { والله شَكُورٌ } يَعطى الجزيلَ بمقابلةِ النزرِ القليلِ { حَلِيمٌ } لا يعاجلُ بالعقوبةِ مع كثرةِ ذنوبِكُم .
