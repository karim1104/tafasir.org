قوله تعالى : { كَمَا أَرْسَلْنَا فِيكُمْ } يعني من العرب { رَسُولاً مِّنكُمْ } يعني محمداً صلى الله عليه وسلم { يَتْلُوا عَلَيْكُمْ آيَاتِنَا } يعني القرآن .

{ وَيُزَكِّيكُمْ } فيه تأويلان :

أحدهما : يعني يطهركم من الشرك .

والثاني : أن يأمركم بما تصيرون به عند الله أزكياء .

{ وَيُعَلِّمُكُمُ الْكَتَابَ } فيه تأويلان :

أحدهما : القرآن .

والثاني : الإخبار بما في الكتب السالفة من أخبار القرون الخالية .

{ وَالحِكْمَةَ } فيها تأويلان :

أحدهما : السنّة .

والثاني : مواعظ القرآن .

{ وَيُعَلِّمُكُم مَّا لَمْ تَكُونُوا تَعْلَمُونَ } يعني من أحكام الدين وأمور الدنيا .
