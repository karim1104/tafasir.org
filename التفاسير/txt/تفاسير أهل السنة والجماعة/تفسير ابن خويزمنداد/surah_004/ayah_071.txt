42- قوله تعالى :  {  يَأَيُّهَا اَلذِينَ ءَامَنُواْ خُذُواْ حِذْرَكُمْ فَانفِرُواْ ثُبَاتٍ اَوِ ِانفِرُواْ جَمِيعًا } ( 71 ) .

47- ( ذكر ابن خويز منداد :  وقيل إن هذه الآية منسوخة بقوله تعالى :  {  اِنفِرُواْ خِفَافًا وَثِقَالاً }  وبقوله :  {  إِلاَّ تَنفِرُواْ يُعَذِّبْكُمْ } ؛  ولأن يكون {  اِنفِرُواْ خِفَافًا وَثِقَالاً } منسوخا بقوله :  {  فَانفِرُواْ ثُبَاتٍ اَوِ اِنفِرُواْ جَمِيعًا } وبقوله :  {  وَمَا كَانَ اَلْمُؤمِنُونَ لِيَنفِرُواْ كَافَّةً } أولى لأن فرض الجهاد تقرر على الكفاية ،  فمتى سَدَّ الثغور بعضُ المسلمين أسقط الفرض عن الباقين ) .
