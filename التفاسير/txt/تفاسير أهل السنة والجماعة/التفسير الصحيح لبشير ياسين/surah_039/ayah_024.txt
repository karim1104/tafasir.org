قوله تعالى {  أفمن يتّقي بوجهه سوءَ العذابِ يوم القيامة وقيل للظّالِمينَ ذوقوا ما كنتم تكسبون } :

أخرج الطبري بسنده الصحيح عن مجاهد في قوله {  أفمن يتقي بوجهه سوء العذاب } قال :  يخر على وجهه في النار ،  يقول :  هو مثل {  أفمن يلقى في النار خير أم من يأتي آمنا يوم القيامة } .

قال ابن كثير :  يقول تعالى {  أفمن يتقي بوجهه سوء العذاب يوم القيامة } ويقرع فيقال له ولأمثاله من الظالمين {  ذوقوا ما كنتم تكسبون } كمن يأتي آمنا يوم القيامة ؟  .  كما قال تعالى :  {  أفمن يمشي مكبا على وجهه أهدى أمن يمشي سويا على صراط مستقيم } وقال :  {  يوم يسحبون في النار على وجوههم ذوقوا مس سقر } وقال :  {  أفمن يلقى في النار خير أم من يأتي آمنا يوم القيامة } .
