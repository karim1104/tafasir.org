{ عَرَّضْتُمْ بِهِ مِنْ خِطْبَةِ ٱلنِّسَآءِ } التعريض: الإيماء والتلويح من غير كشف ولا تبيين.  { خِطْبَةِ }: أي تزويج.  (السر): هو ضد العلانية، وسر: نكاح، كقوله عز وجل { وَلَـٰكِن لاَّ تُوَاعِدُوهُنَّ سِرّاً } وسر كل شيء خياره.  { ٱلْمُوسِعِ } أي المكثر أي الغني.  { ٱلْمُقْتِرِ } أي المقل أي الفقير.
