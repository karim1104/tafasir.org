{ عَلَقَةٍ }: دم جامد، وجمعها علق.  { مُّضْغَةٍ }: هي لحمة صغيرة، سميت بذلك لأنها بقدر ما يمضغ.  { مُّخَلَّقَةٍ }: مخلوقة تامة. { وَغَيْرِ مُخَلَّقَةٍ } هي غير تامة، يعني السقط.  { أَرْذَلِ ٱلْعُمُرِ }: الهرم الذي ينقص قوته وعقله ويصيره إلى الخرف ونحوه.  { هَامِدَةً } أي ميتة يابسة { رَبَتْ }: انتفخت { بَهِيجٍ }: أي حسن يبهج من يراه، أي يسره. والبهجة: الحسن، والبهجة: السرور أيضا.
