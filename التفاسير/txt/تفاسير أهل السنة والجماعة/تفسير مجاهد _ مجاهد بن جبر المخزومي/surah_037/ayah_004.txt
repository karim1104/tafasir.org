أَنا أَبو القاسم عبد الرحمن بن الحسن بن أَحمد الهمذاني قال: نا إبراهيم بن الحسين بن علي الكسائي، قال: نا آدم ابن أَبي إِياس، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { وَٱلصَّافَّاتِ صَفَّا } [الآية: 1]. قال: يعني الملائكة. { فَٱلزَّاجِرَاتِ زَجْراً } [الآية: 2]. قال: يعني الملائكة، { فَٱلتَّالِيَاتِ ذِكْراً } [الآية: 3]. قالك يعني الملائكة.  أَنبا عبد الرحمن، قال نا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد: { وَيُقْذَفُونَ } قال: يرمون { مِن كُلِّ جَانِبٍ } [الآية: 8]. يعني: من كل مكان. { دُحُوراً } [الآية: 9]. قال: يعني مطرودين.  أَنا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح، عن مجاهد في قوله: { وَاصِبٌ } [الآية: 9]. قال: يعني دائم.
