أَنا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح عن مجاهد: { يَنْبُوعاً } [الآية: 90]. يعني: عيوناً. { أَوْ تُسْقِطَ ٱلسَّمَآءَ كَمَا زَعَمْتَ عَلَيْنَا كِسَفاً } يعني: السماءَ جميعاً. { أَوْ تَأْتِيَ بِٱللَّهِ وَٱلْمَلاۤئِكَةِ قَبِيلاً } [الآية: 92]. يعني بكل قبيل على حدة، { أَوْ يَكُونَ لَكَ بَيْتٌ مِّن زُخْرُفٍ } يعني: ذهب { وَلَن نُّؤْمِنَ لِرُقِيِّكَ حَتَّى تُنَزِّلَ عَلَيْنَا كِتَاباً نَّقْرَؤُهُ } [الآية: 93] من رب العالمين إِلى فلان بن فلان، لكل رجل صحيفة تصبح عند رأْسه يقرؤها.  أَنا عبد الرحمن، قال: نا إِبراهيم، قال: نا آدم، قال: نا ورقاءُ عن ابن أَبي نجيح عن مجاهد: { كُلَّمَا خَبَتْ زِدْنَاهُمْ سَعِيراً } [الآية: 97]. يقول: كلما أُطفئت أُوقدت.
