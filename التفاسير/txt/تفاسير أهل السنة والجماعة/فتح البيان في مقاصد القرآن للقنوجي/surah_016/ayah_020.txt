{ وَالَّذِينَ يَدْعُونَ مِن دُونِ اللّهِ لاَ يَخْلُقُونَ شَيْئًا وَهُمْ يُخْلَقُونَ ( 20 ) }

ثم شرع سبحانه في تحقيق كون الأصنام التي أشار إليها بقوله كمن لا يخلق عاجزة عن أن يصدر منها خلق شيء فلا تستحق عبادة فقال : { وَالَّذِينَ يَدْعُونَ } بالياء والتاء سبعيتان ،  أي الآلهة الذين يدعوهم الكفار { مِن دُونِ اللّهِ } سبحانه صفتهم هذه الصفات الثلاثة المذكورة المنافية للألوهية ،  وهي أنهم { لاَ يَخْلُقُونَ شَيْئًا } من المخلوقات أصلا لا كبيرا ولا صغيرا ولا جليلا ولا حقيرا .

{ وَهُمْ يُخْلَقُونَ } أي وصفهم أنهم يخلقون فكيف يتمكن المخلوق من أن يخلق غيره ؛ ففي هذه الآية زيادة بيان لأنه أثبت لهم صفة النقصان بعد أن سلب عنهم صفة الكمال بخلاف قوله : { أفمن يخلق كمن لا يخلق } فإنه اقتصر على مجرد سلب صفة الكمال .
