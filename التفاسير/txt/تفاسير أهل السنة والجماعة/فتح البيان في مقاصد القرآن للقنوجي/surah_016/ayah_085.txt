{ وَإِذَا رَأى الَّذِينَ ظَلَمُواْ الْعَذَابَ فَلاَ يُخَفَّفُ عَنْهُمْ وَلاَ هُمْ يُنظَرُونَ ( 85 ) } .

{ وَإِذَا رَأى } ،  أي : أبصر .  { الَّذِينَ ظَلَمُواْ } ،  أي : أشركوا وكفروا ،  { الْعَذَابَ } الذي يستحقونه بشركهم ،  وهو : عذاب جهنم ،  { فَلاَ يُخَفَّفُ } ذلك العذاب ، { عَنْهُمْ وَلاَ هُمْ يُنظَرُونَ } ،  أي : لا يمهلون ولا يؤخرون ليتوبوا ،  إذ لا توبة هنالك .
