{ قَالَ يَا قَوْمِ لِمَ تَسْتَعْجِلُونَ بِالسَّيِّئَةِ قَبْلَ الْحَسَنَةِ لَوْلَا تَسْتَغْفِرُونَ اللَّهَ لَعَلَّكُمْ تُرْحَمُونَ ( 46 ) قَالُوا اطَّيَّرْنَا بِكَ وَبِمَن مَّعَكَ قَالَ طَائِرُكُمْ عِندَ اللَّهِ بَلْ أَنتُمْ قَوْمٌ تُفْتَنُونَ ( 47 ) وَكَانَ فِي الْمَدِينَةِ تِسْعَةُ رَهْطٍ يُفْسِدُونَ فِي الْأَرْضِ وَلَا يُصْلِحُونَ ( 48 ) قَالُوا تَقَاسَمُوا بِاللَّهِ لَنُبَيِّتَنَّهُ وَأَهْلَهُ ثُمَّ لَنَقُولَنَّ لِوَلِيِّهِ مَا شَهِدْنَا مَهْلِكَ أَهْلِهِ وَإِنَّا لَصَادِقُونَ ( 49 ) }

{ قال } صالح للمكذبين : { يا قوم لم تستعجلون بالسيئة قبل الحسنة ؟ } قال مجاهد : أي بالعذاب قبل الرحمة .  والمعنى لم تؤخرون الإيمان الذي يجلب إليكم الثواب ؟ وتقدمون الكفر الذي يجلب إليكم العقوبة ؟ وقد كانوا لفرط كفرهم يقولون : ائتنا يا صالح بالعذاب ،  ووصف العذاب بأنه سيئة مجازا ،  إما لأن العقاب من لوازمه ،  أو لأنه يشبه في كونه مكروها .

{ لولا } هلا { تستغفرون الله } وتتوبون إليه من الشرك { لعلكم ترحمون ؟ } أي : رجاء أن ترحموا أو لكي ترحموا فلا تعذبوا ،  فإن استعجال الخير أولى من استعجال الشر ،
