والإشارة بقوله :

{ ذَلِكَ عَالِمُ الْغَيْبِ وَالشَّهَادَةِ الْعَزِيزُ الرَّحِيمُ ( 6 ) الَّذِي أَحْسَنَ كُلَّ شَيْءٍ خَلَقَهُ وَبَدَأَ خَلْقَ الإِنسَانِ مِن طِينٍ ( 7 ) ثُمَّ جَعَلَ نَسْلَهُ مِن سُلالَةٍ مِّن مَّاء مَّهِينٍ ( 8 ) ثُمَّ سَوَّاهُ وَنَفَخَ فِيهِ مِن رُّوحِهِ وَجَعَلَ لَكُمُ السَّمْعَ وَالأَبْصارَ وَالأَفْئِدَةَ قَلِيلا مَّا تَشْكُرُونَ ( 9 ) }

{ ذَلِكَ } إشارة إلى الله باعتبار اتصافه بتلك الأوصاف أي : ذلك الخالق المدبر { عَالِمُ الْغَيْبِ وَالشَّهَادَةِ } أي العالم بما غاب عن الخلق وما حضرهم ،  وفي هذا معنى التهديد لأنه سبحانه إذا علم بما يغيب وما يحضر ،  فهو مجاز لكل عامل بعمله ،  أو فهو يدبر الأمر بما تقتضيه حكمته { الْعَزِيزُ } القاهر الغالب { الرَّحِيمُ } بعباده
