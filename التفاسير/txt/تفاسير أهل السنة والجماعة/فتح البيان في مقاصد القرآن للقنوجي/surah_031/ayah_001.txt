بسم الله الرحمن الرحيم

{ الم ( 1 ) تِلْكَ آيَاتُ الْكِتَابِ الْحَكِيمِ ( 2 ) هُدًى وَرَحْمَةً لِّلْمُحْسِنِينَ ( 3 ) الَّذِينَ يُقِيمُونَ الصَّلَاةَ وَيُؤْتُونَ الزَّكَاةَ وَهُم بِالْآخِرَةِ هُمْ يُوقِنُونَ ( 4 ) أُوْلَئِكَ عَلَى هُدًى مِّن رَّبِّهِمْ وَأُوْلَئِكَ هُمُ الْمُفْلِحُونَ ( 5 ) وَمِنَ النَّاسِ مَن يَشْتَرِي لَهْوَ الْحَدِيثِ لِيُضِلَّ عَن سَبِيلِ اللَّهِ بِغَيْرِ عِلْمٍ وَيَتَّخِذَهَا هُزُوًا أُولَئِكَ لَهُمْ عَذَابٌ مُّهِينٌ ( 6 ) }

{ ألم } الله أعلم بمراده به ،  وقد تقدم الكلام على مثل فاتحة هذه السورة فلا نعيده
