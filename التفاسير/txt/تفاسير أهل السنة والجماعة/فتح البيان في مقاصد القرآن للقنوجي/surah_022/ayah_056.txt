{ الْمُلْكُ يَوْمَئِذٍ لِّلَّهِ يَحْكُمُ بَيْنَهُمْ فَالَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ فِي جَنَّاتِ النَّعِيمِ ( 56 ) وَالَّذِينَ كَفَرُوا وَكَذَّبُوا بِآيَاتِنَا فَأُوْلَئِكَ لَهُمْ عَذَابٌ مُّهِينٌ ( 57 ) وَالَّذِينَ هَاجَرُوا فِي سَبِيلِ اللَّهِ ثُمَّ قُتِلُوا أَوْ مَاتُوا لَيَرْزُقَنَّهُمُ اللَّهُ رِزْقًا حَسَنًا وَإِنَّ اللَّهَ لَهُوَ خَيْرُ الرَّازِقِينَ ( 58 ) لَيُدْخِلَنَّهُم مُّدْخَلًا يَرْضَوْنَهُ وَإِنَّ اللَّهَ لَعَلِيمٌ حَلِيمٌ ( 59 ) } .

{ الْمُلْكُ يَوْمَئِذٍ } أي السلطان الظاهر والاستيلاء التام يوم القيامة والتنوين عوض عن الجملة أي يوم يؤمنون أو يوم تزول مريتهم { لِّلَّهِ } سبحانه وحده لا منازع له فيه ولا مدافع له عنه { يَحْكُمُ } أي يفصل { بَيْنَهُمْ } مستأنفة أو هي حالية ،  ثم فسر هذا الحكم بقوله :

{ فَالَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ } كائنون { فِي جَنَّاتِ النَّعِيمِ } مستقرون في أرضها منغمسون في نعيمها فضلا من الله
