قوله تعالى: { ذٰلِكَ } أي: ذلك الذي ذكرنا من خلق بني آدم وإحياء الأرض وما في ضمن ذلك من أنواع الحِكَمِ حاصل بهذا السبب، وهو أن الله تعالى { هُوَ ٱلْحَقُّ } أي: الثابت [الوُجُود] القادر على إيجاد المعدوم وإعدام الموجود، { وَأَنَّهُ يُحْيِـي ٱلْمَوْتَىٰ وَأَنَّهُ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ }.  قوله تعالى: { وَأَنَّ ٱلسَّاعَةَ } أي: وليعلموا أن الساعة { آتِيَةٌ لاَّ رَيْبَ فِيهَا } في نفس الأمر، [أو هو] نفي في معنى النهي.  وفي قوله: { وَأَنَّ ٱللَّهَ يَبْعَثُ مَن فِي ٱلْقُبُورِ } دلالة على إنشاء الأجساد البالية يوم النشور.
