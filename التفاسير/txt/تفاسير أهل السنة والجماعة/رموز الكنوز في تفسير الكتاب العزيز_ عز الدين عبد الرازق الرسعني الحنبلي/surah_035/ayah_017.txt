قوله تعالى: { يٰأَيُّهَا ٱلنَّاسُ أَنتُمُ ٱلْفُقَرَآءُ إِلَى ٱللَّهِ } أي: المحتاجون إليه في رزقه ومغفرته ورحمته.  { وَٱللَّهُ هُوَ ٱلْغَنِيُّ } عن عبادتكم { ٱلْحَمِيدُ } عنكم بإحسانه إليكم.  وما بعده سبق تفسيره إلى قوله تعالى: { وَإِن تَدْعُ مُثْقَلَةٌ إِلَىٰ حِمْلِهَا } أي: نفس مثقلة بالذنوب إلى حملها الذي حملته { لاَ يُحْمَلْ مِنْهُ شَيْءٌ وَلَوْ كَانَ ذَا قُرْبَىٰ } أي: ولو كان المدعو ذا قرابة.  قال ابن عباس: يقول الأب والأم: يا بني احمل عني، فيقول: حسبي ما عليّ.  قال أهل المعاني: لما غضب الله عليهم في قوله تعالى: { إِن يَشَأْ يُذْهِبْكُـمْ } أتبعه الإنذار بيوم القيامة وذكر أهوالها فقال: { إِنَّمَا تُنذِرُ } ، كأن رسول الله صلى الله عليه وسلم أسمعهم ذلك، فلم ينفع، فنزل قوله تعالى: { إِنَّمَا تُنذِرُ }.
