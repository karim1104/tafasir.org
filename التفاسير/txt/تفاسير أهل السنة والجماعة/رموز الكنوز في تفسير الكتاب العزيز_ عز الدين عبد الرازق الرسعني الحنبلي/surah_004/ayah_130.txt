قوله: { وَإِنِ ٱمْرَأَةٌ خَافَتْ مِن بَعْلِهَا نُشُوزاً أَوْ إِعْرَاضاً } أي: خشيتْ من زوجها نشوزاً ترفعاً عليها، أو إعراضاً عنها لدمامة في خَلْقها، أو لذمامة في خُلُقها، أو لِكبَر، أو لملال وضجر، أو اشتغال بغيرها.  { فَلاَ جُنَاْحَ عَلَيْهِمَآ } أي: لا إثم عليهما { أَن يُصْلِحَا } أصله: يتصالحا، فأدغمت التاء في الصاد.  وقرأ أهل الكوفة: " يُصْلِحَا " بضم الياء وسكون الصاد وتخفيفها وكسر اللام من غير ألف، مِن أصلح يُصْلح.  والمعنى: لا بأس أن تطيب له نفساً ببعض صداقها، أو بإسقاط بعض حقوقها، أو بتخفيف نفقتها.  أخرج الترمذي من حديث ابن عباس قال: " خَشِيَتْ سَوْدَةُ أَنْ يُطَلِّقَهَا رَسُولُ الله صلى الله عليه وسلم، فَقَالَتْ: لا تُطَلِّقْني وَأَمْسِكْني، وَاجْعَلْ يَوْمِي لِعَائِشَةَ، فَفَعَلَ، فَنَزَلَتْ: { فَلاَ جُنَاْحَ عَلَيْهِمَآ أَن يُصْلِحَا بَيْنَهُمَا صُلْحاً وَٱلصُّلْحُ خَيْرٌ } فَمَا اصْطَلَحَا عَلَيْهِ مِنْ شَيْءٍ فَهُوَ جَائِزٌ ".  أخبرنا شيخ الإسلام موفق الدين أبو محمد، عبد الله بن أحمد بن محمد ابن قدامة المقدسي رضي الله عنه قراءة عليه وأنا أسمع بدمشق، والشيخ أبو بكر محمد بن سعيد بن الموفق النيسابوري بقراءتي عليه ببغداد قالا: أخبرنا أبو زرعة طاهر بن محمد بن طاهر المقدسي، أخبرنا أبو الحسن مكي بن منصور بن عِلان الكَرْجي، أخبرنا أبو بكر أحمد بن الحسن الحيري، حدثنا محمد بن يعقوب الأصم، أخبرنا الربيع، أخبرنا الشافعي، أخبرنا سفيان بن عيينة، عن الزهري، عن سعيد بن المسيب، " أن ابنة محمد بن مسلمة كانت عند رافع بن خديج، فكره منها أمراً، إما كِبَراً، وإما غيره، فأراد طلاقها، فقالت: لا تُطلِّقني، وأمسكني، واقسم لي ما بدا لك، فأنزل الله: { وَإِنِ ٱمْرَأَةٌ خَافَتْ مِن بَعْلِهَا نُشُوزاً أَوْ إِعْرَاضاً... } الآية ".  { وَٱلصُّلْحُ خَيْرٌ } أي: خير من الفُرْقة.  وقيل: خير من النشوز والإعراض.  قوله: { وَأُحْضِرَتِ ٱلأنْفُسُ ٱلشُّحَّ } أي: أُلزمته، والشُّحّ: البخل مع الحرص، فالمرأة تشح بحقها من زوجها، والزوج يشح بنفسه عليها لعدم ميله إليها.  { وَإِن تُحْسِنُواْ } أيها الأزواج بالصبر عليهن، والإحسان في العشرة إليهن، { فَإِنَّ ٱللَّهَ كَانَ بِمَا تَعْمَلُونَ خَبِيراً }.  قوله: { وَلَن تَسْتَطِيعُوۤاْ أَن تَعْدِلُواْ بَيْنَ ٱلنِّسَآءِ } يعني: في المحبة التي هي ميل القلب، { وَلَوْ حَرَصْتُمْ }؛ لأن ذلك لا يدخل تحت كسبكم.  أخرج الإمام أحمد من حديث عائشة قالت: " كَانَ رَسُولُ الله صلى الله عليه وسلم يَقْسِمُ بَيْنَ نِسَائِهِ فَيَعْدِلُ، ثمَّ يَقُولُ: اللهمّ هَذا فِعْلِي فيمَا أَمْلِكُ، فَلا تَلُمْني فيمَا تَمْلِكُ وَلا أَمْلِكُ " ، يريد بذلك صلى الله عليه وسلم ميله إلى عائشة، وإفراطه في محبتها من بين نسائه.  { فَلاَ تَمِيلُواْ } بالنفقة والقسم إلى التي تحبون { كُلَّ ٱلْمَيْلِ } ، فتذروا المرغوب عنها { كَٱلْمُعَلَّقَةِ } وهي التي ليست بذات بعل ولا مُطلَّقة. وفي مسند الإمام أحمد من حديث أبي هريرة عن النبي صلى الله عليه وسلم قال: " مَنْ كَانَ لَهُ امْرَأَتَانِ يَمِيلُ إلى إِحْدَاهُمَا عَلَى الأخْرَى جَاءَ يَوْمَ القِيَامَةِ يجرّ أحد شِقَّيْهِ ساقطاً أو مائلاً ".  قوله: { وَإِن تُصْلِحُواْ } يعني: تعدلوا في النفقة والقسم، { وَتَتَّقُواْ } الجور { فَإِنَّ ٱللَّهَ كَانَ غَفُوراً رَّحِيماً } رحمكم وغفر لكم ميل قلوبكم.  وقيل: المعنى: " وإن تُصْلِحوا " ما أفسدتموه وحملكم الميل عليه بالتوبة والاستغفار " وتتقوا " الجَوْر فيما تستقبلون في صحبتهن.  { فَإِنَّ ٱللَّهَ كَانَ غَفُوراً } لما كان منكم، { رَّحِيماً } بكم.  قوله تعالى: { وَإِن يَتَفَرَّقَا } يعني: الزوجين إذا لم يتفقا على الصلح، { يُغْنِ ٱللَّهُ كُلاًّ مِّن سَعَتِهِ } أي: يرزق كل واحد منهما من رزقه الواسع ما يغنيه، ومن الأزواج ما يرضيه، { وَكَانَ ٱللَّهُ وَاسِعاً } يسع رزقه جميع خلقه { حَكِيماً } فيما أمر به، ونهى عنه، وخوّف منه.
