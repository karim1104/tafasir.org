قوله تعالى: { فَلَمَّا جَآءَهُم مُّوسَىٰ بِآيَاتِنَا بَيِّنَاتٍ قَالُواْ مَا هَـٰذَآ إِلاَّ سِحْرٌ مُّفْتَرًى } أي: سحر تفتعله وتختلقه وتفتريه على الله، { وَمَا سَمِعْنَا بِهَـٰذَا } الذي تدعونا إليه وتأمرنا به { فِيۤ آبَآئِنَا ٱلأَوَّلِينَ } أي: حُدِّثنا بكونه فيهم.  وقوله: " في آبائنا " حال منصوبة عن " هذا " ، أي: كائناً في زمانهم.  { وَقَالَ مُوسَىٰ } وقرأ ابن كثير: " قال موسى " بغير واو، وهكذا هو في مصحف أهل مكة.  { رَبِّيۤ أَعْلَمُ بِمَن جَآءَ بِٱلْهُدَىٰ مِنْ عِندِهِ } أي: بالبيان الواضح، { وَمَن تَكُونُ لَهُ عَاقِبَةُ ٱلدَّارِ } أي: العاقبة المحمودة، وهي النصر في الدنيا والجنة في الآخرة.  وقرأ حمزة والكسائي: " يكون " بالياء، وقد ذُكر وعُلل فيما مضى.  { إِنَّهُ لاَ يُفْلِحُ ٱلظَّالِمُونَ } لا يسعد ولا ينجح المشركون.
