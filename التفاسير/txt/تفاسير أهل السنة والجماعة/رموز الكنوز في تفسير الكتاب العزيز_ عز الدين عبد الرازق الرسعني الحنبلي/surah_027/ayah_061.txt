قوله تعالى: { أَمَّن جَعَلَ } وما [بعده] بدل من [الفرقان: 60].  ومعنى: { جَعَلَ ٱلأَرْضَ قَرَاراً }: دحاها وسوّاها للاستقرار عليها، { وَجَعَلَ خِلاَلَهَآ } أي: فيما بينها { أَنْهَاراً وَجَعَلَ لَهَا رَوَاسِيَ } جبالاً ثوابت، { وَجَعَلَ بَيْنَ ٱلْبَحْرَيْنِ } العذب والملح { حَاجِزاً } مانعاً من قدرته، كقوله تعالى: [الفرقان: 53].
