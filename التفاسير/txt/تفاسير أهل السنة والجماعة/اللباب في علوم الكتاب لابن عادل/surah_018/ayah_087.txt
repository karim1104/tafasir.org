ثم قال ذو القرنين : { أَمَّا مَن ظَلَمَ } أي : ظلم نفسه ؛ بمعنى  "  كفر  "  لأنَّه ذكر في مقابلته : { وَأَمَّا مَنْ آمَنَ } ثم قال : { فَسَوْفَ نُعَذِّبُهُ } أي بقتله { ثُمَّ يُرَدُّ إلى رَبِّهِ فَيُعَذِّبُهُ } في الآخرة { عَذَاباً نُّكْرا } أي : منكراً فظيعاً .

وهو النار ،   والنار أنكر من القتل .
