قوله : { أَوَ لَمْ يَهْدِ لَهُمْ } يتبين لهم { أَهْلَكْنَا مِن قَبْلِهِمْ مِّنَ القرون يَمْشُونَ فِي مَسَاكِنِهِمْ } لما أعاد ذكر الرسالة أعاد ذكر التوحيد وقال : { أَوَلَمْ يَهْدِ لَهُمْ كَمْ أَهْلَكْنَا مِن قَبْلِهِمْ } وقوله { يَمْشُونَ فِي مَسَاكِنِهِمْ } أي مساكن المُهْلَكِينَ ( دلالة على حالتهم ) وأنتم تمشون فيها وتبصرونها { إِنَّ فِي ذَلِكَ لآيَاتٍ أَفَلاَ يَسْمَعُونَ } آيات الله وعِظَاته واعتبر السمع لأنهم ما كان لهم قوة الإدراك بأنفسهم والاستنباط بعقولهم فقال : «أفلا يسمعون » ( يعني ) ليس لكم درجة المتعلم الذي يسمع الشيء ويفهمه .
