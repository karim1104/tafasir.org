قوله : { وَإِذَا تتلى عَلَيْهِمْ آيَاتُنَا بَيِّنَاتٍ قَالُواْ مَا هذا } يعنون محمداً - صلى الله عليه وسلم - «إلاَّ رَجُلٌ يُريدُ أنْ يَصْدَّكُمْ عَمَّا كَانَ يَعْبُدُ آبَاؤُكُمْ » فعارضوا البرهانَ بالتقليد «وَقَالُوا مَا هَذَا إلاَّ إفْكٌ مُفْتَرى » يعنون القرآن وقيل : القول بالوحدانية «إفْكٌ مُفْتَرًى » كقوله تعالى في حقهم : { أَإِفْكاً آلِهَةً دُونَ الله تُرِيدُونَ } [ الصفات : 86 ] وكقولهم للرسول : { أَجِئْتَنَا لِتَأْفِكَنَا عَنْ آلِهَتِنَا } [ الأحقاف : 22 ] وعلى هذا فيكون قوله : { وَقَالَ الذين كَفَرُواْ } بدلاً وقالوا لِلْحَقِّ لَمَّا جَاءَهُمْ ؛ هذا إنكار للتوحيد وكان مختصاً بالمشركين ،   وأما إنكار القرآن والمُعْجِزة فكان متفقاً عليه بين المشركين وأهل الكتاب فقال تعالى : { وَقَالَ الذين كَفَرُواْ لِلْحَقِّ } على العموم .
