قوله تعالى : { كَذَلِكَ نَقُصُّ } الكاف إما نعت لمصدر محذوف ،   أو حال من ضمير ذلك المصدر المقدر ،   والتقدير : كقصّنا هذا النبأ الغريب نقص ،   و  "  مِن أنْبَاءِ  "  صفة لمحذوف هو مفعول  " نَقُصُّ "  أي : نقص نبأ من أنباء .

فصل

لمَّا ذكر قصة موسى - عليه السلام - مع فرعون ثم مع السامري قال : { كذلك نَقُصُّ عَلَيْكَ } من أخبار سائر الأمم وأحوالهم تكثيراً لشأنك وزيادةً في معجزاتك { وَقَدْ آتَيْنَاكَ مِن لَّدُنَّا ذِكْراً } يعني القرآن ( لقوله تعالى ) : { وهذا ذِكْرٌ مُّبَارَكٌ أَنزَلْنَاهُ } { وَإِنَّهُ لَذِكْرٌ }  { والقرآن ذِي الذكر }  { يا أيها الذي نُزِّلَ عَلَيْهِ الذكر } وفي تسمية القرآن بالذكر وجوه :

أحدها : أنه كتاب فيه ذكرُ ما يحتاج إليه الناس من أمور دينهم ودنياهم .

وثانيها : أنه يذكر أنواع آلاء الله ونعمائه ،   وفيه التذكير والموعظة .

وثالثها : فيه الذكر والشرف لك ولقومك كما قال : { وَإِنَّهُ لَذِكْرٌ لَّكَ وَلِقَوْمِكَ }   و سمى الله تعالى كل كتاب أنزله ذكراً فقال تعالى : { فاسألوا أَهْلَ الذكر }
