قوله تعالى : { إِنَّمَا يَنْهَاكُمُ الله عَنِ الذين قَاتَلُوكُمْ فِي الدين } أي : جاهدوكم على الدين { وَأَخْرَجُوكُم مِّن دِيَارِكُمْ } وهم عتاة أهل «مكة » ،   { وَظَاهَرُواْ } أي : عاونوا { على إِخْرَاجِكُمْ } وهم مشركو مكة { أَن تَوَلَّوْهُمْ وَمَن يَتَوَلَّهُمْ } أي : يتخذهم أولياء وأنصاراً وأحباباً { فأولئك هُمُ الظالمون } .
