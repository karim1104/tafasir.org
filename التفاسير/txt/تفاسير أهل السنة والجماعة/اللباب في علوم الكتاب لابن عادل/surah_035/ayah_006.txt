قوله : { إِنَّ الشيطان لَكُمْ عَدُوٌّ } لما قال تعالى : { وَلاَ يَغُرَّنَّكُمْ بالله الغرور } [ فاطر : 5 ] ذكر ما يمنع العاقل من الاغترار وقال : { الشيطان لَكُمْ عَدُوٌّ فاتخذوه عَدُوّا } ولا تسمعوا قوله .   وقوله : { فاتخذوه عَدُوّا } أي اعملوا ما يسوؤه وهو العمل الصالح .   ثم قال : { إِنَّمَا يَدْعُو حِزْبَهُ لِيَكُونُواْ } أي أشياعه { لِيَكُونُواْ مِنْ أَصْحَابِ السعير } ( و ) في الآية أشارة إلى معنى لطيف وهو أن من يكون له عدو فإما أنْ يُعَادِيَه مجازاةً له وإما أن يُرْضيه فلما قال تعالى : { إِنَّ الشيطان لَكُمْ عَدُوّ } أمرهم بالعداوة وأَشَارَ إلى أن الطريق ليس إلا هذا .   وأما الإرضاء فلا فائدة فيه لأنكم إنْ أَرْضَيْتمُوهُ واتَّبعتُمُوهُ فهو لا يؤدِّيكم إلا إلى السعير .
