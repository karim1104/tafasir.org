قوله : { إِنَّهُمْ يَكِيدُونَ كَيْداً } ،   أي : أنَّ أعداء الله يكيدون كيداً ،   أي : يمكرون بمحمد صلى الله عليه وسلم وأصحابه مكراً .

قيل : الكَيْدُ : إلقاء الشبهات ،   كقولهم : { إِنْ هِيَ إِلاَّ حَيَاتُنَا الدنيا } [ المؤمنون : 37 ] { مَن يُحيِي العظام وَهِيَ رَمِيمٌ } [ يس : 78 ] { أَجَعَلَ الآلهة إلها وَاحِداً } [ ص : 5 ] { لَوْلاَ نُزِّلَ هذا القرآن على رَجُلٍ مِّنَ القريتين عَظِيمٍ } [ الزخرف : 31 ] { فَهِيَ تملى عَلَيْهِ بُكْرَةً وَأَصِيلاً } [ الفرقان : 5 ] .

وقيل : الطعن فيه بكونه ساحراً ،   أو شاعراً ،   أو مجنوناً ،   حاشاه من ذلك صلى الله عليه وسلم .

وقيل : قصدهم قتله ،   لقوله تعالى : { وَإِذْ يَمْكُرُ بِكَ الذين كَفَرُواْ } [ الأنفال : 30 ] الآية .
