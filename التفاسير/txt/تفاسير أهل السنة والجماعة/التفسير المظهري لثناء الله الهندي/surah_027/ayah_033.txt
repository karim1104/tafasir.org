{ قالوا } مجيبين لها { نحن أولوا قوة }في القتال { وأولوا بأس شديد } عند الحرب قال مقاتل أرادوا بالقوة كثرة العدد وبالبأس شدة الشجاعة لما أن الاستشار منها دائرا بين الصلح والقتال وكان القتال أصعب الأمرين أجابوا بامتثال أمرها في القتال على خلاف ما قالت اليهود : { اذهب أنت وربك فقاتلا إنا هاهنا قاعدون } وهذا يدل على إجابة أمرها في الصلح بالطريق الأولى ولذلك خيروها في الأمرين حيث قالوا { والأمر } في الصلح والقتال وفي كل شيء موكل { إليك فانظري ماذا تأمرين } من المقاتلة والصلح ما استفهامية والجملة بتأويل المفرد مفعول لأنظري يعني فانظري وتأملي حتى يتعين لك أمرك الذي ينفعك نطيعك ونتبع رأيك
