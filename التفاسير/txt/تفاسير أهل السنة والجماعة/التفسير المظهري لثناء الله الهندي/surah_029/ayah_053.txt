{ ويستعجلونك بالعذاب } عطف على { قالوا لولا أنزل عليه } نزلت الآية حين قال النضر بن الحارث أمطر علينا حجارة من السماء { ولولا أجل مسمى } قال ابن عباس يعني ما وعدتك أن لا أعذب قومك ولا أستأصلهم وأؤخر عذابهم إلى يوم القيامة كما قال { بل الساعة موعدهم والساعة أدهى وأمر }  وقال الضحاك مدة أعمارهم لأنهم إذا ماتوا صاروا إلى العذاب وقيل يوم بدر { لجاءهم العذاب } عاجلا ( وليأتينهم ) العذاب وقيل الأجل { بغتة } فجأة في الدنيا كوقعة بدر أو في الآخرة عند نزول الموت بهم { وهم لا يشعرون } بإتيانه
