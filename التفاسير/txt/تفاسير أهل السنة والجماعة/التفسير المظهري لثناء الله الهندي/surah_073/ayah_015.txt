{ إنا أرسلنا إليكم } يا أهل مكة { رسولا } في الكلام التفات فإن فيما سبق من الكلام كان الخطاب مع النبي صلى الله عليه وسلم وذكر الكفار في قوله : { واصبر على ما يقولون } الخ إلى الغيبة وهذا خطاب مع الكفار وذكر النبي صلى الله عليه وسلم على الغيبة وفي هذا الكلام تأكيد لما سبق قال الله تعالى : { إنا سنلقي عليك قولا ثقيلا 5 } ومضمون هذه الآية إنا أرسلناك فمضمون الآيتين واحد .

{ شاهدا عليكم } بالإجابة أو الامتناع { كما أرسلنا } صفة لمصدر محذوف أي إرسالا كإرسالنا { إلى فرعون رسولا } يعن موسى عليه السلام .
