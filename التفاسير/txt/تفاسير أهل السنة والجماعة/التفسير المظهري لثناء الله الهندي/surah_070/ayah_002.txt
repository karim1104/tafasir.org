{ للكافرين ليس له دافع 2 }

أخرج بن المنذر عن الحسن قال : نزلت { سأل سائل بعذاب واقع 1 } فقال الناس على من يقع العذاب ؟ فأنزل الله عز وجل { للكافرين ليس له دافع 2 } الخ يكون السؤال للاستفهام فالباء في قوله تعالى : { بعذاب } بمعنى عن أو يكون تعديته بالباء لتضمن سأل معنى أهم { واقع } صفة لعذاب { للكافرين } صفة أخرى لعذاب أو صلة الواقع وإن كان السؤال عمن يقع به العذاب كان جوابا ليس له دافع صفة أخرى للعذاب أو هو في حيز الجواب أي واقع للكافرين { ليس له دافع من الله }
