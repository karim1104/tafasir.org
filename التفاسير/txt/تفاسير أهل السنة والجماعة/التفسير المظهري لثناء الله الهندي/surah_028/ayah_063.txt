{ قال الذين حق } أي وجب { عليهم القول } لوجوب مقتضاه والمراد بالقول : { لأملأن جهنم من الجنة والناس أجمعين }  وغيره من آيات الوعيد يعني قال رؤساء الكفار { ربنا هؤلاء } أي الأتباع مبتدأ خبره { الذين أغوينا } الضمير المنصوب العائد على الموصول محذوف ويعني أغويناهم { أغويناهم } فغووا { كما غوينا } الكاف صفة لمصدر فعل محذوف دل عليه أغويناهم تقديره فغووا غيا كما غوينا أي مثل ما غوينا وهو استئناف للدلالة على أنهم غووا باختيارهم مثل ما غوينا باختيارنا وإنا لم نفعل بهم إلا وسوسة وتسويلا وتسويلنا وإن كان داعيا لهم على الكفر فقد كان دعاء الله تعالى لهم بإقامة الحجج وبعث الرسل وإنزال الكتب أولي بالإتباع من تسويلنا وهذا كقوله تعالى : { وقال الشيطان لما قضي }  الآية ويجوز أن يكون الموصول صفة وأغويناهم الخبر لأجل ما أتصل به من المقدر والملفوظ أعني فغووا كما غوينا فأفاد زيادة على الصفة وهو وإن كان فضله لكنه صار من اللوازم { تبرأنا } منهم ومما اختاروا من الكفر هوى منهم { إليك } متعلق بتبرأ بتضمين معنى التوجه يعني تبرأنا منهم متوجهين إليك { ما كانوا إيانا يعبدون } أي ما كانوا يعبدوننا بل كانوا يعبدون أهواءهم وقيل ما مصدرية متصلة بتبرأنا أي تبرأنا من عبا دتهم إيانا
