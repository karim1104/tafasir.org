{ أَلَمْ تَرَ أَنَّ اللَّهَ يُولِجُ اللَّيْلَ فِي النَّهَارِ وَيُولِجُ النَّهَارَ فِي اللَّيْلِ وَسَخَّرَ } عطف على يولج أو حال بتقدير قد { الشمس والقمر كل } واحد من النيرين { يجري } في السماء { إلى أجل مسمى } أي وقت معين وهو يوم القيامة الفرق بينه وبين قوله لأجل مسمى أن الأجل منتهى الجري وثمة غرضه حقيقة أو مجازا وكلا المعنيين حاصل في الغايات { وأن الله بما تعملون خبير } عطف على قوله : { ألم تر أن الله يولج } وجملة ألم تر متصل بقوله : { ألم تروا أن الله سخر لكم ما في السماوات } مقرر له .
