{ قال } أبوهم { هل آمنكم عليه إلا كما أمنتكم على أخيه } يوسف { من قبل } هذا أي كيف آمنكم عليه وقد قلتم في يوسف { وإنا له لحافظون } وفعلتم به ما فعلتم { فالله خير } منكم ومن كل أحد { حافظا } فأتوكل عليه وأفوض أمري إليه { وهو أرحم الراحمين } فأرجو أن يرحمني بحفظه ولا يجمع علي مصيبتين ،  وانتصاب حفظا على التميز كذا قرأ الأكثرون بلفظ المصدر وقرأ حفص وحمزة والكسائي حافظا على وزن الفاعل وهو يحتمل الحال والتمييز كقولهم الله دره فارسا .
