{ كذبت قبلهم قوم نوح والأحزاب من بعدهم } أي الذين تحزبوا على الرسل وناصبوهم بعد قوم نوح كعاد وثمود يعني كذبوا نوحا وغيره من الرسل هذه معللة بقوله فلا يغررك { وهمت كل أمة } منهم { برسولهم ليأخذوه } قال ابن عباس أي ليقتلوه ويهلكوه وقيل ليأسروه والعرب يسمى الأسير أخيذا { وجادلوا بالباطل } أي بمثل قولهم { ما أنتم إلا بشر مثلنا } { ولولا أنزل علينا الملائكة أو نرى ربنا } ونحو ذلك { ليدحضوا } أي ليزيلوا ويبطلوا { به الحق فأخذتهم } بالإهلاك جزاء لهمهم عطف على جادلوا { فكيف كان عقاب } أي عقابي فإنكم تمرون على ديارهم وترون أثره والاستفهام للتقرير والتعجيب .
