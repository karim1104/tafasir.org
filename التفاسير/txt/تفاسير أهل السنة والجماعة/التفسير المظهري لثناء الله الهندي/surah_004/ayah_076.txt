{ الذين آمنوا يقاتلون في سبيل } موصل إلى { الله } يعني طاعته { والذين كفروا يقاتلون في سبيل الطاغوت } في طاعة الشيطان وسبيل يلحقهم بالشيطان في دركات جهنم { فقاتلوا } أيها المؤمنون { أولياء الشيطان } أي جنوده وهم الكفار ثم شجعهم بقوله : { إن كيد } أي مكر { الشيطان كان ضعيفا } فإنه لا يقدر إلا على الوسوسة قال يوم بدر للكفار { لا غالب لكم اليوم من الناس وإني جار لكم } لما رأى الملائكة هرب وخذلهم ونكص على عقبيه { وقال إني برئ منكم إني أرى ما لا ترون إني أخاف الله والله شديد العقاب } والله أعلم .
