{ فَانتَقَمْنَا مِنْهُمْ } يعني أخذناهم بالنقمة والعذاب بيانه { فَأَغْرَقْنَاهُمْ فِي الْيَمّ } أي البحر الذي لا يدرك قعره وهو لجة البحر المالح ومعظم مائه ،  واشتقاقه من التيمم لأن المشفعين به يقصدونه { بِأَنَّهُمْ } أي بسبب أنهم { كَذَّبُواْ بِآيَاتِنَا وَكَانُواْ عَنْهَا } أي عن الآيات { غَافِلِينَ } يعني أنهم لم يتفكروا فيها حتى صاروا كالغافلين عنها ،  وقيل : الضمير للنقمة المدلول عليها بقوله فانتقمنا
