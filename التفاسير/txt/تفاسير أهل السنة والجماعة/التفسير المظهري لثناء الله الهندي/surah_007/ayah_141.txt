{ و } اذكروا صنيعه معكم الآن { وإِذْ أَنجَيْنَاكُم } قرأ ابن عامر من الأفعال على الغيبة وهكذا في مصاحف أهل الشام والباقون على التكلم والتعظيم { مِّنْ آلِ فِرْعَونَ يَسُومُونَكُمْ } استئناف لبيان ما أنجاهم منه أو حال من المخاطبين أو من آل فرعون ومنها { سُوَءَ الْعَذَابِ يُقَتِّلُونَ } قرأ نافع بفتح الياء وإسكان القاف وضم التاء الفوقانية من المجرد والباقون بضم الياء وفتح القاف وكسر التاء مشددا من التفعيل للتكثير { أَبْنَاءكُمْ وَيَسْتَحْيُونَ نِسَاءكُمْ } جملة يقتلون مع ما عطف عليه بدل من يسومونكم مبين له { وَفِي ذَلِكُم } العذاب أو الإنجاء { بَلاء } محنة أو نعمة { مِّن رَّبِّكُمْ عَظِيمٌ } .
