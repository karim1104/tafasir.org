{ ثُمَّ بَعَثْنَا مِن بَعْدِهِم } الضمير للرسل في قوله ولقد جاءتهم رسلهم والمراد نوح وهود وصالح ولوط وشعيب عليهم السلام أو للأمم والمراد أقوامهم { مُّوسَى } بن عمران عليه السلام { بِآيَاتِنَا } يعني المعجزات التي تذكر بعد ذلك { إِلَى فِرْعَوْنَ } هو لقب لملك مصر ككسرى لملك فارس وكان اسمه قابوس وقيل : الوليد بن مصعب بن الريان { فرعون } أي شرفاء قومهم { فَظَلَمُواْ بِهَا } أي الآيات والظلم وضع الشيء في غير موضعه ،  ولما كانت الآيات لوضوحها من حقها الإيمان بها وهم كفروا بها مكان الإيمان ،  قال : الله تعالى{ فَظَلَمُواْ بِهَا } مكان كفرا بها { فَانظُرْ كَيْفَ كَانَ عَاقِبَةُ الْمُفْسِدِينَ } حيث أغرقوا في اليم
