{ مثل الفريقين }المؤمنين والكافرين { كالأعمى والأصم } فإنه مثل الكافر فإن الكفار لا يستطيعون السمع يعني سماع الحق سماع قبول وما كانوا يبصرون الهدى { والبصير السميع } وذلك مثل المؤمن : { يسمعون القول فيتبعون أحسنه }  ويبصرون بنور الله في قلوبهم ،  فالكافر مشبه بالجامع بين العمى والصمم والمؤمن بالجامع بين ضديهما ،  والعاطف لعطف الصفة على الصفة ولذلك قال : { هل يستويان } ولم يقل هل يستوون كذا قال : الفراء { مثلا } أي تمثيلا أو صفة أو حال { أفلا تذكرون155 } أي تتعظون بضرب الأمثال والتأمل فيها ،  فيه أدغمت التاء في الذال .
