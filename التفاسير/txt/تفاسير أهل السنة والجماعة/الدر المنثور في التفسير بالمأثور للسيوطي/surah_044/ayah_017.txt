أخرج ابن أبي حاتم ،   عن ابن عباس رضي الله عنهما في قوله : { ولقد فتنا } قال : بلونا .

وأخرج عبد بن حميد وابن جرير وابن المنذر ،   عن قتادة رضي الله عنه في قوله : { ولقد فتنا } قال : ابتلينا { قبلهم قوم فرعون وجاءهم رسول كريم } قال : هو موسى { أن أدوا إليَّ عباد الله } قال : يعني أرسلوا بني إسرائيل { وأن لا تعلوا على الله } قال : لا تعثوا { إني آتيكم بسلطان مبين } قال : بعذر مبين { وإني عذت بربي وربكم أن ترجمون } قال : بالحجارة { وإن لم تؤمنوا لي فاعتزلون } أي خلوا سبيلي .
