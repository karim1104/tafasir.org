وقوله : { وَالأرْضَ مَدَدْنَاهَا } أي : وسعناها وفرشناها ،   { وَأَلْقَيْنَا فِيهَا رَوَاسِيَ } وهي : الجبال ؛ لئلا تميد بأهلها وتضطرب ؛ فإنها مُقَرة على تيار الماء المحيط بها من جميع جوانبها ،   { وَأَنْبَتْنَا فِيهَا مِنْ كُلِّ زَوْجٍ بَهِيجٍ } أي : من جميع الزروع والثمار والنبات والأنواع ،   { وَمِنْ كُلِّ شَيْءٍ خَلَقْنَا زَوْجَيْنِ لَعَلَّكُمْ تَذَكَّرُونَ } [ الذاريات : 49 ] ،   وقوله : { بهيج } أي : حسن نضر .
