{ وَسُيِّرَتِ الْجِبَالُ فَكَانَتْ سَرَابًا } كقوله : { وَتَرَى الْجِبَالَ تَحْسَبُهَا جَامِدَةً وَهِيَ تَمُرُّ مَرَّ السَّحَابِ } [ النمل : 88 ] وكقوله : { وَتَكُونُ الْجِبَالُ كَالْعِهْنِ الْمَنْفُوشِ } [ القارعة : 5 ] .

وقال هاهنا : { فَكَانَتْ سَرَابًا } أي : يخيل إلى الناظر أنها شيء ،   وليست بشيء ،   بعد هذا تَذهب بالكلية ،   فلا عين ولا أثر ،   كما قال : { وَيَسْأَلُونَكَ عَنِ الْجِبَالِ فَقُلْ يَنْسِفُهَا رَبِّي نَسْفًا فَيَذَرُهَا قَاعًا صَفْصَفًا لا تَرَى فِيهَا عِوَجًا وَلا أَمْتًا } [ طه : 105 - 107 ] وقال : { وَيَوْمَ نُسَيِّرُ الْجِبَالَ وَتَرَى الأرْضَ بَارِزَةً } [ الكهف : 47 ] .
