ثم قالوا : { وَأَنَّهُ كَانَ يَقُولُ سَفِيهُنَا عَلَى اللَّهِ شَطَطًا } قال مجاهد ،   وعكرمة ،   وقتادة ،   والسدي : { سَفِيهُنَا } يعنون : إبليس ،   { شَطَطًا } قال السُّدِّي ،   عن أبي مالك : { شَطَطًا } أي : جورا .   وقال ابن زيد : ظلما كبيرا .

ويحتمل أن يكون المراد بقولهم : { سَفِيهُنَا } اسم جنس لكل من زعم أن لله صاحبة أو ولدا .   ولهذا قالوا : { وَأَنَّهُ كَانَ يَقُولُ سَفِيهُنَا } أي : قبل إسلامه { عَلَى اللَّهِ شَطَطًا } أي : باطلا وزورا ؛
