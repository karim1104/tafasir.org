{ فَإِذَا جَاءَتْهُمُ الْحَسَنَةُ } أي : من الخصب والرزق { قَالُوا لَنَا هَذِهِ } أي : هذا لنا بما نستحقه : ،   { وَإِنْ تُصِبْهُمْ سَيِّئَةٌ } أي : جدب وقحط { يَطَّيَّرُوا بِمُوسَى وَمَنْ مَعَهُ } أي : هذا بسببهم وما جاؤوا به .

{ أَلا إِنَّمَا طَائِرُهُمْ عِنْدَ اللَّهِ } قال علي بن أبي طلحة ،   عن ابن عباس : { أَلا إِنَّمَا طَائِرُهُمْ عِنْدَ اللَّهِ } يقول : مصائبهم عند الله ،   قال الله : { وَلَكِنَّ أَكْثَرَهُمْ لا يَعْلَمُونَ }

وقال ابن جُرَيْج ،   عن ابن عباس قال : { أَلا إِنَّمَا طَائِرُهُمْ عِنْدَ اللَّهِ } قال : إلا من قِبَل الله .
