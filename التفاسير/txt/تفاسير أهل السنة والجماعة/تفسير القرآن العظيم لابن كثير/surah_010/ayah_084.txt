ومما يدل على أنه لم يكن في بني إسرائيل إلا مؤمن قوله تعالى :

{ وَقَالَ مُوسَى يَا قَوْمِ إِنْ كُنْتُمْ آمَنْتُمْ بِاللَّهِ فَعَلَيْهِ تَوَكَّلُوا إِنْ كُنْتُمْ مُسْلِمِينَ ( 84 ) فَقَالُوا عَلَى اللَّهِ تَوَكَّلْنَا رَبَّنَا لا تَجْعَلْنَا فِتْنَةً لِلْقَوْمِ الظَّالِمِينَ ( 85 ) وَنَجِّنَا بِرَحْمَتِكَ مِنَ الْقَوْمِ الْكَافِرِينَ ( 86 ) }

يقول تعالى مخبرا عن موسى أنه قال لبني إسرائيل : { يَا قَوْمِ إِنْ كُنْتُمْ آمَنْتُمْ بِاللَّهِ فَعَلَيْهِ تَوَكَّلُوا إِنْ كُنْتُمْ مُسْلِمِينَ } أي : فإن الله كاف من توكل عليه ،   { أَلَيْسَ اللَّهُ بِكَافٍ عَبْدَهُ } [ الزمر : 36 ] ،   { وَمَنْ يَتَوَكَّلْ عَلَى اللَّهِ فَهُوَ حَسْبُهُ } [ الطلاق : 3 ] .

وكثيرا ما يقرن الله بين العبادة والتوكل ،   كما في قوله تعالى : { فَاعْبُدْهُ وَتَوَكَّلْ عَلَيْهِ } [ هود : 123 ] ،   { قُلْ هُوَ الرَّحْمَنُ آمَنَّا بِهِ وَعَلَيْهِ تَوَكَّلْنَا } [ الملك : 29 ] ،   { رَبُّ الْمَشْرِقِ وَالْمَغْرِبِ لا إِلَهَ إِلا هُوَ فَاتَّخِذْهُ وَكِيلا } [ المزمل : 9 ] ،   وأمر الله تعالى المؤمنين أن يقولوا في كل صلواتهم مرات متعددة : { إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ } [ الفاتحة : 5 ] .
