وقوله : { وَهُوَ الَّذِي أَحْيَاكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ إِنَّ الإنْسَانَ لَكَفُورٌ } ،   كقوله : { كَيْفَ تَكْفُرُونَ بِاللَّهِ وَكُنْتُمْ أَمْوَاتًا فَأَحْيَاكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ ثُمَّ إِلَيْهِ تُرْجَعُونَ } [ البقرة : 28 ] ،   وقوله : { قُلِ اللَّهُ يُحْيِيكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يَجْمَعُكُمْ إِلَى يَوْمِ الْقِيَامَةِ لا رَيْبَ فِيهِ } [ الجاثية : 26 ] ،   وقوله : { قَالُوا رَبَّنَا أَمَتَّنَا اثْنَتَيْنِ وَأَحْيَيْتَنَا اثْنَتَيْنِ } [ غافر : 11 ] ومعنى الكلام : كيف تجعلون [ مع ] الله أندادا وتعبدون معه غيره ،   وهو المستقل بالخلق والرزق والتصرف ،   { وَهُوَ الَّذِي أَحْيَاكُمْ } أي : خلقكم بعد أن لم تكونوا شيئًا يذكر ،   فأوجدكم { ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ } أي : يوم القيامة ،   { إِنَّ الإنْسَانَ لَكَفُورٌ } أي : جحود .
