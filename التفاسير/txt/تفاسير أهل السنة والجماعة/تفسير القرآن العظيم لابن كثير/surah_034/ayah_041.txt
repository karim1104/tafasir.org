وهكذا تقول الملائكة : { سُبْحَانَكَ } أي : تعاليتَ وتقدست عن أن يكون معك إله { أَنْتَ وَلِيُّنَا مِنْ دُونِهِمْ } أي : نحن عبيدك ونبرأ إليك من هؤلاء ،   { بَلْ كَانُوا يَعْبُدُونَ الْجِنَّ } يعنون : الشياطين ؛ لأنهم هم الذين يزينون لهم عبادة الأوثان ويضلونهم ،   { أَكْثَرُهُمْ بِهِمْ مُؤْمِنُونَ } ،   كما قال تعالى : { إِنْ يَدْعُونَ مِنْ دُونِهِ إِلا إِنَاثًا وَإِنْ يَدْعُونَ إِلا شَيْطَانًا مَرِيدًا } [ النساء : 117 ] .
