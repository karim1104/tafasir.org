يقول تعالى : { مِمَّا خَطايَاهُمْ } وقرئ : { خَطِيئَاتِهِمْ } { أُغْرِقُوا } أي : من كثرة ذنوبهم وعتوهم وإصرارهم على كفرهم ومخالفتهم رسولهم { أُغْرِقُوا فَأُدْخِلُوا نَارًا } أي : نقلوا من تيار البحار  إلى حرارة النار ،   { فَلَمْ يَجِدُوا لَهُمْ مِنْ دُونِ اللَّهِ أَنْصَارًا } أي : لم يكن لهم معين ولا مُغيث ولا مُجير ينقذهم من عذاب الله كقوله : { قَالَ لا عَاصِمَ الْيَوْمَ مِنْ أَمْرِ اللَّهِ إِلا مَنْ رَحِمَ } [ هود : 43 ] .
