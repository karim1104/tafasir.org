وقوله : { الَّذِي يَرَاكَ حِينَ تَقُومُ } أي : هو معتن بك ،   كما قال تعالى : { وَاصْبِرْ لِحُكْمِ رَبِّكَ فَإِنَّكَ بِأَعْيُنِنَا } [ الطور : 48 ] .

قال ابن عباس : { الَّذِي يَرَاكَ حِينَ تَقُومُ } يعني : إلى الصلاة .

وقال عكرمة : يرى قيامه وركوعه وسجوده .

وقال الحسن : { الَّذِي يَرَاكَ حِينَ تَقُومُ } : إذا صليت وحدك .

وقال الضحاك : { الَّذِي يَرَاكَ حِينَ تَقُومُ .   } أي : من فراشك أو مجلسك .

وقال قتادة : { الَّذِي يَرَاكَ } : قائما وجالسا وعلى حالاتك .
