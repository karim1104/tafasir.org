{ رَبَّنَا إِنَّنَا سَمِعْنَا مُنَادِيًا يُنَادِي لِلإيمَانِ } أي : داعيا يدعو إلى الإيمان ،   وهو الرسول صلى الله عليه وسلم { أَنْ آمِنُوا بِرَبِّكُمْ فَآمَنَّا } أي يقول : { آمِنُوا بِرَبِّكُمْ فَآمَنَّا } أي : فاستجبنا له واتبعناه { رَبَّنَا فَاغْفِرْ لَنَا ذُنُوبَنَا } أي : بإيماننا واتباعنا نبيك فاغفر لنا ذنوبنا ،   أي : استرها { وَكَفِّرْ عَنَّا سَيِّئَاتِنَا } أي : فيما بيننا وبينك { وَتَوَفَّنَا مَعَ الأبْرَارِ } أي : ألحقنا بالصالحين .
