ثم قال تعالى : { قُلْ آمَنَّا بِاللَّهِ وَمَا أُنزلَ عَلَيْنَا } يعني : القرآن { وَمَا أُنزلَ عَلَى إِبْرَاهِيمَ وَإِسْمَاعِيلَ وَإِسْحَاقَ وَيَعْقُوبَ } أي : من الصحف والوحي : { وَالأسْبَاطِ } وهم بطون بني إسرائيل المتشعبة من أولاد إسرائيل - هو يعقوب - الاثني عشر .   { وَمَا أُوتِيَ مُوسَى وَعِيسَى } يعني : بذلك التوراة والإنجيل { وَالنَّبِيُّونَ مِنْ رَبِّهِمْ } وهذا يَعُم جميعَ الأنبياء جملة { لا نُفَرِّقُ بَيْنَ أَحَدٍ مِنْهُمْ } يعني : بل نؤمن بجميعهم { وَنَحْنُ لَهُ مُسْلِمُونَ } فالمؤمنون من هذه الأمة يؤمنون بكل نبي أرسل ،   وبكل كتاب أنزل ،   لا يكفرون بشيء من ذلك بل هم مُصَدِّقون بما أنزل من عند الله ،   وبكل نبي بعثه الله .
