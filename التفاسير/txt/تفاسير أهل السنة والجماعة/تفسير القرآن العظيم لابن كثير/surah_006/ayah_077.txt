{ فَلَمَّا رَأَى الْقَمَرَ بَازِغًا } أي : طالعا { قَالَ هَذَا رَبِّي فَلَمَّا أَفَلَ قَالَ لَئِنْ لَمْ يَهْدِنِي رَبِّي لأكُونَنَّ مِنَ الْقَوْمِ الضَّالِّينَ فَلَمَّا رَأَى الشَّمْسَ بَازِغَةً قَالَ هَذَا رَبِّي } أي : هذا المنير الطالع ربي { هَذَا أَكْبَرُ } أي : جرمًا من النجم ومن القمر ،   وأكثر إضاءة .   : { فَلَمَّا أَفَلَتْ } أي : غابت ،   { قَالَ يَا قَوْمِ إِنِّي بَرِيءٌ مِمَّا تُشْرِكُونَ }
