وقوله : { وَتِلْكَ حُجَّتُنَا آتَيْنَاهَا إِبْرَاهِيمَ عَلَى قَوْمِهِ } أي : وجهنا حجته على قومه .

قال مجاهد وغيره : يعني بذلك قوله : { وَكَيْفَ أَخَافُ مَا أَشْرَكْتُمْ وَلا تَخَافُونَ أَنَّكُمْ أَشْرَكْتُمْ بِاللَّهِ مَا لَمْ يُنزلْ بِهِ عَلَيْكُمْ سُلْطَانًا فَأَيُّ الْفَرِيقَيْنِ أَحَقُّ بِالأمْنِ [ إِنْ كُنْتُمْ تَعْلَمُونَ ] } وقد صدقه الله ،   وحكم له بالأمن والهداية فقال : { الَّذِينَ آمَنُوا وَلَمْ يَلْبِسُوا إِيمَانَهُمْ بِظُلْمٍ أُولَئِكَ لَهُمُ الأمْنُ وَهُمْ مُهْتَدُونَ } ثم قال بعد ذلك كله : { وَتِلْكَ حُجَّتُنَا آتَيْنَاهَا إِبْرَاهِيمَ عَلَى قَوْمِهِ نَرْفَعُ دَرَجَاتٍ مَنْ نَشَاءُ }

قرئ بالإضافة وبلا إضافة ،   كما في سورة يوسف ،   وكلاهما قريب في المعنى .

وقوله : { إِنَّ رَبَّكَ حَكِيمٌ عَلِيمٌ } أي : حكيم في أفعاله وأقواله { عَلِيمٌ } أي : بمن يهديه ومن يضله ،   وإن قامت عليه الحجج والبراهين ،   كما قال : { إِنَّ الَّذِينَ حَقَّتْ عَلَيْهِمْ كَلِمَةُ رَبِّكَ لا يُؤْمِنُونَ * وَلَوْ جَاءَتْهُمْ كُلُّ آيَةٍ حَتَّى يَرَوُا الْعَذَابَ الألِيمَ } [ يونس : 96 ،   97 ] ؛  ؛ ولهذا قال هاهنا :

{ إِنَّ رَبَّكَ حَكِيمٌ عَلِيمٌ }
