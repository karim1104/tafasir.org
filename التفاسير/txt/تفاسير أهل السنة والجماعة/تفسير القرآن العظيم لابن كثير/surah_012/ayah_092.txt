{ قَالَ لا تَثْرِيبَ عَلَيْكُمُ الْيَوْمَ } يقول : لا تأنيب عليكم ولا عَتْب عليكم اليوم ،   ولا أعيد ذنبكم في حقي بعد اليوم .

ثم زادهم الدعاء لهم بالمغفرة فقال : { يَغْفِرُ اللَّهُ لَكُمْ وَهُوَ أَرْحَمُ الرَّاحِمِينَ }

قال السدي : اعتذروا إلى يوسف ،   فقال : { لا تَثْرِيبَ عَلَيْكُمُ الْيَوْمَ } يقول : لا أذكر لكم ذنبكم .

وقال ابن إسحاق والثوري : { لا تَثْرِيبَ عَلَيْكُمُ [ الْيَوْمَ ] }  أي : لا تأنيب عليكم اليوم عندي فيما صنعتم { يَغْفِرُ اللَّهُ لَكُمْ } أي : يستر الله عليكم فيما فعلتم ،   { وَهُوَ أَرْحَمُ الرَّاحِمِينَ }
