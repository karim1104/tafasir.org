يقول تعالى : { إِنَّمَا يُؤْمِنُ بِآيَاتِنَا } أي : إنما يصدق بها { الَّذِينَ إِذَا ذُكِّرُوا بِهَا خَرُّوا سُجَّدًا } أي : استمعوا لها وأطاعوها قولا وفعلا { وَسَبَّحُوا بِحَمْدِ رَبِّهِمْ وَهُمْ لا يَسْتَكْبِرُونَ } [ أي ]  عن اتباعها والانقياد لها ،   كما يفعله الجهلة من الكفرة الفجرة ،   [ وقد ]  قال الله تعالى : { إِنَّ الَّذِينَ يَسْتَكْبِرُونَ عَنْ عِبَادَتِي سَيَدْخُلُونَ جَهَنَّمَ دَاخِرِينَ } [ غافر : 60 ] .
