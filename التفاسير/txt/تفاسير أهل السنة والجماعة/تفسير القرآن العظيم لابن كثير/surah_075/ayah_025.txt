{ تَظُنُّ } أي : تستيقن ،   { أَنْ يُفْعَلَ بِهَا فَاقِرَةٌ } قال مجاهد : داهية .   وقال قتادة : شر .   وقال السدي : تستيقن أنها هالكة .   وقال ابن زيد : تظن أن ستدخل النار .

وهذا المقام كقوله : { يَوْمَ تَبْيَضُّ وُجُوهٌ وَتَسْوَدُّ وُجُوهٌ } [ أل عمران : 106 ] وكقوله { وُجُوهٌ يَوْمَئِذٍ مُسْفِرَةٌ ضَاحِكَةٌ مُسْتَبْشِرَةٌ وَوُجُوهٌ يَوْمَئِذٍ عَلَيْهَا غَبَرَةٌ تَرْهَقُهَا قَتَرَةٌ أُولَئِكَ هُمُ الْكَفَرَةُ الْفَجَرَةُ } [ عبس : 38 - 42 ] وكقوله { وُجُوهٌ يَوْمَئِذٍ خَاشِعَةٌ عَامِلَةٌ نَاصِبَةٌ تَصْلَى نَارًا حَامِيَةً } إلى قوله : { وُجُوهٌ يَوْمَئِذٍ نَاعِمَةٌ لِسَعْيِهَا رَاضِيَةٌ فِي جَنَّةٍ عَالِيَةٍ } [ الغاشية : 2 - 10 ] في أشباه ذلك من الآيات والسياقات .
