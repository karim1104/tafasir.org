يقول تعالى محتجًا على منكري البعث في إعادة الخلق بعد بدئه : { أَأَنْتُمْ } أيها الناس { أَشَدُّ خَلْقًا أَمِ السَّمَاءُ } ؟ يعني : بل السماءُ أشدّ خلقًا منكم ،   كما قال تعالى : { لَخَلْقُ السَّمَاوَاتِ وَالأرْضِ أَكْبَرُ مِنْ خَلْقِ النَّاسِ } [ غافر : 57 ] ،   وقال : { أَوَلَيْسَ الَّذِي خَلَقَ السَّمَاوَاتِ وَالأرْضَ بِقَادِرٍ عَلَى أَنْ يَخْلُقَ مِثْلَهُمْ بَلَى وَهُوَ الْخَلاقُ الْعَلِيمُ  } [ يس : 81 ] ،

فقوله : { بَنَاهَا } فسره بقوله : { رَفَعَ سَمْكَهَا فَسَوَّاهَا }
