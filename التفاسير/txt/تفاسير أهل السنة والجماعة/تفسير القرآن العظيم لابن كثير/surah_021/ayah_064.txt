يقول تعالى مخبرًا عن قوم إبراهيم حين قال لهم ما قال : { فَرَجَعُوا إِلَى أَنْفُسِهِمْ } أي : بالملامة في عدم احترازهم وحراستهم لآلهتهم ،   فقالوا : { إِنَّكُمْ أَنْتُمُ الظَّالِمُونَ } أي : في ترككم لها مهملة لا حافظ عندها ،   { ثُمَّ نُكِسُوا عَلَى رُءُوسِهِمْ } أي : ثم أطرقوا في الأرض فقالوا : { لَقَدْ عَلِمْتَ مَا هَؤُلاءِ يَنْطِقُونَ } قال قتادة : أدركت القوم حيرة سوء فقالوا : { لَقَدْ عَلِمْتَ مَا هَؤُلاءِ يَنْطِقُونَ } .
