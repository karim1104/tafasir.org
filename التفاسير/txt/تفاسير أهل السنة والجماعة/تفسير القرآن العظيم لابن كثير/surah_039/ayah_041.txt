يقول تعالى مخاطبا رسوله محمدا صلى الله عليه وسلم : { إِنَّا أَنزلْنَا عَلَيْكَ الْكِتَابَ } يعني : القرآن { لِلنَّاسِ بِالْحَقِّ } أي : لجميع الخلق من الإنس والجن لتنذرهم به ،   { فَمَنِ اهْتَدَى فَلِنَفْسِهِ } أي : فإنما يعود نفع ذلك إلى نفسه ،   { وَمَنْ ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } أي : إنما يرجع وبال ذلك على نفسه ،   { وَمَا أَنْتَ عَلَيْهِمْ بِوَكِيلٍ } أي : بموكل أن يهتدوا ،   { إِنَّمَا أَنْتَ نَذِيرٌ وَاللَّهُ عَلَى كُلِّ شَيْءٍ وَكِيلٌ } [ هود : 12 ] ،   { فَإِنَّمَا عَلَيْكَ الْبَلاغُ وَعَلَيْنَا الْحِسَابُ } [ الرعد : 40 ] .
