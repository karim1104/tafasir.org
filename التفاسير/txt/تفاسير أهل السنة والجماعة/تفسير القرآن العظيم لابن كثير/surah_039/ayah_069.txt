وقوله : { وَأَشْرَقَتِ الأرْضُ بِنُورِ رَبِّهَا } أي : أضاءت يوم القيامة إذا تجلى الحق ،   تبارك وتعالى ،   للخلائق لفصل القضاء ،   { وَوُضِعَ الْكِتَابُ } قال قتادة : كتاب الأعمال ،   { وَجِيءَ بِالنَّبِيِّينَ } قال ابن عباس : يشهدون على الأمم بأنهم بلغوهم رسالات  الله إليهم ،   { وَالشُّهَدَاءِ } أي : الشهداء من الملائكة الحفظة على أعمال العباد من خير وشر ،   { وَقُضِيَ بَيْنَهُمْ بِالْحَقِّ } أي : بالعدل { وَهُمْ لا يُظْلَمُونَ } قال الله [ تعالى ]  : { وَنَضَعُ الْمَوَازِينَ الْقِسْطَ لِيَوْمِ الْقِيَامَةِ فَلا تُظْلَمُ نَفْسٌ شَيْئًا وَإِنْ كَانَ مِثْقَالَ حَبَّةٍ مِنْ خَرْدَلٍ أَتَيْنَا بِهَا وَكَفَى بِنَا حَاسِبِينَ } [ الأنبياء : 47 ] ،   وقال [ الله ]  تعالى : { وَإِنْ تَكُ حَسَنَةً يُضَاعِفْهَا وَيُؤْتِ مِنْ لَدُنْهُ أَجْرًا عَظِيمًا } [ النساء : 40 ] ،  ولهذا قال : { وَوُفِّيَتْ كُلُّ نَفْسٍ مَا عَمِلَتْ }
