يقول تعالى : { كَذَّبَتْ } قبل قومك يا محمد { قَوْمُ نُوحٍ فَكَذَّبُوا عَبْدَنَا } أي : صرحوا له بالتكذيب واتهموه بالجنون ،   { وَقَالُوا مَجْنُونٌ وَازْدُجِرَ } قال مجاهد : { وَازْدُجِرَ } أي : استطير جنونا .   وقيل : { وَازْدُجِرَ } أي : انتهروه وزجروه وأوعدوه : { لَئِنْ لَمْ تَنْتَهِ يَا نُوحُ لَتَكُونَنَّ مِنَ الْمَرْجُومِينَ } [ الشعراء : 116 ] .   قاله ابن زيد ،   وهذا متوجه حسن .
