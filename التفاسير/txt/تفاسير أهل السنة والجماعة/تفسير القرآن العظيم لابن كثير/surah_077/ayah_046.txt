وقوله : { كُلُوا وَتَمَتَّعُوا قَلِيلا إِنَّكُمْ مُجْرِمُونَ } خطاب للمكذبين بيوم الدين ،   وأمَرَهم أمر تهديد ووعيد فقال تعالى : { كُلُوا وَتَمَتَّعُوا قَلِيلا } أي : مدة قليلة قريبة قصيرة ،   { إِنَّكُمْ مُجْرِمُونَ } أي : ثم تساقون إلى نار جهنم التي تقدم ذكرها ،   { وَيْلٌ يَوْمَئِذٍ لِلْمُكَذِّبِينَ } كما قال تعالى : { نُمَتِّعُهُمْ قَلِيلا ثُمَّ نَضْطَرُّهُمْ إِلَى عَذَابٍ غَلِيظٍ } [ لقمان : 24 ] وقال تعالى : { إِنَّ الَّذِينَ يَفْتَرُونَ عَلَى اللَّهِ الْكَذِبَ لا يُفْلِحُونَ مَتَاعٌ فِي الدُّنْيَا ثُمَّ إِلَيْنَا مَرْجِعُهُمْ ثُمَّ نُذِيقُهُمُ الْعَذَابَ الشَّدِيدَ بِمَا كَانُوا يَكْفُرُونَ } [ يونس : 69 ،   70 ]
