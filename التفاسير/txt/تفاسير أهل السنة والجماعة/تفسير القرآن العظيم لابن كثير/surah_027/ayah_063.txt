يقول : { أَمَّنْ يَهْدِيكُمْ فِي ظُلُمَاتِ الْبَرِّ وَالْبَحْرِ } أي : بما خلق من الدلائل السماوية والأرضية ،   كما قال : { وَعَلامَاتٍ وَبِالنَّجْمِ هُمْ يَهْتَدُونَ } [ النحل : 16 ] ،   وقال تعالى : { وَهُوَ الَّذِي جَعَلَ لَكُمُ النُّجُومَ لِتَهْتَدُوا بِهَا فِي ظُلُمَاتِ الْبَرِّ وَالْبَحْرِ } الآية [ الأنعام : 97 ] .

{ وَمَنْ يُرْسِلُ الرِّيَاحَ بُشْرًا بَيْنَ يَدَيْ رَحْمَتِهِ } أي : بين يدي السحاب الذي فيه مطر ،   يغيث به عباده المجدبين الأزلين القنطين ،   { أَإِلَهٌ مَعَ اللَّهِ تَعَالَى اللَّهُ عَمَّا يُشْرِكُونَ } .
