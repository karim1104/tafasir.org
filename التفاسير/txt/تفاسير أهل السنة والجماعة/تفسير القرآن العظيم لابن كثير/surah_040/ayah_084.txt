{ فَلَمَّا رَأَوْا بَأْسَنَا } أي : عاينوا وقوع العذاب بهم ،   { قَالُوا آمَنَّا بِاللَّهِ وَحْدَهُ وَكَفَرْنَا بِمَا كُنَّا بِهِ مُشْرِكِينَ } أي : وحدوا الله وكفروا بالطاغوت ،   ولكن حيث لا تُقَال العثرات ،   ولا تنفع المعذرة .   وهذا كما قال فرعون حين أدركه الغرق : { آمَنْتُ أَنَّهُ لا إِلَهَ إِلا الَّذِي آمَنَتْ بِهِ بَنُو إِسْرَائِيلَ وَأَنَا مِنَ الْمُسْلِمِينَ } [ يونس : 90 ] ،   قال الله [ تبارك و ]  تعالى : { آلآنَ وَقَدْ عَصَيْتَ قَبْلُ وَكُنْتَ مِنَ الْمُفْسِدِينَ } [ يونس : 91 ] أي : فلم يقبل الله منه ؛ لأنه قد استجاب لنبيه موسى دعاءه عليه حين قال : { وَاشْدُدْ عَلَى قُلُوبِهِمْ فَلا يُؤْمِنُوا حَتَّى يَرَوُا الْعَذَابَ الألِيمَ } [ يونس : 88 ] .   و[ هكذا ]  هاهنا قال : { فَلَمْ يَكُ يَنْفَعُهُمْ إِيمَانُهُمْ لَمَّا رَأَوْا بَأْسَنَا سُنَّةَ اللَّهِ الَّتِي قَدْ خَلَتْ فِي عِبَادِهِ }
