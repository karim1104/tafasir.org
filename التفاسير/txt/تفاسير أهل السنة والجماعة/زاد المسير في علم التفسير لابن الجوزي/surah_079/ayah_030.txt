{ وَالأرْضَ بَعْدَ ذَلِكَ } أي : بعد خلق السماء { دَحَاهَا } أي : بسطها .   وبعض من يقول : إن الأرض خلقت قبل السماء يزعم أن { بعد } هاهنا بمعنى { قبل } كقوله تعالى : { وَلَقَدْ كَتَبْنَا فِي الزَّبُورِ مِن بَعْدِ الذّكْرِ } [ الأنبياء : 105 ] .   وبعضهم يقول : هي بمعنى { مع } كقوله تعالى : { عُتُلٍ بَعْدَ ذَلِكَ زَنِيمٍ } [ القلم : 13 ] ،   ولا يمتنع أن تكون الأرض خلقت قبل السماء ،   ثم دحيت بعد كمال السماء ،   وهذا مذهب عبد الله بن عمرو بن العاص .   وقد أشرنا إلى هذا الخلاف في [ البقرة : 29 ] .   ونصبت الأرض بمضمر تفسيره قوله تعالى : { دَحَاهَا } .
