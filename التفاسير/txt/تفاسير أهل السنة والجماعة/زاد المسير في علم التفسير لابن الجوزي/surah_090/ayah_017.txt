ثم بين أن هذه القُرب إنما تنفع مع الإيمان بقوله تعالى : { ثُمَّ كَانَ مِنَ الَّذِينَ آمَنُواْ } و{ ثم } هاهنا بمعنى الواو ،   كقوله تعالى : { ثُمَّ اللَّهُ شَهِيدٌ } [ يونس :46 ] .

قوله تعالى : { وَتَوَاصَوْاْ بِالصَّبْرِ } على فرائض الله وأمره { وَتَوَاصَوْاْ بِالْمَرْحَمَةِ } أي : بالتراحم بينهم .
