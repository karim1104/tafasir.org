قوله تعالى : { وَقَفَّيْنَا عَلَى آثَارِهِم } أي : وأتبعنا على آثار النبيين الذين أسلموا { بِعَيسَى } فجعلناه يقفو آثارهم { مُصَدّقاً } أي : بعثناه مصدقا { لّمَا بَيْنَ يَدَيْهِ } { وآتيناه الإنجيل فيه هدى ونور ومصدقا } ليس هذا تكرارا للأول ،   لأن الأول لعيسى ،   والثاني : للإنجيل ،   لأن عيسى كان يدعو إلى التصديق بالتوراة ،   والإنجيل أنزل وفيه ذكر التصديق بالتوراة .
