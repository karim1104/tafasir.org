واختلف القراء في تاء { تُخْرَجُونَ } ؛ فقرأ ابن كثير ،   وعاصم ،   وأبو عمرو : بضم التاء وفتح الراء ،   ها هنا ؛ وفي الرُّومُ : { وكَذَلِكَ تُخْرَجُونَ } [ الروم : 19 ] .   وفي الزخرف : { كَذَلِكَ تُخْرَجُونَ } [ الزخرف : 11 ] .   وفي الجاثية : { لاَ يُخْرَجُونَ مِنْهَا } [ الجاثية : 35 ] .   وقرأهن حمزة ،   والكسائي : بفتح التاء وضم الراء .   وفتح ابن عامر التاء في ( الأعراف ) فقط .   فأما التي في ( الرُّومُ ) { إِذَا أَنتُمْ تَخْرُجُونَ } [ الروم : 25 ] ،   وفي { سَأَلَ سَائِلٌ } { يَوْمَ يَخْرُجُونَ } [ المعارج : 43 ] فمفتوحتان من غير خلاف .
