قوله تعالى : { أَمْ يَقُولُونَ افْتَرَاهُ }  " أم "  بمعنى  " بل "  ،   و " افتراه "  أتى به من قبل نفسه .   { قُلْ فَأْتُواْ } أنتم في معارضتي { بِعَشْرِ سُوَرٍ مّثْلِهِ } في البلاغة { مُفْتَرَيَاتٍ } بزعمكم ودعواكم { وَادْعُواْ مَنِ اسْتَطَعْتُمْ مّن دُونِ اللَّهِ } إلى المعاونة على المعارضة { إِن كُنتُمْ صَادِقِينَ } في قولكم :  " افتراه "  .
