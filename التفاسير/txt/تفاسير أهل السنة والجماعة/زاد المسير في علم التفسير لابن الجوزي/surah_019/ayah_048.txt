قوله تعالى : { وَأَعْتَزِلُكُمْ } أي : وأتنحى عنكم ،   { و }أعتزل { مَّا تَدْعُونَ مِن دُونِ اللَّهِ } يعني : الأصنام .

وفي معنى { تدعون } قولان :

أحدهما : تعبدون .

والثاني : أن المعنى : وما تدعونه ربا ،   { وَأَدْعُو رَبّي } أي : وأعبده { عَسَى أَلاَّ أَكُونَ بِدُعَاء رَبّى شَقِيّا } أي : أرجو أن لا أشقى بعبادته كما شقيتم أنتم بعبادة الأصنام ،   لأنها لا تنفعهم ولا تجيب دعاءهم
