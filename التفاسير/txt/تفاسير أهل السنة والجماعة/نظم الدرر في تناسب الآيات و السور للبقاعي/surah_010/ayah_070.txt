ثم بين عدم الفلاح بقوله : { متاع } أي لهم ،   ونكره إشارة إلى قلته كما قال في الآية الأخرى { متاع قليل } وأكد ذلك بقوله : { في الدنيا } لأنها دار ارتحال ،   وما كان إلى زوال وتلاش واضمحلال كان قليلاً وإن تباعد مدّه وتطاولت مُدَده وجل مَدَده ،   وزاد على الحصر عَدده ؛ وبين حالهم بعد النقلة بقوله : { ثم } أي بعد ذلك الإملاء لهم وإن طال { إلينا } أي على ما لنا من العظمة لا إلى غيرنا { مرجعهم } بالموت فنذيقهم عذاباً شديداً لكنه دون عذاب الآخرة { ثم نذيقهم } يوم القيامة { العذاب الشديد بما } أي بسبب ما { كانوا } أي كوناً هو جبلة لهم { يكفرون } ووجب كسر  "  إن  "  بعد القول لأنه حكاية عما يستأنف الإخبار به كما فعل في لام الابتداء لذلك .
