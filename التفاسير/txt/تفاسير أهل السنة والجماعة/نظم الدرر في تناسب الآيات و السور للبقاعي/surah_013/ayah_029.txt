ثم أخبر عما لهذا القسم بقوله : { الذين آمنوا } أي أوجدوا وصف الإيمان { وعملوا } أي تصديقاً لدعواهم الإيمان { الصالحات } لطمأنينة قلوبهم إلى الذكر { طوبى لهم } أي خير وطيب وسرور وقرة عين { وحسن مآب * } فكان ذلك مفهماً لحال القسم الآخر ،   فكأنه قيل : ومن لم يطمئن أو اطمأن قلبه ولم يذعن بؤسي لهم وسوء مآب .
