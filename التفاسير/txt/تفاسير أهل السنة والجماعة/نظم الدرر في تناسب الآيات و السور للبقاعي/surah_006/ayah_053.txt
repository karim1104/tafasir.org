{ وكذلك } أي ومثل ما فتناهم بإرسالك { فتنا } أي فعلنا فعل المختبر قسراً بما لنا من العظمة { بعضهم ببعض } بالتخصيص بالإيمان والغنى والفقر ونحو ذلك { ليقولوا } أي إنكاراً لأن تفضل غيرهم عليهم احتقاراً لهم واستصغاراً { أهؤلاء } أي الذين لا يساووننا بل لا يقاربوننا في خصلة من خصال الدنيا { منَّ الله } أي على جلاله وعظمه { عليهم } أي وفقهم لإصابة الحق وما يسعدهم عنده وهم فيما نرى من الحقارة { من بيننا } فالآية ناظرة إلى ما يأتي في هذه السورة من قوله تعالى

{ حتى نؤتى مثل ما أوتي رسل الله }[ الأنعام : 124 ] .

ولما كان الإنكار لا يسوغ إلاّ مع نهاية العلم بمراتب المفضلين ،   وأن المفضل لا يستحق التفضيل من الوجه المفضل به ،   أنكر إنكارهم بقوله : { أليس الله } أي الذي له جميع الأمر ،   فلا اعتراض عليه { بأعلم بالشاكرين * } أي الذين يستحقون أن يفضلوا لشكرهم على غيرهم لكفرهم .
