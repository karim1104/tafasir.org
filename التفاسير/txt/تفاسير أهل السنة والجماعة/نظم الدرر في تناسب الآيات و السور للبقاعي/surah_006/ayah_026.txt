فصدق قوله إخبار هذه الآية { وهم } حال من فاعل { يستمع } أي يستمعون إليك والحال أنهم { ينهون عنه } أي عن الاستماع أو عن اتباع القرآن { وينأون } أي يبعدون { عنه } أي كما وقع لأبي جهل وصاحبيه في المعاهدة على ترك المعاودة للسماع وما يتبعه { وإن } أي وما { يهلكون } أي بعبادتهم ومكابدتهم { إلاّ أنفسهم } أي وما هم بضاريك ولا بضاري أحد من أتباعك فيما يقدح في المقصود من إرسالك من إظهار الدين ومحو الشرك وإذلال المفسدين { وما يشعرون } أي وما لهم نوع شعور بما يؤديهم إليه الحال ،   بل هم كالبهائم ،   بل هي أصلح حالاً منهم .
