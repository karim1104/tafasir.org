ولما نهوا رسولهم عن الإشعار بهم عللوا ذلك فقالوا : { إنهم } أي أهل المدينة { إن يظهروا } أي يطلعوا عالين { عليكم يرجموكم } أي يقتلوكم أخبث قتلة إن استمسكتم بدينكم { أو يعيدوكم } قهراً { في ملتهم } إن لنتم لهم { ولن تفلحوا إذاً } أي إذا عدتم فيها مطمئنين بها ،   لأنكم وإن أكرهتم ربما استدرجكم الشيطان بذلك إلى الإجابة حقيقة { أبداً * } أي فبعثوا أحدهم فنظر الأزكى وتلطف في الأمر ،   فاسترابوا منه لأنهم أنكروا ورقه لكونها من ضرب ملك لا يعرفونه فجهدوا به فلم يشعر بهم أحداً من المخالفين ،   وإنما أشعر بهم الملك لما رآه موافقاً لهم في الدين لأنه لم يقع النهي عنه
