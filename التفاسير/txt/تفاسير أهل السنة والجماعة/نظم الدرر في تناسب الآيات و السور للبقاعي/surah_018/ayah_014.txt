{ وربطنا } بما لنا من العظمة { على قلوبهم } أي قويناها ،   فصار ما فيها من القوى مجتمعاً غير مبدد ،   فكانت حالهم في الجلوة كحالهم في الخلوة { إذ قاموا } لله تعالى حق القيام في ذلك الجيل الكافرين بين يدي طاغيتهم دقيانوس { فقالوا } مخالفين لهم : { ربنا } الذي يستحق أن نفرده بالعبادة لتفرده بتدبيرنا ،   هو { رب السماوات والأرض } أي موجدهما ومدبرهما { لن ندعوا من دونه إلهاً * } بعد أن ثبت عجز كل من سواه ،   والله { لقد قلنا إذاً } أي إذا دعونا من دونه غيره { شططاً } أي قولاً ذا بعد مفرط عن الحق جداً ؛
