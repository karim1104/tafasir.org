ثم غلظ ذلك باستفهام آخر كذلك فقال : { وكيف تأخذونه وقد } أي والحال أنه قد { أفضى } أي بالملامسة { بعضكم إلى بعض } أي فكدتم أن تصيروا جسداً واحداً { وأخذن } أي النساء { منكم } أي بالإفضاء والاتحاد { ميثاقاً غليظاً * } قوياً عظيماً ،   أي بتقوى الله في المعاشرة بالإحسان وعدم الإساءة ،   لأن مبنى النكاح على ذلك وإن لم يصرح به فيه .
