ولما أجابهم بما هو الحق إيجاداً علمهم ما هو الأدب لماحظة السبب فقال مستأنفاً : { ما أصابك من حسنة } أي نعمة دنيوية أو أخروية { فمن الله } أي إيجاداً وفضلاً ،   والإيمان أحسن الحسنات ،   قال الإمام : إنهم يقولون : إنهم اتفقوا على أن قوله

{ ومن أحسن قولاً ممن دعا إلى الله }[ فصلت : 33 ] المراد به كلمة الشهادة { وما أصابك } وأنت خير الخلق { من سيئة } أي بلاء { فمن نفسك } أي بسببها فغيرك بطريق الأولى .

ولما اقتضى قولهم إنكار رسالته صلى الله عليه وسلم إلا أن فعل كل خارق ،   وأخبر سبحانه وتعالى بأنه مستو مع الخلق في القدرة قال سبحانه وتعالى مخبراً بما اختصه به عنهم : { وأرسلناك } أي مختصين لك بعظمتنا { للناس } أي كافة { رسولاً } أي تفعل ما على الرسل من البلاغ ونحوه ،   وقد اجتهدت في البلاغ والنصيحة ،   ولم نجعلك إلهاً تأتي بما يطلب منك من خير وشر ،   فإن أنكروا رسالتك فالله يشهد بنصب المعجزات والآيات البينات { وكفى بالله } المحيط علماً وقدرة { شهيداً * } لك بالرسالة والبلاغ .
