{ قالوا } وثوقاً منهم بالبراءة وإخباراً بالحكم عندهم { جزاؤه } أي الصواع { من } .

ولما كان العبرة بنفس الوجدان ،   بنوا للمفعول قولهم : { وجد في رحله } ولتحققهم البراءة علقوا الحكم على مجرد الوجدان لا السرقة ؛ ثم أكدوا ذلك بقولهم : { فهو جزاؤه } أي ليس غير ،   فكأنه قيل : هل هذا أمر أحدثتموه الآن أو هو مشروع لكم ؟ فقالوا : { كذلك } أي بل هو سنة لنا ،   مثل ذلك الجزاء الشديد { نجزي الظالمين * } أي بالظلم دائماً ،   نرقّه في سرقته ؛ فحينئذ فتش أوعيتهم
