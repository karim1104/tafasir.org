ولما تم أمرهم هذا وشبوا على أبيهم عليه السلام نار الحزن ،   التفتت النفس إلى الخبر عن يوسف عليه الصلاة والسلام فيما أشار إليه قوله :

{ لتنبئنهم }[ يوسف : 15 ] الآية ،   فقال تعالى مخبراً عن ذلك في أسبابه : { وجاءت سيارة } أي قوم بليغو السير إلى الأرض التي ألقوا يوسف عليه الصلاة والسلام في جبها { فأرسلوا واردهم } أي رسولهم الذي يرسلونه لأجل الإشراف على الماء إلى الجب ليستقي لهم { فأدلى } فيه { دلوه } أي أرسلها في البئر ليملأها - وأما  "  دلى  "  فأخرجها ملأى - فاستمسك بها يوسف عليه الصلاة والسلام فأخرجه ،   فكأنه قيل : ماذا قال حين أدلى للماء فتعلق يوسف بالحبل فأطلعه فإذا هو بإنسان أجمل ما يكون ؟ فقيل : { قال } أي الوارد يعلم أصحابه بالبشرى { يا بشرى } أي هذا أوانك فاحضري ،   فكأنه قيل : لم تدعوا البشرى ؟ فقال : { هذا غلام } فأتى به إلى جماعته فسروا به كما سر { وأسروه } أي الوارد وأصحابه { بضاعة } أي حال كونه متاعاً بزعمهم يتجرون فيه { والله } أي المحيط علماً وقدرة { عليم } أي بالغ العلم { بما يعملون * } وإن أسروه ؛ قال أبو حيان ونعم ما قال : وتعلقه بالحبل يدل على صغره إذ لو كان ابن ثمانية عشر أو سبعة عشر لم يحمله الحبل غالباً ،   ولفظة  "  غلام  "  ترجح ذلك إذ تطلق عليه ما بين الحولين إلى البلوغ حقيقة ،   وقد تطلق على الرجل الكامل - انتهى .
