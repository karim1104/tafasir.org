ولما كان هذا السياق محركاً للنفس إلى معرفة جوابهم عنه ،   أورده على تقدير سؤال من كأنه قال : إن هذا لترغيب مشوق وترهيب مقلق ،   فما قالوا في جوابه ؟ فقال : { قالوا } معرضين عن ذلك كله بهمم سافلة وأحوال نازلة ،   مخاطبين له باسمه جفاء وجلافة وقلة أدب { يا موسى } وأكدوا قولهم تأكيد من هو محيط العلم ،   فقالوا مخاطبين بجرأة وقلة حياء لأعلم أهل زمانه : { إن فيها } أي دون غيرها { قوماً جبارين } أي عتاة قاهرين لغيرهم مكرهين له على ما يريدون { وإنا لن ندخلها } خوفاً منهم { حتى يخرجوا منها } ثم صرحوا بالإتيان بالجملة الاسمية المؤكدة بتهالكهم على الدخول وأنه لا مانع لهم إلا الجبن فقالوا : { فإن يخرجوا منها } أي بأي وجه كان ،   وعبروا بأداة الشك مع إعلام الله لهم بإهلاكهم على أيديهم جلافة منهم وعراقة طبع في التكذيب { فإنا داخلون * }
