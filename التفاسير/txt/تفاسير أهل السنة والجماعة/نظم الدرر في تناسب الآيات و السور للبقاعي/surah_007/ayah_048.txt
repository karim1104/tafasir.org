ولما تقدم كلامهم لأهل الجنة بالسلام ،   أخبر أنهم يكلمون أهل النار بالتوبيخ والملام فقال : { ونادى } وأظهر الفاعل لئلا يلبس بأهل الجنة فقال { أصحاب الأعراف } أي الحال صرف وجوهم إلى جهة أهل النار { رجالاً } أي من أهل النار { يعرفونهم } أي بأعيانهم ،   وأما معرفتهم إجمالاً فتقدم ،   وإنما قال هنا : { بسيماهم } لأن النار قد أكلتهم وغيرت معالمهم مع تغيرهم بالسمن وسواد الوجوه وعظم الجثث ونحوه { قالوا } نفياً أو استفهاماً توبيخاً وتقريعاً { ما أغنى عنكم جمعكم } أي للمال والرجال { وما كنتم تستكبرون* } أي تجددون بهما هذه الصفة وتوجدونها دائماً في الدنيا زاعمين أنه لا غالب لكم ؛
