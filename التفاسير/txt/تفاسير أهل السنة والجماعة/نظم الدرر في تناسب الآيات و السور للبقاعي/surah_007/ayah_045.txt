{ الذين يصدون } أي لهم فعل الصد لمن أراد الإيمان ولمن آمن ولغيرهما بالإضلال بالإرغاب والإرهاب والمكر والخداع { عن سبيل الله } أي طريق دين الملك الذي لا كفوء له الواضح الواسع { ويبغونها } أي يطلبون لها { عوجاً } بإلقاء الشكوك والشبهات ،   وقد تقدم ما فيه في آل عمران { وهم بالآخرة كافرون* } أي ساترون ما ظهر لعقولهم من دلائلها ؛ فمتى وجدت هذه الصفات الأربع حقت اللعنة
