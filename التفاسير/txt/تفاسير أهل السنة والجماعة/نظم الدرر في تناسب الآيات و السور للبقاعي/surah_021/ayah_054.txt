استأنف الله تعالى الإخبار عن جوابه بقوله : { قال } أي منبهاً لهم بسوط التقريع على أن الكلام مع آبائهم كالكلام معهم : { لقد كنتم } وأكد بقوله : { أنتم } لأجل صحة العطف لأن الضمير المرفوع المتصل حكمه حكم جزء الفعل ،   هذا مع الإشارة إلى الحكم على ظواهرهم وبواطنهم { وءاباؤكم } أي من قبلكم { في ضلال } قد أحاط بكم إحاطة الظرف بالمظروف والمسلوك بالسلك { مبين* } ليس به نوع من الخفاء .
