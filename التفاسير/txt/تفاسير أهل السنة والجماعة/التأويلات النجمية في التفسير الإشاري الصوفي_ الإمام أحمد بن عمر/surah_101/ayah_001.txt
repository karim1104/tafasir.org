يا قارع رأس نفسك بمقرعة الشقاوة، اعتبر بسورة القارعة حيث يقول الله تعالى: { ٱلْقَارِعَةُ } [القارعة: 1] قد جاءت القارعة احذرها، ولا يثقل مقرعتك بالهوى.  { مَا ٱلْقَارِعَةُ } [القارعة: 2]، هي القيامة الهوائية التي قامت في قالبك، { وَمَآ أَدْرَاكَ مَا ٱلْقَارِعَةُ } [القارعة: 3]؛ لأنك غافل عنها مشتغل بما فيه بثقل المقرعة في القارعة.  { يَوْمَ يَكُونُ ٱلنَّاسُ كَٱلْفَرَاشِ ٱلْمَبْثُوثِ } [القارعة: 4] المتفرق في النيران المشتعلة بريح هواء النفس، { وَتَكُونُ ٱلْجِبَالُ كَٱلْعِهْنِ ٱلْمَنفُوشِ } [القارعة: 5]؛ يعني: جبال قالبك تكون في تلك الريح كالعهن المنقوش.
