{ وَبَدَا لَهُمْ سَيِّئَاتُ مَا كَـسَبُواْ } [الزمر: 48] من كفران النعمة، ونسيان الحضرة بالبعد والطرد والهجران، { وَٱلَّذِينَ ظَلَمُواْ مِنْ هَـٰؤُلاَءِ } [الزمر: 51]؛ يعني: الغفلة، { سَيُصِيبُهُمْ سَيِّئَاتُ مَا كَسَبُواْ } [الزمر: 51] بأعمالهم وأخلاقهم، { وَمَا هُمْ بِمُعْجِزِينَ } [الزمر: 51] عن مجازاتهم بالخير والشر.  { أَوَلَمْ يَعْلَمُوۤاْ أَنَّ ٱللَّهَ يَبْسُطُ ٱلرِّزْقَ لِمَن يَشَآءُ } [الزمر: 52] من نعمة الدنيا والآخرة وسعادتهما، { وَيَقْدِرُ } [الزمر: 52] على من يشاء؛ يعني: أمر الدنيا والآخرة يبنى على مشيئته سبحانه وتعالى لا على مشيئة العباد، { إِنَّ فِي ذَلِكَ لآيَاتٍ لِّقَوْمٍ يُؤْمِنُونَ } [الزمر: 52] بأن يخرجهم عن مشيئتهم، ويستسلمون لمشيئة الله تعالى وحكمه وقضائه.
