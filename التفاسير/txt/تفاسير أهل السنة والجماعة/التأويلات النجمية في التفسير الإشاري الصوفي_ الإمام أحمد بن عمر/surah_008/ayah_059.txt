ثم أخبر عن أهل الكفر أنهم شر الدواب بقوله تعالى: { إِنَّ شَرَّ ٱلدَّوَابِّ عِندَ ٱللَّهِ ٱلَّذِينَ كَفَرُواْ } [الأنفال: 55] إلى قوله: { وَأَنْتُمْ لاَ تُظْلَمُونَ } [الأنفال: 60] الإشارة فيه: { إِنَّ شَرَّ ٱلدَّوَابِّ عِندَ ٱللَّهِ ٱلَّذِينَ كَفَرُواْ } يعني: بالذين كفَّروا النفوس المتمردة الأمارة بالسوء هم عند الله محكومون بالشقاوة في الأزل مكتوبون بشر الدواب كقوله: [الفرقان: 44]، { فَهُمْ لاَ يُؤْمِنُونَ } [الأنفال: 55] لما حكموا بالشقاوة الأبدي وإنما صاروا شر الدواب لأنهم { ٱلَّذِينَ عَاهَدْتَّ مِنْهُمْ } [الأنفال: 56] يوم الميثاق والخطاب مع الروح؛ لأن النفس المودعة في الذرة التي أخذ الله تعالى من ظهر آدم عليه السلام أقرت بربوبية الحق تعالى وعاهدته بتبعية الروح؛ لأن نوره وصفته غلبت على ظلمة النفس وصفاتها، { ثُمَّ يَنقُضُونَ عَهْدَهُمْ فِي كُلِّ مَرَّةٍ } [الأنفال: 56] بمعصية من المعاصي وذنب من الذنوب، { وَهُمْ لاَ يَتَّقُونَ } [الأنفال: 56] من خاتمة السوء فيما ينقضون العهد مع الله بالإشراك وعبادة الهوى.  { فَإِمَّا تَثْقَفَنَّهُمْ فِي ٱلْحَرْبِ } [الأنفال: 57] أي: لو ظفرت يا روح ببعض صفات النفس في جهادها، { فَشَرِّدْ بِهِم مَّنْ خَلْفَهُمْ } [الأنفال: 57] أي: بالغ في تبديل تلك الصفات التي هي خلقها، { لَعَلَّهُمْ يَذَّكَّرُونَ } [الأنفال: 57] يعتبرون ويتبدلون بالصفات الروحانية والأخلاق الربانية، { وَإِمَّا تَخَافَنَّ مِن قَوْمٍ خِيَانَةً } [الأنفال: 58] أي: تفرست من بعض تلك الصفات خيانة نقض العهد، والعود إلى طبعها الخسيس، والرجوع إلى أوصافها، { فَٱنْبِذْ إِلَيْهِمْ عَلَىٰ سَوَآءٍ } [الأنفال: 58] يعني: أظهر عليهم عداوتك معهم، وجاهدهم على سوية رجوعهم حتى يفنوا إلى العهد، ويتركوا خيانة النقض، { إِنَّ ٱللَّهَ لاَ يُحِبُّ ٱلخَائِنِينَ } [الأنفال: 58] معه في العهود، { وَلاَ يَحْسَبَنَّ ٱلَّذِينَ كَفَرُواْ سَبَقُوۤاْ } [الأنفال: 59] أي: النفوس التي كفرت ونقضت العهود ورجعت إلى أوصافها أنهم سبقونا وخرجوا من تصرفنا.  { إِنَّهُمْ لاَ يُعْجِزُونَ } [الأنفال: 59] أي: لا يعجزوني عن التصرف فيهم فلا يقنطوا من رحمتي في صلاح حالهم، { وَأَعِدُّواْ لَهُمْ مَّا ٱسْتَطَعْتُمْ مِّن قُوَّةٍ } [الأنفال: 60] أي: من قوة الروح وغلبات صفاتها وأعداءه بمداومة الذكر وقطع التعلق، { وَمِن رِّبَاطِ ٱلْخَيْلِ } [الأنفال: 60] أي: من رباط القلب بطريق المراقبة لئلا يلتفت إلى الدنيا وزينتها، { تُرْهِبُونَ بِهِ } [الأنفال: 60] يعني: بالذكر والمراقبة، { عَدْوَّ ٱللَّهِ وَعَدُوَّكُمْ } [الأنفال: 60] أي: الشيطان والنفس، { وَآخَرِينَ مِن دُونِهِمْ } [الأنفال: 60] من نفوس شياطين الأنس، { لاَ تَعْلَمُونَهُمُ } [الأنفال: 60] أنهم عدوكم من الأحباب والأصدقاء والأقرباء، { ٱللَّهُ يَعْلَمُهُمْ } [الأنفال: 60] أنهم عدو لكم كقوله تعالى: [التغابن: 14].  { وَمَا تُنفِقُواْ مِن شَيْءٍ } [الأنفال: 60] أي: في شهوات النفس ولذاتها والدنيا وزينتها بطريق الذكر والمراقبة، { فِي سَبِيلِ ٱللَّهِ } [الأنفال: 60] في طلبه والسير إليه، { يُوَفَّ إِلَيْكُمْ } [الأنفال: 60] أي: يوف لكم فوائده في مزيد القربة، كما قال تعالى: " من تقرب إلي بشبر تقربت إليه ذراعاً " ، { وَأَنْتُمْ لاَ تُظْلَمُونَ } [الأنفال: 60] فيما تقربتم به إليه إلى الله تعالى، بل يضاعفه ويؤت من لدنه أجراً عظيماً.
