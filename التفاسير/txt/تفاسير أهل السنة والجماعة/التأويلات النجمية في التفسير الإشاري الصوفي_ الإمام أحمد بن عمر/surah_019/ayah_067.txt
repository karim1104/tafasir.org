ثم أخبر عن صفات كماله وكمال جلاله بقوله تعالى: { رَّبُّ ٱلسَّمَٰوَٰتِ } [مريم: 65] إلى قوله: [مريم: 72] بقوله: { رَّبُّ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ وَمَا بَيْنَهُمَا فَٱعْبُدْهُ } [مريم: 65] يشير إلى أنه تعالى خالق ورب سماوات الأرواح وأرض الأجساد وما بينهما من النفوس والقلوب والأسرار، فاعبده بجسدك ونفسك وقلبك وسرك وروحك، فعبادة جسدك إياه بأركان الشريعة وهي: الائتمار بما أمرك الله به، والانتهاء عمَّا نهاك الله عنه، وعبادة نفسك بآداب الطريقة وهي: ترك موافقات هواها، ولزوم مخالفة هواها، وعبادة القلب بالإعراض عن الدنيا وما فيها، والإقبال على الآخرة ومكارمها، وعبادة السر خلوة عن تعلقات الكونين اتصالاً بالله ومحبة له، وعبادة الروح ببذل الوجود ليل الشهود { وَٱصْطَبِرْ لِعِبَادَتِهِ } [مريم: 65] بالمداومة على المجاهدات، فإنها تورث المشاهدات، { هَلْ تَعْلَمُ لَهُ سَمِيّاً } [مريم: 65] أي: مثلاً في الخالقية والربوبية أو جنساً في المحبة والمحبوبية.  { وَيَقُولُ ٱلإِنسَانُ } [مريم: 66] أي: النفس الإنسانية لجهلها بالحقائق { أَءِذَا مَا مِتُّ } [مريم: 66] عن صفات الحيوانية { لَسَوْفَ أُخْرَجُ حَيّاً } [مريم: 66] بصفات الروحانية بطريق الاستهزاء { أَوَلاَ يَذْكُرُ ٱلإِنسَٰنُ } [مريم: 67] أي: لا يتذكر نفسه { أَنَّا خَلَقْنَاهُ مِن قَبْلُ } [مريم: 67] بازدواج الروح والحسد { وَلَمْ يَكُ شَيْئاً } [مريم: 67] موجوداً أفلا نقدر على أنها إذا ماتت عن صفاتها الحيوانية يحييها بصفات الروحانية، بل بصفات الربانية.  ثم ذكر القسم للتوكيد بقوله: { فَوَرَبِّكَ لَنَحْشُرَنَّهُمْ وَٱلشَّيَاطِينَ } [مريم: 68] أي: لنجعلهم مع الشياطين شياطين الجن والإنس { ثُمَّ لَنُحْضِرَنَّهُمْ حَوْلَ جَهَنَّمَ } [مريم: 68] القهر والغضب { جِثِيّاً * ثُمَّ لَنَنزِعَنَّ مِن كُلِّ شِيعَةٍ } [مريم: 68-69] من النفوس المتمردة العاتية { أَيُّهُمْ أَشَدُّ عَلَى ٱلرَّحْمَـٰنِ عِتِيّاً * ثُمَّ لَنَحْنُ أَعْلَمُ بِٱلَّذِينَ } [مريم: 69-70] نزعناهم من { هُمْ أَوْلَىٰ بِهَا صِلِيّاً } [مريم: 70] أي: أولى وأحق لجهنم القهر أن يصليه فيها، ومن منهم أولى وأحق أن ينعم عليه ويميزه عنهم بتخليصه عن ظلمات وجوده بنور وجودنا، ونهديه إلى عالم الوصول والوصال بجذبات العناية الأزلية التي هي كفاية الأبدية.
