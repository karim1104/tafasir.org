وقوله تعالى: { يَهْدِي بِهِ ٱللَّهُ } [المائدة: 16]، أي: بنور النبي صلى الله عليه وسلم وهو نور حكمته وإرشاده { مَنِ ٱتَّبَعَ رِضْوَانَهُ } [المائدة: 16]، أي: من اتبع النبي صلى الله عليه وسلم لأنه رضوان الحق تعالى كما أن الملائكة رضوان الجنة { سُبُلَ ٱلسَّلاَمِ } [المائدة: 16]، طرق السلام وهو الله { وَيُخْرِجُهُمْ مِّنِ ٱلظُّلُمَاتِ } [المائدة: 16]، أي: من ظلمات وجودهم المجازي، { إِلَى ٱلنُّورِ } [المائدة: 16]، أي: إلى نور الله تعالى وهو الوجود الحقيقي الأزلي الأبدي { بِإِذْنِهِ } ، أي: بجذبات عنايته { وَيَهْدِيهِمْ إِلَىٰ صِرَاطٍ مُّسْتَقِيمٍ } [المائدة: 16]، إلى الله تعالى وهذا حقيقة حظ العباد من الله ورسوله فافهم جيداً وإن لم تُفهم حقيقته.
