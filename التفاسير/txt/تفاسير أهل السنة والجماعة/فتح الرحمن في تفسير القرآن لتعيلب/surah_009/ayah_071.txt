{  بَعْضُهُمْ أَوْلِيَاء بَعْضٍ } في مقابلة قوله في المنافقين :  {  بَعْضُهُمْ مّن بَعْضٍ } .  {  سَيَرْحَمُهُمُ الله } السين مفيدة وجود الرحمة لا محالة ،  فهي تؤكد الوعد ،  كما تؤكد الوعيد في قولك :  سأنتقم منك يوماً ،  تعني أنك لا تفوتني وإن تباطأ ذلك ،  ونحوه {  سَيَجْعَلُ لَهُمُ الرحمن وُدّاً } [ مريم :  96 ] ،  {  وَلَسَوْفَ يُعْطِيكَ رَبُّكَ فترضى } [ الضحى :  5 ] ،  {  سَوْفَ يُؤْتِيهِمْ أُجُورَهُمْ } [ النساء :  152 ] .  {  عَزِيزٌ } غالب على كل شيء قادر عليه ،  فهو يقدر على الثواب والعقاب {  حَكِيمٌ } واضع كلا موضعه على حسب الاستحقاق .
