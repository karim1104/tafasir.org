{  إِلا إِحْدَى الحسنيين } إلاّ إحدى العاقبتين اللتين كل واحدة منهما هي حسن العواقب ،  وهما النصرة والشهادة {  وَنَحْنُ نَتَرَبَّصُ بِكُمْ } إحدى السوأتين من العواقب ،  إمّا {  أَن يُصِيبَكُمُ الله بِعَذَابٍ مّنْ عِندِهِ } وهو قارعة من السماء كما نزلت على عاد وثمود {  أَوْ } بعذاب {  بِأَيْدِينَا } وهو القتل على الكفر {  فَتَرَبَّصُواْ } بنا ما ذكرنا من عواقبنا {  إِنَّا مَعَكُمْ مُّتَرَبّصُونَ } ما هو عاقبتكم ،  فلا بدّ أن يلقى كلنا ما يتربصه لا يتجاوزه .
