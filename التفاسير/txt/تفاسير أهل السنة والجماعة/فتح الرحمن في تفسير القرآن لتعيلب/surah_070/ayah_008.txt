{  يوم تكون السماء كالمهل ( 8 ) وتكون الجبال كالعهن ( 9 ) ولا يسأل حميم حميما ( 10 ) }

واليوم الذي توعدون يوم فزع وهول تكون السماء فيه واهية متداعية كأنها رواسب زيت ،  أو ذوب معدان واستحال صخر الجبال إلى ما يشبه الغبار المتناثر أو الصوف المنفوش :  {  وبست الجبال بسا .  فكانت هباء منبثا } {  وتكون الجبال كالعهن المنفوش } .  ولا يسأل القريب قريبه ولا القرين قرينه ولا الحبيب حبيبه عما هو فيه من الكرب حين يغشاه من البلاء ما يذهله :  {   .  .  تذهل كل مرضعة عما أرضعت وتضع كل ذات حمل حملها وترى الناس سكارى وما هم بسكارى ولكن عذاب الله شديد } {  ولكل امرئ منهم يومئذ شأن يغنيه }
