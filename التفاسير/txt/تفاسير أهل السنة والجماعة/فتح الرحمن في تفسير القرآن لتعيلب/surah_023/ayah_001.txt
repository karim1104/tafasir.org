بِسْمِ اللَّهِ الرَّحْمَانِ الرَّحِيمِ

{  قَدْ أَفْلَحَ الْمُؤْمِنُونَ {  1 ) الَّذِينَ هُمْ فِي صَلَاتِهِمْ خَاشِعُونَ {  2 ) وَالَّذِينَ هُمْ عَنِ اللَّغْوِ مُعْرِضُونَ {  3 ) }

{  أفلح } فاز ونجا وبقي في النعيم .

{  المؤمنون } المصدقون بالله وملائكته وكتبه ورسله والآخرة والعاملون بمقتضى التصديق .

/خ1
