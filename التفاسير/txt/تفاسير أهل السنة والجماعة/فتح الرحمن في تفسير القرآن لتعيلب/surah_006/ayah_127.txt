{  لَهُمْ } لقوم يذكرون {  دَارُ السلام } دار الله ،  يعني الجنة أضافها إلى نفسه تعظيماً لها أو دار السلامة من كل آفة وكدر {  عِندَ رَبّهِمْ } في ضمانه كما تقول لفلان عندي حق لا ينسى ،  أو ذخيرة لهم لا يعلمون كنهها ،  كقوله :  {  فَلاَ تَعْلَمُ نَفْسٌ مَّا أُخْفِىَ لَهُم مّن قُرَّةِ أَعْيُنٍ } [ السجدة :  17 ] ،  {  وَهُوَ وَلِيُّهُم } مواليهم ومحبهم أو ناصرهم على أعدائهم {  بِمَا كَانُواْ يَعْمَلُونَ } بسبب أعمالهم ،  أو متوليهم بجزاء ما كانوا يعملون .
