{  أَوَ عَجِبْتُمْ } الهمزة للإنكار ،  والواو للعطف ،  والمعطوف عليه محذوف ،  كأنه قيل :  أكذبتم وعجبتم {  أَن جَاءكُمْ } من أن جاءكم {  ذِكْرٌ } موعظة {  مّن رَّبّكُمْ على رَجُلٍ مّنْكُمْ } على لسان رجل منكم ،  كقوله :  {  مَا وَعَدتَّنَا على رُسُلِكَ } [ آل عمران :  194 ] وذلك أنهم يتعجبون من نبوّة نوح عليه السلام ويقولون :  ما سمعنا بهذا في آبائنا الأوّلين ،  يعنون إرسال البشر ،  ولو شاء ربنا لأنزل ملائكة {  لِيُنذِرَكُمْ وَلِتَتَّقُواْ } ليحذركم عاقبة الكفر وليوجد منكم التقوى وهي الخشية بسبب الإنذار {  وَلَعَلَّكُمْ تُرْحَمُونَ } ولترحموا بالتقوى إن وجدت منكم .
