{  فِي بُيُوتٍ أَذِنَ اللَّهُ أَنْ تُرْفَعَ وَيُذْكَرَ فِيهَا اسْمُهُ يُسَبِّحُ لَهُ فِيهَا بِالْغُدُوِّ وَالْآَصَالِ {  36 ) رِجَالٌ لَا تُلْهِيهِمْ تِجَارَةٌ وَلَا بَيْعٌ عَنْ ذِكْرِ اللَّهِ وَإِقَامِ الصَّلَاةِ وَإِيتَاءِ الزَّكَاةِ يَخَافُونَ يَوْمًا يَخَافُونَ يَوْمًا تَتَقَلَّبُ فِيهِ الْقُلُوبُ وَالْأَبْصَارُ {  37 ) لِيَجْزِيَهُمُ اللَّهُ أَحْسَنَ مَا عَمِلُوا وَيَزِيدَهُمْ مِنْ فَضْلِهِ وَاللَّهُ يَرْزُقُ مَنْ يَشَاءُ بِغَيْرِ حِسَابٍ {  38 ) }

{  في بيوت }في مساجد .

{  أذن الله } أمر الله .

{  ترفع } تبنى وتطهر وتصان

{  يسبح له فيها } يصلى له في المساجد

{  بالغدو } وقت الغداة وهو الصبح وأول النهار إلى زوال الشمس عند الظهيرة .

{  الآصال } وقت الآصال جمع أصيل  وهو من زوال الشمس حتى الصباح  .
