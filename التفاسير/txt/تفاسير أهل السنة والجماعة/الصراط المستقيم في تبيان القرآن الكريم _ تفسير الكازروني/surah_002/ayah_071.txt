{ قَالَ إِنَّهُ يَقُولُ إِنَّهَا بَقَرَةٌ لاَّ ذَلُولٌ } مُذَلَّلَةٌ للعمل { تُثِيرُ } تقلب { ٱلأَرْضَ } للزراعة { وَلاَ تَسْقِي ٱلْحَرْثَ مُسَلَّمَةٌ } عن العمل أو العيب { لاَّ شِيَةَ } لا علامة من لون آخر { فِيهَا قَالُواْ ٱلآنَ جِئْتَ بِٱلْحَقِّ } بحقيقة وصفها، فحصولها { فَذَبَحُوهَا وَمَا كَادُواْ يَفْعَلُونَ } لكثرة مراجعتهم أو خوف التغيير أو لأنهم وجدوها بعد أربعين سنة.
