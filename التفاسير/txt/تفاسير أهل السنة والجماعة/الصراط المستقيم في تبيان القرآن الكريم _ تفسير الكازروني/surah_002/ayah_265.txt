{ وَمَثَلُ ٱلَّذِينَ يُنْفِقُونَ أَمْوٰلَهُمُ ٱبْتِغَآءَ }: طلب، { مَرْضَاتِ ٱللَّهِ وَتَثْبِيتاً }: تصديقا، { مِّنْ أَنْفُسِهِمْ }: بأن الله سيجزيهم عليه، أَفْهَم أن حكمة الإنفاق للمنفق تزكية نفسه من البخل وحب المال، { كَمَثَلِ جَنَّةٍ }: بستان، { بِرَبْوَةٍ }: بموضع مرتفع، { أَصَابَهَا وَابِلٌ }: مطر شديد، { فَآتَتْ }: أعطت، { أُكُلَهَا }: ثمرها، { ضِعْفَيْنِ }: مثلين بالنسبة إلى البساتين، أو المواد الكثرة، كلبيك، { فَإِن لَّمْ يُصِبْهَا وَابِلٌ فَطَلٌّ }: فيصيبها مطر صغيرالقطر، فبستانهم ينتفع، قلَّ ماؤُهُ أو كَثُر، { وَٱللَّهُ بِمَا تَعْمَلُونَ بَصِيرٌ }: فلا تُراءُوا.
