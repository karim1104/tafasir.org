{ كُتِبَ }: فًرِضَ، { عَلَيْكُمْ إِذَا حَضَرَ أَحَدَكُمُ ٱلْمَوْتُ }: أي: أَسْبابُهُ، { إِن تَرَكَ خَيْراً }: مالاً أو مالاً كثيراً، نَبَّهَ بتَسْمَيتَه خيراً أن الوصية تُسْتحبُّ في مال طيب، { ٱلْوَصِيَّةُ }: الإبصاء، { لِلْوَالِدَيْنِ وَٱلأَقْرَبِينَ }: عَطَفَ لأن القرب الإدلاء بواسطة فهما لا يتصفان به، { بِٱلْمَعْرُوفِ }: بالعَدْل بلا ترجيح غَنيّ، وتجاوز ثُلثٍ، حَق ذلك { حَقّاً عَلَى ٱلْمُتَّقِينَ }: هذا كان في صدر الإسلام، فنُسِخَ بآية المَواريث، بدليل حديث: " إنَّ الله أَعْطَى كُلَّ ذِيْ حَقٍّ حَقَّهُ أَلَا لَا وَصِيَّةَ لِوَارثٍ " ، { فَمَن بَدَّلَهُ }: الإيْصَاء، { بَعْدَ مَا سَمِعَهُ }: من الميت، { فَإِنَّمَا إِثْمُهُ }: إثْمُ التَّبْدِيْل، { عَلَى ٱلَّذِينَ يُبَدِّلُونَهُ إِنَّ ٱللَّهَ سَمِيعٌ عَلِيمٌ }: وَصِتَّكُم وتبديلكم.
