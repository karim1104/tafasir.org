{ وَيَسْأَلُونَكَ }: السائل: أبو الدحداح مع جمع عن أحكام { ٱلْمَحِيضِ }: الحَيْض إذْ كانوا لا يؤاكلوهن ولا يساكنوهن حينئذ ترك الواو في الأسئلة الأُول لأنهم سألوها في أوْقَاتٍ متفرقة، وأتى بالواو في البواقي إشارةً إلى أنهم سألوها في وقت واحد عُرْفاً، كشَهْر كذا، { قُلْ هُوَ أَذًى }: كناية عن مستقذر، { فَٱعْتَزِلُواْ }: اجتنبوا، { ٱلنِّسَآءَ }: مُجَامعتَهُنَّ، { فِي ٱلْمَحِيضِ وَلاَ تَقْرَبُوهُنَّ }: بالجماع، { حَتَّىٰ يَطْهُرْنَ }: بالاغتسال أو التيمم، وَعند أبي حنيفة -رحمه الله- بدُوْنه إن طهرن لأكثر الحيض، وتأتي قراءةُ: يُطَّهَّرْن بالتشديد وفقٌ له:، { فَإِذَا تَطَهَّرْنَ فَأْتُوهُنَّ } بالجماع، { مِنْ حَيْثُ }: من مأْتَى، { أَمَرَكُمُ ٱللَّهُ }: وهو القبل، { إِنَّ ٱللَّهَ يُحِبُّ ٱلتَّوَّابِينَ وَيُحِبُّ ٱلْمُتَطَهِّرِينَ }: من الأقذار، { نِسَآؤُكُمْ حَرْثٌ }: موضع حرث، { لَّكُمْ فَأْتُواْ حَرْثَكُمْ }: جامعوهن، { أَنَّىٰ }: من أي: جهة، { شِئْتُمْ }: بعد ملاحظة موضع الحرث، لا كما قال اليهود: الجماع في القبل مدبرة يسخط الله، ويجعل الولد أحول، { وَقَدِّمُواْ لأَنْفُسِكُمْ }: ثواب امتثال أمر الله، { وَٱتَّقُواْ ٱللَّهَ }: في معاصيه، { وَٱعْلَمُوۤاْ أَنَّكُمْ مُّلاَقُوهُ } يوم القيامة، { وَبَشِّرِ ٱلْمُؤْمِنِينَ }: الذين اتقوه.
