{ قَالَ } بعد عجزهم { يَآءَادَمُ أَنبِئْهُمْ بِأَسْمَآئِهِمْ } فقال: أنت جبريل، وأنت ميكائيل حتى وصل الغراب وذكر حكمته التي خُلِقَ لَهَا { فَلَمَّآ أَنْبَأَهُمْ بِأَسْمَآئِهِمْ قَالَ } وتوبيخاً أو تقريراً { أَلَمْ أَقُلْ لَّكُمْ إِنِيۤ أَعْلَمُ غَيْبَ } ما غاب في { ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ } عن الخلق { وَأَعْلَمُ مَا تُبْدُونَ } تُظْهِرُوْنَهُ بألسنتكم نحو [البقرة: 30] إلى آخره { وَمَا كُنْتُمْ تَكْتُمُونَ } تسرونه من أنكم أحق بالخلافة استفدنا أن تعلم اللغة خير من التخلي للعبادة، وأن اللغة، وأن اللغة توقيفية، وأن علوم المَلَكِ وكماله يقبل الزيادة وأن آدم أفضل منهم ولو من وجه.
