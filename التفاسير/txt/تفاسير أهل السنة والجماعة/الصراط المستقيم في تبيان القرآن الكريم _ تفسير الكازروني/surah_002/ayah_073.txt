{ فَقُلْنَا ٱضْرِبُوهُ } القتيل { بِبَعْضِهَا } أي: البقرة ليحيا، فضَربُوه بلسانها فحيى وأخبر ومات بلا مهلة { كَذَلِكَ } الإحياء به { يُحْيِي ٱللَّهُ ٱلْمَوْتَىٰ وَيُرِيكُمْ آيَاتِهِ } دلائل قدرته { لَعَلَّكُمْ تَعْقِلُونَ } أن من قدر عليه قدرعلى الحشر وإنما لم يحيه - الله ابتداء بلا شرط لما فيه من التقرب وأداء الواجب ونفع اليتيم وبيان بركة التوكل والشفقة على الأولاد واستجاب القربة للطالب والمغالاة بثمنها وغير ذلك من الحكم.
