{ وَإِذْ قُلْنَا } بعد التيه { ٱدْخُلُواْ هَـٰذِهِ ٱلْقَرْيَةَ } أريحا أو بيت المقدس، وهم ما دَخَلوه إلَّا زمان يُوْشَع { فَكُلُواْ مِنْهَا حَيْثُ شِئْتُمْ رَغَداً } واسعاً { وَٱدْخُلُواْ ٱلْبَابَ } باب القرية، أو قبة كانوا يُصَلُّوْنَ إليها { سُجَّداً } مُنحنِيْنَ تواضعاً، أو ساجدين شكراً { وَقُولُواْ } مسألتنا { حِطَّةٌ } لخطئينا، أو حط حطة { نَّغْفِرْ لَكُمْ خَطَٰيَٰكُمْ } هذا لعُصَاتِهم { وَسَنَزِيدُ ٱلْمُحْسِنِينَ } ثواباً.
