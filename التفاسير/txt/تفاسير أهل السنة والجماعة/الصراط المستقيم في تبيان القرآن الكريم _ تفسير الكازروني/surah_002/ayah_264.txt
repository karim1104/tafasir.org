{ قَوْلٌ مَّعْرُوفٌ }: رَدٌّ حَسَنٌ، { وَمَغْفِرَةٌ }: تجاوز عن إلحاح السائل، { خَيْرٌ مِّن صَدَقَةٍ يَتْبَعُهَآ أَذًى وَٱللَّهُ غَنِيٌّ }: عَن إنفاقكم، { حَلِيمٌ }: لا يعجل عقوبتكم، { يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ لاَ تُبْطِلُواْ }: ثَواب، { صَدَقَٰتِكُم بِٱلْمَنِّ وَٱلأَذَىٰ }: { كَ } إبطال المنافق، { ٱلَّذِي يُنْفِقُ مَالَهُ رِئَآءَ ٱلنَّاسِ }: مُرائياً لهم لطب المدحة والشهرة، { وَلاَ يُؤْمِنُ بِٱللَّهِ وَٱلْيَوْمِ ٱلآخِرِ فَمَثَلُهُ }: أي: المرائي، { كَمَثَلِ صَفْوَانٍ }: حجر أملس، { عَلَيْهِ تُرَابٌ }: يرى أرضا طيبة للزرع فيها بإزاء عمله، { فَأَصَابَهُ وَابِلٌ }: مطر عظيم القَطْر، هذا بإزاء الغنى، { فَتَرَكَهُ صَلْداً }: أمْلس بلا تُرَاب، { لاَّ يَقْدِرُونَ }: جمعٌ بمعنى الذي، { عَلَىٰ شَيْءٍ مِّمَّا كَسَبُواْ }: لا ينتفعون به، { وَٱللَّهُ لاَ يَهْدِي ٱلْقَوْمَ ٱلْكَافِرِينَ }: إيماء إلى أن الرياء صفتهم فاحذروا.
