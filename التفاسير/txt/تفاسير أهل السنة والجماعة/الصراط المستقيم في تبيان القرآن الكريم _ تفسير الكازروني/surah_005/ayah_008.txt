{ وَٱذْكُرُواْ نِعْمَةَ ٱللَّهِ عَلَيْكُمْ }: دينية ودنيويه، { وَمِيثَاقَهُ ٱلَّذِي وَاثَقَكُم بِهِ }: ببيعة الرضوان، { إِذْ قُلْتُمْ سَمِعْنَا وَأَطَعْنَا }: في المنشط والمكره، { وَٱتَّقُواْ ٱللَّهَ }: في نقض عهده، { إِنَّ ٱللَّهَ عَلِيمٌ بِذَاتِ ٱلصُّدُورِ }: خفياتها، { يَا أَيُّهَآ ٱلَّذِينَ آمَنُواْ كُونُواْ قَوَّامِينَ }: بالحقِّ، { للَّهِ }: لا رياء، { شُهَدَآءَ بِٱلْقِسْطِ }: بالعدل، { وَلاَ يَجْرِمَنَّكُمْ }: يكسبنكم، { شَنَآنُ }: بغض، { قَوْمٍ عَلَىۤ أَلاَّ تَعْدِلُواْ ٱعْدِلُواْ }: ولو مع العدو، وهو العدل، { هُوَ } العَدْلُ { أَقْرَبُ لِلتَّقْوَىٰ }: من قبيل [الفرقان: 24] إلى آخره، { وَٱتَّقُواْ ٱللَّهَ إِنَّ ٱللَّهَ خَبِيرٌ بِمَا تَعْمَلُونَ }: فيجازيكم.
