{ وَمَنْ } لا { أَظْلَمُ مِمَّنِ ٱفْتَرَىٰ عَلَى ٱللَّهِ كَذِباً }: بافتراء الأحكام، { أَوْ قَالَ أُوْحِيَ إِلَيَّ }: كمسيلمة، { وَلَمْ يُوحَ إِلَيْهِ شَيْءٌ }: وهذا تخصيص بعد تعميم، { وَ } لمزيد قباحته، { مَن قَالَ سَأُنزِلُ مِثْلَ مَآ أَنَزلَ ٱللَّهُ }: كمن قال: [الأنفال: 31]، { وَلَوْ تَرَىۤ إِذِ ٱلظَّالِمُونَ }: كلهم، { فِي غَمَرَاتِ }: شدائد، { ٱلْمَوْتِ وَٱلْمَلاۤئِكَةُ بَاسِطُوۤاْ أَيْدِيهِمْ }: بقبض أرواحهم كمتقاض مُلِظّ، قائلين زَجراً { أَخْرِجُوۤاْ أَنْفُسَكُمُ }: في الحديث " أرواح الكفار تأبى الخروج فتضربهم الملائكةُ حتى تَخرج " { ٱلْيَوْمَ }: يَوم الموت، { تُجْزَوْنَ عَذَابَ ٱلْهُونِ }: الذل { بِمَا كُنتُمْ تَقُولُونَ عَلَى ٱللَّهِ }: قولا، { غَيْرَ ٱلْحَقِّ وَكُنْتُمْ عَنْ آيَاتِهِ تَسْتَكْبِرُونَ }: فما آمنتم بها.
