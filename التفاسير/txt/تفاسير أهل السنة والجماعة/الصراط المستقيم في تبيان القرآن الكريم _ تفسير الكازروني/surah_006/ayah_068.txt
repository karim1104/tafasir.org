{ لِّكُلِّ نَبَإٍ }: خبر من أخبار الله، { مُّسْتَقَرٌّ }: وقت وقوع، { وَسَوْفَ تَعْلَمُونَ }: إمَّا في الدنيا أو في العقبى أو مُبعضاً، { وَإِذَا رَأَيْتَ ٱلَّذِينَ يَخُوضُونَ فِيۤ ءَايَاتِنَا }: بنحو الطَّعن { فَأَعْرِضْ عَنْهُمْ }: بترك مجالستهم، { حَتَّىٰ يَخُوضُواْ فِي حَدِيثٍ غَيْرِهِ }: غير الخَوْض { وَإِمَّا يُنسِيَنَّكَ ٱلشَّيْطَٰنُ }: هو الذي وسوسه، { فَلاَ تَقْعُدْ بَعْدَ ٱلذِّكْرَىٰ }: التذكرة { مَعَ ٱلْقَوْمِ ٱلظَّٰلِمِينَ }: أي معهم.
