{ وَأَنَّ }: بالكسر استئناف وبالفتح علة لقوله: فاتبعوه، { هَـٰذَا } ما في الآيتين { صِرَاطِي }: ديني، { مُسْتَقِيماً فَٱتَّبِعُوهُ وَلاَ تَتَّبِعُواْ ٱلسُّبُلَ } التي غيره { فَتَفَرَّقَ بِكُمْ }: فتزيلكم، { عَن سَبِيلِهِ }: المستقيم، { ذٰلِكُمْ }: الاتباع، { وَصَّاكُمْ بِهِ لَعَلَّكُمْ تَتَّقُونَ }: الضلال.
