{ وَلَقَدْ جِئْتُمُونَا فُرَٰدَىٰ }: جمع فريد منفردين عن الشفاء والأهل والمال مجيئا، { كَمَا خَلَقْنَٰكُمْ أَوَّلَ مَرَّةٍ وَتَرَكْتُمْ مَّا خَوَّلْنَٰكُمْ }: تفضلنا عليكم من المال، { وَرَاءَ ظُهُورِكُمْ وَمَا نَرَىٰ مَعَكُمْ شُفَعَآءَكُمُ ٱلَّذِينَ زَعَمْتُمْ أَنَّهُمْ فِيكُمْ }: فيما بينكم، { شُرَكَآءُ }: لله، { لَقَد تَّقَطَّعَ بَيْنَكُمْ }: وصلكم، وبالفتح ظرف لما المحذوفَة { وَضَلَّ } ضَاعَ { عَنكُم مَّا كُنتُمْ تَزْعُمُونَ }: أنه شريك وشفيع.
