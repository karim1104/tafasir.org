{ وَلاَ تَقْرَبُواْ مَالَ ٱلْيَتِيمِ إِلاَّ بِٱلَّتِي }: بالطريقة التي { هِيَ أَحْسَنُ }:وهي ما فيه صلاحه، وتخصيصه مع أن مال البالغ كذلك لأن طمع الطامعين وفيه أكثر لضعفهم ولعظم إثمه { حَتَّىٰ يَبْلُغَ أَشُدَّهُ }: جمع شدَّة كأنعم جمع نعمة، وقيل: ولا واحد له بمعنى بلوغه، أي: ثم سلموه إليه { وَأَوْفُواْ ٱلْكَيْلَ وَٱلْمِيزَانَ بِٱلْقِسْطِ }: بالعدل بمعنى لا تبخسوا، { لاَ نُكَلِّفُ نَفْساً إِلاَّ وُسْعَهَا }: أي ما يسعها، وفوقه معفو عنه، { وَإِذَا قُلْتُمْ }: تكلمتم في شيء، { فَٱعْدِلُواْ }: في القول بمعنى: لا تتركوه، أفهم أنه في الفعل أولى، { وَلَوْ كَانَ }: المقول له أو عليه { ذَا قُرْبَىٰ } من قرابتكم { وَبِعَهْدِ ٱللَّهِ أَوْفُواْ }: أي: لا تنكثوا، { ذٰلِكُمْ وَصَّـٰكُمْ بِهِ لَعَلَّكُمْ تَذَكَّرُونَ }: خَصَّها بالذكر لأنها خفية تحتاج إلى اجتهاد وتذكر بخلاف الخمسة الأول، فإنها يكفي فيها العقل لظهورها.
