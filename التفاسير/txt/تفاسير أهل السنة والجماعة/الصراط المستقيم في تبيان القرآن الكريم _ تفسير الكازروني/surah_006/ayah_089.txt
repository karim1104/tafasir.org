{ أُوْلَـٰئِكَ ٱلَّذِينَ آتَيْنَاهُمُ ٱلْكِتَابَ }: جنسه { وَٱلْحُكْمَ }: الحكمة أي: العلم والعمل به { وَٱلنُّبُوَّةَ فَإِن يَكْفُرْ بِهَا }: بالنبوة أو بالثلاثة، { هَـٰؤُلاۤءِ }: أهل مكة { فَقَدْ وَكَّلْنَا بِهَا }: بمراعاتها، { قَوْماً لَّيْسُواْ بِهَا بِكَافِرِينَ }: هم الصَّحابة وتابعوهم، أو الفرس.
