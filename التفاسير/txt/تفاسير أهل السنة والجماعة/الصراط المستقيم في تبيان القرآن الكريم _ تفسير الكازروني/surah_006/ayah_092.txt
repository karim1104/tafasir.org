{ وَهَـٰذَا }: القرآن، { كِتَٰبٌ أَنزَلْنَٰهُ مُبَارَكٌ }: كثير النفع، { مُّصَدِّقُ ٱلَّذِي بَيْنَ يَدَيْهِ }: من الكتب السماوية للبركات، { وَلِتُنذِرَ }: به، { أُمَّ ٱلْقُرَىٰ }: أهل مكة، فإن الأرض دُحَيِتْ منْ تحتها { وَمَنْ حَوْلَهَا } أهل المشرق والمغرب، { وَٱلَّذِينَ يُؤْمِنُونَ بِٱلأَخِرَةِ }: إيماناً يعتد به بخلاف بعض أهل الكتاب، { يُؤْمِنُونَ بِهِ }: بالقرآن، { وَهُمْ عَلَىٰ صَلاَتِهِمْ يُحَافِظُونَ }: فإن خوف الآخرة يحمله على التدبير حتى يؤمن بالنبيّ والكتاب ويحافظ على ما هو عِمَاد الدين.
