لمَّا منعهُ عن ضيق الصدر، استعجالاً للنصر وعذابهم الموعود قال: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * أَتَىٰ }: تحقَّق وقوعاً { أَمْرُ ٱللَّهِ }: وعده من القيامة وغيرها، { فَلاَ تَسْتَعْجِلُوهُ }: أيها المشركون، فإنه واقع، { سُبْحَانَهُ وَتَعَالَىٰ عَمَّا } مشاركة { يُشْرِكُونَ * يُنَزِّلُ ٱلْمَلاۤئِكَةَ }: جبريل، { بِٱلْرُّوحِ }: بالوحي المحي للقلوب، { مِنْ أَمْرِهِ }: بأمره، { عَلَىٰ مَن يَشَآءُ مِنْ عِبَادِهِ أَنْ }: بأن، { أَنْذِرُوۤاْ }: اعلموا، { أَنَّهُ لاَ إِلَـٰهَ إِلاَّ أَنَاْ فَٱتَّقُونِ * خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ بِٱلْحَقِّ }: بالحكمة، { تَعَالَىٰ عَمَّا } مشاركة { يُشْرِكُونَ }  { خَلَقَ ٱلإِنْسَانَ مِن نُّطْفَةٍ فَإِذَا هُوَ }: حين اسْتقلّ، { خَصِيمٌ } لربه { مُّبِينٌ }: ظاهر الخصومة.
