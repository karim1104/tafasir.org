{ فَقَالُواْ عَلَىٰ ٱللَّهِ تَوَكَّلْنَا رَبَّنَا لاَ تَجْعَلْنَا فِتْنَةً لِّلْقَوْمِ ٱلظَّالِمِينَ }: بتسليطهم فيفتنونا في ديننا فَيظن بنا الضلا، نَبَّهَ على أن تقديم التوكل على الدعاء يوجب الإجابة، { وَنَجِّنَا بِرَحْمَتِكَ مِنَ }: كيد، { ٱلْقَوْمِ ٱلْكَافِرِينَ * وَأَوْحَيْنَآ إِلَىٰ مُوسَىٰ وَأَخِيهِ أَن تَبَوَّءَا }: اتخذا مباءةً موضع أقامة، { لِقَوْمِكُمَا بِمِصْرَ بُيُوتاً وَٱجْعَلُواْ بُيُوتَكُمْ قِبْلَةً }: مُصلَّى، كانوا لا يصلون إلاَّ في كنائسهم، وخافوا من فرعون { وَأَقِيمُواْ ٱلصَّلٰوةَ }: فيها، { وَبَشِّرِ }: يا موسى { ٱلْمُؤْمِنِينَ }: بالنصر، ثنى أوَّلاً لأنَّ التبوئه للرئيس، ثم جمع لأن تحصيل مواضع الصلاة يجب على الكل ثم وحَّد لأن البشارة لصاحب الشريعة، { وَقَالَ مُوسَىٰ رَبَّنَآ إِنَّكَ آتَيْتَ فِرْعَوْنَ وَمَلأَهُ زِينَةً }: ما يتزين به، { وَأَمْوَالاً فِي ٱلْحَيَاةِ ٱلدُّنْيَا رَبَّنَا لِيُضِلُّواْ عَن سَبِيلِكَ }: أي: استدرجتهم بإيتائها، { رَبَّنَا ٱطْمِسْ عَلَىٰ أَمْوَالِهِمْ }: أذهب نورها وبهجتها فاصرت معادنهم مطموسة ودراهمهم حجارة منقوشة { وَٱشْدُدْ عَلَىٰ قُلُوبِهِمْ }: أقسها { فَلاَ يُؤْمِنُواْ }: جاب الدعاء، { حَتَّىٰ يَرَوُاْ ٱلْعَذَابَ ٱلأَلِيمَ }: دعا به غضباً لله ولدينه بعد يأسه من إيمانهم، كلعنتنا على إبليس، ثم الرضا بالكفر من حيث إنه كُفْرٌّ كُفر لا يكفر شخص معين بعقوبته، أو عطف على: ليضلوا، وقيل: بمعنى: فلا آمنوا، { قَالَ }: الله، { قَدْ أُجِيبَتْ دَّعْوَتُكُمَا }: لأن هارون أمن على دعائه، { فَٱسْتَقِيمَا }: على الدعوة إليَّ { وَلاَ تَتَّبِعَآنِّ سَبِيلَ ٱلَّذِينَ لاَ يَعْلَمُونَ }: في الاستعجال، ثم حصل بعد أربعين سنة.
