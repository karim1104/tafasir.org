{ وَإِن كَذَّبُوكَ }: أصروا على تكذيبك { فَقُل لِّي عَمَلِي وَلَكُمْ عَمَلُكُمْ }: أي: تبرأ منهم، { أَنتُمْ بَرِيۤئُونَ مِمَّآ أَعْمَلُ }: من الطاعة، { وَأَنَاْ بَرِيۤءٌ مِّمَّا تَعْمَلُونَ }: من المعصية، نُسخَتْ بالسَّيف، { وَمِنْهُمْ مَّن يَسْتَمِعُونَ إِلَيْكَ }: إذا قرأْت القرآن بلا قبول، { أَفَأَنتَ تُسْمِعُ ٱلصُّمَّ }: أتقدر على إسماعهم؟ { وَلَوْ كَانُواْ لاَ يَعْقِلُونَ }: مع صممهم، نبَّه على أن حقيقة استماع كلام فهم معناه { وَمِنهُمْ مَّن يَنظُرُ إِلَيْكَ }: ويعاين دلائل صدقكَ { أَفَأَنْتَ تَهْدِي ٱلْعُمْيَ وَلَوْ كَانُواْ لاَ يُبْصِرُونَ }: أي: ولو انضم إلى العمى عدم البصيرةِ، فهما تعليل للتبري، { إِنَّ ٱللَّهَ لاَ يَظْلِمُ ٱلنَّاسَ شَيْئاً }: بسَلْب حواسِّهم وعقولهم، دلَّ على أنَّ للعبد كسباً اختياراً، خلافاً للمجبرة، { وَلَـٰكِنَّ ٱلنَّاسَ أَنفُسَهُمْ يَظْلِمُونَ }: بتضييعها، { وَ }: اذكر، { يَوْمَ يَحْشُرُهُمْ كَأَن }: كأنه { لَّمْ يَلْبَثُوۤاْ إِلاَّ سَاعَةً مِّنَ ٱلنَّهَارِ }: في الدنيا أو القبر لهولِ المحشرِ { يَتَعَارَفُونَ بَيْنَهُمْ }: يعرف بعضهم بعضاً، كأنهم لم يتعارفوا { إِلاَّ سَاعَةً }: قليلاً ثم ينقطع التعارف، { قَدْ خَسِرَ ٱلَّذِينَ كَذَّبُواْ بِلِقَآءِ ٱللَّهِ }: بالبعث، { وَمَا كَانُواْ مُهْتَدِينَ }: لمصالح هذه التجارة.
