{ وَجَاوَزْنَا بِبَنِيۤ إِسْرَائِيلَ ٱلْبَحْرَ }: في أرضه، { فَأَتْبَعَهُمْ }: لحقهم، { فِرْعَوْنُ وَجُنُودُهُ بَغْياً }: باغين { وَعَدْواً }: ظالمين، { حَتَّىٰ إِذَآ أَدْرَكَهُ ٱلْغَرَقُ قَالَ آمَنتُ أَنَّهُ }: بأنه، { لاۤ إِلِـٰهَ إِلاَّ ٱلَّذِي آمَنَتْ بِهِ بَنوۤاْ إِسْرَائِيلَ وَأَنَاْ مِنَ ٱلْمُسْلِمِينَ }: فدَسَّ جبريل في فمه الحَمْأةَ مخافة قبوله فقال الله أو جبريل: { آلآنَ }: حين يأْسكَ تؤمن: [غافر: 85] { وَقَدْ عَصَيْتَ قَبْلُ }: مدة عمرك { وَكُنتَ مِنَ ٱلْمُفْسِدِينَ }: المضلين { فَٱلْيَوْمَ نُنَجِّيكَ }: نبعدك عن قعر البحر فنجعلك طافيا، ولم ير من الغرقاء غير فرعون { بِبَدَنِكَ }: بلا روح أو بدرعك أو نلقيه على نجوةٍ من الأرض، قال ابن عباس - رضي الله عنهما - كان له درعمن ذهب يرف به { لِتَكُونَ لِمَنْ خَلْفَكَ }: بعدك من القرون، { آيَةً }: عبرة { وَإِنَّ كَثِيراً مِّنَ ٱلنَّاسِ عَنْ آيَاتِنَا لَغَافِلُونَ }: لا يتفركون بها.
