{ قَاتِلُوهُمْ يُعَذِّبْهُمُ ٱللَّهُ بِأَيْدِيكُمْ وَيُخْزِهِمْ }: يذلهم، { وَيَنْصُرْكُمْ عَلَيْهِمْ وَيَشْفِ صُدُورَ قَوْمٍ مُّؤْمِنِينَ }: الذين كانوا متأذين منهم، { وَيُذْهِبْ غَيْظَ }: كَرْب { قُلُوبِهِمْ }: لما لقوا منهم { وَيَتُوبُ ٱللَّهُ عَلَىٰ مَن يَشَآءُ }: كأبي سفيان وأضرابهِ { وَٱللَّهُ عَلِيمٌ }: بالكائنات { حَكِيمٌ }: في أفعاله.
