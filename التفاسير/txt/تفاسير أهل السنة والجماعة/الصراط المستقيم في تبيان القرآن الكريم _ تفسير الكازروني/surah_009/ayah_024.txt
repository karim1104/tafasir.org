{ يُبَشِّرُهُمْ رَبُّهُم بِرَحْمَةٍ مِّنْهُ وَرِضْوَانٍ وَجَنَّاتٍ لَّهُمْ فِيهَا نَعِيمٌ مُّقِيمٌ }: دَائمٌ { خَالِدِينَ فِيهَآ أَبَداً إِنَّ ٱللَّهَ عِندَهُ أَجْرٌ عَظِيمٌ }: يستحقرُ دونه كلُّ نعيم الدنيا { يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ لاَ تَتَّخِذُوۤاْ آبَآءَكُمْ وَإِخْوَانَكُمْ أَوْلِيَآءَ }: أصدقاء، { إِنِ ٱسْتَحَبُّواْ }: اختاروا { ٱلْكُفْرَ عَلَى ٱلإِيمَانِ وَمَن يَتَوَلَّهُمْ مِّنكُمْ فَأُوْلَـٰئِكَ هُمُ ٱلظَّالِمُونَ * قُلْ إِن كَانَ آبَاؤُكُمْ وَأَبْنَآؤُكُمْ وَإِخْوَانُكُمْ وَأَزْوَاجُكُمْ وَعَشِيرَتُكُمْ }: أقاربكم، { وَأَمْوَالٌ ٱقْتَرَفْتُمُوهَا }: اكتسبتموها { وَتِجَارَةٌ تَخْشَوْنَ كَسَادَهَا }: عدم نفاقها، { وَمَسَاكِنُ تَرْضَوْنَهَآ }: تستطيبونها، { أَحَبَّ إِلَيْكُمْ }: حُبّاً اختيارياً لا طبيعياً إذ لا يكلف به { مِّنَ ٱللَّهِ وَرَسُولِهِ وَجِهَادٍ فِي سَبِيلِهِ فَتَرَبَّصُواْ حَتَّىٰ يَأْتِيَ ٱللَّهُ بِأَمْرِهِ }: عقابه، قيل هو فتح مكَّةَ، { وَٱللَّهُ لاَ يَهْدِي }: لا يُرشدُ { ٱلْقَوْمَ ٱلْفَاسِقِينَ }: فيه تشديد، قلَّ مَن يتخلص عنه.
