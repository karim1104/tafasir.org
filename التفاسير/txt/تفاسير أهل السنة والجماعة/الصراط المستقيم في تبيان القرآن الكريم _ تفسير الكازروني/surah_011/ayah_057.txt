{ إِن نَّقُولُ إِلاَّ ٱعْتَرَاكَ }: أصابكَ { بَعْضُ آلِهَتِنَا بِسُوۤءٍ }: بجنون لأنك تسبهم { قَالَ إِنِّيۤ أُشْهِدُ ٱللَّهَ } على نفسي { وَٱشْهَدُوۤاْ أَنِّي بَرِيۤءٌ مِّمَّا تُشْرِكُونَ * مِن دُونِهِ }: به، { فَكِيدُونِي }: أنتم مع كمال قوَّتكم وآلهتكم { جَمِيعاً ثُمَّ لاَ تُنظِرُونِ }: لا تُمْهلون وهذا من معجزاته، { إِنِّي تَوَكَّلْتُ عَلَى ٱللَّهِ رَبِّي وَرَبِّكُمْ مَّا مِن دَآبَّةٍ إِلاَّ هُوَ آخِذٌ بِنَاصِيَتِهَآ } تمثل لقدرته عليهم وتصريفهم على ما يريده، ومن لطائفه أنه مادة اسم قائله على قاعدة المُعمى، { إِنَّ رَبِّي عَلَىٰ صِرَاطٍ مُّسْتَقِيمٍ }: على العدل فيجازي كُلاًّ بعمله أو: يدل عليه { فَإِن تَوَلَّوْاْ }: فتتولوا فلا شيء عليَّ { فَقَدْ أَبْلَغْتُكُمْ مَّآ أُرْسِلْتُ بِهِ إِلَيْكُمْ }: وما عليَّ ألاَّ البلاغ، { وَيَسْتَخْلِفُ رَبِّي قَوْماً غَيْرَكُمْ }: بعد استئصالكم، { وَلاَ تَضُرُّونَهُ }: بإعراضكم { شَيْئاً إِنَّ رَبِّي عَلَىٰ كُلِّ شَيْءٍ حَفِيظٌ } فلا تخفى عليه أعمالكم.
