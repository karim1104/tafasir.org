{ بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * الۤر }: هذا، { كِتَابٌ أَنزَلْنَاهُ إِلَيْكَ لِتُخْرِجَ ٱلنَّاسَ }: بدعوتهم إلى مضمونه { مِنَ ٱلظُّلُمَاتِ }: الضلالات، { إِلَى ٱلنُّورِ }: الهدى، { بِإِذْنِ }: بتوفيق، { رَبِّهِمْ إِلَىٰ صِرَاطِ }: بدل من: إلى النور، { ٱلْعَزِيزِ }: الغالب، { ٱلْحَمِيدِ }: المستحق للحمد، أفهم بتخصيص الوصفين أنه لا يذل سالكه، ولا يخيب سائله.
