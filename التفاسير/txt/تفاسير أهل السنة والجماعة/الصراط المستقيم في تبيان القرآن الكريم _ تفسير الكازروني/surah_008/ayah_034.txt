{ وَمَا لَهُمْ }: أن أي: كيف { لاَّ يُعَذِّبَهُمُ ٱللَّهُ }: بعد خروجك مع المؤمنين، { وَهُمْ يَصُدُّونَ }: يَمنعون المؤمنين { عَنِ ٱلْمَسْجِدِ ٱلْحَرَامِ }: كعام الحديبية، { وَمَا كَانُوۤاْ أَوْلِيَآءَهُ }: مستحقين ولاتيه، { إِنْ }: ما، { أَوْلِيَآؤُهُ إِلاَّ ٱلْمُتَّقُونَ }: الشرك، { وَلَـٰكِنَّ أَكْثَرَهُمْ لاَ يَعْلَمُونَ }: عدم ولا يهتم.
