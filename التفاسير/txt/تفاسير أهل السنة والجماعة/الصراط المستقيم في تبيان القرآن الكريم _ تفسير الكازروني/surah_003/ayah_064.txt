{ قُلْ يٰأَهْلَ ٱلْكِتَابِ تَعَالَوْاْ إِلَىٰ كَلِمَةٍ سَوَآءٍ }: مستوية، { بَيْنَنَا وَبَيْنَكُمْ }: لا يختلف فيه كتاب وَلا رَسُولٌ وهيَ: { أَلاَّ نَعْبُدَ إِلاَّ ٱللَّهَ وَلاَ نُشْرِكَ بِهِ شَيْئاً }: في استحقاق العبادة، { وَلاَ يَتَّخِذَ بَعْضُنَا بَعْضاً أَرْبَاباً مِّن دُونِ ٱللَّهِ }: كاتخاذ اليهود عزيزاً، والنصارى عيسى وإطاعة الأحبار والرهبان في إحداث التحريم والتحليل ومعنى { فَإِن تَوَلَّوْاْ } سيأتي وهو في المائدة، { فَقُولُواْ ٱشْهَدُواْ بِأَنَّا مُسْلِمُونَ }: عن إجابتها، { يٰأَهْلَ ٱلْكِتَابِ لِمَ تُحَآجُّونَ فِيۤ إِبْرَاهِيمَ }: مُوحِّدون دونكم: فتزعمون بيهودِّيَّته ونصرانيته، { وَمَآ أُنزِلَتِ ٱلتَّورَاةُ وَٱلإنْجِيلُ إِلاَّ مِن بَعْدِهِ }: بألف سنة وألفي سنة، ومنهما أُخِّذَتا، { أَفَلاَ تَعْقِلُونَ }: فتدعون محالاً.
