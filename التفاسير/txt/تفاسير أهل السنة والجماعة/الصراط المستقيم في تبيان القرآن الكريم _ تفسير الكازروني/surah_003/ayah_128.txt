{ وَمَا جَعَلَهُ ٱللَّهُ }: أي: الإمتداد، { إِلاَّ بُشْرَىٰ }: بشارة، { لَكُمْ }: بالنصر بأنكم على الحق، { وَلِتَطْمَئِنَّ } لتسكن { قُلُوبُكُمْ بِهِ وَمَا ٱلنَّصْرُ إِلاَّ مِنْ عِندِ ٱللَّهِ ٱلْعَزِيزِ } الغالب { ٱلْحَكِيمِ }: في أفعاله، ونصركم { لِيَقْطَعَ }: لينقص، { طَرَفاً }: جانباً، { مِّنَ ٱلَّذِينَ كَفَرُوۤاْ }: بالقتل والسبي والفرار { فَيَنقَلِبُواْ }: يخزيهم، وأو للتنويع،يرجعوا { خَآئِبِينَ }:، منقطعي الآمال، { لَيْسَ لَكَ مِنَ ٱلأَمْرِ شَيْءٌ }: من إصلاحهم وعقابهم، { أَوْ يَتُوبَ عَلَيْهِمْ } عُطِفَ على { أَوْ يَكْبِتَهُمْ } وما قبله اعتراض أو بمعنى " إلا " أن { أَوْ يُعَذِّبَهُمْ فَإِنَّهُمْ ظَالِمُونَ }: فيستحقوا العذاب.
