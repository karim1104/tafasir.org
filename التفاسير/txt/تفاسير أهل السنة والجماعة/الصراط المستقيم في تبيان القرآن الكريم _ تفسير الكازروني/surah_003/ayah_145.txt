{ وَمَا كَانَ لِنَفْسٍ أَنْ تَمُوتَ إِلاَّ بِإِذْنِ ٱللهِ }: فلا أثر للجُبْن والشَّجاعَة فقد كتب ذلك، { كِتَٰباً مُّؤَجَّلاً }: مؤقتاً، { وَمَن يُرِدْ ثَوَابَ ٱلدُّنْيَا }: بعمله، { نُؤْتِهِ مِنْهَا }: إن أردنا، وفيه تعريض لمن سبقتهم الغنائم يوم أحد، { وَمَن يُرِدْ ثَوَابَ ٱلآخِرَةِ }: كمن ثبت وحارب، { نُؤْتِهِ مِنْهَا }: من ثوابها، { وَسَنَجْزِي ٱلشَّٰكِرِينَ }: نعمة الله.
