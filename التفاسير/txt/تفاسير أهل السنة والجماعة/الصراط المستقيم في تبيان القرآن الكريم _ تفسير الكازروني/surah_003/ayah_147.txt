{ وَكَأَيِّن }: كم، { مِّن نَّبِيٍّ قَاتَلَ مَعَهُ رِبِّيُّونَ }: ربانيون كما مر، أو عابدون لربهم جماعات منسوب إلى ربه أي: الجماعة، { كَثِيرٌ فَمَا وَهَنُواْ }: افتروا خوفاً { لِمَآ أَصَابَهُمْ فِي سَبِيلِ ٱللَّهِ }: من قتلهم أو قتل نبيهم، { وَمَا ضَعُفُواْ }: عن العدو، { وَمَا ٱسْتَكَانُواْ }: ما خَضَعُوا للعدُو، والاستكانة الخضوع عَن ذُلٍّ، { وَٱللَّهُ يُحِبُّ ٱلصَّابِرِينَ * وَمَا كَانَ قَوْلَهُمْ }: مع ثبوتهم، { إِلاَّ أَن قَالُواْ ربَّنَا ٱغْفِرْ لَنَا ذُنُوبَنَا وَإِسْرَافَنَا فِيۤ أَمْرِنَا وَثَبِّتْ أَقْدَامَنَا }: في الحروب، { وٱنْصُرْنَا عَلَى ٱلْقَوْمِ ٱلْكَافِرِينَ * فَآتَاهُمُ ٱللَّهُ ثَوَابَ ٱلدُّنْيَا }: بالنصر والغنيمة، { وَحُسْنَ ثَوَابِ ٱلآخِرَةِ وَٱللَّهُ يُحِبُّ ٱلْمُحْسِنِينَ * يَا أَيُّهَا ٱلَّذِينَ آمَنُوۤاْ إِن تُطِيعُواْ ٱلَّذِينَ كَفَرُواْ }: إذ قالوا يوم أحد: ارجعوا إلى دين آبائكم، { يَرُدُّوكُمْ عَلَىٰ أَعْقَابِكُمْ }: إلى الشرك، { فَتَنقَلِبُواْ خَاسِرِينَ }: في الدارين، { بَلِ ٱللَّهُ مَوْلاَكُمْ }: ناصركم، { وَهُوَ خَيْرُ ٱلنَّاصِرِينَ }: فلا تستنصروا من غيره.
