{ قَالَ }: تعجباً بأشياء أو سؤالا عن ردهما إلى الشباب والولودية، { رَبِّ أَنَّىٰ } كيف { يَكُونُ لِي غُلاَمٌ } ولد { وَقَدْ بَلَغَنِي ٱلْكِبَرُ وَٱمْرَأَتِي عَاقِرٌ }: لا تلد، كان عمره مائة وعشرين، وعمرها ثمانية وتسعين، { قَالَ }: الملك، { كَذَلِكَ }: الأمر من خَلْقِ غُلامٍ منكُما { ٱللَّهُ يَفْعَلُ مَا يَشَآءُ }: لَا يعجزهُ عنه شيء، ولإظهارِ هذه القدرة العظيمة أُلهم السّؤال ليجَاب بها، ولما تاقَت نفسُهُ إلى شِرْعة البشرية، { قَالَ رَبِّ ٱجْعَلْ لِّيۤ آيَةً } أي: علامةً على حَمْل امرأتي، { قَالَ }: الله، { آيَتُكَ أَلاَّ تُكَلِّمَ ٱلنَّاسَ }: أي: تمتنع من كلامهم بخلاف ذكر الله -تعالى-، { ثَلاَثَةَ أَيَّامٍ }: أي: بلياليها، { إِلاَّ رَمْزاً }: إشارةً { وَٱذْكُر رَّبَّكَ }: صَلِّ، { كَثِيراً }: أصله كونه للتأسيس فيفهم أنه لا يفيد التكرار، { وَسَبِّحْ بِٱلْعَشِيِّ }: أواخر النهار، { وَٱلإِبْكَارِ }: وأوائله.
