{ إِنَّ ٱللَّهَ رَبِّي وَرَبُّكُمْ } المأمور كرره تأكيداً وليبني عليه { فَٱعْبُدُوهُ هَـٰذَا } أي: الذي أمركم به، { صِرَاطٌ } طريق { مُّسْتَقِيمٌ }: فكذبوه ولم يؤمنوا به، { فَلَمَّآ أَحَسَّ عِيسَىٰ مِنْهُمُ ٱلْكُفْرَ } وأرادوا قتله { قَالَ مَنْ أَنصَارِيۤ }: أعواني ذاهباً، { إِلَى ٱللَّهِ }: لأنصر دينه، { قَالَ ٱلْحَوَارِيُّونَ }: أعوان دينه وهم أصفياء عيسى أول من آمن به وكانوا اثني عشر من الحَوَر وهو البياض الخالص وقيل: كانوا قَصَّارين يُحوِّروْن الثياب أي: يبيضونها، { نَحْنُ أَنْصَارُ ٱللَّهِ }: أي: بأي دينه { آمَنَّا بِٱللَّهِ وَٱشْهَدْ }: يا عيسى، { بِأَنَّا مُسْلِمُونَ * رَبَّنَآ آمَنَّا بِمَآ أَنزَلَتَ } من الإنجيل { وَٱتَّبَعْنَا ٱلرَّسُولَ } عيسى { فَٱكْتُبْنَا مَعَ ٱلشَّٰهِدِينَ }: بوحدانيتك أو أمة محمد عليه الصلاة والسلام فإنهم يشهدون على الناس لك بالوحدانية ولرسولك بالصدق.
