{ فَإنْ حَآجُّوكَ }: جادلوك بعد إقامة الحجة، { فَقُلْ }: معرضاً عنهم، { أَسْلَمْتُ }: أخلصت، { وَجْهِيَ }: نفسي، عبر به عنها، لأنه أشرف الأعضاء الظاهرة، لأنه مظهر القُوى والحواسّ، { للَّهِ }: لا أشرك به غيره، { وَ }: مع { مَنِ ٱتَّبَعَنِ وَقُلْ لِّلَّذِينَ أُوتُواْ ٱلْكِتَٰبَ وَٱلأُمِّيِّينَ }: مشركي العرب، { أَأَسْلَمْتُمْ }: بعد وضوح الحُجَّة أم لا؟ استفهام تعيير بالمعاندة والبلادة، { فَإِنْ أَسْلَمُواْ فَقَدِ ٱهْتَدَواْ وَّإِن تَوَلَّوْاْ }: أعرضوا، { فَإِنَّمَا عَلَيْكَ ٱلْبَلَٰغُ }: لا هدايتم، { وَٱللَّهُ بَصِيرٌ بِٱلْعِبَادِ }: فيجازيهم.
