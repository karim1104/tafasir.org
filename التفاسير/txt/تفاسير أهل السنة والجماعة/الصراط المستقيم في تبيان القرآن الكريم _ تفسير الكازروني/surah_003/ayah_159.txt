{ وَلَئِنْ مُّتُّمْ أَوْ قُتِلْتُمْ لإِلَى ٱلله تُحْشَرُونَ }: لا إلى غيره فيجازيكم، { فَبِمَا رَحْمَةٍ }: فاصلة للتأكيد، أي: بسبب رحمة عظيمة، { مِّنَ ٱللَّهِ لِنتَ }: سَهُلَتْ أخلاقك، { لَهُمْ وَلَوْ كُنْتَ فَظّاً }: سيء الخلق، { غَلِيظَ }: قاسي، { ٱلْقَلْبِ لاَنْفَضُّواْ }: لتفرقوا، { مِنْ حَوْلِكَ فَٱعْفُ عَنْهُمْ }: فيما لك عفوه، { وَٱسْتَغْفِرْ لَهُمْ }: فيما الله، { وَشَاوِرْهُمْ فِي ٱلأَمْرِ }: الذي ليس فيه وحي ممَّا يصحُّ أن يشاور فيه ليصير سنة، ولتطيب قلوبهم، { فَإِذَا عَزَمْتَ }: عَلَيْهِ بعد الشّوْرَى، { فَتَوَكَّلْ عَلَى ٱللَّهِ }: فيه، { إِنَّ ٱللَّهَ يُحِبُّ ٱلْمُتَوَكِّلِينَ }: فينصركُمْ، { إِن يَنصُرْكُمُ ٱللَّهُ فَلاَ غَالِبَ لَكُمْ وَإِن يَخْذُلْكُمْ }: كما في أحد، { فَمَن ذَا ٱلَّذِي يَنصُرُكُم مِّنْ بَعْدِهِ }: بعد خذلانه، { وَعَلَى ٱللَّهِ فَلْيَتَوَكَّلِ ٱلْمُؤْمِنُونَ * وَمَا كَانَ }: ما صح، { لِنَبِيٍّ أَنْ يَغُلَّ }: يخون، ومجهولاً: أي: ينسب إلى الخيانة أو يخان، { وَمَن يَغْلُلْ يَأْتِ بِمَا غَلَّ }: حاملاً له على عُنُقه، وقوله تعالى: [الأنعام: 94]، أي: عن أموالكم وأولادكم ومعبودكم { يَوْمَ ٱلْقِيَامَةِ ثُمَّ تُوَفَّىٰ كُلُّ نَفْسٍ }: جزاء، { مَّا كَسَبَتْ وَهُمْ لاَ يُظْلَمُونَ }: في العقاب، { أَفَمَنِ ٱتَّبَعَ رِضْوَانَ ٱللَّهِ }: بطاعَتِهِ، { كَمَن بَآءَ }: رجع، { بِسَخَطٍ مِّنَ ٱللَّهِ }: بمخالفته، { وَمَأْوَاهُ جَهَنَّمُ وَبِئْسَ ٱلْمَصِيرُ }: هي، والفرق بينه وبين المرجع أنه يجب أن يخالف الحالَ الأولى دون المرجع.
