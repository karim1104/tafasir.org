{ وَإِذاً }: والله، { لأَتَيْنَٰهُم مِّن لَّدُنَّـآ أَجْراً عَظِيماً * وَلَهَدَيْنَاهُمْ صِرَاطاً مُّسْتَقِيماً }: يَصلُوْن به إلى الفلاح، { وَمَن يُطِعِ ٱللَّهَ وَٱلرَّسُولَ فَأُوْلَـٰئِكَ مَعَ ٱلَّذِينَ أَنْعَمَ ٱللَّهُ عَلَيْهِم مِّنَ ٱلنَّبِيِّينَ وَٱلصِّدِّيقِينَ }: أفاضل أصحاب الأنبياء، { وَٱلشُّهَدَآءِ }: في سبيل الله، { وَٱلصَّالِحِينَ }: من غيرهم، { وَحَسُنَ }: كُلٌّ من { أُولَـٰئِكَ رَفِيقاً }: هذا يقال للواحد والجمع، كالصديق، { ذٰلِكَ }: المرافقة، { ٱلْفَضْلُ مِنَ ٱللَّهِ وَكَفَىٰ بِٱللَّهِ عَلِيماً }: بالمطيع.
