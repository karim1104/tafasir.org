{ يَٰأَيُّهَا ٱلَّذِينَ ءامَنُواْ خُذُواْ حِذْرَكُمْ }: آلته كالسلاح واحذروا من أعدائكم، { فَٱنفِرُواْ }: اخرجوا إلى الجهاد، { ثُبَاتٍ }: جماعات متفرِّقةٍ، جمع ثبة، { أَوِ ٱنْفِرُواْ جَمِيعاً }: مجتمعين، أي: بادروا كيف ما أمكن، { وَإِنَّ مِنْكُمْ لَمَن لَّيُبَطِّئَنَّ }: ليتثاقل عن الجهاد، أو يبطئُ غيره، وهم المنافقون، { فَإِنْ أَصَٰبَتْكُمْ مُّصِيبَةٌ }: كقتل، { قَالَ قَدْ أَنْعَمَ ٱللَّهُ عَلَيَّ إِذْ لَمْ أَكُنْ مَّعَهُمْ شَهِيداً }: حاضراً، { وَلَئِنْ أَصَٰبَكُمْ فَضْلٌ مِنَ الله }: كغنيمة، { لَيَقُولَنَّ كَأَن }: كأنه، { لَّمْ تَكُنْ بَيْنَكُمْ وَبَيْنَهُ مَوَدَّةٌ }: بل لم تحبوا إلا المال، والجملة معترضة، أي: ليقولن، { يٰلَيتَنِي كُنتُ مَعَهُمْ فَأَفُوزَ فَوْزاً عَظِيماً }: نصيباً وافراً من الغنيمة إن بطأ هؤلاء، { فَلْيُقَاتِلْ فِي سَبِيلِ ٱللَّهِ ٱلَّذِينَ يَشْرُونَ ٱلْحَيَاةَ ٱلدُّنْيَا بِٱلآخِرَةِ }: وهم المخلصون، { وَمَن يُقَاتِلْ فِي سَبِيلِ ٱللَّهِ فَيُقْتَلْ أَو يَغْلِبْ فَسَوْفَ نُؤْتِيهِ أَجْراً عَظِيماً }:رَد لمن قال: قَدْ أنعم الله عليَّ -إلى آخره.
