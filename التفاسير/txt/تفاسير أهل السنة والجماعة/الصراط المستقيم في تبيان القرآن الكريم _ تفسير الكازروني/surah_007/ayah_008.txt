{ وَٱلْوَزْنُ }: للأعمال، { يَوْمَئِذٍ }: يوم السؤال، { ٱلْحَقُّ }: العدل فيزون صحائفها بميزان له لسانٌ وكفتان، إظهاراً للمعدلة وقطعا للمعذرة على كيفية يعلمها الله، وقيل: تجسم الأعمال بصورة حسنة أو قبيحة، { فَمَن ثَقُلَتْ مَوَازِينُهُ }: بالحسنات، جمع مُوزونٍ أو ميزان، وجمه لتعداد أجزائه، كثوب أخْلاق لقيامه مقام الموازين، { فَأُوْلَـٰئِكَ هُمُ ٱلْمُفْلِحُونَ }: في الحديث: " السيئة خفيفة وإن كثرت والحسنة الصالحة ثقيلة وإن قَلَّتْ " { وَمَنْ خَفَّتْ مَوَازِينُهُ }: بالسيئة، { فَأُوْلَـۤئِكَ ٱلَّذِينَ خَسِرُوۤاْ أَنْفُسَهُم }: بتضييع الفطرة السليمة، { بِمَا كَانُواْ بِآيَاتِنَا يِظْلِمُونَ }: بإنكارها.
