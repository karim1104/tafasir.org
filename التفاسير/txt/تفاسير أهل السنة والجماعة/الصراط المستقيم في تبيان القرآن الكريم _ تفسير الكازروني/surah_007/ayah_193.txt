{ فَلَمَّآ آتَاهُمَا صَالِحاً جَعَلاَ لَهُ شُرَكَآءَ }: ذا شرك، { فِيمَآ آتَاهُمَا }: كتسمية ولدها عبد الحارث بأمر إبلس جاهلاً بأن الحارث اسمه، ولا شكَّ أنه ليس بشرك حقيقة، إذ الأعلام لا تفيد مفهومها اللغوية فأطلقه عليه تغليظاً ولأن الأعلام المضافة تلاحظ فيها المعاني الأصليَّة، وقريء: شركاء بالجمع، فإنَّ من جوَّز شريكاً جوز عقد شركاء { فَتَعَالَى ٱللَّهُ عَمَّا يُشْرِكُونَ }: جليّاً أو خفياً، { أَيُشْرِكُونَ مَا لاَ يَخْلُقُ شَيْئاً وَهُمْ }: الأصنام { يُخْلَقُونَ }: أتى بضمير العُقَلاء بناء على اعتقادهم، { وَلاَ يَسْتَطِيعُونَ لَهُمْ }: لعبدتهم، { نَصْراً وَلآ أَنْفُسَهُمْ يَنصُرُونَ }: إن قُصِدُوا بمكروه { وَإِن تَدْعُوهُمْ }: الشركاء، { إِلَى ٱلْهُدَىٰ }: إلى أن يهدوكم { لاَ يَتَّبِعُوكُمْ }: لا يجيبوكم { سَوَآءٌ عَلَيْكُمْ أَدَعَوْتُمُوهُمْ أَمْ أَنْتُمْ صَٰمِتُونَ * إِنَّ ٱلَّذِينَ تَدْعُونَ }: تعبدونهم، { مِن دُونِ ٱللَّهِ عِبَادٌ أَمْثَالُكُمْ }: مملوكون مخلوقون، { فَٱدْعُوهُمْ }: في نفع أو ضر، { فَلْيَسْتَجِيبُواْ لَكُمْ إِن كُنتُمْ صَادِقِينَ }: أنهم آلهة.
