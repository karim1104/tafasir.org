{ ذَلِكَ } العذاب، { جَزَآؤُهُم بِأَنَّهُمْ كَفَرُواْ بِآيَاتِنَا }: مطلقاً، { وَقَالُواْ أَءِذَا كُنَّا عِظَاماً وَرُفَاتاً }: تُراباً { أَءِنَّا لَمَبْعُوثُونَ خَلْقاً جَدِيداً } جُوزوا بكثرة الإعادة بعد الإفناء لإنكارهم الإعادة { أَوَلَمْ يَرَوْاْ }: يعلموا، { أَنَّ ٱللَّهَ ٱلَّذِي خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ قَادِرٌ عَلَىٰ أَن يَخْلُقَ مِثْلَهُمْ }: بدءاً وإعادةً { وَجَعَلَ لَهُمْ }: لإعادتهم { أَجَلاً لاَّ رَيْبَ فِيهِ فَأَبَىٰ ٱلظَّالِمُونَ }: بعد قيام الحُجَّة، { إِلاَّ كُفُوراً }: جُحوداً { قُل لَّوْ أَنْتُمْ تَمْلِكُونَ خَزَآئِنَ رَحْمَةِ }: نعمة، { رَبِّي إِذاً لأمْسَكْتُمْ }: لبخلتم، { خَشْيَةَ ٱلإِنْفَاقِ }: النفاد به فلا ينفعكم تفجُّرُ الأنهار ونحوه، { وَكَانَ ٱلإنْسَانُ }: جنسه بالطبع، { قَتُوراً }: بخيلاً.
