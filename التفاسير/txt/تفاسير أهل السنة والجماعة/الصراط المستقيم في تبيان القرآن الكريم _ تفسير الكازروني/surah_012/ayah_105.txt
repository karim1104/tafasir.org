{ وَمَا تَسْأَلُهُمْ عَلَيْهِ }: على تبليغ الوحي، { مِنْ أَجْرٍ }: جعلٍ { إِنْ هُوَ إِلاَّ ذِكْرٌ }: عظةٌ { لِّلْعَالَمِينَ }: عامة { وَكَأَيِّن }: كم { مِّن آيَةٍ }: دليل على وحدانيته وصفاته الحسنى، { فِي ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ يَمُرُّونَ عَلَيْهَا }: يرونها، { وَهُمْ عَنْهَا مُعْرِضُونَ }: لا يتفكرون فيها، { وَمَا يُؤْمِنُ أَكْثَرُهُمْ بِٱللَّهِ }: حين إقرارهم بأنه خالق الكل، { إِلاَّ وَهُمْ مُّشْرِكُونَ }: بإشراكهم، فالمراد إيمان المشركين أو بالنظر إلى الأسباب وقيل: منه قول الرجل: لولا الله وفلان لهلكت.
