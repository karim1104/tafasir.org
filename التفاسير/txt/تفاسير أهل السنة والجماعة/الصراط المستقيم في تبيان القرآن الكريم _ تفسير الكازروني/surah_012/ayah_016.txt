{ وَجَآءُوۤا أَبَاهُمْ عِشَآءً }: آخر النهار، { يَبْكُونَ * قَالُواْ يَٰأَبَانَآ إِنَّا ذَهَبْنَا نَسْتَبِقُ }: نتسابق في الرمي والعدو { وَتَرَكْنَا يُوسُفَ عِندَ مَتَاعِنَا }: ثيابا، { فَأَكَلَهُ ٱلذِّئْبُ وَمَآ أَنتَ بِمُؤْمِنٍ }: مُصدِّق { لَّنَا }: فيه { وَلَوْ كُنَّا صَادِقِينَ }: لسوء ظنك بنا، { وَجَآءُوا عَلَىٰ }: فوقَ { قَمِيصِهِ }: حال من، { بِدَمٍ }: ذي: { كَذِبٍ قَالَ }: ما أكله الذئب، { بَلْ سَوَّلَتْ }: زَيَّنتْ { لَكُمْ أَنفُسُكُمْ أَمْراً }: عظيماً، { فَصَبْرٌ جَمِيلٌ }: أجمل وهو ما لَا شَكوى فيه إلى الخلق، { وَٱللَّهُ ٱلْمُسْتَعَانُ عَلَىٰ }: تحمُّل { مَا تَصِفُونَ }: من هلاكه.
