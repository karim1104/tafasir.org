{ حَتَّىٰ إِذَا ٱسْتَيْأَسَ }: أيس، { ٱلرُّسُلُ }: عن إيمانهم أو النصر، { وَظَنُّوۤاْ } القوم أنَّ الرسل { أَنَّهُمْ قَدْ كُذِبُواْ }: بالتخفيف، وعلى التشديد أي: ظن الرسل بمعنى تيقنوا، أو ظنوا الرسل أنهم قد كذبوا بالتخفيف أي: في وعد النصر، { جَآءَهُمْ نَصْرُنَا فَنُجِّيَ مَن نَّشَآءُ }: أتباع الرسل { وَلاَ يُرَدُّ بَأْسُنَا }: عذابنا، { عَنِ ٱلْقَوْمِ ٱلْمُجْرِمِينَ * لَقَدْ كَانَ فِي قَصَصِهِمْ }: الأنبياء وقومهم، أو يوسف وإخوته، { عِبْرَةٌ لأُوْلِي ٱلأَلْبَابِ }: العقول السليمة { مَا كَانَ }: القرآن، { حَدِيثاً يُفْتَرَىٰ وَلَـٰكِن تَصْدِيقَ ٱلَّذِي بَيْنَ يَدَيْهِ }: من الكتاب، { وَتَفْصِيلَ }: تبيين، { كُلِّ شَيْءٍ }: ديني بواسطة أو ب غير واسطة، { وَهُدًى وَرَحْمَةً لِّقَوْمٍ يُؤْمِنُونَ }: يصدقونه - واللهُ أعلمُ.
