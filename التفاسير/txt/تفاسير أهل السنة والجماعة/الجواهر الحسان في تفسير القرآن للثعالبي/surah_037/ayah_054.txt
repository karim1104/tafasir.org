وقوله تعالى : { قَالَ هَلْ أَنتُمْ مُّطَّلِعُونَ } الآية ،   في الكلامِ حَذْفٌ ،   تقديرُه : فقالَ لِهذَا الرجلُ حاضِرُوهُ مِنَ الملائِكَةِ : أنَّ قَرِينَكَ هذا في جَهَنَّمَ يُعَذَّبُ فقال عند ذلك : { هَلْ أَنتُمْ مُّطَّلِعُونَ } يخَاطِبُ ب { أَنْتُم } الملائكةَ أو رفقاءَه في الجنةِ أو خَدَمَتَهُ ؛ وَكُلَّ هذا حَكَى المَهْدَوِيُّ ،   وقَرَأ أبو عمرو في رواية حُسَيْنٍ { مُطْلِعُونَ } بسكون الطاء وفتح النون ،   وقرِئ شاذًّا { مُطْلِعُونِ } بسكون الطاء وكسر النون .
