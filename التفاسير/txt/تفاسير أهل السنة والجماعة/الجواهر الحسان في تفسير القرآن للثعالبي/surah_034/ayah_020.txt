وقوله تعالى : { وَلَقَدْ صَدَّقَ عَلَيْهِمْ إِبْلِيسُ ظَنَّهُ } الآية ،   قَرَأَ نَافِعُ وأَبُو عمرِو وابن عَامِرٍ : { ولقد صَدَقَ } بِتَخْفِيفِ الدَّالِ ،   وَقَرَأَ حَمْزَةُ والكسائيِّ : ( صَدَّقَ ) بِتَشْدِيدِها ؛ فالظَّن عَلى هذِهِ القِرَاءَةِ مَفْعُولُ «بَصدَّقَ » ومَعْنَى الآية : أَنَّ إبْلِيسَ ظَنَّ فِيهمْ ظَنّاً حَيْثُ قَالَ : { وَلاَ تَجِدُ أَكْثَرَهُمْ شاكرين } [ الأعراف : 17 ] .

وغَيْرَ ذلك فَصَدَّقَ ظَنَّهُ فِيهمْ ؛ وأَخْبَرَ تَعَالَى أَنَّهُمْ اتَّبَعُوهُ وهُو اتِّبَاعٌ فِي كُفْرٍ لأَنَّهُ فِي قِصَّة قَوْمٍ كُفَّارٍ .

وقولُه : { مِمَّنْ هُوَ مِنْهَا فِي شَكٍّ } يَدُلّ عَلى ذَلكَ ،   وَ«مِنْ » فِي قوله : { مِّنَ المؤمنين } لبيَانِ الجِنْسِ لاَ لِلتَّبْعِيضِ .
