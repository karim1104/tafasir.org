وقالت فرقة : { الزبور } [ الأنبياء : 105 ] .

هنا يعم جميعَ الكتب المُنَزَّلَة لأَنه مأخوذ من : زبرت الكتابَ إذا كتبته ،   و { الذكر } أراد به اللَّوحَ المحفوظ ،   وقالت فرقة : { الزبور } هو زبورُ داودَ عليه السلام ،   و{ الذكر } : التوراة ،   وقالت فرقة : { الزبور } : ما بعد التوراةِ من الكتب ،   و{ الذكر } : التوراة ،   وقالت فرقة : { الأرض } هنا : أرضُ الدنيا ،   أي : كل ما يناله المؤمنون من الأرض ،   وقالت فرقة : أراد أرض الجنة ،   واستشهدوا بقوله تعالى : { وَأَوْرَثَنَا الأرض نَتَبَوَّأُ مِنَ الجنة حَيْثُ نَشَاءُ } [ الزمر : 74 ] .
