وقوله سبحانه : { حتى إِذَا جَاء أَحَدَهُمُ الموت قَالَ رَبِّ ارجعون * لَعَلِّي أَعْمَلُ صالحا فِيمَا تَرَكْتُ } [ المؤمنون : 99 و100 ] .

{ حَتَّى } في هذا الموضع حَرْفُ ابتداءٍ ،   والضمير في قوله : { أَحَدَهُمُ } للكفار ،   وقوله : { ارجعون } أي : إلى الحياة الدنيا ،   والنون في : { ارجعون } : نونُ العَظَمَةِ ،   وقال النبي صلى الله عليه وسلم لعائشة : ( إذَا عَايَنَ المُؤْمِنُ المَوْتَ ،   قَالَتْ لَهُ الْمَلاَئِكَةُ : نُرْجِعُك ؟ فيقول : إلى دَارِ الهُمُومِ وَالأَحْزَانِ بل قُدُماً إلى اللّهِ ،   وأَمَّا الكَافِرُ ،   فَيَقُولُ : { ارجعون * لَعَلِّي أَعْمَلُ صَالِحاً } )
