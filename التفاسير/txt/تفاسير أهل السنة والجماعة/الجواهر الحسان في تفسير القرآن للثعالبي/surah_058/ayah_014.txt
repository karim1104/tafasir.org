وقوله تعالى : { أَلَمْ تَرَ إِلَى الذين تَوَلَّوْاْ } : نزلت في قوم من المنافقين ،   تولوا قوماً من اليهود ،   وهمُ المغضوب عليهم ،   قال الطبري : { مَّا هُم مِّنكُمْ } : يريد به المنافقين { وَلاَ مِنْهُمْ } أي : ولا من اليهود ،   وهذا التأويل يجري مع قوله تعالى : { مُّذَبْذَبِينَ بَيْنَ ذلك لاَ إلى هَؤُلاءِ وَلاَ إِلَى هَؤُلاءِ } [ النساء : 143 ] كالشاة العائرة بين الغنمين ،   وتحتمل الآية تأويلاً آخرَ ،   وهو أَنْ يكونَ قوله : { مَّا هُم } يريد به اليهودَ { وَلاَ مِنْهُمْ } يريد به المنافقين ،   { وَيَحْلِفُونَ } : يعني المنافقين .
