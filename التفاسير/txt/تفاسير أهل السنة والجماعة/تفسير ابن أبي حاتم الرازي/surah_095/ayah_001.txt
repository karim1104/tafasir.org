قوله تعالى :  {  والتين }

عن ابن عباس في قوله :  {  والتين } قال :  مسجد نوح الذي بني بأعلى الجودي {  والزيتون } قال :  بيت المقدس .

عن قتادة في قوله :  {  والتين } قال :  التين الجبل الذي عليه دمشق {  والزيتون } الذي عليه بيت المقدس .

عن محمد بن كعب قال :  {  والتين } مسجد أصحاب الكهف {  والزيتون } مسجد إيليا .

عن ابن عباس {  والتين والزيتون } قال :  الفاكهة التي يأكلها الناس .

عن مجاهد {  والتين والزيتون } قال :  الفاكهة التي يأكل الناس .

عن عكرمة {  والتين } قال :  هو هذا التين {  والزيتون } قال :  هو هذا الزيتون .
