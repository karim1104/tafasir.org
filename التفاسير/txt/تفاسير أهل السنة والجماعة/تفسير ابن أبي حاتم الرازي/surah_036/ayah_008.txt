قوله تعالى :  {  الأغلال } قوله :  {  مقمحون } آية 8

عن ابن عباس رضي الله عنهما قال :  {  الأغلال } ما بين الصدر إلى الذقن {  فهم مقمحون } كما تقمح الدابة باللجام .

عن ابن عباس في قوله :  {  مقمحون } قال :  مجموعة أيديهم إلى أعناقهم تحت الذقن .   عن مجاهد {  فهم مقمحون } قال :  رافعو رؤوسهم ،   وأيديهم موضوعة على أفواههم .
