قوله :  {  يا يحيى خذ الكتاب بقوة } آية 12

فِي قَوْلِهِ :  "  {  يَا يَحْيَى خُذِ الْكِتَاب بِقُوَّةٍ } قَالَ :  بجد {  وَآتَيْنَاهُ الْحُكْمَ صَبِيًّا } قَالَ :  الفهم "  .

عَنْ سَعِيدِ بْنِ جُبَيْرٍ ،   فِي قَوْلِهِ :  "  {  خُذِ الْكِتَاب بِقُوَّةٍ } يَقُولُ :  اعمل بما فيه مِنْ فرائضه "  .   قوله :  {  وَآتَيْنَاهُ الْحُكْمَ صَبِيًّا }

عَنْ معمر بن راشد ،   فِي قَوْلِهِ :  "  {  وَآتَيْنَاهُ الْحُكْمَ صَبِيًّا } ،   قَالَ :  بلغني أنَّ الصبيان قالوا ليحيى بن زكريا :  اذهب بنا نلعب ،   قَالَ :  مَا للعب خلقت ،   فهو قوله :  {  وَآتَيْنَاهُ الْحُكْمَ صَبِيًّا } "  .
