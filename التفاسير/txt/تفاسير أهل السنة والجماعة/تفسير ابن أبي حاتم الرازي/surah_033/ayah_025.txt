قوله تعالى :  {  ورد الله الذين كفروا بغيظهم }

عن مجاهد رضي الله عنه في قوله :  {  ورد الله الذين كفروا بغيظهم } قال :  الأحزاب .

قوله تعالى :  {  لم ينالوا خيراً } .

عن السدى رضي الله تعالى عنه في قوله :  {  ورد الله الذين كفروا بغيظهم } قال :  أبو سفيان وأصحابه {  لم ينالوا خيراً } قال :  لم يصيبوا من محمد صلى الله عليه وسلم وأصحابه ظفراً    {  وكفى الله المؤمنين القتال } انهزموا بالريح من غير قتال .

قوله تعالى :  {  وكفى الله المؤمنين القتال }

عن قتادة رضي الله عنه في قوله :  {  وكفى الله المؤمنين القتال } قال :  بالجنود من عنده ،   والريح التي بعث عليهم {  وكان الله قويا } في أمره {  عزيزاً } في نقمته .

عن ابن مسعود رضي الله عنه أنه كان يقرأ هذا الحرف {  وكفى الله المؤمنين القتال } بعلي بن أبي طالب .
