قوله تعالى :  {  ومالكم ألا تأكلوا مما ذكر اسم الله عليه } آية

وبه عن سعيد في قول الله :  {  وما لكم ألا تأكلوا مما ذكر اسم الله عليه } يعني :  الذبائح ؟

قوله تعالى :  {  وقد فصل لكم ما حرم عليكم }

حدثنا الحسن بن أبي الربيع انا عبد الرزاق انا معمر عن قتادة ،   قوله :  {  وقد فصل لكم ما حرم عليكم } ،   يقول :  بين لكم .

قوله تعالى :  {  إلا ما اضطررتم إليه }

حدثنا أبو زرعة ثنا يحيى بن عبد الله بن بكير ثنا ابن لهيعة حدثني عطاء عن سعيد قوله :  {  إلا ما اضطررتم إليه } يعني :  ما حرم عليكم من الميتة ،   فهو الاضطرار كله .

قوله تعالى :  {  وإن كثيرا }

وبه عن سعيد بن جبير :  قوله :  {  وإن كثيرا } ،   يعني من مشركي العرب .

قوله تعالى :  {  ليضلون بأهوائهم بغير علم }

وبه عن سعيد بن جبير :  قوله :  {  ليضلون بأهوائهم بغير علم } يعني في أمر الذبائح وغيره .   {  إن ربك هو أعلم بالمعتدين } .
