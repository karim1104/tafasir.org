وفي قوله :  {  مَا أَخْلَفْنَا مَوْعِدَكَ بِمَلْكِنَا } بأمر ملكنا {  وَلَكِنَّا حُمِّلْنَا أَوْزَارًا } ،   قَالَ :  أثقالا مِنْ زينة القوم ،   وهي الحلي الّذِي استعاروه مِنَ آل فرعون {  فَقَذَفْنَاهَا } ،   قَالَ :  فألقيناها ،   {  فَكَذَلِكَ أَلْقَى السَّامِرِيُّ } ،   قَالَ :  كذلك صنع {  فَأَخْرَجَ لَهُمْ عِجْلا جَسَدًا لَهُ خُوَار } قَالَ :  حفيف الريح فيه فهو خواره ،   والعجل ولد البقرة "  .

قَوْلهُ تَعَالَى :  {  بِمَلْكِنَا } آية 78

عَنْ ابْنِ عَبَّاسٍ رَضِيَ اللهُ عَنْهُمَا ،   فِي قَوْلِهِ :  "  {  بِمَلْكِنَا } ،   قَالَ :  بأمرنا "  .

عَنِ الحَسَنِ رَضِيَ اللهُ عَنْهُ ،   فِي قَوْلِهِ :  "  {  بِمَلْكِنَا } ،   قَالَ :  بسلطاننا "  .
