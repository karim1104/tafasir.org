{ ولولا أن تصيبهم مصيبة بما قدمت أيديهم فيقولوا ربنا لولا أرسلت إلينا رسولا فنتبع آياتك ونكون من المؤمنين }

{ ولولا أن تصيبهم مصيبة } عقوبة  { بما قدمت أيديهم } من الكفر وغيره  { فيقولوا ربنا لولا } هلا  { أرسلت إلينا رسولاً فنتبع آياتك } المرسل بها  { ونكون من المؤمنين } وجواب لولا محذوف وما بعده مبتدأ ،   والمعنى لولا الإصابة المسبب عنها قولهم أو لولا قولهم المسبب عنها لعاجلناهم بالعقوبة ولما أرسلناك إليهم رسولاً .
