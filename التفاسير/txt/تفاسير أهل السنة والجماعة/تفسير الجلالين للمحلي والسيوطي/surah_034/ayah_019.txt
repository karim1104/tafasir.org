{ فقالوا ربنا باعد بين أسفارنا وظلموا أنفسهم فجعلناهم أحاديث ومزقناهم كل ممزق إن في ذلك لآيات لكل صبار شكور }

{ فقالوا ربنا بَعَّدْ } وفي قراءة باعد  { بين أسفارنا } إلى الشام اجعلها مفاوز ليتطاولوا على الفقراء بركوب الرواحل وحمل الزاد والماء فبطروا النعمة  { وظلموا أنفسهم } بالكفر  { فجعلناهم أحاديث } لمن بعدهم في ذلك  { ومزقناهم كل ممزق } فرقناهم في البلاد كل التفريق  { إن في ذلك } المذكور  { لآيات } عبراً  { لكل صبَّار } عن المعاصي  { شكور } على النعم  .
