{ يوم يقول المنافقون والمنافقات للذين آمنوا انظرونا } أبصرونا وفي قراءة بفتح الهمزه وكسر الظاء  : أمهلونا  { نقتبس } نأخذ القبس والإضاءة  { من نوركم قيل } لهم استهزاءً بهم  { ارجعوا وراءكم فالتمسوا نورا } فرجعوا  { فضرب بينهم } وبين المؤمنين  { بسور } قيل هو سور الأعراف  { له باب باطنه فيه الرحمة } من جهة المؤمنين  { وظاهره } من جهة المنافقين  { من قبله العذاب }  .
