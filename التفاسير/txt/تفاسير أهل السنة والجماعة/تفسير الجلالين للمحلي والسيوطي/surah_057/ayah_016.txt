{ ألم يأن للذين آمنوا أن تخشع قلوبهم لذكر الله وما نزل من الحق ولا يكونوا كالذين أوتوا الكتاب من قبل فطال عليهم الأمد فقست قلوبهم وكثير منهم فاسقون }

{ ألم يَأنِ } يحن  { للذين آمنوا } نزلت في شأن الصحابة لما أكثروا المزاح  { أن تخشع قلوبهم لذكر الله وما نزَّل } بالتشديد والتخفيف  { من الحق } القرآن  { ولا يكونوا } معطوف على تخشع  { كالذين أوتوا الكتاب من قبل } هم اليهود والنصارى  { فطال عليهم الأمد } الزمن بينهم وبين أنبيائهم  { فقست قلوبهم } لم تلن لذكر الله  { وكثير منهم فاسقون }  .
