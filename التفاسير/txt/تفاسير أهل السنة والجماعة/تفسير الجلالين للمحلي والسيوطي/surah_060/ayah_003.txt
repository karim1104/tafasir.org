{ لن تنفعكم أرحامكم ولا أولادكم يوم القيامة يفصل بينكم والله بما تعملون بصير } .

{ لن تنفعكم أرحامكم } قراباتكم   ،  { ولا أولادكم } المشركون الذين لأجلهم أسررتم الخبر من العذاب في الآخرة   ،  { يوم القيامة يُفصَل } بالبناء للمفعول والفاعل  ،  { بينكم } وبينهم فتكونون في الجنة وهم جملة الكفار في النار { والله بما تعلمون بصير }  .
