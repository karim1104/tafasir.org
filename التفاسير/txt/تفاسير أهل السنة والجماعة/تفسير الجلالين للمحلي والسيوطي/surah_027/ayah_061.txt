{ أم من جعل الأرض قرارا وجعل خلالها أنهارا وجعل لها رواسي وجعل بين البحرين حاجزا أإله مع الله بل أكثرهم لا يعلمون }

{ أمَّن جعل الأرض قراراً } لا تميد بأهلها  { وجعل خلالها } فيما بينها  { أنهاراً وجعل لها رواسي } جبالاً أثبت بها الأرض  { وجعل بين البحرين حاجزاً } بين العذب والملح لا يختلط أحدها بالآخر  { أإلهٌ مع الله بل أكثرهم لا يعلمون } توحيده  .
