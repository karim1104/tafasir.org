{ أم من خلق السماوات والأرض وأنزل لكم من السماء ماء فأنبتنا به حدائق ذات بهجة ما كان لكم أن تنبتوا شجرها أإله مع الله بل هم قوم يعدلون }

{ أمَّن خلق السماوات والأرض وأنزل لكم من السماء ماءً فأنبتنا } فيه الفتات من الغيبة إلى التكلم  { به حدائق } جمع حديقة وهو البستان المحوط  { ذات بهجةِ } حُسن  { ما كان لكم أن تنبتوا شجرها } لعدم قدرتكم عليه  { أإلهٌ } بتحقيق الهمزتين وتسهيل الثانية وإدخال ألف بينهما على الوجهين في مواضعه السبعة  { مع الله } أعانه على ذلك أي ليس معه إله  { بل هم قوم يعدلون } يشركون بالله غيره  .
