{ إذ قال موسى لأهله إني آنست نارا سآتيكم منها بخبر أو آتيكم بشهاب قبس لعلكم تصطلون }

اذكر :  { إذ قال موسى لأهله } زوجته عند مسيره من مدين إلى مصر  { إني آنست } أبصرت من بعيد  { ناراً سآتيكم منها بخبر } عن حال الطريق وكان قد ضلها  { أو آتيكم بشهاب قبس } بالإضافة للبيان وتركها أي شعلة نار في رأس فتيلة أو عود  { لعلكم تصطلون } والطاء بدل من تاء الافتعال من صلى بالنار بكسر اللام وفتحها : تستدفئون من البرد  .
