{ وألق عصاك فلما رآها تهتز كأنها جان ولى مدبرا ولم يعقب يا موسى لا تخف إني لا يخاف لدي المرسلون }

{ وألق عصاك } فألقاها  { فلما رآها تهتز } تتحرك  { كأنها جان } حية خفيفة  { ولّى مدبراً ولم يُعقِّبْ } يرجع قال تعالى  { يا موسى لا تخف } منها  { إني لا يخاف لديَّ } عندي  { المرسلون } من حية وغيرها  .
