{ فلما جاءت قيل أهكذا عرشك قالت كأنه هو وأوتينا العلم من قبلها وكنا مسلمين }

{ فلما جاءت قيل } لها  { أهكذا عرشك } أي أمثل هذا عرشك  { قالت كأنه هو } فعرفته وشبهت عليهم كما شبهوا عليها إذ لم يقل أهذا عرشك ولو قيل هذا قالت : نعم ،   قال سليمان : لما رأى لها معرفة وعلماً  { وأتينا العلم من قبلها وكنا مسلمين }  .
