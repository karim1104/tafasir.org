{ وما تفرقوا إلا من بعد ما جاءهم العلم بغيا بينهم ولولا كلمة سبقت من ربك إلى أجل مسمى لقضي بينهم وإن الذين أورثوا الكتاب من بعدهم لفي شك منه مريب }

{ وما تفرَّقوا } أي أهل الأديان في الدين بأن وحد بعض وكفر بعض  { إلا من بعد ما جاءهم العلم } بالتوحيد  { بغياً } من الكافرين  { بينهم ولولا كلمة سبقت من ربك } بتأخير الجزاء  { إلى أجل مسمى } يوم القيامة  { لقضي بينهم } بتعذيب الكافرين في الدنيا  { وإن الذين أورثوا الكتاب من بعدهم } وهم اليهود والنصارى  { لفي شك منه } من محمد صلى الله عليه وسلم  { مريب } موقع في الريبة  .
