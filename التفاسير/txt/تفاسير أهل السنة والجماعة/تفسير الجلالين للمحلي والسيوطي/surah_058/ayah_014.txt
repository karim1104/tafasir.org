{ ألم تر إلى الذين تولوا قوما غضب الله عليهم ما هم منكم ولا منهم ويحلفون على الكذب وهم يعلمون } .

{ ألم ترَ } تنظر  { إلى الذين تولَّوْا } هم المنافقون  { قوماً } هم اليهود { غضب الله عليهم ما هم } أي المنافقين { منكم } من المؤمنين { ولا منهم }من اليهود بل هم مذبذبون { ويحلفون على الكذب } أي قولهم إنهم مؤمنون { وهم يعلمون } أنهم كاذبون فيه  .
