{ إنا نحن نحيي الموتى ونكتب ما قدموا وآثارهم وكل شيء أحصيناه في إمام مبين }

{ إنا نحن نحي الموتى } للبعث  { ونكتب } في اللوح المحفوظ  { ما قدَّموا } في حياتهم من خير وشر ليجازوا عليه  { وأثارهم } ما استنَّ به بعدهم  { وكل شيء } نصبه بفعل يفسره  { أحصيناه } ضبطناه  { في إمام مبين } كتاب بيّن ،   هو اللوح المحفوظ  .
