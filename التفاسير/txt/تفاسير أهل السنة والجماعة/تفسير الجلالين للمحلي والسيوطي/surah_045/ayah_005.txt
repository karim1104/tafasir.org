{ و } في  { اختلاف الليل والنهار } ذهابهما ومجيئهما  { وما أنزل الله من السماء من رزق } مطر ؛ لأنه سبب الرزق  { فأحيا به الأرض بعد موتها وتصريف الرياح } تقليبها مرة جنوباً ومرة شمالاً وباردة وحارة  { آيات لقوم يعقلون } الدليل فيؤمنون  .
