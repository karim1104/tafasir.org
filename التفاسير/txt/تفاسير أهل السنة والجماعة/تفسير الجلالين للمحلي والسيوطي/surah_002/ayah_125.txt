{ وإذ جعلنا البيت مثابة للناس وأمنا واتخذوا من مقام إبراهيم مصلى وعهدنا إلى إبراهيم وإسماعيل أن طهرا بيتي للطائفين والعاكفين والركع السجود } .

{ وإذ جعلنا البيت } الكعبة { مثابة للناس } مرجعا يثوبون إليه من كل جانب { وأمنا } مأمنا لهم من الظلم والإغارات الواقعة في غيره  ،   كان الرجل يلقى قاتل أبيه فيه فلا يهيجه { واتخِذوا } أيها الناس { من مقام إبراهيم } هو الحجر الذي قام عليه عند بناء البيت { مصلَّى } مكان صلاة بأن تصلوا خلفه ركعتي الطواف  ،   وفي قراءة بفتح الخاء خبر { وعهدنا إلى إبراهيم وإسماعيل } أمرناهما { أن } أي بأن { طهرا بيتي } من الأوثان { للطائفين والعاكفين } المقيمين فيه { والركع السجود } جمع راكع وساجد المصلين .
