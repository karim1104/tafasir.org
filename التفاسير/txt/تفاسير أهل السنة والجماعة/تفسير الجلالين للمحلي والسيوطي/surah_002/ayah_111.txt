{ وقالوا لن يدخل الجنة إلا من كان هودا أو نصارى تلك أمانيهم قل هاتوا برهانكم إن كنتم صادقين } .

{ وقالوا لن يدخل الجنة إلا من كان هودا } جمع هائد { أو نصارى } قال ذلك يهود المدينة ونصارى نجران لما تناظروا بين يدي النبي صلى الله عليه وسلم أي قال اليهود لن يدخلها إلا اليهود وقال النصارى لن يدخلها إلا النصارى { تلك } القولة { أمانيهم } شهواتهم الباطلة { قل } لهم

{ هاتوا برهانكم } حججكم على ذلك { إن كنتم صادقين } فيه .
