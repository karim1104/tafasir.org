{  وإذا لقوا الذين آمنوا قالوا آمنا وإذا خلا بعضهم إلى بعض قالوا أتحدثونهم بما فتح الله عليكم ليحآجوكم به عند ربكم أفلا تعقلون } .

{ وإذا لقوا } أي منافقو اليهود { الذين آمنوا قالوا آمنا } بأن محمد صلى الله عليه وسلم نبي وهو المبشر به في كتابنا { وإذا خلا } رجع { بعضهم إلى بعض قالوا } أي رؤساؤهم الذين لم ينافقوا لمن نافق { أتحدثونهم } أي المؤمنين { بما فتح الله عليكم } أي عرفكم في التوراة من نعت محمد صلى الله عليه وسلم { ليحاجُّوكم } ليخاصموكم واللام للصيرورة { به عند ربكم } في الآخرة ويقيموا عليكم الحجة في ترك اتباعه مع علمكم بصدقه { أفلا تعقلون } أنهم يحاجونكم إذا حدثتموهم فتنبهوا .
