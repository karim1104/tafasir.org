{ ولتجدنهم أحرص الناس على حياة ومن الذين أشركوا يود أحدهم لو يعمر ألف سنة وما هو بمزحزحه من العذاب أن يعمر والله بصير بما يعملون } .

{ ولتجِدَنَّهم } لام قسم { أحرص الناس على حياة و } أحرص { من الذين أشركوا } المنكرين للبعث عليها لعلمهم بأن مصيرهم النار دون المشركين لإنكارهم له { يود } يتمنى { أحدهم لو يعمر ألف سنة } لو مصدرية بمعنى أن وهي بصلتها في تأويل مصدر مفعول يود { وما هو } أي أحدهم { بمزحزحه } مبعده { من العذاب } النار { أن يعمر } فاعل مزحزحه أي تعميره { والله بصير بما يعملون } بالياء والتاء فيجازيهم .
