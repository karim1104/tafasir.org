{ الذين آتيناهم الكتاب يتلونه حق تلاوته أولئك يؤمنون به ومن يكفر به فأولئك هم الخاسرون } .

{ الذين آتيناهم الكتاب } مبتدأ { يتلونه حق تلاوته } أي يقرؤونه كما أنزل  ،   والجملة حال وحقَّ نصبٌ على المصدر والخبر { أولئك يؤمنون به } نزلت في جماعة قدموا من الحبشة وأسلموا { ومن يكفر به } أي بالكتاب المؤتى بأن يحرفه { فأولئك هم الخاسرون } لمصيرهم إلى النار المؤبدة  .  عليهم
