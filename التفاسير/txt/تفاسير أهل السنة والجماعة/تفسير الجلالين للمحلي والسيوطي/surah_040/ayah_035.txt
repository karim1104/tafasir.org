{ الذين يجادلون في آيات الله بغير سلطان أتاهم كبر مقتا عند الله وعند الذين آمنوا كذلك يطبع الله على كل قلب متكبر جبار }

{ الذين يجادلون في آيات الله } معجزاته مبتدأ  { بغير سلطان } برهان  { أتاهم كبر } جدالهم خبر المبتدأ  { مقتاً عند الله وعند الذين آمنوا كذلك } مثل إضلالهم  { يطبع } يختم  { الله } بالضلال  { على كل قلب متكبَّرِ جبار } بتنوين قلب ودونه ،   ومتى تكبَّر القلب ،   تكبَّر صاحبه وبالعكس ،   وكل على القراءتين لعموم الضلال جميع القلب لا لعموم القلب  .
