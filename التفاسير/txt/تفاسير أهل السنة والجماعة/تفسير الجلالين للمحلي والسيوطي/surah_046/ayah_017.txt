{ والذي قال لوالديه أف لكما أتعدانني أن أخرج وقد خلت القرون من قبلي وهما يستغيثان الله ويلك آمن إن وعد الله حق فيقول ما هذا إلا أساطير الأولين }

{ والذي قال لوالديه } وفى قراءة بالإدغام أريد به الجنس  { أفِ } بكسر الفاء وفتحها بمعنى مصدر ،   أي نتناً وقبحاً  { لكما } أتضجر منكما  { أتعدانني } وفي قرائه بالإدغام  { أن أخرج } من القبر  { وقد خلت القرون } الأمم  { من قبلي } ولم تخرج من القبور  { وهما يستغيثان الله } يسألانه الغوث برجوعه ويقولان إن لم ترجع  { ويلك } أي هلاكك بمعنى هلكت  { آمن } بالبعث  { إن وعد الله حق فيقول ما هذا } أي القول بالبعث  { إلا أساطير الأولين } أكاذيبهم  .
