{ أم يقولون افتراه قل إن افتريته فلا تملكون لي من الله شيئا هو أعلم بما تفيضون فيه كفى به شهيدا بيني وبينكم وهو الغفور الرحيم }

{ أم } بمعني بل وهمزة الإنكار  { يقولون افتراه } أي القرآن  { قل إن افتريته } فرضاً  { فلا تملكون لي من الله } أي من عذابه  { شيئاً } أي لا تقدرون على دفعه عنى إذا عذبني الله  { هو أعلم بما تفيضون فيه } تقولون في القرآن  { كفى به } تعالى  { شهيداً بيني وبينكم وهو الغفور } لمن تاب  { الرحيم } به فلم يعاجلكم بالعقوبة  .
