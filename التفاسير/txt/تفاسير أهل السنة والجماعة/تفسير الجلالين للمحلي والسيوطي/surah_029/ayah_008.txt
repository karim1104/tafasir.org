{ ووصينا الإنسان بوالديه حسنا وإن جاهداك لتشرك بي ما ليس لك به علم فلا تطعهما إلي مرجعكم فأنبئكم بما كنتم تعملون }

{ ووصينا الإنسان بوالديه حسناً } أي إيصاء ذات حسن بأن يبرهما  { وإن جاهداك لتشرك بي ما ليس لك به } بإشراكه  { علم } موافقة للواقع فلا مفهوم له  { فلا تطعهما } في الإشراك  { إليَّ مرجعكم فأنبئكم بما كنتم تعملون } فأجازيكم به .
