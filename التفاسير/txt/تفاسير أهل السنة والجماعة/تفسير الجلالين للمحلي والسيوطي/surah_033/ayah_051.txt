{ ترجي من تشاء منهن وتؤوي إليك من تشاء ومن ابتغيت ممن عزلت فلا جناح عليك ذلك أدنى أن تقر أعينهن ولا يحزن ويرضين بما آتيتهن كلهن والله يعلم ما في قلوبكم وكان الله عليما حليما }

{ ترجئ } بالهمزة والياء بدله : تؤخر  { من تشاء منهنَّ } أي أزواجك عن نوبتها  { وتؤوي } تضم  { إليك من تشاء } منهن فتأتيها  { ومن ابتغيت } طلبت  { ممن عزلت } من القسمة  { فلا جُناح عليك } في طلبها وضمها إليك خُيِّر في ذلك بعد أن كان القسم واجباً عليه  { ذلك } التخيير  { أدنى } أقرب إلى  { أن تقرَّ أعينهنَّ ولا يحزن ويرضين بما آتيتهن } ما ذكر المخيّر فيه  { كلهن } تأكيد للفاعل في يرضين  { والله يعلم ما في قلوبكم } من أمر النساء والميل إلى بعضهن ،   وإنما خيَّرناك فيهن تيسيراً عليك في كل ما أردت  { وكان الله عليماً } بخلقه  { حليماً } عن عقابهم .
