{ يحسبون الأحزاب لم يذهبوا وإن يأت الأحزاب يودوا لو أنهم بادون في الأعراب يسألون عن أنبائكم ولو كانوا فيكم ما قاتلوا إلا قليلا }

{ يحسبون الأحزاب } من الكفار  { لم يذهبوا } إلى مكة لخوفهم منهم  { وإن يأت الأحزاب } كرة أخرى  { يودُّوا } يتمنوا  { لو أنهم بادون في ألأعراب } أي كائنون في البادية  { يسألون عن أنبائكم } أخباركم مع الكفار  { ولو كانوا فيكم } هذه الكرة  { ما قاتلوا إلا قليلاً } رياءً وخوفاً من التعيير .
