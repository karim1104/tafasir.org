{ فهل ينظرون إلا الساعة أن تأتيهم بغتة فقد جاء أشراطها فأنى لهم إذا جاءتهم ذكراهم }

{ فهل ينظرون } ما ينتظرون ،   أي كفار مكة  { إلا الساعة أن تأتيهم } بدل اشتمال من الساعة ،   أي ليس الأمر إلا أن تأتيهم  { بغتةٌ } فجأة  { فقد جاء أشرطها } علاماتها : منها النبي صلى الله عليه وسلم وانشقاق القمر والدخان  { فأنَّى لهم إذا جاءتهم } الساعة  { ذكراهم } تذكرهم ،   أي لا ينفعهم  .
