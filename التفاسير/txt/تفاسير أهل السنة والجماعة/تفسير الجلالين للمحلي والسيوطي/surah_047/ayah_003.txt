{ ذلك بأن الذين كفروا اتبعوا الباطل وأن الذين آمنوا اتبعوا الحق من ربهم كذلك يضرب الله للناس أمثالهم }

{ ذلك } أي إضلال الأعمال وتكفير السيئات  { بأن } بسبب أن  { الذين كفروا اتبعوا الباطل } الشيطان  { وأن الذين آمنوا اتبعوا الحق } القرآن  { من ربهم كذلك } أي مثل ذلك البيان  { يضرب الله للناس أمثالهم } يبيِّن أحوالهم ،   أي فالكافر يحبط عمله ،   والمؤمن يغفر له  .
