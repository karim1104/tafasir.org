{ هو الذي أنزل السكينة في قلوب المؤمنين ليزدادوا إيمانا مع إيمانهم ولله جنود السماوات والأرض وكان الله عليما حكيما }

{ هو الذي أنزل السكينة } الطمأنينة  { في قلوب المؤمنين ليزدادوا إيماناً مع إيمانهم } بشرائع الدين كلما نزَّل واحدة منها آمنوا بها ومنها الجهاد  { ولله جنود السماوات والأرض } فلوا أراد نصر دينه بغيركم لفعل  { وكان الله عليماً } بخلقه  { حكيماً } في صنعه ،   أي لم يزل متصفاً بذلك  .
