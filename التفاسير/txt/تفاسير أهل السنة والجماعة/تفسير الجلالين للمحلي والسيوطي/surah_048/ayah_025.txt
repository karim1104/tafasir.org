{ هم الذين كفروا وصدوكم عن المسجد الحرام والهدي معكوفا أن يبلغ محله ولولا رجال مؤمنون ونساء مؤمنات لم تعلموهم أن تطؤهم فتصيبكم منهم معرة بغير علم ليدخل الله في رحمته من يشاء لو تزيلوا لعذبنا الذين كفروا منهم عذابا أليما }

{ هم الذين كفروا وصدوكم عن المسجد الحرام } أي عن الوصول إليه  { والهدي } معطوف على كم  { معكوفاً } محبوساً حال  { أن يبلغ محله } أي مكانه الذي ينحر فيه عادة وهو الحرم بدل اشتمال  { ولولا رجال مؤمنون ونساء مؤمنات } موجودون بمكة مع الكفار  { لم تعلموهم } بصفة الإيمان  { أن تطؤوهم } أي تقتلوهم مع الكفار لو أذن لكم في الفتح بدل اشتمال من هم  { فتصيبكم منهم معرة } أي إثم  { بغير علم } منكم به وضمائر الغيبة للصنفين بتغليب الذكور ،   وجواب لولا محذوف ،   أي لأذن لكم في الفتح لكن لم يؤذن فيه حينئذ  { ليدخل الله في رحمنه من يشاء } كالمؤمنين المذكورين  { لو تزيَّلوا } تميزوا عن الكفار  { لعذَّبنا الذين كفروا منهم } من أهل مكة حينئذ بأن فأذن لكم في فتحا  { عذاباً أليماً } مؤلماً  .
