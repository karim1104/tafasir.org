{ يا أيها الذين آمنوا توبوا إلى الله توبة نصوحا عسى ربكم أن يكفر عنكم سيئاتكم ويدخلكم جنات تجري من تحتها الأنهار يوم لا يخزي الله النبي والذين آمنوا معه نورهم يسعى بين أيديهم وبأيمانهم يقولون ربنا أتمم لنا نورنا واغفر لنا إنك على كل شيء قدير }

{ يا أيها الذين آمنوا توبوا إلى الله توبة نصوحاً } بفتح النون وضمها صادقة ،   بأن لا يعاد إلى الذنب ولا يُراد العود إليه  { عسى ربكم } ترجية تقع  { أن يكفر عنكم سيئاتكم ويدخلكم جنات } بساتين  { تجري من تحتها الأنهار يوم لا يجزي الله } بإدخال النار  { النبي والذين آمنوا معه نورهم يسعى بين أيديهم } أمامهم  { و } يكون  { بأيمانهم يقولون } مستأنف  { ربنا أتمم لنا نورنا } إلى الجنة والمنافقون يطفأ نورهم  { واغفر لنا } ربنا  { إنك على كل شيءٍ قدير }  .
