{ لا يقاتلونكم جميعا إلا في قرى محصنة أو من وراء جدر بأسهم بينهم شديد تحسبهم جميعا وقلوبهم شتى ذلك بأنهم قوم لا يعقلون } .

{ لا يقاتلونكم } أي اليهود  { جميعاً } مجتمعين  { إلا في قرى محصنة أو من وراء جدار } سور  ،   وفي قراءة جدر  { بأسهم } حربهم  { بينهم شديد تحسبهم جميعاً } مجتمعين  { وقلوبهم شتى } متفرقة خلاف الحسبان  { ذلك بأنهم قوم لا يعقلون }  .
