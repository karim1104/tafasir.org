{ وإن جاهداك على أن تشرك بي ما ليس لك به علم فلا تطعهما وصاحبهما في الدنيا معروفا واتبع سبيل من أناب إلي ثم إلي مرجعكم فأنبئكم بما كنتم تعملون }

{ وإن جاهداك على أن تشرك بي ما ليس لك به علم } موافقة للواقع  { فلا تطعهما وصاحبهما في الدنيا معروفاً } أي بالمعروف : البر والصلة  { واتبع سبيل } طريق  { من أناب } رجع  { إليَّ } بالطاعة  { ثم إليَّ مرجعكم فأنبئكم بما كنتم تعملون } فأجازيكم عليه وجملة الوصية وما بعدها اعتراض .
