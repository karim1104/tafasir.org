{ يا أيها الناس اذكروا نعمة الله عليكم هل من خالق غير الله يرزقكم من السماء والأرض لا إله إلا هو فأنى تؤفكون }

{ يا أيها الناس } أي أهل مكة  { اذكروا نعمة الله عليكم } بإسكانكم الحرم ومنع الغارات عنكم  { هل من خالق } من زائدة وخالق مبتدأ  { غيرُ الله } بالرفع والجر نعت لخالق لفظاً ومحلا ،   وخبر المبتدأ  { يرزقكم من السماء } المطر  { و } من  { الأرض } النبات ،   والاستفهام للتقرير ،   أي لا خالق رازق غيره  { لا إله إلا هو فانَّى تؤفكون } من أين تصرفون عن توحيده مع إقراركم بأنه الخالق الرازق  .
