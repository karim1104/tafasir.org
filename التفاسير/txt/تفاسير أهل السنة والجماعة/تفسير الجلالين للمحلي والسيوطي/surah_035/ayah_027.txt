{ ألم تر أن الله أنزل من السماء ماء فأخرجنا به ثمرات مختلفا ألوانها ومن الجبال جدد بيض وحمر مختلف ألوانها وغرابيب سود }

{ ألم ترَ } تعلم  { أن الله أنزل من السماء ماءً فأخرجنا } فيه التفات عن الغيبة  { به ثمرات مختلفاً ألوانها } كأخضر وأحمر وأصفر وغيرها  { ومن الجبال جدد } جمع جدة ،   طريق في الجبل وغيره  { بيضٌ وحمر } وصفر  { مختلف ألوانها } بالشدة والضعف  { وغرابيب سود } عطف على جدد ،   أي صخور شديدة السواد ،   يقال كثيراً أسود غربيب ،   وقليلاً : غربيب أسود  .
