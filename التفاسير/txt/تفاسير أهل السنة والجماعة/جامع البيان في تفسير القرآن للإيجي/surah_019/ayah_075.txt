{ قُلْ مَن كَانَ فِي الضَّلالَةِ } : الشرك { فَلْيَمْدُدْ لَهُ الرَّحْمَنُ مَدًّا } : يدعه ويمهله في طغيانه استدراجا وهو خبر بلفظ الأمر إشعار بوجوب ذلك وأنه مفعول لا محالة وقيل هذا دعاء { حَتَّى إِذَا رَأَوْا مَا يُوعَدُونَ إِمَّا الْعَذَابَ } : في الدنيا كالأسر والقتل { وَإِمَّا السَّاعَةَ } : القيامة { فَسَيَعْلَمُونَ } عند ذلك { مَنْ هُوَ شَرٌّ مَّكَانًا وَأَضْعَفُ جُندًا } : فئة وناصرا وحتى غاية المد أي : هم في الاستدراج ممدود لهم الغواية إلى أن يأتيهم وعد الله أو غاية قول الكفار أي : الفريقين خير ،   أي : لا يزالون يقولون ذلك إلى أن يشاهد الموعود .
