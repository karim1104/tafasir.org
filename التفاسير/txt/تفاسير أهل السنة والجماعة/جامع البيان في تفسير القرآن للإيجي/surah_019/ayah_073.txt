{ وَإِذَا تُتْلَى عَلَيْهِمْ آيَاتُنَا بَيِّنَاتٍ } : واضحات المعاني والبرهان حال مؤكدة { قَالَ الَّذِينَ كَفَرُوا لِلَّذِينَ آمَنُوا } : معهم ،   ولأجلهم { أَيُّ الْفَرِيقَيْنِ خَيْرٌ } : منا ومنكم خير { مَّقَامًا } : مكانا { وَأَحْسَنُ نَدِيًّا } : مجلسا يعني لما سمعوا آيات الله أعرضوا عنها واستدلوا على فضلهم وشرفهم بزيادة حظهم حطام الدنيا فرد الله تعالى عليهم بقوله{ وَكَمْ أَهْلَكْنَا قَبْلَهُم مِّن قَرْنٍ هُمْ أَحْسَنُ أَثَاثًا وَرِئْيًا } .
