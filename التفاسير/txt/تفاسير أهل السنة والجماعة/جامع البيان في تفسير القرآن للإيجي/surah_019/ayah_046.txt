{ قَالَ } : أبوه { أَرَاغِبٌ أَنتَ عَنْ آلِهَتِي يَا إِبْراهِيمُ } ،   قابل استعطافه بالغلظة حيث سماه باسمه ولم يقل يا ولدي وأخره وقدم المبتدأ وصدره بهمزة الإنكار ،   ثم أوعده بأقبح و عيد فقال : { لَئِن لَّمْ تَنتَهِ } : عن مقالتك أو عن الرغبة عنها { لأَرْجُمَنَّك } : بلساني أي أشتمك جزاء سبك آلهتي ،   وقيل بالحجارة حتى تموت { وَاهْجُرْنِي } ،   عطف على مقدر أي : فاحذرني و اهجرني { مَلِيًّا } زمانا طويلا أو سويا سالما قبل أن يصيبك مني مكروه .
