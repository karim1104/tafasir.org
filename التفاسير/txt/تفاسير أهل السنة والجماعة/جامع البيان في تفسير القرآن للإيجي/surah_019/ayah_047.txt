{ قَالَ } : إبراهيم { سَلامٌ عَلَيْكَ } : سلمت بعد مني لا أقول لك ما يؤذيك وهذا جواب الجاهل { وإذا خاطبهم الجاهلون قالوا سلاما "  ( الفرقان : 63 ) ،   { سَأَسْتَغْفِرُ لَكَ رَبِّي } رجاء أن يوفقك للتوبة ،   فتؤمن أو كان يستغفر له أولا ثم رجع عنه كما قال تعالى :  " فلما تبين له أنه عدو الله تبرأ منه "  ( التوبة :114 ) ،   { إِنَّهُ كَانَ بِي حَفِيًّا } بليغا في البر واللطف .
