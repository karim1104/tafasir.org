{ قَالَ كَذَلِكِ } أي : الأمر كذلك ،   صدقها فيما قالت ثم ابتدأ ،   وجاز أن يتعلق  " كذلك " { بقال ربك } "  و قوله  " هو علي هين "  مفسر ذلك المبهم { قَالَ رَبُّكِ هُوَ } أي : وهب غلام من غير أب { عَلَيَّ هَيِّنٌ وَلِنَجْعَلَهُ } ،   تقديره : ونفعل ذلك لنجعله أو لنبين قدرتنا ولنجعله { آيَةً لِلنَّاسِ } : على كمال قدرتنا { وَرَحْمَةً مِّنَّا } : على عبادنا لأنه يهديهم { وَكَانَ أَمْرًا مَّقْضِيًّا } : في علم الله الأزلي الذي لا يتغير .
