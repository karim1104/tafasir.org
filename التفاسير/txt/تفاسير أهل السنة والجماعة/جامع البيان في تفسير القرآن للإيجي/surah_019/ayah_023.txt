{ فَأَجَاءهَا } ألجأها : واضطرها { الْمَخَاضُ } : وجع الولادة { إِلَى جِذْعِ النَّخْلَةِ } : لتعتمد عليه عند الولادة ،   والتعريف إما للجنس أو للعهد ؛ إذ لم يكن ثم غيرها متعالم عند الناس ،   { قَالَتْ } : استحياء من الناس { يَا لَيْتَنِي مِتُّ قَبْلَ هَذَا } الأمر { وَكُنتُ نَسْيًا } ما من حقه أن يطرح وينسى كالذبح اسم لما من شأنه أن يذبح وبفتح النون لغة فيه { مَّنسِيًّا } : بحيث لا يخطر ببال أحد .
