{ فَخَلَفَ مِن بَعْدِهِمْ خَلْفٌ } خلفه أي : عقبه وخلق بسكون اللام عقب السوء وبفتحها عقب الخير { أَضَاعُوا الصَّلاةَ } : تركوها أو أخروا عن وقتها { وَاتَّبَعُوا الشَّهَوَاتِ } مالوا إلى زخارف الدنيا وهم اليهود والنصارى ،   وعن بعضهم أنهم من هذه الأمة في آخر الزمان { فَسَوْفَ يَلْقَوْنَ غَيًّا } : شرا وخسرانا أو هو واد في جهنم يسيل فيها صديد أهل النار .
