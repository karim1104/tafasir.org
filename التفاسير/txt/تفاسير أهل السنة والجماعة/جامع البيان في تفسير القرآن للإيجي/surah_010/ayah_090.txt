{ وَجَاوَزْنَا بِبَنِي إِسْرَائِيلَ الْبَحْر } أي : جاوزناهم في البحر بلا سفينة وتعب ،   { فَأَتْبَعَهُمْ } أدركهم ،   { فِرْعَوْنُ وَجُنُودُهُ } قيل : كانوا في مائة ألف أدهم سوى بقية الألوان ،   { بَغْيًا وَعَدْوًا } للبغي أي : لطلب الاستعلاء والظلم أو باغين ،   { حَتَّى إِذَ ا أَدْرَكَهُ الْغَرَقُ قَالَ آمَنتُ أَنَّه } أي : بأنه ،   { لا إِلِهَ إِلاَّ الَّذِي آمَنَتْ بِهِ بَنُو إِسْرَائِيل وَأَنَاْ مِنَ الْمُسْلِمِينَ } .
