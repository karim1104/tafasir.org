{ قَالُواْ اتَّخَذَ اللّهُ وَلَدًا } كما قالوا الملائكة بنات الله ،   { سُبْحَانَهُ } تنزيه على التبني وتعجب عن حماقتهم ،   { هُوَ الْغَنِيُّ } واتخاذ الولد مسبب عن الحاجة ،   { لَهُ مَا فِي السَّمَاوَات وَمَا فِي الأَرْضِ } مقرر لغناه ،   { إ نْ عِندَكُم مِّن سُلْطَانٍ بِهَذَا } أي : ليس عندكم دليل بهذا ،   بل أنتم تابعون للجهالة ،   { أَتقُولُونَ عَلَى اللّهِ مَا لاَ تَعْلَمُونَ } فيه تهديد شديد ووعيد أكيد .
