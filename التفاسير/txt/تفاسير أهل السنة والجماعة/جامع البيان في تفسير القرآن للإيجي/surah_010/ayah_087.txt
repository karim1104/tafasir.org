{ وَأَوْحَيْنَا إِلَى مُوسَى وَأَخِيهِ أَن تَبَوَّءَا } أي : اتخذا مباءة يعني موضع إقامة ،   { لقومكما بمصر بيوتا واجعلوا } أنتما وقومكما { في بيوتكم } التي اتخذتموها ،   { قِبْلَةً } أي : مساجد فإنهم كانوا لا يصلون إلا في كنائسهم وكانوا يخافون من فرعون فأمروا أن يجعلوا في بيوتهم مساجد يصلون فيها سرا أو اجعلوا بيوتكم قبلة مصلى ،   أو متقابلة والمقصود على هذا حصول الجمعية ،   { وَأَقِيمُواْ الصَّلاَةَ } أي : فيها قال بعضهم : أمروا بكثرة الصلاة كما قال تعالى :  " واستعينوا بالصبر والصلاة "  ( البقرة : 45 ) ،   { وَبَشِّرِ } يا موسى ،   { اْلمُؤْمِنِينَ } بالنصر في الدارين .
