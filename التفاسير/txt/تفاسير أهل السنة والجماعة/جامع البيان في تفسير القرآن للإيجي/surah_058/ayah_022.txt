{ لا تجد قوما يؤمنون بالله واليوم الآخر يوادون من حاد الله ورسوله }  ،   يعني لا يجتمع الإيمان ومحبة أعداء الله تعالى  ،  { ولو كانوا } أي من حاد الله  ،  { آبائهم أو أبناءهم أو إخوانهم أو عشيرتهم } أقاربهم  ،  { أولئك } الذين لم يوادوهم { كتب } الله { في قلوبهم الإيمان } : أثبته فيها  ،  { وأيدهم بروح منه } : من عند الله تعالى وهو النصر على العدو أو نور القلب  ،  { ويدخلهم جنات تجري من تحتها الأنهار خالدين } حال مقدرة  ،  { فيها رضي الله عنهم ورضوا عنه } لما سخطوا على القرائب لله تعالى عوضهم بالرضا عنهم وأرضاهم عنه بما أنعم عليهم من الفضل العظيم  ،  { أولئك حزب الله } أنصار دينه  ،  { ألا إن حزب الله هم المفلحون } الفائزون بخير الدارين .

اللهم اجعلنا منهم .
