{ وَلَوْ دُخِلَتْ عَلَيْهِم مِّنْ أَقْطَارِهَا } يعني : لو دخلت هذه العساكر المدينة من جوانبها ،   { ثُمَّ سُئِلُوا } : سألت هذه العساكر من قال إن بيوتنا عورة ،   { الْفِتْنَةَ } : الردة ومحاربة المسلمين ،   { لَآتَوْهَا } لأعطوها ،   { وَمَا تَلَبَّثُوا بِهَا } : بالفتنة ،   { إِلَّا يَسِيرًا } : تلبثا يسيرا قدر سؤال وجواب فأسرعوا الإجابة ،
