{ يَا نِسَاء النَّبِيِّ مَن يَأْتِ مِنكُنَّ بِفَاحِشَةٍ } : كبيرة ،   { مُّبَيِّنَةٍ } : ظاهر قبحها ،   عن ابن عباس هي النشوز وسوء الخلق ،   { يُضَاعَفْ لَهَا الْعَذَابُ ضِعْفَيْنِ } : ضعفي عذاب غيرهن ،   فإن الذنب أقبح من العارفين والشرط لا يقتضي الوقوع قال تعالى : { قل إن كان للرحمن ولد } [ الزخرف : 81 ] ،   { وَكَانَ ذَلِكَ عَلَى اللَّهِ يَسِيرًا } هيّنا ،   لا ينظر إلى كونهن نساء نبيه ،   بل هو السبب
