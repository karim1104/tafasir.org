{ هو الله الذي لا إله إلا هو الملك القدوس } الطاهر البليغ في النزاهة عن كل النقصان { السلام } ذو السلامة من كل نقص { المؤمن } واهب الأمن أم المصدق للمؤمنين والكافرين في وعدهم ووعيدهم { المهيمن } الرقيب المطلع على السرائر  ،  { العزيز الجبار } العظيم أو الذي جبر خلقه على مراده أو جبر حالهم وأصلحها  ،  { المتكبر } الذي تكبر عن كل نقص وأصل الكبرياء الامتناع  ،  { سبحان الله عما يشركون } .
