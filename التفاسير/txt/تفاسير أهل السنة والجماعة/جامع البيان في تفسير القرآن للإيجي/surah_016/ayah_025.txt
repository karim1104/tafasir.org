{ لِيَحْمِلُواْ أَوْزَارَهُمْ كَامِلَةً يَوْمَ الْقِيَامَةِ } هي لام العاقبة فإن قولهم هذا أداهم إلى حمل أوزارهم ضلالهم كاملة لم يكفر منها شيء بمصيبة أصابتهم في الدنيا لكفرهم ،   { وَمِنْ أَوْزَارِ } أي : ليحملوا أوزار أنفسهم وبعض أوزار ،   { الَّذِينَ يُضِلُّونَهُم } يعني خطيئة إغوائهم لغيرهم ،   { بِغَيْرِ عِلْمٍ } حال من مفعول يضلون أو من فاعله ،   { أَلاَ سَاء مَا يَزِرُونَ } أي : بئس شيئا يزرونه صنيعهم .
