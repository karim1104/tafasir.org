{ وَيَوْمَ نَبْعَثُ } ،   أي : اذكر هذا اليوم وهوله ،   { فِي كُلِّ أُمَّةٍ شَهِيدًا عَلَيْهِم مِّنْ أَنفُسِهِمْ } ،   نبي كل أمة بعث من قومه ،   { وَجِئْنَا بِكَ } : يا محمد ،   { شَهِيدًا عَلَى هَؤُلاء } : على أمتك ،   { وَنَزَّلْنَا } ،   حال بإضمار قد ،   { عَلَيْكَ الْكِتَابَ تِبْيَانًا } : بيانا بليغا ،   { لِّكُلِّ شَيْءٍ } يحتاجون إليه من أمور الدين ،   { وَهُدًى } من الضلال ،   { وَرَحْمَةً } للجميع ،   { وَبُشْرَى } : وبشارة { لِلْمُسْلِمِينَ } خاصة ،   وحاصله أن الله أمره يخوف أمته بيوم شهادته  عليه الصلاة والسلام  على أمته ،   حال كونه مسئولا عن تبليغ أحكام الله المبينة في القرآن ،   والأمة عن قبولها ،   كما قال تعالى :  " فلنسألن الذين أرسل إليهم ولنسألن المرسلين "  ( الأعراف : 6 ) ،    " فوربك لنسألنهم أجمعين عما كانوا يعملون "  ( الحجر :92 ) .
