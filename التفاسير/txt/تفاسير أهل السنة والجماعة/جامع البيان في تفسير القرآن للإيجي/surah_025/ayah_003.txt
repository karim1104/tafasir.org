{ وَاتَّخَذُوا مِن دُونِهِ آلِهَةً لَّا يَخْلُقُونَ شَيْئًا } : عاجزين ،   { وَهُمْ يُخْلَقُونَ } : فإن عبدتهم ينحتونهم ،   { وَلَا يَمْلِكُونَ لِأَنفُسِهِمْ ضَرًّا } أي : دفعه ،   { وَلَا نَفْعًا } أي : جلبه ،   { وَلَا يَمْلِكُونَ مَوْتًا } ،   إماتة أحد { وَلَا حَيَاةً } : إحياءه { وَلَا نُشُورًا } : بعثه ثانيا فكيف يستحقون الألوهية ،   وهم متصفون بصفات تنافيها ،
