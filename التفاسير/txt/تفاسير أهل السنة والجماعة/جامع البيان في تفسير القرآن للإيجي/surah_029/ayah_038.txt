{ وَعَادًا وَثَمُود } منصوبان بفعل دل عليه ما قبله مثل أهلكنا وعدم انصراف ثمود بتأويل القبيلة { وَقَد تَّبَيَّنَ لَكُم مِّن مَّسَاكِنِهِمْ } بعض مساكنهم باليمن أو تبين لكم إهلاكهم من جهة مساكنهم إذا رأيتموها { وَزَيَّنَ لَهُمُ الشَّيْطَانُ أَعْمَالَهُمْ } السيئة { فَصَدَّهُمْ عَنِ السَّبِيلِ } عن الطريق المستقيم { وَكَانُوا مُسْتَبْصِرِينَ } عقلاء عند أنفسهم معجبين برأيهم أو كانوا في نفس الأمر متمكنين من النظر إلى مستبصرين بضلالهم لكنهم لجوا
