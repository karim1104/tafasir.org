{ إِنَّمَا تَعْبُدُونَ مِن دُونِ اللَّهِ أَوْثَانًا وَتَخْلُقُونَ } تكذبون { إِفْكًا } كذبا في أنها شركاء الله شفعاء أو تنحتونها للإفك ،   جعل نحتهم خلقا وإيجادا { إِنَّ الَّذِينَ تَعْبُدُونَ مِن دُونِ اللَّهِ لَا يَمْلِكُونَ لَكُمْ رِزْقًا } ولا يكون المعبود إلا الرازق ،   ورزقا مفعول به من غير تأويل ،   والتنكير للتعميم { فَابْتَغُوا عِندَ اللَّهِ الرِّزْق } كله فإنه مالكه وحده { وَاعْبُدُوهُ وَاشْكُرُوا لَهُ إِلَيْهِ تُرْجَعُونَ } فاستعدوا للقائه
