{ أَوَلَمْ يَرَوْا } أهل مكة { أَنَّا جَعَلْنَا حَرَمًا آمِنًا } جعلنا بلدتهم ذا أمن لا يغار على أهله { وَيُتَخَطَّفُ النَّاسُ مِنْ حَوْلِهِمْ } يختلسون تغزوا العرب بعضهم بعضا حولهم ،   وهم آمنون مع قتلهم وكثرة العرب { أَفَبِالْبَاطِلِ } أي : أبعد لهذه النعمة الظاهرة بالصنم { يُؤْمِنُونَ وَبِنِعْمَةِ اللَّهِ يَكْفُرُونَ } حيث أشركوا به غيره
