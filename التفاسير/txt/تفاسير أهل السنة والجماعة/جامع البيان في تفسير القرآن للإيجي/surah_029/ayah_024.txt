{ فَمَا كَانَ جَوَابَ قَوْمِهِ } أي : إبراهيم له { إِلَّا أَن قَالُوا اقْتُلُوهُ أَوْ حَرِّقُوهُ } أي : عذبوه أحد العذابين { فَأَنجَاهُ اللَّهُ مِنَ النَّارِ } بعد ما قذفوه فيها بأن جعلها عليه برادا وسلاما { إِنَّ فِي ذَلِكَ } إنجائه منها { لَآيَاتٍ لِّقَوْمٍ يُؤْمِنُونَ } فإن الكفار غير موفقين على التدبر في مثل ذلك
