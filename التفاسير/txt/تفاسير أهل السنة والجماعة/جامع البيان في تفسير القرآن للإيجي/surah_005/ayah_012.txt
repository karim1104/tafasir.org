{ وَلَقَدْ أَخَذَ اللَّهُ مِيثَاقَ بَنِي إِسْرَائِيلَ } لما أمر المؤمنين بالوفاء بعهده وأمرهم بالحق والعدل وذكرهم نعمه شرع يبين لهم كيفية أخذ العهود على من كان قبلهم وطردهم ولعنهم لما نقضوها ليتعظ المؤمنون { وبعثنا منهم اثني عشر نقيبا } كفيلا ضمنوا عن قومهم الوفاء بالعهد { وقال الله إني معكم } بالنصرة { لئن } أي : والله لئن { أقمتم الصلاة وآتيتم الزكاة وآمنتم برُسلي } صدقتموهم بما جاءوا به { وعزّرتموهم } نصرتموهم وعظمتموهم { وأقرضتم الله قرضا حسنا } بأن تنفقوا في سبيل الخيرات نصب بالمصدر أو بالمفعول الثاني { لأُكفّرن } جواب القسم سد مسد جواب الشرط { عنكم سيئاتكم ولأّدخلنّكم جنات تجري من تحتها } تحت غرفها { الأنهار فمن كفر بعد ذلك } الميثاق { منكم فقد ضل سواء السبيل } صراط الحق فإن الضلال بعده أظهر وأعظم وأقبح .
