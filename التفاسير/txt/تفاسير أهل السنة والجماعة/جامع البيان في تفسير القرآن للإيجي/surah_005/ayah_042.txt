{ سمّاعون للكذب } كرره للتأكيد .   { أكّالون للسُّحت } : الحرام كالرشى ،   فإنه مسحوت البركة { فإن جاءوك فاحكم بينهم أو أعرض عنهم } تخيير في الحكم والإعراض { وإن تُعرض عنهم فلن يضرّوك شيئا } فإن الله يعصمك من الناس قال كثير من السلف : الآية منسوخة بقوله : ( وأن احكم بينهم بما أنزل الله ) ( المائدة : 48 ) { وإن حكمت فاحكُم بينهم بالقسط } أي : العدل وإن كانوا ظلمة مستحقين للتعذيب { إن الله يحب المقسطين } : يرضى عنهم ويعظمهم .
