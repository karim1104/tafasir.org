{ وَيَوْمَ } أي : اذكر يوم { نُسَيِّرُ الْجِبَالَ } : نقلعها ونسيرها كالسحاب { وَتَرَى الْأَرْضَ بَارِزَةً } : ظاهرة قاعا صفصفا سطحا مستويا لا وادي فيها ولا جبل { وَحَشَرْنَاهُمْ } الواو للعطف أو للحال أي : وقد حشرنا جمع الخلق وأحييناهم قبل تسيير الجبال ليعاينوا ما أنكروا { فَلَمْ نُغَادِرْ } : لم نترك ،   { مِنْهُمْ أَحَدًا } .
