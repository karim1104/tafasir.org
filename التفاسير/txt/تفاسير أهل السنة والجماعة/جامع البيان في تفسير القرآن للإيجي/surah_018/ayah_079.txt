{ أَمَّا السَّفِينَةُ فَكَانَتْ لِمَسَاكِينَ } قيل : فيه دليل على أن المسكين يطلق على ما لا يملك شيئا يكفيه { يَعْمَلُونَ فِي الْبَحْرِ فَأَرَدتُّ أَنْ أَعِيبَهَا } : أجعلها ذات عيب { وَكَانَ وَرَاءهُم } أي : أمامهم { مَّلِكٌ يَأْخُذُ كُلَّ سَفِينَةٍ } : صالحة { غَصْبًا } نصب بالحال أو بالمفعول له .
