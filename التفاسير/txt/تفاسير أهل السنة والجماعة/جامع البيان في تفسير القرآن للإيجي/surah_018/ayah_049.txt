{ وَوُضِعَ الْكِتَابُ } أي : صحف الأعمال في أيمانهم وشمائلهم { فَتَرَى الْمُجْرِمِينَ مُشْفِقِينَ } : خائفين { مِمَّا فِيهِ وَيَقُولُونَ يَا وَيْلَتَنَا } ينادون هلكتهم من بين الهلكات { مَا لِهَذَا الْكِتَابِ } تعجيبا من شأنه ،   { لا يُغَادِرُ } : لا يترك ،   { صَغِيرَةً } أي : هنة صغيرة من أعمالنا { وَلا كَبِيرَةً إِلا أَحْصَاهَا } : عدها وحصرها { وَوَجَدُوا مَا عَمِلُوا حَاضِرًا } : في الصحف أو جزاء ما عملوا حاضرا عندهم { وَلا يَظْلِمُ رَبُّكَ أَحَدًا } ،   فيكتب عليه ما لم يفعل أو بأن يعاقبه بما لم يفعل .
