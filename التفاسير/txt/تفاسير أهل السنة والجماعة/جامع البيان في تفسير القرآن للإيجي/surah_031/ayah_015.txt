{ وَإِن جَاهَدَاكَ } : بالغاك وحرضاك ،   { عَلى أَن تُشْرِكَ بِي مَا لَيْسَ لَكَ بِهِ عِلْمٌ } أي : ما ليس بإله يعني : ما ليس لك علم باستحقاقه للإشراك تقليدا للوالدين ف ( ما ليس ) مفعول تشرك ،   { فَلَا تُطِعْهُمَا } : في ذلك ،   { وَصَاحِبْهُمَا فِي الدُّنْيَا مَعْرُوفًا } أي : صحابا معروفا مشروعا حسنا بخلق جميل وحلم وبر ومروة ،   { وَاتَّبِعْ } : في دينك ،   { سَبِيلَ مَنْ أَنَابَ } : رجع ،   { إِلَيَّ } : بالتوحيد والطاعة ،   { ثُمَّ إِلَيَّ مَرْجِعُكُمْ } أي : المولود والوالدين ،   { فَأُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ } : بجزاء عملكم والآيتان أعني : ووصينا إلى هنا وقعتا في أثناء وصية لقمان على سبيل الاستطراد تأكيدا لما في وصيته من النهي عن الشرك ،   وقد نقل أنهما نزلتا حين قالت أم سعد لسعد حين أسلم : لتدعن دينك أو لأدع الطعام والشراب حتى أموت ،   فأجاب : والله لو كانت لك مائة نفس فخرجت نفسا نفسا ما تركت ديني هذا بشيء إن شئت كلي وإن شئت لا تأكلي ،
