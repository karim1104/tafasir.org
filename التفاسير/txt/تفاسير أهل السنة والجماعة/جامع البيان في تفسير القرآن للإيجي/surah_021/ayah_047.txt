{ وَنَضَعُ الْمَوَازِينَ } ،   جمعه لكثرة ما يوزن به ولاختلافه ،   { الْقِسْطَ } : ذوات القسط أو نحو رجل عدل ،   { لِيَوْمِ الْقِيَامَةِ } : لأجل جزائه أو لأجل أهله ،   أو اللام بمعنى في ،   { فَلَا تُظْلَمُ نَفْسٌ شَيْئًا } : من الظلم أو من العمل ،   { وَإِن كَانَ } : العمل ،   { مِثْقَالَ حَبَّةٍ مِّنْ خَرْدَلٍ أَتَيْنَا بِهَا } : أحضرنا لنجازي بها ،   ومن قرأ : مثقال بالرفع فكان تامة ،   { وَكَفَى بِنَا حَاسِبِينَ } لكمال علمنا وعدلنا مفعول كفى محذوف ،   أي كفينا العالمين حال كوننا حاسبين لا يحتاجون إلى محاسب غيرنا ،
