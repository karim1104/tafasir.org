{ وَلاَ تَقْتُلُواْ  النَّفْسَ الَّتِي حَرَّمَ اللّهُ } : قتله ،   { إِلاَّ بِالحَقِّ } ،   بردة وزنى بعد إحصان وقتل معصوم عمدا ،   { وَمَن قُتِلَ مَظْلُومًا } غير مستوجب القتل ،   { فَقَدْ جَعَلْنَا لِوَلِيِّهِ } وهو الوارث لأنه يلي أمره بعده ،   { سُلْطَانًا } : تسلطا على القاتل بقتله أو أخذ الدية أو عفوه ،   { فَلاَ يُسْرِف } أي : الوالي ،   { فِّي الْقَتْلِ } بأن يقتل غير القاتل أو يمثل بالقاتل ،   أو معناه لا يسرف القاتل فيه بأن يقتل من لا يحق قتله وقراءة لا تسرفوا يؤيده ،   { إِنَّهُ كَانَ مَنْصُورًا } استئناف أي : لا يسرف الولي لأن الله نصره ولطف عليه حيث أوجب القصاص له وأمر الناس بمعونته ،   وعلى الوجه الثاني معناه : فإن المقتول منصور لا محالة يقتل به الظالم .
