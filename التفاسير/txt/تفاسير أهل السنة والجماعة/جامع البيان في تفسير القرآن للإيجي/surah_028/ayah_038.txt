{ وَقَالَ فِرْعَوْنُ يَا أَيُّهَا الْمَلَأُ مَا عَلِمْتُ لَكُم مِّنْ إِلَهٍ غَيْرِي } أظهر عند الرعية أن وجود إله غيره غير معلوم ،   وأنه يستطيع أن يحقق ذلك ،   فلذلك أمر ببناء صرح وقال : { فَأَوْقِدْ لِي يَا هَامَانُ عَلَى الطِّينِ } أطبخ لي الأجر { فَاجْعَل لِّي صَرْحًا } بناء مشرفا عاليا { لَّعَلِّي أَطَّلِعُ إِلَى إِلَهِ مُوسَى } كأنه ظن بجهله أنه لو كان لكان جسما في السماء يمكن الصعود إليه { وَإِنِّي لَأَظُنُّهُ } أي : موسى { مِنَ الْكَاذِبِينَ } في أن لكم إلها غيري وهو رسوله
