{ تِلْكَ الدَّارُ الْآخِرَةُ } في تلك الإشارة تعظيم للآخرة أي : التي سمعت بذكرها ،   وبلغك وصفها { نَجْعَلُهَا } إما خبر تلك والدار صفته أو الدار خبره وهو استئناف { لِلَّذِينَ لَا يُرِيدُونَ عُلُوًّا فِي الْأَرْضِ } تكبرا أو استكبارا عن الإيمان { وَلَا فَسَادًا } عملا بالمعاصي أو دعوة الخلق إلى الشرك { وَالْعَاقِبَةُ } الحسنى { لِلْمُتَّقِينَ } عن معاصيه
