{ وَإِذَا سَمِعُوا اللَّغْو } القبيح من القول كشتمهم { أَعْرَضُوا عَنْهُ } تكرما { وَقَالُوا } للاغين { لَنَا أَعْمَالُنَا وَلَكُمْ أَعْمَالُكُمْ سَلَامٌ عَلَيْكُمْ } المراد سلام المتاركة والتوديع { لَا نَبْتَغِي الْجَاهِلِينَ } لا نريد صحبتهم وطريقتهم وذلك حين كان المشركون يسبون مؤمني أهل الكتاب قائلين تبا لكم تركتم دين آبائكم
