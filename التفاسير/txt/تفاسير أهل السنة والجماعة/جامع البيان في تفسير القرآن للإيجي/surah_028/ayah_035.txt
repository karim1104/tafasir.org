{ قَالَ سَنَشُدُّ عَضُدَكَ } نقويك { بِأَخِيكَ } فإن اليد تشتد بشدة العضد وجملة البدن تقوى بشدة اليد { وَنَجْعَلُ لَكُمَا سُلْطَانًا } حجة وبرهانا { فَلَا يَصِلُونَ إِلَيْكُمَا } لا سبيل لهم إلى الوصول إلى أذاكم { بِآيَاتِنَا } بسبب إبلاغكما آيات الله ،   وقيل متعلق بنجعل { أَنتُمَا وَمَنِ اتَّبَعَكُمَا الْغَالِبُونَ } وقيل : بآياتنا متعلق بالغالبون على أن يكون اللام فيه للتعريف لا بمعنى الذي
