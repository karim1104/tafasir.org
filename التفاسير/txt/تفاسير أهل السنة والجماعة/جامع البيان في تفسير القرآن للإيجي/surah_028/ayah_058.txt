ثم بين أنهم أحقاء بأن يخافوا بأس الله لا العرب ،   فقال : { وَكَمْ أَهْلَكْنَا مِن قَرْيَةٍ } أي : من أهلها { بَطِرَتْ } طغت وأشرت تلك القرية { مَعِيشَتَهَا } أي : في معيشتها منصوب بنزع الخافض أو مفعول بطرت بتضمين كفرت يقال : بطر فلان نعمة الله أي : استخفها وكفرها { فَتِلْكَ مَسَاكِنُهُمْ } خاوية { لَمْ تُسْكَن } من السكنى { مِّن بَعْدِهِمْ إِلَّا قَلِيلًا } أي : إلا سكنى قليلا إذ لا يسكنها إلا المسافر حين العبور { وَكُنَّا نَحْنُ الْوَارِثِينَ } إذ لم يبق أحد منهم يرثهم
