{ فَلَمَّا قَضَى مُوسَى الْأَجَلَ } في الحديث قضى أطولهما { وَسَارَ بِأَهْلِه } بامرأته بنته الصغرى وقيل الكبرى { آنَسَ } أبصر { مِن جَانِبِ الطُّورِ نَارًا } وكان في البرية في ليلة مظلمة شديدة البرد { قَالَ لِأَهْلِهِ امْكُثُوا } لعل معها غيرها أو عظمها لأنها ابنة نبي { إِنِّي آنَسْتُ نَارًا لَّعَلِّي آتِيكُم مِّنْهَا بِخَبَرٍ } من الطريق فإنه أخطأ الطريق { أَوْ جَذْوَةٍ } عود غليظ { مِنَ النَّارِ لَعَلَّكُمْ تَصْطَلُونَ } تستدفئون بها من البرد
