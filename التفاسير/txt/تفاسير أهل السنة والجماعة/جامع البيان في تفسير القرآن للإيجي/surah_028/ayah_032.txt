{ اسْلُكْ } أدخل { يَدَكَ فِي جَيْبِكَ تَخْرُجْ بَيْضَاء } كأنها قطعة قمر { مِنْ غَيْرِ سُوءٍ } كبرص { وَاضْمُمْ إِلَيْكَ جَنَاحَكَ مِنَ الرَّهْبِ } أمر أن يضم إليه يده إذا خاف من شيء ،   وعن ابن عباس وغيره إذا خاف أحد ووضع يده على فؤاده يخفّ ويزول خوفه فمن الرهب أي : من أجله أو معناه تجلد ولا ترتعد من الخوف ،   والطائر ينشر جناحيه حين خوفه ويضم حين اطمئنانه { فَذَانِكَ } العصا واليد { بُرْهَانَانِ مِن رَّبِّكَ } معجزتان { إِلَى فِرْعَوْنَ } أي : مرسلا بهما إليه { وَمَلَئهِ إِنَّهُمْ كَانُوا قَوْمًا فَاسِقِينَ }
