{ وَلَمَّا وَرَدَ مَاء مَدْيَنَ } وصل إلى بئر لهم { وَجَدَ عَلَيْهِ أُمَّةً } جماعة { مِّنَ النَّاسِ يَسْقُونَ } مواشيهم { وَوَجَدَ مِن دُونِهِمُ } في مكان أسفل من مكانهم { امْرَأتَيْنِ تَذُودَانِ } تمنعان غنمهما عن الماء انتظارا لخلو شفير البئر { قَالَ } موسى : { مَا خَطْبُكُمَا } ما شأنكما تذودان ؟ { قَالَتَا لَا نَسْقِي حَتَّى يُصْدِرَ } يصرف { الرِّعَاء } مواشيهم { وَأَبُونَا شَيْخٌ كَبِيرٌ } لا يستطيع الخروج للسقي ،   ونحن ضعفاء لا نقدر على مزاحمة الرجال
