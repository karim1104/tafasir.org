{ قَالَ } موسى : { ذَلِكَ } الذي عاهدتني فيه { بَيْنِي وَبَيْنَكَ } قائم لا نخرج عما شرطنا { أَيَّمَا الْأَجَلَيْنِ } الأقصر والأطول { قَضَيْتُ } ما زائدة { فَلَا عُدْوَانَ عَلَيَّ } لا يعتدي علي في طلب الزيادة عليه ،   ولي الخيار مطلقا { وَاللَّهُ عَلَى مَا نَقُولُ } من المشارطة ،   { وَكِيلٌ } شاهد .
