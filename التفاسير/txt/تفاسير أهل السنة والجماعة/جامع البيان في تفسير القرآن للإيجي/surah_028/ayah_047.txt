{ وَلَوْلَا } هي امتناعية { أَن تُصِيبَهُم مُّصِيبَةٌ بِمَا قَدَّمَتْ أَيْدِيهِمْ فَيَقُولُوا } الفاء للعطف على تصيبهم { رَبَّنَا لَوْلَا } هلا { أَرْسَلْتَ إِلَيْنَا رَسُولًا فَنَتَّبِعَ } الفاء جواب لولا الثانية { آيَاتِكَ وَنَكُونَ مِنَ الْمُؤْمِنِينَ } وجواب لولا الأولى محذوف ،   أي : لما أرسلناك وحاصل الآية لولا قولهم ربنا هلا أرسلت رسولا نؤمن به ويعلمنا الدين ،   إذا عاقبناهم بسبب ما كسبت أيديهم من المعاصي لما أرسلناك فإرسالك لئلا يكون لهم حجة علينا إن عذبناهم يعني هم مستحقون للعقاب لكن تأخيره وإرسالك لقطع الحجة
