{ فَجَاءتْهُ إِحْدَاهُمَا تَمْشِي عَلَى اسْتِحْيَاء } مستحيية متسترة بكم درعها { قَالَتْ إِنَّ أَبِي يَدْعُوكَ } فإنهما لما رجعتا سأل أبوهما عن سرعتهما اليوم في السقي فقصتا ،   فبعث إحداهما لتدعوه { لِيَجْزِيَكَ أَجْرَ مَا سَقَيْتَ لَنَا } جزاء سقيك { فَلَمَّا جَاءهُ } موسى { وَقَصَّ عَلَيْهِ الْقَصَصَ } أخبره بأمر الذي أخرجه من أرضه { قَالَ لَا تَخَفْ نَجَوْتَ مِنَ الْقَوْمِ الظَّالِمِينَ } فرعون وقومه
