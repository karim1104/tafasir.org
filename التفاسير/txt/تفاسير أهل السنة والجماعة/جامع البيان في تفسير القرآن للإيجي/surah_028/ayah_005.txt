{ وَنُرِيدُ } حكاية حال ماضية { أَن نَّمُنَّ } نتفضل { عَلَى الَّذِينَ اسْتُضْعِفُوا فِي الْأَرْضِ } بإنقاذهم من بأسه ،   والجملة عطف على { إن فرعون } أو حال من مفعول يستضعف { وأن نمن } مستقبل وإرادة الله إذا تعلقت بشيء في زمان مترقب وجب أن لا يتوقف عن ذلك الزمان { وَنَجْعَلَهُمْ أَئِمَّةً } قادة في الخير أو ملوكا { وَنَجْعَلَهُمُ الْوَارِثِينَ } : لما كان في تحت يد فرعون وقومه ،
