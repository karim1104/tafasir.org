{ فَسَقَى } مواشيهما { لَهُمَا } رحمة عليهما عن عمر : ( لما فرغ الناس جعلوا صخرة لا يستطيع رفعها إلا عشرة على رأس البئر فرفع موسى الحجر وحده ثم لم يستق إلا ذنوبا واحدا ودعا بالبركة وروى غنمهما { ثُمَّ تَوَلَّى إِلَى الظِّلِّ } ظل شجرة { فَقَالَ رَبِّ إِنِّي لِمَا أَنزَلْتَ إِلَيَّ مِنْ خَيْرٍ } طعام { فَقِيرٌ } محتاج سأل ربه أن يرزقه شيئا ليأكل فإنه من الجوع في غاية ( وما ) موصوفة وتنكير خير للشيوع أي : قليل أو كثير ،   وتعدية فقير باللام لأنه ضمن معنى طالب وسائل
