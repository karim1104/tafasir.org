{ فَلَمَّا أَتَاهَا نُودِي مِن شَاطِئِ } جانب { الْوَادِي الْأَيْمَنِ } عن يمين موسى { فِي الْبُقْعَةِ الْمُبَارَكَةِ } متصل بالشاطئ ،   أو صلة لنودي { مِنَ الشَّجَرَةِ } بدل اشتمال من شاطئ فإنها نابتة على الشاطئ { أَن يَا مُوسَى } أن مفسرة { إِنِّي أَنَا اللَّهُ رَبُّ الْعَالَمِينَ } أي : الذي يكلمك رب العالمين
