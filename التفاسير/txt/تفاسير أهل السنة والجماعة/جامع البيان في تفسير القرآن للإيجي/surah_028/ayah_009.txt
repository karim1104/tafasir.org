{ وَقَالَتِ امْرَأَتُ فِرْعَوْنَ } لفرعون حين فتحت التابوت ورأت فيه غلاما بهيا { قُرَّتُ } أي : هو قرة { عَيْنٍ لِّي وَلَكَ } فأجابها أما لك فنعم ،   وأما لي فلا فكان كذلك { لَا تَقْتُلُوهُ } فإنه جاء من أرض أخرى ،   وهو أكبر من ابن سنة { عَسَى أَن يَنفَعَنَا } فإن آثار اليمن تظهر منه { أَوْ نَتَّخِذَهُ وَلَدًا } نتبناه فليس لها ولد منه { وَهُمْ لَا يَشْعُرُونَ } من كلام الله أي : التقطوا ،   وقيل : كذا وكذا أو الحال أنهم لا يشعرون ما أراد الله منه بالتقاطهم إياه وقيل : من كلام امرأة فرعون والضمير للناس ،   أي : نتخذه ولدا والناس لا يشعرون أنه ولد غيرنا
