{ أَوَلَمْ يَرَوْا } أي : ألم يسمعوا ولم يروا ؟ ،   { أَنَّا نَسُوقُ الْمَاء إِلَى الْأَرْضِ الْجُرُزِ } : التي قطع نباتها ،   { فَنُخْرِجُ بِهِ } : بالماء ،   { زَرْعًا تَأْكُلُ مِنْهُ } : من الزرع ،   { أَنْعَامُهُمْ } من أوراقه ،   { وَأَنفُسُهُمْ } من حبوبه ،   { أَفَلَا يُبْصِرُونَ } فيستدلون على كمال القدرة ،
