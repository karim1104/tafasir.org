{ أَوَلَمْ يَهْدِ لِلَّذِينَ يَرِثُونَ الْأَرْضَ مِنْ بَعْدِ أَهْلِهَا } أي : يرثون ديار من قبلهم { أن } أي : أن الشأن { لو نشاء أصبناهم } بالبلاء { بذنوبهم } بسببها كما عذبنا من قبلهم وجملة أن لو نشاء فاعل يهد ومن قرأ بالنون فهو مفعول وفي الهداية حينئذ تضمين التبيين ولهذا عدى باللام { ونطبع } نختم { على قلوبهم } هو استئناف ولهذا غير الأسلوب أي : نحن نطبع ،   أو عطف على مدلول أو لم يهد يعني يغفلون ونطبع وليس بعطف على أصبناهم ،   لاستلزام انتفاء كونهم مطبوعين مع بطلانه لقوله : ( فهم لا يسمعون ) وقوله : ( كذلك يطبع الله على قلوب الكافرين ) وقوله : ( فما كانوا ليؤمنوا ) ؛ لدلالته على أن حالهم منافية للإيمان { فهم لا يسمعون } الموعظة أبدا سماع قبول .
