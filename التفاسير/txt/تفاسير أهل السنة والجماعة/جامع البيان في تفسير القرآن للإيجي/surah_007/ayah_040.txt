{ إِنَّ الَّذِينَ كَذَّبُوا بِآَيَاتِنَا وَاسْتَكْبَرُوا عَنْهَا } أي : عن الإيمان بها ،   { لا تُفتّح لهم } لأرواحهم { أبواب السماء } بل يهوى بها إلى السجين أو لا يصعد لهم عمل صالح ولا دعاء { ولا يدخلون الجنة حتى يلج الجمل في سمّ الخياط } أي : حتى يدخل البعير في ثقب الإبرة وذلك مما لا يكون فكذا ما توقف عليه { وكذلك } مثل ذلك الجزاء الفظيع { نجزي المجرمين } .
