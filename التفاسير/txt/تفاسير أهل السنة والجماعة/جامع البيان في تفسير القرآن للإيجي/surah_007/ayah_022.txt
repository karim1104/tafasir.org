{ فدلاهما } خدعهما { بغرور } بما غرهما به من القسم { فلما ذاقا الشجرة } وجد طعمها { بدت لهما سوءاتُهما } بأن تهافت عنهما لباسهما { وطفقا } أخذا { يخصفان } يلزقان { عليهما من ورق } أشجار { الجنة وناداهما ربهما ألم أَنْهَكُمَا عَنْ تِلْكُمَا الشَّجَرَةِ وَأَقُلْ لَكُمَا إِنَّ الشَّيْطَانَ لَكُمَا عَدُوٌّ مُبِينٌ ( 22 ) قَالَا رَبَّنَا ظَلَمْنَا أَنْفُسَنَا وَإِنْ لَمْ تَغْفِرْ لَنَا وَتَرْحَمْنَا لَنَكُونَنَّ مِنَ الْخَاسِرِينَ } الهالكين ،   والأصح أن هذه كلمات تلقاها آدم من ربه فتاب عليه .
