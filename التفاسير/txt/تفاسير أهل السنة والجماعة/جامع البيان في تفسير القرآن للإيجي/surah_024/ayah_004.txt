{ وَالَّذِينَ يَرْمُونَ } : يقذفون بالزنا ،   { الْمُحْصَنَاتِ } : المسلمات الحرائر العاقلات البالغات العفيفات عن الزنا ،   { ثُمَّ لَمْ يَأْتُوا } : على ما رموهن به ،   { بِأَرْبَعَةِ شُهَدَاء } ،   يشهدون عن الزنا ،   { فَاجْلِدُوهُمْ } ،   أي : كل واحد من الرامين ،   { ثَمَانِينَ جَلْدَةً } ،   وتخصيص النساء لخصوص الواقعة ،   ولأن قذفهن أغلب وأشنع وإلا فلا فرق فيه بين الذكر والأنثى ،   { وَلَا تَقْبَلُوا لَهُمْ شَهَادَةً أَبَدًا } : في أي واقعة كانت ،   { وَأُوْلَئِكَ هُمُ الْفَاسِقُونَ } : عند الله ،
