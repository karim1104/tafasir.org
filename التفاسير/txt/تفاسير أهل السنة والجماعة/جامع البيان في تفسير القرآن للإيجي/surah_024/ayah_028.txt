{ فَإِن لَّمْ تَجِدُوا فِيهَا } : في البيوت ،   { أَحَدًا } : يأذن لكم ،   { فَلَا تَدْخُلُوهَا حَتَّى يُؤْذَنَ لَكُمْ } ،   يعني : حتى يأتي من يأذن لكم أو لا تدخلوها إلا بإذن مالكها ،   { وَإِن قِيلَ لَكُمُ ارْجِعُوا فَارْجِعُوا } : ولا تلحوا ،   { هُوَ } : الرجوع ،   { أَزْكَى } : أطهر وأصلح ،   { لَكُمْ وَاللَّهُ بِمَا تَعْمَلُونَ عَلِيمٌ } : فيجازيكم به .
