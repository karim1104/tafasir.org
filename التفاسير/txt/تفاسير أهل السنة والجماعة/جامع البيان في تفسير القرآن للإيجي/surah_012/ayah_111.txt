{ لقد كَانَ فِي قَصَصِهِمْ } : قصص المرسلين مع قومهم أو قصص يوسف وإخوته ،   { عِبْرَةٌ } : عظة ،   { لِّأُوْلِي الأَلْبَابِ مَا كَانَ } : القرآن ،   { حَدِيثًا يُفْتَرَى } : يخلق ،   { وَلَكِن } كان ،   { تَصْدِيقَ الَّذِي بَيْنَ يَدَيْهِ } : من الكتب السماوية ،   { وَتَفْصِيلَ كُلَّ شَيْءٍ } : يحتاج إليه العباد من أمر الدين ،   { وَهُدًى } : من الضلال ،   { وَرَحْمَةً } : ينال بها خير الدارين { لِّقَوْمٍ يُؤْمِنُونَ } : يصدقونه .

اللهم اجعلنا منهم .

* في الأصل ( خزف ) ص332 .
