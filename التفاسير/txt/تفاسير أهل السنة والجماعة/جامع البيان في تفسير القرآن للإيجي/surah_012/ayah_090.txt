{ قَالُواْ أَإِنَّكَ } : استفهام تقرير ،   { لَأَنتَ يُوسُفُ } : وضع التاج وكان فوق جبهته مثل شامة بيضاء وكانت لسارة ويعقوب مثلها فعرفوه أو هو من وراء ستر فرفع الحجاب فعرفوه ،   { قَالَ أَنَاْ يُوسُفُ وَهَذَا أَخِي } : من الأبوين ذكره لتعريف نفسه ولإدخاله في قوله : { قَدْ مَنَّ اللّهُ عَلَيْنَا } : بالوصال ،   { إِنَّهُ مَن يَتَّقِ } : الله ،   { وَيِصْبِرْ } : على المصائب ،   { فإن اللّهَ لاَ يُضِيعُ أَجْرَ الْمُحْسِنِينَ } أي : أجره ولإحسانه بالجمع بين الصبر والتقوى .
