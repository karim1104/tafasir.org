{ وَمَا أَرْسَلْنَا مِن قَبْلِكَ } : يا محمد ،   { إِلاَّ رِجَالاً } : لا نساء ولا ملائكة ،   { نُّوحِي إِلَيْهِم } : كما أوحينا إليك ،   { مِّنْ أَهْلِ الْقُرَى } : فإن أهلها أعقل من أهل البادية ،   { أَفَلَمْ يَسِيرُواْ فِي الأَرْضِ فَيَنظُرُواْ كَيْفَ كَانَ عَاقِبَةُ الَّذِينَ مِن قَبْلِهِمْ } : من الأمم المكذبة فيعتبروا ،   { وَلَدَارُ } : الحياة ،   { الآخِرَةِ خَيْرٌ لِّلَّذِينَ اتَّقَواْ } : الشرك ،   { أَفَلاَ تَعْقِلُونَ } : يستعملون  عقولهم فيؤمنوا .
