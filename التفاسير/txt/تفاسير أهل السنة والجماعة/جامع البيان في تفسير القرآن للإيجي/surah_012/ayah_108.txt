{ قُلْ هَذِهِ } أي : الدعوة إلى التوحيد ،   { سَبِيلِي } : طريقتي ،   { أَدْعُو إِلَى اللّهِ } : بينان وتفسير للسبيل ،   { عَلَى بَصِيرَةٍ } : معرفة وحجة ،   { أَنَاْ } : تأكيد لضمير أدعوا ،   { وَمَنِ اتَّبَعَنِي } أي : من آمن بي أيضا يدعوا إلى الله تعالى ،   قال بعضهم : تم الكلام عند قوله :  " إلى الله "  و " على بصيرة "  خبر أنا وما عطف عليه ،   { وَسُبْحَانَ اللّهِ } أي : قل أنزهه تنزيها عن الشريك ،   { وَمَا أَنَاْ مِنَ الْمُشْرِكِينَ } .
