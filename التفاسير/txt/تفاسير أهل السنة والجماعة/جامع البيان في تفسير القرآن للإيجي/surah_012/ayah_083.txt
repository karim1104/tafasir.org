{ قَالَ } أي : لما رجعوا وقالوا ليعقوب ما قالوا قال : { بَلْ سَوَّلَتْ } : زينب وسهلت ،   { لَكُمْ أَنفُسُكُمْ أَمْرًا } : عظيما قررتموه ،   { فَصَبْرٌ جَمِيلٌ } : أجمل ،   { عَسَى اللّهُ أَن يَأْتِيَنِي بِهِمْ } : بيوسف وأخيه وأخيهما الذي توقف بمصر ،   { جَمِيعًا } : مجتمعين ،   { إِنَّهُ هُوَ الْعَلِيمُ } : بحالي ،   { الْحَكِيمُ } : في أفعاله .
