{ وَدَخَلَ مَعَهُ السِّجْنَ فَتَيَانَ } : أحدهما ساقي الملك والآخر خبازه آتهما بأنهما يردان إهلاك الملك بالسم ،   { قَالَ أَحَدُهُمَا } أي : الشرابي ،   { إِنِّي أَرَانِي } : في المنام ،   { أَعْصِرُ خَمْرًا } أي : عنبا سماه باسم ما يئول إليه ،   { وَقَالَ الآخَرُ } أي : الخباز ،   { إِنِّي أَرَانِي أَحْمِلُ فَوْقَ رَأْسِي خُبْزًا تَأْكُلُ الطَّيْرُ مِنْهُ نَبِّئْنَا } : أخبرنا { بِتَأْوِيلِهِ } : بتعبير ما قصصنا قال بعضهم : إنهما اخترعا تلك الرؤيا لاختبار يوسف ،   { إِنَّا نَرَاكَ مِنَ الْمُحْسِنِينَ } : في أعمالك وأقوالك أو من الذين يحسنون تعبير الرؤيا .
