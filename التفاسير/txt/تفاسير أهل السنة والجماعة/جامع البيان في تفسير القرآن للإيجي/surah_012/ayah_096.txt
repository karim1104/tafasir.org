{ فَلَمَّا أَن جَاء الْبَشِيرُ } أي : البريد قال البصريون : تقديره لما ظهر مجيء البشير فأضمر الرافعَ قال بعضهم : البشير يهوذا الذي جاء بقميصه ملطخا بدم كذب ،   { ألْقَاهُ عَلَى وَجْهِهِ فَارْتَدَّ } : عاد ،   { بَصِيرًا قَالَ أَلَمْ أَقُل لَّكُمْ إِنِّي أَعْلَمُ مِنَ اللّهِ } : بتعليمه ،   { مَا لاَ تَعْلَمُونَ } .
