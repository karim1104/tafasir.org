{ وَقَالَ } : يوسف ،   { لِلَّذِي ظَنَّ } : علم يوسف ،   { أَنَّهُ نَاجٍ مِّنْهُمَا } : أو الظان الشرابي ،   { اذْكُرْنِي } : أذكر حالي ،   { عِندَ رَبِّكَ } : أي الملك كي يخلصني { فأنسَاهُ } أي : الشرابي ،   { الشَّيْطَانُ ذِكْرَ رَبِّه } أي : ذكره لربه أو معناه أنسى الشيطان يوسف ذكر ربه فاستعان بغير الله تعالى ،   { فَلَبِثَ فِي السِّجْنِ بِضْعَ سِنِينَ } هو ما بين الثلاث إلى التسع وأكثرهم على أنه سبع سنين .
