{ فَبَدَأَ } : المؤذن أو يوسف بعد ما ردوا إليه ،   { بِأَوْعِيَتِهِمْ } فتشها أولا ،   { قَبْلَ وِعَاء أَخِيهِ } :من أبويه ،   { ثُمَّ اسْتَخْرَجَهَا مِن وِعَاء أَخِيهِ كَذَلِكَ } : مثل ذلك الكيد ،   { كِدْنَا لِيُوسُفَ } : بأن علمناه إياه ،   { مَا كَانَ لِيَأْخُذَ أَخَاهُ فِي دِينِ الْمَلِكِ } فإن دين ملك مصر الضرب والتغريم في السارق دون الاسترقاق ،   { إِلاَّ أَن يَشَاء اللّهُ } ،   أي : لم يتيسر له أخذه في دين الملك بحال من الأحوال إلا في حال مشيئة الله تعالى بأن أجرى على ألسنة إخوته أن السارق الاسترقاق فوجد السبيل إلى ذلك وجاز أن يكون منقطعا ،   { نرْفَعُ دَرَجَاتٍ مِّن نَّشَاء } : بالعلم كما رفعنا درجة يوسف { وَفَوْقَ كُلِّ ذِي عِلْمٍ عَلِيمٌ } : حتى ينتهي العلم إلى الله تعالى .
