{ وَرَفَعَ أَبَوَيْهِ عَلَى الْعَرْشِ } : السرير ،   { وَخَرُّواْ لَهُ سُجَّدًا } : أبواه وإخوته وكان سجود التعظيم شائعا من لدن آدم إلى شريعة عيسى عليه السلام فحرم في هذه الملة الغراء وجعل السجود مختصا بجناب الرب تعالى شأنه قال بعضهم : المراد من السجود الانحناء ،   وعن بعضهم معناه : خروا لله تعالى سجدا شكرا له والأول أصح ،   { وَقَالَ يَا أَبَتِ هَذَا تَأْوِيلُ رُؤْيَايَ مِن قَبْلُ } : الشمس والقمر أبواي وأحد عشر كوكبا إخوتي ،   { قَدْ جَعَلَهَا رَبِّي حَقًّا } : صدقا وكان بين رؤياه وتأويله أربعون سنة أو ثمانون سنة أو خمس وثلاثون سنة أو ثماني عشرة سنة والله تعالى أعلم ،   { وَقَدْ أَحْسَنَ بَي إِذْ أَخْرَجَنِي مِنَ السِّجْنِ } : ولم يذكر الجب لأنه وعد مع إخوته لا تثريب عليكم بعد هذا ،   وأيضا عد لهم نعما غير معلومة لهم وإخراجه من الجب معلوم لإخوته ،   { وَجَاء بِكُم مِّنَ الْبَدْوِ } : البادية فإنهم كانوا أهل بادية ومواشي ،   { مِن بَعْدِ أَن نَّزغَ } : أفسد ،   { الشَّيْطَانُ بَيْنِي وَبَيْنَ إِخْوَتِي إِنَّ رَبِّي لَطِيفٌ } : تدبيره ،   { لِّمَا يَشَاء إِنَّهُ هُوَ الْعَلِيمُ } : بالأمور ،   { الْحَكِيمُ } : الذي لا يفعل إلا على وفق الحكمة .
