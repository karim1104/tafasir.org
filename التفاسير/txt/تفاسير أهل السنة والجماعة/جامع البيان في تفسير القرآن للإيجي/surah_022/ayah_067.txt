{ لِكُلِّ أُمَّةٍ جَعَلْنَا مَنسَكًا } أي : لكل أمة نبي جعلنا شريعة ،   { هُمْ نَاسِكُوهُ } : عاملوه ،   { فَلا يُنَازِعُنَّكَ } : سائر أرباب الملل ،   { فِي الأَمْرِ } : في أمر الدين أو المراد نهيه –عليه السلام- عن منازعتهم ،   أي : لا يلتفت إلى منازعتهم ولا تمكنهم من المنازعة ،   أو معناه : لكل قوم جعلنا وقدرنا طريقة هم فاعلوها البتة بحكم القدر فلا تتأثر منازعتهم فيك ولا يصرفنك عما أنت عليه من الحق ونحو { ولكل وجهة هو موليها } [ البقرة : 148 ] ،   قيل : نزلت فيمن جادل وقال : ما لكم تأكلون ما تقتلونه ولا تأكلون ما قتله الله ؟ ! { وَادْعُ إِلَى رَبِّكَ إِنَّكَ } : إلى عبادته ،   { إنَّكَ لَعَلَى هُدًى مُّسْتَقِيمٍ } : طريق موصل إلى المقصود ،
