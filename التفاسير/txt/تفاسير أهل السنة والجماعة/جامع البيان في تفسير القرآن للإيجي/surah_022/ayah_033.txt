{ لَكُمْ فِيهَا } : في الشعائر وهي البدن ،   { مَنَافِعُ } : درها وصوفها وظهرها ،   { إِلَى أَجَلٍ مُّسَمًّى } : وقت النحر وإن سماها وجعلها هدايا أو الأجل المسمى تسمينها وجعلها هديا فما لم تسم بدنا ينتفع به ،   { ثُمَّ مَحِلُّهَا } : منحرها ،   { إِلَى الْبَيْتِ الْعَتِيق } ،   أي عنده يعني الحرم مطلقا .
