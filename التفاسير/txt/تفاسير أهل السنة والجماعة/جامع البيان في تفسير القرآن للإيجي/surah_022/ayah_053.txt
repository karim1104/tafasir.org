{ لِيَجْعَلَ } ،   أي : مكنا الشيطان منه ليجعل ،   { مَا يُلْقِي الشَّيْطَانُ فِتْنَةً } : ضلالة ،   { لِّلَّذِينَ فِي قُلُوبِهِم مَّرَضٌ } : شك ونفاق ،   { وَالْقَاسِيَةِ قُلُوبُهُمْ } : المشركين فإنهم لما سمعوا نسخ قول الشيطان ازدادوا غيظا وظنوا أنه ندم مما ألقى من عند نفسه ،   { وَإِنَّ الظَّالِمِينَ } : المنافقين والمشركين ،   { لَفِي شِقَاقٍ } : خلاف وعناد ،   { بَعِيدٍ } : عن الحق شديد ،
