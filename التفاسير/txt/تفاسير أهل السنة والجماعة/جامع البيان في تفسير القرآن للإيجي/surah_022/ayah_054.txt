{ وَلِيَعْلَمَ } ،   عطف على ليجعل ،   { الَّذِينَ أُوتُوا الْعِلْمَ } : القرآن وهم المسلمون ،   { أَنَّهُ } : ما أوحينا إليك ،   { الْحَقُّ } : الصدق ،   { مِن رَّبِّكَ } ،   حال أو خبر بعد خبر ،   { فَيُؤْمِنُوا بِهِ } : بالقرآن أو بالله ،   فإن العقلاء لما رأوا أنه أعرض عما تكلم به ،   ولم يعبأ ببيان خطأه ولم يبال بمزيد عداوتهم مع كثرة حرصه بألفتهم ،   عملوا أن الشيطان دخل في أمنيته فنسخه الله ،   وعصم نبيه ،   فزادوا يقينهم وثبتوا* دينهم ،   { فَتُخْبِتَ } : تخشع ،   { لَهُ } : لله ،   { قُلُوبُهُمْ } : واطمأن ،   { وَإِنَّ اللَّهَ لَهَادِ الَّذِينَ آمَنُوا إِلَى صِرَاطٍ مُّسْتَقِيمٍ } : في الدارين ،
