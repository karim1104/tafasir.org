{ وَلَنَبْلُوَنَّكُمْ } : ولنصيبنكم إصابة من يختبركم ،   { بِشَيْءٍ } ،   أي : قليل ،   { مِّنَ الْخَوفْ وَالْجُوعِ } ،   أي : القحط ،   { وَنَقْصٍ مِّنَ الأَمَوَالِ } : خسران الأموال ،   { وَالأنفُسِ } : الموت أو هو المرض والشيب ،   { وَالثَّمَرَاتِ } : الحوائج ،   وحكى عن الشافعي رضي الله عنه : الخوف ،   خوف الله والجوع رمضان ،   ونقص الأموال الزكوات والصدقات ،   والأنفس الأمراض ،   والثمرات موت الأولاد ،   { وَبَشِّرِ } : يا محمد ،   { الصَّابِرِينَ }
