{ وَإِذْ قَالَ مُوسَى لِقَوْمِهِ } : العابدين للعجل ،   { يَا قَوْمِ إِنَّكُمْ ظَلَمْتُمْ أَنفُسَكُمْ بِاتِّخَاذِكُمُ الْعِجْلَ } : معبوداً ،   { فَتُوبُواْ إِلَى بَارِئِكُمْ } : خالقكم ،   قالوا كيف نتوب ؟ قال : { فَاقْتُلُواْ أَنفُسَكُمْ } أي : كل منكم من لقي فأصابتهم سحابة سوداء لا ينظر بعضهم بعضاً ففعلوا فغفر الله للقاتل والمقتول والقتلى سبعون ألفاً أو ليقتل البريء المجرم ،   { ذَلِكُمْ } ،   أي القتل ،   { خَيْرٌ لَّكُمْ عِندَ بَارِئِكُمْ } ،   من حيث إنه وصلة إلى الحياة الأبدية ،   { فَتَابَ عَلَيْكُمْ } ،   أي : ففعلتم فتاب عليكم ،   { إِنَّهُ هُوَ التَّوَّابُ } : الذي يكثر قبول التوبة ،   { الرَّحِيمُ } : المبالغ في الرحمة .
