{ الشَّيْطَانُ يَعِدُكُمُ الْفَقْرَ } : يخوفكم الفقر لتبخلوا ولا تنفقوا في مرضات الله ،   { وَيَأْمُرُكُم بِالْفَحْشَاء } : بالبخل ،   أو المعاصي مطلقاً ،   { وَاللّهُ يَعِدُكُم مَّغْفِرَةً مِّنْهُ } ،   الوعد للخير والشر ،   أي : يعدكم  جزاء إنفاقكم مغفرة ذنوبكم ،   { وَفَضْلاً } ،   خلفاً  أفضل مما أنفقتم { وَاللّهُ وَاسِعٌ } : واسع الفضل { عَلِيمٌ } : بالإنفاق .
