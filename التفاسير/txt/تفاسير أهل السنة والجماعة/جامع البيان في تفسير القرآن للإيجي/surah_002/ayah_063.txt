{ وَإِذْ أَخَذْنَا مِيثَاقَكُمْ } : باتباع أحكام التوراة ذكرهم ما أخذ عليهم من العهود ،   { وَرَفَعْنَا فَوْقَكُمُ الطُّورَ } ،   لما نزل التوراة أبوا قبولها لما فيها من التكاليف فأمر جبريل بقلع جبل الطور فظلله فوقهم حتى  كان قبل الأمر بالقتال/12 ] قبلوا ،   { خُذُواْ } أي : قلنا له خذوا ،   { مَا آتَيْنَاكُم } : من الكتاب واعملوا به ،   { بِقُوَّةٍ } : بجد وطاعة ،   { وَاذْكُرُواْ مَا فِيهِ } : اقرءوا ولا تنسوه ،   { لَعَلَّكُمْ تَتَّقُونَ } : لكي تتقوا عن المعاصي .
