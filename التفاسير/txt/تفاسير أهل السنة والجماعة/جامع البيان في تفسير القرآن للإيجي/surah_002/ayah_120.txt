{ وَلَن تَرْضَى عَنكَ الْيَهُودُ وَلاَ النَّصَارَى } ،   كانوا يرجحون أن يرجع محمد عليه الصلاة والسلام إلى دينهم حين كان يصلي إلى قبلتهم ،   فلما صرفت القبلة أيسوا منه فأنزل الله ،   { حَتَّى تَتَّبِعَ مِلَّتَهُمْ } : دينهم وقبلتهم ،   { قُلْ } : يا محمد ،   { إِنَّ هُدَى اللّهِ } : الذي بعثني به ،   { هُوَ الْهُدَى } : طريق الحق ،   { وَلَئِنِ اتَّبَعْتَ أَهْوَاءهُم } : آراءهم الباطلة ،   { بَعْدَ الَّذِي جَاءكَ مِنَ الْعِلْمِ } : القرآن والسنة ،   { مَا لَكَ مِنَ اللّهِ مِن وَلِيٍّ وَلاَ نَصِيرٍ  } : يدفع عنك العقاب وهو تهديد شديد للأمة .
