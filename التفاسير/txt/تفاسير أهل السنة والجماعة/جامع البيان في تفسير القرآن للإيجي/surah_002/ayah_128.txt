{ رَبَّنَا وَاجْعَلْنَا مُسْلِمَيْنِ لَكَ } : مخلصين منقادين ،   { وَمِن ذُرِّيَّتِنَا } ،   أي : اجعل بعض أولادنا ،   { أُمَّةً } : جماعة ،   { مُّسْلِمَةً لَّكَ } : خاضعة مخلصة والأصح أنها تعم  العرب وغيرهم ،   { وَأَرِنَا } : أبصرنا ،   { مَنَاسِكَنَا } : معالم حجنا أو مذابحنا ،   { وَتُبْ عَلَيْنَا } : مما فرط عنا ،   { إِنَّكَ أَنتَ التَّوَّابُ الرَّحِيمُ  } : للتائب .
