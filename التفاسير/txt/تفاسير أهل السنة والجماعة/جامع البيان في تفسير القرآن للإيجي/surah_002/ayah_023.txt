{ وَإِن كُنتُمْ فِي رَيْبٍ } شك { مِّمَّا نَزَّلْنَا } : أي : القرآن ،   { عَلَى عَبْدِنَا } : محمد عليه الصلاة والسلام { فَأْتُواْ بِسُورَةٍ } : طائفة من القرآن معبر عنها بسورة كذا { مِّن مِّثْلِهِ } : مثل القرآن في البلاغة والإخبار عن الغيب ،   { وَادْعُواْ شُهَدَاءكُم } : واستعينوا بأعوانكم أو آلهتكم ،   { مِّن دُونِ اللّهِ } : أي : ادعوا من شئتم غير الله ،   وقيل : ادعوا من دون الله شهداء يشهدون لكم بأن ما أتيتم مثله ولا تستشهدوا بالله فإنه علامة العجز ،   { إِنْ كُنْتُمْ صَادِقِينَ } : إنه من كلام البشر .
