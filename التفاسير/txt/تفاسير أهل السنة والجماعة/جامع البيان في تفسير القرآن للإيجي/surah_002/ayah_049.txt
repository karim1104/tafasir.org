{ وَإِذْ نَجَّيْنَاكُم } : عطف على نعمتي وتفصيل لها { مِّنْ آلِ فِرْعَوْنَ } : أتباعه { يَسُومُونَكُمْ } : يبغونكم ،   والجملة حال ،   { سُوَءَ الْعَذَابِ } : أفظعه وأشده نصب على مفعول يسومونكم { يُذَبِّحُونَ } : يقتلون بيان ليسومونكم  { أَبْنَاءكُمْ وَيَسْتَحْيُونَ } يتركون أحياء للخدمة { نِسَاءكُمْ وَفِي ذَلِكُم } صنيعهم ،   { بَلاءٌ } : محنة { مِّن رَّبِّكُمْ عَظِيمٌ } : أو  الإشارة إلى الاتجاه فالبلاء بمعنى النعمة وهو قول كثير من السلف  .
