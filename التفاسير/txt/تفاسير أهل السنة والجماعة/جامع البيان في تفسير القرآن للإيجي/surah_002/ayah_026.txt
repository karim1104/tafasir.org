{ إِنَّ  اللَّهَ لاَ يَسْتَحْيِي } : لا يستنكف  من { أَن يَضْرِبَ مَثَلاً } : أن يبيّن شبها { مَّا } أي : أي مثل { بَعُوضَةً } : صغار البق عطف بيان لمثلاً { فَمَا فَوْقَهَا } في الصغر والحقارة كجناحها  أو في الكبر كالذباب ،   { فَأَمَّا الَّذِينَ آمَنُواْ فَيَعْلَمُونَ أَنَّهُ } المثل { الْحَقُّ } : الثابت الذي لا يسوغ إنكاره { مِن رَّبِّهِمْ وَأَمَّا الَّذِينَ كَفَرُواْ فَيَقُولُونَ مَاذَا } : أي شيء { أَرَادَ اللَّهُ بِهَذَا مَثَلاً } : نصب على التمييز أو الحال ،   { يُضِلُّ بِهِ } : بالمثل { كَثِيراً } : من الكفار ،   أي : إضلال كثير وضع الفعل موضع المصدر جواب  ماذا ،   { وَيَهْدِي بِهِ كَثِيراً } : من المؤمنين ،   { وَمَا يُضِلُّ بِهِ إِلاَّ الْفَاسِقِينَ } : الخارجين عن حد الإيمان .
