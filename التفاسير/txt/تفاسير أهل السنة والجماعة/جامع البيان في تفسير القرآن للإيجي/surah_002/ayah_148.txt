{ وَلِكُلٍّ } : من أهل الأديان ،   { وِجْهَةٌ } : قبلة ،   { هُوَ مُوَلِّيهَا } : وجهه ،   ووجهة الله حيت توجه المؤمنون ،   أو الله مولى الأمم إلى قبلتهم ،   { فَاسْتَبِقُواْ } : بادروا ،   { الْخَيْرَاتِ } : قبول أمر القبلة وغيره ،   { أَيْنَ مَا تَكُونُواْ } ،   أنتم وأهل الكتاب ،   { يَأْتِ بِكُمُ اللّهُ جَمِيعاً } : يحشركم إليه ويجازيكم { إِنَّ اللّهَ عَلَى كُلِّ شَيْءٍ } : من الإماتة والإحياء والجمع ،   { قَدِيرٌ }
