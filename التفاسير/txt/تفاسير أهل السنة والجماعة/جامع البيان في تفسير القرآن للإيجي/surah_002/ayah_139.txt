{ قُلْ } : يا محمد لأهل الكتاب ،   { أَتُحَآجُّونَنَا } : أتجادلوننا  ،   { فِي اللّهِ } ،   في دين الله وأمره حيث قالوا الأنبياء منا فنحن أولى بالله منكم ،   { وَهُوَ رَبُّنَا وَرَبُّكُمْ } : لا اختصاص له بقوم دون قوم ،   { وَلَنَا أَعْمَالُنَا وَلَكُمْ أَعْمَالُكُمْ } : لكلّ جزاء عمله فليس ببعيد أن يكرمنا الله تعالى ،   { وَنَحْنُ لَهُ مُخْلِصُونَ }
