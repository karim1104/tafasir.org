{ وَبَشِّرِ } البشارة خير سار يظهر أثر السرور في البشرة  { الَّذِين آمَنُواْ وَعَمِلُواْ الصَّالِحَاتِ } : عملاً بلا رياء ،   أو كل ما حسنه الشرع { أَنَّ لَهُمْ } : بأن لهم { جَنَّاتٍ } : دار الثواب وهي سبعة  { تَجْرِي مِن تَحْتِهَا } : تحت أشجارها وغرفها { الأَنْهَارُ كُلَّمَا رُزِقُواْ مِنْهَا } مبتدأ من الجنات { مِن ثَمَرَةٍ } : بيان تقدم كرأيت منك أسداً  } : ليس لهم خوف فوات نعمة .

ولما قالت الجهلة : الله أجل من أن يضرب الأمثال بالصيب والمستوقد وبيت العنكبوت والذباب فنزلت  .
