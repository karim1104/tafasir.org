{ وَمَا آتَيْتُم مِّن رِبًا } ،   أي : ما أعطيتم من أجل ربا ،   { لِّيَرْبُوَ } : ليزيد ويزكو ،   { فِي أَمْوَالِ النَّاسِ } أي : بين أموالهم ،   { فَلَا يَرْبُو } : لا يزكو ،   { عِندَ اللَّهِ } ،   ولا يثاب عليه يعني من يعطى عطية يريد أن يرد المهدى له أكثر مما أهدى فلا ثواب له لكن هذا ليس بحرام أو الآية في الربا المحرم والأول هو قول السلف ،   { وَمَا آتَيْتُم مِّن زَكَاةٍ } : صدقه ،   { تُرِيدُونَ } : به ،   { وَجْهَ اللَّهِ } أي : مخلصين ،   { فَأُوْلَئِكَ هُمُ الْمُضْعِفُونَ } أي :ذو الإضعاف من الثواب وضمير ما محذوف أي المضعفون به ،
