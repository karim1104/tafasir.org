{ وَلَئِنْ أَرْسَلْنَا رِيحًا } : مضرة ،   { فَرَأَوْهُ } الضمير لأثرها أي : النبات والزرع ،   { مُصْفَرًّا } : من الجائحة ،   { لَّظَلُّوا مِن بَعْدِهِ } من بعد اصفرار الزرع ،   { يَكْفُرُونَ } وأما المؤمنون فيفرحون بنزول الرحمة لا فرح بطر ويشكرون ويرون الجائحة من شؤم أنفسهم ويستغفرون ،   واللام موطئة للقسم ،   وقوله ( لظلوا ) جواب له ساد جزاء الشرط ،
