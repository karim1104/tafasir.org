{ ولأُضلّنهم } عن الصواب { ولأُمنينّهم } إدراك الآخرة مع المعاصي وطول الحياة ،   يأمرهم بالتسويف والتأخير أو أنه لا جنة ولا نار { ولآمُرنّهم فليُبتّكن آذان الأنعام } يشقونها ويجعلون ركوب تلك الأنعام حراما ويسمونها بحائر : ما يجيء في المائدة وهو إشارة إلى تحريم كل حلال { وَلآَمُرَنَّهُمْ فَلَيُغَيِّرُنَّ خَلْقَ اللَّهِ } هو الخصاء أو الوشم أو دين الله { ومن يتخذ الشيطان وليًّا من دون الله } فيطيعه ولا يطيع الله { فقد خسر خسرانا مبينا } إذ ضيع بالكلية ماله وباع الجنة بالدنيا .
