{ يا أيها الذين آمنوا أطيعوا الله وأطيعوا الرسول وأولي الأمر منكم } السلاطين والأمراء فيما وافقوا الحق ،   وأهل العلم والدين { فإن تنازعتم } أنتم وأولو الأمر { في شيء فرُدّوه } فراجعوا فيه { إلى الله } إلى كتابه { والرسول } في زمانه وسنته بعده { إن كنتم تؤمنون بالله واليوم الآخر ذلك } : أي : الرد { خيرٌ } لكم { وأحسن تأويلاً } مآلا وعاقبة .
