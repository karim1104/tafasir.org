{ ولكم نصف ما ترك أزواجُكم إن لم يكن لهنّ ولد فإن كان لهن ولد فلكم الربع مما تركن } وحكم أولاد البنين وإن سفلوا حكم أولاد الصلب { من بعد وصية يوصين بها أو دَين ولهنّ } أي : الزوجات { الربع مما تركتم إن لم يكن لكم ولد فإن كان لكم ولد فلهن الثّمن مما تركتم من بعد وصية توصون بها أو دَين } وسواء في الربع والثمن الواحدة والأكثر { وإن كان رجل يورَث } : منه { كلالة } لا ولد له فيورث : صفة رجل من ورث ،   وكلالة : خبر كان ،   والرجل هو الميت { أو امرأة } عطف على رجل { وله } أي : للرجل ،   ومنه يعلم حكم المرأة فاكتفي به { أخ أو أخت } من الأم بالإجماع وهو مذكور في بعض القراءة { فلكل واحد منهما السّدس فإن كانوا } الضمير لمن يرث ،   وجمعه محمول على المعنى { أكثر من ذلك } أي : من واحد { فهم شركاء في الثُّلث } ذكرا كانوا أو أنثى { من بعد وصية يوصي بها أو دَين غير مضار } لورثته بحرمان بعضهم أو زيادة أو تنقيص مما قدر من الفريضة ،   ولا يكون غرضه من الوصية الإضرار بل القربة ،   حال من فاعل يوصى ،   وفي قراءة  البناء للمفعول ما يدل عليه وهو الفاعل المتروك { وصية من الله } مصدر أو مفعول به لغير مضار { والله عليم } : بالمضار وغيره { حليم } لا يعاجل بعقوبته .
