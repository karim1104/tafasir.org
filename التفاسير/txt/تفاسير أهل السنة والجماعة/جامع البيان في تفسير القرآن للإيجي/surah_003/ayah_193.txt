{ ربنا إنا سمعنا مُناديا } أي : محمدا عليه الصلاة والسلام أو القرآن ،   { ينادي للإيمان } ،   والنداء يعدى بإلى ،   واللام لتضمنه معنى الانتهاء والاختصاص { أن آمنوا بربكم } أي : بأن آمنوا ،   { فآمنا ربنا فاغفر لنا ذُنوبنا } : كبائرنا ،   { وكفّر عنا سيئاتنا } : صغائرنا بقبول الطاعات { وتوفّنا مع الأبرار } : معدودين في زمرة الصالحين .
