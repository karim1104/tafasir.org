{ من قبلُ } من قبل تنزيل القرآن { هدىً للناس } في زمانهما { وأنزل الفرقان } الفارق بين الحق والباطل ،   وهو جنس الكتب الإلهية عم بعد ما خص ذكر الثلاثة ،   أو القرآن كرر ذكره بوصفه تعظيما له { إنّ الذين كفروا بآيات الله لهم عذاب شديد } يوم القيامة { والله عزيز } غالب لا يغلب { ذو انتقام } عقوبة من خالف الرسل .
