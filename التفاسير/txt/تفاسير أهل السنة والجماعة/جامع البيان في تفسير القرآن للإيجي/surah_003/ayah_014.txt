{ زُيِّن للناس حب الشهوات } أي : المشتهيات سماها شهوات مبالغة .   { من النساء والبنين والقناطير } القناطر المال الكثير .   { المُقنطرة } ذكرت للتأكيد كبدرة مبدرة أو القنطار ألفا أوقية أو ألف دينار أو ألف ومائتا دينار ،   وقيل غيرها .   { من الذهب والفضة والخيل } : عطف على النساء .   { المسوّمة } : الراعية ،   والمطهمة الحسان أو الغرة والتحجيل وقيل غيرهما .   { والأنعام } الإبل ،   والبقر ،   والغنم .   { والحرث ذلك } إشارة إلى ما ذكر .   { متاع الحياة الدنيا } : وهي فانية .   { والله عنده حُسن المآب } أي : المرجع والثواب وفيه تزهيد من الدنيا .
