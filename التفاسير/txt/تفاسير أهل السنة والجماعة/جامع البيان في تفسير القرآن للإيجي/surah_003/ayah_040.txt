{ قال رب أنّى يكون لي غلام } استبعاد من حيث العادة واستعظام أو استفهام عن كيفية حدوثه ،   { وقد بلغني الكبر }

{ وامرأتي عاقر } : لا تلد .   { قال } : أي الملك ،   { كذلك الله يفعل ما يشاء } أي : يفعل ما يشاء من العجائب مثل ذلك الفعل ،   فكذلك متعلق يفعل وقيل : ( كذلك الله ) مبتدأ وخبر و( يفعل ما يشاء ) بيان أو تقديره : الأمر كذلك ،   و( الله يفعل ) بيان .
