{ فاستجاب لهم ربهم } : يعدى بنفسه وباللام { أنّي } أي : بأني ،   { لا أُضيع عمل عامل منكم من ذكر أو أنثى } : بيان عامل ،   { بعضكم من بعض } : في الدين أو كلكم من آدم أو لأن الذكر من الأنثى ،   والأنثى من الذكر قالت أم سلمة : يا رسول الله لا نسمع الله تعالى ذكر النساء في الهجرة بشيء فأنزل الله تعالى ( فاستجاب لهم ) إلخ .   { فالذين هاجروا } : تفصيل للأعمال ،   { وأُخرجوا من ديارهم وأوذوا في سبيلي وقاتلوا } : الكفار ،   { وقُتلوا } : في الجهاد ،   { لأكفّرن } : لأمحون ،   { عنهم سيئاتهم ولأدخلنهم جنات تجري من تحتها الأنهار } : تحت أشجارها ،   { ثوابا من عند الله } أي : لأثيبنهم ثوابا من عند الله العظيم ،   { والله عنده حُسن الثواب } : على الطاعات .
