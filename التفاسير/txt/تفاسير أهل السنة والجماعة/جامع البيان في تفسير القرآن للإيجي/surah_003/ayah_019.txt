{ إن الدّين عند الله الإسلام } جملة مؤكدة للأولى أي : لا دين مقبول عنده سوى الإسلام ،   وهو اتباع سيد الأنبياء عليهم الصلاة والسلام .   { وما اختلف الذين أُوتوا الكتاب } مطلقا أو اليهود في دين الإسلام بأنه حق أو باطل { إلا من بعد ما جاءهم العلم } : بحقية الإسلام .   { بغيا } : حسدا .   { بينهم ومن يكفر بآيات الله } بما أنزله في كتابه { فإن الله سريع الحساب } المجازاة .
