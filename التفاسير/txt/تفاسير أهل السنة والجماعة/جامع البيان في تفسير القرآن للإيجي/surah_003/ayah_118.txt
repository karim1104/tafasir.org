{ يا أيها الذين آمنوا لا تتّخذوا بِطانة } بطانة الرجل خاصة أهله الذي يطلعه على أسراره ،   { من دونكم } : من دون المسلمين ،   متعلق بلا تتخذوا أو صفة بطانة أي لا تتخذوا أولياء أصفياء من غير أهل ملتكم ،   { لا يألونكم خبالا } : لا يقصرون في الفساد ،   وخبالا مفعول ثان لتضمين معنى المنع ،   والجملة مستأنفة أو صفة بطانة ،   وكذا الجملتان بعده ،   { ودّوا ما عنتّم } : تمنوا شدة ضرركم ،   { قد بدت البغضاء } : ظهرت علامة العداوة ،   { من أفواههم } : فلتات كلامهم ،   { وما تُخفي صدورهم } : من البغضاء { أكبر } أكثر مما بدا ،   { قد بيّنا لكم الآيات } : الدالة على صلاح أحوالكم ،   { إن كنتم تعقلون } : ما بيّن لكم ،   نزلت في مواصلة اليهود لما بينهم من القرابة أو في مصافاة المنافقين
