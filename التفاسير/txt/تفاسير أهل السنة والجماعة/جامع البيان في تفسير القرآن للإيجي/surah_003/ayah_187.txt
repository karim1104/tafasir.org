{ وإذ أخذ الله } أي : اذكره ،   { ميثاق الذين أوتوا الكتاب } : بلسان أنبيائهم ،   { لتُبيّنُنّه للناس } : حكاية لمخاطبتهم أي : والله لتبينن الكتاب بجملته لهم ،   { ولا تكتمونه فنبذوه } أي : الميثاق ،   { وراء ظهورهم } : هو مثل في ترك الاعتداد والاعتبار ،   { واشتروا به ثمناً قليلاً } أخذوا بدله قليلا من حطام الدنيا ،   { فبئس ما يشترون } : يختارون .
