{ وَتَرَى الْجِبَالَ تَحْسَبُهَا جَامِدَةً } : ثابتة في مكانها ،   { وَهِيَ تَمُرُّ مَرَّ السَّحَابِ } في السرعة والأجرام العظام إذا تحركت لا يكاد تتبين حركتها كالسحاب ،   { صُنْعَ اللَّهِ } مصدر مؤكد لنفسه من مضمون ( يوم ينفخ ) الآية ،   { الَّذِي أَتْقَنَ } : أحكم { كُلَّ شَيْءٍ } وأودع فيه من الحكم ما أودع ،   { إِنَّهُ خَبِيرٌ بِمَا تَفْعَلُونَ } فيجازيهم عليه ،
