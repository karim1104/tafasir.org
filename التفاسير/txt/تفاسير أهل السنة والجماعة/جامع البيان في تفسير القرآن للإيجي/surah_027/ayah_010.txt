{ وَأَلْقِ عَصَاكَ } عطف على بورك ،   أي : قيل له بورك من في النار ،   وقيل له : ألق عصاك { فَلَمَّا رَآهَا } أي : فلما ألقى رآها { تَهْتَزُّ } : تتحرك { كَأَنَّهَا جَانٌّ } : حية خفيفة سريعة ،   { وَلَّى مُدْبِرًا } أي : هرب موسى ،   { وَلَمْ يُعَقِّبْ } : لم يرجع ،   { يَا مُوسَى } أي : نودي يا موسى ،   { لَا تَخَفْ إِنِّي لَا يَخَافُ لَدَيَّ الْمُرْسَلُونَ } حين يوحي إليهم من فرط الاستغراق ،   قيل معناه : من أمنته من عذابي لا يخاف من حية ،
