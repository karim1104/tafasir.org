{ أَمَّن جَعَلَ } بدل من ( أمّن خلق ) ،   { الْأَرْضَ قَرَارًا } : دحاها وسواها للاستقرار ،   { وَجَعَلَ خِلَالَهَا } : وسطها ،   { أَنْهَارًا } جارية ،   { وَجَعَلَ لَهَا رَوَاسِيَ } : جبالا ثوابت ،   { وَجَعَلَ بَيْنَ الْبَحْرَيْنِ } : العذب والمالح ،   { حَاجِزًا } : مانعا من قدرته لا يختلطان كما مر في سورة الفرقان ،   { أَإِلَهٌ مَّعَ اللَّهِ بَلْ أَكْثَرُهُمْ لَا يَعْلَمُونَ } : جهلاء ،
