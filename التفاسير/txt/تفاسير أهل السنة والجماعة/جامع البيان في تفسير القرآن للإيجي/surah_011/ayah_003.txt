{ وَأَنِ اسْتَغْفِرُواْ } عطف على أن لا تعبدوا ،   { رَبَّكُمْ } من الذنوب السالفة ،   { ثُمَّ تُوبُواْ إِلَيْهِ } فيما تستقبلونه ،   أو ثم ارجعوا إليه بالطاعة ،   { يُمَتِّعْكُم مَّتَاعًا حَسَنًا } يعيشكم في أمن وسعة ،   { إِلَى أَجَلٍ مُّسَمًّى } إلى حين موت مقدر ،   { وَيُؤْتِ كُلَّ ذِي فَضْلٍ فَضْلَهُ } عن ابن عباس يؤت كل من فضلت وزادت حسناته على سيئاته فضل الله ،   أي : الجنة أو يعط كل ذي عمل صلح جزاء عمله الصالح ،   { وَإِن تَوَلَّوْاْ } أي : تتولوا ،   { فإنيَ أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ كَبِيرٍ } يوم القيامة .
