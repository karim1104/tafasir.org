{ وَيَا قَوْمِ أَوْفُواْ الْمِكْيَالَ وَالْمِيزَانَ } أمر بالإيفاء بعد أن نهى عن ضده مبالغة ،   { بِالْقِسْطِ } بالعدل والسوية ،   { وَلاَ تَبْخَسُواْ } لا تنقصوا ،   { النَّاسَ أَشْيَاءهُمْ } تعميم بعد تخصيص وقيل : كانوا مكاسين ،   { وَلاَ تَعْثَوْاْ } لا تبالغوا ،   { فِي الأَرْضِ } بالفساد حال كونكم ،   { مُفْسِدِينَ } وقد كانوا يقطعون الطريق .
