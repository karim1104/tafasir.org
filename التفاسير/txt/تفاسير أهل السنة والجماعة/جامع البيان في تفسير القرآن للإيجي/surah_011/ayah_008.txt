{ وَلَئِنْ أَخَّرْنَا عَنْهُمُ الْعَذَابَ } الموعود ،   { إِلَى أُمَّةٍ } جماعة من الأوقات والأمة تستعمل في معان متعددة ،   { مَّعْدُودَةٍ } محصورة قليلة ،   { ليَقُولُنَّ } استهزاء ،   { مَا يَحْبِسُهُ } ويمنعه من الوقوع ،   { أَلاَ يَوْمَ يَأْتِيهِمْ } أي : اليوم المقدر لنزول العذاب ،   { لَيْسَ } العذاب ،   { مَصْرُوفًا عَنْهُمْ } ويوم ظرف مصروفا ،   { وَحَاقَ بِهِم } وأحاط بهم ذكر بلفظ الماضي تحقيقا و مبالغة ،   { مَّا كَانُواْ بِهِ يَسْتَهْزِؤُونَ } أي : العذاب .
