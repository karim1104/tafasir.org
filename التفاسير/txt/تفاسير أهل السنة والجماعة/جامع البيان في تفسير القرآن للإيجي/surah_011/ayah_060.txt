{ وَأُتْبِعُواْ فِي هَذِهِ الدُّنْيَا لَعْنَةً } قال السدي : ما بعث نبي بعد عاد إلا لعنوا على لسانه ،   { وَيَوْمَ الْقِيَامَة } أي : لعنوا في الدارين ،   { أَلا إِنَّ عَادًا كَفَرُواْ رَبَّهُمْ } أي : نعمه أو بربهم فحذف الجار ،   { أَلاَ بُعْدًا } من رحمته وهلاكا ،   { لِّعَادٍ قَوْمِ هُود } جيء بعطف البنان للتمييز عن عاد الإرم قيل : ينادي في القيامة فقوله : { ألا إن عادا } إلخ .
