{ وَمَا ظَلَمْنَاهُمْ وَلَكِن ظَلَمُواْ أَنفُسَهُمْ } فاستحقوا العذاب ،   { فَمَا أَغْنَتْ عَنْهُمْ } ما دفعت عنهم ،   { آلِهَتُهُمُ الَّتِي يَدْعُونَ مِن دُونِ اللّهِ مِن شَيْءٍ } شيئا من عذابه ،   { لِّمَّا جَاء } حين جاء ،   { أَمْرُ رَبِّكَ } عذابه ،   { وَمَا زَادُوهُمْ } أي : ما زاد الآلهة الظالمين ،   { غَيْرَ تَتْبِيبٍ } بلاء وتخسير .
