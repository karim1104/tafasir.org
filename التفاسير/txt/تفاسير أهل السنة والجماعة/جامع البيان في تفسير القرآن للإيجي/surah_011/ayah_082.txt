{ فَلَمَّا جَاء أَمْرُنَا } : بالعذاب ،   { جَعَلْنَا عَالِيَهَا سَافِلَهَا } أدخل جبريل عليه السلام جناحه تحت قريتهم فقلعها وصعد بها إلى السماء ثم قلبها وفيها أربعمائة ألف أو أربعة آلاف ألف ،   { وَأَمْطَرْنَا عَلَيْهَا } على تلك القرية قبل التقليب أو حين التقليب ،   { حِجَارَةً } أو كانت الحجارة على شدادهم ومسافريهم ،   { مِّن سِجِّيلٍ } أصله سنك كل أي : حجر وطين فارسية معربة أو الطين أو الآجر قيل اسم لسماء الدنيا أو لجبل فيها ،   { مَّنضُودٍ } متتابع أو معد في السماء لذلك .
