{ وهو القاهر فوق عباده } : تصوير لقهره وعلوه بالقدرة ،   { ويُرسل عليكم حفظة } : من الملائكة تحفظ أبدانكم كما قال تعالى : ( له معقبات من بين يديه ) ( الرعد : 11 ) .   أو تحفظ جميع أعمالكم وهم الكرام الكاتبون ،   { حتى إذا جاء أحدكم الموت } : حان أجله ،   { توفّته رسلنا } لملك الموت أعوان يخرجون الروح فيقبض ملك الموت ،   { وهم لا يُفرّطون } : فيما أمروا يفعلون ما يؤمرون .
