{ يَا مَعْشَرَ الْجِنِّ وَالْإِنْسِ أَلَمْ يَأْتِكُمْ رُسُلٌ مِنْكُمْ } هو الله سبحانه يقرع الكافرين يوم القيامة بهذا السؤال وهو استفهام تقرير ،   والأصح بل الصحيح أن الرسل من الإنس والجن تبع لهم قالوا نظيره ( يخرج منهما اللؤلؤ والمرجان ) ( الرحمن : 22 ) وهما لا  يخرجان من العذب كما سنذكر إن شاء الله تعالى ،   { يقُصّون عليكم آياتي ويُنذرونكم لقاء يومكم هذا } : يوم القيامة ،   { قالوا } : جوابا ،   { شهدنا على أنفسنا } : أنهم قد بلغوا ذلك حين شهدت عليهم جوارحهم قال تعالى : { وغرّتهم الحياة الدنيا } : فأعرضوا عن رسلنا ولم يرفعوا إليهم رأسا ،   { وشهدوا على أنفسهم } : يوم القيامة ،   { أنهم كانوا كافرين } : في الدنيا .
