{ وكذلك } : مثل ذلك الفتن العظيمة { فتنّا } ابتلينا ،   { بعضهم ببعض ليقولوا } : رؤساء قريش قالوا في شأن فقراء المسلمين وضعفائهم : { أهؤلاء منّ الله عليهم من بيننا } إنكار لأن يخصهم الله بهداية ونعمة كما قالوا : ( لو كان خيرا ما سبقونا إليه ) ( الأحقاف : 11 ) ،   واللام للعاقبة للتعليل ،   { أليس الله بأعلم بالشاكرين } ؛ هذا جواب لقولهم أي : الله أعلم بمن يشكر الإيمان وطبعه مستقيم فيهديه .
