{ وهو الذي خلق السماوات والأرض بالحق } : بالعدل والحكمة ،   { ويوم يقول كن فيكون } ،   عطف على السماوات فذكر بدء الخلق وإعادته أو على مفعول اتقوه أو بتقدير واذكر ،   والمراد يوم القيامة فإن الأمر فيه غير تدريجي ،   { قوله الحق } أي : الصدق الواقع لا محالة مبتدأ وخبر أو ( قوله ) مبتدأ و( الحق ) صفته ( ويوم يقول ) خبره أي : قضاؤه الحكمة والصواب حين يقول للشيء كن فيكون ذلك الشيء يعني ما ظهر من مكوناته شيء إلا عن حكمة وصواب ،   فلا يكون المراد من يوم القيامة ،   { وله الملك يوم يُنفخ في الصور } إما ظرف لقوله : ( له الملك ) كقوله : ( لمن الملك اليوم لله الواحد القهار ) [ غافر : 16 ] وإما بدل من ( يقول ) والصور القرن الذي ينفخ فيه إسرافيل ،   وقيل : جمع صورة أي ينفخ فيها فتحيا ،   { عالم الغيب والشهادة } أي : هو عالم الغيب ،   { وهو الحكيم الخبير } .
