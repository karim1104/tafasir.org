{ من بين أيديهم } أي : من القرى القريبة من بلادهم { ومن خلفهم } القرى البعيدة كما قال :{ وقد خلت النذر من بين يديه ومن خلفه }[ الأحقاف :21 ] ،   وقيل : من كل جانب وعملوا فيهم كل حيلة كما قاتل الشيطان : { لآتينهم من بين أيديهم ومن خلفهم }[ الأعراف :17 ] ،   وقيل :

أنذروهم من مثل الوقائع المتقدمة ومن العذاب المتأخر أي : عذاب الآخرة { ألا تعبدوا إلا الله } أن بمعنى أي { قالوا لو شاء ربنا } : إرسال الرسل ،   { لأنزل ملائكة } : برسالته فإنما أنتم لستم بملائكة { فإنا بما أرسلتم به } : على زعمكم ،   { كافرون }
