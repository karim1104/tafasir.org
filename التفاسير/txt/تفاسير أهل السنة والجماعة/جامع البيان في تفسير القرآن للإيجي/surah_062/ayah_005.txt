{ مثل الذين حملوا التوراة } علموها وكلفوا العمل بها { ثم لم يحملوها } لم يعملوا ولم ينتفعوا بها { كمثل الحمار يحمل أسفارا } كتبا كبارا أو يحمل إما حال والعامل معنى المثل ،   أو صفة ؛ لأن التعريف في الحمار للجنس { بئس مثل القوم الذين كذبوا بآيات الله } حذف المضاف من المخصوص ،   أي : مثل الذين ،   أو المخصوص محذوف أي مثل القوم الذين كذبوا بآيات الله هو والضمير إلى مثل الذين حملوا { والله لا يهدي القوم الظالمين }
