{ ضرب الله مثلا للذين كفروا امرأة نوح وامرأة لوط } أي جعل امرأة نوح وامرأة لوط مثلا لهم ،   أو مثل لهم مثلا مثل امرأة نوح في أن قرابة أحد وإن كان نبيا لا ينفع مع الكفر ،   قيل : هذا تخويف لعائشة وحفصة { كانتا تحت عبدين من عبادنا صالحين فخانتاهما } بإظهار الإيمان مع إسرار الكفر لا بالفاحشة { فلم يغنيا } النبيان { عنهما من الله شيئا } من الإغناء { وقيل } لهما يوم القيامة { ادخلا النار مع الداخلين } مع سائر الكفرة
