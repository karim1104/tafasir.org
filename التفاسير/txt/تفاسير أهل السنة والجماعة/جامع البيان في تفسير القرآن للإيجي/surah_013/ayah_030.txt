{ كَذَلِكَ } : مثل ذلك الإرسال العظيم الشأن ،   { أَرْسَلْنَاكَ فِي أُمَّةٍ قَدْ خَلَتْ } : مضت ،   { مِن قَبْلِهَا أُمَمٌ لِّتَتْلُوَ عَلَيْهِمُ الَّذِيَ أَوْحَيْنَا إِلَيْكَ } أي : القرآن ،   { وَهُمْ } الواو للحال ،   { يَكْفُرُونَ بِالرَّحْمَنِ } : بالبليغ الرحمة ،   لا يشكرونه ،   نزلت في قريش حين قيل لهم :  " اسجدوا للرحمن قالوا و ما الرحمن "  ( الفرقان : 60 ) ،   أو في أبي جهل حين قال : إن محمدا يدعوا إلهين الله وإلها آخر يسمى الرحمن ،   { قُلْ هُوَ } أي : الرحمن ،   { رَبِّي لا إِلَهَ إِلاَّ هُوَ عَلَيْهِ تَوَكَّلْتُ وَإِلَيْهِ مَتَابِ } : مرجعي .
