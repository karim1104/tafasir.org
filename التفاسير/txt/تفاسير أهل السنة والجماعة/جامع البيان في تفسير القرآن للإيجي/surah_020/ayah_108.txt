{ يَوْمَئِذٍ } : يوم إذ نسفت { يَتَّبِعُونَ الدَّاعِيَ } : حيث ما أمرهم بادروا إليه أو الداعي إلى المحشر { لَا عِوَجَ لَهُ } : لا يعوج له مدعو ولا يعدل عنه { وَخَشَعَت } : سكنت أو خفضت { الْأَصْوَاتُ لِلرَّحْمَنِ } : لمهابته ،   { فَلَا تَسْمَعُ إِلَّا هَمْسًا } : صوت وطء أقدامهم إلى المحشر أو صوتا خفيا .
