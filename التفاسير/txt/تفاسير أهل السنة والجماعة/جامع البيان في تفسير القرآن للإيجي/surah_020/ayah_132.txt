{ وَأْمُرْ أَهْلَكَ } : أهل بيتك أو أمتك { بِالصَّلَاةِ } ،   ولا تهتموا بأمر المعيشة { وَاصْطَبِرْ } : وداوم ،   { عَلَيْهَا لَا نَسْأَلُكَ رِزْقًا } : أن نرزق أحدا { نَّحْنُ نَرْزُقُكَ } ،   ففرغ بالك للصلاة وفي الحديث إذا أصابه عليه السلام خصاصة نادى أهله :  " يا أهلاه صلوا وصلوا وفي الحديث القدسي :  " يا ابن آدم تفرغ لعبادتي أملأ صدرك غنى وأسد فقرك وإن لم تفعل ملأت صدرك شغلا ولم أسد فقرك "  { وَالْعَاقِبَة } : المحمودة ،   { لِلتَّقْوَى } : لذويه قد نقل أنها نزلت لما استسلف عليه السلام من يهودي فأبى إلا برهن فضاق صدره الأشرف .
