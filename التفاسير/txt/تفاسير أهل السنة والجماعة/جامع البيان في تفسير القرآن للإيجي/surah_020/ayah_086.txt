{ فَرَجَعَ مُوسَى إِلَى قَوْمِهِ } : بعد أخذ التوراة { غَضْبَانَ } : عليهم { أَسِفًا } الأسف الشديد الغضب أو الحزين ،   { قَالَ يَا قَوْمِ أَلَمْ يَعِدْكُمْ رَبُّكُمْ وَعْدًا حَسَنًا } بأن يعطيكم التوراة ،   ووعدكم على لساني خير الدارين { أَفَطَالَ عَلَيْكُمُ الْعَهْدُ } أي : الزمان في انتظار ما وعدكم الله { أَمْ أَرَدتُّمْ أَن يَحِلَّ } يجب { عَلَيْكُمْ غَضَبٌ مِّن رَّبِّكُمْ فَأَخْلَفْتُم مَّوْعِدِي } أي : وعدكم إياي بالثبوت على الدين واتباع هارون .
