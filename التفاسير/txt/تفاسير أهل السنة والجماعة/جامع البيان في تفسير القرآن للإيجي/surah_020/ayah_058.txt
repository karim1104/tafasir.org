{ فَلَنَأْتِيَنَّكَ بِسِحْرٍ مِّثْلِهِ } : مثل سحرك { فَاجْعَلْ بَيْنَنَا وَبَيْنَكَ مَوْعِدًا } اسم مكان أو زمان { لَّا نُخْلِفُهُ } جعل المكان أو الزمان مخلفا على الاتساع كيوم شهدناه { نَحْنُ وَلَا أَنتَ مَكَانًا } بدل من الموعد على الأول ،   وظرف للانخلفه على الثاني ،   وقيل مفعول أول لا جعل { سُوًى } منصفا يستوي مسافته إلينا وإليك أو عدلا أو مستوى يتبين الناس وما فيه فيه .
