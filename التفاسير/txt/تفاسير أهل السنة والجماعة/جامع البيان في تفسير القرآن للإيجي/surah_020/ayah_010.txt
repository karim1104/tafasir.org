{ إِذْ رَأَى } مفعول لاذكر أو ظرف للحديث { نَارًا } : في طريق مصر حيث استأذن شعيبا في الرجوع إلى مصر لزيارة الوالدة ،   فخرج بأهله فأضل الطريق في ليلة مظلمة باردة فرأى من جانب الطور نارا { فَقَالَ لأَهْلِهِ امْكُثُوا } : أقيموا مكانكم { إِنِّي آنَسْتُ } : أبصرت إبصارا بينا { نَارًا لَّعَلِّي آتِيكُم مِّنْهَا بِقَبَسٍ } : بشعلة منها { أَوْ أَجِدُ عَلَى النَّارِ هُدًى } : هاديا يهديني إلى الطريق .
