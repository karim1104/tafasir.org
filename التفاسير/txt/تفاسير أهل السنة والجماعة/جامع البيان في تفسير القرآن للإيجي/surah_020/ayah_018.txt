{ قَالَ هِيَ عَصَايَ أَتَوَكَّأُ } : أعتمد { عَلَيْهَا } : عند المشي والإعياء { وَأَهُشُّ } : أخبط الورق عن الشجر { بِهَا عَلَى } رؤوس .   { غَنَمِي } : تأكله ،   { وَلِيَ فِيهَا مَآرِبُ } : حاجات ،   { أُخْرَى } : كحمل الماء والزاد بها .   قيل : لما أمره الله بخلع لنعلين وتركهما تصور عند هذا السؤال إنكار التمسك بها .   وأمره بالرفض فبسط الكلام ،   وقال : أنا محتاج إليها غاية الاحتياج ،   وعن وهب لما قال الله ألقها ظن موسى أنه يقو ل ارفضها .
