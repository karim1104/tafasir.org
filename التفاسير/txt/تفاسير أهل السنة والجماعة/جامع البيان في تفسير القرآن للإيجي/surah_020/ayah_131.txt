{ وَلَا تَمُدَّنَّ } : نظر{ عَيْنَيْكَ إِلَى مَا مَتَّعْنَا بِهِ } : نظر استحسان وغبطة ،   { أَزْوَاجًا مِّنْهُمْ } : أصنافا من الكفرة ،   وقيل منهم مفعول متعنا ،   و " أزواجا "  حال من ضمير به { زَهْرَةَ الْحَيَاةِ الدُّنيَا } : زينة وبهجة زائلة ،   نصب على الضم نحو ،   أتاني زيد الفاسق ،   أو ثاني مفعولي متعنا لتضمن معنى الإعطاء { لِنَفْتِنَهُمْ } : نختبرهم ،   { فِيهِ } أو لنجعل ذلك فتنة وبلاء لهم لأن يمدوا في طغيانهم { وَرِزْقُ رَبِّكَ } : في المعاد أو ما رزقك من علم النبوة { خَيْرٌ وَأَبْقَى } .
