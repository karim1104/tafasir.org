{ فَتَعَالَى اللَّهُ } : جل الله في ذاته وصفاته { الْمَلِكُ } : الذي جميع الكائنات تحت سلطانه ،   { الْحَقُّ } : وعده ووعيده ،   أو الثابت في ذاته وصفاته ،   { وَلَا تَعْجَلْ بِالْقُرْآنِ } أي : بقراءته { مِن قَبْلِ أَن يُقْضَى إِلَيْكَ وَحْيُهُ } أي : لا تقرأه حين يقرأ جبريل ،   بل أنصت فإذا أتم قراءته عليك فاقرأه بعده ،   وعن بعض : لا تبلغ ،   ولا تمله على أصحابك حتى يتبين لك معانيه { وَقُل رَّبِّ زِدْنِي عِلْمًا } : بالقرآن ومعانيه .
