{ فأْتِيَاهُ } : فأتياه مكثا في بابه حينا طويلا قيل : سنتين حتى أذن لهما { فَقُولَا إِنَّا رَسُولَا رَبِّكَ فَأَرْسِلْ  مَعَنَا بَنِي إِسْرَائِيلَ } : خل عنهم وأطلقهم { وَلَا تُعَذِّبْهُمْ } : بالأعمال الشاقة { قَدْ جِئْنَاكَ بِآيَةٍ مِّن رَّبِّكَ } : ببرهان ومعجزة على رسالتنا { وَالسَّلَامُ عَلَى مَنِ اتَّبَعَ الْهُدَى } أي : السلامة من عذاب الله عليه .
