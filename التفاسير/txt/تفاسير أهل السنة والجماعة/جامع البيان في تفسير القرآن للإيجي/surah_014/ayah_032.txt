{ اللّه } مبتدأ ،   { الَّذِي خَلَقَ السَّمَاوَاتِ وَالأَرْضَ } خبره ،   { وَأَنزَلَ مِنَ السَّمَاء مَاء فَأَخْرَجَ بِهِ مِنَ الثَّمَرَاتِ } أي : بعضها ،   { رِزْقًا } مفعول له أو حال أو مصدر ،   فإن أخرج بمعنى رزق ،   { لَّكُمْ وَسَخَّرَ لَكُمُ الْفُلْكَ لِتَجْرِيَ فِي الْبَحْرِ بِأَمْرِهِ } بإرادته ،   { وَسَخَّرَ لَكُمُ } لأجل انتفاعكم ،   { الأَنْهَارَ } .
