{ قَالَتْ } : لهم ،   { رُسُلُهُمْ أَفِي اللّهِ } ،   أي : في تفرده بوجوب العبادة له ،   { شَكٌّ } : فاعل الظرف ،   { فَاطِرِ السَّمَاوَاتِ وَالأَرْضِ } : لا يستحق العبادة إلا من ابتدعهما من غير مثال سبق ،   { يَدْعُوكُمْ } : إلى طاعته ،   { لِيَغْفِرَ لَكُم مِّن ذُنُوبِكُمْ } ،   أي : بعض ذنوبكم الذي يُكفَّر بالإيمان فإن المَظَالم لا يكفَّر بالإيمان  للذمي خصوصا ،   وقيل من صلة ،   وقيل بمعنى البدل ،   { وَيُؤَخِّرَكُمْ إِلَى أَجَلٍ مُّسَمًّى } : فلا يعاجلكم بالعذاب ،   { قَالُواْ إِنْ أنتم إِلاَّ بَشَرٌ مِّثْلُنَا } : فمن أين لكم المتبوعية ،   { تُرِيدُونَ أَن تَصُدُّونَا } : تمنعونا ،   { عَمَّا كَانَ يَعْبُدُ آبَآؤُنَا فَأْتُونَا بِسُلْطَانٍ مُّبِينٍ } : حجة ومعجزة ظاهرة دالة على فضلكم وصحة دعواكم كأنهم اقترحوا آية أظهر مما جاءوا به من المعجزات .
