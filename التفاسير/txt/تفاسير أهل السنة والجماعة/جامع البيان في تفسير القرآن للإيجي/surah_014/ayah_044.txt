{ وَأَنذِرِ النَّاسَ } يا محمد ،   { يَوْمَ } مفعول ثان لأنذر ،   { يَأْتِيهِمُ الْعَذَابُ } يوم القيامة ،   { فَيَقُولُ الَّذِينَ ظَلَمُواْ } أشركوا ،   { رَبَّنَا أَخِّرْنَا } أمهلنا ،   { إِلَى أَجَلٍ } حد من الزمان ،   { قَرِيبٍ } سألوا الرد إلى الدنيا ،   { نُّجِبْ } جواب للأمر ،   { دَعْوَتَكَ وَنَتَّبِعِ الرُّسُل } فيجابون بقوله : { أَوَلَمْ تَكُونُواْ أَقْسَمْتُم مِّن قَبْلُ } حلفتم في الدنيا ،   { مَا لَكُم مِّن زَوَالٍ } جواب القسم ،   أي : أقسمتم أنكم لا تنتقلون إلى الآخرة ،   و لا معاد لكم ،   فذوقوا وباله .
