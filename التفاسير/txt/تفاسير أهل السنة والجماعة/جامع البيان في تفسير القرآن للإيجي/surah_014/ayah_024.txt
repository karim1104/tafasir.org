{ أَلَمْ تَرَ كَيْفَ ضَرَبَ اللّهُ } أي : قصد ،   { مَثَلاً } : ووضعه ،   { كلِمَةً طَيِّبَةً } هي كلمة التوحيد ،   ونصبها بتقدير جعل كلمة ،   ويكون تفسيرا لقوله ضرب الله ،   { كَشَجَرةٍ طَيِّبَةٍ } : هي النخلة أو شجرة في الجنة ،   { أَصْلُهَا ثَابِتٌ } : في الأرض ،   { وَفَرْعُهَا } : غصونها ورأسها ،   { فِي السَّمَاء } .
