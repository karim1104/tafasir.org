{ فاتقوا الله ما استطعتم } أي : جهدكم وطاقتكم ،   وعن كثير من السلف أنه لما نزلت { اتقوا الله حق تقاته }[ آل عمران :102 ] اشتد عليهم العمل ،   فقاموا حتى ورمت عراقيبهم ،   وتقرحت جباههم ،   فأنزل الله قوله :{ فاتقوا الله ما استطعتم } تخفيفا فيكون ناسخة لما في آل عمران { واسمعوا } مواعظه { وأطيعوا } أوامره { وأنفقوا } في مصارف الخير { خيرا لأنفسكم } تقديره ائتوا خيرا لأنفسكم فهو كالفذلكة للأوامر السابقة ،   أو تقديره يكن خيرا فيكن جوابا للأوامر ومعناه أنفقوا لأنفسكم من أموالكم { ومن يوق } وقاه الله { شح } حرص { نفسه فأولئك هم المفلحون }
