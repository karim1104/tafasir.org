{ رفيع الدرجات } كناية عن علو شأنه ،   أو درجات الجنة للمؤمنين ،   خبر ثان لهو أو خبر لمحذوف { ذو العرش } : مالك أصل العالم الجسماني ومدبره { يلقي الروح } خبر رابع ،   والروح الوحي فإنه محيي القلوب من موت الكفر أو المراد جبريل { من أمره } : من قضائه ومن ابتدائية متعلقة بيلقى أو حال من الروح { قل الروح من أمر ربي } [ الإسراء :85 ] { على من يشاء من عباده } فيجعله نبيا { لينذر } : الضمير لمن { يوم التلاق } : يوم القيامة يتلقى فيه الخالق والمخلوق ،   وأهل السماء والأرض ،   والظالم والمظلوم ،   والعباد وما عملوا من خير وشر ،
