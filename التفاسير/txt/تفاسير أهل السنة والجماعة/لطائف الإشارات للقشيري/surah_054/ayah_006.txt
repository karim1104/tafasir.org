قوله جلّ ذكره : { فَتَوَلَّ عَنْهُمْ يَوْمَ يَدْعُ الدَّاعِ إِلَى شَيءٍ نُّكُرٍ خُشَّعاً أَبْصَارُهُمْ } .

{ فَتَوَلَّ عَنْهُمْ } : ها هنا تمام الكلام - أي فأعرِضْ عنهم ،   وهذا قبل الأمر بالقتال .   ثم استأنف الكلامَ : { يَوْمَ يَدْعُ الدَّاعِ .   .   .   } والجواب : { يَخْرُجُونَ مِنَ الأَجْدَاثِ } - أراد به يوم القيامة .

ومعنى { نُّكُرٍ } : أي شيءٌ ينكرونه ( بِهَوْله وفظاعته ) وهو يوم البعث والحشر .
