قوله جلّ ذكره : { إِذْ دَخَلُوا عَلَيْهِ فَقَالُوا سَلاَماً قَالَ سَلاَمٌ قَوْمٌ مُّنكَرُونَ } .

أي سلَّمنا عليك { سَلاَماً } فقال إبراهيم : لكم مني { سَلاَمَاً } .

وقولُهم : { سَلاماً } أي لك منّا سلام ،   لأنَّ السلامَ : الأمانُ .

{ قَوْمٌ مُّنكَرُونَ } : أي أنتم قوم منكرون ؛ لأنه لم يكن يعرف مِثْلَهم في الأضياف .   ويقال : غُرَبَاء .
