{ أَمْ عِندَهُمْ خَزَآئِنُ رَبِّكَ } .

- أي خزائن أرزاقه ومقدوراته ؟ { أَمْ هُمُ الْمُصَيْطِرونَ } المُتَسلِّطون عَلَى الناس ؟

أم لهم سُلّمٌ يرتقون فيه فيستمعون ما يجري في السماوات ؟ { فَلْيَأْتِ مُسْتَمِعُهُم بِسُلْطَانٍ مُّبِينٍ } ثم إنه سفّهَ أحلامهم فقال :

{ أَمْ لَهُ الْبَنَاتُ وَلَكُمُ الْبَنُونَ أَمْ تَسْئَلُهُمْ أَجْراً فَهُم مِّن مَّغْرَمٍ مُّثْقَلُونَ } .
