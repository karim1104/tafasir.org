قوله جل ذكره : { إِنَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ لَهُمْ أَجْرٌ غَيْرُ مَمْنُونٍ } .

{ آمِناً } : شاهدوا ،   { وَعَمِلُواْ الصَّالِحَاتِ } : لازموا بِساط العبودية .

{ آمَنُواْ } : شهدوا الحضرة ،   { وَعَمِلُواْ الصَّالِحَاتِ } : وقفوا بالباب .

{ آمَنُواْ } : حضروا ،   { وَعَمِلُواْ الصَّالِحَاتِ } : بعد ما حضروا لم ينصرفوا .

{ لَهُمْ أَجرٌ غَيْرُ مَمْنُونٍ } : غير منقوص ؛ فأجرُ النفوسِ الجنةُ ،   وأجرُ القلوب الرضا بالله ،   وأجرُ الأرواح الاستئناسُ بالله ،   وأجرُ الأسرار دوام المشاهدة لله .
