{ ولقد مكناهم } من العمر والقوة والمال { فيما } أي في شيء { إن مكناكم فيه } كان بغيكم أكثر { وجعلنا لهم سمعا } يسمعون به المواعظ { وأبصارا } يبصرون ت بها الآيات الدالة على وحدانيتنا { وأفئدة } ليفهموا بها ما فيه دلالة على ألوهيتنا { فما أغنى عنهم } بسبق الشقاوة عليهم { سمعهم } فصرفوه في أهوائهم لا في سماع المواعظ { ولا أبصارهم } فشغلوها بالنظر فيما لا يعنيهم ولم يصرفوها للنظر في الآيات { ولا أفئدتهم } فما استعملوها فيما ينفعهم بل استعملوها في الكفر والمكر والخديعة { من شيء } من الإغناء ولو قليلا { إذ كانوا يجحدون } الكفار { يآيات الله } وحججه الواضحة { وحاق } نزل { ربهم ما كانوا به يستهزئون } من العقاب والعذاب
