{ ووصينا الإنسان بوالديه حسنا } وقرئ إحسانا وقرئ حسنا أي إيصاء حسنا { حملته أمه كرها } على مشقة { ووضعته كرها } على مشقة { وحمله } مدة حمله { وفصاله } من الرضاع وقرئ وفصله { ثلاثون شهرا } لأن أقل مدة الحمل ستة أشهر والباقي للرضاع { حتى إذا بلغ } استكمل { أشده } وغاية شبابه وهي ثلاث وثلاثون سنة { وبلغ أربعين سنة } وفيها نهاية كمال العقل والرأي وقد قيل إنه لم يبعث نبي إلا بعد الأربعين { قال رب أوزعني } ألهمني { أن أشكر نعمتك التي أنعمت علي } بالإيمان { وعلى والدي } كذلك والآية نزلت في الصديق فإنه لم يكن أحد أسلم هو وأبواه من المهاجرين والأنصار سواه { وأن أعمل } عملا { صالحا ترضاه } تقبله مني وقد أعتق سبعة من المؤمنين يعذبون في الله { وأصلح لي } واجعل الصلاح ساريا { في ذريتي } فآمنوا كلهم { إني تبت إليك } عما يشغل عنك { وإني من المسلمين } المخلصين في طلب رضاك
