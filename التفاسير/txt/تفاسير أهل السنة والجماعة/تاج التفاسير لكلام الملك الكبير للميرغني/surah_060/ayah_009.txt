{ إنما ينهاكم الله } عباده المؤمنين { عن الذين قاتلوكم } للمعاداة  ، { في الدين وأخرجوكم من دياركم } كمن سعى في إخراجكم من مشركي مكة  ، { وظاهروا } وعاونوا المخرجين { على إخراجكم } وهم أيضا من بعض مشركي مكة { أن تولوهم } تتخذوهم أولياء { ومن يتولهم } ويجعلهم أولياء له  ، { فأولئك هم الظالمون } لسلوكهم خلاف ما أمرهم به مولاكم .
