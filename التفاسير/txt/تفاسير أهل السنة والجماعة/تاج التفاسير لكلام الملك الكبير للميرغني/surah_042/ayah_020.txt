{ من كان يريد } بعمله وعمله { حرث الآخرة } أي ثوابها { نرد له } بمحض منتنا { في حرثه } كسبه الذي حصله ونعطيه بالحسنة الواحدة عشرة إلى سبعمائة إلى أكثر من ذلك كما ورد أن النبي صلى الله عليه وسلم قال إن اللقمة يتصدق بها من عبد فتقع في يد الرحمن فيربيها حتى تكون كجبل أحد فهذا التضعيف أكثر من المذكور { ومن كان يريد } بجميع أحواله { حرث الدنيا } وزينتها وشهواتها ولذاتها { نؤته } ما قسم { منها } له { وما له في الآخرة } لدينا { من نصيب } من حظ يجده
