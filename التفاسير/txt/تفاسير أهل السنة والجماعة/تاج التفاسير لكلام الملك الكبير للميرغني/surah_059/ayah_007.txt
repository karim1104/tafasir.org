{ ما أفاء على الله رسوله }منه  ،  { من أهل القرى } كينبع والصفراء  ، { فلله } ووليه رسوله يفعل فيه ما يشاء { وللرسول } حق يفعل فيه ما يشاء  ، { ولذي القربى } قرابة المصطفى عليه الصلاة والسلام من بني المطلب وهاشم  ، { واليتامى } أطفال المؤمنين الذين مات عنهم آباؤهم وتركوهم فقراء  ، { والمساكين } أهل الحاجة من المؤمنين  ، { وابن السبيل } وهو المنقطع من المؤمنين في سفر فهؤلاء أهل استحقاقه  ،  وحاصله أن الفيء كان يجعل خمسة أخماس على هؤلاء المذكورين  ، والأربعة أخماس للرسول صلى الله عليه وسلم يفعل فيها كيف يشاء  .  { كي لا يكون } الفيء { دولة } يتداول { بين الأغنياء منكم } ويمنع منه الفقراء وقرئ دولة بفتح الدال  .  { وما آتاكم } أعطاكم من الفيء { الرسول } صلى الله عليه وسلم { فخذوه فهو طيب لكم  ، { وما نهاكم } الرسول } عنه { عن أخذه { فانتهوا } فاجتنبوا تناوله  .  { واتقوا الله } ولا تخالفوا رسوله { إن الله شديد العقاب } للذين يخالفونه  .
