{ هو الله الذي لا إله إلا هو } لا مقصود بحق سواه  ، { الملك } الذي لا يشاركه أحد في ملكه  ، { القدوس } الطاهر عن كل ما لا يليق به وقرئ بالفتح وهو لغة فيه  ، { السلام } ذو السلامة من النقائص والآفات  ، { المؤمن } وقرئ بالفتح الذي صدق رسله بإيجاد المعجزات لهم  ، { المهيمن } الرقيب الشهيد على أعمال العباد  ، { العزيز } في ملكه  ، { الجبار } بجبره خلقه على ما أراد منهم  ، { المتكبر } عما يوجب نقصا أو حاجة  ، { سبحان الله } تنزه نفسه { عما يشركون } فلا شريك له  .
