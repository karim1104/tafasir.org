{ إنا بلوناهم } أي أهل مكة بالجوع والقحط اختبرناهم { كما بلونا } أي كما اختبرنا { أصحاب } أهل { الجنة } البستان الذي كان دون صنعاء بفرسخين ،  وكان لرجل صالح ينادي الفقراء وقت الصرام ،  وينفعهم منه منافع كثيرة ،  فلما مات قال بنوه إن فعلنا ما كان يفعل أبونا ضاق علينا الأمر ،  { إذ أقسموا } حلفوا { ليصرمنها } ليقطعنها { مصبحين } وقت الصباح .
