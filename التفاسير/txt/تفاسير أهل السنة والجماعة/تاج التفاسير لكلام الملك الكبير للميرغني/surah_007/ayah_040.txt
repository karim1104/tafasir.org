( إن الذين كذبوا بآياتنا ) بحججنا الدالة على توحيدنا ونبوة أنبيائنا ( واستكبروا ) تكبروا ( عنها ) عن الإيمان بها ( لا تفتح لهم ) أي لأرواحهم إذا عرج بها بعد الموت ( أبواب السماء ) بل يهبط بها إلى سجين وأما المؤمن فتفتح له ويعرج بروحه إلى السماء السابعة كما ورد في الحديث ( ولا يدخلون الجنة ) دار الرضا ( حتى يلج الجمل في سم الخياط ) أي حتى يدخل البعير في ثقب الإبرة وهذا لا يكون ودخولهم مثله وقرئ  الجمل كالقمل ( وكذلك ) مثل هذا الجزاء ( نجزي المجرمين ) الكافرين
