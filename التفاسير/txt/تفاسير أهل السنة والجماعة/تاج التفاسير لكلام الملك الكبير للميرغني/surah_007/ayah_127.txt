( وقال الملأ من قوم فرعون ) له ( أتذر ) أتدع ( موسى وقومه ليفسدوا في الأرض ) ويأمر الناس بمخالفتك ( ويذرك ) وقرئ بالرفع وقرئ بالسكون ( وآلهتك ) وكان صنع لهم أصناما يعبدونها تقربا إليه ويقول أنا ربكم وربها ولذا قال أنا ربكم الأعلى ( قال ) فرعون ( سنقتل ) وقرئ مخففا ( أبناءهم ) أولادهم الذكور ( ونستحيي ) نستبقي ( نساءهم ) لخدمتنا كما كنا نفعل بهم قبل ( وإنا فوقهم قاهرون ) ولهم غالبون
