( أو عجبتم ) أكذبتم وعجبتم ( أن جاءكم ذكر ) موعظة وتذكير ( من ربكم على رجل منكم ) تعلمون نسبه ( لينذركم ) ليخوفكم عاقبة الإدبار عن الله ( واذكروا إذ جعلكم ) في الأرض ( خلفاء ) تملكون وتتصرفون ( من بعد قوم نوح ) أي بعد تدميرهم ( وزادكم في الخلق بسطة ) قوة وقامة ( فاذكروا آلاء الله ) نعمه التي لا تحصى ( لعلكم تفلحون ) تفوزون
