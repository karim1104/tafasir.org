( قد افترينا ) اختلقنا ( على الله كذبا إن عدنا في ملتكم ) الفاسدة ( بعد إذ نجانا الله منها ) معشر المؤمنين وأما الرسل فمعصومون ابتداء وانتهاء في سلوك ( وما يكون لنا ) أي وما يصلح لنا ( أن نعود فيها ) الضمير لملتهم ( إلا أن يشاء الله ربنا ) أي إلا أن يكون قد سبق في علمه غير التوحيد ( وسع ربنا كل شيء علما ) أي وسع علمه كل شيء ( على الله توكلنا ) فهو يكفينا شركم ( ربنا افتح ) اقض ( بيننا وبين قومنا بالحق ) وأظهر أمرنا ( وأنت خير الفاتحين ) القاضين
