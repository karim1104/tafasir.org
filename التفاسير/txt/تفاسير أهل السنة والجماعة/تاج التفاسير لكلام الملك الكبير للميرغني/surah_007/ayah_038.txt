( قال ) الحق لهم يوم القيامة ( ادخلوا ) النار ( في أمم ) من أمم ( قد خلت ) مضت ( من قبلكم من الجن والإنس في النار ) بكفرهم مثلكم ( كلما دخلت أمة ) فيها ( لعنت أختها حتى إذا اداركوا فيها ) الضمير للنار أي تلاحقوا فيها ( جميعا قالت أخراهم ) أي الأتباع ( لأولاهم ) أي المتبوعين ( ربنا هؤلاء أضلونا ) وعن سبيل الإيمان أغوونا ( فآتاهم عذابا ضعفا ) أي مضاعفا ( من النار ) لإغوائهم لنا ( قال ) الله تعالى ( لكل ) منكم ومنهم ( ضعف ) عذاب مضعف ( ولكن لا تعلمون ) ما لكم وقرئ بالياء
