( هل ينظرون ) ما ينتظرون ( إلا تأويله ) عاقبة ما وعدوه ( يوم يأتي تأويله ) وهو يوم القيامة ( يقول الذين نسوه من قبل ) تركوا العمل به ( قد جاءت رسل ربنا بالحق ) بالصدق ( فهل لنا من شفعاء فيشفعوا لنا ) في هذا اليوم ( أو نرد ) أو هل نرد إلى الدنيا ( فنعمل ) وقرئ بالرفع ( غير الذي كنا نعمل ) فنوحد الله وندع الشرك ( قد خسروا أنفسهم ) وضيعوا أوقاتهم فيما لا ينفعهم عند الله ( وضل عنهم ما كانوا يفترون ) من الأكاذيب
