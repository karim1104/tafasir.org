( فدلاهما ) حطهما عن درجتهما ( بغرور ) غرهما به ( فلما ذاقا الشجرة ) أكلا منها ( بدت لهما ) ظهرت لهما ( سوءاتهما ) أي لكل منهما قبله وقبل الآخر ودبره ( وطفقا ) أخذا ( يخصفان ) يلزقان ( عليهما من ورق الجنة ) ليستتروا ويلزم الإنسان إذا كشف عورته أن يستتر ولو بالورق إذا لم يجد ثوبا كما قال ابن عباس رضي الله عنهما : من لم يجد ثوبا فليستتر بالورق وغيره كما فعل آدم عليه السلام حين أكل من الشجرة وكانت شجرة التين ( وناداهما ربهما ) معاتبا لهما ( ألم أنهكما ) رحمة بكما ( عن تلك الشجرة ) أي عن الأكل منها فإن الأكل منها لا يناسب خلود الجنان ( وأقل لكما ) ناصحا ومحذرا من إبليس ( إن الشيطان لكما عدو مبين ) ظاهر العداوة
