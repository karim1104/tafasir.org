{ لا جناح عليهن في آبائهن } أن يدخلوا من وراء الحجاب ويكلموهن { ولا أبنائهن ولا إخوانهن } سواء من النسب أو الرضاع { ولا أبناء إخوانهن ولا أبناء أخواتهن } أيضا من نسب أو رضاع { ولا نسائهن } المؤمنات { ولا ما ملكت إيمانهن } من الإماء وقيل منهن ومن العبيد { واتقين الله } فيما أمرتن به { إن الله كان على كل شيء شهيدا } لا يخفى عليه شيء
