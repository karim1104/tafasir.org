{ وأنزل الذين ظاهروهم } أي عاونوا الأحزاب { من أهل الكتاب } وهم بنو قريظة { من صيامهم } من حصونهم { وقذف في قلوبهم الرعب } الخوف وقرئ بالضم { فريقا تقتلون } منهم { وتأسرون فريقا } وذلك أنه أتى جبريل النبي صلى الله عليه وسلم صبيحة ما انهزم الأحزاب فقال له أتنزع لأمتك والملائكة لم تضع السلاح إن الله يأمرك بالسير على بني قريظة فصار بالجيش وحبسهم وحصرهم نحو عشرين ليلة ثم نزلوا فقتل مقاتلهم وسبي ذراريهم ونساءهم
