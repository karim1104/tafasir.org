{ ولما رأى المؤمنون الأحزاب } كثرة الأعداء المتحزبين عليهم { قالوا هذا ما وعدنا الله ورسوله } لقوله تعالى أم حسبتم أن تدخلوا الجنة الآية وقول النبي عليه الصلاة والسلام سيشتد الأمر باجتماع الأحزاب عليكم والعاقبة لكم عليهم .   وكذا قوله إنهم سائرون إليكم بعد تسع أو عشر { وصدق الله } في وعده { ورسوله } عليه الصلاة والسلام كذلك فجاءوا وقع النصر { وما زادهم } المؤمنين ذلك { إلا إيمانا } تصديقا بوعد الله { تسليما } لقضائه
