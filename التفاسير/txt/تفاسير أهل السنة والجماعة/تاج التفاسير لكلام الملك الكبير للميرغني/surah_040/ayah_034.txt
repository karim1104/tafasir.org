{ ولقد جاءكم يوسف } مرسلا من عند الله { من قبل } أي من قبل موسى { بالبينات } المعجزات الواضحات { فما زلتم في شك } وتردد وتكذيب { مما جاءكم به } من الهدى القويم { حتى إذا هلك } انتقل إلى البرزخ { قلتم لن يبعث الله } لن يرسل الله وقرئ ألن يبعث الله { من بعده رسولا } فكفركم ملازم لكم مع يوسف وغيره { كذلك } أي مثل الضلال { يضل الله } عن سبيل الإيمان { من هو مسرف } على نفسه بإدخالها في طرق الهلاك { مرتاب } شاك فيما يأتي به أنبياء الله
