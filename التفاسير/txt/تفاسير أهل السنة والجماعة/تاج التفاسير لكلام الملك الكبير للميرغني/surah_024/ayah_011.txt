{ إن الذين جاءوا بالإفك } بالكذب على عائشة رضي الله عنها وصفوان بن معطل السلمي { عصبة } جماعة { منكم } معشر المؤمنين مسطح وزيد بن رفاعة وحسان بن ثابت وحمنة بنت جحش وعبد الله بن أبي المنافق وذلك أنها كانت معه عليه الصلاة والسلام في بعض الغزوات وكانت خرجت لقضاء الحاجة ثم عادت ووجدت قد انقطع عقدها من ظفار فردعت تطلبه ورحل الجيش في غيبتها وحملوا هودجها ظنا أنها فيه فلما عادت إلى منزلها ووجدت الناس رحلوا جلست موضعها فجاء صفوان وكان معرسا وراء الجيش فوجدها فأناخ لها الراحلة فركبت وأخذ يقود البعير وهو مع ذلك لم يكلمها ولم تكلمه حتى أوصلها الجيش فخاض من خاض في أمرها برأها الله بنزول هذه الآيات { لا تحسبوه } ذلك الإفك { شرا لكم } وفي مضرة { بل هو خير لكم } لاكتسابهم به الأجر { لكل امرئ منهم } من الخائضين في الإفك { ما اكتسب من الإثم } بقدر ما خاض فيه { والذي تولى كبره } معظمه { منهم وهم عبد الله بن أبي { له عذاب عظيم } في النار في الآخرة وعمى حسان وشلت يداه وكف بصر مسطح
