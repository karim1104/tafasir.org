{ الله نور السماوات والأرض } منورهما بالشمس والقمر وقرئ منور { مثل نوره } في قلب عبده المؤمن { كمشكاة } المشكاة هي الطاقة غير النافذة والمراد الأنبوبة في القنديل التي تجعل فيها الفتيلة { فيها مصباح المصباح } هو السراج أي الفتيلة الموقدة { في زجاجة } هي القنديل { الزجاجة كأنها } في ضيائها { كوكب دري } منسوب إلى الدر أي أنه كأنه الدر { توقد } وقرئ بمضارع أوقد مبنيا للمفعول بالتحتانية وقرئ بالفوقانية { من شجرة أي من زيتها { مباركة زيتونة  لا شرقية ولا غربية } لا يتمكن منها حر ولا برد مضرين بل بين المشرق والمغرب { يكاد زيتها يضيء } لصفائه دون السراج { ولو لم تمسسه نار نور } كأين به { على نور } بالنار ونور الله هذا نور على نور الإيمان { يهدي الله لنوره } للإيمان به { من يشاء } هدايته { ويضرب } يبين { الله الأمثال للناس } تقريبا لأفهامهم { والله بكل شيء عليم } لا يخفى عليه شيء أو مثل نوره كمشكاة هي ذات المؤمن فيها مصباح هو نور قلبه المصباح الذي هو نور القلب في زجاجة وهو ذات المؤمن الزجاجة التي هي قلب المؤمن كأنها في صفائها كوكب دري مثل الكوكب المضيء والجواهر الدرية يتوقد مصباحها الذي هو النور الداخل في القلب من شجرة مباركة شجرة أصل الإيمان فإن نور قلب المؤمن مدده منها بل أصله زيتونة مثل شجرة الزيتون فإنها شجرة مباركة لا شرقية ولا غربية لا تشرق على من ليس من أهلها ولا تغرب عن أهلها بل تمد أهلها المستحقين لها يكاد زيتها نورها يضيء على مدى الأوقات ولو لم تمسسه نار ،  نار بركة أعماله نو إلهي أصلي على نور أي على نور قلب المؤمن الحاصل من أعماله يهدي الله بهذين النورين إلى جنابه الأقدس وكماله المقدس من يشاء إدخاله إلى حضراته الصمدانية ومشاهده الفردانية أو النور المشرق نور الحق في قلب المؤمن كما يليق بالجلال الإلهي وفي الحديث القدسي ما وسعني سمائي ولا أرضي ولكن وسعني قلب عبدي المؤمن
