( أحل لكم ) أيها الصائمون ( ليلة الصيام ) أي الليلة التي تصبحون صائمين نهارها ( الرفث إلى نسائكم ) الإفضاء إليهن بالجماع ( هن ) أي نسائكم ( لباس لكم ) فراش ( وأنتم لباس لهن ) أي لحاف ،  وهو كناية عن التعانق ( علم الله ) منكم ( أنكم ) لغلبة نفوسكم ( كنتم تختانون ) تخونون وتظلمون ( أنفسكم ) وذلك حين حجر عليكم فعل ذلك من أول الليل ( فتاب عليكم ) ما فعلتموه ( وعفا عنكم ) فيما أسأتموه ( فالآن ) وسع لكم في ذلك فقال لكم ( باشروهن ) أي جامعوهن ( وابتغوا عنكم ) اطلبوا ( ما كتب الله لكم ) الترخيص فيه من الجماع وطلب الولد ( وكلوا ) من طيبات ما أحل الله لكم ( وشربوا ) كذلك طول الليل ( حتى يتبين ) ويظهر ( لكم الخيط الأبيض ) وهو مبادى الفجر ( من الخيط الأسود ) وهو الليل ( من الفجر ) المعبر عنه بالخيط الأبيض فقد وسعنا لكم وأبحنا لكم ما كنا حجرناه عليكم من أول الليل إلى الفجر ( ثم أثموا ) من وقتكم ذلك ( الصيام ) عن كل مفطر ( إلى الليل ) وفي البخاري ومسلم عنه صلى الله عليه وسلم قال إذا أقبل الليل وأدبر النهار من ههنا وغربت الشمس فقد أفطر الصائم ( ولا تباشروهن ) الضمير للنساء ( وأنتم ) أيها المؤمنون ( عاكفون ) مقيمون ( في المساجد ) بنية الاعتكاف فإنه يفسد ( تلك ) أحكام الله التي ذكرها ( حدود الله ) حدها لعباده ( فلا تقربوها ) فإنه من قرب من الشيء يخشى أن يدخل فيه  ، وفي الخبرعنه "  صلى الله عليه وسلم "  أن لكل ملك حمى وحمى الله محارمه  ، فمن رتع حول الحمى يوشك أن يقع فيه  .  ( كذلك ) مثل ما بين الله لكم هذه الأحكام ( يبين الله آياته ) التي يفرق بها بين الحق والباطل ( للناس ) الطالبين النجاة منه ( لعلهم يتقون ) يجتنبون ما يوجب غضبه وعقابه .
