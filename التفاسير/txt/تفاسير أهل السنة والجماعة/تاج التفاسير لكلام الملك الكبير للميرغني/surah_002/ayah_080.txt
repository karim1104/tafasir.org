{ وقالوا } تاليا على الله حين هددهم النبي صلى الله عليه وسلم بالنار { لن تمسنا النار } أي نار جهنم { إلا أياما معدودة } أربعين يوما مدة عبادة آبائهم العجل { قل }أيها النبي الكريم { أتخذتم } بذلك وقرئ اتخذتم بالإدغام { عند الله عهدا } وميثاقا { فلن يخلف الله عهده } أن عهد إليكم أن لا يعذبكم إلا هذه المدة { أم } بل { تقولون على الله } تهكما وجرأة { ما لا تعلمون } أن الله واعدكم به فاستولت أحبارهم على جهالهم وجهالهم على علمائهم فصار الكل على الوبال وفي الحديث وفي معنى مثل ذلك ويل للعالم من الجاهل وويل للجاهل من العالم .
