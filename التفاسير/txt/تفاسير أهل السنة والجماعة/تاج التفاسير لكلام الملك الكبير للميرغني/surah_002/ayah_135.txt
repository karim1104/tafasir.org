{ وقالوا كونوا هودا } هذا قول اليهود { أو نصارى } وهذا قول النصارى { تهتدوا } إن تهودتم أو تنصرتم يقولونه للمسلمين { قل } لهم أيها النبي ومن معك من المؤمنين { بل } نتبع { ملة إبراهيم } الخليل { حنيفا } مائلا إلى الحق عن الباطل { وما كان من المشركين } فنحن وهو ديننا الإسلام والتوحيد وأنتم في ضلالكم .
