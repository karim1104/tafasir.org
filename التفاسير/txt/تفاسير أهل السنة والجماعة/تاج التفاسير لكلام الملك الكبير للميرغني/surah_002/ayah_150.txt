( ومن حيث خرجت ) أي من أي موضع خرجت ( فول وجهك شطر المسجد الحرام ) وقد أكدنا عليك ولأتباعك ذلك فلا كلام ( وحيثما كنتم ) من الجهات ( فولوا ) وجهوا ( وجوهكم ) في صلاتكم ( شطره ) نحوه ( لئلا يكون ) في التولي إلى غير الكعبة ( للناس عليكم حجة ) مجادلة فلا تبالوا قول اليهود تجحدون ديننا وتتبعون قبلتنا وقول المشركين تدعى ملة إبراهيم وتخالف قبلته ( إلا الذين ظلموا ) أنفسهم ( منهم ) بالعناد حتى أدخلهم في طرق الفساد ( فلا تخشوهم ) تخافوهم وتبالوا بمحاججتهم ( واخشوني ) خافوني واجتهدوا فيما أمرتكم به ( ولأتم نعمتي عليكم ) بالتأييد عليهم ( ولعلكم تهتدون ) إلى سبيل الحق فتنصروا
