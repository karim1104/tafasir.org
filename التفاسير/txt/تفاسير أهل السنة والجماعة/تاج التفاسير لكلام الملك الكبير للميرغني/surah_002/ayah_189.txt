( يسألونك ) بعض من الصحابة ( عن الأهلة ) ما بالها تبدو دقيقة كالخيط ثم تزيد حتى تستوي ثم لا تزال تنقص حتى ترجع كما بدأت ( قل ) لهم أيها النبي الكريم ( هي ) الأهلة ( مواقيت للناس ) معالم للناس يعلمون بها أوقات أمورهم ومعالم لعبادتهم كأوقات صيامهم وإفطارهم ( والحج ) كذلك يعلم وقته بها فلو بقيت على حالة واحدة لم يعرف ذلك ( وليس البر ) الذي تتقربون به إلى الله ( بأن تأتوا البيوت ) حين تقدموا محرمين وقرئ بكسر الباء ( من ظهورها ) لأنهم كانوا ينقبون نقبا في ظهر البيت فيخرجون به ويظنون أن ذلك البر ( ولكن البر ) المقرب إلى الله ( من اتقى ) الله واختشى حتى لم ير سواه ( وأتوا البيوت )حالة إحرامكم ( من أبوابها ) كما كنتم تأتونها في غير وقت الإحرام ( واتقوا الله ) واخشوه وامتثلوا ما أمركم به ( لعلكم ) بما يقرب لديه ( تفلحون ) تظفرون
