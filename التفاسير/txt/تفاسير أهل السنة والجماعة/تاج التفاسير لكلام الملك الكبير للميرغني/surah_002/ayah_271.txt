( إن تبدوا ) تظهروا ( الصدقات ) التي تنفقونها في مرضات الله ( فنعما هي ) نعم شيئا إظهارها ( وإن تخفوها ) تسروها ( وتؤتوها ) تعطوها ( الفقراء ) المحتاجين ( فهو خير لكم ) من إبدائها وعن ابن عباس رضي الله عنهما صدقة السر في التطوع تفضل علانيتها سبعين ضعفا وصدقة الفريضة علانيتها أفضل من سرها بخمس وعشرين ( ويكفر عنكم ) ببركة ذلك ( من سيئاتكم ) وقرئ نكفر بالنون وقرئ بالتاء مرفوعا ( والله بما تعملون خبير ) لا يخفي عليه شيء
