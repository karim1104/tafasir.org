( وإذا طلقتم النساء ) أزواجكم ( فبلغن أجلهن ) بأن انقضت عدتهن فيما دون الثلاثة ( فلا تعضلوهن ) تمنعوهن والخطاب للأولياء ( أن ينكحن أزواجهن ) الذين طلقوهن ( إذا تراضوا ) المطلقون والمطلقات ( بينهم بالمعروف ) المرتضى شرعا ( ذلك ) الحكم المذكور ( يوعظ به ) معشر العباد ( من كان منكم يؤمن بالله ) ويخشاه ( واليوم الآخر ) يخاف مما فيه من المعاقبة لمن خالف الآمر ( ذلكم ) عملكم بما ذكر لكم ( أزكى لكم ) خير لكم وأنفع ( وأطهر ) من الذنوب والآثام ( والله يعلم ) ما فيه الخير لكم ( وأنتم لا تعلمون ) ذلك فامتثلوا أوامره واجتنبوا لنواهيه لتفوزوا بغاية ما فيه مراضيه
