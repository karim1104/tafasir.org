( كتب ) فرض معشر المؤمنين ( عليكم القتال ) للكفار ( وهو كره لكم ) أي تكرهه أنفسكم وتأباه طباعكم ( وعسى أن تكرهوا شيئا ) يا عباد الله ( وهو ) القتال وغيره ( خير لكم ) لما فيه من الشهادة التي بها تنال الدرجات العلى والغنيمة وقوة الإسلام ( وعسى أن تحبوا شيئا ) كترك الجهاد ونحوه ( وهو شر لكم ) لما فيه من فوات درجات الشهادة وفوات الغنيمة وضعف الإسلام ( والله يعلم ) ما فيه الخير لكم ( وأنتم لا تعلمون ) فبادروا إلى السعي فيما أمركم به
