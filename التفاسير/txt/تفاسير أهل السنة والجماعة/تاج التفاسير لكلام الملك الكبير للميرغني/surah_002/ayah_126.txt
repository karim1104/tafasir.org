{ وإذ قال إبراهيم } سائلا مولاه { رب اجعل هذا } البلد { بلدا آمنا } أي ذا أمن فاستجاب الله له ما سأل ،  وفي الحديث :  إن إبراهيم حرم مكة فلا يسفك فيها دم إنسان ولا يصاد صيده ولا يقطع شجرة إلا الإذخر ولا يظلم فيه أحد { وارزق أهله } لأني أسكنتهم في محل ليس فيه معاش { من الثمرات } أي أنواع ما تحمل الأشجار { من آمن منهم } من سكان البلد { بالله واليوم الآخر } وعمل له { قال ومن كفر } منهم { فأمتعه } بالرزق في دنيه وقرئ فأمتعه من أمتع { قليلا } مدة إقامته في الدنيا { ثم أضطره } ألجئه { إلى عذاب النار } في الآخرة ،  وقرئ فمتعه ثم أضطره بلفظ الأمر ،  وقرئ فمتعه ثم نضطره { وبئس المصير } النار لمن كفر بالملك الكبير .
