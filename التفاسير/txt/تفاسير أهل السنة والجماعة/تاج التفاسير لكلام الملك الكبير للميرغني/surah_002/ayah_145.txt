( ولئن أتيت ) أيها النبي الكريم ( الذين أوتوا الكتاب ) اليهود والنصارى ( بكل آية ) حجة وبرهان على صدق تحولك إلى الكعبة ( ما تبعوا قبلتك ) لتصميمهم على التكذيب كفرا وعنادا ( وما أنت بتابع قبلتهم ) فلا يطمعوا فيك ولييأسوا ( وما بعضهم ) بعض الفريقين ( بتابع قبلة بعض ) لأن اليهود تستقبل الصخرة والنصارى مطلع الشمس فلا يتفقون على جهة واحدة ( ولئن اتبعت أهواءهم ) الفاسدة في استقبال قبلتهم ( من بعد ما جاءك من ) الله من ( العلم ) بأن القبلة الكعبة ( إنك إذا لمن الظالمين ) وقد عصمك الله من مخالفته واتباع القوم الخاسرين
