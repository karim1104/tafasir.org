( الطلاق مرتان ) الذي تصح بعده المراجعة ( فإمساك ) للزوجة بمراجعة ( بمعروف ) من غير مضارة ( أو تسريح ) تتميم للطلاق ( بإحسان ) بغير إساءة ( ولا يحل لكم ) عباد الله المؤمنين ( أن تأخذوا ) من نسائكم ( مما آتيتموهن ) من الصدقات ( شيئا ) إذا فارقتموهن ( إلا أن يخافا ) الزوجان ( أن لا يقيما ) بينهما في أنفسهما وقرئ تخافا وأن لا تقيما بالتاء الفوقية ( حدود الله ) التي تلزم كلا منهما ( فإن خفتم ) أمناء الله الحكام ( أن لا يقيما ) بينهما ( حدود الله ) على أنفسهما فيؤذي كل منهما صاحبه ( فلا جناح عليهما ) عند ذلك ( فيما افتدت ) المرأة ( به ) من الرجل من المال ( تلك حدود الله ) التي حدها لعباده ( فلا تعتدوها ) فتقعوا في غضبه ( ومن يتعد حدود الله ) وتجرأ على ارتكابها ( فأولئك ) المعتدون ( هم الظالمون ) أنفسهم بإدخالها النار
