( إن الله لا يستحى ) لا يترك ( أن يضرب ) لعباده ( مثلا ) وقرئ مثل ( ما بعوضة ) أي بالبعوضة ( فما فوقها ) اكبر منها مثل الذباب والعنكبوت ( فأما الذين آمنوا ) وفكروا في حقائق الأمور ( فيعلمون أنه ) أي ضرب المثل ( الحق من ربهم ) الذي لا يسوغ إنكاره ( وأما الذين كفروا ) ولم يكن فيهم أهلية أن يعلموا حقائق الأمور ( فيقولون ) منكرين لذلك ( ماذا ) ما الذي ( أراد الله بهذا مثلا ) أي فائدة في ضرب المثل به فأجابهم الله فقال ( يضل به ) أي بالمثل ( كثيرا ) من العباد ( ويهدي به ) إلى الحق ( كثيرا ) منهم فيصدقون ويؤمنون ( وما يضل به ) عن سبيل هدايته ( إلا الفاسقين ) الكافرين الخارجين عن حوطة الإيمان وقرئ يضل على البناء للمفعول والفاسقون بالرفع
