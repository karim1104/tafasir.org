( واقتلوهم ) الكفار ( حيث ثقفتموهم ) وجدتموهم ( وأخرجوهم ) أعداء الله ( من حيث أخرجوكم ) أي من مكة ( والفتنة ) أي شركهم بالله ( أشد ) وأكبر لهم ( من القتل ) في حرمه مع الإحرام ( ولا تقاتلوهم ) ابتداء ( عند المسجد الحرام ) في الحرم ( حتى يقاتلوكم ) يفاتحوكم ( فيه ) الضمير للمسجد الحرام ( فإن قاتلوكم ) في الحرم ( فاقتلوهم ) ولا تبالوا بهم فإنهم بدءوا بهتك الحرمة ( كذلك ) قتلهم وإخراجهم ( جزاء الكافرين ) على كفرهم وتعديهم سابقا .
