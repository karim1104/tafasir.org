{ و إذ أخذنا } في التوراة { ميثاق } وعهد { بني إسرائيل لا تعبدون } أي وقلنا لهم في ذلك العهد لا تعبدون وقرئ لا تعبدوا وقرئ أن لا تعبدوا وقرئ يعبدوا بالياء { إلا الله } الذي خلقكم { وبالوالدين } أحسنوا إليهما { إحسانا } بأن تبروهم { وذي القربى } أحسنوا إليهم بالمواصلة

{ واليتامى والمساكين } أيضا أحسنوا إليهم بأنواع الإحسان { وقولوا للناس } إن جادلتموهم أو هديتموهم { حسنا } وقرئ حسنا بفتحتين وقرئ حسنا بضمتين أي قولوا لهم قولا حسنا مشتملا على لطف ولين ووعظ وتذكير بصورة غير منفردة حتى ينقادوا وفيما ذكرنا من معنى الآية تعليم خطاب المعلم لمن يتعلم منه وأما اليهود فلم يفعلوا ما أمرهم الله به ثم قال لهم الله في العهد { وأقيموا الصلاة } التي افترضتها عليكم { وآتوا الزكاة } التي أوجبتها عليكم { ثم توليتم } عن ذلك بعد قبوله { إلا قليلا منكم } وهم الذين أسلموا { وأنتم معرضون } عن قبول الحق كما هو دأب آبائكم من قبلكم .
