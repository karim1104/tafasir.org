( لا إكراه في الدين ) على الدخول فيه نزلت فيمن كان له من الأنصار أولاد وأراد أن يكرههم على الإسلام ( قد تبين الرشد ) أنه هو الإيمان ( من الغي ) أنه هو الكفر ( فمن يكفر بالطاغوت ) بالأصنام ( ويؤمن بالله ) يوحده ويصدق رسله ( فقد استمسك ) تمسك ( بالعروة الوثقى ) الشديدة القوية التي ( لا انفصام ) لا انقطاع ( لها ) لقوتها ( والله سميع ) لمن تمسك بالإيمان ( عليم ) به فيجازيه على ذلك
