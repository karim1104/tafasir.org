{ وإذا جعلنا البيت } الكعبة المشرفة { مثابة } مرجعا { للناس } يثوبون إليه من كل جهة { وأمنا } مأمنا لهم من الخوف وقد كان الرجل يلاقي قاتل أبيه في الحرم فلا يتجرأ عليه { واتخذوا } عباد الله المؤمنين { من مقام إبراهيم مصلى } ولما فرغ صلى الله عليه وسلم من طوافه عمد إلى مقام إبراهيم فصلى خلفه ركعتين وقرأ { واتخذوا من مقام إبراهيم مصلى } فبين المقصود من الآية للعباد  ،  وقرئ واتخذوا بلفظ الماضي ومقام إبراهيم هو الحجر الذي كان يقف عليه حين بنى البيت { وعهدنا إلى إبراهيم وإسماعيل } بأن أمرناهما وأوصينا إليهما { أن طهرا بيتي } وقرئ : بسكون الياء من الأوثان والأنجاس وسائر الأدناس { للطائفين } به { والعاكفين } فيه أي المقيمين عنده { والركع السجود } أي المصلين ثم .
