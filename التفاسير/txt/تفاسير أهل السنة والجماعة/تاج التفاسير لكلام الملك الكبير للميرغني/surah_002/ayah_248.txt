( وقال لهم نبيهم ) حين سألوه آية تدل على استحقاق طالوت للملك ( إن آية ) علامة ( ملكه ) أنه بأمر من الحق ( أن يأتيكم التابوت ) الصندوق الذي فيه صور الأنبياء ( فيه سكينة ) طمأنينة لكم ( من ربكم ) يسكن به قلوبكم ويثبتهاغَلَبَتْ فِئَةً كَثِيرَةً بِإِذْنِ اللّهِ وَاللّهُ مَعَ الصَّابِرِينَ 249 وَلَمَّا بَرَزُواْ لِجَالُوتَ وَجُنُودِهِ ( وبقية ) فيه ( مما ترك آل موسى ) وهي رضاض الألواح وثيابه وعصاه ونعلاه ( وآل هرون ) عمامته ( تحمله ) الضمير للتابوت ( الملائكة ) فنزلت به وهم ينظرون إليه ( إن في ذلك ) إتيان التابوت ( لآية لكم ) على أنه حقيق بالملك ( إن كنتم مؤمنين ) فقد رأيتم ما يدل على أهليته للملك
