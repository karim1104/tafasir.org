{ أم تقولون } وقرئ بالياء { إن إبراهيم } الخليل { وإسماعيل } الذبيح { وإسحق ويعقوب والأسباط } أبناء يعقوب { كانوا هودا أو نصارى } بزعمكم الفاسد { قل ءأنتم اعلم أم الله } هو أعلم  ،  وقد قال تعالى  :{ ما كان إبراهيم يهوديا ولانصرنيا } ،  وهم تبعا له معه { ومن أظلم } لا أحد أظلم { ممن كتم } وأخفى { شهادة عنده } ثابتة { من الله } وهو ما عرفوه في التوراة من حنيفية إبراهيم وصدق نبوة سيدنا محمد صلى الله عليه وسلم { وما الله بغافل } يا معشر الخاسرين { عما تعملون } من الجراءة عليه وكتمان ما تعلمون ،  وقرئ بالياء .
