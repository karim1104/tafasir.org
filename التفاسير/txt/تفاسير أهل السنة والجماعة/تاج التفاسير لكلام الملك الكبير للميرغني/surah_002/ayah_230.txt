( فإن طلقها ) بعد المرتين ( فلا تحل له ) أي فلا يحل له زواجها ( من بعد ) أي من بعد الطلقة الثالثة ( حتى تنكح ) تتزوج ( زوجا غيره ) ويطأها لقوله عليه الصلاة والسلام للمرأة التي أرادت مراجعة زوجها الأول أتريدين أن ترجعي إلى رفاعة قالت نعم قال لا حتى تذوقي عسيلته ويذوق عسيلتك ( فإن طلقها ) زوجها الثاني ( فلا جناح عليهما ) الضمير للمرأة والزوج الأول ( أن يتراجعا ) أن يرجعا كل منهما إلى صاحبه ( إن ظنا ) بأنفسهما ( أن يقيما ) عليهما ( حدود الله ) التي حدها لعباده ( وتلك حدود الله ) المذكورة في شرعه ( يبينها ) ويفهمها ( لقوم يعلمون ) فيعملون بمقتضى ذلك
