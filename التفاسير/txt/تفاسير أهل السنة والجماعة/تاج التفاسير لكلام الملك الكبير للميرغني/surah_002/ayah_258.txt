( ألم تر إلى ) قصة ( الذي حاج ) جادل ( إبراهيم في ربه ) وهو النمروذ ( أن آتاه الله ) أعطاه ( الملك ) ومع ذلك كفر بنعمة الله ( إذ قال إبراهيم ) للنمرود حين قال له من ربك قال إبراهيم ( ربي الذي يحيي ) يخلق الحياة في الأجسام ( ويميت ) بإظهار الموت في الأجساد ( قال ) النمرود ( أنا أحيي ) أيضا ( وأميت ) ودعا برجلين فقتل أحدهما وأبقى الآخر وقال ها أنا أحيي وأميت فلما أبصر إبراهيم قلة عقله وشدة سكرته وغفلته عن ربه ( قال إبراهيم ) له ( فإن الله يأتي بالشمس ) أي يطلعها ( من المشرق ) فإن كنت صادقا في ادعائك الربوبية ( فأت بها من المغرب ) عكس ما يرى ( فهبت الذي كفر ) تحير وصار مدهوشا وقرئ فهبت بالبناء للفاعل ( والله لا يهدي ) إلى طريق الاحتجاج ( القوم الظالمين ) الكافرين
