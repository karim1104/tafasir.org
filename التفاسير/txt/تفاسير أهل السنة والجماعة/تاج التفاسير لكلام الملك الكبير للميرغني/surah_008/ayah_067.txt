( ما كان لنبي ) وقرئ للنبي ( أن يكون ) وقرئ بالتاء ( له أسرى حتى يثخن في الأرض ) بكثرة القتل ويبالغ فيه وقرئ يثخن بالتشديد ( تريدون ) الخطاب للمؤمنين ( عرض الدنيا ) حطامهما الفاني بأخذ الفداء ( والله يريد الأخرة ) أي يمن بالثواب الأخروي ( والله عزيز ) ينصر أولياءه على أعدائه ( حكيم ) ومن حكمته ذلك ثم خفف عنهم الأمر فأنزل { فإما منا بعد وإما فداء }
