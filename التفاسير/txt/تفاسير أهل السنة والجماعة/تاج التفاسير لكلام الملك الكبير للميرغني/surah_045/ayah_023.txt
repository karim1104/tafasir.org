{ أفرأيت } أخبرني { من اتخذ إلهه هواه } ترك اتباع الهدى إلى مطاوعة الهوى فكأنه إله ،  وقرئ آلهة هواه ؛ لأنهم يستحسنون الحجارة فيعبدون الحجر فإذا رأوا أحسن منهن رفضوا ومالوا إلى الآخر { وأضله الله } خذله { على } وفق { علم } سابق قبل خلقه ؛ لأنه مطبوع على الضلال { وختم } طبع { على سمعه } فلم يسمع الهدى { و } ختم على { قلبه } فلم يتعظ بالمواعظ { وجعل على بصره غشاوة } ظلمة فلم ينظر الهدى وقرئ غشوة { فمن يهديه } الضمير للمتخذ إلهه هواه { من بعد الله } أي من بعد إضلال الله له { أفلا تذكرون } تتعظون وقرئ تتذكرون .
