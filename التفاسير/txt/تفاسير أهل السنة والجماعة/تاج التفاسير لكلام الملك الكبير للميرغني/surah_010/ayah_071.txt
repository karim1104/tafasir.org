( واتل عليهم نبأ ) خبر ( نوح ) مع قومه ( إذ قال لقومه ) حين أرسل إليهم ( يا قوم إن كان كبر ) شق ( عليكم مقامي ) أي قيامي بالدعوة ( وتذكيري ) وعظي لكم ( بآيات الله فعلى الله توكلت ) اعتصمت به ( فأجمعوا أمركم ) اعزموا على ما تفعلون بي( وشركاءكم ) معكم وقرئ بالرفع ( ثم لا يكن أمركم ) الذي قصدتموه في ( عليكم غمة ) مستورا بل أظهروه ( ثم اقضوا إلي ) أمضوه بي وقرئ أفضوا بالفاء ( و لا تنظرون ) ولا تمهلون فإني لست خاشيا منكم
