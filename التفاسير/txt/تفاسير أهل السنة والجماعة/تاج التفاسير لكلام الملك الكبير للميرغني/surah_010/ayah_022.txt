( هو الذي يسيركم ) يحملكم على السير وقرئ ينشركم بالنون والشين من النشر ( في البر والبحر ) فضلا منه ( حتى إذا كنتم في الفلك ) السفن ( وجرين بهم ) بمن فيها ( بريح طيبة ) معتدلة ليست بسريعة مغرقة ولا بثقيلة مثبطة ( وفرحوا بها ) لاعتدالها ( جاءتها ريح عاصف ) شديدة يخشى منها الغرق ( وجاءهم الموج من كل مكان ) يتسلط منه الموج ( وظنوا أنهم أحيط بهم ) أهلكوا ولا خلاص ( دعوا الله مخلصين له الدين ) أنهم لا يعصونه قائلين ( لئن أنجيتنا من هذه ) الواقعة ( لنكونن من الشاكرين ) المؤمنين الطائعين
