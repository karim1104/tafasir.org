( وإذا مس الإنسان الضر ) المرض والبلاء ( دعانا ) لرفعه ( لجنبه ) مضطجعا ( أو قاعدا أو قائما ) في جميع أحواله ( فلما كشفنا عنه ضره ) رفعنا عنه البلاء ( مر ) مضى مستمرا في كفره ( كأن لم يدعنا ) أي كأنه لم يدعنا ( إلى ضر مسه ) إلى كشف ما نزل به من الضر ( كذلك ) مثل ذلك التزيين ( زين للمسرفين ما كانوا يعملون ) انهماكهم في شهواتهم وإعراضهم عن الله
