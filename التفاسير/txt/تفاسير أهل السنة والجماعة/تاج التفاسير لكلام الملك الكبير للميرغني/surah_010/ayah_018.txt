( ويعبدون من دون الله ) أي غيره ( ما لا يضرهم ) ما لا يدفع عنهم ضرا ( ولا ينفعهم ) ولا يجلب لهم نفعا ( ويقولون هؤلاء ) الأصنام ( شفعاؤنا عند الله ) تشفع لنا لديه ( قل أتنبئون الله ) تخبرونه ( بما لا يعلم ) وهو أن له شريكا ( في السموات ولا في الأرض ) وكل ما فيهما حادث مخلوق لله ( سبحانه ) تنزه ( وتعالى ) تعاظم ( عما يشركون ) عن إشراكهم
