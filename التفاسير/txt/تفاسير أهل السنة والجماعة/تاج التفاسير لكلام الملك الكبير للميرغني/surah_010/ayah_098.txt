( فلولا ) فهلا ( كانت قرية آمنت ) آمن أهلها قبل نزول العذاب بهم ( فنفعها إيمانها ) قبل إيمان أهلها وكشف عنهم العذاب ( إلا قوم يونس ) لكن قوم يونس ( لما آمنوا ) عند رؤية أمارة العذاب ولم يؤخروا إلى حلوله ( كشفنا عنهم عذاب الخزي في الحياة الدنيا ) وذلك أنهم لما رأوا العذاب لبسوا المسوح وبرزوا إلى الصعيد وعجوا وأخلصوا التوبة وأظهروا الإيمان وتضرعوا بعد أن رأوا غيما أسود ذا دخان شديد فرفع عنهم ( ومتعناهم إلى حين ) إلى انقضاء آجالهم
