{ إن تكفروا } تشركوا بالله { فإن الله } الغني بذاته { عني عنكم } وعن إيمانكم به { ولا يرضى لعباده } الذين اختارهم واصطفاهم له { الكفر } وإن أراده لبعض من سبقت له الشقاوة نعوذ بالله { وإن تشكروا } لخالقكم وتؤمنوا به { يرضه لكم } لأن به فلا حكم ويثبكم عليه وقرئ بإشباع ضمة الهاء وبإسكانها { ولا تزر } نفس { وازرة } حاملة وزرا { وزر } نفس { أخرى } فتحمله عنها بل كل إنسان يحمل ذنبه { ثم إلى ربكم مرجعكم } أي معادكم إليه { فينبئكم } فيخبركم بمحاسبته { بما كنتم تعملون } فيجد كل احد ما قدمه { إنه عليم } خبير { بذات الصدور } بما تنطوي عليه
