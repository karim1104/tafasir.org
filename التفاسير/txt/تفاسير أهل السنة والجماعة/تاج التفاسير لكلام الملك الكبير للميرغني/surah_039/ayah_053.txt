{ قل } أيها النبي الرحمة الكاملة والرأفة الشاملة { يا عبادي } المؤمنين { الذين أسرفوا } أفرطوا بالإسراف في المعاصي { على أنفسهم } فخافوا من بطشه { لا تقنطوا } لا تيئسوا وقرئ بالكسر { من رحمة الله } أي مغفرته { إن الله يغفر الذنوب جميعا } لعبده المؤمن ما عدا الشرك لقوله تعالى إن الله لا يغفر أن يشرك به أو يغفر الذنوب جميعا حتى الشرك لمن أسلم وقد قال صلى الله عليه وسلم الإسلام يجب ما قبله { إنه هو الغفور } لمن تاب إليه { الرحيم } بمن أقبل عليه وفي الحديث أن رسول الله صلى الله عليه وسلم قال ما أحب أن لي الدنيا وما فيها بهذه الآية قل يا عبادي الذين أسرفوا الآية
