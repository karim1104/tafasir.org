{ يا أيها الناس } المدبرون عن الله المشركون به { ضرب مثل } بين لكم الأمر { فاستمعوا له } متدبرين متفكرين { إن الذين تدعون } تعبدون { من دون الله } أي غيره وهم الأصنام { لن يخلقوا ذبابا } لا يقدرون على خلقه { ولو اجتمعوا له } لخلقه { وإن يسلبهم الذباب شيئا } مما عليهم من الطيب والزعفران قال ابن عباس رضي الله عنهما كانوا يلوثون الأصنام بالزعفران ورءوسها بالعسل ويغلقون عليها الأبواب فيدخل الذباب فيأكلها { لا يستنقذوه منه } لا يمنعون من ذلك ولا يستخلصوه { ضعف الطالب } عابدها { والمطلوب } الأصنام المعبودة
