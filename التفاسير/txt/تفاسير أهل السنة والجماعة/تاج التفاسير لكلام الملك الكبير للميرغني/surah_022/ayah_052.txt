{ وما أرسلنا من قبلك من رسول } نبي أمر التبليغ { ولا نبي } لم يؤمر بالتبليغ { إلا إذا تمنى } صور في نفسه ما يهواه { ألقى الشيطان في أمنيته } في تشهيه ما يوجب اشتغاله بما هو دون مقامه وفي الحديث إنه ليغان على قلبي فأستغفر الله في اليوم سبعين مرة قال الشاذلي رأيت النبي صلى الله عليه وسلم فسألته عن الغين الذي هو في هذا الحديث فقال غين أسرار وأنوار لا غين أغيار وأكدار { فينسخ الله ما يلقي الشيطان } بعصمة ذلك النبي { ثم يحكم الله آياته } فيستغرق في أوقاته شغلا بالله { والله عليم } بمن يصلح لهذه المقامات { حكيم } بإعطائها لمستحقها
