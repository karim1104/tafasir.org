( إن أحسنتم أحسنتم لأنفسكم ) لعود منفعة ذلك عليكم ( فإذا جاء وعد الآخرة ) وعد العقوبة المرة الآخرة بعثناهم عليكم ( ليسئوا وجوهكم ) يحزنوكم بالقتل والسبي ( وليدخلوا المسجد ) بيت المقدس فيخربوه ( كما دخلوه أول مرة ) وخربوه ( وليتبروا ) يهلكوا ( ما علوا ) ما غلبوا عليه ( تتبيرا ) هلاكا وقد وقع ذلك حين قتلوا يحيي تسلط عليهم بختنصر فقتلهم وسبى ذراريهم وخرب بيت المقدس
