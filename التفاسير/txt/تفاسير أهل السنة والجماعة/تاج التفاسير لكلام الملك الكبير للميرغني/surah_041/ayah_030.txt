{ إن الذين قالوا ربنا الله } أذعنوا لله بالتوحيد { ثم استقاموا } على النهج القويم والطريق المستقيم { تتنزل عليهم الملائكة } عند النزع تقول لهم { ألا تخافوا } من سيئاتكم { ولا تحزنوا } على ما خلفتم وراءكم من أبنائكم فالله ولي الصالحين من بعدهم على أولادهم { وأبشروا بالجنة } دخولا وسكنى { التي كنتم توعدون } أي التي بشركم بها المرسلون { إن الذين قالوا } من الأولياء { ربنا الله ثم استقاموا } وفتنوا في كمال الفناء فيه على حقوق العبودية { تتنزل عليهم } من حضرة الحق { الملائكة } فتبشرهم تقول لهم في قلوبهم { ألا تخافوا } من الحجاب عن شهود الملك الوهاب { ولا تحزنوا } ولا ينالكم حزن ببعض تقصيركم بفوات بعض درجات الكمال { وأبشروا بالجنة } جنة الشهود { التي كنتم توعدون } حين كنتم مريدين على لسان شيوخكم أولياء المعبود
