{ ولا تستوي الحسنة } عند الله { ولا السيئة } فالأولى جزاؤها الثواب والثانية جزاؤها العقاب { ادفع } أيها النبي المتخلق بأخلاقنا { بالتي هي أحسن } بالحسنة السيئة فقابل المسيئين بالصفح عنهم { فإذا الذي بينك وبينه عداوة } إذا فعلت ذلك { كأنه ولي } صديق لك { حميم } قريب وفي الحديث قال رسول الله صلى الله عليه وسلم وأتبع السيئة الحسنة تمحها وخالق الناس بخلق حسن
