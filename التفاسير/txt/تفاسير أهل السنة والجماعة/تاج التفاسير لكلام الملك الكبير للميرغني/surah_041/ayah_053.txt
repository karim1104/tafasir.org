{ سنريهم آياتنا } من الأمور التي وعدهم بها نبينا ومن باب الإشارة لأهل الذوق وأنوارنا القدسية { في الآفاق } من الحوادث الموعود بها وأنوارنا المشرقة فيها { وفي أنفسهم } ما أخبرهم به صلى الله عليه وسلم في أنفسهم كفتح مكة واستغراق أهل الحال في أنوارنا السرمدية { حتى يتبين لهم أنه } أي القرآن أو الرسول { الحق } أو ما عمر الوجود إلا نور الحق { أو لم يكف بربك } أي لم تحصل الكفاية به { أنه على كل شيء شهيد } مما ينكرونه
