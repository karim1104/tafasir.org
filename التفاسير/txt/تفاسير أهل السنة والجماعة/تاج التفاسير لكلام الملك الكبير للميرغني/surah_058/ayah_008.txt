{ ألم تر } تنظر { إلى الذين نهوا } نهاهم النبي صلى الله عليه وسلم { عن النجوى } نزلت في اليهود والمنافقين  ، كانوا يتناجون فيما بينهم ويتغامزون إذا رأوا المؤمنين وينظرون إليهم ليوقعوا في قلوبهم ريبا  ، { ثم يعودون } إلى النجوى ولذا قال { لما نهوا عنه } من التناجي  ، { ويتناجون } أي مناجاتهم بينهم { بالإثم } والمعصية  ، { والعدوان } والعداوة للمؤمنين { ومعصية الرسول } وارتكاب ما نهاهم عنه ،  وقريء ينتجون كيقتتلون  ، { وإذا جاءوك } أيها الرسول { حيوك } في تحيتهم { بما لم يحيك به الله }  ، وقولهم السام عليك أي الموت  ، والله يقول  :{ وسلام على عباده الذين اصطفى  } ، { ويقولون } أعداء الله { في أنفسهم لولا } هلا { يعذبنا الله بما نقول } إن كان نبينا  ، { حسبهم جهنم } عذابا وعقابا { يصلونها } يدخلونها  ، { فبئس المصير } لهم جهنم  .
