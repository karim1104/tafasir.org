( ومن لم يستطع منكم طولا ) يجد قدرة وغنى ( أن ينكح المحصنات ) أي يتزوج بالحرائر ( المؤمنات فمن ما ملكت أيمانكم ) أي يتزوج ( من فتياتكم المؤمنات ) الإيماء ( والله أعلم بإيمانكم ) فيكفيكم ظاهر الإيمان فإن علم السرائر موكول إليه وأمر التفاضل هو أعلم به فربما فضلت أمة حرة وفي الآية تأنيس للناكحين للإماء ( بعضكم من بعض ) أنتم وهن من أولاد آدم والإيمان جامعكم ( فانكحوهن ) الضمير للفتيات ( بإذن أهلن ) أي أخطبوهن من مواليهن ( وآتوهن ) أعطوهن ( أجورهن ) الصداق ( بالمعروف ) من غير نقصان ولا مطل ( محصنات ) متعففات ( غير مسافحات ) أي غير مجاهرات بزنا ( ولا متخذات أخدان ) أخلاء في السر يزنون بهن ( فإذا أحصن ) بالنكاح وقرئ بالبناء للفاعل ( فإن أتين بفاحشة ) ارتكبن زنا ( فعليهن ) أي الإماء ( نصف ما على المحصنات ) أي الحرائر ( من العذاب ) من الحد فتحد الأمة والعبد خمسين ويغربان نصف سنة ولا رجم عليهما ( ذلك ) تزويج الإماء ( لمن خشي ) خاف ( العنت ) الزنا ( منكم ) معشر المؤمنين ( وأن تصبروا ) عن نكاح الإماء ( خير لكم ) لئلا تسترق أولادكم ( والله غفور ) لمن لم يقدر على الصبر ( رحيم ) بترخيصه له في ذلك
