( ستجدون آخرين ) وهم أسد وغطفان ( يريدون أن يأمنوكم ) ويظهروا لكم الإيمان ( ويأمنوا قومهم ) ويظهروا لهم الكفر إذا عادوا إليهم ( كلما ردوا ) دعوا ( إلى الفتنة ) الكفر وقتال المسلمين ( أركسوا ) عادوا ( فيها ) إليها بأشد من حالهم الأول ( فإن لم يعتزلوكم ) لم يتركوا قتالكم ( ويلقوا إليكم السلم ) وينبذوا إليكم العهد ( ويكفوا أيديهم ) عن مقاتلكم ( فخذوهم ) أسرى ( واقتلوهم ) لخبث نيتهم وفعلهم ( حيث ثقفتموهم ) أي حيث تمكنتم منهم ( وأولئكم ) المنافقون ( جعلنا لكم عليهم ) أيها المؤمنون ( سلطانا مبينا ) أي حجة بينة على قتلهم وأسرهم
