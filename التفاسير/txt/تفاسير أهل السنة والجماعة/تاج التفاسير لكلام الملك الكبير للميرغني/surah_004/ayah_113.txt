( ولولا فضل الله عليك ) أيها النبي الكريم بعصمته لك والتأييد والتكريم ( ورحمته ) التي أقامك بها على المنهج القويم ( لهمت طائفة منهم ) من أهل الباطل الذميم ( أن يضلوك ) لتلبيسهم لك الحق بالباطل ( وما يضلون إلا أنفسهم ) الخبيثة المائلة إلى السوء ( وما يضرونك من شيء ) لأنك لم تمل إلى الباطل إنما ملت إلى الحكم بالظاهر( وأنزل عليك ) يا محبوبه الكامل الفطنة ( الكتاب والحكمة ) وجعلك مظهر أحكامه الحقية وأوامره الصدقية ( وعلمك ما لم تكن تعلم ) من العوم الشرعية والأسرار الفردية ( وكان فضل الله عليك ) يا مصطفاه ( عظيما ) فزادك بما حباك تكريما وتفخيما
