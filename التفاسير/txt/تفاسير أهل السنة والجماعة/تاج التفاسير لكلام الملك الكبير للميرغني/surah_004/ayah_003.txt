( وإن خفتم ) خشيتم ( أن لا تقسطوا ) تعدلوا ( في اليتامى ) وتركتم أكل أموالهم خوفا من الله ( فانكحوا ) تزوجوا أي كما تحرجتم من أكل مال اليتيم فتحرجوا من عدم العدل بين النساء إذا تزوجتموهن ثم ذكر القدر الذي يحل بقوله ( ما طاب لكم من النساء ) غير المحرمات وهو ( مثنى ) اثنتان اثنتان ( وثلاث ) ثلاث ثلاث ( ورباع ) أربع أربع ( فإن خفتم ) الله وعلمتم ( ألا تعدلوا ) بين النساء إذا تزوجتم اثنتين أو ثلاثا أو أربعا ( فواحدة ) تزوجوا ( أو ما ملكت أيمانكم ) واكتفوا بالتسري إذا خشيتم من عدم الوفاء بحقوق النساء ( ذلك ) أخذ الواحدة والتسري ( أدنى ) أقرب لكم إلى ( أن لا تعولوا ) تميلوا
