( لكن الراسخون ) البالغون الحقيقة ( في العلم منهم ) كابن سلام ( والمؤمنين ) من المهاجرين والأنصار ( يؤمنون بما أنزل إليك ) من الأحكام ( وما أنزل من قبلك ) من الكتب ( والمقيمين ) وقرئ بالرفع ( الصلاة ) المتمين بأركانها ( والمؤتون الزكاة ) على حقيقتها ( والمؤمنون بالله واليوم الآخر ) فيعملون له ( أولئك سنؤتيهم ) وقرئ بالياء ( أجرا عظيما ) الجنة وما أعد فيها من الدرجات العلا
