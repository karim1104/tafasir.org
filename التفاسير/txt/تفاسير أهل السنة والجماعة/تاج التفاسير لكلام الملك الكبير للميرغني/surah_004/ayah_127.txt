( ويستفتونك في النساء ) أي في حكم ميراثهن ( قل الله يفتيكم فيهن ) وميراثهن ( وما يتلى عليكم في الكتاب ) القرآن ( في يتامى النساء ) أي في النساء اليتيمات ( اللاتي لا تؤتونهن ) في الميراث ( ما كتب لهن ) فرض لهن ( وترغبون ) أيها الأولياء لهم ( أن تنكحوهن ) إن كن جميلات لتأكلوا أموالهن أو تعضلوهن طمعا في أكل أموالهن ( والمستضعفين ) الصغار ( من الولدان ) فالكل من المستضعفين والنساء أعطوهم ميراثهم ( وأن تقوموا لليتامى ) في أمر ميراثهن ومهرهن ( بالقسط ) بالعدل ( وما تفعلوا ) معهن ( من خير ) قل أو أكثر ( فإن الله كان به عليما ) فيجازيكم عليه
