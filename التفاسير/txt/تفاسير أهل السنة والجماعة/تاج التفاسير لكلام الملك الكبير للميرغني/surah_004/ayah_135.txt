( يا أيها الذين آمنوا كونوا قوامين ) أي قائمين ( بالقسط ) بالعدل ( شهداء لله ) بما في ذمتكم ( ولو على أنفسكم ) كانت شهادتكم فأقروا ولا تكتموا ( أو الوالدين والأقربين ) أي كذلك ولو كانت عليهما فاشهدوا ( إن يكن ) من تشهدون عليه ( غنيا ) ذا ثروة ( أو فقيرا ) مسكينا ( فالله أولى بهما ) وأعلم بما يصلحهما ( فلا تتبعوا الهوى ) فتجوروا في الشهادة ( أن تعدلوا ) أي تميلوا عن الحق ( وإن تلووا ) تغيروا الشهادة وقرئ وإن تلوا بحذف الواو تخفيفا ( أو تعرضوا ) تجحدوها وتكتموها ( فإن الله كان بما تعلمون خبيرا ) فيجازيكم على ذلك وفي معجم الطبراني الكبير أن رسول الله صلى الله عليه وسلم قال من كتم شهادة إذا دعي إليها كان كمن شهد بالزور
