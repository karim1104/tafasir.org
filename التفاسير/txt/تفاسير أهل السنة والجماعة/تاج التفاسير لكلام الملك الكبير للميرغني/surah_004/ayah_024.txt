( والمحصنات ) أي حرمت عليكم المتزوجات ( من النساء ) أي تنكحوهن ما لم يفارقهن أزواجهن سواء كن حرائر مسلمات أم لا ( إلا ما ملكت أيمانكم ) من الإماء المسبيات ولو كان لهن أزواج كفار فيحل لكم بعد الاستبراء وطؤهن ( كتاب الله ) كتب ( عليكم ) فيه تحريم ذلك وقرئ كتب الله بالجمع والرفع وكتب الله بلفظ الفعل ( وأحل لكم ) وقرئ بالبناء للمفعول ( ما رواء ذلكم ) أي ما سوى المحرمات المذكورة ( أن تبتغوا ) من نسائكم ( بأموالكم ) سواء بثمن أو بصداق ( محصنين ) متزوجين ( غير مسافحين ) فاعلين زنا ( فما استمتعتم ) أي فمن تمتعتم ( به منهن ) من عقد عليهن أو جماع ( فآتوهن أجورهن ) مهورهن التي استبحتم بها فروجهن ( فريضة ) عليكم ( ولا جناح عليكم فيما تراضيتم ) أنتم وأزواجكم ( به من بعد الفريضة ) سواء كان بحط بعضها أو زيادة عليها أو حطها كلها ( إن الله كان عليما ) بما هو أصلح لكم ( حكيما ) فيما أوجبه عليكم
