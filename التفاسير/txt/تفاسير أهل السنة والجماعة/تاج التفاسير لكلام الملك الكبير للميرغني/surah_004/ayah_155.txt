( فبما نقضهم ) أي فبنقضهم وما مؤكدة ( ميثاقهم ) أي عهدهم ذلك ( وكفرهم بآيات الله ) أي بما في الكتب ( وقتلهم الأنبياء بغير حق ) بغير وجه يوجب القتل ( وقولهم ) لنبينا محمد صلى الله عليه وسلم ( قلوبنا غلف ) مغطاة لا تعي ما تقول ( بل طبع ) ختم ( الله عليها بكفرهم ) فلا تعي ما ينفعهم ( فلا يؤمنون إلا قليلا ) كعبد الله بن سلام ومن أسلم منهم
