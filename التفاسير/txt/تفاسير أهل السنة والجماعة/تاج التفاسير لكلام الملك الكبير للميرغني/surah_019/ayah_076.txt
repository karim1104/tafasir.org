{ ويزيد الله الذين اهتدوا } بالإيمان { هدى } يقينا يوليهم إياه { والباقيات الصالحات } من الأعمال { خير عند ربك ثوابا } للأجر { وخير مردا } مرجعا في الحديث قال صلى الله عليه وسلم خذوا جنتكم من النار قولوا سبحان الله والحمد لله ولا إله إلا الله والله أكبر فإنهن يأتين يوم القيامة مقدمات ومعقبات ومجنبات وهن الباقيات الصالحات رواه النسائي والحاكم
