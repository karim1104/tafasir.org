ثم قال للرسول { ارجع إليهم } بهديتهم { فلنأتينهم بجنود لا قبل طاقة لهم بها بمدافعتهم لها وقرئ بهم { ولنخرجنهم منها } من بلدهم سبأ سميت البلد باسم القبيلة { أذلة وهم صاغرون } مهانون إن لم يأتوني مسلمين فلما جاءها رسولها وأخبرها بذلك جعلت سريرها جوف سبعة قصور كل قصر له باب مغلقة الأبواب وجعلت عليها حرسا ومضت إليه في اثني عشر ألف قيل تحت يد كل قيل ألوف كثيرة
