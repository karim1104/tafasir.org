{ إنا أنذرناكم } يا معشر الكفار { عذابا } أي عذاب يوم القيامة { قريبا } وكل آت قريب { يوم ينظر } أي يرى { المرء } أي كل امرئ { ما قدمت يداه } أي ما قدمه { ويقول الكافر } حينما يقول الله للبهائم بعد أخذ القصاص لها من بعضها بعضا كوني ترابا { يا ليتني كنت ترابا } أي يتمنى أن يكون ترابا مثلها فيستريح من العذاب ولا يجد ذلك .
