( ومن الذين قالوا إنا نصارى ) الحكاية عن النصارى ( أخذنا ) على يد عسى ( ميثاقهم ) بأن يؤمنوا بك يا نبينا يا محمد ( فنسوا حظا ) تركوه ( مما ذكروا به ) من الإيمان بك ( فأغرينا ) فألقينا ( بينهم العداوة ) أي بين اليهود والنصارى ( والبغضاء ) يبغض بعضهم بعضا ( إلى يوم القيامة ) فلا يتفقون أبدا ( وسوف ينبئهم الله ) إذا وقفوا بين يديه ( بما كانوا يصنعون ) من سوء المعاملة فيعاقبهم
