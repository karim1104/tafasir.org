( إن الذين آمنوا ) بالله ورسوله ( والذين هادوا ) اليهود ( والصابئون ) وقرئ والصابئين وقرئ والصابيون بقلب الهمزة ياء والصابون بحذفها وهم فرقة من اليهود والنصارى ( والنصارى ) قوم عيسى ( من آمن بالله واليوم الآخر ) واجتهد فيما ينجيه منهم ( وعمل صالحا ) أحسن عمله بالإخلاص ( فلا خوف ) عليهم في دنياهم ( ولا هم يحزنون ) في آخرتهم
