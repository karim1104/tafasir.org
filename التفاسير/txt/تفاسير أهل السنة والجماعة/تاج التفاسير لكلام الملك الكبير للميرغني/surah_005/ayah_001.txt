بسم الله الرحمن الرحيم

( بسم الله الرحمن الرحيم يا أيها الذين آمنوا ) بالله ورسوله ( أوفوا بالعقود ) العهود التي بينكم وبين ربكم وكذا عهودكم مع الناس ( أحلت لكم ) فضلا من الله ( بهيمة الأنعام ) فكلوها بعد الذبح وهي الإبل والبقر والغنم ( إلا ما يتلى عليكم ) وتعرفوا تحريمه في { حرمت عليكم الميتة } الآية ( غير محلي الصيد وأنتم حرم ) أي حالة إحرامكم ( إن الله يحكم ما يريد ) فيحلل ما شاء تحليله ويحرم ما شاء تحريمه
