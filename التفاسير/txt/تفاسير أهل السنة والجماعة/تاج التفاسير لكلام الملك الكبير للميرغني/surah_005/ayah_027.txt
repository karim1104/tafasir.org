( واتل عليهم ) اقصص عليهم ( نبأ ) خبر ( ابني آدم بالحق ) قابيل وهابيل ( إذ قربا قربانا ) إلى الله وكان قربان هابيل كبشا وقربان قابيل زرعا ( فتقبل ) فتقبل الله ( من أحدهما ) وهو هابيل بما كان يتقبل به القربان قبل ذلك وهو إنزال النار من السماء تأكله ( ولم يتقبل من الآخر ) أي لم يقبل الله من الآخر القربان وهو قابيل ( قال ) قابيل عند ذلك لأخيه هابيل ( لأقتلنك ) لقبول قربانك وعدم قبول قرباني ( قال ) له هابيل ( إنما يتقبل الله من المتقين ) المتحققين بتقواه ومن التقوى قوله
