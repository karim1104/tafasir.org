( وذر ) واترك ( الذين اتخذوا دينهم ) الذي هو عين سبيل نجاتهم ( لعبا ولهوا ) تشهيا وأماني فاسدة ( وغرتهم الحياة الدنيا ) ولذاتها وما علموا أنها دار زوال ولا يعتمد على زهرتها إلا خلي من العقل وعنه صلى الله عليه وسلم الدنيا دار من لا دار له ومال من لا مال له ولها يجمع من لا عقل له رواه أحمد ( وذكر به ) أي بالقرآن ( أن تبسل نفس بما كسبت ) خشية أن تسلم على الهلاك بما عملت ( ليس لها من دون الله ) من غيره ( ولي ) ينصرها ( ولا شفيع ) من عذاب الله يمنعها ( وإن تعدل كل عدل ) وإن تفد كل فداء ( لا يؤخذ منها ) لا يقبل منها ولو كانت الدنيا بحذافيرها ( أولئك ) الخائضون هم ( الذين أبسلوا ) أسلموا على العذاب ( بما كسبوا ) من السيئات ( لهم شراب من حميم ) ماء حار ( وعذاب أليم ) يا لألمه من شدة ( بما كنوا يكفرون ) أي بسبب كفرهم
