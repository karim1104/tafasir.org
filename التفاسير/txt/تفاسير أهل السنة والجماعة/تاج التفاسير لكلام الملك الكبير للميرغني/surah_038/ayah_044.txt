{ وخذ بيدك } تكفيرا ليمينك وكان قد حلف ليضربن امرأته ليا بنت يعقوب مائة جلدة حين أرسلها وهو في مرضه فأبطأت عليه فقال له الحق خذ بيدك { ضغثا } وهو حزمة حشيش { فاضرب به } امرأتك مرة واحدة { ولا تحنث } فتفكر عن يمينك { إنا وجدناه } أيوب { صابرا } على بلوانا { نعم العبد } المتحقق بالعبودية لصبره على ما حدث من حضرة الربوبية وفي الحديث قال رسول الله صلى الله عليه وسلم الصبر من الإيمان بمنزلة الرأس من الجسد { إنه } إلى تجليات الله الكمالية { أواب } رجاع إليها بالكلية قد شغله شهود الجمال عن رؤية ألم البلاء والاعتلال
