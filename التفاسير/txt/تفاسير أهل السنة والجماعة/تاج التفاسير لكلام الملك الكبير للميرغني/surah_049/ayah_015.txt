{ إنما المؤمنون } الجامعون مع الانقياد ظاهر التصديق بالباطن { الذين آمنوا بالله ورسوله } ظاهرا وباطنا { ثم لم يرتابوا } لم يشكوا فيما جاءهم من عند الله ورسوله { وجاهدوا } لابتغاء مرضاة الله { بأموالهم وأنفسهم } ويذلوا أنفيهم وأموالهم { في سبيل الله } طاعته ومحبته { أولئك هم الصادقون } في ادعائهم الإيمان ولما نزلت الآيتان جاءت الأعراب إلى النبي صلى الله عليه وسلم وحلفوا بالله أنهم مؤمنون والله عالم منهم خلاف ذلك فأنزل
