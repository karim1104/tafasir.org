{ يا أيها الذين آمنوا إذا جاءكم } قدم إليكم { فاسق بنبأ } بخبر { فتنيبوا } فتعرفوا صدق ما يخبركم به من كذبه وقرئ فتثبتوا روى أن النبي صلى الله عليه وسلم بعث الوليد بن عقبة مصدقا إلى قوم وكان بينه وبينهم في الجاهلية شيء فرجع وقال إنهم منعوني الصدقة وهموا بقتلي فهم رسول الله صلى الله عليه وسلم بغزوهم فظهر خلاف ما أخبر الوليد وذلك أنه صلى الله عليه وسلم أر سل خالد ابن الوليد لهم فسلموا إليه الصدقة { أن تصيبوا } أي خوف أن تصيبوا { قوما } مطيعين { بجهالة } أي جاهلين بحالهم { فتصبحوا } تصيروا على ما فعلتم } من إصابة القوم بالخطأ { نادمين } مغتنمين
