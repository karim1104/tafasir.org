( ألم يأتهم نبأ ) خبر ( الذين من قبلهم ) من الأمم ( قوم نوح ) أغرقوا بالطوفان ( وعاد ) قوم هود أخذوا بالريح العقيم ( وثمود ) قوم صالح دمروا بالصحية ( وقوم إبراهيم ) أهلك النمروذ ببعوضة وأخذ قومه ( وأصحاب مدين ) قوم شعيب نزلت بهم نار الظلة فدمرتهم ( والمؤتفكات ) أهل قرى لوط أمطرت عليهم حجارة من سجيل فأهلكتهم ( أتتهم ) هؤلاء الأمم المعدودة ( رسلهم بالبينات ) كل رسول إلى أمته بمعجزات واضحات فكذبوهم فأهلكوا ( فما كان الله ليظلمهم ) ليعذبهم بغير جرم ولا إنذار رسل ( ولكن كانوا أنفسهم يظلمون ) بتكذيب الرسل ومخالفة الحق
