( كالذين من قبلكم ) من أهل النفاق والكفر عملتم ( كانوا أشد منكم قوة ) في أجسامهم ( وأكثر أموالا وأولادا ) منكم ( فاستمتعوا ) تمتعوا ( بخلاقهم ) بما نالوه من دنياهم ( فاستمتعتم ) أيها المنافقون ( بخلاقكم ) زخارفكم الدنيوية ( كما استمتع الذين من قبلكم بخلاقهم ) واغتروا به ( وخضتم ) في الباطل ( كالذي خاضوا ) نحو خوضهم ( أولئك حبطت ) بطلت ( أعمالهم في الدنيا والآخرة ) فلم يثابوا عليها ( وأولئك هم الخاسرون ) الذين خسروا أنفسهم بإدخالها النار
