( ألا تقاتلون قوما ) تحريض على القتال ( نكثوا ) نقضوا ( أيمانهم ) التي عاهدوا عليها ( وهموا بإخراج الرسول ) صلى الله عليه وسلم من مكة حين تشاوروا في أمره بدار الندوة كما مر في سورة الأنفال في قوله تعالى : { وإذ يمكر بك الذين كفروا } الآية ( وهم بدءوكم ) بالقتال ( أول مرة ) حين قاتلوا حلفاءكم خزاعة ( أتخشونهم ) تخافون أن تقاتلوهم ( فالله أحق أن تخشوه ) في ترك قتالهم ( إن كنتم مؤمنين ) فالمؤمن لا يخشى إلا الله
