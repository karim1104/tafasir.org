( والذين اتخذوا مسجدا ) وهم جماعة من المنافقين وقرئ بغير واو ( ضرارا ) مضارة لمسجد قباء ( وكفرا ) تقوية لما يضمرونه من الكفر ( وتفريقا بين المؤمنين ) الذين كانوا يجتمعون في مسجد قباء ( وإرصادا ) ترقبا ( لمن حارب الله ورسوله من قبل ) وهو أبو عامر الراهب ( وليحلفن ) لكم ( إن أردنا ) ما أردنا ببنائه ( إلا الحسنى ) الفعلة الطيبة الحسنة وهي التوسعة على المسلمين ووقاية الحر والمطر لهم ( والله يشهد إنهم لكاذبون ) في حلفهم
