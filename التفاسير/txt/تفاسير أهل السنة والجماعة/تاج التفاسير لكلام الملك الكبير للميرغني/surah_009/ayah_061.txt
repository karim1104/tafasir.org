( ومنهم ) أي المنافقين ( الذين يؤذون النبي ) بعيبه وبثقل حديثه ( ويقولون هو أذن ) أي يسمع القول في الناس ويقبله ( قل أذن خير لكم ) أي هو أذن يسمع الخير لا الشر ( يؤمن بالله ) يصدق به ( ويؤمن للمؤمنين ) أي يصدقهم ( ورحمة ) وقرئ بالجر ( للذين آمنوا منكم ) ولجميع المؤمنين وهو عين الرحمة لكل العباد المؤمنين وفي الحديث مرفوعا إنما أنا رحمة مهداة رواه الحاكم ( والذين يؤذون رسول الله ) بأي وجه من وجوه الإيذاء ( لهم عذاب أليم ) مؤلم
