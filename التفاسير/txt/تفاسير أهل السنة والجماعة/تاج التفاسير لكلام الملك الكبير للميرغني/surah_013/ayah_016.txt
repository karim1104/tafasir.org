( قل من رب السموات والأرض ) خالقهما ومالكهما ( قل الله ) إن الله يقولوه ( قل أفاتخذتم من دونه ) أي غيره ( أولياء ) أصناما تعبدونها ( لا يملكون لأنفسهم نفعا ولا ضرا ) فكيف ينفعونكم أو يضرونكم فاعبدوا الله القادر على نفكم وضركم ( قل هل يستوي الأعمى ) الكافر ( والبصير ) المؤمن ( أم عل تستوي الظلمات ) الشرك ( والنور ) الإيمان لا يستوون قرئ بالياء ( أم جعلوا ) المشركون ( لله وشركاء ) في ملكه ( خلقوا كخلقه ) سبحانه ( فتشابه الخلق عليهم ) خلق الله وخلقهم فلذا اتخذتموهم شركاء لله وعبدتموهم والاستفهام هنا إنكاري أي ليس ذلك لهم فلماذا يعبدونهم ( قل الله خالق كل شيء ) منفرد بخلق الأشياء كلها مستحق أن يعبد فاعبدوه ( وهو الواحد ) المنفرد بالألوهية ( القهار ) الغالب على كل شيء
