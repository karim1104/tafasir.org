( له دعوة الحق ) كلمته ( والذين يدعون ) يعبدون وقرئ بالتاء ( من دونه ) غيره هم الأصنام ( لا يستجيبون لهم بشيء ) من طلبهم ( إلا ) استجابة ( كباسط ) أي كاستجابة باسط ( كفيه إلى الماء ) على شفير البئر يطلبه ( ليبلغ فاه ) ليصل إلى فيه بغير آلة ( وما هو ببالغه ) واصل إليه أبدا ( وما دعاء الكافرين إلا في ضلال ) في ضياع لا يجدون نتيجة لأمورهم كطالب الماء المذكور
