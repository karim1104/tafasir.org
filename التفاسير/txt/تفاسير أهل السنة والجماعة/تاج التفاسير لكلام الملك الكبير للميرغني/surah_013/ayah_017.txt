( وأنزل من السماء ) من السحاب ( ماء ) مطرا ( فسالت أودية ) أنهار ( بقدرها ) بمقدارها ( فاحتمل السيل ) رفع ( زبدا رابيا ) وهو ما على وجه الأرض من القذر ( ومما يوقدون ) وقرئ بالتاء ( عليه في النار ) يذيبونه بها من الذهب والفضة والحديد والنحاس ( ابتغاء ) طلب ( حلية ) زينة يتحلون بها ( أو متاع ) ينتفعون به من أوان وآلة حرب وحرث ( زبد مثله ) أي مثل زبد السيل وهو خبثه الذي ينفيه الكير ( كذلك يضرب الله الحق والباطل ) أي يضرب مثلهما ( فأما الزبد ) من السيل وخبث المعادن المذكورة ( فيذهب جفاء ) يرمي به وقرئ جفالا ( وأما ما ينفع الناس ) من الماء والمعادن ( فيمكث في الأرض ) ينتفع به ( كذلك ) يمحق ويذهب الباطل ويثبت الحق فكذلك ( يضرب الله الأمثال ) بينهما كإيضاح المشتبهات
