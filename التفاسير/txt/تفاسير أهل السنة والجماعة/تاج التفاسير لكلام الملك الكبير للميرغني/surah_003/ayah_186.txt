( لتبلون ) والله لتختبرن ( في أموالكم ) بالإنفاق والجوائح ( وأنفسكم ) بالعبادات وأنواع البلاء ( ولتسمعن من الذين أوتوا الكتاب ) التوراة والإنجيل ( من قبلكم ) وهم اليهود والنصارى ( ومن الذين أشركوا ) وهم كفار العرب ( أذى كثيرا ) من سب وطعن وإغراء ( وإن تصبروا ) على ذلك ( وتتقوا ) تخشوا الله ( فإن ذلك ) تحليكم بالصبر والتقوى ( من عزم الأمور ) التي يطلب العزم عليها
