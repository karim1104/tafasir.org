( فإن حاجوك ) خاصمك الكفار ( فقل ) لهم ( أسلمت وجهي لله ) وجهت وجهي له وسلمت نفسي ( ومن اتبعن ) كذلك وجه وجهه لله وسلم نفسه ( وقل للذين أوتوا الكتاب ) فكفروا به وأشركوا مع الحق كاليهود والنصارى ( والأميين ) المشركين ( أأسلمتم ) كما أسلمت ( فإن أسلموا ) وانقادوا للحق ( فقد اهتدوا ) إلى الصواب ( وإن تولوا ) عن الإسلام ( فإنما عليك البلاغ ) بتبليغ ما أمرت به إليهم ( والله بصير بالعباد ) فيجازيهم على ما عملوا والآية منسوخة بقوله تعالى ( وقاتلوهم حتى لا تكون فتنة ) .
