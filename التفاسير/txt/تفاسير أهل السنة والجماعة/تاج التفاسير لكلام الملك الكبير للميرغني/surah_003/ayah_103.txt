( واعتصموا ) تمسكوا ( بحبل الله ) الذي هو القرآن وفي الخبر قال رسول الله صلى الله عليه وسلم : القرآن حبل الله المتين ( جميعا ) مجتمعين عليه ( ولا تفرقوا ) عن الحق كما افترق أهل الضلال ( واذكروا نعمة الله ) التي تفضل الله بها ( عليكم ) أيها العباد ( إذ كنتم أعداء ) في الجاهلية ( فألف ) جمع ( بين قلوبكم ) بدينه القويم ( فأصبحتم ) فصرتم ( بنعمته ) التي معظمها الرسول صلى الله عليه وسلم ( إخوانا ) لله وفي الله ( وكنتم على شفا ) طرف ( حفرة من النار ) للكفر الذي كنتم فيه ( فأنقدكم ) أخرجكم ( منها ) بالإسلام ( كذلك ) مثل التبيين المذكور ( يبين الله لكم الآيات ) الدالة على جنابه ( لعلكم تهتدون ) إلى أكمل درجات الخير
