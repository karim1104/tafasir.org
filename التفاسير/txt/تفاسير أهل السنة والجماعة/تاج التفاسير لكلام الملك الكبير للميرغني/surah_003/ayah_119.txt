( ها أنتم أولاء ) يا معشر المؤمنين ( تحبونهم ) لصداقتهم وبعض قرابة بينكم وبينهم ( ولا يحبونكم ) لأنكم نازعتموهم في دينهم ( وتؤمنون بالكتاب كله ) أي الكتب المنزلة كلها من جملتها كتابهم وهم لا يؤمنون بكتابكم ( وإذا لقوكم ) في مجمع أو طريق أو خلوة ( قالوا آمنا ) نفاقا ( وإذا خلوا ) مع بعضهم بعضا أو وحدهم ( عضوا عليكم الأنامل ) أطراف أصابعهم ( من الغيظ ) تأسفا حيث لم يجدوا طريقا إلى مضرتكم ( قل ) لهم أيها النبي الكريم ( موتوا ) يا أعداء الله ( بغيظكم ) فإنكم لا تجدون نصرا على المؤمنين ولا ما يشفى غيظكم فيهم ( إن الله عليم بذات الصدور ) بما في الصدور فيعاقبكم على سوء سريرتكم
