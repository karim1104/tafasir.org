( ولا تؤمنوا ) تقروا وتظهروا إيمانكم ( إلا لمن تبع دينكم ) فإنه أرجى لقبول ذلك ( قل ) لهم أيها النبي الكريم ( إن الهدى ) الذي به النجاة ( هدى الله ) وهو الإسلام وغيره ضلال وظلام ( أن يؤتي ) يعطي ( أحد مثل ما أوتيتم ) من الحكمة والفضائل أي لا يعطى أحد ذلك إلا إذا تبع دينكم ( أو يحاجوكم ) أي يغلبكم المؤمنين ( عند ربكم ) يوم العرض عليه ( قل إن الفضل ) والعطاء الذي لا يحد ( بيد الله ) ليس يمنعه أحد ( يؤتيه ) يعطيه ( من يشاء ) فمن أين لكم حجره ( والله واسع ) عطاؤه للعباد ( عليم ) بمن يستحق ذلك العطاء .
