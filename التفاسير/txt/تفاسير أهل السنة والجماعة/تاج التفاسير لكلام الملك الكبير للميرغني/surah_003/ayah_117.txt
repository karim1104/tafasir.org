( مثل ما ينفقون ) أي صفة الشيء الذي ينفقونه الكفار ( في هذا الحياة الدنيا ) في معاداتهم للنبي صلى الله عليه وسلم وصدقاتهم ونحوها ( كمثل ريح فيها صر ) برد شديد ( أصابت ) تلك الريح ( حرث ) زرع ( قوم ظلموا أنفسهم ) بكفرهم وارتكابهم المعاصي ( فأهلكته ) فلم تنلهم منه منفعة وكذلك نفقات الكفار لا تنالهم منها منفعة ( وما ظلمهم الله ) جزاء نفقاتهم ( ولكن أنفسهم يظلمون ) لتضييعهم الإيمان الذي هو الأصل المرتب عليه الجزاء
