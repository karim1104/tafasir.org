( فلما وضعتها ) ولدتها ( قالت ) كالمستحسرة ( رب إني  وضعتها ) يا رب ( أنثى ) على خلاف ما كانت ترجو ( والله ) سبحانه ( أعلم بما وضعت )

أي بالشيء الذي وضعته وقرئ بضم التاء ( وليس الذكر كالأنثى ) لأن مرادها خدمة بيت المقدس والأنثى يعتريها بعض موانع كالحيض والنفاس ( وإني سميتها مريم ) ومعناه بلغتهم العابدة ( وإني أعيذها ) أجيرها وأحصنها ( بك ) يا حفيظ فاحفظها ( وذريتها ) أولادها ( من الشيطان الرجيم ) المطرود عن رحمتك ،  وفي الصحيحين أن رسول الله صلى الله عليه وسلم قال :  " ما من مولود يولد إلا مسه الشيطان حين يولد فيستهل صارخا إلا مريم وابنها "  .
