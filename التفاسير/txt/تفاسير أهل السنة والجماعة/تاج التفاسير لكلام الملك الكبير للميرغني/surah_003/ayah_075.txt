( ومن أهل الكتاب ) نزلت الآية في اليهود ( من إن تأمنه بقنطار ) مال كثير ( يؤده إليك ) كعبد الله بن سلام استودعه قرشي ألفا ومائتي أوقية ذهبا فأداها له وأوفى بالأمانة ( ومنهم من إن تأمنه بدينار ) تودع عنده دينارا أمانة  ككعب بن الأشرف ( لا يؤده إليك ) وذلك أنه استودعه قرشي ألفا دينارا فجحده إياه ( إلا مادمت ) مدة دوامك ( عليه قائما ) تطالبه فيك ( ذلك ) الترك لأداء الأمانة فعلوه ( بأنهم ) أي بسبب أنهم ( قالوا ) أعداء الله ( ليس علينا في ) أمر ( الأميين ) العرب ( سبيل ) إثم لأننا أهل كتاب وهم مخالفون لديننا ( ويقولون ) بدعواهم ما قالوه ( على الله الكذب ) لنسبتهم ذلك إليه ( وهم يعلمون ) أن الله لم يقله ولكنهم افتروا على الله .
