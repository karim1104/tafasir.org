( يا أيها الذين آمنوا ) المتحققون بالإيمان ( لا تكونوا ) في معاملاتكم ( كالذين كفروا ) بالله ورسوله ( وقالوا لإخوانهم ) في النسب ( إذا ضربوا في الأرض أو كانوا غزا لو كانوا عندنا ) أي ولم يخرجوا للقتال ( ما ماتوا وما قتلوا ) وذلك لعدم معرفتهم بأن ما قدره الله لا بد أن يكون ( ليجعل الله ) بقولهم ( ذلك حسرة في قلوبهم ) تحسرا على ما أصابهم ( والله يحي ويميت ) أي بيده الحياة والموت سواء خرجوا أو أقاموا ومن كتب عليه الموت أو القتل لا بد أن يصيبه ( والله بما تعملون بصير ) لا يخفى عليه شيء
