( يوم ) أي يوم القيامة ( تجد كل نفس ) مؤمنة كانت أو كافرة ( ما عملت ) في الدنيا ( من خير محضرا ) حاضرا ( وما عملت ) أي وما عملته ( من سوء ) أيضا حاضرا ( تود ) تحب وقرئ ودت ( لو أن بينها وبينه ) أي وبين عملها السوء ( أمدا بعيدا ) غاية في البعد طمعا أن لا يصل إليها

( ويحذركم الله ) يخوفكم ( نفسه ) فإن غضبه شديد فإياكم من هتك حرمه الموجبة لغضبه ( والله رءوف بالعباد ) ومن رأفته بهم أن نبههم على ذلك لما فيه من منافعهم .
