( إن تمسسكم ) تصبكم ( حسنة ) كغنيمة ونصر ( تسؤهم ) تغضبهم وتحزنهم ( وإن تصبكم سيئة ) كقحط أو هزيمة ( يفرحوا بها ) عليكم فإذا علمتم أنهم كذلك فامتنعوا من موالاتهم ( وإن تصبروا ) على عداوتهم ( وتتقوا ) الله باجتناب موالاتهم ( لا يضركم ) وقرئ لا يضركم بكسر الضاد المعجمة وسكون الراء ( كيدهم شيئا إن الله بما يعملون ) من عداوتكم ( محيط ) فيجازيهم عليه وقرئ تعملون بالتاء أي من صبركم على أذيتهم فيجازيكم
