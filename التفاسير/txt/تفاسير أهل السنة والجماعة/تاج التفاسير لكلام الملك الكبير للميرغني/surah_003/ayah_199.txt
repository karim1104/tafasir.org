( وإن من أهل الكتاب ) الكتب القديمة ( لمن يؤمن بالله ) كابن سلام والنجاشي ( وما أنزل إليكم ) أي يؤمنون بالقرآن ( وما أنزل إليهم ) أي يؤمنون بالتوراة والإنجيل ( خاشعين ) خاضعين متواضعين ( لا يشترون ) لا يستبدلون ( بآيات الله ثمنا قليلا ) فيحرفون الأحكام ووأصاف النبي التي فيها لبعض مصالح دنيوية لهم وحب رياسات ( أولئك ) الموصوفون ( لهم أجرهم ) جزاؤهم على عملهم ( عند ربهم ) مرتين كما قال تعالى فيهم في سورة القصص ( أولئك يؤتون أجرهم مرتين بما صبروا إن الله سريع الحساب ) يحاسب العباد في مدة يسيرة
