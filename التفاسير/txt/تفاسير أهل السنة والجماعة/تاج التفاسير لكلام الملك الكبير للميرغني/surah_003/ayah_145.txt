( وما كان لنفس ) أي نفس كانت ( أن تموت إلا بإذن الله ) بقضائه وإذنه لملك الموت أن يقبضها ( كتابا مؤجلا ) أي جعل الله للموت وقتا معينا لا يتقدم ولا يتأخر عنه ( ومن يرد ) بأعماله ( ثواب الدنيا ) ومنافعها ( نؤته منها ) القدر الذي قسمناه له وماله نصيب في الآخرة ( ومن يرد ) بأعماله ( ثواب الآخرة ) وجزاءها الذي لا يحصر ( نؤته منها ) حظا كبيرا ( وسنجزي الشاكرين ) لنعمائنا
