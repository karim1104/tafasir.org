( يا أيها الذين آمنوا ) الطالبين للتحقق بحقيقة الإيمان ( لا تتخذوا ) يا أحباء الله ( بطانة ) أحبابا تطلعونهم على ما في بطونكم ( من دونكم ) أي غيركم من المنافقين واليهود ( لا يألونكم خبالا ) لا يقصرون لكم في الفساد ( ودوا ) تمنوا ( ما عنتم ) عنتكم وهو شدة المضرة والمشقة عليكم ( قد بدت ) برزت ( البغضاء ) كرههم لكم ( من أفواههم ) بشتمهم لكم وغيبتهم ( وما تخفي ) تكن ( صدورهم ) من يغضكم وعداوتكم ( أكبر ) مما أبدوه ( وقد بينا لكم الآيات ) على شدة عداوتهم لكم ( إن كنتم تعقلون ) ما ذكرناه لكم من العلامات
