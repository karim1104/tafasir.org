{ أم } عاطفة { من هذا } مبتدأ وخبره { الذي } بدل من الخبر { هو جند لكم } صلة الموصول ،  أي أعوان لكم أيها المكذبون ،  { ينصركم } أي يتولى نصركم ،  فيرفع عنكم العذاب ،  { من دون } أي غير { الرحمن } لا ناصر لكم غيره ،  { إن } نافية { الكافرون } في إنكارهم هذا ،  { إلا في غرور } من إبليس ،  حيث ظنوا أنه لا ينزل بهم العذاب .
