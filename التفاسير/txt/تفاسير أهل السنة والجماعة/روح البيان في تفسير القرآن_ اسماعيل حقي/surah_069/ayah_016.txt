{ وانشقت السماء } وآسمان برشكافت ازطرف مجره. يعنى انفرجت لنزول الملائكة لامر عظيم أراده الله كما قال يوم تشقق السماء بالعمام ونزل الملائكة تنزيلا اوبسبب شدة ذلك اليوم وهو معطوف على وقعت { فهى } اى السماء { يومئذ } ظرف لقوله { واهية } ضعيفة مسترخية ساقطة القوة جدا كالغزل المنقوض بعدما كانت محكمة مستمسكة وان كانت قابلة للخرق والالتئام يقال وهى البناء يهى وهيا فهو واه اذا ضعف جدا قال فى القاموس وهى كوعى وولى تخرق وانشق واسترخى رباطه وفى المفردات الوهى شق فى الاديم والثوب ونحوهما.
