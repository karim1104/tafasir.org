{ كذب اصحاب الايكة المرسلين } اى شعيبا ومن قبله عليهم السلام. والايكة الغيضة التى تنبت ناعم الشجر كالسدر والادراك وهى غيضة بقرب مدين يسكنها طائفة فبعث الله اليهم شعيبا بعد بعثه الى مدين ولكن لما كان اخا مدين فى النسب قال تعالى ولما كان اجنيبا من اصحاب الايكة قال { اذ قال لهم شعيب } ولم يقل اخوهم شعيب وهو شعيب بن تويب بن مدين بن ابراهيم او ابن ميكيك بن يشجر بن مدين ابن ابراهيم وام ميكيك بنت لوط { ألا تتقون } آيا نمى ترسيد از عذاب حضرت بروردكار خودكه بدو شرط مى آريد { انى لكم رسول امين } بينكم وعلى الرسالة ايضا لا اطلب الاصلاح حالكم { فاتقوا الله وأطيعون } فيما أمركم به فان امرى امر عن الله واطاعتى اطاعة له فى الحقيقة { وما اسألكم } ونمى خواهيم ازشما { عليه } اى على اداء الرسالة والتبليغ المدلول عليه بقوله رسول { من اجر } ومكافأة { ان } ما { اجرى } ثواب عملى واجرة خدمتى { الا على رب العالمين } فان الفيض حسن التربية منه تعالى على الكل خصوصا على من كان مأمورا بامر من جانبه
