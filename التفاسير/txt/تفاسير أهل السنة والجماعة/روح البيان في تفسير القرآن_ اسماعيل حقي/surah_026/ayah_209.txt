{ وما اهلكنا من قرية } من القرى المهلكة { الا لها منذرون } قد انذروا اهلها.، قال فى كشف الاسرار جمع منذرين لان المراد بهم النبى واتباعه المظاهرون له { ذكرى } اى لاجل التذكير والموعظة والزام الحجة فمحلها النصب على العلة { وما كنا ظالمين } فنهلك غير الظالمين والتعبير عن ذلك بنفى الظالمية مع ان اهلاكهم قبل الانذار ليس بظلم اصلا على ما تقرر من قاعدة اهل السنة لبيان كمال نزاهته عن ذلك بتصويره بصورة ما يستحيل صدوره عنه من الظلم. وفى التأويلات النجمية { وما اهلكنا من قرية } اى من اهل قرية فالقرية الجسد الانسانى واهلها النفس والقلب والروح واهلاكهم بافساد استعدادهم الفطرى بترك المأمورات واتيان المنهيات { الا لها منذرون } بالالهامات الربانية { ذكرى } اى تذكرة من ربهم كما قال تعالى { وماكنا ظالمين } بان نضع العذاب فى غير موضعه او نضع الرحمة فى غير موضعها انتهى
