{ ومن } هركه { يدع } يعبد { مع الله الها آخر } افرادا او اشتراكا { لابرهان له به } اى بدعائه معه ذلك وبالفارسية هيج حجتى نيست بربر ستنده را بيرستش آن اله وهو صفة لازمة لا لها كقوله اذ لا يكون فى الآلهة ما يجوز ان يقوم عليه برهان اذ الباطل ليس له برهان جىء بها للتأكيد وبناء الحكم عليها تنبيها على ان الدين بمالا دليل عليه باطل فكيف بما شهدت بداهة العقول بخلافه { فانما حسابه عند ربه } فهو مجازى له على قدر ما يستحقه جواب يدع { انه لايفلح الكافرون } اى الشان لا ينجو من كفر من سوء الحساب والعذاب.
