{ ولا يملك } اى لا يقدر { الذين يدعون } اى يعبدهم الكفار { من دونه } تعالى { الشفاعة } عند الله كما يزعمون { الا من شهد بالحق } الذى هو التوحيد والاستثناء اما متصل والموصول عام لكل ما يعبد من دون الله كعيسى وعزير والملائكة وغيرهم او منفصل على انه خاص بالاصنام { وهم يعلمون } بما يشهدون به عن بصيرة وايقان واخلاص قال الكاشفى وايشان ميداند بدل خودكه بزبان خواهى داده اند وايشان شفاعت نخواهند كرد الا مؤمنان كنهكار را. وجمع الضمير باعتبار معنى من كما ان الافراد اولا باعتبار لفظها
