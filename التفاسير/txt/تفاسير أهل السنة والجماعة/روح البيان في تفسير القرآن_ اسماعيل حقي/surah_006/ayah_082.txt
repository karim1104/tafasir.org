{ الذين ءامنوا } اى احد الفريقين الذين آمنوا { ولم يلبسوا إيمانهم } اى لم يخلطوه { بظلم } اى بشرك كما يفعله الفريق المشركون حيث يزعمون انهم يؤمنون بالله تعالى وان عبادتهم للاصنام من تتمات ايمانهم واحكامه لكونها لاجل التقريب والشفاعة كما قالوا الزمر 3. وهذا معنى الخلط { أولئك لهم الأمن } فقط من العذاب { وهم مهتدون } الى الحق ومن عداهم فى ضلال مبين.
