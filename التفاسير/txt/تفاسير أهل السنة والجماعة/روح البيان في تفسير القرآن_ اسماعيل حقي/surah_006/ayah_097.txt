{ وهو الذى } واوست خداونديكه بقدرت كامله { جعل لكم } اى انشأ لاجلكم وابدع { النجوم } التى تختلف مواضعها من جهة الشمال والجنوب والصبا والدبور { لتهتدوا بها فى ظلمات البر والبحر } اى فى ظلمات الليل فى البر والبحر واضافتها اليهما للملابسة فان الحاجة الى الاهتداء بها انما تحقق عند ذلك قال الحدادى لتعرفوا بها الطرق من بلد الى بلد فى المفاوز ولجج البحار فى الليالى المظلمة فى السفن فان من النجوم ما يجعله السائر تلقاء وجهه. ومنها ما يجعله على يمنيه. ومنها ما يجعله على يساره. ومنها ما يجعله خلفه ليظهر له الطريق التى تؤديه الى بغيته. وللنجوم فوائد اخر وهى انها زينة السماء ورمى الشياطين وغير ذلك { قد فصلنا الآيات } اى بينا الآيات الدالة على قدرتنا فصلاً فصلاً { لقوم يعلمون } فانهم المنتفعون بها.
