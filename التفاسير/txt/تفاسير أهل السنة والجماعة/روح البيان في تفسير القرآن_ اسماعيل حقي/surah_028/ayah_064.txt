{ وقيل } لمن عبد غير الله توبيخا وتهديدا والقائلون الخزنة { ادعوا شركاءكم } اى الاصنام ونحوها ليخلصوكم من العذاب اضافها اليهم لادعائهم انها شركاء الله { فدعوهم } من فرط الحيرة { فلم يستجيبوا لهم } ضرورة عدم قدرتهم على الاستجابة والنصرة { ورأوا العذاب } الموعود قد غشيهم { لو انهم كانوا يهتدون } لوجه من وجوه الحيل يدفعون به العذاب او الى الحق فى الدنيا لما لقوا مالقوا من العذاب. وقال بعضهم لو للتمنى هنا اى تمنوا لون انهم كانوا مهتدين لاضالين
