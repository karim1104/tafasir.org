{ وآتيناهم بينات من الامر } دلائل ظاهرة فى امر الدين ومعجزات قاهرة فمن بمعنى فى كما فى قوله تعالى وقال ابن عباس رضى الله عنهما هو العلم بمبعث النبى عليه السلام وما بين لهم من امره وانه يهاجر من تهامة الى يثرب ويكون انصاره أهل يثرب { فما اختلفوا } فما وقع بينهم الخلاف فى ذلك الامر { الا من بعد ما جاءهم العلم } بحقيقته وحقيته فجعلوا ما يوجب زوال الخلاف موجبا لرسوخه { بغيا بينهم } تعليل اى عداوة وحسدا حدث بينهم لا شكا فيه { ان ربك يقضى بينهم يوم القيامة } بالمؤاخذة والجزآء { فيما كانوا فيه يختلفون } من امر الدين
