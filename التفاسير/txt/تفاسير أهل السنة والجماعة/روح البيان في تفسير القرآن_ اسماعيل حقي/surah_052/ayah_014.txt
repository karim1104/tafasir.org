{ يوم يدعون الى نار جهنم دعا } الدع الدفع الشديد واصله أن يقال للعاثر دع دع اى يدفعون اليها دفعا عنيفا شديدا بان تغل ايديهم الى اعناقهم وتجمع نواصيهم الى اقدامهم فيدفعون الى النار دفعا على وجوههم وفى اقفيتهم حتى يردوها ويوم اما بدل من يوم تمور او ظرف لقول مقدر قبل قوله تعالى { هذه النار } اى يقال لهم من قبل خزنة النار هذه النار { التى كنتم } فى الدنيا وقوله { بها } متعلق بقوله { تكذبون } اى تكذبون الوحى الناطق بها
