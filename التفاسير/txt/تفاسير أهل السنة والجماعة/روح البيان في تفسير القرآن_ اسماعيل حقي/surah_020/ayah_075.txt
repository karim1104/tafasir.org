{ ومن يأته مؤمنا } به تعالى وبما جاء من عنده من المعجزات التى من جملتها ما شاهدناه { قد } اى وقد { عمل الصالحات } الصالحة كالحسنة جارية مجرى الاسم ولذلك لا تذكر غالبا مع الموصوف وهى كل ما استقام من الاعمال بدليل النقل والنقل { فاولئك } اشارة الى من والجمع باعتبار معناها اى فاولئك المؤمنون العاملون للصالحات { لهم } بسبب ايمانهم واعمالهم الصالحة { الدرجات العلى } جمع العليا تأنيث الاعلى اى المنازل الرفيعة فى الجنة. وفيه اشارة الى الفرق بين اهل الايمان المجرد وبين الجامع بين الايمان والعمل حيث ان الدرجات العالية للثانى وغيرها لغيره.
