{ لا ترى فيها } اى فى مقار الجبال لا بالبصر ولا بالبصيرة استئناف مبين لكيفية القاع الصفصف والخطاب لكل احد ممن يتأتى منه الرؤية { عوجا } بكسر العين اى عوجا ما كأنه لغاية خفائه من قبيل خافى المعانى وذلك لان العوج بالكسر يخص المعانى. قال فى المفردات العوج العطف عن حال الانتصاب والعوج يقال فيما يدرك بالبصر كالخشب المنتصب ونحوه والعوج يقال فيما يدرك بفكر وبصيرة كما يكون فى ارض بسيطة وكالدين والمعاش { ولا امتا } ارتفاعا يسيرا. قال الزمخشرى الامت النتوء اليسير. وفى القاموس الا مت المكان المرتفع والتلال الصغار والانخفاض والارتفاع. قال فى المناسبات { ولا امتا } اى تفاوتا بارتفاع وانخفاض. وفى الجلالين { عوجا ولا امتا } انخفاضا وارتفاعا ومثله ما فى تفسير الفارسى حيث قال عوجا بستى درمناره ولا امتا ونه بلندى وبشته.
