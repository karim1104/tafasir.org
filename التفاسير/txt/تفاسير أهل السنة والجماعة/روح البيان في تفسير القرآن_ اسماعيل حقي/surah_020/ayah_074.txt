{ انه } اى الشأن وهو تعليل من جهتهم لكونه تعالى خيرا وابقى { من } كس كه { يأت } آيد در روزقيامت { ربه } نزديك برور دكار او { مجرما } حال كونه متوغلا فى اجرامه منهمكا فيه بان يموت على الكفر والمعاصى ولانه مذكور فى مقابلة المؤمن { فان له جهنم لا يموت فيها } فينتهى عذابه ويستريح وهذا تحقيق لكون عذابه ابقى { ولا يحيى } حياة ينتفع بها.
