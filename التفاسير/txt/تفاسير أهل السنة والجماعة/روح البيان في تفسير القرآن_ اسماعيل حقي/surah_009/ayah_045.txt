{ انما يستأذنك } فى التخلف { الذين لا يؤمنون بالله واليوم الآخر } قال فى التبيان كان الاستئذان فى ذلك الوقت علامة النفاق قيل كانوا تسعة وثلاثين رجلا { وارتابت قلوبهم } عطف على الصلة والماضى للدلالة على تحقيق الريب والريب شك مع اضطراب القلب ودل على ان الشاك المرتاب غير مؤمن { فهم } حال كونهم { فى ريبهم } وشكهم المستقر فى قلوبهم { يترددون } اى يتحيرون فان التردد ديدن المتحير كما ان الثبات ديدن المستبصر
