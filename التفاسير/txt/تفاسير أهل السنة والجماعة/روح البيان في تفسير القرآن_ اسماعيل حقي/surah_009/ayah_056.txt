{ ويحلفون } اى المنافقون { بالله } يحتمل ان يتعلق بيحلفون ويحتمل ان يكون من كلامهم { انهم لمنكم } اى لمن جملة المسلمين { وما هم منكم } لكفر قلوبهم { ولكنهم قوم يفرقون } اي يخافون منكم ان تفعلوا بهم ما تفعلون بالمشركين فيظهرون الاسلام تقية ويؤكدونه بالايمان الفاجرة يقال فرق كفرح اى فزع والفرق بفتحتين الفزع
