{ المنافقون } مردان منافق مه سيصد نفر بودند { والمنافقات } وزنان منافقه كه صدو هفتاد بودند { بعضهم من بعض } اى متشابهون فى النفاق والبعد عن الايمان كابعاض الشيء الواحد بالشخص { يأمرون بالمنكر } اى بالكفر والمعاصى { وينهون عن المعروف } اى عن الايمان والطاعة استئناف مقرر لمضمون ما سبق ومفصح عن مضادة حالهم لحال المؤمنين { ويقبضون ايديهم } اى عن الانفاق فى سبيل الله وعن الصدقة وعن كل خير فان قبض اليد كناية عن الشح او عن رفعها للدعاء والمناجاة كما فى الكاشفى { نسوا الله } صاروا غافلين عن ذكره وتركوا امره حتى صار كالمنسى عندهم ذكر الملزوم وهو النسيان واريد اللازم وهو الترك لان النسيان ليس من الافعال الاختيارية فلا يذم عليه { فنسيهم } فتركهم من لطفه وفضله لا من قهره وتعذيبه وفسر النسيان ايضا بالمعنى المجازى الذى هو الترك لانه محال فى حقه تعالى { ان المنافقين هم الفاسقون } الكاملون فى التمرد والفسق الذى هو الخروج عن الطاعة والانسلاخ عن كل خير
