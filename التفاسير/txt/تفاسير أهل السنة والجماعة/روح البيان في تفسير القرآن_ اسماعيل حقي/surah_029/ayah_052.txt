{ قل كفى بالله } اى كفى الله و الباء صلة { بينى وبينكم شهيدا } بما صدر عنى وعنكم { يعلم مافى السموات والارض } اى من الامور التى من جملتها شأنى وشأنكم { والذين آمنوا بالباطل } الذى لايجوز الايمان به كالصنم والشيطان وغيرهما. وفه اشارة الى ان من ابصر بعين النفس لايرى الا الباطل فيؤمن به { وكفروا بالله } الذى يجب الايمان به مع تعاضد موجبات الايمان { اولئك هم الخاسرون } المغبونون فى صفتهم الاخروية حيث اشتروا الكفر بالايمان وضيعوا الفطرة الاصلية والادلة السمعية الموجبة للايمان
