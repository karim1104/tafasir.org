{ قال الذين استكبروا للذين استضعفوا } منكرين لكونهم الصادين لهم عن الايمان مثبتين ذلك لانفسهم اى المستضعفين { أنحن } آياما { صددناكم } منعناكم وصرفناكم { عن الهدى } ازقبول ايمان وهدايت { بعد اذ جاءكم } اى الهدى اى لم نصدكم عنه كقولك ما انا قلت هذا تريد لم اقله مع انه مقول لغيرى فان دخول همزة الاستفهام الانكارى على الضمير يفيد نفى الفعل عن المتكلم وثبوته لغيره كما قال { بل كنتم مجرمين } فى الاجرام فبسبب ذلك صددتم انفسكم عن الايمان وآثرتم التقليد وفى هذا تنبيه للكفار على ان طاعة بعضهم لبعض فى الدنيا تصير سبب عداوة فى الآخرة وتبرى بعضهم من بعض
