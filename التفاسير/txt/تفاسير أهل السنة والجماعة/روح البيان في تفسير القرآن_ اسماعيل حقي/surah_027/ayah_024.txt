{ وجدتها وقومها يسجدون للشمس من دون الله } اى يعبدونها مجاوزين عبادة الله تعالى { وزين لهم الشيطان اعمالهم } اى حسن لهم اعمالهم القبيحة التى هى عبادة الشمس ونظائرها من اصناف الكفر المعاصى { فصدهم } منعهم بسبب ذلك { عن السبيل } اى سبيل الحق والصواب والسبيل من الطريق ماهو معتاد السلوك { فهم } بسبب ذلك { لايهتدون } اليه
