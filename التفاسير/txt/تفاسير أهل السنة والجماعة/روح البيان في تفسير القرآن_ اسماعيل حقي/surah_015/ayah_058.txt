{ قال } ابراهيم { فما خطبكم ايها المرسلون } اى امركم وشأنكم الخطر لعل ابراهيم عليه السلام علم بالقرائن ان مجيئ الملائكة ليس لمجرد البشارة بل لهم شأن آخر لاجله ارسلوا فكأنه قال ان لم يكن شأنكم مجرد البشارة فماذا هو { قالوا } اى الملائكة { انا ارسلنا الى قوم مجرمين } مصرين على اجرامهم متناهين فى آثامهم وهم قوم لوط
