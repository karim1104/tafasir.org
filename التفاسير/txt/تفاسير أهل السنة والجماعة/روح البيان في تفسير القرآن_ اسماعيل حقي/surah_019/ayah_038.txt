{ اسمع بهم وابصر } جه شنو باشد كافران وجه بينا وهو تعجب من حدة سمعهم وابصارهم يومئذ ومعناه ان استماعهم وابصارهم للهدى { يوم يأتوننا } للحساب والجزاء يوم القيامة جدير بان يتعجب منه بعد ان كانوا فى الدنيا صما وعميا والتعجب استعظام الشئ مع الجهل بسببه ثم استعمل لمجرد الاستعظام { لكن الظالمون اليوم } اى فى الدنيا { فى ضلال مبين } فى خطأ ظاهر لا يدرك غايته اغفلوا الاستماع والنظر بالكلية حين ينفعهم
