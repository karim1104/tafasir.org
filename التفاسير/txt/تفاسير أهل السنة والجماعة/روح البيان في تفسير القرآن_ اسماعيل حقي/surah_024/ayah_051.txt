{ انما كان قول المؤمنين } بالنصب على انه خبر كان وان مع مافى حيزها اسمها { اذا دعوا الى الله ورسوله ليحكم } اى الرسول { بينهم } وبين خصومهم سواء كانوا منهم او من غيرهم { ان يقولوا سمعنا } الدعاء { وأطعنا } بالاجابة والقبول والطاعة موافقة الامر طوعا وهى تجوز لله ولغيره كما فى فتح الرحمن بهرجه كنى درميان حكمى { واولئك } المنعوتون بما ذكر من النعت الجميل { هم المفلحون } الفائزون بكل مطلب والناجون من كل محذور. قال فى المفردات الفلاح الظفر وادراك البغية.
