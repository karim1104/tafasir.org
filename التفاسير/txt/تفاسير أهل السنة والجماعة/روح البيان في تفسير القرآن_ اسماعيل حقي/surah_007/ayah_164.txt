{ واذ قالت } عطف على اذ يعدون { امة منهم } اى جماعة من صلحائهم الذين ركبوا فى عظتهم متن كل صعب وذلول حتى يئسوا من احتمال القبول لآخرين لا يقلعون عن التذكير رجاء للنفع والتأثير مبالغة فى الاعذار وطمعا فى فائدة الانذار { لم تعظون } جرابند ميدهيد { قوما } كروهى را كه بى شبهة { الله مهلكهم } اى مستأصلهم ومطهر الارض منهم { او معذبهم عذابا شديدا } دون الاستئصال بالمرة. والمفهوم من بقية الآية كون المراد عذاب الدنيا قالوه مبالغة فى ان الوعظ لا ينجح فيهم لا انكارا لوعظهم ورضى بالمعصية منهم { قالوا } اى الوعاظ { معذرة الى ربكم } مفعول له اى نعظم معذرة اليه تعالى. والمعذرة اسم مصدر بمعنى العذر وهو بضم فسكون فى الاصل تحرى الانسان بما يمحو به ذنوبه بان يقول لم افعل او فعلت لاجل كذا او فعلت ولا اعود وهذا الثالث التوبة فكل توبة عذر بلا عكس وقيل المعذرة بمعنى الاعتذار يقال اعتذرت الى فلان من جرمى ويعدى بمن والمعتذر قد يكون محقا وغير محق كذا فى تاج المصادر قال السعدى قدس سره { ولعلهم يتقون } عطف على معذرة اى ورجاء لان يتقوا بعض التقاة ويتركوا المعصية لان قبول الحق الواضح يرجى من العاقل. واليأس لا يحصل الا بالهلاك وهذا صريح فى ان القائلين لم تعظون الخ ليسوا من الفرقة الهالكة والا لوجب الخطاب اى ولعلكم.
