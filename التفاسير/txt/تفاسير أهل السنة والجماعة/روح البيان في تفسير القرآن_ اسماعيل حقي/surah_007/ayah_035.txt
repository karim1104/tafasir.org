{ يا بنى آدم } خطاب لكافة الناس { اما } اصله ان ما ضمت كلمة ما الى ان الشرطية تأكيدا لما فيها من معنى الشرط { يأتينكم رسل } كائنون { منكم } اى من جنسكم فهو صفة لرسل { يقصون عليكم آياتى } صفة اخرى لرسل اى يبينون لكم احكامى وشرائعى ومقتضى الظاهر كلمة اذا بدل ان لكون الاتيان محقق الوقوع فى علم الله تعالى لكنه سيق المعلوم مساق المشكوك للتنبيه على ان ارسال الرسل امر جائز لا واجب عقلا حتى لا يقدر على عدم ارساله ولا واجب شرعا حتى يأثم بترك ارساله لانه لا يجب على الله شئ لا عقلا ولا شرعا لكن مقتضى الحكمة ارسال الرسل لما فيه من الحكم والمصالح { فمن } شرطية بالفارسية يس هركه { اتقى } منكم التكذيب { واصلح } عمله واطاع رسوله الذى يقص آياته { فلا خوف عليهم } اى لا يخافون ما يلحق العصاة فى المستقبل { ولا هم يحزنون } على ما فاتهم فى الدنيا لاستغراقهم فى الاستلذاذ بما اعد للمتقين فى دار الكرامة والرضوان.
