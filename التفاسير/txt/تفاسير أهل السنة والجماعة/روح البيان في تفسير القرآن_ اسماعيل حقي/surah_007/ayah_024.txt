{ قال } الله تعالى { اهبطوا } خطاب لآدم وحواء وذريتهما اولهما ولابليس { بعضكم لبعض عدو } جملة حالية من فاعل اهبطوا اى متعادين فطبع ابليس على العداوة كطبع العقرب على اللدغ والذئب على السلب فعادى آدم لذهاب رياسته بين الملائكة بسبب خلافة آدم وامرنا بمعاداة ابليس لان الابن يعادى عدو ابيه { ولكم فى الارض مستقر } قرار كاهى وآرام جابى { ومتاع } اى تمتع وانتفاع { الى حين } هو حين انقضاء آجالهم فاغتم آدم وظن انه لا يرجع الجنة.
