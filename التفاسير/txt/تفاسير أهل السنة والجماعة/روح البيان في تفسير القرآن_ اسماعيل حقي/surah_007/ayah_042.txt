{ والذين آمنوا } بالآيات { وعملوا الصالحات } اى الاعمال الصالحات التى شرعت بالآيات وهى ما اريد به وجه الله تعالى { لا نكلف نفسا الا وسعها } اى طاقتها وقدرتها هو اعتراض بين المبتدأ والخبر للدلالة على ان استحقاق الخلود فى النعيم المقيم بسبب اتصافهم بالايمان والعمل الصالح على حسب ما تسعه طاقتهم وان لم يبذلوا مجهودهم فيه { اولئك اصحاب الجنة } ملازمان بهشت اند { هم فيها خالدون } حال من اصحاب الجنة.
