{ لو كان } لو وجد واستقر { فى الارض } بدل البشر { ملائكة يمشون } على اقدامهم كما يمشى الناس ولا يطيرون باجنحتهم الى السماء فيسمعوا من اهلها ويعلموا ما يجب علمه { مطمئنين } ساكنين فيها قارين { لنزلنا عليهم من السماء ملكا } حال من { رسولا } ليبين لهم ما يحتاجون اليه من امور الدنيا والدين لان الجنس الى الجنس يميل ولما كان سكان الارض بشرا وجب ان يكون رسولهم بشرا ليمكن الافادة والاستفادة وهم جهلوا ان التجانس يورث التوانس والتخالف يوجب التنافر
