بقوله { ان الذين آمنوا } بآياتنا { وعملوا الصالحات } وعملوا بموجبها. قال فى كشف الاسرار الايمان التصديق بالقلب وتحقيقه بالاعمال الصالحة ولذلك قرن الله بينهما وجعل الجنة مستحقة بهما قال تعالى { لهم } بمقابلة ايمانهم واعمالهم { جنات النعيم } بهشتهاى بانعمت ناز ويا نعمتهاى بهشت كما قال البيضاوى اى نعيم جنات فعكس للمبالغة. وقيل جنات النعيم احدى الجنات الثمان وهى دار الجلال ودار السلام ودار القرار وجنة عدن وجنة المأوى وجنة الخلد وجنة الفردوس وجنة النعيم كذا روى وهب بن منبه عن ابن عباس رضى الله عنهما
