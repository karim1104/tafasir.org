يخبر تعالى عن المشركين أنهم يستعجلون أيضاً بوقوع العذاب بهم، تكذيباً وجحوداً وكفراً وعناداً فقال: { وَيَقُولُونَ مَتَىٰ هَـٰذَا ٱلْوَعْدُ إِن كُنتُمْ صَادِقِينَ }؟ قال الله تعالى: { لَوْ يَعْلَمُ ٱلَّذِينَ كَفَرُواْ حِينَ لاَ يَكُفُّونَ عَن وُجُوهِهِمُ ٱلنَّارَ وَلاَ عَن ظُهُورِهِمْ } أي لو تيقنوا أنها واقعة بهم لا محالة لما استعجلوا. ولو يعلمون حين يغشاهم العذاب من فوقهم ومن تحت أرجلهم [الزمر: 16]، وقال في هذه الآية، { حِينَ لاَ يَكُفُّونَ عَن وُجُوهِهِمُ ٱلنَّارَ وَلاَ عَن ظُهُورِهِمْ } ، فالعذاب محيط بهم من جميع جهاتهم { وَلاَ هُمْ يُنصَرُونَ } أي لا ناصر لهم، كما قال: [الرعد: 34]، وقوله: { بَلْ تَأْتِيهِم بَغْتَةً } أي تأتيهم النار بغتة أي فجأة، { فَتَبْهَتُهُمْ } أي تذعرهم فيستسلمون لها، حائرين لا يدرون ما يصنعون { فَلاَ يَسْتَطِيعُونَ رَدَّهَا } أي ليس لهم حيلة في ذلك، { وَلاَ هُمْ يُنظَرُونَ } أي ولا يؤخر عنهم ذلك ساعة واحدة.
