يقول تعالى لنبيّه صلوات الله وسلامه عليه: { وَإِذَا رَآكَ ٱلَّذِينَ كَفَرُوۤاْ } يعني كفار قريش كأبي جهل وأشباهه { إِن يَتَّخِذُونَكَ إِلاَّ هُزُواً } أي يستهزئون بك وينتقصونك، يقولون { أَهَـٰذَا ٱلَّذِي يَذْكُرُ آلِهَتَكُمْ }؟ يعنون أهذا الذي يسب آلهتكم ويسفه أحلامكم، قال تعالى: { وَهُمْ بِذِكْرِ ٱلرَّحْمَـٰنِ هُمْ كَافِرُونَ } أي وهم كافرون بالله ومع هذا يستهزئون برسول الله كما قال في الآية الأخرى: [الفرقان: 41]؟ وقوله: { خُلِقَ ٱلإنْسَانُ مِنْ عَجَلٍ } كقوله: [الإسراء: 11] أي في الأمور. والحكمة في ذكر عجلة الإنسان هٰهنا، أنه لما ذكر المستهزئين بالرسول صلوات الله وسلامه عليه، وقع في النفوس سرعة الانتقام منهم واستعجلت ذلك، فقال الله تعالى: { خُلِقَ ٱلإنْسَانُ مِنْ عَجَلٍ } لأنه تعالى يملي للظالم حتى إذا أخذه لم يفلته، يؤجل ثم يعجل، وينظر ثم لا يؤخر، ولهذا قال: { سَأُوْرِيكُمْ آيَاتِي } أي نقمي وحكمي واقتداري على من عصاني { فَلاَ تَسْتَعْجِلُونِ }.
