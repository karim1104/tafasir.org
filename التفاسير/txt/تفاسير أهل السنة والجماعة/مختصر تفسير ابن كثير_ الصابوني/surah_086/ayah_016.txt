قال ابن عباس: الرجع المطر، وعنه: هو السحاب فيه المطر، وقال قتادة: ترجع رزق العباد كل عام، ولولا ذلك لهلكوا وهلكت مواشيهم، { وَٱلأَرْضِ ذَاتِ ٱلصَّدْعِ } قال ابن عباس: هو انصداعها عن النبات، وقوله تعالى: { إِنَّهُ لَقَوْلٌ فَصْلٌ } قال ابن عباس: حق، وقال غيره: حكم عدل، { وَمَا هوَ بِٱلْهَزْلِ } أي بل هو جد حق، ثم أخبر عن الكافرين بأنهم يكذبون به، ويصدون عن سبيله فقال: { إِنَّهُمْ يَكِيدُونَ كَيْداً } أي يمكرون بالناس، في دعوتهم إلى خلاف القرآن، ثم قال تعالى { فَمَهِّلِ ٱلْكَافِرِينَ } أي أنظرهم ولا تستعجل لهم، { أَمْهِلْهُمْ رُوَيْداً } أي قليلاً وسترى ماذا أحل بهم، من العذاب والنكال، والعقوبة والهلاك كما قال تعالى: [لقمان: 24].
