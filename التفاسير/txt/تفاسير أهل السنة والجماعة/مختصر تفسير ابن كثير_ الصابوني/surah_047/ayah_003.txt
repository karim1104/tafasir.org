يقول تعالى: { ٱلَّذِينَ كَفَرُواْ } أي بآيات الله { وَصَدُّواْ } غيرهم { عَن سَبِيلِ ٱللَّهِ أَضَلَّ أَعْمَالَهُمْ } أي أبطلها وأذهبها، ولم يجعل لها ثواباً ولا جزاء، كقوله تعالى: [الفرقان: 23]، ثم قال جلّ وعلا { وَٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ } أي آمنت قلوبهم وسرائرهم، وانقادت لشرع الله جوارحهم وبواطنهم، { وَآمَنُواْ بِمَا نُزِّلَ عَلَىٰ مُحَمَّدٍ } عطف خاص على عام، وهو دليل على أنه شرط في صحة الإيمان بعد بعثته صلى الله عليه وسلم، وقوله تبارك وتعالى: { وَهُوَ ٱلْحَقُّ مِن رَّبِّهِمْ } جملة معترضة حسنة، ولهذا قال جلّ جلاله: { كَفَّرَ عَنْهُمْ سَيِّئَاتِهِمْ وَأَصْلَحَ بَالَهُمْ } قال ابن عباس: أي أمرهم، وقال مجاهد: شأنهم، وقال قتادة: حالهم، والكل متقارب، وفي حديث تشميت العاطس " يهديكم الله ويصلح بالكم " ، ثم قال عزّ وجلّ: { ذَلِكَ بِأَنَّ ٱلَّذِينَ كَفَرُواْ ٱتَّبَعُواْ ٱلْبَاطِلَ } أي إنما أبطلنا أعمال الكفّار، وتجاوزنا عن سيئات الأبرار، وأصلحنا شؤونهم؛ لأن الذين كفروا اتبعوا الباطل، أي اختاروا الباطل على الحق، { وَأَنَّ ٱلَّذِينَ آمَنُواْ ٱتَّبَعُواْ ٱلْحَقَّ مِن رَّبِّهِمْ كَذَلِكَ يَضْرِبُ ٱللَّهُ لِلنَّاسِ أَمْثَالَهُمْ } أي يبين لهم مآل أعمالهم، وما يصيرون إليه في معادهم، والله سبحانه وتعالى أعلم.
