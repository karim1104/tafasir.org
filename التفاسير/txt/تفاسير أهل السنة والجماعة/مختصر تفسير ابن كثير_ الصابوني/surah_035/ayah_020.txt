يقول تعالى: كما لا تستوي هذه الأشياء المتباينة المختلفة كالأعمى والبصير، لا يستويان بل بينهما فرق وبون كثير، وكما لا تستوي الظلمات ولا النور ولا الظل ولا الحرور، كذلك لا تستوي الأحياء ولا الأموات، وهذا مثل ضربه الله تعالى للمؤمنين وهم الأحياء، وللكافرين وهم الأموات، كقوله تعالى: [الأنعام: 122]، وقال عزَّ وجلَّ: [هود: 24] فالمؤمن بصير سميع في نور يمشي على صراط مستقيم، في الدنيا والآخرة حتى يستقر به الحال في الجنات ذات الظلال والعيون، والكافر أعمى وأصم في ظلمات يمشي لا خروج له منها، بل هو يتيه في غيه وضلاله في الدنيا والآخرة، حتى يفضي به ذلك إلى الحرور والسموم والحميم [الواقعة: 43-44]، وقوله تعالى: { إِنَّ ٱللَّهَ يُسْمِعُ مَن يَشَآءُ } أي يهديهم إلى سماع الحجة وقبولها والانقياد لها { وَمَآ أَنتَ بِمُسْمِعٍ مَّن فِي ٱلْقُبُورِ } أي كما لا ينتفع الأموات بعد موتهم وصيرورتهم إلى قبورهم وهم كفار بالهداية والدعوة إليها، كذلك هؤلاء المشركون الذين كتب عليهم الشقاوة لا حيلة لك فيهم، ولا تستطيع هدايتهم { إِنْ أَنتَ إِلاَّ نَذِيرٌ } ، أي إنما عليك البلاغ والإنذار والله يضل من يشاء ويهدي من يشاء، { إِنَّآ أَرْسَلْنَاكَ بِٱلْحَقِّ بَشِيراً وَنَذِيراً } أي بشيراً للمؤمنين ونذيراً للكافرين، { وَإِن مِّنْ أُمَّةٍ إِلاَّ خَلاَ فِيهَا نَذِيرٌ } أي وما من أمة خلت من بني آدم إلا وقد بعث الله تعالى إليهم النذر وأزاح عنهم العلل، كما قال تعالى: [الرعد: 7]، وكما قال تعالى: [النحل: 36] الآية، والآيات في هذا كثيرة. وقوله تبارك وتعالى: { وَإِن يُكَذِّبُوكَ فَقَدْ كَذَّبَ ٱلَّذِينَ مِن قَبْلِهِمْ جَآءَتْهُمْ رُسُلُهُم بِٱلْبَيِّنَاتِ } وهي المعجزات الباهرات والأدلة القاطعات، { وَبِٱلزُّبُرِ } وهي الكتب، { وَبِٱلْكِتَابِ ٱلْمُنِيرِ } أي الواضح البين، { ثُمَّ أَخَذْتُ ٱلَّذِينَ كَفَرُواْ } ، أي ومع هذا كله كذب أولئك رسلهم فيما جاءوهم به فأخذتهم أي بالعقاب والنكال، { فَكَيْفَ كَانَ نَكِيرِ } أي فكيف رأيت إنكاري عليهم عظيماً شديداً بليغاً؟ والله أعلم.
