هذه السورة هي آخر المسبحات، وقد تقدّم الكلام على تسبيح المخلوقات لبارئها ومالكها، ولهذا قال تعالى: { لَهُ ٱلْمُلْكُ وَلَهُ ٱلْحَمْدُ } أي هو المتصرف في جميع الكائنات، المحمود على جميع ما يخلقه ويقدره. وقوله تعالى: { وَهُوَ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ } أي مهما أراد كان بلا ممانع ولا مدافع، وما لم يشأ لم يكن، وقوله تعالى: { هُوَ ٱلَّذِي خَلَقَكُمْ فَمِنكُمْ كَافِرٌ وَمِنكُمْ مُّؤْمِنٌ } ، أي هو الخالق لكم على هذه الصفة، فلا بد من وجود مؤمن وكافر، وهو البصير بمن يستحق الهداية ممن يستحق الضلال، ولهذا قال تعالى: { وَٱللَّهُ بِمَا تَعْمَلُونَ بَصِيرٌ } ، ثم قال تعالى: { خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ بِٱلْحَقِّ } أي بالعدل والحكمة، { وَصَوَّرَكُمْ فَأَحْسَنَ صُوَرَكُمْ } أي أحسن أشكالكم، كقوله تعالى: [الإنفطار: 7-8]، وكقوله تعالى: [غافر: 64] الآية، وقوله تعالى: { وَإِلَيْهِ ٱلْمَصِيرُ } أي المرجع والمآل. ثم أخبر تعالى عن علمه بجميع الكائنات السمائية والأرضية والنفسية فقال تعالى: { يَعْلَمُ مَا فِي ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ وَيَعْلَمُ مَا تُسِرُّونَ وَمَا تُعْلِنُونَ وَٱللَّهُ عَلِيمٌ بِذَاتِ ٱلصُّدُورِ }.
