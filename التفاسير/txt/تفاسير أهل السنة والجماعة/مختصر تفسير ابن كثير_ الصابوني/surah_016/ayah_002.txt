يقول تعالى: { يُنَزِّلُ ٱلْمَلاۤئِكَةَ بِٱلْرُّوحِ } أي الوحي كقوله: [الشورى: 52]، وقوله: { عَلَىٰ مَن يَشَآءُ مِنْ عِبَادِهِ } وهم الأنبياء، كما قال تعالى: [الأنعام: 124]، وقال: [الحج: 75]، وقال: [غافر: 15]، وقوله: { أَنْ أَنْذِرُوۤاْ } أي لينذروا { أَنَّهُ لاَ إِلَـٰهَ إِلاَّ أَنَاْ فَٱتَّقُونِ } أي فاتقوا عقوبتي لمن خالف أمري وعبد غيري.
