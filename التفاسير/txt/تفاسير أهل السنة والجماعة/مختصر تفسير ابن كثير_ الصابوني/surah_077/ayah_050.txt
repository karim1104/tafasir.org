يقول تعالى مخبراً عن عبادة المتقين، إنهم يوم القيامة يكونون في جنات وعيون أي بخلاف ما أولئك الأشقياء فيه من ظل اليحموم وهو الدخان الأسود المنتن، وقوله تعالى: { وَفَوَاكِهَ مِمَّا يَشْتَهُونَ } أي ومن سائر أنواع الثمار مهما طلبوا وجدوا، { كُلُواْ وَٱشْرَبُواْ هَنِيـۤئاً بِمَا كُنتُمْ تَعْمَلُونَ } أي يقال لهم ذلك على سبيل الإحسان إليهم، ثم قال تعالى: { إِنَّا كَذَلِكَ نَجْزِي ٱلْمُحْسِنِينَ } أي هذا جزاؤنا لمن أحسن العمل، { وَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ } ، وقوله تعالى: { كُلُواْ وَتَمَتَّعُواْ قَلِيلاً إِنَّكُمْ مُّجْرِمُونَ } خطاب للمكذبين بيوم الدين، وأمرهم أمر تهديد ووعيد، فقال تعالى: { كُلُواْ وَتَمَتَّعُواْ قَلِيلاً } أي مدة قليلة قريبة قصيرة. { إِنَّكُمْ مُّجْرِمُونَ } أي ثم تساقون إلى نار جهنم التي تقدم ذكرها، { وَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ } ، كما قال تعالى: [لقمان: 24]، وقال تعالى: [يونس: 70]. وقوله تعالى: { وَإذَا قِيلَ لَهُمُ ٱرْكَعُواْ لاَ يَرْكَعُونَ } أي إذا أمر هؤلاء الجهلة من الكفار أن يكونوا من المصلين مع الجماعة امتنعوا من ذلك واستكبروا عنه ولهذا قال تعالى: { وَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ } ، ثم قال تعالى: { فَبِأَيِّ حَدِيثٍ بَعْدَهُ يُؤْمِنُونَ }؟ أي إذا لم يؤمنوا بهذا القرآن فبأي كلام يؤمنون به؟ كقوله تعالى: [الجاثية: 6] روي عن أبي هريرة: " إذا قرأ { وَٱلْمُرْسَلاَتِ عُرْفاً } فقراً { فَبِأَيِّ حَدِيثٍ بَعْدَهُ يُؤْمِنُونَ } فليقل آمنت بالله وبما أنزل ".
