يقول تعالى: { أَلَمْ نُهْلِكِ ٱلأَوَّلِينَ } يعني المكذبين للرسل المخالفين لما جاءوهم به، { ثُمَّ نُتْبِعُهُمُ ٱلآخِرِينَ } أي ممن أشبههم، ولهذا قال تعالى: { كَذَلِكَ نَفْعَلُ بِٱلْمُجْرِمِينَ * وَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ } ، ثم قال تعالى ممتناً على خلقه ومحتجاً على الإعادة بالبداءة: { أَلَمْ نَخْلُقكُّم مِّن مَّآءٍ مَّهِينٍ } أي ضعيف حقير بالنسبة إلى قدرة الباري عزَّ وجلَّ، كما تقدم في سورة يسۤ: " ابن آدم أنّى تعجزني، وقد خلقتك من مثل هذه؟ " { فَجَعَلْنَاهُ فِي قَرَارٍ مَّكِينٍ } يعني جمعناه في الرحم، وهو حافظ لما أودع فيه من الماء، وقوله تعالى: { إِلَىٰ قَدَرٍ مَّعْلُومٍ } يعني إلى مدة معينة من ستة أشهر أو تسعة أشهر، ولهذا قال تعالى: { فَقَدَرْنَا فَنِعْمَ ٱلْقَادِرُونَ * وَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ } ، ثم قال تعالى: { أَلَمْ نَجْعَلِ ٱلأَرْضَ كِفَاتاً * أَحْيَآءً وَأَمْواتاً } قال مجاهد: يكفت الميت فلا يرى منه شيء، وقال الشعبي: بطنها لأمواتكم وظهرها لأحيائكم، { وَجَعَلْنَا فِيهَا رَوَاسِيَ شَامِخَاتٍ } يعني الجبال رسى بها الأرض لئلا تميد وتضطرب، { وَأَسْقَيْنَاكُم مَّآءً فُرَاتاً } أي عذباً زلالاً من السحاب، أو مما أنبعه من عيون الأرض، { وَيْلٌ يَوْمَئِذٍ لِّلْمُكَذِّبِينَ } أي ويل لمن تأمل هذه المخلوقات، الدّالة على عظمة خالقها، ثم بعد هذا يستمر على تكذيبه وكفره.
