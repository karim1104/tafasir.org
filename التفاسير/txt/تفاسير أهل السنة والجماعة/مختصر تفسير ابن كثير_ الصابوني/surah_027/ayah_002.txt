قد تقدم الكلام في سورة البقرة على الحروف المقطعة في أوائل السور، وقوله تعالى: { تِلْكَ آيَاتُ } أي هذه آيات { ٱلْقُرْآنِ وَكِتَابٍ مُّبِينٍ } أي بيِّن واضح، { هُدًى وَبُشْرَىٰ لِلْمُؤْمِنِينَ } أي إنما تحصل الهداية والبشارة من القرآن، لمن آمن به واتبعه وصدقه وعمل بما فيه، وأقام الصلاة المكتوبة، وآتى الزكاة المفروضة، وأيقن بالدار الآخرة، والبعث بعد الموت، والجزاء على الأعمال خيرها وشرها، والجنة والنار، كما قال تعالى: [فصلت: 44] الآية، وقال تعالى: [مريم: 97]، ولهذا قال تعالى هٰهنا: { إِنَّ ٱلَّذِينَ لاَ يُؤْمِنُونَ بِٱلآخِرَةِ } أي يكذبون بها ويستبعدون وقوعها، { زَيَّنَّا لَهُمْ أَعْمَالَهُمْ فَهُمْ يَعْمَهُونَ } أي حسناً لهم ما هم فيه، ومددنا لهم في غيهم، فهم يتيهون في ضلالهم، كما قال تعالى: [الأنعام: 110] الآية، { أُوْلَـٰئِكَ ٱلَّذِينَ لَهُمْ سُوۤءُ ٱلْعَذَابِ } أي في الدنيا والآخرة { وَهُمْ فِي ٱلآخِرَةِ هُمُ ٱلأَخْسَرُونَ } أي ليس يخسر سواهم من أهل المحشر، وقوله تعالى: { وَإِنَّكَ لَتُلَقَّى ٱلْقُرْآنَ مِن لَّدُنْ حَكِيمٍ عَلِيمٍ } أي { وَإِنَّكَ } يا محمد { لَتُلَقَّى } أي لتأخذ { ٱلْقُرْآنَ مِن لَّدُنْ حَكِيمٍ عَلِيمٍ } أي من عند حكيم عليم أي حكيم في أمره ونهيه، عليم بالأمور جليلها وحقيرها، فخبره هو الصدق المحض، وحكمه هو العدل التام، كما قال تعالى: [الأنعام: 115].
