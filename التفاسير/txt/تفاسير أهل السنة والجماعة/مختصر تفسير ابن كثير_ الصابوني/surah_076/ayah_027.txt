يقول تعالى ممتناً على رسوله صلى الله عليه وسلم بما أنزله عليه من القرآن العظيم، { فَٱصْبِرْ لِحُكْمِ رَبِّكَ } أي كما أكرمتك بما أنزلت عليك فٱصْبِرْ على قضائه وقدره، واعلم أنه سيدبرك بحسن تدبيره، { وَلاَ تُطِعْ مِنْهُمْ آثِماً أَوْ كَفُوراً } أي لا تطع الكافرين والمنافقين إن أرادوا صدك عما أنزل إليك، بل بلغ ما أنزل إليك من ربك وتوكل على الله فإن الله يعصمك من الناس، فالآثم هو الفاجر في أفعاله والكفور هو الكافر قلبه، { وَٱذْكُرِ ٱسْمَ رَبِّكَ بُكْرَةً وَأَصِيلاً } أي أول النهار وآخره، { وَمِنَ ٱللَّيْلِ فَٱسْجُدْ لَهُ وَسَبِّحْهُ لَيْلاً طَوِيلاً } ، كقوله تعالى: [الإسراء: 79] الآية، وكقوله تعالى: [المزمل: 1-2]، ثم قال تعالى منكراً على الكفّار ومن أشبههم حب الدنيا والإقبال عليها، وترك الدار الآخرة وراء ظهورهم، { إِنَّ هَـٰؤُلاَءِ يُحِبُّونَ ٱلْعَاجِلَةَ وَيَذَرُونَ وَرَآءَهُمْ يَوْماً ثَقِيلاً } يعني يوم القيامة، ثم قال تعالى: { نَّحْنُ خَلَقْنَاهُمْ وَشَدَدْنَآ أَسْرَهُمْ } ، قال ابن عباس ومجاهد: يعني خلقهم { وَإِذَا شِئْنَا بَدَّلْنَآ أَمْثَالَهُمْ تَبْدِيلاً } أي وإذا شئنا بعثناهم يوم القيامة، وبدلناهم فأعدناهم خلقاً جديداً، وهذا استدلال بالبداءة على الرجعة، وقال ابن جرير: { وَإِذَا شِئْنَا بَدَّلْنَآ أَمْثَالَهُمْ تَبْدِيلاً } أي وإذا شئنا أتينا بقوم آخرين غيرهم كقوله تعالى: [النساء: 133]، وكقوله تعالى: [إبراهيم: 19-20، فاطر: 16-17] ثم قال تعالى: { إِنَّ هَـٰذِهِ تَذْكِرَةٌ } يعني هذه السورة تذكرة، { فَمَن شَآءَ ٱتَّخَذَ إِلَىٰ رَبِّهِ سَبِيلاً } أي طريقاً ومسلكاً، أي من شاء اهتدى بالقرآن، { وَمَا تَشَآءُونَ إِلاَّ أَن يَشَآءَ ٱللَّهُ إِنَّ ٱللَّهَ } أي لا يقدر أحد أن يهدي نفسه ولا يدخل في الإيمان ولا يجر لنفسه نفعاً { إِلاَّ أَن يَشَآءَ ٱللَّهُ إِنَّ ٱللَّهَ كَانَ عَلِيماً حَكِيماً } أي عليم بمن يستحق الهداية فييسرها له ويقيض له أسبابها، ومن يستحق الغواية فيصرفه عن الهدى، وله الحكمة البالغة، والحجة الدامغة، ولهذا قال تعالى: { إِنَّ ٱللَّهَ كَانَ عَلِيماً حَكِيماً } ، ثم قال: { يُدْخِلُ مَن يَشَآءُ فِي رَحْمَتِهِ وَٱلظَّالِمِينَ أَعَدَّ لَهُمْ عَذَاباً أَلِيماً } أي يهدي من يشاء ويضل من يشاء، فمن يهده فلا مضل له ومن يضلل فلا هادي له.
