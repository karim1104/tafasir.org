يقول تعالى منكراً على المشركين في عبادتهم غير الله، بلا برهان ولا دليل ولا حجة { أَمْ آتَيْنَاهُمْ كِتَاباً مِّن قَبْلِهِ } أي من قبل شركهم، { فَهُم بِهِ مُسْتَمْسِكُونَ } أي ليس الأمر كذلك، كقوله عزّ وجلّ [الروم: 35] أي لم يكن ذلك، ثم قال تعالى: { بَلْ قَالُوۤاْ إِنَّا وَجَدْنَآ آبَآءَنَا عَلَىٰ أُمَّةٍ وَإِنَّا عَلَىٰ آثَارِهِم مُّهْتَدُونَ } أي ليس لهم مستند فيما هم فيه من الشرك، سوى تقليد الآباء والأجداد بأنهم كانوا على { أُمَّةٍ } والمراد بها الدين هٰهنا، وفي قوله تبارك وتعالى: [الأنبياء: 92]، وقولهم { وَإِنَّا عَلَىٰ آثَارِهِم } أي وراءهم { مُّهْتَدُونَ } دعوى منهم بلا دليل. ثم بين جلّ وعلا أن مقالة هؤلاء قد سبقهم إليها أشباههم ونظراؤهم من الأمم السالفة المكذبة للرسل تشابهت قلوبهم فقالوا مثل مقالتهم [الذاريات: 52] وهكذا قال هٰهنا: { وَكَذَلِكَ مَآ أَرْسَلْنَا مِن قَبْلِكَ فِي قَرْيَةٍ مِّن نَّذِيرٍ إِلاَّ قَالَ مُتْرَفُوهَآ إِنَّا وَجَدْنَآ آبَآءَنَا عَلَىٰ أُمَّةٍ وَإِنَّا عَلَىٰ آثَارِهِم مُّقْتَدُونَ }. ثم قال عزّ وجلّ { قَٰلَ } أي يا محمد لهؤلاء المشركين { أَوَلَوْ جِئْتُكُمْ بِأَهْدَىٰ مِمَّا وَجَدتُّمْ عَلَيْهِ آبَآءَكُمْ قَالُوۤاْ إِنَّا بِمَآ أُرْسِلْتُمْ بِهِ كَافِرُونَ } أي ولو علموا وتيقنوا صحة ما جئتهم به لما انقادوا لذلك لسوء قصدهم ومكابرتهم للحق وأهله. قال الله تعالى { فَٱنتَقَمْنَا مِنْهُمْ } أي من الأمم المكذبة بأنواع من العذاب كما فصله تبارك وتعالى في قصصهم { فَٱنظُرْ كَيْفَ كَانَ عَاقِبَةُ ٱلْمُكَذِّبِينَ } أي كيف بادوا وهلكوا، وكيف نجَّى الله المؤمنين.
