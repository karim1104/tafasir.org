{ ٱمْرَأَةُ }  { تُرَاوِدُ }  { فَتَاهَا }  { لَنَرَاهَا }  { ضَلاَلٍ }  (30) - يُخْبِرُ اللهُ تَعَالَى أَنَّ قِصَةَ يُوسُفَ مَعَ المَرْأَةِ قَدْ شَاعَ خَبَرُهَا فِي المَدِينَةِ (مِصْرَ)، حَتَّى تَحَدَّثَ النَّاسُ بِهَا، فَقَالَتْ نِسَاءُ الكُبَرَاءِ وَالأُمَرَاءِ يُنْكِرْنَ عَلَى امْرَأَةِ العَزِيزِ (وَهُوَ الوَزِيرُ الأَوَّلُ) فِعْلَهَا، وَيَعِبْنَ عَلَيْهَا مَسْلَكَهَا فِي مُرَاوَدَةِ غُلاَمِهَا (فَتَاهَا) وَعَبْدِهَا عَنْ نَفْسِهِ، وَدَعْوَتِهِ إِلَى نَفْسِهِ، وَقُلْنَ إِنَّهُ قَدْ سَلَبَ لُبَّهَا مِنَ الحُبِّ، وَإِنَهُنَّ يَرَيْنَهَا فِي ضَلاَلٍ وَاضِحٍ بَيِّنٍ فِي تَصَرُّفِهِا هذا.  (وَقَالَ ابْنُ عَبَّاسٍ: الشَّغَفُ هُوَ الحُبُّ القَاتِلُ، وَالشَّغَافُ هُوَ حِجَابُ القَلْبِ، أَيْ إِنَّ حُبَّهُ قَدْ مَسَّ شَغَافَ قَلْبِهَا).  شَغَفَهَا حُبّاً - شَقَّ حُبُّهُ سُوَيْدَاءَ قَلْبِهَا.
