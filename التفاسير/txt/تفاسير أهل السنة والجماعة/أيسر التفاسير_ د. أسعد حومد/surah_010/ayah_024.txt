{ ٱلْحَيَاةِ }  { أَنزَلْنَاهُ }  { وَٱلأَنْعَامُ }  { قَادِرُونَ }  { أَتَاهَآ }  { فَجَعَلْنَاهَا }  { ٱلآيَاتِ }  (24) - ضَرَبَ اللهُ تَعَالَى مَثَلاً لِلْحَيَاةِ الدُّنْيَا فِي جَمَالِهَا وَبَهْجَتِهَا، ثُمَّ فِي سُرْعَةِ فَنَائِهَا، بِالنَّبَاتِ الذِي أَخْرَجَهُ اللهُ تَعَالَى مِنَ الأَرْضِ بِمَا أَنْزَلَهُ عَلَيْهَا مِنَ المَطَرِ، مِمَّا يَأْكُلُ النَّاسُ مِنْ زُرُوعٍ وَثِمَارٍ عَلَى اخْتِلاَفِ أَنْوَاعِهَا وَأَصْنَافِهَا، وَمِمَّا تَأْكُلُ الحَيوانَاتُ (الأَنْعَامُ) حَتَّى إِذا أَخَذَتِ الأَرْضُ زِينَتَهَا الفَانِيَةَ (زُخْرُفَها) وَازَّيَّنَتْ بِمَا خَرَجَ فِي رُبَاهَا مِنْ زُهُورٍ نَضِرَةٍ مُخْتَلِفَةِ الأَشْكَالِ وَالأَلوانِ، كَمَا تَتَزَيَّنُ العَرُوسُ لَيْلَةَ زَفَافِهَا، وَظَنَّ أَهْلُهَا، الذِينَ زَرَعُوهَا وَغَرَسُوهَا، أَنَّهُمْ قَادِرُونَ عَلَى جزازهَا وَحصَادِهَا، وَجَنْيِ ثِمَارِها، وَالتَّمَتُّعِ بِهَا، فَبَيْنَمَا هُمْ يَأْمُلُونَ ذَلِكَ إِذْ جَاءَتْهَا صَاعِقَةٌ، أَوْ رِيحٌ شَدِيدَةٌ بَارِدَةٌ فَأَيْبَسَتْ أَوْراقَها، وَأَتْلَفَتْ ثِمَارَها، فَأَصْبَحَتْ كَأَنَّهَا لَمْ تَكُنْ حِيناً قَبْلَ ذَلِكَ، وَهَكَذا يُبَيَّنُ اللهُ الحُجَجَ والآياتِ، لِقَومٍ يَتَفَكَّرُونَ، فَيَعْتَبِرُونَ بِهذا المَثَلِ، فِي زَوَالِ الدُّنْيَا عَنْ أَهْلِهَا سَرِيعاً، مَعَ اغْتِرَارِهِمْ بِهَا.  مَثَلُ الحَيَاةِ الدُّنْيَا - حَالُها فِي سُرْعَةِ زَوَالِهَا وَانْقِضَائِهَا.  زُخْرُفَهَا - نَضَارَتَهَا وَبَهْجَتَهَا وَزِينَتَهَا بِأَلْوَانِ النَّبَاتِ.  أَمْرُنا - مَا يَجْتَاحُهَا مِنَ الآفَاتِ وَالعَاهَاتِ.  حَصْيداً - كَالنَّبَاتِ المَحْصُودِ بِالمَنَاجِلِ.  كَأَنْ لَمْ تَغْنَ بِالأَمْسِ - كَأنَّها لَمْ تَكُنْ حِيناً قَبْلَ ذَلِكَ.
