{ ٱلأُمِّيِّينَ }  { يَتْلُواْ }  { آيَاتِهِ }  { ٱلْكِتَابَ }  { ضَلاَلٍ }  (2) - وَاللهُ تَعَالَى هُوَ الذِي أَرْسَلَ رَسُولاً فِي العَرَبِ الأُميِّينَ هُوَ مُحَمَّدٌ صلى الله عليه وسلم، وَهُوَ أُميٌّ مِنْهُمْ. لاَ يَقْرَأُ وَلاَ يَكْتُبُ، وَقَدْ بَعَثَهُ اللهُ إِليْهِمْ لِيَتْلُوَ عَلَيْهِمْ آيَاتِ القُرآنِ التِي أَنْزَلَهَا اللهُ تَعَالَى، لِيُطهرَهُمْ مِنْ خَبَائِث العَقَائِِدِ وَالأَعْمَالِ، وَلِيعَلِّمَهُم الشَّرَائِعَ وَالأَحْكَامَ، وَحِكْمَتَهَا وَأَسْرَارَهَا، وَقَدْ كَانَ هَؤُلاَءِ الأُمِّيونَ، قَبْلَ إِرْسَالِ النَّبِيِّ إِليهِمْ، فِي ضَلاَلٍ بَيِّنٍ عَنْ جَادَّةِ الهُدَى، إِذْ إِنَّ العَرَبَ كَانُوا قَبْلاً عَلَى دِينِ إِبْرَاهِيمَ، ثُمَّ ابْتَعَدُوا عَنِ التَّوْحِيدِ، وَتَسَرَّبَتِ الضَّلاَلاَتُ إِلَى عَقِيدَتِهِمْ، فَأَصْبَحُوا مُشْرِكِينَ.  الأُميِّينَ - العَرَبِ - وَالأُمِّيُّ هُوَ مَنْ لاَ يَقْرَأُ وَلاَ يَكْتُبُ.  يُزَكِّيهِمْ - يُطَهِّرُهُمْ مِنْ أَدْنَاسِ الجَاهِلِيَّةِ.
