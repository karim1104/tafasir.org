{ ٱلإِنسَانَ }  { صَلْصَالٍ }  { حَمَإٍ }  (26) - وَلَقَدْ خَلَقْنَا آدَمَ أَبَا البَشَرِ مِنْ طِينٍ يَابِسٍ لَهُ صَلْصَلَةٌ إِذَا نُقِرَ بِاليَدِ (صَلْصَالٍ)، وَكَانَ قَبْلاً طِيناً رَطْباً (حَمَأٍ) مَُغَيِّرَ اللَّوْنِ مُسْوَدَّهُ (مَسْنُونٍ).  صَلْصَالٍ - طِينٍ يَابِسٍ كَالفَخَّارِ.  حَمَأٍ - طِينٍ أَسْوَدَ مُتَغَيِّرٍ.
