{ ٱلْجَاهِلِيَّةِ }  { ٱلصَّلاَةَ }  { آتِينَ }  { ٱلزَّكَـاةَ }  (33) - وَالزَمْنَ بُيُوتَكُنَّ فَلاَ تَخْرُجْنَ لِغيرِ حَاجَةٍ.  (وَفِي الحَدِيث: " إِن المَرأَةَ عَوْرَةٌ، فَإِذا خَرَجَت استَشْرَفَها الشَّيْطَانُ، وَأَقْربُ مَا تَكُونُ مِنْ وَجْهِ رَبِّها وهيَ فِي قَعْرِ بَيْتِها " (أَخْرَجَهُ التِرْمِذِيُّ والبَزَّارُ).  وَلاَ تُبدِيَنَّ زِينَتَكُنَّ وَمَحَاسِنَكُنَّ لِلرِّجَالِ، كَمَا كَانَتْ تَفْعَلُ نِسَاءُ الجَاهِلِيَّةِ، وَأَقِمْنَ الصَّلاَةَ عَلَى الوَجهِ الأَكْمَلِ، وأَدِّينَ الزَّكَاةَ عَنْ أَموَالِكُنَّ كَمَا أَمَرَ اللهُ، فَاللهُ تَعالى يُريدُ أَنْ يُطَهِّرَ أَهلَ بَيْتِ رَسُولِهِ تَطهيراً لا تُخَالِطُهُ شُبْهَةٌ مِنْ دَنَسِ الفِسْقِ والفُجُورِ، وَأَنْ يُذْهِبَ عَنْهُم السُّوءَ والفَحْشَاءَ.  قَرْنَ فِي بُيُوتِكُنَّ - الزَمْنَ بُيُوتَكُنَّ.  لاَ تَبَرِّجْنَ - لاَ تُبْدِيَن الزِّينَةَ الوَاجِبَ سَتْرُها.  الجَاهِليةِ الأُولَى -مَا قبلَ الإِسْلاَمِ.  الرِّجْسَ - الذَّنْبَ أَوِ الإِثْمَ.
