{ ٱلْمُنَافِقِينَ }  { ٱلْمُنَافِقَاتِ }  { ٱلْمُشْرِكَاتِ }  { ٱلْمُؤْمِنَاتِ }  (73) - وَقَدْ حَمَّلَ اللهُ الإِنسَانَ الأَمَانةَ (وَهِيَ التَّكَالِيفُ) لِتَكُونَ نَتيجَةُ ذلِكَ أَنْ يُعَذِّبَ مَنْ خَانَها، وَقَصَّرَ فِي حَمْلِها وَأَدَائِهَا، مِنْ المُنَافِقينَ وَالمُنَافِقَاتِ الذِينَ يُبْطِنُونَ الكُفْرَ والشِّرْكَ، وَيُظْهِرُونَ الإِيمَانَ خَوْفاً وَتَحَسُّباً، ومنَ الكَافِرِينَ الجَاحِدِينَ بِوُجُودِ اللهِ وَوحْدَانِيَّتِهِ، وَلِيَقْبَلَ تَوْبَةَ المُؤْمِنينَ وَالمُؤمِنَاتِ إِذا رَجَعُوا إِليهِ تَائِبينَ مُنِيبِينَ، لِتَلافِيهِمْ مَا فَرطَ مِنْهُمْ عَنْ جَهْلٍ وَعَدَمِ تَبَصُّرٍ، وَتَدَارُكِهِمْ ذَلِكَ بالتَّوْبَةِ.  واللهُ تَعَالى غَفَّارٌ لِلذُّنُوبِ، سَتَّارٌ لِلْعُيوبِ، كَثيرُ الرَّحْمَةِ لِلْعِبَادِ التَّائِبِينَ إِليْهِ.
