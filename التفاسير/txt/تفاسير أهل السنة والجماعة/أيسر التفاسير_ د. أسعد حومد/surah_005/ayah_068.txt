{ يَـٰأَهْلَ ٱلْكِتَابِ }  { ٱلتَّوْرَاةَ }  { طُغْيَاناً }  { ٱلْكَافِرِينَ }  (68) - قُلْ لأهْلِ الكِتَابِ مِنَ اليَهُودِ وَالنَّصَارَى فِيمَا تُبَلِّغُهُمْ إيّاهُ عَنْ رَبِّهِمْ: لَسْتُمْ عَلَى شَيءٍ يُعْتَدُّ بِهِ مِنْ أمْرِ الدِّينِ وَالهُدَى حَتَّى تُؤْمِنُوا بِجَمِيعِ مَا بِأَيْدِيكُمْ مِنَ الكُتُبِ المُنَزَّلَةِ، وَتَعْمَلُوا بِمَا فِيهَا، وَمِنْهَا الإِيمَانُ بِمُحَمَّدٍ، وَالأمْرُ بِاتِّبَاعِهِ، وَالإِيمَانِ بِمَبْعَثِهِ، وَالاقْتِدَاءُ بِشَرِيعَتِهِ، وَسَيُثيرُ مَا أنْزَلنا عَلَيكَ يَا مُحَمَّدُ، مِنَ القُرْآنِ وَالهُدَى، كَثيراً مِنَ الحَسَدِ وَالحِقْدِ وَالطُّغْيَانِ وَالكُفْرِ فِي نُفُوسِ الكَثِيرِينَ مِنْ هَؤُلاَءِ، وَلَكِنْ لَيْسَ عَلَيْكَ أنْ تَهْتَمَّ بِذَلِكَ، أوْ تَحْزَنَ لَهُ.  لاَ تَأْسَ - لاَ تَحْزَنْ وَلاَ تَأسَفْ.  يَزِيدُهُمْ طُغْيَاناً - يَزِيدُهُمْ إمْعَاناً فِي الحَسَدِ.
