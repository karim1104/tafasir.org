{ يَـٰأَهْلَ }  { ٱلْكِتَابِ }  { آمَنَّا }  { فَاسِقُونَ }  (59) - قُلْ يَا مُحَمَّدُ لهؤلاءِ الذِينَ يَتَّخِذُونَ دِينَكُمْ هُزْواً وَلَعِباً مِنْ أهْلِ الكِتَابِ: هَلْ لَكُمْ مَطْعَنٌ عَلينا، وَمَا الذِي تَعِيبُونَهُ عَلينا، وَتَنْقِمُونَهُ مِنّا، غَيْرَ إيمانِنَا بِرَبِّنا، وَبِمَا أنْزَلَهُ إلَيْنا وَمَا أَنْزَلَهُ عَلَى أهْلِ الكِتَابِ مِنْ قَبْلِنَا، وَغَيْرَ إيْمَانِنَا - يَا أهْلَ الكِتَابِ - بِأنَّ أَكْثَرَكُمْ فَاسِقُونَ خَارِجُونَ عَنْ طَاعَةِ اللهِ، وَعَنْ طَرِيقِ الهُدْى؟  نَقَمَ عَلَيهِ - أنْكَرَ عَلَيهِ أوْ عَابَهُ.
