{ آيَاتِهِ }  { ٱلسَّمَاوَاتِ }  { ٱخْتِلاَفُ }  { أَلْوَانِكُمْ }  { لآيَاتٍ }  { لِّلْعَالَمِينَ } (22) - ومِنْ آياتِهِ الدَّالَّةِ عَلَى قُدْرَتِهِ العَظِيمَةِ، أَنَّهُ تَعَالى خَلَقَ السَّماوَاتِ في ارْتِفَاعِهَا واتِّسَاعِها، وَخَلَقَ فِيها النُّجُومَ والكَواكِبَ، وَخَلَقَ الأَرضَ وَمَا فِيها مِنْ بِحَارٍ وَمياهٍ ومخلُوقَاتٍ وَنَبَاتَاتٍ وجِبَالٍ، وجَعَلَ أَلسِنَةَ البَشَرِ مُخْتَلِفَةً مُتَمَايِزَةً، كَما جَعَلَ أَلوانَ البَشَرِ مُخْتَلِفةً، وإِن تَشَابَهُوا جَمِيعاً في الخُطُوطِ الكُبرى مِنْ مَلاَمِحِهِم، وَفي ذَلك آياتٌ تَدُلُّ عَلى عَظَمَةِ الخَالِقِ لأُِولِي العِلْمِ الذِينَ يَتَفَكَّرُونَ فِيمَا خَلَقَ اللهُ.
