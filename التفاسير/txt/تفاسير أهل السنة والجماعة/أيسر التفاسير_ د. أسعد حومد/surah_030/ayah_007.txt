{ ظَاهِراً }  { ٱلْحَيَاةِ }  { غَافِلُونَ }  (7) - وَأَكْثَرُ النَّاسِ لَيْسَ لَهُمْ عِلْمٌ إلاَّ بِالأُمُورِ الدُّنْيا: كَتَدْبيرِ مَعَايِشِهِمْ، وَتَنْمِيَةِ مَتَاجِرِهِمْ، وَاسْتِثْمَارِ مَزَارِعِهِمْ.. وَهُمْ غَافِلُونَ عَنْ أُمُورِ الدِّينِ، وما يَنْفَعُهُمْ في الآخِرَةِ، كَأَنَّ أَحَدَهُمْ مُغَفَّلٌ لا عَقْلَ لَهُ.
