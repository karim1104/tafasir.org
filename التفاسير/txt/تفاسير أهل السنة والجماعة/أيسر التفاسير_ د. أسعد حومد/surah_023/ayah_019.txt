{ جَنَّاتٍ }  { وَأَعْنَابٍ }  { فَوَاكِهُ }  (19) - فَأَخْرَجَ اللهُ بِهَذَا المَاءِ الذي أَنْزَلَهُ مِنَ السمَاءِ بَسَاتِينَ وَحَدَائِقَ (جَنَّاتٍ)، فِيهَا النَّخِيلُ والأَعْنَابُ والزَّيْتُونُ وغَيْرُها مِنَ الفَوَاكِهِ الكَثِيرَةِ التِي يَأْكُلُهَا النَّاسُ، وَيَتَمتَّعُونَ بِهَا.  { لِّلآكِلِيِنَ }
