{ أُوْلَـٰئِكَ }  { يُسَارِعُونَ }  { ٱلْخَيْرَاتِ }  { سَابِقُونَ }  (61) - وَهَؤُلاَءِ الذينَ جَمَعُوا هَذِهِ المَحَاسِنَ، يَرْغَبُونَ فِي الطَّاعَاتِ أَشَدَّ الرَّغْبَةِ، فَيُبَادِرُونَهَا لِئلاَّ تَفُوتَهم إِذَا هُمْ مَاتُوا، وَيَتَعَجَّلُونَ فِي الدَّنْيَا وُجُوهَ الخَيْرَاتِ العَاجِلَةِ التي وُعِدُوا بِهَا عَلَى الأَعْمَالِ الصَّالِحَةِ، وَهُمْ يَرْغَبُونَ فِي الطَّاعَاتِ، وَهُمْ لأَِجْلِهَا سَابِقُونَ النَّاسَ إِلَى الثَّوَابِ.
