{ عِظَاماً }  { ٱلْعِظَامَ }  { أَنشَأْنَاهُ }  { آخَرَ }  { ٱلْخَالِقِينَ }  (14) - ثُمَّ صَيَّرَ النُطْفَةَ عَلَقَةً مِنْ دَمٍ. ثُمَّ صَيَّرَ العَلَقَةَ مُضْغَةً - أَيْ قِطْعَةً مِنْ لَحْمٍ بِقَدَرِ مَا يُمْضَغُ - ثُمَّ أَعْطَى هَذِهِ المُضْغَةَ شَكْلَ المَخْلُوقِ، فَأَخَذَ فِي إِظْهَارِ الرأسِ واليَدَيْنِ والرِّجْلَيْنِ وَمَلاَمِحِ الوَجْهِ. وَخلَقَ العِظَامَ وَكَسَاهَا لَحْمَاً، ثُمَّ جَعَلَ هذَا الجَنِينَ خَلْقَاً آخر بَعْدَ وِلاَدَتِهِ. ذَا سَمْعٍ وَبَصَرٍ وَصَوْتٍ وَحَرَكَةٍ وَإِدْرَاكٍ، مُغَايِراً لِمَا كَانَ عَلَيْهِ فِي بَدْءِ تَكَوِينِهِ، ثُمَّ يَتَطَّورُ فِي النُمُوِّ. فَتَبَارَكَ اللهُ، وَتَنَزَّهَ عَلَى هَذِهِ القُدْرَةِ، وَعَلَى هَذَا الخَلْقِ.  عَلَقَةً - دَماً مُتَجَمِّداً.  مُضْغَةً - قِطْعَةَ لَحْمٍ قَدْرَ مَا يُمْضَغُ.  خَلْقاً آخَرَ - مُبَايِناً للأَوَّل بِنَفْخِ الرُّوحِ فِيهِ.  أَحْسَنُ الخَالِقِينَ - أَتْقَنُ الصَّانِعِينَ والمُصَوِّرِينَ.
