{ يَا أَيُّهَا }  { آمَنُوۤاْ }  { أَعْقَابِكُمْ }  { خَاسِرِينَ }  (149) - يُحَذِّرُ اللهُ تَعَالَى عِبَادَهُ المُؤْمِنينَ مِنْ إطَاعَةِ الكَافِرِينَ وَالمُنَافِقينَ، الذِينَ حَاوَلُوا إلْقَاءَ الشُّبُهَاتِ فِي قُلُوبِ ضِعَافِ المُؤْمِنينَ بِقَوْلِهِمْ: لَوْ كَانَ مُحَمَّدٌ نَبِيّاً حَقّاً لانْتَصَرَ وَلَمْ يَكُنْ لَهُ يَوْمٌ وَعَلِيهِ يَوْمٌ. (وَهَؤُلاءِ هُمْ أبُو سُفْيَانُ وَعَبْدُ اللهِ بْنُ أُبَيِّ بْنِ سَلُولٍ) لأنَّ إِطَاعَتَهُمْ تُورِثُ البَوَارَ فِي الدُّنْيا، بِخُضُوعِهِمْ لِسُلْطَانِهِمْ، وَذِلَّتِهِمْ بَيْنَهُمْ، وَفِي الآخِرَةِ فِيمَا يُصِيبُهُمْ مِنَ العَذَابِ الأَبَدِيِّ فِي نَارِ جَهَنَّمَ، وَجَهَنَّمُ بِئْسَ المَصِيرُ وَالمُسْتَقَرُّ.
