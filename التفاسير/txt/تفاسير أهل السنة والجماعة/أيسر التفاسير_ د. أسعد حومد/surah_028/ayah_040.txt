{ فَأَخَذْنَاهُ }  { فَنَبَذْنَاهُمْ }  { عَاقِبَةُ }  { ٱلظَّالِمِينَ }  (40) - فَجَمَعَ اللهُ تَعَالَى فِرْعَوْنَ وَجُنُودَهُ، وأَغْرَقَهُمْ في البَحْرِ في صَبِيحَةِ وَاحِدَةٍ، وَلَمْ يُبْقِ مِنْهُمْ أَحَداً. فَانظُرْ أَيُّها المُعْتَبِرُ بالآيَاتِ، كَيفَ كَانَ أَمرُ هؤلاءِ الذينَ كَفَرُوا بِرَبِّهِمْ، وَظَلَمُوا أَنْفُسَهُمْ، وَهذِهِ هِيَ عَاقِبَةُ الكُفرِ والبَغْيِ والظُّلْمِ.  فَنَبَذْنَاهُمْ فِي اليَمِّ - ألقَيْنَاهُمْ وأَغْرَقْنَاهُمْ في البَحْرِ.
