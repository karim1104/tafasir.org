{ ٱلْمُنَافِقُونَ }  { ٱلْمُنَافِقَاتُ }  { آمَنُواْ }  { ظَاهِرُهُ }  (13) - وَفِي يَوْمِ القِيَامَةِ يَقُولُ المُنَافِقُونَ وَالمُنَافِقَاتُ لِلْمُؤْمِنِينَ الذِينَ سَعَى نُورُهُمْ بَيْنَ أَيْدِيهِمْ فَاتَّبَعُوهُ وَنَجَوْا: انْتَظِرُونَا لِنَلْحَقَ بِكُمْ، وَنَقْتَبِسَ مِنْ نُورِكُمْ حَتَّى نَخْرُجَ مِنَ الظُّلْمَةِ التِي نَحْنُ فِيهَا، فَيُقَالُ لَهُمْ: ارْجِعُوا مِنْ حَيْثُ أَتَيْتُمْ، وَاطْلُبُوا لأَِنْفُسِكُمْ نُوراً، فَلاَ سَبِيلَ لأَِحَدٍ أَنْ يَقْتَبِسَ مِنْ نُورِ أَحَدٍ، فِي هَذَا اليَوْمِ، فَيَرْجِعُ المُنَافِقُونَ إِلَى حَيْثُ كَانُوا فَلاَ يَجِدُونَ شَيْئاً فَإِذَا أَرَادُوا العَوْدَةَ لِلِّحَاقِ بِالمُؤْمِنينَ، ضُرِبَ بَيْنَ المُؤْمِنِينَ وَالمُنَافِقِينَ بِسُورٍ يَفْصِلُ بَيْنَ الجَنَّةِ، التِي دَخَلَهَا المُؤْمِنُونَ، لِيَنْعَمُوا فِيهَا، وَبَيْنَ العَذَابِ الذِي أَعَدَّهُ اللهُ تَعَالَى لِلْكَافِرِينَ وَالمُنَافِقِينَ لِيَذُوقُوهُ.  انْظُرُونَا - انْتَظِرُونَا.  نَقْتَبِسْ - نُصِبْ وَنَأْخُذْ وَنَسْتَضِىءْ.  بِسُورٍ - بِحَاجِزٍ بَيْنَ الجَنَّةِ والنَّارِ (الأَعْرَافِ).
