{ آمِنُواْ }  { وَجَاهِدُواْ }  { ٱسْتَأْذَنَكَ }  { أُوْلُواْ }  { ٱلْقَاعِدِينَ }  (86) - وَإِذَا أُنْزِلتَ سُورَةٌ مُحْكَمَةٌ فِيهَا دَعْوَةٌ إِلَى الإِيْمَانِ بِاللهِ، وَالإِخْلاَصِ فِي الْعَقِيدَةِ لَهُ، وَفِيهَا ذِكْرٌ لِلْقِتَالِ، وَحَثٌّ عَلَى الْجِهَادِ مَعَ رَسُولِ اللهِ صلى الله عليه وسلم، حَاوَلَ ذَوُو الْقُدْرَةِ عَلَى الجِهَادِ، وَالسَّعَةِ فِي الإِنْفَاقِ، أَنْ يَتَخَلَّفُوا عَنِ القِيَامِ بِمَا أَمَرَ اللهُ، وَاسْتَأْذَنُوكَ فِي القُعُودِ مَعَ الْقَاعِدِينَ مِنَ الْعَجَزَةِ وَأَصْحَابَ الأَعْذَارِ.  أُولُو الطَّوْلِ - أَصْحَابُ الغِنَى وَاليَسَارِ.
