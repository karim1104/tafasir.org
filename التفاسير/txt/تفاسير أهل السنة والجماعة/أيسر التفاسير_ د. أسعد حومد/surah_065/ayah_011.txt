{ يَتْلُواْ }  { آيَاتِ }  { مُبَيِّنَاتٍ }  { آمَنُواْ }  { ٱلصَّالِحَاتِ }  { ٱلظُّلُمَاتِ }  { صَالِحاً }  { جَنَّاتٍ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  (11) - وَأَرْسَلَ اللهُ تَعَالَى إِليكُمْ، يَا ذَوِي الأَلْبَابِ وَالبَصَائِرِ مِنَ المُؤْمِنِينَ، رَسُولاً يَتْلُو عَلَيْكُمْ آيَاتِ القُرْآنِ الذِي أَنْزَلَهُ اللهُ عَلَيْهِ، وَهِيَ آيَاتٌ وَاضِحَاتٌ لِمَنْ يَتَدَبَّرُهَا وَيَعْقِلُهَا، لِيُخْرِجَ مَنْ لَدِيهِ اسْتِعْدَادٌ لِلْهُدَى مِنْ ظُلُمَاتِ الكُفْرِ، إِلَى نُورِ الإِيْمَانِ، وَمَنْ يَهْتَدِ إِلَى الإِيْمَانِ بِاللهِ فَإِنَّ اللهَ يُدْخِلُهُ جَنَّاتٍ تَجْرِي الأَنْهَارُ فِي جَنَبَاتِهَا وَيَبْقَى خَالداً فِيهَا، وَيُوَسِّعُ لَهُ فِيهَا فِي الرِّزْقِ الحَسَنِ مِنْ جَمِيعِ مَا تَشْتَهِيهِ الأَنْفُسُ وَتَلَذُّ الأَعْيُنُ.  رَسُولاً - وَأَرْسَلَ رَسُولاً.
