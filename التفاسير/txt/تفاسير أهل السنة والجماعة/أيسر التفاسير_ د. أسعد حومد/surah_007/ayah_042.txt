{ آمَنُواْ }  { ٱلصَّالِحَاتِ }  { أُوْلَـٰئِكَ }  { أَصْحَابُ }  { خَالِدُون }  (42) - وَالذِينَ آمَنَتْ قُلُوبُهُمْ، وَصَدَّقُوا رُسُلَ اللهِ فِيمَا جَاؤُوهُمْ بِهِ، وَعَمِلُوا الأَعْمَالَ الصَّالِحَةَ، بِجَوارِحِهِمْ، فَهؤلاءِ أَصْحَابُ الجَنَّةِ يَخْلُدُونَ فِيها أَبَداً.  وَالإِيمَانُ وَالعَمَلُ الصَّالِحُ سَهْلانِ مَيْسُورٌ فِعْلُهُمَا لِجَمِيعِ النَّاسِ، لأَِنَّ اللهَ لاَ يُكَلِّفُ أَحَداً إلا قَدْرَ طَاقَتِهِ وَاسْتِطَاعَتِهِ.  وُسْعَها - طَاقَتَها وَمَا تَقْدِرُ عَلَيْهِ.
