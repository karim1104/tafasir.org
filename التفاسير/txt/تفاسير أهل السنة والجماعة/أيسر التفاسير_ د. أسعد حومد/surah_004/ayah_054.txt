{ آتَاهُمُ }  { آتَيْنَآ }  { آلَ }  { إِبْرَاهِيمَ }  { ٱلْكِتَابَ }  { وَآتَيْنَاهُمْ }  (54) - إنَّ هَؤُلاَءِ يُرِيدُونَ أنْ يَضِيقَ فَضْلُ اللهِ بِعِبَادِهِ، وَلاَ يُحِبُّونَ أنْ يَكُونَ لأمَّةٍ فَضْلٌ أكْثَرُ مِمَّا لَهُمْ أوْ مِثْلُهُمْ، لِمَا اسْتَحْوذَ عَلَيْهِمْ مِنَ الغُرُورِ بِنَسَبِهِمْ، وَتَقَالِيدِهِمْ، مَعَ سُوءِ حَالِهِمْ. وَإنَّ حَسَدَهُمْ لِلرَّسُولِ صلى الله عليه وسلم، عَلَى مَا رَزَقَهُ اللهُ مِنَ النُّبُوَّةِ العَظِيمَةِ، هُوَ الذِي مَنَعَهُمْ مِنَ التَّصْدِيقِ وَالإِيمَانِ بِمَا جَاءَ بِهِ الرَّسُولُ، لأنَّهُ مِنَ العَرَبِ، وَلَيْسَ مِنْ بَني إِسْرَائِيلَ.  وَإنْ يَحْسُدُوا مُحَمَّداً عَلَى مَا أوتِيَ، فَقَدْ أخْطَؤُوا إذْ أنَّ مَا آتَى اللهُ مُحَمَّداً لَيْس بِدْعاً مِنَ اللهِ، فَقَدْ آتَى اللهُ هَذا آلَ إِبْرَاهِيمَ، وَالعَرَبُ مِنْ ذُرِّيَّةِ إِسْمَاعِيلَ، فَلِمَاذَا يَعْجَبُونَ مِمَّا آتَى اللهُ مُحَمَّداً، وَلَمْ يَعْجَبُوا مِمَّا آتَى آلَ إِبْرَاهِيمَ؟
