{ آمَنُواْ }  { ٱلصَّالِحَاتِ }  { جَنَّاتٍ }  { ٱلأَنْهَارُ }  { خَالِدِينَ }  { أَزْوَاجٌ }  (57) - وَالذِينَ صَدَّقُوا بِمَا جَاءَهُمْ مِنْ رَبِّهِمْ، وَعَمِلُوا الأَعْمَالَ الصَّالِحَةَ، فَإنَّ اللهَ سَيُثِيبُهُمْ عَلَى إيمَانِهِمْ وَعَمَلِهِمُ الصَّالِحِ، بِإدْخَالِهِمُ الجَنَّةَ التِي تَجْرِي فِي أرْضِها الأنْهَارُ، وَيَبْقُونَ فِيهَا خَالِدِينَ أَبَداً، لاَ يَحُولُونَ عَنْهَا وَلاَ يَزُولُونَ، وَلَهُمْ فِيهَا أزْوَاجٌ مُطَهَّرَةٌ، مِنَ الحَيْضِ وَالدَّنَسِ وَالأذَى، وَالأخْلاَقِ الرَّذِيلَةِ، وَالصِّفَاتِ النَّاقِصَة، وَيُدخِلُهُمْ فِي ظِلٍّ وَارِفٍ كَثِيفٍ لا حَرَّ فِيهِ وَلاَ قَرَّ.  ظَلِيلاً - دَائِماً لاَ حَرَّ فِيهِ وَلاَ قَرَّ.
