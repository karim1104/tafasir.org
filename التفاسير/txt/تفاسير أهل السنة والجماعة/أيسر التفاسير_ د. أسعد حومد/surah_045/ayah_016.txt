{ آتَيْنَا }  { ۤ إِسْرَائِيلَ }  { ٱلْكِتَابَ }  { وَرَزَقْنَاهُمْ }  { ٱلطَّيِّبَاتِ }  { فَضَّلْنَاهُمْ }  { ٱلْعَالَمينَ }  (16) - يَذْكُرُ اللهُ تَعَالى مَا أَنْعَمَ بِهِ عَلَى بَنِي إِسْرَائِيلَ مِنْ إِنزَالِ الكُتُبِ عَلَيهم، وَإرسَالِ الرُّسُلِ إِليهِم، وَمِنْ جَعْلِهِ المُلْكَ فِيهِمْ، وَمِنْ رِزْقِهِ إِيَّاهُمْ طَيِّباتِ المآكِلِ وَالمَشَارِبِ، وَمِنْ تَفْضِيلِهِمْ عَلَى أَهْلِ زَمَانِهِمْ، إِذْ لَمْ يَكُنْ في أُمَّةٍ منَ الأَنبياءِ مِثْلُمَا كَانَ فِيهِمْ.
