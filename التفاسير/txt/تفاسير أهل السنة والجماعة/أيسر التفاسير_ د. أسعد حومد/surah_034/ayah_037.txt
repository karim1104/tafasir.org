{ أَمْوَالُكُمْ }  { أَوْلاَدُكُمْ }  { آمَنَ }  { صَالِحاً }  { فَأُوْلَـٰئِكَ }  { آمِنُونَ }  { ٱلْغُرُفَاتِ }  (37) - قُلْ لَهُمْ يَا مُحَمَّدُ: إِنَّ أَمْوَالَكُمُ التي تُفَاخِرُونَ النَّاسَ بِها، وَأَوْلاَدَكُم الذِينَ تَسْتَكْبِرُونَ بِهِمْ عَلَى النَّاسِ، لا تُقرِّبُكُمْ مِنَ اللهِ، وَليسَتْ دَلِيلاً عَلَى عِنَايَتِهِ بِكُمْ، وَمَحَبَّتِهِ إِيَّاكُمْ، وَإِنَّما الذِي يُقَرِّبُكُمْ مِنَ اللهِ هُوَ الإِيمَانُ وَالعَمَلُ الصَّالِحُ، وَاللهُ يُضَاعِفُ لِمَنْ آمَنَ وَعَمِلَ صَالِحاً جَزَاءَ عَمَلِهِ فَيَجْزِيهِ بِالحَسَنَةِ عَشَرَةَ أَمْثَالِها إِلى سَبْعِمِئَةِ ضِعْفٍ، وَيُدْخِلُهُ الجَنَّةَ، وَيَجْعَلُ مَسْكَنَهُ فِي غُرُفَاتِها العَالِيَةِ، وَهُوَ آمِنٌ مِنْ كُلِّ خَوْفٍ وَشَرٍّ وَهَوْلٍ.  زُلْفَى - تَقْرِيباً.  لَهُمْ جَزَاءُ الضِّعْفِ - لَهُمُ الثَّوَابُ المُضَاعَفُ.  فِي الغُرُفَاتِ - المَنَازِلِ الرَّفِيعَةِ العَالِيَةِ في الجَنَّةِ.
