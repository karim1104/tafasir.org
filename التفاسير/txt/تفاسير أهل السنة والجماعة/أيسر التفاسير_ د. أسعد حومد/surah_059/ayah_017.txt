{ عَاقِبَتَهُمَآ }  { خَالِدِينَ }  { جَزَآءُ }  { ٱلظَّالِمِينَ }  (17) - فَكَانَ عَاقِبَةَ الأَمْرِ بِالكُفْرِ أَنْ صَارَ الشَّيْطَانُ وَمَنْ أَغْرَاهُ بِالكُفْرِ إِلَى نَارِ جَهَنَّمَ، لِيَبْقَيَا فِيهَا خَالِدَيْنِ أَبَداً، وَذَلِكَ العَذَابُ فِي نَارِ جَهَنَّمَ، هُوَ جَزَاءُ كُلِّ مَنْ ظَلَمَ نَفْسَهُ بِالكُفْرِ وَالفُسُوقِ وَالعِصْيَانِ.
