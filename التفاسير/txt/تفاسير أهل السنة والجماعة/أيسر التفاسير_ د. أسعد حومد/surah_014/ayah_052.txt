{ بَلاَغٌ }  { وَاحِدٌ }  { أُوْلُواْ }  { ٱلأَلْبَابِ }  (52) - هذا القُرْآنُ بَلاَغٌ لِجَمِيعِ المَخْلُوقَاتِ، مِنْ إِنْسٍ وَجِنٍّ، لِيَتَّعِظُوا بِهِ، وَلِيَعْلَمُوا حُدُودَ مَا أَنْزَلَ اللهُ عَلَى رُسُلِهِ، وَلِيَسْتَدِلُّوا بِمَا فِيهِ مِنَ الحُجَجِ وَالدَّلاَلاَتِ عَلَى أَنَّ اللهَ وَاحِدٌ لا إِلهَ غَيْرُهُ، وَلْيَتَذَكَّر ذَوُو العُقُولِ وَالأَفْهاَم ِ(الأَلْبَابِ).  بَلاَغٌ لِلنَّاسِ - كِفَايَةٌ فِي العِظَةِ وَالتَّذْكِيرِ.  الأَلْبَابِ - العُقُولِ وَالأَفْهَامِ.
