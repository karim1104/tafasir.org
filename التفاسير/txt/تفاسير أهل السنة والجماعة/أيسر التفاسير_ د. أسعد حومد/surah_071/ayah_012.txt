{ بِأَمْوَالٍ }  { جَنَّاتٍ }  { أَنْهَاراً }  (12) - وَيُكَثِّرُ لَكُمُ الأَمْوَالَ وَالخَيْرَاتِ، وَيُكَثِّرُ لَكُمُ الأَوْلاَدَ، وَيَجْعَلُ لَكُمْ بَسَاتِينَ تُنْتِجُ الثِّمَارَ، وَيَجْعَلُ لَكُمْ أَنْهَاراً جَارِيَةً تَرْوِي الزُّروعَ وَالبَسَاتِينَ والأَشْجَارَ وَالمَوَاشِيَ فَتَزْدَادُ الخَيْرَاتُ.
