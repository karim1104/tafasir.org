{ تِجَارَةٌ }  { ٱلصَّلاَةِ }  { ٱلزَّكَـاةِ }  { ٱلأَبْصَارُ }  (37) - وَهَؤُلاَءِ الرِّجَالُ، الذينَ يَعْمُرُونَ بُيُوتَ اللهِ، هُمُ رِجَالٌ أَصْحَابُ هِمَمٍ وَعَزَائِمَ لاَ يُلْهِيهِمْ شَيْءٌ عَنْ ذِكْرِ اللهِ، وإِقَامِ الصَّلاَةِ: لاَ تِجَارَةٌ، وَلاَ بَيْعٌ، وَلاَ تَشْغَلُهُم الدُّنْيَا وَزُخْرُفُهَا، وَزِينَتُهَا، وَمَلاَذُّهَا، وَلاَ بَيْعُها، وَلاَ رِبْحُها.. عَنْ ذِكْرِ رَبِّهِمْ لأَنَّهُمْ يَعْلَمُونَ أَنَّ الذي عَنْدَ اللهِ خَيْرٌ لَهُمْ وأَنْفَعُ مِمَا بِأَيْدِيهِمْ، وَهُمْ يُقَدِّمُونَ طَاعَةَ رَبِّهِمْ وَمَحَبَّتَه عَلَى مُرَادِهِم وَمَحَبَّتِهِمْ، فَلاَ شَيءَ يُلْهِيهِم عَنْ أَنْ يُؤدُّوا الصَّلاَةَ فِي وَقْتِهَا، لأَِنَّهُمْ يَخَافُونَ يَوْمَ القِيَامَةِ الذي تتَقَلَّبُ فِيهِ القُلُوبُ والأَبْصَارُ مِنْ شِدَّةِ الفَزَعِ، وَعِظَمِ الهَوْلِ.
