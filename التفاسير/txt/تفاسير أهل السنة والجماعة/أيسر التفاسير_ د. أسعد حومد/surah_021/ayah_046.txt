{ وَلَئِن }  { يٰويْلَنَآ }  { ظَالِمِينَ }  (46) - وإذا مَسَّ هَؤُلاَءِ المُكَذِّبِينَ شَيءٌ يَسِيرٌ مِنْ عَذَابِ اللهِ الذِي يَسْخَرُونَ مِنْهُ، وَلَوْ كَانَ طَفِيفاً { نَفْحَةٌ } ، فَإِنَّهُمْ يَعْتَرِفُونَ بِذُنُوبِهِم، وَيَقُولُونَ: إِنَّهُمْ كَانُوا ظَالِمِينَ لأَِنْفُسِهِمْ فِي الدُّنْيَا بِعِبَادَتِهِمْ غَيْرَ اللهِ، وَتَرْكِهِمْ عِبَادَةَ الوَاحِدِ الأحَدِ، الذِي لاَ إِلَهَ سِوَاهُ.  نَفْحَةٌ - دَفْعَةٌ يَسِيرَةٌ، أَوْ نَصِيبٌ يَسِيرٌ.
