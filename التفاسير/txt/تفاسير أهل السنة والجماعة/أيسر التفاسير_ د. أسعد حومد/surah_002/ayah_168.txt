{ يٰأَيُّهَا }  { حَلاَلاً }  { خُطُوَاتِ }  { ٱلشَّيْطَانِ }  (168) - يَمْتَنُّ اللهُ تَعَالَى جَدُّهُ عَلَى النَّاسِ بِمَا أَبَاحَ لَهُمْ مِنَ الأَكلِ مِمَّا فِي الأَرْضِ مِنْ أَصْنَافِ المَأْكُولاَتِ حَلاَلاً طَيِّباً، وَيَنْهَاهُمْ عَنِ اتِّبَاعِ سِيرَةِ الشَّيطَانِ فِي الإِغْوَاءِ وَالإِضْلاَلِ، وَالوَسْوَسَةِ بِالسُّوءِ وَالفَحْشَاءِ، وَعَنِ اتِّبَاعِ مَسْلَكِهِ وَطَرَائِقِهِ فِيمَا أَضَلَّ بِهِ أَتْبَاعَهُ مِنْ تَحْرِيمِ البَحَائِرِ وَالسَّوائِبِ وَالوَصَائِلِ وَغَيرِهَا مِمَّا كَانَ زَيَّنَهُ لِلْمُشْرِكِينَ فِي الجَاهِلِيَّةِ، لأَنَّ الشَّيطَانَ عَدُوٌّ مُبِينُ العَدَاوَةِ للإِنْسَانِ.  خُطُواتِ الشَّيطَانِ - طُرُقَهُ وَأَسَالِيبَهُ.
