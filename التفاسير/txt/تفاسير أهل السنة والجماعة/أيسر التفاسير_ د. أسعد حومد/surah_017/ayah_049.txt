{ أَإِذَا }  { عِظَاماً }  { وَرُفَاتاً }  { أَإِنَّا }  (49) - يُخْبِرُ اللهُ تَعَالَى عَمَّا قَالَهُ الكُفَّارُ، وَهُمُ يَسْتَبْعِدُونَ وُقُوعَ الحَشْرِ وَالمَعَادِ، فَيَسْتَفْهِمُونَ اسْتِفْهَامَ مُنْكِرٍ: هَلْ إِذا صِرْنَا عِظَاماً وَتُرَاباً هَلْ سَنُخْلَقُ مِنْ جَدِيدٍ خَلْقاً آخَرَ يَوْمَ القِيَامَةِ؟ إِنَّ هَذا لَشَيءٌ لاَ يُصَدِّقُهُ العَقْلُ السَّلِيمُ.  رُفَاتاً - أَجْزَاءً مُفَتَّتَةً أَوْ تُرَاباً أَوْ غُبَاراً.
