قوله تعالى :  {  ولا أقسم بالنفس اللوامة }  النفس الأمارة بالسوء هي النفس اللوامة ،   وهي قرينة الحرص وطول الأمل .   ثم قال :  إنما نهاكم الله عن القبول وعن الاغترار بالدنيا وعن مخادعة النفس ،   فقال تعالى :  {  إن النفس لأمارة بالسوء } [ يوسف :  53 ] وقال :  {  فلا تغرنكم الحياة الدنيا } [ لقمان :  33 ] وقال :  {  إن الشيطان لكم عدو } [ فاطر :  6 ] .
