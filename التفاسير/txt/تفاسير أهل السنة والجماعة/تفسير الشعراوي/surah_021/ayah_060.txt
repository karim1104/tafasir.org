أي :  تطوع بعضهم وقالوا هذا ،  وكان لقوم يوم محدد يذهبون فيه إلى معبدهم ومكان أصنامهم ،  ويأخذون طعامهم وشرابهم ،  ويبدو أنه كان يوم عيد عندهم ،  وقد استعد آزر لهذا اليوم ،  وأراد أن يأخذ معه إبراهيم لعل الآلهة تجذبه فيهتدي وينصرف عما هو فيه .

لكن إبراهيم عليه السلام ادعى أنه مريض ،  لا يستطيع الخروج معهم ،  فقال {  إني سقيم( 89 ) } ( الصافات ) وعندها عزم إبراهيم على تحطيم أصنامهم وقال :  {  تَاللَّهِ لَأَكِيدَنَّ أَصْنَامَكُم بَعْدَ أَن تُوَلُّوا مُدْبِرِينَ ( 57 ) } ( الأنبياء ) :  سمعه بعض القوم فأخبرهم بأمره .

{  قَالُوا سَمِعْنَا فَتًى يَذْكُرُهُمْ .  .  ( 60 ) } ( الأنبياء ) :  والذكر هنا يعني بالشر بالنسبة لهم ،  {  يُقَالُ لَهُ إِبْرَاهِيمُ ( 60 ) } ( الأنبياء ) :  يعني :  اسمه إبراهيم ،  أو حين نناديه نقول :  يا إبراهيم .
