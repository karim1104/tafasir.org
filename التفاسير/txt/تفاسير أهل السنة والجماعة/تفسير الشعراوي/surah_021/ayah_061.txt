ثم يقول الحق سبحانه :  {  قَالُوا فَأْتُوا بِهِ عَلَى أَعْيُنِ النَّاسِ لَعَلَّهُمْ يَشْهَدُونَ ( 61 ) } .

ومعنى :  {  على أعين الناس .  .  ( 61 ) } ( الأنبياء ) :  يعني :  على مرأى منهم ليشاهدوه بأعينهم {  لَعَلَّهُمْ يَشْهَدُونَ ( 61 ) } ( الأنبياء ) : أي :  يشهدون ما نوقعه به من العذاب حتى لا يجترئ أحد آخر أن يفعل هذه الفعلة ،  ويكون عبرة لغيره .
