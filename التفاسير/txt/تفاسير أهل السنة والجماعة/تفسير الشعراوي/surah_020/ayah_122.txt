ثم يقول الحق سبحانه :  {  ثُمَّ اجْتَبَاهُ رَبُّهُ فَتَابَ عَلَيْهِ وَهَدَى ( 122 ) } .

إذن :  مثل آدم دور الإنسان العادي الذي يطيع ويعصي ،  ويسمع كلام الشيطان ،  لكن ربه شرع له التوبة كما قال سبحانه :  {  فتلقى آدم من ربه كلمات فتاب عليه .  .  ( 37 ) } ( البقرة ) .

إذن :  عصى آدم وهو إنسان عادي وليس وهو نبي كما يقول البعض .

فقوله :  {  ثم اجتباه .  .  ( 122 ) } ( طه ) :  هذه بداية لمرحلة النبوة في حياة آدم عليه السلام ،  و ( ثم ) تعني الترتيب مع التراخي {  اجتباه .  .  ( 122 ) } ( طه ) اصطفاه ربه .

ولم يقل الحق سبحانه :  ثم اجتباه الله ،  إنما{  اجتباه ربه .  .  ( 122 ) } ( طه ) :  لأن الرب المتولي للتربية والرعاية ،  ومن تمام التربية الإعداد للمهمة ،  ومن ضمن إعداد آدم لمهمته أن يمر بهذه التجربة ،  وهذا الترتيب في الجنة .

{  وهدى ( 122 ) } ( طه ) :  المراد بالهداية قوله :  {  قَالَ اهْبِطَا مِنْهَا جَمِيعًا بَعْضُكُمْ لِبَعْضٍ عَدُوٌّ فَإِمَّا يَأْتِيَنَّكُم مِّنِّي هُدًى فَمَنِ اتَّبَعَ هُدَايَ فَلَا يَضِلُّ وَلَا يَشْقَى ( 123 ) } .
