{  19-22 } {  وَجَاءَتْ سَكْرَةُ الْمَوْتِ بِالْحَقِّ ذَلِكَ مَا كُنْتَ مِنْهُ تَحِيدُ * وَنُفِخَ فِي الصُّورِ ذَلِكَ يَوْمُ الْوَعِيدِ * وَجَاءَتْ كُلُّ نَفْسٍ مَعَهَا سَائِقٌ وَشَهِيدٌ * لَقَدْ كُنْتَ فِي غَفْلَةٍ مِنْ هَذَا فَكَشَفْنَا عَنْكَ غِطَاءَكَ فَبَصَرُكَ الْيَوْمَ حَدِيدٌ }

أي {  وَجَاءَتْ } هذا الغافل المكذب بآيات الله {  سَكْرَةُ الْمَوْتِ بِالْحَقِّ } الذي لا مرد له ولا مناص ،  {  ذَلِكَ مَا كُنْتَ مِنْهُ تَحِيدُ } أي :  تتأخر وتنكص  عنه .
