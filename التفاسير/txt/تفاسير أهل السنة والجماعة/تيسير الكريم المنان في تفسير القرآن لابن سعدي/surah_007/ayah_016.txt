{  16 - 17 } {  قَالَ فَبِمَا أَغْوَيْتَنِي لَأَقْعُدَنَّ لَهُمْ صِرَاطَكَ الْمُسْتَقِيمَ * ثُمَّ لَآتِيَنَّهُمْ مِنْ بَيْنِ أَيْدِيهِمْ وَمِنْ خَلْفِهِمْ وَعَنْ أَيْمَانِهِمْ وَعَنْ شَمَائِلِهِمْ وَلَا تَجِدُ أَكْثَرَهُمْ شَاكِرِينَ }

أي :  قال إبليس - لما أبلس وأيس من رحمة اللّه - {  فَبِمَا أَغْوَيْتَنِي لَأَقْعُدَنَّ لَهُمْ } أي :  للخلق {  صِرَاطَكَ الْمُسْتَقِيمَ } أي :  لألزمن الصراط ولأسعى غاية جهدي على صد الناس عنه وعدم سلوكهم إياه .
