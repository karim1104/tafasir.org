{  13-14 } {  إِنَّ الَّذِينَ قَالُوا رَبُّنَا اللَّهُ ثُمَّ اسْتَقَامُوا فَلَا خَوْفٌ عَلَيْهِمْ وَلَا هُمْ يَحْزَنُونَ * أُولَئِكَ أَصْحَابُ الْجَنَّةِ خَالِدِينَ فِيهَا جَزَاءً بِمَا كَانُوا يَعْمَلُونَ } أي :  إن الذين أقروا بربهم وشهدوا له بالوحدانية والتزموا طاعته

وداموا على ذلك ،  و {  اسْتَقَامُوا } مدة حياتهم {  فَلَا خَوْفٌ عَلَيْهِمْ } من كل شر أمامهم ،  {  وَلَا هُمْ يَحْزَنُونَ } على ما خلفوا وراءهم .
