{  50 - 51 } {  إِنْ تُصِبْكَ حَسَنَةٌ تَسُؤْهُمْ وَإِنْ تُصِبْكَ مُصِيبَةٌ يَقُولُوا قَدْ أَخَذْنَا أَمْرَنَا مِنْ قَبْلُ وَيَتَوَلَّوْا وَهُمْ فَرِحُونَ * قُلْ لَنْ يُصِيبَنَا إِلَّا مَا كَتَبَ اللَّهُ لَنَا هُوَ مَوْلَانَا وَعَلَى اللَّهِ فَلْيَتَوَكَّلِ الْمُؤْمِنُونَ }

يقول تعالى مبينا أن المنافقين هم الأعداء حقا ،  المبغضون للدين صرفا :  {  إِنْ تُصِبْكَ حَسَنَةٌ } كنصر وإدالة على العدو {  تَسُؤْهُمْ } أي :  تحزنهم وتغمهم .

{  وَإِنْ تُصِبْكَ مُصِيبَةٌ } كإدالة العدو عليك {  يَقُولُوا } متبجحين بسلامتهم من الحضور معك .

{  قَدْ أَخَذْنَا أَمْرَنَا مِنْ قَبْلُ } أي :  قد حذرنا وعملنا بما ينجينا من الوقوع في مثل هذه المصيبة .

{  وَيَتَوَلَّوْا وَهُمْ فَرِحُونَ } فيفرحون بمصيبتك ،  وبعدم مشاركتهم إياك فيها .
