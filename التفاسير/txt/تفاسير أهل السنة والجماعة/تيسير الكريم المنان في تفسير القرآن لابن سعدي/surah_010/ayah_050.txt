{  50 - 52 ْ } {  قُلْ أَرَأَيْتُمْ إِنْ أَتَاكُمْ عَذَابُهُ بَيَاتًا أَوْ نَهَارًا مَاذَا يَسْتَعْجِلُ مِنْهُ الْمُجْرِمُونَ * أَثُمَّ إِذَا مَا وَقَعَ آمَنْتُمْ بِهِ آلْآنَ وَقَدْ كُنْتُمْ بِهِ تَسْتَعْجِلُونَ * ثُمَّ قِيلَ لِلَّذِينَ ظَلَمُوا ذُوقُوا عَذَابَ الْخُلْدِ هَلْ تُجْزَوْنَ إِلَّا بِمَا كُنْتُمْ تَكْسِبُونَ ْ }

يقول تعالى :  {  قُلْ أَرَأَيْتُمْ إِنْ أَتَاكُمْ عَذَابُهُ بَيَاتًا ْ } وقت نومكم بالليل {  أَوْ نَهَارًا ْ } في وقت غفلتكم {  مَاذَا يَسْتَعْجِلُ مِنْهُ الْمُجْرِمُونَ ْ } أي :  أي بشارة استعجلوا بها ؟  وأي عقاب ابتدروه ؟  .
