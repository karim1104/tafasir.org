{  وَالذَّارِيَاتِ ذَرْواً } * {  فَالْحَامِلاَتِ وِقْراً } * {  فَالْجَارِيَاتِ يُسْراً } * {  فَالْمُقَسِّمَاتِ أَمْراً }

أخبرنا أبو جعفر .  قال :  حدّثنا علي بن أحمد .  قال :  حدّثنا عطاء بن السّائب عن أبي خالد عن زيد بن علي عليهما السّلامُ في قولهِ تعالى :  {  وَالذَّارِيَاتِ ذَرْواً } معناهُ الرِّياحُ
