وقوله تعالى :  {  هَلْ يَنظُرُونَ إِلاَّ أَن تَأْتِيهُمُ الْمَلائِكَةُ } معناهُ تَنتَظرُونَ .  قالَ زيدُ بن علي عليهما السَّلامُ :  {  هَلْ يَنظُرُونَ إِلاَّ أَن تَأْتِيهُمُ الْمَلائِكَةُ } قالَ :  المَوتُ :  {  أَوْ يَأْتِيَ رَبُّكَ } قال :  القِيامةُ {  أَوْ يَأْتِيَ بَعْضُ آيَاتِ رَبِّكَ } قالَ :  هُوَ طُلُوعُ الشَّمسِ مِن مَغْرِبِهَا .
