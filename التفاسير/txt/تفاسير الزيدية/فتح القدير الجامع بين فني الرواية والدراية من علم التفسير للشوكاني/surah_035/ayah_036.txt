ثم لما فرغ سبحانه من ذكر جزاء عباده الصالحين ،  ذكر جزاء عباده الطالحين ،  فقال : { والذين كَفَرُواْ لَهُمْ نَارُ جَهَنَّمَ لاَ يقضى عَلَيْهِمْ فَيَمُوتُواْ } أي لا يقضي عليهم بالموت ،  فيموتوا ،  ويستريحوا من العذاب { وَلاَ يُخَفَّفُ عَنْهُمْ مّنْ عَذَابِهَا } بل { كُلَّمَا نَضِجَتْ جُلُودُهُمْ بدلناهم جُلُوداً غَيْرَهَا لِيَذُوقُواْ العذاب } [ النساء : 56 ] وهذه الآية هي مثل قوله سبحانه : { لاَ يَمُوتُ فِيهَا وَلاَ يحيى } [ الأعلى : 13 ] .   قرأ الجمهور : { فيموتوا } بالنصب جواباً للنفي ،  وقرأ عيسى بن عمر ،  والحسن بإثبات النون .   قال المازني : على العطف على { يقضى } .   وقال ابن عطية : هي قراءة ضعيفة ،  ولا وجه لهذا التضعيف بل هي كقوله : { وَلاَ يُؤْذَنُ لَهُمْ فَيَعْتَذِرُونَ } [ المرسلات : 36 ] .   { كَذَلِكَ نَجْزِى كُلَّ كَفُورٍ } أي مثل ذلك الجزاء الفظيع نجزي كل من هو مبالغ في الكفر ،  وقرأ أبو عمرو : { نجزي } على البناء للمفعول .
