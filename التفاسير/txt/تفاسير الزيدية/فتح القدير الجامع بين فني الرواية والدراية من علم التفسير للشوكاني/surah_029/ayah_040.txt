قال الكسائي : { فكلاًّ أخذنا } أي فأخذنا كلاًّ بذنبه { فَمِنْهُم مَّن أَرْسَلْنَا عَلَيْهِ حَاصِباً } أي ريحاً تأتي بالحصباء ،  وهي الحصى الصغار فترجمهم بها ،  وهم قوم لوط { وَمِنْهُمْ مَّنْ أَخَذَتْهُ الصيحة } وهم ثمود وأهل مدين { وَمِنْهُمْ مَّنْ خَسَفْنَا بِهِ الأرض } وهو قارون وأصحابه { وَمِنْهُمْ مَّنْ أَغْرَقْنَا } وهم قوم نوح وقوم فرعون { وَمَا كَانَ الله لِيَظْلِمَهُمْ } بما فعل بهم ،  لأنه قد أرسل إليهم رسله وأنزل عليهم كتبه { ولكن كَانُواْ أَنفُسَهُمْ يَظْلِمُونَ } باستمرارهم على الكفر وتكذيبهم للرسل وعملهم بمعاصي الله .
