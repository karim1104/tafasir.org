قوله : { فَبِمَا نَقْضِهِم ميثاقهم } الباء سببية وما زائدة ،  أي : فبسبب نقضهم ميثاقهم : { لعناهم } أي : طردناهم وأبعدناهم { وَجَعَلْنَا قُلُوبَهُمْ قَاسِيَةً } أي : صلبة لا تعي خيراً ولا تعقله .   وقرأ حمزة والكسائي «قسِّية » بتشديد الياء من غير ألف ،  وهي قراءة ابن مسعود والنخعي ويحيى بن وثاب ؛ يقال درهم قسىّ مخفف السين مشدّد الياء : أي زائف ،  ذكر ذلك أبو عبيد .

وقال الأصمعي وأبو عبيدة : درهم قسىّ كأنه معرب قاس .   وقرأ الأعمش «قسية » بتخفيف الياء وقرأ الباقون : { قَاسِيَةً } { يُحَرّفُونَ الكلم عَن مواضعه } الجملة مستأنفة لبيان حالهم أو حالية : أي : يبدّلونه بغيره أو يتأولونه على غير تأويله .   وقرأ السلمي والنخعي «الكلام » .   قوله : { وَلاَ تَزَالُ تَطَّلِعُ على خَائِنَةٍ مّنْهُمْ } أي : لا تزال يا محمد تقف على خائنة منهم ،  والخائنة : الخيانة ؛ وقيل هو نعت لمحذوف ،  والتقدير فرقة خائنة ،  وقد تقع للمبالغة نحو علاّمة ونسّابة إذا أردت المبالغة في وصفه بالخيانة ؛ وقيل خائنة معصية .   قوله : { إِلاَّ قَلِيلاً مّنْهُمُ } استثناء من الضمير في { منهم } { فاعف عَنْهُمْ واصفح } قيل : هذا منسوخ بآية السيف ؛ وقيل : خاص بالمعاهدين .
