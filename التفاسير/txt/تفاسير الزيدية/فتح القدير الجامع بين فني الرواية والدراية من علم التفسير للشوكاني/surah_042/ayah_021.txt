{ أَمْ لَهُمْ شُرَكَاء شَرَعُواْ لَهُمْ مّنَ الدين مَا لَمْ يَأْذَن بِهِ الله } لما بين سبحانه القانون في أمر الدنيا ،  والآخرة أردفه ببيان ما هو الذنب العظيم الموجب للنار ،  والهمزة لاستفهام التقرير والتقريع ،  وضمير { شرعوا } عائد إلى الشركاء ،  وضمير { لهم } إلى الكفار .   وقيل : العكس ،  والأوّل أولى .   ومعنى { مَا لَمْ يَأْذَن بِهِ الله } ما لم يأذن به من الشرك والمعاصي { وَلَوْلاَ كَلِمَةُ الفصل } وهي تأخير عذابهم حيث قال : { بَلِ الساعة مَوْعِدُهُمْ } [ القمر : 46 ] { لَقُضِيَ بَيْنَهُمْ } في الدنيا ،  فعوجلوا بالعقوبة ،  والضمير في { بينهم } راجع إلى المؤمنين والمشركين ،  أو إلى المشركين وشركائهم { وَإِنَّ الظالمين لَهُمْ عَذَابٌ أَلِيمٌ } أي المشركين والمكذبين لهم عذاب أليم في الدنيا والآخرة .   قرأ الجمهور { وإن الظالمين } بكسر الهمزة على الاستئناف .   وقرأ مسلم والأعرج وابن هرمز بفتحها عطفاً على { كلمة الفصل } .
