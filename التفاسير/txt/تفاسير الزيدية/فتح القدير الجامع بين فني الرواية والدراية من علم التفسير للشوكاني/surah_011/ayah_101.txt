{ وَمَا ظلمناهم } بما فعلنا بهم من العذاب { ولكن ظَلَمُواْ أَنفُسَهُمْ } بالكفر والمعاصي { فَمَا أَغْنَتْ عَنْهُمْ آلِهَتَهُمُ } أي : فما دفعت عنهم أصنامهم التي يعبدونها من دون الله شيئاً من العذاب { لَمَّا جَاء أَمْرُ رَبّكَ } أي : لما جاء عذابه { وَمَا زَادُوهُمْ غَيْرَ تَتْبِيبٍ } : الهلاك والخسران : أي ما زادتهم الأصنام التي يعبدونها إلا هلاكاً وخسراناً ،  وقد كانوا يعتقدون أنها تعينهم على تحصيل المنافع .
