{ قَالَتْ أُخْرَاهُمْ لأولاهم } أي أخراهم دخولاً لأولاهم دخولاً .   وقيل { أخراهم } : أي سفلتهم وأتباعهم { لأولاهم } لرؤسائهم وكبارهم .   وهذا أولى كما يدل عليه { رَبَّنَا هَؤُلاء أَضَلُّونَا } فإن المضلين هم الرؤساء .   ويجوز أن يراد أنهم أضلوهم لأنهم تبعوهم واقتدوا بدينهم من بعدهم ،  فيصح الوجه الأوّل ،  لأن أخراهم تبعت دين أولاهم .

قوله : { فَآتِهِمْ عَذَاباً ضِعْفاً مِّنَ النار } الضعف الزائد على مثله مرة أو مرات .   ومثله قوله تعالى : { رَبَّنَا آتِهِمْ ضِعْفَيْنِ مِنَ العذاب والعنهم لَعْناً كثيرا } وقيل : الضعف هنا الأفاعي والحيات ،  وجملة { قَالَ لِكُلّ ضِعْفٌ } استئنافية جواباً لسؤال مقدّر ،  والمعنى لكل طائفة منكم ضعف من العذاب ،  أي الطائفة الأولى والطائفة الأخرى { ولكن لاَّ تَعْلَمُونَ } بما لكل نوع من العذاب { وَقَالَتْ أولاهم لأخْرَاهُمْ } أي قال السابقون للاحقين ،  أو المتَبوعُونَ للتابعين { فَمَا كَانَ لَكُمْ عَلَيْنَا مِن فَضْلٍ } بل نحن سواء في الكفر بالله واستحقاق عذابه .   { فَذُوقُواْ } عذاب النار ،  كما ذقناه { بِمَا كُنتُمْ تَكْسِبُونَ } من معاصي الله والكفر به .
