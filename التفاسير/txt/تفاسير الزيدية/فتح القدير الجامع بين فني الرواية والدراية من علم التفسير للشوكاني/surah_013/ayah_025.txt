ثم أتبع أحوال السعداء بأحوال الأشقياء ،  فقال : { والذين يَنقُضُونَ عَهْدَ الله مِن بَعْدِ ميثاقه وَيَقْطَعُونَ مَا أَمَرَ الله بِهِ أَن يُوصَلَ } وقد مرّ تفسير عدم النقض وعدم القطع فعرف منهما تفسير النقض والقطع ،  ولم يتعرض لنفي الخشية والخوف عنهم وما بعدهما من الأوصاف المتقدّمة لدخولها في النقض والقطع { وَيُفْسِدُونَ فِي الأرض } بالكفر وارتكاب المعاصي والأضرار بالأنفس والأموال { أولئك } الموصوفون بهذه الصفات الذميمة { لَهُمْ } بسبب ذلك { اللعنة } : أي : الطرد والإبعاد من رحمة الله سبحانه { وَلَهُمْ سُوء الدار } أي : سوء عاقبة دار الدنيا ،  وهي النار أو عذاب النار .
