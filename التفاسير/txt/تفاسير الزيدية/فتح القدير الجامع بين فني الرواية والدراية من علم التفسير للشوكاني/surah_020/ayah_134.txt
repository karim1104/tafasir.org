{ وَلَوْ أَنَّا أهلكناهم بِعَذَابٍ من قَبْلِهِ } أي من قبل بعثة محمد صلى الله عليه وسلم أو من قبل إتيان البينة لنزول القرآن { لَقَالُوا } يوم القيامة { رَبَّنَا لَوْلا أَرْسَلْتَ إِلَيْنَا رَسُولاً } أي هلا أرسلت إلينا رسولاً في الدنيا { فَنَتَّبِعَ آياتك } التي يأتي بها الرسول { مِن قَبْلِ أَن نَذِلَّ } بالعذاب في الدنيا { ونخزى } بدخول النار ،  وقرئ : «نذلّ ونخزى » على البناء للمفعول .   وقد قطع الله معذرة هؤلاء الكفرة بإرسال الرسول إليهم قبل إهلاكهم ؛ ولهذا حكي الله عنهم أنهم : { قَالُوا بلى قَدْ جَاءنَا نَذِيرٌ فَكَذَّبْنَا وَقُلْنَا مَا نَزَّلَ الله مِن شَيء } [ الملك : 9 ] .
