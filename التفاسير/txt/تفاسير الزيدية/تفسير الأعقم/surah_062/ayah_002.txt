{  هو الذي بعث في الأميين رسولاً } الأمي منسوب إلى أم القرى لأنهم كانوا لا يكتبون ولا يقرون من بين الأمم ،  وقيل :  {  منهم } كقوله :  من أنفسكم {  يتلو عليهم آياته } يقرؤها عليهم مع كونه أميَّاً لم يعهد منه قراءة {  ويزكيهم } ويطهرهم من الشرك {  ويعلمهم الكتاب والحكمة } القرآن والسنة {  وإن كانوا من قبل } أي قبل مبعثه {  لفي ضلال مبين } عن الحق وذهاب عن الدين لا يرى ضلالاً أعظم منه
