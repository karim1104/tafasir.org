{  ومن الذين قالوا إنَّا نصارى أخذنا ميثاقهم } قيل :  بالاقرار بتوحيد الله ،  وأن عيسى عبده ورسوله ،  وبجميع الأنبياء ،  وقيل :  بجميع ما أمرهم به من الميثاق وغيرهم فنقضوا ذلك {  فنسوا } أي تركوا {  حظاً } نصيباً {  ممَّا ذكروا به } من الميثاق ،  وقيل :  من الكتاب {  فأغرينا بينهم العداوة والبغضاء } وقيل :  بين اليهود والنصارى {  إلى يوم القيامة } يعني عداوة تبقى بينهم إلى يوم القيامة {  وسوف ينبئهم الله } أي يخبرهم {  بما كانوا يصنعون } يجازيهم
