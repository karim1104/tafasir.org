{  لقد أخذنا ميثاق بني اسرائيل } بالتوحيد {  وأرسلنا إليهم رسلاً كلما جاءهم رسول بما لا تهوى أنفسهم } بما يخالف أهواءهم {  فريقاً كذبوا وفريقاً يقتلون وحسبوا الاَّ تكون فتنة } يعني حسب بنو إسرائيل أنهم لا يصيبهم من الله فتنة أي بلاء وعذاب في الدنيا والآخرة {  فعموا } عن الدين {  وصموا } حين عبدوا العجل ثم تابوا عن ذلك فتاب الله عليهم {  ثم عموا وصموا } مرة ثانية بطلبهم المحال في صفات الله سبحانه وهو الرؤية
