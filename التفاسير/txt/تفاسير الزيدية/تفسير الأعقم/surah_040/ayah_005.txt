ثم قال سبحانه ذاكراً حال الأمم :  {  كذّبت قبلهم قوم نوح والأحزاب } الذين تحزبوا على رسول الله وهم عاد وثمود وفرعون {  وهمَّت كل أمة } من هذه الأمم {  برسولهم ليأخذوه } وقرئ برسولها ليأخذوه ليتمكنوا منه بما أرادوا من تعذيب أو قتل {  وجادلوا بالباطل ليدحضوا به الحق } ليدفعوا ويزيلوا {  فأخذتهم } يعني أنهم قصدوا أخذه فجعلت جزاءهم على إرادة أخذه أن أخذتهم {  فكيف كان عقاب } فإنكم تمرون على بلادهم ومساكنهم فتعاينون أثر ذلك .
