{  ولا تزر وازرة وزر أخرى } أي لا تؤاخذ بذنب أحد {  وإن تدع مثقلة } أي حاملة حملاً ثقيلاً {  إلى حملها لا يحمل منه شيء ولو كان ذا قربى } وإن كان أقرب الناس إليه {  إنما تنذر الذين يخشون ربهم } إنما خصّهم لقبولهم وانتفاعهم به وإلا فهو منذر للجميع ،  ومعنى يخشون يخافون الله تعالى {  بالغيب وأقاموا الصلاة } أداموها {  ومن تزكّى } قيل :  تطهر من المآثم ،  وقيل :  صلح وعمل خيراً {  فإنما يتزكى لنفسه } لأن جزاؤه يصل إليه {  وإلى الله المصير } المرجع للجزاء
