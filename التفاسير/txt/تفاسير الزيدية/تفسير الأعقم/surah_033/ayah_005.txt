{  ادعوهم لآبائهم } أي انسبوهم إلى آبائهم الذين ولدوا على فراشهم {  هو أقسط عند الله } أعدل في القول :  لأن الانسان نسابته إلى المدعي كذب {  فإن لم تعلموا آباءهم فإخوانكم في الدين } لأن المؤمنين أخوة {  ومواليكم } في أصدقائكم ،  وقيل مواليكم في وجوب النصرة {  وليس عليكم جناح فيما أخطأتم به } يعني إذا نسبتم أحداً إلى الجدّ ظنّاً منكم أنه أباه فلا حرج {  ولكن ما تعمدت قلوبكم } فنسبتموه إلى غيركم مع علمكم بخلافه فإذا كان خطأ فلا حرج {  وكان الله غفوراً رحيماً } لعفوه عن الخطأ ،  عن العمد إذا تاب العامد
