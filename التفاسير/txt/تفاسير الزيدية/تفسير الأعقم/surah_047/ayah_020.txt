{  ويقول الذين آمنوا } حرصاً على الجهاد {  لولا نزّلت سورة } بالجهاد {  محكمة } بالأمر والنهي قال قتادة :  كل سورة ذكر فيها الجهاد فهي ملحمة محكمة وهي أشد القرآن على المنافقين {  وذكر فيها القتال } أي أمروا به {  رأيت } يا محمد {  الذين في قلوبهم مرضٌ } أي شك وكفر يعني المنافقين {  ينظرون إليك } من الخوف والجبن {  نظر المغشي عليه } وهو نظر شزر بتحديق شديد مخافة القتال كنظر المغشي عليه {  من الموت } كما ينظر من أصابته الغشية عند الموت {  فأولى لهم } وعيد ،  يعني فويل لهم ،  ومعناه الدعاء عليهم بأن يليهم المكروه
