{  قالت } يعني امرأة العزيز قالت :  {  فذلكنَّ الذي لمتُنَّني فيه } أي في حبي إياه ثم إنها أقرت على نفسها واعترفت ببراءة يوسف فقالت :  {  ولقد راودته عن نفسه } أي أردت منه الفاحشة {  فاستعصم } أي امتنع بالله وسأله العصمة {  ولئن لم يفعل ما آمره } أي إن لم يطعني فيما دعوته إليه {  ليسجنن وليكوناً من الصاغرين } وذلك إنهنَّ زيّن له مطاوعتها ،  وقلن له :  إياك وإلقاء نفسك في السجن والصغار فالتجأ إلى ربه
