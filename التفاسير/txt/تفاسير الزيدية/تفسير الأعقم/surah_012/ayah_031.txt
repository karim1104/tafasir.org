{  فلما سمعت } راعيل {  بمكرهنّ } بقولهنّ {  أرسلت إليهنَّ } ،  قيل :  أرادت إبلاغ عذرها ،  وقيل :  أرادت إيقاعهن فيما وقعت فيه ،  قال وهب :  اتخذت مائدة ودعت أربعين امرأة منهنَّ {  وأعتدت } أي أعدت {  لهنَّ متكئا } أي مجلساً وما يتكأ عليه من النمارق والوسائد {  وآتت كل واحدة منهن سكيناً } لقطع الفواكه {  وقالت اخرج عليهنَّ } وكانت أجلسته غير مجلسهنّ فأمرته بالخروج إما للخدمة أو للسلام {  فلما رأينه أكبرنَهُ } أي عظّمنه وكان ( عليه السلام ) كالقمر ليلة البدر {  وقطّعن أيديهن } بتلك السكاكين وهنَّ يحسبن أنها الأترج والفواكه ،  وقيل :  جرحنَّ أيديهنّ ،  وقيل :  ما أحسسن إلاَّ بالدم {  وقلن حاشَ لله } أي برأه الله سبحانه من كل سوء أن يكون هذا بشراً {  إن هذا إلا ملك كريم }
