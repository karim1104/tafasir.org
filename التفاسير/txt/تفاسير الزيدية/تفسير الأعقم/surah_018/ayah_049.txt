{  ووضع الكتاب } يعني صحائف الأعمال {  فترى المجرمين مشفقين } خائفين {  مما فيه } من الأعمال السيئة {  ويقولون } إذا قرأوها {  يا ويلتنا } يدعون بالويل والثبور ،  والويل :  الهلاك {  ما لهذا الكتاب لا يغادر صغيرة ولا كبيرة إلا أحصاها } أي لا شيئاً من الذنوب إلا أحصاها ،  قيل :  الصغيرة التبسم والكبيرة القهقهة ،  وقيل :  الكبيرة الزنا ،  وقيل :  المراد به يجري بما جل ودق لأن الصغيرة ما نقص عقابه عن طاعته والكبيرة ما زاد عقابه على ثواب طاعته ،  ومتى قيل :  أليس معفواً عنها ؟  قيل :  لا صغيرة للكفار وإنما يقع الصغائر من المؤمن {  ووجدوا ما عملوا حاضراً } في الصحف عتيداً {  ولا يظلم ربك أحداً } فيكتب عليه ما لم يعمل أو يزيد في عقابه
