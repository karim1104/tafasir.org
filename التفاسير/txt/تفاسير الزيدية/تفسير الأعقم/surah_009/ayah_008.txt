{  كيف وإن يظهروا عليكم } أي كيف يكون لهم عهد وحالهم أنهم إن يظهروا عليكم بعدما سبق لهم من توكيد الايمان والمواثيق لم ينظروا في حلف ولا عهد {  لا يرقبوا } أي لا يحفظوا {  فيكم إلاًّ } بألسنتهم ،  قيل :  عهداً ،  وقيل :  يميناً {  ولا ذمَّة } يعني عهداً {  يرضونكم بأفواههم } يعطونكم بألسنتهم خلاف ما في قلوبهم {  وتأبى قلوبهم } أي تأبى الإِيمان
