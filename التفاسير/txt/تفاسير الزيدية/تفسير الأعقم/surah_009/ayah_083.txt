{  فإن رجعك } الله {  إلى طائفة منهم } يعني ردك الله يا محمد إلى جماعة ممن تخلف عنك وإنما قال طائفة لأنه ليس من تخلف عن تبوك منافقاً بل كان منهم منافق ومنهم من تخلف لعذر ،  وقيل :  لأن منهم من تاب من النفاق وندم على التخلف فاعتذر بعذر صحيح {  فقل } لهم يا محمد {  لن تخرجوا معي أبداً } ما بقيت في سفر ولا غزوة {  ولن تقاتلوا معي عدواً } وذلك عقوبة لهم على فعلهم {  إنكم } أيها المنافقون {  رضيتم بالقعود أول مرة } يعني في غزوة تبوك {  فاقعدوا } تهديداً لهم وليس بأمر {  مع الخالفين } ،  قيل :  مع المنافقين ،  وقيل :  مع النساء والصبيان ،  وقيل :  مع الزمنى والعميان
