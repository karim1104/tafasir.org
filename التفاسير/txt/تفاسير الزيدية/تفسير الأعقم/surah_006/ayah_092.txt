{  وهذا كتاب } يعني القرآن {  مصدق الذي بين يديه } يعني الكتب التي أنزلها الله تعالى {  ولتنذر أم القرى } أي لتخوفهم ،  وأم القرى مكة لأن الخلق يجتمعون إليها ،  ولأن الأرض دحيت من تحتها {  والذين يؤمنون بالآخرة } يعني يصدقون بالنشأة الآخرة {  يؤمنون به } قيل :  بمحمد ( صلى الله عليه وآله وسلم ) ،  وقيل :  بالقرآن {  وهم على صلاتهم يحافظون } يعني الصلوات الخمس يداومون عليها .
