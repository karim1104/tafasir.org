{  قل } يا محمد {  هلمَّ شهداءكم } أي احضروا شهداءكم على ما ادعيتم {  الذين يشهدون ان الله حرم هذا } وقيل :  احضروا حجتكم على ما قلتم {  فإن شهدوا فلا تشهد معهم } يعني لا تسلم لهم ما شهدوا به ولا تصدقهم لأنه إذا سلم فكأنه شهد معهم {  ولا تتبع أهواء الَّذين كذبوا بآياتنا } الآية ،  وقوله :  {  يعدلون } أي يشركون ،  قوله تعالى :  {  ألا تشركوا به شيئا } احكام هذه الآيات الظاهرة من قوله تعالى :  {  اتل ما حرم ربكم عليكم } إلى قوله تعالى :  {  وبعهد الله أوفوا ذلكم وصاكم به لعلكم تذكرون } {  وان هذا صراطي مستقيماً فاتبعوه } عن ابن عباس هذه الآيات محكمات لم ينسخهن شيء من جميع الكتب ،  وقيل :  هن أم الكتاب من عمل بهن دخل الجنة ومن تركهن دخل النار ،  وعن كعب الأحبار :  والَّذي نفس كعب بيده ان هذه الآيات لأول شيء في التوراة {  ولا تقتلوا أولادكم } أي لا تدفنوا بناتكم {  من إملاق } يعني خوف الفقير {  ولا تقربوا الفواحش ما ظهر منها وما بطن } أي ما أعلنتم وما أسررتم {  ولا تقتلوا النفس الَّتي حرم الله إلا بالحق } وهي كل نفس مؤمنة أو معاهدة إلاَّ بالحق يعني ما أباح قتلها وهو الارتداد والقصاص والرجم ذلك المذكور لكم {  وصاكم به لعلكم تعقلون } {  ولا تقربوا مال اليتيم إلاَّ بالتي هي أحسن } أنفع وأعدل ،  وقيل :  حفظ ماله إلى أن يكبر فيسلم إليه {  وإذا قلتم فاعدلوا } أي أصدقوا في مقالتكم {  ولو كان ذا قربى } أي ذا قرابة منكم {  وبعهد الله أوفوا } ،  قيل :  عهده في فرائضه وما أوجب عليكم فافعلوا ،  وقيل :  ما أوصى به في هذه الآيات .
