{  إن الذين آمنوا وعملوا الصالحات أولئك هم خير البرية } أي خير الخليقة {  جزآؤهم عند ربهم جنات عدنٍ } إقامة {  تجري من تحتها الأنهار } أي من تحت أبنيتها وأشجارها {  خالدين فيها أبداً } أي دائمين لا ينقطع {  رضي الله عنهم } بما قدموا من الطاعات ،  وقيل :  رضي أعمالهم ورضوا بما جازاهم من النعم والثواب ،  وقيل :  رضي الله عنهم حيث وحدوه ونزهوه عن القبائح وأطاعوه {  ورضوا عنه } حيث فعل لهم ما رجوا من فضله وخيره {  ذلك لمن خشي ربه } عقابه فأطاعه .
