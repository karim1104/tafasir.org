قوله تعالى :  {  وقلنا من بعده } أي من بعد هلاك فرعون {  لبني اسرائيل اسكنوا الأرض } أي أرض مصر والشام {  فإذا جاء وعد الآخرة } يعني القيامة {  جئنا بكم } من القبر إلى الموقف للحساب والجزاء {  لفيفاً } مختلطين التفت بعضكم ببعض ،  وقيل :  لفيفاً جميعاً ،  ثم عاد الكلام إلى ذكر القرآن الذي تقدم ذكره فقال سبحانه :  {  وبالحق أنزلناه }
