{  أم يقولون } هؤلاء الكفار {  افترى } محمد {  على الله كذباً } فيما يقول أنه رسوله {  فإن يشأ الله يختم على قلبك } ،  قيل :  يربط على قلبك حتى لا يشق عليك أذاهم ،  وقيل :  يطبع على قلبك ينسيك القرآن ،  وهو زجر للنبي ( صلى الله عليه وآله وسلم ) وبيان للكفار أنه لا يفعل ما يقولون {  ويمح الله الباطل } أي يزيله ويبطله {  ويحق الحق بكلماته } أي يبيّنه وكلماته ما أثبته في الكتب {  إنه عليم بذات الصدور } من حق أو باطل
