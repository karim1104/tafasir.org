{  فلذلك فادع } أي لأجل الشك والذي هم فيه فادعهم إلى الحق ،  وقيل :  اللام بمعنى الذي أي الذي شرعه الله ورضي به {  فادع واستقم } بما أتاك من النبوة والكتاب ،  وقيل :  استقم في الرسالة وأبلغها {  كما أمرت } {  ولا تتبع أهواءهم } يعني أهواء المشركين بل اتبع الوحي {  وقل آمنت بما أنزل الله من كتاب } منزل {  وأمرت لأعدل بينكم } في الدين والدنيا والدعاء ولا أحابي أحداً فيكون القريب والبعيد سواء ،  وقيل :  {  لأعدل بينكم } في جميع الأشياء {  الله ربنا وربكم } أي خالق الجميع والمنعم عليهم {  لنا أعمالنا ولكم أعمالكم } أي جزاء أعمالنا لنا وجزاء أعمالكم لكم {  لا حجة بيننا وبينكم } ،  قيل :  لا خصومة قد ظهر الحق فسقط الجدال بالحجة لنا عليكم {  الله يجمع بيننا وإليه المصير } يعني يجمع بيننا يوم القيامة والمرجع إليه
