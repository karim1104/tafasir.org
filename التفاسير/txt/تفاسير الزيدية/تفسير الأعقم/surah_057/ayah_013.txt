{  يوم يقول المنافقون والمنافقات } يعني إذا رأى المنافقون نور المؤمنين يقولون لهم :  {  انظرونا نقتبس من نوركم } انظرونا بصلة الهمز وضم الظاء وهي قراءة نافع ومن تابعه ،  يعني اصبروا لنا ،  فأما بكسر الظاء وقطع الألف وهي قراءة حمزة أمهلونا لأنه يسرع بهم إلى الجنة كالبرق الخاطف ركاب على نوق تزف بهم وهؤلاء مشاة ،  أو انظروا إلينا لأنهم إذا نظروا إليهم استقبلوهم بوجوههم والنور بين أيديهم فيستضيئون به {  قيل ارجعوا وراءكم فالتمسوا نوراً } طرداً لهم وتهكم بهم ،  أي ارجعوا إلى الموقف إلى حيث أعطينا هذا النور فالتمسوا نوراً هناك فمن ثم يقتبس ،  أو ارجعوا إلى الدنيا فالتمسوا نوراً وهو أنه لا سبيل إليه وإنما قالوه توبيخاً {  فضرب بينهم بسور } الباء صلة وهو حاجز بين الجنة والنار يعني بين المؤمنين والمنافقين بحائط حيل من شق الجنة وشق النار ،  وقيل :  هو الأعراف ،  ولذلك السور {  باب } لأهل الجنة يدخلون فيه {  باطنه } باطن السور والباب وهو الشق الذي يلي الجنة {  وظاهره } ما ظهر لأهل النار {  من قبله } من عنده ومن جهته {  العذاب } وهو الظلمة والنار فيقول المنافقون عند ذلك للمؤمنين
