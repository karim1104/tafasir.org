{  وإذ أسرّ النبي إلى بعض أزواجه } حفصة بالإِجماع {  حديثاً } قال لها وأمرها بإخفائه وذلك الحديث حديث مارية وتحريمها ،  وقيل :  تحريم العسل {  فلما نبّأت به } أخبرت حفصة بالحديث عائشة {  وأظهره الله عليه } أي أطلع الله عليه رسوله ،  وما جرى من إفشاء سرّه {  عرّف بعضه } قرأ الكسائي بالتخفيف وهي قراءة علي بن أبي طالب ( عليه السلام ) أي غضب عليها وجازاها بما فعلت ،  وقراءة الباقين بالتشديد معناه عرّف غيره ،  يعني عرَّف النبي حفصة ببعض الحديث وأخبرها به {  وأعرض عن بعض } ولم يخبرها به ،  قال الحسن :  ما استقصي كريم قط {  فلمَّا نبَّأها به } أي أخبر رسول الله ( صلى الله عليه وآله وسلم ) حفصة بما أظهر الله عليه {  قالت } حفصة {  من أنبأك هذا قال نبَّأني العليم الخبير } بالسر ،  وإنما قالت من أنبأك هذا لأنها وثقت بعائشة أنها لا تخبر
