{  ويرى الذين أوتوا العلم } أعطوا العلم قيل :  هو أصحاب محمد ( صلى الله عليه وآله وسلم ) ،  وقيل :  من آمن من علماء أهل الكتاب كعبد الله بن سلام ،  وقيل :  كل من أوتي العلم إلى يوم القيامة ،  وقيل :  هم علماء التوحيد والعدل {  الذي أنزل إليك } أي يعلمون أنه {  الحق } وهو القرآن {  ويهدي } يعلمون أنه حق ويعلمون أنه يهدي {  إلى صراط العزيز } القادر {  الحميد } المحمود والصراط قيل :  هو دين الإِسلام
