{  إن فرعون علا في الأرض } أي تكبر وتجبّر {  وجعل أهلها شيعاً } فرقاً وأصنافاً ،  قيل :  جعل بني إسرائيل فرقاً في أعمالهم ،  وقيل :  في الخدمة والتسخير {  يستضعف طائفة منهم } وهم بنو إسرائيل {  يذبح أبناءهم } لأنه أخبر أنه يولد فيهم من يكون زوال ملكه على يديه {  ويستحيي نساءهم } أي يبقيهن أحياء {  إنه كان من المفسدين }
