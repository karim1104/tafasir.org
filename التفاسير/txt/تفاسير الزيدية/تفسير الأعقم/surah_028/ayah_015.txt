{  ودخل المدينة } يعني موسى دخل مدينة مصر ،  وقيل :  أرض مصر {  على حين غفلة من أهلها } ،  قيل :  وقت القائلة ،  وقيل :  يوم عيد لهم قد اشتغلوا بلعبهم ،  وقيل :  بين المغرب والعشاء {  فوجد فيها رجلين يقتتلان } ،  قيل :  كانت خصومتهما الدين وقيل :  في أمر الدنيا {  هذا من شيعته } ممن شايعه على دينه {  وهذا من عدوه } كان كافراً {  فاستغاثه الذي من شيعته على الذي من عدوه } يعني الإِسرائيلي استغاث موسى على القبطي لأنه علم منزلته من بني إسرائيل ولم يعلم الناس إلاَّ من قبل الرضاعة فقال موسى للقبطي :  خلي سبيله ،  فقال :  إنما أخذته ليحمل الحطب إلى مطبخ أبويك ،  فتنازعا {  فوكزه موسى } أي دفع في صدره بجميع كفه ،  وقيل :  الوكز بأطراف الأصابع {  فقضى عليه } وروي أن موسى لم يتعمد لقتله ولكن قصد لتخليص المؤمن من يد الكافر ،  وروي أنه لم يُبح قتل الكافر حينئذ {  قال هذا من عمل الشيطان } أي من اغوائه ووسوسته {  إنه عدو } لبني آدم {  مضل } الكافر بوسوسته {  مبين } ظاهر العداوة
