{  فكلاًّ أخذنا بذنبه } يعني ممن تقدم ذكرهم وأنهم أتوا في هلاكهم من جهة أنفسهم ،  بذنبه أي عاقبنا بذنبه {  فمنهم من أرسلنا عليه حاصبا } قيل :  هم قوم لوط ،  وهي ريح عاصف فيها حصى ،  وقيل :  ملك يرميهم {  الصيحة } لمدين وثمود {  ومنهم من خسفنا } الخسف لقارون {  ومنهم من أغرقنا } وهم قوم نوح وفرعون {  وما كان الله ليظلمهم } أي يعذبهم بغير ذنب {  ولكن كانوا أنفسهم يظلمون } يكفرون
