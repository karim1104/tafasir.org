{  وكذلك أنزلنا إليك الكتاب } كما أنزلنا الكتب عليهم أنزلنا عليك الكتاب أيضاً {  فالذين آتيناهم الكتاب } أي علم الكتاب {  يؤمنون به } ،  قيل :  الكتاب القرآن ومن آمن به أصحاب النبي ( صلى الله عليه وآله وسلم ) {  ومن هؤلاء } قيل :  أصحاب مكة ،  وقيل :  العرب {  من يؤمن به } بالقرآن ،  وقيل :  الكتاب هو التوراة والإِنجيل والذين يؤمنون به عبد الله بن سلام وأصحابه {  وما يجحد بآياتنا إلاّ الكافرون } يعني آيات القرآن مع ظهورها وزوال الشبهة ،  قيل :  هو كعب بن الأشرف وأصحابه
