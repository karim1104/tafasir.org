{  ولمَّا أن جاءت رسلنا لوطا سيء بهم } يعني خاف الملائكة لوطاً ظن أنهم من الإِنس لأنهم جاؤوه على صورة الإِنس {  سيء بهم } قيل :  بالملائكة ساءه مجيئهم لما جاؤوه في أحسن صورة لما يعلم من خبث قومه وأفعالهم الشنيعة {  وضاق بهم ذرعاً } أي ضاقت حيله ،  وقيل :  ضاق قلبه وناله وباله الغم فلما رأت الملائكة حزنه وضيق صدره {  وقالوا لا تخف } علينا وعليك {  ولا تحزن } بما يفعله قومك {  إنا منجوك وأهلك إلا امرأتك كانت من الغابرين } الباقين في العذاب
