{  يمنّون عليك أن أسلموا } أي يعدون إسلامهم نعمة على الرسول ويتوهمون أنهم نفعوك به حيث قالوا آمنا وأسلمنا وهاجرنا وفعلنا {  قل } يا محمد {  لا تمنّوا عليّ إسلامكم } فإن نفعه يعود عليكم {  بل الله يمنّ عليكم أن هداكم للإِيمان } يعني أنعم عليكم أكثر حيث هداكم وأمركم فأراح عليكم ووفقكم {  إن كنتم صادقين } في أنكم مؤمنين به
