{  ليس عليكم جناح } الآية ،  قيل :  كانوا يتأثمون بالتجارة في الإحرام في صدر الإسلام ويمتنعون منها فنزلت الآية ،  وقيل :  ان قوماً قالوا :  ليس للتاجر ولا للأجير ولا للجمال حج فنزلت {  فاذا أفضتم من عرفات } سميت عرفات لتعريف جبريل ( عليه السلام ) المناسك ابراهيم ( عليه السلام ) ،  أو لمعرفة آدم حواء هناك ،  أو لتعارف الناس هناك ،  أو لاعترافهم بذنوبهم قوله تعالى :  {  فاذكروا الله عند المشعر الحرام } هو جانبا جبل المزدلفة قيل :  بالتلبية والدعاء ،  وقيل :  الجمع بين صلاة المغرب والعشاء {  واذكروه كما هداكم } لدينه {  وان كنتم من قبله لمن الضالين } قيل :  من قبل النبي ( صلى الله عليه وآله وسلم )
