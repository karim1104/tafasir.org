{  كالذي ينفق ماله رئاء الناس } أي لا تبطلوا صدقاتكم كإبطال المنافق الذي ينفق ماله رئاء الناس لا يريد بها رضاء الله وثواب الآخرة {  فمثله كمثل صفوان } أي مثله ونفقته بصفوان حجر أملس {  عليه تراب فأصابه وابل } مطر عظيم القطر {  فتركه صلداً } أي أجرداً نقياً من التراب الذي كان عليه {  لا يقدرون على شيء } ممن ثابه {  مما كسبوا } حيث أعطوه بالرياء ،  وقيل :  هو قوله تعالى :  {  فجعلناه هباءً منثوراً } [ الفرقان :  23 ] .
