الكلام :  في أوائل السور مثل {  الم } و {  الر } و {  حم } و {  طس } و {  طسم } و {  المص } و {  كهيعص } قيل :  هي أسماء للسور ،  وقيل :  أسماء لله تعالى ،  روي :  ذلك عن أمير المؤمنين ( عليه السلام ) انه كان يقول في دعائه :   "  يا حم يا طس يا كفها  "  ،  وقيل :  مأخوذة من اسماء الله تعالى ،  وقيل :  أسماء كانت العرب تكاتب بها فنزل القرآن عليها فلم يأتوا بمثله فدلَّ على انه معجزٌ .
