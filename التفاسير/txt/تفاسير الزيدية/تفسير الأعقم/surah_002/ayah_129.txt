{  ربنا وابعث فيهم } في الأمّة المسلمة .  {  رسولاً } الآية ،  روي انه قيل له :  قد استجيب لك وهو نبي في آخر الزمان فبعث الله فيهم محمداً ( صلى الله عليه وآله وسلم ) .  وقال ( صلى الله عليه وآله وسلم ) :   "  انا دعوة ابي ابراهيم وبشرى عيسى ابن مريم  "  {  يتلو عليهم آياتك } يقرأ عليهم ويبلغهم ما يوحى اليه {  ويعلمهم الكتاب } القرآن {  والحكمة } الشريعة {  ويزكيهم } يطهرهم من الشرك وسائر الارجاس .
