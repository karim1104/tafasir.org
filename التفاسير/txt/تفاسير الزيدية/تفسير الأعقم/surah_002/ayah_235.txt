قوله تعالى :  {  ولا جناح عليكم فيما عرضتم به من خطبة النساءِ أو أكننتم } اي اسررتم واضمرتم {  ولكن لا تواعدوهن سراً } والسر وقع كناية عن النكاح الذي هو الوطء لانه مما يُسر ،  وقيل :  الزنا ،  وقيل :  السر عقد النكاح ،  وقيل :  السر الجماع يعني لا تصفو انفسكم بكثرته {  إلا أن تقولوا قولاً معروفاً } قيل :  هو التعريض من غير تصريح ،  قوله تعالى :  {  ولا تعزموا عقدة النكاح } قيل :  لا تضمروا النكاح ،  وقيل :  لا تعزموا النكاح {  حتى يبلغ الكتاب أجله } يعني تنقضي العدَّة ومعنى الكتاب القرآن ومعناه فرض الكتاب اجله ،  وقيل :  الكتاب الفرض ومثله {  كتب عليكم الصيام } يعني فرض الله اجله {  واعلموا ان الله يعلم ما في أنفسكم } يعني يعلم ضمائرهم وما يسرونه {  فاحذروه } اي احذروا عقابه ولا تخالفوا امره .
