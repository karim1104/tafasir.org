{  واذا طلقتم النساء } خطاب للازواج {  فبلغن اجلهن } أي بلغن انقضاء العدة ومعناه قاربن وأشرفن أجلهن لأنه بعد انقضاء العدة ليس له الامساك يقال :  بلغت البلد اذا قاربت منها ،  والاجل الذي تنقضي به العدة ،  الأقراء في ذات الحيض والاشهر فيمن لا تحيض او الوضع فيمن بها حمل {  فامسكوهن بمعروف } يعني راجعوهن قبل انقضاء العدة {  ولا تتخذوا آيات الله هزوا }
