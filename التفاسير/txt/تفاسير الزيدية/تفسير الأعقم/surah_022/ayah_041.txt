{  الذين إن مكّناهم في الأرض } قيل :  هم {  المهاجرين الذين أخرجوا من ديارهم } [ الحشر :  8 ] ،  وقيل :  هم أصحاب محمد ( صلى الله عليه وآله وسلم ) ،  وقيل :  أهل الصلوات الخمس ،  وقيل :  هذه الأمة {  أقاموا الصلاة } أي أداموها {  وآتوا الزكاة } {  ولله عاقبة الأمور } أي أمور الخلق ومصيرهم اليه يوم القيامة
