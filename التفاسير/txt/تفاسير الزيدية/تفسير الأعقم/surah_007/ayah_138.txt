{  وجاوزنا ببني إسرائيل البحر } قطعنا بهم بأن جعلنا لهم فيه طريقاً يابسة حتى عبروه وغرق فرعون ،  وروي أنه عبر بهم موسى يوم عاشوراء بعد أن أهلك الله فرعون وقومه فصاموا شكراً لله تعالى {  فأتوا على قوم } فمروا على قوم {  يعكفون على أصنام لهم } يواظبون على عبادتها ،  قيل :  كانت تماثيل بقر وذلك أول شأن العجل ،  وقيل :  كانت أوثان ،  وقيل :  كان القوم من الكنعانيين {  قالوا يا موسى اجعل لنا إلهاً } صنماً نعتكف عليه {  كما لهم آلهة } أصنام يعكفون عليها {  قال } لهم موسى {  إنكم قوم تجهلون إنَّ هؤلاء } يعني القوم الذين عبدوا الأصنام {  مُتَبَّرٌ } مهلك مدمر
