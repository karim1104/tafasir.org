{  فإذا قضيتم الصلاة } فإذا صليتم في حال الخوف والقتال فصلّوها {  قياماً } مشايفين ومقارعين {  وقعوداً } جاثمين على الركب مرامين {  فإذا اطمأننتم } حين تضع الحرب أوزارها {  فأقيموا الصلاة } فاقضوا ما صلَّيتم في تلك الأحوال التي هي أحوال القلق {  إن الصلاة كانت على المؤمنين كتاباً موقوتاً } محدوداً بأوقات لا يجوز إخراجها عن أوقاتها
