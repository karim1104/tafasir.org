{  يأيها الذين آمنوا كونوا قوَّامين بالقسط } مجتهدين في إقامة العدل {  شهداء لله } يقيمون شهادتكم كما أمرتم بإقامتها {  ولو على أنفسكم } ولو كانت الشهادة على أنفسكم وآبائكم وأقاربكم وهو أن يقرّ على نفسه بما عليها لأنه في معنى الشهادة {  إن يكن غنياً أو فقيراً فالله أولى } بالغني والفقير أي بالنظر لهما {  فلا تتَّبعوا الهوى } يعني هوى أنفسكم {  أن تعدلوا } عن الحق {  وأن تلووا أو تعرضوا } يعني وأن تلووا ألسنتكم عن الشهادة بما عندكم وتمنعوها .
