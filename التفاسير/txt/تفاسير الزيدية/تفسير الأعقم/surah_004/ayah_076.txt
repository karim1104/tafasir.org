{  الذين آمنوا } صدقوا الله ورسوله {  يقاتلون } يجاهدون {  في سبيل الله } أي في دينه وطاعته {  والذين كفروا } كذبوا الله ورسوله {  يقاتلون في سبيل الطاغوت } قيل :  طريق الشيطان ،  وقيل :  كلَّ ما عُبِد من دون الله فهو طاغوت ،  وقيل هو الكاهن ،  وقيل :  في طاعة كبرائهم {  فقاتلوا } جاهدوا أيها المؤمنون {  أولياء الشيطان } يعني الذين يتولونه ويطيعونه ،  وقيل :  حزب الشيطان {  إن كيد الشيطان } مكره وتدبيره {  كان ضعيفاً } قيل :  تضعف نصرته لأوليائه وكيد الشيطان للمؤمنين إلى حيث كيد الله الكافرين أضعف شيء وأهونه ،  وقيل :  انه أخبرهم بظهور المؤمنين عليهم فلذلك كان كيده ضعيف ،  وقيل :  سمَّاه ضعيفاً لضعف دواعي أوليائه إلى القتال لأنه لا نصرة لهم وقوة دواعي المسلمين لأنه تعالى ناصرهم
