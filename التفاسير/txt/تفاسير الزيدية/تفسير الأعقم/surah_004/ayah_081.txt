{  ويقولون } إذا أمرتهم بشيء {  طاعة فإذا برزوا من عندك } ،  الآية ،  نزلت في المنافقين ،  ومعنى :  {  بيَّت طائفة } زوّرت طائفة وسوَّت {  غير الذي تقول } خلاف ما قلت وما أمرت به {  والله يكتب ما يبيتون } يبيّته في أعمالهم ويجازيهم عليه أو يكتبه في جملة ما يوحي إليك فيطلعك على أسرارهم {  فأعرض عنهم } ولا تحدث نفسك بالانتقام منهم {  وتوكّل على الله } في شأنهم
