{  إلا الذين تابوا } يعني تابوا من النفاق بالندم عليه {  وأصلحوا } يعني أصلح قولهم وفعلهم {  واعتصموا بالله } أي بطاعته من كل ما يخاف عاجلاً وآجلاً {  وأخلصوا دينهم لله } قيل :  عبدوا الله وحده دون من سواه {  فأولئك مع المؤمنين } ،  قيل :  معهم في الجنة ،  وقيل :  معهم في الولاية والكرامة في الدنيا والآخرة {  وسوف يؤت الله المؤمنين أجراً عظيماً } أي ثواباً دائماً
