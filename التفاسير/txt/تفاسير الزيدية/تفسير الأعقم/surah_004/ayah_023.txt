قوله تعالى :  {  حرمت عليكم أمهاتكم } حرم الله من النسب سبعاً وهنَّ إلى قوله تعالى :  {  وبنات الأخت } وقالوا :  تحريم الرضاع كتحريم النَّسب ،  ومن النَّسب سبع إلى قوله تعالى :  {  والمحصنات } أي ذوات الأزواج فلا يحللن لغير أزواجهن {  وحلائل أبنائكم } قيل :  نزلت حين تزوج الرسول ( صلى الله عليه وآله وسلم ) امرأة زيد بن حارثة فقال المشركون في ذلك وكما نزل قوله :  {  وما جعل أدعياءكم أبناءكم } [ الأحزاب :  4 ] و {  ما كان محمد أبا أحد من رجالكم } [ الأحزاب :  40 ] {  الذين من أصلابكم } دون من تبنَّيتم كما تزوج ( صلى الله عليه وآله وسلم ) امرأة زيد حين فارقها زيد وهي زينب بنت جحش ،  قوله تعالى :  {  وأن تجمعوا بين الأختين } أي وحرّم عليكم أن تجمعوا ،  والمراد :  تحريم النكاح لأن التحريم في الآية تحريم النكاح وأما الجمع بينهما في ملك اليمين فعن علي ( عليه السلام ) أنه قال :   "  أحلتها آية وحرمتها آية  "  يعني هذه الآية ،  وقوله تعالى :  {  أو ما ملكت أيمانكم } فرجح علي ( عليه السلام ) التحريم ،  وعثمان التحليل {  إلا ما قد سلف } ولكن ما قد مضى مغفور بدليل قوله :  {  إن الله كان غفوراً رحيماً }
