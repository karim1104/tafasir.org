{  لئن أخرجتم } من ديارنا {  لنخرجن معكم } يعني لئن أخرجكم محمد من دياركم بالغلبة {  لنخرجن معكم } أروهم بذلك أنهم يوافقونهم في حرب رسول الله ( صلى الله عليه وآله وسلم ) {  ولا نطيع فيكم أحداً أبداً } أي لا نطيع رسول الله ولا المؤمنين ان أمرونا بخذلانكم وإن قاتلكم محمد {  لننصرنكم } عليه {  والله يشهد إنهم لكاذبون } في هذا القول  .
