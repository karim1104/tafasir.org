قوله تعالى :  {  أفرأيتم الماء الذي تشربون } إلى قوله {  فلو لا تشكرون } المزن السحاب ،  وقوله :  {  فلو لا تشكرون } تحضيض على الشكر ،  وشكره تعالى جميل ذكره تعالى على نعمه وهو إظهار عبوديته قولا وعملا .

و الباقي ظاهر .

بحث روائي

و في تفسير القمي ،  :  {  ءأنتم أنزلتموه من المزن } قال :  من السحاب {  نحن جعلناها تذكرة } لنار يوم القيامة {  و متاعا للمقوين } قال :  المحتاجين .
