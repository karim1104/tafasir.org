و قوله :  {  يقول أإنك لمن المصدقين أإذا متنا وكنا ترابا وعظاما أ إنا لمدينون } ضمير {  يقول } للقرين ،  ومفعول {  المصدقين } البعث للجزاء وقد قام مقامه قوله :  {  أإذا متنا } إلخ والمدينون المجزيون .

و المعنى :  كأن يقول لي قريني مستبعدا منكرا ءإنك لمن المصدقين للبعث للجزاء ءإذا متنا وكنا ترابا وعظاما فتلاشت أبداننا وتغيرت صورها أ إنا لمجزيون بالإحياء والإعادة ؟  فهذا مما لا ينبغي أن يصدق .
