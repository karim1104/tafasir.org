قوله تعالى :  {  فانطلقا حتى إذا لقيا غلاما فقتله قال أ قتلت نفسا زكية بغير نفس لقد جئت شيئا نكرا } في الكلام بعض الحذف للإيجاز والتقدير :  فخرجا من السفينة وانطلقا .

و في قوله :  {  حتى إذا لقيا غلاما فقتله قال } إلخ {  فقتله } معطوف على الشرط بفاء التفريع و{  قال } جزاء {  إذا } على ما هو ظاهر الكلام :  وبذلك يظهر أن العمدة في الكلام ذكر اعتراض موسى لا ذكر القتل ،  ونظيرته الآية اللاحقة {  فانطلقا حتى إذا أتيا أهل قرية } إلى قوله {  قال لو شئت } إلخ بخلاف الآية السابقة :  {  فانطلقا حتى إذا ركبا في السفينة خرقها قال } فإن جزاء {  إذا } فيها {  خرقها } وقوله :  {  قال } كلام مفصول مستأنف .

و على هذا فالآيات مسرودة في صورة قصة واحدة اعترض فيها موسى على الخضر ( عليهما السلام ) ثلاث مرات واحدة بعد أخرى لا في صورة ثلاث قصص اعترض فيها ثلاث اعتراضات كأنه قيل :  وقع كذا وكذا فاعترض عليه ثم اعترض ثم اعترض فالقصة قصة اعتراضاته فهي واحدة لا قصة أعمال هذا واعتراضات ذاك حتى تكون ثلاثا .

و من هنا يتبين وجه الفرق بين الآيات الثلاث حيث جعل {  خرقها } جواب إذا في الآية الأولى ،  ولم يجعل {  قتله } و{  وجدا } أو {  أقامه } جوابا في الثانية والثالثة بل جزءا من الشرط معطوفا عليه فافهم ذلك .

و قوله :  {  أقتلت نفسا زكية } الزكية الطاهرة ،  والمراد طهارتها من الذنوب لعدم البلوغ كما يشعر به قوله :  {  غلاما } والاستفهام للإنكار ،  والقائل موسى .

و قوله :  {  بغير نفس } أي بغير قتل منها لنفس قتلا مجوزا لقتلها قصاصا وقودا فإن غير البالغ لا يتحقق منه القتل الموجب للقصاص ،  وربما استفيد من قوله :  {  بغير نفس } أنه كان شابا بالغا ،  ولا دلالة في إطلاق الغلام عليه على عدم بلوغه لأن الغلام يطلق على البالغ وغيره فالمعنى أ قتلت بغير قصاص نفسا بريئة من الذنوب المستوجبة للقتل ؟  إذ لم يظهر لهما من الغلام شيء يستوجبه .

و قوله :  {  لقد جئت شيئا نكرا } أي منكرا يستنكره الطبع ولا يعرفه المجتمع وقد عد خرق السفينة إمرا أي داهية يستعقب مصائب لم يقع شيء منها بعد وقتل النفس نكرا أو منكرا وهو أفظع وأفجع عند الناس من الخرق الذي يستوجب عادة هلاك النفوس لكن لا بالمباشرة فعلا .
