* ( وناديناه ان يا ابراهيم ) * و ( ناديناه ) هو جواب ( فلما ) قال الفراء : العرب تدخل الواو في جواب ( فلما ) و ( حتى ) و ( إذا ) كما قال * ( حتى إذا جاؤها فتحت ابوابها ) * وفي موضع آخر * ( وفتحت ) * وفي قراءة عبدالله * ( فلما جهزهم بجهازهم وجعل السقاية ) * وفي المصاحف ( جعل ) بلا واو وموضع ان نصب بوقوع النداء عليه وتقديره وناديناه بأن يا ابراهيم أي هذا الضرب من القول فلما حذف الباء نصب .
