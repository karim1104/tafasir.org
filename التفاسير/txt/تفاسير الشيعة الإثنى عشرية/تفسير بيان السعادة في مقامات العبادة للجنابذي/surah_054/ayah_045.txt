{ سَيُهْزَمُ ٱلْجَمْعُ } ان كانوا متّكلين على جماعتهم والمراد انّهم سيهزمون فى القيامة او فى الدّنيا يوم بدرٍ { وَيُوَلُّونَ ٱلدُّبُرَ بَلِ ٱلسَّاعَةُ } المناسب لهذا الاضراب ان يكون المراد بهزيمتهم هزيمتهم فى الدّنيا يعنى انّهم يهزمون فى الدّنيا بل السّاعة اى القيامة او ساعة الموت { مَوْعِدُهُمْ } والّذى لهم فى الدّنيا من العذاب انموذجٌ من عذاب السّاعة { وَٱلسَّاعَةُ أَدْهَىٰ } اشدّ { وَأَمَرُّ } بل شدّة السّاعة ومرارته لا تقاس بعذاب الدّنيا.
