{ لاَّ يَنْهَاكُمُ ٱللَّهُ عَنِ ٱلَّذِينَ لَمْ يُقَاتِلُوكُمْ فِي ٱلدِّينِ وَلَمْ يُخْرِجُوكُمْ مِّن دِيَارِكُمْ أَن تَبَرُّوهُمْ } بدل عن الّذين لم يقاتلوكم { وَتُقْسِطُوۤاْ إِلَيْهِمْ } بتضمين تقضوا { إِنَّ ٱللَّهَ يُحِبُّ ٱلْمُقْسِطِينَ إِنَّمَا يَنْهَاكُمُ ٱللَّهُ عَنِ ٱلَّذِينَ قَاتَلُوكُمْ فِي ٱلدِّينِ وَأَخْرَجُوكُم مِّن دِيَارِكُمْ وَظَاهَرُواْ عَلَىٰ إِخْرَاجِكُمْ أَن تَوَلَّوْهُمْ } بدل عن الّذين قاتلوكم او التّقدير كراهة ان تولّوهم { وَمَن يَتَوَلَّهُمْ فَأُوْلَـٰئِكَ هُمُ ٱلظَّالِمُونَ } بوضع الولاية غير موضعها بل موضع العداوة.
