{ إِنِّي وَجَّهْتُ وَجْهِيَ لِلَّذِي فَطَرَ ٱلسَّمَاوَاتِ وَٱلأَرْضَ حَنِيفاً } خالصاً { وَمَآ أَنَاْ مِنَ ٱلْمُشْرِكِينَ وَحَآجَّهُ قَوْمُهُ قَالَ أَتُحَاجُّوۤنِّي فِي ٱللَّهِ وَقَدْ هَدَانِ } فلا ينبغى لكم ان تحاجّونىّ لانّى على هداية وبيّنة وانتم على عمى وضلالة { وَلاَ أَخَافُ مَا تُشْرِكُونَ بِهِ } كأنّهم كانوا يحاجّونه بالتّخويف من آلهتهم وبما اراهم الشّيطان منهم من بعض ما لا يعتاد { إِلاَّ أَن يَشَآءَ رَبِّي شَيْئاً } وحينئذٍ لا يكون خوفى منهم بل من ربّى { وَسِعَ رَبِّي كُلَّ شَيْءٍ عِلْماً } فلا أخاف ان يصيبنى مكروه من غير علم ربّى به { أَفَلاَ تَتَذَكَّرُونَ } بما اقول لكم من انّ ربّى خالق آلهتكم وانّ علمه محيط بالكلّ ولا قدرة ولا علم لالهتكم كما انّ ربّى له القدرة الكاملة والعلم الكامل.
