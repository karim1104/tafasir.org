{ ثُمَّ رُدُّوۤاْ إِلَىٰ ٱللَّهِ } كما جاؤا منه { مَوْلاَهُمُ ٱلْحَقِّ أَلاَ لَهُ ٱلْحُكْمُ } يومئذٍ او مطلقاً { وَهُوَ أَسْرَعُ ٱلْحَاسِبِينَ قُلْ مَن يُنَجِّيكُمْ مِّن ظُلُمَاتِ ٱلْبَرِّ وَٱلْبَحْرِ } يعنى الزمهم الاقرار { تَدْعُونَهُ تَضَرُّعاً } جهراً { وَخُفْيَةً } سرّاً قائلين { لَّئِنْ أَنجَانَا مِنْ هَـٰذِهِ لَنَكُونَنَّ مِنَ ٱلشَّاكِرِينَ قُلِ ٱللَّهُ يُنَجِّيكُمْ مِّنْهَا وَمِن كُلِّ كَرْبٍ ثُمَّ أَنتُمْ تُشْرِكُونَ قُلْ } تهديداً لهم { هُوَ ٱلْقَادِرُ عَلَىٰ أَن يَبْعَثَ عَلَيْكُمْ عَذَاباً مِّن فَوْقِكُمْ } كما بعث على قوم لوط بامطار الاحجار { أَوْ مِن تَحْتِ أَرْجُلِكُمْ } كغرق فرعون وقومه وخسف قارون { أَوْ يَلْبِسَكُمْ } يخلطكم { شِيَعاً } فرقاً مختلفى المسلك متخالفى الاهواء كلّ فرقة مشايعة لامام { وَيُذِيقَ بَعْضَكُمْ بَأْسَ بَعْضٍ } بالمقاتلة والمدافعة والسّرقة وقطع الطّريق { ٱنْظُرْ كَيْفَ نُصَرِّفُ ٱلآيَاتِ لَعَلَّهُمْ يَفْقَهُونَ } آيات قدرتنا على التّفضّل على المؤمنين والانتقام من الكافرين عن الصّادق (ع) من فوقكم من السّلاطين الظّلمة ومن تحت ارجلكم العبيد السّوء ومن لا خير فيه، ويلبسكم شيعاً يضرب بعضكم ببعض بما يلقيه بينكم من العداوة والعصبيّة ويذيق بعضكم بأس بعضٍ هو سوء الجوار، وامثال هذا الخبر تريك طريق التّعميم فى الآيات وفى الالفاظ بما امكن ووسع اللّفظ.
