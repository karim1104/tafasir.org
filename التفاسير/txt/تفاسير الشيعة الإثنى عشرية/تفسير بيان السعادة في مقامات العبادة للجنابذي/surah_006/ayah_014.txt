{ قُلْ أَغَيْرَ ٱللَّهِ أَتَّخِذُ وَلِيّاً } بعد انّه مالك الكلّ { فَاطِرِ ٱلسَّمَاوَاتِ وَٱلأَرْضِ } التّوصيف به للاشعار بالعلّة { وَهُوَ يُطْعِمُ وَلاَ يُطْعَمُ } علّة اخرى للحكم { قُلْ إِنِّيۤ أُمِرْتُ أَنْ أَكُونَ أَوَّلَ مَنْ أَسْلَمَ } لا يسبقنى احد فى ظاهر الاسلام ولا فى باطنه لانّى امرت تكويناً وتكليفاً ان اكون خاتم الرّسل وسابق الكلّ { وَ } قيل لى { لاَ تَكُونَنَّ مِنَ ٱلْمُشْرِكَينَ } او هو عطف على { قُلْ إِنِّيۤ أَخَافُ إِنْ عَصَيْتُ رَبِّي عَذَابَ يَوْمٍ عَظِيمٍ }.
