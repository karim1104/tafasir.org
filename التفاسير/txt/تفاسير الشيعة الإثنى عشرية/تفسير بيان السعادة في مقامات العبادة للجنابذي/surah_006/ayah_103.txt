{ لاَّ تُدْرِكُهُ ٱلأَبْصَارُ } لا ابصار العيون ولا ابصار القلوب لاحاطته وقصور المحاط عن ادراك المحيط، ولكن تدركه القلوب بحقيقة الايمان { وَهُوَ يُدْرِكُ ٱلأَبْصَارَ } لانّ شأن المحيط ادراك المحاط { وَهُوَ ٱللَّطِيفُ } لطفاً يقصر عن ادراكه الابصار لقصورها { ٱلْخَبِيرُ } بالاشياء ومنها الابصار ومثل هذا يسمّى فى البديع بتشابه الاطراف.
