{ وَكَذٰلِكَ } اى مثل ما جعلنا فى قريتك اكابر مجرميها { جَعَلْنَا فِي كُلِّ قَرْيَةٍ أَكَابِرَ مُجْرِمِيهَا لِيَمْكُرُواْ فِيهَا } لتخليص المؤمنين وتميز المنافقين عنهم { وَمَا يَمْكُرُونَ } فى مكر الانبياء والمؤمنين { إِلاَّ بِأَنْفُسِهِمْ } لانّهم فى مكرهم يخرجون اوّلاً انفسهم من حدّ الاعتدال والتّوجّه الى كمالها الى حدّ التّفريط والتّوجّه الى نقصانها { وَمَا يَشْعُرُونَ } انّ المكر فى الحقيقة بأنفسهم.
