{ وَلاَ يَنفَعُكُمْ نُصْحِيۤ إِنْ أَرَدْتُّ أَنْ أَنصَحَ لَكُمْ } هذا الكلام منه تحسّر عليهم بانصرافهم عمّا يدعوهم اليه والاتيان باداة الشّكّ وذكر الارادة مع انّه نصحهم واكثر نصحهم للاشعار بانّهم لغاية بعدهم كأنّه لم ينصح ولا ينبغى ان يريد نصحهم { إِن كَانَ ٱللَّهُ يُرِيدُ أَن يُغْوِيَكُمْ } جزاء الشّرط الاوّل محذوف بقرينة لا ينفعكم نصحى وجزاء الشّرط الثّانى محذوف بقرينة مجموع الشّرط والجزاء الاوّل { هُوَ رَبُّكُمْ } تعليل لعدم النّفع مع ارادة الله الاغواء { وَإِلَيْهِ تُرْجَعُونَ } تعليل للتّهديد من العذاب.
