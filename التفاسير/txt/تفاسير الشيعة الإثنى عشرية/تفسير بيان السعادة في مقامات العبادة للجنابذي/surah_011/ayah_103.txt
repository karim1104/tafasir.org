{ إِنَّ فِي ذٰلِكَ } الاخذ والاهلاك الواقع بالامم الماضية الهالكة { لآيَةً لِّمَنْ خَافَ عَذَابَ ٱلآخِرَةِ } فانّه وان كان فى الدّنيا لكنّه من تصرّف الغيب وانموذج الآخرة { ذٰلِكَ } اليوم الّذى هو الآخرة والتّذكير باعتبار الخبر { يَوْمٌ مَّجْمُوعٌ لَّهُ ٱلنَّاسُ } لانّ المتعاقبين متلاحقون فى ذلك اليوم { وَذَلِكَ } تكرار اسم الاشارة للتّهويل { يَوْمٌ مَّشْهُودٌ } يشهد فيه كلّ حاضر وغائب او يقوم الاشهاد من الانبياء (ع) واوصيائهم (ع) بالشّهادة فيه او يطلب منهم الشّهادة فيه.
