{ فَعَقَرُوهَا فَقَالَ تَمَتَّعُواْ فِي دَارِكُمْ } تعيّشوا فى منازلكم او بلدكم { ثَلاَثَةَ أَيَّامٍ } وعيد بالعذاب والاهلاك بعد الثّلاثة { ذٰلِكَ وَعْدٌ غَيْرُ مَكْذُوبٍ فَلَمَّا جَآءَ أَمْرُنَا } باهلاكهم { نَجَّيْنَا صَالِحاً وَٱلَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مِّنَّا وَمِنْ خِزْيِ يَوْمِئِذٍ } عطف على محذوف اى نجّيناهم من ذلك العذاب ومن مسيس الخزى منه ايضاً فى يوم ذلك العذاب او فى يوم القيامة { إِنَّ رَبَّكَ هُوَ ٱلْقَوِيُّ } يقوى على عذاب جمع وانجاء جمع منهم { ٱلْعَزِيزُ } غالب لا مانع له من مراده { وَأَخَذَ ٱلَّذِينَ ظَلَمُواْ ٱلصَّيْحَةُ فَأَصْبَحُواْ فِي دِيَارِهِمْ جَاثِمِينَ } ميّتين.
