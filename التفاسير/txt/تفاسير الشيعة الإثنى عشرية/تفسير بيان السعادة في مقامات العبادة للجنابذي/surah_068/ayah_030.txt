{ قَالُواْ } اعترافاً بظلمهم لانفسهم وتنزيهاً للحقّ تعالى عن الظّلم { سُبْحَانَ رَبِّنَآ إِنَّا كُنَّا ظَالِمِينَ فَأَقْبَلَ بَعْضُهُمْ عَلَىٰ بَعْضٍ يَتَلاَوَمُونَ قَالُواْ } اعترافاً بطغيانهم { يٰوَيْلَنَا } يا قوم ويلنا او نادوا الويل لغاية دهشتهم { إِنَّا كُنَّا طَاغِينَ } وهذه تقال عند شدّة الغيظ وغلظ اليأس، ويقال عند التّوجّه الى الله والتّوبة اليه والنّدم على ما فرّط.
