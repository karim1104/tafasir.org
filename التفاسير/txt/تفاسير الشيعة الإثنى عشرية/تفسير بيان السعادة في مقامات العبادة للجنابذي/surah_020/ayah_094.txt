{ قَالَ } هارون (ع) { يَبْنَؤُمَّ } كان اخاه لامّه وابيه لكنّه اضافه الى الامّ استعطافاً { لاَ تَأْخُذْ بِلِحْيَتِي وَلاَ بِرَأْسِي إِنِّي خَشِيتُ أَن تَقُولَ } ان كنت لحقت بك او قاتلتهم { فَرَّقْتَ بَيْنَ بَنِيۤ إِسْرَآئِيلَ } يعنى لو كنت فارقتهم او قاتلتهم لتفرّقوا باللّحوق بى والبقاء على عبادة العجل { وَلَمْ تَرْقُبْ قَوْلِي } بالخلافة والاصلاح، ولمّا سكت عنه الغضب وكسر سورته باستعطاف هارون (ع) والاعتذار عمّا رآه موسى (ع) خلافاً اقبل على السّامرىّ.
