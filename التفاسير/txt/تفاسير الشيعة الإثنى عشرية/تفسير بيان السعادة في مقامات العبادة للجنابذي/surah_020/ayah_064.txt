{ فَأَجْمِعُواْ } قرئ بقطع الهمزة من باب الافعال وبوصلها اى اجمعوا { كَيْدَكُمْ } المتفرّق فى باب المقابلة مع موسى (ع) { ثُمَّ ٱئْتُواْ صَفّاً } فانّ الاتّفاق والاصطفاف فى المناظرة ارعب واشدّ هيبةّ فى الانظار، قيل: كانوا سبعين الفاً مع كلّ عصا وحبل { وَقَدْ أَفْلَحَ ٱلْيَوْمَ مَنِ ٱسْتَعْلَىٰ } وغلب قيل: هذا كان قول فرعون للسّحرة، وقيل: قول بعضهم لبعضٍ، او قول قوم فرعون للسّحرة.
