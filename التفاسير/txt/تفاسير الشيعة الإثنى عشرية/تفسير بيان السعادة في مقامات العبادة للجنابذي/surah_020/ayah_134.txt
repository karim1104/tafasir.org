{ وَلَوْ أَنَّآ أَهْلَكْنَاهُمْ بِعَذَابٍ مِّن قَبْلِهِ } اى من قبل محمّد (ص) او القرآن او من قبل الاحتجاج بمحمّد (ص) وكتابه { لَ } ادلوا حجّتهم علينا و { قَالُواْ رَبَّنَا لَوْلاۤ أَرْسَلْتَ إِلَيْنَا رَسُولاً } يدعونا اليك وينبّهنا من غفلتنا ويخرجنا من جهلنا { فَنَتَّبِعَ آيَاتِكَ } اى رسلك وخلفاءك وكتبك واحكامك { مِن قَبْلِ أَن نَّذِلَّ } نهون بالعذاب فى الدّنيا { وَنَخْزَىٰ } فى الآخرة، او من قبل ان نذلّ فى الانظار ونخزى فى انفسنا، او من قبل ان نذلّ ونستحيى من اعمالنا عندك.
