{ وَيَقُولُونَ } اى قومك المنكرون للبعث { مَتَىٰ هَـٰذَا ٱلْوَعْدُ إِن كُنتُمْ صَادِقِينَ قُلْ } لهم انّ البعث خارج عن الزّمان انّما هو فى طول الزّمان لا فى عرضه وانتم تسألون عن وقته فى عرض الزّمان و { إِنَّمَا ٱلْعِلْمُ } بمرتبته فى طول الزّمان { عِنْدَ ٱللَّهِ } من العلوم الخاصّة به لا يعلمها غيره { وَإِنَّمَآ أَنَاْ نَذِيرٌ } من عنده { مُّبِينٌ } ظاهرٌ او مظهرٌ لصدقى.
