{ سَخَّرَهَا عَلَيْهِمْ سَبْعَ لَيَالٍ وَثَمَانِيَةَ أَيَّامٍ } قد مضى فى سورة القمر بيان الايّام الثّمانية، وقد مضى سابقاً قصّة عادٍ وثمود { حُسُوماً } الحسوم بالضّمّ الشّؤم والدّؤب فى العمل، ويجوز ان يكون جميعاً لحاسمٍ بمعنى القاطع او بمعنى المانع، فالمعنى ثمانية ايّام شومات، او متتابعات او قاطعات لحياتهم، او مانعات لهم، قال القمّىّ: كان القمر منحوساً بزحل { فَتَرَى ٱلْقَوْمَ فِيهَا صَرْعَىٰ } موتى { كَأَنَّهُمْ أَعْجَازُ نَخْلٍ خَاوِيَةٍ } خالية الاجواف تشبيه لهم بعد خروج ارواحهم باعجاز النّخل المتأكّلة الاجواف.
