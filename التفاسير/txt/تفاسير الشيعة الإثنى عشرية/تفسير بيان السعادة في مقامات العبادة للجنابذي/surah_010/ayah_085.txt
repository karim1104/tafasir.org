{ فَقَالُواْ } اجابة له { عَلَىٰ ٱللَّهِ تَوَكَّلْنَا } متضرّعين قائلين { رَبَّنَا لاَ تَجْعَلْنَا فِتْنَةً } سبب فتنة وشقاءٍ { لِّلْقَوْمِ ٱلظَّالِمِينَ } بان يبلغوا باستعبادنا وتعذيبنا غاية الغرور والشّقاء يعنى لو اردت بلوغهم غاية الشّقاء فاجعل سببه غير عذابنا، او المراد لا تجعلنا محّلاً لفتنتهم وعذابهم لنا.
