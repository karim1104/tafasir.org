{ وَلَوْ أَنَّ لِكُلِّ نَفْسٍ ظَلَمَتْ } فى حقّ الله او حقّ محمّدٍ (ص) { مَا فِي ٱلأَرْضِ لاَفْتَدَتْ بِهِ } عن نفسه من هول العذاب وشدّته { وَأَسَرُّواْ ٱلنَّدَامَةَ } كراهة شماتة الاعداء كما فى الخبر او خوف اطّلاع ملائكة العذاب او اطّلاع الله على ندامتهم النّاشئة عن اعترافهم بالظّلم فانّهم يحلفون لله كما يحلفون لكم على انكار الظّلم والّذنب { لَمَّا رَأَوُاْ ٱلْعَذَابَ وَقُضِيَ بَيْنَهُمْ } بين المؤمنين والمنافقين او بين الظّالمين او المظلومين { بِٱلْقِسْطِ } باعطاء كلّ ذى حقٍّ حقّه وكلّ ذى عقوبهٍ عقوبته { وَهُمْ لاَ يُظْلَمُونَ } بمنع الحقّ وعقوبة غير المتسحقّ وبنقص الحقّ وزيادة العقوبة.
