{ إِنَّ ٱلَّذِينَ آمَنُواْ } بالبيعة العامّة او بالبيعة الخاصّة { وَعَمِلُواْ ٱلصَّالِحَاتِ } اى البيعة الخاصّة وشرائطها او شرائط البيعة الخاصّة والاعمال الّتى كلّفوا بها فيها { يَهْدِيهِمْ رَبُّهُمْ } المضاف الّذى هو ولىّ امرهم الى ملكه وولايته على الاوّل والى ملكوته على الثّانى { بِإِيمَانِهِمْ } باسلامهم او بايمانهم الخاصّ او يهديهم فى الآخرة الى الجنّة { تَجْرِي } حال او مستأنف جواب سؤال { مِن تَحْتِهِمُ ٱلأَنْهَارُ فِي جَنَّاتِ ٱلنَّعِيمِ } متعلّق بتجرى او ظرف مستقرّ حال متداخلة او مترادفة او مستأنفٌ جواب لسؤالٍ مقدّرٍ بتقدير مبتدء محذوف.
