{ وَإِن كَذَّبُوكَ فَقُل } اعراضاً عن الجاهلين او متاركة لهم { لِّي عَمَلِي } نافعاً كان او ضارّاً { وَلَكُمْ عَمَلُكُمْ } كذلك { أَنتُمْ بَرِيۤئُونَ مِمَّآ أَعْمَلُ وَأَنَاْ بَرِيۤءٌ مِّمَّا تَعْمَلُونَ } تأكيد للاوّل ولذا ترك العاطف وعكس التّرتيب لانّه تأكيد للمفهوم لا للمنطوق كأنّه قال: لى عملى لا لكم بحسب مفهوم الحصر ولكم عملكم لالى.
