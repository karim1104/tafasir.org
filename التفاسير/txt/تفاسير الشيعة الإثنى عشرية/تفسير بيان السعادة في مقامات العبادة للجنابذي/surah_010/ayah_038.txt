{ أَمْ يَقُولُونَ ٱفْتَرَاهُ قُلْ } ان افتريته { فَأْتُواْ بِسُورَةٍ مِّثْلِهِ } فانّه ان كان كلام المخلوق وانتم فصحاء الخلق ينبغى ان تقدروا على مثله { وَٱدْعُواْ مَنِ ٱسْتَطَعْتُمْ } للاستعانة به على الاتيان { مِّن دُونِ ٱللَّهِ } كما ادّعيتم انّه من غير الله { إِن كُنتُمْ صَادِقِينَ } فى دعوى الافتراء.
