{ قَالُوۤاْ إِنَّا تَطَيَّرْنَا بِكُمْ لَئِن لَّمْ تَنتَهُواْ } عمّا تقولون وهو الّذى تطيّرنا به { لَنَرْجُمَنَّكُمْ وَلَيَمَسَّنَّكُمْ } علاوة عن الرّجم { مِّنَّا عَذَابٌ أَلِيمٌ قَالُواْ طَائِرُكُم مَّعَكُمْ } قد مضى هذه الكلمة مكرّرةً { أَإِن ذُكِّرْتُم } تطيّرتم او توعّدتم { بَلْ أَنتُمْ قَوْمٌ مُّسْرِفُونَ } فى جميع الامور فلا غرو فى ان تعذّبونا بعد ان تذكّرتم بانّا لا نقول الاّ الحقّ.
