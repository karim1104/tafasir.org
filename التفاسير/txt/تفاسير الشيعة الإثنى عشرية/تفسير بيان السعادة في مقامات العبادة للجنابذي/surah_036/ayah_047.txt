{ وَإِذَا قِيلَ لَهُمْ أَنفِقُواْ مِمَّا رِزَقَكُمُ ٱلله } على المحتاجين { قَالَ ٱلَّذِينَ كَفَرُواْ } بالله او بمحمّدٍ (ص) او بعلىٍّ (ع) وولايته { لِلَّذِينَ آمَنُوۤاْ } مخاطبين لهم { أَنُطْعِمُ مَن لَّوْ يَشَآءُ ٱللَّهُ أَطْعَمَهُ } تخصيص المؤمنين بالخطاب امّا للتّهكّم بهم كأنّهم تعرّضوا بانّكم مقرّون بالله وانّه رازق كلّ مرزوقٍ فلو كان الامر كما تذكرون كنتم انتم اولى باطعامه، او مقصودهم ابداء العذر فى عدم الانفاق بانّ الله اولى منّا بالاعطاء فلمّا لم يشأ الله اطعامهم كنّا اولى بعدم الاطعام { إِنْ أَنتُمْ } فى هذا القول او فى الاقرار بالله او بمحمّدٍ (ص) او بعلىٍّ (ع) { إِلاَّ فِي ضَلاَلٍ مُّبِينٍ وَيَقُولُونَ مَتَىٰ هَذَا ٱلْوَعْدُ } اى وعد العذاب الّذى تعدوننا انتم وصاحبكم او وعد القيامة واحياؤنا للجزاء وعذابنا عندها { إِن كُنتُمْ صَادِقِينَ } فى انّ لنا مُبدءً وانّه يبعثنا بعد موتنا، وانّ محمّداً (ص) رسولٌ منه وانّ ما يقوله صدق.
