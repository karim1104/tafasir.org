{ وَلَئِن سَأَلْتَهُمْ } عطف على من يضلل الله وهو حالٌ فى مقام التّعليل { مَّنْ خَلَقَ ٱلسَّمَاوَاتِ وَٱلأَرْضَ لَيَقُولُنَّ ٱللَّهُ } فكيف يخوّفونك بالّذين من دونه { قُلْ } ردّاً عليهم فى تخويفهم { أَفَرَأَيْتُم مَّا تَدْعُونَ مِن دُونِ ٱللَّهِ إِنْ أَرَادَنِيَ ٱللَّهُ بِضُرٍّ هَلْ هُنَّ كَاشِفَاتُ ضُرِّهِ أَوْ أَرَادَنِي بِرَحْمَةٍ هَلْ هُنَّ مُمْسِكَاتُ رَحْمَتِهِ } والحال ان لا ضرّ الاّ منه ولا رحمة الاّ باذنه فكيف تخوفّوننى بها والخوف لا يكون الاّ بالاضرار او منع النّفع وفى ايراد الضّمائر مؤنّثاتٍ توهينٌ لآلهتهم سواء اريد بها الاصنام والكواكب وامثالها او المترأسّين فى الدّين مقابل الرّؤساء الحقّة { قُلْ } لهم بنحو التّجرى ولا تخف { حَسْبِيَ ٱللَّهُ } ولا حاجة لى الى غيره فلتفعل آلهتكم بى ما قدروا { عَلَيْهِ يَتَوَكَّـلُ ٱلْمُتَوَكِّلُونَ } يعنى ينبغى ان يتوكّل عليه المتوكّلون لانّه لا فاعل فى الوجود باقرار الكلّ الاّ هو.
