{ قُلْ يٰعِبَادِ ٱلَّذِينَ آمَنُواْ } امره (ص) ان يخاطب عبيده بنسبة عبديّتهم الى نفسه اشعاراً بانّه (ص) خليفة له فى ارضه بل فى ارضه وسمائه ومظهرٌ لجميع اوصافه ونسبه فكلّ من كان عبداً له تعالى يكون عبداً لخليفته (ص) عبد طاعةٍ لا عبد عبادةٍ { ٱتَّقُواْ رَبَّكُمْ } اى سخطه { لِلَّذِينَ أَحْسَنُواْ فِي هَـٰذِهِ ٱلدُّنْيَا } متعلّق باحسنوا او حال عن قوله تعالى حسنة فانّ المحسن كما يكون له الحسنى فى الآخرة يكون له الحسنة الّتى هى سهولة الطّريق والسّلوك عليه والالتذاذ به فى الدّنيا، ونعم ما قال المولوىّ فى تفسير الحسنة فى الدّنيا والآخرة بقوله: والجملة فى موضع تعليل بملفوظها ومحذوفها لمنطوق قوله تعالى { ٱتَّقُواْ رَبَّكُمْ } ومفهومه كأنّه قال: اتّقوا سخطه فانّ العاصى معذّب والمطيع مثاب، لانّه للّذين احسنوا { حَسَنَةٌ } وللّذين أساؤا عقوبة { وَأَرْضُ ٱللَّهِ وَاسِعَةٌ } فان لم تتمكّنوا من الاحسان فى ارضٍ فهاجروا الى ارضٍ يمكنكم الاحسان فيها { إِنَّمَا يُوَفَّى ٱلصَّابِرُونَ } جوابُ سؤالٍ مقدّرٍ كأنّه قيل: ان لم يمكن الهجرة فما لمن صبر على مشاقّ الاحسان فى محلّ يشقّ عليه الاحسان؟ او كأنّه قيل: فما لمن هاجر وصبر على مشاقّ الهجرة؟! او كأنّه قيل: ما لمن صبر على الاحسان فى الاوطان؟ او على الهجرة؟ فقال: انّما يوفّى الصّابرون على ذلك { أَجْرَهُمْ بِغَيْرِ حِسَابٍ } كناية عن عظمة الاجر وكثرته، وفى الاخبار اشارة الى انّ المراد اعطاء الاجر بدون محاسبة الاعمال.
