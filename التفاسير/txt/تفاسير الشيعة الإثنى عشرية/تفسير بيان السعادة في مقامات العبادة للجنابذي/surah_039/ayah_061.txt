{ وَيُنَجِّي ٱللَّهُ } عطف على قوله تعالى اليس فى جهنّم فانّه فى معنى يكون فى جهنّم مثوىً للكافرين وينجّى الله { ٱلَّذِينَ ٱتَّقَوْاْ } قد مضى فى اوّل البقرة بيان التّقوى وتفاصيلها { بِمَفَازَتِهِمْ } بنجاتهم يعنى باستعدادهم للنّجاة او فى محلّ نجاتهم والمفازة المَنجاة والمهلكة ضدّ والفلاة الّتى لا ماء بها { لاَ يَمَسُّهُمُ ٱلسُّوۤءُ وَلاَ هُمْ يَحْزَنُونَ ٱللَّهُ خَالِقُ كُـلِّ شَيْءٍ } جوابُ سؤالٍ مقدّرٍ فى مقام التّعليل او منقطع عن سابقه لفظاً ومعنًى { وَهُوَ عَلَىٰ كُلِّ شَيْءٍ وَكِيلٌ } بالحفظ والابقاء على ما هو خير له.
