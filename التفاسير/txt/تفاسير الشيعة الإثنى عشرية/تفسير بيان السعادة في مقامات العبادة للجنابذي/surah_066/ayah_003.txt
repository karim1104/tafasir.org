{ وَإِذَ أَسَرَّ ٱلنَّبِيُّ إِلَىٰ بَعْضِ أَزْوَاجِهِ حَدِيثاً } حديث خلافة ابى بكر وعمر، او حديث تحريم مارية وامرها بكتمانه { فَلَمَّا نَبَّأَتْ بِهِ } عائشة به { وَأَظْهَرَهُ ٱللَّهُ } اى اظهر اخبارها لعائشة { عَلَيْهِ } على محمّدٍ (ص) { عَرَّفَ } تلك الزّوج المأمورة بالكتمان { بَعْضَهُ وَأَعْرَضَ عَن بَعْضٍ } كما مضى { فَلَمَّا نَبَّأَهَا بِهِ قَالَتْ } حفصة { مَنْ أَنبَأَكَ هَـٰذَا قَالَ نَبَّأَنِيَ ٱلْعَلِيمُ ٱلْخَبِيرُ } ثمّ خاطب الله على لسان جبرئيل ومحمّدٍ (ص) حفصة وعائشة فقال: { إِن تَتُوبَآ إِلَى ٱللَّهِ }.
