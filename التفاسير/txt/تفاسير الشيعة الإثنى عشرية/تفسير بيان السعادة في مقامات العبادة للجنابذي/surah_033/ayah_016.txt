{ قُل لَّن يَنفَعَكُمُ ٱلْفِرَارُ إِن فَرَرْتُمْ مِّنَ ٱلْمَوْتِ أَوِ ٱلْقَتْلِ } فانّه لا بدّ من الموت او القتل لكلّ احدٍ ولا ينجو احد من احدهما { وَإِذاً } يعنى اذا فررتم { لاَّ تُمَتَّعُونَ إِلاَّ قَلِيلاً قُلْ مَن ذَا ٱلَّذِي يَعْصِمُكُمْ مِّنَ ٱللَّهِ إِنْ أَرَادَ بِكُمْ سُوۤءاً أَوْ أَرَادَ بِكُمْ رَحْمَةً وَلاَ يَجِدُونَ لَهُمْ مِّن دُونِ ٱللَّهِ وَلِيّاً وَلاَ نَصِيراً قَدْ يَعْلَمُ ٱللَّهُ ٱلْمُعَوِّقِينَ مِنكُمْ } المثبّطين عن الغزو وعن الموافقة مع الرّسول (ص) ولفظة قد للتّحقيق { وَٱلْقَآئِلِينَ لإِخْوَانِهِمْ هَلُمَّ إِلَيْنَا وَلاَ يَأْتُونَ ٱلْبَأْسَ إِلاَّ قَلِيلاً } منهم او اتياناً او زماناً او بأساً قليلاً والمراد بالبأس الحرب.
