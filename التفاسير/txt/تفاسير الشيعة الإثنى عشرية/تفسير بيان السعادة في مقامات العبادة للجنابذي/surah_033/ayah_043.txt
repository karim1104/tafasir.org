{ هُوَ ٱلَّذِي يُصَلِّي عَلَيْكُمْ } اى يرحمكم او ينزّل الرّحمة عليكم { وَمَلاَئِكَتُهُ } يعنى ويستغفر لكم ملائكته فانّ الصّلٰوة من العباد الدّعاء ومن الله الرّحمة ومن الملائكة الاستغفار، وهذه الكلمة فى موضع التّعليل للامر بالذّكر الكثير { لِيُخْرِجَكُمْ مِّنَ ٱلظُّلُمَاتِ } ظلمات نقائص المادّة وحدود الطّبع واهوية النّفس ورذائلها { إِلَى ٱلنُّورِ } اى نور الايمان والطّاعة والاخلاق الحسنة ونور عالم الاطلاق { وَكَانَ بِٱلْمُؤْمِنِينَ رَحِيماً } لانّ فعليّتهم الاخيرة الّتى هى عبارة عن صورة نازلة عن ولىّ امرهم رحمة من الله وجاذبة لرحمةٍ اخرى منه كما انّها ولىّ امرهم بوجهٍ.
