{ وَلاَ تُطِعِ ٱلْكَافِرِينَ وَٱلْمُنَافِقِينَ } فيما يقولون فى حقّ فقراء المؤمنين، او فى ترك التّعرضّ لاصنامهم، او فى حقّ علىّ (ع) وخلافته { وَدَعْ أَذَاهُمْ } هذه الكلمة اسم مصدر لايذاء ومضاف الى الفاعل او الى المفعول { وَتَوَكَّـلْ عَلَى ٱللَّهِ } فى كلّ امورك { وَكَفَىٰ بِٱللَّهِ وَكِـيلاً يٰأَيُّهَا ٱلَّذِينَ آمَنُوۤاْ إِذَا نَكَحْتُمُ ٱلْمُؤْمِنَاتِ ثُمَّ طَلَّقْتُمُوهُنَّ مِن قَبْلِ أَن تَمَسُّوهُنَّ فَمَا لَكُمْ عَلَيْهِنَّ مِنْ عِدَّةٍ تَعْتَدُّونَهَا } اى ايّام عديدة تعدّونها عليهنّ { فَمَتِّعُوهُنَّ } وجوباً بنصف ما فرضتم ان كنتم فرضتم لهنّ فريضة او بما يتمتّع امثالهنّ ان لم تكونوا فرضتم لهنّ فريضة، او متّعوهنّ استحباباً بعدما ادّيتم اليهنّ نصف مهرهنّ او نصف مهر الامثال { وَسَرِّحُوهُنَّ سَرَاحاً جَمِيلاً } اى طلّقوهنّ او ارسلوهنّ من بيوتكم من غير اذًى ومنع حقّ.
