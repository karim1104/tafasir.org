{ وَجَعَلْنَا بَيْنَهُمْ وَبَيْنَ ٱلْقُرَى ٱلَّتِي بَارَكْنَا فِيهَا } اى بلاد الشّام وقيل مكّة { قُرًى ظَاهِرَةً } يعنى متواصلة يظهر بعضها لبعض لقربها واتّصالها { وَقَدَّرْنَا فِيهَا ٱلسَّيْرَ } بحيث ينتقل كلّ من الغادى والرّائح من قرية الى قرية اخرى من غير تعبٍ فى السّير { سِيرُواْ فِيهَا } حال بتقدير القول او مستأنفٌ جوابٌ لسؤالٍ مقدّرٍ بتقدير القول { لَيَالِيَ وَأَيَّاماً } الى الشّام او الى مكّة { آمِنِينَ } من الجوع والعطش ومن السّرّاق وقطّاع الطّريق.
