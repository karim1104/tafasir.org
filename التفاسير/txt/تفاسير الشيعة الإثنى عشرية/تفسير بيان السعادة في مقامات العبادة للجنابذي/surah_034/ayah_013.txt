{ يَعْمَلُونَ لَهُ مَا يَشَآءُ مِن مَّحَارِيبَ } اى قصورٍ رفيعة سمّيت بها لمنعها من الاستيلاء عليها والقدرة على المحاربة فيها { وَتَمَاثِيلَ } اى صورٍ، عن الصّادق (ع): والله ما هى تماثيل الرّجال والنّساء ولكنّها الشّجر وشبهه { وَجِفَانٍ } جمع الجفنة بمعنى القصعة { كَٱلْجَوَابِ } جمع الجابية الحوض الضّخم { وَقُدُورٍ رَّاسِيَاتٍ } ثابتات على الاثافىّ لا تنزل عن مكانها لعظمها { ٱعْمَلُوۤاْ } اى قائلين اعملوا { آلَ دَاوُودَ شُكْراً وَقَلِيلٌ مِّنْ عِبَادِيَ ٱلشَّكُورُ } الكثير الشّكر الّذى لا يغفل عن النّعمة والانعام وتعظيم المنعم وصرفها فى وجهها ومع ذلك لا يمكن لاحدٍ اداء الشّكر حقّه، لانّ الشكر نعمة اعظم من كلّ نعمة يشكر عليها.
