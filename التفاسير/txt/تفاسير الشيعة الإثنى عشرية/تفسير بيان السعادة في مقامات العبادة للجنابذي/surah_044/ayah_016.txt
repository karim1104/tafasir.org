{ يَوْمَ نَبْطِشُ ٱلْبَطْشَةَ ٱلْكُبْرَىٰ } اى يوم القيامة او يوم بدرٍ { إِنَّا مُنتَقِمُونَ وَلَقَدْ فَتَنَّا } وابتلينا { قَبْلَهُمْ قَوْمَ فِرْعَوْنَ } بانواع العذاب التّسعة { وَجَآءَهُمْ رَسُولٌ كَرِيمٌ } اى كريم الاخلاق والافعال، او كريم الاصل والآباء، لانّه كان من اولاد الانبياء (ع)، او كريم عند الله.
