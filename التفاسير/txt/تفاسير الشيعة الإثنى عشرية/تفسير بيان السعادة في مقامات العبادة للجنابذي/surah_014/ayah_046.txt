{ وَقَدْ مَكَرُواْ } صرف الخطاب عنهم او الضّمير راجع الى الّذين ظلموا { مَكْرَهُمْ } ما كان فى وسعهم وجهدهم { وَعِندَ ٱللَّهِ مَكْرُهُمْ } يعنى مكرهم ثابت عند الله فيجازيهم عليه، او عند الله مكرهم فلا ينفذوا ولا يؤثّرا الاّ باذنه، او عند الله مكرهم يعنى ان يمكر بهم مكراً لائقاً بحالهم { وَإِن كَانَ مَكْرُهُمْ } انّه كان مكرهم او ان شرطيّة وصليّة او نافية اى وان كان مكرهم لعظمه مستعدّاً { لِتَزُولَ مِنْهُ ٱلْجِبَالُ } وما كان مكرهم لتزول منه الجبال بل كان اعظم، وقرئ بفتح اللاّم ورفع الفعل على ان يكون ان هى المخفّفة واللاّم للفصل.
