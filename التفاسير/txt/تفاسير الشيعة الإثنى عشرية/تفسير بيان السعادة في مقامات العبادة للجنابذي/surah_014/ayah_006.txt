{ وَإِذْ قَالَ مُوسَىٰ } وذكّرهم اذ قال موسى { لِقَوْمِهِ ٱذْكُرُواْ نِعْمَةَ ٱللَّهِ عَلَيْكُمْ إِذْ أَنجَاكُمْ مِّنْ آلِ فِرْعَوْنَ يَسُومُونَكُمْ سُوۤءَ ٱلْعَذَابِ } باستعبادكم { وَيُذَبِّحُونَ أَبْنَآءَكُمْ وَيَسْتَحْيُونَ نِسَآءَكُمْ } بدل تفصيلىّ { وَفِي ذٰلِكُمْ بَلاۤءٌ مِّن رَّبَّكُمْ عَظِيمٌ } فى سوء العذاب ابتلاء او فى الانجاء نعمة.
