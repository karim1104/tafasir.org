{ يَتَجَرَّعُهُ } يتكلّفه جرعة جرعة لغاية كراهته له { وَلاَ يَكَادُ يُسِيغُهُ وَيَأْتِيهِ ٱلْمَوْتُ مِن كُلِّ مَكَانٍ } بحسب اسبابه لانّه يحيط به اسبابه من جميع جهاته { وَمَا هُوَ بِمَيِّتٍ } فيستريح { وَمِن وَرَآئِهِ عَذَابٌ غَلِيظٌ } اعاذنا الله بمنّه وفضله وقدم احسانه، وقد فسّر العذاب الغليظ الّذى له بعد ذلك العذاب بحميم تغلى به جهنّم منذ خلقت كالمهل يشوى الوجوه بئس الشّراب وسائت مرتفقاً.
