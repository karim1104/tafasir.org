{ ذَلِكَ } الاضلال وتكفير السّيّئات واصلاح الحال { بِأَنَّ ٱلَّذِينَ كَفَرُواْ } بالولاية { ٱتَّبَعُواْ ٱلْبَاطِلَ } اى اهواءهم واعداء امير المؤمنين (ع) { وَأَنَّ ٱلَّذِينَ آمَنُواْ ٱتَّبَعُواْ ٱلْحَقَّ } الولاية وامير المؤمنين { مِن رَّبِّهِمْ كَذَلِكَ } الضّرب لمثل علىٍّ (ع) وعدوّه بنحو العموم الّذى لا يلتفت اليه اعداء آل محمّد (ص) حتّى يسقطوه { يَضْرِبُ ٱللَّهُ لِلنَّاسِ أَمْثَالَهُمْ } اى اوصافهم او حكاياتهم او الامثال الّتى تشبه احوالهم.
