{ وَكَأَيِّن مِّن دَآبَّةٍ } لا تحصى نوعاً وفرداً { لاَّ تَحْمِلُ } الخطاب عامّ او خاصّ بمحمّدٍ (ص) او بمن يزعم ان لا مدخليّة فى الامور لشيءٍ سوى الاسباب الطّبيعيّة كالطّبيعيّة اعتقاداً او حالاً كاكثر النّاس { رِزْقَهَا ٱللَّهُ يَرْزُقُهَا وَإِيَّاكُمْ } فانّ الانسان فى بادى النّظر يظنّ انّ الرّزق منوط بالاسباب الطّبيعيّة لكن دقيق النّظر يحكم بان لا مدخليّة لشيءٍ من الاسباب الطّبيعيّة فى ارتزاق الانسان وليس الارتزاق الاّ بالاسباب الالهيّة وانّ الاسباب الطّبيعيّة حجب على الاسباب الالهيّة ونعم ما قيل: { وَهُوَ ٱلسَّمِيعُ } لاقوالكم القاليّة والحاليّة والاستعداديّة الّتى لا شعور لكم بها { ٱلْعَلِيمُ } بمقدار الاستعداد وقدر الاستحقاق وعمدة اسباب الرّزق هى السّماوات والارض والشّمس والقمر.
