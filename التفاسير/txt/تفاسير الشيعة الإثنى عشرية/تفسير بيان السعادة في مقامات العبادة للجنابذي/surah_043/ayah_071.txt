{ يُطَافُ عَلَيْهِمْ } التفات فيه تجديد نشاط { بِصِحَافٍ } جمع الصّحفة بمعنى القصعة { مِّن ذَهَبٍ وَأَكْوَابٍ } جمع الكوب بالضّمّ كوز لا عروة له، او لا خرطوم له { وَفِيهَا مَا تَشْتَهِيهِ ٱلأَنْفُسُ وَتَلَذُّ ٱلأَعْيُنُ وَأَنتُمْ فِيهَا خَالِدُونَ } فانّ النّعيم الزّائل مستعقب لالم زواله ومشوبٌ لذّته بالم خوف زواله وزحمة حفظه من الزّوال.
