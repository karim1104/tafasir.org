{ بَلْ } ليس بقاؤهم على طريقتهم الباطلة لاعتمادهم على تقليد آباءهم وتمسّكهم به ولكن { مَتَّعْتُ هَـٰؤُلاَءِ } قريشاً { وَآبَآءَهُمْ } بالتّمتّعات الحيوانيّة من غير منذرٍ لهم من البلايا والمصائب ومن الانبياء (ع) فسكنوا الى تلك التّمتّعات واطمأنّوا بها { حَتَّىٰ جَآءَهُمُ ٱلْحَقُّ } اى الولاية { وَرَسُولٌ مُّبِينٌ } ظاهر رسالته وصدقه فيها، او مظهر رسالته.
