{ سَوَآءٌ مِّنْكُمْ } فى علمه { مَّنْ أَسَرَّ ٱلْقَوْلَ } يعنى قول من اسرّ القول { وَمَنْ جَهَرَ بِهِ وَمَنْ هُوَ مُسْتَخْفٍ بِٱلْلَّيْلِ وَسَارِبٌ } بارز { بِٱلنَّهَارِ لَهُ } اى لله او لمن اسرّ القول ومن جهر به { مُعَقِّبَاتٌ } ملائكة يعقّب بعضهم بعضاً، من عقّبه تعقيباً اذا جاء بعقبه { مِّن بَيْنِ يَدَيْهِ وَمِنْ خَلْفِهِ يَحْفَظُونَهُ } حفظاً ناشئاً { مِنْ أَمْرِ ٱللَّهِ } او من اجل امر الله، عن الصّادق (ع) انّه قرئ الآية عنده هكذا فقال لقاريها: الستم عرباً؟! فكيف يكون المعقّبات من بين يديه؟ وانّما المعقّب من خلفه فقال الرّجل: جعلت فداك كيف هذا؟ - فقال: انّما انزلت له معقّبات من خلفه ورقيب من بين يديه يحفظونه بأمر الله ومن ذا الّذى يقدر ان يحفظ الشّيء من امر الله وهم الملائكة الموكّلون بالنّاس، وعن الباقر (ع) من امر الله يقول بأمر الله من ان يقع فى ركىٍّ او يقع عليه حائط او يصيبه شيءٌ حتّى اذا جاء القدر خلّوا بينه وبينه الى المقادير وهما ملكان يحفظانه باللّيل وملكان بالنّهار يتعاقبانه، وقيل: يحفظونه من امر الله بالاستمهال والاستغفار { إِنَّ اللَّهَ لاَ يُغَيِّرُ مَا بِقَوْمٍ } من النّعم { حَتَّىٰ يُغَيِّرُواْ مَا بِأَنْفُسِهِمْ } من حسن الحال والطّاعة والبّر وصلة الارحام { وَإِذَا أَرَادَ اللَّهُ بِقَوْمٍ سُوۤءًا فَلاَ مَرَدَّ لَهُ وَمَا لَهُمْ مِّن دُونِهِ مِن وَالٍ } يعنى لا ناصر سواه ولا متولّى لامور النّاس غيره.
