{ لِلَّذِينَ ٱسْتَجَابُواْ } متعلّق بيضرب الامثال اى يضرب الامثال لحال هؤلاء وهؤلاء يعنى حالهما كحال الماء والزّبد او يضرب الامثال لبشارة هؤلاء وانذار اولئك، او يضرب الامثال لانتفاع الّذين استجابوا { لِرَبِّهِمُ } الاستجابة { ٱلْحُسْنَىٰ وَٱلَّذِينَ لَمْ يَسْتَجِيبُواْ لَهُ } عطف على الّذين استجابوا على الاوّلين وهو مع ما بعده جملة مستأنفة على الثّالث ويجوز ان يكون قوله للّذين استجابوا خبراً مقدّماً للحسنى مع كون الجملة مستأنفة جواباً لسؤالٍ مقدّرٍ ويكون المعنى للّذين استجابوا لرّبهم العاقبة الحسنى والّذين لم يستجيبوا له { لَوْ أَنَّ لَهُمْ مَّا فِي ٱلأَرْضِ جَمِيعاً وَمِثْلَهُ مَعَهُ لاَفْتَدَوْاْ بِهِ أُوْلَـٰئِكَ لَهُمْ سُوۤءُ ٱلْحِسَابِ } بان لا تقبل لهم حسنةٌ ولا تغفر لهم سيّئة كما نسب الى الصّادق (ع) او بان نوقش فى حسابهم واستقصى بهم كما فى خبرٍ آخر { وَمَأْوَاهُمْ جَهَنَّمُ وَبِئْسَ ٱلْمِهَادُ } المستقرّ.
