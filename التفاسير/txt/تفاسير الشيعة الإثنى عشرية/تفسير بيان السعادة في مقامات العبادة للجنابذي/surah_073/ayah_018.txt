{ السَّمَآءُ مُنفَطِرٌ بِهِ } اى فيه او بسببيه اى بسبب شدّة البلاء والهول فيه { كَانَ وَعْدُهُ مَفْعُولاً إِنَّ هَـٰذِهِ } المذكورات من الوعد والوعيد { تَذْكِرَةٌ } للنّفوس المتيقّظة { فَمَن شَآءَ ٱتَّخَذَ إِلَىٰ رَبِّهِ } فى الولاية { سَبِيلاً } هو قبول ولايته بالبيعة معه واتّباع اوامره ونواهيه او الى ربّه المطلق والسّبيل الى الرّبّ المطلق هو صاحب الولاية وقبول ولايته بالبيعة معه واتّباعه.
