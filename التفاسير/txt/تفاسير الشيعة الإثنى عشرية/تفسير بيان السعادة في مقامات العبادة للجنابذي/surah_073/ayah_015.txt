{ إِنَّآ أَرْسَلْنَآ } جوابُ سؤالٍ مقدّرٍ كأنّه قيل بعد ما هدّدهم بقوله: { وَذَرْنِي وَٱلْمُكَذِّبِينَ }: ما فعلت بنا؟ وما تفعل بعد بنا؟ - فقال: انّا ارسلنا { إِلَيْكُمْ رَسُولاً شَاهِداً } يشهد { عَلَيْكُمْ } يوم القيامة بالرّدّ والقبول والاقرار والنّكول { كَمَآ أَرْسَلْنَآ إِلَىٰ فِرْعَوْنَ رَسُولاً } نكّر الرّسول لعدم تعلّق الغرض بتعيين الرّسول.
