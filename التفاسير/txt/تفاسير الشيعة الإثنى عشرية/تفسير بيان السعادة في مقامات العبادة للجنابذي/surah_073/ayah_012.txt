{ وَذَرْنِي وَٱلْمُكَذِّبِينَ } بالله او بك او بوصيّك، وعن الكاظم (ع) والمكذّبين بوصيّك، قيل: هذا تنزيلٌ؟ - قال: نعم { أُوْلِي ٱلنَّعْمَةِ وَمَهِّلْهُمْ } ولا تعاجلهم بالعقوبة من عندك او بطلب العقوبة من عند الله { قَلِيلاً إِنَّ لَدَيْنَآ } تعليل { أَنكَالاً } جمع النّكل بالكسر القيد الشّديد، او القيد من النّار، او ضرب من اللّجم { وَجَحِيماً وَطَعَاماً ذَا غُصَّةٍ } ينشب فى الحلق ولا يسيغ { وَعَذَاباً أَلِيماً يَوْمَ تَرْجُفُ ٱلأَرْضُ } تضطرب او تخسف كما قال القمّىّ { وَٱلْجِبَالُ وَكَانَتِ ٱلْجِبَالُ كَثِيباً مَّهِيلاً } الكثيب التّلّ من الرّمل، وهال عليه التّراب والتّراب مهيل.
