{ قُلْ أَرَأَيْتُمْ } قد مضى فى سورة الانعام بيان لهذه الكلمة عند قوله تعالى: قل ارأيتكم ان اتاكم عذاب الله { إِن جَعَلَ ٱللَّهُ عَلَيْكُمُ ٱلْلَّيْلَ سَرْمَداً } دائماً طويلاً { إِلَىٰ يَوْمِ ٱلْقِيَامَةِ مَنْ إِلَـٰهٌ غَيْرُ ٱللَّهِ يَأْتِيكُمْ بِضِيَآءٍ } لمّا كان المقصود من النّهار الضّياء الّذى به يبصرون ويتعيّشون اتى موضع النّهار بالضّياء { أَفَلاَ تَسْمَعُونَ } ولمّا كان الضّياء بنفسه مطلوباً ونافعاً ويكون طلب المكاسب والمعايش بسبب الانتفاع به لم يأت بوصفٍ للضّياء مثل قرينه.
