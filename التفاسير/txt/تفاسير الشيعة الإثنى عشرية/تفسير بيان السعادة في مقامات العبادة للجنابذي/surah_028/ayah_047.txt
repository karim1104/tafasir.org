{ وَلَوْلاۤ أَن تُصِيبَهُم مُّصِيبَةٌ } اى لولا كراهة ان تصيبهم مصيبة { بِمَا قَدَّمَتْ أَيْدِيهِمْ } بجهالتهم { فَيَقُولُواْ } بعد ذلك اعتراضاً علينا واعتذاراً عن جهالتهم { رَبَّنَا لَوْلاۤ أَرْسَلْتَ إِلَيْنَا رَسُولاً } فنعلم انّ لك آياتٍ { فَنَتِّبِعَ آيَاتِكَ وَنَكُونَ مِنَ ٱلْمُؤْمِنِينَ } فلم تصبنا تلك المصيبة بجهالتنا ما ارسلناك اليهم لعدم استعدادهم واستحقاقهم لرسول مثلك.
