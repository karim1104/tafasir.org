{ وَمَا كُنتَ } عطف باعتبار المعنى فانّ المقصود من قوله: { قُل رَّبِّيۤ أَعْلَمُ } (الآية) تسليته كأنّه قال: انت على الهدى وما كنت { تَرْجُوۤ أَن يُلْقَىٰ إِلَيْكَ ٱلْكِتَابُ } يعنى النّبوّة والقرآن { إِلاَّ رَحْمَةً مِّن رَّبِّكَ } استثناء مفرّغ فى موضع التّعليل او منصوب بنزع الخافض اى الاّ برحمةٍ من ربّك او استثناء منقطع والمعنى لكن اعطيت الكتاب رحمةً من ربّك { فَلاَ تَكُونَنَّ ظَهيراً لِّلْكَافِرِينَ } فانّ الكتاب نعمة والنّبوّة نعمة عظيمة فلا تصرفهما فى اعداء المعطى، وهذه وما بعدها خطاب له (ص) على ايّاك اعنى واسمعى يا جارة.
