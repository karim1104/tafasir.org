{ فَأَصْبَحَ } موسى (ع) فى اليوم الثّانى { فِي ٱلْمَدِينَةِ خَآئِفاً } من فرعون وقومه لشياع خبر اجتماع السّبطىّ عليه وشياع قتله القبطىّ { يَتَرَقَّبُ } الاخبار من فرعون وقومه فى حقّه { فَإِذَا ٱلَّذِي ٱسْتَنْصَرَهُ بِٱلأَمْسِ يَسْتَصْرِخُهُ قَالَ لَهُ مُوسَىٰ إِنَّكَ لَغَوِيٌّ مُّبِينٌ } قاتلت بالامس رجلاً وتقاتل اليوم الآخر.
