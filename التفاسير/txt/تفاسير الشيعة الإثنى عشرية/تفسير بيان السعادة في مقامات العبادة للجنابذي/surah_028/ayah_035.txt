{ قَالَ } اجابةً لمسؤله { سَنَشُدُّ عَضُدَكَ بِأَخِيكَ وَنَجْعَلُ لَكُمَا سُلْطَاناً } اجابةً من مسؤله وتفضّل عليه بالزّيادة على مسؤله اعنى وعد النّصر لهما وعدم وصول الضّرر منهم اليهما { فَلاَ يَصِلُونَ إِلَيْكُمَا } بضررٍ { بِآيَاتِنَآ } الباء سببيّة والظّرف متعلّق بلا يصلون او بالغالبون { أَنتُمَا وَمَنِ ٱتَّبَعَكُمَا ٱلْغَالِبُونَ } فاطمأنّ موسى (ع) بوعده تعالى وذهب الى فرعون.
