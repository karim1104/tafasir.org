{ أَفَمَن وَعَدْنَاهُ وَعْداً حَسَناً } تأكيد للتّزهيد والتّشويق { فَهُوَ لاَقِيهِ كَمَن مَّتَّعْنَاهُ مَتَاعَ ٱلْحَيَاةِ ٱلدُّنْيَا } الّذى لا بقاء له ويكون لذّته مشوباً بالالم وراحته بالتّعب وغناه بالحاجة ويكون عاقبته الحسرة والنّدامة { ثُمَّ هُوَ يَوْمَ ٱلْقِيَامَةِ مِنَ ٱلْمُحْضَرِينَ } للحساب او العقاب.
