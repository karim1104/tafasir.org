{ وَلَمَّا وَرَدَ مَآءَ مَدْيَنَ } وهو بئر كانت لهم { وَجَدَ عَلَيْهِ أُمَّةً مِّنَ ٱلنَّاسِ يَسْقُونَ } لمواشيهم من البئر { وَوَجَدَ مِن دُونِهِمُ ٱمْرَأَتَينِ تَذُودَانِ } تمنعان غنمهما عن الماء { قَالَ مَا خَطْبُكُمَا } ما شأنكما تذودان اغنامكما عن الورد { قَالَتَا لاَ نَسْقِي } اغنامنا عند مزاحمة النّاس { حَتَّىٰ يُصْدِرَ ٱلرِّعَآءُ } قرئ من باب الافعال ومن الثّلاثىّ المجرّد وننتظر فضول الماء فنسقى به ولا نقدر نحن على السّقى من البئر { وَأَبُونَا شَيْخٌ كَبِيرٌ } لا يقدر على ان يتولّى السّقى بنفسه.
