{ وَقِيلَ } للاتباع { ٱدْعُواْ شُرَكَآءَكُمْ } فى الولاية والطّاعة او فى الرّبوبيّة { فَدَعَوْهُمْ فَلَمْ يَسْتَجِيبُواْ لَهُمْ } لعجزهم عن الجواب او اشتغالهم بانفسهم { وَرَأَوُاْ ٱلْعَذَابَ لَوْ أَنَّهُمْ كَانُواْ يَهْتَدُونَ } استيناف بصورة التّمنّى واظهار انّه ينبغى ان يتحسّر عليهم، او حال بتقدير القول اى مقولاً فيهم لو انّهم كانوا يهتدون الى الولاية لما كانوا فى العذاب.
