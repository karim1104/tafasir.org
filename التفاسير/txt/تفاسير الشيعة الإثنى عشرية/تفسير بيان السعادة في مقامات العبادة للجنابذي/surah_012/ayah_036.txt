{ وَدَخَلَ } اُدخل { مَعَهُ ٱلسِّجْنَ فَتَيَانَ } كانا عبدين للملك احدهما كان خبّازه والآخر صاحب شرابه واستعمال الفتى والفتاة فى العبيد والاماء غالب فى عرفهم وقيل: انّه لمّا ادخل السّجن استدعى من السّجّان ان ينزله تحت شجرة يابسة كانت فى وسط السّجن فآواه هناك فتوضّأ (ع) تحتها وصلّى فأصبحت الشّجرة مخضرّة، وكان ينصح اهل السّجن ويسلّيهم ويعظهم ويتعاهدهم كلّ صباح ومساء فعرفوه بالصّلاح واحبّوه وكان يبثّ كلّ شكواه اليه ورأى فى المنام صاحباه ما قصّ الله تعالى فاتيا { قَالَ أَحَدُهُمَآ إِنِّيۤ أَرَانِيۤ أَعْصِرُ خَمْراً } اى عصيراً او عنباً، واطلاق الخمر للاشارة الى انّه يعصره للخمر او المراد انّى اعصر الخمر عن درديّها واصفّيها { وَقَالَ ٱلآخَرُ إِنِّي أَرَانِيۤ أَحْمِلُ فَوْقَ رَأْسِي خُبْزاً } جفنةً فيها خبز { تَأْكُلُ ٱلطَّيْرُ مِنْهُ نَبِّئْنَا بِتَأْوِيلِهِ } ورد عن الصّادق (ع) انّه لمّا امر الملك بحبس يوسف (ع) فى السّجن الهمه الله تعالى علم تأويل الرّؤيا فكان يعبّر لاهل السّجن رؤياهم وانّ فتيين ادخلا معه السّجن يوم حبسه فباتا فأصبحا فقالا: انّا رأينا رؤيا فعبّرها لنا فقال: وما رأيتما؟ فقصّا { إِنَّا نَرَاكَ مِنَ ٱلْمُحْسِنِينَ } من صاحبى السّجن او ممّن يحسن الى جلسائه ومعاشريه لانّه كان يقوم على المريض ويلتمس للمحتاج ويوسّع فى المجلس على جلسائه او ممّن يحسن تعبير الرّؤيا لانّه كان يعبّر لاهل السّجن ويوافق تعبيره الواقع.
