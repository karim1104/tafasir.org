{ ٱقْتُلُواْ يُوسُفَ أَوِ ٱطْرَحُوهُ أَرْضاً } مجهولة { يَخْلُ لَكُمْ وَجْهُ أَبِيكُمْ } عن مزاحمة التّوجّه الى يوسف (ع) { وَتَكُونُواْ مِن بَعْدِهِ } بعد يوسف وقتله او طرحه { قَوْماً صَالِحِينَ } بان تتوبوا الى الله ثمّ تعبدوه فى اوامره ونواهيه وهذا دليل على انّهم فى ذواتهم كانوا طيّبين وانّما عرض ذلك لهم من الشّيطان.
