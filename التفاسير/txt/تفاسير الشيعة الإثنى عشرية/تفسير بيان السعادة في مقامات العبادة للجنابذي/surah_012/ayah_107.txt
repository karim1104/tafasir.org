{ أَفَأَمِنُوۤاْ } اى الّذين انكروا رسالتك او الّذين آمنوا مع الاشراك تهديد لهم حتّى يخلصوا التّوحيد ويستوجبوا المزيد { أَن تَأْتِيَهُمْ غَاشِيَةٌ مِّنْ عَذَابِ ٱللَّهِ } عقوبة تغشاهم { أَوْ تَأْتِيَهُمُ ٱلسَّاعَةُ } ساعة القيامة الصّغرى او الكبرى او ظهور القائم عجّل الله فرجه { بَغْتَةً } من غير ظهور علامة { وَهُمْ لاَ يَشْعُرُونَ } حتّى يستعدّوا ويتهيّؤا لها.
