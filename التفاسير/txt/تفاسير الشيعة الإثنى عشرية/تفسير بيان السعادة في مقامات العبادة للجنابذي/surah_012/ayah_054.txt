{ وَقَالَ ٱلْمَلِكُ ٱئْتُونِي بِهِ أَسْتَخْلِصْهُ لِنَفْسِي } بجلعه من خواصّى من غير حكومة لغيرى عليه فذهب الرّسول واحضره { فَلَمَّا كَلَّمَهُ } ووجده صاحب رشدٍ وكمال وكلام وقد علم عفّته وامانته سابقاً { قَالَ إِنَّكَ ٱلْيَوْمَ لَدَيْنَا مِكِينٌ } ذو مكانة ومنزلة لرشد وعقلك { أَمِينٌ } لظهور عفّتك وامانتك.
