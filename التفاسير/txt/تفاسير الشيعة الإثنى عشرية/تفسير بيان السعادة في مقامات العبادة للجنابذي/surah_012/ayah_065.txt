{ وَلَمَّا فَتَحُواْ مَتَاعَهُمْ } اوعية متاعهم { وَجَدُواْ بِضَاعَتَهُمْ } ثمن مقلهم او نعالهم واديمهم { رُدَّتْ إِلَيْهِمْ قَالُواْ } استبشاراً { يٰأَبَانَا مَا نَبْغِي } يعنى لا مزيد على ذلك الاحسان حيث احسن ضيافتنا ومثوانا وجعل بضاعتنا فى رحالنا { هَـٰذِهِ بِضَاعَتُنَا رُدَّتْ إِلَيْنَا وَنَمِيرُ أَهْلَنَا } اى نذهب بأخينا ونمير أهلنا { وَنَحْفَظُ أَخَانَا } او نبغى من البغى اى لا نبغى ونمير اهلنا { وَنَزْدَادُ كَيْلَ بَعِيرٍ } بمصاحبة اخينا { ذٰلِكَ } الكيل الّذى كيل لنا { كَيْلٌ يَسِيرٌ } او ذلك الكيل المزيد على اكيالنا كيل يسير لا يضايقنا الملك فيه او هو من كلام يعقوب (ع) جواباً لبنيه وردّاً عليهم يعنى ذلك الكيل المزيد كيل يسير لا ينبغى للعاقل ان يجعل ابنه فى معرض المخاوف لمثل ذلك.
