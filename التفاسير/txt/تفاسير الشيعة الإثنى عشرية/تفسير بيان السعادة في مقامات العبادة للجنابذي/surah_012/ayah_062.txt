{ وَقَالَ لِفِتْيَانِهِ ٱجْعَلُواْ بِضَاعَتَهُمْ فِي رِحَالِهِمْ لَعَلَّهُمْ يَعْرِفُونَهَآ } يعرفون حقّ ردّها او يعرفون اعيانها، فرغبوا الى الرّجوع { إِذَا ٱنْقَلَبُوۤاْ إِلَىٰ أَهْلِهِمْ لَعَلَّهُمْ يَرْجِعُونَ فَلَمَّا رَجِعُوا إِلَىٰ أَبِيهِمْ قَالُواْ يٰأَبَانَا مُنِعَ مِنَّا ٱلْكَيْلُ } حكم بمنعه ان لم نذهب بأخينا { فَأَرْسِلْ مَعَنَآ أَخَانَا نَكْتَلْ } برفع المانع فانّ سبب المنع عدم ذهابنا بأخينا بنيامين، وقرئ يكتل اى بنيامين لنفسه اولنا ايضاً اى يصير سبباً للاكتيال او يكتل الكيّال لنا برفع المانع ولمّا كانوا مسبوقين بما فعلوا بيوسف (ع) وخدعوا اباهم فيه تبادروا الى قولهم { وَإِنَّا لَهُ لَحَافِظُونَ قَالَ هَلْ آمَنُكُمْ عَلَيْهِ } تعييراً لهم على قولهم بما قالوا فى حقّ يوسف (ع) ولم يفوا به { إِلاَّ كَمَآ أَمِنتُكُمْ عَلَىٰ أَخِيهِ } يوسف (ع) { مِن قَبْلُ } ثمّ انصرف عنهم من الاعتماد على قولهم والتجأ الى الحافظ الحقيقىّ فقال: { فَٱللَّهُ خَيْرٌ حَافِظاً وَهُوَ أَرْحَمُ ٱلرَّاحِمِينَ } فعلى حفظه ورحمته أعتمد لا على قولكم فى حقّ يوسف (ع) واخيه، نسب الى الخبر انّه تعالى قال: فبعزّتى لاردّنهما اليك بعد ما توكّلت علىّ.
