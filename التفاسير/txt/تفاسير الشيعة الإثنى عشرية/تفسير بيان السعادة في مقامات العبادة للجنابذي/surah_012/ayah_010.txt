{ قَالَ قَآئِلٌ مِّنْهُمْ } قيل: كان القائل يهودا وورد أنّه كان لاوى وهو الّذى بقى النّبوّة فى عقبه { لاَ تَقْتُلُواْ يُوسُفَ } عظّم القتل ونهاهم عنه ووضع الظّاهر موضع المضمر تعليلاً للنّهى بتذكيرهم انّه يوسف (ع) وابن ابيهم وأحبّهم اليه ليعظّموا قتله ايضاً { وَأَلْقُوهُ فِي غَيَابَةِ ٱلْجُبِّ } قعره الّذى يغيب عن الانظار { يَلْتَقِطْهُ بَعْضُ ٱلسَّيَّارَةِ } فيذهب به عن ارضكم ويبعّده عن ابيكم { إِن كُنتُمْ } لا محالة { فَاعِلِينَ } به ما يفرّق بينه وبين ابيه.
