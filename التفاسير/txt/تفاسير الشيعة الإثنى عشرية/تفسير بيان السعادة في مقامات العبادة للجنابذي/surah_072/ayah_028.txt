{ لِّيَعْلَمَ } الله { أَن قَدْ أَبْلَغُواْ } الى الرّسل الّذين هم الملائكة او الرّسل البشريّون { رِسَالاَتِ رَبِّهِمْ } والمعنى ليظهر علمه بذلك او ليعلم الرّسول (ص) ان قد ابلغ الملائكة او ابلغ الرّسل الماضون رسالات ربّهم { وَأَحَاطَ بِمَا لَدَيْهِمْ } عطف على عالم الغيب ورفع لتوهّم ان يكون لله علم حادث كما يتوهّم من قوله ليعلم { وَأَحْصَىٰ كُلَّ شَيْءٍ عَدَداً } تأكيد وتعميم بعد تخصيصٍ.
