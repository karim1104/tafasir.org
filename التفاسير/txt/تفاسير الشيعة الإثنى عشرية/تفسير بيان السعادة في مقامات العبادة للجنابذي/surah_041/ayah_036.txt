{ وَإِمَّا يَنزَغَنَّكَ } نزغه كمنعه طعن فيه واغتابه ووسوس وبينهم افسدوا غرى { مِنَ ٱلشَّيْطَانِ نَزْغٌ } مصدر بمعنى الفاعل او من قبيل جدّ جدّه يعنى ان يوسوسك من قبل الشّيطان موسوسٌ او يطعن فيك طاعنٌ او يدفعك دافعٌ حال ارادتك الاحسان الى المسيء { فَٱسْتَعِذْ بِٱللَّهِ } من نزغه فانّه يعيذك { إِنَّهُ هُوَ ٱلسَّمِيعُ } لاستعاذتك { ٱلْعَلِيمُ } باستجارتك، او فاستعذ بالله من طاعته فانّه السّميع لاقتصاصك القولىّ، العليم لاقتصاصك الفعلىّ فيؤاخذ عليه.
