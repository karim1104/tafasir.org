{ وَيٰقَوْمِ مَا لِيۤ أَدْعُوكُـمْ إِلَى ٱلنَّجَاةِ } لم يقل مالكم نصفاً من نفسه فى مقام النّصح { وَتَدْعُونَنِيۤ إِلَى ٱلنَّارِ تَدْعُونَنِي } بدل من الاوّل { لأَِكْـفُرَ بِٱللَّهِ وَأُشْرِكَ بِهِ مَا لَيْسَ لِي بِهِ } اى بربوبيّته واستحقاق آلهته { عِلْمٌ } تعريضٌ بهم وانّ عبادة ما ليس على جواز عبادته برهانٌ ليست الاّ سفاهةً وانتم تعبدون ما ليس لكم بالهته علمٌ { وَأَنَاْ أَدْعُوكُمْ إِلَى ٱلْعَزِيزِ } المنيع الّذى لا يمنعه عن مراده مانعٌ وعزّته دليل آلهته { ٱلْغَفَّارِ } الّذى ينبغى ان يطلب بعبادته غفرانه.
