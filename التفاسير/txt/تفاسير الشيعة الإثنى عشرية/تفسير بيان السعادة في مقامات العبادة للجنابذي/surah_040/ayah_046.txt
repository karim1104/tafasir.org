{ ٱلنَّارُ } ان كان المراد بسوء العذاب عذاب البرزخ والآخرة جاز ان يكون النّار بدلاً منه بدل الاشتمال، وجاز ان يكون مبتدءً وقوله تعالى { يُعْرَضُونَ } خبره والجملة تفسيراً لسوء العذاب، وان كان المراد به عذاب فرعون فى الدّنيا فالنّار مبتدء ويعرضون خبره والجملة مستأنفة منقطعة او حاليّة حالاً مقدّرة اى حال كونهم بعد سوء العذاب النّار يعرضون { عَلَيْهَا غُدُوّاً وَعَشِيّاً } فى اخبارٍ كثيرةٍ انّ هذا فى نار الدّنيا يعنى نار البرزخ لانّ فى نار القيامة لا يكون غدوٌّ وعشىٌّ وامّا نار الخلد فهو قوله تعالى { وَيَوْمَ تَقُومُ ٱلسَّاعَةُ أَدْخِلُوۤاْ آلَ فِرْعَوْنَ أَشَدَّ ٱلْعَذَابِ } بتقدير القول، وقرئ ادخلوا من الثّلاثىّ المجرّد.
