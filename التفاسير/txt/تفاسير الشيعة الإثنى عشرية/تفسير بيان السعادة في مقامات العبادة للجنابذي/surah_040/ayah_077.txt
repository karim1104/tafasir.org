{ فَٱصْبِرْ } يعنى اذا علمت حال المنافقين الّذين ينافقون بالنّسبة اليك والى علىٍّ (ع) فاصبر ولا تجزع ولا تحزن { إِنَّ وَعْدَ ٱللَّهِ حَقٌّ } لا خلف فيه { فَـإِمَّا نُرِيَنَّكَ بَعْضَ ٱلَّذِي نَعِدُهُمْ } من العذاب { أَوْ نَتَوَفَّيَنَّكَ فَإِلَيْنَا يُرْجَعُونَ } وقد سبق الآية فى سورة يونس وسورة الرّعد.
