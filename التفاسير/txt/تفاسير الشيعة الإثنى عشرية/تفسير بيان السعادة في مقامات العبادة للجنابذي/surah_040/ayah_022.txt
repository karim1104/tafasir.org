{ أَوَلَمْ يَسِيروُاْ فِي ٱلأَرْضِ } فيشاهدوا آثار الماضين وآثار قضائه تعالى بالحقّ { فَيَنظُرُواْ كَيْفَ كَانَ عَاقِبَةُ ٱلَّذِينَ كَانُواْ مِن قَبْلِهِمْ كَانُواْ هُمْ أَشَدَّ مِنْهُمْ قُوَّةً وَآثَاراً فِي ٱلأَرْضِ فَأَخَذَهُمُ ٱللَّهُ بِذُنُوبِهِمْ وَمَا كَانَ لَهُم مِّنَ ٱللَّهِ مِن وَاقٍ ذَلِكَ بِأَنَّهُمْ كَانَت تَّأْتِيهِمْ رُسُلُهُم بِٱلْبَيِّنَاتِ } كما أتيتهم بها { فَكَفَرُواْ } كما كفر هؤلاء { فَأَخَذَهُمُ ٱللَّهُ إِنَّهُ قَوِيٌّ شَدِيدُ ٱلْعِقَابِ } فليحذر هؤلاء ممّا نزل بهم.
