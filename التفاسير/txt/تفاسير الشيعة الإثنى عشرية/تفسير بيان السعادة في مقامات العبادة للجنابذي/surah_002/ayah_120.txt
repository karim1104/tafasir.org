{ وَلَنْ تَرْضَىٰ عَنكَ ٱلْيَهُودُ وَلاَ ٱلنَّصَارَىٰ } عطف على جملة لا تسأل او جملة انّا أرسلناك { حَتَّىٰ تَتَّبِعَ مِلَّتَهُمْ } اقناط له (ص) عن رضاهم بأنّهم لا يرضون عنه الاّ بما هو محالٌ عنده وردعٌ للمؤمنين عن طلب رضاهم { قُلْ } للمؤمنين { إِنَّ هُدَى ٱللَّهِ هُوَ ٱلْهُدَىٰ } لا استرضاء اليهود والنّصارى ورضاهم، او قل لليهود والنّصارى: { نَّ هُدَى ٱللَّهِ هُوَ ٱلْهُدَىٰ } لا ما اعتدتموه من الملّة المأخوذة من الآباء المهويّة لكم بسبب اعتيادها { وَلَئِنِ ٱتَّبَعْتَ أَهْوَآءَهُمْ } آراءِ أنفسهم من غير مداخلة العقل او مهويّاتهم { بَعْدَ ٱلَّذِي جَآءَكَ مِنَ ٱلْعِلْمِ } بحقّيّة ملّتك وبطلان ملّتهم وآرائهم { مَا لَكَ مِنَ ٱللَّهِ مِن وَلِيٍّ وَلاَ نَصِيرٍ } لم يأت بالفاء لكونه جواباً للقسم لا للشّرط وهو على " ايّاك اعنى واسمعى يا جارة " تعريض بأمّته (ص).
