{ وَمَآ أَنفَقْتُمْ مِّن نَّفَقَةٍ } ممّا يطلق عليه اسم النّفقة قليلاً كان ام كثيراً فى حقّ ام باطل صحيحاً او فاسداً مبطلاً او مبقىً سرّاً او علانيةً { أَوْ نَذَرْتُمْ مِّن نَّذْرٍ } كذلك تجزوا به { فَإِنَّ ٱللَّهَ يَعْلَمُهُ } ويقدر على المجازاة ولا مانع من مجازاته { وَمَا لِلظَّالِمِينَ } اى مانعى الحقوق من اهاليها ومعطيها لغير اهاليها فى الانفاق والنّذر او فى مطلق الموارد ومنها الانفاق والنّذر { مِنْ أَنْصَارٍ } يدفعون عقوبة الله عنهم.
