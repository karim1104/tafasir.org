{ أَمْ كُنتُمْ شُهَدَآءَ } ام منقطعة متضمّنة للهمزة والمقصود اظهار انّ بنى يعقوب أقرّوا بعبادة الله وتوحيده تعريضاً باليهود والنّصارى فى عبادة العزير والمسيح، وأقرّوا بالاسلام تعريضاً بنفى التهوّد والتنصّر { إِذْ حَضَرَ يَعْقُوبَ ٱلْمَوْتُ إِذْ قَالَ } بدل من اذ حضر { لِبَنِيهِ مَا تَعْبُدُونَ مِن بَعْدِي } سأل (ع) عمّا يعبدونه تذكيراً بالتّوحيد وتقريراً لهم عليه وعلى الاسلام { قَالُواْ نَعْبُدُ إِلَـٰهَكَ وَإِلَـٰهَ آبَائِكَ إِبْرَاهِيمَ وَإِسْمَاعِيلَ } عدّوه من الاباء لانّ العمّ كالأب ويسمّيه العرب اباً { وَإِسْحَاقَ إِلَـٰهاً وَاحِداً } صرّح بالتّوحيد تعريضاً باليهود والنّصارى فى القول بأنّ عزيراً ابن الله والمسيح ابن الله او ثالث ثلاثةٍ { وَنَحْنُ لَهُ مُسْلِمُونَ } لا يهوديّون ولا نصرانيّون.
