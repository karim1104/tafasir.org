{ بَلَىٰ } اثبات لما نفوه بقولهم: لن يدخل الجنّة الاّ من كان هودا او نصارى { مَنْ أَسْلَمَ } اخلص { وَجْهَهُ } الوجه العضو المخصوص وما يتوجّه الشّيء به ونفس الشّيء والمعنى من أخلص جهة توجّهه او ذاته { لِلَّهِ وَهُوَ مُحْسِنٌ } فى أفعاله او محسن الى خلقه { فَلَهُ أَجْرُهُ } الّلائق به الّذى لا يمكن تعيينه الاّ بالاضافة اليه { عِندَ رَبِّهِ } كأنّه للاهتمام به لم يكل أجره الى غيره { وَلاَ خَوْفٌ عَلَيْهِمْ } جمع الضّمير مع الافراد فى الضّمائر السّابقة باعتبار لفظ من ومعناه { وَلاَ هُمْ يَحْزَنُونَ } قد مضى بيان هذه الآية فى اوّل السّورة.
