{ فَإِن لَّمْ تَفْعَلُواْ } ترك ما بقى من الرّبوا { فَأْذَنُواْ } اى اعلموا { بِحَرْبٍ } عظيمة { مِّنَ ٱللَّهِ وَرَسُولِهِ } وهذا غاية التهديد قلّما يهدّد بمثله { وَإِنْ تُبْتُمْ } بعد ما علمتم بالحرب من مطالبة ما بقى من الربا واعتقاد حلّه { فَلَكُمْ رُؤُوسُ أَمْوَالِكُمْ } ليس للمدينين ان يحاسبوا رؤس الاموال فيما أخذتموه من الربا قبل البيّنة { لاَ تَظْلِمُونَ } بأخذ الزّيادة على رأس المال { وَلاَ تُظْلَمُونَ } بنقصان رأس المال.
