{ قَالُواْ ٱدْعُ لَنَا رَبَّكَ يُبَيِّنَ لَّنَا مَا هِيَ } ما وصفها فانّ ما هى كما هو سؤالٌ عن حقيقة الشيء ومهيّته يكون سؤالاً عن صفة الشّيئ ومميّزاته العرضيّة { قَالَ إِنَّهُ يَقُولُ إِنَّهَا بَقَرَةٌ لاَّ فَارِضٌ } اى لا مسنّة ولغلبة الاسميّة عليه لم يأت بتاء التّأنيث { وَلاَ بِكْرٌ } لا صغيرة { عَوَانٌ بَيْنَ ذٰلِكَ } المذكور من الفارض والبكر { فَٱفْعَلُواْ مَا تُؤْمَرونَ } ولا تكثروا السّؤال عنها حتّى يشدّد عليكم.
