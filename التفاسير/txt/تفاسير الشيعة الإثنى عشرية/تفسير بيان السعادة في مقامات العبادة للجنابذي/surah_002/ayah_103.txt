{ وَلَوْ أَنَّهُمْ آمَنُواْ } ولو انّ اليهود ومن يليهم من النّواصب آمنوا بالايمان العامّ او بالايمان الخاصّ او أقرّوا وأذعنوا بالكتاب الّذى نبذوه وراء ظهورهم وهو عطفٌ على لمن اشتراه، او على سائر الجمل السّابقة لكن عطفه على قوله { لَمَنِ ٱشْتَرَاهُ } أوفق بحسب أجزاء ما بعده { وٱتَّقَوْا } مخالفة من بايعوا معه او اتّباع ما تتلو الشّياطين { لَمَثُوبَةٌ } لهم { مِّنْ عِندِ ٱللَّهِ خَيْرٌ } ونكّر المثوبة للاشعار بانّ ما يصدق عليه المثوبة أىّ شيءٍ كان يسيراً او كثيراً خيرٌ ولم يأت بالجملة الفعليّة للاشعار بأنّ لزوم المثوبة أمر مفروغ عنه والمحتاج الى البيان لزوم خيريّة المثوبة لا نفس المثوبة، ولم يأت بالمفضّل عليه لعدم الاعتداد به وليذهب ذهن السّامع كلّ مذهبٍ { لَّوْ كَانُواْ يَعْلَمُونَ } لو للتّمنّى او للّشرط.
