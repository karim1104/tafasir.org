{ دَرَجَاتٍ } عظيمة { مِّنْهُ وَمَغْفِرَةً } عظيمة بستر نسبة الافعال والصّفات والانفس عنهم { وَرَحْمَةً } عظيمة لانّهم خرجوا عن دار السّخط ودخلوا فى دار الرّحمة وصاروا رحمةً بانفسهم وقد علم وجه عدم الاتيان بالاموال والانفس ههنا { وَكَانَ ٱللَّهُ غَفُوراً رَّحِيماً } يعنى انّ شيمته المغفرة والرّحمة فلا اختصاص لمغفرته ورحمته بالمجاهدين المستحقّين لهما بل تشملان القاعد الغير المستحّق وفيه تهييج واطماع للقاعدين.
