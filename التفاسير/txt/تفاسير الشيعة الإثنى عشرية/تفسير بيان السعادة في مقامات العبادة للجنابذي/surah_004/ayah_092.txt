{ وَمَا كَانَ لِمُؤْمِنٍ } ما صحّ وما لاق بحاله { أَن يَقْتُلَ مُؤْمِناً } بغير حقّ { إِلاَّ خَطَئاً } استثناء من لازمه اى فيعذّب على كلّ حال الاّ خطأ { وَمَن قَتَلَ مُؤْمِناً خَطَئاً }  { فَ } عليه { تَحْرِيرُ رَقَبَةٍ مُّؤْمِنَةٍ } كفّارة له { وَدِيَةٌ مُّسَلَّمَةٌ إِلَىٰ أَهْلِهِ } لئلاّ يهدر دم امرء مسلم { إِلاَّ أَن يَصَّدَّقُواْ } يتصدّقوا بالعفو فانّ التّصدّق يطلب على كلّ معروف { فَإِن كَانَ مِن قَوْمٍ عَدُوٍّ لَّكُمْ وَهُوَ مْؤْمِنٌ } من عطف التّفصيل على الاجمال { فَ } عليه { تَحْرِيرُ رَقَبَةٍ مُّؤْمِنَةٍ } من غير دية لعدم السّبيل للكافر على المسلم { وَإِن كَانَ مِن قَوْمٍ بَيْنَكُمْ وَبَيْنَهُمْ مِّيثَاقٌ }  { فَ } عليه { دِيَةٌ مُّسَلَّمَةٌ إِلَىۤ أَهْلِهِ } حفظاً للميثاق { وَتَحْرِيرُ رَقَبَةٍ مُّؤْمِنَةً } قدّم الدّية ههنا للاهتمام ببيانها فانّه يتراءى ان لايكون لهم كفّاراً عليه دية مسلّماً، واخّرها فى الآية السّابقة لانّها حقّ النّاس والتّحرير حقّ الله { فَمَن لَّمْ يَجِدْ } رقبة ولا ثمنها { فَصِيَامُ شَهْرَيْنِ مُتَتَابِعَيْنِ تَوْبَةً مِّنَ ٱللَّهِ } سبب توبة من الله { وَكَانَ ٱللَّهُ عَلِيماً } بوضع الاحكام { حَكِيماً } يضعها على غايات محكمة.
