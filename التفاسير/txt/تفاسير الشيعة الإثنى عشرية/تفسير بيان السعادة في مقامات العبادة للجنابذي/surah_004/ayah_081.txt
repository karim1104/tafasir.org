{ وَيَقُولُونَ } بألسنتهم شأننا { طَاعَةٌ } لك فى علىّ (ع) كأنّه قال لكنّهم يطيعون بألسنتهم ويتولّون بقلوبهم ويقولون بألسنتهم شأننا طاعة { فَإِذَا بَرَزُواْ مِنْ عِندِكَ بَيَّتَ طَآئِفَةٌ مِّنْهُمْ } ودبّروا ليلاً { غَيْرَ ٱلَّذِي تَقُولُ } انت فى علىٍّ (ع) او تلك الطّائفة من الطّاعة لك فى علىّ (ع) فيقولون ويتعاقدون على ان يمنعوا عليّاً (ع) من الخلافة { وَٱللَّهُ يَكْتُبُ مَا يُبَيِّتُونَ } تسلية للرّسول (ص) وتهديد لهم { فَأَعْرِضْ عَنْهُمْ } ولا تؤاخذهم فانّه اصلح لك لعدم افتتان سائر امّتك { وَتَوَكَّلْ } فى جملة امورك خصوصاً فيما تهتّم به من خلافة علىّ (ع) { عَلَى ٱللَّهِ وَكَفَىٰ بِٱللَّهِ وَكِيلاً } فانّه لا حاجة له الى معاون فى امضاء امرٍ ولا الى مشاور فى استعلام امر.
