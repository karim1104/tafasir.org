{ وَمَآ أَرْسَلْنَا مِن رَّسُولٍ أِلاَّ لِيُطَاعَ بِإِذْنِ ٱللَّهِ } عطف على قوله: اذا قيل لهم، وتنبيه على غاية شقاوتهم فى الآباء عن الرّجوع اليه (ص) { وَلَوْ أَنَّهُمْ إِذ ظَّلَمُوۤاْ أَنْفُسَهُمْ } بالمعاهدة على معاندة علىّ (ع) والاتّفاق على غصب حقّه تابوا وندموا و { جَآءُوكَ } يعنى جاؤا عليّاً (ع) تعريضاً او لانّه مظهره { فَٱسْتَغْفَرُواْ ٱللَّهَ } مخلصين عند علىّ (ع) { وَٱسْتَغْفَرَ لَهُمُ ٱلرَّسُولُ } اى نفس الرّسول (ص) وهو علىّ (ع) { لَوَجَدُواْ ٱللَّهَ تَوَّاباً رَّحِيماً } فانّه جعل عليّاً (ع) بابه ومظهر رحمته فمن تاب عنده فاز بتوبة الله ورحمته.
