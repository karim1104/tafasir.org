{ إِلاَّ ٱلَّذِينَ تَابُواْ } من نفاقهم { وَأَصْلَحُواْ } ما افسدوا بنفاقهم بنصرة الرّسالة والرّسول او مظهره { وَٱعْتَصَمُواْ بِٱللَّهِ } اى بمظهره الّذى هو شيخ الارشاد وهو علىّ (ع) { وَأَخْلَصُواْ دِينَهُمْ للَّهِ } الدّين هو الولاية، واخلاصها بان لا تكون باشراك ولاية من ليس لها باهلٍ وبان لا تكون مشوبة بالاغراض الكاسدة { فَأُوْلَـٰئِكَ مَعَ ٱلْمُؤْمِنِينَ } لانّهم بتوبتهم على يد علىّ (ع) واعتصامهم ببيعتهم الخاصّة الولويّة صاروا مؤمنين بعد نفاقهم وطهروا عن دنسه بالتّوبة ولذلك قبلهم علىّ (ع) { وَسَوْفَ يُؤْتِ ٱللَّهُ ٱلْمُؤْمِنِينَ أَجْراً عَظِيماً } فيساهمونهم.
