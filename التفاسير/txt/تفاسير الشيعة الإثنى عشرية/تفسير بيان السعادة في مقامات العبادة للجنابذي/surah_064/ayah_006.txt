{ ذَلِكَ بِأَنَّهُ كَانَت تَّأْتِيهِمْ رُسُلُهُم بِٱلْبَيِّنَاتِ } كما جاءكم رسولكم بالبيّنات { فَقَالُوۤاْ أَبَشَرٌ يَهْدُونَنَا } مثل ما تقولون لو شاء الله ان يرسل رسولا لأنزل ملائكة { فَكَفَرُواْ } بالرّسل مثلكم { وَتَوَلَّواْ } عنهم وعن بيّناتهم وعن التّدبّر فيها { وَّٱسْتَغْنَىٰ ٱللَّهُ } عنهم يعنى استغنى الله فى مظاهر رسلهم (ع) بمعنى استغنى الرّسل عنهم وعن الاعتداد بهم فلم يكن من قبلهم استعداد لقبول الايمان ولم يكن من قبل الرّسل دعوةٌ لهم { وَٱللَّهُ غَنِيٌّ } عنهم وعن عبادتهم وعن ايمانهم { حَمِيدٌ } فى نفسه عرف ام لم يعرف، حمد ام لم يحمد.
