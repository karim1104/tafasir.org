{ يٰزَكَرِيَّآ } جواب سؤال مقدّر بتقدير القول كأنّه قيل: ما قال فى جوابه؟- فقال: قال الله: يا زكريّا { إِنَّا نُبَشِّرُكَ بِغُلاَمٍ } ولدٍ ذكرٍ { ٱسْمُهُ يَحْيَىٰ } الجملة صفة للغلام او جواب سؤالٍ مقدّرٍ { لَمْ نَجْعَل لَّهُ مِن قَبْلُ سَمِيّاً } هذه صفة بعد صفة او حال او جواب لسؤالٍ مقدّرٍ والمراد بالسّمىّ المشارك فى الاسم، او المماثل فى الوصف و الحال.
