{ وَهُزِّىۤ إِلَيْكِ بِجِذْعِ ٱلنَّخْلَةِ } هزّه وبه حرّكه { تُسَاقِطْ } قرئ بضمّ التّاء الفوقانيّة وتخفيف السّين وكسر القاف، وقرئ يساقط بفتح الياء التّحتانيّة وتشديد السّين وبفتحها وتخفيف السّين وبفتح التّاء الفوقانيّة وتشديد السّين { عَلَيْكِ رُطَباً جَنِيّاً فَكُلِي وَٱشْرَبِي } من الرّطب والماء، او كلى ممّا يتغذّى به واشربى ممّا يشرب فى هذا المكان او مطلقاً { وَقَرِّي عَيْناً } بهذا الولد فانّه لا ينبغى ان تحزنى بسببه ولا تكترثى بما توهّمت من لوم الجهّال { فَإِمَّا تَرَيِنَّ } اى فان ترى { مِنَ ٱلبَشَرِ أَحَداً } فسألك عن ولدك { فَقُولِيۤ إِنِّي نَذَرْتُ لِلرَّحْمَـٰنِ صَوْماً } اى سكوتاً ولكونه بمعنى السّكوت فرّع عدم التّكلّم عليه، قيل: كان فى بنى اسرائيل انّه من اراد ان يجتهد فى العبادة صام عن الكلام كما يصوم عن الطّعام، ولذلك استعمل الصّوم فى عدم التّكلّم { فَلَنْ أُكَلِّمَ ٱلْيَوْمَ إِنسِيّاً } قيل: صارت مأذونة لهذا القدر من الكلام، وقيل: كانت تُفهم بالاشارة انّها صائمة ولا تتكلّم، قيل: لفّته فى خرقةٍ.
