{ إِلاَّ مَن تَابَ } عن اتّباع الشّهوات فى الافعال { وَآمَنَ } بالبيعة العامّة او الخاصّة، او اذعن انّ الاعمال لها جهة آلهيّة وجهة نفسانيّة { وَعَمِلَ صَالِحاً } طبق ما اخذ عليه فى بيعته او عمل صالحاً يعنى بالامر الآلهى حتّى يصير صالحاً، واقامة للصّلٰوة لا اضاعةً او اتّباعاً للشّهوات { فَأُوْلَـٰئِكَ يَدْخُلُونَ ٱلْجَنَّةَ } قرئ بضمّ الياء وفتح الخاء وبفتح الياء وضمّ الخاء { وَلاَ يُظْلَمُونَ شَيْئاً } بنقص شيءٍ من ثواب اعمالهم.
