{ فَإِنَّمَا يَسَّرْنَاهُ } الفاء عاطفة دالّة على شرافة الحكم الآتى والهاء للقرآن او قرآن ولاية علىّ (ع) او جعل الودّ الّذى هو ملكوت علىٍّ (ع) { بِلِسَانِكَ } بلغتك فانّ اللّسان يستعمل كثيراً فى اللّغة او على لسانك او فى لسانك { لِتُبَشِّرَ بِهِ ٱلْمُتَّقِينَ } الّذين اتّقوا بالولاية الطّرق المنحرفة النّفسانيّة { وَتُنْذِرَ بِهِ قَوْماً لُّدّاً } جمع الالدّ وهو الخصم الشّحيح الّذى لا يزيغ الى الحقّ.
