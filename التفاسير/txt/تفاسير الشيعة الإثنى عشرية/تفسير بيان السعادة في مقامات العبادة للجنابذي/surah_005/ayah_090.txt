{ يَـۤأَيُّهَا ٱلَّذِينَ آمَنُواْ إِنَّمَا ٱلْخَمْرُ وَٱلْمَيْسِرُ } كلّ ما تقومر به { وَٱلأَنصَابُ وَٱلأَزْلاَمُ } قد سبقا فى اوّل السّورة { رِجْسٌ } قذر تستكرهه العقول { مِّنْ عَمَلِ ٱلشَّيْطَانِ فَٱجْتَنِبُوهُ لَعَلَّكُمْ تُفْلِحُونَ } اكدّ الحرمة باداة الحصر، واطلاق الرّجس عليها وكونها من عمل الشّيطان والامر بالاجتناب فانّه يفيد التّأكيد بالنّسبة الى النّهى عن الفعل والمقصود ههنا النّهى عن الخمر والميسر، وقرنهما بالانصاب والازلام مبالغة فى حرمتها ولذلك لم يذكر فى بيان الغاية سواهما، وذكر غايتهما والمفسدة الّتى تترتّب عليها مبالغة اخرى فى حرمتها فقال { إِنَّمَا يُرِيدُ ٱلشَّيْطَانُ أَن يُوقِعَ بَيْنَكُمُ ٱلْعَدَاوَةَ وَٱلْبَغْضَآءَ فِي ٱلْخَمْرِ وَٱلْمَيْسِرِ }.
