{ قَالُوا يَامُوسَىٰ إِنَّ فِيهَا قَوْماً جَبَّارِينَ وَإِنَّا لَن نَّدْخُلَهَا حَتَّىٰ يَخْرُجُواْ مِنْهَا } لعدم طاقتنا لمقاومتهم { فَإِن يَخْرُجُواْ مِنْهَا فَإِنَّا دَاخِلُونَ قَالَ رَجُلاَنِ } يوشع بن نون وكالب بن يوفّنا ابنا عمّه وقيل: رجلان من اهل الشّام اسلما بموسى (ع) { مِنَ ٱلَّذِينَ يَخَافُونَ } يتّصفون بالخوف او يخافون سخط الله { أَنْعَمَ ٱللَّهُ عَلَيْهِمَا } معترضة او حال { ٱدْخُلُواْ عَلَيْهِمُ ٱلْبَابَ } يعنى باغتوهم حتّى لا يتمكّنوا من الاصحار او قوّوا قلوبكم ولا تنظروا الى عظم جثّتهم فانّهم اجسام خالية عن الجرأة { فَإِذَا دَخَلْتُمُوهُ فَإِنَّكُمْ غَالِبُونَ وَعَلَى ٱللَّهِ فَتَوَكَّلُوۤاْ إِن كُنتُم مُّؤْمِنِينَ } يعنى ان الايمان يقتضى التّوكّل عليه فهو شرط للتّهييج.
