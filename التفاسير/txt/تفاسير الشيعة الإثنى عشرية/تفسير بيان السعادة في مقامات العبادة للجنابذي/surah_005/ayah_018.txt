{ وَقَالَتِ ٱلْيَهُودُ وَٱلنَّصَارَىٰ نَحْنُ أَبْنَاءُ ٱللَّهِ وَأَحِبَّاؤُهُ } بيان لحال الفريقين ومقالتهم الفضيحة، ووجه هذا الادّعاء انّهم قالوا من اقرّ به تعالى وتقرّب لديه فهو ابنه الرّوحانّى وقيل: مقصودهم من هذا انّهم اشياع ابنيه المسيح (ع) وعزير (ع) وهو بعيد { قُلْ } ردّاً لهم { فَلِمَ يُعَذِّبُكُم بِذُنُوبِكُم } فى الدّنيا بالمغلوبيّة وفى الآخرة بالنّار دائماً او ايّاماً قلائل على زعمكم { بَلْ أَنتُمْ بَشَرٌ مِمَّنْ خَلَقَ يَغْفِرُ لِمَن يَشَآءُ } منكم { وَيُعَذِّبُ مَن يَشَآءُ } منكم على حسب اختلاف استعدادكم { وَللَّهِ مُلْكُ ٱلسَّمَاوَاتِ وَٱلأَرْضِ وَمَا بَيْنَهُمَا } بيان لتسويتهم مع غيرهم فى النّسبة اليه، وتكراره ههنا وفى غير هذا الموضع لتمكينه فى قلب السّامع ولأنّ كلاً يقتضيه المقام المخصوص { وَإِلَيْهِ ٱلْمَصِيرُ } بيان لمساواتهم مع غيرهم فى الانتهاء اليه.
