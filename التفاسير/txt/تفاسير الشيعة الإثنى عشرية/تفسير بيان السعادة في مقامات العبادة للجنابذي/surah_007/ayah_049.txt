{ أَهَـۤؤُلاۤءِ } اشارة الى اصحابهم الّّذين معهم فى الاعراف الّذين يطمعون دخول الجنّة ولم يدخلوها بعد لاختلاطهم السّيّئات بالحسنات { ٱلَّذِينَ أَقْسَمْتُمْ } فى الدّنيا { لاَ يَنَالُهُمُ ٱللَّهُ بِرَحْمَةٍ } قالوها تقريعاً وشماتةً ثمّ صرفوا الخطاب عن اصحاب النّار الى اصحابهم الّذين معهم فى الاعراف وقالوا لهم فى حال شهود اصحاب النّار لازدياد تحسّرهم { ٱدْخُلُواْ ٱلْجَنَّةَ لاَ خَوْفٌ عَلَيْكُمْ وَلاَ أَنتُمْ تَحْزَنُونَ } وبما ذكرنا يمكن الجمع بين جميع ما ورد فى الاخبار فى بيان الاعراف واصحاب الاعراف وكيفيّة وقوفهم على الاعراف مع كثرتها واختلافها.
