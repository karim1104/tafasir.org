{ وَقَاسَمَهُمَآ } كأنّهما لم يعتمدا على قوله وطلبا منه البيّنة والقسم وعهدا قبول قوله ولذا أتى بلفظ قاسم { إِنِّي لَكُمَا لَمِنَ ٱلنَّاصِحِينَ فَدَلاَّهُمَا } اى اهبطهما مع تعلّقٍ منهما بمقامها العلوىّ { بِغُرُورٍ } بمعنى المصدر او بمعنى ما يغرّ به من القسم الكذب وغيره { فَلَمَّا ذَاقَا ٱلشَّجَرَةَ بَدَتْ لَهُمَا سَوْءَاتُهُمَا وَطَفِقَا يَخْصِفَانِ عَلَيْهِمَا مِن وَرَقِ ٱلْجَنَّةِ } قد مضى البيان { وَنَادَاهُمَا رَبُّهُمَآ أَلَمْ أَنْهَكُمَا عَن تِلْكُمَا ٱلشَّجَرَةِ وَأَقُل لَّكُمَآ إِنَّ ٱلشَّيْطَآنَ لَكُمَا عَدُوٌ مُّبِينٌ } تقريع وتوبيخ لهما على ارتكاب النّهى والاغترار بقول العدوّ حتّى يتنبّها على نقصهما ويستدركاه بالتّوبة ولذلك ابتدرا بالاعتراف والاستغفار.
