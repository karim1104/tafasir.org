{ قَالَ مُوسَىٰ لِقَوْمِهِ } تسليةً لهم ووعداً { ٱسْتَعِينُوا بِٱللَّهِ } بالتّضرّع عليه والالتجاء اليه { وَٱصْبِرُوۤاْ } على يسير اذاه { إِنَّ ٱلأَرْضَ للَّهِ } فى موضع التّعليل { يُورِثُهَا مَن يَشَآءُ مِنْ عِبَادِهِ } لا لفرعون وقومه حتّى يفعلوا فيها ما يشاؤن فالتجؤا اليه واسئلوا منه وخافوا منه لا من غيره { وَٱلْعَاقِبَةُ } الحسنى الّتى هى الآخرة ودار الكرامة { لِلْمُتَّقِينَ } الجزع عند الشّدائد، وعد وتذكير لما وعدهم من اهلاك القبط وتسليطهم على مصر فى الدّنيا ومن الجنان فى الآخرة.
