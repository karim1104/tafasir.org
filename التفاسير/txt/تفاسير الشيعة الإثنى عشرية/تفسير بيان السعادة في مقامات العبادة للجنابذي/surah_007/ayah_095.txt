{ ثُمَّ بَدَّلْنَا مَكَانَ ٱلسَّيِّئَةِ ٱلْحَسَنَةَ } يعنى عادتنا الابتلاء تارة بالسّيّئات وتارة بالحسنات ليتمّ حجّتنا ودعوتنا ولم نجعلهم مسلوبى الاختيار فى قبول الدّعوة فانّه فى اجبارهم لا يحصل المطلوب من امتياز السّعيد عن الشّقىّ وعمارة الدّارين { حَتَّىٰ عَفَوْاْ } محوا عن قلوبهم آثار البأساء والضّرّاء والمهما او محوا تضرّعهم والتجاءهم وازادوا فى المال والاولاد او زادوا فى العلم فبطروا { وَّقَالُواْ } حالاً او قالاً { قَدْ مَسَّ آبَاءَنَا ٱلضَّرَّآءُ وَٱلسَّرَّآءُ } يعنى انّ الضّرّاء والسرّاء من عادة الدّهر قالوا ذلك للتلّويح بانّه لا ينبغى ترك التّمتّع ولا الالتجاء والتّضرّع { فَأَخَذْنَاهُمْ بَغْتَةً } من غير تقديم امارات { وَهُمْ لاَ يَشْعُرُونَ } لعدم تقدّم الامارات.
