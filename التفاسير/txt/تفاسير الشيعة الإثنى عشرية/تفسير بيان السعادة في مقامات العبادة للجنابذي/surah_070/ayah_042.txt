{ فَذَرْهُمْ يَخُوضُواْ } فى اباطيلهم { وَيَلْعَبُواْ حَتَّىٰ يُلاَقُواْ يَوْمَهُمُ ٱلَّذِي يُوعَدُونَ يَوْمَ يَخْرُجُونَ مِنَ ٱلأَجْدَاثِ } اى القبور { سِرَاعاً } مسرعين { كَأَنَّهُمْ إِلَىٰ نُصُبٍ } النّصب بالفتح والسّكون وقرئ به وبالتّحريك العلم المنصوب، وبالضّمّتين كلّما جعل علماً وكلّما عبد من دون الله وقرئ به، والنّصب بالضّمّ والسّكون كلّما عبد من دون الله { يُوفِضُونَ } اى يسرعون، قال القمّىّ: الى الدّاعى يبادرون.
