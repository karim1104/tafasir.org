{ إِذْ يُرِيكَهُمُ ٱللَّهُ فِي مَنَامِكَ قَلِيلاً } لتخبر اصحابك بقلّتهم ليجترؤا على القتال وهو متعلّق بمتعلّق ليقضى او بدل من، اذ انتم بالعدوة الدّنيا او بدل ثانٍ من يوم الفرقان او متعلّق بعليم { وَلَوْ أَرَاكَهُمْ كَثِيراً } فاخبرت اصحابك { لَّفَشِلْتُمْ } جبنتم { وَلَتَنَازَعْتُمْ فِي ٱلأَمْرِ } امر القتال لانحراف آراء اكثركم عن القتال { وَلَـٰكِنَّ ٱللَّهَ سَلَّمَ } نفوسكم عن الفشل والتّنازع { إِنَّهُ عَلِيمٌ بِذَاتِ ٱلصُّدُورِ } بالخفيّات الّتى تصاحب الصّدور فيدبّر امركم عن علم بما لا تعلمون، نقل انّ المخاطبة للرّسول (ص) والمعنى لاصحابه يعنى أرى اصحابه المشركين قليلاً فى منامهم، وعن الباقر (ع): كان ابليس يوم بدرٍ يقلّل المسلمين فى اعين الكفّار ويكثّر الكفّار فى اعين النّاس فشدّ عليه جبرئيل (ع) بالسّيف فهرب منه.
