{ وَقَاتِلُوهُمْ حَتَّىٰ لاَ تَكُونَ فِتْنَةٌ } فساد من الشّرك ولوازمه { وَيَكُونَ الدِّينُ كُلُّهُ لله } ولا يكون لكلٍّ دين او اديانٌ وكان بعضه للشّيطان كالاديان الباطلة وبعضه لله كدينك، هذا فى الصّغير ظاهر، وامّا فى الكبير فقد ورد انّه لم يجئ تأويل هذه الآية بعد انّ رسول الله (ص) رخّص لهم لحاجته وحاجة اصحابه فلو قد جاء تأويلها لم يقبل منهم ولكنّهم يقتلون حتّى يوحّدوا الله وحتّى لا يكون شرك { فَإِنِ انْتَهَوْاْ } عن الكفر { فَإِنَّ اللَّهَ بِمَا يَعْمَلُونَ } من الانتهاء والاسلام { بَصِيرٌ } فيجازيهم على حسبه.
