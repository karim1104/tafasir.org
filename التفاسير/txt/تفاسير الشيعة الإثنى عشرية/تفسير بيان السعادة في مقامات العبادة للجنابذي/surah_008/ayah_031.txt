{ وَإِذَا تُتْلَىٰ عَلَيْهِمْ آيَاتُنَا } عطف على يمكرون { قَالُواْ قَدْ سَمِعْنَا } استهزاءً { لَوْ نَشَآءُ لَقُلْنَا مِثْلَ هَـٰذَا } قيل قائله النّضر بن الحارث بن كلدة الّذى قتل يوم بدرٍ بعد اسره على يد علىّ (ع) { إِنْ هَـٰذَآ إِلاَّ أَسَاطِيرُ ٱلأَوَّلِينَ } اسمار الاوّلين فانّه يكنّى بالاساطير عنها.
