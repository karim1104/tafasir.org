{ وَٱلَّذِينَ آمَنُواْ مِن بَعْدُ } يعنى من ايمانكم وهجرتكم { وَهَاجَرُواْ وَجَاهَدُواْ مَعَكُمْ فَأُوْلَـٰئِكَ مِنكُمْ } ويجب موالاتهم كموالاتكم { وَأْوْلُواْ ٱلأَرْحَامِ بَعْضُهُمْ أَوْلَىٰ بِبَعْضٍ فِي كِتَابِ ٱللَّهِ } فى مكتوبةٍ فى اللّوح وهو نسخ للتّوارث بالهجرة والنّصرة { إِنَّ ٱللَّهَ بِكُلِّ شَيْءٍ عَلِيمٌ } فيحكم تارةً بالتّوارث بالهجرة وتارةً بالرّحم لمصلحةٍ يعلمها ويأمركم بموالاة انفسكم وترك موالاة الكفّار ايضاً لمصلحة.
