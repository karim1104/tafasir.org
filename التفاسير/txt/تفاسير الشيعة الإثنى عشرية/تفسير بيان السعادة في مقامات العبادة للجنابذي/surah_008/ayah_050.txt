{ وَلَوْ تَرَىٰ إِذْ يَتَوَفَّى ٱلَّذِينَ كَفَرُواْ } لو للتمنّى لأنّه كثيراً ما يستعمل ليت فى امثال تلك القضايا ولا مانع من جعل لو بمعناها مع انّه غنىّ عن تقدير الجواب ولو جعل لو للشّرط فالجواب محذوف اى لرأيت امراً فظيعاً والخطاب لمحمّد (ص) او عامّ والمراد توفّيهم يوم بدرٍ او عامّ { ٱلْمَلاۤئِكَةُ يَضْرِبُونَ وُجُوهَهُمْ وَأَدْبَارَهُمْ } يعمّ الضّرب جميع اطرافهم او المراد الوجوه والاستاه كما فى الخبر لانّ الله حيى ويكنّى { وَ } يقولون { ذُوقُواْ عَذَابَ ٱلْحَرِيقِ } او يقول الله: ذوقوا عذاب الحريق فى الدّنيا او فى الآخرة.
