{ فَإِمَّا تَثْقَفَنَّهُمْ فِي ٱلْحَرْبِ } ان كان المراد منافقى الامّة فجريان الامر على يد علىّ (ع) { فَشَرِّدْ بِهِم } بقلتهم والنّكاية فيهم { مَّنْ خَلْفَهُمْ } من سائر الكفّار بان يتسامعوا بشّدة بأسك بقتل المقاتلين فلا يطمعوا فى مقاتلتك وهو امر بشدّة نكايتهم على ابلغ وجهٍ { لَعَلَّهُمْ } اى من خلف المقاتلين { يَذَّكَّرُونَ } صدق نبوتّك وشدّة بأسك.
