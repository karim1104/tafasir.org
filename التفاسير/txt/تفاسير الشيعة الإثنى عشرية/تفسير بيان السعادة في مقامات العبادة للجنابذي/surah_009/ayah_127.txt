{ وَإِذَا مَآ أُنزِلَتْ سُورَةٌ نَّظَرَ بَعْضُهُمْ إِلَىٰ بَعْضٍ } ذمّ آخر يعنى اشاروا بأنظارهم استهزاءً او غيظاً لما يرون فيها من عيوبهم قائلين { هَلْ يَرَاكُمْ مِّنْ أَحَدٍ } يعنى ان قمتم وصرفتم من هذا المجلس { ثُمَّ ٱنصَرَفُواْ } قاموا من مجلس محمّد (ص) وانصرفوا عنه غيظاً { صَرَفَ ٱللَّهُ قُلُوبَهُم } استينافٌ، دعاءٌ عليهم او خبار عن حالهم { بِأَنَّهُمْ قَوْمٌ لاَّ يَفْقَهُون } لا يدركون ادراكاً يوصلهم الى طريق الآخرة ويستعقب ادراكاً آخر من امر الآخرة.
