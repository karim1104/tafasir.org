{ إِلاَّ تَنفِرُواْ يُعَذِّبْكُمْ عَذَاباً أَلِيماً وَيَسْتَبْدِلْ قَوْماً غَيْرَكُمْ } بعد اهلاككم تهديد ووعيد بعد توبيخٍ وتقريعٍ { وَلاَ تَضُرُّوهُ شَيْئاً } بهلاككم او بتقاعدكم او بمكركم وهو اظهار للغنى عنهم وعدم الحاجة اليهم، والضّمير المفعول امّا لله او للرّسول (ص) بقرينة المقام ولتوافق ضمير ان لا تنصروه { وَٱللَّهُ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ } يقدر على نصرة رسوله بدون امدادكم وعلى اهلاككم واستبدالكم قوماً غيركم.
