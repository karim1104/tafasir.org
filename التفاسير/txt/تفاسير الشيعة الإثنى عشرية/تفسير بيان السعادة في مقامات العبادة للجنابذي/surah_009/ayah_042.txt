{ لَوْ كَانَ عَرَضاً قَرِيباً } غنيمةً قريبة الوصول { وَسَفَراً قَاصِداً } متوسّطاً غير بعيدٍ { لاَّتَّبَعُوكَ } بيان لسبب تخلّفهم وتثبّطهم وانّ المانع لهم والباعث على العذر الكاذب هو بعد السّفر وكثرة المشقّة { وَلَـٰكِن بَعُدَتْ عَلَيْهِمُ ٱلشُّقَّةُ } الشّقة بالضّمّ وبالكسر النّاحية يقصدها المسافر والسّفر البعيدة والمشقّة وتعدية بعدت بعلى لتضمينه معنى ثقلت { وَسَيَحْلِفُونَ بِٱللَّهِ } بعد رجوعكم اليهم { لَوِ ٱسْتَطَعْنَا لَخَرَجْنَا مَعَكُمْ } يعنى ما كان لنا استطاعة للخروج فلم نخرج، اخبر نبيّه (ص) انّهم سيعتذرون بعدم الاستطاعة كذباً وهو اخبار عن المستقبل { يُهْلِكُونَ أَنْفُسَهُمْ } استيناف جواباً لسؤالٍ مقدّر اى ما لهم فى هذا العذر والمقصود؛ انّهم بعد التّخلّف ان اعترفوا بتقصيرهم وتابوا أحيوا أنفسهم لبقاء استعداد الحياة لكنّهم بالعذر الكاذب أبطلوا استعدادهم للحياة وأهلكوا انفسهم من صورة الحياة بالتّخلّف، ومن استعدادها بعدم التّوبة والعذر الكاذب { وَٱللَّهُ يَعْلَمُ إِنَّهُمْ لَكَاذِبُونَ } بالغ فى تأكيد تكذيبهم بانّ واسميّة الجملة والّلام مبدّواً بعلم الله الّذى هو بمنزلة القسم.
