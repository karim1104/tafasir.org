{ ٱلَّذِينَ قَالُوۤاْ } صفة للّذين { قالوا انّ الله فقير } او بدل منه ويجوز ان يكون مقطوعاً مستأنفاً للذّمّ خبر مبتدأ محذوف، او مفعول فعل محذوف، او مبتدأ خبر محذوف { إِنَّ ٱللَّهَ عَهِدَ إِلَيْنَا } اى فى التّوراة لانّ القائلين القول الاوّل كانوا من اليهود كما سلف او على لسان نبيّه (ص) وخلفاء نبيّه (ص) وخلفاء نبيّه { أَلاَّ نُؤْمِنَ لِرَسُولٍ حَتَّىٰ يَأْتِيَنَا بِقُرْبَانٍ تَأْكُلُهُ ٱلنَّارُ } يعنى عهد الينا ان لا نؤمن الاّ برسولٍ يأتى بهذه المعجزة الّتى كانت لانبياء بنى اسرائيل وهى ان يقرب (ع) بقربان فيقوم النّبىّ (ع) فيدعو فيأتى نار من السّماء فتحيل القربان الى طبعها بالاحراق { قُلْ } لهم { قَدْ جَآءَكُمْ } اى اسلافكم الّذين كنتم اسناخاً لهم { رُسُلٌ مِّن قَبْلِي بِٱلْبَيِّنَاتِ } والمعجزات الكثيرة غير ما قلتم { وَبِٱلَّذِي قُلْتُمْ فَلِمَ قَتَلْتُمُوهُمْ إِن كُنتُمْ صَادِقِينَ } فى هذه الدّعوى.
