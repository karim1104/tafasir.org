{ قُلْ } يا محمّد (ص) { يٰأَهْلَ ٱلْكِتَابِ لِمَ تَكْفُرُونَ بِآيَاتِ ٱللَّهِ } التّدوينيّة من آيات القرآن والتّوراة والانجيل والتّكوينيّة والاحكام الالهيّة الثّابتة فى الشّرائع الثّلاث { وَٱللَّهُ شَهِيدٌ } حاضر او حافظ { عَلَى مَا تَعْمَلُونَ } فيجازيكم على كفركم بالآيات ولا ينفعكم التّحريف والإسرار.
