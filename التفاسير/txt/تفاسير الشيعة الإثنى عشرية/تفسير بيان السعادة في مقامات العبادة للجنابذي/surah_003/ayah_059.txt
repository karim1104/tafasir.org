{ إِنَّ مَثَلَ عِيسَىٰ عِندَ ٱللَّهِ كَمَثَلِ آدَمَ } فلا غرو فى خلقه بلا ابٍ لانّ آدم (ع) خلق بلا ابٍ وامّ وهم يقرّون به مع انّه اغرب { خَلَقَهُ مِن تُرَابٍ } مستأنف جواب لسؤالٍ مقدّرٍ او حال بتقدير قد وبيان لوجه الشّبه يعنى خلق عيسى (ع) من الروح مثل خلق آدم من التّراب، ونكّر التّراب للاشعار بأنّه كان تراباً خاصّاً لا يمكن تعريفه { ثُمَّ قَالَ لَهُ } اى لآدم والاتيان بثمّ للتفاوت بين الاخبارين فانّ التّفصيل مرتبة بعد الاجمال او المعنى قدّر خلقه من تراب ثمّ قال له { كُن } او صوّر صورته من تراب ثمّ قال له كن بشراً تامّاً { فَيَكُونُ } وقد مرّ هذه الكلمة وبيانها عند قوله [البقرة:117] من سورة البقرة.
