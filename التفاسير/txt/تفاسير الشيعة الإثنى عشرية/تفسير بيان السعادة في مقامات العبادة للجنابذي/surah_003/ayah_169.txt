{ وَلاَ تَحْسَبَنَّ } عطف على (قل) او على { فادرأوا } ، او الخطاب لمحمّد (ص) او لكلّ من يتأتّى منه الخطاب، وقرئ بالياء على اسناده الى الرّسول (ص) او الى من يتأتّى منه الحسبان، او الى الظّاهر بعده اى لا يحسبنّ { ٱلَّذِينَ قُتِلُواْ فِي سَبِيلِ ٱللَّهِ } انفسهم { أَمْوَاتاً } بحذف المفعول الاوّل وهذا ردّ على المنافقين حيث قالوا: { لو كانوا عندنا ما ماتوا }  { ولو اطاعونا ما قتلوا }  { بَلْ } هم { أَحْيَاءٌ } حياة اتمّ واكمل واشرف واعلى من هذه الحياة الدّانية { عِندَ رَبِّهِمْ يُرْزَقُونَ } بالرّزق المناسب لمقامهم عند الرّبّ.
