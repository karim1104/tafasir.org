{ إِنَّ ٱلَّذِينَ ٱشْتَرَوُاْ ٱلْكُفْرَ بِٱلإِيمَانِ } تأكيدٌ للاوّل او تعليل له وتعميم للحكم لجميع الكفّار بعد تخصيصه بالقاعدين المنافقين { لَن يَضُرُّواْ ٱللَّهَ شَيْئاً وَلهُمْ عَذَابٌ أَلِيمٌ وَلاَ يَحْسَبَنَّ ٱلَّذِينَ كَفَرُواْ } قرئ { تحسبنّ } بالخطاب وبالغيبة { أَنَّمَا نُمْلِي } انّ الّذى نملى او انّ الاملاء { لَهُمْ خَيْرٌ لأَنْفُسِهِمْ } لهم متعلّق بنملى وانّما نملى مفعول ثان ليحسبنّ او بدل من المفعول الاوّل مغنٍ عن المفعول الثّانى وعلى كون الّذين كفروا فاعلاً فهو قائم مقام المفعولين والاملاء الامهال او اطاعة العمر { إِِنَّمَا نُمْلِي لَهُمْ لِيَزْدَادُوۤاْ إِثْمَاً } جواب لسؤال مقدّرٍ وما كافّة او مصدريّة او موصولة { وَلَهْمُ عَذَابٌ مُّهِينٌ } فى الدّنيا والآخرة من حين التّكلّم ولمّا كان المقام مقام السّخط والغضب ناسبه البسط والتّغليظ والتّكرير ولذلك كرّر نفى الضّرر وثبوت العذاب باوصافٍ مختلفة واتى فى الاوّل بوصف العظيم للعذاب للاشعار بانّ عذاب المنافق اشدّ واعظم من عذاب سائر الكفّار.
