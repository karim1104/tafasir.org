{ يٰأَيُّهَا ٱلنَّاسُ } ناداهم تلطّفاً بهم لتهييجهم للاستماع وصرف الخطاب عنه (ص) الى المكذّبين بعد تسليته ردعاً لهم عن تكذيبهم او الى مطلق العباد وعداً ووعيداً لهم { إِنَّ وَعْدَ ٱللَّهِ } بالثّواب والعقاب { حَقٌّ } لا خلف فيه { فَلاَ تَغُرَّنَّكُمُ ٱلْحَيَاةُ ٱلدُّنْيَا } فتغفلوا عن وعد الله ولا تعملوا له { وَلاَ يَغُرَّنَّكُمْ بِٱللَّهِ ٱلْغَرُورُ } اى الشّيطان بان يمنّيكم المغفرة ويؤخّركم التّوبة.
