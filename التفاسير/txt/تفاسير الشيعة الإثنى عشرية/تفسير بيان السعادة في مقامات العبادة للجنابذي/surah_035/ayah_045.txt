{ وَلَوْ يُؤَاخِذُ ٱللَّهُ } كأنّه توهّم متوهّم انّ الله ان كان عالماً بهم وقديراً على مؤاخذتهم فلم لا يؤاخذهم؟! فعطف قوله ولو يؤاخذ الله { ٱلنَّاسَ بِمَا كَسَبُواْ } رفعاً لذلك التّوهّم { مَا تَرَكَ عَلَىٰ ظَهْرِهَا } اى ظهر الارض { مِن دَآبَّةٍ } بشؤم اعمال بنى آدم ومؤاخذة دوابّ الارض بمؤاخذتهم { وَلَـٰكِن يُؤَخِّرُهُمْ إِلَىٰ أَجَلٍ مُّسَمًّى فَإِذَا جَآءَ أَجَلُهُمْ فَإِنَّ ٱللَّهَ كَانَ بِعِبَادِهِ بَصِيراً } فيجازى كلاًّ باعماله ولا يفوت احدٌ منه.
