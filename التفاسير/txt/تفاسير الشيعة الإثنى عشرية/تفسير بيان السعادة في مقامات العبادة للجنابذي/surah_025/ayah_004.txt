{ وَقَالَ ٱلَّذِينَ كَفَرُوۤاْ } بالله انكاراً لرسالة رسوله (ص) وكتابه { إِنْ هَـٰذَا إِلاَّ إِفْكٌ ٱفْتَرَاهُ وَأَعَانَهُ عَلَيْهِ قَوْمٌ آخَرُونَ } يعنى لمّا عجزوا عن معارضته ورأوا حسن نظمه أنكروه وقالوا: كان هذا بمعاونة معاونين له { فَقَدْ جَآءُوا } اى منكروا الرّسالة او منكروا الله والرّسالة جميعاً { ظُلْماً } حيث انكروا ما حقّه الاقرار وعبدوا ما حقّه الجحود والانكار { وَزُوراً } اى رأياً وقولاً منحرفاً عن الصّواب.
