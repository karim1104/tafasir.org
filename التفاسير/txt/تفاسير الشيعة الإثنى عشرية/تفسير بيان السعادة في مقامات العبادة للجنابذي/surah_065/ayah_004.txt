{ وَٱللاَّئِي يَئِسْنَ مِنَ ٱلْمَحِيضِ مِن نِّسَآئِكُمْ } بانقطاع الحيض عنهنّ لمرضٍ او حملٍ او لكبرٍ لكن لم يبلغ كبرهنّ الى خمسين او ستّين، او كان بلوغهنّ مشكوكاً فيه، وامّا اللاّئى يئسن من المحيض بسبب البلوغ الى الخمسين او السّتّين فلا يصبرن بعد التّفريق ثلاثة اشهر ولا يعتددن من الطّلاق اصلاً ولذلك قال { إِنِ ٱرْتَبْتُمْ } فى كبرهنّ وبلوغهنّ الى سنّ من لا تحيض { فَعِدَّتُهُنَّ ثَلاَثَةُ أَشْهُرٍ وَٱللاَّتِي لَمْ يَحِضْنَ } بعد ولكنّهنّ بلغن سنّ من تحيض فعدتهنّ ثلاثة اشهرٍ مثل من قطع حيضهنّ ولم يبلغن خمسين او ستّين { وَأُوْلاَتُ ٱلأَحْمَالِ أَجَلُهُنَّ } اى مدّة عدّتهنّ او آخر عدّتهنّ { أَن يَضَعْنَ حَمْلَهُنَّ } وبيان الطّلاق وكيفيّته واقسامه مذكورة فى الكتب الفقهيّة { وَمَن يَتَّقِ ٱللَّهَ } فى امر النّساء، او فى احكام الطّلاق، او فى الرّفق بهنّ وعدم الاقدام على الطّلاق، او فى مطلق احكام الله { يَجْعَل لَّهُ مِنْ أَمْرِهِ يُسْراً } فى الدّنيا او فى الدّنيا والآخرة.
