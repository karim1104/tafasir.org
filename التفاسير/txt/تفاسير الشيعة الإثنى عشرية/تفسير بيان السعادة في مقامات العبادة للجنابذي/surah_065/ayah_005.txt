{ ذَلِكَ } المذكور من امر النّساء او من امر الطّلاق والعدّة { أَمْرُ ٱللَّهِ } اى حكمه { أَنزَلَهُ إِلَيْكُمْ وَمَن يَتَّقِ ٱللَّهَ } تأكيدٌ للسّابق واشارة الى غايةٍ اخرى، او الاوّل اشارة الى التّقوى فى امر النّساء، والثّانى الى التّقوى فى مطلق احكام الله { يُكَفِّرْ عَنْهُ سَيِّئَاتِهِ } الّتى وقعت منه قبل التّقوى او بالخطاء { وَيُعْظِمْ لَهُ أَجْراً } فى الآخرة.
