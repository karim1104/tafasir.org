{ أَلَمْ تَرَ إِلَى ٱلَّذِينَ تَوَلَّوْاْ قَوْماً غَضِبَ ٱللَّهُ عَلَيْهِم } قيل المراد منهم قوم من المنافقين كانوا يوالون اليهود ويفشون اليهم اسرار المؤمنين ويجتمعون معهم على ذكر مساءة النّبىّ (ص) والمؤمنين { مَّا هُم مِّنكُمْ } لعدم ايمانهم باطناً { وَلاَ مِنْهُمْ } لاقرارهم اللّسانىّ بالاسلام { وَيَحْلِفُونَ عَلَى ٱلْكَذِبِ } اى على عدم مجالستهم لهؤلاء القوم، او عدم استماعهم الى ازدراء المؤمنين، او على قصد تقوية الدّين والكلّ كذب منهم { وَهُمْ يَعْلَمُونَ } انّهم يحلفون على الكذب.
