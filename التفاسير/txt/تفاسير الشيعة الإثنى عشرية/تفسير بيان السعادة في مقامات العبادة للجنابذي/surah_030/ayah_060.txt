{ فَٱصْبِرْ } يا محمّد (ص) على انكارهم ونسبتك الى الابطال، او فاصبر على انكارهم لخلافة خليفتك { إِنَّ وَعْدَ ٱللَّهِ } بنصرتك واظهار دينك على الاديان او بنصرة خليفتك واحقاق حقّه { حَقٌّ } لا يتغيّر { وَلاَ يَسْتَخِفَّنَّكَ ٱلَّذِينَ لاَ يُوقِنُونَ } اى لا يحملنّك على الجهل ولا يصرفنّك عمّا انت عليه من الحقّ.
