{ ٱللَّهُ ٱلَّذِي يُرْسِلُ ٱلرِّيَاحَ } جملة مستأنفة فى مقام التّعليل { فَتُثِيرُ سَحَاباً فَيَبْسُطُهُ } الله { فِي ٱلسَّمَآءِ كَيْفَ يَشَآءُ } سائراً وواقفاً، سريعاً وبطيئاً، غليظاً ورقيقاً، ذا مطر وثلجٍ وبردٍ وخالياً عن ذلك { وَيَجْعَلُهُ كِسَفاً } قطعاً متراكمة بعد بسطه او يبسطه تارةً ويجعله كسفاً اخرى { فَتَرَى ٱلْوَدْقَ } اى المطر { يَخْرُجُ مِنْ خِلاَلِهِ فَإِذَآ أَصَابَ بِهِ مَن يَشَآءُ مِنْ عِبَادِهِ } يعنى بلادهم { إِذَا هُمْ يَسْتَبْشِرُونَ } بمجيء الخصب.
