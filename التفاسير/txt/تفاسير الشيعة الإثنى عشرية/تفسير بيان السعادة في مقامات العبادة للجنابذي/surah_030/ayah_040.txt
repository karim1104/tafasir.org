{ ٱللَّهُ ٱلَّذِي خَلَقَكُمْ } جملة منقطعة عن سابقها { ثُمَّ رَزَقَكُمْ } فما لكم تبخلون { ثُمَّ يُمِيتُكُمْ } فما لكم تجمعون وتدّخرون { ثُمَّ يُحْيِيكُمْ } فما لكم لا تدّخرون لحيٰوتكم الباقية بالاعطاء من الفانيات والارباء عند الله { هَلْ مِن شُرَكَآئِكُمْ مَّن يَفْعَلُ مِن ذَلِكُمْ مِّن شَيْءٍ } الزام لهم على الاقرار بعجز الشّركاء وابطال شراكتهم { سُبْحَانَهُ وَتَعَالَىٰ عَمَّا يُشْرِكُونَ } قرئ بالغيبة والخطاب.
