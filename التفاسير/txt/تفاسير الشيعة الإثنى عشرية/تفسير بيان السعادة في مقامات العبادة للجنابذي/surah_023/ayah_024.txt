{ فَقَالَ ٱلْمَلأُ ٱلَّذِينَ كَفَرُواْ مِن قَوْمِهِ } يعنى قال الرّؤساء للاتباع { مَا هَـٰذَا إِلاَّ بَشَرٌ مِّثْلُكُمْ } يعنى لا فرق بينه وبينكم حتّى يكون مستحقّاً للتّفضّل عليكم ويستحقّ الرّسالة دونكم { يُرِيدُ أَن يَتَفَضَّلَ عَلَيْكُمْ } فيجعلكم اتباعاً لنفسه { وَلَوْ شَآءَ ٱللَّهُ } ان يرسل علينا رسولاً { لأَنزَلَ مَلاَئِكَةً } للرّسالة { مَّا سَمِعْنَا بِهَـٰذَا } اى بارسال رسول من البشر بما يدعوننا اليه من التّوحيد { فِيۤ آبَآئِنَا ٱلأَوَّلِينَ } حتّى لا نستغرب منه ولا ننكره.
