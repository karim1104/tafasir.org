{ وَمَن يَدْعُ } جملة حاليّة او معطوفة على لا اله الاّ هو { مَعَ ٱللَّهِ } الّذى لا اله الاّ هو { إِلَـهَا آخَرَ } من الاصنام والكواكب والظّلمة واهريمن او من يدع مع علىّ (ع) اماماً آخر { لاَ بُرْهَانَ لَهُ بِهِ } لانّ من يدعو الهاً له على آلهته برهان كمن يدعو الانبياء والاولياء (ع) لظهور برهان صدقهم فى ادّعائهم فهو موحّد لا مشرك ومثاب لا معاقب ولكنّ الّذى يدعو الهاً او اماماً لا برهان له على صدقه { فَإِنَّمَا حِسَابُهُ عِندَ رَبِّهِ } كناية عن شدّة العقاب وسوء الحساب { إِنَّهُ لاَ يُفْلِحُ ٱلْكَافِرُونَ } جواب لسؤالٍ عن العلّة كأنّه قال: فانّه كافر ولا يفلح الكافرون.
