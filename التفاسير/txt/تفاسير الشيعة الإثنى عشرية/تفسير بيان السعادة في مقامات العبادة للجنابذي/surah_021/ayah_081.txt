{ وَ } سخّرنا { لِسُلَيْمَانَ ٱلرِّيحَ عَاصِفَةً } شديدة الهبوب بحيث كان غدوّها شهراً ورواحها شهراً مع انّها كانت رخاءً وتحريكها كان فى لينٍ { تَجْرِي بِأَمْرِهِ } بامر سليمان { إِلَى ٱلأَرْضِ ٱلَّتِي بَارَكْنَا فِيهَا } اى الشّام، قيل: كان سليمان يسير من الشّام بكرة واليه رواحاً { وَكُنَّا بِكُلِّ شَيْءٍ عَالِمِينَ } فكان اعطاؤنا ما نعطى لمن نعطى وامساكنا ما نمسك ممّن نمسك عن علمٍ بالاعطاء والامساك والمصالح المترتّبة عليهما.
