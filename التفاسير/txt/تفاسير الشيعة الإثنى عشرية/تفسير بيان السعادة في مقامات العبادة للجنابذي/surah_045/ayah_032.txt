{ وَإِذَا قِيلَ إِنَّ وعْدَ ٱللَّهِ } بالعذاب والثّواب { حَقٌّ وَٱلسَّاعَةُ لاَ رَيْبَ فِيهَا قُلْتُم مَّا نَدْرِي مَا ٱلسَّاعَةُ إِن نَّظُنُّ إِلاَّ ظَنّاً وَمَا نَحْنُ بِمُسْتَيْقِنِينَ وَبَدَا لَهُمْ } التفاتٌ من الخطاب الى الغيبة { سَيِّئَاتُ مَا عَمِلُواْ } حيث رأوا مقام ولىّ امرهم وخساسة اوليائهم الظّلمة { وَحَاقَ بِهِم مَّا كَانُواْ بِهِ يَسْتَهْزِئُونَ } اى القول او العذاب الّذى كانوا به يستهزؤن.
