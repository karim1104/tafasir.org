{ فَأَمَّا ٱلَّذِينَ آمَنُواْ } بالبيعة العامّة او الخاصّة { وَعَمِلُواْ ٱلصَّالِحَاتِ } واصلها البيعة الخاصّة الولويّة { فَيُدْخِلُهُمْ رَبُّهُمْ فِي رَحْمَتِهِ } الّتى هى الولاية { ذَلِكَ } الدّخول فى الولاية { هُوَ ٱلْفَوْزُ ٱلْمُبِينُ وَأَمَّا ٱلَّذِينَ كَفَرُوۤاْ أَفَلَمْ تَكُنْ } اى يقال لهم احملتم فلم تكن { آيَاتِي تُتْلَىٰ عَلَيْكُمْ فَٱسْتَكْبَرْتُمْ } عن الانقياد لها واتّباعها حتّى استكبرتم عن الآيات العظمى والولاية الكبرى { وَكُنتُمْ قَوْماً مُّجْرِمِينَ } بسبب مخالفتكم لولىّ امركم.
