{ قَالُواْ } اى الاتباع للمتبوعين او بنو العبّاس لبنى اميّة { بَلْ أَنتُمْ لاَ مَرْحَباً بِكُمْ } لاقدامكم اوّلاً على ما ادخلنا فى النّار وكونكم فى ذلك قدوة لنا { أَنتُمْ قَدَّمْتُمُوهُ } اى هذا العذاب او الدّخول فى النّار او هذا الدّعاء { لَنَا } باقدامكم اوّلاً وبجعلنا اتباعكم { فَبِئْسَ ٱلْقَرَارُ } جهنّم.
