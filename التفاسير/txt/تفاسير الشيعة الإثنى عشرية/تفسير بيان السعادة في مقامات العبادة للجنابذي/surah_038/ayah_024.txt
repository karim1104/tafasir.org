{ قَالَ لَقَدْ ظَلَمَكَ بِسُؤَالِ نَعْجَتِكَ إِلَىٰ نِعَاجِهِ وَإِنَّ كَثِيراً مِّنَ ٱلْخُلَطَآءِ لَيَبْغِيۤ بَعْضُهُمْ عَلَىٰ بَعْضٍ إِلاَّ ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ وَقَلِيلٌ مَّا هُمْ } ما زائدة او وصفيّة لتأكيد التّقليل { وَظَنَّ دَاوُودُ } بعدما تبادر فى الحكم بالظّلم { أَنَّمَا فَتَنَّاهُ } امتحنّاه بذلك { فَٱسْتَغْفَرَ رَبَّهُ } من تبادره فى الحكم { وَخَرَّ رَاكِعاً } خاضعاً { وَأَنَابَ } رجع الى الله بالاعتذار.
