{ وَإِنَّهُمْ عِندَنَا لَمِنَ ٱلْمُصْطَفَيْنَ ٱلأَخْيَارِ وَٱذْكُرْ إِسْمَاعِيلَ } بن ابراهيم { وَٱلْيَسَعَ } قد مضى فى سورة الانعام { وَذَا ٱلْكِفْلِ } قد مضى فى سورة الانبياء { وَكُلٌّ مِّنَ ٱلأَخْيَارِ هَـٰذَا } المذكور من الانبياء واحوالهم { ذِكْرٌ } وعبرة لمن اراد الآخرة { وَإِنَّ لِلْمُتَّقِينَ لَحُسْنَ مَآبٍ } سواء كانوا نبيّاً او لم يكونوا.
