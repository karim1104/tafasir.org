{ كِلْتَا ٱلْجَنَّتَيْنِ آتَتْ } افراد الضّمير بلحاظ لفظ كلتا { أُكُلَهَا } مأكولها من الثّمار والتّمر والحبوب { وَلَمْ تَظْلِمِ مِّنْهُ شَيْئاً } لم تنقص من الاكل شيئاً بالآفة او بتغيير بحسب الاعوام كسائر البساتين فانّها كثيراً تثمر كما ينبغى فى عامٍ وينقص ثمرها فى عامٍ آخر { وَفَجَّرْنَا خِلالَهُمَا نَهَراً } ليدوم شربهما ولا يتعب فى سقيهما ويزيد بهاءهما.
