{ فَلَمَّا جَاوَزَا } الموضع عييا وكان موسى (ع) لم يعى فى سفرٍ قطّ او فى هذا السّفر الاّ فى هذا السّير حين جاوزا مجمع البحرين و { قَالَ لِفَتَاهُ آتِنَا غَدَآءَنَا } الغداء ما يتغذّى به فى الصّباح { لَقَدْ لَقِينَا مِن سَفَرِنَا هَـٰذَا } فى ابدال اسم الاشارة اشعارٌ بانّه لم يعى قبل ذلك فى سفرٍ { نَصَباً } عياءً.
