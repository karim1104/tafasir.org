{ وَمَا يَأْتِيهِم مِّن رَّسُولٍ إِلاَّ كَانُواْ بِهِ يَسْتَهْزِئُونَ كَذَلِكَ } الادخال على سبيل الاستهزاء او كذلك الاستهزاء { نَسْلُكُهُ } ندخل الذّكر او الاستهزاء { فِي قُلُوبِ ٱلْمُجْرِمِينَ لاَ يُؤْمِنُونَ بِهِ } حال عن المجرمين او عن مفعول نسلكه، او مستأنفة جواب لسؤالٍ مقدّرٍٍ، او مفسّره للجملة السّابقة { وَقَدْ خَلَتْ سُنَّةُ ٱلأَوَّلِينَ } اى سنّة الله فى الاوّلين او طريقتهم المستعقبة للعذاب فى الدّنيا والآخرة.
