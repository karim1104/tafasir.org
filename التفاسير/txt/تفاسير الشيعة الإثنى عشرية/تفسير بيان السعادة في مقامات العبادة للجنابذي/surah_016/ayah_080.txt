{ وَٱللَّهُ جَعَلَ لَكُمْ مِّن بُيُوتِكُمْ سَكَناً وَجَعَلَ لَكُمْ مِّن جُلُودِ ٱلأَنْعَامِ بُيُوتاً } يعنى الاخبية المتّخذة من الاديم والشّعر والصّوف { تَسْتَخِفُّونَهَا } تعدّونها خفيفةً لا كبيوت الطّين والاحجار { يَوْمَ ظَعْنِكُمْ وَيَوْمَ إِقَامَتِكُمْ وَمِنْ أَصْوَافِهَا وَأَوْبَارِهَا وَأَشْعَارِهَآ أَثَاثاً } لبيوتكم من الفرش والالبسة ومحالّ الامتعة وغير ذلك { وَمَتَاعاً إِلَىٰ حِينٍ } ما تتمتّعون به الى مدّة اندراسه.
