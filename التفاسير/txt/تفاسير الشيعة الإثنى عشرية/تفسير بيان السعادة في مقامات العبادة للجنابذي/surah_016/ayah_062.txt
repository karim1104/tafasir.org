{ وَيَجْعَلُونَ لِلَّهِ مَا يَكْرَهُونَ } من البنات والشّركاء من الرّياسة واراذل الاموال { وَتَصِفُ أَلْسِنَتُهُمُ ٱلْكَذِبَ } ان قرئ برفع الكذب فهو صفة لالسنتهم كما انّه قرئ الكذب بضمّتين مرفوعاً وجمعاً للكذوب وصفة لالسنتهم، وان قرئ بنصب الكذب كما هو المشهور فهو مفعول تصف وعلى الاوّل فقوله { أَنَّ لَهُمُ ٱلْحُسْنَىٰ } مفعول تصف وعلى الثّانى فهو بدل من الكذب وقد قالوا لئن رجعت الى ربّى انّ لى عنده للحسنى، ويجوز ان يكون ان لهم الحسنى بتقدير اللاّم تعليلاً لتصف على الوجهين والمعنى لانّ لهم الحسنى فى الدّنيا { لاَ جَرَمَ أَنَّ لَهُمُ ٱلْنَّارَ } لاكسب جرمٍ فى ذلك اثبات لضدّ ما ادّعوا لانفسهم { وَأَنَّهُمْ مُّفْرَطُونَ } فيما ادّعوا لانفسهم او فى اعمالهم.
