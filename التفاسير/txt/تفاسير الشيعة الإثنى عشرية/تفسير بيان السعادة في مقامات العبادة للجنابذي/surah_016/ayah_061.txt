{ وَلَوْ يُؤَاخِذُ ٱللَّهُ ٱلنَّاسَ بِظُلْمِهِمْ } ومنه تسمية الملائكة اناثاً ونسبة الولد الى الله او التّمثيل له بمثل غير لائقٍ بشأنه { مَّا تَرَكَ عَلَيْهَا } على الارض { مِن دَآبَّةٍ } لانّ ظلمهم قد سرى الى البهم من الدّوابّ وبجزائهم يهلك الدّوابّ ايضاً { وَلٰكِن يُؤَخِّرُهُمْ إلَىٰ أَجَلٍ مُّسَمًّىٰ } ليبلغوا ما بلغوا من الشّقاوة ويتوب من يتوب ويسعد من يسعد { فَإِذَا جَآءَ أَجَلُهُمْ لاَ يَسْتَأْخِرُونَ سَاعَةً وَلاَ يَسْتَقْدِمُونَ } قد مضى انّ المعنى اذا قدّر مجيء اجلهم حتّى لا يستشكل بيستقدمون.
