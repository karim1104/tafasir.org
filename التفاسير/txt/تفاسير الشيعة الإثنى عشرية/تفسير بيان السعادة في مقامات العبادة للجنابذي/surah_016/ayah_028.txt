{ ٱلَّذِينَ تَتَوَفَّاهُمُ ٱلْمَلائِكَةُ } خبر مبتدءٍ محذوفٍ او مفعول فعلٍ محذوفٍ او صفة للكافرين { ظَالِمِي أَنْفُسِهِمْ } ظالمين فى حقّهم او فى حقّ امامهم فانّه بمنزلة انفسهم بل اولى بهم منهم { فَأَلْقَوُاْ ٱلسَّلَمَ } اى الاستسلام والانقياد او القول بالاستسلام او القول بالاستسلام والانقياد { مَا كُنَّا نَعْمَلُ مِن سُوۤءٍ } تفسير للسّلم على الّذين انكروا مافعلوا من الجحود والانكار والاستهزاء فى الدّنيا { بَلَىٰ } ردّ من الملائكة او من الله اى قالوا او قال بلى { إِنَّ ٱللَّهَ عَلِيمٌ بِمَا كُنْتُمْ تَعْمَلُونَ } فلا ينفعكم انكاره الآن.
