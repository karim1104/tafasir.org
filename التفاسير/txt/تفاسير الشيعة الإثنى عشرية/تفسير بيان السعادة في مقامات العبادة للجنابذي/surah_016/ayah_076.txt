{ وَضَرَبَ ٱللَّهُ مَثَلاً } للشّركاء ولنفسه او للكافر والمؤمن او لعلىّ (ع) ولاعدائه ومخالفيه { رَّجُلَيْنِ أَحَدُهُمَآ أَبْكَمُ } ولد اخرس لا ينطق ولا يفهم نطق غيره { لاَ يَقْدِرُ عَلَىٰ شَيْءٍ } من النّطق وسائر الافعال كمن كان جميع حواسّه وجميع قواه المحرّكة معطّلة { وَهُوَ كَلٌّ } ثقل { عَلَىٰ مَوْلاهُ أَيْنَمَا يُوَجِّههُّ لاَ يَأْتِ بِخَيْرٍ هَلْ يَسْتَوِي هُوَ وَمَن يَأْمُرُ بِٱلْعَدْلِ } يعنى من كان متّصفاً بالعدل فى جميع احواله واقواله وافعاله ويعرف العدل فى جميع موارده ويأمر غيره بالعدل لأنّ الامر بالعدل يسلتزم الاتّصاف به ومعرفته فى جميع موارده، وللاشارة الى هذا قال { وَهُوَ عَلَىٰ صِرَاطٍ مُّسْتَقِيمٍ } اى على التّوسّط بين طرفى الافراط والتّفريط فى جميع ما ذكر.
