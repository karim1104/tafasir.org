{ وَٱللَّهُ خَلَقَكُمْ ثُمَّ يَتَوَفَّاكُمْ } بآجالكم { وَمِنكُم مَّن يُرَدُّ إِلَىٰ أَرْذَلِ ٱلْعُمُرِ } وهو وقت الهرم، وفى الخبر: اذا بلغ العبد مائة سنة فذلك ارذل العمر، وفى خبر آخر: ان يكون عقله مثل عقل ابن سبع سنين { لِكَيْ لاَ يَعْلَمَ بَعْدَ عِلْمٍ شَيْئاً } لا يعلم ما علمه قبل ذلك، وفى الخبر: انّ هذا ينقص منه جميع الارواح وينقص روح الايمان وليس يضرّه شيئاً { إِنَّ ٱللَّهَ عَلِيمٌ } بما ينبغى وانّ الموت قبل ارذل العمر خير لكم ولذلك لا يصل اكثركم الى ارذل العمر { قَدِيرٌ } على الايصال الى ارذل العمر.
