{ هَلْ يَنْظُرُونَ } ينتظرون اى الّذين لا يؤمنون بالآخرة { إِلاَّ أَن تَأْتِيَهُمُ ٱلْمَلائِكَةُ } حين الموت { أَوْ يَأْتِيَ أَمْرُ رَبِّكَ } بالعذاب او بخروج القائم (ع) { كَذَلِكَ فَعَلَ ٱلَّذِينَ مِن قَبْلِهِمْ وَمَا ظَلَمَهُمُ ٱللَّهُ } بتدميرهم وعذابهم { وَلـٰكِن كَانُواْ أَنْفُسَهُمْ يَظْلِمُونَ فَأَصَابَهُمْ سَيِّئَاتُ مَا عَمِلُواْ وَحَاقَ بِهِم مَّا كَانُواْ بِهِ يَسْتَهْزِئُونَ } من العذاب او المعاد او الرّجعة او مطلق ما قاله رسلهم.
