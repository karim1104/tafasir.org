{ يَوْمَ تَأْتِي كُلُّ نَفْسٍ } ظرف لغفور او رحيم او كليهما على سبيل التّنازع، او ظرف لرحيم لانّ المغفرة تكون قبل الوصول الى القيامة، او مستأنف مقدّر باذكر { تُجَادِلُ عَن نَّفْسِهَا } عن ذاتها بالاعتذار فى الخلاص عن البوار وطلب مقام الابرار { وَتُوَفَّىٰ كُلُّ نَفْسٍ } عين { مَّا عَمِلَتْ } على تجسّم الاعمال او جزاء ما عملت { وَهُمْ لاَ يُظْلَمُونَ } بنقص الثّواب او زيادة العذاب.
