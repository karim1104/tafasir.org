{ وَقُلْ } بعد مسئلتك السّلطان النّصير واجابتنا لك ونزول الولاية الكلّيّة المعبّر عنها بعد النّزول بالسّكينة تبجّحاً بما اعطيناك { جَآءَ ٱلْحَقُّ } فانّ الولاية المطلقة هى الحقّ وبحقّيّتها حقّيّة كلّ ذى حقٍّ { وَزَهَقَ ٱلْبَاطِلُ } فانّ الباطل يزهق ويضمحلّ بمجيء الحقّ فى العالم الصّغير وفى العالم الكبير { إِنَّ ٱلْبَاطِلَ كَانَ زَهُوقاً } لكن بدون مجيء الحقّ يترائى حقّيّة له وبعد مجيء الحقّ يظهر انّه كان باطلاً ولم يكن له حقيقة وحقّيّة.
