{ وَقُلْنَا مِن بَعْدِهِ لِبَنِي إِسْرَائِيلَ ٱسْكُنُواْ ٱلأَرْضَ } الّتى اراد فرعون ان يستفزّكم منها { فَإِذَا جَآءَ وَعْدُ ٱلآخِرَةِ } وعد دار الآخرة { جِئْنَا بِكُمْ } يعنى بنى اسرائيل وقوم فرعون او الخطاب لبنى اسرائيل فقط { لَفِيفاً } مختلطين، المحقّين والمبطلين من بنى اسارئيل وقوم فرعون، او دانى الدّرجة ومرتفعيها.
