{ قُلْ } فى جوابهم لا تستعجلوا هذا الفتح فانّ { يَوْمَ ٱلْفَتْحِ لاَ يَنفَعُ ٱلَّذِينَ كَفَرُوۤاْ إِيَمَانُهُمْ } فانّه يوم بروز المكسوبات لا يوم كسب الخيرات { وَلاَ هُمْ يُنظَرُونَ فَأَعْرِضْ عَنْهُمْ } اى عن الجواب والسّؤال معهم، او عن دعوتهم، او عن ذواتهم فانّهم لا يتأثّرون بمجاورتك { وَٱنتَظِرْ } يوم الفتح { إِنَّهُمْ مُّنتَظِرُونَ } لذلك اليوم.
