{ فَتَبَسَّمَ ضَاحِكاً مِّن قَوْلِهَا } لتعجّبه من قدرة الله واسماعه قول النّمل خصوصاً من المسافة البعيدة، او من نعمة الله عليه بان اقدره على سماع كلام النّمل وفهم مقصده، او من فطانة النّمل وتميزه بين الحاطم وغيره ومعرفته لسليمان وجنوده، وهذا يدلّ على انّه وجنوده كانوا يمشون مشاة وراكبين لا انّهم يسيرون فى الهواء بمركب الرّيح { وَقَالَ } تبجّحاً بنعم الله واظهاراً لشكرها { رَبِّ أَوْزِعْنِيۤ } الهمنى او اولعنى { أَنْ أَشْكُرَ نِعْمَتَكَ ٱلَّتِيۤ أَنْعَمْتَ عَلَيَّ } اشارة الى هذه النّعمة اى نعمة افهام نطق الحيوان او جنس النّعمة الّتى انعمها عليه { وَعَلَىٰ وَالِدَيَّ } باعطائهما ولداً مثلى او لسائر نعمهم { وَأَنْ أَعْمَلَ صَالِحاً تَرْضَاهُ } ليكون عملى شكراً فعليّاً لانعمك { وَأَدْخِلْنِي بِرَحْمَتِكَ فِي عِبَادِكَ ٱلصَّالِحِينَ } فى الدّنيا او فى الآخرة او فيهما.
