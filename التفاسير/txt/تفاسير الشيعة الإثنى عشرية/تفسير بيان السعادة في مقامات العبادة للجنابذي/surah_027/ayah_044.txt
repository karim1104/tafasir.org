{ قِيلَ لَهَا ٱدْخُلِي ٱلصَّرْحَ } الصّرح هو الموضع المنبسط من غير سقفٍ، وقيل: انّه قصر من زجاجٍ، وقيل: كلّ بناءٍ من زجاجٍ او صخرٍ او غير ذلك موثّق فهو صرح، قيل: لمّا اقبلت بلقيس امر سليمان (ع) الشّياطين ببناء الصّرح من قوارير واجرى تحته الماء وجمع فى الماء الحيتان والضّفادع ودوابّ البحر ثمّ وضع له فيه سرير فجلس عليه { فَلَمَّا رَأَتْهُ حَسِبَتْهُ لُجَّةً } قيل قالت: ما وجد ابن داود (ع) عذاباً يقتلنى به الاّ الغرق وانِفَت ان تجبن فلا تدخل { وَكَشَفَتْ عَن سَاقَيْهَا } فلمّا رآها سليمان (ع) وكان عليهما شعور كرهتها سليمان فاستشار الجنّ فى ذلك فعملوا الحمّامات وطبخوا النّورة وكان اوّل ما صنعت النّورة { قَالَ } لها سليمان (ع): ليس ههنا ماء { إِنَّهُ صَرْحٌ مُّمَرَّدٌ } مملّس { مِّن قَوارِيرَ قَالَتْ } بعد ما علمت انّها اساءت الظّنّ بنبىّ الله (ع) { رَبِّ إِنِّي ظَلَمْتُ نَفْسِي } بالظّنّ السّوء بنبيّك { وَأَسْلَمْتُ مَعَ سُلَيْمَانَ لِلَّهِ رَبِّ ٱلْعَالَمِينَ } وللاشارة الى ضعفها وعدم استقلالها باسلامها قال: اسلمت مع سليمان (ع) واختلف فى امرها؛ فقيل: انّه تزوّجها سليمان واقرّها على ملكها، وقيل: انّه زوّجها من ملك يقال له تتّبع وردّها الى ارضها، وامر اميراً من امراء الجنّ باليمن ان يطيعه ويعمل له، فصنع له المصانع باليمن.
