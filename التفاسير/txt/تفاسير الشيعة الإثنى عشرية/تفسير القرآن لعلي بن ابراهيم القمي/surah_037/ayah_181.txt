قوله: { فإذا نزل بساحتهم فساء صباح المنذرين }  يعني العذاب إذا نزل ببني أمية وأشياعهم في آخر الزمان وقوله: { وتول عنهم حتى حين وأبصر فسوف يبصرون } [178-179] فذلك إذا أتاهم العذاب أبصروا حين لا ينفعهم النظر فهذه في أهل الشبهات والضلالات من أهل القبلة.  وقال علي بن إبراهيم في قوله: { فإذا نزل بساحتهم } أي بمكانهم { فساء صباح المنذرين } إلى قوله { والحمد لله رب العالمين } .
