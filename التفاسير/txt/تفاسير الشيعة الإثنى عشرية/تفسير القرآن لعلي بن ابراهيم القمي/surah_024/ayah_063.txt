قوله: { لا تجعلوا دعاء الرسول بينكم كدعاء بعضكم بعضاً } قال: لا تدعوا رسول الله كما يدعو بعضكم بعضاً ثم قال: { فليحذر الذين يخالفون عن أمره أن تصيبهم فتنة } يعني بلية { أو يصيبهم عذاب أليم } قال: القتل، وفي رواية أبي الجارود عن أبي جعفر عليه السلام في قوله: { لا تجعلوا دعاء الرسول بينكم كدعاء بعضكم بعضاً } يقول لا تقولوا يا محمد ولا يا أبا القاسم لكن قولوا يا نبي الله ويا رسول الله قال الله: { فليحذر الذين يخالفون عن أمره } أي يعصون أمره { أن تصيبهم فتنة أو يصيبهم عذاب أليم }.
