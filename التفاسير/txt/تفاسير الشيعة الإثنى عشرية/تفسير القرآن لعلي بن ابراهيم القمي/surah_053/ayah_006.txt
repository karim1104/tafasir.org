{ ذو مرة فاستوى }  يعني: رسول الله صلى الله عليه وآله، قال: وحدثني ياسر عن أبي الحسن الرضا عليه السلام قال: ما بعث الله نبياً إلا صاحب مرة سوداء صافية.  وقوله: { وهو بالأفق الأعلى }  يعني: رسول الله صلى الله عليه وآله.  { ثم دنا }  يعني رسول الله صلى الله عليه وآله من ربه عز وجل { فتدلى } قال: إنما نزلت هذه ثم دنا فتدانى { فكان قاب قوسين أو أدنى }  قال: كان من الله كما بين مقبض القوس إلى رأس السية { أو أدنى } أي: من نعمته ورحمته قال بل أدنى من ذلك.  فقال { ذو مرة فاستوى وهو بالأفق الأعلى. ثم دنا فتدلى } (فتدانى ط) { فكان قاب قوسين أو أدنى } كان بين لفظه وبين سماع محمد كما بين وتر القوس وعودها.
