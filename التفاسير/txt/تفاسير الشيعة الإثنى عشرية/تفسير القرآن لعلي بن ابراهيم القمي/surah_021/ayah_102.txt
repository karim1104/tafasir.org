قوله: { إن الذين سبقت لهم منا الحسنى أولئك عنها مبعدون لا يسمعون حسيسها وهم في ما اشتهت أنفسهم خالدون } [101-102] وقوله { حصب جهنم } يقول يقذفون فيها قذفاً وقوله: { أولئك عنها مبعدون } يعني الملائكة وعيسى ابن مريم عليه السلام, وقال علي بن إبراهيم: { إن الذين سبقت لهم منا الحسنى } ناسخة لقوله: { وإن منكم إلا واردها }.
