قوله: { يا أيها الذين آمنوا لا تحلوا شعائر الله ولا الشهر الحرام ولا الهدي ولا القلائد ولا آمين البيت الحرام } فالشعائر الإِحرام، والطواف والصلاة في مقام إبراهيم، والسعي بين الصفا والمروة، ومناسك الحج كلها من شعائر الله، ومن الشعائر إذا ساق الرجل بدنة في الحج ثم أشعرها أي قطع سنامها أو جللها أو قلدها ليعلم الناس أنها هدي فلا تتعرض لها أحد، وإنما سميت الشعائر لتشعر الناس بها فيعرفونها، وقوله: { ولا الشهر الحرام } وهو ذو الحجة وهو من الأشهر الحرام، وقوله: { ولا الهدي } وهو الذي يسوقه إذا أحرم { ولا القلائد } قال: يقلدها النعل الذي قد صلى فيه وقوله: { ولا آمين البيت الحرام } قال: الذين يحجون البيت الحرام وقوله: { وإذا حللتم فاصطادوا } فأحل لهم الصيد بعد تحريمه اذا أحلوا، وقوله: { ولا يجرمنكم شنآن قوم أن صدوكم عن المسجد الحرام أن تعتدوا } أي لا يحملنكم عداوة قريش إن صدوك عن المسجد الحرام في غزوة حديبية أن تعتدوا عليهم وتظلموهم ثم نسخت هذه الآية بقوله: { فاقتلوا المشركين حيث وجدتموهم }.
