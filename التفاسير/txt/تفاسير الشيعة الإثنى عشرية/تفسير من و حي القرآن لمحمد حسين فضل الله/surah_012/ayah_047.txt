{  دَأَبًا } :  العادة ،  والمراد به هنا :  الدوام على الزرع .

{  قَالَ تَزْرَعُونَ سَبْعُ سِنِينَ دَأَبًا } بدون انقطاعٍ {  فَمَا حَصَدتُّمْ } منه {  فَذَرُوهُ فِي سُنبُلِهِ } واحفظوه بطبيعته لئلا يتلف ويهلك ،  ولا تتصرفوا فيه {  إِلاَّ قَلِيلاً مِّمَّا تَأْكُلُونَ } مما تحتاجونه في الغذاء بكل اقتصاد ،
