قوله تعالى:  { الۤـمۤ * تَنزِيلُ ٱلْكِتَابِ لاَ رَيْبَ فِيهِ } - إلى قوله تعالى- { لَعَلَّهُمْ يَهْتَدُونَ } [1- 3] 8458/ - علي بن إبراهيم: { الۤـمۤ * تَنزِيلُ ٱلْكِتَابِ لاَ رَيْبَ فِيهِ } أي لا شك فيه { مِن رَّبِّ ٱلْعَالَمِينَ * أَمْ يَقُولُونَ ٱفْتَرَاهُ } ، يعني قريشا، يقولون: هذا كذب محمد، فرد الله عليهم، فقال: { بَلْ هُوَ ٱلْحَقُّ مِن رَّبِّكَ لِتُنذِرَ قَوْماً مَّآ أَتَاهُم مِّن نَّذِيرٍ مِّن قَبْلِكَ لَعَلَّهُمْ يَهْتَدُونَ }.
