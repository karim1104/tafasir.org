قوله تعالى:  { ٱلَّذِيۤ أَحْسَنَ كُلَّ شَيْءٍ خَلَقَهُ } - إلى قوله تعالى- { ثُمَّ سَوَّاهُ } [7- 9] 8462/ - علي بن إبراهيم: قوله: { ٱلَّذِيۤ أَحْسَنَ كُلَّ شَيْءٍ خَلَقَهُ وَبَدَأَ خَلْقَ ٱلإِنْسَانِ مِن طِينٍ } ، قال: هو آدم (عليه السلام) { ثُمَّ جَعَلَ نَسْلَهُ } أي ولده { مِن سُلاَلَةٍ } ، و هي الصفوة من الطعام و الشراب { مِّن مَّآءٍ مَّهِينٍ } قال: النطفة المني { ثُمَّ سَوَّاهُ } أي استحاله من نطفة إلى علقة، و من علقة إلى مضغة، حتى نفخ فيه الروح.
