قوله تعالى: { ثُلَّةٌ مِّنَ ٱلأَوَّلِينَ } - إلى قوله تعالى- { يَطُوفُ عَلَيْهِمْ وِلْدَانٌ مُّخَلَّدُونَ } [13-17]  10387/ - محمد بن العباس، قال: حدثنا محمد بن الحرير، عن أحمد بن يحيى، عن الحسن بن الحسين، عن محمد بن الفرات، عن جعفر بن محمد (عليه السلام)، في قوله تعالى: { ثُلَّةٌ مِّنَ ٱلأَوَّلِينَ * وَقَلِيلٌ مِّنَ ٱلآخِرِينَ } ، قال: { ثُلَّةٌ مِّنَ ٱلأَوَّلِينَ } ابن آدم الذي قتله أخوه، و مؤمن آل فرعون، و حبيب النجار صاحب يس: { وَقَلِيلٌ مِّنَ ٱلآخِرِينَ } علي بن أبي طالب (عليه السلام)”.  10388/ - ابن الفارسي في (الروضة): قال الإمام الصادق (عليه السلام): { ثُلَّةٌ مِّنَ ٱلأَوَّلِينَ } ابن آدم المقتول، و مؤمن آل فرعون، و صاحب يس، { وَقَلِيلٌ مِّنَ ٱلآخِرِينَ } علي بن أبي طالب (عليه السلام)”.  10389/ - علي بن إبراهيم، في قوله تعالى: { ثُلَّةٌ مِّنَ ٱلأَوَّلِينَ } ، قال: هم أتباع الأنبياء { وَقَلِيلٌ مِّنَ ٱلآخِرِينَ } هم أتباع النبي محمد (صلى الله عليه و آله) { عَلَىٰ سُرُرٍ مَّوْضُونَةٍ } ، أي منصوبة { يَطُوفُ عَلَيْهِمْ وِلْدَانٌ مُّخَلَّدُونَ } ، أي مسرورون.  10390/ - الطبرسي، في معنى الولدان: عن علي (عليه السلام): “أنهم أولاد أهل الدنيا، لم يكن لهم حسنات فيثابوا عليها، و لا سيئات فيعاقبوا عليها، فانزلوا هذه المنزلة”.  10391/ - قال: و روي عن النبي (صلى الله عليه و آله) أنه سئل عن أطفال المشركين، فقال: “هم خدام أهل الجنة”.
