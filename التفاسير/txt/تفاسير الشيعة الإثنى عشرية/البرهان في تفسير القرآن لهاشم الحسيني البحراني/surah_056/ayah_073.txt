قوله تعالى: { أَفَرَأَيْتُمُ ٱلنَّارَ ٱلَّتِي تُورُونَ } - إلى قوله تعالى- { وَمَتَاعاً لِّلْمُقْوِينَ } [71- 73] 10433/ - علي بن إبراهيم، قوله تعالى: { أَفَرَأَيْتُمُ ٱلنَّارَ ٱلَّتِي تُورُونَ } أي تورونها و توقدنها و تنتفعون بها { أَأَنتُمْ أَنشَأْتُمْ شَجَرَتَهَآ أَمْ نَحْنُ ٱلْمُنشِئُونَ * نَحْنُ جَعَلْنَاهَا تَذْكِرَةً } لنار يوم القيامة { وَمَتَاعاً لِّلْمُقْوِينَ } ، قال: المحتاجين.
