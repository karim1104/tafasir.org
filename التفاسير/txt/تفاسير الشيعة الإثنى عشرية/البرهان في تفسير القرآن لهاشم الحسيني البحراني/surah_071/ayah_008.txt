قوله تعالى: { وَإِنِّي كُلَّمَا دَعَوْتُهُمْ لِتَغْفِرَ لَهُمْ } - إلى قوله تعالى - { وَأَسْرَرْتُ لَهُمْ إِسْرَاراً } [7- 9]  11101/ - علي بن إبراهيم، قوله تعالى: { وَإِنِّي كُلَّمَا دَعَوْتُهُمْ لِتَغْفِرَ لَهُمْ جَعَلُوۤاْ أَصَابِعَهُمْ فِيۤ آذَانِهِمْ وَٱسْتَغْشَوْاْ ثِيَابَهُمْ } ، قال: استتروا بها { وَأَصَرُّواْ وَٱسْتَكْبَرُواْ ٱسْتِكْبَاراً } أي عزموا على أن لا يسمعوا شيئا { ثُمَّ إِنِّيۤ أَعْلَنْتُ لَهُمْ وَأَسْرَرْتُ لَهُمْ إِسْرَاراً } ، قال: دعوتهم سرا وعلانية.
