قوله تعالى:  { كَذَلِكَ حَقّاً عَلَيْنَا نُنجِ ٱلْمُؤْمِنِينَ } - إلى قوله تعالى - { وَٱتَّبِعْ مَا يُوحَىٰ إِلَيْكَ وَٱصْبِرْ حَتَّىٰ يَحْكُمَ ٱللَّهُ وَهُوَ خَيْرُ ٱلْحَاكِمِينَ } [103- 109]  4994/ - العياشي: عن مصقلة الطحان، عن أبي عبد الله (عليه السلام) قال: " ما يمنعكم أن تشهدوا على من مات منكم على هذا الأمر أنه من أهل الجنة؟! إن الله يقول: { كَذَلِكَ حَقّاً عَلَيْنَا نُنجِ ٱلْمُؤْمِنِينَ } ".  4995/ - و قال علي بن إبراهيم: في قوله: { قُلْ } يا محمد { يٰأَيُّهَا ٱلنَّاسُ إِن كُنتُمْ فِي شَكٍّ مِّن دِينِي فَلاَ أَعْبُدُ ٱلَّذِينَ تَعْبُدُونَ مِن دُونِ ٱللَّهِ وَلَـٰكِنْ أَعْبُدُ ٱللَّهَ ٱلَّذِي يَتَوَفَّاكُمْ } فإنه محكم.  ثم قال: و قوله: { وَلاَ تَدْعُ مِن دُونِ ٱللَّهِ مَا لاَ يَنفَعُكَ وَلاَ يَضُرُّكَ فَإِن فَعَلْتَ فَإِنَّكَ إِذاً مِّنَ ٱلظَّالِمِينَ } فإنه مخاطبة للنبي (صلى الله عليه و آله) و المعني للناس. ثم قال: { قُلْ يٰأَيُّهَا ٱلنَّاسُ قَدْ جَآءَكُمُ ٱلْحَقُّ مِن رَّبِّكُمْ فَمَنِ ٱهْتَدَىٰ فَإِنَّمَا يَهْتَدِي لِنَفْسِهِ وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا وَمَآ أَنَاْ عَلَيْكُمْ بِوَكِيلٍ } أي لست بوكيل عليكم أحفظ أعمالكم، إنما علي أن أدعوكم. ثم قال: { وَٱتَّبِعْ } يا محمد { مَا يُوحَىٰ إِلَيْكَ وَٱصْبِرْ حَتَّىٰ يَحْكُمَ ٱللَّهُ وَهُوَ خَيْرُ ٱلْحَاكِمِينَ }.
