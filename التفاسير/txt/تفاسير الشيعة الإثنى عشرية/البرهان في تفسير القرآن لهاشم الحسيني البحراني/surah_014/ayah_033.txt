قوله تعالى:  { ٱللَّهُ ٱلَّذِي خَلَقَ ٱلسَّمَٰوَٰتِ وَٱلأَرْضَ وَأَنزَلَ مِنَ ٱلسَّمَآءِ مَآءً فَأَخْرَجَ بِهِ مِنَ ٱلثَّمَرَاتِ } - الى قوله تعالى - { وَسَخَّر لَكُمُ ٱلشَّمْسَ وَٱلْقَمَرَ دَآئِبَينَ } [32- 33]  5755/ - علي بن ابراهيم: و قوله: { وَسَخَّر لَكُمُ ٱلشَّمْسَ وَٱلْقَمَرَ دَآئِبَينَ } اي علي الولاء.  و كيفية خلق السماوات و الأرض تقدم في أول سورة هود، في قوله تعالى: [هود: 7]. و قوله: { وَأَنزَلَ مِنَ ٱلسَّمَآءِ مَآءً } تقدم الحديث في أول سورة البقرة، في قوله تعالى [البقرة: 22]. وقوله { وَسَخَّر لَكُمُ ٱلشَّمْسَ وَٱلْقَمَرَ } تقدم حديثها في سورة يونس، في قوله تعالى: [يونس: 5].
