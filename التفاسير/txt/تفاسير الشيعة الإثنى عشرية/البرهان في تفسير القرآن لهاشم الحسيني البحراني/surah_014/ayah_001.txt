قوله تعالى:  { الۤر كِتَابٌ أَنزَلْنَاهُ إِلَيْكَ لِتُخْرِجَ ٱلنَّاسَ مِنَ ٱلظُّلُمَاتِ إِلَى ٱلنُّورِ } - الى قوله تعالى - { وَوَيْلٌ لِّلْكَافِرِينَ مِنْ عَذَابٍ شَدِيدٍ } [1- 2]  5669/ - قال علي بن ابراهيم: في قوله تعالى: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * الۤر كِتَابٌ أَنزَلْنَاهُ إِلَيْكَ } يا محمد { لِتُخْرِجَ ٱلنَّاسَ مِنَ ٱلظُّلُمَاتِ إِلَى ٱلنُّورِ بِإِذْنِ رَبِّهِمْ } يعني من الكفر الي الإيمان إِلى { صِرَاطِ ٱلْعَزِيزِ ٱلْحَمِيدِ } والصراط: الطريق الواضح، و امامة الأئمة (عليهم السلام).  ثم قال: وقوله: { ٱللَّهِ ٱلَّذِي لَهُ مَا فِي ٱلسَّمَٰوَٰتِ وَمَا فِي ٱلأَرْضِ وَوَيْلٌ لِّلْكَافِرِينَ مِنْ عَذَابٍ شَدِيدٍ } انه محكم.
