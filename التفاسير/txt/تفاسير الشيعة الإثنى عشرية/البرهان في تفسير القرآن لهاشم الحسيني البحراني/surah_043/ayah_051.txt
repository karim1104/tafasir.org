قوله تعالى:  { وَقَالُواْ يَٰأَيُّهَ ٱلسَّاحِرُ } - إلى قوله تعالى- { إِنَّهُمْ كَانُواْ قَوْماً فَاسِقِينَ } [49- 54] 9646/ - قال علي بن إبراهيم: ثم حكى قول فرعون و أصحابه [لموسى (عليه السلام)]، فقال: { وَقَالُواْ يَٰأَيُّهَ ٱلسَّاحِرُ } أي يا أيها العالم { ٱدْعُ لَنَا رَبَّكَ بِمَا عَهِدَ عِندَكَ إِنَّنَا لَمُهْتَدُونَ } ثم قال فرعون: { أَمْ أَنَآ خَيْرٌ مِّنْ هَـٰذَا ٱلَّذِي هُوَ مَهِينٌ } يعني موسى { وَلاَ يَكَادُ يُبِينُ } ، قال: لم يبن الكلام، ثم قال: { فَلَوْلاَ أُلْقِيَ عَلَيْهِ أَسْوِرَةٌ } أي هلا القي عليه أسورة { مِّن ذَهَبٍ أَوْ جَآءَ مَعَهُ ٱلْمَلاَئِكَةُ مُقْتَرِنِينَ }؟ يعني مقارنين { فَٱسْتَخَفَّ قَوْمَهُ } لما دعاهم { فَأَطَاعُوهُ إِنَّهُمْ كَانُواْ قَوْماً فَاسِقِينَ }.
