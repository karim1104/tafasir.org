قوله تعالى:  { أَفَنَضْرِبُ عَنكُمُ ٱلذِّكْرَ صَفْحاً } - إلى قوله تعالى- { وَجَعَلَ لَكُمْ مِّنَ ٱلْفُلْكِ وَٱلأَنْعَامِ مَا تَرْكَبُونَ } [5- 12] 9574/ - علي بن إبراهيم: قوله تعالى: { أَفَنَضْرِبُ عَنكُمُ ٱلذِّكْرَ صَفْحاً } استفهام، أي ندعكم مهملين لا نحتج عليكم برسول أو بإمام أو بحجج، و قوله تعالى: وَكَمْ أَرْسَلْنَا مِن نَّبِيٍّ فِي ٱلأَوَّلِينَ * وَمَا يَأْتِيهِم } إلى قوله تعالى: { أَشَدَّ مِنْهُم } يعني من قريش { بَطْشاً وَمَضَىٰ مَثَلُ ٱلأَوَّلِينَ } ، و قوله تعالى: { ٱلَّذِي جَعَلَ لَكُمُ ٱلأَرْضَ مَهْداً } أي مستقرا { وَجَعَلَ لَكُمْ فِيهَا سُبُلاً } أي طرقا { لَّعَلَّكُمْ تَهْتَدُونَ } أي كي تهتدون.  ثم احتج على الدهرية، فقال: { وَٱلَّذِي نَزَّلَ مِنَ ٱلسَّمَآءِ مَآءً بِقَدَرٍ فَأَنشَرْنَا بِهِ بَلْدَةً مَّيْتاً كَذَلِكَ تُخْرَجُونَ }.  و قوله تعالى: { وَجَعَلَ لَكُمْ مِّنَ ٱلْفُلْكِ وَٱلأَنْعَامِ مَا تَرْكَبُونَ } هو معطوف على قوله تعالى: [النحل: 5].
