قوله تعالى:  { بَلْ قَالُوۤاْ إِنَّا وَجَدْنَآ ءَابَآءَنَا عَلَىٰ أُمَّةٍ } - إلى قوله تعالى- { فَإِنَّهُ سَيَهْدِينِ } [22- 27] 9584/ - علي بن إبراهيم: قوله تعالى: { بَلْ قَالُوۤاْ إِنَّا وَجَدْنَآ ءَابَآءَنَا عَلَىٰ أُمَّةٍ } أي على مذهب { وَإِنَّا عَلَىٰ ءَاثَارِهِم مُّهْتَدُونَ } فقال الله عز و جل: قل يا محمد: { أَوَلَوْ جِئْتُكُمْ بِأَهْدَىٰ مِمَّا وَجَدتُّمْ عَلَيْهِ آبَآءَكُمْ قَالُوۤاْ إِنَّا بِمَآ أُرْسِلْتُمْ بِهِ كَافِرُونَ } ثم قال عز و جل: { وَإِذْ قَالَ إِبْرَاهِيمُ لأَبِيهِ وَقَوْمِهِ إِنَّنِي بَرَآءٌ مِّمَّا تَعْبُدُونَ * إِلاَّ ٱلَّذِي فَطَرَنِي فَإِنَّهُ سَيَهْدِينِ } أي يبين لي و يثبتني.
