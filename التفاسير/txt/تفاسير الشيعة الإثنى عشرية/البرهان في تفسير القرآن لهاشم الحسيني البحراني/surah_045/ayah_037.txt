قوله تعالى: { وَقِيلَ ٱلْيَوْمَ نَنسَاكُمْ كَمَا نَسِيتُمْ لِقَآءَ يَوْمِكُمْ هَـٰذَا } - إلى قوله تعالى- { وَهُوَ ٱلْعِزِيزُ ٱلْحَكِيمُ } [34- 37] 9753/ - علي بن إبراهيم، في قوله تعالى: { وَقِيلَ ٱلْيَوْمَ نَنسَاكُمْ } ، أي نترككم، فهذا النسيان هو الترك كَما { نَسِيتُمْ لِقَآءَ يَوْمِكُمْ هَـٰذَا وَمَأْوَاكُمُ ٱلنَّارُ وَمَا لَكُمْ مِّن نَّاصِرِينَ * ذَلِكُم بِأَنَّكُمُ ٱتَّخَذْتُمْ ءَايَٰتِ ٱللَّهِ هُزُواً } ، و هم الأئمة (عليهم السلام)، أي كذبتموهم و استهزأتم بهم { فَٱلْيَوْمَ لاَ يُخْرَجُونَ مِنْهَا } ، يعني من النار { وَلاَ هُمْ يُسْتَعَتَبُونَ } ، يعني لا يجابون، و لا يقبلهم الله { فَلِلَّهِ ٱلْحَمْدُ رَبِّ ٱلسَّمَٰوَٰتِ وَرَبِّ ٱلأَرْضِ رَبِّ ٱلْعَالَمِينَ * وَلَهُ ٱلْكِبْرِيَآءُ فِي ٱلسَّمَاوَاتِ وَٱلأَرْضِ وَهُوَ ٱلْعِزِيزُ ٱلْحَكِيمُ }.
