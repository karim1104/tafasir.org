قوله تعالى: { إِنَّ ٱلَّذِينَ كَفَرُواْ وَظَلَمُواْ لَمْ يَكُنِ ٱللَّهُ لِيَغْفِرَ لَهُمْ وَلاَ لِيَهْدِيَهُمْ طَرِيقاً * إِلاَّ طَرِيقَ جَهَنَّمَ } [النساء 168-169] - إلى قوله تعالى - { وَكَانَ ٱللَّهُ عَلِيماً حَكِيماً } [النساء: 170].  - محمد بن يعقوب: عن أحمد بن مهران، عن عبد العظيم بن عبد الله الحسني، عن محمد بن الفضيل، عن [أبي حمزة، عن] أبي جعفر (عليه السلام)، قال: " نزل جبرئيل (عليه السلام) بهذه الآية هكذا إِنَّ الَّذِينَ كَفَرُوا وَ ظَلَمُوا آل محمد حقهم { لَمْ يَكُنِ ٱللَّهُ لِيَغْفِرَ لَهُمْ وَلاَ لِيَهْدِيَهُمْ طَرِيقاً * إِلاَّ طَرِيقَ جَهَنَّمَ خَالِدِينَ فِيهَآ أَبَداً وَكَانَ ذٰلِكَ عَلَى ٱللَّهِ يَسِيراً } ، ثم قال: { يٰأَيُّهَا ٱلنَّاسُ قَدْ جَآءَكُمُ ٱلرَّسُولُ بِٱلْحَقِّ مِن رَّبِّكُمْ فَآمِنُواْ خَيْراً لَّكُمْ وَإِن تَكْفُرُواْ فَإِنَّ للَّهِ مَا فِي ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ } ".  - العياشي: عن أبي حمزة الثمالي، قال: سمعت أبا جعفر (عليه السلام) يقول: «نزل جبرئيل بهذه الآية هكذا { إِنَّ ٱلَّذِينَ كَفَرُواْ وَظَلَمُواْ } آل محمد حقهم { لَمْ يَكُنِ ٱللَّهُ لِيَغْفِرَ لَهُمْ وَلاَ لِيَهْدِيَهُمْ طَرِيقاً } إلى قوله { يَسِيراً } ثم قال: { يٰأَيُّهَا ٱلنَّاسُ قَدْ جَآءَكُمُ ٱلرَّسُولُ بِٱلْحَقِّ مِن رَّبِّكُمْ فَآمِنُواْ خَيْراً لَّكُمْ وَإِن تَكْفُرُواْ فَإِنَّ للَّهِ مَا فِي ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ وَكَانَ ٱللَّهُ عَلِيماً حَكِيماً } ».  - علي بن إبراهيم، قال: و قرأ أبو عبد الله (عليه السلام): " { إِنَّ ٱلَّذِينَ كَفَرُواْ وَظَلَمُواْ } آل محمد حقهم { لَمْ يَكُنِ ٱللَّهُ لِيَغْفِرَ لَهُمْ } " إلى آخر الآية.  - الطبرسي: { قَدْ جَآءَكُمُ ٱلرَّسُولُ بِٱلْحَقِّ } قيل: بولاية من أمر الله تعالى بولايته. عن أبي جعفر (عليه السلام).
