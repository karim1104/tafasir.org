قوله تعالى: { فَفَتَحْنَآ أَبْوَابَ ٱلسَّمَآءِ بِمَاءٍ مُّنْهَمِرٍ } - إلى قوله تعالى- { إِنَّآ أَرْسَلْنَا عَلَيْهِمْ رِيحاً صَرْصَراً } [11- 19] 10271/ - علي بن إبراهيم، في قوله تعالى: { فَفَتَحْنَآ أَبْوَابَ ٱلسَّمَآءِ بِمَاءٍ مُّنْهَمِرٍ } ، قال: صب بلا قطر { وَفَجَّرْنَا ٱلأَرْضَ عُيُوناً فَالْتَقَى ٱلمَآءُ } ، قال: ماء السماء و ماء الأرض { عَلَىٰ أَمْرٍ قَدْ قُدِرَ * وَحَمَلْنَاهُ } ، يعني نوحا { عَلَىٰ ذَاتِ أَلْوَاحٍ وَدُسُرٍ } قال: ذات ألواح: السفينة، و الدسر: المسامير، و قيل: الدسر: ضرب من الحشيش، تشد به السفينة { تَجْرِي بِأَعْيُنِنَا } أي بأمرنا و حفظنا، و قصة نوح قد مضى الحديث فيها في سورة هود فلتؤخذ من هناك.  قوله تعالى: { وَلَقَدْ يَسَّرْنَا ٱلْقُرْآنَ لِلذِّكْرِ فَهَلْ مِن مُّدَّكِرٍ } أي يسرناه لمن تذكر، قوله تعالى: { إِنَّآ أَرْسَلْنَا عَلَيْهِمْ رِيحاً صَرْصَراً } ، أي باردة، و قد ذكرنا حديث الرياح الأربع في سورة الجاثية.
