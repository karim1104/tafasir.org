قوله تعالى:  { بَلْ عَجِبْتَ وَيَسْخَرُونَ } - إلى قوله تعالى- { يٰوَيْلَنَا هَـٰذَا يَوْمُ ٱلدِّينِ } [12- 20] 8964/ - علي بن إبراهيم: { بَلْ عَجِبْتَ وَيَسْخَرُونَ * وَإِذَا ذُكِّرُواْ لاَ يَذْكُرُونَ * وَإِذَا رَأَوْاْ آيَةً يَسْتَسْخِرُونَ } يعني قريشا. ثم حكى قول الدهرية من قريش، فقال: أَ { أَءِذَا مِتْنَا وَكُنَّا تُرَاباً وَعِظَاماً } إلى قوله تعالى: { دَاخِرُونَ } أي مطروحون في النار { فَإِنَّمَا هِيَ زَجْرَةٌ وَاحِدَةٌ فَإِذَا هُمْ يَنظُرُونَ } ، و قوله: { وَقَالُواْ يٰوَيْلَنَا هَـٰذَا يَوْمُ ٱلدِّينِ } ، قال: يوم الحساب و المجازاة.  8965/ - علي بن إبراهيم، قال: حدثني أبي، عن محمد بن أبي عمير، عن النضر بن سويد، عن أبي بصير، عن أبي عبد الله (عليه السلام)، في قوله: { وَقَالُواْ يٰوَيْلَنَا هَـٰذَا يَوْمُ ٱلدِّينِ }: " يعني يوم الحساب ".
