قوله تعالى:  { وَتَرَى ٱلْجِبَالَ تَحْسَبُهَا جَامِدَةً } - إلى قوله تعالى- { أَتْقَنَ كُلَّ شَيْءٍ }  8060/ - قال علي بن إبراهيم: قوله: { وَتَرَى ٱلْجِبَالَ تَحْسَبُهَا جَامِدَةً وَهِيَ تَمُرُّ مَرَّ ٱلسَّحَابِ صُنْعَ ٱللَّهِ ٱلَّذِيۤ أَتْقَنَ كُلَّ شَيْءٍ } قال: فعل الله الذي أحكم كل شيء.  8061/ - وفي رواية أبي الجارود، عن أبي جعفر (عليه السلام): " قوله: { أَتْقَنَ كُلَّ شَيْءٍ } أحسن كل شيء خلقه ".
