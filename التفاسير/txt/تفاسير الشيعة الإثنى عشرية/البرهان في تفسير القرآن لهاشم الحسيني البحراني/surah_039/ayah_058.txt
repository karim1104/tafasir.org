قوله تعالى:  { لَوْ أَنَّ ٱللَّهَ هَدَانِي لَكُـنتُ مِنَ ٱلْمُتَّقِينَ } - إلى قوله تعالى- { وَكُنتَ مِنَ ٱلْكَافِرِينَ } [57- 59]  9263/ - ابن شهر آشوب: عن الباقر (عليه السلام)، في قوله تعالى: { لَوْ أَنَّ ٱللَّهَ هَدَانِي لَكُـنتُ مِنَ ٱلْمُتَّقِينَ } ، قال: " الولاية لعلي (عليه السلام)، فرد الله عليهم: بَلَىٰ قَدْ جَآءَتْكَ آيَاتِي فَكَذَّبْتَ بِهَا وَٱسْتَكْبَرْتَ وَكُنتَ مِنَ ٱلْكَافِرِينَ } ".  9264/ - علي بن إبراهيم: ثم قال: { أَوْ تَقُولَ حِينَ تَرَى ٱلْعَذَابَ لَوْ أَنَّ لِي كَـرَّةً } الآية، فرد الله تعالى عليهم، فقال: { بَلَىٰ قَدْ جَآءَتْكَ آيَاتِي فَكَذَّبْتَ بِهَا } يعني بالآيات الأئمة (عليهم السلام) { وَٱسْتَكْبَرْتَ وَكُنتَ مِنَ ٱلْكَافِرِينَ } [يعني] بالله.
