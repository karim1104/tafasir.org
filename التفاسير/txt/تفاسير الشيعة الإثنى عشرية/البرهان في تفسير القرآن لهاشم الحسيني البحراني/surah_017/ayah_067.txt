قوله تعالى:  { رَّبُّكُمُ ٱلَّذِي يُزْجِي لَكُمُ ٱلْفُلْكَ فِي ٱلْبَحْرِ } - إلى قوله تعالى - { ثُمَّ لاَ تَجِدُواْ لَكُمْ عَلَيْنَا بِهِ تَبِيعاً } [66- 69]  6442/ - علي بن إبراهيم: ثم قال: { رَّبُّكُمُ ٱلَّذِي يُزْجِي لَكُمُ ٱلْفُلْكَ فِي ٱلْبَحْرِ } إي السفن في البحر { لِتَبْتَغُواْ مِن فَضْلِهِ إِنَّهُ كَانَ بِكُمْ رَحِيماً * وَإِذَا مَسَّكُمُ ٱلْضُّرُّ فِي ٱلْبَحْرِ ضَلَّ مَن تَدْعُونَ إِلاَّ إِيَّاهُ } أي بطل من تدعون غير الله { فَلَمَّا نَجَّاكُمْ إِلَى ٱلْبَرِّ أَعْرَضْتُمْ وَكَانَ ٱلإِنْسَانُ كَفُوراً } ثم أرهبهم، فقال: أَ فَأَمِنْتُمْ أَنْ يَخْسِفَ بِكُمْ جانِبَ الْبَرِّ أَوْ يُرْسِلَ عَلَيْكُمْ حاصِباً أي عذابا و هلاكا { ثُمَّ لاَ تَجِدُواْ لَكُمْ وَكِيلاً * أَمْ أَمِنْتُمْ أَن يُعِيدَكُمْ فِيهِ تَارَةً أُخْرَىٰ } أي مرة اخرى { فَيُرْسِلَ عَلَيْكُمْ قَاصِفاً مِّنَ ٱلرِّيحِ } أي تجيء من كل جانب { فَيُغْرِقَكُم بِمَا كَفَرْتُمْ ثُمَّ لاَ تَجِدُواْ لَكُمْ عَلَيْنَا بِهِ تَبِيعاً }.  6443/ - قال: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام) في قوله: { قَاصِفاً مِّنَ ٱلرِّيحِ } قال: " هي العاصف " و قوله: تَبِيعاً يقول: وكيلا، و يقال: كفيلا، و يقال: ثائرا.
