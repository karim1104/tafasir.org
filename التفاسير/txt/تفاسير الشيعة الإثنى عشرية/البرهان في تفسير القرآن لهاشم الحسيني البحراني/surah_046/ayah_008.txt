قوله تعالى: { وَمَنْ أَضَلُّ مِمَّن يَدْعُواْ مِن دُونِ ٱللَّهِ } - إلى قوله تعالى- { وَهُوَ ٱلْغَفُورُ ٱلرَّحِيمُ } [5- 8] 9761/ - علي بن إبراهيم، في قوله تعالى: { وَمَنْ أَضَلُّ مِمَّن يَدْعُواْ مِن دُونِ ٱللَّهِ مَن لاَّ يَسْتَجِيبُ لَهُ إِلَىٰ يَوْمِ ٱلْقِيَامَةِ } إلى قوله تعالى: { بِعِبَادَتِهِمْ كَافِرِينَ } ، قال: من عبد الشمس و القمر و الكواكب و البهائم و الشجر و الحجر، إذا حشر الناس كانت هذه الأشياء له أعداء، و كانوا بعبادتهم كافرين.  قال: قوله تعالى: { أَمْ يَقُولُونَ } يا محمد { ٱفْتَرَاهُ } يعني القرآن، وضعه من عنده فقل لهم: { إِنِ ٱفْتَرَيْتُهُ فَلاَ تَمْلِكُونَ لِي مِنَ ٱللَّهِ شَيْئاً } ، إن أثابني أو عاقبني على ذلك { هُوَ أَعْلَمُ بِمَا تُفِيضُونَ فِيهِ } ، أي تكذبون { كَفَىٰ بِهِ شَهِيداً بَيْنِي وَبَيْنَكُمْ وَهُوَ ٱلْغَفُورُ ٱلرَّحِيمُ }.
