قوله تعالى:  { وَلَوْلاَ كَلِمَةُ ٱلْفَصْلِ لَقُضِيَ بَيْنَهُمْ وَإِنَّ ٱلظَّالِمِينَ لَهُمْ عَذَابٌ أَلِيمٌ } - إلى قوله تعالى- { ٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ } [21- 23]  9491/ - محمد بن يعقوب: عن علي بن محمد، عن علي بن العباس، عن الحسن بن عبد الرحمن، عن عاصم بن حميد، عن أبي حمزة، عن أبي جعفر (عليه السلام)، قال: أما قوله عز و جل: { وَلَوْلاَ كَلِمَةُ ٱلْفَصْلِ لَقُضِيَ بَيْنَهُمْ وَإِنَّ ٱلظَّالِمِينَ لَهُمْ عَذَابٌ أَلِيمٌ } قال: " لو لا ما تقدم فيهم من أمر الله عز و جل ما أبقى القائم (عليه السلام) منهم واحدا ".  9492/ - علي بن إبراهيم، قال: الكلمة: الإمام، و الدليل على ذلك قوله تعالى: [الزخرف: 28] [يعني الإمامة]، ثم قال: { وَإِنَّ ٱلظَّالِمِينَ } يعني الذين ظلموا هذه الكلمة { لَهُمْ عَذَابٌ أَلِيمٌ } ثم قال: { تَرَى ٱلظَّالِمِينَ } لآل محمد حقهم، { مُشْفِقِينَ مِمَّا كَسَبُواْ } ، قال: خائفون مما ارتكبوا [و عملوا] { وَهُوَ وَاقِعٌ بِهِمْ } [أي ما يخافونه].  ثم ذكر الله الذين آمنوا بالكتب و اتبعوها، فقال: { وَٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ فِي رَوْضَاتِ ٱلْجَنَّاتِ لَهُمْ مَّا يَشَآءُونَ عِندَ رَبِّهِمْ ذَلِكَ هُوَ ٱلْفَضْلُ ٱلْكَبِيرُ * ذَلِكَ ٱلَّذِي يُبَشِّرُ ٱللَّهُ عِبَادَهُ ٱلَّذِينَ آمَنُواْ } [بهذه الكلمة] { وَعَمِلُواْ ٱلصَّالِحَاتِ } [مما أمروا به].
