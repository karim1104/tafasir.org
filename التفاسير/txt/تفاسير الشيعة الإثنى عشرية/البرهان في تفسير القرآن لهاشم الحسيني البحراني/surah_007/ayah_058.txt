قوله تعالى: { وَهُوَ ٱلَّذِي يُرْسِلُ ٱلرِّيَاحَ بُشْراً } [الأعراف: 57] - إلى قوله تعالى - { وَٱلَّذِي خَبُثَ لاَ يَخْرُجُ إِلاَّ نَكِداً } [الأعراف: 58] - علي بن إبراهيم، قال: قوله: { وَهُوَ ٱلَّذِي يُرْسِلُ ٱلرِّيَاحَ بُشْراً بَيْنَ يَدَيْ رَحْمَتِهِ } إلى قوله:  { كَذٰلِكَ نُخْرِجُ ٱلْموْتَىٰ } دليل على البعث و النشور، و هو رد على الزنادقة.  قال: و قوله: { وَٱلْبَلَدُ ٱلطَّيِّبُ يَخْرُجُ نَبَاتُهُ بِإِذْنِ رَبِّهِ } و هو مثل الأئمة (صلوات الله عليهم) يخرج علمهم بإذن ربهم { وَٱلَّذِي خَبُثَ لاَ يَخْرُجُ إِلاَّ نَكِداً } أي كدرا فاسدا.
