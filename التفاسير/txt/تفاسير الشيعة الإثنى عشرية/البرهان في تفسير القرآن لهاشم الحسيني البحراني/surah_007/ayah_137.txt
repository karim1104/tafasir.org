قوله تعالى: { وَأَوْرَثْنَا ٱلْقَوْمَ ٱلَّذِينَ كَانُواْ يُسْتَضْعَفُونَ مَشَارِقَ ٱلأَرْضِ وَمَغَارِبَهَا ٱلَّتِي بَارَكْنَا فِيهَا } [الأعراف: 137] - إلى قوله تعالى - { وَفِي ذٰلِكُمْ بَلاۤءٌ مِّن رَّبِّكُمْ عَظِيمٌ } [الأعراف: 141] - علي بن إبراهيم، في قوله تعالى: { وَأَوْرَثْنَا ٱلْقَوْمَ ٱلَّذِينَ كَانُواْ يُسْتَضْعَفُونَ مَشَارِقَ ٱلأَرْضِ وَمَغَارِبَهَا ٱلَّتِي بَارَكْنَا فِيهَا }: يعني بني إسرائيل لما أهلك الله تعالى فرعون، ورثوا الأرض و ما كان لفرعون.  قال: و قوله: { وَتَمَّتْ كَلِمَةُ رَبِّكَ ٱلْحُسْنَىٰ عَلَىٰ بَنِيۤ إِسْرَآئِيلَ بِمَا صَبَرُواْ } يعني الرحمة بموسى (عليه السلام) تمت لهم { وَدَمَّرْنَا مَا كَانَ يَصْنَعُ فِرْعَوْنُ وَقَوْمُهُ وَمَا كَانُواْ يَعْرِشُونَ } يعني المصانع و العريش و القصور.  قال: و أما قوله: { وَجَاوَزْنَا بِبَنِيۤ إِسْرَآئِيلَ ٱلْبَحْرَ فَأَتَوْاْ عَلَىٰ قَوْمٍ يَعْكُفُونَ عَلَىٰ أَصْنَامٍ لَّهُمْ } فإنه لما أغرق الله فرعون و أصحابه و عبر موسى (عليه السلام) و أصحابه البحر، نظر أصحاب موسى إلى قوم يعكفون على أصنام لهم، فقالوا لموسى: { يٰمُوسَىٰ ٱجْعَلْ لَّنَآ إِلَـٰهاً كَمَا لَهُمْ آلِهَةٌ } فقال موسى: { إِنَّكُمْ قَوْمٌ تَجْهَلُونَ * إِنَّ هَـٰؤُلاۤءِ مُتَبَّرٌ مَّا هُمْ فِيهِ وَبَاطِلٌ مَّا كَانُواْ يَعْمَلُونَ * قَالَ أَغَيْرَ ٱللَّهِ أَبْغِيكُمْ إِلَـٰهاً وَهُوَ فَضَّلَكُمْ عَلَى ٱلْعَالَمِينَ * وَإِذْ أَنْجَيْنَاكُمْ مِّنْ آلِ فِرْعَونَ يَسُومُونَكُمْ سُوۤءَ ٱلْعَذَابِ يُقَتِّلُونَ أَبْنَآءَكُمْ وَيَسْتَحْيُونَ نِسَآءَكُمْ وَفِي ذٰلِكُمْ بَلاۤءٌ مِّن رَّبِّكُمْ عَظِيمٌ } قال علي ابن إبراهيم: هو محكم.  - ابن شهر آشوب، قال علي (عليه السلام) لرأس الجالوت، لما قال له: لم تلبثوا بعد نبيكم إلا ثلاثين سنة، حتى ضرب بعضكم وجه بعض بالسيف. فقال (عليه السلام): " و أنتم، لم تجف أقدامكم من ماء البحر حتى قلتم لموسى (عليه السلام): { ٱجْعَلْ لَّنَآ إِلَـٰهاً كَمَا لَهُمْ آلِهَةٌ } ".
