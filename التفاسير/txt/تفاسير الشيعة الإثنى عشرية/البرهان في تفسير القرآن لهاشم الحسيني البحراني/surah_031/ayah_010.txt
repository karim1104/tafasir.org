قوله تعالى:  { خَلَقَ ٱلسَّمَٰوَٰتِ بِغَيْرِ عَمَدٍ تَرَوْنَهَا }  تقدم الحديث فيها في أول سورة الرعد ، و يأتي- إن شاء الله تعالى- في قوله تعالى: [الذاريات: 7].  قوله تعالى:  { وَبَثَّ فِيهَا مِن كُلِّ دَآبَّةٍ } - إلى قوله تعالى- { هَـٰذَا خَلْقُ ٱللَّهِ } [10- 11] 8393/ - علي بن إبراهيم: قوله: { وَبَثَّ فِيهَا مِن كُلِّ دَآبَّةٍ } ، يقول: جعل فيها من كل دابة. قال: قوله: { فَأَنْبَتْنَا فِيهَا مِن كُلِّ زَوْجٍ كَرِيمٍ } يقول: من كل لون حسن، و الزوج: اللون الأصفر و الأخضر و الأحمر، و الكريم: الحسن. قال: قوله: { هَـٰذَا خَلْقُ ٱللَّهِ } أي مخلوق الله، لأن الخلق هو الفعل، و الفعل لا يرى، و إنما أشار إلى المخلوق، و إلى السماء و الأرض و الجبال و جميع الحيوان، فأقام الفعل مقام المفعول.
