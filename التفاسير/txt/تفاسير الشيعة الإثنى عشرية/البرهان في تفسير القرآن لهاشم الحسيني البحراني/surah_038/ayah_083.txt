قوله تعالى:  { قَالَ فَبِعِزَّتِكَ لأُغْوِيَنَّهُمْ } - إلى قوله تعالى- { وَمِمَّن تَبِعَكَ مِنْهُمْ أَجْمَعِينَ } [82- 85] 9146/ - علي بن إبراهيم: ثم قال لإبليس (لعنة الله) لما قال: { فَبِعِزَّتِكَ لأُغْوِيَنَّهُمْ أَجْمَعِينَ * إِلاَّ عِبَادَكَ مِنْهُمُ ٱلْمُخْلَصِينَ }. فقال الله: { فَٱلْحَقُّ وَٱلْحَقَّ أَقُولُ } أي إنك تفعل ذلك، و الحق أقول: { لأَمْلأَنَّ جَهَنَّمَ مِنكَ وَمِمَّن تَبِعَكَ مِنْهُمْ أَجْمَعِينَ }.
