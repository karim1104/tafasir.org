{ (46) وَكانُوا يُصِرُّونَ عَلَى الْحِنثِ الْعَظِيمِ } الذنب العظيم قيل يعني الشرك.  { (47) وَكانُوا يَقُولُونَ أَئِذا مِتْنَا وَكُنَّا تُراباً وَعِظَاماً أَءِنَّا لَمَبْعُوثُونَ }.  { (48) أَوَءَاباؤُنَا الأَوَّلُونَ } وقرىء أَو بالسكون.  { (49) قُلْ إِنَّ الأَوَّلِينَ وَالأَخِرِينَ }.  { (50) لَمَجْمُوعُونَ إِلى مِيقَاتِ يَوْمٍ مَعْلُومٍ } الى ما وقّت به الدنيا وحدّ من يوم معيّن عند الله معلوم له.  { (51) ثُمَّ إِنَّكُمْ أَيُّها الضَّالُّونَ المُكَذِّبُونَ } بالبعث.  { (52) لأَكِلُونَ مِنْ شَجَرٍ مِنْ زَقُّومٍ }.  { (53) فَمَالِئُونَ مِنهَا الْبُطُونَ } من شدّة الجوع.  { (54) فَشارِبُونَ عَلَيْهِ مِنَ الْحَمِيمِ } لغلبة العطش.  { (55) فَشارِبُونَ شُرْبَ الْهِيمِ } الابل التي بها الهيام وهي داء يشبه الاستسقاء جمع اهيم وهيماء او الرمال على انّه جمع هيام بالفتح وهو الرمل الذي لا يتماسك.  في الفقيه والمحاسن والمعاني عن الصادق عليه السلام انّه سئل عن الهيم قال الابل.  وفي رواية الهيم الرمل وقرىء شرب بضمّ الشين.  { (56) هذَا نُزُلُهُمْ يَوْمَ الدَّينِ } فما ظنّك بما يكون لهم بعدما استقرّوا في الجحيم وفيه تهكّم بهم لأنّ النزل ما يعدّ للنّازل تكرمه له وقيل النّزل ما ينزل عليه صاحبه القمّي قال هذا ثوابهم يوم المجازاة.  { (57) نَحْنُ خَلَقْنَاكُمْ فَلَوْلاَ تُصَدِّقُونَ } بالخلق او البعث.  { (58) أَفَرَأَيْتُمْ مَا تُمْنُونَ } ما تقذفونه في الأرحام من النّطف.  { (59) ءَأَنتُمْ تَخْلُقُونَهُ } تجعلونه بشراً سويّاً { َأمْ نَحْنُ الْخالِقُونَ }.  { (60) نَحْنُ قَدَّرْنا بَيْنَكُمُ الْمَوْتَ } قسّمناه عليكم واقتنا موت كلّ بوقت معيّن وقرىء بتخفيف الدّال { وَمَا نَحْنُ بِمَسْبُوقِينَ } بمغلوبين.  { (61) عَلَى أَنْ نُبَدِّلَ أَمْثَالَكُمْ } ان نبدّل منكم اشباهكم فنخلق بدلكم { وَنُنشِئَكُمْ فِي ما لاَ تَعْلمُونَ } في نشأة لا تعلمونها.  { (62) وَلَقَدْ عَلِمْتُمُ النَّشْأَةَ الأَُولَى فَلَوْلاَ تَذَكَّرُونَ } انّ من قدر عليها قدر على النّشأة الاخرى.  في الكافي عن السجّاد عليه السلام العجب كلّ العجب لمن انكر النّشأة الاخرى وهو يرى النّشأة الاولى.  { (63) َأفَرَأَيْتُمْ مَا تَحْرُثُونَ } تبذرون حبّه.  { (64) ءَأَنْتُمْ تَزْرَعُونَهُ } تنبتونه { أَمْ نَحْنُ الزّارِعُونَ } المنبتون.  في المجمع عن النبيّ صلّى الله عليه وآله لا يقولنّ احدكم زرعت وليقل حرثت.  { (65) لَوْ نَشَآءُ لَجَعَلْنَاهُ حُطاماً } هشيماً { فَظَلْتُمْ تَفَكَّهُونَ } تتحدّثونه فيه تعجّباً وتندّماً على ما انفقتم فيه والتفكّه التنقّل بصنوف الفاكهة قد استعير للتنقل بالحديث.  { (66) إِنَّا لَمُغْرَمُونَ } لملزمون غرامة ما انفقنا او مهلكون لهلاك رزقنا من الغرام.  وقرىء أنا على الإِستفهام.  { (67) بَلْ نَحْنُ } قوم { مَحرُومُونَ } حرمنا رزقنا.  { (68) أَفَرَأَيْتُمُ الْمَاءَ الَّذِي تَشْرَبُونَ } اي العذب الصالح للشرب.  { (69) ءَأَنتُمْ أَنزَلْتُمُوهُ مِنَ الْمُزْنِ } من السّحاب { أَمْ نَحْنُ الْمُنزِلُونَ } بقدرتنا.  { (70) لَوْ نَشَآءُ جَعَلْنَاهُ أُجاجاً } قيل ملحاً والقمّي اي زعاقاً { فَلَوْلاَ تَشْكُرُونَ } امثال هذه النعم الضرورية.
