{ (1) وَالشَّمْسِ وَضُحَاهَا } امتداد ضوئها وانبساطه واشراقه.  { (2) وَالْقَمَرِ إِذَا تَلاَهَا } طلع عند غروبها أخذ من نورها.  { (3) وَالنَّهَارِ إِذَا جَلاَّهَا } عند انبساطه.  { (4) وَاللَّيْلِ إِذَا يَغْشَاهَا } فيظلم الآفاق ويلبسها سواده.  في الكافي والقمّي عن الصادق عليه السلام قال الشمس رسول الله صلّى الله عليه وآله به اوضح الله للنّاس دينهم والقمر امير المؤمنين عليه السلام تلا رسول الله صلّى الله عليه وآله ونفثه بالعلم نفثاً واللّيل ائمّة الجور الّذين استبدّوا بالامر دون آل الرسول وجلسوا مجلساً كان آل الرّسول اولى به منهم فغشّوا دين الله بالظلم والجور.  { (5) وَالسَّمَاءِ وَمَا بَنَاهَا } والقادر الّذي بناها.  { (6) وَالأَرْضِ وَمَا طَحَاهَا } والصانع الذي دحاها.  { (7) وَنَفْسٍ وَما سَوَّاهَا } والخالق الذي سوّاها اي عدّل خلقها القمّي قال خلقها وصوّرها.  { (8) فَأَلْهَمَهَا فُجُورَهَا وَتَقْواها } قال اي عرفّها والهمها ثمّ خيّرها فاختارت وفي الكافي عن الصادق عليه السلام قال بيّن لنا ما تأتي وما تترك.
