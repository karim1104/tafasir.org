{ (32) كَلاَّ } ردع لمن انكرها او انكار لأن يتذكّروا بها { وَالْقَمَرِ }.  { (33) وَاللَّيْلِ إِذا دَبَرَ } دبر بمعنى ادبر كقبل مبعنى اقبل اي ولّى وانقضى وقيل دبر اي جاء في اثر النّهار وقرىء اذ أدبر من الادبار.  { (34) وَالصُّبْحِ إِذَا أَسْفَرَ } اضاء.  { (35) إِنَّها لإِحْدَى الْكُبَرِ } لاحدى البلايا الكبر في الحديث السابق قال الولاية.  { (36) نَذِيراً لِلْبَشَرِ } انذار لهم او منذرة.  { (37) لِمَنْ شَآءَ مِنكُمْ أَنْ يَتَقَدَّمَ أَوْ يَتَأَخَّرَ } ليتقدّم الى الخير او يتأخّر عنه قال في الحديث السابق من تقدّم الى ولايتنا آخّر عن سقر ومن تأخّر عنها تقدّم الى سقر.  { (38) كُلُّ نَفْسٍ بِمَا كَسَبَتْ رَهِينَةٌ } مرهونة عند الله.  { (39) إلاَّ أَصْحابَ الْيَمِينِ } فانّهم فكّوا رقابهم بما احسنوا من اعمالهم في الحديث السابق هم والله شيعتنا والقمّي قال اليمين امير المؤمنين عليه السلام واصحابه شيعته.  { (40) فِي جَنَّاتٍ يَتَساءَلُونَ }.  { (41) عَنِ الْمُجْرِمِينَ } يسأل بعضهم بعضاً او يسألون غيرهم عن حالهم كقولك تداعيناه اي دعوناه.  { (42) مَا سَلَكَكُمْ فِي سَقَرَ } حكاية لم جرى بين المسؤولين او المجرمين.  { (43) قَالُوا لَمْ نَكُ مِنَ الْمُصَلِّينَ } قيل يعني الصلاة الواجبة في نهج البلاغة تعاهدوا امر الصلاة وحافظوا عليها واستكثرا منها وتقرّبوا بها فانّها كانت على المؤمنين كتاباً موقوتاً الا تسمعون الى جواب اهل النار حين سئلوا ما سلككم في سقر قالوا لم نك من المصلّين.  وفي الكافي عنه عليه السلام مثله وعن الصادق عليه السلام قال عنى لم نك من اتباع الأئمّة الذين قال الله فيهم [الواقعة: 10-11] اما ترى الناس يسمّون الّذي يلي السابق في الحلبة مصلّياً فذلك الذي عني حيث قال لم نك من المصلّين اي لم نك من اتباع السابقين.  وعن الكاظم عليه السلام قال يعني انّا لم نتولّ وصيّ محمد والاوصياء من بعده عليهم السلام ولم نصلّ عليهم.  { (44) وَلَمْ نَكُ نُطْعِمُ الْمِسْكِينَ } ما يجب اعطاؤه القمّي قال حقوق آل محمد صلوات الله عليهم من الخمس لذوي القربى واليتامى والمساكين وابن السبيل وهم آل محمد صلوات الله عليهم.  { (45) وَكُنّا نَخُوضُ مَعَ الْخَائِضِينَ } نشرع في الباطل مع الشارعين فيه.  { (46) وَكُنْا نُكَذِّبُ بِيَوْمِ الدِّينَ } اي وكنّا بعد ذلك كلّه مكذّبين بالقيامة وتأخيره لتعظيمه.  { (47) حَتَّى أَتَانَا الْيَقِينُ } الموت.  { (48) فَمَا تَنْفَعُهُمْ شَفاعَةُ الشَّافِعِينَ } لو شفعوا لهم جميعاً.
