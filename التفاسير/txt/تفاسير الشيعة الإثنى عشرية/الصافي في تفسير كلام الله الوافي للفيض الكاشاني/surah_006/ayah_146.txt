{ (146) وَعَلَى الَّذِينَ هَادُواْ حَرَّمْنَا كُلَّ ذِي ظُفُرٍ } من دابة أو طير { وَمِنَ الْبَقَرِ وَالْغَنَمِ حَرَّمْنَا عَلَيْهِمْ شُحُومَهُمَآ } الثروب وشحوم الكلى { إلاَّ مَا حَمَلَتْ ظُهُورُهُمَآ } أي ما علقت بظهروهما { أَوِ الْحَوَايَآ } أو ما اشتمل على الأمعاءِ { أَوْ مَا اخْتَلَطَ بِعَظْمٍ } وهو شحم الإلية فانه متصل بالعصعص { ذلِكَ جَزَيْنَاهُم بِبَغْيِهِمْ } بسبب ظلمهم { وَإِنَّا لَصَادِقُونَ } في الأخبار والوعد والوعيد.
