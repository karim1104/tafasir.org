{ (10) إِنَّ الَّذِينَ فَتَنُوا الْمُؤْمِنِينَ وَالْمُؤْمِنَاتِ } بلاهم بالأذى { ثُمَّ لَمْ يَتُوبُوا فَلَهُمْ عَذابُ جَهَنَّمَ } بكفرهم { وَلَهُمْ عَذابُ الْحَرِيقِ } العذاب الزائد في الاحراق بفتنهم وقيل المراد بالذين فتنوا اصحاب الاخدود وبعذاب الحريق ما روي انّ النار انقلب عليهم فاحرقهم.  { (11) إِنَّ الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ لَهُمْ جَنَّاتٌ تَجْرِي مِنْ تَحْتِهَا الأنْهَارُ ذلِكَ الْفَوْزُ الْكَبِيرُ } اذا الدنيا وما فيها يصغر دونه.  { (12) إِنَّ بَطْشَ رَبَِّكَ لَشَدِيدٌ } مضاعف عنفه فانّ البطش اخذ بعنف.  { (13) إِنَّهُ هُوَ يُبْدِىءُ وَيُعِيدُ } يبدأ الخلق ويعيده.  { (14) وَهُوَ الْغَفُورُ الْوَدُودُ } لمن تاب واطاع.  { (15) ذُو الْعَرْشِ الْمَجِيدُ } العظيم في ذاته وصفاته.  القمّي عن الباقر عليه السلام في قوله { ذُوْ الْعَرْشِ الْمَجِيدُ } قال فهو الله الكريم المجيد.
