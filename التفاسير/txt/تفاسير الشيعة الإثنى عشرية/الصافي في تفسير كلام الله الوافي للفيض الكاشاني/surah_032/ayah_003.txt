{ (1) الم }  { (2) تَنْزِيلُ الْكِتَابِ لاَ رَيْبَ فِيهِ مِنْ رَبِّ الْعَالَمِينَ }  { (3) أَمْ يَقُولُونَ افْتَراهُ بَلْ هُوَ الْحَقُّ مِنْ رَبِّكَ لِتُنْذِرَ قَوْمًا مَا آتَاهُمْ مِنْ نَذِيرٍ مِنْ قَبْلِكَ } إذ كانوا أهل الفترة { لَعَلَّهُمْ يَهْتَدُونَ } بانذارك ايّاهم.  { (4) اللهُ الَّذِى خَلَقَ السَّمَاوَاتِ وَالأَرْضَ وَمَا بَيْنَهُمَا فِى سِتَّةِ أَيّامٍ ثُمَّ اسْتَوَى عَلَى الْعَرْشِ } سبق تفسيره في سورة الاعراف { مَا لَكُمْ مِنْ دُونِهِ مِنْ وَلِىٍّ وَلاَ شَفِيعٍ } اذا جاوزتم امره { أَفَلاَ تَتَذَكَّرُونَ } بمواعظ الله.  { (5) يُدَبِّرُ الأَمْرَ مِنَ السَّمَاءِ إِلَى الأَرْضِ ثُمَّ يَعْرُجُ إِلَيْهِ فِى يَوْمٍ كَانَ مِقْدَارُهُ أَلْفَ سَنَةٍ مِمّا تَعُدُّونَ }  القمّي يعني الأمور التي يدبّرها والامر والنهي الذي امر به واعمال العباد كلّ هذا يظهر يوم القيامة فيكون مقدار ذلك اليوم الف سنة من سنيّ الدنيا وقد سبق في سورة الحجّ اخبار في هذا المعنى.  { (6) ذَلِكَ عَالِمُ الْغَيْبِ وَالشَّهَادَةِ } فيدبّر امرها على وفق الحكمة { الْعَزِيزُ } الغالب على امره { الرَّحِيمُ } على العباد في تدبيره.  { (7) الَّذِى أَحْسَنَ كلَّ شَىْءٍ خَلْقَهُ } موفّراً عليه ما يستعدّه ويليق به على وفق الحكمة والمصلحة وقرء بفتح اللاّم { وَبَدَءَ خَلْقَ الإِنْسَانِ مِنْ طِينٍ } القمّي قال هو آدم.
