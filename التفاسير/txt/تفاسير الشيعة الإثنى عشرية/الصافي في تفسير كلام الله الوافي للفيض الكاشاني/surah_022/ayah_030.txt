{ (30) ذَلِكَ } الأَمر ذلك وهو وامثاله يطلق للفصل بين الكلامين { وَمَن يُعَظِّمْ حُرُماتِ اللهِ } احكامه وما لا يحلّ هتكه { فَهُوَ خَيْرٌ لَهُ عِندَ رَبِّهِ } ثوابا { وَأُحِلَّتْ لَكُمُ الأَنْعامُ إِلاّ مَا يُتْلَى عَلَيْكُمْ } كالميتة وما اهلّ به لغير الله فلا تحرّموا منها غير ما حرّمه الله كالبحيرة والسّائبة { فَاجْتَنِبُوا الرِّجْسَ مِنَ الأَوْثَانِ وَاجْتَنِبُوا قَوْلَ الزُّورِ } فاجتنبوا الرّجس الّذي هو الاوثان كما يجتنب الأنجاس وكلّ افتراء.  في الكافي والقمّي عن الصادق عليه السلام قال الرّجس من الأوثان الشطرنج وقول الزّور والغناء وزاد في المجمع وساير انواع القمار وساير الأقوال الملهية وعن النبي صلّى لله عليه وآله عدلت شهادة الزّور بالشرك بالله ثم قرء هذه الآية.  { (31) حُنَفَاءَ لِلَّهِ }  القمّي عن الصادق عليه السلام اي طاهرين { غَيْرَ مُشرِكِينَ بِهِ }  في التوحيد عن الباقر عليه السلام انّه سئل عنه وعن الحنيفة فقال هي الفطرة التي فطر النّاس عليها لا تبديل لخلق الله قال فطرهم الله على المعرفة { وَمَن يُشْرِكْ بِاللهِ فَكَأَنَّمَا خَرَّ مِنَ السَّماءِ } لأنّه سقط من اوج الايمان الى حضيض الكفر { فَتَخْطَفُهُ الَّطيْرُ } فانّ الاهواء المردية توزّع افكاره وقرء بتشديد التّاء { أَوْ تَهْوِي بِهِ الرِّيحُ فِي مَكانٍ سَحِيقٍ } بعيد فان الشيطان قد طرح به في الضّلالة
