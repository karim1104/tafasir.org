{  إِن تَدْعُوهُمْ لَا يَسْمَعُوا دُعَاءكُمْ } إن كانوا بلا إحساس وشعور كالأحجار والأشجار والكواكب {  وَلَوْ سَمِعُوا } إن كانوا من الإنس أو الجن أو الملائكة {  مَا اسْتَجَابُوا لَكُمْ } لأنهم لا يملكون لأنفسهم نفعا ولا ضرا ،  فكيف يملكون ذلك لغيرهم {  وَيَوْمَ الْقِيَامَةِ يَكْفُرُونَ بِشِرْكِكُمْ } .  يبرأون منكم ويوبخونكم على الشرك والضلال {  وَلَا يُنَبِّئُكَ مِثْلُ خَبِيرٍ } بمصير هؤلاء المكذبين بنبوتك يا محمد وغيرهم من العصاة والطغاة .
