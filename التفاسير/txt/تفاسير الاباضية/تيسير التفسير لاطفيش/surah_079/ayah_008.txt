{ قُلُوبٌ } مبتدأ ولو نكرة لأَنها للتنويع أو للتنكير .  { يَوْمَئِذٍ } متعلق بقوله { وَاجِفَةٌ } أى مضطربة لشدة الفزع اضطرابا مسرعا كقوله تعالى فما أوجفتم عليه من خيل ولا ركاب وقيل زائلة عن مكانها وهو كالأَول لأَن زوالها عنه لاضطرابها لشدة الفزع ،  وعن ابن عباس خائفة بلغة همدان وذلك كقوله تعالى { وجوه يومئذ ناضرة إِلى ربها ناظرة } [ القيامة : 22 - 23 ] .
