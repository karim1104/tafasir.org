{ إِنَّمَا السَّبِيلُ } أَى الذم { عَلَى الَّذِينَ يَسْتَأْذِنُونَكَ } فى القعود { وَهُمْ أَغْنِيَاءُ } أَى والحال أَن لهم ما ينفقون ذهاباً ورجوعاً عليهم وعلى عيالهم .  { رَضُوا بِأَنْ يَكُونُوا مَعَ الْخَوَالِفِ } رضوا بحالة خسيسة هي كونهم مع الخوالف جواب لقول القائلين ما بالهم يستأْذنون فى القعود ،  أَو حال من واو يستأْذنونك { وَطَبَع اللهُ عَلَى قُلُوبِهِمْ } حتى غفلوا عن سوءِ العاقبة { فَهُمْ لاَ يَعْلَمُونَ } تلك العاقبة .
