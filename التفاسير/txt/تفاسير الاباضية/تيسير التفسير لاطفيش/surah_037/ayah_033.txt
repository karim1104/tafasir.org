{ فإنَّهم } الرؤساء والمرءوسين ، والتفريع على محذوف أى الأمر ظاهر ، أو الأمر كذلك فانهم { يَومئذ } إذ قامت القيامة { في العَذاب مُشْتركُون } على اختلافهم فى شدة العذاب شديد ، وأشد فان المغوين أشد عذابا لقوله تعالى : { ومن أوزار الذين يضلونهم } [ النحل : 25 ] وقوله : { وأثقالا مع أثقالهم } [ العنكبوت : 13 ] ونحو ذلك .
