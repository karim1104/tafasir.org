{ فلمَّا جاءهم الحقُّ } القرآن { من عندنا قالوا } عنادا { لَوْلا } مثل لولا الثانية { أُوتِىَ } محمد { مثل ما أوتِىَ مُوسَى } أى مثل ما أوتيه موسى من كتاب منزل بمرة ، وهو التوراة ، ومن اليد والعصا { أو لم يكْفروا بما أوتى مُوسَى من قَبْل } قبل مجىء محمد ، أو قبل مجىء الحق وهو القرآن { قالُوا } موسى ومحمد ، أو موسى وهارون { سِحْرانِ تَظَاهرا } تعاونا فى سحرهما ، وتوافق كتابيهما ، قيل : وكان فرعون عربيا من أولاد عاد ، يتكلم بالعربية ، روى أن أهل مكة بعثوا رهطاً يوم عيد لليهود يسألونهم عن رسول الله صلى الله عليه وسلم ، فأجابوهم بأنا نجده بصفته كما هو فى التوراة ، فقالوا : ساحران أى مُوسَى ومحمد تظاهرا بخوارقهما وكتابيهما .

{ وقالوا إنَّا بكلِّ } منهما أو بالأنبياء مطلقاً ، والكتب مطلقاً { كافرون } ويقوى أن المراد بكل هو كل ما أتيا به ، قوله : { لولا أوتى } وقوله : { أو لم يكفروا بما أوتى } وقوله : { قلْ فأتُوا بكتاب مِن عِنْد الله هُو أهْدى منهُما أتَّبعه إن كُنتم صادقين }
