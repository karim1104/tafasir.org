وذكر موصولا آخر بصلتين فى قوله { الَّذِينَ } نعت للمؤمنين { يُقِيمُونَ الصَّلاَةَ } الواجبة والنافلة { وَمِمَّا رَزَقْنَاهُمْ يُنْفِقُونَ } فى الطاعة واجبا ونفلا .  قرن الله تعالى الإِيمان وعمل الصالحات كما فى الآية قبل هذه ،  وقوله : { آمنوا وعملوا الصالحات } [ العصر : 3 ] والزكاة والصلاة ،  والصلاة والإِنفاق ،  فى هذه الآية ،  وقوله تعالى { وأَقيموا الصلاة وآتوا الزكاة } [ النور : 56 ] وطاعة الرسول كما فى قوله عز وجل  "  وأَطيعوا الله وأَطيعوا الرسول  "  وطاعة الله والإِحسان إِلى الوالدين فى قوله تعالى { وقضى ربك أَلا تعبدوا إِلا إِياه وبالوالدين إِحسانا } [ الإِسراء : 23 ]
