{ وَإِنْ يُرِيدوا } أَى الأَسرى { خِيَانتَك } نقض العهد بقتالك وقتال المؤمنين ،  وبإِعانة أَعدائك ،  والجواب محذوف تقديره قتلوا وأَسروا ،  أَو فليتوقعوا القتل والأَسر لأَنهم خانوا قبل ذلك فقتلوا وأَسروا كما قال : { فَقَدْ خَانُوا } لأَنهم تحقق خيانتهم { اللهَ مِنْ قبْلُ } قبل بدر بقتالك وإِعانة العدو { فَأَمْكَن } أَمكنك والمؤمنين { مِنْهُمْ } فى بدر بالقتل والأَسر فهو يمكنك منهم بعد { وَاللهُ عَلِيمٌ } بخلقه وأَحوالهم وجزائهم { حَكِيمٌ } فيما يصنع بهم .
