{ فألقَوا حِبَالهم وعِصِيِّهم } فانه ليس الحبال والعصى فى أيديهم حاملين لها ، وقد علم موسى ان سحرهم بالالقاء ، أو أراد بالالقاء العمل { وقالُوا } لجزمهم بأنهم غالبون لبلوغهم أقصى جهدهم فى السحر { بعزَّةِ } قوة وغلبة { فرعون } أقسموا به على طريق الغيبة ، لا الخطاب ، اعظاما له { إنَّا لنحنُ الغالبُون } لموسى .
