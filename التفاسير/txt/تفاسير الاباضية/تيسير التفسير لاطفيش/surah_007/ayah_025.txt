{ قَالَ } كرر القول ،  قيل لبعد اتصال الحياة فى الأَرض والموت فيها والإِخراج منها بالأَمر بالإِهباط وبعداوة بعض لبعض ،  والاستقرار فى الأَرض والتمتع فيها ،  ويبحث بأَنه لا بعد فى ذلك بل مناسبة لأَن ذلك كله فى الأَرض والإِهباط إِليها والإِخراج منها ،  بل كرر لإظهار الاعتناء بما بعده وهو قوله { فِيهَا } للحصر { تَحْيَوْنَ وَفِيهَا } قدم للحصر { تَمُوتُونَ } ودخل البحر فى الأَرض لأَن المراد بها ما قابل السماءَ مطلقاً { وَمِنْهَا } قدم للحصر والفاصلة { تُخْرَجُونَ } للجزاء ،  وكذا فى قوله : { يَا بَنِى آدمَ } .
