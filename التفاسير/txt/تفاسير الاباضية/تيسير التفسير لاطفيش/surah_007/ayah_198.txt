{ وَإِنْ تَدْعُوهُمْ } أَيها المؤمنون الأَصنام ؛ أَو أَيها المشركون { إِلَى الْهُدَى لاَ يَسْمَعُوا } دعاءَكم { وَتَرَاهُمْ } أَى ترى الأَصنام يا محمد ،  ويامن يصلح للرؤية { يَنْظُرُونَ إِلَيْكَ } بصورة الناظر إِليك فهو استعارة تبعية صورية { وَهُمْ لاَ يُبْصِرُونَ } أَو إِن تدعوا المشركين إِلى الهدى لا يسمعوا دعاءَكم سماع قبول أَو تفهم ،  وتراهم ينظرون بأَعينهم إِليك وهم لا يبصرونك بقلوبهم ،  أَو لا يقبلون حجتك .
