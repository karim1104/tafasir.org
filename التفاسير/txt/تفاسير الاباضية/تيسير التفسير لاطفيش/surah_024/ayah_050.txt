{ أفى قُلوبهم مَرضٌ } إشراك { أم ارتابُوا } بل هل ارتابوا فى نبوته مع وضوح صحتها { أم يخافون } بل أيخافون { أن يحيف الله } يميل عن الحكم بالحق الى الحكم بالجور { عليهم ورسوله } لا ريبة لمشاهدتهم دلائل النبوة وامانته ، ولا حيف فتعين أن فى قلوبهم مرضاً ، ويجوز ان تكون ام متصلة أى أرأوا منه تهمة فزالت بتهمتهم .
