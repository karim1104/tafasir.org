{ حَتَّى إِذَا اسْتَيْأَسَ } أَى أَيس فهو لموافقة المجرد { الرُّسُلُ } تراخى نصر الرسل حتى استيأَسوا من النصر فى الدنيا ،  فمن وعد له بالنصر ولا يدرى فيها أَوفى الآخرة ،  أَو أَيسوا من إيمان الكفرة { وَظَنُّوا } أى أيقن الرسل { أَنَّهُمْ قَدْ كُذِبُوا } بلغ التكذيب غايته بأَن لا يعقبه نصر ،  أَو ظن الرسل توهمهم أَن لا ينصروا لذهولهم عن الوعد بالنصر لشدة الهول عليهم ،  أَو لتوهم أَن النصر على شرط لم يقع الشرط فلم يقع النصر { جَاءَهُمْ نصْرُنا } لهم على أَممهم المكذبة لهم بتنجيتهم وإهلاك تكذيبهم كما قال : { فَنُجِّىَ مَنْ نَشَاءُ } وهم الرسل وأَتباعهم { ولاَ يُردُّ بَأْسُنَا } عذابنا { عَنِ الْقَوْمِ المُجْرِمِينَ } المكذبين .
