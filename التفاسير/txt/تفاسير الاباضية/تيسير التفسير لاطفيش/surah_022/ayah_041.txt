{ الَّذين } نعت الذين أُخرجوا أو بدل منه ، أو مِنْ مَن أو منصوب أو مرفوع على المدح { إنْ مكنَّاهم فى الأرْضِ } فوَّيناهم على إنفاذ الأمر فى جنس الأرض أو فى أرض مكة { أقامُوا الصَّلاة } المكتوبة الخمس { واتُوا الزَّكاة } المالية الواجبة { وأمُروا } من خالف { بالمَعْروف } التوحيد والعبادة { ونَهوْا عن المْنكر } الشرك والمعاصى ، والآية على العموم ، وقيل لفظها فى المهاجرين ، والعبرة بعموم اللفظ لا بخصوص السبب { ولله } لا لغيره { عاقبة الأمُور } مرجعها الى حكمه ، وهذا تأكيد للوعد بالنصر .
