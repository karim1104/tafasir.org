{ هَذَا } مضمون ما ذكره من قوله : { ولا تحسبن } [ آل عمران : 169 ،  إبراهيم : 42 ] إلى هنا ،  أَو القرآن الذى هو هذه السورة ،  فإن بعض القرآن قرآن ،  أَو ما فيه أو ما فيها من العظة والتذكير { بَلاَغٌ لِلنَّاسِ } هو ما فيه كفاية فى الترهيب والترغيب ،  أَو كأَنه هذا مبلغ لهم إلى الخير إن عملوا به ،  فيكون بمعنى الوصف { وَلِيُنْذَرُوا بِهِ } عطف على محذوف أَى أَنزلناه ليبشروا به ولينذروا به ،  أَو لينصحوا ولينذروا { وَلِيَعْلَمُوا } بالتدبر فيه وفى سائِر الدلائِل { أَنَّمَا هُوَ } أى الله { إِلهٌ وَاحِدٌ } فلا يعبد سواه { وَلِيَذَّكَّرَ } يتذكر { أَولُوا الأَلْبَابَ } فيجعلوا لأَنفسهم عن النار درعا بالإِيمان والتقوى والعمل الصالح .

 وصلى الله على سيدنا محمد وآله وصحبه وسلم ،  ولا حول ولا قوة إلا بالله العلى العظيم .
