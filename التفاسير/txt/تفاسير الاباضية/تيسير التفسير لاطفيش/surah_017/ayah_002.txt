{ وَآتَيْنَا مُوسَى الْكِتَابَ } التوراة فى الطور بعد المناجاة ،  كما أنزلنا عليك الكتاب ،  وعرجنا بك ،  وهذا وجه الاتصال بما قيل ولا سواء ،  فانظركم بين { أسرى بعبده } [ الإسراء : 1 ] { وآتينا موسى } وانظركم بين { يهدى للتى هى أقوم } [ الإسراء : 9 ] وبين { هدى لبنى إسرائيل } وبين { خير أمة أُخرجت } [ آل عمران : 110 ] وبنى إسرائيل وبين { أسرى بعبده }

[ الإسراء : 1 ] { ولما جاء موسى لميقاتنا } [ الأعراف : 143 ] والعبودية لله تعالى وصف عظيم .

{ وَجَعَلْنَاهُ } أى الكتاب ،  أولى من أن يقال جعلنا موسى { هُدًى لِبَنِى إِسْرَائِيلَ } متعلق بهدًى ،  واللام للتقوية ،  أو نعت هدىً أو متعلق بجعلنا واللام للنفع ولا تقل للتعليل .

{ ألا تَتّخِذُوا مِنْ دُونِى وَكِيلاً } أن مفسرة لآتينا أو لجعلناه هدى ،  أو لهما فإن إيتاءه وجعله هدى تكليف بالامتثال والازدجار ،  وذلك معنى القول دون حروفه ،  ولا ناهية وإن ناصبة ،  ولا ناهية على تقدير الباء ،  أو على ،  ومعنى وكيلا ربًّا يعبدونه من دون الله ،  يتركون إليه أمرهم ،  أى موكولا إليه أمرهم فعيل بمعنى مفعول .
