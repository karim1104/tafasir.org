{ وَاتَّقُوا يَوْماً } عقاب يوم { لاَّ تَجْزِى } فيه { نَفْسٌ } مؤمنة أو مطلقا { عَنْ نَّفْسٍ } كافرة ،  أو مطلقا { شَيْئاً } أى جزاء ،  أو لا تدفع شيئاً { وَلاَ يُقْبَلُ مِنْهَا عَدْلٌ } فداء ،  لأنه يعادل المفدى { وَلاَ تَنْفَعُهَا شَفَعَةٌ } أى لا شفاعة لهم ،  فضلا عن أن تقبل ،  أو هو على ظاهره ،  إلا لمن أذن له ،  فقد روى أنه صلى الله عليه وسلم يقول :  "  أصيحابى ،  فيقال : لا تدرى ما أحدث هذا بعدك  "  { وَلاَ هُمْ يُنْصَرُونَ } يدفع العذاب عنهم .
