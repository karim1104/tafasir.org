{ اللهُ الَّذِي يُرْسِلُ الرِّيَاحَ فَتُثِيرُ } تحرك وتزعج .

{ سَحَاباً فَيَبْسُطُهُ فِي السَّمَآءِ كَيْفَ يَشَآءُ } اي فوقهم تارة متصلا كيف يشاء مسيرة يوم او يومين او اقل او اكثر وسائرا وواقفا الى غير ذلك .

{ وَيَجْعَلُهُ كِسَفاً } قطعا متفرقة تارة اخرى وقرأ ابن عامر ( كسفا ) باسكان السين مخففا او جمع كسفة او مصدرا وصف به مبالغة او تأويلا بوصف او بتقدير مضاف .

{ فَتَرَى الوَدْقَ } المطر .

{ يَخْرُجُ مِنْ خِلالِهِ } من وسطه متى كان مبسوطا ومتى كان كسفا .

{ فَإِذَا أَصَابَ بِهِ } بالودق .

{ مَن يَشَآءُ مِنْ عِبَادِهِ إِذَا هُمْ يَسْتَبْشِرُونَ } يفرحون به او يذكره بعض لبعض فرحا والمراد اذا اصاب به ارض من يشاء .
