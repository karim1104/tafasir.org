{ يَوْمَ } بدل من يوم أو حال من ميقات أو متعلق بيفصل محذوفاً دل عليه الفصل لا متعلق بالفصل ؛ لانه لا يفصل المصدر من معموله بأجنبي ولا يجوز تعليقه بمحذوف فعرف نعت لميقات ؛ لان النعت يسبق التوكيد على الراجح وأجازه القاضي لجواز تأخيره مرجوحاً أو لجعله { أَجمعين } حالاً { لاَ يُغْنِي مَوْلًى } من قرابة أو نصر أو عبودية وغيرها* { عَن مَّوْلًى } أي مولى كان* { شَيْئاً } قليلاً من اغناء وهو مفعول مطلق أي لا يغني عنه إغناء أو مفعول به أي لا يدفع عنه شيء من العذاب*

{ وَلاَ هُمْ يُنصَرُونَ } الضميران للمولى الأول ؛ لأنه نكرة في سياق النفي تعم .
