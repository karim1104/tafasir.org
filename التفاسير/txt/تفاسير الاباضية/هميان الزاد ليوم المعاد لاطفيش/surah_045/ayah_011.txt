{ وَلَهُمْ عَذَابٌ عَظِيمٌ هَذَا } القرآن* { هُدًى } من الضلالة ويدل على ان الاشارة ( القرآن ) قوله* { وَالَّذِينَ كَفَرُواْ بِآيَاتِ رَبِّهِمْ } لان آياته القرآن وتنكير هدى للتعظيم أي كامل في الهداية كقولك ( زيد رجل ) تريد الكمال .

{ لَهُمْ عَذَابٌ } لكفرهم* { مِّن رِّجْزٍ أَلِيمٌ } بجر ( أليم ) نعتاً ( لرجز ) وقرأ ابن كثير ويعقوب وحفص برفعه نعتاً ( لعذاب ) قيل : معنى { عَذَابٌ } حظ ؛ لأن ( الرجز ) هو العذاب أي ( عذاب ) من جملة العذاب أي حظ منه وقيل ( الرجز ) أشد العذاب
