{ يَسْمَعُ آيَاتِ اللهِ تُتْلَى عَلَيْهِ } حال من آيات* { ثُمَّ يُصِرُّ } يقيم على كفره* { مُسْتَكْبِراً } عن الايمان معجباً بما عنده ( والاصرار ) موجود حال السماع وبعده ،  وثم انما هي لاستبعاد الاصرار بعده .  وأصل الاصرار من اصرار الحمار العانة ( الأتان ) أن ينحى عنها صاراً أذنيه* { كَأَن } أي كأنه* { لَّمْ يسْمَعْهَا } والآية في النضر بن الحارث وما كان يثيره من أحاديث الأعاجم ويشغل به الناس عن سماع القرآن وقيل : في أبي جهل .  والحكم عام لكل من كان كذلك والجملة خبر ( كأَن ) المخففة المحذوف اسمها ضمير الشأن والمجموع حال من ضمير { يُصِرُّ } أو ضمير { مُسْتَكْبِراً } *

{ فَبَشِّرْهُ بِعَذَابٍ أَلِيمٍ } مؤلم وذلك لاصراره .  والتبشير حقيقة في الشر عند بعض ،  والمشهور انه حقيقة في الخير فقط فهو هنا مجاز للتهكم
