{ وَإِذَا قِيلَ } لكم يا كفار* { إِنَّ وَعْدَ اللهِ } بالبعث أو موعوده وهو البعث { حَقٌّ } لا خلف فيه* { وَالسَّاعَةُ لاَ رَيْبَ فِيهَا } يوم القيامة وذلك مبتدأ وخبر عطفاً على ان وما بعدها أو على محل ان واسمها وقرأ حمزة بالنصب عطفاً للساعة على وعد والجملة ( لاَ رَيْبَ فِيهِ ) على { حَقٌّ } ولو جعلنا حقاً غير وصف لان ذلك من العطف على معمولي عامل فالعاطف قام مقام العامل .

وقرأ ابن مسعود ( وان الساعة )* { قُلْتُم مَّا نَدْرِي مَا السَّاعَةُ } ( ما ) خبر ( والساعة ) مبتدأ .  وهذا أولى من العكس والجملة مفعول لأدري قامت مقام فعلين والمعلق ما استفهامية ، وهذا انكار منهم واستغراب* { إِن نَّظُنُّ إِلاَّ ظَنّاً } فيه دليل لاجازة التفريغ الى المصدر المؤكد ،  وأجيب بأنه نوعي أي ظناً ضعيفاً والتنكير للتحقير .

وقال المبرد : الاصل ( ان نحن الا نظن ظناً ) والمراد نفي ما عدا الظن وأكد هذا النفي بقوله { وَمَا نَحْنُ بِمُسْتَيْقِنِينَ } وذلك انهم يظنون ولا يتيقنون ،  ثم يغلب عليهم الجهل والكفر ويتركون ذلك الظن أو الظن ،  لما سمع لبعضهم من الآباء وما تليت عليهم من الآيات .
