{ وَأَمَّا الَّذِينَ كَفَرُواْ } جوابه محذوف أي فيقال لهم { أَفَلَمْ تَكُنْ آيَاتِي } أي قرآني { تُتْلَى } تقرأ* { عَلَيْكُمْ } والهمزة مما بعد الفاء العاطفة على محذوف ،  أي فيقال لهم ألم تأتكم فلم تكن آياتي فحذف القول والمعطوف عليه اكتفاء بالمقصود واستغناء بالقرينة .  وقال بعض المتأخرين الفاء من الجواب المقدر أي فيقال لهم ( ألم تكن ) حذف القول ومتعلقه وقدمت الهمزة على الفاء لتمام صدارتها .  قاله ابن هشام .

{ فَاسْتَكْبَرْتُمْ } تكبرتم عن الايمان بها وبما فيها { وَكُنتُمْ قَوْماً مُّجْرِمِينَ } عادتهم الاجرام أي الاشراك والذنوب العظام
