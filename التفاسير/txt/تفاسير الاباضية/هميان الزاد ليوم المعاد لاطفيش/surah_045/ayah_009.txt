{ وَإِذَا عَلِمَ مِنْ آيَاتِنَا } القرآن* { شَيْئاً اتَّخَذَهَا هُزُواً } حين العلم ؛ لأن ( اذا ) متعلقة ( باتخذ ) من غير أن يرى سبب الهزؤ وضمير النصب بجميع الآيات أي ( اذا سمع بآية خاض بالاستهزاء بجميع الآيات واثارة سماعها الى الاستهزاء بالكل أو لشيء ) لان المراد به آية كذا ظهر لي ثم رأيت الاول للزمخشري وأجاز كون جواب ( اذا ) محذوفاً ناب عنه ( اتخذ ) والاصل اذا علم ما يمكن التمسك به طعناً افترضه واتخذ آيات الله هزوا كاعتراض النضر في { انكم وما تعبدون } الخ وفي { شجرة الزقوم }

ويتخذون الآيات هزوا سواء علموا اللفظ أو اللفظ والمعنى أو الحقيقة لتصورهم كفرهم عناداً ،  ولو عرفوا الحقيقة خلافاً لمن قال : لو علموا الحقائق لآمنوا*

{ أُوْلَئِكَ لَهُمْ عَذَابٌ مُّهِينٌ } موقع في الهوان ،  والاشارة للأفاكين الآثمين .
