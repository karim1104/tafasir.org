{ فَأَوْجَسَ } أضمر* { مِنْهُمْ خِيفَةً } لانهم لم يأكلوا طعامه ظن انهم أرادوا سوءاً .

وعن ابن عباس وقع في نفسه انهم ملائكة أرسلوا لعذاب وعن عون ابن شداد أن جبريل مسح العجل بجناحه فقام يدرج حتى لحق بأمه فزال خوفه*

{ قَالُواْ لاَ تَخَفْ } انا رسل ربك* { وَبَشَّرُوهُ بِغُلاَمٍ عَلِيمٍ } يكثر علمه وقيل نبي وقرأ الحسن بنبي عليم والمراد اسحاق على الصحيح لان الصفة صفة سارة لا هاجر وقال مجاهد هو اسماعيل
