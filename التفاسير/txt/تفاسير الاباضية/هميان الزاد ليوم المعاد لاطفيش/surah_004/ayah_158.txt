{ بَل رَّفَعَهُ اللَّهُ إِلَيْهِ وَكَانَ اللَّهُ عَزِيزاً حَكِيماً }

{ بَلْ رَّفَعَهُ اللهُ إِلَيْهِ } : لأن مابعد العاطف لا يتقدم عليه ،  وهذه الجملة أيضا تأكيد لقوله : { فى شك } وكل ذلك تكذيب لهم .

{ وَكَانَ اللهُ عَزِيزاً } : غالبا فى أمره لايرد عنه ،  ومنه الانتقام وقد انتقم منه بملك رومى يسمى نيطوس قتل منهم مقتلة عظيمة .

{ حَكِيماً } : فى انجاء عيسى عليه السلام .
