{ وَاللَّهُ أَعْلَمُ بِأَعْدَائِكُمْ وَكَفَى بِاللَّهِ وَلِيّاً وَكَفَى بِاللَّهِ نَصِيراً }

{ وَاللَّهُ أَعْلَمُ } : منكم .

{ بِأَعْدَائِكُمْ } : فاحذروا من أعمالكم الله أنه عدوكم ،  كهؤلاء اليهود فما أرادوا بكم إلا هلاك الدين والدنيا والأخرى فلا تطمئنوا إليهم .

{ وَكَفَى بِاللَّهِ وَلِيّاً } : يلى أمركم فلا تضركم عداوتهم وبغضاؤهم وشدة مكرهم .

{ وَكَفَى بِاللَّهِ نَصِيراً } : ينصركم عليهم ،  فاكتفوا بولايته ونصره ولهذا أعاد الظاهر ،  فلم يقل : وكفى به والباء صلة فى فاعل { كفى } كما قررنا فى كتب النحو .
