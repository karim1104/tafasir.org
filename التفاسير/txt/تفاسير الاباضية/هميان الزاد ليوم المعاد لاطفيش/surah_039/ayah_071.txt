{ وَسِيقَ } سوقاً عنيفاً مبني للمفعول من ساق يسوق* { الَّذِينَ كَفَرُواْ إِلَى جَهَنَّمَ زُمَراً } أي ( أمماً ) كل أمة وحدها وقيل جماعات جماعة اثر جماعة على تماديهم في الضلالة والمفردة زمرة وقيل الزمرة الجماعة القليلة والاشتقاق من الزمر وهو الصوت لان الجماعة لا تجلو عنه أو من قولهم شاة زمرة قليلة الشعر ورجل زمر قليل المروءة .

{ حَتَّى إِذَا جَآءُوهَا فُتِحَتْ أَبْوَابُهَا } السبعة ليدخلوها وانما فتحت بعد مجيئهم لا قبله وأوقفوا بعد فتحها اذلالا لهم كما هو حال المسجونين يجاء بهم الى السجن فيوقفون يهددون وابقاء لحرها وحتى للابتداء وقرأ الكوفيون ( فتحت ) بالتخفيف على الأصل أما التشديد فللمبالغة .

قال ابن هشام وزعم الأخفش ان ( اذا ) جر ( بحتى ) * { وَقَالَ لَهُمْ خَزَنَتُهَآ } توبيخاً وتعزيراً* { أَلَمْ يَأْتِكُمْ رُسُلٌ مِّنكُمْ } من جنسكم وبعض منكم ظاهرون لكم تفهمون كلامهم لا من الملائكة أو الجن فتهابون ولا تفهمون وقرئ ( ألم يأتكم نذر منكم ) .

{ يَتْلُونَ عَلَيْكُمْ آيَاتِ رَبِّكُمْ وَيُنذِرُونَكُمْ لِقَآءَ يَوْمِكُمْ هَذَا } ( هذا ) بدل من ( يوم ) أو مفعول ( للقاء ) مشاراً به للعذاب والمراد باليوم الوقت وهو وقت دخولهم النار وكثيراً ما يستعمل اليوم في مطلق الوقت ولا سيما أوقات الشدة ويصح خلافا للزمخشرى أن يراد يوم القيامة فان وقت دخولهم منه وقد أنذروا به وما يقع فيه واعلم انه لولا الرسل ما قطع عذر الكفار ولكن حيث وجد رسول قطع عذر من لم يكن على دين من طرق الانبياء ولو لم يبلغه دين ذلك النبي فأهل الفترة والجاهلية مقطوعو العذر لتقدم الأنبياء عليهم السلام واما تعليل توبيخهم باتيان الرسل وتبليغ الكتب فالتأكيد زيادة في الحجة لانه لا تكليف الا بالسماع* { قَالُواْ بَلَى } أتونا وتلوا علينا .

{ وَلَكِنْ حَقَّتْ كَلِمَةُ الْعَذَابِ } وجبت وكلمة العذاب قول الله فيهم بالشقاوة وحكمه بها لسوء أعمالهم وقيل قوله : { عَلَى الْكَافِرِينَ } الأصل علينا وبه ينطقون كما قالوا : { ربنا غلبت علينا شقوتنا }

ووضع الظاهر موضعه ليصرح بالكفر اشعاراً بأنه علة كلمة العذاب وذلك أن قوله ( ولكن ) .  .  .  الخ من كلامهم أما لو قلنا من كلامه تعالى فالأصل عليهم وعبر بالظاهر لما تقدم
