{ أَوْ تَقُولَ حِينَ تَرَى الْعَذَابَ } عياناً* { لَوْ } حرف تمن { أَنَّ لِي كَرَّةً } رجعة الى الدنيا مصدر ( كرّ ) دال على الوحدة* { فَأَكُونَ } النصب في الجواب التمنى وهو دليل على أن ( لو ) للتمنى قاله بعض ،  وقال ابن هشام : لا دليل فيه لجواز عطف مصدر ( أكون ) على ( كرة ) وجعل ( لو ) شرطية والجواب محذوف أي لنجوت من العذاب أو نحو هذا* { مِنَ الْمُحْسِنِينَ } من المؤمنين أو من الذين أحسنوا اعتقادا وفعلا وهم المؤمنون و ( لو ) في ذلك لمنع الخلوي أي لا بد أن تقول شيئاً من ذلك لتحيرها ولاكتسابها العذر بما لا يغني لا لمنع الجمع لجواز أن تقول ذلك كله
