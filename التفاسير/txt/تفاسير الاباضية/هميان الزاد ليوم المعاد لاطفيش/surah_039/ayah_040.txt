{ فَسَوْفَ تَعْلَمُونَ مَن يَأْتِيهِ عَذَابٌ يُخْزِيهِ } صفة عذاب أي يذله ويهينه ( ومن ) موصولة وفعول تعلم بمعنى تعرف أو استفهامية مبتدأ ويأتيه عذاب خبره والجملة سدت مسد مفعولي ( تعلم ) وعلق بالاستفهام أو مفعول تعلم بمعنى ( تعرف ) وقد أتاهم عذاب أخزاهم يوم بدر وغيره* { وَيَحِلُّ } ينزل* { عَلَيْهِ عَذَابٌ مُّقِيمٌ } دائم وهو عذاب النار
