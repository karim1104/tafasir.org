وللحصر المذكور قال : { فَاعْبُدُواْ مَا شَِئْتُم مِّن دُونِهِ } زجر وتهديد وتوبيخ وهو مبالغة فى الخذلان حيث خلاهم وعبادة ما شاء والمهلكة لهم واشعار بأنهم لا يعبدون الله وكمل الزجر بقوله* { قُلْ إِنَّ الْخَاسِرِينَ } هم* { الَّذِينَ خَسِرُواْ أَنفُسَهُمْ } أي أن الكاملين فى الخسران وأسبابه هم الذين خسروا أنفسهم بالقائها في النار* { وَأَهْلِيهِمْ يَوْمَ الْقِيَامَةِ } أي هذا الاهل من الأزواج والخدم في النار هم الذين خسروا باضلالهم فأوقعوهم في النار مع أنفسهم وان كان هذا الأهل من أهل الجنة فقد خسروه بممارقته أبداً وقيل المراد بالأهل الأهل في الجنة ،  كما قال ابن عباس ( جعل الله لكل انسان منزلاً وأهلاً في الجنة فمن أطاع كانا له ومن عصى خسرهما ودخل النار ) وعلامة نصب ( أهليهم ) الياء ملحق بالزيدين ووصف خسرانهم بغاية الفظاعة بقوله :

{ أَلاَ ذَلِكَ هُوَ الْخُسْرَانُ الْمُبِينُ } حيث جدد جملة مستقلة لذمه وجعلها اسمية للتأكيد وأتى فيها بألا التي للتنبيه وتوكيد مضمون الجملة وعرف طرفين للحصر وأكد بضمير الفعل وحصر به أيضاً ونعت الخسران بالمبين وبين ذلك الخسران بقوله : { لَهُم مِّن فَوْقِهِمْ ظُلَلٌ }
