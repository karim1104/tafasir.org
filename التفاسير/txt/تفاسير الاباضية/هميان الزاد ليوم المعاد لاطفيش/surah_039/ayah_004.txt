{ لَّوْ أَرَادَ اللهُ أَن يَتَّخِذَ وَلَداً } كما زعموا { لاَّصْطَفَى } أي اختار { مِمَّا يَخْلُقُ مَا يَشَآءُ } فيختار الذكور لا الاناث لكنه لم يرد اتخاذ الولد لانه محال ولو أراد الله اتخاذ الولد لاصطفى بعض خلقه واختاره وقربه كما يختص الرجل ولده ويقربه اصطفاء بدل اتخاذ الولد لامتناعه وكونه محالاً لمخالفته تعالى للاجسام والاعراض كأنه قال لو أراد اتخاذ الولد لم يزد على هذا الاصطفاء والتقريب ولم يرد عنه راد وقد اصطفى الملائكة وقربهم* { سُبْحَانَهُ } تنزيها له عما لا يليق كاتخاذ الولد والشريكة* { هُوَ اللهُ الْوَاحِدُُ } ذاتاً وفعلاً وصفة ولو كانت له زوجة لم يكن واحداً لانها  حاشاه  تكون من جنسه ومثله ولا جنس له ولا مثل فلا ولد له اذا لم تكن له صاحبة* { الْقَهَّار } الغلاب لكل شيء فكيف يكون له شركاء والقاهرية المطلقة تنافي قبول الزوال المحوج الى الولد
