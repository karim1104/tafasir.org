{ قالَ } وقرأ حمزة والكسائي ( قيل ) وابن كثير ( قل ) { إِن لَّبِثْتُمْ إِلاَّ قَلِيلاً } زمانا أو لبثا قليلا بالنسبة إلى ما تلبثون في النار فانها انقضاء لها وذلك تصديق لهم * { لَوْ } ثبت * { أَنَّكُمْ كُنتُمْ تَعْلَمُونَ } كم تلبثون في النار أو ما لبثتم الا قليلا بالنسبة لو تعلمون مقدار لبثكم من الطول في الدنيا .
