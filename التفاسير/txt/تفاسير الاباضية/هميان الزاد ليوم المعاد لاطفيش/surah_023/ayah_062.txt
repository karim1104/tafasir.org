و { لاَّ نُكَلِّفُ نَفْساً إِلاَّ وُسْعَهَا } قدر طاقتها فما وصف به الصالحون ليس يخرج فالقصور عنه لا ينبغي فافعلوا ما فعلوا ومن لم يبلغ ان يكون صفتهم بعد استفراغ وسعه وبذل طاقته فلا عليه فمن لم يستطع ان يصلي قائما فليصل قاعدا أو لم يستطع فمضطجعا ومن لم يستطع ان يصوم فلياكل وهكذا * { وَلَدَيْنَا كِتَابٌ يَنطِقُ بِالحَقِّ } بما عملته كل نفس وهو اللوح المحفوظ تسطر فيه الاعمال أو كتاب كل نفس أو الديوان الجامع لاعمال كل نفس المكتوبة في كتابها غير اللوح المحفوظ ونفى بقوله : ( بالحق ) ان تكون فيه زيادة أو نقص { وَهُمْ } اي الناس المدلول عليهم بذكر النفس في سياق النفي { لاَ يُظْلَمُونَ } بنقص من الحسنات أو زيد في السيئات .

وقيل : المراد بالكتاب القرآن .
