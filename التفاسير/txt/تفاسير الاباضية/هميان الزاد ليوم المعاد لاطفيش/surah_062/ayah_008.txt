{ قُلْ إِنَّ المَوْتَ الَّذِى تَفِرُّونَ مِنْهُ } وتخافون أن تتمنوه بألسنتكم مخافة أن يصيبكم فتؤخذوا بأعمالكم { فَإِنَّهُ مُلاَقِيكُمْ } لا تفوتونه والجملة خبر وقرنت بالفاء لكون اسم ان موصوفا بالموصول حتى كان فرارهم سبب للحوقه بهم وقد قرأ زيد بن علي باسقاط الفاء ويجوز كون الخبر هو الذي وقرأ ابن مسعود قل ان الموت الذي تفرون منه ملاقيكم وإذا كان الموصول خبرا فالفاء عاطفة أو استئنافية .

{ ثُمَّ تُرَدُّونَ إِلَى عَالِمِ الغَيْبِ } السر { وَالشَّهَادَةِ } العلانية الرد لبعث يوم القيامة { فَيُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ } ومن لازم التنبئة الجزاء .
