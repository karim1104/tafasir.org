{ وَنَزَعْنَا } أخرجنا .

{ مِن كُلِّ أُمَّةٍ شَهِيداً } وهو رسولهم يشهد عليهم بما كانوا عليه من شرك وتوحيد .

{ فَقُلْنَا } لهم .

{ هَاتُوا بُرْهَانَكُمْ } على ما قلتم من الاشراك .

{ فَعَلِمُوا } حينئذ .

{ أَنَّ الحَقَّ } في الألوهية .

{ وَضَلّ عَنْهُم } غاب عنهم غيبة الضائع .

{ مَّا كَانُوا يَفْتَرُونَ } من الباطل من الأوثان التي يعبدونها .
