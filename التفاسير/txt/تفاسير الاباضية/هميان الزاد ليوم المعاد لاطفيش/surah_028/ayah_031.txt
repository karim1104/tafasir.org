{ وَأَنْ أَلْقِ عَصَاكَ } فألقاها واهتزت .

{ فَلَمَّا رَآهَا تَهْتَزُّ } تتحرك .

{ كَأَنَّهَا جَانٌّ } أي حية في الهيئة والخفة او في السرعة وقد مر ذلك .

{ وَلَّىَ مُدْبِراً } حال مؤكدة لعاملها وهو ولي فان التولية والادبار بمعنى وهو الرجوع الى خلف او توليتك ظهرك لغيرك مع الذهاب وقيل مدبرا بمعنى هاربا استعمالا للعام في الخاص فالحال مؤسسة .

{ وَلَمْ يُعَقِّبْ } لم يرجع اليها بعد توليه وادباره وقيل لم يلتفت وكان يراها تبلع الصخور والعظام والشجر العظام ويسمع صرير اسنانها والدخان خارج من ذلك .

{ يَا مُوسَى } أي فقيل له يا موسى .

{ أَقْبِلْ } أيتها .

{ وَلا تَخَفْ إِنَّكَ مِنَ الآمِنِينَ } عن المخاوف فانه لا يخاف لدي المرسلون .
