{ وَقَالَتْ لأُخْتِهِ } واسمها مريم .

{ قُصِّيهِ } اتبعي أثره حتى تعلمي خبره .

{ فَبَصُرَتْ } أي الأخت .

{ بِهِ } أي اتصل نظرها به ،  والباء للإلصاق المجازي وقرأ بعض بكسر الصاد .

{ عَن جُنُبٍ } أي عن بعد أو باختلاص تنظر إليه كأنها لا تريده بالنظر ،  وقرىء بإسكان النون وقرىء عن جنابة أي بعد وعن جانبه .

{ وَهُمْ لا يَشْعُرُونَ } أي والناس لا يشعرون انها أخته وأنها ترفيه .
