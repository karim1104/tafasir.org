{ وَقِيلَ ادْعُوا شُرَكَاءَكُمْ } الأصنام التي تعبدونها وتزعمون انها شركاء الله .

{ فَدَعَوْهُمْ } لشدة حيرتهم .

{ فَلَمْ يَسْتَجِيبُوا لَهُمْ } لعجزهم عن الاجابة والنصر .

{ وَرَأَوُا العَذَابَ } أبصروه .

{ لَوْ أَنَّهُمْ كَانُوا } في الدنيا .

{ يَهْتَدُونَ } للاسلام جواب لو محذوف اي ما ابصروه ويجوز كون لو للتمني ويقدر القول اي وقالوا ليتنا اهتدينا فيكون بين قالوا .

و { لَوْ أَنَّهُمْ كَانُوا } الخ التفات السكاكي ويجوز ان يراد وانهم يهتدون اليوم لحيلة يدفعون بها العذاب .
