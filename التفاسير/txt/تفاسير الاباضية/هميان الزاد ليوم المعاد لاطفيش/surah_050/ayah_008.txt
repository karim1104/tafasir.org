{ تَبْصِرَةً } أي تبصيراً كما هو القياس وهو مفعول لاجله لمحذوف أي فعلنا ذلك تبصرة* { وَذِكْرَى } أي مذكراً أو مفعول لاجله لانبتنا ويقدر مثله لما سبق* { لِكُلِّ عَبْدٍ مُّنِيبٍ } مخلص راجع الى طاعتنا مفكر في بدائع خلقنا وقرئ برفع ( تبصره وذكرى ) رفعاً ظاهراً في ( تبصره ) مقدراً فى ( ذكرى ) خبر لمحذوف أي خلقها تبصرة وذكرى باسكان اللام
