{ فَادْخُلُوا أَبْوَابَ جَهَنَّمَ } كلها على التوزيع يدخل كل صنف منهم الباب المعد له منها المستوجب عمله الدخول منه وقيل أبواب جهنم أُصناف عذابها { خَالِدِينَ } مقدرين الخلود { فِيهَا } أي في جهنم فالضمير عائد على المضاف إِليه وعائد إِلى الأَبواب بمعنى الطبقات أو أصناف العذاب { فَلَبِئْسَ مَثْوَى } موضع الثواء وهو الإِقامة { الْمُتَكَبِّرِينَ } عن الإِيمان والمخصوص بالذم محذوف أي جهنم وها هنا تم جواب الملائكة .
