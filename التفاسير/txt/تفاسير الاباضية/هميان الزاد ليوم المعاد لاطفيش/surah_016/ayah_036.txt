{ وَلَقَدْ بَعَثْنَا في كُلِّ أُمَّةٍ رَّسُولاً } يدعوهم إِلى الإِيمان كما بعثناك في هؤلاء { أَنِ اعْبُدُوا اللهَ } أن تفسيريه فإِن في البعث معنى القول دون حروفه وقيل مصدرية بتقدير الياء { وَاجْتَنِبُوا الطَّاغُوتَ } أي اتركوا عبادة الطاغوت وهو ما عبد من دون الله وقيل الطاغوت الشيطان وهو الداعي لعبادة غير الله { فَمِنْهُم مَّنْ هَدَى } وفق { اللهُ } إِلى الإِيمان بإرشادهم { وَمِنْهُم مَّنْ حَقَّتْ } وجبت { عَلَيْهِ الضَّلاَلَةُ } لعدم التوفيق وذلك دليل على أن الهادي والمضل هو الله وأشار إِلى ذلك بقوله { إِن تحرص على هداهم } إلى آخره وعلى فساد قولهم أنه لو كان فعلهم قبيحا لما شاء الله صدوره منهم { فَسِيرُوا فِى الأَرْضِ } يا كفار مكة أو معشر قريش { فَانظُرُوا كَيْفَ كَانَ عَاقِبَةُ الْمُكَذِّبِينَ } لرسلهم قبلكم كعاد وثمود لعلكم تتعظون بما ترون من سراف منازلهم بالهلاك .
