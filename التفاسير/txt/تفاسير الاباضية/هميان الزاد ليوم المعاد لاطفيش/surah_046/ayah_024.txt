{ فَلَمَّا رَأَوْهُ } ( الهاء ) للعذاب أو الى ( ما ) من قوله بما تعدنا أو الى ( عارضاً ) ( وعارضاً ) تمييز وحال وبدل من الهاء وهذا أغرب وأفصح وهو مما يعود فيه الضمير بما بعده لفظاً ورتبة* { عَارِضاً } سحاباً عرض في أفق السماء سمي لانه يمنع من رؤية السماء والقمرين والنجوم وقيل : العارض الذى يعرض في ناحية ثم يطبق السماء*

{ مُّسْتَقْبِلَ أَوْدِيَتِهِمْ } متوجهاً اليها واضافته لفظية لانه للحال على ذلك المعنى أو للاستقبال أي آتياً وارداً أي سيمطرهم فلذلك وقع نعتاً لنكرة وكذا في { قَالُواْ هَذَا عَارِضٌ مُّمْطِرُنَا } وممطر للاستقبال فقط جاءهم من جانب واد يمطرون منه لا من غيره يقال له المغيث جاء سحابة سوداء وقد حبس عنهم المطر مدة طويلة ففرحوا شديداً وقال لهم هود ليس كما ترون*

{ بَلْ هُوَ مَا اسْتَعْجَلْتُمْ بِهِ } استهزاء فأضمر القول ويدلل له قراءة ابن مسعود وقال : ( هو دليل ) الخ وقرئ ( قل بل ) الخ أي قال الله ( قل بل هو ما استعجلتم به من العذاب )* { رِيحٌ } بدل من ماء أو خبر لمحذوف أي هو ريح أو هي ريح بالتأنيث للاخبار بالمؤنث لجواز نعت الريح
