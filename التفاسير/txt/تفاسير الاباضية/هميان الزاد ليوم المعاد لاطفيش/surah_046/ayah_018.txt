{ أُوْلَئِكَ الَّذِينَ حَقَّ } وجب* { عَلَيْهِمُ الْقوْلُ } بالعذاب { فِي أُمَمٍ } في جملة أمم أو مع أمم ومر مثله* { قَدْ خَلَتْ مِن قَبْلِهِم مِّنَ الْجِنِّ وَالإِنسِ } بيان للأمم فان بعض الجنس يسمى باسمه أو تبعيضه والآية دليل على موت الجن مثلنا لا مرة وهو الصواب*

{ إِنَّهُمْ كَانُواْ خَاسِرِينَ } تعليل جملي لحق القول أي كافرين أو ذم لهم واخبار بعقابهم
