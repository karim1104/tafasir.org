{ فَلَوْلاَ } حرف تحضيض*

{ نَصَرَهُمُ الَّذِينَ اتَّخَذُواْ مِن دُونِ اللهِ قُرْبَاناً آلِهَةً } هلا منعتهم آلهتهم من الاهلاك الذين يتقربون بهم الى الله { ويقولون هؤلاء شفعاؤنا عند الله }

وأول مفعولي ( اتخذ ) محذوف رابط للصلة أي ( اتخذوهم ) وثانيهما قرباناً وآلهة بدل أو بيان أو ثانيهما آلهة وقرباناً حال أو مفعول لاجله على انه بمعنى التقرب قاله القاضي وقال الزمخشري : لا يصح كون { قُرْبَاناً } مفعولاً ثانياً ( وآلهة ) بدلاً لفساد المعنى قيل أي لأن الآلهة لا تتخذ قرباناً بل يتقرب اليها وقال ابن هشام لانهم اذا ذموا على اتخاذهم قرباناً من دون الله اقتضى مفهومه الحث على أن يتخذوا الله قرباناً دون الآلهة كما انك اذا قلت لا تتخذ فلاناً معلماً من دوني كنت آمراً له أن يتخذك معلماً دونه والله يتقرب اليه بغيره لا الى غيره وقرئ بكسر القاف والقربان كل ما يتقرب به الى الله* { بَلْ ضَلُّواْ } أي غابت الالهة* { عَنْهُمْ } عند نزول العذاب والمراد عدم النفع لهم كانهم لم يحضروا* { وَذَلِكَ إِفْكُهُمْ } كذبهم والاشارة الى الإتخاذ أي وذلك الاتخاذ أثر افكهم وقرئ ( افكهم ) بالفعل أي ( جعلهم افكين وصرفهم عن الحق ) وبالفعل مشدداً للمبالغة*

{ وَمَا كَانُواْ يَفْتَرُونَ } أو وكونهم يفترون وأجاز بعض كون ما بمعنى الذي والرابط محذوف أي يفترون فيه أو يفترونه
