{ لَهُ مَا فِي السَّمَوَاتِ وَمَا فِي الأَرْضِ } خبره وعلى الأوجه الاخرى مستأنفة لتقرير عزته وحكمته وقوله { وَهُوَ الْعَلِيُّ الْعَظِيمُ } عطف على التي قبلها أو استئناف وعن بعضهم ان تقدير ( يوحي ) الخ ( يوحي اليك والى الذين من قبلك اخبار الغيب ) والعزيز في ملكه والحكيم في صنعه و { له ما في السموات وما في الأرض } ملكاً وخلقاً وعبيداً و { العليّ } على خلقه و { العظيم } الكبير
