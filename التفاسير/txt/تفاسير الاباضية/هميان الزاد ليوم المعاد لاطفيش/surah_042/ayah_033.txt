{ إِن يَشَأْ يُسْكِنِ الرِّيحَ } وقرأ بعض القراء غير نافع ( الريح ) بالافراد { فَيَظْلَلْنَ } أي السفن أي يصرن أو يبقين مدة النهار أو غيره والأصل مدة النهار يستعمل فيما دونها وفى غيره* { رَوَاكِدَ } ثوابت لا تجري* { عَلَى ظَهْرِهِ } أي ظهر البحر ويظللن بالفتح مضارع ظل أصله ظلل بالكسر مضارع ضلل بالفتح .

{ إِنَّ فِي ذَلِكَ لأَيَاتٍ لِكُلِّ صَبَّارٍ } على بلاء الله* { شَكُورٍ } لنعمائه وذلك هو المؤمن فانه هو الموصوف بالصبر على شدة البلاء والشكر فى الرضاء والرخاء فهو كامل الايمان لان الايمان نصفه صبر ونصفه شكر وفى الآية مدح له وقيل : المراد لكل من ترك همته وحبس نفسه على النظر فى آيات الله
