{ قَالَ } يا { رَبِّ فَأَنظِرْنِى } أي أخرني ولا تمتني { إِلَى يَوْمِ يُبْعَثُونَ } أي الناس والجملة نعت والرابط محذوف أي فيه ان ينون ( يوم ) وان لم ينون فالجملة مضاف اليه ولا حذف .

قال أبو عمرو عثمان بن سعيد آيات ( ص ) ست { ولي نعجة } { وما كان لي من علم } فتحهما حفص { إني أحببت } فتحها الحرميان وأبو عمرو : { مسني الشيطان } سكنها حمزة { لعنتي إلى } فتحها نافع .
