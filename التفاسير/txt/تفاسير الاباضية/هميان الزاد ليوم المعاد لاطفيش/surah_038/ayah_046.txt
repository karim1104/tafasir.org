{ إِنَّآ أَخْلَصْنَاهُم } أي جعلناهم خالصين لنا أي اصطفيناهم* { بِخَالِصَةٍ } أي بخصلة خالصة لا شوب فيها واضافتها لقوله { ذِكْرَى الدَّارِ } للبيان أي هي ذكر الدار أو خالصة مصدر بمعنى الخلوص أضيف لفاعله .

وقرأ غير نافع وهاشم بتنوين ( خالصة ) فذكرى بدل أو خبر لمحذوف أو مفعول لمحذوف والدار الآخرة حتى لا يشوبهم هم سواها وانما أطلق الدار فتعرف انها الاخرة لان الاخرة هي الدار الحقيقية وأما الدنيا فمعبر وباء ( خالصة ) للسببية أي أخلصناهم بسبب هذه الخصلة وبأنهم من أهلها وأخلصناهم بتوفيقهم لها واللطف بهم في اختبارها ،  وقيل أخلصناهم لذكر الله والدعاء اليه والى الآخرة وقيل : أخلص بأفضل ما في الآخرة وقيل : المراد بالدار الدنيا وذكرها الثناء الجميل عليهم من الناس وقرئ ( بخالصتهم ) وقيل : الذكر القرآن وهو ضعيف
