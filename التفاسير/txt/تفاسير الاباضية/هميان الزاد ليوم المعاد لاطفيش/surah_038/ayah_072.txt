{ فَإِذَا سَوَّيْتُهُ } أتممت خلقه وعدلته { وَنَفَخْتُ } أجريت* { فِيهِ مِن رُّوحِى } أي من الروح التى خلقتها اجعلها في خلقي وملكتها فالاضافة للملك على سبيل التشريف كما نقول ( بيت الله ) ولست تريد انه فيه و ( ناقة الله ) ولست تريد انه يفعل بها ما يفعل الخلق والروح جوهر شريف لطيف يحيا به الانسان بنفوذه فيه يسري فيه سريان الضوء في الفضاء والنار في الفحم* { فَقَعُواْ } الفاء رابطة وقعوا أمر من وقع أي فخروا* { لَهُ سَاجِدِينَ } سجود تحية وتعظيم بالانحناء أي فخروا مطأطئين تعظيماً له أو اخضعوا له في أحوالكم وعظموه أو اسجدوا لله الى جهته تعظيماً كما يسجد الى الكعبة
