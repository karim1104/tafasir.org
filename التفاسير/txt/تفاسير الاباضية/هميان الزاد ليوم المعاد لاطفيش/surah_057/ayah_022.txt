{ مَا أَصَابَ } مفعوله محذوف أي احدا أو شيئا .

{ مِن مُّصِيبَةٍ } فاعل ومن صلة أو فاعل أصاب الله ومصيبة مفعول به أي ما أحدثها { فِى الأَرْضِ } من جدب وعاهة في الشجر والنبات { وَلا فِى أَنفُسِكُمْ } كمرض وموت { إِلا فِى كِتَابٍ } اللوح المحفوظ مكتوبة فيه مشيئة في علم الله عز وجل { مِّن قَبْلِ أَن نَّبْرَأَهَا } نخلقها والضمير للمصيبة والارض والانفس وقيل للانفس والمصيبة وقال ابن عباس : للمصيبة أو قيل : لاحدى ذلك وقيل : للانفس وقيل : للارض وقيل : للسماوات والارض .

{ إِنَّ ذَلِكَ } على كثرته وعسره عند الخالق أي اثبات ذلك في اللوح وتصريفه وقيل خلق ذلك وحفظه { عَلَى اللهِ يَسيِرٌ } هين سهل لأنه غني عن عدة ومدة .
