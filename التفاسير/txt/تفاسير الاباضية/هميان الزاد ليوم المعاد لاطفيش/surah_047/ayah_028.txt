{ ذَلِكَ } التوفي { بِأَنَّهُمُ } أي لانهم { اتَّبَعُواْ مَآ أَسْخَطَ اللهَ } وهو الكفر وكتمان أهل الكتاب نعت رسول الله صلى الله عليه وسلم*

{ وَكَرِهُواْ رِضْوَانَهُ } ما يرضاه من الايمان والجهاد وغيرهما من الطاعات* { فَأَحْبَطَ أَعْمَالَهُمْ } لاجل ذلك ولم تكن لله لان تأدية الفرض من جملة اتباع الهوى اذا ترك الفرض الآخر لا من العمل لله
