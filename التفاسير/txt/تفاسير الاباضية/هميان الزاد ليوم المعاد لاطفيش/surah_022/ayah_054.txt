{ وَلِيَعْلَمَ الذِّينَ أُوتُوا الْعِلْمَ } التوحيد والقرآن والتصديق بالنسخ * { فَيُؤْمِنُوا بِهِ } بالقرآن أو بالله { فَتُخْبِتْ } تطمئن * { لَهُ قُلُوبُهُمْ } بالانقياد والخشية وقيل : تخشع { وَإِنَّ اللَّهَ لَهَادِ الَّذِينَ آمَنُوا } فيما اشكل { إِلَى صِرَاطٍ } طريق { مُّسْتَقِيمٍ } هو دين الاسلام فلا تزل اقدامهم بالمشكل المتشابه بل يهديهم إلى تأويله بما تقتضيه الاصول المحكمة .

وقرئ لهاد بالتنوين كقاض فالذين مفعول له .
