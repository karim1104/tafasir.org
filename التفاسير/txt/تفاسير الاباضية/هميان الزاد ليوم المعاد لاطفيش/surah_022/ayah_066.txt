{ وَهُو الَّذِي أَحْيَاكُمْ } بالانشاء من نطفة { ثُمَّ يُمِيتُكُمْ } لآجالكم { ثُمَّ يُحْيِيكُمْ } بالبعث للثواب والعقاب * { إِنَّ الإِنسَانَ } المشرك * { لَكَفُورٌ } لنعم الله بترك التوحيد والطاعة وفعل المعاصي ولا يبعد ان يراد بالانسان المشرك والمنافق صاحب الكبيرة وبالكفر كفر النعمة بان لا يشكرها وكفر الشرك فالمراد مطلق الكفر .
