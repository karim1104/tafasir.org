{ ذَلِكَ } النصر ايضا أو ذلك الوصف بكمال القدرة والعلم { بِأَنَّ اللَّهَ هُوَ الحَقُّ } الثابت في نفسه الواجب لذاته وحده ووجوب وحدانيته وذاته يقتضي ان يكون منشئا لما سواه عالما بذاته وبما عداه أو الثابت الالهية ولا يصلح لها الا القادر العالم { وَأَنَّ مَا يَدْعُونَ } تعبدون أو تسألون وهو الاصنام والخطاب للمشركين وهذه قراءة ابن عامر وابي بكر والحرميين نافع وابن كثير وقرأ الباقون بالتحتية وقرأ اليماني بها مع البناء للمفعول فتكون الواو راجعة لما واقعة على الاصنام لانها عندهم آلهة بمنزلة العقلاء * { مِن دُونِهِ هُوَ البَاطِلُ } زائل لا ينفع ولا يضر أو باطل الالوهية فكيف يدعي وقيل : المراد بما يدعون من دون الله هو ابليس * { وَأَنَّ اللهَ هُوَ العَلِي } على كل شيء شأنا وقدرة { الكَبِيرُ } سلطانا أو المتنزه عن ان يكون له شريك .
