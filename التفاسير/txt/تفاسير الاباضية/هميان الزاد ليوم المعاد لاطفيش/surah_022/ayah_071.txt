{ وَيَعْبِدُونَ مِن دُونِ اللَّهِ مَا لَمْ يُنَزِّلْ } الله { بِهِ سُلْطَاناً } حجة تدل على جواز عبادته من السمع { وَمَا لَيْسَ لَهُمْ بِهِ عِلْمٌ } ضروري أو عقلي أنه آلة والمراد الاصنام { وَمَا لِلظَّالِمِين } بالشرك وهو ظاهر في موضع الضمير تشنيعا عليهم بالظلم { مِنْ نَّصِيرٍ } يثبت دينهم أو يدفع العذاب عنهم .
