{ وَلِبُيُوتِهِمْ أَبْوَاباً } أي وجعلنا لبيوتهم أبواباً من فضة أو عطف على معمولي عامل ويراعى المبدل منه في ذلك فانهم { وَسُرُراً عَلَيْهَا يَتَّكِئُونَ } أي وجعلنا لهم سرراً أو معطوف على { أَبْوَاباً } كما تقول جعلت للدار خادماً مع انه يخدم أهلها لا نفسها و { سُرُراً } جمع سرير وهو نوع من الكراسي وقرئ ( سرراً ) بفتح الراء لاستثقال الضمتين مع حرفي التضعيف
