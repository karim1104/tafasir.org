{ وَالَّذِي خَلَقَ الأَزْوَاجَ كُلَّهَا } أي الأصناف كالشتاء والصيف والليل والنهار والأرض والسماء وكل واحد زوج لا كل اثنين كما قيل وعن بعض كل ما سوى الله فهو زوج والفرد الله* { وَجَعَلَ } أي خلق* { لَكُم مِّنَ الْفُلْكِ } أي السفن* { وَالأَنْعَامِ } كالابل { مَا تَرْكَبُونَ } ركوب السفينة يتعدى بفي وركوب الدابة بنفسه ويعدي الركوب هنا بنفس أي تركبونه تغليباً لركوبها على ركوب السفينة ووجه التغليب ان التعدي بالنفس أصل للتعدي بالحرف وان السفن مصنوعة للركوب والدابة مخلوقة له أو ان ركوب السفينة قليل والدابة كثير كذا قيل وليس هذا مطرداً فى الازمان والاماكن وقد يقال التحقيق ان ركوب السفينة يجوز تعديه بنفسه فلا تغليب ( ومن ) للتبعيض أو البيان
