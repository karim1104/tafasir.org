{ إِنَّكَ عَلَى كُلِّ شَىْءٍ قَدِيرٌ0يَا أَيُّهَا النَّبِىُّ جَاهِدِ الكُفَّارَ } بالسيف { وَالمُنَافِقِينَ } بالحجة { وَاغْلُظْ عَلَيْهِم } أي على الكفار والمنافقين أي استعمل معهم الخشونة اذا بلغ الرفق حده وقال قتادة : مجاهدة المنافقين اقامة الحدود عليهم وعن مجاهد : الوعيد وقيل : إفشاء أسرارهم ولو كانوا قرابة أو أصهار لان الكفر والنفاق أوجبا لهم ذلك .

{ وَمَأوَاهُم جَهَنَّمُ وَبِئْسَ المَصِيرُ } جهنم .
