{ انظُرْ كَيْفَ ضَرَبُوا لَكَ الأَمْثَالَ } اخترعوا لك صفات كقولهم : { ان هذا الا افك افتراه } واعانه عليه قوم آخرون وقولهم : { اساطير الاولين اكتببها } وقولهم : { مال هذا الرسول يأكل الطعام ويمشي في الاسواق } وقولهم : ( ساحر وشاعر وكاهن مجنون ) و( لولا انزل اليه ملك فيكون معه نذيرا أو يلقى اليه كنز أو تكون له جنة فيأكل منها وان تتبعون الا رجلا مسحور ) .

{ فَضَلُّوا } عن الحق فلم يجدوا طريقا إلى الحق فلم تتميز لهم صفة النبي من صفة المتنبي فيهم متحيرون لا يجدون قولا يستقرون عليه * { فَلاَ يَسْتَطِيعُونَ سَبِيلاً } إلى الهدى أو لا يستطيعون سبيلا صحيحا إلى القدح في نبوتك .
