{ فَكُلاًّ } من المذكورين .

{ أَخَذْنَا بِذَنبِهِ } عاقبناه بذنبه .

{ فَمِنْهُم مَّنْ أَرْسَلْنَا عَلَيْهِ حَاصِباً } حجارة صغارا رماهم بها بالريح او بأيدي الملائكة او الحاصب الريح العاصف او الملك رماهم بالحصباء كقوم لوط رميت مدينتهم ومن غاب منها او كان خارجها وخسف بها .

{ وَمِنْهُم مَّنْ أَخَذّتْهُ الصَّيْحَةُ } كثمود ومدين .

{ وَمِنْهُم مَّنْ خَسَفْنَا بِهِ الأَرْضِ } كقارون .

{ وَمِنْهُم مَّنْ أَغْرَقْنَا } كفرعون وقومه وقوم نوح .

{ وَمَا كَانَ اللهُ لِيَظْلِمَهُمْ } بالعذاب من غير ذنب .

{ وَلَكِن كَانُوا أَنفُسَهُمْ يَظْلِمُونَ } بفعل ما يوجب العذاب واما الله جل وعلا فليس له الظلم عادة ولا نادرا ولكن العدل .
