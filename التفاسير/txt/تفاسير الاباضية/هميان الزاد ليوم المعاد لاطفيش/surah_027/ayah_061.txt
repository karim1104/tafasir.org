{ أَمَنْ جَعَلَ الأَرْضَ قَرَاراً } يستقر الخلق عليها ولا تميد بهم .

{ وَجَعَلَ خِلالِهَا } أي بين أجزائها .

{ أَنْهَاراً } تجري .

{ وَجَعَلَ لَهَا رَوَاسِيَ } جبالا فيها معادن ثبتت بها الأرض فيلا تميل .

{ وَجَعَلَ بَيْنَ البَحْرَيْنَ } البحر العذب والمالح أو بحر فارس وبحر الروم .

{ حَاجِزاً } يمنع من اختلاط أحدهما بالآخر وهو أرض وقال مجاهد حلزا لا يرى .

{ أَءِلَهٌ مَّعَ اللهِ بَلْ أَكْثَرُهُمْ لا يَعْلَمُونَ } الحق فهم يشركون به .
