{ إنْ تُصْبكَ حَسنةٌ } ما يستحسن طبعا كظفر وغنيمة { تَسُؤهُم } يحزنهم تلك الحسنة لشدة حسدهم { وإنْ تُصْبكَ مُصيبةٌ } كشدة وهزيمة كما جرى يوم بدر .

{ يقُولُوا قَدْ أخذْنَا أمْرَنا } حذرنا بالتخلف عنهم { مِنْ قَبلُ } أى قبل هذه المصيبة { ويتَولَّوْا } إلى منازلهم عنه صلى الله عليه وسلم ،  أو عن متحدثهم { وهُم فَرِحُونَ } بسلامتهم وبإصابتك .
