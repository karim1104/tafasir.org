{ فَسَتَذْكُرُونَ مَآ أَقُولُ لَكُمْ } يذكرونه عند معاينة العذاب يوم القيامة وعند موتهم يوم لا ينفع الذكر وقرئ ( فستذكرون ) بضم التاء وفتح الذال وكسر الكاف مشددة أي ( يذكر بعضكم بعضاً ) .

{ وَأُفَوِّضُ أَمْرِي إِلَى اللهِ } قاله لما توعدوه لمخالفة دينهم أى أرد أمرى الى الله ليعصمني من كل سوء* { إِنَّ اللهَ بَصِيرٌ بِالْعِبَادِ } فيجازيهم ويكفي من فوض اليه قيل خرج من بينهم فطلبوه فلم يقدروا عليه كما قال* { فَوَقَاهُ اللهُ سَيِّئَاتِ مَا مَكَرُواْ }
