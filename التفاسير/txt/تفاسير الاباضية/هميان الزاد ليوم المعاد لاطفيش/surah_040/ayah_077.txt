{ فَاصْبِرْ إِنَّ وَعْدَ اللهِ } بعذابهم ونصرك* { حَقٌّ } وذلك تأنيس له صلى الله عليه وسلم* { فَإِمَّا } ان الشرطية وما الزائدة أدغمت نون ( ان ) بعد القلب فيما يدل على ذلك التوكيد بالنون ولولا ما الزائدة لما أكد بعد ( إن ) .

{ نُرِيَنَّكَ بَعْضَ الَّذِي نَعِدُهُمْ } اياه من العذاب في حياتك وهو القتل والاسر يوم بدر وغيره فتقر عينك وجواب ( إن ) محذوف أى فذاك { أَوْ نَتَوَفَّيَنَّكَ } نمتك قبل تعذيبهم { فَإِلَيْنَا يُرْجَعُونَ } بالموت بعدك أو يرجعون يوم القيامة فننتقم منهم أشد الانتقام لأعمالهم والجملة جواب معطوف على الشرط أى وان نتوفينك على حذف بعضها أي قد يرجعون بقد التحتية أو التوقعية باعتبار المخاطب أو هم يرجعون والتحقيق ان هذه جواب لذلك كله أي ان أريناك ولم نرك فمرجعهم الينا وان قلت من أين يفهم أشدية العذاب ؟ قلت : من ذكر الرجوع في معرض العقاب .
