{ وَإِذْ يَتَحَآجُّونَ } أي وأذكر وقت يتحاجون يتخاصمون { فِى النَّارِ } والضمير لجميع كفار الأمم ومن عطفه على ( غدوا ) أو على ( عشياً ) فقد خصه بآل فرعون* { فَيَقُولُ الضُّعَفَآءُ لِلَّذِينَ اسْتَكْبَرُواْ } أي الرؤساء* { إِنَّا كُنَّا لَكُمْ } فى الدنيا { تَبَعاً } جمع تابع كخادم وخدم أو مصدر أخبروا به عن ذواتهم لتأويله باسم الفاعل أو تقدير مضاف أي ذوى تبع أو للمبالغة فى المتابعة حتى انهم نفس المتابعة { فَهَلْ أَنتُم مُّغْنُونَ } اسم فاعل أصله مغنيون بكسر النون ونقلت اليه ضمة الياء لثقلها وحذفت الياء للساكنين أي دافعون أو حاملون { عَنَّا نَصِيباً } أي جزاء مفعول لمغنون لتضمنه معنى الدفع أو الحمل أو لمحذوف أى دافعون أو ( حاملون ) على أن ( مغنون ) لم يتضمنه أو هو بمعنى ( دافع ) وتضمن مغنى حامل { مِّنَ النَّارِ } نعت ل ( نصيبا ) وان جعلنا ( نصيباً ) بمعنى ( اغناء ) مفعولا مطلقاً غمن النار متعلق ب ( مغنون ) .
