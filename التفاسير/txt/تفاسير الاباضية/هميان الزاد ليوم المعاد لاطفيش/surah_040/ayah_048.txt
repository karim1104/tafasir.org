{ قَالَ الَّذِينَ اسْتَكْبَرُواْ إِنَّا } ايانا واياكم* { كُلٌّ } مبتدأ { فِيهَآ } خبره والجملة خبر ( إن ) وقرئ بالنصب توكيداً لاسم ( ان ) والاصل ( كلنا ) وعوض التنوين عن المضاف اليه أو حال منه على قول مجيزة ومن أجاز تقدم الحال على عاملها الظرفي مطلقاً أجاز كونه حالاً من الضمير المستتر في ( فيها ) والخبر لان على هذه القراءة هو ( فيها ) قال ابن هشام وليس ( كلاً ) توكيداً خلافاً للفراء والزمخشري بل ( بدل ) من اسم ( ان ) وابدال الظاهر من ضمير الحاضر بدل كل جانب اذا أفاد الاحاطة وبدل الكل لا يربط وكل بالعامل اذا لم تتصل بالضمير وتبدل وفى كونها حالاً قطعها عن الاضافة لفظاً ومعنى وبسطت ذلك فى النحو والمعنى نحن وأنتم فى النار كيف تغنى عنكم ولو قدرنا لأغنينا عن أنفسنا* { إِنَّ اللهَ قَدْ حَكَمَ بَيْنَ الْعِبَادِ } بادخال هذا الى الجنة وهذا الى النار ولا مبطل لحكمه فينقص من عذاب أحد أو يدخله الجنة
