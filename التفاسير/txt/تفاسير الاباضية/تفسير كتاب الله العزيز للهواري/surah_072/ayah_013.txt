}وَأَنَّا لَمَّا سَمِعْنَا الْهُدَى } أي :  القرآن {  آمَنَّا بِهِ } أي :  صدقناه {  فَمَن يُؤمِن بِرَبِّهِ فَلاَ يَخَافُ بَخْساً } أي :  أن ينقص من عمله شيء {  وَلاَ رَهَقاً } ولا يخاف أن يزاد عليه ما لم يعمل .   وهي مثل قوله :

{  فَلاَ يَخَافُ ظُلْماً } أي لا يخاف أن يزاد عليه في سيئاته {  وَلاَ هَضْماً } أي :  ولا ينقص من حسناته [ طه : 112 ] .
