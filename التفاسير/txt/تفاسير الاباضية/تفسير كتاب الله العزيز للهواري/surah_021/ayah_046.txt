قوله عز وجل :  {  وَلَئِن مَّسَّتْهُمْ نَفْحَةٌ } أي عقوبة {  مِّنْ عَذَابِ رَبِّكَ } يعني النفخة الأولى التي يهلك بها كفار آخر هذه الأمة بكفرهم وجحودهم {  لَيَقُولُنَّ } أي إذا جاءهم العذاب :  {  يَا وَيْلَنا إِنَّا كُنَّا ظَالِمِينَ } .   وهي مثل الآية الأولى التي في سورة الأعراف :

{  فَمَا كَانَ دَعْوَاهُمُ إِذْ جَاءَهُمْ بَأْسُنَا } أي عذابنا {  إِلا أَن قَالُوا إِنَّا كُنَّا ظَالِمِينَ } [ الأعراف :  5 ] .
