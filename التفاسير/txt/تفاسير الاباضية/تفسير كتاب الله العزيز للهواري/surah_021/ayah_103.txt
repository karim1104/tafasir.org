قوله تعالى :  {  لاَ يَحْزُنُهُمُ الفَزَعُ الأَكْبَرُ } أي :  النفخة الآخرة .   قال بعضهم :  إذا أيقن أهل النار بالخلود ،   فعند ذلك يقولون :  {  رَبَّنَا أَخْرِجْنَا مِنْهَا } أي من النار {  فَإِنْ عُدْنَا فَإِنَّا ظَالِمُونَ } [ المؤمنون :  107 ] فيقول الله :

{  قَالَ اخْسَؤُوا فِيهَا وَلاَ تُكَلِّمُونِ } [ المؤمنون :  107-108 ] .   فإذا قال ذلك أطبقت عليهم فلم يخرج منهم أحد ،   فذلك قوله :  {  الفَزَعُ الأَكْبَرُ } .   قوله :  {  وَتَتَلَقَّاهُمُ المَلائِكَةُ } قال الحسن :  تتلقاهم بالبشارة حين يخرجون من قبورهم ،   وتقول لهم :  {  هَذَا يَوْمُكُمُ الذِي كُنتُمْ تُوعَدُونَ } .
