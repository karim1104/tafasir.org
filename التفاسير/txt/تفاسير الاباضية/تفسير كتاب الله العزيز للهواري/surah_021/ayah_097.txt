قوله عزّ وجلّ :  {  وَاقْتَرَبَ الوَعْدُ الحَقُّ } أي :  النفخة الآخرة {  فَإِذَا هِيَ شَاخِصَةٌ أَبْصَارُ الذِينَ كَفَرُوا } أي إلى إجابة الداعي إلى بيت المقدس .   {  يَا وَيْلَنا } أي يقولون :  يا ويلنا {  قَدْ كُنَّا فِي غَفْلَةٍ مِّنْ هَذَا } يعني تكذيبهم بالساعة {  بَلْ كُنَّا ظَالِمِينَ } أي :  لأنفسنا .
