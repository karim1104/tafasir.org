قوله تعالى :  {  وَلَقَدْ كَتَبْنَا فِي الزَّبُورِ } أي :  الكتب التوراة والإِنجيل والفرقان {  مِن بَعْدِ الذِّكْرِ } أي :  الكتاب الذي عند الله في السماء ،   وهو أم الكتاب .   هذا تفسير مجاهد .   {  أَنَّ الأَرْضَ } يعني أرض الجنة {  يَرِثُهَا عِبَادِيَ الصَّالِحُونَ } وهم المؤمنون .

وقال ابن عباس :  {  وَلَقَدْ كَتَبْنَا فِي الزَّبُورِ } أي :  زبور داوود {  مِن بَعْدِ الذِّكْرِ } أي :  التوراة .   {  أَنَّ الأَرْضَ يَرِثُهَا عِبَادِيَ الصَّالِحُونَ } أي :  أمة محمد صلى الله عليه وسلم .
