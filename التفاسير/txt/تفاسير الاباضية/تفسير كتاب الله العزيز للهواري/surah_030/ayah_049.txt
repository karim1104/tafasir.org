قوله :  {  وَإِن كَانُوا مِن قَبْلِ أَن يُنَزِّلَ عَلَيْهِم } المطر {  مِّن قَبْلِهِ لَمُبْلِسِينَ } أي :  لآيسين من المطر قانطين .   كقوله :

{  وَهُوَ الَّذِي يُنَزِّلُ الغَيْثَ مِن بَعْدِ مَا قَنَطُوا } [ الشورى :  28 ]

وقوله :  {  وَإِن كَانُوا مِن قَبْلِ أَن يُنَزَّلَ عَلَيْهِم مِّن قَبْلِهِ لَمُبْلِسِينَ } هو كلام من كلام العرب مثنى .   مثل قوله : {  وَهُم بالآخرة هُمْ يُوقِنُونَ } [ النمل :  3 ] وكقوله :  {  وَهُمْ عَنِ الآخرة هُمْ غَافِلُونَ } [ الروم :  7 ]
