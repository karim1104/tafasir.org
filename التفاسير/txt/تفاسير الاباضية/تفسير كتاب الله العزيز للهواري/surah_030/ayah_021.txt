قوله :  {  وَمِنْ آيَاتِهِ أَنْ خَلَقَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجاً } يعني أزواجكم ،   أي :  المرأة من الرجل {  لِّتَسْكُنُوا إِلَيْهَا } أي :  لتستأنسوا إليها {  وَجَعَلَ بَيْنَكُم مَّوَدَّةً } يعني محبة {  وَرَحْمَةً } يعني الولد {  إِنَّ فِي ذَلِكَ لآيَاتٍ لِّقَوْمٍ يَتَفَكَّرُونَ } أي :  فيؤمنون ،   وإنما يتفكَّر المؤمن .
