قوله :  {  وَلِكُلٍّ وَجْهَةٌ } أي ولكل قوم وجهة وشريعة {  هُوَ مُوَلِّيهَا } أي :  الله موليها ،   مثل قوله :

{  لِكُلٍّ جَعَلْنَا مِنكُمْ شِرْعَةً وَمِنْهَاجاً }

[ المائدة : 48 ] أي سبيلاً وسنة ،   والدين واحد وإن اختلفت الشرائع والأحكام .   وقال مجاهد :  ولكل صاحب ملّة وجهة هو مستقبلها .   وقال بعضهم :  ولكل قبلة هو مستقبلها .

قوله :  {  فَاسْتَبِقُوا الخَيْرَاتِ } قال بعض المفسرين :  لا تُغْبَنُنَّ عَن قبلتكم {  أَيْنَ مَا تَكُونُوا يَأْتِ بِكُمُ اللهُ جَمِيعاً إِنَّ اللهَ عَلَى كُلِّ شَيْءٍ قَدِيرٌ } .
