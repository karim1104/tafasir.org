قوله :  {  وَإِذَا قِيلَ لَهُ اتَّقِ اللهَ أَخَذَتْهُ العِزَّةُ بِالإِثْمِ } أي فكفاه جهنم .   {  وَلَبِئْسَ الْمِهَادُ } وهو كقوله :

{  لَهُم مِّن جَهَنَّمَ مِهَادٌ وَمِن فَوْقِهِمْ غَوَاشٍ } [ الأعراف : 41 ] ومثل قوله :  {  لَهُم مِّن فَوْقِهِمْ ظُلَلٌ مِّنَ النَّارِ وَمِن تَحْتِهِمْ ظُلَلٌ } .   والمهاد والفراش واحد .

وذكر بعضهم قال :  {  إِذَا قِيلَ لَهُ اتَّقِ اللهَ أَخَذَتْهُ العِزَّةُ بِالإِثْمِ } يقول :  إني لأزداد بهذا عند الله قربة .
