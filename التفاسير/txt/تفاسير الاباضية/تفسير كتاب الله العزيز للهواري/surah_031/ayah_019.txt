قال :  {  وَاقْصِدْ فِي مَشْيِكَ } وقال في آية أخرى :  {  وَلاَ تَمْشِ فِي الأَرْضِ مَرَحاً إِنَّكَ لَن تَخْرِقَ الأَرْضَ وَلَن تَبْلُغَ الجِبَالَ طُولاً } [ الإِسراء :  37 ] .

قال :  {  وَاغْضُضْ مِن صَوْتِكَ إِنَّ أَنْكَرَ الأَصْوَاتِ } يعني أقبح الأصوات {  لَصَوْتُ الحَمِيرِ } وإنما كانت {  لَصَوْتُ الحَمِيرِ } ولم تكن لأصوات الحمير لأنه عنى صوتها الذي هو صوتها .
