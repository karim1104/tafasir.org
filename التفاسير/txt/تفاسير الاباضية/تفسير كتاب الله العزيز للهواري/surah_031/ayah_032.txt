قوله :  {  وَإِذَا غَشِيَهُم مَّوْجٌ كَالظُّلَلِ } أي :  كالجبال .   وقال في آية أخرى :  {  وَهِيَ تَجْرِي بِهِمْ فِي مَوْجٍ كَالْجِبَالِ }

[ هود :  42 ] .   وقال في آية أخرى :  {  وَإِذْ نَتَقْنَا الْجَبَلَ فَوْقَهُمْ كَأَنَّهُ ظُلَّةٌ }

[ الأعراف :  171 ] .   قال :  {  دَعَوُا اللهَ مُخْلِصِينَ لَهُ الدِّينَ } [ يعني التوحيد ] {  فَلَمَّا نَجَّاهُمْ إِلَى الْبَرِّ فَمِنْهُم مُّقْتَصِدٌ } وهذا المؤمن .   وأما الكافر فعاد في غدره .   قال :  {  وَمَا يَجْحَدُ بِآيَاتِنَا إِلاَّ كُلُّ خَتَّارٍ } أي :  غدّار {  كَفُورٍ } .   يقول :  أخلص لله في البحر للمخافة من الغرق ،   ثم غدَر فأشرك .   كقوله :  {  فَإِذَا رَكِبُوا فِي الْفُلْكِ دَعَوُا اللهَ مُخْلِصِينَ لَهُ الدِّينَ فَلَمَّا نَجَّاهُمْ إِلَى الْبَرِّ إِذَا هُمْ يُشْرِكُونَ } [ العنكبوت :  65 ]
