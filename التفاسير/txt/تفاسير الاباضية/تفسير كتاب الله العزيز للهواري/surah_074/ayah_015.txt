قال تعالى :  {  ثم يطمع أن أزيد } قال بعضهم :  فلم يزده بعد هذه الآية شيئاً .   تفسير الحسن :  {  ثُمَّ يَطْمَعُ أَنْ أَزِيدَ } أي :  أن أدخله الجنة .   أي :  لقول المشرك {  وَلَئِن رُّجِعْتُ إِلَى رَبِّيَ إِنَّ لِي عِنْدَهُ لَلْحُسْنَى } [ فصلت : 50 ] أي :  للجنة إن كانت جنة .   وكقوله :  {  وَلَئِن رُّدِدتُّ إِلَى رَبِّي لأَجِدَنَّ خَيْراً مِّنْهَا مُنقَلَباً } [ الكهف : 36 ] .   وكقوله : {  لأُوتَيَنَّ مَالاً وَوَلَداً }

[ مريم : 77 ] أي :  في الجنة إن رددت إلى ربي كما تقولون .
