قوله :  {  وَيَقُولُونَ لَوْلاَ أُنزِلَ عَلَيْهِ } أي هلا أنزل عليه {  ءَايَةٌ مِّن رَّبِّهِ } يعنون الآيات التي كانت الأمم تسألها أنبياءها .   فقال :  {  فَقُلْ إِنَّمَا الغَيْبُ لِلَّهِ } وهو كقوله {  إِنَّمَا الآيَاتُ عِندَ اللهِ } [ الأنعام : 109 ] أي :  إذا شاء أنزلها .   {  فَانتَظِرُوا إِنِّي مَعَكُم مِّنَ المُنتَظِرِينَ } أي فستعلمون بمن ينزل عليه العذاب .
