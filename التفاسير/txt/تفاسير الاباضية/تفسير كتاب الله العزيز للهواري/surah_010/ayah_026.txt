قوله :  {  لِّلَّذِينَ أَحْسَنُوا الحُسْنَى } أي الجنة .   {  وَزِيَادَةٌ } يعني الحسنة بعشر أمثالها إلى سبعمائة ضعف .

قوله :  {  وَلاَ يَرْهَقُ وُجُوهَهُمْ } أي :  ولا يغشى وجوههم {  قَتَرٌ وَلاَ ذِلَّةٌ } القتر :  السواد ،   والذلة :  الذل .   {  أُوْلَئِكَ أَصْحَابُ الجَنَّةِ } أي :  أهل الجنة .   {  هُمْ فِيهَا خَالِدُونَ } أي لا يخرجون منها ولا يموتون .
