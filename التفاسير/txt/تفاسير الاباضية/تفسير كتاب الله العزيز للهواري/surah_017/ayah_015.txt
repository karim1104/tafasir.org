قوله :  {  مَّنِ اهْتَدَى فَإِنَّمَا يَهْتَدِي لِنَفْسِهِ وَمَن ضَلَّ فَإِنَّمَا يَضِلُّ عَلَيْهَا } أي :  على نفسه .   {  وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أَخْرَى } أي :  لا يحمل أحد ذنب آخر .

قوله :  {  وَمَا كُنَّا مُعَذِّبِينَ حَتَّى نَبْعَثَ رَسُولاً } قال الحسن :  لا يعذب قوماً بالاستئصال حتى يحتجّ عليهم بالرسل .   كقوله :  {  وَمَا كَانَ رَبُّكَ مُهْلِكَ القُرَى حَتَّى يَبْعَثَ فِي أُمِّهَا رَسُولاً } [ القصص : 59 ] .   وكقوله :  {  وَإِن مِّنْ أُمَّةٍ إِلاَّ خَلاَ فِيهَا نَذِيرٌ } [ فاطر : 24 ] يعني الأمم التي أهلك الله بالعذاب .
