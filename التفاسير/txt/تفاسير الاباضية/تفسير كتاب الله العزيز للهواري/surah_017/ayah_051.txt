{  أَوْ خَلْقاً مِّمَّا يَكْبُرُ فِي صُدُورِكُمْ } أي :  الموت ،   أي :  إذاً لأماتكم ثم يبعثكم يوم القيامة {  فَسَيَقُولُونَ مَن يُعِيدُنَا } أي :  خلقاً جديداً {  قُلِ الَّذِي فَطَرَكُمْ أَوَّلَ مَرَّةٍ } {  فَسَيُنْغِضُونَ إِلَيْكَ رُءُوسَهُمْ } أي :  فسيحرّكون إليك رؤوسهم تكذيباً واستهزاء .   قال :  {  وَيَقُولُونَ مَتَى هُوَ } يعنون البعث {  قُلْ } يا محمد {  عَسَى أَن يَكُونَ قَرِيباً } .   وعسى من الله واجبة ؛  وكل ما هو آتٍ قريب .
