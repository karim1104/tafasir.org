قوله :  {  قُلْ آمِنُوا بِهِ } يعني القرآن .   يقول :  قل للمشركين آمنوا به {  أَوْ لاَ تُؤْمِنُوا إِنَّ الَّذِينَ أُوتُوا العِلْمَ مِن قَبْلِهِ } أي :  من قبل هذا القرآن ،   يعني المؤمنين من أهل الكتاب {  إِذَا يُتْلَى عَلَيْهِمْ } أي :  القرآن {  يَخِرُّونَ لِلأَذْقَانِ } أي :  للوجوه {  سُجَّدا }ً
