{  أَمْ أَمِنتُمْ أَن يُعِيدَكُمْ فِيهِ } أي :  في البحر {  تَارَةً أُخْرَى } أي :  مرة أخرى {  فَيُرْسِلَ عَلَيْكُمْ قَاصِفاً مِّنَ الرِّيحِ } والقاصف من الريح الشديد {  فَيُغْرِقَكُم بِمَا كَفَرْتُمْ ثُمَّ لاَ تَجِدُوا لَكُمْ عَلَيْنَا بِهِ تَبِيعاً } أي :  لا تجدوا أحداً تبيعاً بذلك لكم فينتصر لكم .   وهو كقوله :

{  فَدَمْدَمَ عَلَيْهِمْ رَبُّهُم بِذَنْبِهِمْ فَسَوَّاهَا } [ الشمس : 14-15 ] أي :  فسواها عليهم بالعذاب .   {  وَلاَ يَخَافُ عُقْبَاهَا } أي :  التبعة ،   فينتصر لهم .   وقال بعضهم :  ولا يخاف أن يُتْبَع بشيء مما أصابكم .   وقال مجاهد :  {  تَبِيعاً } أي :  ثائراً .
