قوله :  {  وَإِذْ قُلْنَا لِلْمَلاَئِكَةِ اسْجُدُوا لآِدَمَ فَسَجَدُوا إِلاَّ إِبْلِيسَ قَالَ أأسْجُدُ لِمَنْ خَلَقْتَ طِيناً } أي :  من طين .   كقوله :  {  هُوَ الَّذِي خَلَقَكُم مِّن طِينٍ } [ الأنعام : 2 ] وقال إبليس :  {  خَلَقْتَنِي مِن نَّارٍ وَخَلَقْتَهُ مِن طِينٍ } [ سورة ص : 76 ] ،   وقول إبليس :  {  أأسْجُدُ لِمَنْ خَلَقْتَ طِيناً } على الاستفهام ،   أي :  لا أسجد له .
