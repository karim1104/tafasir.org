قوله :  {  وَقَضَيْنَا إِلَى بَنِي إِسْرَائِيلَ فِي الكِتَابِ } قال الحسن :  يقول :  أعلمناهم .   كقوله :  {  وَقَضَيْنَا إِلَيْهِ ذَلِكَ الأَمْرَ } [ الحجر : 66 ] أي :  أعلمناه :  ذكروا أن مجاهداً قال :  {  وَقَضَيْنَا } أي :  كتبنا .   {  لَتُفْسِدُنَّ فِي الأَرْضِ مَرَّتَيْنِ } [ يعني لتهلكن في الأرض مرّتين ] {  وَلَتَعْلُنَّ عُلُوّاً كَبِيراً } [ يعني لتقهرن قهراً شديداً ] .
