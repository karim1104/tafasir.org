قال الله عز وجل :  {  نَّحْنُ أَعْلَمُ بِمَا يَقُولُونَ إِذْ يَقُولُ أَمْثَلُهُمْ طَرِيقَةً } وقال الله عز وجل في آية أخرى :  {  وَيَذْهَبَا بِطَرِيقَتِكُمُ المُثْلَى } [ طَهَ :  63 ] .   قال بعضهم :  كانوا أكثر عدداً وأموالاً .   وقال بعضهم :  {  أَمْثَلُهُمْ طَرِيقَةً } أي أعدلهم طريقة .   {  إِن لَّبِثْتُّمْ } أي :  ما لبثتم {  إِلاَّ يَوْماً } .

وهي مواطن .   قالوا :  إِلاَّ عَشْراً وَإِلاَّ يَوْماً و {  قَالُوا لَبِثْنَا يَوْماً أَوْ بَعْضَ يَوْمٍ } [ المؤمنون :  113 ] .   وقال عز وجل : {  كَأَنَّهُمْ يَوْمَ يَرَوْنَهَا لَمْ يَلْبَثُوا إِلاَّ عَشِيَّةً أَوْ ضُحَاهَا } [ النازعات :  46 ] وقال عز وجل :  {  كأَنَّهُمْ يَوْمَ يَرَوْنَ مَا يُوعَدُونَ لَمْ يَلْبَثُوا إِلاَّ سَاعَةً مِّن نَّهَارٍ } [ الأحقاف :  35 ] وقال عز وجل :  {  وَيَوْمَ تَقُومُ السَّاعَةُ يُقْسِمُ المُجْرِمُونَ مَا لَبِثُوا غَيْرَ سَاعَةٍ } [ الروم :  55 ] وذلك لتصاغر الدنيا عندهم وقلتها في طول الآخرة .
