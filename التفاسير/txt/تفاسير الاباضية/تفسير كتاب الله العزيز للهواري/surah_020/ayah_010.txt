{  إذْ رَأَى نَاراً } أي عند نفسه وإنما كانت نوراً .   {  فَقَالَ لأَهْلِهِ امْكُثُوا إِنِّي آنَسْتُ نَاراً } أي رأيت ناراً {  لَّعَلِّي آتِيكُم مِّنْهَا بِقَبَسٍ } .   وقال في آية أخرى :  {  سَآتِيكُم مِّنْهَا بِخَبَرٍ } أي :  خبر الطريق {  أَوْ آتِيكُم بِشِهَابِ قَبَسٍ لَّعَلَّكُمْ تَصْطَلُونَ } [ النمل :  7 ] وكان شاتياً .   وقال في هذه الآية :  {  لَّعَلِّي آتِيكُم مِّنْهَا بِقَبَسٍ } {  أَوْ أَجِدُ عَلَى النَّارِ هُدىً } أي :  هداة يهدونني الطريق في تفسير الحسن .

وقال بعضهم :  وكان يمشي على غير طريق .   وكان يمشي متوكلاً على ربه متوجهاً بغير علم .
