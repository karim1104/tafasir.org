قوله :  {  وَلَوْ شَاء اللَّهُ لَجَعَلَهُمْ أُمَّةً وَاحِدَةً } أي :  على الإيمان .   كقوله :  {  وَلَوْ شَاء رَبُّكَ لآمَنَ مَن فِي الأَرْضِ كُلُّهُمْ جَمِيعًا } [ يونس : 99 ] .   قال :  {  وَلَكِن يُدْخِلُ مَن يَشَاء فِي رَحْمَتِهِ } أي :  في دينه الإسلام .   {  وَالظَّالِمُونَ وَلاَ نَصِيرٍ } أي :  المشركون {  مَا لَهُم مِّن وَلِيٍّ } أي :  يمنعهم من عذاب الله {  وَلاَ نَصِيرٍ } أي :  ينتصر لهم .
