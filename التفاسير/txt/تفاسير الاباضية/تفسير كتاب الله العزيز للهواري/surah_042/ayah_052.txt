قوله :  {  وَكَذَلِكَ أَوْحَيْنَا إِلَيْكَ رُوحًا مِّنْ أَمْرِنَا } يعني القرآن {  مَا كُنتَ تَدْرِي } من قبل أن يوحى إليك {  مَا الْكِتَابُ وَلاَ الإِيمَانُ وَلَكِن جَعَلْنَاهُ } أي :  القرآن {  نُورًا } [ أي :  ضياء من الظلمة ] {  نَّهْدِي بِهِ مَنْ نَّشَاء مِنْ عِبَادِنَا وَإِنَّكَ لَتَهْدِي } أي :  لتدعو {  إِلَى صِرَاطٍ مُّسْتَقِيمٍ } أي إلى الجنة .
