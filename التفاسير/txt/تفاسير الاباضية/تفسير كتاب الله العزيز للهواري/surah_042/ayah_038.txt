قوله :  {  وَالَّذِينَ اسْتَجَابُوا لِرَبِّهِمْ } أي :  آمنوا {  وَأَقَامُوا الصَّلاَةَ } كانت الصلاة يوم نزلت هذه الآية ركعتين غدوة وركعتين عشية قبل أن تفرض الصلوات الخمس .

قوله :  {  وَأَمْرُهُمْ شُورَى بَيْنَهُمْ } تفسير الحسن :  يتشاورون في كتاب الله .   وقال بعضهم :  {  وَأَمْرُهُمْ } يعني التوحيد ،   {  شُورَى بَيْنَهُمْ } {  وَمِمَّا رَزَقْنَاهُمْ يُنفِقُونَ } أي :  الزكاة ،   ولم تكن يومئذ شيئاً موقتاً .
