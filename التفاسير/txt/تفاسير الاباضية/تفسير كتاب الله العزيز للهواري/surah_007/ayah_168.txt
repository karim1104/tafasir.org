قوله :  {  وَقَطَّعْنَاهُمْ فِي الأَرْضِ } [ أي فرّقناهم ] {  أُمَماً } مختلفين .   قال الحسن :  بني إسرائيل .   وقال مجاهد :  يعني اليهود .   {  مِّنْهُمُ الصَّالِحُونَ } يعني المؤمنين {  وَمِنْهُمْ دُونَ ذَلِكَ } يعني المنافقين ،   ومنهم مشركون .   {  وَبَلَوْنَاهُم } أي ابتليناهم ،   أي اختبرناهم {  بِالْحَسَنَاتِ وَالسَّيِّئَاتِ } أي بالشدة والرخاء .   {  لَعَلَّهُمْ يَرْجِعُونَ } أي لكي يرجعوا إلى الإيمان .
