{  قَالَ ادْخُلُوا فِي أُمَمٍ } أي مع أمم {  قَدْ خَلَتْ مِن قَبْلِكُم مِّنَ الجِنِّ وَالإِنسِ فِي النَّارِ كُلَّمَا دَخَلَتْ أُمَّةٌ لَّعَنَتْ أُخْتَهَا } كقوله : {  ثُمَّ يَوْمَ القِيَامَةِ يَكْفُرُ بَعْضُكُم بِبَعْضٍ وَيَلْعَنُ بَعْضُكُم بَعْضاً } [ العنكبوت : 25 ] .   قوله يكفر بعضكم ،   أي بولاية بعض .

{  حَتَّى إِذَا ادَّارَكُوا فِيهَا جَمِيعاً } أي إذا صاروا فيها جميعاً {  قَالَتْ أُخْرَاهُمْ لأُولاَهُمْ رَبَّنَا هَؤُلاَءِ أَضَلُّونَا } كل أمة تقوله أخراها لأولاها .   {  فَئَاتِهِمْ عَذَاباً ضِعْفاً مِّنَ النَّارِ قَالَ لِكُلٍّ ضِعْفٌ وَلَكِن لاَّ تَعْلَمُونَ } .   ذكروا أن مجاهداً قال :  لكل ضعف مضاعف لأُولاَهُم ولأُخراهُم .   [ وقوله :  ولكن لا تعلمون أي أيها المخاطبون ما لكل فريق منكم ] .
