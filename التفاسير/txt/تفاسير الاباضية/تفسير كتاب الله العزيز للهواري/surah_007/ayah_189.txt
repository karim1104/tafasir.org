قوله :  {  هُوَ الَّذِي خَلَقَكُم مِّن نَّفْسٍ وَاحِدَةٍ } أي :  آدم {  وَجَعَلَ مِنْهَا زَوْجَهَا } يعني حواء من ضلعه القصيري اليسرى وهو نائم {  لِيَسْكُنَ إِلَيْهَا } .

قال :  {  فَلَمَّا تَغَشَّاهَا حَمَلَتْ حَمْلاً خَفِيفاً فَمَرَّتْ بِهِ } أي [ استمر بها الحمل فأتمته ] .   {  فَلَمَّا أَثْقَلَت } قال بعضهم :  استبان حملها ،   أي فاشتهر بها الحمل .   {  دَّعَوا اللهَ رَبَّهُمَا } أي :  آدم وحواء {  لَئِنْ ءَاتَيْتَنَا صَالِحاً } أي غلاماً {  لَّنَكُونَنَّ مِنَ الشَّاكِرِينَ } أي لأنعمك .
