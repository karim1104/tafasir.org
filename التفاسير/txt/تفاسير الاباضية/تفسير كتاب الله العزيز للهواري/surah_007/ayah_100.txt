قوله :  {  أَوَ لَمْ يَهْدِ لِلَّذِينَ يَرِثُونَ الأَرْضَ } وهي تقرأ على وجهين :  {  يَهْدِ } و {  نَهْدِ } .   فمن قرأها {  نَهْدِ } فيقول نُبين .   ومن قرأها {  يَهْدِ } فيقول :  يبيّن الله للذين يرثون الأرض .   {  مِن بَعْدِ أَهْلِهَا } أي الذين هلكوا من الأمم السالفة {  أَن لَّوْ نَشَاءُ أَصَبْنَاهُم بِذُنُوبِهِمْ } فأهلكناهم بالعذاب كما أهلكنا من كان قبلهم حين كذّبوا رسلهم .   {  وَنَطْبَعُ عَلَى قُلُوبِهِمْ فَهُمْ لاَ يَسْمَعُونَ } أي لو شئنا أصبناهم بذلك .
