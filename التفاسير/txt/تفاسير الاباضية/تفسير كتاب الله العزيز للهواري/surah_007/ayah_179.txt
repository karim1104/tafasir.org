قوله :  {  وَلَقَدْ ذَرَأْنَا لِجَهَنَّمَ كَثِيراً مِّنَ الجِنِّ وَالإِنسِ } ذرأنا ،   أي :  خلقنا لجهنم في تفسير الحسن وغيره {  لَهُمْ قُلُوبٌ لاَّ يَفْقَهُونَ بِهَا } الهدى {  وَلَهُمْ أَعْيُنٌ لاَّ يُبْصِرُونَ بِهَا } الهدى {  وَلَهُمْ ءَاذَانٌ لاَّ يَسْمَعُونَ بِهَا } الهدى {  أُوْلَئِكَ كَالأَنْعَامِ بَلْ هُمْ أَضَلُّ } من الأنعام فيما تُعُبِّدُوا به {  أُوْلَئِكَ هُمُ الغَافِلُونَ } عن الآخرة .
