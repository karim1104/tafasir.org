قوله :  {  وَإِن كَانَ كَبُرَ عَلَيْكَ إِعْرَاضُهُمْ } عنك وتكذيبهم إياك {  فَإِنِ اسْتَطَعْتَ أَن تَبْتَغِيَ نَفَقاً فِي الأَرْضِ } أي سرَباً فتدخل فيه {  أَوْ سُلَّمًا فِي السَّمَاءِ } أي إلى السماء فترقى إليها {  فَتَأْتِيَهُمْ بِآيَةٍ } وهذا حين سألوه الآية .   قال :  {  وَلَوْ شَاءَ اللهُ لَجَمَعَهُمْ عَلَى الهُدَى فَلاَ تَكُونَنَّ مِنَ الجَاهِلِينَ } كقوله :  {  وَلَوْ شَاءَ رَبُّكَ لأَمَنَ مَن فِي الأَرْضِ كُلُّهُمْ جَمِيعاً } [ يونس : 99 ] .
