{  قُلْ } يا محمد {  أَغَيْرَ اللهِ أَتَّخِذُ وَلِيّاً فَاطِرِ السَّمَاوَاتِ وَالأَرْضِ } أي خالق السماوات والأرض {  وَهُوَ يُطْعِمُ وَلاَ يُطْعَمُ } أي يرزق ولا يُرزق .   وقال في الذاريات :  {  وَمَا أُرِيدُ أَن يُطْعِمُونِ } [ الذاريات : 57 ] وبعضهم يقرأها :  ولا يَطعَم .   {  قُلْ إِنِّي أُمِرْتُ أَنْ أَكُونَ أَوَّلَ مَنْ أَسْلَمَ } يعني من أمته {  وَلاَ تَكُونَنَّ مِنَ المُشْرِكِينَ } .
