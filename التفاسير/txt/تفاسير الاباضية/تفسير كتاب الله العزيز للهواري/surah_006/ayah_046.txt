قوله :  {  قُلْ أَرَأَيْتُمْ إِنْ أَخَذَ اللهُ سَمْعَكُمْ } فأذهبه {  وَأَبْصَارَكُمْ } فأعماها {  وَخَتَمَ عَلَى قُلُوبِكُم مِّنْ إِلَهٌ غَيْرُ اللهِ } أي ليس غيره إله {  يَأْتِيكُم بِهِ } أي بما اذهب من أسماعكم وأبصاركم فإنه ليس يفعل ذلك حتى يرده عليكم  إن شاء  إلا هو .   قوله :  {  انظُرْ كَيْفَ نُصَرِّفُ الآيَاتِ } يقول :  كيف نبيّن الآيات {  ثُمَّ هُمْ يَصْدِفُونَ } يقول :  يعرضون عنها .
