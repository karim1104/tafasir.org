قال :  {  فَقُطِعَ دَابِرُ القَوْمِ الَّذِينَ ظَلَمُوا } أي القوم الذين أشركوا {  وَالحَمْدُ لِلَّهِ رَبِّ العَالَمِينَ } .

وهي مثل الآية التي في الأعراف :  {  وَمَا أَرْسَلْنَا فِي قَرْيَةٍ مِّن نَّبِيٍّ إِلاَّ أَخَذْنَا أَهْلَهَا بِالبَأْسَاءِ وَالضَّرَّاءِ لَعَلَّهُمْ يَضَّرَّعُونَ ثُمَّ بَدَّلْنَا مَكَانَ السَّيِّئَةِ } أي القحط {  الحَسَنَةَ } أي الرخاء {  حَتَّى عَفَوْا } أي حتى كثروا {  وَّقَالُوا قَدْ مَسَّ ءَابَاءَنَا الضَّرَّاءُ وَالسَّرَّاءُ } فلم يكن شيء .   قال الله :  {  فَأَخَذْنَاهُم بَغْتَةً وَهُمْ لاَ يَشْعُرُونَ } [ الأعراف : 94-95 ] .
