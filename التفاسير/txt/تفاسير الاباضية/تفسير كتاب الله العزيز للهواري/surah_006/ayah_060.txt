قوله :  {  وَهُوَ الَّذِي يَتَوَفَّاكُم بِالَّيْلِ } يعني النوم {  وَيَعْلَمُ مَا جَرَحْتُم بِالنَّهَارِ } أي ما عملتم بالنهار .   ذكروا أن أبا موسى الأشعري قال :  الذنوب جراحات .   وأعظمها القتل ،   والإِشراك بالله مقتلة .

قال :  {  ثُمَّ يَبْعَثُكُمْ فِيهِ } أي يبعث أحدكم في أجله حتى يستوفي أجله ،   في تفسير الحسن .   وقال مجاهد :  {  ثُمَّ يَبْعَثُكُمْ فِيهِ } أي في النَّهار .   وقال :  {  لِيُقْضَى أَجَلٌ مُّسَمّىً } يعني الساعة باختلاف الليل والنهار .   {  ثُمَّ إِلَيْهِ مَرْجِعُكُمْ } يوم القيامة {  ثُمَّ يُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ } .
