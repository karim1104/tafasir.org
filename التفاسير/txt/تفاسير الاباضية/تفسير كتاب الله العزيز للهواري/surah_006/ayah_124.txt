قوله :  {  وَإِذَا جَاءَتْهُمْ ءَايَةٌ قَالُوا لَن نُّؤْمِنَ حَتَّى نُؤْتَى مِثْلَ مَا أُوتِيَ رُسُلُ اللهِ اللهُ أَعْلَمُ حَيْثُ يَجْعَلُ رِسَالَتَهُ سَيُصِيبُ الَّذِينَ أَجْرَمُوا } أي الذين أشركوا {  صَغَارٌ عِندَ اللهِ } أي ذلة عند الله {  وَعَذَابٌ شَدِيدٌ } أي في الآخرة {  بِمَا كَانُوا يَمْكُرُونَ } أي :  يشركون .
