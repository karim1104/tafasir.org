قوله :  {  وَلَوْ أَنَّنَا نَزَّلْنَا إِلَيْهِمُ المَلاَئِكَةَ وَكَلَّمَهُمُ المَوْتَى وَحَشَرْنَا عَلَيْهِمْ كُلَّ شَيْءٍ قُبُلاً } .

 قال الحسن وغيره :  هذا حين قالوا ابعث لنا موتانا نسألهم أحق ما تقول أم باطل ،   لقولهم :  {  لَوْلاَ أُنزِلَ عَلَيْنَا المَلاَئِكَةُ أَوْ نَرَى رَبَّنَا } [ الفرقان : 21 ] ولقولهم : {  أَوْ تَأْتِيَ بِاللهِ وَالمَلاَئِكَةِ قَبِيلاً } [ الإِسراء : 92 ] ؛

يقول :  لو فعلنا هذا بهم حتى يروه عياناً {  مَّا كَانُوا لِيُؤْمِنُوا إِلاَّ أَن يَشَاءَ اللهُ وَلَكِنَّ أَكْثَرَهُمْ يَجْهَلُونَ } ،   أي لا يعلمون :  كقوله :  {  وَلَكِنَّ أَكْثَرَهُمْ لاَ يَعْلَمُونَ } [ الأنعام : 37 ] يقول :  أي جماعتهم .   يعني من ثبت منهم على الكفر .
