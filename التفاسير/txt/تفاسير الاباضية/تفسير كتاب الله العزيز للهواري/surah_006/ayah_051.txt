قوله :  {  وَأَنذِرْ بِهِ } أي بالقرآن {  الَّذِينَ يَخَافُونَ أَن يُحْشَرُوا إِلَى رَبِّهِمْ } يعني المؤمنين .   وهذا كقوله :

{  إِنَّمَا تُنذِرُ مَنِ اتَّبَعَ الذِّكْرَ } [ يس : 11 ] ،   يقول :  إنما يقبل منك من آمن .   قوله :  {  لَيْسَ لَهُم مِّن دُونِهِ } أي من دون الله {  وَلِيٌّ } يمنعهم من عذابه {  وَلاَ شفِيعٌ } يشفع لهم إن لم يكونوا مؤمنين .   {  لَّعَلَّهُمْ } لعل المشركين {  يَتَّقُونَ } هذا فيؤمنوا .
