قال :  {  وَمِن قَبْلِهِ } أي :  ومن قبل هذا القرآن {  كِتَابُ مُوسَى إِمَامًا } يعني التوراة يهتدون به {  وَرَحْمَةً } أي :  لمن آمن به {  وَهَذَا كِتَابٌ } يعني القرآن {  مُّصَدِّقٌ } أي :  للتوراة وَالإِنجِيل {  لِّسَانًا عَرَبِيًّا لِّيُنذِرَ الَّذِينَ ظَلَمُوا } أي :  أشركوا {  وَبُشْرَى لِلْمُحْسِنِينَ } يعني المؤمنين بالجنة .
