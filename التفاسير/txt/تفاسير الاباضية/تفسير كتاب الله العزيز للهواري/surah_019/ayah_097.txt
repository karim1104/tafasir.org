قوله عز وجل :  {  فَإِنَّمَا يَسَّرْنَاهُ بِلِسَانِكَ } أي :  بلسان محمد عليه السلام .   قال الحسن :  لولا أن الله يسّره بلسان محمد عليه السلام ما كانوا ليعرفوه ولا ليفقهوه .

قوله عز وجل :  {  لِتُبَشِّرَ بِهِ } أي بالقرآن {  المُتَّقِينَ } أي يبشرهم بالجنة {  وَتُنْذِرَ بِهِ } أي بالقرآن النار {  قَوْماً لُّدّاً } أي جُدُلاً بالباطل وذوي لَدَد وخصومة .

وقال مجاهد :  ( قَوْماً لُّدّاً ) أي :  لا يستقيمون .
