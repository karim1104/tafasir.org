قوله :  {  وَقَالَ الذِينَ لاَ يَرْجُونَ لِقَاءَنَا } وهم المشركون لا يقرون بالبعث .   {  لَوْلا } أي :  هلاّ {  أُنْزِلَ عَلَيْنَا المَلائِكَةُ } [ فيشهدوا أنك رسول الله يا محمد {  أَوْ نَرَى رَبَّنَا } معاينة ،   فيخبرنا أنك رسول الله .

قال الله :  {  لَقَدِ اسْتكْبَرُوا فِي أَنْفُسِهِمْ وَعَتَوْ عُتُوّاً كَبِيراً } أي :  وعصوا عصياناً كبيراً .
