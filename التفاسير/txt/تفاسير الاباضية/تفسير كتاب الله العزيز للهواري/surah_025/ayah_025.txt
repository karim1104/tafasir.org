قوله :  {  وَيَوْمَ تَشَقَّقُ السَّمَاءُ بِالغَمَامِ } أي :  عن الغمام .   هذا بعث البعث ،   تشقّق فتراها واهية متشققة ،   كقوله :  {  وَفُتِحَتِ السَّمَاءُ فَكَانَتْ أَبْوَاباً } [ النبأ :  19 ] ويكون الغمام شرايين السماء والأرض .   قال :  {  وَنُزِّلَ المَلائِكَةُ تَنزِيلاً } هو مثل قوله : {  هَلْ يَنظُرُونَ إِلا أَن يَّأتِيَهُمُ اللهُ فِي ظُلَلٍ مِّنَ الغَمَامِ وَالمَلائِكَةُ } [ البقرة :  210 ] ،   ومثل قوله :  {  وَجَاءَ رَبُّكَ وَالمَلَكُ صَفّاً صَفّاً } [ الفجر :  22 ] .
