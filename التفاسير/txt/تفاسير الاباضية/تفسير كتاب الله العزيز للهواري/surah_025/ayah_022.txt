قال :  {  يَوْمَ يَرَوْنَ المَلائِكَةَ } وهذا عند الموت {  لاَ بُشْرَى يَوْمَئِذٍ لِّلْمُجْرِمِينَ } أي :  للمشركين ،   وهذا جرم الشرك ،   أي :  لا بشرى لهم يومئذ بالجنة .   وذلك أن المؤمنين تبشرهم الملائكة عند الموت بالجنة .   قال الله :  {  إِنَّ الذِينَ قَالُوا رَبُّنَا اللهُ ثُمَّ اسْتَقَامُوا تَتَنَزَّلُ عَلَيْهِمُ المَلائِكَةُ } عند الموت {  أَلاَّ تَخَافُوا وَلاَ تَحْزَنُوا وَأَبْشِرُوا بِالجَنَّةِ التِي كُنتُمْ تُوعَدُونَ } [ فصلت :  30 ] وتفسير مجاهد :  {  يَوْمَ يَرَوْنَ المَلائِكَةَ } يوم القيامة .

قال :  {  وَيَقُولُونَ حِجْراً مَّحْجُوراً } أي :  وتقول الملائكة :  حرام محرم أن تكون لهم الجنة .   وقال مجاهد :  {  وَيَقُولُونَ حِجْراً مَّحْجُوراً } [ يعني عوذاً معاذاً ] أي :  معاذ الله أن تكون لهم البشرى بالجنة .
