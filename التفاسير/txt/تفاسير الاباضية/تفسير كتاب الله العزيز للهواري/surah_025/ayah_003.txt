قوله :  {  وَاتَّخَذُوا مِن دُونِهِ } أي :  من دون الله {  آلِهَةً } يعني الأوثان {  لاَّ يَخْلُقُونَ شَيْئاً وَهُمْ يُخْلَقُونَ } أي :  لا يصنعون شيئاً ،   أي :  إنهم يصنعونها بأيديهم .

ذكر بعضهم في قوله :  {  أَتَعْبُدُونَ مَا تَنْحِتُونَ } يعني أصنامهم التي عملوها بأيديهم

{  وَاللهُ خَلَقَكُمْ وَمَا تَعْمَلُونَ }

[ الصافات :  95-96 ] أي :  بأيديكم .   قوله :  {  وَلاَ يَمْلِكُونَ لأَنفُسِهِمْ } يعني الأوثان {  ضَرّاً وَلاَ نَفْعاً وَلاَ يَمْلِكُونَ مَوْتاً وَلاَ حَيَاةً } أي :  لا يميتون أحداً ولا يحيون أحداً {  وَلاَ نُشُوراً } أي :  ولا بعثاً ،   لا يملكون شيئاً من ذلك .
