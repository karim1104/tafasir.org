{  قَالُوا } قالت الملائكة في تفسير الحسن .   وقال مجاهد :  قالت الملائكة وعيسى وعزير :  {  سُبْحَانَكَ } يُنزِّهون الله عن ذلك {  مَا كَانَ يَنبَغِي لَنَا أَن نَّتَّخِذَ مِن دُونِكَ مِنْ أَوْلِيَاءَ } أي :  لم نكن نواليهم على عبادتهم إيانا .   وبعضهم يقرأها :  {  أَن نَّتَّخِذَ مِنْ دُونِكَ مِنْ أَوْلِيَاءَ }

{  وَلَكِن مَتَّعْتَهُمْ وَآبَاءَهُمْ } في عيشهم في الدنيا بغير عذاب {  حَتَّى نَسُوا الذِّكْرَ } أي :  حتى تركوا الذكر لما جاءهم في الدنيا .   {  وَكَانُوا قَوْماً بُوراً } أي :  فاسدين فساد الشرك .   وقال مجاهد :  هالكين .
