قوله :  {  وَعَدَ اللهُ المُنَافِقِينَ وَالمُنَافِقَاتِ } أهل الإِقرار بالله والنبي والكتاب .   {  وَالكُفَّارَ } أهل الإِنكار والجحود .   {  نَارَ جَهَنَّمَ خَالِدِينَ فِيهَا } لا يموتون ولا يخرجون منها .   {  هِيَ حَسْبُهُمْ } جميعاً :  المشركين والمنافقين .   كقوله :  {  حَسْبُهُمْ جَهَنَّمُ يَصْلَوْنَهَا }

[ المجادلة : 8 ] {  وَلَعَنَهُمُ اللهُ وَلَهُمْ عَذَابٌ مُّقِيمٌ } أي :  دائم في الآخرة .
