ثم قال :  {  إِن تُصِبْكَ حَسَنَةٌ } يعني النصر فتظهر بها على المشركين {  تَسُؤْهُمْ } أي تلك الحسنة {  وَإِن تُصِبْكَ مُصِيبَةٌ } أي نكبة من المشركين {  يَقُولُوا قَدْ أَخَذْنَا أَمْرَنَا مِن قَبْلُ } أي [ أخذنا الوثيقة ] في مخالفة محمد والتخلف عنه .   {  وَيَتَوَلَّوا } إلى منازلهم {  وَّهُمْ فَرِحُونَ } أي بالذي دخل على النبي صلى الله عليه وسلم والمؤمنين من النكبة .

وقال مجاهد :  {  قَدْ أَخَذْنَا أَمْرَنَا } أي :  أخذنا حذرنا من قبل .
