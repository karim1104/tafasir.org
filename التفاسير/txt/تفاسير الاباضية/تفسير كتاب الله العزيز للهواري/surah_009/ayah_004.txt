ثم رجع إلى قصة أصحاب العهد فقال :  {  إِلاَّ الَّذِينَ عَاهَدتُّم مِّنَ المُشْرِكِينَ ثُمَّ لَمْ يَنقُصُوكُمْ شَيْئاً } أي لم يضروكم شيئاً {  وَلَمْ يُظَاهِرُوا } أي لم يعاونوا {  عَلَيْكُمْ أَحَداً } من المشركين {  فَأَتِمُّوا إِلَيْهِمْ عَهْدَهُمْ إِلَى مُدَّتِهِمْ } أي إلى الأجل الذي عاهدتموهم عليه من يوم النحر إلى عشر يمضين من شهر ربيع الآخر .   {  إِنَّ اللهَ يُحِبُّ المُتَّقِينَ } .
