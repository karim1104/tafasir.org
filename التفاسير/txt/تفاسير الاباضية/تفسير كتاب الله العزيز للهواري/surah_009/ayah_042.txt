{  لَوْ كَانَ عَرَضاً قَرِيباً } أي :  غنيمة قريبة {  وَسَفَراً قَاصِداً } أي :  هيّناً .   وقال الحسن :  {  لَوْ كَانَ عَرَضاً قَرِيباً } ،   أي :  غنيمة حاضرة {  وَسَفَراً قَاصِداً } أي :  قريباً {  لاَّتَّبَعُوكَ وَلَكِن بَعُدَتْ عَلَيْهِمُ الشُّقَّةُ } [ يعني السفر ] قال :  وتخلّف المنافقون وقال بعضهم لبعض :  أترى هذا الرجل أنه يظهر على الشام ،   وما الشام ،   إنما الشام الدّهم ،   وتبوك في أدنى الشام ؛  فقال الله :  لو كان عرضاً قريباً وسفراً قاصداً لاتبعوك ولكن بعدت عليهم الشقة أي السفر .

{  وَسَيَحْلِفُونَ بِاللهِ لَوِ اسْتَطَعْنَا لَخَرَجْنَا مَعَكُمْ يُهْلِكُونَ أَنفُسَهُمْ } أي :  بالكذب .   {  وَاللهُ يَعْلَمُ إِنَّهُمْ لَكَاذِبُونَ } أي أنهم إنما اعتلوا بالكذب .
