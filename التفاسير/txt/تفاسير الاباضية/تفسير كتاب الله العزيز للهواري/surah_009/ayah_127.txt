قوله :  {  وَإِذَا مَا أُنزِلَتْ سُورَةٌ نَّظَرَ بَعْضُهُمْ إِلَى بَعْضٍ } يعني المنافقين {  هَلْ يَرَاكُم مِّنْ أَحَدٍ } يعني من المسلمين ؛  يقوله بعضهم لبعض {  ثُمَّ انْصَرَفُوا } قال الحسن :  يعني عزموا على الكفر .   {  صَرَفَ اللهُ قُلُوبَهُم } هذا دعاء واجب عليهم {  بِأَنَّهُمْ قَوْمٌ لاَّ يَفْقَهُونَ } أي لا يرجعون إلى الإيمان .
