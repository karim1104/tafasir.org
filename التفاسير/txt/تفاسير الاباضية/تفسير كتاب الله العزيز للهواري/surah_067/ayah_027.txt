قال الله تعالى :  {  فَلَمَّا رَأَوْهُ } يعني العذاب {  زُلْفَةً } أي :  قريباً ،   في تفسير الكلبي .   وقال مجاهد :  قد اقترب ،   وقال الحسن :  عياناً {  سِيئَتْ وُجُوهُ الَّذِينَ كَفَرُواْ } أي :  ساء العذاب وجوههم {  وَقِيلَ } [ لهم عند ذلك ] {  هَذَا الَّذِي كُنتُمْ بِهِ تَدَّعُونَ } لقولهم :  {  ائْتِنَا بِعَذَابِ اللهِ } [ العنكبوت : 29 ] استهزاء وتكذيباً .
