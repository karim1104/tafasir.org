قال تعالى :  {  أَوَلَمْ يَرَوْاْ إِلَى الطَّيْرِ فَوْقَهُمْ صَافَّاتٍ } أي :  بأجنحتها ،   أي :  قد رواها {  وََيَقْبِضْنَ } قال الحسن :  حين تحرك الطير جناحيها .   وبعضهم يقول :  ( وَيَقْبِضْنَ ) يعني إذا وقف الطائر صافاً جناحيه لا يزول .   قال تعالى :  {  مَا يُمْسِكُهُنَّ إلاَّ الرَّحْمَنُ إِنَّهُ بِكُلِّ شَيْءٍ بَصِيرٌ } .
