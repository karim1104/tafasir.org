قال الله جواباً لقولهم :  {  قُلِ اللَّهُ يُحْيِيكُمْ } يعني هذه الحياة {  ثُمَّ يُمِيتُكُمْ } يعني الموت {  ثُمَّ يَجْمَعُكُمْ إِلَى يَوْمِ الْقِيَامَةِ } أي :  ليوم القيامة .   {  لاَ رَيبَ فِيهِ } أي :  لا شك فيه ،   يعني البعث {  وَلَكِنَّ أَكَثَرَ النَّاسِ لاَ يَعْلَمُونَ } أي :  إنهم مبعوثون .
