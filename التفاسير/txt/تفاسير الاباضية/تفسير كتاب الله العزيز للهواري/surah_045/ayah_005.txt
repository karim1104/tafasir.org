قال :  {  وَاخْتِلاَفِ } أي :  وفي اختلاف {  الَّليْلِ وَالنَّهَارِ وَمَا أَنزَلَ اللَّهُ مِنَ السَّمَاء مِن رِّزْقٍ } [ يعني المطر ،   فيه أرزاق الخلق ] {  فَأَحْيَا بِهِ الأَرْضَ بَعْدَ مَوْتِهَا } أي بعد إذ كانت يابسة ليس فيها نبات {  وَتَصْرِيفِ الرِّيَاحِ } في الرحمة والعذاب {  آيَاتٌ لِّقَوْمٍ يَعْقِلُونَ } وهم لمؤمنون .
