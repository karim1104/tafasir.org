{  إِنَّا جَعَلْنَاهُ } يعني القرآن {  قُرْآنًا عَرَبِيًّا لَّعَلَّكُمْ تَعْقِلُونَ } أي :  لكي تعقلوا .

وقوله :  {  جَعَلْنَاهُ } أي :  خلقناه ،   كقوله :  {  وَجَعَلْنَا السَّمَاء سَقْفًا مَّحْفُوظًا } [ الأنبياء : 32 ] ،   وقوله :  {  وَجَعَلْنَا اللَّيْلَ وَالنَّهَارَ آيَتَيْنِ } [ الإسراء : 12 ] ،   وقوله :  {  وَجَعَلْنَا مِنَ الْمَاء كُلَّ شَيْءٍ حَيٍّ } [ الأنبياء : 30 ] ونظيره في كتاب الله كثير .
