{  وَجَعَلَهَا كَلِمَةً بَاقِيَةً فِي عَقِبِهِ } أي :  في ذريته ،   والكلمة لا إله إلا الله .   كقوله : {  وَمِن ذُرِّيَّتِنَآ أُمَّةً مُّسْلِمَةً لَّكَ } [ البقرة : 128 ] وقوله : {  رَبَّنَا وَابْعَثْ فِيهِمْ رَسُولاً مِّنْهُمْ } [ البقرة : 129 ] {  لَعَلَّهُمْ يَرْجِعُونَ } أي :  لكي يرجعوا إلى الإيمان .
