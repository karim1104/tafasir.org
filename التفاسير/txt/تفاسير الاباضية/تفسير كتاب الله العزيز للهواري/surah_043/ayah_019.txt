قوله :  {  وَجَعَلُوا الْمَلاَئِكَةَ الَّذِينَ هُمْ عِبَادُ الرَّحْمَنِ إِنَاثًا } كقوله :  {  وَمَنْ عِندَهُ لاَ يَسْتَكْبِرُونَ عَنْ عِبَادَتِهِ } [ الأنبياء : 19 ] يعني الملائكة .   وقرأ ابن عباس {  الَّذِينَ هُمْ عِبَادُ الرَّحْمَنِ إِنَاثًا } كقوله :  {  سُبْحَانَهُ بَلْ عِبَادٌ مُّكْرَمُونَ } [ الأنبياء : 26 ] .

قال :  {  أَشَهِدُوا خَلْقَهُمْ } أي :  إنهم لم يشهدوا خلقهم {  سَتُكْتَبُ شَهَادَتُهُمْ وَيُسْأَلُونَ } أي :  عنها يوم القيامة .
