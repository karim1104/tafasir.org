قوله :  {  الذِينَ يَتَرَبَّصُونَ بِكُمْ } يعني المنافقين ؛  كانوا يتربصون برسول الله صلى الله عليه وسلم وبالمؤمنين .   {  فَإِن كَانَ لَكُمْ فَتْحٌ مِّنَ اللهِ } أي نصر وغنيمة {  قَالُوا أَلَمْ نَكُن مَّعَكُمْ وَإِن كَانَ لِلْكَافِرِينَ نَصِيبٌ } أي نكبة على المؤمنين {  قَالُوا } للكافرين {  أَلَمْ نَسْتَحْوِذْ عَلَيْكُمْ } أي :  ألم نغلب عليكم بمودتنا إياكم {  وَنَمْنَعْكُم مِّنَ المُؤْمِنِينَ } يقولون :  إنهم آمنوا بمحمد ،   وكنا لكم عيوناً ،   نأتيكم بأخبارهم ،   ونغينكم عليهم ؛  وكان ذلك في السِّرّ .

قال الله :  {  فَاللهُ يَحْكُمُ بَيْنَكُمْ } فيجعل المؤمنين في الجنة ويجعل الكافرين في النار {  وَلَن يَجْعَلَ اللهُ لِلْكَافِرِينَ عَلَى المُؤْمِنِينَ سَبِيلاً } أي حجة في الآخرة ؛  وقد تكون في الدنيا الدولة للكافرين ؛  وربما ابتلي المؤمنون .
