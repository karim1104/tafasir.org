قوله :  {  إِنَّ المُنَافِقِينَ يُخَادِعُونَ اللهَ } بكونهم {  وَإِذَا لَقُوا الذِينَ ءَامَنُوا قَالُوا ءَامَنَّا وَإِذَا خَلَوْا إِلَى شَيَاطِينِهِمْ قَالُوا إِنَّا مَعَكُمْ } [ البقرة : 14 ] {  وَهُوَ خَادِعُهُمْ } .

قوله :  {  وَإِذَا قَامُوا إِلَى الصَّلاَةِ قَامُوا كُسَالَى } عنها {  يُرَاءُونَ النَّاسَ } بصلاتهم ليظنوا أنهم مؤمنون ،   وليسوا بمؤمنين {  وَلاَ يَذْكُرُونَ اللهَ إِلاَّ قَلِيلاً } أي :  التوحيد الذي قِبَلَهم .   وقال الحسن :  إنما قلّ لأنه لغير الله .
