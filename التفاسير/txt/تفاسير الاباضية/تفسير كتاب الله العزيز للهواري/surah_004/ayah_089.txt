{  وَدُّوا لَوْ تَكْفُرُونَ كَمَا كَفَرُوا فَتَكُونُونَ سَوَاءً } [ أي في الكفر شرعاً سواء ] .   {  فَلاَ تَتَّخِذُوا مِنْهُمْ أَوْلِيَاءَ } أي :  لا توالوهم .   {  حَتَّى يُهَاجِرُوا فِي سَبِيلِ اللهِ } فيرجعوا إلى الدار التي خرجوا منها ،   يعني المدينة .   {  فَإِن تَوَلَّوْا } أي أبوا الهجرة {  فَخُذُوهُمْ وَاقْتُلُوهُمْ حَيْثُ وَجَدتُّمُوهُمْ وَلاَ تَتَّخِذُوا مِنْهُمْ وَلِيّاً وَلاَ نَصِيراً } .
