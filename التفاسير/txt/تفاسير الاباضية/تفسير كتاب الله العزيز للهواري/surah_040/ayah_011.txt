{  قَالُوا رَبَّنَا أَمَتَّنَا اثْنَتَيْنِ وَأَحْيَيْتَنَا اثْنَتَيْنِ } وهو قوله في سورة البقرة ،   {  كَيْفَ تَكْفُرُونَ بِاللَّهِ وَكُنتُمْ أَمْوَاتاً فَأَحْيَاكُمْ ثُمَّ يُمِيتُكُمْ ثُمَّ يُحْيِيكُمْ } [ البقرة : 28 ] يقول :  {  كُنتُمْ أَمْوَاتاً } في أصلبة آبائكم نطفاً ،   {  فَأَحْيَاكُمْ } ،   يعني هذه الحياة في الدنيا ،   {  ثُمَّ يُمِيتُكُمْ } يعني بهذا موتكم {  ثُمَّ يُحْيِيكُمْ } يعني البعث {  فَاعْتَرَفْنَا بِذُنُوبِنَا فَهَلْ إِلَى خُرُوجٍ مِّن سَبِيلٍ } .

تفسير الحسن :  إن فيها إضماراً :  قال الله :  [ لا ،   ثم قال ] :  {  ذَلِكُم بِأَنَّهُ إِذَا دُعِيَ اللَّهُ وَحْدَهُ كَفَرْتُمْ وَإِن يُشْرَكْ بِهِ تُؤْمِنُوا }
