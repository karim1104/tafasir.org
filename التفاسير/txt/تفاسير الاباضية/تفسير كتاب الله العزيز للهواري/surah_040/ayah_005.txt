قوله :  {  كَذَّبَتْ قَبْلَهُمْ } أي قبل قومك يا محمد {  قَوْمُ نُوحٍ وَالأَحْزَابُ مِن بَعْدِهِمْ } ،   يعني عاداً وثموداً ومن بعدهم ،   الذين أخبر بهلاكهم لتكذيبهم رسلهم .   {  وَهَمَّتْ كُلُّ أُمَّةٍ بِرَسُولِهِمْ لِيَأْخُذُوهُ } فيقتلوه {  وَجَادَلُوا } أي :  وخاصموا {  بِالْبَاطِلِ } أي :  بالشرك ،   جادلوا به الأنبياء والمؤمنين .   {  لِيُدْحِضُوا بِهِ الْحَقَّ } أي :  ليدفعوا به الحق ؛  أي :  الإِيمان {  فَأَخَذْتُهُمْ } أي :  بالعذاب {  فَكَيْفَ كَانَ عِقَابِ } أي :  كان شديداً .
