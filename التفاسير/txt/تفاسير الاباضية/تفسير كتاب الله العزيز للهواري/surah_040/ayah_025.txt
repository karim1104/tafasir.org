{  فَلَمَّا جَاءهُم } أي :  موسى {  بِالْحَقِّ مِنْ عِندِنَا قَالُوا اقْتُلُوا أَبْنَاء الَّذِينَ آمَنُوا مَعَهُ } أي :  الذين صدقوه {  وَاسْتَحْيُوا نِسَاءهُمْ } فلا تقتلوهن .   قال الله :  {  وَمَا كَيْدُ الْكَافِرِينَ } يعني المشركين {  إِلاَّ فِي ضَلاَلٍ } أي :  يذهب فلا يكون شيئاً ،   أي :  في العاقبة .
