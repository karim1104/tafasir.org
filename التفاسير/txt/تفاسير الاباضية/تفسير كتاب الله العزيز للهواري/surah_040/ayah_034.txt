قوله :  {  وَلَقَدْ جَاءكُمْ يُوسُفُ مِن قَبْلُ } [ أي :  من قبل موسى ] {  بِالْبَيِّنَاتِ } أي :  بالهدى ،   والبينات :  الحق .   {  فَمَا زِلْتُمْ فِي شَكٍّ مِّمَّا جَاءكُم بِهِ حَتَّى إِذَا هَلَكَ قُلْتُمْ لَن يَبْعَثَ اللَّهُ مِن بَعْدِهِ رَسُولاً } .   أي :  إنه لم يكن برسول ،   فلن يبعث الله من بعده رسولاً ،   كقول مشركي العرب للنبي عليه السلام :  {  يَا أَيُّهَا الَّذِي نُزِّلَ عَلَيْهِ الذِّكْرُ إِنَّكَ لَمَجْنُونٌ } [ الحجر : 6 ] ،   وكقول فرعون :  {  إِنَّ رَسُولَكُمُ الَّذِي أُرْسِلَ إِلَيْكُمْ لَمَجْنُونٌ } [ الشعراء : 27 ] أي :  فيما يدّعي .

قال :  {  كَذَلِكَ يُضِلُّ اللَّهُ مَنْ هُوَ مُسْرِفٌ } أي :  مشرك {  مُّرْتَابٌ } أي :  في شك من البعث ،   أي :  يضله الله بشركه وتكذيبه وشكّه .
