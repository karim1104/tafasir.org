قوله :  {  فَكَأَيِّن مِّنْ قَرْيَةٍ } أي :  فكم من قرية {  أَهْلَكْنَاهَا وَهِيَ ظَالِمَةٌ } يعني أهلكنا أهلها .   {  فَهِيَ خَاوِيَةٌ } أي :  فالقرية خاوية ليس فيها أحد .   قد هلك أهلها .   فهي خاوية {  عَلَى عُرُوشِهَا } أي :  على بنيانها .   وبعضهم يقول :  العروش السقوف ،   صار أعلاها أسفلها {  وَبِئرٍ مُّعَطَّلَةٍ } أي :  باد أهلها فعطِّلت {  وَقَصْرٍ مَّشِيدٍ } أي :  مبني معطّل .   [ معطوف ] على قوله معطّلة .   وقال الكلبي :  المشيد الحصين .
