قوله :  {  إِنَّ الذِينَ آمنوا وَالذِينَ هَادُوا } أي :  اليهود تهوّدوا {  وَالصَّابِئِينَ } هم قوم كانوا يعبدون الملائكة ،   ويقرؤون الزبور {  وَالنَّصَارَى } أي :  تنصرّوا .   وإنما يقال لهم نصارى لأنهم كانوا بقرية يقال لها ناصرة .   {  وَالمَجُوسَ } وهم عبدة الشمس والقمر والنار {  وَالذِينَ أَشْرَكُوا } أي :  عبدة الأوثان {  إِنَّ اللهَ يَفْصِلُ بَيْنَهُمْ يَوْمَ القِيَامَةِ } أي :  فيما اختلفوا فيه في الدنيا ،   فيدخل المؤمنين الجنة ،   ويدخل جميع هؤلاء النار ،   على ما أعد لكل قوم ،   وقد ذكرنا ذلك في سورة الحجر في قوله تعالى :

{  لَهَا سَبْعَةُ أَبْوَابٍ لِّكُلِّ بَابٍ مِّنْهُمْ جُزْءٌ مَّقْسُومٌ } [ الحجر :  44 ] .

قوله :  {  إِنَّ اللهَ عَلَى كُلِّ شَيْءٍ شَهِيدٌ } أي :  شاهد على كل شيء ،   وشاهد كل شيء .
