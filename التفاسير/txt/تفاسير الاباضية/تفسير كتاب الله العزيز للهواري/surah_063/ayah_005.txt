قوله تعالى :  {  وَإِذَا قِيلَ لَهُمْ تَعَالَوْاْ } أي :  أخلصوا الإِيمان {  يَسْتَغْفِرْ لَكُمْ رَسُولُ اللهِ لَوَّوْاْ رُءُوسَهُمْ } أي :  أعرضوا عن ذلك {  وَرَأَيْتَهُمْ يَصُدُّونَ } أي :  عن دين الله وعن الحكومة إلى نبي الله والمؤمنين ،   ويدعون إلى المحاكمة إلى وثن بني فلان الذي كان أهل الجاهلية يتحاكمون إليه .   كقوله تعالى : {  وَإِذَا دُعُواْ إِلَى اللهِ وَرَسُولِهِ لِيَحْكُمَ بَيْنَهُمْ إِذَا فَرِيقٌ مِّنْهُم مُّعْرِضُونَ } [ النور : 48 ] وكقوله تعالى : {  وَإِذَا قِيلَ لَهُمْ تَعَالَوْاْ إِلَى مَآ أَنزَلَ اللهُ وَإِلَى الرَّسُولِ رَأَيْتَ الْمُنَافِقِينَ يَصُدُّونَ عَنكَ صُدُوداً } [ النساء : 61 ] .   قال :  {  وَهُم مُّسْتَكْبِرُونَ } أي :  إنهم أهل كبر وعظمة وأَنَف .
