قال تعالى :  {  وَإِذَا رَأَيْتَهُمْ تُعْجِبُكَ أَجْسَامُهُمْ } يعني في المنظر والهيئة {  وَإِن يَقُولُواْ تَسْمَعْ لِقَوْلِهِمْ } أي :  من قولهم بما أقروا به وادعوه {  كَاَنَّهُمْ خُشُبٌ مُّسَنَّدَةٌ } أي :  إنما هم أجساد ليست لهم نية ولا حسبة في الخير .

ثم وصف جبنهم وجزعهم فقال :  {  يَحْسَبُونَ كُلَّ صَيْحَةٍ عَلَيْهِمْ } حذراً من القتال وجبناً عنه ،   ليست لهم نية في الجهاد .

ثم انقطع الكلام ،   ثم قال :  {  هُمُ الْعَدُوُّ } الأدنى إليك {  فَاحْذَرْهُمْ قَاتَلَهُمُ اللهُ } أي لعنهم الله {  أَنَّى يُؤْفَكُونَ } أي :  كيف يُصَدّون عن الإِيمان .
