{  بسم الله الرحمن الرحيم } قوله تعالى :  {  ن والْقَلَمِ } ذكروا عن الحسن قال :  نون :  الدواة ( والقلم ) هذا القلم الذي يكتب به .   وتفسير الكلبي :  القلم الذي يكتب به الملائكة الذكر وأعمال العباد .

قوله :  {  وَمَا يَسْطُرُونَ } أي :  وما يكتبون ،   يعني الملائكة {  ما أنت بنعمة ربك بمجنون }

ذكروا أن عليا قال :  ( الر ) و ( حم ) و ( ن ) :  الرحمن .   وبعضهم يقول :  ( ن ) الحوت الذي عليه قرار الأرض .  أقسم بهذا كله للنبي عليه السلام {  ما أنت بنعمة ربك بمجنون } .

ومقرأ العامة ن بالوقف والإِسكان ،   ووقع القسم على القلم وما يسطرون ،   وبعضهم يجرّون ن والقلم وما يسطرون ،   ويحمله كله على القسم .

ذكروا أن عليا قال :  ( الر ) و ( حم ) و ( ن ) :  الرحمن .   وبعضهم يقول :  ( ن ) الحوت الذي عليه قرار الأرض .   أقسم بهذا كله للنبي عليه السلام {  مَآ أَنتَ بِنِعْمَةِ رَبِّكَ بِمَجْنُونٍ } لقول المشركين إنه مجنون .
