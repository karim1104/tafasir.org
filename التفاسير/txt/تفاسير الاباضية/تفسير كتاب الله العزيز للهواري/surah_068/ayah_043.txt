{  خَاشِعَةً أَبْصَارُهُمْ } أي :  ذليلة أبصارهم {  تَرْهَقُهُمْ } أي :  تغشاهم {  ذِلَّةٌ وَقَدْ كَانُواْ يُدْعَوْنَ إِلَى السُّجُودِ } أي :  إلى الصلاة المفروضة {  وَهُمْ سَالِمُونَ } .   رجع إلى قوله تعالى :  {  وَيُدْعَوْنَ إِلَى السُّجُودِ } أي :  يُخادَعون بذلك كما كانوا يُخادِعون في الدنيا ،   وذلك أن سجودهم في الدنيا راءَوا بِهِ الناس .
