قوله :  {  اللهُ الذِي رَفَعَ السَّمَاوَاتِ بِغَيْرِ عَمَدٍ تَرَوْنَهَا } فيها تقديم في تفسير الحسن .   يقول :  الذي رفع السماوات ترونها بغير عمد .   وقال الكلبي أيضاً :  إن رفعها بغير عمد .   وقال ابن عباس :  لها عمد ولكن لا ترونها .

قوله :  {  ثُمَّ اسْتَوَى عَلَى الْعَرْشِ } .   وهو مثل قوله :  {  الرَّحْمَنُ عَلَى العَرْشِ اسْتَوَى } [ سورة طَهَ : 5 ] .   قال :  {  وَسَخَّرَ الشَّمْسَ وَالقَمَرَ كُلٌّ يَجْرِي لأَجَلٍ مُّسَمًّى } أي :  القيامة وقال بعضهم :  يجري مجرًى لا يَعْدُوه .

قوله :  {  يُدَبِّرُ الأَمْرَ } أي :  [ يقضي القضاء ] في خلقه فيما يخلق ويحيي ويميت ويرزق ويفعل {  يُفَصِّلُ الآيَاتِ } أي :  يبيّنها {  لَعَلَّكُم بِلِقَاءِ رَبِّكُمْ تُوقِنُونَ } أي :  تصدّقون بالبعث .   يقول :  {  لَعَلَّكُم بِلِقَاءِ رَبِّكُمْ تُوقِنُونَ } ،   أي :  إذا سمعتم ما في القرآن .
