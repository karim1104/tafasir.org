قوله :  {  وَقَدْ مَكَرَ الَّذِينَ مِن قَبْلِهِمْ } أي :  من قبل مشركي هذه الأمة ،   فكان مكرهم في تباب ،   أي :  في خسار .

قال الله :  {  فَلِلَّهِ المَكْرُ جَمِيعاً } فمَكَر بِهِم ؛  أهلكهم أحسن ما كانوا في دنياهم حالاً وأعزَّه .   وقال في آية أخرى :  {  وَمَا أَرْسَلْنَا فِي قَرْيَةٍ مِّن نَّبِيٍّ إِلاَّ أَخَذْنَا أَهْلَهَا بِالبَأْسَاءِ وَالضَّرَّاءِ لَعَلَّهُمْ يَضَّرَّعُونَ .   ثُمَّ بَدَّلْنَا مَكَانَ السَّيِّئَةِ الحَسَنَة } أي :  مكان الشدة الرخاء {  حَتَّى عَفَوا } أي :  حتى كثروا {  وَّقَالُوا قَدْ مَسَّ آبَاءَنَا الضَّرَّاءُ وَالسَّرَّاءُ } أي :  قد أتى على آبائنا مثل هذا فلم يكن شيء .   قال الله :  {  فَأَخَذْنَاهُم بَغْتَةً } أي :  فجأة {  وَهُمْ لاَ يَشْعُرُونَ } [ الأعراف : 94-95 ] .

قوله :  {  يَعْلَمُ مَا تَكْسِبُ كُلُّ نَفْسٍ } أي :  ما تعمل كل نفس {  وَسَيَعْلَمُ الكُفَّارُ لِمَنْ عُقْبَى الدَّارِ } أي :  لمن الجنة .
