قوله :  {  الَّذِينَ آمَنُوا وَتَطْمَئِنُّ قُلُوبُهُم } أي :  تسكن قلوبهم {  بِذِكْرِ اللهِ } قال الحسن :  بوعد الله الذي وعدهم من الجنة .

قال :  {  أَلاَ بِذِكْرِ اللهِ } أي :  بوعد الله {  تَطْمَئِنُّ القُلُوبُ } كقوله :  {  يَا أَيَّتُهَا النَّفْسُ الْمُطْمَئِنَّةُ ارْجِعِي إِلَى رَبِّكِ رَاضِيَةً مَّرْضِيَّةً فَادْخُلِي فِي عِبَادِي وَادْخُلِي جَنَّتِي } [ الفجر : 27-30 ] .   وقال بعضهم :  {  وَتَطْمَئِنُّ قُلُوبُهُم بِذِكْرِ اللهِ } أي :  هشّت قلوبهم إلى ذكر الله فاستأنست به .
