قوله :  {  وَاذْكُرُوا إِذْ أَنتُمْ قَلِيلٌ مُّسْتَضْعَفُونَ فِي الأَرْضِ } [ أي مقهورون في أرض مكة ] {  تَخَافُونَ أَن يَتَخَطَّفَكُمُ النَّاسُ } أي فارس والروم في تفسير بعضهم .   {  فَئَاوَاكُمْ } [ أي ضمّكم ] إلى المدينة حين أسلمتم .   {  وَأَيَّدَكُم } أي أعانكم {  بِنَصْرِهِ } أي نصركم على المشركين {  وَرَزَقَكُم مِّنَ الطَّيِّبَاتِ } أي :  الحلال من الرزق والغنيمة بعد ،   {  لَعَلَّكُمْ تَشْكُرُونَ } أي لكي تشكروا هذه النعم .
