قوله :  {  لِيَمِيزَ اللهُ الخَبِيثَ مِنَ الطَّيِّبِ } أي ليميز نفقة المؤمنين من نفقة الكفار .   {  وَيَجْعَلَ الخَبِيثَ بَعْضَهُ عَلَى بَعْضٍ } أي نفقاتهم التي أنفقوها في حرب النبيّ من كسبهم الخبيث .   {  فَيَرْكُمَهُ جَمِيعاً } أي بعضه على بعض {  فَيَجْعَلَهُ فِي جَهَنَّمَ } أي معهم {  أُوْلَئِكَ هُمُ الخَاسِرُونَ } قال الحسن :  هي كقوله :  {  يَوْمَ يُحْمَى عَلَيْهَا فِي نَارِ جَهَنَّمَ فَتُكْوَى بِهَا جِبَاهُهُمْ وَجُنُوبُهُمْ وَظُهُورُهُمْ } [ التوبة : 35 ] .
