قوله :  {  وَكَم مَّن مًّلَكٍ فِي السَّمَاوَاتِ لاَ تُغْنِي شَفَاعَتُهُمْ شَيْئاً } أي :  لا تنفع شفاعتهم المشركين والمنافقين شيئاً ،   إنما يشفعون للمؤمنين ولا يشفعون {  إِلاَّ مِن بَعْدِ أَن يَأذَنَ اللهُ لِمَن يَّشَآءُ وَيَرْضَى } .   هو كقوله :  {  وَلاَ يَشْفَعُونَ إِلاَّ لِمَنِ ارْتَضَى } [ الأنبياء : 28 ] وكقوله :  {  وَلاَ تَنْفَعُ الشَّفَاعَةُ عِندَهُ إِلاَّ لِمَنْ أَذِنَ لَهُ } [ سبأ : 23 ] ،   وكقوله :  {  وَلاَ يَمْلِكُ الَّذِينَ يَدْعُونَ مِنْ دُونِهِ الشَّفَاعَةَ إِلاَّ مَن شَهِدَ بِالْحَقِّ } [ الزخرف : 86 ] أي :  قال لا إله إلا الله ،   وعمل بفرائض الله .
