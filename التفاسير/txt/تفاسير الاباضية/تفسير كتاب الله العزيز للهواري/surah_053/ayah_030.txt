قال :  {  ذَلِكَ مَبْلَغُهُم مِّنَ الْعِلْمِ } أي إن علمهم لم يبلغ الآخرة .   كقوله عز وجل :  {  بَلِ ادَّارَكَ عِلْمُهُمْ فِي الآخِرَةِ بَلْ هُمْ في شَكٍّ مِّنْهَا بَلْ هُم مِّنْهَا عَمُونَ } [ النمل : 66 ] .   وقال مجاهد :  {  ذَلِكَ مَبْلَغُهُم مِّنَ الْعِلْمِ } أي :  [ مبلغ ] رأيهم .

قوله عز وجل :  {  إِنَّ رَبَّكَ هُوَ أَعْلَمُ بِمَن ضَلَّ عَن سَبِيلِهِ } أي :  إن المشركين هم الذين ضلوا عن سبيله {  وَهُوَ أَعْلَمُ بِمَنِ اهْتَدَى } أي :  إن النبي والمؤمنين هم المهتدون .
