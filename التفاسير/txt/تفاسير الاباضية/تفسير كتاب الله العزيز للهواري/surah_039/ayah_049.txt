قوله :  {  فَإِذَا مَسَّ الإِنسَانَ ضُرٌّ } أي :  مرض .   {  دَعَانَا ثُمَّ إِذَا خَوَّلْنَاهُ نِعْمَةً مِّنَّا } أي أعطيناه عافية .   فهذا الكافر {  قَالَ :  إِنَّمَا أُوتِيتُهُ عَلَى عِلْمٍ } [ تفسير مجاهد :  يقول :  هذا بعملي ] كقوله :  {  وَلَئِن أَذَقْنَاهُ رَحْمَةً مِّنَّا مِنْ بَعْدِ ضَرَّآءَ مَسَّتْهُ لَيَقُولَنَّ هَذَا لِي }

[ فصلت : 50 ] أي :  أنا محقوق بهذا .   قال الله :  {  بَلْ هِيَ فِتْنَةٌ } أي :  بلية {  وَلَكِنَّ أَكْثَرَهُمْ لاَ يَعْلَمُونَ } يعني جماعة الكافرين .
