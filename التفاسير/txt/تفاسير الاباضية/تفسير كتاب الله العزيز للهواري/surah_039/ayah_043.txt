قوله :  {  أَمِ اتَّخَذُوا مِن دُونِ اللَّهِ شُفَعَاء } أي :  قد اتخذوهم ليشفعوا لهم  زعموا  وذلك لدنياهم ليصلحوها لهم ،   كقولهم :

{  مَا نَعْبُدُهُمْ إِلاَّ لِيُقَرِّبُونَآ إلَى اللهِ زُلْفَى }

[ الزمر : 3 ] ليصلحوا لهم معايشهم ولا يقرّون بالآخرة .

قال الله :  {  قُلْ } يا محمد {  أَوَلَوْ كَانُوا } يعني أوثانهم {  لاَ يَمْلِكُونَ شَيْئًا وَلاَ يَعْقِلُونَ } أي :  إنهم لا يملكون شيئاً ولا يعقلون شيئاً .
