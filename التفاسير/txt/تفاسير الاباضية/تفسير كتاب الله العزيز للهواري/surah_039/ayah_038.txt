قوله :  {  وَلَئِن سَأَلْتَهُم } يعني المشركين {  مِّنْ خَلَقَ السَّمَاوَاتِ وَالأَرْضَ لَيَقُولُنَّ اللهُ قُلْ أفَرَءَيْتُم مَّا تَدْعُونَ مِن دُونِ اللهِ } يعني أوثانهم {  إِن أَرَادَنِي اللهُ بِضُرٍّ } أي :  بمرض {  هَلْ هُنَّ كَاشِفَاتُ ضُرِّهِ أَوْ أَرَادَنِي بِرَحْمَةٍ } أي بعافية {  هَلْ هُنَّ مُمْسِكَاتُ رَحْمَتِهِ } أي :  لا يقدرون أن يكشفن ضراً ولا يمسكن رحمة .   فكيف تعبدون الأوثان من دونه وأنتم تعلمون أن الله هو الذي خلق السماوات والأرض {  قُلْ حَسْبِيَ اللهُ عَلَيْهِ يَتَوَكَّلُ الْمُتَوَكِّلُونَ } أي :  لا رجاء غيره للصالحين .
