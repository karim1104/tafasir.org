قوله :  {  إِنَّ عِبَادِي لَيْسَ لَكَ عَلَيْهِمْ سُلْطَانٌ } مثل قوله :  {  إِنَّهُ لَيْسَ لَهُ سُلْطَانٌ عَلَى الَّذِينَ آمَنُواْ وَعَلَى رَبِّهِمْ يَتَوَكَّلُونَ } [ النحل : 99 ] أي :  لا يستطيع أن يضل من هدى الله .   قال :  {  إِنَّمَا سُلْطَانُهُ عَلَى الَّذِينَ يَتَوَلَّوْنَهُ } أي :  يتولون إبليس قال :  {  وَالَّذِينَ هُم بِهِ } أي :  بالله {  مُشْرِكُونَ } [ النحل : 100 ] .

قوله :  {  إِلاَّ مَنِ اتَّبَعَكَ مِنَ الغَاوِينَ } وهم من كل ألف تسعمائة وتسع وتسعون .
