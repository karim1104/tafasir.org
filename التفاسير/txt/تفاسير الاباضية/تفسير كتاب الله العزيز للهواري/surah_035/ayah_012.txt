قوله :  {  وَمَا يَسْتَوِي البَحْرَانِ هذَا عَذْبٌ فُرَاتٌ } أي :  حلو {  سَائِغٌ شَرَابُهُ وَهذَا مِلْحٌ أُجَاجٌ } أي :  مالح مر .   {  وَمِن كُلٍّ } أي :  من العذب والمالح {  تَأْكُلُونَ لَحْماً طَرِيّاً } يعني الحيتان {  وَتَسْتَخْرِجُونَ حِلْيَةً تَلْبَسُونَهَا } يعني اللؤلؤ {  وَتَرَى الْفُلْكَ فِيهِ مَوَاخِرَ } أي :  مقبلة ومدبرة بريح واحدة {  لِتَبْتَغُوا مِن فَضْلِهِ } يعني طلب التجارة في البحر {  وَلَعَلَّكُمْ تَشْكُرُونَ } أي :  ولكي تشكروا هذه النعم .
