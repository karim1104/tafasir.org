قوله :  {  وَلاَ تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَى } أي :  لا يحمل أحد ذنب أحد .   {  وَإِن تَدْعُ مُثْقَلَةٌ } أي :  من الذنوب {  إِلَى حِمْلِهَا } ليحمل عنها {  لاَ يُحْمَلْ مِنْهُ شَيْءٌ وَلَوْ كَانَ ذَا قُرْبَى } أي :  لا يحمل القريب عن قريبه شيئاً من ذنوبه {  إِنَّمَا تُنذِرُ } أي :  إنما يقبل نِذارتك {  الَّذِينَ يَخْشَوْنَ رَبَّهُم بِالْغَيْبِ } أي :  في السّر حيث لا يطّلع عليهم أحد {  وَأَقَامُوا الصَّلاَةَ } أي :  المفروضة {  وَمَن تَزَكَّى } أي :  عمل صالحاً {  فَإِنَّمَا يَتَزَكَّى لِنَفْسِهِ } أي :  يجد ثوابه ،   {  وَإِلَى اللهِ الْمَصِيرُ } أي :  المرجع .
