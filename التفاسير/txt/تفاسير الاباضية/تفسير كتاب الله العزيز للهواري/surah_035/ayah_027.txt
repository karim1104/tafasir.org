قوله تعالى :  {  أَلَمْ تَرَ أَنَّ اللهَ أَنزَلَ مِنَ السَّمَاءِ مَاءً فَأَخْرَجْنَا بِهِ } أي :  فأنبتنا به ،   أي :  بذلك الماء {  ثَمَرَاتٍ مُّخْتَلِفاً أَلْوَانُهَا } ،   وطعمها في الإِضمار {  وَمِنَ الجِبَالِ جُدَدٌ } أي :  طرائق {  بِيضٌ وَحُمْرٌ مُّخْتَلِفٌ أَلْوَانُهَا وَغَرَابِيبُ سُودٌ } والغربيب :  الشديد السواد .
