قوله :  {  مَتَاعٌ قَلِيلٌ } أي ذاهب :  {  ثُمَّ مَأْوَاهُمْ جَهَنَّمُ } أي مصيرهم جهنم .   {  وَبِئْسَ المِهَادُ } مثل قوله :  {  لَهُم مِّن جَهَنَّمَ مِهَادٌ } والمهاد الفراش {  وَمِن فَوْقِهِمْ غَوَاشٍ } [ الأعراف : 41 ] .   وقال :  {  لَهُم مِّن فَوْقِهِمْ ظُلَلٌ مِّنَ النَّارِ وَمِن تَحْتِهِمْ ظُلَلٌ } [ الزمر :  16 ] .
