قال نوح :  {  وَلاَ أَقُولُ لَكُمْ عِندِي خَزَائِنُ اللهِ } أي :  خزائن علم الله .   {  وَلاَ أَعْلَمُ الغَيْبَ وَلاَ أَقُولُ إِنِّي مَلَكٌ } من الملائكة {  وَلاَ أَقُولُ لِلَّذِينَ تَزْدَرِي أَعْيُنُكُمْ } من المؤمنين {  لَن يُّؤْتِيَهُمُ اللهُ خَيْراً } قال بعضهم :  إيماناً ،   وقال الحسن :  {  لَن يُؤْتِيَهُمُ اللهُ خَيْراً } أي :  في العاقبة .

{  اللهُ أَعْلَمُ بِمَا فِي أَنفُسِهِمْ } أي :  إنه سيؤتيهم بذلك خيراً إن كانت قلوبهم صادقة .   {  إِنِّي إِذاً لَّمِنَ الظَّالِمِينَ } .
