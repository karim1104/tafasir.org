قوله :  {  فَلَعَلَّكَ تَارِكٌ بَعْضَ مَا يُوحَى إِلَيْكَ } يعني النبي عليه السلام ،   حتى لا تبلّغ عن الله الرسالة مخافة قومك {  وَضَائِقٌ بِهِ صَدْرُكَ أَن يَقُولُوا } أي :  بأن يقولوا :  {  لَوْلاَ } أي :  هلا {  أُنزِلَ عَلَيْهِ كَنزٌ } أي :  مال فإنه فقير ليس له شيء {  أَوْ جَاءَ مَعَهُ مَلَكٌ } فيخبرنا أنه رسول الله فنؤمن به .

وقوله :  {  فَلَعَلَّكَ تَارِكٌ بَعْضَ مَا يُوحَى إِلَيْكَ } على الاستفهام ،   أي :  لست بتارك ذلك حتى تبلغ عن الله الرسالة .

{  إِنَّمَا أَنتَ نَذِيرٌ } أي :  تنذرهم عذاب الله في الدنيا والآخرة إن لم يؤمنوا {  وَاللهُ عَلَى كُلِّ شَيْءٍ وَكِيلٌ } أي :  حفيظ لأعمالهم حتى يجازيهم بها .
