{  فَقَالَ الْمَلأُ الَّذِينَ كَفَرُوا مِن قَوْمِهِ مَا نَرَاكَ إِلاَّ بَشَراً مِّثْلَنَا وَمَا نَرَاكَ اتِّبَعَكَ إِلاَّ الَّذِينَ هُمْ أَرَاذِلُنَا } أي :  سفلتنا {  بَادِيَ الرَّأْيِ } أي :  فيما ظهر لنا {  وَمَا نَرَى لَكُمْ عَلَيْنَا مِن فَضْلٍ } أي :  في الدين {  بَلْ نَظُنُّكُمْ كَاذِبِينَ } يعنون نوحاً ومن آمن معه .
