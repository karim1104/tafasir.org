قال :  {  وَامْرَأَتُهُ قَائِمَةٌ } أي :  امرأة إبراهيم سارّة .   {  فَضَحِكَتْ } أي :  ضحكت تعجّباً أن قوماً قد أتاهم العذاب وهم في غفلة .

قال الكلبي :  {  فَلَمَّا رَأى أَيْدِيَهُمْ لاَ تَصِلُ إِلَيْهِ نَكِرَهُمْ وَأَوْجَسَ مِنْهُمْ خِيفَةً } عرف أنهم ملائكة .   {  قَالُوا لاَ تَخَفْ إِنَّا أُرْسِلْنَا إِلَى قَوْمِ لُوطٍ } .   فلما رأت سارة فَرَقَ إبراهيم عجبت من فَرَقه فضحكت ،   وهي لا تدري من القوم .

قال :  {  فَبَشِّرْنَاهاَ بِإِسْحَاقَ } .   فبشروها بإسحاق ،   وقالوا نرجع إليك [ عاماً ] قابلاً ،   وقد ولدت غلاماً اسمه إسحاق .   {  وَ } يكون {  مِن وَرَاءِ إِسْحَاقَ يَعْقُوبَ } .

قال الحسن :  {  مِن وَرَاءِ إِسْحَاقَ } أي :  من بعد إسحاق {  يَعْقُوبَ } بشر بِنُبوّته وهو ابن إسحاق ،   وهو نبي يوحى إليه .
