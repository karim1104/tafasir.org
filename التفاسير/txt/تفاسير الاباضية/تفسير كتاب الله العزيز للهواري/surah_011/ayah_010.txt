قال :  {  وَلَئِنْ أَذَقْنَاهُ نَعْمَاءَ بَعْدَ ضَرَّاءَ مَسَّتْهُ } فعافيناه من تلك الضراء .   والضرّاء :  المرض واللاواء ،   وهي الشدائد {  لَيَقُولَنَّ ذَهَبَ السَّيِّئَاتُ عَنِّي } أي :  بعد إذ نزلت به {  إِنَّهُ لَفَرِحٌ فَخُورٌ } أي ليست له حسبة عند ضراء ،   ولا شكر عند سراء .   {  فَرِحٌ } أي بالدنيا ،   مثل قوله :  {  وَفَرِحُوا بِالحَيَاةِ الدُّنْيَا } [ الرعد : 26 ] وهم أهل الشرك .
