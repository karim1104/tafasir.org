قوله :  {  وَمَا ظَلَمْنَاهُمْ وَلَكِن ظَلَمُوا أَنفُسَهُمْ } ،   وهو كقوله :  {  وَلَكِن كَانُوا هُمُ الظَّالِمِينَ } [ الزخرف : 76 ] ،   أي :  لأنفسهم ،   وكقوله :  {  إِنَّ اللهَ لاَ يَظْلِمُ النَّاسَ شَيْئاً وَلَكِنَّ النَّاسَ أَنفُسَهُمْ يَظْلِمُونَ } [ يونس : 44 ] .

قوله :  {  فَمَا أغْنَتْ عَنْهُمْ آلِهَتُهُمُ الَّتِي يَدْعُونَ مِن دُونِ اللهِ مِن شَيْءٍ } ،   يعني  :  الأوثان التي كانوا يعبدونها .   {  لَّمَّا جَاءَ أَمْرُ رَبِّكَ } ،   يعني  :  العذاب .   {  وَمَا زَادُوهُمْ } ،   أي :  تلك الأوثان في عبادتهم ،   {  غَيْرَ تَتْبِيبٍ } ،   أي :  غير تخسير .   وقال الحسن :  غير تدمير .
