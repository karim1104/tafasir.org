قوله :  {  يَآ أَيُّهَا الَّذِينَ آمَنُوا اتَّقُوا اللهَ وَآمِنُوا بِرَسُولِهِ يُؤْتِكُمْ كِفْلَيْنِ مِن رَّحْمَتِهِ } أي أجرين {  وَيَجْعَل لَّكُمْ نُوراً تَمْشُونَ بِهِ } أي :  ويجعل لكم إيماناً [ تهتدون به ] كقوله عز وجل : {  أَوَ مَن كَانَ مَيتاً فَأَحْيَيْنَاهُ وَجَعَلْنَا لَهُ نُوراً يَمْشِي بِهِ فِي النَّاسِ } [ الأنعام :  122 ] {  وَيَغْفِرْ لَكُمْ وَاللهُ غَفُورٌ رَّحِيمٌ } أي :  لمن تاب .
