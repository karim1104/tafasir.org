قال :  {  يُنَادُونَهُم } أي ينادي المنافقون المؤمنين حين ضرب الله بينهم بسور :  {  أَلَمْ نَكُن مَّعَكُمْ } أي في الدنيا ،   أي على دينكم ،   نشهد بشهادتكم ،   ونتنسك مناسككم {  قَالُواْ } أي قال لهم المؤمنون {  بَلَى } [ أي فيما أظهرتم ] {  وَلَكِنَّكُمْ فَتَنتُمْ أَنفُسَكُمْ } أي :  بالمعاصي {  وَتَرَبَّصْتُمْ } أي :  بالتوبة .   {  وَارْتَبْتُمْ } أي :  وشككتم أن يعذبكم الله بعد إقراركم وشهادتكم {  وَغَرَّتْكُمُ الأَمَانِيُّ } التي منيتم بها أنفسكم من قولكم .   يهلك محمد وأصحابه فلا نستفسد إلى إخواننا من المشركين .   {  حَتَّى جَآءَ أَمْرُ اللهِ } أي :  الموت وأنتم على حالكم هذه {  وَغَرَّكُم بِاللهِ الْغَرُورُ } وهو الشيطان ،   غرّكم بوسواسه إليكم أن الله لا يعذبكم بعد إقراركم وتوحيدكم .
