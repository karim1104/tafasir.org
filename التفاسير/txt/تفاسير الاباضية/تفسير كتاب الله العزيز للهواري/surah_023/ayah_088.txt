ثم قال :  {  قُلْ } لهم يا محمد {  مَن بِيَدِهِ مَلَكُوتُ كُلِّ شَيْءٍ وَهُوَ يُجِيرُ وَلاَ يُجَارُ عَلَيْهِ } {  مَلَكُوتُ كُلِّ شَيْءٍ } أي :  ملك كل شيء وخزائنه .   {  وَهُوَ يُجِيرُ } من يشاء ،   فيمنعه فلا يوصل إليه {  وَلاَ يُجَارُ عَلَيْهِ } أي :  من أراد أن يعذّبه لم يستطع أحد منعَه {  إِنْ كُنْتُمْ تَعْلَمُونَ } .
