{  بسم الله الرحمن الرحيم } قوله عز وجل :  {  يَآ أَيُّهَا الَّذِينَ آمَنُوا لاَ تَتَّخِذُوا عَدُوِّي وَعَدُوَّكُمْ أَوْلِيَآءَ } [ يعني في الدين ] {  تُلْقُونَ إلَيْهِم بِالْمَوَدَّةِ } أي في الدنيا {  وَقَدْ كَفَرُوا بِمَا جَآءَكُم مِّنَ الْحَقِّ } أي :  القرآن {  يُخْرِجُونَ الرَّسُولَ وَإِيَّاكُمْ } أي أخرجوا الرسل {  أَن تُؤْمِنُوا بِاللهِ رَبِّكُمْ } أي :  إنهم أخرجوكم من مكة لأنكم آمنتم بربكم .

ثم قال تعالى :  {  إِنْ كُنتُمْ خَرَجْتُمْ جِهَاداً فِي سَبِيلِي وَابْتِغَآءَ مَرْضَاتِي تُسِرُّونَ إِلَيْهِم بِالْمَوَدَّةِ } وبأخبار النبي عليه السلام والمؤمنين .   {  وَأَنَا اعْلَمُ بِمَآ أَخْفَيْتُمْ وَمَآ أَعْلَنتُمْ وَمَن يَفْعَلْهُ مِنكُمْ } أي :  ومن ينافق منكم .   {  فَقَدْ ضَلَّ سَوَآءَ السَّبِيلِ } أي :  قصد الطريق طريق الهدى .
