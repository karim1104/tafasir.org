قوله عز وجل :  {  يَوْمَ تُقَلَّبُ وُجُوهُهُمْ فِي النَّارِ } أي :  يُجَرّون على وجوههم ،   تجرّهم الملائكة {  يَقُولُونَ } أي :  في النار {  يَا لَيْتَنَا أَطَعْنَا اللهَ وَأَطَعْنَا الرَّسُولاَ } وإنما صارت {  الرَّسُولاَ } و {  السَّبِيلاَ } لأنها مخاطبة .   وهذا جائز في كلام العرب إذا كانت مخاطبة .
