ثم قال :  {  لَّئِن لَّمْ يَنتَهِ الْمُنَافِقُونَ وَالَّذِينَ فِي قُلُوبِهِم مَّرَضٌ } يعني الزنى {  وَالْمُرْجِفُونَ فِي الْمَدِينَةِ } يعني المنافقون ،   يرجفون بالنبي وأصحابه ؛  يقولون :  يهلك محمد وأصحابه .   وقال الكلبي :  {  لَّئِن لَّمْ يَنتَهِ المُنَافِقُونَ } أي :  لئن لم ينتهوا عن أذى نساء المؤمنين .   {  لَنُغْرِيَنَّكَ بِهِمْ } أي :  لنسلطَنَّك عليهم {  ثُمَّ لاَ يُجَاوِرُونَكَ فِيهَا } أي :  في المدينة .
