قوله :  {  وَإِذْ قَالَ مُوسَى لِقَوْمِهِ اذْكُرُوا نِعْمَةَ اللهِ عَلَيْكُمْ } ثم أخبر بتلك النعمة فقال :  {  إِذْ أَنْجَاكُم مِّنْ آلِ فِرْعَوْنَ يَسُومُونَكُمْ سُوءَ العَذَابِ } أي :  يذيقونكم شدّة العذاب {  وَيُذَبِّحُونَ أَبْنَاءَكُمْ وَيَسْتَحْيُونَ نِسَاءَكُمْ } أي :  فلا يقتلونهن {  وَفِي ذَلِكُم } أي :  فيما نجاكم منهم {  بَلاَءٌ مِّن رَّبِّكُمْ عَظِيمٌ } أي :  نعمة من ربكم عظيمة .   وقال في آية أخرى :  {  إِنَّ فِرْعَوْنَ عَلاَ فِي الأَرْضِ } أي :  بغى في الأرض {  وَجَعَلَ أَهْلَهَا شِيَعاً } [ القصص : 4 ] أي :  فرقاً ؛  يقتل طائفة ،   ويستحيي طائفة ،   ويستعبد طائفة ،   فهو الذي كان يسومهم سوء العذاب .
