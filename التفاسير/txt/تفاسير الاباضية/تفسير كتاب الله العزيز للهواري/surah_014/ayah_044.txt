قوله :  {  وَأَنذِرِ النَّاسَ } أي :  في الدنيا {  يَوْمَ يَأْتِيهِمُ العَذَابُ } أي :  أنذرهم اليوم ذلك اليوم {  فَيَقُولُ الَّذِينَ ظَلَمُوا } أي :  الذين أشركوا والذين نافقوا {  رَبَّنَا أَخِّرْنَا إِلَى أَجَلٍ قَرِيبٍ نُّجِبْ دَعْوَتَكَ وَنَتَّبِعِ الرُّسُلَ } .   سألوا الرجعة إلى الدنيا حتى يؤمنوا ويجيبوا الدعوة ويتّبعوا الرسل ويكملوا الفرائض .   قال الله :

{  أَوَلَمْ تَكُونُوا أَقْسَمْتُم مِّن قَبْلُ } أي :  في الدنيا {  مَا لَكُم مِّن زَوَالٍ } أي :  من الدنيا إلى الآخرة ،   يعني المشركين خاصة .   ثم انقطع الكلام .
