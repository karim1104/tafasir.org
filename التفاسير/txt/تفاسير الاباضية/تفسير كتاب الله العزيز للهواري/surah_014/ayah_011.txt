{  قَالَتْ لَهُمْ رُسُلُهُمْ إِنْ نَّحْنُ إِلاَّ بَشَرٌ مِّثْلُكُمْ وَلَكِنَّ اللهَ يَمُنُّ عَلَى مَن يَشَاءُ مِنْ عِبَادِهِ } أي :  بالنبوة فيوحي إليه .   {  وَمَا كَانَ لَنَا أَن نَّأْتِيَكُم بِسُلْطَانٍ } أي :  بحجة {  إِلاَّ بِإِذْنِ اللهِ } أي :  إلا بأمر الله {  وَعَلَى اللهِ فَلْيَتَوَكَّلِ المُؤْمِنُونَ } .
