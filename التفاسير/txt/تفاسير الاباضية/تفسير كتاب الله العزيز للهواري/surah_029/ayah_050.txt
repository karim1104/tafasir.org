{  وَقَالُوا لَوْلاَ } أي :  هلاّ {  أُنزِلَ عَلَيْهِ آيَاتٌ مِّن رَّبِّهِ قُلْ إِنَّمَا الآيَاتُ عِندَ اللهِ } كانوا يسألون النبي أن يأتيهم بالآيات كقولهم :

{  فَلْيَأْتِنَا بِآيَةٍ كَمَا أُرْسِلَ الأوَّلُونَ }

[ الأنبياء :  5 ] وما أشبه ذلك .   قال الله :  {  قُلْ إِنَّمَا الآيَاتُ عِندَ اللهِ } إذا شاء أنزلها {  وَإِنَّمَا أَنَا نَذِيرٌ مُّبِينٌ } أي :  ليس عليّ أكثر من أن أنذركم كما أمرت .
