قال الله :  {  يَوْمَ يَغْشَاهُمُ الْعَذَابُ مِن فَوْقِهِمْ وَمِن تَحْتِ أَرْجُلِهِمْ } وهذا عذاب جهنم .   كقوله :

{  لَهُم مِّن جَهَنَّمَ مِهَادٌ وَمِن فَوْقِهِمْ غَوَاشٍ } [ الأعراف :  41 ] أي :  يغشاهم .   وكقوله :

{  لَهُم مِّن فَوْقِهِمْ ظُلَلٌ مِّنَ النَّارِ وَمِن تَحْتِهِمْ ظُلَلٌ } [ الزمر :  16 ] قال :  {  وَيَقُولُ ذُوقُوا مَا كُنتُمْ تَعْمَلُونَ } أي :  ثواب  ما كنتم تعملون في الدنيا .
