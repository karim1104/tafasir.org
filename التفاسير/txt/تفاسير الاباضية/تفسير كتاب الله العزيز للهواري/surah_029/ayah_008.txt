قوله :  {  وَوَصَّيْنَا الإِنْسَانَ } يعني جميع الناس {  بِوَالِدَيْهِ حُسْناً } أي :  بِرّاً كقوله :  {  وَبِالوَالِدَيْنِ إِحْسَانًا }

[ النساء :  36 ] قال :  {  وَإِن جَاهَدَاكَ لِتُشْرِكَ بِي } أي :  إن أراداك على أن تشرك بي {  مَا لَيْسَ لَكَ بِهِ عِلْمٌ فَلاَ تُطِعْهُمَا } أي :  إنك لا تعلم أن معي شريكاً ،   يعني المؤمنين .   {  إِلَىَّ مَرْجِعُكُمْ } يعني يوم القيامة {  فَأُنَبِّئُكُم بِمَا كُنتُمْ تَعْمَلُونَ } .
