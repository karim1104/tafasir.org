قوله :  {  إِن تَحْرِصْ عَلَى هُدَاهُمْ فَإِنَّ اللهَ لاَ يَهْدِي مَن يُضِلُّ } كقوله :  {  مَن يُّضْلِلِ اللهُ فَلاَ هَادِيَ لَهُ } [ الأعراف : 186 ] .   وهي تقرأ على وجه آخر :  {  لا يَهْدِي من يُضِل } :  أي :  من أضله الله ،   وقد حقت عليه الضلالة بفعله ،   فإن الله لا يهديه .   وقوله :  {  إِنْ تَحْرِصْ } كقوله :  {  إِنَّكَ لاَ تَهْدِي مَنْ أَحْبَبْتَ وَلَكِنَّ اللهَ يَهْدِي مَن يَشَاءُ } [ القصص : 56 ] {  وَمَا لَهُم مِّن نَّاصِرِينَ } أي :  إذا جاءهم العذاب .
