ثم قال :  {  لِلَّذِينَ لاَ يُؤْمِنُونَ بِالآخِرَةِ مَثَلُ السَّوْءِ وَلِلَّهِ المَثَلُ الأَعْلَى } أي :  إنه {  لَمْ يَتَّخِذْ وَلَداً وَلَم يَكُن لَّهُ شَرِيكٌ فِي المُلْكِ } [ الإسراء : 111 ] {  وَهُوَ العَزِيزُ الحَكِيمُ } .

قال بعضهم :  في قوله :  {  وَلِلَّهِ المَثَلُ الأَعْلَى } قال :  الإِخلاص والتوحيد .
