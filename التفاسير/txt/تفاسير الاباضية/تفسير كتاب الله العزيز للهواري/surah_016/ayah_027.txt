قال :  {  ثُمَّ يَوْمَ القِيَامَةِ يُخْزِيهِمْ } أي :  في النار بعد عذاب الدنيا {  وَيَقُولُ أَيْنَ شُرَكَائيَ } أي :  الذين زعمتم أنهم شركائي {  الَّذِينَ كُنتُمْ تُشَاقُّونَ فِيهِمْ } أي :  تفارقون فيهم ،   يعني المحاربة والعداوة ،   أي :  عادوا الله في الأوثان يعبدونها من دونه .

{  قَالَ الَّذِينَ أُوتُوا العِلْمَ } وهم المؤمنون {  إِنَّ الخِزْيَ اليَوْمَ } أي :  الهوان {  وَالسُّوءَ } أي :  العذاب {  عَلَى الكَافِرِينَ } وهذا الكلام يوم القيامة .
