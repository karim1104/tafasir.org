قال :  {  وَأَمَّا ثَمُودُ فَهَدَيْنَاهُمْ } أي :  فبصّرناهم ،   وهو في تفسير العامة بيّنّا لهم سبيل الهدى وسبيل الضلالة {  فَاسْتَحَبُّوا الْعَمَى } أي :  الضلالة {  عَلَى الْهُدَى } أي :  اختاروا الضلالة على الهدى {  فَأَخَذَتْهُمْ صَاعِقَةُ الْعَذَابِ الْهُونِ } أي من الهوان {  بِمَا كَانُوا يَكْسِبُونَ } أي :  بما كانوا يعملون .
