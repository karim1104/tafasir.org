قوله :  {  وَلَقَدْ آتَيْنَا مُوسَى الْكِتَابَ } يعني التوراة {  فَاخْتُلِفَ فِيهِ } يعني آمن به قوم وكفر به قوم {  وَلَوْلاَ كَلِمَةٌ سَبَقَتْ مِن رَّبِّكَ } أي :  ألا يحاسب بحساب الآخرة في الدنيا {  لَقُضِيَ بَيْنَهُمْ } أي :  لحاسبهم في الدنيا فأدخل أهل الجنة الجنة ،   وأهل النار النار .   وهذا تفسير الحسن .

وقال الكلبي :  {  وَلَوْلاَ كَلِمَةٌ سَبَقَتْ مِن رَّبِّكَ } لكفار هذه الأمة ألا يهلكهم بالعذاب قبل يوم القيامة ،   كما أهلك من كان قبلهم من الكفار ،   لقضي بينهم ،   أي :  لعذبهم كما عذب الأمم الأولى حين كذّبوا رسلهم .   قال :  {  وَإِنَّهُمْ لَفِي شَكٍّ مِّنْهُ } أي :  من العقاب {  مُرِيبٍ } أي :  من الريبة .
