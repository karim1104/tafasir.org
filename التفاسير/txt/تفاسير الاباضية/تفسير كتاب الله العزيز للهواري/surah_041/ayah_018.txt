قال :  {  وَنَجَّيْنَا الَّذِينَ آمَنُوا وَكَانُوا يَتَّقُونَ } وكذلك قضى الله أنه إذا أهلك قوماً أنجى رسولهم والمؤمنين معه ؛  كقوله :  {  وَلَمَّا جَاءَ أَمْرُنَا } أي :  عذابنا {  وَلَمَّا جَاء أَمْرُنَا نَجَّيْنَا هُودًا وَالَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مِّنَّا } [ هود : 58 ] ،   وقوله :  {  فَلَمَّا جَاء أَمْرُنَا نَجَّيْنَا صَالِحًا وَالَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مِّنَّا } [ هود : 66 ] ،   وقوله :  {  وَلَمَّا جَاء أَمْرُنَا نَجَّيْنَا شُعَيْبًا وَالَّذِينَ آمَنُواْ مَعَهُ بِرَحْمَةٍ مَّنَّا } [ هود : 94 ] .
