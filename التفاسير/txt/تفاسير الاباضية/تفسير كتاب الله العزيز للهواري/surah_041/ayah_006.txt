قال الله تعالى للنبي عليه السلام :  {  قُلْ إِنَّمَا أَنَا بَشَرٌ مِّثْلُكُمْ يُوحَى إِلَيَّ } أي :  إنما أنا بشر مثلكم ،   غير أنه يوحى إلي {  أَنَّمَا إِلَهُكُمْ إِلَهٌ وَاحِدٌ فَاسْتَقِيمُوا إِلَيْهِ } بالتوحيد والعمل الصالح {  وَاسْتَغْفِرُوهُ } أي :  من الشرك والنفاق والعمل السوء .

{  وَوَيْلٌ لِّلْمُشْرِكِينَ } أي :  في النار
