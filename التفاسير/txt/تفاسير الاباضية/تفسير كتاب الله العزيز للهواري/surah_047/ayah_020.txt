قوله عزّ وجلّ :  {  وَيَقُولُ الَّذِينَ آمَنُوا لَوْلاَ } أي :  هلاّ {  نُزِّلَتْ سُورَةٌ فَإِذَا أُنزِلَتْ سُورَةٌ مُّحْكَمَةٌ } والمحكمة المفروضة {  وَذُكِرَ فِيهَا الْقِتَالُ } وهي كل سورة فرض فيها القتال ،   أي أُمِرَ به {  رَأَيْتَ الَّذِينَ فِي قُلُوبِهِم مَّرَضٌ } يعني المنافقين {  يَنظُرُونَ إِلَيْكَ نَظَرَ الْمَغْشِيِّ عَلَيْهِ مِنَ الْمَوْتِ } أي :  خوفاً منه وكراهية للقتال .   كقوله :  {  يَحْسَبُونَ كُلَّ صَيْحَةٍ عَلَيْهِمْ هُمُ الْعَدُوُّ فَاحْذَرْهُمْ } [ المنافقون : 4 ] .

قال :  {  فَأَوْلَى لَهُمْ } وهذا وعيد من الله لهم :  ثم انقطع الكلام .
