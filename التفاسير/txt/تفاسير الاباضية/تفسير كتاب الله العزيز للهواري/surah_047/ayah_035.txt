قوله عز وجل :  {  فَلاَ تَهِنُوا } أي :  لا تضعفوا في الجهاد {  وَتَدْعُوا إِلَى السَّلْمِ } أي :  إلى الصلح .   أي :  لا تدعوا إلى الصلح {  وَأَنتُمُ الأَعْلَوْنَ } أي :  الظاهرون المنصورون ؛  يقوله للمؤمنين .   وهذا الحرف يقرأ بوجه آخر :  إلى السِّلْم ،   أي :  إلى الإسلام .   قال :  {  وَاللَّهُ مَعَكُمْ } أي :  ناصركم {  وَلَن يَتِرَكُمْ } أي :  ولن يظلمكم {  أَعْمَالَكُمْ } .
