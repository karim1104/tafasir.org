قوله :  {  إِذْ قَالَ مُوسَى لأَهْلِهِ إِنِّي آنَسْتُ نَاراً } قال بعضهم :  إني أحسست ناراً .   وقال في آية أخرى :

{  إِذْ رَأَى نَاراً } [ طه :  10 ] أي :  رآها ناراً عند نفسه ،   وإنما كانت نوراً .

{  سََآتِيكُم مِّنْهَا بِخَبَرٍ } أي :  بخبر الطريق ،   وكان على غير الطريق .   وقال في آية أخرى :  {  أًو أَجِدُ عَلَى النَّارِ هُدىً } أي :  هداة يهدونني إلى الطريق .   {  أَو آتِيكُم بِشِهَاب قَبَسٍ } وقال في آية أخرى :  {  أَوْ جِذْوَةٍ مِّنَ النَّارِ }

[ القصص :  29 ] ،   {  لَّعَلَّكُمْ تَصْطَلُونَ } لكي تصطلوا ،   وكان شاتياً .
