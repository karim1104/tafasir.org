{  قَالَ يَا قَوْمِ لِمَ تَسْتَعْجِلُونَ بِالسَّيِّئَةِ قَبْلَ الحَسَنَةِ } والسيئة العذاب ،   لقولهم :  {  فَأتِنَا بِمَا تَعِدُنَا إِن كُنتَ مِنَ الصَّادِقِينَ } [ الأعراف :  70 ] أي :  المرسلين .   والحسنة :  الرحمة .   {  لَوْلاَ } أي :  هلا {  تَسْتَغْفِرُونَ اللهَ } أي :  من شرككم {  لَعَلَّكُمْ تُرْحَمُونَ } أي :  لكي تُرْحَمُوا .
