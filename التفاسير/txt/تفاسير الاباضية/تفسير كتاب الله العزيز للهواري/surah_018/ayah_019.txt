{  وَكَذَلِكَ } أي :  بهيئاتهم {  بَعَثْنَاهُمْ لِيَتَسَاءَلُوا بَيْنَهُمْ قَالَ قَائِلٌ مِّنْهُمْ كَمْ لَبِثْتُمْ قَالُوا لَبِثْنَا يَوْماً أَوْ بَعْضَ يَوْمٍ } .   وكانوا دخلوا الكهف في أول النهار .   قال :  فنظروا فإذا هو قد بقي من الشمس بقيّة ،   فقالوا :  أو بعض يوم .   ثم إنهم شكّوا ،   فردّوا علم ذلك إلى الله ف {  قَالُوا رَبُّكُمْ أَعْلَمُ بِمَا لَبِثْتُمْ } يقوله بعضهم لبعض .

قال :  {  فَابْعَثُوا أَحَدَكُم بِوَرِقِكُمْ هَذِهِ } أي :  بدراهمكم هذه {  إِلَى المَدِينَةِ } وكانت معهم دراهم {  فَلْيَنظُرْ أَيُّهَا أَزْكَى طَعَاماً } قال بعضهم :  أحل طعاماً ،   وقد كان من طعام قومهم ما لا يستحلون أكله قط .   وقال بعضهم :  أزكى أي :  أطيب {  فَلْيَأْتِكُم بِرِزْقٍ مِّنْهُ وَلْيَتَلَطَّفْ وَلاَ يُشْعِرَنَّ } أي :  لا يعلمنّ {  بِكُمْ أَحَدا } .  ً
