قال :  {  وَمَنْ أَظْلَمُ مِمَّن ذُكِّرَ بآيَاتِ رَبِّهِ } يقوله على الاستفهام .   وهذا استفهام على معرفة {  فَأَعْرَضَ عَنْهَا } أي :  لم يؤمن بها .   {  وَنَسِيَ مَا قَدَّمَتْ يَدَاهُ } أي :  ما سلف منه .   قال الحسن :  عمله السوء .   أي :  لا أحد أظلم منه .

قوله :  {  إِنَّا جَعَلْنَا عَلَى قُلُوبِهِمْ أَكِنَّةً } أي :  غلفاً {  أَن يَفْقَهُوهُ } أي :  لئلا يفقهوه .   {  وَفِي آذَانِهِمْ وَقْراً } وهو الصمم عن الهدى .   {  وَإِن تَدْعُهُمْ إِلَى الهُدَى فَلَن يَهْتَدُوا إِذاً أَبَداً } يعني الذين يموتون على كفرهم .
