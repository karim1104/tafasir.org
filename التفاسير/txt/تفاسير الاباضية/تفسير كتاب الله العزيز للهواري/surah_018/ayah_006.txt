قوله :  {  فَلَعَلَّكَ بَاخِعٌ نَّفْسَكَ } أي :  قاتل نفسك في تفسير العامة {  عَلَى آثَارِهِمْ } أي :  آسفاً ،   أي :  حزناً عليهم في تفسير مجاهد .   {  إِن لَّمْ يُؤْمِنُوا بِهَذَا الحَدِيثِ } أي :  القرآن .   {  أَسَفاً } .   قال بعضهم :  غضباً .   وهي مثل قوله :  {  فَلَمَّا آسَفُونَا } [ الزخرف : 55 ] أي :  أغضبونا .   وقال مجاهد :  أسفاً :  أي :  جزعاً .
