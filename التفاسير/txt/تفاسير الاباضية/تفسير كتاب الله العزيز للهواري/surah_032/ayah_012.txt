قوله :  {  وَلَوْ تَرَى إِذِ الْمُجْرِمُونَ } أي :  المشركون والمنافقون {  نَاكِسُوا رُءُوسِهِمْ عِندَ رَبِّهِمْ } أي :  خزايا نادمين {  رَبَّنَا أَبْصَرْنَا وَسَمِعْنَا } أي :  يقولون :  أبصرنا وسمعنا ،   أي :  سمعوا حين لم ينفعهم السمع وأبصروا حين لم ينفعهم البصر .   {  فَارْجِعْنَا } أي :  إلى الدنيا {  نَعْمَلْ صَالِحاً إِنَّا مُوقِنُونَ } أي :  بالذي أتانا به محمد أنه حق .
