قال :  {  ثُمَّ سَوَّاهُ } أي :  سوّى خلقه كيف شاء {  وَنَفَخَ فِيهِ مِن رُّوحِهِ } أي :  ضعيف ،   يعني النطفة .   قال :  {  ثُمَّ سَوَّاهُ } أي :  سوّى خلقه كيف شاء {  وَنَفَخَ فِيهِ مِن رُّوحِهِ } أي :  أحدث فيه الروح .   قال :  {  وَجَعَلَ لَكُمُ السَّمْعَ وَالأَبْصَارَ وَالأَفْئِدَةَ قَلِيلاً مَّا تَشْكُرُونَ } أي :  أقلكم المؤمنون ،   وهم الشاكرون .
