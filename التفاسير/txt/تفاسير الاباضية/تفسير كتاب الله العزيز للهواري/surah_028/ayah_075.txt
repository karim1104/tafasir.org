قال :  {  وَنَزَعْنَا مِن كُلِّ أُمَّةٍ شَهِيداً } أي :  جئنا برسولهم ،   كقوله :  {  فَكَيْفَ إِذَا جِئْنَا مِن كُلِّ أُمَّةٍ بِشَهِيدٍ وَجِئْنَا بِكَ عَلَى هَؤُلاءِ شَهِيداً } [ النساء :  41 ] ،   وكقوله :  {  يَوْمَ نَدْعُو كُلَّ أُنَاسٍ بِإمَامِهِمْ } [ الإِسراء :  71 ] أي :  بنبيّهم ،   وقال بعضهم :  بكتابهم قال :  {  فَقُلْنَا هَاتُوا بُرْهَانَكُمْ } أي :  حُجَّتكم ،   في تفسير الحسن ،   أي :  بأن الله أمركم بما كنتم عليه من الشرك .   وقال بعضهم :  {  هَاتُوا بُرْهَانَكُمْ } أي :  بيّنَتَكم .   قال :  {  فَعَلِمُوا } أي :  يومئذ {  أَنَّ الْحَقَّ لِلَّهِ } أي :  التوحيد {  وَضَلَّ عَنْهُم مَّا كَانُوا يَفْتَرُونَ } يعني أوثانهم التي كانوا يعبدون .
