{  وَلاَ تَدْعُ مَعَ اللهِ إلهاً آخَرَ لا إلهَ إِلاَّ هُوَ كُلُّ شَيْءٍ هَالِكٌ إِلاَّ وَجْهَهُ } يعني إلا هو ،   كقوله :

{  كُلُّ مَنْ عَلَيْهَا فَانٍ وَيَبْقَى وَجْهُ رَبِّكَ ذُو الجَلاَلِ وَالإِكْرَامِ }

[ الرحمن :  26-27 ] {  لَهُ الحُكْمُ } أي :  له القضاء {  وَإِلَيْهِ تُرْجَعُونَ } أي :  إليه  يرجع الخلق يوم القيامة .
