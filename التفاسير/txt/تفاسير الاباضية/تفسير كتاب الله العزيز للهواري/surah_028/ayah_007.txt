قوله :  {  وَأَوْحَيْنَا إِلَى أُمِّ مُوسَى } وحي إلهام ،   أي :  قذف في قلبها ،   وليس بوحي نبوّة .   {  أَن أَرْضِعِيهِ فَإِذَا خِفْتِ عَلَيْهِ } الطلب {  فَأَلْقِيهِ فِي اليَمِّ } أي :  البحر {  وَلاَ تَخَافِي } أي :  الضّيعة {  وَلاَ تَحْزَنِي } أن يُقتل {  إِنَّا رَادُّوهُ إِلَيْكِ وَجَاعِلُوهُ مِنَ المُرْسَلِينَ } فجعلته في تابوت ،   ثم قذفته في البحر .
