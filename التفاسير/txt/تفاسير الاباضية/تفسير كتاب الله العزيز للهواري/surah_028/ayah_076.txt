قوله :  {  إِنَّ قَارُونَ كَانَ مِن قَوْمِ مُوسَى } ،   كان ابن عمه ،   أخي أبيه {  فَبَغَى عَلَيْهِمْ } كان عاملاً لفرعون فتعدّى عليهم وظلمهم {  وَآتَيْنَاهُ } يعني قارون أعطيناه {  مِنَ الْكُنُوزِ } أي :  من الأموال {  مَا إِنَّ مَفَاتِحَهُ } قال بعضهم :  خزائنه ،   يعني أمواله ،   وقال بعضهم :  مفاتح خزائنه {  لَتَنُوءُ بِالْعُصْبَةِ } أي :  لتثقل العصبة {  أُولِي القُوَّةِ } أي :  من الرجال ،   والعصبة الجماعة ،   وهم ها هنا أربعون رجلاً .

{  إِذْ قَالَ لَهُ قَوْمُهُ } إذ قال له موسى والمؤمنون من بني إسرائيل {  لاَ تَفْرَحْ } أي :  لا تبطر {  إِنَّ اللهَ لاَ يُحِبُّ الْفَرِحِينَ } أي :  المرحين المشركين الذين يفرحون بالدنيا ولا يفرحون بالآخرة ،   أي :  لا يؤمنون بها ،   لا يرجونها .   وقال في آية أخرى :  {  وَفَرِحُوا بِالْحَيَاةِ الدُّنْيَا } ،   وهم المشركون .

وقال مجاهد :  {  لاَ يُحِبُّ الفَرِحِينَ } [ المُتَبَذِّخِينَ ] الأَشِرين البَطِرِين الذين لا يشكرون الله فيما أعطاهم ،   وهو واحد .
