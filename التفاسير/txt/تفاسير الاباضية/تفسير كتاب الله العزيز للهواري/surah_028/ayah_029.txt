قال :  {  فَلَمَّا قَضَى مُوسَى الأَجَلَ } ذكر ابن عباس قال :  قضى أوفاهما وأبرهما :  العشر .   قوله :  {  وَسَارَ بِأَهْلِهِ } قال مجاهد :  {  فَلَمَّا قَضَى مُوسَى الأَجَلَ وَسَارَ بِأَهْلِهِ } أي :  قضى العشر السنين ثم أقام بعد ذلك عشر سنين فخرج بعد عشرين سنة .   {  آنَسَ مِن جَانِبِ الطُّورِ نَاراً } أي :  حسب أنها نار ،   وإنما كانت ناراً عند موسى ،   وهي نور وليست بنار .   {  قَالَ لأَهْلِهِ امْكُثُوا إِنِّي آنَسْتُ نَاراً لَّعَلِّي آتِيكُم مِّنْهَا بِخَبَرٍ } أي :  بخبر الطريق ،   وكان على غير الطريق {  أوْ جَذْوَةً مِّنَ النَّارِ } وهي أصل شجرة {  لَعَلَّكُمْ تَصْطَلُونَ } أي :  لكي تصطلوا ،   وكان شاتياً .
