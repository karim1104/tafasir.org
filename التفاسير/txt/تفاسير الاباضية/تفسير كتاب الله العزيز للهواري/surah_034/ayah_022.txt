قوله :  {  قُلِ ادْعُوا الَّذِينَ زَعَمْتُم مِّن دُونِ اللهِ } يعني أوثانهم ،   أي :  زعمتم أنهم آلهة {  لاَ يَمْلِكُونَ } أي :  لا تملك تلك الآلهة {  مِثْقَالَ ذَرَّةٍ } أي :  وزن ذرة {  فِي السَّمَاوَاتِ وَلاَ فِي الأَرْضِ وَمَا لَهُمْ فِيهِمَا } أي :  في السموات و الأرض {  مِن شِرْكٍ } {  وَمَا لَهُ } أي :  لله {  مِنْهُم } أي :  من أوثانهم {  مِّن ظَهِيرٍ } أي :  من عوين .
