قال الله :  {  فَاليَوْمَ } يعني يوم القيامة {  لاَ يَمْلِكُ بَعْضُكُمْ لِبَعْضٍ نَّفْعاً وَلاَ ضَرّاً } أي :  الشياطين والكفار {  وَنَقُولُ لِلَّذِينَ ظَلَمُوا } أي :  أشركوا {  ذُوقُوا عَذَابَ النَّارِ الَّتِي كُنتُم بِهَا تُكَذِّبُونَ } وهم جميعاً قرناء في النار :  الشياطين ومن أضلوا يلعن بعضهم بعضاً ويبرأ بعضهم من بعض .
