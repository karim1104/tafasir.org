قوله :  {  وَلَقَدْ آتَيْنَا دَاوُودَ مِنَّا فَضْلاً } يعني النبوة {  يَا جِبَالُ أَوِّبِي مَعَهُ } أي :  سبّحي معه {  وَالطَّيْرَ } وهو قوله :

{  وَسَخَّرْنَا مَعَ دَاوُودَ الجِبَالَ يُسَبِّحْنَ وَالطَّيْرَ } [ الأنبياء :  79 ]

قال :  {  وَأَلَنَّا لَهُ الْحَدِيدَ } ألانه الله له ،   فكان يعمل بلا نار ولا مطرقة بأصابعه الثلاث كهيئة الطين بيده
