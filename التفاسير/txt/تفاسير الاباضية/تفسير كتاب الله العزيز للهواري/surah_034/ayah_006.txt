قوله :  {  وَيَرَى الَّذِينَ أُوتُوا الْعِلْمَ } يعني المؤمنين {  الَّذِي أُنزِلَ إِلَيْكَ مِن رَّبِّكَ هُوَ الْحَقَّ } أي :  يعلمون أنه هو الحق {  وَيَهْدِي } أي :  ويعلمون أن القرآن يهدي {  إِلَى صِرَاطِ } أي :  إلى طريق {  العَزِيزِ } الذي ذل له كل شيء {  الحَمِيدِ } المستحمد إلى خلقه ،   أي :  استوجب عليهم أن يحمدوه .   والطريق إلى الجنة .
