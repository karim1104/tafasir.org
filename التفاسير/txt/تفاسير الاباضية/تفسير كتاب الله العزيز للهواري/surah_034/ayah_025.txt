قوله تعالى :  {  قُل لاَّ تُسْأَلُونَ عَمَّا أَجْرَمْنَا وَلاَ نُسْأَلُ عَمَّا تَعْمَلُونَ } هو كقوله :

{  قُلْ إِنِ افْتَرَيْتُهُ فَعَلَيَّ إِجْرَامِي وَأَنَا بَرِيءٌ مِّمَّا تُجْرِمُونَ }[ هود :  35 ] وكقوله :

{  وَإِن كَذَّبُوكَ فَقُل لِّى عَمَلِي وَلَكُمْ عَمَلُكُمْ أَنتُم بَرِيئُونَ مِمَّا أَعْمَلُ وَأَنَا بَرِيءٌ مِّمَّا تَعْمَلُونَ } [ يونس :  41 ]
