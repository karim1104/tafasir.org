قال :  {  وَمَا كَانَ لَهُ عَلَيْهِم مِّن سُلْطَانٍ } كقوله :  {  فَإِنَّكُمْ } يا بني إبليس {  وَمَا تَعْبُدُونَ مَا أَنتُمْ عَلَيْهِ بِفَاتِنِينَ } أي :  ليس له عليكم سلطان

{  إِلاَّ مَنْ هُوَ صَالِ الْجَحِيمِ }

[ الصافات :  161-163 ] أي :  لستم بمضلي أحد إلا من هو صال الجحيم .   قال :  {  إِلاَّ لِنَعْلَمَ مَن يُؤْمِنُ بالآخرة } وهذا علم الفَعال .   {  مِمَّنْ هُوَ مِنْهَا } أي :  من الآخرة {  فِي شَكٍّ } منها .   وإنما جحد المشركون الآخرة ظناً منهم ،   وذلك منهم على الشك .   قال :  {  وَرَبُّكَ عَلَى كُلِّ شَيْءٍ حَفِيظٌ } أي :  حتى يجازيهم في الآخرة .
