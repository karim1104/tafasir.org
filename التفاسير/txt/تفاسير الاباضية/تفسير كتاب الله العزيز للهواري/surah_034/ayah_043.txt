قوله :  {  وَإِذَا تُتْلَى عَلَيْهِمْ آيَاتُنَا بَيِّنَاتٍ } أي :  القرآن {  قَالُوا مَا هذَا } يعنون محمدًا صلى الله عليه وسلم {  إِلاَّ رَجُلٌ يُرِيدُ أَن يَصُدَّكُمْ عَمَّا كَانَ يَعْبُدُ آبَاؤُكُمْ وَقَالُوا مَا هذَا } أي :  القرآن {  إِلاَّ إِفْكٌ مُّفْتَرىً } أي :  إلا كذب افتراه محمد .   قال الله :  {  وَقَالَ الَّذِينَ كَفَرُوا لِلْحَقِّ } أي :  للقرآن {  لَمَّا جَاءَهُمْ إِنْ هَذَا إِلاَّ سِحْرٌ مُّبِينٌ } .
