{  وَجَزَاءُ سَيِّئَةٍ سَيِّئَةٌ مِثْلُهَا } .  ونحوه :  {  فمن اعتدى عليكم فاعتدوا عليه بمثل ما اعتدى عليكم  194 البقرة } ج 1 ص 301 {  فَمَنْ عَفَا وَأَصْلَحَ فَأَجْرُهُ عَلَى اللَّهِ } .  ومثله :  {  وأن تعفوا أقرب للتقوى  237 البقرة } .  وأيضا :  {  فمن تصدق به فهو كفارة له  45 المائدة } .  {  إِنَّهُ لَا يُحِبُّ الظَّالِمِينَ } .  والمراد بالظالمين هنا يتجاوزون الحد في القصاص والانتقام .
