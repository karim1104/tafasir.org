{  جَنَاحِكَ } :  الجناح :  جناح الطائر ،  واليد والإبط . <br />
{  مِنْ غَيْرِ سُوءٍ } :  من غير عاهة أو قبح . <br />
{  وَاضْمُمْ يَدَكَ إِلَى جَنَاحِكَ } أي تحت إبطك ،  {  تَخْرُجْ بَيْضَآءَ } في نقاء البياض وإشراقه ،  {  مِنْ غَيْرِ سُوءٍ } أي من غير مرض أو عاهة كالبرص ونحوه ،  {  آيَةً أُخْرَى } وهذه هي العلامة الثانية التي تدل على الرسالة التي أوكل الله إلى موسى( ع ) التحرك في مواقعها . <br />
