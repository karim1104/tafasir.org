{  يُحَادِدِ } :  المحادّة :  مجاوزة الحدّ بالمخالفة . <br />
{  الْخِزْيُ } :  الهوان . <br />
جزاء من يحادد الله ورسوله<br />
{  أَلَمْ يَعْلَمُواْ أَنَّهُ مَن يُحَادِدِ اللَّهَ وَرَسُولَهُ } فيتجاوز الحد بالمخالفة والمعاداة لهما {  فَأَنَّ لَهُ نَارَ جَهَنَّمَ خَالِداً فِيهَا } لأن ذلك هو الجزاء العادل لمثل هذا الموقف الذي يوحي بنكران الجميل وكفران النعمة وجحود الحقيقة .  {  ذَلِكَ الْخِزْيُ الْعَظِيمُ } الذي يمثل العار كله في النهايات السوداء للمصير . <br />
