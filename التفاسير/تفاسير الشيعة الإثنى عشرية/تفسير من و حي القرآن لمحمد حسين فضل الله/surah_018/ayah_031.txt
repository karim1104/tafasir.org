{  سُنْدُسٍ } :  ما رقّ من الثياب . <br />
{  وَإِسْتَبْرَقٍ } :  ديباج وقيل هو الحرير . <br />
{  أُوْلَئِكَ لَهُمْ جَنَّاتُ عَدْنٍ تَجْرِي مِن تَحْتِهِمُ الأَنْهَارُ } وكلمة عدن تعني الإقامة ،  وبذلك كانت كلمة {  جَنَّاتُ عَدْنٍ } تعني جنات الخلود على سبيل الكناية .  {  يُحَلَّوْنَ فِيهَا مِنْ أَسَاوِرَ مِن ذَهَبٍ } وهذا متمثل بالزينة الظاهرة التي تمنح الإنسان جمالاً فوق جمال {  وَيَلْبَسُونَ ثِيَابًا خُضْرًا مِّن سُنْدُسٍ } وهو نوع من الحرير الرقيق {  وَإِسْتَبْرَقٍ } وهو الحرير الغليظ ،  {  مُّتَّكِئِينَ فِيهَا عَلَى الآرَآئِكِ }  جمع أريكة  وهو السرير .  {  نِعْمَ الثَّوَابُ وَحَسُنَتْ مُرْتَفَقاً } . <br />
