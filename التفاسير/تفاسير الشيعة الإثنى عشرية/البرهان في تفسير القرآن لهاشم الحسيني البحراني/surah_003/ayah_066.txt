قوله تعالى: { يٰأَهْلَ ٱلْكِتَابِ لِمَ تُحَآجُّونَ فِيۤ إِبْرَاهِيمَ وَمَآ أُنزِلَتِ ٱلتَّورَاةُ وَٱلإنْجِيلُ إِلاَّ مِن بَعْدِهِ أَفَلاَ تَعْقِلُونَ } - إلى قوله تعالى:- { حَنِيفاً مُّسْلِماً وَمَا كَانَ مِنَ ٱلْمُشْرِكِينَ } [65- 67] 1735/ [2]- قال علي بن إبراهيم: قوله: { يٰأَهْلَ ٱلْكِتَابِ لِمَ تُحَآجُّونَ فِيۤ إِبْرَاهِيمَ وَمَآ أُنزِلَتِ ٱلتَّورَاةُ وَٱلإنْجِيلُ إِلاَّ مِن بَعْدِهِ أَفَلاَ تَعْقِلُونَ } ثم قال: { هٰأَنْتُمْ هَؤُلاۤءِ حَاجَجْتُمْ فِيمَا لَكُم بِهِ عِلمٌ } يعني بما في التوراة و الإنجيل { فَلِمَ تُحَآجُّونَ فِيمَا لَيْسَ لَكُمْ بِهِ عِلْمٌ } يعني بما في صحف إبراهيم { وَٱللَّهُ يَعْلَمُ وَأَنْتُمْ لاَ تَعْلَمُونَ } ثم قال: { مَا كَانَ إِبْرَاهِيمُ يَهُودِيّاً وَلاَ نَصْرَانِيّاً وَلَكِن كَانَ حَنِيفاً مُّسْلِماً وَمَا كَانَ مِنَ ٱلْمُشْرِكِينَ }.  1736/ [2]- العياشي: عن عبيد الله الحلبي، عن أبي عبد الله (عليه السلام) قال: " قال أمير المؤمنين (عليه السلام): { مَا كَانَ إِبْرَاهِيمُ يَهُودِيّاً وَلاَ نَصْرَانِيّاً } لا يهوديا يصلي إلى المغرب، و لا نصرانيا يصلي إلى المشرق { وَلَكِن كَانَ حَنِيفاً مُّسْلِماً } يقول: كان على دين محمد (صلى الله عليه و آله) ".
