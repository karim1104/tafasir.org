قوله تعالى: { وَإِذْ أَخَذَ ٱللَّهُ مِيثَاقَ ٱلَّذِينَ أُوتُواْ ٱلْكِتَابَ لَتُبَيِّنُنَّهُ لِلنَّاسِ وَلاَ تَكْتُمُونَهُ } - إلى قوله تعالى- { وَلَهُمْ عَذَابٌ أَلِيمٌ } [187- 188]  2016/ [1]- علي بن إبراهيم، في رواية أبي الجارود، عن أبي جعفر (عليه السلام) { وَإِذْ أَخَذَ ٱللَّهُ مِيثَاقَ ٱلَّذِينَ أُوتُواْ ٱلْكِتَابَ لَتُبَيِّنُنَّهُ لِلنَّاسِ وَلاَ تَكْتُمُونَهُ }: " و ذلك أن الله أخذ ميثاق الذين أوتوا الكتاب في محمد (صلى الله عليه و آله) ليبيننه للناس إذا خرج و لا يكتمونه { فَنَبَذُوهُ وَرَآءَ ظُهُورِهِمْ } يقول: نبذوا عهد الله وراء ظهورهم { وَٱشْتَرَوْاْ بِهِ ثَمَناً قَلِيلاً فَبِئْسَ مَا يَشْتَرُونَ } ".  و قال: قوله تعالى: { لاَ تَحْسَبَنَّ ٱلَّذِينَ يَفْرَحُونَ بِمَآ أَتَوْاْ وَّيُحِبُّونَ أَن يُحْمَدُواْ بِمَا لَمْ يَفْعَلُواْ } نزلت في المنافقين الذين يحبون أن يحمدوا على غير فعل.  2017/ [2]- و في رواية أبي الجارود، عن أبي جعفر (عليه السلام)، في قوله تعالى: { فَلاَ تَحْسَبَنَّهُمْ بِمَفَازَةٍ مِّنَ ٱلْعَذَابِ } يقول: ببعد من العذاب { وَلَهُمْ عَذَابٌ أَلِيمٌ }.
