قوله تعالى: { وَوُجُوهٌ يَوْمَئِذٍ بَاسِرَةٌ } - إلى قوله تعالى - { إِلَىٰ رَبِّكَ يَوْمَئِذٍ ٱلْمَسَاقُ } [24- 30]  11245/ [1]- علي بن إبراهيم، قوله تعالى: { وَوُجُوهٌ يَوْمَئِذٍ بَاسِرَةٌ } أي ذليلة { تَظُنُّ أَن يُفْعَلَ بِهَا فَاقِرَةٌ } ، قوله تعالى: { كَلاَّ إِذَا بَلَغَتِ ٱلتَّرَاقِيَ } قال: يعني النفس إذا بلغت الترقوة { وَقِيلَ مَنْ رَاقٍ } ، قال: يقال له: من يرقيك؟ { وَظَنَّ أَنَّهُ ٱلْفِرَاقُ }  { وَٱلْتَفَّتِ ٱلسَّاقُ بِٱلسَّاقِ } قال: التفت الدنيا بالآخرة { إِلَىٰ رَبِّكَ يَوْمَئِذٍ ٱلْمَسَاقُ } ، قال: يساقون إلى الله.  11246/ [2]- محمد بن يعقوب: عن علي بن إبراهيم، عن أبيه، عن عمرو بن عثمان، عن المفضل بن صالح، عن جابر، عن أبي جعفر (عليه السلام)، قال: سألته عن قول الله عز و جل: { وَقِيلَ مَنْ رَاقٍ * وَظَنَّ أَنَّهُ ٱلْفِرَاقُ } ، قال: " ذلك ابن آدم، إذا حل به الموت قال: هل من طبيب؟ { وَظَنَّ أَنَّهُ ٱلْفِرَاقُ } أيقن بمفارقة الأحبة { وَٱلْتَفَّتِ ٱلسَّاقُ بِٱلسَّاقِ } التفت الدنيا بالآخرة ثم { إِلَىٰ رَبِّكَ يَوْمَئِذٍ ٱلْمَسَاقُ } ، قال: المصير إلى رب العالمين ".  11247/ [3]- ابن بابويه، قال: حدثنا أبي، قال: حدثنا سعد بن عبد الله، قال: حدثنا الهيثم بن أبي مسروق النهدي، قال: حدثنا الحسن بن محبوب، عن جميل بن صالح، عن محمد بن مسلم، عن أبي جعفر محمد بن علي الباقر (عليه السلام)، أنه سئل عن قول الله عز و جل: { وَقِيلَ مَنْ رَاقٍ } ، قال: " ذلك قول ابن آدم إذا حضره الموت قال: هل من طبيب، هل من دافع؟ { وَظَنَّ أَنَّهُ ٱلْفِرَاقُ } يعني فراق الأهل و الأحبة عند ذلك. قال: { وَٱلْتَفَّتِ ٱلسَّاقُ بِٱلسَّاقِ } التفت الدنيا بالآخرة، قال: { إِلَىٰ رَبِّكَ يَوْمَئِذٍ ٱلْمَسَاقُ } إلى رب العالمين يومئذ المصير ".
