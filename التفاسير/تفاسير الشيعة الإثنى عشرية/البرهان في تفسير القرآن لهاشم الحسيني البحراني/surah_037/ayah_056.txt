قوله تعالى:  { لاَ فِيهَا غَوْلٌ } - إلى قوله تعالى- { وَلَوْلاَ نِعْمَةُ رَبِّي لَكُنتُ مِنَ ٱلْمُحْضَرِينَ } [47- 57] 8984/ [1]- علي بن إبراهيم: قوله: { لاَ فِيهَا غَوْلٌ } يعني الفساد { وَلاَ هُمْ عَنْهَا يُنزَفُونَ } أي لا يطردون منها، قوله: { وَعِندَهُمْ قَاصِرَاتُ ٱلطَّرْفِ عِينٌ } يعني الحور العين، يقصر الطرف، عن النظر إليها من صفائها و حسنها: { كَأَنَّهُنَّ بَيْضٌ مَّكْنُونٌ } يعني مخزون { فَأَقْبَلَ بَعْضُهُمْ عَلَىٰ بَعْضٍ يَتَسَآءَلُونَ * قَالَ قَآئِلٌ مِّنْهُمْ إِنِّي كَانَ لِي قَرِينٌ * يَقُولُ أَءِنَّكَ لَمِنَ ٱلْمُصَدِّقِينَ } أي تصدق بما يقول لك: إنك إذا مت حييت. قال: فيقول لصاحبه:  { هَلْ أَنتُمْ مُّطَّلِعُونَ } قال: { فَٱطَّلَعَ فَرَآهُ فِي سَوَآءِ ٱلْجَحِيمِ } ، فيقول له: { تَٱللَّهِ إِن كِدتَّ لَتُرْدِينِ * وَلَوْلاَ نِعْمَةُ رَبِّي لَكُنتُ مِنَ ٱلْمُحْضَرِينَ }.  8985/ [2]- ثم قال علي بن إبراهيم: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام) في قوله: { فَٱطَّلَعَ فَرَآهُ فِي سَوَآءِ ٱلْجَحِيمِ } ، يقول: " في وسط الجحيم ".
