قوله تعالى:  { قُلْ مَن رَّبُّ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ } - إلى قوله تعالى- { قُلِ ٱللَّهُ خَالِقُ كُلِّ شَيْءٍ وَهُوَ ٱلْوَاحِدُ ٱلْقَهَّارُ } [16]  5511/ [5]- قال علي بن إبراهيم: { قُلْ مَن رَّبُّ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ قُلِ ٱللَّهُ قُلْ أَفَٱتَّخَذْتُمْ مِّن دُونِهِ أَوْلِيَآءَ لاَ يَمْلِكُونَ لأَنْفُسِهِمْ نَفْعاً وَلاَ ضَرّاً قُلْ هَلْ يَسْتَوِي ٱلأَعْمَىٰ وَٱلْبَصِيرُ } يعني المؤمن و الكافر { أَمْ هَلْ تَسْتَوِي ٱلظُّلُمَاتُ وَٱلنُّورُ } أما الظلمات فالكفر، و أما النور فهو الإيمان، ثم قال في قوله: { قُلْ مَن رَّبُّ ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ قُلِ ٱللَّهُ }: الآية محكمة.
