قوله تعالى:  { وَمَآ أَهْلَكْنَا مِن قَرْيَةٍ إِلاَّ وَلَهَا كِتَابٌ مَّعْلُومٌ } - إلى قوله تعالى - { وَمَا كَانُواْ إِذاً مُّنظَرِينَ } [4- 8]  5814/ [1]- و قال علي بن إبراهيم: قوله: { وَمَآ أَهْلَكْنَا مِن قَرْيَةٍ إِلاَّ وَلَهَا كِتَابٌ مَّعْلُومٌ } أي أجل مكتوب. ثم حكى قول قريش لرسول الله (صلى الله عليه و آله): { يٰأَيُّهَا ٱلَّذِي نُزِّلَ عَلَيْهِ ٱلذِّكْرُ إِنَّكَ لَمَجْنُونٌ * لَّوْ مَا تَأْتِينَا بِٱلْمَلائِكَةِ إِن كُنتَ مِنَ ٱلصَّادِقِينَ } أي هلا تأتينا بالملائكة؟ فرد الله عز و جل عليهم، فقال: { مَا نُنَزِّلُ ٱلْمَلائِكَةَ إِلاَّ بِٱلحَقِّ وَمَا كَانُواْ إِذاً مُّنظَرِينَ } قال: لو أنزلنا الملائكة لم ينظروا و هلكوا.
