قوله تعالى:  { وَلاَ يَحْزُنكَ قَوْلُهُمْ إِنَّ ٱلْعِزَّةَ لِلَّهِ جَمِيعاً- إلى قوله تعالى- ثُمَّ لاَ يَكُنْ أَمْرُكُمْ عَلَيْكُمْ غُمَّةً ثُمَّ ٱقْضُوۤاْ إِلَيَّ وَلاَ تُنظِرُونَ } [65- 71]  4940/ [1]- علي بن إبراهيم قال في قوله: { وَلاَ يَحْزُنكَ قَوْلُهُمْ إِنَّ ٱلْعِزَّةَ لِلَّهِ جَمِيعاً } إلى قوله تعالى { بِمَا كَانُواْ يَكْفُرُونَ } فإنه محكم، و قوله: { وَٱتْلُ عَلَيْهِمْ } مخاطبة لمحمد (صلى الله عليه و آله) نَبَأَ نُوحٍ أي خبر نوح { إِذْ قَالَ لِقَوْمِهِ يٰقَوْمِ إِن كَانَ كَبُرَ عَلَيْكُمْ مَّقَامِي وَتَذْكِيرِي بِآيَاتِ ٱللَّهِ فَعَلَى ٱللَّهِ تَوَكَّلْتُ فَأَجْمِعُوۤاْ أَمْرَكُمْ وَشُرَكَآءَكُمْ } الذين تعبدون { ثُمَّ لاَ يَكُنْ أَمْرُكُمْ عَلَيْكُمْ غُمَّةً } أي لا تغتموا { ثُمَّ ٱقْضُوۤاْ إِلَيَّ } أي ادعوا علي { وَلاَ تُنظِرُونَ }.
