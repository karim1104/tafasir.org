قوله تعالى: { وَيَقُولُ ٱلَّذِينَ آمَنُواْ لَوْلاَ نُزِّلَتْ سُورَةٌ } - إلى قوله تعالى- { لَكَانَ خَيْراً لَّهُمْ } [20-21] 9853/ [1]- قال علي بن إبراهيم: قوله تعالى: { وَيَقُولُ ٱلَّذِينَ آمَنُواْ لَوْلاَ نُزِّلَتْ سُورَةٌ فَإِذَآ أُنزِلَتْ سُورَةٌ مُّحْكَمَةٌ وَذُكِرَ فِيهَا ٱلْقِتَالُ رَأَيْتَ ٱلَّذِينَ فِي قُلُوبِهِمْ مَّرَضٌ يَنظُرُونَ إِلَيْكَ نَظَرَ ٱلْمَغْشِيِّ عَلَيْهِ مِنَ ٱلْمَوْتِ } الآية، فهم المنافقون، ثم قال: { فَإِذَا عَزَمَ ٱلأَمْرُ } يعني الحرب { فَلَوْ صَدَقُواْ ٱللَّهَ لَكَانَ خَيْراً لَّهُمْ }.
