قوله تعالى: { كَأَنَّهُمْ خُشُبٌ مُّسَنَّدَةٌ } - إلى قوله تعالى- { لَوَّوْاْ رُءُوسَهُمْ } [4-5]  10754/ [1]- ثم قال علي بن إبراهيم: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام)، في قوله تعالى: { كَأَنَّهُمْ خُشُبٌ مُّسَنَّدَةٌ } يقول: “لا يسمعون و لا يعقلون، قوله: { يَحْسَبُونَ كُلَّ صَيْحَةٍ عَلَيْهِمْ } يعني كل صوت { هُمُ ٱلْعَدُوُّ فَٱحْذَرْهُمْ قَاتَلَهُمُ ٱللَّهُ أَنَّى يُؤْفَكُونَ } فلما نعتهم الله لرسوله و عرفه مساءتهم إليه و إلى عشائرهم فقالوا لهم: قد افتضحتم ويلكم فأتوا نبي الله يستغفر لكم فلووا رؤوسهم و زهدوا في الاستغفار، يقول الله: { وَإِذَا قِيلَ لَهُمْ تَعَالَوْاْ يَسْتَغْفِرْ لَكُمْ رَسُولُ ٱللَّهِ لَوَّوْاْ رُءُوسَهُمْ } ”.
