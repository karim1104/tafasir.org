قوله تعالى:  { وَإِبْرَاهِيمَ إِذْ قَالَ لِقَوْمِهِ ٱعْبُدُواْ ٱللَّهَ وَٱتَّقُوهُ ذٰلِكُمْ خَيْرٌ لَّكُمْ إِن كُنتُمْ تَعْلَمُونَ } - إلى قوله تعالى- { نَّ فِي ذٰلِكَ لآيَاتٍ لِّقَوْمٍ يُؤْمِنُونَ } [16- 24] 8261/ [1]- علي بن إبراهيم: { وَتَخْلُقُونَ إِفْكاً إِنَّ ٱلَّذِينَ تَعْبُدُونَ مِن دُونِ ٱللَّهِ لاَ يَمْلِكُونَ لَكُمْ رِزْقاً فَٱبْتَغُواْ عِندَ ٱللَّهِ ٱلرِّزْقَ وَٱعْبُدُوهُ وَٱشْكُرُواْ لَهُ إِلَيْهِ تُرْجَعُونَ }.  و انقطع خبر إبراهيم، و خاطب الله امة محمد (صلى الله عليه و آله)، فقال: { وَإِن تُكَذِّبُواْ فَقَدْ كَذَّبَ أُمَمٌ مِّن قَبْلِكُمْ وَمَا عَلَى ٱلرَّسُولِ إِلاَّ ٱلْبَلاَغُ ٱلْمُبِينُ } الى قوله: { أُوْلَـٰئِكَ يَئِسُواْ مِن رَّحْمَتِي وَأُوْلَـٰئِكَ لَهُمْ عَذَابٌ أَلِيمٌ } ثم عطف على خبر إبراهيم، فقال: { فَمَا كَانَ جَوَابَ قَوْمِهِ إِلاَّ أَن قَالُواْ ٱقْتُلُوهُ أَوْ حَرِّقُوهُ فَأَنْجَاهُ ٱللَّهُ مِنَ ٱلنَّارِ إِنَّ فِي ذٰلِكَ لآيَاتٍ لِّقَوْمٍ يُؤْمِنُونَ } فهذا من المنقطع المعطوف.
