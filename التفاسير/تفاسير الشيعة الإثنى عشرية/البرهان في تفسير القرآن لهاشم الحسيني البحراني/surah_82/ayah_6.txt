قوله تعالى: { بِسمِ ٱللهِ ٱلرَّحْمٰنِ ٱلرَّحِيـمِ * إِذَا ٱلسَّمَآءُ ٱنفَطَرَتْ } [الإنفطار: 1] - قوله تعالى - { فِيۤ أَيِّ صُورَةٍ مَّا شَآءَ رَكَّبَكَ } [الإنفطار: 8]. - علي بن إبراهيم، قال: في قوله تعالى: { وَإِذَا ٱلْبِحَارُ فُجِّرَتْ } ، قال: تتحول نيرانا { وَإِذَا ٱلْقُبُورُ بُعْثِرَتْ } ، قال: تنشق فيخرج الناس منها { عَلِمَتْ نَفْسٌ مَّا قَدَّمَتْ وَأَخَّرَتْ } أي ما عملت من خير و شر، ثم خاطب الناس { يٰأَيُّهَا ٱلإِنسَٰنُ مَا غَرَّكَ بِرَبِّكَ ٱلْكَرِيمِ * ٱلَّذِي خَلَقَكَ فَسَوَّاكَ فَعَدَلَكَ } أي ليس فيك اعوجاج { فِيۤ أَيِّ صُورَةٍ مَّا شَآءَ رَكَّبَكَ } ، قال: لو شاء ركبك على غير هذه الصورة.  - الطبرسي: عن الصادق (عليه السلام): " لو شاء ركبك على غير هذه الصورة ".
