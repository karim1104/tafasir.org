قوله تعالى:  { وَلَوْ تَرَىٰ إِذِ ٱلْمُجْرِمُونَ نَاكِسُواْ رُءُوسِهِمْ } - إلى قوله تعالى- { إِنَّا نَسِينَاكُمْ } [12- 14] 8477/ [1]- علي بن إبراهيم، قال: قوله: { وَلَوْ تَرَىٰ إِذِ ٱلْمُجْرِمُونَ نَاكِسُواْ رُءُوسِهِمْ عِندَ رَبِّهِمْ رَبَّنَآ أَبْصَرْنَا وَسَمِعْنَا } في الدنيا و لم نعمل به { فَٱرْجِعْنَا نَعْمَلْ صَالِحاً إِنَّا مُوقِنُونَ * وَلَوْ شِئْنَا لآتَيْنَا كُلَّ نَفْسٍ هُدَاهَا } ، قال: لو شئنا أن نجعلهم كلهم معصومين لقدرنا. قال: قوله: { فَذُوقُواْ بِمَا نَسِيتُمْ لِقَآءَ يَوْمِكُمْ هَـٰذَآ إِنَّا نَسِينَاكُمْ } أي تركناكم.
