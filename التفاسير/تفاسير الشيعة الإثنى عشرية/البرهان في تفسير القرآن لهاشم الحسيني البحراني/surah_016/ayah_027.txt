قوله تعالى:  { ثُمَّ يَوْمَ ٱلْقِيَامَةِ يُخْزِيهِمْ } - إلى قوله تعالى - { فَلَبِئْسَ مَثْوَى ٱلْمُتَكَبِّرِينَ } [27- 29]  6013/ [1]- قال علي بن إبراهيم: قوله تعالى: { ثُمَّ يَوْمَ ٱلْقِيَامَةِ يُخْزِيهِمْ وَيَقُولُ أَيْنَ شُرَكَآئِيَ ٱلَّذِينَ كُنْتُمْ تُشَاقُّونَ فِيهِمْ قَالَ ٱلَّذِينَ أُوتُواْ ٱلْعِلْمَ إِنَّ ٱلْخِزْيَ ٱلْيَوْمَ وَٱلْسُّوۤءَ عَلَى ٱلْكَافِرِينَ } قال: الذين أوتوا العلم: الأئمة (عليهم السلام) يقولون لأعدائهم: أين شركاؤكم، ومن أطعتموهم في الدنيا؟ ثم قال فيهم أيضا: { ٱلَّذِينَ تَتَوَفَّاهُمُ ٱلْمَلائِكَةُ ظَالِمِي أَنْفُسِهِمْ فَأَلْقَوُاْ ٱلسَّلَمَ } سلموا لما أصابهم من البلاء، ثم يقولون: { مَا كُنَّا نَعْمَلُ مِن سُوۤءٍ } فرد الله عليهم، فقال: { بَلَىٰ إِنَّ ٱللَّهَ عَلِيمٌ بِمَا كُنْتُمْ تَعْمَلُونَ * فَٱدْخُلُوۤاْ أَبْوَابَ جَهَنَّمَ خَالِدِينَ فِيهَا فَلَبِئْسَ مَثْوَى ٱلْمُتَكَبِّرِينَ }.
