قوله تعالى: { يَحْلِفُونَ بِٱللَّهِ لَكُمْ لِيُرْضُوكُمْ } - إلى قوله تعالى - { إِن كَانُواْ مُؤْمِنِينَ } [التوبة: 62] - علي بن إبراهيم، في قوله تعالى: { يَحْلِفُونَ بِٱللَّهِ لَكُمْ لِيُرْضُوكُمْ } أنها نزلت في المنافقين الذين كانوا يحلفون للمؤمنين أنهم منهم لكي يرضى عنهم المؤمنون، فقال الله: { وَٱللَّهُ وَرَسُولُهُ أَحَقُّ أَن يُرْضُوهُ إِن كَانُواْ مُؤْمِنِينَ }.
