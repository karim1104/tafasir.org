قوله تعالى: { مَا كَانَ لأَهْلِ ٱلْمَدِينَةِ وَمَنْ حَوْلَهُمْ مِّنَ ٱلأَعْرَابِ أَن يَتَخَلَّفُواْ عَن رَّسُولِ ٱللَّهِ } [التوبة: 120] - إلى قوله تعالى - { لِيَجْزِيَهُمُ ٱللَّهُ أَحْسَنَ مَا كَانُواْ يَعْمَلُونَ } [التوبة: 121] - و قال علي بن إبراهيم: قوله تعالى: { مَا كَانَ لأَهْلِ ٱلْمَدِينَةِ وَمَنْ حَوْلَهُمْ مِّنَ ٱلأَعْرَابِ أَن يَتَخَلَّفُواْ عَن رَّسُولِ ٱللَّهِ وَلاَ يَرْغَبُواْ بِأَنْفُسِهِمْ عَن نَّفْسِهِ ذٰلِكَ بِأَنَّهُمْ لاَ يُصِيبُهُمْ ظَمَأٌ }: أي عطش { وَلاَ نَصَبٌ } أي عناء { وَلاَ مَخْمَصَةٌ فِي سَبِيلِ ٱللَّهِ } أي جوع { وَلاَ يَطَأُونَ مَوْطِئاً يَغِيظُ ٱلْكُفَّارَ } يعني لا يدخلون بلاد الكفار { وَلاَ يَنَالُونَ مِنْ عَدُوٍّ نَّيْلاً } يعني قتلا و أسرا { إِلاَّ كُتِبَ لَهُمْ بِهِ عَمَلٌ صَالِحٌ إِنَّ ٱللَّهَ لاَ يُضِيعُ أَجْرَ ٱلْمُحْسِنِينَ } و قوله:  { وَلاَ يُنفِقُونَ نَفَقَةً صَغِيرَةً وَلاَ كَبِيرَةً وَلاَ يَقْطَعُونَ وَادِياً إِلاَّ كُتِبَ لَهُمْ لِيَجْزِيَهُمُ ٱللَّهُ أَحْسَنَ مَا كَانُواْ يَعْمَلُونَ } ، قال:  كلما فعلوا من ذلك لله جازاهم الله عليه.
