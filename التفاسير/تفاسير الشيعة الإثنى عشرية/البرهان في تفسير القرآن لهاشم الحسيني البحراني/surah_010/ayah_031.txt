قوله تعالى:  { وَيَوْمَ نَحْشُرُهُمْ جَمِيعاً ثُمَّ نَقُولُ لِلَّذِينَ أَشْرَكُواْ مَكَانَكُمْ أَنتُمْ وَشُرَكَآؤُكُمْ فَزَيَّلْنَا بَيْنَهُمْ - إلى قوله تعالى- قُلْ مَن يَرْزُقُكُم مِّنَ ٱلسَّمَآءِ وَٱلأَرْضِ } [28- 31]  4884/ [1]- علي بن إبراهيم، في قوله تعالى: { وَيَوْمَ نَحْشُرُهُمْ جَمِيعاً ثُمَّ نَقُولُ لِلَّذِينَ أَشْرَكُواْ مَكَانَكُمْ أَنتُمْ وَشُرَكَآؤُكُمْ فَزَيَّلْنَا بَيْنَهُمْ } قال: يبعث الله نارا تزيل بين الكفار و المؤمنين.  قال: قوله تعالى: { هُنَالِكَ تَبْلُواْ كُلُّ نَفْسٍ مَّآ أَسْلَفَتْ } أي تتبع ما قدمت { وَرُدُّوۤاْ إِلَى ٱللَّهِ مَوْلاَهُمُ ٱلْحَقِّ وَضَلَّ عَنْهُمْ مَّا كَانُواْ يَفْتَرُونَ } أي بطل عنهم ما كانوا يفترون.  و قوله: { قُلْ مَن يَرْزُقُكُم مِّنَ ٱلسَّمَآءِ وَٱلأَرْضِ } إلى قوله: [يونس: 38] فإنه محكم.
