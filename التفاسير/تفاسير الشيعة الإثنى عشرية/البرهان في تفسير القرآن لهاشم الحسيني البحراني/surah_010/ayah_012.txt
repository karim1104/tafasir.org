قوله تعالى:  { وَإِذَا مَسَّ ٱلإِنسَانَ ٱلضُّرُّ دَعَانَا لِجَنبِهِ أَوْ قَاعِداً أَوْ قَآئِماً فَلَمَّا كَشَفْنَا عَنْهُ ضُرَّهُ مَرَّ كَأَن لَّمْ يَدْعُنَآ إِلَىٰ ضُرٍّ مَّسَّهُ } [12].  4854/ [1]- علي بن إبراهيم، قال: دَعانا لِجَنْبِهِ العليل الذي لا يقدر أن يجلس { أَوْ قَاعِداً } ، قال: الذي لا يقدر أن يقوم { أَوْ قَآئِماً } ، قال: الصحيح. و قوله: { فَلَمَّا كَشَفْنَا عَنْهُ ضُرَّهُ مَرَّ } أي ترك و مر و نسي { كَأَن لَّمْ يَدْعُنَآ إِلَىٰ ضُرٍّ مَّسَّهُ }.
