قوله تعالى:  { وَإِمَّا يَنزَغَنَّكَ مِنَ ٱلشَّيْطَٰنِ نَزْغٌ } - إلى قوله تعالى- { أُوْلَـٰئِكَ يُنَادَوْنَ مِن مَّكَانٍ بَعِيدٍ } [36- 44] 9448/ [1]- علي بن إبراهيم: في قوله تعالى: { وَإِمَّا يَنزَغَنَّكَ مِنَ ٱلشَّيْطَٰنِ نَزْغٌ } أي إن عرض بقلبك نزغ من الشيطان فاستعذ بالله، و المخاطبة لرسول الله (صلى الله عليه و آله)، و المعنى للناس. ثم احتج على الدهرية، فقال:  { وَمِنْ آيَاتِهِ أَنَّكَ تَرَى ٱلأَرْضَ خَاشِعَةً } أي ساكنة هامدة { فَإِذَآ أَنزَلْنَا عَلَيْهَا ٱلْمَآءَ ٱهْتَزَّتْ وَرَبَتْ إِنَّ ٱلَّذِيۤ أَحْيَاهَا لَمُحْىِ ٱلْمَوْتَىٰ إِنَّهُ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ * إِنَّ ٱلَّذِينَ يُلْحِدُونَ فِيۤ آيَاتِنَا لاَ يَخْفَوْنَ عَلَيْنَآ } ثم استفهم عز و جل على المجاز، فقال تعالى: أ { أَفَمَن يُلْقَىٰ فِي ٱلنَّارِ خَيْرٌ أَم مَّن يَأْتِيۤ آمِناً يَوْمَ ٱلْقِيَامَةِ ٱعْمَلُواْ مَا شِئْتُمْ إِنَّهُ بِمَا تَعْمَلُونَ بَصِيرٌ } ، و قوله تعالى: { إِنَّ ٱلَّذِينَ كَفَرُواْ بِٱلذِّكْرِ } يعني بالقرآن { لَمَّا جَآءَهُمْ وَإِنَّهُ لَكِتَابٌ عَزِيزٌ }.  9449/ [2]- الطبرسي: عن أبي جعفر و أبي عبد الله (عليهما السلام)، في قوله تعالى: { لاَّ يَأْتِيهِ ٱلْبَاطِلُ } الآية:  " معناه أنه ليس في إخباره عما مضى باطل، و لا في إخباره عما يكون في المستقبل باطل، بل أخباره كلها موافقة لمخبراتها ".  9450/ [3]- علي بن إبراهيم: ثم قال تعالى: { مَّا يُقَالُ لَكَ إِلاَّ مَا قَدْ قِيلَ لِلرُّسُلِ مِن قَبْلِكَ إِنَّ رَبَّكَ لَذُو مَغْفِرَةٍ } يا محمد { وَذُو عِقَابٍ أَلِيمٍ } ، قال: عذاب أليم، ثم قال تعالى: { وَلَوْ جَعَلْنَاهُ قُرْآناً أعْجَمِيّاً لَّقَالُواْ لَوْلاَ فُصِّلَتْ آيَاتُهُ ءَاعْجَمِيٌّ وَعَرَبِيٌّ } ، قال: لو كان هذا القرآن أعجميا لقالوا: لو لا انزل لنا بالعربية، فقال الله تعالى: { قُلْ هُوَ لِلَّذِينَ آمَنُواْ هُدًى وَشِفَآءٌ } أي بيان { وَٱلَّذِينَ لاَ يُؤْمِنُونَ فِيۤ آذَانِهِمْ وَقْرٌ } أي صمم { وَهُوَ عَلَيْهِمْ عَمًى أُوْلَـٰئِكَ يُنَادَوْنَ مِن مَّكَانٍ بَعِيدٍ }. 9451/ [4]- ثم قال علي بن إبراهيم: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام)، في قوله تعالى: { إِنَّ ٱلَّذِينَ كَفَرُواْ بِٱلذِّكْرِ لَمَّا جَآءَهُمْ }: " يعني القرآن { لاَّ يَأْتِيهِ ٱلْبَاطِلُ مِن بَيْنِ يَدَيْهِ } ". قال: " لا يأتيه الباطل من قبل التوراة، و لا من قبل الإنجيل و الزبور، و أما { مِنْ خَلْفِهِ } لا يأتيه من بعده كتاب يبطله ".  قوله تعالى: { لَوْلاَ فُصِّلَتْ آيَاتُهُ ءَاعْجَمِيٌّ وَعَرَبِيٌّ } ، قال: " لو كان هذا القرآن أعجميا لقالوا: كيف نتعلمه، و لساننا عربي، و أتيتنا بقرآن أعجمي؟ فأحب [الله] أن ينزله بلسانهم، و قد قال الله عز و جل: [إبراهيم: 4] ".
