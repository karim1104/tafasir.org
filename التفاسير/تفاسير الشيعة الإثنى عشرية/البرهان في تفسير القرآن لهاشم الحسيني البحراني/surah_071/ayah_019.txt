قوله تعالى: { لاَ تَرْجُونَ لِلَّهِ وَقَاراً } - إلى قوله تعالى - { وَمَكَرُواْ مَكْراً كُبَّاراً } [13- 22]  11105/ [2]- علي بن إبراهيم: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام)، في قوله تعالى: { لاَ تَرْجُونَ لِلَّهِ وَقَاراً } ، قال: " لا تخافون لله عظمة ".  11106/ [3]- علي بن إبراهيم، قوله تعالى: { وَقَدْ خَلَقَكُمْ أَطْوَاراً } ، قال: على اختلاف الأهواء و الإرادات و المشيئات، قوله: { وَٱللَّهُ أَنبَتَكُمْ مِّنَ ٱلأَرْضِ } أي على وجه الأرض { نَبَاتاً } ، قوله: { رَّبِّ إِنَّهُمْ عَصَوْنِي وَٱتَّبَعُواْ مَن لَّمْ يَزِدْهُ مَالُهُ وَوَلَدُهُ إِلاَّ خَسَاراً } ، قال: اتبعوا الأغنياء { وَمَكَرُواْ مَكْراً كُبَّاراً } أي كبيراً.
