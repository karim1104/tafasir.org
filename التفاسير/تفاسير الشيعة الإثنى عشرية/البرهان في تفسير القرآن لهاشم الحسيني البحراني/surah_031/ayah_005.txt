قوله تعالى:  { الۤـمۤ * تِلْكَ آيَاتُ ٱلْكِتَابِ ٱلْحَكِيمِ } - إلى قوله تعالى- { أُوْلَـٰئِكَ عَلَىٰ هُدًى مِّن رَّبِّهِمْ } [1- 5] 8383/ [1]- علي بن إبراهيم، قوله تعالى: { الۤـمۤ * تِلْكَ آيَاتُ ٱلْكِتَابِ ٱلْحَكِيمِ * هُدًى وَرَحْمَةً لِّلْمُحْسِنِينَ * ٱلَّذِينَ يُقِيمُونَ ٱلصَّلاَةَ وَيُؤْتُونَ ٱلزَّكَاةَ وَهُمْ بِٱلآخِرَةِ هُمْ يُوقِنُونَ * أُوْلَـٰئِكَ عَلَىٰ هُدًى مِّن رَّبِّهِمْ } أي على بيان من ربهم.
