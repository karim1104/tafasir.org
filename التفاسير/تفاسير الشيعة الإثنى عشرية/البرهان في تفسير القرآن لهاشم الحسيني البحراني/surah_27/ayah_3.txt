قوله تعالى:  { طسۤ تِلْكَ آيَاتُ ٱلْقُرْآنِ وَكِتَابٍ مُّبِينٍ } - إلى قوله تعالى- { فَإِنِّي غَفُورٌ رَّحِيمٌ } [1- 11] معناها تقدم في أول سورة الشعراء.  7974/ [1]- علي بن إبراهيم: { طسۤ تِلْكَ آيَاتُ ٱلْقُرْآنِ وَكِتَابٍ مُّبِينٍ * هُدًى وَبُشْرَىٰ لِلْمُؤْمِنِينَ } إلى قوله: { فَهُمْ يَعْمَهُونَ } يعني يتحيرون: { أُوْلَـٰئِكَ ٱلَّذِينَ لَهُمْ سُوۤءُ ٱلْعَذَابِ وَهُمْ فِي ٱلآخِرَةِ هُمُ ٱلأَخْسَرُونَ * وَإِنَّكَ } مخاطبة لرسول الله (صلى الله عليه و آله): { لَتُلَقَّى ٱلْقُرْآنَ مِن لَّدُنْ } أي من عند { حَكِيمٍ عَلِيمٍ }.  و قوله: { إِذْ قَالَ مُوسَىٰ لأَهْلِهِ إِنِّيۤ آنَسْتُ نَاراً } أي رأيت، ذلك لما خرج من المدائن، من عند شعيب، فنكتب خبره- إن شاء الله تعالى- في سورة القصص.  و قوله: { يٰمُوسَىٰ لاَ تَخَفْ إِنِّي لاَ يَخَافُ لَدَيَّ ٱلْمُرْسَلُونَ * إِلاَّ مَن ظَلَمَ }. و معنى إلا من ظلم، كقولك:  و لا من ظلم فوضع حرف مكان حرف { ثُمَّ بَدَّلَ حُسْناً بَعْدَ سُوۤءٍ فَإِنِّي غَفُورٌ رَّحِيمٌ }. فوضع حرف مكان حرف.
