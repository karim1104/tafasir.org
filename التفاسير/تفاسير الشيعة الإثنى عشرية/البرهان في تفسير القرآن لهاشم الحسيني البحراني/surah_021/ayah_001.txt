قوله تعالى:  { ٱقْتَرَبَ لِلنَّاسِ حِسَابُهُمْ } - إلى قوله تعالى - { وَهُمْ يَلْعَبُونَ } [1- 2]  7098/ [1]- علي بن إبراهيم، في قوله تعالى { ٱقْتَرَبَ لِلنَّاسِ حِسَابُهُمْ وَهُمْ فِي غَفْلَةٍ مُّعْرِضُونَ } ، قال: قربت القيامة و الساعة و الحساب، ثم كنى عن قريش، فقال: { مَا يَأْتِيهِمْ مِّن ذِكْرٍ مِّن رَّبِّهِمْ مُّحْدَثٍ إِلاَّ ٱسْتَمَعُوهُ وَهُمْ يَلْعَبُونَ } قال: من التلهي.
