قوله تعالى:  { وَٱلَّتِيۤ أَحْصَنَتْ فَرْجَهَا } - إلى قوله تعالى - { فَلاَ كُفْرَانَ لِسَعْيِهِ } [91- 94]  7197/ [1]- علي بن إبراهيم، في قوله تعالى: { وَٱلَّتِيۤ أَحْصَنَتْ فَرْجَهَا } قال: مريم، لم ينظر إليها بشر، قال: قوله تعالى: { فَنَفَخْنَا فِيهَا مِن رُّوحِنَا } قال: ريح مخلوقة، قال: يعني من أمرنا. قال: قوله تعالى: { فَمَن يَعْمَلْ مِنَ ٱلصَّالِحَاتِ وَهُوَ مُؤْمِنٌ فَلاَ كُفْرَانَ لِسَعْيِهِ } أي لا يبطل سعيه.
