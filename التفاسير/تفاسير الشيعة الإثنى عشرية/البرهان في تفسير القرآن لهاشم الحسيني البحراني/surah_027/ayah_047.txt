قوله تعالى:  { وَلَقَدْ أَرْسَلْنَآ إِلَىٰ ثَمُودَ أَخَاهُمْ صَالِحاً } - إلى قوله تعالى- { وَإِنَّا لَصَادِقُونَ } [45- 49]  8028/ [1]- علي بن إبراهيم، قال: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام)، في قوله تعالى: { وَلَقَدْ أَرْسَلْنَآ إِلَىٰ ثَمُودَ أَخَاهُمْ صَالِحاً أَنِ ٱعْبُدُواْ ٱللَّهَ فَإِذَا هُمْ فَرِيقَانِ يَخْتَصِمُونَ }: " يقول: مصدق، و مكذب. قال الكافرون منهم: أ تشهدون أن صالحا مرسل من ربه؟ و قال المؤمنون: إنا بالذي أرسل به مؤمنون. قال الكافرون منهم: إنا بالذي آمنتم به كافرون، و قالوا: يا صالح ائتنا بما تعدنا إن كنت من الصادقين. فجاءهم بناقة، فعقروها، و كان الذي عقرها أزرق، أحمر، ولد زنا ".  و أما قوله: { لِمَ تَسْتَعْجِلُونَ بِٱلسَّيِّئَةِ قَبْلَ ٱلْحَسَنَةِ } فإنهم سألوه قبل أن تأتيهم الناقة، أن يأتيهم بعذاب أليم، و أرادوا بذلك امتحانه، فقال: { يٰقَوْمِ لِمَ تَسْتَعْجِلُونَ بِٱلسَّيِّئَةِ قَبْلَ ٱلْحَسَنَةِ } يقول: بالعذاب قبل الرحمة.  و أما قوله: { قَالُواْ ٱطَّيَّرْنَا بِكَ وَبِمَن مَّعَكَ } فإنهم أصابهم جوع شديد، فقالوا: هذا من شؤمك، و شؤم من معك- أصابنا هذا القحط، و هي الطيرة { قَالَ طَائِرُكُمْ عِندَ ٱللَّهِ } يقول: خيركم، و شركم، و شؤمكم من عند الله { بَلْ أَنتُمْ قَوْمٌ تُفْتَنُونَ } يقول تبتلون بالاختبار.  و أما قوله: { وَكَانَ فِي ٱلْمَدِينَةِ تِسْعَةُ رَهْطٍ يُفْسِدُونَ فِي ٱلأَرْضِ وَلاَ يُصْلِحُونَ } كانوا يعملون في الأرض بالمعاصي، و أما قوله: { تَقَاسَمُواْ بِٱللَّهِ لَنُبَيِّتَنَّهُ وَأَهْلَهُ ثُمَّ لَنَقُولَنَّ لِوَلِيِّهِ } أي لنحلفن { لِوَلِيِّهِ } منهم " { مَا شَهِدْنَا مَهْلِكَ أَهْلِهِ وَإِنَّا لَصَادِقُونَ } يقول: لنفعلن، فأتوا صالحا ليلا ليقتلوه، و عند صالح ملائكة يحرسونه، فلما أتوه قاتلتهم الملائكة في دار صالح رجما بالحجارة، فأصبحوا في داره مقتلين، و أخذت قومه الرجفة، و أصبحوا في دارهم جاثمين.  و أما قوله: [النمل: 61] يقول: فضاء. و أما قوله: [النمل: 66] يقول: علموا ما كانوا جهلوا في الدنيا، و أما قوله: [النمل: 87] قال: صاغرين، و أما قوله: [النمل: 88] يقول: أحسن كل شيء خلقه.
