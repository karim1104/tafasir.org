قوله تعالى:  { ذَلِكَ مِنْ أَنْبَآءِ ٱلْغَيْبِ نُوحِيهِ إِلَيْكَ وَمَا كُنتَ لَدَيْهِمْ إِذْ أَجْمَعُوۤاْ أَمْرَهُمْ وَهُمْ يَمْكُرُونَ } إلى قوله تعالى- { وَهُمْ عَنْهَا مُعْرِضُونَ } [102- 105]  5391/ [1]- قال علي بن إبراهيم: ثم قال الله لنبيه: { ذَلِكَ مِنْ أَنْبَآءِ ٱلْغَيْبِ نُوحِيهِ إِلَيْكَ وَمَا كُنتَ لَدَيْهِمْ إِذْ أَجْمَعُوۤاْ أَمْرَهُمْ وَهُمْ يَمْكُرُونَ } ثم قال: { وَمَآ أَكْثَرُ ٱلنَّاسِ وَلَوْ حَرَصْتَ بِمُؤْمِنِينَ }.  قال: و قوله تعالى: { وَكَأَيِّن مِّن آيَةٍ فِي ٱلسَّمَٰوَٰتِ وَٱلأَرْضِ يَمُرُّونَ عَلَيْهَا وَهُمْ عَنْهَا مُعْرِضُونَ } قال:  الكسوف و الزلزلة و الصواعق.
