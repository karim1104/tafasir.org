قوله تعالى:  { وَفَتَنَّاكَ فُتُوناً } - إلى قوله تعالى - { وَلاَ تَنِيَا فِي ذِكْرِي } [40- 42]  7010/ [1]- علي بن إبراهيم: وَ فَتَنَّاكَ فُتُوناً أي اختبرناك اختبارا، قوله تعالى: { فَلَبِثْتَ سِنِينَ فِيۤ أَهْلِ مَدْيَنَ } يعني عند شعيب، و قوله تعالى: { وَٱصْطَنَعْتُكَ لِنَفْسِي } أي اخترتك، و قوله: { ٱذْهَبْ أَنتَ وَأَخُوكَ بِآيَاتِي وَلاَ تَنِيَا فِي ذِكْرِي } أي لا تضعفا.
