قوله تعالى:  { وَإِذَآ أَرَدْنَآ أَن نُّهْلِكَ قَرْيَةً أَمَرْنَا مُتْرَفِيهَا فَفَسَقُواْ فِيهَا } - إلى قوله تعالى - { لاَّ تَجْعَل مَعَ ٱللَّهِ إِلَـٰهاً آخَرَ فَتَقْعُدَ مَذْمُوماً مَّخْذُولاً } [16- 22]  6291/ [1]- العياشي: عن حمران، عن أبي جعفر (عليه السلام) في قوله: " و إذا أردنا أن نهلك قرية أمرنا مترفيها " مشددة منصوبة: " تفسيرها: كثرنا- و قال- لا قرأتها مخففة ".  6292/ [2]- عن حمران، عن أبي جعفر (عليه السلام)، في قوله تعالى: { وَإِذَآ أَرَدْنَآ أَن نُّهْلِكَ قَرْيَةً أَمَرْنَا مُتْرَفِيهَا } ، قال: " تفسيرها أمرنا أكابرها ".  6293/ [3]- علي بن إبراهيم: في قوله تعالى: { وَإِذَآ أَرَدْنَآ أَن نُّهْلِكَ قَرْيَةً أَمَرْنَا مُتْرَفِيهَا } أي كثرنا جبابرتها، ثم قال: قوله: { مَّن كَانَ يُرِيدُ ٱلْعَاجِلَةَ } - يعني أموال الدنيا - { عَجَّلْنَا لَهُ فِيهَا مَا نَشَآءُ لِمَن نُّرِيدُ } - في الدنيا - { ثُمَّ جَعَلْنَا لَهُ جَهَنَّمَ } - في الآخرة - { يَصْلاهَا مَذْمُوماً مَّدْحُوراً } يعني: يلقى في النار، ثم ذكر من عمل للآخرة فقال: { وَمَنْ أَرَادَ ٱلآخِرَةَ وَسَعَىٰ لَهَا سَعْيَهَا وَهُوَ مُؤْمِنٌ فَأُولَئِكَ كَانَ سَعْيُهُم مَّشْكُوراً } ثم قال قوله تعالى: { كُلاًّ نُّمِدُّ هَـٰؤُلاۤءِ وَهَـٰؤُلاۤءِ مِنْ عَطَآءِ رَبِّكَ } يعني: من أراد الدنيا و أراد الآخرة، و معنى نمد: أي نعطي { وَمَا كَانَ عَطَآءُ رَبِّكَ مَحْظُوراً }: أي ممنوعا.  ثم قال: قوله تعالى: { لاَّ تَجْعَل مَعَ ٱللَّهِ إِلَـٰهاً آخَرَ فَتَقْعُدَ مَذْمُوماً مَّخْذُولاً } أي في النار، و هو مخاطبة للنبي و المعنى للناس، قال: و هو قول الصادق (عليه السلام): " إن الله بعث نبيه بإياك أعني و اسمعي يا جارة ".
