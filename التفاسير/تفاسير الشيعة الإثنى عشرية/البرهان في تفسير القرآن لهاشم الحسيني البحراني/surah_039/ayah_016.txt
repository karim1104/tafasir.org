قوله تعالى:  { قُلْ إِنَّ ٱلْخَاسِرِينَ ٱلَّذِينَ خَسِرُوۤاْ أَنفُسَهُمْ } - إلى قوله تعالى- { وَمِن تَحْتِهِمْ ظُلَلٌ } [15 و 16]  9188/ [1]- علي بن إبراهيم، قال: في رواية أبي الجارود، عن أبي جعفر (عليه السلام)، في قوله: { قُلْ إِنَّ ٱلْخَاسِرِينَ ٱلَّذِينَ خَسِرُوۤاْ أَنفُسَهُمْ } ، يقول: " غبنوا أنفسهم { وَأَهْلِيهِمْ يَوْمَ ٱلْقِيَامَةِ أَلاَ ذَلِكَ هُوَ ٱلْخُسْرَانُ ٱلْمُبِينُ } ".  9189/ [2]- علي بن إبراهيم: قوله: { لَهُمْ مِّن فَوْقِهِمْ ظُلَلٌ مِّنَ ٱلنَّارِ وَمِن تَحْتِهِمْ ظُلَلٌ } يعني تظلل عليهم النار من فوقهم و من تحتهم.
