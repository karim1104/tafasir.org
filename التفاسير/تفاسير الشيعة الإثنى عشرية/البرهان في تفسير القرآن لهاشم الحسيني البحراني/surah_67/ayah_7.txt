قوله تعالى: { ٱلَّذِي خَلَقَ سَبْعَ سَمَٰوَٰتٍ طِبَاقاً } - إلى قوله تعالى- { إِنْ أَنتُمْ إِلاَّ فِي ضَلاَلٍ كَبِيرٍ } [3-9] 10912/ [1]- علي بن إبراهيم: { ٱلَّذِي خَلَقَ سَبْعَ سَمَٰوَٰتٍ طِبَاقاً } ، قال: بعضها طبق لبعض { مَّا تَرَىٰ فِي خَلْقِ ٱلرَّحْمَـٰنِ مِن تَفَاوُتٍ } قال: من فساد { فَٱرْجِعِ ٱلْبَصَرَ هَلْ تَرَىٰ مِن فُطُورٍ } أي من عيب { ثُمَّ ٱرجِعِ ٱلبَصَرَ } قال: انظر في ملكوت السماوات و الأرض { يَنْقَلِبْ إِلَيْكَ ٱلبَصَرُ خَاسِئاً وَهُوَ حَسِيرٌ } أي يقصر و هو حسير، أي منقطع.  قوله: { وَلَقَدْ زَيَّنَّا ٱلسَّمَآءَ ٱلدُّنْيَا بِمَصَٰبِيحَ } قال: بالنجوم { وَجَعَلْنَٰهَا رُجُوماً لِّلشَّيَٰطِينِ وَأَعْتَدْنَا لَهُمْ عَذَابَ ٱلسَّعِيرِ } قوله: { إِذَآ أُلْقُواْ فِيهَا سَمِعُواْ لَهَا شَهِيقاً } قال: وقعا { وَهِيَ تَفُورُ } اي ترتفع { تَكَادُ تَمَيَّزُ مِنَ الغَيْظِ } قال: على أعداء الله { كُلَّمَا أُلْقِيَ فِيهَا فَوْجٌ سَأَلَهُمْ خَزَنَتُهَآ أَلَمْ يَأْتِكُمْ نَذِيرٌ } و هم الملائكة الذين يعذبونهم بالنار { قَالُواْ بَلَىٰ قَدْ جَآءَنَا نَذِيرٌ فَكَذَّبْنَا وَقُلْنَا مَا نَزَّلَ ٱللَّهُ مِن شَيْءٍ } فيقولون لهم: { إِنْ أَنتُمْ إِلاَّ فِي ضَلاَلٍ كَبِيرٍ } أي في عذاب شديد.  10913/ [2]- ابن بابويه، قال: حدثنا علي بن أحمد (رحمه الله)، قال: حدثنا محمد بن أبي عبد الله الكوفي، عن موسى بن عمران، عن عمه الحسين بن يزيد، عن علي بن أبي حمزة، عن أبي بصير، عن أبي عبد الله (عليه السلام)، أنه سأله رجل فقال: لأي شيء بعث الله الأنبياء و الرسل إلى الناس؟ فقال: “لئلا يكون للناس على الله حجة بعد الرسل، و لئلا يقولوا: ما جاءنا من بشير و لا نذير، و لتكون حجة الله عليهم، ألا تسمع قول الله عز و جل، يقول حكاية عن خزنة جهنم و احتجاجهم على أهل النار بالأنبياء و الرسل: { أَلَمْ يَأْتِكُمْ نَذِيرٌ * قَالُواْ بَلَىٰ قَدْ جَآءَنَا نَذِيرٌ فَكَذَّبْنَا وَقُلْنَا مَا نَزَّلَ ٱللَّهُ مِن شَيْءٍ إِنْ أَنتُمْ إِلاَّ فِي ضَلاَلٍ كَبِيرٍ }؟”.
