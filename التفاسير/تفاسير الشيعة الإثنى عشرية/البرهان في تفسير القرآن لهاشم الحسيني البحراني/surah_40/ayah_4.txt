قوله تعالى:  { غَافِرِ ٱلذَّنبِ وَقَابِلِ ٱلتَّوْبِ } - إلى قوله تعالى- { فَكَيْفَ كَانَ عِقَابِ } [3- 5] 9308/ [2]- علي بن إبراهيم: في قوله تعالى: { غَافِرِ ٱلذَّنبِ وَقَابِلِ ٱلتَّوْبِ } ذلك خاصة لشيعة أمير المؤمنين (عليه السلام)، { ذِي ٱلطَّوْلِ لاَ إِلَـٰهَ إِلاَّ هُوَ إِلَيْهِ ٱلْمَصِيرُ } ، و قوله: { مَا يُجَادِلُ فِيۤ آيَاتِ ٱللَّهِ } هم الأئمة (عليهم السلام) { إِلاَّ ٱلَّذِينَ كَفَرُواْ فَلاَ يَغْرُرْكَ تَقَلُّبُهُمْ فِي ٱلْبِلاَدِ * كَـذَّبَتْ قَبْلَهُمْ قَوْمُ نُوحٍ وَٱلأَحْزَابُ مِن بَعْدِهِمْ } و هم أصحاب الأنبياء الذين تحزبوا { وَهَمَّتْ كُـلُّ أُمَّةٍ بِرَسُولِهِمْ لِيَأْخُذُوهُ } يعني يقتلوه أي خاصموا { لِيُدْحِضُواْ بِهِ ٱلْحَقَّ } أي يبطلوه و يدفعوه { فَأَخَذْتُهُمْ فَكَيْفَ كَانَ عِقَابِ }.
