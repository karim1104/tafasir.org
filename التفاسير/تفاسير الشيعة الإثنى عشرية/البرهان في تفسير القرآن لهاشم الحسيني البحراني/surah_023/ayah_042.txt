قوله تعالى:  { فَجَعَلْنَاهُمْ غُثَآءً } - إلى قوله تعالى- { ثُمَّ أَرْسَلْنَا رُسُلَنَا تَتْرَا } [41- 44]  7473/ [1]- وقال علي بن إبراهيم: و في رواية أبي الجارود، عنه (عليه السلام)، في قوله: { فَجَعَلْنَاهُمْ غُثَآءً }.  " و الغثاء: اليابس الهامد من نبات الأرض. و قوله تعالى: { ثُمَّ أَرْسَلْنَا رُسُلَنَا تَتْرَا } يقول بعضهم في إثر بعض ".
