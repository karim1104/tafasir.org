قوله تعالى:  { قَالَ كَمْ لَبِثْتُمْ فِي ٱلأَرْضِ عَدَدَ سِنِينَ } - إلى قوله تعالى- { وَقُل رَّبِّ ٱغْفِرْ وَٱرْحَمْ وَأنتَ خَيْرُ ٱلرَّاحِمِينَ } [112- 118] 7543/ [2]- علي بن إبراهيم، في قوله تعالى: { قَالَ كَمْ لَبِثْتُمْ فِي ٱلأَرْضِ عَدَدَ سِنِينَ * قَالُواْ لَبِثْنَا يَوْماً أَوْ بَعْضَ يَوْمٍ فَسْئَلِ ٱلْعَآدِّينَ } ، قال: سل الملائكة الذين كانوا يعدون علينا الأيام، فيكتبون ساعاتنا و أعمالنا التي اكتسبناها فيها فرد الله عليهم، فقال: قل لهم، يا محمد: { إِن لَّبِثْتُمْ إِلاَّ قَلِيلاً لَّوْ أَنَّكُمْ كُنتُمْ تَعْلَمُونَ * أَفَحَسِبْتُمْ أَنَّمَا خَلَقْنَاكُمْ عَبَثاً وَأَنَّكُمْ إِلَيْنَا لاَ تُرْجَعُونَ }.  و قوله تعالى: { وَمَن يَدْعُ مَعَ ٱللَّهِ إِلَـهَا آخَرَ لاَ بُرْهَانَ لَهُ بِهِ } أي لا حجة له به { فَإِنَّمَا حِسَابُهُ عِندَ رَبِّهِ إِنَّهُ لاَ يُفْلِحُ ٱلْكَافِرُونَ * وَقُل } يا محمد { رَّبِّ ٱغْفِرْ وَٱرْحَمْ وَأنتَ خَيْرُ ٱلرَّاحِمِينَ }.
