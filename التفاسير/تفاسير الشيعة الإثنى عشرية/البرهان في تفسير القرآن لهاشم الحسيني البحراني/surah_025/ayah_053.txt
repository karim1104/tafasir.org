قوله تعالى:  { وَهُوَ ٱلَّذِي مَرَجَ ٱلْبَحْرَيْنِ } - إلى قوله تعالى- { وَحِجْراً مَّحْجُوراً } [53] 7800/ [3]- علي بن إبراهيم: قوله تعالى: { وَهُوَ ٱلَّذِي مَرَجَ ٱلْبَحْرَيْنِ } في رواية أبي الجارود، عن أبي جعفر (عليه السلام) يقول: " أرسل البحرين { هَـٰذَا عَذْبٌ فُرَاتٌ وَهَـٰذَا مِلْحٌ أُجَاجٌ } فالأجاج المر، { وَجَعَلَ بَيْنَهُمَا بَرْزَخاً } يقول: حاجزا، و هو المنتهى، { وَحِجْراً مَّحْجُوراً } يقول: حراما محرما، بأن يغير أحدهما طعم الآخر ".
