قوله تعالى: { وَقَالُوۤاْ إِنْ هِيَ إِلاَّ حَيَاتُنَا ٱلدُّنْيَا } [الأنعام: 29] - إلى قوله تعالى - { وَلَوْ تَرَىٰ إِذْ وُقِفُواْ عَلَىٰ رَبِّهِمْ } [الأنعام: 30] - و قال علي بن إبراهيم: ثم حكى عز و جل قول الدهرية، فقال: { وَقَالُوۤاْ إِنْ هِيَ إِلاَّ حَيَاتُنَا ٱلدُّنْيَا وَمَا نَحْنُ بِمَبْعُوثِينَ } فقال الله: { وَلَوْ تَرَىٰ إِذْ وُقِفُواْ عَلَىٰ رَبِّهِمْ } قال حكاية عن قول من أنكر قيام الساعة.
