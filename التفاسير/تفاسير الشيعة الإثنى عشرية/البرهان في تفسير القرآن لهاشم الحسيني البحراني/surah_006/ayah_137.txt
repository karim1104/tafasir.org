قوله تعالى: { وَكَذٰلِكَ زَيَّنَ لِكَثِيرٍ مِّنَ ٱلْمُشْرِكِينَ قَتْلَ أَوْلَٰدِهِمْ شُرَكَآؤُهُمْ } - إلى قوله تعالى - { يَفْتَرُونَ } [الأنعام: 137] - علي بن إبراهيم قال: يعني أسلافهم زينوا لهم قتل أولادهم { لِيُرْدُوهُمْ وَلِيَلْبِسُواْ عَلَيْهِمْ دِينَهُمْ } يعني يغروهم و يلبسوا عليهم دينهم { وَلَوْ شَآءَ ٱللَّهُ مَا فَعَلُوهُ فَذَرْهُمْ وَمَا يَفْتَرُونَ }.
