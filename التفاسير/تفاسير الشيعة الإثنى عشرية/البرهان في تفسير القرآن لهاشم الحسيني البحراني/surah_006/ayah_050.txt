قوله تعالى: { قُل لاَّ أَقُولُ لَكُمْ عِندِي خَزَآئِنُ ٱللَّهِ } [الأنعام: 50] - إلى قوله تعالى - { لَّعَلَّهُمْ يَتَّقُونَ } [الأنعام: 51] - قال علي بن إبراهيم: ثم قال: { قُل } لهم يا محمد { لاَّ أَقُولُ لَكُمْ عِندِي خَزَآئِنُ ٱللَّهِ وَلاۤ أَعْلَمُ ٱلْغَيْبَ وَلاۤ أَقُولُ لَكُمْ إِنِّي مَلَكٌ إِنْ أَتَّبِعُ إِلاَّ مَا يُوحَىٰ إِلَيَّ } قال: لا أملك خزائن الله، و لا أعلم الغيب، و ما أقول فإنه من عند الله. ثم قال: { هَلْ يَسْتَوِي ٱلأَعْمَىٰ وَٱلْبَصِيرُ } أي من يعلم و من لا يعلم { أَفَلاَ تَتَفَكَّرُونَ } ثم قال:  { وَأَنذِرْ بِهِ } يعني بالقرآن { ٱلَّذِينَ يَخَافُونَ أَن يُحْشَرُوۤاْ إِلَىٰ رَبِّهِمْ لَيْسَ لَهُمْ مِّن دُونِهِ وَلِيٌّ وَلاَ شَفِيعٌ لَّعَلَّهُمْ يَتَّقُونَ }.  - الطبرسي: قال الصادق (عليه السلام): " أنذر بالقرآن من يرجون الوصول إلى ربهم برغبتهم فيما عنده، فإن القرآن شافع مشفع ".
