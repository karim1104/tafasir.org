قوله تعالى:  { وَآيَةٌ لَّهُمْ أَنَّا حَمَلْنَا ذُرِّيَّتَهُمْ } - إلى قوله تعالى- { لَهُمْ مِّن مِّثْلِهِ مَا يَرْكَبُونَ } [41 و 42] 8929/ [3]- علي بن إبراهيم: قول: { وَآيَةٌ لَّهُمْ أَنَّا حَمَلْنَا ذُرِّيَّتَهُمْ فِي ٱلْفُلْكِ ٱلْمَشْحُونِ } ، قال: السفن المليئة { وَخَلَقْنَا لَهُمْ مِّن مِّثْلِهِ مَا يَرْكَبُونَ } ، قال: يعني الدواب و الأنعام.
