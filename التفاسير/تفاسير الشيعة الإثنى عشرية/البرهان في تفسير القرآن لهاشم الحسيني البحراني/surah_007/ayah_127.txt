قوله تعالى: { وَقَالَ ٱلْمَلأُ مِن قَوْمِ فِرْعَونَ أَتَذَرُ مُوسَىٰ وَقَوْمَهُ لِيُفْسِدُواْ فِي ٱلأَرْضِ وَيَذَرَكَ وَآلِهَتَكَ } - إلى قوله تعالى - { قَاهِرُونَ } [الأعراف: 127] - علي بن إبراهيم، قال: كان فرعون يعبد الأصنام، ثم ادعى بعد ذلك الربوبية، فقال فرعون:  { سَنُقَتِّلُ أَبْنَآءَهُمْ وَنَسْتَحْيِـي نِسَآءَهُمْ وَإِنَّا فَوْقَهُمْ قَاهِرُونَ } أي غالبون.
