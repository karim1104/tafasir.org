قوله تعالى:  { أَلَمْ يَأْتِكُمْ نَبَأُ ٱلَّذِينَ مِن قَبْلِكُمْ قَوْمِ نُوحٍ } - الى قوله تعالى - { وَإِنَّا لَفِي شَكٍّ مِّمَّا تَدْعُونَنَآ إِلَيْهِ مُرِيبٍ } [9] 5692/ [15]- قال علي بن ابراهيم، قوله: { أَلَمْ يَأْتِكُمْ نَبَأُ ٱلَّذِينَ مِن قَبْلِكُمْ قَوْمِ نُوحٍ } الى قوله: { فَرَدُّوۤاْ أَيْدِيَهُمْ فِيۤ أَفْوَٰهِهِمْ } يعني في أفواه الأنبياء { وَقَالُوۤاْ إِنَّا كَفَرْنَا بِمَآ أُرْسِلْتُمْ بِهِ وَإِنَّا لَفِي شَكٍّ مِّمَّا تَدْعُونَنَآ إِلَيْهِ مُرِيبٍ }.
