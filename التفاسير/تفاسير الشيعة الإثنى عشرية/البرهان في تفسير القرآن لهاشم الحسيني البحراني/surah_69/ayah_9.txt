11002/ [3]- علي بن إبراهيم: قوله تعالى: { وَجَآءَ فِرْعَوْنُ وَمَن قَبْلَهُ وَٱلْمُؤْتَفِكَاتُ بِالْخَاطِئَةِ } المؤتفكات: البصرة، و الخاطئة: فلانة.  11003/ [4]- شرف الدين النجفي: عن محمد البرقي، عن الحسين بن سيف بن عميرة، عن أخيه، عن منصور بن حازم، عن حمران، قال: سمعت أبا جعفر (عليه السلام) يقرأ: { وَجَآءَ فِرْعَوْنُ وَمَن قَبْلَهُ وَٱلْمُؤْتَفِكَاتُ بِالْخَاطِئَةِ } قال: { وَجَآءَ فِرْعَوْنُ } يعني الثالث، { وَمَن قَبْلَهُ } الأولين { وَٱلْمُؤْتَفِكَاتُ } [أهل البصرة] { بِالْخَاطِئَةِ } [الحميراء] يعني عائشة”.  قال: “و قوله تعالى: { وَٱلْمُؤْتَفِكَاتُ } أهل البصرة”. فقد جاء في كلام أمير المؤمنين (عليه السلام) لأهل البصرة: “يا أهل المؤتفكة، ائتفكت بأهلها ثلاثا، و على الله تمام الرابعة”. و معنى ائتفكت بأهلها، أي خسفت بهم.  و قد تقدم كلام أمير المؤمنين (عليه السلام) بزيادة في قوله تعالى: [النجم: 53].
