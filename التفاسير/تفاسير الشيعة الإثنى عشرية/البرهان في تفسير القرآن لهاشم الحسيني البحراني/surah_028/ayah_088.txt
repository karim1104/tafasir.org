قوله تعالى:  { فَلاَ تَكُونَنَّ ظَهيراً لِّلْكَافِرِينَ } - إلى قوله تعالى- { وَلاَ تَدْعُ مَعَ ٱللَّهِ إِلَـٰهاً آخَرَ } [86- 88] 8203/ [1]- علي بن إبراهيم: قوله تعالى: { فَلاَ تَكُونَنَّ } يا محمد { ظَهيراً لِّلْكَافِرِينَ } قال: المخاطبة للنبي (صلى الله عليه و آله)، و المعنى للناس.  و قوله: { وَلاَ تَدْعُ مَعَ ٱللَّهِ إِلَـٰهاً آخَرَ } المخاطبة للنبي (صلى الله عليه و آله)، و المعنى للناس، و هو قول الصادق (عليه السلام): " إن الله بعث نبيه بإياك أعني و اسمعي يا جارة ".
