قوله تعالى:  { وَيَوْمَ يُنَادِيهِمْ فَيَقُولُ أَيْنَ شُرَكَآئِيَ } - إلى قوله تعالى- { لَوْ أَنَّهُمْ كَانُواْ يَهْتَدُونَ } [62- 64] 8179/ [1]- علي بن إبراهيم: قوله: { وَيَوْمَ يُنَادِيهِمْ فَيَقُولُ أَيْنَ شُرَكَآئِيَ ٱلَّذِينَ كُنتُمْ تَزْعُمُونَ } يعني الذين قلتم هم شركاء لله، { قَالَ ٱلَّذِينَ حَقَّ عَلَيْهِمُ ٱلْقَوْلُ رَبَّنَا هَـٰؤُلاۤءِ ٱلَّذِينَ أَغْوَيْنَآ أَغْوَيْنَاهُمْ كَمَا غَوَيْنَا تَبَرَّأْنَآ إِلَيْكَ مَا كَانُوۤاْ إِيَّانَا يَعْبُدُونَ } يعني ما عبدوا، و هي عبادة الطاعة، { وَقِيلَ ٱدْعُواْ شُرَكَآءَكُمْ } الذين كنتم تدعونهم شركاء، { فَدَعَوْهُمْ فَلَمْ يَسْتَجِيبُواْ لَهُمْ وَرَأَوُاْ ٱلْعَذَابَ لَوْ أَنَّهُمْ كَانُواْ يَهْتَدُونَ }.
