قوله تعالى:  { لَقَدْ كَانَ فِي قَصَصِهِمْ عِبْرَةٌ لأُوْلِي ٱلأَلْبَابِ } - إلى قوله تعالى - { يُؤْمِنُونَ } [111]  5429/ [1]- و قال علي بن إبراهيم: ثم قال الله عز و جل: { لَقَدْ كَانَ فِي قَصَصِهِمْ عِبْرَةٌ لأُوْلِي ٱلأَلْبَابِ } يعني لاولي العقول: { مَا كَانَ حَدِيثاً يُفْتَرَىٰ } يعني القرآن { وَلَـٰكِن تَصْدِيقَ ٱلَّذِي بَيْنَ يَدَيْهِ } يعني من كتب الأنبياء { وَتَفْصِيلَ كُلِّ شَيْءٍ وَهُدًى وَرَحْمَةً لِّقَوْمٍ يُؤْمِنُونَ }.
