قوله تعالى:  { وَمَا مَنَعَنَآ أَن نُّرْسِلَ بِٱلآيَاتِ إِلاَّ أَن كَذَّبَ بِهَا ٱلأَوَّلُونَ } - إلى قوله تعالى- { إِلاَّ تَخْوِيفاً } [59]  6409/ [1]- و قال علي بن إبراهيم: قوله: { وَمَا مَنَعَنَآ أَن نُّرْسِلَ بِٱلآيَاتِ إِلاَّ أَن كَذَّبَ بِهَا ٱلأَوَّلُونَ } نزلت في قريش، وقوله: { وَآتَيْنَا ثَمُودَ ٱلنَّاقَةَ مُبْصِرَةً فَظَلَمُواْ بِهَا وَمَا نُرْسِلُ بِٱلآيَاتِ إِلاَّ تَخْوِيفاً } فعطف على قوله: { وَمَا مَنَعَنَآ أَن نُّرْسِلَ بِٱلآيَاتِ }.  6410/ [2]- قال: و في رواية أبي الجارود، عن أبي جعفر (عليه السلام) في قوله: { وَمَا مَنَعَنَآ أَن نُّرْسِلَ بِٱلآيَاتِ }.  قال: " و ذلك أن محمدا (صلى الله عليه و آله) سأله قومه أن يأتيهم بآية، فنزل جبرئيل (عليه السلام)، فقال: إن الله عز و جل يقول: { وَمَا مَنَعَنَآ أَن نُّرْسِلَ بِٱلآيَاتِ } إلى قومك { إِلاَّ أَن كَذَّبَ بِهَا ٱلأَوَّلُونَ } و كنا إذا أرسلنا إلى قرية آية فلم يؤمنوا بها أهلكناهم، فلذلك أخرنا عن قومك الآيات ".
