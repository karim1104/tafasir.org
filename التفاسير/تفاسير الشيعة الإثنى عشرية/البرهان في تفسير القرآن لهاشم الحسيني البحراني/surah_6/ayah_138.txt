قوله تعالى: { وَقَالُواْ هَـٰذِهِ أَنْعَٰمٌ وَحَرْثٌ حِجْرٌ } [الأنعام: 138] - إلى قوله تعالى - { قَدْ خَسِرَ ٱلَّذِينَ قَتَلُوۤاْ أَوْلَٰدَهُمْ سَفَهاً بِغَيْرِ عِلْمٍ وَحَرَّمُواْ مَا رَزَقَهُمُ ٱللَّهُ } [الأنعام: 140] - علي بن إبراهيم، في قوله تعالى: { وَقَالُواْ هَـٰذِهِ أَنْعَٰمٌ وَحَرْثٌ حِجْرٌ } قال: الحجر: المحرم { لاَّ يَطْعَمُهَآ إِلاَّ مَن نَّشَآءُ بِزَعْمِهِمْ } قال: كانوا يحرمونها على قوم { وَأَنْعَٰمٌ حُرِّمَتْ ظُهُورُهَا } يعني البحيرة و السائبة و الوصيلة و الحام.  ثم قال علي بن إبراهيم: قوله { وَقَالُواْ مَا فِي بُطُونِ هَـٰذِهِ ٱلأَنْعَٰمِ خَالِصَةٌ لِّذُكُورِنَا وَمُحَرَّمٌ عَلَىٰ أَزْوَٰجِنَا وَإِن يَكُن مَّيْتَةً فَهُمْ فِيهِ شُرَكَآءُ } قال: كانوا يحرمون الجنين الذي يخرجونه من بطون الأنعام، يحرمونه على النساء، فإذا كان ميتا أكله الرجال و النساء، فحكى الله تعالى قولهم لرسول الله (صلى الله عليه و آله) فقال: { وَقَالُواْ مَا فِي بُطُونِ هَـٰذِهِ ٱلأَنْعَٰمِ خَالِصَةٌ لِّذُكُورِنَا وَمُحَرَّمٌ عَلَىٰ أَزْوَٰجِنَا وَإِن يَكُن مَّيْتَةً فَهُمْ فِيهِ شُرَكَآءُ سَيَجْزِيهِمْ وَصْفَهُمْ إِنَّهُ حِكِيمٌ عَلِيمٌ }.  - و قال علي بن إبراهيم: ثم قال { قَدْ خَسِرَ ٱلَّذِينَ قَتَلُوۤاْ أَوْلَٰدَهُمْ سَفَهاً بِغَيْرِ عِلْمٍ } أي بغير فهم { وَحَرَّمُواْ مَا رَزَقَهُمُ ٱللَّهُ } و هم قوم يقتلون أولادهم من البنات للغيرة، و قوم كانوا يقتلون أولادهم من الجوع، و هذا معطوف على قوله: [الأنعام: 137] فقال الله: [الإسراء: 31].
