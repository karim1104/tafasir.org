قوله تعالى: { وَمِنْهُمْ مَّن يَسْتَمِعُ إِلَيْكَ وَجَعَلْنَا عَلَىٰ قُلُوبِهِمْ أَكِنَّةً } [الأنعام: 25] - إلى قوله تعالى - { وَهُمْ يَنْهَوْنَ عَنْهُ } [الأنعام: 26] - قال علي بن إبراهيم: ثم ذكر قريشا فقال: { وَمِنْهُمْ مَّن يَسْتَمِعُ إِلَيْكَ وَجَعَلْنَا عَلَىٰ قُلُوبِهِمْ أَكِنَّةً أَن يَفْقَهُوهُ } يعني غطاء { وَفِيۤ ءَاذَانِهِمْ وَقْراً } أي صمما { وَإِن يَرَوْاْ كُلَّ ءَايَةٍ لاَّ يُؤْمِنُواْ بِهَا حَتَّىٰ إِذَا جَآءُوكَ يُجَٰدِلُونَكَ } أي يخاصمونك { يَقُولُ ٱلَّذِينَ كَفَرُوۤاْ إِنْ هَـٰذَآ إِلاَّ أَسَٰطِيرُ ٱلأَوَّلِينَ }.  3442/ [2]- و قال علي بن إبراهيم: قوله تعالى: { وَهُمْ يَنْهَوْنَ عَنْهُ وَيَنْأَوْنَ عَنْهُ } قال: بنو هاشم، كانوا ينصرون رسول الله (صلى الله عليه و آله)، و يمنعون قريشا عنه، و ينأون عنه، أي يباعدون عنه، و يساعدونه و لا يؤمنون.
