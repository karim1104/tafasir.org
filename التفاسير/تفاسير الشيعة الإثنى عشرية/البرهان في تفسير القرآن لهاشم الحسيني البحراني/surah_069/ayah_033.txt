قوله تعالى: { إِنَّهُ كَانَ لاَ يُؤْمِنُ بِٱللَّهِ } - إلى قوله تعالى- { وَلاَ طَعَامٌ إِلاَّ مِنْ غِسْلِينٍ } [33-36] 11048/ [1]- علي بن إبراهيم: قوله تعالى: { إِنَّهُ كَانَ لاَ يُؤْمِنُ بِٱللَّهِ ٱلْعَظِيمِ * وَلاَ يَحُضُّ عَلَىٰ طَعَامِ ٱلْمِسْكِينِ } حقوق آل محمد التي غصبوها، قال الله: { فَلَيْسَ لَهُ ٱلْيَوْمَ هَا هُنَا حَمِيمٌ } أي قرابة { وَلاَ طَعَامٌ إِلاَّ مِنْ غِسْلِينٍ } قال: عرق الكفار.
