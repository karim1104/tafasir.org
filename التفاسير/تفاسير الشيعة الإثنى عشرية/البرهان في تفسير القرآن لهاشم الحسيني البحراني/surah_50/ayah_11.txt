قوله تعالى: { وَٱلنَّخْلَ بَاسِقَاتٍ لَّهَا طَلْعٌ نَّضِيدٌ } - إلى قوله تعالى- { كَذَلِكَ ٱلْخُرُوجُ } [10-11] 10029/ [1]- علي بن إبراهيم، في قوله تعالى: { وَٱلنَّخْلَ بَاسِقَاتٍ } أي مرتفعات لَها { طَلْعٌ نَّضِيدٌ } يعني بعضه على بعض { رِّزْقاً لِّلْعِبَادِ وَأَحْيَيْنَا بِهِ بَلْدَةً مَّيْتاً كَذَلِكَ ٱلْخُرُوجُ } ، جوابا لقولهم: [ق: 3]، فقال الله: كما أن الماء إذا أنزلناه من السماء، فيخرج النبات من الأرض، كذلك أنتم تخرجون من الأرض.
