{ (86) وَلاَ يَمْلِكُ الَّذِينَ يَدْعُونَ مِنْ دُونِهِ الشَّفَاعَةَ } القمّي قال هم الذين عبدوا في الدنيا لا يملكون الشفاعة لمن عبدهم { إِلاَّ مَنْ شَهِدَ بِالْحَقِّ وَهُمْ يَعْلَمُونَ } بالتوحيد.  { (87) وَلَئِنْ سَئَلْتَهُمْ مَنْ خَلَقَهُمْ لَيَقُولُنَّ اللهُ } لتعذّر المكابرة فيه من فرط ظهوره { فَأَنَّى يُؤْفَكُونَ } يصرفون من عبادته الى عبادة غيره.  { (88) وَقِيلِهِ } وقول الرسول اي ويعلم قوله او وقال قوله وقيل الهاء زائدة وقرئ بالجرّ عطفاً على الساعة { يَا رَبِّ إِنَّ هؤُلاَءِ قَوْمٌ لاَ يُؤْمِنُونَ }  (89) فَاصْفَحْ عَنْهُمْ } فاعرض عن دعوتهم آيساً عن ايمانهم { وَقُلْ سَلاَمٌ } تسلم منكم ومتاركة { فَسَوفَ يَعْلَمُونَ } تسلية للرسول صلّى الله عليه وآله وتهديد لهم وقرئ بالتاء.  في ثوال الاعمال والمجمع عن الباقر عليه السلام من قرأ حم الزّخرف آمنه الله في قبره من هوام الارض وضغطة القبر حتّى يقف بين يدي الله عزّ وجلّ ثم جاءت حتّى تدخله الجنّة بأمر الله تبارك وتعالى.
