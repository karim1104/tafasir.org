{ (1) وَيْلٌ لِكُلِّ هُمَزَةٍ لُمَزَةٍ } اصل الهمز الكسر واللّمز الطّعن وشاعا في كسر الاعراض بالطّعن القمّي قال همزة الذي يغمز الناس ويستحقر الفقراء وقوله لمزة الذي يلوي عنقه ورأسه ويغضب اذا رأى فقيرا او سائلاً.  { (2) الَّذِي جَمَعَ مَالاً وَعَدَّدَهُ } وجعله عدّة للنّوازل او عدّة مرّة بعد اخرى والقمّي قال اعدّه ووضعه وقرىء جمع بالتّشديد للتكثير.  { (3) يَحْسَبُ أَنْ مَالَهُ أَخْلَدَهُ } تركه خالداً في الدّنيا والقمّي قال ويبقيه.  { (4) كَلاَّ لَيُنْبَذَنَّ } ليطرحنّ { فِي الْحُطَمَةِ } القمّي النّار التي تحطم كلّ شيء.  { (5) وَمَا أَدْرَاكَ مَا الْحُطَمَةُ }.  { (6) نارُ اللَّهُ الْمُوقَدَةُ } التي اوقدها الله وما اوقده الله لا يقدر ان يطفأه غيره.  { (7) الَّتِي تَطَّلِعُ عَلَى الأَفْئِدَةِ } القمّي قال تتلهّب على الفؤاد.  { (8) إِنَّهَا عَلَيْهِمْ مُؤصَدَةٌ } قال مطبقة.  { (9) فِي عَمَدٍ مُمَدَّدةٍ } في اعمد ممدودة اي موثّقين في اعمد ممدودة القمّي قال اذا مدّت العمد عليهم كان والله الخلود.  والعيّاشي عن الباقر عليه السلام ما في معناه وقرىء عُمد بضمّتين.  في ثواب الأعمال والمجمع عن الصادق عليه السلام من قرأ ويل لكلّ همزة لمزة في فريضة من فرائضه بعّد الله عنه الفقر وجلب عليه الرزق ويدفع عنه ميتة السوء.
