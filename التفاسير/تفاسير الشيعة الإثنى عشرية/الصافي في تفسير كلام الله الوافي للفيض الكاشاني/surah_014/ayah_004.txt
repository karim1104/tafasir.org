{ (4) وَمَا أَرْسَلْنَا مِن رَسُولٍ إِلاَّ بِلِسَانِ قوْمِهِ } إلاّ بلغة قومه الذين هو منهم وبعث فيهِم { لِيُبَيِّنَ لَهُمْ } ما أمروا به فيفقهوه بيسر وسرعة في الخصال عن النّبيّ صلىَّ الله عليه وآله وسلم في حديث " ومنّ عليّ ربّي وقال يا محمّد قد أرسلت كلّ رسول إلى أمّة بلسانها وأرسلتك إلى كل أحمر وأسود من خلقي " { فَيُضِلُّ اللهُ مَن يَشَاءُ } بالخذلان { وَيَهْدِي مَن يَشَاءُ } بالتوفيق { وَهُوَ الْعَزِيزُ } فلا يغالب على مشَّيته { الْحَكِيمُ } الذي لا يفعل ما يفعل إلاّ لحكمته.
