{ (35) ذلِكُمْ بِأنَّكُمُ اتَّخَذْتُمْ آيَاتِ اللَّهِ هُزُواً } القمّي وهم الأئمّة عليهم السلام اي كذبتموهم واستهزأتم بهم { وَغَرَّتْكُمُ الْحَياةُ الدُّنْيا } فحسبتم ان لا حياة سواها { فَالْيَوْمَ لاَ يُخْرَجُونَ مِنْهَا } من النار وقرء بفتح الياء وضمّ الرّاء { وَلاَ هُمْ يُسْتَعْتَبُونَ } لا يطلب منهم ان يعتبوا ربّهم اي يرضوه لفوات اوانه والقمّي ولا يجاوبون ولا يقبلهم الله.
