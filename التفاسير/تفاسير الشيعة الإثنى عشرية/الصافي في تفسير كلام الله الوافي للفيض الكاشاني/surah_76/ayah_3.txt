{ (1) هَلْ أَتَى عَلَى الإِنسانِ } استفهام تقرير وتقريب ولذلك فسرّ بقد { حِينٌ مِنَ الدَّهْرِ } طائفة من الزمان { لَمْ يَكُنْ شَيْئاً مَذْكُوراً }.  في الكافي عن الصادق عليه السلام قال كان مقدوراً غير مذكور.  وفي المجمع قال كان شيئاً مقدوراً ولم يكن مكوّناً.  وعن الباقر عليه السلام قال كان شيئاً ولم يكن مذكوراً.  ومثله في المحاسن عن الصادق عليه السلام وفي المجمع عنهما عليها السلام كان مذكوراً في العلم ولم يكن مذكوراً في الخلق.  { (2) إِنَّا خَلَقْنَا الإِنْسانَ مِنْ نُطْفَةٍ أَمْشَاجٍ } اخلاط.  القمّي عن الباقر عليه السلام ماء الرجل والمرأة اختلطا جميعاً { نَبْتَلِيهِ } نختبره { فَجَعَلْنَاهُ سَمِيعاً بَصِيراً } ليتمكّن من استماع الآيات ومشاهدة الدّلائل.  { (3) إِنَّا هَدَيْنَاهُ السَّبِيلَ } بنصب الدلائل وانزال الآيات القمّي اي بيّنا له طريق الخير والشرّ { إِمَّا شَاكِرَاً وَإِمَّا كَفُوراً }.  في الكافي والتوحيد عن الصادق عليه السلام قال عرّفناه امّا آخذا وامّا تاركا.  والقمّي عن الباقر عليه السلام امّا آخذ فشاكر وامّا تارك فكافر.
