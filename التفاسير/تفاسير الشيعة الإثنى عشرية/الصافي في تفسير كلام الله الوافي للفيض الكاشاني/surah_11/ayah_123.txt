{ (123) وَللهِ غَيْبُ السَّمَوَاتِ وَالأَرْضِ } لا لغيره { وَإلَيْهِ يُرْجَعُ الأَمْرُ كُلُّهُ } لا إلى غيره وقرئ بضمّ الياءِ { فَاعْبُدْهُ وَتَوَكَّلْ عَلَيْهِ } فانّه كافيكَ { وَمَا رَبُّكَ بِغَافِلٍ عَمَّا تَعْمَلُونَ } أنت وهم فيجازي كلاّ بما يستحقّه وقرئ بالياءِ.  في ثواب الأعمال عن الباقر عليه السلام من قرأ سورة هود في كل جمعة بعثه الله يوم القيامة في زمرة النّبيّين ولم تعرف له خطيئة عملها يومَ القيامةِ وِالحمدُ للهِ.
