و قوله :  {  و نحن أقرب إليه منكم ولكن لا تبصرون } أي والحال أنا أقرب إليه منكم لإحاطتنا به وجودا ورسلنا القابضون لروحه أقرب إليه منكم ولكن لا تبصروننا ولا رسلنا . <br />
قال تعالى :  {  الله يتوفى الأنفس حين موتها } :  الزمر :  26 ،  وقال :  {  قل يتوفاكم ملك الموت الذي وكل بكم } :  السجدة :  11 ،  وقال :  {  حتى إذا جاء أحدهم الموت توفته رسلنا } :  الأنعام :  61 .
