{  قالوا } تندما {  يا ويلنا إنا كنا ظالمين فما زالت تلك } وهي كلمتهم يا ويلنا المشتملة على الاعتراف بربوبيته تعالى وظلم أنفسهم {  دعواهم حتى جعلناهم حصيدا } محصودا مقطوعا {  خامدين } ساكنين ساكتين كما تخمد النار لا يسمع لهم صوت ولا يذكر لهم صيت . <br />
و قد وجه قوله :  {  لعلكم تسألون } بوجوه أخرى بعيدة من الفهم تركنا التعرض لها . <br />
