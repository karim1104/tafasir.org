قوله تعالى :  {  لا يسمعون حسيسها } إلى قوله {  توعدون } الحسيس الصوت الذي يحس به ،  والفزع الأكبر الخوف الأعظم وقد أخبر سبحانه عن وقوعه في نفخ الصور حيث قال :  {  و يوم ينفخ في الصور ففزع من في السماوات ومن في الأرض } النمل :  87 . <br />
و قوله :  {  و تتلقاهم الملائكة } أي بالبشرى وهي قولهم :  {  هذا يومكم الذي كنتم توعدون } .
