بيان<br />
إجمال قصة شعيب ( عليه السلام ) وهو من أنبياء العرب ،  وهي آخر القصص السبع الموردة في السورة . <br />
قوله تعالى :  {  كذب أصحاب الأيكة المرسلين } - إلى قوله – {  رب العالمين } الأيكة الغيضة الملتف شجرها . <br />
قيل :  إنها كانت غيضة بقرب مدين يسكنها طائفة وكانوا ممن بعث إليهم شعيب ( عليه السلام ) ،  وكان أجنبيا عنهم ولذلك قيل :  {  إذ قال لهم شعيب } ولم يقل :  أخوهم شعيب بخلاف هود وصالح فقد كانا نسيبين إلى قومهما وكذا لوط فقد كان نسيبا إلى قومه بالمصاهرة ولذا عبر عنهم بقوله :  {  أخوهم هود } {  أخوهم صالح } {  أخوهم لوط } . <br />
و قد تقدم تفسير باقي الآيات . <br />
بحث روائي<br />
في جوامع الجامع في قوله تعالى :  {  إذ قال لهم شعيب } وفي الحديث أن شعيبا أخا مدين أرسل إليهم وإلى أصحاب الأيكة<br />
