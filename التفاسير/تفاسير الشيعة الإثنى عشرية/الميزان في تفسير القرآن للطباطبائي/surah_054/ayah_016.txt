قوله تعالى :  {  فكيف كان عذابي ونذر } النذر جمع نذير بمعنى الإنذار ،  وقيل :  مصدر بمعنى الإنذار . <br />
و الظاهر أن {  كان } ناقصة واسمها {  عذابي } وخبرها {  فكيف } ،  ويمكن أن تكون تامة فاعلها قوله :  {  عذابي } وقوله :  {  فكيف } حالا منه . <br />
و كيف كان فالاستفهام للتهويل يسجل به شدة العذاب وصدق الإنذار . <br />
