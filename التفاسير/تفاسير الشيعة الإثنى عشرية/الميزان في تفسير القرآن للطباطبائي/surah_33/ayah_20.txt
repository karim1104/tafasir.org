قوله تعالى :  {  يحسبون الأحزاب لم يذهبوا } إلى آخر الآية ،  أي يظنون من شدة الخوف أن الأحزاب - وهم جنود المشركين المتحزبون على النبي ( صلى الله عليه وآله وسلم ) - لم يذهبوا بعد {  و إن يأت الأحزاب } مرة ثانية بعد ذهابهم وتركهم المدينة {  يودوا } ويحبوا {  أنهم بادون } أي خارجون من المدينة إلى البدو {  في الأعراب يسألون عن أنبائكم } وأخباركم {  ولو كانوا فيكم } ولم يخرجوا منها بادين {  ما قاتلوا إلا قليلا } أي ولا كثير فائدة في لزومهم إياكم وكونهم معكم فإنهم لن يقاتلوا إلا قليلا لا يعتد به . <br />
