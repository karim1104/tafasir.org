قوله تعالى :  {  و أنزل الذين ظاهروهم من أهل الكتاب من صياصيهم } - إلى قوله – {  قديرا } المظاهرة المعاونة ،  والصياصي جمع صيصية وهي الحصن الذي يمتنع به ولعل التعبير بالإنزال دون الإخراج لأن المتحصنين يصعدون بروج الحصون ويشرفون منها ومن أعالي الجدران على أعدائهم في خارجها ومحاصريهم . <br />
والمعنى :  {  و أنزل الذين ظاهروهم } أي عاونوا المشركين وهم بنو قريظة {  من أهل الكتاب } وهم اليهود {  من صياصيهم } وحصونهم {  و قذف } وألقى {  في قلوبهم الرعب } والخوف {  فريقا تقتلون } وهم الرجال {  و تأسرون فريقا } وهم الذراري والنساء<br />
