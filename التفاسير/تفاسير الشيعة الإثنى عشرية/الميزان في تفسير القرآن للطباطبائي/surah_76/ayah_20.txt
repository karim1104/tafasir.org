قوله تعالى :  {  و إذا رأيت ثم رأيت نعيما وملكا كبيرا } {  ثم } ظرف مكان ممحض في الظرفية ،  ولذا قيل :  إن معنى {  رأيت } الأول :  رميت ببصرك ،  والمعنى وإذا رميت ببصرك ثم يعني الجنة رأيت نعيما لا يوصف وملكا كبيرا لا يقدر قدره . <br />
و قيل :  {  ثم } صلة محذوفة الموصول والتقدير وإذا رأيت ما ثم من النعيم والملك ،  وهو كقوله :  {  لقد تقطع بينكم } :  الأنعام :  94 والكوفيون من النحاة يجوزون حذف الموصول وإبقاء الصلة وإن منعه البصريون منهم . <br />
