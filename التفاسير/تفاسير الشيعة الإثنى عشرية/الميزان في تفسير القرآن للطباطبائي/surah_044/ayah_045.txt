قوله تعالى :  {  كالمهل يغلي في البطون كغلي الحميم } المهل هو المذاب من النحاس والرصاص وغيرهما ،  والغلي والغليان معروف ،  والحميم الماء الحار الشديد الحرارة ،  وقوله :  {  كالمهل } خبر ثان لقوله :  {  إن } كما أن قوله :  {  طعام الأثيم } خبر أول ،  وقوله :  {  يغلي في البطون كغلي الحميم } خبر ثالث ،  والمعنى ظاهر . <br />
بحث روائي<br />
و في تفسير القمي ،  ثم قال :  {  إن شجرة الزقوم طعام الأثيم } نزلت في أبي جهل بن هشام ،  وقوله :  {  كالمهل } قال :  المهل الصفر المذاب {  يغلي في البطون كغلي الحميم } وهو الذي قد حمي وبلغ المنتهى . <br />
أقول :  ومن طرق أهل السنة أيضا روايات تؤيد نزول الآية في أبي جهل . <br />
