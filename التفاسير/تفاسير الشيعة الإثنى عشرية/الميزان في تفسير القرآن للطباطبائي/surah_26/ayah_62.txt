{  قال موسى كلا } لن يدركونا {  إن معي ربي سيهدين } والمراد بهذه المعية معية الحفظ والنصرة وهي التي وعدها له ربه أول ما بعثه وأخاه إلى فرعون :  {  إنني معكما } وأما معية الإيجاد والتدبير فالله سبحانه مع موسى وفرعون على نسبة سواء ،  وقوله :  {  سيهدين } أي سيدلني على طريق لا يدركني فرعون معها . <br />
