قوله تعالى :  {  وما تنزلت به الشياطين } - إلى قوله – {  لمعزولون } شروع في الجواب عن قول المشركين :  إن لمحمد جنا يأتيه بهذا الكلام ،  وقولهم :  إنه شاعر ،  وقدم الجواب عن الأول وقد وجه الكلام أولا إلى النبي ( صلى الله عليه وآله وسلم ) فبين له أن القرآن ليس من تنزيل الشياطين وطيب بذلك نفسه ثم وجه القول إلى القوم فبينه لهم بما في وسعهم أن يفقهوه . <br />
فقوله :  {  وما تنزلت به الشياطين } أي ما نزلته والآية متصلة بقوله :  {  وإنه لتنزيل رب العالمين } ووجه الكلام كما سمعت إلى النبي ( صلى الله عليه وآله وسلم ) بدليل قوله تلوا :  {  فلا تدع مع الله إلها آخر } إلى آخر الخطابات المختصة به ( صلى الله عليه وآله وسلم ) المتفرعة على قوله :  {  وما تنزلت به } إلخ ،  على ما سيجيء بيانه . <br />
و إنما وجه الكلام إلى النبي ( صلى الله عليه وآله وسلم ) دون القوم لأنه معلل بما لا يقبلونه بكفرهم أعني قوله :  {  إنهم عن السمع لمعزولون } والشيطان الشرير وجمعه الشياطين والمراد بهم أشرار الجن . <br />
