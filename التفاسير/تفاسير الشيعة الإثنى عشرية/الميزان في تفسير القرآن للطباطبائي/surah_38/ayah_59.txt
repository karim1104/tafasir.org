قوله تعالى :  {  هذا فوج مقتحم معكم } إلى قوله {  في النار } الآيات الثلاث - على ما يعطيه السياق - حكاية ما يجري بين التابعين والمتبوعين من الطاغين في النار من التخاصم والمجاراة . <br />
فقوله :  {  هذا فوج مقتحم معكم } خطاب يخاطب به المتبوعون يشار به إلى التابعين الذين يدخلون النار مع المتبوعين فوجا ،  والاقتحام الدخول في الشيء بشدة وصعوبة . <br />
و قوله :  {  لا مرحبا بهم إنهم صالوا النار } جواب المتبوعين لمن يخاطبهم بقوله :  {  هذا فوج } ومرحبا تحية للوارد معناه عرض رحب الدار وسعتها له فقولهم :  {  لا مرحبا بهم } معناه نفي الرحب والسعة عنهم . <br />
و قولهم :  {  إنهم صالوا النار } أي داخلوها ومقاسوا حرارتها أو متبعوها تعليل لتحيتهم بنفي التحية . <br />
