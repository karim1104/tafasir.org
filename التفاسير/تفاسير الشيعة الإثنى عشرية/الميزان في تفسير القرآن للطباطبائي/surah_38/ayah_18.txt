قوله تعالى :  {  إنا سخرنا الجبال معه يسبحن بالعشي والإشراق } الظاهر أن {  معه } متعلق بقوله :  {  يسبحن } وجملة {  معه يسبحن } بيان لمعنى التسخير وقدم الظرف لتعلق العناية بتبعيتها لداود واقتدائها في التسبيح لكن قوله تعالى في موضع آخر :  {  و سخرنا مع داود الجبال يسبحن والطير } الأنبياء :  - 79 يؤيد تعلق الظرف بسخرنا ،  وقد وقع في موضع آخر من كلامه تعالى :  {  يا جبال أوبي معه والطير } سبأ :  - 10 . <br />
و العشي والإشراق الرواح والصباح . <br />
و قوله :  {  إنا سخرنا } إلخ {  إن } فيه للتعليل والآية وما عطف عليها من الآيات بيان لكونه ( عليه السلام ) ذا أيد في تسبيحه وملكه وعلمه وكونه أوابا إلى ربه .
