قوله تعالى :  {  و الكتاب المبين } ظاهره أنه قسم وجوابه قوله :  {  إنا جعلناه قرآنا عربيا } إلى آخر الآيتين ،  وكون القرآن مبينا هو إبانته وإظهاره طريق الهدى كما قال تعالى :  {  و نزلنا عليك الكتاب تبيانا لكل شيء } النحل :  89 ،  أو كونه ظاهرا في نفسه لا يرتاب فيه كما قال :  {  ذلك الكتاب لا ريب فيه } البقرة :  2 .
