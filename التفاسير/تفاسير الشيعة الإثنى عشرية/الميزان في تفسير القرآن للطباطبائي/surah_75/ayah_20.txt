قوله تعالى :  {  كلا بل تحبون العاجلة وتذرون الآخرة } خطاب للناس وليس من تعميم الخطاب السابق في شيء لأن خطاب {  لا تحرك } اعتراضي غير مرتبط بشيء من طرفيه . <br />
و قوله :  {  كلا } ردع عن قوله السابق :  {  يحسب الإنسان أن لن نجمع عظامه } وقوله :  {  بل تحبون العاجلة } - أي الحياة العاجلة وهي الحياة الدنيا - {  و تذرون الآخرة } أي تتركون الحياة الآخرة ،  وما في الكلام من الإضراب إضراب عن حسبان عدم الإحياء بعد الموت نظير الإضراب في قوله :  {  بل يريد الإنسان ليفجر أمامه } . <br />
