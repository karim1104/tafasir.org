قوله تعالى :  {  ثم قيل للذين ظلموا ذوقوا عذاب الخلد هل تجزون إلا بما كنتم تكسبون } الأشبه أن تكون الآية متصلة بقوله تعالى :  {  لكل أمة أجل } إلخ ،  فتكون الآية الأولى تبين تحقق وقوع العذاب عليهم وإهلاكه إياهم ،  والآية الثانية تبين أنه يقال لهم بعد الوقوع والهلاك :  ذوقوا عذاب الخلد وهو عذاب الآخرة ولا تجزون إلا أعمالكم التي كنتم تكسبونها وذنوبكم التي تحملونها والخطاب تكويني كني به عن شمول العذاب لهم ونيله إياهم ،  وعلى هذا المعنى فالآيتان :  {  قل أرأيتم } إلى قوله {  تستعجلون } واردتان مورد الاعتراض . <br />
