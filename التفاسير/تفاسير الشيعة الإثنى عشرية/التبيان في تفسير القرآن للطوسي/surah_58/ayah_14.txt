ثم قال للنبي ( صلى الله عليه وآله ) { ألم تر } يا محمد { إلى الذين تولوا قوما غضب الله عليهم }  ،  والمراد به قوم من المنافقين ،   كانوا يوالون اليهود ويغشون اليهم أسرارهم ويجتمعون معهم على ذكر مساءة النبي ( صلى الله عليه وآله ) والمؤمنين - وهو قول قتادة وابن زيد - ثم قال { ما هم منكم } أي ليسوا مؤمنين  ،  { ولا منهم } أي ولا هم يهود ،   فيكونوا منهم بل هم قوم منافقون  .   ثم قال { ويحلفون } يعني هؤلاء المنافقون { على الكذب } يعني يقولون إنا معكم ونحن نتوب ،   وليسوا كذلك { وهم يعلمون } أنه كذلك .  <br />
