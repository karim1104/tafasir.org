أما قوله: { فأما من أوتي كتابه بيمينه } [19] فإنه قال الصادق عليه السلام: كل أمة يحاسبها إمام زمانها ويعرف الأئمة أولياء‌هم وأعداء‌هم بسيماهم وهو قوله تعالى: { وعلى الأعراف رجال } وهم الأئمة { يعرفون كلاًّ بسيماهم } فيعطون أولياء‌هم كتابهم بيمينهم فيمرون إلى الجنة بلا حساب، ويعطون أعداء‌هم كتابهم بشمالهم فيمرون إلى النار بلا حساب فإذا نظر أولياؤهم في كتابهم يقولون لإِخوانهم { هاؤم اقرؤا كتابيه إني ظننت أني ملاق حسابيه فهو في عيشة راضية } [19-21] أي: مرضية فوضع الفاعل مكان المفعول.
