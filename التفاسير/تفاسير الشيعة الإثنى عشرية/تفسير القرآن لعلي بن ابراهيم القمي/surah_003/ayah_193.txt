قال علي بن إبراهيم في قوله: { الذين يذكرون الله قياماً وقعوداً وعلى جنوبهم } [191] يعني الصحيح يصلي قائماً والمريض يصلي جالساً وعلى جنوبهم يعني مضطجعاً يؤمي إيماء‌اً إلى قوله { ما للظالمين من أنصار } [192] فهو محكم { ربنا إننا سمعنا منادياً ينادي للإيمان } [193] يعني رسول الله ينادي إلى الإِيمان إلى قوله { إنك لا تخلف الميعاد } [194].
