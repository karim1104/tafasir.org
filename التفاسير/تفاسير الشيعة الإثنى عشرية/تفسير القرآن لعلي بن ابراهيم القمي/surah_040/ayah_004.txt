قوله: { ما يجادل في آيات الله } [4] وهم الأئمة عليه السلام { إلا الذين كفروا فلا يغررك تقلبهم في البلاد كذبت قبلهم قوم نوح والأحزاب من بعدهم } [4-5] أصحاب الأنبياء الذين تحزبوا { وهمت كل أمة برسولهم ليأخذوه } يعني: يقتلوه { وجادلوا بالباطل } أي: خاصموا { ليدحضوا به الحق } أي: يبطلوه ويدفعوه { فأخذتهم فكيف كان عقاب }.
