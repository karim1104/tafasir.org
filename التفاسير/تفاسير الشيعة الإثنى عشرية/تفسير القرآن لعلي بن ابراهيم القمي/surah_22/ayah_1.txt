{ يا أيها الناس اتقوا ربكم إن زلزلة الساعة شيء عظيم } [1] قال: مخاطبة للناس عامة { يوم ترونها تذهل كل مرضعة عما أرضعت } [2] أي: تبقى وتتحير وتتغافل { وتضع كل ذات حمل حملها } قال: كل امرأة تموت حاملة عند زلزلة الساعة تضع حملها يوم القيامة وقوله: { وترى الناس سكارى } قال: يعني ذاهلة عقولهم من الخوف والفزع متحيرين وقال { وما هم بسكارى ولكن عذاب الله شديد }.
