حدثنا محمد بن جعفر قال: حدثنا يحيى بن زكريا اللؤلؤي عن علي بن حنان عن عبد الرحمن بن كثير قال: سألت الصادق عليه السلام عن قوله: { أم نجعل الذين آمنوا وعملوا الصالحات } قال أمير المؤمنين عليه السلام وأصحابه { كالمفسدين في الأرض } حبتر وزريق وأصحابهما { أم نجعل المتقين } أمير المؤمنين عليه السلام وأصحابه { كالفجار } حبتر ودلام وأصحابهما.
