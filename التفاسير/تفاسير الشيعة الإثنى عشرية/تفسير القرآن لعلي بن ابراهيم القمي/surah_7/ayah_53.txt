قوله: { هل ينظرون إلا تأويله يوم يأتي تأويله } فهو من الآيات التي تأويلها بعد تنزيلها، قال: ذلك في القائم عليه السلام، ويوم القيامة { يقول الذين نسوه من قبل } أي: تركوه { قد جاء‌ت رسل ربنا بالحق فهل لنا من شفعاء فيشفعوا لنا } قال هذا يوم القيامة { أو نرد فنعمل غير الذي كنا نعمل قد خسروا أنفسهم وضل عنهم } أي: بطل عنهم { ما كانوا يفترون }.
