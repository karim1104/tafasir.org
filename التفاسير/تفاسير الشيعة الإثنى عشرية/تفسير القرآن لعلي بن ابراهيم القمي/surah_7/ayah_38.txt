قوله: { قال ادخلوا في أمم قد خلت من قبلكم من الجن والإِنس في النار كلما دخلت أمة لعنت أختها حتى إذا اداركوا فيها جميعاً } يعني: اجتمعوا وقوله: { أختها } أي: التي كانت بعدها تبعوهم على عبادة الأصنام وقوله: { قالت أخراهم لأولاهم ربنا هؤلاء أضلونا } يعني: أئمة الجور { فآتهم عذاباً ضعفاً من النار } فقال الله: { لكل ضعف ولكن لا تعلمون }.
