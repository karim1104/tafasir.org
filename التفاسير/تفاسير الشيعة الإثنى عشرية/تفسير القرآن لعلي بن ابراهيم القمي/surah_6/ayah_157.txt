{ أو تقولوا لو أنا أنزل علينا الكتاب لكنا أهدى منهم } يعني: قريشاً، قالوا لو أنزل علينا الكتاب لكنا أهدى وأطوع منهم { فقد جاء‌كم بينة من ربكم وهدى ورحمة } يعني: القرآن { فمن أظلم ممن كذب بآيات الله وصدف عنها } يعني: دفع عنها { سنجزي الذين يصدفون عن آياتنا } أي: يدفعون ويمنعون عن آياتنا { سوء العذاب بما كانوا يصدفون }.
