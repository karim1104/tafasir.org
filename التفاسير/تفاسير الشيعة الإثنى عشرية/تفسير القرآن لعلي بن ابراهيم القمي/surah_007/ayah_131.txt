قوله: { ولقد أخذنا آل فرعون بالسنين ونقص من الثمرات } يعني بالسنين الجدبة لما أنزل الله عليهم الطوفان والجراد والضفادع والدم، وأما قوله: { فاذا جاء‌تهم الحسنة قالوا لنا هذه } قال: الحسنة ها هنا الصحة والسلامة والأمن والسعة { وإن تصبهم سيئة } قال السيئة ها هنا الجوع والخوف والمرض { يطيروا بموسى ومن معه } أي يتشاء‌موا بموسى ومن معه.
