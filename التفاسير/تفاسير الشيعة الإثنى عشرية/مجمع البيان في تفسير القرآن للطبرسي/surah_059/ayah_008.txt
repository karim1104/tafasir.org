ثم قال سبحانه : { للفقراء المهاجرين } الذين هاجروا من مكة إلى المدينة ،   ومن دار الحرب إلى دار الإسلام { الذين أخرجوا من ديارهم وأموالهم } التي كانت لهم { يبتغون } أي يطلبون { فضلا من الله ورضوانا وينصرون الله } أي وينصرون دين الله { ورسوله أولئك هم الصادقون } في الحقيقة عند الله العظيمو المنزلة عنده .   قال الزجاج : بين سبحانه من المساكين الذين لهم الحق فقال : { للفقراء المهاجرين الذين أخرجوا من ديارهم وأموالهم } .
