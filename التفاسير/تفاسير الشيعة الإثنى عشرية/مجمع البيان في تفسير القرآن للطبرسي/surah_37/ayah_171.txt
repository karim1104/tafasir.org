{  وَلَقَدْ سَبَقَتْ كَلِمَتُنَا لِعِبَادِنَا الْمُرْسَلِينَ  } * {  إِنَّهُمْ لَهُمُ الْمَنصُورُونَ  } * {  وَإِنَّ جُندَنَا لَهُمُ الْغَالِبُونَ  } * {  فَتَوَلَّ عَنْهُمْ حَتَّى حِينٍ  } * {  وَأَبْصِرْهُمْ فَسَوْفَ يُبْصِرُونَ  } * {  أَفَبِعَذَابِنَا يَسْتَعْجِلُونَ  } * {  فَإِذَا نَزَلَ بِسَاحَتِهِمْ فَسَآءَ صَبَاحُ الْمُنْذَرِينَ  } * {  وَتَوَلَّ عَنْهُمْ حَتَّى حِينٍ  } * {  وَأَبْصِرْ فَسَوْفَ يُبْصِرُونَ  } * {  سُبْحَانَ رَبِّكَ رَبِّ الْعِزَّةِ عَمَّا يَصِفُونَ  } * {  وَسَلاَمٌ عَلَى الْمُرْسَلِينَ  } * {  وَالْحَمْدُ للَّهِ رَبِّ الْعَالَمِينَ  }<br />
المعنى : ثم أقسم سبحانه فقال {  ولقد سبقت كلمتنا لعبادنا المرسلين  } أي سبق الوعد منا لعبادنا الذين بعثناهم إلى الخلق <br />
