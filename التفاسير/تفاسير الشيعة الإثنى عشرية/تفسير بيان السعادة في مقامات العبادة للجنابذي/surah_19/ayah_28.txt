{ يٰأُخْتَ هَارُونَ } قيل: كان هارون امرءً صالحاً فنسبوها اليه استهزاءً او لصلاحها وعبادتها، وقيل: انّ هارون كان اخاها لابيها، وقيل: انّ هارون كان معروفاً بالفسوق فنسبوها اليه { مَا كَانَ أَبُوكِ ٱمْرَأَ سَوْءٍ } حتّى اكتسبت هذا الفعل منه { وَمَا كَانَتْ أُمُّكِ بَغِيّاً } بغت المرأة فجرت فهى بغىّ وبغوّ.
