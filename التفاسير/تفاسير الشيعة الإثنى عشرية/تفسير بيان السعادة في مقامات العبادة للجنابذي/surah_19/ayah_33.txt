{ قَالَ } عيسى (ع) { إِنِّي عَبْدُ ٱللَّهِ } اقرّ لنفسه بالعبوديّة اوّلاً لئلاّ يتموهّموا ما يتوهموا لكونه بلا ابٍ وتكلّمه حين الولادة من انّه ابن الله او انّه هو الله، او انّه ثالث ثلاثةٍ { آتَانِيَ ٱلْكِتَابَ } اتى بالماضى لتحقّق وقوعه، او لتحقّق استعداده، والمراد بالكتاب الانجيل او كتاب النّبوّة { وَجَعَلَنِي نَبِيّاً وَجَعَلَنِي مُبَارَكاً } كثير الخير نفّاعاً او نامياً فى الخير { أَيْنَ مَا كُنتُ وَأَوْصَانِي بِٱلصَّلاَةِ وَٱلزَّكَاةِ مَا دُمْتُ حَيّاً وَبَرّاً بِوَالِدَتِي } قرئ برّاً بفتح الباء وصفاً بمعنى كثير البرّ وحينئذٍ يكون عطفاً على مباركاً ويلزم منه الفصل بين المعطوف والمعطوف عليه، او عطفاً على اوصانى بتقدير جعلنى، وقرئ برّاً بكسر الباء مصدراً فيكون عطفاً على الصّلوة { وَلَمْ يَجْعَلْنِي جَبَّاراً } متجبّراً متكبّراً { شَقِيّاً وَٱلسَّلاَمُ عَلَيَّ يَوْمَ وُلِدْتُّ وَيَوْمَ أَمُوتُ وَيَوْمَ أُبْعَثُ حَيّاً } تغيير السّلام مع قوله تعالى سلامٌ عليه بالتّعريف والتّنكير وبنسبة الاوّل الى الله والثّانى الى عيسى (ع) نفسه يعلم وجهه من تفاوت مقام عيسى (ع) ويحيى (ع).
