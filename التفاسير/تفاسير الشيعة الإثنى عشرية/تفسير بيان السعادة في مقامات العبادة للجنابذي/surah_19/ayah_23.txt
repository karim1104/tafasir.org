{ فَأَجَآءَهَا ٱلْمَخَاضُ } اى حركة الولد للطّلق مخضت المرأة كمنع وسمع وعنى مخاضاً بفتح الميم ومخاضاً بكسرها ومخّضت تمخيضاً وتمخّضت اخذها الطّلق { إِلَىٰ جِذْعِ ٱلنَّخْلَةِ } اليابسة التّى اُلهمت ان تأتيها، والجذع ما بين العرق والغصن { قَالَتْ } بعدما ولدت عيسى (ع) ونظرت اليه { يٰلَيْتَنِي مِتُّ } قرئ بكسر الميم وضمّها { قَبْلَ هَـٰذَا } قالت ذلك استحياء ومخافة لومهم { وَكُنتُ نَسْياً } قرئ بكسر النّون وهو اجود اللّغتين وبفتحها وهو فى الاصل مصدر يستعمل فى الشّيء الحقير الّذى من شأنه ان ينسى وفيما يلقى من الشّيء ولا يعتنى به { مَّنسِيّاً } التّوصيف به للمبالغة.
