{ إِنَّ ٱلَّذِينَ آمَنُواْ } اى اسلموا بالبيعة على يد محمّد (ص) فانّ الايمان صار اسماً للاسلام فى بدو الاسلام لكون المسلم مشرفاً على الايمان { وَٱلَّذِينَ هَادُواْ } كانوا على اليهوديّة { وَٱلصَّابِئِينَ } الخارجين عن الدّين وهم الّذين عبدوا الكواكب، وقيل: انّهم يزعمون انّهم على دين نوحٍ (ع) { وَٱلنَّصَارَىٰ وَٱلْمَجُوسَ وَٱلَّذِينَ أَشْرَكُوۤاْ } الاصنام او غيرها بالله { إِنَّ ٱللَّهَ يَفْصِلُ } اى يميّز { بَيْنَهُمْ يَوْمَ ٱلْقِيامَةِ } وان كانوا فى الدّنيا متشابهين غير ممتازين وانّ الثّانية مع مدخولها خبر لانّ الاولى { إِنَّ ٱللَّهَ عَلَىٰ كُلِّ شَيْءٍ شَهِيدٌ } استيناف فى مقام التّعليل.
