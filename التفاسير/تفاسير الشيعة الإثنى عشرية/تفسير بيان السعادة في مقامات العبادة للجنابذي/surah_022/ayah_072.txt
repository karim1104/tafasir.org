{ وَإِذَا تُتْلَىٰ عَلَيْهِمْ آيَاتُنَا } فى ولاية علىّ (ع) { بَيِّنَاتٍ } واضحات او موضحات لولايته { تَعْرِفُ فِي وُجُوهِ ٱلَّذِينَ كَفَرُواْ } بولايته { ٱلْمُنْكَرَ } المنكر من كلّ شيءٍ ما لا يرضاه العقل او العرف { يَكَادُونَ يَسْطُونَ بِٱلَّذِينَ يَتْلُونَ عَلَيْهِمْ آيَاتُنَا } لشدّة غيظهم { قُلْ أَفَأُنَبِّئُكُم بِشَرٍّ مِّن ذٰلِكُمُ } الخبر الشّديد المورث لغيظكم { ٱلنَّارُ } قرئ بالرّفع خبراً لمحذوف او مبتدء خبر ما بعده، وقرئ بالنّصب على الاختصاص وبالجرّ بدلاً من شرٍّ { وَعَدَهَا ٱللَّهُ ٱلَّذِينَ كَفَرُواْ وَبِئْسَ ٱلْمَصِيرُ } نسب الى الكاظم (ع) انّه قال فى قول الله تعالى: { وَإِذَا تُتْلَىٰ عَلَيْهِمْ آيَاتُنَا } (الآية) كان القوم اذا نزلت فى امير المؤمنين (ع) آية فى كتاب الله فيها فرض طاعته او فضيلة فيه او فى اهله سخطوا ذلك وكرهوا حتّى همّوا به وارادوا به وارادوا برسول الله (ص) ايضاً ليله العقبة غيظاً وخنقاً وغضباً وحسداً حتّى نزلت هذه الآية يعنى الآية السّابقة.
