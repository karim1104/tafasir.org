{ يُنَادُونَهُمْ } اى ينادى المنافقون والمنافقات الّذين آمنوا { أَلَمْ نَكُن مَّعَكُمْ } فى الانسانيّة، او فى الاسلام والبيعة العامّة، او فى الايمان والبيعة الخاصّة { قَالُواْ بَلَىٰ } كنتم معنا فى ظاهر الاسلام وفى ظاهر الايمان { وَلَـٰكِنَّكُمْ فَتَنتُمْ } الفتنة اعجابك بالشّيء واذابة الذّهب والفضّة والاضلال والايقاع فى الفتنة { أَنفُسَكُمْ وَتَرَبَّصْتُمْ } بمحمّدٍ (ص) او بالمؤمنين الدّوائر { وَٱرْتَبْتُمْ } فى دينكم وما كنتم فيه معنا { وَغرَّتْكُمُ ٱلأَمَانِيُّ } عن طلب الآخرة والعمل لها { حَتَّىٰ جَآءَ أَمْرُ ٱللَّهِ } بقبض ارواحكم { وَغَرَّكُم بِٱللَّهِ ٱلْغَرُورُ } اى الشّيطان حيث قال انّ الله كريم وزمان التّوبة وسيع.
