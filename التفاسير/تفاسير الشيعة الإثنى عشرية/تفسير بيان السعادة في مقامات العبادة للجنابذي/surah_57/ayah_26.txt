{ وَلَقَدْ أَرْسَلْنَا } عطف على قوله لقد أرسلنا عطف التّفصيل على الاجمال { نُوحاً وَإِبْرَاهِيمَ وَجَعَلْنَا فِي ذُرِّيَّتِهِمَا ٱلنُّبُوَّةَ وَٱلْكِتَابَ } اى الرّسالة { فَمِنْهُمْ مُّهْتَدٍ } فى غاية الاهتداء كالانبياء والاولياء (ع) او فى اواسط الاهتداء كسائر المؤمنين { وَكَثِيرٌ مِّنْهُمْ فَاسِقُونَ } لم يقل فى مقابل منهم مهتد ومنهم فاسق للاشارة الى الغلبة فى جانب الضّلالة.
