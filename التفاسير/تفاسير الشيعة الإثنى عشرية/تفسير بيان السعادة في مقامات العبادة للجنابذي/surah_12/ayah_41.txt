{ يٰصَاحِبَيِ ٱلسِّجْنِ أَمَّآ أَحَدُكُمَا } الّذى يرى أنّه يعصر خمراً { فَيَسْقِي رَبَّهُ خَمْراً } وهو الّذى كان قبل ادخاله السّجن صاحب شرابه { وَأَمَّا ٱلآخَرُ فَيُصْلَبُ فَتَأْكُلُ ٱلطَّيْرُ مِن رَّأْسِهِ } وهو الّذى كان قبل ادخاله السّجن صاحب غذائه، قيل: انّهما ما رأيا شيئاً وامتحناه بذلك، وقيل: انّهما رأيا رؤياهما، وقيل: انّ صاحب الشّراب رأى وكان صادقاً، وصاحب الغذاء ما رأى شيئاً وكذب فى رؤياه وقال بعد ذلك: ما رأيت شيئاً وانّما اردت امتحانك فقال فى جوابه { قُضِيَ ٱلأَمْرُ ٱلَّذِي فِيهِ تَسْتَفْتِيَانِ } رأيتما او ما رأيتما.
