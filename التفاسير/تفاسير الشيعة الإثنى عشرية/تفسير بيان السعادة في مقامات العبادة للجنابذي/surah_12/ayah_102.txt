{ ذَلِكَ } المذكور من قصّة يوسف (ع) واخوته وحزن يعقوب (ع) وامرئة العزيز ومراودتها وسجن يوسف (ع) وسلطنته واجتماعه مع ابويه واخوته { مِنْ أَنْبَآءِ ٱلْغَيْبِ } من انباء ما غاب عنك وعن غيرك { نُوحِيهِ إِلَيْكَ } يا محمّد (ص) { وَمَا كُنتَ لَدَيْهِمْ } لدى اخوة يوسف (ع) { إِذْ أَجْمَعُوۤاْ أَمْرَهُمْ } عزموا على الامر الّذى اتّفقوا عليه { وَهُمْ يَمْكُرُونَ } بالنّسبة الى يعقوب (ع) ويوسف (ع) فليس علم ذلك لك الاّ بالوحى.
