{ رَبِّ قَدْ آتَيْتَنِي مِنَ ٱلْمُلْكِ } ظاهراً وباطناً { وَعَلَّمْتَنِي مِن تَأْوِيلِ ٱلأَحَادِيثِ } بعضاً من تأويلها { فَاطِرَ ٱلسَّمَاوَاتِ وَٱلأَرْضِ أَنتَ وَلِيِّي فِي ٱلدُّنُيَا وَٱلآخِرَةِ } ثمّ طلب حسن العاقبة كما احسن اليه فى الدّنيا فقال { تَوَفَّنِي مُسْلِماً وَأَلْحِقْنِي بِٱلصَّالِحِينَ } الكاملين فى الصّلاح، فى الخبر عاش يعقوب بن اسحاق (ع) مائة واربعين سنة، وعاش يوسف (ع) مائة وعشرين سنة، وفى الخبر: دخل يوسف (ع) السّجن وهو ابن اثنى عشر ومكث فيها ثمانى عشرة سنةً وبقى بعد خروجه ثمانين سنة، وعاش يعقوب (ع) بمصر حولين، وروى غير ذلك اربع وعشرين سنةً.
