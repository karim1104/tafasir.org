{ وَمَا تَسْأَلُهُمْ عَلَيْهِ } اى على التّبليغ او على الاخبار بانباء الغيب او على القرآن { مِنْ أَجْرٍ } حتّى يكون ذلك مانعاً من ايمانهم { إِنْ هُوَ } اى التّبليغ او الاخبار بتلك الانباء او القرآن { إِلاَّ ذِكْرٌ لِّلْعَالَمِينَ وَكَأَيِّن مِّن آيَةٍ فِي ٱلسَّمَاوَاتِ وَٱلأَرْضِ } فى سماوات العالم الكبير والعالم الصّغير وكذا فى اراضيهما { يَمُرُّونَ عَلَيْهَا وَهُمْ عَنْهَا مُعْرِضُونَ } فلا غرو فى اعراضهم عمّا ظهر منك من الآيات وهو تسلية له (ص).
