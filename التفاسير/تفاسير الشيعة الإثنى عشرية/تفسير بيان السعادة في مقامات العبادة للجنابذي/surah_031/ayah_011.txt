{ هَـٰذَا } المذكور من السّماوات والارض والجبال والمواليد { خَلْقُ ٱللَّهِ } اى مخلوق الله { فَأَرُونِي مَاذَا خَلَقَ ٱلَّذِينَ مِن دُونِهِ } حتّى يكونوا مستحقّين للشّراكة معه وللعبادة لهم فانّ الشّريك لا بدّ وان يكون مثل الشّريك الآخر فى شيءٍ من صفاته { بَلِ ٱلظَّالِمُونَ فِي ضَلاَلٍ مُّبِينٍ } التفات من الخطاب الى الغيبة ووضع الظّاهر موضع المضمر توصيفاً لهم بالظّلم فى اشراكهم، وبياناً لعلّة الحكم، ولفظ بل اضراب من تعجيزهم الى التّصريح بضلالهم.
