{ وَلاَ تُصَعِّرْ خَدَّكَ لِلنَّاسِ } لا تمل خدّك عنهم فى المعاشرة معهم ولا تعرض عمّن يكلّمك استخفافاً به، وقيل: المعنى لا تذلّ للنّاس طمعاً فيما عندهم { وَلاَ تَمْشِ فِي ٱلأَرْضِ مَرَحاً } المرح شدّة الفرح اى تكبّر عنهم فرحاً بما عندك { إِنَّ ٱللَّهَ لاَ يُحِبُّ كُلَّ مُخْتَالٍ فَخُورٍ } الاختيال والفخر متقاربا المفهوم فانّهما خصلتان ناشئتان من ملاحظة النّفس وانانيّتها والفرح بها، وملاحظة الغير وتحقيره فى جنب نفسه لكن فى الاختيال ملاحظة النّفس غالبة، وفى الفخر ملاحظة الغير وتحقيره غالبة.
