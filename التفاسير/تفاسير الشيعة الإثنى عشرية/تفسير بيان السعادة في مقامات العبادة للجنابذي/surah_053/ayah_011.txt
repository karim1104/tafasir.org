{ مَا كَذَبَ } قرئ بتخفيف الذّال وتشديدها { ٱلْفُؤَادُ } اى فؤاد محمّدٍ (ص) ولم يضفه اليه لايهام ان ليس فؤادٌ غير فؤاده، وانّ المطلق ينصرف اليه { مَا رَأَىٰ } فى بعض الاخبار انّ محمّداً (ص) رأى ربّه بفؤاده لا بالبصر، وفى بعضٍ: { لَقَدْ رَأَىٰ مِنْ آيَاتِ رَبِّهِ ٱلْكُبْرَىٰ } وآيات الله غير الله، او رأى خلافة علىّ (ع) وعلىّ اكبر الآيات، او رأى جبرئيل على صورته الّتى خلق عليها، ولم يره احد كذلك.
