{ قَدْ خَسِرَ ٱلَّذِينَ قَتَلُوۤاْ أَوْلاَدَهُمْ } تصريح بخسرانهم وضلالهم التّلويح تأكيداً وتفضيحاً، قيل: كانوا يقتلون الاولاد للاصنام ويقتلون بناتهم مخافة العار والسبى والعيلة { سَفَهاً بِغَيْرِ عِلْمٍ } بانّ الله رازق لاولادهم وانّه خالقهم لمصلحة النّظام { وَحَرَّمُواْ مَا رَزَقَهُمُ ٱللَّهُ } من الانعام السّالفة على انفسهم او على غيرهم من النّساء او حرّموا ما رزقهم الله من الاولاد فانّهم نعمة ايضاً رزقهم الله { ٱفْتِرَآءً عَلَى ٱللَّهِ } صرّح هنا بالافتراء تأكيداً لما سلف { قَدْ ضَلُّواْ وَمَا كَانُواْ مُهْتَدِينَ } الى امر الحقّ تعالى وابتغاء رضاه.
