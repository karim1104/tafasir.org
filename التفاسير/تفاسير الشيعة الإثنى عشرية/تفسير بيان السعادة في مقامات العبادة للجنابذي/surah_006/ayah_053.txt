{ وَكَذٰلِكَ } اى مثل ابتلاء اغنياء قومك بفقرائهم { فَتَنَّا بَعْضَهُمْ بِبَعْضٍ لِّيَقُولوۤاْ } حالاً وقالاً اى الّذين لا استحقاق لهم للدّين واردنا ان نصرفهم عنك او عن الولاية { أَهَـٰؤُلاۤءِ مَنَّ ٱللَّهُ عَلَيْهِم مِّن بَيْنِنَآ } استهزاء بهم وتنفّراً عنهم حتّى لا يرغبوا فى الاسلام او فى الولاية ولا يؤذوا صاحب الدّين بتزاحمهم بالاغراض الدّنيوية له، فاللاّم للغاية لا لمحض العاقبة كما قيل { أَلَيْسَ ٱللَّهُ بِأَعْلَمَ بِٱلشَّاكِرِينَ } فما بالك تطردهم وما بالهم يستهزؤن ويطلبون طردهم والله تعالى يذكرهم بالشّكر الّذى هو ابتغاء وجه ربّهم ثمّ بعد نهيه عن طردهم امره بتقريبهم والتّلطّف بهم بالتحيّة عليهم وبشارتهم بالغفران والرّحمة فقال { وَإِذَا جَآءَكَ ٱلَّذِينَ يُؤْمِنُونَ بِآيَاتِنَا }
