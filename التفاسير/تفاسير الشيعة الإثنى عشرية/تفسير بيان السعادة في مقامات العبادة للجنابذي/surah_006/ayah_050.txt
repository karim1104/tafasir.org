{ قُل لاَّ أَقُولُ لَكُمْ عِندِي خَزَآئِنُ ٱللَّهِ } يعنى تنزّل الى مقام البشريّة ودارهم بحسب بشريّتك وأظهر ما هو لازمها حتّى يروك مثلهم فلا ينفروا عنك فقل: ليس عندى خزائن الله فتطالبونى بمال كثيرٍ { وَلاۤ أَعْلَمُ ٱلْغَيْبَ } فتطالبونى بالاخبار المغيبات { وَلاۤ أَقُولُ لَكُمْ إِنِّي مَلَكٌ } فتطالبونى بما يقدر الملك عليه من الصّعود فى السّماء واتيان كتابٍ منه وامثال ذلك { إِنْ أَتَّبِعُ إِلاَّ مَا يُوحَىٰ إِلَيَّ } فى كلّ بابٍ من الاحكام والآيات الّتى يظهرها الله على يدى والاخبار بالمغيبات { قُلْ هَلْ يَسْتَوِي ٱلأَعْمَىٰ } عن النّبوّات وكيفيّتها { وَٱلْبَصِيرُ } بها وبانّ النّبىّ لا يجوز ان يكون غير البشر يجرى عليه كلّ ما يجرى على سائر افراده، الا انّه يعلم بتعليم الله ما لا يعلمه غيره ويوحى اليه ولا يوحى الى غيره { أَفَلاَ تَتَفَكَّرُونَ } فى عدم التّسوية حتّى تخرجوا من ظلمة العمى الى نور البصر.
