{ لاَ يَزَالُ بُنْيَانُهُمُ ٱلَّذِي بَنَوْاْ } يعنى اهل مسجد الضّرار { رِيبَةً فِي قُلُوبِهِمْ } سبب شكٍّ { إِلاَّ أَن تَقَطَّعَ قُلُوبُهُمْ } فلا يبقى منها اثر حتّى تتّصف بالرّيبة { وَٱللَّهُ عَلِيمٌ حَكِيمٌ } يعنى انّ بنيانهم سبب جهلهم وبلاهتهم والله عليمٌ حكيمٌ فيكون بنيانهم سبب بعدهم من الله فليهدم كما روى انّه (ص) امر بهدمه واحراقه.
