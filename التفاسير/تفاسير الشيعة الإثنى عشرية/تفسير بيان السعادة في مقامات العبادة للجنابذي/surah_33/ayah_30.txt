{ يٰنِسَآءَ ٱلنَّبِيِّ } ثمّ قطع مخاطبة النّبىّ (ص) وخاطب ازواجه تفخيماً لشأنهنّ من حيث انّهنّ ازواج النّبىّ (ص) { مَن يَأْتِ مِنكُنَّ بِفَاحِشَةٍ مُّبَيِّنَةٍ } قبحها او ظاهرة على الانظار كالخروج بالسّيف وقد فسّرت فى الاخبار بالخروج بالسّيف وبالخروج على علىّ (ع) تعريضاً بفعلة عائشة { يُضَاعَفْ لَهَا ٱلْعَذَابُ ضِعْفَيْنِ } يعنى فى الآخرة والاّ فعلىّ (ع) احسن اسرها فى الدّنيا بعد ما قاتل وقتل مقاتليها وقال فى حقّها: ولها حرمتها، { وَكَانَ ذَلِكَ } التّضعيف { عَلَى ٱللَّهِ يَسِيراً } ولمّا كان المقام للتّهديد اتى بالتّيسير قبل ذكر تضعيف الاجر للمحسنات منهنّ لّئلاّ يتوهّم انّه لتضعيف الاجر.
