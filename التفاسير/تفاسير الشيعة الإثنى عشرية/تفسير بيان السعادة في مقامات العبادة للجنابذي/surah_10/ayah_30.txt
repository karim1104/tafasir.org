{ هُنَالِكَ } المقام او الزّمان { تَبْلُواْ } تختبر { كُلُّ نَفْسٍ مَّآ أَسْلَفَتْ } فتعرف حقّها عن باطلها او صحيحها عن سقيمها وجيّدها عن مغشوشها لحدّة بصرهم وصفاء ادراكهم فيدركون ايّها صدر عن النّفس الامّارة والشّيطان وايّها صدر عن العقل بشركة النّفس وايّها صدر عن العقل ثمّ طرء عليه اغراض النّفس { وَرُدُّوۤاْ } بعد ما عرفوا اعمالهم { إِلَى ٱللَّهِ مَوْلاَهُمُ ٱلْحَقِّ } التّوصيف بالحقّ تعريض ببطلان معبوداتهم { وَضَلَّ عَنْهُمْ مَّا كَانُواْ يَفْتَرُونَ } من الشّركاء لكونها باطلة.
