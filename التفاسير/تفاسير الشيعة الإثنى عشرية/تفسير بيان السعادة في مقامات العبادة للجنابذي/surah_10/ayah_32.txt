{ فَذَلِكُمُ } الموصوف بما ذكر { ٱللَّهُ رَبُّكُمُ ٱلْحَقُّ } تعريض ببطلان شركاءهم كما مرّ، وفى اعرابه وجوه احسنها ان يكون ذلكم مبتدء والله صفة او بدلاً منه وربّكم خبراً عنه والحقّ صفة له { فَمَاذَا بَعْدَ ٱلْحَقِّ } بعد الانصراف عنه او بعد الحقّيّة { إِلاَّ ٱلضَّلاَلُ فَأَنَّىٰ تُصْرَفُونَ } وليس انصرافكم الاّ الى الضّلال لعدم الواسطة.
