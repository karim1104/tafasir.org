{ قُلْ مَن يَرْزُقُكُم مِّنَ ٱلسَّمَآءِ } بالرّزق الانسانىّ { وَٱلأَرْضِ } بالرّزق الحيوانىّ او بكليهما باعداد كليهما { أَمَّن يَمْلِكُ ٱلسَّمْعَ وٱلأَبْصَارَ } اقتصر على المدارك الجزئيّة المحسوسة ومنها على اشرفها وانفعها للانسان اعنى السّمع والبصر افادة لمملوكيّة غيرها بالطّريق الاولى والمراد بمالكيّته تعالى لها كونها تحت قدرته بحيث لا مدخليّة لاحد غيره فيها فيعطى ويمنع ويأخذ ويبقى ويجعل سليماً ومأوفا وقويّاً وضعيفاً ما يشاء منها لمن يشاء { وَمَن يُخْرِجُ ٱلْحَيَّ مِنَ ٱلْمَيِّتِ وَيُخْرِجُ ٱلْمَيِّتَ مِنَ ٱلْحَيِّ } والمراد باخراج الحىّ اعمّ من اخراج الحيوان من مادّته الميتة وانشاء النّفس الحيّة بالّذات من البدن الميتة واخراجها منه بالموت او بالنّوم واخراج المؤمن الّذى هو حىّ بالحياة الانسانيّة من الكافر الّذى هو ميّت عنها واخراج المثال الصّاعد من عالم الطّبع وهكذا اخراج الميّت من الحىّ { وَمَن يُدَبِّرُ ٱلأَمْرَ } قد مضى تفسير هذه الكلمة فى اوّل السّورة { فَسَيَقُولُونَ ٱللَّهُ } الفاء زائدة والجملة جوابٌ لسؤالٍ مقدّرٍ او الفاء جواب شرط محذوف او خالصة للسبيّة { فَقُلْ أَفَلاَ تَتَّقُونَ } توبيخاً لهم او امراً لهم بالتّقوى بعد اقرارهم يكون الكلّ بقدرته.
