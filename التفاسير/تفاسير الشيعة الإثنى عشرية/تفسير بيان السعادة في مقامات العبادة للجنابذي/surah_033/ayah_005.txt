{ ٱدْعُوهُمْ لآبَآئِهِمْ } بان تقولوا زيد بن حارثة دون غير آبائهم وان كان الغير يدعونهم ابناءهم { هُوَ أَقْسَطُ عِندَ ٱللَّهِ } اعدل من غير شوب ظلمٍ وتجاوز عن الحقّ { فَإِن لَّمْ تَعْلَمُوۤاْ آبَاءَهُمْ فَإِخوَانُكُمْ فِي ٱلدِّينِ } فادعوهم اخواناً { وَمَوَالِيكُمْ } فادعوهم احباباً { وَلَيْسَ عَلَيْكُمْ جُنَاحٌ فِيمَآ أَخْطَأْتُمْ بِهِ } بدعائهم الى غير آبائهم قبل النّهى او بعد النّهى بالنّسيان عن النّهى او بسبق اللّسان { وَلَـٰكِن مَّا تَعَمَّدَتْ قُلُوبُكُمْ } اى فيما تعمّدت قلوبكم او ما تعمّدت قلوبكم مبتدءٌ خبره محذوف { وَكَانَ ٱللَّهُ غَفُوراً رَّحِيماً } يغفر للمخطئ وللمتعمّد بعد التّوبة ويرحمه تفضّلاً منه عليه.
