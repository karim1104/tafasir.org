{ وَلَوْ دُخِلَتْ عَلَيْهِمْ } يعنى لو دخل الاعداء بيوتهم او المدينة غالباً عليهم { مِّنْ أَقْطَارِهَا } من جوانب البيوت او المدينة { ثُمَّ سُئِلُواْ ٱلْفِتْنَةَ } اى الكفر او المقاتلة مع المسلمين { لآتَوْهَا وَمَا تَلَبَّثُواْ بِهَآ } مع الفتنة او فى المدينة او البيوت او ما تلبّثوا فى اعطاء الفتنة او بسبب اعطاء الفتنة لعدم وثوقهم بدينهم { إِلاَّ يَسِيراً } اى الاّ تلبّثاً يسيراً او زماناً يسيراً.
