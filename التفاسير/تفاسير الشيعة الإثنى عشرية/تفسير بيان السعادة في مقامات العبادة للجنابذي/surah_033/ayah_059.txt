{ يٰأَيُّهَا ٱلنَّبِيُّ } ادبٌ آخرُ لنساء النّبىّ (ص) وسائر الامّة { قُل لأَزْوَاجِكَ وَبَنَاتِكَ وَنِسَآءِ ٱلْمُؤْمِنِينَ يُدْنِينَ عَلَيْهِنَّ مِن جَلاَبِيبِهِنَّ } كنّ لا يغطّين وجوههنّ وسائر مواضع زينتهنّ بجلبابهنّ فأمرهنّ الله تعالى بستر الوجوه والصّدور بالجلابيب حتّى يتميّزن عن سائر النّساء بذلك، والجلباب للنّساء ثوبٌ وسيعٌ يلبسنه فوق الثّياب دون الملحفة او هو الملحفة { ذٰلِكَ أَدْنَىٰ أَن يُعْرَفْنَ } بتميّزهنّ من الاماء والقيان وسائر النّساء { فَلاَ يُؤْذَيْنَ } قيل: كان سبب نزولها انّ النّساء كنّ يخرجن الى المسجد ويصلّين خلف رسول الله (ص) فاذا كان باللّيل وخرجن الى صلٰوة المغرب والعشاء الآخرة والغداة يقعد الشّباب لهنّ فى طريقهنّ فيؤذونهنّ ويتعرّضون لهنّ { وَكَانَ ٱللَّهُ غَفُوراً رَّحِيماً } فيغفر تقصيرهنّ فيما سلف ويرحمهنّ بتعليم آداب المعاشرة لهنّ.
