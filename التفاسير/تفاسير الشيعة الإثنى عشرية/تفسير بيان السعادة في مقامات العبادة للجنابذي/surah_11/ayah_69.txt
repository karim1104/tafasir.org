{ وَلَقَدْ جَآءَتْ رُسُلُنَآ } اى الملائكة وكانوا اربعة كما ورد فى الخبر جبرئيل وميكائيل واسرافيل وكرّوبيل { إِبْرَاهِيمَ بِٱلْبُـشْرَىٰ } ببشارة الولد اى اسماعيل من هاجر او اسحاق من سارة باختلاف الاخبار { قَالُواْ سَلاَماً } حيّوه بتلك التّحيّة { قَالَ سَلاَمٌ } اجابهم بابلغ من تحيّتهم حيث عدل عن النّصب الى الرّفع { فَمَا لَبِثَ أَن جَآءَ } اى ما لبث زماناً معتدّاً به الى ان جاء { بِعِجْلٍ حَنِيذٍ } يعنى اسرع فى قراهم وفى طبخه والحنيذ المشوىّ النّضيج، فقال كلوا، فقالوا لا نأكل حتّى تخبرنا ما ثمنه؟ - قال اذا اكلتم فقولوا بسم الله واذا فرغتم فقولوا الحمد لله، فقال جبرئيل لاصحابه حقّ على الله ان يتّخذه خليلاً.
