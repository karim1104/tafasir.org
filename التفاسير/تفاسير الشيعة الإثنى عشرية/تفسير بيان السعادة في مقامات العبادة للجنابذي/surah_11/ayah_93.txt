{ وَيٰقَوْمِ ٱعْمَلُواْ عَلَىٰ مَكَانَتِكُمْ } منزلتكم عن آلهتكم او رزانتكم فى انفسكم وهو تهكّم بهم لكنّه ابرزه فى صورة الانصاف ولذا لم يقيّد قوله { إِنِّي عَامِلٌ } بمكانتى { سَوْفَ تَعْلَمُونَ مَن يَأْتِيهِ عَذَابٌ يُخْزِيهِ وَمَنْ هُوَ كَاذِبٌ } مضى مثله { وَٱرْتَقِبُوۤاْ } نصر آلهتكم وعذابى { إِنِّي مَعَكُمْ رَقِيبٌ } نصر الهىّ وعذابكم.
