{ قَالَ يٰقَوْمِ أَرَأَيْتُمْ إِن كُنتُ عَلَىٰ بَيِّنَةٍ مِّن رَّبِّي } قد مضى بيان البيّنة { وَرَزَقَنِي مِنْهُ رِزْقاً حَسَناً } اشارة الى موائد الولاية فانّها الرّزق الحسن، والجزاء محذوف اى انصرف عن دعواى؟ واخف غير مولاى؟! { وَمَآ أُرِيدُ أَنْ أُخَالِفَكُمْ إِلَىٰ مَآ أَنْهَاكُمْ عَنْهُ } يعنى ليس مطمح نظرى دنياكم حتّى تكّذبونى بمنزلة ما أسألكم عليه مالاً { إِنْ أُرِيدُ إِلاَّ ٱلإِصْلاَحَ مَا ٱسْتَطَعْتُ } لمّا نسب الارادة الى نفسه تبرّى عن استقلاله فقال { وَمَا تَوْفِيقِيۤ إِلاَّ بِٱللَّهِ عَلَيْهِ تَوَكَّلْتُ وَإِلَيْهِ أُنِيبُ } يعنى لا انظر فى فعلى ودعوتى الى نفسى وحولى وقوّتى ولا فى غاية فعلى اى غير ربّى فالآية اشارة الى التّبرّى من حوله ومن النّظر الى غاية سوى مولاه.
