{ إِنَّا بَلَوْنَاهُمْ } اى اهل مكّة بالقحط والجوع { كَمَا بَلَوْنَآ أَصْحَابَ ٱلْجَنَّةِ } المعهودة الّتى كانت مالكوها مستعدّين لان يصرموها فلمّا دخلوها وجدوها بلا ثمرٍ لانّهم لم يستثنوا وكانت تلك الجنّة على تسعة اميالٍ من صنعاء اليمن وكانت يقال لها الرّضوان { إِذْ أَقْسَمُواْ } اى المالكون لها { لَيَصْرِمُنَّهَا مُصْبِحِينَ } وقت الصّباح.
