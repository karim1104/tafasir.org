{ إِن كُلٌّ إِلاَّ كَذَّبَ ٱلرٌّسُلَ } اى رسلهم او جميع الرّسل لانّ تكذيب واحد تكذيب للجميع { فَحَقَّ عِقَابِ وَمَا يَنظُرُ هَـٰؤُلآءِ } تصريح بما عرّض به من عقوبة المنكرين من قريشٍ والمراد بهؤلاء المنكرون من قريشٍ { إِلاَّ صَيْحَةً واحِدَةً } هى الصّيحة عند الموت او عند القيامة يعنى المراد به النّفخة الاولى او الثّانية { مَّا لَهَا مِن فَوَاقٍ } توقّف او رجوع او راحة او افاقة من الغشى ورجوع الى الدّنيا او فتور.
