{ هَـٰذَا فَوْجٌ } جملة حاليّة او مستأنفة على تقدير القول { مُّقْتَحِمٌ مَّعَكُمْ } الاقتحام الدّخول فى الشّدّة بنحو الشّدّة يعنى يقال للرّؤساء او لبنى اميّة: هذا السّواد اى المتبوعون او بنو العبّاس فوج مقتحم معكم { لاَ مَرْحَباً بِهِمْ } جملة حاليّة او وصفيّة او مستأنفة جواباً لسؤالٍ مقدّرٍ او للدّعاء عليهم من كلام الله او من قول الرّؤساء للمتبوعين بتقدير القول { إِنَّهُمْ صَالُواْ ٱلنَّارِ } تعليل وقيل: يقول بنو اميّة: لا مرحباً بهم.
