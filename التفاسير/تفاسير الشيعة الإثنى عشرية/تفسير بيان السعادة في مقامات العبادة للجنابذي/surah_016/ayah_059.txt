{ يَتَوَارَىٰ مِنَ ٱلْقَوْمِ مِن سُوۤءِ مَا بُشِّرَ بِهِ } قائلاً عند نفسه متفكّراً { أَيُمْسِكُهُ عَلَىٰ هُونٍ } وهو ان من امساكه { أَمْ يَدُسُّهُ فِي ٱلتُّرَابِ } ليتخلّص من هوانه { أَلاَ سَآءَ مَا يَحْكُمُونَ } من جعل النّصيب فى رزق الله لغيره وجعل البنات له وجعل الملائكة اناثاً وجعل البنين لانفسهم.
