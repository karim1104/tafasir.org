{ وَلاَ تَشْتَرُواْ بِعَهْدِ ٱللَّهِ } بيعة محمّد (ص) او بيعة علىّ (ع) { ثَمَناً قَلِيلاً } من اعراض الدّنيا واغراضها بان تنكثوا بيعة علىّ (ع) خوفاً من فوت الجاه وطمعاً فى الرّياسة كما كان حال المترئّسين او طمعاً فى جيف الدّنيا كما كان حال المرئوسين { إِنَّمَا عِنْدَ ٱللَّهِ } ممّا ادّخره لعباده الوافين من نعم الجنان { هُوَ خَيْرٌ لَّكُمْ إِن كُنْتُمْ تَعْلَمُونَ } علمتم انّه خير لكم.
