{ ثُمَّ يَوْمَ ٱلْقِيَامَةِ يُخْزِيهِمْ وَيَقُولُ أَيْنَ شُرَكَآئِيَ } من الاصنام والكواكب والاهوية وغيرها او شركاء مظاهرى من الاولياء والاصل علىّ (ع) { ٱلَّذِينَ كُنْتُمْ تُشَاقُّونَ فِيهِمْ } تعاندون المؤمنين ومظاهرى فى حقّهم، او تخالفون الانبياء والاولياء (ع) فى حقّهم { قَالَ ٱلَّذِينَ أُوتُواْ ٱلْعِلْمَ } الانبياء (ع) واوصيائهم او جملة المؤمنين وائمّتهم { إِنَّ ٱلْخِزْيَ ٱلْيَوْمَ وَٱلْسُّوۤءَ عَلَى ٱلْكَافِرِينَ } الخزى الهوان والسّوء العذاب.
