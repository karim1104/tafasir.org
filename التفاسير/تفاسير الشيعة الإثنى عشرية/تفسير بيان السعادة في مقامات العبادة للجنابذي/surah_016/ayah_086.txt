{ وَإِذَا رَأى ٱلَّذِينَ أَشْرَكُواْ شُرَكَآءَهُمْ } من الاصنام والكواكب والشّياطين وخلفاء الجور { قَالُواْ رَبَّنَا هَـٰؤُلآءِ شُرَكَآؤُنَا ٱلَّذِينَ كُنَّا نَدْعُوْا مِن دُونِكَ فَألْقَوْا } اى الشّركاء { إِلَيْهِمُ } الى المشركين { ٱلْقَوْلَ إِنَّكُمْ لَكَاذِبُونَ } فى ادّعاء اشراكنا بل كنتم تعبدون اهواءكم وجعلتم صورة عبادتنا جالبة لمقتضى اهويتكم.
