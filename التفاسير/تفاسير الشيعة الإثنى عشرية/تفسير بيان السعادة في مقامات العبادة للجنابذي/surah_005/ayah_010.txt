{ وَٱلَّذِينَ كَفَرُواْ } ببيعة علىّ (ع) او ببيعة محمّد (ص) { وَكَذَّبُواْ بِآيَاتِنَآ } واصلها علىّ (ع) { أُوْلَـۤئِكَ أَصْحَابُ ٱلْجَحِيمِ } جمع بين الوعد والوعيد كما هو شأنه وللاشارة الى انّ المغفرة والاجر للمؤمن المستقيم مقصودة بالذّات وجزاء المسيء مقضىّ بالعرض غيّر الاسلوب واتى بالجلمة الاسميّة الدّالة على انّ الجزاء لهم كأنّه من لوازم ذواتهم المسيئة.
