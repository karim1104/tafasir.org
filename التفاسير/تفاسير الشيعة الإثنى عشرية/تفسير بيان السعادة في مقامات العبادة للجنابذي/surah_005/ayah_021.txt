{ يَاقَوْمِ ادْخُلُوا الأَرْضَ المُقَدَّسَةَ } يعنى الشّام { الَّتِي كَتَبَ اللَّهُ لَكُمْ } ان تكون مسكناً لكم فخالفوا وحرموا ودخلها أبناء أبنائهم كذا نقل { وَلاَ تَرْتَدُّوا } من طريق الارض المقدّسة الّتى هى الشّام او ارض القلب { عَلَىٰ أَدْبَارِكُمْ فَتَنْقَلِبُوا خَاسِرِينَ } كما قال نبيّنا (ص) لامّته هذه المقالة فى علىٍّ (ع) فأبوا الاّ الارتداد.
