{ مَّا ٱلْمَسِيحُ ٱبْنُ مَرْيَمَ إِلاَّ رَسُولٌ } لا آله كما قال الفرقة الاولى ولا واحد الالهة كما قال الفرقة الثّانية { قَدْ خَلَتْ مِن قَبْلِهِ ٱلرُّسُلُ وَأُمُّهُ صِدِّيقَةٌ } صدقت عن الاعوجاج قولاً وفعلاً وحالاً، وصدّقت بكلمات ربّها وكتبه ورسله والدّليل على انّهما ليسا آلهين انّهما { كَانَا يَأْكُلاَنِ ٱلطَّعَامَ } فيشتركان معكم فى اخسّ احوالكم وهو الاحتياج الى الاكل، وهو كناية عن الاحتياج الى التخلّى ومن كان محتاجاً مبتلى بأخسّ الاحوال لا يصير آلهاً فى ارفع المقام { ٱنْظُرْ كَيْفَ نُبَيِّنُ لَهُمُ ٱلآيَاتِ } يعنى انظر الى بياننا العجيب لآيات القرآن فى بيان حال عيسى (ع) وامّه مناسباً لفهمهم وشأنهم بحيث لا يمكن لهم انكاره، أو انظر الى بياننا لآياتنا الّتى منها عيسى (ع) وامّه (ع) بحيث يدرَكه كلّ احد ولا يبقى له ريب { ثُمَّ ٱنْظُرْ أَنَّىٰ يُؤْفَكُونَ } تخليل ثمّ للتّفاوت بين التّعجّبين يعنى انصرافهم عن الحقّ فى عيسى (ع) وامّه (ع) بعد هذا البيان او بعد ما رأوا منهم وعلموا هذه الحالة الخسيسة اعجب من كلّ عجيب.
