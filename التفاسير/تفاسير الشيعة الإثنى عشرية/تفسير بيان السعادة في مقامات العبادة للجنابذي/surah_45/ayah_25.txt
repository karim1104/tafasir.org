{ وَإِذَا تُتْلَىٰ عَلَيْهِمْ آيَاتُنَا بَيِّنَاتٍ } واضحات الدّلالات او موضحات لصدق الآتى بها وموضحات لحالهم الّتى هم عليها { مَّا كَانَ حُجَّتَهُمْ } فى المعارضة مع الرّسول وفى انكار تلك الآيات { إِلاَّ أَن قَالُواْ ٱئْتُواْ بِآبَآئِنَآ إِن كُنتُمْ صَادِقِينَ } يعنى علّقوا علامة صدقهم على الاتيان بالمحال بحسب العادة.
