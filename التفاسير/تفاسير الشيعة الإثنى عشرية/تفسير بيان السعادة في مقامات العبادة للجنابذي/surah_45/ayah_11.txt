{ هَـٰذَا } اى المذكور من الآيات او القرآن او قرآن ولاية علىٍّ (ع)، او هذا الامر من ولاية علىّ (ع) او الاسلام وقبوله واحكامه { هُدًى } الى الايمان { وَٱلَّذِينَ كَفَرُواْ بِآيَاتِ رَبِّهِمْ } التّكوينيّة الآفاقيّة والانفسيّة وخصوصاً الآيات العظمى الّذين هم خلفاء الله فى الارض والتّدوينيّة { لَهُمْ عَذَابٌ مِّن رِّجْزٍ أَلِيمٌ } الرّجز اشدّ العذاب.
