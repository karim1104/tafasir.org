{ تَنزِيلٌ } اى بل هو تنزيل { مِّن رَّبِّ ٱلْعَالَمِينَ وَلَوْ تَقَوَّلَ } ابتدع { عَلَيْنَا } كذباً { بَعْضَ ٱلأَقَاوِيلِ لأَخَذْنَا مِنْهُ بِٱلْيَمِينِ } لامسكنا من اعضائه بيمينه كما يمسك من اعضاء الجانى المستحقّ للعذاب بيده، وذكر اليمين لانّه اشرف اطرافه فيكون ابلغ فى الدّلالة على الاذلال او لاخذنا منه باليمين للقطع اى قطعناها فانّه حينئذٍ يكون سارقاً فى الدّين، والسّارق يقطع منه اليمين، او لاخذناه بقوّتنا، واستعمال اليمين فى القوّة لظهورها على اليد فى الاغلب، واليمين اقوى الاطراف.
