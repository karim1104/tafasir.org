{ يَقْدُمُ قَوْمَهُ يَوْمَ ٱلْقِيَامَةِ } لانّه كان اصل ضلالتهم فى الدّنيا فهكذا يصير يوم القيامة رئيساً لهم فى الذّهاب الى النّار { فَأَوْرَدَهُمُ ٱلنَّارَ } لانّهم يتّبعونه فى الّذهاب الى النّار والتّأدية بالمضىّ اشعارٌ بتحقّقه تأكيداً { وَبِئْسَ ٱلْوِرْدُ ٱلْمَوْرُودُ وَأُتْبِعُواْ فِي هَـٰذِهِ } الدّنيا او فى هذه الخصلة { لَعْنَةً وَيَوْمَ ٱلْقِيَامَةِ بِئْسَ ٱلرِّفْدُ ٱلْمَرْفُودُ } اى العطاء المعطى رفدهم واستعمال الورد والرّفد وتوصيفهما مبالغة فى الذّمّ وتهكّم بهم.
