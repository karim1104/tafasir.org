{ إِن تَمْسَسْكُمْ حَسَنَةٌ تَسُؤْهُمْ } وجه آخر لردعهم عن موالاتهم { وَإِن تُصِبْكُمْ سَيِّئَةٌ يَفْرَحُواْ بِهَا } وهذه حالة العدوّ وحقّه العداوة لا الموالاة { وَإِن تَصْبِرُواْ } عن موالاتهم مع خوفكم عن ايذائهم وعلى ايذائهم ان آذوكم { وَتَتَّقُواْ } الله فى موالاتهم او تتّقوا عنهم بان تكونوا على حذرٍ منهم حتّى لا يصل اليكم اثر احتيالهم { لاَ يَضُرُّكُمْ كَيْدُهُمْ شَيْئاً } فثقوا بالله ولا تكلوا على موالاتهم فى دفع مضرّاتهم { إِنَّ ٱللَّهَ بِمَا يَعْمَلُونَ مُحِيطٌ } فى موضع التّعليل قرء بالخطاب وبالغيبة.
