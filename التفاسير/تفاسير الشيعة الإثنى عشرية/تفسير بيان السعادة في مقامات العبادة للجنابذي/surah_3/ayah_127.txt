{ لِيَقْطَعَ } متعلّق بقوله { لقد نصركم الله } او بقوله { يمددكم } او بالنّصر فى قوله { وما النّصر الاّ من عند الله } او متعلّق بمحذوف اى جعل هذا النّصر لكم ليقطع { طَرَفاً مِّنَ ٱلَّذِينَ كَفَرُوۤاْ } بالقتل والاسر كما وقع فى بدر { أَوْ يَكْبِتَهُمْ } كبته صرعه واخزاه وصرفه وكسره وردّه بغيظه واذلّه والكلّ مناسب ولفظة او للتّنويع { فَيَنقَلِبُواْ } يرجعوا { خَآئِبِينَ } غير نائلين من آمالهم شيئاً.
