{ لَكِنِ ٱلَّذِينَ ٱتَّقَوْاْ رَبَّهُمْ لَهُمْ جَنَّاتٌ } استدراك ممّا استفيد من قوله { تقلّب الّذين كفروا } فانّه يستفاد منه انّ الكفّار متنعّمون دون المؤمنين فقال لكنّ المؤمنين لهم جنّات { تَجْرِي مِن تَحْتِهَا ٱلأَنْهَارُ خَالِدِينَ فِيهَا } من غير زوال { نُزُلاً } تشريفاً لهم والنّزل ما يعدّ للنّازل من طعام وشراب وصلة مثلاً لان يكون حاضراً عند نزوله { مِّنْ عِندِ ٱللَّهِ وَمَا عِندَ ٱللَّهِ خَيْرٌ لِّلأَبْرَارِ } ممّا يتقلّب فيه الفجّار، وضع الظّاهر موضع المضمر اشارة الى مديحة اخرى لهم.
