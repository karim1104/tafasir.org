{ وَلَئِن سَأَلْتَهُمْ مَّن نَّزَّلَ مِنَ ٱلسَّمَآءِ مَآءً فَأَحْيَا بِهِ ٱلأَرْضَ مِن بَعْدِ مَوْتِهَا } لمّا كان الاسباب القريبة للرّزق بعد السّماوات والارض والشّمس والقمر وامطار الامطار واحياء الارض بانبات النّبات اتى به بعد السّؤال عن السّماوات والارض وتسخير الشّمس والقمر { لَيَقُولُنَّ ٱللَّهُ قُلِ } بعد اقرارهم بذلك { ٱلْحَمْدُ لِلَّهِ } شكراً لانعامه عليك بتبصيرك ذلك، او قل لهم بعد ذلك: جميع الصّفات الّتى يحمد عليها لله فانّ جميع الخيرات المنتشرة المحسوسة الّتى لا يتجاوز مداركهم عنها محصورة فى خلق السّماوات والارض والشّمس والقمر وامطار الامطار وانبات النّبات فهؤلاء لا يجحدون الله وتسبيبه لاسباب الرّزق { بَلْ أَكْثَرُهُمْ لاَ يَعْقِلُونَ } فيتوسّلون بالاسباب وينصرفون عن مسبّبها لعدم تعقّلهم لا لانكارهم.
