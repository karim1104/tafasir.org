{ وَكَذَلِكَ } اى مثل انزال الكتاب اليهم، او مثل انزال الامر بالمجادلة بالّتى هى احسن، او مثل انزال الامر بان تقولوا آمنّا بالّذى انزل اليكم (الى آخر الآية) { أَنزَلْنَآ إِلَيْكَ ٱلْكِتَابَ } اى كتاب النّبوّة او القرآن { فَٱلَّذِينَ آتَيْنَاهُمُ ٱلْكِتَابَ } اى القرآن وهم آل محمّدٍ (ص) او فالّذين آتيناهم احكام النّبوّة بقبول الرّسالة بالبيعة العامّة او بقبول الولاية بالبيعة الخاصّة، او فالّذين آتيناهم الكتاب اى الانتعاش او الاستعداد لامور الآخرة تكويناً { يُؤْمِنُونَ بِهِ } اى يذعنون او يؤمنون بالبيعة العامّة او الخاصّة بالقرآن او بمحمّدٍ (ص) او بكتاب النّبوّة او بعلىٍّ (ع) فانّه المنظور من كلّ منظورٍ { وَمِنْ هَـٰؤُلاۤءِ } يعنى من اهل الكتاب وهم اليهود والنّصارى او من هؤلاء المشركين او من هؤلاء الّذين آتيناهم القرآن وآمنوا به بالبيعة { مَن يُؤْمِنُ بِهِ } اى يؤمن باحدى البيعتين او يذعن قلباً بمحمّدٍ (ص) او بالقرآن او باحكام النّبوّة او بعلىٍّ (ع) { وَمَا يَجْحَدُ بِآيَاتِنَآ } الّتى اعظمها علىّ (ع) { إِلاَّ ٱلْكَافِرونَ } وهذا تعريض بمنافقى الامّة الّذين جحدوا عليّاً (ع).
