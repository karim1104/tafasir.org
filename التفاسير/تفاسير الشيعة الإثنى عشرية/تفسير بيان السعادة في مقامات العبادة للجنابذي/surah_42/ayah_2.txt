{ حـمۤ عۤسۤقۤ كَذَلِكَ } الوحى الّذى اوحينا اليك قبل ذلك من اخبار المغيبات ومن الاحكام والمواعظ { يُوحِيۤ إِلَيْكَ } بعد هذا الزّمان، او كذلك الوحى بالرّمز والحروف المقطّعة الّذى اوحينا اليك قبل ذلك يوحى اليك بعد ذلك، او كذلك الوحى المحفوف باذى القوم وانكارهم الّذى اوحينا اليك يوحى بعد ذلك، او كذلك الوحى باهلاك القوم واسكان الارض يوحى اليك { وَإِلَى ٱلَّذِينَ مِن قَبْلِكَ } اى واوحى الى الّذين من قبلك وأتاه بطريق عطف المفرد للاغتفار فى الثّوانى او لتقدير المعطوف بقرينة المعطوف عليه، وقرئ: يوحى بالبناء للفاعل، وبالبناء للمفعول، واذا كان مبنيّاً للمفعول فقوله تعالى { ٱللَّهُ ٱلْعَزِيزُ ٱلْحَكِيمُ } يكون فاعل فعلٍ محذوفٍ او مبتدءً والجملة مستأنفة فى موضع التّعليل وخبره العزيز او الحكيم او قوله تعالى { لَهُ مَا فِي ٱلسَّمَاوَاتِ وَمَا فِي ٱلأَرْضِ }.
