{ إِنَّمَا ٱلسَّبِيلُ } فى الدّنيا بالمؤاخذة وفى الآخرة بالعقوبة { عَلَى ٱلَّذِينَ يَظْلِمُونَ ٱلنَّاسَ وَيَبْغُونَ فِي ٱلأَرْضِ } فى العالم الصّغير او الكبير { بِغَيْرِ ٱلْحَقِّ } والمنتصر وان كان ظالماً بوجهٍ على المسيء وعلى قوّته العاقلة لكنّه ظلم بالحقّ { أُوْلَـٰئِكَ لَهُمْ عَذَابٌ أَلِيمٌ وَلَمَن صَبَرَ } اى لكن من صبر عن الانتقام { وَغَفَرَ } بتطهير القلب عن الحقد على المسيء { إِنَّ ذَلِكَ لَمِنْ عَزْمِ ٱلأُمُورِ } اى الامور الّتى ينبغى ان يعزم عليها لكونها من اجلّ الخصال.
