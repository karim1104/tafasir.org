{ وَٱلَّذِينَ ٱسْتَجَابُواْ لِرَبِّهِمْ } فى دعوة خلفائه (ع) دعوةً عامّة اسلاميّة او دعوةً خاصّة ايمانيّة، او الّذين استجابوا لربّهم المضاف وهو ربّهم فى الولاية فى دعوته الباطنة الى الولاية { وَأَقَامُواْ ٱلصَّلاَةَ } بعد قبول الولاية فانّ اقامة الصّلاة لا يتيسّر لاحدٍ بدون قبول الولاية { وَأَمْرُهُمْ شُورَىٰ بَيْنَهُمْ } اى امرهم ذو شورى يعنى يستشيرون فى امورهم ولا يستبدّون بآرائهم لخروجهم من انانيّاتهم واعتماد كلٍّ على الآخر فى طلب الخير وبيانه له { وَمِمَّا رَزَقْنَاهُمْ يُنفِقُونَ } قد مضى فى اوّل البقرة بيان اقامة الصّلاة وكيفيّة الانفاق وفى سورة النّساء عند قوله: [النساء: 43] بيان معانى الصّلاة.
