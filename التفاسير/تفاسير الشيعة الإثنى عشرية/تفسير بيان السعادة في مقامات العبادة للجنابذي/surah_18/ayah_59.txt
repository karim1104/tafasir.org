{ وَتِلْكَ ٱلْقُرَىٰ } اى قرى الامم الماضية { أَهْلَكْنَاهُمْ } من قبيل الاستخدام او بتقدير المضاف فى المرجع، او بارادة الاهل من القرى مجازاً { لَمَّا ظَلَمُواْ } انفسهم بالمعاصى والاعراض عن الآيات او ظلموا الآيات بالعناد او الخلق بالصّدّ والمنع من الآيات وهو تعريض بامّة محمّدٍ (ص) وتحذير عن الاعراض عن الآيات وترغيب فى الاقبال عليها وقبول قوله (ص) فى علىٍّ (ع) { وَجَعَلْنَا لِمَهْلِكِهِم } اى لهلاكهم او اهلاكهم على قراءة فتح الميم وضمّه { مَّوْعِداً } لا يتجاوزون عنه فلا تغترّوا يا امّة محمّدٍ (ص) بالامهال وعدم التّعجيل فى المؤاخذة، وفسّر المهلك بنار الآخرة، والموعد بالقيامة.
