{ فَٱنْطَلَقَا } طالبين للسّفينة { حَتَّىٰ إِذَا رَكِبَا فِي ٱلسَّفِينَةِ خَرَقَهَا } تثنية الضّمير مع كونهم ثلاثة لكون يوشع (ع) تابعاً وكونهما مقصودين بالحكاية { قَالَ } موسى (ع) { أَخَرَقْتَهَا لِتُغْرِقَ أَهْلَهَا } استنكر فعله وانكر عليه نسياناً للشّرط الّذى كان بينهما لعظم ما رأى منه فانّه كان ينكر الظّلم ولا يتحمّل مشاهدته { لَقَدْ جِئْتَ شَيْئاً إِمْراً } اى منكراً عجيباً.
