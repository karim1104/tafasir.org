{ قَالَ } بعد تخيير الله تعالى ايّاه مجيباً له بما فيه خروج عن الظّلم وعمل بالعدل كما هو شأن الانبياء (ع) { أَمَّا مَن ظَلَمَ } على نفسه بالاصرار على كفره بعد دعوته او على الغير بعدم قبول السّياسات والخروج من تحت الحدود الالهيّة { فَسَوْفَ نُعَذِّبُهُ } بما يليق بحاله من القتل وقطع الاطراف والاسر والنّهب والاستعباد { ثُمَّ يُرَدُّ إِلَىٰ رَبِّهِ } بعد الموت { فَيُعَذِّبُهُ عَذَاباً نُّكْراً } منكراً لم يعهد مثله.
