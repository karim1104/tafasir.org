{ قَالَ يَاقَوْمِ لَيْسَ بِي ضَلاَلَةٌ } داراهم بنفى معتقدهم ولذا لم يؤكّده مثل تأكيداتهم { وَلَكِنِّي رَسُولٌ مِّن رَّبِّ ٱلْعَالَمِينَ أُبَلِّغُكُمْ رِسَالاَتِ رَبِّي وَأَنصَحُ لَكُمْ } اتى باللاّم اشارة الى خلوص النّصح عن شوب الخديعة { وَأَعْلَمُ مِنَ ٱللَّهِ } يعنى من صفاته وتدبيره او بافاضة الله { مَا لاَ تَعْلَمُونَ } بلّغ اوّلاً رسالته مع تعقيبه بالانذار ولمّا كّذبوه بابداء اعتقاد ضدّ الرّسالة وهو الضّلالة نفى معتقدهم واثبت دعواه مع لازمها الّذى هو التّبليغ، ثمّ عقّبها بما لاينبغى ردّه من النّصح والعلم بما ليس لهم علم به مداراةً معهم واظهاراً للرّأفة بهم.
