{ وَإِذْ تَأَذَّنَ رَبُّكَ } عطف على اذ يعدون او على اذ تأتيهم او على اذ قالت امّة او عطف على اسئلهم بتقدير اذكر او ذكّر وتأذن واذّن من باب التّفعيل واذنه من الثّلاثىّ المجرّد واذن به بمعنى اعلم وكثر استعمال اذن مخفّف العين بمعنى علم واباح ورخّص وجاء تأذّن بمعنى اقسم { لَيَبْعَثَنَّ عَلَيْهِمْ } على العادين يوم السّبت او على اليهود مطلقاً بفعل العادين { إِلَىٰ يَوْمِ ٱلْقِيَامَةِ مَن يَسُومُهُمْ } يكلّفهم { سُوۤءَ ٱلْعَذَابِ } بالقتل والاذلال بالجزية والاجلاء كما فعل بخت نصّر ومن بعده ومحمّد (ص) { إِنَّ رَبَّكَ لَسَرِيعُ ٱلْعِقَابِ } فلا ينبغى الاغترار بحلمه { وَإِنَّهُ لَغَفُورٌ رَّحِيمٌ } لمن ارعوى عن غيّه وتاب اليه.
