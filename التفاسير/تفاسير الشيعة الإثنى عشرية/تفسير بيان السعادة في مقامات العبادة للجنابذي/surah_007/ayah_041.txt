{ لَهُمْ مِّن جَهَنَّمَ مِهَادٌ وَمِن فَوْقِهِمْ غَوَاشٍ } حال او استيناف لبيان حالهم، والغواشى جمع الغاشى بمعنى المغمى، او جمع الغاشية بمعنى الغطاء او الاغماء، وفى لفظ مهادٍ وغواش بمعنى الاستار تهكّم بهم { وَكَذٰلِكَ نَجْزِي ٱلظَّالِمِينَ وَٱلَّذِينَ آمَنُواْ وَعَمِلُواْ ٱلصَّالِحَاتِ } قد مضى مثله، وانّ المراد بالايمان ان كان الاسلام الحاصل بالبيعة النّبويّة وقبول الدّعوة الظّاهرة فالمراد بعمل الصّالحات الايمان الخاصّ الحاصل بالبيعة الولويّة وقبول الدّعوة الباطنة ودخول الايمان فى القلب وتوابعه من الاعمال القلبيّة المستتبعة للاعمال القالبيّة، وان كان المراد به الايمان الخاصّ فالمراد بعمل الصّالحات مستتبعات هذا الايمان، ولمّا جاء بالصّالحات معرّفة بلام الاستغراق واوهم الاتيان بجميع الصّالحات وليس فى وسع افراد البشر الاتيان بجميع الصّالحات استدركه بقوله { لاَ نُكَلِّفُ نَفْساً إِلاَّ وُسْعَهَا } معترضاً بين المبتدء وخبره { أُوْلَـٰئِكَ أَصْحَابُ ٱلْجَنَّةِ هُمْ فِيهَا خَالِدُونَ } تكرار المبتدء باسم الاشارة اوّلاً وبالضّمير ثانياً لتأكيد الحكم واحضار المبتدء بوصفه المذكور وتفخيماً لشأنهم بالاشارة البعيدة وتثبيتاً لهم فى الاذهان بالتّكرار.
