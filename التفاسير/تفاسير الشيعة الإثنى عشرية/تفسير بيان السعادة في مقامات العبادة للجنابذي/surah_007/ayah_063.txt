{ أَوَعَجِبْتُمْ } اى اكذّبتم وعجبتم يعنى لا ينبغى التّعجّب منكم { أَن جَآءَكُمْ ذِكْرٌ مِّن رَّبِّكُمْ } اى ما به تذكّركم للآخرة { عَلَىٰ رَجُلٍ مِّنْكُمْ } ابدل الرّسالة الّتى فيها الشّقاق والعناد بلازمها الّذى فيه صلاحهم وهو تذكّرهم بعواقب امورهم واضافه الى الرّبّ المضاف اليهم حتّى يكون اقرب الى النّصح والقبول، ثمّ عقّبه بغاياتٍ ثلاث مترتّبة منسوبة الى الرّسول والمرسل اليهم والمرسل وفى الكلّ صلاحهم ونفعهم لابداء انّ دعواه الرّسالة ليست الاّ محض نفعهم حتّى يكون ابعد من الشّغب، فقال { لِيُنذِرَكُمْ } عمّا انتم عليه مما ليس فيه الاّ الشّرّ والسّوء { وَلِتَتَّقُواْ } عمّا فيه فسادكم بالتّوجّه والرّغبة فيما فيه صلاحكم { وَلَعَلَّكُمْ تُرْحَمُونَ } من ربّكم وهو حسن العاقبة.
