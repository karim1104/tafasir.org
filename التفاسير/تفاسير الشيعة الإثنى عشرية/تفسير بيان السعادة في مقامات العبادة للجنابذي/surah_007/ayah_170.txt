{ وَٱلَّذِينَ يُمَسِّكُونَ بِٱلْكِتَابِ } اى كتاب النّبوّة الاسلاميّة { وَأَقَامُواْ ٱلصَّلاَةَ } بالبيعة الولويّة { إِنَّا لاَ نُضِيعُ أَجْرَ ٱلْمُصْلِحِينَ } وضع الظّاهر موضع المضمر اشارة الى انّ التّمسّك بالكتاب والولاية مصلح لا محالة فعلى هذا قوله تعالى والدّار الآخرة (الى أخرها) جملة حاليّة والّذين يمسّكون بالكتاب عطف عليه والاحتمالات الاخر فى تركيبها بعيدة عن سوق الكلام.
