{ إِنَّ ٱلَّذِينَ ٱتَّخَذُواْ ٱلْعِجْلَ } معبوداً { سَيَنَالُهُمْ غَضَبٌ مِّن رَّبِّهِمْ } فى الآخرة { وَذِلَّةٌ فِي ٱلْحَياةِ ٱلدُّنْيَا } بقتلهم انفسهم { وَكَذَلِكَ } الجزاء من الغضب والّذلّة { نَجْزِي ٱلْمُفْتَرِينَ } فتنبّهوا يا امّة محمد (ص) ولا تفتروا او لا تأخذوا العجل والسّامرىّ خليفة بعد محمّد (ص) والافتراء اعمّ ممّا وقع قولاً او فعلاً او حالاً او اعتقاداً، ولمّا توهّم انّ المفترى جزاؤه ما ذكر مطلقاً وصار سبباً ليأس اهل المعاصى سيّما على تعميم الافتراء استدركه بقوله { وَٱلَّذِينَ عَمِلُواْ ٱلسَّيِّئَاتِ ثُمَّ تَابُواْ مِن بَعْدِهَا }.
