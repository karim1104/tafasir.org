{ وَإِذ نَتَقْنَا ٱلْجَبَلَ } رفعناه بالقلع { فَوْقَهُمْ كَأَنَّهُ ظُلَّةٌ } سقف يظلّلهم { وَظَنُّوۤاْ أَنَّهُ وَاقِعٌ بِهِمْ } استعمال الظّنّ مع انّهم كانوا متيقّنين لوقوعه لكونه معلّقاً وليس من عادة الاثقال ان تقف معلّقة لانّهم كانوا اصحاب النّفس وليس من صفة النّفس الاّ الظّنّ وان كان متيقنة او لانّهم لمّا علموا انّه كان باعجاز احتملوا ان يقف باعجاز ايضاً ولا يقع عليهم { خُذُواْ مَآ آتَيْنَاكُم بِقُوَّةٍ } على تقدير القول يعنى قائلين خذوا التّوارة واحكامها بقوّة وعزم من قلوبكم وامتثلوا احكامها بقوّة من ابدانكم { وَٱذْكُرُواْ مَا فِيهِ } من العبر والاحكام { لَعَلَّكُمْ تَتَّقُونَ } موبقات النّفس، عن الصّادق (ع) لمّا انزل الله التّوارة على بنى اسرائيل لم يقبلوه فرفع الله عليهم جبل طور سيناء فقال لهم موسى (ع) ان لم تقبلوا وقع عليكم الجبل فقبلوه وطأطأوا رؤسهم وقد مضى فى سورة البقرة.
