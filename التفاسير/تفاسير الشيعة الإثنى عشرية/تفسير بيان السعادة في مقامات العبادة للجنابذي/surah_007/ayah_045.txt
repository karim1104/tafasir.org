{ ٱلَّذِينَ يَصُدُّونَ } اى يعرضون او يمنعون { عَن سَبِيلِ ٱللَّهِ } تفسيراً للظّلم { وَيَبْغُونَهَا عِوَجاً وَهُمْ بِٱلآخِرَةِ كَافِرُونَ } فانّ سبيل الله هو وجهة القلب تكويناً وولاية الامام الّذى هو المتحقّق بتلك الوجهة تكليفاً، والكفر بالآخرة هو الكفر بالولاية التّكوينيّة والتّكليفيّة او مسبّب عنه.
