{ قَالَ فِيهَا } فى ارض العالم الكبير والصّغير { تَحْيَوْنَ } بالحيوة الحيوانيّة او بالحيوة الانسانيّة { وَفِيهَا تَمُوتُونَ } بالموتين { وَمِنْهَا تُخْرَجُونَ } فانّ السعادة والشّقاوة تحصلان فى الدّنيا وفى غلاف الطّبع وليس خروج الانسان وانتقاله الى الجنان او النّيران، الاّ من جهة المادّة والقوّة الّتى هى ارضيّة الدّنيا والطّبع لا من جهة الصّورة وفعليّتها الّتى هى سماويّتها بوجهٍ.
