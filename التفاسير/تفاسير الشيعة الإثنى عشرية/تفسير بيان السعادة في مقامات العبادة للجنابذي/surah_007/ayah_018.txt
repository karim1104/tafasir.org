{ قَالَ ٱخْرُجْ مِنْهَا } من السّماء { مَذْءُوماً } مذموماً { مَّدْحُوراً } مطروداً { لَّمَن تَبِعَكَ مِنْهُمْ } أقسم مقابلة لقسمه وتأكيداً { لأَمْلأَنَّ جَهَنَّمَ مِنكُمْ أَجْمَعِينَ وَيَا آدَمُ } قال يا آدم { ٱسْكُنْ أَنتَ وَزَوْجُكَ ٱلْجَنَّةَ فَكُلاَ مِنْ حَيْثُ شِئْتُمَا وَلاَ تَقْرَبَا هَـٰذِهِ ٱلشَّجَرَةَ فَتَكُونَا مِنَ ٱلظَّالِمِينَ } قد سبق فى سورة البقرة.
