{ وَإِذَا صُرِفَتْ أَبْصَارُهُمْ تِلْقَآءَ أَصْحَابِ ٱلنَّارِ } كان ابصارهم وانظارهم بالاصالة الى اصحاب الجنّة { قَالُواْ } تعوّذاً والتجاءً الى علىّ (ع) { رَبَّنَا لاَ تَجْعَلْنَا مَعَ ٱلْقَوْمِ ٱلظَّالِمِينَ وَنَادَىٰ أَصْحَابُ ٱلأَعْرَافِ } الّذين هم على الاعراف { رِجَالاٍ } من اهل النّار { يَعْرِفُونَهُمْ بِسِيمَاهُمْ قَالُواْ مَآ أَغْنَىٰ عَنكُمْ } يعنى ما اغنى الله عن عذابكم هذا بحسب مفهومه اللّغوىّ والمقصود ما دفع عنكم العذاب { جَمْعُكُمْ وَمَا كُنْتُمْ تَسْتَكْبِرُونَ } ما موصولة او مصدريّة.
