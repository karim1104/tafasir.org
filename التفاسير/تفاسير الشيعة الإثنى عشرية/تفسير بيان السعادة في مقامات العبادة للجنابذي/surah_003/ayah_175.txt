{ إِنَّمَا ذٰلِكُمُ ٱلشَّيْطَانُ } الشّيطان خبر ذلكم او صفته والخبر { يُخَوِّفُ أَوْلِيَاءَهُ } والمراد بالمشار اليه نعيم بن مسعود المثبّط او ابو سفيان او المثبّط من ركب عبد القيس واولياءه مفعول اوّل او مفعول ثانٍ { فَلاَ تَخَافُوهُمْ } اى الشّيطان ومن معه او اولياء الشّيطان { وَخَافُونِ } فانّ الضّرر من كلّ ضارّ لا يصل الى احد الاّ باذنى { إِن كُنتُمْ مُّؤْمِنِينَ } فانّ شأن الايمان والاعتقاد بتوحيد الله ان لا يرجو المؤمن ولا يخاف الاّ الله.
