{ إِذْ قَالَتِ } بدل من قوله { اذ يختصمون } او من قوله { وَإِذْ قَالَتِ ٱلْمَلاَئِكَةُ يٰمَرْيَمُ إِنَّ ٱللَّهَ ٱصْطَفَاكِ } وقوله { وَمَا كُنتَ لَدَيْهِمْ إِذْ يُلْقُون أَقْلاَمَهُمْ أَيُّهُمْ يَكْفُلُ مَرْيَمَ وَمَا كُنْتَ لَدَيْهِمْ إِذْ يَخْتَصِمُونَ } اذ قالت { ٱلْمَلاۤئِكَةُ } تعليل لكون الاخبار فى غيب منه { يٰمَرْيَمُ إِنَّ ٱللَّهَ يُبَشِّرُكِ بِكَلِمَةٍ مِّنْهُ } قد مضى وجه تسمية عيسى (ع) لكلمة الله { ٱسْمُهُ ٱلْمَسِيحُ } وهو بالعربيّة بمعنى المبارك وله معان اخر تناسب التّسمية بها وقيل هو معرّب مشيحا بالسّريانية بمعنى المبارك { عِيسَى ٱبْنُ مَرْيَمَ } خبر بعد خبر او خبر مبتدأ محذوف { وَجِيهاً } حال مقدّرة من كلمة والجاه والوجاهة رفعة المنزلة { فِي ٱلدُّنْيَا وَٱلآخِرَةِ وَمِنَ ٱلْمُقَرَّبِينَ } من الله.
