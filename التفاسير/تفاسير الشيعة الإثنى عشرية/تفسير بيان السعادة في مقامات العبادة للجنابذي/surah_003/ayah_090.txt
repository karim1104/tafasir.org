{ إِنَّ ٱلَّذِينَ كَفَرُواْ } بيان للمرتدّ الفطرىّ { بَعْدَ إِيمَانِهِمْ } العامّ او الخاصّ { ثُمَّ ٱزْدَادُواْ كُفْراً } بحيث يؤدّى الى ابطال الفطرة وقطع حبل الله { لَّن تُقْبَلَ تَوْبَتُهُمْ } الاتيان باداة نفى التّأبيد للاشعار بأنّهم ما بقى لهم استحقاق التّوبة وقبولها لقطع ما به الاستعداد والاستحقاق { وَأُوْلَـٰئِكَ هُمُ ٱلضَّآلُّونَ } يعنى انّ الضّلال على الاطلاق منحصر بمن قطع الفطرة وامّا من لم يقطع الفطرة وان ارتدّ عن الاسلام لم يكن ضالاًّ على الاطلاق لبقاء الهداية التّكوينيّة له.
