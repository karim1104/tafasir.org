{ هَـٰذَا } القرآن بآياته او هذا المذكور من ذكر حال المتّقين ومآلهم وذكر المكذّبين والاشارة الى عاقبتهم الفضيحة، او هذا المذكور من السّنن الماضية من المتّقين والمكذّبين، او السّير فى الارض، او فضيحة عاقبة المكذّبين { بَيَانٌ } اى ظاهر او مظهر او اظهار { لِّلنَّاسِ } عامّة { وَهُدًى } هاد او هداية { وَمَوْعِظَةٌ } واعظ او وعظ { لِّلْمُتَّقِينَ } خاصّة فانّ شرط الهداية والوعظ قبول القابل لانّهما امران اضافيّان.
