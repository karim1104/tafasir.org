{ إِن يَنصُرْكُمُ ٱللَّهُ } جواب لسؤالٍ مقدّرٍ { فَلاَ غَالِبَ لَكُمْ وَإِن يَخْذُلْكُمْ فَمَن ذَا ٱلَّذِي يَنصُرُكُم مِّنْ بَعْدِهِ } اى بعد خذلانه { وَعَلَى ٱللَّهِ فَلْيَتَوَكَّلِ ٱلْمُؤْمِنُونَ } تخلّل الفاء بين العامل والمعمول مع صدارتهما امّا بتقدير امّا او بتوهّمه، او لفظة الفاء فى امثاله زائدة، او العامل محذوف بقرينة المذكور.
