{ ذٰلِكَ } الاخبار باخبار امّ مريم (ع) وزكريّا (ع) ومريم (ع) { مِنْ أَنَبَآءِ ٱلْغَيْبِ } اى من الانباء الّتى كانت فى غيب منك او من انباء الغائبين والغائبات منك { نُوحِيهِ إِلَيكَ } خبر بعد خبر او حال او خبر ابتداء او مستأنف جواب لسؤالٍ مقدّرٍ { وَمَا كُنتَ لَدَيْهِمْ إِذْ يُلْقُون أَقْلاَمَهُمْ أَيُّهُمْ يَكْفُلُ مَرْيَمَ } قد مضى حكاية القرعة فى كفالة مريم { وَمَا كُنْتَ لَدَيْهِمْ إِذْ يَخْتَصِمُونَ } فى كفالة مريم حين لفّتها امّها فى خرقةٍ واتت بها الى الاحبار او حين كبرها وعجز زكريّا عن تربيتها كما قيل، ويجوز ان يراد اذ يختصمون عند ولادة عيسى (ع).
