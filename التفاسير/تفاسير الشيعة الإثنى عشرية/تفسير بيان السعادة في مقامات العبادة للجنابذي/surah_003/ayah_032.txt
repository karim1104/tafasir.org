{ قُلْ أَطِيعُواْ ٱللَّهَ } يعنى بعد ما قلت لهم انّ محبوبيّة الله فى متابعتك بعد محبّة الله قل لهم { أَطِيعُواْ ٱللَّهَ وَٱلرَّسُولَ } لم يكرّر اطيعوا اشعاراً بانّ اطاعة الله تكليفاً ليس الاّ طاعة الرّسول لا انّ طاعة كلّ مستقلة مغايرة لطاعة الآخر { فإِن تَوَلَّوْاْ } لفظ تولّوا هذا مشترك بين المضىّ والمضارعة { فَإِنَّ ٱللَّهَ لاَ يُحِبُّ ٱلْكَافِرِينَ } بطاعة الله وطاعة الرّسول (ص) لانّ المراد به الكفر بالطّاعة هاهنا والمعنى انّه يبغضهم وان كان نفى الحبّ اعمّ من البغض فانّه يستعمل فى امثال المقام فى احد فرديه ووضع الظّاهر موضع المضمر للاشارة الى علّة الحكم والى انّ التولّى عن الطّاعة كفر.
