{ إِن تُصِبْكَ حَسَنَةٌ } غنيمة وغلبة فى تلك الغزوة { تَسُؤْهُمْ } استينافٌ فى موضع التّعليل يعنى انّهم احاط بهم الحسد الّذى هو من آثار السّجّين واشتعال نار الجحيم واحاطته دليل احاطة جهنّم بهم { وَإِن تُصِبْكَ مُصِيبَةٌ } قتل او جرح او انهزام { يَقُولُواْ قَدْ أَخَذْنَا أَمْرَنَا مِن قَبْلُ } اى الامر الّذى هو لائقٌ بنا وبجودة رأينا من التّخلّف عمّا فيه الهلاك والاغترار بما لا حقيقة له من نصرة الله وملائكته { وَيَتَوَلَّواْ } عنك وعن المؤمنين { وَّهُمْ فَرِحُونَ } بما أصابك لاقتضاء الحسد ذلك.
