{ أَلاَ تُقَاتِلُونَ قَوْماً نَّكَثُوۤاْ أَيْمَانَهُمْ } تحريص على القتال وتكرير للحكم بلفظ آخر لاقتضاء مقام الغضب له { وَهَمُّواْ بِإِخْرَاجِ ٱلرَّسُولِ } قبل الايمان فانّ مشركى مكّة قبل المعاهدة والحلف مع الرّسول (ص) همّوا باخراجه عام الهجرة فانّ المشاورة والهمّة باخراجه كانت عام الهجرة قبل الهجرة كما مضى حكاية مشاورتهم فى دار النّدوة والمعاهدة والايمان كانت عام الحديبية وعام فتح مكّة { وَهُم بَدَءُوكُمْ أَوَّلَ مَرَّةٍ } بالمعاداة ومقابلة البادى بالمقاتلة كان جزاء عمله لا تعدّى فيها { أَتَخْشَوْنَهُمْ } لا ينبغى لكم ان تخشوهم مع كونكم مؤمنين بالله مستظهرين به تجرئة لهم { فَٱللَّهُ أَحَقُّ أَن تَخْشَوْهُ إِن كُنتُمْ مُّؤُمِنِينَ } شرط تهييج فانّ ايمانهم العامّ محقّق وهو يقتضى الاستظهار به وعدم الخوف من غيره والخوف من سخطه.
