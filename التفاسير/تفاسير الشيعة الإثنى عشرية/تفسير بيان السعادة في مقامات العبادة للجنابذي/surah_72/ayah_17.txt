{ لِّنَفْتِنَهُمْ فِيهِ } لنختبرهم فى ذلك الماء، او لنعذّبهم بسببه { وَمَن يُعْرِضْ عَن ذِكْرِ رَبِّهِ } اى عن ذكره لربّه او ذكر ربّه له، او عمّا به ذكر ربّه، واصل ما به ذكر الرّبّ علىٌّ (ع) وولايته كما روى عن ابن عبّاس انّه قال: ذكر ربّه ولاية علىّ بن ابى طالب (ع) { يَسْلُكْهُ } اى يدخله { عَذَاباً صَعَداً } صاعداً كلّ العذاب او غالباً وغالباً على المعذّب.
