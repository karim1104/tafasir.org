{ تِلْكَ ٱلدَّارُ ٱلآخِرَةُ } جواب لسؤالٍ ناشٍ من السّابق كأنّه قيل: فمن ينجو من العذاب ومن يدخل الجنّات؟- فقال: تلك الدّار الآخرة { نَجْعَلُهَا } مقرّاً { لِلَّذِينَ لاَ يُرِيدُونَ عُلُوّاً فِي ٱلأَرْضِ } لانّ المستعلى فى الارض منازع لى، والمنازع لى لا يدخل دارى { وَلاَ فَسَاداً } لانّ المفسد موذٍ لعبادى وخلقى { وَٱلْعَاقِبَةُ } الحسنى { لِلْمُتَّقِينَ } من ذلك او لمن كان شيمته التّقوى عن جميع ما ينبغى ان يتّقى منه.
