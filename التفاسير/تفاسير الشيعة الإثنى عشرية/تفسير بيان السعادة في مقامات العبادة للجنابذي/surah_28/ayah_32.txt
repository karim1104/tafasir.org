{ ٱسْلُكْ يَدَكَ فِي جَيْبِكَ تَخْرُجْ بَيْضَآءَ مِنْ غَيْرِ سُوۤءٍ } يعنى من غير علّة البرص فادخلها فى جيبه واخرجها منه فاضاءت له الدّنيا { وَٱضْمُمْ إِلَيْكَ جَنَاحَكَ مِنَ ٱلرَّهْبِ } من اجل الرّهب حتّى يسكن خوفك فانّ وضع اليد والعضد على القلب يعين على سكونه عن اضطرابه { فَذَانِكَ } قرئ بتخفيف النّون وتشديدها { بُرْهَانَانِ } اى احياء العصا وابيضاض اليد ناشئان { مِن رَّبِّكَ } منتهيان { إِلَىٰ فِرْعَوْنَ وَمَلَئِهِ إِنَّهُمْ كَانُواْ قَوْماً فَاسِقِينَ } لمّا استفاد موسى (ع) انّ انتهاء البرهانين الى فرعون وملائه ليس الاّ على يده.
