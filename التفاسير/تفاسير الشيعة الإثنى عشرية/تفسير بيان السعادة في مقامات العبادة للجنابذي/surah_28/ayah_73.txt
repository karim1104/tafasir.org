{ وَمِن رَّحْمَتِهِ جَعَلَ لَكُمُ ٱلْلَّيْلَ وَٱلنَّهَارَ } عطف على ارأيتم ونتيجة لسابقه { لِتَسْكُنُواْ فِيهِ وَلِتَبتَغُواْ مِن فَضْلِهِ } لفّ ونشر مرتّب { وَلَعَلَّكُمْ تَشْكُرُونَ } اى لعلّكم تتنبّهون نعمه العديدة المندرجة فى اختلاف اللّيل والنّهار وانّ فى اختلافهما حيٰوة كلّ ذى حيٰوةٍ وبقاءه ونماء كلّ ذى نماءٍ وكماله، وانّه لولا اختلافهما لما وجد من المواليد شيءٌ فتشكروا تلك النّعم المندرجة فى اختلافهما، وتشكروا نفس تلك النّعمة الّتى هى اللّيل والنّهار.
