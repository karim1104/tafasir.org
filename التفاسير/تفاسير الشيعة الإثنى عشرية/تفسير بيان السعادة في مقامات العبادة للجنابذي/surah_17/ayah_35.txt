{ وَأَوْفُوا ٱلْكَيْلَ } الوفاء والايفاء بمعنىً لكن فى الايفاء مبالغة { إِذا كِلْتُمْ وَزِنُواْ } الموزونات { بِٱلقِسْطَاسِ ٱلْمُسْتَقِيمِ } فسّر القسطاس فى الخبر بالميزان الّذى له كفّتان ولسان { ذٰلِكَ خَيْرٌ } فى الدّنيا بحسن الصّيت والخروج من رذيلة السّرقة والخديعة { وَأَحْسَنُ تَأْوِيلاً } غايةً او ارجاعاً او مرجوعيّةً الى الغايات لانّ غايته فى الدّنيا جلب البركة وفى الآخرة سهولة المحاسبة وحسن المثوبة.
