{ أَمْ أَمِنْتُمْ أَن يُعِيدَكُمْ فِيهِ تَارَةً أُخْرَىٰ } بتسلّط الحرص عليكم حتّى ينسيكم ضرّ البحر { فَيُرْسِلَ عَلَيْكُمْ قَاصِفاً } يقصف اى يكسر كلّ ما هبّ عليه { مِّنَ ٱلرِّيحِ } فتكسر سفينتكم { فَيُغْرِقَكُم بِمَا كَفَرْتُمْ } بكفرانكم نعمة الانجاء اوّلاً { ثُمَّ لاَ تَجِدُواْ } من مدعوّيكم { لَكُمْ عَلَيْنَا بِهِ } اى فى الارسال والاغراق { تَبِيعاً } يتبعنا للانتصار والانجاء.
