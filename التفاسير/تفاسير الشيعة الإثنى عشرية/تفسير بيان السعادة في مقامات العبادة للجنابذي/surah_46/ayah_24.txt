{ فَلَمَّا رَأَوْهُ } رأوا الموعود { عَارِضاً } سحاباً عارضاً فى الافق { مُّسْتَقْبِلَ أَوْدِيَتِهِمْ قَالُواْ هَـٰذَا عَارِضٌ مُّمْطِرُنَا } قال الملائكة او هودٌ او الله { بَلْ هُوَ مَا ٱسْتَعْجَلْتُم بِهِ } من العذاب { رِيحٌ } بدل من ما { فِيهَا عَذَابٌ أَلِيمٌ تُدَمِّرُ } التّدمير المبالغة فى الاهلاك { كُلَّ شَيْءٍ } من الانفس والاموال { بِأَمْرِ رَبِّهَا فَأْصْبَحُواْ لاَ يُرَىٰ إِلاَّ مَسَاكِنُهُمْ } قرئ بالتّاء الفوقانيّة مبنيّاً للفاعل، او المفعول، وبالياء التّحتانيّة مبنيّاً للمفعول، ومساكنهم على حسبه والمعنى لا ترى الاّ سكونهم او محلّ سكناهم { كَذَلِكَ نَجْزِي ٱلْقَوْمَ ٱلْمُجْرِمِينَ } قد مضى قصّتهم فى سورة الاعراف وسورة هودٍ.
