{ يٰقَوْمَنَآ أَجِيبُواْ دَاعِيَ ٱللَّهِ وَآمِنُواْ بِهِ يَغْفِرْ } الله او الدّاعى { لَكُمْ مِّن ذُنُوبِكُمْ وَيُجِرْكُمْ مِّنْ عَذَابٍ أَلِيمٍ وَمَن لاَّ يُجِبْ دَاعِيَ ٱللَّهِ } ابتداء كلام من الله تعالى او جزء كلام النّفر من الجنّ { فَلَيْسَ بِمُعْجِزٍ فِي ٱلأَرْضِ وَلَيْسَ لَهُ مِن دُونِهِ أَوْلِيَآءُ أُوْلَـٰئِكَ فِي ضَلاَلٍ مُّبِينٍ أَوَلَمْ يَرَوْاْ } هذا ايضاً امّا ابتداء كلام من الله او جزء كلام الجنّ { أَنَّ ٱللَّهَ ٱلَّذِي خَلَقَ ٱلسَّمَاوَاتِ وَٱلأَرْضَ وَلَمْ يَعْيَ بِخَلْقِهِنَّ بِقَادِرٍ عَلَىٰ أَن يُحْيِـيَ ٱلْمَوْتَىٰ بَلَىٰ إِنَّهُ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ وَيَوْمَ يُعْرَضُ ٱلَّذِينَ كَفَرُواْ عَلَىٰ ٱلنَّارِ } عطف على اذ صرفنا عطف المفرد، او مقدّر باذكر، او متعلّق بيقال المقدّر، او بقالوا، وعطف نحو عطف الجملة { أَلَيْسَ هَـٰذَا بِٱلْحَقِّ } مقدّرٍ بالقول { قَالُواْ بَلَىٰ وَرَبِّنَا قَالَ فَذُوقُواْ ٱلْعَذَابَ بِمَا كُنتُمْ تَكْفُرُونَ } بالله او بالرّسول او بالآخرة او بالولاية فاذا كان أمر هؤلاء على ما ذكر.
