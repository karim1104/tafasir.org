{ وَلَوْ تَرَىٰ } لو للتّمنّى او للشّرط، واذا كانت للشّرط كان الجزاء محذوفاً اى لرأيت امراً عجيباً والجملة حاليّة بتقدير القول على الاوّل والخطاب عامّ او خاصّ بمحمّد (ص) { إِذِ ٱلْمُجْرِمُونَ نَاكِسُواْ رُءُوسِهِمْ عِندَ رَبِّهِمْ } المضاف يقولون { رَبَّنَآ أَبْصَرْنَا } بعد رجوعنا اليك او فى الدّنيا لكن لم نعمل قالوا ذلك اعترافاً بتقصيرهم { وَسَمِعْنَا } منك وقبلنا او سمعنا فى الدّنيا من انبيائك (ع) لكن لم نعمل { فَٱرْجِعْنَا } الى الدّنيا { نَعْمَلْ صَالِحاً } بعدما رأينا عظمتك وشاهدنا عقوبتك { إِنَّا مُوقِنُونَ } من غير شكٍّ وريبٍ.
