{ وَلَن يُؤَخِّرَ ٱللَّهُ } جملة حاليّة ورفع لتوهّم انّه يجوز التّأخير ام لا { نَفْساً إِذَا جَآءَ أَجَلُهَآ } اذا قدّر مجيء اجلها، عن الباقر (ع) انّ عند الله كتباً موقوفةً يقدّم منها ما يشاء ويؤخّر ما يشاء، فاذا كان ليلة القدر انزل الله فيها كلّ شيءٍ يكون الى مثلها فذلك قوله: { وَلَن يُؤَخِّرَ ٱللَّهُ نَفْساً إِذَا جَآءَ أَجَلُهَآ } اذا انزل الله، وكتبه كتاب السّماوات وهو الّذى لا يؤخّره { وَٱللَّهُ خَبِيرٌ بِمَا تَعْمَلُونَ } تهديدٌ للمنافقين والكافرين، او ردع وزجر للكافر فى القيامة.
