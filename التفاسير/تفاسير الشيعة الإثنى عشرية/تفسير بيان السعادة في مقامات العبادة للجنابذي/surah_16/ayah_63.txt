{ تَٱللَّهِ لَقَدْ أَرْسَلْنَآ إِلَىٰ أُمَمٍ مِّن قَبْلِكَ } كما ارسلتك الى هذه الامّة { فَزَيَّنَ لَهُمُ ٱلشَّيْطَانُ أَعْمَالَهُمْ } كما زيّن لهؤلاء فلا تحزن على ما فعلوا فانّه ليس بامرٍ حادث فى زمانك { فَهُوَ وَلِيُّهُمُ ٱلْيَوْمَ } فالشّيطان ولىّ الامم الماضية فى النّار اليوم او هو ولىّ امّتك اليوم بتزيين السّوء لهم كما كان ولىّ الامم الماضية قبل بذلك { وَلَهُمْ عَذَابٌ أَلِيمٌ } للامم الماضية او لامّتك وعلى اىّ تقديرٍ فهو تهديد لامّته.
