{ وَيَوْمَ نَبْعَثُ فِي كُلِّ أُمَّةٍ شَهِيداً عَلَيْهِمْ مِّنْ أَنْفُسِهِمْ وَجِئْنَا بِكَ شَهِيداً عَلَىٰ هَـٰؤُلآءِ } لمّا كان هذه الآية تأكيداً لسابقتها فصّلها وأجمل الاولى { وَنَزَّلْنَا عَلَيْكَ ٱلْكِتَابَ } كتاب النّبوّة والقرآن صورته واحكام القالب والقلب ايضاً صورته، ولمّا كان النّبوّة مقام الجمع بعد الفرق وتفصيلاً للوحدة الاجماليّة واجمالاً للكثرة كان فيه بيان كلّ شيءٍ وظهوره ولذلك قال { تِبْيَاناً لِّكُلِّ شَيْءٍ وَهُدًى } الى الولاية والايمان القلبىّ الحاصل بالبيعة الخاصّة الولويّة { وَرَحْمَةً } لانّ النّبوّة لكونها صورة الولاية رحمة بكون الولاية رحمة { وَبُشْرَىٰ } بشارة الى مراتب الولاية { لِلْمُسْلِمِينَ } البايعين بالبيعة العامّة او المنقادين المشار اليهم بقوله [ق:37].
