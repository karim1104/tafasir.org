{ وَهُوَ ٱلَّذِي سَخَّرَ ٱلْبَحْرَ لِتَأْكُلُواْ مِنْهُ لَحْماً طَرِيّاً وَتَسْتَخْرِجُواْ مِنْهُ حِلْيَةً تَلْبَسُونَهَا } كأنواع ما يخرج من البحر { وَتَرَى ٱلْفُلْكَ مَوَاخِرَ فِيهِ } جوارى من المخر وهو شقّ الماء او صوت شقّ الماء { وَلِتَبْتَغُواْ مِن فَضْلِهِ } بالتّجارات { وَلَعَلَّكُمْ تَشْكُرُونَ } يعنى غاية الكلّ ان تنظروا الى الانعام وتشكروا حقّ النّعمة برؤيتها من المنعم.
