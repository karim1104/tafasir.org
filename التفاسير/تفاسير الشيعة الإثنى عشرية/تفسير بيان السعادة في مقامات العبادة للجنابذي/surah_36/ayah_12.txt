{ إِنَّا نَحْنُ نُحْيِي ٱلْمَوْتَىٰ } تعليل وتسلية ووعد ووعيد { وَنَكْتُبُ مَاَ قَدَّمُواْ } من الاعمال الّتى لا تبقى بصورها عليهم { وَآثَارَهُمْ } من العلوم والاخلاق وآثار الاعمال الّتى عملوها فبقى آثارها على نفوسهم { وَكُلَّ شيْءٍ } غير المذكورات { أَحْصَيْنَاهُ } اى كتبناه { فِيۤ إِمَامٍ مُّبِينٍ } هو اللّوح المحفوظ، او القلم الاعلى، او الامام الّذى هو بنفسه علم الله بكلّ شيءٍ فانّ الله بكلّ شيءٍ عليم [النور: 36] وتلك البيوت هى ائمّة النّاس.
