{ رَّبُّ ٱلْمَشْرِقِ وَٱلْمَغْرِبِ } التّوصيف للاشعار بوجه الحكم { لاَ إِلَـٰهَ إِلاَّ هُوَ } فاذا كان كذلك { فَٱتَّخِذْهُ وَكِيلاً وَٱصْبِرْ عَلَىٰ مَا يَقُولُونَ } فى الله او فيك او فى ابن عمّك { وَٱهْجُرْهُمْ هَجْراً جَمِيلاً } بان تكون فى الباطن مجانباً مبايناً متباعداً منهم وفى الظّاهر مخالطاً مدارياً بهم.
