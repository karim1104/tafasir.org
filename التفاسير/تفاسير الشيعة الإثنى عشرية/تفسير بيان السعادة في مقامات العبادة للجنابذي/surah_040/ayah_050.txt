{ وَقَالَ ٱلَّذِينَ فِي ٱلنَّارِ لِخَزَنَةِ جَهَنَّمَ ٱدْعُواْ رَبَّكُمْ يُخَفِّفْ عَنَّا يَوْماً مِّنَ ٱلْعَذَابِ قَالُوۤاْ أَوَلَمْ تَكُ تَأْتِيكُمْ رُسُلُكُمْ بِٱلْبَيِّنَاتِ } المعجزات او براهين صدقهم او احكام الرّسالة { قَالُواْ بَلَىٰ قَالُواْ فَٱدْعُواْ } تهكّموا بهم وسخروا منهم ولذلك قالوا { وَمَا دُعَاءُ ٱلْكَافِرِينَ إِلاَّ فِي ضَلاَلٍ } اى فى ضياعٍ، ويحتمل ان يكون هذا من الله.
