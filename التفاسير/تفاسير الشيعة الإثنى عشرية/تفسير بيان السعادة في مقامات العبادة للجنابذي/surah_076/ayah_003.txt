{ إِنَّا هَدَيْنَاهُ ٱلسَّبِيلَ } جوابُ سؤالٍ مقدّرٍ كأنّه قيل: ما فعلت به بعد ذلك؟ وما تفعل به؟ - فقال: انّا هديناه السّبيل بحسب فطرته فانّ الكلّ بحسب الفطرة يعرف الخير والشّرّ الانسانيّين وبحسب التّكليف بتوسّط الانبياء والاولياء (ع) { إِمَّا شَاكِراً } اى عاملاً بما عرفناه { وَإِمَّا كَفُوراً } تاركاً لما عرفناه.
