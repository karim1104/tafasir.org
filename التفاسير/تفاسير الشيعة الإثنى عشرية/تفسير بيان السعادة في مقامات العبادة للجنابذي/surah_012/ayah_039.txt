{ يٰصَاحِبَيِ ٱلسِّجْنِ } الاضافة لأدنى ملابسةٍ سواء كان المراد صحابة يوسف (ع) فى السّجن او صحابة نفس السّجن { أَأَرْبَابٌ } متكثّرون والتّعبير بالارباب تعبير بما اعتقدوه ليكون ادخل فى النّصف { مُّتَّفَرِّقُونَ } غير قاهرين بعضهم لبعض وجمع العقلاء ايضاً لموافقة اعتقادهم { خَيْرٌ } افعل التّفضيل للمداراة والنّصف ايضاً { أَمِ ٱللَّهُ } لم يصرّح بربوبيّته لتسليم الخصم او ادّعاء تسليمه وانّه ممّا لا ينكر { ٱلْوَاحِدُ } مقابل المتكثّرين { ٱلْقَهَّارُ } مقابل المتفرّقين.
