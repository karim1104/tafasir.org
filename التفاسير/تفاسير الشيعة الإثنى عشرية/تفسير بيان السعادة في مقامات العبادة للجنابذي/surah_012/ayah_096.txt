{ قَالُواْ تَٱللَّهِ إِنَّكَ لَفِي ضَلاَلِكَ ٱلْقَدِيمِ فَلَمَّآ أَن جَآءَ ٱلْبَشِيرُ } يهودا ابنه او ابن الجارية الّذى باعه يعقوب (ع) فى صغره { أَلْقَاهُ } اى القميص { عَلَىٰ وَجْهِهِ فَٱرْتَدَّ بَصِيراً } لانتعاش الشّوق والحرارة الغريزيّة { قَالَ أَلَمْ أَقُلْ لَّكُمْ } استفهام تعجّب والمحكىّ محذوف يعنى انّ يوسف حىّ وانّى الاقيه او المحكىّ قوله { إِنِّيۤ أَعْلَمُ مِنَ ٱللَّهِ مَا لاَ تَعْلَمُونَ } وقد نقل مكاتبات يعقوب (ع) وعزيز مصر بعد المجاعة وارتهان واحدٍ من ابنائه واسترقاق بنيامين من غير علمٍ منه بانّ العزيز هو يوسف (ع) وكيفيّة تظلّم يعقوب (ع) الى يوسف (ع) وتأديب الله ايّاه ببثّ شكواه الى غيره تعالى فى المفصّلات.
