{ إِنَّآ أَنْزَلْنَاهُ } اى الكتاب فى صورة الحروف والنّقوش { قُرْآناً } جامعاً لجهتى الوحدة والكثرة والامر والخلق { عَرَبِيّاً } بلغة العرب او عربيّاً ذا علم وفقه لا اعرابيّاً ذا جهل وسبعيّة وبهيميّة { لَّعَلَّكُمْ تَعْقِلُونَ } اى يسهل عليم تعقّله لكونه بلغتكم او تصيرون ذا عقلٍ وفقه لاشتماله على ما يحصل به عقل وفقه.
