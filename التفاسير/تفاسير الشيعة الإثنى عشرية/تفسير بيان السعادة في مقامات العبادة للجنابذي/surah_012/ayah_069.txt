{ وَلَمَّا دَخَلُواْ عَلَىٰ يُوسُفَ آوَىۤ إِلَيْهِ أَخَاهُ } وكيفيّة دخولهم عليه وايوائه ايّاه مذكورة بتفصيلها فى المفصّلات { قَالَ إِنِّيۤ أَنَاْ أَخُوكَ فَلاَ تَبْتَئِسْ } لا تحزن { بِمَا كَانُواْ يَعْمَلُونَ } من الاساءة الىّ واليكم فانّها صارت سبباً لرفعتنا وموجباً لسلطنتنا ويجمع الله بيننا وبين ابينا واخوتنا فى احسن حالٍ.
