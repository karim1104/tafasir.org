{ ٱذْهَبُواْ بِقَمِيصِي هَـٰذَا } وقد ابتلّ القميص بدموعه او كان قميص ابراهيم (ع) الّذى اتى به جبرئيل من الجنّة حين القاء نمرود فى النّار فصارت برداً وسلاماً وقد جعله ابراهيم (ع) تعويذاً لاسحاق (ع) وجعله اسحاق (ع) تعويذاً ليعقوب (ع) وجعله يعقوب (ع) تعويذاً ليوسف (ع) على اختلاف الاخبار { فَأَلْقُوهُ عَلَىٰ وَجْهِ أَبِي يَأْتِ بَصِيراً وَأْتُونِي بِأَهْلِكُمْ أَجْمَعِينَ وَلَمَّا فَصَلَتِ ٱلْعِيرُ } عير اخوة يوسف (ع) الّتى فيها القميص عن مصر { قَالَ أَبُوهُمْ } لمن حضره { إِنِّي لأَجِدُ رِيحَ يُوسُفَ لَوْلاَ أَن تُفَنِّدُونِ } تنسبونى الى الفند والخرافة من الكبر.
