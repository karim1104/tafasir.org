{ فَإِن لَّمْ تَجِدُواْ فِيهَآ أَحَداً فَلاَ تَدْخُلُوهَا } لانّه قد يوجد فى بيوت غيركم ما لا يجوز لكم الاطّلاع عليه وما يكره صاحب البيت اطّلاع الغير عليه { حَتَّىٰ يُؤْذَنَ لَكُمُ وَإِن قِيلَ لَكُمْ ٱرْجِعُواْ فَٱرْجِعُواْ } ولا تلجّوا ولا تكرهوا فانّه قد يكون صاحب البيت بحالٍ لا يجوز للغير الاطّلاع عليه { هُوَ أَزْكَىٰ لَكُمْ } انمى لكم او اصفى او انفع لكم { وَٱللَّهُ بِمَا تَعْمَلُونَ عَلِيمٌ } فان ترجعوا عن طيب نفوسكم يعلمه الله ويجازكم به.
