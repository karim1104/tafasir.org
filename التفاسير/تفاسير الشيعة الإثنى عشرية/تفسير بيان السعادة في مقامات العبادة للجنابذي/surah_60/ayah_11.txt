{ وَإِن فَاتَكُمْ شَيْءٌ } اى واحدة { مِّنْ أَزْوَاجِكُمْ إِلَى ٱلْكُفَّارِ } اى راجعة الى الكفّار { فَعَاقَبْتُمْ } اى فأصبتم من الكفّار عقبى اى غنيمة { فَآتُواْ } ايّها المؤمنون { ٱلَّذِينَ ذَهَبَتْ أَزْوَاجُهُمْ مِّثْلَ مَآ أَنفَقُواْ } من الغنيمة الّتى اصبتم او المعنى فعاقبتم على نساء اخر فأتوا ايّها المؤمنون من بيت مال المسلمين الّذين ذهبت ازواجهم ما أنفقوا، وقيل: عاقبتم الكفّار لسبى النّساء منهم او باخذ الغنيمة او باتيان النّساء منهم اليكم مؤمناتٍ { وَٱتَّقُواْ } ايّها المؤمنون من عدم اعطاء ما أنفقوا { ٱللَّهَ ٱلَّذِيۤ أَنتُمْ بِهِ مُؤْمِنُونَ } قيل: كانت لحق المشركين من نساء المؤمنين ستّ نسوة فأعطى النّبىّ (ص) ازواجهنّ مهورهنّ.
