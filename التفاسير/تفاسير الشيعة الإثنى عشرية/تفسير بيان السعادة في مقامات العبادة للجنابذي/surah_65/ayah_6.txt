{ أَسْكِنُوهُنَّ } اى أسكنوا المطلّقات اللاّتى لا يخرجن من بيوتكم { مِنْ حَيْثُ سَكَنتُم } يعنى لا تجعلوا مساكنهنّ ادون من مساكنكم { مِّن وُجْدِكُمْ } ممّا تجدون لسكناكم { وَلاَ تُضَآرُّوهُنَّ } فى السّكنى او لا تضارّوهنّ من جهةٍ اخرى غير السّكنى { لِتُضَيِّقُواْ عَلَيْهِنَّ } فتلجئوهنّ الى الخروج من مساكنكم { وَإِن كُنَّ أُوْلاَتِ حَمْلٍ فَأَنفِقُواْ عَلَيْهِنَّ حَتَّىٰ يَضَعْنَ حَمْلَهُنَّ } يعنى انّ الرّجعيّات اللاّتى عليهنّ البقاء فى بيت الزّوج لهنّ النّفقة والبائنات لا نفقة لها الاّ ان يكنّ حاملاتٍ فلهنّ النّفقة حتّى يضعن حملهنّ { فَإِنْ أَرْضَعْنَ لَكُمْ } اولادكم بعد وضع الحمل وانقطاع علاقة النّكاح { فَآتُوهُنَّ أُجُورَهُنَّ } على الارضاع لكم { وَأْتَمِرُواْ بَيْنَكُمْ بِمَعْرُوفٍ } يعنى ليأمر بعضكم بعضاً بالمعروف فى الارضاع وفى ايتاء الاجر { وَإِن تَعَاسَرْتُمْ } اى تضايقتم ايّها الآباء عن اتمام الاجرة وايفاء ما هو حقّ الامّهات من الاجور، وايّتها الامّهات من المساهلة فى مقدار الاجرة { فَسَتُرْضِعُ لَهُ أُخْرَىٰ } مرضعةٌ اخرى وهو عتابٌ للآباء على المضائقة فى الاجرة ومقدارها، وللامّهات على المضائقة المزبورة.
