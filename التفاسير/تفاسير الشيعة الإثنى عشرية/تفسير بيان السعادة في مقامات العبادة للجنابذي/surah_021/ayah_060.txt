{ قَالُواْ سَمِعْنَا } يعنى قال بعضهم فى جواب هذا القائل: سمعنا قبل ذلك { فَتًى يَذْكُرُهُمْ } ويعيب فيهم { يُقَالُ لَهُ إِبْرَاهِيمُ قَالُواْ } اى قال القوم للجماعة الّذين قالوا سمعنا فتىً يذكرهم { فَأْتُواْ بِهِ عَلَىٰ أَعْيُنِ ٱلنَّاسِ } فاكشفوه بالاتيان به على اعين جميع النّاس حتّى يعرفوه { لَعَلَّهُمْ يَشْهَدُونَ } بما سمعتم منه او لعلّهم يشهدون على اقراره بان يقرّ بهذا الفعل فشهدوا على اقراره او لعلّهم يحضرون عذابه وعقوبته فجاؤا به وساءلوه.
