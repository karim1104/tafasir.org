{ فَجَعَلَهُمْ جُذَاذاً } الجذاذ بتثليث الجيم اسم من الجذّ بمعنى القطع والاستيصال وقرئ ههنا بالضّمّ والكسر { إِلاَّ كَبِيراً لَّهُمْ } فى الخلقة او فى التّعظيم وعلّق الفاس فى عنقه وخرج { لَعَلَّهُمْ إِلَيْهِ } اى الى ابراهيم او الى الكبير { يَرْجِعُونَ } فيسألون ابراهيم عن حال الاصنام وكسرهنّ ولينبّههم على جهلهم بذلك او يسألون الكبير فيتنبّهون انّه ليس قابلاً للسّؤال فضلاً عن العبادة.
