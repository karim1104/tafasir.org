{ وَجَعَلْنَا فِي ٱلأَرْضِ رَوَاسِيَ } بعد فتقهما { أَن تَمِيدَ بِهِمْ } قد سبق الآية بتنزيلها وتأويلها { وَجَعَلْنَا فِيهَا فِجَاجاً } جمع الفجّ الطّريق الواسع بين الجبلين، او مطلقاً كالفجاج بالضّمّ ويستفاد من تنزيل الآية السّابقة وتأويلها بيان هذه { سُبُلاً } بدلٌ من فجاجاً { لَّعَلَّهُمْ يَهْتَدُونَ } الى معايشهم ومصالحهم ومنافعهم ودفع مضارّهم والى بلادهم الصّوريّة ومواطنهم الحقيقيّة.
