{ مَا يَأْتِيهِمْ مِّن ذِكْرٍ } للحساب { مِّن رَّبِّهِمْ مُّحْدَثٍ } فى باطنهم بزجر الملك الزّاجر ونهى العقل النّاهى والواردات النّفسانيّة من الهموم والغموم والمنامات المنذرة والمبشّرة، وفى الخارج بالواردات الخارجة من الابتلاءات والامتحانات والدّوائر الدّائرة الّتى قلّما يخلوا الانسان منها، وبتذكيرات الانبياء والاولياء (ع) والعلماء رضى الله عنهم من الانذارات والتّبشيرات { إِلاَّ ٱسْتَمَعُوهُ } بآذانهم الباطنة او الظّاهرة { وَهُمْ يَلْعَبُونَ } به بان يجعلوه كالاسمار الّتى لا حقيقة لها او بغيره لعدم الاعتداد به.
