{ وَلَقَدْ آتَيْنَآ إِبْرَاهِيمَ رُشْدَهُ } ما به رشده من الحجج والبراهين او الرّشد الّلائق بحاله من الاهتداء الى كمالاته { مِن قَبْلُ } اى من قبل القرآن او من قبل موسى { وَكُنَّا بِهِ } اى برشده او بابراهيم { عَالِمِينَ إِذْ قَالَ } ظرف لآتينا او لعالمين { لأَبِيهِ وَقَوْمِهِ مَا هَـٰذِهِ ٱلتَّمَاثِيلُ } جمع التّمثال بالكسر وهو الصّورة والاغلب استعماله فيما لا روح له { ٱلَّتِيۤ أَنتُمْ لَهَا عَاكِفُونَ } الّلام بمعنى على او للتّقوية فانّ العكوف يتعدّى بنفسه ويكون بمعنى الحبس، وبعلى ويكون بمعنى الاقبال، ويجوز ان يتضمّن معنى العبادة فيكون الّلام للتّقوية ايضاً.
