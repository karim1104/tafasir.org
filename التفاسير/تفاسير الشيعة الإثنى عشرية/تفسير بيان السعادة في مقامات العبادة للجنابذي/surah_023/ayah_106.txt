{ أَلَمْ تَكُنْ آيَاتِي تُتْلَىٰ عَلَيْكُمْ } جملة مستأنفة بتقدير القول وجواب لسؤالٍ مقدّرٍ كأنّه قيل: ما يقال لهم حينئذٍ؟- فقال: يقال: لتأنيبهم: الم تكن آياتى تتلى عليكم { فَكُنْتُمْ بِهَا تُكَذِّبُونَ قَالُواْ } هذا ايضاً جواب لسؤالٍ مقدّرٍ كأنّه قيل: فما يقولون؟- فقال: يقولون لكنّه عدل الى الماضى لتحقّق وقوعه { رَبَّنَا غَلَبَتْ عَلَيْنَا شِقْوَتُنَا } فلم تدعنا نتّبع آياتك وقادتنا الى تكذيب الآيات وسوء العاقبة { وَكُنَّا قَوْماً ضَآلِّينَ } بحسب الفطرة.
