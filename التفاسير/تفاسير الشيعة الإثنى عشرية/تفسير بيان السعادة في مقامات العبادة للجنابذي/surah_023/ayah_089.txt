{ قُلْ مَن بِيَدِهِ مَلَكُوتُ كُلِّ شَيْءٍ } يعنى من بيده تدبير كلّ شيءٍ والتّصرّف فيه والتّسلّط عليه فانّ الملكوت هو باطن الاشياء المسلّط عليها والمتصرّف فيها باىّ تصرّف شاء { وَهُوَ يُجْيِرُ } اى يغيث { وَلاَ يُجَارُ عَلَيْهِ } يعنى لا احد يغيث مغضوبه { إِن كُنتُمْ تَعْلَمُونَ سَيَقُولُونَ لِلَّهِ } وقرئ بدون الّلام { قُلْ فَأَنَّىٰ تُسْحَرُونَ } اى كيف يخيّل اليكم الحقّ باطلاً مع وضوحه او كيف تعمون عن صحّة الاعادة مع ظهور الادلّة او كيف تخدعون.
