{ إِنَّمَا يَسْتَجِيبُ ٱلَّذِينَ يَسْمَعُونَ } يعنى الّذين يستعدّون للقبول فبقدر سببيّة القابل فى الفعل لهم سببيّة فى ضلالهم وهديهم ولمّا توهّم من انّ المستعدّ يجيب وغير المستعدّ لا يجيب انّه لا ينبغى لغير المستعدّ دعوة ولا امر ولا نهى ولا يلزم عليه ذمّ ولوم فأجاب عنه وقال { وَٱلْمَوْتَىٰ } الّذين لا استعداد لهم والمتوقّفون فى مراقد طبعهم اذا جاهدوا { يَبْعَثُهُمُ ٱللَّهُ } من مراقد طبعهم { ثُمَّ إِلَيْهِ يُرْجَعُونَ } فيسمعون بعد التّوجّه اليه ويجيبون بعد السّماع ليس الموت للموتى حتماً ولا الحيوة للاحياء حتماً.
