{ فَلَمَّا نَسُواْ مَا ذُكِّرُواْ بِهِ } من البأساء والضّرّاء بترك الاتّعاظ بها { فَتَحْنَا عَلَيْهِمْ أَبْوَابَ كُلِّ شَيْءٍ } من المأمولات والمهويّات استدراجاً لهم وامهالاً { حَتَّىٰ إِذَا فَرِحُواْ بِمَآ أُوتُوۤاْ } ممّا يرونهم نعمة { أَخَذْنَاهُمْ بَغْتَةً فَإِذَا هُمْ مُّبْلِسُونَ } الابلاس اليأس والتّحيّر وقيل منه ابليس وقيل انّه اعجمىّ.
