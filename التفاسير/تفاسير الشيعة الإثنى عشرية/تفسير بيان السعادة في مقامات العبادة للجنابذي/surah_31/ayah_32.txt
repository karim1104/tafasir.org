{ وَإِذَا غَشِيَهُمْ مَّوْجٌ } من البحر { كَٱلظُّلَلِ } مرتفعاً فوق رؤسهم { دَعَوُاْ ٱللَّهَ مُخْلِصِينَ لَهُ ٱلدِّينَ } اى طريق الدّعاء او الطّاعة او الطّريق مطلقاً، وقد تكرّر فيما سلف انّه اذا ارتفع مانع الفطرة من الخيال وحيله خلص الانسانيّة لربّه وخلص الطّريق الى الله من الطّرق الشّيطانيّة { فَلَمَّا نَجَّاهُمْ إِلَى ٱلْبَرِّ فَمِنْهُمْ مُّقْتَصِدٌ } اى منهم من يبقى على خلوصه ومنهم من يعود اليه خياله وحيله ويجحد آيات ربّه { وَمَا يَجْحَدُ بِآيَاتِنَآ إِلاَّ كُلُّ خَتَّارٍ } اى غدّار فانّ الختر الغدر او اقبحه والخديعة { كَفُورٍ } كثير السّتر للطّريق اى الولاية وهى طريق القلب الى الله او كفور للنّعم.
