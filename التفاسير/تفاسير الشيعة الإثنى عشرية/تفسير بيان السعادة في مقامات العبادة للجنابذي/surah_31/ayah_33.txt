{ يٰأَيُّهَا ٱلنَّاسُ ٱتَّقُواْ رَبَّكُمْ وَٱخْشَوْاْ يَوْماً لاَّ يَجْزِي وَالِدٌ عَن وَلَدِهِ } قرئ يجزى من الثّلاثىّ المجرّد بمعنى لا يقضى، ومن باب الافعال بمعنى لا يكفى { وَلاَ مَوْلُودٌ هُوَ جَازٍ } اى مولود شأنه ان يكون جازياً عن ابيه وعن اقربائه { عَن وَالِدِهِ شَيْئاً إِنَّ وَعْدَ ٱللَّهِ } باتيان القيامة ونشر الكتاب والحساب والمجازاة فيها { حَقٌّ } لا شوب كذبٍ فيه { فَلاَ تَغُرَّنَّكُمُ ٱلْحَيَاةُ ٱلدُّنْيَا } عن آخرتكم واليوم الموعود لكم حتّى تغفلوا عنه وعن العمل له { وَلاَ يَغُرَّنَّكُم بِٱللَّهِ ٱلْغَرُورُ } اى الشّيطان بأن طوّل آمالكم وارجاكم التّوبة عند الموت واجرأكم على معاصى الله وجمع الدّنيا من الحلّ والحرام.
