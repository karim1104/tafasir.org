{ جَنَّاتُ عَدْنٍ } اقامة { يَدْخُلُونَهَا وَمَنْ صَلَحَ مِنْ آبَائِهِمْ وَأَزْوَاجِهِمْ وَذُرِّيَّاتِهِمْ } بتبعيّتهم فالمراد بالصّلاح ههنا عدم الفساد والاستعداد للصّلاح الحقيقىّ والاّ فلم يكن لهم حاجة الى ان يدخلوها بتبعيّة غيرهم { وَالمَلاَئِكَةُ يَدْخُلُونَ عَلَيْهِمْ مِّن كُلِّ بَابٍ } من ابواب قصورهم فى الجنان قائلين.
