{ وَيُسَبِّحُ ٱلرَّعْدُ بِحَمْدِهِ } وتسبيح كلّ بحسبه وكذا حمده { وَٱلْمَلاَئِكَةُ مِنْ خِيفَتِهِ } واجلاله { وَيُرْسِلُ ٱلصَّوَاعِقَ فَيُصِيبُ بِهَا مَن يَشَآءُ } فيهلكه { وَهُمْ } لغاية جهلهم وعنادهم وعدم تدبّرهم فى تسخّرهم تحت تلك المسخّرات { يُجَادِلُونَ فِي ٱللَّهِ } ومبدئيّته ومرجعيّته وتفرّده بالآلهة واستحقاق العبادة وسائر صفاته { وَهُوَ شَدِيدُ ٱلْمِحَالِ } المماحلة المكائدة، او شديد القوّة من المحل بمعنى القوّة وفسّر بشديد الاخذ وشديد الغضب وهما من لوازم ما ذكر.
