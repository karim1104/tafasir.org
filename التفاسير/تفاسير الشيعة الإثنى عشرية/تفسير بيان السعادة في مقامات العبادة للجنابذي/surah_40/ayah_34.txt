{ وَلَقَدْ جَآءَكُـمْ } عطف او حال فيه معنى التّعليل { يُوسُفُ مِن قَبْلُ بِٱلْبَيِّنَاتِ فَمَا زِلْتُمْ فِي شَكٍّ مِّمَّا جَآءَكُـمْ بِهِ حَتَّىٰ إِذَا هَلَكَ } اقررتم به لارتضائكم بالغائب عن انظاركم دون الحاضر عندكم وجعلتموه خاتم الرّسالة و { قُلْتُمْ لَن يَبْعَثَ ٱللَّهُ مِن بَعْدِهِ رَسُولاً } او المعنى حتّى اذا هلك بقيتم على كفركم وقلتم: لن يبعث الله من بعده رسولاً { كَذَلِكَ } الضّلال الّذى كنتم انتم واسلافكم عليه { يُضِلُّ ٱللَّهُ مَنْ هُوَ مُسْرِفٌ } متجاوزٌ عن حدّه { مُّرْتَابٌ } اى شأنه الارتياب وليس له حالة يقين بما ينبغى ان يتيقّن.
