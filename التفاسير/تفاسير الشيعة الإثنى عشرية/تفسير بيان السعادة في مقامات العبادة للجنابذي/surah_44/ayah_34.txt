{ إِنَّ هَـٰؤُلاَءِ } قريشٌ بعد ذكر قصّة قوم فرعون لتهديد قريش ذكر حال قريش بنحو كونها جواباً لسؤالٍ مقدّرٍ { لَيَقُولُونَ إِنْ هِيَ إِلاَّ مَوْتَتُنَا ٱلأُوْلَىٰ } اى ان الموتة، او ان الفتنة، او ان العاقبة ونهاية الامر الاّ موتتنا الاولى انكاراً للمعاد { وَمَا نَحْنُ بِمُنشَرِينَ } معادين مبعوثين.
