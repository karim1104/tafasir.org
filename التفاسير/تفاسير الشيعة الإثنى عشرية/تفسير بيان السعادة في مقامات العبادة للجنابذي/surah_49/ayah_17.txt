{ يَمُنُّونَ عَلَيْكَ أَنْ أَسْلَمُواْ } منّ عليه منّاً ومنّينى كحلّيفى انعم عليه، ومنّ عليه منّةً عدّ نعمته عليه واعتدّ بها وعظّمها، وهذا هو المراد ههنا فانّهم اعتدّوا باسلامهم نعمةً عليه { قُل لاَّ تَمُنُّواْ عَلَيَّ إِسْلاَمَكُمْ } لانّ الاسلام ليس نعمة لكم ولا لى بل هو مقدّمة للايمان الّذى هو نعمة لكم ولى فقل لهم: لا تعتدّوا باسلامكم ولا تعدّوه نعمة علىّ { بَلِ ٱللَّهُ يَمُنُّ عَلَيْكُمْ } ينعم عليكم او يعدّه نعمةً عليكم { أَنْ هَداكُمْ لِلإِيمَانِ } ان ادخلكم فى الاسلام الّذى هو ما به الهداية الى الايمان الّذى هو نعمة { إِن كُنْتُمْ صَادِقِينَ } فى ادّعاء الاسلام، قال القمّىّ: نزلت الآية فى عثمان يوم الخندق.
