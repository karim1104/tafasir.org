{ يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ } لمّا كانت السّورة المباركة لتأديب الامّة صدّر كلّ حكمٍ منها بالنّداء تلطّفاً بهم وتنشيطاً لهم للاستماع وجبراً لكلفة التّأديب بلذّة الخطاب { لاَ تَرْفَعُوۤاْ أَصْوَاتَكُمْ فَوْقَ صَوْتِ ٱلنَّبِيِّ وَلاَ تَجْهَرُواْ لَهُ بِٱلْقَوْلِ } سواءٌ كان فوق صوته (ص) او لم يكن { كَجَهْرِ بَعْضِكُمْ لِبَعْضٍ أَن تَحْبَطَ } كراهة ان تحبط { أَعْمَالُكُمْ وَأَنتُمْ لاَ تَشْعُرُونَ } فانّ رفع الصّوت عنده تركٌ لتعظيمه او اظهارٌ لتحقيره وكلاهما مورثٌ لحبط العمل، وورد انّ رسول الله (ص) كان اذا رفع احدٌ عنده صوته رفع صوته فوق صوته.
