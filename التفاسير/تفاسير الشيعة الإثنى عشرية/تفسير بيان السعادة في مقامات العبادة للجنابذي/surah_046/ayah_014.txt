{ أُوْلَـٰئِكَ أَصْحَابُ ٱلْجَنَّةِ خَالِدِينَ فِيهَا جَزَآءً بِمَا كَانُواْ يَعْمَلُونَ وَوَصَّيْنَا ٱلإِنسَانَ بِوَالِدَيْهِ إِحْسَاناً } جملة منقطعة عمّا سبق بيان لحال اشخاصٍ او شخصٍ مخصوصٍ لكنّه أتى باداة العطف ايهاماً لاتّصالها بسابقها كأنّه قال: انّ الّذين قالوا ربّنا الله ثمّ استقاموا على ما وصّيناهم وامرناهم ووصّينا الانسان بوالديه احساناً { حَمَلَتْهُ أُمُّهُ كُرْهاً وَوَضَعَتْهُ كُرْهاً وَحَمْلُهُ وَفِصَالُهُ ثَلاَثُونَ شَهْراً } لمّا اراد المبالغة فى التّوصية فى حقّ الامّ ذكر ما تتحمّله الامّ من المشاقّ على الولد { حَتَّىٰ إِذَا بَلَغَ أَشُدَّهُ } قد سبق ذكر الاشدّ فى سورة الانعام وسورة يوسف وغيرهما، وذكر بيانٌ له هناك { وَبَلَغَ أَرْبَعِينَ سَنَةً قَالَ } يعنى ينبغى ان يقول على ان تكون الآية عامّةً او يقول لا محالة على ان يكون الآية خاصّةً بالحسين (ع) كما فى اخبارنا { رَبِّ أَوْزِعْنِيۤ } ألهمنى او أولعنى { أَنْ أَشكُرَ نِعْمَتَكَ ٱلَّتِيۤ أَنْعَمْتَ عَلَيَّ وَعَلَىٰ وَالِدَيَّ } هذه الكلمة تدلّ على انّ الآية خاصّةٌ بالحسين (ع) { وَأَنْ أَعْمَلَ صَالِحاً تَرْضَاهُ وَأَصْلِحْ لِي فِي ذُرِّيَّتِيۤ } ورد فى خبرٍ انّه لو لم يقل فى ذرّيّتى لكانت ذرّيّته كلّهم ائمّةً { إِنِّي تُبْتُ إِلَيْكَ } عمّا يشغلنى عنك { وَإِنِّي مِنَ ٱلْمُسْلِمِينَ } المخلصين او المنقادين.
