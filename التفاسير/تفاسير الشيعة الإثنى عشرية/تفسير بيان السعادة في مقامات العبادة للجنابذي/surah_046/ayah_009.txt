{ قُلْ } لهم لم تستغربون رسالتى وقد كنت مثل سائر الرّسل و { مَا كُنتُ بِدْعاً مِّنَ ٱلرُّسُلِ } اى من بينهم او حالكونى بعضاً منهم وقد كان الرّسل بشراً مثلى وكانوا يأكلون ويشربون وينكحون ويمشون فى الاسواق وقد كانوا يأتون بالاحكام من الله ويدعون الى التّوحيد { وَمَآ أَدْرِي مَا يُفْعَلُ بِي وَلاَ بِكُمْْْ } بحسب اقتضاء بشريّتى فما لكم تطالبونى بعلم الغيب { إِنْ أَتَّبِعُ إِلاَّ مَا يُوحَىٰ إِلَيَّ } لا أتجاوزه الى ما تشتهون او اشتهى { وَمَآ أَنَاْ إِلاَّ نَذِيرٌ } بحسب رسالتى لا شأن لى سوى الانذار وان كنت بحسب ولايتى هادياً لكم وقادراً على ما لا تقتدرون عليه وعالماً بما لا تعلمون { مُّبِينٌ } ظاهر الانذار، وظاهر الصّدق او موضح.
