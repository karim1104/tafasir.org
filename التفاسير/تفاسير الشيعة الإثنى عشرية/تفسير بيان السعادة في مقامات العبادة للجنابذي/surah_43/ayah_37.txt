{ وَإِنَّهُمْ } اى الشّياطين القرناء للعاشين { لَيَصُدُّونَهُمْ } اى العاشين { عَنِ ٱلسَّبِيلِ } الّذى ينبغى ان يسلكه الانسان وهو الولاية التّكوينيّة والتّكليفيّة، ولمّا كان اغلب خطابات القرآن غير خاليةٍ من الاشارة الى الولاية وقبولها وردّها فمعنى الآية انّ من يعش على علىٍّ (ع) وولايته نقيّض له شيطاناً وانّهم يعنى الشّيطان واتباعه ليصدّون العاشين عن علىٍّ (ع) وولايته { وَيَحْسَبُونَ } اى الشّياطين او العاشون او المجموع { أَنَّهُم مُّهْتَدُونَ } والحال انّهم ضالّون مصدودون عن الطّريق.
