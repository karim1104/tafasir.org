{ وَحَسِبُوۤاْ } من تماديهم فى الغفلة والاعراض { أَلاَّ تَكُونَ فِتْنَةٌ } عذاب وابتلاء من الله بسبب هذا التّكذيب والقتل واستصغاراً للّّذنب العظيم { فَعَمُواْ } عن الاعتبار بمن مضى { وَصَمُّواْ } عن استماع حكاياتهم وعن استماع الحقّ { ثُمَّ تَابَ ٱللَّهُ عَلَيْهِمْ } بتوبتهم وقبول نصح الانبياء واوصيائهم { ثُمَّ عَمُواْ وَصَمُّواْ } كرّة اخرى { كَثِيرٌ مِّنْهُمْ } بدل بعض من الكلّ { وَٱللَّهُ بَصِيرٌ بِمَا يَعْمَلُونَ } وقد وقع هذا فى امّة محمّد (ص) والمقصود بالآية التّعريض بهم، فى الكافى عن الصّادق (ع) فى بيان وجه التّعريض وحسبوا ان لا تكون فتنة قال حيث كان النّبىّ (ص) بين اظهرهم فعموا وصمّوا حيث قبض رسول الله (ص) ثم تاب الله عليهم حيث قام امير المؤمنين (ع) ثمّ عموا وصمّوا الى السّاعة، ويمكن بيان التّعريض بوجهٍ آخرٍ وهو ان يقال: حسبوا ان لا تكون فتنة حيث تعاهدوا فى مكّة فعموا وصمّوا عن دلائل صدق محمّد (ص) ثمّ تاب الله عليهم حيث بايعوا عليّاً (ع) بالخلافة ثمّ عموا وصمّوا حيث نقضوا بيعته.
