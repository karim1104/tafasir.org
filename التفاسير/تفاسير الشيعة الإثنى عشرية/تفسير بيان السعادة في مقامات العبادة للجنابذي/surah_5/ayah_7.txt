{ وَٱذْكُرُواْ نِعْمَةَ ٱللَّهِ عَلَيْكُمْ } عطف على تيمّموا يعنى حين تطهّركم تذكّروا محمّداً (ص) او الاسلام الّذى هو البيعة مع محمّد (ص)، او الاسلام الحاصل بالبيعة مع محمّدٍ (ص) حتّى يكون شروطها فى ذكركم من عدم المخالفة واتّباع قوله فى كلّ ما يأمر وينهى، هذا ان كان المراد بالميثاق الميثاق الّذى أخذ عليهم بغدير خمٍّ، وان كان المراد بالميثاق المبايعة مع محمّدٍ (ص) فالمراد بالنّعمة هو الاسلام الحاصل بالبيعة، او محمّد (ص) فانّه اصل نعمة الاسلام كما انّ علياً (ع) اصل نعمة الايمان { وَمِيثَاقَهُ ٱلَّذِي وَاثَقَكُم بِهِ } عاهدكم عهداً وثيقاً به لعلىّ (ع) فى غدير خمّ حتّى لا تنسوه فتخالفوا عليّاً (ع) او عهداً وثيقاً بان لا تخالفوا قوله حتّى لا تنسوه فتخالفوا قوله فى علىّ (ع) والاوّل هو المروىّ { إِذْ قُلْتُمْ سَمِعْنَا } قولك فى علىٍّ (ع) على الاوّل، او شرطك علينا بعدم المخالفة على الثّانى { وَأَطَعْنَا } عليّاً (ع) او اطعناك { وَٱتَّقُواْ ٱللَّهَ } فى نسيان نعمته ونقض ميثاقه بالمخالفة لعلىّ (ع) { إِنَّ ٱللَّهَ عَلِيمٌ بِذَاتِ ٱلصُّدُورِ } فيعلم نيّاتكم واغراضكم فكيف بأفعالكم.
