{ وَلَوْ كَانُوا يُؤْمِنُونَ بِالله والنَّبِيِّ } الحاضر اعنى محمّداً (ص) على ان يكون بيان حال الامّة او نبيّهم على ان يكون بيان حال اهل الكتاب لكنّ الاوّل اولى لافراده { وَمَا أُنْزِلَ إِلَيْهِ } يعنى فى علىّ (ع) او مطلقاً والمقصود ما انزل فى علىّ (ع) { مَا اتَّخَذُوهُمْ أَوْلِيَآءَ } لمجانبة الايمان للكفر والتّولّى يقتضى المجانسة { وَلَـٰكِنَّ كَثِيراً مِّنْهُمْ فَاسِقُونَ } خارجون عن الحق الّذى هو الايمان.
