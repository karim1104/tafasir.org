{ يٰعِبَادِ } الّذين آمنوا بالولاية فانّه لا يصير الانسان عبداً لله تكليفاً الاّ بعد قبول الولاية ولذلك بيّنهم بقوله [الزخرف: 69] (الى آخر الآية) { لاَ خَوْفٌ عَلَيْكُمُ ٱلْيَوْمَ } فانّ شدّته لمن كان معرضاً عن صاحب ذلك اليوم وهو علىّ (ع) { وَلاَ أَنتُمْ تَحْزَنُونَ } وقد مضى اوّل البقرة وفى غيرها بيانٌ لاختلاف الفقرتين من هذه العبارة.
