{ أَفَنَضْرِبُ } الهمزة على التّقديم والتّأخير والمعنى جعلناه قرآناً عربيّاً لتعقّلكم واستكمالكم فهل نضرب { عَنكُمُ ٱلذِّكْرَ صَفْحاً } اى اعراضاً ونصرفه الى غيركم، او المستفهم عنه مقدّر بعد الهمزة والمعنى انهملكم ولا ندعوكم فنصرف عنكم القرآن { أَن كُنتُمْ قَوْماً مُّسْرِفِينَ } قرئ بفتح الهمزة بتقدير اللاّم وبكسر الهمزة.
