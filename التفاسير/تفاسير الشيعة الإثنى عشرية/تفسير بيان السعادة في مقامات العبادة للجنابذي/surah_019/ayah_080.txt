{ كَلاَّ سَنَكْتُبُ مَا يَقُولُ } لنجزيه عليه فانّه افتراء واستهزاء { وَنَمُدُّ لَهُ } عوض ما تصوّره من المال والولد { مِنَ ٱلْعَذَابِ مَدّاً وَنَرِثُهُ مَا يَقُولُ } يعنى المال والولد الّذى يدّعى انّه يؤتى فى الآخرة منهما بان نهلكه ونأخذ ما كان له فى الدّنيا من المال والولد { وَيَأْتِينَا } يوم القيامة { فَرْداً } ممّا له فى الدّنيا فلا يكون له ما كان له فى الدّنيا ولا يحصل له ما يدّعيه فى الآخرة.
