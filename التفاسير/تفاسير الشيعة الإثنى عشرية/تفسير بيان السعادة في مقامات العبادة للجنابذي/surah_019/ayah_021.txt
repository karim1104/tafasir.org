{ قَالَ كَذٰلِكَ قَالَ رَبُّكِ هُوَ عَلَيَّ هَيِّنٌ } قد مضى نظيره { وَلِنَجْعَلَهُ } عطف على مقدّر او متعلّق بمعطوف مقدّر اى نفعل ذلك لنجعله { آيَةً } دالّةً على آلهتنا وعلى سعة علمنا وقدرتنا على ما لا يقدر عليه احد من الايلاد من غير والدٍ ومن احياء الموتى وابراء الاكمه والابرص ونفخ الرّوح فى الطّين وجعله حيّاً { لِّلْنَّاسِ وَرَحْمَةً مِّنَّا } عليهم { وَكَانَ أَمْراً مَّقْضِيّاً } محتوماً.
