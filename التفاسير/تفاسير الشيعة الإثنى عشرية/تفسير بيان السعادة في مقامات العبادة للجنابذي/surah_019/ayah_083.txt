{ أَلَمْ تَرَ } برؤيتك الباطنيّة { أَنَّآ } لا غيرنا { أَرْسَلْنَا ٱلشَّيَاطِينَ عَلَى ٱلْكَافِرِينَ } فاذا ترى انّا ارسلنا الشّياطين فما لك تتحسّر او تعجّل بالعذاب { تَؤُزُّهُمْ أَزّاً } ازّت القدر من باب نصر وضرب اشتدّ غليانها، وازّت السّحابة صوّتت من بعيدٍ، وازّ النّار اوقدها، والشّىء حرّكه شديداً، والازّ ضربان العروق؛ فاذا ترى انّا ارسلنا الشّياطين عليهم.
