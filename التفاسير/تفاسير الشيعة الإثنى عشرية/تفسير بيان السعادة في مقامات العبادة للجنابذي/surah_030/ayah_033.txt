{ وَإِذَا مَسَّ ٱلنَّاسَ ضُرٌّ دَعَوْاْ رَبَّهُمْ مُّنِيبِينَ إِلَيْهِ } لما يرتفع حينئذٍ حجاب النّفس ومانع الرّجوع والسّلوك الى الله { ثُمَّ إِذَآ أَذَاقَهُمْ مِّنْهُ رَحْمَةً } نعمةً بعد الخلاص من ذلك الضّرّ { إِذَا فَرِيقٌ مِّنْهُمْ } لا كلّهم لانّ بعضهم لا يغلب عليهم الواهمة ولا تمنعهم من شكر النّعمة كما كانوا حال الضّرّ لا يمنعهم الواهمة عن الالتجاء ودعاء كشف الضّرّ { بِرَبِّهِمْ يُشْرِكُونَ } بربّهم المطلق يسوّون الاصنام والكواكب والاهوية، او بربّهم المضاف يسوّون غير ولىّ امرهم.
