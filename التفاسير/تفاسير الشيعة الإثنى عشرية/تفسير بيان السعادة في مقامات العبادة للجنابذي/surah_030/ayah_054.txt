{ ٱللَّهُ ٱلَّذِي خَلَقَكُمْ } مستأنف فى مقام الامتنان واظهار الآيات كأنّه قال الله لا غيره الّذى خلقكم { مِّن ضَعْفٍ } وهذا من جملة آياته فما لكم تصرفون عنه الى غيره يعنى خلقكم من مادّةٍ ضعيفةٍ فاذا انتم اقوياء خصماء، او جعل الضّعف بمنزلة مادّته مبالغة فى ضعف مادّته، وقرئ فى الكلّ بضمّ الضّاد وفتحها والمعنى واحدٌ { ثُمَّ جَعَلَ مِن بَعْدِ ضَعْفٍ قُوَّةٍ ثُمَّ جَعَلَ مِن بَعْدِ قُوَّةٍ ضَعْفاً } فى سنّ الكهولة { وَشَيْبَةً } فى سنّ الهرم او كليهما فى سنّ الهرم { يَخْلُقُ مَا يَشَآءُ } من ضعف وقوّةٍ وشيبةٍ وشبيبةٍ وليس خلقه ما يشاء غير منوطٍ بحكمة فانّه لا يشاء الاّ ما هو الاصلح بحال خلقه { وَهُوَ ٱلْعَلِيمُ } بخلقه وما فيه صلاحهم { ٱلْقَدِيرُ } على ما يشاء فلا يشاء الاّ ما يعلم انّ فيه صلاحهم.
