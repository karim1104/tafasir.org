{ وَٱلَّذِينَ يَنقُضُونَ عَهْدَ ٱللَّهِ مِن بَعْدِ مِيثَاقِهِ } اى عهد النّبوّة من بعد ميثاقه وتأكّده بعهد الولاية فانّه مرتدٌّ فطرىّ لا يقبل له توبة لا ظاهراً ولا باطناً، وامّا النّاقض لعهد النّبوّة والبيعة العامّة فانّه يقبل توبته ظاهراً وباطناً وهو مرتدٌّ ملّىّ لا فطرىّ وقد مضى تحقيقٌ وافٍٍ للاتردادين فى سورة آل عمران عند قوله: [آل عمران: 85] { وَيَقْطَعُونَ مَآ أَمَرَ ٱللَّهُ بِهِ أَن يُوصَلَ } ويحصل اصل القطع بنقض العهد كما سبق { وَيُفْسِدُونَ فِي ٱلأَرْضِ } ارض العالم الكبير والعالم الصّغير وقد مضى فى سورة البقرة تحقيق تامّ لقطع ما امر الله به ان يوصل وللافساد فى الارض عند قوله ويقطعون ما أمر الله به ان يوصل { أُوْلَـٰئِكَ لَهُمُ ٱللَّعْنَةُ وَلَهُمْ سُوۤءُ ٱلدَّارِ ٱللَّهُ يَبْسُطُ ٱلرِّزْقَ } النّباتّى والحيوانّى والانسانّى { لِمَنْ يَشَآءُ وَيَقَدِرُ وَفَرِحُواْ بِٱلْحَيَاةِ ٱلدُّنْيَا وَمَا ٱلْحَيَاةُ ٱلدُّنْيَا فِي ٱلآخِرَةِ } فى جنب الآخرة او بين الحياة الآخرة { إِلاَّ مَتَاعٌ } الاّ شيءٌ قليل يتمتّع به يسيراً.
