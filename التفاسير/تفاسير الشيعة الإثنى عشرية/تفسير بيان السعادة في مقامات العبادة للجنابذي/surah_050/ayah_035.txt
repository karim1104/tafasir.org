{ ٱدْخُلُوهَا } خبر لمن خشى، او حال، او مستأنف والكلّ بتقدير القول { بِسَلاَمٍ } من كلّ آفةٍ { ذَلِكَ يَوْمُ ٱلُخُلُودِ لَهُم مَّا يَشَآءُونَ فِيهَا } متعلّق بيشاؤن او بلهم { وَلَدَيْنَا مَزِيدٌ } فانّ لدينا ما لا يخطر ببالهم حتّى يشاؤها ثمّ عطف على عقوبة الكفّار تهديداً لهم وقال: { وَكَمْ أَهْلَكْنَا قَبْلَهُمْ }.
