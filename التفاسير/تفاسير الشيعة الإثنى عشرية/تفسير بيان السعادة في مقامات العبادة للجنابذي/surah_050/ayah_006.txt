{ أَ } لم يخرجوا من حدود انفسهم فلم يقوموا من نكسهم { فَلَمْ يَنظُرُوۤاْ إِلَى ٱلسَّمَآءِ فَوْقَهُمْ كَيْفَ بَنَيْنَاهَا } بحيث لا يمكن بقاء مواليد الارض بدون هذا البناء { وَزَيَّنَّاهَا } بالكواكب بحيث يتّصل اثرها الى الارض ومواليدها ولولا آثار تلك الكواكب لما امكن بقاؤها { وَمَا لَهَا مِن فُرُوجٍ } بحسب الصّورة يعنى ليس بناؤها مثل بناء البانين من البشر لا يمكن لهم ان يبنوا بلا فروجٍ وما لها خلل ونقص فى خلقتها حتّى يمكن لاحدٍ ان يقول: لو كان كذا لكان اولى.
