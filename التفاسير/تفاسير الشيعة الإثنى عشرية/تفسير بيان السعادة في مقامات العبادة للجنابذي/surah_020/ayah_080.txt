{ يٰبَنِي إِسْرَائِيلَ } مربوطٌ بسابقه جواب لسؤالٍ مقدّرٍ بتقدير القول وحكاية لما قاله تعالى لهم بعد انجائهم كأنّه قيل: فما فعل بهم بعد غرق فرعون وقومه؟ وما قال الله تعالى لهم؟- فقال: قال لهم: يا بنى اسرائيل، او منقطع عن سابقه واستيناف وخطاب منه تعالى للحاضرين منهم فى زمان الرّسول (ص) { قَدْ أَنجَيْنَاكُمْ مِّنْ عَدُوِّكُمْ } باغراق فرعون { وَوَاعَدْنَاكُمْ جَانِبَ ٱلطُّورِ ٱلأَيْمَنَ } لمناجاة موسى (ع) وانزال التّوراة فانّه تعالى اخبر موسى (ع) ووعده التّوراة فى بيان شرائعهم واحكامهم ووعد موسى (ع) قومه فعدّ تعالى وعد موسى (ع) وعدهم، او المقصود واعدنا جانب الطّور الّذى هو الصّدر المنشرح بالاسلام جانبه الايمن الّذى يلى القلب بشرط وفائكم بشروط عهدكم وميثاق بيعتكم { وَنَزَّلْنَا عَلَيْكُمُ ٱلْمَنَّ وَٱلسَّلْوَىٰ } فى التّيه وقد مضى هذه بالتّفصيل فى اوّل البقرة، وقرئ الافعال الثّلاثة بالمتكلّم وحده قائلين.
