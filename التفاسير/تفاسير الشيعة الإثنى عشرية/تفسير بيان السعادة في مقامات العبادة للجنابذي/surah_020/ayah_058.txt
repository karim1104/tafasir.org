{ قَالَ أَجِئْتَنَا لِتُخْرِجَنَا مِنْ أَرْضِنَا بِسِحْرِكَ } فانّه حمل الآيات على السّحر مثل خوارق العادات الّتى كان السّحرة يأتون بها { يٰمُوسَىٰ فَلَنَأْتِيَنَّكَ بِسِحْرٍ مِّثْلِهِ فَٱجْعَلْ بَيْنَنَا وَبَيْنَكَ مَوْعِداً } زمان وعدٍ او مكان وعدٍ او وعداً { لاَّ نُخْلِفُهُ نَحْنُ وَلاَ أَنتَ مَكَاناً } حال عن موعداً او وصف له او بدلٌ عنه بدل الكلّ او الاشتمال، او مفعول اوّل او ثانٍ لا جعل او مفعول فعلٍ محذوفٍ { سُوًى } قرئ بضمّ السّين وكسرها وهما وصفان بمعنى المستوى اى مكاناً يكون مستوى المسافة الينا واليك، او يكون مستوياً لا تلال فيه ولا وهاد حتّى يكون جميع النّظّار ناظرين الينا واليك من غير حجابٍ.
