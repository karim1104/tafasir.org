{ وَلَقَدْ يَسَّرْنَا ٱلْقُرْآنَ لِلذِّكْرِ } اى للتّذكّر والاتّعاظ بان ذكرنا فيه الحكايات المبشّره والمنذرة والامثال العديدة بالفاظٍ واضحة الدّلالة، او يسّرنا القرآن بان نزّلناه من مقامه العالى وادخلناه فى قوالب الالفاظ والحروف ليسهل ادراكه لكم { فَهَلْ مِن مُّدَّكِرٍ كَذَّبَتْ عَادٌ } قوم عادٍ بعد قوم نوحٍ { فَكَيْفَ كَانَ عَذَابِي وَنُذُرِ إِنَّآ أَرْسَلْنَا } جوابٌ لسؤالٍ مقدّرٍ عن العذاب { عَلَيْهِمْ رِيحاً صَرْصَراً } باردة { فِي يَوْمِ نَحْسٍ مُّسْتَمِرٍّ } نحو ستّة الى مثله، عن الصّادق (ع): يوم الاربعاء يوم نحس لانّه اوّل يومٍ وآخر يومٍ من الايّام الّتى قال الله عزّ وجلّ [الحاقّة:7].
