{ كَذَّبُواْ بِآيَاتِنَا } التّسع { كُلِّهَا } او بآياتنا الآفاقيّة والانفسيّة كلّها، او بآياتنا العظمى كلّها وهم الرّسل { فَأَخَذْنَاهُمْ أَخْذَ عِزِيزٍ مُّقْتَدِرٍ أَكُفَّارُكُمْ } يا قريش او يا اهل مكّة او يا ايّها العرب او يا ايّها النّاس { خَيْرٌ مِّنْ أُوْلَـٰئِكُمْ } الهالكين الماضين حتّى لا نعذّبهم ولا نهلكهم مثلهم وليس كذلك { أَمْ لَكُم بَرَآءَةٌ فِي ٱلزُّبُرِ }. بل اثبت لهم فى الزّبر الاوّلين او فى الالواح العالية والكتب الّتى بايدى الملائكة براءة من العذاب او من الهلكة او من النّار.
