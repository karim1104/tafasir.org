{ وَإِبْرَاهِيمَ } عطف على نوحاً او بتقدير اذكر او ذكّرهم { إِذْ قَالَ لِقَوْمِهِ ٱعْبُدُواْ ٱللَّهَ وَٱتَّقُوهُ ذٰلِكُمْ خَيْرٌ لَّكُمْ } من تقليد الآباء واخذ الدّين بالرّسم والعادة وعبادة الاصنام من غير حجّة، وخير امّا خالٍ من معنى التّفضيل او الاتيان بصيغة التّفضيل لاعتقادهم بانّ ذلك خير { إِن كُنتُمْ تَعْلَمُونَ إِنَّمَا تَعْبُدُونَ مِن دُونِ ٱللَّهِ أَوْثَاناً وَتَخْلُقُونَ } من عند انفسكم من دون برهانٍ { إِفْكاً } اى كذباً فى ادّعاء انّها الهةٌ او معبودات او شفعاء وهذا ابتداء كلامٍ من الله او هو من قول ابراهيم (ع) { إِنَّ ٱلَّذِينَ تَعْبُدُونَ مِن دُونِ ٱللَّهِ لاَ يَمْلِكُونَ لَكُمْ رِزْقاً } فاذا كانوا لا يملكون لكم رزقاً { فَٱبْتَغُواْ عِندَ ٱللَّهِ ٱلرِّزْقَ } لانّه هو الّذى يملك رزق كلّ مرزوقٍ، وهذا ايضاً يحتمل كونه من قول ابراهيم (ع) ومن قول الله تعالى { وَٱعْبُدُوهُ } لاستحقاقه بمالكيّة الرّزق { وَٱشْكُرُواْ لَهُ } لانّه المالك للنّعم كلّها ومعطيها { إِلَيْهِ تُرْجَعُونَ } تعليل لسابقه.
