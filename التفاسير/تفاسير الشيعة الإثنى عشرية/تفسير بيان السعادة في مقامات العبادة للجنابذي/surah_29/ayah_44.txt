{ خَلَقَ ٱللَّهُ ٱلسَّمَاوَاتِ وَٱلأَرْضَ بِٱلْحَقِّ } قد مضى مكرّراً هذه الآية { إِنَّ فِي ذٰلِكَ } اى فى خلق السّماوات والارض بحيث يتمّ بخلقهما امر المواليد واستمرار الفيض من الواهب الفيّاض بحيث لولاهما لما استتمّ امر المواليد ولما استمرّ الفيض ولما وجد غاية الايجاد وهو الانسان او فى خلق السّماوات والارض متلبّسات بالغايات الحقّة او بالتّنضيدات الحقّة الّتى لا شوب باطل فيها { لآيَةً } عظيمة او المراد بها الجنس اى آياتٌ عديدة { لِّلْمُؤْمِنِينَ } بالبيعة العامّة او الخاصّة او للمذعنين بالله والآخرة.
