{ فَلاَ أُقْسِمُ } لفظة لا قد مضى مكرّراً انّها شائع دخولها فى القسم، وتكون زائدة للتّأكيد { بِرَبِّ ٱلْمَشَارِقِ وَٱلْمَغَارِبِ } مشارق عالم الطّبع ومغاربه فانّ للشّمس فى كلّ يوم بل فى كلّ آنٍ مشرقاً ومغرباً غير ما كان له فى الآن السّابق، ومشارق العوالم العالية ومغاربها، فانّ كلّ عالمٍ مشرقٌ بوجهٍ ومغرب بوجهٍ، وله مشرق بوجهٍ ومغرب بوجهٍ { إِنَّا لَقَادِرُونَ عَلَىٰ أَن نُّبَدِّلَ خَيْراً مِّنْهُمْ } بان نذهبهم ونجعل بدلهم جمعاً يكونون خيراً منهم { وَمَا نَحْنُ بِمَسْبُوقِينَ } بمغلوبين ان اردنا ذلك يعنى نقدر على ذلك ولا مانع لنا ولكنّا اهملناهم لحكمةٍ ومصلحةٍ.
