{ لاَ يُقَاتِلُونَكُمْ } ايّها المؤمنون { جَمِيعاً } اى المنافقون واليهود اذا اجتمعوا لا يقاتلونكم { إِلاَّ فِي قُرًى مُّحَصَّنَةٍ } لخوفهم منكم وهذه تجرئة للمؤمنين { أَوْ مِن وَرَآءِ جُدُرٍ بَأْسُهُمْ بَيْنَهُمْ شَدِيدٌ } ولكن لالقاء الرّعب فى قلوبهم لا يجترئون على مقاتلتكم لا لضعفٍ وجبن فيهم { تَحْسَبُهُمْ جَمِيعاً وَقُلُوبُهُمْ شَتَّىٰ } كما انّ هذا شأن جميع اهل الدّنيا تكون ابدانهم مجتمعةً وقلوبهم متفرّقةً { ذَلِكَ بِأَنَّهُمْ قَوْمٌ لاَّ يَعْقِلُونَ } لا عقل لهم، او لا يدركون بعقولهم، او لا يتعقّلون ما فيه صلاحهم.
