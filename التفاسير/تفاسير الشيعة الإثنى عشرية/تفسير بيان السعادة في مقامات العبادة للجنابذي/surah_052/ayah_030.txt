{ أَمْ يَقُولُونَ } هو { شَاعِرٌ } يتكلّم بما لا حقيقة له ويتموّه فيقرّب البعيد ويبعّد القريب، ولمّا كان الشّاعر فى اكثر الامر يأتى فى شعره بما لا حقيقة له ويموّه سمّى كلّ من يأتى بكلام مموّه لا حقيقة له بالشّاعر { نَّتَرَبَّصُ بِهِ رَيْبَ ٱلْمَنُونِ } الرّيب صرف الدّهر، والمنون الدّهر والموت والمقصود منه انّا نتربّص هلاكته.
