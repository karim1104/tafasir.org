{ ٱلَّذِينَ هُمْ فِي خَوْضٍ } فى الملاهى، او فى انكار المبدء والمعاد، او فى انكار الرّسول (ص)، او فى انكار ولاية علىٍّ (ع) { يَلْعَبُونَ يَوْمَ يُدَعُّونَ } اى يدفعون بعنفٍ فانّ الدّعّ الدّفع العنيف { إِلَىٰ نَارِ جَهَنَّمَ دَعًّا } وقيل: هو ان تغلّ ايديهم الى اعناقهم وتجمع نواصيهم الى اقدامهم، ثمّ يدفعوا الى جهنّم دفعاً على وجوههم.
