{ فَذَكِّرْ } يعنى اذا كان الامر هكذا فذكّر ولا تبال بردّهم وقبولهم فانّه ينفع بعضهم ان لم ينفع كلّهم، او ينفع آخراً ان لم ينفع اوّل الامر { فَمَآ أَنتَ بِنِعْمَةِ رَبِّكَ } الباء للقسم او للسّببيّة، والنّعمة هى الولاية والنّبوّة والرّسالة صورتها { بِكَاهِنٍ } الكهانة الاخبار بالغيب بطريق خدمة الجنّ، والفعل كمنع ونصر وكرم { وَلاَ مَجْنُونٍ } كما يقولون ويصفونك بهما.
