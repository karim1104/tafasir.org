{ فَكَيْفَ } يكون حالهم او كيف يحتاجون { إِذَا تَوَفَّتْهُمُ ٱلْمَلاَئِكَةُ يَضْرِبُونَ وُجُوهَهُمْ وَأَدْبَارَهُمْ ذَلِكَ } الضّرب { بِأَنَّهُمُ ٱتَّبَعُواْ مَآ أَسْخَطَ ٱللَّهَ وَكَرِهُواْ رِضْوَانَهُ } من ولاية علىٍّ (ع) فانّ الرّحمة والرّضا والرّضوان والنّعمة كلّها ولاية علىٍّ (ع) { فَأَحْبَطَ } الله او ذلك الاتّباع والكراهة { أَعْمَالَهُمْ } عن الباقر (ع) قال: كرهوا عليّاً (ع) امر الله بولايته يوم بدرٍ ويوم حنينٍ وببطن نخلة ويوم التّروية ويوم عرفة نزلت فيه خمس عشرة آية فى الحجّة الّتى صدّ فيها رسول الله (ص) عن المسجد الحرام وبالجحفة وبخمّ والمراد بحبط الاعمال حبط ما عملوها فى الاسلام.
