{ كَتَبَ ٱللَّهُ } تعليلٌ للسّابق { لأَغْلِبَنَّ } لمّا اجرى كتب مجرى القسم فى الاتيان به للتّأكيد أتى له بجوابٍ مثل جواب القسم { أَنَاْ وَرُسُلِيۤ } فى الدّنيا بالحجّة والدّين وعلى جنود الشّياطين الّذين كانوا فى مملكتهم وان صاروا مغلوبين بحسب اجسامهم بعض الاحيان { إِنَّ ٱللَّهَ قَوِيٌّ عَزِيزٌ } تعليلٌ للسّابق.
