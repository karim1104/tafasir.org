{ يٰأَيُّهَا ٱلَّذِينَ آمَنُوۤاْ } بعد ما ذمّ النّجوى مطلقاً وذمّ المتناجين بالاثم والعدوان ومعصية الرّسول (ص) نادى المؤمنين ونهاهم عن النّجوى بما فيه قوّة القوى الثّلاث، فانّ الانسان اذا اجتمع مع غيره قوى فيه الشّأن الّذى هو عليه فنهاهم عن ذلك حتّى يتنبّهوا، واذا كانوا على تلك الشّؤن ارتدعوا عنها فقال { إِذَا تَنَاجَيْتُمْ فَلاَ تَتَنَاجَوْاْ بِٱلإِثْمِ وَٱلْعُدْوَانِ وَمَعْصِيَةِ ٱلرَّسُولِ } يعنى راقبوا احوالكم فان تروا قوّة الميل منكم الى ذلك فاعلموا انّكم بعد فى شأن البهيمة او السّبع او الشّيطان فعالجوا انفسكم بدفع تلك القوّة عنكم { وَتَنَاجَوْاْ بِٱلْبِرِّ } الّذى هو لازم قوّتكم العاقلة { وَٱلتَّقْوَىٰ } من القوى الثّلاث يعنى قوّوا بالاجتماع قوّتكم العاقلة وضعّفوا قواكم الثّلاث { وَٱتَّقُواْ ٱللَّهَ } اى سخط الله فى تقوية القوى الثّلاث { ٱلَّذِيۤ إِلَيْهِ تُحْشَرُونَ } توصيف للتّعليل.
