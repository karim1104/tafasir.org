{ تِلْكَ أُمَّةٌ } جماعة قاصدون لمقصودٍ واحدٍ { قَدْ خَلَتْ } والمراد ابراهيم (ع) ويعقوب وبنوهما { لَهَا مَا كَسَبَتْ وَلَكُمْ مَّا كَسَبْتُمْ وَلاَ تُسْأَلُونَ عَمَّا كَانُوا يَعْمَلُونَ } يعنى انّ انتسابكم اليهم لا ينفعكم به حسناتهم ولا يضرّكم به سيّئاتهم فانظروا الى اعمال أنفسكم لا الى انسابكم وآبائكم.
