{ وَ } قل { لَقَدْ جَآءَكُمْ مُّوسَىٰ بِٱلْبَيِّنَاتِ } اى بالمعجزات الدّالّة على صدقه وحقّيّة نبوّته فلم تؤمنوا به { ثُمَّ ٱتَّخَذْتُمُ ٱلْعِجْلَ } الهاً { مِن بَعْدِهِ } اى من بعد مجيء موسى (ع) بالبيّنات او من بعد ذهابه الى جبل الطّور وهو دليلٌ على انّكم مفطورون على تكذيب الحقّ واتّباع الباطل { وَأَنْتُمْ ظَالِمُونَ } واضعون الباطل موضع الحقّ او ظالمون على انفسكم.
