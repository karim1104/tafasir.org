{ وَلَئِنْ أَتَيْتَ ٱلَّذِينَ أُوتُواْ ٱلْكِتَابَ بِكُلِّ آيَةٍ } معجزة مقترحةٍ لهم او غير مقترحةٍ { مَّا تَبِعُواْ قِبْلَتَكَ } لأنّهم أصحاب النّفس والنّفس كالشّيطان من فطرتها عدم الانقياد، وطلب الآية ليس الاّ للفرار من الانقياد ولو اتيت بالآية المقترحة لما انقادت واعتذرت بعذر آخر واقترحت آيةً أخرى وهذا قطع لأطماع المؤمنين عن اتّباع أهل الكتاب لهم { وَمَآ أَنتَ بِتَابِعٍ قِبْلَتَهُمْ } قطع لأطماعهم عن متابعته (ص) قبلتهم فانّهم قالوا: لو كنت ثابتاً على قبلتنا لكنّا نرجو ان تكون صاحبنا الّذى ننتظره { وَمَا بَعْضُهُم } كالنّصارى بتابعٍ { قِبْلَةَ بَعْضٍ } كاليهود فانّ اليهود كما قيل تستقبل الصّخرة والنّصارى مطلع الشّمس { وَلَئِنِ ٱتَّبَعْتَ أَهْوَاءَهُم } خطابٌ له (ص) والمقصود أمّته (ص) كسابقتها فانّ المؤمنين لرغبتهم فى اسلام اهل الكتاب كانوا يودّون لو كان رسول الله (ص) بقى على قبلتهم حتّى يسلموا { مِّن بَعْدِ مَا جَآءَكَ مِنَ ٱلْعِلْمِ إِنَّكَ إِذَاً لَّمِنَ ٱلظَّالِمِينَ } قطعٌ لاطماع المؤمنين عن بقائه (ص) على قبلتهم واتّباعه (ص) لأهواءهم.
