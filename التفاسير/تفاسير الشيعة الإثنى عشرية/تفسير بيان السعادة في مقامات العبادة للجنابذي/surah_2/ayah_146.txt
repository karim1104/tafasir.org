{ ٱلَّذِينَ آتَيْنَاهُمُ ٱلْكِتَابَ } جواب لسؤالٍ مقدّرٍ ولذا لم يأت بأداة الوصل كأنّه قيل: الا يعرف أحدٌ منهم محمّداً (ص) وقبلته؟ - فقال الّذين آتيناهم الكتاب يعنى أحبارهم ولذا نسب الفعل الى نفسه تشريفاً لهم ونسب الكتمان الى فريق منهم { يَعْرِفُونَهُ } اى محمّداً (ص) او تحويله الى قبلةٍ اخرى فى صلاته { كَمَا يَعْرِفُونَ أَبْنَاءَهُمْ } فى منازلهم بحيث لا يمكن الشكّ والريبة لهم { وَإِنَّ فَرِيقاً مِّنْهُمْ } وهم الّذين عاندوا الحقّ عن علمٍ لمحض اللّجاج { لَيَكْتُمُونَ ٱلْحَقَّ وَهُمْ يَعْلَمُونَ } الحقّ او انّ محمّداً (ص) نبىّ، او المراد أنّهم علماء على ان يكون المفعول منسيّاً.
