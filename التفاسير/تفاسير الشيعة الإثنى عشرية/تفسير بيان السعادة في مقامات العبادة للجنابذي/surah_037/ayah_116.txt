{ وَنَجَّيْنَاهُمَا } الى آخر المعطوفات عطف فيه معنى التّفسير لقوله منّنا { وَقَوْمَهُمَا مِنَ ٱلْكَرْبِ ٱلْعَظِيمِ } الّذى هؤلاء الاستبعاد وقتل الاولاد والتّفريق بين الرّجال والنّساء وتجسّس حياء النّساء للعيب او الولد وخوف قتل فرعون لهم بعد خروجهم من مصر واخذه لهم واستعباده ثانياً وخوف الغرق بعد دخول البحر { وَنَصَرْنَاهُمْ } بانجائهم من عدوّهم واغراق عدوّهم { فَكَانُواْ هُمُ ٱلْغَالِبُونَ وَآتَيْنَاهُمَا ٱلْكِتَابَ ٱلْمُسْتَبِينَ } البالغ فى ظهور الصّدق وكون صاحبه صادقاً والمراد به النّبوّة والرّسالة واحكامهما والتّوراة صورتهما.
