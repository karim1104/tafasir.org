{ قُلْ يَجْمَعُ بَيْنَنَا رَبُّنَا } فى القيامة حتّى يكون وعداً ووعيداً لكم ولهم { ثُمَّ يَفْتَحُ بَيْنَنَا بِٱلْحَقِّ } بحكومة حقّة { وَهُوَ ٱلْفَتَّاحُ ٱلْعَلِيمُ قُلْ أَرُونِيَ ٱلَّذيِنَ أَلْحَقْتُمْ بِهِ شُرَكَآءَ } يعنى قل اظهروا شركاءكم لله حتّى يظهر عليكم انّه ليس لها من وصف الشّراكة لله شيءٌ { كَلاَّ } كلام من الله لردعهم عن الاشراك او جزء مقول قوله { بَلْ هُوَ ٱللَّهُ } المعبود بالحقّ لا غيره { ٱلْعَزِيزُ } الغالب الّذى لا يجوز ان يكون فى مقابله ثانٍ { ٱلْحْكِيمُ } الّذى يعجز عن ادراك دقائق صنعه ولطائف علمه عقول العقلاء فكيف يكون مصنوعه او مصنوعكم شريكاً له مع اتّصافه بالجهل وعدم الشّعور فضلاً عن الحكمة.
