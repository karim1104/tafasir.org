{ يٰأَيُّهَا ٱلَّذِينَ آمَنُواْ } ناداهم اظهاراً للّطف بهم وترغيباً لهم فى استماع خطابه { لاَ تَتَّبِعُواْ خُطُوَاتِ ٱلشَّيْطَانِ } فى اشاعة الفاحشة ورمي البريء وغير البريء وقد مضى فى سورة البقرة عند قوله [البقرة:168] تحقيق الخطوات { وَمَن يَتَّبِعْ خُطُوَاتِ ٱلشَّيْطَانِ } يضلّ ويشقى { فَإِنَّهُ يَأْمُرُ بِٱلْفَحْشَآءِ } البالغة فى القبح { وَٱلْمُنْكَرِ } ما لا يعرفه العقل والعرف حسناً وهو ما لا يكون بالغاً فى القبح { وَلَوْلاَ فَضْلُ ٱللَّهِ عَلَيْكُمْ وَرَحْمَتُهُ مَا زَكَا مِنكُمْ مِّنْ أَحَدٍ أَبَداً } زكى يزكو زكاءً نما كا زكى وزكى الرّجل صلح وتنعّم وصفا من الكدورات { وَلَـٰكِنَّ ٱللَّهَ يُزَكِّي مَن يَشَآءُ } باستعداد من قبله بسبب قوله او فعله { وَٱللَّهُ سَمِيعٌ } لاقواله المقاليّة والحاليّة { عَلِيمٌ } بافعاله واحواله ونيّاته واستعداداته المكمونة الغير الظّاهرة عليه وعلى غيره.
