{ وَيَوْمَ نُسَيِّرُ ٱلْجِبَالَ } بجعلها هباءً منبثّاً فى الجوّ وهو عطف على عند ربّك او هو بتقدير ذكّر والجملة باعتبار المعنى { وَتَرَى ٱلأَرْضَ بَارِزَةً } من تحت الجبال وخلف التّلال بحيث لا يكون فيها تلال ووهاد { وَحَشَرْنَاهُمْ } للحساب فى تلك الارض البارزة والجملة امّا حال، وماضوّيتها بالنّسبة الى عاملها، او عطف وما ضوّيتها لتحقّق وقوعها { فَلَمْ نُغَادِرْ مِنْهُمْ أَحَداً } لا محسناً ولا مسيئاً.
