{ فَاكِهِينَ } متنعّمين او معجبين { بِمَآ آتَاهُمْ رَبُّهُمْ وَوَقَاهُمْ رَبُّهُمْ عَذَابَ ٱلْجَحِيمِ كُلُواْ وَٱشْرَبُواْ } حاليّة او مستأنفة جوابٌ لسؤالٍ مقدّرٍ بتقدير القول { هَنِيئَاً بِمَا كُنتُمْ تَعْمَلُونَ مُتَّكِئِينَ } حال { عَلَىٰ سُرُرٍ مَّصْفُوفَةٍ } متّصل بعضها ببعضٍ { وَزَوَّجْنَاهُم بِحُورٍ عِينٍ } أتى بالماضى للاشعار بانّ التّزويج حاصل لهم فى دار الدّنيا وان كان لا يظهر عليهم، او للاشارة الى تحقّق وقوعه.
