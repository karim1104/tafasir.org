{ بَلْ ظَنَنْتُمْ } يعنى ليس شغلتكم اموالكم واهلوكم بل خفتم عن قريش لانّكم ظننتم انّهم يغلبون ويقتلون محمّداً (ص) واصحابه و { أَن لَّن يَنقَلِبَ ٱلرَّسُولُ وَٱلْمُؤْمِنُونَ إِلَىٰ أَهْلِيهِمْ أَبَداً وَزُيِّنَ ذَلِكَ } اى استحكم ذلك { فِي قُلُوبِكُمْ } بحيث لا تحتملون غيره { وَظَنَنتُمْ ظَنَّ ٱلسَّوْءِ } بالله ورسوله { وَكُنتُمْ قَوْماً بُوراً } هالكين عن الحياة الانسانيّة.
