{ سَيَقُولُ } لكم { ٱلْمُخَلَّفُونَ إِذَا ٱنطَلَقْتُمْ إِلَىٰ مَغَانِمَ } كمغانم خيبر { لِتَأْخُذُوهَا ذَرُونَا نَتَّبِعْكُمْ يُرِيدُونَ أَن يُبَدِّلُواْ كَلاَمَ ٱللَّهِ } يعنى قوله انّ الخارجين الى مكّة المصدودين عن طواف البيت مخصوصون بمغانم خيبر بدلاً من دخول مكّة او قوله انّ المتخلّفين لا يتّبعوكم فى مغانم خيبر { قُل لَّن تَتَّبِعُونَا } أتى بنفى التّأبيد مكان النّهى اشارة الى تحقّقه وتأكيداً له { كَذَلِكُمْ قَالَ ٱللَّهُ مِن قَبْلُ } انّكم لا تكونون معنا فى مغانم خيبر { فَسَيَقُولُونَ بَلْ تَحْسُدُونَنَا بَلْ كَانُواْ لاَ يَفْقَهُونَ إِلاَّ قَلِيلاً } يعنى لا يدركون من امر الآخرة فى المخاطبات الاّ قليلاً فلذلك يحملون قولكم ومنعكم على الحسد الّذى هى من اوصاف الدّنيا.
