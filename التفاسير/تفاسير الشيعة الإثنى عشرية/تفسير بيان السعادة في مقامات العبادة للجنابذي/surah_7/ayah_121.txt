{ قَالُوۤاْ آمَنَّا بِرَبِّ ٱلْعَالَمِينَ رَبِّ مُوسَىٰ وَهَارُونَ } بيّنوا المجمل بالابدال منه { قَالَ فِرْعَوْنُ آمَنتُمْ بِهِ قَبْلَ أَن آذَنَ لَكُمْ إِنَّ هَـٰذَا لَمَكْرٌ مَّكَرْتُمُوهُ فِي ٱلْمَدِينَةِ } اى مدينة مصر { لِتُخْرِجُواْ مِنْهَآ أَهْلَهَا } المالكين لها المتصرّفين فيها وهم القبطيّة { فَسَوْفَ تَعْلَمُونَ } تهديد لهم.
