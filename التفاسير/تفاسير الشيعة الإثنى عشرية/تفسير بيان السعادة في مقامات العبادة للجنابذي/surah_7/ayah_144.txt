{ قَالَ } الله تعالى بعد ما اندكّ جبل انّيّته ومات عن انانيّته ثمّ احياه الله بحيوةٍ اخرى غير الحيوة الاولى واستحقّ اعطاء كتاب النّبوّة { يٰمُوسَىٰ إِنِّي ٱصْطَفَيْتُكَ عَلَى ٱلنَّاسِ بِرِسَالاَتِي } يعنى بما به الرّسالة ولذا جمعه وهو اسفار التّوارة او احكام التّوارة { وَبِكَلاَمِي } اى بشرافة كونك كليماً لي { فَخُذْ مَآ آتَيْتُكَ } من التّوارة او احكام الرّسالة اطلق الاخذ هنا وقيّده فيما بعد وفى قصّة يحيى وفى قصّة رفع الجبل فوق بنى اسرائيل بقوله بقوّة للاشارة الى عدم الحاجة اليها هنا لقوّة الآخذ وعدم حاجة المأخوذ الى قوّةٍ وللاشارة الى قوّةٍ المأخوذ وضعف الآخذ فى قصّة يحيى وقصّة بنى اسرائيل { وَكُنْ مِّنَ ٱلشَّاكِرِينَ } بصرفه لاهله ومنعه من غير اهله، وروى انّ سؤال الرّؤية كان يوم عرفة واعطاء التّوارة يوم النّحر.
