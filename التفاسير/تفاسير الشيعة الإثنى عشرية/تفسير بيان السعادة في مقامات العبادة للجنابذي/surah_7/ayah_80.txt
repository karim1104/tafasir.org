{ وَلُوطاً } عطف على نوحاً ولوط (ع) كان ابن خالة ابراهيم (ع) وكانت سارة زوجة ابراهيم (ع) اخت لوطٍ وخرج ابراهيم (ع) من بلاد نمرود الى الشّام ومعه لوطٌ وسارة وخلّف لوطاً بادنى الشّامات للدّعوة وذهب هو الى اعلى الشّامات { إِذْ قَالَ لِقَوْمِهِ } فى الدّعوة والمعاشرة لا فى النّسب والملّة { أَتَأْتُونَ ٱلْفَاحِشَةَ } المعهودة وهى اتيان الرّجال والاعراض عن النّساء { مَا سَبَقَكُمْ بِهَا مِنْ أَحَدٍ مِّن ٱلْعَالَمِينَ إِنَّكُمْ لَتَأْتُونَ ٱلرِّجَالَ شَهْوَةً } صرّح بما كنّى عنه اوّلاً تفضيحاً وتوبيخاً ولذلك اتى به مؤكّداً بتوكيداتٍ توكيداً للتّوبيخ { مِّن دُونِ ٱلنِّسَآءِ بَلْ أَنْتُمْ قَوْمٌ مُّسْرِفُونَ } يعنى لستم عادلين بل انتم قوم مسرفون، فهو من قبيل العطف باعتبار المعنى.
