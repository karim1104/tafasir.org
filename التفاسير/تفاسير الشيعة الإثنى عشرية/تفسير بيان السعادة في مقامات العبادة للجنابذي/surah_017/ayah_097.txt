{ وَمَن يَهْدِ ٱللَّهُ فَهُوَ ٱلْمُهْتَدِ } يعنى ليس الاهتداء بكثرة السّؤال والاقتراح انّما هو امر آلهىّ لمن يشاء من عباده لا اختيارىّ باختيار العبد وحيلته { وَمَن يُضْلِلْ فَلَن تَجِدَ لَهُمْ أَوْلِيَآءَ مِن دُونِهِ وَنَحْشُرُهُمْ يَوْمَ ٱلْقِيَامَةِ عَلَىٰ وُجُوهِهِمْ } يعنى منكوساً ارجلهم من فوق ورؤسهم من تحت { عُمْياً } مطلقاً او عن رحمة الله وفضله { وَبُكْماً وَصُمّاً } مطلقاً او عمّا ينفعهم { مَّأْوَاهُمْ جَهَنَّمُ كُلَّمَا خَبَتْ زِدْنَاهُمْ سَعِيراً } توقّداً.
