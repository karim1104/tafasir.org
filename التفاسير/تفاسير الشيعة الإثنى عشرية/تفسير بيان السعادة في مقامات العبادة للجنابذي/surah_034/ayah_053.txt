{ وَقَدْ كَـفَرُواْ بِهِ } بالقائم (ع) او بمحمّدٍ (ص) { مِن قَـبْلُ } اى من قبل ذلك الزّمان، او من قبل ذلك المكان الّذى هو اسفل امكنة النّفس { وَيَقْذِفُونَ بِٱلْغَيْبِ } اى يلقون الامر الغائب عنهم بمحض الظّنّ والتّخمين، او يقذفون بالغيب الغائب عنهم على الحاضر المشهود لستره { مِن مَّكَانٍ بَعِيدٍ } من الغيب.
