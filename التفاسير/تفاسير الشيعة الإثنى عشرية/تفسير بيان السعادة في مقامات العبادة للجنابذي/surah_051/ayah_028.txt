{ فَقَرَّبَهُ إِلَيْهِمْ قَالَ أَلاَ تَأْكُلُونَ فَأَوْجَسَ مِنْهُمْ خِيفَةً قَالُواْ لاَ تَخَفْ } لانّا رسل ربّك { وَبَشَّرُوهُ بِغُلاَمٍ عَلَيمٍ فَأَقْبَلَتِ ٱمْرَأَتُهُ } بعد البشارة وهى سارة { فِي صَرَّةٍ } اى فى صيحةٍ او فى جماعة كما روى عن الصّادق (ع) { فَصَكَّتْ وَجْهَهَا } قيل: جمعت اصابعها وضربت بها جبهتها، وقيل: لطمت وجهها للتّعجّب، وقيل: غطّت وجهها { وَقَالَتْ عَجُوزٌ عَقِيمٌ } يعنى كيف اَلِد وكنت عاقراً وقت اقتضاء السّنّ الحمل وصرت عجوزاً ليس من شأنى الحمل.
