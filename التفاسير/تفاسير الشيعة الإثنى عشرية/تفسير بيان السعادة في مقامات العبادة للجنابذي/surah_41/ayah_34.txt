{ وَلاَ تَسْتَوِي ٱلْحَسَنَةُ وَلاَ ٱلسَّيِّئَةُ } تمهيدٌ لما يأتى وتعليلٌ لما مضى والاعتقاد بعدم استواء الحسنة والسّيّئة من الفطريّات فمن اختار عليه غيره ممّن اطّلع عليهما كان خارجاً من الفطرة { اٱدْفَعْ } سيّئة من اساء اليك { بـِ } الفعلة { ٱلَّتِي هِيَ أَحْسَنُ } وقد مضى بيان هذه الآية فى سورة المؤمنون { فَإِذَا ٱلَّذِي بَيْنَكَ وَبَيْنَهُ عَدَاوَةٌ كَأَنَّهُ وَلِيٌّ حَمِيمٌ } اى محبٌّ قريبٌ فى النّسب وقد فسّر فى الخبر الحسنة بالتّقيّة والسّيّئة بالاذاعة وهو وجهٌ من وجوه الآية، ويجوز ان يفسّر الّتى هى احسن بالولاية اى ادفع سيّئات نفسك وسيّئات غيرك بتذكّر جهة الولاية او بقبول الولاية او بتذكيرهم بالولاية ولعلّ التّعبير عن الاساءة بالسّيّئة كان لهذا الوجه.
