{ وَقَيَّضْنَا } عطف على نجّينا والمعنى انّا قدّرنا وسبّبنا { لَهُمْ } فى الدّنيا { قُرَنَآءَ } يعنى شياطين الانس والجنّ { فَزَيَّنُواْ لَهُم مَّا بَيْنَ أَيْدِيهِمْ } قد مضى مكرّراً انّ ما بين ايديهم فسّر بالدّنيا وبالآخرة وكذا قوله تعالى { وَمَا خَلْفَهُمْ } يعنى انّ القرناء زيّنوا لهم الشّهوات ومقتضى السّبعيّة والشّيطانيّة وزيّنوا لهم ما ظنّوه وقالوا فى امر الآخرة من الرّدّ والانكار، او بان قالوا ان رددنا الى ربّنا لكان لنا خيراً منها منقلباً { وَحَقَّ عَلَيْهِمُ ٱلْقَوْلُ } بسوء اعمالهم واقوالهم واحوالهم { فِيۤ أُمَمٍ قَدْ خَلَتْ مِن قَبْلِهِمْ مِّنَ ٱلْجِنِّ وَٱلإِنْسِ } من الامم الفاجرة { إِنَّهُمْ كَانُواْ خَاسِرِينَ وَقَالَ ٱلَّذِينَ كَفَرُواْ لاَ تَسْمَعُواْ لِهَـٰذَا ٱلْقُرْآنِ } اى مطلق القرآن او قرآن ولاية علىٍّ (ع) { وَٱلْغَوْاْ فِيهِ } لغى فى قوله كسعى ودعا ورضى اخطأ والمقصود اقرأوه مغلوطاً مخلوطاً بغيره او ادخلوا على قرّائه ما ليس منه او عارضوه بالباطل واللّغو { لَعَلَّكُمْ تَغْلِبُونَ } قرّاءه او تغلبون محمّداً (ص).
