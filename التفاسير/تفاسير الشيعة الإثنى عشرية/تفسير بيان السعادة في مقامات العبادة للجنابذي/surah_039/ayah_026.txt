{ كَذَّبَ ٱلَّذِينَ مِن قَبْلِهِمْ } جوابٌ لسؤالٍ مقدّرٍ كأنّه قيل: هل لهم نظير فى تكذيبهم؟ - فقال تعالى: { كذّب الّذين من قبلهم }  { فَأَتَاهُمُ ٱلْعَـذَابُ مِنْ حَيْثُ لاَ يَشْعُرُونَ فَأَذَاقَهُمُ ٱللَّهُ ٱلْخِزْيَ فِي ٱلْحَيَاةِ ٱلدُّنْيَا } تفصيل لعذابهم الآتى يعنى اتاهم العذاب فاذاقهم الله ذلك العذاب بالمسخ او الخسف او القتل او الاجلاء او السّبى او النّهب او البلايا الواردة الالهيّة فانّها ان كانت نعمة بالنّسبة الى المؤمنين كانت نقمةً بالنّسبة الى المنافقين والكافرين { وَلَعَذَابُ ٱلآخِرَةِ أَكْبَرُ } فانّ عذاب الدّنيا وان كان اشدّ ما يكون يكون جزءً من سبعين جزءً من عذاب الآخرة { لَوْ كَانُواْ يَعْلَمُونَ } لاجتنبوا او لفظة لو للتّمنّى.
