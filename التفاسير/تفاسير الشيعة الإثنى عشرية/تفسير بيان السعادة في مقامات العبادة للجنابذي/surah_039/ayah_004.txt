{ لَّوْ أَرَادَ ٱللَّهُ أَن يَتَّخِذَ وَلَداً } كما نسبوا اليه الملائكة والمسيح وعزيراً { لاَّصْطَفَىٰ مِمَّا يَخْلُقُ } من اصناف الملائكة وانواع البشر والجنّ { مَا يَشَآءُ } من البنين لا ما نسبوا اليه من البنات { سُبْحَانَهُ } عن الشّريك والولد والصّاحبة { هُوَ ٱللَّهُ ٱلْوَاحِدُ } الّذى لا مثل له حتّى يكون له ولدٌ { ٱلْقَهَّارُ } الّذى لا يجوز فى قهّاريّته ان يكون له شريكٌ ومثلٌ، والولد يكون مثلاً له، والشّريك يكون مثلاً له ومقابلاً لا مقهوراً.
