{ لَقَدْ كَانَ لَكُمْ فِيهِمْ } فى ابراهيم (ع) وقومه { أُسْوَةٌ حَسَنَةٌ } كرّره للتّأكيد والتّرغيب ولتخصيصه بمن كان يرجوا لله { لِّمَن كَانَ يَرْجُواْ ٱللَّهَ وَٱلْيَوْمَ ٱلآخِرَ } يعنى هذه الاسوة مختصّة بمن كان يرجوا لله وامّا غيره فلا يتأسّى { وَمَن يَتَوَلَّ } عن التّأسّى منكم فلا يضرّ الله شيئاً وانّما امركم بالتّأسّى ترحّماً عليكم { فَإِنَّ ٱللَّهَ هُوَ ٱلْغَنِيُّ ٱلْحَمِيدُ } حمد ام لم يحمد
