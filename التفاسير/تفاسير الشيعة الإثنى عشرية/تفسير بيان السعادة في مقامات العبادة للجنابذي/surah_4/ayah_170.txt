{ يٰأَيُّهَا ٱلنَّاسُ قَدْ جَآءَكُمُ ٱلرَّسُولُ بِٱلْحَقِّ } اى بولاية علىٍّ (ع) فانّها الحقّ وكلّ ما سواها حقّ بها كما مضى { مِن رَّبِّكُمْ } فلا تبالوا بمن كفر به ولا تتّبعوه { فَآمِنُواْ } بهذا الحقّ او بالرّسول فيما قال فى حقّ هذا الحقّ واتّبعوا { خَيْراً لَّكُمْ } او ايماناً خيراً لكم او حال كونه خيراً لكم او يكن خيراً لكم { وَإِن تَكْفُرُواْْ } بهذا الحقّ لا تخرجوا من حيطة قدرته وتصرّفه ولا يهملكم من غير عقوبةٍ وجزاءٍ { فَإِنَّ للَّهِ مَا فِي ٱلسَّمَاوَاتِ وَٱلأَرْضِ وَكَانَ ٱللَّهُ عَلِيماً حَكِيماً } لا يهملكم بل يجزيكم بما يقتضى حكمته.
