{ إِلاَّ ٱلَّذِينَ يَصِلُونَ إِلَىٰ قَوْمٍ بَيْنَكُمْ وَبَيْنَهُمْ مِّيثَاقٌ } فلا تتّخذوهم اولياء ولا تقتلوهم حفظاً للميثاق من جميع الوجوه { أَوْ جَآءُوكُمْ حَصِرَتْ صُدُورُهُمْ أَن يُقَاتِلُونَكُمْ } فلا يكونوا عليكم { أَوْ يُقَاتِلُواْ قَوْمَهُمْ } فلا يكونوا معكم فانّهم لحصر صدورهم عن مقاتلتكم يستحقّون الرّفق لا الاخذ والقتل، ونزول الآية مذكور فى التّفاسير وتعميمها سهل على البصير { وَلَوْ شَآءَ ٱللَّهُ لَسَلَّطَهُمْ عَلَيْكُمْ فَلَقَاتَلُوكُمْ فَإِنِ ٱعْتَزَلُوكُمْ فَلَمْ يُقَاتِلُوكُمْ وَأَلْقَوْاْ إِلَيْكُمُ ٱلسَّلَمَ فَمَا جَعَلَ ٱللَّهُ لَكُمْ عَلَيْهِمْ سَبِيلاً } بالاخذ والقتل.
