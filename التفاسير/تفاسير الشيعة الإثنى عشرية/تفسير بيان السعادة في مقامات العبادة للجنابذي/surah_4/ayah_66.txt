{ وَلَوْ أَنَّا كَتَبْنَا } فرضنا { عَلَيْهِمْ أَنِ ٱقْتُلُوۤاْ أَنْفُسَكُمْ } كفّارة لذنوبكم كما كتبنا على بنى اسرائيل بعد عبادتهم للعجل { أَوِ ٱخْرُجُواْ مِن دِيَارِكُمْ } بالجلاء { مَّا فَعَلُوهُ إِلاَّ قَلِيلٌ مِّنْهُمْ } تفضيح بليغ لهم ببيان انّ حالهم فى اتّخاذهم العجل باغواء سامريّهم اقبح واقوى فى الشّقاء من قوم موسى (ع) فانّهم ندموا وتابوا وبعد ندمهم كتبنا عليهم القتل ففعلوا وهؤلاء لا يندمون ولو ندموا لا يفعلون ما كتب عليهم { وَلَوْ أَنَّهُمْ فَعَلُواْ مَا يُوعَظُونَ بِهِ } من الرّجوع الى الكتاب والى قولك فى علىّ (ع) ومن الرّجوع اليه والرّضا بحكومته والتّسليم له بعد التّندّم وطلب الاستغفار منه { لَكَانَ خَيْراً لَّهُمْ وَأَشَدَّ تَثْبِيتاً } لاقدامهم على الاسلام.
