{ أَمْ لَهُمْ } اى للمتبوعين { نَصِيبٌ مِّنَ ٱلْمُلْكِ } حتّى يستحقّوا بذلك الاتّباع وان فرض انّ لهم نصيباً من الملك { فَإِذاً لاَّ يُؤْتُونَ ٱلنَّاسَ } الّذين هم المتحقّقون بالانسانيّة وهم الاولياء واصلهم علىّ (ع) فكيف بأشباه النّاس والنّسناس { نَقِيراً } والنّقير النّقطة الّتى فى وسط النّواة يمثّل به فى الحقارة والمعنى انّهم ليس لهم نصيب من الملك حتّى يطمعوا فيه فيتّبعوهم وحالهم ان لو كان لهم نصيب من الملك لما اتوا النّاس شيئاً حقيراً منه فكيف بهم وهم نسناس فلا ملكهم يقتضى الاتّباع ولا حالهم ثمّ صرف القول الى الاتباع والمتبوعين جميعاً فقال تعالى { أَمْ يَحْسُدُونَ ٱلنَّاسَ }.
