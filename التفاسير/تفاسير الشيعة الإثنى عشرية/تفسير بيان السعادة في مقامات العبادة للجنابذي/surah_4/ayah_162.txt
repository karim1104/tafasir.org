{ لَّـٰكِنِ ٱلرَّاسِخُونَ فِي ٱلْعِلْمِ مِنْهُمْ وَٱلْمُؤْمِنُونَ } اى منهم فالمعنى والمنقادون المسلمون بأنبيائهم وخلفاء انبيائهم او المؤمنون من امّتك فالمعنى والمناقدون المسلمون بك من امّتك او منهم ومن امّتك { يُؤْمِنُونَ بِمَآ أُنزِلَ إِلَيكَ } عموماً ومنه الولاية او بما انزل اليك من ولاية علىّ (ع) خصوصاً فانّها منظورة من كلّما ذكر { وَمَآ أُنزِلَ مِن قَبْلِكَ } فى علىٍّ (ع) او عموماً { وَٱلْمُقِيمِينَ ٱلصَّلاَةَ } ويؤمنون بالمقيمين الصّلوة ولمّا وسم عليّاً (ع) باسم مقيم الصّلوة ومؤتى الزّكوة بقوله: [المائدة:55] ورّى عنه بالمقيمين الصّلوة وأتى بالمؤتون الزّكوة بالرّفع ليكون توريةً اخرى حتّى لا يسقطوه كسائر موارد التّصريح به وعلى هذا فقوله تعالى { وَٱلْمُؤْتُونَ ٱلزَّكَاةَ } خبر مبتدءٍ محذوفٍ كأنّه قال: وهم المعهودون بايتاء الزّكوة فى الرّكوع وقد بيّن العامّة وجوهاً لاعراب الآية لا فائدة فى ايرادها وان كانت محتملةً بحسب اللّفظ { وَ } هم { ٱلْمُؤْمِنُونَ بِٱللَّهِ وَٱلْيَوْمِ ٱلآخِرِ أُوْلَـۤئِكَ } الرّاسخون المؤمنون { سَنُؤْتِيهِمْ أَجْراً عَظِيماً } لايمانهم بما انزل اليك فى علىٍّ (ع).
