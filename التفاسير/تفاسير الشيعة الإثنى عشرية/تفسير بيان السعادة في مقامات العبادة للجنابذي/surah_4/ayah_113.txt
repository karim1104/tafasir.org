{ وَلَوْلاَ فَضْلُ ٱللَّهِ } النّبوّة والرّسالة بالنّسبة الى النّبىّ المخاطب به ولولا النّبىّ والرّسول بالنّسبة الى المعرّض به { عَلَيْكَ } وارداً او حافظاً عليك { وَرَحْمَتُهُ } الولاية او علىّ (ع) بالنّسبتين { لَهَمَّتْ طَّآئِفَةٌ مِّنْهُمْ } يعنى انّ هيبة الفضل والرّحمة مانعة من همّتهم او من تأثير همّتهم على تضمين اثّرت { أَن يُضِلُّوكَ } عن رأيك الصّواب او عن رؤيتك الصّواب وعلى ما بيّنا فالمعنى لولا النّبىّ (ص) وعلىّ (ع) حافظاً عليكم لهمّ منافقوا الامّة ان يضلّوكم عن نهج الصّواب والطّريق المدلول عليه بالاسلام من ولاية علىّ (ع) { وَمَا يُضِلُّونَ إِلاَّ أَنْفُسَهُمْ } بهمّتهم { وَمَا يَضُرُّونَكَ مِن شَيْءٍ } على فرض الهمّة منهم { وَأَنزَلَ ٱللَّهُ عَلَيْكَ ٱلْكِتَابَ } اى النّبوّة { وَٱلْحِكْمَةَ } اى الولاية { وَعَلَّمَكَ مَا لَمْ تَكُنْ تَعْلَمُ } بانزال الولاية من دقائق الكثرات ودقائق احكامها الّتى هى لازمة الرّسالة { وَكَانَ فَضْلُ ٱللَّهِ } اى الرّسالة او مطلق نعم الله { عَلَيْكَ عَظِيماً } وفى وصل هذا الامتنان اشارة الى تعليل عدم الاضرار.
