{ أُولَـٰئِكَ ٱلَّذِينَ يَعْلَمُ ٱللَّهُ مَا فِي قُلُوبِهِمْ } من النّفاق ويستر عليهم { فَأَعْرِضْ عَنْهُمْ } اى عن تفضيحهم ولا تعاقبهم ودارهم فانّ فى مداراتهم مصلحة كلّيّة لنظام الكلّ { وَعِظْهُمْ } اتماماً للحجّة وتقليلاً لاظهارهم نفاقهم { وَقُل لَّهُمْ فِيۤ أَنْفُسِهِمْ } فى شأن علىّ (ع) فانّه نفسيّة كلّ ذى نفس او فى الخلوة او فى شأن انفسهم { قَوْلاً بَلِيغاً } يؤثّر فيهم ويمنعهم من اظهار نفاقهم حتّى لا يوافقهم كثير من امّتك فانّ اكثرهم بسبب قتل علىّ (ع) منهم اقاربهم يعادونه واذا رأوا من يعانده وينافقه يوافقونه، والمداراة مع هؤلاء المنافقين وموعظتهم وتخويفهم بحيث لا يجترؤن على اظهار نفاقهم مع غيرهم اصلح لحفظ امّتك عن النّفاق.
