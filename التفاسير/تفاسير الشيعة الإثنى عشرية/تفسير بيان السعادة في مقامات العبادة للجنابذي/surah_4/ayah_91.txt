{ سَتَجِدُونَ آخَرِينَ } استيناف وتنبيه على حال المختدعين وبيان لحكمهم { يُرِيدُونَ أَن يَأْمَنُوكُمْ } خدعة { وَيَأْمَنُواْ قَوْمَهُمْ } وفاقاً حال كونهم { كُلَّ مَا رُدُّوۤاْ إِلَى ٱلْفِتْنِةِ } اى القتال معكم فالجملة حال اوستيناف جواب سؤال مقدّر { أُرْكِسُواْ فِيِهَا } انقلبوا عن اظهار الوفاق الى القتال معكم { فَإِن لَّمْ يَعْتَزِلُوكُمْ وَيُلْقُوۤاْ إِلَيْكُمُ ٱلسَّلَمَ وَيَكُفُّوۤاْ أَيْدِيَهُمْ } عطف على المنفىّ { فَخُذُوهُمْ وَٱقْتُلُوهُمْ حَيْثُ ثِقِفْتُمُوهُمْ وَأُوْلَـٰئِكُمْ جَعَلْنَا لَكُمْ عَلَيْهِمْ سُلْطَاناً مُّبِيناً } تسلّطاً ويداً او حجّة لغدرهم.
