{ وَمَن جَآءَ بِٱلسَّيِّئَةِ } فانّه اذا اريد بالسّيّئة الجنس لزم ان يكبّ صاحبها فى النّار وليس كذلك وأذا اريد بالسّيّئة محبّة اعداء اهل البيت وولايتهم صحّ ان يقال { فَكُبَّتْ وُجُوهُهُمْ فِي ٱلنَّارِ } مقولاً لهم { هَلْ تُجْزَوْنَ إِلاَّ مَا كُنتُمْ تَعْمَلُونَ } وقد فسّر الحسنة والسّيّئة فى اخبارٍ عديدةٍ بولاية اهل البيت (ع)، وبغضهم قل لهم.
