{ ٱرْجِعْ إِلَيْهِمْ } ولم يذكر رجوع الهدايا لعدم الاعتداد بها { فَلَنَأْتِيَنَّهُم بِجُنُودٍ لاَّ قِبَلَ لَهُمْ بِهَا } وقد رأيتم شيئاً منها { وَلَنُخْرِجَنَّهُم مِّنْهَآ } اى من سبا او من عند بلقيس { أَذِلَّةً وَهُمْ صَاغِرُونَ } تأكيد للاذلّة فلمّا رجعوا اليها وقصّوا القصّة علمت انّه رسول من الله وعزمت على الخروج الى سليمان (ع) فلمّا علم بعزمها ورأى انّ قلبها متعلّق بعرشها.
