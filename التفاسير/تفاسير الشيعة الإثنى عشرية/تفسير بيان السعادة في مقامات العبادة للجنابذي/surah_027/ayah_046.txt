{ وَلَقَدْ أَرْسَلْنَآ إِلَىٰ ثَمُودَ أَخَاهُمْ صَالِحاً أَنِ ٱعْبُدُواْ ٱللَّهَ فَإِذَا هُمْ فَرِيقَانِ } مؤمنون وجاحدون { يَخْتَصِمُونَ قَالَ } صالح (ع) لهم بعد ما قالوا فأتنا بما تعدنا ان كنت من الصّادقين { يٰقَوْمِ لِمَ تَسْتَعْجِلُونَ بِٱلسَّيِّئَةِ } بالعذاب { قَبْلَ ٱلْحَسَنَةِ } اى قبل سؤال الرّحمة { لَوْلاَ تَسْتَغْفِرُونَ ٱللَّهَ } لولا تطلبون مغفرته وعفوه عمّا فعلتم { لَعَلَّكُمْ تُرْحَمُونَ } منه.
