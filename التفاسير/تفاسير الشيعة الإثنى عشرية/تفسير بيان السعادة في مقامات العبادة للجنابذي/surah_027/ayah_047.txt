{ قَالُواْ ٱطَّيَّرْنَا } تشأمّنا { بِكَ وَبِمَن مَّعَكَ } يعنى انّك منذ ادّعيت واتيت بدينٍ جديدٍ اُبتلينا بالقحط والجدب والامراض وليس الاّ بشؤم دينك الجديد، وقد مضى فى سورة الاعراف وجه اطلاق التّطيّر على التّشأمّ { قَالَ } لهم صالح (ع) { طَائِرُكُمْ } اى سبب خيركم وشرّكم او سبب شرّكم { عِندَ ٱللَّهِ بَلْ أَنتُمْ قَوْمٌ تُفْتَنُونَ } تختبرون بالخير والشّرّ لعلّكم تذكّرون انّ هذه بشؤم اعمالكم فتلتجؤن الى الله وتصدّقون رسوله (ع)، او المعنى انتم قوم تعذّبون بتلك البلايا بشؤم اعمالكم.
