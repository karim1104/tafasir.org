{ وَمَن لَّمْ يُؤْمِن بِٱللَّهِ وَرَسُولِهِ } وظنّ لهما ظنّ السّوء { فَإِنَّآ أَعْتَدْنَا لِلْكَافِرِينَ } وضع الظّاهر موضع المضمر لذمٍّ آخر لهم وللاشعار بعلّة الحكم { سَعِيراً وَلِلَّهِ مُلْكُ ٱلسَّمَاوَتِ وَٱلأَرْضِ يَغْفِرُ لِمَن يَشَآءُ وَيُعَذِّبُ مَن يَشَآءُ } بحسب استعداد كلٍّ فانّ مشيّته ليست جزافيّة { وَكَانَ ٱللَّهُ غَفُوراً رَّحِيماً } ترجيح لجانب الرّجاء واشعارٌ بانّ المغفرة والرّحمة ذاتيّة له، والتّعذيب داخل فى قضائه بالقصد الثّانى.
