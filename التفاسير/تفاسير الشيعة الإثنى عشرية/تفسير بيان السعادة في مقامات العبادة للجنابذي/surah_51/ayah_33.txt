{ قَالَ } ابراهيم (ع) بعد ما عرفهم وانس بهم { فَمَا خَطْبُكُمْ } امركم وشغلكم لمّا لم يكن نزول الاربعة الاملاك دفعةً معهوداً له علم انّهم لم ينزلوا الاّ لامرٍ عظيمٍ فسأل ما خطبكم؟ { أَيُّهَا ٱلْمُرْسَلُونَ قَالُوۤاْ إِنَّآ أُرْسِلْنَآ إِلَىٰ قَوْمٍ مُّجْرِمِينَ لِنُرْسِلَ عَلَيْهِمْ حِجَارَةً مِّن طِينٍ مُّسَوَّمَةً عِندَ رَبِّكَ لِلْمُسْرِفِينَ فَأَخْرَجْنَا مَن كَانَ فِيهَا مِنَ ٱلْمُؤْمِنِينَ فَمَا وَجَدْنَا فِيهَا غَيْرَ بَيْتٍ مِّنَ ٱلْمُسْلِمِينَ } قد مضى قصّتهم فى سورة هود وغيرها.
