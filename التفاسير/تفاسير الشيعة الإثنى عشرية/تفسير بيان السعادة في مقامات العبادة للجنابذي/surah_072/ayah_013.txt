{ وَأَنَّا لَمَّا سَمِعْنَا ٱلْهُدَىٰ } اى القرآن او الرّسالة او الولاية { آمَنَّا بِهِ فَمَن يُؤْمِن بِرَبِّهِ } الفاء للسّببيّة { فَلاَ يَخَافُ بَخْساً } نقصاً او ظلماً او مشاحّة فى الحساب او فقأً لعينه { وَلاَ رَهَقاً } قد مضى الرّهق قبيل ذلك، عن الكاظم (ع) انّه قال: الهدى الولاية، آمنّا بمولانا فمن آمن بولاية مولاه فلا يخاف بخساً ولا رهقاً، قيل: تنزيلٌ؟ - قال: لا، تأويلٌ.
