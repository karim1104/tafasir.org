{ وَٱللَّهُ يُرِيدُ أَن يَتُوبَ عَلَيْكُمْ } كرّره تأكيداً وتصويراً للمقابلة ترغيباً في اتّباع اوامره واجتناب مخالفتها { وَيُرِيدُ ٱلَّذِينَ يَتَّبِعُونَ ٱلشَّهَوَاتِ } كمن يمنع عن الاستمتاع بالنّساء { أَن تَمِيلُواْ } عن الطّريق المؤدّى الى نجاتكم { مَيْلاً عَظِيماً } فهو حقيق بالاتّباع وهم احقّاء بالاجتناب.
