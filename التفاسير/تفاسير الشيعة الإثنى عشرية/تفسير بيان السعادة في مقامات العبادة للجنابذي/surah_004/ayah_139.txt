{ ٱلَّذِينَ يَتَّخِذُونَ ٱلْكَافِرِينَ } الّذين سبق ذكرهم من اعداء آل محمّد (ص) { أَوْلِيَآءَ } باتّباعهم وقبول دعوتهم والبيعة معهم { مِن دُونِ ٱلْمُؤْمِنِينَ } علىّ (ع) واتباعه { أَيَبْتَغُونَ عِندَهُمُ ٱلْعِزَّةَ } استفهام انكارىّ للتّوبيخ يعنى لا ينبغى ان يبتغوا عندهم العزّة { فَإِنَّ ٱلعِزَّةَ للَّهِ جَمِيعاً } مجتمعة عنده فما لهم يخالفون امره ولا يتّبعون اولياءه ويبتغون من غيره العزّة.
