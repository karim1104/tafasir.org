{ وَإِنْ خِفْتُمْ } ايّها النّاظرون من امر اليتامى اذا اردتم نكاحهنّ ضنّة بأموالهنّ { أَلاَّ تُقْسِطُواْ فِي ٱلْيَتَامَىٰ } بالتّقصير في حقّهنّ { فَ } دعوا نكاحهنّ و { ٱنكِحُواْ مَا طَابَ لَكُمْ مِّنَ ٱلنِّسَآءِ } وعن امير المؤمنين (ع) في جواب مسائل الزّنديق الّذي سأل عن اشياء انّه اسقط بين طرفى تلك الآية اكثر من ثلث القرآن { مَثْنَىٰ وَثُلاَثَ وَرُبَاعَ } تخيير بين الواحدة الى اربع وايضاً تخيير فى الاستبدال فانّ فى هذا الوزن دلالة على التّكرير { فَإِنْ خِفْتُمْ } ايّها الرّاغبون في النّكاح { أَلاَّ تَعْدِلُواْ } بينهنّ اذا كنّ اكثر من الواحدة { فَ } انكحوا { وَاحِدَةً أَوْ مَا مَلَكَتْ أَيْمَانُكُمْ } ان خفتم التّقصير في حقّ الحرّة { ذٰلِكَ أَدْنَىٰ أَلاَّ تَعُولُواْ } اى لا تميلوا عن الحقّ اولا تمونوا فتعسروا فانّ خفّة العيال احد اليسارين كما في الخبر.
