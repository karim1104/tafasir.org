{ وَمَا يَسْتَوِي ٱلْبَحْرَانِ هَـٰذَا عَذْبٌ فُرَاتٌ سَآئِغٌ شَرَابُهُ وَهَـٰذَا مِلْحٌ أُجَاجٌ } قد مضى فى سورة الفرقان بيان للبحرين { وَمِن كُلٍّ تَأْكُلُونَ لَحْماً طَرِيّاً وَتَسْتَخْرِجُونَ حِلْيَةً تَلْبَسُونَهَا وَتَرَى ٱلْفُلْكَ فِيهِ مَوَاخِرَ } الفلك المواخر الّتى يسمع صوت جريها او تشقّ الماء بجؤجؤها، او المقبلة والمدبرة بريحٍ واحدةٍ { لِتَبْتَغُواْ مِن فَضْلِهِ } اى من فضل الله بالتّجارات الرّابحة { وَلَعَلَّكُمْ تَشْكُرُونَ } النّعمة الّتى اودعها الله تعالى فى الفلك والبحرين.
