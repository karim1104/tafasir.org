{ أَوَلَمْ يَسِيرُواْ فِي ٱلأَرْضِ } حتّى يشاهدوا آثار الرّسل وآثار مصدّقيهم ومكذّبيهم { فَيَنظُرُواْ كَيْفَ كَانَ عَاقِبَةُ ٱلَّذِينَ مِن قَبْلِهِمْ } فيعتبروا بهم ويتأسّوا بالمصدّقين ويجتنبوا عن مثل افعال المكذّبين واقوالهم وقد مضى مكرّراً تفسير الارض والسّير فيها بارض القرآن والاخبار والسّير الماضية وبارض العالم الصّغير { وَكَانُوۤاْ أَشَدَّ مِنْهُمْ قُوَّةً } فهؤلاء اولى لضعفهم بان يجتنبوا عن مثل افعالهم { وَمَا كَانَ ٱللَّهُ لِيُعْجِزَهُ مِن شَيْءٍ } عن انفاذ امره وامضاء سنّته { فِي ٱلسَّمَاوَاتِ وَلاَ فِي ٱلأَرْضِ إِنَّهُ كَانَ عَلِيماً } بجملة الاشياء فيعلم تكذيب المكذّب واستكباره ومكره وتصديق المصدّق وتسليمه { قَدِيراً } على ما يريد.
