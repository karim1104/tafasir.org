{ ٱسْتِكْبَاراً فِي ٱلأَرْضِ } مفعولٌ له { وَمَكْرَ ٱلسَّيِّىءِ } عطف على استكباراً او هما مصدران وفعلاهما محذوفان { وَلاَ يَحِيقُ ٱلْمَكْرُ ٱلسَّيِّىءُ إِلاَّ بِأَهْلِهِ } لانّ الماكر حين يمكر ليس الاّ سخريّة للشّيطان ومحاطاً به ومحكوماً له، والدّخول تحت حكومة الشّيطان عذاب عاجل لانسانيّة الانسان قبل وصول مكره الى الممكور، وبعد وصول مكر الماكر الى الممكور يكون ارتفاعاً للممكور امّا فى الدّنيا والآخرة، او فى الآخرة، وتنزّلاً للماكر فيهما او فى الآخرة فقط { فَهَلْ يَنظُرُونَ } اى ينتظرون { إِلاَّ سُنَّةَ آلأَوَّلِينَ } فى الرّسل والمكذّبين الماكرين بتعذيبهم واحاطة وبال مكرهم بهم { فَلَن تَجِدَ لِسُنَّةِ ٱللَّهِ تَبْدِيلاً وَلَن تَجِدَ لِسُنَّةِ ٱللَّهِ تَحْوِيلاً } عن المستحقّ الى غير المستحقّ.
