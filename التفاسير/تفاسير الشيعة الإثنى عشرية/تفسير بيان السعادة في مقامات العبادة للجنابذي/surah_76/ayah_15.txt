{ وَيُطَافُ عَلَيْهِمْ بِآنِيَةٍ مِّن فِضَّةٍ وَأَكْوابٍ } جمع الكوب وهو كوز لا عروة له ولا خرطوم { كَانَتْ قَوَارِيرَاْ قَوَارِيرَاْ } قرئ فيهما بالتّنوين للمناسبة، وقرئ فى الاوّل فقط بالتّنوين { مِن فِضَّةٍ } يعنى كانت الاكواب مثل القوارير فى الصّفاء والشّفيف، او كانت القوارير مأخوذة من الفضّة لا من سائر الاحجار مثل قوارير الدّنيا { قَدَّرُوهَا تَقْدِيراً } صفة للاكواب او للآنية والاكواب والمعنى اكواب كان المؤمنون يقدّرون قدرها فى انفسهم، او كانوا يتمنّونها، او كان الغلمان المديرون يقدّرونها بقدر ميل المؤمنين، وقرئ قدّروها على البناء للمفعول.
