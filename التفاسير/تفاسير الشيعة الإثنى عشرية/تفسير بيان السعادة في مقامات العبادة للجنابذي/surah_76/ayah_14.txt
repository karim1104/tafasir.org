{ وَدَانِيَةً عَلَيْهِمْ ظِلاَلُهَا } اى قريبة منهم افياؤها او دائمةً عليهم افياؤها، ومعنى دنوّ الظّلال دنوّ المظلّة منهم، او الظّلال ههنا جمع الظّلة بالضّمّ بمعنى المظلّة { وَذُلِّلَتْ } اى سهلت { قُطُوفُهَا } للجنىّ { تَذْلِيلاً } فانّ ثمارها كأنّها باختيار الجانى يجنيها متى شاء وكيف شاء وعلى اىّ حالٍ شاء.
