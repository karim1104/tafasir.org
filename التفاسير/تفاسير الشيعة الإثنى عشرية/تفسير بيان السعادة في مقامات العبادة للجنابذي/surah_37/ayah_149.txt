{ فَٱسْتَفْتِهِمْ } بعدما ذكرت لهم هذه القصص الّتى فيها عبر لكلّ من يعتبر { أَلِرَبِّكَ } الّذى فعل ما فعل بالامم السّالفة ومكذّبيهم ومصدّقيهم وانبيائهم (ع) { ٱلْبَنَاتُ } الّلاتى هنّ اخسّ الاولاد { وَلَهُمُ ٱلْبَنُونَ } الّذين هم اشرف الاولاد حتّى يعلموا انّهم مخطئون فى تلك النّسبة فيتنبّهوا فيعلموا انّهم مخطئون فى نسبة الولد اليه.
