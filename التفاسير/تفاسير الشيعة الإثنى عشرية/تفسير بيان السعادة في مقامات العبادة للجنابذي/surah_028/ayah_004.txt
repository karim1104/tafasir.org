{ إِنَّ فِرْعَوْنَ } جواب سؤالٍ مقدّرٍ كأنّه قيل: ما ذلك النّبأ { عَلاَ فِي ٱلأَرْضِ } اى ارض مصر { وَجَعَلَ أَهْلَهَا شِيَعاً } بان جعل القبطىّ مكرماً بانواع الكرامة والسّبطىّ مهاناً بانواع الاهانة او جعل السّبطىّ فرقاً متفرّقةً فى الاستعباد والاعمال الشّاقّة فانّهم كانوا أهل مصر واحقّ بها لكن قوله تعالى { يَسْتَضْعِفُ طَآئِفَةً مِّنْهُمْ } يدلّ على المعنى الاوّل { يُذَبِّحُ أَبْنَآءَهُمْ } بدل من يستضعف { وَيَسْتَحْيِي نِسَاءَهُمْ } يعنى يستبقى البنات او يتجسّس حياء النّساء لطلب الحمل او لطلب العيب { إِنَّهُ كَانَ مِنَ ٱلْمُفْسِدِينَ } فى الارض بمنع اهلها من طلب كمالهم والوصول الى رسولٍ او امامٍ، او بالقتل والاستعباد من غير استحقاقٍ.
