{ قَالَ ٱلَّذِينَ حَقَّ عَلَيْهِمُ ٱلْقَوْلُ } من مدّعى الرّبوبيّة ومن مدّعى الولاية والرّسالة وممّن جعلهم المشركون شركاء الله او شركاء الولاية لكنّ المنظور شركاء الولاية { رَبَّنَا هَـٰؤُلاۤءِ ٱلَّذِينَ أَغْوَيْنَآ } اشارة الى المشركين والاتباع { أَغْوَيْنَاهُمْ } بصرفهم عنك أو عن ولّى امرهم { كَمَا غَوَيْنَا } بأنفسنا { تَبَرَّأْنَآ إِلَيْكَ } منهم فانّهم كانوا اعداء لنا وكنّا نظنّهم احباباً { مَا كَانُوۤاْ إِيَّانَا يَعْبُدُونَ } بل كان معبودهم ومطاعهم اهويتهم.
