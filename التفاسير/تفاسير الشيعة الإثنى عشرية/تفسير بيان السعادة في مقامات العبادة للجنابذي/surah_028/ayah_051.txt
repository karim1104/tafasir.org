{ وَلَقَدْ وَصَّلْنَا } جملة حاليّة واستدراك لمّا توهّم من قوله { إِنَّ ٱللَّهَ لاَ يَهْدِي ٱلْقَوْمَ ٱلظَّالِمِينَ } انّه تعالى اهملهم ولم يأت لهم باسباب الهداية يعنى انّا لا نهديهم لعدم قابليّتهم وقبولهم والاّ فنحن لم نهملهم ووصّلنا { لَهُمُ ٱلْقَوْلَ } فى الاحكام والمواعظ والنّصائح والعبر والمواعيد بل وصّلنا لهم الاقوال الحقيقيّة الّذين هم خلفاؤنا فى الارض وقد فسّر فى الاخبار بامامٍ بعد امامٍ { لَعَلَّهُمْ يَتَذَكَّرُونَ } ما لهم وما عليهم فلا يتّبعون الهوى بغير هدىً من الله.
