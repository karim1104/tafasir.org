{ كَذَلِكَ } متعلّق بتصرفون و { حَقَّتْ } ابتداء كلام او متعلّق بحقّت وعلى اىّ تقدير فالجملة مستأنفة جواب لسؤالٍ مقدّرٍ كأنّه قيل: فلا ينبغى لاحدٍ ان ينصرف عنه فقال كحقّية الرّبوبيّة او ككون الضّلال بعد الحقّ او كانصرافهم عن الحقّ حقّت { كَلِمَةُ رَبِّكَ } اى الضّلال او حكمه بالضّلال او عدم ايمانهم { عَلَى ٱلَّذِينَ فَسَقُوۤاْ } خرجوا عن الحقّ او عن طاعة العقل او النّبىّ (ص) او الولىّ (ع) { أَنَّهُمْ لاَ يُؤْمِنُونَ } بتقدير الباء او اللاّم او بدل من كلمة ربّك.
