{ أَوْ يُزَوِّجُهُمْ ذُكْرَاناً وَإِنَاثاً } يعنى يعطى لبعضٍ الاناث فقط، ولبعضٍ الذّكور فقط، ويجمع بينهما لبعضٍ { وَيَجْعَلُ مَن يَشَآءُ عَقِيماً } فكلّ ذلك باعطاء الله ومنعه لا باسبابٍ طبيعيّةٍ كما يقوله الطّبيعىّ والّذين ينظرون الى الاسباب الطّبيعيّة { إِنَّهُ عَلِيمٌ } بصلاح كلٍّ وما يصلحه وما يفسده فيعطى ما يصلحه ويمنع ما يفسده { قَدِيرٌ } على ذلك سواء وافقه الاسباب الطّبيعيّة ام لم توافقه.
