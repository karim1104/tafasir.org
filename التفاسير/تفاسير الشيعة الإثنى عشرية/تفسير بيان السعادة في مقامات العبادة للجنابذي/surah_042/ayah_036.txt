{ فَمَآ أُوتِيتُمْ } عطف وتعقيب باعتبار الاخبار يعنى اذا علمتم ذلك فاعلموا انّ ما اوتيتم { مِّن شَيْءٍ } من حيث انّكم من ابناء الدّنيا { فَمَتَاعُ ٱلْحَيَاةِ ٱلدُّنْيَا } ولا بقاء له ولا خلوص من شوب الآلام وخوف الزّوال { وَمَا عِندَ ٱللَّهِ خَيْرٌ } لعدم شوبه بالآلام وخوف الزّوال { وَأَبْقَىٰ لِلَّذِينَ آمَنُواْ } متعلّق بخير وابقى، او خبر مبتدءٍ محذوفٍ اى ذلك للّذين آمنوا { وَعَلَىٰ رَبِّهِمْ يَتَوَكَّلُونَ } والمراد بالايمان الاسلام الحاصل بالبيعة العامّة وقبول الدّعوة الظّاهرة فيكون قوله وعلى ربّهم يتوكّلون اشارة الى الايمان الخاصّ الحاصل بالبيعة الخاصّة وقبول الدّعوة الباطنة.
