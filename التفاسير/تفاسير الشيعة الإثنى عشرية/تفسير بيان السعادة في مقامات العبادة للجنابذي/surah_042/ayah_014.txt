{ وَمَا تَفَرَّقُوۤاْ إِلاَّ مِن بَعْدِ مَا جَآءَهُمُ ٱلْعِلْمُ } بصحّة دين نبيّهم او بصدق خلافة علىٍّ (ع) فقبل بعضهم على علمٍ، وانكر بعضهم حسداً { بَغْياً بَيْنَهُمْ وَلَوْلاَ كَلِمَةٌ سَبَقَتْ مِن رَّبِّكَ } بامهالهم { إِلَىٰ أَجَلٍ مُّسَمًّى لَّقُضِيَ بِيْنَهُمْ } بالاهلاك للمنكر والخلاص للمقرّ من بين المنكر { وَإِنَّ ٱلَّذِينَ أُورِثُواْ ٱلْكِتَابَ مِن بَعْدِهِمْ } بعد الانبياء (ع) واممهم { لَفِي شَكٍّ مِّنْهُ مُرِيبٍ } وقد فسّر بغياً بينهم ببغى بعضهم على بعض لمّا رأوا من تفاضل امير المؤمنين (ع) وقوله تعالى لفى شكٍّ منه مريبٍ بانّه كناية عن الّذين نقضوا امر رسول الله (ص).
