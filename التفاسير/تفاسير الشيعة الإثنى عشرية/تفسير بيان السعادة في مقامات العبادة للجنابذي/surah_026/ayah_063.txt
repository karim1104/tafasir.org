{ فَأَوْحَيْنَآ إِلَىٰ مُوسَىٰ أَنِ ٱضْرِب بِّعَصَاكَ ٱلْبَحْرَ } وهو نهر النّيل فضرب البحر { فَٱنفَلَقَ } فانشقّ البحر اثنى عشر طريقاً بين كلّ طريق وطريق ماء كالجبل مشبّك بحيث يرى كلّ فريقٍ صاحبيهم { فَكَانَ كُلُّ فِرْقٍ } اى كلّ قطعةٍ من البحر يفرق بها بين طريقٍ وطريقٍ { كَٱلطَّوْدِ ٱلْعَظِيمِ } كالجبل العظيم، والفرق بكسر اسم لما انفرق كما انّ الفرق بالفتح مصدر.
