{ وَمَآ أَنتَ إِلاَّ بَشَرٌ مِّثْلُنَا وَإِن نَّظُنُّكَ } اى انّه نظنّك { لَمِنَ ٱلْكَاذِبِينَ فَأَسْقِطْ عَلَيْنَا كِسَفاً } جمع الكسفة كالكسف بالكسر والفتح { مِّنَ ٱلسَّمَآءِ إِن كُنتَ مِنَ ٱلصَّادِقِينَ قَالَ } بعد ما لم ينجح فيهم المحاجّة { رَبِّيۤ أَعْلَمُ بِمَا تَعْمَلُونَ } فان رآكم مستحقّين للعذاب واسقاط السّماء عليكم فعل بكم، وان رآكم مستحقّين للتّوبة ومستعدّين لرحمته وفّقكم.
