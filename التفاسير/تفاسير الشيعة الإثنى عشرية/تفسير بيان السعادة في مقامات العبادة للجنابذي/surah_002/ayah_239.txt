{ فَإنْ خِفْتُمْ } من عدوٍّ ولصٍّ وسبع { فَـ } ـحافظوا عليها { رِجَالاً } جمع راجل او رجيل او رجلان او رجل بكسر الجيم او ضمّه يعنى لا يلزم القيام والتّوقّف فى الصّلاة وقت الخوف { أَوْ رُكْبَاناً } جمع راكب ولا اختصاص له بركوب الجمل وغيره وعن الصّادق (ع) انّه قال: اذا خاف من سبعٍ او لصٍّ يكبّر يومئ ايماء { فَإِذَآ أَمِنتُمْ فَٱذْكُرُواْ ٱللَّهَ } فصلّوا، او المراد مطلق الذّكر، او المراد الذّكر القلبىّ الّذى هو صلاة الصّدر { كَمَا عَلَّمَكُم } ذكراً يكون مثل تعليمه ايّاكم يعنى يوازى تعليمه ايّاكم، او كذكر علّمكم بلسان خلفائه، او كالذّكر الّذى علّمكم بلسان خلفائه على ان يكون ما مصدريّةً او موصوفةً او موصولةً وعلى الاخيرين فقوله تعالى { مَّا لَمْ تَكُونُواْ تَعْلَمُونَ } يكون بدلا.
