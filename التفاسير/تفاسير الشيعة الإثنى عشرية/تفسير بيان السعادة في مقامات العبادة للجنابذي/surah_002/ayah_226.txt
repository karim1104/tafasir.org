{ لِّلَّذِينَ يُؤْلُونَ } يبعدون بالحلف { مِن نِّسَآئِهِمْ } بان يحلفوا ان لا يجامعوهنّ { تَرَبُّصُ أَرْبَعَةِ أَشْهُرٍ } من النّساء وأهلهنّ ومن حكّام الشّرع فلا يطالبوهم بشيءٍ من المضاجعة والطّلاق { فَإِنْ فَآءُوا } فى تلك المدّة بحنث ايمانهم وكفّارتها فلا شيء عليهم { فَإِنَّ ٱللَّهَ غَفُورٌ } يغفر ما فرط منهم بعد الكفّارة { رَّحِيمٌ } يرحمهم بترخيص المراجعة بعد الحلف.
