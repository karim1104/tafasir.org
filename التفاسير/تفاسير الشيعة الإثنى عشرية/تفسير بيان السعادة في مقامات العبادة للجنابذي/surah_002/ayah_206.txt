{ وَإِذَا قِيلَ لَهُ ٱتَّقِ ٱللَّهَ } اتّق سخط الله فى الافساد والاهلاك استنكف من نصح النّاصح لانّه لا يظنّ من نفسه سوى الاصلاح يعنى { أَخَذَتْهُ ٱلْعِزَّةُ } اى المناعة والاستنكاف { بِٱلإِثْمِ } اى بسبب الاثم الّذى اكتسبه قبل او اخذته العزّة بقيد الاثم الّذى ينهى عنه اى حملته العزّة على ازدياد الافساد والاهلاك للجاجته { فَحَسْبُهُ جَهَنَّمُ وَلَبِئْسَ ٱلْمِهَادُ } المهاد ككتاب الفراش والموضع الّذى يهيّئ للسكون عليه.
