{ لِيَمِيزَ ٱللَّهُ ٱلْخَبِيثَ مِنَ ٱلطَّيِّبِ وَيَجْعَلَ ٱلْخَبِيثَ بَعْضَهُ عَلَىٰ بَعْضٍ } لضيق السّفل وعدم سعته { فَيَرْكُمَهُ جَمِيعاً } فيجعله متراكماً متداقّاً { فَيَجْعَلَهُ فِي جَهَنَّمَ } بعد انتهاء حشره وتراكمه { أُوْلَـٰئِكَ هُمُ ٱلْخَاسِرُونَ } فى موضع التّعليل والاتيان بالمسند اليه باسم الاشارة موضع الضّمير لاحضار حالهم الفظيعة اشعاراً بعلّة الحكم، وتعريف المسند وضمير الفصل للتّأكيد والحصر.
