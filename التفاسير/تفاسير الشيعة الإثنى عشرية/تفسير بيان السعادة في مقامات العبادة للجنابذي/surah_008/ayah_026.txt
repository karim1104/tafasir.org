{ وَٱذْكُرُوۤاْ إِذْ أَنتُمْ قَلِيلٌ } من حيث العدد او من حيث المال ولفظ قليلٌ قد يفرد وقد يجمع { مُّسْتَضْعَفُونَ فِي ٱلأَرْضِ } تذكيرٌ لهم بنعمه والمراد ضعفهم قبل المهاجرة { تَخَافُونَ أَن يَتَخَطَّفَكُمُ ٱلنَّاسُ } من قريشٍ { فَآوَاكُمْ } الى المدينة { وَأَيَّدَكُم بِنَصْرِهِ وَرَزَقَكُمْ مِّنَ ٱلطَّيِّبَاتِ } من الغنائم وغيرها { لَعَلَّكُمْ تَشْكُرُونَ } وجعل الخطاب للعرب تماماً وجعل ضعفهم ذلّتهم عند الرّوم والعجم بعيدٌ جدّاً.
