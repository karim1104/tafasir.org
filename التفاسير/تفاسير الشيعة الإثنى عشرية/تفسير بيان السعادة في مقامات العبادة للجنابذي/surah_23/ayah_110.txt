{ فَٱتَّخَذْتُمُوهُمْ سِخْرِيّاً } قرئ بضمّ السّين وكسرها { حَتَّىٰ أَنسَوْكُمْ } يعنى صاروا بسبب اشتغالكم باستهزائهم اسباباً لنسيانكم { ذِكْرِى } واسباباً لضلالكم لا انّكم كنتم ضالّين بفطرتكم { وَكُنْتُمْ مِّنْهُمْ تَضْحَكُونَ } وهؤلاء كانوا اوليائى وكان الاستهزاء بهم استهزاءً بى فجزيتكم ذلك الجزاء واكرمتهم غاية الاكرام.
