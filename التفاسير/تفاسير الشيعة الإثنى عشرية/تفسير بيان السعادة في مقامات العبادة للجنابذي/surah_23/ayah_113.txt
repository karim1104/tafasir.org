{ قَالَ } اى قال الله او الملك الموكّل بهم وقرئ قل:على ان يكون امراً للملك الموكّل بهم { كَمْ لَبِثْتُمْ فِي ٱلأَرْضِ } اى حين الحيٰوة الدّنيا او فى ارض القبور بعد الموت { عَدَدَ سِنِينَ قَالُواْ لَبِثْنَا يَوْماً أَوْ بَعْضَ يَوْمٍ } فانّهم لدهشتهم ووحشتهم استقلّوا مدّة لبثهم فى الدّنيا او فى القبور { فَسْئَلِ ٱلْعَآدِّينَ } اى الملائكة الموكّلين بحفظ الاعوام والشّهور والايّام علينا يستشهدون الملائكة على صدق مقالتهم او كأنهم يلتفتون انّهم مخالطون متحيّرون فى تعيين الايّام والشّهور ويقولون: لا علم لنا بما نقول فاسئل الملائكة.
