{ حَتَّىٰ إِذَآ أَخَذْنَا مُتْرَفِيهِمْ } متنعّميهم { بِٱلْعَذَابِ } غاية لعملهم او لكون قلوبهم فى غمرة، وخصّ المترفين لانّهم كانوا منشاءً لكفرهم وكفر غيرهم؛ ولانّ المترفين لا يتنبّهون ولا يتضرّعون بمؤاخذة غيرهم، والمراد بالعذاب عذاب الموت والآخرة، او عذاب الدّنيا، وفسّر بقتلهم يوم بدرٍ وبالاخذ بالجوع حين دعا عليهم رسول الله (ص) فقال: " اللّهمّ اشدد وطأتك على مُضَر واجعلها عليهم سنين كسنى يوسف (ع) " فابتلاهم بالقحط حتّى اكلوا الجيف والكلاب { إِذَا هُمْ يَجْأَرُونَ } جأر كمنع رفع صوته بالدّعاء وتضرّع واستغاث.
