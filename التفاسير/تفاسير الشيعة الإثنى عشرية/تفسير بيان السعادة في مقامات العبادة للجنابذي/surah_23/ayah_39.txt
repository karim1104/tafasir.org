{ قَالَ رَبِّ ٱنْصُرْنِي بِمَا كَذَّبُونِ قَالَ } الله اجابة لدعائه { عَمَّا قَلِيلٍ لَّيُصْبِحُنَّ نَادِمِينَ فَأَخَذَتْهُمُ ٱلصَّيْحَةُ بِٱلْحَقِّ فَجَعَلْنَاهُمْ غُثَآءً } الغثاء ما احتمل السّيل من الزّبد والهالك والبالى { فَبُعْداً } بعدُوا بعداً حذف الفعل واقيم المصدر مقامه والقياس فبعداً لهم لكنّه وضع المظهر موضع المضمر للاشعار بعلّة الحكم وذمّ آخر لهم فقال { لِّلْقَوْمِ ٱلظَّالِمِينَ } والّلام للتّبيين وهو اخبار او دعاء عليهم والمعنى انّ الهلاكة ثابتة للقوم الظّالمين.
