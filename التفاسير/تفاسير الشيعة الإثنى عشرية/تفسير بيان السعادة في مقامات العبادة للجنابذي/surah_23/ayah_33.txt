{ وَقَالَ ٱلْمَلأُ مِن قَوْمِهِ ٱلَّذِينَ كَفَرُواْ وَكَذَّبُواْ بِلِقَآءِ ٱلآخِرَةِ } قولاً كمنكرى البعث او فعلاً وحالاً كأكثر اهل كلّ زمانٍ { وَأَتْرَفْنَاهُمْ } أنعمنا عليهم بنعمة أبطرتهم { فِي ٱلْحَيـاةِ ٱلدُّنْيَا مَا هَـٰذَا إِلاَّ بَشَرٌ مِّثْلُكُمْ يَأْكُلُ مِمَّا تَأْكُلُونَ مِنْهُ وَيَشْرَبُ مِمَّا تَشْرَبُونَ } ذكروا الجملتين لتأكيد التّشابه واستغراب التّفضيل.
