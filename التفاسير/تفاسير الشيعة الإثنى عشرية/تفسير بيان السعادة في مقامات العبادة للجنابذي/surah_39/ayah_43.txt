{ أَمِ ٱتَّخَذُواْ } ام منقطعة متضمّنة للاستفهام او مجرّدة عنه، او متّصلة محذوف معادلها والتّقدير اتّخذوا من دون الله آلهة يعبدونها ام اتّخذوا { مِن دُونِ ٱللَّهِ شُفَعَآءَ قُلْ } لهم اتتّخذونهم آلهةً او شفعاء { أَوَلَوْ كَـانُواْ لاَ يَمْلِكُونَ شَيْئاً } ممّا يملك { وَلاَ يَعْقِلُونَ } بمنزلة بل لا يعقلون.
